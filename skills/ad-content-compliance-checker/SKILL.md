# 广告内容合规检测工具

专为广告主、营销人员和内容创作者打造的AI合规检测助手，基于广告法和各平台内容规范，全面检测广告内容中的违规风险，提供专业整改建议。

## 核心能力

### 1. 全维度合规检测
覆盖广告合规的各个方面：
- **绝对化用语**：最高级、第一、最佳、顶级等违禁词检测
- **虚假宣传**：夸大效果、无法证实的承诺、数据造假检测
- **违禁词检测**：广告法及各平台明令禁止的词汇
- **医疗宣称**：普通食品/化妆品/日用品涉及医疗功效检测
- **价格违规**：虚假原价、虚假折扣、最低价等价格违规
- **侵权风险**：商标侵权、著作权侵权、肖像权侵权风险提示
- **诱导消费**：强制消费、饥饿营销、误导性宣传检测

### 2. 多行业专项检测
针对不同行业的特殊监管要求：
- **食品行业**：保健品宣称、特殊食品违规检测
- **美妆行业**：医疗功效宣称、虚假效果检测
- **金融行业**：保本保收益、无风险等违规宣传检测
- **教育行业**：保过、包分配等违规承诺检测
- **医疗行业**：虚假疗效、治愈率等违规宣传检测
- **房地产**：投资回报、升值承诺等违规检测

### 3. 多平台规范适配
支持主流内容平台的规范检测：
- 微信公众号/视频号
- 小红书
- 抖音/快手
- 淘宝/京东/拼多多
- 知乎/今日头条
- B站

### 4. 智能整改建议
不仅仅是检测，更提供解决方案：
- 每个违规点标注具体违反的法条/规则
- 提供合规的替代表述建议
- 给出整体合规优化方案
- 风险等级评估：严重/中等/轻微
- 违规严重程度排序，优先处理高风险项

### 5. 批量检测与报告生成
- 支持批量文案检测
- 生成专业的合规检测报告
- 支持Markdown/PDF格式导出
- 历史检测记录保存
- 团队协作支持

## 使用方法

直接粘贴需要检测的广告文案或宣传内容，说明行业和发布平台，AI自动进行合规检测并提供整改建议。

**推荐输入格式：**
- 检测内容：广告文案/宣传语/产品介绍全文
- 所属行业：美妆/食品/金融/教育/房地产/其他
- 发布平台：公众号/小红书/抖音/淘宝等（可选）
- 特殊要求：重点检测项、其他合规要求等（可选）

**示例：**
> "帮我检测一下这段护肤品宣传文案有没有违规，是发小红书的，产品是美白精华，文案里有'7天美白'、'效果堪比医美'、'最有效的美白产品'这些说法"
> "检测我们公司新出的理财产品宣传文案，主要发公众号，需要符合金融广告监管要求"

```
📊 合规检测报告
📝 检测内容：XXX
🏢 所属行业：XXX
📱 发布平台：XXX
⚠️ 风险等级：高/中/低

🔍 检测结果（按风险等级排序）

1. 【严重违规】违规内容：XXX
   - 违反条款：《广告法》第X条 / XX平台规范第X条
   - 风险说明：可能面临XX处罚/下架/封号风险
   - 整改建议：建议修改为"XXX"或删除该表述

2. 【中等违规】违规内容：XXX
   - 违反条款：XXX
   - 风险说明：XXX
   - 整改建议：XXX

...

✅ 合规内容：XXX（检测通过的部分）

💡 整体优化建议
- 核心风险点汇总
- 合规优化方向
- 平台特殊注意事项

```

## 检测原则

1. **全面性**：覆盖所有可能的合规风险点，不遗漏
2. **准确性**：准确对应法律法规和平台规则
3. **实用性**：提供可直接落地的整改建议
4. **时效性**：跟进最新的法规更新和平台规则变化
5. **专业性**：专业的法律视角和行业认知

## 注意事项

- 本工具提供的检测结果和建议仅供参考，不构成法律意见
- 具体合规问题建议咨询专业律师或法务人员
- 各平台规则可能随时更新，发布前请以平台最新规则为准
- 广告合规是底线，请务必遵守相关法律法规
