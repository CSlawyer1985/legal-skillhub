# 典型纠纷的可视化提示

以下内容是选图和提问的提示，不是实体法规则或完整办案清单。任何法条、程序期限、案由和裁判规则必须另行核验现行权威来源。

## 借款与担保类

- 合同签署主体、实际收付款主体和最终资金使用主体是否一致？
- 是否存在委托支付、代偿、以物抵债、债权转让或其他特殊履行路径？
- 多笔借款与多笔还款能否逐笔勾稽，计息口径和余额如何形成？
- 担保关系、期间和责任范围是否应另画关系/程序图？

优先模式：关系图 + 资金流 + 逐笔数据表 + 必要时间线。

## 票据类

- 人、款项、票据/单据三条链是否一致？
- 出票、背书、交付、提示、拒付和追索的主体与时间如何对应？
- 票面关系与基础交易关系是否需要分层？
- 虚假、断裂或有争议的背书/流转节点有哪些？

优先模式：票据流转关系图 + 时间线 + 资金/基础交易对照。

## 建设工程类

- 发包、承包、分包、实际施工、供应、监理等主体链如何形成？
- 合同链与实际施工/付款/材料流是否一致？
- 开工、停工、变更、签证、验收、结算等阶段如何排列？
- 工程量、进度款、结算价、质量缺陷和责任主张能否分表核算？
- 项目分区或标段是否需要空间示意，而不是一张总关系图？

优先模式：合同/主体关系图 + 分阶段时间线 + 工程量/付款矩阵 + 项目示意。

## 土地开发与房地产合作类

- 土地权利、开发主体、项目公司、出资和收益分配如何分层？
- 行政审批流程与当事人合同义务是否被错误混为一体？
- 名义权利、实际投入、控制和收益是否存在错位？
- 不同阶段的合同、证照、付款和交付如何对应？

优先模式：项目结构图 + 权利/合同关系图 + 审批流程（现行法核验后）+ 资金表。

## 国际货物买卖类

- 货物、单据、资金和指令分别经过哪些主体？
- 买卖、运输、保险、信用证/结算、代理等关系是否分层？
- 交付、风险转移、检验、通知和付款的时间点分别是什么？
- 法域、准据法、公约和惯例状态是否已由权威来源核验？

优先模式：多泳道流向图 + 时间线 + 关系分层图；不要用一条箭头混合货物、单据和资金。

## 公司与股权类

- 工商登记、协议安排、实际出资、表决、控制和收益是否一致？
- 静态股权结构与历次变化是否分开表达？
- 直接持股、间接控制、代持或利益共同体是事实、主张还是推论？
- 股权、价款和公司控制的流向能否用统一交易 ID 对应？

优先模式：静态股权结构 + 动态变更时间线/流向图 + 争点证据矩阵。

## 使用边界

- 上述案型来自 2017 年出版的民商事经验，不能自动覆盖其他法域、刑事/行政/家事/劳动事项。
- 类型化提示若与具体材料冲突，以材料和现行权威法源为准。
- 图表只帮助看见结构与缺口，不替代专业判断、鉴定、审计或证据核验。
