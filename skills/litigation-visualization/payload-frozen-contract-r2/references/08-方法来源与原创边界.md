# 方法来源与原创边界

## 原创控制基底

本包的控制结构来自李时瑀律师团队原创的“案由诉讼 Skill 蒸馏方法论 V1.0”及融资租赁合同纠纷真实试点，包括：授权与只读基线、答案键隔离、事实/证据/法源 SSOT、隐私封装、三席独立验收、冻结和发布权限分离。

这些控制面决定优先于 donor 的便利性设计。

## 仓颉方法启发

参考项目：[kangarooking/cangjie-skill](https://github.com/kangarooking/cangjie-skill)

本包吸收并重新实现的思想包括：完整理解后提取、多镜头候选池、保留 rejected 轨迹、原子化、触发/边界表达、知识链接、正负边界压力测试和断点续跑。

法律专用改写包括：

- 书籍单一输入扩展为案件、法源资料、课程和实务经验；
- RIA/预测力/独特性筛选替换为来源、法源、复现和误用四重门禁；
- 一般引文规则替换为可定位、可校验、可核验时效的法律来源协议；
- 自动安装和特定 darwin 工具依赖被舍弃；
- 每阶段用户确认优化为默认一键本地构建，仅在权利、隐私、法源和发布门停下。

本包未复制仓颉的程序代码或原始模板正文。

## 姚金刚 GEORank 与 GEO 方法启发

参考项目：姚金刚（GitHub 账号 `yaojingang`）的 [yaojingang/GEORank](https://github.com/yaojingang/GEORank)

GEORank 自带 Skill 的定位是操作已部署实例的 API，不是通用 GEO 策略。本包不继承其 HTTP 客户端、会话、管理员能力或平台部署栈；只对仓库中公开表达、结构化数据、查询、诊断和 30/60/90 规划思想进行法律化改写。

明确舍弃：

- GEORank 平台运行依赖和管理员接口；
- 将启发式综合分当作法律质量或真实排名；
- 确定性伪关键词业务分数；
- 对排名、引用、流量或转化作保证。
