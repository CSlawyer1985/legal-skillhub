# 法律四重验证与候选晋升

验证采用门禁，不以一个综合分掩盖致命缺陷。L1 或 L2 不通过即不得晋升；任何 P0 风险都优先于内容价值。

## L1 来源忠实度

检查：

- 命题是否能回到具体页、段、条款、事件或访谈片段；
- 是否保留例外、限定、否定和时间条件；
- OCR、转述或翻译是否改变意思；
- 多来源是否真正独立，而非彼此复制；
- 推论是否与来源陈述分开。

结果：`pass`、`narrow-and-retest` 或 `reject`。

## L2 法源、法域与时效

检查：

- 规范层级、发布机关、适用法域和生效日期；
- 修订、废止、失效、过渡条款和司法解释；
- 案例是约束性、指导性、参考性还是仅为事实样本；
- 二手资料是否已回溯权威文本；
- 结论是现行法、争议观点、地区实践还是历史规则。

动态法源必须记录 `law_checked_at`。无法确认当前有效性时进入 `HOLD-LEGAL`，不得用模型记忆补齐。

## L3 可复现、反事实与边界

至少使用两类独立验证：

- 不同案件或公开样本的复跑；
- 改变一个关键事实的反事实测试；
- 正例、反例和边界例对照；
- 由独立审查席按相同输入复算；
- 对程序、证据或法源缺失情况做降级测试。

只在一个成功案例中成立的动作可以保留为案例注释，不得伪装为通用 Skill。

## L4 原创增量与误用风险

判断候选是否：

- 比常识、原法条或既有 Skill 增加了触发条件、动作链、证据结构或失败边界；
- 能指导可观察动作，而非仅作概念摘要；
- 会导致未经律师复核的确定性结论、结果承诺或越权操作；
- 会把客户秘密、个人经验或地域惯例误写成普遍规则；
- 与相邻 Skill 高度重叠并造成误触发。

无增量的内容降级为 glossary、reference 或 example；高误用风险且无法通过边界控制的内容舍弃。

## 验证记录最小字段

```json
{
  "record_id": "akr-example-001",
  "l1_source_fidelity": {"result": "pass", "evidence": []},
  "l2_legal_validity": {"result": "pass", "checked_at": "YYYY-MM-DD", "evidence": []},
  "l3_reproducibility": {"result": "pass", "tests": []},
  "l4_value_and_misuse": {"result": "pass", "risks": []},
  "decision": "verified",
  "reviewer": "independent-seat",
  "reviewed_at": "YYYY-MM-DD"
}
```

验证记录只写可复核证据，不记录隐含推理链或未经脱敏的案情。
