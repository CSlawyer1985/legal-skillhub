# 💀 清算分配模板

## 一、破产财产变价方案

### 1.1 变价原则
- 价值最大化原则（评估先行+公开变价+竞争机制）
- 程序合规原则（债权人会议表决+法院批准+公开监督）
- 及时变现原则（防止资产贬值）

### 1.2 变价方式

| 方式 | 适用资产 | 操作流程 | 优势 | 劣势 |
|:-----|:---------|:---------|:-----|:-----|
| **拍卖** | 不动产/动产/股权/知识产权等 | 委托拍卖机构+公告+竞拍 | 公开透明+价格发现 | 周期较长+佣金成本 |
| **变卖** | 小额资产/不易保存资产 | 公开询价+协议出售 | 快速变现 | 价格可能偏低 |
| **网络司法拍卖** | 各类财产（推荐） | 淘宝/京东等司法拍卖平台 | 覆盖面广+成本低+透明 | 技术操作要求 |
| **协议转让** | 特定资产（如需行政批准） | 协商+评估+批准 | 灵活+定向 | 公允性需论证 |
| **折价抵债** | 流拍资产/实物分配 | 评估后折价给债权人 | 处置效率高 | 债权人接受度 |

### 1.3 变价方案要点
- [ ] 各类资产的评估方法（市场法/收益法/成本法）
- [ ] 评估机构选任（管理人委托+法院备案）
- [ ] 拍卖底价确定（评估价/评估价的80%/一再降价规则）
- [ ] 流拍处理（二次拍卖/变卖/折价抵债）
- [ ] 特殊资产处置方案（在建工程/知识产权/采矿权/排污权/特许经营权）

## 二、分配方案

### 2.1 分配顺序（《企业破产法》第113条）

```
破产费用（诉讼费+管理/变价/分配费用+管理人报酬）
    ↓
共益债务（破产程序中的新债务，随时清偿）
    ↓
第一顺位：职工债权
    ├── 工资/奖金/津贴/补贴
    ├── 基本养老/基本医疗保险费
    └── 经济补偿金
    ↓
第二顺位：税款债权
    ├── 欠缴税款（不含罚款/滞纳金）
    └── 社保（基本养老/基本医疗之外的社保）
    ↓
第三顺位：普通债权
    ├── 无担保的合同债权
    ├── 侵权债权
    ├── 无因管理/不当得利
    └── 附条件/附期限债权（条件成就前提存）
    ↓
劣后债权（如有）
    └── 股东借款/关联方债权等
```

### 2.2 分配方案内容

```
                         破产财产分配方案

债务人：[企业名称]
案号：[（ ）破字第  号]

一、参加分配的债权总额
  1. 有财产担保债权：___万元
  2. 职工债权：___万元
  3. 税款债权：___万元
  4. 普通债权：___万元
  5. 劣后债权：___万元
  合计：___万元

二、可供分配的破产财产总额：___万元

三、破产费用与共益债务
  1. 诉讼费：___万元
  2. 财产管理与变价费用：___万元
  3. 管理人报酬：___万元
  4. 其他费用：___万元
  5. 共益债务：___万元
  合计：___万元

四、各顺位分配
  第一顺位（职工债权）
    应分配额：___万元  清偿比例：___%
  第二顺位（税款债权）
    应分配额：___万元  清偿比例：___%
  第三顺位（普通债权）
    应分配额：___万元  清偿比例：___%

五、分配方式
  1. 分配时间：[具体时间安排]
  2. 分配方式：□现金 □实物 □其他
  3. 提存安排：[附条件/未决债权的提存]
  4. 追加分配：[如发现可分配财产的追加分配安排]

六、分配方案的执行
  1. 分配方案由管理人执行
  2. 分配完毕后管理人向法院提交执行报告
  3. 未受领的分配额提存+公告（满2个月不受领归入国库）
```

## 三、破产终结程序

### 3.1 终结条件
- [ ] 破产财产已分配完毕/无可分配财产
- [ ] 重整计划执行完毕
- [ ] 和解协议执行完毕

### 3.2 终结后工作清单
- [ ] 管理人提交破产终结申请
- [ ] 法院裁定终结破产程序（公告）
- [ ] 管理人提交了结执行的申请（执转破案件）
- [ ] 办理税务注销（完税证明+注销登记）
- [ ] 办理工商注销（清算报告+注销登记）
- [ ] 银行账户销户（管理人账户销户）
- [ ] 印章销毁（管理人印章+债务人印章）
- [ ] 档案归档（破产卷宗+会计档案+人事档案）
- [ ] 追加分配准备（如后续发现应分配财产）
