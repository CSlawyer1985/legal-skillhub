# 🏛️ 债权人会议策略模板

## 一、表决权速查卡

### 1.1 普通决议（财产管理方案/变价方案/分配方案/其他事项）

```
✅ 通过条件（双重多数决）：
   ① 出席会议的债权人人数过半数
   ② 所代表的债权额占无财产担保债权总额的1/2以上

⚠️ 关键规则：
   • 有财产担保的债权人，未放弃优先受偿权的，对普通决议事项不享有表决权
   • 债权尚未确定的债权人，法院可为其设定临时债权额（赋予临时表决权）
   • 债务人/管理人等利害关系人不得参与表决

📐 计算示例：
   出席会议：50人（有表决权的40人）
   同意：26人（人数过半✓）+ 债权额5800万/1亿=58%（过1/2✓）
   → √ 通过
```

### 1.2 重整计划分组表决

```
✅ 每组通过条件（双重多数决）：
   ① 该组出席会议的债权人过半数同意
   ② 所代表的债权额占该组债权总额的2/3以上

📐 示例（普通债权组）：
   该组总债权额：2亿
   出席人数：120人
   同意：68人（人数过半数✓）+ 债权额1.5亿/2亿=75%（占2/3以上✓）
   → √ 该组通过
```

### 1.3 和解协议表决

```
✅ 通过条件（双重多数决）：
   ① 出席会议的债权人过半数同意
   ② 所代表的债权额占无财产担保债权总额的2/3以上

⚠️ 有财产担保的债权人不参与和解协议表决
```

### 1.4 出资人组表决

```
✅ 通过条件：
   出资人所持表决权2/3以上通过

📐 示例：
   出席出资人代表股份：8000万股（总股本1亿股）
   同意：5500万股（占出席的68.75% = 未达2/3）
   → ✗ 未通过
```

## 二、各类型会议表决速查表

| 表决事项 | 表决权人 | 人数要求 | 债权额要求 | 特殊规则 |
|:---------|:---------|:---------|:-----------|:---------|
| 核查债权 | 全体债权人（含担保债权人） | 不需表决 | 不需表决 | 核查≠确认，异议需15日内起诉 |
| 财产管理方案 | 无担保债权人 | >1/2 | >1/2 | 一次表决不通过→法院裁定 |
| 变价方案 | 无担保债权人 | >1/2 | >1/2 | 同上 |
| 分配方案 | 无担保债权人 | >1/2 | >1/2 | 同上 |
| 重整计划 | 各分组分别表决 | 各组>1/2 | 各组>2/3 | 分组表决+强裁可能 |
| 和解协议 | 无担保债权人 | >1/2 | >2/3 | 担保债权人不参与 |
| 选任债委会 | 全体债权人（含担保债权人） | >1/2 | >1/2 | — |
| 更换管理人 | 全体债权人（含担保债权人） | >1/2 | >1/2 | 需说明理由+法院同意 |

## 三、债权人会议议事规则

### 3.1 会议召开
- 第一次债权人会议：债权申报期满后15日内召开（法院召集）
- 后续会议：法院认为必要时/管理人/债委会/占债权额1/4以上的债权人提议

### 3.2 会议程序
```
主席宣布开会
    │
    ├── 管理人报告（履职情况+财产状况+债权审查+其他）
    │
    ├── 核查债权（逐笔或批量核查+债权人质询）
    │
    ├── 审议表决事项
    │   ├── 管理人说明方案
    │   ├── 债权人提问+管理人/债务人回答
    │   └── 投票表决（现场/书面/网络）
    │
    ├── 选任债权人委员会（如需）
    │
    └── 宣布表决结果+闭会
```

### 3.3 表决方式
- 现场投票（传统方式）
- 书面表决（不需要现场+邮寄/传真/电子邮件）
- 网络表决（全国企业破产重整案件信息网+微信小程序等）
- 结合方式（部分现场+部分书面+部分网络）

### 3.4 会议决议
- 决议效力：对全体债权人（包括未出席/反对的债权人均有约束力）
- 决议撤销：债权人认为决议违反法定程序/损害其利益的→15日内申请法院撤销

## 四、债权人参与策略

### 4.1 会前准备
- [ ] 确认债权是否已被认可+认可的金额和性质
- [ ] 确认是否有表决权（有担保债权人在无担保事项上无表决权）
- [ ] 计算表决份额（自己所代表的债权额占该组的比例）
- [ ] 研读会议材料（管理人报告/财产管理方案/重整计划草案等）
- [ ] 准备发言提纲+质询问题
- [ ] 确定投票意向+备选方案

### 4.2 表决策略选择

| 对方案的态度 | 策略 | 后续动作 |
|:------------|:-----|:---------|
| **同意** ✅ | 投赞成票+推动其他债权人支持 | 监督方案执行 |
| **反对** ❌ | 投反对票+联合其他债权人阻止 | 提出替代方案/申请撤决议 |
| **弃权** ⏸️ | 保持中立 | 保留诉讼权利 |
| **有条件同意** | 投票赞成+在决议中附条件 | 监督条件实现 |

### 4.3 异议救济
- 决议撤销之诉（15日内向法院提起）
- 损害赔偿请求（如管理人/债务人故意损害债权人利益）
