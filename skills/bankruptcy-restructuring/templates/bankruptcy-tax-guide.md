# 📊 破产税务处理模板

## 一、破产程序中的主要涉税问题

| 阶段 | 涉税事项 | 涉及税种 | 处理要点 |
|:-----|:---------|:---------|:---------|
| **受理前** | 欠缴税款+滞纳金+罚款 | 各税种 | 欠税列入税款债权；滞纳金在受理日停止计算；罚款作为普通债权 |
| **清算变价** | 资产处置 | 增值税+土增税+契税+印花税+所得税 | 拍卖/变卖资产→发生纳税义务 |
| **清算分配** | 分配 | 所得税（如有分配所得） | 债权人取得分配财产的税务处理 |
| **重整期间** | 继续经营 | 增值税+所得税+其他 | 正常纳税申报+可能的税收优惠 |
| **重整计划** | 债务减免+债转股 | 所得税 | 债务减免→可能产生所得税（需适用特殊性税务处理） |
| **终结** | 税务注销 | — | 完税证明+税务注销登记 |

## 二、破产程序中各类债权的税务定性

| 债权类型 | 税务认定 | 处理规则 |
|:---------|:---------|:---------|
| **欠缴税款** | 税款债权（第二顺位） | 以法院受理日为截止日；不含罚款 |
| **税款滞纳金** | 普通债权 | 受理日起停止计算+作为普通债权申报 |
| **税务罚款** | 普通债权 | 行政处罚纳入普通债权 |
| **社保欠费** | 职工债权（基本养老+基本医疗）/税款债权（其他社保） | 按险种区分顺序 |
| **增值税进项留抵** | 可抵扣权益 | 管理人可以继续抵扣（需税务机关配合） |
| **预缴税款** | 应退税款 | 纳入破产财产清理范围 |

## 三、清算变价的税务处理

### 3.1 各资产类别的增值税处理

| 资产类别 | 增值税处理 | 税率 |
|:---------|:-----------|:-----|
| 不动产（2016年4月30日前取得） | 简易计税 | 5% |
| 不动产（2016年5月1日后取得） | 一般计税 | 9%/5% |
| 动产（旧设备/车辆等） | 简易计税（依条件） | 3%减按2%/13% |
| 无形资产/股权 | 不征增值税（股权）/6%（无形资产） | —/6% |
| 存货 | 正常销售 | 13%/9% |

### 3.2 土地增值税
- 不动产拍卖/变卖→涉及土地增值税的清算（四级超率累进税率30%-60%）
- 破产程序中的土增税能否减免→各地税务机关政策不同
- 管理人需在资产处置前测算土增税影响（可能严重影响可供分配财产）

### 3.3 企业所得税
- 清算所得=资产处置收入-资产计税基础-清算费用-损失
- 清算所得并入企业当年应纳税所得额
- 亏损弥补：可向前弥补5年（高新技术企业/科技型中小企业10年）

## 四、重整税务特别处理

### 4.1 债务减免的所得税处理

```
债务减免金额：1亿元
    │
    ├── 一般税务处理：减免的债务→计入应纳税所得额（缴税2500万）
    │
    └── 特殊性税务处理（适用条件）：
        ├── 债务人经营困难+债权人让步
        ├── 债务重组所得占应纳税所得额50%以上
        ├── 可分期纳税（5年均匀计入）
        └── 债转股：暂不确认债务重组所得
```

### 4.2 债转股的税务处理

| 税种 | 处理规则 | 要点 |
|:-----|:---------|:-----|
| **企业所得税** | 债务人和债权人均暂不确认所得/损失（特殊性税务处理） | 债转股视为"债务清偿+股权投资"两个步骤 |
| **印花税** | 股权转让书据或增资协议→按万分之五贴花 | 资金账簿贴花 |
| **增值税** | 不征增值税 | 债转股不属于增值税应税行为 |

### 4.3 重整税收优惠（各地政策差异较大）
- 重整企业欠税的分期缴纳
- 重整期间房产税/城镇土地使用税的减免（部分地区）
- 资产重组中的增值税不征税优惠（整体资产转让/合并/分立/划转等）
- 关联企业间资产划转的企业所得税递延

## 五、税务注销流程

### 5.1 注销前置条件
- [ ] 完成破产清算/重整/和解
- [ ] 清算所得已申报+清算所得税已缴纳
- [ ] 发票已缴销
- [ ] 税务登记证件已交回（如有）
- [ ] 无欠税/滞纳金/罚款（或已按破产程序处理）

### 5.2 注销流程
```
管理人向税务机关提交注销申请
    │
    ├── 提交材料：
    │   ├── 法院终结破产程序裁定书
    │   ├── 管理人身份证明
    │   ├── 清算报告（含税务处理情况）
    │   ├── 最后一期纳税申报表
    │   └── 发票缴销凭证
    │
    ├── 税务机关审核
    │   ├── 无欠税→出具清税证明
    │   └── 有欠税→按破产程序处理→出具清税证明
    │
    ├── 税务注销登记（在市场监管部门办理工商注销前完成）
    │
    └── 联动 [[tax-compliance]] 进行专项审查
```

## 六、税务债权申报与审核

### 6.1 税务债权申报材料
- 欠税明细（税种+所属期+金额）
- 滞纳金计算清单
- 税务处理决定书（如有）
- 其他证明材料

### 6.2 税务债权审核要点
- 税款真实性（欠税是否确实发生+有无争议）
- 税款计算准确性（适用税率+计税依据）
- 截止时间（受理日截止+受理日后产生的税款为共益债务或破产费用）
- 罚款/滞纳金/税款的区分（后者优先于前两者）
