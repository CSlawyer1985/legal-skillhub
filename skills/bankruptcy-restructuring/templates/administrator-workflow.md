# 📋 管理人工作流程模板

## 一、管理人履职全流程时间线

```
受理日（T日）
    │
T+0 至 T+7（7日内紧急事项）
    ├── 刻制管理人印章
    ├── 开立管理人银行账户
    ├── 办理债务人财产保全（如有必要）
    ├── 公告受理破产申请
    └── 通知已知债权人（受理日起25日内）
    │
T+7至债权申报期满
    ├── 接管债务人（印章/证照/财务/人事/IT/档案）
    ├── 债务人财产调查（审计+评估+产权调查）
    ├── 债务人有关人员谈话+职工情况调查
    ├── 应收款追收+取回权/别除权处理
    ├── 继续/停止营业决定（如需）
    └── 债权申报登记+审查
    │
债权申报期满后15日内
    └── 召开第一次债权人会议
        ├── 管理人报告（履职/债权审查/财产状况）
        ├── 债权人核查债权
        ├── 选任债权人委员会
        └── 表决（财产管理方案/变价方案等）
    │
后续程序
    ├── 清算程序：变价方案→分配方案→执行→终结
    ├── 重整程序：重整计划草案（6+3个月）→表决→批准→执行监督→终结
    └── 和解程序：和解协议草案→表决→批准→执行→终结
```

## 二、7日内紧急事项检查清单

- [ ] 收到指定管理人决定书+受理裁定书
- [ ] 刻制管理人印章（公章+财务章+负责人名章）
- [ ] 开立管理人银行账户
- [ ] 公告破产受理（全国企业破产重整案件信息网+指定报纸）
- [ ] 通知已知债权人（邮寄+公告）
- [ ] 债务人财产保全申请（如有必要）
- [ ] 向债务人有关人员发出配合通知书
- [ ] 制定内部管理制度（印章使用/财务报销/档案保管）
- [ ] 组建管理人工作团队（主办律师+助理+财务+审计）

## 三、接管检查清单

### 3.1 文书与证照
- [ ] 营业执照正副本
- [ ] 公章/合同章/财务章/发票章/法人章
- [ ] 其他专用章（报关/质检/招投标等）
- [ ] 行政许可/资质证书/行业准入文件
- [ ] 法定代表人/股东会/董事会决议文件

### 3.2 财务资料
- [ ] 会计凭证（原始凭证+记账凭证）
- [ ] 会计账簿（总账+明细账+日记账+辅助账）
- [ ] 财务报表（年报+季报+月报）
- [ ] 银行账户资料（开户许可证+银行流水+余额对账单）
- [ ] 税务资料（纳税申报表+完税证明+发票存根）
- [ ] 审计报告

### 3.3 资产资料
- [ ] 不动产（房产证+土地使用权证+租赁合同）
- [ ] 动产（设备清单+车辆登记证+存货清单）
- [ ] 知识产权（专利/商标/著作权证书）
- [ ] 股权/投资（对外投资企业清单+股权证明）
- [ ] 应收款（应收账款明细+合同+催收记录）
- [ ] 现金/银行存款（盘点+核对）

### 3.4 合同与诉讼仲裁
- [ ] 重大合同（采购/销售/借款/租赁/担保/合作等）
- [ ] 劳动合同（全体职工花名册+合同+社保记录）
- [ ] 诉讼/仲裁/执行案件材料
- [ ] 律师函/催收函/法律文书

### 3.5 IT与档案
- [ ] 财务软件/ERP系统/业务系统的管理员权限
- [ ] 电子邮件系统
- [ ] 电子数据备份
- [ ] 人事档案/行政档案/技术档案

## 四、债权审查流程

```
债权申报登记
    │
    ├── 形式审查（材料是否齐全）
    │   └── 不齐→通知补充
    │
    ├── 实质审查
    │   ├── 真实性（合同+履行+付款）
    │   ├── 合法性（不违法/不违公序良俗）
    │   └── 关联性（债务人与债权人+与破产程序相关）
    │
    ├── 债权性质认定
    │   ├── 有担保/无担保
    │   ├── 职工/税款/普通/劣后
    │   └── 附条件/附期限/未决
    │
    ├── 债权金额认定
    │   ├── 本金（确认无误）
    │   ├── 利息（截止受理日+停止计息）
    │   └── 违约金/赔偿金（不超法定上限）
    │
    ├── 编制债权表
    │   ├── 确认债权
    │   ├── 不予确认债权
    │   └── 待确认债权（诉讼未决/附条件）
    │
    └── 债权异议处理
        ├── 债权人/债务人提出异议
        ├── 管理人复核+书面说明
        └── 异议人15日内向法院起诉
```

## 五、管理人履职风险防范

### 5.1 程序合规要点
- [ ] 所有重要决定经法院批准（财产处分/担保物处置/合同解除等）
- [ ] 债权人会议通知及时+规范（15日前书面通知）
- [ ] 债权审查客观公正（不偏袒任何一方）
- [ ] 分配严格按法定顺序（不逾越顺序）
- [ ] 信息披露充分（财务状况+重大事项及时披露）

### 5.2 费用控制
- [ ] 管理人报酬按法院批准方案收取（不超法定上限）
- [ ] 各项支出有据可查+合理必要
- [ ] 聘用专业人员的必要性论证+费用合理
- [ ] 破产费用与共益债务区分清晰

### 5.3 利益冲突避免
- [ ] 管理人及其团队成员与债务人/债权人无利益关系
- [ ] 管理人不得自营/为他人经营与债务人同类业务
- [ ] 管理人不得收受债务人/债权人财物

### 5.4 报告义务
- [ ] 定期向法院报告（工作进展/财产状况/重大事项）
- [ ] 债权人会议要求报告的事项
- [ ] 重大事项即时报告（影响债权人利益的重大资产处置等）
