# 🌐 跨境破产模板

## 一、跨境破产法律框架

### 1.1 中国跨境破产制度核心依据

| 文件 | 主要内容 | 实务要点 |
|:-----|:---------|:---------|
| 《企业破产法》第5条 | 跨境破产的承认与协助原则；互惠原则+公共政策例外 | 目前法院主要依据 |
| 内地与香港跨境破产安排（2021） | 内地破产程序可在香港承认+管理人可在香港行使权力；反之亦然 | 实操性最强 |
| 香港跨境破产补充机制（2024） | 扩大适用范围+简化程序 | 最新动态 |
| 联合国贸法会《跨境破产示范法》 | 国际通行规则（COMI+自动中止+平行程序协调） | 中国未加入，但法院参照适用 |
| 中国与有关国家签订的双边司法协助条约 | 民商事判决的承认与执行（包括破产相关） | 看具体条约内容 |

### 1.2 核心概念

| 概念 | 说明 | 实务意义 |
|:-----|:-----|:---------|
| COMI（主要利益中心） | 债务人主要利益所在地（注册地/营业地/管理地） | 确定主破产程序所在地 |
| 外国主要程序 | COMI所在国的破产程序 | 自动获得承认+自动中止效果 |
| 外国非主要程序 | 债务人设有营业所的国家的破产程序 | 仅就该营业所资产产生效力 |
| 自动中止 | 破产程序获得承认后，对债务人资产的执行/诉讼自动中止 | 防止"抢跑" |
| 平行程序 | 同一债务人在多国同时进行破产程序 | 需要协调配合 |

## 二、内地破产程序在香港的承认与协助

### 2.1 申请条件（2021年安排+2024年补充机制）
- 债务人主要利益中心（COMI）在内地
- 内地破产程序已受理
- 管理人已获法院指定
- 不违反香港公共政策

### 2.2 申请流程

```
内地管理人聘请香港律师
    │
    ├── 准备申请材料：
    │   ├── 内地法院受理破产裁定（经公证+加签）
    │   ├── 指定管理人决定书
    │   ├── 管理人的身份证明
    │   ├── 债务人COMI在内地的证明
    │   └── 案件情况说明（支持性宣誓书）
    │
    ├── 向香港高等法院原讼法庭提交申请
    │
    ├── 法院审查
    │   ├── 符合条件→作出协助命令
    │   └── 不符合条件→驳回（可上诉）
    │
    ├── 协助命令的效力
    │   ├── 中止对债务人资产在香港的执行
    │   ├── 管理人可在香港行使权力
    │   ├── 管理人可要求相关人员提供信息
    │   └── 管理人可管理/处置债务人位于香港的资产
    │
    └── 管理人在香港履职
        ├── 追收债务人位于香港的资产
        ├── 在香港法院提起相关诉讼（如需）
        └── 管理/处置香港资产+分配
```

### 2.3 材料清单
- [ ] 内地法院受理破产申请的裁定书（公证+加签认证）
- [ ] 指定管理人的决定书
- [ ] 管理人的身份证明+授权委托书
- [ ] 债务人COMI在内地的证明（注册地/主要营业地/管理地/账簿保管地）
- [ ] 债务人资产在香港的初步证据（如有）
- [ ] 支持性宣誓书（内地法律专家的法律意见）

## 三、香港破产程序在内地的承认

### 3.1 申请条件
- 债务人COMI在香港
- 香港破产程序已启动
- 不违反内地公共政策
- 互惠关系成立（2021年安排已建立互惠基础）

### 3.2 申请流程
```
香港清盘人/受托人聘请内地律师
    │
    ├── 向债务人COMI所在地的中级人民法院提出申请
    │
    ├── 法院审查
    │   ├── 对等互惠（已有基础）
    │   ├── 不违反公共政策
    │   └── 不损害内地债权人利益
    │
    └── 承认后的效力
        ├── 中止对债务人资产在内地的执行
        ├── 清盘人可在内地行使权力
        └── 内地资产纳入破产财团
```

## 四、跨境破产中的主要挑战

| 挑战 | 说明 | 应对建议 |
|:-----|:-----|:---------|
| **互惠原则的不确定性** | 与不同国家的互惠关系不明确 | 提前研究双边司法协助条约+先例 |
| **公共政策例外** | 法院可以"损害公共利益"为由拒绝承认 | 避免敏感行业/国家安全因素 |
| **COMI认定争议** | 债务人可能在多地注册+经营 | 重点证明实际管理地+主要营业地 |
| **平行程序冲突** | 同一债务人在多国的破产程序可能冲突 | 通过跨境破产协议协调 |
| **资产所在国的执行障碍** | 部分国家不承认外国破产程序 | 提前在当地申请承认+采取保全 |
| **信息不对称** | 管理人难以掌握债务人全部海外资产 | 通过跨境协作+法院调查令 |
