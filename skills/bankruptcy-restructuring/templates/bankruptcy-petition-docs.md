# 📋 破产申请文书模板

## 一、债务人申请破产文件清单

### 1.1 必备材料（《企业破产法》第8条+司法解释一第6条）

| # | 文件名称 | 说明 | 已备 |
|:-|:---------|:-----|:-----|
| 1 | **破产申请书** | 载明申请人+被申请人+申请目的+事实理由+法律依据 | □ |
| 2 | **主体资格证明** | 营业执照+法定代表人身份证明+最新工商登记信息 | □ |
| 3 | **股东会/董事会决议** | 同意申请破产的有效决议（章程规定的表决比例） | □ |
| 4 | **审计报告** | 最近一期经审计的财务报告（或有保留意见需说明） | □ |
| 5 | **资产清册** | 按资产类别（货币/应收/存货/固定/无形/长期投资等）逐项列明 | □ |
| 6 | **债务清册** | 按是否有担保分类列明债权人+金额+到期日+联系方式 | □ |
| 7 | **债权清册** | 债务人对外享有的债权（应收款+预付款+其他应收款等） | □ |
| 8 | **职工安置预案** | 职工基本情况+安置方案+劳动债权测算+维稳预案 | □ |
| 9 | **财务会计报告** | 最近三年及最近一期的财务报表+纳税申报表 | □ |
| 10 | **担保情况说明** | 对外担保/资产抵押/质押的清单+合同+登记证明 | □ |

### 1.2 补充材料（视情况需要）

- [ ] 关联企业情况说明（子公司/参股公司/关联交易/资金往来）
- [ ] 涉诉/仲裁/执行案件清单（案号+标的+进展+保全情况）
- [ ] 行政处罚/税务稽查/环保处罚等重大行政事项
- [ ] 重大合同清单（金额大/期限长/或有重大影响）
- [ ] 知识产权清单（专利/商标/著作权/特许经营权）
- [ ] 行政许可清单（行业资质/许可证/资质证书）
- [ ] 账户开立情况（全部银行账户+余额+性质+是否冻结）

## 三、预重整申请相关

### 3.1 预重整申请条件
- 债务人具备破产原因（《企业破产法》第2条）
- 债务人具有重整价值和可能性
- 债务人与主要债权人已有初步沟通或达成初步意向

### 3.2 预重整期间的主要工作
- 债务人自行管理（法院批准）或临时管理人管理
- 与主要债权人协商重组方案
- 引入战略投资人（如需）
- 完成审计评估
- 形成预重整方案

### 3.3 预重整与正式重整的衔接
- 预重整期间达成的重组方案 → 转换为正式重整计划草案
- 预重整期间暂停诉讼/执行（需法院批准）
- 预重整期间形成的表决结果 → 在正式重整程序中沿用规则（各地司法实践不一致）
