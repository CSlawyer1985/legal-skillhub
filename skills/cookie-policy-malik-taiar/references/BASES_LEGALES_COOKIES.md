# Cookies 与追踪器的法律基础

> 参考：ePrivacy 指令（2002/58/CE）+ GDPR（RGPD）（第 6 条）+ CNIL 2020 指南
> **文档**：[RGPD_texte_officiel.pdf](assets/RGPD_texte_officiel.pdf)、[CNIL_transparence.pdf](assets/CNIL_transparence.pdf)

## 概述

Cookie 和追踪器的放置受两部互补法规管辖：
- **ePrivacy 指令**：规范访问用户设备的同意
- **GDPR**：一旦通过 Cookie 收集个人数据即适用

原则：**必须事先同意**，除非有有限的例外。

---

## 一般原则：同意（《信息技术与自由法》第 82 条）

### 定义

在放置非必要 Cookie 之前，网站发布者必须：
1. **告知**用户 Cookie 的用途
2. **事先获得其同意**
3. **允许拒绝与接受一样容易**

### 同意的有效性条件（CNIL 2020）

| 标准 | 要求 |
|---------|----------|
| **自由** | 无严格 Cookie 墙，提供替代方案 |
| **具体** | 按用途（分析、广告、社交网络等） |
| **知情** | 关于 Cookie 及其用途的清晰信息 |
| **明确** | 积极行为（点击“接受”），不接受沉默或预勾选 |
| **事先** | 在 Cookie 放置**之前** |

### 什么不是有效同意

```
❌ 继续浏览 = 接受
❌ 预勾选复选框
❌ 无“拒绝”按钮的横幅
❌ “拒绝”按钮隐藏或不显眼
❌ “继续即表示您接受...”而无需要采取的行动
❌ 无替代方案的 Cookie 墙
```

---

## 例外：免于同意的 Cookie

### 豁免标准（第 82 条第 2 款）

如果 Cookie **严格必要**，则免于同意：
- 为用户要求的服务提供所需
- 或为通信传输所需

### 豁免的 Cookie

| 类型 | 示例 | 理由 |
|------|----------|---------------|
| **会话** | `session_id`、`PHPSESSID` | 保持连接 |
| **认证** | `auth_token`、`jwt` | 识别用户 |
| **购物车** | `cart`、`basket` | 记忆购买 |
| **安全** | `csrf_token`、`__Host-` | 防攻击保护 |
| **用户偏好** | `lang`、`theme` | 用户要求的个性化 |
| **Cookie 选择** | `cookie_consent` | 记忆同意 |
| **负载均衡** | `SERVERID` | 负载分配 |

### 非豁免的 Cookie（需要同意）

| 类型 | 示例 | 为何不豁免 |
|------|----------|----------------------|
| **分析** | `_ga`、`_gid`、`_gat` | 受众测量 ≠ 用户要求的服务 |
| **广告** | `_fbp`、`IDE`、`fr` | 广告画像 |
| **社交网络** | 分享按钮、嵌入 | 跨站跟踪 |
| **广告个性化** | 重定向、再营销 | 商业目的 |

---

## 特殊情况：豁免的分析 Cookie

### 严格条件（CNIL）

如果满足以下条件，分析 Cookie 可以免于同意：

```
✅ 用途严格限于受众测量
✅ 数据已匿名化（无用户标识符）
✅ 不与其他处理进行交叉比对
✅ 不向第三方转移
✅ 寿命有限
✅ 告知用户 + 反对权
```

### Google Analytics：不豁免

Google Analytics 不满足这些条件，因为：
- 数据转移给 Google（第三方）
- 可能与其他 Google 服务交叉比对
- 持久性用户标识符

### Matomo：可以豁免

Matomo（前 Piwik）可以配置为豁免模式：
- 内部托管（无转移）
- IP 匿名化
- 无持久 Cookie
- 无交叉比对

## 按 Cookie 类型的汇总表

| Cookie 类型 | 同意 | 法律依据 | 备注 |
|----------------|--------------|-------------|-------|
| 会话 | **不需要** | 合同履行 | 严格必要 |
| 认证 | **不需要** | 合同履行 | 严格必要 |
| 购物车 | **不需要** | 合同履行 | 严格必要 |
| 安全 | **不需要** | 法定义务 / 合法利益 | 网站保护 |
| 偏好 | **不需要** | 合同履行 | 用户要求 |
| Cookie 选择 | **不需要** | 法定义务 | 同意的证明 |
| 分析（标准） | **需要** | 同意 | 例：Google Analytics |
| 分析（豁免） | **不需要** | 合法利益 | 例：配置后的 Matomo |
| 广告 | **始终需要** | 同意 | 无例外 |
| 社交网络 | **需要** | 同意 | 按钮、嵌入 |
| 功能性 | **需要** | 同意 | 聊天、视频等 |

## 同意的有效期

> **阅读来源**：`assets/CNIL_recommandation_cookies_et_traceurs.pdf` + https://www.cnil.fr/fr/cookies-et-autres-traceurs/regles/cookies

### CNIL 建议：6 个月（最佳）- 最长 13 个月

| 要素 | CNIL 建议期限 | 最长期限 |
|---------|------------------------|-----------|
| **同意 Cookie** | **6 个月** | 13 个月 |
| 同意的有效性 | **6 个月**（然后重新征求） | 13 个月 |
| 放置的 Cookie | 视用途而定 | 最长 13 个月 |

> **重要**：CNIL 建议同意 Cookie 保存**6 个月**。默认使用 6 个月。

### 义务

- 有效期届满后**重新征求同意**（建议 6 个月，最长 13 个月）
- 在同意有效期内**保存同意的证明**
- **允许随时撤回**

---

## 同意的证明

### 需要保存的内容

| 要素 | 强制性 |
|---------|-------------|
| 用户标识符 | 是（可匿名化） |
| 同意的日期和时间 | 是 |
| 横幅版本 | 是 |
| 所作选择（按类别） | 是 |
| Cookie 政策版本 | 建议 |

### 保存期限

证明必须在**同意有效期内**保存（最长 13 个月）。

## 最佳实践

### 1. 合规横幅

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│  我们使用 Cookie                                                       │
│                                                                         │
│  我们使用 Cookie 以改善您的体验、分析我们的流量并用于广告目的。         │
│                                                                         │
│  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐      │
│  │  全部接受        │  │  全部拒绝        │  │  个性化设置      │      │
│  └──────────────────┘  └──────────────────┘  └──────────────────┘      │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 2. 拒绝与接受一样容易

- “全部拒绝”按钮与“全部接受”按钮**处于同一层级**
- 相同大小、相同可见度
- 无需点击“个性化设置”即可拒绝

### 3. 无黑暗模式

```
❌ “接受”按钮颜色鲜艳，“拒绝”置灰
❌ “拒绝”以横幅下方小字显示
❌ 预选非必要 Cookie
❌ 用“继续而不接受”替代“全部拒绝”
❌ 内疚感信息（“您将错过某些功能...”）
```

### 4. 完整信息

- 含用途的 Cookie 详尽清单
- 放置 Cookie 的第三方身份
- 每个 Cookie 的期限
- 指向第三方政策的链接

## 常见错误

| 错误 | 后果 | 解决方案 |
|--------|-------------|----------|
| 同意前放置 Cookie | 罚款 | 等待明确点击 |
| 未经同意的分析 | 罚款 | 同意或使用豁免 Matomo |
| 期限 > 13 个月 | 不合规 | 遵守最长 13 个月 |
| 无同意证明 | 不合规 | 记录选择日志 |
| 严格 Cookie 墙 | 罚款 | 付费替代方案或缩减内容 |
| “拒绝”按钮隐藏 | 罚款 | 与“接受”同等可见 |
