# Cookies 与追踪器

> 参考：CNIL 指南（2020）+ ePrivacy 指令
> **文档**：[CNIL_transparence.pdf](assets/CNIL_transparence.pdf)

## 概述

Cookie 和追踪器受 ePrivacy 指令衍生规则的约束，并由 CNIL 的建议补充。除例外情况外，大多数 Cookie 都需要同意。

---

## 监管框架

### 原则：事先同意

在放置非必要 Cookie 之前，网站发布者必须：
1. 告知用户 Cookie 的用途
2. 获得其同意
3. 允许拒绝与接受一样容易

---

## Cookie 类别

### 1. 严格必要的 Cookie（豁免）

**定义**：网站运行所不可或缺的 Cookie，没有它们用户无法使用服务。

**示例**：
```
- 会话 Cookie（保持登录状态）
- 购物车 Cookie
- 认证 Cookie
- 安全 Cookie（CSRF）
- 语言偏好 Cookie
- 记住 Cookie 选择的 Cookie（！）
```

**无需同意**：这些 Cookie 可在用户一到达网站时即放置。

---

### 2. 受众测量 / 分析 Cookie

**定义**：用于测量网站访问量和使用情况的 Cookie。

**示例**：
```
- Google Analytics
- Matomo（前 Piwik）
- AT Internet
- Adobe Analytics
```

**同意**：**需要**，除非：
- 用途严格限于受众测量
- 数据已匿名化
- 不与其他处理进行交叉比对
- 不向第三方转移

> **CNIL 提示**：以豁免模式配置的 Matomo 可以在无需同意的情况下运行。

---

### 3. 功能性 Cookie

**定义**：改善用户体验但非严格必要的 Cookie。

**示例**：
```
- 记忆显示偏好
- 界面个性化
- 在线聊天
- 嵌入式视频播放器
```

**同意**：**需要**

---

### 4. 广告 / 营销 Cookie

**定义**：用于展示定向广告或衡量活动效果的 Cookie。

**示例**：
```
- Google Ads / DoubleClick
- Facebook Pixel
- LinkedIn Insight Tag
- Criteo
- 重定向（Retargeting）
```

**同意**：**始终需要** - 无例外可能

---

### 5. 社交网络 Cookie

**定义**：由分享按钮或社交网络集成放置的 Cookie。

**示例**：
```
- Facebook“点赞”按钮
- Twitter/LinkedIn 分享按钮
- 嵌入的 YouTube 视频
- Instagram 嵌入
```

**同意**：**需要**

> **提示**：使用两步点击分享按钮（先激活再分享），以避免自动放置。

---

## 同意横幅

### CNIL 要求（2020）

1. **拒绝与接受一样容易**
   - “全部拒绝”按钮与“全部接受”按钮处于同一层级可见
   - 无欺骗性设计（dark patterns）

2. **事先告知**
   - Cookie 的用途
   - 负责人身份（或指向清单的链接）
   - 拒绝的后果

3. **分级同意**
   - 可按类别接受
   - 无默认全选

4. **无 Cookie 墙**（原则上）
   - 网站访问不得以接受 Cookie 为条件
   - 例外：如提供公平的替代方案

5. **同意的证明**
   - 在有效期内保留证明
   - 能够证明：谁、何时、什么

### 合规横幅示例

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│  🍪 我们使用 Cookie                                                    │
│                                                                         │
│  我们使用 Cookie 以改善您的体验、分析我们的流量并用于广告目的。         │
│                                                                         │
│  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐      │
│  │  全部接受        │  │  全部拒绝        │  │  个性化设置      │      │
│  └──────────────────┘  └──────────────────┘  └──────────────────┘      │
│                                                                         │

│                                                                         │
```

## Cookie 的保存期限

> **阅读来源**：`assets/CNIL_recommandation_cookies_et_traceurs.pdf` + https://www.cnil.fr/fr/cookies-et-autres-traceurs/regles/cookies

### CNIL 建议：6 个月（最佳）- 最长 13 个月

| 类型 | CNIL 建议期限 | 最长期限 |
|------|------------------------|-----------|
| **同意 Cookie** | **6 个月** | 13 个月 |
| 分析 Cookie | 视用途而定 | 最长 13 个月 |
| 广告 Cookie | 视用途而定 | 最长 13 个月 |
| 会话 Cookie | 会话时长 | - |

> **重要**：CNIL 建议同意 Cookie 保存**6 个月**。默认使用 6 个月，除非有正当理由。

超过所选择的期限后，同意必须重新取得。

## 常见错误

| 错误 | 可能的制裁 | 解决方案 |
|--------|-------------------|----------|
| 同意前放置 Cookie | 罚款 | 等待点击“接受” |
| 无可见的“拒绝”按钮 | 罚款 | 按钮与“接受”处于同一层级 |
| 严格 Cookie 墙 | 罚款 | 提供替代方案 |
| 期限 > 13 个月 | 责令整改 | 遵守最长期限 |
| 无 Cookie 清单 | 不合规 | 详细表格 |
| 黑暗模式 | 罚款 | 中性清晰的界面设计 |
