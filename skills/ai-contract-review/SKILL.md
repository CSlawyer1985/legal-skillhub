# 合同审查（民法典）

## 一句话概述
基于《中华人民共和国民法典》（合同编）及最新司法解释，对合同进行逐条智能审查——五维风险评估、12 类缺失条款检测、风险标注、修订建议，输出结构化审查报告。

## 如何开始 / 触发方式（先看这段）

本技能在 WorkBuddy 对话框里**直接用自然语言触发**，不需要记命令：

- **审一份合同**：把合同文件（docx/pdf/txt）拖进对话框，说「帮我审一下这份采购合同」「审合同」「合同风险检查」即可。
- **审一条条款**：直接说「审查这条条款：违约金为合同总额的50%」。
- **批量审一个文件夹**：「批量审查 D:/合同/ 这个目录下的所有合同」。
- **查法条**：「民法典第585条讲什么的」。

**触发词**（命中任意一个即唤醒）：合同审查、审合同、民法典审查、合同风险检查、合同合规、合同条款审查、法律风险、合同漏洞、合同缺失条款、合同审阅、contract review、合同检查、帮我审合同。

> 提示：首次用时若没反应，确认技能已启用（左侧【技能】面板里「AI合同审查」开关打开）。本技能只做文本分析，不会替你改合同原文。

## 快速验证（30秒跑通）

```bash
# 1. 查询民法典法条

# 2. 审查一条违约金条款
python main.py review-clause --clause "违约金为合同总额的50%"

# 3. 查看风险类型和缺失类别
python main.py list-risk-types

# 4. 生成一份模拟审查报告
python main.py generate-report --input contract.txt --output D:\skill-test\review-report.md
```

## 使用场景
- 签署合同前快速审查，规避法律风险
- 采购合同、服务合同、劳动合同、租赁合同等各类合同
- 企业法务日常合同审阅
- 个人租房合同、合作协议审阅
- 合同模板合规性检查
- 政府采购合同、招投标项目合同专项审查（v1.3.0 新增 gov-review）

## 法律依据
- 《中华人民共和国民法典》2021年1月1日施行
- 合同编（第三编，第463-988条）：通则、典型合同、准合同
- 总则编（第一编）：民事主体、民事法律行为、代理
- 相关司法解释（截至2026年最新）

## 命令清单

### parse-contract
解析合同文件（docx/pdf/txt），提取条款结构。
```bash
python main.py parse-contract --input contract.docx
```

### review-clause
逐条审查合同条款，对照民法典给出意见。
```bash
python main.py review-clause --clause "违约金为合同总额的50%"
```

### risk-assess
五维风险评估（合法性/公平性/完整性/明确性/可执行性）。
```bash
python main.py risk-assess --input contract.docx
```

### missing-check
检测12类常见缺失条款。
```bash
python main.py missing-check --input contract.docx
```

### generate-report
生成结构化审查报告（Markdown格式）。
```bash
python main.py generate-report --input contract.docx --output review-report.md
```

### batch-review
批量审查多个合同文件。
```bash
python main.py batch-review --dir ./contracts/
```

### law-lookup
查询民法典相关法条。
```bash
python main.py law-lookup --article 584
```

### gov-review（政府采购/招投标专项，v1.3.0 新增）
针对政府采购合同做专项审查：转包/分包禁止、质保金惯例、履约保证金上限、进口产品审批等。
```bash
python main.py gov-review --input 政府采购合同.txt
```
> 说明：该命令仅对命中政府专项关键词（转包/分包/质保金/履约保证金/进口）的条款触发检测，不主动要求政府条款；普通民法典审查仍走 review-clause / batch-review。

### list-risk-types
列出所有风险类型及说明。
```bash
python main.py list-risk-types
```

### list-missing-categories
列出12类常见缺失条款及重要性。
```bash
python main.py list-missing-categories
```

## 五维风险评估

| 维度 | 评估内容 | 风险权重 |
|------|----------|----------|
| 合法性 | 条款是否符合民法典强制性规定 | 40% |
| 公平性 | 双方权利义务是否对等 | 20% |
| 完整性 | 必要条款是否齐全 | 20% |
| 明确性 | 条款表述是否清晰无歧义 | 10% |
| 可执行性 | 条款是否具备实际可操作 | 10% |

## 风险等级

| 等级 | 标识 | 说明 |
|------|------|------|
| [HIGH] 高风险 | 红色 | 违反强制性规定、权利义务严重失衡、核心条款缺失 |
| [MED] 中风险 | 黄色 | 表述模糊、非核心条款缺失、存在可争议空间 |
| [LOW] 低风险 | 绿色 | 格式瑕疵、非实质性建议 |

3. **发现 3 个风险项**：
   - [HIGH] 第5条：违约金约定为"合同总额的50%"，可能被认定为过高（民法典第585条，建议不超过实际损失的30%）

## 常见问题（FAQ）

**Q：这个技能能替代律师吗？**
A：不能。本技能提供法律参考意见，不构成正式法律意见书。重大合同、涉诉合同、金额巨大或关系重大的，建议由执业律师最终审核。

**Q：怎么在对话框里触发它？**
A：不用记命令。把合同文件拖进对话框，说「帮我审一下这份合同」或「审合同」即可；也能直接说「审查这条条款：违约金为合同总额的50%」或「批量审查 D:/合同/ 这个目录」。详见上文「如何开始 / 触发方式」。

**Q：支持哪些合同类型？**
A：通用合同审查框架，适用于采购、服务、劳动、租赁、合作/合伙、保密（NDA）、借款等各类合同。核心是民法典合同编通则的通用审查规则。

**Q：支持政府采购 / 招投标合同吗？**
A：支持（v1.3.0 起）。通用民法典审查对所有合同生效；另提供 `gov-review` 命令做政府专项检测——转包/分包禁止（政府采购法第48条）、质保金惯例（国办发〔2016〕49号）、履约保证金≤10%（实施条例第48条）、进口产品审批（进口产品管理办法）。仅命中政府关键词的条款触发，不主动要求政府条款。

**Q：批量审查现在是真的逐份审吗？**
A：是的（v1.2.0 起）。`batch-review` 会对目录里每个 txt/docx/pdf 真正执行解析→五维评估→缺失检测→生成单份报告，并在末尾输出汇总表（得分/评级/缺失数/风险项）。解析失败（缺依赖或扫描件）的文件会跳过并标注。

**Q：参数报错看不懂怎么办？**
A：命令统一用 `[参数错误]` 前缀并附用法示例。常见原因：①`--clause` 的条款没用引号包裹，空格被当成多参数 → 用引号包住整句；②`--input`/`--dir` 路径含空格没引号、或文件/目录不存在 → 用引号包裹绝对路径并核对；③扩展名不是 txt/docx/pdf。

**Q：docx/pdf 解析需要额外安装什么？**
A：docx 需要 `pip install python-docx`，pdf 需要 `pip install PyPDF2`。txt 格式无需额外依赖。未安装时工具会提示你装，不会静默失败。

**Q：PDF 解析不准 / 是扫描件怎么办？**
A：文本型 PDF 用 PyPDF2 提取文字层；若 PDF 是扫描图片（文本层为空），工具会提示"需 OCR"，此时建议先转成 txt 或 docx 再审。排版复杂的 PDF 提取可能有错位，关键条款建议人工核对。

**Q：审查结果准吗？复杂条款怎么处理？**
A：审查基于关键词匹配与模式识别（违约金比例、模糊词、格式条款标志等），对典型风险（过高违约金、模糊表述、缺失必备条款）识别较稳。但本技能只内置 24 条民法典核心法条＋政府采购专项法条、不覆盖全部情形，**遇到复杂/非典型/行业专项条款（如金融、医疗深度法规），结论仅供参考，建议人工复核或咨询律师**。

**Q：能审查英文合同或境外法律管辖的合同吗？**
A：不能。本技能仅依据《中华人民共和国民法典》审查**中国大陆法律管辖**的合同。含境外管辖、适用外国法、或涉国际公约的合同不在适用范围内（见下方「适用范围」）。

**Q：审查报告能导出吗？**
A：能。`generate-report --input 合同.docx --output 报告.md` 会生成 Markdown 格式报告；批量审查会在目标目录下的 `review_reports/` 生成每份合同的报告。

**Q：它在本机运行吗？收费吗？**
A：本地运行，不上传、不存储你的合同内容（见下方「法务与安全声明」）。工具本身免费，仅 docx/pdf 解析所需的 python-docx/PyPDF2 是开源第三方库。

**Q：法条数据是最新的吗？**
A：内置 24 条民法典核心法条（截至 2026 年），基于公开版本。具体适用需结合最新司法解释、修订与地方规定；如发现与官方最新版本不一致，以官方公布为准。
