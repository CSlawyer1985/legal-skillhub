# 法律法规工具契约

运行前先对 `yuandian-law` 执行能力发现。下表是 1.2.0 的路由基线；调用参数、枚举和必填项以运行时工具模式为准，即 source of truth。

| MCP 工具 | 用途 | 路由原则 |
|---|---|---|
| `yuandian_law_vector_search` | 自然语言语义检索 | 问题口语化、术语不确定或需跨法规发现 |
| `yuandian_rh_ft_detail` | 法条详情 | 已知法规和条款号，优先精确取文 |
| `yuandian_rh_fg_detail` | 法规全文或详情 | 已知法规名称或法规 ID |
| `yuandian_rh_ft_search` | 法条关键词检索 | 已知法律术语、条款主题或法规范围 |
| `yuandian_rh_fg_search` | 法规关键词检索 | 查找法规名称、发布机关或法规级别 |

## 调用纪律

- 精确请求先于语义请求；不得把语义摘要冒充法条原文。
- 默认优先现行有效版本，并同时保留发布机关、发布日期、施行日期和效力状态。
- 工具响应为空不代表法律不存在；应报告检索条件、返回范围和未命中事实。
- 任何引用都必须来自工具返回。无法取得原文时标记为“待原文核验”。
- MCP 使用 Stateless Streamable HTTP `POST`；`GET` 返回 `405` 属于预期协议行为。

## 响应与错误

兼容 JSON 和 SSE 帧中的 JSON-RPC 结果。开放平台 API 的成功码可能是 200 或 201，数据可能位于 `data` 或 `extra`；若元力适配层回退到 API，不得只接受单一成功码或单一数据字段。401/403、429、超时和缺失工具按接入门禁映射为稳定状态，不得退回模型记忆生成法条。
