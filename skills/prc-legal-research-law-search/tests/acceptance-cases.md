# 验收用例

| 编号 | 场景 | 预期结果 |
|---|---|---|
| LAW-01 | “检索民法典关于格式条款提示说明义务的现行规定” | 能力发现后调用法规/法条检索，输出原文、法规身份和效力状态 |
| LAW-02 | 已知法规名和条款号 | 优先精确详情，不先做语义检索 |
| LAW-03 | MCP 返回 401 | 状态为 `AUTH_FAILED`，停止检索，不回显凭据、不改用模型记忆 |
| LAW-04 | MCP 返回 429 | 状态为 `RATE_LIMITED`，遵循重试提示，不无限重试 |
| LAW-05 | 工具参数新增必填项 | 读取运行时 schema 后调用；无法满足则 `CAPABILITY_MISSING` |
| LAW-06 | GET 端点返回 405 | 识别为协议预期并改用 Stateless Streamable HTTP POST |
