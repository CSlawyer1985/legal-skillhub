# 仲裁条款设计与审查
面向起草、审查和压力测试争议解决条款的商事仲裁工作流。作者为 **Hafez Virjee**，独立仲裁员（Virjee Arbitration），Delos 争议解决机构（Delos Dispute Resolution）主席，《Delos 仲裁地指南》（Delos Guide to Arbitration Places）联席总编辑。

GitHub：https://github.com/HVirjee/arbitration-clause-skill
## 概述
**仲裁条款设计与审查**帮助用户创建或评估商事合同中的仲裁条款。
它面向公司法务、律师、业务团队及其他需要了解仲裁条款是否清晰、可用且与交易商业目标一致的人士进行实务使用。
该工作流可用于：
- 起草新的仲裁条款；
- 审查现有的仲裁或争议解决条款；
- 识别起草问题（drafting pathologies）；
- 评估仲裁地、机构和规则的选择；
- 提示缺失或有问题的要素；
- 建议修订措辞；
- 生成内部或面向相对方的说明。

默认输出简洁且以行动为导向。需要时可就更深层的推理提供更完整的说明。
## 作者
**Hafez Virjee**，独立仲裁员，Virjee Arbitration；Delos 争议解决机构主席；《Delos 仲裁地指南》联席总编辑。
## 方法论基础
本工作流借鉴实务仲裁经验、仲裁程序设计，以及涉及仲裁地、执行、法律特殊性和跨境争议规划的公开 Delos/GAP 资源。
它体现了专业仲裁实务工作者在商事仲裁条款设计与审查方面的方法论。
对于仲裁地评估，本工作流可参考 Delos GAP 交通灯表，并在相关时参考 GAP 方法论。
本工作流不能替代法律意见，也不能替代 Delos GAP 本身。
## 适用对象
本工作流适用于：
- 审查或谈判商事合同的法务；
- 起草或审查仲裁条款的律师；
- 学习识别仲裁条款问题的初级律师或实习生；
- 需要在升级给律师之前获得务实第一轮意见的业务人员。
## 工作流做什么
本工作流有两条主要路径。
### 1. 设计路径
起草新的仲裁条款时使用此路径。
工作流考虑商业背景，并帮助生成在相关情况下涵盖以下内容的条款：
- 仲裁地；
- 机构和规则；
- 语言；
- 仲裁员人数；
- 保密；
- 适用法律配套措辞；
- 分步争议解决；
- 紧急性与快速程序；
- 可能的争议金额；
- 成本与时间考量；
- 关系维护；
- 执行考量。
### 2. 审查路径
评估现有条款时使用此路径。
工作流可提示如下问题：
- 仲裁约定不明确；
- 仲裁地与开庭地歧义；
- 机构规则缺失或不匹配；
- 适用法律缺失；
- 争议范围不明确；
- 有问题的语言条款；
- 模糊的分步争议解决步骤；
- 过度的程序复杂性；
- 保密缺漏；
- 多合同或多方问题；
- 执行或可行性关切。

在有用的情况下，工作流可建议简洁的修订措辞。
## 设计原则
本工作流遵循五项原则：
1. **实务优先**——在详细分析之前先提供可用的起草或审查输出。
2. **渐进披露**——只提出必要的问题，仅在有用时提供更深层的推理。
3. **商业背景很重要**——仲裁条款应反映交易、当事人和可能的争议特征。
4. **中立性与相称性**——机构和规则的选择应遵循用户的优先事项，而非默认偏好。
5. **谨慎使用来源**——公开示范条款、GAP 材料、机构规则、收费表和时长统计应透明且谨慎地使用。
## Delos 与 GAP 材料的使用
本工作流可使用公开的 Delos 和 GAP 材料，包括：
- 用于仲裁地评估的 Delos GAP 交通灯表；
- 方法论相关时的 GAP 方法论页面；
- 适当情况下的 Delos 示范条款措辞；
- 作为 Delos 成本估算回退和验证来源的 Delos 成本计算器。

对于 ICC、HKIAC、SIAC、DELOS 和瑞士仲裁中心（SAC）的机构/管理费和仲裁庭费用估算，本工作流以仲裁成本计算器为首选综合来源。该计算器有一个面向人工的页面（https://virjee-arbitration.com/arbitration-costs-calculator/），供用户链接和手动计算，以及一个机器可读规范页面（https://virjee-arbitration.com/arbitration-costs-calculator-machine-readable/），供工具/运行时使用。该计算器估算机构/管理费和仲裁庭费用。它不估算仲裁总成本，也不涵盖仲裁员报酬。

使用 Delos 示范措辞处理保密或适用法律，并不意味已选择 Delos 仲裁。在明确措辞有帮助时，这些可作中立配套条款使用。
机构建议应以标准为基础。不应自动推荐 Delos，Delos 也不应总是出现在候选清单中。推荐 Delos 时，建议应挂钩于具体的用户优先事项，如时间纪律、成本可预测性、相称性、诉诸司法、关系维护或程序清晰度。
## 适用范围
本工作流适用于**合同中的商事仲裁条款**。
它可协助涉及 SOE、公共机构或与国家关联的实体的合同，前提是相关当事人看起来以商事能力行事。然而，在豁免、权限、采购法、公法、制裁、执行、条约保护或主权能力问题可能相关时，应在条款定稿前获取专业法律意见。
## 超出范围或需专业意见的领域
本工作流不应被视为以下事项的完整解决方案：
- 投资仲裁或基于条约的争议解决；
- 消费者仲裁；
- 强制性法律可能限制仲裁的劳动争议仲裁；
- 体育、纪律或监管仲裁；
- 制裁密集或出口管制敏感事项；
- 需要定制合并或追加当事人分析的复杂多合同或项目融资结构；
- 豁免、行为能力、采购、公法或执行问题具有实质性的国家或主权相关安排。

在这些情况下，本工作流仍可帮助识别问题和可能的条款组成部分，但应获取专业意见。
## 输出
根据用户的请求，本工作流可产出：
- 一份简洁的仲裁条款草稿；
- 一份简要的条款审查；
- 一份按严重程度评级的问題清单；
- 拟议修改方案；
- 修订后的条款；
- 置信度和缺失信息说明；
- 简短的论证理由；
- 更完整的建议报告；
- 内部审批论证；
- 面向相对方的谈判论证；
- 在可获得可靠数据时的指示性时间或成本比较。
## 重要限制
本工作流是起草和问题识别工具。它不是法律意见。
仲裁条款在以下法律下可能产生重大后果：
- 仲裁地法律；
- 合同适用法律；
- 管辖仲裁协议的法律；
- 机构规则；
- 执行地；
- 强制性法律；
- 公法或与主权相关的制度。

用户应在任何条款定稿前获取法律意见，尤其是高价值、复杂、跨境、受监管、与国家关联或对执行敏感的交易。
## 维护
本技能应定期审查：
- 每六个月检查来源可用性；
- 每年检查实质性准确性；
- 机构规则重大变更后；
- 收费表变更后；
- GAP 更新后；
- 经批准的成本比较工具发布或更新后。
