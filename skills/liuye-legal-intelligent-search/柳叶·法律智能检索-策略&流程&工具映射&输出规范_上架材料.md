### 长描述（详情页正文）

```
⚖️ 柳叶·法律智能检索-策略&流程&工具映射&输出规范

本技能提供法律事务处理的标准RAG（检索增强生成）完整流程，
确保每一个法律问题都优先使用最新法律信息作答——因为法律时刻在变化。

🔍 核心能力

✅ 并行RAG检索（北大法宝 + IMA，不再区分公私法源）
   · 所有法律问题默认并行检索：公域权威数据 + 个性化知识库
   · 北大法宝：权威法律依据（法规/案例/司法解释）
   · IMA知识库：个性化补充（个人笔记/历史案例/法律订阅）
   · 检索结果互补，互不排斥

✅ 北大法宝 MCP 工具完整映射（10+工具）
   · 综合语义检索、法规检索、案例检索
   · 法条精确获取、案号识别标准化
   · 法条引用校验与调整

✅ IMA知识库集成（通用辅助来源）
   · 所有法律问题均建议并行检索 IMA 知识库
   · 内容来源：用户上传文件 + IMA发现法律订阅
   · 适用场景不限内部制度，作为北大法宝的个性化补充

✅ 检索失败降级处理
   · 北大法宝无结果 → 自动建议更换关键词或转向IMA
   · IMA无结果 → 自动建议上传文档或转向公域检索
   · 两者均无结果 → 明确告知，建议咨询专业律师

✅ Legal技能智能路由
   · 合同审查 → 自动加载 contract-risk-reviewer
   · 诉讼分析 → 自动加载顶级诉讼律师分析技能
   · 法律概念解析 → 自动加载深度解析技能

✅ 标准输出格式（强制规范）
   · 法律依据 → 案情分析 → 风险评估 → 可操作建议 → 免责声明
   · 风险评估含：法律后果 / 胜诉概率 / 执行难度 三维度

📦 适用场景

· 劳动合同纠纷咨询
· 合同条款风险审查
· 公司规章制度合规性检查
· 法律文书起草（诉状/合同/法律意见书）
· 司法案例检索与类案比对
· 日常法律咨询（婚姻/租赁/消费/交通等）

⚠️ 前置要求

本技能需配合北大法宝 MCP 服务使用。
使用者需自行申请北大法宝账户并获取 MCP Token（免费申请）。
北大法宝已开放 MCP 服务，可直接申请使用。
详见技能文件内附的完整配置说明。

📌 免责声明

本技能输出内容基于AI检索和分析，不构成正式法律意见。
复杂或重大案件建议咨询专业律师。
```
