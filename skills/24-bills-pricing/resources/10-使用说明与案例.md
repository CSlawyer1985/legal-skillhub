## 1. 技能简介

### 1.1 适用范围

本Skill基于《建设工程工程量清单计价标准》（GB/T 50500-2024），适用于建设工程施工发承包及实施阶段的计价活动。

### 1.2 核心能力

- **术语查询**：快速查询标准中的35个核心术语定义
- **规则查询**：查询工程量清单编制、计量、价款调整、结算支付等规则
- **流程指导**：按标准流程指导用户完成计价工作
- **合规校验**：对计价文件进行合规性审查

### 1.3 数据来源

- **标准名称**：《建设工程工程量清单计价标准》
- **标准编号**：GB/T 50500-2024
- **发布机构**：住房城乡建设部
- **标准页数**：95页

## 2. 使用方法

### 2.1 快速查询模式

**适用场景**：需要快速了解某个术语或规则的含义

**使用方式**：
```
用户：什么是综合单价？

AI：根据《建设工程工程量清单计价标准》（GB/T 50500-2024）

【术语】综合单价（all-in unit rate）

定义：综合考虑技术标准规范、施工工期、施工顺序、施工条件、地理气候等影响因素以及约定范围与幅度内的风险，完成一个单位数量工程量清单项目所需的费用。

组成：人工费、材料费、施工机具使用费、管理费、利润和一定范围内的风险费用，不包括增值税。

来源：01-术语定义.md 第2.0.9条
对应PDF：第11页
```

### 2.2 流程指导模式

**适用场景**：需要按标准流程完成某项计价工作

**使用方式**：
```
用户：我要编制工程量清单，应该怎么做？

AI：根据《建设工程工程量清单计价标准》，工程量清单编制应按以下流程进行：

**步骤1：明确编制依据**
- 操作：收集招标文件、设计图纸、技术标准规范等资料
- 引用标准：03-清单编制规则.md 第4.2.1条
- 关键校验：确保使用最新版国家及行业工程量计算标准

**步骤2：确定清单项目**
- 操作：按分部分项工程项目清单、措施项目清单、其他项目清单、增值税分别列项
- 引用标准：02-基本规定.md 第3.1.2条
- 关键校验：清单项目列项明确、边界清晰

**步骤3：描述项目特征**
- 操作：载明构成工程量清单项目自身的本质及要求
- 引用标准：01-术语定义.md 第2.0.5条
- 关键校验：项目特征应说明设计图纸、技术标准规范及招标文件所要求完成的清单项目的文字性描述

**步骤4：确定计量单位**
- 操作：按国家及行业工程量计算标准确定计量单位
- 引用标准：02-基本规定.md 第3.1.4条

**步骤5：计算工程数量**
- 操作：按国家及行业工程量计算标准计算工程数量
- 引用标准：04-工程计量规则.md 第7.2条
- 关键校验：工程量计算精度应保留小数点后两位

**步骤6：确定综合单价**
- 操作：按人工费、材料费、施工机具使用费、管理费、利润和风险费组成综合单价
- 引用标准：02-基本规定.md 第3.1.6条
- 关键校验：综合单价应为不含增值税的税前全费用价格

**步骤7：汇总清单价格**
- 操作：按工程数量乘以综合单价计算各清单项目价格，汇总形成工程量清单总价
- 引用标准：02-基本规定.md 第3.2条

**输出成果**：
- 工程量清单封面
- 工程量清单编制说明
- 工程量计算规则说明
- 分部分项工程项目清单
- 措施项目清单
- 其他项目清单
- 增值税
```

### 2.3 校验审查模式

**适用场景**：需要对已有计价文件进行合规性审查

**使用方式**：
```
用户：请帮我审查这份工程量清单的合规性
[用户上传工程量清单内容]

AI：根据《建设工程工程量清单计价标准》，对该工程量清单进行合规性审查：

**一、清单完整性审查**
- [ ] 分部分项工程项目清单 已包含
- [ ] 措施项目清单 已包含
- [ ] 其他项目清单 缺少暂列金额
- [ ] 增值税 已包含

**二、计价方式审查**
- 采用单价计价 符合标准
- 措施项目采用总价计价 符合标准

**三、综合单价组成审查**
- 人工费 已包含
- 材料费 已包含
- 施工机具使用费 已包含
- 管理费 已包含
- 利润 已包含
- 风险费 未明确约定范围

**四、风险分担审查**
- 未采用"无限风险"表述 合规

**五、问题汇总**
1. 【问题】其他项目清单缺少暂列金额
   【建议】根据工程实际情况补充暂列金额
   【依据】02-基本规定.md 第3.1.2条

2. 【问题】综合单价中风险费未明确约定范围
   【建议】在招标文件中明确风险范围与幅度
   【依据】02-基本规定.md 第3.1.6条、第3.3条
```

## 3. 典型案例

### 案例一：术语查询（快速模式）

**场景**：用户询问"暂估价"的含义

**查询过程**：
```
用户：什么是暂估价？包括哪些类型？

AI：根据《建设工程工程量清单计价标准》（GB/T 50500-2024）

【术语】暂估价

暂估价包括两种类型：

1. **材料暂估价**（material prime cost rate）
   - 定义：发包人在工程量清单中提供的，用于支付设计图纸要求必需使用的材料，但在招标时暂不能确定其标准、规格、价格而在工程量清单中预估到达施工现场的不含增值税的材料价格。
   - 来源：01-术语定义.md 第2.0.14条
   - 对应PDF：第12页

2. **专业工程暂估价**（specialist works prime cost sum）
   - 定义：发包人在工程量清单中提供的，在招标时暂不能确定工程具体要求及价格而预估的含增值税的专业工程费用。
   - 来源：01-术语定义.md 第2.0.15条
   - 对应PDF：第12页

**注意事项**：
- 材料暂估价不含增值税
- 专业工程暂估价含增值税
- 暂估价应在合同约定的事项发生后按实际价格调整
```

### 案例二：工程变更价款调整（流程指导模式）

**场景**：工程实施过程中发生设计变更，需要调整合同价款

**项目信息**：
| 参数 | 数值 |
|------|------|
| 合同类型 | 单价合同 |
| 变更项目 | 主体结构混凝土工程量增加 |
| 原工程量 | 1000m3 |
| 变更后工程量 | 1200m3 |
| 综合单价 | 500元/m3 |

**处理流程**：
```
用户：工程发生变更，混凝土工程量从1000m3增加到1200m3，如何调整价款？

AI：根据《建设工程工程量清单计价标准》，工程变更价款调整应按以下流程处理：

**步骤1：确认变更程序合规性**
- 检查：工程变更是否经发包人批准
- 引用标准：05-价款调整规则.md 第8.9.1条
- 关键校验：未经批准的变更不予调整价款

**步骤2：计算变更工程量**
- 变更工程量 = 1200m3 - 1000m3 = 200m3
- 引用标准：04-工程计量规则.md 第7.4条

**步骤3：确定变更价款**
- 变更价款 = 变更工程量 x 综合单价
- 变更价款 = 200m3 x 500元/m3 = 100,000元
- 引用标准：05-价款调整规则.md 第8.9.2条

**步骤4：调整合同价款**
- 原合同价款：1000m3 x 500元/m3 = 500,000元
- 调整后合同价款：500,000元 + 100,000元 = 600,000元

**步骤5：确认支付**
- 变更价款应在进度款中支付
- 引用标准：06-结算支付规则.md 第9.4条

**汇总结果**：
| 项目 | 金额（元） |
|------|-----------|
| 原合同价款 | 500,000 |
| 变更增加价款 | 100,000 |
| 调整后合同价款 | 600,000 |

**数据来源**：
- 变更计量规则：04-工程计量规则.md 第7.4条
- 变更价款调整规则：05-价款调整规则.md 第8.9条
- 进度款支付规则：06-结算支付规则.md 第9.4条
```

### 案例三：物价变化价款调整（校验规则触发）

**场景**：施工期间主要材料价格上涨，触发物价变化价款调整

**项目信息**：
| 参数 | 数值 |
|------|------|
| 合同类型 | 单价合同 |
| 可调材料 | 钢筋 |
| 基准价 | 4000元/吨 |
| 现行价 | 4500元/吨 |
| 风险幅度 | +/-5% |
| 工程量 | 100吨 |

**处理流程**：
```
用户：钢筋价格从4000元/吨涨到4500元/吨，合同约定风险幅度+/-5%，如何调整？

AI：根据《建设工程工程量清单计价标准》，物价变化价款调整如下：

**步骤1：判断是否需要调整**
- 价格上涨幅度 = (4500 - 4000) / 4000 = 12.5%
- 风险幅度 = 5%
- 超出幅度 = 12.5% - 5% = 7.5%
- 结论：超出风险幅度，应予调整
- 引用标准：02-基本规定.md 第3.3.5条

**步骤2：计算调差基数**
- 调差基数 = 现行价 - 基准价 x (1 + 风险幅度)
- 调差基数 = 4500 - 4000 x 1.05 = 4500 - 4200 = 300元/吨
- 引用标准：02-基本规定.md 第3.3.5条

**步骤3：计算调差金额**
- 调差金额 = 调差基数 x 工程量
- 调差金额 = 300元/吨 x 100吨 = 30,000元

**步骤4：调整合同价款**
- 调差金额应计入综合单价，调整合同价款
- 引用标准：05-价款调整规则.md 第8.7条

**步骤5：计取增值税**
- 综合单价的人工费、材料费、施工机具使用费的燃料动力费价差调整应计取增值税
- 引用标准：02-基本规定.md 第3.3.5条第4款

**汇总结果**：
| 项目 | 数值 |
|------|------|
| 价格上涨幅度 | 12.5% |
| 风险幅度 | 5% |
| 超出幅度 | 7.5% |
| 调差基数 | 300元/吨 |
| 调差金额 | 30,000元 |
| 增值税（假设税率9%） | 2,700元 |
| 合计调整金额 | 32,700元 |

**校验规则触发**：
- 规则3（风险分担合规性校验）：已确认未采用"无限风险"表述
- 规则4（综合单价组成完整性校验）：调差金额计入材料费

**数据来源**：
- 物价变化调整规则：02-基本规定.md 第3.3.5条
- 价款调整规则：05-价款调整规则.md 第8.7条
```

## 4. 常见问题（FAQ）

**Q1：单价合同和总价合同有什么区别？**

A：根据 `01-术语定义.md` 第2.0.6条和第2.0.7条：
- **单价合同**：以工程量清单、项目特征及其综合单价进行合同价款计算、调整和确认。在约定的范围内合同单价不做调整。
- **总价合同**：以合同图纸、合同规范进行合同价款计算、调整和确认。在约定的范围内合同总价不做调整。

**Q2：综合单价包括哪些费用？**

A：根据 `02-基本规定.md` 第3.1.6条，综合单价包括：
1. 人工费
2. 材料费
3. 施工机具使用费
4. 管理费
5. 利润
6. 一定范围内的风险费用

**不包括增值税**。

**Q3：哪些风险由发包人承担？**

A：根据 `02-基本规定.md` 第3.3.2条，以下风险由发包人承担：
1. 工程量清单缺陷（单价合同中）
2. 发包人提供的原始数据和基准资料错误
3. 发包人批准的工程变更
4. 赶工、提前竣工、停工或暂缓施工
5. 法律法规与政策性变化
6. 超出约定幅度的市场物价变动

**Q4：进度款支付比例一般是多少？**

A：根据 `06-结算支付规则.md` 第9.4.3条，进度款支付比例一般为已完工程量的80%~90%。

**Q5：工程保修金预留比例是多少？**

A：根据 `06-结算支付规则.md` 第10.5.2条，工程保修金预留比例一般为合同价款的3%~5%。

**Q6：发生工程变更后，承包人应在多长时间内提出价款调整报告？**

A：根据 `05-价款调整规则.md` 第8.9.1条，承包人应在工程变更确认后，按合同约定的期限向发包人提交合同价款调整报告。合同未约定的，应在工程变更确认后14天内提交。

## 6. 使用建议

### 6.1 最佳实践

1. **先查术语再查规则**：遇到不熟悉的术语，先使用快速查询模式了解定义
2. **按流程操作**：进行计价工作时，使用流程指导模式按标准步骤操作
3. **及时校验**：完成计价文件后，使用校验审查模式检查合规性
4. **保留溯源**：引用标准时保留数据来源标注，便于核查

### 6.2 注意事项

1. 本Skill基于GB/T 50500-2024版本，使用时请确认标准版本
2. 具体工程应结合相关工程国家及行业工程量计算标准使用
3. 标准附录中的表格格式为推荐格式，可根据实际需要调整
4. 涉及具体金额计算时，应以合同约定和实际情况为准
