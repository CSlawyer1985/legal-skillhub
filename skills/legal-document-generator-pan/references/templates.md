# Chinese Legal Document Templates

## 民事起诉状模板

```
民事起诉状

原告：[姓名]，[性别]，[出生日期]，[民族]，[工作单位]，[住址]，[联系电话]
法定代表人/法定代表人：[姓名]，[职务]
被告：[名称/姓名]，[地址]，[联系电话]
法定代表人：[姓名]，[职务]

诉讼请求：
1. [具体请求1]
2. [具体请求2]
3. 诉讼费用由被告承担

事实与理由：

[详细叙述案件事实，包括时间、地点、人物、经过、结果等]

[说明法律关系和争议焦点]

[引用相关法律条款作为依据]

此致
[法院名称]人民法院

具状人：[签名]
[日期]

附：1. 本起诉状副本X份
    2. 证据清单X份
```

## 取保候审申请书模板

```
取保候审申请书

申请人：[姓名]，[性别]，[出生日期]，[身份证号]，[住址]，[联系电话]
系犯罪嫌疑人/被告人[姓名]的[关系]

被申请人：[姓名]，[性别]，[出生日期]，[身份证号]，[住址]

申请事项：
请求对犯罪嫌疑人/被告人[姓名]变更强制措施为取保候审。

事实与理由：

[说明被申请人涉嫌的罪名和案件情况]

[阐述取保候审的理由：
 1. 涉嫌罪名较轻，可能判处轻刑
 2. 无社会危险性
 3. 有固定住所和工作
 4. 有保证人或可以提供保证金
 5. 患有严重疾病等特殊情况]

[引用《刑事诉讼法》第六十七条关于取保候审的规定]

综上，申请人认为对[姓名]采取取保候审不致发生社会危险性，符合法律规定，恳请贵院予以准许。

此致
[公安机关/人民检察院/人民法院]

申请人：[签名]
[日期]
```

## 保密协议模板

```
保密协议

甲方（披露方）：[公司名称]
地址：[地址]

乙方（接收方）：[姓名/公司名称]
住址/地址：[地址]

鉴于甲乙双方正在进行/拟进行[项目名称]项目合作，甲方向乙方披露或乙方接触到了甲方的保密信息，为保护甲方权益，双方达成如下协议：

第一条 保密信息定义
保密信息包括但不限于：[列举保密信息类型]

第二条 保密义务
1. 乙方承诺对保密信息严格保密
2. 不得向第三方披露保密信息
3. 仅可将保密信息用于合作目的
4. 采取合理的保密措施

第三条 保密期限
自本协议签署之日起[X]年。

第四条 例外情形
以下情形不构成违反保密义务：
1. 已公开的信息
2. 法律法规要求披露
3. 事先获得甲方书面同意

第五条 违约责任
乙方违反保密义务的，应承担以下责任：
[具体约定违约责任]

第六条 争议解决
争议提交甲方所在地法院诉讼解决。

甲方（盖章）：           乙方（签字/盖章）：
法定代表人：            日期：
日期：
```
