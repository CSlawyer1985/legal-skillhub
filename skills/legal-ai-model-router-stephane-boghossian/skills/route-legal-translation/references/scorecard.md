## 5. 法律翻译

**五个垂直领域中公开基准覆盖最弱的——请将本节视为方向性指引，而非如 §1–§3 那样有基准支持。** 前沿 LLM **没有干净的法律翻译排行榜**。指引由以下三角验证得出：(a) 不涉及法律文本的一般机器翻译（MT）基准，(b) 用作代理的多语言推理基准，以及 (c) 专门的法律 MT 研究。**认证/宣誓翻译始终需要合格的人工译者——LLM 在此仅是初稿引擎，绝非法定签署人。**

**一般翻译质量**
- **WMT25**（该领域的严谨性标准）：人工评估 → **Gemini** 系列胜出（在 16 个语言对中的 14 个居首）；GPT 和 Cohere Command-A 接近；DeepSeek/Claude 属第二梯队。排名**依赖指标**——另一种方法论将 GPT-5、Grok 4、Claude Opus、Gemini 排成不同顺序。没有既定的“领头羊”。
- **按语言拆分（方向性）：** Claude 在德语/日语/韩语/荷兰语/意大利语领先，并被**专业译者认为在语气/语域方面更优**；Gemini 在中文/巴西葡萄牙语/乌克兰语领先，并为长文档提供更大的上下文窗口。

**多语言推理（无法律 MT 数据时的代理）**
- 大致而言：**Gemini 3.1 Pro** 在原始多语言知识方面居首（约 94 MMLU），**GPT-5.x** 接近且 MMLU-ProX 最强，**Claude Opus** 为稳健的第三名，多语言数学（MGSM）表现尤佳。
- 这是*在*某种语言中的推理，而非翻译*质量*——是代理，不是替代。

**法律翻译特定证据（薄弱但真实）**
- **SwiLTra-Bench**（arXiv 2503.01372）——找到的最严谨的专门法律 MT 基准（瑞士法规/判例，德/法/意/罗曼什语）。发现：**通用 LLM 在术语对等、法规语域和保留先例的判例翻译方面仍落后于专门的法律 MT 系统。**
- **欧盟 EUR-Lex** 明确告知用户**不要**依赖其自身用于立法的 MT 工具——只有经人工核验的官方语言文本才是权威文本。机构对法律 MT 的不信任是明确、直接的表述。
- 术语表可以解决*术语一致性*，但解决不了**否定准确性**、**法域概念映射**（普通法的“discovery 证据开示”/“plea bargain 认罪协商”在大陆法中没有对应物）、**交叉引用完整性**或**法律效力**。这些正是使法律 MT 危险失效的模式。

**阿拉伯语 / 中东北非**
- **不存在阿拉伯语法律*翻译*基准**——这是一个真实的空白。存在阿拉伯语法律*推理*基准（**ArabLegalEval**、**ALARB**）；耐人寻味的是，ArabLegalEval 是将英文 LegalBench 机器翻译成阿拉伯语*然后*经专家核验构建的——这隐含承认原始 MT 需要人工检查。
- 一般阿拉伯语推理：**Gemini 3.1 Pro / 3 Pro** 领先（约 93），**Claude Opus** 接近（约 91–92）。Claude 的阿拉伯语散文据报告（软性/定性）更自然。
- **Mistral 是有据可查的阿拉伯语薄弱点。** **Qwen**（Qwen-MT 系列）和 **Cohere Aya** 是专门构建的多语言模型，是最强的*可自托管*阿拉伯语选项。
- **RTL 是 UI 问题，不是模型问题**——输出文本没问题；显示对齐是前端问题（仅在你基于 API 自建阿拉伯语 UI 时相关）。

**路由指标：** 无公开数据。基于上述代理进行路由；**人工法律语言学审查是强制性的，而非可选项**——这是有据可查的行业共识，不是推诿之词。

## 跨领域注意事项（纳入每一项路由决策）

1. **能力 ≠ 可控性**（Wei Chen，Atticus 项目）。高分基准不意味着模型能保持在范围内、真实引用或可安全无监督部署。治理是与原始性能分开的另一个维度。
2. **全有或全无的现实**（Harvey）。能发现 10 个风险中 8 个的审查不是 80% 有用——它实质上是不完整的。高风险工作应路由给可靠性，而非平均质量。
3. **评分并不完美。** legalbenchmarks.ai 的可靠性由*单一* LLM 裁判（Claude Sonnet 4.6）评分；实用性由双裁判小组（约 82% 一致性）评分。其自身的偏见检查：Sonnet 在两个榜单上均非榜首，Anthropic 模型在长度上排名最低——这是反对自我评分偏袒的证据，但 LLM 裁判的分数仍不是地面真值。
4. **覆盖范围狭窄。** legalbenchmarks.ai 仅限英文、偏向美/英、单轮、每任务一次运行（无漂移/一致性测试），任务集不公开。Vals LegalBench 是选择题推理，而非起草。**非美国、非英语、多轮和长期工作被低估。**
5. **基准漂移与路由坍缩。** 这里的数字每月都会过时；而且一个总是选择同一主导模型的路由器已停止路由。新前沿模型发布时重新验证。
6. **静默质量回退。** 成本节约立即体现在账单上；质量损失在数日后才体现在工作产品中。任何成本驱动的降级都要以抽查为门槛。
