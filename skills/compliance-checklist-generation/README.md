# 合规控制清单与差距评估

- 唯一标识：`industry-compliance-checklist-generation`
- 显示名称：合规控制清单与差距评估
- 能力摘要：将 SOC 2、HIPAA、PCI-DSS 或 GDPR 等框架要求映射为可跟踪的控制项，记录现状、证据、缺口和整改优先级；适合作为合规准备工具，不代替审计师或法律意见。

## 案例素材

1. 二十人 B2B SaaS 团队计划六个月后接受 SOC 2 审计，按访问控制、变更管理、事件响应、风险评估和供应商管理逐项盘点，列出需要的 IAM 配置截图、审批记录及政策文档。
2. 面向欧盟消费者的电商站点评估 GDPR，就数据访问、更正、删除、可携带、Cookie 同意和跨境传输建立差距清单，标出 30 天响应义务及每项修复的工作量。
3. 同时被客户要求 SOC 2 与 HIPAA 时，将日志、最小权限、培训和事件响应等共用控制合并规划，避免两个项目重复取证，并为不适用项留下审计可接受的理由。
