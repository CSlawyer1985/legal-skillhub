# 劳动争议风险评估方法论

> 本文档详细说明蚂蚁工资条劳动争议风险评估引擎的量化模型设计。
> 供LLM在撰写风险报告时理解评分逻辑，也可供用户审计评估结果的科学性。

---

## 一、评估架构总览

```
输入参数
├── 争议场景代码（36+场景之一）
├── 月平均工资
├── 工作月数/工龄
├── 城市（可选，影响仲裁倾向）
├── 行业（可选，影响争议密度）
├── 公司类型（可选，影响判赔率）
└── 岗位（可选，影响争议复杂度）
        │
        ▼
        双层计算引擎
        │
        ├── 第一层：基础风险分（场景自带，来自判例大数据）
        │     ├── 法律合规风险 (Legal Risk)
        │     ├── 经济损失风险 (Economic Risk)
        │     └── 声誉影响风险 (Reputation Risk)
        │
        └── 第二层：四维调节因子加权
              ├── 城市系数 (×0.85 ~ ×1.20)
              ├── 行业系数 (×0.85 ~ ×1.10)
              ├── 公司类型系数 (×0.92 ~ ×1.15)
              └── 岗位系数 (×0.90 ~ ×1.15)
                    │
                    ▼
                综合风险评分 + 等级 + 行动建议
```

---

## 二、三维风险评分模型

### 2.1 法律合规风险（权重50%）

衡量企业在该争议场景下的法律败诉概率及相关合规瑕疵。

| 分值区间 | 含义 | 典型场景 |
|---------|------|---------|
| 85-100 | 极高法律风险——企业几无合法抗辩空间 | 三期女职工解雇、未缴社保、未签合同 |
| 70-84 | 高法律风险——企业抗辩空间有限 | 违法解除、欠薪、未足额社保 |
| 50-69 | 中法律风险——取决于证据与管理规范性 | 试用期解除、绩效奖金、竞业限制违约 |
| <50 | 低法律风险——法律依据较充分 | 合法裁员、合规解除 |

**赋分依据**：
- 该场景在全国仲裁/法院中的劳动者胜诉率（来源：中国裁判文书网年度司法大数据）
- 最高法院指导案例的裁判倾向
- 各地仲裁委年度报告中的同类争议裁决比例

### 2.2 经济损失风险（权重30%）

衡量企业败诉后面临的经济赔偿金额。

| 分值区间 | 含义 | 计算示例 |
|---------|------|---------|
| 85-100 | 赔偿可能超过12个月工资 | 大规模裁员群体争议、工伤一级伤残 |
| 70-84 | 赔偿在6-12个月工资区间 | 违法解除(2N)、重大社保补缴+滞纳金 |
| 50-69 | 赔偿在2-6个月工资区间 | 二倍工资差额、经济补偿N、加班费 |
| <50 | 赔偿低于2个月工资 | 未休年假折算、最低工资差额 |

**计算要素**：
1. 法定赔偿金额公式（如2N、N+1、二倍工资上限11个月）
2. 可能叠加的多项赔偿（如违法解除2N + 三期工资损失）
3. 企业规模对赔偿上限的影响（3倍社平封顶、12年封顶）
4. 滞纳金、加付赔偿金、诉讼费用、律师费用

### 2.3 声誉影响风险（权重20%）

衡量该争议对企业品牌、招聘吸引力和员工士气的外部影响。

| 分值区间 | 含义 | 触发条件 |
|---------|------|---------|
| 85-100 | 极可能引发舆论危机 | 涉及群体性事件、性别歧视、三期保护、工伤死亡 |
| 70-84 | 较大声誉风险 | 违法解除、欠薪、社保问题、大面积裁员 |
| 50-69 | 中等声誉影响 | 加班费争议、年终奖争议 |
| <50 | 声誉影响有限 | 小额计算争议、个体性争议 |

**考虑维度**：
- 是否具有"公共事件"属性（如大规模裁员 vs 单人试用期解除）
- 是否涉及敏感话题（性别歧视、工伤、三期女工）
- 媒体报道可能性
- 招聘市场影响（脉脉/看准/小红书传播速度）

## 三、四维调节因子详解

### 3.1 城市因子（权重25%）

| 系数 | 城市特征 | 代表城市 |
|:---:|------|------|
| 1.15-1.20 | 仲裁活跃、裁判偏向保护劳动者 | 深圳(1.20)、北京/上海(1.15) |
| 1.05-1.10 | 经济活跃、争议密度高 | 杭州(1.10)、广州(1.08)、苏州(1.05) |
| 0.95-1.03 | 争议水平中等 | 南京/成都/武汉/厦门/珠海 |
| 0.88-0.93 | 争议密度相对较低 | 郑州/东莞/石家庄/沈阳 |
| 0.85-0.88 | 仲裁案例较少 | 拉萨/乌鲁木齐 |

**调节原理**：城市仲裁活跃度和判例密度越高，意味着：
1. 劳动者维权意识和途径更成熟
2. 仲裁委/法院裁判标准更明确
3. 企业应诉成本和曝光风险更高

### 3.2 行业因子（权重25%）

| 系数 | 行业特征 | 代表行业 |
|:---:|------|------|
| 1.08-1.10 | 高密度高薪高流动性 | 互联网(1.10)、金融(1.08) |
| 1.02-1.05 | 特定争议高发行业 | 建筑(1.02)、房地产(1.05)、游戏(1.05) |
| 0.98-1.00 | 中等水平 | 制造业、医疗、汽车、银行 |
| 0.90-0.95 | 较低争议密度 | 零售、物流、物业、旅游 |
| 0.85 | 争议较少 | 农业 |

### 3.3 公司类型因子（权重25%）

| 系数 | 类型特征 |
|:---:|------|
| 1.12-1.15 | 民营企业、个体工商户——用工管理规范性较低 |
| 1.08-1.10 | 小微企业、创业公司、上市公司——不同维度的风险 |
| 1.00-1.05 | 外资企业、合资企业——管理规范但裁员风险高 |
| 0.92 | 国有企业——用工合规性最高 |

### 3.4 岗位因子（权重25%）

| 系数 | 岗位特征 |
|:---:|------|
| 1.10-1.15 | 高管、法务——争议复杂性高、赔偿金额大 |
| 1.05-1.08 | HR、中层管理——自身权益争议+参与用工管理 |
| 1.00-1.02 | 技术研发、产品——高薪职位 |
| 0.93-0.97 | 行政、运营、销售、客服 |
| 0.90 | 实习生——用工关系认定存有争议 |

## 四、综合评分公式

```
综合分 = (法律分 × 0.5 + 经济分 × 0.3 + 声誉分 × 0.2)
         × (城市×行业×公司×岗位)^0.25

等级映射：
  综合分 ≥ 80  → 极高风险
  综合分 ≥ 65  → 高风险
  综合分 ≥ 45  → 中风险
  综合分 < 45  → 低风险
```

**为什么用几何平均？**
- 四维因子相互独立，几何平均避免某一维极度放大/缩小结果
- 算术平均可能导致极端城市（如深圳1.20）过度抬高风险

## 五、赔偿预计算模型

### 5.1 计算原则

1. **法定优先**：严格按法律公式计算，不凭经验"估"
2. **范围估算**：对不精确场景（如加班时长未知），给出合理估算范围
3. **和解建议**：基于该场景历史和解比例（来源：仲裁委调解数据分析）

### 5.2 和解金额建议

```
和解金额 = 法定赔偿 × 和解比例区间中值
```

和解比例来自大量实际仲裁调解案例的分析：

| 场景和解比例 | 理由 |
|-------------|------|
| 欠薪：75%-100% | 劳动者几乎必胜，企业无谈判空间 |
| 未签合同：60%-90% | 事实清楚但金额可谈判 |
| 违法解除：60%-90% | 2N有威慑力，企业倾向和解 |
| 加班费：50%-80% | 举证有难度，双方各退一步 |
| 年终奖：30%-60% | 法律依据相对弱 |
| 试用期解除：30%-50% | 双方举证难度均高 |

## 六、置信度评分规则

| 置信度 | 条件 |
|:---:|------|
| **高** | 有同类判例参考 + 法律依据明确 + 事实争议不大 |
| **中** | 无直接同类判例，但法律依据可参考 |
| **低** | 场景涉及事实争议较大且法律依据不明确 |

## 七、与 LLM 协作流程

本方法论与LLM的配合模式：

1. **用户描述争议 → LLM 匹配场景代码**：LLM 理解用户自然语言描述（如"试用期最后一天被辞退"），通过 `--search` 或场景关键词匹配，输出场景代码。

2. **场景代码 → Python 引擎计算**：精确的数学计算交给引擎，LLM 不做数字运算。

3. **引擎 JSON 输出 → LLM 撰写报告**：引擎输出结构化 JSON（含风险分、赔偿额、行动建议框架），LLM 基于此撰写可读性报告，补充：
   - 行业实际案例分析
   - 管理建议的具体化
   - 判决趋势预判

4. **LLM → WebSearch 判例检索**（可选增强步骤）：对于置信度为"中"的场景，LLM 可实时搜索中国裁判文书网或权威法律数据库，获取最新同类判例补充到报告中。

## 八、模型局限性

1. **非法律意见**：本评估不构成法律意见，仅为风险量化参考工具。
2. **数据时效性**：基础风险分基于近3年裁判文书大数据，每季度手动校准。
3. **个案差异**：现实争议受具体事实、证据、仲裁员/法官自由裁量权影响，评分不能替代个案分析。
4. **地方政策变化**：各地人社局/公积金中心的政策调整可能影响模型准确性，建议结合 `劳动力-law-reference.md` 中的时效性提示。
