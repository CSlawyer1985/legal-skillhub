# 劳动法律法规速查手册

> 本文档为蚂蚁工资条劳动争议风险评估引擎的法律依据快速参考。
> 覆盖《劳动合同法》《劳动争议调解仲裁法》及配套司法解释的要点索引。

## 一、核心法律框架

### 1.1 基本法律

| 法律 | 发布/修订 | 核心调整 |
|------|---------|---------|
| 《劳动法》 | 1994年/2018年修正 | 工时、工资、休假、社保基本原则 |
| 《劳动合同法》 | 2008年/2012年修正 | 劳动合同订立/履行/解除/终止全流程规则 |
| 《劳动争议调解仲裁法》 | 2008年 | 仲裁程序、时效、一裁终局 |
| 《社会保险法》 | 2011年/2018年修正 | 五大险种权利义务 |
| 《就业促进法》 | 2008年/2015年修正 | 公平就业、反歧视 |
| 《民法典》 | 2021年 | 第1010条性骚扰条款、人格权保护（对外部影响补充适用） |

### 1.2 行政法规与部门规章

| 文件 | 发布 | 核心内容 |
|------|------|---------|
| 《劳动合同法实施条例》 | 2008年 | 劳动合同法细化操作 |
| 《女职工劳动保护特别规定》 | 2012年 | 三期保护、产假、哺乳假 |
| 《工伤保险条例》 | 2004年/2010年修订 | 工伤认定、等级、待遇标准 |
| 《职工带薪年休假条例》 | 2008年 | 年假天数、折算规则 |
| 《工资支付暂行规定》 | 1994年 | 工资支付形式、扣款规则、加班费基数 |
| 《最低工资规定》 | 2004年 | 最低工资标准制定与执行 |
| 《劳务派遣暂行规定》 | 2014年 | 派遣比例(≤10%)、岗位三性、同工同酬 |
| 《住房公积金管理条例》 | 1999年/2019年修订 | 缴存比例(5%-12%)、基数、强制缴纳 |

## 二、关键条款速查

### 2.1 劳动合同订立

| 条款 | 内容摘要 |
|------|---------|
| 第10条 | 用工之日1个月内签书面合同 |
| 第14条 | 无固定期限合同适用条件（连续工作10年/连续2次固定期后） |
| 第19条 | 试用期上限：3月-1年→≤1月；1-3年→≤2月；3年↑→≤6月 |
| 第20条 | 试用期工资≥约定工资80%且≥当地最低工资 |
| 第82条 | 未签合同超1个月→二倍工资（上限11个月） |

### 2.2 劳动合同解除

| 条款 | 关键信息 |
|------|---------|
| 第36条 | 协商一致解除（N或高于N） |
| 第37条 | 劳动者单方解除（提前30日通知，无补偿） |
| 第38条 | 劳动者被迫解除（N）——未付工资/未缴社保/制度违法等 |
| 第39条 | 企业过失性解除（无补偿）——试用期不符/严重违纪/失职/兼职/欺诈/刑责 |
| 第40条 | 企业无过失性解除（N+1）——医疗期满/不胜任/客观情况重大变化 |
| 第41条 | 经济性裁员（N）——≥20人或≥10% |
| 第42条 | 禁止解除情形——三期/医疗期/工伤丧失劳动能力/连续工作15年距退休不足5年 |
| 第46条 | 应支付经济补偿N的七种情形 |
| 第47条 | N计算公式：工作年限×月工资（上限12年+3倍社平封顶） |
| 第48条 | 违法解除→2N或恢复劳动关系 |
| 第87条 | 违法解除→2N |

### 2.3 工资与工时

| 条款 | 关键信息 |
|------|---------|
| 劳动法第44条 | 加班费标准：150%/200%/300% |
| 劳动法第36条 | 标准工时：日≤8h 周≤40h |
| 劳动法第41条 | 加班上限：日≤3h 月≤36h（特殊原因除外） |
| 劳动合同法第85条 | 欠薪→加付50%-100%赔偿金 |

### 2.4 竞业限制

| 条款 | 关键信息 |
|------|---------|
| 第23条 | 竞业限制对象：高管/高级技术人员/其他涉密人员 |
| 第24条 | 限制期限：≤2年；范围：合理限制+补偿 |
| 司法解释四第6条 | 补偿标准≥离职前12个月平均工资30% |
| 司法解释四第8条 | 3个月未付补偿→劳动者可解除竞业限制 |
| 司法解释四第10条 | 劳动者违约→支付违约金+继续履行 |

### 2.5 仲裁程序

| 条款 | 关键信息 |
|------|---------|
| 第27条 | 仲裁时效：1年（知道或应当知道权利被侵害之日起） |
| 第43条 | 仲裁审理期限：45日+可延长15日 |
| 第47条 | 一裁终局金额门槛（各地自行规定） |
| 第48条 | 劳动者对终局裁决可起诉；企业仅可申请撤销 |

## 三、各地司法口径差异速查

### 3.1 二倍工资仲裁时效

| 地区 | 裁判规则 |
|------|---------|
| 北京/上海/江苏 | 整体时效：最后一月满1年（有利于劳动者） |
| 广东/浙江 | 分段时效：每月独立起算（仅能主张近12个月） |
| 最高法 | 目前无统一指导意见 |

### 3.2 未休年假工资性质

| 地区 | 裁判规则 |
|------|---------|
| 北京/上海 | 劳动报酬→适用特殊时效（离职后1年） |
| 广东/江苏 | 福利待遇→适用一般时效（1年，从应休未休起算） |

### 3.3 竞业限制补偿下限

| 地区 | 地方标准 |
|------|---------|
| 北京 | 按约定，无约定按月平均工资30%且不低于最低工资 |
| 上海 | 同最高法标准（30%） |
| 深圳 | 同最高法标准，部分案例支持50% |
| 江苏 | ≥离职前12个月月平均工资的1/3 |
| 浙江 | ≥离职前12个月月平均工资的30% |

### 3.4 不定时工作制节假日加班

| 地区 | 裁判规则 |
|------|---------|
| 北京 | 法定节假日加班需支付300%（审批后不定时制不免除） |
| 上海 | 审批后不定时制法定节假日可不支付加班费 |
| 广东 | 倾向上海观点 |

### 3.5 加班费基数

| 地区 | 裁判规则 |
|------|---------|
| 上海 | 按劳动合同约定的正常工作月工资 |
| 北京 | 按实际工资（含绩效/津贴），以当月全额工资为基数 |
| 广东 | 按合同约定工资，无约定按实际工资 |

## 四、2024年最新政策动向

1. **最高法劳动争议司法解释（二）**：2023年12月发布，2024年1月1日施行。核心变化：
   - 明确年终奖离职比例折算
   - 规范股权激励的劳动争议处理
   - 细化平台用工劳动关系认定标准

2. **各城市社保基数调整**：2024年7月起多城调整，企业应及时关注。

3. **电子劳动合同**：人社部2021年明确法律效力等同于纸质合同，2024年多地仲裁委开始接受。

4. **个税专项扣除**：2024年继续执行婴幼儿照护、子女教育等专项附加扣除。
