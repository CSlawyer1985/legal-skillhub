# 演示用例简报：退款和费用豁免代理

## 文档状态

用于测试 Agent Authority Charter Builder Skill 的匿名演示文档。

本文档纯属虚构。它不描述任何真实公司、客户、员工、系统或交易。

## 组织背景

组织：Northstar Financial Services Ltd.
行业：消费金融服务
运营区域：美国和英国
业务单元：客户运营
部署阶段：拟议的受监督试点
受监管环境：是
主要利益相关方：客户运营、合规、法务、风险、AI 工程、内部审计

## 拟议代理

代理名称：退款审查代理
代理类型：半自主工作流代理
主要目的：审查客户退款和费用豁免请求，并根据内部政策准备或执行有界行动。

## 工作流描述

客户通过客户支持渠道提交退款或费用豁免请求。退款审查代理将审查客户请求、检索相关账户和交易信息、将事实与内部退款政策比对，并建议是否应批准退款或费用豁免。

业务团队提议，在所有要求的政策条件均满足时，代理可以自动批准不超过 50 美元的低额退款。

## 系统访问

代理可以访问：

- 客户支持工单系统；
- 交易历史系统；
- 账户状态系统；
- 既往退款历史；
- 内部退款和费用豁免政策；
- CRM 备注字段。

代理不得访问：

- 信贷决策系统；
- 催收系统；
- 法律案件管理系统；
- 员工 HR 系统；
- 生产审计日志修改工具；
- 客户通讯发送工具。

## 拟议能力

代理可以：

- 读取客户支持工单；
- 读取交易历史；
- 读取账户状态；
- 读取既往退款历史；
- 检索适用的退款政策；
- 总结客户请求；
- 分类请求类型；
- 建议批准、升级或信息不足；
- 起草内部理由；
- 以内部备注更新 CRM；
- 在所有政策条件均满足时自动批准不超过 50 美元的退款。

## 拟议限制

代理不得：

- 自主拒绝退款；
- 向客户发送对外通讯；
- 批准超过 50 美元的退款；
- 推翻先前的人工决定；
- 修改审计日志；
- 删除记录；
- 访问未经授权的系统；
- 在中止或撤销后继续运行；
- 对涉及法律、监管、歧视、困难或弱势客户措辞的投诉作出决定；
- 批准任何涉及疑似欺诈或未决争议的案件。

## 拟议升级条件

代理必须在以下情形升级：

- 所请求退款超过 50 美元；
- 客户有未决争议；
- 账户有欺诈标记；
- 客户看似弱势或处于困难境况；
- 支持工单提及监管机构、律师、投诉、歧视、不公平待遇、困难、残障、疾病、死亡、失业或类似敏感措辞；
- 政策依据不明确；
- 各系统间账户状态不一致；
- 既往退款历史提示潜在滥用；
- 交易数据不完整；
- 代理无法保存所需证据；
- 案件属新型或超出已定义的政策示例范围。

## 所有权

业务负责人：客户运营主管
技术负责人：AI 工程负责人
合规负责人：客户合规经理
法务负责人：待确认
风险负责人：运营风险负责人
内部审计负责人：待确认

## 当前批准状态

业务负责人已批准探索受监督试点。

试点前需要进行合规审查。

任何生产部署前需要进行法务审查。

代理可以自动批准退款之前需要进行风险审查。

代理获得系统访问权限之前需要进行安全审查。
