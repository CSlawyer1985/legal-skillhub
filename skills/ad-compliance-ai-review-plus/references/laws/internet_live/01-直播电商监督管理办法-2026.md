# 直播电商监督管理办法（2026年2月1日起施行）

来源：国家市场监管总局官网 https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2026/art_ce66ea61fcec4583b5dbd677f470088b.html

**（2025年12月18日国家市场监督管理总局、国家互联网信息办公室令第117号公布 自2026年2月1日起施行）**

## 一、核心监管框架

本办法适用于在中国境内从事直播电商活动（通过互联网以视频/音频直播形式销售商品或提供服务）。监管主体为市场监督管理部门和网信部门，坚持"鼓励创新、严守底线、线上线下一体化监管"原则。

### 主体分类

| 主体 | 定义 |
|------|------|
| 直播电商平台经营者 | 提供网络经营场所、交易撮合、信息发布等服务的法人或非法人组织 |
| 直播间运营者 | 注册账号开设直播间从事直播电商的自然人/法人/非法人组织 |
| 直播营销人员 | 直接面向公众开展商品/服务宣传推介的自然人（即主播） |
| 直播营销人员服务机构 | 为主播提供策划、运营、经纪、培训等服务的机构（即 MCN 机构） |

## 二、直播电商平台经营者核心义务

### 2.1 准入与核验（第8-9条）

- 核验直播间运营者真实身份信息，建立登记档案，**至少每六个月核验更新一次**
- 主播首次直播前须核验身份信息（姓名、身份证号、居住地址、联系方式、专业资质等）
- 建立直播营销人员**真实身份动态核验制度**，不得为与真实身份不符的人员提供服务
- 每年1月和7月向省级市场监管部门报送直播间运营者和主播身份信息

### 2.2 培训义务（第10条）

- 每年对主播开展法律培训（网络交易、信息安全、产品质量安全、消费者权益保护等）
- 首次从事直播电商的主播，直播前必须完成培训

### 2.3 分级分类管理（第11条）

- 根据合规情况、关注量、交易规模等建立分级分类管理制度
- 对**关注用户多、交易规模大、主播影响力强、多次违法或从事关系生命健康商品**的直播间，须采取技术监测、实时巡查等措施

### 2.4 违法行为处置制度（第12条）★ 核心处罚机制

平台须建立并明确以下处置措施的具体情形、程序及救济途径：

| 处置措施 | 适用情形 |
|---------|---------|
| 警示 | 轻微违规 |
| 限制功能 | 一般违规 |
| 限制流量 | 一般违规 |
| 暂停直播 | 较重违规 |
| 限期停播 | 较重违规 |
| **关闭账号** | 严重违规 |
| **禁止重新注册账号** | 严重违规 |
| **列入黑名单** | 严重违反法律、行政法规 |

**处置措施的种类和幅度，应当与违法行为的事实、性质、情节、社会危害程度等相当。**

市监/网信部门通报违法情况后，平台须及时采取处置措施。采取关闭账号、禁止重新注册、列入黑名单的，须同时向**省级**市监/网信部门报告。

### 2.5 黑名单制度（第14条）

- 将严重违法的主体列入黑名单
- 告知事实、理由、依据、期限及申诉途径
- 防止被列入黑名单期间通过更换/重新注册账号逃避惩戒
- 鼓励平台间共享黑名单信息

### 2.6 交易信息保存（第16条）

须保存以下信息，保存时间**自交易完成之日起不少于三年**：
- 直播账号、直播视频回放记录、直播互动信息
- 订单形成时的商品详情页快照、客服记录、支付记录
- 物流快递、退换货及售后信息

### 2.7 AI 技术防范（第17条）

采取有效措施防范利用 AI 编造/传播虚假商业信息、假冒他人进行商业宣传。

### 2.8 消费者权益保护（第18-20条）

- 发生争议时须提供直播间运营者、主播信息及相关交易记录
- 知道或应当知道销售商品不符合安全要求的，须采取必要措施
- 建立投诉机制，对投诉集中的直播间采取技术监测、实时巡查

## 三、直播间运营者核心义务

### 3.1 信息公示（第25-26条）

- 在直播账号主页显著公示主体信息（名称/姓名、统一社会信用代码/身份证号、住所/经营地址、行政许可等）
- 直播页面以显著方式**持续展示**实际销售商品/提供服务的经营者信息
- 链接跳转不得设置多次跳转、强制关注、打赏互动等不合理限制

### 3.2 选品审核（第27条）

核验供货商信息（名称、证照、行政许可、CCC认证、产品合格证明），强化对**选品、营销用语**的审核把关，保存记录不少于三年。

### 3.3 事前合规审核（第30条）

直播前对展示内容、讲解内容、服装、布景、道具等进行合规审核。

### 3.4 纠错机制（第31条）

发现主播出现口误、表述不当等情形时，应当场纠正并保存记录。

### 3.5 价格标示（第32条）

显著展示商品品名、价格、计价单位。采取价格比较、折价、减价等促销方式的，须显著标明被比较价格或计算基准。

### 3.6 违禁商品/服务（第33条）

不得销售：
- 不符合安全要求的商品
- 掺杂掺假、以假充真、以次充好的商品
- 法律禁止交易、损害国家利益、违背公序良俗的商品

### 3.7 虚假宣传禁止（第34条）

不得对经营主体、性能、功能、质量、销售情况、用户评价、荣誉资质等作虚假或引人误解的商业宣传。**不得利用 AI 编造、传播虚假商业信息。**

### 3.8 广告法适用（第35条）

直播内容构成商业广告的，应履行广告发布者/经营者/代言人义务。以下情形一般构成商业广告：
- 非经营者以自己名义对商品作推荐证明的（即**达人/网红带货**）
- 将直播内容录制剪辑后通过互联网再次发布的
- 其他构成商业广告的情形

### 3.9 AI 虚拟人标识（第37条）

使用 AI 生成的人物图像/视频从事直播，须**依照国家规定进行标识**，持续向消费者提示。违规由直播间运营者承担责任。

## 四、直播营销人员服务机构（MCN）义务（第38-45条）

- 核验主播身份信息，与主播签订书面协议
- 加强对主播的培训、日常管理和规范引导
- 建立主播违法行为处置制度
- **不得通过组织虚假交易、虚假评价等方式帮助进行虚假宣传**
- 提供选品服务的，须核验供货商资质信息

## 五、法律责任（处罚条款汇总）★

| 条款 | 违规行为 | 处罚 |
|------|---------|------|
| 第53条 | 平台未核验直播间运营者身份/未报送信息/未保存交易信息 | 依《电子商务法》第80条处罚 |
| 第54条 | 平台未核验主播身份/未培训/未建立分级分类管理/未建立违法行为处置制度/未建立风险识别制度/未建立黑名单制度/未防范AI虚假宣传等（共9项） | 责令改正，拒不改正或情节严重的，**1万-10万元罚款** |
| 第55条 | 平台不提供经营者信息及交易记录 | 依《消保法实施条例》第50条处罚 |
| 第56条 | 平台对侵害消费者权益行为未采取必要措施 | 依《电子商务法》第83条处罚 |
| 第57条 | 直播间运营者未公示信息 | 依《电子商务法》第76条处罚 |
| 第58条 | 直播间运营者未展示经营者信息 | 责令改正，逾期不改正的，**1万元以下罚款** |
| 第59条 | 直播间运营者未核验/违规设置账号信息/未建立合规审核机制/未建立纠错机制/未标识AI虚拟人（共5项） | 责令改正，拒不改正或情节严重的，**1万-10万元罚款** |
| 第60条 | 价格违规 | 依《价格法》处罚 |
| 第61条 | 销售违禁商品/服务 | **1万-10万元罚款** |
| 第62条 | 虚假宣传/虚假交易评价 | 依《反不正当竞争法》第25条/**《广告法》第55条**处罚 |
| 第64条 | MCN 未核验/未管理主播 | **1万-10万元罚款** |
| 第65条 | 传播违法信息/违反网信管理 | 依《网络安全法》《互联网信息服务管理办法》处罚，无规定的**1万-10万元**，可**责令暂停提供相关服务** |
| 第66条 | 拒绝阻碍监管执法 | 个人1000-1万元，单位**1万-10万元** |

**刑事追诉**：违反本办法涉嫌犯罪的，移送司法机关（第67条）。

## 六、信用监管与约谈（第51-52条）

- 行政处罚信息通过国家企业信用信息公示系统公示
- 严重违法失信行为依法采取惩戒措施
- 网信部门将情节严重、影响恶劣的主体列入互联网严重失信名单
- 存在法定义务履行不到位、重大负面舆情、未保障消费者权益等情形的，可对责任人进行约谈
