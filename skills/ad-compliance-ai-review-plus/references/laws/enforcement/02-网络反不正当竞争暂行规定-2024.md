# 网络反不正当竞争暂行规定（2024年9月1日起施行）

来源：市场监管总局 https://www.cqn.com.cn/zj/content/2024-05/11/content_9050340.htm

**国家市场监督管理总局令第91号，2024年5月6日公布，自2024年9月1日起施行**

## 一、广告合规核心条款

### 第8条 — 网络虚假宣传

经营者不得通过以下方式对商品生产经营主体以及商品性能、功能、质量、来源、荣誉、资质等作虚假或引人误解的商业宣传：

1. 网站、客户端、小程序、公众号等展示、演示、说明、推介或文字标注
2. **直播、平台推荐、网络文案**等商业营销活动
3. 热搜、热评、热转、榜单等商业营销活动
4. 其他虚假或引人误解的商业宣传

**不得帮助其他经营者实施上述虚假宣传行为。**

### 第9条 — 刷单炒信与虚假评价 ★

经营者不得实施以下行为：

| 行为类型 | 具体表现 |
|---------|---------|
| 虚假交易 | 虚假交易、虚假排名 |
| 虚构数据 | 虚构交易额、成交量、预约量等经营数据 |
| 虚假营销 | 谎称现货、虚构预订、虚假抢购 |
| 操纵评价 | 编造用户评价、隐匿差评、好评前置差评后置、不显著区分不同商品评价 |
| 好评返现 | 以返现、红包、卡券等方式利诱用户作出指定好评、点赞、定向投票 |
| 虚构流量 | 虚构收藏量、点击量、关注量、点赞量、阅读量、订阅量、转发量 |
| 虚构互动 | 虚构投票量、收听量、观看量、播放量、票房、收视率 |
| 虚构教育效果 | 虚构升学率、考试通过率、就业率 |
| 伪造舆论 | 伪造口碑、炮制话题、制造虚假舆论热点、虚构网络就业者收入 |

**不得通过组织虚假交易、组织虚假排名等方式，帮助其他经营者实施上述行为。**

> **合规要点**："好评返现"被明确列为违法行为。直播间的"家人们给个好评返5元红包"构成违法。

### 第11条 — 商业诋毁

经营者不得利用网络实施以下损害竞争对手商业信誉、商品声誉的行为：
1. 组织、指使他人对竞争对手商品进行恶意评价
2. 利用或组织、指使他人散布虚假或误导性信息
3. 传播含有虚假或误导性信息的风险提示、告客户书、警告函、举报信

### 第16条 — 反向刷单

经营者不得利用技术手段实施：
- 故意短期内大规模高频次交易或好评，使其他经营者被搜索降权、下架
- 恶意批量拍下商品不付款
- 恶意批量购买后退货或拒绝收货

## 二、平台责任（第6条）

平台经营者应当：
- 发现平台内经营者采取不正当竞争方式，**及时采取必要处置措施**
- 保存有关记录，自处置之日起**不少于三年**
- 向平台住所地县级以上市场监管部门报告

## 三、处罚条款

| 违规行为 | 适用法律 | 处罚 |
|---------|---------|------|
| 混淆行为（第7条） | 《反不正当竞争法》第18条 | — |
| 虚假宣传（第8-9条） | 《反不正当竞争法》第20条 | 罚款20万-100万元，情节严重的100万-200万元，可吊销执照 |
| 商业贿赂（第10条） | 《反不正当竞争法》第19条 | 罚款10万-300万元，没收违法所得 |
| 商业诋毁（第11条） | 《反不正当竞争法》第23条 | 罚款10万-50万元，情节严重的50万-300万元 |
| 技术手段不正当竞争（第12-23条） | 《反不正当竞争法》第24条 | 罚款10万-50万元，情节严重的50万-300万元 |
| 平台违规（第24-25条） | 《电子商务法》第82条 | 罚款5万-50万元，情节严重的50万-200万元 |

**违法所得没收**（第41条）：除依法退赔外，应予以没收。

**刑事责任**（第42条）：涉嫌构成犯罪的，移送公安机关。

## 四、广告合规审查速查

| 行为 | 定性 | 依据 |
|------|------|------|
| 好评返现 | 违法（利诱用户作出指定好评） | 第9条第5项 |
| 删除差评/隐藏差评 | 违法（误导性展示） | 第9条第4项 |
| 虚构销量 | 违法（虚构交易数据） | 第9条第2项 |
| 刷单 | 违法（虚假交易） | 第9条第1项 |
| 制造虚假抢购氛围 | 违法（谎称现货、虚构预订） | 第9条第3项 |
| 直播中虚假宣传 | 违法（直播商业营销） | 第8条第2项 |
| 组织恶意差评攻击竞品 | 违法（商业诋毁） | 第11条第1项 |
| MCN 组织刷单 | 违法（帮助其他经营者虚假宣传） | 第8条第2款 + 第9条第2款 |
