# 最高人民法院关于审理网络消费纠纷案件适用法律若干问题的规定（一）

来源：最高人民法院 https://www.court.gov.cn/fabu/xiangqing/348031.html

**法释〔2022〕8号，2022年3月1日公布，自2022年3月15日起施行**

## 一、网络消费格式条款无效情形（第1条）★

以下格式条款法院应认定无效：

1. 收货人签收商品即视为认可商品质量符合约定
2. 平台依法应承担的责任一概由平台内经营者承担
3. 电子商务经营者享有单方解释权或最终解释权
4. 排除或限制消费者投诉、举报、调解、仲裁、诉讼权利
5. 其他排除/限制消费者权利、减轻/免除经营者责任的不公平不合理内容

> **广告合规提示**：广告页面、商品详情页中的"最终解释权归本店所有""签收即视为验收合格"等声明无效。

## 二、直播营销民事责任 ★ 核心

### 第11条 — 平台内经营者直播责任

平台内经营者开设网络直播间销售商品，其**工作人员**在网络直播中因**虚假宣传**等给消费者造成损害，消费者主张平台内经营者承担赔偿责任的，法院应予支持。

### 第12条 — 直播间运营者默认销售者责任

消费者在直播间点击购买商品受损，直播间运营者**不能证明已以足以使消费者辨别的方式标明其并非销售者并标明实际销售者**的，消费者主张直播间运营者承担商品销售者责任的，法院应予支持。

> **合规要点**：直播间运营者（尤其是达人/网红带货）必须在直播中**明确标明**"我不是销售者，实际销售者是XXX"，否则直接承担销售者责任。

### 第13条 — 直播平台自营责任

网络直播营销平台经营者通过网络直播方式开展**自营业务**销售商品，消费者主张其承担商品销售者责任的，法院应予支持。

### 第14条 — 直播平台不能提供主播信息

网络直播间销售商品损害消费者权益，直播平台**不能提供直播间运营者的真实姓名、名称、地址和有效联系方式**的，消费者可向平台请求赔偿。平台承担责任后可向直播间运营者追偿。

### 第15条 — 食品直播平台审核义务 ★

直播平台对依法需取得**食品经营许可**的网络直播间的食品经营资质**未尽到法定审核义务**，使消费者受损，消费者可主张平台与直播间运营者承担**连带责任**。

### 第16条 — 直播平台明知侵权

直播平台知道或应当知道网络直播间销售的商品不符合安全要求，或有其他侵害消费者权益行为，**未采取必要措施**，消费者可主张平台与直播间运营者承担**连带责任**。

### 第17条 — 主播知道侵权仍推广 ★

直播间运营者（主播）**知道或应当知道**经营者提供的商品不符合安全要求或有其他侵害消费者权益行为，**仍为其推广**，给消费者造成损害，消费者可主张主播与经营者承担**连带责任**。

> **合规要点**：主播对推广商品有审查义务，明知商品有问题仍带货推广的，承担连带责任。这意味着主播不能以"我只是推荐，不负责质量"为由免责。

## 三、其他重要条款

| 条款 | 内容 | 实务要点 |
|------|------|---------|
| 第2条 | 法定无理由退货除外商品，经营者承诺七天无理由退货的须遵守 | 承诺高于法定标准 |
| 第3条 | 消费者因检查商品拆封不影响完好，经营者以已拆封拒绝退货的不予支持 | 拆封查验 ≠ 影响完好 |
| 第4条 | 平台标记自营或误导消费者相信是自营的，平台承担销售者责任 | 自营标识责任 |
| 第5条 | 引导消费者通过平台外支付方式付款，经营者不能以未经平台支付为由抗辩 | 私下交易不免责 |
| 第6条 | 店铺转让未变更公示，注册经营者和实际经营者均承担赔偿责任 | 店铺转让的公示义务 |
| 第7条 | 二手平台经营者被认定为商业经营活动的，承担经营者责任 | 二手"商家"不免责 |
| 第8条 | 促销奖品、赠品、换购商品造成损害不免责 | 免费 ≠ 免责 |
| 第9条 | 虚构交易、虚构点击量、编造用户评价的合同无效 ★ | 刷单合同无效 |
| 第10条 | 经营者承诺的赔偿标准高于法定标准的，按承诺赔偿 | 承诺高于法律 |

## 四、广告合规审查速查要点

| 场景 | 法律后果 | 依据 |
|------|---------|------|
| 达人带货未标明实际销售者 | 主播承担销售者责任 | 第12条 |
| 主播明知商品有问题仍推广 | 主播与经营者连带责任 | 第17条 |
| 食品直播平台未尽审核义务 | 平台与直播间连带责任 | 第15条 |
| 直播平台明知侵权不处理 | 平台与直播间连带责任 | 第16条 |
| 直播平台不能提供主播信息 | 平台先行赔偿 | 第14条 |
| 店铺员工直播虚假宣传 | 店铺承担赔偿责任 | 第11条 |
| "签收即视为合格"条款 | 无效 | 第1条 |
| "最终解释权归本店"条款 | 无效 | 第1条 |
| 刷单合同 | 无效 | 第9条 |
| 赠品质量问题 | 不免责 | 第8条 |
