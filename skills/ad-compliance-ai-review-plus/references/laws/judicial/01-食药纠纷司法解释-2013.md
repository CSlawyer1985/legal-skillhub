# 最高人民法院关于审理食品药品纠纷案件适用法律若干问题的规定

来源：最高人民法院 https://www.court.gov.cn/fabu/xiangqing/6042.html

**法释〔2013〕28号，2013年12月23日公布，自2014年3月15日起施行**

（注：2020年修正时已将《侵权责任法》《合同法》更新为《民法典》）

## 一、核心条款（广告合规审查重点关注）

### 第3条 — 知假买假抗辩不予支持 ★

> 因食品、药品质量问题发生纠纷，购买者向生产者、销售者主张权利，生产者、销售者以购买者明知食品、药品存在质量问题而仍然购买为由进行抗辩的，人民法院不予支持。

**实务意义**：在食品、药品领域，**"知假买假"不影响消费者主张权利**。这意味着职业打假人在食药领域的主张得到司法支持。这是广告合规审查中评估职业打假风险的核心条款。

### 第5条 — 举证责任

消费者举证证明购买事实 + 商品不符合合同约定 → 可主张违约责任。

消费者举证证明**受到损害** + **初步证明**损害与食用/使用存在因果关系 → 可主张侵权责任。但生产者/销售者能证明损害不是因产品不符合质量标准造成的除外。

### 第6条 — 食品合格认定标准

认定食品是否合格，按以下优先顺序：
1. 国家标准
2. 地方标准
3. 企业标准
4. 食品安全法相关规定

**生产者采用的标准高于国家/地方标准的，以企业标准为依据。**

### 第7条 — 检验合格证明不免责

食品、药品虽在销售前取得检验合格证明且尚在保质期内，但经检验确认产品不合格，生产者/销售者以检验合格证明为由抗辩的，法院不予支持。

### 第11条 — 虚假广告连带责任 ★

> 消费者因虚假广告推荐的食品、药品存在质量问题遭受损害，依据消费者权益保护法等法律相关规定请求**广告经营者、广告发布者**承担连带责任的，人民法院应予支持。
>
> **社会团体或者其他组织、个人**，在虚假广告中向消费者推荐食品、药品，使消费者遭受损害，消费者依据消费者权益保护法等法律相关规定请求其与食品、药品的生产者、销售者承担**连带责任**的，人民法院应予支持。

**实务意义**：广告经营者、广告发布者、推荐者（包括代言人/网红/KOL）对虚假广告推荐承担**连带责任**。

### 第12-13条 — 检验/认证机构责任

- 食品、药品检验机构**故意**出具虚假检验报告 → **连带责任**
- 食品、药品检验机构**过失**出具不实检验报告 → 相应责任
- 食品认证机构**故意**出具虚假认证 → **连带责任**
- 食品认证机构**过失**出具不实认证 → 相应责任

### 第15条 — 惩罚性赔偿（十倍价款） ★

> 生产不符合安全标准的食品或者销售明知是不符合安全标准的食品，消费者除要求赔偿损失外，向生产者、销售者主张**支付价款十倍赔偿金**或者依照法律规定的其他赔偿标准要求赔偿的，人民法院应予支持。

### 第17条 — 参照适用 ★

> 消费者与**化妆品、保健品**等产品的生产者、销售者、广告经营者、广告发布者、推荐者、检验机构等主体之间的纠纷，**参照适用本规定**。

**实务意义**：本规定的知假买假规则、惩罚性赔偿规则、连带责任规则等均适用于化妆品和保健品领域。

## 二、其他重要条款

| 条款 | 内容 | 实务要点 |
|------|------|---------|
| 第2条 | 消费者可分别或同时起诉生产者和销售者 | 诉讼策略灵活 |
| 第4条 | 赠品质量问题不免责 | 赠品同样受质量监管 |
| 第8条 | 集中交易市场开办者/柜台出租者/展销会举办者未尽义务的连带责任 | 线下场所经营者的连带责任 |
| 第9条 | 网络交易平台不能提供商家真实信息的先行赔偿；知道或应当知道侵权的连带责任 | 平台责任 |
| 第10条 | 挂靠经营的连带责任 | 无资质主体挂靠有资质主体的责任 |
| 第14条 | 民事赔偿优先于行政罚款和刑事罚金 | 消费者权益优先 |
| 第16条 | 不公平格式条款无效 | 排除/限制消费者权利的格式条款无效 |

## 三、广告合规审查速查要点

| 场景 | 法律后果 | 依据 |
|------|---------|------|
| 食品/药品虚假广告致消费者损害 | 广告经营者、发布者、推荐者连带责任 | 第11条 |
| 知假买假（食药领域） | 不影响主张权利 | 第3条 |
| 食品不符合安全标准 | 价款十倍赔偿 | 第15条 |
| 化妆品/保健品虚假广告 | 参照适用本规定全部条款 | 第17条 |
| 检验报告虚假 | 检验/认证机构连带责任 | 第12-13条 |
| 平台不能提供商家信息 | 平台先行赔偿 | 第9条 |
