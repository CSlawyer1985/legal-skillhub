# 文书模板库（10类）

> 基于项目实际文书提炼。使用时：①替换所有[占位符]；②法律条文引用先经法规工具核验；③涉密、个人信息（身份证号、住址、账号）一律脱敏。

## 1. 质疑函

```
质 疑 函

致：[采购人/代理机构名称]

一、质疑供应商
名称：[全称]  地址：  法定代表人：
委托代理人：  联系电话：  电子邮箱：

二、被质疑项目
项目名称：  项目编号：  采购方式：  预算金额：

三、质疑事项
事项一：[具体描述，如"招标文件第五章第X条设定的XX参数具有唯一性、
        指向性强，涉嫌以不合理条件排斥潜在供应商"]
  事实依据：[时间、文件位置、具体内容]
  法律依据：[列明违反的具体条款]
事项二：……

四、诉求
1. [如：修改招标文件第X条技术参数后重新发布]
2. [如：暂停采购活动]

五、附件
1. 法定代表人身份证明  2. 授权委托书  3. 证据目录及证据复印件

质疑供应商（盖章）：
法定代表人/授权代表（签字）：
日期：  年  月  日
```

**写作要点**（项目实战）：质疑事项必须精确到"文件位置+条款文字"，忌笼统表述"评分标准不合理"；每个事项单独给法律依据，方便逐项答复；诉求明确可执行。

## 2. 投诉书

```
投 诉 书

投诉人：[全称]  地址：  法定代表人：  委托代理人：  联系电话：
被投诉人1：[采购人名称及地址]
被投诉人2：[代理机构名称及地址]（如适用）

一、投诉事项
（一）项目基本情况（名称、编号、方式、预算）
（二）投诉人参与情况（何时获取文件、何时投标、报价）
（三）质疑及答复情况（质疑日期、答复日期、答复内容摘要）

二、具体投诉请求
1. [认定采购文件第X条违法]  2. [认定中标结果无效]  3. [责令重新开展采购活动]

三、事实与理由
（一）事实经过（时间线）
（二）法律依据（逐项对应）
（三）因果关系论证（该瑕疵如何影响或可能影响采购结果——财政审查核心）

四、附件
1. 身份证明  2. 质疑函及答复函复印件  3. 证据目录及证据材料

投诉人（盖章）：
日期：  年  月  日
```

**写作要点**：投诉必须已完成质疑程序（附质疑函+答复函）；"影响采购结果"的因果论证是成立与否的关键，务必单独成段。

## 3. 质疑答复函

```
质 疑 答 复 函

[质疑供应商名称]：

贵司就[项目名称]（项目编号：）提出的质疑函（日期：），我单位
于[日期]收悉。依法在7个工作日内答复如下：

一、关于质疑事项一"[原文摘录]"
（一）事实认定：[引用采购文件条款原文、评审报告记载、客观证据]
（二）法律依据：[条款]
（三）答复意见：不接受。理由：[逐层论证]
      或：接受。处理措施：[修改文件/更正公告/重新评审]

二、关于质疑事项二……

三、投诉权利告知
如对本答复不满意或我单位未在规定期限内答复，贵司可在答复期满后
15个工作日内向[同级财政部门名称]提起投诉。

[采购人/代理机构名称]（盖章）
日期：  年  月  日
```

**写作要点**（项目实战教训）：①**必须盖章**（某中学案答复未盖章被投诉抓住）；②禁用"几乎""完全可以"等模糊表述（被指"答复与事实明显不符"）；③逐项对应质疑事项，不得避重就轻；④引用采购文件要抄原文。

## 4. 政府采购投诉处理决定书

```
[财政部门全称]
政府采购投诉处理决定书

[财x采处〔  〕x号]

投诉人：  地址：  法定代表人：  委托代理人：
被投诉人：  地址：

一、项目基本情况
[名称、编号、方式、预算、开标时间、中标人及金额、合同签订及履行状态]

二、投诉事项及请求

三、调查查明的事实
[客观叙述：查阅的档案、询问的人员、查询的平台记录、评标录音录像审查情况]
[不掺入主观评价，每段一个事实]

四、处理决定及理由
（一）关于投诉事项1
  1. 事实认定：  2. 法律依据：
  3. 决定：[驳回/不成立/成立/部分成立]
  4. 处理措施：[继续开展采购活动/责令限期改正/责令重新开展采购活动/
     认定中标无效/撤销合同/记分/移送线索]
（二）关于投诉事项2 ……

五、救济途径告知
如不服本决定，可自收到本决定书之日起60日内向[上一级财政部门/本级
人民政府]申请行政复议，或者6个月内向[有管辖权的人民法院]提起行政诉讼。

[财政部门全称]（盖章）
日期：  年  月  日
```

**写作要点**（项目实战）：①查明事实部分必须写明**调查手段**（查询cx.cnca.cn记录、调取评标录音、组织专家论证）；②逐项决定+理由；③合同状态（未签/已签未履行/已履行）决定适用94号令第31条哪一项处理；④救济途径告知遗漏属程序违法。

```

我局收到[移送机关/举报人名称]的[移送/举报材料名称]，涉及你单位作为

请予以配合，如实提供，不得隐匿、伪造、变造或销毁。

[财政部门全称]（盖章）

```

## 7. 行政处罚先行告知书 / 听证告知书

```
[财政部门全称]
行政处罚先行告知书

编号：

[当事人名称]：
你单位在[项目名称]（编号：）政府采购活动中，存在[具体违法行为]，
违反了《中华人民共和国政府采购法》第[X]条的规定。

根据《中华人民共和国政府采购法》第七十七条第一款及[当地裁量权指导
标准]，本机关拟对你单位作出如下行政处罚：
1. 罚款人民币[X]元（采购金额[X]元的千分之[X]）；
2. 列入不良行为记录名单；
3. 自处罚决定生效之日起[X]年内禁止参加政府采购活动。

如对上述认定的违法事实、处罚依据及处罚内容有异议，可在收到本告知书
之日起[X]日内提出书面陈述申辩意见，逾期视为放弃。

[财政部门全称]（盖章）
日期：
```

**写作要点**（品品案实战）：①罚款计算式写明（基数×比例），如"2,063,810元×6‰=12,382.86元（采购金额约206.38万元）"；②处罚依据写明政府采购法第七十七条第一款具体项（虚假材料为第（一）项、恶意串通为第（三）项）+实施条例第74条，不要只写87号令第37条（防止"适用依据错误"的抗辩，见品品案对方律师函）；③罚款数额达到听证标准的同步发听证告知书。

## 8. 律师法律分析意见书（实战修订定稿版——2026-09投诉处理案金标准）

> **总铁律：正文2000字以内。** 实战教训：初稿6231字（六大板块：归纳+程序审查+法律分析+瑕疵提示+建议+期限管理）被委托律师整体修订至1972字。啰嗦的根源是把"分析报告"写成了"教学讲义"。意见书是"事实+结论+依据"的结论性文书，不是论证过程展示；读的人是财政部门业务处室，不需要普法。

```
关于[项目名称]的法律分析意见

[开头一段搞定，约100字]：对[投诉人]投诉[项目名称]（项目编号：，受理编号：）
投诉一案，经本律师认真研究[材料清单：投诉书、质疑函、质疑答复函、采购人《投诉
回复》《前期调查报告》《质疑核实报告》、中标供应商《回复函》、相关通知书及外调
函件等书面材料]，具体分析意见如下。

一、投诉事项分析
（一）关于投诉事项一（[事项四字简称]）的分析
1.[争点小标题：名词短语，不带冒号评论]
[一段：双方分歧点+各自证据主张，客观陈述不加评论]
[一段：已启动的程序动作（如属地主管部门认定函）+"[认定结论]是本案处理的
关键前置事实"]
2.[后果与处理判断]
情形一：……[结论+依据条款]
情形二：……[结论+依据条款，含处罚后果引用]
（二）关于投诉事项二（[事项简称]）的分析
[法理一句话]→[卷内数据核查结果：评审打分明细、价格分计算等硬数据全保留]→
[结论："故此，……，从卷宗不能看出评审违法。"]

二、处理建议
（一）若[情形A]：[处理决定+恢复采购+后续动作，一段]
（二）若[情形B]：[事项一处理+处罚（保障陈述申辩听证）+事项二处理，分段]

以上意见，供处理时参考。

[律所地址电话页眉]
[律师事务所名称]
律   师  ： [姓  名]
[日期]
```

**简洁性铁律（逐条来自实战修订，违反即返工）**：
1. **法理通说不写**——划型标准讲解、认定职权归属条款、重新评审边界辨析（实施条例第44条与87号令第64条的关系）、处理条款裁量原理，一律删除。法条只在"处理路径"处引用。
2. **不设归纳层**——不单独写"投诉事项与各方主张归纳"，主张直接融入争点分析首段。
3. **程序无瑕疵一字不提**——质疑前置、时效、受理、暂停合法合规的，全删；程序瑕疵提示（如通知书模板残留）也不进正稿，另行口头/书面提示。
4. **不列工作清单**——调查动作清单、期限管理、文书写作提示是财政部门自己的活，律师意见书不给委托人布置todo。
5. **对照性论证不写**——与处理结论无直接关联的旁证对照删；保留的只有直接影响结论的事实与数据。
6. **数据说话，不议论**——评审打分明细、价格分等硬数据全保留；摆完数据一句"未见系统性压分"收，删掉"凸显核查必要性"式过渡议论。
7. **每段一个意思，三五句话**；标题层级最多两级（一、/（一）/必要时1.）。
8. **谦抑表达**——"从卷宗不能看出评审违法"不断言"不存在违法"；"基本复核"不写"精确印证"；留有余地。
9. **称谓用"贵局"**（写给财政部门的意见书），不用"我局"。
10. **落款**：律所全称+律师个人署名+日期；标题不带"处理结论的"之类限定语。

**仍须坚持的旧要点**：①条文引用先经法规工具核验；②分情形给路径（各投诉事项独立认定、独立处理）；③数据核查结果必须写进意见书（简的是议论，不是事实）。

**写作要点**（检察院案教训）：申辩中"公司代号""未派人开标"等辩解若无证据支撑反而坐实疑点；党组会记录、参数提供记录等内部文件可能成为对方书证——提交前先做证据风险评估。
