## 1. 法律

### 中华人民共和国政府采购法（2014修正）
| 条 | 内容要点（核验原文归纳） |
|----|------------------------|
| 第3条 | 公开透明、公平竞争、公正、诚实信用原则 |
| 第25条 | 采购当事人不得相互串通损害国家利益、社会公共利益和其他当事人合法权益；不得以任何手段排斥其他供应商参与竞争 |
| 第31条 | 单一来源采购三种法定情形：①只能从唯一供应商处采购；②不可预见的紧急情况；③必须保证原有采购项目一致性或服务配套要求，需要继续从原供应商处添购（添购资金总额不超过原合同采购金额10%） |
| 第49条 | 补充合同不超过原合同采购金额10% |
| 第52条 | 供应商质疑：知道或应知其权益受损之日起**7个工作日**内，以书面形式向采购人提出 |
| 第53条 | 采购人收到书面质疑后**7个工作日**内答复，书面通知质疑供应商和其他有关供应商，答复不得涉及商业秘密 |
| 第55条 | 对答复不满意或采购人未在规定时间内答复的，可在答复期满后**15个工作日**内向同级政府采购监督管理部门投诉 |
| 第56条 | 财政部门收到投诉后**30个工作日**内作出处理决定，并书面通知投诉人和相关当事人 |
| 第57条 | 处理投诉期间，可以视具体情况书面通知采购人暂停采购活动，但暂停时间最长不超过**30日** |
| 第71条 | 采购人/代理机构违法（规避公开招标、不合理条件限制排斥潜在供应商等）：责令限期改正、警告、罚款、处分 |
| 第77条 | 供应商违法行为：罚款（采购金额**5‰以上10‰以下**）、列入不良行为记录名单、**1-3年**内禁止参加政府采购活动；构成犯罪的追究刑事责任 |
| 第82条 | 集中采购机构虚报业绩等：罚款2-20万元，情节严重取消代理资格 |

## 2. 行政法规

### 政府采购法实施条例（2015施行）
| 条 | 内容要点 |
|----|---------|
| 第20条 | 以不合理条件对供应商实行差别待遇或歧视待遇的**8种情形**：①就同一项目向供应商提供有差别的项目信息；②资格、技术、商务条件与项目具体特点和实际需要不相适应或与合同履行无关；③技术、服务等要求指向特定供应商、特定产品；④以特定行政区域或特定行业的业绩、奖项作加分或成交条件；⑤对供应商采取不同的资格审查或评审标准；⑥限定或指定特定的专利、商标、品牌或供应商；⑦非法限定供应商所有制形式、组织形式或所在地；⑧以其他不合理条件限制或排斥潜在供应商 |
| 第74条 | 恶意串通的7种情形（供应商与采购人/代理机构、供应商之间恶意串通的具体列举） |

## 3. 部门规章

### 政府采购质疑和投诉办法（财政部令第94号，2018施行）
| 条 | 内容要点 |
|----|---------|
| 第2条 | 适用范围：质疑的提出和答复、投诉的提起和处理 |
| 第7条 | 采购文件应载明接收质疑函的方式；财政部门应公布投诉受理方式 |
| 第11条 | 投诉人资格：参与该采购活动的供应商；潜在供应商对采购文件可质疑 |
| 第13条 | 质疑答复期限：收到质疑函后**7个工作日**内 |
| 第16条 | 质疑答复导致中标、成交结果改变的，应将有关情况书面报告财政部门 |
| 第17条 | 投诉期限：答复期满后**15个工作日**内 |
| 第21条 | 财政部门收到投诉书后**5个工作日**内审查，作出受理/不予受理 |
| 第22条 | 被投诉人和其他与投诉事项有关的当事人应当在收到投诉答复通知书及投诉书副本之日起**5个工作日**内，以书面形式向财政部门作出说明，并提交相关证据、依据和其他有关材料 |
| 第23条 | 处理投诉原则上**书面审查**；必要时可调查取证或组织质证；可依职权委托相关单位或第三方开展调查取证、检验、检测、鉴定 |
| 第25条 | **应当由投诉人承担举证责任的投诉事项，投诉人未提供相关证据、依据和其他有关材料的，视为该投诉事项不成立**；被投诉人未按要求提交材料的，视同放弃说明权利，依法承担不利后果 |
| 第26条 | 财政部门应当自收到投诉之日起**30个工作日**内，对投诉事项作出处理决定 |
| 第28条 | 财政部门处理投诉期间可暂停采购活动，最长**30日** |
| 第29条 | **驳回投诉的4种情形**：①受理后发现不符合法定受理条件；②投诉事项缺乏事实依据、不成立；③投诉人捏造事实或提供虚假材料；④投诉人以非法手段取得证明材料（来源合法性存疑且无法证明合法取得的，视为非法手段） |
| 第31条 | **采购文件投诉成立的处理矩阵**：不影响采购结果的→继续开展采购活动；影响或可能影响的→①未确定中标/成交供应商：责令重新开展采购活动；②已确定但未签合同：认定中标/成交结果无效，责令重新开展；③合同已签但未履行：撤销合同，责令重新开展；④合同已履行：给他人造成损失的，相关当事人可依法提起诉讼，由责任人承担赔偿责任 |
| 第32条 | **采购过程/采购结果投诉成立的处理矩阵**：第1款前段——经认定成立的投诉事项**不影响采购结果的，继续开展采购活动**；影响或可能影响采购结果的→①未确定中标/成交供应商：责令重新开展采购活动；②已确定但未签合同：认定中标/成交结果无效，合格供应商符合法定数量时可另行确定中标/成交供应商，否则责令重新开展；③合同已签未履行：撤销合同，可另行确定或重新开展；④合同已履行：相关当事人依法提起诉讼索赔。第2款：对废标行为投诉成立的，认定废标行为无效 |
| 第34条 | 处理决定书送达、公告 |
| 第36条 | 采购人/代理机构有下列情形的，财政部门责令限期改正；情节严重的给予警告+对责任人处分并通报：①拒收法定质疑期内的质疑函；②对质疑不予答复或答复与事实明显不符，**并不能作出合理说明**；③拒绝配合财政部门处理投诉事宜 |

### 政府采购货物和服务招标投标管理办法（财政部令第87号，2017修订）
| 条 | 内容要点 |
|----|---------|
| 第17条 | 不得将注册资本、资产总额、营业收入、从业人员、利润、纳税额等**规模条件**作为资格要求或评审因素；不得通过将除进口货物以外的**生产厂家授权、承诺、证明、背书**作为资格要求，对投标人差别待遇或歧视待遇 |
| 第29条 | 发布招标公告/发出投标邀请书后，不得擅自终止招标（除重大变故、采购任务取消等法定情形外） |
| 第37条 | **视为串通投标的6种情形**（投标无效）：①不同投标人的投标文件由同一单位或者个人编制；②不同投标人委托同一单位或者个人办理投标事宜；③不同投标人的投标文件载明的项目管理成员或者联系人员为同一人；④不同投标人的投标文件异常一致或者投标报价呈规律性差异；⑤不同投标人的投标文件相互混装；⑥不同投标人的投标保证金从同一单位或者个人的账户转出 |
| 第52条 | 评标委员会应当按照**招标文件中规定的评标方法和标准**，对符合性审查合格的投标文件进行商务和技术评估，综合比较与评价 |
| 第60条 | 评标委员会认为投标人的报价明显低于其他通过符合性审查投标人的报价，有可能影响产品质量或者不能诚信履约的，应当要求其提供书面说明及证明材料，不能证明其报价合理性的，评标委员会应当将其作为无效投标处理 |
| 第62条 | **评标委员会及其成员禁止行为**：私自接触投标人；接受不一致的澄清说明（51条情形除外）；违反评标纪律发表倾向性意见或征询采购人倾向性意见；**对需要专业判断的主观评审因素协商评分**；擅离职守；记录、复制、带走评标资料等。有第一至五项行为之一的，评审意见无效 |
| 第64条 | **评标结果汇总完成后可修改评标结果的仅4种情形**：①分值汇总计算错误；②分项评分超出评分标准范围；③评标委员会成员对**客观评审因素评分不一致**；④经评标委员会认定评分畸高、畸低。签署前发现应当场修改并记载；签署后发现的组织原评标委员会重新评审并书面报告财政部门 |
| 第69条 | 中标结果2个工作日内公告，招标文件随中标结果同时公告；公告内容含采购人及代理机构名称地址联系方式、项目名称编号、中标人名称地址和中标金额、主要中标标的名称规格型号数量单价服务要求、**评审专家名单**；第5款：对未通过资格审查的投标人告知未通过原因；**采用综合评分法的，应告知未中标人本人的评审得分与排序** |

### 政府采购非招标采购方式管理办法（财政部令第74号）
| 条 | 内容要点 |
|----|---------|
| 第38条 | 达到公开招标数额标准的货物、服务项目拟采用单一来源采购方式的，应在省级以上财政部门指定媒体上公示 |

### 政府采购促进中小企业发展管理办法（财库〔2020〕46号）
| 条 | 内容要点 |
|----|---------|
| 第5条 | 不得以注册资本、资产总额、营业收入、从业人员、利润、纳税额等规模条件和财务指标作为供应商的资格要求或评审因素；不得在企业股权结构、经营年限等方面对中小企业实行差别待遇或歧视待遇 |
| 第7条 | 采购限额标准以上、**200万元以下**的货物和服务采购项目、**400万元以下**的工程采购项目，适宜由中小企业提供的，采购人应专门面向中小企业采购 |
| 第8条 | 超过200万元的货物和服务、超过400万元的工程项目，适宜的应预留该部分预算总额**30%以上**专门面向中小企业，其中预留给小微企业的比例不低于**60%**；预留措施：整体/采购包专门面向、联合体（中小企业承担一定比例）、分包 |
| 第11条 | 中小企业参加政府采购活动，应当出具本办法规定的《中小企业声明函》，否则不得享受相关中小企业扶持政策；**任何单位和个人不得要求供应商提供《中小企业声明函》之外的中小企业身份证明文件** |
| 第16条 | **政府采购监督检查、投诉处理及行政处罚中对中小企业的认定，由货物制造商或者工程、服务供应商注册登记所在地的县级以上人民政府中小企业主管部门负责**；中小企业主管部门应当在收到协助开展中小企业认定函后**10个工作日**内做出书面答复 |
| 第20条 | **供应商提供声明函内容不实的，属于提供虚假材料谋取中标、成交**，依照《政府采购法》等国家有关规定追究相应责任（适用招标投标法的工程项目，属于弄虚作假骗取中标） |

## 4.2 属地化指引（各省不同，务必替换）

> ⚠️ 本技能一律不引用具体地方号段文件（如省财政厅发布的采购负面清单、省本级单一来源采购管理办法、代理机构监督考核办法等），应用时须以**属地财政部门现行文件**为准。以下列出"不同省份可能不同、需要替换"的情形，供核对。

| 事项 | 地方化情形（各省不同） | 核对方式 |
|------|----------------------|---------|
| **采购负面清单** | 多数省份发布本省负面清单（如某省财政厅〔2021〕283号） | 查本省财政部门官网/政府采购网，或财政部负面清单；无则参照财政部及本省历年监督检查报告 |
| **单一来源采购管理办法** | 部分省份发布"省本级单一来源采购管理办法"，**仅适用省级本级预算单位** | 地方性办法第2条通常限定适用范围；**非省本级单位须适用《政府采购非招标采购方式管理办法》（74号令）**——这是最容易踩的坑 |
| **代理机构监督考核办法** | 各省代理机构考核/记分办法（如某省财政厅〔2019〕5号），记分条款（"一次记6分""一次记2分"）各省不同但逻辑相通 | 查本省财政厅发布的代理机构监督考核办法，对照记分条款 |
| **评审专家/劳务报酬标准** | 评审费标准各省不同（样例：2小时以内300元/人，每增1小时+100元） | 查本省《评审专家管理办法》或财政部门规定 |
| **履约验收管理办法** | 多数省份发布本省履约验收管理办法（除公共服务项目外，未强制公示验收情况） | 查本省财政厅发布的履约验收管理办法 |
| **行政自由裁量权指导标准** | 处罚幅度阶次（虚假材料罚款5‰-10‰、禁入1-3年）由各市县财政局/财政部门细化 | 查本级财政部门发布的自由裁量权指导标准 |
| **电子化质疑投诉平台** | 各省设政府采购电子化质疑投诉平台/一体化平台 | 查本省政府采购网/一体化平台在线质疑投诉入口 |
| **采购文件模板** | 各省财政厅发布现行采购文件模板 | 查本省财政厅发布的采购文件标准文本 |
