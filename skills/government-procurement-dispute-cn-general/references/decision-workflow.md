# 政府采购投诉处理决定书撰写工作流（2026实战案提炼）

> **定位**：本文件是 `templates.md` §4 决定书骨架的**全流程操作手册**——从收材料到定稿的每一步怎么做、实体怎么定性、docx 怎么落地。骨架看模板，方法论看本文件；法条原文对照 `legal-basis.md`。
> 提炼自真实案件：运动木地板采购项目投诉（投诉事项1＝虚假中小企业声明函、投诉事项2＝倾向性打分＋业绩漏评），最终"事项1驳回＋事项2部分成立但不影响结果、继续开展采购活动"，历经属地工信部门外调认定、5名评标委员会成员询问、多轮修订定性，全流程实操验证。

## 0. 工作流总览

```
收材料 → 梳时间轴 → 逐事项定性 → 补强调查（外调认定／约谈评委）
→ 调机关同类样板定格式 → 起草（五段式＋法条附录）→ 三方核对（事实／定性／法条）
→ 渲染校验 → 交付留白清单
```

**先定性，后动笔**。定性决定依据条文与主文写法（§4.4 对应表），定性反复则全文重写。

## 1. 材料清单与时间轴

**材料清单**（缺项先补材料，禁止推测）：

| 材料 | 用途 |
|---|---|
| 投诉书（常为扫描件） | "投诉事项及投诉请求"部分**逐字录入**，不得转述概括 |
| 质疑函、质疑答复函 | 质疑前置链条日期；投诉不得超出质疑范围（94号令第20条） |
| 招标文件 | 项目名称／编号／包号、所属行业、是否专门面向中小企业、评分细则原文（分值、分档标准、业绩条款） |
| 相关供应商投标文件 | 《中小企业声明函》原文（引号＋"……"节录）、被投诉材料原始记载 |
| 投诉人投标文件 | 被漏评材料的位置（目录有无该项、页数）——业绩漏评认定的关键 |
| 评标报告、各评委分项评分表 | 客观分是否评委一致、主观分是否超分档范围、打分方向 |
| 程序文书 | 收诉、调查取证通知书、受理、答复通知书、暂停通知书、各方答复收讫日期 |
| 外调函件 | 协助认定函、督促函、**回函原文** |
| 询问笔录 | 询问时间地点人员、关键问答（评分依据、是否独立、有无针对性） |
| 律师法律分析意见 | 说理骨架参考（模板见 `templates.md` §8）；**内部参谋件，不对外引用** |

**时间轴锚点**（按序写进"调查取证情况"，日期与程序文书一一对应）：
招标公告日 → 开标日 → 中标（结果）公告日 → 质疑日 → 质疑答复日 → 收诉日（同日可发调查取证通知书）→ 受理／答复通知书／暂停 → 各方答复收讫 → 外调发函／（督促函）／回函 → 询问 → 处理决定。

**期限红线**（对照 SKILL.md Step 2 时限表）：30个工作日作出处理决定；暂停最长30日，注意暂停届满与处理决定衔接。

## 2. 格式基准：先拿机关样板，再动笔

**禁止凭空排版**。调取委托机关**近期同类决定书**（优先选与本案投诉事项类型最接近的：声明函类／评审打分类／资格类），以样板文件为底版复制后清空正文，逐段提取格式参数复刻。同类文书格式与机关既往文书完全一致，体现连续性。

典型参数（地市级财政局实操样板，**以属地机关样板为准**）：

| 元素 | 参数 |
|---|---|
| 大标题"政府采购投诉处理决定书" | 宋体，二号，加粗，居中 |
| 编号行 | 仿宋_GB2312 三号，居中 |
| "一、"级节标题 | 黑体，三号 |
| "（一）"级小节标题 | 楷体_GB2312，三号 |
| 正文 | 仿宋_GB2312，三号，两端对齐 |
| 行距 | 固定值28磅，全篇一致 |
| 首行缩进 | 三号字两字符（约32磅）；节标题、编号行不缩进 |
| "投诉事项N：""事实依据：""投诉请求："标签 | 加粗（仅标签，正文不加粗） |
| 落款 | 机关全称＋成文日期，右下（首行缩进实现，与样板一致） |
| 法条附录"本决定所依据的相关法律" | 标题居中；条文 仿宋_GB2312 四号，首行缩进 |
| 页面设置、页边距 | 整体继承样板文件 |

## 3. 五段式结构详解

```
政府采购投诉处理决定书
编号：××××
一、投诉相关主体基本情况        投诉人／被投诉人1（采购人）／被投诉人2（代理机构）／相关供应商，各附地址
二、投诉项目基本情况            项目名称／编号＋包号／采购人／代理机构
三、投诉事项及投诉请求          投诉事项N＋事实依据（逐字）、投诉请求；标签加粗
四、调查取证情况
  （一）项目质疑投诉情况        招标→开标→中标公告→质疑→答复→收诉（质疑前置链条）
  （二）投诉调查情况            受理、发答复通知书及副本、暂停、各方答复、外调发函与回函、询问
  （三）查明事实情况            按事项分块："关于投诉事项N。"→各方答复主要内容→招标文件／投标文件
                              相关规定原文→回函→"根据查明事实，我局认为：…"
五、处理决定                  定性＋依据条文→决定主文（分项）→救济途径（60日复议／6个月诉讼，
                              复议机关与管辖法院写具体名称）
本决定所依据的相关法律          正文中**实际引用过**的条文全文，按"法律—法规—规章"顺序编号，
                              四号仿宋
```

**引用原文的格式**：招标文件、投标文件、声明函、回函一律引号直录＋"……"省略无关部分。**禁止转述代替引用**——划型数据、评分标准、给分条件必须原文（实战例："……（运动地板），属于（工业）行业；制造商为（××公司），从业人员239人……属于（小型企业）……"）。

## 4. 实体定性方法论（核心）

### 4.1 中小企业声明函类投诉（属地外调认定路径）

- **认定权不在财政部门**：《政府采购促进中小企业发展管理办法》第16条——投诉处理中对中小企业的认定，由**货物制造商注册登记所在地**的县级以上人民政府中小企业主管部门负责。财政部门**不得径行裁断**，必须发《关于协助开展中小企业认定函》（主管部门10个工作日内书面答复）；逾期不复的，向其**上级主管部门发督促函**。
- **以回函为准**：回函认定的从业人数、划型与《中小企业声明函》一致 → 投诉事项缺乏事实依据，不成立。
- **第三方信息不是法定依据**：企查查标注、招聘平台规模标注（如"500-999人"）、小微企业名录检索无记录等，均非划型认定依据，决定书中应明确写"不足以推翻属地中小企业主管部门作出的认定结论"。
- 三个易错点：划型对象是**供货产品的制造商**而非供应商本身；划型用**上一年度**数据；注意投诉人引用的"营业收入达标即中型"忽略了划型标准"从业人数**且**营业收入"的双条件结构。

### 4.2 评审打分类投诉（四查＋两查）

**四查**（＝87号令第64条四种可修改评标结果情形）：
① 分值汇总有无计算错误；② 分项评分有无超出评分标准范围；③ 评标委员会成员对**客观**评审因素评分有无不一致；④ 有无评分畸高畸低。

**两查**（＝87号令第62条评标纪律）：有无对需要专业判断的主观评审因素**协商评分**；有无违反评标纪律发表**倾向性意见**。

**主观分分差≠违法**，核查路径：主观分各分项是否设有分档量化标准 → 各评委打分是否都在分档范围内 → 对投诉人的打分**方向是否一致**（实战案：5名评委打分方向并不一致，有评委给投诉人的分高于给中标供应商的分，属主观评审正常分歧，未见系统性压分）→ 客观分各评委是否一致。必要时**约谈评审专家**并制作笔录固定：评分依据、是否独立评审、有无针对性压分、是否知悉评分标准。

### 4.3 部分成立的处理范式（本文件最重要沉淀）

同一投诉事项内部常含多项指控，**必须拆开逐项定性**：

> **范式**：指控A（倾向性打分）查证不成立 ＋ 指控B（业绩客观分漏评）查证属实 ⇒ **投诉事项部分成立、部分不成立**。若 B 补分后总分仍低于中标供应商（实战案：84.20＋2＝86.20＜88.23，排序不变）⇒ **不影响中标结果** ⇒ 依94号令第32条第1款前段"经认定成立的投诉事项不影响采购结果的，**继续开展采购活动**"，不触发中标无效／重新采购。

正文论证用**"退而言之"结构**：先答指控是否成立 → 再退一步核算"即便……仍……不影响本项目中标结果" → 引32条1款前段收束"无需重新组织评审"。

**决定主文分项列明**：

```
一、驳回投诉事项1。
二、投诉事项2部分成立，不影响本项目中标结果，本项目继续开展采购活动。
```

### 4.4 查明情形 → 定性 → 依据 → 主文 对应表

| 查明情形 | 定性表述 | 依据 | 主文 |
|---|---|---|---|
| 指控无证据、与查明事实不符 | 投诉事项缺乏事实依据，不成立 | 94号令第29条第(二)项 | 驳回投诉事项N |
| 部分指控属实、部分不成立，属实部分不影响结果 | 投诉事项N部分成立、部分不成立，不影响中标结果 | 第29条第(二)项、**第32条第1款前段** | 分项：驳回＋继续开展采购活动 |
| 投诉事项成立，影响或可能影响结果（已定标未签合同） | 投诉事项成立 | 第32条第1款第(二)项 | 认定中标结果无效；合格供应商够数可另行确定，否则重新采购 |
| 对采购文件的投诉成立，不影响结果 | 投诉事项成立 | 第31条前段 | 继续开展采购活动 |
| 受理后发现不符合受理条件 | 不符合法定受理条件 | 第29条第(一)项 | 驳回 |

**表述自洽红线**：正文"我局认为"段、处理决定引导段、决定主文三处定性口径必须一致；改定性时全文检索旧表述（如"均缺乏事实依据""投诉事项N不成立"）清除残留。

## 6. docx 操作规范

- **新建**：以机关样板为底版复制，清空正文段落但保留节设置（sectPr），逐段重建并显式设置中文字体（须同时设 eastAsia）、字号、行距、缩进、对齐。
- **在既有文件上修改**（经办人已手改的，**手改内容一字不可覆盖**）：改单段＝保留段落格式与首个 run 格式、仅整体替换文本；新增段落＝深拷贝文内同类段落（法条段克隆法条段、块头克隆块头）再改文本。
- **渲染校验**：转 PDF（WPS：`KWPS.Application`；Word：`Word.Application`）后逐页检查——字体嵌入、页数、无乱码（U+FFFD／空心方块）、关键锚点文本按序在位；格式与样板逐参数比对。
- 未知信息**留全角空格占位**（如"2026年9月　日"），随交付附**留白清单**：回函日期、回函内容数据、落款日期、待经办人核对的推定信息（答复收讫日、地址、主体排序等）。

## 7. 质控清单（交付前逐项打勾）

- [ ] 结构：五段＋附录齐全，节序正确；主文与"我局认为"段定性口径一致，无旧表述残留
- [ ] 投诉事项、事实依据、请求与投诉书**逐字**一致；未超出质疑范围
- [ ] 时间轴每个日期与程序文书对应；质疑前置、30个工作日、暂停届满衔接无瑕疵
- [ ] 引用原文（评分细则、声明函、回函）均为直录＋省略号，无转述失真
- [ ] 数字一致性：总分、分项分、报价、人数、家数各处一致
- [ ] 声明函类：已函询属地主管部门（必要时督促函），以回函认定为准，已写明第三方信息非法定依据
- [ ] 评审类：四查＋两查已覆盖；约谈笔录要点已入卷；"不影响中标结果"有核算过程
- [ ] 部分成立：拆分定性清楚；32条1款前段已引；主文分项
- [ ] 附录法条＝正文实际引用的条文，且经法规库核验现行有效
- [ ] 救济途径：60日复议／6个月诉讼，复议机关与管辖法院写**具体名称**
- [ ] 排版与机关样板逐参数一致；渲染无乱码、无空页
- [ ] 留白清单已附（未知日期、待填数据、待核对推定信息）

## 8. 禁止事项

- 禁止凭记忆默写法条（对照 `legal-basis.md` 及法规库核验）；禁止附录囤积正文未引用的条文。
- 禁止编造日期、回函内容、评分数据；未知信息留白并列入交付清单。
- 禁止以第三方平台信息（企查查、招聘网站、名录检索）替代属地中小企业主管部门的划型认定。
- 禁止在对外决定书中引用律师内部分析意见、专家个人姓名及内部研判过程。
- 禁止覆盖经办人在文书上的手改内容；修改一律打补丁，改后全文核验。
- 主文不得超出投诉请求与查明事实的范围；"继续开展采购活动"与"责令重新开展采购活动"不得混用。
