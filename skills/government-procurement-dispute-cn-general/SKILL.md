## 核心工作流（四步法）

### Step 1：定位环节
将争议放入"采购文件 → 采购过程 → 中标结果"三段之一，这决定了处理规则和法律后果。
- **采购文件问题**（资格条件、技术参数、评分标准）→ 94号令第31条处理矩阵
- **采购过程问题**（评审程序、信息泄露、录音异常）→ 94号令第32条
- **中标结果问题**（虚假材料、串通投标、履约能力）→ 行政调查+处罚路径

### Step 2：程序检查（先于实体，一票否决项）
1. **质疑前置**：未质疑直接投诉 → 不予受理
2. **时效**（硬数据，记错即失权）：

| 时限 | 天数 | 起算点 |
|------|------|--------|
| 提出质疑 | **7个工作日** | 知道或应知权益受损之日（政府采购法第52条） |
| 质疑答复 | **7个工作日** | 收到书面质疑之日（第53条） |
| 提出投诉 | **15个工作日** | 答复期满之日（第55条） |
| 财政处理投诉 | **30个工作日** | 收到投诉之日（第56条） |
| 暂停采购 | **≤30日** | 处理决定作出期间（第57条） |
| 投诉受理审查 | **5个工作日** | 收到投诉之日（94号令第21条） |
| 被投诉人答复 | **5个工作日** | 收到投诉书副本之日 |
| 行政复议 | **60日** | 知道具体行政行为之日 |
| 行政诉讼 | **6个月** | 知道具体行政行为之日 |

3. **主体适格**：投诉人须是参与该项目的供应商；潜在供应商仅可对采购文件质疑
4. **材料齐备**：投诉书+身份证明+质疑函+答复函+证据清单，缺项一次性告知补正

### Step 3：实体审查（对照红线清单）
**八大高频违规红线**（识别标准详见 references/review-manual.md）：

1. **品牌指向**（实施条例第20条第3、6项）：参数与特定品牌说明书高度重合／评分标准照搬某品牌检测报告原文／向代理机构提供特定品牌详细参数。实战案例：希沃（某中学智慧教室）、深信服（某检察院项目，党组会记录直接证明意图）
2. **规模条件**（87号令第17条）：信用等级、注册资本、资产总额、营业收入、从业人员、利润、纳税额作资格或评分项——**间接反映**也算（如AAA信用等级报告内含资产总额指标）。实战案例：法院物业项目
3. **专利/检测报告**（实施条例第20条第6项）：要求专利证明；CNAS标识报告（CMA已足够）；检测报告时间供应商无法在投标前取得。实战案例：某教育系统一体化设备采购（认证需6-8周）
4. **虚假材料**（政府采购法第七十七条第一款第（一）项）：认证证书全国认证认可信息公共服务平台（cx.cnca.cn）查不到即认定虚假；处罚=罚款采购金额5‰-10‰+列入不良名单+1-3年禁入。实战案例：某小学（采购金额2,063,810元×6‰=12,382.86元）
5. **串通投标**（87号令第37条，**6种**情形）：不同投标人文件异常一致/报价规律性差异等，外观一致即**视为**串通，无需证明共谋；但当事人常见抗辩"系第三方造假所致被动相似"（品品案），需区分。**证明路径**：可要求供应商提供中标通知书、付款凭证等原件，逾期未提供→视为不能排除合理怀疑→认定串通
6. **擅自终止招标**（87号令第29条）与**单一来源违法**（政府采购法第31条+74号令第38、40条）：达到公开招标数额的单一来源必须批准+公示；**本级预算单位不适用"仅适用省级本级的单一来源采购管理办法"**（全省各地均应按政府采购非招标采购方式管理办法执行，地方性办法仅限对应预算级次）
7. **变相规模/成立年限门槛**（实施条例第20条、87号令第17条）：信息安全管理体系认证（ISMS）、国家秘密载体印制资质、软件著作权证书、七星级售后服务认证、CNAS/ilac-MRA标识检测报告——表面"与需求相关"，实则隐含年限/净资产/人数/场所/自愿性认证要求（详见 references/review-manual.md §6）
8. **评审专家责任**（全新维度）：评审专家可当举报人；代理机构干预评审、指定磋商组长、手机未上交（属地代理机构监督考核办法示例口径记6分）；评审费示例口径：2小时以内300元、每增1小时+100元（评2小时20分应付400元，付300元记2分）——具体标准以属地现行文件为准

### Step 4：处理决定（影响判断是关键）
94号令第31条矩阵（采购文件投诉成立时）：

| 采购进展 | 处理结果 |
|---------|---------|
| 未确定中标/成交供应商 | 责令重新开展采购活动 |
| 已确定但未签合同 | 认定中标/成交结果无效，责令重新开展 |
| 已签合同未履行 | 撤销合同，责令重新开展 |
| 合同已履行 | 相关当事人依法提起诉讼索赔 |

关键原则：**投诉事项成立但"不影响或不可能影响采购结果"的，继续开展采购活动**（94号令第32条第1款前段；如垃圾分类环保驿站案：3项不成立+1项成立仍继续采购）。因果影响判断是财政部门的核心裁量点，也是双方攻防主战场。

**部分成立范式**（2026实战案沉淀，详见 `decision-workflow.md` §4.3）：同一投诉事项内含多项指控时**拆开逐项定性**——指控A查证不成立＋指控B查证属实＝"部分成立、部分不成立"；若B补分核算后排序不变（不影响中标结果），则不触发中标无效/重新采购，主文分项列明"驳回＋继续开展采购活动"。正文论证用"退而言之"结构：先答指控是否成立，再退一步核算"即便……仍……不影响本项目中标结果"。

**决定书起草的完整工作流**（材料清单、时间轴锚点、机关样板复刻格式、五段式结构详解、声明函属地外调认定、评审"四查＋两查"、docx操作规范、质控清单）见 `references/decision-workflow.md`。

## 分析方法论

**三步分析法**：
1. **事实切割**：按"采购文件—采购过程—中标结果"三段整理时间线（精确到日）
2. **规范检索**：先查属地财政部门发布的采购负面清单（无则查财政部负面清单，或参照属地历年监督检查报告），再对照实施条例第20条8种情形
3. **效果评估**：违规成立后是否影响采购结果 → 决定"责令改正"还是"重新采购"

**对抗性思维**（出具法律意见前必做）：
- 我方观点 → 预判对方反驳 → 准备应对
- 例：主张"信用等级评分违反87号令第17条" → 对方会说"是为了优选履约能力" → 应对：信用评定内含资产总额等规模指标，实质构成规模条件评审；履约能力应通过履约验收环节考察而非事前评分

## 法条核验纪律（重要）

⚠️ **禁止凭记忆引用具体条号和条文内容**。本技能的引用已核验，但使用时仍应：
1. 通过法规检索工具（pkulaw / yuandian 等）核验条号与原文后再写入文书
2. 注意时效：《政府采购法》2014修正、《实施条例》2015施行、87号令/94号令2017-2018修订
3. 本技能曾自查出3处引用错误（87号令37条"4种"应为"6种"、中小企业办法第7/8条张冠李戴），**这证明凭记忆引用不可靠**
