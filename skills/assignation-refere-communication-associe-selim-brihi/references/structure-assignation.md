## 2. 强制警告

完整援引标准段落：

```
非常重要

您必须在前述开庭日期前委托律师，方可在 [城市] [商事法院 / 经济活动
法院] 紧急程序合议庭中获得代理。

否则，法院可能仅依据对方提供的材料作出对您不利的裁定。

提醒您，《民事诉讼法典》第 861-2 条规定：

“在不影响第 68 条规定的前提下，依据《民法典》第 1343-5 条提出的给予
付款期限的附带请求，可以通过向书记室提交、递交或寄送的申请书提出，
并在书记室登记。该请求人必须在开庭前证明对方已通过附回执的挂号信知悉
此事。当事人为支持其付款期限请求而援引的证据随申请书一并附上。

该附带请求人可以依照第 446-1 条第二款的规定不出庭。在此情况下，法官
仅在其认为针对该方提出的请求符合规定、可受理且理由充分时方予支持。”

支持请求的证据按所附清单列于文书末尾。
```

## 3. 传票正文：敬请庭长

### 1. 事实

#### 1.1. 当事人及公司 [名称] 的介绍

必须包括：
- 当事人的确切身份
- 公司的介绍（设立、法律形式、业务、注册地）
- 资本构成及股份/份额的分配，附确切百分比
- 原告的身份（持股 X% 的股东）
- 被告的身份（经理、总裁等）
- 证据引用（Kbis 工商登记摘录、章程）

#### 1.2. [根据案情的语境标题]

描述导致争议的事实时间线。小节示例：
- 查阅请求未获回应
- 股东之间分道扬镳的背景（如相关）
- 律师之间的往来

#### 1.3. [被告] 对 [原告] 表现出的缺乏透明

按时间顺序详述每项缺失：
- 通知所附文件不完整或零散
- 所提供文件中缺页
- 以空白页替代所声明的文件
- 对查阅请求不予回应

对每项事件，说明：
- 日期
- 要求提供的文件与所提供文件的性质
- 缺页情况及总页数
- 证据引用

#### 1.4. [关于明显恶意的可选章节]

如适用，记录：
- 规避义务的尝试（例如：邀请前往个人住所现场查阅）
- 此前认定恶意的判决
- 设立竞争公司
- 施压要求转让股份
- 任何表明阻挠策略的要素

#### 1.5. 事实结论

结论为原告始终未能行使其权利，故向法院提起紧急程序。

### 2. 论证

#### 2.1. 关于依据《商法典》第 L. 238-1 条责令查阅文件的禁令

##### 2.1.1. 适用法律条文回顾

完整引用：

```
《商法典》第 L. 238-1 条规定：

“当利害关系人无法获得第 L. 221-7、L. 223-26、L. 225-115、L. 225-116、
L. 225-117、L. 225-118、L. 225-129、L. 225-129-5、L. 225-129-6、
L. 225-135、L. 225-136、L. 225-138、L. 225-177、L. 225-184、
L. 228-69、L. 237-3 和 L. 237-26 条所述文件的出示、提供或传递时，
可以请求在紧急程序中审理的法院庭长，或者责令清算人、管理人、经理
和负责人限期提供，并科以逾期罚款，或者指定一名受托人负责完成该提供。

任何利害关系人如无法从清算人、管理人、经理或负责人处获得符合国务
院法令规定格式的委托书格式或该法令为召开股东大会所要求的信息，均可
提起同样的诉讼。

当请求获准支持时，逾期罚款和程序费用由被追究的管理人、经理、负责人
或清算人承担。”
[加粗下划线为笔者所加]
```

然后根据公司形式引用具体条文：

**对于有限责任公司——第 L. 223-26 条第 4 款：**
```
“股东还可以在任何时候，按照国务院法令规定的条件，获得该法令确定的、
涉及最近三个会计年度的公司文件的查阅。”
```

##### 2.1.2. 条件具备

按编号要点结构（i、ii、iii、iv）：

**i. 股东身份**
- 原告是持股 X% 的公司股东
- 证据引用

**ii. 属于查阅权范围的文件**
有限责任公司标准清单：
- 管理报告
- 财产清单
- 年度账目
- 拟议决议的文本
- 提交股东大会的报告
- 股东大会记录
- 说明：“涉及最近三个会计年度 [年份]”

**iii. 请求直接针对负责人**
- 请求针对 [姓名]，其身份为 [职务]

**iv. 阻挠已明确**
- 对事实部分所述缺失的概括回顾
- 引用事实章节

结论：
```
因此，[原告] 依据《商法典》第 L. 238-1 条的条件向本院 [商事法院 /
经济活动法院] 庭长先生/女士提起诉讼，请求责令 [被告] 提供上列文件。
```

##### 2.1.3. 语境要素（可选但建议）

如恶意已明确，使用要点（ð）加以强调：
- 冲突背景
- 被告此前的败诉判决
- 规避义务的尝试
- 隐瞒的迹象
- 设立平行公司
- 对原告施加的压力

#### 2.2. 关于不可重复费用

标准表述：
```
为在本诉讼中维护自身权利，[原告] 不得不支出不可重复费用，由
其自行承担有失公平。

据此，其请求本院庭长依据《民事诉讼法典》第 700 条判令 [被告]
支付 [金额] 欧元。
```

惯常金额：5,000 欧元

## 4. 主文：鉴于上述理由

```
鉴于上述理由

鉴于《商法典》第 L. 238-1 条，
鉴于《商法典》第 [L. 223-26 / 其他视公司形式而定] 条，
鉴于传票及其所附证据，

请求 [城市] [商事法院 / 经济活动法院] 庭长：

- 责令 [先生/女士 姓氏 名字] 向 [先生/女士 姓氏 名字] 提供公司
  [名称] 最近三个会计年度 [年份] 的全部相关文件，清单如下：

  - 管理报告；
  - 财产清单；
  - 年度账目；
  - 拟议决议的文本；
  - 提交股东大会的报告；
  - 股东大会记录。

- 责令附以逾期罚款，自判决送达后 [期限] 天 [7 天后 / 自] 起，每
  延迟一日罚款 [金额] 欧元；

- 判令 [先生/女士 姓氏 名字] 依据《民事诉讼法典》第 700 条向
  [先生/女士 姓氏 名字] 支付 [金额] 欧元，并承担全部诉讼费用。

保留一切权利
```

惯常的逾期罚款参数：
- 金额：每天 1,000 至 2,000 欧元
- 期限：60 天
- 起算点：“送达后 7 天”
