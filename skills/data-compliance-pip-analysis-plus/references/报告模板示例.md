# 数据合规与个人信息保护分析报告 · 排版模板示例

> 本文件为技能生成 docx 报告的**排版基准**，供 AI 套用，不随每次分析单独输出。目标是减少不同次生成之间的风格漂移，提升交付一致性。

## 一、文档属性建议

- **页面**：A4；页边距常规（上下 2.54 cm、左右 3.18 cm）
- **正文**：仿宋_GB2312 / 宋体，小四（12 pt），行距 1.5 倍，首行缩进 2 字符
- **一级标题**（报告四大段）：黑体 / 方正小标宋，三号，左对齐
- **二级标题**（各节内小点）：楷体_GB2312 / 黑体，四号，加粗
- **表格**：全边框，表头加粗底纹，字号五号；长表建议跨页重复表头

## 二、固定结构（四段式，强制）

1. **一、法律层面分析**
2. **二、相关法律法规规章司法解释政策等依据**
3. **三、相关学术论文分析**
4. **四、其他**
5. **文末免责声明（必填，显著）**："此为AI分析，不作为法律意见和建议。"

## 三、页脚页码（强制）

- **插入位置**：页面底端（页脚），居中
- **格式**："第 X 页，共 Y 页"（或"— X —"）
- 如设封面/目录，可用罗马数字编页，正文起切换为阿拉伯数字连续编码

## 四、来源与标注规范（贯穿全文）

- **官方原文事实**：注明法规/文件名称、令号/发文字号、施行日期、来源（知识库文件或官方 URL）
- **AI 归纳观点**：标注"非原文·需复核"或"AI归纳·需复核"
- **外部补充内容**：前缀「【外部补充·需复核】」+ 来源（数据库/网站 + URL）+ 检索时点（YYYY-MM-DD）

## 五、临近生效提示（强制，若适用）

- 所涉规范处于"尚未生效"或距生效不足 60 日（含）的，须在相关分析处显著标注「【即将施行·YYYY-MM-DD】」，并提示过渡期安排与新旧衔接义务。
- 示例：《小型个人信息处理者个人信息保护简化措施规定》自 2026-09-01 起施行（当前尚未生效），合规方案应预留衔接。

## 六、交付口径

- 报告须生成 **docx 格式文件**，并在**页脚**插入页码（页面底端居中，格式"第 X 页，共 Y 页"）；不得仅在文末标注页码。
- 正式引用与适用前，须以官方公布的政府令/法律文本及华宇元典核验结果交叉复核，不得仅凭本技能检索结论定论。
