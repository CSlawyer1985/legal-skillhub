# 外部补充：官方渠道与 MCP 检索指引

> 用途：当本技能内置知识库（**三库**：四级规范体系速查框架、学术文献库、典型案例库）未覆盖用户所需内容时，依本指引通过华宇元典法律数据 MCP（yuandian-mcp）与官方网站主动补充。
> **口径说明（2026-08-29）**：历史表述中的"三库"不含典型案例库；案例缺失同样触发本机制，见下文「一、5 案例类检索」。
> 所有外部结果须以「【外部补充·需复核】」标注来源（数据库 / 网站 + URL）与检索时点（YYYY-MM-DD），并区分"官方原文事实"与"AI 归纳观点"。

## 〇、前置可用性检查（调用前必做）

- 确认 `yuandian-mcp` 已连接且可用；可先查询余额确认额度充足，避免因连接中断或额度耗尽导致检索中途失败。
- 若 MCP 不可用，转用本指引「二、官方网站渠道（WebFetch）」直接检索官方来源，并仍按标注规范以「【外部补充·需复核】」标记。

## 一、华宇元典法律数据 MCP（yuandian-mcp）调用

### 1. yuandian_law_vector_search（法条级语义检索，首选）
- **用途**：按自然语言 query 检索法规 / 法条，适合"某主题有哪些规定""某行为违反哪条"类提问。
- **必填**：`query`（自然语言问题）。
- **选填**：`rewrite_flag`（默认 true）；`return_num`（默认 45，建议 6–10）；`fatiao_filter`：
  - `sxx`：时效性，取值 `现行有效` / `失效` / `已被修改` / `部分失效` / `尚未生效`（数组）
  - `effect1`：一级效力级别，取值 `法律` / `行政法规` / `部门规章` / `司法解释` / `地方性法规` / `地方政府规章` 等（数组）
  - `law_start` / `law_end`：实施日期范围（YYYY-MM-DD）
- **返回**：`extra.fatiao`，每条为法条内容及所属法规信息（非整部法规全文）；需全文再调详情接口。

### 2. yuandian_rh_fg_search（法规列表精确检索）
- **用途**：按名称 / 部门 / 日期 / 效力级别检索法规清单。
- **选填**：`keyword`、`fgmc`（法规名称，空格拆分后全命中）、`sxx`、`dy`（地域）、`xljb_1`（效力级别）、`fbbm`（发布部门）、`fbrq_start/end`（发布日期）、`ssrq_start/end`（实施日期）、`top_k`（默认 10，最大 50）。
- **返回**：法规列表，`content` 仅关键词命中高亮片段；全文需调详情。

### 3. yuandian_rh_fg_detail（法规详情·全文）
- **用途**：获取法规原文全文、时效性、发布 / 实施日期、发布部门、附件。
- **必填其一**：`id`（详情 ID）或 `fgmc`（法规名称，id 为空时必填）；可传 `refer_date` 定位当时生效版本。

### 4. yuandian_rh_ft_search（法条级检索，keyword 必填）
- **用途**：按关键词检索具体法条，支持按所属法规、效力级别、时效性、地域、日期过滤。
- **必填**：`keyword`；选填 `fgmc`、`xljb_1`、`sxx`、`dy`、`fbbm`、日期范围、`top_k`。

### 5. yuandian_rh_ft_detail（单条法条详情）
- **用途**：定位具体条文内容、条号、所属法规、时效性、日期。
- **必填其一**：`id`，或 `fgmc` + `ftnum`；可传 `refer_date`。

### 5. 案例类检索（案例库补检 / 核验，2026-08-29 细化）
- **`yuandian_case_vector_search`**（案例语义检索）
  - **必填**：`query`（自然语言，如"以不正当方式获取其他经营者合法持有的数据构成不正当竞争"）。
  - **常用 `wenshu_filter` 字段**：
    - `source`：权威案例来源筛选，取值 `指导性案例` / `典型案例` / `参考案例` / `公报案例` / `解纷案例` / `参阅案例` / `刑事参考案例` / `检指导案例`（数组，或关系）
    - `dianxing`：`true` 时仅检权威案例库；默认 `false`（普通 + 权威）
    - `wenshu_type`：案件类别（刑事案件 / 民事案件 / 行政案件 / 执行案件 等）
    - `ay`（案由，数组）、`fayuan`（法院，数组）、`cj`（法院层级：基层/中级/高级/最高）、`xzqh_p`（省份）、`ja_start` / `ja_end`（结案日期范围）
  - `return_num`：默认 45，建议 5—10。
- **`yuandian_rh_case_details`**：案例详情，传 `id` 或案号，获取结构化全文（关键词 / 裁判要点 / 相关法条 / 基本案情 / 裁判理由 / 裁判结果）。
- **核验要点**：案例库中"经华宇元典权威案例库核验"即通过此类工具执行；核验时至少比对**案号、审理法院、裁判日期、裁判要点**四项，与官网原文不一致的以官网为准。正式引用前须以官方原文复核。

> **证券行业专项**：`yuandian_law_vector_zq_search`（参数同 `law_vector_search`，聚焦证券合规）。

## 三、补充内容标注规范

每条外部补充内容须包含：
- 前缀：`【外部补充·需复核】`
- 来源：数据库（yuandian-mcp，附法规 ID / URL）或 网站（机构全称 + 具体 URL）
- 检索时点：YYYY-MM-DD
- 性质标注：官方原文事实 / AI 归纳观点（后者须人工复核）
- 正式引用前：以官方原文 + 华宇元典核验交叉确认，不臆造、不遗漏时效变化。

## 四、可选持久化

对高频、权威且状态稳定的缺失规范，将核验结果写入：
- `references/法规体系速查明细.md` 对应层级（法律 / 行政法规 / 部门规章 / 司法解释），行末注明「【外部补充·YYYY-MM-DD·来源】」；
- 或新建 `references/外部补充_*.md` 专题文件。

避免对同一规范重复检索。
