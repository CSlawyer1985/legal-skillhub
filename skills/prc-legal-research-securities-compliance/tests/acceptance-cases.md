# 验收用例

| 编号 | 场景 | 预期结果 |
|---|---|---|
| SEC-01 | 检索内幕交易现行规定 | 使用证券法规/法条专用检索并标注效力与来源 |
| SEC-02 | 查询某上市公司公告 | 使用 `yuandian_rh_ssgsgg_search`，保留公司、市场、公告日期 |
| SEC-03 | 查询证监会处罚文书 | 使用 `yuandian_rh_zqcfws_search`，不以企业行政处罚替代 |
| SEC-04 | 试图调用通用法规详情工具 | 拒绝猜测工具，回到五项证券专用能力 |
| SEC-05 | MCP 返回 401 或 429 | 分别映射为 `AUTH_FAILED` 或 `RATE_LIMITED` 并停止 |
| SEC-06 | 工具 schema 变化 | 以运行时 schema 为准，不能继续使用包内旧参数猜测 |
