# CNIPA 免费源接入指引（详细版）

> 本 skill 推荐优先用官方免费源做交叉与复核，全程无需付费。本文件供用户/代理自行核验时参考。

## 一、三个全免费官方源

1. **商标网上查询系统**（wcjs.sbj.cnipa.gov.cn）
   - 注册登录即用，5 大查询模块（近似查询 / 综合查询 / 状态查询 / 公告查询 / 商品服务项目查询），数据覆盖 1980 年至今。
   - **日常复核主入口**，免费、无需数字证书。
   - 适用：输入检索词表的词，按「相同/类似商品（类似群）」范围核验近似商标。

2. **知识产权数据资源公共服务系统**（ggfw.cnipa.gov.cn，原数据资源管理系统）
   - 自然人/企事业单位免费注册，开放专利/商标/地标等全量数据包下载。
   - **批量拉取首选**，最易上手。

3. **商标数据开放系统**（sbj.cnipa.gov.cn）
   - 需先在线申请「商标数字证书」（约 1 个月发放）才能批量下载 8 张表 60 项全量数据。
   - 适合程序化/批量拉取。

## 二、结构化 API（进阶）

- 知识产权出版社 open.cnipr.com 提供 `tmd0`（商标详情）/ `tmd1`（商标下载）接口。
- 需 `client_id + openid + access_token` 认证，适合 B 方案程序化调用（见 V2 迭代规划）。

## 三、使用建议

- 上架版 skill 保持纯文本、不引外部密钥；详细分步教程见单独文档。
- 预检结论以多源交叉为参考，**最终裁定以官方源（尤其 wcjs 商标网上查询）为准**。
- 正式申报前，务必委托备案商标代理机构做官方近似查询（商标网自助查询不等同代理机构的专业检索口径）。
