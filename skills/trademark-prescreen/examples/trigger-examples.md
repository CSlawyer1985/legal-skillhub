# 触发示例

以下任意一句话均可触发 `trademark-prescreen` 技能（在支持该技能的 AI 助手对话中直接说）：

1. **单标预检**
   > 我想把「青松」注册成商标，公司叫 XX 科技，做智能家居的，帮我看看能不能注册、注册率多少。

2. **多标 + 拼音**
   > 查一下「青松」和「QINGSONG」这两个商标能不能注册，我是 XX 智能科技有限公司，经营范围有软件开发、广告设计、互联网销售。

3. **只问类别布局**
   > 我们公司做 SaaS 和品牌全案设计，适合注册哪些商标类别？

4. **要完整报告**
   > 给我出一份「星河 / XINGHE」的商标可行性分析报告，申请人星河文化传媒。

5. **带图形组合标**
   > 打算用「鹿鸣 + 鹿头图形」组合标注册，做茶饮连锁，评估下注册方案。

---

## 技能会向你追问的信息（若缺失）

- 标样（文字 / 拼音 / 英文 / 是否含图形）
- 申请人公司全名（用于查名下是否已有在先申请）
- 经营范围 / 业务（优先营业执照原文；区分自有业务与替甲方做的项目）

## 产出

一份 HTML 分析报告，含：多源交叉验证表、在先商标全景、尼斯类别映射、逐类注册率、三套注册方案（确权 / 全覆盖 / 护城河）、风险与行动建议、免责声明。
