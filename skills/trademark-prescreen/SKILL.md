# 商标注册可行性预检分析工作流

## 快速上手（3 步出报告 · 首次用先看这）

1. **给信息**：标样（注册什么词/拼音/图形）+ 公司全称 + 经营范围（最好营业执照原文）。
2. **出报告**：技能自动跨 ≥3 个公开商标库交叉检索（中国商标网 / 权大师 / 标库网 / 企查查），产出含「总判定 GO/CAUTION/NO-GO + 注册率 + 多套方案 + 官方核验检索词表」的 HTML 报告。
3. **复核 + 接洽**：拿报告的「官方核验检索词表」去中国商标网自查；如需找近似标注册人接洽，报告后可一键生成联系方式清单（opt-in，见步骤 7）。

> 详细数据源、降级策略、尼斯映射、报告模板、FAQ、案例均在 `references/` 下，执行到对应步骤时按 📎 提示 `Read` 加载（渐进式披露），确保不丢规则。

**一句话交付**：给定标样（中文/拼音/英文/图形）+ 经营范围，产出含「在先全景 → 类别映射 → 逐类注册率 → GO/CAUTION/NO-GO 总判定 → 多套方案 → 行动建议 → 官方核验检索词表」的 HTML 报告。

> ⚠️ 本 skill 产出的是**预检报告，非法律意见**。正式申报前必须以中国商标网 sbj.cnipa.gov.cn 复核，并委托备案商标代理机构做官方近似查询。每份报告必须带此免责声明。

## 适用场景（满足任一即触发）
- 想把某词/拼音/图形注册成商标，问"能不能注册""注册率多高"
- 问"我这生意适合注册哪些商标类别"
- 给了经营范围，要做商标类别布局
- 要一份商标分析报告 / 可行性评估

## 前置信息（缺则先问）
1. **标样**：具体文字/拼音/英文/是否含图形（组合标）。可多个。
2. **申请人主体**：公司全名（核实是否已有自己名下在先申请）。
3. **经营范围/业务**：优先营业执照原文。**关键区分**：企业"自有业务"才映射类别；替甲方做的项目服务不算自有业务，不据此选类。

> 信息不足时：列「已知/未知/假设」，基于假设给**区间判断**并标置信度 + 给「建议补充清单」。一次追问 ≤3 个关键问题。

## 执行流程

### 步骤 1 — 查现成 skill / 数据源
先跑 `find-skills`（商标/尼斯分类/知识产权关键词）确认无更专用 skill。无专用商标 MCP 时，用 WebSearch + WebFetch 检索公开库（阿里云商标、标库网、企查查/天眼查、权大师等）。官方复核入口：**中国商标网 sbj.cnipa.gov.cn**（商标网上查询 → 近似/综合查询）。

### 步骤 2 — 在先商标全景检索（每个标样都做 · 多源交叉）
检索维度：① 文字/拼音**本身**在 1–45 类的状态/注册号/申请人；② **同音/近似**风险词；③ **同名企业**是否已抢注；④ 申请人自己名下是否已有在先申请。
- 关键词模板：`<标样> 商标 第X类 注册 注册号`、`<标样> <近似词> 商标 注册 申请人`。
- **必须跨 ≥3 源交叉**（权大师+标库网+企查查/天眼查+中国商标网；高冲突类补社标网+路标网）。结果标注：≥2 独立源印证=高可信障碍；仅 1 源=待官方复核。
- 网络可用：可补公开信息，但仍标"待官方核验"，**不得**说成"官方已确认无冲突"。网络不可用：做结构分析并写明"官方近似检索尚未执行"，结论上限 CAUTION。
- 📎 `Read references/data-sources.md`（数据源 4 层 + 四级降级策略 + 错误场景提示语 + 尼斯映射表 + 类目锚点 + 音形义三维五级评级）

### 步骤 3 — 经营范围 → 尼斯类别映射
逐条映射成表，**只映射企业自有业务**。📎 映射表与类目锚点见 `references/data-sources.md` 第三节。

### 步骤 4 — 逐类注册率评估
依据：有无相同/近似在先商标（相同商品有在先相同标=直接障碍，注册率骤降）；标样显著性（通用/褒义词弱，建议组合标+20–30pp）；同音近似+同名企业引证。经验分档：无障碍且显著 80–90% / 中等冲突 55–70% / 相同商品有在先相同标 20–45%（参考，非承诺）。

### 步骤 4.5 — 合规红线 / 盲期 / 撤三 / 监测
- **第10条 绝对禁用**：外国国家名/国旗/国徽、国际组织名、"红十字"、县级以上地名（如"青岛"作主体）、欺骗性、不良影响等 → 直接不可注册。
- **第11条 缺乏显著性**：通用词/褒义词（"青松""星河"）纯文字大概率驳，须改组合标（加独创图形/英文）破显著性。
- **第12条 三维标志**：仅由商品性质/技术效果/实质性价值形状禁用。
- **盲期**：申请到录入库约 1–4 个月不公开，报告必须明示"无在先≠绝对安全"，建议申报后 1 年期监测。
- **撤三**：连续三年不使用可被撤销，防御类要有使用证据/合理理由。
- **监测清单**：初审公告 3 月内提异议；定期查状态防撤三（留合同/发票/包装/广告）；满 10 年提前 1 年续展；发现仿冒依第57条维权。

### 步骤 4.8 — 总判定 GO / CAUTION / NO-GO + 置信度
| 判定 | 触发条件 | 对用户说法 |
|---|---|---|
| **GO** | 核心类无障碍且显著性强，盲期外无高可信冲突 | 「值得推进，但请先完成官方近似检索」 |
| **CAUTION** | 明显障碍或不确定（近似/显著性弱/盲期/跨类抢注） | 「可改创组合标再推，或接受较高驳回风险」 |
| **NO-GO** | 命中第10/11条、傍名牌、与驰名显著部分高度近似 | 「不建议以当前方案提交，建议放弃或大幅改创」 |

**置信度**（必带）：高=官方源交叉+主体核实+范围明确；中=多源完成但未官方核验/有假设；低=只有名字无商品服务，上限 CAUTION。
> 诚信底线：无实时官方结果时**禁止**编造注册号/"检索通过"，须标「待核验/推断/参考」；不作保过承诺；不冒充律师或官方。

### 步骤 4.9 — 官方核验检索词表
对每个拟定商标输出：① 全称 ② 去通用词后的显著部分 ③ 谐音/近音 ④ 拼音连续与分写 ⑤ 英文/中文对应 ⑥ 常见前后缀变体。提示用户去官方渠道按"相同/类似商品（类似群）"核验。无官方结果时近似维度最高 CAUTION（极端傍名牌可 NO-GO）。

### 步骤 5 — 多套注册方案
- **A 精准确权**（最省）：只报无障碍核心类，防同名企业抢先。
- **B 主营全覆盖**（默认推荐）：A + 组合标攻主营高价值类 + 延伸类。
- **C 品牌护城河**（防御）：B + 防御性注册 + 图形单独注册 + 马德里预留。
贯穿策略：组合标破显著性、申请时序（先无障碍→中等→高冲突）、一标一类分开报、驳回 15 天内复审预案、无障碍类尽早卡位。

### 步骤 6 — 生成 HTML 报告并 present_files
**透明度强制项**：报告「数据来源与交叉方法说明」节须以 callout 给**本次检索源状态摘要**——逐源 ✅成功 / ⚠️降级（标备用源）/ ❌失败（标原因），并写明**置信度边界**（哪些类 ≥2 源核实、哪些单源/待复核、盲期未覆盖区间）。
📎 `Read references/report-template.md`（14 章固定结构 + 摘要样例 + 样式约定 + 费用周期口径）

### 步骤 7 — 可选：近似引证注册人联系方式清单（opt-in · V1.2.3 新增）
报告 present 后主动提示（默认不生成，需确认）：「💡 是否需要生成【已注册类似商标的注册人及联系方式清单】？仅含本案近似引证的已注册商标注册人，供授权/转让/异议/无效宣告/维权等正式接洽。确认后生成。」
确认后强制护栏（违反即踩 PIPL 数据最小化 + 平台 ToS 红线）：① **范围限定**仅本案近似引证，不做全网扫描；② **三态分离**严格区分「已注册/在审/字号使用」；③ **来源标注**电话来自公开工商库（商标网字段不含电话），标"以最新工商登记为准"；④ **数据最小化（PIPL 第6条）**优先企业座机/官网/企业邮箱，个人手机谨慎；⑤ **用途与免责**仅限正式法律商业接洽，禁骚扰/冒用/买卖；⑥ **获取方式**引导国家企业信用信息公示系统，不自动爬受限商业库；⑦ **资质边界**委托备案代理机构（《商标法》第19条）。

## 能力边界与行业强监管提醒
- 能力边界：官方库实时检索≠商标局系统（给检索词+核验步骤）；不提供法律意见书；精确官费/周期只给区间；海外只给路径（逐国 vs 马德里）建议当地代理；图形细比对需用户图样。
- **行业强监管**：药品/医疗器械/医美/食品/金融/教育等，商标核准 ≠ 业务可合法开展，还需并行办理行业许可（器械注册证/食品经营许可/金融牌照/办学许可），报告须提示。

## 反模式清单（出现即返工）
| 反模式 | 为什么有害 | 改成 |
|---|---|---|
| 编造注册号或「库中无冲突」 | 虚假确定性，误导提交 | 给检索词 + 待核验 + 结构风险 |
| 「包过 / 百分百下证」 | 违法承诺感、不可控 | 风险分级 + 降低风险方案 |
| 脱离商品谈全国都不能用 | 商标权利有指定范围 | 绑定类群谈冲突 |
| 教恶意抢注、傍名牌 | 违法与商业自杀 | 劝阻并说明后果 |
| 教伪造使用/销售证据 | 违法 | 只列合法证据类型 |
| 只贴法条无动作 | 用户无法执行 | 每段结论配下一步 |
| 把商标=公司名=域名=版权 | 权利体系不同 | 分项说明还要做什么 |
| 随便报 35 类「包打天下」 | 保护落空 | 按真实商品映射核心类 |
| 海外国家「也能过」空口判断 | 法域不同 | 只给路径，建议当地代理 |
| 忽视药品/医疗/金融强监管 | 商标过了业务仍不能做 | 并行提示行业许可 |
| 同名企业混淆当成一家 | 主体搞错全盘错 | 先核实申请人到底是谁 |
| 项目服务 ≠ 自有业务 | 错选行业类别 | 不据此推该行业类别 |
| 通用词显著性弱仍推纯文字 | 大概率被第11条驳 | 默认建议组合标破显著性 |
| 同音字未查在先 | 拼音标踩雷 | 拼音标查同音中文词 |
| 已有自申请重复交费 | 浪费官费 | 名下已申请只跟进下证 |
| 近似评分当精确结论 | 误导决策 | 标「启发式参考」，以官方为准 |
| 无差别罗列/自动爬取法人手机营销 | 违反 PIPL 数据最小化 + 平台 ToS | 仅 opt-in + 限定近似引证 + 用途声明 + 引导官方公示系统自查 |
