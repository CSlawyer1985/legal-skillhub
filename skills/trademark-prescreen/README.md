# trademark-prescreen · 商标注册可行性预检

> 中国商标（CNIPA / 尼斯分类）注册前的可行性预检与分析技能。一句话触发，自动产出含在先商标全景、类别映射、逐类注册率、GO/CAUTION/NO-GO 总判定与多套注册方案的 HTML 报告。

**版本**：v1.3.0 ｜ **分类**：法律·知识产权 ｜ **许可**：MIT

## 这个技能解决什么

你想把某个词 / 拼音 / 图形注册成商标，但在正式花官费（约 270 元/类）申报前，需要先搞清楚：

- 这个标在哪些类别**已经被别人注册了**（会直接驳回你）？
- 你公司真实经营范围，应该布局哪些尼斯分类？
- 每个类别注册**成功率**大概多少？
- 该用纯文字标还是**组合标**提升通过率？
- 给出几套**不同预算 / 风险偏好**的注册方案。

本技能基于公开商标数据库（中国商标网 + 权大师 + 标库网 + 企查查/天眼查 + 通用搜索）做**多源交叉预检**，把上述结论结构化输出，帮你"先想清楚再花钱"。

## 你需要提供（缺则会被追问，一次 ≤3 个关键问题）

1. **标样**：待注册的文字 / 拼音 / 英文，是否含图形（组合标）。可多个。
2. **申请人主体**：公司全名（用于核实名下是否已有在先申请，避免重复交费）。
3. **经营范围 / 业务**：优先给营业执照原文的经营范围。
   - ⚠️ 关键区分：**企业自有业务**才映射类别；替甲方做的项目服务（如给客户开发的某设备质保系统）**不算自有业务，不据此选类**。

## 输出报告结构（固定 14 章）

0. 总判定 GO/CAUTION/NO-GO + 置信度（首页置顶）
1. 数据来源与多源交叉方法说明
2. 多源交叉验证表（各冲突标的来源命中与可信度）
3. 各标样在先商标全景（按类别）
4. 同音 / 近似风险
5. 经营范围 → 尼斯类别映射表
6. 推荐注册大类与注册率评估（进度条）
7. 近似度三维评估（音/形/义）与五级风险评级
8. 注册方案（三选一对比 + 策略要点）
9. 注册前合规红线与盲期提示
10. 官方核验检索词表
11. 综合风险评估
12. 行动建议（分阶段）
13. 注册后监测清单（公告异议 / 撤三防御 / 续展提醒）
14. 能力边界声明 + 类目释义 + CNIPA 免费源指引 + 免责声明

## 数据来源（多源交叉 · 方案 A，零成本）

| 层 | 源 | 作用 |
|---|---|---|
| 1 官方金标准 | 中国商标网 sbj.cnipa.gov.cn / wcjs / ggfw | 最终裁定基准（全免费） |
| 2 主力商业库 | 权大师 / 标库网 / 社标网 / 路标网 | 免费检索、近似比对 |
| 3 申请人关联 | 企查查 / 天眼查 | 核实申请人主体、防同名企业混淆 |
| 4 兜底 | WebSearch | 补查零散结果 |

交叉原则：同一冲突标被 ≥2 个独立源印证 → 高可信障碍；仅 1 源且无官方印证 → 待官方复核。

> 进阶（方案 B/C）：申请权大师官方 API key 走 MCP 结构化检索，结果更精准可复现。

## 常见坑（技能已内置检查，详见 SKILL.md 反模式清单）

1. **同名企业混淆**：多家同名公司是不同的主体，别当成一家。
2. **项目服务 ≠ 自有业务**：替甲方做的方案，不能据此推该行业类别。
3. **通用词显著性弱**：褒义/通用词纯文字大概率被《商标法》第 11 条驳回，默认建议组合标。
4. **同音字引证**：拼音标要查同音中文词的在先注册。
5. **已有自申请勿重复**：名下已申请的类别只需跟进下证。

## 能力边界

- 不提供法律意见书，只做决策准备与科普级分析。
- 官方库实时检索不可直接等同商标局系统，结论以官方核验为准。
- 海外精确可注册性超出默认深度，只给路径提示 + 建议当地代理。
- 药品/医疗/金融/食品等强监管行业，商标核准 ≠ 业务可合法开展，须并行行业许可。

## ⚠️ 免责声明

本技能产出的是**预检报告，非法律意见**。中国大陆商标审查以国家知识产权局商标局裁定为准。正式申报前**必须**以中国商标网（sbj.cnipa.gov.cn）复核，并委托备案商标代理机构做官方近似查询。
