# Reg. 64 科索沃——判例地图

本文件梳理 UNMIK 及 EULEX 继承框架下第64号条例小组（Regulation 64 Panels）的制度时期、实体覆盖范围和案件类型学。本文旨在作为分析导向工具，**并非**权威案例索引。务必对照权威档案核实具体案例引用（`references/authoritative-sources.md`）。

## 制度时期

### 阶段0——UNMIK 前崩溃期（1999年6月——2000年初）

- 联合国安理会第1244号决议于1999年6月10日通过；UNMIK 设立
- 科索沃司法体系大体崩溃：多数科索沃塞族法官和检察官离开；科索沃阿族司法体系在前南斯拉夫联盟共和国管理下实际停摆
- 1999年7月25日 UNMIK 第1999/1号条例将全权授予秘书长特别代表（SRSG）；保留1989年3月22日时有效的法律（即科索沃自治被撤销前），作为适用法律，受 UNMIK 条例约束
- 国家级刑事司法活动有限；重组后的科索沃阿族司法体系早期起诉塞族时存在严重偏见关切

### 阶段1——特设国际法官（2000年2月——2000年12月）

- **2000年2月米特罗维察族际暴力事件**——催化剂事件
- UNMIK 依 SRSG 特设授权，**为每个地区法院任命一名国际法官和一名国际检察官**
- **2000年2月15日 UNMIK 第2000/6号条例**正式确立了任命和撤换框架
- 国际法官与科索沃阿族法官在普通审判庭并列审理——处于**少数**地位；可能被投票否决
- 效果有限：在族裔色彩浓厚的案件中，国际声音被科索沃阿族法官否决
- Michael E. Hartmann 被任命为首位国际检察官（2000年2月——2003年初）；其报告记录了 Reg. 64 旨在填补的制度缺口

### 阶段2——Reg. 64 小组运行（2000年12月——2008年2月）

- **2000年12月15日 UNMIK 第2000/64号条例**——实施文书
- 初始期限12个月；后经修正延长
- 逐案指定：检察官/辩护方/司法部自行申请 → 司法部建议 → SRSG 批准 → 司法部指定
- **审判庭组成：3名职业法官，至少2名国际法官（即国际法官占多数）**——取代普通5人职业/非职业混合审判庭
- UNMIK 第2001/2号条例扩大了国际检察官的权力，可**复活弃案**（处理选择性起诉中的族裔偏见）
- KWECC（科索沃战争和族裔犯罪法院）于**2000年秋放弃**，转而采用 Reg. 64 机制——制度选择为**融合而非分立**
- 2003年7月6日——通过《临时刑法典》和《临时刑事诉讼法典》（UNMIK 第2003/25和2003/26号条例），取代1976年《南斯拉夫联邦刑法典》；2004年4月6日生效
- 2001年5月15日——《科索沃临时自治宪法框架》（UNMIK 第2001/9号条例）设立过渡机构，但**保留了 UNMIK 的保留权力**，包括国际司法机构

### 阶段3——UNMIK 向 EULEX 过渡（2008年12月——持续）

- **2008年2月17日**——科索沃议会宣布独立
- **2008年6月15日**——《科索沃共和国宪法》生效
- **2008年12月9日**——EULEX 依其执行授权（2008年2月4日联合行动 2008/124/CFSP）实现全面行动能力
- **2008年3月13日第2008/03-L053号法律**——科索沃共和国关于 EULEX 法官和检察官管辖权、案件甄选和案件分配的法规——独立后的继承框架
- EULEX 法官继续以调整后的安排参与科索沃法院审判庭；逐步向完全国家司法体系过渡，最终以 EULEX 转型为以监测/指导为重点的“强化特派团”（2018年后）并最终逐步退出而告终

## Reg. 64 小组的实体覆盖范围

### 战争罪（1998-1999年冲突）

- 1998-1999年科索沃战争期间实施的战争罪：
  - 南斯拉夫联盟共和国/塞尔维亚部队（武装部队、MUP、准军事部队）
  - 科索沃解放军（KLA）——尽管结构性限制和证人恐吓严重制约了这一类别
- 分类法律依据：1976年《南斯拉夫联邦刑法典》战争罪条款（第十六章——反人类和国际法罪行），其后自2004年4月6日起为《科索沃临时刑法典》
- **重要方法论说明：**针对 KLA 关联被告的案件中，证人恐吓和难以获得合作的问题在学术和非政府组织文献（USIP、OSCE、ICTJ、人权观察报告）中有广泛记载。这一结构性限制是最终于**2015年设立科索沃特别分庭（KSC）**作为处理 KLA 罪行的独立、异地法庭的深层原因——KSC 在制度上区别于 Reg. 64 小组，**不在本技能涵盖范围内**

### 族裔间犯罪（战后，主要为1999-2004年）

- 战后初期针对科索沃塞族、罗姆族、阿什卡利族、埃及族、戈拉尼族及其他少数族裔实施的犯罪
- **2004年3月族裔骚乱**——尤为重大：数十座塞尔维亚东正教教堂和财产被毁、约30人死亡、数千人流离失所；此后依 Reg. 64 指定进行了重大起诉努力
- 《临时刑法典》之前的适用依赖《南斯拉夫联邦刑法典》条款

### 有组织犯罪与腐败（选择性）

- 尽管 Reg. 64 机制主要为族裔犯罪设计，也被用于存在公正性关切的严重有组织犯罪和腐败案件
- 在制度理据中较次要，但 UNMIK 和 OSCE 报告中有记载

### 恐怖主义案件

- 有限但存在于案件记录中；尤其涉及边境/前沿地带事项

## 案件类型学——分析类别

- **复活案件**——被科索沃检察官放弃、由国际检察官依 UNMIK 第2001/2号条例重启的案件
- **变更审判地案件**——依第2000/64号条例在地区间移送、以处理证人恐吓或公正性关切的案件
- **国家上诉审查下的混合审判庭**——一审 Reg. 64 小组，可上诉至科索沃最高法院（最高法院本身可被 Reg. 64 指定）
- **重审案件**——尤其在欧洲人权法院审查后或程序挑战后
- **共同起诉书**——不同族裔社区的多个被告

## 实质性法理贡献

Reg. 64 小组的法理贡献分散于各案判决而非系统化，但以下主题在学术文献中反复出现（Cerone、Reidy、Hartmann、Strohmeyer、Cohen、OSCE 驻科索沃特派团、EULEX 法律官员反思）：

- **冲突后过渡中的适用法律**——1989年前南斯拉夫法律、UNMIK 条例及（2004年起）《临时刑法典》的互动；连续性和不溯及既往原则（相关《欧洲人权公约》第7条关切与波黑战争罪分庭出现的关切类似——见 `wcc-bih` 技能）
- **以国际标准为参照的国内法指挥责任**——将 ICTY 判例有选择地引入国家层面程序
- **混合语言程序中的程序保护**——阿尔巴尼亚语、塞尔维亚语、英语；口译标准
- **持续族际紧张地区的证人保护和安保**——揭示了制度局限
- **融合模式本身**——Reg. 64 作为“渐进式混合”（见 Romano/Nouwen/Stahn 分类法）的案例研究，展示了嵌入普通国家法院而非另行设立的司法职能的可能性与局限

## 比较定位（分析性，非管辖权）

- **与东帝汶特别分庭（SPSC）相比**——两者均在联合国过渡管理下运作；SPSC 是帝力地区法院内的独立分庭结构，Reg. 64 是既有地区法院内的小组指定；两者均面临高级指挥官的结构性有罪不罚问题
- **与波黑战争罪分庭（WCC-BiH）相比**——WCC-BiH 于2009-2012年实现完全国家化；Reg. 64 在同一时期向 EULEX 过渡而非完全国家化
- **与 KSC（2015年至今）相比**——KSC 根本不同：设于海牙的独立异地法庭，处理特定子集的 KLA 相关指控；**不在本技能涵盖范围内**
- **与 ICTY/IRMCT 余留职能相比**——ICTY 处理更广泛的南斯拉夫冲突；Reg. 64 处理科索沃特有的国家层面案件；偶有重叠时，ICTY 判例为 Reg. 64 裁决提供参考，但两程序在制度上分离

## 档案状态——实务影响

Reg. 64 小组判例的档案状态是**碎片化的**：

- **UNMIK 遗留档案**（unmik.unmissions.org）——条例和秘书长特别代表级文件的主要存储库；对个案卷宗覆盖较不全
- **EULEX 档案**——对2008年后续案件的覆盖为部分性
- **法律工具数据库**（legal-tools.org）——选择性覆盖
- **OSCE 驻科索沃特派团报告**——运行期间广泛的庭审监测报告
- **USIP/学术专著**——逐案分析（Hartmann、Cerone、Reidy、Cohen）
- **人权观察、大赦国际、ICTJ**——精选高关注案件

**实务影响：**核实特定 Reg. 64 案件时，预期需要查阅**多个来源**以确认引用；不要指望有类似国际刑事法院 CourtRecords 或 ICTY 记录数据库的单一权威案例索引。在输出中明确标注核实级别（存在性/内容/段落）。
