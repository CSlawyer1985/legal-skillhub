# 刑事辩护全流程办案策略 V7.0

**作者：Z律同行 | 版本：V7.0 | 适用：AI Agent执行刑辩办案辅助**

⚠️ **前置指令**：每次输出先脱敏（姓名→「当事人」/「嫌疑人A」，案号→「[信息脱敏]」），开头标注「本分析为律师内部办案参考，不得向当事人、家属泄露，不得作为案件结果承诺」。**案卷材料属国家秘密，严禁上传**。

**无罪推定贯穿始终**——控方承担证明责任，标准"排除合理怀疑"，辩方只需制造合理怀疑。

## Part 2: 程序实体递进分析引擎

### 2.1 程序轴扫描

#### 2.1.1 公安侦查程序深度审查

| 审查维度 | 法律依据 | 审查要点 | 违法后果 |
|---------|---------|---------|---------|
| **立案标准** | 刑诉法第112条 | "以刑代民"？是否符合"有犯罪事实+需要追究刑事责任"？ | →申请撤案/不起诉 |
| **搜查令状** | 刑诉法第138-140条 | 持证？无证搜查是否"执行逮捕+紧急"？ | →物证书证资格存疑 |
| **辨认程序** | 公安程序规定第258-264条 | 混杂量(照片≥10/人≥7/物≥5)、主持人(≥2侦查员)、见证人(非公安)、无暗示 | 违反→不得作为定案根据 |
| **讯问程序** | 刑诉法第118-123条 | 拘留后24h内/每次≤12h/未成年人合适成年人在场/权利告知 | 违法→供述可排 |
| **技术侦查** | 刑诉法第150-154条 | 设区市级审批？期限3月+可延？证据转化程序？ | 未审批→不能作证据 |
| **电子数据** | 电子数据规定(2016) | 封存原始介质？哈希值？录像？提取笔录？ | 完整性不能保证→排除 |
| **冻结/查封/扣押** | 刑诉法第141-145条 | 与案有关？超额？案外人财产？存款冻结6月+可延 | 超额/无关→申请解除 |
| **侦查实验** | 刑诉法第135条 | 条件相似？录音录像？见证人？ | 不相似→不可靠 |
| **情况说明** | 无法定依据 | 替代侦查人员出庭？ | 非法定证据→申请出庭作证 |

#### 2.1.2 检察机关程序利用

| 策略 | 法律依据 | 操作要点 |
|------|---------|---------|
| 检察监督申请 | 刑诉法第8条/第57条 | 发现侦查违法→申请同级检察院监督(侦查/起诉/审判阶段均可) |
| 退补利用 | 刑诉法第175条 | 退补期间(每次1月/最多2次)：①同步收集有利证据 ②申请变更强制措施 ③推动不起诉 |
| 撤回起诉应对 | 刑诉法解释第296条 | 撤回起诉≠无罪→争取不起诉/撤案 |
| 变更/追加起诉 | 刑诉法解释第289条 | 庭审中变更→申请延期+重新阅卷 |
| 量刑协商时机 | 认罪认罚指导意见 | 侦查阶段减让≈30% / 审查起诉≈20% / 审判≈10%以内 |

#### 2.1.3 排非线索扫描

| 证据类型 | 绝对排除/细化规则 | 发现后操作 |
|---------|-----------------|-----------|
| 言词证据 | 刑讯逼供/暴力威胁/非法拘禁；**重复性供述**(严格排非第5条—更换侦查员+调查核实+告知权利+自愿→可不排否则排除)；**疲劳审讯**(连续>12h/未保证休息)；**监察委排非**(监察法第40条+第33条—移送后立即核对+调取留置记录)；**未成年人**无合适成年人→排除 | 调录音录像+体检记录+申请排非 |
| 物证/书证 | 无证搜查无补正/合理解释→排除 | 审查补正可能性 |
| 鉴定意见 | 8种不得定案情形(无资质/检材不明或污染/对象不一致/程序违规/方法错误/依据不充分/应回避未回避等) | 申请重新鉴定或专家出庭 |
| 电子数据 | 未封存/未哈希/未录像→排除 | 审查完整性 |
| 情况说明 | 无法定证据形式→申请侦查人员出庭替代 | 庭前申请+发问提纲 |

#### 2.1.4 追诉时效审查（V6新增）

| 法定最高刑 | 追诉期限 | 起算 |
|-----------|---------|------|
| 不满5年 | 5年 | 犯罪之日起算 |
| 5年以上不满10年 | 10年 | 同前 |
| 10年以上 | 15年 | 同前 |
| 无期/死刑 | 20年（20年后须最高检核准） | 同前 |

⚠️ 时效中断：立案侦查+逃避侦查→不受限制。时效延长：被害人在追诉期内控告→应立案未立案→不受限制。（刑法第87-89条）

### 2.2 实体轴扫描

**注意**：程序轴发现排非线索→实体轴需分别在"原证据体系"和"假设排非后"两套状态下分析。

#### 2.2.1 主观性审查（第一序位）

**第一步：识别主观要件类型**

| 类型 | 审查焦点 | 适用罪名群 |
|------|---------|-----------|
| 故意犯 | 「明知」+「希望/放任」 | 暴力/职务/毒品/其他 |
| 目的犯 | 「非法占有目的」/「营利目的」 | 诈骗/集资/合同诈骗 |
| 明知型 | 「明知利用信息网络犯罪」/「明知是犯罪所得」 | 帮信/掩隐 |
| 过失犯 | 「应预见而未预见」/「已预见但轻信避免」 | 交通肇事等 |

**第二步：间接故意vs过于自信过失判断矩阵**

| 要素 | 间接故意（放任） | 过于自信过失（轻信避免） |
|------|----------------|------------------------|
| 意志因素 | 听之任之、漠不关心 | 轻信可避免 |
| 关键证据 | 无避免措施/无求助/无所谓/有类似前科 | 有避免措施(虽无效)/有求助报警/事后积极补救/有合理信赖 |
| 区分口诀 | "发生了就发生了" | "我认为不会发生" |
| 辩护方向 | 证明"有避免措施"→可能转过失→非故意犯罪 | — |

**第三步：各罪名群推定规则速查**

**(a) 帮信罪——两高司法解释第11条 7种推定**

| # | 推定情形 | 可推翻性 | 反驳要点 |
|---|---------|:--:|---------|
| 1 | 经监管部门告知仍实施 | 低 | 告知是否"有效送达"+"实质知悉"？ |
| 2 | 接到举报不履行监管义务 | 中 | 是否有监管义务？→岗位/技术范围 |
| 3 | 交易价格/方式异常 | 中-高 | 行业正常价？合理理由？ |
| 4 | 提供专门违法程序/工具 | 低 | 通用合法用途？证明非专门性 |
| 5 | 隐蔽上网/加密通信/销毁数据 | 中 | 合法安全需求？商业保密/隐私保护 |
| 6 | 帮助逃避监管/规避调查 | 低-中 | 常规技术服务？日常性非针对性 |
| 7 | 其他足以认定 | 中 | 要求更严格证明 |

**(b) 掩隐罪推定**

| 推定情形 | 反驳路径 |
|---------|---------|
| 价格明显低于市场 | 行业正常价/合理解释(急于变现) |
| 时间/地点/方式异常 | 商业合理原因 |
| 无正当理由协助转换转移 | 正当商业目的/不知是赃 |
| 隐蔽方式交易 | 行业惯例/隐私保护 |
| 事前通谋 | ⚠️可能转上游共犯(更重) |

**(c) 诈骗罪——非法占有目的四维判断**

| 维度 | 有非法占有目的 | 无 |
|------|--------------|-----|
| 签约前 | 无履约能力+虚构身份/资质 | 有履约能力+真实身份 |
| 签约后 | 无履约/象征性履约 | 实质履约/部分履约 |
| 资金去向 | 挥霍/转移/隐匿/还债 | 用于项目/经营 |
| 事后态度 | 逃匿/失联 | 协商/配合 |

**(d) 毒品——主观明知推定**

| 推定情形 | 反驳 |
|---------|------|
| 高度隐蔽携带/体内藏毒 | 反驳极难——需被利用/被胁迫/被陷害 |
| 虚假身份/地址托运 | 委托人要求/隐私保护？ |
| 检查时丢弃/逃跑 | 因其他原因(恐慌/其他违法)？ |
| 高额不等值报酬 | 正常运输/服务费？ |
| 隐蔽交货/接货 | 约会/私人事务？ |

#### 2.2.4 量刑情节全量扫描

**自首完整规则**（法释〔1998〕8号 + 法发〔2010〕60号）

| # | 到案方式 | 自首？ | 关键判断 |
|---|---------|:--:|---------|
| 1 | 犯罪事实未被发觉时投案 | ✅ | 投案时是否已立案？ |
| 2 | 嫌犯未被发觉时投案 | ✅ | 身份是否已暴露？ |
| 3 | 已发觉但未受讯问/强制措施 | ✅ | "讯问"≠传唤。电话通知→一般视为自动。网上追逃后被动抓获→非自首 |
| 4 | 逃跑后主动投案 | ✅ | 通缉后仍主动 |
| 5 | 正在投案途中被捕获 | ✅ | 需证据(通话/GPS/短信) |
| 6 | 委托他人代为投案 | ✅ | 委托+实际代为 |
| 7 | 信电方式投案 | ✅ | 表明意愿+提供位置 |
| 8 | 形迹可疑被盘问+主动交代 | ✅ | 关键："形迹可疑"vs"有针对性"。已有具体线索锁定→非自动 |
| 9 | 交通肇事后保护+抢救+报警 | ✅ | 限于交通肇事等 |
| 10 | 明知报案在现场等待+未拒捕+如实供述 | ✅ | 三项缺一不可 |
| 11 | 主动报案未逃离 | ✅ | 身份未暴露但关联报案 |
| 12 | 排查阶段主动交代 | ✅ | 与#8区别：已在排查但未确定 |
| 13 | 行政/司法措施期间交代 | ✅ | 因拘留/戒毒中交代刑事犯罪 |
| 14 | 被亲友规劝/陪同 | ✅ | 规劝≠强制，陪同≠扭送 |
| 15 | 亲友代为报案 | ✅(特殊) | 当事人不反对/愿归案 |

**翻供规则树**：
```
投案→如实供述？
  是→翻供→不自首。但一审判决前又恢复如实供述→可认定自首
  否→不自首

如实供述标准：
  供述"主要犯罪事实"(身份+行为+结果)→构成
  仅供述部分→仅对供述部分认定自首
  仅供轻罪隐瞒重罪→不构成

时间：一审判决前(含一审)→可认定；二审才供述→不认定(仅酌定)
监察委阶段→可构成自首(监察法第31条)
```

**立功完整规则**（法发〔2010〕60号）

| 维度 | 规则 |
|------|------|
| 一般vs重大 | 一般≤20%减。重大（无期以上/全省全国影响/重大嫌犯）→20-50%减或免 |
| 对合犯 | 行贿检举受贿→如实供述，非独立立功。**但**检举受贿人**其他**受贿→构成立功 |
| 共犯揭发 | 揭发共犯事实→非立功(如实供述)。揭发共犯**其他**犯罪→构成立功 |
| 线索来源 | 贿买/暴力/胁迫/违规→不认。职务行为→不认。亲友提供(非职务)→可认 |
| 协助抓捕 | 4种情形：①约至指定地点 ②提供藏匿地 ③带路指认 ④提供联系方式→据此抓获 |
| 尚未掌握 | 已上网追逃→已掌握；仅立案未锁定→可能未掌握 |
| 时间 | 到案后→判决/裁定生效前(含二审)均可 |

**其他情节**：

| 情节 | 要点 |
|------|------|
| 从犯 | 地位+作用(次要/辅助) |
| 未遂/中止 | 实行终了/未终了→是否造成损害 |
| 认罪认罚 | 越早减让越大：侦查~30%→审查起诉~20%→审判~10% |
| 退赃退赔 | 比例+时间节点 |
| 被害人过错 | 程度(重大/一般/轻微)+因果 |
| 初犯/偶犯 | 前科情况 |
| 特殊减轻 | 刑法第63条第2款 |
| ⚠️ 反悔风险 | 刑诉法解释第355条—反悔后供述证据效力 |

#### 2.2.5 交叉分析矩阵（9组）

```
1. 【主观性】×【排非】→排非成功→主观故意证据充足否？
2. 【自首】×【程序】→到案经过→自动投案？→匹配15种基准
3. 【排非】×【程序】→违法取证→排除后证据链完整？
4. 【立功】×【主观性】→检举他人→明知他人犯罪？→影响本案明知
5. 【实体错误】×【主观性】→经济纠纷刑事化→非法占有目的不存在→出罪
6. 【主观性】×【自首】→承认客观但否认主观→仍构成如实供述(辩解不影响)
7. 【量刑情节】×【证据】→自首/立功证明标准→优势证据vs排除合理怀疑
8. 【涉案财物】×【程序】→超额查封→案外人保护
9. 【单位意志】×【主观性】→决策层知情？→个人vs单位
10.【追诉时效】×【程序】→犯罪时间→是否超过追诉期限？→绝对出罪事由（刑法第87-89条）
```

| 情节 | 调节幅度 | 关键条件 |
|------|---------|---------|
| **自首** | 减少基准刑≤40% | 犯罪较轻→可减40%以上或免除 |
| **立功(一般)** | 减少基准刑≤20% | — |
| **立功(重大)** | 减少20-50%；或免除 | 重大犯罪/案件/嫌疑人 |
| **从犯** | 减少20-50% | 犯罪较轻→50%以上或免除 |
| **未遂** | 减少≤50% | 实行终了/未终了区别 |
| **中止(无损害)** | 免除 | — |
| **中止(有损害)** | 减少≥60% | 基准较高时须结合 |
| **认罪认罚(侦查)** | 减少≤30% | 越早减让越大 |
| **认罪认罚(审查起诉)** | 减少≤20% | — |
| **认罪认罚(审判)** | 减少≤10% | — |
| **退赃退赔** | 减少≤30% | 全额+被害人谅解→可达更大减让 |
| **被害人过错(重大)** | 减少20-30% | 直接引发犯罪 |
| **被害人过错(一般)** | 减少≤20% | 对引发犯罪有责任 |
| **达成刑事和解** | 减少≤50%；或免除 | 轻微犯罪 |
| **累犯** | 增加10-40% | ≥3个月 |
| **前科** | 增加≤10% | — |

### 4.4 数罪并罚（刑法第69条）

| 情形 | 规则 |
|------|------|
| 除死刑/无期外 | 总和刑以下、最高刑以上，酌情决定 |
| 总和<35年 | ≤20年 |
| 总和≥35年 | ≤25年 |
| 附加刑同种 | 合并执行 |
| 附加刑不同种 | 分别执行 |

### 4.5 缓刑适用条件（刑法第72条）（V6新增）

| 条件 | 审查要点 |
|------|---------|
| 犯罪情节较轻 | 法定刑3年以下+非暴力/非严重危害 |
| 有悔罪表现 | 认罪认罚+退赃退赔+道歉 |
| 无再犯危险 | 初犯/偶犯+家庭稳定+工作稳定 |
| 对社区无重大不良影响 | 非累犯+非集团首要分子 |

**不适用缓刑**：累犯（刑法第74条）、犯罪集团首要分子。
**缓刑常见适用**：交通肇事+赔偿+谅解；故意伤害轻伤+和解；帮信罪+退赃+认罪。

### 4.6 罚金刑辩护（V6新增）

| 维度 | 策略 |
|------|------|
| 罚金基准 | 一般为违法所得1-5倍或犯罪数额的一定比例（各罪不同） |
| 减少辩点 | ①退赃退赔(已缴纳部分应扣减) ②家庭经济困难 ③积极赔偿被害人 |
| 与自由刑关系 | 积极缴纳罚金→可作为自由刑从轻依据 |

### 4.7 量刑计算完整示例（V7新增·AI可直接套用）

```
【示例：诈骗罪，数额巨大（50万元），有自首+部分退赃】

Step 1: 量刑起点
  诈骗数额巨大→3-4年（取3年6个月=42个月）

Step 2: 基准刑
  50万超数额巨大起点（10万）40万→每增加5万加2个月→加16个月
  基准刑 = 42 + 16 = 58个月

Step 3: 情节调节
  ┌─────────────────────────────────────┐
  │ 基准刑58个月                         │
  │  × 自首(减少25%) → 58×(1-0.25)=43.5 │
  │  × 部分退赃(减少10%) → 43.5×(1-0.10)=39.2 │
  │  × 认罪认罚审判阶段(减少8%) → 39.2×(1-0.08)=36.1 │
  │ = 宣告刑≈36个月（3年）                │
  └─────────────────────────────────────┘

Step 4: 确定宣告刑
  36个月→3年→符合缓刑条件(刑法第72条 3年以下+悔罪+无再犯危险)
  →建议宣告刑3年+缓刑X年

⚠️ 注意：
  - 如调整为审查起诉阶段认罪→认罪减少20%→最终≈31个月(约2年7个月)
  - 如增加全额退赃(减30%)→最终可能≤24个月
  - 存在减轻处罚情节(自首减轻)→可突破量刑起点下限
```

## Part 6: 罪名体系全景图——近5年+未来5-10年高发重点刑事案件

### 6.0 理论基础：双轴分类法

**理论依据**：以「犯罪场域」（物理空间/网络空间/跨境空间）为横轴，以「侵害法益」（国家法益/社会法益/个人法益）为纵轴，构建15类罪名的矩阵定位。每种犯罪类型在矩阵中的位置决定了其**证据特征、程序策略、突破口类型**的差异。

**三类核心差异决定突破口策略**：

| 差异维度 | 传统犯罪 | 网络犯罪 | 跨境犯罪 |
|---------|---------|---------|---------|
| **主要证据类型** | 言词+物证+书证 | 电子数据+服务器日志+资金流水 | 境外电子证据+国际司法协助 |
| **证明难点** | 主观故意推定 | 虚拟身份同一性+电子数据真实性 | 境外证据合法性+管辖权 |
| **程序突破口** | 排非+辨认+搜查令状 | 电子取证规范+哈希值+区块链存证 | 国际条约+取证合法性审查 |
| **实体突破口** | 构成要件精细拆解 | 技术中立抗辩+主观明知层级 | 双重犯罪原则+管辖异议 |
| **政策敏感度** | 中（常规打击） | 高（专项打击常交替） | 极高（外交+主权因素） |

| **辩护主张** | 无非法占有目的，本案为民事纠纷 |
| **法条依据** | 刑法第266条；非法占有目的四维→Part 2.2.1(c) |
| **证据策略** | ①签约前—公司资产/项目审批/银行流水(履约能力)②履约中—项目推进记录/邮件/付款凭证(实质履约)③资金去向—资金使用明细(用于项目非挥霍)④事后—协商记录(积极解决非逃匿) |
| **刑民交叉** | ①民事程序在进行→申请刑事中止②民事判决已认定合同有效→出罪有利因素③论证：实质是合同违约纠纷 |
| **量刑争取** | 无力全额退赃→部分退赃+认罪认罚→减少基准刑 |

#### 6.5.4 非法吸收公众存款罪

| 环节 | 内容 |
|------|------|
| **辩护主张** | 不满足"四性"或金额/人数未达入罪 |
| **法条依据** | 刑法第176条；最高法非法集资司法解释 |
| **四性反驳** | ①公开性—未通过媒体/推介会/传单(仅口头→可能不满足)②利诱性—未承诺还本付息③社会性—仅向亲友/内部人员(对象特定化)④非法性—合法审批/资质 |
| **金额六层剥离** | ①亲友借款②自有资金③已归还④利息/复利(仅本金)⑤单位内部员工⑥合法经营收入 |
| **⚠️生死线** | 集资诈骗(最高无期)vs非法吸存(最高10年)——关键"非法占有目的"。资金用于生产经营+无挥霍+无逃匿→非法吸存 |
| **量刑争取** | 全额退赃+投资人谅解→可能缓刑。合规整改→不起诉可能性 |

#### 6.5.5 合同诈骗罪

| 环节 | 内容 |
|------|------|
| **辩护主张** | 签约时不具有非法占有目的，未能完全履行为客观原因 |
| **法条依据** | 刑法第224条 |
| **证据策略** | ①签约前—公司注册/经营/资质真实②签约时—真实项目/标的物存在③履约中—实际投入资金/人力/物力(最核心)④不能履约原因—市场变化/政策变动/第三方违约(客观原因)⑤事后—未逃匿(有利于证明) |
| **金额分拆** | 已履行部分从指控总额扣除 |
| **量刑争取** | 签约时有履约能力+意愿→非法占有目的不成立→合同纠纷非刑事犯罪→不起诉/无罪 |

#### 6.5.6 毒品犯罪

| 环节 | 内容 |
|------|------|
| **辩护主张** | ①主观不明知②数量认定错误③特情引诱④罪名应降格 |
| **法条依据** | 刑法第347-357条；各会议纪要(武汉/大连/昆明) |
| **数量攻击** | ①未缴获仅口供认定？→刑诉法第55条②含量鉴定？(死刑→必须做)③全链条完整？④不同批次分别鉴定？ |
| **特情引诱** | ①调取审批手续②审查首次接触起因和时间③犯意引诱→证据应排除；数量引诱→量刑从轻④特情证人→申请出庭 |
| **罪名降格** | 运输→非法持有(无运输目的证据)；贩卖→非法持有(无贩卖行为证据) |
