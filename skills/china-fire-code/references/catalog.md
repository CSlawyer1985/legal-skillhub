# 消防法律法规总目录（catalog · 机器可读索引）
> **本 skill 的核心发现层。** 仓库**不捆绑任何 PDF**，只维护此目录（含官方 URL）。
> agent 接到查询后，先在本目录检索定位文档 → 取「类型 / 效力层级 / 官方 URL」→ 走「模式一·联网检索」从官方源抓取精确条文。
> 用户若自行下载 PDF 到本地私有语料，可再用「模式二·本地抽取」兜底。
>
> ⚠️ **本目录为 v1 国家层面核心，所有条目均 `⏳ 待官方核对`**——引用前请经模式一在官方源复核（与 skill 自身「精准性铁律」一致）。
> 地方/省级法规请按相同 schema 自行追加。
>
> 效力层级（冲突裁决用）：`1 法律` > `2 行政法规/规范性文件` > `3 部门规章(部令)` > `4 国家标准` > `5 行业标准`。同层新法优于旧法。
> **📖 在线可读性（默认约定）**：本目录默认全部条目**可在官方平台在线阅读**，agent 走「模式一」即可抓取精确条文。
> **不可在线阅读的例外**（采标/仅下载PDF/不提供公开文本，多因采用 ISO/IEC 国际标准版权限制）**不在此逐行标注**，统一集中在 `references/online_readability.md` 例外清单。
> agent 在第 0 步定位文档后，先扫该清单是否命中；命中即按 `SKILL.md`「模式一·例外处理」分支执行（绝不伪造 / 替代权威源）。
> **Schema（每条字段）**：`名称 | 类型 | 编号/令号 | 发布机关 | 施行日期 | 状态 | 效力层级 | 官方URL(权威域) | 权威域级别 | 核对`
> **权威域级别（行政层级，逐级往下）**：`国`=国家级平台（全国人大/国务院/部委/国家标委/国家消防救援局等）｜`省`=省级（省人大/省政府/省消防救援）｜`市`=市级（含直辖市 北京/上海/天津/重庆 及设区市人大/政府）。该列仅标注「权威域」的行政级别，法律位阶仍以「效力层级」列为准。

## 如何扩展
- 追加行即可，字段同上；新文档务必填「效力层级」以支持冲突裁决。
- 省级/地方性法规：在对应省市政府/人大官网核对后追加（效力层级按性质归入 2 或 3）。
