# 在线可读性例外清单（采标 / 仅下载PDF / 不提供公开文本）

> 本 skill 默认：`catalog.md` 中**绝大多数**消防法律法规条文都可在官方平台**在线阅读 / 网页检索**，
> agent 走「模式一·联网检索」即可抓取精确条文。
> 下列为**例外**：因版权 / 平台策略，官方**不提供在线阅读**，仅可下载 PDF 或完全不公开文本。
> **命中例外时，按 `SKILL.md`「模式一·例外处理」执行，绝不伪造或替代权威源。**

---

## 一、为什么"采标"标准常不提供在线阅读

- **采标** = 采用国际标准（如 ISO / IEC）。中国将国际标准转化为 GB / GB/T 时，文本版权归国际标准组织（ISO / IEC）所有。
- 国标委（SAC）对此类标准通常**不提供免费在线阅读**，仅提供**付费下载**或**纸质 / 正式出版物**。
- 这是**版权 / 许可限制，非技术故障**——skill 无法绕过，必须如实告知用户，并引导其自行获取官方原文。
- 判断信号：标准详情页「采标情况」字段标注「等同 / 修改采用 ISO xxxx / IEC xxxx」，且平台提示「不提供在线阅读」。

---

## 二、取值与处理映射

| 取值 | 含义 | agent 处理（见 SKILL.md 模式一·例外处理） |
|---|---|---|
| `可在线阅读` | 官方提供网页版条文（**默认**，不列入本清单） | 正常走模式一抓取 |
| `仅下载PDF` | 官方仅提供 PDF 下载，无网页在线阅读 | 如实告知 → 引导用户凭官方 URL 下载 → 走「模式二·`extract_pdf.py`」；或建议正式出版物 |
| `不提供公开文本` | 官方不公开免费条文（多因采标版权） | 如实告知无法经本 skill 获取精确条文 → 建议正式出版物，输出标注「待核实」 |

## 三、例外清单（采标 / 仅下载 / 不提供）

> ⚠️ 下列均为**真实存在**的消防类采标标准，按"采标标准官方通常不提供在线阅读"的通行规则**预判**为不可在线阅读；
> 采标情况以官方平台「采标情况」字段为准，精确开关仍须**经模式一在官方平台复核**。
> **精确开关仍须经模式一在官方平台复核**，复核后更新本表「在线可读性」列。

## 四、与 catalog.md 的关系

- `catalog.md` 是**发现层索引**，默认全部可在线阅读，**不逐行重复标注可读性**。
- 不可在线阅读的采标 / 仅下载 / 不提供公开文本标准，**统一集中在本清单**，避免 47+ 行逐条加列造成的冗余与漂移。
- **但采标标准本身仍应补入 `catalog.md` 以保持"全收"覆盖**（见 catalog.md「四-b、GB/T 采标」小节），本清单仅补充其**在线可读性例外信息**（取值/采标依据/处理建议）。
- agent 在第 0 步定位文档后，先扫本清单是否命中；命中即按「模式一·例外处理」分支执行。
