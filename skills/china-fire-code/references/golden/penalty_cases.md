## 一、消防法 法律责任（罚则）核心条款
依据《中华人民共和国消防法》（2021 修正）「法律责任」章：

| 条款 | 适用情形（摘要） | 处罚种类 / 典型区间 |
|---|---|---|
| 第58条 | 未经消防验收/抽查不合格擅自投入使用；公众聚集场所未经检查擅自营业 | 责令停止使用/停产停业，并处 **3万–30万元** |
| 第59条 | 建设/设计/施工/监理单位降低消防技术标准 | 责令改正或停止施工，并处 **1万–10万元** |
| 第60条 | 消防设施缺陷/挪用停用；占用堵塞疏散/安全出口/消防车通道；人员密集场所设障碍物 | 单位 **5000元–5万元**；个人警告或 **500元以下**；拒不改正可强制执行 |
| 第61条 | 易燃易爆场所与居住场所混设/未保持安全距离 | 责令停产停业，并处 **5000元–5万元** |
| 第63条 | 违规进入易燃易爆场所/违规使用明火 | 警告或 **500元以下**；情节严重 **5日以下拘留** |
| 第64条 | 指使强令冒险作业、过失起火、阻拦/不及时报警、破坏火灾现场、擅自拆封查封 | **10–15日拘留**，可并处 **500元以下**；情节较轻警告或 500 元以下 |
| 第65条 | 人员密集场所使用不合格/淘汰消防产品逾期不改 | 处 **5000元–5万元**，直接责任人 **500元–2000元** |
| 第66条 | 电器/燃气用具安装使用不符合规定逾期不改 | 责令停止使用，可并处 **1000元–5000元** |
| 第67条 | 机关团体企事业单位违反第16/17/18/21条职责 | 责令限期改正；逾期不改对直接责任人处分或警告 |
| 第68条 | 人员密集场所现场工作人员不履行疏散引导义务（情节严重） | **5–10日拘留** |
| 第69条 | 消防技术服务机构出具虚假文件 | 责令改正，处 **5万–10万元**，直接责任人 **1万–5万元**；没收所得；情节严重责令停业/吊销资质 |
| 第71条 | 住建/消防救援等部门工作人员滥用职权、玩忽职守、徇私舞弊 | 依法给予处分 |

## 二、主要部门规章罚则要点
- **《高层民用建筑消防安全管理规定》（应急管理部令第5号，2021-08-01 施行）**
  - 第47条第7项：在高层民用建筑公共门厅、疏散走道、楼梯间、安全出口停放电动自行车或充电，**拒不改正** → 经营性单位/个人 **2000–10000元**，非经营性 **500–1000元**。
  - 第47条：未落实消防控制室值班制度或安排不具备条件人员值班 → 同上区间。
- **《机关、团体、企业、事业单位消防安全管理规定》（公安部令第61号，2002-05-01 施行）**
  - 第4章明确单位消防安全职责；违反责令限期改正，逾期不改依法处罚（罚则衔接消防法及处分机制）。
- **《消防监督检查规定》（公安部令第120号，2012 修订）**
  - 规范监督检查职权、责令改正/临时查封/强制执行等措施及程序，具体罚则援引消防法；2018 机构改革后职能由消防救援机构承接。

## 三、典型执法 / 处罚案例（公开可溯源）
1. **酒店堵塞疏散通道及安全出口被罚 5000 元** — 多楼层走廊、楼梯间堆放杂物堵塞疏散通道/安全出口，依消防法第60条罚款 5000 元。来源：海南消防 http://hi.119.gov.cn/info/1464/30723.htm （2023）
2. **餐饮场所堵塞安全出口被罚 5100 元** — 北侧安全出口堆放杂物并上锁，依消防法第60条第1款第三项罚款 5100 元。来源：人民网 http://m2.people.cn/news/default.html?s=Ml8yXzQwOTkwNTU5XzQwNjYzMV8xNzI3MzMzOTM3 （2024-09）
3. **小区电动车违规停放充电拒不改正被罚 500 元** — 居民在高层住宅楼道停放电动车并充电，复查拒不改正，依《高层规定》第47条第7项罚款 500 元（全市首张）。来源：江西消防 http://jx.119.gov.cn/news-show-14786.html （2021-08）
4. **消防技术服务机构出具虚假评估报告被罚 6.5 万元** — 为室内消火栓瘫痪、安全出口不足的场所出具"合格"虚假评估报告，依消防法第69条罚款 6.5 万、没收违法所得 0.16 万。来源：广德市政府 https://www.guangde.gov.cn/OpennessContent/download/3756577.html （2024）
5. **不具备从业条件出具虚假报告、负责人伪造印章获刑** — 依消防法第69条责令停业、没收 0.12 万、罚 5 万，主管罚 1 万；伪造印章罪判刑 8 个月、缓刑 1 年 2 个月。来源：罗江区政府 https://www.luojiang.gov.cn/.../1580542.htm （2025）
