消防水泵零流量扬程：H_零流量 = 150m × 1.30 = **195m**

零流量扬程换算为压力：
P_零流量 = H_零流量 × ρg = 195m × 0.00980665MPa/m
P_零流量 ≈ 195 ÷ 102 = **1.912MPa**
（工程简算：195 × 0.01 = 1.95MPa）

取精确值：**P_零流量 ≈ 1.912MPa**

**第二步：计算消防水泵吸水口的最大静压**

高位消防水箱底标高：+98m
消防水泵吸水口标高：-5m
高差：H_静 = 98m - (-5m) = **103m**

最大静压（水箱满水时）：
P_静 = 103m ÷ 102 ≈ **1.010MPa**
（工程简算：103 × 0.01 = 1.03MPa）

**第三步：计算系统工作压力**

系统工作压力 = P_零流量 + P_静
系统工作压力 = 1.912MPa + 1.010MPa = **2.922MPa**
（工程简算：1.95 + 1.03 = 2.98MPa）

**结论：** 该临时高压消防给水系统（高位水箱稳压）的系统工作压力约为**2.92～2.98MPa**。

**工程提示：** 系统工作压力接近3.0MPa，属超高压系统，管道、阀门、水泵接合器等所有承压设备的额定工作压力均须不低于该值，需选用特殊高压等级产品，设计时需特别关注。

### [HF-SFT] #59
- 问：独立前室vs共用前室的加压送风系统独立性判断
- 答：判断逻辑：
第一步：识别前室类型——独立前室 vs 共用前室
第二步：分析漏风特性——不同前室类型的密闭性差异
第三步：适用条文——根据3.1.5条（强制性条文）
第四步：做出结论——

**结论：两个系统不可共用一套风机和风道，必须分别独立设置。**

判断理由分析：

**独立前室的特点：**
- 漏风泄压较少（只与楼梯间和走道相连）
- 可采用仅在楼梯间送风、前室不送风的方式
- 仍能保证楼梯间-前室-走道形成压力梯度

**共用前室的特点：**
- 漏风泄压多（与多个楼梯间、走道相连）
- 若机械加压送风的楼梯间溢出的空气会通过共用前室的其他开口或缝隙而流失
- 无法保证共用前室和走道之间的压力梯度
- 不能有效防止烟气侵入

因此：根据3.1.5条（强制性条文），**当采用共用前室时，楼梯间、共用前室应分别独立设置机械加压送风的防烟设施。**

**关键压力梯度原理：**
- 独立前室：楼梯间加压→前室→走道，形成有效梯度
- 共用前室：若只设一套系统，压力无法在共用前室处形成有效梯度

**强制性要求：**
本条第2、3款是强制性条文，必须严格执行，不允许为节省成本而合并系统。

- 问：消防水源的水量应如何确定？
- 答：根据GB 55036-2022第3.0.7条规定，消防水源的水量应满足水基消防设施在设计持续供水时间内的最大用水量要求。水量是确保水灭火系统实现相应防护目标的根本保障，其设计目的在于保证火灾发生时系统能够在规定的持续供水时间内维持足够的流量和压力，从而有效控制或扑灭火灾。从安全逻辑角度看，水量不足将导致系统提前断水，使灭火行动功亏一篑，造成火灾蔓延扩大。在工程实践中，应综合考虑建筑类型、危险等级、同时开启的用水系统数量及各自的设计流量，叠加计算总用水量，并据此确定储水设施的有效容积或市政供水的保障能力。适用条件上，该要求适用于所有采用水基消防设施的建筑和场所，水量核算应以最不利工况下的最大用水量为设计依据。

结论：应设置5个排烟窗（总面积5m²）。
因为屋面斜度≤12°时，屋面较平缓，烟气在屋面上的流动阻力小，排烟效率相对较高，所以密度要求为每200m²一个。而屋面斜度>12°时（陡坡），烟气流动困难，密度要求提高到每400m²一个。这体现了斜度对排烟效率的影响。

### [HF-SFT] #272
- 问：计算轴对称烟羽流质量流量（近场区）
- 答：根据第4.6.11条第1款的规定，计算步骤如下：

【第一步】确定对流热释放速率
Q_c = 0.7Q = 0.7 × 3000 = 2100 kW

【第二步】计算火焰极限高度Z₁
Z₁ = 0.166 × Q_c^(2/5) = 0.166 × 2100^0.4

计算2100^0.4：
- ln(2100) = 7.650
- 0.4 × 7.650 = 3.060
- e^3.060 = 21.3

Z₁ = 0.166 × 21.3 = 3.54 m ≈ 3.5 m

【第三步】确定高度Z
Z = 烟层底部高度 - 火源高度 = 3 - 0.5 = 2.5 m

【第四步】判断适用公式
比较：Z = 2.5 m < Z₁ = 3.5 m
因此采用近场区公式(4.6.11-2)：
M_ρ = 0.032Q_c^(3/5)Z

【第五步】计算Q_c的3/5次方
Q_c^(3/5) = 2100^0.6

计算步骤：
- ln(2100) = 7.650
- 0.6 × 7.650 = 4.590
- e^4.590 = 98.4

Q_c^(3/5) = 98.4

【第六步】代入公式计算
M_ρ = 0.032 × 98.4 × 2.5
M_ρ = 0.032 × 246
M_ρ = 7.87 kg/s

【第七步】结论
烟羽流质量流量M_ρ = 7.87 kg/s ≈ 7.9 kg/s
