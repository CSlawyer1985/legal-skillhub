# 历史废止条款归档库

> 存放已被官方标注为「废止」的规范/条款，从活跃金标准（`golden/`）移出后落此目录。
> 格式与白名单官网一致：含废止日期、替代标准、原文、依据来源。
> **仅作历史追溯**，不作为当前有效依据使用。

## 条目格式
```
### [规范编号] 第 X.X.X 条 [废止]
- 状态：废止
- 废止日期：YYYY-MM-DD
- 替代标准：GB XXXX-XXXX《名称》或 —
- 废止依据来源：权威 URL
- 归档日期：YYYY-MM-DD
- 原文：（废止前版本）
- 备注：本条已从活跃金标准库移出，仅作历史追溯。
```

## 触发条件（模式三-b）
1. 联网检索到某规范/条款被 openstd / mohurd 官方标注「废止」；
2. agent 自动检查本地 `references/golden/` 是否存在该条目；
3. 若存在 → 执行 `python scripts/golden.py abolish --std ... --clause ... --source ...` 将其移入本目录。

## 文件命名
与 `golden/` 一致：按规范编号分文件，如 `GB_55037-2022.md`。
