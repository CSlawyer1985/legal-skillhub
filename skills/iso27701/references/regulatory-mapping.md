# ISO 27701:2025——监管与框架映射

ISO/IEC 27701:2025 旨在作为**同时满足多项隐私法规的合规框架**。该标准更新的对应附录提供了对 GDPR 和其他主要隐私法律的映射。本指南涵盖最常被请求的映射。

---

## GDPR（欧盟《通用数据保护条例》）

ISO 27701:2025 提供了任何隐私管理标准中对 GDPR 最详细的对齐。其更新的对应附录将控制直接映射到 GDPR 条文。

### 关键 GDPR 原则 → ISO 27701 控制

| GDPR 原则（第 5 条） | ISO 27701:2025 控制 |
|------------------------|------------------------|
| 合法性、公平性、透明性 | A.1.2.3（合法依据）、A.1.3.3-A.1.3.4（透明性） |
| 目的限制 | A.1.2.2（记录目的）、A.1.4.3（限制处理） |
| 数据最小化 | A.1.4.2（限制收集）、A.1.4.5（PII 最小化） |
| 准确性 | A.1.4.4（准确性和质量）、A.1.3.7（更正） |
| 存储限制 | A.1.4.8（保留）、A.1.4.9（处置）、A.1.4.6（删除） |
| 完整性与保密性 | A.3.26（密码学）、A.3.25（日志记录）、A.3.9（访问） |
| 问责 | A.1.2.9（处理活动记录）、SoA、隐私风险评估、管理评审 |

### ISO 27701 认证如何支持 GDPR 合规

ISO 27701 认证并不自动意味着 GDPR 合规——GDPR 还要求特定法律依据、某些情况下任命 DPO、向监管机构登记等。然而，认证提供：

- 用于监管调查的隐私控制**文件化证据**
- **问责证据**（第 5(2) 条）——证明控制已到位
- **公认框架**——监管机构对 ISO 27701 持积极看法
- **DPIA 证据**——SoA 和控制文件可支持 DPIA 要求

## 英国 GDPR

英国 GDPR（脱欧后保留自欧盟 GDPR）维持与欧盟 GDPR 几乎相同的要求。相同的 ISO 27701:2025 控制映射适用。英国 ICO 已表示，ISO 27701 可用作英国 GDPR 第 42 条下的隐私标志机制。

**英国特定关键考量**：英国的国际数据传输协议（IDTA）和 SCC 英国附录不同于欧盟机制。A.1.5.2 必须引用适当的英国转移机制。

## CCPA / CPRA（加利福尼亚）

《加州消费者隐私法》（CCPA）及其修正案（CPRA）与 GDPR 共享许多概念，但有独特要求。

| CCPA/CPRA 权利或义务 | ISO 27701:2025 控制 |
|------------------------------|------------------------|
| 知情权（类别和具体要素） | A.1.3.9、A.1.3.10 |
| 删除权 | A.1.3.7、A.1.4.6、A.1.4.9 |
| 退出出售/共享的权利 | A.1.3.6、A.1.2.3 |
| 更正权 | A.1.3.7、A.1.4.4 |
| 限制使用敏感个人信息 | A.1.4.2、A.1.4.5 |
| 不歧视权 | 未直接涵盖——流程设计 |
| 隐私通知（收集时） | A.1.3.3、A.1.3.4 |
| 数据最小化 | A.1.4.2、A.1.4.5 |
| 服务提供商合同 | A.1.2.7（相当于 DPA） |
| CPRA 风险评估 | A.1.2.6（PIA/DPIA） |
| 承包方义务 | A.2（处理者控制） |

**CCPA/CPRA 注释**：
- CCPA 使用「consumer（消费者）」「business（企业）」「service provider（服务提供商）」「contractor（承包方）」「third party（第三方）」——映射到 ISO 27701 的「PII principal（个人信息主体）」「PII controller（个人信息控制者）」「PII processor（个人信息处理者）」
- CPRA 的「sensitive personal information（敏感个人信息）」类别需要额外限制（映射到 A.1.4.2、A.1.4.5）
- CPRA 的强制风险评估和网络安全审计与 A.1.2.6 和 A.3.15 对齐

## PIPEDA（加拿大）

加拿大《个人信息保护和电子文件法》（PIPEDA）围绕 10 项公平信息原则构建。ISO 27701:2025 对齐良好。

| PIPEDA 原则 | ISO 27701:2025 控制 |
|-----------------|------------------------|
| 1. 问责 | 第 5 章（领导力）、管理评审、SoA |
| 2. 识别目的 | A.1.2.2、A.1.2.9 |
| 3. 同意 | A.1.2.3、A.1.2.4、A.1.2.5 |
| 4. 限制收集 | A.1.4.2、A.1.4.5 |
| 5. 限制使用、披露、保留 | A.1.4.3、A.1.4.8、A.1.5.4 |
| 6. 准确性 | A.1.4.4、A.1.3.7 |
| 7. 保障措施 | A.3（安全控制） |
| 8. 公开性 | A.1.3.3、A.1.3.4 |
| 9. 个人访问 | A.1.3.9、A.1.3.10 |
| 10. 质疑合规 | A.1.3.10（处理请求）、第 10 章 |

**注**：加拿大 C-27 法案（《消费者隐私保护法》——CPPA）在颁布后将取代 PIPEDA。ISO 27701:2025 对齐将延续，因为 CPPA 共享受 GDPR 影响的原则。

## ISO 27001:2022 整合

ISO 27701:2025 设计为与 ISO 27001:2022 协同工作，尽管不再要求以它为前提。同时实施两者时：

- A.3 安全控制可直接引用组织的 ISO 27001 ISMS 控制——无需重复实施安全控制
- ISO 27001 SoA 和 PIMS SoA 可作为单独文件维护，或作为带基于角色的选项卡的合并文件
- 风险评估可关联：ISMS 风险评估聚焦安全风险；PIMS 风险评估聚焦对个人信息主体的伤害
- 范围界定正确时，内部审计可合并以提高效率
- 管理评审可合并，并附专门的隐私章节

**关键整合点：**
| ISO 27701 要求 | 可引用的 ISO 27001 证据 |
|----------------------|------------------------------------------|
| A.3.3（信息安全政策） | 信息安全政策（ISO 27001 第 5.2 章） |
| A.3.9（访问权） | 访问控制政策和记录（A.5.15-5.18） |
| A.3.11-A.3.12（事件） | 事件响应政策和记录（A.5.24-5.28） |
| A.3.26（密码学） | 密码学政策（A.8.24） |
| A.3.27（安全 SDLC） | 安全开发政策（A.8.25-8.32） |
| A.3.25（日志记录） | 日志记录和监测控制（A.8.15-8.16） |

## 框架比较摘要

| 框架 | 地域范围 | 具有法律约束力？ | ISO 27701 对齐度 |
|-----------|-----------------|-----------------|---------------------|
| GDPR | 欧盟/欧洲经济区 | 是——强制性法律 | 优秀（专门对应附录） |
| 英国 GDPR | 英国 | 是——强制性法律 | 优秀（与欧盟 GDPR 相同） |
| CCPA/CPRA | 美国加利福尼亚 | 是——强制性法律 | 良好（涵盖大多数权利和义务） |
| LGPD | 巴西 | 是——强制性法律 | 优秀（紧密镜像 GDPR） |
| PIPEDA | 加拿大 | 是——强制性法律 | 良好（基于原则的对齐） |
| PDPA（新加坡） | 新加坡 | 是——强制性法律 | 良好 |
| PDPA（泰国） | 泰国 | 是——强制性法律 | 良好 |
| ISO 27001:2022 | 全球 | 自愿标准 | 支持直接整合 |
