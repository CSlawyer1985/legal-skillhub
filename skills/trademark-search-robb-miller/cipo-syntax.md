# CIPO 加拿大商标数据库——查询语法速查表

## 端点

- **检索：** https://ised-isde.canada.ca/cipo/trademarks-search/
- **商标审查手册：** https://ised-isde.canada.ca/site/canadian-intellectual-property-office/en/trademarks/trademarks-examination-manual
- **马德里体系参考（CIPO 指定）：** https://ised-isde.canada.ca/site/canadian-intellectual-property-office/en/trademarks/madrid-system-international-trademark-registration

## 加拿大的检索理念

CIPO **不会**像 USPTO 审查员那样按尼斯类别机械隔离。混淆审查在整个注册簿上跨类别进行，无严格类别
限制，尽管类别仍为 s. 6(5)(c) 下商品性质分析提供信息。运行初筛（knockout）时，不要跳过跨类别命中。

现行界面支持：

- 商标文本字段（带隐式语音评分）
- 所有人 / 申请人 / 代理人字段
- 申请 / 注册号
- 状态（有效 / 无效 / 全部）
- 商品和服务关键词
- 尼斯类别
- 维也纳编码（用于图形商标——见下文）
- 放弃声明 / 权利要求类型筛选

## 每次初筛的建议查询组合

```
1. 精确——全部状态：
   商标 = "商标名"
   状态 = 全部

2. 语音 / 前缀：
   商标 = 商标名（不加引号；CIPO 应用语音评分）

3. 词根通配符：
   商标 = 商标名*
   （捕捉家族商标）

4. 所有人：
   所有人 = "所有人名称公司"

5. 商品主导：
   商品/服务关键词 = [主要商品术语]
   尼斯类别 = [N]
   （捕捉同一领域描述性在先使用人）
```

## 维也纳编码（图形商标）

加拿大对图形要素使用**维也纳分类**，而非 USPTO 设计编码。常见类别：

- 1.x——天体
- 2.x——人类
- 3.x——动物
- 5.x——植物
- 26.x——几何图形
- 27.x——书写形式（数字、字母）

如果商标含图形要素，将维也纳检索与文字商标检索分开运行，并在冲突矩阵中合并结果。

## 逐条记录提取

对每个潜在冲突的加拿大商标，提取：

1. 状态（已注册、待审、已获准、已放弃、已注销）
2. 所有人——若经转让变更，为当前所有人
3. 申请日和注册日
4. 在加拿大的首次使用日期（如主张）
5. 商品/服务（完整尼斯类别陈述，2019 年修正后）
6. 放弃声明
7. 第 9 条官方商标状态（s. 9(1)(n)——联邦/省级机构、大学、公共机关——这些具有超强阻却力，
   应立即标记）
8. 审查往来文件（如可得）——针对该商标引用的混淆异议是金矿

## 需在备忘录中呈现的加拿大特殊考量

- **s. 9 官方商标** ——公共机关可注册“官方商标”，无论类别如何均阻却所有后续混淆性商标。
  若出现 s. 9 商标，立即升级。
- **s. 22 商誉贬值** ——加拿大驰名商标即使不存在混淆，也有平行诉因（Veuve Clicquot Ponsardin
  v Boutiques Cliquot Ltée, 2006 SCC 23），只要在先商标驰名且在后商标的使用会贬损商誉。
- **s. 7(b) 仿冒（passing off）** ——普通法/未注册商标权利受保护。在加拿大，普通法检索不是
  可选项；在某地理区域的商誉赋予优先权。
- **CUSMA / NAFTA 遗留申请** ——2019 年前不要求尼斯分类的加拿大申请可能拥有非常宽泛的商品/服务。
  按陈述字面理解，而非按类别标签。
- **魁北克语言考量** ——若客户计划在魁北克经营，涉及法语存在和《法语宪章》（第 96 号法案）
  的影响。本身不是可注册性问题，但值得在建议部分注明。
