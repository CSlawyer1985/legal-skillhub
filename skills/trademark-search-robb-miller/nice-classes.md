# 尼斯分类——速查参考与关联性

尼斯分类（第 12 版，美国和加拿大均采用）将商品（1-34）和服务（35-45）分组。尼斯分类不决定混淆——关联性才决定——但类别是 USPTO 按类别检索的入口，也是 CIPO 有用的组织字段。

## 关联性配对（USPTO §2(d) / TMEP 1207.01）

类别相同**并非**混淆所必需。审查员和法院按惯例认定以下配对具有关联性。检索类别 N 时，同时检索下表中的关联类别。

| 主要类别 | 惯例上关联 |
|---|---|
| 9（软件/应用） | 42（SaaS）、41（在线教育内容）、35（软件在线零售）、38（电信平台） |
| 25（服装） | 35（服装零售）、18（箱包/皮革制品）、14（珠宝）、9（太阳镜） |
| 29-30（食品） | 35（食品零售）、43（餐厅）、32-33（饮料） |
| 32-33（饮料） | 43（酒吧/餐厅）、35（饮料零售） |
| 36（金融） | 9（金融科技软件）、42（金融科技 SaaS）、35（金融咨询） |
| 41（娱乐） | 9（可下载媒体）、38（广播）、16（纸质书籍）、28（游戏） |
| 5（药品） | 3（边缘情形下化妆品）、44（医疗服务） |
| 44（医疗/美容） | 3（化妆品）、5（保健品）、41（培训） |
| 45（法律） | 35（咨询）、41（法律教育）、42（法律 SaaS） |

## 加拿大关联性

CIPO 适用 s. 6(5)(c)（商品/服务性质）和 s. 6(5)(d)（贸易性质），不要求类别匹配。上述配对在加拿大同样具有说服力。*Masterpiece* 案的“匆忙中的普通消费者”标准意味着视觉-听觉-概念相似性优于精细的类别区分。

## 面向科技 / SaaS / AI 客户的策略

软件和平台品牌的默认尼斯策略：

- **第 9 类** ——可下载软件、移动应用、可下载 AI 模型
- **第 42 类** ——SaaS、PaaS、AI 即服务、软件开发服务、托管
- **第 35 类** ——有市场/在线零售组成部分时
- **第 41 类** ——有可下载/流媒体教育或媒体内容时
- **第 38 类** ——有实时通信/消息核心功能时

法律科技产品：9 + 42 + 45（法律信息服务，取决于未经授权执业的放弃声明）。
