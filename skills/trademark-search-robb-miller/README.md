在美国和加拿大执行面向律师的初筛/可用性商标检索。当用户（创始人、客户或律师）询问品牌、商标、名称、标志、口号或产品名是否“可用”“可自由使用”“可清理”或“已被占用”时使用——或要求 Claude“检索商标注册簿”“查 USPTO”“查 CIPO”“做初筛检索”“清理检索”“可用性检索”，或“看看 [商标] 是否已注册商标”。即使用户以随意方式表述（“我能把我的公司叫 X 吗？”“这个名字被占用了吗？”）也触发。覆盖联邦 USPTO（TESS/TSDR）、联邦加拿大（CIPO）、普通法/网络/州层面，以及 WIPO 马德里国际。输出为供律师审查的初筛可用性备忘录，带绿/黄/红判定。包括实质性分析前的职业责任门禁（AI 使用披露、冲突检索、范围确认）。不构成法律意见——产出供律师签署的工作成果。
