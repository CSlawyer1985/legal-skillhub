## 快速安装

本Skill提供两种使用方式：

### 方式一：直接复制使用（推荐）🚀
将SKILL.md内容直接粘贴到你的AI对话中即可使用，无需任何安装配置。

### 方式二：下载Zip包安装

```bash
unzip lawyer-skills-v5.0.3.zip -d /path/to/your/ai/skills/
pip install python-docx
```

## 功能模块

### 模块A：法律咨询
- 民商事法律问题专业解答，五步分析法：事实梳理→法律定性→法条检索→分析论证→实务建议
- 内置国家法律法规数据库API交叉核验 + Logic Doctor五维自检 + 诉讼时效自动追踪
- 9类异常容错处理，覆盖输入模糊、领域越界、信息不足、案由竞合、法条缺失等场景
- 严格基于现行有效法律，不编造法条

### 模块B：要素式起诉状起草
- 覆盖11个标准案由+通用民事起诉状，非标准案由自动使用通用模板
- 三步工作流：案由识别→关键信息追问→模板填充，输出规范docx格式起诉状
