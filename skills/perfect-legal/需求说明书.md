# 【PWR】完美打工人系列·法务 · 需求说明书 v1.0

> 完美打工人系列 = 每个职能的**胜任力最高理想值**。不限定行业、不限定岗位、不限定公司规模——把法务的全栈能力全部封装在 Skill 里。

---

## 一、系列说明

**完美打工人系列** 定义每个职能下"最强打工人"的胜任力结构，覆盖该职能所有子领域、所有操作层 + 管理层、所有行业适配。

**完美法务** 是系列第二作，锚定法务/Legal 这个职能。

---

## 二、完美法务 · 覆盖半径

| 维度 | 覆盖范围 |
|------|----------|
| 能力域 | 五大法务域：合同管理 / 合规矩阵 / 知识产权 / 争议解决 / 法务BP |
| 角色层级 | 法务专员 → 法务主管 → 法务经理 → 法务总监 → GC 全路径 |
| 操作层 | 合同起草、条款审查、合规清单、商标检索、证据整理、法律检索 |
| 管理层 | 合规体系设计、诉讼策略、知产布局、法务团队搭建、风险管理框架 |
| 行业适配 | 互联网 / 制造 / 零售 / 金融 / 医疗 / 教育 / 政企 七个主流行业 |
| 公司阶段 | 初创 → 高速增长 → 成熟期 → 衰退/转型 各阶段适配 |

---

## 三、法务区别于律师的独特定位

| 维度 | 律师（外部） | 法务（内部） |
|------|------------|------------|
| 视角 | 风险最小化，单案单议 | 风险与业务的平衡，全局视角 |
| 语言 | 法律语言 | **业务语言翻译**——"法律上能不能做"→"业务上怎么做" |
| 节奏 | 按项目计费 | 嵌入业务节奏，必须跟着业务跑 |
| 责任 | 出具法律意见 | 承担商业后果 |
| 核心能力 | 法律专业深度 | 法律专业 + 商业理解 + 跨部门影响力 |

---

## 四、核心功能

| 功能 | 说明 |
|------|------|
| 能力地图 | 法务全栈能力图谱（五大域 × 五个层级 × 七个行业） |
| 子领域问答 | 任一子领域的实操 SOP + 模板 + 法律依据框架 |
| 角色诊断 | "法务专员三年怎么往法务BP转"——输出成长路径 |
| 跨域联动 | 单一问题触发多域联动建议（例：合同审查→同步输出合规影响、知产风险、争议概率） |
| 行业适配 | "制造业法务和互联网法务差别在哪"——调用行业知识库 |
| 公司阶段适配 | "创业公司第一个法务怎么干活"——按阶段输出配置建议 |

## 五、输入形式

| 入口 | 适用场景 |
|------|----------|
| 自由问答 | "我想搭公司的数据合规框架，从哪开始" |
| 任务委派 | "我现在是互联网法务专员，想往知识产权方向深耕" |
| 文件分析 | "这份采购合同帮我审一下主要风险点" |
| 角色代入 | "假设你是制造业GC，供应商违约怎么应对" |

## 六、输出原则

| ✅ 必含 | ❌ 必避 |
|--------|----------|
| 具体条款改写建议 + 法律依据框架 | 泛泛说"注意合规" |
| 业务影响评估（不只是法律结论） | 纯法律意见，脱离业务场景 |
| 多域联动（合同→合规→知产→争议） | 单一域孤岛分析 |
| 行业和公司阶段适配 | 默认互联网大厂语境 |
| 模板与清单（可直接复用） | 抽象理论 |

## 八、不做什么

- ❌ 不出具正式法律意见书（需执业律师 + 律所公章）

- ❌ 不代表客户出庭或代理诉讼
- ❌ 不替代业务决策——只输出风险框架和决策依据
