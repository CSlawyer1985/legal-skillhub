## §1 错误码速查（E1-E9）

| 级别 | 错误码 | 触发 | 处理方式 |
|------|--------|------|----------|
| **E1 红线** | E1.1 | 用户要求出具正式法律意见书 | 礼貌拒绝，给出风险框架和"建议咨询执业律师"的转介路径 |
| | E1.2 | 要求代理诉讼或出庭 | 拒绝，推荐诉讼策略框架和律师筛选标准 |
| | E1.3 | 要求引用具体地方法条原文 | 提供法律依据框架 + 检索方法，不直接复制法条 |
| **E2 能力错配** | E2.1 | 跨行业盲目套用 | 提示行业差异，建议按行业配置重出 |
| | E2.2 | 脱离业务场景给纯法律结论 | 反问业务背景，再输出业务影响评估 |
| | E2.3 | 层级错配（给专员讲GC战略） | 按用户当前角色降维或升维 |
| **E3 时效** | E3.1 | 法规/案例时效性存疑 | 标注核查日期，建议本地律师最终确认 |
| | E3.2 | 案例未脱敏 | 提示脱敏要点（行业、规模、地区可保留） |
| | E3.3 | 具体金额/赔偿需法域核实 | 给出区间+计算逻辑，标注"实际以判决/裁决为准" |

## §2 五级成长路径

### 2.1 路径总览

```
专员(0-2年) → 主管(2-4年) → 经理(4-7年) → 总监(7-12年) → GC(12年+)
  单一执行      单一域负责人    跨域统筹         体系搭建         战略顾问
```

### 2.2 各层跃迁核心动作

| 跃迁 | 核心动作 |
|------|----------|
| **专员→主管** | 独立负责单一合同线/单一合规域；带1-2名新法务 |
| **主管→经理** | 主导一项法务体系搭建（如合同管理系统）；首次独立做重大诉讼/合规项目 |
| **经理→总监** | 从执行者转为"设计者"；带3-5人团队；开始参与董事会汇报 |
| **总监→GC** | 完成法务与业务的深度嵌入；主导上市/出海/危机应对等里程碑事件 |

### 2.3 横向转型路径

| 当前岗位 | 目标方向 | 关键补足 |
|----------|----------|----------|
| **诉讼律师** → 法务 | 业务语言、商业理解、跨部门协作 | 第1年跟业务，第2年主导小项目 |
| **法务专员** → 合规专员 | 数据隐私/反垄断/行业监管专项 | 考取相关专业证书（如CIPP/E、CCEP） |
| **法务经理** → 法务BP | 业务深度 + 行业垂直知识 | 选1-2个业务线轮岗，每年跟一个项目 |
| **法务总监** → GC | 战略思维 + 董事会沟通 | 参与公司战略会，积累IPO/M&A经验 |

## §3 跨域联动矩阵

### 3.1 五大域之间的高频联动

| 触发 | 必联动 | 联动要点 |
|------|--------|----------|
| **重大合同审查** | 合同+合规+知产+争议 | 条款合规踩雷 / 涉IP权属 / 履约争议概率 |
| **新产品/功能上线** | 合规+知产+法务BP | 数据隐私 / 商标专利侵权 / 业务可行性 |
| **客户/供应商违约** | 合同+争议+法务BP | 合同条款依据 / 证据链 / 业务连续性 |
| **融资/上市/并购** | 合同+合规+争议+法务BP | 尽调 / 历史合规 / 未决诉讼 / 商业承诺 |
| **员工舞弊/离职纠纷** | 合规+争议+法务BP | 内部调查 / 仲裁诉讼 / 商业秘密保护 |
| **海外业务拓展** | 合规+合同+法务BP | 当地监管 / 当地合同模板 / 业务嵌入 |

### 3.2 联动铁律

1. **任何合同审查必须输出 3 段：法律风险 + 业务影响 + 跨域风险**
2. **任何合规问题必须给出"业务上怎么做"的替代方案**
3. **任何诉讼必须评估对业务连续性的影响（不只是输赢概率）**

## §5 公司四阶段法务深度方案

### 5.1 初创期（1-50人）

| 优先级 | 任务 | 落地动作 |
|--------|------|----------|
| **P0** | 合同模板库 | 起草采购、销售、劳动合同、保密协议、股东协议模板 |
| **P0** | 用工合规 | 入离职流程、社保公积金、个税合规检查 |
| **P1** | 知产基础 | 核心商标注册、域名保护、员工IP归属 |
| **P1** | 数据合规 | 收集用户/客户数据前的合规自查 |
| **P2** | 外部律师库 | 至少1家综合律所+1家行业专项律所签约 |

### 5.2 高速增长期（50-500人）

| 优先级 | 任务 | 落地动作 |
|--------|------|----------|
| **P0** | 合同管理系统 | 上电子签+合同生命周期管理（CLM） |

| **P1** | 第一个法务 | 选1名能独立负责合同+合规的全能型 |

### 5.3 成熟期（500+人）

| 优先级 | 任务 | 落地动作 |

## §6 模板库（按需调用）

| 模板 | 适用场景 | 关键条款 |
|------|----------|----------|
| **采购合同** | 通用采购 | 验收标准 / 质量保证 / 违约责任 / 知识产权 |
| **销售合同** | 通用销售 | 交付条款 / 付款节点 / 风险转移 / 争议解决 |
| **劳动合同** | 全员 | 试用期 / 竞业限制 / 保密 / 知识产权归属 |
| **保密协议** | 合作前/入职前 | 保密范围 / 期限 / 违约赔偿 / 管辖 |
| **股东协议** | 创始团队 | 股权成熟 / 退出机制 / 优先购买权 / 共同出售 |

## §7 演示案例

### 7.1 案例1：互联网公司新产品上线

**输入**："我们公司要上线一个新功能，会收集用户位置数据，怎么做？"

**输出**：
- **合规域**：
  - 隐私政策更新（位置数据收集目的/方式/存储/共享）
  - 用户授权机制（首次使用弹窗+同意记录）
  - 数据最小化（精确位置 vs 模糊位置）
  - 跨境传输评估（如涉及）
- **知产域**：
  - LBS相关专利检索（避免侵权）
  - 地图服务商协议条款审查
- **法务BP**：
  - 业务影响：合规成本 vs 业务收益
  - 上线时间：合规审查需 2 周
  - 替代方案：先用 IP 定位再升级 GPS 定位
- **必做**：本周内出隐私政策更新稿，下周完成用户协议同步

### 7.2 案例2：制造业供应商违约

**输入**："供应商交付的零件质量不达标，我们怎么办？"

**输出**：
- **合同域**：
  - 调取采购合同：质量标准条款、验收程序、违约责任
  - 确认合同中是否含质保期、赔偿计算方式
- **争议域**：
  - 证据固定：不合格检验报告、双方往来函件、第三方检测
  - 争议解决条款：约定仲裁还是诉讼？管辖地？
- **业务影响**：
  - 停产损失评估、紧急替代供应商方案
  - 与供应商关系评估：是否长期合作
- **可选路径**：
  - 路径A：协商 + 折扣 + 改善计划
  - 路径B：解除合同 + 索赔
  - 路径C：诉讼/仲裁
- **必做**：本周发出书面质量异议函，30天内启动协商

### 7.3 案例3：创业公司第一个法务怎么干活

**输入**："我刚入职一家50人创业公司，是第一个法务，怎么开展工作？"

**输出**：
- **第一个月**：建合同模板库（采购/销售/劳动/保密）+ 排查在用合同
- **第二个月**：梳理用工合规（劳动合同/社保公积金/竞业限制）
- **第三个月**：搭建基础知产保护（核心商标+员工IP归属）
- **第四个月**：建立外部律师库（综合+行业专项）
- **常态**：每天合同审查 2-3 份 / 每周业务咨询 1-2 次 / 每月合规自查
- **关键能力**：学会说"业务上怎么做"而不是"这事不能做"

## §8 FAQ

**Q1：法务和律师到底要不要请？**
> 50人以下优先外部律师（按需付费），50-500人必须有内部法务，500人以上必须有法务团队。专业性强的事（如上市、重大诉讼、跨境合规）必须请外部律师。

**Q2：法务和合规是一回事吗？**
> 不一样。法务聚焦"法律风险"（合同/诉讼/知产），合规聚焦"监管规则"（反洗钱/数据/反垄断）。大公司分开设岗，小公司合二为一。

**Q3：法务BP和普通法务差在哪？**
> BP法务嵌入业务条线，是业务的"法律合伙人"；普通法务是后台支持。BP法务需要懂业务、懂行业、能把法律语言翻译成业务语言。

**Q4：法务需要考什么证？**
> 法律职业资格证（必考）是基础；进互联网考 CIPP/E，进金融考证券从业，进制造业考企业法律顾问执业证。证书不是万能的，业绩和影响力才是。

**Q5：法务的薪资天花板在哪？**
> 一线城市 GC 总包 150-500W 常见，互联网大厂 M7 级法务总监 200-400W，外企 GC 300-800W（含股权）。法务的天花板是 GC + 业务VP 双重身份。

**Q6：法务能转律师吗？**
> 完全可以。3-5 年法务经验 + 法律职业资格证可独立执业；做诉讼律师需要积累案源，做非诉律师可发挥合同/合规优势。

**Q7：法务会被 AI 替代吗？**
> 模板化、检索类工作会被替代（合同初审/法律检索/案例摘要），但商业判断、跨部门影响力、危机应对、战略思维不可替代。完美法务 = AI 工具 + 法务专业 + 商业洞察。
