## 能为你做什么（增值税法落地四大场景）
---

### 一、应税交易识别与税目适用
- 🧾 **概念重构**：以"应税交易"取代原应税行为，按业务实质准确识别销售货物/服务/无形资产/不动产并适用税率
- 📊 **税目复核**：避免业务实质与税目税率不匹配导致的少缴或多缴
- ⚠️ **高频风险**：税目适用错误、视同应税交易（代销等）漏确认销项

**典型问法：**
```
"增值税法应税交易怎么理解？"
"增值税税目适用要注意什么？"
```

### 二、进项抵扣与数电票合规
- 💱 **合规抵扣**：贷款服务、餐饮娱乐等不得抵扣项目须剔除；数电票须查验后抵扣
- 🔍 **风险防范**：取得不合规数电票、虚开专票导致进项转出与补税
- 🛡️ **留抵退税**：常态化退还机制下，确保进销项真实，防范骗取退税刑事风险

**典型问法：**
```
"数电票进项抵扣要注意什么？"
"留抵退税怎么防范骗退风险？"
```

### 三、混合销售与兼营分别核算
- 🧮 **规则法定化**：混合销售按主要业务适用税率；兼营须分别核算，否则从高适用
- 📑 **合同修订**：按应税交易概念重梳合同涉税条款与定价模型
- 🔗 **内控更新**：建立数电票全生命周期管理（开具、接收、查验、抵扣、归档）

**典型问法：**
```
"混合销售和兼营有什么区别？"
"兼营没有分别核算会怎样？"
```

### 四、登记、起征点与优惠衔接
- 📋 **一般纳税人登记**：年应税销售额超小规模标准应登记，自然人及不经常发生应税交易的非企业单位可不办
- 📈 **起征点调整**：自然人按次纳税起征点提高，部分出租情形参照按期纳税标准
- 🔄 **优惠衔接**：梳理现有减免税政策衔接，放弃优惠须合规处理

**典型问法：**
```
"一般纳税人登记标准是什么？"
"增值税法起征点有什么变化？"
```

## 重要提示与边界声明

**重要提示**
1. **税目适用须准**：以应税交易概念按业务实质识别税目税率，避免少缴或多缴。
2. **进项须合规**：不得抵扣项目须剔除，数电票须查验，防范虚开与骗退风险。
3. **留抵退税须真实**：进销项须真实，杜绝虚构进项或隐匿收入申请退税。
4. **数据以官方为准**：增值税法配套公告时效性强，具体适用请核验最新文件与主管税务机关口径。

**边界（本技能不做的）**
- **不代办**：纳税申报填报、发票开具系统操作等需登录系统的事项
- **不代理**：税务鉴证、法律尽调等需执业资质的事务
- **不担保**：税目适用、稽查定性等争议区最终以财政、税务机关或司法机关认定为准

- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告
