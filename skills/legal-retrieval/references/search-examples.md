# 法规检索 CLI 场景指南

本指南承接 `legal-retrieval` 的可变命令示例、参数组织和结果映射。使用前必须先执行 [cli-common.md](./cli-common.md) 中的前置检查和命令发现步骤。

## 一、CLI 命令使用原则

1. 先用 `npx @delilegal/deli-cli@latest cmds legal-retrieval@1.0.0` 获取本次 `RUN id`、命令名和参数。
2. 后续调用必须采用当次返回的 `npx @delilegal/deli-cli@latest run_... <command> [options]` 形态。
3. 不在本指南中固化真实命令名；以下示例中的 `law-list`、`law-search`、`law-compare`、`law-verify` 仅表示可能的命令类型，实际以 `cmds` 输出为准。
4. 检索参数优先在 `cmds` 返回的 `usage` 和 `params` 中选择，不主动假设 `--semantic`、`--query`、`--page`、`--size` 或排序参数一定存在。
5. 一个检索目标默认只调用一次；结果不足时先说明不足，并提出建议改写检索式，等待用户确认。
6. 当用户提供自然语言法律问题、法律场景、事实经过、争议点、材料摘要或条文适用问题，且 `cmds` 同时支持 `--semantic` 和 `--query` 时，首次必须使用 `--semantic`；不得先执行 `--query` 或多组关键词预检索。
7. 语义检索已有有效命中时，停止继续检索；不得再拆成关键词追加调用。
8. 检索调用会产生用户成本；除用户确认重试、翻页或要求更多结果外，不自动追加 CLI 调用。

示例 `cmds` 返回后，实际调用可能形如：

```bash
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 law-list --semantic "用人单位解除劳动合同时，劳动者请求经济补偿的法律依据"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 law-list --query "竞业限制 补偿金"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 law-verify --query "中华人民共和国合同法"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 law-compare --query "民法典 违约金"
```

以上仅为参数组织示例。正式执行时必须替换为当次 `cmds` 返回的 `run_...`、命令名和参数。

## 二、检索文本组织

### 语义或自然语言问题

适用于：

- 法律场景、争议事实、材料摘要
- 用户不知道具体法规名称
- 用户提出条号、款号、项号问题，需要保留完整语义关系
- 需要根据主体关系、行为类型和法律后果匹配条文

组织规则：

- 建议 50-800 字。
- 包含主体、行为、约束、争议点和查询目标。
- 不拆成多个泛化关键词。
- 将自然语言问题直接传给 `--semantic`、语义检索或自然语言问题参数；不要先拆成 `--query`。
- 如果 `--semantic` 返回有效结果，不再执行关键词检索。

示例：

```text
用人单位解除劳动合同时，劳动者请求经济补偿的法律依据。
公司安排员工在工作日和周末长期加班，但没有支付加班费，员工想查询工资支付、加班费计算、劳动监察和劳动仲裁相关法规依据。
互联网平台收集用户手机号、身份证号和定位信息，用于账号注册、风控和营销推送，想查询个人信息处理告知同意、最小必要和敏感个人信息保护要求。
```

### 关键词或短主题

适用于：

- 明确法规名称
- 明确短主题词
- 时效核实目标
- 用户只需要某个制度主题下的法规列表

组织规则：

- 控制为最有区分度的短主题。
- 不主动加入“现行有效”“有效”“失效”“废止”“时效”等状态词。
- 不把多个法规或多个问题塞进一次检索。

示例：

```text
中华人民共和国合同法
竞业限制 补偿金
数据安全
民法典 合同编
```

## 三、典型场景

### 1. 法规依据查询

用户输入：

```text
用人单位解除劳动合同时，经济补偿有什么法律依据
```

处理：

1. 抽取主体关系、行为和查询目标。
2. 优先构造自然语言法律问题。
3. 若 `cmds` 支持 `--semantic`，直接执行一次语义检索。
4. 只有语义参数不可用时，才降级为一个短主题检索；降级时说明原因。
5. 根据 CLI 返回结果核对法规名称、条款号和时效状态。

建议检索问题：

```text
用人单位解除劳动合同时，劳动者请求经济补偿的法律依据。
```

### 2. 时效核实

用户输入：

```text
合同法现在还有效吗？
```

处理：

1. 将简称映射为标准全称：中华人民共和国合同法。
2. 用时效核实或法规检索命令执行一次检索。
3. 根据 CLI 返回的时效字段或文本说明当前状态、废止或替代信息。
4. 若 CLI 未返回替代文件，不要自行补写；标注“待核验”。

建议检索主题：

```text
中华人民共和国合同法
```

### 3. 法规对比

用户输入：

```text
对比一下民法典和合同法关于违约金的规定
```

处理：

1. 抽取法规 A、法规 B 和对比维度。
2. 若 `cmds` 返回对比命令，按对比参数调用。
3. 若仅返回法规检索命令，分别围绕两个法规形成检索主题；多次调用前应确认用户确实要求对比。
4. 只基于 CLI 返回结果写原文、差异和结论。

建议检索主题：

```text
民法典 违约金
合同法 违约金
```

### 4. 结构化筛选

用户输入：

```text
找一下关于竞业限制的所有现行有效法规
```

处理：

1. 抽取主题为竞业限制，关注状态为现行有效。
2. 检索主题只保留实质检索词，不把“现行有效”塞进关键词。
3. 检索后根据 CLI 返回的时效状态筛选和说明。

建议检索主题：

```text
竞业限制
```

### 5. 语义泛搜

用户输入：

```text
公司不给加班费怎么办
```

处理：

1. 识别为劳动者与用人单位之间的加班工资争议。
2. 构造自然语言法律问题，覆盖工资支付、加班费、劳动监察和劳动仲裁。
3. 若 `cmds` 支持 `--semantic`，直接执行一次语义检索，不先拆分“加班费 工资支付 劳动监察 劳动仲裁”等关键词。
4. 输出法规依据和维权路径时，区分 CLI 返回依据与一般提示。

建议检索问题：

```text
劳动者已经实际加班，但用人单位拒绝支付加班费，想查询工资支付、加班费计算、劳动监察和劳动仲裁相关法规依据。
```

### 6. 翻页或查看更多

用户输入：

```text
再查更多
```

处理：

1. 先说明继续查看会产生一次新的 CLI 调用。
2. 用户确认后，沿用上一轮检索条件。
3. 按 `cmds` 当前返回的分页参数形态请求下一页或更多结果。

## 四、CLI 返回结果映射

将 CLI 返回内容写入最终答复时，优先保留：

- 法规名称
- 条款号、款号、项号
- 效力级别
- 发文机关
- 发布日期、生效日期、废止日期
- 时效状态
- 条文原文或内容摘要
- 废止、修订或替代文件信息
- 数据来源或收录说明

如果 CLI 未返回某字段，不要补写。可标注“CLI 未返回”或省略该列。

## 五、无结果或结果不足

出现无结果、结果明显失焦、字段缺失或命令不可用时：

- 标注“检索受限”“结果不足”或“命令不可用”。
- 给出一个建议改写的检索主题或自然语言问题。
- 不自动连续换词重试。
- 不编造法规名称、条文原文、发文机关、废止日期、替代文件或时效状态。
