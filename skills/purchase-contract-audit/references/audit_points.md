# 采购合同审核要点清单（甲方视角·完整版）

本文档详细列出了采购合同审核的关键要点，供审核时参考使用。**审核视角为甲方（采购方/买方）**，从甲方利益出发识别风险。

**新增功能**：
1. **采购类型自动识别**：货物类/工程类/服务类/混合类
2. **分类专项审核规则**：不同类型适用不同的审核重点和法律依据
3. **完整法律依据**：引用《民法典》《招标投标法》《政府采购法》《建筑法》《产品质量法》等

---

## 〇、采购类型识别规则（审核第一步，必须执行！）

### 类型判断关键词

| 采购类型 | 核心关键词 | 辅助关键词 |
|---------|----------|-----------|
| **货物类** | 采购、购买、供货、销售、买卖 | 设备、材料、产品、硬件、软件许可、备品备件 |
| **工程类** | 施工、建设、安装工程、装修、改造 | EPC、总承包、分包、竣工、工期、工程量清单 |
| **服务类** | 技术服务、咨询服务、开发服务、设计服务 | 运维、外包、培训、人力、SLA、服务水平 |

### 判断优先级

1. **优先匹配工程类**：出现"施工""建设""装修""EPC""总承包""竣工""工程量" → **工程类**
2. **其次匹配服务类**：出现"技术服务""咨询""开发""设计""运维""外包"且主给付为劳务/智力成果 → **服务类**
3. **默认货物类**：以实物交付为主，含明确设备清单/材料清单/产品规格表 → **货物类**
4. **混合类型处理**：
   - 货物+安装调试 → 按主给付义务判断，通常为**货物类**（附带安装服务）
   - 工程+材料采购 → 按主给付义务判断，通常为**工程类**（包工包料）
   - 货物+长期运维 → 分别审核，标注为**混合类（货物+服务）**

### 判断结果应用

- 确定类型后，在审核报告"合同要点总结"最前面增加"采购类型"行
- 同时加载对应类型的专项审核规则（本文档第三至五章）
- 分类专项字段必须体现在合同要点总结表中

## 一、审查总体目标（优先级顺序）

审查采购合同时，应依次判断以下四个层面（从甲方视角）：

1. **合法性**：条款是否违反《民法典》《招标投标法》《政府采购法》《建筑法》《产品质量法》《安全生产法》《保障农民工工资支付条例》等强制性规定？（最高优先级）
2. **可执行性**：条款在司法实践中是否可能被认定无效或不被支持？
3. **风险可控性**：甲方与乙方的权利义务是否实质对等？是否存在对甲方不利的单方陷阱？
4. **商业目标匹配**：条款是否保障甲方按时按质获得合格产品/服务/工程？

## 二、合同要点总结字段要求

### 通用必需字段（所有类型）

| 字段 | 说明 | 审核要点 |
|------|------|----------|
| **采购类型** | 货物类/工程类/服务类/混合类 | **审核第一步必须判断，标注判断依据** |
| 合同主体 | 甲方（买方）、乙方（卖方/承包方/服务方） | 确认乙方主体资质、经营范围、履约能力 |
| 合同标的 | 产品/服务/工程内容 | 规格型号是否唯一可量化，避免模糊表述 |
| 合同金额 | 金额及是否含税 | 价格是否合理、含税、有无隐藏费用 |
| **付款方式** | 付款条件（预付款比例、时间节点、验收款、质保金等） | 预付款比例是否过高（资金安全），付款节点是否与履约进度匹配，**付款金额与发票金额是否一致** |
| **发票要求** | 每个阶段需提供的发票类型和金额 | 发票是否及时开具，内容是否合规 |
| **合同变更** | 变更原则和变更计价方式 | **可选展示**：只有合同中包含明确的变更条款（变更程序、审批要求、计价方式等）时才展示此项。合同无变更条款则不展示。甲方是否有变更审批权，变更计价方式是否合理 |
| **交付时间** | 交付期限及起算条件 | 必须明确交付时间，逾期交付是否有违约金保障 |
| **验收标准** | 验收标准、流程、期限 | 标准是否量化可执行，甲方是否有充分验收权 |
| **质保期** | 质保期限及起始条件 | 质保期是否足够长，起算时间是否合理（验收合格后起算对甲方更有利） |
| **履约担保** | 履约保证金/保函 | **工程类必须有**，货物类/服务类视情况 |
| 合同生效条件 | 合同生效的条件 | 签字盖章后生效（标准商业惯例） |
| 合同终止条件 | 合同终止的条件和方式 | 甲方是否有充分的合同解除权 |
| **争议解决** | 管辖约定及管辖地 | **甲方所在地优先** |
| **违约责任** | 双方违约责任概述 | 乙方违约责任是否充分保障甲方权益 |
| **违约责任** | 发票违约责任 | 乙方未按期提供发票、发票不合规的责任 |
| **违约责任** | 单边违约风险判断 | 是否存在只对甲方不利的单边违约条款 |
| **知识产权** | 成果归属 | 采购/开发成果的知识产权是否归甲方所有 |
| **保密条款** | 保密义务 | 乙方保密义务是否充分、保密期限是否合理 |

### 货物类专项字段

| 字段 | 说明 | 审核要点 |
|------|------|----------|
| **所有权转移** | 货物所有权转移时点 | 应在验收合格后转移，《民法典》第604条风险承担规则 |
| **运输与保险** | 运输方式、风险承担 | 交付前风险由乙方承担 |
| **包装标准** | 包装要求和标准 | 应符合国家/行业标准，防止运输损坏 |
| **知识产权保证** | 产品不侵犯第三方知识产权 | 乙方应保证并承担侵权赔偿责任 |
| **备品备件** | 是否包含备品备件 | 关键设备应包含 |

### 工程类专项字段

| 字段 | 说明 | 审核要点 |
|------|------|----------|
| **工期及节点** | 开工日期、竣工日期、中间节点 | 必须明确，逾期违约金充分 |
| **履约保函** | 履约保证金/银行保函 | 比例不低于合同价5%，《招标投标法实施条例》第58条 |
| **质量标准** | 工程质量标准 | 明确引用国家/行业标准（GB/GBJ等） |
| **安全生产** | 安全生产责任 | 乙方负总责，《建筑法》第45条、《安全生产法》 |
| **农民工工资** | 农民工工资保障 | 必须约定专用账户、工资保证金，《保障农民工工资支付条例》第26条 |
| **分包管理** | 分包条件及审批 | 分包须甲方书面同意，禁止转包，《建筑法》第29条 |
| **竣工验收** | 竣工验收程序 | 明确验收标准、程序、整改期限 |
| **质量保修** | 工程质量保修范围和年限 | 地基基础和主体结构最低保修年限为设计文件规定的工程合理使用年限，《建设工程质量管理条例》第40条 |

### 服务类专项字段

| 字段 | 说明 | 审核要点 |
|------|------|----------|
| **服务标准/SLA** | 服务水平协议 | 响应时间、解决时间、可用率等必须量化 |
| **人员资质** | 服务人员要求 | 资质、经验、替换条件 |
| **知识产权** | 服务成果知识产权 | 应归甲方所有（尤其定制开发） |
| **保密与数据安全** | 数据保护义务 | 乙方不得泄露甲方数据，《个人信息保护法》 |
| **服务验收** | 服务验收标准 | 可量化的交付成果和验收标准 |

## 三、通用审查维度与法律要点

### 1. 合同主体与资信（甲方视角）

**审查要点**：
- 乙方是否为合法存续的法人，经营范围是否覆盖合同标的
- **统一社会信用代码**（必须核查）：甲乙双方应在合同中明确标注统一社会信用代码，用于核实企业合法存续状态
- **乙方资质**（重要！）：工程类需核查建筑业企业资质等级；服务类需核查相关专业资质
- **乙方成立年限**：供应商应成立1年以上，不足1年可能缺乏履约经验（重大采购项目应审慎评估）
- **乙方履约能力**：财务状况、过往业绩、技术能力
- **乙方涉诉/被执行情况** - 通过中国执行信息公开网、信用中国等核查
- 乙方签约代表权限是否充分
- **法律依据时效性**：合同中不得引用已废止的《合同法》，应引用《民法典》相关条款

**法律依据**：
- 《民法典》第143条：民事法律行为有效的条件
- 《民法典》第170条：法人工作人员执行职务的民事法律行为效力
- 《建筑法》第12条：从事建筑活动的企业资质要求
- 《招标投标法》第26条：投标人资格条件
- 《公司登记管理条例》第2条：统一社会信用代码制度

**甲方风险**：乙方不具备履约能力/资质 → 项目失败或质量不达标；签约代表无授权 → 合同效力待定；供应商成立不足1年 → 履约经验不足；引用已废止法律 → 合同效力存疑

---

### 2. 标的物与规格

**审查要点**：
- 产品名称、品牌、型号、数量、技术参数、质量标准必须**唯一、可量化**
- **禁止"同等质量""类似品牌"等模糊表述**（乙方可能以次充好）
- 乙方须保证对所售货物拥有完整所有权，且不侵犯第三人知识产权
- 知识产权侵权责任应由乙方承担

**法律依据**：
- 《民法典》第596条：买卖合同的内容
- 《民法典》第612条：出卖人权利瑕疵担保义务
- 《产品质量法》第26条：产品质量要求
- 《产品质量法》第41条：产品缺陷责任

**甲方风险**：标准不明 → 乙方交付不合格产品难以追责；知识产权瑕疵 → 甲方被第三方追诉

---

### 3. 交付与风险转移

**审查要点**：
- **交付时间**：必须明确具体交付期限，区分"工作日""自然日"
- **延期交付违约金**：必须约定乙方延期交付的违约金比例及上限
- **验收标准与流程**（关键！）：
  - 设定明确的验收标准、验收流程和验收期限
  - 甲方应有充分的验收权，包括但不限于到货验收、安装调试验收、试运行验收
  - 验收不合格的，乙方应限期整改，整改后仍不合格的甲方有权解除合同
- **交付地点**：明确交货地点
- **分批交付**：若分批交付，每批的交付时间和验收标准应明确

### 3.5 验收规则（两段时限！）

**审查要点**：
- **两段时限**（重要！）：
  1. **收货后验收期限**：甲方应在收到货物后明确约定的期限内完成外观及数量验收
  2. **质量异议期**：甲方应在货物投入使用或发现质量问题后明确约定的期限内向乙方提出质量异议
- **验收凭证**：甲方签收的验收单仅作为"表面检查材料"的证明，不代表对货物内在质量的认可，不能免除乙方提供质量证明材料的义务
- **不合格处置**：验收不合格的，乙方应承担退换货、赔偿损失等责任
- **质保期起算**：质保期应从**验收合格之日起**计算，而非从交付之日起计算
  - "自验收合格之日起" → 对甲方有利
  - "自交付之日起" → 对甲方不利（可能提前消耗质保期）

**法律依据**：
- 《民法典》第620条：买受人的检验义务
- 《民法典》第621条：买受人检验期限
- 《民法典》第617条：出卖人质量瑕疵担保义务

**甲方风险**：未约定两段验收时限 → 甲方权利无法保障；验收凭证约定不清 → 难以证明货物质量问题；质保期起算点不利 → 质保期过早届满

**法律依据**：
- 《民法典》第604条：标的物毁损灭失风险承担
- 《民法典》第620条：买受人的检验义务
- 《民法典》第621条：买受人检验期限

**甲方风险**：交付时间不明 → 项目延期无法追责；验收标准缺失 → 接受不合格产品

---

### 2.5 签署地点（新增重点！）

**审查要点**：
- 合同签署地点应精确约定至**县级市/区**级别
- 精确的签署地点约定是确定管辖法院的重要依据之一
- 签署地点模糊（如仅写"某省某市"）可能导致管辖约定不明确

**法律依据**：
- 《民事诉讼法》第35条：协议管辖可选择合同签订地法院
- 《民法典》第493条：合同成立地点的认定

**甲方风险**：签署地点约定不精确 → 管辖约定存在争议风险

---

### 4. 价格与支付（重点！）

**审查要点**：
- **价格是否含税**？是否为全包价？是否包含运输费？
- **付款条件**（必须详细审核）：
  - **预付款比例不宜过高**（建议不超过30%），降低甲方资金风险
  - 付款节点应与乙方履约进度匹配，**避免提前支付大额款项**
  - 每次付款前必须确认乙方已完成对应阶段的工作
  - **必须保留质保金**（建议5%-10%），质保期满后支付
  - **先货后款**：甲方先收货，乙方后收款，避免先款后货风险
  - **分期付款**：大额采购建议分3-4期付款（预付款+到货款+验收款+质保金）
- **避免"背靠背"付款被滥用**：若存在背靠背条款，应明确其适用条件和救济措施
- **付款与发票金额一致性**：每次付款金额应与乙方提供的发票金额一致

**法律依据**：
- 《民法典》第526条：先履行抗辩权
- 《保障中小企业款项支付条例》第8条：付款期限要求

**甲方风险**：预付款过高 → 乙方收款后履约不力；付款与进度不匹配 → 甲方丧失制约手段；付款先于收货 → 甲方资金损失风险

---

### 5. 售后服务与质保（关键！）

**甲方视角核心原则（重要！）**：
- **"自验收合格之日起"起算质保期对甲方有利**：质保期从项目实际可用时开始计算
- **"自交付之日起"起算质保期对甲方不利**：可能出现安装调试未完但质保期已开始消耗的情况

**审查要点**：
- **质保期起算点**（必须明确！）：
  - **有利于甲方：**"**自验收合格之日起**"——质保期从项目可用时开始
  - **不利于甲方：**"**自交付之日起**"或"**自提交验收申请之日起**"——可能提前消耗质保期
- **质保期时长**：是否足够覆盖项目使用周期
- **质保范围**：是否包含人工费、上门费、备件费、软件升级
- **维修响应时限**：是否具有商业可行性（如24小时响应、48小时到达现场）
- **质保期后服务**：是否约定质保期后的服务内容和费用标准

**法律依据**：
- 《民法典》第617条：出卖人质量瑕疵担保
- 《产品质量法》第40条：销售者修理更换退货责任
- 《建设工程质量管理条例》第40条：最低保修期限

**甲方风险**：质保期过短或起算点不合理 → 项目使用早期即失去售后保障

---

### 6. 违约责任（必须详细审核！）

**甲方视角核心原则（关键！）：**
- **对甲方有利的违约责任条款 = 甲方的保障，不是风险**
- **乙方违约金高是对甲方履约保障，不应标记为风险点**

#### 6.1 乙方违约责任（甲方保障）
- **乙方逾期交付的违约金**：是否约定？比例是否足够威慑？（建议不低于每日万分之五）
- **乙方质量不合格的违约责任**：是否明确维修、更换、退货、赔偿条款
- **乙方违约金上限**：不宜过低，应保留甲方充分索赔权
- **乙方应对其分包商/供应商的行为承担全部责任**

#### 6.2 甲方违约责任（合理控制）
- 甲方逾期付款违约金应控制在合理范围
- 甲方违约责任不应过重，应限于直接损失
- 甲方应保留合理的合同解除权

**法律依据**：
- 《民法典》第577条：违约责任一般规定
- 《民法典》第584条：损害赔偿范围
- 《民法典》第585条：违约金调整规则（违约金过高可请求减少，违约金低于损失可请求增加）
- 《民法典》第563条：合同法定解除权

#### 6.3 乙方违约责任保障要点
- 乙方延期交付：明确违约金比例和上限
- 乙方质量违约：明确整改、退货、赔偿条款
- 乙方擅自转包/分包：明确违约责任
- 乙方泄密/侵权：明确赔偿责任
- **分情形违约金**：不同违约情形（逾期交付、质量不合格、侵权等）应分别约定违约金，避免混同
- **损失赔偿范围**：明确乙方违约造成甲方损失时的赔偿范围（直接损失、可得利益损失等）
- **单方解除合同权**：明确甲方的单方解除合同权利及触发条件
- **瑕疵补救**：明确乙方在发现质量问题时的瑕疵补救义务
- **第三方损失**：明确乙方造成第三方损失时的责任承担
- **违约金抵扣**：明确甲方可直接将乙方应付违约金从应付款项中抵扣，无需乙方同意

#### 6.4 发票违约责任
**必须审核并列出以下发票相关违约责任**（从合同原文引用）：
- 乙方未按期提供发票的责任
- 乙方提供发票不合规的责任
- 乙方未正常纳税导致甲方无法抵扣的责任

#### 6.5 发票开具细节（新增重点！）

**审查要点**：
- **开票主体信息**：乙方提供的发票必须包含完整的开票主体信息（名称、统一社会信用代码、开户行、账号、地址电话）
- **发票类型**：应明确约定开具增值税专用发票还是普通发票
- **开票时间**：应明确约定每个付款节点乙方开具发票的时间要求
- **发票内容**：发票内容应与合同标的一致，不得开具与实际交易不符的发票
- **异常发票处理**：如收到异常发票（如发票代码密度异常等），乙方应配合甲方换开正常发票

**法律依据**：
- 《增值税暂行条例》第9条：增值税扣税凭证
- 《发票管理办法》第22条：开具发票的要求

**甲方风险**：发票信息不完整 → 甲方无法正常抵扣；发票类型不符 → 税务风险；收到异常发票 → 税务稽查风险

#### 6.6 审减条款（政府投资项目重点！）

**审查要点**：
- **适用范围**：审减条款主要适用于政府投资项目中的配套采购或追加采购
- **同比例核减**：如政府投资项目的配套采购需进行审计，乙方应同意甲方按审计结果同比例核减合同金额
- **审减期限**：应明确约定接受审计结果的时间期限，避免无限期拖延
- **审减风险**：审减条款可能影响乙方的合同收益，乙方应在报价时考虑此风险

**法律依据**：
- 《审计法》第22条：政府投资项目审计
- 《政府采购法》第50条：采购合同的变更

**甲方风险**：未约定审减条款 → 政府投资项目审计后可能面临合规性风险

#### 6.5 单边违约风险判断（重要！）
**从甲方视角判断"单边违约风险"**：

| 风险类型 | 判断标准 | 风险等级 |
|---------|---------|---------|
| **乙方违约责任过轻** | 乙方违约（如逾期交付）无对应违约责任或责任极轻 | 高风险 |
| **甲方违约责任过重** | 甲方违约金比例高于乙方，或甲方违约后果严重于乙方 | 中风险 |
| **单边解除权** | 乙方有权任意解除合同，但甲方无对等解除权 | 高风险 |
| **乙方履约义务模糊** | 乙方交付标准、验收标准不明确 | 中风险 |
| **甲方违约责任无上限** | 甲方违约责任未设置上限 | 中风险 |

#### 6.6 合同变更原则审核
- 甲方是否有变更审批权
- 变更计价方式是否合理
- 变更程序是否明确

---

### 7. 知识产权

**审查要点**：
- 采购/开发过程中产生的技术成果、软件著作权、专利等知识产权归属是否明确
- **知识产权应归甲方所有**（尤其是定制开发项目）
- 若知识产权归乙方，甲方至少应获得永久、免费、不可撤销的使用许可
- 乙方应保证其产品/服务不侵犯第三方知识产权
- **成果归属甲方**（重要！）：合同中应明确约定乙方为甲方完成的开发成果（包括但不限于源代码、设计文档、技术方案等）归甲方所有
- **侵权责任兜底**（重要！）：乙方应保证其提供的产品/服务不侵犯任何第三方知识产权，如发生第三方侵权索赔，乙方应承担全部赔偿责任，包括但不限于甲方因此支付的和解金、赔偿款、律师费等

**法律依据**：
- 《民法典》第861条：技术开发合同成果归属（委托开发）
- 《民法典》第876条：技术转让/许可的侵权责任
- 《专利法》第11条：专利侵权责任

**甲方风险**：知识产权不明确 → 甲方后续使用受限或被第三方追诉；无侵权责任兜底 → 甲方承担第三方追诉损失

---

### 8. 保密条款

**审查要点**：
- 乙方保密义务的范围是否充分覆盖甲方商业秘密
- **完整商业秘密范围**（重要！）：商业秘密的定义应完整，包括但不限于：技术信息（设计方案、源代码、技术参数、工艺流程）、经营信息（客户名单、报价策略、采购渠道、商业计划）、以及其他甲方标注"保密"或"机密"的信息
- **保密期限**（重要！）：保密期限应不少于**2年**，且在合同终止后仍持续有效
- 信息泄露的赔偿责任是否明确
- **保密义务主体**：乙方的董事、监事、高级管理人员及员工均应承担保密义务
- **保密措施**：乙方应采取与保护自身保密信息同等的保护措施保护甲方保密信息

**法律依据**：
- 《民法典》第501条：缔约过失责任中的保密义务
- 《反不正当竞争法》第9条：商业秘密保护
- 《反不正当竞争法》第17条：商业秘密侵权赔偿

**甲方风险**：保密义务不充分 → 甲方商业秘密泄露；保密期限过短 → 合同终止后商业秘密缺乏保护

---

### 9. 不可抗力

**审查要点**：
- 不可抗力的定义是否合理
- 发生不可抗力后通知义务是否明确
- 不可抗力持续期间的合同处理方式

**法律依据**：
- 《民法典》第180条：不可抗力的定义
- 《民法典》第590条：不可抗力的法律效果

---

### 10. 争议解决

**审查要点**：
- **管辖地优先级**：**甲方所在地法院/仲裁委 > 合同签订地 > 标的物所在地 > 乙方所在地**
- **选择仲裁还是诉讼**：仲裁一裁终局 vs 诉讼两审终审
- 仲裁机构的选择
- **二选一约定**（重要！）：争议解决条款应选择仲裁或诉讼其中一种方式，不得同时约定
- **禁止仲裁+诉讼同时约定**（重要！）：同时约定仲裁和诉讼可能导致争议解决条款无效
- 仲裁条款应明确仲裁机构名称（如"北京仲裁委员会"），避免仲裁机构约定不明

**法律依据**：
- 《民事诉讼法》第24条：合同纠纷管辖
- 《民事诉讼法》第35条：协议管辖（可选择被告住所地、合同履行地、合同签订地、原告住所地、标的物所在地等）
- 《仲裁法》第16条：仲裁协议的有效条件
- 《仲裁法解释》第7条：仲裁协议无效的情形

**甲方风险**：异地管辖 → 维权成本高昂；仲裁诉讼同时约定 → 条款可能无效

---

### 11. 合同生效与终止

**审查要点**：
- **生效条件**：签字盖章即生效为标准商业惯例
- **终止条件**：甲方是否保留充分的合同解除权
- **解除后果**：解除后乙方应退还款项、移交资料、承担违约责任

---

### 12. 解除条款

**审查要点**：
- **甲方解除权**应覆盖以下情形：
  - 乙方逾期交付超过约定期限
  - 乙方交付的产品/服务不合格且拒不整改
  - 乙方擅自转包/分包
  - 乙方丧失履约能力
  - 乙方严重违约
  - 乙方发生重大不利变化（破产、被吊销等）
- 解除通知的形式和送达方式应明确
- 解除后乙方的义务（退款、资料移交、保密等）应明确

**法律依据**：
- 《民法典》第563条：法定解除权
- 《民法典》第565条：解除权的行使
- 《民法典》第566条：合同解除的效力

---

## 四、货物类采购专项审核规则

### 4.1 所有权转移与风险承担

**法律依据**：
- 《民法典》第604条：标的物毁损、灭失的风险，在标的物交付之前由出卖人承担，交付之后由买受人承担
- 《民法典》第641条：所有权保留买卖

**审核要点**：
- 货物所有权转移时点：交付时/验收合格后/付款后？
- **建议**：约定验收合格后所有权转移
- 运输途中的风险承担应明确
- 是否约定所有权保留条款（对甲方不利！甲方应争取验收后即取得所有权）

**风险等级**：
- 约定"付款后转移所有权" → **中风险**（乙方未交付即要求付款）
- 约定"签收即转移所有权" → 低风险（可接受）

---

### 4.2 运输与保险

**审核要点**：
- 运输方式是否明确
- 运输费用由谁承担（通常含在合同总价中）
- **运输保险**：应由乙方购买运输保险，保险受益人为甲方
- 交货地点是否明确
- **风险转移时点**（关键！）：若由供货方负责运输，货物风险应在**送达并验收合格后**转移给甲方此前风险由乙方承担）
- 合同中应明确约定风险转移条款，避免到货后才发现货损责任归属不清

**法律依据**：
- 《民法典》第604条：标的物毁损灭失风险承担规则
- 《民法典》第607条：出卖人送货上门的风险转移

**风险**：运输中货物损坏 → 未约定保险则损失归属争议；风险转移时点不明 → 争议责任归属

---

### 4.3 包装标准

**审核要点**：
- 包装是否符合国家/行业标准
- 特殊货物（精密仪器、危险品等）是否有特殊包装要求
- 因包装不善造成的损失由乙方承担

---

### 4.4 知识产权保证

**审核要点**：
- **乙方保证**：所供产品不侵犯任何第三方知识产权
- **侵权责任**：若发生第三方知识产权侵权索赔，乙方应承担全部责任并赔偿甲方损失
- 软件产品：明确许可范围、使用人数、使用期限

**法律依据**：
- 《民法典》第612条：出卖人权利瑕疵担保义务

---

### 4.5 备品备件

**审核要点**：
- 关键设备是否包含备品备件
- 备品备件清单和数量是否明确
- 备品备件价格是否合理

---

## 五、工程类采购专项审核规则

### 5.1 工期管理

**法律依据**：
- 《民法典》第795条：建设工程合同内容（应包含工期）
- 《建设工程质量管理条例》第10条：不得压缩合理工期

**审核要点**：
- 开工日期、竣工日期是否明确
- 是否包含中间节点（基础完工、主体封顶等）
- 工期延误的违约金是否约定
- **甲方原因导致工期延误的，工期是否相应顺延**（对甲方有利）
- 不可抗力导致工期延误的处理

**风险等级**：
- 工期不明确 → **高风险**
- 无工期延误违约金 → **高风险**
- 工期延误违约金过低 → **中风险**

---

### 5.2 履约担保（必须！）

**法律依据**：
- 《招标投标法实施条例》第58条：履约保证金不得超过中标合同金额的10%
- 《民法典》第388条：担保合同

**审核要点**：
- **工程类采购必须约定履约担保**（履约保证金或银行保函）
- 履约担保金额：建议合同价的5%-10%
- 履约担保形式：银行保函优先（相比现金保证金，对双方更合理）
- 退还条件：竣工验收合格后退还
- 有效期：应覆盖整个施工期+缺陷责任期

**风险等级**：
- 工程类合同无履约担保 → **高风险**
- 履约担保比例过低（<5%）→ **中风险**

---

### 5.3 工程质量标准

**法律依据**：
- 《建筑法》第52条：建筑工程质量必须符合国家建筑工程安全标准
- 《建设工程质量管理条例》第40条：最低保修年限

**审核要点**：
- 工程质量标准是否明确引用国家标准（GB系列）
- 是否约定质量等级（合格/优良）
- 材料和设备的质量标准
- 隐蔽工程验收程序

---

### 5.4 安全生产（必须！）

**法律依据**：
- 《建筑法》第45条：施工现场安全由建筑施工企业负责
- 《安全生产法》第49条：发包方安全责任
- 《建设工程安全生产管理条例》

**审核要点**：
- 乙方对施工现场安全负总责
- 乙方应配备专职安全管理人员
- 乙方应购买建筑工程一切险和第三方责任险
- 安全事故的责任划分
- 甲方有权对乙方安全生产进行监督检查

**风险等级**：
- 安全生产责任不明确 → **高风险**
- 未约定保险要求 → **中风险**

---

### 5.5 农民工工资保障（工程类必须！）

**法律依据**：
- 《保障农民工工资支付条例》第26条：施工总承包单位应开设农民工工资专用账户
- 《保障农民工工资支付条例》第32条：工资保证金制度
- 《保障农民工工资支付条例》第30条：分包单位拖欠农民工工资的，由施工总承包单位先行清偿

**审核要点**：
- **必须约定**农民工工资专用账户
- **必须约定**工资保证金
- 乙方应按时足额支付农民工工资
- 乙方拖欠农民工工资的违约责任（甲方可从未付工程款中直接扣除）
- 乙方应每月向甲方提供农民工工资支付证明

**风险等级**：
- 工程类合同未约定农民工工资保障 → **高风险**（甲方可能承担连带责任）
- 约定不充分 → **中风险**

---

### 5.6 分包管理

**法律依据**：
- 《建筑法》第29条：分包须经发包人认可，禁止转包
- 《民法典》第791条：禁止承包人将工程分包给不具备相应资质条件的单位

**审核要点**：
- **禁止转包**（必须明确！）
- 分包须经甲方书面同意
- 乙方对分包单位的行为承担全部责任
- 分包单位的资质要求

**风险等级**：
- 未禁止转包 → **高风险**
- 分包无需甲方同意 → **中风险**

---

### 5.7 竣工验收

**法律依据**：
- 《民法典》第799条：建设工程竣工后验收
- 《建设工程质量管理条例》第16条：竣工验收条件

**审核要点**：
- 竣工验收的标准和程序
- 竣工资料的移交要求
- 验收不合格的整改期限
- 逾期不整改的处理方式
- 竣工结算的时限

---

### 5.8 质量保修

**法律依据**：
- 《建设工程质量管理条例》第40条：最低保修期限：
  - 基础设施工程、房屋建筑的地基基础工程和主体结构工程：设计文件规定的合理使用年限
  - 屋面防水工程、有防水要求的卫生间、房间和外墙面的防渗漏：5年
  - 供热与供冷系统：2个采暖期、供冷期
  - 电气管线、给排水管道、设备安装和装修工程：2年

**审核要点**：
- 质量保修范围是否覆盖全部工程
- 保修期限是否不低于法定最低年限
- 缺陷责任期的长短（通常1-2年）
- 质量保修金的预留比例和退还条件

---

## 六、服务类采购专项审核规则

### 6.1 服务标准与SLA

**审核要点**：
- 服务内容、范围是否明确（建议以附件形式列明）
- **服务水平协议（SLA）必须量化**：
  - 响应时间（如：故障响应≤15分钟）
  - 解决时间（如：一般故障≤4小时解决）
  - 可用率（如：系统可用率≥99.9%）
- SLA未达标的处罚机制
- 服务报告的提交频率和内容要求

**风险等级**：
- 服务标准不量化 → **高风险**
- SLA无违约后果 → **中风险**

---

### 6.2 人员资质要求

**审核要点**：
- 服务人员的资质、经验要求是否明确
- 关键人员变更是否需要甲方同意
- 人员替换的交接要求
- 乙方保证服务人员具有相应资质

**风险**：关键人员随意更换 → 服务质量不稳定

---

### 6.3 知识产权归属

**法律依据**：
- 《民法典》第861条：委托开发完成的发明创造，除另有约定外，申请专利的权利属于研究开发人
- **注意**：若合同未约定知识产权归属，委托开发成果默认归受托方！

**审核要点**：
- **服务过程中产生的技术成果知识产权应归甲方所有**（尤其是定制开发）
- 若知识产权归乙方，甲方应获得：
  - 永久的、免费的、不可撤销的使用许可
  - 可再许可的权利（甲方可授权关联公司使用）
  - 源代码（软件类）
- 乙方应保证服务成果不侵犯第三方知识产权

**风险等级**：
- 知识产权归属未约定 → **高风险**（法律默认归受托方！）
- 知识产权归乙方且无永久许可 → **高风险**

---

### 6.4 保密与数据安全

**法律依据**：
- 《个人信息保护法》
- 《数据安全法》
- 《网络安全法》

**审核要点**：
- 乙方接触甲方数据/信息的安全保护义务
- 数据不得用于合同目的之外的用途
- 数据泄露的通知和赔偿义务
- 合同终止后数据的删除/返还
- 若涉及个人信息处理，应约定乙方作为受托处理者的义务

**风险等级**：
- 无数据安全条款 → **高风险**
- 数据安全条款不充分 → **中风险**

---

### 6.5 服务验收

**审核要点**：
- 服务交付成果的可量化标准
- 验收期限和流程
- 验收不合格的处理
- 定期评审机制（长期服务合同）

## 七、甲方视角风险判断速查表（关键！）

在审核报告"潜在风险点"部分，只能列出对甲方不利的条款。以下速查表帮助判断：

| 条款类型 | 对甲方有利 | 对甲方不利（=风险点） |
|----------|------------|----------------------|
| 乙方逾期交付违约金 | 比例高+有上限→有利（非风险） | 比例低/未约定→风险 |
| 甲方逾期付款违约金 | 比例低/有上限→有利 | 比例高/无上限→风险 |
| 乙方任意解除权 | 未约定→有利 | 约定了→风险 |
| 预付款比例 | 比例低→有利（减少资金占用风险） | 比例过高（>50%）→风险 |
| 验收条款 | 标准明确+甲方有充分验收权→有利 | 标准模糊/验收权不足→风险 |
| 质保期起算 | 验收合格之日→有利 | 交付之日→风险 |
| 质保期限 | 长度充足→有利 | 过短→风险 |
| 管辖约定 | 甲方所在地→有利 | 乙方所在地/其他→风险 |
| 知识产权归属 | 归甲方→有利 | 归乙方且无永久许可→风险 |
| 保密条款 | 义务充分+期限≥2年→有利 | 义务不足/期限过短→风险 |
| 质保金 | 比例充足+支付节点靠后→有利 | 比例低/支付过早→风险 |
| 履约担保（工程类） | 有银行保函/保证金→有利 | 缺失→高风险 |
| 农民工工资保障（工程类） | 有专用账户+保证金→有利 | 缺失→高风险 |
| 安全生产责任（工程类） | 乙方负总责+保险齐全→有利 | 责任不清→高风险 |
| 分包转包限制 | 禁止转包+分包需甲方同意→有利 | 无限制→高风险 |
| SLA（服务类） | 量化+有违约后果→有利 | 模糊/无后果→风险 |
| 知识产权（服务类） | 归甲方→有利 | 未约定/归乙方→高风险 |
| 统一社会信用代码 | 合同中明确标注→有利 | 未标注→中风险 |
| 供应商成立年限 | 成立1年以上→有利 | 不足1年→中风险（重大采购） |
| 签署地点 | 精确至县级市/区→有利 | 模糊仅写省市→中风险 |
| 风险转移时点 | 送达验收合格后→有利 | 签收即转移/未约定→中风险 |
| 验收两段时限 | 有明确约定→有利 | 未约定→高风险 |
| 发票开具细节 | 信息完整+类型明确→有利 | 信息缺失/类型不明→中风险 |
| 审减条款（政府投资） | 有明确约定→有利 | 未约定→中风险（政府项目） |
| 违约金抵扣权 | 甲方可直接抵扣→有利 | 未约定→中风险 |
| 知识产权侵权兜底 | 乙方承担全部赔偿→有利 | 未约定→高风险 |
| 保密期限 | ≥2年→有利 | 不足2年→中风险 |
| 争议解决方式 | 二选一（仲裁或诉讼）→有利 | 同时约定→高风险（条款可能无效） |

## 八、数字准确性铁律（最高优先级！）

**报告中的所有数字必须从合同原文中直接引用，严禁推断、换算或自行计算。**

### 铁律规则
1. **数字引用原文，不做转换**：合同写"0.4‰"就写"0.4‰"，不要自行转换或简写。
2. **不推断修订痕迹**：合同有修订痕迹（Track Changes）时，删除/插入的内容不能混用。
3. **违约金比例不可自行比对**：引用双方违约金时分别引用原文。

### 禁止行为
- ❌ 看到"万分之四"自行写成"0.4‰"或"0.04%"
- ❌ 将"肆佰伍拾贰万元整"简化为"452万"
- ❌ 将中文数字自行换算为阿拉伯数字

## 九、审查优先级总结

| 优先级 | 审查层面 | 说明 |
|--------|----------|------|
| 0 | **采购类型识别** | **必须先判断合同类型，加载对应规则** |
| 1 | 合法性 | 违反《民法典》《招标投标法》《政府采购法》《建筑法》《产品质量法》等强制性规定的条款必须指出 |
| 2 | 可执行性 | 司法实践中可能无效或不获支持的条款 |
| 3 | 风险可控性 | 权利义务是否对等，是否存在对甲方不利的单方陷阱 |
| 4 | 商业目标匹配 | 是否保障甲方按质按期获得交付物 |

## 附录：参考条款生成规则（重要！）

### 生成逻辑

"四、参考条款"模块不再展示通用的标准合同条款模板，而是**针对已识别的风险点，展示该风险违背的具体法律法规条款原文**。

### 规则

| 规则 | 说明 |
|------|------|
| **风险-条款对应** | 参考条款N 对应"潜在风险点"中的风险项N，编号一一对应 |
| **仅含法律风险** | 只有涉及违反法律法规的风险才生成参考条款；纯商业谈判类风险（如预付款比例过高、质保期偏短）不生成 |
| **必备要素** | 每个参考条款必须包含：法律文件全称 + 具体条款号 + 条款原文 + 违背说明 |
| **引用来源** | 条款原文必须从本文件正文中各章节标注的法律依据 + 第十章节"主要法律法规索引"中精确引用 |
| **违背说明** | 阐述合同条款与法律规定的冲突点，以及该冲突对甲方权益的具体影响 |

### 示例

| 风险项 | 参考条款 |
|--------|---------|
| 合同约定异地管辖（违反《民事诉讼法》第35条） | 展示《民事诉讼法》第35条原文 + 违背说明 |
| 工程类无农民工工资专户（违反《保障农民工工资支付条例》第26条） | 展示《保障农民工工资支付条例》第26条、第30条原文 + 违背说明 |
| 预付款比例50%（纯商业风险） | **不生成参考条款** |
| 质保期起算为"交付之日"（纯商业安排） | **不生成参考条款** |
