## 四、律师函起草指南

### 4.1 起草五步法

```
Step 1：厘清事实
  └─ 问委托人：什么事？什么时间？什么地点？谁？什么证据？
  └─ 核对已有证据（合同/付款凭证/聊天记录/邮件/催收记录）

Step 2：确定诉求
  └─ 委托人想达到什么目的？（付款/停止侵权/解除合同/道歉/赔偿）
  └─ 最底线是什么？可让步空间？
  └─ 发函的紧急程度？（正常/加急/特急）

Step 3：检索法律
  └─ 确定法律依据（具体到条、款、项）
  └─ 确认诉讼时效/除斥期间是否届满
  └─ 确认管辖法院和举证责任分配

Step 4：填充模板
  └─ 选择对应文书类型模板（L-01至L-28）
  └─ 按模板填空，确保事实和法律准确

Step 5：质量检查
  └─ 逐项核对质量检查清单
  └─ 确认送达方式和送达地址
  └─ 内部审签（重大/复杂/标的额较大）
```

### 4.2 事实陈述原则

> **客观、精准、可证明**

```
✅ 正确写法：
  "2026年3月15日，委托人与贵司签订《钢材购销合同》（合同编号：GM-2026-001），
   约定贵司应于2026年5月1日前支付货款500万元。截至本函出具之日，贵司仅于
   2026年4月20日支付200万元，尚欠300万元未付。"

❌ 错误写法：
  "贵司一直拖延付款，严重违约，给委托人造成了巨大损失。"
  （情绪化、模糊、缺乏具体事实和数据支撑）
```

### 4.3 法律引用规范

| 正确引用 | 错误引用 |
|:---------|:---------|
| 《中华人民共和国民法典》第577条 | 《民法典》577条 |
| 《最高人民法院关于审理买卖合同纠纷案件适用法律问题的解释》第18条 | 《买卖合同司法解释》第18条 |
| 《中华人民共和国民事诉讼法》第67条第1款 | 《民诉法》67条 |
| **引用原则**：首次全称→后续简称 | 全程不使用全称 |

### 4.4 诉求表述原则

> **明确、具体、可执行**

```
✅ 正确写法：
  "一、请贵司于收到本函之日起7日内，向委托人支付货款人民币300万元
   （大写：叁佰万元整）；"
  "二、请贵司于收到本函之日起7日内，支付逾期付款违约金人民币____元
   （计算方式：以300万元为基数，按____计算，自____起至实际付清之日止）。"

❌ 错误写法：
  "请贵司尽快支付欠款。"
  （"尽快"不明确，无法判断是否履行）
```

### 4.5 三档语气预设系统

本SKILL内置**四档可选语气**，用户选择档位后自动匹配措辞，无须手动调整。

| 档位 | 图标 | 适用场景 | 默认措辞 |
|:----:|:----:|:---------|:---------|
| 温和协商 | 🟢 | 首次催收/长期客户/合作关系良好 | "望贵方本着诚信原则，妥善处理上述事宜。" |
| 标准正式 | 🔵 | 一般业务函件（**默认档位**） | "本律师代表委托人郑重致函如下：" |

  - 警告："委托人已授权本律师立即启动诉讼程序，届时不再另行通知。"
  - 结尾："请贵方慎重决定，尽快履行。"

## 五、回函批驳模块

收到对方律师函后如何回函，是实务中的高频需求。本模块提供标准化的回函分析+批驳框架。

### 5.1 收到来函后的四步处理

```
Step 1：不慌张，不立即回应
  └─ 律师函不等于起诉，多数情况下是谈判的开始
  └─ 标记收到日期（法律期限的起算点）

Step 2：分析来函（填写来函分析表）
  └─ 对方诉求是什么？（合法？合理？）
  └─ 对方事实陈述是否准确？（逐句核对）
  └─ 对方法律依据是否成立？（引用是否正确？适用于本案？）
  └─ 对方掌握了什么证据？（对我方威胁多大？）
  └─ 对方发函的真实目的？（施压？取证？和解试探？）

Step 3：确定回函策略
  └─ 情形A：对方诉求合理 → 协商和解方案，避免诉讼
  └─ 情形B：对方事实错误/法律不成立 → 回函逐条批驳
  └─ 情形C：对方纯属施压/试探 → 简要回应或不回应，但保留证据
  └─ 情形D：对方纯属骚扰 → 不回复，保留证据+报警（如涉及威胁恐吓）

Step 4：起草回函
  └─ 使用下方回函模板
  └─ 确认送达到己方委托人确认
  └─ 归档（来函原件/复印件+回函底稿+各方确认记录）
```

### 5.4 回函的三种策略

| 策略 | 适用场景 | 语气 | 篇幅 |
|:----|:---------|:----|:----:|
| **全面批驳型** | 对方事实严重失实、法律依据错误 | 理性反击 | 较长 |
| **简明立场型** | 对方部分合理、部分不合理 | 客观冷静 | 适中 |
| **保留回应型** | 对方纯属施压/试探、我方可暂不暴露底牌 | 模糊回应 | 简短 |

**策略选择原则**：回函不是越强硬越好——过度暴露底牌会让对方提前准备；过度示弱会让对方提高要价。根据案件整体策略选择适度的回应强度。

## 六、律师函质量检查清单

### 6.1 形式要件

- [ ] 致送对象名称正确无误（全称+地址）
- [ ] 委托人姓名/名称正确
- [ ] 律师事务所名称、承办律师姓名
- [ ] 函号、日期完整
- [ ] 格式符合法律文书惯例（页边距/字体/行距）
- [ ] 律师签名/律所盖章

### 6.2 实质内容

- [ ] 事实陈述客观、准确、有证据支撑
- [ ] 法律引用精确到条、款、项
- [ ] 诉求明确具体、可量化、有时限
- [ ] 法律后果提示清晰、合法
- [ ] 无虚假陈述（不得协助虚构事实或伪造证据——《律师法》第49条）
- [ ] 无侮辱诽谤或贬损性语言
- [ ] 无恐吓威胁（不得以刑事报案为要挟实现非法目的）

### 6.3 风险审查

- [ ] 不构成虚假诉讼（《刑法》第307条之一）
- [ ] 不构成敲诈勒索（《刑法》第274条）——特别注意：
  - 维权内容须有合法依据
  - 索赔金额不应显著超出合法范围
  - 不得以"举报/报案"为要挟索取不正当利益
- [ ] 不泄露委托人商业秘密或个人隐私
- [ ] 不超出委托人的授权范围

### 6.4 送达确认

- [ ] 送达地址正确（合同约定地址/工商登记地址/身份证地址）
- [ ] 送达方式选择：
  - EMS邮寄（推荐）：备注"律师函"或函号，保留底单+签收回执
  - 电子邮件：确认收件邮箱正确，保留发送记录
  - 微信/短信：确认手机号/微信号实名认证
  - 公证送达：对方拒收或下落不明时使用
- [ ] 送达凭证归档（寄件底单+签收回执+送达截图）

## 七、常见风险防范专项

### 7.1 涉及刑事风险的红线

| 行为 | 可能触犯罪名 | 正确做法 |
|:-----|:------------|:---------|
| 虚构事实要求对方赔偿 | 敲诈勒索罪/诈骗罪 | 事实必须有证据支撑 |
| 以"举报犯罪"要挟索取远超合法范围的钱财 | 敲诈勒索罪 | 举报与索赔应当分离 |
| 明知无合法债权仍发函催收 | 虚假诉讼罪（预备） | 先核实债权合法性 |
| 在函中泄露他人隐私/商业秘密 | 侵犯公民个人信息罪/侵犯商业秘密罪 | 仅陈述必要事实 |

### 7.2 保全证据价值

律师函除了"施压"功能外，还有一个容易被忽视的重要功能——**固定证据**：

| 目的 | 操作 | 法律效果 |
|:-----|:-----|:---------|
| 中断诉讼时效 | 通过EMS发出催款函，保留签收回执 | 《民法典》第195条——诉讼时效重新计算 |
| 催告履行 | 发函设定合理履行期限 | 构成催告，对方逾期不履行可解除合同 |
| 固定对方违约状态 | 函中明确载明对方违约事实 | 如对方回函未否认，可能构成自认 |
| 履行通知义务 | 发函通知解除合同/债权转让/股东会召集 | 通知到达即生效 |
