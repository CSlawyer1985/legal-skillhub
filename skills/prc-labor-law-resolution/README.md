# 中国劳动法争议解决 Skill

## 技能名称

- 技术名称：`prc-labor-law-resolution`
- 中文名称：中国劳动法争议解决

## 技能描述

面向中国大陆劳动用工和劳动争议，使用现行有效且可核验的中国政府官方法律来源，完成事实核对、争点分析、证据规划、请求金额透明暂算、协商、劳动监察、调解、仲裁、诉讼、执行、合同制度审查和企业合规指导。

## 最简单的使用方法

直接说：

> 请使用 prc-labor-law-resolution 技能处理以下问题：公司准备辞退我，我该怎么取证、计算补偿并按步骤维权？

不需要会命令行，也不需要先判断专业术语。直接说“老板让我走”“一人多岗不会就优化”“公司欠薪还辞退我”即可；技能会识别全部争点，先判断紧急事项，再逐项询问地域、日期、工资、解除理由、证据和目标。遇到工伤时按“事故保全→关系与主体→认定→鉴定→待遇→救济与第三人衔接”逐阶段处理；遇到劳务派遣时建立派遣单位、用工单位、劳动者三方责任矩阵，分别核验退回、重新派遣、待派报酬、解除、同工同酬和跨地区参保。FAQ未覆盖的新问题执行“主体、期限、要件、证据、渠道、金额、抗辩、衔接”八格排雷。官方网站暂时不可用时会自动给出三级离线降级方案，不让行动停在“稍后重试”。

## 支持场景

- 劳动关系、劳动合同和试用期
- 辞职、协商解除、被迫解除、裁员和违法解除
- N、N+1、2N及复杂分段工龄测算
- 欠薪、加班费、病假工资、未休年假工资暂算
- 社保、工伤、竞业限制、劳务派遣、平台用工
- 工伤认定、劳动能力鉴定、待遇责任、行政救济及第三人侵权衔接
- 派遣三方责任、退回与解除区分、重新派遣、待派报酬、同工同酬和假外包真派遣
- FAQ未覆盖的新问题八格排雷，避免机械套用相似案例
- 劳动监察、调解、仲裁、诉讼和执行
- 劳动合同、员工手册、绩效制度和企业用工合规

## 零参数受理与计算向导

普通用户可直接用自然语言，不需要理解专业参数：

```bash
python scripts/labor_claim_intake.py --text "我2005年入职，2026年被辞退，补偿怎么分段算？"
```

无参数运行也会返回一般劳动法受理表；`--demo` 提供可复制示例。系统会返回已识别信息、缺失信息、缺失原因、获取方式、填写表和拿不到材料时的替代方案。

金额计算向导：

```bash
python scripts/labor_claim_calculator.py guide
```

脚本只做算术，不判断请求是否成立。地方基数、比例、倍率、封顶值、资格和时效必须依据争议发生时有效的官方规则核验。

## 安全边界

- 不承诺胜诉，不冒充执业律师。
- 不编造法条、案例、地方标准或办事入口。
- 不指导非法取证、盗号、破解、伪造证据或泄露商业秘密。
- 不帮助用人单位规避工资、社保、补偿等法定义务。
- 输出中的身份证号、住址、电话、银行卡、病历和第三人信息应脱敏。
