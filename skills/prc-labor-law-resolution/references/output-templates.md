## 模板 2：证据目录——你手头有什么、还缺什么

### 这个模板是干嘛的？
仲裁和打官司时，你的证据要编好号、写清楚每样证明什么。填这张表能让你一目了然地知道"我已经有了什么、还差什么、对方可能攻击我哪块"。

### 范本

```markdown
| 序号 | 证据名字 | 什么时候形成/发生的 | 放在哪/什么格式 | 用来证明什么 | 原件还在吗 | 对方可能怎么反驳 |
|---|---|---|---|---|---|---|
| 1 |  |  |  |  | 有/没有 |  |
```

### 怎么填

- "证据名字"：简洁写，比如"劳动合同"、"2026年7月考勤截图"、"HR微信聊天记录"
- "什么时候形成/发生的"：证据产生的日期
- "放在哪/什么格式"：截图、PDF、纸质扫描件等
- "用来证明什么"：不要写"证明我被辞退"这种笼统的话，要写"证明公司于2026年7月20日通过微信通知本人不再安排工作"
- "对方可能怎么反驳"：提前想好公司会说什么，"这是假的""这个不能证明是我们公司的""你没有我们的授权查看这个"

## 模板 3：给公司的书面沟通函

### 这个模板是干嘛的？
当你需要跟公司正式说一件事、留下证据、同时不让他们把你当成"拒绝配合"或"不服从管理"时，用这个模板发邮件。**最关键的点是：表示你愿意配合，但同时要求公司书面说清楚要你做什么、怎么做、什么标准。**

### 范本

```text
主题：关于【你要说的事，比如"岗位调整"或"解除通知"】的书面确认

我于【日期】收到/了解到【公司做了什么或说了什么】。为了避免理解不一样，现在书面确认一下：
1. 【事实一：我看到/听到什么，什么时候、谁说的、怎么说的】；
2. 【事实二】；
3. 请贵公司于【一个合理的时间，比如7天】内书面告诉我【你想要他们说明白的问题】并给我【你要的材料】。

我愿意在法律范围内理性协商解决。这封信只是确认事实和沟通，不表示我同意变更劳动合同、主动辞职或者放弃任何法律权利。

姓名：
日期：
怎么送达的及凭证：
```

### 怎么改

- 把【】里的内容替换为你自己的情况
- "你要说的事"：比如"关于调去新部门降薪的事""关于11月工资没发的事"
- 不要在这封信里编造公司还没做的事，也不要写你没法证明的指控
- 发送方式最好是公司邮箱+个人邮箱同时发送，重要的事再打印一份EMS寄到公司注册地址

## 模板 4：解除或调岗异议函——专门应对"调岗/多能工/被说不胜任"

### 这个模板是干嘛的？
公司让你一个人干好几个人的活，或者把你调到完全不搭边的岗位，或者跟你说"你不胜任/优化"——这时你需要一封正式的不卑不亢的回信，表明"我配合、但我要知道你让我干什么、怎么考核、按什么标准"。

### 范本

```text
主题：关于【调岗/多能工/绩效考核/解除】的书面确认和我的异议

我于【日期】收到【通知，或谁口头跟我说了什么】。我愿意在合法、合理、符合劳动合同约定的范围内好好工作，没有主动辞职或拒绝干活的想法。

请公司书面告诉我：
1. 新岗位/新任务具体要干什么、在哪、每天干多久、工资变不变、需要什么上岗证；
2. 有没有培训安排、适应期多长时间、怎么考核、考核标准是谁定的、有没有经过员工讨论和公示；
3. 公司如果觉得我不胜任或违反了什么规定，请书面写清楚具体哪件事、违反了哪条规定、有什么证据；
4. 如果公司打算解除我的劳动合同，请出具书面通知，写明事实是什么、理由是什么、根据哪条法律、从哪天开始。

我对【降薪/工作量明显过大/要我干没资质的事/没培训就直接考核/其他你不同意的点】表示不同意，并且愿意继续跟公司商量合理的方案。这封信只是确认事实，不表示我同意变更劳动合同、不表示我主动辞职、也不表示我放弃任何法定权利。

姓名：
日期：
怎么送达的及凭证：
```

### 怎么改

- 把【调岗/多能工/绩效考核/解除】替换成公司实际用的词（比如"岗位整合方案""多岗位轮岗办法"）
- 把【降薪/工作量明显过大……】里面只保留你实际不同意的那条，删掉不用的
- 不要写公司没做过的事，不要编造指控
- 发邮件时一定要保留"发送记录"截图

## 模板 5：劳动仲裁申请书——提交之前先自查这9条

### 这个模板是干嘛的？
在帮你想仲裁申请书怎么写之前，先用这9条过一遍你的请求有没有硬伤——避免到了仲裁庭才发现请求写错了、被告写漏了、忘了算利息。

### 核对清单

- 你要的每样东西是不是劳动仲裁能受理的？
- 该告谁，名字写对了没有？
- 每项请求有没有具体到金额、时间区间？还是笼统地说"赔偿"？
- 时间和金额区间清不清楚？
- 有没有冲突的请求（比如又要"继续履行合同"又要"支付解除补偿"）？
- 有没有漏掉：利息要不要？继续履行合同的话怎么说？要求公司出具离职证明？
- 每项请求的每个条件要件，是不是都能找到对应的证据？
- 有没有超过一年的仲裁时效（或劳动关系终止后的一年）？
- 找哪个仲裁委、材料寄到哪个地址——查过了你当地的最新要求了吗？

## 模板 6：合同或公司制度审查表

### 这个模板是干嘛的？
审你的劳动合同、员工手册、或者公司新发的制度文件时用的。逐条标注"这条好不好、要不要改、为什么、改成什么"。

### 范本

```markdown
| 条款内容 | 评级 | 为什么有风险 | 实际会有什么后果 | 建议改成什么 | 后续怎么做 |
|---|---|---|---|---|---|
|  | 能用/该改/高风险/可能无效 |  |  |  |  |
```

### 怎么用

- "能用"：合法合理，保留
- "该改"：有瑕疵但不至于无效，建议修改
- "高风险"：很可能被认定违法
- "可能无效"：明显违反法律规定，写了也别想用
- 除了改文字，还要检查：制定时有没开过会、有没有让员工讨论、有没有公示告知、有没有培训、执行中是不是一视同仁、有没有保存记录

## 模板 7：地方规则核验卡——你去当地看什么

### 这个模板是干嘛的？
很多标准每个城市不一样（最低工资、病假工资比例、工伤待遇、社平工资封顶金额等）。我一查不到的话，就把这张卡给你——你可以拿着去人社局网站搜、打12333问、或者去窗口当面确认。

### 范本

```markdown
| 项目 | 内容 |
|---|---|
| 在哪个城市、什么时候发生的事 |  |
| 全国层面已经确定的规定 |  |
| 需要在你城市核实的具体数字和程序 |  |
| 首选去哪查 | 你们省市的人社局官网、市政府官网、法院官网、政务服务网 |
| 备用的 | 打12333电话问，或直接去当地人社局窗口问 |
| 可以复制去搜索的关键词 | 【城市名】【要查的事】【年份】官方 现行有效 |
| 打电话或当面可以这样问 | 你好，我想确认在【城市】、【年份】关于【要查的事】，现行的规定文件全称是什么、具体数字是多少、找哪个部门、带哪些材料。 |
| 查不到之前的保守做法 | 不猜数字、不瞎写比例和地址；先把证据保全、书面提主张，留心期限 |
```
