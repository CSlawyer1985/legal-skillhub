# 怎么算钱——补偿金、加班费、欠薪、病假、年假

> 你不会填JSON、不会写命令行都没关系。把你知道的信息像聊天一样告诉我，我来帮你算。算出来的钱会告诉你"怎么算的、前提是什么、还有哪些不确定"——不只是扔给你一个数。

---

## 先看你想要算哪一种

| 你想算什么 | 就这样告诉我 | 在帮你算之前我得先搞清楚的事 |
|---|---|---|
| 被辞退/开除能拿多少补偿 | "我2021年入职，刚被辞退，算N还是2N" | 你是被怎么辞退的、工龄多少年、辞退前12个月平均每月挣多少、你那个城市工资高的有没有封顶 |
| 2008年前后工龄要分开算 | "我2005年就进公司了，现在被裁" | 不同时间段的规则不一样、基数不一样、封顶要求不一样——分段来 |
| 公司欠我几个月工资 | "从1月开始工资就没发全过" | 每个月该发多少、实际发了多少、一共多少个月 |
| 天天加班从来没拿过加班费 | "每天晚上做到十点、周末也经常来" | 你是标准工时还是别的、工作日加了几小时、周末加了几小时、节假日加了几小时、有没有给调休、一小时你该拿多少 |
| 休病假了工资怎么发 | "我在深圳，请了10天病假，到底该发多少钱" | 你在哪个城市、具体是哪年哪月的病假、每天工资基数多少、当地规定什么比例、你有没有医疗期、公司已经付了多少 |
| 年假没休辞职/被辞退 | "快离职了，去年年假一天没休" | 你有没有休年假的资格、应该有几天、实际休了几天、每天的工资基数多少、折算是按多少比例 |

如果上面的表里没有你想要的，我还是按同样的方式帮你算——变量名字、怎么算的、你提供的数据、算出来的结果、有什么不确定的、你还得注意什么——一样都不会少。

## 你就像聊天一样告诉我这些信息就行

### 算辞退补偿（N / 2N）

像这样跟我说：

> "我在广州工作，2021年4月入职，2026年8月被公司以经营困难为由辞退。辞退前12个月平均工资大概8000，没签过什么自愿离职的东西。帮我先看看能主张什么、需要补什么信息。"

我会先搞清楚辞退的性质和地方标准，该算的时候才帮你算。

你需要给我的信息卡（知道几个说几个，不知道的就说不知道）：

```text
1. 你在哪个城市上班：
2. 你哪天进的公司：
3. 哪天被辞退（或最后一次上班）：
4. 公司说是为什么要辞退你（有书面通知的话上面怎么写的）：
5. 辞退之前12个月你每月大概挣多少（基本工资+绩效奖金+各种补贴全算上）：
6. 中间有没有2008年之前就在同一家公司的工龄：
7. 你所在城市的高工资封顶标准知不知道：
8. 你想要什么结果：继续留在公司 / 拿N补偿金走人 / 拿2N双倍赔偿 / 先谈协商：
```

### 算加班费

像这样跟我说：

> "我是标准工时，最近半年基本每天都干到晚上十点，周末也经常来一天。从来没见过加班费，也没安排过补休。我基本工资6000，帮我看看怎么算。"

你需要给我的信息卡：

```text
1. 你是什么工时制度：标准 / 不太清楚（我问你细节来判断）
2. 你加了哪几天的班、每天加了多少小时：
3. 工作日晚上加班多少小时、周末加班多少小时、法定节假日（春节、国庆等）加班多少小时：
4. 加完班有没有让你调休过：
5. 你一小时工资大概多少、这个数是哪里来的：
6. 加班费计算比率是150%/200%/300%（这个我来核实，你不需要提供）
7. 公司已经给过你什么加班钱了吗：
8. 你手上有什么：考勤记录 / 排班表 / 加班审批单 / 工作群让你加班的聊天记录 / 你加班做出来的东西
```

### 算病假工资或没休的年假

**必须告诉我你在哪个城市、病假或年假是哪一年的事**——因为每个城市的比例和标准不一样。算钱的公式会先核实当地规定再套进去。

## 你填错了怎么办？——对照着改

| 你填的哪里不对 | 为什么不行 | 怎么改 |
|---|---|---|
| 日期写成"8月1号" | 需要固定格式 | 全部改成"年-月-日"，比如2026-08-01 |
| 结束日期比你填的开始日期还要早 | 日期填反了，或者事实记错了 | 对照合同、通知书、离职证明再确认一遍 |
| 金额写了"8,000元" | 只要数字 | 把"元"和逗号去掉，改成8000 |
| 让你填的JSON里用了单引号、掉了逗号或者格式不对 | 程序识别不了 | 先运行 guide 拿一份范本，照着改 |
| 两段时间重叠了 | 同一段日子算了两遍 | 保证后一段开始日严格晚于前一段结束日 |
| 算出来的结果是负数 | 公司给的钱比你现在暂算的应付额还多 | 检查基数、时间区间、天数和已付项目是不是搞错了 |
| 不知道一个比率或比例该填多少 | 你还没查过你那个城市当时的规定 | 先停下来，上当地人社局官网核实，或者打12333问了再填 |

## 计算结果里必须包含这些——一个都不能少

给你算钱时，我会把下面这些全部写清楚：

- **这个钱你能要的前提是什么**（不是说算出来就一定是你的）
- **用到了哪些数字、从哪来的**
- **怎么算的、用了什么公式**
- **分项各是多少、加起来总共多少**
- **公司已经付了多少**
- **还有哪些数据没有核实**
- **对你有利的证据和对你不利的证据分别是什么**
- **下一步怎么把这个数写进你的仲裁请求或者协商方案里**

## 跨2008年工龄分段算——记住这个就行

如果你2005年入职、2026年被辞退，不能直接用"干了21年"×"现在工资"=21个月。要分两段（甚至更多段）：

每段填这些东西：

```text
第一段：2005年X月X日 到 2007年12月31日
  - 用哪套规则：
  - 那段时间你的月工资是多少：
  - 倍数：
  - 有没有封顶：
  - 最多算多少年：

第二段：2008年1月1日 到 2026年X月X日
  - 用哪套规则（《劳动合同法》）：
  - 辞退前12个月平均工资多少：
  - 倍数（N=1，2N=2）：
  - 有没有封顶（你们那上年度社平工资的3倍）：
  - 最多算多少年：
```

把所有段的结果加起来才是总数。封顶标准不能乱填，要查你所在城市人社局公布的"上年度职工月平均工资"这个数字。
