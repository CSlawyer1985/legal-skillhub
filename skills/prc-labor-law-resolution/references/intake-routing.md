# 我怎么知道你的情况该走哪条路？

## 我想帮你，但需要知道这8件事

我会先从你告诉我的话里尽量提取，只追问那些真正会影响最后结果的信息：

1. **你是谁**：劳动者/公司HR/老板/派遣员工/平台接单员
2. **在哪个城市**：实际工作的城市、合同签的地址、公司注册地
3. **什么时候的事**：哪天入职的、哪天发生的争议、哪天收到的通知
4. **和谁签的合同**：直接和公司签、还是派遣公司、还是外包
5. **工资情况**：一月挣多少（基本工资＋绩效＋补贴都算上）、公司给你发的每笔钱有没有记录
6. **发生了什么**：老板说了什么/做了什么、有没有书面通知
7. **手头有什么证据**：合同、工资条、银行流水、考勤、聊天记录、邮件、通知、社保记录、看病材料
8. **你想要什么结果**：继续上班、拿钱走人、补交社保、认定工伤、让公司改正……

一次最多问6个问题。问题太多太杂的话分几轮来，顺序是固定的：先问紧急的期限和文书日期 → 再问发生什么事（被辞退、欠薪、受伤……）→ 然后问谁在哪 → 然后是工资和时间 → 再问证据在谁手里 → 最后问你想达到什么目的。每问一个问题我都告诉你为什么需要知道这个、从哪能拿到、拿不到的话怎么办。

如果时间很紧（比如仲裁期限快到了），我先把能做的紧急动作告诉你，再慢慢问别的。你不回答我也得给你一个保守的结论和马上就能做的步骤，不会说"你是不是先回答完问题再说"。

## 你就这样说，我能听懂——口语化入口指引

你不需要事先搞清楚自己的问题在法律上算什么。看看下面这些情况有没有像你的，照着说就行：

| 你可能会这样说 | 你遇到的实际问题 | 说明 |
|---|---|---|
| "老板让我明天别来了" / "主管微信说不用来了" | 可能是被辞退，可能解除通知即将丢失 | 我会先提醒你保存证据，再判断是什么性质的解除 |
| "公司不让打卡了" / "门禁卡刷不开了" | 可能被停工、被解除，或者工作条件出了问题 | 我会让你书面确认还在岗、还要上班，避免被反咬一口"旷工" |
| "HR逼我自己写辞职信" / "让我签自愿离职" | 被迫离职，签字后果严重 | 我会告诉你千万别签、怎么留证据、怎么书面表示不自愿 |
| "一个人干三个人的活，干不好就说要优化" | 调岗和不能胜任的争议 | 我会分析：到底是不是劳动合同的变更、有没有培训、考核公平不公平 |
| "这个月工资少了" / "提成一直不给" / "拖了三个月工资" | 欠薪，可以主张工资差额 | 我会帮你算差额，告诉你去劳动监察还是走仲裁 |
| "天天加班到晚上十点，从没拿过加班费" | 加班费争议，证据是关键 | 我会教你从现在开始怎么记考勤、怎么整理已有证据、算加班费 |
| "受伤了公司不管" / "在车间出事了老板说不是工伤" | 工伤期限紧急，证据最先灭失 | 我会先让你保存病历和事故证据，再一步一步教你怎么自己申请 |
| "我是派遣工，受伤了派遣公司和上班的地方互相推" | 派遣工伤，两边都不想担责 | 我会分开分析两边责任，不让他们把期限拖过 |
| "怀孕了被调到打杂的岗位，工资也降了" | 孕期保护 + 违法调岗降薪 | 我会核实特殊保护是否适用，怎么提异议、去哪投诉 |
| "公司突然说倒闭了，什么都没有" | 公司注销前的紧急处置 | 我会告诉你怎么锁定证据、怎么申报债权、怎么找劳动监察 |
| "我不知道这算什么，就是觉得不对" / "帮我维权" | 所有你能想到的劳动问题 | **你就这么说就行**，我会先问几个简单问题，然后一样一样来 |

> **一个小技巧**：如果你不确定自己的情况属不属于上面这些，**没关系，直接说**。我会先复述一遍"我理解你是遇到了……这样对吗？"确定了再往下走。

## 你第一步该走哪条路？——快速对照表

| 你的问题类型 | 优先试试这条路 | 要特别注意什么 |
|---|---|---|
| 工资被拖欠 | 先书面催一次，然后去劳动监察投诉或劳动仲裁 | 分清楚"公司承认欠钱"和"公司不认欠钱"，证据要求不一样 |
| 加班不给钱 | 协商，协商不成去仲裁 | 先搞清楚你算哪种工时（标准/综合/不定时），再看证据是谁拿着 |
| 被辞退/开除/劝退 | 先保存所有证据，再协商，最后仲裁 | 区分是拿补偿（N/N+1）还是不拿补偿（严重违纪）还是拿双倍赔偿（违法解除） |
| 社保没交或少交 | 去社保征收部门或税务部门反映，必要时转仲裁 | 各地社保归谁管不一样，要核实 |
| 工作中受伤 | 先治伤留证据 → 工伤认定申请 → 劳动能力鉴定 → 要待遇 → 不服的找上级 | 先弄清事故日期、谁来申请、有没有超过期限、有没有劳动关系、参没参保、有病历吗、有第三方赔钱吗 |
| 派遣工出问题 | 查三方关系 → 书面确认 → 根据具体问题走行政/仲裁/工伤 | 把派遣公司和用工单位的责任分开；"被退回"不等于"被开除"；核对工资社保、同工同酬、特殊保护和跨地区参保 |
| 竞业限制纠纷 | 协商或仲裁 | 核对哪些人要签、签了什么、补偿给没给、多长时间、违约金对不对 |
| 公司制度有问题 | 审查合法性、推动修改 | 检查内容合不合法、有没有经过民主程序、有没有公示签收、执行是不是一致 |
| 确认劳动关系 | 走仲裁或其他程序 | 从招人、管理、出钱、组织三个方面收集证据 |
| 调岗位/降工资/多能工 | 先书面确认、协商、正常上班留证据，必要时仲裁 | 区分"正常安排工作"和"变相赶人走"；查有没有培训义务 |
| 好几件事搅在一起 | 一件一件拆开，画张表看清楚哪条路能并行、哪条要排队 | 被辞退、欠薪、加班、社保、工伤分别查证据和期限，不只看其中一个 |

> **注意**：这张表只是帮你快速找到方向。具体走哪条路、找哪个部门，还需要查你所在城市的具体规则。

## 工伤——一步一步来（紧急！）

### 第一步：立刻做的事（不管你还在医院还是已经好了）

1. **先治病**，把第一次看病的病历、诊断书、拍片、医嘱、发票和所有费用清单全部留好。不要等公司同意再去看。
2. **把出事的时间、地点、怎么回事、是谁叫你干的、当时还有谁在场、打卡记录、有没有监控全部记下来保存好。**
3. **查一下公司有没有帮你申报工伤。** 公司申请和你自己（或家人、工会）申请的期限不一样——从出事那天或者诊断出职业病那天开始算，具体多少天要看你所在城市的人社局怎么说。**不要只听公司嘴上说"我们会申报"。**

### 第二步：搞清楚这八件事

| 要搞清楚什么 | 具体查什么 | 常见的证明材料 |
|---|---|---|
| 伤情和治疗 | 伤在哪、怎么治的、有没有转院、医生有没有让你停工休息 | 全部病历、拍片、诊断、费用清单 |
| 怎么出的事 | 什么时候、在哪、什么原因、领导让你干嘛 | 事故报告、排班表、任务单、目击证人、监控线索 |
| 和公司什么关系 | 有没有合同、谁在管你、谁发工资、是不是公司的人 | 合同、工资条、社保记录、打卡、工牌、工作群聊天 |
| 申报期限 | 出事/诊断的准确日期、公司说什么时候申报、你自己也要算 | 申报回执、邮寄记录、受理文书 |
| 认不认工伤 | 是不是在工作时间/地方/原因伤的、上下班路上算不算 | 任务记录、路线、交通事故责任认定书 |
| 交没交社保 | 有没有交、在哪交的、谁交的 | 社保查询记录、缴费记录 |
| 鉴定和待遇 | 伤情稳没稳定、鉴定到什么阶段、工资和费用怎么付的 | 认定决定书、鉴定结论、工资银行流水 |
| 其他赔偿 | 有没有第三方肇事、有没有买商业保险 | 交通事故认定书、保险合同、行政复议/诉讼文书 |

### 第三步：根据你现在到哪一步来决定下一步

1. **还没申请认定**：查谁来申请、找哪个部门、什么期限内、带什么材料。如果公司说"你不是我们的人"，同时准备证明你们有劳动关系的材料。
2. **已经提交申请、等结果**：继续补充事故和关系的证据，把补材料、调查问话、结果送达的每个环节记清楚。受理了不等于一定能认定。
3. **已经认定是工伤**：核实治疗情况、停工期间工资、到没到做劳动能力鉴定的时候、社保基金付多少、公司付多少，查你所在城市的具体标准。
4. **不受理或不被认定**：看看决定书上写的事实、理由、找谁申诉、什么期限内申诉，再决定是走行政复议、打行政诉讼还是补材料——注意不要直接跑去仲裁要求撤销行政决定。
5. **有第三方肇事或商业保险**：工伤赔偿、侵权赔偿和保险理赔三条路分开算，已经赔了哪些项目、哪些可能衔接，非劳动法的部分转交对应专业人士，但工伤的期限动作不要停。

## 劳务派遣——三方关系必须分清楚（别让他们互相推）

### 第一步：三边都列出来

| 要查什么 | 派遣公司（跟你签合同的那家） | 用工单位（你实际去上班的那家） | 你有什么证据 |
|---|---|---|---|
| 合同、工资、社保、解除 | 它有没有尽到雇主的义务 | 它有没有协助、有没有该担的责任 | 合同、工资流水、社保记录、解除通知 |
| 谁管你、工时、考核、劳动保护 | 它有没有监督、有没有通知你 | 它实际上怎么管你、工作条件好不好 | 考勤、排班、工作指令、公司制度、安全培训记录 |
| 同工同酬、福利 | 合同里工资怎么写的、怎么发的 | 同样的岗位工资怎么分配的、福利有没有 | 岗位说明、工资明细、同岗位正式员工的工资对比 |
| 工伤 | 有没有申报、有没有交工伤保险 | 有没有帮忙、有没有出事的证据和说明 | 事故记录、医疗材料、申报回执、参保证明 |
| 被退回和解除 | 有没有给你重新安排工作、待工工资怎么发的 | 为什么把你退回、有没有正当理由 | 退回通知、重新安排工作的记录、解除通知 |

### 第二步：这五个问题必须分开看

1. **被退回 不等于 被开除**：分别看用工单位为什么把你退回，派遣公司有没有给你安排新工作、怎么解除的——不要把两家的行为混在一起。
2. **工伤和职业病**：查派遣公司有没有申报、用工单位有没有协助、有没有留下职业危害的材料。两家的内部约定不能成为拖延你申报的理由。
3. **工资社保和待工工资**：一笔笔确认谁该付钱、谁该交社保、在哪里交的、跨地区怎么处理、没工作期间的工资按什么标准发。
4. **同工同酬和福利**：先看岗位是不是一样或差不多、大家干的活一样不一样、工资怎么构成的、为什么不一样——而不只看"别人比我多拿多少钱"。
5. **看着像外包其实是派遣**：是谁在招人、谁在管、谁在考核、谁在发钱、谁在承担风险——按实际情况判断，不看你合同上的名字。

## FAQ没有的新问题——八个角度全面排查

FAQ里找不到答案时，不要拿最像的案例硬套。从这八个角度一个一个过：

1. **谁的责任**：合同上是谁、实际谁在管、谁发的钱、谁干的这事、该找谁说理——这五个"谁"是不是同一个人/公司？
2. **什么期限**：从哪天开始算，要在多少天内去申请/仲裁/打官司/复议/鉴定/交证据？
3. **你得满足什么条件**：你的要求在法律上要成立，必须符合哪几条？
4. **需要什么证据**：每条成立条件需要什么证据来证明，谁有这个证据，拿不到能不能有别的东西代替？
5. **走哪条路**：行政投诉、仲裁、打官司、工伤认定几条路是必须先走哪个还是可以同时走还是只能选一个？
6. **能要多少钱**：先确定能不能要、该不该赔，再算基数、期间、比例、已经付了多少、你所在城市的具体标准。
7. **对方会怎么说**：公司最可能拿什么理由来反驳你——事実上的、程序上的、期限上的、证据上的？
8. **还要找谁**：有没有派遣、外包、平台、第三方肇事、商业保险这些外围问题需要一并处理？

八个里面任何一个没法确认时，就告诉你："目前只能得出这个保守的结论 + 还缺什么 + 从哪里能拿到 + 不依赖这个的话现在就能做的事"。

## 紧急！出现以下情况请立刻处理

- 仲裁期限、诉讼期限、工伤申请期限、交证据期限或文书签收期限马上要到期了
- 公司要关掉你的账号、收回电脑/门禁卡、删掉打卡记录
- 有人逼你签空白的文件、让你填以前的日期、或让你当场签"自愿辞职"
- 有人对你动手、威胁你、不让你走、扣你的身份证
- 公司在转移资产、可能要注销、经营异常
- 很多人同时出问题，可能涉及群体事件或刑事风险
