# 法律来源核验规则

## 目的

防止引用失效规范、错误条号、错误地域口径或二手解读。每次需要精确依据、最新政策、地方金额或程序入口时执行本规则。

## 来源优先级

1. 国家法律法规数据库：法律、行政法规、地方性法规等正式文本。
2. 中国政府网、全国人大网、最高人民法院官网、人力资源和社会保障部官网。
3. 省市人大、人民政府、人社部门、法院及政务服务官网。
4. 官方公报或公开发布的规范性文件库。
5. 权威案例库与法院公开案例，仅用于裁判思路参考。
6. 律所文章、媒体、问答平台只能用于发现线索，不得代替原文依据。

## 六项核验

对每一项关键依据记录：

| 项目 | 检查内容 |
|---|---|
| 名称 | 规范名称是否完整、准确 |
| 条款 | 条号和关键文字是否与原文一致 |
| 效力 | 现行有效、已修改、已废止或尚未施行 |
| 时间 | 施行日期与争议发生时间是否匹配 |
| 地域 | 全国、某省市或特定地区 |
| 对象 | 劳动者、用人单位、特殊行业或特殊人员 |

## 引用状态标签

- **已核验**：已查看官方原文，并完成六项核验。
- **部分核验**：已确认规范存在，但条文、效力或地方适用仍有一项待核。
- **待核验**：仅凭用户提供或记忆获知，不得作为确定结论的唯一依据。

回答中不得将“待核验”写成确定事实。

## 地方规则

下列事项通常需要核对地区和时间：最低工资、社平工资、病假工资、婚育假、工伤待遇计算参数、社保补缴情形、线上办事入口、仲裁或法院材料细节。无官方来源时：

1. 给全国层面框架；
2. 说明待核项目；
3. 指导通过当地人社部门、政务服务官网、12333或法院官方渠道确认；
4. 不编造窗口地址、电话号码、平台名称和办理时限。

## 案例使用

- 标注法院、案号、裁判日期和裁判层级；不能核验则不写案号。
- 说明案例仅供同类事实参考，不等于普遍规则。
- 对存在地区差异或裁判分歧的问题，至少列主要观点及影响选择的事实。

## 地方规则核验卡

任何最低工资、社平工资、病假工资、婚育假、工伤参数、社保补缴、地方办事入口等结论，先输出下列核验卡，不把查证任务笼统甩给用户：

```text
地区：
争议发生年月：
事项：
全国层面已确认框架：
待核参数/程序：
首选官方来源：省市人大/政府/人社/法院/政务服务官网
备用官方渠道：12333、当地人社部门或受理机关
可复制查询词：【地区】【事项】【争议年度】 官方 现行有效
可复制电话/窗口问法：请确认【事项】在【年月】适用的文件全称、条款、数值、办理机关和材料要求。
未核验前的保守处理：不填具体比例或地址；先保全证据、书面主张权利并注意期限。
```

核验后记录页面标题、发布机关、发布日期/施行日期、访问日期和链接；只有搜索摘要而未打开原文时，状态仍为“部分核验”。

## 三级失败降级

官方网页无法访问、检索超时或用户处于离线环境时，立即完成以下三级输出，不要求反复重试：

### 第一级：不中断行动

- 使用已经确认的全国法律框架，但不凭记忆猜条号、地方数值或办理期限；
- 先给最多3项证据保全、书面沟通和期限止损动作；
- 明确哪些结论不依赖地方参数，哪些只能条件式表达。

### 第二级：把待核验变成清单

- 给出完整规范名称或应核事项、发布机关、适用地区和争议年月；
- 提供可复制查询词和“地方规则核验卡”；
- 如存在多个可能口径，列出各口径成立所需事实，不擅自选一个。

### 第三级：提供人工官方通道

- 指导通过12333、当地政府/人社/法院官方渠道确认；
- 给出逐项问法，例如：“请确认2026年深圳病假工资的现行文件全称、计算基数、比例、最低保障及适用对象”；
- 记录咨询日期、部门、工号或答复摘要；口头答复只作线索，重要金额仍尽量取得书面或网页依据。

网络恢复后补齐原文核验，不改变已经采取的证据保全和时效动作。如期限迫近或金额重大，建议携材料咨询当地执业律师或受理机关。
