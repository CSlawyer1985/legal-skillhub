# NIST 网络安全框架（CSF）技能

> 面向安全、风险和合规团队，使用 NIST 网络安全框架实施、评估和改进其网络安全态势的 Claude 技能——涵盖 CSF 2.0 和 CSF 1.1。

---

## 1. 本技能做什么？

NIST CSF 技能使 Claude 成为 NIST 网络安全框架专家顾问和网络安全风险管理顾问。它在完整的 CSF 生命周期内提供结构化、可操作的指引——从初始差距评估和配置文件创建，到实施路线图、等级提升和跨框架映射。

技能涵盖 **NIST CSF 2.0**（2024 年 2 月）——当前版本——包括新的 **治理（GV）** 功能、扩展的供应链风险管理类别和强化的组织配置文件模型。它还涵盖 **NIST CSF 1.1**（2018 年 4 月），并支持团队在版本之间迁移。

输出按任务定制：结构化差距评估表、含当前与目标状态的完整组织配置文件、按优先级排序的实施路线图、控制级实施指引，以及映射到特定 CSF 子类别 ID 的政策文档。

---

## 2. 目标受众

本技能面向所有行业和规模组织的安全、风险和合规专业人士。

- **CISO 和安全经理**——构建或成熟组织网络安全计划
- **风险经理和 GRC 分析师**——开展差距评估、创建配置文件或向领导层报告网络安全风险
- **安全工程师和架构师**——寻求特定 CSF 子类别的实施指引
- **合规团队**——将监管要求（HIPAA、FedRAMP、PCI DSS、州法律）映射到通用 CSF 框架
- **中小企业（SMB）**——在无大型内部团队的情况下使用 CSF 理解和优先安排网络安全投资
- **顾问**——支持客户完成初始 CSF 采用或 CSF 1.1 → 2.0 迁移

## 4. 如何使用本技能

技能在 Claude 中安装后，每当您询问 NIST CSF、网络安全风险管理、组织网络安全配置文件、实施等级或相关主题时自动激活。您无需按名称引用技能。

### 获得最佳结果的提示

**指明 CSF 版本**——说明您使用的是 CSF 2.0、CSF 1.1，还是在两者之间迁移。技能默认为 CSF 2.0。

**提供组织背景**——行业、规模、现有安全实践和已知监管义务有助于技能定制输出。例如：

> "我们是一家 50 人的医疗软件公司，有基本的安全控制但没有正式的风险管理计划。帮我们构建 CSF 2.0 当前配置文件。"

**引用特定功能、类别或子类别**——需要针对性指引时，点明功能（例如 `GV`）、类别（例如 `ID.AM`）或子类别 ID（例如 `PR.AA-05`）会产生更聚焦的响应。

**一次请求一个交付物**——差距评估、配置文件和时间表各需单独聚焦才能获得最佳结果。

### 示例交互

```
您：      我们需要对照 NIST CSF 2.0 评估当前的网络安全态势。
          我们是一家 200 人的电子商务公司。没有正式的网络安全政策，
          只有基本的资产清单，没有事件响应计划。

Claude：  [执行涵盖全部 6 项 CSF 2.0 功能的结构化差距评估：
          - GV：❌ 无政策、无风险容忍度声明——关键差距
          - ID：🟡 有基本资产清单，无正式风险评估流程
          - PR：🟡 有一些访问控制，无意识培训计划
          - DE：❌ 无持续监控，无事件分析能力
          - RS：❌ 无事件响应计划或既定标准
          - RC：❌ 无恢复计划或文件化程序
          附 30/60/90 天速胜的优先补救顺序]
```

## 5. 技能实现细节

### 架构

技能采用三层结构：

```
nist-csf/
├── SKILL.md                                  # 核心技能逻辑与工作流
└── references/
    ├── csf-20-functions-categories.md        # 全部 6 项功能、类别、子类别（CSF 2.0）
    ├── csf-10-to-20-mapping.md               # CSF 1.1 → 2.0 迁移指南和子类别映射
    └── csf-implementation-tiers.md           # 第一至四级定义、诊断与提升指引
```

`SKILL.md` 在技能触发时加载到 Claude 的上下文中。参考文件按需加载——每项任务仅加载相关文件——保持上下文使用高效。

### SKILL.md 中的内容

- **角色（Persona）**：Claude 采用 NIST CSF 顾问和网络安全风险管理顾问的角色
- **输出格式矩阵**：将每种任务类型映射到特定输出格式（差距表、配置文件文档、路线图等）
- **CSF 2.0 六功能摘要**：所有功能及其目的和关键输出
- **5 个核心工作流**：差距评估、配置文件创建、实施路线图、跨框架映射、政策生成
- **CSF 2.0 对比 1.1 比较表**：关键结构与内容差异
- **行业特定指引**：金融服务、医疗保健、能源/OT、联邦、制造、中小企业
- **参考文件加载逻辑**：何时加载各参考文件的规则

### 参考文件中的内容

| 文件 | 内容 |
|------|------|
| `csf-20-functions-categories.md` | 全部 6 项功能及完整类别和子类别清单、ID 和描述 |
| `csf-10-to-20-mapping.md` | 详细的 CSF 1.1 → 2.0 子类别迁移表、新增子类别、删除子类别、迁移清单 |
| `csf-implementation-tiers.md` | 三个维度上的完整第一至四级定义、各级别诊断指标、提升指引 |

### 构建技能所使用的输入

- **NIST 网络安全框架 2.0**（2024 年 2 月）——NIST CSWP 29——功能、类别、子类别、等级、配置文件
- **NIST 网络安全框架 1.1**（2018 年 4 月）——用于 1.1 支持和迁移指引
- **NIST CSF 2.0 快速入门指南**——中小企业、企业风险管理、政府指引
- **NIST SP 800-53 修订版 5**——跨框架映射的信息性参考
- **ISO/IEC 27001:2022**——跨框架映射的信息性参考
- **CIS Controls v8**——跨框架映射的信息性参考
- **行业特定社区配置文件**——医疗保健（HHS HPH）、金融服务（FFIEC CAT）、能源（NERC CIP）
