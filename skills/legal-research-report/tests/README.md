# 测试与评分（tests/）

本目录是 legal-research-report Skill 的内置测试环节，用于验证 Skill 产出报告的质量，也用于 Skill 修改后的回归验证。

## 什么时候跑测试

1. **交付前质量背书**：报告生成后，先跑机械校验（第一层），必要时人工评分（第三层）；
2. **Skill 修改后回归**：改动 SKILL.md / references / assets / scripts 任何文件后，用标准测试命题跑一遍完整流程（第二层），确认输出质量未退化；
3. **跨产品迁移验证**：Skill 安装到新环境（其他 AI 产品）后，用任一测试命题试跑，确认双模式判断、检索纪律、报告结构在新环境正常工作。

## 三层测试设计

| 层级 | 内容 | 工具 | 通过标准 |
|------|------|------|----------|
| 第一层：机械校验 | 结构完整性、必备表格、红线违规、案号/链接格式、计数一致性 | `scripts/check_report.py <报告文件>` | 全部 PASS（WARN 需人工确认） |
| 第二层：命题测试 | 用 3 个公司股权标准命题跑完整流程，核对预期命中点、检查是否踩中埋设陷阱 | `tests/test-cases.md` | 每个命题命中点全覆盖、陷阱零踩中 |
| 第三层：人工评分 | 按百分制评分表打分 | `tests/scoring-rubric.md` | ≥ 80 分合格；任一红线项扣分即不合格 |

## 使用方式

### 第一层：机械校验（30 秒）

```bash
python3 scripts/check_report.py path/to/报告.md
# 也支持 .txt / .html / .docx（docx 自动解包取正文）
```

脚本输出 PASS / FAIL / WARN 清单。FAIL 必须修复；WARN 由人工判断。

### 第二层：命题测试（约 20–40 分钟/题）

打开 `tests/test-cases.md`，任选一题作为用户命题输入，让 AI 按 Skill 完整流程生成报告，然后对照该题的"预期命中点"与"埋设陷阱"逐项核对。三题分别覆盖：新规+溯及力型、主体边界型、效力+履行分层型——覆盖公司股权领域最典型的三类研究难点。

### 第三层：人工评分（约 15 分钟）

按 `tests/scoring-rubric.md` 逐项打分，填写评分表底部的总评。评分人应为未参与报告生成的人员（盲评），避免自我背书。

## 注意

- 测试命题的答案要点会随规则变迁更新（尤其涉新公司法时间效力的部分），维护 Skill 时同步更新 `test-cases.md`；
- 机械校验只能发现"形"的问题（缺栏目、违规用语），"实"的问题（法条适用错误、案例误读）只能靠第二、三层发现；
- 评分结果建议留档（评分表复印件附报告归档），作为工作质量留痕。
