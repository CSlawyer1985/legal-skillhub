# 模式 B：通用降级模式（无数据库 MCP）

适用前提：宿主产品没有法律数据库 MCP 工具，但具备通用网页搜索能力（Claude Code / Cursor / CodeBuddy 等产品的 WebSearch/WebFetch 或等价能力）。

## 核心原则

没有数据库不等于放弃核验。用"通用搜索发现线索 → 公开权威源核实原文"两步走，并在报告中**如实标注每一项的核验状态**。

## 检索流程

### 第 1 步：通用搜索发现线索（2–3 轮）

- 法条线索：`"{法规名} 第N条 原文"`、`"{争议焦点} 法律依据"`；
- 案例线索：`"{争议焦点} 判决 案号"`、`"{争议焦点} 法院 裁判观点"`、`"{争议焦点} 驳回 不承担责任"`（反方必查）；
- 实务动态：`"{主题} 理解与适用"`、`"{主题} 观点分歧"`、`"{主题} 备案审查/批复/新规"`；
- 记录所有出现的法规名、条号、案号、文件名，形成**待核实清单**。

### 第 2 步：公开权威源核实

对待核实清单逐项到官方公开渠道核实（用网页读取工具访问，或给出指引由用户人工复核）：

| 来源 | 入口 | 核实内容 |
|------|------|----------|
| 国家法律法规数据库 | https://flk.npc.gov.cn | 法律/行政法规/司法解释原文与效力状态 |
| 人民法院案例库 | https://rmfyalk.court.gov.cn | 入库参考案例裁判要点 |
| 中国裁判文书网 | https://wenshu.court.gov.cn | 裁判文书原文 |
| 最高人民法院官网 | https://www.court.gov.cn | 司法解释、批复、指导意见 |
| 中国政府网 | https://www.gov.cn | 行政法规、政策文件 |
| 各地高院官网/公众号 | — | 典型案例、审判指引 |

核实规则：

1. 在官方来源查到的 → 标注"已核验"，链接按 `citation-rules.md` 模式 B 引用官方入口；
2. 只在非官方来源（律所文章、媒体报道）出现的 → 标注"互联网来源引用，未在官方渠道核实"，且关键结论须有 ≥2 个相互独立的来源交叉印证；
3. 完全查不到的 → 从报告中剔除或明确标注"未检索到"，**严禁保留无法溯源的法条与案号**。

## 降级模式的特别纪律

- 通用搜索摘要 ≠ 法条原文、≠ 裁判文书：摘要中的条文表述必须回到官方文本校对；
- 训练记忆中的法条与案号**一律视为未核实线索**，未经本轮检索印证不得直接写入报告；
- 检索过程记录表的"检索平台"一栏如实填写"通用搜索引擎 + 公开权威源人工核验"；
- 报告的核验说明中须声明："本报告在无专用法律数据库环境下完成，所有引用均经公开权威渠道核实或标注核验状态。"
