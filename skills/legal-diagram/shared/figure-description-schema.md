# FigureDescription 模式（共享）

定义 FigureDescription 对象以及 `html-export.md` 注入到独立 HTML 中的按类型内容。同时包含 `extract.md` 用于 `null_field_classification` 指令的风险评分标准。

## 字段

|字段|类型|内容|
|---|---|---|
|`title`|字符串|`<matter_name> — <category_label>`；回退 `<category_label> — <YYYY-MM-DD>`|
|`matter_context`|字符串|matter_type + 法域（如有）+ 一行当事方摘要|
|`caption`|字符串|一行，模式见下方按类型|
|`overview`|字符串|3 句话：展示什么、为什么对该事项类型重要、支持什么决策|
|`how_to_read`|字符串|图例见下方按类型|
|`observations`|字符串数组|从图表结构读出的 3-5 条通俗语言要点|
|`caveats`|字符串数组|事项类型基础集 + 图表类型补充 + 日期有效性说明|

## 按类型的标题和图例

`caption` 和 `how_to_read` 的按类型内容（与用户交流时使用通俗名称；这些字符串进入 HTML 图形）：

第 2 遍以事项语言（文档的主导语言）编写 `caption`、图例标签和 `caveats`。

|类型|标题|如何解读|
|---|---|---|
|`timeline`|“时间线：<主题>，<日期范围>”|自上而下阅读；章节标题按时期分组事件。|
|`gantt`|“甘特图：<任务/阶段>，<日期范围>”|条形宽度 = 持续时间；菱形 = 里程碑；时间从左到右流动。|
|`flowchart`|“流程图：<流程>决策路径，<上下文>”|跟随箭头；菱形 = 决策，矩形 = 流程/状态。|
|`state diagram`|“状态图：<流程>从<起始>到<结束状态>”|方框 = 状态，箭头 = 转换，标签 = 触发条件；[*] = 进入/退出。|
|`erDiagram`|“实体关系图：<N> 个实体，<M> 个关系”|方框 = 实体，线条 = 关系；基数 `||` 一、`o|` 零或一、`}|` 一或多。|
|`requirementDiagram`|“需求图：<N> 项义务映射到 <M> 项控制措施”|圆角 = 需求，方形 = 元素；箭头 = satisfies/traces/contains/copies。|
|`sequenceDiagram`|“时序图：<流程>经过 <N> 个参与者”|列 = 参与者，水平箭头 = 消息；时间自上而下流动。|
|`mindmap`|“思维导图：<根主题>”|中心 = 根；分支按层级向外辐射；缩进深度 = 层级。|
|`quadrantChart`|“象限图：<Y 轴标签> 对比 <X 轴标签>，<范围>”|位置编码两个分数；右上 = 两轴均高。|
|`journey`|“旅程图：<参与者>经过 <N> 个阶段”|行 = 参与者，列 = 阶段；1-5 分 = 摩擦/满意度。|

## 风险分类评分标准

`extract.md` 在 `obligations[].risk_level` 上的 `null_field_classification` 指令使用。

- **high（高）**：重大违约、终止、赔偿、个人数据暴露、监管期限、信义义务。
- **medium（中）**：付款、通知、报告、常规契约条款、正常经营义务。
- **low（低）**：行政性、信息性、无后果的尽最大努力措辞。

## 事项类型注意事项集

- `litigation`：“不构成法律建议。请对照源文件核实所有日期。”
- `compliance`：“所列控制措施可能未覆盖所有适用要求。请聘请合格法律顾问。”
- `corporate`：“持股百分比截至文件日期，此后可能已变更。”
- `privacy`：“所示数据流具有代表性；请对照当前处理记录核实。”
- 所有类型：“由 /legal-diagram 于 <日期> 生成。准确性取决于源材料质量。”
