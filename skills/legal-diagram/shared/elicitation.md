# 信息引导（共享）

为无文档路径精选的摄取问题集，加上标准的摘要后交付模式。由 `workflows/guided.md` 加载；交付模式也被 `workflows/generation.md` 使用。

## 事项家族摄取问题集

选择家族，询问其问题集（3-5 个问题）。每个问题集以“要映射什么”的问题结束，使选择器有意图可用。接受简写；跳过任何已回答的内容。标注的字段 = 回答所填充的 `ExtractionResult` 字段。

**诉讼**（events、parties、decision_points、concepts、risk_items）
1. 当事方及其角色？（原告、被告、保险人……）
2. 按顺序的关键带日期事件？
3. 在争议中的主张或争点？
4. 是否有需要走一遍的 if/then 法律检验（特权、时效、管辖）？
5. 展示：时间脉络、主张要件图、特权树，还是争点强度矩阵？

**公司 / 交易**（entities、ownership_links、phases、tasks、transfers、conditions）
1. 实体及持股百分比？
2. 交易当事方？（买方、卖方、出借人、托管方、监管机构）
3. 阶段或带日期里程碑（LOI → 尽职调查 → 签署 → 交割）？
4. 交割时的资金变动？
5. 展示：股权结构、交易时间线、资金流向，还是审批链？

**合规**（obligations、controls、conditions）
1. 义务或要求？
2. 来源法律或标准？
3. 控制措施及其责任人？
4. 每项义务的当前状态（合规 / 差距 / 进行中）？
5. 展示：义务到控制措施的映射，还是差距分析？

**雇佣 / 人力资源**（events、investigation_steps、decision_points、states）
1. 员工行为或投诉？
2. 带日期步骤（投诉 → 调查 → 调查发现 → 结果）？
3. 涉及的保护类别或活动？
4. 是否有决策检验（解雇风险、合理便利、休假）？
5. 展示：调查时间线，还是风险决策树？

**知识产权**（ip_assets、states、transitions）
1. 资产类型？（专利、商标、版权、商业秘密）
2. 状态和关键日期？
3. 法域？
4. 展示：申请程序状态机，还是家族树？

**隐私 / 数据**（data_flows、entities、obligations）
1. 数据类别？
2. 系统：来源 → 目的地？
3. 传输机制或合法依据？
4. 展示：数据流图、DSAR 工作流，还是义务映射？

**破产 / 重组**（claim_classes、transfers、events）
1. 债权类别和优先顺序？
2. 破产财产或分配？
3. 关键日期？
4. 展示：优先受偿瀑布图，还是案件时间线？

**税务**（entities、relationships、transfers）
1. 实体和法域？
2. 股权和资金流向？
3. 交易步骤及其税务后果？
4. 展示：结构图，还是资金流向？

**不动产 / 建设工程**（phases、tasks、parties）
1. 阶段或里程碑？
2. 当事方？（买方、卖方、出借人、总承包、分包商）
3. 关键日期？
4. 展示：交易/交割时间线，还是进度表？

**其他**（parties、events、concepts）
1. 当事方或实体是谁？
2. 有哪些事件、步骤或关系？
3. 图表应展示什么？
