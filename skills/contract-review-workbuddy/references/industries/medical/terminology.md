# 医疗行业术语表

## 一、医疗器械相关术语

### 1.1 医疗器械分类管理
| 术语 | 说明 |
|------|------|
| **第一类医疗器械** | 风险程度低，实行常规管理。如手术刀柄、医用棉签等 |
| **第二类医疗器械** | 具有中度风险，需严格控制管理。如血压计、体外诊断试剂等 |
| **第三类医疗器械** | 具有较高风险，需采取特别措施严格控制。如心脏起搏器、人工关节等 |
| **医疗器械注册证** | 国家药监局核发的医疗器械市场准入证明，有效期5年 |
| **医疗器械备案凭证** | 第一、二类医疗器械向药监部门备案后取得的凭证 |
| **进口医疗器械注册证** | 进口医疗器械经国家药监局审批后取得的注册证 |
| **医疗器械注册人** | 持有医疗器械注册证的企业或机构 |
| **医疗器械备案人** | 持有医疗器械备案凭证的企业或机构 |
| **产品技术要求** | 医疗器械注册或备案时提交的法定产品性能指标文件 |
| **临床评价** | 通过临床文献、临床经验或临床试验证明产品安全有效的过程 |

### 1.2 医疗器械经营与使用
| 术语 | 说明 |
|------|------|
| **医疗器械经营许可证** | 经营第二类、第三类医疗器械的企业需取得的许可，有效期5年 |
| **医疗器械经营备案凭证** | 经营第一类医疗器械的备案凭证 |
| **经营范围** | 许可证/备案凭证上核准的医疗器械类别和产品 |
| **冷链运输** | 在规定低温条件下运输医疗器械的方式 |
| **唯一性标识（UDI）** | 医疗器械唯一识别代码，用于追溯产品全生命周期 |
| **批签发** | 国家对疫苗类制品、血液制品、体外诊断试剂等实行的出厂检验制度 |
| **不良事件** | 已上市的医疗器械在正常使用情况下发生的导致或可能导致人体伤害的有害事件 |
| **医疗器械召回** | 医疗器械生产企业按照规定的程序对其已上市销售的缺陷产品采取警示、修理、更换等措施 |

### 1.3 医疗器械临床试验相关
| 术语 | 说明 |
|------|------|
| **申办者（Sponsor）** | 发起临床试验的法人或组织 |
| **研究者（Investigator）** | 实施临床试验的研究人员 |
| **主要研究者（PI）** | 负责临床试验实施的研究者，通常需具备高级职称 |
| **临床试验机构** | 开展临床试验的医疗机构 |
| **合同研究组织（CRO）** | 接受委托提供临床试验专业服务的机构 |
| **临床试验协调员（CRC）** | 协助研究者处理临床试验事务的专业人员 |

## 二、临床试验相关术语

### 2.1 伦理审查相关
| 术语 | 说明 |
|------|------|
| **伦理委员会（IRB/EC）** | 医学研究机构的独立审查委员会，负责审查研究方案的保护受试者权益 |
| **伦理审查批件** | 伦理委员会批准临床试验的正式文件 |
| **知情同意** | 受试者在充分了解试验信息后自愿同意参加试验的过程 |
| **知情同意书（ICF）** | 受试者签署的确认已了解试验信息并自愿参加的书面文件 |
| **法定代理人（LAR）** | 代表无民事行为能力或限制民事行为能力人签署知情同意的代理人 |
| **社区代表** | 伦理委员会中代表社区利益的非医学专业人士 |
| **持续审查** | 伦理委员会对已批准研究的定期跟踪审查 |
| **修正方案审查** | 伦理委员会对临床试验方案修改的审查 |

### 2.2 试验设计与执行
| 术语 | 说明 |
|------|------|
| **临床试验方案（Protocol）** | 详细描述试验目的、设计、方法、统计考虑的书面文件 |
| **研究者手册（IB）** | 试验用医疗器械的全部研发资料和临床前研究资料汇编 |
| **病例报告表（CRF）** | 记录每位受试者临床试验数据的标准化表格 |
| **统计分析计划（SAP）** | 详细描述统计分析方法的书面文件 |
| **数据库锁定（DBL）** | 数据库完成数据清理和分析准备，正式关闭数据修改权限 |
| **盲法** | 试验中使一方或多方不知道受试者分组信息的试验设计 |
| **随机化** | 将受试者随机分配到不同处理组的过程 |
| **对照** | 与试验组进行比较的参照组 |
| **入组/招募** | 将符合条件的受试者纳入试验的过程 |
| **脱落** | 受试者提前退出临床试验 |
**方案偏离** | 未遵循临床试验方案要求的情况 |

### 2.3 安全性监测
| 术语 | 说明 |
|------|------|
| **不良事件（AE）** | 受试者接受试验用医疗器械后出现的任何不良医学事件 |
| **严重不良事件（SAE）** | 导致死亡、危及生命、需住院治疗、导致永久残疾等严重后果的不良事件 |
| **可疑且非预期的严重不良反应（SUSAR）** | 性质与严重程度与已有资料不符的严重不良反应 |
| **数据安全监测委员会（DSMB）** | 独立委员会，定期审查安全性数据并建议是否继续试验 |
| **数据安全监控计划（DSMP）** | 确保临床试验数据安全的管理计划 |

### 2.4 人类遗传资源相关
| 术语 | 说明 |
|------|------|
| **人类遗传资源** | 含有人体基因组、基因等遗传物质的器官、组织、细胞等 |
| **人类遗传资源采集** | 收集人类遗传资源样本的活动 |
| **人类遗传资源保藏** | 对人类遗传资源进行保存的活动 |
| **人类遗传资源利用** | 以研究、开发等为目的使用人类遗传资源的活动 |
| **人类遗传资源对外提供** | 将人类遗传资源向境外组织、个人等提供的活动 |
| **人类遗传资源行政审批** | 科技部对人类遗传资源活动的审批管理 |

### 2.5 数据与隐私保护
| 术语 | 说明 |
|------|------|
| **个人信息** | 以电子或其他方式记录的与已识别或可识别的自然人有关的各种信息 |
| **敏感个人信息** | 一旦泄露或非法使用容易导致人格尊严受损或人身财产安全受危害的信息 |
| **医疗健康信息** | 个人的病历、诊断、治疗、用药等健康相关信息 |
| **去标识化** | 使个人信息在不借助额外信息的情况下无法识别特定自然人 |
| **匿名化** | 使个人信息无法识别特定自然人且不能复原 |

## 三、医生多点执业相关术语

### 3.1 执业资质相关
| 术语 | 说明 |
|------|------|
| **医师执业证书** | 医师经注册取得的执业资格证明，长期有效 |
| **执业注册** | 医师向卫生行政部门申请执业登记的过程 |
| **主执业机构（第一执业点）** | 医师主要执业所在的医疗机构 |
| **多点执业** | 医师在两个及以上医疗机构执业的制度 |
| **执业范围** | 医师执业证书上核准的临床专业范围 |
| **执业类别** | 医师执业证书上核准的类别（临床、口腔、中医、公共卫生） |
| **定期考核** | 卫生行政部门对医师业务水平、工作成绩和职业道德的定期评估（每3年一次） |
| **GCP培训证书** | 药物/医疗器械临床试验质量管理规范培训合格证书 |
| **职称** | 医师专业技术职务等级（医士/医师/主治医师/副主任医师/主任医师） |
| **执业助理医师** | 在执业医师指导下执业的初级医师资格 |

### 3.2 多点执业管理相关
| 术语 | 说明 |
|------|------|
| **多点执业备案** | 医师向卫生行政部门申请增加执业机构的手续 |
| **执业机构数量限制** | 医师多点执业机构数量的上限规定（通常不超过3家） |
| **执业时间安排** | 医师在各执业机构的排班和出诊时间 |
| **会诊** | 医师到其他医疗机构为患者提供诊疗服务 |
| **远程医疗** | 通过网络等信息技术实现的异地医疗服务 |
| **互联网诊疗** | 医疗机构利用本机构注册的医师，通过互联网等信息技术开展疾病诊断 |
| **互联网医院** | 实体医疗机构自行或第三方搭建信息平台，开展的互联网诊疗活动 |

### 3.3 医疗质量与责任
| 术语 | 说明 |
|------|------|
| **医疗质量安全核心制度** | 医疗机构保障医疗质量安全的18项基本制度 |
| **首诊负责制** | 首位接诊医师应对患者全程负责的诊疗制度 |
| **三级查房制度** | 主任/副主任、主治医师、住院医师三级查房制度 |
| **病历** | 医务人员在医疗活动过程中形成的文字、符号、图表等资料的总和 |
| **处方** | 由注册的执业医师开具的用药医嘱 |
| **处方权** | 医师开具处方的资格 |
| **特殊药品处方权** | 麻醉药品、精神药品等特殊管理药品的处方资格 |
| **医疗纠纷** | 医患双方对诊疗结果或原因产生的争议 |
| **医疗事故** | 医疗机构及其医务人员违反规定造成患者明显人身损害的事故 |
| **医疗责任保险** | 医疗机构或医师购买的职业责任保险 |

### 3.4 利益冲突与合规
| 术语 | 说明 |
|------|------|
| **利益冲突** | 医师的经济利益与患者最佳利益之间存在冲突的情形 |
| **商业提成** | 医师因推荐特定药品、检查、治疗等获取经济利益的行为 |
| **医药代表** | 药品/器械生产企业派驻医疗机构推广产品的专业人员 |
| **学术会议赞助** | 医药企业资助医师参加学术会议的行为 |
| **竞业限制** | 协议约定的禁止医师在特定范围从事竞争业务的条款 |
| **医疗广告代言** | 医师以个人名义为医疗机构或产品进行宣传推荐 |

### 3.5 医保相关
| 术语 | 说明 |
|------|------|
| **医保基金** | 基本医疗保险统筹基金和个人账户资金 |
| **医保定点** | 与医保部门签订服务协议的医疗机构 |
| **诊疗项目** | 医保规定可报销的医疗服务项目 |
| **高值耗材** | 单价较高的一次性医用耗材 |
| **DRG/DIP付费** | 按疾病诊断相关分组/按病种分值的医保支付方式 |
