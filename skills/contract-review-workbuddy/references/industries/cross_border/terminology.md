# 跨境电商行业术语表

## 一、INCOTERMS 贸易术语

| 术语 | 全称 | 中文 | 说明 |
|------|------|------|------|
| EXW | Ex Works | 工厂交货 | 卖方在指定地点（工厂或仓库）将货物交给买方即完成交货，买方承担全部费用和风险 |
| FCA | Free Carrier | 货交承运人 | 卖方在指定地点将货物交给买方指定的承运人即完成交货 |
| FAS | Free Alongside Ship | 船边交货 | 卖方在指定装运港将货物放置在船边即完成交货 |
| FOB | Free On Board | 船上交货 | 卖方在指定装运港将货物装上买方指定的船舶即完成交货 |
| CFR | Cost and Freight | 成本加运费 | 卖方支付将货物运至指定目的港所需的运费，但风险在装运港船上转移 |
| CIF | Cost, Insurance and Freight | 成本、保险费加运费 | 卖方支付运费和保险费，但风险在装运港船上转移 |
| CPT | Carriage Paid To | 运费付至 | 卖方支付将货物运至指定目的地的运费，但风险在货交第一承运人时转移 |
| CIP | Carriage and Insurance Paid To | 保险费付至 | 卖方支付运费和保险费，但风险在货交第一承运人时转移 |
| DAP | Delivered At Place | 目的地交货 | 卖方在指定目的地将仍处于运输工具上的货物交由买方处置即完成交货 |
| DPU | Delivered at Place Unloaded | 目的地卸货后交货 | 卖方在指定目的地将货物从运输工具上卸下后交给买方即完成交货 |
| DDP | Delivered Duty Paid | 完税后交货 | 卖方在指定目的地完成进口清关后，将货物交给买方即完成交货 |

### 术语分类

**适用于海运和内河运输：** FAS、FOB、CFR、CIF

**适用于任何运输方式：** EXW、FCA、CPT、CIP、DAP、DPU、DDP

|------|------|

| CO | 原产地证书（Certificate of Origin），证明货物原产地的文件 |
| FORM E | 中国-东盟自由贸易区优惠原产地证书 |
| FORM F | 中国-智利自由贸易区优惠原产地证书 |
| FORM B | 亚太贸易协定优惠原产地证书 |
| AEO | 经认证的经营者（Authorized Enterprise Operator），海关高级认证企业 |
| 报关 | 向海关申报进出口货物的行为 |
| 清关 | 完成海关手续，货物放行 |
| 完税价格 | 海关审定用于计征关税的货物价格 |
| 关税配额 | 对特定商品在一定数量内适用较低关税税率，超过配额适用较高税率 |
| 保税仓库 | 经海关批准设立的用于存储保税货物的仓库 |

| 跨境电商综合税 | 跨境电商零售进口商品按货物征收的关税、增值税和消费税的综合税率 |

| URC522 | 《托收统一规则》1995年修订本（国际商会第522号出版物） |
| SWIFT | 环球银行金融电信协会（Society for Worldwide Interbank Financial Telecommunication） |
| 外汇核销 | 出口收汇后向外汇管理部门办理核销手续 |
| 跨境人民币结算 | 以人民币进行的跨境贸易结算 |
| 第三方支付 | 通过非银行支付机构进行的跨境支付 |
| 备付金 | 支付机构为办理客户委托的支付业务而收到的预收待付货币资金 |
| 反洗钱 | 为预防洗钱活动而采取的措施 |
| 了解你的客户 | 金融机构对客户身份进行识别和核实 |
