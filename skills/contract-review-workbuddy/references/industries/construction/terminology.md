# 建筑行业合同术语表 (Construction Industry Contract Terminology)

## 一、工程类别术语

| 术语 | 英文 | 定义 |
|------|------|------|
| 建筑工程 | Building Engineering | 各类房屋建筑及其附属设施的建造活动 |
| 土木工程 | Civil Engineering | 铁路、公路、隧道、桥梁、水利等基础设施工程 |
| 机电工程 | Mechanical & Electrical Engineering | 电气、给排水、暖通、消防等安装工程 |
| 市政工程 | Municipal Engineering | 城市道路、桥梁、轨道交通、给排水管网等公共设施 |
| 装饰装修工程 | Decoration & Renovation | 建筑物内外装饰装修工程 |
| 地基基础工程 | Foundation Engineering | 建筑物地基处理、基础施工工程 |
| 主体结构工程 | Main Structure Engineering | 建筑物主体承重结构施工工程 |
| 钢结构工程 | Steel Structure Engineering | 以钢材为主的结构工程 |
| 幕墙工程 | Curtain Wall Engineering | 建筑外墙幕墙工程 |
| 古建筑工程 | Ancient Architecture Engineering | 古建筑修缮、复建工程 |

## 二、合同主体术语

| 术语 | 英文 | 定义 |
|------|------|------|
| 建设单位 | Construction Unit/Owner | 工程项目的投资方和发包方 |
| 施工单位 | Contractor | 承担施工任务的承包方 |
| 总承包单位 | General Contractor | 对工程项目全面负责的承包单位 |
| 分包单位 | Subcontractor | 从总包单位分包部分工程的单位 |
| 专业分包 | Professional Subcontract | 将专业工程分包给有资质的单位 |
| 劳务分包 | Labor Subcontract | 将劳务作业分包给劳务企业 |
| 监理单位 | Supervision Unit | 受建设单位委托实施工程监理的单位 |
| 设计单位 | Design Unit | 承担工程设计的单位 |
| 勘察单位 | Survey Unit | 承担工程地质勘察的单位 |
| 项目经理 | Project Manager | 施工单位派驻现场的项目负责人 |
| 注册建造师 | Registered Constructor | 取得注册建造师执业资格的人员 |
| 总监理工程师 | Chief Supervision Engineer | 监理单位派驻现场的总监 |
| 发包人 | Employer | 建设工程合同的发包方 |
| 承包人 | Contractor | 建设工程合同的承包方 |
| 实际施工人 | Actual Constructor | 实际从事施工的单位或个人 |

|------|------|------|

## 四、招标投标术语

| 术语 | 英文 | 定义 |
|------|------|------|
| 招标 | Tendering | 公开或邀请投标人参与竞争 |
| 公开招标 | Open Tendering | 不特定法人或组织均可参与的招标 |
| 邀请招标 | Invited Tendering | 向特定法人或组织发出邀请的招标 |
| 投标 | Bidding | 响应招标参与竞争 |
| 中标 | Winning the Bid | 被招标人确定为合同相对方 |
| 围标 | Bid Rigging | 投标人之间串通投标 |
| 串标 | Collusive Bidding | 招标人与投标人串通 |
| 陪标 | Accompanying Bid | 配合他人投标的行为 |
| 招标文件 | Tendering Documents | 招标人发布的招标相关文件 |
| 投标文件 | Bidding Documents | 投标人提交的竞标文件 |
| 标底 | Base Price | 招标人对工程的预期价格 |
| 投标保证金 | Bid Security | 投标人缴纳的保证金 |
| 履约保证金 | Performance Security | 中标人缴纳的履约担保 |
| 评标 | Bid Evaluation | 评审投标文件确定中标人 |
| 废标 | Rejected Bid | 投标被认定为无效 |
| 中标通知书 | Letter of Acceptance | 招标人发出的中标通知 |
