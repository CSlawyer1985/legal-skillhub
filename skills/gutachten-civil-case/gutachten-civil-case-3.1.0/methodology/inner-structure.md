# inner-structure

鉴定式案例分析的内在结构（三层四步）

鉴定式分析的"内在结构"指：从一个具体的设问出发，沿着请求权或抗辩权的检视，按统一的逻辑层级展开的内部章节顺序。

## 一、三层

任一具体请求权（或抗辩权）的检视，分为相互递进的三层：

1. 请求权（或抗辩权）已产生
2. 请求权（或抗辩权）未消灭
3. 请求权（或抗辩权）可行使

只有上一层成立，才进入下一层；任一层不成立，整个请求权（或抗辩权）即被否定。

## 二、四步（跨三层展开）

三层内部共分四步，按"权利产生 → 权利消灭 → 权利行使"的层级递进展开：

- **第一层（产生）**：第一步 产生要件 + 第二步 产生抗辩
- **第二层（未消灭）**：第三步 消灭事由
- **第三层（可行使）**：第四步 停止性抗辩 / 行使障碍

**第一步：权利产生要件（构成要件）**

逐一检视该请求权或抗辩权的全部构成要件是否在本案中成就。

每个要件下：先客观陈述要件含义，再涵摄案件事实，得出小结论。

要件含义不清楚 → 进入"法律解释"子流程（参 methodology/legal-interpretation-toolkit.md）。

**第二步：产生抗辩**

针对"权利产生"层面的反对事由（如行为能力缺陷、意思表示瑕疵、违法、违背公序良俗等），检视是否存在能阻断权利产生的事实。

**第三步：消灭事由**

进入"未消灭"层面：检视清偿、抵销、提存、混同、免除、解除、撤销等使权利已经消灭的事由是否发生。

> **注意：诉讼时效届满不使权利消灭**，仅产生时效抗辩权（抗辩权说/通说），属第四步"行使障碍"，不是第三步"消灭事由"。此处"撤销"指针对**已产生的合同给付请求权**，撤销权行使后法律行为自始无效，该给付请求权归于消灭。

**第四步：停止性抗辩 / 行使障碍**

进入"可行使"层面：检视先履行抗辩、不安抗辩、同时履行抗辩、保证人先诉抗辩、留置、诉讼时效抗辩等使权利暂时不能行使的事由。

## 三、形成权与返还请求权的检视定位

本节处理鉴定式分析中极易出错的一个问题：**撤销权、解除权等形成权在不同检视对象下的层级定位不同。**

### 3.1 合同存续期间的给付请求权

当检视对象是**合同存续期间的给付请求权**（如买受人请求出卖人交付标的物）时：

- 撤销权/解除权的行使 → 使已产生的合同给付请求权**消灭** → 放在**第二层（未消灭）**的消灭事由中检视
- 此时撤销/解除是"权利消灭抗辩"（《民法典》第155条）

### 3.2 撤销/解除后的返还请求权

当检视对象是**撤销/解除后的返还请求权**（如合同撤销后请求返还价款、合同解除后请求恢复原状）时：

- 撤销权/解除权的**享有与行使**是返还请求权**产生的前提** → 放在**第一层（已产生）**的产生要件中检视
- 请求权基础为《民法典》第157条第1句（撤销/无效后的返还）或第566条第1款（解除后的返还），**不是不当得利（第985条）**
- 此时须检视：是否享有撤销权/解除权（产生要件）→ 是否在除斥期间内行使（第152条/第564条）→ 是否已行使（意思表示到达）

### 3.3 关键区分原则

| 检视对象 | 形成权的层级定位 | 法理依据 |
| --- | --- | --- |
| 合同存续期间的给付请求权 | 第二层（未消灭） | 撤销/解除使已产生的请求权消灭 |
| 撤销/解除后的返还请求权 | 第一层（已产生） | 撤销/解除是返还请求权产生的前提 |

> **写作提示**：在检视返还请求权时，应先在"请求权已产生"层完成形成权的检视（享有→行使→效果），再进入后续层。不可将形成权的检视机械地放在"未消灭"或"可行使"层。

## 四、抗辩—再抗辩链

当被告提出抗辩，原告可提出再抗辩（消灭被告抗辩的反向事由）；如果再抗辩成立，被告可再提再再抗辩……如此递进，直至无新事由可主张为止。

写作时按"主张 → 抗辩 → 再抗辩 → 再再抗辩"的递进结构，每一层均完成"产生—消灭—行使"的三层四步检视。

## 五、否认 vs 抗辩的区分

- **否认**：直接否定原告主张事实的真实性。否认者无须主张新的事实，仅否认对方之主张为真。
- **抗辩**：承认原告主张事实，但主张存在另一项足以排除/消灭/阻却原告权利的新事实。

二者在举证责任和写作位置上完全不同：

- 否认 → 在该构成要件涵摄环节直接得出"要件未成就"的结论；
- 抗辩 → 进入该层的抗辩 / 消灭 / 行使阻却环节，由被告承担举证。

## 六、内部排序的固定顺序（写作友好型）

为使报告排版稳定、读者可预测，内部检视顺序固定为：

```
A. 第一层：请求权已产生
   A.1 责任成立要件（产生要件）
       A.1.1 要件一
       A.1.2 要件二
       ...
   A.2 责任范围
   A.3 产生抗辩
B. 第二层：请求权未消灭
   B.1 消灭事由检视
C. 第三层：请求权可行使
   C.1 停止性抗辩检视
```

确认之诉、形成之诉、非讼程序的检视无须严格走完三层，只需根据规范基础给出该确认/形成/非讼之要件即可。

## 七、抗辩权的检视

抗辩权（如时效抗辩、同时履行抗辩、不安抗辩、先诉抗辩等）本身亦按三层四步检视：

1. 抗辩权已产生（构成要件齐备）；
2. 抗辩权未消灭（如不再具备同时履行的客观情形）；
3. 抗辩权可行使（如已经按程序提出主张）。
