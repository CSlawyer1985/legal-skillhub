# 英语外来词——安全核心、语境判断与白名单

三组。只有**安全核心**由脚本自动替换；**语境判断**组需要判断；**白名单**原样保留。

## 1. 安全核心——自动替换（脚本）

无法语同形词的直译词，因此替换无误解风险。以 **Word 修订**方式替换（形式：`del` 旧词 → `ins` 新词），尽量保持大小写和性数一致。

| 英语外来词 | 对应词 |
|---|---|
| digital（计算机含义） | numérique |
| deadline | échéance, date limite |
| feedback | retour |
| brainstorming | remue-méninges |
| benchmark（名词） | étalonnage, comparatif |
| overview | vue d'ensemble, aperçu |
| checker | vérifier, contrôler |
| forwarder | transmettre, faire suivre |
| switcher | basculer |
| booker | réserver |
| customiser | personnaliser |
| upgrader | mettre à niveau |
| downloader | télécharger |
| uploader | téléverser |
| scheduler | planifier |
| dispatcher | répartir |
| briefer | informer |
| débriefer | faire le point |
| sponsoriser | parrainer |
| canceler | annuler |
| « sur une base régulière » | régulièrement |
| « à date » | à ce jour |

此表**可编辑**：在此添加任何确定在法语中无其他含义的直译词。

## 2. 语境判断——需要判断（不要脚本化）

**在法语中以另一种含义存在**的词（假朋友），或替换取决于语境的词。仅在阅读后、当其按英语含义使用时才纠正。

| 形式 | 错误的英语含义 | 法语含义 / 处理 |
|---|---|---|
| supporter | 忍受 ≠ 支持 | "supporter la douleur" 正确；按 *soutenir/appuyer*（支持/支撑）含义 → 纠正 |
| réaliser | 意识到 | 完成；按 *comprendre*（理解）含义 → "se rendre compte" |
| opportunité | 机会 | *opportunité* = 时机恰当性；按 *occasion*（机会）含义 → 纠正 |
| adresser（一个问题） | 处理 | *adresser* = 寄送/致送；按 *traiter*（处理）含义 → "traiter, prendre en charge" |
| impacter | 影响 | 有争议；优先用"avoir une incidence sur, affecter" |
| éligible | 可接受的 | *éligible* 可被选举；按 *recevable*（可受理）含义 → "admissible, recevable" |
| versatile | 反复无常 | 法语中 = *changeant*（易变）；按 *polyvalent*（多才多艺）含义 → 纠正 |
| définitivement | 最终地 | 按 *assurément*（肯定地）含义 → 纠正 |
| actuel / actuellement | 现在的 / 目前 | 按 *réel / en fait*（真实的 / 事实上）含义 → "réel / en réalité" |
| large | 宽的 | 按 *vaste/important*（广阔/重要）含义 → 纠正 |
| location | 出租行为 | 按 *emplacement*（位置）含义 → "emplacement, site" |
| éventuel / éventuellement | 可能的 / 如适用 | 按 *final / finalement*（最终的/最终）含义 → 纠正 |
| assumer | 承担 | 按 *supposer*（假设）含义 → "présumer, supposer" |
| baser sur | — | "se fonder sur, reposer sur" |
| au niveau de | 实际层级/楼层 | 否则 → "quant à, concernant" |
| en termes de | — | 变换："quant à, pour ce qui est de" |

## 3. 白名单——专业术语，予以保留

约定俗成的技术术语，原样保留（经使用者验证；**可编辑**）。绝不要擅自"法语化"。

`M&A`、`common law`、`civil law`、`trust`、`trustee`、`leasing`（可提及等效词 *crédit-bail*，但不强制）、`holding`、`joint-venture`、`due diligence`、`term sheet`、`covenant`、`escrow`、`closing`（并购含义）、`LBO`、`MBO`、`equity`、`spin-off`、`carve-out`、`compliance`（正式法语中优先用 *conformité*，但容忍）、`soft law`、`hard law`、`class action`、`forum shopping`、`discovery`。

**拉丁语短语**（*ratio decidendi*、*obiter dictum*、*stare decisis*、*amicus curiae*、*a priori*、*in fine*……）不是英语外来词：予以保留，用斜体。

**边界规则**：白名单术语保持英语；任何其他安全核心英语外来词被纠正；任何语境术语在阅读时裁定。如对是否属于专业术语有疑问，保留并以注释提示，而非纠正。
