# 排版与标点——规范化方案

脚本对文本节点应用的**确定性**规则。审慎原则是**规范化已存在的空格**，而非**插入**缺失的空格（以免破坏 URL、时间、代码片段）。

## 1. 不换行空格

采用的方案（精细法语排版）：

| 情境 | 插入的字符 |
|---|---|
| `;` `?` `!` 之前 | **细**不换行空格 `U+202F` |
| `:` 之前 | 不换行空格 `U+00A0` |
| `«` 之后和 `»` 之前 | 细不换行空格 `U+202F` |
| 插入性破折号 `—` 之前 | 不换行空格 `U+00A0` |

**保守**实施：脚本将符号前**已存在的普通空格**替换为相应的不换行空格；它**不会**在没有空格处**插入**空格（避免 `http://`、`12:30`、`n°` 粘连等）。插入缺失空格属于判断事项。

> 允许的变体：某些出版机构一律使用不换行空格 `U+00A0`。脚本可参数化；保持文档内部的一致性。

## 2. 弯引号（撇号）

当直撇号 `'`（`U+0027`）**前面是字母**时（缩略形式 `l’`、`d’`、`qu’`、`n’`、`j’`、`s’`、`c’`、`t’`，以及 `aujourd’hui` 等词），将其替换为弯撇号 `’`（`U+2019`）。幂等：不改动已是弯撇号的字符。

## 3. 法语书名号

将成对的直引号 `"…"` 转换为法语书名号 `« … »`，内部带细不换行空格。仅转换段落内**平衡**的成对引号；不平衡时，放弃并提示。内部英文引号（引文中的引文）变为 `“ ”`。

## 4. 破折号

- **全角破折号（tiret cadratin）** `—`：**保留**（插入语、对话）。脚本保证间距：前为不换行空格，后为普通空格（`mot — mot`），并消除英语式粘连用法（`mot—mot`）。
- **半角破折号（tiret demi-cadratin）** `–`：如其分隔数字范围（`p. 30–35`），保持不变。
- **连字符** `-`：不改动。

## 5. 多重空格与行尾

将任何普通空格序列缩减为单个空格。删除段落末尾的空格。不改动排版制表符。

## 6. 带重音大写字母——*判断*

在法语中，大写字母**应带重音**：`État`、`Île`、`Œuvre`、`À`、`É`、`È`、`Ç`。脚本修正一小批安全的情形（`Etat→État`、`Etats→États`）。其他情形（尤其是句首的 `A`→`À`，有歧义）属于判断事项，因为它们需要区分缩写的首字母（如全大写缩写的 `ETAT`）与普通单词。

## 7. 序数词、称谓、连字、引用——*确定性（v1.1）*

- **序数词**：`1ère`／`1ere` → `1re`；`2ème`／`2eme`／`2è` → `2e`；数字化的 `Xième` → `Xe`。`1er`、`2nd`／`2nde` 形式保留；含“ème”的单词（système、deuxième）不改动（规则要求有数字）。
- **称谓**：`Mr`／`Mr.` → `M.`（`Mr` 是 Monsieur 的英语借词）。
- **œ 连字**：`oeu` → `œu`（cœur、œuvre、manœuvre、vœu、nœud、bœuf、sœur、mœurs）；`oe` → `œ` 的封闭清单（œil、œdème、œsophage、œcuménique、fœtus、œstrogène、Œdipe）。元音分读（coexister、coefficient、moelle）被排除。
- **引用的不换行空格**：缩写与其后内容之间的空格变为不换行——`art.`、`al.`、`p.`、`pp.`、`vol.`、`t.`、`ch.`、`fasc.`、`col.`、`§`、`L.／R.／D.`（法典条文）、`n°`＋数字；称谓 `M.／Mme／Mlle／Me／Mgr／Dr／Pr`＋专名；`%` 和 `€` 之前用**细**不换行空格。
- **省略号**：`...` → `…`。
- **多余空格**：删除错误地放在 `,` 或 `.` 之前的空格。
