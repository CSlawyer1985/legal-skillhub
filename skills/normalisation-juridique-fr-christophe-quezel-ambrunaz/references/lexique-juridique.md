# 法律用语不当与词汇

法国法特有的词汇错误。*stipuler/disposer* 的区分是唯一由脚本**自动**处理（附主语条件）的；其余依赖含义，属**判断**范畴。

## 1. Stipuler / disposer——*确定性（脚本，附条件）*

- **Disposer**（或 *prévoir, énoncer, édicter*）：用于**法律、法规、条款、法令、命令、法典、文本**。
  - ✅ "民法典第 1240 条规定（dispose）：……"
- **Stipuler**：保留给**约定**（合同、当事人之间的协议）。
  - ✅ "合同约定（stipule）竞业禁止条款。"

脚本仅在**主语**为规范性文本（法律、条款、法令、法规、命令、法典、款项……）时将 *stipuler→disposer*。它**不触碰**"le contrat stipule"（正确），也不触碰主语歧义的用法（→ 判断）。

纠正的常见错误："la loi stipule"、"l'article 1382 stipule"、"le décret stipule" → *dispose*。

## 2. 须以判断裁定的区分

- **Juridiction / justice**：*juridiction* 是机构（法庭、法院）；*justice* 是制度。"Saisir la juridiction compétente"（向有管辖权的法院起诉）而非"saisir la justice"。
- **Arrêt / jugement**：*arrêt* = 法院（最高法院、上诉法院）的决定；*jugement* = 法庭的决定。
- **Attendu que / considérant que**：*attendu que* 用于司法法院；*considérant que* 用于行政法院。
- **Préjudice / dommage**：*dommage* 是损害本身；*préjudice* 是其可赔偿的后果。在学说语境中应遵守。
- **Prescription / forclusion / déchéance**：因时间经过而权利消灭 / 丧失起诉权（程序期限）/ 权利的丧失性惩罚。
- **Nullité / inexistence**；**responsabilité civile / pénale**；**garde à vue / détention provisoire**；**avocat / juriste /（旧）conseil juridique**。
- **Amende / peine / sanction / astreinte / dommages-intérêts**：不要混淆刑事制裁（peine、amende）、民事措施（astreinte、dommages-intérêts）和通用词（sanction）。

## 3. 法律中常见的跨领域表达与不当用语

| 应避免 | 应使用 |
|---|---|
| la loi stipule | la loi dispose（见 §1） |
| suite à | à la suite de, par suite de, en réponse à |
| au niveau de（层级/地理之外） | quant à, concernant, en matière de |
| de par | par, du fait de |
| voire même（赘词） | voire |
| au final | en définitive, finalement |
| solutionner | résoudre |
| pallier à | pallier（直接及物） |
| et/ou | l'un, l'autre ou les deux（改写） |
| par contre（正式语域） | en revanche |
| nonobstant（可以） | （正式语域中正确） |
| second / deuxième | 仅有两个要素时用 *second* |
| dommages et intérêts | dommages-intérêts（惯用拼写） |
| problématique（名词，学术之外） | problème, question |

**不应"纠正"的正确法律短语**：*en l'espèce, dès lors, partant, il échet, il appert, débouter, faire droit, ester en justice, à l'encontre de, au visa de, par ces motifs*。予以保留。

## 4. 赘词与唯一正确的用法不当——*确定性（脚本）*

仅有一种正确形式，因此自动纠正（直接编辑）：
- `voire même` → `voire`
- `pallier à` → `pallier`（直接及物）
- `au jour d'aujourd'hui` → `aujourd'hui`

其余（*de par*、*au final*、*solutionner*、*et/ou*、*suite à*……）留在**判断**层：选择取决于语境。
