# 参考文献统一——RefLex 规范与多数用法

规范性参考：**SNE RefLex 2022 编写指南**。引用的规范化**纯属形式性**：缩写、要素顺序、空格。绝不改动实质内容（司法辖区、日期、编号），也不编造引用。本任务与 `assistant-juridique-fr` 的任务 9-10 重叠；复用其逻辑。

## 原则：规范 + 内部一致性

在 RefLex 留有**容忍度**之处，采用**文档中的多数形式**，而非强加规范。检测变体，保留主导形式，统一其余部分。

| 要素 | 容忍的变体 | 规则 |
|---|---|---|
| 作者名字首字母 | `BRUN Ph.` / `Brun (Ph.)` / `Ph. Brun` | 文档多数用法 |
| 最高法院分庭 | `Cass. civ. 2e` / `Cass. 2e civ.` / `Civ. 2e` | 多数用法 |
| 日期 | `12 juill. 2023` / `12 juillet 2023` | 多数用法（建议缩写） |
| 期刊名称 | `RTD civ.` / 全名 | 多数用法 |
| 标题引号 | `« … »` / `"…"` | 与文档排版一致（`« »`） |
| 参见 | `V.` / `v.` / `Cf.` | 多数用法 |
| 页码 | `p.` / `pp.` | `p.`（RefLex） |

## 须纠正的形式错误（不容忍）

- 序数词：`1re`、`2e`、`3e`（而非 `1ère`、`2ème`、位置不当的 `2nd`）。
- 月份缩写：`janv., févr., mars, avr., mai, juin, juill., août, sept., oct., nov., déc.`
- 上诉编号：`n° 21-12.345`（带内部圆点）。
- `n° 21-12.345`、`art. 1240`、`p. 45` 中的不间断空格。

## 引用形式（RefLex 提示）

- **最高法院**：`Cass. [分庭], [JJ 缩写月 AAAA], n° [XX-XX.XXX]`——分庭：`civ. 1re/2e/3e, com., soc., crim.`；全体会议形式：`Ass. plén., Ch. mixte`。
- **国务委员会**：`CE, [组成], [日期], n° [XXXXXX]`。
- **宪法委员会**：`Cons. const., [日期], n° [AAAA-NNN] [DC/QPC]`。
- **上诉法院**：`CA [城市], [分庭], [日期], n° RG [XX/XXXXX]`。
- **法典条文**：`Art. [L./R./D.] [编号] [法典缩写]`——`C. civ., C. pén., C. com., C. trav., CPC, CPP, CJA, CSP, CSS`。
- **法律**：`Loi n° [AAAA-NNN] du [JJ 月 AAAA] [短标题]`。
- **学说（文章）**：`NOM 首字母., « 标题 », 期刊缩写 AAAA, p. X`。

## 程序

1. 清点参考文献（正文、脚注、书目）。
2. 按类别分组，记录变体及其数量。
3. 对每项容忍度保留主导形式；对不容忍的错误适用 RefLex 规范。
4. 以 **Word 修订**形式提出更正；将每项更正记入登记册（“参考文献统一”组）。
5. **不要**修改编号、日期或司法辖区：如出现实质不一致，以**评论**方式标记（`docx/scripts/comment.py`），不擅自更正。
