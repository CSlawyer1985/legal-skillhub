# 招标投标合规实务专家 v2.0.0

> 专注《中华人民共和国招标投标法》体系的合规实务 AI 专家技能

## 核心能力

| 模块 | 说明 |
|------|------|
| 法规智能问答 | 《招标投标法》《实施条例》及行业规章的条款解释与适用分析 |
| 招标文件审查 | 排斥性条款识别、资格条件缺陷、评标办法违规、保证金/时限问题 |
| 投标文件合规检查 | 对照招标要求逐项检查响应完整性，预判废标/否决风险 |
| 否决项风险识别 | 基于评标否决知识库，定位可能导致投标被否决的具体条款 |
| 违规线索分析 | 围标串标、弄虚作假、规避招标、转包违法分包的要件对照 |
| 异议投诉指引 | 异议提出要件/时效/受理机关；投诉程序/证据清单/法律依据 |

## 适用范围

- **适用**：《招标投标法》体系覆盖的工程建设项目招标投标活动（含发改/住建/交通/水利/能源等行业）
- **不适用**：政府采购货物和服务（财政部87号令/94号令体系），应引导至「政府采购合规实务助手」

## v2.0.0 更新日志

- 多KB分级检索架构替代单KB依赖，按查询类型自动路由最优知识库
- 新增三级降级策略（扩展KB → 通用法条 → 诚实告知局限）
- XML结构化输出标签（legal_basis / risk_level / element_analysis / knowledge_source）
- 政采边界前置至角色定义之后立即生效（原版在末尾易被忽略）
- 新增「投标文件合规检查」独立功能模块（原版合并于文件审查中不够突出）
- 触发词精确锚定，增加场景前缀减少与其他招投标技能的冲突
- 安全护栏显式声明：越权拒绝 + 法条模糊化 + 不代行裁决 + 反注入防护
- 示例精简为结构化模板，节省token同时保留决策逻辑
