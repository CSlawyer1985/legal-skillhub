# SKILL.md — 合同履约追踪

## 简介

上传合同 PDF → AI 自动提取付款节点/交期/到期日 → 履约台账 + 飞书提醒。

**履约状态：** 🟡待执行 / 🟢已完成 / 🔴已逾期

---

## 核心流程

1. 用户上传合同 PDF（或粘贴文本）
2. AI 自动提取字段：合同名称/编号、签署日期、付款节点、交期/交付节点、合同到期日、违约金条款
3. 建立履约台账（本地 JSON，可导出 CSV）
4. 飞书消息推送提醒

**提醒规则：**
- 节点前 3 天推送飞书
- 当天推送飞书
- 逾期每天推送飞书（直到标记完成）

---

## 输入方式

| 方式 | 说明 |
|------|------|
| PDF 上传 | 合同全文自动解析 |
| 文本输入 | 粘贴关键条款，人工补全字段 |
| 历史记录 | 查询已有合同状态 |

---

## 履约节点类型

- **付款节点**：金额 + 日期
- **交期/交付节点**：内容 + 日期
- **合同到期日**：最终期限
- **违约金/罚则**：金额或比例

## 技术要求

1. **Token 验证**：`POST https://api.yk-global.com/v1/verify`，`Authorization: Bearer {api_key}`，请求体 `{}`，用 `valid` 字段判断
2. **降级策略**：网络错误 → FREE tier，不阻断使用
3. **缓存**：验证结果缓存本地 5 分钟（TTL 300s）
4. **AI 模型**：不绑定、不推荐、不限定，用户自行配置 API Key
5. **数据存储**：本地 JSON 文件

---

## 配置项

用户需配置：
- `api_key`：Token（格式 `CONT-TRACK-*`）
- `ai_api_key`：AI 模型 API Key
- `ai_base_url`：AI 模型地址（可选）
- `feishu_webhook`：飞书机器人 Webhook URL

---

## 履约状态说明

| 状态 | 含义 |
|------|------|
| 🟡待执行 | 节点未到截止日期 |
| 🟢已完成 | 用户手动标记完成 |
| 🔴已逾期 | 超过截止日期且未完成 |
