# EAR 商业管制清单（CCL）与 ECCN 分类指南

## 如何使用本参考

本指南涵盖：(1) 详细的 ECCN 查询方法，(2) 按类别的关键 ECCN，(3) 商业国家图表的使用，以及 (4) EAR 与 ITAR 之间的管辖权确定。

---

## ECCN 分类方法

### 第 1 步：确定物品是否“受 EAR 管辖”（§ 734.3）

物品受 EAR 管辖的情形：
- **在美国境内**（包括对外贸易区内）的所有物品
- 所有**美国原产**（在美国制造）物品，无论位于何处
- **外国制造物品**，其含有超过最低限值（de minimis threshold，§ 734.4）的美国原产受控内容——视目的地为 10% 或 25%
- 满足 FDPR 标准（§ 736.2(b)(3)）的美国技术/软件的**外国直接产品**
- 总统以行政命令置于 EAR 管辖下的物品

**不受 EAR 管辖：** 可公开获取的信息（§ 734.7）、基础科学研究（基础研究排除，§ 734.8）、专利申请，以及由另一美国机构（ITAR/USML、NRC、FDA 等）专门管制的物品。

---

### 第 2 步：适用审查顺序（§ 732.3）

| 步骤 | 检查 | 如是 |
|------|-------|--------|
| 1 | 物品是否在 USML（22 CFR 第 121 部分）上？ | → ITAR 管辖；到此为止 |
| 2 | 是否由另一美国机构专门管制？ | → 该机构的规章 |
| 3 | 依 § 734.3 是否受 EAR 管辖？ | → 继续 CCL 查询 |
| 4 | 是否在 CCL 上？ | → 分配 ECCN |
| 5 | 不在 CCL 上 | → EAR99 指定 |

---

### 第 3 步：检索 CCL（第 774 部分，补充 1）

检索策略（按优先顺序）：
1. **交互式 CCL**：bis.gov/regulations/ear/interactive-commerce-control-list
2. **自行分类：** 将物品的技术参数（频率、性能、材料）与 CCL 条目的技术说明和参数比较
3. **CCATS 请求：** 通过 SNAP-R 提交 BIS-748P-A 以取得官方分类认定
4. **向 DDTC 提出 CJ 请求：** ITAR 与 EAR 之间管辖权不明时

**阅读 CCL 条目：**
每个 ECCN 条目包含：
- **条目标题：** ECCN 编号和名称
- **受控物项清单：** 决定物品是否属于该 ECCN 的具体技术参数
- **单位：** 报告用计量单位
- **管制理由（RFC）：** NS、AT、CB、NP、MT 等
- **国家图表列：** 应检查国家图表上的哪些 RFC 列
- **许可例外：** 哪些例外（LVS、GBS、CIV 等）可用
- **受控物项清单——相关管制：** 对其他 ECCN 或 USML 类别的引用
- **技术说明：** 关于测量和解释的澄清

---

### 第 4 步：EAR99——何时使用

如果在检索 CCL 后找不到涵盖该物品的 ECCN：
- 该物品为 **EAR99**
- EAR99 物品**不出现在 CCL 上**，没有 ECCN 编号
- 它们受 EAR 管辖，但通常出口不需要许可证

**EAR99 物品在以下情形仍需要许可证：**
- 运往**禁运国家**（古巴、伊朗、朝鲜、叙利亚——第 746 部分）
- 在强化管制下运往**俄罗斯或白俄罗斯**（第 746.8 部分）
- 最终用户在**实体名单**上（第 744 部分补充 4）
- 最终用途为**大规模杀伤性武器开发**（§ 744.2-744.6）
- 出口商**知晓**被禁止的最终用途或最终用户

## 商业国家图表——如何使用（第 738 部分，补充 1）

### 目的
国家图表根据物品的**管制理由（RFC）**与**目的地国家**的组合决定是否需要许可证。

### 读取图表
1. 找到目的地国家（行，按字母顺序）
2. 找到你物品 ECCN 的 RFC 列（如 NS 第 1 列、AT 第 1 列、CB 第 1 列）
3. 如果单元格显示“**X**”→ 一般需要许可证
4. 如果为空→ 该 RFC/国家组合一般不需要许可证

### 重要：多个 RFC
如果 ECCN 有多个 RFC（如 NS 和 AT），检查目的地的**所有适用列**。如果任何 RFC/国家单元格显示“X”，则需要许可证，**除非**该特定 RFC 适用许可例外。

### 国家图表列代码

| 列 | 含义 |
|--------|---------|
| NS 第 1 列 | 国家安全——敏感物品 |
| NS 第 2 列 | 国家安全——较不敏感物品 |
| MT 第 1 列 | 导弹技术 |
| NP 第 1 列 | 核不扩散——主要供应国集团 |
| NP 第 2 列 | 核不扩散——触发清单 |
| CB 第 1 列 | 化学和生物——澳大利亚集团 |
| CB 第 2 列 | 化学和生物——非澳大利亚集团 |
| RS 第 1 列 | 地区稳定——大多数物品 |
| RS 第 2 列 | 地区稳定——较不敏感 |

## 管辖权确定：EAR 与 ITAR

### “审查顺序”详解

美国政府要求出口商在确定出口分类前适用以下顺序：

**第 1 步——查阅 USML（22 CFR 第 121 部分）：**
- USML 有 21 个类别（第 I-XXI 类），涵盖军事物品
- 如果物品是“专门设计”的或在 USML 上列明 → ITAR 管辖，向 DDTC 申报
- “专门设计”标准复杂——为军用物品相同民用用途设计的物品可能仍属 EAR

**第 2 步——查阅 CCL：**
- 不在 USML 上 → 检查 CCL
- 在 CCL 上找到 → 分配 ECCN
- 未找到 → EAR99

**管辖权不明时——提交 CJ 请求：**
- **CJ（商品管辖权）请求**——提交给 DDTC
- 使用情形：物品同时有军用和商用版本；物品在出口管制改革下从 USML 移至 CCL；或存在真正的模糊性
- 时间线：45 天法定期限；实务中可能更长
- **CCATS**——BIS 确认 ECCN 的对应工具（使用 SNAP-R 门户）

### 常见的 EAR/ITAR 边界领域

| 物品类型 | 可能管辖权 |
|-----------|-------------------|
| 消费电子产品、大众市场软件 | EAR（通常为 EAR99 或 5D992） |
| 两用加密（商业 VPN、SSL） | EAR（5D002 或 5D992 ENC） |
| 军用无线电、战术通信 | ITAR（第 XI 类） |
| 卫星部件（商业通信卫星） | EAR（9A515），出口管制改革后 |
| 卫星部件（军事侦察） | ITAR（第 XV 类） |
| 枪支和弹药 | ITAR（第 I 和 III 类）；部分 EAR（霰弹枪） |
| 化学前体（两用） | EAR（类别 1） |
| 化学战剂 | ITAR（第 XIV 类） |
| 飞机部件（商业） | EAR（类别 9，较低门槛） |
| 军用飞机发动机 | ITAR（第 VIII 类） |
| GPS（商用级） | EAR（7A994、EAR99） |
| GPS（军用、高性能） | ITAR（第 XV 类） |
| 网络安全工具（商业渗透测试） | EAR（5D002，ENC 例外可能适用） |
| 网络武器和进攻性能力 | 可能为 ITAR 或单边管制 |

## 仍需要许可证的 EAR99 物品——常见错误

| 情形 | 为何需要许可证 |
|----------|--------------------|
| EAR99 电子产品出口到伊朗 | 第 746 部分禁运——需要许可证 |
| EAR99 软件卖给实体名单当事方 | 实体名单要求——需要许可证 |
| EAR99 泵出售用于核计划 | WMD 最终用途管制 § 744.2 |
| EAR99 笔记本电脑从德国再出口到俄罗斯 | 第 746.8 部分俄罗斯管制适用于所有物品 |
| EAR99 货物含 10% 以上美国含量运往 D:5 国家 | 最低限值规则——可能需要许可证 |
| EAR99 电路板在美国境内向伊朗工程师演示 | 视同出口至伊朗——检查 § 734.13 |

## 对俄罗斯和中国的 EAR 管制——2022-2026 年关键发展

### 俄罗斯和白俄罗斯（第 746.8 部分）
2022 年 2 月之后，BIS 实施了广泛的新管制：
- **所有受 EAR 管辖的物品**出口到俄罗斯/白俄罗斯均需许可证（包括 EAR99）
- 可用的许可例外极为有限（人道主义、飞行安全）
- 实体名单增补：数百个俄罗斯国防和情报实体
- **俄罗斯 FDP 规则：** 扩大后的 FDPR 捕获使用美国设备/软件生产、用于制造运往俄罗斯军事的电路的外国制造物品

### 中国先进计算管制（2022 年 10 月/2023 年 10 月）
- 新 ECCN 3A090、4A090 管制超过性能门槛的先进 AI 芯片
- 实体名单扩大，纳入半导体相关实体（华为、关联公司及其他）
- FDPR 扩大，捕获使用美国设备、运往受限制中国实体的外国制造芯片
- “ITAR 例外”物品——部分卫星/军事物品在出口管制改革下从 ITAR 移至 EAR，但有严格的 CCL 管制
