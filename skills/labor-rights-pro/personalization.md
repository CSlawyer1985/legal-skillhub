## 一、场景级双视角博弈深度（企业HR应诉 → 劳动者破解 → 仲裁员裁判倾向）

> 四大高发场景，在七步引擎通用流程之外，增加场景特有的"企业HR应诉策略 → 劳动者破解路径 → 仲裁员裁判倾向"三层分析，做到"同一场景每次分析都有针对性"，而非仅套法条。

### 场景A · 违法辞退/解除争议（最频发）
```
企业HR应诉策略（真实常见打法）：
  · 主张"严重违纪"→ 拿出员工手册某条（有时是事后补签）
  · 主张"不胜任工作"→ 用绩效C/D当证据
  · 主张"客观情况重大变化"→ 称业务撤销/架构调整
  · 沉默不举证 → 在庭审中突然抛证据

劳动者破解路径：
  · 严重违纪 → 要求公司出示该规章制度经民主程序+已公示的证据；查员工手册版本时间戳
  · 不胜任 → 末位淘汰不合法，要求公司出示"培训/调岗记录"（拿不出即违法）
  · 客观变化 → 审查是否真实（业务撤销or换人？）；是否已履行"协商变更"前置程序
  · 突然抛证据 → 当庭要求核对该证据真实性，申请仲裁委给合理质证期

仲裁员/法官裁判倾向：
  · 多数仲裁委对单方解除的**举证义务分配在公司**（举证责任倒置），公司举证不力即推定为违法
  · 员工手册民主程序是硬门槛，事后补签容易被识破
  · 末位淘汰=违法解除已成主流口径（2025年司法解释二进一步明确）
```

### 场景B · 加班费争议（第二高发）
```
企业HR应诉策略：
  · 主张"加班需审批，无审批视为自愿加班"
  · 已支付的"绩效/补贴"已包含加班费
  · 考勤记录"丢失"或只有部分时段

劳动者破解路径：
  · 无审批不必然无效——若公司安排值班/工作群指令/下班后必须回复=实际加班，审批只是管理层内控
  · 已支付的补贴不含加班费的，主张"该部分未足额"
  · 公司有义务提供考勤记录（仲裁委可责令提交），拒不提供的作不利推定

仲裁员/法官裁判倾向：
  · 对"审批制"态度日趋务实：有实际加班事实的，审批缺失不当然免除加班费
  · 考勤记录举证责任逐步倾向由公司承担（2025年新趋势）
  · 注意：综合工时制/不定时工作制需经劳动部门审批，未经审批=标准工时制
```

### 场景C · 未签合同双倍工资争议
```
企业HR应诉策略：
  · 主张"已签合同但员工自己拿走/销毁"
  · 主张"人事行政高管"负责管理合同，其自己未签不适用双倍工资
  · 主张"补签时程条款"（入职后补签但倒填日期）

劳动者破解路径：
  · 公司签合同的举证责任在用人单位——拿不出原件+员工签字即推定未签
  · 人事高管例外也有争议：仅限实际负责合同管理的HR负责人，普通员工不适用
  · 倒签无合意证据（无法证明员工自愿追认）→可抗辩

仲裁员/法官裁判倾向：
  · 对"员工拿走"类抗辩审查极严，需公司提供签收记录/监控/证人，基本很少采信
  · 双倍工资计算基数：按月应发工资（含补贴津贴，不含非常规奖金）——区域口径见 regional.md
```

### 场景D · 绩效考核与末位淘汰类争议
```
企业HR应诉策略：
  · 主张"绩效不胜任→培训调岗→仍不胜任"的法定流程已履行
  · 用绩效排名C/D/D+作为不胜任证据
  · 主张"由于公司经营困难，合法经济性裁员"

劳动者破解路径：
  · 末位≠不胜任：排名在末位不代表"不能胜任工作"——要求公司出示"客观不能胜任"的独立证据而非仅排名
  · 培训调岗是否真实：培训内容是否针对短板？调岗是否降薪/变相逼退？
  · 经济性裁员：需提前30天通知工会+向劳动部门报告，人数/比例有法定门槛

仲裁员/法官裁判倾向：
  · 末位淘汰=违法解除（2N）已为各地仲裁委主流口径
  · 绩效考核制度民主程序审查逐年趋严
  · 数字绩效排名不能直接等于不能胜任——需公司举证"该员工能力客观上低于同类岗位要求"
```

## 二、基础场景个性化推演模板（按用户具体信息自动填充）

> 以下5个最基础场景，每个都给出一套**按用户具体信息自动填充的个性化分析框架**，避免"每个案子都给同一段法条描述"。Agent 识别场景后，按对应模板填入用户提供的事实数据，生成该用户专属的计算/推演。每个模板尾部附"对方最可能抗辩"提示，增强务实针对性。

**模板① · 违法辞退全推演（首次咨询基础版）**
```
用户输入：离职时间[X]、解除理由[Y]、工作年限[Z年]、月平均工资[W元]
自定义分析：
  · [X年X月X日] 公司以 [Y] 解除 → 属于 [单方解除/协商/自动离职]
  · 违法点自检：[ ]公司有工会? [ ]提前30天? [ ]解除理由有事实依据? [ ]制度经过民主程序?
  · 若用户无过错但公司无合法理由 → 第87条 违法解除(2N)
  · 若公司主张"严重违纪" → 要求出示制度+公示+违纪证据
  · 分段计算：入职到2008.1.1 → 旧法；2008.1.1 至今 → 新法
  · 2N = [W]元 × [Z]年 × 2 = [金额]元
对方大概率抗辩：["严重违纪"/"不胜任"/"客观变化"]
```

**模板② · 拖欠工资/加班费全推演**
```
用户输入：欠薪月数[X]、月应发[Y]、合同写[Z]、实际发[W]
差异化分析：
  · 欠薪金额 = [X]月 × [Y]元 = [A]元（含补贴津贴）
  · 加班费举证缺口：用户有[ ]考勤/[ ]审批/[ ]工作群记录?
  · 阴阳合同检测：Z≠W → 触发专题十二，建议收集银行流水+个税+工资条
  · 时效：欠薪在职期间不受1年限制；已离职→离职工资结清日算1年
针对性风险提示：
  · 若用户缺考勤记录 → 建议：①让仲裁委责令公司提交 ②提供工作群/邮件证据
  · 若公司主张"已包含在绩效里" → 要求公司出示绩效制度原文
```

**模板③ · 未签合同双倍工资全推演**
```
用户输入：入职日期[X]、合同状态[Y]、主张月份[Z]
差异化分析：
  · [X+1月] ~ [X+12月] 期间未签 → 可主张第2-12月共11个月双倍工资
  · 基数 = [W]元/月 × 11 = [金额]元
  · 时效陷阱：双倍工资逐月算1年时效，从"当月工资发放日"起算
  · 若用户为HR/高管 → 需核实是否"负责合同管理"，否则不自动排除
针对性风险提示：
  · 用户最可能的漏洞：①公司倒签合同（看签字日期）②公司补签未追认
  · 若用户有微信/邮件催签记录 → 强化双倍工资主张的证据链
```

**模板④ · 试用期争议全推演**
```
用户输入：合同期限[X年]、试用期约定[Y月]、是否延长过[Z]
差异化分析：
  · 法定上限检测：X≥3年→≤6月；1年≤X<3年→≤2月；X<1年→≤1月
  · 二次约定检测：Y已约定一次+又延长→二次约定违法→第83条赔偿金
  · 试用期工资检测：不得低于合同工资80%+当地最低工资
针对性风险提示：
  · 若用户已过试用期 → 注意公司不能"二次试用"
  · 若公司以"试用期不合格"解除 → 需要法定不符合录用条件证据，不能仅口头说"不行"（试用期走"录用条件"逻辑，非转正后"不胜任"逻辑，见 SKILL.md §9.1 反模式③）
```

**模板⑤ · 经济补偿计算全推演（按用户数据自动计算）**
```
用户：入职[X年X月X日]，离职[Y年Y月Y日]，月平均工资[W元]，当地封顶线[L元]
  Step1 总年限 = (Y-X) = [Z年Z月]
  Step2 分段：2007年及以前 = [N_pre]年（旧法）；2008.1.1至今 = [N_post]年（满6月按1年）
  Step3 封顶检测：W > L×3? [是/否] → 是则基数封顶为L×3
  Step4 合计 N = N_pre + N_post = [N总]
  Step5 经济补偿 = [W] × [N] = [金额]
  Step6 若违法解除 → 2N = 金额×2 = [总金额]
```

## 三、场景路由速查（触发方式专项 · 大白话→场景→模板 一步到位）

> **作用（触发方式/能力边界确定性加固）**：把"用户大白话 → 命中哪个场景 → 调哪个模板/破解模块"的映射固化成一张表，让复杂/口语表述**一次路由到位**，减少"再看一眼才触发"的迟疑，也避免误触发到无关场景。

| 用户大白话（原话样本） | 路由场景 | 调用模块 | 边界提示 |
|------|------|------|------|
| "被开了/炒了/毕业了/优化了/让我走人" | 违法辞退 | 场景A + 模板① | 先核是否"协商解除"（协商则非违法） |
| "调岗降薪逼我走/不给安排活/冷暴力" | 被迫离职 | 场景A变体 | 须先发被迫解除通知书再主张2N |
| "加班不给钱/加班费被吞/值班没算钱" | 加班费 | 场景B + 模板② | 综合/不定时工时需经审批，未审批按标准工时 |
| "没签合同/说签了但没给我" | 未签合同双倍 | 场景C + 模板③ | HR/高管负责合同管理者例外 |
| "试用期还要延/试用期被开/试用不过" | 违法试用期 | 模板④ | 走"不符录用条件"非"不胜任" |
| "绩效垫底/打D/末位淘汰要开我" | 绩效解除 | 场景D | 末位≠不胜任，末位淘汰违法 |
| "干了X年离职能拿多少/N怎么算/n+1" | 经济补偿 | 模板⑤ | 跨2008分段、高薪封顶 |
| "合同写5000实发15000/工资拆分/发现金" | 阴阳合同 | 模板②+专题十二 | 按实际工资，需流水/个税/工资条 |
| "签的A公司B公司管我/集团调动没重签" | 混同用工 | E008 | 列共同当事人 |
| "骑手/网约车/外包被开/超龄被辞" | ⚠️灰色地带 | 先核劳动关系子流程 | 不默认套用/不默认排除，先定关系 |

> **误触发防呆**：当劳动关键词与非劳动语义共现（如"离婚+工资分割""借钱给公司"），先澄清"工资/款项部分是否属劳动报酬"，再决定是否进入本技能（对应 SKILL.md §2.6③、E004）。
