# 场景专题库（Scenario Playbooks）

> 用法：识别用户场景 → 套用对应专题的「五段式」结构输出（诊断流程 → 核心法条 → 计算式 → 证据清单 → 常见败因）。所有金额计算须引用 statutes.md 速查基准；需权威判例/法条核验时调用 connectors.md。

## 专题一：违法辞退 / 开除

**诊断三步**：①有无书面通知及理由 → ②理由是否成立（违纪/不胜任/客观变化/裁员）→ ③程序是否合法（工会/送达）。

**主张路径**

| 情形 | 最佳主张 | 金额 | 举证难度 |
|------|----------|------|----------|
| 明确违法解除 | 2N | 2×年限×月工资 | 中 |
| 难证违法 | N（经济补偿） | 1×年限×月工资 | 低 |
| 逼员工自辞 | 被迫解除+N（第38条） | N+其他 | 中高 |

**核心法条**：第39/40/41/43/46/47/48/87条。

---

## 专题二：工资 / 加班费 / 年假拖欠

**公式**（见 statutes.md 速查）：加班费150/200/300%；年休假300%。
**加班费举证优先级**：①加班审批单 ②考勤+工作成果时间戳 ③工作群非工作时间消息 ④深夜打车报销 ⑤同事证言。
**关键点**："隐形加班/实质加班"不以在公司场所为限，2024年后多地支持。

---

## 专题三：未签书面合同 / 试用期违法基础

双倍工资：起算入职第2个月，最多11个月，逐月计算时效。
核心法条：第19条（期限）、第83条（违法试用期赔偿）、第82条（双倍工资）。深化见专题六。

---

## 专题四：工伤 / 社保补缴

工伤认定：事故发生30日内单位申报，1年内个人申报。待遇以《工伤保险条例》为准。社保补缴部分地区仲裁不受理，走行政（社保征收机构/劳动监察，第86条）。

---

## 专题五：竞业限制 / 离职证明 / 档案转移

- 竞业限制：仅限高管/高技/其他负有保密义务人员；离职后单位须按月付补偿金（一般≥离职前12个月平均工资30%且≥最低工资），单位3个月不付可解除
- 离职证明、档案与社保关系转移：《劳动合同法》第50条强制义务，可单独主张

## 专题六：试用期全专题（★重点）

> 覆盖：试用期限设定、违法延长试用期补偿、试用期包含在合同期限、试用期考核导致延长。

### 6.1 试用期限设定合法性审查（第19条）

| 合同期限 | 法定试用期上限 | 常见违法点 |
|----------|----------------|------------|
| 完成工作任务为期限 / <3个月 / 非全日制 | 不得约定 | 违法约定试用期 |
| 3个月≤合同<1年 | ≤1个月 | 约定2-3个月 |
| 1年≤合同<3年 | ≤2个月 | 约定3-6个月 |
| ≥3年 / 无固定期限 | ≤6个月 | 约定1年 |

**违法情形**：超法定上限；仅约定试用期无正式期；同一单位与劳动者约定两次及以上；试用期工资<转正80%或<最低工资。

### 6.2 违法延长试用期补偿（第83条）

```
违法试用期赔偿金 = 试用期满月工资 × 已经履行的超过法定试用期的期间
（与正常工资并行不抵扣；超期期间若按低标准发薪，另主张工资差额）
```
**示例**：合同3年（上限6个月），实际履行10个月试用期 → 超期4个月×试用期满月工资=赔偿金。

### 6.3 试用期包含在劳动合同期限内（第19条第4款）

- 试用期必须包含在合同期限内。
- "先签3个月试用期合同再签正式合同" → 两段合并；首段视为正式期，第二段不得再约定试用期（否则"再次约定"违法）。
- 仅约定试用期的首段期间可能被认定未签书面合同 → 双倍工资风险。

### 6.4 试用期考核导致"延长试用期"

**法律结论**：
1. **不得延长/二次约定**。"同一用人单位与同一劳动者只能约定一次试用期"，约定一次即锁死。
2. 以"考核不合格"延长 → 违法约定试用期 → 第83条赔偿金。
3. 以"考核不合格"**解除** → 须依第39条（试用期间被证明**不符合录用条件**）：
   - 四要件：录用条件事先明确告知 + 考核标准明确可量化 + 解除须在试用期内 + 有证据证明不符合录用条件；
   - 缺任一 → 违法解除2N。
4. "试用期不胜任"≠"不符合录用条件"，法律路径不同不可混用。

**证据清单（劳动者主张违法延长赔偿金）**：
```
□ 劳动合同（证明法定上限）
□ 工资流水（试用期满月工资、超期期间发放标准）
□ 延长试用期的通知/沟通记录
□ 考核标准文件（是否事先告知、是否明确）
```

**常见败因**：签字确认"自愿延长试用期"（部分地区认定有效）→ 提示谨慎签署任何延长协议，优先主张签约前未告知。

## 专题七：绩效考核争议（★重点）

> 覆盖：绩效分数/不达标/各分数段奖惩机制 → 延长试用期、降薪、调岗、解除劳动合同。

### 7.1 绩效制度合法性前提（一切惩戒基石，第4条/第39条）

公司依绩效作不利处理的前置有效性条件：①内容合法 ②经民主程序（职代会/全体职工讨论+工会协商）③公示告知（签收）。
> 未经公示告知的绩效制度，**不得作为解除或处罚依据**——这是劳动者最核心抗辩点。

### 7.2 各分数段奖惩机制的合法性边界

| 公司动作 | 合法性判断 | 依据 |
|----------|------------|------|
| 绩效奖金/年终奖与分数挂钩（少发/不发奖金） | 一般合法（奖金非法定工资） | 意思自治 |
| 扣减基本工资（底薪） | **违法**（工资不得单方扣减） | 第50条 |
| 降薪（降低固定工资） | **违法**（变更合同须协商一致） | 第35条 |
| 调岗（薪随岗变） | 协商合法；单方依第40条须合理（不侮辱、不随意降薪） | 第35/40条 |
| 延长试用期 | **违法**（见专题六） | 第19条 |
| 解除劳动合同 | 须走法定路径（见7.3） | 第39/40条 |

> **核心区分**：绩效奖金浮动合法，基本工资单方降低违法。公司以"绩效不达标"扣基本工资属违法。

### 7.3 绩效考核不达标 → 解除劳动合同的法定路径

**唯一合法路径（不胜任解除）**：第40条第（二）项
```
证明不胜任 → 培训 或 调整工作岗位 → 仍不胜任 → 提前30日通知或+1代通知金 + N
```
**禁止路径**：
- ❌ 仅凭"绩效分数低/末位"直接解除 → 违法2N
- ❌ **末位淘汰**：最高法明确"末位淘汰/竞争上岗"单方解除，劳动者主张违法解除继续履行或赔偿金的应予支持
- ❌ 未培训/未调岗即解除
- ❌ 解除理由写"不胜任"却实为"不符合录用条件"（试用期）混用

**证据清单（公司须举证，劳动者可反击）**：
```
□ 绩效制度经民主程序+公示告知
□ 考核标准明确、客观、与岗位相关
□ 员工签字确认的考核结果
□ 不胜任的量化证据（非主观评价）
□ 培训记录 或 调岗通知及新岗合理性
□ 二次考核仍不胜任证据
□ 通知工会 + 提前30日/代通知金
```

**常见败因**：主观评语代替客观不胜任证据；未走培训/调岗前置；末位≠不胜任却直接解除。

### 7.4 诊断流程（用户说"因绩效被…"）

```
① 处理类型？延长试用/降薪/调岗/解除
② 绩效制度你是否签收公示过？（未公示→全部抗辩成立）
③ 是否协商一致？（单方=违法风险高）
④ 若解除：是否走"培训/调岗后仍不胜任"程序？是否末位淘汰？
⑤ 主张：违法→2N；违法降薪→补差额+可被迫解除+N；违法调岗→可拒绝并要求原岗
```

## 专题八：病假 / 非全额带薪假工资计算（★重点）

> 覆盖：病假工资、医疗期、事假、法定带薪假（婚丧产陪产等）及非全额带薪情形。

### 8.1 病假工资（核心）

- **下限**：病假工资或疾病救济费可低于最低工资，但**不得低于当地最低工资标准的80%**（劳部发〔1995〕309号第59条）。
- **基数与比例各地不同**（见 regional.md），须标注 `[需核实当地口径]`：
  - 上海：按连续工龄比例（<2年60%、2-4年70%、4-6年80%、6-8年90%、≥8年100%）；疾病救济费（<1年40%、1-3年50%、≥3年60%）
  - 北京/多数地区：不低于最低工资80%（部分按本人工资比例）
- **计算式**：`病假工资 = 计算基数 × 病假工资比例 × 病假天数`（或 日病假工资 = 本人工资 ÷ 21.75 × 比例）。

### 8.2 医疗期（劳部发〔1994〕479号）

| 实际工作年限 | 本单位工作年限 | 医疗期 |
|--------------|----------------|--------|
| <10年 | <5年 | 3个月 |
| <10年 | ≥5年 | 6个月 |
| ≥10年 | <5年 | 6个月 |
| ≥10年 | 5-10年 | 9个月 |
| ≥10年 | 10-15年 | 12个月 |
| ≥10年 | 15-20年 | 18个月 |
| ≥10年 | ≥20年 | 24个月 |

> 医疗期内用人单位不得依第40/41条解除合同（第42条）。医疗期满仍不能从事原工作及另行安排工作的，可依法解除（须支付经济补偿，医疗补助费争议见 statutes.md 效力变更记录）。

### 8.3 其他假期工资性质

| 假期类型 | 工资性质 | 说明 |
|----------|----------|------|
| 事假 | **无薪**（不计发） | 单位规章制度可规定 |
| 病假 | **部分薪**（≥最低工资80%） | 见8.1 |
| 婚假/丧假 | 法定带薪 | 工资支付暂行规定第11条 |
| 产假 | 法定带薪（98天+难产15+多胞胎每婴15+地方延长） | 生育津贴由生育保险支付，低于工资由单位补足 |
| 陪产假/育儿假/护理假 | 地方规定（多带薪） | 各省天数不同，[需核实当地] |
| 年休假 | 带薪（未休另付300%） | 见专题九 |

**常见败因**：公司按"事假"扣病假工资（违法）；以病假超医疗期直接解除未走法定程序；混淆病假与医疗期。

## 专题九：年休假争议（★重点）

### 9.1 天数与资格

- 连续工作**满1年**以上享受（《职工带薪年休假条例》第2条）
- 满1年<10年→**5天**；满10年<20年→**10天**；满20年以上→**15天**

### 9.2 折算规则（高频争议）

**新进单位当年**（条例+实施办法第5条）：
```
当年度年休假天数 =（当年度在本单位剩余日历天数 ÷ 365）× 全年应享受天数
（折算后不足1整天的部分不享受）
```

**解除/终止当年**（未安排休假）：
```
应休未休天数 =（当年度已过日历天数 ÷ 365）× 全年应享受天数 - 已休天数
（不足1整天不支付）
```

### 9.3 未休年休假工资

```
未休年休假工资 = 未休天数 × 日工资 × 300%
（注：含正常工作期间已付工资，实际另付200%差额）
日工资 = 前12个月剔除加班费的月平均工资 ÷ 21.75
```

### 9.4 不享受当年年休假情形（条例第4条）

- 依法享受寒暑假且天数≥年休假
- 请事假累计≥20天且单位不扣工资
- 累计工作满1<10年请病假累计≥2个月；满10<20年≥3个月；满20年以上≥4个月

**时效**：仲裁一般支持当年+前1年度（部分地区支持2年），[需核实当地]。
**常见败因**：公司称"已安排休假员工不休"但无安排证据；以"未申请"为由拒付（安排义务在公司）；超过时效部分被驳回。

## 专题十：经济补偿金计算（★重点，用户特别指定）

> 覆盖：计算基数（平均工资）、工作年限折算、高薪封顶、违法解除2N、代通知金+1、**年限按哪个月折算 / 分段计算**。

### 10.1 计算基数（平均工资）

- 依据：《劳动合同法》第47条 + 《实施条例》第27条
- **基数 = 劳动合同解除或终止前12个月的"应得工资"平均**（含计时/计件工资、奖金、津贴补贴、加班费等货币性收入）
- 工作不满12个月 → 按实际工作月数平均
- ⚠️ 实践对"是否含加班费"各地有细微差异，多数按含加班费处理；若当地裁审口径剔除，标注 `[需核实]`。
- ⚠️ **阴阳合同特别提示**：企业以"合同写最低工资/统一标准"规避经济补偿基数时，仍应按**实际应得工资**（银行流水/个税申报/工资条证明确认）计基数，补贴津贴一律计入、加班费多数计入。详见**专题十二**。

### 10.2 工作年限折算（核心，用户痛点）

| 工作年限 | 折算月数（N） |
|----------|---------------|
| <6个月 | 0.5个月 |
| 6个月≤X<1年 | 1个月 |
| 满N年，余<6个月 | N个月 |
| 满N年，余≥6个月 | N+1个月 |

**示例**：
- 工作3年5个月 → N=3（余5月<6）
- 工作3年7个月 → N=4（余7月≥6）
- 工作5年 → N=5
- 工作5年1个月 → N=5（余1月<6）

### 10.3 高薪封顶

- 月工资 > 用人单位所在地上年度职工月平均工资**3倍** → 按3倍支付，且支付年限**最高不超过12年**
- 普通工资（≤3倍社平）→ 不受12年限制，按实际年限

### 10.4 各项金额汇总

```
经济补偿 N = 基数 × 折算月数（受封顶限制见10.3）
违法解除赔偿金 = 2N（第87条）
代通知金 +1 = 上一个月工资标准（第40条三种情形且未提前30日）
```

### 10.5 分段计算（跨越2008-01-01《劳动合同法》施行日，★关键）

**法律依据**：《劳动合同法》第97条第3款——本法施行前已存续、施行后解除/终止应支付经济补偿的，**2008年前按当时规定执行，2008年后自施行日起算**。

**实务规则**：
- 2008年前：适用当时规定（原481号时期）——协商解除、不胜任解除**受12个月封顶**，无3倍社平限制
- 2008年后：适用新法——普通情形不受12个月限制，高薪3倍封顶且≤12年
- 故工作年限跨越2008年的老职工，经济补偿**应分段计算**，两段分别适用不同规则后相加

**示例**：1998年入职，2026年协商一致解除，前12月平均工资2万（假设当地社平3倍为3万，未封顶）。
```
2008年前（1998-2007，约10年）→ 按当时规定封顶12个月 → 12个月
2008年后（2008-2026，约18年）→ 按新法实际年限 → 18个月
合计 N = 30个月
```
> 若直接按"总工龄28年"单段算会漏算/错算封顶，必须分段。涉及2008年前工龄务必主动提示用户并分段。

### 10.6 常见败因

- 把"6个月以下"误算成0（应为0.5）
- 忘记高薪封顶（>3倍社平按3倍且≤12年）
- 跨越2008年未分段 → 金额严重偏差
- 基数错误剔除加班费/奖金（应含）
- 误把"代通知金+1"当独立赔偿（仅第40条三种情形且未提前30日才加）

## 专题十二：阴阳合同 / 实际工资基数认定（★重点，用户特别指定）

> 覆盖：企业以"劳动合同记载工资 ≠ 实际约定/发放工资"（多为当地最低工资或统一某一标准）规避**社保缴费基数、加班工资计算基数、经济补偿金基数**；劳动者如何以实际证据主张"本人实际工资"，而非合同纸面低额工资。

### 12.1 核心法律立场

- **劳动报酬以实际履行为准**：劳动合同记载工资明显低于实际发放且无合理说明的，裁审机关一般按**实际工资**作为各项计算的基数（"阴阳合同"中，对劳动者不利的低额合同记载不能对抗实际履行事实）。
- **社保缴费基数**依法为职工上年度月平均**实际工资**（《社会保险法》第60条），企业按最低基数缴纳属未足额缴纳（第86条）→ 走行政途径补缴。
- **加班费基数**依法应为实际应得工资（非纸面"基本工资"），具体口径见 regional.md。
- **经济补偿基数**依法为前12个月**实际应得平均工资**，含全部货币性收入（实施条例第27条）。

### 12.2 三类规避场景与对应主张路径

| 规避目标 | 企业典型做法 | 劳动者主张依据与路径 |
|----------|--------------|----------------------|
| **社保缴费基数** | 合同写最低工资，按最低基数缴社保 | 《社会保险法》第60/86条 → 向社保征收机构/劳动监察投诉，要求**补缴基数差额**（行政途径，仲裁多不受理社保补缴本身） |
| **加班费计算基数** | 合同写低额"基本工资"作加班基数 | 应按**实际应得工资**作基数（各地口径见 regional.md）→ 主张加班费差额 |
| **经济补偿金基数** | 合同低额工资作 N 基数 | 实施条例第27条 → 按前12个月**实际应得平均工资**（含加班费、各项补贴津贴） |

### 12.3 主张"实际工资"的四大证据（★关键，务必让用户备齐）

```
□ 工资条 / 工资单：证明应发项目构成（基本工资 + 绩效 + 补贴 + 津贴 + 加班费），而非合同单一低额
□ 银行打卡流水：证明实际入账金额，最关键、最不易篡改（首选证据）
□ 个税 APP / 自然人电子税务局查询的"收入纳税明细"：证明单位向税务申报的实际工资
□ 入职 Offer / 录用邮件 / 微信谈薪记录：证明"谈定的真实工资标准"
□ 社保缴费明细：反证单位按何基数缴纳（与合同低额互相印证"阴阳"事实）
```
> **证据链优先级**：银行流水 > 个税申报记录 > 工资条 > Offer/聊天记录。四项能**互相印证**形成闭环最佳；若仅持"劳动合同"而无实际发放证据，存在被按合同低额工资认定的风险。

### 12.4 经济补偿金基数必须含加班费、各项补贴津贴（强化，用户特别指定）

- 依据《劳动合同法实施条例》第27条：经济补偿的月工资按**应得工资**计算，包括**计时/计件工资、奖金、津贴和补贴、加班加点工资**等全部货币性收入。
- 即便存在"阴阳合同"写低额，仍应以**实际应得（含各项补贴津贴 + 加班费）**为计算基数。
- 实务提示：少数裁审口径对"是否剔除加班费"有差异，但**补贴津贴一律计入**，加班费多数计入；如当地剔除加班费须明确标注 `[需核实当地口径]`（见 regional.md）。

### 12.5 诊断流程（用户说"合同工资比实际少"）

```
① 合同记载工资 与 实际发薪 差额多大？（差额越大，"阴阳"概率越高）
② 实际发薪证据是否齐全？（银行流水/个税/工资条/Offer）
③ 争议落点：社保基数 / 加班费基数 / 经济补偿基数？（对应12.2路径）
④ 主张策略：以实际证据推翻合同低额 → 按实际工资重算各项金额
⑤ 社保补缴走行政，加班费/经济补偿差额走仲裁
```

### 12.6 常见败因

- 仅持"劳动合同"主张，未提供实际发放证据 → 可能被按合同工资认定
- 现金发放、无银行流水 → 难以证明实际工资（须靠个税申报+工资条+证人补强）
- 个税申报工资也偏低（企业两头低报）→ 需结合 Offer/聊天/工资条形成完整证据链
- 误以为"合同写了就认" → 应主动举证实际履行事实
- 经济补偿漏算补贴津贴/加班费 → 金额严重偏低（见 12.4）
