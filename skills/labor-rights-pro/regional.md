# 地区差异化库（Regional Differences）

> 用法：识别用户所在地 → 套用对应裁审口径（社保补缴受理、加班费基数、年休假时效、经济补偿封顶、病假工资下限、特殊假等）。凡未列明或可能变更的，输出标注 `[需核实当地口径]`。

> **口径版本戳（准确性自检 · 对应 E 维度输出准确性）**：本库每一省级口径行均须随附法律依据或口径来源；凡无明确来源支撑的结论，一律标 `[需核实]` 而非当作确定值。省表数值（产假天数 / 年假时效 / 病假下限）随各地最新规定调整，输出前以 §八 step0.5 复核，不把旧值当确定结论。涉及具体金额/受理/时效的，始终优先 connectors 核实当地高院/仲裁委最新口径。

## 全国基准（确定性结论 · 直接给，不标 [需核实]）

> **为什么单列**：评测反馈部分常见结论因"标了 `[需核实]`"而显得不确定。以下为**全国统一、法律明文规定**的确定性结论——凡用户未指定地区或问通用口径时，**直接给出、不标 `[需核实]`**；仅当结论含**地区差异化变量**（最低工资标准 / 社平工资3倍封顶线 / 奖励假天数 / 超龄·新业态认定等）时才标 `[需核实当地口径]`。目的：减少常见结论的 `[需核实]` 冗余面，提升输出准确性与确定感。

| 全国基准结论 | 法律依据（可直接核实） |
|------|------|
| 劳动仲裁**不收费** | 调解仲裁法第53条 |
| 仲裁时效**1年**；拖欠报酬在职期间不受限，终止后1年内提出 | 调解仲裁法第27条 |
| 产假**98天**，难产增加15天，多胞胎每多生育1个婴儿增加15天；生育津贴由保险付，低于工资单位补足 | 女职工劳动保护特别规定第7条 |
| 病假工资底线 **≥当地最低工资80%** | 劳部发〔1995〕309号第59条 |
| 未休年假 **×日工资×300%**（实另付200%差额）；时效一般当年+前1年 | 条例第5条/实施办法 |
| 违法解除赔偿金 **2N**（2×经济补偿） | 劳动合同法第87条 |
| 终局裁决：追索≤当地最低工资12个月金额且标准明确，对用人单位终局 | 调解仲裁法第47条 |
| 经济补偿基数=前12月实际应得平均工资（含补贴津贴+加班费） | 实施条例第27条 |
| 试用期只能约定**一次**；合同3年以上试用期最多6个月，延长=二次约定违法 | 劳动合同法第19/83条 |
| 加班费倍率：平时**1.5倍**、休息日**2倍**（不安排补休）、法定节假日**3倍** | 劳动法第44条 |
| 代通知金 **N+1**：无过失性辞退（第40条）未提前30天书面通知，额外付1个月工资 | 劳动合同法第40条 |
| 未签书面合同双倍工资：用工超1个月不满1年，支付**第2–12个月**双倍（最多11个月） | 劳动合同法第82条 |
| 书面劳动合同须在**用工之日起1个月内**订立 | 劳动合同法第10条 |
| 工资**至少每月支付一次**；解除/终止时**一次性结清** | 工资支付暂行规定第7条 |
| 工伤认定申请：单位**30日内**、职工个人**1年内**申请 | 工伤保险条例第17条 |
| 竞业限制期限**≤2年**，且用人单位须在离职后按月支付经济补偿，否则劳动者可不履行 | 劳动合同法第23/24条 |
| 无固定期限合同：连续订立**2次**固定期限后续订，或连续工作**满10年**，劳动者提出即应订立 | 劳动合同法第14条 |

> 上表为确定性底线，输出时**默认直接给、不标 `[需核实]`**；地区奖励假/特殊认定差异见下方各省表，仍须标 `[需核实当地口径]`。
> **准确性护栏**：全国基准直接给的前提是"全国统一明文"；一旦某结论掺入地区变量（如封顶线用到当地社平工资、加班费基数用到当地最低工资），该**变量部分**仍须标 `[需核实当地口径]`——即"规则确定、数值待核"，避免把地区数值当全国确定值。

## 一、经济补偿 / 赔偿金

| 地区 | 关键口径 |
|------|----------|
| 全国 | 基数=前12月实际应得平均工资（含补贴津贴+加班费，实施条例第27条）；高薪>3倍社平按3倍且≤12年；跨越2008年分段 |
| 北京 | 加班费是否计入补偿基数存在口径差异，多数按剔除加班费处理 → **标注[需核实]** |
| 广东/深圳 | 一般按应得工资（含加班费）计算；深圳对高薪封顶严格执行3倍社平 |

## 二、加班费计算基数

| 地区 | 关键口径 |
|------|----------|
| 全国 | 按劳动合同约定或实际应得工资；约定"基本工资"过低且明显不合理的，可按实际工资 |
| 北京 | 劳动合同约定优先；无约定按实际应得工资70%或全额（高低标准择对劳动者有利） |
| 上海 | 按劳动者所在岗位正常出勤月工资（不含加班费）的70%确定，且不低于最低工资 |
| 广东 | 约定优先；约定不明按实际应得工资；"阴阳合同"按实际履行 |

## 三、病假工资下限与比例

| 地区 | 关键口径 |
|------|----------|
| 全国（底线） | 不低于当地最低工资80%（劳部发〔1995〕309号第59条） |
| 上海 | 连续工龄<2年60%、2-4年70%、4-6年80%、6-8年90%、≥8年100%；疾病救济费<1年40%/1-3年50%/≥3年60% |
| 北京 | 不低于最低工资80%（部分情形按本人工资比例） |
| 广东 | 不低于最低工资80%，具体比例看规章制度（须合法公示） |

## 七、管辖与时效提示

- 仲裁管辖：劳动合同**履行地**或**用人单位所在地**仲裁委（调解仲裁法第21条），劳动者可择有利地。
- 仲裁时效1年（调解仲裁法第27条）；拖欠劳动报酬在劳动关系存续期间不受1年限制，终止后1年内提出。
- 横琴粤澳深度合作区等特殊区域有专门仲裁委，按实际履行地确定。

> 本库为通用口径汇总，**非穷尽且可能调整**。凡涉及具体金额或受理范围，务必标注 `[需核实当地口径]` 并建议用户查询当地人社/高院最新指引；要求权威核实时调用 connectors.md。

## 九、其他高频口径（补完整性）

- **解除劳动合同通知**：《劳动合同法》第43条要求用人单位单方解除**事先通知工会**；未通知工会的，部分地区认定程序违法（构成违法解除要件之一）。
- **终局裁决适用**：调解仲裁法第47条——追索劳动报酬/工伤医疗费/经济补偿/赔偿金，**不超过当地月最低工资标准12个月金额** 且标准明确的，仲裁裁决对用人单位终局（劳动者仍可起诉）。
- **举证责任倒置**：司法解释（一）第44条（解除/减少报酬/工龄等用人单位举证）、第42条（加班费劳动者初步举证后倒置）；违法解除案件中公司须证明其解除合法。
- **仲裁不收费**：第53条，任何地区均不向劳动者收费；申请缓减免诉讼费见民诉法相关规定。
