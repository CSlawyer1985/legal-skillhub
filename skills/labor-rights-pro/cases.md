## 示例0：端到端完整分析走查（从一句话咨询 → 交付清单 · 旗舰示例）

> **为什么放最前**：这是一个"从用户大白话咨询到完整交付"的全流程范例，演示本技能七步引擎 + 双视角预判 + 个性化计算 + 交付清单的**完整输出形态**。第一次用的人看完这一例，就懂"说情况→拿方案"是怎么跑的。

**【用户原话】**："我在珠海一家公司干了3年多，上个月月底突然被通知'岗位取消'让我走人，工资一直是每月1万5，但合同上写的是8000。没提前通知，也没给补偿。我该怎么办？"

**【第1步·事实梳理】**
- 入职：约2022年6月；解除：2025年12月底；工龄≈3年6个月
- 解除理由：公司称"岗位取消"（客观情况变化）；未提前30天、未协商、未支付补偿
- 工资：实发1.5万/月，合同写8000（**阴阳合同信号**）
- 地区：广东珠海；阶段：未申请仲裁

**【第2步·法律定性】**
- "岗位取消"属《劳动合同法》第40条第3项"客观情况重大变化"——但须**先协商变更劳动合同**，协商不成才可解除并支付N+1；公司**未协商即解除 → 程序违法 → 转为违法解除（第87条，2N）**
- 阴阳合同：赔偿基数按**实际工资1.5万**（非合同8000）

**【第3步·诉求优化】**
| 原诉求 | 优化后 | 理由 |
|--------|--------|------|
| "要个说法/补偿" | ①违法解除赔偿金2N ②补足未休年假 | 情绪诉求→法律可支持诉求；漏项年假补齐 |

**【第4步·法条支撑】** 第40条第3项（客观变化须协商前置）、第47条（补偿基数）、第87条（违法解除2N，2008.1.1施行）

**【第5步·输赢预判（双视角）】**
```
公司HR大概率抗辩："客观情况重大变化，属合法解除，按合同8000算"
我方拆解：①要求公司举证"协商变更"记录（无则程序违法）②银行流水+个税证明实发1.5万
仲裁员裁判倾向：单方解除举证责任在公司；未协商即解除主流口径认定违法解除→2N
诉求A（违法解除2N）：证据较充分 → 支持率 高（约85%）
诉求B（未休年假）：需核实历年休假记录 → 支持率 中，建议补证
```

**【第6步·证据指引】** ①解除通知（微信/书面，固定"岗位取消无补偿"）②银行流水近12月（证实发1.5万）③个税APP申报记录 ④劳动合同（证阴阳）⑤考勤/年假审批记录

**【第7步·金额计算（个性化，按你数据）】**
```
经济补偿 N：工龄3年6个月 → 满6月按1年 → N=4
基数：实际工资15,000元（阴阳合同按实际，非合同8000）
违法解除赔偿金 2N = 15,000 × 4 × 2 = 120,000元
未休年假（示例，待核实天数）：5天 × (15,000÷21.75) × 300% ≈ 10,345元（另付200%差额）
> 高薪封顶提示：若珠海上年度社平3倍 < 15,000，基数须封顶并改按≤12年——[需核实当地封顶线]
```

**【本次交付清单】**
```
✓ 法律定性：违法解除（客观变化未协商前置，程序违法）+ 阴阳合同（按实际工资）
✓ 优化后诉求：①违法解除2N约12万 ②未休年假约1万（待核实天数）
✓ 输赢预判：2N支持率高(约85%)；年假中(待补证)
✓ 证据清单：解除通知/银行流水/个税/合同/年假记录（标注取证路径）
✓ 文书草案：可生成"仲裁申请书+证据清单"（模板见 templates.md，形态见下方示例A）
✓ 下一步动作：本周内向珠海市/横琴劳动人事争议仲裁委提交申请（1年时效内）
```
> ⚠️ 金额中"社平3倍封顶线"含地区差异，标 `[需核实当地口径]`；开庭策略与公司套路破解见 creativity-boost.md。

## 示例A：违法解除 + 阴阳合同（完整填充的仲裁申请书）

> 演示"如何把用户事实+阴阳合同实际工资+2N计算"落成一式完整文书。

```
申请人：张明，男，1989年3月生，汉，身份证 320xxxxx
        住址：广东省珠海市香洲区xx路xx号，电话 138xxxx
被申请人：珠海xx科技有限公司（统一社会信用代码：9144xxxx）
        住所地：珠海市横琴新区xx大厦，法定代表人：李xx，电话 0756-xxxx

仲裁请求：
  1. 裁决被申请人支付违法解除劳动合同赔偿金 96,000 元
     （计算：N=3年×月平均工资 16,000 元×2 = 96,000；依据《劳动合同法》第47、87条）；
  2. 裁决被申请人支付2025年10月-12月拖欠工资 18,000 元；
  3. 裁决被申请人支付未休年休假工资 4,414 元（5天×16,000÷21.75×300%≈4,414，实际另付200%差额）；
  4. 本案仲裁费由被申请人承担。

事实与理由：
  申请人2023年2月1日入职，任运营经理，双方口头约定月薪16,000元，但劳动合同仅写"月工资5,000元"（阴阳合同）。
  实际工资由银行打卡发放（见证据2流水，月均16,000），个税APP申报收入亦为16,000（见证据3），证明实际工资标准。
  2025年12月20日，被申请人以"部门撤销、客观情况重大变化"为由单方解除劳动合同，未提前30日通知、未协商、未通知工会。
  该解除不符合《劳动合同法》第40条（所谓"客观变化"未举证、未先行协商变更合同），属违法解除，应支付2N（第87条）。
  合同低额记载不能对抗实际履行，经济补偿/赔偿基数应按实际16,000元计算。
  另被申请人拖欠2025年10-12月工资、未安排2025年年休假，分别应补足。

此致
横琴粤澳深度合作区劳动争议仲裁委员会

申请人（签名）：张明
2026年1月5日

附：证据清单（劳动合同、银行流水、个税明细、解除通知微信记录、考勤记录、社保缴费明细）
```

**该示例示范要点**：
- 阴阳合同：合同写5,000，用银行流水+个税申报证明实际16,000 → 基数按实际
- 2N计算：N=3年（2023.2-2025.12，约2年11个月→3个月不足6月按2年.. 注：2年11个月余11月≥6→N=3）×16,000×2
- 年休假计算式：5天×日工资×300%
- 多请求合并、逐项对应法条

## 示例B：绩效考核不达标解除（败诉点提炼）

**案情**：公司以"2025年绩效得分末位"直接解除劳动合同，未培训、未调岗。
**正确定性**：末位≠不胜任，且未走"培训/调岗后仍不胜任"前置程序 → 违法解除 → 主张2N。
**常见公司败诉原因**（劳动者可反击）：
- 绩效制度未经民主程序+未公示告知 → 不得作依据
- 以"末位"代替"不胜任"客观证据
- 跳过培训/调岗直接解除
**输出形态**：诊断→引用第40条第2项+最高法末位淘汰裁判观点→主张2N。

## 示例C：试用期考核不合格延长（违法点）

**案情**：合同3年约定试用期6个月，期满公司以"考核不合格"再延长3个月。
**正确定性**：第19条"只能约定一次"，延长=二次约定违法 → 第83条赔偿金（超期3个月×试用期满月工资）。
**抗辩提示**：若员工签字"自愿延长"，部分地区认定有效 → 优先主张签约前未被告知考核标准。

## 示例D：经济补偿金分段计算（跨越2008年）

**案情**：1999年入职，2026年协商解除，前12月平均应得工资1.8万（当地社平3倍为3万，未封顶）。
**计算**：2008年前约9年（按当时封顶12个月→12个月）；2008年后18年（新法实际年限→18个月）；合计 N=30个月。
**提示**：必须主动识别"跨越2008年"工龄并分段，否则金额严重偏差。

## 示例E：病假工资下限（地域差异）

**案情**：上海员工连续工龄3年，请病假2个月，公司按最低工资80%以下发。
**正确**：上海按连续工龄比例（2-4年70%）且不低于最低80%；公司低于法定比例违法，应补足。

## 示例F：竞业限制违约金过高被调减（类案裁判要点）

**案情**：员工离职后入职竞品，公司依协议主张违约金 80 万（远高于离职前年薪 30 万）。
**裁判要点**（最高法相关指导/典型案例精神）：竞业限制违约金应与**实际损失、补偿金数额、员工违约获益**相匹配；约定违约金**过分高于**实际损失，劳动者请求调减的，法院可酌情调减。
**输出形态**：先核违约金/已付补偿金比例 → 若明显失衡提示"可主张调减" → 同时审查竞业范围/期限是否超法定（≤2年、限于高管高技负有保密义务人员）→ 给出"继续履行 or 抗辩调减"策略。

## 示例G：工伤未缴社保（公司全担待遇）

**案情**：员工工作中受伤，公司未缴工伤保险。
**正确定性**：依《工伤保险条例》第62条第2款，应参加而未参加工伤保险期间职工发生工伤的，**由该用人单位按条例规定工伤保险待遇项目和标准支付费用**。
**输出形态**：诊断→列明可主张待遇项（医疗费/停工留薪期工资/伤残补助金等）→ 提示 30 日内公司申报、1 年内个人申报时限 → 未缴社保另可走行政补缴（见 regional/statutes）。

## 示例H：加班费举证链（数字化考勤）

**案情**：员工主张近一年休息日加班费，无审批单。
**举证链（按证明力排序）**：①企业微信/钉钉打卡记录导出（显示非工作时段在线）②工作群非工作时间布置/汇报任务截图 ③深夜打车报销记录 ④服务器/系统操作日志时间戳 ⑤同事证言。

**输出形态**：引导用户按上述优先级固定证据 → 给出"初步举证+举证责任倒置"双轨主张。

## 示例I：孕期违法解除（三期特殊保护）

**案情**：女员工孕期被以"绩效不达标"单方解除。
**正确定性**：《劳动合同法》第42条——女职工在孕期/产期/哺乳期，用人单位**不得**依第40条（无过失性辞退，含不胜任）、第41条（裁员）解除；第39条过失性除外。以"不胜任"解除孕期员工 → 违法解除 → 2N。
**常见公司败诉原因**：误用"不胜任"路径；未证明严重违纪（第39条）。
**输出形态**：诊断→引用第42+40+87条→主张2N，并提示"三期"证据（产检记录/生育证明）。

## 示例J：年休假当年折算（新进/离职年度）

**案情**：员工 2025-06-15 入职（此前外地连续工龄已超1年），2025 年应享年假如何算？
**计算**（条例第5条+实施办法）：当年度年休假天数 =（当年度在本单位剩余日历天数 ÷ 365天）× 职工本人全年应享年休假天数；折算后**不足1整天的部分不享受**。
**示例**：全年应享5天，剩余 200 天 ÷ 365 × 5 ≈ 2.74 → 享受 2 天。
**输出形态**：诊断→套用折算公式→提示"入职前连续工龄满1年是前提，否则当年不享"。

## 示例K：多轮前后对话完整走查（从一句话 → 追问补采 → 精算 → 交付 → 用户追问 → refine · 文档质量专项）
