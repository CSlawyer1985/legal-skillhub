# 连接器深度检索指南（北大法宝 / 华宇元典）

> 本技能内置法条库（statutes.md）覆盖 95% 场景且已核验，普通咨询无需调用连接器。但当用户**要求核实最新法条有效性**、**检索真实审判案例**作为支撑，或遇到本库未覆盖/置信度<85%的条文时，启用下方连接器做交叉验证。
> 两大连接器在用户环境中**已连接**（connector-status: connected），由运行本技能的 Agent 直接调用其 MCP 工具完成检索，本文件仅提供"何时用、用哪个工具、传什么参数"的编排指引。

---

## 一、何时启用连接器（触发判定）

| 触发情形 | 启用连接器 | 目的 |
|----------|------------|------|
| 用户明确要求"查一下最新规定/有没有新法/这条规定还有效吗" | pkulaw + yuandian | 核实法条现行有效性、条号与效力状态 |
| 用户要求"有没有类似案例/法院一般怎么判" | yuandian-mcp（案例向量检索） | 提供真实判例支撑主张或答辩 |
| 输出某条文置信度<85% | pkulaw | 交叉核实条号、效力、修正年份 |
| 新型/冷门争议（新业态用工、竞业限制新口径、社保新规） | 两者并用 | 补强依据、避免过时结论 |
| 用户质疑本库某条结论 | pkulaw / yuandian | 用权威来源回应，提升可信度 |

> **不必启用的情形**：标准 N/2N 计算、常见违法解除/未签合同/试用期/年休假等命中 statutes.md 且置信度≥90%的常规咨询。滥用连接器会拖慢响应、增加冗余。

## 二、北大法宝·法律智能检索（pkulaw）

已连接的 MCP 工具及编排用法：

| 工具名 | 用途 | 关键参数（示例） |
|--------|------|------------------|
| `mcp__pkulaw__mcp-law-search-service/search_article` | 按关键词/条号检索法律条文 | `query="经济补偿 计算 基数"`、`law_name="劳动合同法"`（可选限定法域） |
| `mcp__pkulaw__mcp-law-search-service/get_article` | 获取某条文精确内容/效力状态 | 条号或检索结果返回的 ID |
| `mcp__pkulaw__mcp-case-search-service/search_case` | 检索裁判文书/案例 | `query="违法解除劳动合同 2N 支持"`、`court`（可选）、`date`（可选） |
| `mcp__pkulaw__mcp-law/get_law_list` | 列出某部法律全部条文或版本 | `law_name="劳动争议调解仲裁法"` |

**编排示例（核实经济补偿金基数口径）**：
```
1) search_article(query="经济补偿 月工资 应得工资 实施条例第27条")
2) get_article(命中结果) → 核对条号、修正年份、效力
3) 将核实结果回填到对用户输出的法条引用中，并标注来源"北大法宝"
```

## 三、华宇元典法律数据（yuandian-mcp）

已连接的 MCP 工具及编排用法（用于真实判例检索与类案比对）：

| 工具名 | 用途 | 关键参数（示例） |
|--------|------|------------------|
| `mcp__yuandian-mcp__yuandian_search_kb_search` | 知识库/法规检索 | `query="试用期 违法延长 赔偿金"` |
| `mcp__yuandian-mcp__yuandian_law_vector_search` | 法条向量检索 | `query="经济补偿 基数 加班费 计入"` |
| `mcp__yuandian-mcp__yuandian_case_vector_search` | 裁判文书向量检索（类案） | `query="绩效考核不达标 解除劳动合同 违法"` |
| `mcp__yuandian-mcp__yuandian_rh_case_details` | 获取某案裁判详情 | 案例 ID（由检索返回） |
| `mcp__yuandian-mcp__yuandian_rh_fg_search` / `yuandian_rh_ft_search` | 法规/法条检索 | 关键词 |

**编排示例（为用户主张提供判例支撑）**：
```
1) yuandian_case_vector_search(query="阴阳合同 实际工资 经济补偿基数 银行流水")
2) 取 1-3 份高相关判例 → yuandian_rh_case_details(案例ID) 看裁判要旨
3) 提炼"裁审机关以实际工资为基数"的裁判规则，写入用户法律意见，并标注"参考判例：(来源)"
```

## 四、检索结果的使用与标注规范

1. **引用须标注来源**：凡经连接器核实/补充的法条或判例，输出中标注「来源：北大法宝 / 华宇元典」或「参考判例：(案号/来源)」，提升可信任度（trust 维度）。
2. **置信度门控**：连接器返回结果若与本库冲突，以**连接器权威来源**为准，并修正本库对应结论（必要时提示用户"本库结论已据官方来源更新"）。
3. **不杜撰**：连接器无结果时，如实告知用户"未检索到直接依据，建议线下咨询执业律师"，不得编造条文。
4. **隐私**：检索仅输入案情关键词与法条要素，**不得上传用户身份证号、银行卡号等敏感个人信息**到外部系统。

---

## 五、未连接时的降级方案

若运行环境未连接 pkulaw / yuandian-mcp：
- 一律以本库 statutes.md 为准，对置信度<85%的条文标注 `[需核实]` 并给出官方查询途径（全国人大法律法规库 flk.npc.gov.cn / 最高人民法院公报 gongbao.court.gov.cn）。
- 明确告知用户"当前环境未连接权威法律数据库，判例检索不可用，建议自行到北大法宝/裁判文书网核实"。
