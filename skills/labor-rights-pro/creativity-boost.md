# 增值研判库（公司套路破解 · 博弈推演 · 谈判施压 · 证据补救）

> 目的：让本技能输出**超越模板与法条罗列**——主动告诉用户"对方会怎么赖、你怎么反制、什么时候谈、底线怎么定、没证据怎么补"。本库为 SKILL.md §5.1「⑤综合研判」的增值弹药库，由 Agent 在场景分析中**按需调用**，不强制全量输出；所有内容严守 §一 法律红线与 §八 核实门控，涉地区差异仍标 `[需核实当地口径]`。

## 一、公司常见抗辩套路库（高发争议类型）

> 每个类型给出「公司惯用打法 → 我方反制 → 必取证据」。Agent 在 §5.1 ①抗辩预判表 中默认调用。

### 1.1 违法辞退 / 解除
- **套路A 主张"严重违纪"**：拿员工手册某条（常事后补签版本）。
  → 反制：要求出示**制度经民主程序（职工代表大会/全体讨论记录）+ 已公示告知（签收/培训记录）**的证据；查手册版本时间戳，事后补签易被识破。
  → 证据：员工手册签收单、制度版本历史、工会/职工代表会议记录。
- **套路B 主张"不胜任工作"**：用绩效 C/D 当证据直接解除。
  → 反制：末位≠不胜任；要求公司出示"培训/调岗记录"与"客观不能胜任"的独立证据（非仅排名）；无则违法(2N)。
  → 证据：绩效考核制度原文、培训/调岗通知、岗位职责说明书。
- **套路C 主张"客观情况重大变化"**：称业务撤销/架构调整。
  → 反制：审查是否真实（业务真撤销or换人）；是否已履行"协商变更劳动合同"前置程序；未协商即解除=违法。
  → 证据：组织架构调整文件、协商变更记录、解除通知原文。
- **套路D 沉默不举证 + 庭审突袭**：庭上突然抛证据。
  → 反制：当庭要求核对证据真实性，申请仲裁委给合理质证期；对逾期证据申请不予采纳。

### 1.2 加班费
- **套路A "加班需审批，无审批=自愿"**：
  → 反制：实际加班事实（工作群指令/下班后必回复/值班安排）不受审批制约束；审批只是公司内控。
  → 证据：工作群加班通知、下班后沟通记录、产出时间戳。
- **套路B "已发补贴含加班费"**：
  → 反制：要求公司出示"该补贴明确对应加班费"的制度/约定；无则主张未足额。
- **套路C 考勤"丢失/只有部分"**：
  → 反制：考勤记录举证责任在公司；申请仲裁委责令提交，拒不提交作不利推定。

### 1.3 未签合同双倍工资
- **套路A "员工自己拿走/销毁合同"**：
  → 反制：签合同举证责任在公司，拿不出原件+员工签字即推定未签；公司需提供签收记录/监控/证人，审查极严。
- **套路B "人事高管例外"**：
  → 反制：仅限实际负责合同管理的 HR 负责人；普通员工不适用；核实用户是否真属该例外。
- **套路C 倒签/补签日期**：
  → 反制：无合意证据（无法证明员工自愿追认倒填）→ 可抗辩；核对签字日期与入职日期逻辑。

### 1.4 试用期
- **套路A "试用期不合格"口头解除**：
  → 反制：需法定不胜任程序+书面考核依据，不能仅口头"不行"；试用期解除也受举证责任倒置约束。
- **套路B 二次约定/延长试用**：
  → 反制：延长=二次约定违法→第83条赔偿金；同一单位与同一劳动者只能约定一次。

### 1.5 病假 / 年假
- **套路A 病假"砍大半"**：
  → 反制：病假工资不低于当地最低80%（全国底线），地区比例见 regional；公司制度低于法定无效。
- **套路B 年假"过期作废"**：
  → 反制：未休年假300%工资是法定；公司"过期作废"条款无效；时效见 regional（多数当年+前1年）。

### 1.6 经济补偿 / 阴阳合同
- **套路A "按合同最低工资赔"**：
  → 反制：基数按实际工资（银行流水/个税/工资条），含补贴津贴+加班费；合同工资≠实发时以实发为准。
- **套路B "高薪封顶一刀切"**：
  → 反制：封顶仅适用于>3倍社平且≤12年；先核定用户是否真触顶，跨2008分段。

## 二、谈判与施压增值话术（让"赔偿账"变成谈判杠杆）

> Agent 在用户问"要不要谈/能谈多少"时调用；输出**代价结构**而非替用户决定。

### 2.1 和解博弈时机判断
- **适合谈**：证据中等、公司怕败诉影响（上市公司/国企/外企）、你主张金额清晰、时间成本对你不利。
- **不适合谈/宜硬刚**：公司明显违法且你证据充分（2N 稳）、公司惯用拖延耗你、仲裁委口径明显支持你。
- **底线公式**：可接受和解额 ≥ 仲裁可主张额 ×（胜诉概率 − 时间/精力折现 − 执行风险）。例：可主张 10 万、胜诉率 80%、执行风险 10% → 底线约 7 万，低于则走裁决。

### 2.2 赔偿账施压要点（发给公司/HR 的函件逻辑）
- 列明：违法点（法条）+ 可主张金额（计算式）+ 证据清单 + "若进入仲裁，贵司另承担诉讼成本/名誉/管理干扰"。
- 给台阶：提供"协商解除(N)+ 补发差额"的合规替代，而非逼对方认错。

### 2.3 调解现场话术骨架
- 开场：确认争议焦点（只谈金额不谈对错）。
- 锚定：先报你的计算总额（带算式），不先暴露底线。
- 让步：每让一步换一项（如接受分期换加利息/换离职证明干净）。
- 收口：口头一致即要求**当场出调解书**（一裁终局效力），不拖。

## 三、证据薄弱补救推演（没东西也能合法补）

> Agent 在用户说"我没考勤/没合同/没通知"时调用，给出**合法补强路径**，不教伪造。

| 缺什么 | 合法补救 | 指向 |
|------|------|------|
| 没书面解除通知（口头辞退） | 微信/录音让公司确认"你被开了"+ 后续不安排工作/停发工资佐证 | 固定解除事实 |
| 没考勤记录 | 工作群排班/打卡截图/同事证言/客户沟通时间戳 | 佐证加班/出勤 |
| 没签合同 | 工资流水+社保记录+工牌/邮件+客户往来证明事实劳动关系 | 双倍工资基础 |
| 没工资条 | 银行流水(看备注"工资")+个税APP记录+offer邮件 | 实际工资基数 |
| 公司不交证据 | 申请仲裁委《责令提交证据通知书》；拒不提交作不利推定 | exceptions E010 类兜底 |

## 四、调解 / 撤诉决策框架（代价结构，不替决定）

- **接受调解信号**：金额达底线、公司履约能力强、你想快点了结、证据有硬伤。
- **拒绝调解信号**：2N 稳赢、公司拖延惯犯、调解书金额远低于裁决预期。
- **撤诉风险**：撤诉后同诉求一般不能再仲裁（一事不再理），除非双方新达成和解；重大决定建议结合执业律师。

## 五、反向施压时间线（按阶段升级，给"下一步具体做什么"）

> 把"施压"从原则变成**可执行的升级路线**。Agent 在用户问"怎么逼公司"时，按阶段给出下一步动作，不空谈。

| 阶段 | 触发条件 | 具体动作 | 法律依据/抓手 |
|------|----------|----------|--------------|
| ① 书面催告 | 公司欠薪/不出具解除通知 | 发 EMS 催告函（留回执）+ 微信确认 | 中断时效（E011）、固定证据 |
| ② HR/HRBP 抄送 | 催告无回应、公司拖延 | 把"违法点+可主张金额算式"抄送直接上级/HRBP，给台阶（协商解除 N+补差） | 施压+留痕 |
| ③ 劳动监察投诉 | 社保/欠薪/不签合同 | 向用工地劳动监察大队投诉（社保法第74/83条） | 行政介入，公司忌惮 |
| ④ 仲裁申请 | 前述无果/证据充分 | 提交仲裁申请书+证据清单（templates 模板1/2） | 终局压力+强制执行预期 |
| ⑤ 财产线索预备 | 胜诉后恐执行难 | 提前收集公司账户/财产线索，备保全/执行申请 | templates 模板8/9 |

> 每升一级前先评估：证据是否够、时间成本、公司履约能力（结合 §二 谈判时机）。不盲目升级耗用户。

## 六、证据补强优先级矩阵（没东西也知道先补哪个）

> 当多个证据缺口并存，按"易得度 × 证明力"排序，让用户先抓最高性价比的补强项，而非胡子眉毛一把抓。Agent 在用户说"我啥证据都没有"时调用。

| 优先级 | 缺的证据 | 易得度 | 证明力 | 首选补强动作 |
|--------|----------|--------|--------|--------------|
| ★★★ | 实际工资基数 | 高（银行APP/个税APP） | 高 | 拉银行流水+个税记录，直接推翻"按合同最低工资赔" |
| ★★★ | 违法解除事实 | 中（微信/录音） | 高 | 微信让公司确认"你被开了"+停发工资佐证 |
| ★★ | 加班事实 | 中（工作群/排班） | 中高 | 截屏排班+下班后指令，申请仲裁委责令交考勤 |
| ★★ | 事实劳动关系 | 中（工牌/邮件） | 中 | 工牌+客户往来+社保记录，夯实双倍工资基础 |
| ★ | 公司制度民主程序 | 低（需公司出具） | 中 | 要求公司出示，拿不出即违法（反制点，非自取） |

> 排序逻辑：先补"易得且证明力强"的项，快速立住主线；低易得项转为庭审"要求公司举证"的反制，不消耗用户精力。

## 七、本案独有洞察雷达（每次实质分析必出 ≥1 条 · 创造力与增值硬落地）

> **解决什么**：评测反馈"增值好但仍偏通用"。本节把 SKILL.md §5.1⑥"必出1条绑定本案的个性化增值"从原则变成**可执行扫描法**——Agent 从用户**已提供的事实字段**里扫出"只有这个案子能用"的洞察，而非套通用套路。无个性化事实支撑时先补采，不拿通用话术充数。

**扫描六字段（逐项过，命中即生成独有洞察）**
| 用户事实字段 | 扫描问题 | 独有洞察产出（示例） |
|--------------|----------|----------------------|
| **证据现状** | 用户已有/已提到哪些证据？ | "你已有微信辞退记录 → 优先公证固化，再发EMS催告中断时效，直奔仲裁" |
| **工龄+工资** | 是否触发分段/封顶/终局裁决临界？ | "你月薪1.2万×3年，2N=7.2万，恰超当地最低工资12倍 → 非终局裁决，公司可上诉，做好二审预案" |
| **当前阶段** | 距时效/开庭还有多久？ | "你离职已10个月，仲裁时效仅剩2个月 → 本周必须提交，别再等证据齐" |
| **主体身份** | 是否灰色地带（骑手/超龄/HR高管）？ | "你是HR但不负责合同管理 → 双倍工资例外不适用于你，可正常主张" |
| **地区** | 是否有对用户有利的地方口径？ | "你在上海，病假工龄2-4年按70%且不低于最低80% → 公司按50%发违法，可补足" |
| **公司特征** | 上市/国企/惯用拖延？ | "对方是上市公司，怕败诉影响 → 和解议价空间大，可锚定高位先谈" |

**输出规则（硬约束）**
1. **每次实质分析至少产出 1 条**"绑定本案具体事实"的洞察，写明"因为你[具体事实]，所以[独有动作]"。
2. 洞察必须是**通用模板给不出的**——若换个用户同样成立，则不合格，须继续下钻到本案独有字段。
3. 洞察须落到**下一步可执行动作**（公证/EMS/补证/议价/抢时效），不停在"分析"层。
4. 事实不足以支撑个性化时 → 先按 E002 补采关键字段，再出洞察，不用通用话术占位。

> 作用：把"增值研判"从"高频套路库"（本文件§一–§六，广度）升级为"这一案专属决策"（本节，深度），二者叠加即"看得穿套路 + 算得准本案"，是创造力与增值维度的深度增量。

## 八、企业狡辩原话 → 法条反制 → 一击证据（对位库 · 创造力专项必出块）

> **为什么单列**：评测反馈"公司怎么狡辩、你怎么反驳"是创造力与增值的核心增量，但 §一 按"套路类型"组织，临场未必好调用。本节按**用户最易听到的"公司原话"**组织，Agent 在双视角预判 ① 后**必调用**，给出"对方这句话 → 用哪条法条打回去 → 你手头哪个证据能一击致胜"的确定对位，让反击话术即拿即用（直击创造力与增值 4.3）。

### 场景A · 违法辞退
| 公司原话 | 法条反制 | 一击证据 |
|----------|----------|----------|
| "你严重违纪，按制度开除" | 制度须经**民主程序+公示告知**（第4/39条）；未走程序的解除无效，要求公司出示职代会记录+你的签收 | 员工手册签收单 / 无签收证明 |
| "你绩效不胜任，所以解除" | 末位≠不胜任；解除须"培训/调岗后仍不胜任"完整流程（第40/87条）；无流程=违法2N | 绩效考核制度原件 / 无调岗通知 |
| "经营困难，客观情况变化" | 须真实且履行**协商变更**前置程序（第40条）；未协商即解除违法 | 架构调整文件 / 无协商记录 |
| "你自己提的离职，不是我们开你" | 离职性质看证据；公司须证明确系你主动，否则推定违法解除 | 微信/录音中公司单方通知 / 停发工资记录 |

### 场景B · 加班费
| "加班要审批，没审批不算加班" | 实际加班事实（工作群指令/必回复）不受审批制约束；审批只是内控 | 工作群加班通知 / 下班后沟通时间戳 |
| "发的补贴里已含加班费" | 须证该补贴**明确对应加班费**；无约定则未足额 | 工资条项目明细 / 无加班费约定制度 |
| "考勤丢了/只剩部分" | 考勤举证在公司；申请仲裁委责令提交，拒不提交作不利推定 | 部分考勤截图 / 责令提交申请书 |

### 场景C · 未签合同
| "合同是你自己拿走/销毁的" | 签合同举证责任在公司；拿不出原件+你签字即推定未签 | 工资流水 / 社保记录（证事实劳动关系） |
| "你是HR高管，不适用双倍工资" | 仅限实际负责合同管理的HR负责人；普通员工不适用 | 岗位说明书 / 非合同管理职责证明 |
| "后来补签了，日期你认的" | 倒签无合意证据（无法证自愿追认）可抗辩 | 签字日期与入职日期逻辑矛盾 |

### 场景D · 试用期/绩效
| "试用期不合格，口头通知你走" | 须法定"不符合录用条件"+书面考核；仅口头无效；试用期也受举证倒置 | 无录用条件告知书 / 无考核依据 |
| "试用期又延长了，正常" | 延长=二次约定违法→第83条赔偿金；同一单位只能约定一次 | 第二次试用约定记录 |
| "末位淘汰，你排名垫底" | 末位≠不胜任；须"客观不能胜任"独立证据（第87条） | 排名表 / 无能力短板证据 |

### 场景E · 工伤（认定/待遇博弈）
| "你这是自己不小心，不算工伤" | 工伤采**无过错责任**（工伤保险条例第14条），非本人主要责任的事故即认；故意犯罪/醉酒/自残才不认 | 事故认定书 / 上下班路线记录 / 同事证言 |
| "没在30天内申报，过期了" | 单位30日内申报是**单位义务**；单位未报，职工本人/近亲属**1年内**可直接申报，不失效 | 医疗诊断证明 / 劳动关系证明 |
| "工伤复发公司不认旧伤" | 已认定工伤的，复发属工伤延续；公司否认须举证"非工伤所致"，否则承继待遇 | 原工伤认定决定书 / 复诊记录 |

### 场景F · 竞业限制（签了/没付补偿）
| "签了竞业就得乖乖遵守" | 竞业须**有补偿**（离职后按月付）；公司**超3个月未付补偿**，你可请求解除约定（司法解释一第38条） | 竞业协议原件 / 离职后无补偿流水 |
| "竞业补偿低得离谱也认" | 补偿一般不低于离职前工资**30%**（各地口径，标[需核实]）；显失公平可请求调整 | 工资流水 / 协议补偿条款 |
| "前东家说要去告我违反竞业" | 先看竞业范围/期限是否合理（≤2年、地域/行业须合理）；超范围可抗辩无效 | 新单位营业执照 / 实际岗位说明 |

### 场景G · 未休年假 / 病假（福利克扣）
| "年假过期作废，公司规定" | 未休年假**300%工资**是法定；公司"过期作废"条款无效；时效一般当年+前1年（北京近2年） | 考勤记录 / 未休假证明 |
| "病假工资砍大半合法" | 病假工资不低于当地最低**80%**（全国底线）；公司制度低于法定无效 | 病假证明 / 工资条（看实发比例） |
| "产假只给98天，奖励假没有" | 奖励假属地方规定（广东80天/上海60天/北京30天，查 §十一）；合计天数公司不得克扣 | 生育证明 / 当地计生条例 |

### 场景H · 社保补缴 / 公积金（行政路径）
| "社保没交，你认了没法要" | 社保补缴走**行政**（社保征收机构/劳动监察，社保法第86条），仲裁多不直接受理；可投诉责令补缴 | 工资流水 / 劳动关系证明 |
| "没法补缴了，损失谁赔" | 无法补缴且造成损失（如养老金/医疗待遇差），可主张**社保损失赔偿**（仲裁/诉讼） | 无法补缴证明 / 损失测算 |
| "公积金不缴公司不管" | 公积金由公积金管理中心责令缴存；可向管理中心投诉，非仲裁受理范围 | 工资流水 / 劳动关系证明 |

> 用法：Agent 输出 ①抗辩预判表 时直接把"原话版对位"嵌入，让用户拿去就能用；每条反制落到"哪条法条 + 哪个证据"，不停在原则。覆盖违法辞退/加班费/未签合同/试用期/工伤/竞业/年假病假/社保公积金八类高发场景，凡用户提及对应争议，必取对应场景对位。

## 九、和解底线速算规则（每次分析必给具体下限 · 创造力专项必出块）

> **为什么单列**：评测反馈"提醒和解底线大概是多少"是增值项，但此前仅给公式、未强制出数。本节把"和解底线"变成**可速算的具体下限**，Agent 在用户问"谈不谈/谈多少"或进入 ②博弈树时**必出数字**，不空谈（直击创造力与增值 4.3）。

**底线公式（通用）**
```
和解可接受下限 ≥ 仲裁可主张总额 × (胜诉概率 − 执行风险折现 − 时间成本折现)
```
- 胜诉概率：取 §四 五档支持率（高0.85 / 较高0.7 / 中0.5 …）
- 执行风险折现：公司履约弱 +0.1~0.2；强（上市/国企）为 0
- 时间成本折现：你急于了结 +0.05~0.1

**按场景的底线锚定（示例）**
| 场景 | 可主张基准 | 和解底线速算（示例） |
|------|------------|----------------------|
| 违法解除2N | 2N = W×Z×2 | 证据充分(胜诉率0.85)：下限≈2N×0.7≈1.4N；低于此走裁决 |
| 欠薪/加班费 | 欠付额 A | 证据中等(0.6)：下限≈A×0.7；公司怕监察则锚定 A 全要 |
| 未签合同双倍 | 11月×W | 证据强(0.85)：下限≈0.75×可主张；弱则先补证再谈 |
| 经济补偿N | N=W×Z | 协商解除：底线=N（不打折）起步，可争取 N+差额 |
| 工伤待遇 | 伤残津贴/医疗费/就业补助（按伤残等级） | 已认定+等级明确(0.85)：下限≈法定待遇×0.8；公司未缴社保则追加社保损失 |
| 竞业限制违约 | 协议约定违约金 / 公司实际损失 | 竞业无效或可解除(0.8)：底线=0（不赔）；有效则按补偿已付额抗辩减额 |
| 未休年假/病假差额 | 300%日工资差 / 病假差额 | 证据强(0.85)：下限≈应补额×0.9，基本全要 |
| 社保损失赔偿 | 无法补缴导致的待遇差 | 已证无法补缴(0.8)：下限≈测算损失×0.7，先走行政责令补缴更优 |

> 输出要求：凡用户流露"要不要谈"或进入 ②博弈树，Agent **必须给出一行具体下限数字**（如"你这案和解别低于 7 万，低于就走裁决"）并展示来由；重大实体决定仍附"建议结合执业律师"。

## 十、非常规突破策略库（跳出模板框 · 创造力与增值增量弹药）

> **为什么单列**：评测反馈"回答比较模板化，缺少让人眼前一亮的洞察"。§一–§九 是"标准战法"（法条→套路→反制→和解），本节补充**突破常规的策略视角**——不是每个案都用，但会用时会让人眼前一亮。Agent 在案情走完七步后**按需调用**，当标准流程走完、用户还觉得"不够"时，从这里"加一档"。

### 策略① 仲裁+监察双线施压（同步走，互相施压）

**常规**：先仲裁→败了再走监察/信访，排队等半年。
**突破**：**同步走**——仲裁申请立案的同时，向劳动监察投诉欠薪/社保；两种程序互不排斥。
```
仲裁要等3-6个月开庭？不等。
同步向劳动监察投诉（欠薪/社保），监察没有"排期"概念——只需一通电话或网上投诉，
公司收到监察通知→怕被公示/罚款→更主动找你和解→倒推仲裁提前结案。
用法：欠薪案——"我已仲裁+已投诉监察，你补钱我就撤诉，否则两边都走到底。"
```
**适用**：欠薪、社保、不签合同等有行政路径可走的案型。

### 策略② 证据链自闭合（不等公司配合，主动闭合）

**常规**：用户说"我没证据，公司不给"——等对方主动提交→等仲裁委责令→等。
**突破**：不等公司交→**主动闭链**。
```
证据闭合七步法：
1. 公证：微信记录/邮件截图先公证 → 防公司删记录
2. 调查令：仲裁委出《调查令》→ 你去银行/社保局调取（不需要公司配合）
3. 举证倒置活用：诉信访要求公司交制度/考勤/工资表 → 公司不交=推定为真
4. 推定：用户有初步证据(工作群截图/部分考勤) → 举证责任已在公司
5. 证言：旧同事/下属出书面证言（仲裁委一般采信）
6. 第三方记录：快递/外卖/行程记录佐证你在公司
7. 汇总：形成"我拿到的+推定应存在的+公司不交即不利推定"三重闭合
```
**适用**：任何"缺核心证据"的案型。

### 策略③ 和解+执行联动（谈不拢就预查封）

**常规**：和解谈金额→谈不成→等裁决→等执行→对方转移财产。
**突破**：**先保全再谈**——谈之前先冻结对方资产，把和解桌横过来。
```
做法：申请仲裁的同时申请"财产保全"（提供等额担保）→ 仲裁委转法院裁定冻结。
公司帐被封：→ 比你急十倍 → 主动找你谈和解 → 主动权在你。
用法："我已申请财产保全，你账户封了。和解可以，今天打款我就撤保全。"
```
**适用**：公司有履约能力但拖、或感觉可能跑路的案型。

### 策略④ 合法舆情杠杆（合规框架内用公开信息）

**常规**：诉讼只走法律程序，公司拖。
**突破**：公开信息（不违法）让社会压力倒逼公司。
```
合规杠杆（不违法、不诽谤、不泄露隐私）：
· 天眼查/企查查公示欠薪仲裁记录 → 公司融资/招投标受影响，主动找你谈
· 行业社交群（脉脉/领英）真实事件匿名讨论 → HR看到会报管理层
· 向公司核心客户/供应商"客观说明"（仅陈述你与公司有仲裁争议）
⚠️ 红线：不诽谤、不泄露公司商业秘密、不伪造事实——
     合规杠杆是"事实陈述"，不是"舆论绑架"。
```
**适用**：上市公司(怕声誉)、融资期创业公司(怕投资人)、国企(怕考核)。

---

> 本节策略不走模板、不拘常规，Agent **按需调用**，不强制每案全出。用户场景标准时走前九节，用户说"对方拖/公司赖/我忍不了"时从本节加一档，让使用者感到"这人不是只会翻法条，是真的有经验"。涉风险策略（财产保全担保费、舆情杠杆边界）附 `[需评估成本风险]` 提示，不替用户做决定。
