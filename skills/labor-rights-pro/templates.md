# 法律文书模板库（Document Templates）

> 用法：用户要求生成某阶段文书 → 取对应模板 → 用七步引擎收集的事实填充 → 提示用户核对[方括号]项 → 标注"最终以受理机关要求为准"。
> 全套文书覆盖：仲裁申请 → 证据 → 庭审 → 一审 → 二审 → 执行。

---

## 必含要素核对表（生成任何文书前，逐项打勾，缺一项不输出 · 内容完整度硬保证）

> 每次调用模板生成文书，Agent 必须先对照下表逐条核对；任一必含要素缺失即视为不完整，必须先补采/补全再输出（对应 SKILL.md §七 内容完整度）。这不是"建议"，是生成文书的强制末检。

| 文书类型 | 必含要素（缺一不可） |
|----------|----------------------|
| 仲裁申请书（模板1） | ①当事人信息（申请/被申请人+代码）②明确仲裁请求（逐项金额+计算式）③事实与理由（时间线+违法点）④法律依据（条号）⑤致送仲裁委+落款 |
| 证据清单（模板2） | ①案号/当事人 ②序号+证据名称+来源+证明目的 ③原件/复印件标注 ④提交人+日期 |
| 质证提纲（模板3） | ①对方证据逐项 ②真实性/合法性/关联性三性意见 ③证明目的反驳 ④我方反证指向 |
| 代理词（模板4a/b/c） | ①阶段对应结构（仲裁=事实认定/一审=法律适用/二审=法律错误+程序）②争议焦点逐项 ③金额计算式 ④总结请求 |
| 起诉状（模板5） | ①诉讼请求 ②事实与理由（含不服裁决案号+理由）③法律依据 ④致送法院+落款 |
| 上诉状（模板6） | ①上诉请求（撤销/改判项）②事实错误+法律错误+程序违法 ③致送上一级法院 |
| 答辩状（模板7） | ①争议焦点逐项反驳 ②金额纠错 ③总结请求 |
| 保全/执行申请（模板8/9） | ①请求事项（金额/财产）②事实与理由（案号+依据法条）③致送法院 |
| 被迫解除通知（模板10） | ①违法情形列举 ②第38条依据 ③结清/补偿/转移三项要求 ④EMS回执提示 |
| 和解协议（模板11） | ①支付金额+期限 ②撤回仲裁/诉讼+再无争议 ③违约条款 ④双方签署 |
| 授权委托书（模板12） | ①委托人/受托人+证号 ②委托事项（阶段）③代理权限（特别授权明细） |

## 模板1：劳动仲裁申请书

```
申请人：[姓名]，[性别]，[出生年月]，[民族]，[身份证号]
        住址：[省市区街道]，电话：[手机号]
被申请人：[公司全称]（统一社会信用代码：[代码]）
        住所地：[注册地址]，法定代表人：[姓名] 职务：[职务]，电话：[电话]

仲裁请求：
  1. 裁决被申请人支付违法解除劳动合同赔偿金 [2N] 元（N=[ ]年×月平均工资[ ]元×2）；
  2. 裁决被申请人支付[年份]年[月]-[月]拖欠工资/加班费 [ ] 元；
  3. 裁决被申请人支付未休年休假工资 [ ] 元；
  4. 裁决被申请人支付[其他，如试用期赔偿金/双倍工资] [ ] 元；
  5. 裁决被申请人为申请人补缴[年月]至[年月]社会保险（或裁令赔偿社保损失[ ]元）。

事实与理由：
  申请人于[入职日期]入职被申请人处，任[岗位]，约定月工资[ ]元（实际发放见证据）。
  [年月日]，被申请人以[解除理由]单方解除劳动合同，未[程序违法点，如未通知工会/未提前30日/理由不成立]。
  依据《劳动合同法》第[ ]条、第87条，被申请人属违法解除，应支付2N。
  [其他请求对应事实与法条……]

此致
[劳动合同履行地/用人单位所在地]劳动争议仲裁委员会

申请人（签名）：__________
[年] 年 [月] 月 [日] 日

附：1. 申请人身份证复印件
    2. 证据清单及证据材料 [ ] 份
```

## 模板4：代理词（仲裁/一审/二审 · 阶段差异化指引）

> 仲裁、一审、二审的代理词侧重点不同，**不可混用**。生成时必须根据用户当前阶段选对应结构：

### 4a 仲裁阶段代理词（侧重事实认定 + 证据抗辩）
```
代理词

[仲裁委员会名称]：
就申请人xxx与被申请人xxx劳动争议一案，代理人发表如下代理意见：

一、关于劳动关系：……（事实+证据+法条）
二、关于[争议焦点1，如违法解除]：
    1. 事实：……（时间线、解除理由、证据编号）
    2. 法律：依据《劳动合同法》第[ ]条，……
    3. 结论：被申请人[行为]违法，应承担[责任]
三、关于[争议焦点2]：……
四、关于金额计算：……（列计算式，含基数/年限/封顶/分段）
五、总结：请求支持申请人全部/主要仲裁请求。

代理人：__________
[年] 年 [月] 月 [日] 日
```

### 4b 一审代理词（侧重法律适用 + 推翻/维持仲裁裁决）
```
代理词

[一审法院名称]：
就[原告]诉[被告]劳动争议一案（案号：[ ]），代理人在已查明的一审庭审事实基础上，发表如下代理意见：

一、一审庭审已查明事实概要：……（围绕一审法院已确认的无争议事实）
二、关于仲裁裁决的错误 / 正确认定：
    1. 仲裁委认定[具体错误点]，我方认为应纠正为……（事实+法律依据）
    2. 仲裁委对[金额/时效/定性]认定正确，应维持
三、关于[争议焦点]：……（侧重一审法院的审查重点，而非重复仲裁意见）
四、金额调整：……（说明一审阶段可变更的诉求范围）
五、总结：请求[驳回对方全部诉讼请求/支持我方全部诉讼请求]。

代理人：__________
[年] 年 [月] 月 [日] 日
```

### 4c 二审代理词（侧重法律适用错误 + 程序违法 + 新证据）
```
代理词

[二审法院名称]：
就[上诉人]诉[被上诉人]劳动争议上诉一案（案号：[ ]），代理人发表如下代理意见：

一、原审判决认定事实错误：……（指出一审法院对特定事实的认定与证据不符之处）
二、原审判决适用法律错误：……（指出一审适用哪条法律错误，及应适用的正确法条）
三、程序违法（如有）：……（如一审遗漏当事人、未质证、举证期限不当等）
四、新证据（如二审有新证据）：……（依据《民诉法解释》第342条，二审新证据的证明内容）
五、总结：[维持/撤销/改判]请求。

代理人：__________
[年] 年 [月] 月 [日] 日
```

> **代理词阶段选择指引**：未裁决→用4a；已裁决不满→用4b；一审判决不满→用4c。用户不明确阶段时，先走SKILL.md §三 Intake 确认当前阶段再选模板。

## 模板5：民事起诉状（一审，不服仲裁裁决）

```
原告：[姓名]，[基本信息]
被告：[公司全称]（统一社会信用代码），住所地，法定代表人

诉讼请求：
  1. 判令被告支付违法解除劳动合同赔偿金 [ ] 元；
  2. 判令被告支付……（同仲裁请求，可调整）；
  3. 本案诉讼费由被告承担。

事实与理由：
  [简述入职、岗位、工资、解除经过，引用仲裁裁决书案号及不服理由]
  依据《劳动合同法》第[ ]条、《民事诉讼法》第122条，特向贵院起诉。

此致
[用人单位所在地/合同履行地]人民法院

具状人：__________
[年] 年 [月] 月 [日] 日
```

此致
[上一级]人民法院

上诉人：__________
[年] 年 [月] 月 [日] 日
