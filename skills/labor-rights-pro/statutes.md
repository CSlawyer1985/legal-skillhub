## 一、实体法重点条文

### 1.1 《中华人民共和国劳动合同法》（2012年12月28日修正）

| 条号 | 解决的核心问题 | 劳动者高频引用场景 |
|------|----------------|--------------------|
| 第7条 | 用工之日起即建立劳动关系 | 未签合同但已上班→事实劳动关系 |
| 第10条 | 应订立书面合同（用工1个月内） | 入职超1月未签→双倍工资 |
| 第19条 | 试用期期限（见下方专表） | 试用期超法定上限/仅约定试用期 |
| 第19条第4款 | 试用期**包含**在合同期限内；仅约定试用期的，试用期不成立，该期间为合同期限 | "只签试用期合同"→视为正式期 |
| 第20条 | 试用期工资≥转正工资80% 且 ≥ 当地最低工资 | 试用期低薪 |
| 第39条 | 过失性辞退（不符录用条件/严重违纪/双重劳动关系/欺诈/刑事责任）——**无需补偿** | 公司称"试用期不合格"解除 |
| 第40条 | 无过失性辞退（医疗期满/不胜任经培训调岗仍不胜任/客观情况重大变化）——需提前30日或+1代通知金+N | 以绩效考核不达标解除 |
| 第41条 | 经济性裁员（20人或10%+程序+备案） | 规模裁员合法性审查 |
| 第43条 | 单方解除应事先通知工会 | 程序违法点 |
| 第44条 | 劳动合同终止情形 | 合同到期不续签 |
| 第46条 | 应当支付**经济补偿（N）**的情形清单 | 被动离职/合同终止 |
| 第47条 | 经济补偿计算：基数=解除前12个月平均工资；年限每满1年1个月，6个月以上不满1年按1年，不满6个月半个月；高薪（>3倍社平）封顶3倍且年限≤12年 | **经济补偿金计算（核心）** |
| 第48条 | 违法解除后果：继续履行 或 支付赔偿金 | 违法解除救济路径 |
| 第82条 | 未签书面合同二倍工资（用工超1月不满1年，最多11个月） | 双倍工资主张 |
| 第83条 | 违法约定试用期：已履行的，按**试用期满月工资×超过法定试用期的期间**支付赔偿金 | **违法延长试用期补偿** |
| 第85条 | 拖欠工资/低于最低工资/不付加班费/不付经济补偿：劳动行政部门责令支付，逾期按应付金额**50%~100%加付赔偿金**（前置：行政责令） | 取代原481号第10条25%/50% |
| 第87条 | 违法解除/终止赔偿金=**2N** | 2N主张 |
| 第42条 | 女职工在**孕期/产期/哺乳期（三期）**内，用人单位**不得**依第40条（无过失性辞退，含不胜任）、第41条（裁员）解除；第39条过失性辞退除外 | 孕期/哺乳期被辞退→违法解除2N（见 cases 示例I） |

**第19条 试用期期限法定上限表（必须背熟）**

| 劳动合同期限 | 试用期上限 |
|--------------|-----------|
| 以完成一定工作任务为期限 / 合同期限 < 3个月 / 非全日制 | **不得约定试用期** |
| 3个月 ≤ 合同期限 < 1年 | ≤ 1个月 |
| 1年 ≤ 合同期限 < 3年 | ≤ 2个月 |
| 合同期限 ≥ 3年 / 无固定期限 | ≤ 6个月 |

> 补充规则：① 同一用人单位与同一劳动者**只能约定一次试用期**（不得"考核不合格"为由再次约定或延长）；② 试用期包含在合同期限内。

### 1.2 《中华人民共和国劳动法》（2018年修正）

- 第36/38/41条：标准工时（每日8h、每周44h内）、加班限制（每日≤3h、每月≤36h）
- 第44条：加班费标准（150%/200%/300%）
- 第50条：工资按月支付，不得克扣或无故拖欠
- 第72条：用人单位与劳动者必须依法参加社保、缴纳社保费
- 第77条：劳动争议可依法申请调解/仲裁/提起诉讼

### 1.3 《中华人民共和国社会保险法》（2018年修正）

- 第58条：用工30日内办理社保登记
- 第60条：用人单位自行申报、按时足额缴纳（**不得缓缴减免**，职工应缴部分由用人单位代扣代缴）
- 第86条：未足额缴纳→社保费征收机构责令限期缴纳/补足+加收滞纳金；逾期处欠缴数额1~3倍罚款

### 1.4 《职工带薪年休假条例》（2008年1月1日施行）

- 第2条：职工连续工作**1年以上**享受带薪年休假
- 第3条：累计工作满1年不满10年→**5天**；满10年不满20年→**10天**；满20年以上→**15天**。法定休假日、休息日不计入
- 第4条：不享受当年年休假的情形（寒暑假多于年假/事假≥20天且单位不扣薪/病假累计超限等）
- 第5条：单位统筹安排；确因工作需要不能安排的，对职工应休未休天数按**日工资300%**支付（注：含正常工作期间已付工资，实际另付200%差额）

### 1.5 《企业职工患病或非因工负伤医疗期规定》（劳部发〔1994〕479号）

- 医疗期：根据**实际工作年限** + **本单位工作年限**确定 3~24 个月
- 实际工作年限10年以下：本单位<5年→3个月；≥5年→6个月
- 实际工作年限10年以上：本单位<5年→6个月；5~10年→9个月；10~15年→12个月；15~20年→18个月；20年以上→24个月
- 医疗期内合同不得解除（《劳动合同法》第42条）

### 1.6 《工资支付暂行规定》（劳部发〔1994〕489号）及补充规定

- 第7条：工资须在约定日期支付；遇节假日或休息日应提前在最近工作日支付
- 第11条：劳动者依法休假（年假/探亲/婚丧等）期间，用人单位应支付工资
- 第12条：非因劳动者原因停工停产，一个工资支付周期内按合同标准支付；超周期若提供正常劳动≥最低工资，未提供按待岗生活费（地方规定）
- 第15/16条：不得克扣工资；因劳动者本人原因给单位造成损失，每月扣减≤当月工资20%且扣后≥最低工资

### 1.7 病假/疾病救济费依据

- 《关于贯彻执行〈劳动法〉若干问题的意见》（劳部发〔1995〕309号）第59条：职工患病或非因工负伤治疗期间，在规定医疗期内由企业按有关规定支付其**病假工资或疾病救济费**，可以低于当地最低工资标准支付，但**不能低于最低工资标准的80%**。
- 病假工资具体计算基数与比例**各地不同**（见 regional.md），需标注 `[需核实当地口径]`。

## 三、最新司法解释（核心，版本已核验）

### 3.1 《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》
- **文号**：法释〔2020〕26号
- **公布/施行**：2020年12月29日公布，**2021年1月1日施行**
- **覆盖**：劳动关系认定、劳动合同效力、经济补偿/赔偿金、加班费、社保、竞业限制、涉外等
- 常用条款示例：
  - 第44条：因用人单位作出的解除/减少报酬/计算工龄等决定发生的争议，**用人单位负举证责任**
  - 第42条：劳动者主张加班费，应就加班事实存在举证；劳动者有证据证明用人单位掌握加班事实证据而拒不提供的，由用人单位承担不利后果
  - 第46条：劳动者非因本人原因从原单位被安排到新单位，原单位未付经济补偿、新单位解除时合并计算工作年限（原单位已付则除外）

### 3.2 《最高人民法院关于审理劳动争议案件适用法律问题的解释（二）》
- **文号**：法释〔2025〕12号
- **公布/施行**：2025年7月31日公布，**2025年9月1日施行**
- **第21条**：本解释施行，《解释（一）》法释〔2020〕26号第三十二条第一款同时废止；此前司法解释与本解释不一致的以本解释为准
- **重点新增/明确规则**（直接影响本案分析）：
  - 转包/分包/挂靠情形下**用工主体责任**由承包人/被挂靠人承担（保障劳动报酬、工伤保险待遇）
  - **关联单位混同用工**：已订合同按合同确认；未订合同按用工管理行为、工作时间、内容、报酬支付、社保缴纳等综合确认，可主张关联单位共同担责
  - 外国人取得永久居留/工作许可等情形，支持确认劳动关系
  - 未订书面合同的**二倍工资按月计算**，不满一个月按该月实际工作日计算
  - 劳动者**故意或重大过失不订立书面合同**的，用人单位不付二倍工资
  - 约定/承诺不缴社保的约定无效；劳动者据此解除可主张经济补偿；单位补缴后可要求返还已付社保补偿款
  - 劳动合同期满继续用工未续订→视为续订（承担相应责任）
  - 无法继续履行劳动合同情形、职业健康检查对解除效力影响、诉讼中仲裁时效抗辩等

> 凡涉及"公司用关联公司发工资/签合同""外包/挂靠""约定不缴社保""合同到期继续干"等情形，必须援引本解释（二）。

## 五、高频计算基准（速查）

```
月计薪天数 = 21.75 = (365 - 104个休息日) ÷ 12
日工资 = 前12个月平均应得工资（剔除加班费）÷ 21.75
时薪   = 日工资 ÷ 8

加班费：
  工作日延时 = 时薪 × 150% × 小时
  休息日加班（不能补休）= 时薪 × 200% × 小时
  法定节假日 = 时薪 × 300% × 小时

经济补偿 N：
  基数 = 解除/终止前12个月平均应得工资（含奖金/津贴/加班费，按实施条例第27条）
  年限 = 每满1年→1个月；6个月≤X<1年→1个月；X<6个月→0.5个月
  高薪封顶：月工资>当地上年度社平3倍 → 按3倍，年限≤12年
  违法解除赔偿金 = 2N（第87条）；代通知金+1（第40条三种情形，未提前30日）

未休年休假工资 = 未休天数 × 日工资 × 300%（实际另付200%差额）

违法试用期赔偿金 = 试用期满月工资 × 已履行的超过法定试用期的期间（第83条，与正常工资并行不抵扣）
```

> 年限"折算"疑难（用户高频问）：工作年限跨越**2008-01-01《劳动合同法》施行日**的，依法**分段计算**——2008年前按当时规定（481号时期，协商/不胜任解除受12个月封顶），2008年后按新法。详见 scenarios.md「经济补偿金计算」专题。
