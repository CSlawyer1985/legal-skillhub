# 多法域并行分析指引

本文件为涉及跨境/多地运营的尽调对象提供多法域并行分析方法论，于 Phase 5 起草报告时启用。
---

## 一、触发条件

满足以下任一条件即启动多法域并行分析：

| 条件 | 判断依据 |
|------|---------|
| 境外子公司 | 尽调材料显示在境外（含港澳台）设有子公司、分公司或代表处 |
| 境外资产 | 在境外持有不动产、知识产权、重大股权投资 |
| 跨境业务 | 境外收入占比>10% 或境外客户/供应商为前十 |
| 红筹/VIE架构 | 尽调对象本身或母公司为境外上市主体 |
| 外商投资 | 尽调对象为外商投资企业或股东含境外主体 |

## 二、各法域分析要点

| 法域 | 分析维度 | 重点核查 |
|------|---------|---------|
| **中国大陆** | 主体资格 | 营业执照、外商投资企业批准证书/备案 |
| | 行业准入 | 外商投资负面清单、行业许可、资质许可 |
| | 外汇管理 | FDI登记、外债登记、利润汇出合规 |
| | 税务 | 企业所得税优惠、转让定价、跨境关联交易 |
| | 劳动 | 外籍员工就业许可、社保缴纳 |
| | 数据合规 | 个人信息保护法、数据出境安全评估；AI/数据企业须专项核查训练数据权属、算法备案、爬虫与知识产权合规 |
| **香港** | 主体资格 | 公司注册证明书、商业登记证、周年申报表 |
| | 合规 | 公司秘书、注册地址、年度申报义务 |
| | 税务 | 利得税、印花税、与内地税收协定适用 |
| | 劳动 | 强积金（MPF）、雇佣条例、外籍员工签证 |
| **BVI/开曼** | 主体资格 | Certificate of Incorporation、Memorandum & Articles of Association、Register of Members/Directors |
| | 合规 | Registered Agent 维护、年度申报费用缴付、经济实质法（Economic Substance）合规 |
| | 税务 | 该司法管辖区的税务豁免证明、与相关国家的税收信息交换协议 |
| **美国** | 主体资格 | Certificate of Incorporation/Formation、Good Standing Certificate |
| | 合规 | 州税申报、CFIUS（外资审查）、出口管制（EAR/ITAR） |
| | 税务 | 联邦所得税、州所得税、FATCA |
| | 劳动 | 雇佣分类（雇员/独立承包商）、移民法合规 |
| **欧盟** | 主体资格 | Trade Register 摘录 |
| | 合规 | GDPR、反洗钱、外资审查（各国不同） |
| | 税务 | 增值税（VAT）、企业所得税、DAC6跨境安排申报 |
| | 劳动 | 劳动法指令、员工代表/工会 |
| **东南亚**（新加坡/越南/印尼等） | 主体资格 | 营业执照、投资许可（如越南的IRC/ERC） |
| | 行业准入 | 外资持股限制（不同国家差异大）、本地含量要求 |
| | 税务 | 企业所得税、预提税、与中国税收协定 |
| | 土地 | 外资土地所有权限制 |

> 法规引用补注（P0 #1）：表中「外商投资负面清单」指《外商投资准入特别管理措施（负面清单）（2024 年版）》（发改委商务部令第 23 号，2024-11-01 施行，共 29 条）。⛔ 禁止引用「2025 年版／2026 年版负面清单」或「27 条」等未获双源核实的说法；引用前按 NDR §15.4 复核是否有更新版本。

## 三、并行分析工作流

### Phase 5 集成流程

1. **识别法域**根据尽调材料列出尽调对象涉及的所有法域
2. **制定清单**为每个法域列出本文件第二节的核查清单
3. **并行检索**对不同法域同时进行资料收集和公开渠道检索
4. **交叉比对**核查各法域文件是否一致（如股权结构在各法域的登记是否匹配）
5. **汇总输出**在尽调报告中单设法域分析章节

### 输出格式

```
## 一、多法域合规分析

### 涉及法域概览
| 法域 | 主体名称 | 业务性质 | 持股比例 |
|------|---------|---------|---------|

### 各法域合规状态
[逐法域按第二节要点列出发现和风险]

### 跨境合规风险汇总
| 风险类型 | 涉及法域 | 发现 | 风险等级 | 建议 |
|---------|---------|------|---------|------|
```

> 章节编号（#14）：输出模板一律用「一、二、三…」中文数字章编号，⛔ 不得用「§」符号；与 references/quality-checklist.md 第 48 项「章节命名一致性」一致。
>
> 风险等级术语（#9）：上表「风险等级」按 `ndr-standards.md` §9 统一为 **P0（高风险）/ P1（中风险）/ P2（低风险）**。

## 四、跨境风险交叉警示

| 风险场景 | 涉及法域组合 | 警示要点 |
|---------|-------------|---------|
| 红筹架构 | 中国/开曼/香港 | 外汇登记（37号文）、WFOE与VIE控制文件、经济实质法 |
| 跨境并购 | 中国/目标国 | 反垄断审查（中国+目标国）、CFIUS/外资审查、国家安全审查 |
| 跨境数据 | 中国/EU | 数据出境安全评估 + GDPR双重合规 |
| 转让定价 | 中国/低税率法域 | 关联交易是否符合独立交易原则、是否有被中国税务机关调整的风险 |

**注明**受限于公开渠道数据可获取性与所提供材料范围；无法核实的境外事项须注明信息缺口并要求公司补充。
