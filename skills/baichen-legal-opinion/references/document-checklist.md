# 结构化资料清单

启动法律意见书项目时，逐项向客户发出以下资料清单。

| 分类 | # | 资料项 | 用途/触发条件 |
|------|---|--------|-------------|
| **基础信息**（必提交） | 1 | 委托人营业执照/身份证明 | 确认主体资格 |
| | 2 | 涉及交易对方的身份证明文件 | 确认对方主体 |
| | 3 | 委托人公司章程及修正案 | 核查内部决策权限 |
| | 4 | 涉及本次事项的董事会/股东会决议 | 核查决策程序合法性 |
| | 5 | 委托人授权委托书 | 确认委托关系 |
| **事实材料**（必提交） | 6 | 与委托事项相关的合同、协议及补充协议 | 核心事实依据 |
| | 7 | 相关的往来函件、通知、催告文件 | 确认时间节点与意思表示 |
| | 8 | 相关的付款凭证、交割记录 | 核实履约情况 |
| | 9 | 相关的权属证书（产权、知识产权等） | 确认权利基础 |
| | 10 | 相关的行政许可/审批/备案文件 | 核查合规性 |
| **背景信息**（有条件提交） | 11 | 审计报告/评估报告 | 涉及资产交易或国有资产 |
| | 12 | 税务申报记录 | 涉及税务问题 |
| | 13 | 诉讼/仲裁文件 | 涉及既有争议 |
| | 14 | 行业监管政策文件 | 涉及特殊监管行业 |
| | 15 | 境外主体登记文件 | 涉及跨境交易 |
| | 16 | 知识产权登记/许可文件 | 涉及IP事项 |

## 核查提示

- 要求客户提供原件或加盖公章的复印件
- 口头陈述须记录时间、陈述人、内容，标注"未经独立核实"
- 客户拒绝提供关键材料的，应记录并评估是否继续出具意见书
- 所有材料留存工作底稿，独立建档
