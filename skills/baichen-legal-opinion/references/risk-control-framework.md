# 风险控制框架

法律意见书的风险控制依赖三层防护机制假设前提（Assumptions）、资格限制（Qualifications）、依赖与用途限制（Reliance）。三层叠加构成律所的责任边界。

## 呈现方式

| 方式 | 适用场景 | 做法 |
|------|---------|------|
| **结构化** | 正式意见书、重大交易、监管呈报 | 分独立章节（五、假设与前提 / 九、特别提示 / 十、声明），逐项列明 |
| **融合式** | Memo、简式意见、日常咨询答复 | 将核心保留融入引言和结尾段落，以自然语言呈现 |

融合式示例（引言段）

> "需要说明的是，根据贵司目前提供的部分材料，我们对本案情况的理解可能并不完整或不准确，下述法律分析意见仅供贵司参考。如贵司进一步提供材料或介绍新的事实，我们可能对分析意见作出调整或修改。"

融合式示例（结尾段）

> "以上系我们根据目前材料和贵司介绍的情况所作的法律分析。因本项目……本意见不构成对本案所有事项的详尽分析，仅供贵司参考。如贵司进一步补充材料，我们将出具补充法律意见书。"

**原则**初步意见须在引言和结尾**两处**均嵌入保留声明。

## 初步意见特有风险提示

| 风险 | 提示内容 |
|------|---------|
| 材料不完整 | "本意见基于截至XX日已披露的材料，不排除未掌握材料对结论产生实质性影响" |
| 事实变化 | "若相关事实经有权机构最终认定与目前核查不一致，结论可能相应调整" |
| 意见更新义务 | 明确声明"本所不承担主动更新本意见的义务"，同时预留"如贵司补充材料，我们将出具补充意见" |

## 框架总览

| 层级 | 作用 | 定位 | 必须包含 |
|------|------|------|---------|
| **假设前提** | 界定赖以出具意见但未经独立核实的事实基础 | 意见书的"地基" | 文件真实性、签名有效性、客户陈述完整性 |
| **资格限制** | 明确排除不涵盖的法律领域和事项 | 意见书的"围栏" | 破产法限制、衡平法原则、非法律专业事项 |
| **依赖与用途限制** | 限定意见书的可依赖主体和使用范围 | 意见书的"最后一道锁" | 仅指定收件人可依赖、未经同意不得披露 |

## 一、假设前提（Assumptions）

逐项列出意见书赖以成立的前提，每项假设不成立时结论失效

```
1. 所有文件均为真实、完整，签名、印章均为真实且未被撤销
2. 委托人提供的所有陈述、信息和资料均为真实、准确、完整
3. 所有复印件均与原件一致
4. 各方均依照公司章程和内部决策程序行事
5. [个案特殊假设，如目标公司不存在未披露的重大债务]
```

**编写规则**假设应具体，避免"其他一切正常"等笼统表述；对结论有重大影响的假设须特别标注；口头陈述未核实的，假设中载明"基于委托人陈述，未经独立核实"。

## 二、资格限制（Qualifications）

### 2.1 法定限制（必须列入）

| 限制项 | 内容 |
|--------|------|
| 破产法限制 | 救济意见受破产法、重整程序、暂停执行等法律限制 |
| 衡平法限制 | 特定履行、禁令等衡平救济受法院自由裁量权限制 |
| 时效限制 | 诉讼时效/除斥期间可能影响权利主张 |
| 法律变动 | 意见书基于出具日现行有效法律，不涵盖后续法规变动 |

### 2.2 专业领域排除（必须列入）

| 排除项 | 内容 |
|--------|------|
| 税务事项 | 不就税务后果发表意见，建议另行咨询税务顾问 |
| 审计/会计 | 不就财务数据真实性、准确性发表意见 |
| 技术/工程 | 不就技术可行性、工程质量发表意见 |
| 境外法律 | 不就中国法以外的其他法域法律发表意见 |
| 商业判断 | 不就交易的商业合理性和经济可行性发表意见 |

### 2.3 事实依赖排除

```
本意见所依据的事实截止至XXXX年XX月XX日。若该日期后发生新的事实或情况变化，
可能影响本意见结论，本所不承担更新本意见的义务。
```

## 三、依赖与用途限制（Reliance）

| 限制项 | 内容 |
|--------|------|
| 收件人限制 | 仅供{指定对象}参考使用 |
| 目的限制 | 仅用于{具体目的}之决策参考 |
| 披露限制 | 未经本所书面同意，不得向第三方披露、引用或用于其他目的 |
| 责任限制 | 本意见不构成对任何特定结果的法律保证 |

## 四、风险类型提示

分析过程中须关注以下风险类型，在风险判断中提示

| 风险类型 | 说明 | 触发场景 |
|---------|------|---------|
| 法律适用风险 | 法条解释存在分歧、监管口径不统一 | 新型业务、灰色地带 |
| 资料不完整风险 | 客户未提供或被拒绝提供关键材料 | 材料不全 |
| 诉讼风险 | 可能引发或已存在的诉讼/仲裁 | 争议事项 |
| 对方违约风险 | 交易对方不履行或不完全履行 | 双务合同 |
| 非律师业务范围风险 | 涉及税务/审计/会计/技术判断 | 跨专业事项 |
| 资料不实风险 | 客户提供虚假或误导性材料 | 任何依赖客户陈述的结论 |
| 法规变动风险 | 依赖的法规处于修订过渡期 | 法规修订、新法生效前 |
