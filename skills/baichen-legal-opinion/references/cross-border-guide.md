# 跨境与多法域指引

当委托事项涉及境外因素或多个法域时，按以下指引处理。

## 一、适用法律声明

意见书正文须明确限定适用法域

```
本意见书仅就中华人民共和国（为本意见书之目的，不包括香港特别行政区、
澳门特别行政区及台湾地区）现行有效的法律发表意见。本所不就任何其他
司法管辖区的法律发表意见。
```

涉及香港/澳门/台湾的，分别单独声明

```
就香港特别行政区法律事项，建议另行委托香港执业律师出具独立法律意见。
就澳门特别行政区法律事项，建议另行委托澳门执业律师出具独立法律意见。
就台湾地区相关规定，建议另行委托台湾地区执业律师出具独立法律意见。
```

## 二、跨境事务处理流程

```
跨境事项 → 识别涉及的法域
  ├─ 仅中国法 → 正常出具意见
  └─ 涉及境外法域
        ├─ 需境外律师意见
        │     1. 在意见书中明确排除境外法域
        │     2. 建议客户委托当地律师出具独立意见
        │     3. 如在附件中引用境外法律意见副本，注明
        │        "本意见书附件X为[法域]律师出具的[日期]法律意见书副本，
        │         本所对其内容不发表意见，仅供参考。"
        │     4. 如多法域意见存在逻辑依赖关系，正文中写明链条
        │
        └─ 中国法下的跨境影响（可出具）
              审查在中国法下该跨境事项的合规性、审批要求、外汇管制等
```

## 三、常见跨境场景与应对

| 场景 | 中国法律师可出具的意见范围 | 需提示的限制 |
|------|--------------------------|-------------|
| 境外主体在中国投资 | 外商投资准入、国家安全审查、反垄断审查 | 境外主体在其注册地的合法存续状态 |
| 中国企业境外投资 | ODI核准/备案程序、外汇登记 | 东道国投资准入、税收、劳工法律 |
| 跨境并购交易 | 中国法下的交易合法性、交割条件 | 目标公司所在法域的公司法、证券法 |
| 跨境融资/担保 | 中国法下的担保有效性、外债登记 | 管辖法律和争议解决条款的跨境执行 |
| 跨境数据流动 | 数据出境安全评估、个人信息保护 | 接收方法域的数据保护法律 |

## 四、多法域意见的协同

当一份意见书需要依赖境外律师的意见时

1. **独立出具原则**各法域律师独立对各自法域法律负责
2. **依赖声明**如引用境外意见，须声明依赖范围和限制
3. **逻辑链条**如 A 法域结论是 B 法域分析的前提，须在正文中写明
   ```
   本所关于[事项B]的分析系建立在[A国律师]于[日期]出具的[意见]中
   关于[事项A]的结论基础之上。若该结论发生变化，本所意见须相应调整。
   ```
4. **冲突处理**如不同法域结论存在冲突，须向委托人明确提示并建议协调路径

## 五、语言与翻译

- 意见书正文以中文出具
- 涉及外文文件的，在附件中列明原文并附翻译件
- 翻译件注明"本翻译仅供参考，以原文为准"
- 关键术语首次出现时标注外文原文
