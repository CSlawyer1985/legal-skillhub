# 四级意见分级指南

法律意见书的结论意见采用四级分类体系。每个法律问题独立评级。

## 四级体系

| 等级 | 名称 | 定义 | 适用场景 | 用语示例 |
|------|------|------|----------|----------|
| 1 | **无保留意见** | 法律依据充分，事实清楚，司法/监管实践一致，可出具确定性结论 | 法条明确、事实可核实、无争议 | "本所认为，该行为符合……规定。" |
| 2 | **保留意见** | 法律有规定但实践存在分歧，或关键事实需进一步核实，结论附带条件或不确定性提示 | 灰色地带、依赖未核实事实、监管口径不统一 | "在……前提下，本所认为……但需注意……风险。" |
| 3 | **否定意见** | 经分析，该行为/安排不符合法律规定，或存在不可弥补的重大法律瑕疵 | 明确违法、权利基础不存在、不可补救 | "本所认为，该行为不符合……规定，不建议实施。" |
| 4 | **无法表示意见** | 法律依据不足、事实材料严重不充分或存在法律空白，经勤勉尽责仍无法形成判断 | 法律空白、事实无法核实、超执业范围 | "因……，本所无法对该事项发表确定性意见。" |

## 分级决策树

```
法律问题 → 是否有充足法律依据？
  ├─ 否 → 无法表示意见
  └─ 是 → 事实是否可核实？
        ├─ 否 → 关键事实缺多少？
        │     ├─ 完全缺失 → 无法表示意见
        │     └─ 部分缺失 → 保留意见
        └─ 是 → 法律结论是否明确？
              ├─ 明确合规 → 无保留意见
              ├─ 明确违规 → 否定意见
              └─ 存在争议/不确定性 → 保留意见
```

## 使用规则

- **逐问题独立评级**不因某一问题否定而掩盖其他问题的独立结论
- **保留意见须说明条件**明确告知结论依赖的前提和条件
- **否定意见须附法律依据**逐条指明违反的具体法条
- **无法表示意见须说明原因**解释为何勤勉尽责后仍无法判断
- **不得使用模糊措辞**禁止"基本合规""原则上可以""大致可行"等表述
