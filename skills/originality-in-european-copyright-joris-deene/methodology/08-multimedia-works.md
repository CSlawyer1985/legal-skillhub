# 方法论——多媒体作品（复杂客体）

> **版本 1.0** —— 以 Nintendo / PC Box（C-355/12，EU:C:2014:25，2014 年 1 月 23 日）作为多媒体作品 / 复杂客体的关键判决，并交叉引用 Infopaq（C-5/08）、BSA（C-393/09）、SAS Institute（C-406/10）、Sony/Datel（C-159/23）和 Călinescu/FNSA（C-649/23）。随着更多关于多媒体作品（NFT 作品、AR/VR 作品、AI 多媒体、交互装置）的 CJEU 判例被整合，本模块将予以补充。

> **定位**：本模块将**多媒体作品**作为与软件（`03-software.md`）及其他主要作品类别并列的独立类别加以处理。多媒体作品是一种**混合数字作品**，**并非仅由计算机程序构成**，还包含具有**自身创作价值**的**图形、声音、叙事或交互要素**，该价值不能归结为数字编码。欧盟法依据是：多媒体作品整体适用**指令 2001/29/EC**（信息社会指令），而**指令 2009/24/EC**（软件指令）仅作为*特别法*适用于纯粹的计算机程序部分。

## 在两步测试中的位置

多媒体作品遵循标准的 Cofemel 两步测试（第 29 段）：作品概念 + 独创性。Nintendo（C-355/12）明确确认多媒体作品**不适用提高的门槛**；它们按标准的 Infopaq-Cofemel 公式评估。测试分两步进行：

- **第一步——作品概念**：多媒体作品整体必须能被足够精确和客观地加以确定（Levola Hengelo，C-310/17，第 40 段）
- **第二步——独创性**：多媒体作品必须是作者本人的智力创作（Infopaq 第 35 段；Painer 第 88-92 段；Cofemel 第 30-31 段）。必须在其各个组成部分**以及**其组合方式中识别出自由创造性选择

多媒体作品的核心要点：作品须**作为整体**评估；**不得在**技术功能性组成部分（计算机程序）与创作性组成部分（图形、声音、叙事）**之间进行人为分割**。

## Nintendo 学说 ⭐⭐⭐ —— 复杂客体

### 什么是多媒体作品？

多媒体作品是一种将不同创作性组成部分统一于一个整体中的混合数字作品：

- **计算机程序**（可执行文件、脚本、智能合约等）
- **图形要素**（图像、3D 模型、动画、UI 设计、字体排印）
- **声音要素**（音乐、音效、配音、空间音频）
- **叙事要素**（故事情节、对白、关卡设计）
- **交互要素**（游戏玩法机制、输入/输出响应、分支剧情）
- **数据结构**（游戏状态、内容数据库、素材库）

典型领域：电子游戏、含多媒体内容的移动应用、交互式装置艺术、VR/AR 作品、具多媒体维度的网络作品、含数字内容的 NFT 作品、AI 生成的混合作品。

### Nintendo 核心公式（第 23 段）⭐

> "……本案主程序中的电子游戏构成复杂客体，不仅包含计算机程序，还包含**图形和声音要素，这些要素虽然以计算机语言加密，但具有不能归结为这种加密的独特创作价值**。就电子游戏的各部分（本案中即图形和声音要素）构成其独创性的一部分而言，它们与整个作品一道，**在指令 2001/29 所建立的制度框架内受版权保护**。"（Nintendo 第 23 段）

该公式有四个操作性组成部分：

| 组成部分 | 内容 | 操作性后果 |
|---|---|---|
| **(a) 多媒体 = 复杂客体** | 不仅是计算机程序，还包括图形 + 声音要素 | 作品概念不将技术功能性载体与创作实质性要素分割 |
| **(b) 自身创作价值** | 数字编码并不剥夺组成部分的创作价值 | 创作性要素通过计算机语言实现这一事实，并不减损其独立的创作性质 |
| **(c) 特别法仅适用于纯软件部分** | 指令 2009/24 仅涵盖计算机程序部分 | 多媒体作品整体适用指令 2001/29 的完整制度 |
| **(d) 整体保护** | 有助于独创性的组成部分与**整个作品一道**受保护 | 交叉引用 Infopaq 第 39 段（部分复制）和 Călinescu 第 64 段（反可分割规则） |

### 特别法边界：指令 2009/24 / 指令 2001/29

Nintendo 在两个指令之间作出的一项基本区分：

| 方面 | 指令 2009/24（软件） | 指令 2001/29（信息社会） |
|---|---|---|
| **范围** | 仅限计算机程序（第 1(1) 条） | 一般作品，包括多媒体作品 |
| **特别法地位** | 针对一类作品的特定制度 | 一般制度；在其范围内让位于指令 2009/24 |
| **特定例外** | 逆向工程（第 5 条）、为互操作性进行反编译（第 6 条） | 指令 2001/29 第 5 条的特定例外（引用、戏仿、教育等） |
| **作品概念** | "计算机程序"作为界定概念 | "作品"作为开放的欧盟自主概念（Levola） |

**操作性后果**：在任何多媒体案件中，执业者必须追问——哪些组成部分属于哪种制度？

- 纯计算机程序组成部分（源代码、目标代码、程序结构、作为表达的数据结构）→ 指令 2009/24（见 `03-software.md`）
- 具有自身创作价值的图形、声音、叙事、交互组成部分 → 指令 2001/29（本模块）
- 多媒体作品整体 → 指令 2001/29（Nintendo 第 23 段）

### 与 Călinescu 反可分割规则（第 64 段）的联系

Nintendo 第 23 段和 Călinescu 第 64 段共同构成**针对混合作品的整体性作品概念学说**：

| 要素 | Nintendo（多媒体） | Călinescu（校勘版） |
|---|---|---|
| **混合性质** | 计算机程序 + 图形 + 声音 | 原文 + 校勘 + 评注/校勘性材料 |
| **反可分割表述** | 各组成部分在其有助于独创性的范围内与"整个作品一道"受保护（第 23 段） | 无须区分"与原文对应的部分"与评注；只有作为整体才有意义的作品不得被分割（第 64 段） |
| **表述的范围** | 专门针对多媒体作品 | "只有作为整体才有意义"的作品——跨类别 |
| **与部分复制的关系** | 交叉引用 Infopaq 第 38 段（Nintendo 第 22 段） | 交叉引用 Infopaq 第 39 段（Călinescu 第 67 段） |

关于反可分割规则在跨类别视角下的一般学说：见 `01-originality-test.md`《Călinescu 细化：反可分割规则与技能排除》一节。

### 什么不构成多媒体作品

| 示例 | 地位 |
|---|---|
| 无显著创作性图形/声音产出的计算机程序 | 不构成多媒体作品；属于指令 2009/24 范畴 |
| 带装饰性横幅的命令行工具 | 不构成多媒体作品；横幅组成部分可能依指令 2001/29 单独受保护 |
| 无自身多媒体维度的数据库 | 不构成多媒体作品；适用数据库制度（见 `04-databases.md`） |
| 单纯的格式转换工具 | 不构成多媒体作品；属于指令 2009/24 范畴的软件 |

### 什么构成多媒体作品

| 类别 | 定性 |
|---|---|
| **电子游戏**（Nintendo 核心案件） | 指令 2001/29 下的复杂客体（Nintendo 第 23 段） |
| **含多媒体内容的交互式移动应用** | 指令 2001/29 下的复杂客体（类推） |
| **VR/AR 作品** | 指令 2001/29 下的复杂客体（类推） |
| **交互式数字装置艺术** | 指令 2001/29 下的复杂客体（类推） |
| **含实质性数字内容的 NFT 作品** | 内容层属于指令 2001/29 下的复杂客体（类推） |
| **多媒体教育作品**（含视频、音频、交互的在线学习） | 指令 2001/29 下的复杂客体（类推） |

## Nintendo 对 Infopaq 的确认

### 作品概念公式（第 21 段）

Nintendo 第 21 段明确确认了指令 2001/29 下作品概念的 Infopaq 公式——并非专门针对多媒体，而是作为一般基础：

> "对于诸如计算机程序之类的作品，只要它们具有独创性，即属于作者本人的智力创作，即受版权保护。"（Nintendo 第 21 段，交叉引用 Infopaq 第 35 段）

### 部分复制学说（第 22 段）

Nintendo 第 22 段确认：作品的**部分**只要"本身包含整个作品的独创性"，即受保护。这直接适用于多媒体作品：有助于多媒体作品独创性的图形子要素、音乐片段、UI 组件或游戏玩法片段，其本身受保护（交叉引用 Infopaq 第 38 段）。

> 操作效果：对于权利人关于多媒体作品部分复制的主张，只要被复制的子要素"包含整个作品的独创性"即已足够。交叉引用：部分复制的侵权认定问题参见 Infopaq 第 39 段（Călinescu 第 67 段适用）。

## 操作性检查清单——多媒体作品

### 权利人一方（确立版权）

- [ ] 证明该作品属于 Nintendo 第 23 段意义上的**多媒体作品**（复杂客体：不仅是计算机程序）
- [ ] 第一步（作品概念）：证明作品整体的客观可识别性（Levola）
- [ ] 第二步（独创性）：证明各组成部分——视觉、听觉、叙事、交互——及其组合方式中的自由创造性选择
- [ ] 证明创作性组成部分具有不能归结为数字编码的**自身创作价值**（Nintendo 第 23 段）
- [ ] 援引**整体保护**：各组成部分与整个作品一道（Nintendo 第 23 段末）
- [ ] 抵制对方将作品人为分割为软件部分（指令 2009/24）和非软件部分
- [ ] 对"只有作为整体才有意义"的作品援引 **Călinescu 反可分割规则**第 64 段
- [ ] 部分复制：交叉引用 Infopaq 第 38-39 段和 Nintendo 第 22 段

### 被指控侵权人一方（质疑版权）

- [ ] 审查该作品是否真的是**复杂客体**，抑或仅仅是带极少量图形产出的计算机程序
- [ ] 审查图形/声音要素是否具有**自身创作价值**，抑或仅是技术/功能性组成部分（平庸的 UI、通用音效）
- [ ] 可进行逐组成部分分析：论证个别创作性组成部分不满足门槛（如标准 UI 要素、作为思想的通用游戏玩法机制——SAS Institute；技术决定因素——Brompton）
- [ ] 利用纯软件组成部分的特别法边界：指令 2009/24 及其特定制度（第 6 条反编译例外）
- [ ] 限定反可分割规则（Călinescu 第 64 段）：对于组成部分具有独立意义的多媒体作品（如可单独使用多媒体内容的移动应用），逐组成部分分析仍可适用
- [ ] 思想/表达合并：游戏玩法机制、叙事套路和通用设计选择可视为思想（交叉引用 SAS Institute、BSA、Funke Medien）
