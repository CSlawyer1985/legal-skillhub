# 方法论——作品概念（两步测试的第一步）

> **版本 1.0** —— 完整论述基于 Levola Hengelo（C-310/17，EU:C:2018:899，2018 年 11 月 13 日），并以 Cofemel（C-683/17）、Brompton（C-833/18）、Funke Medien（C-469/17）、Mio/Konektra（C-580/23 + C-795/23）、Călinescu/FNSA（C-649/23）和 Nintendo / PC Box（C-355/12）作为确认性判例交叉引用。

## 在两步测试中的位置

在 Levola Hengelo 之前，欧盟独创性测试通常作为一个整体呈现。自 Levola 起，该测试被明确**拆分为两个连续步骤**：

| 步骤 | 问题 | 来源 |
|---|---|---|
| **第一步——作品概念** | 该客体是否根本可被认定为指令 2001/29 意义上的"作品"？ | **Levola Hengelo**（C-310/17）——本模块 |
| **第二步——独创性** | 该作品是否具有独创性（属于作者本人的智力创作）？ | Football Dataco（C-604/10）——模块 `01-originality-test.md` |

两个步骤是**累积的**。客观可识别但不具独创性的客体不构成作品。可能具有独创性但无法客观识别的客体同样不构成作品。

## Levola 公式

作品概念测试的核心载于**Levola Hengelo 第 40 段**：

> "因此，要构成指令 2001/29 所称的'作品'，**受版权保护的客体必须以使其能够以足够的精确性和客观性被识别的方式加以表达，尽管该表达不一定是永久性的**。"

该测试由三个要素构成：

1. **表达形式**：客体必须以某种形式表达（而不仅仅是作为思想存在）
2. **足够的精确性和客观性**：表达必须足够精确，使作品的内容能够被具体识别
3. **不一定是永久性的**：即兴表演、舞蹈、行为艺术和口头表达可以构成作品，即使它们未被固定

## 两个基本理由（Levola 第 41 段）

法院解释了**为何**要求客观可识别性——两个可在操作层面援引的理由：

### 理由 1 —— 第三方的识别

> "这是因为，首先，**负责确保版权固有专有权受保护的机关必须能够清晰、精确地识别受保护的客体**。对个人、尤其是经济经营者而言同样如此，他们必须能够清晰、精确地识别第三方（尤其是竞争对手）所享有的保护客体是什么。"

- 法院必须能够确定是否存在受保护的作品
- 集体管理组织必须能够识别其管理范围内的对象
- 海关机关必须能够确定进口商品是否侵权
- 竞争对手必须能够知道其不得复制的内容
- 使用者必须能够知道其行为何时是被允许的

### 理由 2 —— 通过排除主观性实现法律确定性

> "其次，**鉴于主观性有损法律确定性，必须确保在识别受保护客体的过程中不存在任何主观要素**，这意味着该客体必须能够以精确和客观的方式加以表达。"

- 版权主张不得依赖于个人的主观印象
- 不同观察者必须能够确认他们看到的是否是同一客体
- 保护客体的界定必须是主体间可验证的

## 什么是客观可识别的，什么不是？

### 客观可识别（Levola 第 42 段，附明确示例）

> "不同于例如**文学作品、绘画、电影或音乐作品**这类精确而客观的表达形式……"

| 作品类别 | 锚点 | 备注 |
|---|---|---|
| 文学作品 | 文本 | 通过阅读直接识别 |
| 绘画 | 视觉构图 | 通过观看直接识别 |
| 电影 | 视听录制品 | 通过观看识别 |
| 音乐作品 | 乐谱或录音 | 通过聆听识别 |
| 雕塑 | 三维形态 | 直接识别 |
| 照片 | 图像 | 直接识别 |
| 建筑 | 图纸 + 建筑物 | 通过图纸识别 |
| 舞蹈编排 | 记谱或录像 | 通过重建识别 |
| 软件 | 源代码/目标代码 | 通过检查识别 |
| 戏剧作品 | 剧本 + 演出 | 通过文本识别 |
| 现场表演 / 舞蹈 | 表演 | 在表演时刻识别（第 40 段，非永久性） |
| 即兴表演（如爵士乐） | 表演 | 同上 |

### 客观不可识别（排除于作品概念之外）

| 客体 | 来源 | 理由 |
|---|---|---|
| 食品的**味道** | Levola 主文 + 第 42-44 段 | 主观的，取决于个人因素和情境 |
| **气味**（香水、芳香） | Levola 第 24 段（隐含确认） | 同上 |
| **视觉氛围或环境气氛**本身 | Levola 的逻辑 | 无法具体识别 |
| **风格**本身（体裁、美学） | Levola 的逻辑 | 一般特征，而非具体客体 |
| 无具体展开的**概念** | Levola 第 39 段 + SAS Institute | 思想，而非表达形式 |
| 无具体组成部分的**总体印象** | Levola 的逻辑 | 主观印象，而非客观客体 |
| **体验类型**（如交互活动"模式"） | Levola 的逻辑 | 过于抽象 |
| **口感 / 质地**（如 Levola 本人在诉讼中主张的） | Levola 主文明确涵盖这些要素 | 感官的和主观的 |

## 重要细化

### 非永久性的表达形式是允许的

Levola 第 40 段明确未包含作品必须被永久固定的要求。这与以下情形相关：

- **行为艺术** —— 一次性表演可以构成作品
- **即兴表演**（爵士乐、现代舞）—— 在表演时刻构成作品
- **大地艺术和特定场域作品** —— 临时装置
- **口头表达**和演讲
- **无出版剧本的戏剧**

条件是作品在**表演期间客观可识别**。

### 这是欧盟自主概念（Levola 第 33 段）

作品概念是一个**欧盟自主概念**，由 CJEU 统一解释。成员国不能通过更宽泛的国内解释，对欧盟法意义上不构成作品的对象授予版权保护（Levola 第 45 段 + 主文）。

重要后果：

- 早期给予宽泛保护的国内判例（如将香水作为受保护作品）已被超越
- 国内的"作品"概念必须按欧盟法意义解释

### 与其他知识产权的累积仍然可能

欧盟法意义上不构成"作品"的对象，仍可通过以下途径获得保护：

- **专利法**（针对发明）—— 如 Heksenkaas 的方法专利（Levola 第 15 段）
- **商标法**（针对显著性标志，包括在可图形化表示前提下的味道/气味——自废除图形表示要求以来范围有所拓宽）
- **设计法**（针对产品的外观）
- **数据库特别权利**（针对数据库的内容，与版权并行或替代——Football Dataco）
- **商业秘密**（针对配方、公式、专有技术）
- **不正当竞争 / 仿冒行为**（补充性的，须符合严格标准）

## 操作性检查清单——两步测试的第一步

### 权利人一方：确立作品存在

- [ ] **识别具体客体**：不仅仅是思想，而是具体的表达
- [ ] **描述表达形式**：文本、图像、声音、代码、形状、表演
- [ ] **确立客观可识别性**：第三方如何无需主观评估即可识别该客体？
- [ ] **记录锚点**：手稿、乐谱、代码、照片、视频、实物、表演录像
- [ ] **预判 Levola 攻击**：避免主观描述（"……的风格"、"……的气氛"、"……的味道"）
- [ ] **对非永久性作品**：充分记录表演（视频、证人、描述）

### 抗辩一方：确立作品不存在

- [ ] **识别对方的主张**：要求对方**具体**描述保护客体是什么
- [ ] **指出主观要素**：识别是否依赖于个人评估？
- [ ] **指出变异性**：该客体对不同观察者、在不同时刻是否相同？
- [ ] **通过 Levola 第 41 段论证**：法官、海关官员或竞争对手能否客观确定受保护的是什么？
- [ ] **识别适用的排除类别**：味道、气味、气氛、风格、概念、总体印象

## Cofemel、Brompton、Funke Medien、Mio/Konektra、Călinescu——在 Levola 基础上的发展

后续判例明确承接了 Levola 的作品概念公式：

- **Cofemel 第 32 段**（C-683/17）：逐字重复 Levola 公式，并将其适用于时装设计
- **Brompton**（C-833/18）：确认实用物品（消费品、折叠自行车）同样适用 Levola 测试
- **Funke Medien**（C-469/17）：针对功能性/行政性文本予以确认（Funke Medien 第 19 段交叉引用 Levola）
- **Mio/Konektra 第 72 段**（合并案件 C-580/23 + C-795/23）：针对实用艺术品明确重复 Cofemel 的两个理由（机关和第三方识别 + 排除有损法律确定性的主观性）。明确引用 Cofemel 第 32-33 段
- **Călinescu / FNSA 第 62 段**（C-649/23）：针对演绎作品/校勘版确认，作品概念"必然要求存在一种能够以足够的精确性和客观性识别作品的表达"。交叉引用 Levola Hengelo 第 40 段。第 63 段认为，校勘版**作为整体**可以构成充分可识别——与第 64 段的反可分割规则相关联

对本技能而言，这意味着作品概念测试在所有类别中构成**统一的起点**——无论照片、软件、体育赛事、数据库、实用艺术品、文本、演绎作品还是所有其他作品类别。

## 味道、气味和感官体验——最终排除

Levola 是排除味道和（隐含地）气味的**权威依据**：

| 客体 | Levola 之后的地位 | 替代保护 |
|---|---|---|
| 食品的味道 | 不受保护（主文） | 专利（方法）、商业秘密、商标法（非常有限） |
| 香水的香气 | 几乎确定不受保护 | 专利（配方）、商业秘密、商标法 |
| 质地、口感 | 不受保护（Levola 逻辑） | 有限；商业秘密 |
| 配方（作为思想/方法） | 不受保护 | 专利、商业秘密 |
| **配方（作为文本）** | **确实**构成文字作品，如有独创性 | — |
| **味道的书面描述** | 确实构成文本，如有独创性 | — |

重要区分：烹饪创作的**表达**（配方文本、菜肴图像、雕塑式摆盘）可以构成作品。**味觉体验**本身不能。

## 本模块的主要判决

- **Levola Hengelo**（C-310/17，EU:C:2018:899）—— 提出两步测试和客观可识别性
- **Cofemel**（C-683/17，EU:C:2019:721）—— 确认两步测试，并针对实用艺术品重复 Levola 公式（第 32 段）
- **Brompton**（C-833/18，EU:C:2020:461）—— 针对实用物品确认 Levola
- **Funke Medien**（C-469/17，EU:C:2019:623）—— 针对功能性文本确认 Levola
- **Mio/Konektra**（C-580/23 + C-795/23，EU:C:2025:941）—— 针对实用艺术品确认 Levola 公式（第 72 段）；重复客观可识别性的两个理由
- **Călinescu / FNSA**（C-649/23，EU:C:2026:213）—— 针对演绎作品/校勘版确认 Levola 公式（第 62 段）；作品可以**作为整体**被足够精确和客观地识别（第 63 段）；交叉引用第 64 段的反可分割规则
- **Nintendo / PC Box**（C-355/12，EU:C:2014:25）—— 针对多媒体作品确认 Infopaq 作品概念公式（第 21 段）；"包含整个作品独创性"的部分的部分复制（第 22 段，交叉引用 Infopaq 第 38 段）；Călinescu 反可分割规则在多媒体语境下的学说先驱（第 23 段）
