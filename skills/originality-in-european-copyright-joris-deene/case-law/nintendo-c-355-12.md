## 在本技能中的定位——严格限定范围

> **范围界定**：Nintendo 案主要是**技术保护措施（TPM）判决**（《指令 2001/29》第6条项下的技术保护措施）。关于相称性、有效性以及保护措施商业有限目的的大量论证（第24-38段）**不在**本技能范围内，本技能严格聚焦于作品概念+独创性。
>
> 范围内：**第21-23段**——对 Infopaq 作品概念的确认（第21段）、对 Infopaq 部分复制规则的确认（第22段）以及**多媒体作品复合客体（complex matter）原则**（第23段）。后者是 Nintendo 案在学说上的独立贡献，开启了部门模块 `08-multimedia-works.md`。

## 主题事项与类别

- **技能内主要类别**：多媒体作品/复合客体——作品概念首次适用于混合数字作品
- **特殊贡献** ⭐：
  - **确认 Infopaq 第35段**（第21段）：计算机程序和其他作品的作 品概念公式——"作者自己的智力创作"
  - **确认 Infopaq 第38段**（第22段）："作品的各部分……就其本身而言，由于共享整部作品的独创性而受版权保护"
  - **多媒体复合客体原则** ⭐⭐（第23段）："电子游戏……构成复合客体，不仅包含计算机程序，还包含图形和声音元素，这些元素虽然以计算机语言加密，但具有不能归结为加密本身的独特创作价值"
  - **《指令 2009/24》与《指令 2001/29》的特别法（lex specialis）边界**（第23段）：软件指令**仅适用于计算机程序组成部分**；《指令 2001/29》的完整制度适用于作为整体的多媒体作品（包括图形和声音元素）
- **适用立法**：《指令 2001/29/EC》第1条第(2)款第(a)项和第6条；《指令 2009/24/EC》第1条第(1)款；《指令 2001/29》序言第9、47-50段；《伯尔尼公约》第2条第(1)款
- **对本技能的重要性**：★★★★——*多媒体作品的核心判决；开启模块 08-multimedia-works.md*

## 四行事实摘要

Nintendo 销售两种类型的游戏机（"DS"掌机和"Wii"家用机），配备技术保护措施（主机内的识别系统+游戏实体介质上的加密代码），可阻止电子游戏的非法复制——同时也阻止非 Nintendo 程序和多媒内容在主机上使用。PC Box 通过 9Net 托管的网站销售"改机芯片"和"游戏复制器"；这些设备规避了 TPM，使非法复制品的使用以及独立的"自制（homebrew）"应用程序（MP3、电影、视频）成为可能。Nintendo 依意大利对《指令 2001/29》第6条的转化规定向米兰法院起诉 PC Box 和 9Net。移送法院提出了两个先决问题：(i) TPM 保护是否可以延伸至主机交互；(ii) 评估规避保护范围的准则。

## 法律问题（与本技能相关的子问题）

在主要 TPM 问题（范围外）之外，还存在一个先决问题：电子游戏**本身**是否依《指令 2001/29》受版权保护，以及《指令 2009/24》的特别法是否排除《指令 2001/29》对电子游戏的适用。

## 判决主文（部分——与本技能相关）

判决主文主要涉及 TPM 问题（范围外）。对本技能而言，只有判决第23段在学说上相关：**多媒体作品复合客体原则**产生于判决第21-23段与 Infopaq 原则结合适用的运作。

## 范围内的关键推理

### 第21段——*确认 Infopaq 作品概念公式*

> "就此而言，首先必须指出，《指令 2001/29》——正如其第1条第(1)款等所显示——涉及版权和相关权利的法律保护，包括对作者而言的对其作品的专有权利。至于计算机程序等作品，只要其具有独创性，即属于其作者自己的智力创作，即受版权保护（见 C-5/08 Infopaq International 案 [2009] ECR I-6569，第35段）。"

### 第22段——*确认 Infopaq 部分复制原则*

> "关于作品的各部分，应当铭记，《指令 2001/29》中没有任何内容表明这些部分应与整部作品区别对待。因此，它们受版权保护，因为它们就其本身而言共享整部作品的独创性（见 Infopaq International 案，第38段）。"

### 第23段——*多媒体作品的复合客体原则* ⭐⭐⭐

> "《指令 2009/24》构成相对于《指令 2001/29》的特别法这一事实并不削弱上述认定（见 C-128/11 UsedSoft 案 [2012] ECR，第56段）。依其第1条第(1)款，《指令 2009/24》提供的保护限于计算机程序。正如移送命令所示，**电子游戏，如主诉程序中的电子游戏，构成复合客体，不仅包含计算机程序，还包含图形和声音元素，这些元素虽然以计算机语言加密，但具有不能归结为加密本身的独特创作价值**。就电子游戏的各部分——在本案中即图形和声音元素——属于其独创性的组成部分而言，它们连同整部作品一起，在《指令 2001/29》确立的制度框架内受版权保护。"

## 对本技能的学说意义

### 1. 确认 Infopaq 原则（第21-22段）

Nintendo 案未增加新的独创性测试，但确认了 Infopaq 的两个要素：

| 要素 | Nintendo 案来源 | Infopaq 交叉引用 |
|---|---|---|
| 作品概念公式"作者自己的智力创作" | 第21段 | Infopaq 第35段 |
| "共享独创性"的各部分的部分复制 | 第22段 | Infopaq 第38段（后来 Infopaq 第39段亦适用于 Calinescu 案第67段） |

### 2. 多媒体作品的复合客体原则（第23段）⭐⭐⭐

判决首次明确提出，**多媒体作品（本案中的电子游戏）**必须被视为**复合客体**，适用《指令 2001/29》的完整制度，而非《指令 2009/24》软件指令项下的计算机程序。

| 组成部分 | 内容 | 操作后果 |
|---|---|---|
| **(a) 多媒体 = 复合客体** | 不仅包含计算机程序，还包含图形+声音元素 | 作品概念不将载体（技术性）与内容（艺术性/创作性）分割 |
| **(b) 独特创作价值** | 图形和声音元素具有"不能归结为加密本身的独特创作价值" | 创作性元素通过计算机语言实现这一事实并不剥夺其自主的创作性质 |
| **(c) 特别法仅适用于计算机程序组成部分** | 《指令 2009/24》**仅**涵盖计算机程序组成部分 | 作为整体的多媒体作品由《指令 2001/29》的制度管辖（完整——包括所有利用权和例外） |
| **(d) 子元素与整体一起受保护** | 只要图形/声音元素对作品独创性作出贡献：与**整部作品一起**受保护 | 对图形或声音元素的部分复制可构成对多媒体作品的侵权（交叉引用 Infopaq 第39段、Calinescu 第67段） |

### 3. 与软件判例的关系（BSA、SAS Institute、Sony/Datel）

Nintendo 案细化了软件指令的范围。BSA、SAS Institute 和 Sony/Datel 在《指令 2009/24》**内部**细化范围（什么是计算机程序的"表达"？），而 Nintendo 案划定了软件指令的**外部边界**：

| 判决 | 对《指令 2009/24》范围的贡献 |
|---|---|
| **BSA**（C-393/09） | 图形用户界面（GUI）≠ 计算机程序的表达（属于《指令 2001/29》） |
| **SAS Institute**（C-406/10） | 功能、编程语言、文件格式 ≠ 表达 |
| **Sony/Datel**（C-159/23） | 工作内存中的运行时变量 ≠ 表达 |
| **Nintendo**（C-355/12） | 多媒体作品（带图形/声音元素的电子游戏）≠ 单纯的计算机程序——整体属于《指令 2001/29》 |

### 4. 与 Calinescu 反碎片化原则（C-649/23）的关联

Nintendo 案第23段是 Calinescu 反碎片化原则（Calinescu 第64段）的**学说先行者**。两个判决都拒绝将作品人为分割为受保护与不受保护的组成部分：

| 判决 | 反碎片化表述 |
|---|---|
| **Nintendo 第23段** | 多媒体作品：图形/声音元素在有助于独创性的范围内**与整部作品一起**受保护 |
| **Calinescu 第64段** | 评注版（critical editions）：无须区分"与原始作品对应的部分"与评注/注释——作品只有作为整体才具有意义 |

两个判决都为不同组成部分共同构成作品的混合作品提出了**整体性作品概念方法**。Nintendo 案在多媒体语境中（技术性+创作性组成部分）如此表述，Calinescu 案在演绎作品语境中（公有领域文本+创作性添加）如此表述。

### 5. 对现代数字作品的适用视角

复合客体原则经久不衰，为以下作品类型提供作品概念锚点：

| 作品类型 | 复合客体原则的适用 |
|---|---|
| **电子游戏**（Nintendo 案核心） | 计算机程序+图形+声音元素+叙事 |
| **互动装置** | 代码+视觉/听觉组件+感官输入 |
| **VR/AR 作品** | 代码+3D 模型+空间音频+互动因素 |
| **NFT 作品（纯数字）** | 代码（智能合约）+视觉/听觉内容+元数据 |
| **AI 生成的多媒体** | 算法+参数+输出组件 |
| **网页作品/超文本** | HTML/CSS/JS+内容+互动性 |
| **移动应用** | 计算机程序+UI+多媒体内容 |

在所有这些情形中，经类比：作为整体的作品属于《指令 2001/29》（完整制度），《指令 2009/24》软件指令仅适用于纯计算机程序组成部分。

## 论证后果

### 对寻求确立多媒体作品版权者（支持权利人）

Nintendo 案对权利人**特别有利**：

1. **《指令 2001/29》完整制度**：多媒体作品属于全套专有权利（复制、向公众传播、发行），而非《指令 2009/24》的有限制度
2. **整体性作品方法**：图形、声音和其他创作性元素与计算机程序**一起**受保护——不人为分割
3. **组成部分的独特创作价值**：数字编码不剥夺组成部分的创作价值
4. **部分复制即足以构成侵权**：第22段——共享作品独创性的部分受保护
5. **反碎片化锚点（交叉引用 Calinescu 第64段）**：将作品作为整体评估，不人为分割

策略方法：

- 第1步（作品概念）：将多媒体作品作为整体识别
- 第2步（独创性）：证明各组成部分（视觉、听觉、叙事、互动）及其编排中存在自由的创作选择
- 反驳软件指令抗辩：第23段明确《指令 2009/24》仅涵盖计算机程序组成部分

### 对寻求争辩多媒体作品不构成版权侵权者（支持被控侵权人）

Nintendo 案对被告方**具有挑战性**，但仍存在攻击线：

1. **"独特创作价值"必须证明**：第23段要求图形/声音元素具有**独特创作价值**。对于平庸、通用或技术决定的组成部分，作品未达门槛
2. **可进行逐组件分析**：虽然作品作为整体评估，但被告方可以证明某些组成部分本身不提供创作贡献（如标准 UI 元素、依 SAS Institute 案属于思想的通用游戏机制）
3. **利用特别法边界**：对于纯软件方面（算法、数据结构、程序结构），《指令 2009/24》以其特定制度适用——包括《指令 2009/24》第5-6条的反编译例外
4. **多媒体性质不足**：对于*事实上*只是带有极少图形输出的计算机程序的作品（如带装饰性横幅的命令行工具），被告方可辩称其不符合 Nintendo 案意义上的"复合客体"资格
