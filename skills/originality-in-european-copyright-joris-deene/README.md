# 欧洲版权法中的独创性——构建状态

> **版本 1.0** —— 针对欧盟版权法中独创性与作品概念测试的技能，基于欧盟法院的判例。

## 当前版本

**v1.0** —— 首次公开发布。整合了**欧盟独创性法定统一化框架**：逐字引用四条明确涉及独创性的指令条款——指令 2009/24/EC 第 1(3) 条（计算机程序）、指令 96/9/EC 第 3(1) 条（数据库）、指令 2006/116/EC 第 6 条（照片）以及指令（欧盟）2019/790（DSM 指令）第 14 条（公共领域中的视觉艺术作品）。其中三条条款共有的"*不得适用任何其他标准*"条款构成了 Cofemel 规则（第 29 段）的法定底线，即成员国不得施加额外要求。专门章节《欧盟独创性统一化框架》见 `methodology/01-originality-test.md`；逐字文本亦收录于 `02-photography.md`、`03-software.md`、`04-databases.md`、`07-derivative-works.md`。

学理核心由十五个关键判决构成（Infopaq + Painer + BSA + FAPL + Football Dataco + SAS Institute + Levola Hengelo + Cofemel + Brompton + Funke Medien + Mio/Konektra + Călinescu/FNSA + Nintendo + Renckhoff + Sony/Datel），外加 Top System 作为脚注提及。本技能提供**完整的两步测试**，并为九类作品设有类别特定模块：

- **第一步——作品概念**（Levola Hengelo，C-310/17）：客观可识别性；排除味觉、嗅觉及其他主观对象
- **第二步——独创性**（Infopaq + Painer + BSA + FAPL + Football Dataco + SAS Institute）：作者本人的智力创作；四项一般排除理由（技术功能、规则决定的结果、额头流汗原则、思想/功能性）
- **整合**（Cofemel，C-683/17）：两步测试合为一段；禁止附加美学标准；版权与设计权累积保护
- **实用物品的细化**（Brompton，C-833/18）：技术决定因素并不自动排除版权；替代方案是参考指标而非决定性因素；已过期专利和有效性作为参考标志
- **照片的确认**（Renckhoff，C-161/17，第 14 段）：Painer 公式被明确推广适用于一般照片；国家法院逐案评估的程序要求
- **功能性文本**（Funke Medien，C-469/17）：纯信息性文件的思想/表达合并；三项累积标准；排除额头流汗原则；逐案评估
- **软件的细化**（Sony/Datel，C-159/23）：计算机程序"表达"的可重现性测试；工作内存中的运行时变量不属于表达；字面表达公式；确认洁净室逆向工程；针对现代软件争议（作弊工具、插件、浏览器扩展、运行时修改器、AI 智能体）的操作锚点
- **实用艺术品的最终整合**（Mio/Konektra，合并案件 C-580/23 + C-795/23）：设计与版权之间不存在规则—例外关系（主文第 1 项，无提高的门槛）；**"独特方面"要求**（主文第 2 项：没有独特方面的自由选择不构成创作）；**选择的创作性质无推定**（第 65 段）；作者意图 = 思想（第 74 段）；既有形式不排除独创性（第 78 段）；自身作品的变体与受启发作品（第 79 段）；既有相似作品作为独创性低或缺失的参考标志（第 80 段）；非决定性因素清单（灵感来源、既有形式、独立创作的可能性、专业圈子的认可）
- **校勘版和演绎作品**（Călinescu/FNSA，C-649/23）：CJEU 首次将两步测试适用于公共领域作品的校勘版；核心公式第 54 段（词语的选择/编排/组合 + **"技能无关"**）；补充因素第 55 段（语文学专业知识、对时代的了解、对作者意图的解释作为证据手段，而非独立依据）；第 56 段（结构布局、结构、版面、编排）；评注和校勘性材料亦属智力创作（第 58 段）；**反可分割规则**（第 64 段：不得人为分割"只有作为整体才有意义"的作品——具有一般相关性）；**公共领域保障**（第 68 段：演绎作品的版权不授予对原作品的独占权利）；统一的保护范围（第 66 段）
- **多媒体作品与复杂客体**（Nintendo / PC Box，C-355/12）：CJEU 首例涉及多媒体作品（电子游戏）的裁决；**复杂客体学说**第 23 段（多媒体作品是复杂客体，不仅包含计算机程序，还包含具有自身创作价值的图形和声音元素）；**特别法边界**指令 2009/24 / 指令 2001/29（软件指令仅涵盖计算机程序组成部分；多媒体作品整体属于指令 2001/29 范畴）；整体保护（各组成部分与完整作品在有助于其独创性的范围内一并受保护）；确认 Infopaq 第 35 段（作品概念）和 Infopaq 第 38 段（部分复制）；Călinescu 反可分割规则在多媒体语境下的学说先驱

摄影、软件/图形用户界面、体育赛事、数据库、实用艺术品、实用物品、文本/片段、演绎作品和多媒体作品的类别模块均已完整开发。

## 架构

完整描述见 `SKILL.md`。简要概述：

- `methodology/` —— 一般性和类别特定测试
- `case-law/` —— 各判决的参考文件

- `workflow.md` —— 逐步操作程序

## 范围

本技能仅涉及**欧盟层面的统一化**。各成员国的国内实施不在范围内，执业者须另行查阅。

## 反幻觉规则

本技能仅引用在 `case-law/` 中已有参考文件的判决。对于所有其他引用，应写明"待补充判例引用"（case reference to be added），并仅提供法律原则。
