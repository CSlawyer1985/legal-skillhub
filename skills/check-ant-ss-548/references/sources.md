# 离职前后股权激励纳税归属判断｜来源与核验规则

## 官方来源优先级

1. 国家税务总局
2. 财政部
3. 上市公司或雇主正式文件
4. 办理地税务部门

搜索时优先使用主管部门官网、政务服务网、官方办事指南、正式政策原文和用户合同原文。政策来源优先限定 `.gov.cn` 或对应主管部门官方域名；商业保险责任以用户持有的有效合同及保险公司正式理赔规则为准。

## 每次执行必须记录

- 办理地及具体区县；
- 用户身份和目标事项；
- 政策标题、发文机关、文号或页面名称；
- 生效日期、失效或替代情况；
- 官方链接和本次核验日期；
- 适用条件、例外和仍待确认事项。

## 禁止的准确性捷径

- 不把搜索摘要、营销文章、自媒体问答或第三方计算器当最终依据；
- 不把其他城市、其他年度或其他身份的规则套用到用户；
- 不因存在社保记录就承诺派生资格；
- 不用“绝对合规”“零风险”“百分百通过”等无法验证的表达；
- 不提供虚假劳动关系、伪造材料或违规补缴情形。

## 输出口径

采用“直接结论 → 适用人群 → 政策依据 → 办理流程或计算 → 风险边界 → 常见问题 → 官方来源 → 更新时间”的顺序。来源不足时停止给确定结论。
