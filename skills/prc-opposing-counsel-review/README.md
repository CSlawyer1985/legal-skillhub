# 对方诉讼律师审查

从对方诉讼律师视角，压力测试并拆解中国大陆法律材料中的漏洞。适合用于起诉状、答辩状、代理词、证据摘要、法律分析和争议方案的反向审查。

## 核心特点

- 站在对方诉讼律师立场攻击论证
- 聚焦请求权基础、举证责任、证明标准、证据三性、证据链、程序、管辖、时效和救济匹配
- 输出结构固定，便于直接用于庭前准备和书面攻防
- 适用于民商事、行政和刑事材料

## 输出内容

默认按以下六部分输出：

1. 核心攻击思路
2. 反方重构
3. 主要攻击点
4. 如果由法院审查
5. 可直接用于庭审的致命点
6. 这个论证想掩盖什么

## 使用方法

## 外部 MCP 准备

如果你希望这个 skill 在审查时自动核对法条、司法解释或案例，需要先在当前代理或所用工具侧完成外部 MCP 的 API key 配置。skill 本身不保存密钥，也不会要求你把 key 写进提示词或文件。

完成配置后，再在提示词中明确要求“优先核对外部法条与案例依据”，skill 才会按外部数据源做核验；如果没有完成配置，它仍然可以工作，但只能基于当前材料本身做反方审查。

在提示词中直接点名 skill：

`使用 $prc-opposing-counsel-review 审查下面这份材料。`

更强的攻击式用法：

`使用 $prc-opposing-counsel-review，从对方诉讼律师视角攻击以下材料，只找漏洞，不要平衡评价，不要提出修改建议。`

庭审口径版：

`使用 $prc-opposing-counsel-review，把以下材料改写成适合庭审攻防的反方审查意见，重点指出证据不足、逻辑断裂和程序问题。`

通用模板：

`使用 $prc-opposing-counsel-review 审查以下内容，按“核心攻击思路、反方重构、主要攻击点、如果由法院审查、可直接用于庭审的致命点、这个论证想掩盖什么”六部分输出。`

如果涉及法条、司法解释、案例或时效问题，建议在提示词里明确要求“优先核对外部法条与案例依据”，这样更容易触发外部数据核验流程。

## 适合输入的材料

- 起诉状、答辩状、再答辩、代理词
- 证人证言、当事人陈述、证据摘要
- 合同争议分析、侵权分析、违约责任分析
- 法律论证、研究笔记、结论段落

## 风格

- 直接
- 对抗性强
- 只指出弱点，不做平衡评价
- 只写中国大陆法律语境下真正有用的攻击点
