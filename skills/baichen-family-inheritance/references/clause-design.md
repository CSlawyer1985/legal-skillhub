# 家事法域 — 关键条款设计要求

> 本文件承接 `SKILL.md` Phase 4.4，集中承载分类型关键条款的设计要求细节。援引《婚姻家庭编解释（二）》(法释〔2025〕1号，2025-02-01施行，共23条)。

## 财产归属条款

- 不动产须注明具体地址 + 产权证号
- 股权/股票须注明公司名称 + 持股比例 + 股票代码
- "婚后所得各自所有"须明确列举除外情形（如共同购置房产）

## 子女抚养条款

- 抚养费须明确金额 + 支付日期 + 递增机制 + 教育/医疗额外费用分担
- 探望权须具体频率 + 时间 + 方式 + 假期安排 + 接送安排
- **不得约定排除探望权**（法定权利，第1086条）或约定"放弃抚养费则放弃探望权"
- **抢夺、藏匿未成年子女**（解释二第12–14条）：离婚/抚养条款不得鼓励藏匿；应约定协助对方履行监护职责、违法者承担民事/可申请人身安全保护令或人格权侵害禁令

## 父母出资购房条款（离婚协议）

根据《婚姻家庭编解释（二）》第8条：
- 一方父母全额出资且无明确赠与约定 → 离婚时房屋可归出资方子女所有，但须综合婚姻存续时间、共同生活及孕育情况、离婚过错、对家庭贡献等因素酌定补偿
- 一方父母部分出资或双方父母出资 → 以出资来源及比例为基础，综合上述因素判决归属并合理补偿
- 有明确赠与约定的按约定处理

## 夫妻间赠与房产条款（离婚协议）

根据《婚姻家庭编解释（二）》第5条：婚前/婚内约定一方房屋转移登记至另一方或双方名下，离婚诉讼时尚未转移登记的，法院综合给予目的、婚姻存续时间、共同生活及孕育情况、过错、贡献、房屋市价等因素判决归属与补偿；给予方有欺诈/胁迫/严重侵害等情形的可撤销。

## 财产给予子女条款（离婚协议）

根据《婚姻家庭编解释（二）》第20条：
- 离婚协议约定将财产给予子女的，一方在财产权利转移前不得单方撤销（另一方同意除外）
- 子女可依约定直接主张权利（须在协议中明确约定，参照第522条第2款）
- 存在欺诈、胁迫等情形的可请求撤销

## 债权人保护条款（离婚协议）

根据《婚姻家庭编解释（二）》第3条：离婚协议中财产分割条款影响债权人债权实现的，债权人可请求撤销；法院综合共同财产整体分割及履行情况、子女抚养费负担、离婚过错等因素判断。

## 股权分割条款（离婚协议）

根据《婚姻家庭编解释（二）》第9–10条：
- 一方未经另一方同意转让登记在自己名下的夫妻共同财产出资股权，配偶主张无效不予支持，但恶意串通损害另一方权益除外（第9条）
- 夫妻均登记为股东、对股权归属约定不明的，不按股东名册/章程出资额确定分割比例，依第1087条处理（第10条）
- 起草提示：股权分割宜先厘清登记状态（一方/双方名下）再定条款，避免"无效转让"误判

## 离婚经济补偿与经济帮助条款

根据《婚姻家庭编解释（二）》第21条（补偿，第1088条）、第22条（经济帮助，第1090条）：负担较多义务方（抚育子女、照料老人、协助工作）可请求补偿；一方年老/残疾/重病生活困难的，可请求有负担能力方适当帮助。条款须明确数额确定因素（时间精力投入、给付方负担能力、当地人均可支配收入等）。

## 遗嘱形式要件

| 遗嘱形式 | 要件 |
|---------|------|
| 自书遗嘱 | 遗嘱人亲笔书写全文 + 签名 + 注明年月日 |
| 代书遗嘱 | 2 名以上见证人 + 其中 1 人代书 + 遗嘱人+代书人+见证人均签名 |
| 打印遗嘱 | 遗嘱人 + 见证人在每一页签名 + 注明年月日 |
| 录音录像遗嘱 | 记录姓名/肖像/年月日 + 2 名以上见证人 |
| 公证遗嘱 | 公证机构办理（《民法典》下效力不再优先于其他形式） |
