# 家事法域 — 合规检查清单
---

## 通用检查

| # | 检查项 | 状态 |
|---|--------|:--:|
| 1 | 各方是否具有完全民事行为能力？ | |
| 2 | 协议是否采用书面形式？ | |
| 3 | 各方是否已签字盖章？ | |
| 4 | 是否约定了协议的生效条件？ | |
| 5 | 是否涉及限制身份关系自由的条款？ | |

---

## 婚姻财产协议专项

| # | 检查项 | 状态 |
|---|--------|:--:|
| M1 | 财产清单是否具体（不动产含地址+产权证号）？ | |
| M2 | 债务承担是否明确？ | |
| M3 | 是否声明"仅约束夫妻双方，不得对抗善意第三人"？ | |
| M4 | 是否签字日期在结婚登记前/后（对应婚前/婚后协议）？ | |
| M5 | 涉及登记在未成年子女名下房屋的，是否提示处分限制（解释二第15条）？ | |

---

## 离婚协议专项

| # | 检查项 | 状态 |
|---|--------|:--:|
| D1 | 财产分割方案是否逐项列明？ | |
| D2 | 抚养费金额是否不低于当地最低标准？ | |
| D3 | 探望权是否明确具体（频率+时间+方式）？ | |
| D4 | 债务处理是否明确（对内约定+对外风险的提示）？ | |
| D5 | 是否约定"协议自离婚登记之日起生效"？ | |
| D6 | 给予子女财产是否明确不得单方撤销（解释二第20条）？ | |

---

## 遗嘱专项

| # | 检查项 | 状态 |
|---|--------|:--:|
| W1 | 遗嘱形式要件是否全部满足（对照第1134-1139条逐项核实）？ | |
| W2 | 立遗嘱人是否亲笔签名？ | |
| W3 | 年月日是否注明（精确到日）？ | |
| W4 | 代书/打印遗嘱是否有2名以上适格见证人签名？ | |
| W5 | 是否留有必留份？ | |
| W6 | 遗产是否逐项列明（地址/账号/凭证号）？ | |
| W7 | 是否声明此前遗嘱的处理（作废/冲突以本遗嘱为准）？ | |
| W8 | 是否指定遗产管理人（第1145条）及职责？ | |
