# 家事法域 — 设计原则（7 项）

> 本文件承接 `SKILL.md` Phase 4.3，集中承载家事法域特有的设计原则细节。主文件仅保留域路由与六阶法流程骨架，细节经此处承载。

家事法域与合同编下的合同自由原则完全不同，核心约束为 **身份关系不可约定变更、必留份不可剥夺、公序良俗红线**。条款设计须遵循以下 7 项原则：

| 原则 | 说明 |
|------|------|
| 身份关系不可约定变更 | 不得限制离婚自由、不得排除法定扶养义务、不得剥夺法定继承权 |
| 财产分割须公平 | 《婚姻家庭编解释（二）》下，综合婚姻存续时间、共同生活及孕育情况、离婚过错、对家庭贡献等因素判断（第5、8条）；夫妻一方转让登记在己方名下的共同财产出资股权，配偶主张无效不予支持但恶意串通除外（第9条），双方均登记为股东且约定不明不按出资额分割（第10条）；隐藏/转移/变卖/挥霍夫妻共同财产的一方，分割时可少分或不分（第1092条）；网络直播打赏明显超出家庭消费水平可认定为"挥霍"（解释二第6条） |
| 父母出资购房不搞一刀切 | 一方父母全额出资且无明确赠与约定→房屋可归出资方子女所有，但须综合婚姻存续时间、孕育情况、过错、贡献等因素酌定补偿（解释二第8条）；部分出资或双方出资→以出资来源及比例为基础综合考量（同条） |
| 遗嘱形式要件须严格合规 | 自书/代书/打印/录音录像/公证遗嘱各有法定要求，形式瑕疵 = 遗嘱无效（全国自书遗嘱无效率约 27%） |
| 必留份不可剥夺 | 须为缺乏劳动能力又无生活来源的继承人保留必要份额（第1141条） |
| 公序良俗红线 | "净身出户"承诺书、限制再婚自由的约定均可能无效；违反忠实义务将共同财产赠与第三人→无效，可请求返还（解释二第7条）；抢夺、藏匿未成年子女违反子女最佳利益（解释二第12–14条），可申请人保令/人格权禁令 |
| 遗产管理人制度 | 遗嘱执行人优先担任遗产管理人（第1145条）；职责包括清理遗产、处理债权债务、分割遗产（第1147条）；因故意或重大过失造成损害须承担民事责任（第1148条） |
