# CCPA/CPRA 与 GDPR——并排对比

对同时受两部法律约束的组织（如拥有欧盟客户的美国公司，或拥有加州客户的欧盟公司）而言，理解差异和重叠对于建立高效的双重合规计划至关重要。

---

## 范围与适用性

| 维度 | CCPA/CPRA | GDPR |
|---|---|---|
| **司法辖区触发** | 在加州开展业务 | 处理欧盟/欧洲经济区/英国居民的个人数据 |
| **涵盖对象** | 满足门槛标准的营利性企业 | 任何控制者或处理者，无论规模或所在地 |
| **规模/收入门槛** | 有——2500 万美元收入或 10 万以上消费者或 50% 以上收入来自 PI 出售/共享 | 无——适用于处理欧盟个人数据的任何组织 |
| **非营利组织** | 一般豁免 | 涵盖 |
| **政府实体** | 豁免 | 涵盖（公共机构有特定规则） |
| **B2B 数据** | 一般排除（CPRA 将有限豁免扩展至员工数据） | 涵盖 |

---

## 关键定义

| 概念 | CCPA/CPRA | GDPR |
|---|---|---|
| **个人数据/PI** | 广义定义；包括家庭数据 | 广义定义；仅限与已识别/可识别个人相关的数据 |
| **特殊/敏感类别** | CPRA SPI：社会保障号、精确地理位置、生物识别、健康、种族/民族、宗教、工会、性取向、基因、凭据、通信内容 | 特殊类别：种族/民族、政治观点、宗教、工会、基因、生物识别、健康、性生活、性取向 |
| **控制者对应** | "Business"（企业） | "Controller"（控制者） |
| **处理者对应** | "Service Provider"（服务提供者）+ "Contractor"（承包商）（CPRA） | "Processor"（处理者） |
| **第三方** | 接收 PI 但非服务提供者/承包商的实体 | 无同等方式的单独定义 |
| **出售数据** | 广义：金钱或其他有价值对价 | 无对应概念；向第三方披露 = 独立的处理活动 |
| **共享（跨情境行为广告）** | CPRA 特有概念 | 无直接对应；在合法利益或跟踪同意下涵盖 |

---

## 法律依据

| 方面 | CCPA/CPRA | GDPR |
|---|---|---|
| **处理依据** | 无法律依据要求——企业可未经同意收集 PI（对大多数目的） | 要求六种法律依据之一（同意、合同、法律义务、重大利益、公共任务、合法利益） |
| **敏感数据同意** | SPI 使用限制权（对大多数企业为选择退出模式） | 特殊类别数据须明确同意（有狭义例外） |
| **选择加入与选择退出** | 主要为选择退出模式（消费者必须主动请求选择退出） | 主要为选择加入模式（同意必须自由给予、具体、知情、明确无误） |
| **未成年人（16 岁以下）** | 出售/共享 13-16 岁消费者的 PI 须选择加入；13 岁以下须父母同意 | GDPR 同意年龄因成员国而异（13-16 岁）；基于同意的 16 岁以下处理须父母同意 |

---

## 消费者/数据主体权利

| 权利 | CCPA/CPRA | GDPR |
|---|---|---|
| **知情权** | 有——特定内容 + 类别（CPRA 前为 12 个月范围，2022 年 1 月后无限制） | 有——所有个人数据，无 12 个月限制 |
| **删除权** | 有——附众多例外 | 有（被遗忘权）——附例外 |
| **更正权** | 有（CPRA 新增） | 有（更正权） |
| **可携权** | 有——知情请求中的可移植格式 | 有——明确的结构化、常用、机器可读格式 |
| **出售选择退出权** | 有——"请勿出售或共享我的个人信息" | 无直接对应；可由撤回同意或反对合法利益涵盖 |
| **限制处理权** | 有限——SPI 限制权（CPRA） | 有——更广泛的处理限制权 |
| **反对权** | 有限——出售/共享选择退出 | 有——反对基于合法利益或直接营销的处理 |
| **自动化决策** | 待 CPPA 规则制定；可能为选择退出权 | 有（第 22 条）——不受具有重大影响的纯自动化决策约束的权利 |
| **不受歧视** | 有（第 1798.125 条） | 无直接对应 |
| **响应期限** | 45 天 + 45 天延长；SPI 限制：15 个工作日 | 1 个月 + 2 个月延长 |

---

## 隐私通知

| 要求 | CCPA/CPRA | GDPR |
|---|---|---|
| **收集时通知** | 有——类别、目的、PI 是否被出售/共享、隐私政策链接 | 有——第 13/14 条收集时隐私通知 |
| **隐私政策** | 有——全面；每年更新 | 有——隐私通知必须可访问 |
| **保留期限** | 有（CPRA 新增） | 有（必须指明或说明标准） |
| **法律依据披露** | 无——不适用 | 有——必须为每个处理目的指明法律依据 |
| **GPC 信号** | 必须作为有效选择退出予以尊重 | 无对应；但 ePrivacy 指令可能涵盖浏览器信号 |

---

## 供应商/第三方管理

| 方面 | CCPA/CPRA | GDPR |
|---|---|---|
| **处理者协议** | 须与服务提供者和承包商订立 | 须订立数据处理协议（第 28 条） |
| **合同要求** | 目的限制、禁止转售、删除、审计权 | 详细的第 28 条要求：仅按指示处理、安全、子处理者规则、返还/删除 |
| **子处理者** | 承包商/下游服务提供者也须合规 | 子处理者须有 DPA + 控制者通知/批准 |
| **国际转移** | 无转移限制机制（CCPA 不限制跨境转移） | 限于充分性国家或要求转移机制（SCC、BCR、充分性决定） |

---

## 执法与处罚

| 方面 | CCPA/CPRA | GDPR |
|---|---|---|
| **执法机构** | 加州隐私保护局（CPPA）+ 加州总检察长 | 各欧盟/欧洲经济区成员国的数据保护机构（DPA） |
| **民事罚款** | 每次无意违规 2,500 美元 / 每次故意违规 7,500 美元 | 全球年营业额最高 1000 万欧元或 2%（较低层级）/ 2000 万欧元或 4%（较高层级） |
| **私人诉权** | 有——但限于数据泄露：每消费者每事件 100-750 美元 | 有限；欧盟成员国各异；集体诉讼正在发展 |
| **刑事处罚** | CCPA 无直接刑事责任 | 一些成员国有刑事条款 |
| **补救期** | 30 天补救通知期（针对总检察长诉讼；CPPA 行政行动可能不同） | 无正式补救期 |

---

## 实务双重合规指导

对同时受两套框架约束的组织而言，GDPR 通常是要求更高的法律。GDPR 合规计划将涵盖大多数 CCPA/CPRA 义务，只需针对性补充：

**GDPR 已涵盖的内容：**
- 隐私通知（收集时和政策）
- 消费者/数据主体权利流程（知情、删除、更正、可携）
- 处理者协议
- 数据最小化和目的限制
- 保留时间表
- 安全措施

**需要补充的 CCPA/CPRA 特定内容：**
1. 添加**"请勿出售或共享我的个人信息"**链接和选择退出工作流
2. 尊重**全球隐私控制（GPC）**信号
3. 添加**"限制使用我的敏感个人信息"**链接和 15 天响应工作流
4. 审查供应商分类：所有"处理者"在 CCPA 下是否实际上都是**服务提供者**（合同可能需要更新）？
5. 实施**未成年人选择加入**同意以进行出售/共享（16 岁以下）
6. 如适用，添加**财务激励/忠诚度计划**披露
7. 每年确认企业门槛合规——收入和数据量门槛
8. 为**CPPA 关于自动化决策和网络安全审计的规则制定**做好准备
