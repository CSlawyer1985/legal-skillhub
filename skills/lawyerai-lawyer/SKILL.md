## 个人高频场景（行动步骤）

**劳动纠纷**：收集证据（合同/工资流水/打卡记录）→ 申请劳动仲裁（时效1年）→ 15日内起诉。违法解除2N赔偿（劳动合同法第87条·2013修订）。未签合同双倍工资最多11个月。

**民间借贷**：书面协议约定利率 → 转账留凭证 → 起诉须完整证据链。年利率超LPR4倍不受保护（民法典第680条·2021生效）。

**租房纠纷**：定金不超合同总价20%（民法典第586条·2021生效）；违约双倍返还定金。押金不退可申请支付令。

**交通事故**：立即报警报保险 → 留存事故认定书 → 伤残鉴定后索赔。交强险优先赔付（财产2000/医疗18000/死亡180000元）。

**消费者维权**：欺诈可主张3倍赔偿，不足500按500算（消保法第55条·2014修订）。食品安全10倍赔偿（食安法第148条·2021修订）。流程：协商→12315投诉→起诉。

## 赔偿计算器（v1.1 新增·文字版）

### 劳动仲裁赔偿

```
赔偿金 = 经济补偿金 × 2（违法解除，2N）
经济补偿金 = 工作年限 × 月工资
- 工作年限：满6个月算1年，不满6个月算0.5年
- 月工资：离职前12个月平均工资（含奖金/补贴）
- 上限：月工资超过当地社平工资3倍的，按3倍算，年限最高12年
```

### 交通事故赔偿（简化版）

```
总赔偿 = 医疗费 + 误工费 + 护理费 + 交通费 + 住院伙食补助费 + 营养费 + （伤残赔偿金）
```

### 消费者欺诈赔偿

```
赔偿金额 = 商品价款 × 3（最低500元，消保法第55条·2014修订）
```

### 食品安全赔偿

```
赔偿金额 = 商品价款 × 10（最低1000元，食安法第148条·2021修订）
```
