# 刑事法律援助全流程 Skill 使用指引

适用版本：2026.09.10.1

作者：李鸿鸿｜浙江光正大律师事务所

## 一、这个 Skill 帮你做什么

围绕刑事法律援助案件，将案件阶段、原始材料、办理记录与归档要求串联起来，辅助律师准备文书、核对缺件、整理归档材料。

默认使用温州地区法律援助模板。其他地区应先替换当地模板，不能只修改法援中心名称。

**它是办案辅助工具，不是自动办案或自动上传系统。** 生成文件均须律师复核，不代表会见、阅卷、开庭或结案已经发生。

## 二、按需求快速找到用法

| 你要做什么 | 可以直接这样说 | 可以得到什么 |
|---|---|---|
| 接到法援指派 | “检查这个案件需要准备哪些手续。” | 当前阶段的文书计划、缺失信息提示 |
| 准备会见 | “这是审查起诉阶段，帮我准备会见材料。” | 对应阶段的会见笔录底稿；真实答复需另行整理 |
| 准备阅卷 | “按法援模板准备阅卷笔录。” | 可修改的 Word 阅卷笔录；摘录内容须依据卷宗 |
| 没有流程台账 | “从这些材料里提取办理时间，先让我核对。” | 附来源位置、提取方式和核实状态的候选时间线 |
| 准备庭审 | “按审判阶段准备出庭提纲和庭审笔录底稿。” | 对应 Word 底稿，不预填实际庭审过程 |
| 准备结案材料 | “根据已核实记录，制作承办通报和结案报告。” | 可修改的 Word 材料及律师复核清单 |
| 整理归档 | “按这个系统目录整理，先列出材料对应关系。” | 归档核对方案；内置按确认页码提取 PDF，跨文件合并及格式转换需宿主具备相应工具 |
| 更换地区模板 | “我在其他地区办理，这是当地法援中心的模板。” | 模板适配与验证方案，不强制保留温州原句 |

以上是使用场景，不是必须依次执行的固定步骤。一次生成对应一个承办阶段。

## 三、第一次使用，准备这些信息

至少说明：

- 案件材料目录和允许保存成果的位置。
- 当前承办阶段：侦查、审查起诉或审判。
- 受援人姓名、涉嫌罪名、指派机构和经办机关。
- 承办律师、律师事务所、羁押状态。
- 本次希望完成的具体事项。

有台账、指派通知或已签署材料的，一并提供；没有台账也可以开始。

其他律师使用时，应先填写自己的承办身份。**作品作者署名与案件文书落款是两回事，不应把作者姓名直接当作承办律师。**

可以复制下面这段开始：

> 请使用刑事法律援助全流程 Skill。案件材料位于【路径】，本次承办阶段是【阶段】，指派机构是【名称】，受援人目前【在押／取保候审／其他】。请先检查材料并列出本次文书计划，缺少的信息向我核实，不要推测。原始材料只读，成果保存到【路径】。

## 四、没有台账，也能开始

Skill 可以从可读取的文书、PDF 和图片中寻找日期线索；扫描件需要本机具备中文 OCR 能力。

提取后，律师重点核对：

1. 这个日期属于什么事情？
2. 是文书制作、送达、实际收到，还是办理日期？
3. 原文在哪里，是否存在相反记载？

**文件名日期、OCR 结果和材料修改时间不能直接当作办案事实。** 没找到某项记录，也不能认定该程序没有发生。

## 五、归档建议按这个顺序做

**确认承办阶段 → 对照系统目录 → 核实材料和缺件 → 制作 Word 底稿 → 律师修改确认 → 转换、组合 PDF → 上传前检查。**

重点掌握三条：

**第一，阶段决定起点文书。**

审查起诉阶段以起诉意见书为起点；审判阶段以起诉书为起点。目录前后出现相关文书，可能承担不同程序功能，不机械合并。

**第二，一个系统项目对应一份 PDF。**

介绍信与对应会见笔录、阅卷笔录与对应卷宗是否组合，以当地栏目及本次要求为准，不把全案材料合成一个大文件。

**第三，没有程序就据实说明，缺少材料就继续核查。**

确认未开展调查取证、未召开庭前会议或未出庭时，按当地要求制作情况说明；不能为补齐目录而虚构笔录。

包内生成器主要输出 Word、Excel 和复核清单，**不直接完成整套卷宗 PDF 提取、合并或系统上传**。这些步骤需要具备相应能力的 Agent 在授权范围内另行处理。

## 六、拿到文件后，检查什么

上传或对外使用前，至少核对：

- 人名、机构、阶段、罪名和羁押状态是否正确。
- 日期、会见答复、承办记录和案件结果是否有真实依据。
- 未核实内容是否仍明确标注，没有变成确定事实。
- 签名、捺印、盖章是否按当地要求完成，未自动添加个人印章。
- 起诉意见书、起诉书和结果材料是否放在正确栏目。
- PDF 页序、清晰度及版本是否正确，没有混入旧稿或测试文件。

温州默认排版为：正文仿宋_GB2312 四号，主标题黑体三号，固定行距 28.5 磅。仍需检查本机字体和实际页面效果。

## 七、遇到问题怎么办

- **缺少字段：**补充或核实后继续，不用推测值凑齐。
- **罪名未收录：**由律师核验并补充本案法律依据；内置 23 项说明也不替代现行法源核验。
- **扫描件识别失败：**检查中文 OCR、清晰度和文件是否加密，保留原件。
- **当地模板报错：**按模板指南配置变量填充并试生成，不必恢复温州原句。
- **生成文件进入“未通过校验-勿用”：**先排查原因，不将其中材料提交或上传。
- **平台不能访问本地文件或运行 Python：**只能提供指导，不能声称已经完成扫描或生成。

真实案件资料与公开 Skill 包必须分开保存。本地脚本不主动上传材料，但使用云端 Agent 前，仍应核对数据处理设置与授权范围。
