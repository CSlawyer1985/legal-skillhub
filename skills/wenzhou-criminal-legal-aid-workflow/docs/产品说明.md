# 刑事法律援助全流程 Skill（温州模板版）说明

## 基本信息

- 名称：刑事法律援助全流程 Skill（温州模板版）
- 作者：李鸿鸿
- 工作单位：浙江光正大律师事务所
- 版本：2026.09.10.1
- 适用对象：办理中国大陆刑事法律援助案件的律师、实习律师及法律援助机构工作人员

## 产品定位

本 Skill 面向刑事法律援助案件，将接收指派、会见、阅卷、认罪认罚、庭前准备、庭审、结案归档和判后回访拆解为可执行工作流。使用者提供案件阶段及经核实的必要字段后，Skill 根据阶段和进度选择相应材料，并调用地区模板包生成工作文书。

默认附带经脱敏的温州地区模板包。其他地区可以在不改动核心办案逻辑的情况下，通过 `manifest.json` 导入当地现行模板。温州模板不是全国统一模板，异地使用前必须完成当地模板替换和人工复核。

## 主要能力

1. 将文书生成置于完整办案流程中，不以单一文书代替律师判断。
2. 将地区业务逻辑与模板资产分离，方便法律援助机构和律师团队替换当地母版。
3. 检查未羁押会见口径、法院与公诉机关区分、罪名依据核验等专业易错点。
4. 在公开发布前扫描 OOXML 文档中的真实受援人信息、身份证号、手机号、案号、元数据、图片、批注和修订痕迹。
5. 默认清空模板答复栏，禁止虚构案件事实、受援人陈述和裁判结果。
6. 按诉讼阶段识别归档起点文书：审查起诉阶段对应起诉意见书，审判阶段对应起诉书；分别核对程序行为日期、律师实际收件日期和行政结案日期。
7. 温州模板生成结果统一设置为正文仿宋_GB2312 四号、主标题黑体三号、固定行距 28.5 磅；其他地区可在模板包中替换本地排版参数。
8. 在没有流程台账时，只读扫描本地PDF、扫描件、DOCX及文本材料，输出附来源定位、置信度和“待律师核实”状态的候选时间线。
9. 通过环境自检、中文错误建议、无落盘预览和自动律师复核清单降低首次使用门槛。
10. 用一套核心业务规则适配多个Agent平台：平台层只处理安装、触发、权限和工具差异，不复制或改写阶段判断、日期状态与隐私门。
11. 首批内置23个常见法援罪名的基础法条说明，覆盖侵犯财产、人身权利、公共安全和社会管理秩序；律师可以持续扩充独立JSON罪名库，无须修改文书生成代码。

## 常见罪名库

内置说明用于生成会见笔录中的基础法律告知。它不固化地区数额标准，不替代司法解释检索、证据判断和个案量刑分析。案件JSON中的 `charge_legal_basis` 始终优先；罪名未收录且律师未补充依据时，生成器停止运行并给出中文提示。具体范围和维护方法见 `references/charge-library-guide.md`。

## 平台推荐

- Codex Desktop / CLI：完整验证环境，适合真实案件本地处理。
- WorkBuddy：推荐作为普通律师调用和演示入口，但应确认其具备本地文件及Python执行能力。
- Claude Code、Gemini CLI：遵循通用 `SKILL.md` 结构，可迁移使用，首次真实案件前须完成本地测试。
- OpenCode：可兼容运行，安装目录名应与 Skill name 一致，并配置必要的文件、shell和外部目录权限。
- 纯网页聊天平台：只建议使用脱敏样例进行演示，不建议直接处理真实受援人材料。
- SkillHub：作为发布和版本分发平台，不视为案件运行环境。

具体安装方式和能力降级规则见 `references/platform-compatibility.md`。

## 隐私与安全

公开发布包仅保留作者姓名“李鸿鸿”和工作单位“浙江光正大律师事务所”。包内不含真实受援人信息、个人私章、签名、律师证号或个人手机号。律师使用本 Skill 处理真实案件时，应将案件输入和生成结果保存在发布包之外，不得将真实案件数据回写或重新分发。

## 模板替换

会见笔录、阅卷笔录、庭审笔录等默认材料依据温州地区法律援助中心提供或要求的格式整理。其他地区使用者应在 `assets/template-packs/<pack-id>/` 中建立当地模板包，通过 `manifest.json` 绑定标准文书键和实际文件名，并运行模板校验脚本。具体方法见 `references/template-pack-guide.md`。

## 使用边界

本 Skill 仅辅助承办律师整理和生成工作材料，不替代律师核实事实、证据、法律、期限及当地法律援助中心要求。所有生成结果均须由承办律师逐项审阅后使用。
