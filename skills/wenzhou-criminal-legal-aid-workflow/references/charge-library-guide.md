# 常见罪名基础说明库

## 定位

`charge-law-library.json` 为会见笔录提供常见罪名的基础法条说明。它解决“每次都从零填写法条”的问题，但不是自动法律意见库，也不替代承办律师核对现行刑法、司法解释、地区数额标准和个案证据。

## 第一批范围

- 侵犯财产：盗窃、诈骗、抢劫、抢夺、敲诈勒索、职务侵占、故意毁坏财物。
- 侵犯公民人身权利：故意杀人、过失致人死亡、故意伤害、非法拘禁。
- 危害公共安全：交通肇事、危险驾驶、以危险方法危害公共安全。
- 妨害社会管理秩序及常见关联犯罪：聚众斗殴、寻衅滋事、妨害公务、袭警、赌博、开设赌场、掩饰隐瞒犯罪所得、帮助信息网络犯罪活动、走私贩卖运输制造毒品。

## 使用规则

1. 案件JSON中的 `charge` 与库内正式罪名完全一致时，生成器可调用基础说明。
2. `charge_legal_basis` 有内容时，始终以律师本案核验后填写的内容优先，不被内置库覆盖。
3. 库中没有的罪名，生成器继续阻止正式生成，并要求律师补充 `charge_legal_basis`。
4. 内置说明避免固化地区数额标准、证据结论和个案量刑建议；这些内容必须当次核对。
5. 涉及行为发生后修法、跨修法时间、罪名竞合或司法解释变化时，不得只使用库内摘要。

## 扩充和维护

新增罪名前应：

1. 使用国家法律法规数据库、全国人大、最高人民法院或最高人民检察院的现行官方文本核对罪名和条文。
2. 只写适合会见告知的基础说明；把数额标准、竞合、特别主体等易变事项放入 `review_notes`。
3. 更新库的 `reviewed_on`，运行 `scripts/validate_charge_library.py` 和完整测试。
4. 现行法发生变化时，先标记待复核，再更新摘要；不得继续输出已知过时内容。
