# AI 合规使用门

本文件是使用者和承办律师的合规提示，不是对任何模型、云服务或 SkillHub 的安全认证。技术脚本本地运行，不代表宿主 Agent、模型、插件、日志、备份或外部 API 全程离线。

## 1. 公开发布包与真实案件分离

- 公开包不得包含真实受援人、近亲属、被害人、证人、案号、案情时间线、真实会见答复、辩护策略、裁判结果、签名、私章、律师证号或私人联系方式。
- 作者署名“李鸿鸿、浙江光正大律师事务所”是作品归属信息，不是任何使用者案件的承办身份或作者审核证明。
- 本 Skill 不代表浙江光正大律师事务所、温州市法律援助中心、司法行政机关或办案机关的官方系统、正式意见或统一模板。

## 2. 真实案件使用前的四项门槛

只有同时满足以下条件，才考虑让 AI 读取案件材料：

1. 承办律师已判断材料不是国家秘密，且不违反办案机关对案卷复制、保管和使用的具体要求；
2. 已明确处理目的、最小必要范围、操作者、律所授权和输出用途；
3. 已核验服务商主体、服务器和备份地域、训练政策、长期记忆、日志、分包商、转委托、删除机制、管理员访问和跨境传输；
4. 已采取与风险相适应的权限、加密、隔离、审计和删除措施。

密级未知、数据流向未知、训练政策未知、删除机制未知或存在未获批准的境外传输时，高风险材料停止上传，改用本地处理或先取得专业确认。

## 3. AI 与本地脚本的边界

- 本地 OCR、时间线提取和确定性生成脚本不主动上传案件材料；但 Agent 为理解材料而将其放入云端模型上下文的，仍属于外部处理。
- 默认采用“本地材料、本地脚本、本地输出、模型不接触原文”的安全模式。
- 不能执行本地脚本或不能限制网络、外部目录、插件和外发权限的平台，只能提供脱敏演示或操作指导，不得声称已扫描、核验或生成真实案件材料。
- 禁止 Agent 自动向外部邮箱、网盘、消息系统、办案机关、当事人或证人发送、上传或写入案件信息；任何外部动作须由承办律师逐次确认。

## 4. 输入最小化与脱敏

优先使用抽象争点、匿名角色和结构化字段，不上传完整卷宗、原始音视频、完整讯问笔录、证人信息、未成年人信息、健康、行踪、金融信息或核心辩护策略。仅删除姓名而保留金额、日期、地点、亲属关系和独特事实组合，不足以证明已经匿名化。

## 5. 留痕、删除和事件处置

使用者应记录案件、材料类别、处理目的、工具、上传范围、授权人、操作者、删除时间和输出用途。任务结束后删除云端文件、对话、附件、向量索引、缓存、共享链接和不必要日志，并保存可核验记录。发现误传、异常访问或可能泄露时，立即停止处理、保全日志、通知律所负责人和承办律师，并依法判断补救、报告和通知义务。

## 6. 输出责任

AI 输出只能作为工作底稿。承办律师必须回到原始材料核对事实、页码、证据属性、法条、程序阶段、期限、引用和格式；不得把作者署名、模型输出或自动复核结果理解为律师个案审核。
