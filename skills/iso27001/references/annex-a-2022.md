| ID | 控制名称 | 描述 |

| A.5.24 | 信息安全事件管理规划与准备 | 规划和准备信息安全事件管理 |

| A.5.34 | 隐私和个人信息（PII）保护 | 按适用法规保护隐私和个人信息 |
| A.5.35 | 信息安全的独立审查 | 独立审查信息安全实施和控制 |
| A.5.36 | 政策、规则和标准合规 | 确保符合信息安全政策和标准 |
| A.5.37 | 记录在案的操作程序 | 记录并维护信息安全操作程序 |
