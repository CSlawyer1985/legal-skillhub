# 企业 AI 合规审查垂直执行方法

## 专用步骤

1. 建立当前资源、版本、区域、身份、网络、数据、成本和合规基线。
2. 对合规风险矩阵、整改动作与审计证据清单同时设计正常路径、失败路径、监控信号、容量上限和回滚条件。
3. 变更前执行静态检查或 dry-run，优先最小权限、可重复配置和分阶段发布。
4. 变更后用健康检查、日志、指标和业务请求验证；未实际部署或无监控证据时不得声称上线成功。

## 专项验收

- 主交付物确实是“合规风险矩阵、整改动作与审计证据清单”，不是泛化建议或改写后的输入。
- 输出语言、字段和操作顺序适合企业法务、合规、IT 和 AI 团队。
- 每个阻断项写明解除条件；每个完成项都能指出证据。
- 本 Skill 的来源方向仅用于需求映射，不把来源产品或平台能力冒充为当前环境已连接。
