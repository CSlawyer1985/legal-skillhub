# 示例任务与调用前后对比

## 示例输入

- 资料：AI 方案、数据流和行业约束
- 目标：在本周内得到一份可直接评审、可追踪的结果
- 受众：企业法务、合规、IT 和 AI 团队

## 调用前

> 帮我处理一下这些资料，给点建议。

问题：没有说明对象、输出结构、事实边界和验收标准，容易得到泛化答案。

## 调用后

> 使用 $guoyiyi-v019-azure-compliance。输入是AI 方案、数据流和行业约束；请为企业法务、合规、IT 和 AI 团队产出合规风险矩阵、整改动作与审计证据清单。列明事实来源、关键假设、阻断项和逐项验收状态，不要补写未提供的数据。

## 预期输出片段

1. 结论摘要：最重要的判断与依据
2. 主交付物：合规风险矩阵、整改动作与审计证据清单
3. 风险：缺失输入、冲突信息和合规边界
4. 下一步：负责人建议、截止条件和验证信号

## 验收点

- 输入、产出、受众均明确
- 关键结论可追溯
- 不虚构事实或业绩
- 主交付物可直接进入评审或执行
- 完成、降级、未验证三种状态清楚
