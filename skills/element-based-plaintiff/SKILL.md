# 要素式起诉状生成技能

## 工作流程

### Phase 1：案由识别

读取用户提交的传统起诉状，从中识别案由。识别策略：

1. **标题识别**：起诉状标题中的案由关键词（如"买卖合同纠纷""民间借贷纠纷"）
2. **案由段落识别**：事实与理由部分的首句或"案由"段落
3. **法律依据识别**：引用的法条指向的案由类型（如引用《民法典》合同编→合同纠纷）
4. **事实要素识别**：根据案件事实中的核心要素（如借款+利息→民间借贷；工程款+工期→建设工程）

17种案由的关键识别词：

| 买卖合同纠纷 | 买卖合同、供货、货款、货物、交付 |

### Phase 2：要素提取

根据识别的案由，从传统起诉状中提取对应要素字段的内容。

**提取规则：**
- **当事人信息**：从起诉状首部提取所有原告、被告、第三人、委托诉讼代理人的信息，按"公共部分模板"格式组织
- **当事人类型判定**：根据是否有"法定代表人""统一社会信用代码"等字段，判定为法人/非法人组织；否则为自然人
- **多当事人处理**：如存在多个原告/被告/第三人，分别提取，逐行填入。同一方当事人可以同时存在法人和自然人（如被告1为公司、被告2为个人），各自按对应类型填写
- **委托诉讼代理人（可选，首次录入）**：按下方「配置持久化」章节处理——首次使用时询问并保存，后续自动填入；本案确实无代理则填"无"
- **诉讼请求**：从"诉讼请求"段落提取各项请求及金额
- **事实与理由**：从"事实与理由"段落提取案件事实，按该案由的要素字段分类填入
- **证据清单**：从"证据"段落提取证据列表
- **管辖约定**：从合同中提取管辖约定条款
- **调解意愿**：可从事实描述中合理推断，也可直接询问用户

**若输入缺少某要素字段的内容，填入"无"或留空，不得自行编造事实。**

### Phase 3：生成要素式起诉状

按识别到的案由选择对应的要素式模板格式，将Phase 2提取的内容填入对应字段位置，输出完整的要素式民事起诉状。

### 输出格式要求（严格对标最高院官方样式）

1. **分块表格结构**：整个文书由 **3-6 个分块双列表格**组成（非单一大表），分块按逻辑衔接：①说明栏+当事人信息 ②诉讼请求 ③约定管辖+事实与理由+证据清单+纠纷解决意愿。每个分块表格之间**无缝衔接，不留空行**。
2. **双列布局**：每个表格固定 **2 列**——左列（窄，约 4-5cm）为要素标签，右列（宽，约 9-10cm）为填写内容。模块标题行（如"当事人信息""诉讼请求"）**合并两列**并加边框。
3. **勾选式要素字段**：所有"是否"类字段采用官方勾选结构 `是□ 否□`、`了解□ 不了解□`、`有□ 无□`，子选项用 `□` 并列（如 `一般保证□ 连带责任保证□`）。勾选项与文字之间保留空格。
4. **填写提示语**：关键金额/日期字段保留官方行内提示，如 `元（人民币，下同；如外币需特别注明）`、`（合同条款：第  条）`、`截至  年  月  日止`。
5. **字体规范**（参照官方/博以新模板，**关键：所有字体名必须使用 WPS/Word 通用的"仿宋"/"宋体"**——避免"仿宋_GB2312"等带后缀的名字，否则 WPS/腾讯文档预览可能回退到默认字体影响视觉）：
   - **文书标题（两行，居中，加粗）**：第1行"民事起诉状"，**28pt**（比案由行大 9.5pt，视觉上明显大于案由行）；第2行"（[案由]）"，18.5pt（小二）
   - 模块标题行（当事人信息/诉讼请求/事实与理由/约定管辖/纠纷解决方式意愿等）：仿宋（或宋体），11pt（五号），居中，**加粗**
   - 说明栏：仿宋（或宋体），小五~五号，**不加粗**
   - 表格正文：仿宋_GB2312（或宋体），11pt（五号），**不加粗**
6. **表格边框**：全部单元格带标准单线边框（Table Grid），模块标题行**加粗**（与官方样式一致）；**分段标题行（模块标题行）显式加高至 1.0cm**（约为默认单行高度的两倍，便于阅读与填写）。
7. **勾选框（□）统一规范**：所有 `□` 勾选字符统一字体为 **MS Gothic**（保证方框大小一致），字号与所在行正文一致，不设加粗；勾选字符与后续文字之间保留半角空格。示例：`男□ 女□`、`是□ 否□`、`了解□ 不了解□`。
9. **勾选规则（输出实例时自动勾选）**：
   - **任何当事人为法人/非法人组织时（含原告、被告、第三人）**：该当事人信息中"类型"默认勾选 **有限责任公司**（`有限责任公司☑`，替换该选项后的第一个 `□`），"所有制性质"默认勾选 **民营**（`民营☑`）。若公司类型确为股份公司等则相应勾选。
   - **内容行有填写信息且该行模板含"是/否"（或"有/无"、"了解/不了解"）选项时**：若填写内容为肯定性信息（有金额、有日期、有具体情况等），将该行**"是"（或"有"、"了解"）选项后的 `□` 替换为 `☑`**；若填写内容为否定性信息（"无""不主张""不涉及"等），则将**"否"（或"无"、"不了解"）选项后的 `□` 替换为 `☑`**。
   - **金额选项勾选**：内容行含金额选项（如"利息□ 违约金□ 赔偿金□"等），若某选项后有**实际金额或内容**（非空白），将该选项后的 `□` 替换为 `☑`。示例：`利息□ 1153.71元 违约金□ 元 赔偿金□ 元` 中"利息"后有金额 → `利息☑ 1153.71元 违约金□ 元 赔偿金□ 元`。
   - **无填写信息的行**：保持全部 `□` 不勾选。
   - **示例**：`9. 是否存在迟延履行` 行填有"迟延时间：2025年8月28日起"→ `是☑ 迟延时间：… 否□`；`11. 有无质量争议` 行填"无"→ `有□ 具体情况：… 无☑`；诉讼请求"是否主张诉讼费用"填了"请求判令承担"→ `是☑ 否□`。
10. **可复制行**：当事人信息中，原告/被告/第三人的每一行为一个独立表格行。如需增加当事人，直接在当前表格中**复制一行并修改内容**，即可扩展为多当事人。
11. **输出文件**：写入 `{工作区}/outputs/` 目录（工作区指当前对话的工作目录），格式为标准 **DOCX**（ZIP 结构，勿用 WPS 旧版 .doc 格式——官方模板的 .doc 格式兼容性差，标准 docx 更通用）。
