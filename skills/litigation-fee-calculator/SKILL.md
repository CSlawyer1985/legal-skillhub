# 诉讼费用计算 Skill

## 定位

本 skill 用于计算中国法院案件受理费与各类申请费，属于**计算类 skill**。

命中本 skill 后，必须以 `npx @delilegal/deli-cli@latest` 为默认入口发现和调用当前可用的计算命令；不得调用法规检索或案例检索命令。稳定规则、条款口径和费用区间以本 skill 的 `references/` 为准，用户事实必须来自用户或其材料。

---

## 数据源与前置要求

1. **deli-cli 前置检查**：先执行 [deli-cli 通用前置](./references/cli-common.md)，获取当前 `RUN id`、命令名、参数形态和描述。
2. **CLI 场景指南**：按 [诉讼费用 CLI 场景指南](./references/cli-litigation-fee-guide.md) 将用户事实组织为后端计算任务。
3. **稳定规则**：费用区间、分段比例、上限和默认下限口径来自 [诉讼费用交纳办法费用规则](./references/litigation-fee-rules.md)。
4. **后端计算定位**：计算逻辑由 CLI 调用后端 MCP 计算服务完成；skill 目录不包含本地计算入口。
5. **禁止事项**：不得读取、创建或提示用户配置 skill 目录内旧 `config.json`；不得编造 CLI 未返回或 references 未载明的计算结果、条款、法院口径或地方标准。

## 工作流程

### 1. 抽取用户事实

先判断费用类型，再抽取必要事实；缺关键事实时只追问缺失项。

| 费用类型 | 必要事实 |
| --- | --- |
| 财产案件受理费 | 诉讼请求金额或争议金额 |
| 离婚案件受理费 | 是否涉及财产分割、财产总额；如用户有当地基础费标准，一并记录 |
| 侵害人格权案件受理费 | 损害赔偿请求金额；如用户有当地基础费标准，一并记录 |
| 其他非财产案件 | 是否适用其他非财产案件范围；如有当地标准，一并记录 |
| 知识产权民事案件 | 是否有争议金额；有争议金额时记录金额 |
| 劳动争议案件 | 是否为劳动争议案件 |
| 行政案件 | 区分商标、专利、海事行政案件与其他行政案件 |
| 管辖权异议 | 是否属于异议不成立后的收费；如有当地标准，一并记录 |
| 申请执行 | 是否有执行金额或价额；有则记录金额 |
| 财产保全 | 保全财产数额；不涉及财产数额时记录为无金额 |
| 支付令 | 申请金额 |
| 公示催告 | 是否为公示催告申请 |
| 撤销仲裁裁决或认定仲裁协议效力 | 申请类型 |
| 破产申请 | 破产财产总额 |
| 海事申请 | 具体海事申请类型 |

金额事实必须保留用户原始口径，例如“诉请本金”“财产分割总额”“执行标的”“保全金额”；不要自行把多个金额合并。

### 2. 调用计算能力

完成事实抽取后，按 `cli-common.md` 发现当前 skill scope 的可用命令，再按 `cli-litigation-fee-guide.md` 组织参数。

计算类流程固定为：

```text
用户事实
  -> Agent 抽取/追问
  -> npx @delilegal/deli-cli@latest 发现命令
  -> 本地 references 获取稳定规则和参数口径
  -> 后端计算命令返回分段、上限、区间取值和风险
  -> Agent 输出计算书
```

如 CLI 暂不可用或当前 skill scope 未返回可用计算命令，不得自行补算或寻找本地执行入口；应说明计算服务不可用或参数不足，并基于 `references/` 提示用户需要补充的事实或待后端计算确认的字段。

### 3. 生成最终输出

根据用户问题深度，输出可以简洁或完整，但必须包含以下核心项：

| 模块 | 要求 |
| --- | --- |
| 计算对象 | 明确费用类型和用户事实口径 |
| 计算明细 | 分段累计、固定费、区间默认取值、上限封顶或折算比例 |
| 合计金额 | 金额保留到分；区间费用需说明采用的取值 |
| 依据来源 | 引用 `references/litigation-fee-rules.md` 中对应条款编号；优先使用 CLI 返回的依据字段 |
| 风险提示 | 地方标准、法定幅度、减免缓缴、事实口径不明等影响 |

财产案件、知识产权有争议金额、申请执行、支付令、破产申请、财产保全必须展示关键分段或封顶计算。区间收费项目应明确是用户提供标准、CLI 返回标准，还是默认按区间下限测算。

---

## 质量控制

- 计算类 skill 不调用法规检索或案例检索命令。
- 用户未提供金额、案件类型或必要二级分类时，先追问，不得臆测。
- CLI 返回结果与本地 references 口径不一致时，标注差异并建议人工复核，不得静默改写。
- 区间收费项目不得表达为全国统一固定金额；默认下限只能作为测算口径。
- 减、免、缓缴情形不纳入自动计算，除非用户明确提供法院决定或具体适用事实。
- 最终输出中的法律依据不得超出 CLI 返回结果和本地 references 的稳定条款范围。
