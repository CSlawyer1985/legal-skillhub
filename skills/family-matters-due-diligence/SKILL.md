# 家事尽调

## 概述

本 Skill 面向执业律师在婚姻家事案件接案初期的真实痛点：客户口述零散、事实要素不全、律师需反复追问才能判断案件方向与风险。通过结构化追问 -> 要素抽取 -> 风险研判 -> 方案与文书清单生成的闭环工作流，将律师 1-2 小时的初次会谈尽调压缩到 10 分钟内，输出可直接用于客户沟通的《案件初步研判报告》。

创新点：面向女性当事人的权益保护视角，在通用家事尽调之外，专门内置同居析产、家务补偿、婚内财产保护、未成年子女权益等女性高频但易被忽略的检查项。

## 触发条件

当用户出现以下意图时激活本 Skill：
- 描述婚姻家庭纠纷、离婚咨询、财产分割、抚养权争议
- 提及家暴、出轨、分居、婚外情等家事法律问题
- 要求对婚姻家事案件进行尽调、分析、研判
- 询问离婚协议、起诉状、财产分割方案

## 工作流总览

```
[开始]
  |
  v

  |
  v
Step 3: 要素完整性判断（条件分支）
  |- 关键要素缺失 --> Step 4: 追问节点（生成针对性追问 -> 回到 Step 1，循环补全）
  |- 要素齐备 -----> Step 5: 风险研判
                       |
                       v
                   Step 6: 争议焦点 & 法条匹配
                       |
                       v
                   Step 7: 女性权益专项检查（条件分支）
                       |- 涉及女性当事人 -> 加载家务补偿/析产/损害赔偿检查项
                       |- 其他 -----------> 跳过
                       |

```

## 详细工作步骤

### Step 1: 案情录入

接收用户提供的案情描述（客户口述、咨询文本、或律师整理的案情摘要）。若用户未提供案情，以温和专业的语气引导：

> "请描述您遇到的婚姻家庭情况，包括婚姻状况、财产情况、子女情况、对方是否存在过错行为，以及您的核心诉求。您可以尽量详细地描述，我会帮您梳理。"

将用户输入的完整文本保存为案情原文，供后续步骤使用。

### Step 2: 要素抽取

从案情描述中抽取以下五维要素。详细要素模型见 `references/element-model.md`。

以 JSON 格式输出，缺失项填 null：

```json
{
  "婚姻状况": {
    "结婚时间": null,
    "是否登记": null,
    "分居情况": null,
    "此前婚史": null
  },
  "财产": {
    "婚前财产": null,
    "婚后共同财产": null,
    "房产": null,
    "债务": null,
    "是否存在转移隐匿": null
  },
  "子女": {
    "子女数量年龄": null,
    "现随谁生活": null,
    "抚养意愿": null
  },
  "过错与情感": {
    "是否存在出轨/家暴/赌博": null,
    "婚姻是否破裂": null
  },
  "诉求": {
    "是否要求离婚": null,
    "财产诉求": null,
    "抚养诉求": null,
    "补偿诉求": null
  },
  "当事人性别": null,
  "对方性别": null
}
```

抽取规则：
- 仅从用户提供的文本中提取信息，不做推测
- 若文本中明确提到某要素，填入对应值
- 若文本中未提及某要素，填 null
- 若文本中信息模糊（如"结婚好多年了"），填入原始描述并标注为"模糊"

### Step 3: 要素完整性判断（条件分支）

判断以下关键要素是否齐备：

```
关键要素 = [
  婚姻状况.是否登记,
  诉求.是否要求离婚,
  子女.子女数量年龄,
  财产.婚后共同财产
]
```

分支逻辑：
- 若关键要素中存在 null -> 进入 Step 4（追问节点）
- 若关键要素全部齐备 -> 进入 Step 5（风险研判）

### Step 4: 追问节点

识别仍缺失的关键要素，生成 2-3 个有针对性的追问问题。

追问语气要求：
- 温和、专业、便于当事人理解
- 一次只问 2-3 个问题，避免给当事人压迫感
- 问题应具体、可回答，避免开放式模糊提问

追问示例：
> "为了更准确地评估您的案件，还需要了解以下几点：
> 1. 您和对方是否已经办理了结婚登记？
> 2. 你们目前是否有子女？如果有，孩子多大？
> 3. 婚后是否有共同购置的房产或其他大额财产？"

追问循环上限：连续追问 3 轮仍要素不全 -> 以现有要素出具"信息不全版"研判并标注待补充项，不再继续追问。

收到用户补充回答后，将新信息合并到要素 JSON 中，重新回到 Step 3 判断。

### Step 5: 风险研判

基于已齐备的案件要素，结合法律依据（见 `references/legal-basis.md`），进行风险研判。

研判内容：
1. 案件性质判断（是否构成离婚法定情形、财产性质认定等）
2. 主要风险点识别
3. 举证难易程度评估

### Step 6: 争议焦点 & 法条匹配

定位案件的核心争议焦点，并匹配适用法律条文。法律依据详见 `references/legal-basis.md`。

输出内容：
1. **争议焦点**：以列点形式列出本案的核心争议（如"夫妻共同财产分割比例""抚养权归属""是否存在法定过错"等）
2. **适用法律依据**：列出具体法条编号 + 条文简要说明，包括：
   - 《中华人民共和国民法典》婚姻家庭编相关条文
   - 《妇女权益保障法》相关条文
   - 最高人民法院相关司法解释

### Step 7: 女性权益专项检查（条件分支）

判断条件：当事人性别为女性，或对方当事人为女性。

若涉及女性当事人，加载女性权益专项检查清单（详见 `references/women-rights-checklist.md`），逐项检查：

- **家务劳动补偿**（民法典第1088条）：当事人是否为家务付出较多方（如全职太太），是否可主张经济补偿
- **离婚损害赔偿**（民法典第1091条）：对方是否存在重婚、与他人同居、家暴、虐待遗弃等法定过错
- **同居析产**：是否存在未婚同居期间的共同财产需要分割
- **婚内财产保护**：是否存在对方转移、隐匿共同财产的行为，是否需要申请财产保全
- **经济帮助**：离婚后是否生活困难，是否可主张经济帮助
- **未成年子女权益**：子女抚养权、抚养费、探望权的安排是否有利于未成年人成长
- **家庭暴力救济**：是否存在家暴行为，是否需要申请人身安全保护令

若不涉及女性当事人，跳过此步骤，但仍进行通用的权益检查。

### Step 8: 方案与证据清单生成

综合前面的研判结果，生成以下内容：

**1. 路径建议**
- 协议离婚的可行性与利弊分析
- 诉讼离婚的必要性与利弊分析
- 推荐路径及理由

**2. 所需证据清单**

按类别列出需要收集的证据：

| 证据类别 | 具体证据项 | 证明目的 | 举证难度 |
|---------|----------|---------|---------|
| 婚姻关系 | 结婚证、婚姻登记记录 | 证明婚姻关系 | 低 |
| 财产 | 房产证、银行流水、车辆登记 | 证明财产权属 | 中 |
| 过错 | 出轨证据、家暴报警记录、伤情鉴定 | 证明法定过错 | 高 |
| 子女 | 出生证明、学校记录、生活照片 | 证明抚养条件 | 低 |
| ... | ... | ... | ... |

**3. 可主张权益汇总**
- 列出当事人可主张的全部权益
- 每项权益标注法律依据和主张条件
- 特别标注女性权益专项检查中发现的可主张项

**4. 文书要点**
- 若协议离婚：离婚协议书核心条款要点
- 若诉讼离婚：起诉状核心诉求与事实理由要点

### Step 9: 《初步研判报告》汇总输出

将以上所有步骤的结果整合为结构化的《案件初步研判报告》。报告模板见 `references/report-template.md`。

报告结构：
1. **案件基本信息**（当事人情况、案由）
2. **案情摘要**（事实要素汇总表）
3. **争议焦点**
4. **法律依据与适用分析**
5. **可主张权益**（含女性权益专项检查结果）
6. **证据清单**
7. **路径建议**（协议/诉讼利弊对比）
8. **风险提示**
9. **文书要点**
10. **合规提示**

合规提示固定文本：
> 本报告基于当事人口述信息生成的初步研判，仅供参考，不构成正式法律意见。建议当事人补充提供相关证据材料后，由执业律师出具正式法律意见书。本报告中的法条引用以报告生成时现行有效法律为准。

## 异常处理

### 输入为空或与家事法律无关
- 若用户输入为空或完全不涉及婚姻家庭法律问题 -> 提示"请描述您的婚姻家庭情况，包括婚姻状况、财产、子女、对方是否存在过错等信息"，不进入研判流程
- 若用户提问超出家事法律范围（如刑事、商事）-> 礼貌引导："本工具专注于婚姻家事法律领域的尽调与分析。如需其他领域的法律帮助，建议咨询对应领域的专业律师。"

### 追问循环上限
- 连续追问 3 轮仍有关键要素缺失 -> 以现有要素出具"信息不全版"研判报告，在报告中醒目标注"以下要素待补充"，并说明这些缺失要素可能对研判结论的影响

### 超长文本
- 若用户输入文本超过 5000 字 -> 提取与五维要素相关的关键段落进行研判，并在报告中注明"原始描述较长，已提取关键信息进行分析"

### 越界提问
- 若用户在尽调过程中提出非家事法律问题 -> 礼貌引导回主题："为了完成尽调分析，我们还是先聚焦您的婚姻家事情况。其他问题我们可以在尽调完成后另行讨论。"
