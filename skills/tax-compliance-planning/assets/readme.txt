# Assets Directory

This directory contains templates and files that can be used as outputs or starting points for tax compliance and planning tasks.

## Available Templates

### 1. 税务风险登记表
   - 用于记录和管理税务风险
   - 包含风险描述、评级、控制措施等
   - 建议格式: Excel (.xlsx)

### 2. 合规检查清单
   - 用于日常税务合规检查
   - 包含各税种检查要点
   - 建议格式: Excel (.xlsx)

### 3. 政策摘要模板
   - 用于整理和总结税收政策
   - 包含政策要点、适用条件等
   - 建议格式: Word (.docx) 或 Markdown (.md)

这些模板文件可以:
1. 直接复制使用
2. 根据具体需求定制
3. 作为培训材料
4. 建立标准化流程

注意: 具体模板文件由用户根据实际业务创建,此处仅提供目录结构和使用说明。
