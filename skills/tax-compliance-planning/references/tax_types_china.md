# 中国主要税种概览

## 一、企业涉及的主要税种

### 1. 增值税 (VAT)

**法律依据:** 《中华人民共和国增值税法》(2024年第41号主席令),2026年1月1日起施行

#### 纳税人类型

**一般纳税人:**
- 登记条件: 年应税销售额超过500万元必须登记;未超标的可自愿选择
- 优势: 可抵扣进项税额,适用低税率业务时税负更低
- 适合: 资本密集型行业(制造、贸易),进项抵扣项多

**小规模纳税人:**
- 登记条件: 年应税销售额未超过500万元
- 适用简易计税方法,征收率3%
- 优势: 税负计算简单,管理成本低
- 适合: 劳动密集型行业(咨询、设计),进项抵扣项少

**税负平衡点计算:**
- 增值率 = (销售收入 - 可抵扣成本) / 销售收入
- 当一般纳税人适用13%税率时,平衡点约为64.71%
- 当一般纳税人适用9%税率时,平衡点约为70.59%
- 当一般纳税人适用6%税率时,平衡点约为82.35%
- 若增值率高于平衡点,选择小规模纳税人更优
- 若增值率低于平衡点,选择一般纳税人更优

**纳税人身份选择考量因素:**
- 增值率水平
- 进项税额抵扣项目的多少
- 客户类型(是否要求专票)
- 业务规模和发展规划
- 政策变化风险

#### 税率与征收率

**一般纳税人适用税率:**

| 税率 | 适用范围 |
|------|----------|
| **13%** | 销售或进口货物(除9%税率外),如服装、电子产品、机械设备<br>加工、修理修配服务<br>有形动产租赁服务(设备、汽车租赁) |
| **9%** | 粮食、农产品、食用植物油、自来水、暖气、图书、化肥、农药、农机等<br>交通运输、建筑服务、邮政服务、基础电信、不动产租赁、转让土地使用权、销售不动产 |
| **6%** | 现代服务(研发、信息技术、文化创意、鉴证咨询等)<br>生活服务(文化体育、教育医疗、旅游娱乐、餐饮住宿等)<br>金融服务(贷款、保险、金融商品转让)<br>增值电信服务、销售无形资产(不含土地使用权) |
| **0%** | 出口货物<br>跨境服务(国际运输、研发、设计等)<br>纳税人可放弃零税率选择免税,但36个月内不得变更 |

**征收率(小规模纳税人及简易计税):**
- 标准征收率: **3%**
- 特殊时期政策: 可能减按1%征收(需关注最新政策)
- 免征政策: 月销售额≤10万元(季度≤30万元)免征增值税

#### 计税方法

**一般计税方法(一般纳税人):**
```
应纳税额 = 当期销项税额 - 当期进项税额
销项税额 = 不含税销售额 × 适用税率
```

**简易计税方法(小规模纳税人及特定业务):**
```
应纳税额 = 不含税销售额 × 征收率(3%)
```

#### 进项税额抵扣

**可以抵扣的项目:**
- 取得增值税专用发票注明的增值税额
- 取得海关进口增值税专用缴款书注明的增值税额
- 购进农产品,按9%扣除率计算(生产13%税率货物按10%扣除)
- 接受旅客运输服务,按票据金额计算抵扣

**不得抵扣的项目(实施条例第二十二条):**
1. 简易计税方法计税项目对应的进项税额
2. 免征增值税项目对应的进项税额
3. 非正常损失项目对应的进项税额
   - 非正常损失的购进货物,以及与之相关的加工修理修配服务和交通运输服务
   - 非正常损失的在产品、产成品所耗用的购进货物(不包括固定资产)、加工修理修配服务和交通运输服务
   - 非正常损失的不动产,以及该不动产所耗用的购进货物和建筑服务
   - 非正常损失的不动产在建工程所耗用的购进货物和建筑服务
4. 购进并用于集体福利或者个人消费的货物、服务、无形资产、不动产对应的进项税额
5. 购进并直接用于消费的餐饮服务、居民日常服务和娱乐服务对应的进项税额
6. 贷款服务的利息支出,及其向贷款方支付的与该贷款服务直接相关的投融资顾问费、手续费、咨询费等费用支出,对应的进项税额**暂不得从销项税额中抵扣**(实施条例第二十一条)
7. 购进货物、服务、无形资产、不动产,用于不得抵扣非应税交易的进项税额不得抵扣

**重要说明(2026年1月1日起实施):**
- **贷款服务进项税额暂不得抵扣**(实施条例第二十一条),这与网络流传的"取消限制"说法相反
- 只有餐饮、居民日常、娱乐服务这三项直接用于消费的服务不得抵扣
- 贷款服务的利息支出及其相关费用(投融资顾问费、手续费、咨询费等)对应的进项税额仍然**不得抵扣**

#### 税收优惠政策

**即征即退:**
- 软件产品: 实际税负超过3%的部分即征即退
- 资源综合利用产品: 增值税即征即退70%

**加计抵减:**
- 生活服务类企业(餐饮、旅游等)可按进项税额的15%加计抵减
- 先进制造业: 按进项税额的5%加计抵减

**其他优惠:**
- 自产农产品: 免征增值税
- 小微企业: 月销售额10万元以下免征增值税
- 增值税小规模纳税人: 3%征收率可减按1%征收(阶段性政策)

#### 筹划要点

**纳税人身份筹划:**
- 根据增值率选择纳税人身份
- 考虑行业特性: 资本密集型选一般纳税人,劳动密集型可选小规模

**税率差异利用:**
- 拆分高税率业务(如设备销售13% + 安装服务9%)
- 利用混合销售规则,争取按低税率业务计税
- 出口业务享受零税率"免抵退"政策

**进项税额管理:**
- 优先选择可开具专票的供应商
- 确保"三流一致"(资金流、货物/劳务流、发票流)
- 合理划分应税与非应税项目,避免进项税转出

**销售方式优化:**
- 商业折扣: 折扣额与销售额同票开具,按净额计税
- 分期收款: 延迟纳税义务,获取资金时间价值
- 业务拆分: 将高税率业务与低税率业务分离

#### 申报期限
- 一般纳税人: 月度申报
- 小规模纳税人: 月度或季度申报(可选)

#### 风险提示
- 政策变动频繁,需定期关注财政部、税务总局公告
- 避免"假拆分""假出口"等违规操作
- 确保筹划方案实质重于形式,符合行业限制条件
- 进项抵扣必须取得合规发票,注意发票时效性

### 2. 企业所得税 (CIT)
- **标准税率**: 25%
- **优惠税率**:
  - 小微企业: 年应纳税所得额≤300万,实际税负5%或2.5%
  - 高新技术企业: 15%
  - 技术先进型服务企业: 15%
  - 集成电路/软件企业: 10%-15%
- **计税依据**: 应纳税所得额 = 收入总额 - 不征税收入 - 免税收入 - 各项扣除 - 以前年度亏损
- **申报期限**: 季度预缴、年度汇算清缴

### 3. 个人所得税 (PIT) - 代扣代缴义务
- **所得类型**: 综合所得、经营所得、分类所得
- **税率**: 3%-45%七级超额累进税率(综合所得)
- **申报**: 月度预扣预缴、年度汇算清缴

### 4. 附加税费
- **城市维护建设税**: 7%、5%、1%
- **教育费附加**: 3%
- **地方教育附加**: 2%
- **计税依据**: 实际缴纳的增值税、消费税税额

### 5. 其他税费
- **印花税**: 合同、账簿、证照
- **房产税**: 房产原值×70%×1.2% 或 租金收入×12%
- **城镇土地使用税**: 按土地面积和等级定额征收
- **车辆购置税**: 计税价格×10%
- **车船税**: 按年定额征收
- **土地增值税**: 转让房地产增值额×税率(30%-60%)
- **资源税**: 从价计征或从量计征
- **环境保护税**: 污染当量数×税额

## 二、常见税收优惠政策

### 1. 区域性优惠
- 西部大开发优惠(15%税率)
- 海南自贸港优惠(15%税率,部分行业零税)
- 自贸试验区税收优惠

### 2. 行业性优惠
- 农、林、牧、渔业免税或减税
- 基础设施项目三免三减半
- 环境保护、节能节水项目三免三减半
- 软件产业和集成电路产业优惠

### 3. 研发费用加计扣除
- 一般企业: 75%
- 制造业企业: 100%
- 科技型中小企业: 100%

### 4. 小微企业优惠
- 增值税: 月销售额10万元以下免税
- 企业所得税: 年应纳税所得额≤300万,实际税负5%或2.5%
- 六税两费减半征收

### 5. 其他优惠
- 残疾人就业加计扣除
- 教育支出税前扣除
- 公益性捐赠税前扣除(不超过年度利润总额12%)
- 固定资产加速折旧

## 三、重要税务合规要点

### 1. 发票管理
- 必须取得合法有效凭证
- 发票内容与实际交易相符
- 按规定开具发票
- 发票保管期限至少10年

### 2. 纳税申报
- 按时申报各类税费
- 申报数据真实准确
- 保留申报凭证备查

### 3. 账簿管理
- 建立健全财务制度
- 账簿凭证保存10年以上
- 会计核算规范完整

### 4. 税务登记
- 及时办理税务登记
- 信息变更及时报告
- 注销前完成清算

### 5. 税务档案
- 完整保存税务资料
- 分类整理便于查阅
- 按规定期限保管

## 四、税务风险评估重点

### 1. 高风险领域
- 收入确认时点
- 成本费用扣除合规性
- 关联方交易定价
- 跨境交易税务处理
- 税收优惠政策适用

### 2. 常见问题
- 发票不规范
- 账实不符
- 收入确认不及时
- 费用列支不当
- 优惠政策误用

### 3. 审查重点
- 税收优惠资格条件
- 研发费用归集
- 关联交易公允性
- 成本分配合理性
- 会计政策一致性
