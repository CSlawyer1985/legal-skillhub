# TaxMao图标设计详解

## 🎨 设计目标

创建一个包含"TaxMao"文字的税务合规skill图标。

---

## 📐 设计规格

### 基础参数:
- **尺寸:** 512x512 像素
- **格式:** PNG (透明背景)
- **布局:** 居中对齐
- **主色:** 蓝色 (#1890FF)
- **辅色:** 金色 (#FAAD14)

## 🛠️ 使用Canva制作详细步骤

### 第一步: 创建画布

1. 打开 https://www.canva.com
2. 点击"创建设计" → "自定义尺寸"
3. 输入:
   - 宽度: 512
   - 高度: 512
4. 点击"创建新设计"

---

### 第二步: 添加背景(方案A)

1. 点击左侧"元素" → "形状"
2. 选择"正方形"
3. 拖动到画布,调整至512x512
4. 设置颜色:
   - 点击颜色图标
   - 选择自定义颜色
   - 输入: #1890FF (蓝色)
5. 确保背景填满整个画布

---

### 第三步:添加图标

1. 点击左侧"元素"
2. 搜索关键词:
   - "balance scale" (天平)
   - 或 "shield" (盾牌)
   - 或 "calculator" (计算器)
3. 选择免费图标(有"Free"标签)
4. 点击图标添加到画布
5. 调整大小:
   - 点击图标
   - 拖动角调整大小
   - 建议大小: 120-140px
6. 调整位置:
   - 拖动到顶部居中
   - 距离顶部约80px

---

### 第四步: 添加"TaxMao"文字

1. 点击左侧"文本"
2. 选择"添加标题" 或 "添加副标题"
3. 在文本框中输入: TaxMao
4. 调整字体:
   - 字体: Arial Black (或 Microsoft YaHei Bold)
   - 字号: 56pt (或根据视觉调整)
   - 颜色: 白色 (#FFFFFF)
   - 加粗: 已加粗
5. 调整位置:
   - 拖动到画布中心
   - 垂直居中,水平居中
   - 距离图标下方约40px

6. 文字效果(可选):
   - 点击文字
   - 选择"效果"
   - 添加"阴影" 效果
   - 调整阴影参数:
     * 模糊: 10
     * 透明度: 30
     * X偏移: 0
     * Y偏移: 4

---

### 第五步: 添加装饰线(可选)

1. 点击左侧"元素" → "形状"
2. 选择"线条"
3. 拖动到文字下方
4. 调整:
   - 长度: 180-200px
   - 颜色: #FAAD14 (金色)
   - 粗细: 4-6px
5. 位置:
   - 文字下方约20px
   - 水平居中

---

### 第六步: 调整和优化

1. 检查对齐:
   - 点击顶部"位置"
   - 选择"全部对齐"
   - 确保所有元素居中

2. 检查间距:
   - 图标顶部到画布顶部: 约80px
   - 图标底部到文字顶部: 约40px
   - 文字底部到装饰线: 约20px
   - 装饰线底部到画布底部: 约60px

3. 调整颜色(如需要):
   - 背景色: #1890FF (蓝色)
   - 文字色: #FFFFFF (白色)
   - 图标色: #FFFFFF (白色)
   - 装饰线色: #FAAD14 (金色)

---

### 第七步: 导出图标

1. 点击右上角"分享"
2. 选择"下载"
3. 设置:
   - 文件类型: PNG
   - 质量: 标准
   - 勾选"透明背景"(如果需要)
4. 点击"下载"
5. 文件名保存为: `icon_512x512.png`
