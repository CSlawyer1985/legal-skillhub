# 税法合规与筹划 Skill

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-1.0.0-green.svg)](CHANGELOG.md)

## 📖 简介

这是一个专业的税法合规与筹划技能,基于中国最新税法(含2026年增值税法),为企业提供全面的税务管理支持,包括政策识别、合规分析、税务筹划、风险评估和审计支持。

## ✨ 核心功能

### 1. 税收政策识别与分析
- 识别企业适用的税种和税收政策
- 查找税收优惠政策
- 分析政策适用条件和申报要求

### 2. 税务合规评估与报告
- 评估当前税务合规状况
- 识别合规漏洞和风险
- 生成合规评估报告

### 3. 税务筹划与优化
- 提供合法节税方案
- 优化税务结构
- 评估不同方案的税负影响

### 4. 税务风险评估与管理
- 识别税务风险点
- 评估风险等级和影响
- 制定风险缓解措施

### 5. 税务审计支持
- 准备审计资料清单
- 预判检查重点
- 提供应对策略

### 6. 增值税专项服务
- 2026年增值税法新规解读
- 纳税人身份选择分析
- 税负平衡点计算
- 进项税额抵扣优化

## 🎯 适用场景

- 新公司设立或业务扩张
- 年度税务筹划
- 重大交易筹划(并购、重组)
- 定期合规审查
- 税务审计准备
- 税务风险识别

## 📖 使用指南

### 基本使用

直接在WorkBuddy中提出税务相关的问题即可:

```
"我们公司需要缴纳哪些税?"
"如何合法降低我们的税务负担?"
"我们公司能享受哪些税收优惠政策?"
```

### 深度分析

对于复杂的税务问题,可以提供更多背景信息:

```
"我们是一家软件开发公司,年收入5000万,员工50人,主要客户是大型企业。
我想了解:1)应该选择一般纳税人还是小规模纳税人?2)有哪些税收优惠政策可以申请?"
```

## ⚠️ 重要声明

**本skill仅提供税务分析和筹划参考,不能替代专业税务师的正式意见。**

**重要提醒:**
- **复杂交易**建议咨询专业机构
- 政策变化较快,建议确认最新规定
- 需要结合具体业务场景分析
- 最终决策应以税务机关正式文件为准
