## 概述

欧盟 AI 法案审查报告生成器——产出一份正式的、结构化的 AI 法案合规评估报告，适用于法律档案、审计追踪和监管问询：

- **9 部分报告结构**——引言、系统描述、范围排除核验、适用范围、预期目的、风险分类、适用义务、风险标记、结论
- **上下文优先的自适应输入**——可用时消费先前评估的产出（分类、角色确定、义务映射、快速分流）
- **输入验证阶段**——明确的第 1.5 阶段，在起草前标记缺失或不一致的上下文
- **以引用为支撑的散文**——法律引用索引使条文引用保持一致
- **司法辖区检查清单**——成员国特定合规项目
- **交付前的质量检查阶段**（第 3 阶段）
- **Word 文档导出**，带格式化输出（第 4 阶段）
- **输出模板**——评估、差距分析、监管提交和内部备忘录

## 部署

### Claude.ai（用户技能）

1. 前往**设置 → 个人资料 → 自定义技能**（或等效入口）
2. 上传整个 `ai-act-report/` 文件夹结构
3. 该技能将在"generate AI Act report"、"Prüfbericht"、"create compliance assessment"或"export as Word"时自动触发

### Claude Code / 自定义 MCP 设置

1. 将 `ai-act-report/` 文件夹复制到您的技能目录：
   ```bash
   cp -r ai-act-report/ /path/to/your/skills/user/ai-act-report/
   ```
2. 确保该技能已在您的配置中注册

## 使用

### 快速开始

可从零开始，也可交接先前技能输出的上下文：

> "为我们的 HR 筛选系统生成一份正式的 AI 法案合规报告。
> 我已运行了分类器（高风险，附件 III 第 4 号）和角色
> 技能（我们是部署方）。请汇编完整的 Prüfbericht 并
> 导出为 Word 文档。"

该技能将验证上下文、起草 9 部分报告、运行质量检查，并提供 .docx 导出。

### 触发短语

- "Generate AI Act report" / "Prüfbericht" / "Compliance assessment report"
- "Document the AI Act analysis" / "Export as Word"
- "Create a formal AI Act assessment"

### 工作流

| 阶段 | 描述 |
|-------|-------------|
| **第 1 阶段：输入收集** | 上下文优先的自适应输入——如存在先前技能产出则消费之 |
| **第 1.5 阶段：输入验证** | 明确的门禁，在起草前标记缺失或不一致的输入 |
| **第 2 阶段：报告生成** | 9 部分模板，填入引用和辖区覆盖层 |
| **第 3 阶段：质量检查** | 交付前的一致性、完整性审查 |
| **第 4 阶段：Word 导出** | 可选的格式化 .docx 输出 |

## 报告结构

| 部分 | 内容 |
|---------|---------|
| 1. 引言 | 目的、评估范围、方法说明 |
| 2. 系统描述 | 功能、部署背景、用户 |
| 3. 初步核验——范围排除（第 2 条） | 军事、研发、个人、ILE、开源核验 |
| 4. 适用范围 | 属地范围（第 2 条）、义务对象分析 |
| 5. 预期目的（第 3 条第 12 款） | 提供方声明的预期用途 |
| 6. 风险分类 | 层级结论及第 5 条 / 附件 I / 附件 III / GPAI / 第 50 条分析 |
| 7. 适用义务 | 角色 × 层级义务映射，附法律引用 |
| 8. 风险标记与建议 | 未决问题、后续行动、监控项目 |
| 9. 结论 | 总结结论 + 后续步骤 |
