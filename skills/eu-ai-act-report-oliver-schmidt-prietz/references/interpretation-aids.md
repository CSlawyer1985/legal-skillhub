# 解释辅助——评估框架

## 1. 自主性量表（ISO 22989）

| 级别 | 德语 | 英语 | 说明 | 示例 |
|-------|--------|---------|-------------|---------|
| 0 | Keine Automatisierung | No automation | 操作者完全控制 | 手动数据录入 |
| 1 | Assistenz | Assistance | 系统建议，人工决定 | 拼写检查、自动补全 |
| 2 | Teilautomatisierung | Partial automation | 部分子功能自动化，人工整体控制 | 自动格式化 |
| 3 | Bedingte Automatisierung | Conditional automation | 特定情境下自主运行，人工随时准备干预 | 带升级机制的聊天机器人 |
| 4 | Hohe Automatisierung | High automation | 任务的部分环节无需干预 | 带监测的自动驾驶仪 |
| 5 | Volle Automatisierung | Full automation | 整个任务无需干预 | 全自主流水线 |
| 6 | Autonomie | True autonomy | 无需监督即调整目标 | 自我导向 AI（理论性） |

**应用：** 第1级及以上满足第3(1)条标准2。大多数商业 AI 系统运行在第2-4级。

## 2. 实质性修改——7个示例

| # | 修改类型 | 德语 | 可能实质性？ | 引用 |
|---|------------------|--------|-------------------|-----------|
| 1 | 操作系统变更 | Betriebssystem-Aenderung | 是（如影响行为） | 序言第128段 |
| 2 | 软件架构大改 | Softwarearchitektur | 是 | 序言第128段 |
| 3 | 训练数据调整 | Anpassung der Trainingsdaten | 视范围而定 | 逐案判断 |
| 4 | 算法变更 | Aenderung des Algorithmus | 是 | 核心变更 |
| 5 | 范围/领域扩展 | Erweiterung des Anwendungsbereichs | 是（目的变更） | 第25(1)(c)条 |
| 6 | 外部组件集成 | Integration externer Komponenten | 视情况而定 | 逐案判断 |
| 7 | 硬件升级 | Hardware-Upgrade | 是（如影响行为） | 序言第128段 |

**关键例外：** 原合格评定中预见并涵盖的自学习式调整不构成实质性修改（第25(4)条）。

## 3. 微调分级矩阵

| 技术 | 参数影响 | 风险等级 | 可能实质性？ |
|-----------|-----------------|------------|-------------------|
| PEFT/LoRA/QLoRA/Adapter | < 1% 参数 | 低 | 否（通常） |
| 前缀微调/提示微调 | 仅外部参数 | 低 | 否 |
| 分层微调（顶层） | 5-30% 参数 | 中 | 逐案判断 |
| 分层微调（深层） | 30-50% 参数 | 中-高 | 可能为是 |
| 全量微调 | 所有参数 | 高 | 是（通常） |
| 用新数据完全重新训练 | 所有参数 + 新数据 | 高 | 是 |
| 架构修改 + 重新训练 | 结构性 + 所有参数 | 极高 | 是 |

**需评估的元因素：**
1. 参数变更程度（Umfang der Parameteraenderung）
2. 可预见性（Vorhersehbarkeit）
3. 风险评估影响（Risikobewertung）
4. 技术/组织复杂性（Komplexitaet）

## 4. 开源检查清单摘要

### 检查清单I：AI 系统——第2(12)条完全豁免

| 步骤 | 问题 | 所需答案 |
|------|----------|----------------|
| **第1步** | 是否为 AI 系统（第3(1)条）？ | 是（以继续） |
| **第2a步** | 是否高风险（第6条）？ | 否（以符合资格） |
| **第2b步** | 是否被禁止（第5条）？ | 否（以符合资格） |
| **第2c步** | 是否触发第50条？ | 否（以符合资格） |
| **第3.1步** | 是否公开可获取？ | 是 |
| **第3.2步** | 是否无阻碍平等访问？ | 是 |
| **第3.3步** | 是否不收取价格？ | 是 |
| **第3.4步** | 个人数据是否仅用于技术目的？ | 是 |
| **第3.5步** | 许可证是否允许使用、修改、分发？ | 是 |
| **第3.6步** | 参数/权重/架构是否公开？ | 是 |

**所有第3步 = 是 且 所有第2步 = 否 → 完全豁免**

### 检查清单II：GPAI 模型——第53(2)条部分豁免

| 步骤 | 问题 | 所需答案 |
|------|----------|----------------|
| **第1步** | 是否为 GPAI 模型（第3(63)条）？ | 是（以继续） |
| **第2a步** | 权重是否公开可获取？ | 是 |
| **第2b步** | 架构是否完全披露？ | 是 |
| **第2c步** | 是否提供执行信息？ | 是 |
| **第2d步** | 是否无需认证即可下载？ | 是 |
| **第2e步** | 使用是否不受限制（私营+商业）？ | 是 |
| **第2f步** | 是否允许修改？ | 是 |
| **第3a步** | 是否非付费分发？ | 是（微型企业例外） |
| **第3b步** | 是否不利用个人数据？ | 是 |
| **第3c步** | 是否未被分类为系统性风险？ | 是（无系统性风险） |

**所有标准满足 → 部分豁免（仅文档 + 透明度）**

## 5. 第6(3)条例外决策框架

```
附件 III 触发
        │
        ▼
系统是否进行画像分析（GDPR 第4(4)条）？
├── 是 → 例外不适用 → 高风险
└── 否 → 继续
        │
        ▼
是否适用任何条件 (a)-(d)？
│
├── (a) 狭窄程序性任务？
│   问题：任务是否狭窄？机械性？无实质性判断？
│   示例：OCR、格式转换、数据提取
│
├── (b) 改进先前已完成的人工活动？
│   问题：人工是否已作决定？AI 是否仅提高质量/格式？
│   示例：对已写决定的语法检查、格式化
│
├── (c) 检测决策模式（不取代）？
│   问题：是否分析既往决定？是否标记偏差？无自动纠正？
│   示例：审计工具、质量保证一致性分析
│
└── (d) 评估的准备性任务？
    问题：是否为人工准备信息？人工是否作最终决定？
    示例：判例研究、为审查汇编数据
        │
        ▼
是否至少满足一个条件？
├── 否 → 例外不适用 → 高风险
└── 是 → 继续
        │
        ▼
系统是否构成重大伤害风险？
├── 是 → 例外不适用 → 高风险
└── 否 → 例外适用 → 非高风险
              │
              └── 但：必须依第6(4)条记录 + 登记（第49(2)条）
```

| **高风险（附件 III）** | 第6(2)条 | 第三章全部要求 | 1500万欧元 / 3% |
| **GPAI 系统性风险** | 第51条 | 第53条 + 第55条 | 1500万欧元 / 3% |
| **GPAI 标准** | 第53条 | 第53条透明度/文档 | 1500万欧元 / 3% |
| **有限风险** | 第50条 | 仅透明度义务 | 1500万欧元 / 3% |
| **最低风险** | 不适用 | 仅第4条 AI 能力 | 不适用 |
