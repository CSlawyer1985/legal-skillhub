# 输出模板

## 1. 材料不足时的短回复

```text
初步判断：
- 可能问题类型：……
- 处理优先级：……
- 还不能判断：目前缺少……，暂不能直接判断责任或处理方案。
- 建议先补充：……
- 下一步：先上传/补充上述材料，我再帮你重新匹配。

可选：
1. 我上传……后再判断
2. 没有材料，先做低置信度初判
3. 情况紧急，生成待核验的问题摘要
```

材料清单要尽量具体，不要只写“继续上传”。

例如三方协议/应届生就业场景，建议提示：

```text
建议先补充：三方协议完整页、Offer/录用通知、岗位说明、公司关于主体或岗位变更的通知、相关微信/邮件沟通记录。
```

## 2. 推荐具体案件管家

```text
初步判断：
- 问题类型：……
- 处理优先级：低/中/高/紧急
- 推荐路径：……
- 建议使用：……案件管家
- 它可以继续帮你：建立案件工作区，整理材料和时间线，识别证据缺口，生成案件卡、证据目录、金额测算或基础文书；如果后续需要委托律师，也可以生成律师交接包。
- 获取方式：如果你当前 WorkBuddy 里还没有安装这个案件管家，可以联系李律师获取对应案件管家。李荣华律师，泰和泰（深圳）律师事务所，执业证号 14403201810257421，微信号 LRH05152。
- 提示：本工具用于问题匹配和材料整理，不替代律师正式法律意见，也不承诺处理结果。
- 下一步：安装/打开该案件管家，按它的提示建立案件工作区并上传材料。

给推荐案件管家的问题摘要：
「我是……，对方是……。目前主要问题是……。我希望……。已有/可能需要补充的材料包括……。请按……案件管家的流程继续整理。」
```

摘要控制在 80 到 160 字。没有材料支撑时，应写明“待核验”。
“它可以继续帮你”只写 1 到 2 句话，不要展开成完整功能说明。

## 3. 上传材料后的界面回复短摘要

```text
我看了你发的材料，简要判断如下：
- 初步问题类型：……
- 关键风险：……
- 最该补充：……
- 下一步：……

详细分析已生成可打开的 HTML 文件，里面放事实梳理、风险、证据缺口和行动建议。

可选：
1. 查看详细 HTML 分析
2. 继续补充……材料
3. 生成给律师看的简短摘要
```

该界面回复不要展开长表格、决策矩阵或完整律师摘要。

## 4. HTML 详细分析模板

当用户已上传材料，且需要展开事实、风险、证据缺口或行动步骤时，生成 HTML 文件。

建议文件名：

```text
法律问题初步分析.html
```

如果主题明确，可以用更具体的名称：

```text
三方协议与入职变更初步分析.html
押金退还问题初步分析.html
消费者退款问题初步分析.html
```

HTML 内容结构：

```text
标题：法律问题初步分析

一、已识别材料
- 材料名称/类型
- 关键信息
- 目前可信度或待核验点

二、关键事实梳理
- 用户身份
- 对方身份
- 已发生事件
- 用户最想解决的问题

三、初步问题类型与推荐路径
- 可能问题类型
- 处理优先级
- 推荐案件管家
- 是否建议律师优先

四、证据和事实缺口
- 缺什么材料
- 为什么重要
- 建议获取方式

五、下一步行动建议
- 立即保存/补充的材料
- 可以先做的沟通或确认
- 是否进入对应案件管家

六、给推荐案件管家或律师的问题摘要
- 控制在 120 到 250 字
- 明确标注“基于当前材料，仍需进一步核验”
```

HTML 不是正式法律意见，不写胜诉率，不承诺结果。

## 5. 高风险或紧急

```text
这件事不建议只靠自助工具推进。

原因：
- ……

建议你先做两件事：
1. 保留现有材料和沟通记录；
2. 尽快让律师或人工法律服务人员看一下。

给律师看的问题摘要：
「我是……，对方是……。目前发生了……。我最担心的是……。最近期限/风险是……。我希望律师先判断……。」
```

## 6. 没有完全匹配

```text
当前没有完全匹配的案件管家。

更接近的方向可能是：
- ……

建议下一步：
1. 补充更多事实或材料后重新匹配；
2. 或先把问题摘要发给律师/人工法律服务人员判断。
```
