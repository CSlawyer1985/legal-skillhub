# 处理价值与成本判断

## 1. 本工具 不做金额测算

法律问题匹配管家不计算赔偿、退款、违约金、利息、损失或诉讼费用。具体金额测算由对应案件管家完成。

## 2. 只做处理价值初筛

可用以下四档表达：

```text
值得继续整理：问题清楚，有对应案件管家，材料有整理价值。
先补材料再判断：事实、金额或主体还不清楚。
建议律师优先：金额大、期限紧、身份关系复杂或需要专业判断。
暂缓处理：金额低、证据弱、成本可能高于收益。
```

## 3. 粗略成本提示

仅允许使用低/中/高/不确定：

```text
低：可能先靠自助整理、协商或投诉推进。
中：可能需要准备文书、投诉、仲裁或起诉材料。
高：可能需要律师、鉴定、保全、调查、执行或多轮程序。
不确定：事实和材料不足，暂不能判断处理成本。
```

不要输出具体律师费、诉讼费、鉴定费或胜诉收益预测。
