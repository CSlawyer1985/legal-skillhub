# 浙江政府采购法律服务线索雷达

从权威公告形成可核验、可跟进的法律服务项目清单。不要把聚合平台转载当正式依据，也不要用猜测补齐抓取失败的数据。

## 首次响应

确认或合理默认：地域（默认浙江全省）、时间窗（默认近 7 日）、法律服务范围、律所服务半径/专长/预算偏好，以及一次性检索或持续监控。持续监控必须使用宿主的自动化能力，不能只在文字中承诺。

用不超过 8 行回显检索范围、数据源、限制和产出后再检索。

## 数据源顺序

1. 浙江政府采购网/政采云及公告详情页。
2. 中国政府采购网中地域为浙江的公告。
3. 浙江各地公共资源交易平台，用于补漏。
4. 用户提供的公告、历史中标数据或聚合平台结果。

正式判断须回到官方原始公告核验。动态页面、登录或反爬导致无法覆盖时，明确写出未覆盖的数据源与时间段。

## 工作流

1. 按项目编号、采购人和公告类型去重，串联意向、公告、更正、结果和合同。
2. 从详情页提取项目、编号、采购人、地区、预算/限价、方式、资格、文件获取与截止时间、附件和更正公告。
3. 做门槛筛查：服务地域、主体资格、利益冲突、联合体、业绩/人员要求和剩余准备时间。
4. 按律所匹配 30%、可投性 25%、竞争强度 20%、投入产出 25% 排序并列明依据。缺数据时给区间或“待核验”，不伪造精确分。
5. 对高优先级项目给出负责人、需下载文件和最晚决策时间。
6. 将结果公告沉淀到采购人、竞对、代理机构画像和续约日历；续约日期只作预测线索。

## 固定输出

先给“立即跟进、观察、放弃”各不超过 3 项，再输出：

`优先级｜项目｜编号｜采购人｜地区｜预算｜方式｜截止｜剩余时间｜门槛｜判断｜官方证据链接｜下一步`

每条标记 `已核验 / 待核验 / 信息不足`。末尾列检索时间、已覆盖和未覆盖数据源、复核节点。

## 边界

- 不承诺搜全；无权威来源的项目不得标为已核验。
- 不因画像推断违法、内定或串标。
- 不把省外项目套用浙江渠道和规则。
- 转入拆标、写标、验标或救济时，交接项目编号、属地、采购文件和证据链接。
