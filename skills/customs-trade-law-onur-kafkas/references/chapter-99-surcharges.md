# 第 99 章附加关税 —— 第 301/232/201 条识别

## 概览

HTSUS 第 99 章包含依各种贸易救济法规实施的临时关税修改。这些附加关税**叠加于**常规第 1 栏一般税率之上，且可能是总关税的**最大组成部分**。

使用现行 HTS 数据和官方状态来源。按 `references/agentic-research-protocol.md` 创建证据台账条目；除非生效日期、排除项和来源时效均已核查，否则第 99 章结论不视为现行有效。

---

## 第 301 条 —— 报复性关税（1974 年《贸易法》）

### 背景
授权依据：19 U.S.C. § 2411（1974 年《贸易法》第 301 条）
主要目标：中国（自 2018 年起，多个“清单”涵盖数千个 HTS 子目）

### 识别协议

1. **检查 HTS 脚注**中的第 99 章交叉引用：
   - 在 REST API 结果中查找如“See 9903.88.15”的脚注
   - 这表明该子目受第 301 条行动涵盖
   - 同时检查现行 HTS JSON 中的 `additionalDuties` 和 `addiitionalDuties`

2. **检索现行状态：**
   ```
   web_search("Section 301 tariff {HTS heading} China {current_year}")
   web_search("USTR Section 301 list {product type} {current_year}")
   web_search("9903.88 {HTS heading} Section 301")
   ```
   优先采用 USTR、联邦公报、USITC 和 HTS 第 99 章来源，而非二手摘要。

3. **识别清单和税率：**

   | 清单 | 初始税率 | 现行税率 | HTS 第 99 章 |
   |------|-------------|--------------|-----------------|
   | 清单 1 | 25% | 25%+ | 9903.88.01-03 |
   | 清单 2 | 25% | 25%+ | 9903.88.04-05 |
   | 清单 3 | 25% | 25%+ | 9903.88.06-15 |
   | 清单 4A | 7.5%-25% | 视情况而定 | 9903.88.16+ |
   | 清单 4B | 各种 | 视情况而定 | 9903.88.xx |

   **注：** 税率已被多次修改。务必通过含当前年份的 web_search 核实**现行**税率。

4. **检查排除项：**
   ```
   web_search("Section 301 exclusion {product} {HTS heading} {current_year}")
   ```
   - 产品特定排除项可能减少或取消附加关税
   - 排除项有**到期日**——核实现行状态
   - 如排除项可能适用，触发 `references/human-review-triggers.md` 中的标记

### 国家范围
第 301 条关税目前主要针对**中国**。中国原产产品（就关税而言的原产国）须适用相应清单附加关税。

**关键：** 就第 301 条而言的原产国遵循标准实质性改变分析——而不仅是制造国。

## 第 232 条 —— 国家安全关税（1962 年《贸易扩展法》）

### 背景
授权依据：19 U.S.C. § 1862（1962 年《贸易扩展法》第 232 条）
产品：钢铁和铝制品

### 识别协议

1. **确定产品是否为钢铁或铝：**
   - 钢铁制品：一般为第 72-73 章以及部分其他章节产品
   - 铝制品：一般为第 76 章以及部分其他章节产品
   - 衍生钢铁/铝制品：部分含钢铁/铝的制成品

2. **检索现行状态：**
   ```
   web_search("Section 232 tariff {product} {current_year}")
   web_search("Section 232 steel aluminum tariff rate {current_year}")
   ```
   优先采用总统公告、联邦公报通知、商务部/BIS 材料、USITC 和 HTS 第 99 章来源。

3. **标准税率：**

   | 产品 | 税率 | HTS 第 99 章 |
   |---------|------|-----------------|
   | 钢铁 | 25% | 9903.80.01+ |
   | 铝 | 10% | 9903.85.01+ |

   **注：** 税率和国家覆盖范围已由总统公告修改。部分国家已被豁免或改为配额而非关税。务必核实现行状态。

4. **检查排除项：**
   ```
   web_search("Section 232 exclusion {product} {current_year}")
   ```
   - 可通过商务部申请产品特定排除
   - 可能适用国家特定豁免（按原产国核实）

## 第 201 条 —— 保障关税（1974 年《贸易法》）

### 背景
授权依据：19 U.S.C. § 2251（1974 年《贸易法》第 201 条）
现行产品：太阳能电池/组件、大型家用洗衣机

### 识别协议

1. **检索现行保障措施：**
   ```
   web_search("Section 201 safeguard tariff {product} {current_year}")
   ```
   优先采用总统公告、联邦公报通知、USITC 保障材料、HTS 第 99 章来源。

2. **已知的现行保障措施：**

   | 产品 | 初始税率 | 备注 | HTS 第 99 章 |
   |---------|-------------|-------|-----------------|
   | 太阳能电池/组件 | 30%（递减） | 关税配额结构 | 9903.45.xx |
   | 洗衣机 | 20%（递减） | 关税配额结构 | 9903.44.xx |

   **注：** 第 201 条税率通常在 4 年期间**递减**，且可能延长。关税配额在数量阈值上下适用不同税率。

3. **第 201 条全球适用**（非针对特定国家），但 USMCA 国家（加拿大、墨西哥）及部分自贸协定伙伴可能被豁免。

## 附加关税叠加

第 301、232 和 201 条附加关税可在同一产品上**叠加**：

```
示例：来自中国的太阳能电池板
  一般税率：       免税（8541.40.60）
  + 第 301 条：     25%（清单 3）
  + 第 201 条：     视情况而定（太阳能电池保障措施）
  + 反倾销税：     视情况而定（如来自被涵盖生产商）
  + 反补贴税：     视情况而定（如来自被涵盖生产商）
  = 总估计关税：一般 + 301 + 201 + 反倾销 + 反补贴
```

**重要：** 并非所有附加关税都适用于来自所有国家的每种产品。每项附加关税都有自己的范围（产品覆盖和国家覆盖）。

## 验证步骤

对每个产品-国家组合：

1. **检查 API 结果中的 HTS 脚注**，查找任何“See 99XX.XX.XX”引用
2. **检查现行 HTS JSON 中的 `additionalDuties` 和 `addiitionalDuties`**
3. 如原产国为中国（或其他可能的目标国），**检索第 301 条**
4. 如产品为钢铁、铝或其衍生品，**检索第 232 条**
5. 如产品为太阳能电池/组件或洗衣机，**检索第 201 条**
6. 对每项适用附加关税**检查排除项**
7. **核实现行税率** —— 附加关税税率随总统公告变化
8. 为每项适用附加关税**记录第 99 章子目**
9. 如适用，**注明生效日期和到期日期**
10. 为每个来源**记录证据标签和检索日期**
