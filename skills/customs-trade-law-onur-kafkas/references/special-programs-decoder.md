# 特别计划解码器——FTA 和优惠计划资格

## 概述

HTS 数据中的“special”（特别）列包含字母代码，指示特定子目可享受哪些自由贸易协定（FTA）或优惠计划的税率。本方法解码这些代码并评估资格。

---

## 解码过程

### 第 1 步：提取特别列
从 HTS 数据（REST API 或批量 JSON）读取 `special` 字段：
```
示例："Free (A+,AU,BH,CL,CO,D,E,IL,JO,KR,MA,OM,P,PA,PE,S,SG)"
```

### 第 2 步：解码每个计划代码
使用 `references/fta-program-codes.json` 将每个字母代码映射到其计划名称、依据和合格国家。

### 第 3 步：与原产地匹配
给定产品的原产地，识别哪些计划可能适用。

### 第 4 步：核验资格要求
每个计划都有自己的原产地规则，必须满足。

---

## 资格评估框架

### 对于 FTA 优惠税率（AU、BH、CA、CL、CO、IL、JO、KR、MA、MX、OM、P、PA、PE、S、SG）

**FTA 税率资格的要求：**

1. **原产于 FTA 伙伴国**——产品必须根据该协议的原产地规则原产于 FTA 国家
2. **满足原产地规则**——通常为以下一项或多项：
   - **税则归类改变：** 产品在 FTA 国家生产期间发生规定的税则归类改变
   - **区域价值含量（RVC）：** 产品价值的特定最低百分比归因于 FTA 区域
   - **特定流程：** 产品经历特定的制造作业
3. **认证：** 有效的原产地证书或原产地声明
4. **直接运输：** 在某些 FTA 中，货物必须直接在 FTA 国家之间运输

### 对于优惠计划（A、A+、D、E、R）

**GSP（A、A+）：**
- 国家必须是指定的 GSP 受惠发展中国家
- 产品必须在该国的 GSP 合格清单上
- 产品必须是受惠国的“生长物、产品或制成品”
- 至少 35% 的估定价值必须归因于受惠国
- **检查 GSP 计划状态**——GSP 会定期到期，须经国会续期

**AGOA（D）：**
- 国家必须是撒哈拉以南非洲 AGOA 受惠国
- 产品必须满足 AGOA 原产地规则
- 检查当前受惠国清单——国家可被添加或移除

**CBERA/CBTPA（E、R）：**
- 加勒比盆地国家
- 产品必须满足适用的原产地规则
- CBTPA（R）提供增强的纺织/服装优惠

```
特别计划分析
HTS 子目：{XXXX.XX.XXXX}
原产地：{国家}

特别列：“{特别字段文本}”

| 代码 | 计划 | 合格国家 | 税率 | 合格？ |
|------|---------|---------------------|------|-----------|
| A+ | GSP（最不发达国家） | [清单] | 免税 | {是/否/需核实} |
| S | USMCA | 加拿大、墨西哥 | 免税 | {是/否/需核实} |
| KR | KORUS | 韩国 | 免税 | {是/否/需核实} |
| ... | ... | ... | ... | ... |

适用计划：{计划名称或“无——适用一般税率”}
优惠税率：{税率}
要求：{关键原产地规则要求}
文件：{所需证书或声明}
```

## 常见场景

### 来自 FTA 国家的产品
1. 从特别列识别适用的 FTA 代码
2. 说明优惠税率
3. 注明必须满足的原产地规则
4. 注明所需文件
5. 建议与报关行核实

### 来自 GSP 国家的产品
1. 确认特别列中有 `A` 或 `A+` 代码
2. **核实 GSP 当前有效**（它会定期到期）
3. 核实该国是该产品的现行 GSP 受惠国
4. 注明 35% 增值要求
5. 如 GSP 状态不确定则标记

### 来自非合格国家的产品
1. 无特别计划代码与原产地匹配
2. 适用第 1 栏一般税率
3. 注明可能同时适用的第 99 章附加费（第 301 条、第 232 条）
4. 考虑产品是否可通过第三国 FTA 合格（例如，如在 FTA 国家用部件组装）

### 来自第 2 栏国家的产品
1. 古巴、朝鲜——适用第 2 栏税率
2. 第 2 栏税率明显高于第 1 栏
3. 关税之外可能适用额外的制裁/限制
