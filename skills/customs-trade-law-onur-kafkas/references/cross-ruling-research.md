# CROSS 裁定研究协议

## 概述

海关裁定在线检索系统（CROSS）包含自 1989 年至今 219,915 条以上可检索的 CBP 裁定。本协议定义如何在归类分析中检索、评估和呈现 CROSS 裁定。

---

## 检索协议

### 第 1 步：主要检索——直接 CROSS URL
使用检索 URL 直接检索 CROSS（返回按日期排序的当前结果）：
```
web_fetch("https://rulings.cbp.gov/search?term={产品+关键词}&collection=ALL&commodityGrouping=ALL&sortBy=DATE_DESC&pageSize=30&page=1")
```
- 对检索词进行 URL 编码（空格用 `+`）
- 使用简洁的产品关键词（如 `outdoor+gas+grill`、`bluetooth+keyboard`）
- `collection=ALL` 检索 NY 和 HQ 两类裁定；使用 `collection=HQ` 或 `collection=NY` 收窄范围

### 第 2 步：按品目细化
如果主要检索返回结果过多或过少，通过将 HTS 品目加入检索词来细化：
```
web_fetch("https://rulings.cbp.gov/search?term={产品+关键词}+{4位品目}&collection=ALL&commodityGrouping=ALL&sortBy=DATE_DESC&pageSize=30&page=1")
```
- 如果第一个品目无结果，尝试替代品目
- 使用 `collection=HQ` 聚焦权威的总部裁定

### 第 3 步：裁定详情获取
对找到的每条相关裁定，获取完整的裁定页面：
```
web_fetch("https://rulings.cbp.gov/ruling/{RULING_ID}")
```
- 提取：产品描述、归类、适用的 GRI、关键推理、日期、状态
- 检查裁定文本中的撤销/修改通知
- 这是实现**已验证**（Verified）证据质量的主要方法（见下方证据质量协议）

### 附加模式
完整的已验证检索模式集（包括 CROSS 界面的布尔语法）参见 `references/search-strategies.md`。

## 评估标准

对找到的每条裁定，评估并记录：

### A. 裁定身份
- **裁定编号：** NY N______ 或 HQ H______
- **发布日期**
- **状态：** 有效、已撤销、已修改
- **类别：** NY（纽约）或 HQ（总部）

### B. 产品比较
- **被裁定产品描述：** 被归类的是什么？
- **事实相似度：** 被裁定产品与分析中产品的匹配程度如何？
  - **高：** 相同产品类型、相同材料、相同功能、相同用途
  - **中：** 相同产品类型但配置、材料或用途不同
  - **低：** 相关产品类型但特征显著不同
- **区分事实：** 被裁定产品与我们的产品之间存在哪些差异？

### C. 法律分析
- **分配的 HTS 归类：** 完整子目
- **适用的 GRI：** 哪个 GRI 解决了归类问题？
- **依赖的章/节注释：** 引用的具体注释
- **引用的解释性注释：** WCO EN 引用
- **关键推理：** 决定性的法律分析

### D. 权威性评估
- **HQ 与 NY：** HQ 裁定权重更大（全国范围、复杂事项）
- **时效性：** 较新的裁定更能反映 CBP 现行做法
- **一致性：** 该裁定是否与类似产品的其他裁定一致？
- **司法审查：** CIT/CAFC 是否有决定处理过该归类？

---

## 优先排序规则

当找到多条裁定时，按以下优先呈现：

1. **HQ 优先于 NY**——总部裁定反映国家层面的 CBP 政策
2. **新裁定优先于旧裁定**——现行做法可能不同于过去的裁定
3. **事实接近优先于疏远**——直接产品匹配优先于类比产品
4. **有效优先于已撤销**——但注明已撤销裁定以提供背景（为何变更？）
5. **一致群组优先于离群值**——多条裁定得出相同结论比单一裁定更有力

## 冲突检测

**关键：** 研究裁定时，主动寻找：

### 裁定间冲突
- 两条或以上有效裁定对类比产品归类不同
- 处理：注明两种归类，解释事实差异，触发 `references/human-review-triggers.md` 中的冲突裁定标志

### 裁定与法院冲突
- 一条 CROSS 裁定在已被 CIT 或 CAFC 否定的品目或分析下归类
- 处理：注明冲突，引用法院决定，建议以法院立场为权威，触发 `references/human-review-triggers.md` 中的 CIT 冲突标志

### 撤销链
- 裁定 A 被裁定 B 撤销，B 又被裁定 C 修改
- 处理：追溯完整链条。仅最终的生效裁定具有权威性。注明 CBP 立场的演变。

## 证据质量协议

通过 web_search 或 CROSS 检索找到的每条裁定，在引用前必须分配一个证据质量等级。使用 `references/agentic-research-protocol.md` 中的标签：

| 证据等级 | 条件 | 引用处理 |
|---------------|-----------|-------------------|
| **已验证（Verified）** | 已获取完整裁定文本，并对照 CROSS 或另一官方来源核对了状态/撤销情况 | 可放心引用；可从获取的文本中提取简短"关键引语" |
| **已获取（Retrieved）** | 已获取完整裁定文本，但未独立核实当前状态或撤销链 | 可支持分析；注明状态限制 |
| **已识别（Identified）** | 可见裁定编号 + HTS + 产品类型，但推理不可获取 | 仅以"已识别"方式引用；在 `rulings.cbp.gov/ruling/{ID}` 确认全文 |
| **未验证（Unverified）** | 仅有裁定编号、片段或二手提及 | 注明为研究线索；不依赖其支持归类 |

**关键规则：**"关键引语"——分析中引用的具体推理摘录——要求**已获取**或**已验证**证据等级。仅片段级裁定充其量是"已识别"；它们支持裁定的存在，但不能作为特定法律结论的权威被引用。

呈现裁定时，始终包含证据质量等级，以便审查者了解每条引用的依据。

同时将每条实质性裁定加入证据台账，注明检索日期、权威级别（HQ 或 NY）、状态和支持的命题。

## 输出格式

按以下方式呈现裁定研究结果：

### 对每条裁定：
```
**CBP 裁定 {NY/HQ} {编号}（日期 {日期}）**
- **产品：**{被归类产品的描述}
- **归类：**{HTS 子目}
- **适用的 GRI：**{GRI 编号和简要解释}
- **关键推理：**{决定性分析的 1-2 句摘要}
- **事实相似度：**{高/中/低}——{简要解释}
- **状态：**{有效 / 被 {裁定} 撤销 / 被 {裁定} 修改}
- **证据质量：**{已验证 / 已获取 / 已识别 / 未验证}
```

### 摘要分析：
呈现单条裁定后，提供：
1. **共识立场：** 多数裁定支持什么归类？
2. **离群值：** 是否有偏离的裁定，为什么？
3. **趋势：** CBP 对此类产品的归类方法是否在演变？
4. **缺口：** 现有裁定未处理产品的哪些方面？
5. **建议：** 这些裁定如何为我们的归类分析提供信息？

---

## 目标：3-5 条相关裁定

目标为 3-5 条裁定，共同满足：
- 涵盖推荐的归类品目
- 处理所考虑的各替代品目
- 至少包含一条 HQ 裁定（如有）
- 涵盖产品类型内的不同事实场景
- 有效且现行（或，如已撤销，提供有用背景）

如果找到的相关裁定少于 3 条，注明此情况并触发 `references/human-review-triggers.md` 中的"无 CROSS 裁定历史"标志。
