# 税率汇总

## 概述

美国进口的总关税是多个组成部分的总和。本方法论确保所有适用的关税层级均被识别并汇总。

---

## 汇总前要求

在给出税率之前：

1. 确认 HTS 子税号、统计后缀和原产国。
2. 依 `references/hts-data-sources.md` 解析并记录现行 HTS 来源记录。
3. 对照现行 HTS 修订版或实时的 USITC REST 输出核验第 1 栏普通税率、特别税率和第 2 栏字段。
4. 检查 `footnotes`、`additionalDuties` 和 `addiitionalDuties` 中的第 99 章交叉引用。
5. 依 `references/agentic-research-protocol.md` 创建证据台账条目。
6. 交付前运行人工审查触发器。

**硬性停止：** 如分类或原产国未知，说明关税只能作临时估算，并转至分类或原产分析。如无法确定现行 HTS 修订版，则不给出当前关税结论。

---

## 关税组成部分

### A. 第 1 栏普通税率（MFN/NTR）

适用于与美国保持正常贸易关系（NTR）地位的所有国家进口的标准“最惠国”税率。

**查找方法：**
1. 使用所选现行 HTS JSON 或查询 USITC REST API：
   ```
   web_fetch("https://hts.usitc.gov/reststop/search?keyword={产品}")
   ```
2. `general` 字段包含第 1 栏普通税率。
3. 记录所选 HTS 修订版和来源 URL。
4. 税率格式：
   - **从价：** `6.5%`（海关价值的百分比）
   - **从量：** `3.4¢/kg`（每单位的固定金额）
   - **复合：** `2.8% + 28.8¢/kg`（从价和从量兼有）
   - **免税：** 无关税

---

### B. 特别计划税率

依自由贸易协定（FTA）和优惠计划可用的优惠税率。

**查找方法：**
1. HTS 数据中的 `special` 字段显示可用计划。
2. 示例：`Free (A+,AU,BH,CL,CO,D,E,IL,JO,KR,MA,OM,P,PA,PE,S,SG)`
3. 使用 `references/fta-program-codes.json` 解码代码。
4. 确定原产国是否符合所列任一计划的资格。
5. 核验特定 FTA 的原产地规则已满足（税号改变、区域价值成分等）。
6. 对可能到期或失效的计划，通过官方来源核验现行计划状态。

**重要：** 获得特别税率资格要求：
- 原产于合格国家
- 遵守特定计划的原产地规则
- 适当文件（原产地证书、进口商声明）
- 计划须现行有效（检查 GSP/AGOA 到期情况）

---

### C. 第 2 栏税率

适用于来自无 NTR 地位国家的进口：古巴、朝鲜及可能其他国家。

**查找方法：** HTS 数据中的 `other` 字段包含第 2 栏税率。这些税率通常远高于第 1 栏。

---

### D. 第 99 章附加关税

依贸易救济法规征收的附加费。详细识别见 `references/chapter-99-surcharges.md`。

**类型：**
- **第 301 条**（1974 年《贸易法》第 301 节）：报复性关税（主要针对中国）
- **第 232 条**（1962 年《贸易扩展法》第 232 节）：国家安全关税（钢铁、铝）
- **第 201 条**（1974 年《贸易法》第 201 节）：保障关税（太阳能电池、洗衣机）

**查找方法：**
1. 检查现行 HTS 数据中的 `footnotes` 以获取第 99 章引用（例如“See 9903.88.15”）
2. 检查 `additionalDuties` 和观察到的拼写错误字段 `addiitionalDuties`
3. 检索：`web_search("Section 301 tariff {HTS税号} China {当前年份}")`
4. 检索：`web_search("Section 232 tariff {产品} {当前年份}")`
5. 遵循 `references/chapter-99-surcharges.md` 完成完整识别协议。

---

### E. 反倾销税（AD）

当美国商务部认定特定国家的特定产品以低于公平价值在美国销售时，对其征收的附加关税。

**查找方法：**
```
web_search("site:trade.gov antidumping duty order {产品} {国家}")
web_search("site:federalregister.gov antidumping duty order {产品} {国家}")
web_search("Commerce scope ruling {产品} {国家} antidumping")
```

**要点：**
- AD 税率因公司而异（受查生产商的个别税率、“所有其他”税率和全国性税率）
- 税率范围从 0% 到 200% 以上
- 范围认定精确界定涵盖哪些产品
- AD 关税在所有其他关税之外另行征收
- 区分现金保证金率与最终核定率
- 如范围覆盖看似合理但不明朗，触发 AD/CVD 范围歧义审查

---

### F. 反补贴税（CVD）

为抵消外国政府向其生产商/出口商提供的补贴而征收的附加关税。

**查找方法：**
```
web_search("site:trade.gov countervailing duty order {产品} {国家}")
web_search("site:federalregister.gov countervailing duty order {产品} {国家}")
web_search("Commerce scope ruling {产品} {国家} countervailing")
```

**要点：**
- CVD 税率通常也因公司而异
- 可与 AD 关税同时适用
- 如两者均存在，范围与 AD 令一致
- 区分现金保证金率与最终核定率

---

### G. 货物处理费（MPF）

CBP 对大多数正式报关征收的费用——不是关税（19 CFR § 24.23）。

**费率结构：**
- 按货物申报价值的**从价费率**
- 适用**每票最低**和**每票最高**门槛
- 正式报关（价值 >2,500 美元）和非正式报关的费率结构不同

**查找当前费率：**
```
web_search("CBP merchandise processing fee {当前年份}")
web_search("19 CFR 24.23 merchandise processing fee rate {当前年份}")
```

**重要：** 不要硬编码 MPF 美元金额。从价费率、最低和最高门槛会定期调整。呈现前务必通过 web_search 核验当年费率。

---

### H. 港口维护费（HMF）

对海运货物按海关价值征收的费用——不是关税（26 U.S.C. § 4461）。

**费率结构：**
- 按货物海关价值的**从价费率**
- **仅适用于海运**（不适用于空运或陆路边境）
- 由进口商通过 CBP 缴纳

**查找当前费率：**
```
web_search("harbor maintenance fee rate {当前年份}")
web_search("HMF harbor maintenance fee CBP {当前年份}")
```

**重要：** 不要硬编码 HMF 费率。务必通过 web_search 核验当年费率。

---

## 汇总格式

以分项表格呈现总关税：

```
税率汇总
HTS 子税号：{XXXX.XX.XXXX}
原产国：{国家}
分析日期：{日期}
HTS 修订版：{所选修订版}
HTS 来源：{目录/来源 URL 和 JSON URL}

| 组成部分 | 税率 | 依据 | 备注 |
|-----------|------|-----------|-------|
| 第 1 栏普通 | X.X% | HTSUS {子税号} | MFN/NTR 税率 |
| 第 301 条 | XX% | 9903.XX.XX | 清单 {N}，生效日期 {日期} |
| 第 232 条 | XX% | 9903.XX.XX | {产品类型}，生效日期 {日期} |
| AD 关税 | XX.XX% | A-{XXX}-{XXX} | {公司/所有其他税率} |
| CVD 关税 | XX.XX% | C-{XXX}-{XXX} | {公司/所有其他税率} |
| **估计总关税** | **XX.XX%** | | **所有关税组成部分之和** |
| MPF（费用） | rate%（每票最低/最高——核验） | 19 CFR § 24.23 | 正式报关费用 |
| HMF（费用） | rate%（核验） | 26 U.S.C. § 4461 | 仅海运 |

特别计划税率：{税率}，计划代码 {计划代码}——如原产符合资格
```

---

## 叠加规则

关税**叠加**（相加）：
- 普通税率 + 第 301 条 + 第 232 条 + AD + CVD = 总计
- 示例：2.5% 普通 + 25% 第 301 条 + 10% AD = 总计 37.5%

关税**不**复合（不对关税征收关税）：
- 每项关税按**海关价值**（成交价值）计算，而非按含税价格

---

## 核验检查清单

在呈现税率汇总前，核验：

- [ ] 正确的 HTS 子税号（包括统计后缀）
- [ ] 原产国已确认
- [ ] 来自 Data.gov 的 HTS 来源记录已完成或记录了后备来源
- [ ] 第 1 栏普通税率来自现行 HTS 修订版或实时 REST 确认
- [ ] 所有适用的第 99 章附加费已识别
- [ ] 已针对特定产品-国家组合检查 AD/CVD 令
- [ ] 特别计划资格已评估（如原产符合资格）
- [ ] 已审查 HTS 数据中的脚注以获取交叉引用
- [ ] `additionalDuties` 和 `addiitionalDuties` 已审查
- [ ] MPF 费率/最低/最高已对照当年来源核验
- [ ] HMF 费率已核验（仅海运）
- [ ] 数据时效性：所有费率已对照当年来源核验
- [ ] 证据台账已完成，附来源标签和提取日期
