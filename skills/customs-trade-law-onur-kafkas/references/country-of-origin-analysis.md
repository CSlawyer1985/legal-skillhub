# 原产地分析

## 概述

原产地的确定因目的不同而不同。本方法涵盖可能适用于同一进口货物的三种原产地分析：

1. **标记原产地**——产品必须如何标记？（19 CFR 第 134 部分）
2. **FTA 原产地**——产品是否符合优惠税率资格？（FTA 特定规则）
3. **TAA 原产地**——产品是否符合政府采购资格？（《贸易协定法》）

在得出结论之前，绘制所有国家、加工步骤、已知的供应商/设施事实以及原产地确定的目的。按照 `references/agentic-research-protocol.md` 创建证据台账条目。

---

## 1. 标记规则（19 CFR 第 134 部分）

### 法律框架
- 依据：美国法典第 19 编第 1304 条；19 CFR 第 134 部分
- 要求：进口到美国的外国原产地每件物品都必须标记其原产地
- 标记必须**醒目**、**清晰**、**不易擦除**且**永久**

### 实质性改变测试
标记的原产地是物品经历**最后一次实质性改变**的国家——即将其转变为具有新名称、特征或用途的新颖不同商业物品的制造过程。

**分析步骤：**
1. 绘制涉及所有国家的制造过程
2. 识别物品获得其**本质特征**或**最终身份**的地点
3. 提问：在哪个阶段出现“新颖不同的商业物品”？
4. 发生该转变的国家即为标记原产地

**搜索 CBP 指导：**
```
web_search("CBP country of origin marking {product type}")
web_search("19 CFR 134 substantial transformation {product}")
web_fetch("https://rulings.cbp.gov/search?term=country+of+origin+{product}&collection=ALL&commodityGrouping=ALL&sortBy=DATE_DESC&pageSize=30&page=1")
```

### 特殊规则
- **USMCA 标记规则：**对于来自加拿大/墨西哥的货物，可能适用特定的 USMCA 标记规则（19 CFR 第 102 部分）
- **纺织/服装：**根据 19 CFR § 102.21 的特殊原产地规则
- **管道和管件：**特定的实质性改变规则
- **组装产品：**组装作业是否构成实质性改变取决于其复杂程度

### 标记例外
某些物品豁免个别标记要求（19 CFR § 134.32）：
- 无法标记的物品
- 标记会受损的物品
- 粗原料
- 供进口商自己使用（非转售）进口的物品

## 2. FTA 原产地规则

### 一般框架
每个 FTA 都有其自己的原产地规则，必须满足才能获得优惠关税待遇。常见的原产地标准包括：

**A. 完全获得或生产**
- 完全在 FTA 国家种植、开采、收获或生产的产品
- 无非原产材料

**B. 关税税则归类改变规则**
- 产品因在 FTA 国家生产而发生规定的税则归类改变（在章、品目或子目层面）
- 示例：要求“由任何其他章改变为品目 6204”的规则意味着输入材料必须来自第 62 章之外

**C. 区域价值含量（RVC）**
- 产品价值的特定最低百分比必须原产于 FTA 区域
- 两种常见计算方法：
  - **交易价值法：** RVC = (TV - VNM) / TV × 100
  - **净成本法：** RVC = (NC - VNM) / NC × 100
- 其中 TV = 交易价值、NC = 净成本、VNM = 非原产材料价值

**D. 特定加工规则**
- 一些 FTA 要求特定的制造作业（如化学反应、染色、印刷）

### USMCA（加拿大/墨西哥）——关键条款
```
web_search("USMCA rules of origin {HTS heading} tariff shift")
web_search("USMCA regional value content {product type}")
```
- 需要 USMCA 原产地证书
- 汽车规则：特定的劳动价值含量和钢/铝采购要求
- 微量（de minimis）规则：非原产材料一般为交易价值的 10%

### 其他现行 FTA
使用 `references/fta-program-codes.json` 识别适用的 FTA。然后：
```
web_search("{FTA name} rules of origin {HTS chapter} rule")
web_search("{FTA name} product-specific rule {heading}")
```

### 文档记录
- FTA 原产地证书（格式因协议而异）
- 进口商知情/申报
- 原产地确定记录保存 5 年

## 3. 《贸易协定法》（TAA）——政府采购

### 法律框架
- 依据：美国法典第 19 编第 2511-2518 条
- 适用于：美国政府采购（联邦机构必须购买符合 TAA 的产品）
- 管理机构：总务管理局（GSA）

### TAA 实质性改变测试
与标记原产地类似，但专门用于政府采购资格：

1. 产品必须在**TAA 指定国家**制造或实质性改变
2. TAA 指定国家包括：美国、FTA 伙伴、WTO 政府采购协定国家、加勒比盆地国家和最不发达国家
3. **中国不是 TAA 指定国家**——中国原产地产品不符合 TAA

### TAA 分析步骤
1. 确定产品在何处**实质性改变**（与标记原产地相同的测试）
2. 检查该国是否在**TAA 指定国家清单**上
3. 如在非指定国家实质性改变 → 不符合 TAA
4. 如在指定国家实质性改变 → 符合 TAA

```
web_search("TAA designated country list {current_year}")
web_search("TAA substantial transformation {product} {country}")
web_search("Trade Agreements Act compliance {product type}")
```

### 常见 TAA 问题
- 在 TAA 指定国家用中国组件组装的产品：仅当组装构成实质性改变时才符合 TAA
- 混合原产地供应链：分析最后一次实质性改变发生的地点
- 软件/IT 产品：实体制造地点起控制作用，而非软件编写地点

## 多国供应链分析

对于供应链复杂、涉及多国的产品：

### 第 1 步：绘制供应链
记录每个制造步骤及其发生国家：
```
A 国：原材料开采/生产
B 国：部件制造
C 国：子组件生产
D 国：最终组装和精加工
```

### 第 2 步：识别转变点
在每一步评估是否发生实质性改变：
- 该作业是否创造“新颖不同的商业物品”？
- 物品是否获得新的名称、特征或用途？
- 该作业是否不仅仅是简单的组装、包装或测试？

### 第 3 步：为每种目的确定原产地
- **标记：** 最后一次实质性改变的国家
- **FTA：** 适用特定 FTA 的原产地规则（税则归类改变、RVC 等）
- **TAA：** 最后一次实质性改变的国家——必须是 TAA 指定国家

### 第 4 步：标记复杂情况
触发 `references/human-review-triggers.md` 标记：
- 转变点不明确的多国供应链
- 来自贸易关系不断变化国家的产品
- UFLPA 风险（与新疆的供应链联系）
- 供应商/设施身份缺失，而 UFLPA 或 PGA 准入取决于供应链事实

---

## UFLPA / 强迫劳动叠加

当原产地、供应链、产品类型或用户请求提示强迫劳动风险时，运行本筛查：

1. 识别提供的所有国家、地区、供应商、制造商和原材料来源。
2. 检查官方 CBP/DHS UFLPA 指导、UFLPA 实体清单材料和 WRO 来源。
3. 将 XUAR 联系、列名实体、棉花、多晶硅、番茄产品和其他优先领域视为高风险。
4. 如供应商/设施数据缺失，不得放行产品。说明缺口，并在无法排除风险时触发人工审查。

---

## PGA 原产地关联筛查

一些原产地结论与 PGA 准入或文档交互：

- 农业、植物、动物：USDA/APHIS 和国家特定准入
- 食品、药品、化妆品、医疗器械：FDA 进口要求
- 野生动物/渔业产品：FWS/NMFS 和受保护物种要求
- 化学品、车辆、发动机、农药：EPA 和 DOT/NHTSA/PHMSA 规则

使用官方 PGA 来源，并在产品事实不足以排除其适用时，将潜在适用性作为标记呈现。

## 输出格式

将原产地分析呈现为：

```
原产地分析
产品：{描述}
供应链：{A 国 → B 国 → C 国}

| 目的 | 原产地 | 依据 | 国家状态 |
|---------|--------|-------|----------------|
| 标记（19 CFR 134） | {国家} | 在{步骤}实质性改变 | 不适用 |
| FTA（{计划}） | {国家} | {税则归类改变 / RVC / 特定规则} | {符合/不符合} |
| TAA（政府采购） | {国家} | 在{步骤}实质性改变 | {指定/未指定} |
| 第 301 条 | {国家} | 关税目的的原产地 | {适用/不适用} |
```

附一个紧凑的证据/时效区块，列出所使用的官方来源、检索日期、来源标签和未解决的供应商/设施缺口。
