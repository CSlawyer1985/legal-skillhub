# 代理研究协议

## 目的

本协议控制所有贸易法工作流的来源选择、证据质量、来源时效和幻觉风险。在作出任何法律结论之前使用它。

## 权威层级

适用 `SKILL.md` 和 `references/formatting-standards.md` 中陈述的层级：

1. HTSUS 法律文本：标题、章节注释、章注、美国附加规则、GRI（归类总则）。
2. CAFC（联邦巡回上诉法院）判决。
3. CIT（国际贸易法院）判决。
4. CBP HQ 裁决。
5. CBP NY 裁决。
6. CBP《知情合规出版物》和官方机构指南。
7. 次级评论。

次级来源可以引导研究，但不能确立法院判决的裁判要旨、裁决的推理、现行税率或机构要求的范围。

## 证据质量标签

对证据台账中的每个来源使用以下标签之一：

| 标签 | 含义 | 允许的用途 |
|---|---|---|
| **已获取（Retrieved）** | 已访问并审查完整来源文本或数据文件。 | 可支持法律结论和简短引用。 |
| **已核实（Verified）** | 已获取完整来源文本，并将相关命题与元数据、当前状态或另一官方来源交叉核对。 | 对结论、裁判要旨和引述推理的最强支持。 |
| **已识别（Identified）** | 已找到来源的存在、引文、标题或元数据，但未获取全文。 | 可证明来源存在；不能支持裁判要旨、税率或关键引语。 |
| **未核实（Unverified）** | 来源由搜索结果、片段、次级来源或用户提供的引文提及，但未获取。 | 仅作为线索或限制使用；不得依赖。 |

对 CROSS 和法院意见，"关键引语"要求**已获取**或**已核实**状态。对税率和 HTS 修订选择，优先**已核实**状态，因为时效性是结论的一部分。

## 证据台账

对每个实质性结论维持一个紧凑台账：

```text
证据台账
- 结论：{归类 / 税率 / 原产地 / 范围 / PGA / UFLPA 要点}
- 来源：{官方标题和 URL}
- 权威层级：{HTSUS / CAFC / CIT / CBP HQ / CBP NY / 机构 / 次级}
- 证据标签：{已获取 / 已核实 / 已识别 / 未核实}
- 获取日期：{日期}
- 时效性：{现行修订 / 当年来源 / 发布日期 / 过期风险}
- 支持的命题：{来源实际支持的内容}
- 限制：{如有}
```

对长交付物，将台账放在来源附录中，并在主分析中使用简短证据注释。

## 来源时效规则

- **HTS：** 记录所选修订版、JSON URL、目录检查/采集日期（如可用）和分析日期。
- **第99章：** 通过官方来源核实当前状态和排除情形；税率和排除会变化。
- **CROSS：** 在依赖推理之前实时搜索并获取个别裁决。
- **CIT/CAFC：** 获取意见文本，并在影响结论时检查后续历史。
- **反倾销/反补贴（AD/CVD）：** 通过商务部/ITA、《联邦公报》、ACCESS 或官方指令（如可用）核实当前命令/范围和税率。
- **MPF/HMF：** 核实当年税率和门槛；不要硬编码。
- **FTA/TAA/PGA/UFLPA：** 核实当前官方计划或机构指南。

## 获取纪律

1. 从官方来源开始。
2. 仅在官方来源不可访问时，使用次级来源识别主要来源或解释背景。
3. 如无法获取来源，说明该限制并降级证据标签。
4. 不要从判例摘要（headnote）、文章、搜索结果或案卷标题推断裁判要旨。
5. 在未检查撤销、修改、修正、到期或上诉之前，不要从旧裁决或通知推断当前法律状态。

## 幻觉控制

- 不得编造 HTS 文本、裁决编号、简易意见编号、AD/CVD 案件编号、税率、生效日期、排除日期或机构要求。
- 不得凭记忆"填补"缺失的章节注释。
- 除非来源已获取，不得引用来源语言。
- 如搜索结果不一致，呈现冲突并通过权威层级和时效性解决。
- 当无法获得当前来源时，陈述"未核实"，而不是用貌似合理的税率或规则替代。

## 人工审查联动

证据台账起草后运行 `references/human-review-triggers.md`。在以下情形触发审查：

- 证据不足以支撑法律结论。
- 结论依赖缺失的事实。
- 权威相互冲突。
- 税率、排除、裁决、命令或机构要求的当前状态未解决。
