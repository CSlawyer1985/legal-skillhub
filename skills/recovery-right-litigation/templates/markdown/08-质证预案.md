# 质证预案

**案件**：甲公司诉周某追偿权纠纷　**性质**：起诉前预判稿——对被告可能的抗辩与举证逐项准备应对；正式质证意见须待被告实际举证后经第09号文书门控生成

## 一、被告可能抗辩及应对

### 抗辩一：诉讼时效已过（预判概率最高）
- 预判内容：七笔垫付均发生于2015-2017年，起诉时已超三年。
- 应对要点：（1）第七笔（2017-01-31，21,349.51元）任何口径下均未届满；（2）主张时效起算应结合担保债务整体清偿状态与对账确认过程认定【待人工法律复核：起算规则的现行法依据待人工复核注入】；（3）举证责任分配——被告须对时效届满承担初步举证；（4）继续检索催收凭证补强。
- 底线预案：若前六笔时效抗辩成立，本金可得支持部分收缩至21,349.51元＋对应利息；委托人须在起诉前知悉该敞口（详见法律意见书第四节）。

### 抗辩二：担保关系不存在／担保函非我所知
- 预判内容：担保函系原告与银行之间文件，被告未签字，与己无关。
- 应对要点：（1）《补充协议》由被告签署，其中明确约定原告向贷款银行提供担保（回购担保）及代偿后的追偿安排（《购机合同卷》第10页），被告对担保结构明知且同意；（2）代偿证明书系贷款银行出具，与借款合同借据号一致（《贷款本息代偿证明书》正文）；（3）尽快补入担保函原件（缺失清单第1项）。

### 抗辩三：代偿金额不实／未实际支付
- 预判内容：代偿证明书日期空白、无付款凭证，质疑垫付真实性。
- 应对要点：（1）银行作为收款方出具证明书，其确认效力高于单方陈述；（2）七笔金额与原告账务十四笔代垫记录逐笔勾稽一致（每期两订单各半，尾差0.01元四舍五入）（《对账明细卷》工作表：建起-账务明细）；（3）银行回单补证（缺失清单第2项）；（4）必要时申请法院向银行调查核实。

### 抗辩四：利率过高应予调减
- 预判内容：日万分之八折年约29.2%，超出保护上限。
- 应对要点：（1）该约定系被告自愿签署的商事安排；（2)同时准备日万分之五备选口径（利息217,204.54元）与法定利率口径的階梯计算，庭上按法庭倾向切换【待人工法律复核：上限规则待人工注入】。

### 抗辩五：设备质量／未交付抗辩
- 预判内容：以设备存在质量问题或未验收为由拒付。
- 应对要点：（1）本案系追偿之诉，请求权基础为担保代偿而非货款，质量争议与银行贷款清偿义务分属不同法律关系；（2）被告2013年提货后持续使用多年从未书面异议（卷内无任何异议记录）；（3）质保条款对异议期限有明确约定（《购机合同卷》第2页-第七条）。

### 抗辩六：部分款项已由第三方偿还
- 预判内容：以钱某曾代付为由主张欠款不实。
- 应对要点：来款分解明细显示钱某2013-08-30所付197,250.80元已全额分解至首付款、保险费等项（《对账明细卷》工作表：建起-还款明细），发生于全部垫付之前，与代偿款无关。

## 二、对被告可能提交证据的质证准备

| 预判证据 | 质证方向 |
| --- | --- |
| 还款流水 | 核对是否已在878,245.80元已付款中分解；防止重复抵扣 |
| 与原告业务人员的沟通记录 | 主体权限（是否有权代表原告作出减免承诺）、真实性、完整性 |
| 设备质量凭证/维修记录 | 关联性——与担保代偿之诉无关；异议期限已过 |
| 时效抗辩类证据（如原告长期未催收的消极事实主张） | 消极事实不能仅凭无记录推定；催收凭证补强后正面回应 |

## 三、质证纪律

1. 所有质证意见按"真实性→合法性→关联性→证明力"四步展开，先固定形式异议再谈实体；
2. 对被告举证中含对账函签认件的，第一时间核对签字真伪与签署日期（直接影响时效）；
3. 庭审现场不得脱离本预案作出数额让步表态，调解让步须另行取得委托人书面授权；
4. 本预案为预判稿，正式质证意见的生成条件与规则见《条件性正式质证意见生成门》。
