# 条件性正式质证意见生成门

**案件**：甲公司诉周某追偿权纠纷　**性质**：流程门控文书——本文书本身不含质证意见，仅定义正式质证意见的生成条件与规则（未满足即关闭）

## 一、门控原理

正式质证意见针对**对方实际提交的证据**发表，在被告举证之前任何"正式质证意见"都是无的放矢。本案现处起诉前，被告未举证，故只存在《质证预案》（第08号，预判层），不存在正式质证意见。满足下列全部条件前，禁止生成任何冠以"质证意见"名义的对外文书。

## 二、生成条件（全部满足方可开门）

| 条件 | 内容 | 核验方式 |
| --- | --- | --- |
| 条件1 | 案件已立案且进入举证程序 | 受理通知书＋举证通知书在卷 |
| 条件2 | 被告已实际提交证据并经法院送达我方 | 证据副本＋送达记录在卷 |
| 条件3 | 每份对方证据已逐页阅看原件或经核对的副本 | 阅卷记录；禁止仅凭目录发表意见 |
| 条件4 | 我方补证状态已更新（担保函、回单、时效中断证据到位情况） | 《材料缺失清单》复核版 |
| 条件5 | 人工法律复核已终签（时效、利率、管辖三项结论落地，条文注入） | 复核签署记录 |
| 条件6 | 质证口径与《质证预案》冲突处已经办律师书面确认取舍 | 预案修订记录 |

## 三、生成规则

1. 逐份质证：每份证据单独出具"真实性／合法性／关联性／证明力"四项意见，禁止合并笼统表述；
2. 事实句必须带卷内定位；对方证据引用其举证编号；
3. 涉及时效的证据（尤其对账函签认件、催收回执）先行单独评估，其质证口径由经办律师专项确认后方可写入；
4. 不得出现结果预测性表述；不得引用未经终签复核的法律条文；
5. 生成后的正式质证意见须经人工法律复核终签后方可对外使用，本门不因庭期紧迫而旁路。
