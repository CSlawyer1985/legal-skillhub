# 追偿权四条主路线

| 路线 | 最低闭合事实 | 硬缺口（触发暂停） |
|---|---|---|
| 保证人履责追偿 | 主债务、保证关系、保证人实际履责、履责范围与对象一致 | 无付款/代偿原始凭证，或履责对象无法与主债务对应 |
| 反担保追偿 | 上游担保关系、上游实际履责、反担保合同、反担保范围与期间 | 只见反担保文本但无上游履责，或主体/范围错位 |
| 受让或代位追偿 | 明确的受让、代位或权利承接依据及其范围 | 仅有第三方付款——不得自动推定债权转让或代位 |
| 内部份额追偿 | 共同义务基础、各自份额、超额履行及未获清偿部分 | 无共同义务或份额依据，或可能重复受偿 |

## 判定纪律

1. 从实际履责凭证出发正向判定，不从预设诉状反推；
2. 银行按揭担保（回购担保）场景：出卖人代偿月供与履行回购义务均属履责，追偿依据落在补充协议追偿条款文义内；
3. 债权转让备位条款存在但无《债权转让通知书》时，受让路线仅作备位登记，不得现行主张；
4. 无法排除两条互斥路线、决定性文件不可读或事实冲突时暂停路线判定并登记。

## 双被告结构（本案由高频形态）

存在真实反担保人时为"债务人＋反担保连带保证人"双被告：对债务人走履责追偿，对保证人走保证书连带责任；**保证期间是硬期限**（例：保证期间约定至借款合同履行期限届满二年内，须逐日倒算并在阶段计划中登记起诉截止日）。
