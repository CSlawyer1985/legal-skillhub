本 skill 帮助用户**快速、准确地查找《中华人民共和国民法典》及相关司法解释的条款原文**，并标注权威来源，便于在法律文书、 memo、检索报告中直接引用。

## 一、知识库构成

| 文件 | 内容 | 来源 |
|---|---|---|
| `references/civil_code.md` | 《民法典》全文，1260条，按编/分编/章/节/附则结构化（含7编、8分编、84章、37节、附则） | 用户提供的威科导出版本，已抽校5条关键条文与华宇元典官方版本一致 |
| `references/judicial_index.md` | 民法典相关司法解释索引：全称、法释号、施行日期、关联编/领域、华宇元典 `yuandian_id`（共38件现行有效，含人格权编及生态环境等专门领域） | 华宇元典法律数据（yuandian-mcp）多关键词检索去重、核验 |

> 民法典条文为**本地静态文本**，可离线检索；司法解释条文通过**华宇元典 MCP 实时获取权威全文**（需 MCP 在线）。

## 二、触发条件

满足以下任一情形即启用本 skill：
1. 用户要求查找/引用/核对《民法典》某一条、某一编、某一章、某一节原文（如"民法典第五百零九条""民法典侵权责任编"）。
2. 用户要求查找/引用/核对民法典相关司法解释条款（如"担保制度解释第X条""合同编通则解释关于格式条款""建工解释二""法释〔2023〕13号"）。
3. 用户提及"民法典""司法解释""法释〔〕"等关键词并指向具体条文。

## 三、民法典条文检索流程

1. **定位文件**：`references/civil_code.md`。
2. **检索方式**（优先用 Grep，避免整文件载入）：
   - 按条号：`grep "第一千一百六十五条"`（汉字条号，如"第五百零九条"）。
   - 按关键词：`grep "行为人因过错侵害"`。
   - 按编/章：文件以 `# 第一编 总则`、`## 第一章 基本规定`、`### 第一节` 层级组织，可 Grep 标题定位后 Read 上下文。
3. **输出**：直接呈现该条全文；如需连续多条，逐条列出。
4. **交叉核验（可选/正式引用前建议）**：对关键条文，可用 `yuandian_rh_ft_search(fgmc="中华人民共和国民法典", keyword="<条文特征句>")` 比对华宇元典官方文本；民法典权威 id 见 `judicial_index.md` 顶部。

## 四、司法解释条文检索流程

1. **查索引定位**：在 `references/judicial_index.md` Grep 目标解释（按名称关键词或法释号），取得其 `yuandian_id`、法释号、施行日期。
2. **取权威全文**：调用 `yuandian_rh_fg_detail(id="<yuandian_id>")`，返回法规基础信息 + 全文 `content`。
3. **定位条文**：在返回全文内按"第X条"或关键词定位，摘录对应条文。
4. **输出**：呈现条文原文，并标注 `法规全称 + 法释号 + 施行日期 + 来源：华宇元典法律数据`。
5. **MCP 不可用时**：明确告知用户"当前无法连接华宇元典，无法在线核验司法解释条文"，并建议用户自行通过最高法院官网核对；不得凭记忆编造司法解释条文或法释号。

## 五、输出规范

- **条文原文=事实**：直接引用，注明来源（民法典＝`civil_code.md`；司法解释＝全称+法释号+施行日期+华宇元典）。
- **分析/解读=观点**：如用户进一步要求分析，须明确区分"法条原文"与"本人法律分析"，分析须说明依据与推理，不得把观点包装为事实（遵循用户既定工作规则）。
- **结构清晰**：多条文时使用编号/表格；跨编引用时标注所属编。
- **不编造**：不得臆造条号、条文内容、法释号、施行日期；索引中未列的解释，须先经 `yuandian_rh_fg_search` 核验再引用。
- **内部信息绝不出户**：本 skill 仅在内部记录整理人信息（见"内部整理人信息"节）。**任何对外输出（条文原文、检索报告、法律分析、来源标注、文件页脚/落款等）一律不得包含**整理人姓名、机构（浙江金道律师事务所）、微信号（13967182079）等内部信息；对外引用来源仅标注"《中华人民共和国民法典》/ 华宇元典法律数据"等权威出处。

## 六、风险提示

- 本地 `civil_code.md` 提炼自用户提供之威科导出版本，已抽校关键条文与官方一致；**正式法律文书引用前，仍建议以全国人大公布的官方文本作最终核对**。
