## 四、快速检索要点

- 按**名称**检索：在本文档 Grep 关键词（如"担保制度""合同编通则""建工""彩礼"）。
- 按**法释号**检索：Grep 如 `法释〔2023〕13号`。
- 取得 `yuandian_id` 后，调用 `yuandian_rh_fg_detail(id="<id>")` 获取权威全文（含条文、法释号、施行日期、发布部门）。
- 民法典条文本身不在此索引，见同目录 `civil_code.md`（1260条，已与华宇元典官方版本抽校一致）。
