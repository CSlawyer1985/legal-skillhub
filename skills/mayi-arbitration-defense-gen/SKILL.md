# 劳动仲裁答辩状生成器

> 生成劳动仲裁答辩状，含抗辩理由和证据清单

## 触发场景

用户询问劳动合同、规章制度合规、裁员、仲裁、竞业限制等HR合规问题时触发。

## 核心能力

| 能力 | 说明 |
|------|------|
| 参数输入 | 支持交互式输入所需参数 |
| 智能计算 | 基于最新政策法规自动计算 |
| 结果输出 | 生成结构化结果和说明 |
| 合规校验 | 内置合规规则校验 |

## 使用方式

```bash
python scripts/main.py
```

按提示输入相关参数，获取计算结果和说明。

## 参数说明

根据具体场景，用户需提供以下参数：
- 适用地区/城市（影响政策标准）
- 相关金额数据（工资/基数/比例等）
- 时间范围（月份/年度）

## 输出示例

```

====================================
计算依据：[相关政策法规]
```
