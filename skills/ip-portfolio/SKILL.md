# 知识产权组合管理（中国法）

## 任务目标
- 本 Skill 用于:管理组织知识产权组合的注册、续展、年费缴纳及使用状态追踪
- 能力包含:期限报告、资产添加、缴费记录、注册簿审计（含撤三风险扫描）
- 触发条件:用户询问续展期限、添加资产、记录年费缴纳、或审计注册簿缺口

## 前置准备
- 注册簿文件 `portfolio.yaml` 存放于当前工作目录；如不存在，按模式1初始化
- 非标准文件:无额外依赖

## 操作步骤

### 默认行为（无参数）
等同于 `--report`，展示未来90天内到期的事项，按紧急程度分组（已过期/宽限期、即将到期、即将来临、代理管理中、未知）。

### 模式1:初始化

当注册簿不存在或使用 `--rebuild` 时运行。

**步骤1:确定数据来源**

- **已连接知识产权管理系统**（智慧芽、大为、合享、incopat 等）:通过系统集成拉取组合数据。知识产权管理系统为权威来源；本注册簿仅作镜像，不添加系统未包含的期限。
- **无管理系统但有电子表格/导出文件**:请用户分享导出数据，导入已有内容；缺少注册日期或授权日期的资产标记为 `unknown`。
- **无任何数据**:逐项交互录入——类型、管辖区域、编号、关键日期、权利人。

**步骤2:逐项计算期限**

适用本文件顶部规则。填充 `next_deadlines`，仅存最近2-3个即将到期的事项，远期期限（如数十年后的续展）在报告时按需计算而非提前存储。

**无法确定计算规则的资产:**
- 未知管辖区域规则 → 在 `custom_rules` 下添加占位条目，标记资产 `agent_managed: true`，并注明需与当地代理确认。
- 缺少计算所需日期（专利无授权日、商标无注册日）→ 置 `next_deadlines` 为空，在 `notes` 中注明，初始化摘要中列为 `unknown`。

**步骤3:写入注册簿**

生成 `portfolio.yaml`，展示摘要:

```
知识产权组合注册簿已初始化。

资产总数: [N]
  商标:     [N]  ([N 已注册] / [N 申请中])
  专利:     [N]  ([N 已授权] / [N 申请中])
  著作权:   [N]
  外观设计: [N]
  域名:     [N]

已计算期限: [N]
代理管理/管辖区域待确认: [N] — 请与境外代理确认
未知（缺少关键日期）: [N] — 补充后方可依赖报告

运行 --report 查看到期事项。
```

### 模式2:报告

```
--report [--days 30|60|90|180]
```

默认窗口90天。生成报告前刷新所有资产的计算期限，不要仅依赖存储日期。

输出:

```
知识产权组合期限报告 — [日期]
[公司名称] — 窗口: 未来 [N] 天

已过期/宽限期内 ([N])
  [资产ID] / [管辖区域] / [类型] / [名称]
    [操作] — 原到期日 [日期]，宽限期截止 [日期]
    状态: [宽限期 / 已过期]

[N] 天内到期 ([N])
  [资产ID] / [管辖区域] / [类型] / [名称]
    [操作] — 到期日 [日期]
    依据: [如"注册日起第10年"]
    [代理: 机构 / 案号 — 如有]

即将来临（超过30天但在[N]天内）
  [列表]

代理管理中 ([N])
  [资产ID] / [管辖区域] — 由 [当地代理] 管理；请直接确认
  [资产ID] / [管辖区域] — 未记录当地代理；使用 --update 添加

未知 ([N])
  [资产ID] — 缺少 [字段]；无法计算期限

请在依赖本报告前，向国家知识产权局商标查询系统/中国专利公布公告系统/相关登记机构核实各期限。

汇总
  追踪资产总数: [N]
  窗口内期限数: [N]
  最近审计: [日期]
```

报告末尾附加免责声明: *"根据注册簿计算。请在缴费或续展前，向国家知识产权局或相关登记机构核实各期限。"*

如报告列出超过约10项资产，或用户要求时:提供仪表板——按注册状态统计（有效/宽限期/已失效/申请中）、期限时间线、可排序组合表格。

### 模式3:添加

```
--add
```

交互式添加单项资产。依次询问:
1. 类型（商标/专利/著作权/外观设计/域名）
2. 管辖区域
3. 名称/发明名称
4. 权利人（登记权利人——影响续展和转让）
5. 关键日期（按类型:申请日、注册日、授权日、优先权日、到期日）
6. 编号
7. 类别/权利要求数
8. 来源——是否在知识产权管理系统中以案号追踪？
9. 外部代理/境外代理（如有）
10. 业务负责人（产品线、品牌经理）

录入后:
- 按本文件规则计算下一期限。
- 如管辖区域规则未内置，走 `custom_rules` 录入流程（见下文）。
- 追加至 `portfolio.yaml` 的 `assets:` 下。

**自定义规则录入**

当管辖区域不在内置列表中时:

> 我没有 [管辖区域] / [资产类型] 的维护规则内置记录。
> 让我录入以便后续追踪。
>
> 1. 适用哪些维护事项？（每N年续展？每年年费？使用声明？其他？）
> 2. 到期日的触发基准——申请日、注册日、授权日、国家阶段进入日、或其他纪念日？
> 3. 是否有宽限期？额外费用是多少？
> 4. 是否有境外代理或当地代理管理？

存储于 `custom_rules:` 下，后续同管辖区域资产自动适用。

### 模式4:更新

```
--update
```

#### 后续行动门控

**在记录维护缴费或续展申请已办理之前:**如果用户角色为非法律专业人员:

> 记录商标续展、专利年费缴纳或国际续展为"已办理"具有法律后果。如果记录有误——错过到期日、错误费档、错误使用证据——期限不会顺延，资产仍可能失效。你是否已与实际办理该事项的律师或代理确认（或向国家知识产权局/相关登记机构核实）？如已确认，继续。如未确认:
>
> - 暂不记录为已办理。
> - 以下信息需提交给律师:资产ID、管辖区域、期限类型、知识产权管理系统显示内容、你认为已办理的事项和时间、以及信息来源。
>
> 如需寻找所在管辖区域的持牌律师或其他授权法律专业人士:当地律师协会的转介服务是最快起点（中国:中华全国律师协会或各省律师协会）。

未经明确确认，不得将期限的 `status` 设为 `filed`。状态刷新、报告生成和期限展示不触发此门控。

#### 子模式

**手动更新:**"我们于3月4日办理了商标续展。"更新对应期限: `status: filed`、`filed_date`，并计算生命周期中的下一期限（商标续展后下一个10年期限）。

**从知识产权管理系统同步:**如智慧芽 / 大为 / 合享 / incopat 等已连接，拉取最新案卷并核对。标记注册簿与权威系统之间的不一致——权威系统优先；更新注册簿以匹配，并提示注册簿有而系统没有的内容。

**状态变更:**"将商标 TM-CN-004 标记为已放弃。"更新 `status`，清空 `next_deadlines`，注明放弃日期。

### 模式5:审计

```
--audit
```

超越当月期限的更广泛健康检查:

**期限合规**
- 当前是否有处于 `grace` 状态的期限？（正在进行但产生滞纳金。）
- 是否有 `lapsed` 资产未标记为 `abandoned` 或 `cancelled`？要么恢复要么更新状态。
- 是否有未计算 `next_deadlines` 的资产？要么缺少数据，要么管辖区域未知。

**注册缺口**
- 商标申请超过18个月仍为 `pending`？标记需向商标局查询状态——可能需要答复审查意见。
- 专利申请超过3年仍为 `pending`（发明）？标记需检查审查进度。[模型知识 — 需核验]

**撤三风险（商标专有）**
- 注册商标自注册日起满3年，且 `use_status` 为 `未使用` 或 `不确定`？根据《商标法》第49条第2款，任何人均可申请撤销连续三年不使用的注册商标。[模型知识 — 需核验]
- 接近续展但使用证据不足的商标？续展不要求提交使用声明，但撤三风险持续存在。

**权利人一致性**
- 是否有资产的 `owner` 与当前存续实体不符？标记——可能需要办理转让登记。
- 跨资产的权利人名称不一致（同一实体不同名称）？提示清理。

**到期展望**
- 未来24个月内到期的专利？即使无年费期限，业务方可能需要知晓——产品规划、续展策略、许可窗口。

**未监控资产**
- 已注册商标未在品牌监控清单中？标记为缺口，由律师决定是否添加。

输出:

```
知识产权组合审计 — [日期]

期限合规
  宽限期中: [N] — 立即行动可避免失效
  已失效（未标记放弃）: [N] — 请确认状态
  缺少期限计算: [N] — 补充数据或标记代理管理

注册缺口
  商标申请超过18个月待审: [列表]
  发明专利申请超过3年待审: [列表]

撤三风险（商标）
  注册满3年且使用状态不确定的商标: [列表]

权利人
  权利人名称无法识别的资产: [N]
  权利人名称不一致: [列表]

到期展望（24个月）
  即将到期专利: [列表]

品牌监控
  未纳入监控清单的已注册商标: [列表]

建议行动
  1. [最高优先级]
  2. [次优先级]
```

## 使用示例

- 示例1:
  - 场景/输入:用户询问"我们有哪些商标快要到期了？"
  - 预期产出:展示未来90天内到期商标的续展期限报告，按紧急程度分组
  - 关键要点:需刷新计算期限后再输出，末尾附核实免责声明

- 示例2:
  - 场景/输入:用户要求添加一项新获得授权的发明专利
  - 预期产出:交互式录入发明信息，自动计算年费缴纳期限
  - 关键要点:需确认专利类型（发明/实用新型/外观设计），不同类型年费规则不同

- 示例3:
  - 场景/输入:非法律人员要求将某商标续展标记为"已办理"
  - 预期产出:触发后续行动门控，要求确认与律师或商标局核实
  - 关键要点:门控不可绕过，未确认前不得设为 filed

## 管辖区域与类型规则

维护规则因管辖区域和资产类型而异:

- **中国商标:**注册有效期为10年，自核准注册之日起计算。续展注册应在期满前12个月内办理，每次续展有效期10年。有6个月宽限期。《商标法》第40条。[模型知识 — 需核验] 无使用声明要求（续展不与使用挂钩），但根据第49条第2款，连续三年不使用的注册商标可被申请撤销（撤三）。[模型知识 — 需核验]

- **马德里国际商标（指定中国）:**适用同样的10年续展规则和撤三规则。通过世界知识产权组织国际局办理续展，但撤三应向国家知识产权局提出。[模型知识 — 需核验]

- **中国发明专利:**保护期20年（自申请日起算），需每年缴纳年费。专利权人应当自授予专利权当年开始逐年缴纳年费；逾期未缴年费可享有6个月滞纳期 **，滞纳期内补缴需一并缴纳滞纳金；期满仍未缴纳的，专利权自应当缴纳年费期满之日起终止。《专利法》第42条。[模型知识 — 需核验]

- **中国实用新型专利:**保护期10年（自申请日起算），年费缴纳规则同发明专利。《专利法》第42条。[模型知识 — 需核验]

- **中国外观设计专利:**保护期15年（2021年6月1日后申请的适用；此前为10年），年费缴纳规则同发明专利。《专利法》第42条。[模型知识 — 需核验]

- **中国著作权:**自创作完成之日起自动保护，无需缴费维护。自然人作品:作者终生加50年；法人作品:首次发表后50年。著作权自愿登记可作为权属证据，但非强制。[模型知识 — 需核验]

- **域名:**按注册管理机构及注册商规则按年续展；域名到期后设有30天正常续费宽限期，期满进入约30天高价赎回期，逾期未赎回则域名释放重新注册。

如组合包含上述未列出的管辖区域资产，在注册簿的 `custom_rules` 块中录入维护规则，报告将其标记为 `agent_managed`——与境外代理确认状态，而非本 Skill 无法理解的规则进行计算。

## 注册簿

存放于 `portfolio.yaml`。结构:

```yaml
# 知识产权组合注册簿
# 生成日期: [date]
# 最后更新: [date]
# 免责声明: 计算期限仅供参考 — 向国家知识产权局/相关登记机构或知识产权管理系统核实后方可采取行动。

metadata:
  company: "[公司名称]"
  generated: "[date]"
  last_updated: "[date]"
  last_audit: "[date or null]"
  source_system: "[智慧芽 / 大为 / 合享 / incopat / 手动 / 无]"

custom_rules:   # 非内置管辖区域手动录入
  []

assets:
  - id: "TM-CN-001"
    type: "trademark"                          # trademark / patent / copyright / design / domain
    jurisdiction: "CN"
    mark_or_title: "[商标名称或标题]"
    owner: "[登记权利人——注册实体名称]"
    status: "registered"                       # pending / registered / lapsed / abandoned / cancelled
    application_number: "[申请号或null]"
    registration_number: "[注册号或null]"
    classes: ["9", "42"]                       # 商标:尼斯分类; 专利:IPC分类号; 其他:null
    filing_date: "[YYYY-MM-DD或null]"
    registration_date: "[YYYY-MM-DD或null]"
    priority_date: "[YYYY-MM-DD或null]"
    grant_date: "[YYYY-MM-DD或null]"           # 专利
    next_deadlines:                            # 计算值; --report和--audit时刷新
      - type: "商标续展注册"
        due_date: "[YYYY-MM-DD]"
        grace_end: "[YYYY-MM-DD或null]"
        basis: "注册日起第10年"
        action: "办理商标续展注册申请"
        status: "upcoming"                     # upcoming / due_soon / overdue / grace / filed
    use_status: "in_use"                       # 商标专有 — in_use / not_in_use / uncertain — 驱动撤三风险分析
    cancellation_risk: null                    # 商标专有 — 撤三风险日期或null
    agent_managed: false                       # 境外代理/外部律师管理为true
    local_agent: null
    docket_id: "[知识产权管理系统ID或null]"
    outside_counsel: "[律所或null]"
    business_owner: "[邮箱或团队]"
    notes: ""

  - id: "PAT-CN-001"
    type: "patent"
    patent_type: "invention"                   # invention / utility_model / design
    jurisdiction: "CN"
    mark_or_title: "[发明名称]"
    owner: "[权利人]"
    status: "granted"
    application_number: "[申请号]"
    registration_number: "[专利号]"
    filing_date: "[YYYY-MM-DD]"
    grant_date: "[YYYY-MM-DD]"
    priority_date: "[YYYY-MM-DD或null]"
    expiration_date: "[YYYY-MM-DD]"            # 发明:申请日起20年; 实用新型:10年; 外观设计:15年
    next_deadlines:
      - type: "第[N]年年费"
        due_date: "[YYYY-MM-DD]"
        grace_end: "[YYYY-MM-DD]"
        basis: "申请日起第[N]年"
        action: "缴纳年费（适用费档）"
        status: "upcoming"
    claims_count: 20
    fee_tier: "standard"                       # standard / reduced (drives CNIPA fees)
    docket_id: null
    outside_counsel: null
    business_owner: null
    notes: ""
```

期限状态值 (`next_deadlines`):
- `upcoming` — 超过90天
- `due_soon` — 90天内到期，尚未办理
- `overdue` — 已过主到期日，在宽限期内（如有）
- `grace` — 在宽限期内（显式标记——产生滞纳金）
- `lapsed` — 已过宽限期且未办理；资产实质失效，除非可恢复
- `filed` — 本周期已完成办理

## 期限参考免责声明

> 本 Skill 适用的期限规则反映构建日期时公开可查的要求。知识产权局的要求、宽限期、费用结构和年费安排可能发生变化。**在缴费或续展前，务必向国家知识产权局商标查询系统、中国专利公布公告系统或相关登记机构核实计算期限。**如使用智慧芽、大为、合享、incopat 或其他知识产权管理系统，其案卷数据为权威来源——本追踪器用于组织和展示其数据，而非替代。
>
> 已记录但错误的期限比未记录更危险:它制造虚假安全感。"近期无期限"的输出尤其值得二次核实。

## 集成:续展监控

`ip-renewal-watcher` 代理按计划（默认每周）运行本 Skill 并将模式2报告发送至指定频道。如出现已过期/宽限期项目，代理立即发送通知，不受计划限制。

## 移交

- 接收:来自申请技能的新资产记录（申请提交或商标通过审查时）、来自查新技能的新标记记录（商标采纳并排队申请时）、以及转让登记。
- 发送:向律师发出"现在办理续展"提示——本 Skill 不办理任何事项；它告知律师期限和所需材料。

## 本 Skill 不做的事

- 不办理任何事项。它展示的每项行动均由律师或代理执行。
- 不向国家知识产权局或任何其他登记机构核实期限。它根据用户提供的数据计算。注册簿是工作副本；登记机构是权威来源。
- 不决定是否续展。续展是商业决策——商标是否仍在使用、专利是否仍有价值、域名是否仍重要。本 Skill 展示期限和成本；业务和律师决定。
- 不替代知识产权管理系统处理数百项资产的大型组合。智慧芽、大为、合享、incopat 等系统有直接登记机构数据源、期限自动化和年费支付服务。本 Skill 适合较小型组合，或作为展示权威系统数据的轻量层。
- 不读取登记机构记录验证状态。此处显示为"已办理"意味着有人告知如此——不代表国家知识产权局已受理。请通过国家知识产权局查询系统或知识产权管理系统确认受理。
