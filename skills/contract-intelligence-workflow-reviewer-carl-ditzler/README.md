# 合同情报与工作流审查器

一个适用于 Claude 和 Codex 的合同情报、合同审查和合同运营工作流技能。

目标不是取代法律专业人士对合同的审查。目标是帮助法律、法务运营、采购、合规、隐私、安全和业务团队使用结构化工作流而非临时提示来审查合同。

本技能帮助合同审查者理解什么可能是重要的、异常的和缺失的，以及哪里可能需要谈判、谁应参与审批、下一步应采取什么行动。

## 本技能是什么

本技能结合了：

- 合同审查
- 合同情报
- 剧本（playbook）驱动的分析
- 条款比较
- 偏差评分
- 谈判规划
- 审批路由
- 工作流状态管理
- 合同运营控制
- 质量保证与对标

本技能不是产出一份简单的问题清单，而是遵循一个结构化工作流，旨在镜像成熟法务部门和法务运营团队管理合同审查的方式。

本技能可供法律、采购、合规、隐私、安全和业务团队使用，以提高一致性、争点识别、谈判准备、审批协调和整体合同审查质量。

## 本技能不是什么

本技能不是合同生命周期管理（CLM）平台。

虽然本技能包含 CLM 系统中常见的概念，包括工作流状态、审批路由、剧本管理、合同情报和审查成品，但它不提供企业级 CLM 平台中通常存在的底层基础设施。

示例包括：

- 合同存储库
- 企业数据库
- 电子签名平台
- 自动化工作流引擎
- 续约跟踪系统
- 义务管理系统
- 报告仪表盘
- 企业集成

本技能最好被视为对 Ironclad、Agiloft、DocuSign CLM、Sirion、ContractPodAI、Icertis、Conga 及类似解决方案等 CLM 平台的补充。

## 它审查什么

本技能从法律、业务、运营、合规、隐私、安全、技术和 AI 视角审查合同，而非仅聚焦于合同措辞。

示例包括：

- 商业条款
- 法律风险
- 运营义务
- 合规要求
- 隐私与数据保护
- 信息安全要求
- 知识产权条款
- 供应商与第三方风险
- AI 相关条款
- 治理与报告义务
- 缺失的保护
- 含糊的措辞
- 内部审批要求
- 谈判考量

本技能识别问题、解释其重要性、提供建议，并建议下一步行动。

## 工作流能力

本技能支持一个可能包含以下内容的结构化合同工作流：

1. 设置
2. 受理
3. 分诊
4. 审查
5. 修订（Redline）
6. 谈判
7. 内部审批
8. 可签署
9. 已关闭

视可用信息而定，本技能还可以：

- 标准化剧本
- 将合同与标准比较
- 对偏差评分
- 生成谈判计划
- 识别审批要求
- 产出机器可读的行动输出
- 创建审查成品
- 生成执行摘要

## 目标用户

本技能可能对以下人群有用：

- 法务部门
- 法务运营团队
- 采购团队
- 合同管理人员
- 合规专业人士
- 隐私团队
- 安全团队
- 商业运营团队
- 参与合同审查的业务利益相关方

## 输出

视所提供的文件和指示而定，本技能可能生成：

- 执行摘要
- 关键条款与义务
- 风险评估
- 逐条款发现
- 剧本比较摘要
- 偏差评分
- 谈判计划
- 拟议修订
- 审批路由建议
- 面向内部利益相关方的问题
- 需要律师审查的升级事项
- 行动计划与下一步建议

## 注意事项

输出应始终由适当的法律、合规、隐私、安全、采购或业务利益相关方审查。

本技能可以识别问题并提供分析，但它无法确定每个法域和情形的业务风险承受度、谈判策略、法律结论或监管要求。

对重大交易、监管事项、战略协议和高风险谈判，律师审查仍然必不可少。

## 令牌用量警告

本技能有意做到全面，***可能消耗大量令牌***。

与简单的合同审查提示不同，本技能在生成最终审查前应用多个工作流阶段、审查控制、剧本要求、审批路由逻辑、质量检查、对标标准和输出结构。

在以下情形令牌消耗会增加：

- 审查长篇协议
- 审查多份协议
- 处理大型剧本
- 比较多个合同版本
- 审查附件和附表
- 处理并入文件
- 进行逐条款分析
- 生成详细修订
- 创建谈判计划
- 产出审批包
- 生成结构化审查成品
- 产出综合报告

大型合同加上大型剧本会消耗大量上下文窗口，并导致更高的 LLM 成本。

需要令牌效率时，考虑：

- 分别审查各个部分
- 先使用分诊审查
- 限制支持文件
- 请求针对性分析
- 减少输出细节

## 最佳效果

为获得最完整的审查：

- 尽可能提供完整协议。
- 包含附件、附表、附件材料和被引用的文件。
- 如可用，提供适用的剧本。
- 如可用，提供模板或标准文本。
- 指明被代理的一方。
- 提供相关业务背景。
- 指明具体关切或谈判目标。

当合同和组织的审查标准都可获得时，审查质量显著提高。

## 关于 CLM 能力的说明

在开发过程中，我探索了 AI 技能可以超越传统合同审查多远。

结果包含了许多通常与合同情报、运营和合同生命周期流程相关的功能，包括：

- 结构化受理
- 剧本管理
- 合同情报提取
- 工作流状态
- 审批路由
- 偏差评分
- 谈判规划
- 质量保证控制
- 审查成品
- 机器可读的行动

虽然这些能力通常是 CLM 系统的组成部分，但我发现当前的技能和 LLM 平台仍不太适合许多依赖持久化系统和企业平台的 CLM 能力，例如：

- 合同存储库
- 结构化合同记录
- **持久化合同元数据**
- 工作流引擎
- 义务管理
- 续约管理
- 报告与仪表盘
- 企业集成（尤其是 Salesforce）
- 跨系统同步

因此，本项目聚焦于合同情报、合同审查、工作流指导和决策支持，而非试图取代专用的 CLM 平台。话虽如此，随着模型成熟并改进对更广泛 CLM 能力的支持，该框架可以作为实验的基础。

## 免责声明

本技能提供分析、建议、工作流指导和决策支持信息。

它不提供法律意见，不应被依赖为合格法律顾问意见的替代品。
