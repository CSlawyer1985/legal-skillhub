# 核实工作流——ECCC（柬埔寨法院特别法庭）

本参考是任何 ECCC 引用出现在输出之前进行核实的操作性分步指南。它扩展了 `SKILL.md`"标准工作流"一节。

## 开始之前

将用户的请求读两遍。识别：

1. **哪个法院？**（确认是 ECCC 而非其他法庭——对话可能在多个机构之间切换。）
2. **哪个案件？**（001 / 002 / 002/01 / 002/02 / 003 / 004）
3. **哪种文件类型？**（结案令、起诉书、判决、决定、命令、书状）
4. **该引用支持什么命题？**（具体说明引用的用途。引用存在的意义是支持主张；如果你不知道是什么主张，就无法判断引用是否支持它。）

## 回退阶梯

按顺序逐级工作。仅当上一级失败或返回信息不足时才下移。

### 第一级——eccc.gov.kh

法院自己的网站。对大多数文件而言这是权威来源。

方法：
- 对于已知文件编号，尝试 `web_fetch` 案件页面（如 `https://www.eccc.gov.kh/en/cases/case-002/trial-02`），按编号或标题定位文件。
- 对于已知判决或重大决定，URL 模式 `https://www.eccc.gov.kh/sites/default/files/documents/courtdoc/[日期]/[文件名].pdf` 很常见；日期出现在路径中。
- 对于《内部规则》和基础文本：`https://www.eccc.gov.kh/en/about/legal-framework` 和 `https://www.eccc.gov.kh/en/document/legal/internal-rules`。

"成功"的表现：
- 确认文件编号、标题、日期、审判分庭的页面或 PDF。
- 对于段落精确引用主张，检索内容中实际出现的段落文本。

"部分"的表现：
- 按标题列出文件但不含文件本身的页面。
- 首页确认文件身份、但被引用命题所在的后续段落未在会话中检索到的 PDF。

在任一"部分"情况下，相应地标注核实级别。

### 第二级——legal-tools.org

国际刑事法院法律工具数据库托管 ECCC 文件。当 eccc.gov.kh 缓慢、被屏蔽或返回 403 时有用。文件编号和元数据应与 eccc.gov.kh 一致；如有分歧，以 eccc.gov.kh 版本为准。

方法：
- 按案件名称和文件编号检索。
- 核实元数据（案件、文件编号、日期、审判分庭）与正在核实的引用一致。

### 第三级——人权高专办柬埔寨 / 联合国法治

`https://cambodia.ohchr.org/en/rule-of-law/eccc-decisions` 和 `https://www.un.org/ruleoflaw/`。这些主机有精选的 ECCC 文件子集（尤其是联合国转载的第一级文件）。当 eccc.gov.kh 的 PDF 是同一文件但托管在更易获取的联合国域名上时有用。

### 第四级——第二级来源概述

学术文章、Cambridge Core 国际法律资料、国际刑事司法杂志、柬埔寨法庭监察（Cambodia Tribunal Monitor）。这些不提供文件本身；它们提供文件摘要并附引用。

适合用途：
- 确认重大决定的存在和大致内容。
- 当用户只给了描述时，找到文件编号和日期。

不适合用途：
- 段落精确引用。概述案件 002/02 审判判决第 3445 段的第二级来源本身并不是第 3445 段。概述的命题可能相同，但引用基于的是第二级来源，而非法院文本。

### 第五级——询问用户

如果文件是近期的、经删减的或其他方式无法获取，请用户提供 URL 或副本。不要编造。不要近似。询问的成本是一条短消息；编造的成本是用户提交不准确的引用。

## 部分核实处理

当核实是部分的，输出必须说明。三种惯例：

- **仅存在性核实，段落主张**——弱化为内容级主张，或将段落引用移出命题，放入用户可在提交前核实的"另见"注释。
- **内容已核实，无段落访问**——保留命题；省略段落精确引用；在引用中注明："*（本次会话未检索段落内容——省略段落精确引用）*"。
- **仅存在性核实，宽泛主张**——保留宽泛主张（"审判分庭在本判决中处理了共同犯罪事业"），但不用具体表述（"审判分庭认定共同犯罪事业三型不是习惯国际法"）。只使用核实所支持的特定程度。

工作示例见 `../examples/example-verification.md`。

## 语言纪律

ECCC 文件有三种官方语言：英语、高棉语（ខ្មែរ）和法语。许多决定仅以英语发布。部分基础文本和柬埔寨法律组成部分主要以高棉语存在。

核实时：
- 对指向英文文件的英文引用，英语即可。
- 对依赖柬埔寨原法律文书（如 1956 年《刑法典》、未经修订的《设立法》）的引用，以高棉语版本为准。如果输出依赖英文翻译，予以标记。
- 对同一法院文件的英法版本分歧（罕见但可能），注明分歧并询问用户依赖哪个版本。

## 删减纪律

ECCC 经常对同一文件发布保密版和公开删减版。核实引用时：

- 识别引用所依赖的版本（如有文件编号后缀，它会告诉你）。
- 如果公开删减版包含被引命题，优先使用公开删减版。
- 如果引用依赖公开版中不存在的保密内容，输出必须说明。用户可能合法接触保密书状；模型不能，引用模型看不到的保密段落编号就是编造。

## 当你做对了

一条已核实的引用，到它出现在输出中时，追溯到：

- 项目知识中的基础文本（如果是《联合国-柬埔寨协定》、ECCC 法或《内部规则》），或
- 本次会话中对第一级来源的 `web_fetch`，且相关内容在检索结果中可见，或
- 对第二级来源的 `web_fetch`，如实标注为第二级，并诚实说明核实级别。

任何其他情况都还不是一条引用。
