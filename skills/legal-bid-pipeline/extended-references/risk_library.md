# 法务/服务类标书废标风险库

> 基于实战案例（多个法律顾问投标项目等）和政府采购法/招投标法提取的系统化废标风险模式库。
> v3.0 新增，借鉴 engineering-bid-document-generator 的 55 条风险模式设计思路。

## 一、投标准入类（一票否决，满足则直接废标）

| 编号 | 风险触发条件 | 风险等级 | 规避措施 |
|:---:|-------------|:---:|---------|
| A01 | 营业执照经营范围不含采购项目所属行业 | 🔴 废标 | 投标前核实营业执照范围，必要时变更经营范围 |
| A02 | 特定资质证书缺失（如律师事务所执业许可证、司法鉴定许可证等） | 🔴 废标 | 投标前确认资质齐全且在有效期内 |
| A03 | 资质证书过期（执业许可证、ISO认证、专业资质等） | 🔴 废标 | 标前3个月排查所有资质证书有效期 |
| A04 | 类似业绩数量不达标 | 🔴 废标 | 仔细计算有效业绩（须为投标人自身业绩，子公司/关联公司一般不计） |
| A05 | 业绩证明材料不全（缺合同复印件、缺验收证明、缺中标通知书等） | 🔴 废标 | 按招标文件逐条核对业绩证明材料清单 |
| A06 | 项目负责人资格不满足（执业年限、专业方向、级别等） | 🔴 废标 | 投标前确认指派人员资质与招标要求完全匹配 |
| A07 | 联合体投标但未提供联合体协议 | 🔴 废标 | 联合体投标必须签署联合体协议并明确各方责任 |
| A08 | 被列入失信被执行人/重大税收违法案件当事人名单 | 🔴 废标 | 投标前自行查询信用中国、中国执行信息公开网 |
| A09 | 被列入政府采购严重违法失信行为记录名单 | 🔴 废标 | 投标前查询中国政府采购网 |
| A10 | 3年内有行贿犯罪记录 | 🔴 废标 | 投标前进行内部合规排查 |

## 二、形式要件类（格式不符 = 无效响应）

### 2.1 签字与盖章

| 编号 | 风险触发条件 | 风险等级 | 规避措施 |
|:---:|-------------|:---:|---------|
| B01 | 未按招标文件要求加盖公章（漏盖、盖错位置） | 🔴 废标 | 对照招标文件逐页标注需盖章位置，打印后逐页检查 |
| B02 | 法定代表人签字栏使用打印字代替手签 | 🔴 废标 | 所有签章行保留空白，组装时手签 |
| B03 | 非法定代表人签字但未附授权委托书 | 🔴 废标 | 非法人签字的，授权书必须与投标文件同时提交 |
| B04 | 授权委托书中被授权人与实际签字人不一致 | 🔴 废标 | 签署前核对姓名与身份证号 |
| B05 | 骑缝章缺失或不完整 | 🟡 重大风险 | 全部页面打印后统一加盖骑缝章 |
| B06 | 授权委托书中授权期限已过期 | 🔴 废标 | 检查授权书有效期是否覆盖投标有效期 |
| B07 | 签章行预填了供应商名称（占用了手签空间） | 🟡 重大风险 | **签章行永远留白，不预填任何文字** |

### 2.2 装订与密封

| 编号 | 风险触发条件 | 风险等级 | 规避措施 |
|:---:|-------------|:---:|---------|
| B08 | 未按招标文件要求装订（应胶装却用活页夹等） | 🔴 废标 | 严格按招标文件"装订要求"执行 |
| B09 | 正副本未标明、"正本/副本"字样遗漏 | 🔴 废标 | 封面和扉页均需标注正本/副本 |
| B10 | 正本与副本内容不一致 | 🔴 废标 | 正副本从同一打印文件输出，不可分次打印 |
| B11 | 未按要求提供电子版（U盘/光盘） | 🟡 重大风险 | 按招标文件要求准备电子版并注明投标人名称+项目名称 |
| B12 | 密封不符合要求（密封袋未封口、封条未盖章等） | 🔴 废标 | 按招标文件逐条核对密封要求 |

### 2.3 格式一致性

| 编号 | 风险触发条件 | 风险等级 | 规避措施 |
|:---:|-------------|:---:|---------|
| B13 | 模板表格列数与招标文件不一致（少列/多列） | 🔴 废标 | **模板几列就做几列，多一列少一列都不行** |
| B14 | 模板中标点符号被替换（"5、"→"5."，"——"→"—"） | 🟡 重大风险 | 模板原文的标点符号一字不改 |
| B15 | 承诺书原文被改写（句式变化、文字增减） | 🔴 废标 | 承诺书/声明类模板逐字复制，仅填空白处 |
| B16 | 偏离表缺少"偏离情况"列（模板5列，做了4列） | 🔴 废标 | 逐列核对模板列数 |
| B17 | 目录页码与实际页码不对应 | 🟡 重大风险 | 打印后在WPS中插入自动目录 |
| B18 | 字体/字号与招标文件要求不一致 | 🟡 重大风险 | 按招标文件要求统一设置 |
| B19 | 页眉页脚内容不符合要求（如暗标出现单位名称） | 🔴 废标 | 逐页检查 |

## 四、报价校验类（数字不一致 = 废标）

| 编号 | 风险触发条件 | 风险等级 | 规避措施 |
|:---:|-------------|:---:|---------|
| D01 | 大写金额与小写金额不一致 | 🔴 废标 | 人工双重核对（大小写交叉验证） |

## 六、评分风险类（v3.2 实战教训提炼 — 不直接废标，但会扣分或引起评委质疑）

> **性质区分**：A~E 类是「废标风险」（命中即投标无效）；本类 F 是「评分风险」（命中不废标，但评分打折、印象受损）。门槛7 在阶段四专项审查本类。

| 编号 | 风险触发条件 | 风险等级 | 后果 | 规避措施 |
|:---:|-------------|:---:|------|---------|
| F01 | 人员配置表中列出的律师，附件中无对应执业证复印件 | 🟠 评分风险 | 人员资质评分扣分；评委质疑团队真实性 | 人员配置表与附件证书**一一对应**，缺一不可 |
| F02 | 附件中出现人员配置表未列出的律师执业证 | 🟠 评分风险 | 评委质疑材料真实性（疑似抄袭/复制粘贴历史材料）；印象极差 | **非团队成员证书一律不得放入附件**；附件证书姓名必须在人员配置表中 |
| F03 | 业绩章节中诉讼业务（裁决书/判决书）与常法业务（常年法律顾问合同）混杂在同一子节 | 🟠 评分风险 | 评委检索困难；业绩匹配度评分打折；评委质疑"连自己业绩都分不清" | 按业务类型用三级子标题区分（如 7.5.1 诉讼代理 / 7.5.2 常年法律顾问 / 7.5.3 专项法律服务） |
| F04 | 含多类业务的章节缺少三级子标题，只有一级章节标题 | 🟠 评分风险 | 目录结构残缺，完整性评分扣分；评委印象不专业 | 多业务章节强制要求三级子标题，TOC 必须展示完整层级 |
| F05 | 目录中漏掉某个实际存在的章节（如分所介绍） | 🟠 评分风险 | 评委以为内容缺失；完整性评分扣分 | 所有章节标题必须用 Heading 样式（Normal 不会被 TOC 抓取） |
| F06 | 业绩合同复印件金额与业绩表填写的金额不一致 | 🟠 评分风险 | 评委质疑业绩真实性；业绩评分扣分 | 业绩表中每项金额必须与合同复印件金额逐项核对一致 |

### F 类风险的执行方法（门槛7 专用）

```
F01/F02 团队边界一致性检查：
  1. 从人员配置表提取所有姓名 → lawyers[]
  2. 遍历附件章节所有执业证段落 → certificates[]
  3. 对 certificates 中每个姓名，检查是否在 lawyers[] 中
  4. 反向：对 lawyers[] 中每个姓名，检查是否在 certificates[] 中
  5. 不一致项 → 触发 F01 或 F02

F03/F04 业务混杂检查：
  1. 遍历业绩章节文本
  2. 同时出现"裁决书/判决书"和"常年法律顾问合同"关键词 → 触发 F03
  3. 检查所有 Heading 2 章节是否包含至少一个 Heading 3 子标题 → 触发 F04

F05 目录完整性检查：
  1. 提取文档所有 Heading 1/2/3 段落 → headings_in_doc[]
  2. 提取 TOC 中的所有条目 → headings_in_toc[]
  3. 比对两个列表，差集即为漏抓或多余项

F06 金额一致性检查：
  1. 提取业绩表中每项业绩的金额
  2. 对每项业绩，定位对应合同复印件
  3. OCR 提取合同金额，与业绩表金额比对
```

## 使用说明

### 在 legal-bid-pipeline 各阶段的使用方式

| 阶段 | 使用场景 | 加载模式 |
|------|---------|---------|
| **阶段〇**（可行性预评估） | 快速筛查一票否决类风险（A类），判断是否值得投标 | 仅加载 A 类 |
| **阶段一·步骤4**（解析后风险初筛） | 全量扫描招标文件中可能触发的风险模式 | 全量加载 |
| **阶段四·门槛6**（质检风险库复检） | 成稿后对照风险库逐条扫描，输出「风险命中清单」 | 全量加载 |
| **迭代终止后**（最终扫描） | 交付前最后一遍风险库全量扫描 | 全量加载 |
| **阶段五·B**（补强合规校验） | 补强段落注入后，确保新内容不触发新的风险 | 全量加载 |

### 风险等级含义

| 等级 | 含义 | 说明 |
|:---:|------|------|
| 🔴 废标 | 触发即废标，必须在交付前100%排除 | 对应招标文件中的实质性条款（★号） |
| 🟡 重大风险 | 不直接废标但可能导致扣分或评委质疑 | 需逐项确认并给出合规说明 |
| 🟠 评分风险 | 不废标，但会让评分扣分或印象受损 | F 类，由阶段四门槛7 专项审查 |

> **重要提示**：本风险库不替代人工最终审查。所有风险模式的规避措施仅供参考，具体以招标文件原文和现行法律法规为准。
