# 政策法规合规检查清单

## 一、核心法律法规依据

### 1.1 法律层面
| 序号 | 法规名称 | 适用范围 | 关键条款 |
|-----|---------|---------|---------|
| 1 | 《中华人民共和国招标投标法》（2017修正） | 中国境内招标投标活动 | 第3条（强制招标范围）、第18条（不得歧视）、第33条（不得低于成本报价） |
| 2 | 《中华人民共和国招标投标法实施条例》（2019修订） | 配合招标投标法执行 | 第32条（不得设定不合理条件）、第51条（否决投标情形） |
| 3 | 《中华人民共和国政府采购法》（2014修正） | 政府采购项目 | 第22条（供应商资格条件）、第36条（废标情形） |
| 4 | 《中华人民共和国政府采购法实施条例》 | 配合政府采购法执行 | 第17条（供应商资格证明）、第20条（差别待遇） |
| 5 | 《中华人民共和国电子签名法》（2019修正） | 电子招标投标 | 第14条（可靠电子签名效力） |

### 1.2 部门规章与规范性文件
| 序号 | 法规名称 | 文号/发布机关 | 关键要点 |
|-----|---------|-------------|---------|
| 1 | 《政府采购货物和服务招标投标管理办法》 | 财政部令第87号 | 资格预审、评标方法、中标公告 |
| 2 | 《电子招标投标办法》 | 发改委令第20号 | 电子交易平台要求、数据电文效力 |
| 3 | 关于严格执行招标投标法规制度进一步规范招标投标主体行为的若干意见 | 发改法规规〔2022〕1117号 | 招标人主体责任、评标专家管理 |
| 4 | 政府采购领域"整顿市场秩序、建设法规体系、促进产业发展"三年行动方案 | 国办发〔2024〕33号 | 市场秩序整顿、本国产品标准 |
| 5 | 关于在政府采购中实施本国产品标准及相关政策的通知 | 国办发〔2025〕34号 | 本国产品界定标准、采购比例要求 |

## 二、投标主体资格检查

### 2.1 基础资格
- [ ] 营业执照（三证合一）在有效期内
- [ ] 经营范围覆盖招标项目内容
- [ ] 注册资本满足招标文件最低要求
- [ ] 无重大违法记录（提供声明函+信用中国截图）
- [ ] 未被列入失信被执行人、重大税收违法案件当事人名单
- [ ] 未被列入政府采购严重违法失信行为记录名单
- [ ] 具有独立承担民事责任的能力
- [ ] 具有良好的商业信誉和健全的财务会计制度

### 2.2 纳税与社保
- [ ] 纳税记录满足招标文件要求的连续缴纳时限（通常为近6个月或1年）
- [ ] 社保缴纳无断缴、漏缴情况
- [ ] 纳税和社保证明由税务机关和社保机构出具

### 2.3 财务要求
- [ ] 财务审计报告由合格的第三方审计机构出具
- [ ] 审计报告为全文（含机构营业执照副本、会计师签章）
- [ ] 财务指标（营业收入、净资产、资产负债率等）满足招标要求
- [ ] 审计报告年份与招标文件要求一致

## 三、专业资质检查

### 3.1 证书有效性
- [ ] 所有资质证书在有效期内
- [ ] 证书有效期必须覆盖整个投标有效期
- [ ] 发证机关为国家认可的权威机构
- [ ] 证书内容与投标主体一致（名称、地址）
- [ ] 需要年检的证书已完成最新年度检查

### 3.2 常见资质类型
- [ ] ISO质量管理体系认证（如ISO 9001）
- [ ] 行业特定许可/资质（如建筑资质、涉密资质、安全生产许可证）
- [ ] 信息安全等级保护认证
- [ ] 软件企业认定/高新技术企业证书
- [ ] 专利证书/软件著作权登记证书
- [ ] CCC认证（如涉及强制认证产品）
- [ ] 节能产品认证/环境标志产品认证

### 3.3 项目经理资格
- [ ] 项目经理持有相应级别的职业资格证书
- [ ] 证书注册单位与投标人一致
- [ ] 项目经理无在建项目（如招标文件要求）
- [ ] 提供劳动合同+连续社保缴纳记录+纳税证明
- [ ] 项目经理业绩满足招标要求

## 四、政府采购特殊政策

### 4.1 中小企业政策
- [ ] 如适用：提供《中小企业声明函》
- [ ] 声明函格式符合《政府采购促进中小企业发展管理办法》要求
- [ ] 声明内容真实（从业人员、营业收入、资产总额）
- [ ] 如分包：明确分包比例和分包企业类型

### 4.2 节能环保政策
- [ ] 如涉及：产品在节能产品政府采购清单内
- [ ] 如涉及：产品在环境标志产品政府采购清单内
- [ ] 提供清单截图或认证证书

### 4.3 本国产品政策（2025）
- [ ] 关注国办发〔2025〕34号本文中本国产品界定标准
- [ ] 确认是否需要进行本国产品声明
- [ ] 本国产品需满足：在中国境内生产、关键工序在中国完成等

### 4.4 残疾人福利/监狱企业
- [ ] 如适用：提供残疾人福利性单位声明函
- [ ] 如不适用：声明"我公司不属于残疾人福利性单位"
- [ ] 监狱企业提供省级以上监狱管理局证明

## 五、禁止性条款扫描

### 5.1 围标串标风险
- [ ] 不同投标人的投标文件不由同一单位或个人编制
- [ ] 不同投标人未委托同一单位或个人办理投标事宜
- [ ] 不同投标人的投标文件载明的项目管理成员不是同一人
- [ ] 不同投标人的投标文件异常一致或报价呈规律性差异
- [ ] 不同投标人的投标文件未混装
- [ ] 不同投标人的投标保证金从同一账户转出

### 5.2 利益冲突
- [ ] 与招标人不存在利害关系（可能影响招标公正性）
- [ ] 单位负责人非同一人或不存在控股/管理关系
- [ ] 未为本项目提供过前期设计、咨询或招标代理服务

### 5.3 联合体投标
- [ ] 联合体各方均满足资格条件
- [ ] 联合体协议明确各方工作内容和责任
- [ ] 联合体各方不得再单独或加入其他联合体参加同一项目
- [ ] 联合体资质按资质等级较低的确定（如适用）

### 5.4 其他红线
- [ ] 不得以他人名义投标或弄虚作假
- [ ] 不得向招标人/评委行贿或变相行贿
- [ ] 不得低于成本报价竞标
- [ ] 不得在投标有效期截止前撤销投标文件
- [ ] 不得拒绝接受评标委员会修正的报价算术错误
