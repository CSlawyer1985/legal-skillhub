# 格式检查清单

## 〇、六道硬门槛质检（AND关系——一道不过即打回）

> **执行时机**：标书合稿完成后、评审前。由质检Agent执行。
> **核心规则**：六道门槛为「与」关系，**任一道不通过即打回阶段二（章节编写）**，不得进入阶段五（评审）。
> **打回处理**：仅打回不通过项对应的章节，通过的章节保留；修正后重现阶段三（合稿）→阶段四（质检）。

### 门槛1：字数门槛

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 每章正文字数 | ≥3000字（纯中文正文，不含代码块、图表、表格） | 逐章统计 |
| 引言/概述 | ≥300字 | 统计 |
| 总结 | ≥200字 | 统计 |

**不通过条件**：任一章节正文不足3000字 → 逐章标注字数及缺口，打回。

### 门槛2：图表门槛

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 每章图表数量 | ≥1张图（Mermaid架构图/流程图/甘特图） | 逐章检查 |
| 图表来源 | 必须为Mermaid代码生成（非网络截图/外部链接） | 检查代码块 |
| 图表可渲染性 | 所有Mermaid代码可正常渲染为SVG | 逐一验证 |
| 图表编号连续性 | 图1→图2→...无跳号 | 全文检查 |

**不通过条件**：任一章节缺少图表 / 图表无法渲染 / 编号跳号 → 标注具体章节，打回。

### 门槛3：表格门槛

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 每章表格数量 | ≥1张数据表格 | 逐章检查 |
| 表格内容完整性 | 无空白单元格、无缺失行列 | 逐表检查 |
| 表格格式统一性 | 边框/字体/对齐方式一致 | 逐表检查 |
| 表格编号连续性 | 表1→表2→...无跳号 | 全文检查 |

**不通过条件**：任一章节缺少表格 / 存在空白单元格 / 编号跳号 → 标注具体位置，打回。

### 门槛4：事实核查门槛

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 数据来源 | 所有数字/百分比/金额有来源标注或可验证依据 | 逐条检查 |
| 模糊词扫描 | 无"可能""大概""也许""应该""左右""基本""差不多" | Ctrl+F全文搜索 |
| 交叉验证 | 同一数据在全文各处一致（报价/人员姓名/时间/编号） | 交叉比对 |
| 事实一致性 | 无前后矛盾（如A处说"3年质保"，B处说"5年质保"） | 全文比对 |

**不通过条件**：发现模糊词 / 同一数据不一致 / 明显事实矛盾 → 标注具体位置和内容，打回。

### 门槛5：格式门槛

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 图表编号连续性（全量复查） | 图1→图N / 表1→表N 无跳号无重复 | 全文检查 |
| 目录页码对应 | 目录中每一条目页码 = 正文实际页码 | 逐条核对 |
| 字体颜色 | 全文黑色，无蓝色超链接残留 | 全文检查 |
| 文件命名 | 符合[项目名_标书_v版本号]格式 | 检查文件名 |

**不通过条件**：编号跳号 / 目录页码不对 / 有蓝色文字 → 标注具体位置，打回。

### 门槛6：废标风险库复检（v3.0新增）

> 加载 `references/risk_library.md` 全量模式库，对照标书终稿逐条扫描。

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 形式要件 | 签字/盖章/密封/装订/正副本/电子版/授权项完整 | 逐条对照风险库 B 类模式 |
| 资质证书有效期 | 执业许可证、人员资格证书均在有效期内 | 逐条对照风险库 C 类模式 |
| 业绩证明合规性 | 合同复印件齐全、金额达标、时间在要求范围内 | 逐条对照风险库 A04-A05 |
| 报价一致性 | 大写=小写、分项合计=总价、不超最高限价 | 逐条对照风险库 D 类模式 |
| 签章留白 | 所有签章行保留空白，未预填名字/日期 | 逐条对照风险库 E 类模式 |

**不通过条件**：命中任一 🔴 废标级风险模式 → 标注风险编号 + 具体位置 + 修复建议，打回。
命中 🟡 重大风险 → 标注并提示，由用户决定是否修改。

## 一、文字格式检查

### 1.1 字体规范
| 检查项 | 标准要求 | 检查方法 |
|-------|---------|---------|
| 正文 | 小四号宋体 | 检查字体设置 |
| 目录 | 四号宋体 | 检查字体设置 |
| 标题 | 按层级递减（三号/小三/四号），加粗 | 逐级检查 |
| 表格内文字 | 五号宋体 | 检查表格字体 |
| 页眉页脚 | 五号宋体 | 检查页眉页脚 |
| 英文/数字 | Times New Roman 或 Arial | 检查混排段落 |

### 1.2 段落格式
| 检查项 | 标准要求 | 检查方法 |
|-------|---------|---------|
| 行距 | 1.5倍行距 | 全选检查段落行距 |
| 段前段后 | 0行或0.5行 | 检查段落间距 |
| 首行缩进 | 每层级段落首行缩进两个字符 | 逐段检查 |
| 对齐方式 | 两端对齐 | 全选检查 |
| 编号格式 | 统一的一、（一）1.（1）层次 | 逐级核对 |

## 二、页面格式检查

### 2.1 页面设置
| 检查项 | 标准要求 | 检查方法 |
|-------|---------|---------|
| 纸张大小 | A4（210mm × 297mm） | 页面设置确认 |
| 页边距 | 上2.54cm 下2.54cm 左3.17cm 右3.17cm（可微调） | 页面设置确认 |
| 页码 | 封面无页码，目录用罗马数字，正文用阿拉伯数字 | 逐页核查 |
| 页眉 | 项目名称 / 投标人名称 | 检查一致性 |

### 2.2 目录检查
- [ ] 目录页码与正文实际页码一一对应
- [ ] 目录层级为3-4级（不宜过少也不宜过多）
- [ ] 目录标题与正文标题完全一致
- [ ] 目录包含图表索引（如适用）
- [ ] 页码连续无跳页

## 三、编号与标题检查

### 3.1 层级编号规范
```
一级标题：一、二、三、...（三号宋体加粗）
二级标题：（一）（二）（三）...（小三号宋体加粗）
三级标题：1. 2. 3. ...（四号宋体加粗）
四级标题：（1）（2）（3）...（小四号宋体加粗）
五级标题：① ② ③ ...（小四号宋体）
```

### 3.2 编号连续性检查
- [ ] 章节编号连续无跳号
- [ ] 同级标题编号格式统一
- [ ] 图表编号连续（图1、图2... | 表1、表2...）
- [ ] 公式编号连续（如适用）
- [ ] 页码无跳页、无空白页

## 四、图表格式检查

### 4.1 图片规范
- [ ] 图片清晰度≥300dpi
- [ ] 图片无拉伸变形
- [ ] 图片有水印/版权标记（如需要）
- [ ] 架构图、流程图线条清晰、标注完整
- [ ] 图片编号正确（图X + 图名）
- [ ] 图片与正文引用对应

### 4.2 表格规范
- [ ] 表格格式统一（边框/底纹/字体）
- [ ] 表格无跨页断开（或设置重复标题行）
- [ ] 表格数据对齐方式统一（文字左对齐、数字右对齐/居中对齐）
- [ ] 表格编号正确（表X + 表名）
- [ ] 表格内容不超出页面边界

## 五、文件格式检查

### 5.1 电子标书检查
| 检查项 | 标准要求 | 检查方法 |
|-------|---------|---------|
| 文件格式 | PDF（如招标文件要求） | 文件属性确认 |
| 双层PDF | 可搜索、可复制文字 | Ctrl+F搜索验证 |
| 文件大小 | 不超平台限制（通常≤100MB） | 文件属性确认 |
| 文件命名 | 严格按招标文件要求 | 逐字核对 |
| 密码保护 | 无密码保护 | 尝试无密码打开 |
| 电子签章 | CA认证数字证书签章 | 检查签章完整性 |
| 签章位置 | 与纸质文件盖章位置一致 | 逐页核对 |
| 文件完整性 | 无缺页、无空白页 | 逐页浏览 |

### 5.2 PDF转换注意事项
- 使用WPS或Office的「导出为PDF」功能，不使用截图或虚拟打印
- 检查字体是否正确嵌入（不依赖系统字体）
- 扫描件（资质证书等）分辨率≥300dpi
- 双层PDF：先格式转换→再双层处理→最后签章

### 5.3 纸质标书检查
| 检查项 | 标准要求 |
|-------|---------|
| 打印质量 | 清晰、无断墨、无偏色 |
| 装订方式 | 胶装/线装（按招标要求） |
| 正副本数量 | 严格按要求（正本X份+副本X份+电子版X份） |
| 密封要求 | 按招标要求密封、加盖密封章 |
| 包装标注 | 项目名称、投标人名称、"正本"/"副本"标注 |

## 六、一致性检查

### 6.1 金额一致性
- [ ] 报价总价 = 各分项报价之和
- [ ] 投标函报价 = 报价一览表报价
- [ ] 报价大小写一致
- [ ] 货币单位全文统一

### 6.2 人员一致性
- [ ] 投标函签字人 = 授权书被授权人
- [ ] 项目经理名字在各处一致
- [ ] 人员名单与简历一一对应
- [ ] 联系方式（电话/邮箱）全文统一

### 6.3 时间一致性
- [ ] 各文件签署日期在投标截止日期之前
- [ ] 授权书有效期覆盖投标有效期
- [ ] 业绩合同签订时间在招标要求范围内
- [ ] 证书有效期覆盖整个投标有效期

### 6.4 术语一致性
- [ ] 项目名称全文统一
- [ ] 招标编号全文统一
- [ ] 投标人名称与公章一致
- [ ] 产品/服务名称全文统一
- [ ] 专业术语使用一致

## 八、快速可视化检查

提交前用以下方法快速检查：

1. **Ctrl+F搜索**：
   - 搜索"可能""大概""也许""应该"→ 替换或删除
   - 搜索"本项目承诺"→ 确认用于关键承诺
   - 搜索招标编号 → 确认全文一致
   - 搜索报价数字 → 确认所有出现处一致

2. **PDF阅读器检查**：
   - 缩略图模式逐页浏览 → 检查缺页/空白页
   - 搜索功能测试 → 确认双层PDF
   - 签章面板 → 确认所有签章有效

3. **打印预览**：
   - 检查页面边界 → 确保无内容被裁切
   - 检查图表 → 确保清晰可读
   - 检查页码 → 确保连续且位置一致
