# 格式检查清单

## 〇、八道硬门槛质检（AND关系——一道不过即打回）

> **执行时机**：标书合稿完成后、评审前。由质检Agent执行。
> **核心规则**：八道门槛为「与」关系，**任一道不通过即打回阶段二（章节编写）**，不得进入阶段五（评审）。
> **打回处理**：仅打回不通过项对应的章节，通过的章节保留；修正后重现阶段三（合稿）→阶段四（质检）。

### 门槛1：字数门槛

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 每章正文字数 | ≥3000字（纯中文正文，不含代码块、图表、表格） | 逐章统计 |
| 引言/概述 | ≥300字 | 统计 |
| 总结 | ≥200字 | 统计 |

**不通过条件**：任一章节正文不足3000字 → 逐章标注字数及缺口，打回。

### 门槛2：图表门槛

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 每章图表数量 | ≥1张图（Excalidraw 架构图/流程图/甘特图，v3.3 起取代 Mermaid） | 逐章检查 |
| 图表来源 | 必须为 Excalidraw 生成（非网络截图/外部链接） | 检查图源文件 |
| 图表可渲染性 | 渲染为 PNG 后目检：中文非方框、无箭头穿格、无大面积空白（标准见 docx_engineering.md 第二节） | 逐张目检 |
| 图表编号连续性 | 图1→图2→...无跳号 | 全文检查 |

**不通过条件**：任一章节缺少图表 / 图表无法渲染 / 编号跳号 → 标注具体章节，打回。

### 门槛3：表格门槛

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 每章表格数量 | ≥1张数据表格 | 逐章检查 |
| 表格内容完整性 | 无空白单元格、无缺失行列 | 逐表检查 |
| 表格格式统一性 | 边框/字体/对齐方式一致 | 逐表检查 |
| 表格编号连续性 | 表1→表2→...无跳号 | 全文检查 |

**不通过条件**：任一章节缺少表格 / 存在空白单元格 / 编号跳号 → 标注具体位置，打回。

### 门槛4：事实核查门槛

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 数据来源 | 所有数字/百分比/金额有来源标注或可验证依据 | 逐条检查 |
| 模糊词扫描 | 无"可能""大概""也许""应该""左右""基本""差不多" | Ctrl+F全文搜索 |
| 交叉验证 | 同一数据在全文各处一致（报价/人员姓名/时间/编号） | 交叉比对 |
| 事实一致性 | 无前后矛盾（如A处说"3年质保"，B处说"5年质保"） | 全文比对 |

**不通过条件**：发现模糊词 / 同一数据不一致 / 明显事实矛盾 → 标注具体位置和内容，打回。


**程序化交叉验证（v3.5.1 新增——人眼通读抓矛盾不可靠，必须程序扫描）**：

1. **数值一致性扫描**：正则抓取全文所有「数字+单位」表述（分钟/小时/天/次/季度/半年/%），按语义聚类（如"到场车程""满意度调查频次"），同类表述数值不同即报警
2. **人名×资质比对**：提取全文所有"律师姓名+资质"表述，与 `private/material-library` 简历/人员档案逐人比对；正文中每个人的资质描述必须是其简历的子集，多一个证即判幻觉
3. **导读反向核对**：总述/导读中出现的数量性承诺（"五大专项""七项服务"），逐项在正文和招标文件评分细则中找到对应章节，找不到即判加码

### 门槛5：格式门槛

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 图表编号连续性（全量复查） | 图1→图N / 表1→表N 无跳号无重复 | 全文检查 |
| 目录页码对应 | 目录中每一条目页码 = 正文实际页码 | 逐条核对 |
| 字体颜色 | 全文黑色，无蓝色超链接残留 | 全文检查 |
| 文件命名 | 符合[项目名_标书_v版本号]格式 | 检查文件名 |
| **页码（v3.6）** | 页脚插入 PAGE 域（居中、宋体小五/10.5pt）；封面页不显示页码（节属性 titlePg）；目录页用独立页码序列；正文从第1页起 | 逐节检查页脚 |
| **目录域（v3.6）** | 目录必须是 TOC 域（可 F9 更新），禁止硬编码手工目录；交付前用 Word/docx2pdf 刷新域 | 检查域代码 |

**不通过条件**：编号跳号 / 目录页码不对 / 有蓝色文字 → 标注具体位置，打回。

### 门槛6：废标风险库复检（v3.0新增）

> 加载 `references/risk_library.md` 全量模式库，对照标书终稿逐条扫描。

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 形式要件 | 签字/盖章/密封/装订/正副本/电子版/授权项完整 | 逐条对照风险库 B 类模式 |
| 资质证书有效期 | 执业许可证、人员资格证书均在有效期内 | 逐条对照风险库 C 类模式 |
| 业绩证明合规性 | 合同复印件齐全、金额达标、时间在要求范围内 | 逐条对照风险库 A04-A05 |
| 报价一致性 | 大写=小写、分项合计=总价、不超最高限价 | 逐条对照风险库 D 类模式 |
| 签章留白 | 所有签章行保留空白，未预填名字/日期 | 逐条对照风险库 E 类模式 |

**不通过条件**：命中任一 🔴 废标级风险模式 → 标注风险编号 + 具体位置 + 修复建议，打回。
命中 🟡 重大风险 → 标注并提示，由用户决定是否修改。

### 门槛7：业务结构与团队边界审查（v3.2 新增）

| 检查项 | 标准 |
|--------|------|
| 团队边界一致性 | 人员配置表中每位律师 ↔ 附件执业证复印件一一对应；非团队成员证书不得放入 |
| 业务章节混杂 | 诉讼/常法/专项等不同业务类型必须用三级子标题拆分，不得混在同一子节 |
| 三级子标题完整性 | 含多类业务的章节必须有 Heading 3，目录可完整展示三级结构 |

### 门槛8：文档块唯一性与目录纯净度审查（v3.4 新增，v3.7.3 补占位符检查）

| 检查项 | 标准 |
|--------|------|
| 残留块检查 | 每份模板文书取特征句全文搜索，出现次数必须 = 1（警惕无标题的残留旧块） |
| 目录纯净度 | 全文扫描段落 `outlineLvl`，只有章节标题允许携带；TOC 按 outlineLvl 抓取而非样式名 |
| **占位符残留检查（v3.7.3 新增·废标级）** | 全文扫描未替换的模板占位符：`（供应商名称）`、`（项目名称）`、`（大写）`、`（盖章）`、`（签字）` 等全角括号占位模式，以及 DATA 字典中定义但正文仍是 `{xxx}` 形态的变量。**命中任何一处 = DATA 字典缺字段或填空遗漏，直接废标级，必须打回** |
