# 商务匹配指南

## 一、商务标书核心组成

商务标书是投标文件中最容易出现"低级错误"导致废标的部分。核心要求：**格式合规、内容完备、签章齐全、顺序正确**。

### 1.1 商务标书结构
1. 投标函及投标函附录
2. 法定代表人授权书
3. 报价一览表（总价）
4. 分项报价明细表
5. 商务条款响应/偏离表
6. 付款方式与条件说明
7. 交付/工期承诺
8. 质保与售后服务承诺
9. 培训计划
10. 合同条款响应
11. 中小企业声明函等政策文件
12. 其他承诺书

## 二、报价策略与规范

### 2.1 报价编制规范
| 序号 | 规范项 | 具体要求 |
|-----|-------|---------|
| 1 | **必备文件** | 报价一览表（总价）+ 分项报价表 |
| 2 | **金额一致性** | 分项报价表总和 = 报价一览表总价 = 投标函报价 |
| 3 | **内容一致** | 设备名称、品牌、型号、数量、参数与招标要求一致 |
| 4 | **大小写规范** | 大小写书写正确，数目核对准确 |
| 5 | **货币单位** | 与招标文件保持一致（通常为人民币元） |
| 6 | **表格格式** | 严格按招标文件要求的格式制作 |
| 7 | **价格构成** | 含税/不含税标注清晰 |

### 2.2 报价策略
- **综合评分法**：报价分权重高（>50%）时，重点研究最优报价策略
- **最低评标价法**：在满足技术商务要求前提下，提供最低报价
- **性价比法**：在技术方案有显著优势时，可适当提高报价
- **报价区间分析**：参考历史中标价格区间和最高限价

### 2.3 报价常见错误
- 大小写金额不一致
- 分项报价之和与总价不等
- 货币单位写错
- 报价有效期短于招标要求
- 漏报某一分项

## 三、商务条款响应

### 3.1 商务偏离表规范
```markdown
| 序号 | 招标条款 | 投标响应 | 偏离说明 | 偏离类型 |
|-----|---------|---------|---------|---------|
| 1 | 付款方式：验收后30天内付95% | 验收后30天内付95% | 完全响应 | 无偏离 |
| 2 | 质保期：3年 | 质保期：5年 | 优于要求 | 正偏离 |
| 3 | 交货期：60天 | 交货期：45天 | 优于要求 | 正偏离 |
| 4 | 质保金：5% | 质保金：3% | 低于要求 | 负偏离 |
```

### 3.2 核心商务条款响应
| 条款类别 | 典型要求 | 响应策略 |
|---------|---------|---------|
| **付款方式** | 预付+进度+验收+质保金 | 尽量满足，如偏离需说明理由 |
| **交付/工期** | 合同签订后XX天内 | 提供详细进度计划佐证 |
| **质保期** | 验收后X年 | 建议正偏离（优于要求） |
| **质保金** | 合同金额X% | 接受标准比例，偏离需说明 |
| **售后服务** | X小时内响应、X小时内到场 | 提供具体实施机制 |
| **知识产权** | 归招标方所有/双方共有 | 明确界定，不可模糊 |
| **保密条款** | 永久保密/X年保密期 | 完全接受或给出合理偏离 |
| **违约责任** | 延期罚款（每日X‰） | 评估风险后可接受 |

### 3.3 商务条款注意事项
- 付款条件是否可接受（现金流评估）
- 违约金比例是否合理（通常建议不超过合同总额的5%）
- 知识产权归属是否符合公司政策
- 质保期是否可行（评估成本）
- 保密条款是否过度

## 四、售后服务承诺

### 4.1 售后承诺标准要素
| 要素 | 建议标准 | 如何写实 |
|-----|---------|---------|
| **响应时间** | 7×24小时，XX分钟内响应 | 提供客服系统截图/值班表 |
| **到场时间** | XX小时内到达现场 | 提供服务网点分布图 |
| **故障解决** | 一般故障X小时内，重大故障X小时内 | 提供故障分级和处理流程 |
| **备件供应** | 常用备件X小时内送达 | 提供备件库清单和位置 |
| **巡检服务** | 每月/每季度一次预防性巡检 | 提供巡检内容和报告模板 |
| **培训服务** | 提供X天X人次培训 | 提供培训大纲和教材清单 |
| **质保后服务** | 质保期满后优惠服务方案 | 提供续保报价方案 |

### 4.2 售后承诺要求
- 不使用空话（"提供一流服务"），使用量化指标
- 提供实现机制（不是承诺，而是谁来做、怎么做、何时做）
- 如有远程运维能力，提供监控平台截图
- 如有本地服务团队，提供团队规模和资质

## 五、业绩证明规范

### 5.1 完整业绩四要素
每个业绩证明必须包含：
1. **中标通知书**：原件扫描件
2. **合同文本**：原件扫描件，合同金额、签订时间及签章必须清晰可辨
3. **验收报告/收货单**：原件扫描件，证明项目已完成
4. **用户满意度调查表/售后使用说明书**：证明项目效果

### 5.2 业绩筛选原则
- **金额匹配**：案例合同金额≥招标项目预算的一定比例（通常50%以上）
- **时间匹配**：注意招标文件规定的业绩时间范围（如近3年内）
- **类型匹配**：案例项目类型与招标项目高度相似
- **状态完整**：必须已完工/已完成验收，在建项目通常不算

### 5.3 常见业绩问题
- 合同金额不清晰 → 废标或不给分
- 签订时间超出规定年限 → 不计入有效业绩
- 项目类型不匹配 → 可能有分但不满分
- 缺少验收报告 → 被视为未完成项目
- 合同关键信息打码 → 评委无法采信

## 六、商务标常见废标原因

| 序号 | 废标原因 | 预防措施 |
|-----|---------|---------|
| 1 | 报价超过最高限价 | 报价前再次确认最高限价 |
| 2 | 投标函未签章 | 逐页检查签章 |
| 3 | 授权书过期或未签署 | 检查有效期和签章 |
| 4 | 保证金未按时到账 | 预留3个工作日转账时间 |
| 5 | 报价大小写不一致 | 双人交叉核对 |
| 6 | 未提供分项报价 | 严格按招标文件要求的报价表格式 |
| 7 | 资格证明过期 | 建立证书有效期台账 |
| 8 | 业绩材料不完整 | 参照四要素逐一核对 |
| 9 | 商务偏离表遗漏 | 对照招标文件逐条填写 |
| 10 | 联合体协议缺失 | 如联合体投标必须提供 |

## 七、商务标自查清单

### 7.1 报价检查
- [ ] 总价不超过最高限价
- [ ] 报价大小写一致
- [ ] 分项报价之和等于总价
- [ ] 货币单位正确
- [ ] 报价有效期覆盖投标有效期
- [ ] 未遗漏任何报价分项

### 7.2 商务条款检查
- [ ] 付款方式已响应
- [ ] 交付期限可达成（附进度计划佐证）
- [ ] 质保期已响应（建议正偏离）
- [ ] 质保金已响应
- [ ] 售后承诺具体量化
- [ ] 知识产权归属已明确
- [ ] 违约条款已评估

### 7.3 业绩检查
- [ ] 案例数量满足最低要求
- [ ] 每个案例包含四要素（中标通知书+合同+验收+评价）
- [ ] 合同金额和签订时间清晰可辨
- [ ] 案例类型与招标项目匹配
- [ ] 所有业绩在时间范围内

### 7.4 签章与格式
- [ ] 投标函已签章
- [ ] 授权书已签章
- [ ] 报价表已签章
- [ ] 承诺书已签章
- [ ] 所有签章位置正确、清晰
