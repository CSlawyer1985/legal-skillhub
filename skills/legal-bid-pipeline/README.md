# legal-bid-pipeline — 法务标书全链路生成

将投标文档制作从"人工逐章拼凑"升级为**八阶段多Agent协作自动化流水线**，覆盖政策合规、技术匹配、商务匹配、格式检查、模板对齐、废标风险六大管控维度。

## 快速开始

### 触发方式

在 WorkBuddy 对话中直接说出意图即可，无需指定技能名称。典型触发词：

> 「帮我写XX项目的投标文件」「生成技术方案」「分析这份招标文件」「检查标书格式」「制作响应矩阵」「输出偏离表」

### 执行流程

一次完整的投标文件生成过程如下：

```
用户提供招标文件
       │
       v
阶段一：总调度解析（招标要素提取 + 政策合规预检 + MECE章节拆解 + 响应矩阵草稿）
       │
       v  ← 确认点 #1：审核框架
       │
阶段二：IMA知识库检索 → 知识库优先编写 + AI补全标记 → AI生成内容清单 → 人工确认
       │
       v  ← 确认点 #1.5：审核AI生成内容
       │
阶段三：合稿排版（合并8章 → 渲染Mermaid图表 → 嵌入图片 → 替换占位符 → 生成DOCX）
       │
       v
阶段四：五道硬门槛质检（字数 / 图表 / 表格 / 事实核查 / 格式检查，全部AND通过）
       │
       v
阶段五：五维并行评审（A完整性 / B技术深度 / C商务竞争力 / D语言规范 / E评分博弈）
       │
       v  ← 确认点 #2：审核评审结果
       │
阶段六：修改迭代（按P0/P1/P2逐级修复 → 重新合稿 → 重新质检 → 重新评审，最多3轮）
       │
       v
交付版输出（格式终审 + 终版DOCX）
```

> **直达交付**：如果阶段五评审得分 ≥ 95 且无P0问题，将跳过阶段六直接产出交付版。

### 你需要准备

| 类型 | 内容 | 必需 / 推荐 | 说明 |
|------|------|:----------:|------|
| 招标文件 | PDF / DOCX / Markdown / 纯文本 | **必需** | 完整的招标文件正文（不含附件也可） |
| 公司资料 | 简介、资质证书、案例库、技术白皮书 | 推荐 | 用于阶段二编写时提取真实信息 |
| IMA知识库 | 将公司资料上传至 IMA 并连接 `ima-mcp` | 推荐 | 阶段二优先使用知识库内容，减少AI幻觉 |

## 工作流概览

### 六阶段流水线

```
 ┌────────────┐   ┌──────────────┐   ┌────────────┐   ┌───────────┐   ┌───────────┐   ┌───────────┐
 │  阶段一     │   │   阶段二      │   │  阶段三     │   │  阶段四    │   │  阶段五    │   │  阶段六    │
 │  总调度     │──>│  N个Agent     │──>│  合稿排版   │──>│  五道硬    │──>│  五维评审   │──>│  修改迭代  │
 │  解析       │   │  并行编写     │   │            │   │  门槛质检  │   │  并行打分  │   │  (≤3轮)   │
 └────────────┘   └──────────────┘   └────────────┘   └───────────┘   └───────────┘   └───────────┘
       ▲                                                     │                             │
       └──── 确认点 #1 ◄────                                  │              ┌──────────────┘
                                                确认点 #2 ◄──┘              │
                                                            通过(≥95且无P0)──┴──> 交付版
```

### 角色矩阵

| 角色 | 人数 | 职责 | 使用阶段 |
|------|:---:|------|:-------:|
| **总调度** | 1 | 招标文件解析、MECE拆解、章节Brief生成、响应矩阵草稿 | 阶段一 |
| **IMA检索Agent** | 1 | 对各章Brief关键词搜索IMA知识库，评估素材覆盖率 | 阶段二·A |
| **章节编写Agent** | N | 并行编写各章节（知识库优先 + AI补全 + 溯源标记） | 阶段二·B |
| **合稿Agent** | 1 | 合并章节、渲染图表、嵌入图片、生成DOCX、偏离表 | 阶段三 |
| **质检Agent** | 1 | 五道硬门槛AND检查，生成质检报告 | 阶段四 |
| **评审Agent A~E** | 5 | 并行五维评审（完整性/技术深度/商务/语言/评分博弈） | 阶段五 |
| **修改Agent** | 1 | 按P0>P1>P2优先级逐级修复问题 | 阶段六 |

### 五道硬门槛（AND关系）

全部通过才能进入评审阶段，一道不通过即打回阶段二：

| 门槛 | 标准 | 不通过后果 |
|:----:|------|-----------|
| 1. 字数 | 每章正文 ≥ 3000 中文字符 | 打回阶段二 |
| 2. 图表 | 每章 ≥ 1 张 Mermaid 图（架构图/流程图/甘特图） | 打回阶段二 |
| 3. 表格 | 每章 ≥ 1 张数据表（参数对照/计划表/人员表） | 打回阶段二 |
| 4. 事实核查 | 零模糊词（可能/大概/也许/应该/左右等），数据有来源 | 打回阶段二 |
| 5. 格式 | 全文黑色字体、图表编号连续、标题层级正确 | 打回阶段二 |

### 五维评审（权重制）

| 评审 | 维度 | 权重 | 核心检查项 |
|:----:|------|:---:|-----------|
| A | 完整性 | 20% | ★号条款覆盖、评分项覆盖、章节完整、响应矩阵准确 |
| B | 技术深度 | 25% | 需求理解深度、架构合理性、参数响应、方案创新、实施可行 |
| C | 商务竞争力 | 15% | 报价合理性、商务条款响应、售后可信度、业绩匹配度 |
| D | 语言规范 | 10% | 语言规范、逻辑清晰、术语准确、排版一致、可读性 |
| E | 评分博弈 | 30% | 评委视角模拟打分、失分风险识别、加分机会、竞品博弈 |

**迭代终止条件**（满足任一即停止）：

1. 加权总分 ≥ 95 且无 P0 问题 → **交付**
2. 连续两轮提升 < 2 分 → **停止迭代，提醒用户决策**
3. 已达最大 3 轮 → **强制停止**

### P0 / P1 / P2 问题分级

| 等级 | 含义 | 修复要求 | 扣分 |
|:----:|------|---------|:----:|
| **P0** | 致命 — 可能导致废标 | 必须 100% 修复 | 10~20 分 |
| **P1** | 严重 — 明显减分项 | 必须 ≥ 80% 修复 | 3~8 分 |
| **P2** | 一般 — 锦上添花项 | 选择性修复 | 1~3 分 |

## 三个人工确认点

全流程共 3 个人工确认点，其余阶段完全自动运行：

| 确认点 | 时机 | 审核内容 | 操作 |
|:------:|------|---------|------|
| **#1** | 阶段一完成后 | 招标要素清单 + 政策合规检查报告 + 章节 Brief + 响应矩阵草稿 | "继续" 进入编写 / "修改" 调整框架 |
| **#1.5** | 阶段二·C 完成后 | AI 生成内容逐章逐段清单（标注来源：IMA / Reference / AI） | "全部确认" 定稿 / 指定逐条修改 |
| **#2** | 每轮阶段五完成后 | 5 份评审报告 + 加权总分 + P0/P1/P2 清单 | "交付" 输出最终版 / "再改" 进入阶段六 |

> **#1.5 确认点说明**：当 IMA 知识库未连接时，全部内容标记为 AI 生成 → 100%人工确认；当 IMA 已连接时，仅展示未在知识库中找到匹配素材的段落。

## 核心原理

### 标书四大管控维度

```
         ┌──────────────┐
         │   政策合规    │  ← 法律依据 / 主体资格 / 专业资质 / 政府采购 / 禁止性条款
         ├──────────────┤
         │   技术匹配    │  ← 需求理解 / 架构设计 / 参数响应 / 方案创新 / 实施可行
         ├──────────────┤
         │   商务匹配    │  ← 报价构成 / 商务条款 / 售后承诺 / 业绩匹配 / 风险识别
         ├──────────────┤
         │   格式检查    │  ← 字体规范 / 图表编号 / 页面设置 / PDF规范 / 一致性
         └──────────────┘
```

### 阶段二「知识库优先」三阶梯模式 (v2.1)

```
                    ┌──────────────────┐
                    │  对每章Brief关键  │
                    │  词搜索IMA知识库  │
                    └────────┬─────────┘
                             │
                    ┌────────v─────────┐
              ┌─────│  IMA有匹配素材?  │─────┐
              │ 否  └──────────────────┘  是 │
              │                              │
    ┌─────────v──────────┐      ┌───────────v──────────┐
    │ 全部标记AI生成      │      │ 知识库素材填充        │
    │ 100%人工确认        │      │ 缺失段落标记AI生成    │
    └─────────┬──────────┘      └───────────┬──────────┘
              │                              │
              └──────────┬───────────────────┘
                         │
              ┌──────────v──────────┐
              │ 生成AI内容清单       │
              │ 含每段溯源标注       │
              └──────────┬──────────┘
                         │
              ┌──────────v──────────┐
              │ 人工确认后定稿       │
              └─────────────────────┘
```
