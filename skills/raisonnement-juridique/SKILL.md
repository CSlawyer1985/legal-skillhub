# 法律推理——民事法官方法论

本技能指导 Claude 应用法国法官方法论分析民事法律案件，该方法论基于 ENM/最高法院的方法论指南（2023）。

## 能力

- **分析争议**：识别法律问题、对事实进行定性
- **构建法律推理**：三段论——大前提/小前提/结论
- **起草裁判理由**：完整、忠实、公正、精确的裁判理由
- **检索来源**：判例法（Judilibre）和文本（Légifrance）
- **区分诉讼请求/理由/论点**：正确回应每个要素
- **评估决定层级**：根据审判组织与公布情况权衡判决

## 可用的 MCP 工具

### Judilibre（判例法）
- `judilibre_search`：按关键词、审判庭、日期检索决定
- `judilibre_get_decision`：获取决定的完整文本
- `judilibre_get_taxonomy`：获取参考清单（审判庭、处理结果、审判组织、公布情况）

### Légifrance（法律文本）
- `rechercher_code`：在法典中检索（《民法典》、《劳动法典》……）
- `rechercher_dans_texte_legal`：在法律和法令中检索
- `recherche_journal_officiel`：在《官方公报》（JORF）中检索
- `recuperer_article`：通过 ID 获取条文的完整文本和元数据

## 最高法院决定的层级

### 审判组织（按权威递减）

| 审判组织 | 法官人数 | 系数 | 受理情形 |
|-----------|------------|-------------|----------------|
| **全体大会（Assemblée plénière）** | 19 | 10/10 | 原则问题、第二次上诉、抵制 |
| **混合审判庭（Chambres mixtes）** | ≥13 | 9/10 | 各审判庭分歧、票数均等 |
| **审判庭全体组织（Formation plénière chambre）** | 不定 | 7/10 | 可能的立场反转、敏感问题 |
| **分部组织（Formation de section）** | ≥5 | 5/10 | 复杂的日常案件 |
| **缩减组织（Formation restreinte）** | 3 | 3/10 | 不可受理或明显无根据的上诉 |

### 公布情况（按重要性排序）

| 代码 | 公布情况 | 系数 | 含义 |

### 强制检索规则

⚠️ **在未核验正式审判组织之前，绝不将检索限于单一审判庭。**

**3 步检索策略**：

1. **首先：正式审判组织**
   ```
   chamber: ["pl", "mi"]
   publication: ["b", "c"]
   ```
   
2. **其次：带《公报》公布的相关审判庭**
   ```
   chamber: ["civ1", "civ2", "civ3", "comm", "soc", "cr"]  # 依所涉事项
   publication: ["b"]
   ```
   
3. **最后：无审判庭过滤的穷尽检索**
   ```
   sort: "scorepub"  # 按相关性 + 公布情况排序
   ```

### 衔接原则

- **一份全体大会判决 > 任何审判庭判决**（即使是最近的）
- **公布于《公报》的判决 > 未公布的判决**
- **同级别的两份判决之间，以最近的为准**
- **约束效力**：经全体大会撤销（cassation）后，发回重审的法院**必须**遵从该决定（《司法组织法典》第 L.431-4 条）

## 最高法院判例检索的注意要点

✅ **应做**：
- 始终从正式审判组织（`pl`、`mi`）开始
- 核验所引每份判决的公布情况（`b`、`r`、`c`、`l`、`n`）
- 优先引用公布于《公报》（`b`）的判决
- 核验旧判决未被推翻

❌ **应避免**：
- 在未核验 `pl`/`mi` 的情况下限于单一审判庭
- 将未公布（`n`）的判决引用为主要依据
- 无视全体大会判决而采用最近的审判庭判决

## 分析流程

### 1. 接手案件

1. **识别当事人**：原告、被告、身份
2. **理解争议标的**：主要请求是什么？
3. **按时间线定位**：事实、先前的程序
4. **清点证据材料**：可用证据

### 2. 区分诉讼请求 / 理由 / 论点

| 要素 | 定义 | 示例 | 法官的回应 |
|---------|-----------|---------|-----------------|
| **诉讼请求（Prétention）** | 请求的标的（结论部分） | "判令支付 10,000 欧元" | 在判决主文中裁决 |
| **法律理由（Moyen de droit）** | 援引的法律规则 | "《民法典》第 1240 条" | 在裁判理由中回应 |
| **事实理由（Moyen de fait）** | 支持性的事实要素 | "被告撞倒了原告" | 分析证据 |
| **论点（Argument）** | 无自身法律效果的讨论 | "被告当时很匆忙" | 无需回应 |

**基本原则**：法官必须回应所有理由（moyens），绝不回应论点（arguments）。

### 3. 构建法律三段论

法律推理分三个环节展开：

#### 大前提（法律规则）
- 陈述适用规则（文本 + 判例）
- 明确适用条件
- 说明证明机制
- **使用 Légifrance** 引用确切文本（见下方工作流）
- **使用 Judilibre** 获取判例解释

**结构**："依 Y 法典第 X 条之规定，[规则]。由此可知，[条件]。"

**使用的来源**：
- 用 `rechercher_code` 获取法律条文
- 用 `judilibre_search` 获取解释性判例

#### 小前提（适用于事实）
- 以"在本案中（En l'espèce）……"开头
- 陈述已确立的事实
- 分析证据
- 回应当事人的理由
- 对事实进行法律定性

**结构**："在本案中，依证据材料可知[已确立的事实]。而，[法律定性]。"

#### 结论
- 以"因此（En conséquence）……"开头
- 从小前提引出法律后果
- 必须与大前提和小前提一致
- 在判决主文中再现

**结构**："因此，[对诉讼请求的决定]。"

### 4. 法官的职责（Office du juge）

#### 事实领域
- **《民事诉讼法典》第 6 条**：由当事人主张
- **第 7 条第 1 款**：仅辩论中的事实
- **第 7 条第 2 款**：附带事实（须经对审）
- **《民事诉讼法典》第 9 条**：举证责任在当事人

#### 法律领域
- **《民事诉讼法典》第 12 条**：定性/重新定性的义务
- 可以改变法律依据
- **《民事诉讼法典》第 16 条**：尊重对审原则

#### 限制
- 不得改变争议标的（《民事诉讼法典》第 4 条）
- 尊重有优先次序的诉讼请求
- 不得依职权提出时效（《民法典》第 2247 条）

## 判决结构

1. **首部（Chapeau）**：强制记载事项（《民事诉讼法典》第 454 条）
2. **既定事实**：无争议 + 相关
3. **程序**：受理、审结、庭审
4. **诉讼请求与理由**：各方
5. **裁判理由**：对每项请求事项进行三段论
6. **判决主文（Dispositif）**：决定（《民事诉讼法典》第 480 条——既判力）

## MCP 工具的使用

### 判例检索（Judilibre）

```
# 按层级检索某主题的判决
judilibre_search(query="responsabilité du fait des choses gardien", chamber=["pl", "mi"], publication=["b"])
→ 核验原则判决（正式审判组织）

judilibre_search: query="responsabilité gardien chose chute", chamber=["civ2"], publication=["b"]
→ 专门审判庭的判例（第二民事审判庭 = 侵权责任）

# 获取完整决定
judilibre_get_decision(id="...", resolve_references=true)
```

### 文本检索（Légifrance）

```
# 在《民法典》中检索
rechercher_code(code_name="Code civil", search="responsabilité contractuelle")

# 检索特定法律
rechercher_dans_texte_legal(search="bail habitation", text_id="89-462")
```

### 获取条文的完整文本

**⚠️ 强制规则**：未经事先通过 `recuperer_article` 获取条文的完整文本，绝不在法律三段论中引用法律条文。检索结果的截断摘录不足以进行可靠的法律引用。

#### 两步工作流

**第 1 步：识别条文** 通过 `rechercher_code` 或 `rechercher_dans_texte_legal`

```
# 示例：检索关于恐怖主义受害者的条文
rechercher_code(code_name="Code des assurances", search="victimes terrorisme indemnisation")
```

→ 在结果中，找到相关条文的 LEGIARTI 标识符（例如：`LEGIARTI000038312684`）

**第 2 步：获取完整文本** 通过 `recuperer_article`

```
# 获取带全部元数据的完整文本
recuperer_article(article_id="LEGIARTI000038312684")
```

→ 返回：
- 条文的完整文本
- 元数据：编号、标题、状态（现行有效/已废止）、日期
- 注释和观察
- Légifrance 官方链接

#### 完整示例

```
# 1. 初始检索
rechercher_code(code_name="Code civil", search="responsabilité fait personnel")
# → 找到第 1240 条，ID: LEGIARTI000032041571

# 2. 获取完整文本
recuperer_article(article_id="LEGIARTI000032041571")
# → "人的任何行为，凡给他人造成损害，均使因过错致害者负赔偿之责。"
```

#### 三段论中的引用格式

```
**大前提**

依《民法典》第 1240 条之规定：

> 「人的任何行为，凡给他人造成损害，均使因过错致害者负赔偿之责。」

链接：https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000032041571

由此可知，侵权责任以三个条件同时具备为前提……
```

#### 求助于网络检索

仅在以下情形**最后手段**使用 `web_search`：
- Légifrance API 返回技术错误
- 条文中未找到（非常新或特定的文本）
- 需要补充信息（学说、立法准备工作）

此时：
```
web_search("article L126-1 code des assurances legifrance texte intégral")
```

## 良好实践

1. **在引用条文之前，始终通过 `recuperer_article` 获取完整文本**
2. **核验条文状态**：现行有效、已废止、已修改
3. **通过 Judilibre 检索近期判例**以解决解释问题
4. **使用明显标题**结构化推理
5. **回应当事人的所有相关理由**
6. **确保裁判理由与判决主文一致**
7. **避免**假设性（"似乎"）和存疑性（"大概是"）的动机
8. **精确引用证据材料**（性质、日期、作者）
9. **为每个引用的条文包含官方 Légifrance 链接**
