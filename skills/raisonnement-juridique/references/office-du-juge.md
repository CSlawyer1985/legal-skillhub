# 法官的职责（Office du Juge）

法官的职责界定其在民事诉讼中的权力和义务。它围绕两个领域展开：事实和法律。

## 1. 事实领域的职责

### 《民事诉讼法典》第6条：事实的陈述

> "为支持其主张，当事方有责任陈述足以支撑该主张的事实。"

**原则**：当事方对事实的陈述享有垄断权。

**后果**：法官不能将当事方未援引的事实引入辩论。

### 《民事诉讼法典》第7条：辩论中的事实

#### 第1款：当事方援引的事实

> "法官不能基于不在辩论中的事实作出决定。"

**禁止**：法官不能使用其对事实的个人认知。

**适用**：即使法官个人了解某一情况，也只有在该情况处于辩论中时才能予以考虑。

#### 第2款：附带事实（Faits adventices）

> "在辩论的要素中，法官甚至可以考虑当事方未特别援引以支持其主张的事实。"

**权力**：法官可以使用档案中但未被明确援引的"附带"事实。

**条件**：尊重对审原则（《民事诉讼法典》第16条）。

### 《民事诉讼法典》第9条：举证责任

> "每一当事方都有义务依法证明使其主张成功所必需的事实。"

**原则**：*Actori incumbit probatio*——举证责任由原告承担。

**适用**：
- 原告证明支撑其请求的事实
- 被告证明支撑其抗辩的事实
- 各方证明其所主张的事实

## 2. 法律领域的职责

### 《民事诉讼法典》第12条：法律的适用

#### 第1款：裁判争议的义务

> "法官依照对其适用的法律规则裁判争议。"

**义务**：法官必须适用适当的法律规则，无论当事方提出的定性如何。

#### 第2款：定性（qualification）与重新定性

> "法官必须对争议的事实和行为给予或恢复其准确的定性，而不受当事方可能提出的名称的约束。"

**权力-义务**：法官**必须**正确定性事实，即使当事方提出了错误的定性。

**示例**：
- 将"借款"重新定性为"隐名赠与"
- 将"劳动合同"重新定性为"承揽合同"
- 将"重大过失"重新定性为"严重过错"

### 法律依据的变更

法官可以以其认定的法律依据替代当事方援引的法律依据：

**条件**：
1. 不改变争议的标的
2. 尊重对审原则（《民事诉讼法典》第16条）
3. 基于辩论中的事实

**示例**：
- 以《民法典》第1240条（过错）替代第1242条第1款（物的行为责任）
- 以侵权责任替代合同责任
- 适用特别制度而非普通法

## 3. 依职权提出（Relevé d'Office）

### 法律主张（Moyens de droit）

法官**可以**依职权提出法律主张，但须遵守对审原则。

**程序**：
1. 法官识别一个未被提出的主张
2. 法官邀请当事方就此说明（《民事诉讼法典》第16条）
3. 法官在当事方陈述意见后裁判

### 公共秩序主张（Moyens d'ordre public）

法官**必须**依职权提出某些主张：

**强制性主张**：
- 欧盟的公共秩序规则
- 公共秩序的管辖权归属规则
- 既判力（如当事方、标的和原因相同）

### 不予受理事由（Fins de non-recevoir）

**一般制度**：
- 法官**可以**依职权提出（《民事诉讼法典》第125条）
- 法律另有规定的除外

**公共秩序不予受理事由**（必须依职权提出）：
- 缺乏资格（défaut de qualité）
- 缺乏利益（défaut d'intérêt）
- 既判力（chose jugée）

## 4. 法官职责的界限

### 尊重争议标的（《民事诉讼法典》第4条）

> "争议的标的自当事方各自的主张确定。"

**禁止**：法官不得：
- *Ultra petita* 裁判（超出请求范围）
- *Extra petita* 裁判（就请求之外的事项裁判）
- 遗漏就请求事项裁判（*infra petita*）

### 层级化的主张

当事方提出补充性请求时，法官必须尊重该层级：
1. 首先审查主请求
2. 仅在主请求失败时才审查补充请求

### 对审原则（《民事诉讼法典》第16条）

> "法官必须在任何情况下促使人遵守并亲自遵守对审原则。"

**适用**：
- 在依职权提出主张之前：邀请当事方说明
- 在重新定性之前：将新的定性提交辩论
- 在使用附带事实之前：允许讨论

## 5. 法官不得依职权提出的事项

### 时效（《民法典》第2247条）

> "法官不得依职权补充时效抗辩。"

**后果**：即使诉讼显然已过时效，法官也不能依职权宣告其不予受理。

### 保护特定利益的程序无效

相对无效只能由受保护的当事方主张。

### 被告缺席时的个人主张

被告缺席时，法官不能提出被告本可以援引的主张。

## 6. 汇总表

| 情形 | 法官的权力 | 条件 |
|-----------|-----------------|-----------|
| 事实的定性 | **义务** | 对审原则 |
| 法律依据的变更 | **可能性** | 对审原则 + 事实在辩论中 |
| 依职权提出法律主张 | **可能性** | 对审原则 |
| 依职权提出公共秩序主张 | **义务** | 对审原则 |
| 不予受理事由 | **可能性** | 对审原则 |
| 公共秩序不予受理事由 | **义务** | 对审原则 |
| 时效 | **禁止** | - |
| 辩论之外的事实 | **禁止** | - |
| 修改争议标的 | **禁止** | - |
