# 继承纠纷举证质证要点

## 核心原则

- 以中国大陆民事诉讼和继承法律制度为默认法域；涉及其他法域时先说明本技能资料不适用。
- 把用户提供的案件事实、文书和证据置于参考材料之前。不得用通用模板替代个案分析。
- 区分“举证方证明方案”与“对方质证方案”，并区分真实性、合法性、关联性和证明力。
- 不把材料中的法律依据视为当然现行有效。凡输出法条编号、司法解释状态、举证责任结论或时效结论，均通过全国人大、最高人民法院、中国政府网等官方来源核验。
- 只陈述证据能够支持的事实；对推断、待核实事实和证据缺口作醒目标记。
- 不编造证据、案件事实、鉴定意见、裁判观点或来源。发现材料可能违法取得时，提示合法取证边界。

## 工作流

### 1. 建立案件画像

从用户材料中提取：

1. 当事人及亲属关系；
2. 被继承人死亡时间、住所地和遗产所在地；
3. 用户诉讼角色、诉讼请求及对方抗辩；
4. 继承方式和争议焦点；
5. 已有证据、证据持有人、原件状态及形成时间；
6. 一审、二审、再审或执行等程序阶段；
7. 涉外、港澳台、公司股权、不动产、保险或电子数据等特别因素。

信息不足但仍可工作时，先输出“暂定事实与待确认问题”，再给条件式方案。只有关键分支无法合理判断时才提一个简短问题。

### 2. 选择争议模块

按案情选择一个或多个模块：

- 法定继承与继承人资格；
- 代位继承与转继承；
- 遗嘱效力确认；
- 遗嘱解释与执行；
- 遗产范围确认与分割；
- 被继承人债务清偿；
- 遗赠；
- 遗赠扶养协议；
- 遗产管理人；
- 非继承人适当分得遗产；
- 继承权丧失与恢复；
- 诉讼程序、时效与新旧法衔接。

### 3. 检索参考框架

先在 [evidence-framework.md](references/evidence-framework.md) 中按争议模块、待证事实或证据类型定位相关段落。需要原资料中的具体证据名称和质证角度时，再以关键词检索 [source-material-ocr.md](references/source-material-ocr.md)，只读取命中段落及必要上下文。

OCR 可能存在错字、漏字和表格串行，不得直接用于法条、日期、金额、案号或专有名词的最终引用。参考材料用于发现证据类型、证据链和攻防角度，不是固定答案，也不替代现行法检索及个案论证。用户材料与参考材料冲突时，以经核验的个案事实和现行法律为准。

### 4. 构建证据矩阵

每项证据至少分析：

| 字段 | 内容 |
|---|---|
| 证据名称 | 明确载体、形成主体和原件状态 |
| 拟证明事实 | 只写该证据直接或间接支持的事实 |
| 举证责任 | 说明由谁提交及不利后果 |
| 举证方要点 | 来源、形成过程、证据链和补强方式 |
| 对方质证 | 分真实性、合法性、关联性、证明力提出具体意见 |
| 风险等级 | 高、中、低，并给出理由 |
| 补强动作 | 调取、核验、公证、鉴定、证人出庭、关联印证等 |
| 法律依据 | 仅列经官方来源核验的现行依据 |

不得机械地对所有证据同时否认“四性”。质证意见必须指出具体瑕疵、事实冲突和预期法律后果。

### 5. 检查证据链

逐项检查：

- 主体身份链：死亡事实、亲属关系、婚姻收养关系、继承资格；
- 权利来源链：财产取得、登记、出资、代持、夫妻共同财产与个人财产；
- 意思表示链：遗嘱能力、形式、见证、保管、变更与撤回；
- 时间链：形成、死亡、接受遗赠、起诉、财产处分等时间点；
- 原件与电子数据链：原始载体、元数据、提取过程、保管和完整性；
- 相互印证链：书证、证人证言、鉴定、公证、流水和行政档案能否闭合。

### 6. 输出结果

默认依次输出：

1. 案件画像与暂定争议焦点；
2. 优先级排序的证据清单；
3. 举证与质证矩阵；
4. 关键证据缺口及补强路径；
5. 庭审发问或质证提纲；
6. 经核验的法律依据与核验日期；
7. 风险提示。

用户只要求其中一种成果时，仅输出所需部分。使用简洁、可直接用于律师工作底稿的中文，不写泛泛的法治常识。

## 特别证据处理

- 遗嘱：核验遗嘱类型、订立时间、行为能力、形式要件、见证人资格、原件、笔迹或录音录像连续性、多份遗嘱冲突及撤回变更。
- 亲属关系：优先形成户籍、婚姻、出生、收养、档案、公证及相互印证链；单一村居证明通常需要补强。
- 不动产和股权：区分登记状态与实际权属，审查取得时间、资金来源、代持、夫妻共有、公司章程和其他股东权利。
- 银行流水与电子数据：说明调取主体、账户归属、完整区间、原始载体、哈希或提取过程，并避免将资金流向直接等同于权属。
- 被继承人债务：审查债务真实性、用途、履行、诉讼时效、夫妻共同债务属性及遗产实际价值。
- 证人证言：审查利害关系、感知来源、记忆条件、陈述一致性和出庭接受询问情况。

## 交付前检查

- 争议焦点是否与诉讼请求对应；
- 每项证据是否对应明确待证事实；
- 是否区分证据资格、证明力与事实推断；
- 是否遗漏对己方不利证据和对方最强抗辩；
- 法条、司法解释、施行日期和效力状态是否经官方来源核验；
- 是否明确参考框架的通用性局限；
- 是否避免承诺裁判结果，并提示正式诉讼应由执业律师结合原件复核。
