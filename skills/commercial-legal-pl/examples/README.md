# 测试材料

用于测试技能而不涉及客户数据的虚构文件。

## 测试案卷（`testowe-akta/`）

| 文件 | 合同类型 | 待检测的关键风险 |
|------|-----------|----------------------------|
| `01-nda-b2b.md` | 双向 NDA | 无违约金、„niezwłocznie"（立即）、保密信息定义过窄、合同结束后无保密义务 |
| `02-body-leasing-it.md` | IT body leasing | 劳动关系风险、无使用领域（PrAut，著作权法）、排除 lucrum cessans 而未保留故意过错例外（《民法典》第 473 条第 2 款）、无 non-solicitation |
| `03-saas-z-dpa.md` | SaaS + DPA/RODO | 无硬性 SLA、无解约窗口的自动续约、UPD（委托处理协议）不完整（依 RODO 第 28 条第 3 款缺审计、违约、次处理者） |

## 如何使用

1. 将文件内容（不含警示块）粘贴到加载了技能的 Claude 会话中。
2. 请求：triage、完整分析、风险审计或特定工作流。
3. 将结果与文件页脚的风险清单对比——这是你的基准。

这些文件刻意包含“网上找的”合同或未经法律审查的初稿所特有的漏洞。技能应当能发现它们。

## 规则

- 所有数据（名称、KRS、NIP、人员）均为**虚构**——不得在真实文件中使用。
- KRS 号码以 `0000999` 开头——超出真实登记范围。
- 你可以编辑文件，以在特定条款配置下测试技能。
