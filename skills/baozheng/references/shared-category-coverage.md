# 法律类别覆盖矩阵

本文件用于约束 baozheng-skills 对常见法律类别的承接边界。凡用户问题落入下表任一类别，必须先按本矩阵判断输出类型，避免把“可咨询”误写成“已有专属模板”。

## 覆盖等级

- **专属模板**：已有独立 `assets/template-*`、`references/case-*`、`examples/*-data.json` 和质量门禁。
- **专项材料**：已有专项材料模板或刑事专项流程，但不等同于诉讼代理文书。
- **通用模板**：可使用通用民事起诉状模板或通用咨询流程承接，需要先追问事实要素。
- **法规检索**：优先进入模块C，以现行法规、法条分析、程序路径为主。

## 路由规则

1. 用户要“写起诉状/告他/立案”时，优先匹配专属模板；无专属模板时使用 case-00-general-civil.md 通用民事模板，并说明“当前为通用模板承接”。
2. 用户要“刑事/罪名/控告/取保候审/强制措施/辩护意见/刑事附带民事/羁押家属沟通”时，进入 `module-d-criminal.md`，不得输出承诺式辩护结论。
3. 用户要“查法律依据/法条/政策/行政处罚/征收补偿/涉外程序”时，进入 `module-c-analysis.md`，优先使用官方法规源。
4. 涉及重大人身自由、刑事羁押、行政强拆、群体性纠纷、重大医疗损害、涉外送达等高风险事项时，必须提示尽快委托对应领域执业律师。
5. 意图不清晰时，启动 `shared-intent-convergence.md` 渐进式收敛协议，按3轮状态机逐步确定领域和意图类型。
