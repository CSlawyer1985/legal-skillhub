# 涉外民商事纠纷 — 模块速览

## 模板文件

`assets/template-22-foreign-related.md`

## 表格结构

约18行字段，要素式结构（含说明、当事人、涉外信息、诉讼请求、事实和理由、证据收尾），适用于涉外民商事起诉状辅助

## 适用场景

- 境内外主体之间的买卖合同、服务合同、跨境付款、投资和结算争议
- 境外公司、境外自然人、港澳台主体参与的民商事起诉状草拟
- 涉外管辖、准据法、送达、外文证据翻译、公证认证或附加证明书路径提示
- 中国法院可管辖的涉外民商事争议，不处理纯境外法律争议

## 模块分布

### 模块一：说明与当事人（Row01-Row03）

| Row | 标签 | 填写内容                                                                                             |
| :-: | :--- | :--------------------------------------------------------------------------------------------------- |
| 01  | 说明 | 涉外民商事纠纷须核对境外主体身份、管辖依据、准据法、送达路径、证据公证认证或附加证明书、外文材料翻译 |
| 02  | 原告 | 境内或境外自然人、法人或其他组织名称、证件号或注册号、住所地、联系方式；境外主体需写明国家或地区     |
| 03  | 被告 | 境内或境外交易相对方名称、注册号、住所地、可送达地址、电子邮箱、合同联系人和主体识别线索             |

**追问要点：**

- 境外主体注册地、注册号、住所地、实际经营地址、可送达地址和联系人
- 境外主体登记资料、营业执照或同等效力文件的获取情况
- 是否存在境内代表机构、分支机构或代理人

### 模块二：涉外信息（Row04）

| Row | 标签     | 填写内容                                                                               |
| :-: | :------- | :------------------------------------------------------------------------------------- |
| 04  | 涉外信息 | 合同签订地、履行地、付款地、标的所在地、争议解决条款、适用法律条款、送达条款、语言版本 |

**追问要点：**

- 合同是否约定争议解决条款（法院管辖/仲裁）及适用法律条款
- 合同签订地、履行地、付款地、标的物所在地等涉外连接点
- 合同是否约定送达地址、电子送达方式及语言版本
- 是否存在电子送达约定、境内可供保全的财产线索

## 必问要素

- 境外主体注册地、注册号、住所地、实际经营地址、可送达地址和联系人
- 合同签订地、履行地、付款地、标的所在地、争议解决条款和适用法律条款
- 交易履行证据：合同、订单、发货、报关、提单、验收、付款和对账材料
- 外文材料是否已翻译，境外形成证据是否具备公证认证或附加证明书
- 是否存在电子送达约定、境内代表机构、财产线索或可供保全的境内资产

## 风险提示

- 涉外案件必须先确认中国法院管辖基础，不能仅因原告在中国就默认可起诉。
- 境外证据、授权文件和主体资格材料经常涉及翻译、公证认证或附加证明书要求。
- 最终输出必须附加 `references/shared-disclaimer.md` 的免责声明要点。

## 法律依据

- 《中华人民共和国民法典》第四百六十七条（涉外民事关系的法律适用）
- 《中华人民共和国涉外民事关系法律适用法》
- 《中华人民共和国民事诉讼法》第四编"涉外民事诉讼程序的特别规定"（2023年9月修订，2024年1月1日施行）
- 《最高人民法院关于涉外民商事案件管辖若干问题的规定》
- 《最高人民法院关于适用〈中华人民共和国涉外民事关系法律适用法〉若干问题的解释》
- 《取消外国公文书认证要求的公约》（1961年海牙公约，附加证明书/Apostille）
- 《海牙送达公约》（1965年《关于向国外送达民事或商事司法文书和司法外文书公约》）
