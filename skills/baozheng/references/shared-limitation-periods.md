## A9. 诉讼时效追踪提醒

在分析涉及金钱给付、合同违约、侵权赔偿等民事纠纷时，**自动检查诉讼时效**：

### 标准时效速查

#### 民事/行政时效

- **普通诉讼时效**：3年（《**中华人民共和国民法典**》**第188条**）
- **劳动争议仲裁时效**：1年（《**中华人民共和国劳动争议调解仲裁法**》**第27条**）
- **人身损害赔偿**：3年（民法典第188条）
- **产品质量责任**：2年（《**中华人民共和国产品质量法**》**第45条**）
- **国家赔偿请求时效**：2年（《**中华人民共和国国家赔偿法**》**第39条**）
- **行政诉讼起诉期限**：6个月（《**中华人民共和国行政诉讼法**》**第46条**）
- **专利侵权诉讼时效**：2年（《**中华人民共和国专利法**》**第74条**，自权利人得知或应当得知之日起算）
- **商标侵权诉讼时效**：3年（《**中华人民共和国商标法**》**第39条**）
- **著作权侵权诉讼时效**：3年（《**中华人民共和国著作权法**》**第10条**，自权利人知道或应当知道权利受到损害及义务人之日起算）
- **保险理赔诉讼时效**：2年（《**中华人民共和国保险法**》**第26条**，自知道或应当知道保险事故发生之日起算）
- **证券虚假陈述诉讼时效**：3年（《**中华人民共和国证券法**》**第85条**，自知道或应当知道权益受到损害之日起算）
- **遗赠接受期限**：受遗赠人应当在知道受遗赠后**60日内**作出接受表示（《**中华人民共和国民法典**》**第1124条**，到期未表示视为放弃受遗赠）
- **最长保护期限**：20年（《**中华人民共和国民法典**》**第188条**："自权利受到损害之日起超过二十年的，人民法院不予保护，有特殊情况的，人民法院可以根据权利人的申请决定延长。"）

#### 刑事追诉时效

> 刑事追诉时效与民事时效体系完全不同，module-d 刑事辅助时必须参考本节。法条以 flk.npc.gov.cn 官方 API 为准。

- **法定最高刑 < 5年**：追诉时效 **5年**（《**中华人民共和国刑法**》**第87条**第1项）
- **法定最高刑 5年以上不满10年**：追诉时效 **10年**（刑法第87条第2项）
- **法定最高刑 10年以上有期徒刑**：追诉时效 **15年**（刑法第87条第3项）
- **法定最高刑 无期徒刑/死刑**：追诉时效 **20年**（刑法第87条第4项；如20年后认为必须追诉的，须报请最高人民检察院核准）
- **追诉时效延长**：在司法机关立案侦查或在法院受理案件以后，逃避侦查或审判的，**不受追诉期限限制**（刑法第88条第1款）；被害人在追诉期限内提出控告，司法机关应当立案而不予立案的，**不受追诉期限限制**（刑法第88条第2款）
- **追诉时效中断**：在追诉期限以内又犯罪的，前罪追诉的期限从犯后罪之日起算（刑法第89条第2款）

### 时效检查话术

在分析中主动添加时效提醒：
```
💡 时效提示：本案【纠纷类型】的诉讼时效为【X年】，自【起算时间点】起算。
您需要确认是否在时效期限内？如已接近时效届满，建议尽快采取行动（起诉/仲裁/发函催告等）。
```
