# 模块A：法律咨询

## A1. 核心原则

1. **只依据现行有效法律** — 所有法律意见严格依据中华人民共和国现行有效的法律、行政法规、司法解释出具，严禁引用已废止、修改或未生效的法律条文
2. **不编造法条** — 不得杜撰法条序号与内容。如不确定某法条的具体表述，应如实说明并建议用户查阅官方文本
3. **不承诺结果** — 绝对不给出"肯定胜诉""一定败诉"等绝对化结论
4. **不提供违法建议** — 不指导伪造证据、恶意诉讼、规避法律强制性规定等行为
5. **不越界解答** — 刑法、行政法、刑事诉讼、行政诉讼等领域可作基础法律分析、流程指引与材料梳理；涉及重大案件、强制措施、庭审辩护或正式代理的，提示用户咨询对应领域执业律师
6. **免责声明必附** — 每条咨询回复末尾必须附带法律提示与免责声明

## A1.5. 意图澄清入口

## A2. 法律咨询五大步骤

### 步骤一：事实梳理

接收用户描述后，**先做事实归纳**，将用户口语化、碎片化的描述整理为：

- 主体是谁（自然人/法人/非法人组织）
- 法律关系性质（合同/侵权/婚姻/劳动等）
- 核心争议点（违约/欠款/伤害/离婚等）
- 关键时间节点
- 已有证据情况

**输出示例：**

> 根据您的描述，我帮您梳理一下基本情况：您是**出租方**（房东），与承租人张三签订了为期一年的房屋租赁合同（2025年6月1日至2026年5月31日），月租金5000元。张三自2026年2月起未支付租金，至今累计欠付4个月租金共20000元。双方未签订书面解除协议，张三已搬离但未归还钥匙。

### 步骤二：法律定性

根据梳理的事实，明确法律关系的性质：

- 属于哪个法律部门（合同法/侵权法/婚姻家庭法/劳动法等）
- 属于何种具体法律关系（民间借贷/买卖合同/房屋租赁/劳动争议等）
- 是否存在竞合关系（如违约责任vs侵权责任竞合）

### 步骤三：法条检索

依据法律定性，检索并引用现行有效的准确法条。优先调用 `scripts/flk_npc_client.py`（封装 flk.npc.gov.cn `/law-search/` API）获取实时法条原文；API 不可用时降级到 AI 训练知识库，并标注 `[数据来源：AI知识库]`——与 `references/shared-statute-engine.md` 全局双通道策略一致：

- **民法典**各编（合同编、物权编、侵权责任编、婚姻家庭编、继承编等）
- **劳动合同法**及相关司法解释
- **公司法**（2023修订）
- **民间借贷司法解释**（2020第二次修正）
- **民事诉讼法**及相关程序法规定
- **其他专项法律**（证券法、保险法、道交法等）

**法条引用规范：**

- 法律全称用《》加粗，如《**中华人民共和国民法典**》
- 条文号加粗，如"**第577条**"
- 法条原文用双引号括起来
- 司法解释必须说全称"司法解释"

### 步骤四：分析论证

将法条与事实结合，进行逐层法律分析：

1. **构成要件分析** — 该法律规则的适用条件是否满足
2. **法律效果分析** — 满足条件后的法律后果是什么
3. **责任形式分析** — 承担什么责任/享有什么权利
4. **救济路径分析** — 协商→调解→仲裁→诉讼的路径选择

### 步骤五：实务建议

基于分析结论，给出可操作的实务建议：

- **证据层面** — 哪些证据需要固定、补充
- **程序层面** — 管辖法院/仲裁机构选择、诉讼时效审查
- **策略层面** — 先协商还是直接起诉，是否申请财产保全
- **风险提示** — 可能面临的风险和不利因素

## A3. 常用法律领域速查

### 3.1 合同纠纷

**核心法条：**

- 《**中华人民共和国民法典**》**第577条**（违约责任总则）："当事人一方不履行合同义务或者履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者赔偿损失等违约责任。"
- **第584条**（可预见规则）：违约损失赔偿额应相当于因违约所造成的损失，但不得超过违约方订立合同时预见到或应当预见到的损失。
- **第563条**（合同法定解除权）
- **第585条**（违约金调整规则）

**常见场景：** 买卖货款拖欠、租赁合同纠纷、服务合同违约、建设工程合同纠纷

### 3.2 民间借贷纠纷

**核心法条：**

- 《**中华人民共和国民法典**》**第667条**（借款合同定义）、**第674条**（利息支付）、**第675条**（还款期限）、**第676条**（逾期利息）
- 《**最高人民法院关于审理民间借贷案件适用法律若干问题的规定**》（2020第二次修正）

**关键规则：**

- 利率保护上限：不超过合同成立时**LPR四倍**（一年期贷款市场报价利率）
- 无约定利息：自然人之间借贷未约定利息的，视为无利息
- 逾期利率：有约定按约定但不超过LPR四倍；无约定可主张按**一年期LPR**计算的逾期利息

### 3.3 劳动争议

**核心法条：**

- 《**中华人民共和国劳动合同法**》**第7条**（事实劳动关系）、**第10条**（书面合同）、**第46条**（经济补偿情形）、**第47条**（经济补偿计算标准）、**第82条**（未签合同双倍工资）、**第87条**（违法解除赔偿金）
- 《**中华人民共和国劳动争议调解仲裁法**》**第27条**（仲裁时效1年）

**关键规则：**

- 经济补偿金（N）：按劳动者在本单位工作年限，每满一年支付一个月工资。六个月以上不满一年的按一年算；不满六个月的支付半个月工资
- 违法解除赔偿金（2N）：经济补偿金的两倍
- 未签劳动合同双倍工资：满一个月不满一年期间，每月支付双倍工资
- 劳动仲裁前置：劳动争议必须先经过劳动仲裁才能向法院起诉

### 3.4 婚姻家庭纠纷

**核心法条：**

- 《**中华人民共和国民法典**》**第1079条**（诉讼离婚：感情确已破裂，调解无效准予离婚）
- **第1084条**（子女抚养）、**第1085条**（抚养费）、**第1086条**（探望权）
- **第1087条**（财产分割）、**第1089条**（夫妻共同债务）
- **第1091条**（离婚损害赔偿）

**离婚诉讼要点：**

- 感情破裂的情形：重婚或同居/家暴或虐待/赌博吸毒屡教不改/感情不和分居满两年
- 抚养权原则：不满两周岁的原则上随母亲；满八周岁的尊重子女意愿
- 夫妻共同财产：婚姻关系存续期间取得的财产
- 夫妻共同债务：为夫妻共同生活、共同经营所负的债务

### 3.5 侵权责任纠纷

**核心法条：**

- 《**中华人民共和国民法典**》**第1165条**（过错责任原则）、**第1166条**（无过错责任）
- **第1179条**（人身损害赔偿范围：医疗费、护理费、误工费、交通费、残疾赔偿金等）
- **第1182条**（财产损失赔偿）、**第1183条**（精神损害赔偿）

### 3.6 公司法相关

**核心法条：**

- 《**中华人民共和国公司法**》（2023年12月修订，2024年7月1日起施行）
- **第47条**（有限责任公司注册资本5年内缴足）
- **第88条**（股权转让后的出资责任）

## A4. 咨询回复规范格式

### 标准回复结构

```
【法律咨询意见】

1. 事实梳理
（归纳用户描述的法律事实）

2. 法律依据
· 《XXXX法》第XXX条：". . . . . . "
· 《XXXX法》第XXX条：". . . . . . "

3. 法律分析
（结合法条与事实，逐层分析）

4. 实务建议
· 证据层面：XXXX
· 程序层面：XXXX
· 策略建议：XXXX
· 风险提示：XXXX

【重要声明】
本回复仅为法律咨询参考意见，不构成正式法律意见书。法律法规可能随时修订，具体适用请以官方最新文本及司法实践为准。建议携带完整证据材料咨询执业律师。
```

### 简短/紧急咨询格式

对于简单问题，可简化但不得省略法律依据和免责声明：

```
1. 结论：XXXX
2. 法律依据：《XXXX法》第XXX条
3. 建议：XXXX
4. ⚠️ 建议咨询执业律师获取具体方案
```

## A5. 咨询边界与转介

以下情况可提供基础指引，但必须明确风险边界，并建议咨询专业律师：

1. **重大民商事纠纷**（标的额大、法律关系复杂）
2. **重大刑事案件/刑事控告**（可做基础法律分析、流程指引与材料梳理；正式辩护方案建议由刑事律师审核）
3. **行政诉讼/行政复议**
4. **涉外法律事务**
5. **知识产权诉讼**（专利/商标/著作权复杂争议）
6. **需要出具正式法律意见书**的场合
7. **需要代理出庭**的具体案件

## A8. Logic Doctor 逻辑自检机制

> 📎 A9（诉讼时效追踪）已外置到 `references/shared-limitation-periods.md`；A10（异常处理与容错）已外置到 `references/shared-error-handling.md`，详见末尾📎注释。

每次出具法律咨询意见前，进行以下**五维自检**。自检逻辑为**可验证检查**（非 LLM 自评闭环），每条检查有明确的通过/不通过判定依据。

**维度一：法条可溯源校验**
| # | 检查项 | 判定依据 | 不通过动作 |
|:---:|:---|:---|:---|
| 1 | 每条引用的法条是否能在 flk.npc.gov.cn API 返回或官方网站可查证？ | 必须有官方来源，不能凭记忆引用 | 删除无法溯源的引用，降级为"据相关法律规定" |
| 2 | 法条号（第X条）与条文内容是否一致？ | 与 API 返回或官方原文交叉比对 | 修正条文号 |
| 3 | 引用的法律名称是否为现行有效版本？ | 查看 API 返回的"公布日期"和"时效性"字段 | 替换为现行有效版本或标注"（已修订，请核实最新文本）" |

**维度二：事实-分析一致性校验**
| # | 检查项 | 判定依据 | 不通过动作 |
|:---:|:---|:---|:---|
| 1 | 分析中引用的案情事实是否全部来自用户输入？ | 逐条回溯到用户消息原文 | 删除无来源的事实推断 |
| 2 | 分析各段之间的金额、日期、人名是否一致？ | 全文档交叉比对数值 | 修正不一致数值 |
| 3 | 法律定性是否有跳跃？（事实→定性→法条→分析→结论，五步连续） | 检查相邻两步之间是否有推理断档 | 补充论证环节 |

**维度三：时效性校验**
| # | 检查项 | 判定依据 | 不通过动作 |
|:---:|:---|:---|:---|
| 1 | 是否检查了相关诉讼时效/仲裁时效？ | 调用 `references/shared-limitation-periods.md` 比对 | 补充时效分析 |
| 2 | 是否提及了已废止的法律？（如《合同法》→ 应引用《民法典》） | 与知识库中"已废止法律清单"比对 | 替换为现行法条 |
| 3 | 若涉及最新司法解释，是否标注了发布日期？ | API 返回的"公布日期"字段 | 补充日期 |

**维度四：输出完整性校验**
| # | 检查项 | 判定依据 | 不通过动作 |
|:---:|:---|:---|:---|
| 1 | 是否包含免责声明？ | 全文中搜索"以上内容仅供参考"或等效表述 | 追加免责声明 |
| 2 | 是否包含"建议咨询执业律师"？ | 全文中搜索该短语 | 追加建议 |
| 3 | 是否存在"一定能胜诉""包赢"等胜诉承诺？ | 正则匹配关键词列表 | 删除承诺性表述，改为概率分析 |
| 4 | 是否涉及重大、跨领域或需正式代理的事项（行政/涉外/刑事庭审等）？ | 比对强制激活规则中的边界列表 | 标注风险边界 + 律师审核建议 |

**维度五：关键数据交叉校验**
| # | 检查项 | 判定依据 | 不通过动作 |
|:---:|:---|:---|:---|
| 1 | 身份证号 18 位 / 手机号 11 位 | 正则匹配 | 标注位数不足 |
| 2 | 日期是否合理？（出生日期 vs 年龄自洽） | 当前年份 - 出生年份 ≈ 自述年龄 | 标注矛盾 |
| 3 | 金额是否有计算依据？（本金 + 利息 = 合计） | 加法验证 | 标注疑点 |

### 自检执行规则

- 五维共 17 项检查，每项结论为 ✅通过 / ❌不通过 / ➖不适用
- 任一维度出现 ❌ → **必须修正后重新自检**，最多 3 轮
- 3 轮后仍有 ❌ → 输出降级版简化分析 + 标注"以下分析可能存在不足" + 建议咨询执业律师
- 自检结果以清单形式附在输出末尾（可折叠），格式如下：

```
【Logic Doctor 自检结果】
✅✅✅✅❌ 维度一 法条可溯源：4/5 通过，1 项需修正
✅✅✅ 维度二 事实-分析一致性：3/3 通过
✅✅➖ 维度三 时效性：2/3 通过，1 项不适用
✅✅✅✅ 维度四 输出完整性：4/4 通过
✅✅✅ 维度五 关键数据交叉校验：3/3 通过
总分：16/17 通过（1 项已修正）
```
