## 通用填充代码示例

通用民事起诉状的段落式填充实现（`create_generic_complaint_docx` 函数）位于 `references/module-b-complaint.md` B5 节，本文件不再重复，仅列出关键要点。

**快速调用：**

```bash
python scripts/generate_complaint_docx.py --case 00 --output 起诉状.docx
python scripts/generate_complaint_docx.py --case 00 --data examples/general-civil-data.json --output 起诉状-filled.docx
```

**手动填充要点（按 P0-P21 段落分布）：**

1. 标题"民事起诉状"（P0）保持不动
2. 当事人信息（P2-P8）按段落替换 `×××` 占位符
3. 诉讼请求（P9-P10）/ 事实理由（P11-P12）/ 证据（P13-P14）逐段替换
4. 受诉法院（P15-P16）替换法院名称
5. 副本份数（P18）= 被告人数
6. 具状人+日期（P20-P21）右对齐，保持不动

## 适用场景

当用户描述的案由不在34个专属模板范围内时，使用本通用模板生成起诉状。例如：

- 服务合同纠纷
- 相邻关系纠纷
- 产品责任纠纷
- 名誉权/隐私权纠纷
- 合伙协议纠纷
- 承揽合同纠纷
- 运输合同纠纷
- 等（非34个专属模板的案由均可使用）

## 追问要点

### 案由识别

- 用户描述的纠纷是否属于34个专属模板范围（如民间借贷/离婚/买卖合同等）
- 如不属于专属模板，确认具体法律关系性质（合同/侵权/物权/人格权等）
- 是否存在案由竞合（如违约责任与侵权责任竞合）

### 当事人信息

- 原告/被告的姓名/名称、身份证号/统一社会信用代码、住所地、联系方式
- 是否有共同诉讼当事人、第三人、法定代理人、委托诉讼代理人
- 当事人主体资格证明材料是否齐备

### 诉讼请求

- 具体请求事项（确认/给付/变更/赔偿等）
- 请求金额及计算依据（本金/利息/违约金/损失赔偿等）
- 是否申请财产保全、行为保全、证据保全

### 事实和理由

- 法律关系成立的时间、地点、方式
- 对方违约或侵权的事实经过
- 损害后果及因果关系
- 是否经过协商、调解、仲裁等前置程序

### 证据和管辖

- 现有证据清单（合同/转账记录/聊天记录/证人证言等）
- 是否存在管辖约定（协议管辖条款）
- 管辖法院确定依据（被告住所地/合同履行地/侵权行为地等）

## 风险提示

- 通用模板适用于非34个专属模板的案由，AI 应优先识别是否匹配专属模板
- 诉讼请求金额需有计算依据，避免主观估计
- 证据材料应在起诉前固定，避免证据灭失
- 最终输出必须附加 `references/shared-disclaimer.md` 的免责声明要点

- 《中华人民共和国民事诉讼法》（起诉条件、管辖、证据规则等）
