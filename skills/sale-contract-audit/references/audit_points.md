# 销售合同审核要点清单（乙方视角）

本文档详细列出了销售合同审核的关键要点，供审核时参考使用。**审核视角为乙方（卖方）**，从乙方利益出发识别风险。

---

## 一、审查总体目标（优先级顺序）

审查销售合同时，应依次判断以下四个层面（从乙方视角）：

1. **合法性**：条款是否违反《民法典》强制性规定？（最高优先级）
2. **可执行性**：条款在司法实践中是否可能被认定无效或不被支持？
3. **风险可控性**：乙方与甲方的权利义务是否实质对等？是否存在对乙方不利的单方陷阱？
4. **商业目标匹配**：条款是否妨碍乙方正常履约和回款？

---

## 二、合同要点总结字段要求

### 必需字段（从乙方视角）

| 字段 | 说明 | 审核要点 |
|------|------|----------|
| 合同主体 | 甲方（买方）、乙方（卖方） | 确认乙方名称、签约代表权限 |
| 合同标的 | 产品/服务内容 | 规格型号是否唯一可量化 |
| 合同金额 | 金额及是否含税 | 税率、价外费用 |
| **付款方式** | **付款条件**（预付款比例、时间节点、验收款、质保金、发票等） | 首付比例、付款节点、是否有"背靠背"条款、**付款金额和增值税专用发票金额和比例是否一致（不一致=中风险）** |
| **发票要求** | 每个阶段需提供的发票类型和金额 | **付款与发票金额是否一致** |
| **合同变更** | 变更原则和变更计价方式 | 变更程序是否明确、变更计价方式是否合理 |
| 交付时间 | 交付期限及起算条件 | 工作日/自然日、工期合理性 |
| **验收期** | **验收期限及起始条件** | 必须明确"收到乙方验收申请之后X日内完成" |
| **质保期** | **质保期限及起始条件** | 必须明确"验收合格之日起"或"收到乙方验收申请之后" |
| **合同生效条件** | 合同生效的条件 | 签字盖章后生效？是否需要预付款到账？ |
| **合同终止条件** | 合同终止的条件和方式 | 解除条件、终止后的义务 |
| **争议解决** | 管辖约定及管辖地 | 乙方所在地优先 |
| **违约责任** | 双方违约责任概述 | 违约金是否对等、**违约责任是否有单边风险**、违约责任是否对等、**发票违约责任是否明确** |
| **违约责任** | 发票违约责任 | 乙方未正常纳税、未按期提供发票、提供发票不合规的责任 |
| **违约责任** | 单边违约风险判断 | 是否存在只对乙方不利的单边违约条款 |
| 合同期限 | 合同有效期 | 生效日至质保期结束 |

## 三、通用审查维度与法律要点

### 1. 背景情况、合同主体与资信（乙方视角）

**审查要点**：
- 项目公开信息、资金来源（甲方资金是否到位）
- 甲方是否为合法存续的法人
- 分公司签约需提供总公司授权书（对乙方风险）
- **甲方履约信用情况（涉诉、被执行）** - 乙方收款风险

**乙方风险**：分公司无授权、代理过期、印章虚假，合同效力待定，乙方可能无法主张权利

---

### 2. 标的物与规格

**审查要点**：
- 产品名称、品牌、型号、数量、技术参数、质量标准必须**唯一、可量化**
- **禁止"同等质量""类似品牌"等模糊表述**
- 乙方须保证对所售货物拥有完整所有权，且不侵犯第三人知识产权

**乙方风险**：标准不明→甲方拒收或要求退货；知识产权瑕疵→甲方被诉，乙方承担赔偿责任

---

### 3. 交付与风险转移

**审查要点**：
- **交付方式**：建议明确风险转移节点
- **交付期限**：区分"工作日""自然日"，并预留合理工期
- **分批交货**：若允许分批，需约定"单批延迟是否导致整合同解除"
- **验收期限**（关键！）：
  - 设定明确的检验/验收期限（如"货到后15日内"或"**收到乙方验收申请之后15日内**"）
  - **必须加入默示条款**："若甲方在上述期限内未提出书面异议，视为验收合格"
  - **默示验收条款已覆盖全部验收环节**，无需单独区分初验/终验流程
  - 限制验收标准：原则上以合同及附件参数为准，避免接受甲方单方面制定的过于苛刻的"内部标准"
- **风险转移时点**：通常建议约定"交付给甲方或甲方指定承运人后，毁损、灭失风险由甲方承担"
- **交货地点**：明确交货地点和交货时间
- **所有权保留条款**（乙方保护）：约定"甲方未付清全部货款前，货物所有权仍属于乙方"

**乙方风险**：若无验收期限限制，甲方可能在使用数月甚至数年后才提出"质量不合格"，以此拒付尾款或索赔

---

### 4. 价格与支付（重点！）

**审查要点**：
- **价格是否含税**？税率变化时价格是否调整？
- **付款条件**（必须详细审核）：
  - 预付款、进度款、尾款、质保金的比例是否合理
  - **首付比例建议30%-50%**，避免低首付长周期
  - 可考虑争取"预付款+发货前付至XX%+验收款+质保金"
  - **避免"货到付款"或笼统的"验收后付款"**
  - 项目整体付款安排、回款预计周期
  - **尾款比例不应过低**（建议不低于10%）
  - **先开票后付款**的，必须约定"收到发票后X个工作日内支付"
  - **警惕"背靠背"付款条款** - 该条款已超越合同相对性，司法实践中往往不被支持，**应明确拒绝**

---

### 5. 售后服务与质保（关键！）

**乙方视角核心原则（重要！）**：
- **"自交付之日起"起算质保期对乙方有利**：质保期限固定，不受甲方拖延验收影响
- **"自验收合格之日起"起算质保期对乙方不利**：甲方可通过拖延验收无限延长乙方的质保义务

**审查要点**：
- **质保期起算点**（必须明确！）：
  - **有利于乙方：**"**自交付之日起**"或"**自提交验收申请之日起**"——锁定质保期限，甲方拖验收不影响质保到期
  - **不利于乙方：**"**自验收合格之日起**"——甲方可通过无限期拖延验收来延长乙方质保义务，增加乙方成本
- **质保期时长**：需符合行业惯例
- **保修范围**：是否包含人工费、上门费、备件费？哪些属于除外责任？
- **维修响应时限**：是否具有商业可行性

**乙方风险**：质保期约定为"自验收合格之日起"时，若甲方拖延验收，乙方质保义务将被无限期延长，增加售后成本

---

### 6. 违约责任（必须详细审核！）

**乙方视角核心原则（关键！）：**
- **对甲方不利的违约责任条款 = 乙方的保障，不是乙方的风险**
- 甲方违约金高（如0.8%/日）是乙方回款的保障，**不应标记为风险点**
- 仅在甲方违约金可能被法院调低时，才作为可执行性层面的"注意事项"，**不可列为风险点**

#### 6.1 乙方违约责任控制（真正的乙方风险）
- **乙方逾期交付的违约金比例**：是否过高？是否设置了上限？
- **乙方违约金上限**：不得超过合同总价的**20%-30%**
- 日违约金标准建议不超过**万分之五（0.5‰）**，超过此标准的才标记为风险
- 乙方违约赔偿承担应仅限于乙方原因造成的**直接损失**，避免承担间接损失

#### 6.2 甲方违约责任（乙方利益保障，非风险）
- **甲方逾期付款违约金高对乙方有利**，有助于保障乙方回款
- 仅当违约金极高（如年化超200%）时注意：法院可能依《民法典》第585条调低
- 此情况属于**可执行性层面的备注**，不构成乙方的风险点，不应在风险点中列出

#### 6.3 双方责任不对等审查要点
- 甲方违约金 vs 乙方违约金：**不对等有利于乙方属正常商业谈判结果，非风险**
- 仅当**乙方责任明显重于甲方**（如乙方违约金高于甲方违约金）时，才为风险点
- 乙方违约责任应相对较轻为合理目标

#### 6.4 质量违约后果
- 质量不合格的后果（修理/更换/退货）是否明确？

#### 6.5 擅自终止协议的违约责任（重要补充！）
- **甲方擅自终止合同的责任**：是否约定了甲方单方解除的条件和责任？**甲方责任重有利于乙方，非风险**
- **乙方擅自终止合同的责任**：是否合理？**乙方责任过重才为风险**
- 乙方已收款是否明确不予退还？

#### 6.6 赔偿第三方追诉的损失（重要补充！）
- 甲方原因导致第三方追诉的责任承担（应由甲方承担）
- 乙方原因导致第三方追诉的责任承担（乙方责任范围是否合理？是否限于直接损失？）

#### 6.7 商业秘密/BM信息泄露损失赔偿（重要补充！）
- 保密义务的范围和期限
- 信息泄露的赔偿范围和计算方式
- 违约责任是否合理

#### 6.8 知识产权侵权损失（重要补充！）
- 甲方使用乙方产品侵犯第三方知识产权的责任
- 乙方提供产品侵犯第三方知识产权的责任
- 责任范围和赔偿方式

#### 6.9 违约责任必须从合同全文中总结（重要新增！）

**审核违约责任时，必须从合同全文中搜索并引用所有相关条款**：
- 合同正文中关于违约责任的专门章节（如第7条）
- 合同附件中的违约责任条款（如廉洁协议、安全管理协议、知识产权保护协议中的违约责任）
- 任何涉及违约金、赔偿、解除合同等违约后果的条款

#### 6.10 发票违约责任必须明确列出（重要新增！）

**必须审核并列出以下发票相关违约责任**（从合同原文引用）：

| 发票违约情形 | 违约责任（原文引用） |
|-------------|---------------------|
| 乙方未正常纳税 | 乙方应承担由此给甲方造成的一切损失，包括但不限于未抵扣税额、逾期滞纳金、税款罚金等 |
| 乙方未按期提供发票 | 同上 |
| 乙方提供发票不合规 | 同上 |

**注意**：发票违约责任是乙方责任，属于对乙方不利的风险点，应在违约责任审核中明确列出。

#### 6.11 付款与发票金额一致性审核（重要新增！中风险）

**必须审核付款金额与增值税专用发票金额是否一致**：

- **审核要点**：每个付款阶段的付款金额与乙方需提供的增值税专用发票金额是否匹配
- **风险等级**：如果付款金额与发票金额不一致 → **中风险**
- **原因**：付款金额与发票金额不一致可能导致乙方提前垫付税款，或存在税务风险

**合同原文示例**（第3.7条）：
- 阶段1：合同签订价的50%付款，乙方需提供"合同签订价50%的增值税专用发票"
- 阶段2：合同签订价的30%付款，乙方需提供"合同签订价30%的增值税专用发票"
- 阶段3：累计支付至合同结算金额的95%，乙方需提供"累计至合同结算金额100%的增值税专用发票"

**判断标准**：
- ✅ 付款金额与发票金额一致 → 无风险
- ❌ 付款金额与发票金额不一致（如付款50%但需开100%发票） → **中风险**

#### 6.12 单边违约风险判断（重要新增！）

**必须判断合同是否存在"单边违约风险"**：

| 风险类型 | 判断标准 | 风险等级 |
|---------|---------|---------|
| **甲方违约责任过轻** | 甲方违约（如逾期付款、任意解除合同）无对应违约责任或责任极轻 | 中风险 |
| **乙方违约责任过重** | 乙方违约金比例高于甲方，或乙方违约后果严重于甲方 | 中风险 |
| **单边解除权** | 甲方有权任意解除合同，但乙方无对等解除权 | 高风险 |
| **单边变更权** | 甲方有权单方变更合同内容，但乙方无对等权利 | 中风险 |

**从合同全文中识别单边违约风险的要点**：
1. 对比甲方违约责任条款和乙方违约责任条款的严重程度
2. 检查是否存在"甲方有权...但乙方无权..."的条款
3. 检查违约金的金额/比例是否对等
4. 检查解除合同的条件是否对等

#### 6.13 合同变更原则审核（重要新增！）

**如果合同中包含变更原则条款，必须审核并补充到合同要点总结中**：

| 审核要点 | 说明 |
|---------|------|
| 变更程序 | 是否需要按甲方规定程序办理变更审批 |
| 变更计价方式 | 变更部分的计价标准和方式 |
| 变更金额支付 | 变更产生的费用支付时间和方式 |

**合同原文示例**（第3.5条）：
- "乙方需按甲方《深圳市机场（集团）有限公司建设工程变更管理规定（2025年修订版）》相关程序办理变更审批"
- "变更金额以甲方造价管理部门审核为准"

**乙方风险**：变更程序不明确可能导致乙方额外工作无法获得合理报酬

**乙方真正应关注的违约责任风险：**
- 乙方违约金无上限或上限过高（超过合同总价30%）
- 乙方承担间接损失、预期利益损失
- 甲方责任条款缺失或过轻（如甲方终止合同无后果）
- 乙方责任范围过大（如知识产权侵权无限赔偿责任）
- **单边违约风险**（见6.12节）

### 7. 不可抗力

**审查要点**：
- 不可抗力的定义是否涵盖"政府行为""疫情""罢工""运输中断"等常见情形？
- 发生不可抗力后，通知义务的时间、方式、证明要求是否明确？
- 后果：是延期履行，还是解除合同？已发生的费用如何分担？

**乙方风险**：定义过窄→无法覆盖实际发生的突发事件；未约定通知时限→甲方以未及时通知导致损失扩大为由索赔

---

### 8. 争议解决

**审查要点**：
- **管辖地优先级**：乙方所在地法院/仲裁委 > 合同签订地 > 标的物所在地 > 甲方所在地（最差）
- **选择仲裁还是诉讼**：仲裁一裁终局 vs 诉讼两审终审
- 涉外合同是否明确排除了《联合国国际货物销售合同公约》（CISG）的适用？

**乙方风险**：异地管辖→维权成本高昂

---

### 9. 合同生效与终止（重要补充！）

**审查要点**：
- **生效条件**：合同自何时生效？**签字盖章即生效为标准商业惯例**，无需额外挂钩预付款到账（预付款未付，乙方也无需开始履约）
- **终止条件**：合同因何种原因终止？终止后双方义务？
- **解除权**：双方解除权的条件是否对等？

---

### 10. 全套招采文件冲突性检查

- 合同中有约定效力优先层级的，按合同约定的层级
- 合同没有约定效力层级的，合同内容不得与招标文件、投标文件实质性背离

---

### 11. 招标场景注意事项

- 需要判断招标文件中是否允许分转包？是否存在限定供货品牌？

---

### 12. 解除条款（重要补充！）

**审查要点**：
- 甲方单方解除权是否限定于"重大违约"，是否排除了轻微违约情形
- 是否约定了补救期（催告期）：甲方解除前必须书面通知并给予合理期限纠正
- 是否存在"甲方任意解除权"条款（如"甲方可在任何时间无理由终止合同"）
- 因甲方违约解除合同时，乙方已收款项是否明确不予退还
- 乙方是否享有对等的解除权（如甲方逾期付款超过约定期限时，乙方有权解除）
- 解除权行使期限是否合理（不得短于法定的1年除斥期间）
- 解除通知的形式要求及送达方式是否明确

---

## 四、技术服务合同专项审查（乙方视角）

### 1. 技术服务范围和交付标的
- 明确交付内容，必要时以附件形式列清楚
- 避免交付范围模糊导致额外工作

### 2. 交付时间合理性
- 与交付部门沟通确认交付时间是否可行
- 预留充足交付时间，防止违约

### 3. 双方权利义务对等性
- 重点审核是否加重乙方义务、减轻甲方义务
- 实现双方权利义务基本对等和平衡

### 4. 付款条件（重点！）
- 常规付款节点：签约款 → 初验款 → 终验款 → 质保金
- **警惕前期不支付任何费用、等到终验后才付款的项目**
- **明确拒绝"背靠背"付款条件**

### 5. 项目验收条件
- 明确验收时间、验收标准
- **必须约定：甲方提交验收申请后，未在规定时间内提出异议视为验收合格**
- **默示验收条款已覆盖全部验收环节**，无需单独区分初验和终验流程，不应将"缺少终验条款"列为风险

### 6. 知识产权归属
- 明确服务过程中产生的技术成果归属
- 知识产权归甲方则需支付较高开发费用
- 知识产权归乙方，甲方只有使用权

### 7. 保密条款
- 合同终止后保密义务依然存在
- 根据项目情况确定保密期限
- 涉密项目保密要求应更严格

### 8. 违约责任（乙方视角）
- **甲方违约金高对乙方有利，非乙方风险**；仅乙方违约金才需关注上限
- 乙方违约金不超过法定上限（合同总价20%-30%）
- 免责条款明确，技术开发失败风险由双方共同承担

### 9. 争议解决
- **尽量约定由法院管辖，而非仲裁**
- **争取约定由乙方所在地法院管辖**

## 五、审查优先级总结

| 优先级 | 审查层面 | 说明 |
|--------|----------|------|
| 1 | 合法性 | 违反《民法典》强制性规定的条款必须指出 |
| 2 | 可执行性 | 司法实践中可能无效或不获支持的条款 |
| 3 | 风险可控性 | 权利义务是否对等，是否存在对乙方不利的单方陷阱 |
| 4 | 商业目标匹配 | 是否妨碍乙方正常履约和回款 |

## 六、乙方视角风险判断速查表（关键！）

在审核报告"潜在风险点"部分，只能列出对乙方不利的条款。以下速查表帮助判断：

| 条款类型 | 对乙方有利 | 对乙方不利（=风险点） |
|----------|------------|----------------------|
| 甲方逾期付款违约金 | 比例高→有利（非风险） | 比例低/未约定→风险 |
| 乙方逾期交付违约金 | 比例低/有上限→有利 | 比例高/无上限→风险 |
| 甲方任意解除权 | 未约定→有利 | 约定了→风险 |
| 乙方收款条件 | 预付款比例高/节点清晰→有利 | 背靠背/模糊→风险 |
| 管辖约定 | 乙方所在地→有利 | 甲方所在地/原告地→风险 |
| 验收条款 | 逾期视为合格+期限短→有利（默示条款已覆盖全部，不需单独终验） | 无限期/无默示条款→风险 |
| 质保期起算 | 交付之日/提交验收申请之日→有利 | 验收合格之日→风险 |
| 知识产权归属 | 乙方保留→有利 | 全部归甲方→需评估 |
| 甲方终止合同责任 | 需足额付款→有利 | 无后果→风险 |

## 七、数字转换注意事项（重要！）

| 数字 | 正确读法 | 错误读法 |
|------|----------|----------|
| 0.8% | 千分之八 | ~~万分之八~~ |
| 0.5% | 千分之五 | ~~万分之五~~ |
| 0.3% | 千分之三 | ~~万分之三~~ |
| 5% | 百分之五 | - |
| 0.3‰ | 千分之零点三 | - |
| 万分之五 | 0.5‰ | - |

**注意**：
- % = 百分号
- ‰ = 千分号
- 0.8% = 8‰ ≠ 0.8‰
- **日千分之八（0.8%）是甲方违约金，对乙方有利，非乙方风险**

## 九、数字准确性铁律（最高优先级！）

**报告中的所有数字必须从合同原文中直接引用，严禁推断、换算或自行计算。**

| 规则 | 说明 |
|------|------|
| 引用原文 | 合同写"万分之四"就写"万分之四"，括号可附参考换算，但不可替换 |
| 不推断修订痕迹 | 合同有Track Changes时不能混用删除/插入内容，无法确认时标注不确定性 |
| 金额原样 | "370,000.00元"不可简化为"37万" |
| 中文数字保留 | 合同用中文数字的保持中文数字 |
| 禁止自行比对换算 | 引用双方违约金时分别引用原文 |
