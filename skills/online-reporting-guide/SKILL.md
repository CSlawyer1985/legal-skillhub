# 网络侵权举报指引 · 全流程操作框架

> **本Skill来源于实战**：融合中央网信办官方规范、属地网信办举报中心一线操作模板、以及真实举报辅导经验（含无效举报案例复盘）。不是理论指南，是**可立即执行的操作手册**。

---

## 角色与边界

- **你不是律师**：本Skill提供操作指引和信息汇总，不构成法律意见。重大法律后果应咨询专业律师。
- **全程引导**：用户提供侵权线索后，你负责引导完成每一步：类型识别 → 有效论述构建 → 取证 → 选渠道 → 写材料 → 提交 → 跟踪。
- **模板填充**：当用户提供具体侵权信息时，你应**直接生成可用的举报材料**，不要只给模板让用户自己填。
- **合规红线**：禁止生成捏造事实、诬告陷害类文案；自动剔除情绪化表述，引导客观陈述事实。

## 小白快速入门：发现侵权后的5步走

> 你发现了一篇网络侵权文章，完全不知道该怎么办？按这个顺序来：

### 第1步：立刻取证（趁内容还在）⚠️最紧急

侵权内容随时可能被删除，**先截图保存证据，再去做其他任何事**。

**最少要做的事**（不花钱、不装软件就能完成）：
1. 打开侵权页面，确保**浏览器地址栏的网址完整可见**
2. 截全屏（Windows按`Win+Shift+S`，Mac按`Cmd+Shift+3`）
3. 如果内容很长，**滚动截取**确保全文都在截图里
4. 截图要包含：网址、发布时间、作者账号、内容全文、点赞/评论/转发数
5. 把每条侵权内容的截图**单独保存**，按`序号_平台_描述.png`命名

**想更有法律效力？**（花10-50元，推荐做）：
- 下载"权利卫士"App → 注册 → 选择"网页取证"或"截图取证" → 自动加时间戳
- 时间戳取证的法律效力：法院应当确认（《最高人民法院关于互联网法院审理案件若干问题的规定》第11条）

> 📌 **详细操作见下方「证据收集实操指南」**

### 第2步：判断侵权类型（决定举报策略）

对照下表，看你的情况属于哪一类：

| 你看到的内容 | 侵权类型 | 举报难度 | 是否需要额外证据 |
|-------------|----------|----------|-----------------|
| 有人冒充你公司发内容 | 仿冒性信息 | ⭐容易 | 营业执照+官方账号对比 |
| 文章断章取义、选择性报道 | 误导性信息 | ⭐⭐中等 | 原始完整素材对比 |
| 文章编造虚假数据/事实 | 谣言性信息 | ⭐⭐⭐需举证 | **必须提供8选1证据**（见下） |
| 直接辱骂、人身攻击 | 侮辱性信息 | ⭐容易 | **原则上不需要额外证据** |
| 泄露企业/个人隐私信息 | 泄密性信息 | ⭐容易 | **原则上不需要额外证据** |
| 其他恶意干扰经营 | 恶意干扰 | ⭐⭐⭐需举证 | **必须提供3选1证据** |

> 📌 **关键区别**：如果是谣言（编造虚假事实），你必须拿出证据证明它是假的；如果是侮辱谩骂，直接举报就行。

### 第3步：写举报材料（核心难点）

**90%的举报失败是因为材料写得不对**。记住一个公式：

```
有效举报 = 逐条指出失实之处 + 逐一提供事实证据 + 标注附件编号
```

**❌ 错误写法**（真实失败案例）：
> "该文章恶意诋毁攻击，唱衰意图明显，文中多处表述无事实支撑，严重影响企业声誉"
> → 失败原因：全是主观定性，没有指出具体哪句话失实，没有提供证据

**✅ 正确写法**（同一案例）：
> "文章称'X近两年亏损25.15亿'。实际情况：根据X公司2023-2024年报，累计净利润为XX亿（见附件3）。该表述歪曲财务数据。"

举报材料共需要准备**5件套**：
1. 营业执照扫描件（加盖公章）
2. 举报函（加盖公章）← 最核心的材料
3. 侵权证据（截图/录屏）
4. 侵权链接表（Excel）
5. 授权委托书（非法定代表人操作时需要）

> 📌 **详细写作指南见下方「举报材料逐段写作指南」**

### 第4步：选择举报渠道（决定处理速度）

```
第一选择：侵权内容所在的平台举报 → 最快，直接在APP/网站内操作
           ↓（平台不处理或处理不满意）
第二选择：12377涉企侵权举报专区 → 官方平台，www.12377.cn
           ↓（12377也没处理）
第三选择：属地网信办 → 线下疑难杂症
           ↓（涉嫌犯罪，如敲诈勒索）
第四选择：公安部 cyberpolice.cn → 刑事案件
```

> 📌 **详细渠道清单见下方「举报渠道全表」**

### 第5步：提交并跟踪

1. 按渠道要求上传/提交材料
2. **保存查询码/受理编号**！截图保存
3. 3-7个工作日后查询处理进度
4. 如果被判无效 → 进入「无效举报诊断」流程

## 回答工作流（Agentic Protocol）

### Step 1: 问题分类

| 用户输入类型 | 特征 | 行动 |
|-------------|------|------|
| **提供了具体侵权信息** | 有URL/平台名/侵权描述 | → 走完整流程，直接生成举报材料 |
| **只问某个环节** | "怎么取证""去哪举报""模板是什么" | → 回答具体问题，同时提示完整流程 |
| **不确定是否构成侵权** | "这是不是侵权""能举报吗" | → 先帮用户分析侵权类型，再走流程 |
| **举报被驳回/无效** | "举报了没处理""被判无效" | → 进入「无效举报诊断」流程 |

### Step 2: 侵权类型识别

根据用户描述，对照「六类涉企侵权」+「个人侵权场景」进行匹配。识别后告知用户侵权类型和对应的举报要点。

### Step 3: 有效举报论述构建（核心能力）

**这是本Skill区别于普通模板的关键**。根据真实举报辅导经验，90%的举报失败是因为论述无效。必须按以下方法构建论述。

### Step 4: 证据收集提醒

提醒用户取证的紧迫性（侵权内容可能被删除），提供具体取证方法和工具。

### Step 5: 渠道选择与材料生成

按优先级推荐渠道，根据所选渠道生成对应的举报材料。

### Step 6: 提交指引与跟踪

告知具体提交方式（在线/邮寄/邮件），提醒保存查询码，安排后续跟踪。

## 一、侵权类型识别

### 1.1 涉企网络侵权六类（中央网信办《网站平台受理处置涉企网络侵权信息举报工作规范》）

| 类型 | 定义 | 典型表现 | 举报要点 | 证据要求 |
|------|------|----------|----------|----------|
| **仿冒性信息** | 混淆企业主体身份 | 假冒官方账号、仿冒官网 | 提供营业执照 + 被仿冒账号/内容URL + 对比说明 | 营业执照 + 官方账号截图 |
| **误导性信息** | 影响公众公正评判 | 断章取义、选择性报道、错误关联 | 指出误导手法 | 原始完整素材 vs 被误导版本对比 |
| **谣言性信息** | 不符合企业客观实际 | 编造数据、虚构事件 | **逐条指出失实之处 + 提供事实证据** | 需8选1证据（见下方） |
| **侮辱性信息** | 贬损丑化企业或企业家 | 辱骂、人身攻击、丑化P图 | 指出侮辱性表述的具体位置 | **原则上不需额外证据** |
| **泄密性信息** | 侵害企业家个人隐私 | 泄露个人信息、家庭隐私 | 说明信息属于个人隐私 + 未获授权 | **原则上不需额外证据** |
| **恶意干扰经营** | 其他恶意干扰正常经营 | 恶意投诉、恶意差评 | 说明对企业经营的实际影响 | 需3选1证据（见下方） |

### 1.2 谣言类信息的8选1证据材料

对谣言类信息，**必须提供以下至少一项**证据（否则举报不予受理）：

1. 法院判决书、行政处罚决定书等有效法律文书
2. 主管主办单位出具的证明材料
3. 源发新闻媒体出具的撤稿函
4. 企业对外公告声明
5. 有关职能部门公共查询服务平台查询结果
6. 司法、执法、执纪及相关职能部门对外发布的公告通告、出具的证明
7. 具有特定资质的第三方机构出具的证明
8. 其他能够证明举报内容构成侵权的材料

> 💡 **小白提示**：最常用的是第4项（企业公告声明）和第5项（职能部门查询结果）。比如文章说你公司被立案调查，你可以去市场监管局官网查询并截图证明没有这回事。

### 1.3 恶意干扰类的3选1证据材料

1. 法院判决书、行政处罚决定书等生效法律文书
2. 有关部门对外发布的公告通告、出具的证明
3. 企业自行收集的其他证明证据

### 1.4 个人网络侵权场景（非企业）

| 场景 | 侵权类型 | 维权路径 |
|------|----------|----------|
| 肖像被盗用/P图 | 肖像权 | 平台投诉 → 12377侵权举报 |
| 被造谣诽谤 | 名誉权 | 取证 → 平台投诉 → 12377 → 民事诉讼 |
| 个人信息泄露 | 隐私权 | 平台投诉 → 12377 → 公安报案 |
| 原创作品被盗 | 著作权 | 平台知产投诉 → 12315 → 诉讼 |
| AI换脸伪造 | 肖像权+名誉权 | 取证（AI伪造对比）→ 平台投诉 → 12377 |
| 商标被冒用 | 商标权 | 平台知产投诉 → 12315 → 市监投诉 |

## 二、有效举报方法论（实战经验提炼）

> **来源**：真实举报辅导经验。某企业2022年以来通过12377平台举报，部分成功、部分失败。以下是从失败案例中提炼的方法论。

### 2.1 什么是"有效举报"

有效举报 = **命中受理范围** + **选择合适渠道** + **展开有效论述** + **提供举报要件** + **采取恰当处置诉求**

### 2.2 无效举报的典型特征

| 无效特征 | 说明 | 正确做法 |
|----------|------|----------|
| **只有主观定性** | "恶意诋毁""唱衰意图明显""严重影响声誉" | 这些表述**全部省略**，只陈述客观事实 |
| **罗列错误但不证伪** | 说"文中多处错误"但不指出具体错误 | 逐条列出：原文说X → 事实是Y → 证据见附件Z |
| **事实举证不足** | 没有提供任何可验证的证据 | 提供上述8选1或3选1证据 |
| **诉求模糊** | "请处理" | 明确：删除内容/处置账号/标注争议+链接声明 |

### 2.3 有效论述的构建方法

#### 第一步：梳理不实之处

将侵权内容中的问题分为两类：

**A. 事实表述不实**：文章说的与客观情况不符
- 例：文章称"企业亏损25亿"→ 实际年报显示盈利
- 例：文章称"被市场监管局立案调查"→ 实际未收到任何通知

**B. 引用事实真实但结论错误**：数据没错但解读错误
- 例：讲酒企存货量大→ 实际是正常生产陈酿产品
- 例：讲企业"砸钱营销"→ 实际研发费用占比更高，策略是技术创新
- 例：讲"蓝领业务吃不下蓝海"→ 实际蓝领用户数/付费客户数持续增长

#### 第二步：逐一证伪

对每条不实之处，提供对应的事实证据：

| 论述方式 | 证据类型 | 示例 |
|----------|----------|------|
| 数据反驳 | 财报/审计报告 | "文章称亏损25.15亿，实际累计亏损为XX亿（见附件3）" |
| 概念纠正 | 行业标准/政策文件 | "文章称'突击分红'，但该企业IPO已由证监会审核通过，且'国九条'明确禁止突击分红（见附件5）" |
| 数据处理方式纠正 | 会计准则 | "文章数据计算方式不符合国家会计事务准则（见附件6）" |
| 业务事实反驳 | 平台后台数据 | "文章称'投诉多达4446条'，实际黑猫平台数据显示为XX条（见附件7）" |
| 官方证明反驳 | 主管部门文件 | "文章称'大规模裁员'，实际社保缴纳记录显示员工数稳定（见附件8）" |

#### 第三步：对应附件

每条论述都要标注证据来源的附件编号，形成"论述→证据"的完整链条。

### 2.4 处置诉求的5种类型

| 处置类型 | 适用场景 | 说明 |
|----------|----------|------|
| **信息删除** | 明确侵权的内容 | 最常见的处置方式 |
| **账号处置** | 恶意账号 | 逐次逐级处置（限流→禁言→封禁）；涉嫌敲诈勒索的直接封禁+纳入黑名单 |
| **修改/删除部分内容** | 笔误，无主观恶意 | 出现有事实错误但非故意的情况 |
| **限时加私** | 企业IPO等特殊时期 | 给一定举证时间，暂时设为私密 |
| **标注争议标记+链接企业声明** | 舆情已广泛传播 | 原发媒体删除后，转载媒体内容标注争议并链接企业澄清声明，起到辟谣效果 |

### 2.5 特别提示：三类内容的举报策略

| 内容类型 | 举报策略 | 举证要求 |
|----------|----------|----------|
| **直接侮辱谩骂** | 可直接提交举报，无需特别举证 | 仍需提供内容链接，暂不支持关键词批量清理 |
| **恶意关联解读** | 需从事实角度自证+陈述实际做法成效 | 需提供业务数据、成效证明等 |
| **抹黑正常信息** | 可走侵权类直接举报查删 | 提供信息真实性的证明 |

## 三、证据收集实操指南（小白版）

> ⚠️ **紧迫性提醒**：侵权内容随时可能被发布者删除。**发现后第一时间取证**，再走举报流程！内容一旦被删，你可能再也找不回来了。

### 3.1 取证方法优先级一览

| 优先级 | 方法 | 法律效力 | 费用 | 适用场景 | 推荐指数 |
|--------|------|----------|------|----------|----------|
| ★★★★★ | **时间戳取证** | 法院应当确认 | 10-50元/次 | 网页、截图、录屏 | 🔥首推 |
| ★★★★ | **区块链存证** | 法律明确认可 | 5-25元/次 | 网页全过程取证 | 🔥推荐 |
| ★★★★ | **公证取证** | 最高效力 | 500-1000元 | 重大案件、诉讼保底 | 预算充足时 |
| ★★★ | **在线公证云** | 同公证效力 | 100-500元 | 网页/APP取证 | 中等预算 |
| ★★ | **自行截屏录屏** | 辅助证据 | 免费 | 举报材料附件 | 至少要做 |

> 💡 **小白建议**：先做免费截图（立刻做），再花10-50元做个时间戳取证（增加法律效力），重大案件再做公证。

### 3.2 截图实操：每张截图必须包含的5个要素

**一张合格的举报截图，必须同时包含以下内容**（缺一不可）：

```
┌──────────────────────────────────────────┐
│  ★要素1：浏览器地址栏（完整URL必须可见）      │  ← 证明"这条内容确实在这个网址"
│──────────────────────────────────────────│
│                                          │
│  ★要素2：系统时间（任务栏/状态栏时间可见）    │  ← 证明"截图时间"
│                                          │
│  ★要素3：发布者信息（账号名称、认证标识）      │  ← 证明"是谁发的"
│                                          │
│  ★要素4：侵权内容全文（滚动截取，不能截一半）  │  ← 证明"发了什么"
│                                          │
│  ★要素5：互动数据（点赞、评论、转发数）       │  ← 证明"传播范围有多大"
│                                          │
└──────────────────────────────────────────┘
```

#### 不同设备的截图方法

| 设备 | 截图方法 | 滚动截图（长截图） |
|------|----------|-------------------|
| **Windows电脑** | `Win + Shift + S` → 框选区域 → 粘贴到画图保存 | 用浏览器插件"GoFullPage"或Edge浏览器`Ctrl+Shift+S` |
| **Mac电脑** | `Cmd + Shift + 3`（全屏）/ `Cmd + Shift + 4`（区域） | 用Safari的"整页截图"功能，或Chrome插件 |
| **iPhone** | 侧边键+音量上键同时按 | 截图后点左下角缩略图 → 上方选"整页" |
| **Android** | 电源键+音量下键同时按 | 不同品牌不同：华为/小米/OPPO的截图工具栏有"滚动截屏" |

#### 截图常见错误（会导致举报被退回）

| ❌ 错误做法 | ✅ 正确做法 |
|------------|-----------|
| 只截内容，没截网址 | 必须包含地址栏的完整URL |
| 截了一半内容就保存了 | 滚动截取全文，确保完整 |
| 没有截发布者信息 | 必须包含账号名、头像、认证标识 |
| 没有截时间 | 截图时确保系统时间可见 |
| 多条内容混在一张图里 | 每条侵权内容单独截图 |
| 截图文件名随意 | 按`序号_平台_描述.png`命名 |

### 3.3 截图命名规范

**截图编号必须与《不实信息网址链接表》中的序号一一对应**。

命名格式：`序号_平台_简要描述.png`

示例：
```
1_微博_造谣产品致癌.png
2_微信公众号_虚构亏损数据.png
3_今日头条_编造被立案调查.png
```

### 3.4 时间戳取证：逐点击操作指南

#### 工具一：权利卫士App（联合信任）— 最推荐

## 四、举报材料逐段写作指南（小白版）

> 这是整个举报过程中最关键的一步。材料写得好，举报成功率高；写得不好，直接被判无效。

### 4.1 举报材料5件套总览

| 序号 | 材料 | 必要性 | 格式 | 说明 |
|------|------|--------|------|------|
| 1 | **营业执照扫描件** | 必须 | PDF/图片 | 加盖公章，彩色扫描 |
| 2 | **举报函** | 必须 | PDF/Word | 加盖企业公章，按官方模板填写 |
| 3 | **侵权证据** | 必须 | 图片/视频 | 截图/录屏/时间戳证书 |
| 4 | **侵权链接表** | 必须 | Excel | 逐条列出URL（用官方模板） |
| 5 | **授权委托书** | 视情况 | PDF/Word | 非法定代表人操作时需提供 |

### 4.2 举报函逐段写作指南

举报函是核心材料。以下是官方模板的每一部分该怎么写：

#### 标题

```
关于XXXX的举报函
```
- 把XXXX替换成简要主题，如"关于XX财经观察发布不实信息的举报函"

#### 收件人

```
xx网信办：
```
- 如果向12377举报，可不填收件人
- 如果向属地网信办举报，填"xx网信办："
- 如果向其他省市网信办举报，填对应的网信办名称

#### 企业信息（照填即可）

```
企业名称：XXXXXXX                        ← 填营业执照上的全称
企业类型：民营企业                        ← 四选一：国有企业/民营企业/外资企业/其他
企业性质：专精特新企业                    ← 没有特殊性质可不填，或填"其他"
函件联系人及职务：李四，法务经理           ← 填实际办理人的姓名和职务
联系方式：138XXXXXXXX                    ← 填手机号，保持畅通
```

> ⚠️ **注意**：函件联系人必须与授权委托书中的代理人一致。如果是法定代表人本人操作，不需要授权委托书。

#### 举报概述（200字以内）

**这一段怎么写**：用最简洁的话说清楚"谁、在哪个平台、发了什么内容、侵犯了什么权利"。

**模板**：
```
2026年X月X日，自媒体账号"XXX"在XX平台发布文章/视频，
称我司[简要描述侵权内容，如"亏损超25亿、靠裁员续命、已被立案调查"]。
上述内容全部失实/部分失实，严重损害我司声誉，特此举报。
```

**示例**：
```
2026年7月15日，自媒体账号"XX财经观察"在某财经网站发布文章，
称我司"近两年亏损超25亿，靠裁员续命，已被监管部门立案调查"。
上述内容全部失实，严重损害我司声誉，特此举报。
```

> ❌ **不要这样写**：本文章恶意诋毁攻击，唱衰意图明显，文中多处表述无事实支撑，亦无逻辑可言，严重影响企业声誉，对企业和社会造成负面影响。
> → 这全是主观定性表述，网信办明确：**主观、定性表述不作为论据，可省略**。

#### 举报类型

**直接对照下表选择**（可多选）：

```
举报类型：谣言性信息、误导性信息
```

| 类型 | 什么时候选 |
|------|-----------|
| 仿冒性信息 | 有人冒充你公司 |
| 误导性信息 | 文章断章取义、选择性引用 |
| 谣言性信息 | 文章编造了虚假数据或事实 |
| 侮辱性信息 | 文章有辱骂、人身攻击 |
| 泄密性信息 | 文章泄露了个人隐私 |
| 恶意干扰企业正常经营发展的信息 | 其他恶意干扰 |

#### 陈述性举报函（详细说明）— 最核心部分

官方模板要求写4个要点，以下是每个要点怎么写：

**要点1：企业全称及基本情况**

```
一、企业基本情况
XX科技有限公司成立于20XX年，是一家专注于XX领域的[企业性质]企业，
注册资本XX万元，现有员工XX人。公司主营业务为XXXX。
```

**要点2：充分陈述举报事项** — 这是最关键的部分

**写作公式**（对每一条不实内容都要这样写）：
```
[序号]. 关于"[引用原文表述]"：
   文章称"[原文具体表述]"。
   实际情况：[客观事实描述]（见附件[编号]：[证据名称]）。
   [结论：该表述歪曲事实/虚构数据/误导公众]。
```

**完整示例**：
```
二、侵权事实说明

1. 关于"近两年亏损超25亿"：
   文章称"X近两年亏损超25亿"。
   实际情况：根据我司2024-2025年年报，两年累计净利润为XX亿元
   （见附件3：年报数据对比表）。该数据完全虚构，与公开财报严重不符。

2. 关于"靠裁员续命"：
   文章称我司"靠裁员续命"。
   实际情况：根据社保缴纳记录，我司2024-2025年员工总数分别为
   XX人、XX人，未发生大规模裁员（见附件4：社保缴纳证明）。
   该表述歪曲事实，误导公众。

3. 关于"已被监管部门立案调查"：
   文章称我司"已被监管部门立案调查"。
   实际情况：经向XX市市场监督管理局核实，未对我司进行立案调查
   （见附件5：市场监管局查询回复函）。该信息纯属虚构。

   上述不实信息发布后已被多个平台转载，截至举报时累计阅读量超XX万，
   对我司品牌声誉和正常经营造成严重影响。
```

> ⚠️ **关键原则**：
> - **每一条不实内容都要单独列为一条**，不要笼统说"多处错误"
> - **每条都要引用原文**，让审核人知道你在说哪句话
> - **每条都要提供事实依据**，并标注附件编号
> - **删除所有主观表述**：不要写"恶意""无耻""丧心病狂"等

**要点3：处置诉求**

```
三、处置诉求
1. 删除全部侵权内容
2. 对侵权账号"XX财经观察"采取处置措施
3. 对转载媒体内容标注争议标记并链接我司澄清声明
```

5种处置诉求可选（根据情况选择）：

| 诉求 | 适用场景 |
|------|----------|
| 删除内容 | 明确侵权的内容（最常用） |
| 处置账号 | 恶意账号（逐次逐级：限流→禁言→封禁） |
| 修改/删除部分内容 | 有事实错误但非故意（笔误） |
| 限时加私 | 企业IPO等特殊时期，暂时设为私密 |
| 标注争议+链接声明 | 舆情已广泛传播，转载内容标注争议并链接澄清声明 |

**要点4：真实性保证声明**

```
四、真实性保证
本企业保证上述举报内容客观、真实、完整。如有虚假陈述、
诬告陷害或伪造证据，愿承担相应法律责任。
```

#### 落款

```
                                  XX科技有限公司（公章）
                                     2026年7月X日
```

> ⚠️ 必须加盖企业公章！没有公章的举报函不予受理。

#### 附件清单

```
附件：
1、营业执照（复印件加盖公章）
2、联系人身份证明（身份证正反面复印件）+ 授权委托书（加盖公章）
3、不实信息网址链接表（Excel）
4、侵权信息样本截图（编号与链接表一一对应，截图需包含网址链接和侵权内容）
5、证据材料：
   - 附件5-1：2024-2025年年报数据对比表
   - 附件5-2：社保缴纳证明
   - 附件5-3：市场监管局查询回复函
```

### 4.4 不实信息网址链接表（Excel模板）

> 来源：属地网信办官方模板。每条侵权信息的网址都必须填入此表。

| 序号 | 备案省份 | 网站名称 | 备案号 | 数量 | 文章标题 | 网址链接 | 备注（简要描述不实内容） |
|------|----------|----------|--------|------|----------|----------|--------------------------|
| 1 | xx市 | XX网 | xxICP备XXXXXXXX号 | 1 | 文章标题 | https://... | 虚构亏损数据 |
| 2 | XX市 | XX网 | | | | | |

**填写规则（逐条说明）**：

1. **查ICP备案号**（必须填）：
   - 打开 https://beian.miit.gov.cn/#/Integrated/index
   - 点击"ICP备案查询"
   - 填入网站域名（如 `www.example.com` 只填 `example.com`）
   - 输入验证码 → 查到备案号填入
2. **排列顺序**：先列中央新闻网站 → 再列大型商业网站 → 最后列地方网站，按省归类
3. **同一网站多条**：同一网站登载2条以上信息，可将所有信息排序列入同一单元格
4. **第一行填源发网站**：如查不出源发网站，可不填
5. **无备案网站**：排在最后，备案号处空白
6. **网址链接列**：仅填纯链接，无需添加编号
7. **备注列**：简要描述该链接的不实内容，如"虚构亏损25亿数据"

## 五、无效举报诊断

当用户报告"举报了没处理"或"被判无效"时，按以下流程诊断：

### 5.1 诊断清单

| 检查项 | 常见问题 | 修复方法 |
|--------|----------|----------|
| □ 举报类别是否选对？ | 企业侵权应选"侵权类→涉企侵权"，而非"违法类" | 重新选择正确类别 |
| □ 是否有主观定性表述？ | "恶意诋毁""唱衰"等表述不被采信 | 删除所有主观表述，只留客观事实 |
| □ 是否逐条指出失实之处？ | 只说"多处错误"不指明具体位置 | 逐条列出"原文第X段称Y → 事实是Z" |
| □ 是否提供了事实证据？ | 只有论述没有证据附件 | 补充8选1/3选1证据材料 |
| □ 链接是否完整可访问？ | URL不完整或内容已被删除 | 重新取证，确保链接有效 |
| □ 材料是否加盖公章？ | 举报函和营业执照缺少公章 | 补盖公章后重新提交 |
| □ 是否实名举报？ | 匿名举报不予受理 | 提供企业营业执照 + 联系人信息 |
| □ 24小时内是否超30次？ | 超过限制被系统拦截 | 分批提交 |

### 5.2 升级路径

如果平台内举报无效：

```
平台内举报（失败/超时）
    ↓
```

## 九、常见问题FAQ（小白必读）

### Q1：举报需要花钱吗？

**大部分渠道免费**。12377、各平台举报、公安报案都不收费。
唯一可能花钱的是**取证环节**：
- 免费方案：自行截图录屏
- 低成本方案：时间戳取证（10-50元/次）
- 高成本方案：公证取证（500-1000元/件）

### Q2：可以匿名举报吗？

**涉企侵权举报必须实名**。需要提供企业营业执照 + 联系人信息。匿名举报不予受理。

### Q3：举报后多久有结果？

| 渠道 | 处理周期 |
|------|----------|
| 平台内举报 | 24小时-7个工作日（因平台而异） |
| 12377在线举报 | 3-7个工作日 |
| 属地网信办 | 视情况而定 |
| 公安报案 | 7-30日（刑事案件程序） |

### Q4：举报失败（被判无效）怎么办？

按以下顺序排查：
1. 检查举报类别是否选对（涉企侵权应选"侵权类"而非"违法类"）
2. 检查是否有主观定性表述（删除所有"恶意""无耻"等表述）
3. 检查是否逐条指出了失实之处（不能只说"多处错误"）
4. 检查是否提供了事实证据（谣言类必须提供8选1证据）
5. 检查链接是否完整可访问
6. 检查材料是否加盖公章
7. 修正后重新提交，或升级到上级渠道

### Q5：截图需要公证吗？

**举报阶段不需要公证**。自行截图即可作为举报附件。
但如果后续要走诉讼程序，建议做公证取证或时间戳取证，法律效力更高。

### Q6：文章已经被删了还能举报吗？

**很难**。如果内容已被删除，链接无法访问，举报通常不予受理。
这就是为什么**第一时间取证最重要**——即使内容后来被删，你手里的截图和证据仍然有效。

### Q7：多个平台都有转载，需要分别举报吗？

**需要**。每条侵权内容（每个URL）都要单独举报或列入链接表。
但可以打包提交：12377支持RAR压缩包含多条链接和截图；属地网信办支持Excel批量链接表。

### Q8：对方说"我说的都是事实"，怎么反驳？

需要区分两种情况：
- **如果对方说的确实不是事实**：拿出证据证明。如文章说"亏损25亿"，你拿年报证明没有亏损。
- **如果对方说的数据没错但解读错误**：指出其逻辑错误。如"存货量大"不等于"经营困难"，而是正常生产陈酿需要。

### Q9：被侵权的是我个人，不是企业，能用这个流程吗？

可以，但渠道略有不同：
- 平台投诉 → 同样适用
- 12377 → 选择"侵权类"而非"涉企侵权"
- 不需要营业执照，但需要身份证
- 个人维权可额外考虑：12345热线、民事诉讼

### Q10：举报材料需要邮寄纸质版吗？

大部分渠道支持在线提交。但**微信/公众号侵权投诉**可能需要邮寄纸质材料到腾讯。
具体要求以各平台最新公告为准。

### Q11：一天能举报多少条？

12377平台：**24小时内不超过30条**。超过会被系统拦截，需分批提交。

### Q12：对方涉嫌敲诈勒索（要钱才删帖），怎么办？

1. **先取证**：保存聊天记录、转账要求、对话录音（不要主动提出给钱，不要钓鱼）
2. **向平台举报**：选择"涉嫌敲诈勒索"，提供聊天/转账/汇款记录
3. **向公安报案**：登录 cyberpolice.cn 或去属地派出所报案
4. 平台对涉嫌敲诈勒索的账号可直接封禁 + 纳入黑名单

## 十二、诚实边界

1. **不是法律意见**：本Skill提供操作指引，不构成法律建议。重大案件应咨询专业律师。
2. **信息可能更新**：平台规则和举报入口可能变更，以各平台最新公告为准。信息截止2026年7月。
3. **不能保证结果**：举报结果取决于事实、证据和平台/机构的审核判断。
4. **不完全覆盖**：38家重点平台外的小众平台、海外平台不在覆盖范围内。
5. **地区差异**：各省市网信办操作流程可能略有差异，以属地网信办最新要求为准。
6. **材料审核差异**：不同平台对同一材料的审核标准可能存在差异，建议按"最严标准"准备。
7. **"全国网络举报"公众号**：2026年1月由"中央网信办举报中心"更名而来，功能不变。
