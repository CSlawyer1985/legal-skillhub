# 合同法律风险手册

> 本文档为 smart-contract-reviewer Skill 提供法律风险评估依据。
> 依据：《中华人民共和国民法典》合同编及相关司法解释（2026年有效版）。

---

## 一、高风险条款类型

### 1. 导致合同无效的条款
| 风险条款 | 法律后果 | 依据 |
|-----------|-----------|------|
| 排除法定解除权 | 该条款无效 | 《民法典》第563条 |
| 免除故意/重大过失责任 | 该条款无效 | 《民法典》第506条 |
| 排除消费者依法应享有的权利 | 该条款无效 | 《消费者权益保护法》 |
| 放弃诉讼时效抗辩 | 该条款可能被认定无效 | 《民法典》第197条 |

### 2. 违约金过高/过低
- 违约金超过实际损失30%的，法院可予适当减少（《民法典》第585条）
- 建议：违约金 = 合同总金额 × (10%~30%)

### 3. 赔偿范围过宽
- "赔偿全部损失（包括间接损失、预期利益）" → 实践中法院受可预见性规则限制
- 建议：明确赔偿上限（如合同总金额的30%~50%）

### 4. 管辖权条款风险
| 约定 | 风险 |
|------|------|
| 约定外国法院/法律（涉内合同） | 增加争议解决成本，且中国强制性规定仍适用 |
| 约定仲裁但未明确仲裁机构 | 仲裁条款无效 |
| 约定"由甲方所在地法院管辖"但甲方地址不明确 | 管辖争议 |

## 二、中风险条款类型

### 1. 表述模糊条款
| 模糊表述 | 风险 | 建议修改 |
|-----------|------|----------|
| "合理期限" | 争议时由法官自由裁量 | 明确为"收到通知后X个工作日内" |
| "重大损失" | 无明确标准 | 定义具体金额或计算方式 |
| "及时通知" | 时间不明确 | 明确为"X小时内" |

### 2. 权利义务不对等
- 单方解除权（仅甲方有权解除）→ 显失公平，可能被调整
- 单方变更权 → 需要设置合理限制

### 3. 支付条款不完整
- 缺少发票类型和开具时限 → 税务风险
- 缺少支付前提条件 → 提前付款风险

---

## 三、低风险条款（建议优化）

### 1. 通知方式不明确
- 建议：明确书面（邮件/函件）为有效通知方式

### 2. 合同变更形式
- 建议：增加"本合同任何修改须以书面形式并经双方签字确认"

### 3. 保密期限
- 建议：商业秘密应约定"直至相关信息进入公有领域为止"（而非固定期限）

## 四、必备条款清单

以下条款应在合同中明确约定（如缺失，标注为"缺失条款"）：

| 必备条款 | 说明 |
|-----------|------|
| 当事人信息（名称、地址、联系人） | 履行和通知的基础 |
| 标的/服务内容 | 合同核心，必须明确 |
| 价款及支付方式 | 包括币种、支付节点、发票 |
| 履行期限、地点、方式 | 避免履行争议 |
| 违约责任 | 包括违约金计算方式 |
| 争议解决方式 | 法院或仲裁，明确具体 |
| 合同生效条件 | 签字盖章即生效？附条件生效？ |
| 保密条款（如适用） | 商业秘密保护 |
| 知识产权归属（如适用） | 开发/设计类合同必备 |

## 五、特殊行业合规提示

| 行业 | 关键合规要求 |
|------|---------------|
| 数据相关 | 遵守《个人信息保护法》《数据安全法》 |
| 金融 | 遵守金融监管规定，禁止变相非法集资 |
| 医疗 | 遵守《基本医疗卫生与健康促进法》 |
| 建设工程 | 需要资质，禁止转包（除劳务分包） |
| 进出口 | 遵守出口管制、关税规定 |
