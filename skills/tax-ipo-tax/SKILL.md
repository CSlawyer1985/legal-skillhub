## 能为你做什么（上市审核税务四大场景）
---

### 一、税收优惠依赖与可持续性
- 📊 **依赖红线**：优惠占利润比重过大、到期后可持续性存疑将触发审核问询
- 🛡️ **披露与兜底**：论证可持续性，披露风险提示，必要时实控人兜底补偿承诺
- ⚠️ **典型警示**：同一优惠同一主体多次预警折射优惠理解偏差风险

**典型问法：**
```
"税收优惠依赖有什么风险？"
"上市审核税收优惠怎么披露？"
```

### 二、税收优惠披露要求
- 📋 **中介意见**：须对优惠到期后能否继续享受发表明确意见
- 🔄 **预提处理**：很可能获批复可按优惠预提并披露追缴补偿安排，否则谨慎按正常税率预提
- 🧾 **风险提示**：优惠合法性、合理性、可持续性及风险提示充分性

**典型问法：**
```
"发行类第5号要求什么？"
"税收优惠披露要注意什么？"
```

### 三、红筹架构与跨境税务
- 🌐 **完税凭证级核查**：监管口径从"是否合法"下沉至"是否完税"定量核查
- 💱 **要点**：股权转让对价公允性、资金支付路径、预提所得税/个税完税凭证
- 🔍 **敏感词筛查**：经营范围敏感词形式筛查

**典型问法：**
```
"红筹架构税务怎么核查？"
"境外上市备案税务关注什么？"
```

### 四、全链条实质合规（北交所等）
- 🔗 **监管闭环**：辅导验收—受理审核—过会后再检查，从形式合规转向实质合规
- 🔍 **穿透核查**：历史补税、跨境税务、研发费用真实性、数据资产入表穿透核实
- 🧭 **分阶段路径**：筹备期体检、申报期披露、审核期回复、持续期管理

**典型问法：**
```
"IPO税务合规怎么做？"
"北交所全链条监管关注什么？"
```

## 重要提示与边界声明

**重要提示**
1. **优惠依赖须控**：论证可持续性并充分披露，必要时实控人兜底。
2. **历史问题须清**：申报前完成税务健康体检与历史补税整改。
3. **跨境完税须备**：红筹架构补全股权转让完税凭证，确保对价公允。
4. **以官方为准**：审核口径动态趋严，具体以交易所最新审核动态为准。

**边界（本技能不做的）**
- **不代办**：上市申报、备案系统等需登录操作的事项
- **不代理**：上市税务鉴证、法律尽调等需执业资质的事务
- **不担保**：审核结果、税收优惠认定等最终以监管机关为准

**服务说明**
- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告
