## 简介

**公司法专家**是一款基于《中华人民共和国公司法》（2023年12月29日第二次修订，2024年7月1日施行）及配套司法解释的专业法律AI技能，由民商法执业律师马常成打造。

---

## 安装方法

### 方法一：直接复制目录

```bash
# 克隆或下载本项目后
cp -r company-law-skill-v2.0.0 ~/.hermes/skills/legal/

# 重启 Hermes Agent 或刷新技能列表
hermes reload
```

### 方法二：手动放置

1. 将 `company-law-skill-v2.0.0` 整个目录放入 `~/.hermes/skills/legal/` 路径下
2. 重启 Hermes Agent 或执行 `hermes reload` 刷新 skill 列表
3. 在对话中输入与公司法相关的问题即可自动触发本 skill

### 环境要求

- **Python:** >= 3.7
- **依赖包:** python-docx（可选，用于起诉状生成）
- 如需生成起诉状 docx 文件，需安装 `python-docx`：`pip install python-docx --user`

**无 python-docx 也能用：** 即使没有上述依赖，本技能仍可正常进行法律咨询和起诉状文本输出。只有需要生成 .docx 文件时才需要额外安装。

## 功能模块

### 模块A：公司法律咨询

覆盖公司法律全流程咨询服务，包括以下子模块：

- **A1 公司设立与出资** — 设立条件、出资方式、出资期限（5年认缴期）、出资违约责任、股东失权制度
- **A2 公司治理** — 股东会/董事会/监事会职权、召集程序、审计委员会、法定代表人、职工董事
- **A3 股东权利保护** — 知情权（含会计凭证查阅）、分红权、表决权、异议股东回购请求权、股东代表诉讼（含双重代表诉讼）
- **A4 股权转让** — 内部/外部转让规则、优先购买权、转让后出资责任、股份转让限制
- **A5 公司资本制度** — 增资优先认缴权、普通减资/简易减资、股份回购、财务资助禁止、类别股
- **A6 公司合并分立重组** — 吸收合并/新设合并、简易合并、分立后债务承继
- **A7 公司解散与清算** — 解散事由、司法解散、清算义务人（董事）、简易注销、强制注销
- **A8 公司债券** — 债券发行、可转债、债券持有人会议
- **A9 上市公司特别规定** — 独立董事、关联关系表决回避
- **A10 国家出资公司** — 国家出资公司的治理结构、审批程序、审计委员会
- **A11 董监高法律责任** — 忠实义务/勤勉义务（明确定义）、影子董事、董事对第三人责任、双控人连带责任
- **A12 合伙企业法** — 普通合伙企业（GP）与有限合伙企业（LP）设立、合伙事务执行、入伙与退伙、合伙企业解散与清算、有限合伙人特殊权利保护
- **A13 国家法律法规数据库查询** — 集成全国人大官方API实时查询法条
- **A14 Logic Doctor自检** — 五维逻辑自检机制确保输出质量
- **A15 诉讼时效追踪** — 自动检查诉讼时效并添加提醒

### 模块B：公司纠纷起诉状起草

支持 8 类常见公司纠纷的通用民事起诉状智能生成：公司决议纠纷、股权转让纠纷、股东知情权纠纷、股东出资纠纷、公司盈余分配纠纷、公司解散纠纷、损害公司利益责任纠纷、合伙协议纠纷。

## 使用方法

### 1. 公司法律咨询

直接描述您的公司法律问题即可，例如：

- "注册资本认缴1000万，2025年注册的，必须在什么时候缴足？"
- "小股东能自己召集股东会吗？"
- "公司不给我看账，怎么起诉？需要什么材料？"
- "股权转让后，原股东还要对债务负责吗？"
- "普通合伙人和有限合伙人有什么区别？"

### 2. 起诉状起草

说出您的纠纷类型，根据提示提供关键信息（当事人信息、持股情况、纠纷事实、诉讼请求），即可获得一份完整的通用民事起诉状。
