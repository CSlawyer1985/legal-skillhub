# 公司法律咨询速查

基于《中华人民共和国公司法》（2023年12月29日第二次修订，2024年7月1日施行）及配套司法解释的核心知识点速查手册。

---

## 一、公司类型与基本概念

**有限责任公司：** 股东以其认缴的出资额为限对公司承担责任（新《公司法》第3条）
**股份有限公司：** 股东以其认购的股份为限对公司承担责任（新《公司法》第3条）
**一人公司：** 只有一个股东的公司（新《公司法》第23条）
**国家出资公司：** 国家出资的国有独资公司、国有资本控股公司（新《公司法》第168条）

**关联企业（新增定义）：** 公司可以与其他企业共同投资、共同经营（新《公司法》第22条）

---

## 二、公司设立

**设立条件（新《公司法》第27条）：**
1. 股东符合法定人数（1-50人，有限责任公司；2-200人，股份有限公司发起人）
2. 有符合公司章程规定的全体股东认缴的出资额
3. 有股东共同制定的公司章程
4. 有公司名称，建立符合有限责任公司要求的组织机构
5. 有公司住所

**设立责任（新《公司法》第44条）：**
- 设立时的股东为设立公司从事的民事活动，其法律后果由公司承受
- 设立时的股东以自己的名义从事民事活动产生的责任，第三人有权选择请求公司或者设立时的股东承担

**公司章程应当载明的事项（新《公司法》第46条）：**
1. 公司名称和住所
2. 公司经营范围
3. 公司注册资本
4. 股东的姓名或者名称
5. 股东的出资额、出资方式和出资日期
6. 公司的机构及其产生办法、职权、议事规则
7. 公司法定代表人的产生、变更办法
8. 股东会会议认为需要规定的其他事项

---

## 三、注册资本与出资

**认缴出资期限（新《公司法》第47条）：**
- 全体股东认缴的出资额由股东按照公司章程的规定自公司成立之日起**五年内**缴足
- 法律、行政法规以及国务院决定另有规定的，从其规定

**出资方式（新《公司法》第48条）：**
- 货币
- 实物、知识产权、土地使用权、**股权、债权**（新增）
- 劳务、信用、自然人姓名、商誉、特许经营权或者设定担保的财产不得作价出资

**出资不足的责任（新《公司法》第49-52条）：**
- 股东未按期缴纳出资 → 向公司足额缴纳 + 赔偿损失
- 经催缴后仍未缴纳 → 公司董事会决议可发出**失权通知** → 股东丧失未缴纳出资的股权
- 设立时的其他股东对出资不足承担**连带责任**

**抽逃出资（新《公司法》第53条）：**
- 公司成立后，股东不得抽逃出资
- 违反规定的，股东应当返还抽逃的出资；给公司造成损失的，负有责任的董事、监事、高级管理人员应当与该股东承担**连带赔偿责任**

**出资证明书（新《公司法》第55条）：**
- 公司成立后，应当向股东签发出资证明书
- 出资证明书由法定代表人签名，并由公司盖章

## 四、股东会

**股东会职权（新《公司法》第59条）：**
1. 选举和更换董事、监事，决定报酬
2. 审议批准董事会报告
3. 审议批准监事会报告
4. 审议批准利润分配方案和弥补亏损方案
5. 增资减资决议
6. 发行债券决议
7. 合并、分立、解散、清算或变更公司形式
8. 修改公司章程
9. 章程规定的其他职权

**股东会会议（新《公司法》第62-66条）：**
- 定期会议：按照公司章程规定按时召开
- 临时会议：代表十分之一以上表决权的股东、三分之一以上的董事或者监事会提议召开
- 会议通知：会议召开**二十日前**通知全体股东（章程另有规定的除外）
- 表决权：按照**出资比例**行使（章程可另行规定）
- 普通决议：经代表**过半数**表决权的股东通过
- 特别决议（修改章程、增资减资、合并分立解散等）：经代表**三分之二以上**表决权的股东通过

---

## 五、董事会

**董事会组成（新《公司法》第68条）：**
- 成员为**三人以上**
- 职工人数三百人以上的有限责任公司，**必须有职工董事**（除非已设职工监事）
- 规模较小的有限责任公司，可以不设董事会，设一名董事

**董事会职权（新《公司法》第67条）：**
- 召集股东会会议，执行股东会决议
- 决定公司的经营计划和投资方案
- 制订公司的利润分配方案和弥补亏损方案
- 制订增资减资方案
- 决定公司内部管理机构的设置
- 决定聘任或者解聘公司经理及其报酬事项
- 制定公司的基本管理制度

**董事任期（新《公司法》第70条）：**
- 由公司章程规定，**每届任期不得超过三年**
- 任期届满，连选可以连任
- 董事辞任的，应当以书面形式通知公司，公司收到通知之日辞任生效

---

## 六、监事会与审计委员会

**监事会/监事（新《公司法》第81-83条）：**
- 监事会成员不得少于**三人**（规模较小的可不设监事会，设一名监事）
- 监事会应当包括股东代表和适当比例的公司职工代表，其中职工代表的比例不得低于**三分之一**
- 董事、高级管理人员不得兼任监事
- 监事任期每届为**三年**

**审计委员会（新《公司法》第69条）：**
- 公司可以按照章程规定，在董事会中设置由董事组成的审计委员会，行使监事会的职权
- 审计委员会成员**不得在公司担任除董事以外的其他职务**

---

## 七、经理与法定代表人

**经理（新《公司法》第74条）：**
- 公司**可以**设经理（旧法为「必须设」，新法改为可设）
- 由董事会决定聘任或者解聘

**法定代表人（新《公司法》第10条）：**
- 由**代表公司执行公司事务的董事或者经理**担任
- 法定代表人的产生、变更办法在公司章程中规定
- 法定代表人辞任的，公司应当在法定代表人辞任之日起**三十日内**确定新的法定代表人

---

## 八、股东权利

### 知情权（新《公司法》第57条）

| 可查阅/复制的文件 | 权限 |
|:---|:---|
| 公司章程、股东名册、股东会记录、董事会决议、监事会决议、财务会计报告 | ✅ 查阅+复制 |
| 会计账簿 | ✅ 查阅（需书面请求） |
| **会计凭证（新增）** | ✅ 查阅（需书面请求） |

委托专业机构查阅：可以委托会计师事务所、律师事务所等中介机构进行，不需要股东在场。

### 表决权（新《公司法》第65条）

- 按照出资比例行使表决权
- 公司章程可以另行规定

### 优先认缴出资权（新《公司法》第227条）

- 新增资本时，股东在同等条件下有权优先按照实缴的出资比例认缴出资
- 全体股东约定不按比例认缴的除外

### 异议股东股权回购请求权（新《公司法》第89条）

股东对以下决议投反对票时，可请求公司按合理价格收购其股权：
1. 公司连续五年不向股东分配利润，而公司连续五年盈利
2. 公司合并、分立、转让主要财产
3. 章程规定的营业期限届满或解散事由出现，决议修改章程使公司存续
4. **（新增）** 控股股东滥用股东权利，严重损害公司或者其他股东利益的

### 股东代表诉讼（新《公司法》第189条）

- 董监高执行职务违反规定给公司造成损失 → 股东书面请求监事会/董事会起诉
- 监事会/董事会拒绝或30日未起诉 → 股东有权直接起诉
- **双重代表诉讼（新增）：** 母公司股东可以对全资子公司的董监高提起代表诉讼

---

## 九、股权转让

**内部转让（新《公司法》第84条）：**
- 股东之间可以相互转让全部或部分股权
- 无限制

**外部转让（新《公司法》第84条）：**
- 应书面通知其他股东，载明转让数量、价格、支付方式、期限
- 其他股东在收到通知之日起**三十日内**享有优先购买权
- 两个以上股东主张优先购买权的，协商确定比例；协商不成的，按出资比例行使

**股权转让后的责任（新《公司法》第88条）：**
- 转让未届出资期限的股权 → 受让人承担出资义务
- 受让人未按期缴纳 → 出让人承担**补充责任**

**股份公司股份转让限制（新《公司法》第160条）：**
- 董监高任职期间每年转让不超过持有股份的**25%**
- 离职后**半年内**不得转让

## 十、公司资本变动

### 增资（新《公司法》第227条）
- 股东有优先认缴权（有限责任公司）
- 增资决议须经代表三分之二以上表决权的股东通过

### 减资（新《公司法》第224-226条）

| 类型 | 程序 | 债权人保护 |
|:---|:---|:---|
| 普通减资 | 股东会决议（2/3以上）→ 编制资产负债表 → 通知债权人（10日内）→ 公告（30日内） | 债权人有权要求清偿债务或提供担保 |
| 简易减资（新增） | 使用公积金弥补亏损后仍有亏损的，可减资弥补亏损 | 不需通知债权人，但应公告 |
| 非法减资 | — | 股东退还资金/恢复原状；董监高承担赔偿责任 |

### 股份回购（新《公司法》第162条）

公司可回购股份的情形：
1. 减少注册资本
2. 与持有本公司股份的其他公司合并
3. 员工持股计划或股权激励
4. 股东对合并/分立决议持异议
5. 转换可转换公司债券
6. 上市公司维护公司价值及股东权益

---

## 十一、公司合并分立

**合并程序（新《公司法》第218-222条）：**
1. 各方股东会决议（2/3以上）
2. 签订合并协议
3. 编制资产负债表及财产清单
4. 10日内通知债权人、30日内公告
5. 办理变更/注销/设立登记

**简易合并（新增）：** 公司与其持股90%以上的公司合并 → 不需被合并公司股东会决议

**分立（新《公司法》第223条）：**
- 分立前的债务由分立后的公司承担连带责任
- 与债权人另有约定的除外

---

## 十二、公司解散与清算

**解散事由（新《公司法》第229条）：**
- 章程规定的营业期限届满
- 股东会决议解散
- 因合并或分立需要解散
- 依法被吊销营业执照、责令关闭或被撤销
- 人民法院判决解散

**司法解散（新《公司法》第231条）：**
- 持有公司**10%以上**表决权的股东可请求法院解散公司
- 条件：经营管理发生严重困难，继续存续会使股东利益受到重大损失，通过其他途径不能解决
- ❌ 仅以亏损、不分红、知情权被侵犯等为由起诉解散 → 法院不予受理

**清算义务人（新《公司法》第232条）：**
- **董事**为清算义务人（旧法为股东）
- 15日内组成清算组
- 未及时清算造成损失的，应承担赔偿责任

**简易注销（新《公司法》第240条）：**
- 条件：未产生债务或已清偿全部债务 + 全体股东承诺
- 程序：国家企业信用信息公示系统公告20日 → 申请注销
- 风险：股东对债务承诺不实的，对注销前债务承担**连带责任**

**强制注销（新《公司法》第241条）：**
- 被吊销营业执照、责令关闭或被撤销满三年未注销的
- 登记机关可强制注销

---

## 十三、董监高义务与责任

**忠实义务（新《公司法》第180条第一款）：**
- 采取措施避免自身利益与公司利益冲突
- 不得利用职权牟取不正当利益

**勤勉义务（新《公司法》第180条第二款）：**
- 执行职务应当为公司的最大利益尽到管理者通常应有的合理注意
- **新法首次明确勤勉义务的内涵**

**影子董事（新《公司法》第180条第三款）：**
- 公司的控股股东、实际控制人**不担任公司董事但实际执行公司事务**的，同样适用忠实义务和勤勉义务

**董监高禁止行为（新《公司法》第181条）：**
1. 侵占公司财产、挪用公司资金
2. 将公司资金以其个人名义或者以其他个人名义开立账户存储
3. 利用职权贿赂或者收受其他非法收入
4. 接受他人与公司交易的佣金归为己有
5. 擅自披露公司秘密
6. 违反对公司忠实义务的其他行为

**关联交易（新《公司法》第182条）：**
- 董监高及其近亲属、关联企业与本公司订立合同或进行交易，应当**向董事会或者股东会报告，并按照公司章程的规定经决议通过**
- 利用关联关系损害公司利益的，承担**赔偿责任**（第22条）

**董事对第三人责任（新《公司法》第191条）：**
- 董事、高级管理人员执行职务，给他人造成损害的，公司承担赔偿责任
- 董事、高级管理人员存在**故意或者重大过失**的，也应当承担赔偿责任

**双控人连带责任（新《公司法》第192条）：**
- 控股股东、实际控制人指示董监高从事损害公司或者股东利益的行为的，与该董监高承担**连带责任**

---

## 十四、国家出资公司特别规定

**适用对象（新《公司法》第168条）：**
- 国家出资的国有独资公司、国有资本控股公司

**治理结构（新《公司法》第170-177条）：**
- 不设股东会，由**履行出资人职责的机构**行使股东会职权
- 董事会成员由履行出资人职责的机构委派（职工董事除外）
- **不再要求设监事会**（由审计委员会行使监事会职权）
- 外部董事过半数
- 经理由董事会聘任或解聘

---

## 十五、法律责任速查

| 违法行为 | 责任主体 | 责任形式 |
|:---|:---|:---|
| 股东未按期出资 | 股东 | 足额缴纳 + 赔偿损失 |
| 股东抽逃出资 | 股东 + 负有责任的董监高 | 返还 + 连带赔偿 |
| 瑕疵出资股权转让 | 转让人 + 受让人（连带） | 在未出资本息范围内承担补充赔偿责任 |
| 非法减资 | 股东 + 负有责任的董监高 | 退还资金/恢复原状 + 赔偿损失 |
| 董监高违反忠实义务 | 董事、监事、高级管理人员 | 所得收入归公司所有 + 赔偿损失 |
| 董事对第三人造成损害（故意/重大过失） | 董事、高级管理人员 | 个人承担赔偿责任 |
| 双控人指示损害行为 | 控股股东、实际控制人 | 与董监高承担连带责任 |
| 未及时清算造成损失 | 董事（清算义务人） | 赔偿损失 |
| 简易注销承诺不实 | 全体股东 | 对注销前债务承担连带责任 |
| 财务资助违法 | 负有责任的董监高 | 赔偿损失 |

## 十六、诉讼时效与除斥期间

| 事项 | 期限 | 法律依据 |
|:---|:---|:---|
| 决议撤销之诉 | 自决议作出之日起**60日内** | 新《公司法》第26条 |
| 决议无效/不成立之诉 | 无期间限制 | 新《公司法》第25条、公司法解释四第5条 |
| 股东知情权诉讼 | 无固定期间（但需先书面请求，15日后可诉） | 新《公司法》第57条 |
| 异议股东回购请求权 | 自股东会决议通过之日起**90日内**（协商不成可诉） | 新《公司法》第89条 |
| 股东代表诉讼前置期限 | 监事会/董事会收到请求后**30日内**未起诉方可直接诉 | 新《公司法》第189条 |
| 公司解散之诉 | 持续僵局状态，无期间限制 | 新《公司法》第231条 |
| 清算组成立期限 | 解散事由出现之日起**15日内** | 新《公司法》第232条 |
| 债权人申报债权期限 | 接到通知后**30日内**（未接到通知则公告后**45日内**） | 新《公司法》第217条 |
| 简易注销公告期 | **20日**（国家企业信用信息公示系统） | 新《公司法》第240条 |

## 十七、合伙企业法速查

基于《中华人民共和国合伙企业法》（2006年8月27日修订，2007年6月1日施行）核心知识点速查。

**三种合伙企业类型及责任形式：**

| 类型 | 责任形式 | 适用场景 |
|:---|:---|:---|
| **普通合伙企业（GP）** | 全体合伙人对合伙债务承担**无限连带责任** | 一般商业合伙 |
| **有限合伙企业（LP）** | 普通合伙人承担无限连带责任，**有限合伙人以认缴出资额为限承担有限责任** | 风险投资、基金、员工持股平台 |
| **特殊的普通合伙企业** | 个别合伙人因故意/重大过失造成债务的，该合伙人承担无限连带责任，**其他合伙人以财产份额为限承担责任**；非因故意/重大过失造成的债务，全体合伙人承担无限连带责任 | 会计师事务所、律师事务所等专业服务机构 |

**普通合伙（GP）vs 特殊普通合伙：** 特殊普通合伙并非独立类型，仅是普通合伙在企业名称中标注"特殊普通合伙"后的特殊形态。

---

### 设立与出资

- **合伙人人数：** 普通合伙 **2人以上**，有限合伙 **2-50人**（但至少应有1名普通合伙人）
- **出资方式（《合伙企业法》第16条）：** 货币、实物、知识产权、土地使用权、**劳务**（←与公司法的核心区别之一）或者其他财产权利
- **劳务出资：** 普通合伙人**可以**劳务出资（《合伙企业法》第16条），但须经全体合伙人**协商确定评估办法**；有限合伙人**不得**以劳务出资（《合伙企业法》第64条）
- **出资评估：** 以实物、知识产权、土地使用权或者其他财产权利出资，需要评估作价的，可以由全体合伙人**协商确定**，也可以由全体合伙人委托**法定评估机构**评估（《合伙企业法》第16条）

> **与公司的区别：** 公司法禁止股东以劳务出资（《公司法》第48条要求出资财产应当可以用货币估价并可以依法转让），合伙企业法允许普通合伙人以劳务出资。这是合伙企业的独特优势之一。

---

### 合伙事务执行

- **全体合伙人共同执行**（普通合伙）或**委托一名或数名合伙人执行**（《合伙企业法》第26条）
- **有限合伙人不得执行合伙事务（《合伙企业法》第68条）：**
  - 有限合伙人不执行合伙事务，**不得对外代表有限合伙企业**
  - 这是有限合伙人的**核心红线**——违反该规则将导致对交易的债务承担**无限连带责任**
  - **不视为执行合伙事务的例外行为（第68条第2款）：** 参与决定普通合伙人入伙/退伙、查阅账簿、获取经审计的财务报表、依法为合伙企业提供担保等

**须全体合伙人一致同意的事项（《合伙企业法》第31条）：**
1. 改变合伙企业名称
2. 改变经营范围、经营场所
3. 处分不动产
4. 转让或者处分知识产权和其他财产权利
5. 以合伙企业名义为他人提供担保
6. 聘任合伙人以外的人担任经营管理人员

---

### 竞业禁止与自我交易

| 事项 | 普通合伙人 | 有限合伙人 |
|:---|:---|:---|
| **竞业禁止** | **严格禁止**（不得自营或同他人合作经营与本企业相竞争的业务），除非合伙协议另有约定（第32条） | **允许**（可以自营或同他人合作经营与本有限合伙企业相竞争的业务），除非合伙协议另有约定（第71条） |
| **自我交易** | **严格限制**（不得与本企业进行交易），除非合伙协议另有约定或全体合伙人一致同意（第32条） | **允许**（可以与本有限合伙企业进行交易），除非合伙协议另有约定（第70条） |

> **立法逻辑：** 普通合伙人执行合伙事务、掌握全部商业信息，因此须承担忠实义务；有限合伙人不执行事务、不参与经营，监管风险较低，法律对其限制较少。

---

### 财产份额转让与出质

| 事项 | 普通合伙人（GP） | 有限合伙人（LP） |
|:---|:---|:---|
| **对外转让** | 须经其他合伙人**一致同意**（第22条） | **提前30日通知**其他合伙人即可（第73条） |
| **内部转让** | **通知**其他合伙人（第22条第2款） | 通知其他合伙人（第73条） |
| **优先购买权** | 同等条件下其他合伙人有**优先购买权**（第23条） | 有限合伙人对外转让份额，其他合伙人有**优先购买权**（第74条） |
| **出质（质押）** | **须经全体合伙人一致同意**；未经同意擅自出质的，该行为无效或视为退伙（第25条） | **一般允许**（可将财产份额出质），除非合伙协议另有约定（第72条） |

---

### 入伙与退伙

**入伙：**

- **新合伙人入伙**须经全体合伙人一致同意，并依法订立书面入伙协议（第43条）
- **新合伙人对入伙前债务的责任：**
  - **普通合伙：** 新入伙的普通合伙人对入伙前合伙企业的债务承担**无限连带责任**（第44条）⚠️ 这是重大风险点——即使入伙前的债务也须承担
  - **有限合伙：** 新入伙的有限合伙人对入伙前有限合伙企业的债务，**以其认缴的出资额为限承担责任**（第77条）

**退伙：**

- **退伙类型：** 协议退伙、通知退伙（无固定期限的，提前30日通知）、当然退伙（死亡、丧失行为能力等）、除名
- **退伙人对退伙前债务的责任：**
  - 退伙人对基于退伙前的原因发生的合伙企业债务，承担**无限连带责任**（第53条）⚠️ 即使退伙后，对退伙前的债务仍然承担全部责任
  - 有限合伙人退伙后，对基于退伙前的原因发生的债务，**以其退伙时从合伙企业中取回的财产为限承担责任**（第81条）

**法定当然退伙情形（第48条）：**
1. 合伙人死亡或者被依法宣告死亡
2. 个人丧失偿债能力
3. 法人合伙人被吊销营业执照、责令关闭、撤销或被宣告破产
4. 法律规定或合伙协议约定合伙人必须具有相关资格而丧失该资格
5. 合伙人在合伙企业中的全部财产份额被人民法院强制执行

---

### 解散与清算

**解散事由（第85条）：**
1. 合伙期限届满，合伙人决定不再经营
2. 合伙协议约定的解散事由出现
3. 全体合伙人决定解散
4. 合伙人已不具备法定人数满**30天**
5. 合伙协议约定的合伙目的已经实现或者无法实现
6. 依法被吊销营业执照、责令关闭或者被撤销
7. 法律、行政法规规定的其他原因

**清算与注销后的责任：**

- 清算人由全体合伙人担任，或经全体合伙人过半数同意指定
- **注销登记后，普通合伙人对合伙企业存续期间的债务仍承担无限连带责任（第91条）⚠️**
- 有限合伙人注销后，对存续期间的债务以其认缴出资额为限承担责任

> **★ 与公司的核心区别：** 公司注销后，股东以认缴出资额为限承担有限责任，公司法人人格消灭后股东一般不再承担额外责任（刺破公司面纱除外）；合伙企业注销后，**普通合伙人仍需对合伙企业存续期间的全部债务承担无限连带责任**。这是合伙企业"无限责任"特征的根本体现，也是选择合伙形式时必须考量的最大风险。

---

### 公司与合伙企业的核心区别对比表

| 对比项目 | 公司（有限责任公司） | 合伙企业 |
|:---|:---|:---|
| **法律依据** | 《公司法》（2023年修订） | 《合伙企业法》（2006年修订） |
| **法律人格** | 独立法人（独立承担民事责任） | **非法人组织**（不具有独立法人资格） |
| **出资人责任** | 股东以**认缴出资额为限**承担有限责任 | 普通合伙人承担**无限连带责任**；有限合伙人以认缴出资额为限 |
| **出资方式** | 货币、实物、知识产权等（**不得以劳务出资**） | 同上，但普通合伙人**可以以劳务出资** |
| **纳税主体** | 公司缴纳企业所得税，股东分红缴纳个人所得税（"双重征税"） | 合伙企业**不缴纳企业所得税**，合伙人就经营所得缴纳个人所得税或企业所得税（"穿透税制"） |
| **治理结构** | 股东会、董事会/执行董事、监事会/审计委员会（三会分立） | 全体合伙人共同执行或委托执行（较为灵活） |
| **权力机构** | 股东会（按出资比例行使表决权） | 全体合伙人（一般**一人一票**，按人数而非出资比例） |
| **事务执行** | 董事会/执行董事负责 | 普通合伙人执行，**有限合伙人不得执行合伙事务** |
| **竞业禁止** | 董事、高管负有忠实义务（禁止竞业） | 普通合伙人严格禁止，有限合伙人允许 |
| **财产份额转让** | 股权对外转让须其他股东过半数同意 | GP须全体一致同意，LP提前30日通知即可 |
| **退出机制** | 股权转让（无需其他股东同意即可退出）、减资、异议股东回购 | 退伙（较为灵活，但通常须全体合伙人同意或按合伙协议约定） |
| **解散后责任** | 公司注销后，股东一般不再承担额外责任 | **普通合伙人对注销前的债务仍承担无限连带责任** |
| **税收计算** | 企业所得+个人所得分别计税 | **先分后税**：合伙层面不计税，合伙人各自缴税 |
| **最低人数** | 1人（一人有限责任公司） | 普通合伙2人以上，有限合伙2-50人 |
| **注册资本要求** | 无最低限额（但须5年内缴足） | **无注册资本概念**（合伙人按约定或协议缴纳出资） |
