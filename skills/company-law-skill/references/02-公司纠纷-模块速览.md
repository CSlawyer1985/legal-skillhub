# 公司纠纷通用民事起诉状模块速览

## 说明

本技能目前使用**通用民事起诉状模板**起草公司及合伙纠纷起诉状。通用模板采用**段落式**格式（非要素式表格），适用于各类公司纠纷和合伙纠纷。

等大哥开发好要素式起诉状模板后，再替换为案由专属的要素式格式。

---

## 通用民事起诉状模板模块结构

### 模板结构（8个模块）

| 模块 | 内容 |
|:---|:---|
| 01 标题 | **民事起诉状**（18pt宋体加粗居中） |
| 02 原告信息 | 姓名/名称、身份证号/统一社会信用代码、住所地、联系方式 |
| 03 被告信息 | 姓名/名称、身份证号/统一社会信用代码、住所地、联系方式 |
| 04 第三人（如有） | 姓名/名称、基本信息 |
| 05 诉讼请求 | 逐项列明请求事项 |
| 06 事实与理由 | 按时间顺序叙述案件事实 + 法律分析 |
| 07 证据清单 | 证据名称、证据种类、证明目的 |
| 08 具状人 | 签名/盖章、日期（右对齐） |

## 各案由起草要点

### B1 — 公司决议纠纷

**诉讼请求要点：**
- 请求确认决议无效 / 请求撤销决议 / 请求确认决议不成立
- 诉讼费用由被告承担

**事实与理由要点：**
- 决议基本情况（名称、作出机关、作出时间、主要内容）
- 决议瑕疵事实（内容违法/违反章程、召集程序违法、表决方式违法、未实际召开等）
- 是否在法律规定的期限内起诉（撤销之诉60日内）

**法律依据：** 新《公司法》第25-26条、公司法解释四第1-6条

---

### B2 — 股权转让纠纷

**诉讼请求要点：**
- 请求确认转让合同效力 / 请求继续履行 / 请求撤销转让 / 请求赔偿损失 / 请求确认优先购买权受侵害 / 请求办理股权变更登记

**事实与理由要点：**
- 转让方、受让方、目标公司、转让比例/出资额、转让价款
- 是否履行通知义务（侵犯优先购买权的关键）
- 是否已办理股东名册变更和工商变更登记
- 转让后出资责任争议

**法律依据：** 新《公司法》第84条、第86条、第88条、《民法典》合同编

---

### B3 — 股东知情权纠纷

**⚠️ 前置程序：必须先书面请求查阅，说明目的。公司拒绝或15日内未答复，方可起诉。**

**诉讼请求要点：**
- 请求查阅+复制：公司章程/股东名册/股东会记录/董事会决议/监事会决议/财务会计报告
- 请求查阅：会计账簿 / 会计凭证
- 请求由中介机构协助查阅
- 诉讼费用由被告承担

**事实与理由要点：**
- 股东身份信息（持股比例、出资额、出资时间）
- 前置程序履行情况（书面请求时间、内容、公司拒绝或不答复的证据）
- 查阅目的

**法律依据：** 新《公司法》第57条、公司法解释四第7-12条

---

### B4 — 股东出资纠纷

**诉讼请求要点：**
- 请求依法履行出资义务 / 赔偿损失 / 承担违约责任
- 请求在未出资本息范围内对公司债务承担补充赔偿责任（债权人起诉时适用）

**事实与理由要点：**
- 出资约定（认缴出资额、出资方式、出资期限）
- 出资违约事实（未按期缴纳、未足额、非货币出资评估不实、抽逃出资）
- 催缴及失权通知情况
- 损失情况

**法律依据：** 新《公司法》第49-53条、公司法解释三第7-19条

---

### B5 — 公司盈余分配纠纷

**诉讼请求要点：**
- 请求公司分配利润 / 支付应付股利 / 赔偿损失
- 主张分配的期间和金额

**事实与理由要点：**
- 公司利润分配情况（是否有利润分配决议、可分配利润金额）
- 不分配利润的原因及理由
- 控股股东是否存在滥用权利导致不分配的情形

**法律依据：** 新《公司法》第210条、第211条、公司法解释四第13-15条

---

### B6 — 公司解散纠纷

**⚠️ 要件：必须满足治理僵局（非经营亏损），且用尽其他救济途径。**

**诉讼请求要点：**
- 请求依法解散公司

**事实与理由要点：**
- 公司基本情况（成立时间、注册资本、股东构成）
- 公司僵局事实（两年以上无法召开股东会、无法作出有效决议、董事长期冲突）
- 其他救济途径尝试情况（协商、调解、股权转让等）

**法律依据：** 新《公司法》第231条、公司法解释二第1条

---

### B7 — 损害公司利益责任纠纷

**诉讼请求要点：**
- 请求停止侵害 / 赔偿损失 / 返还财产 / 将所得收入归公司所有

**事实与理由要点：**
- 被告身份及职务（董事/监事/高管/控股股东/实际控制人）
- 侵权行为描述（违反忠实义务、勤勉义务、双控人指示）
- 公司遭受的具体损失

**法律依据：** 新《公司法》第22条、第180-182条、第189条、第191条、第192条

---

### B8 — 合伙协议纠纷

**诉讼请求要点：**
- 请求确认合伙协议效力 / 继续履行 / 解除协议 / 赔偿损失
- 请求进行合伙清算
- 请求承担无限连带责任

**事实与理由要点：**
- 合伙企业基本情况（类型：普通/有限/特殊合伙，GP/LP构成）
- 合伙协议约定（出资、事务执行、利润分配、入退伙）
- 纠纷事实（协议效力、事务执行、利润分配、退伙、解散清算、连带责任争议）
- 合伙企业清算情况

**法律依据：** 《合伙企业法》第2条、第22条、第25条、第32条、第39条、第43条、第53条、第68条、第91条

---

## 通用模板填充说明

**格式要求：**
- 标题：宋体18pt加粗居中
- 正文：宋体14pt，首行缩进2字符，行间距1.5倍
- 日期：右对齐
- 页边距：上下2.54cm，左右3.17cm

**法律依据引用格式：**
- 《中华人民共和国公司法》第XX条
- 《中华人民共和国合伙企业法》第XX条
- 《最高人民法院关于适用〈中华人民共和国公司法〉若干问题的规定（X）》第XX条

**诉讼请求写法：**
- 逐项列明，每项独立成段
- 涉及金额的应注明具体金额
- 请求事项应明确具体，不模糊

**证据清单写法：**
- 列表形式，每项包含：证据名称、证据种类、证明目的
- 核心证据前置，辅助证据后置
