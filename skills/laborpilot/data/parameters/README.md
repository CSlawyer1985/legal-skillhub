# 版本化金额参数包

本目录只保存已经核对官方来源、效力期间和适用地域的动态数值。计算脚本按 `package_id + version + parameter_key` 引用参数，并把参数值、来源 URL、包文件 SHA-256 和本案相关日期一并写入计算记录。

当前随包提供：

- 全国工资折算参数（2025 年起）：月计薪天数、每日小时数；
- 浙江省最低工资标准（2024 年起）：三档月最低工资和小时最低工资。具体市、县（市、区）适用档次仍须依据当地公布文件选择，参数包不自行判断。

年度社平工资、工伤统筹地区待遇标准等数据具有年度、地域和用途差异，不得用未经核验的单一数值代替。需要使用时，按 [参数包 Schema](../../references/parameter-package.schema.json) 新增独立版本包；至少记录制定机关、文件名称与文号、官方 URL、发布日期、效力起止、适用地域、计量单位和原文定位。旧包保留，不覆盖历史版本。

参数包只提供数值事实，不决定请求权基础、工资基数口径、适用档次或公式选择。上述法律判断必须在本案法源和策略记录中另行确认。
