# 证据收集清单与常见陷阱拆解

> 仅供参考，不构成法律意见。证据收集限于合法方式；以现行有效法规及仲裁机构要求为准。

## 总原则

1. **趁在职收集**：被通知辞退的当天，OA、邮箱、企业微信权限可能即刻关闭。感觉到风向不对（被约谈、被架空、被要求「优化」）就开始备份。
2. **原始载体为王**：聊天记录保留手机原件，不要只存截图；邮件保留原始邮箱可登录状态；录音保留原始文件（不要只留剪辑版）。
3. **连续完整**：微信记录从头到尾导出，掐头去尾的截图证明力大打折扣，还可能被质疑篡改。
4. **形成链条**：单一证据弱，组合证据强。例：考勤记录（有加班）+ 加班审批单（公司安排）+ 工资条（未付加班费）= 完整的加班费证据链。
5. **合法边界**：自己参与的对话可以录音；不入侵他人设备、不窃取他人账号、不拿与案件无关的商业秘密（既无必要，也可能反被追责）。

## 四大类证据清单

### 一、劳动关系类（没有劳动合同时尤其重要）

| 证据 | 怎么收集 | 备注 |
|---|---|---|
| 劳动合同 | 自己那份原件妥存；公司没给的，拍下自己签署的过程性文件 | 未签合同本身可主张二倍工资差额 |
| 社保/公积金缴纳记录 | 当地人社 App、支付宝/微信市民中心随时可查并下载 | 证明劳动关系的硬证据 |
| 个税记录 | 个人所得税 App「收入纳税明细」 | 显示扣缴单位与月度收入 |
| 工牌、门禁卡、工服 | 拍照+实物保留 | 辅助证据 |
| 入职通知/Offer | 邮件原件保存并转发个人邮箱 | 含岗位薪资约定 |
| 钉钉/企业微信/OA 账号 | 对个人主页、组织架构中自己的位置截屏录屏 | 权限关闭前做 |
| 工作成果与往来 | 以自己名义发出的邮件、周报、署名文件 | 注意不带走商业秘密内容，取「能证明我在此工作」即可 |
| 同事证言 | 记下愿意作证的在职/离职同事联系方式 | 在职同事出庭意愿通常低，作后备 |

### 二、工资报酬类

| 证据 | 怎么收集 | 备注 |
|---|---|---|
| 银行工资流水 | 手机银行导出近 24 个月，标注「代发工资」字样的流水最佳 | 确定补偿基数的核心证据 |
| 工资条 | 每月拍照/导出存档 | 显示应发构成（基本+绩效+补贴） |
| 年终奖/提成依据 | 薪酬制度文件、提成规则邮件、历年发放记录 | 主张年终奖提成必备 |
| 欠薪确认 | 与 HR/老板的催薪聊天记录、对方承认欠薪的回复 | 同时是时效中断证据 |

实操话术（催薪留痕）：
> 「王总，我 5、6 月份工资共 36,000 元至今未发，请问公司安排在什么时间支付？」
> 对方任何回应（「再等等」「下月一起发」）都是欠薪事实的自认。

### 三、加班事实类

| 证据 | 怎么收集 | 备注 |
|---|---|---|
| 考勤记录 | 打卡 App 每月截屏/导出；指纹打卡的拍打卡机记录屏 | 公司掌握考勤而拒不提供的，可主张由其承担不利后果 |
| 加班审批/通知 | 加班审批单、群里「今晚加班」的通知、排班表 | 证明「公司安排」而非「自愿留着」——这是加班费成立的关键 |
| 工作痕迹 | 深夜/周末发出的邮件、提交记录、系统日志、工作群消息 | 与考勤互相印证 |
| 加班餐/打车报销 | 报销记录带时间地点 | 辅助证据 |

### 四、解除/辞退类（决定 N 还是 2N 的关键）

| 证据 | 怎么收集 | 备注 |
|---|---|---|
| 书面辞退通知 | 主动索要：「请公司出具书面解除通知，注明解除理由和日期」 | 最硬的证据；公司不给就用下面的替代 |
| 辞退谈话录音 | 约谈时录音，自然引导：「您的意思是公司今天正式解除我的劳动合同，理由是岗位取消，对吗？」 | 让对方说出「主体（代表公司）+行为（解除）+理由+日期」四要素 |
| 复述确认信息 | 谈话后当天给 HR 发：「今天您代表公司通知我因组织调整解除劳动合同，最后工作日为 X 日，请确认。」 | 不回复也有价值，回复更佳 |
| 权限关闭证据 | 账号被停用、被移出工作群、门禁失效的截屏录屏 | 证明公司单方阻断劳动条件 |
| 离职证明/退工单 | 离职时依法有权取得 | 看清内容，不接受写「严重违纪」等定性（可要求更正） |
| 工作交接单 | 交接时注明「因公司解除合同进行交接」 | 防止事后被说成「自离」 |

## 常见陷阱拆解（遇到即预警）

### 陷阱 1：让你主动写辞职信
话术表现：「你主动辞职，我们给你写离职证明好看点」「走协商流程麻烦，你写个人原因快」。
后果：写「个人原因辞职」原则上=放弃经济补偿，事后翻案极难。
应对：**任何情况下不写「辞职」「个人原因」字样**。公司要解除，请公司发书面通知。如确系被拖欠工资等被迫离职，辞职理由必须写明「因公司拖欠 X 月工资，依据劳动合同法第三十八条被迫解除劳动合同」——这一句话决定了 N 的有无。

### 陷阱 2：「自愿放弃社保」协议/承诺书
表现：入职时签「自愿放弃缴纳社保，公司折现到工资」。
拆解：缴纳社保是法定强制义务，此类约定**无效**，公司仍应补缴。注意：因存在此约定，员工再以「未缴社保」为由被迫解除并主张经济补偿的，各地司法口径存在差异；社保补缴本身走社保稽核/劳动监察渠道更直接。

### 陷阱 3：调岗降薪逼退
表现：辞退要给钱，于是把你调到边缘岗、异地岗、降薪，逼你自己走。
应对三件套：①书面异议（邮件：「本人不同意本次调岗，原岗位劳动合同约定为 X，本次调整缺乏合理性，本人将继续按原约定提供劳动」）；②**继续正常出勤打卡**（去新岗位报到与否策略上要谨慎评估，绝不能旷工——连续旷工会送给公司「严重违纪」的辞退理由）；③收集调岗不合理的证据（岗位与专业无关、明显侮辱性安排、大幅降薪）。

### 陷阱 4：口头承诺「先离职再补钱」
表现：「你先把离职手续办了，补偿下个月走账」。
应对：没有加盖公章/有权代表签字的**书面协议**（含金额、支付日期、逾期责任），不办任何离职手续。协议和离职手续同步进行是底线。

### 陷阱 5：以「绩效不合格/末位淘汰」直接辞退
拆解：「不胜任工作」解除的法定完整链条=有证据证明不胜任（考核制度+考核结果告知确认）→ 培训或调岗 → 仍不胜任 → 提前 30 日通知或付代通知金。「末位淘汰」直接解除的，末位不等于不胜任，多被认定违法解除（可主张 2N）。公司拿绩效说事时，先要求出示考核制度与你签收确认的记录。

### 陷阱 6：解除协议里的「一揽子放弃条款」
表现：协议写「双方再无任何劳动争议，乙方放弃其他一切请求」。
应对：签字前把所有项目算全（补偿、当月工资、加班费、年假、报销、奖金/提成），全部写进协议金额；签了此条款再主张遗漏项目通常很难。金额远低于法定标准的协议，事后主张撤销存在「重大误解/显失公平」的争点，但举证难，**不如签前算清**。

### 陷阱 7：离职证明写负面评价/威胁背调抹黑
拆解：离职证明依法应载明合同期限、解除或终止日期、岗位、本单位工作年限等客观信息；写「因严重违纪被辞退」等定性内容的，可要求出具合规版本，因此造成求职损失的可主张赔偿。
应对话术：「请按规定出具仅含客观信息的离职证明,这对公司也没有额外成本。」

### 陷阱 8：竞业限制滥用
拆解：竞业限制仅适用于高管、高级技术人员和其他负有保密义务的人员；离职后公司需**按月支付经济补偿**（未约定补偿的,履行了义务可主张按一定标准支付；公司三个月未支付补偿的,可主张解除竞业限制）。普通岗位被要求签全员竞业、违约金畸高的，签署前评估，离职时主动书面询问公司是否启动竞业（留痕），避免自己白守两年。

## 离职前 48 小时行动清单

- [ ] 导出近 24 个月工资流水、全部工资条
- [ ] 备份劳动合同、offer、调薪调岗邮件
- [ ] 导出考勤记录、加班审批记录
- [ ] 对组织架构、个人主页、关键群聊完整录屏
- [ ] 关键沟通（辞退谈话、协商）录音
- [ ] 发出复述确认信息并保存回复
- [ ] 记录 2-3 位愿意作证的同事联系方式
- [ ] 检查手中有无公司财物/欠款,主动结清（不给对方留反诉把柄）
- [ ] 不删除任何聊天记录，手机勿恢复出厂设置
