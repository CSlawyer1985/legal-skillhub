# 合规认证计划生成器

## 技能用途

本技能根据 SOP-CCP-2024-01 规程，为消费电子、IoT 或工业产品生成完整的合规认证计划报告。报告必须包含三大板块：①适用法规标准及清单 ②认证路线图（甘特图） ③时间节点与预算。

## 触发条件

用户在以下场景时触发本技能：
- 提到「合规认证计划」、「认证路线图」、「合规预算」
- 要求为某款产品生成认证规划报告
- 提到产品需要 CE/FCC/RoHS/CCC 等认证并询问计划

## 执行流程

### 1. 收集产品信息

向用户收集以下信息（可通过对话逐步确认）：

| 字段 | 说明 | 示例 |
|------|------|------|
| 产品名称 | 完整产品名 | 智能家居无线网关 |
| 产品类型 | 消费电子/IoT/工业/医疗等 | IoT 智能家居 |
| 目标市场 | 中国/欧盟/美国/其他 | 中国 + 欧盟 |
| 无线功能 | Wi-Fi/蓝牙/蜂窝/LoRa 等 | Wi-Fi + 蓝牙 |
| 预期上市时间 | 年月 | 2026年Q3 |
| 预算上限 | 人民币（可选） | ¥30万 |

### 2. 读取 SOP 文档

读取 `references/SOP.md`，了解完整的操作规程、标准清单模板和预算计算规则。

### 3. 生成报告

按照 `prompt.md` 中定义的报告模板，生成包含以下三大板块的完整报告：

**板块一：适用法规标准及清单**
- 标准编号、版本、强制性质（强制/自愿）、适用区域
- 每项标准附简要说明

**板块二：认证路线图**
- 五个阶段：准备期 → 技术整改 → 测试送检 → 认证审核 → 证书维护
- 每个阶段含：起止时间、负责方、关键交付物、风险点

**板块三：时间节点与预算**
- 时间节点表：阶段、开始日期、结束日期、天数、负责方
- 预算明细表：分项名称、金额范围（¥万）、占比、说明
- 饼图数据：五类费用占比（测试费/认证申请费/整改费/RoHS/缓冲）

### 4. 输出格式

**主要输出：Markdown 报告**
- 分段分类输出，配合详细表格
- 摘要使用编号列表
- 禁止出现 `[待填写]` 等占位符

**可选输出：HTML5 单文件报告**
- 使用 `assets/report_template.html` 作为模板
- 蓝色系主题（#1e88e5 为主色）
- 含完整 CSS 动画（饼图/甘特图/数字计数）
- 支持 PDF 和 PNG 下载
- 将用户产品信息填入模板对应位置，生成最终 HTML 文件

## 质量标准

1. **数据完整**：标准清单含编号/版本/强制性质；预算含分项明细；时间节点含具体起止日期
2. **禁止占位符**：不得出现 `[待填写]`、`[请补充]` 等
3. **标准准确**：引用标准编号和版本须与 SOP.md 一致
4. **预算合理**：分项总和 = 预算总额；饼图占比总和 = 100%
5. **时间合理**：各阶段天数之和与总周期匹配

## HTML 模板使用说明

当用户要求生成 HTML 版本报告时：

1. 读取 `assets/report_template.html`
2. 将模板中的示例数据（智能家居无线网关 / 中国+欧盟）替换为用户产品信息
3. 根据实际认证项目调整：
   - 标准清单表格
   - 甘特图五个阶段的起止时间
   - 预算明细和饼图数据
   - 时间节点表格
4. 更新文件头部 `<title>` 和封面中的产品名称、版本号
5. 将生成的 HTML 文件写入用户工作目录，并用 `preview_url` 展示

## 注意事项

- 保留历史版本：每次迭代升级时，将上一版重命名为 `example_output_vX.Y.html` 再生成新版
- PDF 下载功能：使用 html2canvas + jsPDF，捕获 `#pdf-print-area` 容器内容
- PNG 下载功能：使用 html2canvas 全页捕获（scale: 2），通过临时 `<a>` 标签触发下载
- 动画原理：饼图使用 SVG `stroke-dasharray` + `IntersectionObserver`；甘特图使用 CSS `@keyframes` + `overflow:hidden` 遮罩
