# 薪酬审计合规工具

## 功能简介
一款专为HR薪酬和财务审计岗位设计的专业工具。针对薪酬核算中人工校验耗时耗力、计算错误难以发现、合规风险隐患大的痛点，实现薪酬公式自动校验、异常数值智能识别、合规风险自动提示三大核心能力。

支持自定义薪酬核算规则、多维度薪酬数据交叉验证、自动生成审计报告，帮助企业将薪酬审计效率提升85%以上，将错误率降低95%，有效防范薪酬合规风险。

## 使用方法

### 前置准备
1. 准备薪酬核算结果表（Excel格式）
2. 明确薪酬核算规则和计算公式
3. 准备员工基础信息表（入职时间、职级、考勤数据等）

### 操作步骤
1. **导入薪酬数据** — 上传本月薪酬核算结果Excel表格，系统自动识别薪酬项目
2. **配置审计规则** — 设置公式校验规则、异常数值检测范围、合规检查项
3. **关联基础数据** — 上传员工基础信息表，配置关联字段，设置数据校验逻辑
4. **启动智能审计** — 系统自动执行公式校验，识别异常数值，检测合规风险
5. **生成审计报告** — 查看按错误类型分类的结果，导出问题清单和正式审计报告

## 使用示例
```
导入200人的薪资表，设定异常检测规则：月薪波动超过20%即告警。
系统发现3人薪资异常（1人计算错误、2人涨幅异常），10分钟内完成全量审计。
```
