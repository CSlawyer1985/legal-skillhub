# 人物资产分类与所需授权矩阵

短剧里出现的每一个"人物"，本质上对应一种或多种**人物资产类型**。不同类型触发的
肖像权/声音权授权义务完全不同。本技能把人物资产分为 5 类，逐类判定所需授权。

| 资产类型 (asset_type) | 含义 | 所需授权 (license_type) | 主要风险 |
|----|----|----|----|
| `ai_original` | AI 纯原创虚拟形象，无对应真人 | 无需真人授权 | 可能"神似"公众人物（撞脸）；平台可能要求 AI 形象报备/标识 |
| `real_actor` | 真人演员实拍出演 | `portrait`（肖像授权） | 缺授权、用途/平台/期限越界 |
| `digital_human` | 采购/租用第三方数字人形象 | `digital_human`（数字人许可） | 授权到期、平台越界、转授瑕疵 |
| `face_swap` | 换脸（对源肖像做替换） | `faceswap_source`（换脸源肖像授权） | 源肖像未授权、源为公众人物 |
| `voice_clone` | 声音克隆/语音合成他人音色 | `voice`（声音授权） | 声音权未授权（声音同样受法律保护） |

一个人物可同时属于多类，例如"数字人形象 + 声音克隆"需要**两份**授权。

## 判定原则

- **默认从严**：`drama-cast` 产出的角色若未在 `assets.json` 声明类型，默认按 `ai_original`
  处理（最保守），但仍会走"撞脸公众人物"人工复核项。
- **AI 原创不等于零风险**：AI 生成形象若与真实公众人物高度相似，仍可能构成肖像权/
  姓名权侵权，需人工复核并做区分。
- **声音是独立权利**：即便画面用 AI 原创形象，只要声音克隆了他人音色，仍需声音授权。

## 授权凭证登记字段（licenses.csv / .json）

| 字段 | 说明 | 是否必备 |
|----|----|----|
| `asset_name` | 对应人物名（须与角色名一致） | 是 |
| `license_type` | portrait / digital_human / faceswap_source / voice | 是 |
| `licensor` | 授权方（权利人） | 是（要素检查） |
| `licensee` | 被授权方（应为出品方） | 是（要素检查） |
| `scope_use` | commercial / noncommercial（商用/非商用） | 是（要素检查） |
| `scope_platform` | 授权平台范围，多个用 `;` 或 `,` 分隔 | 建议（平台越界检查依赖） |
| `scope_region` | 地域范围 | 建议 |
| `term_start` / `term_end` | 授权起止日期 YYYY-MM-DD | 是（到期检查依赖 term_end） |
| `transferable` | 是否可转授 yes/no | 建议（转授瑕疵检查） |
| `source` | original / sublicense（原始/二次授权） | 建议 |
| `doc_ref` | 授权凭证编号或存档位置 | 是（要素检查，便于举证留痕） |
