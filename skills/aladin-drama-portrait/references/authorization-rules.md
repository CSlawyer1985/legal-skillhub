# 授权链自查规则定义（A1–A10）

全部为**确定性规则**：同输入必同输出，命中带人物名、级别与整改建议。级别 P0 为授权
硬伤（触发 BLOCK），P1 为需处理的风险，P2 为提示。

| 规则 | 名称 | 级别 | 触发条件 | 整改方向 |
|----|----|----|----|----|
| A1 | 缺授权凭证 | P0 | 人物资产类型需要授权（real_actor/digital_human/face_swap/voice_clone），但登记表中无对应 `license_type` 记录 | 补齐并登记对应授权 |
| A2 | 授权要素缺失 | P1 | 已有授权记录，但缺 licensor/licensee/scope_use/term_start/term_end/doc_ref 任一必备要素 | 补全授权书要素 |
| A3 | 授权已过期 | P0 | `term_end` 早于发行基准日（或今日） | 续签至覆盖发行与持续传播期 |
| A4 | 即将到期 | P1 | `term_end` 距发行基准日不足 30 天 | 提前续签，短剧长期在架 |
| A5 | 平台越界 | P0 | 发行计划平台不在授权 `scope_platform` 范围内 | 扩大授权范围或移除越界平台 |
| A6 | 用途越界 | P0 | 授权 `scope_use` 为非商用，但短剧为商业发行 | 取得商用授权 |
| A7 | 撞脸公众人物 | P1 | ai_original 或 face_swap 被标记 `resembles_public_figure` 或填了 `public_figure_ref` | 人工复核相似度，做区分或取得授权 |
| A8 | 声音克隆缺授权 | P0 | （并入 A1，voice_clone 缺 voice 授权时报出） | 补声音授权 |
| A9 | 转授瑕疵 | P1 | 凭证 `source` 为二次/转授，但授权标注不可转授 | 核实原始授权可转授性，补齐授权链证据 |
| A10 | 平台报备缺失 | P1 | 项目含 AI 合成形象且发行平台属强制报备名单（红果/抖音/快手/腾讯/爱奇艺/芒果），未声明 `--filing-ai-persona yes` | 完成平台 AI 合成人物报备/显著标识 |

## 门禁评分算法

- 扣分权重：`P0=25`、`P1=8`、`P2=3`，总扣分 = Σ(权重 × 命中数)。
- 得分 = `max(0, 100 - 总扣分)`。
- 门禁结论：
  - 任一 **P0** → `BLOCK`（D 档，禁止上架）
  - 否则得分 ≥ 90 → `READY`（A 档）；80–89 → `READY`（B 档）
  - 其余 → `REVIEW`（C 档，建议整改后上架）

## 依据与边界声明

- 依据我国《民法典》人格权编对肖像权、声音（参照肖像权保护）的规定，以及主管部门对
  AI 生成合成内容标识、微短剧管理的通行要求进行的**工程化自查**。
- 本技能为**上架前授权链自查参考**，不出具法律意见，不替代律师审查与平台审核结论。
- 平台报备名单为常见强制报备平台的简化映射，实际以各平台最新规则为准。
