# 决定性问题卡

只选择与当前争点有关的问题。默认最多5个，不重复询问材料中已经明确的事项。

## 招投标与合同效力

1. 订约时项目是否依法必须招标？
2. 起诉时强制招标范围是否已经变化？
3. 定标前是否已经谈妥承包人、范围、价款等实质内容？
4. 是否存在先签合同、后补招标？

## 资质借用

1. 名义承包人与实际组织施工者分别是谁？
2. 发包人在订约时是否知道或者应当知道资质借用？
3. 谁支付保证金、投入资金、组织人员并控制施工？
4. 工程质量和已施工范围是否能够证明？
5. 发包人、名义承包人分别已经支付多少？

## 转包、违法分包与代位权

1. 原告直接与谁订约？
2. 违法形态是转包、违法分包还是资质借用？
3. 原告对直接前手的债权是否成立并到期？
4. 直接前手对发包人的债权是否成立并到期？
5. 直接前手是否怠于行权并影响原告债权实现？

## 农民工工资

1. 请求的是个人工资还是混有班组利润、材料费、机械费？
2. 谁实际招用、考勤和确认工资？
3. 属于违法发包、转包、违法分包还是正常分包？
4. 实名制、工资表、考勤和银行流水是否一致？

## 固定价与中途解除

1. 是固定总价、固定单价还是其他计价？
2. 争议源于市场涨价、工程变更、工程量变化还是工期延误？
3. 合同是否有调价或解除清算约定？
4. 延误可归责于谁？
5. 已完部分是否质量合格，成本结构是否适合比例法？

## 审计与财政评审

1. 合同是否明确约定以审计或财政评审确定价款？
2. 结算资料何时完整提交，有无签收和补正？
3. 合同是否约定审计期限？
4. 迟延是否由承包人造成？
5. 已有结果与合同“明显不符”的具体项目是什么？

## 质量、修复与退场

1. 缺陷原因和责任主体是否确定？
2. 发包人是否通知并给予合理修复机会？
3. 是否已实际修复，范围和费用如何证明？
4. 合同何时解除、承包人何时退场？
5. 已完工程界面、质量和现场资料是否固定？

## 优先受偿权

1. 主张人是否为依法享有优先权的主体？
2. 工程价款本金、损失、利息分别是多少？
3. 对应哪一项特定工程？
4. 应付款日及任何变更付款日如何形成？
5. 是否发生债权转让、折价、毁损灭失或征收？
