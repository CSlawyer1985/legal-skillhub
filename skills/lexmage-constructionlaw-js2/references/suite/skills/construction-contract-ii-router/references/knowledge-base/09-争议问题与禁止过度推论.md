# 争议问题与禁止过度推论

## 一、为什么需要这份清单

新解释解决了大量裁判分歧，但不等于每个边界都已经封闭。AI最危险的错误不是漏引一条，而是把一条有限规则扩张成“任何案件都如此”。以下问题应输出审慎结论。

## 二、逐条边界

### 第1条：起诉时的判断节点

条文解决签约时必须招标、起诉时不再属于必须招标范围的效力问题。不能反推：

- 签约时违反招标规则的所有瑕疵都被治愈；
- 围标、串标、先定后招等独立无效事由也被排除；
- 只要后来政策变化，合同即当然有效。

### 第2条：自愿招标与标前接触

需要结合招标性质、程序文件和实质谈判程度判断。正常技术交流、需求澄清，不当然构成中标无效；但以招标形式掩盖已确定承包人和实质条件，风险极高。

### 第4条：知情时间

“订立施工合同时知道或者应当知道”是核心。后来知道、默认施工、直接支付等事实可以成为间接证据，但不能自动替代订约时知道或者应当知道的证明。

### 第7条：一般代位权边界

第7条明确特定违法施工主体的代位路径，但不能草率断言合法分包人绝无代位权。民法典一般代位权规则仍需独立审查。反过来，特定主体也不能免除代位权要件。

### 第8条：责任形式

条例使用先行垫付、先行清偿、清偿等不同责任表达。AI应按具体事实匹配相应条款，不得统一改写为“承担连带责任”。

### 第9条：工期与涨价原因

条文针对约定工期内的人工、主要材料价格变化。因发包人原因延误后跨期涨价、工程变更、工程量变化等，是否调整要另行审查合同、违约责任和因果关系。

### 第10条：比例法适配

比例法为法院“可以”采用的方法。对于设计采购施工成本结构明显不均、前期投入集中、第三方接续范围不同或比例明显失真的项目，仍应审查鉴定口径与公平性。

### 第12条：折价补偿协议

协议不因基础合同无效而当然无效，也不因名为“结算协议”就当然有效。协议自身的效力、代理权限、意思表示和第三人利益必须另审。

### 第13条：审计适用范围

本条指向审计机关审计结果或财政评审结论。私人造价咨询、发包人内部审核、全过程咨询审定不当然适用本条，但可能受合同约定、诚信原则和一般结算规则约束。

未约定期限时的“一年”是司法鉴定启动规则的重要节点；有约定期限时应依条文分别判断，不能无差别适用一年。

### 第14条：未完工程质量

条文以已施工部分质量合格为重要前提。存在质量争议时，应先固定质量状态并确定修复责任，不能仅因退场满期即忽视质量问题。

### 第16条：紧急修复

条文建立通常的通知和修复机会顺序。遇有危及人身财产安全、缺陷持续扩大、承包人明确拒绝或客观无法联系时，应结合紧急避险、减损义务和证据情况判断，不宜要求机械等待，也不能借“紧急”规避通知。

### 第19条：优先权是否随债权转让

条文采用综合审查而非绝对随附或绝对不随附。质量、结算、转让效力和合理对价均需证明，后续权威案例可能继续细化权重。

### 第20条：替代财产范围

明确列举毁损、灭失或征收对应的保险金、赔偿金、补偿金。普通出售、强制拍卖或其他处置所得是否及如何处理，不应无依据类推。

### 第21条：展期与第三人

客观原因协商变更付款日期、结算后另定付款日，可以影响起算。条文不支持通过虚假展期损害购房消费者、抵押权人或其他第三人。

### 第23条：程序阶段

条文以2026年6月30日后人民法院新受理的一审案件为核心。对该日前已受理案件、上诉案件、发回重审、再审及仲裁程序，应结合司法解释时间效力的一般规定和具体程序状态审查，不得仅凭条文作超范围结论。

## 三、禁止出现的绝对化结论

| 禁止表述 | 应改为 |
|---|---|
| 实际施工人可以直接起诉发包人 | 先识别资质借用、转包、违法分包或工资请求，再匹配第4、6、7、8条 |
| 新解释废除了所有实际施工人规则 | 新解释不再以该概念配置一般性路径，并在冲突范围内替代旧规则；具体主体权利应分别判断 |
| 发包人知道挂靠就要付款 | 重点是订约时知道或者应当知道，并需审查质量、价款、已付款和请求范围 |
| 固定价绝对不能调整 | 原则承担约定工期内普通涨价风险，但合同调价、情势变更、变更和延误等另审 |
| 中途解除只能使用比例法 | 无约定、不能协商且质量合格时法院可以采用，适配性仍需审查 |
| 无效合同所有条款都可参照 | 参照与工程价款有关的完整约定，并受质量、公平和个案事实限制 |
| 政府工程必须审计后付款 | 是否以审计定价取决于合同；长期不出或明显不符时存在司法鉴定路径 |
| 发包人修复了就能全额索赔 | 还需证明责任、通知、机会、实际发生、必要性和合理性 |
| 优先权包括停窝工损失 | 停工、窝工等损失不属于优先受偿范围 |
| 债权一转让，优先权必然随转 | 第19条要求综合审查 |
| 重新约定付款日即可无限续期 | 必须符合第21条条件并审查真实性和第三人利益 |
| 民事法院通报就证明违法犯罪 | 通报、移送与行政认定、刑事定罪不是同一结论 |
