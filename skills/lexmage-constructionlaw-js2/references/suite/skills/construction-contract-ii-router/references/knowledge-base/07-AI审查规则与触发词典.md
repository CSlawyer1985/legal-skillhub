# AI审查规则与触发词典

## 一、审查目标

AI的任务不是检索到关键词后复述法条，而是完成六步判断：

1. 识别材料类型、使用者角色和目标；
2. 还原主体、合同、资金和施工关系；
3. 判断《建工解释二》的具体条文是否命中；
4. 找出旧口径、事实缺口和证据缺口；
5. 说明新规则如何改变结论；
6. 给出可直接执行的修改意见或角色策略。

## 二、输入预检

每次审查至少识别以下字段：

| 字段 | 内容 |
|---|---|
| 材料类型 | 案情简介、合同、起诉状、答辩状、代理词、法律意见、裁判文书、专业文章 |
| 使用角色 | 发包人、承包人、资质出借人、资质借用人、转包人、接受转包者、违法分包人、接受违法分包者、农民工、企业法务、诉讼律师、作者 |
| 时间 | 合同订立、招标、施工、解除、退场、验收、结算、付款到期、起诉受理 |
| 主体链 | 发包人—总包—分包—班组—劳动者；名义主体与实际主体 |
| 请求性质 | 合同价款、折价补偿、代位权、工资、修复费、损失、优先权 |
| 工程状态 | 在建、完工、未完、解除、无效、退场、质量合格或争议 |

无法识别时，使用“未提供”而不是自行补造事实。

## 三、七种工作模式

### 1. 快速扫描

输出不超过十个高价值命中点。每点包括：

- 风险等级；
- 触发条文；
- 原文位置；
- 为什么值得警惕；
- 一句话行动建议。

不展开所有背景规则。

### 2. 深度审查

逐条形成“事实—规则—要件—证据—反方抗辩—结论—下一步”闭环，并区分明确命中、可能命中、证据不足、不适用和待裁判发展。

### 3. 文书纠偏

对起诉状、答辩状、代理词或法律意见：

- 标出旧术语和错误请求权；
- 重构当事人、诉讼请求和法律依据；
- 补充构成要件事实；
- 给出可替换段落；
- 不得在事实不足时虚构证据或确定结论。

### 4. 合同体检

逐条检查招标、资质、授权、固定价、调价、解除结算、审计、退场、质量修复、质保金、债权转让和优先权条款。输出：

- 原条款；
- 新规影响；
- 风险归属；
- 修改建议；
- 建议文本；
- 配套流程或证据要求。

### 5. 文章校准

识别旧口径、绝对化表述、遗漏前提、法源层级错误和时间效力问题。修改后保留作者观点，但把规范结论与研究观点明确分开。

### 6. 角色策略

同一事实至少分别说明当前使用者的有利点、不利点、举证负担、对方可能策略和三项优先行动。

### 7. 新旧规则对照

固定输出：

- 以前规则或常见做法；
- 新规则；
- 变化性质：新增、细化、纠偏、替代、程序化；
- 决定结论的关键事实；
- 对合同、证据和诉讼的影响。

## 四、二十三条触发词典

关键词只能触发“进一步审查”，不能直接判定适用。

| 条文 | 初筛关键词或事实 | 必核要件 | 常见误报 |
|---|---|---|---|
| 第1条 | 必须招标、未招标、招标范围调整 | 订约时属于必招；起诉时已不属；无其他无效原因 | 把一切未招标合同都认定有效 |
| 第2条 | 先定后招、标前谈判、保底中标、陪标 | 定标前；实质性内容；中标合同 | 正常招标咨询、非实质接触 |
| 第3条 | 挂靠、借资质、管理费、借用费 | 资质借用；内部关系；质量合格 | 转包、违法分包误作挂靠 |
| 第4条 | 发包人知道挂靠、直接付款、直接管理 | 发包人订约时知道或者应当知道；质量合格 | 施工中后来知道 |
| 第5条 | 项目部章、材料款、租赁费、无权代理 | 授权或表见代理全部要件 | 材料用于项目即推定责任 |
| 第6条 | 实际施工人、转包、违法分包、欠付范围 | 接受转包/违法分包；直接前手；质量合格 | 继续直诉无合同关系发包人 |
| 第7条 | 代位权、发包人欠总包、怠于行权 | 两层到期债权；怠于行权；影响实现；范围 | 将代位等同一般直诉 |
| 第8条 | 农民工、工资、实名制、专户、班组 | 工资性质；条例对应责任主体 | 包工利润、材料费冒充工资 |
| 第9条 | 固定总价、固定单价、人工材料涨价 | 约定工期内；无调价约定；非情势变更 | 变更、工期延误、工程量变化 |
| 第10条 | 固定总价、未完、解除、比例法 | 无约定且协商不成；质量合格 | 写成任何案件唯一算法 |
| 第11条 | 无效合同、参照合同、折价补偿 | 质量合格；价款条款范围 | 只参照单价不参照完整体系 |
| 第12条 | 无效合同、结算协议、清算协议 | 质量合格；协议无独立瑕疵 | 主合同无效即协议无效或必然有效 |
| 第13条 | 审计、财政评审、久审不决、司法鉴定 | 是否约定；期限；迟延原因；明显不符 | 私人造价审核全部套用本条 |
| 第14条 | 未完工程、解除、无效、质保金、退场 | 基数；约定；退场或解除日期 | 质保金返还等于保修责任消灭 |
| 第15条 | 退场、移交资料、施工界面、证据保全 | 合同解除或无效；占有材料范围 | 任意扣留对方全部资料 |
| 第16条 | 质量缺陷、通知修复、第三方修复费 | 责任原因；通知；机会；实际修复；合理费用 | 未修复即主张估算费用 |
| 第17条 | 优先权、停窝工、判决主文 | 工程价款数额；对应特定工程；范围 | 把全部损失纳入优先权 |
| 第18条 | 折价、以房抵债、优先权行使 | 目的、主体、对价、第三人、不宜折拍 | 普通抵债等同优先权 |
| 第19条 | 债权转让、保理、优先权随附 | 竣工验收、结算、转让效力、合理对价 | 一律随转或一律不随转 |
| 第20条 | 毁损、灭失、征收、保险金、补偿金 | 原权利成立；替代性；对应关系 | 普通出售款也当然代位 |
| 第21条 | 优先权期限、展期、补充付款日 | 客观原因或结算后约定；真实性；第三人 | 任意展期都重启十八个月 |
| 第22条 | 违法招标、资质、行政处罚、犯罪线索 | 民事材料反映违法或犯罪线索 | 把通报移送等同刑事定罪 |
| 第23条 | 2026年6月30日、新受理、旧案 | 一审受理日；旧解释冲突 | 只看合同签订或施工日期 |

## 五、风险等级

- **高风险**：可能改变合同效力、付款被告、请求权基础、重大金额计算、优先权存续或诉讼胜败。
- **中风险**：主要影响举证、程序、合同解释、金额细项或文书说理。
- **低风险**：表述、术语、引用或流程有瑕疵，但暂不改变核心结论。

风险等级不能代替结论标签。

```markdown
- 最重要的新规影响
- 最大事实或证据缺口
- 当前角色最先采取的行动

## 2. 命中矩阵
| 原文位置 | 触发事实 | 条文 | 结论标签 | 风险 | 新旧变化 |

## 3. 逐项分析
### 问题一
- 已知事实
- 隐藏变量
- 现行规则
- 要件匹配
- 反方观点

- 待补证据

## 4. 修改建议
| 原文 | 问题 | 建议替换文本 | 修改理由 |

## 5. 角色化行动清单

## 6. 法源

## 7. 不确定性与适用边界
```

## 七、材料类型专用规则

### 1. 案情简介

先画主体和合同链，再回答；事实不足时给分情形结论和最小补证清单。

### 2. 合同

不仅审查条款文字，还要指出履约流程、授权体系、表单和台账如何配套。建议条款不能违反强制性规范，也不能用合同排除农民工工资法定责任。

### 3. 诉讼文书

逐项核对当事人、请求权、诉讼请求、事实要件、证据和计算口径。新解释条文不得堆砌引用。

### 4. 裁判文书

区分裁判时间、受理时间、规范依据和裁判规则。旧裁判可用于说明历史口径，不得无说明地当作新解释施行后的现行结论。

### 5. 专业文章

逐段识别规范陈述、经验判断和作者意见。对规范陈述要求官方来源；研究性争议应标记为“尚待裁判发展”。

## 八、硬性护栏

1. 先核验第23条，再适用实体条文。
2. 引用条文原文必须来自官方正式文本。
3. 对外披露来源以法律法规、最高人民法院正式发布及其他可核验权威法源为准。
4. 内部研究材料只用于发现问题、构建假设和交叉校验，不在输出中披露其来源。
5. 不虚构案号、裁判观点、合同条款、证据或事实。
6. 不把答记者问、典型案例的说明扩大成条文没有规定的一般规则。
7. 不以关键词直接下结论，必须完成主体、时间、质量、到期和证据审查。
8. 结论存在争议时写明主流解释、反向解释和决定性事实。
9. 每次对外输出应注明审查基准日和适用法版本。
10. 若涉及后续修法、新发布案例或地方差异，应重新检索现行权威来源。
