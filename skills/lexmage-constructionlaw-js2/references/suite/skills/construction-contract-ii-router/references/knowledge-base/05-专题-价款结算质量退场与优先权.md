# 专题二：价款、结算、质量、退场与优先受偿权

## 一、总流程

处理工程款争议时，不应从“欠多少钱”直接起算。正确顺序是：

> 合同效力 → 工程范围与质量 → 计价及风险分配 → 结算和到期 → 扣款与修复 → 已付款 → 优先受偿范围与期限

债权数额成立，不等于付款义务已经到期；付款义务到期，也不等于全部金额享有建设工程价款优先受偿权。

## 二、固定价格合同

### 1. 第9条：约定工期内的市场涨价

适用前提：

- 合同采用固定总价或者固定单价；
- 争议是约定工期内人工费或主要建筑材料价格的重大变化；
- 当事人没有约定价格调整；
- 尚未达到民法典第五百三十三条情势变更的严格条件。

在此前提下，原则上不支持承包人的调价请求。固定价格意味着承包人承担通常市场波动风险。

以下情形不得误判为单纯涨价：

- 发包人变更设计或增加工程范围；
- 实际工程量明显变化；
- 发包人迟延供图、迟延交地、迟延付款造成工期跨期；
- 不可归责于承包人的工期延长；
- 合同已有材料调差、指数联动或风险幅度条款；
- 价格变化达到情势变更条件。

### 2. 第10条：固定总价合同中途解除

当事人没有约定、不能协商，且已完工程质量合格时，法院可以按以下方法计算：

> 应付价款 = 固定总价 × 已完工程价款 ÷ 全部工程价款

其中“已完工程价款”和“全部工程价款”是按合同约定计价方法测算的对应造价，比例法用于保持固定总价风险分配。

不能机械使用比例法的风险点包括：

- 已完部分与未完部分的成本结构严重不均衡；
- 前期措施费、临建费、设计费或设备采购集中发生；
- EPC项目设计、采购、施工之间无法简单同比；
- 解除原因导致某些合同风险不能再按原比例分摊；
- 工程质量不合格；
- 当事人已有有效结算或解除清算约定。

条文使用“可以”，不是承包人或发包人的单方算法选择权。

## 三、无效合同的价款清算

### 1. 第11条：参照范围扩大并明确

工程质量合格时，可以参照合同关于工程价款的约定折价补偿。可参照内容包括：

- 工程价款金额；
- 计价方法；
- 支付时间和支付方式；
- 价格调整规则；
- 结算方法。

不能只摘取对一方有利的单价，而否定同一计价体系中的下浮、风险范围、支付节点和结算规则。是否参照某一条款，仍需审查该条款与工程价值的关联及公平性。

### 2. 第12条：无效合同后的折价补偿协议

施工合同无效，不导致双方事后达成的清算协议当然无效。满足以下条件时，原则上应依协议处理：

- 已施工工程质量合格；
- 协议真实处理折价补偿或结算；
- 协议本身不存在独立的无效、可撤销或不生效事由。

应单独核查虚假意思表示、恶意串通、胁迫、显失公平、无权代理、损害第三人和逃避债务等问题。

## 四、审计与财政评审

第13条只针对审计机关审计结果或财政评审结论，不应泛化至所有建设单位内部审核、造价咨询审核和商业复核。

### 1. 未约定以审计、财政评审为定价依据

发包人不能单方以审计或财政评审结果确定工程价款。

### 2. 有约定但结果长期不出

非因承包人原因出现以下情形，承包人可以申请司法鉴定：

- 合同约定期限届满仍未作出结果；
- 没有约定期限，由法院结合工程规模、造价金额和复杂程度等确定合理期限，但最长不得超过承包人提交竣工结算文件之日起一年。

### 3. 结果与合同明显不符

即使审计或财政评审结论已经作出，承包人有证据证明其与合同约定明显不符的，也可以申请司法鉴定。

“明显不符”需要具体指向漏项、错误计价依据、违反合同风险分配、程序缺失或计算错误，不能只写“审减过多”。

## 五、解除、无效与退场

### 1. 第14条：未完工程的质保金

施工合同解除时，质量保证金以承包人应得工程价款为基数；施工合同无效且工程未完工时，以应得折价补偿款为基数。

本条改变的是质量保证金返还期限的**起算节点**，没有统一创设“两年返还期”：

- 施工合同解除：原则上从承包人退场之日起算；
- 承包人退场后合同才解除：从解除之日起算；
- 施工合同无效且工程未完工：从承包人退场之日起算。

期限长度仍应依据合同约定及其他现行质量保证金规则确定。

质保金返还不等于承包人的保修责任当然消灭。

### 2. 第15条：资料移交与证据保全

施工合同解除后，发包人可以请求承包人移交施工现场、施工资料等。第15条没有把“合同无效”列为该款的明示适用情形；无效合同退场和移交应结合返还、折价补偿及个案占有依据另行分析。承包人不能将依法应移交的完整工程资料长期作为工程款谈判筹码。

退场前应固定：

- 已完与未完工程界面；
- 现场材料、设备和临时设施；
- 质量状态和缺陷；
- 隐蔽工程；
- 施工资料目录；
- 进场、退场时间及原因。

协商不成时，可依法申请证据保全。自行录像应包含连续方位、时间、定位、见证和清单，避免只有零散局部画面。

## 六、质量修复费用

第16条确立的通常顺序是：

> 发包人通知修复 → 给予合理期限和机会 → 承包人拒绝或逾期未修复 → 发包人实际组织修复 → 请求合理修复费用

发包人应证明：

- 缺陷属于承包人施工质量责任；
- 已作有效通知；
- 修复期限合理；
- 承包人拒绝或逾期未修复；
- 第三方修复确已发生；
- 修复范围和费用必要、合理；
- 已避免缺陷扩大和不必要损失。

承包人应重点审查：

- 是否收到具体缺陷通知；
- 是否被剥夺进场检查和修复机会；
- 缺陷是否由设计、材料、使用、第三人施工或维护不当造成；
- 修复是否超出必要范围；
- 费用凭证、招采过程和付款是否真实。

对存在紧急安全危险、损失持续扩大或承包人明确拒绝的情形，是否必须机械等待，应结合减损规则和个案紧迫性判断，不能过度推论。

## 七、建设工程价款优先受偿权

### 1. 第17条：判项和范围

法院支持优先受偿权时，应在裁判主文写明：

- 享有优先受偿权的工程价款数额；
- 对应的具体建设工程。

停工、窝工等损失不属于优先受偿范围。利息、违约金和损害赔偿原则上仍应与工程价款本金区分。

### 2. 第18条：以折价方式行使

承包人依据与发包人订立的折价协议主张已经行使优先受偿权，必须同时满足四项法定条件：

- 承包人施工的工程质量合格；
- 建设工程可以折价；
- 发包人逾期支付工程价款，经催告后在合理期限内仍未支付；
- 折价金额与折价时工程实际价值基本相当。

在四项条件之外，仍应按一般规则审查协议主体、意思表示、处分权限以及购房消费者等第三人合法权益，但不能把这些一般审查事项篡改成第18条列明的第五项要件。

普通以房抵债、抵偿协议或商品房买卖合同，不当然等于依法行使工程价款优先受偿权。

### 3. 第19条：债权转让

工程价款债权转让后，受让人是否取得优先受偿权，不作一刀切。综合审查：

- 工程是否竣工验收合格；
- 工程价款是否结算；
- 债权转让是否真实、有效；
- 受让人是否支付合理对价。

实务中还应审查虚假转让、关联交易、规避执行、债权范围不清和重复转让。

### 4. 第20条：物上代位

工程毁损、灭失或被征收时，优先效力可及于相应保险金、赔偿金或补偿金。应证明：

- 原工程价款优先受偿权成立且未消灭；
- 替代财产与特定工程存在对应关系；
- 款项性质确属保险金、赔偿金或征收补偿金；
- 主张金额未超过原优先权范围。

条文没有明确覆盖普通出售工程所得价款，不能类推为所有处置款均当然承载优先权。

### 5. 第21条：十八个月起算

既有规则为自应当给付建设工程价款之日起最长十八个月。新解释进一步明确：

- 因客观原因协商变更付款日期的，从变更后的日期起算；
- 对工程价款结算后另行约定付款日期的，从该日期起算。

需要核查变更是否真实、是否基于客观原因、是否损害购房消费者或其他第三人利益。双方不能通过倒签、虚假展期无限延长对第三人的优先效力。

## 八、工程款案件最低计算表

| 项目 | 必须查明 |
|---|---|
| 合同效力 | 有效、无效及无效原因 |
| 工程范围 | 合同内、变更、签证、甩项、未完工程 |
| 质量 | 合格、缺陷、修复、未验收责任 |
| 计价 | 固定总价、固定单价、可调价、成本加酬金 |
| 清算 | 合同价、折价补偿、结算协议、审计、鉴定 |
| 到期 | 验收、结算、付款节点、条件是否成就 |
| 扣款 | 质保金、甲供材、水电费、违约金、修复费 |
| 已付款 | 付款主体、收款主体、用途和冲抵顺序 |
| 优先权 | 主体、范围、特定工程、起算、十八个月 |
