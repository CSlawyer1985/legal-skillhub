# 技能路由表

用户无需阅读本表或主动选择模式。总控自动选择；用户明确点名时尊重其选择。

## 一、技能路径

| 模式 | 技能 | 适用任务 |
|---|---|---|
| 快速扫描 | `../../construction-contract-ii-quick-scan/SKILL.md` | 几分钟内发现高风险、新规命中和旧口径 |
| 深度审查 | `../../construction-contract-ii-deep-review/SKILL.md` | 完整审查事实、证据、请求权、抗辩和法律适用 |
| 合同体检 | `../../construction-contract-ii-contract-check/SKILL.md` | 审查和修改施工合同、补充协议、结算或解除协议 |
| 文书纠偏 | `../../construction-contract-ii-document-corrector/SKILL.md` | 修改起诉状、答辩状、代理词、法律意见等 |
| 文章校准 | `../../construction-contract-ii-article-calibrator/SKILL.md` | 校准专业文章、书稿、课程稿和裁判评析 |
| 角色策略 | `../../construction-contract-ii-role-strategy/SKILL.md` | 站在指定主体立场设计策略 |

维护入口：

| 任务 | 文件 | 适用任务 |
|---|---|---|
| 更新检查 | `../../../../update-policy.md` | 检查 SkillHub 版本、开源仓库版本和官方法源变化；经用户确认后通过平台升级 |

## 二、典型组合

| 用户输入 | 主模式 | 辅助模式 |
|---|---|---|
| 一段案情，问“哪里有风险” | 快速扫描 | 角色策略 |
| 完整案卷或证据包 | 深度审查 | 角色策略 |
| 施工合同或补充协议 | 合同体检 | 快速扫描 |
| 起诉状、答辩状、代理词 | 文书纠偏 | 深度审查、角色策略 |
| 专业文章或书稿 | 文章校准 | 快速扫描 |
| 问“作为发包人/承包人怎么办” | 角色策略 | 深度审查 |

## 三、材料处理前置

- 长材料：先建立稳定结构并完成23条覆盖扫描。
- 多份材料：先建材料登记、统一时间轴、主体表和金额表。
- 扫描PDF或图片：先确认OCR质量。
- 用户只要重点：优先一屏版，不展开完整内部矩阵。
