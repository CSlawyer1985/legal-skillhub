# 合同审查矩阵

| 模块 | 必查问题 | 典型修改方向 |
|---|---|---|
| 招标订约 | 是否存在标前实质谈判、先定后招 | 合规接触边界、决策和谈判留痕 |
| 资质分包 | 禁止资质出借、转包、违法分包是否可执行 | 核验、报告、解除、损失和现场处置 |
| 授权印章 | 谁可签约、采购、租赁和确认工程量 | 授权清单、印章范围、相对人核验 |
| 范围变更 | 固定价范围与变更边界是否清楚 | 指令、签证、计量、计价和期限 |
| 价格 | 风险幅度、调价公式、异常涨价 | 区分固定风险、变更、延误、情势变更 |
| 工期 | 开工、顺延、停窝工和归责 | 通知、证据、并发延误和损失计算 |
| 解除清算 | 中途解除如何确定已完工程 | 界面固定、比例法适配、损失分离 |
| 审计结算 | 审计是否定价、多久完成 | 合理期限、超期鉴定或替代机制 |
| 质量修复 | 是否给予通知和修复机会 | 缺陷确认、合理期限、紧急修复、费用审核 |
| 退场移交 | 现场、资料、材料设备如何交接 | 联合清点、影像、公证或证据保全 |
| 质保金 | 基数、起算、期限和保修关系 | 区分解除、无效未完和正常竣工 |
| 优先权 | 范围、期限、折价、转让 | 单列本金、对应工程、真实付款日期 |
