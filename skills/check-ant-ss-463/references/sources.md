# 官方来源与时效规则

## 来源优先级

- 先确认办理城市和区县；没有地点不得输出资格结论或具体数值。
- 人力资源社会保障部
- 当地人力资源社会保障部门
- 国家法律法规数据库
- 国家政策只用于解释上位规则；地方资格、金额、材料和入口必须落到办理地当前有效文件。

## 检索与引用

1. 优先检索发文机关官网、人民政府官网、政务服务网和官方办事平台；域名优先 `.gov.cn`。
2. 精确记录文件或页面标题、发文机关、发布日期、生效日期、适用地区、原文链接和核验日期。
3. 具体数字、连续月份、年龄、比例、基数、额度、办理期限和材料清单必须逐项有官方依据。
4. 对 PDF、附件或政策原文读取正文，不能只引用搜索摘要、自媒体解读或商业计算器。
5. 若官方页面互相冲突，优先采用层级更高、日期更新且仍有效的文件；无法判断时明确列出冲突并建议联系主管部门确认。

## 禁止做法

- 不把往年规则当现行规则。
- 不把其他城市、区县或人员身份的口径套用。
- 不承诺一定能买房、落户、入学、摇号、领取待遇或补贴。
- 不把补缴等同于连续缴费，也不默认补缴记录一定被资格审核采纳。
- 不以“0风险”“绝对合规”等无法验证的绝对表述替代事实核验。
