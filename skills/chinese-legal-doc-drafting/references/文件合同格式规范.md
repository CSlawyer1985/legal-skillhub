# 普通文件与合同格式规范

> 参照 GB/T 9704—2012《党政机关公文格式》改编

---

## 一、纸张与版面

| 项目 | 规范 |
|------|------|
| 纸张 | A4（210mm × 297mm），推荐定量 60~80g/m² |
| 页边距（上） | 37mm |
| 页边距（下） | 35mm |
| 页边距（左/订口） | 28mm |
| 页边距（右/切口） | 26mm |
| 版心尺寸 | 156mm × 223mm |
| 每面行数 | 22行 |
| 每行字数 | 28字 |

## 二、字体与字号

如无特殊说明，文件格式各要素一般使用**三号仿宋体字（16pt）**，特定情况可以作适当调整。

### 常用字号对照

| 字号名称 | 磅值（pt） | 典型用途 |
|----------|-----------|----------|
| 二号 | 22 | 文件标题 |
| 三号 | 16 | 正文、常规要素 |
| 三号 | 16 | 落款署名 |
| 四号 | 14 | 页码、版记、附注 |
| 小四号 | 12 | 表格内文字、附件清单 |
| 五号 | 10.5 | 脚注、注释 |
| 小五号 | 9 | 页眉页脚辅助文字 |

### 字体选用规则

| 用途 | 字体 |
|------|------|
| 文件标题 | 黑体（加粗），二号 |
| 正文 | 仿宋，三号 |
| 层次标题（第一层） | 黑体，三号，加粗 |
| 层次标题（第二层） | 楷体，三号，加粗 |
| 层次标题（第三/四层） | 仿宋，三号，加粗 |

## 三、行距与段落

| 项目 | 规范 |
|------|------|
| 行距 | 固定值 28.95磅（约3号字高度 + 3/8行距） |
| 首行缩进 | 正文每个自然段左空二字（约32pt） |
| 回行 | 顶格排布 |
| 标题间距 | 标题上空一行，标题下空一行 |
| 段落间距 | 段前0磅，段后0磅 |
| 文字颜色 | 黑色（如无特殊说明） |

## 四、正文层次序数

文中结构层次序数依次使用以下标注方式：

| 层次 | 标注方式 | 字体 |
|------|----------|------|
| 第一层 | 一、二、三、 | 黑体（加粗） |
| 第二层 | （一）（二）（三） | 楷体（加粗） |
| 第三层 | 1. 2. 3. | 仿宋（加粗） |
| 第四层 | (1) (2) (3) | 仿宋（加粗） |

## 五、普通文件/合同结构

普通文件与合同的版心内容可划分为三个部分：**文头**、**正文主体**、**文尾附注**。

### 1. 文头区域

| 要素 | 编排规则 |
|------|----------|
| 文件标题 | 居中，二号黑体加粗；可分多行，采用梯形或菱形排列 |
| 合同编号/文号 | 居中或右对齐，三号仿宋，标题下方空一行 |
| 签订日期 | 紧跟编号，三号仿宋 |
| 当事人信息 | 合同类文档在标题下方列出甲乙双方信息，仿宋三号 |

### 2. 正文主体

| 要素 | 编排规则 |
|------|----------|
| 正文 | 三号仿宋，首行缩进二字，回行顶格 |
| 条款编号 | 合同条款用"第一条""第二条"或"1.""2."标注，黑体加粗 |
| 表格 | 居中排列，表头加粗；表内文字可用小四号（12pt） |
| 金额数字 | 使用阿拉伯数字，合同金额应同时注明大写 |

### 3. 文尾区域

| 要素 | 编排规则 |
|------|----------|
| 签署区 | 正文下空二行，甲乙双方分左右排列 |
| 署名/盖章 | 署名用三号仿宋，盖章区域留白，盖章端正居中 |
| 签署日期 | 用阿拉伯数字写全年月日，如"2025年1月15日"，不编虚位 |
| 附件/附注 | 如有附件，在正文末尾空一行标注"附件："后列清单；附注用圆括号标注 |

## 六、页码

一般使用**四号半角阿拉伯数字（14pt）**，居中排列在页面底部。首页是否编排页码可根据需要确定。多页文件页码应连续编排。

## 七、标点符号与数字用法

| 项目 | 规范 |
|------|------|
| 标点符号 | 应符合 GB/T 15834《标点符号用法》 |
| 数字用法 | 应符合 GB/T 15835《出版物上数字用法》 |
| 计量单位 | 应符合 GB 3100/3101/3102 有关规定 |
| 日期格式 | 用阿拉伯数字，年月日标全，不编虚位（如"2025年1月5日"） |

## 八、合同封面页规范

🔴 **强制规则：合同必须包含封面页，且封面页必须单独占一页（封面后插入分页符 `doc.add_page_break()`）。正文内容从封面下一页开始。**

### 1. 封面页结构（从上到下）

| 区域 | 内容 | 编排规则 |
|------|------|----------|
| 顶部留白 | 4 个空段落 | 行距固定值 28.95 磅 |
| 合同名称（中文） | 如"软件产品售卖合同" | 居中，黑体加粗，42pt，行距 70 磅，段后 20 磅 |
| 合同名称（英文） | 如"Software Product Sales Contract" | 居中，楷体，18pt，行距 50 磅，段前 30 磅 |
| 间隔 | 3 个空段落 | 行距 40 磅 |
| 合同编号 | "合同编号：xxx" | 居中，仿宋，20pt，行距 50 磅 |
| 间隔 | 6 个空段落 | 行距 40 磅 |
| 当事人信息 | 甲方、乙方、签订地点、签订日期 | 居中，仿宋 18pt，标签加粗，行距 45 磅 |
| 间隔 | 3 个空段落 | 行距 40 磅 |
| 法律效力声明 | "【本合同共计壹份，具有同等法律效力】" | 居中，仿宋，14pt，行距 40 磅 |
| 分页符 | `doc.add_page_break()` | 封面后强制分页，正文从下一页开始 |

### 2. 当事人信息格式

| 字段 | 格式示例 |
|------|----------|
| 甲方 | "甲  方（出卖方）：" / "甲  方（委托方）：" / "甲  方：" |
| 乙方 | "乙  方（买受方）：" / "乙  方（开发方）：" / "乙  方：" |
| 签订地点 | "签订地点：" |
| 签订日期 | "签订日期：xxx年xxx月xxx日" |

### 3. 实现方式

🔴 **规则：必须使用 `docx_utils.py` 中的 `add_cover_page()` 函数生成封面页，禁止手动拼封面。**

```python
from docx_utils import add_cover_page

add_cover_page(
    doc,
    title_cn='合同中文名称',
    title_en='Contract English Name',
    contract_no='HT-2026-001',
    party_a_label='甲  方（出卖方）：',
    party_b_label='乙  方（买受方）：',
    location='xxx',
    date='xxx年xxx月xxx日'
)
```
