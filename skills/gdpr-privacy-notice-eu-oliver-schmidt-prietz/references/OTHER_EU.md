## 奥地利

| 方面 | 详情 |
|--------|--------|
| **国家法律** | DSG（《数据保护法》，Datenschutzgesetz） |
| **监管机构** | Datenschutzbehörde（DSB），Barichgasse 40-42, 1030 Wien |
| **语言** | 德语（"Datenschutzerklärung"） |
| **儿童年龄** | 14 岁（DSG 第 4 条第(4)款） |
| **DPO 门槛** | GDPR 第 37 条——无额外国家门槛 |
| **Cookie 法律** | 《电信法》（TKG 2021）第 165 条 |
| **保留期（税务）** | 7 年（BAO 第 132 条） |
| **特定内容** | 刑事定罪数据：仅可由官方机关处理或在官方机关监督下处理。媒体特权见 DSG 第 9 条。 |

## 意大利

| 方面 | 详情 |
|--------|--------|
| **国家法律** | D.lgs. 196/2003（《隐私法典》），经 D.lgs. 101/2018 修订 |
| **监管机构** | Garante per la protezione dei dati personali |
| **语言** | 意大利语（"Informativa sulla privacy"或"Informativa sul trattamento dei dati personali"） |
| **儿童年龄** | 14 岁（第 2 条之五） |
| **Cookie 法律** | Garante Cookie 指引（2021 年 6 月，2022 年更新）；"Linee guida cookie e altri strumenti di tracciamento" |
| **保留期（税务）** | 会计 10 年（《民法典》第 2220 条） |
| **特定内容** | 第 2 条之三：公共利益处理要求特定法律依据。第 2 条之六：特殊类别处理要求实质性公共利益。营销：电子邮件选择加入（D.lgs. 196/2003 第 130 条），既有客户软性选择加入。 |

## 西班牙

| 方面 | 详情 |
|--------|--------|
| **国家法律** | LOPDGDD（第 3/2018 号组织法） |
| **监管机构** | AEPD（西班牙数据保护局）+ 大区：APDCAT（加泰罗尼亚）、AVPD（巴斯克）、CTPDA（安达卢西亚） |
| **语言** | 西班牙语（"Política de privacidad"）。可能要求大区语言（加泰罗尼亚语、巴斯克语、加利西亚语） |
| **儿童年龄** | 14 岁（LOPDGDD 第 7 条） |
| **Cookie 法律** | LSSI（第 34/2002 号法律）第 22 条；AEPD cookie 指南 |
| **保留期（税务）** | 税务 4 年（《税收通则法》第 66 条），会计 6 年（《商法典》第 30 条） |
| **特定内容** | LOPDGDD 第 12 条：员工的"数字断连权"。第 89 条：互联网更正权。第 93-94 条：包括搜索引擎被遗忘权、数字教育在内的数字权利。举报人渠道数据：第 2/2023 号法律下的特定制度。 |

## 荷兰

| 方面 | 详情 |
|--------|--------|
| **国家法律** | UAVG（《AVG 实施法》） |
| **监管机构** | Autoriteit Persoonsgegevens（AP） |
| **语言** | 荷兰语（"Privacyverklaring"）。国际服务可接受英语。 |
| **儿童年龄** | 16 岁（GDPR 默认） |
| **Cookie 法律** | 《电信法》第 11.7a 条 |
| **特定内容** | BSN（公民服务号）处理受到严格限制（UAVG 第 46 条）。AP 对 Cookie 执法激进（高额罚款）。同意必须自由给予——不允许 Cookie 墙（AP 指引）。 |

## 比利时

| 方面 | 详情 |
|--------|--------|
| **国家法律** | 2018 年 7 月 30 日法律（Wet van 30 juli 2018） |
| **监管机构** | Autorité de protection des données（APD）/ Gegevensbeschermingsautoriteit（GBA） |
| **语言** | 法语和/或荷兰语和/或德语，视目标受众地区而定 |
| **儿童年龄** | 13 岁（第 7 条） |
| **特定内容** | 诉讼庭在制裁方面一直活跃。直接营销：《经济法法典》条款与 GDPR 并行适用。 |

## 爱尔兰

| 方面 | 详情 |
|--------|--------|
| **国家法律** | 《2018 年数据保护法》 |
| **监管机构** | 数据保护委员会（DPC）——许多美国科技跨国公司的牵头监管机构 |
| **语言** | 英语（爱尔兰语可选） |
| **儿童年龄** | 16 岁（DPA 2018 第 31 条） |
| **特定内容** | DPC 的《面向儿童的数据处理方法基础》。作为牵头监管机构对 Meta、TikTok 等采取重大执法行动。ePrivacy：SI 336/2011 实施 cookie 同意。 |

## 英国（脱欧后）

| 方面 | 详情 |
|--------|--------|
| **国家法律** | 英国 GDPR + 《2018 年数据保护法》 |
| **监管机构** | ICO（信息专员办公室） |
| **语言** | 英语 |
| **儿童年龄** | 13 岁（DPA 2018 第 9 条） |
| **从欧盟传输** | 欧盟对英国充分性决定（2021 年 6 月，已延长——请核实当前状态） |
| **从英国传输** | 英国充分性法规；英国 IDTA（国际数据传输协议）取代 SCC |
| **Cookie 法律** | PECR（《2003 年隐私和电子通信条例》） |
| **特定内容** | 《年龄适当设计准则》（儿童准则）——对可能被儿童访问的在线服务为强制性。ICO"合法利益"指引具有影响力。英国与欧盟 GDPR 的分歧持续——始终核实当前状态。DPDI 法案后 /《数据保护与数字信息法》——请核实实施状态。 |
