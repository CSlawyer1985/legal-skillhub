# 机械领域专利撰写 Skill（v4.1）

> 适用于机械结构、传动机构、控制系统、机械设备等机械领域的**发明专利和实用新型专利**申请材料撰写。覆盖从需求分析、**TRIZ辅助创新分析（§3.0T）**、初步方案设计、**新颖性预评估 → 创造性预评估（发明§3.0B完整版 / 实用新型§3.0C简化版）**、专利检索、规避设计到完整说明书+附图说明+权利要求书+摘要输出的全流程。
>
> **法律依据**：《专利法》(2021.6.1施行)、《专利法实施细则》(2024.1.20施行)、《专利审查指南》(2024.1.20施行，局令第78号)。
>

## 何时使用本 Skill

当用户需要以下帮助时，应使用本 Skill：
- **确认专利类型**（发明 or 实用新型）——第零步必须执行
- **TRIZ辅助创新分析**——运用TRIZ理论系统化生成具有新颖性和创造性的技术方案候选集（§3.0T）
- 撰写专利申请书的技术领域部分
- 分析现有技术并撰写背景技术
- 进行专利检索和规避设计
- 撰写发明内容/实用新型内容，突出新颖性和创造性
- 撰写附图说明，描述机械结构和附图标记
- 撰写具体实施方式，提供结构描述、工作原理和实施例
- 撰写权利要求书（发明专利：产品+方法；实用新型：仅产品）
- 撰写说明书摘要
- **设计初步技术方案并进行新颖性预评估（含方案迭代优化）**
- **发明专利：进行创造性预评估（§3.0B 完整版）**
- **实用新型：进行简化版创造性预评估（§3.0C）——同样需要创造性判断，标准更低**
- 生成完整的专利申请材料
- **将专利文件输出为 DOCX 格式**（§3.11：质量自检通过后，自动生成符合国家知识产权局提交规范的 .docx 文件）

## 核心撰写逻辑

**用清楚完整的结构描述（证明能造出来） + 充分的技术效果分析（证明有用且效果好） = 支撑一个宽泛但不过宽的权利要求（争取最大且有效的保护范围）**

**机械领域的核心特征**：机械领域靠"结构描述+附图+工作原理"证明方案可行。权利要求以**结构特征**限定保护范围，包括部件名称、连接关系、配合方式和参数范围。

**关键原则**：在动笔撰写之前，必须依次执行 **TRIZ前置检索 → TRIZ辅助创新分析（§3.0T）→ 初步方案设计 → 新颖性预评估 → 创造性预评估** 五步——前置检索负责"识别已有方案边界"，TRIZ负责"产生创造性方案的源泉"，预评估负责"验证方案是否满足专利法要求"。只有通过全部验证的方案，才进入正式撰写。若预评估发现核心特征已被公开或显而易见，必须携带"阻断性现有技术清单"返回TRIZ分析或方案设计阶段重新迭代——新一轮TRIZ必须针对该现有技术生成实质性差异化方案，而非简单调整。

## 零、法律框架与关键约束

本节提炼《专利审查指南》(2024) 第二部分第一章"发明和实用新型专利申请的审查"、第二部分第二章"说明书和权利要求书"及《专利法实施细则》(2024) 的核心规定，后续各模块的方法论均以本节为上位法依据。

### 0.1 说明书公开充分（《审查指南》第二部分第二章 §3.2.1）

> "说明书应当对发明或者实用新型作出清楚、完整的说明，以所属技术领域的技术人员能够实现为准。"

**机械领域公开充分三要素**（缺一不可）：

| 要素 | 核心要求 | 审查红线 |
|------|---------|---------|
| 机械结构的**确认** | 产品须公开部件组成、连接关系、配合方式、位置关系；附图须与文字描述一致 | 结构不明确且无法通过附图/参数确认 → 公开不充分 |
| 机械结构的**实现** | 必须记载至少一种实施方式（部件形状、尺寸范围、装配关系、材料选择） | 无实施方式或方式无法实施（如缺少关键连接关系）→ 公开不充分 |
| 机械结构的**用途/效果** | 必须公开用途或效果；技术效果不可预测时须提供**定性或定量描述** | 无效果描述且不可预测 → 公开不充分 |

**机械领域公开充分的特殊要求**：
- **附图是公开的有机组成部分**——对于结构特征，仅靠文字描述不够清楚时，必须有附图支撑（《审查指南》第二部分第二章 §2.3：说明书有附图的，应当对说明书附图进行说明）
- **运动关系必须可推导**——对于有相对运动的部件，须说明运动类型（旋转/直线/摆动/复合）、运动传递路径、运动约束关系
- **配合关系必须明确**——间隙配合、过渡配合、过盈配合须有明确表述；关键配合面须描述配合精度要求

### 0.2 实施例数量的法定标准（《审查指南》第二部分第二章 §3.2.2）

> "实施例的数目，取决于权利要求技术特征的概括程度……足以判断在权利要求所限定的范围内均可实施并取得所述效果。"

**机械领域数量判断原则**：

| 维度 | 机械发明专利 | 机械实用新型专利 |
|------|------------|----------------|
| 实施例性质 | 结构描述+参数范围+工作原理 | 结构描述+工作原理 |
| 数量驱动 | 结构参数概括范围越宽→实施例越多 | 结构清楚即可，数量要求宽松 |
| 典型数量 | **1个核心实施例 + 2-3个参数变化实施例** | **1个核心实施例 + 2-3个变型实施例** |
| 对照实施例 | **可选**（仅🟡风险方案需要，用于证明区别特征效果） | **不需要** |
| 性能测试数据 | **可选**（定性效果说明为主，🟡风险方案可补充） | **不需要**（定性效果说明即可） |

> ⚠️ **关键要点**：机械领域靠"结构描述+附图+工作原理"证明可行性和效果。机械实用新型虽仅做形式审查，但仍需满足创造性要求（§0.14.7），撰写时应有意识设计特征间的协同关系以支持"实质性特点和进步"。

**机械领域实施例设计原则**：
- 权利要求概括范围越宽（如尺寸范围跨度大、材料选择多）→ 需要的参数变化实施例越多
- 并列选择要素越多（如"齿轮传动或同步带传动"）→ 需要的实施例越多
- 核心原则：**"覆盖整个权利要求范围的合理分布"**——不能在某一端点密集而在另一端点空白
- 机械领域通常以**一个详细的核心实施例**为主体（完整结构+工作原理），辅以**少量参数变化实施例**证明范围可实施性
- **实用新型专利**：实施例数量可更少，核心实施例 + 2-3个变型实施例即可，无需对照实施例和性能测试

### 0.3 权利要求的法定类型（《审查指南》第二部分第二章 §3.2.2）

| 类型 | 表达方式 | 法律效果 | 适用场景 |
|------|---------|---------|---------|
| **产品权利要求** | "一种……装置/机构/设备/系统" | 保护产品结构本身 | 机械结构、传动机构、控制系统、机械设备等 |
| **方法权利要求** | "一种……的方法/工艺/控制方法" | 保护制造或使用方法 | 机械加工方法、装配方法、控制方法、检测方法等 |

**关键审查规则**：
- 产品权利要求以**结构特征**限定保护范围（非功能性限定，见 §0.12）
- 方法权利要求以**步骤顺序+工艺参数**限定保护范围
- 一项独立权利要求应只包含一种类型（产品或方法），不得混合
- 产品权利要求与方法权利要求可构成单一性（见 §0.13）

### 0.4 机械参数表述的法定约束（《审查指南》第二部分第二章 §3.2.2）

- 禁止使用"大约""左右""约"等含糊措辞
- 允许使用"0～X"或"＜X"（上限表示）
- 通常不允许使用"＞X"（下限表示，因为下限缺失会导致范围不确定）
- **结构参数范围必须符合机械设计常识**：尺寸、角度、公差、配合精度、传动比等参数的上下限须满足以下约束：

**机械参数合理性验证规则**：

| 验证类型 | 验证内容 | 示例 |
|---------|---------|------|
| **尺寸链一致性** | 有装配关系的部件尺寸须能配合（不干涉、不悬空） | 轴径须小于等于孔径（间隙配合）或大于孔径（过盈配合） |
| **运动学可行性** | 运动参数须满足运动学约束（不矛盾） | 传动比 = 从动轮齿数/主动轮齿数，须为正值且符合物理常识 |
| **参数范围包容性** | 权利要求参数范围 ⊇ 实施例参数范围 ⊇ 说明书范围 | 实施例中齿轮模数2.0-3.0，权利要求中应为1.5-3.5（向外扩展） |
| **公差合理性** | 公差范围须符合加工工艺能力 | 磨齿精度IT5-IT6，不得声称IT1（超出工艺能力） |
| **量纲一致性** | 同一参数的量纲须统一 | 不可在同一权利要求中混用mm和μm |

**违反后果**：参数范围不合理 → 权利要求不清楚 → 驳回/无效。

### 0.5 权利要求的类型选择（《审查指南》第二部分第二章 §3.2.2）

| 类型 | 适用条件 | 示例 |
|------|---------|------|
| **非限定型** | 说明书公开了两种或多种使用性能/应用领域 | "一种机械传动装置，其特征在于……" |
| **性能限定型** | 说明书仅公开一种性能 | "一种高传动效率的机械传动装置，其特征在于……" |
| **用途限定型** | 说明书仅公开一种用途 | "一种用于精密加工的机械传动装置，其特征在于……" |

**机械领域选择建议**：
- 大多数机械发明应使用**非限定型**或**用途限定型**——机械装置通常有明确用途
- 性能限定型慎用——"高效率""低噪音"等性能词可能被视为不清楚
- 用途限定词必须与说明书公开的用途一致，不得随意添加

### 0.6 诚实信用原则（《专利法实施细则》2024 新增 §11）

> "申请专利应当遵循诚实信用原则。提出各类专利申请应当以真实发明创造活动为基础，不得弄虚作假。"

**对本 Skill 的具体约束**：
- 所有结构、尺寸、工艺参数必须是机械上可实现的
- 所有技术效果描述必须在工程上合理（可使用定性或范围值表达，但逻辑必须自洽）
- 不得编造无法通过工程验证的技术效果
- 不得将公知常识包装为创新点
- **不得编造附图**——附图标记必须与文字描述一致，结构关系必须真实可实施

### 0.7 权利要求书的法定要求（《专利法》§26、《实施细则》§19-22）

**权利要求书的作用**：确定专利保护范围，是侵权判定和无效宣告的直接依据。

**基本要求**：
- 以说明书为依据（权利要求书与说明书内容一致）
- 清楚、简要地限定要求专利保护的范围
- 每一项权利要求应当在其结尾处使用句号
- 权利要求之间应当用分号分隔

**独立权利要求**（《实施细则》§21）：整体上反映技术方案，记载**解决技术问题的必要技术特征**。
**从属权利要求**（《实施细则》§22）：用附加技术特征对引用的权利要求作进一步限定。

**单一性要求**（《专利法》§31）：一件申请的权利要求应属于一个总的发明构思。

### 0.8 摘要的法定要求（《实施细则》§23）

- 摘要应当写明发明名称和所属技术领域
- 清楚反映所要解决的技术问题、技术方案的要点以及主要用途
- **不得超过300字**（含标点）
- 不得使用商业性宣传用语
- 可以包含最能说明发明的一幅附图

### 0.9 新颖性判断标准（《专利法》§22、《审查指南》第二部分第三章）

**新颖性**：发明不属于现有技术（申请日以前在国内外为公众所知的技术），也没有任何单位或者个人就同样的发明在申请日以前向专利局提出过申请并记载在申请日以后公布的专利申请文件或者公告的专利文件中。

**单独对比原则**：判断新颖性时，应当将发明专利申请的各项权利要求分别与每一项现有技术或抵触申请相关技术内容单独地进行比较，不得将几项现有技术或抵触申请内容的组合、或者一份对比文件中的多项技术方案的组合进行对比。

**机械领域新颖性特别规则**：
- 现有技术公开了相同结构（部件组成、连接关系、配合方式、位置关系）→ 无新颖性
- 结构有差异但功能相同 → 需分析差异是否带来预料不到的技术效果（此为创造性问题，非新颖性）
- **结构参数范围的端点交叉** → 新颖性丧失（只要现有技术的参数范围与本申请有交叉，且该参数是限定特征）
- **上位概念 vs 下位概念**：现有技术公开"齿轮传动"（上位），本申请"斜齿轮传动"（下位）→ 无新颖性；反之有新颖性

### 0.10 创造性判断标准（《专利法》§22、《审查指南》第二部分第四章 §3.2.1.1）

**创造性**：与现有技术相比，发明具有突出的实质性特点和显著的进步。

**新颖性 vs 创造性 — 关键区别（本 Skill 的核心方法论基石）**：

| 维度 | 新颖性 (§0.9) | 创造性 (§0.10) |
|------|:---:|:---:|
| 对比方式 | **单独对比**：一项权利要求 vs 一份现有技术 | **组合对比**：可将多份现有技术的不同技术内容组合评价 |
| 核心问题 | 该结构特征是否在某单一文件中被公开？ | D2/D3是否给出**技术启示**将区别特征应用于D1？ |
| 判断逻辑 | "有/没有"（二元判断） | "是否显而易见"（程度判断，需分析动机） |
| 评价顺序 | 先于创造性判断 | 仅在新颖性成立后才进行 |

**"三步法"判断流程**（《审查指南》第二部分第四章 §3.2.1.1，审查员标准流程）：

**第一步：确定最接近的现有技术（D1）**
- 优先选择：技术领域相同、技术问题/效果/用途最接近、公开技术特征最多的现有技术
- 次选：技术领域不同但能实现发明功能、且公开技术特征最多的现有技术
- 应注意首先考虑技术领域相同或相近的现有技术

**第二步：确定区别特征和发明实际解决的技术问题**
- 分析发明与 D1 的区别特征（机械领域主要是结构区别）
- 根据区别特征在发明中达到的技术效果，确定发明**实际解决的技术问题**
- 注意：实际解决的技术问题可能不同于说明书中描述的原始问题

**第三步：判断是否显而易见 — "技术启示"分析（本 Skill 的核心方法论）**

从 D1 和发明实际解决的技术问题出发，判断现有技术**整体上**是否存在技术启示——即现有技术是否给出将区别特征应用于 D1 以解决该技术问题的**动机**。

**下述三种情况，通常认为存在技术启示（发明是显而易见的，不具备创造性）：**

| 编号 | 技术启示来源 | 判定标准 | 机械领域案例类比 |
|:---:|------|------|------|
| **(i)** | **区别特征为公知常识** | 该特征是所属领域中解决该技术问题的惯用手段，或教科书/工具书中披露的解决该技术问题的技术手段 | 用滚动轴承替代滑动摩擦副（《机械设计手册》已指出轴承可减少摩擦） |
| **(ii)** | **区别特征在同一份对比文件的其他部分披露** | 同一文件的其他部分公开了该特征，且该特征在该部分所起的作用**与在发明中解决该技术问题所起的作用相同** | 对比文件A部分公开齿轮传动+B部分公开减震装置，两者可自然结合 |
| **(iii)** | **区别特征在另一份对比文件（D2/D3...）中披露，且作用相同** | D2公开了该区别特征，且该特征在 D2 中所起的作用**与在发明中解决该技术问题所起的作用相同** | 齿轮传动(D1)+滚珠丝杠定位(D2)→齿轮传动+滚珠丝杠定位（作用相同：精密定位） |

**⚠️ 注意**：第(iii)种情况是实质审查中最常见的驳回理由——审查员用 D1+D2 组合来质疑创造性。本 Skill 的 §3.0B 创造性预评估模块即围绕此场景设计。

**组合发明的创造性特殊规则**（《审查指南》第二部分第四章 §4.2）：

| 类型 | 判断标准 | 创造性 |
|------|---------|:---:|
| 显而易见的组合 | 各特征各自以常规方式工作，总效果=各部分效果之和，特征间无功能上的相互作用 | ✗ 不具备 |
| 非显而易见的组合 | 特征间功能上彼此支持，组合效果 > 各部分效果之和，产生了**预料不到的技术效果** | ✓ 具备 |

**"预料不到的技术效果"原则**：当发明与现有技术相比产生"质"的变化（新性能）或"量"的变化（超出预期想象），且对本领域技术人员事先无法预测或推理 → 具备创造性。

**本 Skill 的预评估体系**：
- **§3.0A（新颖性预评估）** → 逐特征检索 + 单独对比 → 过滤已被公开的方案
- **§3.0B（创造性预评估）** → 三步法 + 多文档技术启示分析 → 过滤"已知特征组合无协同"的方案
- 两个阶段**串行执行**：§3.0A 通过 → 才能进入 §3.0B

### 0.11 背景技术引用规范（《审查指南》第二部分第二章 §2.2.3）

> 《审查指南》第二部分第二章 §2.2.3："说明书的背景技术部分应当写明对发明的理解、检索、审查有用的背景技术，并且**尽可能引证反映这些背景技术的文件**。"

**本 Skill 的核心约束**：基于上述规定，背景技术部分中引用的每一项现有技术，必须有明确的、可检索验证的文献标识。具体规则如下：

**一、强制引用标识规则**

| 引用对象类型 | 必须提供的标识 | 正确示例 | 禁止写法 |
|------------|------|------|------|
| **中国发明专利/实用新型** | 申请号或公开号（CN开头） | CN202111092234A | ~~例如，已有专利公开了……~~ |
| **中国外观设计** | 申请号或公开号 | CN202330123456S | ~~例如，一种设计……~~ |
| **PCT国际申请** | 国际公开号（WO开头） | WO2025077933A1 | ~~例如，PCT申请……~~ |
| **美国专利** | 专利号或公开号（US开头） | US10,123,456 B2 | ~~例如，美国专利……~~ |
| **欧洲专利** | 公开号（EP开头） | EP3484444A1 | ~~例如，欧洲专利……~~ |
| **日本专利** | 公开号（JP开头） | JP2020-123456A | ~~例如，日本专利……~~ |
| **学术期刊文献** | 作者（至少第一作者）、标题、期刊名、卷期、页码（或DOI） | Wang et al., "High-precision gear transmission design", Mech. Eng. Sci., 2023, 235: 456-478 | ~~已有文献报道……；例如，有研究……~~ |
| **学位论文** | 作者、标题、学校、年份 | 李某某，"精密机械传动系统设计方法研究"，清华大学博士学位论文，2022 | ~~例如，有论文……~~ |
| **技术标准** | 标准编号、标准名称 | GB/T 10095.1-2008《圆柱齿轮精度制》 | ~~根据相关标准……~~ |

**二、禁止的模糊引用写法**

以下写法在背景技术部分**绝对禁止**：

| 禁止写法 | 问题 | 正确替代 |
|---------|------|---------|
| "例如，已有专利公开了一种……" | 未给出具体专利号，无法检索验证 | 直接引用具体专利号和方案描述 |
| "已有文献报道……" | 未给出文献出处 | 给出完整的作者、标题、期刊、卷期页码 |
| "现有技术中，一些方案采用……" | 未指明具体方案来源 | 引用具体专利号或文献 |
| "例如，有研究采用……的方法" | 模糊引用，无出处 | 给出可检索的具体文献 |
| "例如，CN202111092234公开了……" | "例如"一词暗示引用是举例性质，削弱权威性 | 删除"例如"，直接使用："CN202111092234A公开了一种……" |

**三、背景技术引用数量与质量要求**

| 要求 | 具体标准 |
|------|---------|
| 最少引用数 | ≥2项具体现有技术（专利或文献），每项有完整的可检索标识 |
| "例如"禁词 | 全文背景技术部分不得出现"例如"二字 |
| 引用方式 | 每项引用独立成句，明确描述该文献公开的技术方案及其缺陷 |
| 最新性 | 引用文献应覆盖近5年的相关技术（除非经典基础专利） |
| 可比性 | 引用的现有技术方案应能与本发明形成直接的技术对比 |

**四、预评估检索与背景技术引用的衔接**

- §3.0A 和 §3.0B 检索到的现有技术文献，其完整标识信息（申请号/公开号/文献出处）应**原样保留**，在撰写背景技术时直接引用
- 预评估阶段不得使用模糊引用——检索结果必须记录具体的文档标识符
- 背景技术中引用的文献必须全部来自预评估和正式检索的产出，不得凭空添加

### 0.12 功能性限定规则（《审查指南》第二部分第二章 §3.2.2）⭐机械领域核心

> **定位说明**：功能性限定是机械领域专利**最高频的审查驳回点和无效宣告攻击点**。机械发明人天然倾向于用功能语言描述发明（如"夹紧装置""定位机构""驱动组件"），而非具体的结构语言（如"凸轮夹紧机构""销钉定位结构""伺服电机驱动组件"）。《审查指南》对此有严格限制。

> 《审查指南》第二部分第二章 §3.2.2："通常，对产品权利要求来说，应当尽量避免使用功能性限定。只有在某一技术特征无法用结构特征来限定，或者技术特征用结构特征限定不如用功能性限定更恰当的情况下，才允许使用功能性限定。"

**一、功能性限定的定义与识别**

| 限定类型 | 定义 | 机械领域示例 |
|---------|------|------------|
| **结构限定**（推荐） | 用部件的形状、尺寸、材料、连接关系、配合方式等结构特征限定 | "所述夹紧机构包括凸轮（3）和压板（4），凸轮（3）通过销轴（5）铰接于机架（1），压板（4）的一端与凸轮（3）的轮廓面接触" |
| **功能性限定**（限制使用） | 用部件所实现的功能或效果限定，而非具体结构 | "所述夹紧机构用于将工件固定在预定位置" |
| **混合限定** | 结构特征+功能性特征组合 | "所述夹紧机构包括凸轮（3）和压板（4），凸轮（3）转动时驱动压板（4）压紧工件" |

**二、功能性限定的审查规则**

| 规则 | 内容 | 对撰写的影响 |
|------|------|------------|
| **原则禁止** | 产品权利要求应当尽量用结构特征限定 | 默认使用结构限定 |
| **例外允许** | 仅当结构特征无法限定或不如功能限定恰当时 | 须在说明书中证明"无法用结构限定" |
| **保护范围解释** | 功能性限定涵盖说明书所述的具体实施方式及其等同方式 | 保护范围可能比预期窄（仅限说明书实施例+等同） |
| **清楚性要求** | 功能性限定须使本领域技术人员能确定其边界 | "用于提高精度的装置"→不清楚（边界不明） |

**三、功能性限定的风险与规避策略**

| 风险 | 说明 | 规避策略 |
|------|------|---------|
| **保护范围缩窄** | 功能性限定仅覆盖说明书实施例+等同，结构限定覆盖所有实现该结构的方案 | 优先使用结构限定 |
| **不清楚驳回** | 功能描述模糊导致边界不清 | 将功能描述转化为可识别的结构特征 |
| **得不到说明书支持** | 功能性限定过宽，说明书实施例无法支撑 | 增加实施例覆盖度，或收窄功能性限定 |
| **无效宣告攻击** | 对手主张功能性限定应限缩解释，绕过保护范围 | 从属权利要求中补充结构限定作为防御纵深 |

**四、本 Skill 的功能性限定审查流程（§3.8 权利要求撰写时强制执行）**

```
对独立权利要求1中的每一个技术特征，执行以下审查：

第一步：识别——该特征是结构限定还是功能性限定？
  ├─ 结构限定（含部件名称+连接关系+配合方式）→ ✅ 通过
  └─ 功能性限定（仅描述功能，无具体结构）→ 进入第二步

第二步：评估——是否属于"无法用结构限定"的例外？
  ├─ 是（该功能确实无法用结构表达）→ 保留功能性限定，但在说明书中说明理由
  └─ 否（可以用结构表达）→ 进入第三步

第三步：转化——将功能性限定转化为结构限定
  ├─ 问：实现该功能的具体结构是什么？
  ├─ 用"包括[具体部件]，所述[部件]通过[连接方式]与[另一部件]连接，[配合关系描述]"替代
  └─ 在从属权利要求中保留功能性限定作为备用（纵深防御）

第四步：混合限定（推荐）——结构限定为主+功能性描述为辅
  ├─ "包括凸轮（3）和压板（4），凸轮（3）通过销轴（5）铰接于机架（1），
  │    压板（4）的一端与凸轮（3）的轮廓面接触，凸轮（3）转动时驱动压板（4）压紧工件"
  └─ 结构限定（凸轮+压板+销轴+接触关系）+ 功能描述（压紧工件）
```

**五、机械领域常见功能性限定→结构限定转化对照**

| 功能性限定（避免） | 结构限定（推荐） | 转化说明 |
|------------------|----------------|---------|
| "夹紧装置" | "凸轮夹紧机构，包括凸轮和压板，凸轮通过销轴铰接于机架" | 用具体机构替代功能描述 |
| "定位组件" | "定位销和定位孔，定位销与定位孔间隙配合" | 用具体结构要素替代 |
| "驱动单元" | "伺服电机，通过联轴器与传动轴连接" | 用具体驱动类型+连接方式替代 |
| "导向机构" | "直线导轨和滑块，滑块与直线导轨滑动配合" | 用具体导向结构替代 |
| "减震装置" | "橡胶减震垫，套设于支撑柱外侧，两端分别与机架和底座接触" | 用具体减震元件+安装关系替代 |
| "传动组件" | "同步带传动机构，包括主动轮、从动轮和同步带" | 用具体传动类型替代 |
| "锁紧件" | "锁紧螺栓，螺纹连接于调节座的螺纹孔，端部抵接滑块" | 用具体紧固件+连接关系替代 |

### 0.13 产品权利要求与方法权利要求的关系（《审查指南》第二部分第六章 §2.2）

机械领域常同时存在产品发明和方法发明，两者关系须明确：

| 关系类型 | 说明 | 单一性 | 撰写建议 |
|---------|------|:---:|---------|
| **产品+制造方法** | 方法用于制造该产品 | ✓ 有 | 产品独立权利要求 + 方法独立权利要求（"权利要求1-N中任一项所述的……的制造方法"） |
| **产品+使用方法** | 方法用于使用该产品 | 视情况 | 通常有单一性，但使用方法权利要求保护力较弱 |
| **产品+控制方法** | 方法用于控制该产品运行 | ✓ 有 | 控制方法须与产品结构特征关联 |
| **纯方法** | 仅保护方法步骤 | — | 方法权利要求须写明步骤顺序+工艺参数 |

**方法权利要求的类型**（机械领域）：

| 方法类型 | 保护对象 | 典型步骤 | 参数要求 |
|---------|---------|---------|---------|
| **加工方法** | 机械加工工艺 | 装夹→粗加工→精加工→检测 | 切削参数、进给量、精度等级 |
| **装配方法** | 产品装配工艺 | 零件准备→预装配→总装→调试 | 装配顺序、配合参数、拧紧力矩 |
| **控制方法** | 设备控制策略 | 信号采集→数据处理→控制输出→反馈调节 | 采样频率、控制参数、响应时间 |
| **检测方法** | 质量检测流程 | 标定→测量→数据处理→判定 | 测量精度、检测条件、判定标准 |

### 0.14 实用新型专利的完整撰写规范（《专利法》§2、《实施细则》§20-§23、《审查指南》第一部分第二章）

机械领域是实用新型专利最集中的领域。实用新型专利与发明专利在**说明书结构、实施例要求、权利要求类型、有益效果表述**等方面存在重大差异，必须严格区分。

#### 0.14.1 实用新型与发明的核心区别

| 维度 | 发明专利 | 实用新型专利 |
|------|---------|------------|
| 保护客体 | 产品、方法 | **仅产品**（形状、构造或其结合） |
| 创造性要求 | 突出的实质性特点+显著进步 | 实质性特点+进步（标准更低） |
| 保护期限 | 20年（申请日起） | 10年（申请日起） |
| 审查制度 | 实质审查 | **仅形式审查+初步审查** |
| 方法特征 | ✓ 允许 | ✗ 不允许 |
| 材料特征 | ✓ 允许 | ✗ 不允许（材料替换不是实用新型客体） |
| 无固定形状 | ✓ 允许 | ✗ 不允许（如流体、粉末） |
| 附图 | 可选 | **必须有**（实用新型定义决定） |

#### 0.14.2 实用新型说明书结构（5部分）

实用新型专利说明书严格按照以下5部分撰写（《实施细则》§20）：

| 序号 | 标准名称 | 注意事项 |
|:---:|---------|---------|
| 1 | **技术领域** | 与发明专利相同 |
| 2 | **背景技术** | 与发明专利相同，引用现有技术并指出缺陷 |
| 3 | **实用新型内容** | ⚠️ 标题为"实用新型内容"，**不是**"发明内容" |
| 4 | **附图说明** | 实用新型**必须有附图** |
| 5 | **具体实施方式** | 简化版，详见 §0.14.4 |

#### 0.14.3 实用新型内容的撰写要求

**与发明专利"发明内容"的关键差异**：

| 项目 | 发明专利 | 实用新型专利 |
|------|---------|------------|
| 标题 | "发明内容" | **"实用新型内容"** |
| 技术问题 | 针对背景技术缺陷提出 | 相同 |
| 技术方案 | 宽泛结构方案+参数范围 | 相同，但聚焦**产品结构特征** |
| 有益效果数量 | 3-5条 | **3-5条**（定性为主） |
| 有益效果深度 | 可量化，可声称"预料不到的技术效果" | **定性说明即可**，不要求量化数据 |
| 有益效果措辞 | "显著提升""有效降低"等 | 相同，但**不要求与对照实施例对应** |
| 结尾段 | 标准结尾段 | 相同 |

**实用新型有益效果撰写原则**：
- 以**定性描述**为主，说明结构改进带来的效果即可
- **不需要**通过对照实施例或性能测试数据来量化证明
- **不需要**声称"预料不到的技术效果"（实用新型创造性标准更低，无需此论证）
- 每条效果应与技术方案中的结构特征相对应，但不需要数据支撑
- ⭐ **协同效应设计**（§0.14.7）：有益效果中应至少有1条描述**各结构特征之间的协同关系**——说明特征组合如何产生超出各自单独使用的效果，以支持"非简单叠加"的争辩（§3.0C.5）

**实用新型内容首句标准句式**：
"本实用新型旨在克服上述背景技术中存在的不足，特别是解决[核心技术缺陷]的问题，提供一种[实用新型名称]。"

**实用新型内容次句标准句式**：
"为实现上述目的，本实用新型采用的技术方案是：通过[核心结构手段1]、结合[核心结构手段2]，从而实现[主要技术效果]。"

#### 0.14.4 实用新型具体实施方式的简化要求

**与发明专利具体实施方式的关键差异**：

| 项目 | 发明专利 | 实用新型专利 |
|------|---------|------------|
| 整体结构概述 | ✓ 必须有 | ✓ 必须有 |
| 部件描述（五要素法） | ✓ 必须有 | ✓ 必须有 |
| 工作流程描述 | ✓ 必须有 | ✓ 必须有 |
| 实施例数量 | 1核心 + 2-3参数变化 | **1核心 + 2-3变型** |
| 对照实施例 | 可选（🟡风险方案需要） | **✗ 不需要** |
| 性能测试数据表格 | 可选（🟡风险方案可补充） | **✗ 不需要** |
| 技术效果说明 | 可量化或定性 | **定性说明即可** |

**实用新型具体实施方式的标准结构**：
```
一、整体结构概述（引用附图，说明核心组成和工作原理）
二、部件描述（五要素法：名称编号/结构特征/连接关系/配合方式/功能作用）
三、工作流程描述（从启动到完成的完整运行过程）
四、实施例（1个核心实施例 + 2-3个变型实施例，说明参数变化和技术效果）
```

> ⚠️ **实用新型具体实施方式不需要**：对照实施例、性能测试数据表格、"预料不到的技术效果"论证。这些是发明专利的审查要求，不适用于实用新型。

#### 0.14.5 实用新型权利要求书的撰写要求

**核心原则**：以**产品结构特征**为主线撰写，仅包含产品权利要求。

| 项目 | 发明专利 | 实用新型专利 |
|------|---------|------------|
| 权利要求类型 | 产品权利要求 + 方法权利要求 | **仅产品权利要求** |
| 独立权利要求数量 | 2-3项（产品+方法+用途） | **1项**（产品） |
| 从属权利要求数量 | 5-10项 | **5-8项** |
| 总数量 | 10-15项 | **6-10项** |
| 限定方式 | 结构特征+方法步骤+参数 | **仅结构特征+参数** |

**实用新型权利要求书标准结构**：
```
独立权利要求1：产品权利要求（装置/机构/设备）
  ├─ 从属权利要求2：进一步限定核心结构特征
  ├─ 从属权利要求3：进一步限定传动/配合参数
  ├─ 从属权利要求4：进一步限定连接方式
  ├─ 从属权利要求5：进一步限定材料/工艺（仅作为结构的一部分）
  └─ 从属权利要求6-8：进一步限定辅助结构特征
```

#### 0.14.7 实用新型创造性判断标准（《审查指南》第四部分第六章 §4）

> **法律依据**：《专利法》§22第三款——实用新型的创造性是指与现有技术相比具有**实质性特点和进步**（发明专利要求"突出的实质性特点和显著的进步"）。

实用新型创造性判断同样采用"三步法"，逻辑框架与发明专利完全一致，但在以下三个方面标准更低、范围更窄：

**差异一：创造性高度要求不同**

| 维度 | 发明专利 | 实用新型专利 |
|------|---------|------------|
| 法定标准 | 突出的实质性特点 + 显著的进步 | **实质性特点 + 进步** |
| 区别 | 多了"突出的"和"显著的"两个限定词 | 标准更低 |
| 实务影响 | 需要更强的非显而易见性论证 | 一般的结构组合改进即可满足 |

**差异二：技术领域范围不同（核心差异）**

技术启示的判断（三步法第三步）中，可考虑的现有技术领域范围不同：

| 对比维度 | 发明专利 | 实用新型专利 |
|---------|---------|------------|
| 可考虑的技术领域 | 所属领域、相近/相关领域、甚至其他领域 | **一般仅考虑所属技术领域** |
| 扩大领域的前提 | 只要技术问题能促使去寻找即可 | **需现有技术给出明确启示**，才可考虑相近或相关技术领域 |
| 实务含义 | 审查员可跨领域找技术启示 | 审查员一般不能跨领域找技术启示来否定创造性 |

> 这意味着：实用新型创造性争辩时，若审查员引用了**相近/相关技术领域**的对比文件来否定创造性，可以争辩"现有技术未给出明确启示促使到该领域寻找技术手段"。

**差异三：现有技术数量不同**

| 对比维度 | 发明专利 | 实用新型专利 |
|---------|---------|------------|
| 可引用的现有技术数量 | 一项、两项或多项 | **一般一项或两项** |
| 例外情况 | — | 由"**简单叠加**"而成的，可引用多项 |

> 这意味着：实用新型创造性争辩时，若审查员引用了**三篇及以上**对比文件来否定创造性，可以争辩"本实用新型并非简单叠加，各特征间存在功能上的相互支持/协同关系"。

**"简单叠加"的判定标准**：
- 各技术特征之间**无功能上的相互支持**、**无协同作用**、各自独立发挥作用 → 属于简单叠加 → 可引用多篇现有技术
- 各技术特征之间**有功能上的相互支持**、**产生协同效应** → 不属于简单叠加 → 一般仅可引用1-2篇现有技术

**实用新型创造性预评估的实务要点**：
1. **聚焦所属技术领域**：检索 D2/D3 时优先在本技术领域内检索，跨领域检索仅作为补充参考
2. **控制对比文件数量**：一般仅考虑1-2篇现有技术的组合，评估是否存在技术启示
3. **强调非简单叠加**：在实用新型内容中有意设计特征间的协同关系，并在具体实施方式中说明协同效应
4. **争辩策略预设**：①所属技术领域内无技术启示；②非简单叠加（特征间有协同）；③结构组合产生了"进步"效果

### 0.15 TRIZ创新方法论——技术方案创造性提升工具集

> **定位说明**：本节引入TRIZ（发明问题解决理论）作为技术方案创造性提升的核心工具集。TRIZ理论通过系统化的创新方法论，帮助突破常规思维定式，生成具有新颖性和创造性的技术方案。本节的方法论将贯穿"第一步B：TRIZ辅助创新分析"（§3.0T）和后续方案设计全过程。
>
> **与专利法的关系**：TRIZ生成的创新方案仍须通过§3.0A新颖性预评估和§3.0B/§3.0C创造性预评估的法律验证。TRIZ是"产生创造性方案的源泉"，预评估是"验证方案是否满足专利法要求的标准"。两者串行：TRIZ先产生方案→预评估后验证方案。
>
> **核心解决的问题**：机械领域专利常因"常规结构组合、无协同效应、技术特征各自独立"而被审查员以"显而易见"驳回。TRIZ通过系统化的矛盾分析与创新原理应用，从根源上提升方案的创造性高度。

#### 0.15.1 TRIZ功能分析

**功能分析**是TRIZ的起点，通过识别系统中的关键功能部件、其功能目标及相互作用关系，建立功能模型。

**机械领域功能分析框架**：

| 分析维度 | 分析内容 | 机械领域示例 |
|---------|---------|------------|
| 功能部件识别 | 系统中执行有用功能的部件 | 电机（驱动）、齿轮组（传动）、轴承（支撑）、导轨（导向） |
| 功能目标 | 每个部件要实现的功能目标 | 电机→提供动力；齿轮组→减速增扭；轴承→减少摩擦 |
| 相互作用 | 部件间的功能联系（支持/阻碍/中性） | 齿轮组依赖轴承支撑→支持；齿轮啮合产生振动→阻碍 |
| 有害功能识别 | 产生负面效果的部件或相互作用 | 摩擦发热、振动传递、磨损碎屑 |
| 功能不足/过度 | 功能执行不充分或过度 | 传动精度不足、间隙过大、预紧力过度 |

**功能分析输出**：功能模型表（部件→功能→作用对象→功能类型[有用/有害]→功能水平[正常/不足/过度]）

**有害功能和功能不足是创新机会点**——通过消除有害功能或弥补功能不足来产生创新方案。

#### 0.15.2 因果链分析

**因果链分析**从表面技术问题出发，逐层追溯根因，识别真正需要解决的关键问题。

**因果链分析流程**：
```
表面问题（如"折叠机构操作繁琐"）
  → 为什么？ → 第一层原因（如"需要逐个折叠每个机臂"）
  → 为什么？ → 第二层原因（如"各机臂之间缺乏联动机制"）
  → 为什么？ → 第三层原因（如"现有设计未集成同步驱动结构"）
  → 为什么？ → 根因（如"缺少一个能将单点驱动转化为多点同步运动的传动核心"）
```

**关键原则**：
- 每层追溯必须回答"为什么会导致上一层问题"
- 因果链至少追溯3-5层
- 识别"关键缺点"——因果链中可以通过结构创新消除的环节
- 根因分析的结果将作为矛盾求解和方案创新的输入

#### 0.15.3 技术矛盾与物理矛盾

**技术矛盾**：系统中两个参数之间的冲突——改善参数A导致恶化参数B。

**机械领域常见技术矛盾**：

| 改善参数 | 恶化参数 | 矛盾描述 | TRIZ发明原理方向 |
|---------|---------|---------|----------------|
| 刚性↑ | 重量↑ | 提高刚性需要增加材料，但增加重量 | #27廉价替代、#40复合材料 |
| 精度↑ | 成本↑ | 提高精度需要更精密加工，但增加成本 | #1分割、#28机械系统替代 |
| 响应速度↑ | 稳定性↓ | 快速响应需要减小惯量，但降低稳定性 | #15动态化、#19周期性作用 |
| 强度↑ | 空间↑ | 提高强度需要增大截面，但占用空间 | #17另一维度、#35参数变化 |
| 密封性↑ | 拆装性↓ | 提高密封需要更紧配合，但影响拆装 | #1分割、#2抽取 |
| 同步性↑ | 复杂性↑ | 提高同步性需要更多联动机构，但增加复杂度 | #5组合、#20有效作用的连续性 |

**物理矛盾**：系统对同一参数有相互矛盾的需求——既需要A又需要非A。

**机械领域常见物理矛盾**：

| 物理矛盾 | 矛盾需求 | 分离原理方向 |
|---------|---------|------------|
| 既要刚性又要柔性 | 定位时需要刚性锁定，运动时需要柔性释放 | 时间分离（不同工作阶段） |
| 既要固定又要可调 | 工作时需要固定，调试时需要可调 | 条件分离（不同工作条件） |
| 既要密封又要通风 | 储存时需要密封，工作时需要通风 | 空间分离（不同位置） |
| 既要轻量化又要高强度 | 便携需要轻，承载需要强 | 整体与部分分离（关键部位加强） |

**分离原理**：
1. **空间分离**：矛盾的需求在不同空间位置实现
2. **时间分离**：矛盾的需求在不同时间段实现
3. **条件分离**：矛盾的需求在不同条件下实现
4. **整体与部分分离**：整体具有一种特性，部分具有相反特性

#### 0.15.4 TRIZ发明原理（机械领域适配精选）

从40个发明原理中精选机械领域最常用的15个，并给出机械适配示例：

| 原理编号 | 原理名称 | 机械领域应用方向 | 示例 |
|:---:|---------|---------|------|
| #1 | 分割 | 将整体分解为独立部分 | 整体齿轮→分体式齿轮（便于更换磨损部分） |
| #2 | 抽取 | 移除有害部分或提取有用部分 | 移除独立锁定机构→将锁定功能集成到驱动件 |
| #3 | 局部质量 | 在特定位置改变材料/结构特性 | 在应力集中处局部增加壁厚或使用高强度材料 |
| #5 | 组合 | 将相同或相似操作合并 | 多个独立折叠操作→一个同步折叠机构 |
| #10 | 预先作用 | 提前执行有用功能或预置应急手段 | 弹簧预紧→到位后自动锁定（无需额外操作） |
| #15 | 动态化 | 使刚性结构变为柔性/可动 | 固定支撑→弹性支撑（适应热膨胀和振动） |
| #17 | 另一维度 | 将直线运动转为旋转或使用第三维度 | 平面凸轮→空间凸轮（利用第三维度实现复合运动） |
| #19 | 周期性作用 | 连续作用改为脉冲/周期作用 | 持续润滑→定时脉冲润滑（减少润滑剂消耗） |

| #35 | 参数变化 | 改变物理状态或参数 | 常规配合→热胀冷缩配合（利用温度变化实现过盈/间隙转换） |
| #40 | 复合材料 | 用组合材料替代单一材料 | 单一金属→金属-橡胶复合件（兼顾强度和减振） |

#### 0.15.5 剪裁与特性传递

**剪裁**：移除系统中的某个部件，将其有用功能转移到其他部件或系统。

**剪裁规则**：
1. 如果被剪裁部件的有用功能由系统中的其他部件执行 → 可剪裁
2. 如果被剪裁部件的有用功能由超系统执行 → 可剪裁
3. 如果被剪裁部件的有用功能不再需要 → 可剪裁

**剪裁在机械专利中的应用**：
- 移除独立锁定机构 → 锁定功能集成到驱动凸轮盘（减少零件数量）
- 移除独立密封件 → 密封功能由配合面自身的过盈配合实现
- 移除独立传感器 → 检测功能由电机电流变化间接反映

**特性传递**：将另一个系统的优势特性转移到当前系统。

**特性传递在机械专利中的应用**：
- 将航空领域的轻量化蜂窝结构特性转移到民用机械外壳
- 将医疗领域的精密微动传动特性转移到工业机器人关节
- 将消费电子领域的磁吸连接特性转移到工业快速拆装机构

#### 0.15.6 跨领域技术移植

**跨领域技术移植**：将A领域的成熟技术原理移植到B领域，解决B领域的技术问题。

**移植原则**：
1. 识别源领域的技术原理（非简单照搬结构，而是提取原理）
2. 分析目标领域的适配约束（工况、环境、成本、标准）
3. 进行适配性改造（保留核心原理，调整实现方式）

**机械领域跨领域移植案例**：

| 源领域 | 源技术原理 | 目标领域 | 适配改造 |
|-------|---------|---------|---------|
| 生物领域 | 关节韧带的弹性储能原理 | 机械传动 | 弹性储能元件用于传动间隙补偿 |
| 航空航天 | 折叠展开机构原理 | 消费无人机 | 轻量化同步折叠机构 |
| 光学领域 | 凸轮轨迹的精密控制原理 | 机械定位 | 阿基米德螺线凸轮实现等速同步 |
| 磁悬浮领域 | 无接触悬浮原理 | 精密导向 | 磁悬浮导轨消除接触摩擦 |
| 仿生领域 | 变色龙舌部的弹射机构原理 | 快速夹持 | 储能释放式快速夹持机构 |

#### 0.15.7 常规技术突破法

**核心思想**：在常规技术认知中，存在"X会导致Y劣化"的技术偏见。通过引入辅助手段Z，不仅允许X的存在，反而利用X实现意想不到的协同效应。

**机械领域适配示例**：

| 常规认知（技术偏见） | 突破方案（引入Z） | 协同效应 |
|-------------------|----------------|---------|
| 高刚性结构会导致冲击载荷传递加剧，应避免过度刚性 | 引入弹性耦合件Z，允许高刚性结构存在 | 高刚性保证定位精度+弹性耦合件吸收冲击→刚性结构与弹性件协同实现"精确定位+冲击隔离" |
| 增加配合精度会导致装配困难，应控制精度等级 | 引入热胀冷缩辅助装配工艺Z | 高精度配合保证运行精度+温差装配降低装配难度→高精度与可装配性兼得 |
| 增加同步联动机构会增加系统复杂度和故障率 | 引入集成式凸轮盘Z，将驱动和锁定功能合一 | 同步联动提升操作效率+功能集成减少零件数量→同步性与简洁性兼得 |

#### 0.15.8 常规认知突破法

**核心思想**：某部件A在常规认知中一直用于实现功能X，但在本申请中，A被用于实现完全不同的功能Y——跨越了人们对其本质效果的认知。

**机械领域适配示例**：

| 部件A | 常规功能认知（功能X） | 突破应用（功能Y） | 认知跨越说明 |
|-------|-------------------|-----------------|------------|
| 弹簧 | 储能/复位/缓冲 | 精密力矩传递 | 弹簧的弹性变形被用于传递恒定力矩（而非储能或复位） |
| 凸轮 | 运动轨迹转换 | 同步锁定触发 | 凸轮的轮廓曲线被用于在特定角度触发锁定（而非运动转换） |
| 轴承 | 减少摩擦/支撑旋转 | 精密角度分度 | 轴承的滚动体排列被用于实现等分角度定位（而非减少摩擦） |
| 密封圈 | 密封防漏 | 振动阻尼 | 密封圈的弹性体被用于吸收振动（而非密封） |
| 螺栓 | 紧固连接 | 精密调距 | 螺栓的螺纹微动被用于实现微米级间距调节（而非紧固） |

#### 0.15.9 部件协同创新法

**核心思想**：组合使用部件A和部件B，其目的不在于同时获得A和B各自的技术功能，而在于获得一种全新的技术功能C——A和B在功能上彼此相互支持，产生了超越各自功能的新效果。

**机械领域适配示例**：

| 部件A | 部件B | A的常规功能 | B的常规功能 | 全新功能C（协同效果） |
|-------|-------|---------|---------|-----------------|
| 弹簧 | 凸轮 | 储能复位 | 运动转换 | 同步锁定（弹簧驱动凸轮到位后自动锁定，非储能也非运动转换） |
| 磁铁 | 导轨 | 磁力吸附 | 直线导向 | 无接触悬浮导向（磁力与导向协同实现悬浮导向，非吸附也非普通导向） |
| 热胀材料 | 螺栓 | 热膨胀密封 | 紧固连接 | 温度自适应预紧（热胀材料驱动螺栓微动，实现预紧力自动补偿） |
| 齿条 | 弹性件 | 直线传动 | 弹性缓冲 | 间隙自适应补偿传动（弹性件驱动齿条微动补偿啮合间隙） |

#### 0.15.10 非简单叠加效果设计（1+1>2）

**核心思想**：在同一技术效果方面，两个（或多个）技术特征的组合取得了1+1大于2的预料不到的效果——量化效果不等同于简单叠加，而是高于叠加之和。

**机械领域适配判断标准**：

| 判断维度 | 简单叠加（1+1=2） | 非简单叠加（1+1>2） |
|---------|:---:|:---:|
| 功能关系 | 各自独立发挥作用 | 相互支持、产生耦合效应 |
| 效果可加性 | A+B效果 = A单独效果 + B单独效果 | A+B效果 > A单独效果 + B单独效果 |
| 替换影响 | 替换任一特征不影响其他特征 | 替换任一特征影响整体功能 |
| 作用机制 | 无相互作用 | 存在物理/力学/运动学耦合 |

**设计方法**：
1. 识别两个技术特征各自的常规效果
2. 设计两者之间的耦合机制（结构耦合、力学耦合、运动学耦合、热学耦合）
3. 论证耦合效应如何产生超出加和的效果
4. 在具体实施方式中通过定性或定量方式证明"1+1>2"

> ⚠️ **与§3.0C.5简单叠加判定的关系**：本节的"非简单叠加效果设计"是主动的设计方法，§3.0C.5是被动的事后判定。在方案设计阶段就应有意识地设计特征间的协同关系，为后续创造性争辩预设基础。

#### 0.15.11 D1对标创新法

**核心思想**：检索最接近的现有技术D1，对D1的核心结构做"增减/替换/重构"，或突破D1的工艺/参数边界，或跨领域移植技术原理。

**四种D1对标创新路径**：

| 创新路径 | 操作方法 | 机械领域示例 |
|---------|---------|------------|
| **结构创新** | 对D1核心结构做增减/替换/重构 | D1用单一齿轮传动→设计"行星齿轮+柔性齿圈"复合传动 |
| **工艺/参数创新** | 突破D1的工艺边界，设计非常规参数组合 | D1常温装配→设计"温差装配+预紧力补偿"复合工艺 |
| **跨领域技术移植** | 将其他领域成熟技术原理移植到本领域 | 将生物领域"弹性储能释放"原理移植到机械快速夹持 |
| **功能集成创新** | 将D1中分离的多个功能集成到一个部件 | D1分离式驱动+锁定→集成式凸轮盘（驱动与锁定合一） |

#### 0.15.12 成熟技术非简单应用法

**核心思想**：应用某耳熟能详的技术手段或其组合，其目的不在于发挥该技术的固有技术功能，而在于解决依托于特定场景固有存在的技术问题。

**判断标准**：
- 使用了成熟技术手段（非新发明）
- 但应用目的与技术手段的固有功能不同
- 解决的是特定场景下固有的技术问题

**机械领域适配示例**：

| 成熟技术手段 | 固有功能 | 非简单应用目的 | 解决的场景问题 |
|------------|---------|-------------|-------------|
| 弹簧预紧 | 提供持续压力 | 利用预紧力的变化检测到位状态 | 折叠到位检测（到位时预紧力突变→触发锁定） |
| 螺纹连接 | 紧固可拆卸 | 利用螺纹的微动特性实现精密调距 | 间隙补偿（螺纹微动补偿磨损间隙） |
| 磁力吸附 | 固定/吸附 | 利用磁力变化实现位置反馈 | 非接触式到位检测（磁通量变化反映位置） |
| 热胀冷缩 | 密封/配合 | 利用温差实现自动预紧力调节 | 温度自适应预紧（高温时松开补偿热膨胀） |
| 齿轮啮合 | 传动/减速 | 利用啮合间隙的变化实现过载保护 | 机械式过载保护（过载时齿面滑移脱离啮合） |

> ⚠️ **重要约束**：
> - 禁止在输出的内容中出现数学计算公式或物理上定义的公式
> - 禁止出现"智能体""博弈"相关方案
> - 所有TRIZ分析结果须以结构化文本输出，不得使用公式表达技术效果

## 二、工作流程

### 2.1 发明专利工作流程（13步法）

```
第零步：确认专利类型 ⭐
  ├─ 与用户确认申请类型：发明专利 or 实用新型专利
  ├─ 判断依据：核心创新是"结构改进"→可申请实用新型或发明；核心创新是"方法/工艺"→只能发明
  └─ 输出：专利类型确认（本节为发明专利流程；若为实用新型，转 §2.2）

第一步：需求收集与技术转译
  ├─ 收集用户原始需求（如"提高机械传动效率"）
  ├─ 技术转译（将功能需求转化为具体结构/参数问题）
  └─ 输出：转译后的技术问题 + 可测指标清单

第一步B：TRIZ辅助创新分析 ⭐（§3.0T）——v4.0新增，v4.1强化
  ├─ 1B-0：⭐前置专利检索（§3.0T.1B）——v4.1新增：按核心技术问题+核心机制类型检索已有专利
  ├─ 1B-a：功能模块分类分析（系统工程+模块化设计，§3.0T.2）
  ├─ 1B-b：TRIZ功能分析（识别有用功能/有害功能/功能不足，§3.0T.3）
  ├─ 1B-c：因果链分析（逐层追溯根因，识别关键缺点，§3.0T.4）
  ├─ 1B-d：矛盾识别（技术矛盾+物理矛盾，§3.0T.5）
  ├─ 1B-e：创新方案生成（7大路径，受前置检索约束，§3.0T.6）
  ├─ 1B-f：候选方案评估与排序（含⭐专利可行性快检，§3.0T.7）
  └─ 输出：TRIZ创新分析报告（含前置检索结果+推荐方案1-3个，§3.0T.8）

第二步：初步技术方案设计 ⭐（基于TRIZ分析结果）
  ├─ 基于TRIZ推荐方案，设计核心创新架构
  ├─ 确定四大维度：核心结构/传动机构 / 控制系统 / 材料与工艺 / 关键参数
  └─ 输出：初步技术方案（含核心结构、传动方式、控制系统、工艺路线）

第三步A：新颖性预评估 ⭐（§3.0A）——v4.1新增维度5核心机制检索
  ├─ 3A-a：技术特征分解（A/B/C/D四层次）
  ├─ 3A-b：逐特征多维度检索（单独对比原则，含⭐维度5核心机制检索）
  ├─ 3A-c：特征-现有技术映射表（标注每个特征的公开状态）
  ├─ 3A-d：新颖性风险评分（🔴高/🟡中/🟢低）
  ├─ 3A-e：判定
  │   ├─ 🟢 低风险 → 进入第三步B
  │   ├─ 🟡 中风险 → 标注风险点，进入第三步B
  │   └─ 🔴 高风险 → ⭐v4.1：携带阻断性现有技术清单返回第一步B TRIZ重新分析（最多3轮）
  └─ 输出：新颖性预评估报告

第三步B：创造性预评估（§3.0B）
  ├─ 3B-a：确定最接近的现有技术 D1（三步法第一步）
  ├─ 3B-b：确定区别特征 + 发明实际解决的技术问题（三步法第二步）
  ├─ 3B-c：对每个区别特征，检索潜在的 D2/D3（其他现有技术）
  ├─ 3B-d：技术启示分析矩阵（三步法第三步——这是创造性判断的核心）
  │   ├─ 对每对(D1, D2/D3)分析：相同技术领域？相同作用？存在组合动机？
  │   └─ 依据 §0.10 三种技术启示类型逐项排查
  ├─ 3B-e：组合发明分析（各特征是否在功能上彼此支持？是否有超出加和的协同效应？）
  ├─ 3B-f：创造性风险结论 + 争辩策略预判
  │   ├─ 🟢 低风险（无技术启示或组合非显而易见）→ 进入第四步
  │   ├─ 🟡 中风险（个别特征有启示但组合可能非显而易见）→ 进入第四步，强化创造性论证
  │   └─ 🔴 高风险（D2/D3给出明确技术启示）→ 返回第二步，针对薄弱点重新设计
  └─ 输出：创造性预评估报告（含 D1 文献、技术启示矩阵、组合发明分析、争辩策略）

第四步：技术领域定界
  ├─ 确定宏观技术领域（如：机械传动）
  ├─ 确定具体技术方向（如：精密齿轮传动装置）
  └─ 输出：技术领域段落（150-200字，4句法）

第五步：专利检索（正式检索，用于背景技术）
  ├─ API检索优先 + WebSearch回退（§3.10）
  ├─ 与第三步预评估检索不同——本次检索覆盖更广，用于背景技术撰写
  └─ 输出：检索结果摘要（含最接近的现有技术文档列表）

第六步：背景技术撰写
  ├─ 选择1-2项最接近的现有技术作为比较对象
  ├─ 采用"虽然…但是…"结构剖析缺陷（至少3项技术缺陷）
  └─ 输出：背景技术段落（含技术空白总结）

第七步：发明内容撰写
  ├─ 首句标准句式：直击背景技术缺陷
  ├─ 次句标准句式：概括核心创新手段
  ├─ 宽泛技术方案（结构+参数范围），满足 §0.4 合理性约束
  ├─ 选择权利要求类型（§0.5）
  └─ 输出：发明内容段落 + 有益效果（3-5条）

第八步：附图说明撰写
  ├─ 分析发明内容中的结构特征，确定附图数量（5-6个）
  ├─ 描述每个附图的结构组成、连接关系和工作原理
  └─ 输出：附图说明 + 附图标记列表

第九步：具体实施方式撰写
  ├─ 整体结构概述
  ├─ 按附图顺序详细描述各部件结构、连接关系和工作过程
  ├─ 实施例设计（1个核心实施例 + 2-3个参数变化实施例）
  ├─ 对照实施例（可选：仅🟡风险方案需要，证明区别特征效果）
  └─ 输出：具体实施方式完整章节

第十步：权利要求书撰写
  ├─ 独立权利要求1：产品权利要求（基于发明内容中的宽泛方案）
  ├─ 功能性限定审查（§0.12 强制流程）
  ├─ 独立权利要求2：方法权利要求（如适用）
  ├─ 从属权利要求（纵深防御体系）
  └─ 输出：完整的权利要求书（10-15项）

第十一步：说明书摘要撰写
  ├─ 从说明书+权利要求书精简
  ├─ 含发明名称、技术领域、技术问题、技术方案要点、主要用途
  └─ 输出：150-300字摘要（一段式）

第十二步：质量自检
  └─ 对照"质量自检清单"A-M组逐项检查

第十三步：生成 DOCX 专利申请材料（§3.11）
  ├─ 加载 docx 技能（Skill 工具，command="docx"）
  ├─ 编写 docx-js 生成脚本（按 §3.11.3 排版规范 + §3.11.5 代码模板）
  ├─ 执行脚本生成 .docx 文件
  ├─ 验证文件（validate.py）
  └─ 输出：[发明名称]-专利申请材料.docx
```

## 三、各模块详细方法论

### 3.0T：TRIZ辅助创新分析与方案生成

> **定位说明**：本模块在需求收集与技术转译（第一步）之后、初步技术方案设计（第二步）之前执行，运用§0.15的TRIZ方法论，对技术问题进行系统化的创新分析，生成具有新颖性和创造性的技术方案候选集。本模块是解决"专利创造性不足、授权率低"问题的核心模块。
>
> **与预评估的关系**：§3.0T生成创新方案 → §3.0A验证新颖性 → §3.0B/§3.0C验证创造性。TRIZ是方案的"源泉"，预评估是方案的"验证器"。

#### 3.0T.1 TRIZ分析在整体流程中的位置

```
需求收集与技术转译（第一步）
  ↓
⭐§3.0T TRIZ辅助创新分析⭐（第一步B）
  ├─ ⭐前置专利检索（§3.0T.1B）⭐——v4.1新增
  ├─ 功能模块分类分析
  ├─ TRIZ功能分析
  ├─ 因果链分析
  ├─ 矛盾识别与求解
  ├─ 创新方案生成（7大路径，受前置检索约束）
  └─ 候选方案评估与排序（含专利可行性快检）
  ↓
初步技术方案设计（第二步，基于TRIZ分析结果）
  ↓
§3.0A 新颖性预评估（含核心机制检索维度） → §3.0B/§3.0C 创造性预评估（含公知常识判定+审查员视角模拟） → 正式撰写
```

#### 3.0T.1B 前置专利检索（v4.1新增）⭐

> **定位说明**：在TRIZ 7大路径生成创新方案之前，必须先执行前置专利检索——识别解决相同核心技术问题的已有专利方案。这些已有方案将作为"创新约束条件"输入到7大路径中，确保生成的方案与已有方案有实质性区别。
>
> **为什么需要前置检索**：TRIZ理论擅长生成"理论上合理"的创新方案，但如果不先了解已有专利布局，极易生成已被公开的方案（例如：TRIZ可能建议用"阿基米德螺旋槽实现同步驱动"，但该方案可能已被某篇专利公开）。前置检索的作用是在方案生成前就划定"已有方案边界"，让TRIZ在边界之外寻找创新空间。

**前置检索三维度**：

| 检索维度 | 检索目的 | 查询构造方法 | 示例 |
|---------|---------|------------|------|
| **维度1：核心技术问题检索** | 谁在解决相同的技术问题？ | 提取核心技术问题关键词，不限产品类型 | "多臂同步折叠 机构"（不限无人机/机器人/天线） |
| **维度2：核心机制类型检索** ⭐关键 | 相同机械原理是否已被用于其他产品？ | 提取TRIZ功能分析中识别的核心功能原理 | "阿基米德螺旋槽 同步驱动"、"凸轮槽 多臂联动"、"螺旋槽 同步展开" |
| **维度3：跨领域同功能检索** | 其他领域是否用类似机制解决类似问题？ | 按功能动词+作用对象检索 | "同步展开 收纳 机构"、"旋转运动转化为多个同步折叠运动" |

**检索执行要求**：
- 每个维度至少执行2次搜索（中文+英文）
- 检索工具优先级：WebSearch（多角度组合）→ PQAI语义检索（如可用）→ CNIPR/EPO
- **必须记录每篇高相关专利的：专利号、标题、核心技术方案摘要、与本方案的重叠特征**
- 检索结果形成"已有方案约束清单"，输入到§3.0T.6的7大路径生成中

**已有方案约束清单格式**：

| 序号 | 专利号 | 标题 | 核心技术方案 | 与本方案重叠特征 | 差异特征 | 约束等级 |
|:---:|------|------|------------|---------------|---------|:---:|
| 1 | CNXXXXXXXA | [标题] | [2-3句核心技术方案] | [列出重叠的结构/功能特征] | [列出差异] | 🔴强约束/🟡弱约束 |

**约束等级判定**：
- 🔴 **强约束**：已有专利公开了本方案拟采用的核心驱动/传动机制 → TRIZ 7大路径必须避开该机制或在该机制基础上做实质性改进
- 🟡 **弱约束**：已有专利公开了部分特征但核心机制不同 → TRIZ 7大路径应注意差异化设计

> ⚠️ **强制规则**：如果前置检索发现某篇专利的"核心驱动/传动机制"与本方案拟采用的完全相同，则该专利在后续§3.0A新颖性预评估中将自动成为D1候选——TRIZ必须生成与该专利有实质性区别的替代方案或改进方案。**不得在已知存在强约束专利的情况下，仍然生成与该专利高度相似的方案。**

#### 3.0T.2 第一步：功能模块分类分析

运用系统工程方法论和模块化设计原理，对技术方案进行结构化功能模块分类。

**分析框架**：

| 模块类型 | 功能描述 | 机械领域典型模块 | 生命周期阶段 |
|---------|---------|---------------|------------|
| 驱动模块 | 提供动力源 | 电机、气缸、手动操作件 | 全生命周期 |
| 传动模块 | 传递和转换运动 | 齿轮组、连杆、凸轮、同步带 | 全生命周期 |
| 执行模块 | 实现最终功能动作 | 夹爪、定位销、折叠臂 | 使用阶段 |
| 锁定模块 | 维持稳定状态 | 锁紧销、卡扣、棘爪 | 使用阶段 |
| 导向模块 | 约束运动方向 | 导轨、滑槽、导向销 | 使用阶段 |
| 支撑模块 | 承载和固定 | 机架、底座、轴承座 | 全生命周期 |
| 保护模块 | 安全防护 | 限位件、过载保护、防护罩 | 使用阶段 |
| 调节模块 | 参数调整 | 调节螺钉、偏心件、补偿件 | 维护阶段 |

**输出格式**：功能模块分类表（模块名称→功能→部件组成→生命周期阶段→优先级）

**模块推荐性判断**：根据产品生命周期阶段，对每个模块给出优先级建议：
- **高优先级**：核心创新模块（驱动/传动/执行/锁定），直接影响创造性高度
- **中优先级**：辅助功能模块（导向/调节），可增加从属权利要求层次
- **低优先级**：通用支撑模块（支撑/保护），通常为公知技术

#### 3.0T.3 第二步：TRIZ功能分析

对每个功能模块进行TRIZ功能分析，识别有用功能、有害功能、功能不足/过度。

**功能分析表**：

| 功能部件 | 作用对象 | 功能类型 | 功能描述 | 功能水平 |
|---------|---------|:---:|---------|:---:|
| [部件A] | [对象] | 有用 | [功能描述] | 正常/不足/过度 |
| [部件B] | [对象] | 有害 | [负面效果] | — |
| [部件C] | [对象] | 有用 | [功能描述] | 正常/不足/过度 |

**有害功能和功能不足是创新机会点**——通过消除有害功能或弥补功能不足来产生创新方案。

#### 3.0T.4 第三步：因果链分析

从表面技术问题出发，逐层追溯根因，识别关键缺点。

**因果链分析模板**：

```
表面问题：[用户描述的技术问题]
  → 为什么？ → 第一层原因：[直接原因]
  → 为什么？ → 第二层原因：[更深层原因]
  → 为什么？ → 第三层原因：[更深层原因]
  → 为什么？ → 根因：[可通过结构创新消除的关键缺点]

关键缺点标记：
  ⭐ [可在专利中解决的关键缺点] → 进入矛盾求解
  ✓ [已通过现有技术解决的缺点] → 不需要处理
  ✗ [无法通过结构创新解决的缺点] → 不处理
```

#### 3.0T.5 第四步：矛盾识别

基于因果链分析中的关键缺点，识别技术矛盾和物理矛盾。

**矛盾识别表**：

| 矛盾类型 | 改善参数 | 恶化参数 | 矛盾描述 | 适用发明原理 |
|---------|---------|---------|---------|------------|
| 技术矛盾 | [参数A] | [参数B] | [改善A导致B恶化] | #X, #Y, #Z |
| 物理矛盾 | [参数C] | — | [既需要C又需要非C] | 分离原理类型 |

#### 3.0T.6 第五步：创新方案生成（7大路径）⭐核心

基于矛盾分析和§0.15的方法论，从7个路径生成创新方案候选。

**路径1：TRIZ发明原理求解**

对每个技术矛盾，从§0.15.4的发明原理表中选取适用的原理，生成方案。

| 矛盾 | 适用原理 | 方案描述 |
|------|---------|---------|
| [矛盾描述] | #[原理编号] [原理名称] | [具体方案：如何应用该原理解决矛盾] |

**路径2：分离原理求解**

对每个物理矛盾，选用空间/时间/条件/整体与部分分离原理。

| 物理矛盾 | 分离原理 | 方案描述 |
|---------|---------|---------|
| [矛盾描述] | [分离类型] | [如何在不同空间/时间/条件下实现矛盾需求] |

**路径3：跨领域技术移植（§0.15.6）**

| 源领域 | 源技术原理 | 移植到本方案的方式 | 适配改造 |
|-------|---------|----------------|---------|

**评估维度**：

| 评估维度 | 评分标准 | 权重 |
|---------|---------|:---:|
| 新颖性潜力 | 该方案在现有技术中被公开的可能性（低→高分），结合专利可行性快检结果 | 30% |
| 创造性高度 | 该方案对本领域技术人员的非显而易见性（高→高分），重点考察与最接近现有技术的差异是否属于"常规设计选择" | 30% |
| 可实施性 | 该方案在工程上可实现的程度（高→高分） | 20% |
| 效果显著性 | 该方案带来的技术效果改善程度（显著→高分） | 20% |

**排序原则**：
- 综合评分最高的1-3个方案作为推荐方案
- 推荐方案将作为"第二步：初步技术方案设计"的输入
- 评分较低的方案作为备选（预评估不通过时回退使用）

### 3.0A：新颖性预评估与方案迭代

> **定位说明**：本模块在正式撰写之前，对初步技术方案进行系统性的**新颖性**预评估——基于《审查指南》的"单独对比"原则（§0.9），逐特征检索是否有单一现有技术公开了该特征。只有通过新颖性预评估的方案，才能进入 §3.0B 的创造性预评估。
>
> **与 §3.0B/§3.0C 的关系**：§3.0A（新颖性）和 §3.0B/§3.0C（创造性）是两个串行执行的独立阶段。§3.0A 回答"每个结构特征是否已被单独公开？"（二元判断），§3.0B/§3.0C 回答"D2/D3是否给出了将区别特征应用于D1的技术启示？"（程度判断）。发明专利进入§3.0B（完整版），实用新型专利进入§3.0C（简化版）。

#### 3.0A.1 预评估在整体流程中的位置

```
需求收集 → [初步方案设计] → ⭐§3.0A 新颖性预评估⭐ → [通过] → ⭐§3.0B/§3.0C 创造性预评估⭐ → [通过] → 技术领域 → …… → 撰写
                                    ↓                                              ↓
                               [不通过] → 方案重设计                      [不通过] → 方案重设计
                                              （发明：§3.0B完整版，最多3轮；实用新型：§3.0C简化版，最多2轮）
```

**迭代规则**：
- 每个方案最多经过 3 轮预评估（第1轮：初始方案；第2-3轮：重新设计方案）
- 第3轮后若仍为🔴高风险，终止预评估循环，向用户展示完整的特征映射表和建议方向
- 每次迭代必须保留完整的预评估记录（形成"方案演化轨迹"）

#### 3.0A.2 预评估六步法

**第一步：技术特征分解（四层次法）**

将初步技术方案分解为四个层次的技术特征。每个层次的特征将独立进行检索评估。

| 层次 | 名称 | 包含内容 | 示例（精密齿轮传动案例） |
|:---:|------|------|------|
| **A层** | 核心结构+传动机构 | 核心结构是什么？传动方式如何？部件如何连接配合？ | A1=新型渐开线修形齿形, A2=滚珠丝杠副, A3=A1+A2组合传动链 |
| **B层** | 控制系统 | 控制方式、传感器、执行器、反馈策略等 | B1=伺服电机驱动, B2=PID闭环控制, B3=光栅尺位置反馈 |
| **C层** | 材料与工艺 | 材料选择、加工工艺、装配方式、热处理等 | C1=20CrMnTi合金钢, C2=渗碳淬火磨齿, C3=过盈配合装配 |
| **D层** | 关键参数 | 尺寸、公差、配合精度、传动比、性能指标等 | D1=模数2.0-3.0, D2=压力角20°, D3=传动比1:5-1:10 |

**分解原则**：
- A层是新颖性/创造性的主力战场——至少1个A层特征必须具有🟢状态
- 如果A层全部为🔴或🟡，则必须返回第二步重新设计方案
- B层的创新（如控制系统改进）可以作为创造性辅助论点，但不能单独支撑创造性
- C层和D层通常为🟡或🔴，只要其中1-2个参数存在与现有技术的实质性差异即可加分
- **机械领域特殊注意**：A层特征须分解到"部件+连接关系+配合方式"的粒度，不能停留在"有齿轮"这种粗粒度

**第二步：多维度语义检索**

对每个层次的每个特征，执行多维度的语义检索。本模块优先使用语义检索工具（PQA），不可用时以WebSearch回退。

**检索渠道优先级**：

```
第一优先：PQAI 语义检索（projectpq.ai / search.projectpq.ai）
  ├─ 优势：自然语言输入，ML模型基于专利审查记录训练，语义匹配精度高
  ├─ 输入：用自然语言描述技术特征，而非关键词
  └─ 限制：需网络访问，免费使用，覆盖US/EP/WO/CN等主要专利局

第二优先：CNIPR / EPO OPS / PATENTSCOPE API（§3.10）
  ├─ 优势：结构化数据，支持精确检索
  └─ 限制：需注册获取API密钥

回退方案：WebSearch（多角度组合检索）
  ├─ 对每个特征，至少3个角度的搜索
  └─ 中文+英文双语言覆盖
```

**检索维度设计**（对每个特征，至少5个检索维度）：

| 检索维度 | 目的 | 查询示例（以A3"修形齿形+滚珠丝杠"为例） |
|---------|------|------|
| 维度1：特征本身 | 是否有文献公开了该特征 | "渐开线修形齿形 滚珠丝杠 传动装置" |
| 维度2：特征+产品类型 | 该特征在目标产品中的应用 | "精密齿轮传动 滚珠丝杠 伺服系统" |
| 维度3：特征+技术问题 | 该特征是否被用来解决相同问题 | "高精度齿轮传动 噪音降低 滚珠丝杠" |
| 维度4：完整组合 | 多个特征的组合是否已公开 | "修形齿形 滚珠丝杠 伺服电机 精密传动" |
| ⭐维度5：核心机制检索（v4.1新增） | 相同机械原理是否已被用于其他产品类型 | "螺旋槽 同步驱动 多臂联动"、"凸轮槽 旋转运动转化为同步运动" |

> ⚠️ **v4.1核心机制检索说明**：维度5是v4.1新增的关键检索维度。很多专利驳回发生在"核心驱动/传动机制已被另一篇不同产品类型的专利公开"的情况——例如"阿基米德螺旋槽驱动多臂同步折叠"可能已被一篇无人机旋翼收纳专利公开，也可能被一篇天线展开机构或太阳能板展开机构的专利公开。维度5的要求是：**提取方案的核心机械原理（而非产品名称），跨产品类型检索是否已有相同原理的专利**。这一维度必须覆盖§3.0T.1B前置检索中识别的所有强约束专利，并进一步扩展搜索范围。

**检索执行要求**：
- 必须使用至少2个检索渠道（第一个失败时用备选）
- 每个特征的检索结果必须记录（搜索查询 + 命中文献 + 相关性判断）
- 如果维度4命中高相关文献（技术方案高度相似），标记为"🔴 核心组合已被公开"

|---------|------|:---:|

**第四步：新颖性风险评估**

| 风险等级 | 判定标准 | 行动 |
|:---:|------|------|
| 🔴 **高** | A层核心组合（A3）被单一现有技术公开，或至少2个A层特征分别被公开且组合显而易见 | **必须返回第二步重新设计** |
| 🟡 **中** | A层个别特征已知但组合未见公开，B层/D层存在已知特征；可依赖"预料不到的技术效果"争辩创造性 | **可以进入撰写，但须标注所有风险点并在有益效果中重点强化创造性论证** |
| 🟢 **低** | A层至少1个特征（核心结构或传动机构）未被公开，且A3组合整体未见公开 | **可以进入撰写** |

**第五步：创造性论点预判**

当新颖性通过（🟢或🟡）但创造性可能被质疑时，预判可用的创造性争辩论点：

**可用的创造性论点类型**：

| 论点类型 | 说明 | 证据要求 |
|---------|------|---------|
| **预料不到的技术效果** | 区别特征产生了超出合理预期的效果 | 必须在具体实施方式中通过对照实施例量化证明 |
| **技术偏见克服** | 本领域普遍认为某方案不可行，但本发明证明可行 | 需引用本领域的技术偏见文献 |
| **长期悬而未决的技术需求** | 该技术问题长期存在但无人解决 | 需说明问题存在的时间跨度和尝试历史 |
| **商业成功** | 产品在市场上取得了成功 | 需证明成功归因于技术特征而非营销 |

**⚠️ 创造性论点使用限制**：
- "预料不到的技术效果"是最常用且最有力的论点——每个方案至少应有一个可预判的此类效果
- 如果所有区别特征的效果都是"可预期的"（线性等效替换），则创造性非常薄弱
- "要素组合发明"（多个已知结构要素的组合）的创造性判断标准更高——必须有超出各要素效果之和的协同效应

**第六步：判定与迭代**

```
评估结论为 🟢 或 🟡
  → 记录预评估报告（含特征映射表+风险评分+创造性论点预判）
  → 进入第四步（技术领域撰写）
  
评估结论为 🔴
  → 记录预评估报告（含驳回理由）
  → ⭐v4.1：记录"阻断性现有技术清单"（专利号+核心机制+重叠特征）
  → 执行"方案重新设计"策略（见 §3.0A.3）
  → ⭐v4.1：返回§3.0T TRIZ分析，携带阻断性现有技术清单作为约束条件
  → 新一轮TRIZ必须生成与阻断性专利有实质性区别的方案（非简单调整）
  → 返回第二步，基于重新设计的方案再次预评估
  → 迭代次数+1（最多3轮）
```

> ⚠️ **v4.1迭代闭环强化**：当预评估判定为🔴高风险时，不能仅返回"第二步（方案设计）"做简单调整——必须返回"第一步B（TRIZ分析）"，携带阻断性现有技术清单，重新执行TRIZ 7大路径生成。新一轮TRIZ分析中：
> - §3.0T.1B前置检索的"已有方案约束清单"必须包含阻断性专利
> - §3.0T.6的7大路径必须明确标注与阻断性专利的差异
> - 如果阻断性专利公开了核心驱动机制，新一轮方案必须采用**不同的驱动/传动机制**，而非仅在锁定/辅助结构上做改进
> - 简单的"换一种锁定方式"或"调整部件位置"不构成实质性差异化——审查员会认定为常规设计选择

#### 3.0A.3 方案重新设计策略（当预评估发现高风险时）

当预评估判定为🔴高风险时，使用以下策略重新设计方案：

**策略一：改变核心传动机构（推荐优先尝试）**

原理：传动机构是A层中最容易替换而不影响整体产品定位的维度。

| 原传动机构 | 备选方案 | 区别机制 |
|-----------|---------|---------|
| 齿轮传动 | 谐波传动 | 柔性齿轮变形传动，传动比大，精度高，无回程间隙 |
| 齿轮传动 | RV摆线针轮传动 | 摆线轮与针齿啮合，抗冲击能力强，精度保持性好 |
| 滚珠丝杠 | 静压丝杠 | 油膜支撑，摩擦极低，精度保持性好 |
| 滚珠丝杠 | 磁悬浮丝杠 | 磁力驱动无机械接触，零磨损 |
| 皮带传动 | 同步带传动 | 齿形啮合，无滑动，传动比精确 |
| 蜗杆传动 | 行星齿轮传动 | 多齿啮合，承载能力大，效率高 |
| 链条传动 | 齿形链传动 | 啮合传动，噪声低，寿命长 |
| 直接驱动 | 直线电机 | 电磁力直接驱动，无中间传动环节，响应快 |

**策略二：增加新的结构创新点**

引入一个与核心结构产生"非显而易见的协同效应"的新特征。

- 协同效应不能是简单的"轴承+轴承=更好支撑"
- 必须是跨类别的协同（如"结构优化+控制算法=更高精度"，而非"更好的结构"）
- 必须有合理的机械原理解释（应力分布、运动学关系、动力学特性等）

**策略三：改变核心技术问题**

将技术问题从"已被解决"的方向调整为"尚未被充分解决"的子方向。

- 例："解决传动效率问题"→已有大量研究 → **改为**→"解决高速传动下的振动抑制问题"
- 子方向应在背景技术中描述为"长期被忽视的技术盲区"

**策略四：改变控制系统架构**

- 开环控制 → 闭环控制 → 自适应控制 → 智能控制
- 单一传感器 → 多传感器融合 → 视觉辅助定位
- 固定参数控制 → 变参数控制 → 自学习控制

**策略五：寻找"意料不到的协同效应"作为核心创新点**

当传动机构和结构都难以改变时，聚焦于发现两个（多个）已知结构之间的"意料不到的协同效应"。

- 这种协同效应必须在具体实施方式中通过对照实施例量化证明
- 必须说明"为什么本领域技术人员无法预期这种协同效应"

#### 3.0A.5 精密齿轮传动案例：新颖性预评估复盘

以下用精密齿轮传动方案，展示预评估如何避免高风险方案被提交。

**原始方案**：渐开线修形齿形 + 滚珠丝杠副 + 伺服电机PID闭环控制 + 20CrMnTi渗碳淬火磨齿 → 精密传动装置

**如果执行了预评估**：

| 特征 | 检索结果 | 风险 |
|------|---------|:---:|
| 修形齿形+滚珠丝杠 | "高精度齿轮-滚珠丝杠传动系统"专利已公开类似组合 | 🔴 |
| 20CrMnTi渗碳淬火磨齿 | "高精度齿轮磨齿工艺"专利已公开 | 🔴 |
| 伺服+PID+光栅尺 | 均为精密传动领域已知方案 | 🟡 |
| 模数2.0-3.0 | 通用齿轮参数范围 | 🟡 |

**结论**：🔴高风险 → 不应进入撰写 → 重新设计

**可能的重新设计方案**（策略一+策略三）：
- 改变传动机构：齿轮+滚珠丝杠 → **谐波减速器+直线电机**（谐波减速器无回程间隙，直线电机无中间传动环节，与所有齿轮-丝杠方案有本质区别）
- 改变技术问题方向：从"传动精度"→"高速响应下的振动抑制"
- 谐波减速器的柔轮变形特性与直线电机的直接驱动特性产生新的减振机制

这样重新设计后，A层核心组合变为"**谐波减速器+直线电机直驱**"，与所有齿轮-丝杠方案有本质区别，预评估风险有望降到🟢或🟡。

### 3.0B：创造性预评估（三步法 + 多文档技术启示分析）

> **定位说明**：本模块在新颖性预评估（§3.0A）通过后，对技术方案进行系统性的**创造性**（非显而易见性）预评估——严格执行《审查指南》第二部分第四章 §3.2.1.1 的"三步法"判断流程，重点分析多篇现有技术是否给出了将区别特征组合起来的技术启示。
>
> **为什么审查员会用"组合对比"驳回**：新颖性使用"单独对比"（一项权利要求 vs 一份现有技术），创造性使用"组合对比"（可用多份现有技术的不同技术内容组合评价）。审查员最常见的驳回逻辑是：D1（最接近现有技术）+ D2（公开区别特征 X）= 本发明显而易见。

#### 3.0B.1 创造性预评估在整体流程中的位置

```
§3.0A 新颖性预评估 → [通过🟢/🟡] → ⭐§3.0B 创造性预评估⭐ → [通过🟢/🟡] → 正式撰写
                                          ↓
                                     [不通过🔴] → 返回第二步，针对创造性薄弱点重新设计方案（最多3轮）
```

**与 §3.0A 的关键区别**：

| 维度 | §3.0A 新颖性评估 | §3.0B 创造性评估 |
|------|:---:|:---:|
| 法律原则 | 单独对比（§0.9） | 组合对比（§0.10） |
| 核心问题 | 结构特征X在单篇文献中是否被公开？ | D2/D3是否给出将区别特征应用于D1的技术启示？ |
| 检索目标 | 找"相同公开" | 找"相同作用 + 组合动机" |
| 失败后果 | 方案不可用（已被公开） | 方案不可用（显而易见） |

#### 3.0B.2 第一步：确定最接近的现有技术 D1

> 法律依据：《审查指南》第二部分第四章 §3.2.1.1(1)

从 §3.0A 的检索结果中，选择一项作为最接近的现有技术（D1）。

**选择优先级**（按序判定）：

| 优先级 | 判定条件 | 示例 |
|:---:|------|------|
| 1 | 技术领域相同 + 技术问题/效果/用途最接近 + 公开技术特征最多 | 同样是精密齿轮传动装置，采用滚珠丝杠 |
| 2 | 技术领域相同 + 公开技术特征最多 | 同为传动装置，含齿轮和丝杠结构 |
| 3 | 技术领域不同但能实现发明功能 + 公开技术特征最多 | 机器人关节中采用了类似传动方案 |

**输出格式**：

```
D1 候选文献列表（按优先级排序）：

优先级1：[文献标识] — [关键内容摘要]
  ├─ 技术领域：[与本发明的关系]
  ├─ 公开的技术特征：[列出与本发明重叠的特征]
  └─ 未公开的技术特征：[本发明的核心区别]

优先级2：……

最终选定 D1：[文献标识]
  理由：[为什么它是最接近的现有技术]
```

#### 3.0B.3 第二步：确定区别特征和发明实际解决的技术问题

> 法律依据：《审查指南》第二部分第四章 §3.2.1.1(2)

**操作步骤**：

**2a — 列出区别特征**：将发明与 D1 对比，列出 D1 未公开的所有技术特征。

```
区别特征清单：
├─ 区别A：[特征描述] — D1中对应的是[D1特征/或D1未提及]
├─ 区别B：[特征描述] — D1中对应的是[D1特征/或D1未提及]
└─ 区别C：[特征描述] — D1中对应的是[D1特征/或D1未提及]
```

**2b — 重新确定发明实际解决的技术问题**：根据区别特征在发明中所达到的技术效果反推。

```
基于区别特征重新确定的技术问题：
├─ 原说明书描述的技术问题：[从需求转译的问题]
├─ 基于D1重新确定的问题：[根据区别特征的效果反推]
└─ 说明：[为什么重新确定的问题不同于/同于原始问题]
```

**⚠️ 关键注意**：重新确定的技术问题不是原始需求（如"提高传动精度"），而是**从 D1 出发要改进什么**（如"如何在不增加结构复杂度的前提下消除回程间隙"）。

#### 3.0B.4 第三步（前段）：对每个区别特征检索 D2/D3

> 这一步是技术启示分析的前置步骤——为每个区别特征寻找可能构成技术启示的 D2/D3。

**检索策略**：对每个区别特征，检索**公开了该特征、且特征在对比文件中的"作用"与在发明中的"作用"相同或类似的文献**。

| 区别特征 | 检索查询 | D2/D3 候选 | 该特征在D2/D3中的作用 | 该特征在发明中的作用 | 作用是否相同？ |
|------|---------|------|------|------|:---:|
| 区别A | 查询A1, A2... | D2-A: [文献] | [D2中作用] | [发明中作用] | 是/否/类似 |
| 区别B | 查询B1, B2... | D2-B: [文献] | [D2中作用] | [发明中作用] | 是/否/类似 |
| 区别C | 查询C1, C2... | — | — | [发明中作用] | 无相关D2 |

**检索要求**：
- 使用至少2个检索渠道（PQAI语义检索优先，WebSearch回退）
- 中文+英文双语言覆盖
- 重点关注**作用（技术功能）**的相似性——不只看表面特征名称，更要看该特征在对比文件中发挥了什么功能

#### 3.0B.5 第三步（主体）：技术启示分析矩阵 ⭐核心

> 法律依据：《审查指南》第二部分第四章 §3.2.1.1(3)，§0.10 三种技术启示类型

这是创造性判断的核心——逐一检查每个区别特征是否在现有技术中存在"技术启示"。

**技术启示判定规则**：存在以下任一种情况 → 该区别特征存在技术启示 → 该区别特征对本领域技术人员是显而易见的。

**每对(D1, D2/D3)的技术启示分析**：

```
区别特征A — 技术启示分析：

D2候选：[文献标识]
├─ 类型判定：属于 §0.10 三种技术启示中的哪一种？
│   ├─ (i) 公知常识？→ D2是教科书/工具书/本领域惯用手段？
│   ├─ (ii) 同一文件其他部分？→ D2和D1是同一份文件？
│   └─ (iii) 另一份对比文件？→ D2是独立文件？← 最常见情况
│
├─ 技术领域分析：
│   ├─ D2的技术领域：[领域描述]
│   ├─ 发明的技术领域：[领域描述]
│   └─ 判定：相同/相近/不同 → [分析是否有跨领域转用的动机]
│
├─ 作用分析（最关键判断）：
│   ├─ 区别特征在D2中解决的技术问题：[D2中的问题]
│   ├─ 区别特征在D2中达到的技术效果：[D2中的效果]
│   ├─ 区别特征在发明中解决的技术问题：[发明中的问题]
│   ├─ 区别特征在发明中达到的技术效果：[发明中的效果]
│   └─ 判定：相同/类似/不同 → [若相同或类似 → 存在技术启示]
│
├─ 结合动机分析：
│   ├─ D2是否明确或暗示将区别特征用于D1的技术领域？
│   ├─ D1面临的技术问题是否自然引导本领域技术人员寻找D2的方案？
│   ├─ D1和D2的结合是否存在技术障碍？
│   └─ 判定：存在明确动机/存在暗示动机/无动机 → [详细理由]
│
└─ 结论：该区别特征是否存在技术启示？
    ├─ ✅ 存在 → 该区别特征显而易见 → [原因引用]
    └─ ❌ 不存在 → 该区别特征非显而易见 → [原因引用]
```

**如果所有区别特征都存在技术启示 → 发明整体是显而易见的 → 🔴 高风险，不具备创造性。**

**如果至少一个区别特征不存在技术启示 → 需进一步分析组合发明的创造性（§3.0B.7）。**

#### 3.0B.6 谐波减速器+直线电机案例：技术启示分析示例

以下用重新设计后的方案，展示技术启示分析的完整过程：

**发明方案**：谐波减速器（柔轮变形传动）+ 直线电机直接驱动 + 自适应振动抑制控制 → 高速精密传动装置

**D1（最接近现有技术）**：CN10XXXXXXA 精密齿轮-滚珠丝杠传动装置
- 含渐开线齿轮 + 滚珠丝杠 + 伺服电机PID控制
- 未公开谐波减速器、未公开直线电机、未公开自适应振动抑制

**区别特征A**：谐波减速器替代齿轮传动（柔轮变形传动，无回程间隙）

```
D2候选：CN10YYYYYYA（工业机器人用谐波减速器专利）
├─ 类型：§0.10 (iii) —— 另一份对比文件
├─ 技术领域：D2=工业机器人关节，发明=精密传动装置
│  └─ 判定：相近领域（均为精密传动），存在转用动机
├─ 作用分析：
│   ├─ D2中作用：实现机器人关节的高精度减速，消除回程间隙
│   ├─ 发明中作用：实现精密传动装置的高精度减速，消除回程间隙
│   └─ 判定：作用相同！均用于"高精度减速+消除回程间隙"
├─ 结合动机：
│   ├─ 谐波减速器在精密传动领域已是公知部件
│   ├─ D1面临"回程间隙影响精度"的问题，本领域技术人员有动机寻找无间隙方案
│   └─ 判定：存在明确动机
└─ 结论：✅ 存在技术启示。谐波减速器替代齿轮传动对本领域技术人员是显而易见的
```

**区别特征B**：直线电机直接驱动（无中间传动环节）

```
D2候选：CN10ZZZZZZA（半导体设备直线电机定位平台专利）
├─ 类型：§0.10 (iii) —— 另一份对比文件
├─ 技术领域：D2=半导体定位设备，发明=精密传动装置
│  └─ 判定：相近领域（均为精密定位/传动）
├─ 作用分析：
│   ├─ D2中作用：实现半导体晶圆的高精度直线定位，无中间传动误差
│   ├─ 发明中作用：实现传动装置的直线驱动，消除丝杠传动误差
│   └─ 判定：作用类似！均用于"高精度直线驱动+消除传动误差"
├─ 结合动机：
│   ├─ 直线电机在精密定位领域已是公知技术
│   ├─ 但D1是旋转传动装置，D2是直线定位平台，将直线电机用于旋转传动装置的直线输出端需要重新设计
│   └─ 判定：存在一定暗示，但结合需要创造性劳动（旋转→直线的转换设计）
└─ 结论：🟡 中等风险。直线电机本身已知，但与谐波减速器的集成设计需要创造性
```

**区别特征C**：自适应振动抑制控制（根据振动信号实时调整控制参数）

```
D2候选：未找到公开"谐波减速器+直线电机+自适应振动抑制"组合的文献
├─ 类型：无直接对应D2
├─ 作用分析：
│   ├─ 自适应振动控制在通用控制领域已知
│   ├─ 但针对"谐波减速器柔轮变形+直线电机直驱"这一特定组合的振动特性进行自适应控制，未见公开
│   └─ 判定：组合特征的作用在现有技术中未被公开
└─ 结论：❌ 不存在技术启示。针对特定结构组合的自适应振动抑制是非显而易见的
```

**整体技术启示结论**：
- 区别A（谐波减速器）：✅ 存在技术启示（相近领域，作用相同）
- 区别B（直线电机）：🟡 存在部分启示但集成需创造性
- 区别C（自适应振动抑制）：❌ 不存在技术启示（特定组合的自适应控制未被公开）
- 关键争辩点：区别C是核心创新——谐波减速器的柔轮变形特性与直线电机的直接驱动特性产生特殊的耦合振动模态，针对该模态的自适应控制是非显而易见的

#### 3.0B.7 第四步：组合发明分析

> 法律依据：《审查指南》第二部分第四章 §4.2——组合发明的创造性

即使每个区别特征单独来看可能已知，但若特征间存在**功能上的相互支持**且产生**超出各部分效果之和的协同效应**，则组合可能具备创造性。

**组合分析框架**：

```
组合发明分析：

┌─────────────────────────────────────────────────────┐
│ 特征A（谐波减速器） + 特征B（直线电机） + 特征C（自适应控制） │
├─────────────────────────────────────────────────────┤
│ 问题1：A、B、C在功能上是否彼此支持？                    │
│   ├─ A的柔轮变形特性是否与B的直接驱动特性产生耦合？       │
│   ├─ C的自适应控制是否针对A+B的特定振动模态？            │
│   └─ 回答：[是/否，机制说明]                            │
│                                                         │
│ 问题2：A+B+C的效果是否 > A单独 + B单独 + C单独？         │
│   ├─ 仅用A（无直线电机+无自适应控制）：效果值？           │
│   ├─ 仅用B（无谐波减速器+无自适应控制）：效果值？         │
│   ├─ A+B（无自适应控制）：效果值？                       │
│   ├─ A+B+C组合效果：效果值？                            │
│   └─ 协同系数：(A+B+C) / (A+B无控制) = ?               │
│                                                         │
│ 问题3：特征间是"简单叠加"还是"相互作用"？                │
│   ├─ A、B、C是否各自以常规方式工作？                     │
│   ├─ 总效果是否等于各部分效果之和？                      │
│   └─ 回答：[叠加/相互作用，证据]                         │
│                                                         │
│ 结论：🟢非显而易见组合 / 🟡边界情况 / 🔴显而易见          │
└─────────────────────────────────────────────────────┘
```

**对审查员反馈的应用**：
- 谐波减速器的柔轮变形 + 直线电机的直接驱动 → 产生特殊的耦合振动模态（各特征单独使用时不存在）
- 自适应振动抑制控制 → 针对该特定耦合模态进行实时抑制（非通用控制算法）
- 这种"结构耦合→特定振动→针对性控制"的链条是各特征单独使用时不存在的——构成了功能上的相互支持
- 在对照实施例中应设置"仅用谐波减速器（无直线电机+无自适应控制）"和"谐波减速器+直线电机（无自适应控制）"两个对照组来量化证明协同效应

#### 3.0B.8 第五步：创造性风险结论

| 风险等级 | 判定标准 | 行动 |
|:---:|------|------|
| 🔴 **高** | 所有区别特征均存在技术启示（§0.10 (i)/(ii)/(iii)），且组合为简单叠加（无协同效应） | **必须返回第二步重新设计** |
| 🟡 **中** | 部分区别特征存在技术启示，但至少一个关键特征的技术启示不成立，或组合可能非显而易见 | **可以进入撰写，但必须：①有益效果中围绕"非显而易见组合"展开至少2条论证；②具体实施方式中设置"最接近现有技术方案"对照实施例；③量化证明协同效应** |
| 🟢 **低** | 关键区别特征无技术启示，或组合的非显而易见性有明确证据支撑 | **可以进入撰写** |

#### 3.0B.9 第六步：创造性争辩策略预判

当创造性为🟡时，预判可用的争辩策略：

| 策略 | 适用场景 | 证据要求 |
|------|---------|---------|
| **作用不同** | D2公开了相同特征但作用/功能不同 | 需详细对比D2中的作用描述与发明中的作用描述 |
| **跨领域无动机** | D2的技术领域与D1/发明不同，不存在转用动机 | 需论证技术领域的距离和转用的技术障碍 |
| **组合非显而易见** | 特征间存在功能上的相互支持，不是简单叠加 | 需对照实施例量化"单独效果和" vs "组合效果"的差异 |
| **预料不到的技术效果** | A+B+C的效果远超A单独+B单独+C单独的预期 | 需对照实施例数据证明量级差异（非线性增长） |
| **克服技术偏见** | 本领域普遍认为某方向不可行 | 需引用技术偏见文献 |
| **长期悬而未决** | 该问题长期存在但现有方案均未解决 | 需说明时间跨度和尝试历史 |

**每一份🟡风险方案至少预判2个可用的争辩策略。**

#### 3.0B.10 第七步（如适用）：针对创造性薄弱点的方案重设计

当创造性预评估结论为🔴时，重新设计应**针对技术启示分析中的薄弱点**：

| 技术启示薄弱点 | 重设计方向 |
|-------------|----------|
| D2公开了区别特征A且作用相同 | 改变特征A的实现方式（如换传动机构、换控制策略），使新旧方案的作用机制不同 |
| D1和D2的技术领域相同/相近 | 引入跨领域的技术特征（如航空航天的轻量化结构用于民用机械），使组合的跨领域性质构成创造性 |
| 组合效果 = 各部分之和 | 寻找特征间的相互作用机制（结构耦合、动力学耦合、机电耦合等），证明功能上彼此支持 |
| 区别特征仅为公知常识的替换 | 引入非公知的新结构或非显而易见的新参数组合 |
| D2明确建议将特征A用于D1 | 改变发明解决的技术问题方向（从已被D2暗示的方向改为D2未提及的方向） |

### 3.0C：实用新型创造性预评估（简化版）

> **定位说明**：本模块在实用新型专利的新颖性预评估（§3.0A）通过后，对技术方案进行**简化版创造性预评估**——采用与发明专利相同的"三步法"逻辑框架，但依据 §0.14.7 的三大差异（创造性高度更低、技术领域范围更窄、现有技术数量更少）进行适配。
>
> **与 §3.0B 的关系**：§3.0B 是发明专利的**完整版**创造性预评估（可跨领域检索、可引用多篇文献）；§3.0C 是实用新型专利的**简化版**（一般仅限所属技术领域、一般仅1-2篇文献）。两者的三步法逻辑完全一致，差异在第三步"技术启示判断"的适用范围。

#### 3.0C.1 实用新型创造性预评估在流程中的位置

```
§3.0A 新颖性预评估 → [通过🟢/🟡] → ⭐§3.0C 实用新型创造性预评估⭐ → [通过🟢/🟡] → 正式撰写
                                          ↓
                                     [不通过🔴] → 返回第二步，针对创造性薄弱点重新设计方案（最多2轮）
```

**与发明专利 §3.0B 的关键区别**：

| 维度 | §3.0B 发明创造性评估 | §3.0C 实用新型创造性评估 |
|------|:---:|:---:|
| 法定标准 | 突出的实质性特点+显著进步 | **实质性特点+进步**（标准更低） |

#### 3.0C.2 第一步：确定最接近的现有技术 D1

> 法律依据：《审查指南》第四部分第六章 §4.1——三步法第一步

从 §3.0A 的检索结果中，选择一项作为最接近的现有技术（D1）。**选择逻辑与 §3.0B.2 相同**，但更加强调技术领域的同一性。

**实用新型 D1 选择优先级**：

| 优先级 | 判定条件 | 说明 |
|:---:|------|------|
| 1 | **所属技术领域相同** + 技术问题/效果最接近 + 公开特征最多 | 最佳D1 |
| 2 | 所属技术领域相同 + 公开特征最多 | 次佳D1 |
| 3 | 相近技术领域 + 公开特征最多 | 仅作参考（实用新型一般不跨领域否定创造性） |

> ⚠️ **实用新型特别注意**：若 D1 来自相近/相关技术领域（非所属领域），在后续技术启示分析中需额外评估"现有技术是否给出了明确启示促使到该领域寻找技术手段"。若无明确启示，该 D1 的技术启示说服力较弱。

2. **重新确定实际解决的技术问题**：根据区别特征在实用新型中达到的技术效果反推

#### 3.0C.4 第三步（核心）：技术启示分析——受限技术领域 + 受限文献数量 ⭐

> 法律依据：《审查指南》第四部分第六章 §4.1——三步法第三步 + §0.14.7 三大差异

这是实用新型创造性判断的核心，与发明专利的关键差异集中在此步。

**实用新型技术启示分析的三重限定**：

**限定一：技术领域限定**

| 判定 | 处理方式 |
|------|---------|
| D2 来自**所属技术领域** | ✅ 正常分析技术启示 |
| D2 来自**相近/相关技术领域** | ⚠️ 需额外判断：现有技术中是否有**明确记载**促使本领域技术人员到该领域寻找技术手段？有→可引用；无→不可作为否定创造性的依据 |
| D2 来自**其他技术领域** | ❌ 一般不考虑（除非有极其明确的启示） |

**限定二：现有技术数量限定**

| 情况 | 可引用文献数量 |
|------|-------------|
| 一般情况 | **1-2篇**（D1 + D2） |
| 实用新型被认定为"简单叠加" | 可引用**多篇**（D1 + D2 + D3 + ...） |

**限定三：创造性高度限定**

| 维度 | 发明专利标准 | 实用新型标准 |
|------|------------|------------|
| 实质性特点 | "突出的"实质性特点 | "实质性特点"（一般结构改进即可） |
| 进步 | "显著的"进步 | "进步"（一般效果提升即可） |
| 论证强度 | 需要较强的非显而易见性论证 | 一般的结构组合改进即可满足 |

**每对(D1, D2)的技术启示分析**（简化版）：

```
│   ├─ 实用新型的技术领域：[领域描述]

│   └─ 判定：相同/类似/不同 → [若相同或类似 → 存在技术启示]
│
├─ 结合动机分析：
│   ├─ D2是否明确或暗示将区别特征用于D1的技术领域？
│   └─ 判定：存在明确动机/存在暗示动机/无动机
│
└─ 结论：该区别特征在所属技术领域内是否存在技术启示？
    ├─ ✅ 存在 → 该区别特征显而易见
    └─ ❌ 不存在 → 该区别特征非显而易见 → 实用新型具有实质性特点
```

#### 3.0C.4B 公知常识判定（v4.1新增）⭐

> **定位说明**：技术启示分析（§3.0C.4）回答的是"D2是否给出了将区别特征应用于D1的启示"。但审查员还有另一条否定创造性的路径——直接认定区别特征属于"本领域公知常识"或"常规设计选择"，不需要引用D2。本节对每个区别特征逐一进行公知常识判定，识别哪些区别特征可能被审查员认定为公知常识。

**为什么需要公知常识判定**：

审查意见中最常见的创造性否定逻辑是：
1. 确定D1（最接近现有技术）
2. 确定区别特征
3. 认定区别特征属于"本领域公知常识/常规设计选择"
4. 结论：在D1的基础上结合公知常识得到本方案是显而易见的

如果所有区别特征都被认定为公知常识，即使新颖性通过（D1未完全公开），创造性也会被否定。

**公知常识判定表**：

对每个区别特征，从以下5个维度判定是否属于公知常识：

| 区别特征 | 维度1：是否为本领域常用结构？ | 维度2：是否在多篇现有技术中出现？ | 维度3：是否属于功能性替代（换一种等效方式实现相同功能）？ | 维度4：是否属于位置/布局调整（将已知结构移到另一位置）？ | 维度5：是否属于参数/尺寸常规选择？ | 综合判定 |
|---------|:---:|:---:|:---:|:---:|:---:|:---:|
| 区别A | 是/否 | 是/否 | 是/否 | 是/否 | 是/否 | 🔴公知常识/🟡可能争议/🟢非公知常识 |
| 区别B | 是/否 | 是/否 | 是/否 | 是/否 | 是/否 | 🔴/🟡/🟢 |
| 区别C | 是/否 | 是/否 | 是/否 | 是/否 | 是/否 | 🔴/🟡/🟢 |

**判定标准**：

| 综合判定 | 条件 | 对创造性的影响 |
|:---:|------|------------|
| 🔴 **公知常识** | 5个维度中≥3个为"是" | 该区别特征不能单独支撑创造性 |
| 🟡 **可能争议** | 5个维度中2个为"是" | 该区别特征需配合其他特征或"预料不到的技术效果"争辩 |
| 🟢 **非公知常识** | 5个维度中≤1个为"是" | 该区别特征可独立支撑创造性 |

> ⚠️ **高风险场景**：如果所有区别特征的公知常识判定均为🔴，则即使新颖性通过，创造性也面临极高风险——审查员会认定"在D1的基础上结合本领域公知常识得到本方案是显而易见的"。此时必须返回TRIZ重新设计方案，寻找非公知常识的区别特征。

**常见的"公知常识陷阱"**（审查员常用的否定论据）：

| 陷阱类型 | 描述 | 示例 |
|---------|------|------|
| **功能性等效替换** | 用一种公知的等效结构替换D1中的结构 | "将锁紧杆替换为弹簧销定位"→弹簧销和锁紧杆都是公知锁定方式 |
| **功能集成化** | 将原本分离的功能合并到同一部件上 | "将锁定功能集成到凸轮盘上"→功能集成是机械设计常规追求 |
| **位置布局调整** | 将已知结构从位置A移到位置B | "将锁定销从独立支架移到凸轮盘下端面"→位置选择属常规设计 |
| **参数范围选择** | 选择常规的尺寸/角度/比例参数 | "螺旋槽升角5°-15°"→常规设计范围 |
| **简化设计** | 取消D1中的某个辅助结构 | "取消直线槽仅保留螺旋槽"→简化属常规优化方向 |

> 2. 公知常识判定（§3.0C.4B）中，至少1个区别特征判定为🟢非公知常识
> 3. 审查员视角模拟（§3.0C.4C）中，至少有1条反驳强度为"强"
>

#### 3.0C.5 "简单叠加"判定

> 法律依据：《审查指南》第四部分第六章 §4.1——若实用新型由现有技术"简单叠加"而成，可引用多篇现有技术。

**简单叠加判定标准**：

| 判定维度 | 简单叠加（可引用多篇） | 非简单叠加（一般仅1-2篇） |
|---------|:---:|:---:|
| 特征间功能关系 | **各自独立**发挥作用 | **相互支持**、产生协同 |
| 组合效果 | A+B+C = A单独+B单独+C单独（加和） | A+B+C > A单独+B单独+C单独（超加和） |
| 组合动机 | 各特征无关联、随意拼凑 | 各特征为解决同一技术问题而协同设计 |
| 替换影响 | 替换任一特征不影响其他特征 | 替换任一特征影响整体功能 |

**判定流程**：
```
步骤1：各区别特征之间是否存在功能上的相互支持？
  ├─ 是 → 可能非简单叠加 → 进入步骤2
  └─ 否 → 简单叠加 → 审查员可引用多篇现有技术

步骤2：特征组合是否产生超出加和的协同效应？
  ├─ 是 → 非简单叠加 → 审查员一般仅可引用1-2篇 → 创造性更有利
  └─ 否 → 简单叠加 → 审查员可引用多篇现有技术
```

> ⚠️ **撰写启示**：在实用新型内容（§3.6.2）和具体实施方式（§3.7）中，**应有意识地描述各结构特征之间的协同关系**，说明特征组合如何产生超出各自单独使用的效果。这有助于在后续可能的无效宣告程序中争辩"非简单叠加"。

#### 3.0C.6 实用新型创造性风险结论与争辩策略

**风险评分标准**（v4.1强化——加入公知常识判定和审查员视角模拟条件）：

| 风险等级 | 判定标准 | 处理方式 |
|:---:|---------|---------|
| 🟢 低风险 | 同时满足：①所属技术领域内无技术启示；②至少1个区别特征为🟢非公知常识；③至少1条反驳强度为"强" | 直接进入正式撰写 |
| 🟡 中风险 | 满足：①所属技术领域内无明确技术启示；但②所有区别特征为🟡可能争议（无🟢）；或③最强反驳仅为"中" | 进入撰写，但须在有益效果中重点强化创造性论证，且须预设审查意见答复策略 |
| 🔴 高风险 | 满足以下任一：①所属技术领域内有明确技术启示；或②所有区别特征均为🔴公知常识；或③所有反驳强度均为"弱" | **必须返回TRIZ重新设计方案**（携带阻断性现有技术清单，最多2轮） |

> ⚠️ **v4.1关键变化**：v4.0版🟢低风险仅要求"无技术启示+特征间有协同"——但审查员可以不引用D2，直接用"公知常识"否定创造性。v4.1版新增了公知常识判定（§3.0C.4B）和审查员视角模拟（§3.0C.4C）作为必要条件，确保方案不仅能抵抗"D1+D2组合"的否定，也能抵抗"D1+公知常识"的否定。

**实用新型创造性争辩策略**（按优先级排序，v4.1更新）：

| 策略 | 适用场景 | 争辩要点 | v4.1变化 |
|------|---------|---------|---------|
| **策略1：所属技术领域内无技术启示** | D2来自相近/相关领域 | "现有技术未给出明确启示促使到该领域寻找技术手段，不构成技术启示" | 不变 |
| **策略2：非简单叠加** | 审查员引用了3篇以上对比文件 | "各结构特征间存在功能上的相互支持，产生协同效应，非简单叠加，不应引用多篇现有技术" | 不变 |
| **策略3：结构组合产生进步** | 区别特征单独已知但组合非显而易见 | "虽然各特征单独已知，但特定组合方式产生了所属技术领域人员未曾预见的进步效果" | 不变 |
| **策略4：实际解决的技术问题不同** | D2中特征的作用与实用新型中不同 | "区别特征在D2中解决的技术问题与在本实用新型中不同，不构成技术启示" | 不变 |
| ⭐**策略5：非公知常识（v4.1新增）** | 审查员用"D1+公知常识"否定创造性 | "区别特征不属于本领域公知常识——[具体论证：该特征在现有技术中未被普遍使用/产生了预料不到的技术效果/克服了技术偏见]" | **v4.1新增** |
| ⭐**策略6：预料不到的技术效果（v4.1新增）** | 区别特征效果超出合理预期 | "区别特征产生了所属技术领域人员无法合理预期的技术效果——[具体效果描述+与常规方案的对比]" | **v4.1新增**：虽然实用新型标准更低，但当所有区别特征均面临公知常识风险时，"预料不到的技术效果"是最有力的最后防线 |

> v4.1更新说明：原v4.0版认为实用新型"不需要争辩预料不到的技术效果"——这在大多数情况下是正确的。但当审查员使用"D1+公知常识"路径否定创造性时（而非"D1+D2"路径），非简单叠加和技术启示争辩均无效，此时"预料不到的技术效果"成为唯一的反驳手段。因此v4.1将其作为补充策略保留。

### 3.1 发明名称

**命名规则**：
- 长度控制在 20-25 个汉字
- 不得包含：商标名、商品名、人名、"新型""高效""神奇"等宣传性词汇
- 不得包含括号（除非是该领域的标准命名方式）
- 推荐格式：`一种[核心特征]+[产品类型]` 或 `一种[核心特征]+[产品类型]+及其方法`

**注意**：发明名称中出现的关键词（核心结构、产品类型、功能属性）会直接影响后续的专利检索关键词选择，因此命名需慎重。名称应在预评估通过后最终确定——该名称也是**摘要（§3.9）的第一要素**和**权利要求性能限定的来源**。

### 3.1-补充：功能需求的技术转译

当用户提出的发明动机涉及功能描述时（如"提高传动效率""降低噪音""提高精度"等），必须在撰写前完成**技术转译**，将功能需求转化为具体的结构/参数问题。

**转译原则**：
1. 不要对抗用户——理解其产品意图，用结构语言重新表达
2. 转译后的表述必须可以在工程中通过测量或分析验证
3. 转译后的"技术问题"必须能与"技术效果"和"实施例"形成对应关系
4. 在背景技术和发明内容中统一使用转译后的表述

**常用转译对照**：

| 用户原始表述 | 技术转译（技术问题） | 可测指标 |
|------------|-------------------|---------|
| 提高传动效率 | 传动链中的摩擦损耗过大/回程间隙导致能量损失 | 传动效率、回程间隙、摩擦系数 |
| 降低噪音 | 齿轮啮合冲击/振动传递路径未隔离 | 噪音分贝值、振动加速度 |
| 提高精度 | 传动间隙/热变形/弹性变形导致定位误差 | 定位精度、重复定位精度、传动误差 |
| 提高可靠性 | 关键部件磨损/疲劳导致寿命下降 | 疲劳寿命、磨损量、MTBF |
| 轻量化 | 结构冗余材料/材料密度过大 | 质量、惯量、功率质量比 |
| 提高刚性 | 结构刚度不足导致变形 | 静刚度、动刚度、固有频率 |
| 减小体积 | 传动链布局冗余/部件集成度低 | 外形尺寸、体积比 |
| 提高响应速度 | 传动惯量过大/控制延迟 | 响应时间、带宽、加速度 |

### 3.2 技术领域

**固定四句结构**：

| 句序 | 功能 | 内容 | 字数参考 |
|:---:|-----|------|:---:|
| 第一句 | 宏观定位 | "本发明属于[宏观技术领域]技术领域" | 8-15字 |
| 第二句 | 具体指向 | "具体为[具体技术方向]领域中的[产品类型]" | 15-25字 |
| 第三句 | 问题引子 | 指出现有技术的主要缺陷和局限性（1-2个核心问题） | 40-70字 |
| 第四句 | 发明目标 | "本发明旨在解决上述问题，提供一种[核心特征]的[产品类型]" | 40-70字 |
| **合计** | | | **150-200字** |

**关键约束**：
- 第三句和第四句中不得出现任何模糊性表述
- 技术效果描述只能使用机械性能词汇：传动效率、精度、稳定性、可靠性、低噪音、轻量化、刚性、响应速度等
- 第四句中的"核心特征描述"必须与预评估通过的方案一致

### 3.3 背景技术

**撰写结构**：
```
段落一：行业背景铺垫
├─ 产品类型的基本定义和应用场景（1-2句）
├─ 核心技术的工程基础介绍（2-3句）
└─ 过渡到"本领域的研究热点/技术需求"

段落二至四：现有技术分析（"虽然…但是…"结构）
├─ 针对每个现有技术方案：
│   ├─ "虽然[现有方案]通过[具体技术手段]在一定程度上[实现了某种效果]，"
│   ├─ "但是，由于[具体机理缺陷]，导致了[可观测的技术问题]。"
│   └─ 如有必要，补充："具体表现为[性能下降、精度不足等具体现象]。"
└─ 至少分析3项技术缺陷，每项150-300字

段落五：技术空白总结
├─ 归纳上述缺陷形成的"技术空白"
├─ "综上，现有技术在[A]、[B]和[C]方面均存在明显不足，"
└─ "亟需一种能够同时解决上述问题的新型[产品类型]。"
```

**技术特征具体化要求**（对应《审查指南》"清楚、完整"要求）：
- **禁止使用模糊的功能性限定词汇**：不得使用"特定的""特殊的""优选的"等模糊词汇
- **必须提供具体的技术特征**：对于核心结构、工艺参数、设备要求等，必须提供具体的技术细节
- **避免"占坑"式写法**：不得使用无具体支撑的表述
- **技术方案必须具体可行**：所有技术特征必须基于真实的机械和工程原理

**关于背景技术引用（强制性规范，依据 §0.11）**：

引用专利时必须给出完整申请号/公开号，不得使用"例如""已有专利"等模糊表述：

```
正确：
  CN202111092234A公开了一种精密齿轮传动装置，其采用渐开线齿形和滚珠丝杠副，通过伺服电机驱动实现高精度传动。
  
错误：
  例如，已有专利公开了精密齿轮传动方案。
  现有技术中，一些方案采用滚珠丝杠作为传动部件。
```

**引用数量与实质内容要求**：
- 背景技术中至少引用 2 项具体现有技术（专利或文献），每项有完整的可检索标识
- **全文背景技术部分禁止出现"例如"二字**
- 每项引用必须描述该文献公开的**具体技术方案**（结构、参数、效果），不能仅提及存在性
- 每项引用后必须指出该现有技术的**具体缺陷**（为什么需要本发明改进），使用"虽然……但是……"结构
- 引用的现有技术方案应能与本发明形成**直接的技术对比**

**检索-引用一致性**：
- 背景技术中引用的所有文献必须来自**本 Skill 实际执行的预评估检索（§3.0A + §3.0B）和正式检索（§3.4）**
- 不得凭空添加未在检索结果中出现的文献
- 预评估阶段的检索结果必须记录具体的文档标识符（申请号/公开号/文献出处），不得使用模糊引用

### 3.4 专利检索

检索当前日期前的相关专利，为新颖性和创造性分析提供依据。

**与本模块的关系**：本模块的检索是正式撰写时的**补充检索**——预评估阶段（§3.0A 新颖性 + §3.0B 创造性）已完成核心特征的多维度语义检索，本阶段主要确保没有遗漏的技术方案，同时为背景技术提供引用素材。

**检索策略：**
1. **关键词检索**：基于发明标题、技术领域、核心结构和传动方式构建检索关键词
2. **分类号检索**：根据技术领域确定相关的IPC/CPC分类号（机械领域常见IPC见 §3.10 及 references 文件）
3. **技术相似性**：重点关注与本发明技术方案相似的现有技术

**执行方式**：优先使用 §3.10 中的 API 渠道，API 不可用时以 WebSearch 作为回退方案。

### 3.5 附图说明 ⭐机械领域核心模块

> **定位说明**：附图是机械领域专利的**核心组成部分**。机械发明的结构特征必须通过附图才能清楚表达，《审查指南》要求"说明书有附图的，应当对说明书附图进行说明"。附图说明的质量直接影响公开充分性和权利要求清楚性。

#### 3.5.1 附图类型选择指南

机械领域发明专利的附图通常需要 **5-6 幅**，涵盖以下类型：

| 附图类型 | 功能 | 必要性 | 典型内容 |
|---------|------|:---:|---------|
| **整体装配示意图** | 展示装置全貌和各部件空间布局 | 必选 | 所有主要部件的位置关系和总体结构 |
| **关键部件结构详图** | 展示核心创新部件的具体结构 | 必选 | 核心部件的形状、尺寸特征、配合面 |
| **连接关系细节图** | 展示部件间的连接方式 | 必选 | 螺栓连接/焊接/轴孔配合/铰接等细节 |
| **剖面图/剖视图** | 展示内部结构或配合关系 | 推荐 | 内部零件的配合、密封结构、内部传动链 |
| **运动状态示意图** | 展示工作过程中的运动关系 | 推荐 | 运动部件的轨迹、极限位置、运动方向 |
| **分解爆炸图** | 展示装配关系和零件层次 | 可选 | 各零件的装配顺序和配合关系 |
| **局部放大图** | 展示关键细节 | 可选 | 配合精度、密封结构、微小特征 |

#### 3.5.2 附图说明撰写规范

**标准输出格式**：

```
## 附图说明

图1为本发明的整体结构装配示意图，展示了各主要机械部件的空间布局和连接关系。

图2为[核心部件名称]的结构详图，重点显示[关键结构特征]和[配合关系]。

图3为[连接部位]的剖面图，呈现[内部配合结构]和[密封/紧固细节]。

图4为[运动部件]的运动状态示意图，显示[运动类型]过程中的相对位置变化。

图5为[关键部件]的分解示意图，呈现各零件的装配顺序和配合面设计。

附图标记如下：
1、机架；2、传动轴；3、齿轮组；4、轴承座；5、连接板；6、电机；7、联轴器；8、导向轴；9、滑块；10、工作台。
```

#### 3.5.3 附图标记规范

**编号规则**：
1. **统一编号**：全文（说明书+权利要求书+摘要）中同一部件使用同一编号
2. **编号格式**：阿拉伯数字+顿号+部件名称，用分号分隔（如"1、机架；2、传动轴；"）
3. **编号顺序**：按附图出现的先后顺序或部件重要程度编号
4. **编号范围**：通常1-50，复杂装置可扩展
5. **禁止重复**：不同部件不得使用相同编号
6. **禁止缺号**：编号应连续，不得跳号（如1、2、4缺3）

**附图标记与权利要求的对应关系**：
- 权利要求中提及的每个部件，都应在附图中有对应标记
- 权利要求中可使用附图标记（如"所述齿轮（3）"），但标记不得限定权利要求保护范围
- 附图标记放在括号内，如"齿轮（3）"，不影响权利要求的解释

#### 3.5.4 附图与具体实施方式的衔接

- 附图说明中描述的结构，必须在具体实施方式中详细展开
- 具体实施方式中引用附图时使用"如图X所示"
- 附图标记在具体实施方式中首次出现时应与附图说明一致
- 工作原理描述须结合附图说明运动过程

### 3.6 发明/实用新型内容撰写

> **法律依据**：《审查指南》第二部分第二章 §2.2.4"发明或者实用新型内容"。
>
> **发明专利和实用新型专利在本节的差异**：发明专利标题为"发明内容"，可声称量化效果和"预料不到的技术效果"；实用新型专利标题为"实用新型内容"，以定性效果为主（详见 §0.14.3）。

#### 3.6.1 发明专利——发明内容撰写

**首句标准句式**（直接回应背景技术）：
"本发明旨在克服上述背景技术中存在的不足，特别是解决[核心技术缺陷A]和[核心技术缺陷B]的问题，提供一种[发明名称]。"

**次句标准句式**（概括核心手段）：
"为实现上述目的，本发明采用的技术方案是：通过[核心手段1]、结合[核心手段2]和[核心手段3]，从而协同实现[主要技术效果]。"

**技术方案段**（宽泛结构范围，必须满足 §0.4 合理性约束）：
描述装置的组成结构、连接关系、传动方式等核心技术特征，给出关键参数的合理范围。

**权利要求类型选择**（§0.5）：
1. 若说明书中公开了多种使用性能 → 使用非限定型："一种机械传动装置，其特征在于……"
2. 若仅公开一种性能 → 使用性能限定型："一种高传动效率的机械传动装置，其特征在于……"
3. 若公开了特定用途 → 使用用途限定型

**核心要求：**
1. **直击要害**：开篇第一句直接回应背景技术中提出的核心问题
2. **概括核心手段**：概括性揭示本发明采用的最核心、最具区别性的技术手段
3. **保持概要性**：避免深入具体的结构参数或工艺细节
4. **提出宽泛的技术方案**：根据说明书实际公开的内容，选择合适的权利要求类型（§0.3）
5. **不要编造具体的技术效果数据**：技术效果使用定性描述，具体数据由具体实施方式提供
6. **功能性限定审查**：技术方案段中的每个特征须通过 §0.12 功能性限定审查——优先用结构特征表达

**有益效果部分结构（发明专利）：**
- 固定开头："本发明提供一种[发明名称]，其有益效果为："
- 主体：**3-5条**有益效果，每条2-4句。效果标题使用"显著提升""有效降低""可靠增强""充分保障"等，禁止使用"更好""更快""极大""理想的……特征"
- **创造性强化要求**（仅🟡风险发明方案）：如果创造性预评估结论为🟡中风险，有益效果中可设置1-2条围绕"预料不到的技术效果"展开，并可在具体实施方式中设置对照实施例佐证（可选）
- 固定结尾："本发明的其他特征和优点将在随后的说明书中阐述，并且，部分地从说明书中变得显而易见，或者通过实施本发明而了解。本发明的目的和其他优点在说明书中所特别指出的结构来实现和获得。"
- 最后一段："为使本发明的上述目的、特征和优点能更明显易懂，下文特举较佳实施例，作详细说明如下。"

**有益效果 ⟷ 具体实施方式 映射关系**（对应 §0.1 公开充分要求）：
- 每条有益效果都必须有对应的具体实施方式可以证明
- 在规划时确保"声称的每一条效果 = 有一个实施例的描述支撑"
- **该映射同时约束 §3.8 权利要求书撰写**：有益效果中提及的所有性能指标，都应在权利要求中找到对应的特征支撑

#### 3.6.2 实用新型专利——实用新型内容撰写

> **关键差异**（§0.14.3）：标题为"实用新型内容"（非"发明内容"）；有益效果定性为主（3-5条）；不要求量化数据；不要求"预料不到的技术效果"论证。

**首句标准句式**：
"本实用新型旨在克服上述背景技术中存在的不足，特别是解决[核心技术缺陷]的问题，提供一种[实用新型名称]。"

**次句标准句式**：
"为实现上述目的，本实用新型采用的技术方案是：通过[核心结构手段1]、结合[核心结构手段2]，从而实现[主要技术效果]。"

**技术方案段**：
描述装置的组成结构、连接关系等核心技术特征，聚焦**产品结构特征**（不含方法步骤）。

**有益效果部分结构（实用新型专利）：**
- 固定开头："本实用新型提供一种[实用新型名称]，其有益效果为："
- 主体：**3-5条**有益效果，每条1-3句。**以定性描述为主**，说明结构改进带来的效果
- 效果标题使用"有效提升""可靠实现""简化结构""便于操作"等
- **不需要**通过对照实施例或性能测试数据来量化证明
- **不需要**声称"预料不到的技术效果"
- 固定结尾："本实用新型的其他特征和优点将在随后的说明书中阐述。"
- 最后一段："为使本实用新型的上述目的、特征和优点能更明显易懂，下文特举较佳实施例，作详细说明如下。"

**实用新型有益效果撰写示例**：
```
本实用新型提供一种无人机机臂同步折叠锁定机构，其有益效果为：

（1）有效实现多机臂同步折叠，通过凸轮盘与联动连杆的配合，一键操作即可完成全部机臂的同步收折，显著提升了使用便捷性；

（2）可靠保证折叠后的锁定状态，弹簧锁定销在折叠到位后自动插入定位孔，无需额外操作即可实现双向锁定；

（3）结构紧凑，凸轮盘集成驱动与锁定功能于一体，减少了零件数量，降低了整体重量；

（4）展开后机臂定位精度高，阿基米德螺线凸轮槽保证等速运动，避免机臂间不同步导致的定位偏差。
```

### 3.7 具体实施方式撰写

> **机械领域特点**：机械领域的具体实施方式以"结构描述+附图引用+工作原理+实施例"为核心。
>
> **发明专利与实用新型专利的差异**（§0.14.4）：
> - **发明专利**：1核心实施例 + 2-3参数变化实施例 + 可选对照实施例（仅🟡风险方案）+ 可选性能测试
> - **实用新型专利**：1核心实施例 + 2-3变型实施例，**无对照实施例、无性能测试**，技术效果定性说明

#### 3.7.1 整体结构概述

首先介绍发明/实用新型的目的、组成结构和核心工作原理。

**开头段落必须包含**：
- 发明/实用新型提供的技术方案
- 核心部件的协同作用
- 要解决的技术问题
- "以下结合附图对本发明/实用新型的具体实施方式进行详细说明"

**发明专利示例开头**：
"为了解决现有技术中[核心技术问题]，本发明提供了一种[发明名称]。以下结合附图对本发明的具体实施方式进行详细说明。如图1所示，本发明包括[主要部件列表]，各部件通过[连接方式]协同工作，实现[核心技术效果]。"

**实用新型专利示例开头**：
"为了解决现有技术中[核心技术问题]，本实用新型提供了一种[实用新型名称]。以下结合附图对本实用新型的具体实施方式进行详细说明。如图1所示，本实用新型包括[主要部件列表]，各部件通过[连接方式]协同工作，实现[核心技术效果]。"

#### 3.7.2 部件描述（部件描述五要素法）

**按附图顺序**，逐一描述每个部件。每个部件的描述必须包含以下五要素：

| 要素 | 内容 | 示例 |
|------|------|------|
| **①部件名称+编号** | 部件名称与附图标记一致 | "齿轮组（3）" |
| **②结构特征** | 形状、尺寸范围、材料、表面处理 | "所述齿轮组（3）包括主动齿轮和从动齿轮，齿形为渐开线修形齿形，模数为2.0-3.0，材料为20CrMnTi合金钢，经渗碳淬火处理，表面硬度HRC58-62" |
| **③连接关系** | 与其他部件的连接方式和位置关系 | "主动齿轮通过平键固定于传动轴（2）的一端，从动齿轮通过螺栓连接于轴承座（4）" |
| **④配合方式** | 配合类型（间隙/过渡/过盈）和配合精度 | "传动轴（2）与轴承座（4）采用过盈配合，配合精度为IT6" |
| **⑤功能作用** | 该部件在装置中的功能 | "齿轮组（3）用于将电机的旋转运动传递至工作台，并实现1:5-1:10的减速传动" |

**部件描述模板**：
```
如图X所示，[部件名称]（[编号]）为[结构特征描述]。[部件名称]（[编号]）通过[连接方式]与[另一部件]（[编号]）连接，[配合方式描述]。[部件名称]（[编号]）的作用是[功能描述]。
```

**关键要求**：
- 引用具体附图编号（"如图X所示"）
- 每个部件的五要素必须完整
- 有相对运动的部件须说明运动类型（旋转/直线/摆动/复合）和运动约束
- 材料和工艺参数使用范围值，不得使用精确值

#### 3.7.3 工作流程描述

**必须包含**：
- 完整的运行过程描述（从启动到完成的全流程）
- 各部件在过程中的作用和运动关系
- 关键的技术原理说明
- 运动关系和传动过程（旋转→直线、减速、换向等）

**工作流程描述模板**：
```
本发明的工作过程如下：

工作时，[动力源]启动，驱动[动力输入部件]进行[运动类型]运动。[运动传递路径描述]。[运动转换过程描述，如旋转运动转换为直线运动]。[控制过程描述，如传感器采集信号→控制器处理→执行器响应]。最终，[输出部件]实现[目标运动/功能]。

在上述过程中，[核心创新部件]的[核心机制]发挥了关键作用：[机制说明]，从而实现了[技术效果]。
```

#### 3.7.4 实施例设计（三维实施例法）

**数量确定**：根据 §0.2 概括程度确定实施例总数。
- **发明专利**：通常为 **1个核心实施例（已在§3.7.1-§3.7.3详细描述）+ 2-3个参数变化实施例**
- **实用新型专利**：通常为 **1个核心实施例 + 2-3个变型实施例**（结构参数变化）

**三个设计维度**（通过参数变化产生实质性差异）：

| 设计维度 | 具体变量 | 差异策略 |
|---------|---------|---------|
| 维度一：核心结构参数 | 核心部件的关键尺寸（如模数、直径、行程等） | 从小到大至少取3个点，**端点必须落在权利要求范围内** |
| 维度二：传动/配合参数 | 传动比、配合精度、间隙等 | 随核心参数等比例或非等比例变化 |
| 维度三：材料/工艺参数 | 材料牌号、热处理工艺、表面处理等 | 改变关键工艺参数以产生不同技术效果 |

**实质性差异判断**：至少一个维度有意义变化 + 技术效果差异显著。

**实施例分布的审查要求**（§0.2）：
- 覆盖整个权利要求范围的**合理分布**：端点附近、中点附近都应设有实施例
- 避免某一区域密集而另一区域空白
- 至少有一个实施例验证最佳方案（核心实施例）

**每个实施例必须完整包含**：核心结构参数 + 传动/配合参数 + 材料/工艺参数 + 与核心实施例的差异说明 + 技术效果说明（定性为主）。

**实施例描述模板**：
```
实施例X：

本实施例与核心实施例的区别在于：[差异说明]。

具体参数如下：
- 核心结构参数：[参数名]=[范围值]
- 传动/配合参数：[参数名]=[范围值]
- 材料/工艺参数：[参数名]=[范围值]

本实施例的技术效果：[效果描述，与核心实施例对比，定性说明]。
```

#### 3.7.5 对照实施例设计（可选——仅发明专利🟡风险方案）

> ⚠️ **适用范围限制**：本节内容**仅适用于发明专利**且**创造性预评估结论为🟡中风险**的方案。实用新型专利**不需要**对照实施例（§0.14.4）。发明专利🟢低风险方案也**不需要**对照实施例。
>
> **机械领域特点**：机械领域的对照实施例是**可选的**，仅在需要证明"预料不到的技术效果"时设置。

**何时需要对照实施例**：
- 发明专利 + 🟡中风险 + 需要证明"区别特征产生了预料不到的技术效果" → **需要**
- 发明专利 + 🟢低风险 → **不需要**
- 实用新型专利 → **不需要**

**数量要求**（仅在需要时）：2-3个对照实施例

**"缺一法"设计原则**：每个对照实施例只改变/移除一个关键结构特征，其余与核心实施例完全一致。

**对照实施例设计模板**（仅在需要时使用）：
- 对照实施例1 — "无核心特征A"：移除核心创新结构A → 证明该特征的必要性
- 对照实施例2 — "换常规方案"：用常规结构替代创新结构 → 证明创新结构选择的必要性
- 对照实施例3 — "最接近现有技术"：模拟D1的方案 → 证明区别特征的效果

**关键要求**（仅在需要时）：
- 每个对照实施例必须有完整独立的结构描述，不得使用"同实施例X"
- 对照实施例首段说明与核心实施例的区别及验证目的
- 对照实施例须与核心实施例进行效果对比

#### 3.7.6 技术效果说明（默认） / 性能测试（可选）

> **法律依据**：《审查指南》第二部分第二章 §2.2.6——具体实施方式应说明技术方案如何解决技术问题、取得何种技术效果。机械领域不强制要求性能测试数据表格，以定性技术效果说明为主。
>
> ⚠️ **适用范围**：
> - **实用新型专利**：仅需**技术效果说明**（定性），**不需要**性能测试数据表格
> - **发明专利🟢低风险**：仅需**技术效果说明**（定性），**不需要**性能测试数据表格
> - **发明专利🟡中风险**：可补充**性能测试数据**（可选），用于佐证"预料不到的技术效果"

**技术效果说明（默认——适用于所有专利类型）**：

在实施例描述中，以**定性方式**说明每个实施例的技术效果，包括：
- 结构改进带来的直接效果（如"同步折叠减少操作步骤"）
- 结构组合带来的协同效果（如"凸轮盘集成驱动与锁定，减少零件数量"）
- 与现有技术的对比效果（如"相比逐个折叠，同步折叠效率提升"）

**技术效果说明示例**：
```
本实施例的技术效果：
（1）通过凸轮盘的阿基米德螺线凸轮槽驱动各联动连杆等速运动，实现了多机臂的同步折叠，相比现有技术的逐个折叠方式，操作步骤从N次减少为1次；
（2）弹簧锁定销在折叠到位后自动插入定位孔，实现了双向自动锁定，无需额外锁定操作；
（3）凸轮盘集成了驱动和锁定功能，相比分离式设计减少了30%的零件数量。
```

**性能测试数据（可选——仅发明专利🟡风险方案需要时使用）**：

> **机械领域特点**：机械领域的性能测试是**可选的**，仅在需要证明"预料不到的技术效果"时使用。

**结构要求**（每项性能测试，仅在需要时）：
- 测试名称：精确描述
- 测试对象：核心实施例及对照实施例
- 测试方法：含测试条件、测试设备类型（不编造具体厂商型号）、测试步骤
- 测试数据：表格形式，使用范围值
- 测试分析：分层对比（核心实施例间对比 + 核心实施例vs对照实施例对比 + 解释趋势）

**测试数据表格要求**（仅在需要时）：
- 格式：Markdown 表格
- 数据：使用范围值（如95-98%），不使用精确值（如96.7%）
- 范围跨度建议 3-8 个百分点

**测试数据真实性要求**（对应 §0.6 诚实信用原则）：
1. **禁止编造具体数值**：测试数据使用合理的范围值表达
2. **禁止使用精确数值**：测试数据必须使用范围值
3. **禁止编造测试方法、设备型号、厂商名称、标准编号**
4. **数据逻辑自洽**：核心实施例 > 对照实施例；参数优化方向一致；所有数据趋势必须有机械原理可解释

### 3.8 权利要求书撰写

> **法律依据**：《专利法》§26、《实施细则》§19-§22、《审查指南》第二部分第二章 §3、§0.12 功能性限定规则。
>
> **核心原则**：权利要求书以说明书为依据，保护范围由独立权利要求确定，从属权利要求逐步收窄形成纵深防御体系。**机械领域产品权利要求以结构特征限定保护范围**（非功能性限定）。

#### 3.8.1 权利要求书的结构层次

机械领域的典型权利要求书结构：

**发明专利**：
```
独立权利要求1：产品权利要求（装置/机构/设备）
  ├─ 从属权利要求2：进一步限定核心结构特征
  ├─ 从属权利要求3：进一步限定传动机构参数
  ├─ 从属权利要求4：进一步限定连接方式/配合关系
  ├─ 从属权利要求5：进一步限定控制系统
  └─ 从属权利要求6：进一步限定材料/工艺

独立权利要求7：方法权利要求（如适用）
  ├─ 从属权利要求8：进一步限定加工工艺参数
  ├─ 从属权利要求9：进一步限定装配步骤
  └─ 从属权利要求10：进一步限定控制方法

用途权利要求（如适用）：
  └─ 权利要求11：装置在特定场景中的应用
```

**实用新型专利**（§0.14.5）：
```
独立权利要求1：产品权利要求（装置/机构/设备）——唯一独立权利要求
  ├─ 从属权利要求2：进一步限定核心结构特征
  ├─ 从属权利要求3：进一步限定传动/配合参数
  ├─ 从属权利要求4：进一步限定连接方式
  ├─ 从属权利要求5：进一步限定材料/工艺（作为结构的一部分）
  └─ 从属权利要求6-8：进一步限定辅助结构特征
```

> ⚠️ **实用新型权利要求约束**：仅产品权利要求，**无方法权利要求、无用途权利要求**。总数量6-10项。

**数量建议**：
- 发明专利：10-15项权利要求（其中2-3项独立权利要求）
- 实用新型专利：**6-10项权利要求**（仅1项独立权利要求——产品权利要求）

#### 3.8.2 独立权利要求1：产品权利要求（四步法）

**法律要求**（《实施细则》§21）：记载解决技术问题的**必要技术特征**。

**⚠️ 产品权利要求撰写四步法**：

**第一步——确定必要技术特征**：
- 从发明内容中提取所有对技术效果有实质性贡献的部件和连接关系
- 问：去掉这个部件/连接关系，发明还能实现声称的效果吗？不能 → 必要特征
- 辅助部件（紧固件、密封件、装饰件等）通常不是必要特征，不列入独立权利要求
- **注意**：必要技术特征应包含"部件+连接关系+配合方式"的完整组合，不能只写部件名称

**第二步——设定参数范围**：
- 以实施例中的参数为基准
- 向两端各扩展合理范围（确保仍在工程合理范围内）
- 检查参数合理性（§0.4）

**第三步——选择限定方式（§0.3 + §0.5）**：
- 确定产品权利要求类型（装置/机构/设备/系统）
- 确定是否需要性能/用途限定（§0.5）

**第四步——功能性限定审查（§0.12 强制执行）**：
- 对每个技术特征执行 §0.12 的功能性限定审查流程
- 优先使用结构限定，必要时使用混合限定
- 将功能性限定转化为结构限定或混合限定

**撰写模板**：

```
1. 一种[性能/用途限定词]+[产品类型]，其特征在于，包括：
   [核心部件A]，所述[核心部件A][结构特征描述]；
   [核心部件B]，所述[核心部件B]与[核心部件A]通过[连接方式]连接，[配合关系描述]；
   [传动机构]，所述[传动机构]用于实现[运动功能]，[结构特征描述]；
   [控制系统]（如有），所述[控制系统]与[传动机构]电连接，[控制方式描述]；
   ……（列出所有必要部件）
   其中，所述[关键部件]的[关键特征]与[另一部件]的[特征]协同作用，实现[核心技术效果]。
```

**关键规则**：
- 使用分号分隔各部件特征，最后一项用句号结束
- 列出的每一个部件都是**必要技术特征**——缺少任何一个，发明就无法实现
- 参数范围直接源于发明内容中的宽泛方案，且必须与说明书中的实施例分布对应
- 权利要求中的参数范围 **⊆** 说明书中公开的范围 **⊆** 实施例实际覆盖的范围
- **每个技术特征须通过 §0.12 功能性限定审查**

#### 3.8.3 从属权利要求

**法律要求**（《实施细则》§22）：
- 必须用"根据权利要求X所述的……，其特征在于，……"的格式引用在前的权利要求
- 附加技术特征必须对引用的权利要求作进一步限定

**五种从属权利要求类型**：

| 类型 | 功能 | 示例 |
|------|------|------|
| **结构特征限定型** | 收窄独立权利要求中某一部件的具体结构 | "根据权利要求1所述的传动装置，其特征在于，所述齿轮组（3）的齿形为渐开线修形齿形，模数为2.0-3.0。" |
| **传动参数限定型** | 收窄传动比、转速、扭矩等参数范围 | "根据权利要求1所述的传动装置，其特征在于，所述传动机构的传动比为1:5-1:10。" |
| **配合关系限定型** | 进一步限定连接方式和配合精度 | "根据权利要求1所述的传动装置，其特征在于，所述传动轴（2）与轴承座（4）采用过盈配合，配合精度为IT6。" |
| **材料工艺限定型** | 增加材料选择和加工工艺限定 | "根据权利要求1所述的传动装置，其特征在于，所述齿轮组（3）的材料为20CrMnTi合金钢，经渗碳淬火处理，表面硬度HRC58-62。" |
| **控制策略限定型** | 进一步限定控制算法和反馈方式 | "根据权利要求1所述的传动装置，其特征在于，所述控制系统采用PID闭环控制，位置反馈采用光栅尺。" |

**从属权利要求撰写的纵深策略**：

```
独立权利要求1（宽泛：齿轮模数1.5-3.5，传动比1:3-1:12）
  ├─ 权利要求2（收窄结构：模数2.0-3.0，渐开线修形齿形）← 对应核心实施例的最佳参数
  ├─ 权利要求3（收窄传动：传动比1:5-1:10）← 对应核心传动链设计
  ├─ 权利要求4（收窄配合：过盈配合IT6）← 对应核心装配工艺
  ├─ 权利要求5（收窄控制：PID闭环+光栅尺反馈）← 对应核心控制系统
  └─ 权利要求6（收窄材料：20CrMnTi+渗碳淬火HRC58-62）← 对应核心材料工艺
```

**纵深设计原则**：
- 权利要求2-3：保护"最佳商业实施方案"（最可能被模仿的参数组合）
- 权利要求4-5：保护"协同增效体系"（证明创造性的核心证据）
- 权利要求6：保护"材料/工艺壁垒"（制造壁垒）

#### 3.8.4 独立权利要求2：方法权利要求（如适用）

**法律要求**：记载解决技术问题的必要步骤和参数范围。

**撰写模板**：

```
7. 一种[产品类型]的[方法类型：制造/装配/控制/检测]方法，其特征在于，包括以下步骤：
   S1：[第一步操作描述]，所述[操作参数]为[参数范围]；
   S2：[第二步操作描述]，所述[操作参数]为[参数范围]；
   S3：[第三步操作描述]，所述[操作参数]为[参数范围]；
   ……（列出所有必要步骤）
   其中，所述步骤[S关键步骤]的[参数]与步骤[S另一步骤]的[参数]协同配合，实现[核心技术效果]。
```

**关键规则**：
- 步骤数控制在4-7步（与具体实施方式中的方法描述一致）
- 每个步骤的工艺参数必须使用范围值，不得使用精确值
- 引用方式："权利要求1-6中任一项所述的……装置的制造方法"
- 从属权利要求可进一步限定各步骤的具体工艺条件
- **方法类型选择**（§0.13）：制造方法/装配方法/控制方法/检测方法

#### 3.8.5 用途权利要求（如适用）

当装置具有多种应用场景时，可单独撰写用途权利要求。

**撰写格式**：

```
11. 权利要求1-6中任一项所述的[产品类型]在[具体应用场景]中的应用。
```

#### 3.8.6 权利要求撰写的全局规则

1. **"其特征在于"** —— 独立权利要求和从属权利要求的分界线。之前的部分是现有技术共有特征，之后的部分是区别技术特征。
2. **一项权利要求只能有一个句号**（在其结尾处）。
3. **不得引用多项权利要求** —— "根据权利要求1或2所述的……"在中国不被接受，应改为"根据权利要求1-6中任一项所述的……"。
4. **不得使用模糊措辞** —— 禁止"大约""左右""约""优选""例如""特别是"等（§0.4）。
5. **参数范围** —— 必须与说明书中公开的范围一致或为其中更窄的子范围。
6. **附图标记** —— 权利要求中可使用附图标记（如"齿轮（3）"），但标记不得限定权利要求保护范围。
7. **功能性限定审查** —— 每个技术特征须通过 §0.12 审查流程（强制）。
8. **权利要求数量**没有法定上限，但超过10项需缴纳附加费。建议控制在10-15项。

### 3.9 说明书摘要撰写

> **法律依据**：《专利法实施细则》§23、《审查指南》第一部分第一章 §5.3。
>
> **核心原则**：摘要是专利文献的检索入口，仅提供技术信息，不具有法律效力。

#### 3.9.1 摘要的结构

**固定内容要素**（缺一不可）：

| 要素 | 来源 | 字数参考 |
|------|------|:---:|
| 发明名称 | §3.1 | 20-25字 |
| 所属技术领域 | §3.2 | 15-25字 |
| 要解决的技术问题 | §3.3（技术空白总结） | 30-60字 |
| 技术方案的要点 | §3.6（发明内容宽泛方案）+ §3.8（独立权利要求1） | 80-150字 |
| 主要用途 | §3.6（发明内容首句） | 15-30字 |
| **总字数** | | **150-300字（含标点）** |

#### 3.9.2 摘要撰写模板

```
本发明公开了一种[发明名称]，属于[技术领域]技术领域。针对现有技术中[核心技术问题A]和[核心技术问题B]的问题，本发明提出一种[核心技术方案]，通过[关键技术手段1]、结合[关键技术手段2]，实现[主要技术效果]。本发明可应用于[主要应用领域]，具有[关键优势]。
```

**关键规则**：
- 全文连续书写，不分段
- 不得包含商业性宣传用语
- 不得出现"本发明提供""权利要求所述"等法律用语
- 不得包含对技术效果的比较级描述（如"优于""高于"），只陈述事实
- 技术问题描述不得模糊
- 与说明书内容严格一致（无额外超出信息）

#### 3.9.3 摘要的质量标准

- 全文一段，无分段
- 总字数150-300字
- 技术方案要点与权利要求1一致或不超出
- 无商业宣传语（"卓越""神奇""革命性"等）
- 无比较级（"优于""高于""相比现有技术"等）
- 无"本发明提供""权利要求所述"等用语

### 3.11 DOCX 专利申请材料生成

> **定位说明**：当第十二步质量自检通过后，将 Markdown 版专利文件转换为符合国家知识产权局提交规范的 DOCX 格式专利申请材料。本模块依赖 `docx` 技能（通过 Skill 工具加载），负责定义专利文档的结构、排版和内容映射规则。

#### 3.11.1 触发条件与前置要求

- **触发时机**：第十二步质量自检 A-M 组全部通过后
- **前置条件**：Markdown 版完整专利文件已生成并通过自检
- **依赖技能**：加载 `docx` 技能（通过 `Skill` 工具，command="docx"）获取 docx-js API 用法和验证脚本路径
- **生成方式**：编写 JavaScript 脚本（docx-js 库），执行后生成 .docx 文件，再用 `validate.py` 验证

#### 3.11.2 专利申请材料文档结构

中国专利申请材料的标准文档顺序：

| 顺序 | 文档部分 | 页面要求 | 内容来源 | 是否放入 DOCX |
|:---:|---------|---------|---------|:---:|
| — | 新颖性预评估报告 | — | §3.0A 产出 | ❌ 不放入 |
| — | 创造性预评估报告 | — | §3.0B 产出 | ❌ 不放入 |

| 2 | 说明书 | 独立页起 | §3.2-§3.7 产出 | ✅ |
| 3 | 权利要求书 | 独立页 | §3.8 产出 | ✅ |
| 4 | 说明书附图 | 独立页（占位） | §3.5 产出 | ✅ 占位 |

> **重要**：预评估报告（新颖性/创造性）是内部工作文件，**不放入** DOCX 专利申请材料。DOCX 仅包含正式申请所需的四部分。

**说明书内部章节顺序**（在同一 section 内连续排版，章节间不分页）：
1. 发明名称（居中，三号加粗）
2. 技术领域
3. 背景技术
4. 发明内容
5. 附图说明
6. 具体实施方式

**各文档部分（摘要/说明书/权利要求书/附图）之间使用 `PageBreak` 分页。**

| 页码 | 宋体 | 小五号（9pt / size 18） | 页脚居中 |

**页面设置**：
- 纸张：A4（宽 11906 DXA × 高 16838 DXA）
- 页边距：上下左右各 25.4mm（1440 DXA）
- 行距：1.5 倍行距（line: 360, lineRule: "auto"）

**表格规范**：

- 表头底纹：浅灰（fill: "F2F2F2", type: `ShadingType.CLEAR`）
- 单元格内边距：margins: { top: 60, bottom: 60, left: 80, right: 80 }

**docx-js 关键规则**（详见 docx 技能）：
- 页面尺寸必须显式设置（docx-js 默认 A4，但仍建议显式声明）

- **禁止使用 Unicode 项目符号**——使用 `LevelFormat.BULLET` + numbering config
- **PageBreak 必须在 Paragraph 内部**——`new Paragraph({ children: [new PageBreak()] })`
- **表格需要双重宽度**——`columnWidths` 数组 + 每个 cell 的 `width`

#### 3.11.5 代码模板

以下为生成脚本的核心结构模板。将 Markdown 专利文件的各部分内容填入对应位置：

```javascript
const { Document, Packer, Paragraph, TextRun, Table, TableRow, TableCell,
        Header, Footer, AlignmentType, HeadingLevel, BorderStyle, WidthType,
        ShadingType, PageNumber, PageBreak, LevelFormat, VerticalAlign } = require('docx');
const fs = require('fs');

// ===== 排版常量（§3.11.3）=====
const FONT_BODY = "宋体";
const FONT_HEADING = "黑体";
const SIZE_TITLE = 32;       // 三号 16pt
const SIZE_H1 = 28;          // 四号 14pt
const SIZE_BODY = 24;        // 小四号 12pt
const SIZE_TABLE = 21;       // 五号 10.5pt
const SIZE_PAGENUM = 18;     // 小五号 9pt
const LINE_SPACING = 360;    // 1.5倍行距
const PAGE_W = 11906;        // A4 宽
const PAGE_H = 16838;        // A4 高

// ===== 辅助函数 =====

function bodyPara(text) {

  });
}

// 章节标题

  return new Paragraph({
    spacing: { before: 240, after: 120, line: LINE_SPACING, lineRule: "auto" },

  });
}

// 文档标题（居中加粗）
function docTitle(text) {
  return new Paragraph({
    alignment: AlignmentType.CENTER,
    spacing: { before: 0, after: 240, line: LINE_SPACING, lineRule: "auto" },

  });
}

// 页脚（页码居中）
function pageFooter() {
  return new Footer({
    children: [new Paragraph({
      alignment: AlignmentType.CENTER,
      children: [new TextRun({ children: [PageNumber.CURRENT], font: FONT_BODY, size: SIZE_PAGENUM })]
    })]
  });
}

// 性能测试表格（headers 为表头数组，rows 为二维数据数组）

  const borders = { top: border, bottom: border, left: border, right: border };
```

#### 3.11.6 内容映射规则

将 Markdown 专利文件各部分映射到 DOCX 结构时，须遵循以下规则：

| Markdown 部分 | DOCX 位置 | 处理方式 |
|--------------|----------|---------|
| 新颖性预评估报告 | **不放入** | 内部评估文件，不作为申请材料 |
| 创造性预评估报告 | **不放入** | 同上 |
| 技术领域 | 说明书 → 技术领域 | 直接转为正文段落 |
| 背景技术 | 说明书 → 背景技术 | 直接转为正文段落，引用的专利号保留 |
| 发明/实用新型内容 | 说明书 → 发明内容/实用新型内容 | 宽泛方案转为段落；有益效果每条转为独立段落 |
| 附图说明 | 说明书 → 附图说明 | 附图描述转为段落；附图标记列表转为段落 |
| 具体实施方式 | 说明书 → 具体实施方式 | 各小节转为段落；性能测试数据（如有）转为 `dataTable()` |
| 权利要求书 | 权利要求书 section | 每项权利要求转为独立 `bodyPara()`，编号格式保留 |
| 摘要 | 说明书摘要 section | 一段式，直接转为正文段落 |

**Markdown → DOCX 格式转换规则**：
- `##` 标题 → `sectionHeading()` 函数
- 段落 → `bodyPara()` 函数
- Markdown 表格 → `dataTable()` 函数（提取表头行和数据行）
- 编号列表项 → 逐项转为 `bodyPara()`，保留"1.""2."等编号
- `**加粗**` → `TextRun({ bold: true })`
- 去除所有 Markdown 语法标记（`#`、`|`、`-`、`**`、`` ` `` 等）
- 性能测试表格中的数据保持范围值（如"3-5"），不转为精确值

#### 3.11.7 附图处理说明

- **附图无法自动生成**——专利附图需专业 CAD 绘制，DOCX 中仅放入文字占位清单
- 在附图 section 中列出所有附图标题（如"图1：整体结构装配示意图"），供绘图人员参考
- 附图说明的完整文字内容已在说明书的"附图说明"章节中呈现
- 如用户后续提供附图图片文件（PNG/JPG），可使用 `ImageRun` 插入（参考 docx 技能 Images 章节，注意 `type` 参数必填）

#### 3.11.8 实用新型 DOCX 适配

撰写实用新型专利时，DOCX 生成需适配以下差异（§0.14）：
- 说明书标题：**"实用新型内容"**（非"发明内容"）
- 全文使用**"本实用新型"**（非"本发明"）
- 权利要求书中**不含方法权利要求**（仅产品权利要求，6-10项）
- 具体实施方式中**无对照实施例、无性能测试数据表格**
- 技术效果以**定性说明**为主
- 其余文档结构与发明专利相同（摘要→说明书→权利要求书→附图占位）
- 新颖性预评估报告可简化，创造性预评估报告使用**简化版（§3.0C）**，两者均**不放入** DOCX
- 预评估报告均**不放入** DOCX

## 四、全局约束与规则

### 4.1 技术红线（最高优先级）

以下内容绝对禁止出现在专利文件的任何部分（含权利要求书、摘要和预评估报告）：

| 禁止内容 | 说明 |
|---------|------|
| 医疗用途暗示 | 不得暗示任何治疗/预防疾病的功能 |
| 商业宣传用语 | 不得使用"新型""高效""神奇""卓越""革命性"等宣传性词汇 |
| 模糊表述 | 不得使用"特定的""特殊的""优选的""适当的""一定的"等模糊词汇 |
| 精确值（工艺参数） | 输出工艺/结构参数时，具体数值必须是一个范围，不可以使用精确值 |
| 省略表述 | 不得使用"同实施例X""同上""同前"等省略表述 |
| 无结构支撑的功能性限定 | 产品权利要求中的功能性限定须通过 §0.12 审查，优先使用结构限定 |

### 4.2 格式约束

1. **禁止使用markdown的无序列表**，改用编号列表或段落
2. **输出工艺参数时，具体数值必须是一个范围，不可以使用精确值**
3. **性能测试数据（如有）必须使用范围值**——性能测试仅发明专利🟡风险方案可选，实用新型不需要
4. **必须生成完整的内容，不要截断**
5. **不得使用"同实施例X""同对照实施例X"等省略表述**
6. **每个实施例的结构描述必须完整**
7. **权利要求中每一项以句号结尾，各项之间用分号或换行分隔**
8. **附图标记全文一致**：同一部件在说明书、权利要求书、摘要中使用同一编号
9. **背景技术引用规范**（§0.11）：每项引用必须有具体可检索的文档标识（申请号/公开号/文献出处）；全文背景技术部分**禁止出现"例如"二字**；禁止"已有文献报道""现有技术中一些方案"等模糊表述
10. **专利类型标识**：实用新型专利全文使用"本实用新型"（非"本发明"），说明书标题为"实用新型内容"（非"发明内容"）

### 4.3 数据真实性约束（§0.6 诚实信用原则）

- 不得编造专利号（无法确认时使用通用描述）
- 不得编造厂商名称、设备型号（描述技术参数即可）
- 不得编造标准编号
- 不得编造精确测试数据（使用范围值）
- 所有技术方案必须基于真实的机械和工程原理
- **背景技术中引用的专利号和文献出处必须是真实可检索的**：所有引用文献必须来自实际执行的预评估检索（§3.0A + §3.0B）和正式检索（§3.4）的产出，不得凭空编造专利号或文献信息来填充背景技术

### 4.4 诚实信用特别约束（《专利法实施细则》2024 §11）

- 不得将公知常识包装为创新点
- 不得编造无法实施的结构或工艺流程
- 所有声称的效果必须有对应的实施例描述或工程依据支撑
- 实施例之间的对比逻辑（如有）必须严谨、可验证
- **权利要求中的保护范围必须是说明书能够支撑的**（不得过度概括）
- **预评估报告中的检索结果必须真实**（不得虚构检索命中文献）
- **附图标记必须与文字描述一致**，结构关系必须真实可实施

## 五、质量自检清单

### A. 结构完整性

**发明专利**：
- 发明名称：20-25字，无宣传语/人名/商标，含核心特征+产品类型
- 技术领域：150-200字，4句结构完整
- 背景技术：含至少3项技术缺陷分析，"虽然…但是…"结构
- 发明内容：首句+次句标准句式+宽泛技术方案+3-5条有益效果
- 附图说明：5-6幅附图，含附图标记列表，标记编号连续无缺号
- 具体实施方式：整体结构概述+部件描述（五要素法）+工作流程+实施例（1核心+2-3变型）+可选对照实施例+可选性能测试
- 权利要求书：独立权利要求1（产品）+ 独立权利要求2（方法，如适用）+ 5-10项从属权利要求
- 摘要：150-300字，包含发明名称+技术领域+技术问题+方案要点+主要用途
- **预评估报告（新颖性 §3.0A + 创造性 §3.0B）** ⭐

**实用新型专利**：
- 实用新型名称：20-25字，无宣传语/人名/商标，含核心特征+产品类型
- 技术领域：150-200字，4句结构完整
- 背景技术：含至少3项技术缺陷分析，"虽然…但是…"结构
- **实用新型内容**（非"发明内容"）：首句+次句标准句式+结构方案+3-5条有益效果（定性）
- 附图说明：5-6幅附图（实用新型**必须有附图**），含附图标记列表
- **具体实施方式**：整体结构概述+部件描述（五要素法）+工作流程+实施例（1核心+2-3变型）——**无对照实施例、无性能测试**
- **权利要求书**：仅产品权利要求（1项独立+5-8项从属），**无方法权利要求**
- 摘要：150-300字，使用"本实用新型"（非"本发明"）
- **预评估报告（新颖性 §3.0A + 创造性 §3.0C 简化版）** ⭐——实用新型同样需要创造性预评估

### B. 技术方案合法性（§0.4 参数约束）
- 结构参数范围符合机械设计常识（尺寸链一致性、运动学可行性）
- 参数范围包容性验证通过（权利要求 ⊇ 说明书 ⊇ 实施例）
- 公差范围符合加工工艺能力
- 量纲一致性（同一参数量纲统一）
- 实施例参数落在发明/实用新型内容声明的范围内
- 对照实施例（如有）仅改变声称的变量，其余与参照实施例一致
- 实施例分布覆盖权利要求范围的关键端点
- 权利要求1中的参数范围包含实施例的全部参数点

### C. 技术红线（§4.1）
- 全文中不出现医疗用途暗示
- 全文中不出现商业宣传用语
- 全文中不出现模糊表述（特定的/特殊的/优选的/适当的/一定的）
- 不暗示任何治疗/预防疾病的功能
- 权利要求书中不出现任何医疗性能限定
- 预评估报告中不出现医学/病理表述

### D. 数据质量（§0.6 + §0.2）
- 工艺参数全部为范围值，无精确值
- 性能测试数据（如有）全部为范围值，无精确值
- 实施例数据趋势有机械原理可解释，逻辑自洽
- **实用新型**：无性能测试数据表格（仅有定性技术效果说明）

### E. 新颖性/创造性支撑（§0.3 + §0.5 + §0.9 + §0.10）

**发明专利**：
- 每条有益效果均有对应实施例支撑
- 每个关键创新点均有实施例验证
- "预料不到的技术效果"（如有）有对照实施例确证（可选，仅🟡风险方案）
- 🟡风险方案：至少2个对照实施例模拟最接近现有技术方案（可选）

**实用新型专利**：
- 每条有益效果均有对应实施例支撑（定性即可）
- **不需要**对照实施例
- **不需要**"预料不到的技术效果"论证

### F. 表述规范
- 无模糊词汇（特定的/特殊的/优选的/适当的/一定的）
- 无省略表述（同实施例X/同上/同前）
- 无Markdown无序列表
- 所有核心结构、工艺参数有具体数值/范围
- 不存在截断的段落
- 参数范围无"大约""左右""约"等被《审查指南》禁止的含糊措辞（§0.4）
- **背景技术引用规范**（§0.11）：
  - 全文背景技术部分**无"例如"二字**
  - 每项引用有具体的文档标识（专利：CN/US/EP/WO/JP开头+数字；文献：作者+标题+期刊+卷期页码/DOI）
  - 无"已有文献报道""现有技术中一些方案"等模糊引用
  - 至少引用2项具体现有技术
  - 所有引用的专利号/文献出处可检索验证

### G. 说明书公开充分（§0.1 三要素）
- 产品确认：部件组成、连接关系、配合方式完整清楚
- 产品实现：至少一种完整实施方式，结构描述清晰可实施（五要素法）
- 用途/效果：有定性描述 + 定量测试数据支撑（不可预测效果必须有数据）
- **附图支撑**：结构特征有附图对应，附图标记与文字描述一致

### H. 权利要求书合规（§0.7 + §0.12）

**发明专利**：
- 独立权利要求1记载了全部必要技术特征
- 独立权利要求2（如有）完整记载了方法（步骤数4-7步，参数为范围值）
- 从属权利要求引用关系正确（"根据权利要求X所述的"）
- 若干从属权利要求形成纵深防御（结构收窄→传动参数→配合关系→控制策略→材料工艺）
- 权利要求中的参数范围 ⊆ 说明书中的范围 ⊆ 实施例覆盖的范围
- **功能性限定审查通过**（§0.12）：每个技术特征已执行审查流程，无无结构支撑的功能性限定
- 无"大约""左右""约""优选""例如"等禁止措辞
- 每项权利要求以一个句号结尾
- 附图标记使用正确（括号内，不限定保护范围）
- 总数量10-15项（含2-3项独立权利要求）

**实用新型专利**：
- 独立权利要求1记载了全部必要技术特征（**仅产品权利要求**）
- **无方法权利要求、无用途权利要求**
- 从属权利要求引用关系正确
- 从属权利要求形成结构特征纵深防御（结构收窄→传动参数→配合关系→材料工艺）
- 权利要求中的参数范围 ⊆ 说明书中的范围 ⊆ 实施例覆盖的范围
- **功能性限定审查通过**（§0.12）
- 无"大约""左右""约""优选""例如"等禁止措辞
- 每项权利要求以一个句号结尾
- 附图标记使用正确
- 总数量**6-10项**（仅1项独立权利要求）

### I. 摘要合规（§0.8）
- 总字数150-300字（含标点）
- 全文一段，无分段
- 包含：发明名称/技术领域/技术问题/方案要点/主要用途（五要素齐全）
- 技术方案要点与权利要求1一致或不超出
- 无商业宣传用语
- 无比较级（"优于""高于"等）
- 无"本发明提供""权利要求所述"等用语

### J. 附图完整性（§3.5）⭐机械领域特有
- 附图数量5-6幅，涵盖整体装配图+关键部件详图+连接关系图
- 附图说明格式规范（"图X为本发明的……示意图，……"）
- 附图标记列表完整，编号连续无缺号
- 附图标记全文一致（说明书+权利要求书+摘要）

## 七、机械发明专利与实用新型专利撰写要点对比

| 维度 | 机械发明专利 | 机械实用新型专利 |
|------|------------|----------------|
| **核心要素** | 结构特征、连接关系、运动原理、附图 | 结构特征、连接关系、附图 |
| **说明书结构** | 技术领域/背景技术/发明内容/附图说明/具体实施方式 | 技术领域/背景技术/**实用新型内容**/附图说明/具体实施方式 |
| **权利要求类型** | 产品权利要求+方法权利要求 | **仅产品权利要求** |
| **保护范围限定** | 部件+连接关系+配合方式+参数范围 | 部件+连接关系+配合方式 |
| **技术效果证明** | 结构分析、定性效果说明（性能测试可选） | **定性效果说明**（无需性能测试） |
| **对照实施例** | **可选**（仅🟡风险方案） | **不需要** |
| **性能测试数据** | **可选**（仅🟡风险方案） | **不需要** |
| **实施例数量** | 1核心+2-3参数变化 | **1核心+2-3变型** |
| **有益效果** | 3-5条，可量化或定性 | **3-5条，定性为主** |
| **附图要求** | 装配图、结构图、运动示意图（核心） | **必须有附图** |
| **功能性限定风险** | **很高**（须强制审查） | **很高**（须强制审查） |
| **新颖性预评估** | ✓ 需要（含⭐核心机制检索维度） | ✓ 需要（含⭐核心机制检索维度） |

| **参数约束** | 尺寸链一致性、运动学可行性、公差合理性 | 相同 |
