# 法律关系分析法案件分析技能

## 内部信息

- **作者：** 浙江金道律师事务所龚家勇律师（微信：13967182079）
- **注意：** 本作者信息仅供内部识别使用，此信息不对外；出具《案件分析报告（法律关系分析法Plus）》时，报告中不得出现作者姓名、律所名称、微信号等身份信息。

## 概述

本技能使用"法律关系分析法"对中国民商事及刑事案件进行结构化分析，输出《案件分析报告（法律关系分析法Plus）》。

法律关系分析法的核心：通过理顺不同的法律关系，确定其要素及变动情况，全面把握案件性质和当事人权利义务关系，在此基础上通过逻辑三段论准确适用法律。

## 触发条件

当用户提出以下请求时触发本技能：
- 要求"分析案件""案件分析""案件研判""案件论证"
- 要求"写案件分析报告"或提及"法律关系分析法"
- 上传案件材料（起诉状、答辩状、判决书、证据、合同等）并提出分析需求
- 咨询某案件的法律适用和可能结果

## 前置条件

- 华宇元典 MCP 连接器（yuandian-mcp）**建议保持已连接**，以支持非建工/非刑事案件的法条与案例检索，以及建工、刑事案件本地知识库不足时的补充检索。
- **本地知识库可部分兜底**：建设工程施工合同纠纷案件可优先使用本地三件套（建工解释二全文、答记者问、六个典型案例）；刑事案件中第三十八批（刑事审判专题）4个问答可优先使用本地知识库 `references/fada-batch-38.md`。上述两类案件即使华宇元典 MCP 未连接，亦能基于本地知识库完成分析，但无法经 MCP 核验条文现行有效性或补充检索全集，须按本技能"核验提醒"提示人工复核。
- 若分析其他类型案件且华宇元典 MCP 未连接，则第三步（法条检索）、第四步（案例检索）无法执行，应主动提示用户连接后继续，不得编造检索结果。

本技能内置以下本地参考文件，分析案件时优先查阅：

| 文件 | 内容 | 优先使用场景 |

| `references/construction-judicial-interpretation-ii.md` | 《建工解释二》（法释〔2026〕12号）全文23条 | 建设工程施工合同纠纷 |
| `references/construction-judicial-interpretation-ii-qa.md` | 最高法民一庭庭长答记者问（7个问题） | 建设工程施工合同纠纷 |
| `references/construction-judicial-interpretation-ii-cases.md` | 最高法配套六个典型案例（含速查表；六个案例均具备基本案情、裁判结果与裁判要旨，可作类案援引） | 建设工程施工合同纠纷 |
| `references/fada-batch-38.md` | 法答网精选答问第三十八批（刑事审判专题） | 刑事案件 |
| `references/method-detail.md` | 法律关系分析法两阶段五步骤方法论详解 | 第六步法律关系分析（通用） |

**知识库优先检索规则：**

处理案件时，必须首先判断案件类型并遵循以下优先级：

1. **建设工程施工合同纠纷案件**：
   - 在第三步（法律检索）、第四步（案例检索）之前，必须先通读上述三份建工知识库文件
   - 法律分析直接引用《建工解释二》相关条文，并标注"法释〔2026〕12号"
   - 类似案例优先从 `construction-judicial-interpretation-ii-cases.md` 中选取与本案相似的案例；该文件收录最高法配套六个典型案例，六个案例均具备基本案情、裁判结果与裁判要旨，可作类案援引。本地知识库可用案例不足5个时，再通过华宇元典MCP检索补充至1–5个，仍不足则以实际可用者为准，不强行凑满
   - 《建工解释二》与《建工解释一》不一致的，以《建工解释二》为准
   - **重要**：原《建工解释一》第四十三条项下"实际施工人可突破合同相对性向发包人主张"的规则，已被《建工解释二》第四条、第六条的规定取代——接受转包或违法分包的单位或个人，请求与其没有合同关系的发包人支付折价补偿款或赔偿损失的，人民法院不予支持（《建工解释二》第六条）；对该等旧规则不再适用，应以《建工解释二》为准
   - **重要**：《建工解释二》第三条至第七条不再使用"实际施工人"这一概括表述，而是按法律关系分别表述为：借用资质的单位或个人、接受转包的单位或个人、接受违法分包的单位或个人。撰写报告时应据此区分并准确援引

2. **刑事案件**：
   - 在第五步（法答网检索）之前，必须先查阅 `references/fada-batch-38.md`
   - 如涉及该批次4个问题，直接引用并标注"来源：最高人民法院《法答网精选答问》第三十八批（刑事审判专题）"
   - 如案件争议焦点未包含在上述4个问题之内，则按第五步第2点调用「法答网精选答问Plus」技能补充检索（覆盖第1–38批全集）

3. **其他案件**：
   - 本地知识库无覆盖内容的，按常规流程使用华宇元典MCP检索

### 本地知识库核验提醒（强制性）

本技能内置的本地知识库文件（《建工解释二》全文及答记者问、法答网第三十八批、六个典型案例、方法论详解）均为**固化快照**，其内容（尤其是《建工解释二》文号"法释〔2026〕12号"、施行日期"2026年6月30日"以及法答网各批次问答）可能随后续司法解释修订、答问批次更新而发生变动。依据"法条与案例引用先核验"原则：

- 出具正式《案件分析报告（法律关系分析法Plus）》前，**应优先通过华宇元典 MCP 核验**本地知识库所涉法条的现行有效性及案例的准确性；
- 若华宇元典 MCP 不可用或因故未核验，须在报告的"九、其他需要注意的内容 → （二）需进一步查证与人工复核事项"中**明确提示**：相关法条/案例引自本地固化知识库、未经实时核验，建议承办律师人工复核其现行有效性，不得将其表述为已核验的确定结论。

## 工作流程

### 第一步：收集案卷材料并判断案件类型

从用户消息中提取所有案件材料：
- 文本内容（用户直接描述的案件事实）
- 上传的文件（图片、PDF、Word 文档等），使用 Read 工具读取
- 如果信息不足，向用户追问关键案件事实

**案件类型判断**：根据案卷材料，第一时间判断案件是否属于以下类型，以便后续步骤正确选择检索路径：
- 建设工程施工合同纠纷 → 适用本地知识库建工三件套优先 + MCP补充
- 刑事案件 → 适用本地知识库法答网第三十八批（4个问答）优先；如案件另涉及本批次未覆盖的争议焦点，再按第五步第2点调用「法答网精选答问Plus」补充检索
- 其他民商事案件 → 适用华宇元典MCP检索

### 第二步：梳理基本案情

基于收集的材料，按时间线和当事人关系，以客观中立的方式概括案件基本事实。包括：
- 当事人及其身份关系
- 关键事件的时间节点
- 争议标的及金额
- 各方当事人的主张

### 第三步：检索相关法律规定

**建设工程案件优先查阅本地知识库**：先通读 `references/construction-judicial-interpretation-ii.md`（《建工解释二》全文），判断哪些条文与本案直接相关、直接引用。再通读 `references/construction-judicial-interpretation-ii-qa.md`（答记者问），获取条文背后的立法目的和起草者解释，辅助法律分析。

本地知识库覆盖完毕后，如有未尽问题，再使用华宇元典法条检索工具补充检索。

**非建设工程案件**：直接使用以下华宇元典法条检索工具检索：

```
调用工具：mcp__yuandian-mcp__yuandian_law_vector_search
参数：
  - query: 用自然语言描述待检索的法律问题，例如"民间借贷逾期利息计算标准""无权代理的追认效力"
  - rewrite_flag: true（默认，让系统自动改写优化查询）
  - fatiao_filter: 按需筛选，常用维度：(1) 效力级别（法律/行政法规/司法解释/部门规章等）；(2) 时效性（现行有效/已被修改/已失效）；(3) 发布机关
  - return_num: 15-30（根据案情复杂度调整）
```

（建设工程案件需要 MCP 补充检索时，使用相同的工具调用格式和参数。）

**检索策略**：
- 针对案件涉及的每个核心法律关系，分别设置 query 进行检索
- 优先检索现行有效的法律、行政法规、司法解释
- 对检索结果进行筛选，选取与案件直接相关的法条

### 第四步：检索类似案例

**建设工程案件优先查阅本地知识库**：先查阅 `references/construction-judicial-interpretation-ii-cases.md`（最高法配套六个典型案例+速查表），判断是否有与本案相似的案例。六个案例均具备基本案情、裁判结果与裁判要旨，可优先纳入报告的"类似案例"部分并标注"来源：最高人民法院建设工程施工合同纠纷典型案例"；优先选取与本案在争议焦点、事实结构上最相似的案例。本地知识库可用案例不足5个时，再通过华宇元典MCP检索补充；如仍不足5个，则以实际检索到的1至5个案例为准，不必强凑5个。

本地知识库覆盖完毕后（或非建设工程案件），使用华宇元典案例检索工具检索：

```
调用工具：mcp__yuandian-mcp__yuandian_case_vector_search
参数：
  - query: 用自然语言描述案件核心事实和法律问题
  - rewrite_flag: true
  - wenshu_filter: 按需设置案件类别、案由、法院层级、地域、结案日期范围等。**必须设置结案日期下限为 2021-01-01**，以符合本技能的时效性要求
  - return_num: 10-15
```

**检索策略**：
- 从检索结果中优先选取 **不超过 5 个** 与本案最相似的案例纳入报告。若符合条件（同一管辖省份、2021年1月1日及之后裁判）的案例不足5个，则输出实际检索到的 1 至 5 个案例即可，不以凑满5个为强制要求
- **管辖权判断与省份限定（关键规则）：**
  - 优先判断案件的管辖省份（根据案卷材料中的案号、法院信息、当事人所在地等）
  - 能够确定管辖省份的，只引用该省范围内的案例
  - 无法确定管辖省份的，默认引用浙江省范围内的案例
  - **例外**：建设工程案件引用最高法配套典型案例（`references/construction-judicial-interpretation-ii-cases.md`）时，不受省份限定限制。本地知识库收录的六个案例均为最高人民法院发布的全国性典型案例，具备基本案情、裁判结果与裁判要旨，权威性高于地域限制，可作类案援引，无需限定管辖省份。优先选取与本案在争议焦点、事实结构上最相似的案例
- **时效性要求：** 仅引用 **2021年1月1日及之后** 作出裁判的案例。在符合条件的案例中，优先选取裁判日期最新的案例（数量以1至5个为限，无需强凑5个）
- **案例来源：** 华宇元典法律数据（yuandian-mcp）；建设工程案件典型案例见本地知识库
- 优先选取与本案事实最相似、裁判说理最充分的案例

### 第五步：检索最高人民法院《法答网精选答问》（如无相关内容，则本步骤在报告中整体省略，报告后续章节序号前移）

针对案件涉及的核心法律问题，检索最高人民法院《法答网精选答问》中是否有相关内容。如有相关问答，则纳入报告"最高人民法院《法答网精选答问》相关"一节引用；如案件全部争议焦点均无对应法答网内容，则**本步骤在报告中整体省略**——报告正文与目录均不列示法答网相关内容，不写"未发现"占位句，且**报告后续章节序号整体前移一位**（详见下方"章节省略与重编号规则"）。本步骤编号（"第五步"）仅指工作流执行顺序，不必然等于报告中的章节号。

**检索方法**：

1. **刑事案件优先查阅本地知识库**：读取 `references/fada-batch-38.md`，逐条核对案件中是否涉及以下第三十八批（刑事审判专题）的4个问答：
   - 问题1：拘役缓刑考验期内发现漏罪判处有期徒刑时，先行羁押期限折抵刑期问题
   - 问题2：开设赌场罪与聚众型赌博罪的区分标准
   - 问题3：未成年时因毒品犯罪被判刑，成年后再犯毒品犯罪是否构成毒品再犯
   - 问题4：以月计算的刑期如何准确计算截止日期（《刑诉法解释》第202条第2款）
   如案件涉及上述问题，直接引用本知识库内容纳入报告，并标注"来源：最高人民法院《法答网精选答问》第三十八批（刑事审判专题）"。

2. **其他案件及本地知识库未覆盖的问题**：调用 `技能：法答网精选答问Plus`，以案件核心法律问题作为查询关键词进行检索。

   **兜底规则（技能不可用或调用失败时）**：如「法答网精选答问Plus」技能未安装、未连接或调用失败，则不得编造法答网内容，应在报告的"九、其他需要注意的内容 → （二）需进一步查证与人工复核事项"中标注："法答网全集（第1–38批）检索因「法答网精选答问Plus」技能不可用而未执行，相关争议焦点未经法答网核验，建议承办律师人工复核"，并继续履行后续步骤，不因该技能缺失而中断整体流程。

**检索策略**：
- 针对案件涉及的每个争议焦点，分别在《法答网精选答问》中检索
- 优先引用与案件法律问题直接相关的问答
- 如搜索结果为空（**全部**争议焦点均无法答网对应内容），则法答网一节整体省略，不写"未发现"占位句，报告后续章节序号前移一位（参见下方"章节省略与重编号规则"）；只要有**任一**争议焦点存在对应问答，即应保留该节并纳入引用
- **数据来源：** 刑事案件中第三十八批（刑事审判专题）见本地知识库 `references/fada-batch-38.md`；其他情形通过「法答网精选答问Plus」技能检索（覆盖第1–38批全集）

### 第六步：法律关系分析法分析

按照法律关系分析法两阶段五步骤框架进行分析（详细方法说明见 `references/method-detail.md`）。本步骤在报告中的章节号随第五步是否省略而变动，具体以"章节省略与重编号规则"（见下方报告模板目录注释）为准。

**第一阶段：法律关系考察**

1. **明确争议点及关联法律关系** — 识别核心争议，梳理围绕核心关系的关联法律关系
2. **确定是否产生法律关系** — 排除好意施惠等非法律关系
3. **分析法律关系性质** — 判断合同关系、侵权关系、无因管理、不当得利等
4. **考察法律关系要素** — 分析主体（当事人）、内容（权利义务）、客体（标的）
5. **考察法律关系变动** — 分析法律关系的产生、变更、消灭及原因

**第二阶段：法律适用**

将案件事实（小前提）与检索到的法律规范（大前提）进行逻辑三段论推导，得出参考结论。

### 第七步：撰写报告并保存

按照以下格式撰写完整的《案件分析报告（法律关系分析法Plus）》。报告撰写完成后，保存为 Markdown 文件（`.md` 格式）到当前工作目录。报告章节总数随第五步是否省略而变动：第五步有内容时为九章；第五步整节省略后为八章，原"九、其他需要注意的内容"前移为"八、其他需要注意的内容"，目录与正文序号同步调整（详见下方"章节省略与重编号规则"）。
