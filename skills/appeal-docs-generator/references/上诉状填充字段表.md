# 上诉状填充字段表

> 供 `scripts/fill_appeal_docx.py` 使用。脚本以 `assets/民事上诉状-脱敏模板.docx` 为格式母版，
> **原位填充、格式 100% 保留**（黑体 18pt 居中标题／仿宋 14pt 正文／1.5 倍行距／首行缩进 2 字符）。

## 二、字段规则

| 字段 | 必填 | 规则 |
|---|---|---|
| `上诉人.原审地位` | ✓ | 只填「原告／被告／第三人」，**不要**自带"一审"二字（母版已含「一审」前缀） |
| `上诉人.身份` | ✓ | 完整身份信息，格式：`姓名，性别，出生年月日，民族，住住所地。`；法人为 `名称，住所地，法定代表人×××，职务。` |
| `上诉人.姓名` | — | 仅用于生成前提句「×××因不服……」。**缺省时传 `上诉人简称`** |
| `被上诉人[]` | ✓ | 数组，按实际人数增减；每人一项，同 `身份` 格式 |
| `第三人[]` | — | 数组，无第三人时传 `[]`，母版中的示例行会被删除 |
| `一审法院` / `一审案号` | ✓ | 案号**自带全角括号时不会重复加括号** |
| `二审法院` | ✓ | 写入「此致」下方 |
| `上诉请求[]` | ✓ | 数组，**逐项完整文本**（含「1、」「2、」序号）。改判与发回重审用递进式：`改判××；或撤销原判决，发回重审；` |
| `事实与理由[]` | ✓ | 数组，每项含 `kind` 与 `text`。`kind` 三选一：`lead`（开篇结论段）／`head`（"一、二、"小结标题，加粗）／`body`（正文，不加粗） |
| `落款签名` | — | 留空则输出「上诉人：　　　　　（签名/盖章）」 |
| `落款日期` | — | 留空则输出「　　　　年　　月　　日」 |

## 三、`kind` 的选择标准

| kind | 用在哪 | 母版格式 |
|---|---|---|
| `lead` | **第一项必须是 lead**——开篇一句话结论段 | 仿宋 14pt，不加粗 |
| `head` | 「一、……」「二、……」这类**分项大标题** | 仿宋 14pt，**加粗** |
| `body` | 其余全部正文（含「错误之一：……」「综上，……」） | 仿宋 14pt，不加粗 |

## 四、禁止项

1. **`text` 中不得残留 `〔` 或 `〕`** —— 脚本自检会拦截并不落盘。占位符只允许出现在母版里。
2. **不得为「错误之一／之二／之三」单独设 `head`** —— 按母版体例，它们是 `body`，加粗只用于「一、」「二、」。
3. **上诉请求不得超出一审诉请射程** —— 超出的部分二审只能调解或告知另诉（民诉法解释第326条）。
4. **`事实与理由` 中每一句事实主张都必须能指出依据** —— 当事人陈述、在案证据编号或二审新证据，三者之一，具体到名称（铁律三）。
