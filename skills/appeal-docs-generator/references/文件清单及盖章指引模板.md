# 二审上诉材料清单（打印份数 + 盖章指引）

> 打印时按本清单份数准备，备注列标「公司盖章」「律所盖章」的位置需加盖相应印章。
>
> ⚠️ **本表是全量清单，必须按实际情形裁剪后再交付**：
> - **情形 A（一审本所代理，续办二审）** → 用 `--skip` 剔除 **04、05-1、05-2、06、07、08、09**（法代证明仅在主体为法人时需要）等本次未生成的行。理由：续办时沿用一审已办妥的委托手续与工作文书，**授权委托书、风险告知书、律师工作反馈卡、二审接待笔录均不再生成**。
> - **情形 B（一审非本所，二审新接）** → 全表适用。
> - **情形 C（仅代书）** → 另行裁剪。
>
> **清单只列本次真正要当事人签字／盖章的材料**，未生成的一律剔除。
>
> **份数规则**：标「随对方当事人数」的行，份数 = 对方当事人人数 + 2（我方 1 份 + 对方 N 份 + 法院 1 份）。默认按 1 名对方当事人计为 3 份，每多一名对方当事人多 1 份，生成时由脚本 `--counterparties` 参数自动调整。依据：《中华人民共和国民事诉讼法》第173条——上诉状应当按照对方当事人或者代表人的人数提出副本。
>
> **上诉期限**：判决书送达之日起 **15 日**、裁定书 **10 日**（民诉法第171条）。**上诉案件受理费应在提交上诉状时预交；上诉期内未预交的，法院通知后 7 日内预交，逾期视为撤回上诉**（诉讼费用交纳办法第22条第2款）。
