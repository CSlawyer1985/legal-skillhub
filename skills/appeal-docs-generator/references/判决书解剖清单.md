# 判决书解剖清单（六诊）

> 本文件是本技能的分析层规则。**逐诊执行，不许跳诊、不许合并**。每一诊的产出都必须落成下表的字段，不得只写结论性文字。
> 锚点法条见 `民诉法审查尺子表.md`；事实来源见 `当事人事实核对清单.md`；法条与类案见 `元典检索姿势.md`。

## 一、总输出格式（《一审判决漏洞清单》）

每一条漏洞必须填满以下九列，缺一列即为不合格：

| 列 | 字段 | 填写要求 |
|---|---|---|
| 1 | 漏洞编号 | `D-01` 起顺序编号，不跳号 |
| 2 | 类型 | 事实认定 / 法律适用 / 程序违法 / 说理缺失 / 新要素 |
| 3 | 一审定位 | 必须精确到「判项第 × 项」或「判决书『本院查明』第 × 段」或「判决书第 × 页」 |
| 4 | 一审原话 | 摘录判决书原文，加引号。不许转述、不许概括 |
| 5 | 违反的法律依据 | 法条名称 + 条文序号 + 原文（经元典核验现行有效） |
| 6 | 支撑依据 | 当事人陈述 / 在案证据编号 / 二审新证据；三者之一，必须具体 |
| 7 | 对应二审处理 | 维持 / 改判 / 发回重审（基本事实不清）/ 发回重审（严重违反法定程序）/ 撤销原裁判 |
| 8 | 我方受损后果 | 金额或权利，可量化则量化 |
| 9 | 可信度 + 是否主张 | 高 / 中 / 低；「是否主张」列留空，由律师在 G2 闸门勾选 |

**红线**：第 4 列**摘不出判决书原话的，第 6 列给不出具体依据的**，**该条不得进入上诉状**（铁律三）。

## 二、诊断一 · 期限诊

| 检查项 | 结论 |
|---|---|
| 裁判类型 | 判决 / 裁定（不予受理、驳回起诉、管辖权异议裁定可上诉） |
| 送达日期与送达方式 | 直接 / 邮寄 / 电子 / 公告；以送达回证为准 |
| 上诉期 | 判决 15 日 / 裁定 10 日，自送达之日起算（民诉法第171条） |
| 剩余天数 | 由 `scripts/deadline_check.py` 计算 |
| 我方原审地位 | 原审原告 / 原审被告 / 第三人 |
| 委托人主体 | 自然人 / 法人或非法人组织 |
| 一审是否本所代理 | 是（走情形 A）/ 否（情形 B）/ 仅代书（情形 C） |

**剩余 ≤3 天 → 进入紧急模式**：先出上诉状保期限，其余材料后补。

## 三、诊断二 · 主体·程序诊

逐项核对，命中任一即为上诉理由：

1. 遗漏必须参加诉讼的当事人（民诉法第177条1款4项 → 发回重审）
2. 违法缺席判决（同上）
3. 送达瑕疵：未合法送达、公告送达条件不具备、送达地址未经确认
4. 审判组织不合法：合议庭组成、独任制适用范围、审判人员应回避未回避
5. 程序申请未处理：回避申请、管辖异议、鉴定申请、调查取证申请、举证期限延长申请 —— 庭审笔录中提出但判决书未回应
6. 违反专属管辖（民诉法解释第329条 → 撤销原裁判并移送）
7. 不应受理而受理（民诉法解释第328条 → 撤销原裁判，驳回起诉）
8. 判决书内部自相矛盾：正文不同段落对同一事实的描述不一致
9. 未开庭径行裁判是否具备条件（民诉法第176条）

同时产出：《庭审笔录未尽事宜清单》（程序性未决事项 / 证据事项悬置 / 实体权利搁置三类）。

## 四、诊断三 · 诉请·判项比对诊

方法：把一审诉讼请求逐项列出，与判项逐项对照，每项打一个标。

| 打标 | 判定 | 二审攻击点 | 依据 |
|---|---|---|---|
| 判如所请 | 诉请全部获支持 | 无（我方为原告时无上诉利益） | — |
| 部分支持 | 只获部分支持 | 缺口金额／权利认定错误 | 民诉法第177条1款2项 |
| 判非所请／漏判 | 判决未就某项诉讼请求作出处理 | 遗漏诉请 | 民诉法第172条、第177条 |
| 超裁 | 判决超出诉讼请求范围 | 违反处分原则，法院超越当事人请求范围裁判 | 民诉法第13条第2款 |
| 判如所请但理由错误 | 结果对、说理错 | 仅说理纠正（改判阻力大，慎用） | 民诉法第177条1款2项 |

**产出物：《诉请—判项对照表》**（列：诉请原文 / 判项原文 / 打标 / 我方受损后果 / 是否上诉）。

**红线**：上诉请求**不得超出一审诉请射程**——二审新增独立诉讼请求只能调解或告知另诉（民诉法解释第326条）。写超等于白写。

## 五、诊断四 · 三段论诊（改判理由主战场）

### （一）大前提 —— 法律适用

- 援引法条是否现行有效？（用元典 `rh_ft_detail` 核验，注意是否已被修改／废止）
- 是否漏引应适用的法条？
- 法律关系识别 / 请求权基础是否错误？（此处在元典穷举候选法条，见 `元典检索姿势.md` 第 2 步）
- 有无更贴合本案事实的条文？一审未援引但更贴合，即为上诉点

### （二）小前提 —— 事实认定

对每一个待证事实填下表：

| 待证事实 | 判决认定 | 支撑证据（判决书所列） | 是否有证据缺失 | 是否已提交未采信 | 当事人核对意见 |
|---|---|---|---|---|---|

四步检验：
1. 对应性：认定的每个事实是否均有对应证据？
2. 充分性：证据是否达到相应证明标准？
3. 排他性：是否存在与认定相矛盾的证据未被采纳而法院未说明？
4. 合理性：采信是否遵循逻辑常理，有无断章取义或无理由排除？

另两项独立检查：
- 举证责任分配是否错误（一方未完成举证却被豁免／本应转移的举证责任未转移）
- 证明标准是否被抬高（结合待证事实类型与行业特征，论证现有证据已满足要求）

### （三）涵摄 —— 要件齐备性

每一项法律要件是否均有对应事实？有无要件缺失或事实涵摄不全？

### （四）结论 —— 唯一性与价值导向

- 在既有事实与法律下，是否还存在同样合理的其他结论？法院是否说明了排除其他结论的理由？
- 结论是否符合公序良俗、交易领域基本商业惯例或行业规则？

## 六、诊断五 · 说理诊

1. 判而不理：对关键抗辩、关键证据、关键当事人陈述未作回应
2. 说理与判项脱节：说理结论推不出判项
3. 同一证据被矛盾评价：同一份证据在不同段落获得相反评价
4. 对质证意见未作评判
5. 争议焦点漂移：判决书列示的争议焦点与庭审笔录中法官归纳的焦点不一致（新增／遗漏）

> 说理缺失本身可以独立作为上诉理由，但单独使用时改判阻力大，应与其他诊断结果合并主张。

## 七、诊断六 · 新要素诊

| 类型 | 检查 | 影响 |
|---|---|---|
| 新证据 | 一审庭审结束后新发现／新形成；一审已提交但未经质证且未作为裁判依据 | 决定二审是否开庭（民诉法第176条） |
| 新事实 | 判决书完全未提到但对案件重要的事实（只能来自当事人陈述） | 同上 |
| 新理由 | 一审未主张的法律适用路径：请求权基础重构、法律关系重构、法学理论深化 | 同上 |
| 逾期举证理由 | 是否符合法定正当理由（原审庭审结束前已存在但因客观原因庭审后才发现／已发现但客观原因无法取得或期限内不能提供／庭审后形成且无法另诉） | 理由不成立 → 不予采纳 |

举证期限参照：当事人提供新的证据的二审案件，举证期限不得少于十日（民诉法解释第99条第2款）。

## 八、汇流为三条流水线

```
事实线 ── 事实核对结果（当事人陈述／在案证据／二审新证据）
         ──→ 归类：认定错误 / 认定遗漏 / 认定无证据支持
         ──→ 每条挂：具体依据（当事人陈述 / 在案证据编号 / 新证据线索）

法律线 ── 律师定方向 + 元典检索
         ──→ 归类：适用错误 / 应适用而未适用 / 援引法条失效 /
                  举证责任分配错误 / 证明标准误用
         ──→ 每条挂：法条原文 + 条文序号 + 类案案号

程序线 ── 期限诊 + 主体程序诊 + 诉请判项比对
         ──→ 归类：发回重审 / 撤销原裁判 / 指令立案或审理 / 超裁 / 漏判
         ──→ 每条挂：判决书段落 + 程序法条
```

三条线汇入《一审判决漏洞清单》。**映射不到二审法定处理方式（民诉法第177条）的，直接剔除**。
