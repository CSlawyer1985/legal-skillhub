# 合同智囊（Contract Advisor）

合同智囊（Contract review）是一款由广东知恒（大连）律师事务所高圣杰律师（V：gsj15940877933）开发的面向律师与法务的合同全生命周期 AI 助手。覆盖「审核—起草—比对—修订」四大流程，内置 21 类合同模板与风险规则库，支持 Word 原生 Track Changes 修订落痕，并提供批量审查、主从合同一致性校验、误报率质控看板等平台化能力。所有交付物附免责声明，定位为律师辅助工具而非法律意见替代。

## 核心能力

- **审核（Review）**：全量 / 增量审核，内置五步审查框架，自动生成双版本示范条款
- **起草（Draft）**：从零起草，支持「深度定制」（逐章确认）与「快速生成」（一键出稿）两种模式，覆盖 21 类合同
- **比对（Diff）**：对比 A / B 两个版本，识别增删改并分析条款效力影响
- **修订（Revise）**：四段式修订（原条款 → 简版 → 全版 → 理由），支持原生 OOXML Track Changes 写入原文件

## 平台化增强

- **反馈闭环**：定稿学习、误报率统计、规则反哺（rule-pack）
- **批量 / 组合审查**：同质合同汇总画像、主合同 + 补充协议一致性校验
- **质控指标看板**：审查次数、风险分布、类型覆盖、平均耗时与误报率
