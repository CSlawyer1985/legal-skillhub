# 合同模板库管理

## 目录结构

每个合同类型文件夹下存放该类型的标准模板文件：

```
template-library/
├── 买卖合同/
│   ├── _标准模板.md        ← 主模板（必须存在）
│   ├── 甲方主导模板.md
│   └── 乙方主导模板.md
├── 借款合同/
│   ├── _标准模板.md
│   └── ...
└── ...（其他17种合同类型）
```

## 导入模板方法

### 方法一：复制文件

将您的 `.docx` 或 `.txt` 格式合同文件复制到对应类型文件夹即可。

**命名规则：**
- 以 `_` 开头（如 `_标准模板.md`）= 主模板，优先比对
- 以 `甲方主导_` 开头 = 甲方视角模板
- 以 `乙方主导_` 开头 = 乙方视角模板
- 其他命名 = 辅助模板

### 方法二：告诉AI导入

直接对AI说：
```
"帮我把这份合同导入到合同库，类型是XX合同"
```

AI会自动解析内容并保存到正确位置。

### 方法三：粘贴文本导入

将合同文本内容粘贴给AI，注明合同类型，AI会自动整理入库。

## 模板格式要求

建议使用 Markdown 格式，包含以下结构化标记：

```markdown
# 合同标题

## 第一章 总则
（条款内容...）

## 第二章 主要权利义务
（条款内容...）

## 关键条款标记
<!-- KEY: 付款条款 -->
<!-- KEY: 违约条款 -->
<!-- KEY: 管辖条款 -->
```

## 规则包说明

rule-packs/ 目录存放专项审核规则：

| 文件 | 适用范围 |
|-----|---------|
| rule-pack-capital-bond.md | 银行资本债券 |
| rule-pack-hk-law.md | 香港法律 |
| rule-pack-ipo.md | 上市公司/IPO |
| rule-pack-banking.md | 银行监管 |
