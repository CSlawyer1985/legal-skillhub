## 一、合同审查总体思维框架

### 1.1 三大维度框架（合法性 → 合规性 → 合理性）

适用场景：法务/律师拿到一份合同后的全面评审

| 维度 | 核心问题 | 审核重点 |
|------|---------|---------|
| **合法性评审** | 合同是否合法有效？ | 主体资质、签约权限、主体信用、条款合法性、必备条款完整性、交易目的的合法性 |
| **合规性评审** | 是否符合公司制度？ | 项目审批流程、合作方遴选程序、与前期文件一致性、与公司制度适配性、用印签署合规 |
| **合理性评审** | 条款是否公平可落地？ | 权责划分对等、付款节奏合理、验收标准量化、违约责任全覆盖、知识产权/保密/质保条款完整 |

### 1.2 四维度通用审核标准

适用场景：通用快速审核，覆盖绝大多数合同

| 维度 | 审核点 |
|------|------|
| **法律法规** | 合同目的是否合法、主体是否有资质/授权、条款是否齐备（民法典470条9大核心条款）、损失是否有量化标准、是否存在违法无效条款、前置审批程序是否完成 |
| **公司制度** | 内部决策是否完成、供应商选定是否合规、合同内容是否与招标文件一致、审核流程是否合规、是否与公司制度冲突 |
| **国资监管**（国企专属） | 国资报批是否完成、资产评估备案是否完成、是否进场交易、是否存在股权代持/对赌/明股实债等违规条款 |
| **商业逻辑** | 主体是否经营异常/失信、付款条款/节点是否合理、是否有暂付权拒付权、是否有追偿机制、退出机制是否合理 |

### 1.3 1234框架（1中心 · 2目的 · 3步骤 · 4重点）

| 层次 | 内容 |
|------|------|
| **1个中心** | 以委托人为中心——围绕其商业目标、风险承受能力、交易场景展开 |
| **2个目的** | 防范风险 + 促进交易——在法律框架内为委托人争取最大利益，同时保障交易能落地 |
| **3个步骤** | 审前沟通（交易背景/合同地位/文本来源/工作要求）→ 正式审查 → 交付成果 |
| **4大重点** | 交易主体 → 交易内容（标的/数量/质量/价款）→ 交易方式（期限/地点/履行方式）→ 问题处理（违约责任/争议解决） |

## 二、合同审查九步法

| 步骤 | 审查内容 | 核心要点 |
|------|---------|---------|
| **第1步** | 审合同主体 | 核实对手合法性、真实性、履约能力；穿透式核查营业执照/资质/信用/授权 |
| **第2步** | 审鉴于条款 | 锁定交易背景与目的；事实陈述准确性；合同目的明确性（关联法定解除权） |
| **第3步** | 审合同标的 | 名称/规格/型号/等级/数量/权属清晰；涉及IP的需明确归属/授权范围/地域/期限 |
| **第4步** | 审权利义务 | 权利对等性、条款可操作性（时间节点/履行方式/前提条件）、陈述与保证 |
| **第5步** | 审违约责任 | 违约情形全面覆盖；责任方式明确（继续履行/违约金/赔偿损失）；违约金不超实际损失30% |
| **第6步** | 审效力与生效 | 生效条件（签章/条件成就）；生效时间；合同有效期 |
| **第7步** | 审解除与终止 | 约定解除权（在法定解除权外增设）；解除程序；解除后果处理 |
| **第8步** | 审争议解决 | 仲裁 vs 诉讼选择；管辖机构必须明确唯一；避免模糊表述 |
| **第9步** | 审附件附录 | 完整性（所有附件是否齐备）、一致性（与正文无矛盾）、签署（附件页也需签章） |

## 三、合同风险防控六类60要点清单

### 第1类：订立合同时（12点）
1. **无合同不交易**——完备书面合同是最基本保障
2. **有行动必留痕**——发票/送货单/汇款凭证/邮件/传真/信函妥善保管
3. **慎用善用公章**——完善公章管理制度，多页合同盖骑缝章
4. **慎用授权文书**——授权范围明确详尽，业务完成后收回未用文件
5. **离职通知相关客户**——办理交接时书面通知客户
6. **撤销问题合同注意时效**——知道撤销事由之日起1年内行使
7. **注意定金条款**——必须写明"定金"字样，区分"订金""保证金"
8. **保证条款要明确**——避免"负责解决""负责协调"等模糊表述
9. **注意保证性质**——明确"连带保证"或"一般保证"，否则默认连带
10. **注意保证时效**——保证期间内行使权利
11. **抵押经登记有效**——签署后立即办理登记
12. **质押要转移占有**——签署时立即办理交接手续

### 第2类：合同履行中（9点）
13. 企业换人不影响合同
14. 市场变化，解约须慎重
15. 付款方式须可靠（优先银行结算）
16. 验收异议及时提（书面方式，约定期限内）
17. 商业秘密要保护
18. 合理行使不安抗辩权（有确切证据→通知中止→等待担保）
19. 解除异议及时提（约定异议期限内书面提出）
20. 对方违约也须及时止损（减损义务）
21. 诉讼时效内必须有动作

### 第3类：企业治理（10点）
### 第4类：劳动用工（14点）
### 第5类：知识产权保护（10点）

## 四、违约条款设置核心规则

### 4.1 民法典核心条款
- **第584条**：损失赔偿额 = 实际损失 + 可得利益，但不超订立时可预见的损失
- **第585条**：违约金过低可请求增加，过高（超实际损失30%）可请求减少

### 4.2 违约条款五要素
1. **违约情形**：针对每项重要义务逐一设定，避免笼统表述
2. **违约金计算**：具体金额或清晰计算公式（如"每逾期一日按合同总金额千分之一"）
3. **违约金上限**：不超过实际损失30%（含守约方预期利益）
4. **扩充损失赔偿范围**：明确包含律师费、诉讼费、保全费等维权成本
5. **解除权联动**：逾期超过30日+催告后10日未履行 → 守约方有权单方解除

### 4.3 付款方保护策略
- 优先"先履约、后付款"模式
- 降低预付款比例，付款节点与履约成果挂钩
- 设置暂付权/拒付权（对方违约时）
- 发票条款：明确类型/税率/开具时间，未提供合规发票可拒付

## 五、争议解决条款30个细节（精要）

### 5.1 仲裁 vs 诉讼选择
| 仲裁 | 诉讼 |
|------|------|
| 一裁终局 | 两审终审 |
| 保密性强 | 程序公开 |
| 可选专业仲裁员 | 救济渠道更多 |
| 条款必须明确唯一仲裁机构 | 不得违反级别管辖和专属管辖 |

### 5.2 管辖条款核心规则
- **诉讼管辖优先约定己方所在地**
- 仲裁条款：必须写明唯一、具体的仲裁委员会全名
- 避免无效表述："守约方所在地""当地法院""可仲裁可诉讼"
- 完整条款："凡因本合同引起的争议，协商不成的，任何一方均有权向甲方所在地有管辖权的人民法院提起诉讼"
- 附加维权成本条款：违约方承担律师费/诉讼费/保全费/差旅费

## 六、合同审查五大标准（通用版）

| 标准 | 内容 |
|------|------|
| **合规性标准** | 符合法律强制性规定，不违反公序良俗 |
| **周延性标准** | 条款覆盖全部交易环节，无逻辑漏洞 |
| **可操作性标准** | 每项义务有明确时间/方式/标准，可量化、可检验 |
| **公平性标准** | 权利与义务对等，无显失公平条款 |
| **倾向性标准** | 在法律允许范围内照顾委托方利益 |

## 七、法务防背锅实践要点

### 7.1 当业务发来"不能修改"的合同
1. 如实出具书面风险提示（邮件/审核意见），不做口头沟通
2. 将风险分级提示：可接受风险 / 需业务确认风险 / 不可接受风险
3. 保留完整审核记录和沟通证据
4. 建议业务部门在风险确认书上签字

### 7.2 话术模板
- "经审核，该条款存在以下法律风险：[具体描述]，可能导致：[后果]。建议修改为：[示范条款]。"
- "如业务部门评估后认为风险可接受，请书面确认后推进。"

## 八、合同签署12种方式及效力

| 方式 | 定义 | 效力 |
|------|------|------|
| 正签 | 按实际签署日期签署 | 完全有效 |
| 补签 | 事后补签，落款日期=实际签署日期 | 有效，补正效力 |
| 倒签 | 事后补签，落款日期≠实际签署日期 | 有风险，但一般有效 |
| 代签 | 他人代为签署 | 需有明确授权 |
| 预签 | 先签字后补充内容 | 高风险 |
| 传签 | 各方分别签署后交换 | 有效 |
| 会签 | 各方同时在场签署 | 有效 |
| 亲签 | 本人亲自签署 | 完全有效 |
| 电子签 | 电子签名 | 满足《电子签名法》则有效 |
| 盖章 | 公章/合同专用章 | 有效（法人） |
| 草签 | 草案签字（未定稿） | 仅表示阶段性共识 |
| 骑缝签 | 多页合同每页或接缝处签章 | 防止换页 |

## 九、AI时代合同审查定位

> "律师应始终作为合同审查的把关人和最终决定人，AI只能是工具。"

- AI可辅助：条款检索、风险模式识别、示范条款生成、初步审查
- 律师必须做：商业判断、风险权衡、条款谈判、最终决策
- 核心价值：将"法律专业性"转化为符合委托人商业需求的"解决方案"
