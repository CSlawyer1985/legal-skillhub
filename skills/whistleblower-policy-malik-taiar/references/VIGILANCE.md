## 两种预警机制之间的差异

| 标准 | Sapin II 预警 | 尽职预警 |
|---------|-----------------|------------------|
| **门槛** | ≥ 50 名员工 | ≥ 5,000 / 10,000 名员工 |
| **对象** | 犯罪、轻罪、对公共利益的威胁、违反法律 | 对人权和基本自由、人身健康和安全以及环境（价值链）的严重侵害 |
| **范围** | 公司活动 | 活动 + 子公司 + 分包商 + 供应商 |
| **制定方式** | 可单方制定（咨询企业委员会 CSE） | **须与代表工会协商** |
| **可举报人员** | 员工、服务提供者、候选人等 | 利益相关者（社区、非政府组织、潜在受害者） |

---

## 两种机制的衔接（Sapin II 第 6 条 III）

**在实践中：**
- 同时受两项义务约束的公司可**共用**其举报渠道
- 尽职预警机制必须**与工会协商建立**（附加义务）
- 如**Sapin II 保护**（第 10-1 条）更有利则适用
- 尽职机制必须覆盖**更广范围**（价值链）

## CS3D 指令 (UE) 2024/1760——对机制的影响

欧洲尽职指令：

1. **修改指令 2019/1937**（举报人），将违反尽职义务的举报纳入保护范围

2. **规定通知程序**（第 14 条）：
   - 可访问、公平、可预测且透明
   - 向受影响人员、非政府组织、工会、工人代表开放
   - 可匿名和保密举报

**完整文本**：`assets/Directive_CS3D_2024_1760.pdf`

## 受尽职义务约束公司的专项检查清单

```
附加核验：

[ ] 预警机制已与代表工会协商建立
[ ] 范围扩展：子公司 + 分包商 + 供应商（既定商业关系）
[ ] 对象扩展：人权、基本自由、健康安全、环境
[ ] 外部利益相关者可举报（社区、非政府组织、潜在受害者）
[ ] 公布尽职计划和实施报告
[ ] 与 Sapin II 机制的衔接已记录

如 CS3D 指令适用（转化后）：
[ ] 通知程序符合 CS3D 第 14 条
[ ] 已采纳气候转型计划（CS3D 第 22 条）
[ ] 规定补救机制
```
