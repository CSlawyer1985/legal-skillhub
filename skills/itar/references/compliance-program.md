# ITAR 合规计划——处罚、VSD 与 TCP

## ITAR 合规计划要素

有效的 ITAR 合规计划（被 DDTC 认可为减轻处罚因素）包括：

### 1. 治理与领导
- 指定**授权官员（EO）**（22 CFR § 120.67）：有权签署许可证申请并确保 ITAR 合规的美国人士；必须担任高级职务，能够为合规原因推翻商业决策
- 由高级管理层签署的书面**ITAR 合规政策**
- 出口管制问题的明确升级路径
- 年度管理层对合规计划有效性的审查

### 2. 培训
- 所有可接触 ITAR 的员工在入职 **30 天内**接受**初始培训**
- **年度复习培训**，涵盖近期监管变化、执法行动和公司特定程序
- 面向以下人员的**岗位特定培训**：授权官员、运输/物流、工程/研发、法务、IT
- 培训记录保留 5 年

### 3. 技术控制计划（TCP）

TCP 控制对 ITAR 管制技术数据的访问，尤其是外籍人员的访问。

**TCP 章节：**
```
1. 目的与范围
2. ITAR 管制物品和数据清单
3. 物理访问控制（安全区域、访客陪同、徽章）
4. IT 访问控制（网络隔离、访问清单、加密）
5. 外籍人员筛选程序
   - 在雇佣/聘用时收集国籍信息
   - 对照被拒绝方清单筛选
   - 在授予访问权限前确定是否需要 TAA/许可证
6. 访客和承包商程序
7. 年度 ITAR 培训计划
8. 事件识别、报告和响应
9. 记录管理（5 年保留）
10. TCP 审查和更新周期（至少每年）
```

### 4. 筛选与尽职调查
对照以下清单筛选所有当事方（客户、供应商、员工、访客）：
- **DDTC 被取消资格方清单**（22 CFR § 127.7）
- **OFAC 特别指定国民（SDN）清单**
- **BIS 被拒绝人员清单、实体清单、未核实清单**
- **美国国务院观察名单**

筛选必须记录在案，并在每笔交易时重新执行。

### 5. 管辖与分类审查
- 对每件新产品、组件和软件进行正式的**产品分类流程**
- 记录分类决定（USML 引用或 EAR ECCN）并附理由
- 产品修改、用例变化或法规变化时重新审查分类
- 对含混物品考虑**商品管辖（CJ）**请求

### 6. 许可证管理
- 集中追踪所有有效许可证、TAA、MLA
- 发货前许可证审查检查清单
- 许可证条件合规（数量、最终用户、再出口限制）
- 及时续展许可证（追踪到期日并提前 90 天提醒）
- 发货后申报（自动出口系统 / 电子出口信息）

### 7. 审计
- 年度内部 ITAR 合规审计（或每 2-3 年第三方审计）
- 审计范围：注册时效、许可证合规、TCP 有效性、培训记录、筛选日志、记录保留
- 审计结果形成文件并附纠正行动计划及责任人

## 处罚——22 CFR 第 127 部分和 22 USC § 2778

### 民事处罚
- 每次违规最高 **$1,369,000**（金额依据《联邦民事处罚通胀调整法》每年调整）
- 每次无证出口、每次无证披露技术数据、每次经纪违规 = 单独违规
- DDTC 可通过同意协议施加民事处罚，无需刑事移送

### 刑事处罚
- 每次违规最高 **$1,000,000 罚款**（22 USC § 2778(c)）
- 每次违规最高 **20 年监禁**
- 刑事案件移送司法部；由 DOJ 国家安全司起诉

### 取消资格
- DDTC 可取消任何人参与 ITAR 的资格（22 CFR § 127.7）
- 期限：通常 3 年；情节严重可永久
- 取消资格导致：禁止注册、许可、参与 TAA/MLA、美国政府承包
- 公布于 DDTC 被取消资格方清单

### 其他后果
- **没收**涉案物品（22 USC § 2778(e)）
- 调查期间**暂停出口特权**
- 涉及外国政府的重大违规需**通知国会**
- **声誉损害**——同意协议公开披露

## 自愿自我披露（VSD）——22 CFR § 127.12

### 为何披露
VSD 是可用的最强减轻因素。DDTC 指引承认，拥有有效合规计划并自行发现和及时披露违规的公司应获得宽大处理。

### VSD 流程

**第 1 步——初步通知**（发现后约 30 天内）
- 向 DDTC 合规主任提交简要书面通知
- 包括：公司名称、注册号、潜在违规的一般描述、估计发生次数
- 请求时效中止协议，在调查进行期间保留诉讼时效

**第 2 步——内部调查**（30-90 天）
- 调查所有事实：谁知道什么、何时知道、出口/披露了什么、向谁
- 调取所有记录（许可证、运输文件、邮件、TAA 文件）
- 识别根本原因（流程失败、培训缺口、故意行为）
- 保全所有证据；适当时发布诉讼保留通知

**第 3 步——最终 VSD 报告**（初步通知后约 60-90 天内）
提交综合书面报告，包括：
- 所有违规的详细事实叙述
- 每次违规违反的 CFR 章节
- 所有涉事方识别
- 事件时间线
- 根本原因分析
- 已实施的纠正行动
- 拟议的额外补救措施

**第 4 步——DDTC 审查与解决**
- DDTC 审查报告；可要求补充信息
- 结果：不采取行动、警告信、民事处罚（通常减轻）、或移送刑事审查
- 最合作的 VSD 在 6-18 个月内解决

### 减轻因素
- 自愿自我披露
- 配合 DDTC 调查
- 有效的既有合规计划
- 及时补救
- 无先前 ITAR 违规
- 国家安全损害小
- 交易价值相对较低

### 加重因素
- 故意/蓄意违规
- 高级管理层参与或知情
- 损害国家安全
- 违规成模式
- 阻挠或缺乏配合
- 高风险最终用户（恐怖主义国家支持者、武器禁运对象）
- 先前违规

## DDTC 蓝灯最终用途监测

**蓝灯（Blue Lantern）**计划是 DDTC 的最终用途监测计划。美国使馆人员开展发货后核查，确认物品到达所述最终用户并按要求使用。

**对出口商的影响：**
- 充分配合蓝灯检查（不配合可触发许可证暂停）
- 维护准确的运输记录以利核查
- 在外国分销商合同中纳入配合义务
- 发现物品被转移或滥用时报告

## 检查清单——ITAR 合规计划就绪度

| 领域 | ✅ | 关键问题 |
|------|----|--------------|
| 注册 | | 注册是否有效？续展是否按时提交？ |
| 授权官员 | | 是否指定 EO 并附书面授权？ |
| 政策 | | 是否由高级管理层签署？ |
| TCP | | 是否有书面 TCP？最近 12 个月是否审查？ |
| 培训 | | 所有可接触 ITAR 的员工最近 12 个月是否受过培训？记录是否保留？ |
| 分类 | | 所有产品/组件是否正式分类？需要时是否取得 CJ？ |
| 筛选 | | 每笔交易是否进行 SDN/取消资格筛选？是否记录？ |
| 许可证追踪 | | 所有许可证是否登记？是否设置到期提醒？条件是否追踪？ |
| 记录保留 | | 5 年保留是否落实？审计是否可获取？ |
| 内部审计 | | 年度 ITAR 审计是否完成？结论是否追踪？ |
| 事件响应 | | VSD 程序是否记录并传达？ |
