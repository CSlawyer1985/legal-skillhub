# GB50500-2013 — 建设工程工程量清单计价规范审查核对表

## 规范概述

GB50500-2013《建设工程工程量清单计价规范》是建设工程计价领域的强制性国家标准，是合同审查中计价条款的主要对标依据。

## 逐章审查要点

### 第4章 工程量清单编制

| 条款 | 审查要点 | 风险等级 |
|------|---------|---------|
| 4.1.2 | 招标工程量清单是否作为合同文件组成部分 | 如未纳入 → 🟠 |
| 4.2.1 | 分部分项工程量清单项目特征描述是否完整 | 描述不清 → 🟡 |
| 4.2.2 | 工程量是否准确 | 重大偏差 → 🟠 |

### 第5章 招标控制价

| 条款 | 审查要点 |
|------|---------|
| 5.1.1 | 国有资金投资项目必须编制招标控制价 |
| 5.3.1 | 投标报价不得高于招标控制价，否则废标 |

### 第7章 合同价款约定

| 条款 | 审查要点 | 风险等级 |
|------|---------|---------|
| 7.1.3 | 单价合同/总价合同的选择是否与项目特点匹配 | 选择不当 → 🟡 |
| 7.2.1 | 合同价款中是否明确风险范围和风险费用计算方法 | 未明确 → 🟠 |

### 第8章 工程计量

| 条款 | 审查要点 | 风险等级 |
|------|---------|---------|
| 8.1.2 | 工程量计量周期和程序是否明确 | 未明确 → 🟡 |
| 8.2.1-8.2.5 | 单价合同的计量规则是否完整 | 缺失关键条款 → 🟠 |

### 第9章 合同价款调整（高频风险区）

| 条款 | 内容 | 合同审查要点 | 风险等级 |
|------|------|-------------|---------|
| 9.1.1 | 15项价款调整事项 | 合同是否遗漏了关键调整事项 | 遗漏 → 🟠~🔴 |
| 9.2.1 | 法律法规变化 | 基准日后的法规变化由谁承担 | 转嫁承包人 → 🔴 |
| 9.3.1 | 工程变更 | 变更价款的确定方法和时限 | 未明确时限 → 🟡 |
| 9.4.1 | 项目特征不符 | 不符时的价款调整方法 | 未约定 → 🟠 |
| 9.5.1 | 工程量偏差>15% | 超出部分的调价公式 | 未约定 → 🟠 |
| 9.6.1-9.6.3 | 物价变化 | 材料/设备价格波动的调整方法 | 固定价不调 → 🟠~🔴 |
| 9.7.1-9.7.2 | 暂估价 | 暂估价项目的定价和确认流程 | 流程不清 → 🟡 |
| 9.8.1-9.8.3 | 不可抗力 | 不可抗力导致的费用分担 | 全部转嫁承包人 → 🔴 |
| 9.10.1 | 提前竣工/赶工 | 赶工费和补偿 | 只要求赶工不补偿 → 🟠 |
| 9.11.1 | 误期赔偿 | 赔偿额度和上限 | 无上限 → 🔴 |
| 9.12.1-9.12.2 | 索赔 | 索赔程序和时限 | 过度限制 → 🟠 |
| 9.14.1 | 现场签证 | 签证确认时限 | 超过7天未确认 → 🟡 |

### 第11章 竣工结算与支付

| 条款 | 审查要点 | 风险等级 |
|------|---------|---------|
| 11.1.3 | 竣工结算编制依据是否完整 | 缺少依据 → 🟡 |
| 11.3.1 | 发包人审核结算的时限（通常28-60天） | 超60天或无时限 → 🟠 |
| 11.3.5 | 竣工结算价款的支付时限 | "审计完成后再付" → 🔴 |

## 常见违规条款

1. **约定"以审计结果为结算依据"** → 🔴 违反GB50500第11章精神，实质上是无限期拖延结算
2. **约定"工程量误差由承包人承担"** → 🔴 违反风险共担原则
3. **约定"材料价格不因市场变化而调整"** → 🟠 违反第9.6条物价变化调整规定
4. **约定"发包人不承担任何不可抗力费用"** → 🔴 违反第9.8条
