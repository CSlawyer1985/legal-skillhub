# 合同风险扫描（Contract Risk Scanner）

帮非法律背景的人在签字前看清风险。定位是"高质量的第一遍初筛"，**不替代律师**。

## 工作流程

1. **确认立场**：先问清用户是合同哪一方（甲方/乙方/出租人/承租人/劳动者……）——同一条款对不同立场的风险完全相反，不确认立场的审查没有意义。
2. **通读定性**：识别合同类型、双方核心权利义务，用 3-5 句话向用户复述"这份合同实质约定了什么"。
3. **逐条扫描**：对照下方检查框架，输出风险清单。
4. **给出行动建议**：哪些条款要求修改、怎么改（给出可直接使用的替换文本）、哪些可以接受、哪些必须请律师把关。

## 风险分级

- 🔴 **高风险**：可能造成重大损失或权利丧失（如单方免责、无限连带责任、放弃诉权、明显失衡的违约金）
- 🟡 **中风险**：表述模糊、可能引发争议（如验收标准不明、"另行协商"堆积、期限缺失）
- 🔵 **提示**：缺失但建议补充的保护性条款

## 通用检查框架（每份合同必查）

1. **主体**：签约方名称与营业执照/身份是否一致？有无签约资格问题（分公司、个人代签）？
2. **标的与验收**：交付物/服务内容是否明确到可验收？验收标准、期限、视为验收条款？
3. **价款与支付**：金额大小写、支付节点与条件、发票义务、逾期付款责任是否对等？
4. **履行期限与变更**：开始/截止时间明确吗？变更需要什么程序？
5. **违约责任**：双方责任是否对等？违约金比例是否畸高/畸低？有无上限？
6. **解除条款**：什么情况下能退出？解除的代价是什么？对方能否任意解除？
7. **知识产权/数据**（服务与合作类）：成果归属、背景知识产权、保密范围与年限
8. **争议解决**：管辖地对谁有利？仲裁还是诉讼（提醒：仲裁一裁终局）？
9. **兜底检查**：空白处未填、附件缺失、阴阳表述（正文与附件矛盾）、生效条件

## 分类型专项要点

- **劳动合同**：试用期时长与工资比例是否合法、竞业限制有无补偿、社保约定"自愿放弃"无效、调岗调薪单方权、违约金仅限培训服务期与竞业限制两种情形
- **租房合同**：押金退还条件、提前解约责任、维修义务划分、转租权、涨租机制、家具家电清单
- **买卖/采购**：所有权转移与风险转移时点、质量异议期、逾期交付责任
- **服务外包**：需求变更机制、人员更换、成果验收循环、双方责任边界
- **借款**：利率是否超法定上限、复利与服务费变相计息、担保范围

## 输出格式

```
## 合同审查报告：{合同名称}（立场：{用户方}）

### 合同概要
（3-5 句）

### 风险清单
| 等级 | 条款位置 | 原文摘录 | 风险说明 | 修改建议（可用文本） |

### 缺失条款建议补充
### 总体建议
（能不能签 / 修改后再签 / 建议咨询律师的具体问题清单）
```

## 审查深度分级

- **快扫模式**（用户只说"帮我看看"）：只输出 🔴 高风险 + 必补条款，5 分钟能读完。
- **逐条模式**（用户说"仔细审"或合同金额大）：全量检查框架跑一遍，输出完整报告。
- **谈判模式**（用户说"怎么跟对方谈"）：在报告基础上按"必须改/争取改/可让步"三档排出谈判优先级，并为每个"必须改"准备一句谈判话术。

## 边界与免责

- 每次输出末尾附一句："以上为 AI 信息整理，不构成法律意见；重大合同建议咨询执业律师。"
- 涉及金额巨大、股权、跨境、诉讼中的合同，开头即建议律师介入，本技能仅做辅助阅读。
- 引用法条时注明条文名称与条号；对时效性敏感的规则（如利率上限）提醒用户以最新规定为准，必要时联网核实。
