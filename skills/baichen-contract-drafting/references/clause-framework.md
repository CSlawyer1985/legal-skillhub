# 合同条款框架模板

## 一、通用合同条款框架

### 首部
- 合同名称
- 合同编号
- 签订日期与地点
- 当事人信息（名称、统一社会信用代码/法人番号、法定代表人、注册地址、联系人）
- 鉴于条款（交易背景与目的）

### 正文

#### 1. 定义与解释
- 核心术语定义
- 解释规则（标题效力、"包括"的含义、条款编号引用、附件效力优先级）

#### 2. 合同标的与服务范围
- 标的物/服务内容描述
- 范围边界（包含与不包含）
- 排他性约定（如适用）
- 分包限制（如适用）

#### 3. 数量、质量或服务标准
- 规格、数量、质量标准
- 服务水平指标（SLA）
- 行业标准引用
- 项目经理/联络人制度

#### 4. 价格/报酬与支付方式
- 费用构成（固定费用/按量计费/实报实销）
- 计价币种与汇率约定（涉外合同）
- 分期支付安排（预付款/进度款/尾款）
- 发票要求
- 税费承担（含代扣代缴、双边税收协定）
- 逾期付款违约金

#### 5. 履行期限、地点与方式
- 合同期限与续约条件
- 分阶段时间节点
- 履行地点
- 履行方式（亲自履行/允许分包部分工作）
- 各方配合义务

#### 6. 验收标准与方法
- 验收节点（分阶段验收）
- 验收标准
- 瑕疵处理（整改期限、费用扣减）
- 视为验收通过的情形

#### 7. 知识产权归属与许可
- 既有知识产权保留
- 新增知识产权归属
- 商标/标识使用许可（范围、规范、终止后处理）
- 第三方知识产权侵权处理

#### 8. 保密义务
- 保密信息范围
- 保密义务内容
- 保密例外
- 保密期限（协议终止后持续有效）
- 强制披露处理
- 数据跨境传输合规（涉外合同）

#### 9. 承诺与保证
- 双方各自保证（主体资格、授权、合规、不侵权）
- 反商业贿赂承诺

#### 10. 违约责任
- 分违约情形设定责任
  - 根本违约 → 单方解除权 + 违约金
  - 一般违约 → 整改 + 费用扣减
  - 延迟履行 → 按日违约金
- 违约金计算方式与上限
- 赔偿范围
- 减损义务

#### 11. 不可抗力
- 定义与范围
- 通知义务与期限
- 法律后果（免责、费用分担、解除权）
- 减损义务

#### 12. 合同变更与解除
- 变更程序（书面补充协议）
- 协商解除
- 单方解除权（各方的触发情形）
- 解除后的清算规则

#### 13. 法律适用与争议解决
- 准据法
- 争议解决方式（协商→仲裁/诉讼）
- 仲裁条款（机构、地点、语言、仲裁庭组成）或诉讼管辖
  - **法条锚点（《仲裁法》2025 年修订·主席令第 54 号·2026-03-01 施行）**：仲裁协议三要素 → **第 27 条第 2、3 款**（旧法第 16 条）；约定不明无效 → **第 29 条**（旧法第 18 条）；仲裁机构的协议选定 → **第 6 条**（条号未变）；可仲裁性 → **第 3 条第 1 款**、不可仲裁 → **第 3 条第 2 款**（旧法第 2 条）。法定用语统一为「**仲裁机构**」，机构专名（如「中国国际经济贸易仲裁委员会（CIETAC）」）保持不变。完整口径详见 ../baichen-contract-drafting/references/playbook.md §一·4。
- 争议期间的履约义务

#### 14. 通知与送达
- 通知方式（专人/快递/传真/邮件）
- 送达日认定
- 送达地址变更
- 涉外合同的双语通知要求

#### 15. 合同生效、期限与终止
- 生效条件
- 期限与续约
- 终止后义务

#### 16. 其他条款
- 完整协议
- 可分性
- 权利弃权
- 转让限制
- 关联公司定义
- 出口管制与制裁合规（涉外合同）
- 合同语言（涉外合同）
- 合同份数
- 附件清单

### 尾部
- 签署页（签字、职务、日期、盖章）
- 附件

## 二、常见合同类型特有条款

### 买卖合同
- 标的物所有权转移时点
- 风险转移（交付时/验收时）
- 质量保证期/保修期
- 退换货条件

### 技术开发/委托开发合同
- 里程碑交付与验收
- 源代码/技术文档交付
- 知识产权归属（委托方/开发方/共有）
- 技术改进的权利归属
- 竞业限制/非招揽

### 服务合同
- 服务水平指标（SLA）
- 最低服务时长保证
- 人员资质要求
- 替换人员程序

### 合作/合资合同
- 出资方式与比例
- 利润分配与亏损分担
- 经营管理权分配
- 退出/回购机制
- 优先购买权

### 许可/特许经营合同
- 许可范围（地域/领域/排他性）
- 许可费计算方式
- 质量控制
- 最低经营指标
- 许可终止后处理

### 建设工程合同
- 工程范围与设计变更
- 工期与里程碑
- 工程款支付（预付/进度/结算/质保金）
- 竣工验收
- 缺陷责任期与保修

## 三、涉外合同特别条款

| 条款 | 要点 |
|------|------|
| 法律适用 | 明确约定准据法，避免"最密切联系地法"的不确定性 |
| 争议解决 | 优先评估仲裁（纽约公约缔约国间仲裁裁决可跨境执行），附利弊分析；评估前须先过可仲裁性关 →《仲裁法》（2025 年修订）**第 3 条第 1 款**（可仲裁）／**第 3 条第 2 款**（不可仲裁） |
| 判决/裁决执行 | 评估对方国家是否有承认与执行中国判决/裁决的机制 |
| 货币与支付 | 计价币种、汇率约定、跨境汇款费用分担 |
| 税务 | 代扣代缴义务、双边税收协定适用 |
| 数据跨境 | 各国个人信息保护法的合规要求 |
| 出口管制 | 适用国家的出口管制和制裁合规 |
| 合同语言 | 双语文本的效力优先级 |
| 通知送达 | 国际快递/电子邮件的送达认定 |
