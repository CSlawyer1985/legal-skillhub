# 合同起草

根据交易需求从零起草专业、完整的合同，遵循七步法**领域识别→提纲确认→确认需求→法律调研→条款设计→风险扫描→文档生成**。新增"提纲确认"阶段：AI先输出起草提纲（合同结构+关键条款清单）供用户确认，避免大段返工。本技能为水平基础层，垂直技能为领域深化层。

**基座前置｜检索分级（B层试点·2026-09-04）：§0 订阅检测＋引用前核验（§2.1.1 三态/AI防幻觉）所有档位强制，不得降级。调研深度按案情风险分档：①高风险（涉新司法解释/新法施行初期/交易金额重大/对方可能援引新规）→ 双源强制（百宸库+互联网各≥2组+深度fetch≥2-3件）；②常规（无①情形）→ 单源主检≥2组＋另一源抽查1次交叉验证关键条号与规则时效。

### 强制性法规更新核对（2024-2025·条款须以最新为准）
法律调研须覆盖已生效新规，避免引用已废止/修订条文：
- **民法典合同编通则司法解释**（法释〔2023〕13号·2023-12-05施行）：格式条款订入与提示说明（第9-10条）、名实不一/阴阳合同按真实关系认定（第14-15条）、违约金司法酌减以损失为基础兼顾主体/履行/过错（第65条第1款；"超过造成损失30%"量化起点见第65条第2款，恶意违约一般不调减见第65条第3款；调减请求权基础为《民法典》第585条第2款）、情势变更"重大变化"认定与变更/解除裁判（第32条；再协商义务见《民法典》第533条第1款，第32条第3款仅将重新协商情况列为判项考量因素）、印章/越权担保相对人善意（第20-22条）。
- **新公司法**（2023年修订·主席令第十五号·2023-12-29公布·2024-07-01施行）：认缴出资五年内缴足（第47条第一款第二句）、决议撤销60日（第26条）、股东查阅会计账簿及凭证并可委托中介（第57条）、董监高忠实勤勉与关联交易回避（第180-185条）、横向人格否认（第23条第2款）。

## Phase 0.5起草提纲确认（新增·强制）

**在进入 Phase 1 领域识别和条款设计之前，必须先生成起草提纲并获用户确认。**

### 提纲内容

| # | 要素 | 说明 |
|:--:|------|------|
| 1 | 合同类型 | 根据交易需求识别的合同类型 |
| 2 | 合同结构 | 预计章节/条款编号体系 |
| 3 | 关键商业条款 | 标的/对价/支付节奏/履行期限/交割安排（留空待用户填写）|
| 4 | 条款分类 | 核心条款（必含）/ 标准条款（建议含）/ 可选条款（按需）|
| 5 | 风险预判 | 根据合同类型预判的高风险条款和应对策略 |

> **风险分级口径（#9）**：本表第 5 项「风险预判」及全技能「高/中/低风险」表述，统一适用 `ndr-standards.md` §9 风险评级统一标准，术语对应为 **P0（高风险）/ P1（中风险）/ P2（低风险）**，不得自行另设评级。详见 `ndr-standards.md` §9。

### 确认规则

1. 输出提纲 → ask_user 逐项确认或修改
2. 用户确认后 → 将确认结果作为 Phase 2-5 的约束条件
3. 用户修改后 → 以修改版为准，不得自行恢复原方案
4. 用户要求跳过 → 记录"用户跳过提纲确认"，直接进入 Phase 1

## Phase 1领域识别与上浮判断（强制）

**先确定合同类型与适用分析框架。**

### 1.1 合同类型识别

根据交易需求识别合同类型（七步法适用于所有合同类型）。

### 1.1.1 领域合同速查表

| 领域 | 合同类型 | 核心条款 | 替代方案 |
|------|---------|---------|---------|
| 买卖 | 货物买卖合同 | 标的/数量质量/交付/验收/价款/违约责任 | 框架协议+单次PO |
| 服务 | 服务合同/外包 | 服务范围SOW/SLA/计费/知识产权归属/终止 | 人月合同/MSP协议 |
| 技术 | 技术开发/许可 | 开发里程碑/交付物/验收标准/IP归属/不竞争 | 开源+商业授权 |
| 租赁 | 商业租赁/设备租赁 | 租赁物/租期/租金调整/维修/提前解约 | 融资租赁 |
| 劳动 | 劳动合同/竞业限制 | 岗位薪酬/保密/竞业期限补偿/IP归属 | 顾问协议 |
| 投融资 | SPA/SHA/JVA | 估值/交割条件/对赌回购/反稀释/领售 → **归 `重大交易`**（含交割先决条件/对赌/反稀释，合同起草不承接） | 可转债/SAFE（简单投资协议可由合同起草处理） |
| 跨境 | 经销/代理/合资 | 区域排他/定价/终止/IP/适用法律/争议解决 | 战略联盟MOU |

> **使用**：Phase 0.5 提纲确认时参照对应领域核心条款快速搭建合同骨架。领域不在表内→按通用七步法。

### 1.2 上浮判断垂直技能分流

| 触发关键词 | 对应垂直技能 | 说明 |
|-----------|------------|------|
| 交割先决条件 / 对赌 / 多层次赔偿 | **重大交易** | 重大交易交割安排、对赌机制、多层次赔偿责任设计 |
| 治理安排 / 股权激励 | **公司治理** | 公司治理结构、股权激励方案设计 |
| 竞业 / 裁员 / 解雇 / 员工手册 | **劳动人事** | 竞业限制、裁员方案、解雇合规、员工手册制定 |
| PIA / 数据出境 / 分类分级 | **数据合规** | 个人信息保护影响评估、数据出境安全评估、数据分类分级 |
| 商标 / 专利 / 商业秘密布局 | **知识产权管理** | 商标战略、专利布局、商业秘密保护体系 |
| FDI / ODI / VIE / 负面清单 | **跨境投资** | 外商直接投资、对外直接投资、VIE架构、外商投资负面清单 |
| 遗嘱 / 离婚 / 婚前 / 婚内 / 继承 / 遗赠 / 意定监护 | **婚姻家庭与继承** | 婚姻家庭与继承文书起草，须加载 婚姻家庭与继承 技能处理 |

**处理规则**识别到触发关键词后，先完成 Phase 1 合同类型识别，再加载对应垂直技能进行领域分析，最后回到本技能完成 Phase 2-5 及文档生成。**注意：** 命中 婚姻家庭与继承 触发词时，直接移交 婚姻家庭与继承 技能处理，不再回到本技能。

### 1.3 交叉场景识别

| 场景 | 主维度 | 关联维度 | 处理规则 |
|------|:--:|------|---------|
| 股权激励协议（劳动合同关联） | 劳动人事 | 公司治理 | 劳动人事 处理劳动法合规，公司治理 处理激励方案设计 |
| 并购协议（含交割先决条件+竞业） | 重大交易 | 劳动人事 | 重大交易 处理交易安排，劳动人事 处理竞业限制合规 |
| 数据资产转让协议 | 合同起草 | 数据合规 | 合同起草 起草主协议，数据合规 审查数据合规 |
| 合资企业设立（FDI+治理） | 跨境投资 | 公司治理 | 跨境投资 审查外资准入，公司治理 设计治理架构 |
| 知识产权许可+技术转让 | 知识产权管理 | 合同起草 | 知识产权管理 处理知识产权布局，合同起草 起草许可协议 |

### 1.4 无法明确归类的兜底

输入信息不足以判断时，按以下优先级询问用户

> "请确认
1. 本次合同的主要交易类型是？（买卖/服务/技术/建工/租赁/委托/其他）
2. 是否涉及以下领域A.交割先决条件/对赌 B.治理安排/股权激励 C.竞业/裁员/解雇 D.数据合规 E.知识产权布局 F.跨境投资 G.婚姻家庭（遗嘱/离婚/财产协议/继承）
3. 如涉及多个领域，请一一说明，我将协调对应技能处理。"

如不确定，参见 `ndr-standards.md` §11 功能相近技能边界表。

## 条款资源管理（Playbook 与 Clause Library 分离）

本技能与 合同审查 共享条款资源，但遵循**素材与规则分离**原则：

| 文件 | 定位 | 内容 | 归属 |
|------|------|------|------|
| `references/playbook.md` | **Playbook（决策规则库）** | 什么情况下用什么条款、什么风险等级对应什么方案 | 合同起草 + 合同审查 共用 |
| `references/clause-framework.md` | **Clause Library（条款素材库）** | 按主题存储的标准条款文本（理想版/平衡版/底线版三档） | 合同起草 维护，合同审查 只读 |

**调用规则**：
- 起草合同 → 先查 Playbook 确定条款选型 → 再从 Clause Library 取对应文本
- 审查合同 → 先查 Playbook 确定审查基线 → 再对照 Clause Library 出替代方案
