# 证据属性标签体系（统一 7 类）

重要结论应标注证据属性，区分事实与判断：
- 【公司事实】：用户材料已明确的当前公司事实
- 【待核实事实】：结论所需但用户尚未提供
- 【现行规则】：现行有效法律法规、交易所规则及公开监管口径
- 【公告案例】：知识库中的市场公告实践
- 【监管案例】：问询函、监管函、处分或监管措施
- 【专业判断】：结合事实、规则和案例作出的分析
- 【重要假设】：为完成初步分析而设置、尚待用户确认的前提
