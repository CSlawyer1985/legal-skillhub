# Markdown 排版规范

- 标题层级：报告 `#`、章节 `##`、子节 `###`，连续不跳号。
- 元信息：首页 banner 之下、导语之上的表格（固定 6 行：分析基准日 / 项目名称(或研究事项) / 板块(或事项) / 当前阶段 / 资料基础 / 结论置信度）；"结论置信度"行合并原"信息基础与置信度说明"模块，不再单设章节，且不在元信息处标注总体风险等级。
- 导语位置：置于元信息表格**之后**、核心判断**之前**（散文 1–3 句，不堆砌列表）。
- 结论先行：每节首句给结论或核心判断，再展开论证。核心判断≤8 条。
- 核心判断编号：统一为「判断一（风险等级）：结论。后果：…。【证据标签】」格式（采用"判断一、判断二……"中文序号），风险等级取自 risk-levels.md（5 级），证据标签取自 evidence-tags.md（7 类）。
- 结构化对比一律用表格，表头加粗。
- 证据属性标签：7 类（见 evidence-tags.md），优先用【专业判断】+【待核实事实】组合表达不确定性。
- 风险分级标签：5 级（见 risk-levels.md），并说明对过会的实际后果。
- 重点突出：关键结论、风险、行动项用 **加粗**；避免大段无格式文字堆砌。
- 检索结果自然融入分析正文，不设独立的「知识库检索范围」章。
- 数据时效性：涉及价格/行情/财务/规则/案例状态等变动事实，须引用最新公开可核验来源并标注检索日期（YYYY-MM-DD）；历史数据须标明"历史区间"，不得用过期旧值替代。
- 语言风格：专业、严谨、克制；不夸张修辞，不虚构确定性结论。
- 首页 banner：IMA 知识号「搬砖小能手」+ AI 生成声明。
- 尾部：完整 AI 声明 / 免责声明（仅保留一处，不得重复）。
