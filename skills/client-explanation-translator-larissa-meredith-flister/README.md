将复杂的法律分析转化为清晰、具有商业实用性的面向客户建议。每当用户有密集的法律材料——起草文件、内部分析、顾问笔记、研究备忘录、诉状、案件更新或往来函件——并希望将其转换为客户真正能理解和据此行动的内容时使用。触发短语如“explain this to the client”（向客户解释这个）、“put this in plain English”（用通俗英语表达）、“translate this for a non-lawyer”（为非律师翻译这个）、“turn this into client-facing advice”（将其转化为面向客户的建议）、“make this client-ready”（使其可交付客户）、“draft a client update”（起草客户更新），或当用户分享法律分析并问“what does this mean for them”（这对他们意味着什么）时。当用户想要源自法律材料的董事会摘要、诉讼风险更新或通话脚本时也触发。本技能保留法律细微差别、不确定性和风险，而非过度简化——它让建议可用，而不只是更简单。
