# 工伤赔偿计算器 (work-injury-calculator)

当用户说「工伤赔偿 / 工伤能赔多少 / 伤残等级 / 一次性伤残补助金 / 停工留薪期 / 工伤认定 / 劳动能力鉴定 / 公司没给我交工伤保险 / 工亡待遇」时触发。

## 适用场景
工伤认定下来了，伤残等级也评了，接下来最现实的问题是"到底能拿多少、找谁拿"。这个技能把《工伤保险条例》规定的每一项待遇代入本人工资和社平工资算出金额，并且逐项标明支付主体。

它解决的具体困境：
- 只知道有个"一次性伤残补助金"，不知道解除劳动关系还能再拿两笔
- 单位说"社保都赔给你了"，不知道就业补助金和停工留薪期工资本来就该单位出
- 单位没参保，不清楚这种情况下待遇由谁承担
- 高薪或低薪，不知道本人工资要按 300% 封顶或 60% 保底折算
- 家属遇到工亡，供养亲属抚恤金怎么分不清楚

## 本技能的核心：钱从两个口袋出（务必在输出里说清）

**工伤保险基金支付**：一次性伤残补助金、一至四级伤残津贴、生活护理费、一次性工伤医疗补助金、工伤医疗费、辅助器具配置费、丧葬补助金、供养亲属抚恤金、一次性工亡补助金

**用人单位支付**：停工留薪期工资及护理、五至六级难以安排工作时的伤残津贴、一次性伤残就业补助金

**单位未依法参保**：上述全部待遇由用人单位承担，工伤认定书即为索赔依据（《工伤保险条例》第 62 条）

只向单位要，或者只向社保要，都会漏掉另一半。这是工伤案件里最常见的损失。

## 另一个必须区分的：一次性待遇 vs 按月待遇

伤残津贴、生活护理费、供养亲属抚恤金是长期按月发放的，不能并入一次性金额。本技能把两类待遇分表列出，绝不混加。

原因很实际：把按月待遇折进总数，谈判时容易被对方用一个打折的一次性数字打发掉，而一至四级伤残的津贴是要发到退休转养老金的，折价买断往往吃大亏。

## 输入规范（逐项问全）
必填：
- 伤残等级（1-10 级，以劳动能力鉴定委员会结论为准）或是否为工亡案件
- 本人工资：受伤前 12 个月平均月缴费工资
- 统筹地区上年度职工月平均工资（用于 300% 封顶、60% 保底判断，以及护理费和补助金基数）
- 单位是否依法缴纳工伤保险
- 是否解除或终止劳动关系（5-10 级触发两项一次性补助金）

选填：
- 停工留薪期月数（一般不超过 12 个月，伤情严重经确认可延长不超过 12 个月）
- 生活护理等级：完全不能自理 / 大部分不能自理 / 部分不能自理
- 当地最低工资（一至四级伤残津贴的保底线）
- 已自付的工伤医疗费、辅助器具配置费、鉴定费
- 本省规定的两项一次性补助金计发月数与计发基数
- 工亡案件：上一年度全国城镇居民人均可支配收入、供养亲属名单及比例

## 输出规范（每次按这个结构）
1. 计算基数：本人工资是否触发封顶或保底，说明折算过程
2. 一次性待遇明细：项目、金额、支付主体、算式、条文依据，逐项列全
3. 一次性合计，并拆分为"基金支付多少 / 单位支付多少"
4. 按月长期待遇：单独一表，标明月标准和支付主体
5. 办理路径：工伤认定 → 劳动能力鉴定 → 向社保申领 → 向单位主张
6. 时间节点提醒与免责声明

## 关于地区差异（必须主动提示用户）
一次性工伤医疗补助金和一次性伤残就业补助金的计发月数、计发基数由各省《工伤保险条例》实施办法规定，省与省之间差距很大：有的省按统筹地区社平工资计发，有的省按本人工资计发；同样是十级，有的省合计不到十个月工资，有的省超过二十个月。

本引擎内置的是多省常见参考值，输出时必须提醒用户按本省标准核对，或直接询问用户所在省份后覆盖参数。

## 成果物（这是本技能的交付重点）
计算完成后，运行 `scripts/calculator.py` 的 `to_html_report()` 生成一份《工伤保险待遇测算报告》：
- A4 版式的自包含 HTML 文件，含一次性待遇表、按月待遇表、支付主体标注、法律依据、办理路径、时间节点、报告编号
- 浏览器打开后按 Ctrl+P（Mac 为 Cmd+P）选择"另存为 PDF"，即得到一份可存档、可打印、可提交给单位或社保经办机构的正式测算报告
- 包内 `sample-report.html` 是一份真实生成的样例

## 边界与免责
- 不代理案件、不介入与单位的谈判、不承诺任何核定结果
- 伤残等级须以劳动能力鉴定委员会的鉴定结论为准
- 两项一次性补助金的实际金额以本省标准和社保经办机构核定为准
- 涉及工亡、一至四级伤残、单位拒不配合工伤认定或否认劳动关系的，明确建议委托律师
- 每次输出结尾附免责声明与"12333 社保热线 / 12348 法律援助"提示
