# 工伤赔偿计算器

工伤认定下来了，等级也评了，接下来的问题是：到底能拿多少，找谁拿。这个技能把两个问题一起回答。

## 它做什么

输入伤残等级、本人工资、社平工资和是否解除劳动关系，输出：

- 逐项待遇金额，**每一笔标注由工伤保险基金还是用人单位支付**
- 一次性待遇与按月长期待遇分开列，不混加
- 一份 A4 版式的测算报告，可打印、可存 PDF、可提交给单位或社保经办机构

## 为什么需要它

工伤最常见的损失不是算错金额，是**找错人**。

待遇从两个口袋出：一次性伤残补助金、一次性工伤医疗补助金走工伤保险基金；停工留薪期工资、一次性伤残就业补助金由用人单位掏。很多人去社保领完就以为结束了，单位那部分从来没提过——以包里案例一为例，那是 122,000 元，占总额的 43%。

还有三个容易吃亏的点：

**本人工资要折算。** 高于社平三倍按三倍算，低于六成按六成算。案例四里低薪职工按保底计算，一次性伤残补助金多出 2,800 元。

**停工留薪期工资不封顶。** 它按"原工资福利待遇不变"发放，高薪职工这一项别自己先打折——案例二里这一条差了 12 万。

**按月待遇不能折价买断。** 一至四级的伤残津贴要发到退休，案例二那个月标准 32,000 元，二十年七百多万，任何一次性方案都要先算清楚再谈。

## 包含什么

| 文件 | 内容 |
|------|------|
| SKILL.md | 技能定义、触发词、输入输出规范、支付主体分账规则 |
| formulas.md | 全部公式速查：封顶保底、各级补助金月数、伤残津贴、护理费、工亡待遇、时间节点 |
| examples.md | 四个完整案例（九级离职结算、一级高薪封顶、工亡多亲属、未参保），数字均由引擎实跑 |
| scripts.md | 维权沟通话术：单位不申报怎么办、否认劳动关系怎么办、买断方案怎么判断、投诉还是仲裁 |
| disclaimer.md | 免责边界与省际差异说明 |
| scripts/calculator.py | 计算引擎，Python 3.8+，无第三方依赖 |
| scripts/report.py | A4 报告渲染器 |
| sample-report.html | 一份真实生成的报告样例 |

## 怎么跑

```bash
python scripts/calculator.py
```

输出案例一的完整测算并在当前目录生成 HTML 报告。浏览器打开后按 Ctrl+P 选"另存为 PDF"。

## 一个必须说清的局限

一次性工伤医疗补助金和一次性伤残就业补助金的计发月数、计发基数，由各省《工伤保险条例》实施办法各自规定，省与省之间能差出一倍。引擎内置的是多省常见参考值，用的时候一定要按本省标准覆盖参数——`medical_subsidy_months` 和 `employment_subsidy_months` 两个字段可以直接传入。

## 不做什么

不代理案件，不介入与单位的谈判，不承诺任何核定结果。伤残等级以劳动能力鉴定委员会结论为准。涉及工亡、一至四级伤残、单位否认劳动关系的，找执业律师。
