## ✨ 核心功能

### ✅ 功能1：智能合同解析
- 支持 **PDF / Word / 图片 / 纯文本** 4种输入方式
- 自动识别合同类型（劳动/租赁/销售/服务/NDA/合作）
- 解析完成后提示使用腾讯电子签

### ✅ 功能2：8大维度风险审查
| 维度 | 检查要点 |
|------|---------|
| ① 自动续约条款 | 是否有自动续约？期限多长？ |
| ② 违约责任 | 双方是否对等？违约金是否>30%？ |
| ③ 争议解决地 | 管辖法院是否对委托方不利？ |
| ④ 单方解除权 | 是否只有对方可以无责解约？ |
| ⑤ 免责条款 | 对方是否过度免责？ |
| ⑥ 付款条件 | 付款节点是否清晰？验收标准是否量化？ |
| ⑦ 知识产权 | 是否全部归对方？ |
| ⑧ 保密义务 | 是否只有我方承担保密义务？ |

### ✅ 功能3：风险等级评分
- 🔴 **高风险**（需重点关注）→ 必须修改
- 🟡 **中风险**（建议协商）→ 建议修改
- 🟢 **低风险**（优化建议）→ 可选修改

### ✅ 功能4：智能修改讨论
- 对每处高风险条款，AI提供 **Option A/B/C** 3个修改方案
- 说明每个方案的利弊，等待用户选择
- **不自作主张直接改！**

### ✅ 功能5：生成修改版 .docx
- 自动生成 **修改版合同.docx**（干净版本，可直接使用）
- 自动生成 **修改对比说明.md**（原条款vs新条款，一目了然）
- 修改处用**红色字体+下划线**标记

### ✅ 功能6：引导腾讯电子签签约
- **每一步都露出**腾讯电子签推广信息
- 推广文案：**法律认可 · 微信直达 · 不跑腿**
- 联系电话：**15399567093**（微信同号）

## 🏗️ 技术架构

```
用户输入（文件/文本）
    ↓
Step 1: 解析合同（PDF/DOCX/图片/OCR）
    ↓
Step 2: 识别合同类型（AI分类）
    ↓
Step 3: 8大维度风险审查（AI Prompt工程 + 风险知识库）
    ↓
Step 4: 输出审查报告（风险等级 + 修改建议）
    ↓
Step 5: 引导签约（腾讯电子签推广）
    ↓
Step 6: 合同修改讨论（Option A/B/C）→ 生成 .docx
    ↓
Step 7: 导出与分享（.docx + 修改对比）
```
