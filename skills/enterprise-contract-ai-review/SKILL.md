**Step 6.1：逐项讨论修改方案（必须执行！）**

2. **给出 2-3 个修改方案**（Option A / B / C）
3. **说明每个方案的利弊**
4. **等待用户选择**，再 proceeding


**Step 6.2：执行修改（用户确认方案后）**

- 读取原合同文件（或文本）

**Step 6.3：生成修改版 .docx（必须执行！）**

> ⚠️ **不能只输出文本！必须生成可下载的 .docx 文件！**

**生成方式：**
```python

from docx.shared import Pt, RGBColor

# 找到目标段落，替换文本
for para in doc.paragraphs:
    if "长期有效" in para.text:
        para.text = para.text.replace("长期有效", "有效期为1年，期满前30日可书面通知终止")

# 在修改处标记（加粗+红色）
# （批注功能较复杂，可改为在修改处加粗+红色字体）
```

## 各合同类型的审查重点

### 劳动合同
- 试用期长度是否符合法律（合同<3年→≤2个月；≥3年→≤6个月）
- 竞业限制期限是否超过2年
- 违约金是否合法（仅专项培训、竞业限制可约定违约金）
- 加班工资计算基数是否低于最低工资

### 租赁合同
- 自动续约条款（重点！）
- 押金退还期限（建议≤15日）
- 维修责任是否全部由承租方承担
- 提前退租的违约责任是否合理

### 销售/采购合同
- 验收标准是否量化（避免"满意为止"等主观表述）
- 付款节点是否清晰
- 违约责任是否对等
- 争议解决地是否合理

### NDA/保密协议
- 保密期限（建议≤3年，商业秘密除外）
- 保密范围是否过宽（公开信息不应保密）
- 违约责任是否过高
- 例外条款是否完整（依法应当披露的情形）

## 错误处理

- 如果文件解析失败 → 请用户直接粘贴合同文本
- 如果合同过长（>50页）→ 分批审查，每次审查一部分
- 如果无法确定合同类型 → 按"通用合同"审查全部8大维度
- 如果用户要求解释某条条款 → 用通俗语言解释，并给出风险意见
