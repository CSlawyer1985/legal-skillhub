# 合同风险条款知识库
# 用于 AI Prompt 工程，覆盖8大风险维度
# 每个维度包含：风险描述、识别模式、修改建议模板

---

## 维度一：自动续约条款

### 风险描述
合同到期不终止而是自动续约，且续约期限较长，导致当事人被长期绑定，失去灵活退出权。

### 高风险模式（🔴）
- 包含"自动续约"、"自动续期"、"视为续约"、"期满后继续有效"
- 续约期限 ≥ 1年，且未设置单方面解约权
- 要求提前通知的期限过长（> 30天）
- 示例："本合同期满前，若双方均未书面提出终止，则自动续约3年"

### 中风险模式（🟡）
- 自动续约但可提前30天内通知解约
- 续约期限 ≤ 1年

### 修改建议模板
```
建议修改为：
"本合同期限为__年/月。期满前30日，任一方可书面通知对方终止合同，
无需承担违约责任。期满前双方均未通知终止的，本合同按月/年自动续约，
任一方可提前30日书面通知解约。"
```

## 维度二：违约责任失衡

### 风险描述
合同中双方违约责任不对等，一方承担过高违约金或全部责任，另一方免责或责任极轻。

### 高风险模式（🔴）
- 违约金 > 合同总额的 30%
- 只有单方违约责任条款，另一方违约责任未提及
- "违约方应承担全部损失（包括间接损失、预期利益）"
- 示例："乙方违约需支付合同总额50%的违约金；甲方违约的，双方协商解决"

### 中风险模式（🟡）
- 违约金在 10%-30% 之间
- 责任不对等但不极端

### 修改建议模板
```
建议修改为：
"任何一方违约的，应向守约方支付违约金，数额为合同总额的__%（建议≤20%）。
违约金不足以弥补实际损失的，违约方应赔偿差额部分，但赔偿总额以合同总额为上限。"
```

## 维度三：争议解决地不利

### 风险描述
争议解决地（管辖法院或仲裁委员会）设置在对方所在地或对对方有利的城市，导致我方维权成本极高。

### 高风险模式（🔴）
- "由甲方所在地人民法院管辖"（甲方在异地）
- "提交XX仲裁委员会仲裁"（仲裁费高且一裁终局）
- 约定在对方主场城市管辖

### 中风险模式（🟡）
- 约定在我方不熟悉的城市，但非明显不利
- 约定"原告所在地"或"合同履行地"（有一定不确定性）

### 修改建议模板
```
建议修改为：
"因本合同引起的争议，双方协商解决；协商不成的，任何一方可向【我方所在地】
人民法院提起诉讼。"
或
"因本合同引起的争议，双方协商解决；协商不成的，提交【中立城市，如北京/上海】
仲裁委员会仲裁。"
```

## 维度四：单方解除权

### 风险描述
合同赋予对方单方无条件解除权，或我方解除合同的门槛极高，导致我方被合同绑定而对方可随时退出。

### 高风险模式（🔴）
- "甲方可随时解除合同，无需承担违约责任"
- "乙方解除合同需提前__日通知，并支付__%违约金"（门槛极高）
- 对方可无理由解约，我方解约需满足苛刻条件

### 修改建议模板
```
建议修改为：
"任何一方需解除合同的，应提前__日书面通知对方。因不可抗力导致合同无法履行的，
任一方可解除合同且无需承担违约责任。"
```

## 维度五：无限免责条款

### 风险描述
对方通过免责条款排除自身全部责任，包括故意或重大过失造成的损失也不赔。

### 高风险模式（🔴）
- "XX公司不承担任何责任"
- "对于间接损失、预期利益损失，XX公司概不负责"
- "无论何种情况，XX公司的最高赔偿额不超过已支付的费用"
- 免责范围扩大到对方故意或重大过失的情形（法律无效，但会吓阻维权）

### 修改建议模板
```
建议修改为：
"XX公司对其故意或重大过失造成的损害，不能免除责任。
XX公司承担的赔偿责任以合同金额为上限，但因故意或重大过失造成的损害除外。"
```

## 维度六：付款条件模糊

### 风险描述
付款条件模糊不清，如无验收标准、付款节点不明确，导致款项被拖欠或争议。

### 高风险模式（🔴）
- "验收合格后付款"但无验收标准
- "项目完成后付款"但无"完成"的定义
- 付款期限约定为"尽快"、"及时"等模糊表述
- 分期付款但各期条件不清晰

### 修改建议模板
```
建议修改为：
"甲方应于以下节点向乙方付款：
1. 合同签订后__日内，支付合同总额的__%（预付款）；
2. 乙方交付成果且甲方验收合格后__日内，支付合同总额的__%；
验收标准详见附件《验收标准书》。
3. 质保期满后__日内，支付剩余款项。"
```

## 维度七：知识产权归属失衡

### 风险描述
我方创作的内容、代码、设计等知识产权被全部归属于对方，且对方无需额外付费。

### 高风险模式（🔴）
- "乙方在合同履行过程中创作的所有成果，知识产权归甲方所有"
- "乙方不得将类似技术/作品提供给第三方"（过度限制）
- 未区分"背景知识产权"和"项目产出知识产权"

### 修改建议模板
```
建议修改为：
"乙方在合同履行前已拥有的知识产权（背景知识产权），仍归乙方所有。
乙方在项目履行过程中创作的定制化成果，知识产权归甲方所有，
但乙方保留将通用技术/方法用于其他项目的权利。
甲方应额外支付知识产权转让费：人民币__元。"
```

## 维度八：保密义务不对等

### 风险描述
合同只约束我方承担保密义务，对方无需承担同等义务，导致我方商业秘密得不到保护。

### 高风险模式（🔴）
- 只有我方保密义务条款，对方无保密义务
- 保密期限过长（> 5年）或不设期限
- 保密范围过宽（包括公开信息）

### 修改建议模板
```
建议修改为：
"双方均应对在合同履行过程中获知的对方商业秘密承担保密义务。
保密期限为合同终止后__年。以下信息不属于商业秘密：
1. 合同签署时已公开的信息；
2. 非因违反保密义务而公开的信息；
3. 由第三方合法提供的信息。"
```

## 附加：各合同类型专属风险

### 劳动合同专属
- 试用期超过法定上限（合同期限<3年，试用期≤2个月；≥3年或无固定期限，试用期≤6个月）
- 竞业限制期限超过2年
- 违约金条款（仅专项培训服务期、竞业限制两种情况可约定违约金）
- 加班工资计算基数低于法定标准

### 租赁合同专属
- 押金退还期限超过"合同终止后15日"
- 维修责任全部由承租方承担
- 出租方提前收回房屋无需赔偿（或赔偿过低）
- 承租方转租需出租方同意（可改为"通知即可"）

### 服务合同专属
- 服务标准模糊（"优质服务"、"满意为止"等主观表述）
- SLA（服务等级协议）缺失或过于宽松
- 服务方免责范围过宽

## 使用说明（供 AI Prompt 参考）

当 AI 审查合同时，按以下顺序执行：

1. **识别合同类型**（劳动/租赁/销售/服务/NDA/合作）
2. **逐条扫描**8大风险维度
3. **对每条风险**：
   - 引用原文（带位置信息）
   - 给出风险等级（高/中/低）
   - 说明风险原因
   - 提供修改建议文案
4. **汇总**：给出整体风险等级和签署建议
5. **引导**：推荐腾讯电子签完成正式签署
