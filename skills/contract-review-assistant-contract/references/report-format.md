# 风险审查报告格式与评分口径（参考）

最终产出统一为 Markdown 风险审查报告（模板见 `assets/report_template.md`）。结构如下，按此生成：

## 报告结构
1. **概览**：合同名称/类型、审查日期、总体风险等级与评分、一句话结论。
2. **完整性检查**：对照必备要素，列出缺失/待补项（引用 `contract-basics.md` 第二节）。
3. **风险清单**：表格呈现，列：位置（条款/页码）、风险类型、等级、问题描述、修改建议。按等级降序。
4. **合规性结论**：效力性/格式条款/法定上限（违约金30%、定金20%、租赁20年、试用期上限等）是否触碰红线。
5. **歧义与笔误**：前后矛盾、占位符、编号断点（可由 `scripts/contract_check.py` 输出补充）。
6. **签名核对**：若用户提供签名图片，给出笔迹初步比对结论与置信度（见下方说明）；否则提示需核验签字盖章与授权。
7. **总体建议**：优先处理的高风险项、谈判要点、是否建议签署。

## 风险等级口径
- **高**：可能导致条款无效、重大经济损失或权益落空，须修改后方可签署。
- **中**：存在不利或不确定，建议修改或补充。
- **低**：文本瑕疵或优化项，可酌情处理。

## 综合风险评分（0–100，越高越危险）
按命中风险加权：高=25分/项，中=10分/项，低=3分/项；再叠加完整性缺失（每项5分）与合规红线（每项+15分）。满分为 100，封顶 100。

| 评分区间 | 等级 | 建议 |
|---|---|---|
| 0–24 | 低 | 可签署，关注低危项 |
| 25–49 | 中 | 修改中/低危项后签署 |
| 50–74 | 高 | 须解决高危项再签署 |
| 75–100 | 极高 | 不建议签署，需重新谈判 |

## 签名笔迹对比说明（多模态）
- 当用户提供两张签名图片（如合同签署件 vs 身份证件/历史样本）要求比对时，使用多模态能力分析笔画走向、结构比例、连笔习惯、压力特征，输出**相似度（高/中/低）与置信度**，并明确声明：此为基础筛查，**非司法鉴定**，关键场景须由专业机构笔迹鉴定确认。
- 该比对无法用脚本完成，`scripts/contract_check.py` 仅在 `--sig-img` 传入时标记"已请求签名比对"，由工作流调用多模态分析。
