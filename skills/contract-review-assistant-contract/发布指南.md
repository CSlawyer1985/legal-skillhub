## 2. 本地验证

```bash
# 1) 结构校验（必须通过才能打包）
python <skill-creator>/scripts/quick_validate.py contract-review-assistant

# 2) 运行确定性检查（用样例合同，应检出全部 planted 问题）
python contract-review-assistant/scripts/contract_check.py sample_contract.txt --json

# 3) 打包（自动校验并生成 zip）
python <skill-creator>/scripts/package_skill.py contract-review-assistant ./dist
```

## 3. ⚠️ 上架前必填字段（替换占位符）

当前 `author` / `homepage` / `repository` 为占位符，提交前请替换为你的真实信息：

**`SKILL.md` 顶部 frontmatter：**
```yaml
author: "你的署名"                       # 原：WorkBuddy User
homepage: "https://你的仓库地址"          # 原：github.com/your-org/...
```

**`_skillhub_meta.json`：**
```json
"author": "你的署名",
"homepage": "https://你的仓库地址",
"repository": "https://你的仓库地址"
```

其余字段（id / name / version / description / summary / category / platforms / tags / icon / screenshots / triggerKeywords / capabilities）均已填写完整，无需修改。

## 4. 提交 SkillHub

1. 打开 WorkBuddy 技能管理 → SkillHub → 提交 / 导入技能。
2. 上传 `contract-review-assistant.zip`。
3. 确认 `author` / `homepage` / `repository` 已替换为真实值后提交审核。

## 5. 测试样例

`sample_contract.txt`（随包外提供，不计入 zip）含以下刻意埋点，可用于演示与验收：
- 缺失「争议解决/管辖」「知识产权」「不可抗力」条款
- 占位符：`合同编号：【】`、`乙方：待填`、验收期 `【】日内`
- 条款跳号：第 3 条后直接第 5 条（缺第 4 条）、第 7 条后第 9 条（缺第 8 条）
- 金额矛盾：第 3 条「本合同总价款壹拾万元整（¥100,000）」 vs 第 9 条「本合同总价款贰拾万元整（¥200,000）」
- 含签字盖章行、两个签署日期
