# 更新日志

本项目遵循语义化版本（SemVer）。

## [1.0.0] - 2026-07-29

首个版本。GDPR 护栏系列。

### 新增
- GDPR 规则包 `gdpr`（自包含，不继承 common）：IBAN、UK NI、EU 电话（E.164）、信用卡（Luhn）等 EU 个人数据格式
- 关键词线索覆盖 GDPR Art.9 全部 8 类特殊类别数据 + Art.10 刑事定罪数据
- 三种动作：detect / mask / block，重叠命中去重
- 纯本地运行，零网络、零动态执行、零外部依赖

### 安全
- 无 eval / exec / 动态 import，规则通过显式映射加载
- 检测结果不回传敏感原文，仅提供脱敏预览
