# 数据处理协议（DPA）模板

## 法律依据
GDPR 第 28 条——处理者必须受涵盖第 28 条第(3)款所有强制性条款的合同约束。
没有合规的 DPA 本身即构成违规，可能受到第 83 条第(4)款罚款（最高 1000 万欧元 / 营业额的 2%）。

## 5. 处理者义务（第 28 条第(3)款）

### 5.1 仅按指示处理（第 28 条第(3)款(a)项）
处理者应仅依据控制者的书面指示处理个人数据，包括就传输而言，除非法律要求（在此情况下，处理者应通知控制者，除非被禁止）。

### 5.2 保密（第 28 条第(3)款(b)项）
处理者应确保获授权处理数据的人员已承诺保密或负有法定保密义务。

### 5.3 安全（第 28 条第(3)款(c)项；第 32 条）
处理者应实施适当的技术和组织措施，至少包括：
- 个人数据静态和传输中的加密
- 处理系统持续的保密性、完整性和可用性
- 事件后恢复可用性的能力
- 安全措施的定期测试

### 5.4 子处理者（第 28 条第(2)款、第 28 条第(3)款(d)项）
未经控制者事先**特定或一般书面授权**，处理者不得聘请子处理者。

当前获授权的子处理者：[列出 或"见附表 A"]

处理者应对子处理者施加同等的数据保护义务（第 28 条第(4)款），并继续对控制者就子处理者的失败承担责任。

### 5.5 数据主体权利（第 28 条第(3)款(e)项）
处理者应考虑到处理的性质，通过适当的技术和组织措施协助控制者履行回应数据主体权利请求（第 15-22 条）的义务。

### 5.6 协助控制者义务（第 28 条第(3)款(f)项）
处理者应考虑到处理的性质和可用信息，协助控制者确保遵守：第 32 条（安全）、第 33-34 条（违约通知）、第 35-36 条（DPIA）。

### 5.7 删除或返还（第 28 条第(3)款(g)项）
按控制者的选择，处理者应在服务终止时删除或返还所有个人数据，并删除现有副本，除非欧盟或成员国法律要求存储。
