# 版权通知

三种模式，选择其一：

- `--send` — 依据《信息网络传播权保护条例》第14条起草侵权通知。合理使用审查门（《著作权法》第24条）+ 虚假通知责任警示门（《信息网络传播权保护条例》第24条）在交付前运行。
- `--respond` — 对收到的侵权通知进行分流评估。选项：遵守 / 反通知 / 协商 / 不予处理。
- `--counter` — 依据《信息网络传播权保护条例》第16条起草反通知。管辖权承认与真实性保证的警示门在交付前运行。

## 指令

1. **读取业务配置。** 加载业务配置文件。若包含 `[PLACEHOLDER]` 标记或不存在，停止并提示："本技能需要先完成初始配置才能提供有效输出。请先完成业务配置——版权通知技能依赖于审批矩阵和业务档案。"

2. **检查案件工作区。** 若启用且无活跃案件，询问："本事项归属哪个案件？请切换案件或说明为业务级别处理。"

3. **依据参数分发：**
   - `--send` → 运行发送模式（下文）。依次完成：识别作品、识别侵权材料、合理使用审查门（《著作权法》第24条）、善意确信、准确性与授权、起草第14条通知、运行警示门、写入输出。
   - `--respond` → 运行回应模式（下文）。阅读收到的通知，评估（许可、合理使用、瑕疵、平台合规性、发送方可信度），呈现四个选项，推荐，撰写分流备忘。
   - `--counter` → 运行反通知模式（下文）。确认前提条件（因第14条通知被移除、善意确信为误删或误认、准备好接受人民法院管辖、已有律师参与），起草第16条反通知，运行警示门，写入输出。
   - 无标志位 → 询问一次："是要发送版权侵权通知、评估收到的通知，还是起草反通知？"

4. **遵守警示门。** 在 `--send` 和 `--counter` 模式中，警示门在任何最终输出写入前运行。`--send` 中的合理使用审查门独立且更早运行；"有争议"或"可能成立"的合理使用结论应停止起草并转交律师审查。

5. **管辖说明。** 本技能依据中国《信息网络传播权保护条例》操作。若网络服务提供者、内容或侵权人在中国境外，应在起草前标明——可能需要适用欧盟DSA通知、英国OSA通知或其他法域的工具，而非（或同时配合）中国法下的通知。

6. **适当交接。** `--respond` 模式建议反通知时可衔接 `--counter`——但仅在分流备忘经审查且反通知决定经审慎作出之后。

```
--send
--respond ~/Downloads/bilibili-takedown-notice.pdf
--counter
```

## 备注

- 对外发出的通知和反通知不附加律师工作成果标记。内部草稿、合理使用分析和分流备忘附加该标记。
- 《信息网络传播权保护条例》第14条和第16条是逐项式法条——每一项必要元素必须齐备，否则通知存在瑕疵。
- 反通知意味着如权利人起诉，将接受人民法院管辖。这不是形式要求。
- 非律师用户在警示门通过前获得一份面向律师的简报——尤其重要于反通知，因为反通知是诉讼的前一步。

## 目的

中国《信息网络传播权保护条例》的通知-删除机制是快速、低成本且后果重大的。侵权通知是以真实性保证为前提的声明，可导致内容被无司法审查地移除。反通知是另一份真实性保证声明，可要求恢复内容。两种决定都可能引发诉讼。本技能以各自所需的防护机制处理这三种操作。

三种模式：

- `--send` — 依据第14条起草侵权通知
- `--respond` — 对收到的侵权通知进行分流评估；产出选项
- `--counter` — 依据第16条起草反通知

若用户未传递标志位，询问一次："是要发送版权侵权通知、评估收到的通知，还是起草反通知？"

> **对外交付物（发送和反通知模式）：** 对外通知/反通知发送给网络服务提供者的指定接收方。对外文件不得附加 `保密 — 律师工作成果` 标记。通知本身不属于保密范围——它是法定程序中的声明。内部草稿、发送前简报、合理使用分析和分流备忘保留该标记，依业务配置。

## 管辖假设

本技能依据《信息网络传播权保护条例》操作，适用于受中国司法管辖的网络服务提供者。其他法域有其自身的通知-行动制度——欧盟《数字服务法》第16条、英国《在线安全法》、印度IT规则2021等——在必要元素、反通知机制和滥用责任方面存在实质性差异。若网络服务提供者、内容或侵权人在中国境外，应标明——中国法下的通知可能不是合适的工具，或可能需要配合当地制度的通知。著作权本身因《伯尔尼公约》具有多边性，但执行机制因法域而异。

**电商平台场景下《电子商务法》第42-45条的补充适用。** 当被控侵权行为发生在电商平台（淘宝、天猫、京东、拼多多、1688、抖音电商、快手电商、小红书商城等）时，《电子商务法》第42-45条提供了与《信息网络传播权保护条例》并行且互为补充的通知删除法律框架：
- **第42条（通知删除程序）：** 知识产权权利人有权通知电子商务平台经营者采取删除、屏蔽、断开链接等必要措施；通知应包括构成侵权的初步证据。平台经营者接到通知后应及时采取必要措施，并将该通知转送平台内经营者；未及时采取必要措施的，对损害的扩大部分与平台内经营者承担连带责任。
- **第43条（反通知程序）：** 平台内经营者可提交不存在侵权行为的声明及初步证据；平台经营者将声明转送权利人并告知可投诉或起诉；十五日内未收到投诉或起诉通知的，平台应及时终止所采取的措施。
- **第44条（平台信息披露义务）：** 电子商务平台经营者应及时公示收到的通知、声明及处理结果。
- **第45条（平台连带责任——知道或应知侵权而未采取必要措施）：** 电子商务平台经营者知道或应当知道平台内经营者侵犯知识产权的，应采取必要措施；未及时采取的，对损害扩大部分与平台内经营者承担连带责任。`[模型知识 — 需核验]`

本技能以《信息网络传播权保护条例》为主要操作框架（适用于各类网络服务提供者）；当案件涉及电商平台时，上述《电子商务法》条款与《信息网络传播权保护条例》的规定应一并考虑，二者在通知要素、处理时限和平台责任方面存在互补与重叠。`[模型知识 — 需核验]`

## 发送模式 — 依据第14条起草侵权通知

### 步骤1：识别受版权保护的作品

> 受版权保护的作品是什么？
>
> - **标题 / 描述** — 作品类型（软件、图片、文字、视频、音频）？
> - **登记状态** — 中国版权保护中心登记号和日期（如有）。登记并非发送通知的前提，但在诉讼中可作为权属证据，其时间点影响赔偿计算。[模型知识 — 需核验]
> - **权属** — 是著作权人本人还是独占许可人（含通知权）？（非独占被许可人通常无权以自己名义发送通知。）[模型知识 — 需核验]
> - **先前授权** — 是否曾就该使用或更广泛的使用授予过许可？

权属和授权是虚假通知责任（《信息网络传播权保护条例》第24条）案件首先审查的内容。在起草前必须明确记录。

### 步骤2：识别侵权材料及其位置

> 侵权材料在哪里？
>
> - **平台 / 网络服务提供者** — 抖音、B站、微博、微信公众号、小红书、淘宝、京东、华为应用市场等
> - **URL** — 侵权材料的具体链接。一份通知可覆盖同一网络服务提供者下的多个URL。
> - **描述** — 侵权材料是什么，如何侵权（逐字复制、实质性相似、演绎作品）？
> - **截图 / 证据** — 附带时间戳和URL可见的保存

第14条要求"要求删除或者断开链接的侵权作品的名称和网络地址"。URL通常已足够；应精确提供。

### 步骤3：合理使用审查门

《著作权法》第24条以封闭列举方式规定了12项合理使用情形。发送通知前应审查被指控的使用是否可能落入合理使用范围。

询问：

> 在起草通知前，需进行合理使用审查。请逐项核对《著作权法》第24条列举的12种情形：
>
> 1. 为个人学习、研究或者欣赏，使用他人已经发表的作品
> 2. 为介绍、评论某一作品或者说明某一问题，在作品中适当引用他人已经发表的作品
> 3. 为报道新闻，在媒体中不可避免地再现或者引用已经发表的作品
> 4. 媒体刊登或者播放其他媒体已经发表的关于政治、经济、宗教问题的时事性文章（作者声明不许刊登的除外）
> 5. 媒体刊登或者播放在公众集会上发表的讲话（作者声明不许刊登的除外）
> 6. 为学校课堂教学或者科学研究，翻译或者少量复制已经发表的作品
> 7. 国家机关为执行公务在合理范围内使用已经发表的作品
> 8. 图书馆等为陈列或者保存版本的需要，复制本馆收藏的作品
> 9. 免费表演已经发表的作品，未向公众收费，也未向表演者支付报酬
> 10. 对设置或者陈列在室外公共场所的艺术作品进行临摹、绘画、摄影、录像
> 11. 将中国公民、法人已经发表的以国家通用语言文字创作的作品翻译成少数民族语言文字作品在国内出版发行
> 12. 以阅读障碍者能够感知的无障碍方式向其提供已经发表的作品
>
> 被指控的使用是否可能落入以上任何情形？结论：合理使用不可能 / 有争议 / 可能成立？

记录答案。若"有争议"或"可能成立"，不起草。停止并转交律师审查："合理使用在此事实上有争议/可能成立。对受合理使用保护的使用发送通知，正是第24条虚假通知责任所针对的情形。在发出任何通知前应转交律师审查。"

### 步骤4：善意确信

第14条要求通知方确信使用未经授权。确认以下各项：

- 确认作品为本人所有（或通过独占许可拥有通知权）？
- 确认使用未获授权（无既有许可、无默示许可、无覆盖该使用的Creative Commons授权）？
- 已进行合理使用审查（步骤3）？
- 已直接审阅被指控内容（而非仅基于他人报告）？

四项均确认，善意确信成立。任一项否定，暂停。

### 步骤5：真实性与授权确认

第14条通知应包含构成侵权的初步证明材料。通知中应声明信息的真实性，并确认发送方有权代表权利人行事。

确认签署人：谁代表谁发送此通知，是否有权这样做？

### 步骤6：起草通知

第14条必要元素——每一项必须齐备：

1. **权利人的姓名（名称）、联系方式和地址**
2. **要求删除或者断开链接的侵权作品、表演、录音录像制品的名称和网络地址**
3. **构成侵权的初步证明材料**

结构：

- 发送方地址栏 / 日期
- 收件方：[网络服务提供者]的指定投诉接收渠道（各平台通常公布投诉入口：抖音投诉中心、B站版权投诉、微博侵权投诉、微信侵权投诉、小红书投诉等）
- 标题：关于要求删除/断开侵权内容链接的通知（依据《信息网络传播权保护条例》第14条）
- 上述三项元素，编号或清晰分隔
- 真实性保证及授权声明
- 签署栏

大多数平台发布了自己的投诉表单或网页入口（抖音投诉中心、B站版权投诉通道、微博侵权投诉、微信侵权投诉、小红书投诉通道等）。本技能产出通知内容；用户通过平台的渠道提交。在输出中注明该平台预期的提交渠道。

## 回应模式 — 对收到的侵权通知进行分流评估

你的内容被移除。网络服务提供者已通知你收到一份第14条通知。你有选择。

### 步骤1：阅读收到的通知

提取：

- **发送方** — 实体、签署人、地址、邮箱
- **网络服务提供者** — 通知你的平台
- **主张的作品** — 他们声称拥有的作品
- **被指侵权的内容** — URL或标识
- **移除/通知日期**
- **通知是否在表面上符合第14条要求** — 标注缺失元素；有瑕疵的通知不是合规通知

### 步骤2：评估

- **是否存在许可？** 协商许可、默示许可、Creative Commons、先前和解、转让——任何授权该使用的依据。
- **是否为合理使用？** 对照《著作权法》第24条12项情形逐项审查。诚实判断；这是供己方内部参考。
- **通知是否有瑕疵？** 缺少第14条任何必要元素、缺少真实性保证、签署人无表面授权？有瑕疵的通知不合规；平台可能仍会执行，但发送方的虚假通知风险上升，我方筹码增加。
- **平台是否合规执行？** 是否收到通知并被给予反通知机会？若平台未经此程序即移除，那是与平台之间的问题（而非与发送方）。
- **发送方是否为恶意投诉者？** 在该平台上是否存在反复发送过宽通知的模式？

### 步骤3：选项

呈现4个选项及权衡：

**A — 遵守（接受移除）**
- 适用：对方有理，或不值得争议
- 权衡：内容持续下线；可能影响账号信用、平台处罚机制、创作者收入
- 下一步：记录事件，确认无反通知时限问题，继续

**B — 发送反通知**（《信息网络传播权保护条例》第16条）
- 适用：善意确信材料因错误或误认被移除——通常适用于使用已获授权、属于合理使用、或发送方不享有著作权的情形
- 权衡：包含真实性保证，若权利人起诉则接受人民法院管辖，权利人可在收到反通知后向法院起诉或向著作权行政管理部门投诉——若起诉则内容持续下线；若不起诉则依据《信息网络传播权保护条例》第17条平台应恢复内容
- 下一步：`--counter`

**C — 直接与发送方协商**
- 适用：存在商业解决空间（授权、署名、缩小移除范围）
- 权衡：协商期间内容持续下线；和解沟通的保密性需注意（不得以"保密"标签替代法律保护）
- 下一步：向发送方发出协商函；协商期间不发送反通知

**D — 不予处理；在其他渠道维权**
- 适用：损害较小、不想接受管辖权承认、更愿意另行处理
- 权衡：内容持续下线；若移除本身是恶意的，可依据《信息网络传播权保护条例》第24条主张赔偿——但那是另一场争议

推荐一个选项并附两句理由。

## 反通知模式 — 依据第16条起草反通知

反通知可要求恢复内容，除非原权利人起诉或投诉。这是诉讼的前一步。

### 步骤1：确认前提条件

- 内容是因第14条通知被移除（而非平台依据服务条款的行为）。
- 你善意确信材料因错误或误认被移除——法定标准。
- 你准备接受：如权利人起诉，接受人民法院管辖。
- 决定经审慎作出——非冲动反应，已有律师参与。

### 步骤2：依据第16条起草

第16条必要元素——每一项必须齐备：

1. **服务对象的姓名（名称）、联系方式和地址**
2. **要求恢复的作品、表演、录音录像制品的名称和网络地址**
3. **不构成侵权的初步证明材料**

结构：

- 服务对象地址栏 / 日期
- 收件方：网络服务提供者的指定投诉接收方（与接收原通知的同一渠道）
- 标题：关于要求恢复被删除内容的说明（依据《信息网络传播权保护条例》第16条）
- 上述三项元素，编号或清晰分隔
- 真实性保证及不构成侵权的声明
- 签署栏

## 决策姿态

依据业务配置中的"主观法律判断决策姿态"：当不确定使用是否为合理使用、不确定权利人是否为我方、不确定作品是否确实为我方所有、不确定在接收方合理使用是否抗辩成立时——不得静默决定。合理使用是典型的不确定判断。标明由律师审查；展示各项因素。基于假设发送通知或反通知是不可逆的操作。

## 本技能不做什么

- **提交通知。** 仅起草。用户通过平台指定渠道提交。
- **为用户选择平台的投诉入口。** 注明预期渠道；不自动提交。
- **决定合理使用。** 对照第24条12项情形审查；标明。由律师决定是否推进。
- **在接收方验证发送方主张。** 结构化阅读；每一处法律依据标注待专业人员验证。
- **绕过警示门。** 警示门在 `--send` 和 `--counter` 模式中每次都运行。
- **编造引用。** 包含的引用均标注来源并标注待验证；不静默补充。
- **处理非中国法域制度。** 本技能依据中国法。对欧盟DSA、英国OSA、印度IT规则及其他制度——标明并转交。
