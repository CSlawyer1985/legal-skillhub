# 正常样例：抖音视频版权侵权通知

## 输入

用户是一家独立动画工作室的版权负责人。工作室制作的一部原创动画短片（已在中国版权保护中心登记，登记号：20XX-F-XXXXXX）在抖音上被多个账号未经授权上传完整播放，累计播放量超过50万次。用户提供：
- 作品标题和登记信息
- 3个侵权视频的抖音链接
- 作品原创声明和登记证书扫描件
- 确认未授权任何方上传

## 期望行为

1. **步骤1**：识别受版权保护的作品——确认动画短片标题、登记号、权属（原创工作室）、无先前授权
2. **步骤2**：识别侵权材料——确认抖音平台、3个URL、侵权方式（完整复制上传）
3. **步骤3**：合理使用审查门——逐项核对第24条12项情形，结论为"合理使用不可能"（完整复制上传不落入任何一项）
4. **步骤4**：善意确信——4项全部确认
5. **步骤5**：真实性与授权确认——签署人为工作室版权负责人
6. **步骤6**：起草通知——包含第14条3项元素，注明抖音版权投诉入口
7. **步骤7**：警示门运行——展示警告框，确认4项
8. **步骤8**：输出通知文档

## 期望输出要点

- 通知包含：权利人名称和联系方式、3个侵权视频名称和URL、构成侵权的初步证明材料描述
- 标注抖音版权投诉中心入口
- 警示门已运行并确认
- 引用来源标注 `[国家法律法规数据库]`、`[模型知识 — 需核验]`

## 应触发的人工 gate 或来源标签

- 合理使用审查门通过（"合理使用不可能"），继续起草
- 警示门运行并需用户明确互动确认
- 第24条虚假通知责任说明中标注 `[模型知识 — 需核验]`
