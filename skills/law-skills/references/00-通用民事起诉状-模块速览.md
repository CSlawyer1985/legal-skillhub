# 通用民事起诉状 — 模块速览

## 模板文件
`assets/00-通用民事起诉状.md`

## 文档结构
纯段落式（非表格），共18个段落块，手动排版。

## 段落分布与填充规则

### 标题（P0）
- 内容：**民事起诉状**
- 格式：居中、黑体加粗18pt
- **不修改**

### 当事人信息（P2-P8）
| 段落 | 标签 | 填充说明 |
|:---:|:---|:---|
| P2 | **原告** | 替换"×××"为原告姓名+性别+出生年月+民族+工作单位+住所地+联系方式 |
| P3 | 法定代理人/指定代理人 | 如有则填写，如无须保留"无"或删除该段落 |
| P4 | 委托诉讼代理人 | 如有则填写，如无则删除该段落 |
| P6 | **被告** | 替换"×××"为被告姓名/名称+基本信息 |
| P7 | …… | 多被告时复制P6-P7格式添加；单一被告则删除此段落 |
| P8 | 说明文字 | 保留或删除均可 |

**填充规则：** 直接修改段落中所有run的text，保留原有的粗体/字体格式。删除整段使用 `p._element.getparent().remove(p._element)`。

### 诉讼请求（P9-P10）
| 段落 | 标签 | 填充说明 |
|:---:|:---|:---|
| P9 | **诉讼请求：** | 保持不动 |
| P10 | …… | 替换为具体诉讼请求，逐条列出：(1)...(2)...(3)... |

### 事实和理由（P11-P12）
| 段落 | 标签 | 填充说明 |
|:---:|:---|:---|
| P11 | **事实和理由：** | 保持不动 |
| P12 | …… | 替换为案件事实描述+法律依据引用 |

### 证据清单（P13-P14）
| 段落 | 标签 | 填充说明 |
|:---:|:---|:---|
| P13 | **证据和证据来源，证人姓名和住所：** | 保留或改为"证据清单：", 保留以匹配诉状格式 |
| P14 | …… | 替换为具体证据列表：(1)...(2)...(3)... |

### 受诉法院（P15-P16）
| 段落 | 标签 | 填充说明 |
|:---:|:---|:---|
| P15 | **此致** | 保持不动 |
| P16 | ××××人民法院 | 替换为具体法院名称，如"北京市朝阳区人民法院" |

### 附项（P18）
- 替换"×"为被告人数（副本份数=被告人数）

### 具状人/日期（P20-P21）
| 段落 | 标签 | 填充说明 |
|:---:|:---|:---|
| P20 | 起诉人(签名) | 替换为"起诉人：XXX（签字、盖章）" |
| P21 | ××××年××月××日 | 替换为当前具体日期 |

**P20和P21已右对齐，保持不动。**

## 通用填充代码示例

```python
from docx import Document
import shutil, os

# 模板解密
KEY = 0xAC
with open("assets/00-通用民事起诉状.md", 'rb') as f:
    data = bytearray(f.read())
for i in range(len(data)):
    data[i] ^= KEY
TMP_DOCX = "/tmp/generic_decrypted.docx"
with open(TMP_DOCX, 'wb') as f:
    f.write(data)

TEMPLATE = TMP_DOCX
WORK = "/tmp/generic_complaint.docx"
shutil.copy2(TEMPLATE, WORK)

doc = Document(WORK)

def replace_paragraph_text(doc, old_text, new_text):
    """替换段落中包含old_text的文本为new_text"""
    for p in doc.paragraphs:
        if old_text in p.text:
            for run in p.runs:
                run.text = ''
            if p.runs:
                p.runs[0].text = new_text
            return True
    return False

def remove_paragraph(doc, keyword):
    """删除包含keyword的段落"""
    for p in doc.paragraphs:
        if keyword in p.text:
            p._element.getparent().remove(p._element)
            return True
    return False

# 填充原告信息
replace_paragraph_text(doc, "×××，男/女，××××年××月××日生",
    "张三，男，1985年3月15日生，汉族，XX公司职员，住北京市朝阳区XX路XX号。联系方式：138XXXXXXXX")

# 填充被告信息
replace_paragraph_text(doc, "×××，……",
    "李四，男，1982年7月20日生，汉族，无业，住北京市海淀区XX路XX号。联系方式：139XXXXXXXX")

# 删除委托代理人段（如无）
# remove_paragraph(doc, "委托诉讼代理人")

# 修改诉讼请求
replace_paragraph_text(doc, "……\n", """(1) 判令被告偿还借款本金人民币50000元；
(2) 判令被告支付逾期利息（以50000元为基数，按LPR四倍计算，自2025年6月1日起至实际清偿之日止）；
(3) 本案诉讼费用由被告承担。
""")

# ... 继续填充其他内容

# 修改法院
replace_paragraph_text(doc, "××××人民法院", "北京市朝阳区人民法院")

# 修改副本份数
replace_paragraph_text(doc, "×份", f"{被告人数}份")

# 修改具状人和日期
from datetime import datetime
today = datetime.now().strftime("%Y年%m月%d日")
replace_paragraph_text(doc, "起诉人(签名)", "起诉人：张三（签字、盖章）")
replace_paragraph_text(doc, "××××年××月××日", today)

doc.save(WORK)
```

## 适用场景

当用户描述的案由不在11个标准要素式案由范围内时，使用本通用模板生成起诉状。例如：
- 房屋租赁合同纠纷
- 建设工程施工合同纠纷
- 股权转让纠纷
- 服务合同纠纷
- 相邻关系纠纷
- 产品责任纠纷
- 名誉权/隐私权纠纷
- 合伙协议纠纷
- 承揽合同纠纷
- 运输合同纠纷
- 等（非标准案由均可使用）
