### 一、办税指南（全流程操作路径）

- 🗺️ **场景化路径**：税务登记、信息确认、发票、申报、备案、注销等按电子税务局菜单导航给出操作步骤。
- 📋 **办理要点**：所需资料、办理入口、办理时限、是否网办，避免跑错窗口。
- ⚠️ **高频易错**：申报期限、资料不齐、状态异常（如非正常户）导致无法办理的前置处理。

**典型问法：**

```
"新办纳税人套餐怎么办理？"
"跨区域涉税事项报告怎么报？"
"非正常户解除怎么操作？"
```

### 二、发票与申报实务

- 🧾 **发票业务**：票种核定、专票/普票领用、验旧缴销、红字发票、代开发票的操作路径与资料。
- 📊 **各税种申报**：增值税（一般/小规模）、企业所得税（预缴/汇算）、个税、附加税费、印花税、房产税等申报模块与填写要点。
- 🌐 **出口退税**：出口退（免）税备案、申报、审核、退库全流程网办路径。

**典型问法：**

```
"增值税专用发票领用怎么申请？"
"企业所得税年度汇算怎么申报？"
"出口退税备案流程是什么？"
```

### 三、注销·优惠·信用

- 🔚 **税务注销与清税**：清税申报、一照一码户清税、注销前置（结清税款、缴销发票）与办理顺序。
- 🎁 **优惠与延期**：税收优惠备案、减免税申请、延期申报/延期缴纳税款（最长3个月）、各类退税（多缴/汇算/误收）。
- 🏅 **纳税信用**：A/B/M/C/D 五级评价、A 级便利与 D 级限制、信用修复程序、首违不罚适用。

**典型问法：**

```
"清税申报怎么填？"
"纳税信用等级怎么修复？"
"延期缴纳税款怎么申请？"
```

### 四、表证单书与问题解答

- 📑 **表证单书**：主要税收表单（申报表、缴款书、通知书、申请表）的用途与填写说明、下载入口。
- 🏝️ **离岸信托个税专用申报表**：居民 B 表 / 非居民 A 表 + 纳税明细表 / 年度报告表 / 清算申报表 / 清算报告表 / 分期缴税备案表 等 6 类表单的报送时限与首次附报资料清单，详见「离岸信托个人所得税合规与财富税务管理」专题，本技能不重复罗列表单全文，仅做归口引导。
- ❓ **常见问题**：一般纳税人/小规模标准、征收率、小微优惠、留抵退税、发票红冲、社保关联等高频问答。
- 📅 **办税日历**：各税种申报期限、重要时间节点、办税服务厅与自助终端指引。

**典型问法：**


## 重要提示与边界声明

**重要提示**

1. **以官方为准**：电子税务局界面与办理规则各省市略有差异，具体操作以当地税务机关与电子税务局为准。
2. **按期办理**：申报期限、备案与注销有时限要求，逾期可能产生滞纳金或影响信用。
3. **资料真实**：填报信息须真实准确，虚假申报、虚开发票等将承担法律责任。
4. **状态前置**：存在非正常户、欠税、未缴销发票等状态异常的，须先处理再办后续业务。

**边界（本技能不做的）**

- **不代办**：登录电子税务局、实名认证、实际发起申报/缴税等需本人操作的事项
- **不代理**：税务争议代理、行政复议/诉讼等需执业资质的事务
- **不担保**：具体办理结果、审核结论以税务机关为准

**服务说明**

- 每次提问都能获得完整闭环：智能问答 → 结构化操作路径 → 政策依据溯源 → 表单填写要点 → 实操辅导 → 反馈评价

**隐私保护**

- 仅在本机生成随机匿名标识用于服务调用，不会采集任何设备信息或个人隐私数据。
