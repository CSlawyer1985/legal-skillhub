# enforcement-action-analysis

一个分析 OFAC 和 OFSI 执法行动，并将结构化根本原因分析生成为格式化 Excel 电子表格的 Claude 技能。

放入一份执法行动——URL、PDF 或粘贴文本——几秒钟内即可获得可用的合规自我评估表。

**由 [Sanctrust](https://sanctrust.com) 构建 · MIT 许可下免费使用**

---

## 功能

读取任何 OFAC 或 OFSI 执法行动，输出六列 `.xlsx` 表格：

| 列 | 描述 |
|--------|-------------|
| **根本原因** | 识别合规失败的简短标签 |
| **出了什么问题** | 此具体案件中发生了什么 |
| **问题如何发生** | 潜在的失败机制 |
| **什么本可阻止它** | 本可预防它的具体控制措施 |
| **我的组织对此免疫吗？** | ☐ 是 / ☐ 否 / ☐ 部分——审查时填写 |
| **备注** | 供您团队观察的自由文本字段 |

技能始终交叉引用 OFAC 自身的**合规考量**章节和**OFAC 合规框架根本原因分类法**，因此输出反映监管机构的明示期望——而非仅泛化建议。

---

## 示例输出

| 执法行动 | 罚金 | 发现的根本原因 |
|--------------------|---------|-------------------|
| FTI Consulting, Inc.（2026 年 6 月） | $1,050,000 | 3 |
| Adani Enterprises Limited（2025 年） | $275,000,000 | 5 |

## 如何安装

1. 下载 `enforcement-action-analysis.skill`
2. 在 Claude 中进入 **设置 → 技能** 并上传 `.skill` 文件
3. 技能现已在您的 Claude 会话中可用

---

## 如何触发

只需描述您想要的内容。以下任何方式均可：

- *"分析这份执法行动：[URL 或粘贴文本]"*
- *"FTI Consulting 的 OFAC 和解中根本原因是什么？"*
- *"把它变成合规检查清单"*
- *"我如何确保这种事不会发生在我们身上？"*
- 上传执法行动 PDF 并请 Claude 分析
