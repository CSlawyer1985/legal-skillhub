# 踩坑清单

> 本文件记录**真实发生过的坑**（现象 / 真因 / 怎么防）。规则在 `SKILL.md`，这里是史实。
> **动手前扫一眼，能省很多返工。**

---

## 前端渲染

| 现象 | 真因 | 怎么防 |
|---|---|---|
| 抽屉点开内容被裁掉、**连滚动条都没有** | Chrome 131+ 把 `<details>` 的内容包进 `::details-content` 伪元素，`display:flex` 的高度约束传不进去 | **别用 `<details>` 做需要滚动的抽屉**，改用 `div` + 按钮 |
| **前面模块正常、后面整片空白**（半死不活） | 漏写 `var` 的隐式全局赋值，`"use strict"` 下抛错，把 `refreshAll()` 从中途打断 | 静态检查第 2 项：扫描行首赋值语句 |
| 改了样式没反应 | 旧代码块没删干净，**CSS 重复定义**（后定义覆盖前定义，不报错） | 静态检查第 4 项：统计每个类的定义次数 |
| JS 里拼了 `class="a b"`，样式却不生效 | CSS 里**忘了写 `.a.b`** | 静态检查第 5 项 |
| 两个弹层样式互相覆盖 | **类名撞车**（新弹层复用了已有类名，宽度不同） | 新增 CSS 前先 `grep` 类名 |
| 判断"内容有没有被裁掉、能不能滚"时反复看不准 | headless 通常不渲染滚动条，**截图证明不了这件事** | 用 Chrome 调试端口量 `clientHeight` / `scrollHeight` |

## 数据与写入层

| 现象 | 真因 | 怎么防 |
|---|---|---|
| CSV 表头 8 列、数据 7 列，Excel 打开整列错位 | 写回时对**列表类型**的行直接写、没补齐列 | 写入函数对列表和字典两种输入都补齐 |
| 删掉一条后，**前端删错了别的条目** | id 按行号重新编号，删一条后剩下的整体前移 | **id 必须稳定**：取现有最大编号 +1，绝不按行号重排 |
| 点某个案件后，右栏还显示**所有案子**的动态 | 只给条目加了 `hit` 标记，**没有真的筛掉** | 拆成两份：全量（供左栏汇总）+ 筛选后（供右栏）。两者用途不同，别混用一个变量 |
| `Path("")` 判断"路径为空"失效 | **`Path("")` 等于当前目录，不是空** | 配置项存**字符串**，判断用 `if not CFG`；需要路径时再 `Path(CFG)` |
| 聚焦某案时，该案的排期在日历上被淡化 | 匹配用子串包含，而源里写的是简称（差一个字就配不上） | 剥掉"案件 / 项目 / 纠纷"这类后缀再匹配；**前后端两份实现必须逐字对齐** |
| 同一个案子显示成两种案号 | 全角括号与半角括号混用 | 入库时归一化案号写法 |
| 期限条目在聚焦时被误判为"无关" | 它的显示文字只有"09:00 开庭"，不含案件标识 | 匹配时**把案件标识一起纳入**匹配文本 |

## 排序与判定

| 现象 | 真因 | 怎么防 |
|---|---|---|
| 排序把"我刚碰过的"排最前 | 把过程性信号（最近编辑）当成了重要度 | 排序只反映**紧迫度 + 体量**；"最近动过"只能进悬停提示 |
| "备忘 26 条"和"备忘 1 条"同分 | 用固定分值表示"N 条" | 带数量的信号**随数量递增** |
| 自动分类把案子分错了类别 | 关键词规则必然有边界情况 | 给一键纠正，**并记住纠正结果**（存工作台自己的数据层） |

## 运行与部署

| 现象 | 真因 | 怎么防 |
|---|---|---|
| 启动器双击后代码没更新 | 启动器写了"已在运行就直接退出"的短路 | 比对时间戳，需要重启就**先停旧起新**；启动后自检是否加载了新代码 |
| 日历同步时好时坏 | **权限跟着"谁启动进程"走**（终端启动的有，别的宿主启动的可能没有） | 报状态时标明是哪个进程；交付时用双击 `.command` 的方式让权限挂在"终端"名下 |
| 无头浏览器里 PDF 一片空白 | headless Chrome 不加载 PDF 阅读器（已知限制） | 别据此判断"预览坏了"，要真人点一次 |
| `nohup` 起的服务，测试命令一结束就没了 | 进程被回收 | "起服务 → 测试 → 截图 → 收服务"**写在同一条命令里**，或改用常驻模式 |
| 自动化脚本在 `file://` 页面读不到状态 | CDP 的执行上下文与本地文件不同步 | 改用 **URL 参数 + 截图**验证，比回读状态更可靠 |
| 自检脚本时好时坏 | 在脏数据上连跑了两遍 | 每次跑前清空或备份数据目录 |
| 用 `grep` 批量查关键词，结果"0 命中" | BSD `grep` 的 `\|` 静默假阴性；`grep -c` 无匹配时退出码非零 | 多词搜一律用 `grep -E "A|B"`；**更稳的是用 Python 扫**。校验脚本要先"喂毒自证"再看 0 命中 |
| **服务明明停了，脚本却认定"还在跑"** | 环境里有 `http_proxy` 时本地请求被代理接管：**服务没跑也返回 502，但 curl 退出码仍是 0** | 探测一律加 `--noproxy '*'`（必要时再校验状态码 200）。**别只看 curl 退没退出** |
| 双击桌面图标报"应用已损坏" | 改过 `Info.plist` / 换过图标之后**没重新签名**，签名与 plist 失配 | 生成流程里必须含 `codesign --force --deep --sign -`；签完再核对签名 identifier 与 plist 一致 |
| 服务在跑，却和启动器抢端口生出一个副本 | 启动器自己 `nohup` 起进程，同时又装了开机自启（launchd）—— 两边都占 8765 | 装了开机自启就以 launchd 为正主：**启动器只 kickstart，不自己起进程** |
| 桌面图标把服务拉起来要十几秒 | `bootstrap` 已经启动了服务，紧跟着又 `kickstart -k`，把刚起来的进程杀掉重启 → 白等一次冷启动 | **两条只走一条**：先 kickstart，失败（说明已被摘出托管）才 bootstrap。实测 11 秒 → 1 秒 |

## 解析

| 现象 | 真因 | 怎么防 |
|---|---|---|
| 月历解析出的事项错位 | 按固定行号取内容，而表被插过行 | 按**日期行识别**（一行里 >= 4 个日期就是日期行） |
| `stat -f "%Sm" -t` 在 macOS 输出错乱 | BSD `stat` 的格式串与 GNU 不兼容 | 用 Python 的 `st_mtime` + `strftime` |
| 同步盘里的 Excel 偶尔读失败 | 文件正在被同步 / 被别的程序占用 | 捕获异常并给友好提示，不要崩 |

## 一条元教训

**模板必须亲自跑一遍。** 上面这两条就是"只写模板不实测"会原样传给每个使用者的：

- `Path("")` 不等于空 → 内置示例全部失效，开箱就是空白页
- id 按行号重排 → 删错条目

**静态检查 + 断言脚本能拦住大部分，但拦不住"逻辑上说得通、跑起来不对"的那一类。**
