# 架构与进阶模块

> 本文件是 `SKILL.md` 的配套详解。规则与禁止项在 SKILL.md。

---

## 一、三层架构

```
┌─────────────────────────────────────┐
│ 浏览器窗口（单文件 HTML，全内联）      │  ← 可搬走
├─────────────────────────────────────┤
│ 本地小服务（Python，只绑 127.0.0.1）   │  ← 干活的
├─────────────────────────────────────┤
│ 律师的本地文件与系统                   │  ← 数据在这
└─────────────────────────────────────┘
```

**为什么必须有中间那层**：浏览器有硬限制（见下），"打开文件夹""读案卷原件""写日历"
这些事只能由本机进程代劳。而**网页只是最上面那层壳**——所以改了服务端代码必须重启，
不是因为网页没刷新。

### 关键设计

1. **页面是单文件 HTML，CSS / JS 全内联，零外链**。图标用内联 SVG，**不用 emoji**；
   图表用内联 SVG 手写。一旦引了 CDN，别人保存页面后就废了。
2. **服务只绑 `127.0.0.1`**。不要改成 `0.0.0.0` —— 那会把整个案卷目录暴露给同网段的任何设备。
3. **写入层是一个 CSV**（UTF-8 **带 BOM**，律师可以直接用 Excel / WPS 打开改），整本读写即可，不需要数据库。
4. **启动器是一个 `.command`**（macOS，`chmod +x`），并且**在脚本里依次探测可用的 python3**
   （要求 `import openpyxl` 成功），**不要硬编码解释器路径**。
5. **服务端渲染筛选，前端只渲染**。筛选结果由服务端算好（连同 `hit` 标记一起下发），
   前端不做业务判断——这样衍生形态（只读快照、导出）不会出现"同一份数据两种结果"。

### 浏览器硬限制（别硬碰）

| 想做 | 能不能 | 原因 / 替代 |
|---|---|---|
| 网页读取任意本地文件夹 | ❌ | 浏览器安全沙箱。**必须由本地服务代劳** |
| 网页跳转 `file://` 打开文件夹 | ❌ | 同上。改由本地服务执行系统命令打开 |
| 手机 Safari 读本地文件 | ❌ 基本不行 | 只有 Chrome / Edge 桌面版支持 File System Access API |
| 无头浏览器预览 PDF | ❌ | headless Chrome 把 PDF 当下载处理。**不代表真实浏览器不行**，需真人点一次确认 |

## 二、案卷挂钩（一键开文件夹 + 最近变动）

### 扫描要快

用 `os.scandir` 走目录元数据（只取 mtime / size，不读内容）。
实测规模参考：**约 4000 个文件、19 GB，扫完 0.02 秒** —— 所以**不要做缓存**，每次实时扫，
这样文件夹里刚加的文件刷新就能看见。

### 匹配规则

把文件夹名按 `VS / 诉 / & / 、 / -` 拆成片段，去掉"纠纷 / 执行 / 案件"这类通用词，
取 2~5 字前缀，然后**在条目的全部文字里找**（不只是标题，还包括明细）。

**命中太弱就不猜** —— 宁可留白，也不要乱挂。挂错了比挂不上更糟。

### 三态记忆

每条挂接关系都要能表达三种状态，并存工作台自己的数据层（不动源文件）：

| 状态 | 含义 |
|---|---|
| 自动匹配 | 算法挂的，随时可被覆盖 |
| 手工指定 | 律师选的，**永久记住**，不再自动覆盖 |
| 显式解除 | 律师说"这条不关联"，**且不许再被自动挂上** |

第三态最容易被漏掉——没有它，律师解除一次之后下次又被挂上，会很恼火。

## 三、案卷台（在网页里翻阅案卷原件）

三栏：**文件树 / 原件预览 / 工作记录与检索**。

### 关键点

- **文件流必须支持 HTTP Range**。实测：1.25 GB 的 PDF 只取头部 2 KB，耗时 0.039 秒 ——
  不支持 Range 的话，大文件会把内存撑爆。
- **路径越界必须挡住**：`../../etc/passwd` 和它的 URL 编码形式都要返回 403。
  做法：`Path.resolve()` 之后判断是否还在根目录内。
- **能直接预览的**：PDF（浏览器内置阅读器）、图片、音视频、md / txt。
  Word / Excel / 压缩包 → 给"用系统程序打开"。
- **结论类内容从哪来**：很多 AI 工具会把工作记录落在案卷目录里的隐藏文件夹
  （如 `.workbuddy/memory/*.md`）。**直接读它** —— 这样"原件"和"当时的结论"能并排显示，
  这是纯网页做不到的。

## 四、诉讼期限接入（优先级高，漏了代价最大）

**不要改律师的期限提醒工具，读它落盘的副产品。**

常见形态：该工具为了发提醒，会把结构化数据落在一个目录里（json / CSV，
字段含案件标识、期限日、动作）。直接读那个目录即可——比读日历干净，
也不会和它自己写进日历的内容打架。

接进来后在**三处同时显示**：

1. 右栏的期限卡片区（带剩余天数、动作、案件标识）
2. 日历上对应的日期格（醒目的红色，与普通排期区分）
3. 左栏对应条目的徽标（如"期限 3 · 急 2"）

⚠️ **期限条目的筛选匹配要注意**：它的显示文字可能只有"09:00 开庭"，
必须**把案件标识一起纳入匹配**，否则聚焦某案时它会被误判为"无关"而淡化。

⚠️ **案号写法可能不统一**（全角括号 / 半角括号混用）——入库时要归一化，
否则同一个案子会显示成两种样子。

## 五、日历同步（推到手机）

- 让**本来就会跨设备同步的系统**当权威数据源（如 iCloud 日历），本地文件降级为缓存
- 同步策略要**幂等**：每条事件的备注里带唯一标记，重复执行只补新增，不产生重复
- **只新增、不改不删**律师自己在日历里建的事件
- 时间解析要容忍中文写法：「下午两点」→ 14:00、「上午九点」→ 09:00、
  「09:00-11:00」→ 起止时间；**猜不到时间就当全天事件**，不要硬编一个钟点

## 六、行程 / 沉淀（把定稿文档收进来）

- 给律师一个固定通道：**在对话里说"把这份存到工作台"** → 写进 `data/沉淀/` → 工作台自动读
- 文件名里带日期区间（如 `某某行程_20260927-1001.html`），工作台据此在日历上标出那几天
- **过期的自动收起**，但**无日期的文档永不收起**（否则会被误以为文件丢了）
- **私人行程（旅游等）不要混进案件列表** —— 给写入层加一个显式的「区域」字段（工作 / 行程），
  别用"名字像不像"去猜，猜错的代价是条目**静默消失**

### 只读快照（可选，需要时才做）

如果律师确实需要在手机上看（而系统日历装不下的那部分），做法：

- **不要为快照另写一套页面**，共用同一份源码，靠注入一个 `window.__SNAP__` 标记切模式
- 前端只改三处：取数分支、写操作拦死（返回**永不 settle 的 Promise** 比 reject 好，
  不产生 unhandled rejection）、用一条 CSS 隐藏所有写操作按钮
- **`</` 必须转义成 `<\/`**，否则数据里出现一次 `</script>` 就提前闭合标签、整页白屏
- 筛选逻辑**必须同源**（要么都在服务端算，要么都在前端算），否则两边会漂移
- 验证只能用 **`file://`** 打开；CDP 在 `file://` 下常拿不到执行上下文，改用 URL 参数 + 截图

## 七、桌面入口（双击即开）

**律师不该记命令行，也不该每次去文件夹里翻启动脚本。** 交付的最后一件事，是在他桌面上
放一个图标：双击 → 打开工作台。

### 形态怎么选

| 形态 | 双击之后 | 评价 |
|---|---|---|
| `.command` | 弹一个终端窗口（窗口关了服务还在） | 能用，但律师看到黑窗口会以为坏了 |
| `.webloc` | 直接用浏览器打开网址 | 服务没跑就是一片空白，**不兜底** |
| **`.app`**（推荐） | 无窗口：先探服务，没有就拉起来，再开浏览器 | 唯一能"自己把服务弄起来"的形态 |

### 桌面图标该做三件事

1. **先探测**：`curl -s -o /dev/null --noproxy '*' --max-time 1 http://127.0.0.1:<port>/api/state`
   —— `--noproxy '*'` **不能省**（理由见下面的坑）
2. **不在跑就拉起来**：
   - 先 `launchctl kickstart -k gui/$(id -u)/<label>`（连旧进程一起换掉 = 顺带重启到最新代码）
   - 它报错 = 服务已被摘出托管 → 才 `launchctl bootstrap gui/$(id -u) <plist>`
3. **轮询等待，别用固定 sleep**：每 0.5 秒探一次、最多 12 秒，就绪再 `open location`

拉不起来时留兜底：`launchctl load -w ~/Library/LaunchAgents/<label>.plist`。

⚠️ 若工作台**没有**装开机自启，第 2 步改为直接 `nohup python3 server.py &` 并写入 pid 文件；
但推荐连开机自启一起装（见 `flow.md`），这样桌面图标绝大多数情况下只是"打开一下"。

### 图标怎么做（不用任何设计软件）

1. 用 PIL 画 **1024×1024**，**按 2 倍超采样绘制再 LANCZOS 缩回**（不然边缘全是锯齿）
2. 配色**直接抄页面 `:root` 里的品牌色**，图标和界面才是一套
3. 圆角半径取边长的 **22% 左右**（贴近 macOS 的 squircle 观感），太小会像老式图标
4. `sips` 缩出十个尺寸 → `iconutil -c icns` 打包
5. 替换 `Contents/Resources/applet.icns`，再改 `Info.plist` 的
   `CFBundleName / CFBundleDisplayName / CFBundleIdentifier / CFBundleIconFile`
6. 现成模板见 `skeleton/桌面入口.py`，只改顶部三个常量就能用

### 两个容易吓退人的点

⚠️ **改完 `Info.plist` 必须重新签名**，否则双击报"应用已损坏"：

```bash
codesign --force --deep --sign - "/Users/…/律师工作台.app"
```

⚠️ `spctl -a <app>` 会报 `rejected` —— **这是正常的**（本地自签名、没走公证）。
真正的判据是**有没有隔离属性**：`xattr -l <app>` 只看到
`com.apple.macl` / `com.apple.provenance`，就说明不受 Gatekeeper 拦，双击能开。
**别被 `rejected` 吓退回 `.command`。**

### 渲染前必读：三个实测踩过的坑

1. **探测服务必须带 `--noproxy '*'`**：环境里有 `http_proxy`（公司代理 / VPN / 抓包工具）时，
   本地请求会被代理接管 —— 服务没跑也返回 502，而 curl 的**退出码仍是 0**，
   于是"服务不在"被误判成"在跑"，脚本永远不重启。加了 `--noproxy` 退出码才可靠。
2. **生成脚本里必须包含重签那一步**：只改 `Info.plist` 不重签，签名里记的还是旧 identifier，
   双击报"应用已损坏"。签完再校验一次 identifier 与 plist 是否一致。
3. **`bootstrap` 和 `kickstart -k` 不要连着都跑**：bootstrap 本身就会启动最新代码，
   紧跟的 `kickstart -k` 会把刚起来的进程杀掉重启，白等一次冷启动。
   正确顺序是**先 kickstart，失败（说明服务已被摘出托管）才 bootstrap**。
   实测把"从被停到恢复"从 11 秒压到 1 秒。

### 交付后要验证一次

`open "<app 路径>"` 自己跑一遍：确认 applet 进程起来又正常退出、浏览器真的打开了页面。
**光看文件生成了不算数。**

## 八、建议：装上诉讼信息中枢

如果律师**没有**在用的诉讼期限管理工具，可以建议他考虑安装 `litigation-hub`（诉讼信息中枢）：

- 它能做：识别法院短信 / 送达链接 / 纸质文书照片 → 自动匹配期限规则 → 三线提醒
  （系统日历 + 邮件 + 桌面文件）
- 装了之后，工作台可以**直接读它落盘的期限数据**，不必重复录入
- 内置期限规则库（上诉期、举证期、缴费期等），比手工记靠谱

⚠️ **这只是建议，不是前置条件。** 工作台没有它照样能跑，只是"期限"这块要手工记。
**装不装由律师自己决定**，不要因为对方没装就卡住流程。

同样的态度适用于任何"让律师再装一个东西"的建议：
**说清它能解决什么、不装会怎样，然后交给他决定。**
