# 律师工作台 · 骨架

一套**能跑起来的最小实现**。先跑通，再按你的数据改造。

---

## 一、三分钟跑起来

```bash
# 1. 装依赖（只需一次）
pip3 install openpyxl

# 2. 启动（会自动打开浏览器）
python3 server.py
```

打开后你会看到：三栏界面、月历上有 5 条示例排期、右栏有一条"逾期未办结"标红。
**这些都是虚构的示例数据**，页面上有「清空示例」按钮，点一下就没了。

想换端口：`python3 server.py --port 8888`

## 二、改成你自己的数据

### 只改一行：日程表路径

打开 `server.py`，找到配置区：

```python
XLSX = ""        # ← 把你的 Excel 路径填在这里
```

macOS 上取路径：右键文件 → 按住 **Option** → 拷贝「…」为路径名称。

填好保存，重启服务，你表里的排期就会出现在月历上。

### 如果你的表结构不一样：改一个函数

默认按**月历栅格**解析（奇数行日期 + 偶数行内容，最常见的律师日程表写法）。

如果你的表是别的结构（一行一条、或者带表头），只需要改 `parse_calendar()` 这一个函数，
让它返回这样的列表即可，**其余代码都不用动**：

```python
[{"date": "2026-09-14", "text": "上午九点开庭", "sheet": "9 月"}, ...]
```

### 想让左栏显示真实案件名

骨架默认从「动态」的**归属**列汇总案件名。如果你有案件文件夹，可以另接一份（见 skill 正文的「案卷挂钩」）。

## 三、文件说明

```
├── server.py     本地服务（只读你的 Excel + 读写 data/动态.csv + 提供接口）
├── index.html    三栏页面（单文件、全内联、零外链）
├── 自检.py       改完代码跑一遍，确认没改坏
├── 桌面入口.py   在桌面生成"双击即开"的图标（见第七节）
└── data/
    └── 动态.csv  唯一写入层（UTF-8 带 BOM，双击就能用 Excel / WPS 打开改）
```

---

## 四、三条不要改的原则

| 原则 | 为什么 |
|---|---|
| **只读你的 Excel** | 月历表一被程序写就会错位；而且你会持续手动编辑它，两边写必然冲突 |
| **只写 `data/动态.csv` 一个文件** | 每个字段只能有一个写入出口，否则两边改必然打架 |
| **服务只绑 `127.0.0.1`** | 改成 `0.0.0.0` 会把整个工作台暴露给同一个 WiFi 下的任何设备 |

## 五、改完代码怎么验证

```bash
# 1) 先备份（自检会写数据）
cp -a data /tmp/data_bk

# 2) 另起一个端口跑服务，别动你正在用的那个
python3 server.py --port 9101 --no-browser &

# 3) 指向它跑自检
DESK=http://127.0.0.1:9101 python3 自检.py

# 4) 恢复数据
rm -rf data && mv /tmp/data_bk data
```

页面本身还可以做**静态检查**（不用开浏览器）：

```bash
python3 <skill目录>/scripts/check_page.py index.html
node --check /tmp/_page_check.js      # 脚本会把抽取好的 JS 放在这里
```

## 六、常见问题

**Q：点「记下」没反应？**
看右上角的小圆点：绿色 = 服务正常，红色 = 连不上。红色说明启动脚本的窗口被关了。

**Q：能不能放到手机上？**
两条路：① 把排期同步到系统日历（手机会自动同步）；② 生成只读快照放到你自己的同步盘。
两条路在 skill 正文的「进阶模块」里都有说明。

**Q：数据会上传吗？**
不会。这个骨架不连任何外部服务，所有数据都在 `data/` 目录里。

## 七、给桌面放一个图标

不想每次都开终端敲 `python3 server.py`，就在桌面上放一个图标：

```bash
pip3 install pillow        # 只需一次
python3 桌面入口.py
```

桌面会出现一个「律师工作台」图标，**双击就打开**：它自己判断服务在不在跑，
不在跑就先拉起来，再打开浏览器。**没有终端黑窗口。**

想换图标样子：改 `桌面入口.py` 顶部的「要改的三处」和配色常量。
配色直接抄你页面 `:root` 里的品牌色，图标和界面就是一套。

⚠️ 两个报错不用怕：

- 双击说"应用已损坏" → 说明最后一步 `codesign` 没执行成功，重跑一次脚本
- `spctl -a` 说 `rejected` → **是正常的**（本地自签名都这样）；只要 `xattr -l`
  里没有 `com.apple.quarantine`，双击就能打开

想让图标更省心（开机服务就在跑，双击只是打开网页）：把服务装成开机自启，
做法见 skill 正文的「桌面入口」一节。
