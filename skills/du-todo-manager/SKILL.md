# 待办管家 Skill

## 功能描述
查询和管理所有案件的待办事项和期限，按时间紧迫程度分类展示，帮助律师和法务人员掌握工作节奏，避免遗漏重要期限。

## 使用场景
- 每天早上查看当日待办事项
- 查看未来7天内即将到期的期限
- 查看未来30天的所有任务安排
- 检查是否有已过期的期限

## 输入
- 查询日期（默认为今天）
- 可选：指定查询范围（7天/15天/30天）

## 输出
- 今日待办事项
- 即将到期的期限（7天内）
- 未来30天的任务清单
- 已过期期限警告

## 工作流程

### 步骤1：读取全局任务文件
- 从 `tasks.json` 读取所有案件的期限信息（建议放在你的工作区根目录）
- 文件格式为JSON（`{"tasks": [...]}`），展示时再按紧急程度自动分类：
  - 🔴 已过期
  - 📅 今日待办
  - ⚠️ 紧急（7天内）
  - 📋 近期（30天内）
- 每个任务包含：案号、案件名称（含双方当事人）、期间名称、截止日期、法律依据、案件类型、案件文件夹路径

### 步骤2：计算和分类任务
根据当前日期和截止日期，将任务分为：
1. **已过期**：截止日期 < 今天
2. **今日待办**：截止日期 = 今天
3. **紧急（7天内）**：今天 < 截止日期 ≤ 今天+7天
4. **近期（30天内）**：今天+7天 < 截止日期 ≤ 今天+30天

### 步骤4：提供快捷操作建议
根据任务情况，提供操作建议：
- 如果有已过期任务，提示立即处理
- 如果有今日待办，列出优先级
- 如果有紧急期限，建议提前准备

## 任务状态管理

### 状态类型
- **pending**：待处理
- **completed**：已完成
- **overdue**：已过期

### 状态更新
- 用户可以标记任务为已完成
- 系统自动标记过期任务

## 使用示例

### 示例1：查看今日待办
```
用户：运行待办管家
输出：显示今天的所有待办事项
```

### 示例2：查看指定日期
```
用户：运行待办管家，查询2024-03-15的待办
输出：显示2024-03-15及未来30天的任务
```

### 示例3：查看紧急任务
```
用户：运行待办管家，只看7天内的紧急任务
输出：只显示7天内到期的任务
```

## 与其他技能的集成

待办管家从以下技能生成并写入 `tasks.json` 的任务中读取数据：
- **诉讼管家**：民事诉讼期间
- **执行管家**：执行保全措施期限
- **劳动仲裁管家**：劳动仲裁期间

这些技能在计算期间后，会自动将任务写入全局任务文件。

## 注意事项
1. 任务文件默认使用工作区根目录的 `tasks.json`（如需自定义路径，可自行在 skill 中替换）
2. 建议每天早上运行一次待办管家，掌握当日工作安排
3. 对于已过期的期限，应立即联系承办法官或仲裁员说明情况
4. 本Skill仅作为辅助工具，具体期限以法院/仲裁委通知为准
