# 客户法律咨询 — 答复模板（结论先行结构）

> 本模板对应 `scripts/generate_consultation.py` 的 JSON 输入结构（meta／sections），起草答复时读取。模板结构**必须**遵循：结论先行 → 依据简明 → 操作建议；全篇 200-500 字、每句不超过 40 字。

## 一、JSON 输入结构（generate_consultation.py）

```json
{
  "meta": {
    "date": "2026-08-31",
    "client": "客户简称（贵司）",
    "topic": "咨询事项（关于……之法律咨询答复）",
    "law_firm": "律所全称",
    "lawyer": "承办律师"
  },
  "sections": [
    {"type": "title", "text": "关于[事项]之法律咨询答复"},
    {"type": "conclusion", "text": "直接回答（第一句即结论）"},
    {"type": "body", "text": "依据与要件映射（简明）"},
    {"type": "body", "text": "风险提示（如有，用「建议进一步核实」）"},
    {"type": "list_item", "text": "下一步操作建议一"},
    {"type": "list_item", "text": "下一步操作建议二"},
    {"type": "signature", "text": "落款（律所/律师/中文大写日期）"}
  ]
}
```

## 二、模板结构规范（必须遵循）

| # | 模块 | 要求 |
|---|------|------|
| 1 | 标题 | 居中「关于[事项]之法律咨询答复」；⛔ **不得**写「法律意见书」「法律备忘录」字样（避免与正式文书混淆） |
| 2 | 结论先行 | 第一句直接回答，对话感；⛔ **不得**以「关于您咨询的问题」开头绕圈 |
| 3 | 依据简明 | 法规名称＋条号（如《民法典》第577条）；首次引用**必须**附条文大意；⚠️/⛔ 状态条文**不得**写入正文 |
| 4 | 要件映射 | 客户事实归入法律要件，一句话说明为什么适用/不适用；⛔ **禁止**罗列法条不作解释 |
| 5 | 风险提示 | 不确定处**必须**写「建议进一步核实」，⛔ **不得**给确定性结论 |
| 6 | 操作建议 | 一两句话：发函催告／固定证据／协商／起诉等；⛔ **不得**省略 |
| 7 | 落款 | 律所（盖章）／律师：XX／中文大写日期（调用 `format_base._to_chinese_date()`） |
| 8 | 免责声明 | 面向已有委托关系，不写正式免责声明；但涉重大金额/诉讼时效的**必须**提示核实 |

## 三、示例答复（供应商延迟交货）

> 用户：「客户问供应商延迟交货，合同没写违约金，怎么索赔？」

```json
{
  "meta": {"date": "2026-08-31", "client": "贵司", "topic": "供应商延迟交货索赔", "law_firm": "北京市百宸律师事务所", "lawyer": "XX律师"},
  "sections": [
    {"type": "title", "text": "关于供应商延迟交货索赔之法律咨询答复"},
    {"type": "conclusion", "text": "虽然没有约定违约金，但按照《民法典》规定，你可以要求赔偿实际损失。"},
    {"type": "body", "text": "依据《民法典》第577条（违约责任）与第584条（损失赔偿范围），供应商未按期交货构成违约，你有权主张继续履行或赔偿损失；赔偿范围以实际损失和可得利益为限，需以可预见规则为边界。"},
    {"type": "body", "text": "关键是把损失算清楚——比如因延迟交货导致的生产停工费、向第三方支付的违约金等，保留好相关凭证。"},
    {"type": "list_item", "text": "建议先发函正式催告并说明损失情况，给一个合理履行期限。"},
    {"type": "list_item", "text": "对方继续不理的话，可以考虑起诉；诉讼时效为三年，注意不要超过时效。"},
    {"type": "signature", "text": "北京市百宸律师事务所／XX律师"}
  ]
}
```

## 四、写作红线（必须执行）

1. **必须**结论先行、通俗、简短、有据、实用五原则齐备。
2. ⛔ **禁止**使用「综上所述」「应当指出」「毋庸置疑」等禁用词（`ndr-standards.md` §2.3.1 禁用词表）。
3. ⛔ **禁止**引用未核验法条/案例（§2.1.1 三态纪律＋§2.3.5 案例引用格式）。
4. **必须**在交付前执行四向审核（法条真实性＋案例真实性＋金额计算＋人写感）。
5. **必须**使用中文**弯**引号“”（生成脚本自动将「」转为“”）；全文零 U+FFFD。
6. 涉敏感信息的，**必须**先脱敏再提供云端AI（../baichen-ndr-standard/references/ndr-ai-governance.md §4）。
