# 客户法律咨询 — 方法指南（Step 1–4 执行细则）

> 本文件由 ../SKILL.md 工作流抽取而来，起草客户咨询答复时读取。与 `consultation-template.md`（答复模板）、`scripts/generate_consultation.py`（Word 生成器）配套使用。

## 一、Step 1 理解问题（材料提取与依据时效）

1. **必须**提取核心法律争议点，拆分为可逐一回答的子问题；信息不足时**必须**请用户补充，⛔ **不得**在事实不明时臆断作答。
2. **必须**采集主体、金额/利益、时效性、是否跨境四类关键信息；涉时效问题（诉讼时效/除斥期间/上诉期）**必须**优先核对起算点与剩余期限。
3. **必须**按 `ndr-standards.md` §7.8 标注所涉法规的发布/修订日期与最后核验日；涉审批/备案/登记/前置许可/第三方同意/优先购买权/内部决议程序的，**必须**先行提示程序前置及未满足后果，⛔ **禁止**省略程序性风险提示。
4. 新旧规则冲突时**必须**明确取舍并说明理由，⛔ **禁止**并列罗列不作判断。

## 二、Step 2 检索法律依据（法条核验与双源检索）

1. **基座前置｜双源检索（强制，不可跳过）**：加载 非争议解决公共标准 后第一步执行 §0（百宸法律智能体知识库订阅检测）＋§1（基座双源检索：百宸库[kb_id内置]各≥2组＋互联网各≥2组＋深度fetch≥2-3件库+2件网）。
2. **必须**执行 `ndr-standards.md` §2.3.5（AI生成虚假案例防范）与 ../baichen-ndr-standard/references/ndr-ai-governance.md §2 类案与法条验证决策树：以人民法院案例库（rmfyalk.court.gov.cn）为权威主源，裁判文书网/法答网辅助；法条与案例先验证后引用，异常→`search(web)`核验，均无→删除。
3. **必须**按 `ndr-standards.md` §2.1.1 三态标记法条：✅ 方可写入答复；⚠️ **不得**写入答复正文（仅作内部提示，交付时须向用户标明「依据待核验」）；⛔ **禁止**作为依据引用。未获权威原文时⛔ **不得**以「通常认为」「实践中一般」等模糊表述替代依据。
4. 关键法条与案例**必须**至少两个独立来源互相印证，不一致时标注「来源存在差异」。
5. 引用案例**必须**标注「入库案例编号XXXX-XX-2-XXX-XXX」＋裁判要旨概述，或裁判文书网完整案号，⛔ **禁止**无编号、无案号的笼统引用。

## 三、Step 3 草拟答复（结论先行）

1. **必须**结论先行：第一句直接回答客户问题，对话感，像面对面聊天。
2. **必须**通俗化：日常语言解释法律逻辑（「合同无效」不如「对你没有约束力」）。
3. **必须**简短：200-500 字，每句不超过 40 字；⛔ **禁止**为显得专业而注水。
4. **必须**有据：关键判断附法规或案例依据；不确定的**必须**说「建议进一步核实」，⛔ **不得**给出确定性结论。
5. 如需下一步操作，**必须**用一两句话给出实用建议（发函催告/固定证据/协商/起诉路径等）。
6. 论证深度分级：简单事项（法定/常规内容、结论自明）直接陈述结论，不展开论证；复杂事项（合法性边界、权利义务再分配、风险分配）完整论证——结论→依据→要件→适用。篇幅与内容重要性**必须**匹配。

## 四、Step 4 交付（自检与生成）

1. **必须**执行 `ndr-standards.md` §8.3 交付前强制自检（§8.1 交付前自检表＋§8.2 格式校验表＋§2.6 产物交付七维标准逐项核验），通过后方可生成 Word。
2. **必须**执行 `ndr-standards.md` §15.4 法条状态与依据时效普检（法条状态／时效标注／时法选择／前置条件／冲突取舍五项）；法条锚点表中 ⚠️/⛔ 项**不得**出现在交付正文。
3. 生成 Word 时**必须**调用 `scripts/generate_consultation.py`（`generate_consultation(meta, sections, output_path)` 三段式）；`.docx` 格式**必须**与三系统一底座一致（页边距/行距/字体/首行缩进/中文大写日期/文件名范式，唯一事实来源 `/sandbox/workspace/skills/baichen-ndr-standard/references/format_base.py`）。
4. **必须**执行 `ndr-standards.md` §15 自检清单＋§16 多轮审核流程；完成后参见 §13 技能链，NDR-DR 跨域需求参见 §14。
5. ⛔ **NDR 域不存在 §J 章节**（属法官文书公共标准），本技能对位设施为 §2.1.1＋§7.8＋§15.4。

## 五、AI 治理与信息脱敏（强制）

1. **必须**执行 ../baichen-ndr-standard/references/ndr-ai-governance.md §1 七维搭建、§3 AI幻觉防范五步（①禁杜撰法条案例并供给原文 ②限定引用百宸库[kb_id内置] ③官方平台交叉验证 ④四向审核 ⑤使用留痕）、§4 信息脱敏。
2. 客户咨询可能含身份证/金融账户等敏感信息，提供云端AI前**必须**脱敏；敏感个人信息即便已同意也不宜提供；向云端AI提供前**必须**取得当事人同意。
3. **必须**在交付前完成四向审核：法条真实性＋案例真实性＋金额计算＋人写感；审核结果留痕。
