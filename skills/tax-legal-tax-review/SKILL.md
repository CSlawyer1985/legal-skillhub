## 能为你做什么（法税同审五大场景）
---

### 一、税务合规法律尽职调查
- 🔍 **标的状况**：系统尽调税种登记、申报缴纳、优惠适用与发票台账，识别承继税负。
- 📋 **历史稽查**：检索稽查立案、行政处罚、欠税与失信记录，量化历史风险。
- ⚠️ **重大事项**：穷尽识别在查稽查、复议诉讼、重组税务等并专项披露。

**典型问法：**
```
"并购前怎么做法务税务尽调？"
"标的税务状况怎么查？"
```

### 二、涉税法律文书模板
- 📄 **四类文书**：税务尽调清单、税务承诺函、重大税务事项说明、涉税合规备忘录。
- 🛡️ **赔偿落地**：以承诺函与陈述保证把历史税务责任转化为可分配的契约赔偿。
- 🗂️ **归档闭环**：文书统一编号，与尽调底稿、测算模型形成可追溯证据链。

**典型问法：**
```
"税务尽调清单怎么写？"
"税务承诺函模板有哪些要点？"
```

### 三、审计准则第1142号税务维度落地
- 📑 **程序嵌入**：将税收法规违反识别纳入财报审计，评价列报与披露影响。
- ⚖️ **意见影响**：未计提或错误计提税负时考虑非标意见并与治理层沟通。
- 🧾 **勤勉佐证**：留存识别与沟通底稿，佐证审计勤勉尽责。

**典型问法：**
```
"审计1142号税务维度怎么落地？"
"税务违规对审计意见有什么影响？"
```

### 四、司法会计鉴定风险与质控
- 🔬 **风险识别**：检材不实、方法错误、超范围鉴定是高频被攻击点。
- ✅ **三级复核**：检材法定程序调取、方法可复核、意见限于会计事实。
- 🧱 **证据闭合**：完整工作底稿支撑，意见经复核可溯源。

**典型问法：**
```
"司法会计鉴定风险点有哪些？"
"涉税鉴定质控要点是什么？"
```

### 五、法务—财务—税务一体化同审
- 🤝 **三方会签**：重大交易涉税条款经法务、财务、税务会签，口径一致。
- 🧭 **七步闭环**：立项—尽调—识别—测算—撰文—会签—交割后全程贯通。
- 💡 **同审引擎**：说「做一下法税同审自查」即可触发一体化体检。

**典型问法：**
```
"做一下法税同审自查"
```

## 重要提示与边界声明

**重要提示**
1. **计算结果仅供参考**：所有税额测算、优惠判断、风险评分均为辅助参考，不构成税务申报、审计或法律意见。
2. **专业事项请咨询执业人员**：税务合规计划、争议解决、稽查应对等需结合企业实际，由执业税务师/律师量身定制。
3. **数据以官方为准**：政策时效性强，个案结论可能因地区、行业、时间而异；涉及重大利益请向主管税务机关或专业人士二次确认。

**边界（本技能不做的）**
- **不代办**：实时申报、缴款、退税、注销等需登录电子税务局的操作
- **不代理**：税务行政复议、诉讼、鉴证等需执业资质的法律事务
- **不担保**：政策时效与个案结论以税务机关/执业税务师最终认定为准

**服务说明**
- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告

**数据口径**
- 本技能基于公开财税法框架为你提供结构化梳理与合规提示，所有结论均为参考级、非鉴证意见。涉及具体交易的重大安排，建议结合执业机构意见落地。
