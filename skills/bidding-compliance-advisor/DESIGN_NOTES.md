# 设计说明 · 投标文件合规检查助手

> 记录本技能的设计取舍与演进，便于维护与复评。

## 一、设计目标
面向"投标人投前自检"场景，把零散的废标风险经验沉淀为**可打印、可逐项打勾**的结构化清单，降低因低级疏漏（保证金/签字盖章/密封/份数/迟到）导致废标的概率；同时提供法条审查、问答、违规识别、异议投诉等扩展合规能力。

## 二、关键设计决策
1. **四级风险模型（🔴🟡🟢⏰）**：用颜色分级让"轻重缓急"一目了然，对应原评分报告看重的"红黄绿分类""四色分类一眼看出"。
2. **判定标尺外置（references/compliance-signals.md）**：把"什么算🔴/🟡/🟢/⏰"的精确标准与误判边界独立成文件，作为确定性标尺；好处是（a）SKILL.md 精简、（b）判定跨轮次一致（治原"运行稳定性 4.0 多轮重复背景"之外的"判断漂移"）、（c）校准案例可热插拔。
3. **必查盲区强制校验**：针对长标书"中后段漏检"，强制回溯 ★/废标条款、保证金/密封/份数、电子标/联合体三类盲区，未覆盖红字警告——直接提升功能完善性与运行稳定性。
4. **输入预检先于分析**：防止把"用户没给"误判为"文件没写"，提升异常处理与开箱即用。
5. **内置法条/案例库离线兜底（references/legal_core.md）**：回应"缺少内置法条/案例库"反馈；外部 KB 不可用时仍能给出基本判断，且全程标注"现行有效性以官方为准"。
6. **多轮状态管理**：项目档案卡 + 每轮自动回带 + 📌回显防漂移，治原"复杂追问需重复背景"。
7. **护栏铁律**：法条模糊化不默写、现行有效性核验、分级不越权、政采硬隔离（红线）、不替代法务、以招标文件为准——守住合规与安全边界。

## 三、与「招采萝卜坑识别专家」的关系
- **本技能**：看**投标文件**（我方交出去的东西）的合规完整性，防废标。
- **招采萝卜坑识别专家（bid-carrot-pit）**：看**招标文件**（对方给的文件）里的排他/歧视/量身定制条款，防被坑。
- 两者视角互补、解耦、可串联：先用萝卜坑识别扫招标文件的"坑"→ 再用本技能确保我方投标文件不被废。
