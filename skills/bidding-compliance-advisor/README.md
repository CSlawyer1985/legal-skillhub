# 投标文件合规检查助手

> 投标人侧独立技能（`slug: bidding-compliance-advisor`）。对照招标文件系统检查投标文件的格式、资质、签字盖章、密封、份数、实质性响应等完整性，输出可直接打印打勾的结构化检查清单，提前发现废标风险点；并支撑招标文件合法性审查、法条问答、违规识别、异议投诉辅助。

## 能力边界
| 做 | 不做 |
|---|---|
| 投标文件完整性检查（四级风险 + 倒计时冲刺） | 不代替法务正式审核、不下法定结论 |
| 判定标尺逐类过、必查盲区强制校验 | 不对"我方是否必然废标"下法定结论 |
| 招标文件合法性审查 / 法条问答 / 违规识别 / 异议投诉辅助 | 不处理政府采购货物服务（→ 政府采购合规实务助手） |
| 内置法条/案例库离线兜底 | 不提供规避合规、钻空子、骗分建议 |

## 快速使用
1. 触发技能（见 SKILL.md §7 触发词）。
2. 按 §2.1 预检清单提供关键要求（截止时间/保证金/份数/密封/是否电子标或联合体）。
3. 技能自动提取要求 → 跑 §3 判定标尺 → 必查盲区校验 → 按 §4 输出契约出清单。

## 部署建议
- `references/` 作确定性标尺随技能走，不依赖外部；外部知识库（`rsdLWw5Tz…`）为运行时核实层。
- 触发即抛 §2.1 预检清单作 Welcome Message。
- 发现某类"临界判定"仍看不准 → 在 `compliance-signals.md` / `few_shot.md` 追加 Case。
