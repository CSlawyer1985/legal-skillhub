# 投标文件合规检查助手 · 测试用例

> 用于回归验证技能的"精准度"与"丝滑度"。每个用例给输入要点 + 期望命中 + 易错点。覆盖四级判定、必查盲区、多轮状态、内置库离线、边界校准。

## 用例 T01 · 完整清单生成（基础）
- **输入**：提供完整招标文件关键要求（保证金/授权/营业执照/份数/密封/有效期 + 资质清单 + 截止时间）
- **期望**：生成 🔴/🟡/🟢/⏰ 四级清单；🔴 含保证金/授权/密封/份数；输出 📌项目回显；跑完三类必查盲区无遗漏
- **易错点**：漏掉"密封""份数"等低级高危项（盲区②）；未回显项目档案

## 用例 T02 · 必查盲区·电子标专项
- **输入**：声明"本次电子标"，但未给 CA/签章/文件大小信息
- **期望**：清单含 🖥️电子投标专项，且红字标注「⚠️ 未确认 CA/签章/文件大小，该项风险未知」
- **易错点**：按纸质标流程查，漏掉电子标专属必检项（盲区③）

## 用例 T03 · 必查盲区·联合体专项
- **输入**：声明"联合体投标"，提供各方资质
- **期望**：清单含 🤝联合体专项（协议/各方资质/各方盖章）；保证金以联合体名义
- **易错点**：只查牵头方资质，漏掉"各方在所有要求处分别盖章"

## 用例 T04 · 资质临界·截止日当日到期（FS-1）
- **输入**：资质证书有效期至投标截止当日
- **期望**：标⚠️不擅自升🔴；建议续期/澄清
- **易错点**：直接判无效→🔴（违反 §5 分级不越权）

## 用例 T05 · 格式项挂废标后果（FS-5）
- **输入**：招标文件"未胶装装订按废标处理"
- **期望**：装订动态升🔴，纳入废标清单
- **易错点**：当🟢格式项忽略（违反 标尺 动态规则）

## 用例 T06 · 电子标未提前上传（FS-4）
- **输入**：计划截止前 1 小时上传
- **期望**：标🔴级时效风险，强制建议提前 4h 上传并下载验证
- **易错点**：当普通格式项

## 用例 T07 · 多轮状态不重复背景
- **输入**：第一轮给项目信息+生成清单；第二轮问"那资质快过期怎么办"
- **期望**：不要求重述项目名称/截止/保证金；仅基于档案卡续答，并回显 📌
- **易错点**：重复追问背景（原评分"运行稳定性 4.0"痛点）

## 用例 T08 · 外部知识库离线兜底
- **输入**：断开外部 KB，问"保证金法定上限多少"
- **期望**：用内置 `legal_core.md` 回答"≤估算价2%"，并标注"以官方发布为准/请核实现行有效性"
- **易错点**：声称"无法回答"或编造法条原文

## 用例 T09 · 政采硬隔离（红线）
- **输入**：用户问"政府采购货物服务项目的废标条款"
- **期望**：拒绝并引导至「政府采购合规实务助手」，不引《招标投标法》处理政采
- **易错点**：跨体系引用招法处理政采（行业笑柄级错误）

## 用例 T10 · 不捏造（边界）
- **输入**：一份条款中性的正常招标文件
- **期望**：清单项均基于真实条款；不强行把中性表述说成废标项
- **易错点**：为凑数硬判违规（违反 §5 "只检查不捏造"）

## 回归红线
- 不得编造不存在的废标项（§5 护栏）。
- 法条只给方向/条号，不写定论条文；附现行有效性核验。
- 风险分级不越权（🔴≠必然废标）。
- 清单 >15 项须折叠 🟢（输出长度控制）。
- 电子标/联合体等盲区未确认须红字警告，不得静默假装查完。
- 政采问题硬隔离，绝不跨体系引用。
