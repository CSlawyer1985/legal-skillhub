# 地方法规参考（工资支付 / 劳动合同）

本文件为劳动合同审查中引用**用人单位所在地地方法规**的速查参考。工资相关条款（发薪日、加班工资、工资扣减、最低工资、离职结清）各地普遍有**严于国家法**的细化规定，审查时除国家法律外**必须一并引用**本地法。

## 地域分级检索框架（国家 / 省 / 市）

完整的"国家→省→市"三级匹配流程与参数对照见 `labor_law_rules.md`「零、地域分级适用」。本文件聚焦**市级**工资支付细则。参数与适用层级对照：

| 参数 | 适用层级 | 检索关键词示例 |
|------|----------|----------------|
| 试用期 / 违约金 / 社保 / 解除终止核心规则 | 国家 | 《劳动合同法》第X条 |
| 月最低工资 | 省 / 市 | "XX省/市 最低工资标准 2026" |
| 上年度社平工资 | 省 | "XX省 上年度社平工资 2025" |
| 产假 / 陪产假 / 育儿假 | 省 | "XX省 人口与计划生育条例 产假 天数" |
| 高温津贴标准与月份 | 省 / 市 | "XX省 高温津贴 标准 发放月份" |
| 工资支付（发薪日 / 离职结清 / 扣减） | 市 | "XX市 工资支付条例 离职结清" |
| 停工留薪期 / 工伤待遇 | 市 / 省 | "XX市 工伤保险 待遇 细则" |

> 省级、市级变量参数必须经 WebSearch 实时检索当前有效数值与法规名称、条款号，标注来源与日期后使用，严禁凭记忆填数。

## 使用规则（硬性）
- 引用前**必须**用 WebSearch 实时核对该法规的当前名称、生效版本与关键条款号，**严禁凭本文件直接杜撰**（地方法规常修订，条款号可能变化）。
- `law` 字段写法示例：`《劳动合同法》第30条 + 《深圳市员工工资支付条例》第9、11条 + 《广东省工资支付条例》第12条`。
- 若用人单位所在地不在下列城市，按第 0 步检索该省市的《工资支付条例/规定/办法》及《劳动合同条例》，并把关键条款补入本文件。

## 深圳市（及广东省）
适用法规：
- **《深圳市员工工资支付条例》**（2022 年第三次修正）—— 直接适用于深圳用人单位
- **《广东省工资支付条例》**（2016 年修正）—— 深圳同时适用省级条例
关键条款（引用前再次实时核对条款号）：
- **发薪日**：工资支付周期不超过一个月的，约定的工资支付日**不得超过支付周期期满后第 7 日**（深圳条例第11条）；遇法定休假节日或休息日应提前至最近工作日支付（深圳第11条 / 广东第12条）。
- **延期发薪**：因故不能在约定日支付的，可延期 5 日；因生产经营困难需延期超过 5 日的，须征得本单位工会或员工本人**书面同意**，最长不超过 15 日（深圳条例第12条）。
- **工资扣减**：因劳动者过错造成损失需扣赔偿费的，须**提前书面告知**扣除原因及数额；扣除后余额不得低于当地最低工资（广东条例第15条）。
- **正常工作时间工资**：不得低于市政府公布的最低工资标准（深圳条例第4条）。
- **离职结清**：支付周期不超过一个月的工资，自解除/终止劳动关系之日起 **3 个工作日内一次付清**（深圳条例第13条）；广东条例第13条：解除/终止当日结清并一次性支付。
- **加班工资**：150% / 200% / 300%（广东条例第20条；深圳条例同等标准）。
- **罚则**：克扣、拖欠、低于最低工资、不付加班费的，由行政部门责令支付，逾期不支付按应付金额 **50%–100% 加付赔偿金**（《劳动合同法》第85条）。

## 上海市
适用法规：**《上海市企业工资支付办法》**（沪人社综发〔2016〕29号，2016-08-01 执行）
关键条款（引用前再次实时核对条款号）：
- **发薪频率与日期**：每月至少支付一次，具体日期由双方约定；遇法定休假节日或休息日，通过银行发放**不得推迟**、直接发放应提前（第6条）。
- **延期发薪**：确因生产经营困难，经与工会或职工代表协商一致，可延期在**一个月内**支付，并须告知全体劳动者（第10条）。
- **试用期工资**：不得低于本单位同岗位最低档工资 80% 或约定工资 80%，且不低于本市最低工资（第11条）。
- **工资扣减**：因本人原因造成经济损失需扣赔偿费的，扣除部分**不得超过当月工资 20%**，且扣后余额不得低于最低工资（第22条）。
- **加班工资**：150% / 200% / 300%（第13条）。
- **罚则**：克扣/无故拖欠/低于最低工资/不付加班费，责令支付，逾期按应付金额 50%–100% 加付赔偿金（第21条）。

## 北京市
适用法规：**《北京市工资支付规定》**（2004 施行，2021 修正）
关键条款（引用前再次实时核对条款号）：
- **发薪**：至少每月支付一次，足额支付，不得克扣或无故拖欠；遇法定休假日或休息日应**提前在最近工作日支付**（第9条）。
- **最低工资**：支付工资不得低于本市最低工资（第10条）。
- **工资扣减**：不得随意扣除；因劳动者本人原因造成经济损失扣工资的，扣后余额不得低于最低工资（第11条）。
- **离职结清**：依法终止/解除劳动关系，**一次性付清**工资（第12条）。
- **加班工资**：150% / 200% / 300%（第14条）。
- **延期发薪**：生产经营困难暂无法按时支付，须经与工会或职工代表协商一致，最长延期不超过 **30 日**（第26条）。

---

> 提示：除上述城市外，天津、江苏、浙江、河北、山东等多地均有各自《工资支付条例/规定》，核心要点（月薪发薪日遇节假日提前、离职当日/短期内结清、扣减下限为最低工资、加班 150/200/300%）高度一致；审查非上述城市合同时，按第 0 步检索并补引本地法。
