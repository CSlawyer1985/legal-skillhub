# 网络直播营销行为规范（中国广告协会行业自律规范）

来源：中国广告协会 https://www.china-caa.org/cnaa/newsdetail/369

**2020年7月1日起施行** | 性质：行业自律规范（非强制性法律，但具有重要行业指导意义）

## 一、总则

- **适用范围**：商家、主播等参与者在电商平台、内容平台、社交平台等网络平台上以直播形式向用户销售商品或提供服务的网络直播营销活动
- **基本原则**：坚持正确导向、诚实信用、信息真实、公平竞争
- **禁止内容**：违反宪法基本原则、损害国家利益、民族歧视、淫秽色情、暴力、教唆犯罪、危害未成年人等（第4条）
- **刷单炒信禁止**：不得利用刷单、炒信等流量造假方式虚构或篡改交易数据和用户评价（第6条）
- **知识产权保护**：建立健全知识产权保护机制（第9条）
- **未成年人保护**：完善对未成年人的保护机制（第11条）

## 二、商家义务（第12-18条）

| 义务 | 内容 |
|------|------|
| 资质要求 | 应具有与商品/服务相应的资质、许可，**亮证亮照经营** |
| 信息真实 | 入驻平台时提供真实有效的主体身份、联系方式、行政许可等信息 |
| 商品合规 | 不得销售违法违禁商品/服务；符合质量和使用安全要求 |
| 特殊商品 | 药品、医疗器械、保健食品、特殊医学用途配方食品等须取得相应资质或行政许可 |
| 品牌授权 | 提供真实有效的商标注册证明、品牌特许经营证明、品牌销售授权证明 |
| 信息准确 | 产品服务信息真实、科学、准确，涉及标准的应与国标/行业标准一致 |
| 售后保障 | 依法提供退换货保障等售后服务 |

## 三、主播义务与禁止行为（第19-29条）★

### 基本要求

- 了解网络直播营销基本知识，掌握专业技能，树立法律意识
- 入驻平台须提供真实有效的个人身份信息
- **不得将注册账号转让或出借给他人使用**
- 前端呈现可使用的昵称/名称须符合法律法规

### 直播场所限制（第22条）

不得在以下场所直播：
- 涉及国家及公共安全的场所
- 影响社会正常生产、生活秩序的场所
- 影响他人正常生活的场所

### 主播禁止行为（第23条）★

1. 带动用户低俗氛围，引导场内低俗互动
2. 带有性暗示、性挑逗、低俗趣味
3. 攻击、诋毁、侮辱、谩骂、骚扰他人
4. **在直播活动中吸烟或者变相宣传烟草制品（含电子烟）**
5. 内容荒诞惊悚，以及易导致他人模仿的危险动作
6. 其他违反社会主义核心价值观和社会公德的行为

### 其他主播义务

- 发布的商品内容与商品链接应保持一致且实时有效（第24条）
- **不得对商品和服务进行虚假宣传**（第25条）
- 直播中的承诺应遵守法律法规，遵循平台规则（第26条）
- **不得以任何形式导流用户私下交易**（第27条）
- 向商家/平台提供的营销数据应真实，**不得流量造假、虚假购买骗取佣金**（第28条）
- 主播以机构名义活动的，机构应对签约主播行为负责（第29条）

## 四、平台义务（第30-37条）

| 义务类别 | 内容 |
|---------|------|
| 准入审核 | 要求入驻主体提交真实身份或资质证明，登记建档 |
| 平台规则 | 建立入驻服务协议、制定禁止推销商品/服务目录、建立信用评价奖惩体系 |
| 交易信息保存 | 依法保存网络直播营销交易相关内容 |
| 争议处理 | 完善平台间争议处理衔接机制，协助消费者维权 |
| 知识产权保护 | 建立知识产权保护规则和投诉处理机制 |
| 投诉举报 | 建立便捷的投诉举报机制，及时处理 |
| 内容审核 | 加强直播营销内容生态审核和内容安全治理 |
| 主播管理 | 规范主播准入和营销行为，加强教育培训及管理 |
| 电商平台 | 督促商家公示营业执照、行政许可等信息 |
| 内容平台 | 防止主播诱导用户线下交易 |
| 社交平台 | 禁止主播诱导用户绕过合法交易程序进行线下交易；防范利用社交群组进行违法犯罪 |

## 五、MCN 机构义务（第38-40条）

- 依法取得经营主体资质，与相关主体签订协议明确权利义务
- 确保提交的主体资质材料、账号信息真实有效
- **建立健全内部管理规范**，签约具备相应资质和能力的主播
- 对签约主播进行基本素质、现场应急能力培训
- **对签约主播内容发布进行事前规范、事中审核、违规行为事后及时处置**

### MCN 禁止行为（第40条）

1. 获取不正当利益（如向主播不正当收费）
2. 未恰当履行合作协议，造成恶劣影响
3. 违背承诺、不守信经营
4. 扰乱直播营销活动秩序（如**数据造假或作弊**）
5. 侵犯他人权益（不当使用他人权利、泄露信息、骗取财物、骚扰他人等）
6. 故意或疏于管理，导致实际主播与提交的身份信息不符

## 六、鼓励与监督（第42-44条）

- 鼓励公益直播（脱贫攻坚、乡村振兴等）
- 中国广告协会对违反规范的行为可：**提示劝诫、督促整改、公开批评**，涉嫌违法的**提请政府监管机关依法查处**

---

**备注**：本规范为行业自律规范，不具法律强制力。但实务中，监管部门在认定直播营销行为的合规性时，往往参照本规范判断经营者是否尽到"合理注意义务"。违反本规范的行为也可能同时违反《广告法》《反不正当竞争法》等法律法规。
