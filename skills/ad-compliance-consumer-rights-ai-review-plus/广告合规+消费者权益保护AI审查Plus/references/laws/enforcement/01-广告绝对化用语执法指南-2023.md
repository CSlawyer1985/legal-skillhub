# 广告绝对化用语执法指南（2023年）

来源：市场监管总局 https://www.samr.gov.cn/ggjgs/tzgg/art/2023/art_183b5cb48d9e4f0dba67f9f912a913ba.html

**2023年第6号公告，2023年2月25日发布**

## 一、核心定义

**广告绝对化用语**：指《广告法》第9条第3项规定的情形，包括"国家级""最高级""最佳"以及与其含义相同或近似的其他用语。

执法原则：过罚相当、公平公正、处罚和教育相结合、综合裁量。

## 二、不视为广告的情形（第4条）

商品经营者在经营场所、自设网站或拥有合法使用权的其他媒介发布有关自身名称、简称、标识、成立时间、经营范围等信息，且**未直接或间接推销商品**的，一般不视为广告。

> 但信息中使用绝对化用语且无法证明真实性的，可能依据其他法律法规查处。

## 三、不适用绝对化用语规定的情形

### A. 未指向推销商品的（第5条）★

以下情形**不适用**《广告法》关于绝对化用语的规定：

1. 仅表明服务态度、经营理念、企业文化、主观愿望的
   - 例："顾客至上""追求卓越""力争第一"
2. 仅表达目标追求的
   - 例："打造行业领先品牌"
3. 绝对化用语指向的内容与推销的商品性能/质量**无直接关联**，且不会对消费者产生误导的其他情形

### B. 指向商品但不具有误导后果的（第6条）★

以下情形虽有绝对化用语指向商品，但**不具有误导消费者或贬低其他经营者的客观后果**，不适用绝对化用语规定：

1. **同一品牌或同一企业商品的自我比较**
   - 例："本产品是本公司最高端系列"
2. **消费提示用途**
   - 例："最佳食用日期""最长保存期限"
3. **国家标准/行业标准/地方标准认定的商品分级用语**，能说明依据的
   - 例："一级品""优级品"
4. **商品名称、规格型号、注册商标或专利中含有绝对化用语**，用于指代商品以区分其他商品的
   - 例：商品名为"极品乌龙茶"、商标含"至尊"
5. **国家有关规定评定的奖项、称号中含有绝对化用语**
   - 例："国家级非物质文化遗产"
6. **在限定具体时间、地域等条件下**，表述时空顺序客观情况或宣传销量、销售额、市场占有率等**事实信息**的
   - 例："2024年天猫双11品类销量第一"（须有数据支撑）

> **重要限制（第7条）**：上述情形中，广告主**无法证明真实性**的，仍依照《广告法》查处。

## 四、不予处罚与从轻处罚情形 ★

### 可不予行政处罚（第9条）

初次在广告中使用绝对化用语，**危害后果轻微并及时改正**的，可以不予行政处罚。

### 应当不予/从轻处罚（第10条）

在经营场所、自设网站或拥有合法使用权的其他媒介发布的广告中使用绝对化用语：
- **持续时间短或浏览人数少，没有造成危害后果并及时改正的** → **应当依法不予行政处罚**
- 危害后果轻微的 → 可以依法从轻、减轻行政处罚

## 五、不适用从轻/免罚的情形（第11条）★

以下情形**一般不认为属于违法行为轻微或社会危害性较小**：

1. **医疗、医疗美容、药品、医疗器械、保健食品、特殊医学用途配方食品**广告中出现与**疗效、治愈率、有效率**等相关的绝对化用语
2. **招商等有投资回报预期的商品**广告中出现与**投资收益率、投资安全性**等相关的绝对化用语
3. **教育、培训**广告中出现与教育/培训机构或教育/培训效果相关的绝对化用语

## 六、广告合规审查速查

| 场景 | 结论 |
|------|------|
| "国家级非物质文化遗产" | ✅ 不违规（奖项称号） |
| "2025年天猫品类销量第一" | ✅ 不违规（限定时段+事实信息，需有数据支撑） |
| "本公司最高端产品" | ✅ 不违规（自我比较） |
| "顾客至上、追求卓越" | ✅ 不违规（经营理念） |
| "一级品"（国标分级） | ✅ 不违规（标准分级用语） |
| "全球最好的护肤品" | ❌ 违规（指向商品性能的绝对化用语） |
| "治愈率最高的膏药" | ❌ 违规（医疗+疗效绝对化，不适用免罚） |
| "收益率最高的理财产品" | ❌ 违规（招商投资+安全性绝对化，不适用免罚） |
| 小企业官网短暂使用"最佳"后主动删除 | ✅ 可不予处罚（初次+轻微+及时改正） |
