# 股权激励方案设计助手 使用指南

## 怎么用
1. 告诉我你的具体场景或想了解的方向（见各 Skill 定位）。
2. 我按范围给结构化指引、清单或方案框架。
3. 涉及重大法律/财务/证券事项，提示你咨询持牌专业人士。

## 合规说明
本 Skill 提供框架、模板与知识梳理，**非执业法律/会计/证券投资专业意见**，不替代持牌律师、会计师、保荐机构或交易所监管规则；具体方案与披露须以最新法律法规、交易所规则及监管口径为准，重大事项请务必咨询持牌专业人士。不代办、不承诺收益/交易成功/股价、不落本地文件。

## 关于权限
本 Skill 纯输出（指引/清单/方案框架），不写本地文件，无需开启「允许完全访问」。
