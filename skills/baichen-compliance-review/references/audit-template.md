## 一、报告六章结构（承接 Phase 5.1，逐章要素展开）

| 章 | 标题（沿用 Phase 5.1） | 必备要素 | ⛔ 禁止 |
|---|---|---|---|
| 一 | 审查范围与方法 | 审查目的、审查范围（含主体/期间/地域）、审查方法（材料审阅/访谈/抽凭/公开检索）、材料清单及来源、限制与假设 | ⛔ 禁止省略「限制与假设」；⛔ 禁止将未获取材料写成已获取 |
| 二 | 适用法规体系 | 法规层级图谱（法律→行政法规→部门规章/规范性文件→行业标准/自律规则→地方性法规规章→域外法）、核心合规义务摘要、域外法规适用分析、监管机构与执法权限 | ⛔ 禁止只列名不标版本/施行日；⛔ 禁止引用未标状态的法条（见 §四） |
| 三 | 逐项对标审查 | 按子领域分节，每节「法规要求→企业现状→七列对标表→合规度评分小结」；六层面结论须逐一呈现 | ⛔ 禁止跨子领域混编；⛔ 禁止省略「合规度评分小结」 |
| 四 | 差距汇总与风险评估 | 高/中/低风险逐项编号、风险评估矩阵（可能性 × 影响程度）、差距与法条的逐项映射 | ⛔ 禁止无编号罗列；⛔ 禁止风险定级不给理由 |
| 五 | 整改路线图 | P0／P1／P2 三档（见 §二）、整改优先级矩阵、每项整改的责任主体建议与验收标准 | ⛔ 禁止只列问题不给期限；⛔ 禁止以「尽快整改」代替具体期限 |
| 六 | 结论 | 总体合规评价、核心风险警示、整改后合规展望、后续建议（含复审时点建议） | ⛔ 禁止使用「基本合规」「原则上合规」等模糊措辞（Phase 5.2 明令禁止） |
| 附件 | — | 法规全文索引、对标审查完整表（六层面）、整改事项跟踪表、参考案例汇编 | ⛔ 禁止以正文替代附件完整表；⛔ 禁止附件与正文数据不一致 |

> **强制**：六章**必须**全部出具，⛔ 禁止合并章节、禁止跳章、禁止以「无相关内容」整章略去（确无内容的，须在章下写明「本次审查范围内未涉及」并说明原因）。

## 二、整改路线图三档（P0／P1／P2）

> 三档的期限口径**沿用** `SKILL.md` Phase 5.1 第五章既有定义（P0 紧急 1 个月／P1 短期 1–3 个月／P2 中期 3–12 个月），本表为其「适用情形／交付动作／验收标准」展开，⛔ 不得改期限、不得改档名。

### 2.1 P0 档（1 个月内）

| 项 | 内容 |
|---|---|
| **适用情形** | ①触及法律强制性禁止性规定，继续存续将直接产生行政处罚或刑事责任；②存在正在持续的违法行为（如未完成法定义务仍在实施相关行为）；③可能引发重大声誉损失或监管即时介入；④涉人身安全、公共安全或大规模个人权益的紧迫风险 |
| **交付动作** | ①出具**立即停止/暂停**的具体行为清单（写明停止的具体行为与生效时点）；②出具应急处置方案（含对内通报、对外沟通口径、证据保全）；③出具补正路径与最短合规路径；④同步提示监管沟通/主动报告的可行性及利弊 |
| **验收标准** | ①违法行为已实际停止并有书面证据；②应急处置已完成并留痕；③已确定责任主体与完成时限并载入整改台账；④整改后复核查验通过（复查须形成书面记录） |

> **强制**：P0 项**必须**在报告正文中以独立编号单独列出，**禁止**与 P1/P2 混排；⛔ P0 项**不得**因整改成本高而降档，降档**必须**写明理由并经用户书面确认。

### 2.2 P1 档（1–3 个月）

| 项 | 内容 |
|---|---|
| **适用情形** | ①已违反法定义务但无紧迫现实损害（如制度缺失、流程未闭合）；②监管关注度高、限期整改风险明确；③已发生民事争议或存在明确民事赔偿风险；④制度与现行法冲突但尚未造成后果 |
| **交付动作** | ①出具制度/流程修订建议稿（含新旧对照表）；②出具整改任务分解表（事项／责任部门／里程碑）；③出具人员培训与宣贯方案；④出具配套表单模板（如审批单、留痕表） |
| **验收标准** | ①修订后制度已通过内部审批并公示/签收；②流程已在系统中配置并产生实际留痕记录；③培训已完成且有签到与考核记录；④复查抽查样本执行率达标（建议 ≥90%） |

### 2.3 P2 档（3–12 个月）

| 项 | 内容 |
|---|---|
| **适用情形** | ①未违反强制规定但与国际/行业最佳实践存在差距；②管理优化类事项；③需较长期投入的体系建设（如合规管理体系认证、信息系统改造）；④法规已公布但尚未施行、需提前布局的过渡事项 |
| **交付动作** | ①出具体系建设路线图（分阶段里程碑）；②出具制度优化建议（非强制项）；③出具行业对标分析；④出具复审与持续改进机制建议 |
| **验收标准** | ①各阶段里程碑按期达成并有交付物；②已建立定期自查机制（建议每 6 个月一次）并形成自查记录；③改进效果可量化（指标前后对比） |

### 2.4 整改优先级矩阵（判档口径）

| | 后果严重性：高 | 后果严重性：中 | 后果严重性：低 |
|---|:--:|:--:|:--:|
| **发生可能性：高** | **P0** | **P0** | P1 |
| **发生可能性：中** | **P0** | P1 | P2 |
| **发生可能性：低** | P1 | P2 | P2 |

> **强制**：判档**必须**先填写「发生可能性」与「后果严重性」两轴再查表得出档位，⛔ 禁止直接凭直觉定档；两轴判定理由**必须**写入整改台账。⛔ 矩阵结果与风险三级（高/中/低）不一致的，**必须**在报告中说明理由。

## 三、报告封面与免责/范围限制声明模板

### 3.1 封面模板

```
［合规领域］合规审查报告

目标公司（全称）：＿＿＿＿＿＿＿＿＿＿
审查基准日：＿＿＿＿年＿＿月＿＿日
出具日期：＿＿＿＿年＿＿月＿＿日
出具机构：＿＿＿＿＿＿＿＿＿＿
报告编号：＿＿＿＿＿＿＿＿＿＿
版本：第 ＿＿ 版（草稿／送审稿／正式稿）

严格保密
```

> **强制**：封面**必须**载明「审查基准日」与「出具日期」两个独立日期，⛔ 禁止合并或省略；「严格保密」标识⛔ 禁止刪除。

### 3.2 免责与范围限制声明模板（置于封面次页）

```
一、审查范围限制
1. 本报告基于委托方提供的材料以及本所独立进行的公开检索作出，审查范围以本报告第一章「审查范围与方法」所列为准。
2. 本报告所述「企业现状」以委托方提供的材料为限；本所未对材料的真实性、完整性、准确性进行独立审计，委托方对材料的真实性、完整性与准确性负责。
3. 标注「待补充」的事项，因材料不足未能形成判断，本报告不作结论，且不构成对该事项合规性的任何明示或默示保证。
4. 本报告的结论仅适用于审查基准日的法律状态；基准日之后法律法规发生变化或企业情况发生变化的，本报告结论须相应调整。

二、方法与假设
5. 本报告采用材料审阅、人员访谈、抽样凭证核查与公开信息检索相结合的方法；抽样核查的样本范围与数量见第一章，抽样结论不代表对全部同类事项的逐一核查结论。
6. 本报告以中国法为适用法（含域外法的部分另行注明并单独说明适用前提）。

三、使用限制
7. 本报告仅供委托方为本次审查目的使用，⛔ 不得被任何第三方援引，⛔ 不得用于本次审查目的之外的任何用途，⛔ 不得作为诉讼、仲裁或行政程序中的意见证据使用，除非本所事先书面同意。
8. 本报告不构成对任何投资、交易或商业决策的推荐。

四、法条状态声明
9. 本报告所引法律法规均已标注版本与施行日期，并经核验确认于审查基准日现行有效；标注为待核验的条文未作为结论依据。
```

> **强制**：声明第 7 条三项「⛔ 不得」**必须**原样保留，⛔ 禁止弱化或删除；第 9 条**必须**与本报告「法条锚点表」的三态统计保持一致，⛔ 禁止在无锚点表的情况下出具该条。

## 四、交付前强制自检（撰写完成→生成 Word 之间的必经步骤）

1. **必须**逐条核验报告所引全部法条的状态、版本、施行日期，并对照本技能「法条锚点表」与「待核验清单」逐项打勾。
2. **必须**确认正文与附件数据一致（对标表编号、整改档位、风险等级三处**必须**完全对应）。
3. **必须**确认全部「⬜无法判断」项已在第一章「限制与假设」中列明。
4. **必须**确认 P0 项已独立编号并单独成节。
5. **必须**执行 `ndr-standards.md` §15.4（法条状态与依据时效普检）五项：①法条状态 ②时效标注 ③时法选择 ④前置条件 ⑤冲突取舍。
6. ⛔ **严禁**在自检未全部通过的情况下生成 Word 交付稿。

> 撰写与自检遵循 `ndr-standards.md` §7.8（依据时效与程序前置）；交付前另执行 `SKILL.md` Phase 6 所列 §8.3、§15、§15.4、§16 四项，四者缺一不得生成交付稿。
