## 一、接案与案由分析

### 1.1 接案当场动作

收到民事案件后，**第一时间**完成以下判断：

#### 案由判定（确定法律关系）
```
根据当事人描述，对照《民事案件案由规定》确定一级案由：
- 人格权纠纷：生命权/健康权/名誉权/肖像权
- 婚姻家庭继承：离婚/抚养/赡养/继承
- 物权纠纷：所有权/担保物权/占有保护
- 合同纠纷：买卖/借款/租赁/承揽/建设工程/委托/服务
- 侵权纠纷：机动车/医疗损害/产品责任/劳务/安保义务
- 劳动争议：劳动合同/工伤/竞业限制
- 公司与证券：股权/公司决议/股东损害债权人利益
- 执行异议之诉：案外人执行异议/执行分配方案异议
```

常见案由速查见 [专题：案由速查](#专题案由速查)

#### 接案六问（必须逐一确认）
| 问题 | 目的 |
|------|------|
| ① 什么时候发生的事？ | 判断诉讼时效（一般3年） |
| ② 对方是谁？住在哪里？ | 确定被告和管辖 |
| ③ 你有什么证据？ | 初评胜诉可能 |
| ④ 你之前有没有找过对方/法院？ | 判断时效中断 |
| ⑤ 你想达到什么目的？ | 明确诉讼请求 |
| ⑥ 对方有没有财产？ | 评估执行可行性 |

#### 代理方向判断
- **原告代理人**：分析请求权基础→确定诉讼请求→搜集整理证据→起草起诉状
- **被告代理人**：分析原告诉请是否成立→审查管辖权→搜集抗辩证据→起草答辩状
- **第三人代理人**：分析本诉对其权益的影响→确定诉讼策略

### 1.2 委托手续
| 文书 | 份数 | 备注 |
|------|------|------|
| 法律服务合同 | 2份 | 明确代理阶段、收费方式 |
| 授权委托书 | 3份 | 特别授权/一般代理（特别授权需注明可和解/调解/上诉/执行） |
| 律师事务所函 | 1份 | |
| 风险告知书 | 1份 | 诉讼风险+执行风险 |
| 委托人身份证明 | 1份 | 自然人身份证/法人营业执照 |
| 法定代表人身份证明 | 1份 | 法人作为当事人时 |

### 1.3 收费
- **按标的额比例收费**：分段累计
- **计时收费**：按实际工作时间
- **风险代理**：按执行回款的百分比（注意：婚姻继承/刑事/行政/国家赔偿/群体性案件**禁止风险代理**；风险代理最高不超过标的额30%；标的额100万以下不超过18%，100-500万不超过15%，500-1000万不超过12%，1000-5000万不超过9%，5000万以上不超过6%）

## 二、诉前策略与准备

### 2.1 诉讼时效审查（最关键一步）

**一般诉讼时效：3年**（自知道或应当知道权利受损及义务人之日起算）

| 情形 | 时效起算点 |
|------|----------|
| 约定履行期限的债务 | 履行期限届满次日 |
| 未约定履行期限的债务 | 债权人主张权利时起算 |
| 侵权损害赔偿 | 知道或应当知道损害发生+侵权人之日 |
| 分期履行债务 | 最后一期履行期限届满 |

**时效中断事由：** ①催告（需有证据）；②起诉/申请仲裁；③对方同意履行（需有证据）

**时效快到期应对：**
- 发律师函催告（固定时效中断证据）
- 让对方出具还款承诺/还款计划
- 先行起诉

### 2.2 管辖法院确定

#### 管辖确定步骤
1. **是否为专属管辖**？→ 不动产(不动产所在地)/港口作业(港口所在地)/遗产继承(被继承人死亡时住所地或主要遗产所在地)
2. **是否有协议管辖**？→ 约定的法院（必须与争议有实际联系且不违反级别管辖和专属管辖）
3. **一般地域管辖** → 被告住所地/经常居住地（公民）/被告注册地/主要办事机构所在地（法人）
4. **特殊地域管辖** → 合同纠纷(合同履行地/被告住所地)、侵权纠纷(侵权行为地/被告住所地)、票据纠纷(票据支付地/被告住所地)

> 💡 策略：多个法院有管辖权时，选择对己方最有利的（考虑地方司法实践差异/执行便利性/诉讼成本）

### 2.3 证据收集与组织

#### 证据收集清单（按案由分类索取）
**合同纠纷：** 合同原件/补充协议/变更协议/履行凭证（收付款凭证/送货单/验收单/对账单）/催告记录/往来函件

**侵权纠纷：** 事故认定书/诊断证明/医疗费票据/误工证明/伤残鉴定/现场照片/监控录像/目击证人

**婚姻家事：** 结婚证/户口本/财产证明/收入证明/过错证据/子女出生证明

**劳动争议：** 劳动合同/工资流水/考勤记录/解除通知书/社保缴纳记录

**公司股权纠纷：** 公司章程/股东名册/股东会决议/出资证明/股权转让协议

#### 证据组织策略
详细见 [专题：证据组织策略](#专题证据组织策略)

### 2.4 财产保全

**申请时机：**
- 诉前保全：起诉前（需提供足额担保，法院48小时内裁定）
- 诉中保全：起诉同时或诉讼中

**准备材料：**
1. 财产保全申请书（明确被保全财产线索）
2. 担保财产证明（现金/房产/保险公司保函）
3. 被保全财产线索（银行账号/不动产地址/车辆牌号/股权信息）

**策略考量：**
- 诉前冻结对方账户 → 施压促进调解
- 防止对方转移财产 → 保障执行

## 三、起诉与立案

### 3.1 民事起诉状撰写

#### 核心结构
```
民事起诉状

原告：[姓名/名称、性别、出生日期、民族、住所、联系方式]
（法人：名称、住所、法定代表人、统一社会信用代码）

被告：[同上]

诉讼请求：
1. [明确、具体、可执行] 例如：判令被告支付货款人民币XX元
2. [利息] 判令被告支付自X年X月X日起至实际清偿日止以XX元为基数按LPR/X%计算的利息
3. [诉讼费] 本案诉讼费由被告承担

事实与理由：
一、[基本事实概述：时间、地点、人物、事件经过]
二、[合同/侵权/其他法律关系的形成过程]
三、[被告违约/侵权的具体行为]
四、[造成原告损失的具体情况]
五、[法律依据：列明适用的法条]

此致
[XX人民法院]

具状人：[签名/盖章]
日期：
```

#### 撰写技巧
- 诉讼请求必须**具体明确可执行**，不可笼统写"赔偿损失"
- 事实叙述按**时间顺序**，简明扼要
- 法律依据引用到**具体法条**
- 不要在起诉状中自认不利事实

### 3.2 立案材料清单

| 材料 | 份数 | 备注 |
|------|------|------|
| 民事起诉状 | N+1份 | N=被告人数 |
| 证据材料复印件 | N+1份 | 附证据目录 |
| 原告身份证明 | 1份 | |
| 授权委托手续 | 1套 | 委托书+所函+执业证复印件 |
| 被告身份信息 | 1份 | 自然人身份证号/法人企业信用信息 |
| 财产保全申请 | 1套 | 如同时申请 |
| 送达地址确认书 | 1份 | 法院提供模板 |

### 3.3 立案审查
- 法院收到材料后**7日**内决定是否受理
- 不符合条件：裁定不予受理（可上诉）
- 符合条件：立案并通知缴费
- **诉讼费缴纳**：收到缴费通知后7日内缴纳，逾期按撤诉处理

## 四、庭前准备

### 4.1 举证

#### 举证期限
- 普通程序：一般不少于15日
- 简易程序：可缩短，一般不超过15日
- 举证期限内提交全部证据，逾期可能不被采纳

#### 证据目录格式
```
证据目录

案号：（立案后补填）
原告/被告方证据

| 编号 | 证据名称 | 证据来源 | 页码 | 证明目的 |
|------|---------|---------|------|---------|
| 证1 | [名称] | [来源] | 1-5 | [证明XX事实] |

提交人：
日期：
```

#### 举证相关申请
- 申请法院调查取证（当事人客观上无法自行收集）
- 申请证人出庭（开庭10日前书面申请）
- 申请鉴定（可在举证期限内提出）
- 申请延长举证期限
- 申请证据保全

### 4.2 程序性文书

| 文书 | 提交时机 | 时限 |
|------|---------|------|
| 管辖权异议申请书 | 提交答辩状期间 | 15日内 |
| 追加被告申请书 | 举证期限内 | |
| 变更/增加诉讼请求 | 举证期限届满前 | |
| 反诉状 | 举证期限届满前 | |
| 不公开审理申请书 | 开庭前 | |
| 回避申请书 | 开庭时或知悉回避事由时 | |
| 延期审理申请书 | 开庭前 | |

### 4.3 代理意见准备

#### 庭审提纲要素
- **案情时间轴**：以时间为线索梳理关键事实
- **争议焦点预判**：预判法官审理重点
- **法律依据梳理**：相关法条+司法解释+类案
- **对方可能论点及回应**：模拟对抗

#### 代理词准备
详见 [专题：代理词撰写指南](#专题代理词撰写指南)

## 五、开庭审理

### 5.1 庭审流程与应对

| 环节 | 原告方动作 | 被告方动作 |
|------|-----------|-----------|
| 庭前核对 | 确认当事人到庭、提交授权 | 确认管辖权、是否申请回避 |
| 原告陈述 | 宣读起诉状（可简化为"同起诉状"） | — |
| 被告答辩 | — | 口头答辩/提交书面答辩状 |
| 举证质证 | 逐一出示证据→说明证明目的 | 围绕三性质证→提出质疑 |
| 被告举证 | 质证被告证据 | 出示己方证据 |
| 法庭询问 | 回答法官提问→发问对方→发问证人 | 同左 |
| 法庭辩论 | 发表代理意见→回应对方观点 | 同左 |
| 最后陈述 | 坚持诉讼请求 | 坚持答辩意见 |
| 调解 | 表达调解意愿和方案 | 同左 |

### 5.2 质证技巧

围绕证据"三性"发表质证意见（同刑事标准）：
- **真实性**：证据是否伪造变造/内容是否真实
- **合法性**：取证主体/手段/程序/形式是否合法
- **关联性**：是否与本案待证事实相关

**质证话术模板：**
- "对该证据的真实性予以认可，但对关联性有异议，该证据不能证明……"
- "对该证据的真实性不予认可，理由如下：1.…2.…"
- "对该证据的合法性有异议，该证据系……方式取得，违反……规定"

### 5.3 法庭辩论策略

#### 辩论要素
1. **紧扣争议焦点**：围绕法官归纳的焦点展开，不要偏离
2. **事实+证据+法律**：每个论点要有事实支撑、证据支撑、法律支撑
3. **逻辑递进**：按请求权基础分析顺序辩论
4. **回应对方**：逐一驳斥对方核心观点
5. **类案参考**：可引用最高人民法院的指导性案例/典型案例

### 5.4 庭审笔录
- 庭审结束后核对笔录
- 发现遗漏或错误立即要求补正
- 重大案件可安排助理同步记录庭审要点

## 六、判决后工作

### 6.1 收到判决书后的动作

#### 立即工作
1. 研读判决书，分析胜败诉原因
2. 与当事人沟通判决结果
3. 评估是否上诉：
   - **事实认定**：有无明显错误
   - **法律适用**：有无明显错误
   - **程序**：有无严重违法
   - **利益衡量**：上诉成本与预期收益

#### 上诉时限
- 判决书送达后**15日内** → 决定是否上诉
- 裁定书送达后**10日内** → 决定是否上诉（不予受理/管辖权异议/驳回起诉）

### 6.2 上诉程序

#### 上诉状要点
```
1. 一审判决基本情况和结果
2. 上诉请求：撤销原判/改判/发回重审
3. 上诉理由：
   - 原判决认定事实错误：[具体指出+证据]
   - 原判决适用法律错误：[具体指出+正确法律适用]
   - 原判决违反法定程序：[具体指出+对判决结果的影响]
4. 可提交新证据（需说明一审未提交的合理理由）
```

#### 二审审理
- 审限：判决3个月/裁定30日
- 二审可调解

### 6.3 再审程序

#### 申请再审条件
- 期限：判决生效后**6个月**内
- 法定事由（《民事诉讼法》第211条，13项）
- 向上一级法院或原审法院申请

## 七、强制执行

### 7.1 申请执行

#### 申请条件
- 法律文书已生效
- 义务人未按文书履行义务
- 在法定期限内申请：**2年**（从履行期间届满日起算）
- 中止/中断适用诉讼时效规定

#### 申请材料
1. 强制执行申请书
2. 生效法律文书原件
3. 被执行人财产线索
4. 申请人身份证明
5. 授权委托手续

### 7.2 财产调查
- 银行存款（人民银行查控系统）
- 不动产（自然资源局登记中心）
- 车辆（车管所）
- 工商股权（市场监督管理局）
- 证券（中国结算）
- 被执行人申报财产令

### 7.3 执行措施递进
1. 发出执行通知 → 2. 查询财产 → 3. 冻结/扣划银行账户 → 4. 查封不动产/车辆 → 5. 拍卖变卖 → 6. 限制消费 → 7. 纳入失信名单 → 8. 罚款拘留 → 9. 追究拒执罪

### 7.4 执行异议
- 案外人异议（15日内审查）
- 当事人/利害关系人异议
- 执行分配方案异议
- 执行异议之诉（15日内起诉）

## 专题：案由速查

### 常见合同纠纷案由
| 案由 | 管辖 | 核心证据 | 诉讼时效 |
|------|------|---------|---------|
| 买卖合同纠纷 | 合同履行地/被告住所地 | 合同+送货单+对账单 | 3年 |
| 借款合同纠纷 | 合同履行地/被告住所地 | 借条/转账记录/还款记录 | 3年 |
| 建设工程施工合同 | 工程所在地(专属管辖) | 合同+结算单+验收报告 | 3年 |
| 租赁合同纠纷 | 合同履行地/被告住所地 | 合同+租金支付记录 | 3年（租金） |
| 委托合同纠纷 | 合同履行地/被告住所地 | 委托协议+履行凭证 | 3年 |
| 服务合同纠纷 | 合同履行地/被告住所地 | 合同+服务成果+付费记录 | 3年 |
| 保证合同纠纷 | 合同履行地/被告住所地 | 保证合同+主债务凭证 | 3年 |

### 常见侵权纠纷案由
| 案由 | 管辖 | 核心证据 | 诉讼时效 |
|------|------|---------|---------|
| 机动车交通事故 | 事故发生地/被告住所地 | 事故认定书+医疗记录+费用票据 | 3年 |

## 专题：证据组织策略

### 证据组织原则
1. **完整性**：形成完整证据链，每个事实环节有证据支撑
2. **合法性**：确保证据来源合法、形式规范
3. **层次性**：核心证据（能直接证明的）优先→辅助证据→补强证据
4. **针对性**：每个证据对应一个证明目的，避免"万能证据"

### 按案件类型组织证据

#### 借贷纠纷证据包
```
□ 核心证据层（请求权基础）
   ├── 借条/借款合同（含签字/盖章/指印）
   ├── 银行转账凭证/微信支付宝转账记录
   └── 现金交付的收条

□ 辅助证据层（补强）
   ├── 催收记录（短信/微信/邮件/通话录音）
   ├── 还款记录（证明借款关系的延续）
   └── 证人证言（见证借款过程）

□ 关联证据层（辅助认定）
   ├── 双方关系证据（为何出借）
   ├── 借款用途证据（资金流向）
   └── 对方承认债务的录音/记录
```

#### 交通事故赔偿证据包
```
□ 责任认定层
   ├── 交通事故认定书
   ├── 现场照片/监控录像
   └── 目击证人

□ 损害证明层
   ├── 诊断证明/病历/出院小结
   ├── 医疗费票据（发票+明细）
   ├── 伤残鉴定意见书（如有）
   ├── 误工证明（劳动合同+工资流水+扣发证明）
   ├── 护理费/营养费/交通费票据
   └── 被扶养人身份证明+关系证明（如有）

□ 赔偿计算层
   └── 赔偿明细清单（逐项列明计算依据和标准）
```

### 证据链审查清单（被告/质证用）
- [ ] 合同是否有涂改痕迹？签字/盖章是否真实？
- [ ] 转账记录是否与借款对应？有无备注？
- [ ] 催收记录时间是否连续？内容是否与本案相关？
- [ ] 录音/录像是否完整无剪辑？
- [ ] 证人与当事人有无利害关系？
- [ ] 鉴定机构是否具备资质？方法是否科学？

## 一、接案与罪名分析

### 1.1 接案当场动作

收到刑事案件后，**第一时间**完成以下判断：

#### 罪名初步判定
```
根据当事人/家属描述的行为，对照刑法分则确定可能涉及的罪名：
- 侵犯人身权利：故意杀人(232)、故意伤害(234)、强奸(236)、非法拘禁(238)
- 侵犯财产权利：盗窃(264)、抢劫(263)、诈骗(266)、职务侵占(271)、挪用资金(272)
- 破坏经济秩序：非法吸收公众存款(176)、集资诈骗(192)、虚开发票(205)
- 妨害社会管理：开设赌场(303)、寻衅滋事(293)、帮信罪(287之二)
- 贪污贿赂：贪污(382)、受贿(385)、行贿(389)
- 渎职：滥用职权(397)、玩忽职守(397)
```

#### 罪名分析四要素（必须逐一分析）
| 要素 | 分析要点 |
|------|---------|
| **犯罪构成** | 主体（谁）→ 主观（故意/过失）→ 客体（侵害什么）→ 客观（做了什么） |
| **量刑档次** | 基本刑→加重情节→减轻情节；数轴标注最低-最高刑期 |
| **证据门槛** | 定罪需哪些证据？现有证据能否闭合证据链？缺口在哪？ |
| **辩护空间** | 罪名是否恰当？有无轻罪辩护空间？有无无罪可能？ |

#### 强制措施预判
- 是否已被刑事拘留？拘留起算日？
- 是否符合取保候审条件？（可能判管制/拘役/附加刑；可能判有期以上但不致发生社会危险；重病/怀孕/哺乳；羁押期满未结案）
- 是否涉及三类案件（危害国家安全/恐怖活动/特别重大贿赂）？

### 1.2 委托手续

| 文书 | 份数 | 用途 |
|------|------|------|
| 法律服务合同 | 2份 | 分阶段签（侦查/审查起诉/审判各签一份，或一次性签全程） |
| 授权委托书 | 3份 | 交侦查机关、检察院、法院各一份 |
| 律师事务所函 | 3份 | 同上 |
| 委托人身份证复印件 | 1份 | |
| 亲属关系证明 | 1份 | 委托人非嫌疑人本人时（结婚证/户口本/居委会证明） |
| 风险告知书 | 1份 | 当事人确认知晓诉讼风险 |

> ⚠️ 刑事案件禁止风险代理！收费方式：计件收费/计时收费/按阶段收费。

## 二、侦查阶段

### 2.1 目标
- 尽快见到嫌疑人，了解案情
- 争取变更强制措施（取保候审/监视居住）
- 阻止不当侦查行为（刑讯逼供、超期羁押）
- 为审查起诉阶段打好基础

### 2.2 动作清单

#### 第一次会见（接受委托后24小时内完成）

**会见前准备：**
- 三证：律师执业证 + 律师事务所证明（函）+ 授权委托书
- 准备会见笔录模板（基本信息/案情陈述/权利义务告知/签字确认）
- 了解涉嫌罪名，预判可能的讯问方向

**会见内容：**
1. **确认委托关系**：嫌疑人是否同意委托你（必须本人确认）
2. **了解基本情况**：姓名、年龄、前科、身体状况、是否特殊身份（人大代表等）
3. **了解案情**：
   - 何时被抓？哪个单位抓的？
   - 涉嫌什么罪名？是否已告知？
   - 做了几次笔录？都说了什么？
   - 有没有被刑讯逼供/诱供/指供？
   - 有无同案犯？各人角色？
4. **提供法律咨询**：
   - 告知涉嫌罪名及构成要件、量刑幅度
   - 告知强制措施的法律规定及期限
   - 告知权利义务（沉默权/申请回避/核对笔录/申诉控告）
   - 告知认罪认罚制度的含义和法律后果
5. **制作会见笔录**：嫌疑人签字确认

**会见后动作：**
- 整理会见笔录，提取关键信息
- 如涉及刑讯逼供，准备控告材料
- 如体表有伤，拍照固定 + 申请验伤

#### 申请变更强制措施

**取保候审申请书要点：**
```
1. 嫌疑人基本情况 + 涉嫌罪名
2. 申请理由（选择匹配的法定情形）：
   - 可能判处管制/拘役/独立适用附加刑
   - 可能判处有期徒刑以上但不致发生社会危险
   - 患有严重疾病/正在怀孕/哺乳婴儿
   - 羁押期限届满案件未办结
3. 担保方式：保证金（金额）/保证人（身份+联系方式）
4. 附加条件：可承诺限制出境、交出证件、定期报到
```

提交时机：
- **拘留后即刻提交**：争取在批捕前取保
- **批捕后一周内提交**：申请羁押必要性审查

#### 提交不予批捕法律意见书

**时机**：得知公安机关已提请检察院批准逮捕后，立即提交，在7日审查期内。

**核心论点：**
1. 不构成犯罪（论证犯罪构成要件缺失）
2. 证据不足（现有证据未达到逮捕的证据标准）
3. 无逮捕必要性（社会危险性低）
4. 具备取保候审条件

#### 其他动作
- 申请排除非法证据（有线索即提）
- 申请调取无罪/罪轻证据
- 对超期羁押提出申诉控告

### 2.3 侦查阶段时限

| 措施 | 时限 |
|------|------|
| 传唤/拘传 | 12h（重大复杂可24h） |
| 刑事拘留→提请批捕 | 一般3日→可延长至7日→流窜/多次/结伙30日 |
| 检察院审查批捕 | 7日 |
| 逮捕后侦查羁押 | 2个月→可延长1个月→再延长2个月→再延长2个月（共7个月） |

## 三、审查起诉阶段

### 3.1 目标
- 全面掌握案卷信息
- 形成明确的辩护方向
- 争取不起诉或有利起诉条件
- 为审判阶段做充分准备

### 3.2 动作清单

#### 第一步：阅卷（案件移送审查起诉后24小时内联系检察院预约）

**阅卷流程：**
1. 联系检察院案管中心，预约阅卷时间
2. 持三证到检察院，申请查阅/摘抄/复制案卷
3. 拍照/复印/扫描全部案卷材料
4. 索取电子卷宗（如有）

**详细阅卷方法见 [专题：如何阅卷](#专题如何阅卷)**

#### 第二步：会见核实（阅卷后尽快）

**核实内容：**
- 向嫌疑人核实关键证据（注意：物证/书证/鉴定意见等客观性证据可告知具体内容，证人证言/同案犯供述只能告知梗概）
- 核对笔录与嫌疑人陈述是否一致
- 发现证据矛盾点，再次核实
- 讨论辩护方向（无罪/罪轻/认罪认罚），征得嫌疑人同意

#### 第三步：撰写辩护意见书

**审查起诉阶段辩护意见书结构：**
```
一、基本案情概述
二、证据分析（指出证据缺陷和矛盾）
三、法律分析（犯罪构成分析/量刑分析）
四、辩护意见：
   □ 法定不起诉（无犯罪事实/情节显著轻微/过时效/特赦/死亡）
   □ 酌定不起诉（犯罪情节轻微）
   □ 存疑不起诉（证据不足，退回补充侦查后仍不足）
   □ 量刑从轻意见（自首/立功/从犯/退赃退赔/谅解）
五、程序性请求（取保候审/排除非法证据等）
```

#### 第四步：程序性申请
- **羁押必要性审查申请**：逮捕后每月可申请一次
- **排除非法证据申请**：附线索材料
- **重新鉴定/补充鉴定申请**
- **证人/鉴定人/侦查人员出庭申请**（提前准备）
- **认罪认罚具结**：与检察官协商量刑建议

### 3.3 审查起诉时限
| 阶段 | 时限 |
|------|------|
| 审查起诉 | 1个月 |
| 延长 | 15日（重大复杂） |
| 退回补充侦查 | 每次1个月，最多2次 |
| 补侦后重新审查 | 重新计算1个月 |
| **最长可达** | **6.5个月** |

## 四、审判阶段

### 4.1 目标
- 充分行使辩护权
- 有效质证控方证据
- 完整呈现辩护观点
- 争取最优判决结果

### 4.2 庭前准备动作清单

#### 阅卷（补充侦查后的新证据）
- 审查退回补充侦查获取的新证据
- 更新证据分析和辩护策略

#### 会见（开庭前至少1-2次）
- 确定最终辩护策略
- 模拟庭审发问和回答
- 告知庭审流程和注意事项
- 确认是否申请证人/鉴定人出庭

#### 庭前会议（如有）
- 就管辖/回避/非法证据排除/出庭名单等交换意见
- 申请排除非法证据
- 明确争议焦点

#### 制作庭审材料
- **发问提纲**：按逻辑顺序，封闭式问题为主
- **质证提纲**：按证据编号，逐一写明质证意见
- **举证提纲**（如有辩方证据）：证据目录+证明目的
- **辩护词初稿**：详见 [专题：辩护词撰写指南](#专题辩护词撰写指南)

### 4.3 庭审核心操作

#### 发问技巧
| 类型 | 示例 | 目的 |
|------|------|------|
| 铺垫问 | "你当天是否在公司上班？" | 建立有利事实 |
| 锁定问 | "你在笔录第X页说的XX，是否属实？" | 固定有利供述 |
| 质疑问 | "你说见到被告拿刀，当时距离多远？灯光如何？" | 动摇证言可信度 |
| 补强问 | "有没有人能证明你当时不在场？" | 引出辩方证据 |

**发问原则**：问知道答案的、封闭式为主、一次只问一个事实、不与被告人/证人对吵。

#### 质证技巧
围绕"三性"发表意见：
- **真实性**：证据是否伪造变造？内容是否与实际相符？
- **合法性**：取证主体/程序/形式是否合法？
- **关联性**：与本案是否有关？证明目的与案件事实是否关联？

**逐证质证格式**：
```
对证据X（名称）的质证意见：
1. 真实性：[意见]
2. 合法性：[意见]
3. 关联性：[意见]
综合意见：[不予采信/部分采信/证明力不足]
```

#### 辩论策略
详细见 [专题：辩护词撰写指南](#专题辩护词撰写指南)

### 4.4 一审审限
- 一般：2个月，至迟3个月
- 死刑/附带民事/重大复杂：可延长至6个月
- 补充侦查延期：每次1个月（检察院建议）

---

## 五、上诉与申诉

### 5.1 上诉（一审判决后）

#### 上诉决策（判决书送达后10日内决定）
分析与评估：
- 事实认定是否错误？
- 法律适用是否错误？
- 量刑是否明显不当？
- 程序是否严重违法？

#### 上诉状核心内容
```
1. 一审判决概况
2. 上诉请求（撤销原判/改判/发回重审）
3. 上诉理由：
   - 事实认定错误（指出哪些事实认定有误，证据支撑）
   - 法律适用错误（罪名/量刑/程序违法）
   - 新证据（如有）
4. 提交方式：原审法院或二审法院
```

> ⚠️ 上诉不加刑原则：仅有被告人一方上诉的，二审不得加重刑罚（检察院抗诉/自诉人上诉除外）

#### 二审审理
- **必须开庭**：死刑立即执行/检察院抗诉/对事实证据有异议
- **可以不开庭**：其他情形可书面审理
- 审限：2个月，可延长至4个月

### 5.2 申诉（判决生效后）

#### 申诉条件
- 主体：当事人/法定代理人/近亲属/案外人
- 不停止判决执行
- 可向原审法院或上级法院申诉
- 审查期限：3个月，最长6个月

#### 申诉理由（《刑事诉讼法》第253条）
1. 新证据证明原判决确有错误
2. 据以定罪的证据不确实不充分/存在矛盾/应排除
3. 适用法律错误
4. 程序违法影响公正审判
5. 审判人员有贪污受贿/徇私舞弊/枉法裁判

---

## 六、执行阶段

### 6.1 刑罚执行期间
- 减刑申请：符合条件（认真遵守监规/接受教育改造/确有悔改/立功表现）
- 假释申请：有期徒刑执行1/2以上/无期徒刑13年以上
- 暂予监外执行：严重疾病/怀孕哺乳/生活不能自理

## 专题：常见罪名辩护要点

### 故意伤害罪(234)
- **轻伤/重伤鉴定**：质疑鉴定依据、申请重新鉴定
- **正当防卫**：是否构成正当防卫/防卫过当
- **被害人过错**：被害人先动手/挑衅
- **自首/立功/赔偿谅解**：争取减轻/缓刑

### 盗窃罪(264)
- **数额认定**：质疑价格鉴定、扣除折旧
- **多次盗窃**：每次是否达到入罪标准
- **从犯**：望风/接应人员可辩从犯
- **退赃退赔**：全额退赔争取减轻

### 诈骗罪(266)
- **非法占有目的**：是否有还款意愿和能力
- **民事纠纷vs刑事诈骗**：合同履行能力/经营亏损/不可抗力
- **数额认定**：扣除已归还的、案发前已还的不计入

### 职务侵占罪(271)
- **主体**：是否属于"公司企业人员"
- **利用职务便利**：区别于工作便利
- **本单位财物**：权属是否清晰
- **数额**：6万元以上入罪

### 开设赌场罪(303)
- **是否"开设"**：区别于"聚众赌博"
- **抽头渔利数额/赌资**：质疑计算方式
- **从犯**：荷官/服务员/望风人员可辩从犯

### 帮信罪(287之二)
- **明知**：是否确实知道他人利用信息网络犯罪
- **情节严重**：为3个以上对象/支付结算20万/违法所得1万
- **与共犯区分**：没有通谋，只是提供技术支持

### 非法吸收公众存款罪(176)
- **社会性/公开性/利诱性/非法性**：四性缺一不可
- **数额认定**：扣除亲友/单位内部人员部分
- **退赃退赔**：提起公诉前积极退赃退赔的，可减轻

## 专题：如何阅卷

### 阅卷流程

#### 第一步：宏观浏览
- 先看起诉意见书/起诉书，了解指控内容
- 浏览卷宗目录，掌握证据体系全貌
- 制作证据索引表（编号/名称/来源/页码/类型）

#### 第二步：分类精读

| 证据类型 | 审查重点 |
|---------|---------|
| 被告人供述 | 前后是否一致？与其他证据是否矛盾？是否存在刑讯逼供？ |
| 被害人陈述 | 是否稳定？陈述的合理性？与客观证据是否吻合？ |
| 证人证言 | 证人资格？与案件利害关系？前后是否一致？ |
| 书证 | 来源是否合法？内容是否真实完整？ |
| 物证 | 提取/扣押/保管/鉴定链条是否完整？ |
| 鉴定意见 | 鉴定机构/人员资质？方法是否科学？结论是否唯一？ |
| 视听资料/电子数据 | 提取过程是否规范？是否完整无剪辑？ |
| 勘验/检查/侦查实验笔录 | 程序是否合法？是否有见证人？ |

#### 第三步：制作阅卷摘要

**每份证据的摘要格式：**
```
证据X：[名称]
来源：[侦查机关提取/当事人提供]
页码：卷X第X-X页
内容摘要：[关键内容]
证明目的：[检方想证明什么]
辩方意见：[对该证据的质证意见/可为我所用的内容]
```

#### 第四步：发现矛盾与突破口

- **横向对比**：同案犯供述之间是否一致
- **纵向对比**：同一人前后供述/陈述是否一致
- **交叉对比**：供述与物证/书证/鉴定意见是否吻合
- **程序审查**：取证程序是否有瑕疵（无见证人/无签章/超期）

### 阅卷工具
- Excel表格：制作证据对比表、时间轴
- 思维导图：梳理人物关系、资金流向、事件时间线

## 专题：如何分析证据

### 证据分析框架

#### 1. 单一证据分析
对每一项证据进行"三性"审查：
- **真实性**：证据本身是否真实
- **合法性**：取证程序是否合法
- **关联性**：与待证事实是否相关

#### 2. 证据链分析
- 控方证据链是否闭合？每个环节是否都有证据支撑？
- 证据链中有无断裂？断裂处能否通过辩方证据填补？
- 是否存在合理怀疑空间？

#### 3. 证明力评估
- 直接证据 vs 间接证据
- 原始证据 vs 传来证据
- 言词证据 vs 实物证据
- 有利证据 vs 不利证据

#### 4. 矛盾点分析
| 矛盾类型 | 处理方式 |
|---------|---------|
| 同一人前后矛盾 | 指出不稳定性，质疑可信度 |
| 不同人之间矛盾 | 指出无法印证，质疑真实性 |
| 言词与实物矛盾 | 实物优先，言词存疑 |
| 鉴定与常识矛盾 | 申请重新鉴定/专家辅助人出庭 |

## 专题：辩护词撰写指南

### 辩护词结构

```
刑事辩护词

尊敬的审判长、审判员/人民陪审员：
[律所名称]接受[被告人]的委托/法律援助中心指派，指派我担任[被告人]涉嫌[罪名]一案的辩护人。
现发表辩护意见如下：

一、基本事实概述
[简明概述案情，侧重有利事实]

二、辩护意见
（一）关于定罪
[无罪辩护理由 / 罪名不当应改轻罪理由]
1. [论点一 + 证据支撑]
2. [论点二 + 证据支撑]

（二）关于量刑
1. 自首/坦白（刑法第67条）
2. 立功（刑法第68条）
3. 从犯/胁从犯（刑法第27/28条）
4. 积极退赃退赔
5. 取得被害人谅解
6. 认罪认罚（刑诉法第15条）
7. 系初犯/偶犯，主观恶性小
8. [其他减轻/从轻情节]

（三）关于程序
[如涉及非法证据排除/超期羁押等]

三、量刑建议
建议对被告人判处[刑罚种类][建议刑期]，并建议适用缓刑/免予刑事处罚。

四、结语
[概括辩护核心观点]

此致
[法院名称]

辩护人：[姓名]
[律所名称]
日期：
```

### 辩护策略选择

| 策略 | 适用条件 | 风险 |
|------|---------|------|
| 无罪辩护 | 证据明显不足/不构成犯罪/正当防卫 | 可能激怒法庭 |
| 轻罪辩护 | 指控罪名过重，可改轻罪 | 相对安全 |
| 量刑辩护 | 承认指控但主张从宽处罚 | 放弃无罪机会 |
| 程序辩护 | 程序严重违法 | 可能被驳回 |
| 混合策略 | 无罪辩护+量刑辩护（备位） | 需高超技巧 |
