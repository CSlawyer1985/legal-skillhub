# 表面画像

每个常见目标 AI 表面的风险画像。分析器在此查找用户选择的表面，以在计入内容和案件态势叠加之前确定*基线*风险姿态。

**时效：** 2026 年 4 月。供应商条款会变化。在真实案件中使用以下任何画像之前，律师（或律所 IT/合规部门）必须核实该表面当前的《使用条款》《隐私政策》和《数据处理协议》（依据 ABA 意见 512 § B；引注包 § 5）。本文件是工作快照，不能替代该审查。

**字段模式：**
- **层级：** 消费者（consumer）| 团队（team）| 企业（enterprise）| API | 本地（on-prem）
- **默认以输入训练：** 是 | 否 | 可配置
- **输入保留：** 保留窗口，如为零数据保留（ZDR）则为“零”
- **第三方披露（依使用条款）：** 广泛 | 狭窄 | 无
- **律师-客户特权（A/C）影响：** 适用的 Heppner 式失效模式
- **工作成果影响：** 依 Warner/Morgan 推理，民事姿态
- **ABA 512 保密姿态：** 可能违反 | 附条件 | 可能合规
- **基线区间：** 与案件相关内容的 SAFE（安全）| CAUTION（谨慎）| STOP（停止）

## 消费者表面（默认：任何案件相关内容均 STOP）

### 表面：ChatGPT（免费版、Plus 版）
- **层级：** 消费者
- **默认以输入训练：** 是（设置中可退出，但默认开启）
- **输入保留：** 默认无限期；如禁用聊天历史则为 30 天
- **第三方披露（依使用条款）：** 广泛（法律程序、合作伙伴、服务提供者）
- **A/C 特权影响：** Heppner 三项要素全部失败。非律师；依使用条款不构成保密；非为向模型获取法律意见之目的。
- **工作成果影响：** 依 Warner/Morgan 推理，工作成果在民事证据开示中或可存续——但仅当 (a) 为预期诉讼而准备、(b) 由当事人或其代表准备，且 (c) 依 Morgan 案可单独开示的 AI 工具身份本身不暴露策略时。在刑事姿态或依搜查令（Heppner）下，无保护。
- **ABA 512 保密姿态：** 未经具体知情客户同意，任何案件相关输入均可能违反（引注包 § 5——保密＋样板条款不足的引文）。
- **基线区间：** 任何包含客户信息、律师心智印象或案件特定事实的输入均为 **STOP**。

### 表面：Claude.ai（免费版、Pro 版）
- **层级：** 消费者
- **默认以输入训练：** 付费 Pro 用户否（依 2026 年 4 月使用条款）；免费版历史上可变——核实现行版本
- **输入保留：** 依 Heppner 裁决时（2026 年 2 月）生效的 Anthropic 政策，默认 30 天
- **第三方披露（依使用条款）：** Heppner 法院援引 Anthropic 的政策，保留将用户数据披露给第三方（包括政府监管机构）的权利（引注包 § 1，要素 2）。
- **A/C 特权影响：** 与 ChatGPT 消费者版相同——Heppner 三项要素全部失败。Heppner 正是针对 Claude 消费者版的管辖判例。
- **工作成果影响：** 与 ChatGPT 消费者版分析相同。
- **ABA 512 保密姿态：** 未经具体知情客户同意，案件相关输入可能违反。
- **基线区间：** 任何包含客户信息、律师心智印象或案件特定事实的输入均为 **STOP**。

### 表面：Google Gemini（消费者 / Google 账户）
- **层级：** 消费者
- **默认以输入训练：** 是（依 Google Gemini 应用隐私中心，人工审核员可能查看内容）
- **输入保留：** 默认最长 18 个月；可配置
- **第三方披露（依使用条款）：** 广泛（适用 Google 一般隐私政策）
- **A/C 特权影响：** 相同的 Heppner 失效模式。
- **工作成果影响：** 与 ChatGPT 消费者版分析相同。
- **ABA 512 保密姿态：** 可能违反。
- **基线区间：** 任何包含客户信息的输入均为 **STOP**。

### 表面：免费/公开可用的 AI 工具（一般）
- **层级：** 消费者
- **默认以输入训练：** 假定是
- **输入保留：** 假定无限期
- **第三方披露（依使用条款）：** 假定广泛
- **ABA 512 姿态：** 明确援引 DC 律师协会意见 388（引注包 § 7）：“提供这些[免费]服务的大多数科技公司对其将如何处理提交给它们的任何信息毫不讳言……用户输入归其所有，可按其认为合适的方式使用和共享。”
- **基线区间：** 任何包含客户信息的输入均为 **STOP**。

## 团队/企业表面（默认：CAUTION；配置至关重要）

### 表面：ChatGPT Team / Enterprise
- **层级：** 团队 / 企业
- **默认以输入训练：** 否（依 OpenAI 企业使用条款——核实现行版本）
- **输入保留：** 可定制；默认 30 天；企业级经谈判可获得 ZDR
- **第三方披露（依使用条款）：** 比消费者版狭窄；SOC 2 Type II；受法律程序约束
- **A/C 特权影响：** Heppner 要素 1（非律师）仍然失败。要素 2（保密）更接近——取决于使用条款是“公开可获取”还是依企业合同（含不训练＋保留控制）。要素 3（目的）取决于使用人是否为律师（而非客户）以及律师的使用是否属于代理服务的一部分。即使最佳情形，尚无法院认定任何企业级生成式 AI 使用能完整通过特权分析。
- **工作成果影响：** 若为民事姿态且使用人为当事人/代表，则是 Warner/Morgan 下保护的最强情形。工具的身份仍可开示（Morgan）。
- **ABA 512 保密姿态：** 附条件——如满足以下条件则可能合规：(a) 已审查使用条款并确认不训练和充分的保留控制、(b) 已签订 DPA、(c) 必要时已取得知情客户同意，且 (d) 律所有成文的 AI 使用政策。
- **基线区间：** **CAUTION**——取决于内容叠加。案件相关内容经知情客户同意且使用条款经核实后可允许；对最敏感内容（受特权保护的通讯、反映策略的律师工作成果），除非有明确 ZDR 和已签署的 DPA，否则不允许。

### 表面：Claude Team / Enterprise
- **层级：** 团队 / 企业
- **默认以输入训练：** 依 Anthropic 企业使用条款，否
- **输入保留：** 企业级可获得 ZDR（且为 2026 年 4 月许多企业合同的默认）
- **第三方披露（依使用条款）：** 比消费者版狭窄；受法律程序约束
- **A/C 特权影响：** 与 ChatGPT Enterprise 相同——Heppner 要素 1 仍然失败；要素 2 和 3 更可辩护，但尚无法院裁决。
- **工作成果影响：** 与 ChatGPT Enterprise 相同。
- **ABA 512 保密姿态：** 附条件，条件同上。
- **基线区间：** **CAUTION**——叠加考量相同。

### 表面：Claude Enterprise ＋零数据保留（ZDR）
- **层级：** 企业
- **默认以输入训练：** 否
- **输入保留：** 零（ZDR 合同性保证）
- **第三方披露（依使用条款）：** 商业上可得的最狭窄；ZDR 合同将披露限于法律要求
- **A/C 特权影响：** Heppner 要素 1 仍然失败（Claude 不是律师）。要素 2（保密）是最强可得情形——无保留即无第三方披露路径。要素 3 仍取决于使用人目的。尚无法院对 ZDR 级别的往来作出裁决；Heppner 系依消费者级使用条款裁决。
- **工作成果影响：** 最强可得；民事姿态＋当事人/代表＋ZDR ≈ 存续的最佳情形。
- **ABA 512 保密姿态：** 对案件相关内容可能合规，但须满足 (a) 如输入包含自学习训练数据则取得知情客户同意、(b) 审查实际 ZDR 合同、(c) 律所 AI 政策。
- **基线区间：** 受特权保护的内容 **CAUTION**（法律尚未跟上）；非特权案件相关工作（如研究、起草、摘要）**SAFE**——假定客户同意和律所政策适当。

### 表面：Microsoft Copilot for M365（Business / Enterprise）
- **层级：** 企业
- **默认以输入训练：** 否（租户隔离；依 Microsoft 企业使用条款）
- **输入保留：** 租户内；受租户保留策略约束
- **第三方披露（依使用条款）：** 狭窄；租户隔离
- **A/C 特权影响：** Heppner 要素 1 仍然失败。鉴于租户隔离，要素 2 和 3 更可辩护，但同样——尚无法院裁决。
- **工作成果影响：** 与一般企业生成式 AI 类似。
- **ABA 512 保密姿态：** 附条件——取决于租户配置以及 Copilot 的数据处理是否匹配律所的保密义务。
- **基线区间：** **CAUTION**——与 ChatGPT Enterprise 相同的叠加考量。

### 表面：Google Gemini for Workspace（企业版）
- **层级：** 企业
- **默认以输入训练：** Workspace 企业版否；核实
- **输入保留：** Workspace 内；可配置
- **第三方披露（依使用条款）：** 狭窄
- **A/C 特权影响：** 相同的企业模式。
- **工作成果影响：** 相同的企业模式。
- **ABA 512 保密姿态：** 附条件。
- **基线区间：** **CAUTION**。

### 表面：Anthropic API（直接，无企业合同）
- **层级：** API
- **默认以输入训练：** 否（依 API 使用条款）
- **输入保留：** 30 天用于信任与安全审查；企业协议可获 ZDR
- **第三方披露（依使用条款）：** 受法律程序约束
- **A/C 特权影响：** 相同的企业模式——Heppner 要素 1 失败；要素 2/3 取决于配置和使用。
- **工作成果影响：** 与一般企业生成式 AI 类似。
- **ABA 512 保密姿态：** 附条件。API 是 ABA 意见 512 读者在提到“内部”生成式 AI 时最常想到的表面；佛罗里达律师协会意见 24-1 明确认可内部生成式 AI 可缓解保密风险（引注包 § 6）。
- **基线区间：** 默认 **CAUTION**；签订 ZDR 合同并配备适当的律所控制后可向 SAFE 移动。

## 本地/自托管（默认：内容 SAFE；仅真正受特权输入上调区间）

### 表面：自托管开放权重模型（如 Llama、Mixtral，运行于律所基础设施）
- **层级：** 本地
- **默认以输入训练：** 否（模型由你控制）
- **输入保留：** 仅你的基础设施记录的内容
- **第三方披露（依使用条款）：** 无——不存在第三方
- **A/C 特权影响：** 作为教义问题，Heppner 要素 1 仍然失败（模型仍不是律师），但要素 2 和 3 为最强可能——无第三方披露路径；无任何内容离开律所。
- **工作成果影响：** 最强可能——等同于使用律所文字处理软件（参见 Warner 法院的类比——“AI 是工具，而非人”）。
- **ABA 512 保密姿态：** 可能合规。佛罗里达律师协会意见 24-1 明确赞成内部生成式 AI 有利于保密。
- **基线区间：** 案件相关内容 **SAFE**。受特权保护的通讯仍值得为教义上的 Heppner 要素 1 问题标注 CAUTION，但实际风险极小。

### 表面：律所部署的专有生成式 AI（如律所 VPN 内的企业 AI 平台）
- **层级：** 本地（功能上）
- 与自托管开放权重相同姿态，另有供应商支持和赔偿的额外好处（取决于合同）。
- **基线区间：** 案件相关内容 **SAFE**。

## 特殊：特权哨兵本身（作为 Claude Code skill 运行）

当本工具在律师本地 Claude Code 会话中作为 Claude Code skill 运行时，*被分析提示词*的目标表面是律师计划下一步将其发送到的任何表面——即用户调用 skill 时选择的表面。

skill 本身只是运行在律师既有 Claude Code 环境中的文本。如果律师的 Claude Code 连接到 Claude Enterprise＋ZDR（在 Emily 的 IRG 配置中正是如此），则 skill 自身的分析即在该等条款下进行。这一递归性正是设计所在：本工具在自身本地运行的同时，对其他托管 AI 表面发出警告。

## 如何添加新表面

当律师或律所使用此处未列出的表面时：
1. 获取该表面当前的《使用条款》《隐私政策》以及（如适用）《数据处理协议》。
2. 将该表面映射到上述字段模式。
3. 放入正确的层级章节。
4. 参照最接近的画像确定基线区间。
5. 对任何主张的法律效果，援引 `citations.md` 中的相关条目。

不要凭一般行业知识虚构表面画像。风险图景取决于生效的具体合同条款。
