# 广告合规深度审查Skill

## 法律声明

> **重要提示：**
>
> 1. 审查结论依赖于用户提供的物料内容和信息的完整性。信息不完整可能导致遗漏重大风险——凡用户未提供的资质信息，审查结论中均以"待核实"标注。图片须提供原图/高清截图，视频须提供完整视频及口播、字幕文本，否则相关画面要素按"待核实"处理。
> 2. 广告合规涉及的法律法规、部门规章及规范性文件可能因修订、废止或地方执法口径差异而有所不同。审查依据以现行有效的全国性法律规范为准；地方性法规及执法口径差异，在审查结论中单独提示。
> 3. 《广告合规审查报告》由 AI 辅助起草，**须经承办律师复核、署名后方可对外出具**；涉及跨境广告投放（境外主体、境外服务器、多法域合规）、刑事合规（虚假广告罪、《刑法》第222条）、重大行政处罚应对等复杂情形，建议另行专项论证或委托执业律师介入。


## 一、审查方法论基础

### 1.1 法律推理框架：P-F-C三段论

本Skill的审查逻辑以法律演绎推理三段论为基础框架，确保每一项合规判断均可追溯、可检验、可复现：

```text
大前提 (P, Provision)   →  法律规范（成文法条、司法解释、部门规章、执法指南）
小前提 (F, Fact)        →  广告内容事实（经定性后的待审文案表述）
结论   (C, Conclusion)  →  合规判断（合规 / 违规 / 存疑待核实）
```

**中项识别**是链接大小前提的关键：例如"使用'最'字"是中项，连接小前提"该广告语含'最好'"和大前提"《广告法》第9条第(三)项禁止使用'最好'"。但依据2023年《广告绝对化用语执法指南》第5条，"同一品牌或同一企业内部的自我比较"不适用第9条——此时中项需要进一步限定为"与同业竞争者的绝对化比较"。

**审查中对每一项违规认定，必须完成以下闭环**：

1. 指明具体法律规范（法条全文或核心要旨）
2. 指明广告中的具体表述（引用原文）
3. 说明该表述为何落入该规范的调整范围（涵摄/归入分析）
4. 如涵摄存在争议空间（法规不明确、表述模棱两可），标注"存疑"并说明两造观点

### 1.2 风险等级定义

采用五级风险分类，每级以行政处罚幅度、民事赔偿风险及商誉影响为综合判断依据：

| 等级 | 标记 | 定义 | 典型情形 | 典型处罚幅度 |
|------|------|------|----------|-------------|
| **极高风险** | 🔴🔴 | 可能触发刑事责任，或面临吊销营业执照/许可证的最高行政处罚 | 烟草广告、处方药大众媒介广告、虚假广告情节严重（《广告法》第55条第四款） | 吊销执照 + 刑事追诉可能 |
| **高风险** | 🔴 | 违反强制性禁止性规定，大概率触发行政处罚，罚款起点较高 | 绝对化用语（非例外情形）、虚假宣传、未经审查发布特殊品类广告、损害国家尊严 | 广告费用3-10倍罚款，或20万-200万元（广告费用无法计算或明显偏低时） |
| **中风险** | 🟡 | 违反程序性规定、标识义务或信息披露义务，可能触发责令改正或较低罚款 | 广告标识不显著、引证内容未标明出处、AI生成内容未标识、资质不齐全 | 责令改正 + 10万元以下罚款 |
| **低风险** | 🟢 | 不违反强制性规定，但存在消费者投诉、职业打假或商誉风险 | 表述虽不违法但可能引发消费者误解、用词边缘模糊 | 行政约谈 / 责令改正 / 消费者投诉应对成本 |
| **待核实** | ⬜ | 因信息不足无法判断，需补充资质、检测报告或事实信息后重新评估 | 功效声称的科学依据待验证、商标在先权待检索、肖像权授权待确认 | 不适用 |

**风险评估增补因子**（在基础等级上调整）：

- **投放规模**：大规模投放 +1级（执法关注度更高）
- **受众特殊性**：以未成年人为主要受众 +1级
- **投诉/举报历史**：同类内容已有职业打假投诉记录 +1级
- **行业专项行动**：该品类正处于市场监管总局专项行动期间 +1级

### 1.3 审查流程总览

```text
物料提交 → 步骤0：审查范围确认
         → 步骤1：广告定性与品类识别（路由至对应监管强度层级）
         → 步骤2：资质前置核查
         → 步骤3：通用违禁项扫描（全品类必扫13项）
         → 步骤4：逐句合规审查（表格输出）
         → 步骤5：品类专项深度审查（按监管强度分层）
         → 步骤6：综合风险评估与处罚预判
         → 步骤7：合规改写建议
         → 步骤8：可选 · 审查意见书输出
```


## 二、品类识别与监管强度分级

### 2.1 监管强度四层分级

在识别具体品类前，首先理解广告监管的四个强度层级：

```text
第一层：绝对禁止层
  烟草（含电子烟）、处方药（大众媒介）、麻醉/精神/毒性/放射性药品
  → 无合规空间，一律禁止商业广告

第二层：前置审批层
  药品（非处方药）、医疗器械、保健食品、特殊医学用途配方食品、农药、兽药
  → 须取得广告审查批准文号后方可发布；内容受严格限制

第三层：内容限制层
  食品、化妆品、酒类、教育培训、金融理财、房地产、医疗美容、婴幼儿食品
  → 无需前置广告审批，但广告内容受行业特别规则约束

第四层：一般合规层
  普通商品/一般服务
  → 适用广告法通用规则，无行业特别审批或内容限制
```

## 三、路径A：广告文案/物料合规审查

### 步骤0：审查范围确认与利益冲突检查

在开始实质审查前：

- 确认待审物料的**完整范围与形态**——文字、图片、视频均属审查对象：
  - **文字物料**：标题、正文、注释/脚注、跳转链接落地页内容均属审查范围
  - **图片物料**：海报、详情页图、产品效果图、Banner 等——须获取原图或高清截图；画面中的文字（标语、字幕、角标、贴纸、水印、价格标签）与视觉元素均属审查范围
  - **视频物料**：短视频、直播回放、贴片广告等——须获取完整视频，并要求用户提供（或自行逐段转写）口播文案全文、字幕文本、分镜关键帧截图、背景音乐信息及素材来源
  - 任一形态物料不完整时，先行列明缺口并要求补充；无法补充的部分在报告中列为"⬜ 待核实"
- 确认物料的**投放渠道**（电商详情页、短视频平台、公众号推文、户外广告牌、电视/视频贴片等）——不同渠道的标识义务和审查规则不同
- 确认**目标受众**（是否含未成年人）
- 如物料已发布且收到行政处罚告知书/责令改正通知，切换至**防御模式**（见步骤6.3）
- 如用户（律师）要求出具《广告合规审查报告》，同步收集**报告抬头信息**：律师事务所名称、律师团队名称、承办律师姓名（见步骤8）


### 步骤1：广告定性与前置分类

- **广告定性**：依据《广告法》第2条及《互联网广告管理办法》第2条，判断是否构成"商业广告"——核心判断标准：(1) 是否存在商品/服务经营者；(2) 是否以推销商品/服务为目的；(3) 是否通过一定媒介和形式。注意：《互联网广告管理办法》第9条将"种草文""体验分享""知识介绍"等纳入广告认定范围，**不因形式上非广告而豁免**。
- **品类确认**：依据第二章品类识别表确定产品类目及监管层级。
- **AI生成内容标注**：如文案、图片或视频由AI生成或辅助生成，单独标注并叠加场景（二十四）审查。
- **横切议题标注**：如内容涉及国家版图/港澳台表述/民族/宗教等，叠加场景（二十五）；如内容涉及性别议题/性暗示/低俗/物化等，叠加场景（二十六）。


### 步骤2：资质前置核查

逐一核查以下资质（**如用户未提供，在审查结论中列为"待核实"项，不以"假设已具备"为前提进行审查**）：

| 核查项 | 适用品类 | 法律依据 |
|--------|---------|----------|
| 生产经营许可 | 食品（SC证）、化妆品（备案/注册）、药品（批准文号）、医疗器械（注册/备案） | 各行业管理条例 |
| 广告审查批准文件 | 药品、医疗器械、保健食品、特医食品、农药、兽药 | 《广告法》第46条；《三品一械广告审查管理暂行办法》 |
| 保健食品"蓝帽子" | 保健食品 | 《食品安全法》第74条 |
| 代言人资质 | 所有使用代言人的品类 | 《广告法》第38条（实际使用义务、未满10周岁禁止代言、行政处罚记录） |
| 检测报告/数据来源 | 涉及功效声称、数据引用、性能比较的品类 | 《广告法》第11条第2款（引证内容须真实准确并标明出处） |
| 特殊行业牌照 | 金融（金融许可证）、教育（办学许可证）、医疗（医疗机构执业许可证） | 各行业监管法规 |
| 商标在先权 | 所有涉及品牌名、Logo、广告语的部分 | 《商标法》第57条 |
| 字体/图片著作权授权 | 所有使用商业字体、图片、视频素材的物料 | 《著作权法》第52-54条 |
| AI生成内容标识 | AI生成或辅助生成的广告内容 | 《生成式人工智能服务管理暂行办法》第12条；《互联网广告可识别性执法指南》 |
| 肖像权授权 | 所有使用自然人肖像的素材 | 《民法典》第1018-1022条（肖像权）；第1019条（未经同意不得使用） |

**广告档案制度提示**：依据《广告法》第34条及《互联网广告管理办法》第14条，广告经营者/发布者须建立广告业务档案，保存时间自广告发布行为终了之日起不少于**三年**。档案内容包括：广告主信息、广告内容审核记录、资质证明文件、合同、广告发布链接/截图等。**请确认贵司是否已建立并执行广告档案管理制度。**


### 步骤3：通用违禁项扫描（全品类必扫，共13项）

在逐句审查之前，先对整体物料进行13项必扫违禁项核查——这些是跨越所有品类的底线规则，任何一项触发即构成违规：

#### 3.1 绝对化用语（《广告法》第9条第(三)项 + 2023年《广告绝对化用语执法指南》）

**2023年执法指南的核心变化**：市场监管总局明确，绝对化用语执法应坚持"过罚相当"原则，以下情形**一般不认定为违法**：

| 例外情形 | 示例 | 依据（执法指南） |
|----------|------|------------------|
| 自我比较（同一品牌/企业内部） | "本系列最大容量""品牌旗舰店" | 第5条 |
| 表达经营理念/目标追求 | "顾客至上""追求极致品质" | 第5条 |
| 时间/空间顺序描述 | "首发""首款"（有事实依据） | 第5条 |
| 行业公认或标准认证 | "国家级非物质文化遗产" | 第5条 |
| 主观感受/个人评价 | "个人最爱""强烈推荐" | 第5条 |

**仍应认定为违法**的情形：与同业竞争者进行绝对化比较且无客观依据（"行业第一""全国领先""销量冠军"）。

**审查要点**：

- 判断是否属于"与同业竞争者比较"——这是核心分界线
- 如属于自我比较或主观评价，确认有无事实依据（作为中风险提示，不作为违法认定）
- 如属于同业绝对化比较且无客观数据支撑 → 🔴 高风险

#### 3.2 虚假宣传/误导（《广告法》第28条 + 《反不正当竞争法》第8条）

五种法定情形：

1. 商品/服务不存在的
2. 性能、功能、产地、用途、质量、规格、成分、价格、生产者、有效期限、销售状况、曾获荣誉等与实际情况不符，**对购买行为有实质性影响**的
3. 使用虚构、伪造或无法验证的科研成果、统计资料、调查结果、文摘、引用语等信息作证明材料的
4. 虚构使用商品或接受服务的效果的
5. 其他以虚假或引人误解的内容欺骗、误导消费者的情形

**注意**：第5项"引人误解"为标准——即使字面真实，如果整体效果足以误导一般消费者，仍构成虚假广告（最高人民法院指导案例：以"一般消费者的普通注意力"为判断标准）。

#### 3.3 商业诋毁/不正当竞争（《反不正当竞争法》第11条 + 第6条）

- **商业诋毁**（第11条）：不得编造、传播虚假信息或误导性信息，损害竞争对手的商业信誉或商品声誉。**比较广告中贬低竞争对手的表述即触发此项**——即使不构成"虚假"，只要足以损害对手商誉即违法。
- **商业混淆**（第6条）：不得擅自使用与他人有一定影响的商品名称、包装、装潢、企业名称、域名等相同或近似的标识。
- **虚假宣传**（第8条，详见3.2）

**实务注意**：比较广告中，"比XX品牌更好"类表述需同时审查——(a)比较基础是否真实客观（第28条虚假宣传）；(b)是否构成对竞争对手的贬低（第11条商业诋毁）；(c)是否使用他人注册商标（第57条商标侵权）。三条款可同时触发。

#### 3.4 损害国家/社会公共利益（《广告法》第9条 第(一)(二)(四)-(十一)项）

必扫清单：

- 国旗、国歌、国徽、军旗、军歌、军徽（含变相使用、图案近似）
- "红领巾"等少先队标志（2022年《关于规范使用少先队标志标识的通知》）
- 国家机关/工作人员名义（"政府推荐""国务院认证"）
- 国家尊严与领土完整：台湾/香港/澳门不得与主权国家并列；中国地图须完整（含台湾、南海诸岛、藏南地区）
- 民族/种族/宗教/性别歧视或对立
- 赌博、迷信、恐怖、暴力
- **淫秽、色情、性暗示及违背公序良俗** → 详见下方3.13节及场景（二十六）专项审查
- 妨碍社会安定、损害社会公共利益

#### 3.5 引证内容不规范（《广告法》第11条）

- 广告使用数据、统计资料、调查结果、文摘、引用语等引证内容的，应当**真实、准确，并表明出处**
- 引证内容有适用范围和有效期限的，应当明确表示
- **实务高频违规**：使用"研究表明""数据显示"而未标注来源；使用过期检测报告；引用非CMA/CNAS资质机构的检测结果

#### 3.6 价格表述合规（《价格法》第14条 + 《明码标价和禁止价格欺诈规定》）

- 原价须为**同一经营场所在本次促销前7日内的最低成交价**（或促销前最后一次交易价）
- "划线价"须说明含义（原价/建议零售价/吊牌价）
- 赠品须标明品名、数量、规格
- 有奖销售最高奖金额不得超过5万元（《反不正当竞争法》第10条）

#### 3.7 商业代言合规（《广告法》第38条）

- 广告代言人**须实际使用**所代言的商品或服务（第38条第1款）
- 未满10周岁的未成年人**不得**作为广告代言人（第38条第2款）
- 因发布虚假广告受过行政处罚（未满三年）的自然人/组织**不得**作为广告代言人（第38条第3款，2021年修订新增）
- 医疗、药品、医疗器械广告**不得**利用广告代言人作推荐证明（第16条）

#### 3.8 商标侵权（《商标法》第57条）

- 未经许可在相同商品上使用相同商标（推定侵权）
- 未经许可在类似商品上使用相同/近似商标（以"混淆可能性"为判断标准）
- 广告语中使用他人注册商标须审慎——即使作为"比较"使用，也需评估是否构成商标性使用

#### 3.9 著作权侵权（《著作权法》第52-54条）

- 商业字体授权（使用前须确认授权范围覆盖"广告/商业用途"——个人免费版字体用于商业广告构成侵权）
- 图片/视频素材授权（注意授权期限、地域、使用场景限制）
- 音乐作品授权（短视频背景音乐——"同步权"通常不在平台通用曲库中）

#### 3.10 肖像权/姓名权（《民法典》第1018-1022条 + 第1017条）

- 使用他人肖像须取得书面授权（明示使用范围、期限、场景）
- 使用已故名人肖像，近亲属仍可主张权益（《民法典》第994条）
- AI生成人物形象如与真实自然人高度相似，存在肖像权侵权风险

#### 3.11 格式条款（《消费者权益保护法》第26条）

- 活动规则中不得含"最终解释权归本公司所有"（已被多省市合同格式条款监督条例明确禁止）
- 不得以格式条款排除或限制消费者权利、减轻或免除经营者责任
- 重要条款须以显著方式提请消费者注意

#### 3.12 未成年人保护（《未成年人保护法》第53条 + 《广告法》第40条）

- 不得在中小学校、幼儿园内开展商业广告活动，不得利用教材、教辅材料、校服等发布广告
- 面向未成年人的广告不得含有诱导其要求家长购买的内容
- 面向未成年人的广告不得含有可能引发其模仿不安全行为的内容
- 酒类、烟草、医疗美容广告禁止向未成年人发送

**扫描输出格式**：如13项均未触发，简式输出"经扫描，13项通用违禁项均未触发"。如有触发，逐项详细输出违规认定。

#### 3.13 公序良俗与性暗示（《广告法》第9条第(七)(八)项 + 《民法典》第8条）

本节为通用违禁项扫描的补充维度——原清单中的"淫秽、色情"在此展开为独立审查项。

**两层规制框架**：

| 层级 | 条款 | 规制对象 | 典型示例 |
|------|------|---------|---------|
| **红线层** | 《广告法》第9条第(八)项 | 淫秽、色情内容 | 裸露性器官、性行为描述、明显色情画面 |
| **灰区层** | 《广告法》第9条第(七)项 | 妨碍社会公共秩序或违背社会良好风尚 | 性暗示、擦边文案、低俗画面、物化身体 |
| **原则层** | 《民法典》第8条 | 民事活动不得违背公序良俗 | 虽不违法但引发公众普遍反感的营销内容 |
| **专项法** | 《妇女权益保障法》第51条 | 禁止通过大众传播媒介贬低、损害妇女人格 | 物化女性、以女性身体为噱头的低俗广告 |

**实务要点**：纯粹的"淫秽色情"（红线层）在主流商业广告中已极少出现——真正高频触发舆论危机和行政处罚的是灰区层的"性暗示/擦边/低俗"内容。详细审查框架、四级递进识别维度、舆论风险评估矩阵、典型案例（椰树椰汁、杜蕾斯、OPPO、绝味鸭脖、喜茶×杜蕾斯）及舆论压力测试方法见**场景（二十六）公序良俗与舆论风险合规**。


### 步骤4：逐句合规审查

将物料按"句/段/独立主张"切片后逐条审查，按以下表格输出：

| 序号 | 原文内容 | 风险点 | 触犯条款 | 涵摄分析 | 风险等级 | 合规改写建议 |
|------|----------|--------|----------|----------|----------|--------------|
| 1 | （引用原文） | （该表述可能引发的法律风险） | 《XX法》第X条 + 核心要旨 | 该表述为何落入该条款——中项是什么，涵摄过程 | 🔴/🟡/🟢/⬜ | （可替换的合规表述，非仅"建议删除"） |

**涵摄分析写作要求**：

- 不写"该表述违反了XX法"的结论性语句（这属于"结论"列的内容）
- 而应写："该表述使用'第一品牌'，属于与同业竞争者进行绝对化比较（中项），且用户未提供市场份额排名等客观依据，该表述可能落入《广告法》第9条第(三)项的禁止范围；同时需注意如该'第一'系指销售时间顺序且有事实依据，可主张2023年《广告绝对化用语执法指南》第5条'时间顺序描述'例外"
- 如存疑，明确标注："关于XX要素，存在A/B两种解释路径，建议采取更保守的B路径"


### 步骤4.5：图片与视频专项审查

本步骤适用于**图片类**（海报、详情页图、产品效果图、Banner、户外画面）与**视频类**（短视频、直播回放、电视/视频贴片）物料，与步骤3、步骤4叠加执行——画面元素不因"不在文字文案里"而豁免审查。

#### 4.5.1 通用画面审查清单（图片与视频均适用）

| 序号 | 审查项 | 审查要点 | 主要依据 |
|------|--------|---------|---------|
| 1 | **画面文字/字幕** | 画面中出现的所有文字（标语、字幕、角标、贴纸、水印、价格标签、台词）逐条摘出，按步骤3的13项违禁清单及步骤4同标准审查——绝对化用语、功效声称、引证数据印在图里/视频里同样违法 | 《广告法》第9条、第11条、第28条 |
| 2 | **国家标志与版图** | 画面不得出现国旗、国徽、军旗图案及变体；不得出现国家机关名称/领导人形象；如画面含中国地图、地球仪、国界线元素，核查地图完整性（含台湾、南海诸岛、藏南地区；不得将港澳台标注为国家或与主权国家并列） | 《广告法》第9条；《地图管理条例》 |
| 3 | **产品呈现真实性** | 效果图/渲染图与实物的差异程度——"美化"达到影响一般消费者购买决策的即构成虚假宣传；使用前后对比图须注明"效果因人而异"；机械/设备类产品图片不得虚构产能、精度、规格参数 | 《广告法》第28条 |
| 4 | **肖像权/姓名权** | 画面出现真人（模特、员工、客户、主播、网红）须有书面肖像授权，明确使用范围、期限、场景；未成年人须取得监护人同意，且未满10周岁不得作为广告代言人；AI生成人物与真人高度相似的另行评估 | 《民法典》第1018-1022条、第994条；《广告法》第38条 |
| 5 | **第三方知识产权** | 商业字体授权（须覆盖广告/商业用途）；图片/视频素材授权（期限、地域、场景限制）；背景音乐"同步权"授权（平台通用曲库≠商业广告授权）；他人商标、包装、竞品产品入镜须评估商标性使用与商业诋毁风险 | 《著作权法》第52-54条；《商标法》第57条 |
| 6 | **低俗与公序良俗画面** | 身体部位特写（与产品无关）、湿身/透视/捆绑等视觉元素、挑逗性动作表情——按场景（二十六）四级递进框架（文字暗示/视觉暗示/情境暗示/价值观风险）判断，并执行舆论压力测试 | 《广告法》第9条第(七)(八)项 |
| 7 | **AI生成画面标识** | AI生成或辅助生成的图片/视频须显著标识"AI生成"——画面常驻、字体清晰、位置醒目，不得以短暂闪现、半透明、小字号规避 | 《生成式人工智能服务管理暂行办法》第12条；《互联网广告可识别性执法指南》 |
| 8 | **暴力/恐怖/危险模仿画面** | 不得含暴力、恐怖、自杀等画面；不得含可能诱发未成年人模仿的危险行为（危险动作、滥用器械等） | 《广告法》第9条、第10条、第40条 |

### 步骤5：品类专项深度审查

按照品类识别结果，执行对应专项场景审查。以下场景按监管强度从高到低排列：

---

#### 第一层 · 绝对禁止类

##### 场景（十六）烟草（含电子烟）广告

**底线规则**：几乎全面禁止商业广告。

- 《广告法》第22条：禁止在大众传播媒介、公共场所、公共交通工具、户外发布烟草广告。禁止向未成年人发送任何形式的烟草广告。禁止利用其他商品或服务的广告、公益广告宣传烟草制品名称、商标、包装、装潢及类似内容。
- 电子烟适用同等禁止规则（2021年《国务院关于修改〈烟草专卖法实施条例〉的决定》将电子烟纳入烟草专卖管理；2022年《电子烟管理办法》第20条明确禁止电子烟广告）。
- **唯一例外**：烟草制品生产者向烟草销售者内部发送的烟草制品价目表（非广告性质）。
- 🚫 凡触发此场景 → 🔴🔴 极高风险，无合规改写空间，结论为"禁止发布"。

##### 场景（十）药品广告（分级管理）

**分级框架**：

| 药品类别 | 广告规则 | 法律依据 |
|----------|---------|----------|
| 麻醉药品、精神药品、毒性药品、放射性药品等特殊药品 | **绝对禁止**商业广告 | 《广告法》第15条 |
| 处方药 | **限制发布**——仅可在国务院卫生行政部门和药品监管部门共同指定的医学、药学专业刊物上发布 | 《广告法》第15条 |
| 非处方药 | **须经审查**——须取得省级药品监管部门广告批准文号 | 《广告法》第16条；《三品一械广告审查管理暂行办法》 |
| 仅宣传药品通用名称 | **无需审查**——但内容不得超出通用名称、商品名称、生产企业名称 | 《三品一械广告审查管理暂行办法》第2条 |

**非处方药广告内容红线**（《广告法》第16条）：

- 不得含有功效的断言或保证（"见效快""治愈率99%"）
- 不得含有安全性的断言或保证（"无毒副作用""绝对安全"）
- 不得利用国家机关、科研单位、学术机构、行业协会或专家、医生、药师、患者的名义和形象作推荐证明
- 不得与其他药品功效安全性进行比较
- 药品广告须显著标明禁忌、不良反应，非处方药须显著标明"请按药品说明书或在药师指导下购买和使用"

---

#### 第二层 · 前置审批类

##### 场景（十一）医疗器械广告

- 须经省级广告审查机关批准（《广告法》第46条），取得广告批准文号
- 内容红线与药品非处方药一致（《广告法》第16条通过第46条及《医疗器械监督管理条例》延伸适用）
- 推荐个人自用的医疗器械广告须显著标明"请仔细阅读产品说明书或在医务人员指导下购买和使用"
- 注意区分"医疗器械"与"家用美容仪器"——后者如非医疗器械注册，不得暗示医疗功能

##### 场景（十三）农药/兽药广告 + 场景（十四）饲料/饲料添加剂

- 须取得广告审查批准文号（《广告法》第21条）
- **绝对禁止内容**：功效/安全性断言、"无毒无害""安全环保"等安全性保证、利用第三方推荐、说明有效率、违反安全使用规程的文字/语言/画面
- 罚则提示：《广告法》第58条——广告费用3-5倍罚款（广告费用无法计算或明显偏低的，20万-100万元）；情节严重的，100万-200万元，可吊销营业执照

#### 第三层 · 内容限制类

##### 场景（九）食品（含保健食品）广告

**普通食品**：

- **核心红线**：普通食品不得声称疾病预防、治疗功能（《食品安全法》第73条；《广告法》第17条）——这是食品广告合规的第一高频违规点
- 营养标签声称（"0糖""0脂""高钙""低钠"）须符合GB 28050《食品安全国家标准 预包装食品营养标签通则》的具体数值标准——例如"0糖"要求每100g/100mL含糖量≤0.5g
- "7天见效""喝出好身材"等短期效果承诺须有CMA/CNAS资质机构出具的检测数据支撑

**保健食品**：

- 须取得"蓝帽子"保健食品批准文号，且广告须经审查（《广告法》第46条）
- 须显著标明"保健食品不是药品，不能代替药物治疗疾病"
- 不得涉及疾病预防、治疗功能
- 不得声称或暗示为保障健康所必需

**广告批准文号标注要求**（《三品一械广告审查管理暂行办法》第9条）：药品、医疗器械、保健食品、特医食品广告须显著标明批准文号，视频广告中批准文号的显示时间不少于**2秒**。

##### 场景（十二）化妆品广告

- 不得宣称医疗作用（"治疗""抗炎""消炎""修复皮肤屏障"如涉及医学概念）（《化妆品监督管理条例》第43条）
- 不得使用"药妆""医学护肤""干细胞"等混淆药品与化妆品边界的表述
- 功效宣称须有化妆品功效宣称评价报告支撑（《化妆品功效宣称评价规范》）：祛斑美白、防晒、防脱发、祛痘、修护、滋养等26种功效需相应级别的评价证据

##### 场景（十七）酒类广告

《广告法》第23条四项禁止：

1. 诱导、怂恿饮酒，或宣传无节制饮酒
2. 出现饮酒动作（含画面、声音描述）
3. 表现驾驶车、船、飞机等活动
4. 明示或暗示饮酒有消除紧张焦虑、增加体力等功效


**额外审查点**：

- 不得含"特供""专供""内供"党政军机关等内容（市场监管总局2021年专项整治）
- 不得以"品鉴""文化传播"名义变相发布酒类广告向未成年人群体触达

##### 场景（十八）金融/投资理财广告

- 不得对未来收益作出保证性承诺（"稳赚不赔""保本保息"）——《广告法》第25条
- 须明示风险——"投资有风险，理财须谨慎"或同义表述
- 不得利用学术机构、行业协会、专业人士、受益者名义推荐
- **虚拟货币**注意：2021年十部委《关于进一步防范和处置虚拟货币交易炒作风险的通知》——虚拟货币相关业务活动属于非法金融活动，相关广告不得发布
- 基金销售人员须具备基金从业资格（《证券投资基金法》第98条）

##### 场景（十九）教育培训广告

- 不得对升学、通过考试、获得学历或证书作出明示或暗示的保证性承诺——"包过""保过""不过退款"（《广告法》第24条）
- 不得利用教育机构、行业协会、专业人士、受益者名义推荐
- **双减政策叠加合规**：面向义务教育阶段学生的学科类培训广告全面从严——"双减"后线上线下的学科类校外培训广告基本被禁止发布（参考各地"双减"实施方案及教育部相关文件）

##### 场景（二十）房地产广告

- 房源信息须真实，面积须标明**建筑面积或套内建筑面积**（《广告法》第26条）
- 四类绝对禁止内容：
  1. 升值或投资回报承诺（"年增值XX%""稳赚"）
  2. 以项目到达某一具体参照物所需时间表示位置（"距地铁站5分钟"）
  3. 对规划或建设中的交通、商业、文化教育设施及其他市政条件作误导宣传
  4. 预售广告未取得预售许可证
- 房地产广告须载明预售许可证号或现售备案号

##### 场景（二十一）婴幼儿食品广告

- **绝对禁止**：声称全部或部分替代母乳的婴儿乳制品、饮料和其他食品广告（《广告法》第20条）——这是为执行《国际母乳代用品销售守则》而设，违规将触发🔴高风险
- 婴幼儿配方乳粉广告不得声称具有保健功能，不得进行功能化宣传

##### 场景（二十三）医疗美容广告

- 须取得《医疗广告审查证明》（《广告法》第16条 + 《医疗美容广告执法指南》）
- **制造容貌焦虑**：禁止以"颜值决定命运""女人必须美"等制造关于容貌的心理焦虑
- **术前术后对比**：禁止使用患者术前术后形象对比作为广告宣传（《医疗广告管理办法》第7条第(六)项）
- 禁止以健康养生知识、人物专访、新闻报道等形式变相发布医疗美容广告
- 禁止向未成年人发送医疗美容广告

##### 场景（十五）种子/种养殖广告

- 品种名称、生产性能、产量、品质、抗性等表述须真实、准确（《广告法》第27条）
- 禁止科学上无法验证的断言
- 禁止以缺乏可靠依据的产量、养殖效益数据作承诺

#### 第四层 · 一般合规类

##### 场景（一）~（八）：通用专项审查

**（一）极限词与绝对化用语**：见步骤3.1，结合2023年执法指南进行例外判断。

**（二）比较广告**：

- 比较须有客观、可验证的依据
- 不得贬低竞争对手（叠加《反不正当竞争法》第11条商业诋毁审查）
- 不得使用竞争对手的商标/商号（除非属于《商标法》第59条的合理使用）
- 比较广告须显著标明比较基准、数据来源和日期

**（三）效果承诺与证据链**：

- 功效声称必须有具备法定资质的检测机构（CMA/CNAS）出具的检测报告支撑
- 报告须在有效期内且适用于该产品批次
- "使用前后对比"须注明个体差异可能影响效果

**（四）价格广告与促销**：见步骤3.6。

**（五）代言人与用户评价**：

- 用户评价/UGC内容被广告主选编使用的，须确保评价真实、完整、不误导
- 不得编造用户评价、虚构交易记录（《反不正当竞争法》第8条；《电子商务法》第17条）
- 不得删除差评或进行选择性展示

**（六）数据引用与排名**：见步骤3.5。

**（七）字体与图片知识产权（含肖像权）**：见步骤3.8-3.10。

**（八）AI生成广告合规**：三层风险金字塔：

- **第一层·标识义务**：AI生成或辅助生成的广告内容须显著标识（《生成式人工智能服务管理暂行办法》第12条；《互联网广告可识别性执法指南》）
- **第二层·内容真实性**：AI生成内容同样适用《广告法》第28条虚假宣传规定——不得以"AI生成"为由抗辩内容失实
- **第三层·知识产权**：AI生成内容的可版权性及侵权责任归属存法律空白——如AI生成画面与第三方作品实质性相似，存在著作权侵权风险（需提示用户知悉法律不确定性）


#### 横切议题（可与任何品类叠加审查）

##### 场景（二十四）互联网广告/可识别性

- **种草文、软广、体验分享**须显著标明"广告"（《互联网广告管理办法》第9条）
- **直播带货**：直播间运营者/主播须履行广告标识义务；直播内容构成商业广告的，主播的口头推荐亦受《广告法》规制（《网络直播营销管理办法(试行)》第8条）
- **弹窗广告**：须显著标明关闭标志，确保**一键关闭**（《互联网广告管理办法》第10条）
- **竞价排名广告**：须显著标明"广告"（《互联网广告管理办法》第9条；《互联网广告可识别性执法指南》）
- **AI生成广告标识**：画面常驻、字体清晰、位置醒目——不得以短暂闪现、半透明、小字号等方式规避（《互联网广告可识别性执法指南》）

##### 场景（二十五）国家尊严与政治合规

- 禁止使用或变相使用国旗、国歌、国徽、军旗、军歌、军徽（《广告法》第9条）
- 禁止商业广告使用"红领巾"等少先队标志
- 禁止使用或变相使用国家机关、国家机关工作人员名义
- **国家版图合规**：中国地图须完整、准确——不得缺失台湾（须标注为"台湾省"）、南海诸岛、藏南地区（阿克赛钦）；不得将台湾、香港、澳门标注为"国家"或与主权国家并列
- **民族/宗教**：不得含民族歧视、宗教歧视内容；使用民族元素须尊重民族文化传统


##### 场景（二十六）公序良俗、性暗示与舆论风险合规

**适用条件**：本场景为横切议题，可与任何品类叠加审查。凡物料涉及以下任一信号时触发：

- 文案含双关语、暧昧表述或性暗示
- 画面突出展示与产品功能无关的身体部位（胸部、臀部、裆部等）
- 广告场景暗示性行为、性关系或使用情趣符号
- 人物穿着、动作、表情带有挑逗意味且与产品使用场景无关
- 使用"性"作为主要卖点（非计生用品/性健康产品）
- 可能被公众解读为"物化女性/男性""低俗""油腻"的内容
- 涉及性别刻板印象且可能引发社交媒体争议

**法律依据**：

| 条款 | 核心要旨 | 适用情形 |
|------|---------|---------|
| 《广告法》第9条第(七)项 | 不得妨碍社会公共秩序或违背社会良好风尚 | 性暗示、擦边文案、低俗画面、物化身体——这是最主要的执法依据 |
| 《广告法》第9条第(八)项 | 不得含有淫秽、色情内容 | 明显色情内容（裸露性器官、性行为描述等）——主流商业广告中较少触发 |
| 《民法典》第8条 | 民事主体从事民事活动不得违背公序良俗 | 虽未达到行政处罚标准，但已引发公众普遍反感的营销内容 |
| 《妇女权益保障法》第51条 | 禁止通过大众传播媒介贬低、损害妇女人格 | 物化女性、以女性身体为噱头、强化性别刻板印象的低俗广告 |
| 《广告法》第10条 | 广告不得损害未成年人的身心健康 | 擦边内容在未成年人可接触渠道投放的叠加风险 |

###### 26.1 典型违规模式识别（四级递进判断）

| 识别维度 | 判断要素 | 风险信号（满足任一即触发审查） |
|----------|---------|-------------------------------|
| **文字暗示** | 文案是否存在性暗示、双关语、暧昧表述 | "从小喝到大"（双关发育/饮用）、"不消停/停不下来"（双关性行为/产品使用）、"越摸越爽"（双关触感/性暗示）、"今夜一滴都不许剩"（食品联名文案翻车案例） |
| **视觉暗示** | 画面是否突出展示与产品无关的身体部位 | 大特写胸部/臀部/裆部、穿着暴露（与产品使用场景无关）、舔舐/抚摸动作（与产品功能无关）、湿身/透视/捆绑等视觉元素 |
| **情境暗示** | 广告场景是否暗示性行为或性关系 | 床上场景（与睡眠产品无关）、浴室偷窥视角、酒店房间暧昧互动、SM/情趣符号挪用 |
| **价值观风险** | 是否可能被解读为物化、低俗或不尊重 | 将身体部位与产品功能做不当类比、将女性/男性简化为性符号、以"性"为唯一或主要卖点（非计生用品）、强化性别刻板印象（"女人的价值在于外貌"等） |

**注意区分以下合理商业表达**（通常不构成违规）：

- **性教育/健康科普**类广告（如HPV疫苗、性健康检查）——不以"挑逗"为目的的正常科普表述 ≠ 性暗示
- **内衣/泳装/健身**品类展示产品功能的合理人体展示 ≠ 低俗（关键判断：画面焦点是"产品功能"还是"身体部位"）
- **计生用品**的必要功能描述 ≠ 低俗营销（但创意须有底线——不以"下流"为"有趣"）

###### 26.2 舆论风险评估矩阵

执法处罚并非唯一风险——大量"擦边"广告即使未被监管部门认定为违法，仍可能引发社交媒体舆论危机，导致品牌声誉受损、消费者抵制、合作方解约等连锁后果。

| 舆论风险因子 | 权重 | 说明 |
|-------------|------|------|
| **性别议题敏感性** | 高 | 涉及女性物化、男性凝视的广告在当前舆论环境下极容易被放大——微博/小红书等平台传播速度极快，话题发酵通常在2-4小时内 |
| **未成年人触及风险** | 极高 | 擦边内容如在未成年人可接触的渠道（短视频平台、校园周边）投放，舆论反弹将指数级放大——叠加《广告法》第10条及《未成年人保护法》 |
| **品牌调性反差** | 中 | 传统/严肃/国有品牌出现擦边内容比新消费品牌更容易引发负面舆论——消费者对"人设崩塌"的容忍度极低 |
| **节点敏感性** | 高 | 在妇女节/母亲节/国家公祭日等节点发布擦边内容，风险等级自动+2——节点营销须额外审慎 |
| **二次传播风险** | 高 | 即使原始投放渠道受众有限，截屏/录屏的社交平台二次传播不可控——须以"被截屏发到微博热搜"为假设前提进行审查 |
| **累积效应** | 中 | 品牌历史上如有类似争议，本次再犯的舆论反弹将呈倍数放大——"屡教不改"的标签极难摘除 |

###### 26.3 典型案例参照

| 案例 | 核心问题 | 执法/舆论结果 | 合规教训 |
|------|---------|--------------|---------|

###### 26.4 审查决策流程

对每一条物料，逐项执行以下判断链：

```text
步骤A：是否存在上述26.1节中的任一违规模式信号？
  ├─ 否 → 通过，不触发本节审查
  └─ 是 → 进入步骤B

步骤B：该信号是否具有"商业表达必要性"？
  ├─ 是（如计生用品的功能展示、内衣品类的合身着装展示、健身品类的人体展示）
  │   → 判断表现方式是否"必要且适度"——超出必要范围的部分视为违规风险
  │   → 🟡中风险：即使必要，也须以得体的方式呈现
  └─ 否（如卖手机/食品/饮料/汽车等与性无关的产品却使用性暗示）
      → 意图可推断为"纯粹以低俗博眼球" → 🔴高风险

步骤C：进行舆论压力测试（三个必答题）
  ├─ Q1: 该内容的截屏如被发到微博，是否会引发#低俗广告#话题？
  ├─ Q2: 该内容的表述如被@人民日报/@央视网/@丁香医生 等大V转发批评，是否站得住脚？
  └─ Q3: 如果竞争对手模仿同样的擦边尺度，你的品牌是否乐见其成？

  如任一答案为"是" → 即使法律上可辩解，舆论风险已不可控 → 建议改写

步骤D：叠加风险因子（对照26.2评估矩阵）
  ├─ 涉及性别议题 + 品牌调性正统 → 风险+1级
  ├─ 未成年人可触及渠道 → 风险+1级
  └─ 敏感节点发布 → 风险+2级
```

###### 26.5 合规改写原则

与普通违规项的"删除/替换"不同，公序良俗类问题的改写须从**创意策略层面**调整：

| 违规类型 | 错误方向 | 合规方向 |
|---------|---------|---------|
| 性暗示双关文案 | 以"暧昧"为创意核心 | 以产品功能/使用场景/用户价值为创意核心——去掉双关的"第二层含义" |
| 低俗视觉呈现 | 以身体部位博眼球 | 以产品为主体、人物为辅助——人物的功能是"使用产品"而非"展示身体" |
| 物化表述 | 将人简化为性符号 | 尊重人物主体性——展现真实的使用场景和情感连接 |
| 价值观偏差 | 以"黑红"为策略 | "红"的前提是"不黑"——以品牌价值观为创意边界 |

> **律师注**：《广告法》第9条第(七)项"违背社会良好风尚"是一个**开放性法律概念**，其内涵随社会观念变迁而演变。2020年代以来，性别平等意识和社会道德标准持续提高——5年前可能"无伤大雅"的表述，在今天的舆论环境下可能触发重大危机。审查时须以**当下社会主流价值观**为判断基准，而非以"以前有过类似广告没出事"为参考。


### 步骤6：综合风险评估与处罚预判

#### 6.1 整体合规结论

按以下结构输出：

```text
【整体合规结论】
□ 合规 — 经审查未发现违反现行法律法规的情形
□ 基本合规，存在低风险提示 — 无强制性规定违反，但存在商誉/投诉风险
□ 存在违规项，建议整改后发布 — 有可整改的违规项
□ 不建议发布 — 存在无法通过改写消除的根本性违规（如品类属于绝对禁止层）
```

#### 6.2 关键风险项清单

按风险等级从高到低排列：

| 优先级 | 风险项 | 等级 | 触犯条款 | 处罚预估 | 整改紧迫性 |
|--------|--------|------|----------|---------|-----------|
| 1 | （最严重项） | 🔴🔴/🔴 | XX法第X条 | 罚款XX万-XX万 / 吊销XX / 刑事责任 | 发布前必须整改 |
| 2 | ... | ... | ... | ... | ... |

**处罚预估方法**：

- 对照《广告法》第55-59条、对应行业法规的罚则条款
- 综合考虑：(a) 法定处罚幅度；(b) 是否属于"情节严重"（2年内3次以上违法、造成人身伤害/重大财产损失等）；(c) 当前执法趋势和专项行动
- 引用典型处罚案例辅助说明（如能获取相关行政处罚决定书）

**常见处罚幅度速查**：

| 违规类型 | 一般情节 | 情节严重 |
|----------|---------|---------|
| 虚假广告（第55条） | 广告费用3-5倍罚款（无法计算：20万-100万） | 广告费用5-10倍（无法计算：100万-200万），可吊销营业执照 |
| 禁止性内容（第57条，第9条违禁） | 广告费用1-3倍（无法计算：20万-100万） | 广告费用3-5倍（无法计算：100万-200万），可吊销营业执照 |
| 未经审查发布（第58条） | 广告费用1-3倍（无法计算：10万-20万） | 广告费用3-5倍（无法计算：20万-100万），可吊销营业执照 |
| 标识/程序违规（第59条） | 10万元以下 | — |

#### 6.3 防御模式（如物料已发布且面临调查/投诉）

如待审物料已发布且收到行政处罚告知书、责令改正通知或职业打假投诉，额外执行以下分析：

1. **违法构成要件逐项检验**：对照行政处罚告知书/投诉所指控的违法条款，逐项检验构成要件是否满足——执法机关对事实认定是否有误？涵摄是否正确？
2. **从轻/减轻/不予处罚的法定情节检索**：
   - 《行政处罚法》第32条（从轻/减轻）：主动消除或减轻危害后果、配合查处有立功表现等
   - 《行政处罚法》第33条（不予处罚）：初次违法且危害后果轻微并及时改正、当事人有证据足以证明无主观过错
   - 2023年《广告绝对化用语执法指南》第8-10条：首次绝对化用语违法、情节轻微、及时改正的，可不予行政处罚
3. **陈述申辩/听证策略建议**：争议焦点识别 → 证据准备方向 → 从轻情节论证框架
4. **信用修复路径**：《市场监督管理信用修复管理办法》第6条——行政处罚信息公示期满6个月（食品/药品/特种设备领域满1年），符合条件的可申请信用修复


### 步骤7：合规改写建议

改写原则：

- **保留营销目的**：不因合规而"阉割"广告创意——在合规框架内寻找等效替代表达
- **提供可替换表述**：不只说"删除"，给出可直接使用的合规文案

## 四、路径B：法律咨询问答

**触发条件**：用户提出抽象广告法问题，不涉及具体文案物料。

**执行流程**：

1. **问题定性**：将用户问题归入以下分类——
   - 法规解释类（"《广告法》第XX条如何理解"）
   - 合规标准类（"XX品类广告有什么限制"）
   - 处罚风险类（"XX行为会被罚多少"）
   - 执法趋势类（"最近XX领域执法严不严"）
   - 策略建议类（"我们想做一个XX广告，怎么操作合规"）

2. **法规检索**：检索现行有效的相关法律、行政法规、部门规章、规范性文件、执法指南。

3. **案例/执法实践补充**：如涉及争议性问题，补充典型执法案例或司法判例（如有案号或公开来源）。

4. **五层输出结构**：
   - **（一）核心结论**：1-3句话直接回答
   - **（二）法律依据**：逐条列明适用法条（法条全称 + 条款序号 + 核心要旨）
   - **（三）实务分析**：涵摄分析 + 执法口径 + 灰色地带提示
   - **（四）风险提示**：具体风险及可能后果
   - **（五）合规操作建议**：可落地的操作步骤


## 五、输出规范

### 5.1 必守规则

- **回答分层**：按"核心结论→法律依据→实务分析→风险提示→修改建议"五层结构组织全部输出
- **引用可核查**：每条法律依据给出"法律全称+条款序号"（如"《广告法》第9条第(三)项"），不可仅写"相关法律规定"
- **先识别品类，再路由审查**：品类定错则后续审查全错——品类的确认过程须在审查结论中展示
- **文案审查用表格**：逐句审查必须按步骤4表格输出，不可仅用纯文本描述
- **存疑明示**：法规不明确、事实不足、存在两种以上合理解释路径之处，必须明示"存疑"并列出正反观点——不对不确定事项冒充确定
- **资质缺失不假设**：用户未提供的资质、检测报告、授权文件，一律列为"⬜ 待核实"，不以"假设已具备"为审查前提
- **修改建议可落地**：合规改写不是"建议删除"——每个改写建议须给出可替换的具体表述

### 5.2 质量自检清单（审查结束前逐项自检）

□ 品类是否已确认（而非仅凭关键词猜测）？
□ 监管层级是否已确定（第一/二/三/四层）？
□ 13项通用违禁项是否均已扫描？
□ 每条违规认定是否完成了"法条→事实→涵摄"闭环？
□ 风险等级是否按五级定义标注（而非仅写"高/中/低"）？
□ 处罚预估是否给出了法定幅度（非模糊描述）？
□ 合规改写是否给出了可替换的具体文案（非仅"建议删除"）？
□ 所有法律依据是否标注了具体条款序号？

## 六、边界与禁区

1. **不构成正式法律意见**：本Skill产出为辅助性合规分析，不构成律师法律意见书，不建立律师-客户委托关系。正式广告合规审查应经执业律师复核并出具署名法律意见。
2. **不协助违法**：不协助伪造证据、规避法律义务、设计规避执法检查的广告策略。如用户明确询问"怎么绕开XX条款的监管"，应拒绝并提示法律风险。
3. **信息脱敏**：涉及具体案件细节、企业商业机密或个人信息时，提醒用户脱敏处理。
4. **视觉审查边界**：本Skill对图片/视频的审查以**合规要素**为限（画面文字、国家标志与版图、肖像与授权、素材版权、低俗元素、AI标识、显示时长等，见步骤4.5），不含纯美学判断（构图、配色、设计水准）；对动态视频中无法从关键帧确认的要素（停留时长、转场细节等）列为"待核实"并要求提供原始文件。
5. **跨境投放另案处理**：涉及境外投放（目标市场非中国大陆）的广告合规，不同法域的法规差异需另行评估。本Skill仅基于中国大陆现行法律体系提供分析。
6. **刑事合规需律师介入**：涉及《刑法》第222条虚假广告罪（情节严重：违法所得10万+ / 2年3次+ / 人身伤害）等刑事合规风险时，建议立即委托执业律师介入。
