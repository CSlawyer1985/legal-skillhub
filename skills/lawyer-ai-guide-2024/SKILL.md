# 律师使用AI指南 2024

## Overview

当用户（律师 / 法务 / 法律学习者）提出与"律师如何用 AI"相关的问题时，使用本技能从 `references/guide_full.md`（指南全文提取文本，约 19 万字）中按需检索相关段落，结合原文给出可操作、可回溯的回答。

## 使用方式（How to use）

指南全文较长，**不要一次性全部读入上下文**，而是用检索脚本按需取回相关片段：

### 检索脚本 `scripts/search_guide.py`（仅依赖 Python 标准库）

1. **关键词检索**（返回最相关片段 + 页码 + 上下文）：
   ```bash
   python scripts/search_guide.py "合同审查 提示词"
   ```
2. **列出章节目录**：
   ```bash
   python scripts/search_guide.py --list
   ```
3. **提取整章原文**（按章节序号，如"第二章"，取前 8000 字）：
   ```bash
   python scripts/search_guide.py --chapter "第二章"
   ```

### 推荐工作流

1. 判断用户问题归属的章节 / 主题；不确定时先运行 `--list` 查看目录。
2. 用关键词检索 `search_guide.py` 取得原文片段；需要时再用 `--chapter` 提取整章精读。
3. 基于检索到的权威原文作答，并注明对应页码 / 章节，便于用户回溯原文。
4. 涉及具体工具操作（提示词、工作流）时，优先引用指南中的真实场景示例，而非凭空编造。
