## 一、案件受理费

**计算依据**：《诉讼费用交纳办法》第十三条

| 标的额区间 | 计算公式 |
|-----------|---------|
| ≤1万元 | 50元/件 |
| 1万-10万元 | 标的额×2.5% - 200元 |
| 10万-20万元 | 标的额×2% + 300元 |
| 20万-50万元 | 标的额×1.5% + 1,300元 |
| 50万-100万元 | 标的额×1% + 3,800元 |
| 100万-200万元 | 标的额×0.9% + 4,800元 |
| 200万-500万元 | 标的额×0.8% + 6,800元 |
| 500万-1,000万元 | 标的额×0.7% + 11,800元 |
| 1,000万-2,000万元 | 标的额×0.6% + 21,800元 |
| >2,000万元 | 标的额×0.5% + 41,800元 |

**输出格式**：
```
案件受理费：标的额[X元] → 适用[区间] → 计算公式：[公式] → ¥[金额]
如适用简易程序/调解结案 → 减半收取：¥[一半金额]
非财产案件：[离婚50-300元/劳动争议10元/其他]
```

## 二、保全费

**计算依据**：《诉讼费用交纳办法》第十四条

| 保全财产价值 | 费用 |
|------------|------|
| ≤1,000元 | 30元 |
| 1,000-10万元 | 保全金额×1% + 20元 |
| >10万元 | 保全金额×0.5% + 520元 |
| 上限 | 5,000元 |

**输出格式**：
```
保全费：保全金额[X元] → ¥[金额]
注：申请保全人需提供担保（保险公司保函/现金/房产抵押）
```

## 三、执行费

**计算依据**：《诉讼费用交纳办法》第十四条

| 执行标的额 | 费用 |
|-----------|------|
| ≤1万元 | 50元 |
| 1万-50万元 | 执行金额×1.5% - 100元 |
| 50万-500万元 | 执行金额×1% + 2,400元 |
| 500万-1,000万元 | 执行金额×0.5% + 27,400元 |
| >1,000万元 | 执行金额×0.1% + 67,400元 |

注：执行费由被执行人承担（申请时不预交）。

## 四、利息/违约金计算

**计算模板**：
```
计算基数：[本金金额]元
利率标准：[合同约定XX%/LPR（一年期/五年期以上）XX%+发布日YYYY-MM-DD]
起算日：YYYY-MM-DD（[起算依据]）
暂计至：YYYY-MM-DD（立案日/庭审日）
计算公式：[本金] × [年利率] ÷ 365 × [天数] = ¥[暂计金额]
备注：实际应计算至全部款项付清之日止
```

**LPR适用规则**：
- 2019年8月20日前：中国人民银行贷款基准利率
- 2019年8月20日后：全国银行间同业拆借中心公布的LPR
- 民间借贷利率上限：合同成立时一年期LPR的4倍
- LPR分段计算：利率变动期间分段累计
