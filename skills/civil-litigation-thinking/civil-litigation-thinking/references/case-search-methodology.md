# 类案检索完整方法论 — AI执行手册

> **AI使用说明**：当需要检索类案时（九步法第9步、二审再审程序、用户明确要求），按本手册执行。使用 search 工具（source="web"）进行检索。关键原则：先T0后T4逐级检索，找到即停。

---

## 零、AI执行入口

```
触发类案检索 →
  步骤1：提取本案「案由」+「核心事实关键词」+「法律适用关键词」
  步骤2：按四层关键词法构造检索词
  步骤3：从T0到T4逐级执行 search 工具检索
  步骤4：对搜索结果执行「三相似」筛选
  步骤5：按类案检索报告模板整理输出
```

## 一、类案效力层级与检索顺位

### 1.1 六层效力金字塔

| 顺位 | 层级 | 案例类型 | 发布/审核主体 | 效力 | 裁判文书引用要求 |
|------|------|---------|-------------|------|----------------|
| **T0** | 最高强制 | 最高法指导性案例 | 最高法审判委员会 | **应当参照** | 必须在裁判理由中回应 |
| **T1** | 高度强制 | 人民法院案例库参考案例 | 最高法审核入库 | **应当参考** | 不参考须提交审委会 |
| **T2** | 强参考 | 最高法公报案例/典型案例 | 最高法各审判庭 | 高说服力 | 建议回应 |
| **T3** | 地域参考 | 本省高院参考性案例/生效裁判 | 本省高院 | 体现本地裁判尺度 | 建议引用 |
| **T4** | 直接约束 | 上一级法院/本院生效裁判 | 上级/本院 | 确保裁判尺度一致 | 可直接引用 |

### 1.2 法定检索顺位（《类案检索指导意见》第四条）

```
第一顺位：最高法指导性案例 → 应当参照
    ↓（如未检索到）
第二顺位：最高法典型案例及生效裁判 → 优先参考
    ↓（如未检索到）
第三顺位：本省高院参考性案例及生效裁判 → 地域适配
    ↓（如未检索到）
第四顺位：上一级法院及本院生效裁判 → 兜底确保一致
```

**特别规则**：
- 已在前一顺位检索到类案的，可以不再进行后续检索
- 除指导性案例外，优先检索近三年的案例
- 指导性案例、入库参考案例可不受三年时间限制

## 二、类案"三相似"判断标准

### 2.1 法定定义

《类案检索指导意见》第一条：类案是指与待决案件在**基本事实**、**争议焦点**、**法律适用问题**等方面具有相似性，且已经人民法院**裁判生效**的案件。

### 2.2 三维相似性判断

| 维度 | 判断内容 | 判断标准 | 注意事项 |
|------|---------|---------|---------|
| **基本事实相似** | 核心事实要件一致 | 对裁判结果有实质性影响的事实（《民诉法解释》第335条） | 非案情细节完全一致 |
| **争议焦点相似** | 核心法律/事实争议一致 | 争议焦点是连接基本事实与法律适用的关键节点 | 精确识别争议本质，非表面标签 |
| **法律适用相似** | 适用法律条文或规则一致 | 涉及同一法条的解释和适用 | 新法/旧法衔接需特别关注 |

### 2.3 类案相似性判断"三步法"

- **第一步**：固定待决案件与检索案例的"基本事实、争议焦点、法律适用"三要素，区分相同点与不同点
- **第二步**：将比较点聚焦于关键性事实所蕴含的相关相同点和相关不同点，得出**形式相似性**初步判断
- **第三步**：赋予相同点和不同点何者**压倒性分量**（何者对裁判规则更为关键），得出**实质相似性**最终判断

## 三、类案冲突处理

### 3.1 五项优先准则

| 优先级 | 判断维度 | 规则 |
|--------|---------|------|
| 1 | 效力层级 | 指导性案例 > 入库案例 > 公报案例 > 典型案例 > 普通生效案例 |
| 2 | 法院层级 | 上级法院案例 > 下级法院案例 |
| 3 | 发布时间 | 新案例 > 旧案例（尤其有新法/新司法解释出台背景时） |
| 4 | 决策程序 | 经审委会讨论的案例 > 未经审委会讨论 |
| 5 | 同位阶多案冲突 | 提交专业法官会议→法律适用分歧解决机制 |

### 3.2 排除适用情形

- 所引法律/司法解释已被废止或与新法冲突
- 被新的指导性案例取代
- 案例未生效（被二审/再审改判或发回重审）
- 与本案存在实质性不同（不属于类案）

## 四、检索工具与关键词设计

### 4.1 主要数据库功能对比

| 数据库 | 类型 | 核心功能 | 适用场景 |
|--------|------|---------|---------|
| **人民法院案例库** | 官方免费 | 收录指导性案例+参考案例；支持全文/标题/关键词/基本案情/裁判理由分段检索 | **第一优先检索目标** |
| **中国裁判文书网** | 官方免费 | 高级检索含全文/案由/案号/法院层级/地域/裁判日期/审理程序/法律依据 | 最权威案例来源 |
| **最高人民法院公报网** | 官方免费 | 1985年起全部公报；按栏目和年份检索 | 历史公报案例检索 |
| **法信** | 商业 | 类案检索+争议焦点自动识别+维度检索 | 检索效率高 |
| **北大法宝** | 商业 | 法宝联想（案例→法条→文章双向链接） | 系统性法律研究 |
| **威科先行** | 商业 | 间隔检索（同段/同句）；法条→引用文档反向链接 | 精准定位关键词关联 |

### 4.2 关键词四层设计法

| 层级 | 关键词类型 | 说明 | 示例（以网贷纠纷为例） |
|------|----------|------|----------------------|
| **第一层：案由层** | 规范性关键词 | 确定案件法律分类 | 民间借贷纠纷 |
| **第二层：事实层** | 案情特征关键词 | 个案特征事实词汇 | 服务费、年化利率、实际到账金额 |
| **第三层：法律层** | 规范特征关键词 | 与法律构成要件对应的概念 | LPR四倍、格式条款、砍头息 |
| **第四层：裁判结果层** | 裁判倾向关键词 | 期望的裁判方向和结果 | 合同无效、不支持服务费、改判 |

### 4.3 关键词提取原则

1. **避免口语化**：将日常表述转化为法律术语
2. **控制在三个以内**：单次文本框输入关键词≤3个
3. **同义词转化**："差额补足"→"差额支付"，"售后返租"→"售后回租"
4. **善用逻辑符号**：不包含、布尔逻辑缩小范围
5. **间隔检索**：同段/同句检索将关键词有效衔接

## 五、类案检索报告标准模板

### 5.1 法定要求（《指导意见》第八条）

类案检索报告应当包括：检索主体、检索时间、检索平台、检索方法、检索结果、类案裁判要点以及待决案件争议焦点、对是否参照或参考类案等结果运用情况的分析说明。

### 5.2 标准模板

```
【类案检索报告】

一、检索说明
| 要素 | 内容 |
|------|------|
| 检索主体 | ×××律师事务所 ×××律师 |
| 检索时间 | ××××年××月××日 |
| 检索平台 | 人民法院案例库、中国裁判文书网、法信、北大法宝等 |
| 检索方法 | 关键词检索/法条关联检索/案例关联检索 |
| 检索关键词 | [案由层] + [事实层] + [法律层] + [裁判结果层] |
| 检索结果 | 共检索到相关案例××篇，经筛选有效类案××篇 |

二、检索结果概览（表格式）

| 序号 | 案例名称 | 案号 | 审理法院 | 审理程序 | 裁判日期 | 是否生效 | 裁判要点摘要 | 与本案相似性分析 |
|------|---------|------|---------|---------|---------|---------|-------------|----------------|
| 1 | ... | ... | ... | ... | ... | ... | ... | ... |

三、类案与待决案件对比分析
（1）基本事实对比
（2）争议焦点对比
（3）法律适用对比
（4）相似性结论

四、结论与建议
- 类案确立的裁判规则
- 原审判决与类案裁判规则的冲突（如适用）
- 应当参照/参考类案的具体请求

五、附件：类案裁判文书原文（或二维码/链接）
```

## 六、最高检典型案例运用

### 6.1 民事检察监督案例的检索价值

- **民事生效裁判监督**：最高检第六检察厅发布的抗诉、再审检察建议典型案例
- **虚假诉讼监督**：最高检"五号检察建议"推动专项治理
- **类案监督**：法院对同一性质事实作出相反裁判→检察类案监督的重要情形

### 6.2 在类案检索中的衔接

当事人向检察机关申请民事检察监督时，可提交法院系统类案（尤其是指导性案例、入库案例），证明原审判决与类案裁判规则冲突，能显著提升检察监督的立案率。
