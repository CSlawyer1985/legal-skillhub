> **AI使用说明**：本文件是九步法的详细展开。在SKILL.md模块F中执行九步法时，每一步的具体操作细节参照本文件。注意：本文件为详细参考，执行框架以SKILL.md模块F为准。

## 零、AI执行入口

```
启动九步法分析 →
  步骤1-9：严格按SKILL.md模块F的九步执行清单逐步推进
  每步执行时：
    1. 读取本文件对应步骤的详细规范
    2. 按模板输出该步骤的分析结果
    3. 完成该步骤的自检项
    4. 确认通过后再进入下一步
  全部完成后：汇总九步分析结果 → 进入模块I盲点自检
```

## 第一步：固定权利请求

**任务**：明确原告诉讼请求的全部具体项。

**输出格式**：

| 序号 | 诉讼请求原文 | 问题诊断 | 修正建议 | 计算标准 | 计算依据 |
|------|-------------|----------|----------|----------|----------|
| 1 | [原文] | ⚠️ [问题] | [建议] | [标准] | [依据] |

**重点审查**：
- 请求是否具体明确？金额是否可计算？
- 请求之间是否矛盾？（如同时主张继续履行和解除合同）
- 是否有遗漏的必要请求？
- 是否有不当的请求（超出法院受理范围、缺乏法律依据）？

---

## 第二步：请求权基础检索（严格按序，不得跳序）

必须按以下顺序逐一检索，记录每个请求权的分析结果：

| 优先级 | 请求权类型 | 典型场景 | 法条检索范围 |
|--------|------------|----------|-------------|
| ① | 合同请求权 | 违约、解除、撤销、无效、继续履行 | 《民法典》合同编第一分编+第二分编对应有名合同 |
| ② | 物权请求权 | 返还原物、排除妨害、消除危险、确权 | 《民法典》物权编 |
| ③ | 类合同请求权 | 缔约过失、无权代理、表见代理、效力待定 | 《民法典》第157、171、172、500条 |
| ④ | 侵权请求权 | 人身损害、财产损害、名誉/隐私侵权 | 《民法典》侵权责任编 |
| ⑤ | 不当得利请求权 | 无法律依据获利致他人受损 | 《民法典》第985-988条 |
| ⑥ | 无因管理请求权 | 无义务为他人管理事务 | 《民法典》第979-984条 |
| ⑦ | 其他请求权 | 公司法、劳动法、消费者权益保护法等 | 对应特别法 |

**每个请求权的分析输出**：
```
请求权名称：[类型]
对应法条：[全称+条款项]
构成要件：[要件拆解]
举证难度：[低/中/高] —— [分析]
本地法院支持率：[高/中/低] —— [分析]
综合评价：✅ 优先适用 / ⚠️ 备选 / ❌ 不建议
```

## 第三步：抗辩权基础穷尽检索

### 程序抗辩

| 抗辩类型 | 法律依据 | 成立要件 | 证据要求 |
|----------|----------|----------|----------|
| 管辖异议 | 《民事诉讼法》第130条 | 受理法院无管辖权 | 管辖约定、住所地证明 |
| 主体不适格 | — | 原告/被告与本案无直接利害关系 | 工商登记、合同相对方证明 |
| 重复起诉 | 《民诉法解释》第247条 | 当事人+诉讼标的+诉讼请求均相同 | 前案裁判文书 |
| 超过诉讼时效 | 《民法典》第192条 | 时效期间届满 | 时效起算点证据 |
| 仲裁条款排除 | 《仲裁法》第5条 | 存在有效仲裁协议 | 仲裁协议原件 |

### 实体抗辩

| 抗辩类型 | 法律依据 | 核心要件 |
|----------|----------|----------|
| 合同无效 | 《民法典》第153、154条 | 违反强制性规定或公序良俗/恶意串通 |
| 合同未生效 | 《民法典》第502条 | 未满足法定或约定的生效条件 |
| 已履行 | 《民法典》第557条 | 义务已按约定全面履行 |
| 同时履行抗辩 | 《民法典》第525条 | 双方互负债务+对方未履行或未适当履行 |
| 不安抗辩 | 《民法典》第527条 | 对方经营严重恶化/转移财产/丧失信誉等 |
| 先履行抗辩 | 《民法典》第526条 | 先履行一方未履行或履行不符合约定 |
| 不可抗力 | 《民法典》第180、590条 | 不能预见+不能避免+不能克服 |
| 情势变更 | 《民法典》第533条 | 基础条件发生无法预见的重大变化+继续履行显失公平 |
| 违约金过高 | 《民法典》第585条 | 超过造成损失的30% |
| 免责事由 | 《民法典》侵权责任编 | 受害人故意、第三人原因、自甘风险等 |

## 第四步：要件拆解与事实比对

对确定的请求权基础，拆解每个构成要件，逐一比对证据：

**输出格式（示例——合同违约）**：
```
请求权：《民法典》第577条 违约责任
├── 要件1：存在有效合同
│   证据：证据1《XX合同》，第1-5页
│   评估：✅ 要件满足——合同原件，双方签字盖章完整
│   举证责任：原告
│
├── 要件2：被告存在违约行为
│   证据：证据3《催告函》，第8页；证据4《银行流水》，第9-10页
│   评估：⚠️ 证据不足——催告函未附送达凭证，需补充EMS回单
│   举证责任：原告
│
├── 要件3：原告存在实际损失
│   证据：证据5《损失计算表》，第11页
│   评估：❌ 要件不满足——损失计算仅为单方制作，缺乏第三方佐证
│   举证责任：原告
│   补救建议：补充第三方审计报告或行业标准损失计算依据
│
└── 要件4：违约与损失有因果关系
    证据：无独立证据
    评估：⚠️ 依赖逻辑推定
    补救建议：补充时间线对照分析+行业惯例证据
```

## 第五步：争议焦点提炼

### 事实争议焦点
当事人对事实本身存在分歧——谁说了谎？哪个版本的事实是真的？

示例：借款是否实际交付？合同签字是否真实？货物数量是否相符？

### 法律适用争议焦点
当事人对法律理解与适用存在分歧——法条怎么解释？怎么适用？

示例：违约金是否"过分高于"实际损失？该情形是否构成"情势变更"？

**每个焦点的输出格式**：
```
争议焦点X：[标题]
类型：🔴事实争议 / 🟡法律适用争议
原告/上诉人主张：[主张内容+核心证据]
被告/被上诉人主张：[主张内容+核心证据]
我方论证思路：[法条+证据+逻辑链]
对方反驳预判：[可能的反驳路径]
```

## 第六步：三段论法律论证

每个诉讼请求独立论证：

```
【诉讼请求X的论证】

大前提（法律规范）：
《中华人民共和国民法典》第XXX条第X款：[法条原文]

小前提（本案事实）：
1. [事实1] —— 证据X，第X页
2. [事实2] —— 证据Y，第Y页
3. [事实3] —— 证据Z，第Z页

结论（法律效果）：
被告应[法律效果]。该结论有充分的法律依据和事实支撑，应予采纳。
```

## 第七步：裁判结果预判与风险分层

| 标记 | 含义 | 概率区间 | 特征 |
|------|------|----------|------|
| ✅ 高概率支持 | 要件充分、法条明确、证据扎实、裁判口径有利 | 70%以上 | 胜诉把握较大 |
| ⚠️ 存在争议 | 部分要件有争议、证据存瑕疵、裁判口径不统一 | 40%-70% | 有不确定性，需补强 |
| ❌ 高概率不支持 | 要件缺失、证据不足、裁判规则不利 | 40%以下 | 败诉风险高，需调整策略 |

**每项预判必须标注**：「仅为律师专业判断，最终以法院裁判为准」

**风险分层输出**：
```
🔴 高风险（可能导致败诉）：[风险描述——影响——应对]
🟡 中等风险（可能影响裁判结果）：[风险描述——影响——应对]
🟢 低风险（可控）：[风险描述]
```

## 第九步：要件归入与裁判结论

将认定的事实与法律规范构成要件逐一比对：
- 全部要件满足 → 权利成立，应予支持
- 部分要件不满足 → 权利不成立，应予驳回
- 要件事实真伪不明 → 适用证明责任分配规则（败诉风险由承担举证责任方负担）

---

## 衍生规则：裁判文书"八个一致"检查

1. 诉辩称与卷宗一致
2. 主张与规范一致
3. 证据与主张一致
4. 争点与主张一致
5. 事实与争点一致
6. 法律理由与法律争点一致
7. 判项与请求一致
8. 引法与判项一致

---

## 简易案件简化规则

对于小额诉讼程序（标的额≤当地年平均工资50%）或事实清楚、争议不大的简易程序案件，可执行"九步法精简版"——保留步骤1（固定权利请求）、步骤2（请求权检索）、步骤4（要件拆解与事实比对）、步骤7（裁判预判），其余步骤根据案件复杂程度灵活裁量。但不得跳过管辖权、时效、主体适格三项强制核查。
