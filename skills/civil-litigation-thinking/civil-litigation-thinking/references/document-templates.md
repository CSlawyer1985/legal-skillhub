# 诉讼文书框架模板 — AI生成指引

> **AI使用说明**：当需要生成诉讼文书框架时（模块B Step B.5等），按以下模板生成核心结构。注意：你生成的是**框架和核心论证**，不是可签字的最终文书——律师须在此基础上完善。

---

## 一、起诉状框架

```markdown
# 民事起诉状

**原告**：[姓名/名称]，[性别]，[出生日期]，[身份证号/统一社会信用代码]，住址：[地址]，联系电话：[电话]

**被告**：[同上格式]

**诉讼请求**：
1. [具体请求，金钱给付须明确金额+计算方式+起止时间]
2. [备位请求（如有）]
3. 本案诉讼费用由被告承担

**事实与理由**：
一、[核心事实1] —— 证据：[证据编号]
二、[核心事实2] —— 证据：[证据编号]
三、[核心事实3] —— 证据：[证据编号]

综上所述，[结论性陈述+法律依据：《民法典》第X条]。

此致
[XX人民法院]

具状人：[签名/盖章]
[YYYY年MM月DD日]
```

## 二、答辩状框架

```markdown
# 民事答辩状

**答辩人**：[基本信息]

**被答辩人**：[基本信息]

**答辩意见**：
针对被答辩人的诉讼请求，答辩如下：

一、关于[原告诉讼请求1]
[答辩理由+证据+法律依据]
二、关于[原告诉讼请求2]
[答辩理由+证据+法律依据]

**抗辩主张**：
1. [程序抗辩：时效/管辖/主体/仲裁条款]
2. [实体抗辩：已履行/抵销/免责/违约金过高]

综上所述，请求驳回原告全部/部分诉讼请求。

此致
[XX人民法院]

答辩人：[签名/盖章]
[YYYY年MM月DD日]
```

## 三、上诉状框架

```markdown
# 民事上诉状

**上诉人**：[基本信息]
**被上诉人**：[基本信息]

**上诉请求**：
1. 撤销[原审法院][案号]民事判决第X项
2. 改判[具体请求]
3. 一、二审诉讼费用由被上诉人承担

**上诉理由**：
一、原审认定事实错误
[具体指出原审认定的错误事实]→[正确事实]→[证据支撑]
二、原审适用法律错误
[原审引用的法条]→[应适用的正确法条]→[理由]
三、原审程序违法（如有）
[具体违法情形]→[对应《民事诉讼法》第211条再审事由]

此致
[上级人民法院]

上诉人：[签名/盖章]
[YYYY年MM月DD日]
```

## 四、代理词框架

```markdown
# 代理词

**案由**：[XX纠纷]
**案号**：[案号]
**代理人**：[律师事务所+律师名]
**代理方**：[原告/被告/上诉人/被上诉人]

**一、案件基本事实**
[核心事实时间线——每条关联证据编号]

**二、争议焦点分析**
焦点1：[标题]
我方观点：[核心论证+法条+证据]
对方观点及反驳：[对方主张+反驳理由]

焦点2：[同上]

**三、法律适用论证**
[三段论格式：大前提→小前提→结论]

**四、类案裁判规则**
[相关类案+裁判要旨]

**五、结论**
[总结+请求法庭支持的裁判结果]

代理人：[签名]
[YYYY年MM月DD日]
```

**事实与理由**：

**被执行人财产线索**：
1. [财产类型+具体信息+来源]
2. ...

此致
[XX人民法院]

申请执行人：[签名/盖章]
[YYYY年MM月DD日]

附件：生效法律文书副本
