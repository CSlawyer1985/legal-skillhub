## 一、证据审查双轨模型总览

```
证据审查
├── 轨道1：证据能力审查（可采性/证据资格）
│   ├── 来源审查（三重溯源）
│   ├── 三性审查（真实性+合法性+关联性）
│   └── 非法证据排除规则
│
└── 轨道2：证明力审查（证明价值/证明力度）
    ├── 五级梯度评估
    ├── 加减因素分析
    ├── 印证规则
    └── 孤证补强规则
```

## 二、证据来源审查——三重溯源体系

### 2.1 第一重：原始来源（证据从何而来）

| 来源类型 | 可靠性评估 | 审查要点 |
|---------|-----------|---------|
| 公文书证（政府机关出具） | ✅✅✅ 高 | 核验出具机关+文号+印章 |
| 第三方中立机构记录 | ✅✅ 较高 | 核验机构的独立性+记录时间 |
| 商业交易惯例文件 | ✅ 中等 | 核对交易惯例+行业标准 |
| 当事人单方制作 | ⚠️ 需补强 | 形成时间+有无对方确认 |
| 利害关系人陈述 | ⚠️⚠️ 需补强 | 利害关系程度+与其他证据印证 |
| 来源不明/匿名 | ❌ 不可采 | 直接排除 |

### 2.2 第二重：持有来源（谁掌握证据）

- **当事人自己持有** → 警惕选择性提交（有利提交+不利隐瞒）
- **对方当事人持有** → 可申请法院责令提交（《民诉法解释》第112条+证据偏在规则）
- **第三方持有** → 申请调查令/法院调查取证
- **公证处持有** → 公证书具有较高证明力

### 2.3 第三重：取证来源（如何获取证据）

- **公证取证** ✅✅✅ 最佳 → 可有效避免对方质疑取证过程
- **法院调查取证** ✅✅ 高 → 法院调取的证据证明力较高
- **可信时间戳/区块链存证** ✅✅ 高 → 《在线诉讼电子证据规则》明确认可
- **律师调查令调取** ✅ 中等 → 需审查调查令的合法范围
- **当事人自行取证** ⚠️ → 须注意取证方式合法性边界
- **私下录音录像** ⚠️⚠️ → 公共场所一般合法；私人场所违法

## 三、三性审查深化操作

### 3.1 真实性审查（形式真实+实质真实）

| 审查维度 | 核查问题 | 判定标准 | 常见陷阱 |
|----------|---------|---------|---------|
| **原件比对** | 是否为原件/与原件核对无误的复印件？ | 原件✅ / 无法核对⚠️ / 复印件无原件印证❌ | 对方当庭不认可复印件真实性 |
| **篡改痕迹** | 是否有涂改、添加、删减？ | 无✅ / 可疑⚠️ / 明显篡改❌ | 电子文档元数据揭示修改时间异常 |
| **形成时间** | 落款时间与事件发生时间是否吻合？ | 吻合✅ / 存疑⚠️ / 矛盾🔴 | 倒签合同+倒签日期鉴定 |
| **证据印证** | 是否有其他独立来源证据佐证？ | 有印证✅ / 孤立证据⚠️ | 两份证据"印证"但来源同一人 |
| **形式瑕疵** | 签字/盖章是否完整？ | 完整✅ / 瑕疵⚠️ | 仅有公章无法定代表人签字 |
| **逻辑合理性** | 内容是否符合常理和商业逻辑？ | 合理✅ / 存疑⚠️ | 远低于市场价的交易价格 |

### 3.2 合法性审查（来源合法+形式合法）

| 审查维度 | 核查问题 | 法律依据 | 判定指引 |
|----------|---------|---------|---------|
| **取证方式** | 偷拍偷录是否合法？ | 《民诉法解释》第106条 | 私人场所× / 公共场所一般√ |
| **形式要求** | 是否符合八类法定证据形式？ | 《民事诉讼法》第66条 | 书证/物证/视听资料/电子数据/证人证言/鉴定意见/勘验笔录/当事人陈述 |
| **非法证据排除** | 是否严重侵害他人合法权益？ | 《民诉法解释》第106条 | 侵犯隐私/违反禁止性规定/严重违背公序良俗→排除 |
| **举证期限** | 是否在举证期限内提交？ | 《民事诉讼法》第68条 | 逾期提交→说明理由+可能不被采纳 |
| **证据链完整** | 电子证据原始载体是否可展示？ | 《电子签名法》第5-8条 | 无法展示原始载体→证明力减弱 |

### 3.3 关联性审查（三层次递进）

| 层次 | 审查内容 | 判断标准 |
|------|---------|---------|
| **第一层：有无关联** | 证据能否指向本案的任一要件事实？ | 完全无关→直接排除 |
| **第二层：关联强弱** | 是直接证据还是间接证据？ | 直接证据（单独证明要件）/间接证据（需结合）/背景证据（仅提供上下文） |
| **第三层：证明目的契合度** | 证据能否有效支撑拟证明的目的？ | 完全契合/部分契合/"证非所欲"错位 |

## 四、证明力评估体系

### 4.1 五级梯度

| 等级 | 证明力 | 特征 | 典型证据 | 法律后果 |
|------|--------|------|---------|---------|
| ★★★★★ | 极高 | 公文书证原件+多源印证+对方自认 | 法院生效裁判认定的事实；公证文书；对方当庭自认 | 可直接定案 |
| ★★★★ | 高 | 原始书证+有其他证据印证 | 银行流水原件+合同原件 | 结合印证可定案 |
| ★★★ | 中等 | 复印件/电子数据+部分印证 | 微信聊天记录截图+转账记录印证 | 需补强或综合判断 |
| ★★ | 较低 | 单方制作+无其他印证+利害关系人陈述 | 单方记账本；近亲属证言 | 不能单独定案 |
| ★ | 极低 | 孤证+来源不明+形式瑕疵 | 无落款无签章打印件；匿名举报 | 不可作为定案依据 |

### 4.2 证明力加减因素

**增强因素（+）**：
- +1 证据经公证/第三方权威机构认证
- +1 多份独立来源证据一致指向同一事实
- +1 对方对该证据真实性予以认可（免除举证方证明责任）
- +1 证据形成于纠纷发生前/正常业务过程中（非"溯及性证据"）
- +1 电子证据有区块链存证/可信时间戳/哈希值校验
- +1 证据形成时有中立的第三方在场见证
- +1 证据符合行业惯例或商业习惯

**减弱因素（-）**：
- -1 证据由与案件有利害关系的人单方持有
- -1 证据存在无法解释的瑕疵或矛盾
- -1 证据形成于纠纷发生后（溯及性证据，警惕事后补证）
- -1 电子证据无原始载体/无完整性校验/无法验证未篡改
- -1 证人证言来自与当事人有利害关系的人（近亲属/员工/债务人）
- -1 证据与常识/经验法则/自然规律相悖
- -1 当事人无正当理由拒不提供其持有的对己不利的证据（《民事证据规定》第95条→不利推定）

### 4.3 证明力综合评估公式

```
综合证明力 = 基础证明力等级 × （1 + Σ增强因素） × （1 - Σ减弱因素）
            × 印证系数（孤证×0.5 / 二源印证×1.2 / 三源以上印证×1.5）
            × 来源可靠性系数（公文书证×1.2 / 利害关系人×0.8 / 来源不明×0）
```

注意：此为分析指引，非精确数学公式，最终以法官自由心证为准。

## 五、电子证据专项审查

### 5.1 四步审查法

| 步骤 | 审查内容 | 方法 | 常见问题 |
|------|---------|------|---------|
| **第一步** | 原始载体审查 | 当庭展示原始手机/电脑/服务器 | 原始载体丢失→证明力大幅降低 |
| **第二步** | 主体关联性 | 实名认证状态+账号归属+IP地址 | 账号非实名/借名注册→归属争议 |
| **第三步** | 内容完整性 | 有无删减/篡改/选择性截取 | 不完整的聊天记录→对方可质疑断章取义 |
| **第四步** | 时间连续性 | 时间戳是否连续+与其他证据时间线一致 | 时间线断裂→质疑证据真实性 |

### 5.2 常见电子证据类型审查重点

| 证据类型 | 审查重点 | 加固方法 |
|---------|---------|---------|
| **微信聊天记录** | 双方身份确认+完整对话上下文+原始手机展示 | 公证+腾讯调取实名信息 |
| **电子邮件** | 发件人/收件人身份+邮件服务器记录+邮件头信息 | 邮件服务商协查+公证 |
| **银行/支付宝/微信转账** | 双方账户+转账时间+金额+备注 | 银行盖章流水/官方电子回单 |
| **网页/社交媒体内容** | 网址+发布时间+发布者+取证时间 | 公证+可信时间戳+区块链存证 |
| **电子合同/电子签章** | 电子签名有效性+签署时间+签署主体 | CA认证+签署日志 |

## 六、证据矛盾处理三级响应

| 矛盾级别 | 标记 | 含义 | 处理方法 |
|---------|------|------|---------|
| 根本性矛盾 | 🔴 | 动摇核心要件事实——如合同金额与实际转账差异巨大 | ①分析矛盾可否合理解释；②如无法解释→重新评估胜诉可能性；③如是我方证据→策略调整或撤诉考量 |
| 重大矛盾 | 🟠 | 影响关键情节认定——如关键时间节点存在数日偏差 | ①审查是否有其他证据可弥合矛盾；②预判对方可能攻击方式；③准备替代性论证方案 |
| 一般矛盾 | 🟡 | 边缘性矛盾不触及核心——如非关键证人对次要细节的记忆偏差 | 标注记录以备应对对方攻击；庭前统一口径 |

## 七、证据缺口补证方案模板

```
🟡 证据缺口：[缺失的证据类型]
对应要件：[该证据证明的要件事实]
调取方式：[当事人提供 / 申请法院调取 / 律师调查令 / 第三方函询]
调取主体：[谁有权调取？]
调取期限：[在什么时间前必须完成？]
替代方案：[如无法调取的备选方案]
未补证后果：[该要件无法证明→对裁判结果的影响评估]
```
