## SUP-001：工资支付周期与各地区规定

**适用模块**：薪酬

**内容**：

### 全国统一规定
- **最少每月支付一次**【依据】《工资支付暂行规定》（劳部发[1994]489号）第七条
- 工资必须在约定日期支付；如遇节假日或休息日，提前最近工作日支付

### 各地区差异

**北京市**【依据】《北京市工资支付规定（2007修订）》第九条：
- 可按小时/日/周/月为周期支付，最少每月支付一次
- 以完成一定工作任务计发的，任务完成后即时支付

**上海市**【依据】《上海市企业工资支付办法（2016修订）》第六条：
- 企业与劳动者约定支付日期，最少每月支付一次
- 年薪制或按考核周期兑现的，每月按不低于最低工资标准预付

**广东省**【依据】《广东省工资支付条例》（2016）第十条、第三十九条：
- 月/周/日/小时工资制均可
- 停工停产未超过一个工资支付周期（最长30日），按正常工作时间支付

**四川省/重庆市**：
- "一个工资支付周期"指按规定支付工资的时间间隔
- 月薪制＝一个月，周薪制＝一周

**江西省**【依据】《江西省工资支付规定》第十三条、第十四条：
- 月薪制：按月支付
- 年薪制：每月预付部分工资，年终结算
- 计件制：超过一个月应每月预付部分工资；结算周期超过一年，每半年至少结算一次

**注意**：工资支付周期"最长30日"是指停工停产情形下的工资支付，不是任意情况下均可压30天。

## SUP-002：假期规则详细补充

**适用模块**：假期

**内容**：

### 休息日
- 双休日（周六/周日）共104天，不计薪
- 加班不能补休的，支付日工资200%【依据】《劳动法》第四十四条

### 法定节假日（共11天）
| 节日 | 天数 | 日期 |
|------|------|------|
| 元旦 | 1天 | 1月1日 |
| 春节 | 3天 | 农历正月初一/初二/初三 |
| 清明节 | 1天 | 农历清明当日 |
| 劳动节 | 1天 | 5月1日 |
| 端午节 | 1天 | 农历端午当日 |
| 中秋节 | 1天 | 农历中秋当日 |
| 国庆节 | 3天 | 10月1-3日 |

加班：支付日工资300%【依据】《劳动法》第四十四条

### 部分公民放假节日
| 节日 | 对象 | 天数 |
|------|------|------|
| 妇女节 | 女职工 | 半天 |
| 青年节 | 14-28周岁青年 | 半天 |
| 儿童节 | 不满14周岁少年儿童 | 1天 |
| 八一建军节 | 现役军人 | 半天 |

- 适逢周末不补假
- 不工作的不扣薪，工作的不付加班费；适逢周末加班则付休息日加班费【依据】《国务院全国年节及纪念日放假办法》

### 年假（带薪年休假）
**天数**【依据】《职工带薪年休假条例》第三条：
- 累计工作满1年不满10年 → 5天
- 累计工作满10年不满20年 → 10天
- 累计工作满20年 → 15天

**不享受当年年假的情形**【依据】《职工带薪年休假条例》第四条：
1. 寒暑假天数多于年休假天数
2. 事假累计20天以上且单位不扣工资
3. 病假：1-10年工龄累计2个月以上 / 10-20年累计3个月以上 / 20年以上累计4个月以上

**未休补偿**：按日工资收入300%支付【依据】《职工带薪年休假条例》第五条

### 事假
- 天数由公司规章制度规定
- 原则上无薪；累计满20天不扣工资则当年不享受年假

### 病假/医疗期
**工资标准**【依据】《劳动法意见》第五十九条：
- 病假工资 ≥ 当地最低工资×80%

**医疗期期限**【依据】《企业职工患病或非因工负伤医疗期规定》：
| 本单位工龄 | 实际工龄<10年 | 实际工龄≥10年 |
|-----------|-------------|--------------|
| <5年 | 3个月 | 6个月 |
| ≥5年 | 6个月 | 按以下标准 |

- 10-15年 → 12个月；15-20年 → 18个月；20年以上 → 24个月
- 特殊疾病（癌症/精神病/瘫痪等）经批准可延长

**特殊病假认定**：
- 狂犬疫苗：算病假 ✅
- 变性手术：算病假 ✅
- 整容手术（治疗性）：算病假 ✅；美容性：不算，属私人原因

### 工伤假（停工留薪期）
**【依据】《工伤保险条例》第三十三条**：
- 停工留薪期内原工资福利待遇不变，由单位按月支付
- 一般不超过12个月；伤情严重经鉴定可延长，不超过12个月
- 停工留薪期满仍需治疗的，继续享受工伤医疗待遇

### 探亲假
**【依据】《国务院关于职工探亲待遇的规定》**：
| 情形 | 假期 |
|------|------|
| 探望配偶 | 每年30天 |
| 未婚探望父母（每年） | 20天 |
| 未婚探望父母（两年一次） | 45天 |
| 已婚探望父母（每四年） | 20天 |

- 条件：工作满一年 + 与配偶/父母不住在一起 + 不能在公休假日团聚
- **适用范围严格**：仅限国家机关/人民团体/全民所有制企业/事业单位
- 私营企业一般无法定探亲假

### 路途假
**【依据】《国家劳动总局、财政部关于国营企业职工请婚丧假和路程假问题的通知》**：
- 在批准的婚丧假和路程假期间工资照发
- 途中车船费等全部由职工自理
- 探亲假往返路费：探望配偶/未婚探望父母由单位负担；已婚探望父母超出本人月标准工资30%部分由单位负担

### 社会活动假期
**【依据】《工会法》第四十条第二款**：
- 基层工会非专职委员每月不超过3个工作日参加工会活动，工资照发

### 甲类传染病假（涉疫情）
**【依据】人社部等七部门《关于妥善处置涉疫情劳动关系有关问题的意见》**：
- 政府依法采取停工停业、封锁疫区等紧急措施导致不能返岗：
  - 一个工资支付周期内：按正常工作时间支付
  - 超过一个周期：发放生活费（按地方规定）

### 生育相关假期

**孕检假**【依据】《女职工劳动保护特别规定》第六条：
- 怀孕女职工劳动时间内产前检查，所需时间计入劳动时间
- 怀孕7个月以上：一般不安排夜班；给予工间休息1小时

**保胎假**【依据】原国家劳动总局保险福利司复函：
- 须医师开具证明，按病假工资标准发放

**产假**【依据】《女职工劳动保护特别规定》第七条：
- 基础：98天（产前可休15天）
- 难产：+15天
- 多胞胎：每多生1个婴儿+15天
- 怀孕未满4个月流产：15天
- 怀孕满4个月流产：42天
- 各地奖励假：另行补充

**流产假**（见上）
**节育假**：自愿落实节育措施享受【依据】《人口与计划生育法》第十九条

**哺乳假**【依据】《女职工劳动保护特别规定》第九条：
- 每天1小时哺乳时间
- 多胞胎：每多哺乳1个婴儿每天+1小时

**陪产假**：见基础知识库，各省规定不同
**育儿假**：见基础知识库，各省规定不同

### 婚丧假
**【依据】《国家劳动总局、财政部关于国营企业职工请婚丧假和路程假问题的通知》**：
- 职工本人结婚或直系亲属（父母/配偶/子女）死亡：酌情1-3天
- 婚丧假期间工资照发
- 路途假另议

### 独生子女护理假
- 多省出台：父母患病住院期间，独生子女每年累计5-20天护理假

### 痛经假
**【依据】《女职工保健工作规定》**：
- 重度痛经及月经过多，经医疗机构确诊：月经期间可休1-2天
- 已有10余个省份明确此权益（北京/河南/陕西/浙江/江苏/辽宁等）

## SUP-003：入职办理流程与系统配置

**适用模块**：入职

**内容**：

### 入职办理流程（7步）
1. **发送Offer** → 候选人确认入职意向
2. **背景调查**（如适用）

## SUP-004：辞退工作 SOP（面谈三步法）

**适用模块**：离职

**内容**：

### 第一步：准备工作做到位
- **分析被辞退者的性格特点**，找到彼此之间最恰当的沟通方式
- **收集其过去的业绩表现**，佐证辞退有理有据
- **梳理面谈流程**，弄清公司的赔偿底线以及预设对方可能问的问题
- 目的：更好地掌控面谈局面

### 第二步：谈判态度不卑不亢
- **共情优先**：充分考虑对方的心理和情绪，不要盛气凌人；表现出情感共鸣，给对方找台阶下，让其主动说出"辞职"最好
- **共情与威严结合**：能让被辞退者知深浅、懂道理
- **坚守原则**：涉及原则事项（如赔偿金额），表达斩钉截铁——"晓之以理是公司底线与制度，赔偿额是HR尽最大努力争取的，没有可商量的空间"

### 第三步：体现"利他行为"
- 在适度共情的同时，**真诚为其提供职业发展建议与指导**
- 或利用自身人脉资源提供招聘信息或推荐工作
- 心理学"利他行为"定义：在不期待回报的情况下愿意帮助他人
- **"利他"即是"利己"**：利他行为具有互惠性，有助于维护企业口碑

### 关键注意事项
- 全程录音备份（提前告知对方）
- 赔偿方案准备好AB选项
- 避免单独在密闭空间长时间面谈
- 准备好离职证明/工作证明等材料，当场或约定时间交付

## SUP-008：员工严重违纪证据采集

**适用模块**：劳动关系 / 员工关系

**内容**：

员工严重违纪时，用人单位需依法收集有效证据。以下六类证据按证明力排序：

### 1. 员工自书材料（证明力最强）
- **类型**：检讨书、悔过书、员工签字确认的情况说明书
- **要求**：
  - 完整陈述：时间/地点/涉及人员、原因/经过、造成的损害后果
  - 必须有员工**本人亲笔签名+日期**
  - 最好由主管领导谈话后当场书写
- **技巧**：谈话时先指出行为严重性，再提出书写要求

### 2. 员工签字确认的过失单/违纪记录
- **内容**：违纪事实经过、损害结果、对应的规章制度条款
- **操作要点**：
  - 最好由员工本人填写
  - 如员工无法自行书写，工作人员代填后，**诵读告知**，员工签署"已了解各项内容，本人予以认可"
  - 有困难签字可按手印代替

### 3. 其他员工的证言
- **证明力**：低于书证，一般不能单独使用
- **要求**：需与其他证据形成**完整证据链**
- **优先级**：非用人单位员工的证人证言证明力 > 内部员工证言

### 4. 物证
- **类型**：损坏的机器设备、其他物品等
- **保存**：拍照留档，原物妥善保管

### 5. 政府有关部门的处理记录
- 员工违纪导致公司受行政处罚：《行政处罚决定书》
- 导致公司赔偿第三人：保留相关书面证据
- 违法行为（赌博/盗窃等）：要求政府处理，处理结论作为有力证据
- **"大错不犯，小错不断"**：平时做好跟踪记录，积累证据

### 6. 视听资料及其他书证
- **类型**：监控录像/录音、照片、微信/短信记录
- **注意**：电子证据容易被修改，需**与其他证据形成证据链**后方有较强证明力

## SUP-009：劳动合同解除与终止（13+14+7条）

**适用模块**：劳动合同 / 离职

**内容**：

### 劳动者解除劳动合同（13种情形）

**通知即可解除（无需理由）**：
1. 协商一致解除
2. 提前30日书面通知解除（试用期内提前3日）
3. 法律/行政法规规定的其他情形

**因用人单位过错，劳动者可立即解除**：
4. 未提供劳动保护或劳动条件
5. 未及时足额支付劳动报酬
6. 未缴纳社会保险
7. 规章制度违法损害劳动者权益
8. 以欺诈/胁迫/乘人之危订立/变更合同
9. 免除法定责任/排除劳动者权利
10. 合同违反法律/行政法规强制性规定

**立即解除（无需告知）**：
11. 以暴力/威胁/非法限制人身自由强迫劳动
12. 违章指挥/强令冒险作业危及人身安全

### 用人单位解除劳动合同（14种情形）

**过失性解除（无需通知/补偿）**：
1. 协商一致
2. 试用期不符合录用条件
3. 严重违反规章制度
4. 严重失职/营私舞弊，给用人单位造成重大损害
5. 同时与其他单位建立劳动关系，对本单位造成严重影响，或经提出拒不改正
6. 以欺诈/胁迫/乘人之危订立合同

**刑事责任**：7. 被依法追究刑事责任

**非过失性解除（需提前通知或支付代通知金）**：
8. 患病或非因工负伤，医疗期满后不能从事原工作也不能从事另行安排的工作
9. 不能胜任工作，经培训或调岗后仍不能胜任
10. 客观情况发生重大变化，协商未能达成协议

**经济性裁员（满足其一）**：
11. 依《企业破产法》规定重整，需裁减人员
12. 生产经营发生严重困难
13. 企业转产/重大技术革新/经营方式调整，变更合同后仍需裁减人员
14. 其他客观经济情况发生重大变化

### 劳动合同终止（7种情形）

**自然终止**：
1. 合同期满
2. 劳动者开始依法享受基本养老保险待遇
3. 劳动者死亡或被宣告死亡/失踪

**主体消亡**：
4. 用人单位被依法宣告破产
5. 用人单位被吊销营业执照/责令关闭/撤销/决定提前解散

**法定续延至消失时终止**（合同期满也需续延）：
6. 从事接触职业病危害作业者未进行离岗前健康检查，或疑似职业病人在诊断/医学观察期间
7. 患病或非因工负伤，在规定医疗期内
8. 女职工在孕期/产期/哺乳期
9. 在本单位连续工作满15年，且距法定退休年龄不足5年
10. 法律/行政法规规定的其他情形
> **注意**：职业病或因工负伤丧失劳动能力的，按工伤保险规定执行

## SUP-010：调岗问题答疑（HRSSC 实操指引）

**适用模块**：劳动合同 / 异动

**内容**：

### Q1：员工不服从调岗拒不到岗，能否认定为旷工？

**前提条件（缺一不可）**：
1. 岗位调整**合法合理**，有法律依据和事实依据
2. 劳动者行为属于"旷工"（除不可抗力外，不按规定履行请假手续又不按时上下班）

**HRSSC 操作建议**：
- 调岗须先确认合法性和合理性，不急于作处分决定
- 争议期间（特别是员工已申请仲裁），单方处分往往被认定无效

---

### Q2：合同约定保密人员"合同终止解除前公司有权调岗"，是否合法？

**结论：合法**【依据】
- 《劳动合同法》第二十三条：可约定保守商业秘密条款
- 《劳动部关于企业职工流动若干问题的通知》第二条：掌握商业秘密的职工，在劳动合同终止前或提出解除后**不超过6个月内**，单位可调整其岗位

**实操要点**：合同中须明确约定；员工必须履行

---

### Q3：不能胜任工作的调岗，能否同时调薪？

**结论：可以，但须满足两个前提**

1. **有明确的岗位职系和薪酬对应标准**：有制度规定或合同约定
2. **与员工书面确认新岗位与薪酬标准**

**法律逻辑**：
- 岗位管理包含薪酬管理，不胜任调岗时让渡的是**完整岗位管理权**
- 薪酬应按新岗位标准确定，否则有违"同工同酬"
- 无制度规定和合同约定时，调岗后薪酬须**协商确定**，不能由单位单方决定

---

### Q4：实行岗位聘任制的单位，调岗能否随意进行？

**结论：不能随意，需具备以下前提**

- 有明确的**岗位竞聘标准、聘任程序、待岗管理办法**
- 若仅有聘任书而缺乏制度铺垫，单方随意调岗可能损害劳动者利益
- **第一份岗位聘任书**视为劳动合同重要组成部分，非经协商一致不得改换岗位

---

### Q5：部门取消能否作为单方调岗的合法理由？

**区分取消原因**：

| 取消原因 | 认定 | 法律后果 |
|---------|------|---------|
| 企业合并/分立等 | **客观情况** | 可调岗或解除合同 |
| 管理层单方决定取消 | 企业自主管理 | 不属于客观情况，不能直接援引 |

**判断标准**：以"非主观因素"为界定标准
**依据**：《劳动部关于〈劳动法〉若干条文的说明》

---

### Q6：再次录用的员工调岗后，能否重新约定试用期？

**结论：不可以**【依据】《劳动合同法》第十九条

"同一用人单位与同一劳动者**只能约定一次试用期**"

- 即使岗位发生变化，二次入职也不得再设试用期
- 原《劳动法》相关规定已被新法取代，以《劳动合同法》为准

## SUP-014：薪酬场景与加班工资计算

**适用模块**：薪酬

**内容**：

### 薪酬特殊场景

**当月特殊情况**：
- 当月入职后离职：当月工资按实际出勤天数折算
- 当月离职后入职：区分主体，分别计算
- 当月劳动合同改签：变更劳动主体，财务侧记账区分
- 当月人员类型变化：劳动合同转劳务协议 / 正式转外包 / 退休返聘
- 当月多次调薪：调薪前后分段计算

**调薪场景**：
- 调薪前后的请假扣款计算：按分段工资标准分别计算
- 调薪审批滞后：建议以生效日期为准，避免追溯争议

**区域差异**：
- 国内：月薪制
- 海外：周薪/双周薪（如新加坡等）
- 深圳：次月12日前发薪

**特殊费用**：
- 补发津贴
- 兼职补贴
- 多项目成本中心拆分

**考勤与薪资一致性**：
- 考勤周期与薪资周期须保持一致
- 请假审批流滞后：按系统记录为准，做好补单机制

### 社保公积金特殊场景

**基本逻辑**：基数 × 比例；基数有上下限
- **按城市/按险种/按户籍性质**有差异
- **当月扣当月** vs **当月扣下月**（各城市规定不同）

**调整费用**：
- 月度补缴
- 离职预扣与退费
- 调基追溯：关注调基发布时间与基数生效时间

### 加班工资计算

**标准工时制加班**：
- 加班工资基数：月工资 ÷ 21.75天（法定节假日计入）
- 平时加班：150%
- 休息日加班（不能补休）：200%
- 法定节假日加班：300%

**非标准工时加班认定**：
| 工时制度 | 是否需审批 | 加班认定 |
|---------|---------|---------|
| 综合计算工时制 | 必须 | 周期内总工时超法定标准部分按150%；法定节假日工作按300% |
| 不定时工作制 | 必须 | 无固定上下班时间，原则上不认定加班 |
| 自规定/约定（未经审批） | — | 无效，视为标准工时制 |

**注意**：用人单位自行规定的综合工时/不定时工作制，未经劳动部门审批无效

## SUP-015：公司搬迁与员工安置

**适用模块**：劳动合同 / 员工关系

**内容**：

### 搬迁是否属于"客观情况发生重大变化"？

**结论：需综合评判**

考量因素：
- 搬迁距离远近
- 通勤时间延长程度
- 用人单位是否提供交通工具
- 是否调整出勤时间
- 是否增加交通补贴

**判断标准**：搬迁是否给劳动者工作和生活带来**严重不便**，足以影响劳动合同履行

### 用人单位须采取的措施

1. **提前通知**员工搬迁安排
2. **提供交通工具**（如班车）
3. **调整出勤时间**（如弹性上下班）
4. **增加交通补贴**
5. 综合措施已将不利影响降至合理水平的，员工不得拒绝

### 注意事项

- 搬迁距离确实很远且员工有正当理由无法接受：建议**理性协商解除**，不强行要求到岗
- 不可一刀切、无区别对待所有员工
- 员工因此提出被迫解除劳动合同的，需依法支付经济补偿

2. 体检合格证明原件
3. 学历证书原件
4. 上家公司离职证明
5. 能证明工作年限的相关证明
6. 身份证/就业证件/社保转移手续
7. 照片

**视作不符合录用条件**：

- 在服刑/被剥夺公民权利
- 隐瞒病史或欺骗取得体检合格

- 试用期缺勤率达10%

- 应聘资料与实际情况不符
- 岗前培训考核不合格

## SUP-036：停薪留职处理指引

- **适用模块**：特殊用工 / 劳动关系
- **内容**：

### 定义
停薪留职：劳动者经申请，脱离劳动岗位一段时期但仍保持劳动关系，离岗期间权利义务由双方约定。

### 法律状态
⚠️ **目前无有效法律依据支持停薪留职操作**：
- 唯一相关文件《关于企业职工要求"停薪留职"问题的通知》（劳人计[1983]61号）已于 2016 年 5 月 31 日被人社部宣布废止
- 上海地区：12333 及沪劳保关发〔1999〕9号均已作废，暂无停薪留职操作指引

### 核心风险
- 停薪留职期间产生的劳动争议将按"劳动关系"处理（《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》第三十二条第二款）
- 给公司带来额外不必要的劳动关系风险

### 替代处理方案（按成本由低到高）

| 方案 | 适用场景 | 成本 |
|------|---------|------|
| 试用期不符合录用条件（单方解除） | 仍在试用期内 | 无补偿 |
| 协商一致解除 | 双方均可接受 | N+1（约 1.5 个月工资） |
| 医疗期 | 员工患病需持续治疗 | 6个月 × 60% 工资 + 公司社保公积金部分 |

### 医疗期时长速查（企业职工患病或非因工负伤）
| 实际工作年限 | 本单位工龄 | 医疗期 |
|------------|----------|-------|
| < 10年 | < 5年 | 3个月 |
| < 10年 | ≥ 5年 | 6个月 |
| ≥ 10年 | < 5年 | 6个月 |
| ≥ 10年 | 5-10年 | 9个月 |
| ≥ 10年 | 10-15年 | 12个月 |
| ≥ 10年 | 15-20年 | 18个月 |
| ≥ 10年 | ≥ 20年 | 24个月 |

- **来源/依据**：《企业职工患病或非因工负伤医疗期规定》；企业真实停薪留职案例处理

## SUP-040：员工老赖风险管理

- **适用模块**：用工风险 / 薪资发放
- **内容**：

### 场景定义
员工为失信被执行人（老赖），银行卡无法正常接收工资，申请由他人代领工资（公司打款至他人账户）。

### 公司面临的风险

| 风险类型 | 具体描述 |
|---------|---------|
| 法律风险 | 帮员工规避债务偿还义务；被法院要求配合执行；可能被法院处罚 |
| 劳动风险 | 若无员工书面工资代发申请，公司存在"未足额发放工资"风险 |
| 声誉风险 | 雇佣老赖员工，有舆论影响公司声誉的风险 |
| 业务风险 | 员工职业操守下限低，可能成为竞对的"突破口"，存在信息安全漏洞 |
| 薪资保密风险 | 个别员工由他人代领，违反公司薪资保密制度 |
| 税务风险 | 可能引发公司税务/劳动稽查；可能违反《银行卡业务管理办法》第 28 条 |

### 处理建议

1. **明确内部规则**：员工工资发放至个人名下银行卡，不支持代领；如触发修改工资卡条件，人力跟进了解个人情况

2. **入职背景调查**：重点关注财税、高级管理者等关键岗位（注：不得明示，避免就业歧视风险）

⚠️ 【依据】《银行卡业务管理办法》第 28 条：银行卡及其账户只限经发卡银行批准的持卡人本人使用，不得出租和转借

- **来源/依据**：《银行卡业务管理办法》第 28 条；企业员工老赖用工风险分析

## SUP-042：SSC 运营定位与改进策略

- **适用模块**：SSC 运营 / 组织管理
- **内容**：

### SSC 的核心定位（战略方向）
优质 SSC = 专业 + 服务 → 体验

从"衙门式兜底部门"升级为：
- **解决方案提供方**：不只是执行，而是给出方案
- **数据分析角色**：用数据说话，提供决策支持
- **特批兜底**：处理特殊流程，审批人级别高、次数有限制

### SSC 当前问题（待解决）
1. **数据质量问题**：
   - 业务本身复杂（如入离职数据），不能一刀切
   - 解法：与交付对象沟通标准 → 制定内部审核标准并严格执行

2. **能力提升路径**：
   - 小项目滚动交付（2 周为周期）
   - 项目结果通过海报/BP 等形式同步

3. **历史积累缺失**：
   - 流程是否冗余（反向问题）
   - 建立权限管理台账

### SSC 发声渠道
| 渠道 | 受众 | 内容 |
|------|------|------|
| 无忧 HR 服务台（机器人） | 员工/HRBP | 日常答疑、操作指引 |
| 无忧工会服务台 | 员工 | 工会&妇联活动、福利活动 |
| HRBP 协同群 | HRBP | EHR 操作规范/新功能；员工关系法律法规（联合法务）；SSC 业务优化 |

### SSC 工作规范
- 遇到不规范问题：归整 → 整理处理策略 → 形成方案
- 打断有情绪的对话前：做好确认，表达期待和了解情况
- 特殊需求走单独流程（审批人级别高），并设置使用次数限制，倒逼业务侧宣贯员工
