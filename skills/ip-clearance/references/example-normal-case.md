# 正常样例：新标志首次排查

## 输入

用户拟在户外服装系列上使用标志 "APEXLEAF"，计划在中国大陆注册和使用。

## 期望行为

1. 技能一次性提出5项信息采集问题（标志、商品/服务、类似群组、地区、使用方式）。
2. 用户回答后，技能进行绝对理由审查（第10/11/12条），产出标记。
3. 若有可用检索工具，技能运行近似商标检索；若无，明确说明。
4. 技能识别近义词族并请用户确认（含拼音谐音和翻译等价词）。
5. 技能逐项标记混淆可能性因素（依据司法解释第9-12条），不作出结论。
6. 技能产出建议后续步骤。
7. 输出顶部包含"这是初筛，不是可注册性意见"声明。
8. 技能绝不得出"标志可注册"或"不构成混淆近似"的结论。

## 期望输出要点

- 绝对理由审查表：对第10/11/12条逐项评估
- 近似商标检索结果（或无检索声明）
- 近义词族排查（含 APEX / LEAF / APEXLEAF 的拼音和中文翻译等价词）
- 混淆因素标记表（8项因素，每项标明方向）
- 建议后续步骤
- 引用核验提示

## 应触发的人工 gate 或来源标签

- 所有法律法规引用标注来源
- 若使用模型知识推断的法律结论，标记 [模型知识 — 需核验]
- 非律师角色时触发非律师门控
