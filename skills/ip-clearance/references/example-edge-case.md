# 边界样例：无检索工具且发现地名禁用问题

## 输入

用户拟在食品类商品上使用标志 "阳澄湖鲜"，计划在中国大陆注册。无商标检索工具可用。用户角色为非律师。

## 期望行为

1. 绝对理由审查应标记《商标法》第10条第2款地名禁用问题——"阳澄湖"为知名地名，且可能与地理标志保护产品冲突。
2. 由于无检索工具，技能在近似商标检索部分输出"未运行数据库检索"声明。
3. 技能仍继续进行混淆因素分析，但诚实标注检索范围限制。
4. 非律师角色触发非律师门控，输出1页代理人简要。
5. 技能不因地名禁用问题而跳过后续分析——所有步骤仍完整执行。
6. 技能标记地理标志保护产品可能涉及的额外风险（超出初筛范围的标记）。

## 期望输出要点

- 绝对理由审查：地名禁用已标记（"阳澄湖"为县级以上行政区划/知名地名）
- 近似商标检索：显示"未运行数据库检索"
- 混淆因素分析：基于有限信息逐项标记
- 非律师门控：1页代理人简要 + 转介信息（司法厅/局、中华全国律师协会、中华商标协会）
- 建议后续步骤：包括地理标志冲突排查
- 所有输出块标记 [临时模式]（若为临时模式运行）

## 应触发的人工 gate 或来源标签

- 地名禁用判断标记 [模型知识 — 需核验]（"阳澄湖"是否构成第10条第2款下的地名需代理人确认）
- 无检索声明
- 非律师门控
- 地理标志冲突风险标记（超出初筛范围）
- 红灯/黄灯初筛结果
