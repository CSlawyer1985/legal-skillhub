# /clearance-cn

**这是初筛，不是可注册性意见。** 商标可注册性意见需要全面专业检索和注册商标代理人的专业判断。"未发现明显冲突"仅表示初筛未发现问题——不代表标志可以注册。有当事人因通过近似排查的标志而被起诉的先例。

## 指令

1. 读取业务档案配置（practice profile）。若配置为占位状态，停止并引导用户完成初始配置。
2. 按下述工作流程执行。
3. 信息采集（标志、商品/服务、类似群组、地区、视觉/设计要素）。
4. 绝对理由审查——禁用标志、缺乏显著性、功能性。
5. 近似商标检索——使用已连接的商标检索工具。若无工具可用，在输出中说明，仅进行因素分析。
6. 依据《商标法》及司法解释的混淆可能性因素逐项标记；绝不作出可注册性结论。
7. 将初筛备忘录写入事项文件夹（若事项已激活）或业务输出文件夹，按角色适用工作成果标头。
8. 以建议后续步骤和非律师门控结束。

本技能绝不得出标志可注册的结论。不确定时标记——由代理人决定。

## 这是初筛，不是可注册性意见

**每次输出的顶部必须声明。不得省略。不得弱化。**

> **这是初筛，不是可注册性意见。** 商标可注册性意见需要全面专业检索（中国商标网/国家知识产权局商标数据库、企业名称库、域名及社交媒体、商品化权及外观设计等）和注册商标代理人的专业判断，依赖结构化初筛无法完全评估。"未发现明显冲突"仅表示初筛未发现问题——不代表标志可以注册。有当事人因通过近似排查的标志而被起诉的先例。注册商标代理人在任何人采用、申请或投资该标志之前进行评估。

这是本技能最严格的护栏。漏报冲突是不可逆的——例如卡车上的标志、已上市的产品、已提交的商标申请，等等，背后都可能隐藏问题。误报是可逆的——代理人在复核中缩窄清单。始终偏向误报一侧。

## 信息采集

一次性提问（不要拖长简单任务）：

> 运行初筛前需要确认几个问题：
>
> 1. **拟用标志。** 精确拼写、任何设计要素，以及是文字标志、图形标志还是组合标志。
> 2. **商品或服务。** 该标志下实际销售或提供的内容。一两句话描述——由本技能映射到类似群组。
> 3. **类似群组。** 若已知《类似商品和服务区分表》的群组，列出。否则描述商品/服务，由本技能建议可能的群组并确认后再运行检索。
> 4. **地区。** 计划在哪些地区使用、注册或维权？（中国大陆 / 香港 / 澳门 / 台湾 / 马德里国际注册指定国——未指定时默认使用业务档案中的注册地。）
> 5. **实际使用方式。** 是否有标语、相邻产品名称、包装装潢或设计元素将随标志在市场上出现。

等待回答。若描述模糊（"AI工具"、"平台"），追问一次：

> 请描述客户实际看到的东西——是消费者移动应用、企业API、实体产品还是服务？类似群组的判断取决于此。

## 绝对理由审查

在数据库检索之前，先审查无论是否有在先注册都会导致标志无法注册的内在问题。逐项评估并标记。不得将明显问题合理化消除。

| 驳回理由 | 含义 | 标记条件 |
|---|---|---|
| **禁用标志（《商标法》第10条第1款）** | 国家名称、国旗、国徽、国际组织标志、官方标志、检验印记、红十字等；带有欺骗性、歧视性、不良影响的标志 | 标志包含第10条列明的任何禁用元素 |
| **缺乏显著性（《商标法》第11条第1款）** | 仅含本商品通用名称、图形、型号；仅直接表示商品质量、原料、功能、用途等特点；其他缺乏显著特征的 | 消费者看到标志即知商品是什么或做什么，无需想象力 |
| **功能性（《商标法》第12条）** | 三维标志仅由商品自身性质产生的形状、为获得技术效果而需有的形状或使商品具有实质性价值的形状 | 三维标志且形状具有功能性 |
| **地名禁用（《商标法》第10条第2款）** | 县级以上行政区划的地名或公众知晓的外国地名（地名具有其他含义或作为集体商标/证明商标组成部分的除外） | 标志为地名或包含地名 |

关于第10条第1款第(八)项"有害于社会主义道德风尚或有其他不良影响"：该条款是兜底性禁用条款，需结合具体语境判断。对可能涉及不良影响的标志应标记并提示代理人判断。[模型知识 — 需核验]

关于第11条第1款第(二)项的"仅直接表示"：通过使用获得显著性的标志可注册（第11条第2款），但初筛阶段不对此作出判断——仅标记描述性问题并提示需证明获得显著性。[模型知识 — 需核验]

**输出：** 对每个审查类别，给出"未发现问题"或具体标记及一行说明。不要产出空白的通过表格。

## 近似商标检索

本步骤的目的是**发现可能构成混淆近似的在先商标**，而非判断混淆是否成立——那是代理人的职责。

### 可用的检索工具

读取业务档案配置中的可用集成工具：

- **若有商标检索工具可用**（国家知识产权局商标查询系统或任何提供商标数据库检索的工具）：在相关类似群组和地区范围内运行初步检索。对每个结果标注来源。注明检索日期和范围（哪些数据库、哪些群组、精确匹配还是模糊匹配、是否包含图形检索）。
- **若无检索工具可用：** 在输出中明确说明。不得将模型知识推断的结果呈现为检索发现。

### 无数据库检索时的回退

在输出中写入以下声明：

> **未运行数据库检索。** 本初筛未查询中国商标网/国家知识产权局商标数据库、企业名称库、域名及社交媒体或其他未注册商标来源。在得出任何可用性结论之前，需要对上述数据库进行近似排查或全面检索。以下初筛仅限于绝对理由分析和结构化混淆因素分析。

然后继续——绝对理由审查和因素分析仍有价值，只是需如实标注。

### 对发现的每个近似商标（或用户提供的）

记录：

- **标志**（精确字符、任何设计要素）
- **来源**（中国商标网注册号、国际注册号、企业名称登记、域名、社交媒体—— whichever）
- **类似群组 / 商品服务描述**（来自注册记录）
- **注册人**
- **状态**（已注册 / 申请中 / 无效 / 撤销 / 注销——已失效商标不构成权利障碍但可能与知名度及在先权利相关）
- **申请日期 / 初次使用日期（如可获取）**

**不得静默补充。** 若引用注册号，必须来自实际检索；若描述用户提及的标志，需说明来源。不得编造注册号，不得"补全"记录不支持的细节。检索未返回初次使用日期时，写"初次使用日期检索结果中不可获取"——不得猜测。

### 近义词族排查（结束前必需）

仅检查精确和近似匹配的初筛会遗漏竞品因你的标志已被占用而采纳的标志。结束前，识别3-5个近义词族，供执业者进一步排查，并请用户确认或补充。

近义词族是当直接标志不可用时，合理竞品会考虑的品类常规替代词。以 `NEXUS HOME` 在智能家居中枢领域为例，近义词族至少包括：

- **品类近义词** NEXUS：HUB、NEST、CORE、LINK、CONNECT、BRIDGE、CENTRAL、GATEWAY。
- **同品类助手类名称**：ALEXA、ECHO、SIRI、GOOGLE HOME、CORTANA、HOMEY、HOMEBASE。
- **HOME / HOUSE / SMART 变体**：SMART HOME、HOUSEHOLD、HOUSE、ABODE、CASA、DOM。
- **词根音近词**：NEXIS、NEKSUS、NEXXUS、NECTIS、KNOXUS。

技能应在近似商标章节输出近义词族块并附带确认提示：

> **需排查的近义词族（请确认或补充）：**
>
> - [词族1 — 如 HUB / NEST / LINK / CONNECT]
> - [词族2 — 如 ALEXA 类助手名称]
> - [词族3 — 如 HOME / HOUSE / SMART 变体]
> - [词族4 — 词根音近词]
>
> 仅检查精确和近似匹配的初筛会遗漏竞品因你的标志已被占用而采纳的标志。请确认该列表在本品类中是否完整后再继续。

> **当涉及中文语言环境时，** 英文音近排查不够。需补充：
> - **中文翻译等价词。** 标志在中文中的翻译。中文商标审查将含义对应视为近似判断因素。
> - **拼音/谐音。** 标志的汉语拼音或常见谐音。拼音近似是中文商标实务中公认的冲突基础。
> - **异体字/同音字。** 汉字异体字或同音字替换。
>
> 若无法执行中文语言的近似分析，需说明："未执行中文翻译等价词、拼音谐音及异体字分析——这是中文商标冲突最常见的来源之一。在中国大陆的全面检索应包含此分析。"

若执业者有已连接的商标检索工具，对每个已确认的近义词族重新运行检索（精确+拼音+翻译等价词），将结果加入近似商标表并标注"近义词族"来源。若无工具可用，说明情况，将近义词族列为全面专业检索的明确下一步输入——不得静默跳过。

## 混淆可能性因素

> **混淆判断框架因地区而异。** 中国大陆与其他地区的混淆可能性评估方式不同。不要适用错误的框架。
>
> - **中国大陆（《商标法》第57条第(1)(2)项）：** 商标相同/近似 + 商品/服务相同/类似，容易导致相关公众混淆。判断依据《最高人民法院关于审理商标民事纠纷案件适用法律若干问题的解释》第9-12条：综合考量商标近似的程度（音形义）、商品/服务类似的程度、在先商标的显著性和知名度、相关公众的注意程度、使用人意图、实际混淆证据等。 [模型知识 — 需核验]
> - **《商标审查审理指南》（国家知识产权局2021）：** 商标近似判断——整体比对、要部比对、隔离观察；商品/服务类似判断——功能用途、销售渠道、消费对象等。 [模型知识 — 需核验]
> - **香港（《商标条例》第559章第18条）：** 采用与欧盟类似的"整体评估"方法。 [模型知识 — 需核验]
> - **澳门：** 当前未覆盖。澳门商标法律（《工业产权法律制度》12月13日第97/99/M号法令）尚未纳入本插件框架，建议后续版本补充。
> - **台湾：** 当前未覆盖。台湾商标法规（《商标法》民国100年修正）尚未纳入本插件框架，建议后续版本补充。
>
> **[注：本插件港澳台覆盖尚不完整——当前仅含香港商标条例（第559章）的初步引用。澳门商标法律和台湾商标法规尚未纳入，建议后续版本补充。涉及澳门/台湾业务时，请咨询当地律师。]**
> - **其他地区：** 若信息采集包含未列出框架的地区，说明："未配置[地区]的混淆判断框架。套用中国大陆标准会给出看似正确但实际错误的结论。选项：(a) 检索适用标准，(b) 转介[地区]商标专业代理人，(c) 标注该地区超出范围。" 不得静默套用中国大陆标准。

依据适用法律框架确定需逐项分析的因素。在输出中注明所适用的判断标准：

- **中国大陆行政审查/异议/无效：** 依据《商标审查审理指南》的商标近似和商品/服务类似判断标准。
- **中国大陆民事侵权诉讼：** 依据《最高人民法院关于审理商标民事纠纷案件适用法律若干问题的解释》第9-12条的综合因素判断。
- **其他地区：** 适用当地法律规定，并在输出中注明。

对每个因素，产出**标记**，而非结论。每个因素应说明哪些方面倾向冲突、哪些方面倾向不冲突、不确定性在哪里：

- **商标近似程度**（外观/读音/含义/整体印象）。音形义综合考量。
- **商品或服务类似程度。** 不是商品是否相同——而是相关公众是否会认为它们来自同一来源。
- **销售渠道。** 双方实际销售（或可能销售）的渠道。同一家商店？同一分销渠道？同一展会？仅线上？
- **相关公众的注意程度。** 超市货架上的冲动购买与企业采购的审慎考虑标准不同。
- **在先商标的显著性和知名度。** 臆造词/任意词/暗示词/描述词/通用词，及知名度的证据（如有）。强在先商标获得更宽的保护范围。驰名商标适用《商标法》第13条的跨类保护。
- **使用意图。** 是否有攀附商誉的证据——近似标志在相邻类似群组中使用且搭配相似包装装潢，与独立创作不同。
- **实际混淆。** 任何证据（误发询价、消费者调查、评论、社交媒体帖子）。
- **延伸可能性。** 在先权利人是否可能扩展到后使用者的领域，反之亦然。

按业务档案配置中的决策姿态：

- **绝不得出"不构成混淆近似"的结论。**
- 若不确定，写："发现近似商标——采用前需进行混淆评估。" 或："因素相互抵消；需代理人判断。"
- "检索的数据库中未发现近似商标"的明确结论仅在确实运行了检索时给出；否则参见上方无检索回退。

## 建议后续步骤

每份初筛输出以具体后续步骤结尾，按初筛发现分类：

- **若发现绝对理由问题：** 重新设计标志，或接受描述性障碍并规划通过使用获得显著性；在采用前转交代理人复核。
- **若在已检索的数据库中发现近似商标：** 在采用、申请或营销之前需要代理人复核。通常下一步是全面专业检索，以发现初筛遗漏的所有内容。
- **若未发现近似商标但未运行数据库检索：** 在采用前必须进行全面检索。列出需要查询的数据库。
- **若发现近似商标但在先商标较弱、较老、在不同类似群组或已失效：** 标记需代理人复核——初筛不作此判断。
- **始终：** 注册商标代理人出具全面可注册性意见，按标志将承载的投资规模适配。将用于产品线和央视广告的标志比一次性快闪店的标志需要更审慎的评估。

## 本技能不做的事

- **得出标志可注册的结论。** 永远不会。这是本技能最严格的护栏。
- **替代中国商标网/国家知识产权局商标数据库检索、企业名称库检索、未注册商标检索、国际注册检索、监测服务检索或图形标志检索。**
- **提交商标申请。** 申请是代理人事务；本技能为申请决策提供信息。
- **评估包装装潢、商标淡化或驰名商标主张** 超出初步标记。《商标法》第13条驰名商标保护需要知名度分析，本技能不作此分析。
- **处理外国地方法律障碍**（如日本的音近标准、欧盟的外语等价翻译）超出提示需进行外国法分析的标记——当外国地区在范围内时。
- **将输出提供给客户、对方当事人或媒体。** 这是内部研究。若顶部标头适用，则为保密。
