# 法规快讯来源与范围

本文件定义「法规快讯/政策简报」检索任务的**来源白名单**、**权重与优先级**、**地域/机构范围**、**排除项**、**时间窗口**与**关键词扩展规则**。核心原则:**一切结论以能够打开的官方原文为准**;凡是无法定位到官方原文(官网、官方公报、官方数据库)的线索,不得直接写入快讯结论,只能作为"待核线索"提示。

---

### 1.2 地方级(权重次于国家级,适用范围受地域限制)

- 地方人大及其常委会(地方性法规、自治条例、单行条例)与地方人民政府(地方政府规章、规范性文件)官网;统一入口可经各省、自治区、直辖市"政府网"与"人大网"。
- 国家级监管机构的派出/地方机构,例如:证监会各地证监局、国家金融监督管理总局各地监管局、市场监管局、税务局、网信办地方机构、地方生态环境/住建/人社部门等。
- 地方法规优先经**国家法律法规数据库**(收录地方性法规)或**地方政府公报**核验全文。

> 范围约束:地方性法规、地方政府规章与地方规范性文件**仅在本行政区域内有效**。除非快讯主题被明确限定到某地域,否则地方文件原则上只作为"地方动态"单列,不与国家级文件混排为同一效力层级。

### 1.3 行业级(权重最低,多为自律规则/推荐性标准)

- 全国性行业协会、自律组织(如证券业协会、中国银行业协会、中国互联网协会、中国证券投资基金业协会等)发布的自律规则、业务指引、行业公约。
- 标准化机构与标准平台:国家标准全文公开系统(https://openstd.samr.gov.cn)、全国标准信息公共服务平台(https://std.samr.gov.cn);区分**强制性国家标准(GB)** 与**推荐性标准(GB/T、行业标准)** 的不同约束力。

> 行业自律规则、推荐性标准本身不属于"法律法规";仅在被法律、行政法规、规章援引或被监管要求执行时,才具有对外强制力,引用时须标注其性质。

## 二、来源权重与优先级

当同一事项出现多个来源时,按以下顺序取信与引用:

1. **效力层级优先**:宪法 > 法律(全国人大及其常委会)> 行政法规(国务院)、监察法规 > 部门规章 / 地方性法规 > 地方政府规章 > 规范性文件 > 行业自律规则、推荐性标准。司法解释具有特殊地位,适用中具有约束力,单独标注。
2. **原文渠道优先**:官方法规数据库 / 官方公报 / 发文机关官网 > 官方政务新媒体(微信公众号、客户端)> 权威媒体转述(仅作线索,需回溯原文)。
3. **国家级 > 地方级 > 行业级**:同一主题下,先列国家层面规则,再列地方与行业层面。
4. **新法 > 旧法、特别法 > 一般法、上位法 > 下位法**:遇修订或冲突,以现行有效、效力更高、更专门者为准,并在快讯中标明"修订/废止/被替代"关系。
5. **就高不就低的核验要求**:涉及处罚、资质、合规义务等高风险结论,必须落到效力层级最高且能打开的官方原文,不接受仅有二手概述的情形。

**冲突处理**:若官方原文之间口径不一致(如部委问答与规章不一致),以效力层级更高的规范性文件为准,并在快讯中明确标注分歧点,提示需进一步专业判断。

## 三、地域 / 机构范围如何界定

- **默认范围**:中华人民共和国大陆(内地)现行有效的法律、行政法规、部门规章、司法解释及国家级规范性文件。除非用户另有指定,不纳入港澳台地区规则,亦不纳入境外法。
- **地域细化**:当任务限定某省/市(如"上海""粤港澳大湾区"),则在国家级文件基础上,叠加该行政区域的地方性法规、地方政府规章与地方监管动态;跨区域文件需注明适用地域。
- **机构细化**:当任务限定某监管口径(如"证监会口径""金融监管总局口径""网信办数据合规"),以该主管机关及其派出机构官网为主检索域,辅以其上位法与同位阶横向规则。
- **主题细化**:按业务领域圈定主管机关组合(示例)——
  - 资本市场/上市:证监会 + 证券交易所 + 证券业协会 + 基金业协会。
  - 银行保险/金融机构:国家金融监督管理总局 + 中国人民银行 + 国家外汇管理局。
  - 数据与网络安全:网信办 + 工信部 + 公安部 + 市场监管总局。
  - 反垄断/反不正当竞争/广告:市场监管总局。
  - 税务:财政部 + 国家税务总局。
  - 劳动用工:人社部 + 地方人社部门 + 最高人民法院(劳动争议司法解释)。

## 四、排除项(不得作为结论来源)

以下来源**不得**作为快讯结论的直接依据,至多作为发现线索后回溯官方原文的提示:

- **自媒体与个人账号**:公众号、短视频、微博、知乎、小红书等非机构账号的解读、"独家""内部"消息。
- **二手转载与聚合页**:新闻门户、资讯App、法律数据库的"概要/摘编"页,在未回溯到官方原文前不得直接引用结论。
- **无法打开 / 无法定位原文者**:链接失效、需付费墙或登录才能看到正文、仅有截图无可核验出处、来源不明的"红头文件"图片。
- **AI 生成或未署名的汇编**:无发文机关、无文号、无发布日期的"清单""汇总"。
- **草案、征求意见稿被当作生效文本**:征求意见稿、审议稿仅可作为"立法动态/在途规则"单列,**严禁**表述为现行有效规则;须标注"征求意见中/尚未生效"。
- **已废止 / 已被修订替代的旧文本**:除非任务明确要做历史沿革梳理,否则不引用失效版本作为现行义务依据。

**反幻觉硬约束**:不得编造文号、条号、发布机关或链接。条号拿不准时,宁可写"《民法典》合同编相关规定""《个人信息保护法》关于告知—同意的规定"这类指向明确但不锁死具体条号的表述,也不得编造形如"第 X 条"的具体条号。引用具体条号前,应在官方原文(优先国家法律法规数据库)核对其属于哪一**编/章/节/条**且为现行有效版本。

> 版本核验示例:《中华人民共和国民法典》自 **2021 年 1 月 1 日起施行**,共 **7 编**(总则、物权、合同、人格权、婚姻家庭、继承、侵权责任)及附则;原《合同法》《物权法》《婚姻法》《继承法》《侵权责任法》等已同时废止。引用"合同"相关规则时应指向**民法典合同编**,而非已废止的《合同法》。

## 五、时间窗解释(发布日 vs 生效日)

法规生命周期中存在多个关键日期,快讯须区分并尽量同时给出:

- **发布日 / 公布日**:发文机关签发或对外公布的日期(常见于文号与落款)。它决定一条规则"是否进入本期时间窗"。
- **生效日 / 施行日**:文件正文规定开始施行的日期(如"自 XXXX 年 X 月 X 日起施行"或"自公布之日起施行")。它决定该规则**何时产生约束力**。
- **截止 / 废止日**:有效期届满或被明令废止、替代的日期。

**时间窗口规则**:

- 快讯的"时间窗"**默认按发布日筛选**(例:"近一周/近一月发布的法规"),以反映"最新动态";除非用户明确要求"近期生效"或"即将施行",此时改按生效日筛选。
- 对每条目尽量标注:**发布日 + 生效日**;若两者不同(如"过渡期""延后施行"),必须显著提示,避免读者误以为已经生效。
- "征求意见稿"按**意见反馈截止日**管理,并标注"尚未生效"。
- 涉及"自公布之日起施行"的,发布日即生效日,需明确写出。
- 跨年、跨期的修订决定,标注"本次修改自 X 日起施行",并指明修改前后差异点。

## 六、关键词扩展规则

为提升召回率并避免漏检,检索时按以下方式扩展关键词(在官方域内检索为主):

1. **同义 / 简称—全称互换**:机构与文件名常有简称,需双向覆盖。
   - 机构:金融监管总局 = 国家金融监督管理总局 = NFRA;网信办 = 国家互联网信息办公室 = CAC;市场监管总局 = SAMR;工信部 = 工业和信息化部 = MIIT。
   - 文件:个保法 = 个人信息保护法;数安法 = 数据安全法;网安法 = 网络安全法。
2. **文件类型词扩展**:法律 / 行政法规 / 条例 / 规定 / 办法 / 规则 / 指引 / 通知 / 公告 / 决定 / 批复 / 司法解释 / 征求意见稿。同一主题用多类型词分别检索。
3. **动作词扩展**:出台 / 发布 / 公布 / 修订 / 修正 / 修改 / 废止 / 实施 / 施行 / 解读 / 答记者问。便于捕捉"修订"与"废止"动态。
4. **主题词 + 主管机关组合**:将业务主题(如"数据出境""程序化交易""绿色信贷")与第三章的主管机关组合检索,缩小到权威发文域。
5. **文号 / 年份限定**:已知或疑似文号时,用"〔年份〕第 X 号""令第 X 号"等格式在官网站内检索定位原文。
6. **上下游规则链扩展**:命中一条规则后,追检其**上位法、配套细则、修订决定、被废止文件**,形成完整效力链,避免只见单点不见体系。
7. **去噪约束**:扩展检索的目的是"找到线索",最终仍须落到官方原文核验;扩展命中的二手页面只用于回溯原文,不直接进入结论(见第四章排除项)。

## 七、引用与核验清单(写入快讯前自检)

每条快讯条目落笔前,逐项确认:

- [ ] 来源是否为官方原文(官网/公报/国家法律法规数据库),链接当前可打开?
- [ ] 发文机关、文件全称、文号是否与原文一致(未编造)?
- [ ] 是否区分了发布日与生效日,并标注现行有效 / 征求意见中 / 已废止?
- [ ] 引用的条号是否在原文中逐字核对,且分清编/章/节/条?拿不准是否已降级为"相关规定"表述?
- [ ] 效力层级与适用地域是否标注清楚(国家级/地方级/行业级)?
- [ ] 是否避免将草案、二手转述、自媒体解读当作生效结论?

> 凡有任一项无法确认,该条目应标记为"待核",不得以确定口径写入快讯结论。
