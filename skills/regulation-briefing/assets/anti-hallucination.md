# 法规快讯反幻觉规则

本规则约束法规快讯从检索到成稿全过程的事实核验口径。核心原则:**先锚定来源与产量,再谈取舍;每一条事实都要能追溯到打得开的原文,拿不准就如实标注,绝不臆造,但也不因核验过严而把快讯做空。**

`web_search` 只用于发现候选线索,任何结论、引述、字段都必须以 `web_fetch` 打开的原文为准。搜索结果摘要、第三方转述、AI 生成的概述都不构成证据。

## 原文摘录最小证据标准

每条进入快讯的条目,都必须同时具备以下三项可核验证据,缺一不可:

1. **可打开的真实 URL**
   - 必须是用 `web_fetch` 实际打开成功的链接,且页面内容与该条快讯主题一致。
   - 优先指向发布机构官网或官方公报的原文页面;次选权威平台的全文转载页(须能在页面内看到完整正文,而非仅标题或摘要)。
   - 不得使用搜索结果页 URL、聚合站快照、需登录或付费墙后才显示正文的链接、或 `web_search` 返回但未经 `web_fetch` 验证的链接。
   - 不得拼接、猜测或"还原"URL;链接必须是检索过程中真实出现并打开的。

2. **发布日期**
   - 指原文页面或公报中明确标注的发布/印发/公布日期,以原文为准。
   - 发布日期与生效日期是两个独立字段,不得相互替代或推算。原文只给其一时,只填其一,另一项写"原文未明确"。
   - 仅凭页面收录时间、抓取时间或转载时间不得充当发布日期。

3. **能支撑结论的原文摘录**
   - 每条快讯的核心结论(新增义务、调整事项、适用范围、罚则等)都要有一段直接引自原文的文字作为支撑,摘录须能独立看出结论成立。
   - 摘录应忠实于原文用语,可节略但不得改写、归纳后冒充原文、或断章取义改变原意;节略处用省略号标明。
   - 摘录与结论之间不得存在跳跃推理;若结论是 agent 的概括,须与原文摘录区分表述,概括不得超出摘录可支撑的范围。

工作流提示:`web_search` 拆多组关键词广撒网发现候选;对每个候选逐条 `web_fetch` 打开取证;三项证据齐备方可成稿。证据不齐的候选退回存疑或剔除流程处理(见下节),而非凑数填入。

## 存疑/剔除判定

判定的目的是保证已出稿条目可信,而非追求零误差地清空清单。**宁缺毋滥是底线,不是借口:不得因核验门槛过高而导致空输出或明显低于目标产量。**

### 标"存疑"的情形

条目主题确属用户需求范围、有一定来源支撑,但证据未完全闭合时,保留并显著标注"存疑",同时写明存疑原因:

- 原文能打开,但发布日期、文号等关键字段在原文中缺失或表述不清。
- 仅有权威转载、暂未找到一手官方原文,且转载正文与主题自洽。
- 同一事项多个来源在非关键细节上不一致,但主体结论一致。
- 时效或修订状态(如是否已被后续文件修改/废止)无法当场确认。

存疑条目须单列或就地加注,不得与已核验条目混同呈现。

### 直接剔除的情形

以下情形不进入快讯正文,可在交付说明里简述被剔除的原因:

- 所有候选 URL 均无法用 `web_fetch` 打开,或打开后正文与主题无关。
- 多个来源在关键事实(法规名、文号、发布机构、核心结论、罚则)上直接冲突,且无法判定何者为准。
- 无法找到任何可打开的原文,仅有无出处的转述、社媒传言或 AI 概述。
- 疑似虚假、过期失效或张冠李戴(如把征求意见稿当作正式发布、把地方文件冒充国家文件)。

来源冲突时的处理顺序:发布机构官网/官方公报 > 官方授权平台 > 权威媒体/数据库转载;同级冲突且无法判定时,按"存疑"处理并如实写明分歧,不擅自选边。

### 防止过严导致空输出

- 核验不是为了把清单删空。若严格核验后条目数明显低于用户的目标产量,**不要静默交一份过短或空白的快讯**。
- 应当:① 交付所有已核验通过的条目;② 明确说明缺口(目标 N 条、已核验 M 条、存疑 X 条、剔除及原因);③ 提示可拓宽的检索方向(扩展关键词、放宽时间窗、增加来源渠道),供用户决定是否继续。
- "找不到更多可靠条目"是一个需要如实报告的结果,而不是一个可以靠降低标准或编造来填补的缺口。

## 不得推断的高风险字段

以下字段错一个字都可能误导律师的专业判断,**一律以 `web_fetch` 打开的原文为准,严禁推断、补全、四舍五入或凭印象填写**。原文未给出或无法确认时,统一写"原文未明确",绝不臆造:

- **法规/文件名称**:全称以原文为准,不得简称冒充全称、不得自行补"暂行""试行""修订"等字样,不得把征求意见稿、草案、解读文章的标题当作正式文件名。
- **文号**:发文字号(机关代字、年份、序号)逐字照录,不得推算年份或序号,不得把相近文号张冠李戴。
- **发布日期与生效日期**:两者分别独立认定,均以原文为准;不得用其一推算其二,不得用抓取/转载时间替代。一项缺失即如实标"原文未明确"。
- **数字**:金额、比例、期限、阈值、起止时间、人数、面积等所有数值原样照录,保留原文单位与精度,不得换算、取整或估计。
- **罚则金额与处罚幅度**:罚款数额、倍数、上下限、没收范围等以原文为准,"以下/以上/并处"等限定词不得省略或改写。
- **处罚种类**:警告、罚款、没收、责令改正、停业、吊销资质/许可、行业禁入、信用惩戒、刑事移送等,按原文列明,不得增减种类、不得把"可以"写成"应当"或反之。
- **适用范围与生效条件**:适用主体、地域、行业、起算条件、过渡期安排以原文为准,不得扩大或缩小。

通用底线:**摘录用原文的话,概括用自己的话,且二者清晰区分**;凡涉及上述高风险字段的概括,都必须有同条原文摘录可对照。任何"应该是""通常是""一般规定"式的填空都属于臆造,一律改写为"原文未明确"或退回核验。
