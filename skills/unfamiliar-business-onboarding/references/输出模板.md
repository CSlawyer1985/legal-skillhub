# 五板块输出模板

适用于最终交付物。严格按五大板块输出，**每个板块最上方为【板块总结】（3-5 句话概括核心结论），总结之后才是明细**。下划线处按需填充，表格行列按业务类型裁剪。

---

## 一、材料收集

【板块总结】
> 示例写法：本业务全流程分为 X 个阶段，核心环节为……；现行法规框架以《XX法》为核心，配套 X 部行政法规/部门规章，均现行有效（明细见下表）。

**1. 业务流程图**
（文字或图表呈现前期-中期-后期各环节及关键动作）

**2. 法规框架表**

| 序号 | 法规名称 | 效力位阶 | 时效状态 | 核心条款 | 北大法宝链接 |
|---|---|---|---|---|---|
| 1 | | 法律/行政法规/部门规章 | 现行有效 | | （MCP 实时检索生成） |

**3. 参考材料清单**
（律协指引 / 头部律所文章 / 工具书目录，注明来源）

## 三、风险研判

【板块总结】
> 示例写法：本业务共识别 X 项风险，其中红线 X 项（集中于……）、黄线 X 项、绿线 X 项；最致命的风险是……。

**分级风险清单**

| 序号 | 风险点 | 风险等级 | 依据（法规条款/判例案号） | 北大法宝链接 |
|---|---|---|---|---|
| 1 | | 🔴/🟡/🟢 | | |

风险等级定义：
- 🔴 红线：违反效力性强制性规定或司法实践明确否定效力，不可退让
- 🟡 黄线：存在裁判分歧或显著加重己方责任，可谈判
- 🟢 绿线：一般性提示，不影响交易成立

---

## 编制通用规则

1. 各板块总结置顶，结论先行；总结须能独立成立，读者只看总结也能抓住要点
2. 法规与案例引用全部附北大法宝官方链接（交付时经北大法宝 MCP 实时检索生成）；非"现行有效"法规显式标注时效
3. 风险描述与依据逐点一一对应；案例按参照级别标注，普通案例附"最终以法院裁量为准"
4. 交付物末尾附**依据汇总表**：列明全部引用的法规与案例名称、时效/参照级别、链接，便于核验
