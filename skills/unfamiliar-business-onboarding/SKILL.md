# 陌生业务快速上手

## 用途

面对从未接触过的业务领域，最大的风险不是知识盲区，而是在盲区里乱查乱背、或在项目初期过度依赖做过同类业务的同行而丧失主导权。本技能提供一套系统化方法，把陌生业务拆解成可复用的专业护城河：先建立全景认知（材料+法规+判例），再完成风险研判与解决方案，最后对齐行业语言。

**核心纪律**：凡输出中涉及法规名称、条文、案号、裁判规则的，一律调用北大法宝 MCP 工具实时检索并附**北大法宝官方链接**；北大法宝官网有反爬机制（直连返回异常状态码），无法通过脚本批量预取稳定链接，**禁止在技能文件或交付物中硬编码任何未经验证的 pkulaw.com 链接**。

## 何时使用

- 承接全新业务类型的合同审查、合规体系建设、尽职调查或诉讼代理前，需要系统性补课
- 客户咨询陌生行业的交易结构、法律风险，需要快速建立对话能力
- 要把某类业务的零星研究固化为团队可复用的审查成果

## 执行流程（五阶段，对应五个输出板块）

依次完成五个阶段的研究工作，每阶段成果直接对应最终输出的一个板块。研究顺序与输出顺序一致；**输出时每个板块必须把「板块总结」放在最上方，再展开明细**。

### 阶段一：材料收集（含法律法规检索）

目标：建立业务全景认知，并锁定该业务的现行法规框架。

收集四类材料：

1. **各地律协业务操作指引**：优先北京、上海、广东、浙江等发达地区律协发布的专项业务指引（如建设工程、私募股权、特许经营等），通常完整梳理业务前期、中期、后期流程并附操作图。
2. **头部律所实务观察文章**：业内知名律所公众号的相关业务文章，重点提取风险提示与操作实务，略读理论综述。
3. **行业经典工具书目录**：无需通读正文，研读目录即为该业务的基础逻辑框架。
4. **法律法规检索（必须项）**：调用北大法宝 MCP 完成两轮检索——
   - 法条语义检索（`search_article`，建议带 `lib:"中央"`）定位该业务的核心法律依据；
   - 法规列表检索（`get_law_list`，务必带 `effectiveness:["法律","行政法规","部门规章"]` 与 `timeliness:["现行有效"]` 筛选）梳理专项法规与监管规章。
   每条法规必须附**北大法宝官方链接**（从工具返回中取含 `pkulaw.com` 的字段值），并标注时效状态；非"现行有效"的显式提示。

**阶段产出**：业务流程图 + 法规框架表（法规名称/效力位阶/时效/法宝官方链接）。

### 阶段二：裁判案例检索

目标：通过"业务出事时如何解决"掌握真实风险分布。

1. 调用北大法宝 MCP 案例语义检索（`search_case`），检索式组合：**案由 + 行业关键词 + 法院层级（最高院/省高院）**，限定近三年，筛选 10-15 份典型判例。
2. 逐份提取三要素：**双方争议焦点**（最易引发纠纷的条款）、**法院效力认定标准**（司法与监管底线）、**违约方败诉原因**（合同起草或合规须封堵的漏洞）。
3. **每份判例必须引用北大法宝官方链接**：保留案号、审理法院、参照级别与 pkulaw.com 链接（从工具返回提取；链接锚点若带 `.0` 后缀须去除）。案例按参照级别排序：指导性案例 > 公报案例 > 典型/参考案例 > 普通案例。

**阶段产出**：判例分析表（案号/法院/参照级别/争议焦点/裁判规则/败诉原因/法宝官方链接）。

### 阶段三：风险研判

目标：把法规要求与判例痛点整合为分级风险清单。

1. 汇总阶段一的法规强制性要求与阶段二的判例痛点，逐条形成风险点。
2. 按三级标注风险等级：
   - 🔴 红线：违反效力性强制性规定或司法实践明确否定效力，不可退让；
   - 🟡 黄线：存在裁判分歧或显著加重己方责任，可谈判；
   - 🟢 绿线：一般性提示，不影响交易成立。
3. 每个风险点必须注明来源（法规条款+法宝链接，或判例案号+法宝链接），禁止凭经验虚构。

**阶段产出**：分级风险清单（风险点/等级/依据+法宝链接）。

### 阶段四：解决方案

目标：每个风险点给出可执行对策，禁止只提示风险不给方案。

- 对策形式限于可执行动作：条款改写方向 / 补充协议或文件 / 担保措施 / 交易结构调整 / 资质核验动作。
- 对策与阶段三的风险点一一对应；涉及法规依据的附法宝官方链接。

**阶段产出**：风险-对策对应表。

### 阶段五：行业黑话（术语转译）

目标：消除与客户之间的语言系统错位。

1. 收集 5 份标杆合同（上市公司公告、裁判文书附件、行业协会示范文本），提取行业惯用语。
2. **把行业专业术语转译为法律人士可以理解的专业内容**：每个黑话词汇给出「行业语境含义 → 对应法律概念 → 该词背后的权利义务要点」三栏，不允许只罗列术语不做转译。
3. 补充极速反向访谈：向同行或客户业务人员用商业话术提问（"行业公认的交易惯例有哪些""哪个环节最容易被动手脚""近年典型翻车事件"），验证黑话理解是否与实务一致。

**阶段产出**：行业黑话-法律概念转译表。

## 输出格式（强制）

**交付物固定为独立的 HTML 文件（.html），内容严格按 `references/输出模板.md` 的五板块格式编排，逐板块、逐表格样式套用，不得自行增删板块或变更表头。**

生成路径：按模板生成五板块内容后，产出一份**自包含的独立 HTML 文件**（全部 CSS 内嵌 `<style>`、无外部依赖、UTF-8 编码、浏览器直接打开即可阅读/打印/另存），保存到工作目录后用 `present_files` 打开预览。禁止只在对话中输出文本而不生成 HTML 文件。

五板块结构，**每个板块的最上方必须是该板块的总结段落（结论先行），总结之后才是明细表格/列表**：

```
一、材料收集
【板块总结】……
（明细：业务流程图、法规框架表……）

二、裁判案例检索
【板块总结】……
（明细：判例分析表……）

三、风险研判
【板块总结】……
（明细：分级风险清单……）

四、解决方案
【板块总结】……
（明细：风险-对策对应表……）

五、行业黑话
【板块总结】……
（明细：术语转译表……）
```

板块总结要求：用 3-5 句话概括本板块核心结论（该业务是什么流程/司法底线在哪/最大风险是什么/核心对策是什么/沟通中最易误解的术语是什么），让读者只看总结也能抓住要点。

HTML 文件命名规范：`<行业/业务领域>合规体系梳理报告.html`（或按用户指定的主题词），保存在工作目录下，不覆盖同名旧文件（已存在时加日期后缀）。北大法宝链接在 HTML 中以 `<a href>` 超链接形式呈现，便于点击溯源。

## 北大法宝检索与链接纪律（强制）

1. **实时检索，不预存链接**：所有法规条文与案例链接必须在交付时通过北大法宝 MCP 工具实时检索生成。检索方法、参数形态、返回字段读取、自愈阶梯，一律遵循 `pkulaw` 技能现行约定（语义检索主参数为 `text` 而非 `query`；法条精确取条优先 `get_article`，中文/数字条号均可；包装体参数按平铺传）。
2. **链接提取**：从工具返回中取含 `pkulaw.com` 的字段值作为官方链接；取条（元数据版）链接锚点带 `.0` 后缀（如 `#tiao_1077.0`）须去掉再交付。
3. **法条核验**：引用条文前先精确取条核对原文；条号迁移是高频错源，命中不符时改用语义检索按内容定位现行条号。
4. **时效标注**：非"现行有效"的法规必须显式标注；法条识别工具不返回时效，判断废止须调法规列表或取条（元数据版）。
5. **案例分级**：指导性案例（应当参照）> 公报案例 > 典型/参考案例 > 普通案例，以返回的参照级别字段为准，不得凭推断升级；引用普通案例须附"最终以法院裁量为准"。
6. **反幻觉闭环**：对外交付成果定稿前走 pkulaw 技能第七节闭环（生成→抽取→核验→修正→加链接）。
7. **空结果处理**：检索未命中的如实说明"未在北大法宝库验证到"，禁止用记忆填补法规名、条文或案号。
