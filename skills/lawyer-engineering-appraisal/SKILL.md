# 律师参与建设工程造价司法鉴定操作指引

来源：浙江省律协建设工程专业委员会
依据：《民事诉讼法》《民诉法解释》《民事诉讼证据规定》《建工司法解释（一）》《建设工程造价鉴定规范》（GB/T 51262-2017）

## 核心原则

- **必要性**：鉴定确有必要，非所有造价争议均需鉴定
- **关联性**：鉴定事项与案件争议焦点直接相关
- **可行性**：鉴定事项在技术上可鉴定
- **范围最小化**：仅就争议事项委托鉴定，避免扩大范围

## 阶段一：鉴定的准备

### 触发条件
当事人对工程造价存在争议，既未达成结算协议，也无法通过其他方式确定。

### 律师工作清单

1. **评估鉴定必要性**——以下情形法院一般不支持鉴定，应书面告知当事人风险：
   - 诉前已达成结算协议
   - 约定固定价结算
   - 诉前共同委托并明确接受咨询意见约束
   - 约定"逾期未答复视为认可"且条件已成就
   - 法院可直接根据结算材料认定金额

2. **提示举证期限**——在一审举证期限内提出鉴定申请，预交鉴定费，告知逾期后果

3. **法院释明后的应对**——收到法院释明后在指定期限内提出申请；未按期申请的，书面告知后续申请可能不被接受的风险

4. **鉴定前准备**——明确鉴定范围、鉴定依据，准备鉴定材料

### 关键条文
- 指引第3条（四大原则）、第6-12条

---

## 阶段二：鉴定的委托

### 律师工作清单

1. **审核鉴定启动**——审查鉴定目的、范围是否适当，有异议及时向法院提出
   - 法院未采纳异议的，在笔录中陈述保留意见
   - 但仍有配合鉴定的义务

2. **参与鉴定机构选定**
   - 协商或抽签（摇号）从法院名录中选定
   - 按时参与选取活动，未到场视为同意抽签结果
   - 发现回避情形及时书面报告

3. **确认材料移交**——核实起诉状、答辩状、代理词、证据、质证意见、庭审记录等是否完整移交鉴定机构

### 关键条文
- 指引第13-17条

### 举证质证要点

**提交材料**：
- 按法院/鉴定机构通知的时限提交，无法提交应书面说明
- 逾期前申请延期并说明理由
- 对无关材料可提书面异议

**质证三性审查**：
- **真实性**：形式真实性（原件核查）+ 内容真实性
- **合法性**：取得途径 + 内容合法性
- **关联性**：与争议焦点的关联、证明力

**质证11项要点**（第25条）：
1. 是否影响合同效力或导致合同变更
2. 是否构成无权代理/表见代表/表见代理
3. 是否构成法律上的自认
4. 是否符合程序、是否构成权利失效
5. 是否构成增减造价/调整价格事由
6. 是否影响人材机动态调整或调整方法
7. 是否影响造价计算/结算时间节点认定
8. 是否影响人材机管理费利润措施费税金等计算标准及计量
9. 是否影响工期计算或工期责任分配
10. 是否影响违约金或工程价款利息计算
11. 是否影响法律责任或权利失效情形的豁免

### 需提请法院先行确定的事项（第22条）
1. 涉及合同效力认定
2. 多份合同需确定结算依据
3. 计价依据/方法约定不明或有争议
4. 证据采信涉及法律问题
5. 事实无法查明或证据缺失时的责任分配
6. 鉴定事项有赖于合同约定但约定不明/没有约定
7. 鉴定事项有赖于非委托范围内其他事项先行鉴定

### 证据不足时的补充方法（第23条）
1. 申请补充现场勘验
2. 申请其他在先/同步鉴定或第三方勘验
3. 申请法院调查取证
4. 申请责令对方提交证据
5. 建议征求行业主管部门意见
6. 提供类似鉴定案例/司法判例

### 关键条文
- 指引第18-25条

## 阶段四：鉴定的实施

### 律师工作清单

1. **审核鉴定费用**——不合理或无依据可提异议
2. **审核鉴定方案**——邀请专家辅助人参与，关注鉴定依据是否完整、是否需现场勘验
3. **参加鉴定准备会/听证会**——委派造价人员或邀请专家辅助人参加
4. **补充鉴定材料**——收到通知后及时提示当事人提交
5. **参加现场勘验**——审核程序合规性、勘验笔录准确性，有异议提出书面意见

### 关键条文
- 指引第26-30条

---

## 阶段五：鉴定意见的审查与质证

### 12项审查要点（第31条）

1. **程序合法**——鉴定人资质、专业匹配、回避情况
2. **范围一致**——是否超出/遗漏委托范围，是否需重新/补充鉴定
3. **证据质证**——采信证据是否经过质证，征求意见阶段补充证据是否充分考虑
4. **现场勘验**——程序是否合法合理，反馈问题是否有效回应
5. **以鉴代审**——是否存在应由法院确定而鉴定机构自行确定的情形
6. **鉴定方法**——征求意见时反馈的方法错误是否得到回应
7. **计算依据**——鉴定要素依据是否充分
8. **运算错误**——征求意见时发现的运算/换算错误是否修正
9. **推导说明**——依据不清进行推导的，是否说明推导方法和依据
10. **争议项选择**——选择项是否充分，应结合案件事实提出己方选择意见
11. **处理建议**——是否有客观事实基础，是否公平公正
12. **无法鉴定**——阐述可以鉴定的理由及建议方法

### 申请重新鉴定的4种情形（第32条）
1. 鉴定机构/鉴定人不具备相应资格
2. 鉴定程序严重违法
3. 鉴定意见明显依据不足
4. 其他不能作为证据使用的情形

### 瑕疵处理（第33条）
可通过补正、补充鉴定、补充质证、重新质证解决的，不必申请重新鉴定。

### 关键条文
- 指引第31-33条

---

## 阶段六：鉴定人员出庭接受质询

### 申请出庭的7种情形（第35条）
1. 鉴定意见与在案其他证据存在难以排除的较大矛盾
2. 同一事项多份鉴定意见内容差异较大
3. 鉴定材料的可鉴定条件、依据、论证过程有较大争议
4. 鉴定论证过程与结论矛盾，或分析论证不充分
5. 鉴定意见结论不明确或存有争议
6. 对鉴定程序合法性提出异议并提供证据
7. 其他确有必要的情形

### 出庭注意事项
- 按法院通知预交出庭费用，不预交视为放弃
- 发问不得诱导，围绕各方异议展开
- 发问内容：鉴定人资质、鉴定材料、程序、方法、依据、内容、结论
- 常见问题：工程量计算、鉴定范围确定、材料采用、方法选择、定额取费标准、法律法规技术规范
- 质询后应就当庭内容发表质证意见

### 关键条文
- 指引第34-38条

---

## 阶段七：专家辅助人出庭

### 申请要点
- 举证期限届满前或申请鉴定人出庭时提出
- 申请书内容：人数（一般不超过2人）、身份信息、专业能力证明、出庭理由
- 费用由申请方自行负担

### 专家辅助人可选范围
- 工程造价专业研究人员/学术权威
- 工程造价相关资格技术人员
- 长期从事造价管理的一线经验丰富人员

### 庭审活动范围
- 围绕鉴定意见或专业问题展开
- 协助对鉴定范围、依据、方案提出专业意见
- 参与鉴定材料及意见质证（含对鉴定人的质询）
- 可出具书面专门问题报告
- **不得**参与专业问题之外的法庭审理活动
- **不得**发表与专业问题无关的意见

### 律师与专家辅助人配合
- 开庭前介绍案件基本情况、争议焦点、需解决的专业问题
- 出示鉴定意见等相关证据材料
- 客观真实介绍，不得隐瞒或误导
- 各司其职，专家辅助人不得单独出庭

### 关键条文
- 指引第39-46条

## 自动化任务：征求意见稿审查

### 触发条件
用户提供鉴定征求意见稿文本或文件路径，要求进行审查。

### 执行流程

1. **获取征求意见稿内容**
   - 用户提供文件路径：读取文件内容
   - 用户直接粘贴文本：直接使用
   - PDF文件：使用PyPDF2提取文本

2. **逐项审查（12项要点）**
   对照以下要点逐项检查鉴定意见稿：

   **(1) 程序合法性**
   - 鉴定机构/鉴定人资质是否具备
   - 专业是否匹配、回避是否合规

   **(2) 鉴定范围一致性**
   - 是否超出/遗漏委托范围
   - 是否需重新/补充鉴定

   **(3) 证据质证情况**
   - 采信证据是否经过质证
   - 征求意见阶段补充证据是否充分考虑

   **(4) 现场勘验**
   - 程序是否合法合理
   - 是否遗漏重要环节
   - 反馈问题是否有效回应

   **(5) 以鉴代审问题**
   - 是否存在应由法院确定而鉴定机构自行确定的事项

   **(6) 鉴定方法**
   - 方法选择是否有误
   - 征求意见时反馈的方法错误是否得到回应

   **(7) 计算要素依据**
   - 人材机单价、取费标准、定额套用依据是否充分

   **(8) 运算/换算错误**
   - 工程量、单价/合价计算是否正确
   - 征求意见时发现的错误是否修正

   **(9) 推导说明**
   - 依据不清进行推导的，是否说明推导方法和依据

   **(10) 争议项选择**
   - 供法院选择的选项是否充分
   - 是否遗漏合理计算方案

   **(11) 处理建议**
   - 是否有客观事实基础
   - 是否公平公正

   **(12) 无法鉴定事项**
   - 理由是否成立
   - 是否存在可鉴定但被认定无法鉴定的事项

3. **生成审查报告**
   - 使用模板：`templates/征求意见稿审查报告模板.md`
   - 输出文件路径：案件目录下`鉴定意见审查报告_{日期}.md`
   - 如在Obsidian Vault中处理，输出到对应案件笔记目录

4. **后续动作（根据审查结果）**
   - 存在程序/资质问题：提示可申请重新鉴定
   - 存在计算错误：提示需书面提出并要求修正
   - 存在以鉴代审：提示需向法院提出异议
   - 存在依据不足：提示需补充证据或申请补充鉴定

### 输出格式
- 结构化审查报告（按模板）
- 重点问题清单（便于直接转为书面质证意见）
- 工作建议（下一步行动项）

## 自动化任务：征求意见稿质证意见生成

### 触发条件
完成征求意见稿审查后，用户要求生成质证意见；或用户直接提供审查报告并要求生成质证意见。

### 执行流程

1. **输入来源**
   - 优先使用已生成的审查报告（`鉴定意见审查报告_{日期}.md`）
   - 如无审查报告，先执行"征求意见稿审查"流程

2. **从审查报告提取关键信息**
   - 程序合法性问题 → 对应质证意见第一节
   - 鉴定范围问题 → 第二节
   - 鉴定依据问题 → 第三节
   - 鉴定方法问题 → 第四节
   - 争议金额及各方主张 → 第五节
   - 以鉴代审问题 → 第六节
   - 无法鉴定事项 → 第七节
   - 需补充/重新鉴定事项 → 第八节
   - 需鉴定人出庭 → 第九节

3. **生成质证意见**
   - 使用模板：`templates/质证意见书模板.md`
   - 根据审查发现的问题逐节填充
   - 无对应问题的节删除，不保留空节
   - 语言风格：法律文书规范用语，简洁精准，避免冗余

4. **质证意见撰写要点**
   - **事实先行**：先列明鉴定意见的具体内容，再提出异议
   - **依据充分**：每项异议必须有合同条款、法律规定或证据支撑
   - **主张明确**：明确提出己方主张的计算方案，不能只反对不建设
   - **区分层次**：
     - 证据采信争议 → 要求法院确定
     - 合同解释争议 → 提出己方解释并要求法院确定
     - 计算错误 → 要求鉴定机构修正
     - 方法不当 → 要求鉴定机构说明或调整
     - 遗漏事项 → 要求补充鉴定
   - **避免越权**：质证意见是向法院提出，不是直接与鉴定机构辩论

5. **输出**
   - 文件路径：案件目录下`质证意见_{案号}_{日期}.md`
   - 如在Obsidian Vault中处理，输出到对应案件笔记目录

### 质证意见的结构逻辑

```
鉴定意见内容 → 己方异议 → 事实/合同/法律依据 → 己方主张 → 请求法院处理方式
```

### 常见请求类型
- 要求法院先行确定（证据采信、合同解释）
- 要求鉴定机构修正（计算错误、方法不当）
- 要求补充鉴定（遗漏事项、无法鉴定但实际可鉴定）
- 申请鉴定人出庭（意见矛盾、依据不足）
- 申请重新鉴定（程序违法、资格不符）

## 附则

- 本指引适用于律师参与建设工程造价司法鉴定活动，仅供参考，不具有强制性
- 建设工程仲裁案件中的造价鉴定活动同样适用（第48条）
- 鉴定意见供法院参考，非必然唯一依据，法院可全部或部分不予采纳（第5条）
