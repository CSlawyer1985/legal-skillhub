# 政府信息公开告知书生成技能

> 本技能用于生成政府信息公开告知书（答复书），为政府机关提供标准化的答复文书撰写框架。**全国通用**，与 `gov-info-disclosure-review`（合法性审查技能）配套使用。文中所有机关名称、文号、联系方式、属地规范性文件均为占位示例，发布使用前务必按受案机关所在地现行规定核实。

> **▶ 30 秒速览（TL;DR）**
> - **它做什么**：起草《政府信息公开申请答复书》及配套程序文书（接受回执、补正告知书、延期答复告知书、征求第三方意见告知书、征求意见函）。
> - **怎么用**：按“补不补→该不该→有没有→给不给→当不当”五步走：先审查申请是否需补正；再判断是否属政府信息公开申请；检索信息有无；研判可否公开；最后按情形选用文书并给出救济途径。详见“使用流程”。
> - **何时触发**：申请人提交政府信息公开申请、需依法作出答复/告知/补正/延期/征求意见时。详见“使用触发条件”。
> - **能力边界**：仅一类——涉密程度极高、需专门保密审查人员处理的申请（超出本技能日常答复范围）。其余情形均由本技能判断并分类处理。

> **🛠 怎么用（三步交互）—— 把它当“可执行”的工具，而不是只读文档**
> - **第 1 步 · 给它什么**：告诉 AI“请起草一份政府信息公开申请答复书”，并把申请信息与材料给它（申请人、申请内容/渠道、收悉日期、申请事项、相关机关与联系方式、需作出的答复类型等；缺信息也没关系，它会再要）。
> - **第 2 步 · 它会先问你什么**：关键点不明时会先向你确认/请补充——该申请是信息公开申请还是信访/投诉/履职？信息是否已检索、有无部门回复？是否涉及第三方需征求意见？以谁名义落款（本级政府 还是 政府办）？——你先答，它再起草。
> - **第 3 步 · 它给你什么**：一份可直接印发/修改的《政府信息公开申请答复书》（含文号、申请事实、法律依据、处理决定、救济途径、落款；程序文书用“依告”、实体用“依复”），并标注 ✅ 已明确 · ⚠️ 待核实 · ❌ 需修改的项。

## 一、技能概述与适用场景

**定位**：为政府机关起草政府信息公开告知书/答复书，提供规范、合法、可操作的格式与模板，并提示答复要点与风险。

**适用场景**：
- 依申请公开的政府信息答复
- 主动公开信息的获取指引
- 多申请事项的综合答复
- 复杂/批量信息公开申请的处理
- 行政复议、行政诉讼前置的答复文书

### 使用触发条件（何时使用本技能）
- 行政机关收到政府信息公开申请，需要作出**答复 / 告知 / 不予公开 / 无法提供 / 不予处理**决定时；
- 需出具**程序性文书**（申请接收回执、补正告知书、延期答复告知书、征求第三方意见告知书、征求共同制作机关意见函）时；
- 多个申请事项需**逐项答复**，或需在行政复议、行政诉讼前形成规范答复文书的。
- **不触发**：无需作出答复的咨询性提问；非政府信息公开事务。

### 使用流程（五步，参照国办公开办函〔2020〕2号）
1. **补不补（申请审查）**：申请是否符合《条例》第29条形式要件；内容不明确、缺身份证明/联系方式/形式要求的，依第30条在**7个工作日内一次性**告知补正事项、合理补正期限、拒绝补正后果（补正期限一般不超过15个工作日，原则上一次；逾期不补正视同放弃）。
2. **该不该（职责与申请性质）**：判断是否属政府信息公开申请——信访、投诉、举报、履职等诉求类依《条例》第39条不作信息公开申请处理；属其他机关职责范围、本机关不掌握的，依第36条第（五）项指引。
3. **有没有（信息检索）**：认真检索、查找，确认信息是否存在；未制作/获取、超期销毁、资料灭失等无法提供的，依第36条第（四）项告知“经检索该政府信息不存在”。
4. **给不给（公开研判）**：依法决定是否公开——可公开的予以公开；涉秘密/禁公开/三安全一稳定/第三方权益/内部事务/过程性/执法案卷的依第14、15、16条不予公开；能区分处理的作部分公开（第37条）。
5. **当不当（答复制作与送达）**：依法依规制作答复文书（具备标题、文号、申请人、申请事实、法律依据、处理决定、救济权利期限、答复主体、日期印章等要素），并以适当形式提供、送达。

### 交互验证：起草前须先核实/确认的关键点
起草过程中如材料缺失或关键事实不明，**先向用户确认/请补充，确认后再落笔**，避免答非所问或程序瑕疵：
- **申请性质**：是政府信息公开申请，还是信访、投诉、举报、履职、咨询？→ 决定“作为信息公开申请处理”还是“依第39条不予处理”。| ⚠️ 需判断
- **申请内容**：完整、准确引用申请人原文；多事项是否都须逐项答复？| ✅ 需材料
- **答复类型**：归入哪类（予以公开 / 不予公开 / 无法提供 / 不予处理 / 指引其他机关 / 部分公开）？| ⚠️ 需判断
- **信息存在性**：是否已检索？有无部门回复？信息是否已移交档案馆（区分提前移交）？| ✅ 需材料
- **第三方权益**：是否涉及商业秘密/个人隐私？是否已征求第三方意见、态度如何？| ⚠️ 需确认
- **程序合规**：答复期限（20个工作日）是否足够？需否延期（经批准告知）、补正（7个工作日一次性告知）？| ✅ 核验期限
- **主体与名义**：以谁名义落款（本级政府 / 政府办）？文号用“依复”还是“依告”？→ 决定被告/被申请人、复议机关、管辖法院。| ⚠️ 需核实
- **法条与属地**：引用法条是否现行有效（法释〔2011〕17号已废止）；部门名称、地址、电话按属地核实。| ✅ 核验

> **交付前**：标 ⚠️ / ❌ 的项必须在文书中如实处理（留空待填、标注待核实或提示风险）；涉及“信息不存在”“不予公开”的须保留检索/征求意见留痕。

### 能力边界
- **仅一类硬边界**：涉密程度极高、需专门保密审查人员处理的申请（如涉及国家秘密定密、需保密行政管理部门把握）。此类超出本技能日常答复范围。
- 其余情形均在本技能“内置判断”能力内，由技能自行识别并**分类处理**（不予公开、无法提供、不予处理、指引其他机关、部分公开等），不作排除。

## 二、告知书撰写原则

1. **合法性原则**：答复必须有明确的法律依据；引用条款须准确；不得设法规外条件限制申请人权利。
2. **准确性原则**：机关名称、地址、电话须准确核实；文号格式统一规范；申请内容引用须完整准确。
3. **便民原则**：已主动公开的信息，告知获取途径（网址、查询方式）；指向其他机关的，提供详细联系方式；可以提供的，直接提供复印件。
4. **全面答复原则**：每个申请事项都须有明确答复，不得遗漏；混合类型申请的，逐项分类答复。

## 三、告知书标准结构与格式规范

### 标准结构
```
政府信息公开告知书
（年份）第X号

[申请人姓名/名称]：

本机关于[收悉日期]，接到您通过[申请渠道]提交的政府信息公开申请，申请内容为：“[申请内容]”。

[答复正文]

[救济途径]

[落款机关]
[日期]
```

### 格式要点（参照公文格式常用规范）
- **标题**：“政府信息公开告知书”，宋体，二号，加粗，居中。
- **文号**：“（年份）第X号”，如“（2024）第9号”；位于标题下方居中；年份用全角括号“（）”，数字用阿拉伯数字。
- **申请人称呼**：“[申请人姓名]：”，仿宋，三号；位置在文号下方，顶格（无缩进）。
- **收悉段落**：仿宋，三号，首行缩进2字符；申请渠道可为线上/信函/当面/EMS/传真等；申请内容完整引用原文，加引号。
- **答复正文**：仿宋，三号，首行缩进2字符；按答复类型选用对应模板。
- **救济途径**：见下文模板库。
- **落款**：落款机关 + 日期；仿宋，三号，右对齐。

**关于落款日期的说明**：行政机关草拟的告知书通常暂不填具体日期（如“202X年X月　日”），待正式发出时统一填写，这是工作常规，不是文书瑕疵。

### 文书要素与文号（参照国办公开办函〔2020〕2号）

按《江苏省政府信息公开申请办理答复规范》（**国办公开办函〔2020〕2号** 转发、供参考）的答复文书格式文本，答复书应具备以下要素：**标题、文号、申请人姓名（名称）、申请事实、法律依据、处理决定、申请人复议诉讼的权利和期限、答复主体、答复日期及印章**。

- **文号规则**：实体处理文书（予以公开/不予公开/无法提供/不予处理）用 **「依复〔20XX〕第X号」**，如“依复〔2024〕第9号”；程序处理文书（补正/延期/征求意见等）用 **「依告〔20XX〕第X号」**。
- **答复书标准骨架（实体处理通用）**：
```
依复〔20XX〕第X号
政府信息公开申请答复书
〔申请人姓名/单位名称〕：
本机关于〔收悉日期〕收到您（你单位）通过□在线□信函□传真□当面□提交的《政府信息公开申请书》。
〔答复正文 + 法律依据 + 处理决定〕
如对本答复不服，可以在收到本答复之日起60日内向〔复议机关〕申请行政复议，或者在6个月内向〔管辖法院〕提起行政诉讼。
〔行政机关名称〕（印章）
〔年 月 日〕
```
- 答复书标题建议用「政府信息公开申请答复书」（国办规范口径），亦可按属地习惯用「政府信息公开告知书」；正文须**区分“第X条/款/项”**，引用条文与处理决定一致（除事实判断及适用第38、39条外，适用第36条及其他相关条文）。

### 程序处理文书模板（参照国办公开办函〔2020〕2号）

| 情形 | 文号 | 要点 |
|------|------|------|
| 申请接收回执 | 依告 | 确认收悉、告知20个工作日内答复、提供办理进度查询电话 |
| 补正告知书 | 依告 | 依《条例》第30条，7个工作日内一次性告知补正事项、合理补正期限（一般≤15个工作日）、拒绝补正后果；□列明具体补正项 |
| 延期答复告知书 | 依告 | 依第33条，经政府信息公开工作机构负责人同意，延期≤20个工作日并告知 |
| 征求第三方意见告知书（给第三方） | 依告 | 依第32条，就公开是否损害第三方权益征求意见，15个工作日内回复 |
| 征求第三方意见告知书（给申请人） | 依告 | 告知已征求第三方意见，征求意见时间不计入答复期限 |
| 政府信息依申请公开第三方告知书（给第三方） | 依告 | 第三方回复后决定公开的，告知第三方并附公开内容 |
| 征求意见函（共同制作机关） | 依告 | 依第34条，征求共同制作机关意见，15个工作日内书面回复 |

## 四、答复类型及生成模板

> 法律依据引自《政府信息公开条例》（2019年修订，国务院令第711号）。条款号以该版为准。

### 类型一：已主动公开（第36条第（一）项）
- **适用情形**：信息已主动公开，申请人可通过指定渠道获取。
- **模板**：
  > 经查，您申请的信息已通过[公开渠道]主动公开，您可以自行查阅、获取。[获取方式说明，如网址、查询路径等]。根据《中华人民共和国政府信息公开条例》第三十六条第（一）项规定，特此告知。
- **示例**：申请“征地红线图”，未查到同名文件但查到对应的“勘测定界图”；申请“征地预公告”，未查到同名文件但查到对应“征地告知书”。上述信息已通过**省级征地信息公开平台**主动公开，可自行查阅获取（网址：……）。据此依第36条第（一）项告知。**（注意：平台名称、网址按属地实际填写。）**

### 类型二：直接提供（第36条第（二）项）
- **适用情形**：信息由本机关制作/保存，可直接提供。
- **模板**：
  > 根据《中华人民共和国政府信息公开条例》第三十六条第（二）项的规定，现将[文件名称]复印件（附后，共X页）提供给您。
- **注意**：提供复印件时需加盖公章，注明“与原件一致”。

### 类型三：信息不存在（第36条第（四）项）
- **适用情形**：经检索，信息不存在或未制作/未保存。
- **模板**：
  > 经查，您申请的信息不存在，故无法提供相关信息。根据《中华人民共和国政府信息公开条例》第三十六条第（四）项规定，特此告知。
- **注意**：需说明已进行合理检索，必要时描述检索过程（相关举证/说明要求见法释〔2025〕8号第5条第（六）项）。

### 类型四：告知向其他机关申请（第36条第（五）项）——最常用
- **适用情形**：信息非本机关制作/保存，但可确定负责公开的行政机关。
- **完整模板**：
  > 经查，您申请的信息不是本机关制作保存，故无法提供相关信息。根据《中华人民共和国政府信息公开条例》第三十六条第（五）项规定，特此告知。建议您向[部门全称]申请或咨询。[部门全称]地址：[详细地址]，联系电话：[电话]。
- **简化模板**（不能确定明确联系方式时）：
  > 经查，您申请的信息不是本机关制作保存，故无法提供相关信息。根据《中华人民共和国政府信息公开条例》第三十六条第（五）项规定，特此告知。
- **关键要求**：部门名称必须准确（核实全称）；地址尽量具体；电话必须核实有效；**职责归属按属地“三定”方案确定，勿机械套用其他地区口径**。

### 类型五：不予重复处理（第36条第（六）项）
- **适用情形**：申请人就同一事项重复申请。
- **模板**：
  > 经查，您曾于[前次申请日期]就[申请事项]提出过政府信息公开申请，本机关已于[前次答复日期]作出[文号]答复。本次申请与前次申请内容实质相同，属于重复申请。根据《中华人民共和国政府信息公开条例》第三十六条第（六）项规定，不予重复处理。

### 类型六：不予公开（第36条第（三）项 + 第14/15/16条）
- **模板**：
  - **国家秘密/禁公开/三安全一稳定（第14条第1款）**：
    > 经查，您申请的信息属于依法确定为国家秘密的政府信息（或：属于法律、行政法规禁止公开的政府信息 / 公开后可能危及国家安全、公共安全、经济安全、社会稳定）。根据《中华人民共和国政府信息公开条例》第十四条规定，不予公开。
  - **商业秘密/个人隐私（第15条）**：
    > 经查，您申请的信息涉及[商业秘密/个人隐私]。根据《中华人民共和国政府信息公开条例》第十五条规定，本机关已征求第三方意见，第三方不同意公开且无应当公开之理由，故不予公开。（如因公共利益需公开，应说明理由并依法办理。）
  - **过程性信息（第16条第2款）**：
    > 经查，您申请的信息属于行政机关在履行行政管理职能过程中形成的讨论记录、过程稿、磋商信函、请示报告等过程性信息。根据《中华人民共和国政府信息公开条例》第十六条第二款规定，不予公开。
  - **行政执法案卷信息（第16条第2款）**：
    > 经查，您申请的信息属于行政执法案卷信息。根据《中华人民共和国政府信息公开条例》第十六条第二款规定，不予公开。
  - **党务信息**：
    > 经查，您申请的信息属于党组织制作、形成的信息，不属于《中华人民共和国政府信息公开条例》调整范围，本机关不予处理。建议向[相关党务公开渠道]咨询。

### 类型七：不属于政府信息/咨询事项（第2条）
- **适用情形**：申请内容实质为咨询、提问，或要求行政机关履行职责。
- **模板**：
  > 经查，您申请的内容实质为[咨询事项/履职申请]，不属于《中华人民共和国政府信息公开条例》第二条规定的政府信息。建议您通过政务服务热线（12345）或其他渠道反映。

### 类型八：已移交档案馆
- **适用情形**：信息已依法移交国家档案馆（且已届移交期限）。
- **法律依据**：《中华人民共和国档案法》（2020修订）第15条。
- **模板**：
  > 经查，您申请的信息已于[移交日期]移交至[档案馆名称]，故您申请的信息不是本机关制作保存，无法提供相关信息。根据《中华人民共和国政府信息公开条例》第三十六条第（五）项规定，特此告知。建议您向[档案馆名称]申请或咨询。[档案馆名称]地址：[详细地址]，联系电话：[电话]。
- **注意**：依据《档案法》第15条，**经档案馆同意提前移交的，在移交期限届满前该档案所涉政府信息公开事项仍由原制作/保存单位办理**。因此须先核实是否已届移交期限，再决定由本机关答复还是指引向档案馆。

**无正当理由大量反复申请**：
> 经查，您申请公开政府信息的数量、频次明显超过合理范围。请说明理由；本机关认为理由不合理的，依法不予处理。

## 五、多申请事项的逐项答复格式

当申请人提出多项申请时，须逐项答复，不得遗漏。

### 逐项答复格式
```
经查，现对您申请的上述政府信息，逐项答复如下：

1.第一项“[申请事项1]”。[答复内容]。
2.第二项“[申请事项2]”。[答复内容]。
3.第三项“[申请事项3]”。[答复内容]。
……
```

### 示例
```
1.第一项“前期物业服务合同”。您申请的信息不是本机关制作保存，故无法提供相关信息。根据《中华人民共和国政府信息公开条例》第三十六条第（五）项规定，特此告知。建议您向[属地房地产/住房和城乡建设主管部门]申请或咨询。[地址]、[联系电话]。
2.第二项“[某项目审批原件]”。经查，该信息不属于政府信息公开范围，建议通过[相关渠道]反映。
……
```

### 注意事项
- 每项申请必须编号；每项必须引用原文；每项必须有明确法律依据。
- 同一申请人的多项申请可合并为一份告知书（多个文号），也可分别出具。

## 七、救济途径模板库

> “复议机关”通常为上一级人民政府或本级人民政府；“管辖法院”通常为作出答复的行政机关所在地基层人民法院。**具体以被诉机关、复议机关所在地现行管辖规定为准。**

### 标准模板（适用于本级政府答复）
```
如对本答复有异议，可以在收到本答复之日起60日内向[复议机关]申请行政复议，或者在6个月内向[有管辖权的人民法院]提起行政诉讼。
```

### 复议前置模板
```
如对本答复有异议，可以在收到本答复之日起60日内先向[复议机关]申请行政复议；对行政复议决定有异议的，可以在收到行政复议决定书之日起15日内，依法向[有管辖权的人民法院]提起行政诉讼。
```

### 市级机关模板
```
如对本答复有异议，可以在收到本答复之日起60日内向[上一级人民政府]申请行政复议，或者在6个月内向[有管辖权的人民法院]提起行政诉讼。
```

## 八、工作流程

1. **收案登记**：记录申请人信息、申请日期、申请渠道、申请内容；分配文号。
2. **职责研判**：判断申请事项是否属于本机关制作/保存；确定答复类型；如需征求其他部门意见，发出征求意见函。
3. **部门回复审查**：核实部门回复中关于信息存在性、职责归属的说明；**部门附带材料的处理**——若附带材料并非以受案机关（或其政府办）名义作出、盖章（如事业单位、服务中心、街道等以自身名义形成的备案、证明、说明等），受案机关并无直接附带提供的事由，应将附带材料作为“指引向对应部门”的依据，答复仍按第36条第（五）项作指引告知，不得以“便民”“已实际获取”为由直接附带提供；仅当附带文件以受案机关名义作出、盖章时方可考虑直接提供。
4. **告知书草拟**：按答复类型选模板；填写申请人信息、申请内容、收悉日期、法律依据、答复正文、救济途径；落款并预留日期。
5. **审核签发**：法律顾问审查合法性；负责人审核；正式印发并补填日期。

## 九、注意事项

1. **答复期限**：依《条例》第33条，能当场答复的当场答复；不能当场答复的，自收到申请之日起20个工作日内予以答复；需延长的，经政府信息公开工作机构负责人同意并告知申请人，延长不超过20个工作日；征求意见时限不计算在内。
2. **文号管理**：文号连续使用，不得跳号、重号。
3. **送达与证据**：邮寄送达的保留送达回证；当面送达的需签收；电子渠道保留受理/答复记录。
4. **档案留存**：告知书副本、申请表、征求意见函、部门回复等材料归档保存。
5. **便民与合法并重**：在合法前提下尽量提供便利，但不得为便利而违法（如越权提供非本机关制作/保存的文件、突破不予公开底线）。
6. **时效与核验**：法条、司法解释会修订废止，引用前核验当前有效版本；属地规范性文件（价格、物业、征地等）按受案机关所在地现行规定执行。

## 十一、常见错误（反模式）与 FAQ

### 常见错误
1. **不区分“申请性质”就答复**：先把信访、投诉、举报、履职等诉求类识别出来依《条例》第39条处理，不要当成信息公开申请硬答。
2. **漏掉程序性文书**：补正（7个工作日内一次性告知）、延期（经批准并告知）、征求第三方意见等程序未做，直接答复容易程序违法。
3. **“信息不存在”不说明检索**：应说明已认真检索；未制作/获取、超期销毁、资料灭失等客观无法提供的，按第36条第（四）项处理。
4. **引错“条/款/项”**：引用条文与处理决定须一致，区分第36条第（一）至（七）项、第14/15/16条等。
5. **文号混乱**：实体处理用“依复〔20XX〕第X号”，程序处理用“依告〔20XX〕第X号”，连续、不跳号重号。
6. **一律套用同一模板**：应区分“予以公开/不予公开/无法提供/不予处理”，以及“部分公开/区分处理”。
7. **以“便民”越权提供**：非本机关名义制作/盖章的文件（事业单位、街道以自身名义形成的备案/证明），不得直接附带提供，应指引。
8. **把地方规定当全国通用**：属地性规则（部门、文号、联系方式、物业/征地口径）按受案机关所在地现行规定。
9. **引用已废止/失效法条**：法释〔2011〕17号已废止（由法释〔2025〕8号取代）；《物业服务企业资质管理办法》（建设部令第164号）已废止。
10. **对已移交档案馆不区分期限**：提前移交且未届移交期限的，仍由原单位办理（《档案法》第15条）。

### FAQ
| 问题 | 依据/指引 |
|------|----------|
| 答复期限多长？ | 20个工作日；经批准可延期≤20个工作日并告知；征求第三方/其他机关意见时间不计入（《条例》第33条）。 |
| 申请内容不明确怎么办？ | 依第30条，7个工作日内一次性告知补正事项、合理期限（一般≤15个工作日）、拒绝后果；逾期不补正视同放弃。 |
| 涉及第三方权益？ | 依第32条征求第三方意见，视回复决定公开/不公开/区分处理。 |
| 信息非本机关掌握但能确定机关？ | 依第36条第（五）项指引，并提供机关名称、联系方式。 |
| 是信访/举报/投诉？ | 依第39条第1款，不作为政府信息公开申请处理，建议通过相应渠道。 |
| 申请人要求确认或重新出具已获取信息？ | 一般不予处理。 |
| 没有现成信息需加工分析？ | 依第38条，可不予提供，也可视难易提供。 |
| 党务信息怎么答？ | `适用《中国共产党党务公开条例（试行）》，本机关不予公开，特此告知`；已获取且可公开的可便民提供。 |
| 文号怎么编？ | 实体处理用“依复〔20XX〕第X号”，程序处理用“依告〔20XX〕第X号”。 |
| 何时不适用本技能？ | 仅特殊涉密、需专门保密审查的申请（超出日常答复范围）。其余情形由技能判断并分类处理。 |

### 实例走查（完整演示：输入 → 交互 → 输出）
**① 申请情况（用户提供）**：某申请人对〔某市某区〕政府办（被指定为政府信息公开工作机构）申请公开“〔某小区〕前期物业服务合同”。申请人通过在线渠道提交，收悉日期〔XXXX年X月X日〕。

**② 交互确认（起草前先问）**：
- “该申请是政府信息公开申请吗？是否属信访/投诉/履职？” → 属信息公开申请。
- “是否已检索、有无部门回复？该合同由谁备案/制作？” → 已检索，〔属地〕住建部门复函确认合同由其备案、本机关未制作保存。
- “是否需要征求第三方意见？” → 不涉及。
- “以谁名义落款、文号用依复还是依告？” → 本机关（政府办）名义，实体处理用“依复”。
- → 关键事实已确认，起草。

## 十二、与审查技能的配套使用

本技能（`gov-info-disclosure-response`）用于**生成**告知书，配套技能 `gov-info-disclosure-review` 用于**审查**告知书合法性。建议流程：
1. 使用本技能草拟告知书。
2. 提交法律顾问使用 `gov-info-disclosure-review` 进行合法性审查。
3. 根据审查意见修改完善。
4. 正式签发。
