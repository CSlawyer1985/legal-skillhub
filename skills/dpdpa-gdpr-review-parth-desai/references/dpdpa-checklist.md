# DPDPA 2023——条款检查清单

《2023 年数字个人数据保护法》（印度）。自通知日期起施行。
主要执法机构：印度数据保护委员会（DPBI）。

---

## §6——通知（同意请求）

**通知中的必需要素：**
- [ ] 数据受托人（Data Fiduciary）的身份
- [ ] 拟收集的个人数据类别
- [ ] 处理目的，以清晰平实的语言说明
- [ ] 如何撤回同意（必须与给予同意同样容易）
- [ ] 如何行使权利（§11–§14）
- [ ] 申诉官（Grievance Officer）的联系方式

**可疑模式：**
- 目的含糊：“用于商业目的”“为改进服务”——标记为 ⚠️
- 捆绑同意（同意与服务使用挂钩，无退出选择）——标记为 🔴
- 未说明撤回机制——标记为 🔴

---

## §7——合法使用（无需同意的处理）

仅在以下情形下无需同意即合法：
- 国家 / 政府职能
- 遵守法律或法院命令
- 医疗紧急情况 / 流行病
- 就业相关必要性（有限）
- 依法进行的合并 / 收购

**可疑模式：**
- 商业实体对常规处理主张 §7——标记为 🔴
- 在 DPDPA 语境中使用“合法利益”（GDPR 概念）措辞——标记为 ⚠️（不是有效的 DPDPA 依据）

---

## §8——数据受托人的义务

### §8(1)——准确性
- [ ] 必须确保数据对其目的而言准确且完整

### §8(2)–(3)——数据处理者
- [ ] 需要与数据处理者（Data Processor）订立书面合同
- [ ] 处理者只能按受托人的指示行事
- 可疑：处理者合同缺失或处理者被赋予酌量数据使用权——🔴

### §8(5)——安全保障
- [ ] 必须描述或引用合理的安全措施
- 可疑：无安全条款 / 仅笼统提及而无具体内容——⚠️

### §8(6)——泄露通知
- [ ] 必须就泄露通知 DPBI 和受影响的数据主体（Data Principal）
- [ ] 该法未规定明确时限（规则将予规定）——规则通知后核查
- 可疑：通知仅限于“重大”或“显著”泄露——⚠️

### §8(7)——保留 / 删除
- [ ] 目的达成或同意撤回时必须删除数据
- [ ] 必须规定保留期限（或引用适用法律）
- 可疑：“我们按需要保留”而未界定期限——⚠️
- 可疑：无删除机制——🔴

### §8(10)——申诉官
- [ ] 必须公布/提供申诉官的联系方式
- [ ] 必须在规定期限内（规则将予规定）回应投诉

---

## §9——儿童数据

**最高风险等级。立即标记。**
- [ ] 18 岁以下儿童需要可核验的父母/监护人同意
- [ ] 不得对儿童进行行为跟踪 / 定向广告
- [ ] 不得进行损害儿童福祉的处理
- 可疑：年龄门槛纯属自我声明（复选框）——🔴
- 可疑：任何未排除 18 岁以下人群的画像或定向广告条款——🔴

---

## §11——获取信息的权利
- [ ] 数据主体可请求：处理类别、共享的实体、处理摘要

## §12——更正与删除的权利
- [ ] 更正不准确数据的机制
- [ ] 撤回同意后删除数据的机制

## §13——申诉救济的权利
- [ ] 向受托人投诉的机制
- [ ] 未解决时升级至 DPBI

## §14——指定他人的权利
- [ ] 数据主体可指定他人在其死亡/无行为能力时行使权利

---

## §16——跨境转移

- [ ] 仅可向中央政府批准白名单上的国家转移
- [ ] 不得向黑名单国家转移
- 可疑：无管辖限制的一揽子全球转移条款——⚠️
- 可疑：向尚未列入批准清单的国家转移——⚠️（标记为待规则通知）

---

## 重要数据受托人（SDF）义务

如实体可能被指定为 SDF（高数据量 / 敏感数据）：
- [ ] 任命数据保护官（DPO）
- [ ] 定期进行数据保护影响评估（DPIA）
- [ ] 由独立审计员定期审计
- [ ] 不得对儿童进行画像

---

## 敏感个人数据（SPD）——加强审查

任何涉及以下内容的条款 = 自动高风险：
- 健康 / 医疗数据
- 财务数据
- 生物特征数据
- 种姓或部落
- 宗教或政治信仰
- 性取向

检查：是否单独取得明确同意？目的是否界定狭窄？
