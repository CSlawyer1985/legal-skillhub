# AI合规文档生成助手（AI Compliance Docs）

> 专业AI合规文档生成工具，覆盖算法备案、数据安全、个人信息保护、AI伦理等20+类合规场景

## 核心价值

AI企业面临算法备案、数据安全、个人信息保护、AI伦理等多重合规要求，合规文档编写耗时耗力且容易遗漏关键点。AI合规文档生成助手提供标准化、智能化的文档生成服务，覆盖20+类合规场景，帮助企业快速建立合规体系，降低合规成本和风险。

## 核心能力

### 1. 20+类合规文档全覆盖
- **算法合规类**：算法备案申请表、算法机理说明、算法安全评估报告、生成式AI服务备案材料
- **数据安全类**：数据安全风险评估报告、数据分类分级方案、数据安全管理制度、数据出境安全评估报告
- **个人信息保护类**：PIA/DPIA评估报告、隐私政策与用户协议、个人信息收集使用清单、用户权利保障机制说明
- **网络安全类**：等保2.0测评准备材料、网络安全等级保护备案表、安全管理制度文档集、应急响应预案
- **AI伦理类**：AI伦理审查报告、公平性与偏见评估报告、透明度与可解释性说明、人工干预机制设计文档

### 2. 智能风险识别
自动识别业务场景中的合规风险点，基于行业最佳实践进行风险分级，提供高风险项优先整改建议。

### 3. 法规全覆盖
覆盖《生成式人工智能服务管理暂行办法》《网络安全法》《数据安全法》《个人信息保护法》《网络安全等级保护条例》《互联网信息服务算法推荐管理规定》《互联网信息服务深度合成管理规定》《人工智能法》（草案）等8部核心法规。

### 4. 独立模式（离线降级）
支持网络受限环境下的离线文档生成，内置法规知识库覆盖核心法规要点，确保合规文档生成能力不中断。

## 快速上手指南

### 五步生成合规文档

**第1步：选择文档类型**
- 从20+类合规文档中选择需要生成的文档类型（如PIA/DPIA报告、算法备案申请表、隐私政策等）

**第2步：回答关键问题**
- 提供产品名称、企业名称、用户规模、数据类型、核心功能、技术架构等基本信息
- 信息越详细，生成的文档越贴合实际业务

**第3步：自动生成初稿**
- 工具基于法规要求和行业最佳实践，自动生成标准化合规文档初稿

**第4步：人工审核调整**
- 安排熟悉业务的人员和合规/法务人员审核
- 对照实际业务逐条核对修改，确保"文实相符"

**第5步：导出使用**
- 导出为Markdown/Word格式
- 经企业内部审批流程确认后正式使用

## 使用场景示例

### 场景1：新产品上线合规评审
AI产品上线前，一键生成所需的全部合规文档（PIA报告、隐私政策、安全评估报告等），确保通过法务和安全评审。

### 场景2：算法备案材料准备
按照网信办要求，自动生成算法备案所需的全套材料（申请表、机理说明、安全评估报告），节省大量人工编写时间。

### 场景3：等保测评准备
快速生成等保2.0测评所需的全套管理和技术文档（安全管理制度汇编、应急预案等），加速测评进程。

### 场景4：隐私政策生成
根据产品功能和数据收集情况，自动生成合规的隐私政策和用户协议，涵盖数据收集、使用、共享、用户权利等完整内容。

### 场景5：合规体系建设
为企业提供完整的AI合规管理体系建设方案和制度模板，从核心文档逐步扩展到完整合规体系。
