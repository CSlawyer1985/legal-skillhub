# 排障指南（TROUBLESHOOTING）

本文档帮助您快速定位和解决使用AI合规文档生成助手时遇到的常见问题。

## 错误码速查表

| 错误码 | 错误名称 | 触发场景 | 解决方案 |
|--------|---------|---------|---------|
| ACD-E001 | 项目信息为空 | 未提供任何项目/产品信息 | 提供产品/项目的基本信息（名称、类型、规模等） |
| ACD-E002 | 输入信息过少 | 仅提供产品名称等极少信息 | 补充更多业务细节（数据类型、用户规模、核心功能等） |
| ACD-E003 | 输入信息过载 | 提供的信息过于庞杂 | 按"产品信息-数据处理-技术架构"结构组织信息 |
| ACD-E004 | 信息结构混乱 | 输入零散、逻辑不清 | 按结构化方式重新组织信息后提交 |
| ACD-E005 | 法规条款存疑 | 某合规要求存在多种解读 | 参考保守方案与宽松方案，咨询专业律师确认 |
| ACD-E006 | 法规要求不明 | 法规要求不明确或存在争议 | 标注"建议咨询专业律师或监管部门确认" |
| ACD-E007 | 风险评估不确定 | 风险评估把握不大 | 给出风险等级范围而非确定值，结合实际评估 |
| ACD-E008 | 离线模式法规过期 | 独立模式下法规库截止日期过旧 | 联网后重新生成，核实最新法规要求 |
| ACD-E009 | 多次生成结果不一致 | 同一需求多次生成结果有差异 | 比较多份文档差异，择优选用，关键点以法规文本为准 |
| ACD-E010 | 行业特殊要求未覆盖 | 强监管行业特殊要求超出模板范围 | 结合行业监管要求人工补充调整 |

## 常见问题排查

### 问题1：生成的文档太通用，不贴合实际业务

**现象**：生成的合规文档内容空泛，与实际业务关联度低。

**原因**：提供的业务信息不够详细，工具只能用通用模板填充。

**解决方案**：
1. 提供详细的业务信息：产品名称、企业主体、用户规模、数据类型和范围、核心功能描述、技术架构
2. 不同文档类型需要的信息深度不同：隐私政策需要详细数据收集清单，DPIA需要全链路数据处理说明，算法备案需要算法原理
3. 信息越详细，文档越贴合实际

### 问题2：文档内容与法规要求有出入

**现象**：生成的文档中某些条款与最新法规要求不一致。

**原因**：法规更新存在滞后性（通常1-3个月），最新出台的法规可能未完全覆盖。

**解决方案**：
1. 以官方最新发布的法规文本为准
2. 生成后由法务/合规人员对照最新法规逐条核实
3. 对于跨境数据传输等复杂场景，建议咨询专业律师

### 问题3：多次生成同一类型文档结果不同

**现象**：同一需求多次生成，文档内容有差异。

**原因**：合规文档有多种合理表达方式，AI生成具有随机性。

**解决方案**：
1. 比较几份文档的差异点，选择最适合自己业务的版本
2. 把几份文档的优点整合，形成更完善的终稿
3. 关键合规点如果有矛盾，以正式法规文本为准
4. 对于重要的正式文档，建议多次生成、交叉对比、择优选用

### 问题4：风险识别不全面

**现象**：生成的风险评估报告中遗漏了部分风险点。

**原因**：风险识别准确率取决于业务信息提供的详细程度，信息不充分时约70%-80%的常见风险可被识别。

**解决方案**：
1. 提供更完整的业务信息和数据处理活动说明
2. 说明行业属性，增加对应行业的特殊合规要点
3. 生成后由专业人员补充审查
4. 强监管行业（金融、医疗等）需额外补充行业特定合规要求

### 问题5：行业特殊要求未覆盖

**现象**：生成的文档缺少特定行业的合规要求（如金融、医疗等）。

**原因**：通用模板覆盖基础合规要求，强监管行业有特殊监管要求。

**解决方案**：
1. 生成时明确说明行业属性
2. 生成后结合行业监管要求人工补充
3. 参考《个人金融信息保护技术规范》《健康医疗数据安全指南》等行业标准
4. 建议咨询行业合规专家进行定制化调整

### 问题6：离线模式生成的文档法规滞后

**现象**：独立模式下生成的文档引用了过期的法规条款。

**原因**：离线法规库截止日期较早，无法获取最新法规更新。

**解决方案**：
1. 联网后重新生成文档，获取最新法规要点
2. 手动核实文档中引用的法规条款是否仍然有效
3. 关注国务院、网信办等官方渠道的法规更新公告
4. 对于正式提交的文档，务必在联网模式下生成并经人工审核

## 文档质量提升建议

1. **提供详细业务信息**：信息越详细，文档越贴合实际，避免空模板
2. **生成后必须人工审核**：对照实际业务逐条核对修改，确保"文实相符"
3. **从核心文档开始**：先做隐私政策、数据分类分级、安全管理制度，再逐步扩展
4. **建立定期更新机制**：至少每半年review一次，重大变更后立即更新
5. **保存合规证据**：安全评估有报告、权限变更有审批、培训有签到，做到"有迹可循"
6. **重大问题找专业人士**：跨境传输、重大风险应对等复杂场景务必咨询专业律师
