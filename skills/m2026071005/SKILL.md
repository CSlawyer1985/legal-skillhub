  ## 四、执行流程

  ### 第0步：信息完整性与状态校验
  1. 名称归一化：若为简称，先 WebSearch 获取工商注册全称；集团名（如"华为""中兴"）须追问确认具体主体（如"华为技术有限公司"还是"华为终端有限公司"），避免张冠李戴。
  2. 参数确认：取默认值或用户指定值。
  3. **企业存续状态检查**：
     - 若已注销/吊销/进入破产程序 → 报告开头醒目标注，策略转为"历史合规回溯"而非"当前风险评估"。
     - 若处于经营异常名录 → 标注并纳入风险因子。
  4. 模式告知：report_depth=quick 时，先告知用户将执行快速筛查（仅4模块），省略推演分析；可后续追加 deep 查询。

  ### 第1步：实体信息检索
  WebSearch：`"{企业全称}" 工商信息 统一社会信用代码 法定代表人`，记录：统一信用代码、法定代表人、第一大股东名称、所属行业（用于风险校准）。完整股权结构（前5股东持股、全部子公司）需企查查/天眼查核实，本技能不做完整穿透；penetrate_related=true 时仅对法定代表人和第一大股东执行后续搜索。

  ### 第2步：KB 法律依据预加载
  在搜索企业负面事件前，先从 KB 检索标尺（示例）：
  - 废标/投标无效法定情形 → KB-A "废标 投标无效 法定情形"
  - 围标串标认定方式 → KB-B "围标串标 认定 方式"
  - 虚假材料法律后果 → KB-A "虚假材料 法律责任 处罚"
  - 行政处罚与黑名单 → KB-A "行政处罚 黑名单 禁入期限"
  - 投诉处理 → KB-A "投诉处理 决定书 质疑"
  - 串通投标刑事 → KB-B "串通投标 刑事 法律责任"
  将检索到的法律条文（含条目号）与认定标准记录备用，供后续甄别直接引用。

  ### 第2.5步：建立【法律标尺暂存区】（防遗忘）
  将第2步核心法条提取为 ≤3 条高亮摘要，格式：
  ```
  [法条1] 《政府采购法》第七十七条第一款：提供虚假材料 → 罚款+列入不良记录+1-3年禁入 [KB-A]
  [法条2] 《招标投标法》第五十三条：串通投标 → 中标无效+罚款+吊销资质 [KB-B]
  [法条3] …
  ```
  后续第4-6步引用法律依据**必须**从此暂存区调用，严禁凭空捏造条款号；若暂存区无法覆盖当前事件，标注"需人工补充法条"。

  ### 第3步：官方渠道关键词搜索（熔断 + 容错）
  - **策略**：`"{企业全称}" {单一关键词}` 独立搜索（勿 OR 堆叠，否则返回普法文章而非企业事件）。
  - **轮次**（每轮独立搜索）：
    1. 废标/流标：`…废标`→`…流标`→`…投标无效`
    2. 投诉与争议：`…投诉处理`→`…质疑答复`
    3. 行政处罚：`…行政处罚`→`…黑名单`→`…失信`
    4. 严重红线：`…围标`→`…串标`→`…虚假材料`
    5. 警示函（include_warning_letter=true）：`…警示函`→`…监管关注`
    6. 关联方穿透（penetrate_related=true）：对法代与第一大股东分别执行轮次1-4
  - **搜索资源熔断**：单次执行 WebSearch ≤25 次、WebFetch ≤8 次。接近上限时优先保留"围标串标/虚假材料/行政处罚"高权重维度，裁剪"一般性废标/正常未中标"维度。报告元数据须如实标注"本次检索共 N 次搜索，因资源限制裁剪 X 个维度"。
  - **科普文章过滤（标题+摘要联合判断）**：读取搜索结果的 title 与 snippet——
    - 标题含"《…》解读/律师观点/普法课堂/培训课件"且摘要未出现目标企业全称 → 判定为科普文章，丢弃。
    - 标题含"行政处罚决定书/投诉处理决定/废标公告/黑名单公告" → 视为有效证据，即使 URL 含 law 字符也保留。
    - 自媒体爆料/匿名帖/竞争对手单方投诉 → 过滤，并在报告末注明过滤数量。
  - **信源优先级**：中国政府采购网 > 各省市公共资源交易中心 > 信用中国 > 国家企业信用信息公示系统 > 各级财政部门/行业主管部门官网。
  - 对疑似负面信息用 WebFetch 核实，**记录检索时间戳**。

  ### 第4步：法律事实甄别与证据分级
  每条负面事件须同时满足以下三项方可纳入报告，否则过滤丢弃：
  - **通报主体明确**：有具体的官方通报机构名称（如"XX市财政局"）。
  - **违规描述具体**：有具体的违规行为描述及对应法律依据或规章条款。
  - **信源可回溯**：有公告编号或可直接访问的 URL。

  **角色甄别（关键，直接影响定级）**：
  - 被投诉方（被他人投诉）→ 计入负面；投诉成立（认定违规）→ 计入，不成立/驳回 → 不计入。
  - 投诉方（主动投诉他人）→ 不计入（正当维权）。
  - 废标类型：因自身原因（资质不符/材料虚假）→ 计入；因采购人/招标人原因流标或正常未中标 → 不计入。

  **证据可信度分级（分级容错）**：
  | 等级 | 标准 |
  |:---:|:---|
  | A级 | WebFetch 返回 200，页面正文含处罚文号 → 直接采信 |
  | A-级（新增） | WebFetch 返回 403/超时，但搜索摘要同时含"政府域名+完整文号+处罚机构+日期" → 视为有效，标注"官方页面反爬限制，基于搜索摘要采信，建议人工复核" |
  | B级 | 官方搜索结果摘要含文号但信息不完整 → 采信但标注"待补全" |
  | C级 | 仅媒体转载、无官方文号 → 过滤，不计入事件清单 |
  | 过滤 | 自媒体爆料/匿名帖/竞争对手单方投诉/无法交叉验证 → 丢弃并计过滤数 |

  > 说明：中国政府采购网、信用中国等官方站点常反爬/动态加载，WebFetch 返回 403/超时属常态，不得因此将真实处罚降级为 C 级或丢弃。

  ### 第5步：违规模式分析（仅 deep 输出，quick 跳过）
  - 反复性违规（同一错误多次）→ 推断内控制度缺失。
  - 跨项目模式（多项目同理由）→ 指向标书团队能力不足。
  - 升级性违规（轻度→严重）→ 风险恶化信号。
  - 关联方传染（母公司/控股股东严重失信）→ 分析传导可能。
  所有推演加【推演】前缀。deep 模式下【推演】总字数 ≤200 字。

  ### 第6步：风险定级（定性时序 + 数量权重）
  | 等级 | 判定标准 |
  |:---:|:---|
  | 高危 | 存在围标串标/虚假材料/行贿等红线行为；或处于政府采购禁入期内；或同等级事件反复≥3次 |
  | 中危 | 存在非红线行政处罚；或反复性违规2次；或关联方中等风险传导 |
  | 低危 | 仅有废标/流标且无处罚；或仅程序性瑕疵（格式不规范） |
  | 无异常 | 监测期内未发现官方通报负面事件 |

  **定性时序规则（替代浮点运算）**：
  - 近 6 个月内负面事件 → 定级时"升格一级"（如原低危在6月内视同中危影响）。
  - 12 个月以前历史事件且当前未复发 → "降格一级"。
  - 红线行为 → 不受任何时序规则影响，恒定高危。
  - 禁入期仍执行中的处罚 → 即使发生在监测期外，仍按原等级纳入。
  - **数量权重**：同等级事件 ≥3 条 → 上调一级。

  **综合定级算法**：
  1. 取所有事件中的最高单条等级作为基准。
  2. 近 6 月内 ≥2 条同等级事件，或同等级事件 ≥3 条 → 上调一级。
  3. 全部事件均超 12 月且无近期复发 → 下调一级。
  4. 红线行为恒定高危，不衰减。

  **监测期与超期处理**：
  - 监测期 = time_range 月数，从当前日期向前回溯。
  - 红线行为超监测期仍须纳入，标注"[超期红线]"，不衰减。
  - 非红线事件超监测期不纳入清单，可在拓展分析简要提及。
  - 行政处罚禁入期仍执行中，即使超监测期仍纳入并标注当前禁入状态。
  - 全部非红线事件超监测期且无红线 → 定级"无异常"，注明"监测期内未发现，历史存在 N 条超期事件（见拓展分析）"。
  - 同时检查：是否处于禁入期及剩余时长；合规趋势（改善/恶化/波动/高危稳定）。

  ### 第7步：合作建议与动态监控
  按风险等级给建议；处于禁入期直接"不推荐引入"，不展开。
  - **高危**：建议排除；特殊情况须签高额合规保证金（建议≥合同额20%）、设单方解除权、要求第三方审计整改报告。监控：新增任何负面 → 立即终止合作评估。
  - **中危**：要求每起事件书面澄清；合同增"再犯同类违规视为根本违约"条款；持续监控。监控：新增1起行政处罚 → 预警；列入经营异常 → 72h复查。
  - **低危/无异常**：保留常规合规承诺与履约保证金；建议季度复扫。监控：新增1起废标 → 季度复查纳入。

  ## 五、输出格式（quick / deep 互斥分支）

  **报告元数据（置顶，所有模式均输出）**：
  - 生成时间、检索时间窗口（time_range）、搜索维度覆盖数、KB 版本、总搜索次数、是否裁剪维度。
  - 执行摘要模块末尾嵌入一行免责："本报告基于公开信息自动生成，不构成法律意见，重大决策请咨询专业律师。"

  **若 report_depth == "quick"**：仅输出以下 4 个模块，严禁输出其余内容：
  ① 执行摘要（含风险定级） ② 负面事件清单（表格） ③ 黑名单状态 ④ 合作建议（3条以内）
  其余模块标注"[快速模式省略，可追加 deep 查询]"。

  **若 report_depth == "deep"**：输出全部 6 个模块：
  一、负面异动事件清单 二、关联方穿透风险 三、违规模式与内控缺陷分析 四、黑名单与禁入状态 五、合作建议与动态监控 六、拓展分析
  其中：第③模块【推演】总字数 ≤200 字；第⑥模块仅在发现 ≥2 条同类型事件时生成，否则标注"样本不足，暂不推演"。

  ### 执行摘要
  3-5 行核心结论：
  - 风险等级 + 一句话核心判断
  - 最严重事件概要（时间+类型+机构）
  - 禁入状态 + 关联方风险概况
  - 核心建议（一句话）
  - 格式示例：`【中危】近12个月发现2起负面事件，最严重为非红线行政处罚。当前未处于禁入期，关联方未发现违规。建议要求企业提交整改证明后推进合作。`

  ### 【风险定级结论】
  格式：【高危/中危/低危/无异常】— 核心判断依据（不超过60字，含违规次数、最严重事件类型、是否处于禁入期、合规趋势）。

  ### 一、负面异动事件清单
  | 时间 | 项目/采购单位 | 事件类型 | 违规行为描述 | 法律依据 | 通报机构 | 证据等级 | 严重等级 |
  |------|--------------|----------|-------------|----------|----------|----------|----------|
  按时间倒序排列。若无，填写"**在监测期内未发现官方通报的负面招投标事件。**"
  过滤说明：已过滤X条无法查证的自媒体传闻或竞争对手质疑。
  （信源编号/URL 以脚注形式标注在表格下方，避免移动端过宽）

  ### 二、关联方穿透风险（penetrate_related=true 时）
  列出法代与第一大股东在监测期内招投标违规记录；无发现标注"穿透查询未发现关联方违规"；存在关联违规以文字描述结构及传导路径。完整股权穿透需企查查等平台核实。

  ### 三、违规模式与内控缺陷分析（deep）
  - **事件关联分析**：重复性违规？跨项目相同错误模式？
  - **内控缺陷推断**：【推演】依据违规特征推断招投标内控薄弱环节。
  - **红线触碰评估**：是否涉及围标串标/虚假材料/行贿。若涉及，引用具体条款（须含条目号，注明来源为 KB-A/KB-B 检索结果）。
  - **同类案例参照**：【推演】KB 中是否有类似投诉处理决定书，情节相较更重或更轻？
  - **长期合规趋势**：改善/恶化/波动/高危稳定。

  ### 四、黑名单与禁入状态
  - 当前黑名单状态（是否列于严重违法失信行为记录名单）
  - 禁入期限（起止日期、剩余时长）、禁入范围（全国/地区/行业）
  - 影响评估：对企业获取政府订单能力的实质影响

  ### 五、合作建议与动态监控
  按第五.七步风险等级输出对应建议与监控触发条件（见第7步）。

  ### 六、拓展分析（deep，≥2条同类型事件时）
  可补充：行政复议及处罚撤销记录、违规后高管变更、媒体报道声誉影响、同行业横向对比、超期非红线事件简述等。

  ## 六、失败处理

  | 场景 | 处理方式 | 用户提示 |
  |:---|:---|:---|
  | 搜索无结果 | 明确告知"在{time_range}个月内未检索到相关公开信息" | "公开合规记录良好，建议持续关注。可尝试扩大 time_range 至24个月深度回溯。" |
  | 结果全是法律科普文章 | 标记该维度"未检索到有效企业事件"，继续下一轮 | "部分维度以法规解读文章为主，未发现企业实际负面事件，已按过滤规则处理。" |
  | 投诉方/被投诉方角色不明 | 标注"角色待确认"，不计入负面计数，拓展分析提及 | "检索到 N 条投诉相关记录，企业系投诉方还是被投诉方尚不明确，建议人工核实。" |
  | 企业名称歧义 | 列出候选列表请用户确认，不可自行假定 | "搜索到以下 N 个匹配主体，请确认要审查哪一个：[列表]" |
  | 官方页面无法访问 | 注明"截至检索日期该页面无法访问"，按 A-级记录时间戳 | "该公告原始页面暂时无法访问，已基于搜索摘要信息分析，建议稍后人工核实。" |
  | 信息量过大 | 优先报告近12月事件及最严重3条历史事件，其余摘要 | "监测期内共发现 N 条记录，已按时序权重筛选最关键 M 条，完整列表可要求展开。" |
  | KB 检索无结果 | 标注"知识库未收录相关法规/案例" | "法条引用基于模型内置知识，建议人工核实条款准确性。" |
  | KB 工具不可用 | 降级纯 WebSearch | "知识库检索服务暂不可用，本次基于网络公开信息，法律条款未经知识库验证。" |
  | 企业名称无法归一化 | 追问更多识别信息 | "未能确定'{名称}'对应的工商主体，请提供企业全称或统一社会信用代码。" |
  | 企业已注销/吊销/破产 | 报告开头标注，策略转历史回溯 | "该企业已注销/吊销，本次按历史合规回溯呈现，不代表当前经营风险。" |
