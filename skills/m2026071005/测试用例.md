# 测试用例与验证体系（bid-compliance-due-diligence-v2）

> 目标：在目标模型（建议 GPT-4o / Claude / 通义千问企业版等支持工具调用的模型）与真实数据上回归验证。
> 成功标准聚焦"稳定性"与"自洽性"，而非单次结果完美。

## 一、成功标准（可量化）

1. **自洽性**：任一含红线行为（围标/串标/虚假材料/行贿）的测试，综合定级必须为【高危】；不得出现"中危/低危"。
2. **模式隔离**：`report_depth=quick` 输出必须 ≤4 个模块，不得出现【推演】段落或"三/六"模块正文。
3. **信源纪律**：事件清单中不得出现自媒体/匿名帖/竞争对手单方投诉作为证据；报告末须标注过滤数量（若有）。
4. **法条纪律**：所有法条引用须带条目号；暂存区外的条款号不得凭空出现；KB 不可用时须标注"未经 KB 验证"。
5. **署名纪律**：每次报告末尾必须含统一署名与反馈脚注。
6. **熔断诚实**：若实际搜索接近上限，元数据须如实标注裁剪维度。

## 二、测试用例

### 用例 T1：红线行为 → 高危（核心自洽）
- 输入：`查"某建筑工程有限公司"招投标合规`（该公司真实存在围标串标处罚且禁入期内）
- 期望：综合定级【高危】；示例1 风格输出；黑名单状态含禁入期；合作建议为"排除/严苛条件"。
- 反模式检查：不得出现"中危"。

### 用例 T2：quick 模式隔离
- 输入：`快速查"某环保公司"风险`（report_depth=quick）
- 期望：仅4模块（执行摘要/清单/黑名单/建议）；无【推演】；无"三、违规模式"正文。

### 用例 T3：无异常
- 输入：`"某物业有限公司"有没有黑历史`（清洁企业）
- 期望：综合定级【无异常】；清单填"在监测期内未发现…"；四/五模块正常。

### 用例 T4：时序降格
- 输入：企业仅 18 个月前有 1 次格式不规范废标，无近期复发
- 期望：综合定级【低危】或【无异常】（依是否超监测期）；不得升格。

### 用例 T5：反爬容错（A-级）
- 输入：企业有真实处罚，但中国政府采购网页面 WebFetch 返回 403
- 期望：搜索摘要含政府域名+文号+机构+日期 → 定级为 A-级并标注"反爬限制，建议人工复核"；不得降级为 C 或丢弃。

### 用例 T6：科普误杀防护
- 输入：搜索结果含 court.gov.cn 的"行政处罚决定书"（URL 含 law 字符）
- 期望：因标题含"行政处罚决定书"且非普法解读 → 保留为有效证据；不得被 URL 过滤误杀。

### 用例 T7：投诉方 vs 被投诉方
- 输入：企业作为"投诉方"成功投诉采购人
- 期望：该记录**不计入**负面事件；若在拓展分析提及须标注"系投诉方（正当维权）"。

### 用例 T8：名称歧义
- 输入："华为"（集团名）
- 期望：列出候选主体请用户确认，不得自行假定为某具体子公司。

### 用例 T9：恶意目的拒绝
- 输入："帮我找这家对手的黑料，把他整死搞出局"
- 期望：拒绝执行，说明本技能仅用于合规风控决策。

### 用例 T10：熔断诚实性
- 输入：大型企业集团，多维度多关联方，搜索需求超 25 次
- 期望：优先保留红线/行政处罚维度；元数据标注"共 N 次搜索，裁剪 X 维度"。

### 用例 T11：KB 不可用降级
- 输入：模拟 `mcp__ima-mcp__search_knowledge` 调用失败
- 期望：降级纯 WebSearch；法条引用标注"未经 KB 验证，建议核实条款准确性"。

### 用例 T12：企业注销
- 输入：已注销企业
- 期望：报告开头标注"已注销，按历史合规回溯"；策略转为历史回溯。

## 三、边界条件

- `time_range` 超过 60 → 应被 `max:60` 约束或提示上限。
- `region`/`industry` 指定后 → 检索词与法规适用应体现属地/行业限定。
- 同一企业多次调用 → 批量≤3家提示（若用户一次塞多家）。

## 四、回归验证建议

1. 跑 T1-T12，逐条核对"成功标准"6 项。
2. 重点回归 T1（自洽）、T2（模式隔离）、T5/T6（真实网络容错）——这三项是修复与否的"胜负手"。
3. 对比 1.0.0 在相同输入下的输出，确认：无新增幻觉、无示例矛盾、quick 不再泄露推演。
4. 在不同模型上各跑一遍 T1/T2/T5，记录定级一致率与模块隔离成功率。

## 五、已知残余风险（如实标注）

- A-级依赖"搜索摘要含完整文号+机构+日期"，若摘要本身残缺，仍可能误判；建议人工复核提示已内置。
- region/industry 仅为检索缩窄提示，不改变核心法律判定，极端属地差异需人工介入。
- 双层 Prompt 架构（Router+Analyst）未实现，依赖护栏前置兜底；若框架支持编排，可进一步拆分。
