# 招投标合规风险尽调技能（增强版）bid-compliance-due-diligence-v2

对目标企业进行招投标维度的深度合规审查：检索废标、流标、投诉处理、行政处罚、黑名单、围标串标等负面记录，穿透关联方风险，识别内控缺陷与违规模式，输出结构化风控预警报告。

## 核心能力
- **双轨交叉验证**：IMA 双知识库（政府采购实务与合规 KB-A、招投标实务与合规 KB-B）+ WebSearch/WebFetch 实时检索，法律解释以 KB 为准、企业事件以 Web 为准。
- **两种模式**：`quick` 快速筛查（仅4模块）/ `deep` 深度审计（全6模块）。
- **针对 LLM 推理优化**：
  - 定性时序规则（替代不可靠的浮点加权）
  - 相关性驱动 KB 检索（替代机械截断）
  - 分级容错取证（A / A- / B / C，适配官方站点反爬）
  - 搜索资源熔断（WebSearch≤25 / WebFetch≤8）
  - 法律标尺暂存区（防长上下文遗忘）
  - 宪法级护栏前置（红线恒定高危、事实推演分离、仅采信官方渠道）

## 触发示例
- 查一下这家公司招投标有没有问题、靠不靠谱
- 这家公司有没有被废标过、被处罚过
- 引入供应商前做招投标维度深度尽调

## 参数
| 参数 | 默认 | 说明 |
|---|---|---|
| company_name | 必填 | 企业全称或简称 |
| time_range | 12（≤60） | 回溯月数 |
| region | 全国 | 限定检索地域 |
| industry | 通用 | 限定行业领域 |
| include_warning_letter | true | 含警示函/监管关注 |
| penetrate_related | true | 穿透法代与第一大股东 |
| report_depth | deep | quick / deep |
