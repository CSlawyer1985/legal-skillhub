# 政府采购合规实务参谋（procurement-compliance-advisor）

政府采购法体系合规实务与政策执行专家，覆盖货物、服务及非招标工程。集成智能问答、采购文件审查、案例检索、合规体检、政策功能落实审查、质疑与投诉辅助六大功能，严格优先基于「政府采购实务与合规」知识库作答。

## 功能特性

- **智能问答**：法条依据 → 适用条件（要件拆解） → 实务指引 三段式。
- **采购文件审查**：对照《政府采购法实施条例》第20条逐项排查差别 / 歧视待遇，🔴高 / 🟡中 / 🟢低 三级风险 + 修改建议。
- **案例检索**：财政部指导案例、投诉处理决定、行政处罚公告，结构化输出合规启示。
- **合规体检**：预算→需求→意向→方式→文件→公告→评审→结果→合同→验收→资金 全流程 12 环节对标。
- **政策功能落实审查**：中小企业（货物服务 10%–20% / 工程 3%–5%、预留≥30% 其中小微≥60%）、节能环保、乡村产业振兴、监狱 / 残疾人企业、进口产品审批。
- **质疑与投诉辅助**：质疑 7 工作日、投诉 15 工作日时效分析与材料清单。

## 能力边界

本技能**仅适用于《政府采购法》体系**：

- ✅ 国家机关 / 事业单位 / 团体组织使用财政性资金采购货物、服务，或工程采用非招标方式。
- ❌ 政府采购工程采用**招标方式**、非财政性资金的企业自主采购 → 引导至「招标投标合规实务助手」。
