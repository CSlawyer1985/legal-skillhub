# 非争议解决公共层（NDR）

> ** 强制前置声明** 本技能是 NDR（非诉业务）完整自治标准，覆盖 §§0-16（含§2.6非诉交付物七维标准）。以下 **26 个 NDR 技能**在加载自身前，**必须先加载本技能**
>
> **横向基础（9）** 合同起草 / 合同审查 / 法律尽职调查 / 法律意见书 / 法律研究备忘录 / 合规审查 / 客户法律咨询 / 客户函告 / 律师函
>
> **纵向深度（17）** 重大交易 / 公司治理 / 跨境投资 / 资本市场与证券合规 / 劳动人事 / 数据合规 / 知识产权管理 / 婚姻家庭与继承 / 私募基金设立 / 基金设立法律意见书 / 反垄断 / 税务 / 信托与财富管理 / 建设工程与房地产 / 贸易合规与经济制裁 / 资产管理与资产证券化 / 私募基金投后与退出
>
> **视角** NDR 面向客户/交易对手/监管机构。横向基础技能不限领域提供统一方法论；纵向深度技能提供单一领域的专有分析框架。

**加载协议（全 NDR 技能强制）**：
1. 本技能 SKILL.md 为公共层声明（骨架 + 规则索引），主标准全文在 `references/`；
2. 执行时整读 `references/ndr-standards.md`（面向长上下文模型 ≥256K，默认整读，无需为省窗而分段跳读；仅当素材极端超长时才按 § 定位）；
3. `references/` 下各文件整读后按步骤取用；
4. 版本兼容区仅保留当前生效版，历史版本按需查 `references/CHANGELOG.md`。
