# 主体信息采集清单（NDR 域共享 · ndr-party-info）

> **单一事实来源**：本文件为 NDR 域全部业务技能统一的主体信息采集标准（共享知识层）。业务技能模板引用本文件，不得各自复制副本；技能专属字段本地补充。
> 起草时按场景涉及主体类型逐项采集，缺失字段向用户确认，不得留空。

## 一、通用（全场景）

| 主体类型 | 必填字段 |
|---------|---------|
| 自然人 | 姓名、性别、出生日期、住所地、联系方式 |
| 法人 | 名称（含曾用名）、统一社会信用代码、法定代表人、住所地、电话 |
| 分支机构/分公司 | 名称（含曾用名）、负责人、住所地、统一社会信用代码、电话 |
| 其他组织（合伙企业/个人独资企业/社会团体等） | 名称、负责人（执行事务合伙人/投资人）、住所地、统一社会信用代码（如有） |

## 二、交易/尽调场景（重大交易、法律尽职调查、跨境投资、反垄断申报等）

| 主体类型 | 必填字段 |
|---------|---------|
| 目标公司/标的公司 | 名称（含曾用名）、统一社会信用代码、注册地址、注册资本（实缴/认缴）、股权结构（股东及持股比例）、设立时间 |
| 目标公司股东 | 名称/姓名、持股比例、出资方式、实缴情况 |
| 董监高 | 姓名、职务、任职期限、兼任情况（关联企业任职） |
| 交易相对方 | 名称、住所地、联系方式、履约能力（如适用） |

## 三、函告/意见书场景（客户函告、律师函、法律意见书等）

| 主体类型 | 必填字段 |
|---------|---------|
| 发函方/委托方 | 名称、住所地、联系方式、发函主体形式（客户名义/律所名义） |
| 收函方/致送对象 | 名称、住所地、法定代表人/负责人、送达方式（邮寄/电邮/公证送达） |
| 监管机构（合规/申报场景） | 机构全称、事项类型（申报/备案/答复）、经办窗口（如适用） |

## 四、采集规则

- 文书首部须标注主体角色（委托方/相对方/目标公司/发函方等），与文书类型对应
- 交易类文书须同时采集交易各方完整信息；尽调类须覆盖目标公司及关联方
- 联系方式缺失时标注"待补"，不得留空
- 信息格式与 `ndr-standards.md` §2.1 引用精度及 §7 写作规范保持一致
