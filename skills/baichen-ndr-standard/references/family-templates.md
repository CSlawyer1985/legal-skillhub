# NDR 域族级工作流模板（family-templates）

> **定位**：NDR 23 技能标准流程骨架的族级上浮（刀二轻量版）。各技能 SKILL.md 仅列**差异化步骤**，同构部分遵循此处；规则细则以 `ndr-standards.md` 为准。

## 一、标准流程骨架（全 NDR 技能同构）

| 阶段 | 标准步骤 | 规则出处 |
|---|---|---|
| Phase 0 上下文检测 | 搜索 outputs/*_case_profile.json → 按 type="NDR"+subtype 过滤 → 确认继承或新建 | §4 |
| Phase 1 需求确认 | 确认交付物类型（合同/意见/函件/报告）+ 客户立场 + 上浮判断（横向基础↔纵向深度择技规则 §11） | §11 |
| Phase 2 主体/材料 | 主体信息按 ndr-party-info.md 场景清单采集（⛔ 禁止本地副本）；材料按 §6 多渠道收集 | ndr-party-info.md、§6 |
| Phase 3 法律研究 | **基座前置**：§0 订阅检测 + §1 双源检索 + 法条核验 §2.1.1 三态 + AI 治理（ndr-ai-governance.md）+ 依据时效与程序前置（§7.8） | §0-§1、§7.8 |
| Phase 4 起草/审查 | 按 §2 通用写作规范（含交付物七维标准 §2.6）+ 风险分级 §9（高/中/低统一口径） | §2、§9 |
| Phase 5 交付自检 | §15 质量自检清单 + §15.4 法条状态与依据时效普检 + §16 多轮审核（4轮） | §15-§16 |
| Phase N Profile 回写 | 七元要素映射 + next_actions | §4.5-§4.6 |

## 二、各族差异点速查（技能侧应保留的特有内容）

| 族 | 核心差异 |
|---|---|
| 横向基础（F-N-1/2/5） | 合同七步法/12步审查；咨询五段式；函件八类场景与措辞策略（knowledge-letter.md） |
| 合规族（F-N-3） | 各领域专项框架：劳动六大场景、数据出境四层评估、知产确权双轨、税务四类业务、反垄断申报/合规/调查四模块、贸易合规（出口管制/制裁/海关/执法应对，2026-09-05 新增） |
| 公司与交易（F-N-4） | 尽调 12 章报告结构；交易文件起草；跨境 ODI/FDI 路径（837号令/负面清单）；公司治理章程族谱（2026-09-05 并入） |
| 家事与财富（F-N-7，2 技能） | 家事五大类文书；信托架构（2026-09-05 两族合一） |
| 资产管理（F-N-8，4 技能） | 基金设立七步法+AMBERS 备案；资管产品/ABS/ABN/REITs 结构化融资；投后管理与退出（回购行权/S份额/清算） |
| 单技能族（F-N-10/11） | 证券发行披露链；建工全周期 |

## 三、使用规则

1. 技能通用骨架行可标注"族模板标准步骤"不展开；特有步骤必须保留技能内；
2. 深度去重（技能侧骨架行删除）为下批治理项，本轮仅建立引用机制。
