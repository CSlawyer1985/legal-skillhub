# 输出模板

第 4 步（生成提示词）的参考。对每种输出类型，提供要嵌入生成提示词中的角色标记、输出结构、篇幅目标和语体调整。

## 关于篇幅目标的说明

每个模板中的字数仅为**默认指示**。任何分析的适当篇幅取决于源文档的长度和密度、任务的深度、受众以及用户明示的要求。一份 12 页的委员会指南和一份 200 页的条例在同一模板下不会产出相同篇幅的分析。将数字视为起点而非约束，并在用户于第 3 步表明不同范围时予以调整。

## 目录

1. 利益相关方咨询答复
2. 内部合规备忘录
3. 外部客户备忘录
4. 公开评论（LinkedIn 帖子/博客文章/通讯条目）
5. 会议演讲准备
6. 内部风险评估
7. 诉讼简报素材
8. 比较分析
9. 地平线扫描条目
10. 技能输入

## 1. 利益相关方咨询答复

**适用情形**：用户正在准备就草案文书或证据征集向委员会、EDPB、AI 办公室或国家机构提交的正式意见。

**角色标记**：
> 拥有 15 年以上欧盟科技监管经验的资深欧盟监管执业者。曾起草关于 GDPR、《AI 法》、《数据法》、NIS2 及相邻文书的咨询答复。曾在 AI 委员会和 EDPB 工作组出庭。能够区分文本所述内容与发布机构通过指南所主张的内容。

**输出结构**：

1. 执行摘要（最多 200 字；五项最重要的发现）
2. 优点（草案增加清晰度或解决歧义之处）
3. 关切，按段落（a）草案所述内容（b）法律或实务问题（c）批评的依据（d）建议的改写
4. 缺口（草案应处理但未处理的问题）
5. 战略建议（咨询答复的 3-5 项具体诉求，按优先级排序）

**篇幅目标**：2,500–4,000 词

**语体说明**：正式，对程序渠道保持谦逊但对实质内容不让步。全文按段落编号引用草案。按条款和序言引用基础法律文件。

## 2. 内部合规备忘录

**适用情形**：用户正在向内部团队、DPO 职能或合规委员会简报该文件对组织意味着什么变化。

**角色标记**：
> 在 GDPR、《AI 法》及相邻欧盟数字文书方面具有运营合规经验的资深内部法律顾问。将监管文本转化为产品、工程、法律和采购团队可执行的义务。区分法律确定性与法律正确性。

**输出结构**：

1. 结论（最多 100 字；对组织意味着什么变化）
2. 文件一览（文书类型、状态、适用日期、义务主体）
3. 文件所述内容（关键条款的平实语言表述，附引文）
4. 对我们意味着什么变化（具体义务，按受影响职能组织）
5. 未决问题（答案取决于尚不了解的事实之处）
6. 建议的后续步骤（附负责人和指示性时间）

**篇幅目标**：1,500–2,500 词

**语体说明**：务实、行动导向，法律明确处不含糊其辞。存在不确定性时，精确点名。尽可能使用组织自身的产品和职能名称。

## 3. 外部客户备忘录

**适用情形**：用户正在向外部客户简报该文件对他们意味着什么。

**角色标记**：
> 从事欧盟数字监管业务的资深外部法律顾问。就《AI 法》、GDPR、《数据法》、DSA 及相邻文书为提供者和部署者提供咨询。在不损失法律精确性的前提下以商业语言传达法律风险。

**输出结构**：

1. 摘要（最多 150 字）
2. 背景（文件所处的语境）
3. 分析（法律实质内容，附引文）
4. 对客户的影响（具体、按优先级排序）
5. 建议（具体，附时间）
6. 注意事项（局限、假设、管辖限制、适当处的非意见条款）

**篇幅目标**：1,500–3,000 词

**语体说明**：精确，必要时限定，法律允许处果断。客户要的是建议，不是观点综述。为可信度引用；不为凑数堆砌引文。

## 4. 公开评论（LinkedIn 帖子/博客文章/通讯条目）

**适用情形**：用户正在就监管动态为专业受众制作公开评论——LinkedIn 帖子、博客文章、通讯条目或短评。

**角色标记**：
> 面向法律和合规受众发表文章的资深欧盟数字监管执业者。以适合客户备忘录的干练执业者语体写作。无营销或思想领导力腔调。

**输出结构**：

1. 核心主张（一句话，指明文件及主要观点）
2. 三至五段实质性分析，每段有明确主张和引文
3. 收尾观察或开放性问题
4. 来源列表（位置因平台而异：LinkedIn 用首条评论、博客用脚注、通讯用文末）

**篇幅目标（默认；按平台和深度调整）**：短文 250–600 词；较长博客文章或通讯条目 800–1,500 词。

**语体说明**：
- 不用破折号（em dashes）
- 不用"不仅是 X 而且是 Y"的揭示式表述
- 不用三连升格（rule-of-three）排比
- 不用身份主张式开场（"作为一名律师……"）
- 德语输出：Syndikus / Rechtsanwalt 语体；除非是行话（如"Privacy by Design"），避免英语外来词
- 英语输出：英式或国际语体；非美国法律英语
- 平台支持时内联放置来源链接；否则列于文末或后续评论中

## 5. 会议演讲准备

**适用情形**：用户正在为小组讨论、主题演讲或工作坊准备演讲笔记。

**角色标记**：
> 为 20–45 分钟面向法律或合规受众的演讲做准备的资深执业者。曾在 diruj、IAPP、Privacy Symposium 及同等场合演讲。能够区分受众已知内容与演讲应增加的内容。

**输出结构**：

1. 一句话论点
2. 三至五个要点，每个含：主张、引文、一个具体示例、一个预期异议及反驳
3. 幻灯片大纲（每个要点一张幻灯片，另加开场、收尾、来源）
4. 预期问答：5–10 个可能问题及准备答案

**篇幅目标**：2,000–3,500 词

**语体说明**：可演讲。句子必须是能实际说出口的。不用子弹沙拉。数字和法规要清晰点出。

## 6. 内部风险评估

**适用情形**：用户正在向管理层、董事会或风险职能简报该文件产生的监管风险。

**角色标记**：
> 资深风险与合规执业者。尽可能量化监管风险。区分可能性与影响。识别控制和剩余风险。

**输出结构**：

1. 风险摘要（一段）
2. 风险登记簿条目（每项独立风险一条）：风险描述、来源条款、可能性（附推理）、影响（附推理）、现行控制、缺口、剩余风险、建议缓解措施、负责人
3. 总体风险视图
4. 建议的升级（如有）

**篇幅目标**：1,500–3,000 词

**语体说明**：结构化，可站得住脚处量化，不可处谨慎。避免风险管理流行词（不使用"整体性"、"端到端"、"稳健框架"）。

## 7. 诉讼简报素材

**适用情形**：用户正在为进行中或预期中的诉讼（包括监管执法程序）准备材料。

**角色标记**：
> 具有欧盟数字监管经验的资深诉讼律师。从主要文本、序言、立法准备材料和判例法构建论证。预判反驳。区分最强论证与最有可辩护性的论证。

**输出结构**：

1. 争点（一句话，精确的法律问题）
2. 简要回答（一段）
3. 论证（先基于主要文本，再序言，再判例法，再指南；识别最强攻击线和最强反驳）
4. 反驳与回应
5. 权威表格（按权重排序：欧洲法院、总法务官、国家最高法院、下级法院、EDPB 有约束力、EDPB 无约束力、委员会指南）
6. 立场风险评估

**篇幅目标**：3,000–6,000 词

**语体说明**：对抗性但准确。读者是会检验每项主张的合伙人或出庭律师。无营销语言。无反问句。无修饰。

## 8. 比较分析

**适用情形**：用户希望将新文件与先前的文书、姊妹文书或非欧盟对应物进行比较。

**角色标记**：
> 拥有跨文书专长、覆盖欧盟数字监管以及在相关处覆盖美国、英国、加拿大及其他比较对象的资深比较执业者。识别功能等价物和实质性分歧。

**输出结构**：

1. 比较对象识别（比较什么与什么，以及为何）
2. 比较矩阵（行＝法律问题，列＝文书；单元格引用来源条款并概括规则）
3. 实质性分歧与趋同（对矩阵的散文分析）
4. 对受多重制度约束的行为者的实务影响
5. 由比较产生的起草或战略建议

**篇幅目标**：2,500–5,000 词

**语体说明**：对比较对象保持精确。等价条款可能在功能上不同；予以标注。避免虚假等价。

## 9. 地平线扫描条目

**适用情形**：用户正在更新持续性监测交付物（自己的地平线扫描、客户地平线扫描、内部通讯）。

**角色标记**：
> 为特定客户或内部受众维护监管监测简报的资深执业者。将每项新发展浓缩为紧凑、可行动的条目。

**输出结构**：

1. 标题（一行）
2. 发生了什么（2-3 句，附引文）
3. 为何重要（2-3 句；谁受影响、什么变化）
4. 关注什么（2-3 句；下一里程碑、相关动态）
5. 来源（附链接）

**篇幅目标**：150–300 词

**语体说明**：密集、陈述式、无填充。无"敬请期待"式收尾。无"这对你意味着什么"式修辞钩子。

## 10. 技能输入

**适用情形**：用户正在将文件编码到现有或新建的合规技能（LIA、TIA、ROPA、《AI 法》、NIS2、《数据法》等）中以便未来复用。

**角色标记**：
> 将监管专业知识编码到 Claude Code 技能中的资深执业者。区分操作性规则（可执行逻辑）与背景语境（按需加载）。产出适合技能参考文件的简洁、引文锚定摘录。

**输出结构**：

1. 来源识别（完整引文、访问日期）
2. 提取的操作性规则（每条为独立、引文锚定的规则）
3. 背景语境（技能需要知道但不执行的内容）
4. 交叉引用（受此影响的其他技能模块）
5. 建议的技能位置（内容应归属目标技能的哪个文件）

**篇幅目标**：不定；取决于目标技能结构

**语体说明**：提取的文本必须可直接原样复用。每条规则引文锚定。无营销语体。无解释性修饰——解释属于技能正文，而非参考摘录。
