# legal-analysis-forge

> 📄 **[查看交互式技能页面 →](https://oliverschmidtprietz.github.io/EU-Legal-Analysis-Forge/)**

一个用于对欧盟数字监管文件进行结构化法律分析的**提示词锻造器（prompt forge）**。给定一部条例、指令、委员会指南、EDPB 意见、CJEU 判决、总法务官（AG）意见、国家数据保护机构（DPA）决定、行为准则、协调标准或征求意见稿文件，本技能对文件进行特征化描述、征询期望的交付物类型，并生成量身定制的专家提示词。该提示词可在会话内执行以生成交付物，并始终附有面向使用该技能的执业者的通俗英语说明。

完整六步工作流见 [SKILL.md](SKILL.md)。
版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 本技能做什么

给定一份欧盟数字监管文件和一种交付物类型，本技能：

- **特征化描述**文件——文书类型、约束力、发布机构和法律依据、状态、主题事项、部门接口、可争议的解释动作、时间适用、通俗语言摘要。
- **生成量身定制的专家提示词**，由角色标记、文件语境、任务描述、分析框架（一般法律解释规则加文件特定审查要点）、引用惯例、语域约束、输出结构和自我检查协议组装而成。
- **可选地在会话内执行提示词**以直接产出交付物，并在交付前应用自我检查。
- **始终在正式输出之外生成一份通俗英语说明**；由用户决定是否将其整合进交付物。

支持的交付物类型：利益相关者咨询回应、内部合规备忘录、外部客户备忘录、公开评论（LinkedIn / 博客 / 通讯稿）、会议演讲准备、内部风险评估、诉讼简报素材、比较分析、地平线扫描条目、技能输入。

## 范围

仅限欧盟数字监管：GDPR、AI 法案、数据法案（Data Act）、DGA、DSA、DMA、NIS2（含新版 BSIG）、电子隐私指令（ePrivacy）、CRA、DORA、eIDAS 2.0、产品责任指令（PLD，第 2024/2853 号指令）、AI 责任指令，以及相邻的次级文书（授权法规、实施法规、协调标准、行为准则）。

范围外：竞争、知识产权、税务、雇佣、不触及数字堆栈的部门法。对于操作性合规（DPIA、DPA 起草、AI 法案义务映射、处理活动记录（RoPA）、违规应对、NIS2 范围界定），本技能路由到组合中的相关合规技能，而非承接该任务。

## 部署

将本技能放入您的 Claude Code 技能目录（`~/.claude/skills/` 或工作区级别）。当用户提供欧盟数字监管文件并要求结构化分析、咨询回应、备忘录、简报或类似交付物——无论英语还是德语——Claude 会自动路由到本技能。除 `WebFetch`（用于实时研究）和 `pdf-processing-anthropic`（用于 PDF 摄取）外，本技能不需要任何外部工具配置；两者都是标准的 Claude Code 能力。

输出默认写入用户的当前工作目录。

## 免责声明

本技能不构成法律意见。它执行解释纪律、引用卫生和反幻觉协议，但不保证准确性。欧盟文书会演变，只有 CJEU 能给出权威解释。请在合格律师指导下使用。
