# 解雇通知——法国法律

本 skill 用于起草符合法国劳动法的解雇通知，尤其是因严重过错或个人原因的解除。

## 基本原则

**理由说明至关重要**：解雇通知信函在发生争议时最终确定诉讼的范围。法官只能审查该信函中提及的理由。因此，必须：

1. **详尽**：提及雇主希望援引的**所有**过错
2. **精确**：对每项被指事实注明日期、说明情节并详述
3. **事实性**：以可核验且有记录的事实为依据
4. **连贯**：过错必须能证明所采用的定性（严重过错等）

⚠️ **通知越详细、理由越充分，雇主在法庭抗辩中的保护就越好。**

## 起草工作流

### 第 1 阶段：收集强制信息

开始起草前，通过向用户提问收集以下信息：

#### A. 公司信息
- 完整商号
- 法律形式（SARL、SAS、SA 等）
- 注册地址
- 注册资本
- RCS 编号及注册城市
- APE 代码
- 电话、传真、邮箱

#### B. 员工信息
- 称谓（先生/女士）
- 名和姓
- 完整住址

#### C. 解雇信息
- 信函日期
- 挂号信回执（LRAR）编号（如已知，否则留待填写）
- 内部参考编号（如适用）
- **解雇类型**：严重过错 / 重大过错 / 非纪律性个人原因
- 预先谈话日期
- 员工是否出席谈话
- 员工在谈话期间是否有协助
- 保全停职日期（如适用）

#### D. 合同信息
- 入职日期
- 所任职位 / 资质
- 合同类型（无固定期限合同 CDI / 固定期限合同 CDD）
- 职位的主要职责（详细清单）
- 特别条款（调动、竞业限制、保密等）

#### E. 过错——关键要素

**对每项过错，收集：**

1. **具体事实**：究竟发生了什么？
2. **日期**：何时发生？（必须精确到日期）
3. **背景**：在什么情况下？
4. **证据**：如何认定该事实？（门禁记录、邮件、证言、照片、报告等）
5. **后果**：对公司有何影响？（秩序混乱、财务或形象损害、法律风险等）
6. **先前提醒**：员工是否已被警告过？（警告、训诫、信函等）

**常见过错类型：**
- 无正当理由缺勤 / 擅离职守
- 严重专业能力不足
- 违反安全规则
- 抗命 / 拒绝执行命令
- 违反合同义务（调动、排他性等）
- 欺诈 / 伪造 / 盗窃
- 滥用公司财产
- 不忠诚 / 不正当竞争
- 不当行为（暴力、骚扰等）

**⚠️ 向用户强调：**
> "必须尽可能详细地说明过错，附精确日期、情节和证据。理由越丰富、越有情节，您在劳工法院抗辩中的保护就越好。我将引导您逐项说明过错。"

### 第 3 阶段：起草通知

#### 必须遵守的强制结构

```
[公司抬头]
                                        [员工联系方式]

[地点]，[日期]

带收件回执的挂号信 N° [编号] + 平信

事由：因[理由]解除劳动合同的通知
附件：补充保障权利的可携带性
参考编号：[编号]

[称谓]：

[1. 引用预先谈话]

[2. 通知决定]

[3. 详细陈述理由——关键部分]

[4. 解雇的后果]

[5. 合同终止文件]

[6. 归还公司财物]

[7. 补充保障的可携带性]

[8. 竞业限制条款]

[9. 请求说明的权利]

[10. 客套语]

[签名]
```

#### 理由陈述的起草（关键部分）

**原则：**
- 以概括性引言句开头
- 按逻辑顺序（时间顺序或按主题）呈现过错
- 对每项过错：事实 + 日期 + 背景 + 证据 + 后果
- 在过错之间使用过渡
- 以概括严重程度的句式结尾

**优先采用的表述：**
- "我们遗憾地指出 [...]"
- "对事实的分析表明 [...]"
- "我们的核查已确认 [...]"
- "[具体日期]，您[具体行为] [...]"
- "尽管我们一再要求 [...]"
- "这一情况造成了 [...] 的后果"
- "所有这些事实构成严重过错，使您劳动合同的继续履行成为不可能"

**应避免的内容：**
- 模糊表述："您工作得不好"
- 价值判断："您令人遗憾的态度"
- 未注明日期的事实："多次"（始终注明日期）
- 预先谈话中未提及的过错
- 事实与定性之间的不一致

### 第 4 阶段：最终核验

呈现文件前，核验**强制检查清单**：

- [ ] 完整抬头（公司 + 员工）
- [ ] LRAR + 平信声明
- [ ] 引用预先谈话
- [ ] 精确、注明日期且有情节的理由（严重过错至少 2-3 页）
- [ ] 每项事实精确注明日期
- [ ] 提及证据
- [ ] 解释后果
- [ ] 严重程度句式（"所有这些事实构成……"）
- [ ] 解雇的后果（立即解除，无补偿金）
- [ ] 合同终止文件
- [ ] 归还公司财物
- [ ] 补充保障的可携带性
- [ ] 竞业限制条款（明确立场）
- [ ] 请求说明的权利（15 天）
- [ ] 客套语
- [ ] 签名

### 第 5 阶段：创建文档

1. **使用 `docx` skill 创建 DOCX 格式文档**
2. 应用专业排版：
   - 字体：Arial 或 Calibri 11pt
   - 行距：1.15 或 1.5
   - 页边距：常规
   - 对齐：两端对齐
   - 联系方式标题加粗
   - LRAR 编号用斜体

3. **保存到 `/mnt/user-data/outputs/`**

4. **使用 `present_files` 工具向用户呈现文件**

## 重要法律建议

### 定性区分

**严重过错（Faute grave）：**
- 使员工留在企业成为不可能，即使在预告期内亦然
- 立即解除，无预告期、无解雇补偿金
- 示例：擅离职守、严重抗命、盗窃、暴力

**重大过错（Faute lourde）：**
- 严重过错 + 损害雇主的故意
- 与严重过错后果相同 + 无带薪休假补偿金
- 极难证明，除非明显情形否则避免使用

**非纪律性个人原因解除：**
- 专业能力不足、不适岗
- 须支付预告期和补偿金（除非免除预告期）

### 绝对应避免的错误

1. **理由不精确**："行为不当" → 不充分
2. **缺少日期**："多次" → 始终注明日期
3. **新过错**：绝不添加预先谈话中未提及的事实
4. **矛盾**：事实与定性之间（如过错轻微却以严重过错解雇）
5. **程序未遵守**：预先谈话为强制要求，召集与谈话之间至少间隔 2 个工作日

### 法律加固

**为在争议中最大程度提高成功机会：**
- 谈话前积累尽可能多的书面证据
- 严格遵守程序
- 起草非常详细的通知（严重过错 3-5 页并不为过）
- 复杂案件咨询劳动法专业律师

## 与用户的互动

### 应采用的语气：
- 专业且具有教育性
- 强调精确性的重要性
- 提问以获取所有必要细节
- 不吝提出多次追问

### 典型问题：
- "您能告诉我这一事实的精确日期吗？"
- "您是如何发现这一违规的？您有证据吗（邮件、证言、门禁记录等）？"
- "这一行为对公司造成了哪些具体后果？"
- "员工之前是否已被警告过？如有，何时、以何种方式？"
- "还有其他您想提及的类似事实吗？"

### 应发出的提醒：
如提供的信息不足：
> "⚠️ 注意：所提供的信息不够精确，不足以构成坚实的理由。如发生争议，法官可能认为解雇没有正当理由。必须[说明缺失的内容]。"

## 起草之后

文档创建并呈现后：

1. **提醒后续步骤：**
   - 交由法务/律师复核（建议）
   - 以 LRAR + 平信发送
   - 保留所有凭证和证据
   - 准备合同终止文件

2. **主动提出创建其他必要文件：**
   - 预先谈话召集函（如尚未发出）
   - 保全停职函
   - 补充保障可携带性告知书
