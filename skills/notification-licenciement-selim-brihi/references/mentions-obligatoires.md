# 必需表述——解雇通知（法国法）

## 1. 抬头与联系方式

### 雇主联系方式（左上角）
- 完整商号
- 注册办公地址
- 电话 / 传真
- 电子邮件
- RCS 信息（法律形式、资本、RCS 号码、APE 活动代码）

### 员工联系方式（右上角）
- 称谓 + 名 + 姓
- 完整住址

### 信函信息
- 地点和日期：`[城市]，[日期]`
- **强制**：`带回执的挂号信 第 [号码] 号 + 平信`
- 事由：`严重过错解雇通知`（或其他事由）
- 附件：`补充福利（prévoyance）权利可携性`
- 参考号：[内部参考号]

## 2. 称呼
- `女士，`或`先生，`

## 3. 引用预备谈话（强制）
始终先提及预备谈话：
```
我们已召集您参加预备谈话，原定于 [日期]，[员工出席/缺席 + 可能的协助]。
```

根据情况的变体：
- `您未出席该谈话。`
- `您由 [注明] 协助。`
- `在该以视频会议方式进行的预备谈话中，您没有员工顾问协助。`

## 4. 决定通知（强制）
标准格式：
```
尽管您向我们提出了意见，我们仍决定以严重过错为由解雇您。

特此告知您我们决定以以下事由解雇您：
```

或（如缺席谈话）：
```
特此告知您我们决定以以下事由解雇您：
```

## 5. 事由陈述（关键——须个性化）

### 基本原则：
1. **最大精确度**：事由必须详细、精确、注明日期并说明具体情节
2. **时间顺序**：按逻辑顺序呈现事实
3. **过错累积**：注明事实单独**和**累计地均构成解雇依据
4. **严重性**：解释为何这些事实使劳动合同无法继续

### 常见开头格式：
- `我们不得不遗憾您的多项过错行为。`
- `对事实的分析显示一连串严重且故意的失职行为，这些行为单独地如同累计地，均使您无法继续留在企业内。`
- `如我们在谈话中所陈述，解雇事由如下：`

### 一项过错的典型结构：
```
[失职行为的事实描述]
[精确日期]
[背景与情节]
[对企业的后果]
[法律定性]
```

### 论证充分的过错示例：

**缺勤 / 无正当理由擅离职守：**
```
您多次无故缺勤，未经我们许可且未通知我们。

[精确日期]，您在工作和工作日期间离开工作岗位处理私人事务。
```

**带危险性的严重失职：**
```
[日期]，您从我们公司车队中开出一辆位于特定区域（不合格车辆）的、属于我们企业的车辆，该车辆因危险而不适宜上路、因安全原因被扣留且必须修理后方可重新投入使用，尽管已禁止您使用该车辆，您使自己及其他道路使用者陷入危险。

执法部门不得不拦截该车辆，并发现您正驾驶该所谓危险车辆。

您故意违反我们的指令，可能造成事故并使 [企业名称] 承担民事和刑事责任。
```

**专业能力不足 / 未完成任务：**
```
您自 [日期] 起以无固定期限劳动合同受雇于本公司担任 [岗位]。

您的职能主要包括：
- [任务详细清单]
- [...]

然而，自 [期间] 以来，您的工作被证明远远不足。

[带日期和示例的失职详细说明]

尽管我们提出要求和提醒，[后果描述]。

这对您被分配且未能实现的月度目标产生了负面影响，无论 [年份] 还是 [年份]，均因您缺乏工作、缺乏投入以及未完成您的任务所致。
```

**伪造 / 欺诈：**
```
我们的核查已证实 [带日期的欺诈行为精确描述]。

这种故意的做法构成对您合同义务的严重违反，并损害了雇主与员工之间应有的信任。
```

**违反合同义务（调动条款等）：**
```
按照您劳动合同中您明确同意并载于其中的调动条款，您需定期、在长短不一的期间内、前往不同距离的地点。

[条款引用]

然而，您最近决定违反这一合同调动义务行事。

[带日期和情节的详细事实描述]

您的行为构成对合同义务的严重违反。
```

### 过错结论格式：
```
所有这些事实构成严重过错，使您的劳动合同无法继续履行，即使在通知期内亦然。
```

或：
```
您的这些多项严重失职行为使我们立即解除您的劳动合同，无通知期，无解雇补偿金。
```

## 6. 解雇后果（强制）

### 严重过错立即解除：
```
您的无固定期限劳动合同将于本函寄发之日解除，不向您支付任何解雇补偿金或通知期补偿。
```

或：
```
因此，鉴于被控事实的严重性，我们不得不通知您以严重过错为由解雇。

您的无固定期限劳动合同将于本函寄发之日解除，不向您支付任何解雇补偿金或通知期补偿。
```

### 保全性停职的表述（如适用）：
```
您还曾于 [日期] 被通知保全性停职。因此，自 [日期] 至解雇通知之日的未工作时间将不予计薪。
```

## 7. 合同终止文件（强制）
```
您的离职证明、结清账目收据和供 France Travail（法国就业局）使用的证明将随后通过带回执的挂号信寄送给您。
```

或：
```
您的离职证明、结清账目收据和供 France Travail 使用的证明已备妥，随时可供您领取。
```

## 8. 归还设备（如适用，强制）
```
我们要求您归还仍由您持有的专业设备，并向我们提供用于访问这些设备的标识符和密码。
```

或：
```
请您在收到本函后立即归还您持有的全部专业设备。
```

## 9. 补充福利可携性（强制）
```
随函附上两份关于补充福利权利可携性的信息说明，其中一份须经签署后返还给我们。
```

或长版：
```
在您由失业保险制度承保的前提下，您可以暂时保留我们企业内现行有效的补充福利和补充医疗保险权益。

该制度的维持最长为 12（十二）个月，其资金完全由互助化体系承担：因此，您无需缴纳任何保费。

请您尽快联系我们的承保机构，以证明符合条件并主张维持权利。

维持的保障为您在失业期间本企业内适用的保障，因此，自您离职起，上述保障的任何集体调整均对您适用。
```

## 10. 竞业禁止条款（如适用）
```
我们明确放弃您劳动合同中的竞业禁止条款，并完全免除其中定义的竞业禁止义务。您就此解除相关义务。
```

或：
```
您被明确解除劳动合同中规定的竞业禁止义务，因此您不会获得竞业禁止补偿金。

我们提醒您，即使在劳动合同终止后，您仍须承担保密义务。
```

## 11. 请求说明的权利（强制）
```
最后，您可以在本函通知后 15 日内，通过带回执的挂号信或凭回执交付，请求对本函所述解雇事由作出说明。

我们可以在收到您的请求后 15 日内予以答复。我们也可以主动在解雇通知后 15 日内补充说明这些事由。
```

或长版：
```
您可以在本函通知后十五日内，通过带回执的挂号信或凭回执交付，请求对本函所述解雇事由作出说明。我们可以在收到您的请求后十五日内，以带回执的挂号信或凭回执交付予以答复。我们也可以在必要时以相同形式，在解雇通知后十五日内主动补充说明这些事由。
```

## 关键注意点

### ⚠️ 绝对应避免的错误：

1. **模糊或笼统的事由**："您未遵守您的义务" → 不足
2. **无精确日期**：被控事实始终要注明日期
3. **未经证实的事实**：只提及可核实且有记录的事实
4. **新过错**：不得添加预备谈话中未提及的过错
5. **法律定性错误**：正确区分严重过错（faute grave）/ 重大过错（faute lourde）/ 个人事由（motif personnel）
6. **遗漏强制表述**：带回执挂号信（LRAR）、预备谈话、合同终止文件、15 日期限

### ✅ 良好实践：

1. **积累证据**：照片、电子邮件、证言、报告
2. **清晰的时间线**：按顺序并注明日期呈现事实
3. **因果关系**：解释过错对企业的影响
4. **相称性**：制裁必须与事实相称
5. **一致性**：过错必须与援引的事由一致
6. **最大精确度**：越详细，越有利于在法庭上抗辩
