# 救济与责任（风险分配）

本模块关注出问题时商业上的不利面。

## 内容
- 衡平救济 / 禁令救济
- 律师费 / 费用转移
- 损害赔偿类别
- 责任上限
- 赔偿
- 不依赖 / 保证免责声明
- 违约金 / 罚金
- 争议解决

## 1) 衡平救济 / 禁令救济

### 检查什么
- NDA 是否声明违约造成不可弥补的损害并使披露方有权获得禁令救济？
- 是单向还是双向？
- 是否豁免保证金要求或创设自动权利？

### 接收方危险信号
- 自动禁令救济 + 费用转移 + 宽泛的保密定义。

### 平衡的红线
```
双方确认，未经授权的披露可能造成金钱赔偿不足以弥补的损害，衡平救济在适用法律和衡平原则下可能是适当的。
```

## 2) 律师费 / 费用转移

### 检查什么
- 单向费用（“接收方支付披露方的费用”）。
- 触发条件过宽（“任何争议”而非“胜诉方”）。

### 接收方立场
- 优先各自承担费用。
- 如不可避免，使用“胜诉方”并限制范围。

**建议措辞**
```
各方将各自承担其律师费和成本，除非有管辖权的法院根据适用法律判给。
```

## 3) 损害赔偿类别（直接 / 间接）

### 检查什么
- 排除间接、附带、特殊损害赔偿。
- 是否排除利润损失。

### 接收方危险信号
- 对任何违约的无限制间接损害赔偿。

### 平衡的方法
- 排除间接类别，同时保留直接损害赔偿。

**建议措辞**
```
任何一方均不对因本协议产生的任何间接、附带、后果性、特殊或惩罚性损害赔偿承担责任。
```

## 4) 责任上限

### 检查什么
- 是否有上限？如有，与什么挂钩（已付费用、固定金额）？
- NDA 是否将保密违约排除在上限之外（常见的披露方诉求）？

### 接收方立场
- 避免无限敞口。
- 如披露方坚持例外，收窄之（如仅限故意违约）。

**建议措辞**
```
各方因本协议产生的总责任不超过 [X]。本限制不适用于一方的故意不当行为或故意违约。
```

## 5) 赔偿

### 检查什么
- 接收方是否有义务就违约赔偿披露方。
- 第三方索赔赔偿。

### 接收方危险信号
- 对违约造成的“任何损失”的宽泛赔偿。

### 典型谈判立场
- 删除赔偿；依赖直接损害赔偿。
- 如必须保留：收窄为接收方故意不当行为造成的第三方索赔。

## 6) 不依赖 / 保证免责声明

### 检查什么
- 披露方免责准确/完整性。
- 接收方同意不依赖信息。

### 实务指导
- 在早期阶段讨论中这可能可以接受。
- 如接收方必须依赖（如尽职调查），确保与后期交易文件保持一致。

> **并购 / 尽职调查：** NDA 不依赖条款通常与后期单独的依赖/陈述条款并列。

## 7) 违约金 / 罚金

### 检查什么
- 违约的固定罚金。

### 接收方危险信号
- 与损害脱节的罚金。

### 建议方法
- 优先实际损害赔偿 + 衡平救济，而非预设罚金。

## 8) 争议解决（仲裁、法院地）

即使与司法辖区无关的预案也应标记商业影响：
- 差旅/语言负担。
- 程序保密性。
- 临时救济的可获得性。

**检查清单**
- [ ] 法院地是否实际可行？
- [ ] 是否允许临时措施？
- [ ] 程序是否保密？
