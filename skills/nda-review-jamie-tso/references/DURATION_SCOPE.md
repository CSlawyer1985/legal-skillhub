# 期限与范围（有效期、存续、地域）

本参考聚焦时间、范围和触发机制。保持分析不受司法辖区影响：描述商业影响并提出平衡的语言。

## 内容
- 有效期 vs. 存续
- 地域 / 跨境考量
- 关联公司范围与公司变更
- 追溯覆盖
- 商业秘密（实务处理）

## 1) 有效期 vs. 存续

### 定义
- **有效期（Term）：** 协议管辖披露的时间长度（"关系窗口"）。
- **存续期（Survival period）：** 有效期结束后保密义务持续的时间。

### 应检查的内容
- 有效期何时开始？（生效日 vs. 首次披露。）
- NDA 是否涵盖签署前作出的披露？
- 是否有明确的存续期？

### 接收方危险信号
- 对所有信息无限期存续。
- 存续不明确或与"直至信息进入公共领域"挂钩且无例外条款。

### 平衡方法
- 对一般保密信息固定存续。
- 对严格限定的商业秘密更长存续。

**建议措辞**
```
本协议自生效日起生效，持续 [12–24] 个月（"有效期"）。保密义务在届满或终止后存续 [2–5] 年，但商业秘密（如有）除外，其在其仍构成商业秘密期间持续受保护。
```

## 2) 地域 / 跨境考量

商业 NDA 通常包含：
- 适用法律 / 争议地点条款（法律性）。
- 实务跨境共享关切（操作性）。

### 应检查的内容（操作性）
- 保密信息是否将从多个国家访问？
- 云系统是否全球分布？
- NDA 是否要求"仅在 [国家]"存储？

### 接收方危险信号
- 你无法满足的数据驻留承诺。

**建议方法**
- 除非你有专门的合规环境，避免严格的数据驻留承诺。
- 相反，承诺合理的保障措施和访问控制。

> **个人数据提示：** 涉及个人数据时，NDA 不能替代数据保护条款。应单独处理。

## 3) 关联公司范围与公司变更

### 应检查的内容
- 是否允许关联公司接收披露？（如需要。）
- "关联公司"是否包括未来收购？
- 转让条款：义务能否在合并或资产出售时转移？

### 接收方危险信号
- 即使控制权变更也禁止转让，带来收购中违约的风险。

**建议措辞**
```
任何一方可在合并、收购或出售几乎所有资产时转让本协议，前提是受让人承担本协议项下的义务。
```

## 4) 追溯覆盖

### 应检查的内容
- NDA 是否涵盖签署前披露的信息？

**常见修正**
```
本协议也适用于生效日前 [30–90] 天内披露的保密信息。
```

## 5) 商业秘密（不受司法辖区影响的处理）

### 为何重要
商业秘密概念存在于许多法律体系，但定义各异。避免作出法律认定；相反：
- 询问信息是否实际上被作为秘密对待。
- 询问存在哪些措施使其保持秘密。

**实务检查清单**
- [ ] 该信息在内部是否限制访问？
- [ ] 是否被标注/作为机密处理？
- [ ] 是否以访问控制存储？

> **并购 / 尽职调查：** "商业秘密"标签可能被宽泛使用。聚焦于合规的可行性和相称性。
