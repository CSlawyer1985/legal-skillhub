# NDA 关键条款（审查要点）

本参考以法域中立的方式支持商业 NDA 的逐条审查。聚焦商业风险分配和运营可行性。

## 目录
- "保密信息"的定义
- 目的/允许用途
- 不披露/注意标准
- 期限与存续
- 保密例外
- 被迫披露
- 返还/销毁
- 残留信息

## 1) "保密信息"的定义

### 审查要点
- 范围：是否限于与**所述目的相关**而披露的信息？
- 识别：是否要求标记（"CONFIDENTIAL"），还是涵盖未标记的披露？
- 形式：书面、口头、视觉、电子、演示访问、源代码、样品。
- 衍生信息：是否包括接收方创建的分析、笔记、汇编？

### 接收方警示信号
- "任何种类的所有信息，无论是否标记，均为保密信息"，且无合理性限定。
- 即使信息是独立开发或已知的，保密义务仍适用。
- "残留信息"/"记忆留存"会侵蚀保密义务。

### 披露方警示信号
- 定义仅要求严格标记，口头披露无任何机制。

### 建议的红线修改语言（模块化）
**合理性 + 与目的关联**
```
"保密信息"指披露方或代表披露方就目的向接收方披露的、在披露时被识别为
保密或根据信息性质和披露情形理性人会理解为保密的非公开信息。
```

**口头披露确认（对披露方友好但平衡）**
```
如披露方在披露后 [30] 天内以书面确认其保密性质，口头或视觉披露将被视为
保密信息。
```

## 2) 目的/允许用途

### 审查要点
- 目的足够具体（而非"任何商业目的"）。
- 使用限制与交易匹配（评估 vs 实施）。

### 接收方警示信号
- 使用限制妨碍内部评估（如禁止与需要评估的员工共享）。
- 禁止联系客户、供应商或员工（禁止招揽/禁止接触）隐藏在 NDA 内部。

### 建议的红线修改语言
```
接收方可仅为目的使用保密信息，并可向其因目的需要知悉、且受与本协议同等
保护性保密义务约束的代表披露。
```

> **雇佣/承包商变体：** NDA 有时增加知识产权转让、发明披露、竞业禁止和禁止招揽。将这些作为独立主题处理并升级。

## 3) 不披露/注意标准

### 审查要点
- 注意标准："合理注意"、"与自身相同程度"或绝对义务。
- 安全义务：要求采取的控制或政策。

### 接收方警示信号
- 绝对义务（"应确保不发生未授权披露"）→ 严格责任。
- 强制要求具名安全框架但不可行。

### 建议的红线修改语言
```
接收方将至少以保护自身类似敏感度保密信息所用的同等注意程度保护保密信息，
且无论如何不低于合理注意。
```

## 4) 期限与存续

### 审查要点
- NDA 期限（关系持续多长时间）
- 存续（保密义务持续多长时间）
- 起始日期触发（生效日 vs 首次披露）

### 接收方警示信号
- 对所有信息的永久保密。

### 平衡做法
- 普通保密信息的固定期限。
- 对商业秘密（如已定义）的更长（可能无限期）保护。

**建议语言**
```
保密义务将在期限内及此后 [2–5] 年适用；但对商业秘密（如有）的义务，只要
该等信息依适用法律仍为商业秘密，即持续适用。
```

## 5) 保密例外

（另见：STANDARD_EXCEPTIONS.md）

### 审查要点
- 标准例外条款存在且可操作。
- 谁承担举证责任。

### 接收方警示信号
- 无例外条款。
- 有例外条款但要求不可能完成的证明。

## 6) 被迫披露

### 审查要点
- 法律/监管机构要求时披露的能力。
- 通知要求和时间。

### 接收方警示信号
- 要求"立即"或 24 小时内通知，即使被禁止。
- 不允许披露最低必要信息。

**建议语言**
```
如接收方依法律、法规或法院命令被要求披露保密信息，接收方可以在（在法律
允许的范围内）及时通知披露方并合理配合披露方寻求保护性处理的情况下进行
披露。
```

## 7) 返还/销毁

### 审查要点
- 可行性：备份、档案、法律保留。

### 接收方警示信号
- 要求立即清除所有备份并认证删除一切。

**建议语言**
```
经书面请求，接收方将返还或销毁保密信息，但接收方可以保留副本 (i) 为遵守
法律、法规或内部合规要求所需，以及 (ii) 存在于日常运营中无法合理访问的
常规备份系统中的副本，前提是该等保留信息仍受保密义务约束。
```

## 8) 残留信息

### 为何重要
残留信息条款可以允许接收方使用"记忆留存"的泛化知识，这可能吞没保密义务。

### 接收方立场
- 优先删除。
- 如不可避免：大幅收窄范围（排除源代码、产品路线图、客户名单、定价）。

**建议的收窄语言**
```
残留信息不包括源代码、客户可识别信息、定价、产品路线图，或为规避本协议
而故意记忆的任何信息。
```
