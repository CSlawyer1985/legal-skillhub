# 当事人义务（接收方与披露方）

本模块帮助你将义务映射到正确的一方，并发现隐藏的风险转移。

## 目录
- 接收方义务
- 披露方义务
- 互惠保密协议（范围外）
- 操作可行性检查清单
- 不招揽 / 不接触 / 停滞条款
- 公开与公告

## 1) 接收方义务（最常见）

### 核心义务
- 不披露：除允许情形外不得披露。
- 使用限制：仅用于所述目的。
- 注意义务标准：以合理注意（或与己方同等标准）保护。
- 对代表的控制：将内部/外部共享限制在需要知情（need-to-know）范围内。

### 代表处理
**需检查事项**
- 是否定义了“代表”（员工、承包商、关联公司、顾问）？
- 是否包含关联公司？有时评估需要它们。
- 接收方是否对任何代表违约承担严格责任？

**接收方警示信号**
- 即使代表不在接收方控制之下，也承担无限责任。
- 代表包含“任何人”，但没有“需要知情”限制。

**平衡的修改建议**
```
接收方可向其因目的而需要知情、且受至少与本协议同等保护性保密义务约束的代表披露保密信息。接收方在对其代表具有控制权的范围内，对其代表的合规负责。
```

## 2) 披露方义务（常被遗漏）

即使在单方保密协议中，披露方也可能有义务：
- 确保其有权披露（无第三方限制）。
- 标记或识别保密信息（视定义而定）。
- 按“现状”提供信息（常见）——检查免责声明。

**接收方需注意**
- 披露方在接收方依赖信息的同时，免除对准确性的一切责任。
- 保密协议包含与交易流程不一致的宽泛不依赖（non-reliance）措辞。

> **并购 / 尽职调查：** 不依赖条款在早期可能可接受，但须确认与后续交易文件一致。

## 3) 互惠保密协议（双向流动）—— 范围外

本 skill 专为**单向（单方）**保密协议设计。如保密协议为互惠，停止并升级，或使用单独的互惠保密协议审查手册。

## 4) 操作可行性检查清单（接收方）

- [ ] 我们能否遵守通知要求（如违约通知、被迫披露通知）？
- [ ] 我们能否在实践中限制访问（共享工具、电子邮件、工单系统）？
- [ ] 我们能否按起草内容返还/销毁（备份、保留政策、法律保留）？
- [ ] 我们是否需要向审计师、监管机构或保险人披露的能力？

## 5) 不招揽 / 不接触 / 停滞条款（隐藏在保密协议中）

这些条款并非纯粹的“保密”条款，可能影响重大。

### 需检查事项
- 对接触披露方员工/客户/供应商的任何限制。
- 停滞条款（投资者情境中常见）。

### 接收方立场
- 将其分离到独立协议中，或大幅收窄。

> **投资者 / VC 变体：** 停滞和不招揽条款可能是有意要求的；作为商业决定处理并升级。

## 6) 公开与公告

### 需检查事项
- 保密协议是否禁止提及该关系？
- 是否允许在保密义务下进行所需披露（如向投资者、审计师）？

**平衡的修改建议**
```
未经另一方事先书面同意，任何一方均不得就讨论发表公开声明，法律要求或向专业顾问在保密义务下披露的除外。
```
