## 能为你做什么（数据资源入表四大场景）
---

### 一、会计入表与税务确认的税会差异
- 🧮 **税会差异识别**：会计上可入表的数据资源，税务口径未必确认计税基础；逐项错误识别并做纳税调整，避免重复扣除或漏确认
- 📊 **后续计量协同**：入表资产的摊销、减值与税务扣除口径差异，建立税会差异台账统一跟踪
- ⚠️ **高频风险**：入表即盲目税前扣除、资本化与费用化混淆、税会口径混用导致少缴或重复扣除

**典型问法：**
```
"企业数据资源入表要交税吗？"
"数据资源入表税务怎么处理？"
"会计入表和税务确认有什么差异？"
```
---

### 二、数据资产估值虚高与上市审核问询
- 📈 **估值公允性**：以可观察市场价或收益法公允价值计量，严禁为迎合融资或上市审核虚增资产与利润
- 🔍 **审核问询应对**：拟上市企业须就业务实质、成本归集、摊销与减值政策、权属合规应对审核问询，准备完整材料
- 🛡️ **风险防控**：估值虚高涉嫌利润操纵，是上市审核与监管问询高发点，可能导致审核被否、补税乃至行政处罚

**典型问法：**
```
"数据资源入表上市审核关注什么？"
"数据资产估值虚高有什么风险？"
"拟上市公司数据资产问询怎么应对？"
```
---

### 三、数据产品转让与授权涉税处理
- 💱 **交易实质判定**：数据资产转让通常按“销售无形资产”缴纳增值税，授权使用多按“现代服务”缴纳；转让所得并入应纳税所得额缴纳企业所得税，产权转移书据可能涉及印花税
- 📑 **合同与申报**：规范数据产品交易合同，按规完成增值税、企业所得税与印花税申报
- 🔗 **权属前置**：转让与授权前须确认数据权属清晰、来源合规，避免合规瑕疵影响交易

**典型问法：**
```
"数据资产转让涉及哪些税？"
"数据产品对外授权涉税吗？"
"数据权属合规怎么判断？"
```
---

### 四、数据资源研发支出归集与加计
- 🔬 **费用化资本化划分**：与数据资源相关的研发支出须正确划分研究/开发阶段，费用化部分可加计扣除，资本化部分按无形资产摊销、不得加计
- 🧾 **辅助账与证据链**：建立研发辅助账与备查资料链，应对研发费用加计扣除核查
- 🧮 **合规归集**：严格区分研发与生产经营支出，共用资源按合理基础分摊

**典型问法：**
```
"数据资源研发加计怎么归集？"
"数据资源研发支出怎么区分费用化与资本化？"
```

## 重要提示与边界声明

**重要提示**
1. **税会差异须调整**：会计入表不等于税务确认，入表资产的计税基础、摊销扣除与数据产品交易均须做纳税调整，避免重复扣除或漏确认。
2. **估值须公允**：数据资产估值以可验证公允价值为基础，严禁虚增资产或利润以迎合融资、上市审核。
3. **权属来源须合规**：入表数据资源须权属清晰、取得与采集合规，加工链路可追溯，否则影响资产确认与上市审核。
4. **数据以官方为准**：数据资源入表相关政策时效性强，具体适用请核验最新文件与主管财政、税务机关口径。

**边界（本技能不做的）**
- **不代办**：数据资产确权登记、纳税申报填报、数据交易所挂牌等需登录系统操作的事项
- **不代理**：数据资产估值鉴证、上市审核法律尽调等需执业资质的事务
- **不担保**：税会差异处理、估值公允性、稽查定性等争议区最终以财政、税务机关或司法机关认定为准

**服务说明**
- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告

**隐私保护**
- 仅在本机生成随机匿名标识用于服务调用，不会采集任何设备信息或个人隐私数据。
