在法律 AI 技能、提示词、工作流、MCP/工具指令和代理包被信任或安装之前对其进行审计。它检测提示注入、隐藏或恶意指令、不安全的脚本、可疑的 frontmatter、凭据暴露、数据外泄路径、持久化机制、cron/launchd 钩子、未经授权的网络调用和供应链风险。

它返回裁定 — 批准、附约束批准、重写、隔离或拒绝 — 外加关键风险和推荐的整改措施。
