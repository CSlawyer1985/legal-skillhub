# 命名权落地模块 ·「命名权」环节(naming-playbook)

> 加载时机:流程走到第四步「命名权」。本模块把《核心 20 条》命名权 3 条收进来,叠 RX/OTC 适配 + 合规卡点。
> 三条铁律:① **RX 命名权基于药理机制,绝不暗示优效**;② OTC「服用建议型」命名权默认🟡交审核;③ 任何命名权候选**必附商标占用风险评估**,公开使用前先评估注册。

## 用法
1. 确认分诊口径(RX 走学术机制标签;OTC 走品类心智)。
2. 复制提示词填 `{}`,医药客户追加本条「医药适配」。
3. 产出后用"法规视角读一遍"自检:读到的是机制描述,还是疗效承诺?读到承诺就改。

## 命名权-1 · 命名权头脑风暴(核心-6)

```
你是擅长打造"方法论命名权"的品牌战略顾问。
参考高彭满座命名传统(三国流量战略、五段位、八步法、影子覆盖战)。
【企业】{}【行业】{}【核心业务】{}【目标客户】{}【已有概念】{如有}【品牌调性】{}
命名要求:3-7字、好记、独特、能一句话讲清原理、可应用、可拓展
命名禁忌:别太抽象、别撞大厂术语、别太技术化
请输出:1.3-5个候选命名权概念 2.每个含名称+一句话定义+核心原理(3-5点)+适用场景+差异化+可衍生子概念 3.推荐优先级 4.商标占用风险评估
```
**医药适配:**
- **RX**:候选命名权**只能是药理机制标签**(如基于"非某依赖路径""短效代谢"的机制型),差异化只写机制不写疗效优劣;命名要能被医生理解、可对接循证。
- **OTC**:可做品类心智/场景心智(如时段化服用概念);差异化写品类定位,不写功效承诺。

**合规卡点:** 每个候选过"法规视角"读一遍。RX 凡含"更/最/突破"立即改。**商标:还没注册的命名权,公开传播前先做占用检索,否则等于替整个品类做免费科普**(早X晚Y型概念尤其,其逻辑常是公共共识)。

## 命名权-2 · 传播话术体系(核心-7)

```
为以下命名权设计完整传播话术:
【命名权】{}【定义】{一句话}【核心原理】{}
请输出6个版本:1.30秒电梯版(给老板) 2.3分钟版(给客户) 3.30分钟深度版(上课讲)
4.一篇文章版(发表用) 5.一句话金句(3-5句) 6.学员/客户教育版
要求:跨场景表述完全一致。
```
**医药适配:**
- **RX**:6 个版本的受众**全部是专业人士**(医生/药师/采购/学术),不存在"给患者版";"一篇文章版"走学术期刊/专业社区调性,带循证;金句不得是疗效口号。
- **OTC**:可面向家长,但"金句"不得夸大、不暗示替代医疗。

**合规卡点:** RX 话术体系里**不得出现任何面向患者的营销表述**;OTC 话术受药广审范围约束。所有对外话术 RX 默认走三方审核。

## 命名权-3 · 跨平台一致性检查(核心-8)

```
检查命名权在各平台使用一致性:
【企业】{}【命名权概念】{列出所有应统一的概念}【各平台现状】{粘贴官网/公众号/知乎等使用情况}
请输出:1.一致性评分(每概念每平台1-5分) 2.不一致问题清单 3.标准化修正方案 4.长期一致性保障机制
```
**医药适配:**
- **RX**:检查的平台是专业阵地(官网/丁香园/医脉通/期刊);**额外检查:有没有哪个平台把机制型命名用成了优效暗示**(这是 RX 一致性检查的合规增项)。
- **OTC**:检查 C 端平台;额外检查有无平台夸大疗效。

**合规卡点:** 一致性修正方案里,凡发现优效化/超说明书用法,优先级最高、立即修正,并通报法规。

## 本环节交付物清单(出脑不出手)

| 交付物 | 形态 | 备注 |
|---|---|---|
| 命名权候选 | 3-5 个概念 + 定义/原理/差异化 | RX 机制型;OTC 品类心智 |
| 法规视角自检结论 | 机制 vs 承诺 判定 | 读到承诺即改 |
| 商标占用风险评估 | 建议查哪些、是否先注册 | IP 护城河前提 |
| 传播话术体系 | 6 版本(RX 全专业受众) | RX 经三方审核 |
| 跨平台一致性报告 | 评分 + 修正方案 | 含优效化合规增项 |

> 命名是工作室最锋利的武器,但医药场景对自家武器也要保持合规警惕。
