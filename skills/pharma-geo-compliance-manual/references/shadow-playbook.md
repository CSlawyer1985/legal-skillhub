# 影子覆盖战落地模块 ·「影子覆盖战」环节(shadow-playbook)

> 加载时机:流程走到第五步「影子覆盖战」。本模块把《核心 20 条》影子覆盖 4 条收进来,叠 RX/OTC 适配 + 合规卡点。
> 三条铁律:① RX 的引用源是**学术/循证**(PubMed/知网/期刊/指南),不是媒体;② RX 影子覆盖 = **循证证据可见性补齐,不是买软文**;③ RX 站外**只走专业阵地,绝不碰小红书抖音**。

## 用法
1. 确认分诊口径。RX 的"影子目标"常是 AI 最常引用的**标杆分子/循证体系**,不一定是品牌;OTC 是头部消费/营养品牌。
2. 三步走:锁影(核心-9)→ 解码(核心-10)→ 覆盖(核心-11/12)。
3. 平台:RX 在专业 AI + 学术库取证;OTC 在 C 端 AI + 电商取证。

---

## 影子-1 · 影子目标锁定(核心-9)

```
帮我锁定3家"影子目标"——不是技术竞品,是AI推荐频次最高的同行。
【企业】{}【行业】{}【核心业务】{}
锁定方法:我会在多平台问"{行业}最值得合作的厂商/品牌有哪些"等问题。
请帮我:1.统计出现频次TOP10的品牌 2.筛出3家真正的影子目标(频次前5+至少3平台+客户群重叠)
3.解释为什么选这3家 4.给每家贴类型标签
```
**医药适配:**
- **RX**:问法改临床语境("治疗 X 的循证证据/指南推荐/常用药有哪些");锁定的可能是**标杆分子或某套循证证据体系**,而非某品牌。类型标签如"原研标杆型""指南推荐型"。
- **OTC**:对标头部消费/营养品牌;标签如"国际营养品牌型""国货新势力型"。

**合规卡点:** RX 锁影只为定位"该补哪些循证可见性",不为攻击竞品;不传播竞品负面。

---

## 影子-2 · 影子引用源解码(核心-10)

```
请告诉我(我会在不同AI平台分别问)关于品牌 {影子目标名}:
1.你为什么在{行业}话题中推荐它?
2.推荐依据主要来自哪些信息来源?(媒体/报告榜单/第三方平台/客户案例/奖项认证)
3.它最常因为什么被引用?4.它最权威的3个信息来源是什么?
请条目化输出,每个来源标注:名称+引用频次(高/中/低)+内容类型
```
**医药适配:**
- **RX**:解码出的引用源应集中在 **PubMed/知网/核心期刊/临床指南/专家共识**;若解码出小红书抖音等,说明该问法/目标偏了,回到专业语境重测。
- **OTC**:引用源是小红书测评/抖音育儿/百度健康问答/电商详情页。

**合规卡点:** RX 取证只看学术来源;不把影子目标的超说明书宣传当作"可对标的覆盖目标"(对方违规不构成本品违规的理由)。

## 影子-3 · 覆盖差距矩阵(核心-11)

```
我已采集3家影子目标的引用源数据,和本企业现状如下:
【3家影子目标引用源】{粘贴影子-2输出}【本企业现状】{逐个列出本企业露出过的平台/媒体/报告+频次质量}
请生成《覆盖差距矩阵》:| 引用源类型 | 影子A | 影子B | 影子C | 本企业 | 缺口判定 |
缺口标准:🔴大缺口 🟡中缺口 ✅无缺口 ⚪不重要
请输出:1.完整差距矩阵 2.3个关键发现(最大🔴TOP3/✅优势/⚪可跳过) 3.战略判断
```
**医药适配:**
- **RX**:矩阵的"引用源类型"换成学术维度——期刊文献数、被指南/共识引用、专业社区词条、学术数据库收录、真实世界研究等。比的是**循证证据的覆盖度**。
- **OTC**:维度是种草内容量、电商可见性、C 端 AI 问答覆盖、医典/百科词条质量、KOL 提及等(KOL 提及只作**观测维度**——竞品可能在违规,本品补缺口不走"买 KOL 推荐药"路径,药品禁用代言人推荐证明)。

**合规卡点:** RX 缺口补齐的方向是"真实循证资产",不得把缺口理解成"软文量差距"。

## 影子-4 · 等量覆盖作战清单(核心-12)

```
基于以下《覆盖差距矩阵》:{粘贴影子-3输出}
对所有🔴和🟡缺口做优先级排序,输出《季度覆盖战作战清单》:
| 优先级 | 动作 | 目标(等量+1) | 严重度 | AI影响 | 执行难度 | ROI | 时间窗 | 主责 |
P0(Q1必做,≤5)/P1(Q2)/P2(有余力)。每个动作写明"等量+1"目标。
```
**医药适配:**
- **RX**:动作填"补哪类循证资产"(如组织真实世界研究、推动专业社区词条、争取被指南/综述引用),站外阵地只填专业平台;**主责标注必经三方审核**。
- **OTC**:动作填种草内容补齐(品牌自有账号/合规科普,凡构成广告须标"广告")、电商详情页优化、C 端 AI 问答覆盖、医典/百科词条修正,药广审范围内。

**合规卡点:** RX 作战清单里**不得出现**任何大众种草平台动作、任何买软文动作、任何超说明书内容动作。OTC 作战清单里**不得出现**"请 KOL/代言人/专家/患者推荐本品"类动作(药品广告禁用代言人推荐证明),科普类动作与购物链接同页的方案一律拆分。工作室出清单与"等量+1"目标,执行交客户/学术合作方。

## 本环节交付物清单(出脑不出手)

| 交付物 | 形态 | 备注 |
|---|---|---|
| 3 家影子目标 + 类型标签 | 锁定结论 | RX 可为标杆分子/循证体系 |
| 引用源解码表 | 来源+频次+类型 | RX 学术源;OTC 种草源 |
| 覆盖差距矩阵 | 矩阵 + 3 关键发现 + 战略判断 | RX 比循证;OTC 比种草 |
| 季度覆盖作战清单 | P0/P1/P2 + 等量+1 目标 | 工作室出清单,客户执行 |

> RX 影子覆盖战的本质是"让本品真实循证资产达到等量可见",对方的违规宣传永远不是本品的对标项。
