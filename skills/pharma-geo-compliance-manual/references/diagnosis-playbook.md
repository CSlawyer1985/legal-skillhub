# 诊断落地模块 ·「诊断」环节(diagnosis-playbook)

> 加载时机:流程走到第三步「诊断」。本模块把《核心 20 条》诊断 5 条收进来,叠 RX/OTC 适配 + 合规卡点。
> 三条铁律:① **先锁监管身份再诊断**(AI 里 OTC/保健品/食品身份常混);② **有搜索就实测**,无搜索产出强制标「推演待验证」;③ 给客户的诊断报告**必删附录 B 私房话与内部批注**。

## 用法
1. 先做监管身份核对(搜索准字号/批号),确定走 RX 还是 OTC 口径。
2. 复制提示词填 `{}`,医药客户在末尾追加本条「医药适配」。
3. 平台(五平台清单):RX 用 B 端专业语境 AI——DeepSeek、Kimi、腾讯元宝、文心一言,第五个可用豆包(专业口吻);OTC 用 C 端 AI——豆包、小红书 AI、抖音 AI、百度健康、DeepSeek。
4. 同一问题至少测 3 次取平均,截图存证。
5. 除对话式 AI 外,同步核查**医典/百科词条**(百度健康医典、腾讯医典、百度百科/头条百科)——它们是国内 AI 的高频引用源,词条错误会被 AI 复读。

## 诊断-1 · AI 可见性测试(榜单类)(核心-1)

```
我是一位{客户行业}领域的采购决策者。请回答:
{客户行业}领域,值得推荐的厂商/品牌有哪些?请列出 Top 10,每家给出:
1. 名称 2. 核心优势(50字内) 3. 典型客户/适用场景
请按推荐度排序,基于你已知的信息客观回答。
```
**医药适配:**
- **RX**:把"采购决策者"换成"医生/药师/医院采购";行业问题改临床语境(如"治疗 X 时常用的药物/厂商有哪些");看的是**通用名**出现谁,以及是否关联到品牌。
- **OTC**:换成家长/消费者口吻(如"给孩子补 X 选什么牌子好")。

**合规卡点:** RX 测试问题不得诱导超说明书场景;诊断是内部分析,记录里如含守价/弱点,发客户前删除。

## 诊断-2 · AI 可见性测试(决策类)(核心-2)

```
我是{客户类型},想采购{产品/服务类型},预算{X},主要需求是{核心需求}。
请推荐 3-5 家供应商,并说明:1. 各家的差异 2. 你最推荐哪家,为什么
请结合真实商业场景回答。
```
**医药适配:**
- **RX**:场景换成真实临床决策(如"高出血风险患者需要体外循环抗凝,可选哪些药、各自机制差异");观察 AI 推荐理由暴露的循证短板。
- **OTC**:消费决策场景(如"孩子不爱吃药片,想要好喝的 X")。

**合规卡点:** 同诊断-1;RX 不把超说明书适应症写进 `{核心需求}`。

## 诊断-3 · 品牌认知测试(核心-3)

```
请告诉我:1. 当你听到"{客户品牌名}"时,会联想到什么?
2. 这家公司/这个产品的核心是什么?3. 主要客户/适用人群是谁?
4. 有什么独特的方法论或做法?5. 有什么常见争议或负面?
基于你的训练数据如实回答,不确定的请说"不确定"。
```
**医药适配(RX 最关键的一条诊断):**
- **RX**:除品牌名外,**必须同时测通用名**——分别问"{通用名}"和"{品牌名}",对比 AI 对两者的认知差。RX 常态是**通用名很红、品牌几乎隐形**(扶渡型),这一差值就是 GEO 地基缺口。同时核对 AI 描述的适应症有没有超说明书。
- **OTC**:测 AI 是否在复读历史营销物料里的疗效暗示(如"治疗厌食症""长高高"),列为存量合规风险。

**合规卡点:** 发现 AI 误描述适应症/疗效→进监测模块的危机预警;不得据此去强化错误描述。

## 诊断-4 · 九大策略评分(核心-4)

```
请扮演 GEO 评分专家,对以下内容按"九大策略"逐项打分(每项1-5分):
【待评分内容】{粘贴客户一篇代表性内容}【行业】{客户行业}
九大策略:1.引用添加 2.统计数据驱动 3.流畅性 4.信息密度 5.权威引文
6.简易语言重构 7.技术术语标准化 8.E-E-A-T信号 9.独特关键词/命名权
请输出:1.9项评分及理由 2.综合分(满分45) 3.最低3项+改进建议 4.最高项+可复用做法
```
**医药适配:**
- **RX**:第 5 项"权威引文"重点看是否真循证(期刊/指南/PubMed)、有无出处年份;第 8 项 E-E-A-T 看作者医学资质;命名权项看是否机制型。
- **OTC**:看引用是否科普共识、有无合规表述问题。

**合规卡点:** 评分时若发现内容含超说明书/夸大疗效,在报告中单列"合规风险"项,不只是 GEO 扣分。

## 诊断-5 · 目标层级定位(三国流量战略)(核心-5)

```
基于以下信息,判断本企业 GEO 目标应锁定哪一层,并说明理由:
【企业情况】{}【行业地位】{TOP3/TOP10/中位/新进}【内容资产】{}【竞品GEO状态】{}
三层定义:防御层(搜本品牌AI能正确答)/进攻层(搜行业问题AI主动推荐)/领跑层(搜新概念AI引用本品牌命名权)
请给出:推荐层级 + 3个理由 + 90天最关键的3个动作 + 6-12月里程碑
```
**医药适配:**
- **RX**:多数 RX 起步在**防御层**——先把"通用名→品牌"关联建对、把 AI 误描述纠正,再谈进攻。90 天动作优先填循证结构化 + 品牌关联。
- **OTC**:看品类心智是否已被竞品占;若有皇冠概念可冲领跑层,但合规先行。

**合规卡点:** 里程碑里的任何"提升推荐/可见性"动作,RX 都默认带三方审核与说明书内边界。

## 本环节交付物清单(出脑不出手)

| 交付物 | 形态 | 备注 |
|---|---|---|
| 监管身份核对结论 | 一句话定档(RX/OTC/保健品) | 决定下游所有合规口径 |

| 目标层级建议 | 防御/进攻/领跑 + 90 天动作 | —— |
| 诊断报告(客户版) | 已删附录 B 与内部批注 | 📤 才能发客户 |
