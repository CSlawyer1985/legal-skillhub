# 监测落地模块 ·「监测」环节(monitoring-playbook)

> 加载时机:流程走到第七步「监测」。本模块把《核心 20 条》监测 3 条收进来,叠 RX/OTC 适配 + 合规卡点。
> 三条铁律:① **RX 的 AI 误描述预警优先级最高**——说错适应症/禁忌/疗效不只是营销问题,是合规与患者安全问题;② 给 CMO/老板的报告默认脱敏;③ 监测发现违规误描述要纠偏,但本品不得借机做超说明书宣传。

## 用法
1. 固定每月同一时间测,形成时间序列。
2. 平台(五平台清单):RX 用专业语境 AI——DeepSeek、Kimi、腾讯元宝、文心一言 + 豆包(专业口吻);OTC 用 C 端 AI——豆包、小红书 AI、抖音 AI、百度健康、DeepSeek。
3. 季度汇总成报告;发现误描述按等级响应。医典/百科词条纳入监测(AI 高频引用源,词条被改错=误描述源头)。

## 监测-1 · 月度 AI 可见性监测(核心-18)

```
整理本月AI可见性监测数据:
【周期】{年月}【企业】{}【平台】{列出5个测试平台}
每平台问3类问题:A.行业Top榜单 B.客户决策 C.行业问题
【本月结果】{各平台各问题:出现/未出现+排名+描述准确度1-5}【上月数据】{}
请输出:1.本月可见性总览 2.与上月对比 3.关键发现 4.竞品对照 5.下月行动建议 6.风险预警
```
**医药适配:**
- **RX**:三类问题换专业语境(临床决策/治疗领域/通用名关联);重点追踪**通用名→品牌关联度**随时间的变化(这是 RX 的核心 KPI)。
- **OTC**:追踪品类心智命名权的渗透 + 是否仍在复读历史疗效暗示。

**合规卡点:** 第 6 项"风险预警"对 RX/OTC 都要专列**合规风险**子项(AI 误描述适应症/疗效),不只是营销负面。

## 监测-2 · AI 误描述危机预警(核心-19)(RX 优先级最高)

```
识别AI对本企业的错误描述:
【企业】{}【实际情况】{真实业务/客户/规模/定位}【AI的描述】{粘贴各平台对企业的描述}
识别7类危机:1.业务定位 2.规模 3.客户群 4.方法论 5.案例归属 6.重大负面 7.时效性
请输出:1.错误清单(分类/级别/平台/原文) 2.危机等级(L1-L4) 3.优先级响应建议
```
**医药适配(危机分类扩充):**
- **RX**:在 7 类之外**增加医药专属危机**——① AI 说错适应症(尤其把超说明书用途说成获批适应症)② 说错禁忌/相互作用 ③ 错误疗效归因 ④ 把本品与未获批用途绑定。这几类一旦出现直接判 **L3-L4**(涉患者安全)。
- **OTC**:增加"AI 复读历史夸大疗效""暗示替代医疗""涉未成年人不当表述"三类。

**合规卡点:** 纠偏方式是"用准确循证信息覆盖错误描述",**绝不能借纠偏之机把超说明书用途写成正式适应症**。RX 误描述纠偏内容经三方审核。

## 监测-3 · 季度 GEO 效果报告(核心-20)

```
生成本季度GEO效果监测报告:
【周期】{年QX}【企业】{}【上季度基线】{}【本季度数据】{三个月月度数据}
报告结构:一、执行摘要(老板视角,前300字,数字化) 二、关键指标对比(5平台可见性/三类问题出现率/排名/准确度)
三、四项核心指标(SoM/Citation/Mention/Sentiment) 四、竞品对比 五、本季度动作复盘(有效TOP3/未达预期/ROI) 六、下季度建议
请输出完整报告(可向CMO汇报)。
```
**医药适配:**
- **RX**:核心指标换成学术可见性口径——通用名→品牌关联度、被专业平台/文献引用率、说明书内适应症的正确呈现率;竞品对比走标杆分子/循证体系。
- **OTC**:指标是品类心智渗透、C 端 AI 推荐位、种草/电商可见性;竞品对比走头部消费品牌。

**合规卡点:** 报告若对外/给第三方,按客户视角脱敏(删守价、内部弱点、谈判);RX 报告中任何疗效相关结论附出处,不做优效宣称。

## 本环节交付物清单(出脑不出手)

| 交付物 | 形态 | 备注 |
|---|---|---|
| 月度可见性监测表 | 时间序列 | RX 追踪通用名→品牌关联度 |
| AI 误描述危机清单 | 分类+等级+响应 | RX 医药专属危机判 L3-L4 |
| 合规风险预警 | 专列子项 | 误描述适应症/疗效 |
| 季度效果报告 | 给 CMO 的标准文档 | 对外脱敏 |
| 纠偏内容框架 | 用准确循证覆盖错误 | RX 经三方审核 |

> 对医药,监测不只是看效果,更是合规与患者安全的哨兵。AI 把处方药说错,第一时间纠偏。
