## 概览

本文档整理中国劳动法、劳动合同法等法律中与劳动者权益密切相关的核心知识，供智能体在回应用户咨询时查阅引用。

适用范围：中国境内企业、个体经济组织、民办非企业单位等与劳动者之间的劳动关系。

核心法律依据：
- 《中华人民共和国劳动法》
- 《中华人民共和国劳动合同法》
- 《中华人民共和国劳动争议调解仲裁法》
- 《中华人民共和国社会保险法》
- 《全国年节及纪念日放假办法》

## 加班与工资

### 加班工资标准（劳动法第44条）

| 加班类型 | 报酬标准 | 能否用调休替代 |
|---------|---------|-------------|
| 工作日延时加班 | 不低于工资的150% | 不能 |
| 休息日加班 | 不低于工资的200% | 可以优先安排补休，无法补休才付200% |
| 法定节假日加班 | 不低于工资的300% | 不能，必须支付三倍工资 |

### 法定节假日（共13天）

依据《全国年节及纪念日放假办法》：
- 元旦：1天
- 春节：4天（除夕至初三）
- 清明节：1天
- 劳动节：2天
- 端午节：1天
- 中秋节：1天
- 国庆节：3天

**关键区分**：假期中只有上述法定节假日加班必须付三倍工资，其余调休日按休息日加班规则（2倍或补休）。

### 加班工资计算

- 日工资 = 月工资标准 ÷ 21.75（月计薪天数）
- 小时工资 = 日工资 ÷ 8
- 法定节假日加班工资 = 日工资 × 300% × 加班天数（额外支付，加上正常工资实际应得4倍日工资）
- 休息日加班工资 = 日工资 × 200% × 加班天数（如未安排补休）
- 延时加班工资 = 小时工资 × 150% × 加班小时数

### 加班时间限制（劳动法第41条）

- 一般每日延长不超过1小时
- 特殊原因每日不超过3小时
- 每月累计不超过36小时
- 法定节假日加班不受月加班时间限制

### 禁止情形（劳动合同法第31条）

- 用人单位不得强迫或变相强迫劳动者加班
- 禁止以"自愿加班"为由拒付加班费
- 禁止用节日福利、实物礼品替代加班费（二者需分开执行）
- 加班费计算基数不得低于当地最低工资标准

## 劳动合同

### 签订要求（劳动合同法第10条）

- 用工之日起1个月内必须签订书面劳动合同
- 超过1个月不满1年未签：支付双倍工资
- 满1年未签：视为已订立无固定期限合同，仍需支付11个月双倍工资

### 试用期规定（劳动合同法第19条、第20条）

| 合同期限 | 试用期最长 |
|---------|-----------|
| 不满3个月 | 不得约定试用期 |
| 3个月以上不满1年 | 不超过1个月 |
| 1年以上不满3年 | 不超过2个月 |
| 3年以上及无固定期限 | 不超过6个月 |

- 同一用人单位与同一劳动者只能约定一次试用期
- 试用期包含在劳动合同期限内
- 试用期工资不得低于合同约定工资的80%，且不得低于当地最低工资标准

### 无效条款

以下约定无效：
- "自愿放弃社保"
- "工伤自负"
- "离职扣工资"

## 社保权益

### 缴纳义务（劳动法第72条、社会保险法）

- 用人单位必须依法缴纳养老保险、医疗保险、失业保险、工伤保险
- 约定"自愿放弃社保"的协议无效
- 未缴纳社保的法律后果：
  - 劳动者可据此解除合同并索要经济补偿
  - 逾期不改正：对单位处应缴社保费1倍以上3倍以下罚款
  - 对直接负责人处500元以上3000元以下罚款

### 工伤保险特殊规定

- 职工不缴纳工伤保险费
- 无劳动合同但存在事实劳动关系，依然可认定工伤
- 违法转包、分包的，由用工单位/发包单位承担工伤保险责任

## 解雇与补偿

### 合法解雇情形（劳动合同法第39-41条）

1. **劳动者过错**：试用期不符条件、严重违纪等
2. **非劳动者过错**：需提前30日书面通知或额外支付1个月工资（N+1），且需支付经济补偿
3. **经济性裁员**：需符合法定程序，支付经济补偿

### 经济补偿金标准（劳动合同法第47条）

- 每满1年支付1个月工资
- 6个月以上不满1年按1年计算
- 不满6个月支付半个月工资
- 月工资标准：解除合同前12个月的平均工资（含奖金、津贴，不含加班费）
- 特别规定：月工资高于当地社平工资3倍的，按3倍计算，补偿年限不超过12年

### 违法解雇赔偿（劳动合同法第87条）

- 违法解雇需支付二倍经济补偿金（2N）
- 常见违法情形：未说明合法理由、未提前通知、未征求工会意见、违反禁止性规定

### N、N+1、2N 速查

| 情形 | 补偿标准 |
|------|---------|
| 协商解除、经济性裁员等 | N（经济补偿金） |
| 非过失性解除，未提前30天通知 | N+1 |
| 违法解除 | 2N（赔偿金） |

## 工伤认定

### 典型工伤情形

1. 工作时间、工作场所因工作原因受伤
2. 上下班途中非本人主要责任的交通事故
3. 患职业病
4. 因公外出因工作受伤

### 关键流程

1. 单位应在30日内申报工伤
2. 单位不申报的，劳动者/近亲属在1年内可自行申报
3. 认定工伤后进行劳动能力鉴定
4. 享受伤残待遇、医疗费用、停工留薪期工资等

## 休息休假

### 工时规定（劳动法第36条、第38条）

- 每日工作不超过8小时
- 平均每周不超过44小时
- 每周至少休息1日

### 带薪年假（职工带薪年休假条例）

| 累计工作年限 | 年休假天数 |
|------------|-----------|
| 1年不满10年 | 5天 |
| 10年不满20年 | 10天 |
| 20年以上 | 15天 |

### 女职工特殊保护

- 孕期、产期、哺乳期不得降薪、辞退或解除合同
- 违法解雇需支付赔偿金

## 维权途径与流程

### 维权四步走

```
第1步：协商 → 与用人单位沟通，明确诉求，出示证据
   ↓ 协商不成
第2步：投诉 → 拨打12333或前往当地人社局投诉
   ↓ 投诉无果
第3步：仲裁 → 向劳动仲裁委申请仲裁（1年时效）
   ↓ 对裁决不服
第4步：诉讼 → 15日内向法院起诉 → 可申请强制执行
```

### 劳动仲裁关键信息

- **时效**：1年（从知道权益受损之日起；拖欠工资争议在职期间不受限制，离职后1年内提出）
- **管辖**：劳动合同履行地或用人单位所在地
- **审理期限**：45日（可延15日）
- **费用**：免费
- **所需材料**：
  1. 仲裁申请书（载明双方信息、仲裁请求、事实理由）
  2. 申请人身份证复印件
  3. 被申请人企业信用信息
  4. 证据目录及证明文件

### 投诉渠道

| 渠道 | 号码/方式 | 适用场景 |
|------|----------|---------|
| 全国劳动保障维权热线 | 12333 | 拖欠工资、加班费、社保等 |
| 政务服务热线 | 12345 | 各类劳动权益问题咨询投诉 |
| 当地人社局 | 现场提交 | 书面投诉材料 |
| 线上平台 | 当地政务网/APP | 网上提交仲裁预申请 |
| 法律援助中心 | 12348 | 免费法律咨询和援助 |

## 证据收集指南

### 核心证据清单

| 证据类型 | 具体内容 |
|---------|---------|
| 劳动关系证明 | 劳动合同、入职登记表、录用通知、工牌、工服 |
| 工资记录 | 工资条、银行流水、转账记录 |
| 考勤记录 | 打卡记录、排班表、加班通知 |
| 工作沟通 | 工作群聊天记录、工作邮件、钉钉/企微记录 |
| 加班证据 | 加班通知（群消息/书面）、加班工作成果（日报、项目文件） |
| 解雇证据 | 解除劳动合同通知、离职证明、协商录音（合法取得） |
| 工伤证据 | 就医记录、诊断证明、报警记录 |

### 取证要点

- 谁主张谁举证：劳动者需证明加班事实和未足额支付报酬
- 企业掌握考勤等证据拒不提供的，承担不利后果
- 沟通时可以录音留存记录（合法取得）
- 证据应整理成册、标注序号、逐页编码

## 常见误区

| 误区 | 正确理解 |
|------|---------|
| "不定时工作制无三倍工资" | 仅经劳动部门审批的不定时工作制岗位才适用，普通岗位不适用 |
| "合同约定低于最低工资作为计算基数" | 加班工资基数不得低于当地最低工资标准 |
| "公司发过节福利就等于发了加班费" | 节日福利和加班费是两回事，不可互相替代 |
| "试用期可以随意辞退" | 需证明不符合录用条件，不能随意辞退 |
| "主动辞职就没有补偿" | 因单位违法（欠薪、不缴社保等）而辞职，仍可主张经济补偿 |
| "没签劳动合同就没法维权" | 可通过工牌、考勤、工资转账记录等证明事实劳动关系 |
| "仲裁太慢太麻烦" | 仲裁免费，45日内出结果，比诉讼高效 |
