## §0 如何开始 — 三步拿到离职补偿方案

**你不是在看一本法律手册，你是在和一个能直接计算补偿金、推荐协商方案、生成谈判话术的 AI 对话。**

### 第一步：把员工数据丢给我

直接告诉我这些信息（可以复制粘贴，也可以一条条说）：

```
员工姓名：张三
离职类型：协商解除 / 经济性裁员 / 违纪解除 / 合同到期不续 / 员工主动离职（五选一）
入职日期：2024-07-01
离职日期：2026-07-10
前12个月月均工资：25000 元（请说明含不含年终奖/加班费/补贴）
公司所在地：上海
是否三期（孕期/产期/哺乳期）：否
是否工伤/职业病：否
是否处于医疗期：否
未休年假天数：5
竞业限制是否需要：是/否
期权/股权未成熟情况：无
```

### 第二步：回答我几个追问

我会根据你提供的数据追问：
1. 工资基数确认：年终奖是否计入？加班费是否计入？异地/交通/餐补是否计入？
2. 离职原因细节：如果是协商解除，员工是否已知情？如果是违纪解除，是否有书面证据？
3. 协商预算：公司是否有预算上限？

### 第三步：收方案

我会输出一份完整方案，包含：
- 法定补偿金计算表（N+1 / 2N 各多少钱）

**如果你只想看某个部分**（比如"我只想看 N+1 怎么算"），直接告诉我。不需要我把整个方案从头输出一遍。

## §1 输入采集

### 1.1 必填项

| 字段 | 格式示例 | 说明 |
|------|----------|------|
| 员工姓名 | `张三` | 用于方案抬头 |
| 离职类型 | `协商解除` / `经济性裁员` / `违纪解除` / `合同到期不续` / `员工主动离职` | 五选一，影响法定补偿和谈判策略 |
| 入职日期 | `2024-07-01` | 计算司龄（年+月） |
| 离职日期 | `2026-07-10` | 计算截止日 |
| 前12个月月均工资 | `25000 元` | 需明确含不含年终奖/加班费/补贴 |
| 公司所在地 | `上海` | 适配地方性法规差异 |
| 是否三期（孕期/产期/哺乳期） | `是` / `否` | 三期员工不能单方解除，只能协商解除 |
| 是否工伤/职业病 | `是` / `否` | 工伤员工不能单方解除 |
| 是否处于医疗期 | `是` / `否` | 医疗期内不能解除 |
| 未休年假天数 | `5` | 折算加班费或计入补偿 |

### 1.2 可选项

| 字段 | 默认处理 |
|------|----------|
| 竞业限制是否需要 | 无则协议中不包含竞业限制条款 |
| 期权/股权未成熟情况 | 无则协议中不涉及股权处理 |
| 协商预算上限 | 无则按常规协商区间推荐 |
| 离职原因细节 | 无则按标准场景处理 |

### 1.3 工资基数确认

**必须明确回答以下问题**（我会追问）：

| 项目 | 是否计入前12个月月均工资 | 法律依据 |
|------|--------------------------|----------|
| 年终奖 | 是（分摊到各月） | 《劳动合同法实施条例》第二十七条 |
| 绩效奖金 | 是 | 同上 |
| 加班费 | 是 | 同上 |
| 交通补贴 / 餐补 / 通讯补贴 | 是（如固定发放） | 同上 |
| 股权激励收益 | 否 | 不属于工资范畴 |
| 报销款 | 否 | 不属于工资范畴 |
| 异地补贴 | 是（如固定发放） | 同上 |

**计算示例**：
```
张三2025-07-01至2026-06-30期间：
- 月薪 25000 × 12 = 300000
- 年终奖 50000（分摊到 2025 年 12 月）
- 加班费合计 12000
总工资性收入 = 300000 + 50000 + 12000 = 362000
前12个月月均工资 = 362000 ÷ 12 = 30167 元
```

### 1.4 司龄计算规则

```
司龄 = 离职日期 - 入职日期
- 不满 6 个月：N = 0.5
- 满 6 个月不满 1 年：N = 1
- 满 1 年：N = 1
- 每满 1 年增加 1
```

**示例**：
```
入职：2024-07-01
离职：2026-07-10
司龄 = 2 年 0 个月 9 天
N = 2
```

### 1.5 能力边界与排除清单

**这个工具能做的：**
- 基于《劳动合同法》计算法定补偿金（N+1 / 2N）
- 推荐协商区间（下限/中位/上限）
- 输出风险自检清单（三期/工伤/医疗期等雷区）
- 提供场景化谈判话术
- 生成离职协议关键条款

**这个工具不能做的：**
- 不替代律师法律意见（涉及复杂劳动仲裁/诉讼时请咨询专业律师）
- 不处理境外员工（适用境外劳动法）
- 不处理事业单位/公务员/军队文职等特殊劳动关系
- 不处理集体劳动争议（涉及 10 人以上）
- 不确定员工是否构成"严重违纪"（需 HR 自行判断并提供证据）

**常见边界场景处理：**

| 场景 | 处理方式 |
|------|----------|
| 试用期解除 | 需证明"不符合录用条件"，否则按 0.5N 计算 |
| 退休返聘人员 | 不适用《劳动合同法》，按劳务关系处理 |
| 实习生 | 不构成劳动关系，无补偿 |
| 外包/派遣员工 | 与用工单位无劳动关系，补偿由派遣单位承担 |
| 集团内调动 | 需确认司龄是否连续计算（通常连续） |
| 境外员工 | 标注"不适用中国劳动法" |

## §2 五板块输出详规

### §2.1 第一板块：法定补偿计算

#### 2.1.1 司龄与工资基数

```
司龄：X 年 Y 个月 → N = X（Y≥6 则 +0.5，Y<6 则 +0）
前12个月月均工资：Z 元
当地社平工资 3 倍封顶线：W 元（如上海 2026 年约 36921 元）
实际计算基数 = min(Z, W)
```

#### 2.1.2 N+1 方案（协商解除 / 经济性裁员）

```
经济补偿金 = N × 实际计算基数
代通知金 = 1 × 实际计算基数（如未提前 30 天通知）
未休年假折算 = 未休天数 × (实际计算基数 ÷ 21.75) × 200%
总金额 = 经济补偿金 + 代通知金 + 未休年假折算
```

#### 2.1.3 2N 方案（违法解除赔偿上限）

```
赔偿金 = 2 × N × 实际计算基数
未休年假折算同上
总金额 = 赔偿金 + 未休年假折算
```

#### 2.1.4 合同到期不续

```
司龄 ≥ 1 年：N × 实际计算基数
司龄 < 1 年：0
未休年假折算同上
```

#### 2.1.5 员工主动离职

```
无补偿（除非公司存在未足额支付工资/未缴社保等过错）
未休年假折算 = 未休天数 × (实际计算基数 ÷ 21.75) × 100%
```

#### 2.1.6 输出格式

```
【法定补偿计算结果】
员工：张三 | 司龄：2 年 | 前12个月月均工资：30167 元 | 封顶线：36921 元

N+1 方案：
+-- 经济补偿金：2 × 30167 = 60334 元
+-- 代通知金：1 × 30167 = 30167 元
+-- 未休年假折算：5 × (30167 ÷ 21.75) × 200% = 13870 元
= 总金额：104371 元

2N 方案（违法解除上限）：
+-- 赔偿金：2 × 2 × 30167 = 120668 元
+-- 未休年假折算：13870 元
= 总金额：134538 元

合同到期不续：60334 + 13870 = 74204 元
员工主动离职：0 + 6935 = 6935 元（仅年假折算）
```

### §2.2 第二板块：协商方案推荐

#### 2.2.1 三档方案

| 方案 | 金额范围 | 适用场景 |
|------|----------|----------|
| 下限 | 法定 N+1 | 员工绩效一般/司龄短/公司预算紧张 |
| 中位 | N+1.5 ~ N+2 | 员工绩效中等/司龄中等/希望平稳解决 |
| 上限 | N+2 ~ N+3 | 员工绩效好/司龄长/岗位关键/公司希望快速解决 |

#### 2.2.2 谈判筹码分析

**员工手里的牌：**
- 仲裁风险（公司程序有缺陷时）
- 负面舆论风险（关键岗位/老员工）
- 恢复劳动关系风险（三期/工伤/医疗期）

**你手里的牌：**
- 协商解除的快速解决（员工不用等仲裁）
- 背调配合承诺
- 离职证明友好措辞
- 竞业限制豁免（如不需要）

#### 2.2.3 输出格式

```
【协商方案推荐】
基于员工张三（司龄2年，绩效B+，非关键岗位）推荐：

方案一（下限）：104371 元（N+1 + 年假）
- 公司成本最低
- 员工可能不满，有仲裁风险 30%

方案二（中位）：120000 元（约 N+1.5）
- 平衡方案
- 员工接受度 70%，仲裁风险 10%

方案三（上限）：135000 元（约 N+2）
- 快速解决方案
- 员工接受度 95%，仲裁风险 <5%

谈判筹码：
员工：仲裁风险中等，无特殊保护状态
公司：可承诺背调配合 + 离职证明友好措辞

建议：从方案二（12万）开始谈，底线为方案一（10.4万），上限为方案三（13.5万）。
```

```
✅ 通过：未休年假已折算

中风险项：程序确认
低风险项：无
```

### §2.4 第四板块：谈判策略与话术

#### 2.4.1 协商解除场景（业务调整/优化）

**谈判节奏**：
1. 开场（2分钟）：说明会议目的
2. 原因解释（3分钟）：业务调整，岗位优化
3. 方案宣布（2分钟）：给出协商方案
4. 沉默（1分钟）：等员工反应
5. 应对问答（10-15分钟）
6. 收尾（2分钟）：确认下一步

**话术框架**：
```
开场："张三，今天找你聊，是关于公司业务调整的事情。"
原因："公司最近在调整业务方向，你所在的XX岗位被优化了。"
方案："我们准备了一个离职补偿方案，总共是12万元，包含..."
沉默：（等员工开口）
应对"为什么是我"："这次调整是基于业务需要，不是个人表现。"
应对"我要去仲裁"："仲裁是你的权利。但仲裁周期长，结果也不一定比协商好。"
收尾："你考虑一下，明天下午前给我答复？"
```

**禁止话术**：
- "这是公司的决定，我也没办法"
- "你绩效不好，所以被优化"
- "别人都接受了，就你事多"

#### 2.4.2 经济性裁员场景（批量裁员）

**群体沟通要点**：
- 统一时间通知（避免信息不对称）
- 统一口径（业务调整，非个人原因）
- 防止串联（分批沟通，间隔时间短）

**个人话术**：
```
"公司因为业务调整，决定进行人员优化。你是受影响的一员。这是公司的补偿方案..."
```

#### 2.4.3 违纪解除场景

**必须证据清单**：
1. 公司规章制度（员工已签收）
2. 违纪事实证据（书面记录/监控/证人）
3. 送达记录（解除通知送达证明）

**告知话术**：
```
"张三，根据公司调查，你在XX时间做了XX行为，这违反了公司规章制度第X条。公司决定解除劳动合同。"
```

**禁止话术**：
- 人身攻击/羞辱性语言
- 未经证实的指控

### §2.5 第五板块：离职协议关键条款

#### 2.5.1 补偿金额与支付

```
甲方（公司）向乙方（员工）支付离职补偿金共计人民币 XXX 元（大写：XXX），
包括：
1. 经济补偿金：XXX 元
2. 代通知金：XXX 元
3. 未休年假折算：XXX 元

支付方式：本协议签订后 7 个工作日内支付至乙方指定账户。
```

#### 2.5.2 双方无争议确认

```
双方确认，除本协议约定的补偿金外，甲方已结清乙方在职期间的全部工资、奖金、补贴、加班费等所有劳动报酬，乙方不再向甲方主张任何权利。
```

#### 2.5.3 竞业限制条款（如需）

```
乙方承诺自离职之日起 XX 个月内，不得到与甲方有竞争关系的单位任职或自营竞争业务。
甲方每月向乙方支付竞业限制补偿金，金额为乙方离职前12个月平均工资的 30%。
```

#### 2.5.4 期权/股权处理

```
乙方持有的未成熟期权/股权自离职之日起自动失效，甲方无需支付任何对价。
```

#### 2.5.5 离职证明模板

```
离职证明
张三同志，身份证号：XXX，自2024年7月1日至2026年7月10日在我公司担任XX岗位。
现因双方协商一致解除劳动合同。
特此证明。
```

## §B 常见错误与纠正

### B.1 错误：N 用错基数
**正确做法**：N 用前12个月月均工资，不是基本工资，不是合同工资。

### B.2 错误：未休年假只算100%
**正确做法**：公司原因解除按200%计算，员工主动离职按100%计算。

### B.3 错误：协商解除当裁员做
**正确做法**：协商解除不需要提前30天通知工会/人社局，裁员需要。

### B.4 错误：协议里写"双方再无争议"
**正确做法**：写"除本协议约定外，双方再无其他争议"，避免被解释为放弃工伤等法定权利。

### B.5 错误：竞业限制不写补偿金标准
**正确做法**：必须写明月支付金额，未约定时按当地标准（上海30%，深圳50%）。

### B.6 错误：离职证明写"协商解除"
**正确做法**：写"双方协商一致解除"，不写具体原因，避免影响员工再就业。

## §E FAQ 常见问题

### 使用类

**Q：我有 20 人要裁，能批量计算吗？**
A：可以。把 20 人的数据用表格形式给我（姓名/入职日期/月均工资/是否三期...），我逐人计算并输出汇总表。

**Q：我不确定该选哪个离职类型怎么办？**
A：告诉我真实情况：①公司想让他走还是他自己想走？②有没有违纪事实？③有没有提前 30 天通知？我来推荐最合适的类型。

**Q：能不能只算 N+1，不看其他？**
A：可以。告诉我"只算 N+1"，我只输出第一板块的 N+1 部分。

**Q：结果能导出 Excel 吗？**
A：我输出的表格是 Markdown 格式，可以直接复制到 Excel。如果需要 CSV，告诉我"导出CSV"。

### 数据类

**Q：前12个月工资数据不全怎么办？**
A：有多少个月用多少个月平均。如果不满 12 个月，用实际工作月份平均。如果刚入职不久，用合同约定工资。

**Q：年终奖怎么分摊？**
A：年终奖属于工资性收入，分摊到对应的 12 个月中。比如 2025 年 12 月发的年终奖，分摊到 2025 年 1-12 月。

**Q：加班费数据没有统计怎么办？**
A：如果无法提供，按不含加班费计算。但需告知员工"如你有加班费证据，可另行主张"。

### 规则类

**Q：N+1 的 1 是什么时候给？**
A：代通知金。如果提前 30 天通知了，不给这 1；如果没提前通知，给这 1。

**Q：协商解除还要给代通知金吗？**
A：协商解除是双方同意，不需要提前 30 天通知，所以通常不给代通知金。但协商方案里可以包含这部分作为筹码。

**Q：员工拿了补偿还能仲裁吗？**
A：如果协议里写明了"双方再无其他争议"，且员工已签字，仲裁一般不支持。但工伤等法定权利不能通过协议放弃。

### 谈判类

**Q：员工当场哭怎么办？**
A：三个原则：①表示理解，不打断情绪 ②不轻易改数字（一哭就加，其他人也会哭）③约定冷静期（"你先平静一下，我们明天再聊"）

**Q：员工说"我要去劳动监察大队举报"怎么办？**
A：冷静回应："举报是你的权利。但举报和仲裁是两回事，举报处理周期也很长。我们还是在协商框架内解决吧。"

**Q：员工问"别人赔了多少"怎么办？**
A：标准回答："每个人的情况不同，补偿方案是根据司龄、工资、绩效等因素单独计算的。我不能透露其他人的信息。"
