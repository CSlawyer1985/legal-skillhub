# 离职补偿金计算与协商策略生成器 - 需求说明书

## 1. 产品定位

面向 HR 和 HRBP 的离职补偿金计算与协商策略一键生成工具。无论公司主动裁员、协商离职、还是员工违纪解除，HR 的核心痛点不是"不知道 N+1 是什么意思"——百度一下谁都会——而是：我的真实数据丢进去，法定该赔多少钱？协商该给多少？谈判时怎么开口？风险在哪里？本工具将"法律条文查半天 + Excel 拉到手抽筋 + 谈之前心里没底"三合一，升级为一键方案生成。

## 2. 痛点

1. **金额算不准**：N+1 的 N 到底用哪个工资基数？前12个月均薪含不含年终奖、含不含加班费、含不含异地补贴？算错一个月，差额上千元，员工仲裁直接败诉。

2. **不知道协商给多少**：法律规定 N+1，但 HR 实际会协商 1.5N 或 2N。给多少既能安抚员工情绪、又不让老板觉得你太慷慨？需要一个数据驱动的谈判区间，而不是"凭感觉"。

3. **不会谈判**：HR 不是专业谈判手，面对情绪激动的员工——"为什么是我""我不接受这个方案""我明天就去仲裁"——很多 HR 脑子一片空白。需要场景化的谈判脚本。

4. **风险盲区**：三期员工不能裁、工伤员工不能裁、医疗期内不能裁——这些基本规则大家都知道。但"刚休完产假回来的员工裁员怎么处理""工伤认定中但还未出结果的员工"这种边界场景，才是真正让 HR 踩坑的地方。

5. **协议书写不好**：离职协议看似简单，真出问题的往往是"甲方不再向乙方主张任何权利"这种笼统条款。竞业限制要不要启动？期权未成熟部分怎么处理？离职证明怎么写不违法？

## 3. 目标用户

- 薪酬 HR / C&B 专员（计算补偿金额、核对数据）
- HRBP（执行协商谈判、起草协议）
- HRD / 法务（审批方案、复核风险点）
- 中小公司 HR 负责人（没有法务团队，全流程一肩挑）

## 4. 核心功能

### 4.1 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 员工姓名 | 是 | 用于输出方案抬头 |
| 离职类型 | 是 | 协商解除 / 经济性裁员 / 违纪解除 / 合同到期不续 / 员工主动离职 五选一 |
| 入职日期 | 是 | 计算司龄 |
| 离职日期 | 是 | 计算截止日 |
| 前12个月月均工资 | 是 | 需明确含不含年终奖/加班费/补贴——系统会追问 |
| 是否三期（孕期/产期/哺乳期） | 是 | 触发高风险标注 |
| 是否工伤/职业病 | 是 | 触发特殊保护 |
| 是否处于医疗期 | 是 | 触发特殊保护 |
| 未休年假天数 | 是 | 折算加班费或计入补偿 |
| 竞业限制是否需要 | 否 | 影响协议条款 |
| 期权/股权未成熟情况 | 否 | 影响离职结算条款 |
| 公司所在地 | 是 | 适配地方性法规差异 |
| 协商预算上限（可选） | 否 | 如公司有协商预算限制 |

### 4.2 输出结构（五板块）

#### 第一板块：法定补偿计算

- 司龄精确计算（年+月，不满半年算0.5，满半年不满一年算1）
- 工资基数确认（前12个月均薪，含绩效奖金、年终奖分摊、固定补贴，不含股权激励收益、报销款）
- N+1 方案金额明细（经济补偿金 + 代通知金，逐项拆解计算公式）
- 2N 方案金额明细（违法解除场景的赔偿金上限）
- 未休年假折算金额
- 月工资上限调整（超过当地社平工资3倍时按3倍封顶）

#### 第二板块：协商方案推荐

- 区间建议（下限：法定最低 / 中位线：均衡方案 / 上限：公司可接受的最高方案）
- 三个方案的金额对比表（员工到手多少、公司总成本多少）
- 方案选择的判定依据（员工绩效/司龄/岗位稀缺度/离职真实原因/公司风险偏好）
- 谈判筹码分析：员工手里的牌 vs 你手里的牌

#### 第三板块：风险自检清单

- 三期/工伤/医疗期/职业病 → 红色雷区（禁止解除，强行解除 = 2N + 恢复劳动关系风险）
- 职业病危害岗位未做离职体检 → 黄色警告
- 经济性裁员程序缺陷（未提前30天通知工会/人社局）→ 黄色警告
- 试用期解除证据不足 → 黄色警告（需证明"不符合录用条件"）
- 竞业限制未明确启动 → 灰色提示

#### 第四板块：HR 谈判策略与话术

按离职类型分场景输出：

- **协商解除场景**："公司业务调整，你的岗位被优化了"
  - 谈判节奏（谁先开口/什么时候抛数字/什么时候沉默）
  - 开场话术 / 数字宣布话术 / 应对"为什么是我"话术 / 应对"我要去仲裁"话术
  - 禁止话术清单

- **经济性裁员场景**："公司批量裁员，你是其中一位"
  - 群体沟通要点（统一口径/统一时间/防止串联）
  - 个人话术

- **违纪解除场景**："你的行为构成严重违纪，公司决定解除劳动合同"
  - 必须证据清单（制度依据/违纪事实/送达记录 三件套缺一不可）
  - 告知话术（严肃但不羞辱/陈述事实不给评价）

#### 第五板块：离职协议关键条款

- 补偿金额与支付时间
- 双方无争议确认条款（含兜底范围建议）
- 竞业限制条款（是否启动 / 如果不启动需书面豁免）
- 期权/股权处理条款
- 离职证明文字模板
- 保密义务延续条款

### 4.3 异地规则适配

中国各省市在离职补偿金方面有地方性差异，需支持：

| 地区 | 特殊规则 |
|------|----------|
| 上海 | 社平工资2025年约12307元/月，封顶基数36921元；经济性裁员需提前30日向工会或全体职工说明 |
| 北京 | 社平工资较高，封顶线相应较高；三期员工保护力度全国最强 |
| 深圳 | 经济特区有部分灵活规定；竞业限制补偿金标准为离职前12个月均薪的50% |
| 广州 | 与省规定一致，无特殊地方差异 |
| 其他 | 按《劳动合同法》国家标准计算 |

### 4.4 异常处理

- **月均工资计算争议**：含不含年终奖/加班费/异地补贴/股权收益？→ 逐项明确计算口径，遇争议按对员工有利的原则提示
- **司龄跨多个法律主体**：员工在集团内不同主体调动 → 提示"需确认前后司龄是否连续计算"
- **工伤认定进行中**：结果未出时暂停解除程序，先行标注不可操作
- **三期员工协商解除**：三期员工法律上不能单方解除，但允许协商解除（员工主动同意）→ 需书面确认员工自愿
- **协商破裂预案**：如果协商失败，备选方案是什么？（走正式裁员流程 / 调岗 / 维持现状等）
