# 第 508 条／WCAG 2.0 AA——详细参考

## 第 508 条条款映射

| 508 条款 | 范围 | WCAG 对应 |
|---------------|-------|-----------------|
| E205.2 | 网页内容 | WCAG 2.0 A 级和 AA 级 |
| E205.3 | 电子文档 | WCAG 2.0 A 级和 AA 级（适用时） |
| E205.4 | 软件（用户界面） | WCAG 2.0 A 级和 AA 级 |
| E204 | 创作工具 | WCAG 2.0 A 级和 AA 级 |
| 第 3 章 | 功能性能标准 | 无视觉、颜色、听觉、言语、精细运动、认知限制 |
| 第 4 章 | 硬件 | 物理 ICT 可访问控制、显示、间隙 |
| 第 6 章 | 支持文档和服务 | 以无障碍格式提供的文档和帮助 |

## WCAG 2.0 A 级成功标准——常见失败

### 1.1.1 非文本内容
- **失败：** `<img>` 缺少 `alt` 属性，或信息性图片使用 `alt=""`
- **失败：** 无无障碍名称的图标按钮（`aria-label` 或 `aria-labelledby`）
- **失败：** 无描述数据的文本替代方案的图表和图形
- **测试：** 自动化（axe、WAVE）＋人工屏幕阅读器审查
- **修复：** 添加有意义的 `alt` 文本；仅对装饰性图片使用 `alt=""`；对仅图标的按钮使用 `aria-label`

### 1.3.1 信息和关系
- **失败：** 视觉标题未用 `<h1>`–`<h6>` 标记（改用样式化的 `<div>` 或 `<span>`）
- **失败：** 数据表无 `<th>` 或 `scope` 属性
- **失败：** 表单字段的视觉标签未以编程方式关联（缺少 `<label for="">` 或 `aria-labelledby`）
- **失败：** 必填字段仅以颜色或星号标示，无屏幕阅读器可访问的文本
- **测试：** DOM 检查、NVDA／JAWS、自动化（部分）
- **修复：** 优先使用语义 HTML；仅当语义 HTML 不足时才使用 `aria-*` 属性

### 2.1.1 键盘
- **失败：** 自定义下拉框、日期选择器、模态对话框无法通过键盘操作
- **失败：** 仅鼠标事件处理器（非交互元素上的 `onclick`、无 `focus` 对应的 `mouseover`）
- **失败：** 拖放无键盘替代方案
- **失败：** 模态框中的键盘陷阱——Tab 仅在模态框内循环但无法关闭
- **测试：** 用 Tab 遍历整页；激活所有控件；打开／关闭模态框
- **修复：** 尽可能使用原生 HTML 控件；对自定义组件，实现 ARIA 键盘模式（ARIA 创作实践指南）

### 1.4.1 颜色的使用
- **失败：** 表单验证错误仅以红色边框显示，无文本或图标
- **失败：** 必填字段指示仅用颜色（红色星号，无“必填”文本）
- **失败：** 链接文本颜色是区别于周围正文的唯一方式（无下划线或其他视觉线索）

### 4.1.2 名称、角色、值
- **失败：** 用 CSS 样式化的自定义复选框／单选按钮，无 ARIA 角色或选中状态
- **失败：** 选项卡面板无 `role="tab"`、`role="tablist"`、`aria-selected`
- **失败：** 切换按钮无 `aria-pressed` 属性
- **失败：** 展开／折叠手风琴无 `aria-expanded`
- **测试：** 在浏览器无障碍树中检查 ARIA 属性；用 NVDA／JAWS 测试
- **修复：** 对每种组件类型遵循 WAI-ARIA 创作实践指南的模式

## WCAG 2.0 AA 级成功标准——常见失败

### 1.4.3 对比度（最低）
- 普通文本（< 18pt 或 < 14pt 加粗）：与背景的最低对比度 **4.5:1**
- 大文本（≥ 18pt 或 ≥ 14pt 加粗）：最低 **3:1**
- **失败：** 白色背景上的浅灰色文本（例如 #FFFFFF 上的 #767676 ＝ 4.48:1——不满足 AA）
- **失败：** 输入字段中的占位符文本（常不达标；占位符不能替代标签）
- **例外：** 徽标中的文本、非活动 UI 组件、装饰性文本
- **工具：** WebAIM 对比度检查器、Color Contrast Analyser（桌面应用）、浏览器开发者工具

### 1.4.4 调整文本大小
- **失败：** CSS `@media` 查询内以 `px` 单位渲染文本，阻止浏览器缩放按比例调整文本
- **失败：** 固定高度容器在放大到 200% 时裁剪文本
- **修复：** 字体大小和容器高度使用相对单位（`rem`、`em`）；在 200% 浏览器缩放下测试

### 2.4.5 多种方式
- **要求：** 提供至少两种查找内容的方式：搜索＋导航，或站点地图＋导航
- **例外：** 作为流程结果产生的页面（例如结账确认页）被排除

### 2.4.7 焦点可见
- **失败：** CSS `outline: none` 或 `outline: 0` 移除默认焦点环且无替代
- **失败：** 焦点环存在但与背景颜色对比不可见
- **修复：** 绝不在无替代的情况下移除焦点样式；使用 `focus-visible` CSS 伪类

### 3.3.3 错误建议
- **失败：** 表单验证只说“输入无效”而不说明问题所在或如何修复
- **修复：** “请输入 MM/DD/YYYY 格式的日期”——具体、可操作的建议

### 3.3.4 错误预防
- **要求：** 对法律、财务或数据删除类交易：提供审查并确认步骤，或允许提交被逆转／取消

## 功能性能标准（第 3 章）——第 508 条

| 标准 | 要求 |
|-----------|-------------|
| 302.1 无视觉 | 至少一种可在无视觉情况下操作的模式（屏幕阅读器支持） |
| 302.2 有限视觉 | 至少一种具备适应有限视觉功能的模式（缩放、高对比度） |
| 302.3 无颜色感知 | 颜色不是传达信息的唯一手段 |
| 302.4 无听觉 | 至少一种可在无听觉情况下操作的模式（字幕、转录文本、视觉警报） |
| 302.5 有限听觉 | 至少一种具备适应有限听觉功能的模式（音量控制、字幕） |
| 302.6 无言语 | 至少一种可在无言语情况下操作的模式 |
| 302.7 有限操控 | 至少一种可在无精细运动控制情况下操作的模式（无同时按键、无计时动作） |
| 302.8 有限触及范围和力量 | 至少一种适应有限触及范围的模式（可达的控制） |
| 302.9 有限语言、认知和学习能力 | 至少一种适应有限认知能力的模式 |

## 辅助技术测试矩阵

| 辅助技术＋浏览器 | 主要用例 | 备注 |
|--------------|-----------------|-------|
| JAWS＋Chrome | 联邦机构标准；美国政府部门最常见的屏幕阅读器 | 测试所有交互组件、表单流程、动态内容（ARIA 活动区域） |
| NVDA＋Chrome 或 Firefox | 开源；广泛用于测试；VPAT 测试必需 | 免费；覆盖面广 |
| VoiceOver＋Safari（macOS） | Mac 用户；产品面向 Mac／iOS 时必需 | 键盘快捷键：Cmd+F5 |
| VoiceOver＋Safari（iOS） | 移动网页和原生 iOS 应用 | 滑动导航；三击 Home／侧边按钮激活 |
| TalkBack＋Chrome（Android） | Android 网页和原生应用 | 滑动导航；在无障碍设置中激活 |
| Dragon NaturallySpeaking | 语音控制用户 | 测试所有链接文本和按钮标签可被口述 |
| 仅键盘 | 影响最大的测试；能发现大多数 2.1.x 失败 | Tab、Shift-Tab、Enter、Space、方向键 |
| 高对比度模式（Windows） | 操作系统级对比度覆盖 | 确保无信息丢失；图片不得消失 |
| 浏览器缩放 200% | SC 1.4.4 | 检查水平滚动、内容重叠、文本裁剪 |
| ZoomText／放大镜 | 低视力用户 | 以 4 倍放大测试 |

## VPAT 中常见的采购缺陷

1. **过时模板** ——使用 VPAT 1.x 而非 VPAT 2.x（WCAG 版）。拒绝并要求重新提交。
2. **无证据的“支持”** ——供应商声称支持但无备注。要求对每项“支持”主张作出解释。
3. **过度使用“不适用”** ——供应商无正当理由将标准标记为不适用。提出质疑：几乎没有产品对交互标准有 100% 的不适用。
4. **缺少功能性能标准** ——供应商完全跳过第 3 章。所有 ICT 均须包含。
5. **未披露测试方法** ——VPAT 必须说明测试如何进行（自动化工具、辅助技术＋浏览器组合、日期）。
6. **版本不匹配** ——VPAT 覆盖 1.0 版，但机构采购的是 2.0 版。要求提供所采购确切版本的 VPAT。
