# CMMC 2.0——全部 110 项实践（NIST SP 800-171 Rev 2 映射）

等级代码：**L1** = 第 1 级（17 项实践）· **L2** = 第 2 级（全部 110 项）· **L3** = 第 3 级（110 项 + SP 800-172 增强）

## AC——访问控制（22 项实践）

| 实践编号 | 等级 | 要求 |
|-------------|-------|-------------|
| AC.L1-3.1.1 | L1 | 将系统访问权限限制于授权用户、代表授权用户行事的进程以及设备（包括其他系统）。 |
| AC.L1-3.1.2 | L1 | 将系统访问权限限制于授权用户被允许执行的事务类型和功能类型。 |
| AC.L2-3.1.3 | L2 | 按照经批准的授权控制 CUI 的流动。 |
| AC.L2-3.1.4 | L2 | 分离人员的职责，以降低无需合谋即可从事恶意活动的风险。 |
| AC.L2-3.1.5 | L2 | 采用最小权限原则，包括针对特定安全功能和特权账户。 |
| AC.L2-3.1.6 | L2 | 访问非安全功能时使用非特权账户或角色。 |
| AC.L2-3.1.7 | L2 | 防止非特权用户执行特权功能，并在审计日志中记录执行情况。 |
| AC.L2-3.1.8 | L2 | 限制不成功的登录尝试。 |
| AC.L2-3.1.9 | L2 | 提供与 CUI 规则一致的隐私和安全通知。 |
| AC.L2-3.1.10 | L2 | 在一段时间不活动后使用带图案隐藏显示器的会话锁定。 |
| AC.L2-3.1.11 | L2 | 在定义的条件出现后（自动）终止用户会话。 |
| AC.L2-3.1.12 | L2 | 监控和控制远程访问会话。 |
| AC.L2-3.1.13 | L2 | 采用加密机制保护远程访问会话的机密性。 |
| AC.L2-3.1.14 | L2 | 通过受管理的访问控制点路由远程访问。 |
| AC.L2-3.1.15 | L2 | 仅对已记录的运营需要，授权通过远程访问执行特权命令和访问安全相关信息。 |
| AC.L2-3.1.16 | L2 | 在允许连接之前授权无线访问。 |
| AC.L2-3.1.17 | L2 | 使用认证和加密保护无线访问。 |
| AC.L2-3.1.18 | L2 | 控制移动设备的连接。 |
| AC.L2-3.1.19 | L2 | 加密移动设备和移动计算平台上的 CUI。 |
| AC.L2-3.1.20 | L2 | 验证并控制/限制与外部系统的连接。 |
| AC.L2-3.1.21 | L2 | 限制在外部系统上使用便携式存储设备。 |
| AC.L2-3.1.22 | L2 | 控制发布或处理于可公开访问系统上的 CUI。 |
