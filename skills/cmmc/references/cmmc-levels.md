# CMMC 2.0——级别比较、评估类型与下传规则

## 级别比较表

| 属性 | 第 1 级——基础 | 第 2 级——高级 | 第 3 级——专家 |
|-----------|----------------------|-------------------|-----------------|
| **实践** | 17 项（FAR 52.204-21） | 110 项（NIST SP 800-171 Rev 2） | 110+ 项（SP 800-171 + SP 800-172 子集） |
| **重点** | 联邦合同信息（FCI） | 受控非密信息（CUI） | 国防部最高优先项目上的 CUI；APT 弹性 |
| **评估类型** | 年度自我评估 | 三年期 C3PAO 评估（关键项目）或自我评估（非关键项目） | DIBCAC 主导的政府评估（三年期） |
| **SPRS 提交** | 是 | 是 | 是 |
| **认证机构** | 自我 | C3PAO（CMMC 第三方评估组织） | DIBCAC（国防工业基础网络安全评估中心） |
| **有条件认证** | 否 | 是（允许有限 POA&M） | 否 |
| **谁需要** | 所有接收/生成 FCI 的国防部承包商 | 在国防部合同上处理 CUI 的承包商 | 最高优先项目（如核指挥控制、特定武器系统）的承包商 |

## DFARS 条款映射

| DFARS 条款 | 要求 | 隐含级别 |
|-------------|-------------|---------------|
| FAR 52.204-21 | FCI 基本保护——15 项要求 | 第 1 级基线 |
| DFARS 252.204-7012 | 保护 CUI；72 小时 DIBNET 事件报告；云 = FedRAMP Moderate | 第 2 级前提 |
| DFARS 252.204-7019 | NIST SP 800-171 自我评估；须提交 SPRS | 第 2 级自我评估 |
| DFARS 252.204-7020 | 国防部访问承包商在 SPRS 中的评估结果 | 第 2 级 |
| DFARS 252.204-7021 | CMMC 认证要求；下传至分包商 | 第 2 或 3 级 |

**规则**：如你的合同包含 DFARS 252.204-7021，你的 CMMC 级别在合同中指明。检查 L 部分或绩效工作说明（PWS）。

## 按级别的评估流程

### 第 1 级——自我评估
1. 对照 FAR 52.204-21 评估全部 17 项实践
2. 计算并提交 SPRS 分数（17 项实践，满分 17，每项 1 分）
3. 提交至 https://www.sprs.csd.disa.mil/ 的 SPRS
4. 高级官员确认准确性
5. 每年重复

### 第 2 级——C3PAO 评估（关键项目）
1. **评估前准备**（6-12 个月）：SSP、POA&M、差距整改
2. **选择 C3PAO**：必须是 CMMC-AB 授权；在 cyberAB.us 查找
3. **与 C3PAO 签约**：商定范围、时间表、保密协议
4. **评估**：C3PAO 审查证据、访谈、观察（通常现场/远程 2-4 周）
5. **发现**：CMMC-AB 接收结果；有限 POA&M 时可能获得有条件认证
6. **认证**：由 CMMC-AB 颁发；有效期 3 年
7. **年度确认**：每年确认持续合规

### 第 2 级——自我评估（非关键项目）
- 与 C3PAO 路径相同的 110 项实践
- 由承包商自我评估；高级官员在 SPRS 中确认
- 国防部保留审计权；虚假陈述 = 虚假申报法责任
- 仍须提交 SPRS 分数

### 第 3 级——DIBCAC 评估
1. 承包商必须首先持有有效的第 2 级 C3PAO 认证
2. DIBCAC（政府团队）进行评估——不由承包商选择
3. 评估 SP 800-171 实践以及选定的 SP 800-172 增强要求
4. 无有条件认证——所有实践必须达成（MET）
5. 政府安排评估；无商业谈判

## 下传要求

DFARS 252.204-7021(c) 要求总承包商：
- 在分包商处理、存储或传输 CUI 的**所有分包合同**中纳入 CMMC 要求
- 在分包合同中指明要求的 CMMC 级别
- 授标前核实分包商认证（第 2/3 级必须出现在 SPRS/CMMC-AB 登记册中）
- 下传适用于**所有层级**——次级分包商不豁免

**实际影响**：如你是总承包商，将你的 CUI 映射到每个分包商，并确定适用于各方的级别。在供应链安全计划中记录此内容。

## 国防合同中常见的 CUI 类别

| CUI 类别 | 示例 | 典型合同类型 |
|-------------|----------|----------------------|
| 出口管制（CTI） | 技术数据、软件、图纸 | 工程、制造 |
| 海军核推进（NOFORN） | 推进设计数据 | 造船、核 |
| 受控技术信息（CTI） | ITAR/EAR 管制的技术数据 | 武器系统、航空航天 |
| 隐私（PII） | 人事记录 | 人力资源、健康、福利 |
| 执法敏感 | 调查数据 | 基地安保承包商 |
| 采购/采办 | 授标前合同信息 | 提案/业务发展团队 |

## 关键定义

| 术语 | 定义 |
|------|-----------|
| **FCI** | 联邦合同信息——根据合同由政府提供或为政府生成、不打算公开发布的信息 |
| **CUI** | 受控非密信息——政府创建或持有、依法律/法规/政策需要保护的信息 |
| **SPRS** | 供应商绩效风险系统——提交自我评估分数的国防部门户 |
| **C3PAO** | CMMC 第三方评估组织——获授权开展第 2 级评估 |
| **DIBCAC** | 国防工业基础网络安全评估中心——开展第 3 级政府评估的 DCSA 组织 |
| **CMMC-AB** | Cyber AB——认证 C3PAO、评估员和顾问的认可机构 |
| **OSC** | 寻求认证的组织——被评估的国防承包商 |
| **POA&M** | 行动与里程碑计划——对未达成实践的有记录整改计划 |
| **SSP** | 系统安全计划——描述系统边界、CUI 流向和控制实施 |
