### 一、认定数据三方一致
- 📊 **同源核查**：向工信/科技/税务三方报送的研发与财务数据同源一致，避免抽查剔除。
- ⚠️ **高频风险**：生产费混入研发、口径不一导致认定被否或撤销。
- 🛡️ **合规申报**：建立"一套底层明细、多口径映射"核算体系，留存证据链。

**典型问法：**
```
"认定研发数据和税务怎么一致？"
"专精特新和高新研发费口径一样吗？"
```

### 二、财政奖补资金涉税
- 💰 **不征税收入决策**：依据财税〔2011〕70号选择作/不作不征税收入，单独核算。
- ⚠️ **权衡要点**：作不征税收入则对应支出不得扣除；不作则支出可扣。
- 🛡️ **台账管理**：专项用途资金隔离建账，5年内未支出部分须计入应税收入。

**典型问法：**
```
"财政奖补资金要交税吗？"
"不征税收入对应支出能扣除吗？"
```

### 三、研发加计与高新15%维持
- 📊 **双口径协同**：研发加计100%、高新减按15%，同一费用不得重复归集。
- ⚠️ **高频风险**：套用高新20%上限做加计、高新收入混淆、资格到期未续。
- 🛡️ **资格维持**：到期前6个月重新认定，年度报表按时填报，核心占比持续监测。

**典型问法：**
```
"高新和研发加计口径能混用吗？"
"小巨人资格到期怎么续？"
```

### 四、北交所上市税务规划
- 📈 **时间轴前置**：T-3自查清理、T-2规范关联/发票/研发、T-1股改与合规证明、T年披露问询。
- ⚠️ **审核红线**：优惠依赖过高、历史补税、研发真实性、跨境税务瑕疵。
- 🛡️ **问询支撑**：以证据链回应税收优惠可持续性与兜底安排。

**典型问法：**
```
"小巨人北交所上市税务怎么规划？"
"上市前税务自查做什么？"
```

### 五、股改与关联交易
- 🧮 **股改个税**：有限公司变股份公司净资产折股，个人股东留存收益转增按20%缴个税。
- 🔗 **关联定价**：独立交易原则，准备同期资料防范利润转移调整。
- ⚠️ **风险点**：资本公积（股本溢价）转增有专门口径须区分。

## 重要提示与边界声明

**重要提示**
1. **口径以官方为准**：政策文号、比例、时限以税务总局/财政部/工信部最新规定为准，落地前须联网核验。
2. **资质非优惠**：专精特新"小巨人"本身不直接产生税率优惠，须以独立资质（高新、研发加计等）依法享受。
3. **数据须一致**：向三方报送的财务与研发数据须同源，口径差异须有底层依据。
4. **提前规划**：股改、重组、上市等重大交易须前置税务规划，避免事后调整成本。

**边界（本技能不做的）**
- **不代办**：资质申报、税收优惠备案等需登录操作的事项
- **不代理**：税务争议代理等需执业资质的事务
- **不担保**：优惠认定、稽查结论等最终以主管机关为准

**服务说明**
- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告

**隐私保护**
- 仅在本机生成随机匿名标识用于服务调用，不会采集任何设备信息或个人隐私数据。
