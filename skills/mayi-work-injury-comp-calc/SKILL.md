## 一句话定位

中国工伤待遇精算引擎，覆盖1-10级伤残补助 × 停工留薪期工资 × 伤残津贴 × 解除合同补助，让HR和工伤职工看清工伤后的"工资条"。

## 触发场景

- 用户问"工伤期间工资怎么发"
- 用户问"十级伤残能赔多少"
- 用户问"停工留薪期多长时间"
- 用户问"一次性伤残补助金怎么算"
- 用户问"工伤解除合同有哪些补助"
- 用户问"一级伤残每月津贴多少"

## 核心能力

| 能力 | 说明 |
|------|------|
| 停工留薪期工资 | 按工伤前12个月平均工资计算，一般不超过12个月 |
| 一次性伤残补助金 | 按1-10级伤残等级×本人工资×对应月数计算 |
| 伤残津贴(1-4级) | 按本人工资的90%/85%/80%/75%按月发放 |
| 一次性医疗/就业补助金 | 5-10级解除劳动合同时发放（各省标准不同） |

## 技术特点

- **Decimal 财务精度**：全量 `Decimal` + `ROUND_HALF_UP`，金额精确到分
- **1-10级全覆盖**：伤残等级完整映射，补助月数精确匹配
- **停工留薪引擎**：支持自定义停工留薪月数，默认不超过12个月
- **解除合同判断**：5-10级支持是否解除劳动关系的补助计算

## 使用方式

```bash
# 十级伤残，工伤前月均工资6000，停工留薪3个月，不解除合同
python scripts/work_injury_calc.py --monthly-salary 6000 --disability-level 10 --suspend-period 3

# 七级伤残，工伤前月均工资8000，停工留薪6个月，解除合同
python scripts/work_injury_calc.py --monthly-salary 8000 --disability-level 7 --suspend-period 6 --terminate

# 一级伤残，工伤前月均工资5000，停工留薪12个月
python scripts/work_injury_calc.py --monthly-salary 5000 --disability-level 1 --suspend-period 12
```

## 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `--monthly-salary` | float | 是 | 工伤前12个月平均月工资（元） |
| `--disability-level` | int | 是 | 伤残等级（1-10级） |
| `--suspend-period` | int | 否 | 停工留薪期月数，默认3个月 |
| `--terminate` | flag | 否 | 是否解除劳动关系（仅5-10级适用） |
| `--list-levels` | flag | 否 | 列出1-10级伤残待遇标准 |

## 数据说明

- 伤残补助金月数依据《工伤保险条例》第三十五条至第三十七条
- 停工留薪期一般不超过12个月，伤情严重可延长但不超过12个月
- 1-4级伤残津贴按月发放，5-10级不发放伤残津贴
- 一次性医疗/就业补助金标准因省而异，本工具按全国通用标准估算
- 实际结果以工伤保险经办机构核算为准

## 政策来源

- 《工伤保险条例》（国务院令第586号，2011年修订）
- 《人力资源社会保障部关于执行〈工伤保险条例〉若干问题的意见》
- 各省工伤保险实施细则（一次性医疗/就业补助金标准）
