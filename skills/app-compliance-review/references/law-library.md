### 5. App违法违规收集使用个人信息行为认定方法

| 项目 | 内容 |
|------|------|
| 文号 | 国信办秘字〔2019〕191号 |
| 发布日期 | 2019.11.28 |
| 现行状态 | 现行有效 |
| 效力级别 | 部门规章 |
| 北大法宝链接 | https://www.pkulaw.com/lar/20707917239546b4bdfb.html |

**六大类违规行为认定标准：**

| 章节 | 内容 | 适用检查模块 |
|------|------|-------------|
| §1 | 可认定为"未公开收集使用规则"的情形（无隐私政策、未首次弹窗提示、难以访问、难以阅读） | M1 |
| §2 | 可认定为"未明示收集使用个人信息的目的、方式和范围"的情形（未逐一列出、未同步告知变更、未同步告知权限/敏感信息目的） | M1 |
| §3 | 可认定为"未经用户同意收集使用个人信息"的情形（同意前收集、拒绝后仍收集/频繁索要、超授权范围、默认勾选同意、未经同意改权限、未提供非定向推送选项、诱导采集、未提供撤回途径、违反声明规则） | M2 |
| §4 | 可认定为"违反必要原则，收集与其提供的服务无关的个人信息"的情形（与业务功能无关、拒绝非必要信息则拒绝服务、新增功能超范围则拒原有服务、频率超需要、以非必要理由强制收集） | M3 |
| §5 | 可认定为"未经同意向他人提供个人信息"的情形（未经同意+未匿名化向第三方提供、接入第三方应用未经同意提供） | M5 |
| §6 | 可认定为"未按法律规定提供删除或更正个人信息功能"或"未公布投诉、举报方式等信息"的情形 | M7 |

### 6. 常见类型移动互联网应用程序必要个人信息范围规定

| 项目 | 内容 |
|------|------|
| 文号 | 国信办秘字〔2021〕14号 |
| 发布日期 | 2021.03.12 |
| 施行日期 | 2021.05.01 |
| 现行状态 | 现行有效 |
| 效力级别 | 部门规范性文件 |
| 北大法宝链接 | https://www.pkulaw.com/lar/c82ff05cc0f2a6a4bdfb.html |

**核心内容：** 规定39类常见APP的基本功能服务及其必要个人信息范围。APP不得因用户不同意收集非必要个人信息而拒绝提供基本功能服务。

常见类型必要范围举例：
- 网上购物类：注册手机号、收货人姓名地址电话、支付信息
- 餐饮外卖类：注册手机号、收货人姓名地址电话、支付信息
- 即时通讯类：注册手机号、账号列表
- 网络支付类：注册手机号、本人姓名、证件类型和号码、银行卡号
- 网约车类：注册手机号、乘车人出发地、到达地、位置信息、支付信息
- 运动健身类：无须个人信息即可使用基本功能

## 四、团体标准（T/TAF系列）

T/TAF系列标准由电信终端产业协会（TAF）发布，虽非强制性国家标准，但在工信部APP专项治理检测中作为重要测评依据，是APP合规审查的实操指引。

### 20. T/TAF 077 APP收集使用个人信息最小必要评估规范（系列）
