# 条文锚定表（Article Anchors）

> **用途**：本表将skill引用的每一条合规义务依据与具体法规条款建立程序化映射。skill每次运行时，通过运行时检测到的MCP后端（北大法宝pkulaw或华宇元典yuandian，自动扫描已连接连接器，详见SKILL.md"MCP法规核验后端"章节）按锚点核验法规现行有效性与条款内容，确保在法规频繁修订场景下依据始终准确。

## 使用方法

### 1. 锚点结构

每个锚点（anchor）包含以下字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| `anchor_id` | 锚点唯一编号 | A001 |
| `law_title` | 法规全称 | 中华人民共和国个人信息保护法 |
| `law_doc_no` | 文号（如有） | 主席令第91号 |
| `article_number` | 条款编号（中文） | 第十七条 |
| `article_topic` | 条款主题摘要 | 告知义务 |
| `law_search_key` | 法规检索关键词（传入MCP后端的检索词） | 个人信息保护法 |
| `law_article_no` | 条款中文编号（传入MCP后端的条款编号参数） | 十七 |
| `linked_checks` | 关联的检查项编号 | M1-1, M1-6 |
| `verify_freq` | 核验频率 | every_run / quarterly |
| `last_verified` | 上次核验日期 | 2026-07-05 |

### 2. MCP核验流程（支持双后端）

skill每次运行时，先读取 `assets/mcp-backends.yaml` 确认用户配置的活跃后端（pkulaw或yuandian），然后按对应后端的工具映射执行核验：

**后端1：北大法宝（pkulaw）** — WorkBuddy内置连接器，无需额外配置

```
对article-anchors.md中每个anchor：
  1. 调用 mcp__pkulaw__mcp-law/get_law_list(title=law_search_key)
     → 检查返回结果中TimelinessDic是否包含"现行有效"
     → 如显示"废止或失效"或"已被修改"，标记该anchor为需更新
  2. 如需确认条款内容，调用 mcp__pkulaw__mcp-law-search-service/get_article(title=law_title, number=law_article_no)
     → 核验条款内容是否与skill引用的一致
  3. 如发现法规已更新，调用 mcp__pkulaw__mcp-law-search-service/search_article(text=关键词) 检索最新条款
  4. 将核验结果记入运行日志，对失效依据在报告中标注警告
```

**后端2：华宇元典（yuandian）** — 需在元典开放平台注册获取API Key并配置MCP

```
对article-anchors.md中每个anchor：
  1. 调用 yuandian_rh_fg_search(keyword=law_search_key)
     → 检查返回结果中的法规时效性字段，确认是否现行有效
     → 如显示已废止或已修订，标记该anchor为需更新
  2. 如需确认条款内容，调用 yuandian_rh_ft_detail(law_title=law_title, article_no=law_article_no)
     → 核验条款内容是否与skill引用的一致
  3. 如发现法规已更新，调用 yuandian_law_vector_search(query=关键词) 检索最新条款
  4. 将核验结果记入运行日志，对失效依据在报告中标注警告
  5.（可选）调用法律幻觉校验接口批量校验报告中全部法律引用的准确性
```

### 3. 核验频率策略

| 频率 | 适用对象 | 说明 |
|------|----------|------|
| `every_run` | 高频修订法规（个保法、网安法、数据安全法、认定方法） | 每次运行skill时核验 |
| `quarterly` | 较稳定法规（必要范围规定、移动互联网应用程序信息服务管理规定） | 每季度核验一次 |
| `annual` | 国家标准（GB/T系列） | 每年核验，因标准修订周期较长 |

## 失效依据处理规则

当MCP核验发现法规已失效或修订时：

1. **法规已废止**：在报告中标注"⚠️ 本检查项原依据法规已废止，建议核实替代法规"，并暂停引用该依据
2. **法规已修订**：通过search_article检索新条款内容，更新引用条款编号，在报告中标注"本报告已采用最新修订版条款"
3. **条款内容变化**：如新条款对检查项要求有实质性变化，相应调整检查标准，并在报告中说明变化影响
4. **无法确认**：如MCP工具无法返回结果，标注"⚠️ 法规状态未能通过MCP核验，建议人工确认"
