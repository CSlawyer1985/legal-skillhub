# APP合规检查材料收集清单

**致业务部门：**

为完成APP个人信息保护合规评审，请协助提供以下材料。材料完整性直接决定审查深度和准确性，请确保材料真实、完整、与线上实际版本一致。

请在 **____年__月__日** 前将材料整理至共享目录并通知合规团队。

---

## 一、必需材料（须全部提供）

以下8项材料为合规审查必需，缺失将无法启动完整审查。

### 1. APP安装包 ☐

- **格式：** APK文件（Android）/ IPA文件（iOS）
- **要求：**
  - [ ] 最新正式发布版本（非测试包/Debug包）
  - [ ] 未加固的原始包（如已加固，请额外提供未加固版本）
  - [ ] 64位包
  - [ ] 文件命名：`APP名称_v版本号.apk`

### 2. 最新版隐私政策 ☐

- **格式：** Word / Markdown / PDF
- **要求：**
  - [ ] APP当前线上使用的最新版本
  - [ ] 完整文本（含第三方SDK清单部分）
  - [ ] 注明版本号和更新日期
  - [ ] 如有儿童版/适老版等特殊版本一并提供

### 3. 用户协议/服务协议 ☐

- **格式：** Word / Markdown / PDF
- **要求：** APP当前线上使用的最新版本

### 4. SDK清单 ☐

- **格式：** Excel / CSV
- **要求（每行一个SDK，含以下字段）：**

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| SDK名称 | 第三方SDK的产品名称 | ✅ |
| SDK所属公司 | SDK提供方公司全称 | ✅ |
| SDK功能 | SDK的主要功能分类 | ✅ |
| 收集的个人信息类型 | SDK收集的个人信息字段（穷举，不用"等"） | ✅ |
| 收集目的 | 收集每种信息的具体目的 | ✅ |
| 使用场景 | 触发收集的业务场景 | ✅ |
| 是否独立采集传输存储 | 是/否 | ✅ |
| 隐私政策链接 | SDK提供方的隐私政策URL | ✅ |

- [ ] 已提供，包含全部SDK（含间接依赖的SDK）
- [ ] 与隐私政策中的SDK清单一致

### 5. 权限使用清单 ☐

- **格式：** Excel / CSV
- **要求（每行一个权限，含以下字段）：**

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| 权限名称 | Android/iOS权限标识符 | ✅ |
| 权限中文名 | 权限的中文描述 | ✅ |
| 使用场景 | 调用该权限的业务场景 | ✅ |
| 使用目的 | 调用该权限的目的 | ✅ |
| 是否必要权限 | 基本功能必需/附加功能 | ✅ |
| 是否在隐私政策声明 | 是/否 | ✅ |

- [ ] 已提供，包含APP声明的全部权限

### 6. 业务功能清单 ☐

- **格式：** Excel / CSV
- **要求：**

| 字段 | 说明 |
|------|------|
| 功能名称 | 业务功能的名称 |
| 功能分类 | 基本功能 / 附加功能 |
| 功能描述 | 功能的简要描述 |
| 涉及收集的个人信息 | 该功能收集的个人信息类型 |
| 涉及的权限 | 该功能调用的系统权限 |
| 是否需要登录 | 使用该功能是否需要登录 |

- [ ] 已提供，参照《常见类型移动互联网应用程序必要个人信息范围规定》划分基本/附加功能

### 7. 已收集个人信息清单（双清单之一） ☐

- **格式：** Excel / CSV
- **要求：**

| 字段 | 说明 |
|------|------|
| 信息种类 | 个人信息分类 |
| 信息字段 | 具体收集的字段名称 |
| 使用目的 | 收集该字段的目的 |
| 使用场景 | 在什么业务场景下收集 |
| 是否敏感信息 | 是否属于敏感个人信息 |

- [ ] 已提供

### 8. 与第三方共享个人信息清单（双清单之一） ☐

- **格式：** Excel / CSV
- **要求：**

| 字段 | 说明 |
|------|------|
| 第三方名称 | 接收个人信息的第三方公司名称 |
| 第三方产品/类型 | 第三方产品或SDK名称 |
| 共享信息名称 | 共享的个人信息字段 |
| 使用目的 | 第三方使用该信息的目的 |
| 使用场景 | 共享触发的业务场景 |
| 共享方式 | SDK本机采集/后台接口传输/内部数据库共享 |
| 第三方个人信息处理规则 | 第三方隐私政策链接 |

- [ ] 已提供

## 二、可选材料（影响审查完整度）

以下材料缺失不影响审查启动，但会降低部分模块的审查深度。请尽量提供。

### 9. 个性化推荐/算法推送设置说明 ☐

请说明：
- 是否使用个性化推荐/算法推送
- 算法类型和原理概述
- 是否已完成算法备案
- 个性化推荐开关的位置和默认状态
- 关闭个性化推荐后的行为

### 10. 账号注销流程说明 ☐

请说明：
- 注销方式（APP内注销/客服电话/邮件/在线操作）
- 注销入口路径
- 注销前的身份核验流程和所需信息
- 注销条件（是否存在限制）
- 注销处理时限
- 注销后数据处理方式

### 11. 投诉举报渠道说明 ☐

请说明：
- 投诉举报渠道（邮件/电话/在线客服/表单/即时通信）
- 具体联系方式
- 受理处理时限
- 处理流程

### 12. 适老化改造说明 ☐

请说明：
- 是否完成适老化改造
- 适老版入口路径
- 各维度改造情况（可感知性/可操作性/可理解性/兼容性/安全性）
- 是否有广告插件和诱导按键

### 13. 儿童个人信息保护规则 ☐

- **如涉及儿童（不满14周岁）业务，请提供：**
  - [ ] 儿童个人信息保护规则全文
  - [ ] 监护人同意获取方式
  - [ ] 儿童信息处理的安全保障措施

### 14. 数据出境情况说明 ☐

- **如存在数据出境情形，请提供：**
  - [ ] 出境的个人信息类型
  - [ ] 出境目的地
  - [ ] 境外接收方信息
  - [ ] 合规路径（安全评估/认证/标准合同）
  - [ ] 是否取得单独同意

### 15. 个人信息保护影响评估报告/PIA报告 ☐

- [ ] 已开展PIA评估，提供报告

### 16. 安全评估报告/等保证明 ☐

- [ ] 已提供网络安全等级保护评估报告或相关安全评估报告

### 17. 自动续费/会员订阅机制说明 ☐

- **如有自动续费机制，请说明：**
  - 续费提醒方式（是否提前5日提醒）
  - 退订方式
  - 勾选框设计（是否默认勾选）

---

## 三、材料整理要求

1. **版本一致性：** 所有材料须对应同一APP版本，请注明版本号
2. **时效性：** 材料须为最新版本，与线上实际一致
3. **真实性：** 材料须反映APP真实情况，不得隐瞒或美化
4. **完整性：** SDK清单和权限清单须穷举，不得遗漏
5. **可读性：** 文本材料须为可复制格式（Word/Markdown/纯文本PDF，非扫描件）
