# 第四阶段核验模块（智能核验 + 人工核验）

## 一、触发与流程位置

- **触发方式**：第三阶段生成初稿、使用者**初步确认初稿之后**，由 AI **主动询问**"是否发起核验流程"，经使用者同意后手动发起。**不得自动生成初稿后立即静默执行**。
- 核验分两条轨道：智能核验（AI 自动）→ 人工核验（清单化，分律师/客户两角色）。
- 核验结果回写《合规缺口报告》：已解决项标注关闭、未决项保留。全部关闭后输出**双版本定稿**（清洁版去批注供上线 + 批注版留档供复核）。

## 二、智能核验（AI 自动执行，逐项输出机检结果表）

每项输出：通过 / 异常（+段落定位+建议处理）。**分级处理**：硬伤（假朋友残留、内部矛盾、双语缺段）直接修正并告知使用者；存疑项列入人工核验清单，不擅自改。

| # | 机检项 | 检查内容 |
|---|---|---|
| V1 | 结构完整性机检 | 13 节骨架存在性；Art. 13/14 十五项必备告知的机器比对（语义层，非纯关键词） |
| V2 | 四件套绑定机检 | 每个处理目的是否都挂上数据类别、法律依据、存储期限；交叉引用有效性（"见第X部分"指向是否正确） |
| V3 | 假朋友残留扫描 | 14 组假朋友术语全文扫描，输出命中行号（第二步假朋友清扫动作的自动化复核） |
| V4 | 关键数字一致性机检 | 1 个月 / 72 小时 / 16 岁等关键时限与年龄全文一致性；中英互译核对（"one month" ↔ "一个月"） |
| V5 | 双语对齐机检 | 中英段落一一配对、无单边缺段；术语前后统一（controller 不混用 processor） |
| V6 | 内部矛盾机检 | 如残留"不会跨境转移" vs 跨境章披露；Cookie 章"放置前同意" vs 其他表述；存储期限前后不一 |
| V7 | 占位符清点 | 【待核实】【待客户补充】[占位符] 生成待办清单，防止带占位符发布 |
| V8 | 事实回查 | 与第二步确认的事实记录（问卷答案、跨境判断）比对，有无凭空新增目的/实体/承诺 |

## 三、人工核验清单（生成独立文档）

按使用者确认的形式生成《人工核验清单》独立文档（对话逐条确认结果归档其中）。分两个角色：

### （A）律师核验项（法律判断，AI 不可代劳）

- 法律依据逐目的终裁（含合法利益三步测试留档要求）
- DPO 任命判断；欧盟代表任命与披露
- 自动化决策条款与新指南符合性（运行时核查 EDPB ADM 指南最新版本）
- 营销基础策略选择（同意 vs 合法利益 vs 软选择）
- 强制注册账号评估（EDPB Recommendations 2/2025）
- 特殊类别数据实际收集核实
- 目标市场国别规则核实（兜底条款所涉差异点）

### （B）客户核验项（事实确认）

- 政策描述与实际业务流程一致性走读（下单、权限弹窗、Cookie banner 实际行为）
- 留存期限实操可行性
- 客服渠道能否支撑 1 个月权利响应时限
- 账户内权利行使路径是否存在

### （C）场景 × 处理字段二次核验（客户核验项新增）

**目的**：验证政策声明的"收集字段清单"与各业务系统的**实际收集字段**一致——声明与实际不符即虚假告知风险（EDPB 透明度执法核心维度）。

**机制**：

1. 从政策正文提取**场景 × 处理字段矩阵**（每个处理场景对应的声明数据类别与字段，如：会员注册→手机号/昵称/生日；下单→收货人三要素；位置服务→定位；营销→画像标签等）。
2. 以清单形式请客户逐项确认："以下系统/场景实际收集了哪些字段？是否与政策声明一致？"
3. **上传选项（可选，不得强制）**：AI 主动提示——"如方便，可通过技术手段导出以下任一格式文件供二次核验：CSV / JSON / XML / Excel（如 CRM 导出、电商后台字段表、App SDK 配置清单、埋点事件表）。**您可以选择上传或不上传**；不上传则以您的逐项口头/书面确认作为核验依据，核验结论标注为『客户陈述核验（未经技术导出验证）』。"
4. 收到导出文件后：解析实际字段 → 与政策声明字段比对 → 输出三类结论：①一致字段 ②实际收集但政策未声明（→ 补入政策或停止收集，P0/P1 缺口）③政策声明但实际不收集（→ 删除声明，准确性缺口）。
5. 不上传时：仅按客户逐项确认结论记录，标注核验强度等级（技术导出验证 > 客户陈述核验）。
6. 二次核验结论回写《合规缺口报告》对应项。

## 四、闭环

1. 智能核验机检结果表 + 人工核验清单确认结果 → 汇总。
2. 确认结果回写缺口报告（已解决项关闭、未决项保留）。
3. 全部关闭后输出双版本定稿：清洁版（去批注，供上线）+ 批注版（留档供复核）。
