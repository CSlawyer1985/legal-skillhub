# 劳动仲裁管家 Skill

## 功能描述
自动识别劳动仲裁文书（仲裁申请书、受理通知书、开庭通知书等），提取关键信息，根据劳动争议调解仲裁法规定计算各项期间，输出个性化的期间表。

## 使用场景
- 收到仲裁受理通知书，需要计算答辩期、举证期限
- 收到开庭通知书，需要计算开庭准备时间
- 收到仲裁裁决书，需要计算起诉期限

## 输入
1. 上传文书图片（受理通知书、开庭通知书等）
2. 或手动输入关键信息

## 输出
- 案件基本信息
- 关键期间表（包含具体日期）
- 风险提示（即将到期或已过期的期间）
- 待办事项清单

## 工作流程

### 步骤1：识别文书类型和提取信息
- 如果用户上传图片，先进行OCR识别
- 从文字中提取关键信息：
  - 案号
  - 案件名称（见下方"案件名称提取规则"）
  - 仲裁委员会名称
  - 申请人、被申请人
  - 受理日期
  - 送达日期
  - 开庭时间（如果有）

**日期格式处理：**
- 法律文书的日期通常为中文格式，如"二○二六年一月二十二日"或"二〇二六年一月二十二日"
- 必须同时支持"○"（圆圈）和"〇"（零字）两种零的写法
- 提取日期后，转换为标准格式（YYYY-MM-DD）用于期间计算

**案件名称提取规则：**
劳动仲裁文书中案件名称的表述方式多样，需要按以下优先级提取：

1. **标准格式**：优先提取"申请人XXX与被申请人XXX劳动争议"或"XXX诉XXX劳动争议"格式
   - 示例：李娟诉月州科锐信息技术有限公司劳动争议

2. **第二人称格式**：如果是"申请人XXX与你单位劳动争议"
   - 需要根据文书上下文，将"你单位"替换为实际被申请人名称
   - 示例：文书中"申请人李娟与你单位劳动争议"，根据抬头确定"你单位"是某某公司，提取为"李娟诉某某公司劳动争议"

3. **过滤程式化表述**：
   - 去除"申请人…与你单位…"等程式化表述中的"你单位"等代词
   - 去除重复拼接的当事人名称
   - 只保留核心的"申请人+被申请人+劳动争议"信息

4. **最终格式要求**：
   - 案件名称必须包含申请人和被申请人
   - 格式：申请人诉被申请人劳动争议
   - 示例：李娟诉月州科锐信息技术有限公司劳动争议

### 步骤2：计算期间
根据劳动争议调解仲裁法规定，计算以下期间：

#### 劳动仲裁阶段
1. **仲裁时效**：1年（从知道或应当知道权利被侵害之日起）
2. **答辩期**：收到申请书后10日内
3. **仲裁审理期限**：受理后45日内结束（可延长15日）
4. **起诉期限**：收到裁决书后15日内

### 步骤3：输出结果
按照以下格式输出：

```
━━━━━━━━━━

被申请人：[被申请人]

━━━━━━━━━━

|---------|---------|---------|---------|---------|------|
```

### 步骤4：保存案件信息
本步骤采用两级文件管理：

#### 4.1 本地案件文件（必须）
- 在用户@ 的文件所在目录下，创建期间表文件
- 文件名格式：`[案号]_仲裁期间表.md`
- 内容：包含步骤3输出的完整期间表

#### 4.2 全局任务管理（必须）
- 将所有期限信息写入全局任务文件：`tasks.json`（建议放在你的工作区根目录）
- 文件格式为JSON：`{"tasks": [...]}`
- 每个期限作为 tasks 数组中的一个对象，包含：
  - `case_id`：案号
  - `case_name`：案件名称（必须包含双方当事人/申请执行人+被执行人）
  - `case_type`：案件类型（诉讼/执行/劳动仲裁）
  - `deadline_name`：期间名称
  - `deadline_date`：截止日期（YYYY-MM-DD）
  - `legal_basis`：法律依据
  - `status`：pending/completed/overdue
  - `created_at`：创建日期
  - `case_folder`：案件文件夹路径

**重要说明：**
- 本地文件方便查看单个案件的完整期间信息
- 全局 `tasks.json` 供"待办管家"统一管理所有案件的期限
## 期间计算规则

### 劳动仲裁阶段期间规则

| 期间名称 | 计算规则 | 法律依据 |
|---------|---------|---------|
| 仲裁时效 | 1年（从知道或应当知道权利被侵害之日起） | 《中华人民共和国劳动争议调解仲裁法》第27条（2008年施行） |
| 审查受理 | 收到申请后5日内决定是否受理 | 《中华人民共和国劳动争议调解仲裁法》第29条（2008年施行） |
| 送达申请书 | 受理后5日内送达被申请人 | 《中华人民共和国劳动争议调解仲裁法》第30条（2008年施行） |
| 答辩期 | 收到申请书后10日内提出答辩 | 《中华人民共和国劳动争议调解仲裁法》第30条（2008年施行） |
| 管辖权异议 | 答辩期满前提出 | 《劳动人事争议仲裁办案规则》第10条（2017年施行） |
| 反申请 | 答辩期内提出，5日内决定是否受理 | 《劳动人事争议仲裁办案规则》第36条（2017年施行） |
| 开庭通知 | 开庭前5日通知双方当事人 | 《中华人民共和国劳动争议调解仲裁法》第35条（2008年施行） |
| 延期开庭 | 开庭前3日申请 | 《中华人民共和国劳动争议调解仲裁法》第38条（2008年施行） |
| 仲裁审理期限 | 受理后45日内结束（可延长15日） | 《中华人民共和国劳动争议调解仲裁法》第45条（2008年施行） |
| 起诉期限 | 收到裁决书后15日内 | 《中华人民共和国劳动法》第83条（2018年修正） |

## 特殊规定

### 仲裁时效特殊情形
- 劳动关系存续期间因拖欠劳动报酬发生争议的，不受1年仲裁时效限制
- 但劳动关系终止的，应当自劳动关系终止之日起1年内提出
- 法律依据：《劳动争议调解仲裁法》第27条（2017年修正）

### 期限计算
- 期间以日、月、年计算
- 仲裁办案规则中的3日、5日指工作日
- 节假日顺延规则同样适用

## 注意事项
1. 劳动仲裁是劳动争议诉讼的前置程序，必须先仲裁后诉讼
2. 本Skill计算的期间仅供参考，具体以仲裁委员会通知为准
3. 如有疑问，请及时咨询仲裁委员会工作人员
