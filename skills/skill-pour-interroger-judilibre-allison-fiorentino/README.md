# 面向 Claude 的 Judilibre 技能

_直接从 Claude 检索法国司法判例（最高法院）_

本指南分三步说明如何启用 Judilibre 技能：获取您的 PISTE 标识、授权所需网络域名，然后在 Claude 中安装该技能。首次操作约需十分钟。

> **开始前须知**
>
> - 访问 Judilibre 经由 PISTE 门户：需要一个免费账户和一把 API 密钥（KeyId）。
> - 该技能仅覆盖司法序列（最高法院，以及越来越多的上诉法院和一审法院）。
> - 您的密钥严格属于个人所有：绝不要分享或在任何地方公开。

---

## 1. 获取您的 PISTE 标识

PISTE（国家转型服务中介平台）托管最高法院的 Judilibre API。注册和使用均免费。

1. 在 **piste.gouv.fr/registration** 创建账户。填写您的姓名和电子邮件地址。
2. 通过收到的邮件链接激活账户，然后**登录**门户。
3. 接受 Judilibre 的一般使用条件（CGU）：在您的空间中，搜索「Judilibre」并为**生产**环境（如测试则和/或沙箱环境）接受 CGU。
4. 从您的 PISTE 仪表盘创建**一个应用程序**（一个应用程序 = 一个容器，您的密钥挂靠其上）。
5. 将 Judilibre API 挂靠到该应用程序，然后**生成一把 API 密钥（API Key / KeyId）**。
6. 复制 **KeyId** 的值：这是技能运行所需的唯一信息。

> **小提示**
>
> 在绝大多数情况下，「KeyId 模式」就足够了：一把简单的密钥放在请求头中发送。client_id / client_secret 对（OAuth2）仅用于高级用途。

---

## 2. 授权外部域名

技能在 Claude 的代码执行环境中运行，该环境的网络访问默认受限。因此需要授权 Judilibre 请求所发往的域名。

### 在哪里设置

在 Claude 中，打开**设置 → 能力**。滚动到「域名允许列表」部分，然后在「允许的附加域名」字段中输入每个域名，并点击「添加」。

### 要添加哪些域名

| 域名                         | 状态        | 何时添加                         |
| ------------------------------- | ------------- | --------------------------------------- |
| **api.piste.gouv.fr**           | 必需 | 始终（生产环境，KeyId 模式）       |
| **piste.gouv.fr**               | 必需 | 始终（作为前者的补充）   |
| **sandbox-api.piste.gouv.fr**   | 可选     | 仅沙箱环境 |
| **oauth.piste.gouv.fr**         | 可选     | 仅 OAuth2 模式（高级）      |
| **sandbox-oauth.piste.gouv.fr** | 可选     | 仅沙箱 + OAuth2         |

实际上，对于正常的生产使用，两个域名就足够了：**api.piste.gouv.fr** 和 **piste.gouv.fr**。其他仅用于沙箱或 OAuth2 模式。

> **值得了解**
>
> 判决的公开链接指向 www.courdecassation.fr，但技能不会连接它：它只是构建地址。因此无需授权该域名。
>
> 如果请求失败并提示「无法连接」或「域名未授权」，几乎总是因为允许列表中缺少 **api.piste.gouv.fr** 或 **piste.gouv.fr**。

---

## 3. 安装技能

该技能以一个包含 SKILL.md 文件和 scripts/ 子文件夹的文件夹形式呈现。以下是安装方法。

1. **下载技能**，从提供的链接（Notion 或 Lawve AI——见发布内容的第一条评论）。
2. **将技能添加到 Claude**：打开**自定义 → 技能**，然后点击列表顶部的 **+** 按钮导入技能文件夹（或其 .zip 压缩包）。
3. **填写您的 PISTE 密钥——首次使用时**。技能安装完成后，打开一个对话，直接在聊天中告诉 Claude 您将密钥交给它：例如「这是我的 Judilibre PISTE 密钥：_[您的 KeyId]_」。
4. **Claude 会为您保存它**：它创建（或补全）技能的 _scripts/config.json_ 文件，将您的密钥放入 `key_id` 字段并将环境设为 `prod`。因此您无需手动编辑任何文件。该操作只需进行一次：密钥会为后续使用保留。
5. **验证安装**：请求一次首次检索（例如「搜索一个关于试用期的社会庭判决」）。如果显示决定列表，一切正常。

> **安全**
>
> config.json 文件以明文包含您的密钥。绝不要分享或公开它（既不要发到公共仓库，也不要出现在截图中）。

---

## 遇到问题时

- **密钥缺失**：向 Claude 提供您的 KeyId 以便其保存。
- **401 错误**：密钥错误或环境错误（用了沙箱而非生产环境）。
- **403 错误**：Judilibre CGU 未接受，或 API 未挂靠到您的 PISTE 应用程序。
- **429 / 5xx 错误**：达到配额或 API 暂时不可用——等待后重试。
- **「域名未授权」**：在网络设置中添加 api.piste.gouv.fr（第 2 步）。

---

_完成这三个步骤后，您就可以直接在对话中以自然语言查询最高法院的判例。_
