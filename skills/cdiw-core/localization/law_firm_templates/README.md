# law_firm_templates 目录使用说明

## 用途

本目录为律所常用文书格式模板目录，可放置本所版服务清单与进程确认表。

## 同名覆盖机制

文书生成与服务进程确认时，本目录下的模板优先于assets/templates/下同名模板被调用——移植者放入与assets/templates/同名的基础模板（如investigation_service_checklist.md、service_progress_confirm.md），即可实现本所格式对默认格式的覆盖，核心引擎零改动。

## 使用建议

1. 可放入本所常用格式的Word模板说明版（以Markdown描述格式要点，或直接放置模板文件）；
2. 可按本所服务标准调整各阶段服务量基准，制作本所版服务清单（放入后自动覆盖默认的8接待、6会见及3公安沟通、2检察沟通及3书面意见配置）；
3. 可放置本所版阶段服务进程确认表；
4. 模板内容须符合assets/templates/format_spec.md格式规范与assets/templates/expression_guide.md表述规范。
