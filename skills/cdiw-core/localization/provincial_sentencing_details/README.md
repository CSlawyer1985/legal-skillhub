# 本省量刑实施细则目录（provincial_sentencing_details）

## 用途

存放本省高级人民法院（联合省检察院）发布的《〈关于常见犯罪的量刑指导意见（试行）〉实施细则》文件，供量刑情节线测算时读取省级细化档次。未配置省份按全国指导意见（法发〔2021〕21号）测算并标注“本省细则未配置”。

## 预置状态

- **浙江省已预置**：`zhejiang.md`（浙高法审〔2022〕1号，2022年1月12日施行，现行有效，2026-08-20核验入库，文号已注册law_effectiveness.json可经law_validator.py校验；二十三罪名量刑起点、二十二项情节省级调节档次、与全国指导意见七项差异清单）。测算时传`--province 浙江`即自动读取，无须再传`--local_details_file`。
- 其他省份为移植者配置项：按下方指引填充。

## 文件命名与格式

按省份命名，如`zhejiang.md`（浙江）、`guangdong.md`（广东）；文件为UTF-8文本或JSON，内容含：

- 发布文号与施行日期（经scripts/law_validator.py校验时效后收录，并注册至assets/data/law_effectiveness.json，条目附full_name简称与本地文件路径）；
- 各量刑情节的省级调节档次（参照zhejiang.md第二节表格体例）；
- 与全国指导意见不一致之处的清单（以全国指导意见为基准、省细则为本地执行口径）。

## 填充指引

1. 检索本省高院官网或北大法宝地方法规库获取本省实施细则文本；
2. 按上述格式整理后存入本目录；
3. 在文件头部标注信息时点与核验状态；
4. 测算调用示例：python scripts/sentencing_estimator.py --crime 诈骗罪 --base_sentence 42 --factors `'[...]'` --province 浙江（已预置省份自动读取；未预置省份传 --local_details_file 路径）

## 注意事项

各省细则仅适用于该省法院审理的案件；跨省案件（指定管辖、异地审理）核对审理法院所在地细则；细则更新时旧版本留存归档并在CHANGELOG记录。

## JSON 格式规范（I-1，2.1.0 新增）

为支持主包校验，新填充的省份一律采用 **JSON 格式**，一省一个文件（如 `zhejiang.json`）。字段 schema：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `province` | string | 是 | 省份名，与主包 `--province` 参数取值一致 |
| `effective_date` | string(date) | 是 | 施行日期 YYYY-MM-DD，须在文件头部括注细则文号与时点 |
| `crimes` | object | 是 | 罪名 → 档次 → 刑期幅度数组；**罪名键须与主包 `crime_index.json` 的罪名键一致** |
| `source_note` | string | 是 | 文号出处（如“浙高法审〔2022〕1号”），供法条效力校验定位 |

**刑期幅度格式**：`crimes[罪名][档次]` 为**非空数组**，元素为刑期区间描述（如 `["6个月-1年", "1年-2年"]`）。

**填充模板**：

```json
{
  "province": "浙江",
  "effective_date": "2022-01-12",
  "source_note": "浙高法审〔2022〕1号，2022年1月12日施行，现行有效",
  "crimes": {
    "诈骗罪": {
      "数额较大": ["3个月-6个月", "6个月-1年"],
      "数额巨大": ["3年-4年", "4年-5年"]
    }
  }
}
```

**校验方式**：填充后运行 `python scripts/quality_checker.py --l10n`，脚本逐项核验——

- 罪名键覆盖率：本地细则罪名须为 `crime_index.json` 罪名集的子集，超出即列清单；
- 刑期幅度格式合法性：档次值须为非空数组；
- `effective_date` 必填。

**责任边界**：本地化层为移植者配置项，主链不感知具体地域内容；校验不通过仅列清单，**不阻断主包发布**，责任在填充方。

**当前状态**：浙江省细则为 `.md` 形态（`zhejiang.md`），转 JSON 列遗留项 L-3；转 JSON 后本校验对其生效。`.md` 与 `.json` 并存时以 `.json` 为准。
