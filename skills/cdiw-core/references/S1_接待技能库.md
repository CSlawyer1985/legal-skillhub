# S1　接待技能库

适用节点：线 1 全部十七个接待环节；每次会见前后配套接待。

## §1 首次接待方法论

1. 信息提取围绕**利益、关系、行为**三要素，把控沟通节奏。
2. 五忌——被情绪煽动失中立；未分析即下结论；仅凭口述判断案情；过度迎合；主动提及律师费由对方承担。
3. 预期管理以类案检索数据作答“能不能取保、判几年”类疑问，锚定律师价值于具体环节（谈判、条款设计、节奏把控、执行兜底），不作承诺。
4. 收案沟通嵌入商业目的探询：区分表面诉求与深层目的（现金流、控制权、声誉、关系修复）；按“风险识别 → 条款缺口 → 执行障碍 → 损失放大”因果链递进分析，忌并列堆砌。

## §2 配套接待规则

1. 会见前接待：收集家属转达事项、生成转达清单、核对新情况/新证据/新期限。
2. 会见后接待：保密边界内反馈状态与进展、转达当事人意见、反馈与办案机关沟通情况、商讨方案、了解家事需求。
3. 接待工作从当事人感受角度计，重要性高于专业辩护工作本身——“结果好、不满意”绝大多数源于沟通不足。

## §3 十七环节接待节点库

接待节点库按程序阶段配置十七个环节（环节＋任务要点合一，单一权威源）：第 1—8 环节为侦查阶段，第 9 环节起随阶段包启用。

1. **首次接待（接案）**：三问框架完整执行；案件信息采集（套用 assets/templates/case_intake_form.md）；收费边界说明（刑事辩护禁止风险代理）；人证分离规则与家属注意事项告知。
2. **提请批准逮捕前的接待**：报捕时点与两种走向告知；取保申请窗口（报捕前三日）商讨；赔偿谅解时机判断。
3. **批捕前的接待**：审查批捕七日期限与结果预判（不把话说满）；赔偿谅解加急推进；不批捕后释放流程预告。
4. **批捕后的接待**：安慰疏导优先；逮捕原因七分法分析（以第三方口吻表述）；羁押必要性审查时间安排；下一步方案商讨。
5. **羁押必要性审查的接待**：新情况通报；申请书内容与时机商讨；预期管理（此环节检察院只能建议公安机关变更强制措施）。
6. **移送审查起诉前的接待**：程序告知；委托确认（是否续签）；案外人接触禁区重申。
7. **阅卷后的接待**：证据体系概况通报（经信息边界过滤）；辩解与证据的冲突点提示（不披露细节）；辩护方向初步商讨。（本环节告知双向清单系线 1 第 5 项所引「S1§3 第七节」口径，见本速查「三、信息告知边界全表」。）
8. **辩护意见及法律方案商讨的接待**：两套以上方案逐项讲解利弊；家庭内部意见协调；选择笔录安排。
9. **审查起诉期限届满前的接待**：起诉、不起诉、退查三走向预告；认罪认罚具结的家庭意见收集（决定权在当事人本人）。
10. **审判阶段领取起诉书后的接待**：指控概况通报（过滤后）；庭审安排告知；旁听指引。
11. **审判阶段商讨辩护意见的接待**：辩护立场确认；量刑预期管理；庭审配合事项。
12. **庭审前接待**：程序说明；旁听纪律（不得发言、不得传递信号）；宣判时间预估；情绪预案。
13. **判决前的接待**：结果区间预告；各结果应对预案预先商定。
14. **收到判决书后的接待**：判决解读（定罪、量刑、财产处置）；上诉利弊分析（十日上诉期提示）；上诉程序说明。
15. **上诉案件接案接待**：上诉理由确认；二审委托手续；开庭、书面审理走向预告。
16. **二审辩护意见与方案探讨的接待**：二审焦点商讨；开庭申请必要性；维持原判风险的预期管理。
17. **二审裁判前的接待**：终审性质说明；维持、改判、发回各情形预案；申诉路径初步说明。

## §4 方案商讨方法论

提出两套以上方案 → 逐项讲解利弊、周期、风险 → 结合当事人利益类型（自由/财产/名誉）协助分析但不替代选择 → 提示制作选择笔录 → 新情况出现即重新启动方案商讨。

### 二、三问框架方法论详解

**一句话定性法**：以“是否刑事案件、涉嫌什么罪名、当事人有何诉求”三要素压缩为一句话专业概括，让家属第一时间建立准确认知框架。

**走向穷尽法**：从最重结果到最轻结果逐档列明（含无罪可能），每档标注“可能性分析，非承诺”；预判有利结果的也不把话说满，防止家属四处宣扬影响司法机关决定。

**“你我他要干啥”方案结构**：总目标及各阶段目标；律师（法律咨询、与办案机关沟通、文书撰写、开庭辩护、认罪认罚协商）、当事人（在充分了解法律的前提下准确供述辩解、抓住每次提审机会自我辩护、必要时书写自辩材料）、家属（与被害方沟通赔偿谅解、向办案单位书面反映合理诉求、配合律师工作、人证分离）三方任务分工；方案两套以上，逐项讲解利弊，提示当事人选择后制作笔录。

### 三、信息告知边界全表

**应告知四类**：指控基本事实；证据体系概况；当事人辩解及依据；法定酌定情节。

**禁告知五类**：不利证言作出者；证人姓名身份联系方式；未查获证据存放地点；不利鉴定意见鉴定人；涉非法取证侦查人员姓名。

**两底线**：不得泄露国家秘密（案卷材料庭审前属侦查秘密，不得复印、拍照、抄录给家属）；不得妨害诉讼（防止披露信息被用于串供、伪证、毁灭证据）。

**通报律师工作情况的要点**：已完成的会见次数与内容概况、已递交的文书、已开展的沟通、下一步计划——以工作清单形式定期通报。

### 五、赔偿谅解指导规则

1. **早赔晚赔判断标准**：加害事实清楚的宜早赔早获谅解；因果关系存疑的宜谨慎或框架协议分期。
2. **协议约束条款设计**：对方不得以任何形式撤回谅解，否则退还赔偿款。
3. **谅解范围条款**：宜宽——涵盖从轻处理、缓刑、免刑、不起诉、减刑、假释。
4. **中间人磋商与民事律师分工**：涉及被害人死亡的先赔礼道歉、请中间人磋商；建议由民事律师代理赔偿协商，刑事律师依法不得擅自接触被害人及其近亲属提供的证人（刑诉法第43条第2款双许可要件——经检察院或法院许可，并经被害人或其近亲属、被害人提供的证人同意，2018年修正版条号）。
5. **道歉顺序**：先赔礼道歉、再磋商赔偿、后出具谅解。
6. **人道主义抚恤金运用**：以额外抚恤形式表达诚意，促成谅解。

### 六、逮捕原因七分法与对策映射表

| 逮捕原因 | 对策 |
|---|---|
| 涉嫌罪名量刑可能十年以上 | 定性辩护——争取轻罪认定 |
| 多罪名、案情复杂、涉黑涉恶 | 逐罪名逐一拆解，程序与证据并行 |
| 同案犯在逃、重要事实未清 | 推动到案与事实固定，说明羁押替代手段 |
| 被害方未获赔偿谅解 | 促成赔偿谅解 |
| 可能引发社会稳定事件 | 书面稳定承诺与和解推进 |
| 认罪态度问题 | 认罪认罚评估与辅导 |
| 未退赃退赔 | 及时退赃退赔 |

（以第三方口吻说明“这是检察院的逮捕理由”，逐项给出对策。）

### 七、人证分离规则详解

家属只负责找到知情人并提供联系方式，不得与证人交流案情；家属先行接触证人会导致证言被污染、证据证明力受损甚至被排除；律师获得线索后依取证规则分流处理（自行取证须经证人同意；申请调取；申请证人出庭）。

### 八、接待五要点

时间节点必接待；服务方案必商讨；双方信息必同步（家属信息全量输入、律师信息过滤输出）；家属作用必发挥；执业风险必防范。

### 九、可视化执行细则

1. **反馈清单字段**：日期、事件（会见、沟通、文书）、内容概况、下一步安排。
2. **方案探讨触发情形**：新证据出现、阶段切换、强制措施变化、办案机关新动向。
3. **工作清单四要素**：时间、承办律师、事项、工作用时。
4. **确认方式与归档**：工作清单按月发送委托人，回复“收到”即视为确认；确认记录归档于case_status.md。

### 十、各阶段标准服务量基准表

（供接待时说明服务范围与供服务进程核对；收费金额不在本表范围。）

**侦查阶段**：接待家属八次（每次会见前沟通待转达事项、会见后通报情况，另加首次会见后的接待与逮捕后的接待；会见至少六次对应至少十二次接待往来，八次为面对面接待的底线基准）；会见六次（疑难复杂延长羁押的每月增见一次）；与侦查人员沟通三次（递交手续建立联系了解案情、报捕前提交取保申请、侦查终结前反映意见诉求）；与检察沟通两次（审查批捕阶段提交意见当面沟通、逮捕后一个月羁押必要性审查沟通）；书面意见三份（报捕前三日内的取保候审申请书——刑拘期满要么报捕要么取保，此时提出肯定不产生不利影响，涉十年以上的须找到可能十年以下的理由作依据；审查批捕阶段的不予批准逮捕律师意见书——针对逮捕条件与逮捕必要性；逮捕后一个月的羁押必要性审查申请书）。

**审查起诉阶段**：会见三次（听取对起诉意见的意见、核对证据材料、商讨辩护意见与方案）；阅取全卷；制作案件审查报告一份；申请并参加听证；提出辩护意见一份；提出取保意见一份；与公诉人沟通三次（递交手续阅卷建立联系、提交相关申请、沟通辩护意见）；与家属沟通六次；退回补充侦查的每退查一次另安排会见三次、与公诉人及侦查机关各沟通一次、提出书面或口头辩护意见一次。

**一审阶段**：会见四次（听取对起诉书的意见、核实证据商讨辩护方案、庭前辅导、判决后询问上诉事宜）；制作庭审提纲一套（发问提纲、质证意见、辩护意见、答辩意见）；与公诉人法官庭前沟通一次（含申请参加庭前会议）；开庭辩护；提交书面辩护意见；庭审后与法官沟通一次；领取判决书；草拟上诉状；接待家属四次；延长审限每月另安排会见、沟通各一次；延期审理一次另安排会见三次、沟通三次、补充阅卷并提出补充辩护意见。

**二审阶段**：会见四次（听取上诉意见、核实证据、商讨辩护方案、判后回访）；阅卷（含一审庭审笔录或录音录像）；与法官沟通三次（阅卷建立联系提出初步意见了解是否开庭、提交开庭申请及相关申请、提交并当面讲解书面辩护意见）；与家属沟通四次；二审开庭的另计庭前会见、沟通各一次。

各阶段次数为底线基准，可依委托约定与案件情况上调。
