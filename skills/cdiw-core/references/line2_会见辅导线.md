# 线 2　会见辅导线

适用节点：会见计划、会见提纲生成、会见辅导、会见纪要整理。

**执行步骤**：

1. 首次会见一律按**七步法**生成提纲并逐步执行。七步步序与守卫条件：告知委托（不急于签署委托书，先展示专业性）→ 告知监听风险 → 全面法律咨询（核心步，未听懂不得进入下一步）→ 了解笔录（仅询问次数、讯问内容、如何问如何答，不复述案情）→ 提出辩解（同步询问依据）→ 商讨法律服务方案（定性谱系分析＋当事人/家属/律师三方任务分解）→ 家事转达（明确物品信件传递边界）。分支处理：笔录属实认罪——重点研究定性辩护与认罪认罚方向；笔录不实或受胁迫——引导今后如实陈述、提示在检察官提审时如实反映以固定排非线索。
2. 标准会见节点库（21 环节）：
   - **侦查阶段六次标准会见**：首次会见（七步法）；刑拘后报捕前（告知已交取保申请、两种结果心理准备、“看了但没看到”与“没来得及去看”笔录陷阱识别）；审查批捕初期（检察官提审前辅导——问什么、答什么、真诚感人，“自己就是自己最好的辩护人”）；逮捕后两日内（及时会见安抚——逮捕原因五类分析：量刑十年以上/涉黑多罪/同案犯在逃/赔偿未谅解/易引发稳定事件，针对原因定方案，劝同案犯到案既立功又消除取保障碍）；逮捕后一个月（通报进展＋了解提讯＋羁押必要性研究＋方案商讨）；侦查终结前（系统笔录三项——说主观、说客观、说非法取证；案件走向预告含区县→市级检察院移送）。
   - **审查起诉阶段三次**：阅卷三日内首次会见（宣读起诉意见书听取辩解——辩解是辩护核心；核实本人笔录可全展示；下一步安排）；核实证据会见（人证分离规则）；提审前辅导（检察官拟相对不起诉→少辩解；拟改定性→重点辩解；拟维持起诉→表达留法庭）。
   - **审判阶段各节点**：审判首次会见（三日内；介绍法院程序含庭前会议、审委会、延期审理；逐句听取对起诉书意见；庭前准备商讨）；核实证据会见（审判阶段不采用人证分离，全面展示）；庭审前会见（庭审辅导＋发问演练）；判决前会见（上诉预案）；判决后会见（裁判分析、上诉利弊、不上诉笔录）。
   - **二审及申诉**：二审阶段第一次会见（六点要求——先分析判决/听取意见/介绍二审程序/介绍辩护方案/不诋毁一审律师/不诋毁一审法院）；二审商讨辩护方案会见（四点——方案全面含撤回抗诉上诉结案/听取上诉人意见/协助选最佳方案/落实分工）；二审庭前或提审前辅导（开庭案件按三要求＋不开庭案件提审前辅导）；二审裁判送达前会见（结果预判/送达方式特殊性/后续工作含申诉以家属名义）。
   - **机动会见**：羁押期限每延长一个月至少增加一次会见；重大证据或口供变化、重新鉴定、变更强制措施时触发会见提醒。
3. 证据核实规则：
   - 人证分离（审查起诉阶段适用）：人——先核与当事人关系亲疏利害；证——只讲不利内容不讲人名；目的：防串供＋防律师执业风险。
   - 展示范围三分法：本人笔录全展示；客观性证据可展示（书证、物证、勘验笔录、鉴定意见、电子证据）；同案犯供述与证人证言不直接展示（不利部分按人证分离核实）。
   - 审判阶段：经庭前会议程序，辩护人可代被告人发表质证意见，证据全面开示，不再人证分离。
4. 会见后处理：引导整理会见笔录，区分当事人陈述、已核实事实、待核实线索；更新时间轴、人物关系、资金流、行为证据四张图的数据结构；生成会见纪要并提示接待家属反馈。

**输出要求**：会见七步提纲、分阶段会见提纲（按节点库生成）、首次会见核查清单（含权利义务告知与健康与非法取证专项问题）、会见笔录模板。

**禁止项**：禁止沿用传统四步法（先了解案情、再针对性给出法律咨询）的流程——针对性咨询存在被认定为唆使翻证的执业风险；禁止在第三步之前询问案情；禁止在当事人未供述的情况下要求其陈述犯罪事实；禁止死记硬背式辅导。
