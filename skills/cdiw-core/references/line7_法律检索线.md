# 线 7　法律检索线

适用节点：类案检索、法条检索、罪名辨析、检索报告制作。

**执行步骤**：

1. 先独立分析形成检索目标，再检索印证。检索目标按“全、专、精”确立：全——从会见、接待、办案机关沟通、专家请教、实地走访中全方位捕捉争议焦点；专——从阅卷笔录中提炼证据矛盾与法律适用问题；精——用关系图、组织架构图、时间轴等可视化梳理复杂案件、定位当事人作用。
2. 规范检索：按位阶穷尽——宪法 → 法律 → 法律解释与司法解释 → 行政法规 → 地方性法规与规章 → 会议纪要、答复、批复等规范性文件 → 行业规范 → 刑事政策（民营企业家保护等）；刑民交叉、行刑交叉案件扩展检索民事、行政规范；执行“全（横向＋纵向）、细（逐条看具体规定，防遗漏特殊条款）、小（不放过批复类小文件）”三原则；应用位阶分析（下位法违反上位法、多个文件选择适用、前置法符合性审查）。
3. 案例检索六步（S4§2 全文，双向索引）：
   a. 确定检索路径（依辩护思路）——轻罪检索（变更罪名检索）；罪轻检索（举重以明轻/举轻以明重）；无罪检索（有罪倒推无罪——从有罪判决的控方指控、辩方思路、裁判理由中提炼无罪要素；检索不起诉、二审改判、部分罪名改判案件）；
   b. 确定关键词——情节导向型（自首、立功、从犯、谅解，正反两向）、要素导向型（以案件关键载体设词）、特定行为导向型（从行为本质提炼判决书必现词汇）；
   c. 应用检索三原则与逐层收敛（大类递增关键词缩小范围）——**排除原则**：刑期过高、目标案件不具备的量刑情节、因司法解释变更等特殊情形三类直接排除；**优先原则**：近期优先、地域优先（同一法官同法院最优先，辐射至上级区划）、层级优先（按《指导意见》四类检索顺位）；**适度原则**：覆盖目标案件情节要素即可，不以穷尽为目标；
   d. 检索具体案情——精细比对类案与本案案情（冲突情况、关键情节、指认经过等），细看“经审查认为”“本院认为”并可参考检察院起诉内容；比对时即作摘录与思考笔记；
   e. 检索案件争点——聚焦控辩争议焦点与法官裁判理由（控方指控什么、辩方辩驳什么、法官支持哪方及其理由），着重寻找说理充分的案例；无控辩分析及裁判理由的案例仅可作统计用途或排除；
   f. 制作检索报告——归纳总结用自己的语言形成报告，不将原始案例直接递交承办人。
4. 检索顺位：最高法指导性案例 → 最高法典型案例及生效案件 → 本省高院参考性案例及生效案件 → 上一级法院及本院生效案件；优先近三年；辩护人不受“前一顺位命中即止”限制，必须全面检索。该四类顺位源自《最高人民法院关于统一法律适用加强类案检索的指导意见（试行）》；类案定义同取该意见口径——与待决案件在基本事实、争议焦点、法律适用等方面相似且已裁判生效。
5. 文章检索：范围限理论性文章（权威学者）、实务性文章（承办人及相关法官检察官刊发文章）、党政政策文件与领导讲话、新闻材料（由案号回溯判决）；按专业性、权威性、相关性三原则筛选。
6. 检索报告按范式制作；类案引用须真实可查、案号明确；检索报告须标注检索时点与数据来源的最新更新时间。
7. 工具选用原则（反向管理——索引＋选用标准，不内置固化清单）：按任务类型选择工具类别——案例检索选用一站式专业库（总最推荐组合：Alpha、法信、聚法、微信搜一搜；检察文书可用把手案例），法规检索选用官方权威库并核对最标准文本（全国人大和“两高”官方公报数据库、各部委官网、国家法律法规数据库），文献检索选用学术数据库（万方、维普及图书馆数据库），可视化分析选用图表工具；具体工具与价格随市场变动，按本索引类别结合当期环境选用，选用结果经引用台账登记；调用 scripts/law_validator.py 校验法条现行效力、scripts/law_text_lookup.py 取条文原文（法条全文库以法条数据包内 registry.json 为单一事实源，按三级路径挂载解析；未挂载时原文核对降级“待核实”，效力校验不受影响）；罪名辨析按问题类型查（够不够罪查 threshold_index.md，能不能改轻查 severity_ladder.md，定什么罪经 README 定位 cluster\_*.md，怎么质证查 crime_evidence_map.md）；外部检索结果入库或引用时一并登记其最新更新时间（法规类标注修正年份与文号、案例类标注裁判日期、数据类标注采集时点）。

**禁止项**：禁止将检索报告作为辩护意见附件提交——必须制成独立文书（附电子版）单独提交或当面沟通；禁止引用无法定位原文的案例或内部口径；禁止编造案号或使用占位符——无案号注明“案号未公开/待查”；禁止凭记忆复述法条。
