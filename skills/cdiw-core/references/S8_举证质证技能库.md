# S8　举证质证技能库

适用节点：专项二举证质证；线 6 质证准备；庭前会议。

## §1 质证准备七项

1. 向法庭和公诉人确认证据种类与数量（防遗漏——曾发生阅卷 35 卷庭审 100 卷的教训；审判阶段重新全面阅卷；询问补充证据；申请提交有利讯问笔录）。
2. 证据向被告人开示核对听取意见。
3. 庭审分工（被告人侧重客观性、辩护人侧重合法性关联性；当事人生活语言意见经辩护人转译）。
4. 一组证据质证话术（“凡与我当庭讲的一样我都认可，不一样都不认可，其他意见由我的律师发表”）。
5. 制作质证提纲三式结合（注释式保留全貌、摘录式高效定位、引用式按三性总表并作辩护意见附件）。
6. 与公诉人法官商定举证方式（一证一举一质一辩/一节一举/一案一举/一组一举/复合式/仅被告人先质证/仅辩护人质证不辩论——尽量避免后两种不利方式；可索要举证提纲）。
7. 配套申请（证人出庭、调查证据、重新鉴定——书面申请附理由、依据、线索材料）。

## §2 证据三性两层理解与排序

1. 关联性两层：有无关联（无关联即止）；有什么关联（待证事实整理）。
2. 合法性两层：非法证据（先经排非审查——肉刑变相肉刑、威胁引诱欺骗所得供述；危及家人健康的严重威胁属非法证据；非法限制人身自由所得供述亦属之；庭前会议未排除不影响庭上再提）；不合法证据（单人提审、无见证人等程序违法——不能补正不得作为定案依据）。两种提法不同：“属于非法证据应当排除”与“不具有证据合法性不得作为定案依据”。
3. 客观性三标准：与查明的客观事实相符；与其他证据相符；与常识常情常理相符。
4. 发表顺序：先关联性（无关联即止）→ 有关联则合法性第一 → 客观性次之 → 最后讲“有什么关联”（待证事实）。

## §3 质证意见的表达规则

1. 发表“质证意见”而非“异议”——对有利证据也必须就待证事实发表意见（“该证言三性无意见，但证实了被告人注意力在右方、对左侧危险疏忽预见”）。
2. 质证如砌墙逐砖检验，法官建议留待辩论的不得随便附和。
3. 随时调整：公诉人未出示的笔录——要求出示或辩方举证时出示；未宣读部分也要质证（防不利内容被采信）；待证事实归纳不准确的当场纠正；有利待证事实予以确认补充。
4. 结合被告人及其他同案被告人质证意见（同案不利意见必须主动回应质疑）。
5. 用语规范：分点表述（“对某某证据的某某性有三点意见”）；质证阶段辩论紧扣三性、不展开全案体系论证；被拒后依《刑事诉讼法》第198条质证阶段允许辩论之规则申请，仍被拒则记录留待辩论。
6. 公诉人答辩的再答辩时机：当场简短回应或依申请发表。
7. **二审质证特别规则**：辩护人除对二审新的证据发表质证意见外，还应对原审证据的三性发表质证意见并书面提交法庭（原审证据经一审质证不等于二审免质——上诉审查覆盖原判证据体系）。

## §4 辩方举证规则

1. 必须对被告人有利，不得“交上去再说”；客观性把握不足的作“证据线索”提交或申请出庭。
2. 分类：按功能（反驳类/证明类/质疑类）；按目的（定性类/量刑类——量刑证据须向法庭说明关联）；按证明力（证据/证据线索）。
3. 基本要求：三性齐备；律师笔录两名律师（一名须为辩护人）签字捺印；书证有提取笔录；物证录像封存；排除伪证可能。
4. 七个具体动作：庭前五日提交证据目录与证据册（名称、来源、形式、待证事实、页数，一式两份，复杂案件可分送同案律师——录音录像等客观证据开示不构成妨害诉讼）；庭上带原件；事先商定举证方式；结合争议焦点着重说明待证事实；出示公诉人未示的卷内有利证据并说明待证事实；多媒体示证（视频演示、PPT、现场演示——网络犯罪现场演示直观有效）；辩方证人出庭将证明事项全部问出并堵死后路。

## §5 辩方审查报告（整合质证意见·按指控事实为纲）

**定位**：审查起诉/审判阶段对外提交的系统性证据审查文书；与律师版审查报告分工——（公诉版六部分结构）供内部审查，本节报告按指控事实组织、供对外提交，按案件与阶段选用。

1. **报告结构（以指控事实（起数）为纲）**：每起指控事实一节，节内固定四段——  
   a. **检察机关指控**：概述起诉书就该起事实的指控内容（时间、行为、金额、对象）；  
   b. **相关证据**：逐份罗列该起事实项下全部证据，每份证据标注笔录来源行（笔录名称＋卷宗＋页码＋日期）；言词证据采用问答式摘录（问句加括号＋回答原文摘录，仅摘与指控事实相关部分）；摘录保持案卷原文原貌，不作标点修正；  
   c. **质证意见**：逐份证据分点发表，每点按“问题描述＋法律依据＋质证结论”展开；结论明确（建议采信/建议不予采信/存疑；对真实性无异议但对关联性、证明目的有异议的分别表述）；  
   d. **辩方分析论证**：就该节事实作结论性分析，围绕构成要件展开（行为主动性、主观目的、金额认定等），必须依托本节已摘录证据与质证意见，指出指控能否成立及理由；金额矛盾的按存疑有利于被告原则提出认定意见。
2. **分节与归属规则**：每份证据归入与其最相关的指控事实一节；关联多起事实的证据在主要相关节完整处理、其他节以“证据N（节录）”引用；无法归入任何一起事实的全案性证据（户籍、前科、立功材料等）归入文末附录“通用证据质证”；附录另含证据链综合分析（矛盾逐条梳理：矛盾事项、矛盾内容、评价）与非法证据排除建议。
3. **质证点策略分级**：质证意见各点标注四级——致命（非法证据排除、证据链断裂，可能导向无罪）、重大（核心证据质疑、关键事实推翻，可能改变定性）、量刑（金额降档、情节认定，影响刑期）、程序（取证瑕疵，施压或为排非铺垫）；分级为辩护词取舍与庭审详略提供决策依据。
4. **总体质证结论**：附录末分起给出编号结论与处理建议（不予认定/就低认定/重新评价等），末尾附保留补充、变更质证意见的权利声明。

## §6 对公诉人质证意见的答辩四情形

形式要件被质疑（形式合法或申请补正或申请法庭调查核实）；客观性被质疑（有印证、退一步系合理可能、或申请出庭当庭判断）；与在案矛盾（逐项分析矛盾性质——如补充合同的隐瞒方、自愿性）；关联性被质疑（属量刑证据并分开呈现）。
