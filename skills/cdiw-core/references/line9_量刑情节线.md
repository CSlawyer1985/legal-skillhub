# 线 9　量刑情节线（含认罪认罚）

适用节点：量刑测算、量刑情节认定、认罪认罚决策。

**执行步骤**：

1. 量刑测算：查量刑档次与立案标准，按情节测算，省级细则查（浙江已预置）；刑期意见具体到月。
2. 认罪认罚按三问框架决策：
   a. 认不认——可权衡：无罪辩护可能导致长期羁押并最终实刑，认罪认罚或可争取取保、缓刑、不起诉；程序选择交当事人按自身利益决定；
   b. 何时认——已如实供述且无非法取证的保持供述稳定；未供述的先全面法律咨询，由当事人按构罪要件自行评估，待阅卷判断证据充分性后再定；侦查阶段不轻易劝认（定性争议大的案件认罪会强化司法人员心证）；
   c. 认什么——认罪＝自愿如实供述且对指控犯罪事实无异议；认可事实但不认可罪名的，原则上不构成标准认罪认罚；数罪仅供述部分罪名的，全案不作“认罪”认定，但如实供述部分可争取从宽。
3. 技术活四维：构罪研判（具结前详阅案卷，审查供述自愿稳定性与旁证）；刑期到月（处理认罪认罚从宽与自首坦白等情节的重叠）；罚金数额（按非法所得或经营额倍数区间论证）；强制措施联动（认罪认罚与不批捕、取保联动，先作专业评判再建议）。
4. 三种情形：有罪才认（证据充分的建议尽早认罪认罚并释明从宽幅度——侦查阶段开始最多可减 30%，现行规范上限见法发〔2021〕21号；实务按“三二一”分档掌握：侦查阶段约 30%、审查起诉约 20%、审判阶段约 10%，以办案机关最终意见为准；且快审轻判、利于减刑假释）；无罪也认（向当事人释明继续无罪辩护与认罪认罚争取缓刑、相对不起诉两条路径，由其选择——相对不起诉是争议案件的最优解）；有罪不认（当事人缺乏自愿性的，即使结果有利也不得推动认罪认罚）。
5. 侦查阶段配套工作：会见确认（讲清法律后果、确认自愿）；摸底论证（正式决定前按量刑规则评估大致区间，使当事人心中有数——自愿性根源在于对具体刑罚的内心接受）；催促尽早结案；挖掘、完善、制造从轻减轻情节（固定自首归案经过、从犯认定、立功线索、劝同案犯自首）并提醒写入起诉意见书；共同犯罪中注意认罪对全案定性的影响——可先争取变更强制措施，待主犯判决后再具结。
6. 审查起诉阶段配套工作：拿卷后三日内会见听取对起诉意见书的意见（无罪/轻罪/罪轻三分处理）；量化量刑情节（类案情节逐项列表对比）；反复争取最低量刑并每次讲清理由；与检察院协商前取得当事人与家属统一授权；催签具结书。
7. 量刑意见按两句话模板发表。

**禁止项**：禁止简单叠加量刑情节比例致超过 100%；禁止在当事人缺乏自愿性时推动认罪认罚；禁止建议当事人认下其不认可的重罪罪名——罪名有重大争议时按“认事实、辩定性”路径处理；禁止在未取得当事人与家属授权前向检察机关提出量刑意见。
