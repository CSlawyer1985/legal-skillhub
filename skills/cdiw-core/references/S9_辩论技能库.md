# S9　辩论技能库

适用节点：专项二法庭辩论；线 8 辩护意见撰写；庭前会议发言。

## §1 庭前准备

1. 辅导被告人“何时说、说什么、怎么说”三方案（程度低者请法庭公正判决余由律师发表；程度高者先发表核心观点；复杂案件请法庭安排律师先讲被告人补充；第二轮由被告人提事实异议——当事人陈述事实更有力）。
2. 被告人表达四要：态度诚恳；用生活语言不班门弄斧；善于求助法庭；善于以情动人。**最后陈述两全法**——当庭脱稿陈述显真诚，陈述内容提前制成书面材料，讲完后经法警呈交入卷，供合议庭其他成员阅看。
3. 两方分工：被告人管事实辩驳与情感诉求；辩护人管证据分析、事实认定、罪名与法理。
4. 准备两版书面意见：详细版（详至法官无需翻卷，附证据、判例、法理、图表，重点红笔标注）＋口述版（要点提纲）。
5. 庭前提交辩护意见三情形：认罪认罚案件（必提交——具结书无说理过程，说明义务在辩护人）；简易程序与普通程序简易审理案件（当庭宣判率高）；案情**特别**复杂但事实证据不会因庭审变化的案件（提交辩护意见供法官庭前了解辩护要点，庭审中对疑问部分着重审查，防遗漏；庭审可能发生事实证据变化的改交辩护提纲，防法官先入为主）。

## §2 聆听规则

1. 公诉意见：常规四段结构；有经验的公诉人会将第二轮内容前置（辩驳权对等）；听清观点变化与焦点归纳后针对性答辩；只安排一轮辩论的法庭须在第一轮充分展开；澄清口误；只反驳有依据的；不当言论当场反对。
2. 被告人意见：引用其生活语言翻译成法律语言，形成“一加一大于二”配合。
3. 其他辩护人意见：借鉴（无罪观点引用于罪轻辩护：“如果他的观点被采纳，我的当事人也是无罪的”）；补充（加强论证）；回应不利指证（只说己方轻、不指控他人重）；共同犯罪协同规则（认罪认罚辩护人呼吁法庭重视无罪轻罪意见、罪轻不否定无罪；无罪辩护律师一分为二看待认罪认罚陈述；全案考虑“覆巢之下无完卵”；多点突破全员受益；必要时提出反对）。

## §3 第一轮辩论三感

1. **现场感**：结合庭审因素现场讲评（被告人当庭供述辩解、发问质证内容、各方观点、旁听情况）；书面意见口语化转化（“刚才的法庭发问中，被告人称……与其他证据相互印证”）；肢体语言适度。
2. **层次感**：**六层次分析表达**——事实 → 证据 → 法律 → 法理 → 判例 → 常识常情常理；分层标准统一（无罪观点按构成要件分析时不得混入主观恶性较轻的量刑表述）；口语化分点（一、二、三；首先、其次、最后）；长意见提交书面对照。
3. **正义感**：不曲解证据（合理怀疑须合理——以当事人明知不利仍坚持辩解的事实作支撑性表述）；不曲解法律规定（利用漏洞但不得歪解）；不曲解法理（用通说）；引用的技术规则与公诉人法官一致，结论才可能被采纳。

## §4 第二轮辩论四规则

针锋相对（只针对性答辩；对正确及有利观点反而赞同强调）；言简意赅（三段论：“公诉人某观点不对——我方观点——理由”）；引经据典（直接引用证据、法条、法理与常情常理；当庭核对公诉人引用证据真实性——引经据典可直接驳倒）；总结提升（归纳争议为理论问题或概念对辨——六对概念辨析示范，一锤定音，争取写入判决理由）。

## §5 常见问题九项应对

发言被打断（调整表达、指明书面意见详述、必要时申请休庭或请公诉人居中）；限时（长话短说技能、重点扩展或精简并指明书面详版、申请延时）；公诉人曲解（就事论事指出不指责）；人身攻击（当场反对请法庭制止，不反向攻击）；被告人拒绝辩护（庭前充分沟通预防；解释观点系为其利益并尊重其意见）；被同案辩护人攻击（以事实依据回应、请求法庭制止）；被告人意见突变（申请休庭沟通后继续）；两位辩护人分工（事实/法律、无罪/量刑骑墙式、质证/辩论等维度）；脱稿四阶段（读稿 → 边读边交流 → 全脱稿 → 脱稿为基础引证时看稿）。

## §6 程序保障

开庭过程中注意保障被告人合法权益（解除戒具、坐着受审、饮水等），及时提醒法庭；举证阶段说明证据名称、来源、内容、待证事实；审判阶段每隔半月电话询问案情进展并作记录（沟通节奏见 S6§7 第 8 项）。
