# 常见犯罪案件证据指引库（104罪名·刑辩知识库）

> **入库版本**：cdiw-core v1.3.0（2026-08-20）；**来源**：《常见犯罪案件证据指引》（104罪名，含【刑法条文】【证据要点】【犯罪构成要件】【侦查工作中应注意的问题】【取证指引】五类模块）
> **性质定位**：原文系侦查取证视角的证据体系指引；本库按辩护证据审查视角组织，供阅卷质证、证据完整性审查、取证申请方向确定时反向对照使用。

## 一、刑辩使用方法论（三大用法）

### 用法一：证据完整性反向对照（缺项审查—证据不足辩护）

原文【证据要点】系控方定罪应完成的证据体系清单。辩护人阅卷时逐项对照：

1. **逐类清点**——按八类证据（供述与辩解、被害人陈述、证人证言、物证、书证、鉴定意见、勘验辨认笔录、视听资料，部分罪名另有"其他证据材料"）清点在案证据；
2. **定位缺项**——指引列明而案卷缺失的证据项，即为证据链缺口。核心要件事实（主观明知、行为实施、危害后果、因果关系、数额）对应的证据缺项，落入"证据不足、未达排除合理怀疑标准"的质证结论（与证据矛盾排查规则同此逻辑）；
3. **区分对待**——并非一切缺项均有辩护价值：替代性证据已充分印证的缺项（如无目击证人但有全程监控）不作主攻；指向核心要件且无替代印证的缺项作为主攻点。

### 用法二：逐类证据质证对照（指引条目—质证维度映射）

指引的每一类证据条目对应证据审查框架既有质证框架：

| 指引证据类别 | 质证框架 |
| --- | --- |
| 犯罪嫌疑人供述和辩解 | 第六节言词证据：核对同步录音录像一致性、讯问起止时间与地点连续性；第四节排非审查（刑讯逼供线索） |
| 被害人陈述 | 第五节主体轴：利害关系人陈述的孤立印证检测；细节互印审查 |
| 证人证言 | 第一节取证路径（自行取证、申请出庭）；第二节取证风险边界 |
| 物证 | 第六节书证物证：原件核对、保管链各环节笔录（搜查—扣押—保管） |
| 书证 | 第六节原件核对；复印件与原件一致性 |
| 鉴定意见 | 第三节五项审查框架及"六查"操作（资质、检材保管链、方法标准、关联性、意见范围） |
| 勘查、辨认等笔录 | 第六节现场勘验笔录见证人在场要件；辨认笔录程序合法性（混杂辨认、辨认前不见面） |
| 视听资料、电子数据 | 第六节电子数据：原始载体扣押与哈希校验、提取主体合法性 |
| 其他证据材料 | 归案材料、前科材料的程序合法性核对 |

### 用法三：控方自认薄弱点利用（质证金矿）

原文**【侦查工作中应注意的问题】**（5罪名）与**【取证指引】**（3罪名）系侦查机关自己总结的取证难点与案件特点——控方自认难点的，即为辩方质证的主攻方向；引用时注明"侦查指引自认"，强化质证意见说服力。含此模块的罪名见索引表"条目结构"列标注。

## 二、与既有工作线的衔接

- **取证线**（取证与证据审查线阅卷步骤后）：阅卷质证前先查本库对应罪名条目，确定证据完整性对照基线与取证申请方向；
- **文书线**：质证意见按"指引证据类别—在案证据—质证维度—质证结论"四段式展开（与文书生成线质证意见结构衔接）；
- **量刑线**：本库【刑法条文】仅为条文定位索引，量刑档次查询用scripts/crime_lookup.py（罪名全量索引源assets/data/crime_index.json现行有效483罪名，量刑数据源assets/data/crime_sentencing_table.json覆盖483罪名（2026-08-21汇编202608批次扩容））；
- **检索线**：罪名辨析时结合crime_elements.json构成要件数据与本库证据体系交叉印证。

## 三、使用规则与校验要求

1. **法条核取强制**：各罪名条目内【刑法条文】为条号引用（条文原文已于1.0.0起改为经法条全文库统一供给，消除照录区与刑法库的双处维护），正式引用时**必须**经scripts/law_text_lookup.py（--law 刑法 --article 条号）核取原文并经scripts/law_validator.py校验现行有效性；
2. **四层信息分层**：本库内容属"证据层"信息（证据体系结构），非"事实层"；对照结论属"推断层"，输出时标注"律师分析"；
3. **来源溯源标签**：本库内容标注来源标签[入库资料——常见犯罪案件证据指引]；指引未覆盖的罪名（104罪之外）按通用证据审查框架审查并标【通用框架】；
4. **数据一致性**：罪名罪名数、条目结构与CHANGELOG.md v1.3.0记录互证；本库不替代案卷证据本身，仅为审查基线。
