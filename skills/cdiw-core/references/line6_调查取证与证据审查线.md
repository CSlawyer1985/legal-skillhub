# 线 6　调查取证与证据审查线

适用节点：取证申请、阅卷、证据审查、质证准备、证据矛盾排查。

**执行步骤**：

1. 阅卷六步：a. 审查犯罪嫌疑人基本情况（未成年人、职务与工作性质、特殊身份，逐条与指控事实和量刑结合）；b. 穷尽被控罪名数与量刑区间，形成“说不”（不构成该罪/该事实/该证据非法或不充分）与“说是”（验证当事人辩解）两条线；c. 标出证明力最强的指控证据及其证明目的；d. 先听当事人辩解再深入阅卷（与公诉人阅卷顺序相反），让当事人说透；e. 审查辩解依据——有无其他证据印证、是否符合常识常情常理，先假设辩解成立再寻找一切依据印证；f. 逐项排查控方证据体系的矛盾与漏洞。阅卷同步制作阅卷笔录，固定涵盖五项内容：指控事实与罪名是否准确；证据是否确实、充分；当事人辩解及其依据；拟提辩护意见所依据的事实与证据；办案程序是否存在违法。
2. 供述与辩解笔录按“八看”逐次审查：看次数、看时间、看地点、看讯问人、看身份、看权利告知、看正文、看落款——各项具体审查要点与典型问题（疲劳审讯识别、先供后证与先证后供、笔录“分身”签字、重复供述采纳规则、笔录正文六看、落款日期穿越等）。
3. 发现辩点三途径：证据比对（同一证据前后比对、证据之间比对）；仔细探究“情况说明”（是否合理、有无随意出具）；会见当事人核实无罪辩解（错案多源于漠视无罪辩解）。
4. 客观性与技术性证据优先审查：物证书证查收集全面性、程序正当性（扣押清单、见证人、拍照录像封装）、保管流转（是否原物）；辨认笔录查七类问题（特征突出、安排不严谨、暗示辨认、尸体辨认简单化、无录像或中断、笼统化、短时多次）；鉴定意见查资质、检材、依据、规程执行（时长对照）、结论排他性，必要时申请鉴定人出庭并建议聘请专家辅助人。
5. **特殊类案件证据审查**：商业秘密鉴定意见（四特征＋程序审查七项＋实体审查八项）；毒品物证（三特点三难）；法医学鉴定（CSE 法则＋病理/临床/精神病/保外就医分类规则）；电子数据（12 部分框架＋哈希校验＋镜像复制）；污染环境（危废名录三对比＋污水采样三点＋刑民界分）；死刑案件与涉未成年人案件证据标准（随阶段包扩充）。
6. 自行调查仅限能够证明无罪或罪轻且能自行调取的证据，附取证清单与合法性自检表；申请调查按六要素制作调查取证申请书、重新鉴定申请书、排除非法证据申请书；对无能力调查、被调查对象不配合、向被害人及其提供的证人调查的情形，申请检察院或法院调取；必要时提示查看现场、请教专家辅助人。
7. 做证据矛盾结构化比对；涉罪名证据体系对照的，查（104 罪名证据指引库）作证据完整性反向对照与控方自认薄弱点质证素材，超出覆盖范围的按通用框架审查并标注【通用框架】。

**禁止项**：禁止将当事人陈述直接写成已证实事实；禁止对当事人不利的证据提交或调查；禁止在证据客观性把握不足时直接提交家属提供的证人笔录——改作“证据线索”提交或申请出庭。
