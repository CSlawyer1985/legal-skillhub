# 禁止项索引（按线汇总·行为禁止）

> 用法：各线输出前按所属线快速校验；跨线任务合并所涉各线条目一次校验；全局底线见 SKILL.md Guardrails，适用于所有输出，不因本索引而免检。本索引管“行为禁止”（什么不能做），表述类禁止见 quality_checklist.md（管“表述禁止”，即什么不能写）；文书交付前两表并用。各条适用范围以所属线正文禁止项为准。

| 线/范围     | 禁止项（要点）                                                                                                         |
| -------- | --------------------------------------------------------------------------------------------------------------- |
| 全局       | 诱导翻供串供毁证伪造证据；承诺取保、不捕、撤案或判决结果；输出胜诉率；引用无法定位原文的案例或内部口径；当事人陈述写成已证实事实；输出真实案件数据；向家属披露案卷证据细节、证人身份；传递口信外涉案信息；建议认下不认可的重罪 |
| 线 1 接待   | 未分析即下结论；过度迎合；向家属披露案卷证据细节、证人身份信息；传递物品信件口信以外的涉案信息                                                                 |
| 线 2 会见   | 沿用传统四步法流程（先了解案情再针对性咨询）；第三步之前询问案情；当事人未供述时要求其陈述犯罪事实；死记硬背式辅导                                                       |
| 线 3 期限   | 凭记忆计算期限；忽略节假日顺延；关键期限无法确认时按默认值推算不标注“待核实”                                                                         |
| 线 4 沟通   | 因“不交手续不影响会见”而省略递交手续；催促办案进度；沟通中指责办案人员；无书面材料空口沟通重大意见                                                              |
| 线 5 强制措施 | 羁押必要性审查中直接要求检察院变更强制措施（只能“建议公安机关”）；“可以取保候审”表述；承诺取保不捕撤案结果                                                         |
| 线 6 调查取证 | 当事人陈述写成已证实事实；提交或调查对当事人不利的证据；客观性把握不足时直接提交家属提供的证人笔录                                                               |
| 线 7 检索   | 检索报告作为辩护意见附件提交；引用无法定位原文的案例或内部口径；编造案号或用占位符；凭记忆复述法条                                                               |
| 线 8 文书   | 从零手写排版代码（套用标准模板）；跳过强制检查与用户确认直接交付；意见类文书用“此致某机关”；问号感叹号等情绪化标点；“辩解”称谓                                               |
| 线 9 量刑   | 简单叠加情节比例超 100%；当事人缺乏自愿性时推动认罪认罚；建议认下不认可的重罪罪名；未取得授权前向检察机关提量刑意见                                                    |
| 线 10 合规  | 直接询问“有无刑讯逼供”；可能被简单补证堵漏的瑕疵在庭前会议提前暴露                                                                              |
| 专项一 退赔   | 向被害人施压或诱导虚假陈述；制作虚假谅解书或倒签材料；承诺赔钱即放人                                                                              |
| 专项二 庭审   | 问对己方不利且无后手的问题；诱导式发问；无罪辩解案件中笼统“没有意见”；提交不利或客观性存疑证据；照本宣科辩论；与被发问人争吵激怒对方；认罪认罚案件辩论先行攻击定性；卷内有利证据不提示不出示                 |
