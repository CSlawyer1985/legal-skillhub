# 索引三：罪与非罪界限索引（threshold_index）

> **入库版本**：cdiw-core v1.5.0（2026-08-20）；**定位**：高频罪名的入罪门槛、出罪情形与无罪裁判要旨汇编——以"够不够罪"为问题的第一索引，供收案初评、出罪方案设计与不捕不诉意见书撰写。
> **数据来源**：入罪门槛取自case_filing_standards.json（483罪名（2026-08-21扩容前为275））；出罪情形取自刑法明定条款、量刑数据表所载司法解释条款及各族群辨析文件【罪与非罪出口】段（括注锚点）。本索引系**汇总视图**，正式引用前必须经scripts/law_validator.py校验。
> **无罪要旨的诚实声明**：本索引仅收录**已核验的规范性出罪规则**（下列三件经北大法宝核验现行有效，检索时点2026-08-20：高检发办字〔2023〕187号第十二条〔醉驾出罪〕、法释〔2024〕4号第十条第二款〔虚开出罪〕、刑法第201条第4款〔逃税初犯免责〕）；**不预录具体案例案号**——典型案例的无罪裁判要旨经检索线（法律检索线）按"无罪检索指引"栏关键词实查后引用，案号不明写"案号未公开/待查"，严禁编造。

## 一、通用出罪框架（一切罪名前置审查）

| 出罪路径 | 法律依据 | 审查要点 |
| --- | --- | --- |
| 情节显著轻微但书 | 刑法第13条 | 危害量级综合评价（数额、手段、后果、动机） |
| 意外事件 | 刑法第16条 | 无预见可能性（见cluster_personal.md H3） |
| 正当防卫 | 刑法第20条 | 不法侵害正在进行+防卫限度；特殊防卫（行凶、杀人、抢劫、强奸、绑架等严重暴力侵害的无限防卫） |
| 紧急避险 | 刑法第21条 | 危险现实性+避险不得已+限度 |
| 追诉时效 | 刑法第87-89条 | 法定最高刑对应时效档；立案后逃避侦查的不受限 |
| 自诉程序 | 刑法第98条等 | 侵占（绝对自诉）等——公诉程序追诉的程序性出罪（P1） |
| 行政前置/免责条款 | 罪刑各别 | 逃税初犯免责（第201条第4款）等 |
| 数额门槛 | 立案追诉标准 | 未达门槛即不构成（本索引各条目） |

## 二、分罪名界限条目（按高频辩护场景排序）

### 1. 危险驾驶罪（醉驾）

- **入罪门槛**：血液酒精含量80毫克/100毫升以上（醉酒驾驶）。
- **出罪情形**：①**血液酒精含量不满150毫克/100毫升**且无从重情形的，认定情节显著轻微、危害不大，不予定罪（高检发办字〔2023〕187号第十二条）；②急救伤病人员等紧急情况驾驶；③小区、停车场等场所短距离挪车、停车入位；④短距离接替驾驶；⑤紧急避险（刑法第21条）。
- **技术出罪**：酒精鉴定证据链审查（抽血程序、血样保管链、鉴定资质——鉴定意见六查）。
- **无罪检索指引**："醉驾 出罪 150毫克""血液酒精 鉴定程序 排除"。

### 2. 交通肇事罪

- **入罪门槛**：死亡1人或重伤3人以上负事故全部/主要责任；直损50万以上负主责无力赔偿；重伤1人以上负全责并具酒驾、毒驾、无证、无牌、安全装置失灵、逃逸等情形之一（立案追诉标准（一）口径，正式引用前校验）。
- **出罪情形**：负同等责任且死亡未达3人的不入罪；负次要责任的肇事方不入罪；重伤3人以上但负同等责任以下的不入罪；"逃逸"认定须明知发生事故。
- **无罪检索指引**："交通肇事 责任认定 次责 不构成""事故认定书 质证"。

### 3. 虚开增值税专用发票罪

- **入罪门槛**：虚开税款数额10万以上，或致使国家税款被骗取5万以上。
- **出罪情形**：**为虚增业绩、融资、贷款等不以骗抵税款为目的，没有因抵扣造成税款被骗损失的，不以本罪论处**（法释〔2024〕4号第十条第二款）。
- **降格出口**：退回逃税评价并用初犯免责（见第4条）。
- **无罪检索指引**："虚开 不以骗抵税款为目的""环开 对开 无罪""如实代开"。

### 4. 逃税罪

- **入罪门槛**：逃税数额10万以上且占应纳税额10%以上（经税务机关下达追缴通知后仍不补缴的追诉口径）。
- **出罪情形**：**初犯免责条款（刑法第201条第4款）——经税务机关依法下达追缴通知后补缴应纳税款、缴纳滞纳金、已受行政处罚的，不予追究刑事责任**（五年内因逃税受过刑事处罚或被税务机关给予二次以上行政处罚的除外）。
- **实务要点**：涉案后第一时间评估补缴的出罪价值（须经当事人与家属授权确认后推进）。
- **无罪检索指引**："逃税 初犯免责 201条第4款""不予追究刑事责任 补缴"。

### 5. 盗窃罪

- **入罪门槛**：数额较大（一类地区3000元/二类2000元），或入户盗窃、携带凶器盗窃、扒窃、多次盗窃（2年内3次以上）四类无数额门槛行为。
- **出罪情形**：数额未达且非四类行为；数额达"较大"起点50%以下且系初犯、全部退赃退赔、被胁迫参加等情形的可不起诉（量刑指导意见从宽口径，正式引用前校验）；拿自己所有被他人占有财物的认识错误阻却故意。
- **无罪检索指引**："盗窃 数额较大 未达""入户盗窃 目的要件"。

### 6. 诈骗罪与合同诈骗罪

- **入罪门槛**：诈骗6000/4000元（电信网络诈骗3000元）；合同诈骗个人2万/单位10万。
- **出罪情形**：**民事欺诈界限**——有履约能力、履约行为、纠纷因市场原因的属合同纠纷（cluster_finance.md F4）；数额交叉地带（诈骗6000元-合同诈骗2万元间的合同领域事实两头不入罪）。
- **无罪检索指引**："诈骗 民事纠纷 区分 履约能力""合同诈骗 无罪 非法占有目的"。

### 7. 敲诈勒索罪

- **入罪门槛**：数额较大（4000/2500元）或多次敲诈勒索（2年内3次以上）。
- **出罪情形**：**行使权利**——基础事实真实+权利主张+手段在合理边界（消费维权、工伤索赔）的不构成（cluster_property.md P6）；数额未达且非多次；威胁内容不可能实现且被害人明知。
- **无罪检索指引**："敲诈勒索 维权 无罪""天价索赔 不构成"。

### 8. 非法吸收公众存款罪

- **入罪门槛**：非法吸存100万以上，或直损50万以上，或对象150人以上（情节加重的另升档）。
- **出罪情形**：**社会性缺项**——在亲友或单位内部针对特定对象吸收资金的不构成（非法集资司法解释口径，正式引用前校验）；未达三档门槛。
- **无罪检索指引**："非吸 特定对象 亲友""社会性 出罪"。

### 9. 骗取贷款罪

- **入罪门槛**：以欺骗手段取得贷款等给银行造成**直接经济损失50万以上**（刑法修正案（十一）后以重大损失为要件，引用前经law_validator校验第175条之一现行文本）。
- **出罪情形**：有真实足额担保、案发前已归还、未造成实际损失的——损失要件缺项出罪。
- **无罪检索指引**："骗取贷款 重大损失 要件""足额担保 无罪"。

### 10. 信用卡诈骗罪（恶意透支）

- **入罪门槛**：恶意透支5万以上+非法占有目的+经发卡银行**两次有效催收**+超过三个月不归还（四要件并存）。
- **出罪情形**：任一要件缺项——透支用于经营且积极还款（无非法占有目的）；催收未有效送达；三个月内归还；数额未达5万（利息、复利、手续费不计入）。
- **无罪检索指引**："恶意透支 有效催收""非法占有目的 反证"。

### 11. 帮信罪与掩隐罪

- **入罪门槛**：帮信——为3个以上对象提供帮助/支付结算金额20万以上/提供资金5万以上/违法所得1万以上等；掩隐——2021年解释后无固定数额门槛，综合判断。
- **出罪情形**：帮信门槛未达；掩隐情节显著轻微+认罪认罚退赃初犯从宽条款；两罪共通的**明知推定被合理解释推翻**（交易价格异常、频繁夜间交易等推定情形的替代解释）。
- **无罪检索指引**："帮信 情节显著轻微""掩隐 从宽条款""明知推定 反驳"。

### 12. 故意伤害罪

- **入罪门槛**：轻伤二级以上（人体损伤程度鉴定标准）。
- **出罪情形**：**轻微伤不构成犯罪**（治安处罚）；正当防卫（互殴与防卫的区分——起因、时间、对象、限度四要件）；伤情鉴定的伤病关系审查（既往病变参与度）。
- **无罪检索指引**："轻微伤 治安案件""互殴 正当防卫 区分"。

### 13. 非法拘禁罪

- **入罪门槛**：拘禁24小时以上；或使用械具、捆绑、殴打、侮辱；或致轻伤以上；或致自杀自残重伤/精神失常；或3人次以上每次4小时以上（黑恶情形另从严）。
- **出罪情形**：拘禁时间短（未达24小时）、手段平和、无伤情——情节显著轻微；索债型中债务真实且手段克制。
- **无罪检索指引**："非法拘禁 时间 情节显著轻微""讨债 拘禁 出罪"。

### 14. 寻衅滋事罪

- **入罪门槛**：强拿硬要1000元以上/损毁占用财物2000元以上/1轻伤或2轻微伤以上/多次追逐拦截辱骂恐吓等。
- **出罪情形**：**事出有因**——因债务纠纷、邻里矛盾、消费争执等有起因的行为不属"无事生非"（司法解释精神，正式引用前经检索线核验）；情节未达各项标准；网络寻衅型中点击浏览量证据的审查（编造型与检举型的区分）。
- **无罪检索指引**："寻衅滋事 事出有因 无罪""口袋罪 罪刑法定"。

### 15. 贪污罪、受贿罪、挪用公款罪

- **入罪门槛**：贪污/受贿3万元以上（或1万-3万+特定情形）；挪用公款——非法活动3万以上、营利活动或超3个月未还5万以上。
- **出罪情形**：数额门槛未达；主体身份存疑（非国家工作人员降格评价，见cluster_duty.md D1-D4）；挪用公款三类型要件（3个月内归还+非非法活动+未达5万）；受贿的职务关联断裂（无请托的礼尚往来）。
- **无罪检索指引**："受贿 礼尚往来 职务关联""贪污 主体身份 不明""挪用公款 三个月 归还"。

### 16. 行贿罪

- **入罪门槛**：为谋取不正当利益给予财物3万以上（1万-3万+情形）。
- **出罪情形**：**因被勒索给予财物且没有获得不正当利益的，不是行贿**（刑法第389条第3款）；为谋取**正当利益**给予财物的不构成（第389条第1款反面解释）；单位行贿20万以下（数额地带出罪）；被追诉前主动交待的从宽（第390条第2款——修正案十二调整后梯度，引用前校验）。
- **无罪检索指引**："行贿 被勒索 不正当利益""正当利益 出罪"。

### 17. 滥用职权罪、玩忽职守罪

- **入罪门槛**：直损30万以上；或死亡1人/重伤3人/轻伤9人等伤亡标准。
- **出罪情形**：损失核算之争（债权可实现部分的扣除、直接损失界定）；职责边界不明（义务来源存疑）；集体决策分散个人责任。
- **无罪检索指引**："滥用职权 职责边界""玩忽职守 损失计算 出罪"。

### 18. 失火罪、重大责任事故罪

- **入罪门槛**：失火——直损50万/一死或三重伤/十户烧毁/过火有林地2公顷等；责任事故——直损100万（矿山200万）/死亡1人或重伤3人。
- **出罪情形**：未达伤亡与损失标准；多因一果中监管责任与直接责任的区分（安全评价机构、发包方等第三方责任分散）。
- **无罪检索指引**："失火 过火面积 认定""责任事故 因果关系 介入"。

### 19. 毒品犯罪

- **入罪门槛**：非法持有海洛因10克/鸦片200克以上；贩卖无论数量。
- **出罪情形**：吸毒者持有10克以下且无贩卖证据；为吸毒者代购仅收合理劳务费不加价的不构成贩卖（代购规则，正式引用前经检索线核验现行口径）；**特情引诱**——犯意引诱（本无犯意，引诱后查获）的数量扣除与量刑从宽、数量引诱的从宽（特情侦查规则）。
- **无罪检索指引**："代购 毒品 不构成贩卖""特情引诱 数量扣除"。

### 20. 赌博类

- **入罪门槛**：赌博——抽头渔利5000元/赌资5万/参赌累计20人/组织10人以上赴境外赌博；开设赌场——赌博机10台/违法所得5000元/赌资5万/参赌20人等。
- **出罪情形**：**亲友间娱乐性棋牌活动（不以营利为目的、不抽头）不构成**（司法解释口径，正式引用前校验）；数额未达。
- **无罪检索指引**："赌博 亲友娱乐 不构成"。

## 三、使用规则

1. **收案初评顺序**：先查本索引对应条目（入罪门槛够不够）→通用出罪框架（但书/正当化事由/时效）→severity_ladder.md（降格空间）→cluster_*.md（辨析详情与证据差异）；
2. **数额的地区档差**：盗窃/诈骗/抢夺/敲诈勒索等一类/二类地区数额档差，浙江执行标准以本省规定为准（localization/与本省细则核对），涉数额出罪的标注信息时点；
3. **无罪案例引用纪律**：本索引不预录案号；检索线产出的无罪类案按效力位阶排序引用（指导性＞案例库参考＞公报＞最高法典型/生效＞省高院＞中基层），无案号写"案号未公开/待查"；
4. **四层信息分层**：入罪门槛系法律层（须校验）；出罪情形系法律层与推断层混合（标注来源）；检索指引系方法论层。
