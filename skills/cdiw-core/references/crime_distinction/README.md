# 罪名辨析四维索引库（刑辩知识库）

> **入库版本**：cdiw-core v1.5.0（2026-08-20）；**定位**：罪名辩护的四维交叉索引体系——罪名与罪名对比（此罪与彼罪）、罪名轻重层级（降格路径）、罪与非罪界限（出罪出口）、罪名与证据关联（证据差异即辩点），供罪名辩护（变更、降格、出罪）时定位辨析对、要件差异、轻重梯度、出罪规则与证据抓手。
> **数据来源**：法定刑与立案标准均取自assets/data/crime_sentencing_table.json与assets/data/case_filing_standards.json（483罪名（2026-08-21扩容前为275），v1.1.0规范化后口径，单一事实源）；罪名名称与章节归属以assets/data/crime_index.json（现行有效483罪名）为权威基准；证据指引定位取自evidence_guide/（104罪名）；构成要件辨析参考assets/data/crime_elements.json（10罪名详版）。
> **本库性质**：辨析框架与索引（推断层为主），非法条原文库；正式引用法条前必须经scripts/law_validator.py校验现行有效性。

## 一、三辨框架（本库核心方法论）

罪名辩护的三个辩护目标方向，每个方向对应不同的辨析问题与证据策略：

| 辨析方向 | 辩护目标 | 核心辨析问题 | 证据策略 | 典型路径 |
| --- | --- | --- | --- | --- |
| **罪与非罪** | 出罪（无罪） | 指控事实是否该当构成要件；数额/情节是否达立案标准；是否存在但书（刑法第13条）、正当化事由 | 要件证据缺项审查——指向核心要件且无替代印证的证据缺项为主攻 | 不构成犯罪、撤案、不起诉、无罪判决 |
| **轻罪与重罪** | 降格（重罪改轻罪） | 同一事实在轻重两罪间如何归属——主观内容（故意/过失、明知程度）、行为方式强度、结果归属 | 主观要件降格论证——用客观证据反推主观内容达不到重罪要求 | 故意杀改故意伤害致死、贩卖毒品改非法持有、集资诈骗改非吸 |
| **此罪与彼罪** | 变更（改指控较轻的它罪） | 竞合关系（法条竞合从特别法、想象竞合从一重但辩护可争轻罪）、构成要件交叉地带 | 竞合要件证据对照——按特别罪名额外要件逐项检验证据是否齐备 | 盗窃改侵占（自诉）、职务侵占改挪用资金、掩隐改帮信 |

**三辨联动规则**：同一案件的罪名辩护按"出罪→降格→变更"顺位展开，先审查罪与非罪（要件证据缺项），再审查轻重梯度（主观要件降格），最后审查此彼归属（竞合对照）；三层次均须提供两套以上方案供当事人选择（利益最大化原则）。认罪认罚场景下罪名有重大争议的，按"认事实及辩定性"路径处理（SKILL.md禁止性底线），不得建议当事人认下其不认可的重罪罪名。

**轻重梯度提示**：多数辨析对存在法定刑阶梯（如以危险方法危害公共安全〔未造成严重后果3-10年〕＞交通肇事逃逸〔3-7年〕＞交通肇事〔3年以下〕＞危险驾驶〔拘役〕），降格一档即跨越数年量刑空间，且直接影响缓刑适用可能与羁押必要性评估（联动强制措施线与量刑情节线）。

### 索引二：轻罪与重罪层级索引（severity_ladder.md）

### 索引四：罪名与证据关联索引（crime_evidence_map.md）

**索引选择规则**：问"够不够罪"→索引三；问"能不能改轻"→索引二；问"定什么罪"→索引一；问"怎么质证取证"→索引四。复合问题按"索引三→索引二→索引一→索引四"顺位组合检索。

## 三、辨析条目统一结构（各族群文件）

每对辨析按六段式组织，保证跨条目可比、可grep（锚点格式"### 辨析P1：盗窃罪 ↔ 侵占罪"）：

1. **【要旨】**一句话区分核心（引用crime_elements.json"区分关键"字段口径）；
2. **【法定刑对照】**轻重梯度表（数据取自crime_sentencing_table.json，标注条号；表中数额含地区档差的注明"以本省规定为准"；不在数据表内的罪名依刑法条文转录并标注law_validator校验提示）；
3. **【要件差异表】**主体/主观/客观行为/对象客体/数额情节门槛五维对照，末列即辩护利用点；
4. **【罪与非罪出口】**出罪路径（立案标准数额、但书、正当化事由、程序性出罪如侵占自诉；汇总视图见索引三threshold_index.md）；
5. **【证据差异索引】**两罪核心待证事实差异+各自证据指引锚点（证据指引库锚点，属延伸指引、非必读）+举证负担差分析——控方按重罪指控时额外须证明的要件证据，即为质证主攻点；
6. **【辩护路径】**主张顺序（出罪→降格→变更）、认罪认罚场景处理、类案检索关键词、关联工作线（会见核实重点/文书素材/量刑测算入口）。

## 四、与既有工作线衔接

- **检索线**：罪名辨析先读本库定位辨析对与差异要件，再按第四节规则定向检索类案（关键词取自辨析条目"类案检索关键词"与索引三"无罪检索指引"）；
- **取证线**：辨析条目"证据差异索引"直接生成质证清单——重罪指控的额外要件证据逐项核对缺项；罪名与证据的总索引见索引四crime_evidence_map.md；
- **量刑线**：降格主张成立后的量刑测算调用scripts/crime_lookup.py（--crime罪名/--article条款号/--chapter章节）；轻重梯度（索引二）直接影响认罪认罚利益量化；
- **文书线**：辩护意见罪名部分按"指控罪名要件拆解→在案证据不支撑→应认定轻罪/不构成犯罪→类案印证"结构展开，素材源于本库条目；
- **会见线**：辨析条目"证据差异索引"中依赖当事人陈述的要件（主观明知、目的、通谋）列为会见核实重点。

## 五、使用规则与校验要求

1. **法条校验强制**：条目内法定刑系数据表转录，罪名辨析结论属推断层；正式引用前必须经scripts/law_validator.py校验，条文以校验后为准；掩隐罪等经司法解释修订的数额标准，以现行解释为准（条目内已标注修订提示）；
2. **地区档差**：盗窃/诈骗/抢夺/敲诈勒索等数额标准存在一类/二类地区档差，浙江属一档还是以浙江省高院规定为准，涉数额门槛的降格论证须核对localization/与本省细则，标注信息时点；
3. **罪名名称基准**：罪名名称以crime_index.json（现行有效483罪名）为权威基准——查询罪名不在483之列的按crime_lookup.py提示处理（已取消罪名/俗称/不构成犯罪），勿在非法定罪名上构建辨析；
4. **辨析对未覆盖时**：本库辨析对聚焦高频混淆；未覆盖的罪名组合按"要件差异表"方法自行拆解（主体/主观/客观/客体/数额五维），配合crime_elements.json与evidence_guide通用框架，并标注【通用框架】；
5. **无罪案例纪律**：索引三不预录案例案号，典型案例无罪裁判要旨经检索线实查后引用，案号不明写"案号未公开/待查"，严禁编造；
6. **四层信息分层**：法定刑数据属法律层（须校验）；要件差异属推断层（律师分析）；证据指引锚点属证据层（索引定位）；输出时按 SKILL.md 规则标注；
