# 索引四：罪名与证据关联索引（crime_evidence_map）

> **入库版本**：cdiw-core v1.5.0（2026-08-20）；**定位**：罪名与证据的双向索引——以指控罪名为入口定位该罪的证据指引条目（控方应完成的证据体系清单），以证据要素为入口反查关联罪名；核心方法论为"**证据差异即辩点**"：控方按重罪指控须额外证明的要件证据=质证主攻点。
> **数据来源**：evidence_guide/（104罪名证据指引库，五类模块：刑法条文/证据要点/犯罪构成要件/侦查注意/取证指引）；crime_index.json（483罪名全量索引）；crime_elements.json（10罪名构成要件详版）；crime_distinction/各族群文件【证据差异索引】段（括注锚点）。

## 一、核心方法论：证据差异即辩点

**举证负担差原理**：轻重两罪共用基础事实，重罪=基础要件+额外要件。控方按重罪指控的，**额外要件的每一项证据**都是必须完成的举证——指向额外要件且无替代印证的证据缺项，即"证据不足"质证结论的落点。

| 辨析组 | 控方按重罪指控须额外证明 | 证据缺项的质证结论 |
| --- | --- | --- |
| 抢劫（vs抢夺） | 压制反抗的暴力程度（伤情、反抗受阻陈述） | 降格抢夺 |
| 诈骗（vs帮信/掩隐） | 通谋或对具体犯罪的明知（通联记录） | 降格/出罪 |
| 集资诈骗（vs非吸） | 非法占有目的（资金去向、挥霍逃匿） | 降格非吸 |
| 贪污（vs职务侵占） | 国家工作人员身份（编制、委派文件、公务性） | 降格职务侵占 |
| 绑架（vs索债型拘禁） | 勒索目的（无债务基础） | 降格非法拘禁 |
| 贩卖毒品（vs持有） | 贩卖目的（交易记录、分装状态） | 降格持有/出罪 |
| 故意杀人（vs伤害致死） | 杀人故意（要害攻击、预谋、不救） | 降格伤害致死 |

## 三、反查表：证据要素→关联罪名

以在案证据薄弱环节或关键证据类型为入口反查指控方向：

| 证据要素/场景 | 关联罪名 | 证据审查要点 |
| --- | --- | --- |
| 鉴定意见密集（伤情、死因、毒物、酒精、价格） | 故意伤害、故意杀人、毒品、醉驾、侵财类 | 六查框架：资质、检材保管链、方法标准、关联性、意见范围、文书规范（鉴定意见审查框架） |
| 言词"一对一"（无第三方印证） | 强奸、受贿、行贿、贩卖毒品 | 孤立印证检测：供述与陈述细节互印、时间地点吻合度、利害关系审查（第五节） |
| 电子数据（IP、日志、聊天记录、交易流水） | 计算机三罪、帮信、掩隐、诈骗、非吸 | 原始载体扣押与哈希校验、提取主体合法性、完整性校验（第六节） |
| 司法会计鉴定（资金流、账目） | 贪污、挪用、职务侵占、非吸、集资诈骗、虚开 | 基础数据完整性（凭证齐全性）、鉴定范围的越界审查（资金定性属法律判断非会计判断） |
| 行为能力与主观认知（笔录问答） | 帮信、掩隐、毒品、诈骗共犯 | "明知"问答的逐字审查——诱导性讯问、概括明知的程度分层 |
| 程序性文书（事故认定书、火灾认定书、行政认定） | 交通肇事、失火、责任事故、渎职 | 证据属性之争（行政认定可诉可质）、作出程序合法性 |
| 保管链证据（搜查扣押笔录） | 毒品、枪支、侵财类物证 | 搜查见证、扣押清单、保管移交记录的连续性（第六节） |

## 四、覆盖说明与未覆盖罪名的处理

| 数据层 | 覆盖 | 用途 |
| --- | --- | --- |
| crime_index.json | 483罪名（现行有效全量） | 罪名名称规范化、章节归属、罪名有无判断 |
| crime_sentencing_table.json / case_filing_standards.json | 483罪名（2026-08-21扩容前为275） | 量刑档次、立案门槛 |
| evidence_guide/（本索引正查表） | 104罪名 | 控方证据体系清单反向对照 |
| crime_elements.json | 10罪名（帮信/掩隐/盗窃/侵占/诈骗/合同诈骗/故意伤害/寻衅滋事/贪污/挪用公款） | 构成要件、区分关键、常见辩点详版 |

**未覆盖罪名**（104罪名之外的379罪）：按通用证据审查框架审查并标【通用框架】——八类证据逐一清点、核心要件（主观明知、行为实施、危害后果、因果关系、数额）缺项定位；量刑立案数据按crime_index条文定位+【幅度推演】。

## 五、与四维索引及工作线的联动

- **索引一（此罪与彼罪）**：cluster_*.md各辨析条目【证据差异索引】段即本索引的辨析应用层——两罪证据体系的差异点直接生成质证清单；
- **索引二（轻重层级）**：severity_ladder.md每级降格的"关键辩点"经本索引正查表定位证据审查框架；
- **索引三（罪与非罪）**：threshold_index.md各出罪情形的证明责任分配（要件事实存疑归于控方）；
- **取证线**（调查取证与证据审查线阅卷步骤）：阅卷质证前先经本索引定位罪名证据条目，确定反向对照基线；
- **检索线**：证据瑕疵类案（鉴定排除、电子数据排除）按反查表场景生成关键词。
