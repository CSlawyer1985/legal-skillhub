# 线 1　家属接待与服务管理线

适用节点：家属咨询、接待安排、赔偿谅解沟通、服务进程确认。

**执行步骤**：

1. 首次接待五步：透彻了解（案情、诉讼进程、到案情况、强制措施；家属已收法律文书、办案单位及承办人信息；当事人身份、前科、工作、家庭状况）；初步分析（案件走向、初步辩点、法律服务方案）；事务安排（转达家事、提醒存钱送衣物）；信息采集（按接案信息表四类录入，未知项标注并生成首次会见补充提纲）；预期管理（对“能不能取保、判几年”类疑问以类案检索数据作答，不作承诺）。五步设计核心为首次接待三问“怎么样”方法论——是怎么样（一句话定性）、会怎么样（穷尽走向预测）、要怎么样（三方主体的法律服务方案）。
2. 接待与会见配套规则：每次会见强制配套会见前接待（收集转达事项、生成转达清单、核对新情况/新证据/新期限）与会见后接待（保密边界内反馈状态与进展、转达意见、反馈沟通情况、商讨方案、了解家事）。
3. 接待节点库按程序阶段配置十七个环节：首次接待、提请批捕前接待、批捕前接待、批捕后接待、羁押必要性审查接待、移送审查起诉前接待、阅卷后接待、辩护意见及法律方案商讨接待（侦查阶段适用前八节）；审查起诉到期前接待、拿到起诉书后接待、与家属商讨辩护意见接待、庭审前接待、判决前接待、收到判决书后接待、上诉接案接待、二审方案探讨接待、二审裁判前接待（随阶段包启用）。
4. 关键节点接待：报捕前（告知节点临近与已交取保申请）、批捕后（通报结果、安抚、说明羁押必要性审查计划；**逮捕原因七类分析**——涉嫌罪名刑期十年以上、认罪态度不好、同案犯在逃事实尚未查清、被害方尚未谅解、犯罪事实多尚未查清、多罪名不可能判缓刑、未退赃退赔——分析时从第三方角度说明系检察院逮捕理由，不以第一人称表述防家属误解；同步作认罪认罚节点化辅导：不讲具体罪名的可笼统认罪，明确轻罪的可认，明确重罪的不认。对当事人口径的逮捕原因五类分析见 S2§2 第 4 项，双向索引）、羁押期限延长（说明原因与应对）、侦查终结前（告知移送、衔接审查起诉）。
5. 阅卷后接待告知双向清单（S1§3 第七节口径）：应告知四项——起诉意见书指控的基本事实、指控证据体系概况（证据充分或存在疑问）、当事人辩解及其依据情况、法定及酌定情节；不告知五项——不利证言的作出人、证人姓名身份与联系方式、未查获证据的存放地点、不利鉴定意见的鉴定人、涉嫌非法取证的侦查人员姓名。双向清单以"不泄露国家秘密＋不妨害诉讼正常进行"两底线过滤，凡介绍案情信息先经该规则过滤。
6. 审查起诉到期前接待（含退查预案）：告知下一步工作计划——案子退查的，退查期间至少会见一次、去公安机关或检察机关沟通一次；可能不起诉的积极促成并补充有利于不起诉的材料；已起诉的及时拿起诉书并提示家属与被害方提前沟通（依赔偿协议约定不委托诉讼代理人）。
7. 家属侧取证配合规则（人证分离家属侧）：家属可摸清知情人的联系方式与联系途径后告诉律师去调查，不直接接触了解案情、不叫证人作虚假证言、不与证人交流案情——既保证证据质量又避免家属与律师的执业风险；律师不告知家属要向证人调查什么。
8. 方案商讨接待：提出两套以上方案 → 逐项讲解利弊、周期、风险 → 结合当事人利益类型协助分析但不替代选择 → 提示制作选择笔录 → 新情况出现即重新启动。
9. 对家属的全部输出先经信息告知边界过滤再发出。

**输出要求**：接待三问模板、接案信息表、服务进程确认单。

**禁止项**：禁止在接待中未做分析即下结论；禁止过度迎合；禁止向家属披露案卷证据细节、证人身份信息；禁止为家属传递物品、信件、口信以外的涉案信息；禁止以任何方式将案卷材料泄露给当事人或家属——故意或过失泄露国家秘密达到立案标准的构成犯罪（量化红线见 SKILL.md Guardrails 全局禁止）。
