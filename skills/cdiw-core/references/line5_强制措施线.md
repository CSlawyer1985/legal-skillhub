# 线 5　强制措施线

适用节点：取保申请、不批捕意见、羁押必要性审查、变更强制措施。

**执行步骤**：

1. 取保候审申请按四节点执行（拘留期间、报捕前三日、审查批捕阶段、逮捕后）；对有两档以上法定刑的罪名，先查量刑档次，定位可能降格的法定理由作为申请依据（十年以上重罪必须找到可能降至十年以下的理由）。
2. 不予批准逮捕意见：按实体要件（证据条件——是否有证据证明犯罪事实、可能判处徒刑以上、社会危险性；程序要件——非羁押条件）组织，自动填充已采集的无社会危险性证据点；文书标题为“某某涉嫌某罪一案不予批准逮捕的律师意见书”；按案件情况申请并参加批捕听证会，当庭发表不予批准逮捕意见。
3. 羁押必要性审查：逮捕后一个月左右提出；证据固定、赔偿谅解、疾病、怀孕哺乳、企业经营需要等新情况优先列明、重点强调；申请书附社会危险性反向证明清单。程序期限依据《人民检察院 公安机关羁押必要性审查、评估工作规定》（高检发〔2023〕12号，2026 年核验现行有效）：侦查、审判阶段检察院收到申请后十日以内决定是否提出建议；审查起诉阶段检察院收到变更申请后三日以内作出决定；办案机关收到建议书后十日以内通知处理情况。
4. 按期限变化与案情进展自动提示变更强制措施或申诉节点。

**禁止项**：禁止在羁押必要性审查申请中直接要求检察院变更强制措施——只能请求检察院“建议公安机关”变更；禁止使用“可以取保候审”的表述——使用“符合取保候审的条件”；禁止承诺取保、不捕、撤案结果。

### 一、取保候审法定条件与申请要点全表（理由七要素）

**法定条件**（刑诉法第67条〔2018年修正〕）：可能判处管制、拘役或独立适用附加刑的；可能判处有期徒刑以上刑罚采取取保不致发生社会危险性的；患有严重疾病、生活不能自理，怀孕或正在哺乳自己婴儿的妇女采取取保不致发生社会危险性的；羁押期限届满案件尚未办结需要采取取保的。

**理由七要素**：1.刑期条件符合性；2.事实是否查清证据是否固定；3.社会危险性（是否可能妨碍诉讼、有无逃跑可能）；4.认罪悔罪态度；5.赔偿谅解情况；6.政策及社会效果；7.其他可取保情节。

**申请要点**：重罪案件先解决定性再申请取保（直接对重罪申请取保成功率极低）；递交时点为报捕前三日；侦查阶段向公安机关申请——犯罪嫌疑人及其法定代理人、近亲属或者辩护人有权申请变更强制措施，公安机关应当在收到申请后三日以内作出决定，不同意变更的应当告知申请人并说明理由（《公安机关办理刑事案件程序规定》〔2020修正〕第160条），逮捕后往往征求检察机关意见；已逮捕案件以羁押必要性审查向检察机关提出为宜。

### 一之二、保证金与保证人救济程序（《公安机关办理刑事案件程序规定》〔2020修正〕）

- **保证金起点数额**：犯罪嫌疑人的保证金起点数额为人民币一千元；未成年犯罪嫌疑人的保证金起点数额为人民币五百元；具体数额综合考虑保证诉讼活动正常进行的需要、社会危险性、案件性质情节、可能判处刑罚轻重及经济状况确定（第87条）。
- **没收保证金救济**：被取保候审人或者其法定代理人对没收保证金决定不服的，可以在五日以内向作出决定的公安机关申请复议，公安机关应当在收到复议申请后七日以内作出决定；对复议决定不服的，可以在收到复议决定书后五日以内向上一级公安机关申请复核一次，上一级公安机关应当在收到复核申请后七日以内作出决定（第99条）。
- **保证人罚款救济**：对保证人罚款决定不服的，可以在收到决定书之日起五日以内向作出决定的公安机关申请复议，公安机关应当在收到复议申请后七日以内作出决定；对复议决定不服的，可以在收到复议决定书后五日以内向上一级公安机关申请复核一次（第104条）。
- **期限届满救济**：强制措施法定期限届满的，犯罪嫌疑人及其法定代理人、近亲属或者辩护人有权要求公安机关解除强制措施，公安机关应当审查，情况属实的应当立即解除或者变更（第161条）。
- **文书联动**：没收保证金复议申请书、保证人罚款复核申请书、解除强制措施申请书的结构与程序依据见document_knowledge.md公安程序文书节；复议复核的受理、审查、决定程序统一适用《公安机关办理刑事复议复核案件程序规定》（见compliance_knowledge.md刑事复议复核程序节）。

### 一之三、经济犯罪案件强制措施特别规则（最高人民检察院、公安部关于公安机关办理经济犯罪案件的若干规定〔公通字〔2017〕25号〕）

- **比例原则与慎用羁押**（第31条）：采取强制措施应当与涉嫌犯罪情节轻重、社会危险性相适应，依法慎用羁押性强制措施；采取取保候审、监视居住措施足以防止发生社会危险性的，不得适用羁押性强制措施——经济犯罪案件申请取保时应当将本条作为首要规范依据援引。
- **保证金数额适当原则**（第32条）：经济犯罪案件采取保证金担保的，综合考虑保证诉讼活动正常进行的需要、社会危险性大小、案件性质情节、涉案金额、可能判处刑罚轻重及经济状况确定适当数额；取保期间不得中断侦查，执行取保超过三个月的应当至少每月讯问一次被取保候审人（讯问频次提示当事人遵守报到义务的依据）。
- **逐案审查与不当即释**（第34条）：公安机关应当逐案逐人审查强制措施的合法性和适当性，发现不当的及时撤销或变更，犯罪嫌疑人在押的应当立即释放；犯罪嫌疑人被逮捕后，人民检察院经审查认为不需要继续羁押提出检察建议的，公安机关应当调查核实，不需要继续羁押的予以释放或变更，需要继续羁押的说明理由并在十日以内将处理情况通知人民检察院——辩护律师提出羁押必要性相关意见后，可援引本条跟踪公安机关十日答复义务。

### 二、不予批捕意见的社会危险性论证规则（五情形逐项论证要点与反证思路）

| 社会危险性情形（刑诉法第81条） | 论证要点 | 反证思路 |
|---|---|---|
| 可能实施新的犯罪 | 无再犯的现实基础 | 固定居所、稳定职业、家庭牵绊、初犯偶犯 |
| 有危害国家安全、公共安全或社会秩序现实危险 | 危害的现实性不存在 | 行为一次性、对象特定、社会关系已修复 |
| 可能毁灭、伪造证据，干扰证人作证或串供 | 证据已固定、无干扰条件 | 证据已收集在案、证人证言稳定、同案人到案 |
| 可能对被害人、举报人、控告人实施打击报复 | 无报复动机与条件 | 赔偿谅解已达成、无前科矛盾激化因素 |
| 企图自杀或逃跑 | 无逃跑现实可能 | 到案经过（主动投案）、本地常住、家属配合监管 |

批准或决定逮捕应当将涉嫌犯罪的性质、情节，认罪认罚等情况作为是否可能发生社会危险性的考虑因素。援引《人民检察院审查逮捕质量标准》《最高人民检察院、公安部关于逮捕社会危险性条件若干问题的规定（试行）》相应条文（经scripts/law_validator.py校验后引用）。

### 三、羁押必要性审查的时机、路径、双重目的与诉求表述规范

**时机**：逮捕后一个月左右，以新情况（赔偿谅解取得、同案犯到案、事实查清、定性争议显现）为引；逮捕后可随时提出，但无新情况时立即提出难获支持。

**路径**：向检察机关提出；同时向公安机关通报。

**双重目的**：以取保为目的；以新情况促使司法机关对定性等问题再作审查亦为正当用途。

**诉求表述规范**：此环节检察院无权直接变更强制措施，只能建议公安机关变更——表述为“恳请贵院建议公安机关对某某变更强制措施为取保候审”；新情况须在申请理由中首先列出、重点强调。

### 五、累犯认定规则与取保从严评估

**一般累犯**（刑法第65条〔2011年刑法修正案（八）修正〕）：前罪与后罪均为故意犯罪；均为有期徒刑以上；后罪发生在前罪刑罚执行完毕或赦免后五年以内；不满十八周岁的人犯罪除外。

**特别累犯**（刑法第66条）：前罪与后罪均属危害国家安全犯罪、恐怖活动犯罪、黑社会性质的组织犯罪；后罪发生在刑罚执行完毕或赦免后任何时候。

**法律后果**：应当从重处罚；不得适用缓刑（刑法第74条〔刑法修正案（八）修改，增设犯罪集团首要分子部分〕）；不得适用假释（刑法第81条第2款）；取保时社会危险性评估从严。

> **权威源归属**：认罪认罚主题（认不认／何时认／认什么、四情形分流、摸底、情节挖掘、两句话模板）以 `S10_认罪认罚量刑辩护技能库.md` 为权威源，本线保留强制措施视角的交叉引用；完整方法论见 S10。

### 六、认罪认罚三问框架（一项方案的完整内涵＋三问要点）

#### 一项方案的完整内涵

**认不认的可权衡性**：无罪辩护失败判实刑与认罪换从轻的利弊比较由当事人决断。

**技术活四内容**：罪是否构成的判断方法（供述自愿性及旁证客观证据审查）；刑期具体到月甚至到日的计算要求；罚金数额的确定（非法所得、非法经营额、倍数区间、连带或分别）；强制措施变更的契机运用。

**当事人利益为中心的三分流规则**：有罪才认；无罪也认（由当事人权衡）；有罪不认（尊重意愿）。选择笔录要求：当事人作出选择时制作笔录留痕。

#### 三问要点

**认不认**：三项分流（详见工作线第五步）。

**何时认**：侦查笼统表态（不对具体刑期具结）、审查起诉具结协商、审判庭后协商；实务参考幅度：侦查阶段约30%、审查起诉约20%、审判约10%（经验值非官方规定，须标注“参考幅度，具体以承办检察官、法官裁量为准”）。

**认什么**：认事实及认罪名；认事实不认罪名不属于标准认罪认罚；数罪中仅如实供述部分罪名事实的全案不作“认”的认定（《关于适用认罪认罚从宽制度的指导意见》〔2026修订，高检发〔2026〕5号，现行有效；2019年版已废止〕第7条）；对笼统认罪可接受，对轻罪罪名认罪可接受，对重罪罪名不能认。

### 七、认罪认罚四情形分流详解

（三问框架与分流方法论权威源见 S10§1 三问决策框架、§3 三阶段工作方案。）

| 情形 | 处理 |
|---|---|
| 无罪辩解及证据充分 | 可建议认罪认罚 |
| 无罪辩解及证据虚假存疑 | 作无罪辩护 |
| 有罪供述及证据不足 | 告知当事人律师将作无罪辩护（仅有被告人供述不能定罪），先提无罪意见，法院坚持认定的再走认罪认罚争取最低刑 |
| 有罪供述及证据充分 | 走认罪认罚 |

律师审查后认为有无罪可能的，不建议当事人直接翻供，先作无罪辩护，不成功再做认罪认罚。

### 八、摸底论证方法

（精确测算权威源见 S10 实务速查「一、双轨测算方法论」。）

按法定、酌定、从重、从轻情节结合量刑规则评估大致量刑区间：以刑法分则法定刑幅度为基线，叠加自首（可以从轻或减轻）、从犯（应当从轻减轻或免除）、未遂（可以从轻减轻）、认罪认罚（依法从宽）、退赃退赔与赔偿谅解（酌定从轻）等情节的调节，使当事人心中有数。摸底结果须联动量刑情节线作精确测算（sentencing_workflow.md第四步理论轨测算，测算传--province 浙江自动读取省级细则）。

### 十、量刑意见两句话模板的使用原理

（两句话模板完整文本与适用场景权威源见 S10§4 及 `assets/templates/plea_two_sentences.md`。）

第一句维护具结效力，防止检察官以律师意见不一致为由撤销认罪认罚从宽；第二句为法院依法低于量刑建议处刑保留空间（法律允许法院建议检察院调整量刑建议或依法径行判决），不构成对具结的反悔。两句连用，当事人利益最大化。量刑意见须征得当事人和家属一致授权后方可向检察机关提出。
