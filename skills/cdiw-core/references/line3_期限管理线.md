# 线 3　期限管理线

适用节点：期限计算、倒计时、预警、排期。

**执行步骤**：

1. 调用 scripts/limit_calculator.py 计算期限（节假日日历经 scripts/holiday_update.py 维护，日历范围为周末＋法定节假日＋调休上班日——调休上班的周末按工作日处理）。**期限计算节假日双轨口径**（《刑事诉讼法》第 105 条，截至2026年9月现行有效）：
   - **在押期限轨**：刑拘、报捕期限、审查批捕、侦查羁押及延长、审查起诉与审判在押期间——期间以日计算、开始的日不算在内，按自然日连续计算至期满之日，**不因节假日而顺延**（第 105 条第 3 款但书）；
   - **一般期间轨**：律师文书法定提交期限、上诉期等非在押期间——最后一日为节假日的，以节假日后的第一日为期满日期，期满前已经交邮的不算过期（第 105 条第 3 款前段）；上诉状「先签暂缓递交」战术（S10§3）的递交节点按本轨计算；
   - **机关实际动作日**：机关须在期限届满前完成动作，届满日落在节假日（含周末）的，按节前最后一个工作日计算机关实际动作日——例：刑拘第 30 天为周六，公安机关最迟周五（第 29 天）移送审查逮捕；
   - limit_calculator.py 对每个期限节点输出三类日期：**法定届满日**（自然日连续计算）、**机关实际动作日**（min〔法定届满日，届满日前最后一个工作日〕）、**律师预警日**（按第 4 项预警规则在机关实际动作日前再前推）；
   - **顺延/前移重点提示**：凡计算结果发生节假日顺延或前移的（机关实际动作日早于法定届满日、律师预警日或一般期间届满日因节假日被调整），输出该节点时必须附带醒目提示——以「⚠ 前移提示」或「⚠ 顺延提示」标注原自然日、调整后日期、调整原因（落在周末/法定节假日/调休日）与对动作的影响（如「机关最迟周五移送，材料须在此前递交」）；提示随三类日期一并写入状态文件期限节点块与期限事件载荷；禁止静默调整日期不作提示——使用者只见最终日期而不知被前移/顺延的，属不合格输出。
2. 适用法定期限库：刑拘一般三加七、特殊七加七、流窜/多次/结伙作案三十加七；支持按罪名与涉案情节初判适用档（涉黑类基本三十加七，单人单案本地作案基本七加七）；审查批捕七日；逮捕后侦查羁押二个月，案情复杂经上一级检察院批准延长一个月（刑诉法第156条），交通十分不便的边远地区重大复杂、重大犯罪集团、流窜作案重大复杂、犯罪涉及面广取证困难四类案件经省检察院批准再延长二个月（第158条），可能判处十年以上经省检察院批准再延长二个月（第159条），最长七个月，特殊重大复杂案件经最高检报全国人大常委会批准可延长；取保候审最长十二个月；监视居住最长六个月；传唤、拘传持续不得超过十二小时，案情特别重大、复杂，需要采取拘留、逮捕措施的不得超过二十四小时（刑诉法第119条）——连续传唤、拘传变相拘禁的，作为非法取证线索纳入排非审查。拘留后二十四小时内送看守所并通知被拘留人家属（第85条〔2018年修正〕，无法通知或涉嫌危害国家安全犯罪、恐怖活动犯罪通知可能有碍侦查的情形除外），至迟不得超过二十四小时、异地执行的按抓获地管辖地衔接即时送押（《公安机关办理刑事案件程序规定》第126条）；除无法通知或涉前述两类犯罪外，拘留后二十四小时内制作拘留通知书并通知家属，“有碍侦查”限于法定列举情形（可能毁灭、伪造证据、干扰证人作证或串供，可能引起同案犯逃避、妨碍侦查等），情形消除后应当立即通知（第127条）；一般案件拘留后三日以内提请批捕、特殊情况可延长一至四日（第91条；第129条第1款），多次作案（三次以上）、流窜作案（跨市、县管辖范围连续作案，或在居住地作案后逃至外市、县继续作案）、结伙作案（二人以上共同作案）的重大嫌疑分子提请批捕可延长至三十日（第91条第2款；第129条第2款，定义见第3款）；取保候审届满应当及时解除并通知本人和有关单位，违反规定的没收部分或全部保证金、重新交纳、变更监视居住或予以逮捕（第71条）；指定居所监视居住的期限折抵刑期——判处管制的一日折抵一日，判处拘役、有期徒刑的二日折抵一日（第76条）；执行逮捕后除无法通知外二十四小时内制作逮捕通知书通知家属、无法通知情形消除后应当立即通知（第145条）；发现另有重要罪行的自发现之日起重新计算、身份不明的自查清身份之日起计算（第160条、第160条第2款）。

**审查起诉与审判阶段**：审查起诉应当在一个月以内作出决定，重大、复杂案件可延长十五日；认罪认罚符合速裁条件的十日以内作出决定，可能判处有期徒刑超过一年的可延长至十五日（第172条）；退回补充侦查应当在一个月以内补充侦查完毕、以二次为限，补充侦查完毕移送后重新计算审查起诉期限，二次补充侦查仍证据不足的应当不起诉（第175条）——退查重报全程最长二点五个月；一审公诉案件受理后二个月以内宣判、至迟不超过三个月，可能判处死刑或附带民事诉讼及第158条情形经上一级法院批准可延长三个月，特殊情况报最高法批准（第208条）；简易程序二十日以内审结，可能判处有期徒刑超过三年的可延长至一个半月（第220条）；速裁程序十日以内审结，可能判处有期徒刑超过一年的可延长至十五日（第225条）；改变管辖的案件、补充侦查完毕移送的案件重新计算审理期限（第208条）；二审受理上诉、抗诉后二个月以内审结，可能判处死刑或附带民事诉讼及第158条情形经省高院批准或决定可延长二个月，特殊情况报最高法批准（第243条）；上诉期判决十日、裁定五日，自接到文书的第二日起算（第230条）；死刑复核审限法律未作限制；强制措施法定期限届满应当释放、解除或变更，辩护人有权要求解除（第99条）。上述条文均经北大法宝核验为现行有效文本（2018 修正，截至2026年9月现行有效）。
3. 生成事件时间轴：到案/传唤/拘传 → 刑拘及延长 → 提请批捕 → 审查批捕 → 逮捕执行 → 侦查羁押及延长 → 鉴定/重新鉴定 → 取保/监视居住起止 → 侦查终结/撤案/移送审查起诉。
4. 按预警规则生成提醒：预警点一律基于**机关实际动作日**倒推（机关实际动作日早于法定届满日的，预警点相应前移），推送日本身遇节假日（含周末）自动前移至前一工作日；律师动作（递交手续、沟通、提交材料）预留时间一律向前推，禁止按节假日顺延向后推算。具体节点：刑拘第五日、第十二日、第三十三日预留动作时间；报捕前三日推送取保候审申请书起草任务（结合公安法制大队审查时间）；审查批捕第五日推送不予批准逮捕意见书提交提醒（结合检察官提审时间）；逮捕后满一个月推送羁押必要性审查申请提醒。凡因节假日发生前移/顺延的，提醒输出按第 1 项顺延/前移重点提示规则附带调整说明。
5. **期限节点与子阶段双向联动**：法定期限事件节点同时标注「子阶段切换点」——批捕决定/批捕申请期限届满→侦查·批捕后；退查决定→审查起诉·退查期间；补侦完毕移送→重报审查（重新计算审查起诉期限，刑诉法第 175 条）；审查起诉 12 日届满→审查起诉到期前；开庭→一审·庭审期间。预警触发时由期限引擎回写状态文件**子阶段字段**与阶段进入时间——回写边界：仅限子阶段字段，三大阶段变更、特殊迁移（发回重审、漏罪新罪另案新立、再审重开）一律仍由承办律师确认触发，期限引擎不代行阶段变更。

**禁止项**：禁止凭记忆计算期限；禁止将节假日顺延套用于在押期限（在押期限按自然日连续计算不顺延）；禁止忽略机关实际动作日与律师动作日往前推的规则；禁止顺延/前移调整日期而不向使用者作重点提示；禁止在关键期限无法确认时按默认值推算而不标注“待核实”。

### 二、期间计算通则（刑诉法第105条〔2018年修正〕）

期间以时、日、月计算，开始的时和日不算在期间以内；法定期间不包括路途时间；上诉状在期满前已经交邮的不算过期；期间最后一日为节假日的以节假日后的第一日为期满日期，但犯罪嫌疑人、被告人或者罪犯在押的，应当至期满之日为止，不得因节假日延长——据此，凡涉在押人员的期限（拘留、审查批捕、侦查羁押、上诉期等）一律不顺延，仅非在押情形适用节假日顺延；节假日数据以assets/data/holiday_calendar.json为单一事实源。

### 四、关键预警节点与对应动作全表

（各节点附律师应完成的会见、申请、沟通动作，与接待线的节点接待时机、沟通线的沟通节点联动。）

**侦查阶段关键预警点**：第5日（一般案件提请批捕起点）；第12日（特殊情况延长后提请批捕截止）；第27日（多次、流窜、结伙案件提请批捕前3日，取保申请最后窗口）；第33日（30日延长案件提请批捕截止）。

**节点性质备注**：第5、12、33日系实务惯例预警节点（经验值）——实务中侦查机关多在期限中后段提请批捕、检察院常在法定决定期限届满前即作出决定，预警节点按检察决定前的实务动作窗口设定，为律师动作留出提前量，非刑诉法第91条规定的法定期限。法定期限以本文件第三节规则表为准（提请批捕截止：三日、七日、三十日；检察院决定截止：十日、十四日、三十七日）。对外文书与正式期限计算一律引用法定期限并标注条号；惯例预警节点仅供内部动作编排参考，不得对外引用。

**其余阶段预警节点**：审查起诉受理后第23日（届满前7日，催办与退查应对）；一审开庭前7日（庭前辅导与庭审四纲定稿）；收到判决后第7日（上诉期届满前3日，上诉最后决策窗口）；二审受理后第55日（届满前5日）；全阶段通用：强制措施期限届满前7日（依刑诉法第117条第1款第1项申诉控告预备）。

### 六、经济犯罪案件特有期限节点（最高人民检察院、公安部关于公安机关办理经济犯罪案件的若干规定〔公通字〔2017〕25号，2018年1月1日施行〕）

- 立案审查期限（第15条）：接受线索后7日以内决定是否立案；重大、疑难、复杂线索经县级以上公安机关负责人批准延长至30日；特别重大、疑难、复杂或者跨区域性线索经上一级公安机关负责人批准再延长30日。人民检察院通知立案的，应当在15日以内立案侦查。
- 行政执法机关移送案件（第16条）：移送材料符合规定的，3日以内审查并决定是否立案，至迟10日以内作出决定；重大、疑难、复杂或者跨区域性经县级以上公安机关负责人批准30日以内决定；情况特殊经上一级公安机关负责人批准可再延长30日。
- 不予立案通知（第19条）：有控告人的案件决定不予立案的，应当在立案审查期限内制作不予立案通知书，并在3日以内送达控告人。
- 应当撤案情形（第25条）：对犯罪嫌疑人解除强制措施之日起12个月以内、或者未采取强制措施自立案之日起2年以内，仍然不能移送审查起诉或者依法作其他处理的，应当及时撤销案件（有证据证明有犯罪事实需要进一步侦查，经省级以上公安机关负责人批准的除外）；人民检察院通知撤销案件的，应当撤销案件。撤案后应当立即停止侦查活动。
- 辩护联动提示：经济犯罪案件在立案审查期（最长30+30日）内，辩护律师可依第28条对违法立案提出异议（移送路径见compliance_knowledge.md经济犯罪特殊程序节）；对不予立案决定，控告人可依《公安机关办理刑事复议复核案件程序规定》申请复议、复核（30日内决定，重大复杂可延长）；超过前述撤案时限的，辩护律师应当提示当事人并评估申请检察立案监督的可行性。
