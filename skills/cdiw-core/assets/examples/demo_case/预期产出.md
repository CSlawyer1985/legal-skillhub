## 一、期限计算（scripts/limit_calculator.py）

输入：刑事拘留、起算日 2026-08-23、一般情形（3+7）

预期输出要点：
- 刑拘一般期限届满日、报捕期限届满日、审查批捕七日届满日；
- 三类日期：法定届满日（自然日连续计算）／机关实际动作日（届满日逢休息日按节前最后工作日）／律师预警日（机关实际动作日前前推）；
- 在押期限不顺延（第 105 条第 3 款但书）；发生前移/顺延时附「⚠ 前移提示／⚠ 顺延提示」（原日、调整后日、原因）；日历未覆盖区间须标注「待核实」；
- 预警提示：刑拘第五日、报捕前三日推送取保候审申请书起草任务。

实跑命令：

```bash
python scripts/limit_calculator.py --type detention --start_date 2026-08-23 --subtype general
```

> 标题：阿明涉嫌帮助信息网络犯罪活动罪一案取保候审申请书
> 申请人：××律师事务所××律师；地址；联系电话
> 申请事项：变更强制措施，办理取保候审
> 事实与理由：辩护人总体认为……（观点概述）……阿明符合取保候审的条件。具体意见如下：
> 1. 涉案罪刑是否符合取保候审的刑期条件；
> 2. 事实是否已基本查清、证据是否已基本收集固定；
> 3. 社会危险性（是否可能妨碍诉讼、是否有逃跑可能性）；
> 4. 认罪悔罪态度；5. 赔偿谅解情况；6. 政策及社会效果；7. 其他情节。
> 综上，根据《刑事诉讼法》（2018 修正，现行有效）第67条规定，特申请贵局考虑上述因素，
