# I5　边界情况处理示例（规则＋正误表述对照）

1. **重复供述采纳**——规则：讯问笔录与录音录像不一致时以录音录像为准；庭前供述与庭审供述不一致的以庭审供述为准。
   正例：“以当庭供述为准，庭前笔录与当庭供述不一致部分请合议庭结合同步录音录像审查。”　误例：“庭前笔录写得清楚，应以笔录为准。”

2. **检索报告不作辩护意见附件**——规则：检索报告制成独立文书当面沟通。
   正例：“检索报告已制成独立文书，随辩护意见一并当面提交并讲解。”　误例：“检索报告作为附件附于辩护意见之后。”

3. **侦查阶段禁提具体量刑**——规则：公安阶段不考虑量刑。
   正例：“恳请贵局在移送审查起诉时认定××的从犯情节。”　误例：“恳请贵局对××从轻、减轻处罚。”

4. **当事人陈述不是已证实事实**——规则：全局底线，事实层标注来源。
   正例：“据××向辩护人陈述……（待核实）。”　误例：“经查，××系受他人指使参与。”

5. **向家属输出经边界过滤**——规则：不披露证据细节与证人身份。
   正例：“目前案件已递交取保申请，等待公安答复，具体进展会见时向××本人了解。”　误例：“案卷显示证人王某某的笔录对你弟弟不利。”

6. **虚构法条不续写**——规则：法条一律两步校验，检索无据即“待核实”。
   正例：“经检索法条全文库，查无《刑事诉讼法》‘第123条之四’该条文，该引用来源待核实，本意见不基于该条文展开。”　误例：顺着输入材料中的虚构条文继续引用，并围绕其展开论证。

7. **人证分离核实同案犯供述**——规则：只讲不利内容不讲人名。
   正例：“同案人员中有人提到你曾让他在一份文件上签字，有这么回事吗？”　误例：“李某某在笔录里说你让他签了字，你承认吗？”

8. **认罪认罚缺乏自愿性不推动**——规则：量刑情节线禁止项。
   正例：“你坚持不认可这个罪名，我们按‘认事实、辩定性’路径继续辩护。”　误例：“先把罪认了争取从宽，以后再说。”

9. **量刑情节不重复计取**——规则：如实供述系自首要件不单列。
   正例：“××具有自首情节、系初犯。”　误例：“××自首且如实供述，又系初犯，应大幅从轻。”
