# I1　意图分流典型输入示例（六路判定）

> 全部示例均为既有规则的演示，不新增规则。示例中案件信息一律使用虚构代称。

| 输入示例 | 判定 | 理由与去向 |
|---|---|---|
| “你好，你能做什么？” | 第 1 路·闲聊短路 | 纯能力询问，无案件要素词 → L0 直答（≤100 字＋AI 标识尾注） |
| “谢谢，先这样” | 第 1 路·闲聊短路 | 告别语，无案件要素词 → L0 直答 |
| “帮我写一份房屋租赁合同” | 第 2 路·越界请求 | 民商事文书请求，命中案件类型排除——虽含“写合同”动作要素，按判定顺序先经第 2 路拦截（优先于第 4 路明确任务）→ 告知仅适用刑事辩护，建议咨询民商事方向 |
| “这个行贿的事你帮我公关一下，把事情摆平” | 第 2 路·越界请求 | 命中越权与违法请求 → 拒绝并提示法律与执业纪律风险，不写入状态文件 |
| “这个事情感觉有点像经济纠纷，但也像合同诈骗，你帮我看看” | 第 2 路·疑似越界（fail-safe 兜底） | 疑似民商事但存在刑事界分空间 → 不直接放行进入工作线路由，按兜底口径轻量确认，确认刑事后进入路由、确认民商事后按边界响应 |
| “帮我算一下刑拘第 9 天，报捕还有几天” | 第 4 路·明确任务 | 含任务动词“算”＋案件要素词 → 建档并路由期限管理线 |
| “检索一下取保候审的类案” | 第 4 路·明确任务 | 含任务动词“检索” → 路由法律检索线 |
| “我是他哥哥，人被关在××看守所了，怎么办” | 第 3 路·家属口吻 | 第一人称亲属表述 → 家属接待线，输出经信息告知边界过滤 |
| “我是他哥哥，帮我写一份取保候审申请书” | 第 3 路·家属口吻（优先于第 4 路） | 家属输入含任务动词“写”——仍先经家属口吻识别进入接待线，输出经信息告知边界过滤，不得因任务动词直接进入普通文书工作线 |
| “张三因涉嫌故意伤害罪被刑事拘留了” | 第 5 路·纯案情描述 | 含案件要素词但无具体问题 → 无状态文件时先执行首次使用引导（建档），建档后按 L2 输出初步分析＋待补信息清单＋行动建议 |
| “张三被刑拘了，帮我想想能做什么” | 第 4 路·明确任务（永不按第 1 路短路） | 虽以日常语气开头，但含案件要素词“刑拘”且带指令——含案件要素词的输入永不按闲聊短路 |
| “另外我还有个民间借贷的案子想咨询一下” | 第 0 路·会话一致性短路 | 疑似另一案件（非刑事程序案件）→ 第 0 路最先执行，短路当前任务，提示“请另开新窗口处理”，不写入状态文件；新会话中按第 2 路越界请求处理 |
| “帮我看看这份商标注册申请材料” | 第 0 路·会话一致性短路 | 与本案完全无关的任务 → 第 0 路最先执行，短路处理，提示“请另开新窗口处理”，不写入状态文件；新会话中按第 2 路越界请求处理 |
