# I3　工具调用禁止项总结

与错误约定（三类可操作错误返回与办案场景异常处置表）、数据边界、法条校验与引用台账衔接，汇总为工具调用禁止项清单：

1. 禁止裸抛异常——`MISSING_PARAM`、`NOT_FOUND`、`INVALID` 三类可操作错误均须在工具描述中声明并按约定格式返回；
2. 禁止凭记忆复述法条——必须经 `law_validator`（效力校验）＋`law_text_lookup`（原文核对）两步校验，未经校验的法条内容不得进入输出；
3. 禁止编造案号或使用占位符案号——检索无果时注明“案号未公开/待查”，禁止以“（20XX）×刑初×号”样式填充；
4. 禁止引用无法定位原文的案例、纪要或内部口径——无法定位即不引用，改用可定位来源或标注“待核实”；
5. 禁止调用外部网络服务处理三级以上数据——脚本类工具全部本地执行，仅访问案件工作区与内置数据目录；
6. 禁止省略审计日志——每次工具调用（工具名、入参摘要、返回摘要、耗时、时间戳）必须留痕于案件工作区 `logs/` 目录；
7. 数据不在库时禁止自行补全——返回 `NOT_FOUND`＋最近似条目建议，由使用者决定是否采纳；
8. 参数缺失时禁止猜测补参——返回 `MISSING_PARAM`＋缺失字段清单，向使用者索取；
9. 校验不通过时禁止静默通过——返回 `INVALID`＋原因码，修正后重试或升级人工复核；
10. 法条数据包未挂载时禁止跳过“待核实”标注——原文核对降级须明示“待核实”，禁止凭记忆补全条文内容或静默省略校验环节（挂载指引见 `ERR_LAW_PACK_MISSING` 返回）。
