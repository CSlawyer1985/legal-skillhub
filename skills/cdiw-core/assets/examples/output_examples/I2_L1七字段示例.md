以虚构案件（案件代称“阿明案”，仅作示例，无真实数据）演示七字段结构：

```json
{
  "案件状态摘要": "阿明涉嫌帮助信息网络犯罪活动罪，刑事拘留第 9 日，羁押于××市看守所",
  "当前阶段": "侦查阶段·审查批捕前",
  "已完成节点": ["首次接待", "首次会见（七步法）", "取保候审申请书已递交"],
  "待办事项": ["报捕前三日向检察院递交不予批准逮捕律师意见书", "批捕后两日内会见安抚"],
  "建议下一步动作": "今日内完成不批捕意见书初稿并经承办律师确认",
  "触发的工作线": ["线 3 期限管理", "线 5 强制措施", "线 8 文书生成"],
  "服务进程完成度": "侦查阶段标准服务 3/25 项已销项"
}
```

**字段说明**：服务进程完成度分母取本阶段销项基准（侦查阶段合计 25 项，见 `references/service_config.md`）。
