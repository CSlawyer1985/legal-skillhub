# 表述规范对照表（expression_guide）

禁用表述与规范表述逐条对照（每条含简要理由）：

1. “构成轻罪”（律师直接认定罪名）—“不构成A罪，至多涉嫌B罪”——辩护人不得站在公诉人角度为当事人定罪。

2. “可以取保候审”—“符合取保候审的条件”——前者意为可办可不办，无力度。

3. “该案已移送贵院审查逮捕”—“移送审查批准逮捕”——检察院此环节职责是审查批准逮捕。

4. “案件材料”—“案卷材料”。

5. “根据犯罪嫌疑人的辩解”—“根据犯罪嫌疑人的陈述”——“辩解”仅指对其有利部分，中性引用应用涵盖供述与辩解的“陈述”。

6. “本案定性错误”—“本案定性值得商榷”——前者易激发矛盾。

7. “本案案情存疑”/“犯罪行为存疑”—“犯罪事实不清、证据不足”——法言法语。

8. “主观无心杀人”—明确表述“不具有杀人故意”或“系过失”——主观心态只有故意与过失，含混表述不清。

9. “宣告缓期执行”—“适用缓刑”。

10. “没有适用实刑的必要”—“适用缓刑”或“没有判处实刑的必要”。

11. “量刑存在问题”—“量刑畸重”或“量刑过高”，并点明具体问题（如“一审对自首情节未予认定，二审应予认定并减轻处罚”）。

12. “非法证据排除申请书”—“启动非法证据排除审查的申请”——证据是否非法须经审查，律师申请的是启动审查程序。

13. “对某某作出不予逮捕决定”—“不予批准逮捕”。

14. “恳请检察院变更强制措施”（羁押必要性审查环节）—“恳请贵院建议公安机关变更强制措施为取保候审”——此环节检察院无权直接变更。

15. “供承办检察官办理本案时参考”—“供贵院审查时参考”——警察“办理”、检察官“审查”、法官“审理”，衔接词须对应。

16. “依据法律规定”/“根据《刑事诉讼法》的规定”—具体列明条文序号及全部可援引规定。

17. “自首且初犯，如实供述且悔罪”—分开论述——如实供述系自首组成部分，不重复；自首、初犯、悔罪系三方面内容，不杂糅。

18. “没有同案犯，不存在串供可能”—删除或改写——证人亦可串供。

19. “当事人对当时情况没有任何可预见性”（侦查阶段绝对化表述）—谨慎表述，避免与后续侦查结论冲突致意见可信度受损。

20. “被害人存在过错”（侦查阶段）—侦查阶段不提——定性过早，被害人在案件中地位敏感。

21. “预见能力降低”—直接表述认识因素结论（“没有认识到”或“应当预见而没有预见”）。

22. “尽可能控制危害结果的发生”—“为了防止危害结果发生”——前者含明知结果必然发生而控制的意味。

23. “认罪认罚相关：某某认罪且愿意接受处罚”—注意认事实不认罪名不属于标准认罪认罚；数罪仅供述部分罪名事实的全案不作认罪认定。

24. 调取同步录音录像的文书名—“调取某年某月某日同步录音录像的申请书”，不用调查取证申请书格式（其证据属性实务有争议）。

25. “关于对某某变更强制措施的申请书”—写明变更为某一具体措施（“变更为取保候审”）。

26. 侦查阶段诉求—针对公安机关权力范围（撤案、取保、移送时认定更轻罪名或情节、解封解扣无关财产），不笼统请求从轻减轻处罚（侦查机关不考虑量刑），认罪认罚量刑协商除外。

27. 审查起诉阶段诉求—针对检察院权力范围（不起诉、认定从轻情节、调查取证、重新鉴定），不笼统请求从轻减轻。

28. 阅卷后“定性有争议”—给出倾向性意见，便于检察官法官着力。

29. “恳请公安机关进一步查证”（侦查阶段）—仅在确定所掌握线索绝对有利时提出；不确定是否有利的不得提出。

30. 证据引用—仅列明内容不解释证明目的的，补充说明证据说明了什么问题。

31. 文书整体—每份意见均应有附件辅助（谅解书、赔偿协议、悔过书、品格证明、判例、政策文件等），无附件的意见不完整。
