# 阶段服务进程确认表（service_progress_confirm）

## 表头

案件名称（脱敏代称）；案件阶段；承办律师；起止日期。

## 表格字段（逐行）

服务事项类别（接待、会见、沟通、文书）；日期；工作内容摘要；承办律师；工作用时；委托人确认签名。

| 服务事项类别 | 日期 | 工作内容摘要 | 承办律师 | 工作用时 | 委托人确认签名 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

## 表尾

阶段服务小结（本阶段完成事项统计、下一阶段衔接事项）；委托人整体确认签名栏；日期栏。

【使用说明】阶段终结时由case_state_manager.py按本模板自动生成；打印后交委托人逐项签署；电子确认方式——工作清单按月发送委托人，回复“收到”即视为确认，确认记录归档于case_status.md。
