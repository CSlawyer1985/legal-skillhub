# 申请类文书四部分结构指南（application_structure）

## 四部分结构

第一部分，线索来源：说明申请所涉情况的来源（会见中当事人提出、案卷审查中发现、实地走访了解到）。

第二部分，线索成立可能性：对线索可靠性进行分析（当事人辩解的合理性论证——与客观证据、常情常理的印证；仅凭当事人单方陈述不足以支撑申请，须辅以分析论证；必要时将律师制作的会见笔录作为线索材料附后）。

第三部分，核实必要性与可能性：必要性——该证据对定罪量刑的影响（关键事实认定、情节认定）；可能性——材料能否调取（注意监控录像等有保存期限的材料须及时申请；银行凭证可通过交易柜员编码查询办理网点等具体路径写明）。

第四部分，法律依据与具体诉求：具体列明《刑事诉讼法》及相关司法解释条文（经法条校验）；诉求逐项明确（调取某证据、通知某人出庭、调取同步录音录像、不能调取且无法合理解释时依存疑有利于被告人原则排除等）。

## 申请理由四来源

案件材料中寻找（程序瑕疵、证据缺陷）；当事人辩解中寻找（非法取证线索、款项来源辩解）；法律规定中寻找（调取、排除、出庭的法定情形）；常情常理中寻找（辩解的可信度基础）。

## 五类常见申请要点

1. **调查取证申请书**：上述四部分结构完整适用。

2. **启动非法证据排除审查的申请**：线索指内容具体、指向明确的涉嫌非法取证人员、时间、地点、方式；材料指伤情照片、体检记录、医院病历、讯问笔录、讯问录音录像、同监室人员证言等；可同时申请调取同步录音录像、申请侦查人员出庭作证、主张不能调取且无法合理解释时依存疑原则排除；依据刑诉法第52条、第56条〔2018年修正〕及《人民法院办理刑事案件排除非法证据规程（试行）》。

3. **召开庭前会议申请书**：法定事由：申请排除非法证据的、证据材料多案件疑难复杂的、社会影响重大的、控辩双方对事实证据争议大的；开庭审理前申请排除非法证据的须在庭前会议召开三日前递交申请书及相关线索材料；依据刑诉法第187条第2款〔2018年修正〕及《人民法院办理刑事案件庭前会议规程（试行）》。

4. **证人出庭作证申请书**：论证证人证言对定罪量刑有重大影响、证人了解案件关键事实且愿意出庭；附证人身份材料；依据刑诉法第197条〔2018年修正〕。

5. **公开开庭审理申请书**：二审重点论述对一审事实证据的异议及该异议可能对定罪量刑的影响；依据刑诉法第234条第1款〔2018年修正〕。
