# 发文机关排版先验表

> **用法**：拿到扫描件后先问"这是哪个机关发布的"（见 SKILL.md 第 0.5 步），来此表查候选字体集，
> 再交给 `scripts/identify_font.py` 实测确认。
> **铁律**：先验只用来**缩小候选范围**和**冲突告警**，绝不用来下结论。实测与先验冲突时，**一律信实测**。

## 来源分级（只有前两级可以直接写进结论）

| 标记 | 含义 | 可信度 |
|---|---|---|
| 【国标】 | GB/T 9704-2012《党政机关公文格式》有明文条文 | **限"硬规定"条款**（无限定词的"应当/用…字"）；带"一般/推荐/如无特殊说明"的属软默认，**仍须实测** |
| **【原件】** | 拿到该机关**制式 Word 原件**，值是声明的 | 最高，可直接照抄 |
| 【实证】 | 历史案例已逐像素实测确认，附文件名与实测值 | 高，可直接用 |
| **【反推】** | **只有扫描件，未与原件核对**（本技能产出的大部分条目都属这一级） | **中**——字体"族"可信，**字号/版心/元素归属必须当参考值**。2026-09-12 实测：同一方法在律协《附件3》上被原件证伪 17 项 |
| 【待验】 | 行业常见说法 / 网络流传，未经实测 | 低，**只能当线索，必须实测后才能写进结论** |

⚠️ **回填时务必标清是【原件】还是【反推】**——两级混在一起，下次就会把"我猜的"当"机关规定的"用。

## 一、【国标】GB/T 9704-2012 —— 但请注意它的管辖边界

> 标准全文：国家标准全文公开系统 <https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=F3CC9BEF482524C895FDA7A08BB4A70E>
> 条款号已逐条核对，可直接引用。

| 条款 | 内容要点 |
|---|---|
| **5.2.1 页边与版心尺寸** | 天头（上白边）37mm±1mm；订口（左白边）28mm±1mm；**版心 156mm × 225mm** |
| **5.2.2 字体和字号** | **"如无特殊说明，公文格式各要素一般用 3 号仿宋体字。特定情况可以作适当调整。"** |
| 5.2.3 行数和字数 | 一般每面 22 行、每行 28 字，并撑满版心；特定情况可适当调整 |
| **7.2.4 发文机关标志** | 推荐使用**小标宋体字**，红色 |
| **7.2.6 签发人** | "签发人"三字用 3 号仿宋体字，**签发人姓名用 3 号楷体字** |
| **7.3.1 标题** | 一般用 **2 号小标宋体字**，编排于红色分隔线下空二行位置，居中排布 |
| 7.3.2 | 主送机关（**不是正文**，别引错） |
| **7.3.3 正文** | 一般用 **3 号仿宋体字**，编排于主送机关名称下一行，每自然段左空二字，回行顶格。结构层次序数：**第一层黑体、第二层楷体、第三层和第四层仿宋** |
| 7.3.5.5 特殊情况说明 | 排版后所剩空白不能容下印章时，**"可以采取调整行距、字距的措施解决"** |
| **7.3.7 附件** | **"'附件'二字及附件顺序号用 3 号黑体字顶格编排在版心左上角第一行。附件标题居中编排在版心第三行。"** 末句：**"附件格式要求同正文。"** |
| 第 8 章 公文中的横排表格 | **只规定页码方向（单页表头在订口一边），完全未提表格内文字字体** |
| **7.5 页码** | 一般用 **4 号半角宋体**阿拉伯数字，编排在版心下边缘之下，数字左右各放一条一字线（`—10—`）；一字线上距版心下边缘 7mm；**单页码居右空一字，双页码居左空一字** |

### ⛔ 国标最容易把人带沟里的地方

**国标没有一条是专门管"表格 / 委托书 / 申请书 / 通知书"这类文书表单的内容字体的。**
本技能第一版就栽在这里：拿 5.2.2 / 7.3.3「正文**一般**用3号仿宋」去套一份**授权委托书**，
把正文判成 仿宋_GB2312 三号 16pt —— 实测是**楷体 15.30pt**，字体字号全错，被用户当场指出。

⚠️ 但要说准确：**不是"国标不管表单"，而是"国标给了软默认值，被特定情况改写"。**
国标 7.3.7 末句"附件格式要求同正文"，加上 7.3.3"正文一般用3号仿宋"，
**推出来的默认预期确实就是仿宋**——这正是误判的来源，也是最容易被当成硬规定的地方。

**准确的边界表述（可直接对外引用）**：

- 国标正文条款是 5.2.2「如无特殊说明，各要素**一般**用3号仿宋体字。**特定情况可以作适当调整**」
  ＋ 7.3.3「正文**一般**用3号仿宋体字」——**两条都带"一般"，都是软默认**；
- 表单（填空式文书）属于 5.2.2 明文的"特定情况"，用楷体**不违反国标**；
- 国标同时把**楷体**作为正式用字之一（7.2.6 签发人姓名用3号楷体、7.3.3 第二层层次序数用楷体），
  **小标宋**也是推荐的标题用字（7.2.4 发文机关标志、7.3.1 标题）——
  所以"**楷体 + 小标宋**"是国标体系内的合法组合，不是标新立异。

本案实测也印证了这个边界：

| 元素 | 国标要求 | 本案实测 | 是否吻合 |
|---|---|---|---|
| 附件标识「附件１」 | 3号黑体、顶格版心左上第一行（7.3.7） | 方正黑体简体，顶格第一行 | ✅ **吻合** |
| 页码「—10—」 | 4号宋体、两侧一字线、双页居左（7.5） | 宋体 14pt、双页码居左 | ✅ **吻合** |
| 公文标题 | 2号小标宋（7.3.1） | 方正小标宋简体，21.21pt | ✅ 字体吻合（字号 21.21 < 22） |
| 正文 | "一般"3号仿宋（5.2.2 / 7.3.3） | **方正楷体简体 15.30pt** | ⚪ 属 5.2.2 允许的"特定情况调整" |

→ **结论：国标先验在"边框元素"（附件标识、页码）上是硬规定、可信度最高；
在"正文 / 表单内容"上只是"一般用…"，最容易被"特定情况"改写。**
**凡是条文里出现"一般""推荐""如无特殊说明"的，都必须实测。**

## 二、【实证】已实测案例

| # | 发文机关 | 文件 | 标题字体 | 正文字体 | 实测值 | 备注 |
|---|---|---|---|---|---|---|
| 1 | **无锡市公安局** | 《关于印发〈无锡市律师、基层法律服务工作者…〉》附件1《案件当事人授权委托书》（页码第10页） | **方正小标宋简体** | **方正楷体简体** | 标题 21.21pt、正文 15.30pt（= 15pt+缩放102%）、固定行距 20.5pt、版心 76.06→504.96pt（宽 428.90） | ⚠️ **【扫描件反推，未与原件核对】** 2026-09-12 实测（4 个独立样本交叉，楷体 IoU 0.807 vs 仿宋 0.425）。**字体族结论强**（1.9 倍断层）；**但字号与版心请当"参考值"不当"真值"**——同一方法在同日的 #2 案上被原件证伪了 17 项。附件标识 ✅、页码 ✅ 符合国标硬规定 |
| 2 | **无锡市律师协会秘书处** | 《关于开展2024年度市律协优秀委员会和优秀个人会员评选活动的通知》附件3《优秀个人会员推荐汇总表》（**带框表格**，200dpi） | **方正小标宋简体 22.0pt** | **表头：黑体 11pt；推荐单位行：楷体_GB2312 14pt；表下备注：黑体 12pt** | ⭐ **原件声明值**（2026-09-12 事后取得制式 Word）：附件标识「附件3」黑体 **16pt + 半角数字**；页边距 上72 右90 下72 **左90**、页脚 49.6、文本列宽 **415.3**；表格 `tblW=9630`dxa=**481.5pt**、`jc=center`（**居中溢出文本列**）、边框 **sz=4（0.5pt）**、单元格边距 **108**dxa（**5.4pt 默认**）、列宽 [23.2,55.8,26.7,58.2,104.2,105.8,62.2,45.3]、表头行高 51.1pt exact、数据行高 28.4pt exact、行距 exact 320；**无版记、无页码**（附件本身不含，扫描页上的版记属发文通知） | 2026-09-12。**先验只能取"方正小标宋＋黑体"这一档，其余必须实测**：同一机关同一份文件内就有 4 种字体字号（小标宋22 / 黑体16 / 黑体11 / 楷体_GB2312 14 / 黑体12） |

### 案例 #1（无锡市公安局·段落式表单）的逐元素值【反推】

| 元素 | 值 | 备注 |
|---|---|---|
| 正文 | 方正楷体简体 15.0pt×102% = 15.30pt | 固定行距 20.5pt；版心 76.06→504.96pt（宽 428.90） |
| 标题 | 方正小标宋简体 21.0pt×101% = 21.21pt | 对**版心**居中（不是纸张居中） |
| 附件标识 | 方正黑体简体 15.0pt，数字取**全角** | 版心左上角第一行 |
| 页码 | 宋体 四号 14pt | 单页居右、双页居左，两侧加一字线 `—10—` |
| 填空线 | ASCII `_`，**ASCII 字体必须是 Times New Roman** | 见 references/构建规范.md |

⚠️ 该件**未与原件核对**，故字号与版心只当参考值。

**两份件的差异（重要）**：#1 是**段落式填空表单**（楷体正文 + 下划线填空线 + 版心 428.9pt）；
#2 是**带框表格**（黑体表头 + 楷体_GB2312 推荐单位行 + 黑体备注 + 表格宽 481.5pt、比文本列 415.3pt 还宽）。
**同机关、同类型区域的字体都可能不同** → 先验只能给"候选集"，每个元素仍要单独实测。

⚠️ **#2 是先有像素反推、后拿到原件的对照案例**：反推结果与原件声明值 **21 项错 17 项**
（3 处字体判错、多加了版记与页码、改了页边距与单元格边距、把表格从居中改成左对齐），
而当时的验收数据却是"均差 0.15pt、IoU 0.994"。
完整误差清单与归因见 `references/像素反推误差档案.md`。**这就是"第 0 步先要原件"的由来。**

**观察（样本量 1，仅作提示不作结论）**：该件各项尺寸普遍比国标小约 3~4%
（版心 428.90 vs 442.2、左边距 76.05 vs 79.4、正文 15.30 vs 16、标题 21.21 vs 22，比值均 ≈0.96），
但天头 36.58mm 基本等于国标 37mm（比值 0.99）。**不是统一的整页缩放**，成因不明。
下次遇到公安机关表单可先套这个 ~0.96 的尺寸印象，再按实测修正。

## 四、回填模板（每做完一案就补一行）

做完一案的实测后，在上表"已实测案例"里追加：

```
| N | <发文机关全称> | <文件全称（含附件号）> | <实测标题字体> | <实测正文字体> |
  实测值：标题 <x.xx>pt、正文 <x.xx>pt、行距 <x.xx>pt、版心 <l>→<r>pt |
  <日期> 实测（<样本数> 个样本；与国标/惯例的吻合与背离要点） |
```

**为什么要回填**：这张表是本技能里唯一会随使用而增值的部分。
第二个公安机关表单来时，若与 #1 一致就能直接给出候选集、把实测从"990 款全量"缩到"三款比对"；
若不一致，说明"公安机关"这个粒度还不够，需要细分到具体处室或文种——这个判断只有靠表才能做出来。
