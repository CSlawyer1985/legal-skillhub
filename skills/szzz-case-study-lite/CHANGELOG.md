# SZZZ Case Study Lite 更新日志

## v3.0.1 - 2026-07-20

- README 新增作者介绍和社交平台信息，并把 Lite/Pro 简要区别移至结尾。
- README 改用可在任意目录运行的通用安装与使用命令。
- 新增 Claude、Cursor、WorkBuddy 等多工具使用说明和同项目并发提醒。
- 脚本改为根据自身位置定位依赖、提示模板和后续命令，移除 `~/.claude` 硬编码。
- `SKILL.md` 改用相对于技能根目录的脚本路径。
- LICENSE 保留英文 MIT 原文并追加中文参考译文。

## v3.0.0 - 2026-07-19

- 单案摘要模板和 Master Report 模板与 SZZZ Case Study Pro 保持一致。
- 新增 `main.py` 总控脚本和 `law_analysis_results/` 项目结构。
- 新增案号 + 文书类型去重、无标准案号正文相似去重和去重报告。
- 新增 `status.json`、增量侦测、增量摘要队列和全库数量对账。
- 摘要完成后提供案例库问答、三大高频焦点报告和自定义关键词三个方向。
- 新增既有材料分层问答规则；精确事实和证据问题必须回溯 raw 原文。
- 正式支持旧式 DOC：macOS 使用 `textutil`，其他系统使用 LibreOffice。
- Lite 与 Pro 的边界调整为“完整本地闭环”与“外部检索、Obsidian 增强”。

## v2.0.0 - 2026-07-19

- 项目和技能统一更名为 `szzz-case-study-lite`。
- `SKILL.md` 改用精简、标准的技能元数据，并明确 Lite/Pro 功能边界。
- PDF 提取文本增加页码标记，方便摘要回到原文核对。
- 修正旧版误将 `.doc` 当作 `.docx` 读取的问题；现在会提示先转换格式。
- 文本为空、扫描件或文件损坏时不再生成空白 TXT。
- 批量文件按名称稳定排序，并改进错误提示和退出状态。
- 同名 PDF、DOCX 同时存在时使用格式后缀，避免提取结果相互覆盖。
- 增加 MIT 许可证。

## v1.2.1 - 2026-04-02

- Judgment Analyzer 历史版本。
- 支持本地 PDF、Word 文本提取、逐案摘要和批量综合报告。
