# 律所委托材料自动填写 Skill

> 北京天驰君泰（扬州）律师事务所 · 内部使用

把当事人的谈话记录发进来，AI 自动帮你填好全套委托材料（委托合同、授权委托书、所函、批办单、起诉状/答辩状、代理词等），生成到桌面，核对签字就能用。

**不再手写、不再复制粘贴、不再遗漏。**

## 安装

```bash
# 1. 解压到 skills 目录
unzip 天驰君泰律所委托材料自动填写-Skill.zip -d ~/.workbuddy/skills/

# 2. 重启 WorkBuddy 即可
```

## 快速开始

把跟当事人的谈话记录发到 WorkBuddy，说一句"帮我把这些委托材料填了"。AI 自动提取信息，问几个必要的问题，全部文书生成到桌面。

详细用法见 [操作手册.md](操作手册.md)。

## 功能

- 📄 **13份文书模板**：首次谈话笔录、风险告知书、委托合同（普通/风险）、授权委托书、所函、批办单、监督卡、工作日志、办案小结、起诉状/答辩状、代理词、法定代表人证明书
- 🧠 **智能预提取**：自动从对话/起诉状中提取当事人信息、案由、管辖、费用
- 👤 **自然人/法人自适应**：有身份证号按自然人格式，有统一社会信用代码按法人格式
- ⚖️ **原告/被告自适应**：自动选起诉状或答辩状
- 💰 **普通/风险代理**：根据收费方式自动匹配合同模板
- 💾 **律师信息记忆**：首次填写后自动记住，不用重复输入
