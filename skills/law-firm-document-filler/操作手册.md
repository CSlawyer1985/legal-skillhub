# 律所委托材料自动填写 —— 操作手册

## 这是什么？

一个 AI 工具。你把当事人的谈话记录发进来，它自动帮你填好全部委托材料（委托合同、授权委托书、所函、批办单、起诉状/答辩状、代理词等），生成到桌面，你核对签字就能用。

**不再手写、不再复制粘贴、不再遗漏。**

---

## 怎么用？

### 方式一：录音转文字（最省力）

1. 跟当事人谈话时用手机全程录音
2. 随便找个语音转文字 App 转成文字
3. 把文字内容直接发到 WorkBuddy，说一句"帮我把这些委托材料填了"

AI 自动提取当事人信息、案件事实、诉求，然后问你几个必要问题，填完就输出到桌面。

### 方式二：手动整理案件信息

如果没录音，自己整理一段文字发过来也行，包含这些：

- 当事人的姓名、身份证号/统一社会信用代码、住址
- 对方当事人是谁
- 案件是什么情况（什么时候发生、签了什么、欠了多少、有没有催过、证据有什么）
- 当事人的诉求是什么
- 律师费收多少、怎么收（普通代理还是风险代理）

---

## 会问你什么？

AI 会先扫描你发的内容，能自动提取的就不问。只问必须的：

| 问题 | 什么时候问 | 怎么回答 |
|------|-----------|---------|
| 代理律师是谁？ | 首次使用或更换时问 | 直接打字，支持多人（如"朱彬、陈志宇"） |
| 律师电话？ | 首次使用或更换时问 | 直接打字 |
| 当事人姓名？ | 你发的内容里没提到才问 | 直接打字 |
| 法定代表人？（对方是公司时） | 内容里没提到才问 | 打字，填身份证登记的负责人，不是律师 |
| 案由是什么？ | 每次都确认 | 点选项，或点"其他"自己输 |
| 哪个法院？ | 每次都确认 | 点选项，或点"其他"自己输 |
| 怎么收费？多少钱？ | 你发的内容里没提到才问 | 点选项 + 打字金额 |

## 最后生成到哪儿？

每次生成完，桌面会自动出现一个文件夹，名字就是案件信息：

```
~/Desktop/张某某与XX有限公司买卖合同纠纷/
    ├── 01_首次谈话笔录.docx
    ├── 02_风险告知书.docx
    ├── 03_委托代理合同.docx
    ├── 04_授权委托书.docx
    ├── 05_律师事务所函.docx
    ├── 06_案件批办单.docx
    ├── 07_服务质量监督卡.docx
    ├── 08_工作日志.docx
    ├── 09_办案小结.docx
    ├── 10_民事起诉状.docx（原告）/ 民事答辩状.docx（被告）
    └── 11_代理词.docx
```

如果当事人是公司，还会多一份 `法定代表人身份证明书.docx`。

## 支持哪些案件类型？

不限案由。已经测试过的包括：买卖合同纠纷、民间借贷纠纷、承揽合同纠纷、损害股东利益责任纠纷等。

AI 会根据你发的内容自动判断案由，你确认即可。

---

## 智能功能一览

| 功能 | 说明 |
|------|------|
| 自然人/法人自适应 | 有身份证号按自然人格式，有统一社会信用代码按法人格式 |
| 原告/被告自适应 | 对话里说"起诉他"→起诉状，"他们起诉我"→答辩状 |
| 普通/风险代理自动选 | 说固定金额→普通合同，说按比例→风险合同 |
| 格式自动填充 | 日期、年份自动填当天，不懂格式也能用 |
| 律师信息记忆 | 第一次用会问你律师姓名和电话，填完自动记住，以后就不问了 |

---

## 注意事项

1. 生成完一定要打开核对一遍，AI 可能会因为对话信息不完整而产生小错误
2. 当事人信息（身份证号、住址等）建议核对后再签字
3. 管辖机关的默认建议不一定准确，请根据实际合同约定或法律规定确认
4. 目前仅支持法院诉讼场景，仲裁委场景暂不支持

## 安装方法

1. 收到 `天驰君泰律所委托材料自动填写-Skill.zip`
2. 解压后把整个 `law-firm-document-filler` 文件夹放入：
   ```
   ~/.workbuddy/skills/
   ```
3. 重启 WorkBuddy 或在对话中输入相关指令即可调用
