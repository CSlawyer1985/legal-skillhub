# 律所文书常见字段映射

本文档列出律所委托材料中常见的待填字段，供模板创建时参考命名。

## 当事人信息

| 占位符 | 说明 | 示例值 |
|--------|------|--------|
| `{{委托人姓名}}` | 自然人姓名或法人名称 | 张三 / XX科技有限公司 |
| `{{委托人性别}}` | 自然人性别 | 男 / 女 |
| `{{委托人出生日期}}` | 自然人出生日期 | 1985年6月15日 |
| `{{委托人民族}}` | 自然人所属民族 | 汉族 |
| `{{委托人证件类型}}` | 证件类型 | 身份证 / 护照 |
| `{{委托人证件号}}` | 身份证号或统一社会信用代码 | 31010119850615XXXX |
| `{{委托人住址}}` | 住所地或注册地址 | XX省XX市XX区XX路XX号 |
| `{{委托人联系方式}}` | 联系电话 | 138XXXXXXXX |
| `{{委托人邮编}}` | 邮政编码 | 200001 |
| `{{委托人邮箱}}` | 电子邮箱 | example@email.com |
| `{{法定代表人}}` | 法人单位的法定代表人 | 李四 |
| `{{法定代表人职务}}` | 法定代表人职务 | 执行董事 / 总经理 |

## 案件信息

| 占位符 | 说明 | 示例值 |
|--------|------|--------|
| `{{案由}}` | 案件性质/纠纷类型 | 民间借贷纠纷 / 买卖合同纠纷 |
| `{{案件编号}}` | 法院案号或律所内部编号 | (2026)沪0101民初XXXX号 |
| `{{争议标的}}` | 争议金额/标的额 | 人民币500,000元 |
| `{{管辖机关}}` | 受理法院或仲裁机构 | XX市XX区人民法院 |
| `{{对方当事人}}` | 对方当事人名称 | 王五 / XX股份有限公司 |
| `{{对方住址}}` | 对方当事人地址 | XX省XX市XX区XX路XX号 |
| `{{对方联系方式}}` | 对方联系方式 | — |

## 委托事项

| 占位符 | 说明 | 示例值 |
|--------|------|--------|
| `{{委托事项}}` | 代理的具体事项描述 | 代为提起诉讼、参与庭审、调解、上诉等 |
| `{{代理阶段}}` | 代理的诉讼阶段 | 一审 / 二审 / 再审 / 执行 |
| `{{代理权限}}` | 一般代理或特别授权 | 特别授权代理 |
| `{{授权范围}}` | 授权的具体权限清单 | 代为承认、变更、放弃诉讼请求，进行调解，提起反诉或上诉等 |

## 风险告知书字段

| 占位符 | 说明 | 示例值 |
|--------|------|--------|
| `{{风险告知事项}}` | 具体告知的风险内容 | 诉讼存在败诉风险、执行不能风险等 |

## 使用说明

1. 以上为推荐的占位符命名，模板创建时可根据实际文书内容调整
2. 同一文书使用同一套命名规范
3. 若文书中有以上未涵盖的字段，按 `{{简洁中文描述}}` 格式自行命名
