# 律所委托材料自动填写

> ⚠️ **内部使用声明**：本 skill 为北京天驰君泰（扬州）律师事务所内部使用，模板文件（含律所名称、地址、联系方式等）已预置为天驰君泰信息。如需外部使用，请自行修改 `assets/templates/` 目录下的模板文件。

## 使用指南

本 skill 用于在律师接受委托后，根据当事人信息自动填写全套律所委托材料。

**两种使用方式：**

### 方式一：对话录音转文字（推荐）

1. 与当事人会谈时全程录音
2. 使用语音转文字工具将录音转为文字
3. 将文字稿连同 skill 调用指令一并发送，skill 将自动提取关键信息并生成文书

### 方式二：手动输入案件信息

直接将以下信息整理后发送给 skill：

- 当事人姓名、身份证号/统一社会信用代码、住址、联系方式
- 对方当事人名称及基本信息
- 案件基本经过（时间、事实、争议焦点）
- 证据情况（合同、单据、聊天记录、转账凭证等）
- 当事人的具体诉求
- 是否需要风险代理、代理费金额（如已谈妥）

---

## 调用流程

用户调用 skill 时一并发送对话记录或案件信息，skill 自动完成以下步骤：

| 步骤 | 内容 | 触发条件 |
|:--:|------|------|
| 1 | 询问律师姓名（支持 2 位） | 必问 |
| 2 | 询问律师电话 | 必问 |
| 3 | 询问当事人姓名 | 仅对话中未出现时触发 |
| 4 | AI 建议案由，用户确认或修改 | 必确认 |
| — | `{{签署日期}}` 默认当天 | 全流程复用 |

## 自动选择逻辑

对话中检测以下关键词自动选择模板：

| 关键词 | 模板 |
|--------|------|
| 风险代理、胜诉后付费、按比例收费、标的额百分比、成功后支付、半风险 | `委托代理合同_风险.docx` |
| 代理费XX元（固定金额）、一次性支付（且无风险代理信号） | `委托代理合同_普通.docx` |
| 无收费信息 | 询问用户选择 |
