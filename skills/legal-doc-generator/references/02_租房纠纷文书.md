# 租房纠纷法律文书 参考资料

## 一、法律依据

### 核心法律
- **《中华人民共和国民法典》**（2021年1月1日施行）
  - 第七编 租赁合同（第703-734条）
  - 第五百七十七条：违约责任
  - 第五百八十六条-第五百八十八条：定金规则

### 关键法条速查

| 条款 | 内容 |
|------|------|
| 民法典第712条 | 出租人维修义务 |
| 民法典第713条 | 承租人自行维修权 |
| 民法典第724条 | 承租人法定解除权（房屋被查封/权属争议/违反强制性规定） |
| 民法典第725条 | 买卖不破租赁 |
| 民法典第731条 | 租赁物危及人身安全可随时解除 |
| 民法典第733条 | 租赁期满返还房屋，押金退还 |
| 民法典第734条 | 优先承租权 |

## 二、退押金催告函

### 适用场景
- 租期正常结束，房东无故不退押金
- 押金退还期限届满（合同约定或合理期限）

### 格式模板

```
                    退押金催告函

致：___（房东姓名/公司名称）
地址：____________________

本人___（身份证号：___________）于___年___月___日租用您名下
位于___的房屋，租赁期限自___年___月___日至___年___月___日。
退租时，本人已结清全部租金、水电费、物业费等费用，
房屋及附属设施完好无损（附交接清单/照片为证）。

根据《民法典》第七百三十三条，租赁期限届满，承租人返还租赁物后，
出租人应在合理期限内退还押金。

本人已于___年___月___日搬离并交还钥匙。
您收取的押金人民币___元至今未退还。

请于收到本函之日起**3日内**，将上述押金退还至以下账户：
开户行：___
账号：___

逾期未退的，本人将依据《民法典》第五百七十七条、第七百三十三条，
依法追究您的违约责任，并保留主张逾期利息及维权费用的权利。

此致
敬礼

催告人：___（签名）
___年___月___日

联系方式：____________
送达方式：[ ]直接送达 [ ]邮寄 [ ]微信/短信

附件：
1. 租赁合同复印件
2. 押金收据/转账记录
3. 退房交接清单
4. 房屋现状照片
5. 水电费结清凭证
```

### 发送方式建议
1. **微信/短信**：保留沟通记录
2. **邮寄**：使用EMS，保留寄件凭证和签收回执
3. **直接送达**：两人见证，签字确认

## 三、房屋质量投诉/维修请求函

### 适用场景
- 租赁房屋存在质量问题（漏水、电路故障、墙面开裂等）
- 房东拒绝或拖延履行维修义务

### 格式模板

```
                    房屋质量维修请求函

致：___（房东姓名/公司名称）
地址：____________________

本人___（身份证号：___________）租用您名下位于___的房屋。
地址：____________________
租赁期限：___年___月___日至___年___月___日。

【存在问题】
自___年___月___日起，房屋出现以下质量问题：
1. ___
2. ___
3. ___

上述问题已严重影响本人正常居住使用，且可能危及人身安全。

【已通知情况】
本人已于___年___月___日通过___方式（电话/微信/短信/当面）
向您报告上述问题，但截至本函发出之日，您尚未进行维修处理。

【法律依据】
根据《民法典》第七百一十二条、第七百一十三条，
出租人应当履行租赁物的维修义务；
出租人未履行维修义务的，承租人可以自行维修，维修费用由出租人负担。

【请求事项】
请您在收到本函之日起**7日内**，对上述问题进行维修处理。

若您逾期未履行维修义务，本人将依据《民法典》第七百一十三条，
自行委托第三方维修，维修费用由您承担，
同时保留要求减免相应租金的权利。

此致
敬礼

承租人：___（签名）
___年___月___日

附件：房屋质量问题照片及视频
```

## 四、解除租赁合同通知书

### 适用场景
- 房东违约（拒修房屋、非法进入房屋、擅自涨租等）
- 房屋危及人身安全
- 协商一致解除

### 格式模板

```
                    解除租赁合同通知书

致：___（房东姓名/公司名称）
地址：____________________

本人___（身份证号：___________）于___年___月___日与您签订
《房屋租赁合同》，租用位于___的房屋，租赁期限___年___月___日至___年___月___日。

【解除原因】
依据《民法典》第___条（选择适用）：
□ 第724条：房屋被司法机关依法查封/权属有争议/违反强制性规定
□ 第731条：租赁物危及承租人安全或健康
□ 第710条：正常使用损耗不承担责任
□ 其他：___

具体情况描述：
___

【通知事项】
1. 自本通知送达之日起，解除双方于___年___月___日签订的《房屋租赁合同》
2. 请于___年___月___日前退还押金人民币___元
3. 请配合办理房屋交接手续

【联系方式】
退还押金账户：___
开户行：___

如您对本解除有异议，请在收到本通知之日起7日内书面回复。
逾期未回复的，视为无异议。

此致
通知人：___（签名）
___年___月___日

送达凭证：[ ]签收 [ ]快递单号 [ ]短信/微信发送凭证
```

### 法定解除权速查

| 情形 | 法条依据 | 是否需要提前通知 |
|------|----------|------------------|
| 房屋被查封/扣押 | 民法典第724条 | 无需通知 |
| 权属有争议 | 民法典第724条 | 无需通知 |
| 危及人身安全 | 民法典第731条 | 可随时解除 |
| 协商一致 | 民法典第562条 | 按约定 |
| 不定期租赁 | 民法典第730条 | 合理期限前 |

## 五、押金纠纷处理流程

### 第一步：证据固定
- [ ] 租赁合同原件
- [ ] 押金收据/转账记录
- [ ] 入住时房屋状况照片/视频
- [ ] 退房时房屋照片/视频（证明无损坏）
- [ ] 水电费结清凭证
- [ ] 与房东沟通记录

### 第二步：书面催告
- 发送退押金催告函（参照上文模板）
- 明确期限（3日或合同约定）
- 告知逾期后果

### 第三步：阶梯维权

| 渠道 | 适用情形 | 成本 |
|------|----------|------|
| 12345政务热线 | 中介平台房源 | 免费 |
| 住建部门投诉 | 房东直租 | 免费 |
| 街道/居委会调解 | 双方愿意协商 | 免费 |
| 小额诉讼 | 金额明确、证据充分 | 诉讼费低（10-25元） |

### 第四步：起诉准备
- 通过"人民法院在线服务"小程序立案
- 诉讼请求：退还押金 + 逾期利息 + 维权费用

## 六、注意事项

### 押金退还规则
- ✅ **房东无权扣除**的情况：
  - 正常居住磨损（墙面发黄、家具正常折旧）
  - 卫生未打扫（除非合同明确约定且费用合理）
  - 无正当理由拖延

- ⚠️ **房东有权扣除**的情况：
  - 人为损坏（需房东举证）
  - 未结清水电燃气费
  - 合同明确约定且合理的扣除项目

### 常见错误
- ❌ 退租时未留存交接证据
- ❌ 未结清全部费用导致对方有扣款借口
- ❌ 口头催讨无书面记录
- ❌ 超过诉讼时效（三年）

### 诉讼时效
- 押金纠纷属于**合同纠纷**，诉讼时效**三年**
- 从约定的退还期限届满之日起算
