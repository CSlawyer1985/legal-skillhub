# 法律文书常见错误与注意事项 汇总

## 一、通用注意事项

### 1. 格式与形式
| 错误类型 | 正确做法 |
|----------|----------|
| 手写潦草难以辨认 | 打印或工整手写 |
| 缺少签名/日期 | 每一份文书必须签名+日期 |
| 送达地址不准确 | 提供确认有效的通讯地址 |
| 未按被申请人数量准备副本 | 按"被申请人+1份"准备 |

### 2. 内容规范
| 错误类型 | 正确做法 |
|----------|----------|
| 情绪化表达、辱骂性语言 | 客观陈述事实 |
| 事实与诉求不对应 | 陈述的事实必须支撑诉求 |
| 诉求模糊 | 明确具体金额/行为 |
| 引用法条错误 | 核实法条准确性 |

### 3. 证据意识
| 错误类型 | 正确做法 |
|----------|----------|
| 口头主张无书面证据 | 保留全部书面记录 |
| 证据与诉求无关 | 每项诉求对应相应证据 |
| 原件丢失 | 开庭前补充或说明 |
| 截图无时间/来源 | 确保截图完整可验证 |

## 二、劳动仲裁常见错误

### 1. 申请书错误
| 错误 | 说明 |
|------|------|
| ❌ 被申请人信息不全 | 必须包含统一社会信用代码 |
| ❌ 仲裁请求写"赔偿" | 应写"支付违法解除劳动合同赔偿金___元" |
| ❌ 金额未计算 | 必须附计算方式和依据 |
| ❌ 时效已过 | 一年时效从知道侵权之日起算 |
| ❌ 管辖选错 | 应向合同履行地或用人单位所在地申请 |

### 2. 举证错误
| 错误 | 说明 |
|------|------|
| ❌ 只提交证据目录不提交证据 | 两者必须同时提交 |
| ❌ 证据与诉求无关 | 证据必须支撑仲裁请求 |
| ❌ 证据未标注页码 | 每页证据应标注 |
| ❌ 未保留原件 | 电子材料需保留原件 |

### 3. 时效问题（2025年9月后变化）
- ✅ 新规：用人单位未在仲裁阶段提出时效抗辩，一审/二审提出不予支持
- ⚠️ 劳动者仍需注意：主动维权，及时申请

### 4. 书写要点
```
✅ 正确示例：
"请求裁决被申请人支付2025年6月至9月拖欠工资共计10000元
（计算方式：月工资2500元×4个月）"

❌ 错误示例：
"请求裁决被申请人支付工资，公司太黑了拖欠不给"
```

## 三、租房纠纷常见错误

### 1. 押金纠纷
| 错误 | 正确做法 |
|------|----------|
| ❌ 退租时未拍照留存 | 全屋录像+照片 |
| ❌ 未结清水电费 | 退租前结清全部 |
| ❌ 口头催讨无记录 | 书面催告+送达凭证 |
| ❌ 相信房东口头承诺 | 所有承诺书面确认 |
| ❌ 未签交接清单 | 双方签字确认交接 |

### 2. 维修纠纷
| 错误 | 正确做法 |
|------|----------|
| ❌ 自行维修未通知房东 | 先书面通知，保留证据 |
| ❌ 维修后无法证明系房东责任 | 保留通知、维修、付款凭证 |
| ❌ 未留存沟通记录 | 微信/短信记录完整保留 |

### 3. 合同签订
| 错误 | 正确做法 |
|------|----------|
| ❌ 签了空白合同 | 合同内容填写完整再签 |
| ❌ "任何损坏原价赔偿"条款 | 此类条款无效，但应谨慎 |
| ❌ 未看合同直接签字 | 逐条核对后再签 |

### 4. 押金扣除规则
```
✅ 房东无权扣除押金：
- 正常使用产生的磨损（墙面发黄、家具折旧）
- 卫生未打扫（除非合同明确约定且合理）
- 无任何正当理由

⚠️ 房东有权扣除：
- 人为损坏（需房东举证证明）
- 未结清水电燃气费
- 合同明确约定且合理的项目
```

## 四、消费维权常见错误

### 1. 12315投诉
| 错误 | 正确做法 |
|------|----------|
| ❌ 被投诉方名称写简称 | 必须写营业执照全称 |
| ❌ 事实描述写成"小作文" | 按时间+地点+人物+事件叙述 |
| ❌ 证据截图无时间 | 确保截图显示完整信息 |
| ❌ 诉求写"讨个说法" | 明确退款/赔偿金额 |

### 2. 证据问题
| 错误 | 正确做法 |
|------|----------|
| ❌ 只上传商品图无购买凭证 | 凭证+商品图+沟通记录 |
| ❌ 聊天截图无双方身份 | 确保可识别双方 |
| ❌ 删除了关键信息 | 完整保留原始记录 |

### 3. 赔偿计算
| 场景 | 计算方式 |
|------|----------|
| 欺诈行为 | 退一赔三（不足500元赔500元） |
| 食品安全 | 退一赔十（不足1000元赔1000元） |
| 预付卡余额 | 退还实际余额+利息 |

### 4. 沟通话术
```
✅ 正确："要求全额退款98元，并退一赔三294元（不足500元按500元），
合计598元"

❌ 错误："要求赔偿，精神损失费1000元"
```

## 五、时效与期限汇总

| 类型 | 时效/期限 | 起算点 |
|------|-----------|--------|
| 劳动仲裁申请 | 1年 | 知道或应当知道权利被侵害 |
| 拖欠工资（在职期间） | 无限制 | 劳动关系存续期间 |
| 拖欠工资（离职后） | 1年 | 劳动关系终止之日 |
| 租房押金纠纷 | 3年 | 约定退还期限届满 |
| 消费纠纷 | 3年 | 知道或应当知道侵权 |
| 民事诉讼 | 3年 | 知道或应当知道权利被侵害 |

## 六、文书送达方式

### 1. 微信/短信送达
- 优点：即时、保留记录
- 注意：确保能证明送达对象身份

### 2. 邮寄送达（推荐）
- 使用EMS或挂号信
- 保留寄件凭证和签收回执
- 收件地址：公司注册地址/身份证地址

### 3. 直接送达
- 两人见证
- 要求对方签字确认收到
- 拒绝签收的，记明情况

### 4. 电子送达
- 邮箱送达需确认对方使用该邮箱
- 微信送达截图需完整

## 七、证据效力参考

| 证据类型 | 效力说明 |
|----------|----------|
| 原件 | 效力最高 |
| 公证书 | 效力较高 |
| 电子证据（公证） | 效力较高 |
| 手机截图 | 需能证明真实性 |
| 录音录像 | 需未剪辑，保留原始载体 |
| 证人证言 | 需出庭质证 |

2. **平台投诉** → 免费（淘宝、拼多多等）
3. **12315投诉** → 免费
4. **12345热线** → 免费
5. **消协调解** → 免费

6. **行政举报** → 工商/市场监管
7. **仲裁** → 劳动仲裁/商事仲裁
8. **法院起诉** → 小额诉讼/普通程序

```
协商 → 平台/12315投诉 → 行政调解 → 起诉
  ↓         ↓              ↓         ↓
 免费     免费           免费     诉讼费低
```
