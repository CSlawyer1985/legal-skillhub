## 一、劳动法律

### 《中华人民共和国劳动争议调解仲裁法》

| 条款 | 内容要点 |
|------|----------|
| 第27条 | 仲裁时效期间为一年，从知道或应当知道权利被侵害之日起计算 |
| 第27条4款 | 劳动关系存续期间拖欠劳动报酬争议，劳动者申请仲裁不受时效限制；劳动关系终止的，应当自终止之日起一年内提出 |
| 第28条 | 仲裁申请书应当载明的事项（当事人信息、仲裁请求、事实理由、证据） |

### 《中华人民共和国劳动合同法》

| 条款 | 内容要点 |
|------|----------|
| 第10条 | 建立劳动关系，应当订立书面劳动合同 |
| 第17条 | 劳动合同的必备条款（9项） |
| 第19条 | 试用期期限（3月-1年：≤1月；1-3年：≤2月；3年以上/无固定：≤6月） |
| 第20条 | 试用期工资不得低于约定工资80%或当地最低工资 |
| 第30条 | 用人单位应当按时足额支付劳动报酬 |
| 第38条 | 劳动者解除合同的法定情形（未缴社保/未付工资/规章制度违法等） |
| 第46条 | 经济补偿的法定情形 |
| 第47条 | 经济补偿计算方式（年限×月工资） |
| 第48条 | 违法解除/终止的法律责任（继续履行或2N赔偿） |
| 第82条 | 未签书面劳动合同的双倍工资（自第2个月起，不超过11个月） |
| 第87条 | 违法解除/终止的赔偿金（经济补偿的2倍） |

### 《最高人民法院关于审理劳动争议案件适用法律问题的解释（二）》法释〔2025〕12号

> **2025年9月1日起施行**

| 条款 | 内容要点 |
|------|----------|
| 第11条 | 符合订立无固定期限劳动合同情形，劳动者请求以原条件订立的，法院支持 |
| 第18条 | 违法解除劳动合同的工资损失计算 |
| 第19条 | 约定不缴社保无效，用人单位仍需支付经济补偿 |
| 第20条 | 仲裁时效抗辩需在仲裁阶段提出 |

## 二、租赁法律

### 《中华人民共和国民法典》租赁合同编

| 条款 | 内容要点 |
|------|----------|
| 第703条 | 租赁合同定义 |
| 第707条 | 租赁期限6个月以上应采用书面形式 |
| 第708条 | 出租人交付符合约定用途的租赁物 |
| 第709条 | 承租人按约定方法使用租赁物 |
| 第710条 | 正常使用损耗不承担责任 |
| 第712条 | 出租人维修义务（另有约定除外） |
| 第713条 | 承租人自行维修权，费用由出租人负担 |
| 第716条 | 承租人转租须经出租人同意 |
| 第722条 | 承租人无正当理由逾期不付租金，出租人可解除合同 |
| 第724条 | 承租人法定解除权（房屋被查封/权属争议/违反强制性规定） |
| 第725条 | 买卖不破租赁 |
| 第726条 | 承租人优先购买权（通知后15日内未表示视为放弃） |
| 第729条 | 因不可归责于承租人的事由致租赁物毁损灭失，可解除合同 |
| 第730条 | 不定期租赁可随时解除（合理期限前通知） |
| 第731条 | 租赁物危及人身安全可随时解除 |
| 第733条 | 租赁期满返还租赁物，押金退还 |
| 第734条 | 承租人优先承租权 |

## 三、消费维权法律

### 《中华人民共和国消费者权益保护法》

| 条款 | 内容要点 |
|------|----------|
| 第2条 | 保护为生活消费需要购买、使用商品或接受服务的消费者 |
| 第7条 | 消费者人身财产安全权 |
| 第8条 | 知情权 |
| 第9条 | 选择权 |
| 第20条 | 经营者真实告知义务，禁止虚假宣传 |
| 第23条 | 经营者举证责任（耐用商品/装饰装修服务） |
| 第25条 | 网络购物七日无理由退货 |
| 第44条 | 网络交易平台提供者赔偿责任 |
| 第53条 | 经营者未按约定提供商品/服务应退还预付款 |
| 第55条 | 欺诈行为惩罚性赔偿（退一赔三，不足500元赔500元） |

### 《中华人民共和国食品安全法》

| 条款 | 内容要点 |
|------|----------|
| 第148条 | 生产不符合食品安全标准或经营明知是不符合食品安全标准的食品，退一赔十（不足1000元赔1000元），+损失2倍赔偿 |

### 《中华人民共和国产品质量法》

| 条款 | 内容要点 |
|------|----------|
| 第27条 | 产品或者其包装上的标识必须真实，有产品质量检验合格证明、生产厂名和厂址等 |

### 《最高人民法院关于审理预付式消费民事纠纷案件适用法律若干问题的解释》

> **2025年5月1日起施行**

| 条款 | 内容要点 |
|------|----------|
| 第1条 | 适用范围：零售、住宿、餐饮、健身、理发、美容、培训、养老、旅游等生活消费领域 |
| 第4条 | 允许他人使用其营业执照经营者应承担责任 |
| 第6条 | 商场场地出租者对经营者资质的形式审查义务 |
| 第25条 | 经营者控制证据无正当理由拒不提交的，可依消费者主张认定 |

## 四、2025-2026年重要立法动态

### 已施行的新规

| 法规 | 施行日期 | 主要变化 |
|------|----------|----------|
| 最高法劳动争议解释（二） | 2025年9月1日 | 一裁终局范围扩大、无固定期限合同按原条件订立 |
