# 法学引注手册

> ⚖️ 献给曾经北大国际法学院的自己——引注是法律人的职业尊严。
>
> *A citation manual forged in the spirit of PKU STL. Because every comma in a citation is a promise of intellectual honesty.*

**使用声明：「我正在使用法学引注手册 skill 进行学术引注规范。」**

## 规范依据

本手册以**《法学引注手册》**（2019 年版，由《中国法学》《法学研究》《中外法学》等主要法学期刊编辑委员会联合编制）为核心规范，融合 **Bluebook（第 21 版）** 英文引注规则，适用于：

- 中文学术论文（期刊、学位论文）
- 比较法研究（中英双语引注）
- 法律意见书、备忘录等实务文书
- 英文法学期刊投稿（Law Review / Journal format）

## ⚡ 引注三大铁律

<EXTREMELY-IMPORTANT>
### 铁律一：未经核实，不得引注

**在核实引注每一个要素之前，绝对不要写。**

写任何引注之前：
1. 核实法规名称及条文编号
2. 核实案例案号和裁判日期
3. 核实期刊年份、期号、页码
4. 核实作者姓名及出版信息

**猜测页码或条文号不是帮忙——这是对学术诚信的伤害。论文一旦发表，错误引注只会损害你的声誉。**
</EXTREMELY-IMPORTANT>

<EXTREMELY-IMPORTANT>
### 铁律二：首次引注必须完整，缩略引注不可超前

**“同上注”“前引注”等缩略形式，必须以此前的完整引注为前提。**

使用任何缩略形式之前：
1. 确认前文已出现完整引注
2. 确认没有插入其他引注（“同上注”要求紧接前注）
3. 确认缩略指向明确无歧义

**中间插入了其他引注后还写“同上注”——这是制造歧义。删除，重新完整引注。**
</EXTREMELY-IMPORTANT>

<EXTREMELY-IMPORTANT>
### 铁律三：引注格式因场景而异

**学术论文使用脚注格式（页下注）。法律文书使用随文注或独立引注。**

```
脚注（学术论文）：
① 王泽鉴：《民法总则》，北京大学出版社 2014 年版，第 15 页。
② 参见张明楷：《刑法学》（第 6 版），法律出版社 2021 年版，第 200—205 页。

随文注（法律意见书）：
……依据《中华人民共和国民法典》第 235 条，权利人有权……
```

**如果写了学术论文却用法律文书的引用格式——删除重写。**
</EXTREMELY-IMPORTANT>

## 引注门槛——六步检验法

写任何引注之前：

```
第 1 步 识别   → 这是什么类型的文献？（法规 / 案例 / 期刊 / 著作 / 网络）
第 2 步 定位   → 找到对应的引注规范条目
第 3 步 核实   → 逐项确认所有要素（作者、标题、年份、页码）
第 4 步 排版   → 正确使用标点、字体、空格
第 5 步 比对   → 对照手册示例，看格式是否一致
第 6 步 交付   → 前 5 步确认完成后，才写出引注
```

**跳过任何一个步骤，都会产生不可靠的引注。**

## 快速参考：中文法学引注格式

### 一、法律法规

#### 基本格式

```
《中华人民共和国[名称]》第 [条] 条（[修正年份] 年修正）。
```

**示例：**
```
完整引注：
《中华人民共和国民法典》第 235 条（2020 年）。

含款/项：
《中华人民共和国民法典》第 235 条第 1 款第 2 项（2020 年）。

多条文：
《中华人民共和国民法典》第 235 条、第 240 条（2020 年）。

缩略（前文已引注全书）：
《民法典》第 235 条。
```

#### 行政法规

```
[法规名称]（[制定机关] [年份] 年第 [X] 号令）。
```

**示例：**
```
《公司登记管理条例》（国务院 2016 年第 666 号令修订）。
```

#### 司法解释

```
最高人民法院《关于[事项]的解释／规定》（法释〔[年份]〕[X] 号）。
```

**示例：**
```
最高人民法院《关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（法释〔2023〕12 号）。
```

#### 国际条约

```
《[条约全称]》（[国家] [签署/加入] 日期）。
```

**示例：**
```
《联合国国际货物销售合同公约》（中国 1986 年 12 月 11 日核准）。
```

---

### 二、司法案例

#### 基本格式

```
[案件名称]，[案号]（[审理法院] [裁判日期]）。
```

**示例：**
```
完整引注：
广东省深圳市腾讯计算机系统有限公司诉北京奇虎科技有限公司不正当竞争纠纷案，最高人民法院（2013）民三终字第 5 号民事判决书。

最高人民法院指导案例：
指导案例 78 号：北京奇虎科技有限公司诉腾讯科技（深圳）有限公司滥用市场支配地位纠纷案，最高人民法院（2013）民三终字第 4 号民事判决书。

公报案例：
“深圳市斯瑞曼精细化工有限公司诉深圳市坑梓自来水有限公司专利权纠纷案”，载《最高人民法院公报》2013 年第 8 期。
```

---

### 三、期刊论文

#### 基本格式

```
[作者]：《[文章标题]》，载《[期刊名]》[年份] 年第 [期] 期，第 [起始页]—[结束页] 页。
```

**示例：**
```
完整引注：
朱苏力：《制度是如何形成的？——关于马伯里诉麦迪逊案的故事》，载《比较法研究》1998 年第 1 期，第 66—72 页。

合著：
王利明、周友军：《我国侵权责任法的体系构建》，载《中国法学》2010 年第 4 期，第 5—25 页。

缩略（前文已引注全文）：
朱苏力，见前注 [X]，第 68 页。
```

---

### 四、学术著作

#### 基本格式

```
[作者]：《[书名]》（[版次]），[出版社] [年份] 年版，第 [页码] 页。
```

**示例：**
```
专著：
王泽鉴：《民法思维：请求权基础理论体系》，北京大学出版社 2009 年版，第 45 页。

第 N 版：
张明楷：《刑法学》（第 6 版），法律出版社 2021 年版，第 200 页。

译著：
[德] 卡尔·拉伦茨：《法学方法论》，陈爱娥译，商务印书馆 2003 年版，第 150—160 页。

编著/主编：
梁慧星主编：《民商法论丛》（第 50 卷），法律出版社 2012 年版。
```

---

### 五、文集/集刊论文

```
[作者]：《[文章标题]》，载 [主编] 编：《[文集名]》，[出版社] [年份] 年版，第 [页码] 页。
```

**示例：**
```
苏永钦：《私法自治中的国家强制》，载苏永钦：《走入新世纪的私法自治》，中国政法大学出版社 2002 年版，第 1—50 页。
```

---

### 六、学位论文

```
[作者]：《[论文标题]》，[学校] [学位级别] 学位论文，[年份] 年，第 [页码] 页。
```

**示例：**
```
侯猛：《中国最高人民法院研究——以司法的影响力切入》，北京大学博士学位论文，2004 年，第 88 页。
```

---

### 七、报纸文章

```
[作者]：《[文章标题]》，载《[报纸名]》[年份] 年 [月] 月 [日] 日，第 [版] 版。
```

**示例：**
```
贺小荣：《民法典合同编司法解释的理解与适用》，载《人民法院报》2023 年 12 月 6 日，第 3 版。
```

---

### 八、网络文献

```
[作者]：《[文章标题]》，载 [网站名]，[URL]，[最后访问日期]。
```

**示例：**
```
周光权：《刑法修正案（十一）的理解与适用》，载中国法学网，https://www.iolaw.org.cn/showArticle.aspx?id=xxxx，2024 年 1 月 15 日最后访问。
```

## 快速参考：英文引注格式（Bluebook 21st）

### 美国判例

```
完整引注：
Brown v. Board of Education, 347 U.S. 483, 495 (1954).

短引注（同一脚注内无其他引注）：
Id. at 496.

短引注（不同脚注，无间隔引注）：
Brown, 347 U.S. at 497.
```

### 美国成文法

```
完整引注：
42 U.S.C. § 1983 (2018).

多条文：
42 U.S.C. §§ 1983-1985 (2018).
```

### 英文期刊论文

```
Cass R. Sunstein, *On the Expressive Function of Law*, 144 U. Pa. L. Rev. 2021, 2030 (1996).
```

### 英文著作

```
Richard A. Posner, Economic Analysis of Law 45 (9th ed. 2014).
```

## 引注信号与括号说明

### 中文引注信号

| 信号 | 含义 | 使用场景 |
|------|------|----------|
| （无信号） | 直接支撑 | 文献直接支持所述观点 |
| 参见 | 参考/隐含支持 | 文献支持但不直接陈述 |
| 详见 | 详细论证 | 文献对所述问题有更详细讨论 |
| 例如 | 举例说明 | 从多个文献中举代表性例子 |
| 但见 / 比较 | 对比/矛盾 | 文献提出不同或相反观点 |
| 转引自 | 间接引用 | 通过他人文献引用的原始文献 |

### 英文引注信号（Bluebook Rule 1.2）

| 信号 | 含义 | 使用场景 |
|------|------|----------|
| [no signal] | 直接支撑 | Source directly states proposition |
| *See* | 隐含支持 | Source supports but doesn't directly state |
| *See, e.g.,* | 举例 | Multiple sources support; citing representative |
| *Cf.* | 类比 | Source supports by analogy |
| *But see* | 矛盾 | Source contradicts proposition |
| *Contra* | 直接对立 | Source directly contradicts |
| *See generally* | 背景 | Source provides helpful background |

## 常见错误速查

### 法律法规引注

| 错误 | 正确 |
|------|------|
| 《民法典》第 235 条 | ✅ |
| 《民法典》第二百三十五条 | ✅（中文数字也可） |
| 民法典 235 条 | ❌ 缺书名号 |
| 《民法》235 条 | ❌ 简称需在前文有完整引注 |
| 《合同法》第 52 条 | ❌ 《民法典》已取代《合同法》，需确认适用版本 |

### 期刊引注

| 错误 | 正确 |
|------|------|
| 作者，“文章名”，载... | ❌ 应用中文书名号《》 |
| 载《中国法学》2020 年第 1 期 | ✅ |
| 载《中法》2020/1 | ❌ 期刊名缩写不规范 |
| ...2020 年第 1 期，页 50 | ❌ 应写“第 50 页” |

### 著作引注

| 错误 | 正确 |
|------|------|
| 王泽鉴《民法总则》2014 年版 | ❌ 缺出版社 |
| 王泽鉴：《民法总则》，北京大学出版社 2014 年版，第 15 页。 | ✅ |
| 初版不标版次 | ✅ |
| 第 2 版以上必须标注版次 | ✅ |

### 缩略引注

| 错误 | 正确 |
|------|------|
| 中间插入其他引注后写“同上注” | ❌ 应用“前引 [X]，[作者] 书/文” |
| 从未出现过完整引注却使用缩略 | ❌ 必须先用完整引注 |
| “前引”不写注号 | ❌ 应用“前引 [X]”或“前引注 X” |

| 文献类型 | 核心格式 | 备注 |
|----------|----------|------|

| 司法解释 | 全文称（法释〔年份〕X 号） | |
| 案例 | 案件名，案号（法院 日期） | 含指导案例号 |

## 引注审计模式

审阅论文引注时，按以下清单逐一检查：

### 法律法规
- [ ] 法规名称完整准确
- [ ] 条文号核实无误
- [ ] 修正年份标注（如有修正）
- [ ] 款/项标注清晰
- [ ] 简称在首次完整引注后方可使用

### 案例
- [ ] 案号完整（含办案年份、字号、案号）
- [ ] 法院名称准确
- [ ] 裁判日期正确
- [ ] 指导案例号标注（如适用）
- [ ] 公报案例标注出处卷期

### 期刊论文
- [ ] 作者姓名无误（含外籍作者的国别标注）
- [ ] 文章标题完整（含副标题）
- [ ] 期刊名全称（非缩写）
- [ ] 年份、期号正确
- [ ] 起止页码准确

### 著作
- [ ] 作者/编者/译者区分明确
- [ ] 书名完整（含副标题）
- [ ] 版次标注（初版除外）
- [ ] 出版社全称
- [ ] 出版年份
- [ ] 引用页码精确

## 常见引注借口——立即停止

| 如果这么想 | 事实 | 应该做的 |
|-----------|------|----------|
| “这个条文号应该差不多” | 差不多 = 错 | 查阅法规原文核实 |
| “同上注就行了吧” | 中间有别的引注就不行 | 用“前引 [X]” |
| “出版社缩写没关系” | 不规范缩写影响查证 | 用全称 |
| “页码回头再补” | 不写页码等于没引 | 现在就补上 |
| “标题太长我截一下” | 随意截断 = 不完整引注 | 保持完整标题 |
| “这个网站链接暂时能打开” | 明天可能就打不开了 | 加最后访问日期 |

## 删除并重启模式

**何时删除重写：**

1. **引注使用猜测的页码** → 删除，核实原文，标注真实页码
2. **“同上注” 前有间隔引注** → 删除，改用“前引 [X]”
3. **引用信号错误** → 删除，查阅手册信号规则
4. **法规简称在前文未定义** → 删除，先提供完整引注再使用简称
5. **外文引注未按来源国规范格式** → 删除，查 Bluebook/OSCOLA

**重写示例：**

```
错误：
⑦《民法典》第 235 条。
⑧ 同上注。
⑨ 王泽鉴：《民法思维》，第 45 页。
⑩ 同上注。    ← 注⑧ 到 注⑩ 之间已经有两个引注，不能再用“同上注”

正确：
⑦《中华人民共和国民法典》第 235 条（2020 年）。
⑧《民法典》第 240 条。         ← 上文已出全称，此处可用简称
⑨ 王泽鉴：《民法思维：请求权基础理论体系》，北京大学出版社 2009 年版，第 45 页。
⑩ 王泽鉴，见前注 [⑨]，第 68 页。  ← 正确使用前引形式
```
