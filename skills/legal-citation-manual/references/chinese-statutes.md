# 中国法律法规引注详则

> 参考《法学引注手册》第三章“法律法规”及中国法学期刊通行规范。

## 一、法律

### 基本格式

```
《中华人民共和国[法律全称]》第 [条] 条[款][项]（[年份] 年[修正/修订]）。
```

### 详细规则

#### 1. 法律名称
- 首次出现必须用全称，不得缩写
- 前文已引用全称后，可用约定俗成的简称，如“《民法典》”“《刑法》”
- 简称需在首次使用时以括号注明，如：《中华人民共和国民法典》（以下简称《民法典》）

#### 2. 条文序号
- 条：阿拉伯数字或中文数字均可，全文统一
- 款：按自然段计款（不编号的自然段依次为第 1 款、第 2 款……）
- 项：条文内部以（一）（二）等编号的内容称为项
- 目：条文内部以 1. 2. 等编号的内容称为目
- 示例：第 235 条第 1 款第 2 项第 3 目

#### 3. 修正/修订标注
- 法律颁布后未经修改的，标注原颁布年份，如（2020 年）
- 法律经修正的，可标注修正年份或修正令号，如（2012 年修正）或（根据 2012 年 X 月 X 日第 X 号主席令修正）
- 引用特定版本条文时，必须标注引用版本年份
- 示例：《刑法》第 264 条（1997 年，2020 年修正）

#### 4. 并列条文
- 连续条文：《民法典》第 235—240 条
- 非连续条文：《民法典》第 235 条、第 240 条、第 245 条
- 同一法不同条文：《刑法》第 232 条、第 264 条

## 二、行政法规

### 基本格式

```
[法规全称]（[制定/批准机关] [年份] 年第 [X] 号 [令/决定] [发布日期]）。
```

### 示例

```
《中华人民共和国公司登记管理条例》（国务院 2016 年第 666 号令修订）。

《企业信息公示暂行条例》（国务院 2014 年第 654 号令）。
```

---

## 三、司法解释

### 基本格式

```
最高人民法院[或最高人民检察院]《关于[事项]的[解释/规定/批复/决定]》（法释〔[年份]〕[文号] 号）。
```

### 示例

```
最高人民法院《关于适用〈中华人民共和国民法典〉侵权责任编的解释（一）》（法释〔2024〕10 号）。

最高人民法院、最高人民检察院《关于办理侵犯公民个人信息刑事案件适用法律若干问题的解释》（法释〔2017〕10 号）。

最高人民法院《关于审理民间借贷案件适用法律若干问题的规定》（法释〔2020〕17 号，2020 年第二次修正）。
```

### 主要司法解释类型及缩写

| 类型 | 文号格式 | 备注 |
|------|----------|------|
| 解释 | 法释〔年份〕X 号 | 综合性、体系化解释 |
| 规定 | 法发〔年份〕X 号 | 规范性文件 |
| 批复 | 法释〔年份〕X 号 | 对具体问题的答复 |
| 决定 | 法释〔年份〕X 号 | 修改或废止其他解释的决定 |
| 指导性意见 | 法发〔年份〕X 号 | 审判指导类文件 |

## 四、部门规章

### 基本格式

```
[制定机关]《[规章名称]》（[机关] [年份] 年第 [X] 号令）。
```

### 示例

```
国家市场监督管理总局《网络交易监督管理办法》（国家市场监督管理总局 2021 年第 37 号令）。

中国证券监督管理委员会《上市公司收购管理办法》（中国证券监督管理委员会 2020 年第 166 号令修订）。
```

---

## 五、地方性法规

### 基本格式

```
[省/市]人民代表大会常务委员会《[法规名称]》（[通过日期] [通过机关] [批准情况]）。
```

### 示例

```
广东省人民代表大会常务委员会《广东省数字经济促进条例》（2021 年 7 月 30 日广东省第十三届人民代表大会常务委员会第三十三次会议通过）。
```

---

## 六、国际条约

### 基本格式

```
《[条约全称]》（[签署/加入/批准日期] [对中国生效日期]）。
```

### 示例

```
《保护工业产权巴黎公约》（中国 1984 年 12 月 19 日加入，1985 年 3 月 19 日对中国生效）。

《联合国国际货物销售合同公约》（中国 1986 年 12 月 11 日核准）。

《区域全面经济伙伴关系协定》（2020 年 11 月 15 日签署，2022 年 1 月 1 日对中国生效）。
```

### 英文条约引注（Bluebook Rule 21.4）

```
North American Free Trade Agreement, U.S.-Can.-Mex., Dec. 17, 1992, 32 I.L.M. 289.
```

## 七、中国大陆以外法域法律法规

### 中国香港

```
香港特别行政区《[条例/规例名称]》（第 [章号] 章）。
```

示例：
```
香港特别行政区《个人资料（私隐）条例》（第 486 章）。
```

### 中国台湾

```
中华民国《[法律名称]》（[公布日期] 公布）。
```

注：在引注时应根据发表载体的要求适当处理称谓。

### 欧盟法

```
英文：Regulation (EU) 2016/679 on the protection of natural persons... [2016] OJ L119/1.
中文：欧盟《通用数据保护条例》（GDPR）（Regulation (EU) 2016/679）。
```

## 八、缩略规则

| 缩略形式 | 使用条件 | 示例 |
|----------|----------|------|
| 法律简称 | 前文已有完整引注 | 《民法典》 |
| “同上” / “前引” | 见主文件铁律二 | |
| 特殊简称 | 首次出现时定义 | GDPR |
| 条约简称 | 首次出现时定义 | RCEP |
