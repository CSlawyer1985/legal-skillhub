# 中国司法案例引注详则

> 参考《法学引注手册》第四章“案例”及中国裁判文书网、最高人民法院公报格式。

## 一、基本格式

```
[案件名称]，[案号]（[审理法院] [裁判日期]）。
```

## 二、裁判文书类型

| 类型 | 简称 | 示例 |
|------|------|------|
| 民事判决书 | 民事判决书 | （2019）最高法民终 X 号民事判决书 |
| 刑事判决书 | 刑事判决书 | （2020）京 01 刑初 X 号刑事判决书 |
| 行政判决书 | 行政判决书 | （2021）京行终 X 号行政判决书 |
| 民事裁定书 | 民事裁定书 | （2022）最高法民申 X 号民事裁定书 |
| 刑事裁定书 | 刑事裁定书 | |
| 调解书 | 民事调解书 / 刑事附带民事调解书 | |

## 三、案号解析

案号格式：【（办案年份）】【法院代码】【案件类型简称】【审级】【案号序号】号【裁判文书类型】

### 法院层级代码

| 层级 | 最高人民法院 | 高级人民法院 | 中级人民法院 | 基层人民法院 |
|------|-------------|-------------|-------------|-------------|
| 代码 | 最高法 | [省/自治区/直辖市简称] 高法 | [城市] 中法 | [区/县] 法 |
| 示例 | 最高法 | 京高法 | 京 01 中法 | 海法 |

### 案件类型简称

| 类型 | 简称 |
|------|------|
| 民事 | 民 |
| 刑事 | 刑 |
| 行政 | 行 |
| 知识产权 | 知（或民三） |
| 海事海商 | 海 |
| 国家赔偿 | 赔 |
| 执行 | 执 |

### 审级

| 审级 | 简称 | 适用场景 |
|------|------|----------|
| 一审 | 初 | 基/中/高院一审 |

| 再审审理 | 再 | 再审审理 |
| 申请再审 | 民申 / 刑申 | 向上一级法院申请再审 |

## 四、特殊案例

### 指导性案例

```
指导案例 [序号] 号：[案件名称]（[法院] [案号] [裁判日期]）。
```

示例：
```
指导案例 78 号：北京奇虎科技有限公司诉腾讯科技（深圳）有限公司滥用市场支配地位纠纷案（最高人民法院（2013）民三终字第 4 号民事判决书）。
```

### 公报案例

```
"[案件名称]"，载《中华人民共和国最高人民法院公报》[年份] 年第 [期] 期。
```

示例：
```
"深圳市斯瑞曼精细化工有限公司诉深圳市坑梓自来水有限公司专利权纠纷案"，载《中华人民共和国最高人民法院公报》2013 年第 8 期。
```

**注意：** 公报案例中的案例名称不加书名号，用引号标注。

### 典型案例

```
[发布机关] [年份] 年《[典型案例批次名称]》之 [序号]：[案件名称]（[案号]）。
```

示例：
```
最高人民法院 2020 年《人民法院大力弘扬社会主义核心价值观十大典型民事案例》之一：董存瑞、黄继光英雄烈士名誉权纠纷公益诉讼案（（2019）浙 07 民初 403 号民事判决书）。
```

### 参考案例（人民法院案例库）

```
[案件名称]，人民法院案例库参考案例，入库编号：[编号]。
```

示例：
```
北京微梦创科网络技术有限公司诉北京字节跳动科技有限公司不正当竞争纠纷案，人民法院案例库参考案例，入库编号：2023-09-2-001-001。
```

## 五、英文判例引注（Bluebook Rule 10）

### 美国联邦最高法院

```
[案件名], [卷号] U.S. [起始页], [引用页] ([年份]).
```

示例：
```
Brown v. Board of Education, 347 U.S. 483, 495 (1954).
Marbury v. Madison, 5 U.S. (1 Cranch) 137, 177 (1803).
```

### 美国联邦巡回上诉法院

```
[案件名], [卷号] F.[系列号]d [起始页], [引用页] ([巡回区] Cir. [年份]).
```

示例：
```
Smith v. Jones, 500 F.3d 100, 105 (9th Cir. 2007).
```

### 美国联邦地区法院

```
[案件名], [卷号] F. Supp. [系列号]d [起始页], [引用页] ([地区] [年份]).
```

示例：
```
Doe v. Roe, 200 F. Supp. 3d 50, 55 (E.D. Va. 2016).
```

### 英国判例

```
[案件名] [[年份]] [卷号] [法律报告缩写] [起始页] ([法院]).
```

示例：
```
Donoghue v. Stevenson, [1932] A.C. 562 (H.L.).
```

### 欧盟判例（CJEU）

```
Case C-[案号]/[年份], [案件名], ECLI:EU:C:[年份]:[序号], [引用段].
```

示例：
```
Case C-131/12, Google Spain SL v. Agencia Española de Protección de Datos, ECLI:EU:C:2014:317, ¶ 41.
```

## 六、案例缩略引注

### 中文案例

| 缩略形式 | 使用条件 | 示例 |
|----------|----------|------|
| 同上注 | 紧接前注同一案例 | 同上注。 |
| 前引 [X] | 前文有完整引注 | 前引 [12]，腾讯诉奇虎案民事判决书。 |
| 简称 | 首次引用时定义 | 腾讯诉奇虎案（以下简称“3Q 大战案”） |

### 英文案例

| 缩略形式 | 使用条件 |
|----------|----------|
| Id. at [页码] | 同一脚注内，紧接前注且无其他引注 |
| [案件名简称], [卷号] at [页码] | 前文有完整引注，中间有其他引注 |
