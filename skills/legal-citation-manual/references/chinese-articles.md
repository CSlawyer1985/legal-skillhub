# 期刊论文与学术著作引注详则

> 参考《法学引注手册》第五章“著作”/第六章“论文”及中国法学期刊通用格式。

## 一、期刊论文

### 基本格式

```
[作者]：《[文章标题]》，载《[期刊名]》[年份] 年第 [期] 期，第 [起始页]—[结束页] 页。
```

### 细则

#### 1. 作者
- 中国作者：写全名，不加“著”字
- 外国作者：姓名前加国籍标注，如〔德〕、〔美〕、〔日〕
- 合著：姓名之间用顿号或“、”隔开，三人以上可写“XXX 等”
- 译著论文：标注“XXX 译”

#### 2. 文章标题
- 包含正标题与副标题
- 正副标题之间用“——”或“：”分隔
- 标题中的书名、法规名用双书名号《》
- 标题中外文词语保持原样

#### 3. 期刊名
- 使用全称，不得缩写（中文期刊尤其不能缩略）
- 期刊名中含“学报”“评论”“研究”等必须写全
- 高校学报格式：《北京大学学报（哲学社会科学版）》
- 法学专业期刊示例：
  - 《中国法学》
  - 《法学研究》
  - 《中外法学》
  - 《法商研究》
  - 《法学》
  - 《法律科学》
  - 《法学家》
  - 《环球法律评论》
  - 《比较法研究》

#### 4. 年份和期号
- 使用出版年份（不是投稿/接收年份）
- 期号格式：[年份] 年第 [期号] 期
- 部分期刊有总期号时可一并标注：[年份] 年第 [期号] 期（总第 [X] 期）

#### 5. 页码
- 格式：第 [起始页]—[结束页] 页
- 引用特定观点时标注精确页码：第 15 页
- 页码使用阿拉伯数字

### 常见类型示例

#### 独著
```
朱苏力：《制度是如何形成的？——关于马伯里诉麦迪逊案的故事》，载《比较法研究》1998 年第 1 期，第 66—72 页。
```

#### 合著
```
王利明、周友军：《我国侵权责任法的体系构建》，载《中国法学》2010 年第 4 期，第 5—25 页。
```

#### 外国作者
```
〔美〕罗斯科·庞德：《通过法律的社会控制》，沈宗灵译，载《中外法学》1984 年第 3 期，第 1—10 页。
```

#### 笔谈/专题
```
陈瑞华等：《认罪认罚从宽制度的若干争议问题》，载《中国法学》2017 年第 1 期，第 35—52 页。
```

## 二、学术著作

### 基本格式

```
[作者]：《[书名]》（[版次]），[出版社] [出版地（可选）] [年份] 年版，第 [页码] 页。
```

### 细则

#### 1. 版次
- 初版（第 1 版）不标注版次
- 第 2 版起标注：第 2 版、修订版、增订版等
- 多次再版的重要著作建议标注版次，便于读者查找特定论述

#### 2. 出版社
- 使用出版社全称
- 常见的法学出版社：
  - 北京大学出版社
  - 法律出版社
  - 中国法制出版社
  - 中国政法大学出版社
  - 商务印书馆
  - 中国人民大学出版社
  - 清华大学出版社
  - 社会科学文献出版社

#### 3. 出版年份
- 使用所引用版本的出版年份
- 多次印刷的同版次标注“第 X 次印刷”

#### 4. 页码
- 引用特定内容标注精确页码
- 概括性引用可加“参见”

#### 5. 中国出版地可省略
- 法律出版社等知名出版社出版地通常省略
- 境外出版社建议标注出版地

### 常见类型示例

#### 专著
```
王泽鉴：《民法思维：请求权基础理论体系》，北京大学出版社 2009 年版，第 45 页。
```

#### 第 N 版
```
张明楷：《刑法学》（第 6 版），法律出版社 2021 年版，第 200—205 页。
```

#### 译著
```
〔德〕卡尔·拉伦茨：《法学方法论》，陈爱娥译，商务印书馆 2003 年版，第 150 页。
```

#### 主编/编著
```
梁慧星主编：《民商法论丛》（第 50 卷），法律出版社 2012 年版，第 3 页。
```

#### 英文著作（Bluebook Rule 15）
```
Richard A. Posner, Economic Analysis of Law 45 (9th ed. 2014).

〔英〕H.L.A. Hart, The Concept of Law 100 (3d ed. 2012).
```

## 三、文集论文

### 基本格式

```
[作者]：《[文章标题]》，载 [主编/编者]：《[文集名]》（[版次]），[出版社] [年份] 年版，第 [页码] 页。
```

### 示例

#### 个人文集中的论文
```
苏永钦：《私法自治中的国家强制》，载苏永钦：《走入新世纪的私法自治》，中国政法大学出版社 2002 年版，第 1—50 页。
```

#### 纪念文集中的论文
```
江平：《中国民法典制定的回顾与展望》，载王利明主编：《中国民法典基本理论问题研究》，人民法院出版社 2004 年版，第 1—20 页。
```

#### 会议论文集
```
崔建远：《论合同解释的原则》，载中国法学会民法学研究会编：《中国民法学年会论文集（2015）》，法律出版社 2015 年版，第 88 页。
```

## 四、学位论文

### 基本格式

```
[作者]：《[论文标题]》，[学校全称] [学位级别] 学位论文，[年份] 年，第 [页码] 页。
```

### 示例

```
侯猛：《中国最高人民法院研究——以司法的影响力切入》，北京大学博士学位论文，2004 年，第 88 页。

贺剑：《合同法第 54 条第 1 款第 2 项（显失公平）研究》，北京大学硕士学位论文，2010 年，第 35 页。
```

**注意：**
- 学位论文标题不加书名号
- 学校名称写全称（北京大学，不写“北大”）
- 学位级别：博士 / 硕士
- 年份为答辩/授予年份

## 五、英文期刊论文（Bluebook Rule 16）

### 基本格式

```
[Author], *[Title]*, [Vol.] [Journal Abbrev.] [First Page], [Pinpoint] ([Year]).
```

### 示例

```
Cass R. Sunstein, *On the Expressive Function of Law*, 144 U. Pa. L. Rev. 2021, 2030 (1996).

Ronald Dworkin, *Hard Cases*, 88 Harv. L. Rev. 1057, 1060 (1975).
```

### 短引注格式

```
Sunstein, *supra* note 12, at 2035.
```

## 六、连续出版物、连续文献的引注注意事项

### 期刊连载文章
```
张明楷：《论刑法中的结果归属》（一），载《政治与法律》2023 年第 1 期，第 50 页；
张明楷：《论刑法中的结果归属》（二），载《政治与法律》2023 年第 2 期，第 45 页。
```

### 网络连续出版物
```
[作者]：《[文章标题]》，载 [网站]，[URL]，[发布日期/最后修改日期]，[最后访问日期]。
```
