# 外文文献引注参考

> 涵盖英文 Bluebook、德文、日文、法文法学文献的常见引注格式。

## 一、英文文献综合引注

中文论文中引注英文文献时，一般遵循以下原则：
- 优先使用 Bluebook（21st ed.）格式
- 保持原文格式（斜体、小型大写等印刷格式可用对应中文排版替代或用注释说明）
- 外国作者姓名前在中文学术论文中标注国别：〔美〕、〔英〕、〔德〕等

---

## 二、美国成文法（Bluebook Rules 12—14）

### 美国法典
```
[Title] U.S.C. § [Section] ([Year]).
```
示例：42 U.S.C. § 1983 (2018).

### 美国联邦法规
```
[Title] C.F.R. § [Section] ([Year]).
```
示例：17 C.F.R. § 240.10b-5 (2020).

### 联邦公报
```
[Vol.] Fed. Reg. [Page] ([Date]) (to be codified at [C.F.R. cite]).
```
示例：85 Fed. Reg. 12345 (Mar. 2, 2020).

### 美国宪法
```
U.S. Const. art. I, § 8, cl. 3.
U.S. Const. amend. XIV, § 1.
```

### 州法律
查 Table T1 确定各州格式。
```
Cal. Penal Code § 187 (West 2014).
N.Y. C.P.L.R. § 3211 (McKinney 2015).
```

## 三、英文二级文献（Bluebook Rules 15—17）

### 著作（Rule 15）
```
Richard A. Posner, Economic Analysis of Law 45 (9th ed. 2014).
```
短引注：Posner, *supra* note 5, at 52.

### 期刊论文（Rule 16）
```
Cass R. Sunstein, *On the Expressive Function of Law*, 144 U. Pa. L. Rev. 2021 (1996).
```
短引注：Sunstein, *supra* note 12, at 2030.

### 非连续出版期刊
```
Jonathan Zittrain, *The Fourth Quadrant*, 78 Fordham L. Rev. 1001 (2010).
```

## 四、英文引注信号（Bluebook Rule 1.2）

| Signal | Meaning | Chinese Equivalent |
|--------|---------|-------------------|
| [no signal] | Direct support | （无） |
| *E.g.,* | Examples | 例如 |
| *See* | Implicit support | 参见 |
| *See also* | Additional support | 另参见 |
| *Cf.* | Compare/analogous | 比较 |
| *Compare ... with ...* | Direct comparison | 比较……与…… |
| *But see* | Contradiction | 但见 |

## 五、德文文献引注

德文法学期刊论文常见引注格式：

```
[作者], [标题], [期刊缩写] [卷号] ([年份]), [起始页] ([引用页]).
```

示例：
```
Claus-Wilhelm Canaris, Die Vertrauenshaftung im deutschen Privatrecht, 143 AcP 1 (1937).
Karl Larenz, Methodenlehre der Rechtswissenschaft 200 (6. Aufl. 1991).
```

### 德文常见缩写

| 缩写 | 全称 | 中文 |
|------|------|------|
| AcP | Archiv für die civilistische Praxis | 《民事实践档案》 |
| NJW | Neue Juristische Wochenschrift | 《新法学周刊》 |
| JZ | Juristenzeitung | 《法学家报》 |
| ZHR | Zeitschrift für das gesamte Handelsrecht | 《商法杂志》 |
| Aufl. | Auflage | 第X版 |
| Rn. | Randnummer | 边码号 |
| f. | folgende (Seite) | 及下页 |
| ff. | fortfolgende (Seiten) | 及下数页 |

## 六、日文文献引注

日文法学论文常见引注格式：

```
[作者]「[标题]」[期刊名] [卷号] [期号]（[年份] 年）[起始页] 页。
```

示例：
```
我妻栄「事務管理・不当利得・不法行為」日本評論社（1937 年）。

星野英一「民法の解釈の方法について」法学協会雑誌 94 巻 6 号（1977 年）1 頁。
```

### 日文常见词汇

| 日文 | 中文 |
|------|------|
| 判例 | 判例/案例 |
| 注釈 | 注释 |
| 頁 | 页 |
| 前掲注 | 前引注 |
| 参照 | 参见 |
| 同旨 | 同旨 |

---

## 七、法文文献引注

法文法学论文常见引注格式：

```
[作者], « [标题] », [期刊名] [年份], [起始页], spéc. p. [引用页].
```

示例：
```
René David, « Le droit français », Rev. int. dr. comp. 1950, p. 5, spéc. p. 12.
```

## 八、多语种混排注意事项

### 中英文混排
- 中文学术论文中引用英文文献时：
  - 可使用 Bluebook 标准格式（保持斜体等印刷格式）
  - 建议在作者名前加国别标注：〔美〕
  - 英文期刊名可保留原有缩写（如 Harv. L. Rev.）
  - 投稿中文期刊时，部分期刊要求翻译英文标题，需查询各刊具体投稿须知

### 参考文献列表
- 中文文献在前，外文文献在后；或按语种分列
- 中文文献按作者姓氏拼音排序
- 外文文献按作者姓氏字母排序
- 同一个作者的文献按出版时间先后排序

### 引注原则
- 能见原文则用原文格式，不翻译
- 翻译文献必须在正文标注“XXX 译”
- 转引的文献必须标注“转引自”
- 网络文献必须标注“最后访问日期”
