# 📋 财富传承税务筹划模板

## 一、传承路径税务对比测算

### 1.1 各类资产传承税负对比概览

| 资产类型 | 传承方式 | 当前主要税种 | 税率 | 税负估算 | 遗产税风险 |
|:---------|:---------|:------------|:----|:---------|:----------|
| **不动产** | 法定继承 | 契税(部分地区减免) | 3%-4% | 低 | 高 |
| | 赠与 | 契税+个税(视同转让) | 3%-4%+20% | 高 | 中 |
| | 买卖过户 | 契税+增值税+个税 | 视情况 | 中-高 | 低 |
| | 信托持有 | 契税(设立时)+交易税费 | 需专业测算 | 中-高 | 低 |
| **金融资产** | 继承 | 无直接税负 | — | 低 | 中 |
| | 赠与 | 无直接税负(非直系除外) | — | 低 | 中 |
| | 信托 | 分配时按收益性质定税 | 0-20% | 低-中 | 低 |
| **股权** | 继承 | 无直接税负(变更时可能触发) | 0 | 低 | 高 |
| | 赠与/转让 | 个税(股权转让所得) | 20% | 高 | 中 |
| | 信托装入 | 视同转让(需缴税) | 20%-25% | 高 | 低 |
| | 特殊性税务处理 | 递延纳税 | 暂不征 | 低(短期) | — |
| **保险金** | 指定受益人 | 免征个税+不纳入遗产 | 0 | 零 | 零 |
| | 未指定受益人 | 作为被继承人遗产 | 按继承课税 | 按遗产税 | — |

### 1.2 大额资产传承税务测算模板

#### 情景一：不动产传承（以价值1000万住宅为例）

| 方案 | 税种明细 | 税额 | 总成本 | 优势 | 劣势 |
|:-----|:---------|:-----|:-------|:-----|:-----|
| **继承** | 契税(部分城市减按1.5%)+公证费 | 约15-30万 | **1.5%-3%** | 税负最低 | 程序繁琐/遗产税风险 |
| **赠与** | 契税3%+个税20%(赠与非直系) | 直系30万/非直系230万 | 3%-23% | 手续简单 | 非直系税负极高 |
| **买卖** | 个税1%+增值税5.6%(不满2年)+契税 | 约68-170万 | 6.8%-17% | 权属清晰/无后患 | 当期税负较高 |

#### 情景二：股权传承（以股权转让所得500万为例）

| 方案 | 税种 | 税额 | 总成本 | 说明 |
|:-----|:-----|:-----|:-------|:-----|
| **直接赠与子女** | 个税(视同转让) | 500万×20%=100万 | 20% | 按公允价值计税 |
| **低价转让** | 个税(税务局可能核定) | 按净资产核定 | 类似20% | 平价/低价转让可能被核定 |
| **信托装入** | 视同转让/特殊性税务处理 | 0-100万 | 0-20% | 特殊性税务处理可递延纳税 |
| **留待继承** | 目前无直接税负 | 0 | 0 | 未来遗产税风险最高 |

## 二、遗产税立法趋势与应对预案

### 2.1 立法动态跟踪要点
- 两会提案情况（近5年提案数量与内容变化）
- 财税部门立法研究进展（年度立法工作计划）
- 国际遗产税实践对比（美国/日本/韩国/中国台湾/中国香港）
- OECD税收治理建议

### 2.2 遗产税模拟测算（假设方案）

**假设遗产税方案（参考国际通行做法）：**

| 应税遗产金额 | 假设税率 | 税额测算 | 影响程度 |
|:------------|:--------|:---------|:---------|
| ≤ 500万 | 0%（免征额） | 0 | 不影响 |
| 500万-1000万 | 10% | 25-50万 | 稍有影响 |
| 1000万-5000万 | 20% | 100-800万 | 显著影响 |
| 5000万-1亿 | 30% | 800-2300万 | 重大影响 |
| >1亿 | 40% | 2300万+ | 极其重大 |

### 2.3 应对预案
- **立即行动（遗产税开征前）：**
  - 利用免税窗口期完成大额资产向信托/保险的转移
  - 确保保单受益人指定明确，避免成为遗产
  - 家族信托架构搭建并实质运作
- **遗产税开征后调整：**
  - 评估"祖父条款"保护（已有安排是否追溯）
  - 利用年度免税赠与额度（如有）分散财产
  - 遗产税纳税资金储备（寿险保单）

## 三、税务筹划要点清单

### 3.1 个人所得税筹划
- [ ] 股权传承是否可利用"非交易过户"规则
- [ ] 是否满足特殊性税务处理条件（递延纳税）
- [ ] 创投企业/基金选择单一基金核算vs整体核算的税务影响
- [ ] 信托分配的属性认定（本金/收益/赠与/其他）

### 3.2 不动产传承筹划
- [ ] 买卖vs赠与vs继承的综合成本对比
- [ ] 是否考虑将不动产装入公司/合伙企业持有
- [ ] 是否考虑不动产信托（当前税费门槛高，需专业测算）
- [ ] 满2年/满5年对增值税的影响
- [ ] 是否满足"满五唯一"个税减免条件

### 3.3 企业股权税务筹划
- [ ] 股权转让的税务合规（是否已申报+完税）
- [ ] 是否可适用特殊性税务处理（企业重组）
- [ ] 企业重组增值税/土地增值税/契税优惠适用
- [ ] 股权激励的个税递延纳税备案
- [ ] 非上市公司的股权评估（避免被核定征税）

### 3.4 跨境税务合规
- [ ] CRS申报义务（境外金融账户100万美元以上需特别关注）
- [ ] 境外信托的税务申报要求（美籍/绿卡持有人的PFIC/信托申报）
- [ ] 跨境保险的税务合规（香港保单的申报义务）
- [ ] 税收协定优惠（协定待遇申请+受益所有人认定）
- [ ] 外汇管制合规（资金出境/回流路径规划）

---

**使用说明：** 本模板配合主SKILL「模式四：税务筹划」和「模式一：综合传承规划」使用。重点在于对比各传承路径的税务成本差异，而非追求"零税负"（零税负不现实且可能违法）。筹划方案应标注合规底线和风险提示，联动[[tax-compliance]]进行合规性审查。
