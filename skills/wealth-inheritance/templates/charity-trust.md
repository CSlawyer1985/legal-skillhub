# 🤝 慈善信托与家族慈善规划模板

## 一、慈善信托vs家族基金会对比

| 维度 | 慈善信托 | 家族基金会（慈善组织） |
|:-----|:---------|:---------------------|
| **法律依据** | 《慈善法》第44-50条、《信托法》 | 《基金会管理条例》 |
| **设立门槛** | 无明确规定（实践中100万起可操作） | 原始基金≥800万（全国性）/≥400万（地方性） |
| **设立程序** | 备案制（向民政部门备案） | 审批制（需业务主管单位审批+民政登记） |
| **决策机制** | 受托人决策+保护人监督 | 理事会决策 |
| **财产管理** | 信托公司管理运营 | 基金会自行管理/委托投资 |
| **运营成本** | 低（年管理费约0.3%-0.8%） | 高（行政开支≤年度总支出的10%-15%） |
| **税务优惠** | 可开具捐赠票据（需有公募资格或通过联合劝募） | 可自行开具捐赠票据 |
| **永续性** | 可设定永续 | 永续（需持续运营） |
| **适合场景** | 以财产管理为核心、注重隐私 | 以公益项目运营为核心、希望建立品牌 |

## 二、慈善信托架构设计

```
委托人（家族/企业家）
        │
  设立慈善信托
        │
        ↓
┌───────────────┐
│   慈善信托     │
│   （受托人：    │
│   信托公司）   │
└───────┬───────┘
        │
        ├── 保护人/监察人（家族成员/律师）
        │
        └── 受益人（公益项目/特定人群）
                │
                ├── 教育助学
                ├── 医疗救助
                ├── 扶贫济困
                ├── 文化保护
                └── 环保/ESG
```

## 三、慈善在传承中的四大价值

1. **税务优化** — 慈善支出可税前扣除（年度利润总额12%以内可结转）
2. **家族凝聚力** — 慈善项目作为家族成员共同参与的事务，强化联系
3. **价值观传承** — 以家族名义做慈善，传承家族精神和品牌
4. **社会声誉** — 提升家族/企业的社会形象

## 四、家族慈善规划流程

- [ ] 确定慈善方向（家族使命/社会价值/个人兴趣）
- [ ] 选择慈善工具（慈善信托/基金会/直接捐赠/捐赠人建议基金DAF）
- [ ] 设立架构（受托人选择+保护人任命+备案程序）
- [ ] 财产划拨（现金/股权/不动产的慈善捐赠税务处理）
- [ ] 制定慈善支出计划（年度支出比例+项目方向）
- [ ] 税务合规（捐赠票据+所得税扣除申报）
- [ ] 家族成员参与机制（理事会席位/项目决策权）

## 五、慈善工具组合方案

| 方案 | 架构 | 适合场景 |
|:-----|:-----|:---------|
| **纯慈善信托** | 信托公司受托+慈善项目执行 | 注重财产管理+不希望设立组织 |
| **基金会+慈善信托** | 基金会做项目+慈善信托管钱 | 资产规模大+希望建立慈善品牌 |
| **家族信托+慈善子信托** | 同一信托架构下设慈善与私益双通道 | 兼顾家人利益与慈善 |
| **DAF（捐赠人建议基金）** | 捐赠至公共基金会专项基金，保留建议权 | 规模较小+灵活度高 |
