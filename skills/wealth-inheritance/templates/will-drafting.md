# 📜 遗嘱规划模板

## 一、遗嘱类型选择

| 遗嘱形式 | 法律依据 | 形式要件 | 推荐场景 | 风险提示 |
|:---------|:---------|:---------|:---------|:---------|
| 自书遗嘱 | 《民法典》第1134条 | 全文手写+签名+年月日 | 简单家庭、资产类型单一 | 笔迹鉴定风险、涂改风险 |
| 代书遗嘱 | 《民法典》第1135条 | 2名以上见证人+代书人+遗嘱人+见证人签名+年月日 | 无法手写、需要专业指导 | 见证人资格审查、代书人非见证人 |
| 打印遗嘱 | 《民法典》第1136条 | 2名以上见证人+遗嘱人和见证人每页签名+年月日 | 打印文书较为规范 | 每页签名的完整性 |
| 录音录像遗嘱 | 《民法典》第1137条 | 2名以上见证人+记录姓名或肖像+年月日 | 紧急情况、无法书写 | 完整过程记录、原始载体保管 |
| 公证遗嘱 | 《民法典》第1139条 | 公证处依程序办理 | 希望最高形式效力 | 变更麻烦（需再次公证或另立其他形式） |
| 密封遗嘱 | 参照代书遗嘱+密封 | 密封+签名+2名以上见证 | 希望保密内容 | 形式要件复杂，不常用 |

## 二、遗嘱起草要素检查

### 2.1 基本要素
- [ ] 遗嘱人姓名、身份证号、住址
- [ ] 遗嘱人声明精神清醒、意思表示真实
- [ ] 遗嘱人声明已理解遗嘱的法律后果
- [ ] 排除受胁迫、欺诈或重大误解的情形声明

### 2.2 遗产处分
- [ ] 遗产清单（具体财产名称、位置、权属证明编号）
- [ ] 每项财产的处分方式（由谁继承/赠与谁/设立信托）
- [ ] 如有共有财产（夫妻共有/家庭共有），说明遗嘱人享有的份额
- [ ] 附条件/附义务遗嘱的条件合法性审查

### 2.3 继承人指定
- [ ] 继承人姓名、身份信息、与遗嘱人关系
- [ ] 继承份额（具体比例或固定金额/财产）
- [ ] 备位继承人（继承人先于遗嘱人死亡时的替代方案）
- [ ] 继承顺序（多名继承人的顺位）

### 2.4 特殊条款
- [ ] 必留份审查（是否有缺乏劳动能力且无生活来源的继承人）
- [ ] 遗嘱执行人指定（姓名+联系方式+备位）
- [ ] 遗嘱执行人报酬
- [ ] 遗产管理人指定（如有多名继承人）
- [ ] 遗嘱废止声明（声明废止此前所立全部/部分遗嘱）
- [ ] 特留份（特定继承人可继承的份额）

### 2.5 遗嘱信托条款（如适用）
- [ ] 受托人指定（+备位受托人）
- [ ] 信托财产范围
- [ ] 受益人确定
- [ ] 信托管理方式
- [ ] 信托期限与终止条件

## 三、见证人资格审查

**下列人员不得作为遗嘱见证人：**
- [ ] 无民事行为能力人、限制民事行为能力人
- [ ] 继承人、受遗赠人
- [ ] 与继承人、受遗赠人有利害关系的人
  - 继承人、受遗赠人的近亲属（配偶、子女、父母等）
  - 债权人、债务人、共同经营的合伙人
  - 其他可能影响见证公正性的人

**见证人推荐资格：**
- 律师（最推荐）
- 公证员
- 社区工作者
- 非利害关系亲友

## 四、⚠️ 关键法律风险提示

### 4.1 形式要件缺失的后果
- 缺签名/日期 → 遗嘱无效
- 见证人不足2人 → 遗嘱无效
- 见证人资格有问题 → 遗嘱可能被认定为无效
- 代书遗嘱中代书人未同时作为见证人 → 形式瑕疵

### 4.2 多份遗嘱的效力处理
- 公证遗嘱不再具有优先效力（《民法典》第1142条修正）
- 以最后一份合法有效遗嘱为准
- 建议在新遗嘱中明确废止前一份遗嘱

### 4.3 特留份（必留份）
- 遗嘱应当为"缺乏劳动能力且无生活来源的继承人"保留必要份额
- 违反必留份的遗嘱部分无效
- 审查时点：遗嘱生效时（非订立时）

### 4.4 遗产范围的准确界定
- 夫妻共同财产中仅能处分属于遗嘱人的份额
- 家庭共有财产需先分割
- 处分他人财产的遗嘱部分无效

### 4.5 附义务遗嘱
- 义务内容不得违反法律强制性规定和公序良俗
- 义务内容需具有可执行性
- 继承人不履行义务的，可经利害关系人请求或有关组织请求，法院取消其接受附义务部分遗产的权利

## 五、遗嘱保管与执行

- [ ] 遗嘱原件保管人+保管方式
- [ ] 告知哪些人遗嘱的存在（不一定要告知内容）
- [ ] 遗嘱副本存放安排
- [ ] 遗嘱执行人通知机制
- [ ] 遗产管理启动程序

## 六、遗嘱更新检视（建议每2年一次）

| 检视事项 | 变化情况 | 是否需修正遗嘱 |
|:---------|:---------|:--------------|
| 婚姻状况变化（结婚/离婚/再婚） | □是 / □否 | □是 □否 |
| 子女情况变化（出生/死亡/结婚/特殊需要） | □是 / □否 | □是 □否 |
| 资产重大变化（买卖房产/股权变动/继承大额财产） | □是 / □否 | □是 □否 |
| 法律变化（继承法修改/遗产税立法） | □是 / □否 | □是 □否 |
| 继承人状况变化（死亡/丧失继承权/移民） | □是 / □否 | □是 □否 |
| 遗嘱执行人/受托人情况变化 | □是 / □否 | □是 □否 |
