# 🛡️ 保险金信托与保单规划模板

## 一、保单架构设计基础

### 1.1 保单三方关系

| 角色 | 权利 | 风险 | 传承设计要点 |
|:-----|:-----|:-----|:------------|
| **投保人** | 缴纳保费、持有保单、可变更受益人、可退保、可质押贷款 | 退保权/退保现金价值归属/投保人债务风险 | 建议选择资产隔离能力强、债务风险低的一方担任 |
| **被保险人** | 保险标的、身故/重疾触发保险金给付 | 如实告知义务/寿命风险 | 通常为被传承人（父/母） |
| **受益人** | 保险事故发生后领取保险金 | 指定不明确导致保险金成为遗产 | 建议明确指定姓名+身份证号+份额+顺序 |

### 1.2 大额保单在传承中的特殊功能

| 功能 | 效果 | 法律依据 |
|:-----|:-----|:---------|
| **定向传承** | 身故保险金直接给付指定受益人，不经过继承程序 | 《保险法》第39-42条 |
| **杠杆效应** | 保费支出远低于保额（终身寿险杠杆率1:3-1:7） | 精算原则 |
| **税务优惠** | 身故保险金免征个人所得税 | 《个人所得税法》第4条第5项 |
| **债务隔离（有限）** | 指定受益人的身故保险金不作为被保险人遗产，原则上不用于清偿被保险人生前债务 | 《最高人民法院关于保险金能否作为被保险人遗产的批复》 |
| **隐私保护** | 保险金给付程序简单快捷，无需继承公证 | 保险合同约定 |
| **可控性** | 投保人可随时变更受益人 | 《保险法》第41条 |

## 二、保险金信托架构

### 2.1 保险金信托1.0模式

```
委托人(投保人/被保险人)
        │
        ├── 投保并指定受益人 → [人寿保险合同]
        │                              │
        │                         保险事故(身故)发生
        │                              │
        │                    ┌──────────┘
        │                    ↓
        │              保险金赔付
        │                    │
        └───── 设立 ←── [保险金信托合同]
                                   │
                             受托人(信托公司)
                                   │
                             管理/投资信托财产
                                   │
                             向信托受益人分配
```

**特点：**
- 门槛较低（保额300-500万即可）
- 先投保后设信托（或同步签署）
- 信托生效于保险金给付之时（保单存续期内信托不运作）
- 杠杆效应：低保费撬动高保额，进入信托的资产放大了

**关键条款：**
- 须在保单受益人栏填写信托公司（受托人）为指定受益人
- 信托合同中明确保险金作为信托财产
- 保险事故发生后，保险公司将保险金直接划付至信托专户

### 2.2 保险金信托2.0模式

```
委托人(投保人)
        │
        ├── 向信托公司交付初始资金（可豁免或少量）
        ├── 将保单质押或直接装入信托
        │
        ↓
[家族信托]
   │
   ├── 受托人作为保单的新投保人（缴纳保费）
   ├── 受托人作为保单的被保险人变更管理者
   ├── 保险事故后，受托人作为保单受益人领取保险金
   │
   └── 信托财产统一管理→向信托受益人分配
```

**特点：**
- 更强的资产隔离（保单所有权已转入信托）
- 信托设立时即开始运作
- 门槛较高（保额500万起）
- 可追加其他资产进入同一信托

**与1.0模式对比：**

| 维度 | 保险金信托1.0 | 保险金信托2.0 |
|:-----|:-------------|:-------------|
| 信托财产 | 仅保险金请求权 | 保险合同+资金+其他资产 |
| 信托设立时间 | 与保单同存续 | 即时设立并运作 |
| 资产隔离强度 | ⚠️ 保单现金价值仍在投保人名下 | ✅ 保单所有权已转至信托 |
| 保费支付 | 委托人继续支付 | 信托支付（减少委托人的债务风险） |
| 门槛 | 300-500万(保额) | 500万+(保额) |
| 设立复杂度 | 中 | 较高 |

## 三、常见保单架构设计方案

### 3.1 婚姻财产保护保单设计

**场景：** 客户即将结婚或处于婚姻危机中，希望隔离婚前财产

| 保单类型 | 投保人 | 被保险人 | 受益人 | 效果 |
|:---------|:-------|:---------|:-------|:-----|
| 终身寿险 | 客户自身（保费来源于婚前财产账户） | 客户自身 | 子女/父母 | 身故保险金不属于夫妻共同财产 |
| 年金险 | 客户父母 | 客户 | 客户本人 | 年金不属于夫妻共同财产（父母赠与定向） |
| 重疾/医疗险 | 客户自身（婚前财产支付） | 客户自身 | 法定继承人或指定 | 重疾理赔金用于治疗，不属于共同财产 |

**注意：** 婚前购买但婚后继续缴纳保费的保单，婚后缴费部分对应的现金价值属于夫妻共同财产。

### 3.2 遗产税储备保单设计

**场景：** 客户拥有大量不动产/股权，担心未来遗产税开征时继承人无现金缴税

- 以客户为投保人和被保险人
- 以继承人（子女）为受益人
- 保额 ≈ 预计遗产税的现金需求（一般为应税遗产的20%-50%）
- 寿险杠杆放大传承现金

### 3.3 特殊需要子女保单设计

**场景：** 客户有身心障碍子女，需要终身照护

- 以客户为投保人和被保险人
- 以特殊需要信托为受益人
- 身故保险金进入信托，通过信托条件分配保障特殊子女终身照护

## 四、⚠️ 保单法律风险检查

### 4.1 受益人指定风险
- [ ] 受益人是否明确指定了姓名、身份证号、与投保人/被保险人的关系
- [ ] 多名受益人的受益顺序和份额是否清晰
- [ ] 是否存在"法定"受益人表述 —— 会导致保险金成为遗产
- [ ] 是否留有备位受益人（第一顺位受益人死亡时的替代方案）
- [ ] 受益人变更权限是否明确、是否通知了保险公司

### 4.2 保单执行风险
- [ ] 保单现金价值在投保人所在地的强制执行政策（各地司法实践差异较大）
- [ ] 保单是否属于"生活必需品"（医疗险/重疾险执行豁免可能性高）
- [ ] 投保人的债务风险等级评估
- [ ] 是否考虑将保单装入信托（保险金信托2.0）以强化隔离

### 4.3 跨境保单风险
- [ ] 境外保单是否在中国法下被认定为有效
- [ ] 境外保单的保险金跨境是否受外汇管制限制
- [ ] 境外保单是否合规（大陆居民购买香港/澳门保单需在境内合规销售渠道完成）
- [ ] 外汇管理合规（保险金能否顺利回到内地）

### 4.4 如实告知与不可抗辩条款
- [ ] 被保险人的健康告知是否完整、准确
- [ ] 是否存在未告知的重大健康异常
- [ ] 保险合同生效已满2年（不可抗辩条款适用，保险公司不得以未如实告知解除合同）

## 五、保单年度检视清单

- [ ] 保单状态是否正常（缴费/停效/失效）
- [ ] 受益人信息是否需要更新（婚姻变化/子女出生/原受益人死亡）
- [ ] 保单现金价值是否满足当前的资产隔离需求
- [ ] 保额是否仍然充足（通货膨胀/资产增值）
- [ ] 是否出现新的传承需求需要调整保单架构
- [ ] 保险公司的财务状况/信用评级
- [ ] 是否需要将已有保单升级为保险金信托

---

**使用说明：** 本模板配合主SKILL「模式二：婚姻财产保护」和「模式四：税务筹划」使用。保险方案通常作为综合传承方案的组成部分，与遗嘱、信托、税务筹划配合使用。保单架构设计以简单清晰为原则，避免过度复杂的多层架构导致执行困难。
