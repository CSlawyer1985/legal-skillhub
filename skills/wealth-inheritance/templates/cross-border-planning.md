# 🌏 跨境财富传承规划模板

## 一、跨境传承法律框架

### 1.1 法律适用

| 资产类型 | 法律适用原则 | 法律依据 |
|:---------|:------------|:---------|
| **中国境内不动产** | 不动产所在地法（中国法） | 《涉外民事关系法律适用法》第36条 |
| **中国境内股权** | 法人登记地法（中国法） | 《涉外民事关系法律适用法》第14条 |
| **境外不动产** | 不动产所在地法 | 各国法律 |
| **境外金融资产** | 通常适用账户所在地法/受托人所在地法 | 各国法律+开户行/托管行规则 |
| **动产物权** | 法律事实发生时财产所在地法 | 《涉外民事关系法律适用法》第37条 |
| **继承关系** | 不动产：不动产所在地法；动产：被继承人经常居所地法 | 《涉外民事关系法律适用法》第31-35条 |

### 1.2 常见跨境家庭结构

| 类型 | 典型场景 | 核心风险 | 推荐方案 |
|:-----|:---------|:---------|:---------|
| **子女海外身份型** | 子女持有美/加/澳/新永居或国籍，父母中国籍 | 双重税务居民身份；境外税务申报；继承程序复杂 | 境内信托+境外税务合规+双边规划 |
| **跨境资产型** | 家人在中国，资产分散在美/港/新/欧 | 外汇管制+多法域继承+CRS申报 | 离岸信托+境内信托联动+双边律师合作 |
| **移民家庭型** | 父母已移民，子女在海外出生/成长 | 捐赠税（Exit Tax）；境外资产申报；中国境内资产处理 | 移民前信托规划+税务筹划+跨境遗嘱 |
| **外籍继承中国资产** | 继承人是外籍，资产在中国 | 外汇管制资金出境；继承公证涉外认证；外资准入限制 | 公证继承+外汇申请+信托替代方案 |

## 二、离岸信托常见法域对比

| 法域 | 核心优势 | 劣势 | 设立成本 | 年维护成本 | 推荐场景 |
|:-----|:---------|:-----|:---------|:----------|:---------|
| **新加坡** | 政治稳定+信托法律成熟+税收优惠（13O/13U） | 成本较高 | 3-5万美元 | 1-2万美元 | 亚太资产+希望靠近中国 |
| **香港** | 普通法系+与中国联系紧密+税务简单 | 政治不确定性 | 2-4万美元 | 1-1.5万美元 | 中国背景+有香港资产 |
| **泽西岛** | 信托法最成熟+司法体系完善+信息保密 | 距离远+成本高 | 4-8万美元 | 2-3万美元 | 超高净值+英国/欧资资产 |
| **BVI** | 成本低+灵活度高+VISTA信托适合股权 | 近年监管趋严+经济实质要求 | 1-2万美元 | 0.5-1万美元 | 中小规模资产+控股架构 |
| **开曼** | 免税+STAR信托+私募/SPV成熟 | 成本高于BVI+经济实质法要求 | 2-4万美元 | 1-2万美元 | 股权架构+有上市计划 |
| **新西兰** | 税收透明+政治稳定+信息保密 | 成本高+距离远 | 5-8万美元 | 2-3万美元 | 英联邦资产+长期稳定规划 |

## 三、跨境传承核心问题

### 3.1 外汇管制

| 场景 | 合规路径 | 限制 |
|:-----|:---------|:-----|
| 境内资金出境设立离岸信托 | QDII/对外直接投资(ODI)/个人购汇额度(5万美元/年) | ODI需审批；QDII有额度限制；个人购汇不可用于境外投资 |
| 境外保险金/信托分配入境 | 经常项目外汇收入+税务申报证明 | 需提供基础交易真实性材料 |
| 境内资产变现后转移境外 | 移民财产转移/继承财产转移 | 限移民/继承场景+需税务完税证明 |
| 境外资产变现后使用 | 自由（境外资金自由使用） | CRS需申报 |

### 3.2 CRS与FATCA合规

- [ ] 是否持有境外金融账户（存款/托管/保险/信托等）且余额>25万美元
- [ ] 是否已在所在国申报（FBAR/8938/中国CRS申报等）
- [ ] 境外信托是否在CRS申报范围内（被动NFE/信托申报义务）
- [ ] 美国受益人需额外提交PFIC/信托税务申报
- [ ] 中国税务居民境外收入需自行申报（《个人所得税法》第1条+第7条）

### 3.3 跨境继承程序

```
中国境内资产 → 公证继承（涉外公证+领事认证）→ 不动产/股权变更登记
                  ↓
              继承人外籍 → 涉外公证需翻译+认证
                  ↓
              如需将资金汇出 → 继承财产转移申请（国家外汇管理局）

境外资产 → 遗嘱认证(Probate) → 各法域依冲突规则处理
                  ↓
              境内法院判决 → 外国判决承认与执行（如争议）
```

### 3.4 跨国税务考量

- 是否涉及美国受益人 → PFIC申报+信托申报(3520/3520-A)
- 是否涉及加拿大受益人 → 离岸信托税务申报(T1141/T1142)
- 中国税务居民 → 境外资产/收入申报+税收抵免
- 双重税务居民 → 税收协定优先+税务居民选择
- Exit Tax / 出境税 → 美国/加拿大放弃身份时的视同出售税

## 四、跨境传承方案设计要点

| 问题 | 方案设计要点 |
|:-----|:------------|
| **多法域遗嘱冲突** | 分别就各法域资产立嘱（如：境内资产中国遗嘱+境外资产当地遗嘱） |
| **信托法域选择** | 考虑资产所在地+受益人税务居民身份+受托人所在地 |
| **外汇管制** | 预留资金通道；考虑成本；境内信托兜底 |
| **税务合规** | 确保所有受益人了解申报义务；定期税务审查 |
| **遗嘱认证** | 提前准备；避免冲突；考虑信托替代继承 |
| **跨境争议解决** | 仲裁条款优先；选择中立法域；明确法律适用 |

---

**使用说明：** 跨境财富传承需要至少两个法域的律师配合。本模板用于协助境内律师与境外律师的协作，确保传承方案的各法域合规性。凡涉及美国/加拿大受益人或资产的，必须由当地税务律师参与方案设计。
