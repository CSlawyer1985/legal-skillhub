# 💍 婚前财产隔离与婚姻财产保护模板

## 一、婚姻财产风险全景图

```
结婚前                          结婚后                         离婚/继承
   │                              │                              │
   ├─ 个人财产                  ├─ 共同财产生成               ├─ 财产分割
   │   • 婚前不动产              │   • 婚后工资/经营收益       │   • 共同财产50%/50%
   │   • 婚前存款/股票          │   • 婚内投资增值部分         │   • 个人财产归各自
   │   • 婚前保单               │   • 婚后购置资产             │   • 过错方少分
   │   • 继承/赠与财产          │   • 共同还贷对应增值         │   • 家务补偿/扶助
   │                            │                              │
   ├─ 混同风险                  ├─ 债务风险                   ├─ 传承风险
   │   • 婚前婚后资金混存       │   • 夫妻共同债务认定         │   • 遗产中的共同财产先分割
   │   • 房产加名/换房          │   • 企业担保连带到个人       │   • 配偶必留份
   │   • 账户共用               │   • 个人债务vs共同债务       │   • 遗嘱不能处分配偶份额
```

## 二、三层保护架构

### 第一层：协议保护（基础层）

| 协议类型 | 适用场景 | 核心条款 | 法律依据 | 注意事项 |
|:---------|:---------|:---------|:---------|:---------|
| **婚前财产协议** | 即将结婚 | 各自婚前财产归属+婚后财产制选择+债务隔离 | 《民法典》第1065条 | 需双方自愿+书面+不违反强制性规定 |
| **婚内财产协议** | 已婚/危机中 | 分别财产制或部分分别制+现有财产归属+未来收益安排 | 《民法典》第1065条 | 离婚协议中财产分割条款≠婚内协议效力 |
| **忠诚协议** | 已婚（信任不足） | 违反忠诚义务的经济赔偿+财产归属调整 | 司法实践支持部分 | 不得限制人身自由+不得显失公平 |
| **分居协议** | 分居期间 | 分居期间的财产归属+债务承担+子女抚养 | 司法实践参考 | 分居期间收入是否共同财产各地不一 |

### 第二层：保险保护（隔离层）

```
投保人 → 自已（资产隔离需求方）
         被保险人 → 自己
         受益人 → 子女/父母（非配偶）
                    ↓
         效果：身故保险金直接给付子女/父母
               不作为夫妻共同财产
```

**保险隔离的三种常用策略：**

| 策略 | 架构 | 效果 | 风险 |
|:-----|:-----|:-----|:-----|
| **婚前全额缴清保单** | 婚前以个人财产一次性缴清保费 | 保单现金价值属于婚前个人财产 | 婚前账户与婚后账户混同风险 |
| **父母为投保人** | 父母为投保人+客户为被保险人 | 保单属于父母财产，离婚时不被分割 | 保费来源需清晰+父母掌控保单 |
| **年金险+信托** | 父母为投保人+客户为被保险人，年金进入信托 | 年金归属明确+再隔离一层 | 架构较复杂+有设立成本 |

### 第三层：信托保护（强隔离层）

**婚前信托架构：**
```
委托人（客户）
    │
    ├── 设立信托（婚前/婚前财产）
    │
    ├── 受托人（信托公司）
    │
    ├── 受益人：客户本人（生前）+子女（身后）
    │
    └── 保护人：客户指定的可信人

效果：
• 信托财产独立于委托人（非夫妻共同财产）
• 信托分配按合同执行（不因离婚而变更）
• 信托保护人监督受托人
• 信托受益权（未分配部分）不属于夫妻共同财产
```

**婚内危机信托（防护升级）：**
- 从婚内财产中分离部分资产设立信托
- 受益人包括配偶（稳定婚姻关系）+子女（确信继承权）
- 防止企业债务穿透至家庭资产
- 保护特殊需要子女的终身照护资金

## 三、各婚姻阶段的隔离方案对比

| 婚姻阶段 | 推荐方案 | 保护强度 | 实施难度 | 客户接受度 |
|:---------|:---------|:---------|:---------|:-----------|
| **婚前1-3个月** | 婚前协议+婚前信托+婚前保单 | ⭐⭐⭐⭐⭐ | 低 | 高（结婚前法律安排天然合理） |
| **婚后1-3年** | 婚内协议+保险金信托+部分资产信托 | ⭐⭐⭐⭐ | 中 | 中（需合适的触发契机） |
| **出现危机但未分居** | 婚内协议+信托+保险（综合防护） | ⭐⭐⭐⭐ | 中高 | 高（危机感驱动） |
| **已分居** | 分居协议+资产梳理+证据固定 | ⭐⭐⭐ | 中 | 高（紧迫性驱动） |
| **已启动离婚程序** | 诉讼策略+财产保全+评估鉴定 | ⭐⭐ | 高 | 必须（被动应对） |

## 四、房产保护的税务与法律路径

| 方案 | 法律效果 | 税费成本 | 风险 |
|:-----|:---------|:---------|:-----|
| **婚前全款购房** | 个人财产（房产不因结婚而转化） | 契税3% | 换房可能改变性质 |
| **婚前按揭+婚后共同还贷** | 婚前首付部分个人财产+共同还贷对应部分补偿 | 契税+还贷证明 | 共同还贷部分需折算+增值部分可分 |
| **婚前房产公证+协议** | 明确个人财产+排除混同 | 公证费≈0.1%-0.3% | 需办理抵押银行同意 |
| **父母出资+赠与协议** | 明确赠与给子女一人（非夫妻双方） | 契税3% | 需书面赠与协议+银行流水 |
| **房产装入信托** | 隔离力度最强 | 契税+增值税+个税（高） | 当前税费较高+不动产信托登记制度不成熟 |

## 五、检查清单

### 婚前保护
- [ ] 婚前财产明细清单（附权属证明+价值评估）
- [ ] 婚前银行存款账户隔离（不开设共同账户前）
- [ ] 婚前保单（已缴清全部保费或明确保费来源）
- [ ] 婚前签署财产协议（如有需要）
- [ ] 父母赠与个人的书面协议
- [ ] 婚前信托架构（如资产较大）

### 婚内风险排查
- [ ] 是否存在夫妻共同债务风险（共签共债/日常家事代理）
- [ ] 企业担保是否延伸至个人/家庭财产
- [ ] 保单受益人是否合理指定（非"法定"）
- [ ] 是否有必要签订婚内财产协议
- [ ] 是否需要设立家庭信托保护资产

### 危机期紧急措施
- [ ] 梳理所有资产清单+凭证复印
- [ ] 锁定婚内财产证据（收入证明+房产证+保单+股权证明）
- [ ] 债务隔离评估（区分个人债务vs共同债务）
- [ ] 财产线索保全（防止转移/隐匿）
- [ ] 信托保护方案（如有前期的信托架构检查其效力）
- [ ] 求助[[marriage-family-law-skill]]联动启动诉讼准备
