### 1.2 企业常见传承风险清单

- [ ] **股权过于集中** — 创始人持股过高，去世后遗产分割可能导致控制权分散
- [ ] **股权过于分散** — 多名子女等额持股，决策僵局风险
- [ ] **接班人未明确** — 无法定接班人/接班人未准备好/接班人无意愿
- [ ] **缺乏管理层激励** — 非家族核心管理层无股权/期权，人才流失风险
- [ ] **企业债务与家族财产混同** — 个人担保过多，企业风险向家族传导
- [ ] **家族与企业不分** — 家族消费列支企业费用；股东借款长期不还
- [ ] **缺乏退出机制** — 不参与经营的家人无法退出股权，恶化家族关系
- [ ] **无家族议事规则** — 家族内部纠纷缺乏解决机制
- [ ] **税务不合规历史** — 企业存在税务合规瑕疵，传承时触发稽查风险
- [ ] **境外架构不清晰** — 红筹/VIE/离岸公司等复杂架构的传承安排缺失

## 二、股权架构优化方案

### 2.1 常见股权架构选项

| 架构类型 | 适合场景 | 核心优势 | 核心劣势 | 设立成本 |
|:---------|:---------|:---------|:---------|:---------|
| **直接持股** | 简单家庭、单一股东 | 架构简单、成本低 | 无风险隔离、控制权不灵活 | 最低 |
| **有限公司控股** | 2-3名子女，简单接班 | 有限责任、适度隔离 | 股权分散、决策效率低 | 中 |
| **有限合伙控股** | 需要控制权集中的家族 | GP控制权保留、LP分收益 | GP无限责任 | 中高 |
| **家族信托持股** | 超大家族、长期传承 | 最强隔离、税务灵活 | 设立成本高、监管复杂 | 高 |
| **控股公司+信托双层** | 高净值企业家家族 | 隔离+控制+税务三重优势 | 设立成本最高 | 最高 |

### 2.2 有限合伙持股架构设计

```
                    ┌─────────────────┐
                    │  家族事务委员会  │
                    │  (制定投资策略)  │
                    └────────┬────────┘
                             │
                    ┌────────┴────────┐
                    │  GP(普通合伙人)  │
                    │     • 控制权     │
                    │  • 通常由创始人/  │
                    │    接班人担任    │
                    │  • 出资1%但控股  │
                    └─────────────────┘
                             │
                    ┌────────┴────────┐
                    │ [有限合伙]      │
                    │ 持股平台        │
                    └──┬────────┬───┘
                       │        │
              ┌────────┴──┐  ┌──┴────────┐
              │ LP1(配偶)  │  │ LP2(子女1) │
              │ • 收益权   │  │ • 收益权   │
              │ • 无控制权│  │ • 无控制权│
              └───────────┘  └───────────┘
```

### 2.3 家族信托持股架构设计

```
                    ┌─────────────────┐
                    │  家族信托(委托人) │
                    │  • 创始人为委托人│
                    │  • 家族成员为受益人│
                    └────────┬────────┘
                             │
                    ┌────────┴────────┐
                    │  SPV控股公司    │
                    │  • 信托全资持有  │
                    │  • 董事会决策权  │
                    └────────┬────────┘
                             │
                    ┌────────┴────────┐
                    │  家族企业       │
                    │  (运营实体)     │
                    └─────────────────┘
```

**设计要点：**
- 创始人/接班人通过董事会席位保留经营控制权
- 家族成员通过信托受益人资格享有收益权
- 企业股权与个人债务彻底隔离
- 避免因创始人去世导致的股权继承变更程序

### 2.4 股权传承方案对比

| 方案 | 控制权安排 | 收益权安排 | 税负 | 实施难度 | 推荐 |
|:-----|:----------|:----------|:-----|:---------|:----|
| **方案A：有限合伙架构** | 创始人或接班人为GP | 全部子女为LP | 股权变更触发个税 | 中 | ⭐控制权优先 |
| **方案B：信托持股架构** | 信托持有-董事会决策 | 全部家族成员为受益人 | 股权装入信托视同转让 | 高 | ⭐强隔离+长期传承 |
| **方案C：直接分配股权** | 各子女按持股比例投票 | 各子女按持股比例分红 | 无直接税负 | 低 | 仅适合简单家庭 |
| **方案D：部分出售+信托** | 出售部分给管理层/外部+信托持剩余 | 混合收益 | 出售触发资本利得税 | 中高 | 适合无接班人场景 |

### 3.2 渐进式接班时间表

```
Phase 1: 培训期（第1-3年）
  ├── 行业基础知识培训
  ├── 企业各部门轮岗（6个月/部门）
  ├── 外部MBA/管理培训
  └── 导师制度（创始人1对1辅导）

Phase 2: 管理期（第3-5年）
  ├── 担任部门经理/副总经理
  ├── 独立负责一条业务线
  ├── 参与董事会/经营会议
  └── 逐步接手部分管理决策权

Phase 3: 接班期（第5-7年）
  ├── 担任总经理/CEO
  ├── 创始人转为董事长/顾问
  ├── 完成管理权交接
  └── 股权同步转移（部分/全部）

Phase 4: 巩固期（第7-10年）
  ├── 接班人全面掌权
  ├── 创始人完全退出
  └── 家族治理机制运行成熟
```

### 3.3 管理层股权激励方案

| 激励工具 | 适合场景 | 稀释影响 | 实施复杂度 | 说明 |
|:---------|:---------|:---------|:-----------|:-----|
| **期权** | 成长型企业 | 未来稀释 | 中 | 授予行权价+等待期+行权条件 |
| **限制性股份** | 成熟企业 | 即期稀释 | 中 | 直接授予但限制转让+回购条款 |
| **虚拟股权** | 不愿稀释股权的家族企业 | 不稀释股权 | 低 | 按虚拟股分享利润/增值（非实际股东） |
| **业绩股份** | 上市/拟上市公司 | 业绩达标后稀释 | 高 | 业绩目标+股份兑现 |

## 四、家族治理体系设计

### 4.1 家族治理三层架构

```
┌─────────────────────────────────────────┐
│           家族全体会议（家族议会）        │
│  • 全体家族成员参加（包括不参与经营的成员）│
│  • 每年1次，通报企业情况+家族事务决策     │
│  • 修改家族宪章需2/3以上通过              │
└────────────────┬────────────────────────┘
                 │
┌────────────────┴────────────────────────┐
│          家族理事会（核心决策机构）        │
│  • 3-7名理事（企业家+主要家族成员+外部专家）│
│  • 每季度1次，重大事项决策                │
│  • 选举/罢免家族理事                      │
└────────────────┬────────────────────────┘
                 │
┌────────────────┴────────────────────────┐
│         家族办公室（执行机构）             │
│   ┌──────────┬──────────┬──────────┐     │
│   │ 投资管理   │ 法务税务   │ 家族服务  │    │
│   │ • 资产配置  │ • 法律顾问 │ • 子女教育│    │
│   │ • 投资执行  │ • 税务筹划 │ • 健康管理│    │
│   │ • 风险管理  │ • 合规审查 │ • 公益活动│    │
│   └──────────┴──────────┴──────────┘     │
└──────────────────────────────────────────┘
```

### 4.2 家族宪章核心内容

**第一章：家族愿景与价值观**
- 家族使命宣言（家族精神的核心表述）
- 家族核心价值观（诚信/团结/进取/责任）
- 家族对企业的承诺与期待

**第二章：家族治理结构**
- 家族全体会议：组成、议事规则、决策权限
- 家族理事会：选举规则、任期、职责范围
- 家族办公室：定位、服务范围、费用承担

**第三章：股权管理规则**
- 股权持有资格（仅限家族成员，或可转让至外部？）
- 股权转让限制与优先购买权
- 股权质押限制
- 股权分红政策（每年的最低/最高分配比例）
- 未参与经营的家族成员的退出机制

**第四章：家族成员参与企业管理规则**
- 家族成员入职企业的条件（学历/工作经验/外部任职年限要求）
- 家族成员的晋升规则（不比外部管理者优惠）
- 家族成员的薪酬标准（参照市场水平、不高于行业标准）
- 家族成员退出管理层的条件与程序

**第五章：家族财富管理**
- 财富管理理念（保值/增值/分配/传承的平衡）
- 信托架构设计原则
- 分配政策（受益人的权利与限制）
- 新代际成员的纳入规则

**第六章：家族纠纷解决机制**
- 协商优先原则
- 调解人制度（引入外部中立调解人）
- 仲裁条款（不轻易对簿公堂）
- 家族理事会最终裁决

**第七章：家族宪章修改与终止**
- 修改条件与通过比例（建议2/3以上）
- 终止条件
- 定期检视机制（每3-5年复盘更新）

### 4.3 家族办公室设立方案

| 阶段 | 服务内容 | 人员配置 | 运营成本 | 服务对象 |
|:-----|:---------|:---------|:---------|:---------|
| **第一阶段（1-2年）** | 财富管理+税务+法务基础服务 | 2-3人（可共享外部资源） | 50-100万/年 | 核心家族成员（5-10人） |
| **第二阶段（3-5年）** | 全面财富管理+投资+家族治理 | 5-8人 | 200-500万/年 | 全体家族成员（10-20人） |
| **第三阶段（5年后）** | 全面服务+教育+医疗+慈善+全球化 | 10-20人 | 500万+/年 | 多代家族成员（20-50人） |

## 五、企业传承实施路线图

```
启动（第0-3个月）
├── 成立家族传承项目组（律师+税务师+财务顾问+保险顾问）
├── 完成资产盘点与传承需求评估
├── 制定初步传承方案
└── 召开第一次家族会议（通报+征求意见）

设计（第3-6个月）
├── 确定传承架构（股权重组方案确认）
├── 起草家族宪章（草案）
├── 税务筹划方案确定
├── 保险/信托方案设计
├── 接班人培养计划制定
└── 召开第二次家族会议（讨论宪章草案）

实施（第6-12个月）
├── 股权架构变更（新公司章程/有限合伙/信托设立）
├── 家族宪章签署生效
├── 接班人培养计划启动
├── 保险购买/信托设立
├── 家族办公室筹备
└── 召开第三次家族会议（宪章签署+任命家族理事）

检视（每年）
├── 年度家族会议（企业汇报+家族事务）
├── 传承方案年度检视
├── 家族宪章执行情况审查
└── 调整接班人培养计划
```

---

**使用说明：** 本模板配合主SKILL「模式三：企业传承」使用。企业传承是家族财富传承中最复杂、最具有挑战性的模块，建议配合[[tax-compliance]]进行税务合规审查，并在股权变更前完成税务筹划方案的合规性论证。家族宪章虽然不是具有法律强制执行力的文件，但在家族内部治理中具有重要的指导和约束作用，建议与信托/股份协议等法律文件配套使用。
