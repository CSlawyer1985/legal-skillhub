# 法规与类案 CLI 检索式生成指南

适用于 `litigation-intake-assessment` skill。目标是将争议焦点、请求权基础、抗辩事由和案件关键信息稳定改写为 deli-cli 可执行的检索主题或事实摘要，而不是直接把原始案情整段塞进检索命令。

使用本指南前，必须先执行 [cli-common.md](./cli-common.md) 中的前置检查和命令发现步骤。

## 一、CLI 命令使用原则

1. 先用 `npx @delilegal/deli-cli@latest cmds litigation-intake-assessment@1.0.0` 获取本次 `RUN id`、命令名和参数。
2. 后续调用必须采用当次返回的 `npx @delilegal/deli-cli@latest run_... <command> [options]` 形态。
3. 不在本指南中固化真实命令名；以下示例中的 `law-search`、`case-search`、`similar-case`、`assessment-support` 仅表示可能的命令类型，实际以 `cmds` 输出为准。
4. 检索参数优先在 `cmds` 返回的 `usage` 和 `params` 中选择，不主动假设 `--query`、`--semantic`、`--long-text`、`--page`、`--size` 或筛选参数一定存在。
5. 每次调用都要记录检索目的、检索主题、争议焦点和 CLI 返回数量，便于写入报告“风险识别与裁判检索结论”部分。

示例 `cmds` 返回后，实际调用可能形如：

```bash
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 law-search --semantic "买卖合同中买方拒绝收货，双方就合同解除条件及违约责任发生争议，需要核验请求权基础、解除条件和违约责任规则"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 case-search --query "买卖合同 货物质量瑕疵 拒付货款 举证责任"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 similar-case --long-text "卖方已交货，买方以货物质量不合格为由拒付尾款，双方争议焦点为质量瑕疵举证责任、验收期限和违约责任承担"
```

以上仅为参数组织示例。正式执行时必须替换为当次 `cmds` 返回的 `run_...`、命令名和参数。

## 二、先判断检索对象与策略

- 规范适用争议更强时，优先检索法规、司法解释和规范性文件。
- 裁判倾向、举证责任、违约责任、损失认定、责任比例或本地法院口径更重要时，优先检索案例。
- 同一争议焦点可以分别检索法规和案例，但每次调用必须目的明确。
- 不把多个争议焦点混在同一检索式里；必要时拆成多个检索主题并向用户说明会产生多次调用。

## 三、法规检索式生成规则

### 1. 何时用短主题

出现下列信息时，可组织短主题：

- 明确提到法规名称
- 明确提到发文字号
- 能总结出稳定的规范关键词

写法：

- 优先保留法规全称或常用简称
- 能写发文字号时直接写入
- 再补 1 到 3 个核心问题词
- 避免口语化修饰和无关事实细节

示例：

```text
中华人民共和国民法典 买卖合同 合同解除
法释〔2020〕17号 格式条款
消费者权益保护法 七日无理由退货
```

### 2. 何时用语义问题

出现下列情况时，使用自然语言法律问题或事实摘要：

- 用户没有给出具体法规，但能概括成规范适用问题
- 需要围绕法律要件、责任分配或规则边界寻找依据
- 短主题结果过窄、过散或不贴合争议焦点

写法：

```text
<法律关系>中，因<关键事实>引发<核心争点>，需要核验<请求权基础/抗辩事由/责任规则>
```

示例：

```text
买卖合同中，买方以货物质量不合格为由拒绝支付尾款，需要核验质量异议期限、举证责任和违约责任规则。
```

## 四、案例检索式生成规则

### 1. 何时用短主题

出现下列信息时，可组织案例短主题：

- 明确提到案件名称
- 明确提到当事人信息
- 明确提到案号
- 能总结出稳定的案由或争议关键词

示例：

```text
房屋买卖合同纠纷 阴阳合同 违约金调整
竞业限制纠纷 经济补偿 违约金过高
民间借贷 利率超过四倍LPR
```

### 2. 何时用长文本事实摘要

出现下列情况时，使用长文本或事实摘要：

- 只有案情描述，没有明确案件标识
- 需要寻找事实结构相近、裁判思路接近的类案
- 短主题命中大量噪声
- 用户提供了完整案件材料

写法：

```text
<当事人关系>中，因<关键行为>引发<争议焦点>，造成<结果/后果>，需要判断<裁判倾向/举证责任/责任比例>
```

示例：

```text
卖方已交货，买方以货物质量不合格为由拒付尾款，双方争议焦点为质量瑕疵举证责任、验收期限和违约责任承担。
```

## 五、常见争议焦点模板

| 场景 | 法规检索主题 | 案例检索主题 |
| --- | --- | --- |
| 民间借贷 | 民间借贷 利率上限 逾期利息 | 民间借贷 利率上限 逾期利息 裁判规则 |
| 买卖合同 | 买卖合同 质量异议 解除 违约责任 | 买卖合同 质量瑕疵 拒付货款 举证责任 |
| 劳动争议 | 劳动合同解除 经济补偿 违法解除 | 违法解除 劳动合同 绩效不合格 举证责任 |
| 房屋买卖 | 房屋买卖合同 阴阳合同 合同效力 | 房屋买卖 阴阳合同 合同效力 违约金 |
| 公司股权 | 股权转让 瑕疵出资 股东责任 | 股权转让 瑕疵出资 解除合同 |

## 六、无结果或结果不足

单次检索无结果或结果明显失焦时：

1. 先说明本次检索不足，不自动连续换词重试。
2. 给出一个建议改写的检索主题或事实摘要。
3. 如确需从法规检索切换到案例检索，或从短主题切换到长文本，先说明理由。
4. 在最终报告中只引用有效命中的结果；若无法取得稳定依据，标注“检索受限”“类案不足”或“结论待核”。
