# NZISM——已验证的控制 ID

供答案引用的已验证控制标识符。格式：`章节.节.控制.C.nn`。来源：官方 NZISM（nzism.gcsb.govt.nz）章节结构，按 AWS Config NZISM 3.8 符合性包映射（控制名称已与手册的章节标题交叉核对）。**只引用本清单中的 ID；对未涵盖的主题，引用章节/节，并指导机构在在线手册中确认当前控制编号**——NZISM 大约每年更新两次（v3.9 将第 16 章更名为"认证与访问控制"，并新增了控制，如 16.1.25.C.01、16.1.27.C.02、16.1.31.C.01–03，涉及无密码和抗钓鱼多因素认证）。

## 答案中的使用

- **访问控制政策**：引用 16.1.46.C.02（访问暂停）、16.3.5.C.02（特权账户）、16.6.6.C.02/16.6.10.C.02（访问事件日志），以及第 16.1 章总体用于身份识别/认证/多因素认证要求（确认无密码/抗钓鱼多因素认证的当前 v3.9 控制编号）。
- **日志/监控要求**：16.6.6.C.02、16.6.10.C.02、16.6.12.C.01、16.6.13.C.01。
- **云/离岸托管**：22.1.23.C.01 加第 22.1 章总体；与 PSR 和云风险评估流程配合。
- **网络/边界**：18.4.x（IDS/IPS）、19.1.12.C.01、19.1.14.C.02。
