# DPIA 风险目录

对数据主体权利和自由的风险。源自 GDPR 序言第 75 段、EDPB 指南 WP 248 rev.01、EDPB DPIA 模板 v1.0（2026 年 3 月）、CNIL PIA 知识库、EDPB 意见 28/2024（AI）、EDPB 指南 3/2019（视频监控）、EDPB 指南 1/2020（联网车辆）以及执法实践。

使用本目录根据处理描述**主动提出风险**。选择相关风险——不要呈现整个目录。

**风险轨道：** 每条风险标记为 **A 轨道**（设计固有——处理按预期运作产生的风险）或 **B 轨道**（运营性——意外/非法/异常事件产生的风险）。方法论见 `scoring.md`。

## 处理特定风险画像

每个画像先列出 A 轨道（设计固有）风险，然后列出三个标准威胁向量的 B 轨道（运营性）场景。

### AI/ML 系统（EDPB 意见 28/2024）

**训练阶段（A 轨道）：** DISC-01（偏见）、DISC-02（代理歧视）、CONF-04（记忆）、PSEU-03（单独识别）、CTRL-03（抓取造成的功能蔓延）
**部署阶段（A 轨道）：** REPD-04（幻觉）、DISC-01（歧视性输出）、CTRL-01（不透明性）、CTRL-02（行使权利困难）、DENY-01（自动化决策）
**B 轨道——运营性：**
- 非法访问：训练数据外泄、模型窃取、对模型输出的未授权 API 访问
- 非预期修改：训练数据投毒、对抗性输入操纵、模型参数篡改
- 数据消失：训练数据集丢失、模型检查点损坏、推理日志删除

要点：匿名化挑战——声称训练数据"匿名"的控制者必须受到审查。如果能够单独识别，数据就是个人数据。

### 员工监控（DSK、UODO、CNIL 黑名单）
**A 轨道：** 电子邮件/互联网：CHIL-01、CTRL-01。数据防泄漏（DLP）：DISC-01（误报→纪律处分）、REPD-02。GPS/车队：CHIL-01、CTRL-03（非工作时间跟踪）。
**B 轨道——运营性：**
- 非法访问：主管访问个人电子邮件、DLP 日志泄露、GPS 数据被用于非工作目的
- 非预期修改：监控日志被篡改以掩盖不当行为、活动归属错误
- 数据消失：争议解决前监控记录丢失、事故调查前 GPS 日志被删除

### 视频监控/面部识别（EDPB 指南 3/2019）
**A 轨道：** 标准闭路电视：CHIL-01、CTRL-03、CHIL-02。面部识别：DISC-01（差异化准确性）、REPD-02（错误识别）、CHIL-01（大规模监视）。
**B 轨道——运营性：**
- 非法访问：未授权查看录像、生物特征模板数据库泄露、IDTH-04（生物特征窃取）
- 非预期修改：录像篡改、模板损坏、时间戳操纵
- 数据消失：保留政策失效销毁证据、存储故障丢失录像

### 联网车辆（EDPB 指南 1/2020）
**A 轨道：** 位置/远程信息：CHIL-01、CTRL-03、FINL-03（保险）。生物特征（瞌睡检测）：DISC-04、CHIL-01。驾驶行为：DISC-03、FINL-03、CONF-03。
**B 轨道——运营性：**
- 非法访问：未授权方远程跟踪车辆、远程信息数据被截获、PHYS-01（跟踪）
- 非预期修改：里程表/远程信息操纵、PHYS-03（安全关键系统被攻陷）
- 数据消失：事故后车辆数据丢失（证据销毁）、OTA 更新抹除诊断日志

关键缓解措施：边缘/本地处理。如果生物特征数据留在车内且从不传输，风险大幅降低（EDPB 建议）。

### 健康/基因数据
**A 轨道：** 健康数据仓库：PSEU-01、DISC-04、CTRL-01。基因检测：DISC-04（家庭隐私）、FINL-03。植入式设备：PHYS-04、CTRL-01。
**B 轨道——运营性：**
- 非法访问：CONF-01（违反职业保密）、患者记录暴露、影响家庭成员的基因数据泄露
- 非预期修改：临床系统中患者数据错误、诊断 AI 损坏、PHYS-04（数据不准确造成医疗伤害）
- 数据消失：患者记录丢失、基因检测结果损坏、紧急情况下植入数据不可用

### 金融/信贷处理
**A 轨道：** 信用评分：DISC-01、FINL-02、DENY-01、CTRL-01。共享黑名单：DENY-03、FINL-02、REPD-02。反洗钱/客户尽职调查：REPD-02、DENY-01。
**B 轨道——运营性：**
- 非法访问：FINL-01（未授权交易）、账户数据泄露、内部人员访问信用档案
- 非预期修改：信用评分损坏、虚假黑名单条目、反洗钱标记操纵
- 数据消失：交易记录丢失、审计轨迹缺口、保留期届满前客户尽职调查文件被销毁
