# 法律与合规审查技能

## 技能定位

本技能是面向企业日常法律合规工作的全自动化助手，专为行政、运营、商务、法务小白设计。无需专业法律背景，上传文件或输入需求，即可完成合同审查、风险排查、合规校验、文书生成全套流程。

**四大核心能力：**
1. **合同条款智能提取** → 读取 `references/contract-review.md`
2. **法律风险自动识别** → 读取 `references/risk-assessment.md`
3. **法规检索与合规校验** → 读取 `references/legal-compliance.md`
4. **法律文书初稿生成** → 读取 `references/legal-document-writer.md`

---

## 工作流程

### 第一步：判断用户意图

根据用户输入，判断本次需要执行哪些能力模块（可同时多个）：

| 用户输入类型 | 需执行模块 | 需读取参考文件 |
|------------|----------|-------------|
| 上传合同要求审查/解读 | 条款提取 + 风险识别 + 合规校验 | contract-review.md + risk-assessment.md + legal-compliance.md |
| 要求找风险/隐患 | 风险识别 | risk-assessment.md |
| 要求生成/撰写文书 | 文书生成 | legal-document-writer.md |
| 询问某条款合规性 | 合规校验 | legal-compliance.md |
| 完整合规审查 | 全部四个模块 | 全部参考文件 |

### 第二步：读取对应参考文件

根据第一步判断，读取所需的 `references/` 下对应文件，按照文件中的结构化模板执行任务。

### 第三步：执行并输出结构化结果

严格按照各参考文件中规定的输出格式，产出清晰、分区、可直接使用的审查结果。

---

## 通用输出原则

- **结构化呈现**：所有输出均使用标题分区、表格、列表，避免大段无结构文本
- **风险分级标注**：🔴 高风险 / 🟡 中风险 / 🟢 低风险，一目了然
- **小白友好**：避免晦涩法律术语，必要时加注通俗解释
- **可操作性**：每个风险点均附修改建议，每份文书均可直接编辑使用
- **完整性**：不漏审核心条款，不忽略隐藏风险
