# 法律文书智能撰写指南

## 一、支持的文书类型

| 文书类型 | 适用场景 | 生成要素 |
|---------|---------|---------|
| 合作协议 | 商务合作、项目合作、战略合作 | 合作内容、权利义务、分成比例、期限 |
| 服务合同 | 技术服务、咨询服务、外包服务 | 服务范围、交付物、付款方式 |
| 采购合同 | 产品采购、物资采购 | 产品规格、数量、质量标准、价格 |
| 保密协议（NDA） | 商务谈判前、员工入职 | 保密范围、期限、违约责任 |
| 告知函 | 违约通知、催款、权利保留 | 事实陈述、法律依据、要求事项 |
| 声明书 | 权利声明、情况说明、自愿声明 | 声明主体、声明事项、法律效力 |
| 授权委托书 | 代理诉讼、代理签约、业务授权 | 委托人、受托人、授权范围、期限 |
| 申请书 | 行政申请、内部申请 | 申请人、申请事项、理由依据 |
| 劳动合同补充协议 | 保密、竞业、绩效调整 | 补充事项、原合同关联 |
| 终止/解除协议 | 合同终止、合作结束 | 终止原因、结算方式、权利义务了结 |

---

## 二、文书生成前信息收集

在生成任何文书前，先向用户确认以下信息（未提供的项目可使用【待填写】占位）：

### 必须确认的信息
1. **文书类型**：需要哪种类型文书？
2. **甲方信息**：全称、联系人
3. **乙方信息**：全称、联系人
4. **核心业务内容**：合作/服务的具体事项
5. **金额**：合同金额或费用标准（如有）
6. **期限**：有效期或服务周期

### 可选但建议确认的信息
- 所在行业/细分领域（用于精准匹配模板）
- 特殊需求（如特定条款要求、排他性等）
- 争议解决偏好（诉讼城市或仲裁机构）

### 模板A：商务合作协议

```markdown
商务合作协议

协议编号：[编号]
签署地点：[地点]
签署日期：[年] 月 [日]

甲方：[全称]
地址：[注册地址]
统一社会信用代码：[代码]
法定代表人：[姓名]
联系人：[姓名]  联系方式：[电话/邮箱]

乙方：[全称]
地址：[注册地址]
统一社会信用代码：[代码]
法定代表人：[姓名]
联系人：[姓名]  联系方式：[电话/邮箱]

甲乙双方经友好协商，就[合作事项]达成如下协议：

第一条  合作内容
1.1 乙方向甲方提供[具体服务/产品描述]，具体服务内容及交付标准详见附件一。
1.2 乙方应于[时间节点]前完成[具体交付物]。

第二条  合作期限
2.1 本协议有效期自[开始日期]至[结束日期]，共计[X]个月。
2.2 协议期满前[30]日，任一方如不续约，应书面通知对方；否则协议自动续期[1]年，续期次数不超过[X]次。

第三条  费用与付款
3.1 甲方按照以下安排向乙方支付费用：
    - 合同总金额：人民币[金额]元（大写：[大写金额]整）
    - 首付款：合同签署后[X]个工作日内支付合同总额[X]%，即人民币[金额]元
    - 里程碑付款：[具体里程碑事件]完成并验收合格后[X]个工作日内支付[X]%
    - 尾款：[交付物]验收合格后[X]个工作日内支付剩余[X]%
3.2 乙方应于每笔款项到账后[X]个工作日内向甲方开具相应金额的增值税[普通/专用]发票，税率[X]%。

第四条  甲方权利与义务
4.1 甲方有权对乙方的服务质量进行监督和检查。
4.2 甲方应按本协议约定的时间和方式支付费用。
4.3 甲方应为乙方履行本协议提供必要的配合和支持，包括：[具体配合事项]。

第五条  乙方权利与义务
5.1 乙方应按本协议约定的标准、时限完成服务/交付产品。
5.2 乙方应保证服务/产品质量符合[标准/规范]要求。
5.3 乙方不得将本协议项下的工作全部或主要部分转包给第三方，确有必要分包的，须事先取得甲方书面同意。

第六条  验收
6.1 乙方完成交付后，应书面通知甲方进行验收。
6.2 甲方应在收到验收通知后[X]个工作日内完成验收，并出具验收报告。
6.3 验收不合格的，乙方应在[X]个工作日内整改并重新提交验收，整改次数不超过[X]次。

第七条  保密条款
7.1 双方在合作过程中获知的对方商业信息、技术信息、客户信息等均为保密信息。
7.2 双方应采取合理措施保护保密信息，未经对方书面同意不得向任何第三方披露。
7.3 保密义务自本协议签署之日起至协议终止后[2]年内持续有效。

第八条  知识产权
8.1 本协议签署前双方各自拥有的知识产权仍归各自所有。
8.2 乙方在履行本协议过程中形成的工作成果（含代码、设计、文档等）的知识产权归[甲方/乙方/双方共有]所有。

第九条  违约责任
9.1 任一方违反本协议约定，应向守约方支付违约金，金额为本协议总金额的[10]%。
9.2 违约金不足以弥补守约方实际损失的，违约方还应赔偿超出部分的损失。
9.3 甲方逾期付款超过[X]个工作日，每逾期一日按逾期金额的[0.05]%向乙方支付违约金。

第十条  不可抗力
10.1 不可抗力是指不能预见、不能避免且不能克服的客观情况，包括自然灾害、战争、政府法规政策的重大变化等。
10.2 因不可抗力导致一方无法履行本协议，受影响方应在[5]日内书面通知对方，并提供相关证明材料。
10.3 双方应协商确定协议的继续履行、变更或终止。

第十一条  协议的变更与终止
11.1 本协议的变更须经双方书面确认后方可生效，口头承诺不具有法律效力。
11.2 出现下列情形之一，任一方可书面通知对方提前终止本协议：
    （一）对方严重违约，经通知后[X]日内未纠正；
    （二）双方协商一致同意终止；
    （三）[其他约定情形]
11.3 协议提前终止的，已完成部分按实际工作量结算；因违约终止的，违约方还须承担第九条约定的违约责任。

第十二条  争议解决
12.1 本协议受中华人民共和国法律管辖。
12.2 双方发生争议，应首先友好协商；协商不成的，提交[甲方所在地/乙方所在地/双方约定地]有管辖权的人民法院诉讼解决。
  [或：协商不成的，提交[北京/上海/广州/深圳]仲裁委员会按其仲裁规则仲裁，仲裁裁决为终局裁决。]

第十三条  其他
13.1 本协议一式两份，甲乙双方各执一份，具有同等法律效力。
13.2 本协议附件为本协议不可分割的组成部分，具有同等法律效力。
13.3 本协议自双方法定代表人或授权代表签字并加盖公章之日起生效。

甲方（盖章）：_______________        乙方（盖章）：_______________
法定代表人/授权代表（签字）：___    法定代表人/授权代表（签字）：___
日期：___年___月___日               日期：___年___月___日
```

### 模板B：保密协议（NDA）

```markdown
保密协议

甲方：[全称]（以下简称"披露方"）
乙方：[全称]（以下简称"接收方"）

鉴于双方拟就[合作/谈判事项]进行合作洽谈，披露方将向接收方披露相关保密信息，双方就保密事宜达成如下协议：

第一条  保密信息的定义
本协议所称"保密信息"是指披露方向接收方披露的以下信息，无论以书面、口头、电子或其他形式：
（一）业务计划、财务数据、客户名单及相关信息；
（二）技术方案、产品设计、源代码、算法；
（三）经营策略、市场分析、合作谈判内容；
（四）被明确标注或告知为"保密"的其他信息。

以下信息不属于保密信息：
（一）接收方已合法持有且不承担保密义务的；
（二）已进入公开领域且并非因接收方违约所致的；
（三）接收方从合法第三方获得且不承担保密义务的。

第二条  保密义务
2.1 接收方应采取与保护自身同等机密信息不低于的合理措施保护保密信息。
2.2 接收方不得将保密信息用于本协议约定目的之外的任何用途。
2.3 接收方不得将保密信息向任何第三方披露，确因工作需要披露给内部人员的，应确保相关人员承担不低于本协议的保密义务。

第三条  保密期限
本协议自签署之日起生效，保密义务持续至协议终止后[2]年。

第四条  违约责任
接收方违反本协议，应赔偿披露方因此遭受的全部损失，并支付违约金人民币[金额]元。

第五条  其他
本协议一式两份，双方各执一份，自双方签字盖章之日起生效。

披露方：_______________（盖章）       接收方：_______________（盖章）
签署日期：___年___月___日            签署日期：___年___月___日
```

## 四、文书生成输出规范

生成文书时，必须遵循以下规范：

1. **完整性**：所有关键条款均需包含，不得遗漏重要约定
2. **占位符处理**：
   - 用户已提供的信息直接填入
   - 用户未提供的信息用【待填写：说明】标注
   - 典型示例：【待填写：合同金额，请确认实际金额后填入】
3. **使用提示**：文书末尾附上使用注意事项
4. **法律声明**：注明"本文书为AI辅助生成的初稿，建议实际签署前经专业律师审阅"

### 文书生成输出格式

```markdown
## 📄 [文书名称] 初稿
```
