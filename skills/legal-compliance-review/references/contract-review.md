# 合同关键条款智能提取指南

## 一、支持的输入格式

- PDF合同文件（文字版/扫描件）
- Word文档（.doc/.docx）
- 图片格式合同（JPG/PNG，需OCR识别）
- 用户直接粘贴的合同文本

## 二、提取流程

### 步骤1：合同基本信息识别

首先提取合同的基础元素：

```
合同名称：
合同编号：
签署日期：
生效日期：
合同金额：
合同有效期：
```

### 步骤2：甲乙双方信息提取

| 要素 | 甲方 | 乙方 |
|------|------|------|
| 主体名称 | | |
| 统一社会信用代码/身份证号 | | |
| 法定代表人/负责人 | | |
| 注册地址 | | |
| 联系方式 | | |
| 签署人姓名及职务 | | |

### 步骤3：核心条款逐项提取

按以下12大类条款逐一扫描并提取：

#### 1. 合作内容与范围
- 合作事项描述
- 服务/产品边界
- 交付标准与验收条件

#### 2. 合同金额与付款条款
- 总金额/单价
- 付款方式（一次性/分期/里程碑）
- 付款节点与时间
- 发票要求

#### 3. 合同期限
- 合同起止时间
- 项目完成时限
- 续约条件

#### 4. 违约责任
- 违约情形定义
- 违约赔偿标准（比例/金额）
- 违约通知程序

#### 5. 解除与终止条款
- 单方解除权条件
- 协议解除程序
- 解除后的结算方式

#### 6. 保密义务
- 保密信息范围定义
- 保密期限
- 违反保密的责任

#### 7. 知识产权归属
- 成果/作品的IP归属方
- 授权使用范围
- 背景IP的使用权

#### 8. 免责条款
- 免责事由
- 不可抗力范围定义
- 免责程序（通知义务等）

#### 9. 争议解决
- 解决方式（诉讼/仲裁）
- 管辖地/仲裁机构
- 适用法律

#### 10. 通知与送达
- 通知方式
- 联系地址
- 视为送达的条件

#### 11. 修改与变更
- 变更程序要求
- 变更生效条件

#### 12. 其他特殊条款
- 排他性/独家条款
- 竞业禁止条款
- 担保/抵押条款

## 四、特殊处理规则

1. **条款缺失**：如合同未包含某类核心条款，在对应位置标注"⚠️ 未见此条款，建议补充"
2. **条款模糊**：如条款表述不明确，在提取结果后加注"（表述模糊，详见风险识别）"
3. **矛盾条款**：如发现前后矛盾，标注"（与第X条存在矛盾，详见风险识别）"
4. **图片/扫描件**：先进行OCR文字识别，再按上述流程处理；如识别质量较差，告知用户可能存在误差

---

## 五、提取质量标准

- 不遗漏任何明确约定的金额数字
- 不遗漏任何时间节点（包括隐含的"X个工作日内"等）
- 准确区分权利（"可以"）与义务（"应当/必须"）
- 区分甲方责任与乙方责任，不混淆归属
