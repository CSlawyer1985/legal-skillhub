# legal-academic-research

📚 Hermes Agent 法学学术研究来源核验与规范写作 Skill

## 功能

- 🔍 **来源核验**：案例、法条、学术论文逐项核查，标注核验状态
- ⚖️ **结构化分析**：IRAC / CREAC / 七步分析流程 / 比较法分析
- 📝 **学术写作**：Bluebook 引用规范、中文法学写作格式
- ✅ **自动审校**：逻辑跳跃、概念混用、AI痕迹检测

## 安装

```bash
# 克隆到本地 Hermes skills 目录
git clone https://github.com/lawvinx/legal-academic-research.git ~/.hermes/skills/legal-academic-research
```

## 使用场景

| 场景 | 说明 |
|------|------|
| 法学院作业 | Case brief / IRAC essay / Exam answer |
| 学术论文 | 期刊论文 / 学位论文 / 文献综述 |
| 案例研究 | 个案分析 / 比较法研究 |
| 法律备忘录 | Office Memo / 争议分析 |

## 核心工作流

```
用户输入 → 问题识别 → 来源核验 → 法律分析 → 学术写作 → 自动审校
```
