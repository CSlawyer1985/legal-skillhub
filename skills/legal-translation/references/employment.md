# 雇佣／劳动词典

雇佣协议的标准英文术语：劳动合同、高管服务协议、限制性契约、离职协议、集体谈判协议、职工委员会文件、借调协议及相关工具。

## 核心雇佣术语

| 正确英文术语 | 用法／含义 | 避免使用 |
|---|---|---|
| employment contract / employment agreement | 在雇主与雇员之间创设法律关系的协议 | “employment arrangement”（非正式）；“service agreement”（历史术语） |
| permanent employment contract | 无固定终止日期的劳动合同；只能因故解除或经双方合意解除 | “indefinite contract”（不够精确）；“open-ended contract” |
| fixed-term employment contract | 有指定终止日期的劳动合同；除续签外到期自动终止 | “temporary contract”（可能暗示短期）；“time-limited contract” |
| part-time employment contract | 规定工时低于全职标准的劳动合同 | “part-time agreement”（不够正式） |
| consultancy agreement / contractor agreement | 聘用独立承包人提供特定服务、不产生雇佣关系的合同 | “independent contractor agreement”（更精确但冗长）；“service agreement”（有歧义） |
| project-based contract | 为特定项目或明确的交付成果聘用劳动者的合同 | “project contract”（非正式）；“task-based agreement” |
| letter of appointment / offer letter | 载明关键雇佣条款、薪水和开始日期的文件 | “employment offer”（不够正式）；“offer of employment” |
| non-compete agreement / non-competition covenant | 防止雇员在雇佣期间／之后与雇主竞争的限制性契约 | “non-compete clause”（不够正式）；“restrictive covenant”（更宽泛的类别） |
| non-solicitation agreement | 防止雇员招揽雇主客户或雇员的限制性契约 | “non-poaching agreement”（非正式） |
| confidentiality agreement | 保护雇主机密商业信息和商业秘密的协议 | “non-disclosure agreement” (NDA)（往往更宽泛）；“secrecy agreement”（非正式） |
| minimum term clause / lock-in clause | 要求雇员在最低期限内继续受雇或偿还培训费用的条款 | “lock-in provision”（非正式）；“minimum service period”（不够法律化） |
| probationary period / trial period | 初始雇佣期（通常 1-6 个月），期间任一方可无需通知终止 | “trial employment”（非正式）；“probation period” |
| mutual termination agreement | 雇主与雇员之间按指定条款终止雇佣的协议 | “severance agreement”（专指付款）；“termination settlement” |
| severance agreement | 以放弃索赔为对价，在终止时提供付款／福利的协议 | “settlement agreement”（英国术语，更精确）；“settlement arrangement”（非正式） |
| whistleblowing / protected disclosure | 雇员举报违法、违规或违反道德行为；受欧盟指令 2019/1937 及国家立法保护（英国：《1998 年公共利益披露法》） | Reporting violations（不够精确）；Informing（过于含糊） |
| settlement agreement | 英国雇佣法中的和解协议（2013 年后取代“compromise agreement”），以付款为对价解决争议／索赔 | “compromise agreement”（英国旧术语，2013 年前）；“settlement package”（非正式） |

## 报酬与福利

| 正确英文术语 | 用法／含义 | 避免使用 |
|---|---|---|
| remuneration / salary | 雇主为雇员完成的工作支付的全部报酬 | “pay”（非正式）；“compensation”（可能含福利） |
| gross annual salary | 扣除（税款、社保等）前的全部薪水 | “annual salary”（有歧义）；“base salary”（可能不含奖金） |
| net salary | 扣除一切法定和自愿扣减后的薪水 | “take-home pay”（非正式）；“actual salary” |
| payslip | 显示计薪期毛薪、扣减和净付款的单据 | “pay stub”（美国术语）；“salary statement”（不够正式） |
| thirteenth month's salary | 年末或假期向雇员支付的额外一个月薪水（欧洲做法） | “13th month bonus”（不够精确）；“year-end bonus”（概念不同） |
| fourteenth month's salary | 在第二个指定时间支付的额外一个月薪水（欧洲做法） | “14th month bonus”（不够精确） |
| severance indemnity / end-of-service allowance | 在整个雇佣期间累积、终止时支付的法定权利；存在于许多大陆法法域，计算方法各异 | “severance pay”（更窄）；“termination payment”（非正式） |
| severance pay | 终止／裁员时向雇员支付的款项（可能为法定或合同约定） | “termination payment”（不够正式）；“exit payment”（非正式） |
| payment in lieu of notice | 雇主向雇员支付代替实际通知期工作的款项 | “PILON”（英国缩写）；“notice payment”（不够精确） |
| severance package / ex gratia payment | 终止时超出法定权利的额外酌定付款 | “goodwill payment”（非正式）；“separation incentive” |
| supplementary allowance | 基础薪水之外的额外固定付款（行业特定） | “top-up”（非正式）；“supplementary pay”（不够正式） |
| performance bonus | 基于达成指定绩效目标的浮动付款 | “bonus”（有歧义）；“performance incentive” |
| MBO / management bonus | 将奖金与组织／个人目标挂钩的目标管理（Management by Objectives）制度 | “objectives-based bonus”（不够标准）；“goal-based bonus” |
| stock options | 在指定期限内按指定价格购买公司股份的权利 | “share options”（不够精确）；“equity options” |
| incentive plan | 为绩效提供现金／股权激励的结构化方案 | “incentive scheme”（不够正式）；“performance plan” |
| benefit / fringe benefit | 雇主提供的非现金报酬（保险、退休金、车辆等） | “perk”（非正式）；“indirect compensation”（不够精确） |
| company car | 雇主提供供公务和私人使用的车辆 | “company vehicle”（更宽泛）；“executive car”（更窄） |
| supplementary health insurance | 法定覆盖之外的健康保险，由雇主出资或共同分担 | “additional health coverage”（不够精确）；“top-up health insurance” |
| golden parachute | 因控制权变更或无因终止而触发的高管增强离职／报酬方案 | Golden handshake（不同——泛指离职金）；Executive severance（不够具体） |
| clawback | 雇主在特定事件发生时（不当行为、财务重述）追回已付奖金或激励报酬的合同或监管权利 | Recovery of bonus（不够标准）；Repayment clause（不够具体） |
| vesting / equity vesting | 雇员对股票期权或股权奖励的权利随时间变为无条件的进程（例如 4 年行权、1 年悬崖期） | Share vesting（可接受）；Option vesting（更窄） |
| supplementary pension fund | 强制国家计划之外的职业或个人养老金计划 | “private pension”（不够精确）；“additional pension” |
| social security contributions | 雇主／雇员向社保体系的强制缴费 | “social contributions”（不够精确）；“payroll taxes”（非正式） |
| employer contributions | 雇主强制性的社保／养老金缴费 | “employer taxes”（非正式）；“employer payroll contributions” |
| employee contributions | 雇员强制性的社保／养老金缴费（通常从薪水中扣除） | “employee taxes”（非正式）；“payroll deductions”（更宽泛） |

## 工作条件

| 正确英文术语 | 用法／含义 | 避免使用 |
|---|---|---|
| working hours | 雇员履行工作的时间；可能含标准工时和加班工时 | “work hours”（非正式）；“hours of work” |
| full-time hours | 每周标准工时（通常 35-40 小时；因法域而异） | “full hours”（非正式） |
| overtime | 超过标准工时的工作；通常按溢价费率支付 | “extra hours”（非正式）；“additional hours”（有歧义） |
| night work | 在指定夜间时段（通常 22:00-06:00 或类似）内的工作 | “night shift”（不够精确，可能指轮班模式）；“night-time work” |
| work on public holidays | 在法定公共假日的工作；可能按溢价支付或给予补休 | “holiday work”（有歧义）；“work on holidays” |
| annual leave / holiday entitlement | 用于休息和休闲的带薪假期；法定最低通常为每年 20-30 天 | “vacation”（美国术语）；“holiday”（英国术语，可能有歧义） |
| paid leave | 继续支付薪水的休假 | “paid time off (PTO)”（不够正式）；“paid absence” |
| maternity leave | 女性雇员分娩前后享有的带薪休假 | “pregnancy leave”（不够精确）；“maternity absence” |
| paternity leave | 男性雇员因子女出生享有的带薪休假 | “parental leave”（更宽泛）；“father's leave”（非正式） |
| parental leave | 雇员（父母任一方）照顾幼童的带薪／无薪休假 | “childcare leave”（不够精确）；“family leave”（更宽泛） |
| sick leave | 因疾病休假；可带薪至法定上限 | “illness leave”（不够精确）；“absence due to illness” |
| protected sick leave period | 雇员因病缺勤时雇主必须继续支付薪水的上限期间；因法域和集体协议而异 | “sickness period”（有歧义）；“illness protection period” |
| workplace accident / occupational injury | 雇员因工作或与工作有关的活动遭受的人身伤害 | “work-related injury”（更宽泛）；“occupational accident”（不够精确） |
| place of work | 雇员履行工作的地点（办公室、工厂、现场等） | “work location”（非正式）；“workplace”（更宽泛，含设施） |
| business travel / posting | 要求雇员在不同地点工作的临时派遣 | “business trip”（不够精确）；“work posting”（正式，但特指被派遣劳动者） |
| remote working / agile working | 使用电子通信在雇主场所之外的地点工作 | “work from home”（不够正式）；“flexible working”（可能含其他安排） |
| telework | 使用电信设备定期在家或远程地点工作 | “remote work”（更现代的术语）；“work from home”（不够正式） |
| duties / role | 分配给雇员的职责和任务 | “job duties”（非正式）；“functions”（不够精确） |
| classification / grading | 为薪酬／福利目的将雇员分配到组织层级／类别 | “job classification”（更宽泛）；“grade level” |
| contractual grade / pay grade | 依据集体协议分配给雇员的特定工资类别 | “pay level”（不够正式）；“salary level”（非正式） |
| job title / qualification | 雇员职位的正式名称和所需资格 | “position title”（不够正式）；“job description”（概念不同） |

## 限制性契约

| 正确英文术语 | 用法／含义 | 避免使用 |
|---|---|---|
| restrictive covenant | 限制雇员离职后行为的条款的通用类别 | “non-compete”（更窄，特定类型） |
| non-compete clause | 防止雇员在雇佣终止后与雇主竞争的契约 | “non-competition clause”（变体）；“restrictive covenant”（更宽泛的类别） |
| non-solicitation covenant | 防止雇员在终止后招揽雇主客户或雇员的契约 | “non-solicit clause”（非正式）；“non-poaching covenant” |
| non-dealing covenant | 防止雇员在终止后与雇主客户订立合同的契约 | “customer non-dealing clause”（不够标准）；勿与非招揽混淆 |
| garden leave | 雇主在通知期内要求雇员留在家中、同时维持薪水和福利的权利；实质是在通知期内执行竞业限制 | Gardening leave（变体，可接受）；Paid suspension（概念不同） |

## 终止术语

| 正确英文术语 | 用法／含义 | 避免使用 |
|---|---|---|
| dismissal / termination | 雇主终止雇佣 | “firing”（非正式）；“discharge”（过时） |
| dismissal for just cause / summary dismissal | 雇主因严重不当行为无需通知立即终止 | “dismissal for cause”（有歧义）；“termination for cause”（可能含其他理由） |
| dismissal for justified subjective reason | 雇主基于雇员个人行为终止雇佣；大陆法概念，法律后果与“just cause”不同 | “dismissal for gross misconduct”（更窄）；“disciplinary dismissal”（可能指正式程序） |
| dismissal for justified objective reason | 雇主基于经营需要／重组终止雇佣；大陆法概念，区别于普通法裁员 | “dismissal for redundancy”（更窄，后果不同）；“layoff”（非正式） |
| collective dismissal / redundancy | 因企业关闭／重组终止多名雇员 | “group termination”（不够法律化）；“mass layoff”（非正式） |
| disciplinary dismissal | 因雇员不当行为、经正式纪律程序后终止 | “dismissal for discipline”（不够正式）；“termination for cause”（有歧义） |
| resignation | 雇员终止雇佣；通常需要通知期 | “quitting”（非正式）；“giving notice”（更窄，描述发出通知的行为） |
| constructive dismissal / resignation for just cause | 因雇主严重违约而正当化的雇员辞职；可能使雇员有权获得离职金 | “constructive termination”（不够精确）；“forced resignation”（非正式） |
| notice period | 雇员／雇主在终止生效前必须等待的期间；因合同／法律而异 | “notice”（非正式）；“advance notice”（冗余） |
| challenge of dismissal / unfair dismissal claim | 雇员质疑解雇合法性／公正性的法律行动；救济因法域而异 | “wrongful termination claim”（美国术语，法律标准更窄）；“dismissal dispute” |
| reinstatement | 要求雇主恢复被解雇雇员原职位或同等职位的救济 | “reemployment”（不够精确）；“restoration” |
| compensatory indemnity / damages | 因不当／不公平解雇向雇员支付的款项 | “severance”（可能是合同约定）；“damages”（更宽泛的法律概念） |
| reinstatement remedy | 要求恢复被不当解雇雇员职位的救济；在某些大陆法法域可用 | “substantive protection”（不够精确）；“specific performance”（更宽泛） |
| compensation remedy | 对不公平解雇提供补偿而非复职的救济；在许多法域是复职的替代方案 | “financial protection”（非正式）；“damages award”（更宽泛） |
| change of control | 见 finance-banking.md 中的权威定义。雇佣语境：高管合同可能规定控制权变更时的加速行权、增强离职金或终止权。 | — |

## 集体劳动术语

| 正确英文术语 | 用法／含义 | 避免使用 |
|---|---|---|
| national collective bargaining agreement (NCBA) | 雇主协会／工会在国家层面谈判达成的总集体协议 | “national labour agreement”（非正式）；“sectoral agreement”（范围更窄） |
| company-level collective agreement | 雇主与工会／职工代表在公司层面谈判达成的集体协议 | “site agreement”（非正式）；“enterprise agreement” |
| trade union agreement | 雇主与工会在雇佣事项上达成的协议 | “union agreement”（非正式）；“collective agreement”（更宽泛的术语） |
| trade union | 代表劳动者利益与雇主谈判的正式组织 | “union”（非正式）；“labor union”（美国术语） |
| company trade union representation | 在公司层面代表劳动者利益的职工委员会等效机构；结构因法域而异 | “union representation”（不够精确）；“worker representatives”（更宽泛） |
| unified trade union representation | 公司层面多工会的劳动者代表结构；在大陆法法域常见 | “unified representation”（非正式）；“joint union representation” |
| workers' assembly | 雇员讨论集体事务的正式会议 | “employee assembly”（不够正式）；“staff meeting”（目的不同） |
| right to strike | 劳动者作为产业行动停止劳动的法律权利 | “strike right”（不够正式）；“strike protection” |
| wage supplementation fund / short-time working scheme | 雇主减少工时情况下提供部分收入的政府支持计划；许多欧盟法域有等效计划 | “unemployment insurance”（更窄）；“job protection scheme”（非正式） |
| ordinary wage supplementation | 针对暂时性经济困难的工资补充；通常期限更短、标准更宽松 | “regular benefit”（不够精确）；“ordinary support”（非正式） |
| extraordinary wage supplementation | 针对重大重组／危机的工资补充；期限更长、要求更严格 | “extended benefit”（非正式）；“crisis support” |
| redundancy scheme | 帮助因重组失业工人的政府计划；可能包括再培训、安置和收入支持 | “retraining program”（目的不同）；“displacement scheme”（不够标准） |
| transfer of undertakings / TUPE (UK) | 企业出售／转让时劳动合同的自动转移（欧盟指令 2001/23/EC；英国：《2006 年企业转让（雇佣保护）条例》） | Business transfer（不够精确）；Succession（更宽泛） |
| collective redundancy procedure | 终止多名雇员的法律程序；通常要求通知、协商、社会计划 | “layoff procedure”（非正式）；“mass dismissal process” |
| trade union consultation | 雇主就重大雇佣决定与工会／职工代表进行强制协商 | “union meeting”（非正式）；“worker consultation”（不够精确） |

## 借调与劳务派遣术语

| 正确英文术语 | 用法／含义 | 避免使用 |
|---|---|---|
| secondment | 雇员从原雇主临时派往接待公司工作；雇佣关系通常仍由原雇主保留 | “detachment”（大陆法直译）；“posting”（更窄，欧盟特定） |
| cross-border posting / transnational secondment | 雇员从一国被派往另一国工作（适用欧盟《派遣劳动者指令》） | “international posting”（不够精确）；“cross-border assignment” |
| seconding company | 与被派遣劳动者保留法定雇佣关系的雇主 | “home employer”（不够正式）；“original employer” |
| host company | 使用被派遣劳动者服务、但通常不是劳动合同当事人的雇主 | “receiving company”（不够正式）；“destination employer” |
| seconded employee / posted worker | 被派遣公司保留、同时临时为接待公司工作的雇员 | “seconded worker”（变体）；“posted worker”（欧盟术语，特定法律地位） |
| temporary agency work | 劳务派遣机构向客户雇主提供劳动者进行临时派遣 | “temp work”（非正式）；“temporary staffing” |
| temporary employment agency | 从事招聘并向客户雇主提供临时劳动者的企业 | “staffing agency”（不够正式）；“employment agency”（更宽泛） |
| agency worker / temporary worker | 劳务派遣机构在指定期限内提供给客户雇主的劳动者 | “temp”（非正式）；“temporary employee”（不够精确，可能指直接雇佣） |

## 说明

- **雇佣类别**：许多大陆法法域使用法定雇员分类（如高管、经理／主管、白领、蓝领），在解雇、通知、福利和合同待遇方面适用不同规则。在英／美语境下，按职能描述分类（高管、经理、专业人士、体力劳动者）。子词典提供源语言类别映射。

- **解雇理由**：大陆法法域常区分“正当理由”（因严重不当行为立即终止）与“正当原因”（因行为或经营原因通知后终止），各自法律后果不同。除非源文件确实对应普通法术语（“unfair dismissal”“wrongful termination”），不要将其强行套用于大陆法类别。保持源法域的法律框架。

- **限制性契约类别**：竞业限制、非招揽和非交易是三种不同的限制性契约。不要泛泛用“non-compete”覆盖三者。三者同时出现时分别设立条目。

- **Settlement agreement（英国）**／**“Compromise agreement”**：在英国雇佣法中，“settlement agreement”（2013 年 4 月后）取代了“compromise agreement”（2013 年 4 月前）。现行英文交易使用“settlement agreement”。

- **PILON**：“Payment in lieu of notice”是英国标准术语；其他法域可能使用“payment instead of notice”或类似表述。翻译时，在英国语境使用 PILON 并加说明。

- **Garden leave**：英国概念，允许雇主在通知期内让雇员不工作而维持薪水（限制性契约）。如源文件涉及此概念则包含；并非所有大陆法法域的标准。

- **TUPE／企业转让**：欧盟指令 2001/23/EC 规定企业出售时雇佣关系的自动转移。英国语境使用“transfer of undertakings”／“TUPE”；其他语境使用“business transfer”或“succession in business”。

- **Whistleblowing／受保护披露**：现代劳动法对举报违法、违规行为的雇员的保护。使用“whistleblowing”（非正式、现代）或“protected disclosure”（正式，英国《公共利益披露法》下的术语）。如源文件涉及此概念则包含。

- **全国性集体协议**：许多法域的劳动合同并入适用的全国或行业集体谈判协议。英文翻译中，首次出现保留原语言名称／缩写，但附加英文描述（例如“National Collective Bargaining Agreement for the [sector]”）。子词典提供源语言映射。

- **法域特定规则**：解雇理由、通知期、离职金和救济在不同法域差异显著。不要将源法域的法律类别强行套用于英／美法律。准确翻译并在子词典中注明源法域。

- **法定离职补偿**：某些大陆法法域有独特的法定离职权利，在整个雇佣期间累积，无论终止原因一律支付。这在普通法中没有完全对应的概念。译为“severance indemnity”或“end-of-service allowance”，并在首次使用时以括号保留源语言缩写。子词典提供源语言映射。
