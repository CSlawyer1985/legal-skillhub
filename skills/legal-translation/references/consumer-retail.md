# 消费者/零售词典

面向消费者的商业协议的标准英语术语：条款和条件、特许经营协议、分销协议、供应协议、代理协议、产品责任、消费者保证及相关文书。

## 核心消费者/零售术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| general terms and conditions of sale | 管辖商品零售的标准商业条件 | "conditions of sale"（过于含糊） |
| general terms and conditions | 适用于多种合同类型的宽泛合同条件 | 不带"terms"的"general conditions" |
| franchise agreement | 授予特许经营人依特许人品牌/体系经营权利的法律安排 | "franchise contract"（不够精确） |
| distribution agreement | 向最终客户或下游分销商持续供应和分销商品的合同 | "distribution contract"（非正式） |
| supply agreement | 定期或连续供应商品的框架合同 | "supply contract"（不够精确） |
| agency agreement | 依 EU 指令 86/653/EEC 委任商业代理人的合同 | "sales agency"；"representation agreement"（法律上不等价） |
| framework supply agreement | 约定按约定条款持续定期供应商品的合同；区别于单次供应合同 | "supply contract"（不够精确）；"periodic supply"（过于含糊） |
| purchase order | 载明数量、价格和交付条件的书面购货请求 | "order"（过于含糊） |
| order confirmation | 卖方对购货订单的书面接受和确认 | "order acceptance"（不够精确） |
| price list | 载明商品/服务标准售价的文件 | "price schedule"（通常有时限） |
| discount | 低于标准价目表价格的降价 | "rebate"（通常按数量计算且事后支付） |
| retail price | 商品出售给最终消费者的价格 | "consumer price"（不够精确）；"consumer price index"（不同概念） |
| wholesale price | 商品出售给分销商/零售商转售的价格 | "trade price"（不精确） |
| commercial margin | 采购价与销售价之间的利润空间 | "mark-up"（计算方式不同） |
| mark-up | 在成本价之上加算以确定售价的金额 | "margin"（包含其他成本） |
| exclusivity / exclusive right | 在指定区域或客户细分中的独家分销/销售权利 | "exclusive privilege"（过时） |
| territory | 分销/销售权利适用的地理区域 | "zone"（非正式） |
| territorial exclusivity | 在指定地理区域内独家分销/销售的权利 | "geographic exclusivity"（不够标准） |
| sales channel | 商品分销至消费者的途径（直销、零售、线上等） | "distribution route"（不够精确） |
| point of sale / retail outlet | 直接向消费者出售商品的实体场所 | "sales point"（非正式） |
| online sales / e-commerce | 通过互联网向消费者或企业销售商品 | "internet sales"（过于宽泛）；"online trade" |
| online marketplace / marketplace | 使多个第三方卖家能够向买家提供商品或服务的电子平台。"Online marketplace"是欧盟法律用语（如 (EU) 2019/2161 号指令、《数字服务法》）；数字语境已经明确时可单独使用"marketplace"。 | physical marketplace（不同——实体市场）；e-commerce platform（更窄——自营库存平台不是市场） |

## 特许经营特定术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| franchisor | 授予特许经营人经营商业格式权利的个人或实体 | "franchise grantor"（不够标准） |
| franchisee | 被授予经营特许经营业务权利的个人或实体 | "franchise holder"（非正式） |
| initial franchise fee / entry fee | 特许经营人向特许人支付的特许经营权一次性前置费用 | "franchise fee"（有歧义）；"setup fee" |
| royalty | 特许经营人向特许人持续定期支付的费用，通常按销售额计算 | "license fee"（不够精确）；"franchise contribution" |
| advertising fee / marketing contribution | 特许经营人为特许人集体广告/营销支付的费用 | "marketing fee"（不够精确） |
| operations manual | 载明特许经营操作程序、标准和指示的文件 | "operations handbook"；"operations guide" |
| know-how | 转让给特许经营人的商业经验、方法和技术信息 | "expertise"（法律性较弱）；"technical knowledge" |
| trade mark / brand | 识别特许人业务的注册或未注册商标；许可给特许经营人 | "brand name"（非正式）；"trading name" |
| business format | 特许经营业务运作所依据的完整体系、方法和品牌 | "franchise system"（不够精确） |
| quality standards | 对产品/服务质量、呈现和客户服务的要求 | "quality control"（描述过程而非标准） |
| centralised procurement | 特许经营体系为规模化采购商品的集中采购安排 | "central buying"（非正式） |
| pre-opening | 正式开业前特许经营人准备场所并接受培训的期间 | "pre-launch"（不够精确） |
| right of first refusal | 特许人或特许经营人在第三方之前购买资产/权利的权利 | "pre-emption right"（英式术语，法律上等价） |
| non-compete clause / non-competition clause | 限制一方在合同期间和/或之后竞争的权利条款。英式和美式起草中"non-compete"和"non-competition"均可接受；"non-compete"是较短的现代形式。 | restrictive covenant（更宽泛的概念——涵盖禁止招揽、禁止挖角、保密） |
| change of control | 标准定义见 finance-banking.md。特许经营/分销语境：通常需要特许人/供应商同意，可能触发解除权。 | — |

## 分销与供应术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| distributor | 从供应商采购商品并转售给零售商或其他分销商的实体 | "distribution company"（不够精确） |
| commercial agent | 代表委托人协商买卖的独立中介（EU 指令 86/653/EEC） | "sales agent"；"representative"（欧盟法下不等价） |
| representative | 代表他人行事的人（通用术语；可包括雇员） | 不指明类型的"agent"（有歧义） |
| dealer / concessionaire | 被授予在指定区域销售特定品牌/产品独家权利的实体 | "dealership"（非正式）；"distributor"（更宽泛） |
| wholesaler | 批量采购商品转售给零售商的实体 | "wholesale distributor"（赘余） |
| retailer | 直接向最终消费者销售商品的实体 | "retail outlet"（描述场所而非实体） |
| distribution chain / supply chain | 从制造商到最终消费者的一系列实体 | "chain of distribution"（不够标准） |
| product / goods | 受销售、供应或分销约束的有形物品 | "merchandise"（非正式）；"commodities"（通常指原材料） |
| goods | 受合同约束的有形动产 | "products"（法律语境中不够精确）；"merchandise"（非正式） |
| sample | 为展示质量/性质提供的商品样品 | "trial unit"（不够精确） |
| catalogue | 列明可售产品及描述/价格（印刷或数字）的文件 | "catalog"（美式拼写）；"product list"（不够正式） |
| stock / inventory | 为销售或分销存放在仓库或存储设施中的商品 | "supplies"（不够精确） |
| minimum order quantity (MOQ) | 买方单笔订单必须购买的最低商品数量 | "minimum purchase"（不够精确） |
| minimum order | 构成有效购货订单的最低商品数量 | "minimum purchase order quantity"（赘余） |
| lead time / delivery time | 下单与收货之间的期间 | "delivery period"（不够精确）；"supply time" |
| shipment | 单笔订单下从供应商运至买方的货物 | "delivery"（更宽泛）；"consignment"（特定类型的安排） |
| delivery terms / Incoterms | 明确运输期间哪一方承担费用和风险的条款（ICC Incoterms 标准） | "shipping terms"（不够精确）；"terms of delivery" |
| EXW (ex works) | 国际贸易术语：买方在卖方场所接收货物；买方承担全部运输风险/费用 | "ex factory"（不够标准的缩略语） |
| DAP (delivered at place) | 国际贸易术语：卖方承担费用/风险直至货物交付至指定地点；买方安排卸货 | "delivered at point"（不精确）；"delivery at place" |
| freight collect | 国际贸易术语变体：买方支付运输费用（DDU——未完税交货） | "carriage forward"（英式术语，不够精确） |
| freight prepaid / carriage paid | 国际贸易术语：卖方支付运输费用；买方承担运输途中风险 | "postage paid"（非正式） |
| lack of conformity / non-conformity | 商品不符合合同规格或质量标准（《消费者销售指令》2019/771/EU） | "defective goods"（不够精确）；"deviation from contract" |
| defect | 商品中降低价值或可用性的物理或功能瑕疵 | "fault"（非正式）；"imperfection"（技术性较弱） |
| latent defect | 销售时经合理检查无法发现的隐蔽缺陷 | "hidden defect"（法律性较弱）；"concealed fault" |
| apparent defect | 销售时可见且经合理检查可发现的缺陷 | "obvious defect"（不够精确）；"patent defect"（较少见） |
| selective distribution | 供应商基于定性标准（如专业员工、场所标准）选择分销商的分销体系；受欧盟竞争规则（《纵向协议集体豁免条例》）约束 | Restricted distribution（不够精确） |
| minimum annual purchase obligation / minimum purchase commitment | 分销商每年采购最低数量/金额商品的义务；未履行可能触发解除 | Annual quota（非正式）；Minimum volume（不够精确） |
| goodwill indemnity / compensation on termination | 终止时就为委托人带来的商誉/客户向商业代理人支付的法定补偿（EU 指令 86/653/EEC 第 17 条）；代理人可选择赔偿或补偿模式 | Termination indemnity（不够精确）；Agency compensation（过于含糊） |
| notice of defects | 买方在法定期限内就不合格商品向卖方发出的正式通知 | "defect notification"（不够正式）；"notice of non-conformity" |

## 消费者保护术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| consumer | 为贸易、商业或职业以外目的行事的自然人（EU《消费者权利指令》2011/83/EU） | "customer"（包括企业）；"buyer"（过于宽泛） |
| trader / professional | 以商业/专业身份行事的自然人或法人 | "supplier"（不够精确）；"seller"（非正式） |
| unfair term | 违反诚信、在当事人权利中造成重大不平衡的合同条款（《不公平合同条款指令》93/13/EEC） | "unfair clause"（不够精确）；"unreasonable term"（不同标准） |
| unfair terms / abusive clauses | 符合不公平条款定义的多个合同条款 | "onerous clauses"（不同概念）；"burdensome terms"（主观） |
| right of withdrawal / cooling-off right | 消费者在法定期限内无惩罚地解除远程/场外合同的权利（EU《消费者权利指令》2011/83/EU） | "right of cancellation"（不够标准）；"rescission right"（不同概念） |
| cooling-off period | 消费者可行使撤回权的法定期限（通常为 14 天） | "reflection period"（不够精确）；"cancellation period"（不够标准） |
| statutory guarantee of conformity | 卖方对商品符合合同且适合用途的法定义务（《消费者销售指令》2019/771/EU） | "warranty of title"（不同概念）；"merchantability guarantee"（不够精确） |
| commercial warranty | 经营者超出法定保证范围对商品作出的自愿承诺 | "manufacturer's warranty"（常常两者兼有）；"express warranty"（更宽泛） |
| product liability | 制造商/供应商对有缺陷产品造成伤害/损害的法律责任 | "product defect liability"（赘余） |
| defective product | 因制造/设计/说明缺陷造成伤害或损害的产品 | "faulty product"（非正式） |
| product recall | 制造商/销售商将有缺陷产品撤出流通并提供补救的程序 | "product withdrawal"（不同的法律程序）；"market recall"（不够精确） |
| safety notice | 关于产品安全危害和推荐消费者行动的公开通知 | "product safety alert"（不够正式）；"recall notice" |
| unfair commercial practices | 违反诚实/公平交易标准、实质扭曲消费者行为的商业行为（《不正当商业行为指令》2005/29/EC） | "misleading practices"（更窄）；"unfair competition"（不同概念） |
| misleading advertising | 载有影响消费者购买决定的虚假/欺骗性信息的商业传播 | "deceptive advertising"（不够精确）；"false claims"（非正式） |
| distance selling | 买方和卖方在没有同时物理在场的情况下订立合同的销售 | "distance sale"（非正式）；"remote sale" |
| distance contract | 经营者与消费者使用远程通信手段（电子邮件、电话、网站等）订立的合同 | "distance agreement"（消费者语境中不够标准） |
| off-premises contract | 在经营者营业场所之外（家中、街头等）订立的合同（EU《消费者权利指令》2011/83/EU） | "out-of-store contract"（不够标准）；"doorstep sale"（非正式） |
| pre-contractual information | 消费者在承诺远程/场外合同前必须收到的信息（合同条款、经营者身份、撤回权等） | "pre-contract disclosure"（不够精确）；"pre-sale information" |
| withdrawal form | 使消费者能够行使撤回权的标准表格（EU《消费者权利指令》2011/83/EU） | "cancellation form"（不够标准）；"notice of withdrawal"（可为其他格式） |
| refund | 消费者对已取消或未供应商品/服务支付款项的退还 | "reimbursement"（正式）；"money back"（非正式） |
| replacement | 以符合合同的商品替代不符合合同的商品提供给消费者 | "substitute goods"（不够精确） |
| repair | 将有缺陷/不符合合同商品恢复至符合合同状态 | "fixing"（非正式）；"restoration"（更宽泛的概念） |
| warranty / guarantee | 卖方/制造商对商品符合特定标准/性能的承诺 | "assurance"（法律性较弱） |
| merchantability / satisfactory quality | 商品质量适合正常使用的法定保证（英国《消费者权利法 2015》；satisfactory quality 是英国术语） | "fitness for purpose"（不同概念）；"acceptable quality"（不够精确） |
| fitness for purpose | 卖方对商品适合告知卖方的特定用途的保证 | "suitability"（非正式）；"appropriateness"（法律性较弱） |
| consumer rights | 消费者的法定权利（撤回、保证、救济、安全等） | "consumer protections"（不够精确）；"consumer remedies"（更窄） |
| unfair contract terms | 在实质或谈判上不公平地使经营者优于消费者的合同条款（《不公平合同条款指令》93/13/EEC） | "unreasonable terms"（不同测试）；"oppressive terms"（不够精确） |

| TERRITORY AND EXCLUSIVITY | "Territorial scope and exclusion"（不精确） |

| DELIVERY AND TRANSPORT | "Delivery and shipping"（不够正式）；"Transport of goods" |
| WARRANTY AND LIABILITY | "Warranties and remedies"（不同概念）；"Guarantees and responsibility"（非正式） |
| INTELLECTUAL PROPERTY | "IP rights"；"Intellectual property rights"（含义相同，标题较少见） |
| NON-COMPETE | "Non-competition"；"Competitive restrictions"（不够标准） |
| TERM AND TERMINATION | "Contract duration and ending"（非正式）；"Duration and dissolution" |
| EXPRESS TERMINATION CLAUSE | "Termination for convenience"；"Automatic termination clause"（不同概念） |
| UNFAIR TERMS | "Unfair contract terms"（同一概念） |
| PRODUCT SAFETY AND RECALL | "Safety and withdrawal"；"Product defects"（更窄） |
| CONSUMER REMEDIES | "Consumer rights and remedies"；"Available remedies"（不够具体） |

## 注释

- **"商业代理人"与其他角色**：依 EU 指令 86/653/EEC，"commercial agent"具有区别于代表、分销商或雇员的具体法律地位。精确使用以保留关于通知期、佣金和法定义务的法律后果。

- **不公平合同条款（指令 93/13/EEC）**：按实质和谈判评估：造成重大不平衡、违反诚信的条款。不要译为"onerous"或"burdensome"，这些是主观的。远程销售参考 EU《消费者权利指令》2011/83/EU。

- **消费者定义（指令 2011/83/EU）**：消费者是为贸易/商业/职业以外目的行事的自然人。B2B 交易，即使是与小企业，除非特别约定，不属于消费者保护范围。翻译中维持这一区分。

- **Incoterms**：保留国际商会 Incoterms 缩略语（EXW、FCA、DAP、DDP 等）的英文——它们是国际标准化的。首次出现时附完整英文名称："EXW (ex works)"。

- **法定保证与商业保证（指令 2019/771/EU）**：法定符合性保证是强制性的；商业保证是经营者的自愿承诺。两者均可适用；不要混同。

- **"Satisfactory quality"（英）与"merchantability"**：英国《消费者权利法 2015》使用"satisfactory quality"；较老的判例法和美国法使用"merchantability"。英国语境偏好"satisfactory quality"。

- **产品召回**：区别于自愿市场撤出的正式程序。强制移除或严重安全危害使用"product recall"；自愿或自愿合规情形使用"withdrawal"。

- **远程/场外合同区分**：远程合同＝无同时在场情况下订立协议（线上、电话、邮件）。场外＝在营业场所之外订立（家中、街头）。两者都触发冷静期；不要混同。

- **国际指令**：以英文名称和编号引用欧盟指令（《不公平合同条款指令》93/13/EEC；《消费者权利指令》2011/83/EU；《消费者销售指令》2019/771/EU），而非逐字翻译国内立法援引。
