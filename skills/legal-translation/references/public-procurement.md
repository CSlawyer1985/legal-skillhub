# 公共采购词典

公共采购的标准中文术语：招标、特许经营、PPP/PFI、国家援助、欧盟采购指令、公共合同及相关文书。

## 采购核心术语

| 正确英文术语 | 用法/含义 | 避免 |
|---|---|---|
| public contract / public procurement | 采购当局为买方的所有合同的总称。 | procurement（过于模糊） |
| works contract | 为执行施工作业提供劳务和材料的合同。 | construction contract（不够精确） |
| service contract | 提供服务的合同。 | services agreement（不够精确） |
| supply contract | 提供货物的合同。 | goods contract（不够精确） |
| concession | 将运营风险转移给特许经营者的协议；区别于购买合同。 | award agreement（过于模糊） |
| works concession | 建筑和/或运营工程基础设施的特许经营。 | — |
| service concession | 提供服务供应和运营的特许经营。 | — |
| public-private partnership (PPP) | 公共机关与私人实体之间提供服务的结构化安排。英国：PFI（私人融资计划）。 | partnership（不够精确） |
| project finance / PFI | 大型项目（尤其是 PPP）的融资结构。 | — |
| contracting authority | 负责委托公共合同的公共实体。 | purchasing authority（不够精确） |
| contracting entity | 受《公用事业指令》约束的公用事业或其他实体。 | contracting body（不够精确） |
| economic operator | 在招标中提供货物或服务的任何自然人或法人。 | market participant（不够精确） |
| tenderer / bidder | 应招标提交报价的当事方。 | offeror（在采购语境中不够精确） |
| successful tenderer / contractor | 获授合同的当事方。 | awardee（采购语境外含混） |
| subcontractor | 由主承包商承包以提供部分工程/服务的当事方。 | subcontracted party（不够精确） |
| temporary grouping / joint venture / consortium | 为参与招标而组成的经营主体联合。 | partnership（不够精确） |
| reliance on third-party resources | 经营主体依赖另一实体的技术、财务或专业能力（欧盟采购概念）。 | outsourcing capacity（不够精确） |
| permanent consortium | 经营主体的长期联合；区别于临时联合。 | persistent partnership（含混） |
| social value / social considerations | 作为授标标准或合同条件一部分的社会成果要求（就业、培训、环境可持续性） | Social impact（不够精确） |
| reserved contract | 为庇护工场、社会企业或雇用弱势群体的经营主体保留的合同（欧盟 2014/24/EU 指令第 20 条） | Protected contract（不够标准） |

| technical offer / technical proposal | 投标中的技术和质量部分。 | technical submission（不够精确） |

| award criterion | 选定中标投标的基础。 | selection basis（不够精确） |

| lowest price | 选择成本最低投标的授标标准。 | minimum cost（不够精确） |

| Teckal exemption / in-house exception | 允许采购当局不经招标将合同授予其控制的实体的例外（须满足所有权 + 活动测试）；欧盟法院概念 | in-house award；direct award（不够精确） |

| lot | 合同中可以单独招标和授予的独立部分 | Part；Section（过于模糊） |
| variant / alternative bid | 提供与规定技术方案不同的替代投标；须经采购当局明示允许 | Alternative offer（不够精确） |
| e-procurement / electronic procurement | 采购程序强制使用电子手段（提交、通信、发布）；自 2018 年起欧盟全境强制 | Online procurement（非正式） |

## 说明

- **欧盟 vs 国内采购**：三项指令（2014/24、2014/25、2014/23/EU）为整个欧盟的采购规则设定下限。各国法典往往规定更严格的要求或额外程序。始终识别管辖该交易的框架。

- **合同 vs 特许经营**：公共合同将货物/服务转移给当局；特许经营将运营和/或财务风险转移给特许经营者。这一区分在所有欧盟采购框架中都是根本性的。

- **MEAT 与授标标准**：从"最低价"转向"最具经济优势投标"反映了现代采购对质量、可持续性和创新的偏好。始终澄清适用哪个标准。

- **停顿期（Alcatel 期）**：授标公告后的强制性 10 天等待期是关键的程序保障。未遵守可能使授予无效。

- **框架协议与动态采购系统**：这些是现代欧盟采购工具，可提供灵活性和资金价值，尤其适用于标准货物和服务的重复采购。

- **ESPD**：取代多种国家表格；大幅标准化了欧盟各地的资格证据，尽管国家解释可能不同。

- **国家援助 vs 公共采购**：公共采购规则规范当局**如何**购买；国家援助规则规范支持**是否**符合市场。两者可能同时适用。
