# 知识产权、技术与 IT 词汇表

知识产权与信息技术协议的标准英语术语。第 1 部分涵盖专利、商标、版权、外观设计、商业秘密、许可与技术转让。第 2 部分涵盖软件许可、SaaS、云服务、数据处理、开发协议及相关 IT 文书。

---

## 第 1 部分——知识产权与技术

## 核心知识产权术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| intellectual property (IP) | 涵盖所有知识产权权利的通用术语 | Property rights only；Industrial property（较窄） |
| intellectual property right (IPR) | 单项知识产权权利（专利、商标、版权） | Industrial property only |
| patent | 就发明授予的权利；20 年后届满 | Patent application（用独立术语） |
| patent application | 授予前的待审申请；启动程序 | Filed patent（含糊） |
| granted patent | 已获批准并有效的专利 | Issued patent（较不正式） |
| patent holder / patentee | 拥有专利之人或实体 | Patent owner（较不精确） |
| claim (patent) | 专利说明书中的单项主张 | Claim language |
| patent specification | 向专利局提交的完整技术文件 | Patent document（过于笼统） |
| priority | 主张以在先申请为申请日的权利 | Filing precedence |
| priority date | 最早申请的日期（主张优先权之依据） | First filing date（可能歧义） |
| filing date | 专利申请提交专利局的日期 | Submission date |
| patent term | 专利保护期限（通常自申请日起 20 年） | Patent duration；Patent life |
| European patent | 欧洲专利局（EPO）授予的专利；覆盖多个地区 | EU patent（不精确） |
| Unitary Patent | 以集中化保护覆盖所有参与欧盟国家的单一专利 | Unified European patent |
| supplementary protection certificate (SPC) | 针对药品/农化产品的专利期限延长 | Certificate of supplementary protection |
| invention | 可获得专利的技术创造；专利权的客体 | Discovery（技术性区别） |
| patentable invention | 满足新颖性、创造性步骤和工业适用性的发明 | Patentable subject matter |
| novelty | 第一要件：发明在世界范围内无在先公开 | Newness（较不技术） |
| inventive step | 第二要件：对本领域技术人员而言非显而易见 | Inventiveness；Non-obviousness |
| industrial applicability | 第三要件：能够工业应用 | Utility（美国术语）；Usefulness |
| prior art | 发明之前的既有知识/公开物；新颖性检索中审查 | State of the art；Art known before filing |
| freedom to operate (FTO) | 使用技术而不侵犯第三方专利的权利 | FTO clearance；FTO analysis |
| FTO analysis | 识别侵权风险的全面专利态势研究 | Clearance search；Landscape search |
| prior art search | 识别与发明相似的现有专利/公开物的检索 | Patent search；State of art search |
| patent family | 同一发明在不同法域的一组专利 | Patent portfolio（更宽） |
| infringement | 未经授权制造、使用或销售专利发明 | Violation；Patent violation |
| infringement action | 针对被指控侵权人的法律程序 | Infringement lawsuit；Infringement suit |
| patent invalidity | 认定专利不符合法定要求的决定 | Patent revocation；Patent cancellation |
| patent revocation | 司法或行政撤销专利权利 | Patent invalidation（相近） |
| compulsory licence | 未经专利权人同意由政府授予的许可（紧急情形等） | Mandatory licence；Forced licence |

## 商标术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| trade mark (UK) / trademark (US) | 用于区分商品/服务的标志；“trade mark”（两词）为英国标准；除非用户要求美国翻译，默认英国拼写 | Mark（过于笼统） |
| registered trade mark | 在商标局正式注册的商标 | Registered mark |
| unregistered trade mark | 未经注册的普通法保护；“passing off”为英国概念 | Unregistered mark；Trade dress（美国） |
| EU trade mark (EUTM) | 经 EUIPO 注册、覆盖所有欧盟国家的单一注册 | European trade mark（较不精确） |
| international trade mark | 在多个国家注册的商标；常经 WIPO 马德里体系 | Multi-territorial mark |
| trade mark application | 向商标局提交的注册申请 | Mark application |
| registration | 审查后商标权利的正式授予 | Trademark registration（更宽） |
| renewal | 为维持权利而定期重新注册（通常每 10 年） | Re-registration；Maintenance |
| Nice classes | 商标商品/服务的国际分类体系（45 类） | Classification classes |
| goods and services | 商标注册保护的商品和服务类别 | Products and services |
| word mark | 仅由文字组成、无图形设计的商标 | Verbal mark；Textual mark |
| figurative mark / device mark | 文字和/或视觉设计元素结合的商标 | Design mark；Logo |
| three-dimensional mark / shape mark | 保护独特产品形状或包装的商标 | 3D mark；Shape mark |
| domain name | 互联网地址（如 www.example.com）；与商标不同但常协同 | Website name |
| business sign / trade name | 业务经营所用名称；保护程度低于商标 | Business name |
| company name | 法人的注册名称；不同于商标保护 | Business designation |
| designation of origin | 证明商品产自特定地区（如香槟） | Geographical indication（更宽） |
| geographical indication (GI) | 表明商品/服务产自具有声誉之特定地点的标志 | Place of origin mark |
| genericisation / loss of distinctiveness | 商标成为产品类别的通用名称时发生 | Trademark dilution（美国术语） |
| likelihood of confusion | 标准测试：普通消费者是否会在标志之间产生混淆 | Confusing similarity；Confusion test |
| opposition | 在授予前阻止或质疑商标注册的程序 | Opposition proceedings |
| revocation (for non-use) | 因连续 5 年以上不使用而撤销商标权利 | Cancellation for non-use |
| passing off | 英国普通法侵权：使用标志/装潢导致消费者混淆 | Misappropriation（美国对应） |
| trade dress | 产品/包装的独特外观，像商标一样受保护；注意“trade dress”主要是美国概念——英国对应为经仿冒之诉保护的未注册商标 | Trade dress（作为英国术语——用 passing off / get-up） |

## 版权术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| copyright | 控制创造性作品的复制、发行、改编的权利 | Author's right（大陆法系术语） |
| copyright work / work of authorship | 固定于媒介上的原创性表达（文学、音乐、艺术等） | Copyrighted work（并非所有作品都受保护） |
| original work | 体现独立创作并达到最低创作性门槛的作品 | Novel work（不同概念） |
| author | 版权作品的创作者；版权第一所有人（职务作品除外） | Creator（较不技术） |
| moral rights | 完整权、署名权、隐私权、名誉权等非经济权利 | Droit moral（法语术语） |
| economic rights / exploitation rights | 控制复制、发行、改编、传播的权利 | Patrimonial rights（大陆法系） |
| reproduction right | 以任何媒介复制作品的权利 | Copying right（不精确） |
| distribution right | 控制有形复制品首次销售/发行的权利 | Sale right；Rental right |
| right of communication to the public | 广播或按需提供（互联网、流媒体）的权利 | Public performance right（更窄） |
| adaptation right | 修改、翻译或创作衍生版本的权利 | Modification right；Translation right |
| derivative work | 基于或改编自既有作品的作品；须经原作许可 | Adaptation（较不精确） |
| collective work | 由多位作者的贡献整合为单一作品的作品 | Compilation（结构不同） |
| joint work | 由两位或以上作者创作、贡献不可分的作品 | Co-authored work |
| assignment of rights | 版权所有权从作者转移给另一方 | Transfer of copyright；Cession |
| licence to use | 不转移所有权而许可使用作品 | Licence（缩写形式） |
| exclusive licence | 授予单一被许可人排除所有其他人（包括许可人）的权利 | Sole licence（可能保留许可人权利） |
| non-exclusive licence | 多名被许可人可同时获得相同权利 | Standard licence；Open licence（不精确） |
| fair remuneration | 作品使用中给予作者的公平报酬（法定概念） | Fair compensation |
| public domain | 不再受保护的作品（版权届满、不符合条件、自愿放弃） | Public access（不同于公共领域） |

## 许可与技术转让

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| licence agreement (UK) / license agreement (US) | 授予使用知识产权（专利、商标、版权、专有技术）许可的合同；除非用户要求美国翻译，默认英国拼写 | Licensing contract（不精确）；IP authorisation agreement |
| patent licence | 允许使用专利技术的特定许可 | Patent license（美国） |
| trade mark licence | 允许使用注册商标的许可；许可人保留所有权 | Mark licence |
| cross-licence / cross-licensing | 双方之间的许可互授（技术领域常见） | Mutual licensing |
| sub-licence | 被许可人授予第三方的许可（除非允许，须经许可人同意） | Sublicense（一词，美国） |
| royalty | 被许可人向许可人定期支付的使用知识产权的费用 | Running royalty（特定类型）；Fee |
| lump-sum royalty | 一次性支付的许可费（相对销售额百分比） | Flat fee；Fixed fee |
| running royalty | 按许可期内销售额/收入百分比计算的许可费 | Percentage royalty |
| minimum guarantee | 无论实际销售如何均须支付的最低年许可费 | Guaranteed minimum；Floor |
| know-how | 保密的技术信息、技能、经验；未申请专利 | Trade secret（更窄） |
| trade secret | 具有商业价值的保密商业/技术信息；可包含专有技术 | Confidential know-how |
| technology transfer | 技术知识、专利或专有技术在双方之间传递 | Technology licensing（更窄） |
| R&D agreement | 规范联合研究与开发合作的合同 | Research agreement |
| ownership of results | 研发协议成果的知识产权分配 | Ownership of improvements；IP allocation |
| background IP | 合同/合作开始前已拥有的知识产权；于附表中列明 | Pre-existing IP；Existing IP |
| foreground IP | 合同/合作期间产生的知识产权；所有权通常予以分配 | Project IP；Developed IP |
| sideground IP | 被许可人使用许可人背景知识产权但在不同领域产生的知识产权 | Spin-off IP；Peripheral IP |
| improvement | 对既有许可技术的增强或修改 | Improvement IP；Upgraded version |
| right of first offer | 被许可人须在独立商业化前将新改进提供给许可人 | ROFO |
| right of first refusal | 许可人/被许可人有权在第三方之前取得改进的许可 | ROFR |
| field-of-use restriction | 许可限于特定行业或应用（如“仅限制药用途”） | Field restriction；Limited field licence |
| open source licence | 允许自由使用、修改和分发软件的许可；区分许可宽松型（MIT、Apache、BSD）与著佐权型（GPL、AGPL、LGPL） | Free software licence（不同运动）；Freeware（不同概念） |
| copyleft | 要求衍生作品以相同许可条款分发的开源许可（如 GPL）；专有软件的关键合规风险 | Viral licence（非正式）；Restrictive open source |
| source code escrow | 源代码交由托管代理人持有、在触发事件（如许可人破产、重大违约）时向被许可人释放的安排 | Code deposit；Software escrow（较不精确） |
| change of control | 权威定义见 finance-banking.md。知识产权许可语境：许可协议可规定控制权变更时终止或同意权。 | — |
| articles of association (UK) / by-laws (US) | 权威定义见 corporate-ma-jv.md。知识产权语境：章程规范知识产权所有权政策或知识产权交易董事会审批门槛时可能相关。 | — |

## 外观设计与商业秘密术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| design | 工业产品的装饰性外观；在欧盟可注册为“registered design” | Aesthetic design；Design right |
| registered design | 在知识产权局正式注册的外观设计；提供排他权利 | Design patent（美国）；Protection design |
| Community design | 经 EUIPO 依欧盟制度注册的外观设计（注意：脱欧后术语可能变化） | EU design |
| utility model | 针对功能性创新的知识产权保护形式（期限短于专利）；部分欧盟和亚洲法域提供，英国和美国没有 | Minor patent |
| confidential information | 标注保密并按秘密对待的商业/技术信息 | Proprietary information（更宽） |
| trade secret | 因不予披露而提供竞争优势的保密信息；英国法定依据是实施《欧盟指令》2016/943 的《2018 年商业秘密（执行等）条例》 | Industrial secret（旧大陆法系直译）；Confidential data（不精确） |
| protective measures | 维持保密的物理、技术、组织措施 | Security measures；Protection procedures |
| non-disclosure agreement (NDA) | 对保密信息接收方施加保密义务的合同；首次全称拼写后使用“NDA”作为定义术语 | Confidentiality agreement（同义词但交易实务中较少用）；secrecy agreement |
| confidentiality obligation | 不披露或滥用保密信息的合同义务 | Non-use obligation；Secrecy obligation |

## 注释

- **“Intellectual property”范围**：涵盖专利、商标、版权、外观设计、商业秘密及其他知识产权权利。许多大陆法系法域历史上将工业产权（专利、商标、外观设计）与作者权（版权）分开，但英语对所有权利使用单一伞形术语“intellectual property”。

- **“Trade mark”（英国）与“trademark”（美国）**：英国英语（及 EUIPO）用“trade mark”（两词）；美国用“trademark”（一词）。默认英国用法为主，注明美国变体。

- **“Licence”（英国名词）与“license”（美国名词/动词）**：英国：“licence”（名词）和“license”（动词）；美国：两者均用“license”。默认英国名词形式。

- **“FRAND”条款**：公平、合理且无歧视——标准必要专利（SEP）防止专利挟持的标准许可义务。

- **“SEP”（标准必要专利）**：实施技术标准（如电信、汽车）所必需的专利；受 FRAND 许可义务约束。

- **“Freedom to operate”（FTO）**：使用技术而不侵犯第三方知识产权的许可状态；须进行涵盖相关专利态势的 FTO 分析。

- **“Prior art search”**：识别发明之前已有专利和公开物的全面检索；对新颖性评估和可专利性认定至关重要。

- **“Patent family”**：同一发明在不同法域的一组相关专利（如美国专利+欧洲专利+日本专利）；作为单一知识产权资产管理。

- **“Trade dress”**：产品或包装的独特外观（形状、颜色、设计），像商标一样受保护；不同于外观设计注册；该概念主要用于美国法律；英国对应物可指普通法“passing off”下的“unregistered trade mark”。

- **“Passing off”（英国）**：英国（及部分其他法域）的普通法侵权，通过阻止第三方使用导致消费者受骗的混淆近似标志来保护未注册商标/装潢；美国对应为“misappropriation”或“false passing off”。

- **大小写**：在法律起草中，定义术语如“Licence”“Patent”“Trade Mark”“Licensor”“Licensee”应在整个协议中一致大写。

- **缩写**：首次使用时展开：EPO（欧洲专利局）、EUIPO（欧盟知识产权局）、WIPO（世界知识产权组织）。

## 第 2 部分——IT、软件与 SaaS

## 核心 IT/SaaS 术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| software licence agreement (UK) / software license agreement (US) | 授予软件使用权的合同；除非用户要求美国翻译，默认英国拼写 | Software use agreement |
| end-user licence agreement (EULA) | 面向软件最终用户的标准许可协议；通常为点击同意 | EUA（仅缩写）；Licence agreement（过宽） |
| acceptable use policy (AUP) | 定义软件/服务允许/禁止使用的政策 | Acceptable use terms；Permitted uses |
| subscription | 持续使用服务的权利；区别于永久许可 | Subscription licence（冗余） |
| subscription fee | 持续访问服务的定期付款（按月、按年） | Monthly fee；Annual charge |
| SaaS agreement | 规范基于云的软件即服务合同；包括服务水平、数据处理、支持 | Cloud services agreement（更宽）；SAAS contract |
| service level agreement (SLA) | 定义服务可用性、正常运行时间、性能指标和救济的合同 | Service level；SLA terms |
| uptime | 服务运行可用的时间百分比（如 99.9% 正常运行时间） | System availability；Availability |
| downtime | 服务不可用或无法运行期间 | System downtime；Outage |
| service availability | 在营业时间内或持续保持服务运行的承诺 | Availability；Service uptime |
| service credit | 服务故障时给予的发票折扣/优惠；区别于约定损害赔偿 | Credit（未限定且不精确）；Penalty（暗示不可执行性问题） |
| liquidated damages | 违约的合同损害赔偿（传统外包）；区别于服务积分 | Damages；Breach damages |
| scheduled maintenance | 更新/补丁的计划性停机；通常预先告知用户 | Planned maintenance；Maintenance window |
| production environment | 服务实际用户的生产系统（相对暂存/测试环境） | Live system；Production system |
| staging environment / test environment | 部署至生产前用于测试的非生产环境 | Testing environment；Development environment |
| instance | 面向单个客户的软件或云服务的单次安装/副本 | Virtual machine (VM——不同技术概念)；copy（不精确） |
| multi-tenant | 以共享基础设施服务多个客户的架构 | Multi-tenanted；Shared infrastructure |
| single-tenant | 为单个客户提供专属基础设施的架构 | Dedicated tenant；Single-tenant environment |
| API (application programming interface) | 允许软件通信和交换数据的接口；首次使用全称拼写，此后缩写 | Interface（不精确——也涵盖 UI）；application interface（不完整） |
| API key | 使能访问 API 的身份验证凭证 | Authentication key；Access key |
| webhook | 事件发生时实时传递数据的自动回调 | Webhook notification |
| integration | 使系统之间能够交换数据的连接 | System integration；Data integration |
| data migration | 数据从源系统转移到目标系统（常从遗留系统到云） | Migration；Data transfer |
| data portability | 以标准格式提取和复用客户数据的能力 | Data export；Data extraction |
| data export | 以指定格式从系统提取客户数据的过程 | Data extraction；Export |
| backup and recovery | 备份数据并在丢失后恢复的系统和流程 | Disaster recovery（更宽）；Backup procedures |
| disaster recovery | 重大中断后恢复运营的计划和能力 | DR；Business continuity（更宽） |

## 注释

- **“Licence”（英国名词）与“license”（美国名词/动词）**：英国：“licence”（名词）和“license”（动词）；美国：两者均用“license”。法律词汇表默认英国名词形式。

- **“EULA”（最终用户许可协议）**：面向最终用户的标准软件许可合同；常以点击同意形式呈现。区别于开发/企业协议。

- **“可接受使用政策”（AUP）**：定义允许和禁止的使用；常包括对反向工程、竞争性使用、非法活动的限制。

- **“服务积分”与“约定损害赔偿”**：SaaS 协议通常对服务故障使用“service credits”（发票折扣）；传统 IT 外包使用“liquidated damages”（违约的合同损害赔偿）。不可互换。

- **“服务水平协议”（SLA）结构**：应定义指标（正常运行时间百分比）、衡量周期、故障服务积分和排除项（计划维护、不可抗力、客户行为）。

- **“暂存环境”**：又称“测试环境”“预生产”“开发环境”；用于部署至生产前的测试。区别于生产环境。

- **“数据迁移”**：通常需要在合同开始（接入）和结束（退场）时进行；协议应规定格式、时间表、迁移期间的安全。

- **“数据可移植性”**：与 GDPR 要求相关；客户应能在合理时间范围内以机器可读格式提取数据。

- **“备份与恢复”与“灾难恢复”与“业务连续性”**：备份=数据副本；DR=重大故障后的恢复能力；业务连续性=更广泛的运营韧性。

- **“赔偿”（知识产权侵权）**：开发者向客户赔偿第三方声称开发软件侵犯知识产权权利之索赔；开发协议的标准条款。

- **“不可抗力”**：对双方控制之外的不可预见事件（战争、自然灾害、流行病）的合同免责；通常排除经济困难。

- **“控制权变更”**：合并、收购或所有权变更；因保密/安全顾虑常触发重新谈判权或终止权。

- **“审计权”**：客户检查服务提供商运营以核实 SLA 合规、安全标准、数据处理等的权利；通常受通知和保密约束。

- **“职务作品”（work made for hire）**：受委托创作者的作品所有权归于雇主（而非创作者）的法律概念；因法域而异；应在开发协议中明确写明。

- **大小写**：在法律起草中，定义术语如“Services”“Software”“Customer Data”“Confidential Information”“SLA”“Deliverables”应在整个协议中一致大写。

- **翻译中的服务积分与约定损害赔偿**：一些源语言对两个概念使用单一术语。在英语中，“service credits”（SaaS/云标准）和“liquidated damages”（传统外包）是不同的；务必根据语境确定适用哪一个。
