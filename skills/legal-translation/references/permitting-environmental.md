# 许可与环保法词典

环境法、许可与审批的标准中文术语：环境影响评估、综合许可、水与废弃物、化学品、自然保护、受污染土地、环境责任、气候监管、施工许可与分区，以及行政程序与执法。

交叉引用：土地交易和地役权见 `real-estate.md`；电厂、海上风电和电网资产的许可见 `energy-infrastructure.md`；交易中的环境尽职调查见 `corporate-ma-jv.md`；执法上诉见 `litigation-settlement.md`。

## 核心概念

| 正确英文术语 | 用法/含义 | 避免 |
|---|---|---|
| environmental law | 规范环境保护的规则体系；区别于规划/分区 | Ecological law（非技术性）；Environmental regulation（更窄） |
| sustainability | 经济活动应满足当代需求而不损害后代的原则 | Eco-friendliness（非正式） |
| precautionary principle | 决策原则：即使缺乏科学确定性，也可采取行动防止环境损害 | Preventive principle（不同概念） |
| polluter-pays principle | 污染和修复成本由污染者承担的原则 | Pollution liability（更窄） |
| prevention principle | 环境损害应在源头防止的原则 | Source prevention |
| sustainable development | 协调环境、社会和经济目标的发展 | Green development（非正式） |
| integrated pollution prevention and control (IPPC) | 欧盟历史上对大型工业装置综合许可的框架（现为 IED） | Integrated pollution control（不精确） |
| best available techniques (BAT) | 防止/减少排放的最有效且经济上可行的技术；对 IED 装置具有约束力 | Best practices（非正式）；Best available technology |
| BAT reference document (BREF) / BAT conclusions | 欧盟将某行业 BAT 成文法的文件；BAT 结论对许可条件具有约束力 | BREF notes |
| environmental management system (EMS) | 管理环境绩效的组织框架；通常经 ISO 14001 认证 | Environmental policy（更窄） |

| 正确英文术语 | 用法/含义 | 避免 |
|---|---|---|
| environmental impact assessment (EIA) | 项目在审批前对其可能重大环境影响的程序性评估 | Environmental review（非正式）；EIA study（文件应为"EIA report"） |
| EIA Directive | 2011/92/EU 指令（经 2014/52/EU 修订），规范欧盟项目级 EIA | EIA law |

| scoping | 确定 EIA 的内容和范围 | Scoping opinion |
| environmental impact statement / EIA report | 开发方记录评估的报告 | EIS（美国用法）；Impact study |
| non-technical summary (NTS) | EIA 报告的通俗语言摘要，公众咨询所必需 | Executive summary |
| public consultation / participation | 公众和主管机关对 EIA 发表意见的强制性机会 | Public inquiry（特定的英国程序） |
| Aarhus Convention | 1998 年联合国/欧洲经委会关于环境事务信息获取、公众参与和诉诸司法的公约 | Aarhus Treaty |
| Annex I / Annex II project | EIA 指令类别：附件一——强制 EIA；附件二——逐案筛选 | Listed project（含混） |

| strategic environmental assessment (SEA) | 依据 2001/42/EC 指令的计划/方案层面环境评估 | Strategic assessment（含混） |
| appropriate assessment (AA) | 依据《栖息地指令》第 6 条第(3)款，对影响 Natura 2000 场址的计划/项目进行的评估 | Natura assessment |
| transboundary EIA (Espoo) | 依据《埃斯波公约》的跨境 EIA 程序 | International EIA |
| mitigation measures | 避免、减少或抵消不利环境影响的措施 | Compensation（特定概念） |
| monitoring requirements | 审批后追踪环境影响和缓解措施有效性的义务 | Follow-up（非正式） |

## 说明

- **环境"许可（permit）"vs"同意（consent）"vs"执照（licence）"**：欧盟用法各异。"Permit"是《工业排放指令》下的主导术语；"consent"出现在英国规划和水利立法中；"licence"用于离散活动（如废弃物、取水）。除非源文本或管辖地使用其他术语，默认用"permit"。

- **EIA 术语**：2014 年修订后欧盟统一的用法："environmental impact assessment"（EIA）；"EIA report"（开发方文件，不是"EIS"）；"screening decision"；"scoping opinion"。较早文本可能使用"environmental statement"或"EIS"——注明并统一。

- **"适当评估"（AA）**：区别于 EIA。依据《栖息地指令》第 6 条第(3)款，对可能对 Natura 2000 场址产生重大影响的计划/项目为强制性要求。可与 EIA 并行进行。不得混同。

- **BAT / BAT-AEL / BAT 结论**：BAT 是定性标准；BAT-AEL 是与 BAT 相关的数值排放范围；BAT 结论是欧盟委员会将某行业 BAT 成文法化的决定，对 IED 装置的许可条件具有约束力。

- **《工业排放指令》（IED）2024 年修订**：(EU) 2024/1785 指令扩大了范围（纳入更多集约化养殖和电池/金属行业）、增加了环境管理体系义务和更多透明度。较早文本会以 IED 2010/75/EU 作为基础文书。

- **"污染者付费"与 ELD**：污染者付费原则在《环境责任指令》（ELD）中操作性成文化。ELD 涵盖水、受保护物种/栖息地和土地（限于对人类健康的风险）。它不为私人当事方创设独立的损害赔偿请求权。

- **Seveso III**：按危险物质数量分级别适用（下层级 vs 上层级场址）。上层级运营者必须编制安全报告；下层级必须实施 MAPP。是并购环境尽职调查的常见触发点。

- **REACH——SVHC 披露**：含 SVHC 超过 0.1% w/w 的物品供应商必须通知下游用户和 ECHA（通过 SCIP 数据库）。物品生产商/进口商往往不知道这一义务——在商业翻译中标注。

- **EU ETS 与 CBAM 的接口**：CBAM 适用于碳密集型行业（水泥、钢铁、铝、化肥、氢、电力）的进口商品，并与这些行业免费 EU ETS 配额的逐步取消（2026–2034）并行运行。

- **《奥胡斯公约》——三大支柱**：环境信息获取；公众参与；诉诸司法。已通过 (EC) 1367/2006 和 (EU) 2021/1767 号条例纳入欧盟法律。对翻译公众参与和 NGO 诉讼资格相关内容很重要。

- **CSRD / CSDDD / Taxonomy**：欧盟可持续发展报告栈。CSRD 自 2024 财年起适用（第一波）；CSDDD 自 2027 年起分阶段实施；Taxonomy 提供分类框架。首次使用时完整翻译名称。

- **规划许可 vs 开发许可**：在英国，"planning permission"是《城乡规划法》下的默认许可；"development consent"（DCO）适用于 2008 年《规划法》下的国家重大基础设施项目。在大陆法管辖地，按字面翻译当地对应概念并提供简短说明。

- **"停止通知（stop notice）"/"禁止通知（prohibition notice）"/"紧急命令（emergency order）"**：均指立即停止构成迫在眉睫环境或安全风险活动的执法。酌情使用"stop notice"（英国环境署用法）或"prohibition notice"（英国 HSE 用法）；其他管辖地按字面翻译当地术语并在括号内说明。

- **民事、刑事和行政执法**：环境法横跨三种执法模式，往往同时进行。翻译时明确识别模式——如"administrative fine（行政罚款）"指非刑事处罚，"criminal prosecution（刑事公诉）"指可公诉罪行，"civil injunction（民事禁令）"指私法诉讼。

- **"绿色"营销主张**：在 (EU) 2024/825 指令（赋权消费者实现绿色转型）和待出台的《绿色主张指令》之后，环境营销主张（绿色、可持续、碳中和、可生物降解）的翻译很敏感。避免创造性翻译——保留源术语并标注含混之处。

- **大写**："Permit"、"Competent Authority"、"Remediation"、"Environmental Laws"等定义术语应一致大写。国际法规引用（REACH、IED、WFD、CLP）始终大写。

- **交叉领域性质**：许可与环保法与许多其他领域交叉。翻译涉及多个领域的文件时，检查：土地/房地产（分区、地役权、受污染土地）；能源/基础设施（电厂 EIA、海上风电）；并购（环境尽职调查、保证、赔偿、披露清单）；诉讼（执法上诉、司法审查、公民诉讼）；金融（绿色贷款、可持续发展挂钩贷款、符合 Taxonomy 的融资）。
