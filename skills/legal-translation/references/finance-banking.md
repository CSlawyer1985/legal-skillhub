# 金融／银行词典

金融和银行文件的英文术语：项目融资担保包、贷款协议、质押、抵押、债券、借款合同、债权人间协议、银团贷款、巴塞尔 III／CRR、AML／KYC、制裁合规、银行牌照及相关工具。统一词典，涵盖项目融资／担保（原 `finance.md`）和一般银行／监管（原 `banking-regulatory.md`）。

> **按语言的子词典说明。** 本英文参考文件仅涵盖金融与银行；交易与资本市场术语见 `references/trading-capital-markets.md`。在按语言的子词典中，两个领域已合并：`sub-lexicons/<language>-finance-banking.md` 同时涵盖两者。处理资本市场文件时，阅读两个英文参考文件，但只阅读单个按语言的子词典。

## 核心金融术语

| 正确英文术语 | 用法／含义 | 避免使用 |
|---|---|---|
| facility agreement | 规范贷款／信贷融资的协议（LMA 标准） | “financing agreement”“loan contract” |
| loan agreement | 针对直接（通常为双边）贷款的特定协议 | “loan facility”（若为框架协议）；“credit contract”（非正式） |
| facility | 信贷额度本身（Term Facility、VAT Facility、DSR Facility） | “financing”“loan”（在项目融资语境中） |
| lender | 提供融资的银行或机构 | “financing bank” |
| borrower | 接受融资的一方 | — |
| secured party / secured parties | 从担保中受益的一方／多方 | “secured creditor”（可接受，但在 LMA 中不如前者标准） |
| security interest | 为担保义务而授予的资产上的任何权利——涵盖质押、抵押、担保、留置权等的总称 | — |
| security package | 交易中全部担保文件和担保权益的完整组合 | — |
| enforcement event | 触发行使担保权的事件 | “cause of enforcement” |
| event of default | 产生加速／终止权利的违约或事件 | “relevant event” |
| potential event of default | 经通知或经过时间后将成为违约事件的事件 | “potential relevant event” |
| security period | 担保持续有效的期间 | “guarantee period” |
| maximum secured amount | 受担保金额的上限 | “maximum guaranteed amount” |
| subject matter of the security | 受担保的资产或权利 | “subject matter of guarantee” |
| perfection | 使担保权益对第三方可强制执行的过程，通常通过登记或备案完成 | — |
| mortgage loan | 以不动产抵押／信托契据担保的贷款 | “home loan”（过于非正式）；“real estate loan”（不够具体） |
| unsecured loan | 无抵押物担保的贷款 | “clean loan”；“signature loan”（非正式） |
| credit facility / overdraft facility | 可借用的预先批准金额（通常为短期） | “overdraft account”；“credit line”（可接受，但“facility”为标准） |

| documentary credit | 以所有权单据（提单等）担保的信用证 | “trade credit”（过宽）；“commercial credit”（不精确） |
| bank guarantee | 银行在受益人索赔时见索即付的承诺 | “bank's guarantee”（语法上可接受） |
| comfort letter / letter of awareness | 母公司就子公司履约情况所作的非正式陈述 | “letter of comfort”（可接受）；“parent company letter”（不够正式） |

## 融资类型、提款与金融工具

| material adverse change (MAC) / material adverse effect (MAE) | 对借款人履行义务的能力产生重大不利影响的事件或情况 | “Adverse change”（过于含糊） |

| mandatory prepayment | 由特定事件触发的强制提前还款 | — |

| representations and warranties | 借款人的事实陈述和承诺 | “declarations and warranties” |
| recitals | 协议的引言部分 | “preambles”“premises” |
| schedules | 协议的附件 | “annexes”（欧盟／国际文件中可接受） |

## 英国法担保概念

这些术语为英国法金融文件所特有。仅当源文件的担保结构确实对应英国法概念时使用。大陆法担保概念通常不能与普通法类别干净对应。

| 正确英文术语 | 用法／含义 | 备注 |
|---|---|---|
| debenture | 创设对公司全部或实质上全部资产的固定和浮动担保的文件 | LMA 交易中的标准英国法担保工具 |
| fixed charge | 附着于特定、已识别资产的担保（担保人不能自由处分该等资产） | 与大陆法对特定资产的质押对应良好 |
| floating charge | 悬于不断变化的资产类别（如存货、应收款）之上的担保，直至结晶 | 无直接的大陆法对应——仅当源概念涉及浮动资产池上的担保时使用 |
| crystallisation | 浮动担保转换为对特定资产的固定担保的时刻 | — |
| security trustee | 为所有贷款人的利益以信托方式持有担保的实体（英国法项目融资结构） | 区别于“security agent”（其作为代理人而非受托人行事） |

## 说明

- **担保语境中的“Beneficiary”有歧义**：“beneficiary of the facility”（融资受益人）是借款人（接收资金者），但“beneficiary of the security”（担保受益人）是担保权人（持有担保权益者）。始终根据语境消歧。切勿将两者都译为“borrower”。

- **LMA 标准**：英文金融文件通常遵循贷款市场协会（Loan Market Association，LMA）惯例。在可能处使术语与 LMA 标准保持一致。

- **Loan 与 facility agreement**：许多源语言区分特定贷款合同（双边、本金金额）与更宽泛的信贷融资。在英文中，银团／结构化贷款使用“facility agreement”（LMA 标准），简单双边贷款使用“loan agreement”。不要将源语言的区分强加于英文；根据文件结构和经济实质翻译。

- **项目融资细节**：在项目融资文件中，“Facility”始终指特定的信贷额度（Term Facility、VAT Facility、DSR Facility）。切勿使用“Loan”——“Facility”是市场标准用语。

- **“Article”与“Clause”**：文档内部交叉引用使用“Clause”。仅当指立法时保留“Article”。

- **大陆法与普通法担保**：许多大陆法担保概念（如意大利“privilegio speciale”、法国“nantissement”、德国“Sicherungsübereignung”）不能与英国法类别干净对应。翻译时，仅当概念真正等价时才使用最接近的英国法术语。若不等价，使用描述性英文翻译并考虑加译者注。切勿将普通法术语强行套用于根本不同的大陆法概念。

- **国家银行立法**：翻译对国家银行法典或综合法规的引用时，首次出现提供官方英文译名，随后以括号附源语言引用。子词典提供源语言映射。

- **资本要求术语**：使用精确的巴塞尔 III／CRR 术语（CET1、AT1、T2、MREL、TLAC、SREP）。这些为国际标准化用语。不要转述或翻译缩写——各法域使用完全相同的写法。

- **欧盟监管框架**：欧盟指令／条例（CRR、CRD、AMLD、PSD2）为跨国标准，保留在仅英文主词典中（非子词典）。国家特定的机构和立法只放入子词典。

- **反洗钱指令版本**：欧盟反洗钱框架正在演进。文件可能引用 AMLD4（2015）、AMLD5（2018）、AMLD6（2022）或即将出台的《反洗钱条例》（AMLA）。务必确认适用版本并在翻译中注明。

- **Bail-in 与处置**：“Bail-in”是银行业联盟框架（SRM／SSM）下欧盟特有的恢复与处置工具。区别于美国破产／接管。“Resolution plan”／“living will”＝银行失败策略的必备文件。

- **Passporting 与 ring-fencing**：“Passporting”＝欧盟银行牌照权利（脱欧后仅适用于欧盟内部，不包括英国）。“Ring-fencing”＝英国《维克斯报告》建议（在英国实施，与欧盟结构分离提案不同）。

- **英式与美式英语**：本词典默认使用英式惯例（如“recognised”“licence”（名词）“organisation”“utilisation”）。在重要处注明美式替代（如“authorization”与“authorisation”）。
