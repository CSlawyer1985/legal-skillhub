# 运输与保险术语词典

关于运输（海运、公路、铁路、航空、多式联运）和保险协议的标准英语术语。第一部分涵盖运输合同、提单、租船合同、货运代理和运输责任制度。第二部分涵盖保险合同、寿险和非寿险险种、再保险、经纪人和索赔。海上保险（协会货物条款、船壳和机器险、保赔险）、航空保险和承运人责任保险横跨两个部分。

---

## 第一部分——运输与航运

涵盖运输合同、提单、国际贸易术语（Incoterms）、货运代理、海事留置权、货物运输、租船合同、物流协议及相关文书。

## 核心航运术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| contract of carriage | 规范货物运输的协议 | transportation agreement、shipping agreement |
| carriage by sea / sea transport | 通过船舶运输货物 | maritime transport、ocean carriage |
| carriage by air / air transport | 通过飞机运输货物 | air freight、air shipment |
| carriage by road / road transport | 通过公路车辆运输货物 | road haulage（更特指）、trucking |
| carriage by rail / rail transport | 通过铁路运输货物 | rail freight、rail haulage |
| multimodal transport | 涉及两种或两种以上运输方式的运输 | multi-modal、combined transport（指单一承运人时） |
| combined transport | 单一承运人使用多种运输方式 | multimodal（暗示多个承运人） |
| shipment / forwarding | 被运输的货物或货运代理过程 | shipping（可能暗示海运） |
| freight forwarder / forwarding agent | 安排和协调运输的代理人 | shipper（是发货人）、freight broker |
| carrier | 负责运输货物的当事方 | shipper（是发货方）、consignee（是收货方） |
| shipper | 发送货物的一方（发货人/托运人） | sender、exporter（跨境时） |
| consignee | 接收货物的一方（收货人） | receiver、importer（跨境时） |
| charter | 约定在一定期限或航次内租用船舶的协议 | charterage、ship hire |
| time charter | 为特定时间期限租船；承租人支付租金 | voyage charter（不同：针对单一航次） |
| voyage charter | 为单一航次租船；按货物单位支付运费 | time charter（不同：针对时间期限） |
| bareboat charter / demise charter | 无船员的船舶租约；承租人承担全部控制权 | full charter、charter without crew |
| bill of lading (B/L) | 证明运输合同和货物收讫的运输单据 | bill of lading document、shipping document |
| ocean bill of lading | 用于海运的提单 | sea waybill（不具有可转让性） |
| on-board bill of lading | 货物装船后签发的提单 | received-for-shipment B/L（不同：装船前签发） |
| received-for-shipment bill of lading | 货物在港口收讫时（装船前）签发的提单 | on-board B/L（不同：装船后签发） |
| clean bill of lading | 对货物状况无任何批注或保留的提单 | claused B/L（有保留批注）、dirty bill of lading |
| claused bill of lading | 注明货物缺陷、损坏或不符的提单 | clean B/L（无保留）、qualifying B/L |
| waybill | 不可转让的运输单据（不发生所有权转移） | bill of lading（是可转让的） |
| air waybill (AWB) | 用于航空货物的不可转让运输单据 | air bill of lading（错误：航空货物不可转让） |
| CMR consignment note | 依据 CMR 公约进行公路运输的运输单据 | CMR waybill、road transport document |
| CIM consignment note | 依据 CIM 公约进行铁路运输的运输单据 | rail waybill、railway consignment note |
| transport document | 证明运输合同的任何单据的统称 | shipping document、carriage document |
| through bill of lading | 由单一承运人承运至最终目的地的联运提单 | combined transport bill、multimodal bill of lading |
| combined transport bill of lading | 证明联运（海运+公路/铁路）的提单 | through bill、integrated transport bill |
| letter of indemnity (LOI) | 向承运人签发的、对未出示提单造成的损失予以赔偿的文件 | indemnity、indemnification letter |
| sea protest | 船长就外部情况提出的正式抗议 | ship's protest、master's protest |
| ship arrest | 依法院命令扣押船舶作为索赔担保 | vessel arrest、maritime attachment |

## 租船合同术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| charter party | 船东与承租人之间租用船舶的合同 | chartering agreement、charter contract |
| shipowner | 船舶所有人 | ship owner（两个词的写法也可以接受） |
| charterer | 按时间或航次租用船舶的一方 | ship charterer、lessee |
| vessel | 船舶或大船（正式用语） | boat（非正式）、ship（可以接受） |
| cargo | 由船舶运输的货物 | freight（可能暗示运费）、goods、merchandise |
| gross tonnage (GT) | 船舶内部总容积（以吨计） | tonnage、gross ton |
| net tonnage (NT) | 扣除船员舱室和机舱空间后可供货物使用的容积 | net ton、net tonnes |
| deadweight tonnage (DWT) | 船舶可承载的最大重量（含货物和补给） | deadweight、carrying capacity |
| freight | 货物运输的报酬（或货物本身） | shipping cost（不够精确）；carriage charges（含糊） |
| time freight / hire | 期租按时间单位收取的费用 | hire rate、daily rate |
| voyage freight | 航次租船按货物单位收取的费用 | freight rate、per-tonne freight |
| demurrage | 超出允许装卸时间造成延迟的费用 | overline charges、detention charges |
| laytime | 允许装卸货物的时间（合同约定） | loading time、discharge time |
| dispatch / despatch money | 提前完成装卸时间的付款/优惠 | despatch money（英式拼写）、speed bonus |
| loading port / port of loading | 货物装上船舶的港口 | port of embarkation、loading point |
| discharge port / port of discharge | 货物卸下船舶的港口 | port of debarkation、discharge point |
| safe port | 船舶可以无风险地进入、装卸并离港的港口 | safe port warranty、port safety clause |
| safe berth | 港口内船舶可以安全装卸的特定泊位 | safe port（涵盖所有方面） |
| notice of readiness (NOR) | 船长发出的船舶已准备好装卸的通知 | readiness notice、NOR notice |
| negligence clause | 限制承运人过失责任的租船合同条款 | negligence limitation、Hague-Visby protection |
| paramount clause | 要求遵守适用提单立法（通常为海牙规则或海牙-维斯比规则）的租船合同条款 | controlling clause（不精确）；supreme clause |
| bunkers / fuel | 船上的燃料；燃油条款在船东和承租人之间分配燃料费用 | Fuel oil（海事语境中不够标准） |
| bunker clause | 分配交船/还船时船上剩余燃料费用的租船合同条款 | Fuel clause（不够标准） |
| off-hire | 期租期间租金停止计算的时段（船舶因故障、进坞等无法履行） | Non-hire period（非标准）；Suspension of hire（不够精确） |
| laydays / cancelling date (lay/can) | 船舶必须抵达装货港的期限；如在解约日船舶仍未备妥，承租人可解除合同 | Arrival window（不够精确）；Loading date（过于含糊） |
| deviation | 偏离约定航线的行为 | deviation clause、voyage deviation |

## 海商法术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| maritime lien | 船东/债权人就未付索赔扣押船舶的法定权利 | ship's lien、maritime claim（更宽泛） |
| ship mortgage | 以船舶作为债务担保的抵押 | vessel mortgage、maritime mortgage |
| arrest of vessel | 依法院命令扣押船舶作为海事索赔担保 | ship arrest、detention、attachment |
| general average | 由所有货物和船舶利益方按比例分担的损失 | average、general loss |
| particular average | 仅由货物利益方承担的损失（不进行分摊）；海上保险术语 | average、partial loss |
| average contribution | 货物/船舶对共同海损的比例分摊 | general average contribution、loss sharing |
| salvage | 救助遇险船舶、货物或海上财产的报酬 | salvage services、rescue operation |
| salvage and assistance | 救助（基于报酬）与协助（基于合同）的合并概念 | salvage and rescue、assistance services |
| abandonment | 将船舶、货物或利益让与承保人 | maritime abandonment、total loss abandonment |
| carrier's liability | 承运人对货物灭失/损坏的法律责任 | shipper's liability（不同：托运人的责任） |
| limitation of liability | 对责任的合同或法定上限（按货物单位、吨位或金额） | exemption clause（更宽泛）、liability cap |
| Hague-Visby Rules | 关于提单的国际海事公约（1968年，经修订） | Hague Rules（更早的1924年版本）、Hague-Visby Convention |
| Hamburg Rules | 关于提单的国际海事公约（1978年） | UN Convention on Carriage of Goods by Sea |
| Rotterdam Rules | 关于提单的国际海事公约（2008年） | UN Convention on Contracts for the International Carriage of Goods Wholly or Partly by Sea |
| Athens Convention | 关于旅客责任的海事公约（1974年，2002年修订） | Athens Convention on Passenger Liability |
| flag / registry | 船舶登记并悬挂其国旗的国家（依该国法律登记） | flag state、flag of convenience（政治性称谓） |
| classification | 对船舶结构和设备标准的评定 | vessel classification、class rating |
| classification society | 进行船舶检验并颁发入级证书的组织 | class society（可接受）、classification body |
| seaworthiness certificate | 确认船舶符合安全和技术标准的证书 | seaworthiness declaration、class certificate |
| class certificate | 由船级社颁发的确认船舶等级的证书 | class notation、vessel certificate |
| war risk | 战争、海盗、恐怖主义或政治暴力造成的损失风险；通常单独投保或从标准承保中排除 | War risk insurance（特定产品）；Political risk（更宽泛） |
| York-Antwerp Rules | 规范共同海损理算的国际规则（最新版本：2016年修订版） | General average rules（不够精确） |
| P&I club (protection and indemnity) | 为船东提供责任险的互助保险协会 | P&I insurance、protection and indemnity club |

## 注释

- **BIMCO 标准格式**：航运合同经常援引 BIMCO 标准格式（GENCON、NYPE、BALTIME、WORLDSCALE 等）。格式名称和缩略语保留英文原文。绝不翻译。

- **Incoterms（国际贸易术语）**：始终使用国际商会三字母缩略语（EXW、FOB、CIF、DAP、DDP 等），首次出现时附完整英文名称。Incoterms® 2020 为现行版本（2020 年 1 月起正式生效）。绝不翻译 Incoterms 缩略语。

- **"提单"与"保单"**：某些源语言对"bill of lading"（航运）和"insurance policy"（保险）使用同一同源词。始终根据语境区分：在航运/运输语境中使用"bill of lading"（B/L）；在保险语境中使用"policy"。子词典提供源语言对应关系。

- **伦敦仲裁**：许多租船合同约定按 LMAA（伦敦海事仲裁员协会）规则在伦敦仲裁。保留"LMAA"不变；这是标准的英文称谓。

- **CMR 公约**：《国际公路货物运输合同公约》（1956年）。保留"CMR"，首次出现时扩展为"CMR Convention"或"Convention on the Contract for the International Carriage of Goods by Road"。CMR 运单（CMR consignment note）是标准的运输单据。

- **CIM 公约**：《国际铁路货物运输公约》。保留"CIM"不变；这是标准的英文称谓。CIM 运单（CIM consignment note）是标准的运输单据。

- **海事英语**：海商法拥有经过数百年国际实践形成的极其专业的英语词汇。使用既定术语：
  - 使用"demurrage"而非"delay penalty"
  - 使用"laytime"而非"loading time"或"discharge time"
  - 使用"dispatch"（英式英语中为"despatch"）而非"speed bonus"
  - 使用"deviation"而非"route change"
  - 使用"charter party"而非"chartering agreement"
  - 使用"shipowner"而非"ship owner"（尽管两者均可接受）
  这些术语在所有英语海运法域中均已标准化。

- **提单类型**：仔细区分：
  - 已装船提单（On-board B/L）：货物装上船舶后签发（产生日期确定性）
  - 收讫待运提单（Received-for-shipment B/L）：装船前在港口签发（装船前）
  - 清洁提单（Clean B/L）：对货物状况无任何批注
  - 不清洁提单（Claused B/L）：注明缺陷或损坏（市场用语中称为"脏"提单）
  每种类型具有不同的商业/法律后果。

- **船舶扣押与一般保全**：海事留置权人可扣押船舶（依法院命令）。一般保全（attachment）是更宽泛的民法概念。海事领域的扣押使用"arrest of vessel"；仅在非海事语境中使用"attachment"。

- **赔偿保证函（LOI）**：当无法出示提单（如遗失、延迟）时向承运人签发。LOI 保证承运人在未出示提单即交货的情况下获得赔偿。这是标准海事惯例，但会形成表外风险。

- **直达提单（Through bill of lading）**：单一提单涵盖多种运输方式、由单一承运人运至最终目的地。区别于可能涉及多个承运人的"combined transport B/L"。单一承运人时使用"through B/L"；多种运输方式时使用"combined transport B/L"。

- **海牙-维斯比规则 / 汉堡规则 / 鹿特丹规则**：关于提单和承运人责任的国际海事公约。保留名称不变（如"海牙-维斯比规则"而非"Hague Visby"）。这是三个相互竞争的国际制度（海牙-维斯比规则仍最常用；鹿特丹规则最新但采用有限）。

- **安全港口保证（Safe port warranty）**：标准租船合同保证条款，保证指定港口对船舶安全。超出物理安全范围延伸至法律安全（无战争、禁运等）。在租船合同谈判中至关重要。

- **船级社**：包括劳氏船级社（Lloyd's Register）、DNV GL、美国船级社（ABS）、日本船级社（ClassNK）。机构名称保留原文不变。

## 第二部分——保险与再保险

## 核心保险术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| insurance contract / insurance policy | 保险人与被保险人之间界定承保范围、除外责任、条件的约束性协议 | policy agreement；coverage document（不够精确） |
| policy | 保险合同；指明类型（寿险、非寿险、一切险、多重风险险） | insurance agreement（用法较少） |
| life policy / life insurance policy | 承保死亡、生存、年金的保险；可为定期寿险、终身寿险或万能寿险 | life insurance；mortality policy（过于含糊） |
| non-life policy / property and casualty policy (P&C) | 承保财产损失或责任风险的保险；包括火灾、盗窃、责任、海上险 | casualty policy；general insurance（区域用语） |
| all-risks policy / all-risks insurance | 承保除明确除外风险之外的一切风险的保障；比列明风险险更全面 | blanket coverage；comprehensive insurance（不精确） |
| multi-peril policy | 承保多个列明风险的保单（如火灾+盗窃+水渍）；区别于一切险 | combination policy；combined coverage（含糊） |
| named-peril policy | 仅限于明确列明风险的保障；比一切险范围窄 | specified perils；enumerated coverage |

## 再保险术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|

| stop loss treaty / aggregate excess of loss | 承保分出人超过年度阈值的累计损失；防范累计损失 | aggregate XL；annual stop loss（区域用语） |

| loss reserve / claims reserve | 重复条目——见上文"索赔/准备金"部分的原始条目（第292行）。保留于此以便与后面再保险特有的 IBNR 和未到期保费条目交叉参考。 | — |
| reserve for incurred but not reported (IBNR) | 为已发生但尚未报告索赔提取的准备金；关键的精算估计 | IBNR reserve（非正式）；incurred reserve（过于含糊） |
| premium reserve / unearned premium reserve | 保险人为已承保但未赚取保费上的未来索赔提取的准备金 | unearned premium provision；deferred revenue（会计术语） |
| commutation | 分出人与再保险人之间了结并终止全部义务的协议；用于滚保退出（run-off）情形 | settlement agreement；final settlement（不精确） |
| run-off | 对保险组合、索赔和义务的有序退出管理；分出人可保留准备金或分给滚保退出专营商 | portfolio run-off；orderly closure（过于含糊） |
| run-off reinsurer | 承接遗留索赔和准备金、使分出人退出账册的专营再保险人 | legacy reinsurer；portfolio reinsurer（有歧义） |
| cut-through clause / cut-through endorsement | 分出人破产时，被再保险方允许直接向再保险人索赔；不寻常的保护措施 | direct claim clause；claimant bypass（不精确） |

## 注释

- **损失与索赔**：许多源语言对事件本身和赔偿请求使用同一个词。在英语中始终区分："loss"＝事件/损害；"claim"＝法律上的赔偿请求。根据源文本指的是事件还是请求进行语境化翻译。

- **事故发生制与索赔发生制**：这是根本不同的承保基础。事故发生制承保保单期间内发生的事件；索赔发生制承保保单期间内提出的索赔。始终指明适用哪一种；保费、尾部保障可用性和尾部风险敞口差异巨大。

- **Excess（英）与 Deductible（美）**：同一概念（被保险人的首次损失自留额）的等价术语。英国/欧盟语境用英式术语；美国语境用美式术语。在正式的欧盟英语中，首次出现时优先使用"excess"或两者并用（"excess/deductible"）。

- **免赔额/Excess 与共保**：许多源语言区分固定金额自留（免赔额/excess）和比例自留（共保/比例自留）。根据自留是固定金额还是索赔的百分比，确保使用正确的英语术语。

- **核保（Underwriting）**：区别于"underwriter"（作出承保决定的人）。"Underwriting"＝风险评估和定价的过程；"underwriter"＝履行该职能的专业人士。两者都区别于保险公司（"insurer"）。

- **劳合社术语**：如文件提及劳合社市场，使用劳合社专用术语："slip"（而非"placing document"）、"underwriter"（此语境中而非"insurer"）、"managing agent"、"syndicate"、"Names"、"bureau"。劳合社不仅是一家保险公司；它是一个由独立承保辛迪加组成的市场。

- **W&I 保险**：并购/交易语境中的专项产品。详细的陈述与保证术语交叉参考并购术语词典。W&I 承保交割后卖方陈述与保证的违约，保护买方。

- **重大未披露 / 最大诚信义务（Uberrimae Fidei）**：这些是保险的基础原则。未披露重大事实可能导致撤销合同（合同自始无效）。这比一般合同法更为严格。

- **诉讼时效 / Prescription**：时限因法域和索赔类型而异。英国普通法：合同索赔通常为 6 年，人身伤害为 3 年。欧盟大陆法系法域（"prescription"）：通常为 3 年。始终指明法域。

- **国家保险立法**：翻译对国内保险法典或监管框架的援引时，首次出现时提供法规名称的官方英文译名，括号内附原文名称。子词典提供源语言对应关系。

- **国家保险监管机构**：保留国内监管机构缩略语（如英国 PRA/FCA；德国 BaFin；法国 ACPR），首次出现时予以解释。子词典提供源语言对应关系。
