# 诉讼与和解术语词典

争议性法律工作的标准英语术语：民事诉讼、行政诉讼、刑事诉讼，以及和解协议、免责与弃权、同意令、争议解决条款、调解与仲裁。

本综合词典涵盖诉讼的完整生命周期（起诉→诉状→庭审→判决→上诉→执行），以及用于在最终判决前解决争议的交易性文书（和解协议、免责契据、同意令）。许多术语（judgment、costs、jurisdiction、enforcement）在两种语境中都会出现——应将其视为同一术语体系。

## 核心和解术语

| 正确英文术语 | 用法/含义 | 避免使用 |
|---|---|---|
| settlement agreement | 当事人之间解决争议的有约束力协议 | accord、settlement contract |
| settlement record | 证明已达成和解的文件（例如在调解中达成） | conciliation record（范围更窄） |
| deed of settlement | 正式签署的契据，记载和解条款 | settlement deed、settlement instrument |
| general release and settlement | 全面和解，消灭所有相关请求权 | settlement only、release only |
| release and waiver | 相互免除请求权并放弃进一步权利 | waiver and release（英国法更倾向于 release and waiver） |
| release / discharge | 正式免除责任或义务 | waiver（属不同概念） |
| waiver of claims | 自愿放弃已知的请求权 | release of all claims（范围更宽） |
| mutual release | 双方/多方相互免责 | single release、unilateral release |
| receipt and discharge | 收款确认并同时解除义务 | receipt and release |
| full and final release | 完全免责，阻却就同一标的提出任何进一步请求 | final release、complete release |
| full and final settlement | 完整且有约束力的和解；不得再提出任何请求 | complete settlement、final settlement |
| nothing further to claim | 双方相互确认无任何进一步应付款项 | nothing further owing、no further claims |
| mutual concessions | 双方相互让步（大陆法系所要求） | concessions、mutual give-and-take |
| settlement amount | 和解协议约定的金额 | settlement sum（无限定——可接受但不够精确） |
| settlement consideration | 为换取和解而提供的对价（范围宽于金钱——可包括非金钱承诺，如免责、保密、联合声明） | consideration（无限定——在合同成立意义上存在歧义） |
| settlement payment | 依据和解协议支付的款项 | settlement sum（仅指金额） |
| settlement instalment | 按和解协议分期支付的款项 | instalment payment |
| satisfaction | 正式确认请求权/义务已获满足 | satisfaction and release |
| full and final | 全面且终局（描述和解的质量） | full、final |
| accord and satisfaction | 以提供新对价换取免责的和解 | accord、satisfaction |
| without prejudice | 以陈述不可采纳为基础进行的法律和解谈判 | privileged discussion |
| without prejudice save as to costs | 和解谈判后仍可就费用问题争辩（英国） | without prejudice only |
| Tomlin order | 争议条款保密的同意令（英国程序） | consent order（泛称） |
| no admission of liability | 和解条款，声明和解不构成对过错的承认 | settlement without admission、non-admission clause |
| entire agreement | 确认和解协议构成就标的物达成的全部协议的条款 | complete agreement、whole agreement |
| res judicata | 已经裁判的事项不得再行审理的法律原则 | judgement bar、final determination |
| Part 36 offer | 依据《民事诉讼规则》第 36 部分（CPR Part 36）提出的正式和解要约（英格兰与威尔士），若庭审结果未优于该要约将自动产生费用后果；英国特有的程序概念 | Without prejudice offer（机制不同） |
| Calderbank offer | "不损害权益但保留费用争辩权"（save as to costs）的和解要约（用于仲裁及不适用 Part 36 的法域） | Without prejudice offer（不够精确） |
| penalty clause | 对违约课以过高款项的条款（普通法下若非对损失的真实预估则不可执行）；大陆法系法域可能执行违约金条款 | Punitive clause（不够标准） |
| set-off | 将一方向另一方所负之债务与其应得之债权相互抵销，减少净应付款项的权利；与金融市场的净额结算（netting）不同 | Offset（不够正式）；Compensation（大陆法系术语，英文中含义含糊） |
| compromise / compromise agreement | 通过相互让步解决争议的协议；在英国劳动法中，自 2013 年起已由 settlement agreement 取代 | Transaction（在多种源语言中是大陆法系假朋友） |

## 争议解决术语

| 正确英文术语 | 用法/含义 | 避免使用 |
|---|---|---|
| dispute resolution | 所有争议解决方式的总称 | conflict resolution（可能仅指调解） |
| dispute | 当事人之间的分歧或争议 | conflict、disagreement（不够正式） |
| litigation | 法院诉讼；在法院进行的正式争议解决 | court proceedings、legal action |
| legal proceedings | 在法院启动的正式程序 | court action、legal action |
| action / claim | 在法院提起的法律请求 | suit（古旧）、cause of action |
| counterclaim | 被告在同一程序中针对原告提出的请求 | cross-claim（程序变体） |
| third-party claim | 一方在既有程序中针对第三人提出的请求 | third-party notice、interpleader |
| defence / objection | 否认责任或提出法律异议的答辩 | answer（美国程序变体） |
| preliminary objection | 在庭审前提出的管辖、可受理性或程序瑕疵异议 | jurisdictional objection |
| jurisdiction | 法院审理案件的权力（实质性和对人） | competence（大陆法系术语） |
| competent court / forum | 对争议拥有管辖权的法院 | proper forum、forum of competence |
| arbitration clause | 要求争议通过仲裁解决的合同条款 | submission to arbitration（属不同概念） |
| submission to arbitration | 同意将争议提交仲裁的协议（可于争议发生后达成） | arbitration agreement、compromis |
| arbitral award | 仲裁员或仲裁庭作出的裁决 | award、arbitral decision |
| arbitration | 由中立第三方进行的私人争议解决 | arbitral proceedings |
| sole arbitrator | 被指定解决争议的单一中立人 | single arbitrator |
| arbitral tribunal | 仲裁员组成的合议庭（通常为 3 人） | arbitration panel、tribunal |
| arbitration rules | 规范仲裁程序的规则（ICC、UNCITRAL 等） | rules of arbitration、arbitral rules |
| seat of arbitration | 决定适用法律与执行事宜的仲裁法律所在地/地点 | arbitration seat、place of arbitration |
| mediation | 由中立第三方协助的协商 | conciliation（部分法域含义重叠但不同） |
| conciliation | 中立调解人提供无约束力建议的协助和解程序 | mediation（大致同义） |
| mediator | 协助和解谈判的中立第三方 | conciliator（当其提供建议时） |
| mandatory mediation attempt | 诉讼/仲裁前必须尝试调解的要求（程序性） | compulsory mediation、stay for mediation |
| assisted negotiation | 有中立协助人的协商（不如调解正式） | facilitated negotiation |
| multi-tier dispute resolution clause | 要求先协商、再调解、后仲裁/诉讼的逐级升级条款 | escalation clause、tiered dispute resolution |

## 民事诉讼——当事人、诉状与程序

| 正确英文术语 | 用法/含义 | 避免使用 |
|---|---|---|
| civil proceedings | 私人主体之间就私法权利（合同、侵权、财产、家庭）进行的法院程序 | civil cause（直译）、civil case（不够正式） |
| claimant（英国）/ plaintiff（美国） | 提起民事诉讼的一方 | actor（大陆法系直译）、applicant（保留给行政/司法审查） |
| defendant | 被提起民事诉讼的一方 | respondent（保留给上诉/行政程序）；convenuto（不得直译） |
| respondent | 对申请、上诉或仲裁作出回应的一方（非普通民事请求） | defendant（一审民事请求中应使用 defendant） |
| joinder | 将其他当事人或请求加入既有程序 | intervention（见下——属不同概念） |
| intervener / intervening party | 被准许加入进行中程序以保护自身利益的第三方 | joinder（属不同概念——程序性加入） |
| claim form / particulars of claim（英国）/ complaint（美国） | 载明请求内容的启动民事诉讼的文件 | citation（大陆法系直译）、petition（保留给特定程序） |
| statement of case / pleadings | 当事人陈述案情的正式书面陈述 | memorials（投资条约仲裁）、briefs |
| statement of claim | 原告对请求的正式陈述 | petition、request for judgment |
| defence / statement of defence（英国）/ answer（美国） | 被告的正式答辩 | response、objection（仅限初步异议） |
| reply | 原告对答辩的回应 | rejoinder（见下——属更后阶段） |
| rejoinder | 被告对 reply 的进一步回应 | surrejoinder（美国；很少使用） |
| counterclaim / cross-claim | 被告在同一程序中针对原告提出的请求 | counter-action、reconventional claim（大陆法系直译） |
| set-off（作为抗辩） | 作为抗辩提出的交叉债权，减少或消灭原请求 | counterclaim（属不同概念——反请求是独立的） |
| amendment of pleadings | 经法院许可对诉状进行正式修改 | variation of claim（不精确） |
| service of process / service of proceedings | 向对方当事人正式送达法院文件 | notification（在英文程序中不够精确） |
| substituted service / alternative service | 以标准方式以外的方法送达（例如通过电子邮件、法院令状） | alternative notification |
| cross-border service | 向位于另一法域的当事人送达程序文件（例如《海牙送达公约》、欧盟送达条例） | international notification |
| joinder of parties | 将其他当事人加入程序的程序 | integration of parties（直译） |
| case management conference (CMC) | 法院就案件审理方式作出指示的程序性听审（英国；许多法域类似） | preliminary hearing（属不同概念） |
| directions | 法院规范案件程序性进行的命令 | instructions、procedural orders |
| disclosure（英国）/ discovery（美国） | 要求当事人识别并提交相关文件的程序 | disclosure of documents、document production |
| inspection of documents | 一方查阅对方披露文件的权利 | examination of documents |
| privilege / legal professional privilege | 对特定类别通信（如法律意见、诉讼）免于披露的保护 | professional secrecy（大陆法系直译） |
| witness statement | 附真实声明（statement of truth）签署的证人书面陈述 | witness declaration |
| expert report | 受指定专家就其专业领域事项出具的书面报告 | technical report（过于笼统） |
| court-appointed expert | 法院指定的独立专家（大陆法系法域常见） | judicial expert（直译） |
| single joint expert (SJE) | 由双方共同指定的单一专家（英国 CPR 实务） | joint expert（不够精确） |
| party-appointed expert | 一方指定出具证言的专家 | technical consultant（大陆法系直译） |
| evidence | 用于证明或反驳争议事实的材料 | proofs（自法语/意大利语直译） |
| documentary evidence | 由文件构成的证据 | document proofs |
| oral evidence / testimony | 证人在法庭上提供的证言 | verbal evidence |
| examination-in-chief / direct examination | 一方对本方证人的询问 | initial examination |
| cross-examination | 对方当事人对证人的询问 | contested examination |
| re-examination | 交叉询问后原当事人对证人的进一步询问 | re-direct（美国） |

## 民事诉讼——庭审、判决与救济

| 正确英文术语 | 用法/含义 | 避免使用 |
|---|---|---|
| trial / hearing | 法院裁定案件的实质性听审 | final audience（直译） |
| adjournment | 将听审延期至较后日期 | suspension of hearing |
| judgment（英国）/ judgement / decision | 法院确定当事人权利义务的正式裁定 | sentence（大陆法系直译——保留给刑事） |
| reasoned judgment | 载明法院推理的判决 | motivated judgment（直译） |
| interim judgment / interlocutory judgment | 在最终裁定前就初步问题作出的判决 | partial judgment |
| default judgment | 对未提交答辩状或未出庭的一方作出的判决 | contumacious judgment（直译） |
| summary judgment | 不存在真实胜诉/抗辩前景时不经完整庭审作出的判决 | abbreviated judgment |
| declaratory judgment / declaration | 宣告当事人权利或地位的判决 | declarative judgment |
| final judgment | 最终确定程序中实体问题的判决 | definitive judgment（直译；可接受但不够地道） |
| consent order / judgment by consent | 记载当事人商定的和解条款的法院命令 | agreed judgment |
| damages | 对损失支付的金钱补偿 | indemnities（易混淆——保留给赔偿条款） |
| general damages | 对非金钱损失（痛苦、折磨、生活便利丧失）的赔偿 | — |
| special damages | 对特定、可量化金钱损失的赔偿 | — |
| nominal damages | 权利受侵害但无实质损失时的象征性赔偿 | symbolic damages |
| aggravated damages | 反映被告行为方式的赔偿 | — |
| exemplary / punitive damages | 旨在惩罚被告的赔偿（限于部分普通法案件） | — |
| costs | 判给胜诉方的法律费用及支出 | expenses（范围更窄） |
| costs follow the event | 败诉方承担胜诉方费用的默认规则 | costs to the victor（口语化） |
| indemnity costs / costs on the indemnity basis | 因一方不合理行为而对其加重判处的费用 | — |
| specific performance | 要求履行合同义务的衡平救济 | enforced performance（直译） |
| injunction | 要求当事人作为或不作为的法院命令 | interdict（苏格兰/荷兰语直译） |
| mandatory injunction | 要求作出积极行为的禁令 | performance injunction |
| prohibitory injunction | 禁止某一行为的禁令 | negative injunction |
| interim injunction / interlocutory injunction | 庭审前颁发的禁令 | preliminary injunction（美国；可接受） |
| freezing order / freezing injunction（旧称 Mareva） | 判决前冻结一方资产的命令 | asset-freezing order |
| search order（旧称 Anton Piller） | 准许进入场所检查并扣押证据的命令 | inspection order（过于宽泛） |
| rectification | 纠正未能反映当事人真实协议的书面文书的衡平救济 | correction（过于随意） |
| rescission | 因虚假陈述、胁迫等撤销合同的衡平救济 | annulment（保留给特定法定撤销） |
| restitution | 要求返还不当取得利益的救济 | restitution of the indebitum（直译） |
| stay of proceedings | 中止法院程序的命令 | suspension（含义含糊） |
| strike out | 法院因程序或实体瑕疵而驳回请求或答辩的权力 | dismissal（用于实体判决的驳回） |
| dismissal of claim | 驳回请求（通常经听审后） | rejection of claim |

## 民事诉讼——上诉与执行

| 正确英文术语 | 用法/含义 | 避免使用 |
|---|---|---|
| appeal | 对下级法院裁判提出异议的程序 | recourse（大陆法系直译） |
| appellant | 提起上诉的一方 | appealing party |
| respondent (on appeal) | 对上诉作出回应的一方 | appealed party |
| grounds of appeal | 上诉中提出的具体法律或事实异议 | reasons of appeal |
| permission to appeal / leave to appeal | 提起上诉所需的司法许可（必要时） | authorisation to appeal |
| notice of appeal | 启动上诉的文件 | appeal declaration |
| appeal on a point of law | 仅限于法律错误的复审（不再重新审理事实） | appeal of law（直译） |
| cassation | 在大陆法系中，向最高法院提出的限于法律错误的复审；非普通法概念——可能需要译者注 | — |
| Court of Cassation / Supreme Court | 大陆法系审查法律问题的最高法院 | cassation court（保留大写） |
| setting aside / annulment of judgment | 正式撤销判决（例如因根本性程序瑕疵） | vacatur（美国特有） |
| revision / retrial | 因新证据而重新开启程序（普通法上范围狭窄；大陆法系中范围较宽） | review（含义含糊） |
| final and binding judgment | 不得上诉或上诉期限已届满的判决 | res judicata（是原则，不是判决本身） |
| enforcement / execution | 执行判决或裁决的程序 | execution of judgment（可接受但不够正式） |
| writ of execution | 授权执行判决的法院文件 | execution title（大陆法系直译） |
| enforceable title | 具有直接执行效力的文书（如判决、公证文书）——大陆法系概念；英文中需要解释 | executive title（直译） |
| recognition and enforcement | 外国判决或仲裁裁决在另一法域产生效力的程序 | exequatur（大陆法系术语；可保留并附解释） |
| attachment / freezing order | 查封或冻结资产的法院命令 | seizure（范围更窄） |
| charging order | 以判决债务人于土地或证券中的权益设定负担以保证付款的命令 | — |
| third-party debt order / garnishee order | 将第三人对判决债务人所负债务改向判决债权人支付的命令 | garnishment order（美国） |
| order for possession | 将财产占有交付一方的法院命令 | repossession order |
| judgment creditor | 有权执行判决的一方 | — |
| judgment debtor | 可能被强制执行判决的一方 | — |
| insolvency / bankruptcy proceedings | 处理破产的法院监督程序 | receivership（保留给特定普通法救济） |
| receiver | 法院指定的资产管理人 | — |

## 行政诉讼

| 正确英文术语 | 用法/含义 | 避免使用 |
|---|---|---|
| administrative proceedings | 涉及行使公共权力/政府行为的程序 | administrative cause（直译） |
| administrative court（英国）/ administrative tribunal / administrative law court | 审理公法事务的专门法院或裁判所（如意大利 TAR/Consiglio di Stato、法国 Conseil d'État、德国 Verwaltungsgericht） | administrative jurisdiction（直译——保留给管辖意义） |
| judicial review | 对公共机构的决定、行为或不作为之合法性提出的异议 | control of legitimacy（直译） |
| application for judicial review | 启动司法审查的程序机制 | judicial review recourse |
| applicant (judicial review) | 提起司法审查申请的一方 | claimant（保留给普通民事） |
| interested party | 对司法审查具有充分利害关系的一方 | counter-interested party（"controinteressato"的直译） |
| public authority / public body | 受行政法约束的决策者（如政府部门、机构、监管机关） | public administration（在大陆法系语境中可接受但更宽泛） |
| administrative act / administrative decision | 公共机构作出并产生法律效果的决定、措施或行为 | administrative provision（"provvedimento"的直译） |
| regulatory act / regulation | 公共机构作出的一般适用的行为 | normative act（直译） |
| statutory instrument | 委任立法行为（英国术语） | secondary legislation（范围更宽） |
| ultra vires | 超越公共机构法定权限的行为 | excess of power（美国：可接受；英国程序语言：ultra vires） |
| illegality | 公共机构超越法定权限行事时的审查事由 | unlawfulness（范围更宽） |
| irrationality / Wednesbury unreasonableness | 决定不合理到任何合理机关都不会作出时的审查事由 | absurd decision |
| procedural impropriety | 未遵循正当程序（如磋商、自然正义）时的审查事由 | procedural unfairness（范围更宽） |
| proportionality | 审查事由（欧盟/欧洲人权公约及许多大陆法系），要求措施与其目的相称 | — |
| legitimate expectation | 保护公共机构所诱导期望的原则 | reliance expectation |
| duty to give reasons | 公共机构说明决定理由的义务 | duty of motivation（直译） |
| annulment of administrative act | 法院撤销行政行为 | cassation of the act（直译） |
| suspension of administrative act | 听审前中止行政行为效力的临时命令 | precautionary suspension |
| quashing order / quashing of decision（英国：quash） | 撤销行政决定的法院命令 | cancellation（过于宽泛） |
| mandatory order（英国）/ mandamus（美国） | 要求公共机构作为的法院命令 | injunction to perform |
| prohibiting order（英国）/ prohibition | 阻止公共机构违法作为的法院命令 | — |
| declaration of unlawfulness / declaration of invalidity | 司法宣告某一行为或决定违法 | declaration of illegitimacy |
| administrative appeal / hierarchical appeal | 司法审查前在行政层级内部的申诉 | gerarchico recourse（直译） |

## 注释

- **Settlement 与 transaction 的歧义**：许多源语言用同一个词表示"settlement"（争议的法律解决）和"transaction"（商业交易）。由语境决定：在争议解决语境中，始终使用 "settlement"；在商业语境中，使用 "transaction"。

- **Full and final settlement**：部分源语言对"完整且阻却一切进一步请求的和解"有专门术语（往往口语化）。正确的英文是 "full and final settlement" 或 "complete release"。

- **"Accord and satisfaction"**：普通法原则，以提供新对价换取既有请求权的免除。在大陆法系中，对应概念是 "settlement"，其效力要件不同（例如相互让步）。仅在普通法语境中使用 "accord and satisfaction"。

- **"Without prejudice" / "without prejudice save as to costs"**：英国诉讼特权，保护和解沟通不被采纳为证据。"Without prejudice save as to costs" 允许在和解谈判结束后仍保留费用问题的争辩空间。在英国以外语境中，须澄清是否存在对等特权。

- **"Tomlin order"**：英国程序，争议条款保存在另行封存的文件中保密，主要协议提交法院存档。通用对应词是 "consent order"，但指称英国特有程序时应使用 "Tomlin order"。

- **"No admission of liability"**：标准和解条款，明确和解不构成对过错或责任的承认。在许多法域中，对在相关程序中保留抗辩至关重要。

- **同意令（Consent orders）**：在普通法法域，和解可以 "consent order"（经法院批准）形式记载。在大陆法系法域，对应形式是经法院批准的和解或提交法院存档的调解记录。子词典提供源语言映射。

- **和解语境中的 "Entire agreement"**：确认和解协议构成关于该争议的全部协议并取代所有先前谈判、理解和附属函件的条款。对可执行性至关重要。

- **"Sentence"——假朋友**：许多大陆法系源语言使用 "sentence" 的同源词指称任何终局司法裁判（民事、行政或刑事）。英文中，"sentence" 仅用于刑事诉讼（定罪后判处的刑罚）。民事和行政语境中应使用 "judgment"。这是最常见的直译陷阱之一。

- **"Imputation" / "imputato"——假朋友**：大陆法系中，被告人常被称为 "imputato"（意大利语）、"imputé"（法语）等，动词 "to impute" 表示"指控"。在英文刑事程序中，正确术语是 "defendant" / "accused" 和 "to charge"（名词："charge" 或 "indictment"）。切勿直译为 "imputation" / "imputed"。

- **"Legitimate interest" 与 "legitimate expectation"**：这是两个常被混淆的独立概念。"Legitimate interest"（interesse legittimo）是大陆法系行政法中关于起诉资格的概念，普通法无直接对应。"Legitimate expectation" 是保护公共机构所诱导期望的英国法原则。不得混为一谈。

- **刑事诉讼中的附带民事当事人（Civil party）**：被害人加入刑事诉讼索赔损害赔偿的大陆法系概念（"partie civile"、"parte civile"、"Nebenkläger"）在普通法中没有直接对应（美国有"被害人影响陈述"；英国有独立的民事诉讼）。在技术性区分重要时，保留源语言术语并加译者注。

- **"Court of cassation"**：大陆法系最高法院（Cour de cassation、Corte di Cassazione、Tribunal Supremo）仅审查法律问题，不重新审理事实。这与可酌情考虑事实的英国最高法院和美国最高法院不同。保留专有名称（"Court of Cassation"），在程序角色重要时加译者注。

- **"Judicial review" 与 "appeal"**：英国行政法中，"judicial review" 是独立的公法程序，审查决定的合法性（而非其是非曲直）。大陆法系中，行政法院往往同时审查合法性与是非曲直——翻译时须谨慎，若源文本涉及实体审查，考虑译为 "administrative appeal" 或加译者注。

- **Exequatur / recognition and enforcement**：许多大陆法系使用 "exequatur" 指外国判决/裁决的承认与执行。在英文法律写作中，首选 "recognition and enforcement"；仅在程序被明示以此命名（如欧盟条例）时才保留 "exequatur"。
