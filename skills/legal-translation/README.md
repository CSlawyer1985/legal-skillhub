一个适用于任何需要将法律文件翻译为可出版级英文的人士的技能。将任何语言的 Word 文件交给它，即可获得格式保留的英文 .docx 文件，质量显著高于例如 Legora 的 DeepL 工具。

独特功能：

* 该技能内置英文通用词典以及按语言区分的子词典（短语手册），涵盖并购、知识产权、IT/SaaS、金融、税务、诉讼、劳动法等领域。11 种语言均有完整的子词典覆盖，包括西班牙语、德语、法语和中文；其他语言的翻译效果也非常好。
* 接受或拒绝修订时，修订追踪可正确读取，错别字会被合并消除。
* 定义按字母顺序重新排序。
* 页眉、页脚、脚注和批注均被翻译。
* 默认翻译为英式英语，也可按需翻译为美式英语。
* 全程设置质量门禁。
* 与更简单的技能相比，本技能耗时以分钟计而非以秒计，体积也更大，但整体质量更高。
