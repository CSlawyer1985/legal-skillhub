# 意大利公共采购子词典

意大利特有的公共采购术语和引用。这些主体、法规和程序为意大利特有，应在主词典中译为英文。

## 意大利特有主体与机构

| 意大利语术语 | 英语对应 | 注释 |
|---|---|---|
| ANAC | ANAC (Italian National Anti-Corruption Authority) | 意大利监管机构；依第190/2012号法律设立。首次提及时解释为“负责采购监督和腐败预防的意大利监管机构”。 |
| SOA / attestazione SOA | SOA certification / works qualification | 意大利特有的建筑承包商认证体系。SOA = Società di Attestazione（认证机构）。类别依合同价值从 I 至 VIII。 |
| categoria e classifica SOA | SOA category and classification | 意大利对建筑工程承包商能力的评定体系。 |
| Codice dei Contratti Pubblici (D.Lgs. 36/2023) | Public Contracts Code (Legislative Decree No. 36/2023) | 意大利主要公共采购立法，自2023年1月1日起生效。实施指令 2014/24、2014/25、2014/23。此前法典为 D.Lgs. 50/2016。 |
| D.Lgs. 50/2016 | Legislative Decree 50/2016 (superseded) | 意大利前公共采购法典。核查文件日期以确定适用哪一个。 |
| Certificazione Antimafia | Anti-mafia certification | 意大利要求由反黑手党部门出具的、确认无黑手党关联的证明。部分公共工程合同需要。 |

## 注释

- **ANAC 指南**：意大利 ANAC 发布采购规则指南和解释。可能比欧盟最低标准更严格。

- **SOA 体系**：意大利 SOA 认证对意大利大多数公共工程合同为强制性，但为意大利特有。翻译意大利文件时，首次使用务必解释。

- **RUP 指定**：意大利法律要求每项采购设一名项目经理（RUP）。该角色无直接普通法对应；描述具体职责而非翻译缩写。

- **Decreto-legge 与 Decreto legislativo**：意大利紧急法令（“decreto-legge”）是临时性的，必须转化为法律；立法法令（“decreto legislativo”）用于实施指令。务必指明适用哪一种。

- **内部提供**：“Teckal 豁免”（源自欧盟法院判例法，而非意大利法律）允许公共机构与其他公共机构订立合同而无需采购程序。常与意大利法律下的“affidamento in house”概念混淆。

- **Ricorso / 上诉**：意大利行政法使用“ricorso”（上诉/复议），由专门法院（TAR = 地区行政法院）审理。英文合同中译为“procurement challenge”或“review proceedings”。
