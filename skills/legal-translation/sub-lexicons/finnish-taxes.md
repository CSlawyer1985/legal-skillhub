# 芬兰税法——分词典

与 `references/taxes.md`（主税法词典）和 `sub-lexicons/finnish-corporate-ma-jv.md`（公司法/并购接口）配套使用。

本分词典涵盖芬兰税法。奥兰群岛的特殊地位（欧盟关税/消费税例外、某些目的下排除在增值税领土之外）在相关处予以标注。

## 1. 主要税种——术语与代码

| 芬兰语术语 | 中文释义（英文对应） |
|---|---|
| Yhteisövero | 公司所得税（corporate income tax，CIT） |
| Laki elinkeinotulon verottamisesta (EVL) | 《营业所得征税法》（Business Income Tax Act，《营业所得税法》，简称“BITA”） |
| Tuloverolaki (TVL) | 《所得税法》（Income Tax Act） |
| Maatilatalouden tuloverolaki (MVL) | 《农业所得税法》（Agricultural Income Tax Act） |
| Arvonlisäverolaki (AVL) | 《增值税法》（Value Added Tax Act） |
| Arvonlisävero (alv) | 增值税（value added tax，VAT） |
| Ennakkoperintälaki | 《预缴法》（Prepayment Act，工资/股息的源泉征收） |
| Laki rajoitetusti verovelvollisen tulon verottamisesta (LähdeveroL) | 《非居民所得征税法》（Non-Resident Income Taxation Act，源泉税法） |
| Lähdevero | 源泉预提税（withholding tax at source） |
| Perintö- ja lahjaverolaki | 《继承与赠与税法》（Inheritance and Gift Tax Act） |
| Varainsiirtoverolaki | 《转让税法》（Transfer Tax Act，不动产和证券） |
| Varainsiirtovero | 转让税（transfer tax） |
| Kiinteistöverolaki | 《不动产税法》（Real Estate Tax Act） |
| Kiinteistövero | 不动产税（real estate tax，市级） |
| Valtionvero | 国家（所得）税（state (income) tax） |
| Verotusmenettelylaki (VML) | 《税务评估程序法》（Tax Assessment Procedure Act） |
| Laki oma-aloitteisten verojen verotusmenettelystä (OVML) | 《自行申报税款程序法》（Self-Assessed Taxes Procedure Act） |
| Verohallinto | 芬兰税务局（Finnish Tax Administration，Vero） |
| Valtiovarainministeriö (VM) | 财政部（Ministry of Finance） |

译者注：**yhteisövero**（字面意为“实体税”）即 CIT——译为“corporate income tax”或“CIT”。不要直译为“community tax”。缩写 **EVL**（Laki elinkeinotulon verottamisesta）即《营业所得税法》，是主要的法人税实体法典；**TVL**（Tuloverolaki）是适用于个人和非营业所得的《所得税法》；**MVL** 适用于农业所得。芬兰税法的特色在于三种平行的所得来源（EVL/TVL/MVL）——务必标注某一所得项目适用哪一制度。

## 2. 直接税——税基、税率、分配

| 芬兰语术语 | 中文释义（英文对应） |
|---|---|
| Verotettava tulo | 应税所得（taxable income） |
| Veronalainen tulo | 可课税所得（assessable income） |
| Vähennyskelpoinen meno | 可扣除费用（deductible expense） |
| Vähennyskelvoton meno | 不可扣除费用（non-deductible expense） |
| Veropohja | 税基（tax base） |
| Elinkeinotulo | 营业所得（business income，EVL） |
| Henkilökohtainen tulonlähde | 个人所得来源（personal income source，TVL） |
| Maatalouden tulonlähde | 农业所得来源（agricultural income source，MVL） |
| Pääomatulo | 资本所得（capital income，统一税率，30%/超过 3 万欧元为 34%） |
| Ansiotulo | 劳动所得（earned income，国家累进 + 市级统一税率） |
| Yhteisön tulovero | 公司所得税（corporate income tax，2014 年起统一 20%） |
| Listatun yhtiön osinko | 上市公司股息（dividend from listed company） |
| Listaamattoman yhtiön osinko | 非上市公司股息（dividend from unlisted company） |
| Nettovarallisuus | 净资产（net assets，非上市公司节税股息的计算基础） |
| Matemaattinen arvo | 数学价值（mathematical value，非上市公司股息的每股基础） |
| Huojennettu osinko | 优惠股息（relieved/tax-favoured dividend，非上市有限公司净资产值的最高 8%，其中 25% 应税，上限 15 万欧元） |
| Tuloverolain mukainen osinko | TVL 制度股息（TVL-regime dividend，个人持有上市公司股份的 85% 应税） |
| Käyttöomaisuusosakkeet (KO-osakkeet) | 固定资产股份（fixed-asset shares，EVL 6b 节下的参股免税） |
| EVL 6b § | EVL 第 6b 节（参股免税，适用于股份处置） |
| Menojäännöspoisto | 余额递减折旧（declining-balance depreciation，池化固定资产） |
| Hankintamenon jaksotus | 取得成本的分摊（allocation of acquisition cost） |
| Varaus (toimintavaraus, jälleenhankintavaraus) | 准备金/储备（reserve/provision，经营准备金、重置准备金） |
| Konserniavustus | 集团资助（group contribution，1986 年《税务上集团资助法》） |
| Tappiontasaus | 亏损救济（loss relief，向前结转 10 年；不允许向后结转；EVL 119 节） |
| Omistajanvaihdos ja tappion menettäminen | 所有权变更与亏损丧失（change of ownership and loss forfeiture，直接/间接变更 >50%；TVL 122 节） |
| Poikkeuslupa tappioiden käyttöön | 亏损使用特别许可（special permission to use losses，控制权变更时由芬兰税务局裁量许可） |

译者注：**konserniavustus** 是芬兰特有的机制（无合并纳税制度，但 ≥90% 关联的芬兰公司之间可通过集团资助实现盈亏转移）——译为“group contribution”。其要求：(i) 两公司均为芬兰有限公司，(ii) 整个纳税年度持股 ≥90%，(iii) 最短持有期 5 年，(iv) 双方账簿作相应记账——手续严格。**EVL 6b 节参股免税**适用于固定资产股份的处置（持股 ≥10%、持有 ≥1 年、经营性公司）——译为“participation exemption (EVL 6b §)”。

## 15. 注释与注意事项

- **引用格式。** 芬兰法律引用为*法律名称（缩写）条款节*，如 *EVL 6b §*、*TVL 122 §*。条款使用 § 符号，有时进一步按款（momentti）细分（如 *VML 31 § 2 mom.*）。英文翻译中，首次出现时以加注形式呈现为“EVL 6b §”（“《营业所得税法》第 6b 节”），此后用“EVL § 6b”。空间允许时保留 § 符号。
- **KHO 年鉴案例。** 引用为 *KHO 2023:45*（年鉴/已报道）或 *KHO 15.2.2024 T 456*（按日期和登记号）。自 2013 年起也使用 ECLI 标识符（ECLI:FI:KHO:...）。
- **平行制度。** EVL/TVL/MVL 三制度并存在欧洲是独一无二的。公司通常对营业所得适用 EVL；但非营业投资、某些不动产和农业所得可能落入 TVL 或 MVL，适用不同的亏损抵补和税率规则。务必标注适用制度。
- **2024 年增值税上调。** 标准增值税于 2024 年 9 月 1 日从 24% 升至 25.5%。其他 2024-2025 年改革：某些商品（糖果）的 10% 轻减税率移至 14%，书籍/药品的 14% 轻减税率分别维持在 14%/10%（核对最新税率表）。
- **2024 年转让税下调。** 不动产转让：4% 降至 3%；证券（住房/不动产公司股份除外）：1.6% 降至 1.5%；住房公司股份：2% 降至 1.5%。对某些交易追溯至 2023 年 10 月 12 日。标注转让日期。
- **第二支柱。** 《大型集团最低税法》于 2024 年 1 月 1 日（2023 年 12 月 31 日以后开始的财年）起对 QDMTT 和 IIR 施行；UTPR 自 2025 年 1 月 1 日起。使用“minimum top-up tax”（最低补足税）。
- **集团资助的严格性。** konserniavustus 制度形式主义严格：两公司均须为芬兰 *osakeyhtiö*（股份公司）/*osuuskunta*（合作社），整个纳税年度持股 ≥90%，最短持有期 5 年，且资助必须在同一纳税年度**由支付方扣除并由接收方计入收入**。任何形式缺陷均使资助失效。译者应保留“group contribution”，不要译作“consolidation”（合并纳税）。
- **个人出境税。** 自 2023 年 1 月 1 日起引入（TVL 30a 节），适用于芬兰居住满 10 年中的 ≥4 年后移居海外、持有重要股份（股份/证券未实现收益 >50 万欧元）的个人。
- **研发组合扣除。**《研发组合扣除法》（2023 年起施行，在先前 2021 年额外扣除基础上扩展）提供 50% + 45% 的增量结构。译为“combined R&D deduction”。
- **易混词（false friends）。**
  - *Vero* → tax（不是“blood”——瑞典语 *blod*/芬兰语 *veri* 与其无关）。
  - *Vero + hallinto* → tax administration（税务行政）。
  - *Osinko* → dividend（股息，不是“portion”）。
  - *Lähdevero* → withholding tax at source / source tax（源泉预提税）。
  - *Veronalainen* → subject to tax / assessable（应税的）。
  - *Veronkierto* → tax avoidance/evasion（依语境；芬兰法律不严格区分——*veronkiertoa* 同时涵盖滥用性避税和逃税；译为“tax avoidance”，“tax evasion”保留给刑事语境）。
  - *Yhtiövero* 与 *yhteisövero* → 较旧的 *yhtiövero* 和当前的 *yhteisövero* 均译为“CIT”；现代用法优先使用 *yhteisövero*。
  - *Rajoitettu verovelvollisuus* → limited tax liability（有限纳税义务，非居民），不是“restricted”。
  - *Peitelty osinko* → disguised dividend / constructive dividend（变相股息）。
  - *Huojennus* → relief/mitigation（优惠/减轻，用于继承、传承和税款增加语境）；不是价格意义上的“reduction”。
  - *Valtionvero* → state (income) tax（国家所得税）；区别于 *kunnallisvero*（市镇税）。
- **双语司法辖区。** 芬兰官方双语（芬兰语/瑞典语）。当源文本为瑞典语（如来自奥兰群岛）时，从瑞典语按瑞典税法惯例翻译，但注明适用的是芬兰税制。关键对应：*samfundsskatt* = yhteisövero = CIT；*inkomstskatt* = tulovero；*lag om beskattning av inkomst av näringsverksamhet (NärSkL)* = EVL；*förskottsuppbörd* = ennakkoperintä。
- **奥兰群岛增值税特殊地位。** 奥兰群岛在国内属于芬兰增值税管辖范围，但在共同体内部目的上处于欧盟增值税领土之外。奥兰群岛与芬兰本土之间的供应在欧盟增值税汇总申报和远程销售目的上按第三国流动处理。明确标注涉及奥兰群岛的增值税问题。
