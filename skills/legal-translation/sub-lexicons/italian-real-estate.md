# 意大利语房地产分术语词典

意大利特有的房地产术语和参考资料。这些实体、法规和地籍/行政系统是意大利特有的，应在主词典中译为英文。

## 意大利核心房地产术语

| 意大利语术语 | 英文对应词 | 注释 |
|---|---|---|
| Contratto di locazione | Lease / lease agreement（租赁合同） | 任何租赁的意大利语通用术语。 |
| Locazione commerciale | Commercial lease（商业租赁） | 经营场所的租赁。 |
| Locazione abitativa | Residential lease（住宅租赁） | 住宅的租赁；根据意大利法律可能受特别保护。 |
| Locazione transitoria | Short-term lease（短期租赁） | 临时租赁，通常少于 12 个月；意大利法律下有单独保护。 |
| Contratto di affitto | Lease / tenancy agreement（租赁/租约协议） | contratto di locazione 的同义词。 |
| Contratto di compravendita immobiliare | Property purchase agreement / sale and purchase agreement（房产购买协议/买卖协议） | 房产买卖的合同。 |
| Atto di compravendita | Deed of sale / transfer deed（出售契据/转让契据） | 转移所有权的文件。 |
| Rogito notarile | Notarial deed / deed of conveyance（公证契据/产权转移契据） | 由公证人准备的契据；意大利房产转让必须使用。 |
| Atto notarile | Notarial deed / deed of conveyance（公证契据/产权转移契据） | 公证人准备文件的通用术语。 |
| Preliminare di compravendita / compromesso | Preliminary purchase agreement / preliminary contract（初步购买协议/预备合同） | 有约束力的签署最终契据协议；无确切的普通法对应物。 |
| Proposta di acquisto | Offer to purchase / letter of intent（购买要约/意向书） | 无约束力的购房要约。 |
| Caparra confirmatoria | Earnest money deposit / confirmation deposit（定金/确认定金） | 定金（《民法典》第 1385 条）；兼具确认和预定损害赔偿功能。 |
| Caparra penitenziale | Penalty deposit / right of withdrawal deposit（退约金/退出权定金） | 定金（《民法典》第 1386 条）；允许任一方通过放弃/返还定金而退出。 |
| Acconto prezzo | Deposit on account of the purchase price（计入购买价格的定金） | 计入购买价格的预付款。 |
| Prezzo di vendita | Purchase price / sale price（购买价格/售价） | 约定的售价。 |
| Corrispettivo | Consideration（对价） | 合同中交换的价值。 |
| Canone di locazione / affitto | Rent（租金） | 使用租赁物业的定期付款。 |
| Canone mensile | Monthly rent（月租） | 按月支付的租金。 |
| Spese condominiali | Service charges / common charges / common area maintenance（服务费/公共费用/公共区域维护费） | 共享设施的费用；按分摊表计算。 |
| Oneri accessori | Additional charges / ancillary costs（附加费用/杂项费用） | 租金或购买价格以外的费用。 |
| Deposito cauzionale | Security deposit（押金） | 房东持有的现金担保。 |
| Cauzione | Deposit / security deposit（保证金/押金） | 押金的同义词。 |

| Parti comuni | Common areas / common parts（公共区域/公共部分） | 多单元建筑中的共享空间。 |
| Condominio | Condominium / co-ownership / co-ownership building（共有公寓/共有物业） | 单元所有权各自独立、公共区域共同拥有的多单元建筑；由《意大利民法典》第三编第六章之二管辖。 |
| Amministratore di condominio | Building manager / property manager（物业经理） | 管理共有公寓的人。 |
| Regolamento condominiale | Condominium regulations / house rules（共有公寓规章/房屋规则） | 管理共有公寓使用的规则。 |
| Tabelle millesimali | Apportionment tables（分摊表） | 显示每个单元在公共区域中份额的表（以千分比表示 = "millesimi"）。 |
| Superficie commerciale | Gross floor area（总建筑面积） | 包括所有空间的全部楼面面积。 |
| Superficie calpestabile | Net floor area / usable floor area（净楼面面积/可使用面积） | 实际可供占用的楼面面积。 |

| Catasto | Land registry / cadastre（土地登记/地籍） | 意大利官方不动产登记簿；由税务局（Agenzia delle Entrate）维护。 |
| Foglio | Sheet (cadastral reference)（图幅，地籍参考） | 地籍识别第一部分（图幅/地图编号）。 |
| Particella | Parcel (cadastral reference)（地块，地籍参考） | 地籍识别第二部分（地块编号）。 |
| Subalterno | Sub-unit (cadastral reference)（子单元，地籍参考） | 建筑内单元的地籍识别第三部分。 |

## 意大利租赁特定术语

| 意大利语术语 | 英文对应词 | 注释 |
|---|---|---|
| Locatore | Landlord / lessor（出租人） | 授予租赁的房产所有人。 |
| Conduttore / locatario | Tenant / lessee（承租人） | 租赁房产的一方。 |
| Sublocazione / subaffitto | Sublease / subletting（转租） | 承租人向第三方出租。 |
| Durata della locazione | Lease term（租赁期限） | 租赁的期间。 |
| Rinnovo tacito | Tacit renewal / automatic renewal（默示续租/自动续租） | 除非发出通知，否则到期自动续租。意大利法律通常规定自动续租，除非任一方在指定期限内发出书面通知。 |
| Disdetta | Notice of termination / notice to quit（终止通知/退租通知） | 终止租赁的正式通知。 |
| Recesso anticipato | Early termination（提前终止） | 在约定期限前结束租赁。 |
| Aggiornamento ISTAT | ISTAT indexation / rent indexation（ISTAT 指数化/租金指数化） | 基于 ISTAT 通胀指数调整租金；意大利住宅租赁常见。 |
| Adeguamento del canone | Rent review / rent adjustment（租金复核/租金调整） | 通过指数化或重新谈判改变租金。 |
| Manutenzione ordinaria | Routine maintenance / ordinary maintenance（日常维护/常规维护） | 定期维护和小修；根据意大利法律通常由承租人负责。 |
| Manutenzione straordinaria | Major repairs / structural repairs / extraordinary maintenance（大修/结构性维修/非常规维护） | 重大维修（屋顶、结构构件）；根据意大利法律通常由出租人负责。 |
| Destinazione d'uso | Permitted use / use covenant（允许用途/用途约束） | 租赁中规定的允许用途；也用于土地分区。 |
| Cambio di destinazione d'uso | Change of use（用途变更） | 修改允许用途；需要出租人同意，并可能需要分区变更。 |
| Migliorie | Improvements（改良） | 承租人进行的改良。 |
| Addizioni | Tenant's fixtures / additions（承租人固定装置/添加物） | 承租人附加的物品。 |
| Stato dei luoghi | Condition of the premises（场所状况） | 开始时的物理状态。 |
| Verbale di consegna | Handover report / schedule of condition（交接报告/状况清单） | 记录租赁开始时状况的文件。 |
| Verbale di riconsegna | Return report（归还报告） | 记录租赁结束时状况的文件。 |
| Indennità di avviamento | Goodwill indemnity / key money（商誉补偿/顶手费） | 为占有或接替现有租赁而支付的款项。 |
| Cedolare secca | Flat-rate tax / substitute tax on rental income（固定税率税/租金收入替代税） | 住宅租金收入的简化税收制度（第 431/1998 号法律及后续修正）；可选择退出正常所得税。 |

## 意大利转让与所有权术语

| 意大利语术语 | 英文对应词 | 注释 |
|---|---|---|
| Proprietà / Diritto di proprietà | Ownership / title / right of ownership（所有权/产权/所有权权利） | 拥有和控制财产的法律权利。 |
| Piena proprietà | Freehold / full ownership（完全保有/完全所有权） | 完整、不受限制的所有权。 |
| Nuda proprietà | Bare ownership / reversionary interest（空所有权/回复利益） | 无使用或收益权的所有权（用益权人持有使用权）。大陆法系概念（《意大利民法典》第 978 条及以下）。避免直译 "naked ownership"。 |
| Usufrutto | Usufruct（用益权） | 在指定期限或终身内使用和收益他人财产的权利；空所有权人（nuda proprietà 持有人）保留产权。大陆法系概念。避免映射为 "life interest"——普通法的终身租赁是不同学说。 |
| Diritto di superficie | Right of superficies / building right（地上权/建筑权） | 在他人土地之上或之下建造并保留构筑物所有权的权利。《意大利民法典》第 952 条及以下。 |
| Servitù | Easement / servitude（地役权） | 为特定目的（通行、公用设施、停车、采光）使用他人土地的权利。意大利语术语为 "servitù"；英语术语为 "easement"。 |
| Servitù di passaggio | Right of way（通行权） | 允许穿越他人土地的地役权。 |
| Servitù di veduta | Right of light / right of view（采光权/观景权） | 保护采光或观景权利的地役权。 |
| Ipoteca volontaria | Voluntary mortgage（自愿抵押） | 所有人向贷款人授予的抵押。 |
| Ipoteca giudiziale | Judicial mortgage / charging order（司法抵押/扣押令） | 法院命令施加的抵押。 |
| Iscrizione ipotecaria | Mortgage registration / registration of charge（抵押登记） | 在土地登记簿中登记抵押。 |
| Cancellazione ipotecaria | Mortgage discharge / release of mortgage（抵押注销） | 从登记簿中取消抵押。 |
| Certificato di agibilità | Occupancy certificate / habitability certificate（占用证书/宜居证书） | 证明房产安全且适合占用的官方认证；意大利在使用前必须取得。 |
| Certificato di destinazione urbanistica | Urban planning certificate / zoning certificate（城市规划证书/分区证书） | 规划和分区合规的认证。 |
| Conformità catastale | Cadastral compliance / cadastral match（地籍合规/地籍一致） | 确认房产边界与地籍记录一致。 |
| Conformità urbanistica | Planning compliance（规划合规） | 确认符合分区和规划法。 |
| Attestato di prestazione energetica (APE) | Energy performance certificate (EPC)（能源绩效证书） | 建筑能效认证（欧盟/意大利要求；第 90/2013 号法律实施第 2010/31/EU 号指令）。 |

## 意大利行政与地籍系统

| 意大利语术语 | 英文对应词 | 注释 |
|---|---|---|
| Agenzia delle Entrate | Tax Agency / Revenue Agency（税务局） | 维护土地登记（catasto）和房产记录的意大利政府机构。 |
| ISTAT (Istituto Nazionale di Statistica) | National Institute of Statistics（国家统计局） | 发布用于自动租金调整的通胀指数的意大利政府机构。通常称为"ISTAT 指数化"。 |
| Agenzia del Territorio (historic) | Territory Agency (historic)（土地局，历史） | 原负责管理地籍和登记处的机构；2012 年并入税务局。 |

## 意大利租金监管与税务

| 意大利语术语 | 英文对应词 | 注释 |
|---|---|---|
注：`Cedolare secca` 和 `Aggiornamento ISTAT` 已在上述房产术语部分定义；此处不重复。
| Canone libero | Free market rent（自由市场租金） | 双方自由协商的租金（不受最高上限约束）。根据意大利法律（第 431/1998 号法律），大多数住宅租赁现在使用自由市场租金。 |
| Canone convenuto | Agreed rent / negotiated rent（约定租金/协商租金） | 双方签署时约定的租金。 |
| Tabella dei canoni | Rent tables / reference rental values（租金表/参考租金值） | 部分市政当局发布的参考租金表；不具法律约束力，但用作指引。 |
| Aumento annuale | Annual increase / annual adjustment（年度增加/年度调整） | 租金的同比变化，通常与 ISTAT 挂钩。 |

## 注释

- **Caparra 概念**：意大利法律区分两种定金：
  - *Caparra confirmatoria*（《民法典》第 1385 条）：定金，兼具协议确认和预定损害赔偿功能（若买方退出，通常不可退还）。
  - *Caparra penitenziale*（《民法典》第 1386 条）：退出权定金（任一方可退出；退出方放弃/返还定金）。
  这些大陆法系概念没有确切的普通法对应物。英文翻译中使用英文描述；首次使用时在括号中保留意大利语术语。

- **共有公寓（condominio）**：在意大利法律中，指多单元建筑的共有制度，而非特定建筑类型。由《意大利民法典》第三编第六章之二（第 1100-1139 条）管辖。共有公寓有强制性公共区域（楼梯、屋顶、墙壁、场地）和可选公共区域。每个单元所有人按比例（tabelle millesimali）承担公共费用。

- **Nuda proprietà 和 usufrutto**：独特的大陆法系概念，允许分割所有权：一方持有空产权（nuda proprietà），另一方拥有用益权（使用和收取收益的权利）。普通法中没有。始终准确翻译并在首次使用时解释。

- **地上权（superficies）**：在他人土地之上或之下建造的大陆法系权利。普通法中罕见；英国有 "fee farm rent"；美国有 "easement for building"。《意大利法典》第 952 条及以下。

- **地役权（servitù）**：意大利法律使用 "servitù"；英语使用 "easement"。两者均指使一块地产受益、使另一块地产负担的权利（通行、公用设施、停车、采光/观景）。意大利地役权规定于《民法典》第 1027-1099 条。

- **ISTAT 指数化**：ISTAT（国家统计局）每月发布通胀指数。意大利租赁通常将租金与 "FOI"（工人和职员家庭消费价格指数）或其他指数挂钩。如提及，务必指明是哪个 ISTAT 指数。

- **能源绩效证书（APE）**：意大利缩写为 APE（Attestato di Prestazione Energetica）。自 2008 年 1 月起意大利所有建筑必须取得（第 90/2013 号法律，实施欧盟第 2010/31/EU 号指令）。必须在签署租赁或出售房产前提供。

- **Cedolare secca**：固定税率制度（第 431/1998 号法律，已更新）。允许房东/承租人选择退出正常所得税和资本利得税；按申报租金的标准税率约为 21%（住宅）或 26%（商业）。大幅简化，但将双方锁定于申报租金。

- **地籍参考**：意大利房产通过地籍条目识别：
  - *Foglio*：地籍图幅/地图编号
  - *Particella*：图幅内的地块编号
  - *Subalterno*：子单元编号（用于建筑）
  例如："Foglio 42, Particella 156, Subalterno 5" 识别特定公寓。始终提供英文标签但保留数字引用。

- **建筑许可与通知**：意大利法律区分：
  - *Permesso di costruire*：重大工程的完整建筑许可；需要详细申请和批准。
  - *SCIA*（认证通知）：小型工程的简化程序；基于通知而非批准（第 326/2003 号法律）。
  - *DIA*（较旧程序，基本已被取代）：开工通知。

- **Destinazione d'uso**：该术语可指 (1) 土地分区（城市规划指定）或 (2) 租赁中的允许用途。情境至关重要。若指分区，译为 "zoning" 或 "planning designation"；若与租赁相关，译为 "permitted use"。

- **共有公寓规章**：《意大利民法典》第 1118 条允许共有公寓通过管理公共区域使用的规章。这些规章对所有单元所有人具有约束力。

- **分摊表（tabelle millesimali）**：所有共有公寓必须制定。每个单元被分配以 "millesimi"（千分比）表示的份额，反映其在公共区域中的比例以及相应的公共费用（spese condominiali）责任。这些表格是强制性的，对计算费用非常重要。

- **意大利公证人（notaio）**：在意大利法律中，房产转让需要公证契据。公证人是独立的公职人员（不是律师，尽管受过法律培训）。其职责包括核实身份、确保法律行为能力以及保存记录。这是房产转让和部分其他交易的强制性要求。

- **租赁保护**：第 431/1998 号法律改革了住宅租赁法，引入了固定期限可续租租赁、无正当理由不得驱逐的保护，并允许"cedolare secca"税收制度。务必检查适用哪种租赁制度（受保护 vs. 自由市场）。
