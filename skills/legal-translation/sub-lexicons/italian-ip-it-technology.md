# 意大利语——知识产权、技术与 IT 子词典

合并意大利语知识产权/技术与 IT/SaaS 词汇。第 1 部分涵盖版权、工业产权（专利、外观设计、商标）、商业秘密和技术转让。第 2 部分涵盖软件许可、SaaS/云服务、实施项目、SLA、数据处理和网络安全。

---

## 意大利法律框架参考

翻译中应注意以下意大利特定参考：

| 意大利参考 | 英语对应 | 范围 |
|---|---|---|
| D.Lgs. 30/2005 (CPI) | Industrial Property Code (Legislative Decree No. 30 of 10 February 2005)（《工业产权法典》，2005 年 2 月 10 日第 30 号立法法令） | 规范意大利专利、商标、外观设计 |
| L. 633/1941 | Law No. 633 of 22 April 1941 (Italian Copyright Law)（1941 年 4 月 22 日第 633 号法律——《意大利版权法》） | 规范意大利版权和作者权利 |
| SIAE | Società Italiana degli Autori ed Editori (Italian Society of Authors and Editors)（意大利作者与出版者协会） | 意大利版权集体管理组织；管理许可费分配 |
| Codice della Proprietà Industriale | Industrial Property Code（《工业产权法典》） | 规范工业产权的意大利法律 |
| Ufficio Italiano Brevetti e Marchi (UIBM) | Italian Patent and Trade Mark Office（意大利专利商标局） | 意大利国家知识产权局 |
| EPO (Ufficio Europeo dei Brevetti) | European Patent Office（欧洲专利局） | 泛欧洲专利体系 |
| EUIPO (Ufficio dell'Unione Europea per la Proprietà Intellettuale) | European Union Intellectual Property Office（欧盟知识产权局） | 欧盟商标/外观设计局 |

## 说明

- **"Proprietà industriale" 与 "diritto d'autore"**：意大利法律将知识产权分为工业产权（D.Lgs. 30/2005）和版权（L. 633/1941）。英语使用涵盖两者的总括术语 "intellectual property"。

- **"Contraffazione"**：在专利/商标语境中意为 "infringement"（侵权）。在刑事/商品语境（假冒产品）中也是 "contraffazione"（假冒）。按语境翻译。

- **"Licenza" 到 "licence/license"**：意大利语在所有语境中使用单一术语 "licenza"。英语需要 "licence"（英式名词）、"license"（美式名词/动词）。默认英式名词。

- **"SIAE"**：意大利版权集体管理组织，为作者/出版者收取和分配许可费。不等同于外国组织，但功能类似。翻译中保留为 "SIAE" 并加说明。

- **"Marchio" 拼写**：根据目标受众始终使用 "trade mark"（英式）或 "trademark"（美式）。默认英式（两个词）。

- **意大利立法引用**：翻译意大利知识产权协议时，CPI、SIAE 及其他意大利特定引用应放在翻译注释中，而非合同正文，因为英语合同通常引用国际框架或目标司法辖区的法律。

## 意大利法律/商业语境

应注意以下意大利特定概念或常见用法模式：

| 意大利概念 | 英语对应 | 用法说明 |
|---|---|---|
| Responsabilità civile | Liability / Civil liability | 意大利法律区分民事与刑事；译为民事责任语境 |
| Garanzie | Warranties / Representations | 意大利语使用单一术语；英语区分条件/保证/陈述 |
| Penali | Liquidated damages / Service credits | 视语境而定：SaaS 中 "penali" = 服务信用；传统合同中 = 预定损害赔偿 |
| Indennizzo / indennità | Indemnity / Indemnification | 损失补偿；与 "garanzie"（保证）相区别 |
| Trattamento | Data processing / Treatment | IT/数据语境 = 数据处理（GDPR）；一般合同 = 处理/对待 |
| Aggiornamenti | Updates / Upgrades | 视语境而定：次要修复 = update；主要功能 = upgrade |
| Software su commissione | Custom software / Bespoke software | 委托/定制软件开发 |
| Cliente / Utente | Customer / User | "Cliente" = 缔约方；"utente" = 终端用户（可能是不同的人） |

## 语境翻译说明

- **"Crediti di servizio"**：SaaS 语境 = "service credits"（服务失败的发票折扣）。传统外包中 = "penali" = "liquidated damages"（合同损害赔偿）。不可互换。

- **"Licenza"**：单一意大利语术语；始终译为英式 "licence"（名词）或美式 "license"。默认英式名词形式。

- **"Livello di servizio"**：合同要素通常包括可用性百分比、除外情形（计划维护、不可抗力）、计量方法和救济（服务信用）。

- **"Ambiente"**：通常需同时指明生产（实时用户）和测试（staging）环境；翻译中明确哪种环境适用于保证、备份、SLA。

- **"Aggiornamento vs Upgrade"**：意大利语使用单一术语，但语境很重要——次要补丁 = updates；主要版本 = upgrades。许可影响不同。

- **GDPR 特定术语**：意大利语使用 "trattamento"（处理）；英语 GDPR 语境需要特定术语——"data controller"、"data processor"、"personal data"——并在 DPA 中定义。

- **"Collaudo"**：技术验收测试；在开发合同中通常是触发付款里程碑的正式签字。

- **"Open source"**：意大利协议通常通过 "componente open source" 处理；确保译文指明许可类型（copyleft 与 permissive）和合规义务。

- **"Proprietà dei risultati"**：开发语境 = 开发知识产权的所有权；在委托作品结构中通常归属于委托方，但可协商。

- **"Escrow"**：用于源代码托管（开发者失败时释放代码）；第三方通常为托管代理人；常见于企业软件。

- **数据传输术语**："Migrazione" = 数据迁移；"esportazione" = 导出；"portabilità" = 可移植权；合同中均为不同概念。

- **SLA 指标**：意大利合同通常规定罚则层级（如可用性 99-99.5% 抵免 1%，98-99% 抵免 2%）；翻译为清晰的服务信用时间表。
