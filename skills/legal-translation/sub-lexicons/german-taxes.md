# 德语——税务子词典

德国税务法术语与 `references/taxes.md` 中的中性英语对应词的映射。德国税法主要受《税收通则》（Abgabenordnung，AO——通用税务法典）、《个人所得税法》（Einkommensteuergesetz，EStG——PIT）、《公司税法》（Körperschaftsteuergesetz，KStG——CIT）、《增值税法》（Umsatzsteuergesetz，UStG——VAT）、《营业税法》（Gewerbesteuergesetz，GewStG——营业税）以及一系列特别法（《改组税法》Umwandlungssteuergesetz、《涉外税法》Außensteuergesetz 等）管辖。公司/并购语境下请与 `german-corporate-ma-jv.md` 配合使用。

---

## 2. 直接税——KSt / ESt 概念

| Abschreibung (AfA) | 折旧/摊销（depreciation / amortisation） |
| lineare / degressive AfA | 直线 / 余额递减折旧（straight-line / declining-balance depreciation） |

| Teilwertabschreibung | 部分价值减记（partial-value write-down） |

| Solidaritätszuschlag (5,5% auf KSt) | 团结附加税（solidarity surcharge——KSt 的 5.5%） |

| Verlustrücktrag | 亏损回转（loss carry-back） |

| Mantelkauf / schädlicher Beteiligungserwerb | 壳公司收购 / 有害股权收购（shell acquisition / detrimental share acquisition——KStG 第 8c 条：股权转让超过 50% 时亏损丧失） |
| Sanierungsklausel | 重组条款（restructuring clause——亏损保全，KStG 第 8c 条） |
| fortführungsgebundener Verlustvortrag | 持续经营关联亏损结转（continuation-linked loss carry-forward——KStG 第 8d 条） |
| Organschaft | 财税联合/税务集团（fiscal unity / tax group，Organschaft） |
| Organträger | 财税联合的控制实体（controlling entity of the fiscal unity） |
| Organgesellschaft | 财税联合的被控制实体（controlled entity of the fiscal unity） |
| Gewinnabführungsvertrag (GAV) | 损益转移协议（profit-and-loss transfer agreement——Organschaft 所需） |
| Beteiligung / Schachtelprivileg | 参股免税（participation exemption，Schachtelprivileg） |
| Freistellung von Dividenden (§ 8b KStG) | 股息免税（dividend exemption——KStG 第 8b 条：95% 免税，5% 不可扣除回加） |
| Veräußerungsgewinne auf Beteiligungen (§ 8b KStG) | 股权资本利得（capital gains on shareholdings——95% 免税） |
| Zinsschranke | 利息限制规则（interest limitation rule——30% EBITDA，EStG 第 4h 条 / KStG 第 8a 条） |
| Lizenzschranke | 特许权使用费限制规则（royalty limitation rule——EStG 第 4j 条） |
| Hinzurechnungsbesteuerung (§§ 7-14 AStG) | CFC 规则（add-back taxation——《涉外税法》第 7-14 条） |
| Wegzugsbesteuerung (§ 6 AStG) | 个人退出税（exit tax for individuals——《涉外税法》第 6 条） |
| Außensteuergesetz (AStG) | 《涉外税法》（Foreign Tax Act，AStG） |
| Forschungszulage | 研发补贴（R&D allowance——自 2020 年起） |

## 15. 注释——译者指引

- **KSt 与“公司税”之别**。Körperschaftsteuer 是联邦公司所得税（15%）。连同团结附加税（KSt 的 5.5%）和营业税（Gewerbesteuer，因市政而异，但通常为 14-17%），实际总税负约为 30%。将 KSt 译为“corporate income tax (KSt)”，并务必注明这只是联邦组成部分——GewSt 是独立的。
- **Gewerbesteuer——无英语对应词**。一种对营业所得征收的市政税，在与 KSt 不同的税基上计算（有特定回加项目，如利息的 25%、某些租金的 20%）。税率 = 联邦基准税率（3.5%）× 市政乘数（*Hebesatz*，通常 400-500%，有时更高）。功能上是公司层面的税，但没有单词英语对应词。首次使用时译为“trade tax (GewSt)”并附译者注；切勿单独译为“business tax”或“municipal corporate tax”。
- **Solidaritätszuschlag**。KSt（以及高收入个人的 ESt）的 5.5% 附加税。2021 年改革取消了大多数个人的 Soli，但公司仍须缴纳。译为“solidarity surcharge (Soli)”，并注明其仍适用于 KSt。
- **Kirchensteuer**。教会税，对被承认宗教团体成员按 ESt 的 8%（巴伐利亚、巴登-符腾堡）或 9% 征收。由税务局代收并转交教会。译为“church tax”——真正的税，而非自愿捐款。
- **Maßgeblichkeitsprinzip**。权威性原则：商业资产负债表（HGB）对税务资产负债表具有权威性，但受税务特定规定推翻（如对准备、隐性储备、表外折旧的限制）。译为“authoritative-principle rule”，并解释它是会计利润与应税利润之间的桥梁。
- **Organschaft**。德国财税联合/税务集团。要求 (i) 财务整合（控制实体持有 >50% 表决权）、(ii) 在商业登记册登记损益转移协议（Gewinnabführungsvertrag，至少 5 年）、(iii) 实际实施。译为“fiscal unity”或“tax group”，并在首次提及时以括号保留“Organschaft”——无简洁的单词英语对应词。
- **KStG 第 8b 条**。对法人股权股息和资本利得的参股免税。金额的 95% 免税（按假定费用的 5% 不予扣除）。股息须持股至少 10%（KSt 无持股期要求；营业税需持股 1 年）。务必引用 KStG 第 8b 条。
- **Zinsschranke**。利息限制规则（EStG 第 4h 条 / KStG 第 8a 条）：净利息支出仅可在税务 EBITDA 的 30% 以内扣除。例外：300 万欧元安全港门槛、独立例外、权益豁免例外。译为“interest limitation rule”或“German interest barrier”。
- **vGA（verdeckte Gewinnausschüttung）**。推定股息：公司给予股东的任何资产利益，而审慎的管理者不会给予第三方。在股东层面产生所得，在公司层面不可扣除。无资本利得豁免。译为“constructive (deemed) dividend”或“hidden profit distribution”——并标注为关键审计风险。
- **Wegzugsbesteuerung（AStG 第 6 条）**。德国个人退出税，针对个人停止居民身份时持有的 ≥1% 公司股份（法人）中的未实现利得。2022 年改革（取消欧盟/欧洲经济区迁移的自动递延；改为分期付款）。译为“German exit tax”并引用 AStG 第 6 条。
- **Hinzurechnungsbesteuerung（AStG 第 7-14 条）**。德国 CFC 规则。低税负（<15%）CFC 的被动所得按比例归属于德国居民。2021 年改革（ATAD 实施）。译为“German CFC rules”或“add-back taxation”——首次提及时保留 AStG 引用。
- **Mantelkauf / KStG 第 8c 条**。所有权变更时的亏损丧失：5 年内收购 >50% 的股份即消灭亏损结转。KStG 第 8d 条提供逃生通道（持续经营关联结转）。KStG 第 8c(1a) 条的重组条款在真正的挽救情形中保全亏损。翻译涉及目标公司有亏损结转的并购文件时务必标注。
- **Grunderwerbsteuer（GrESt）与股权交易**。自 2021 年改革以来，10 年内转让房地产持有公司 ≥90% 股份的股权交易触发不动产转让税（RETT）。税率因州而异（通常 3.5%-6.5%）。译为“share-deal real estate transfer tax”，并务必指明适用税率。
- **Abgeltungsteuer**。投资所得的终局固定税率预提：25% + 5.5% Soli + 教会税（如适用），实际约 26.4-28%。适用于利息、股息和私人资本利得。若已正确预扣，无需申报所得税，即属“终局”。译为“final flat-rate withholding tax”或“Abgeltungsteuer”并附解释。
- **Steuerhinterziehung（AO 第 370 条）与 Selbstanzeige（AO 第 371 条）**。逃税是刑事犯罪。在发现前进行自愿披露（*Selbstanzeige*）可消灭刑事责任，但须满足严格的完整性和及时性要求（2011 年和 2015 年收紧）。译为“tax evasion”和“voluntary disclosure with exculpating effect”——不要与单纯的更正混淆。
- **ELSTER**。强制电子纳税申报门户。当来源引用 ELSTER 时，保留该标记并翻译周围叙述。
- **第二支柱（MinBestG）**。德国通过《最低征税法》（Mindestbesteuerungsgesetz，MinBestG）实施第二支柱，适用于 2023 年 12 月 31 日当日或之后开始的财政年度。将法律名称译为“German Pillar Two Act (MinBestG)”，并使用 OECD 英语缩写（IIR、UTPR、QDMTT）。
- **BMF-Schreiben**。联邦财政部发布的行政指导——对税务机关有约束力，但对纳税人或法院无约束力。具有说服力。译为“BMF circular”，并在首次提及时保留通函日期。
- **货币/数字格式**。德语使用点作千位分隔符、逗号作小数分隔符（1.234,56 €）。除非用户另有说明，转换为英式英语风格。务必保留欧元符号和精确数字。
