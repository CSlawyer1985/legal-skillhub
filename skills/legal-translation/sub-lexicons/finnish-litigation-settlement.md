## 注释

- **仲裁法（välimiesmenettelylaki，967/1992）**：芬兰仲裁立法，以联合国国际贸易法委员会《示范法》为基础。2023 年制定新仲裁法（2024 年生效），进一步与《示范法》接轨。首次出现时引用为 "Arbitration Act"。
- **芬兰仲裁院（FAI）**：由芬兰商会运营。芬兰主要的商事仲裁机构。首次出现时引用为 "Finland Arbitration Institute (FAI)"。
- **"Tuomioistuinsovittelu"（法院附设调解）**：依《民事诉讼调解与普通法院确认和解法》（riita-asioiden sovittelulaki）可得。法官担任调解人。调解成功时，和解由法院确认并可执行。标注其可执行性。
- **"Kuluttajariitalautakunta"（消费者争议委员会）**：面向消费者争议的免费 ADR 机制。建议不具有法律约束力，但大多数企业会遵守。译为 "Consumer Disputes Board" 并注明非约束性质。
- **《纽约公约》**：芬兰是《承认及执行外国仲裁裁决公约》（《纽约公约》）缔约国。外国仲裁裁决在芬兰可执行。翻译跨境仲裁条款时予以标注。
- **芬兰的诉讼费用**：依《司法程序法典》，败诉方通常支付胜诉方合理的诉讼费用。该"败诉方付费"原则适用于诉讼。仲裁中，费用分配遵循仲裁规则。

## 翻译者注意事项——诉讼

- **käräjäoikeus**：既定的译法是 "District Court"——不是 "circuit court" 或 "local court"。法院名称使用芬兰官方英语译名。
- **hovioikeus**："Court of Appeal"；有时保留 "Hovioikeus" 并在括号内加注。
- **KKO 与 KHO**：KKO = Korkein oikeus = 最高法院（普通）；KHO = Korkein hallinto-oikeus = 最高行政法院。两个平行的最高法院（民事/刑事 vs 行政）。不要混同。
- **tuomio、päätös 与 ratkaisu**：tuomio = 判决（实体性的民事/刑事审判结果）；päätös = 决定（程序性或行政性）；ratkaisu = 裁定/决定（广泛——常用于行政法院裁定）。视语境而定。
- **valitus**：民事/刑事中向 hovioikeus 的 "appeal"（上诉），或自机关向行政法院的 "administrative appeal"（行政上诉）。行政语境中务必标明行政性以免混淆。
- **kantelu 与 valitus**：kantelu 是非常性申诉/请愿（OK 第 31 章下的程序错误救济）；valitus 是普通上诉。不要将两者都译为 "appeal"。
- **asianosainen 与 asianomistaja**：asianosainen 是"当事人"（广义，含行政和民事）；asianomistaja 是"被害人"（特指刑事诉讼中可自诉的受害人）。角色不同。
- **esitutkinta 与 syyteharkinta**：esitutkinta = 预审调查（警察进行）；syyteharkinta = 公诉审查（检察官决定是否起诉）。刑事程序的两个阶段——不要混同。
- **pakkokeino**："Coercive measure" 是标准英语；包括羁押、搜查、扣押、监控。"Compulsory measure" 亦见。
- **tunnustamisoikeudenkäynti**：2015 年后芬兰的认罪协商机制，检察官与嫌疑人就指控达成一致，嫌疑人以认罪换取减刑；与普通法 plea bargain 不完全相同（附条件、须经法院批准）。首次使用加注。
- **turvaamistoimi 与 pakkokeino**：turvaamistoimi = OK 第 7 章下的民事预防性/临时措施；pakkokeino = 刑事强制措施。同一概念家族但程序制度不同——翻译中须区分。
- **ulosotto**：芬兰执行制度集中统一于执行机关（ulosottolaitos），拥有对收入和银行账户的有力自动化扣押。"Enforcement" 或 "enforcement proceedings"；不用 "execution"（后者保留用于执行特定行为）。
- **uhkasakko / teettämisuhka / keskeyttämisuhka**：行政强制工具。uhkasakko = 附条件罚款（罚款威胁）；teettämisuhka = 代履行威胁（机关代为履行，费用由当事人承担）；keskeyttämisuhka = 中止威胁。英语无单一术语涵盖三者——视需要加注。
- **lainvoima**：视语境译为 "Legal force" 或 "res judicata"——判决取得 lainvoima 后即终局且可执行；通常表述为 "final and binding" 或 "res judicata"。
- **prekluusio**：芬兰民事诉讼有严格的失权制度——准备阶段后新提出的请求或证据除非存在特殊情形否则被排除。英语中保留该术语并加注。
- **ennakkopäätösvalitus**："Leap-frog appeal"（跳跃上诉），经双方同意并获得许可后自地区法院直接上诉至 KKO；翻译时加注。
- **lautamies**：非职业法官（不是"陪审团"）在地区法院特定刑事案件中与职业法官同席；译为 "lay judge" 或 "lay assessor"，绝不可译为 "juror"。
- **oikeudenkäyntikulut**：芬兰费用规则强烈倾向败诉方付费，但法院可调整；在和解协议中约定各自放弃费用是重要的起草要点。
