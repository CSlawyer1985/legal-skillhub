# 意大利语子词典：雇佣/劳动

从 employment.md 中提取的意大利语→英语映射。这些术语为意大利特有，应映射至主词典中的通用英语对应词，而不应直接出现在为英语读者撰写的雇佣合同中。

## 意大利雇佣合同类型

| 意大利语术语 | 英语对应词 | 注释 |
|---|---|---|
| contratto di lavoro subordinato | employment contract / employment agreement | 意大利法下从属雇佣关系的术语；"subordinazione" 表示雇员身份 |
| contratto di lavoro a tempo indeterminato | permanent employment contract | 无固定终止日期的雇佣；意大利雇佣法中的标准形式 |
| contratto di lavoro a tempo determinato | fixed-term employment contract | 有明确终止日期的雇佣（受欧盟指令 1999/70/EC 限制） |
| contratto di lavoro part-time | part-time employment contract | 减少工作时间的雇佣；意大利法单独规范 |
| contratto di collaborazione | consultancy agreement / contractor agreement | 准雇佣安排；可以是"collaborazione coordinata e continuativa"（co.co.co.）或"contratto a progetto" |
| collaborazione coordinata e continuativa / co.co.co. | coordinated and continuous collaboration | 意大利特有安排（2015 年前）；工作者持续提供协调服务但不具雇员身份；2015 年《就业法》改革后基本废止 |
| contratto a progetto | project-based contract | 意大利特有的针对特定项目的准雇佣形式；经 2015 年《就业法》修改，与"真正独立"标准对齐 |
| lettera di assunzione | letter of appointment / offer letter | 载明雇佣条款和起始日期的文件 |
| patto di non concorrenza | non-compete agreement / non-competition covenant | 禁止竞争的限制性契约；意大利法下如范围/期限合理则可执行 |
| patto di non sollecitazione | non-solicitation agreement | 禁止招揽客户/雇员的契约；与竞业禁止不同 |
| patto di riservatezza | confidentiality agreement | 保护雇主保密信息和商业秘密 |
| clausola di stabilità | minimum term clause / lock-in clause | 要求最低雇佣期限或要求雇员偿还培训费用的条款 |
| periodo di prova | probationary period / trial period | 初始雇佣期（通常为 1-6 个月，由 CCNL 确定），期间任何一方可无须通知解除 |
| accordo di risoluzione consensuale | mutual termination agreement | 雇主与雇员按特定条款协议终止的协议 |
| accordo di buonuscita | severance agreement | 提供解雇补偿金的协议，通常以竞业禁止/保密承诺为交换 |
| transazione in sede protetta | protected-venue settlement | 在正式场所通过调解或和解达成的雇佣争议和解（不同于英国的 settlement agreement） |

## 意大利薪酬术语

| 意大利语术语 | 英语对应词 | 注释 |
|---|---|---|
| retribuzione / compenso | remuneration / salary | 为履行工作而支付的全部报酬 |
| retribuzione annua lorda / RAL | gross annual salary | 扣除（税、社保）前的总薪酬；意大利标准 HR 术语 "RAL" |
| retribuzione netta | net salary | 扣除后的薪酬 |
| busta paga | payslip | 月度工资单 |
| tredicesima mensilità | thirteenth month's salary | 年底额外支付的一个月工资（意大利及其他欧洲国家惯例） |
| quattordicesima mensilità | fourteenth month's salary | 在指定时间额外支付的一个月工资（意大利及其他欧洲国家惯例）；不如十三薪常见 |
| TFR / trattamento di fine rapporto | severance indemnity / end-of-service allowance | 依据《意大利民法典》第 2120 条的法定权利；在雇佣期间逐年累积（名义上每年约一个月工资），于终止时（退休、辞职、解雇、死亡）支付；可转入补充养老金基金或 TFR 基金；普通法无确切对应 |
| indennità di fine rapporto | severance pay | 终止时的付款（可以是法定的 TFR 或合同约定的遣散费） |
| indennità sostitutiva del preavviso | payment in lieu of notice | 雇主以付款代替实际工作通知期 |
| buonuscita / incentivo all'esodo | severance package / ex gratia payment | 酌情遣散费或提前退出激励（常用于裁员计划，"esodo incentivato"） |
| superminimo | supplementary allowance | 在 CCNL 要求的基本工资之外支付的固定附加款项 |
| premio di risultato / bonus | performance bonus | 达成目标的浮动薪酬 |
| MBO / management by objectives | MBO / management bonus | 与组织/个人目标挂钩的管理奖金 |
| stock option | stock options | 按特定价格购买公司股份的权利 |
| piano di incentivazione | incentive plan | 提供绩效激励的结构化方案 |
| benefit / fringe benefit | benefit / fringe benefit | 非现金报酬（汽车、保险、养老金等） |
| auto aziendale | company car | 雇主提供的用于业务/个人用途的车辆 |
| assicurazione sanitaria integrativa | supplementary health insurance | 法定国家体系之外的医疗保障 |
| fondo pensione complementare | supplementary pension fund | 强制性 INPS 之外的职业养老金 |
| contributi previdenziali | social security contributions | 雇主/雇员向意大利社会保障（INPS、INAIL 等）的强制性缴费 |
| contributi a carico del datore di lavoro | employer contributions | 雇主向 INPS、INAIL 等的强制性缴费 |
| contributi a carico del lavoratore | employee contributions | 雇员缴费，通常从工资中扣除 |
| INPS | INPS (Italian Institute for Social Security) | 意大利国家社会保障机构（Istituto Nazionale della Previdenza Sociale） |
| INAIL | INAIL (Italian workplace insurance institute) | 意大利工伤/职业病保险（Istituto Nazionale per l'Assicurazione contro gli Infortuni sul Lavoro） |

## 意大利工作条件术语

| 意大利语术语 | 英语对应词 | 注释 |
|---|---|---|
| orario di lavoro | working hours | 合同和 CCNL 规定的每周标准工时 |
| orario a tempo pieno | full-time hours | 标准全职工时（意大利通常为每周 35-40 小时） |
| lavoro straordinario | overtime | 合同工时之外的工作；按加价费率支付 |
| lavoro notturno | night work | 在指定夜间时段（意大利法通常为 22:00-06:00）的工作 |
| lavoro festivo | work on public holidays | 法定公共假日的工作；须额外补偿 |
| ferie / congedo annuale | annual leave / holiday entitlement | 带薪休假（意大利最低 20 天，CCNL 通常更多） |
| permessi retribuiti | paid leave | 用于特定目的的带薪休假 |
| congedo di maternità | maternity leave | 女雇员产前/产后的带薪假期（意大利约 5 个月） |
| congedo di paternità | paternity leave | 父亲在子女出生时的强制带薪陪产假（自第 234/2021 号法律起意大利为 10 个工作日；另有 1 天可选假期） |
| congedo parentale | parental leave | 可用于子女年满 12 岁之前的育儿假（经修订的立法法令 151/2001）；双方父母合计上限 10 个月（父亲休满 3 个月以上可延长至 11 个月）；每位父母个人最多 6 个月；前三个月按 80% 支付补偿（2024 年奖金），之后月份按 30%，受收入条件限制 |
| malattia / assenza per malattia | sick leave | 因病缺勤；部分带薪（由 CCNL 和法律确定） |
| periodo di comporto | protected sick leave period | 雇主在可解雇前必须容忍病假的最高期限（意大利法概念；依据《民法典》第 2110 条通常为 180 天）；付款和期限由 CCNL 确定 |
| infortunio sul lavoro | workplace accident / occupational injury | 工作产生的身体伤害（通过 INAIL 投保） |
| sede di lavoro | place of work | 雇员履行工作的指定地点 |
| trasferta | business travel / posting | 要求在另一地点工作的临时任务（不同于 "secondment" / "distacco"） |
| smart working / lavoro agile | remote working / agile working | 在雇主场所之外利用电子通信工作；由意大利法（第 81/2017 号法律）规范 |
| telelavoro | telework | 定期在家或远程地点工作；意大利法中的正式安排 |
| mansioni | duties / role | 分配给雇员的任务和责任；变更受意大利法规范（雇员有权抵制不合理降职） |
| inquadramento | classification / grading | 根据适用 CCNL 将雇员分配到合同级别/类别 |
| livello contrattuale | contractual grade / pay grade | CCNL 下的具体工资类别（如 "impiegato di 2° livello"） |
| qualifica | job title / qualification | 职位和所需资格的正式名称 |

## 意大利雇佣类别（法定分类）

| 意大利语术语 | 英语对应词 | 注释 |
|---|---|---|
| dirigente | executive / senior manager | 意大利法定雇佣类别（不仅是职衔）；解雇、通知期（通常 1 个月）、遣散费和福利均有不同规则；需要重大决策权；高薪；无权享有 TFR（而是以单独基金或补充养老金形式支付 TFR 等价物）；相当于"C 级高管"或高级管理层，但法律界定更明确 |
| quadro | middle manager | 意大利法定雇佣类别；介于 "impiegato" 与 "dirigente" 之间；决策角色；有时称为 "quadri"（复数）；解雇和通知规则不同 |
| impiegato | white-collar employee | 意大利法定雇佣类别；办公室职员、专业人员、行政角色；CCNL 下可能有子级别（如 1°、2°、3° 级）；有权享有 TFR；标准解雇/通知规则 |
| operaio | blue-collar worker | 意大利法定雇佣类别；体力/生产工人；CCNL 下可能有子级别；有权享有 TFR；标准解雇/通知规则 |

## 意大利解雇与终止术语

| 意大利语术语 | 英语对应词 | 注释 |
|---|---|---|
| licenziamento | dismissal / termination | 雇主发起的雇佣终止 |
| licenziamento per giusta causa | dismissal for just cause / summary dismissal | 因雇员严重不当行为解雇；无须通知立即终止（意大利法，《民法典》第 2119 条）；不同于 "giustificato motivo" |
| licenziamento per giustificato motivo soggettivo | dismissal for justified subjective reason | 基于未达严重不当行为的雇员行为的解雇（第 604/1966 号法律第 3 条）；需要通知期；不同于 "giusta causa"（《民法典》第 2119 条） |
| licenziamento per giustificato motivo oggettivo | dismissal for justified objective reason | 基于业务需求、技术变革、裁员、公司重组的解雇（第 604/1966 号法律第 3 条）；需要通知并遵守程序；不同于主观事由 |
| licenziamento collettivo | collective dismissal / redundancy | 因业务关闭、重组或重大改组而终止多名雇员；须遵守特别程序（通知、协商、社会计划） |
| licenziamento disciplinare | disciplinary dismissal | 对雇员不当行为经过正式纪律程序后的解雇 |
| dimissioni | resignation | 雇员发起的终止；通常需要通知期 |
| dimissioni per giusta causa | constructive dismissal / resignation for just cause | 因雇主严重违约而成立的雇员辞职；可能使雇员获得如同被解雇的遣散费；意大利概念与推定解雇理论一致 |
| preavviso | notice period | 终止生效前的时长；长度因 CCNL、雇佣级别和解雇事由而异（体力劳动者最低 1 天；其他人各异） |
| periodo di preavviso | notice period | 终止通知后雇员/雇主必须等待的期间 |
| impugnazione del licenziamento | challenge of dismissal / unfair dismissal claim | 雇员质疑解雇有效性的法律行动 |
| reintegrazione | reinstatement | 恢复被解雇雇员职位或同等职位的救济（意大利法可能命令"复职"或赔偿，视情况而定） |
| indennità risarcitoria | compensatory indemnity / damages | 因不当/不公平解雇向雇员支付的金钱（意大利法根据解雇事由和程序合规情况确定适用"复职"还是"赔偿"救济） |
| tutela reale | real protection (reinstatement remedy) | 要求恢复被不当解雇雇员职位的救济（意大利法区分；适用于程序违法或不合理解雇） |
| tutela obbligatoria | obligatory protection (compensation remedy) | 以金钱赔偿代替复职的不公平解雇救济（意大利法区分；在特定情形下可代替复职适用） |

## 意大利集体劳动术语

| 意大利语术语 | 英语对应词 | 注释 |
|---|---|---|
| CCNL / contratto collettivo nazionale di lavoro | national collective bargaining agreement (NCBA) | 雇主协会与工会之间在国家层面谈判达成的总体集体协议；规定整个部门/行业的底限条款（如零售业 "CCNL Commercio"、机械工程业 "CCNL Metalmeccanica"）；意大利为强制性的；适用于所覆盖行业的所有雇员，除非更优的公司级协议提供更高标准；包含雇佣类别（dirigente、quadro、impiegato、operaio）、工资表、工时、休假、通知期、TFR 处理、纪律程序等 |
| contratto integrativo aziendale | company-level collective agreement | 在公司层面由雇主与工会/工人代表谈判达成的协议；补充或改进适用 CCNL |
| accordo sindacale | trade union agreement | 雇主与工会就特定雇佣事项达成的协议 |
| sindacato | trade union | 代表工人与雇主谈判的正式组织 |
| rappresentanza sindacale aziendale / RSA | company trade union representation | 公司层面的工会提名工人代表（意大利法概念） |
| rappresentanza sindacale unitaria / RSU | unified trade union representation | 公司层面的多工会工人代表结构（意大利法概念；跨多个工会的统一代表） |
| assemblea dei lavoratori | workers' assembly | 雇员讨论集体事务的正式会议 |
| diritto di sciopero | right to strike | 工业行动的法定权利；在基本服务中受限 |
| cassa integrazione guadagni / CIG | wage supplementation fund / short-time working scheme | 意大利政府支持计划，在雇主因经济/技术困难减少工时时为雇员提供部分收入 |
| CIG ordinaria | ordinary wage supplementation | 针对临时经济困难的 CIG（最长 12 个月，可延长） |
| CIG straordinaria | extraordinary wage supplementation | 针对重大重组或危机的 CIG（期间较长，通常长于 ordinaria） |
| mobilità (storica) | redundancy scheme (historic) | 旧有的意大利计划，援助因重组而失业的工人；经第 92/2012 号法律基本废止，并于 2017 年 1 月 1 日起在《就业法》下逐步取消；现行对应为 NASpI（失业救济金，立法法令 22/2015）和用于重大重组的 CIGS |
| procedura di licenziamento collettivo | collective redundancy procedure | 大规模解雇的法律程序（需要通知、协商、社会计划；通常至少 1-2 个月通知，视受影响人数而定） |
| consultazione sindacale | trade union consultation | 雇主就重大雇佣决定（如重组、大规模解雇）与工会/工人代表协商的强制性义务 |

## 意大利借调与派遣术语

| 意大利语术语 | 英语对应词 | 注释 |
|---|---|---|
| distacco | secondment | 雇员在保留与派出雇主雇佣关系的情况下，临时到接收公司工作的安排；意大利概念（立法法令 276/2003 第 30 条——Biagi 改革）；如跨境，可能触发欧盟《派驻工人指令》（96/71/EC，经 2018/957 更新） |
| distacco transnazionale | cross-border posting / transnational secondment | 跨境借调；适用欧盟《派驻工人指令》（指令 96/71/EC），要求适用派出国雇佣/派驻条件；经指令 (EU) 2018/957 更新 |
| impresa distaccante | seconding company | 保留与借调工人雇佣关系的雇主；支付工资/福利；负责劳动法合规 |
| impresa utilizzatrice | host company | 使用借调工人服务的雇主；通常不是雇佣合同当事人（尽管可能指挥工作） |
| lavoratore distaccato | seconded employee / posted worker | 由派出公司保留雇佣关系、临时为接收公司工作的雇员 |
| somministrazione di lavoro | temporary agency work | 由职业介绍所向客户雇主提供工人；现由经立法法令 81/2015（《就业法》）修订的立法法令 276/2003（Biagi 改革）第 30 条及后续条款规范。较早的 "lavoro interinale" 由第 196/1997 号法律（Pacchetto Treu）引入，此后已被取代 |
| agenzia per il lavoro | temporary employment agency | 经许可招募并向客户雇主提供临时工人的企业（意大利受规制职业） |
| lavoratore somministrato | agency worker / temporary worker | 由职业介绍所提供的工人；技术上受雇于中介机构，同时为客户履行工作 |

## 关键翻译注释

- **CCNL（Contratto Collettivo Nazionale di Lavoro，全国集体劳动合同）**：规范整个部门/行业的总体集体协议。在意大利雇佣法中为强制性。英文翻译中，保留 CCNL 缩写并在首次出现时附英文全名（如"CCNL Commercio, the National Collective Bargaining Agreement for the Retail Sector"）。关键内容：雇佣类别、工资等级、工时、休假权利、通知期、TFR 处理、纪律程序等。

- **"Giusta causa" 与 "giustificato motivo"**：意大利法中的关键区别，法律后果不同：
  * Giusta causa（《民法典》第 2119 条）：严重不当行为；允许立即解雇且无须通知；雇员无权获得代通知金；遣散待遇较差
  * Giustificato motivo（第 2119 条、第 604/1966 号法律）：较轻事由；需要通知期；全额遣散费/TFR；程序要求较宽松
  不得将两者混同或一律译为 "dismissal for cause"；应保留意大利法律框架。

- **雇佣类别**（dirigente、quadro、impiegato、operaio）：CCNL 下的意大利法定分类，在通知、遣散费、解雇、福利方面规则不同。不是任意的职衔。英文翻译中：
  * Dirigente = executive/senior manager（规则不同；通知期较短；不直接支付 TFR；通常薪酬更高；通知期通常为 1 个月）
  * Quadro = middle manager（中间地位；通知/解雇保护增强；有权享有 TFR）
  * Impiegato = white-collar/professional（CCNL 下可能有 1°、2°、3° 子级别；有权享有 TFR）
  * Operaio = blue-collar/manual worker（CCNL 下可能有子级别；有权享有 TFR）
  在子词典中注明意大利类别；在主词典中译为英文描述。

- **TFR（Trattamento di Fine Rapporto）**：《意大利民法典》第 2120 条。法定遣散费，每年累积（每年约 1/13.5 个月工资），于终止时（退休、辞职、解雇、死亡）支付。普通法无确切对应。译为 "severance indemnity" 或 "end-of-service allowance"，首次出现时在括号中保留 "TFR"。注意：Dirigente 可能不直接领取 TFR（而是向养老金基金支付 TFR 等价物或另行安排）。

- **"Comporto"（受保护病假期）**：意大利法概念。解雇合法化前雇主必须容忍的最高累计期间（依据《民法典》第 2110 条通常为 180 天，但由 CCNL 和判例确定；因行业和公司协议而异）。不同于英/美语境中的 "protected sick leave"。

- **解雇救济**：意大利法为程序无效/不合理解雇提供两种救济：
  * Tutela reale（复职救济）：恢复原职位或同等职位并补发欠薪
  * Tutela obbligatoria（赔偿救济）：以金钱赔偿代替复职
  两者可能视解雇事由和程序违法情况而适用。除非源文本明确对应，否则不得使用英国 "unfair dismissal"（不公平解雇）标准。

- **"Somministrazione di lavoro"**（临时机构用工）：由经立法法令 81/2015（《就业法》）修订的立法法令 276/2003（Biagi 改革）第 30 条及后续条款规范；较早的 "lavoro interinale" 由第 196/1997 号法律引入，此后已被取代。不同于借调（distacco）。中介机构是法定雇主；客户只是服务使用者。适用平等待遇规则（薪酬、福利、工作条件须与客户直接雇员相当）。

- **"Distacco"**（借调）：保留派出雇主的临时委派。由立法法令 276/2003 第 30 条（Biagi 改革）规范。如跨境，适用欧盟《派驻工人指令》（96/71/EC，经 2018/957 更新）。不同于 "trasferta"（出差）。

- **《就业法》参考**：意大利雇佣法经立法法令 23/2015（《就业法》）重大改革。关键变化：取消 co.co.co. 作为标准形式；为合同引入"真正独立"标准；修改小公司的解雇救济（不同的赔偿上限）；改变试用期规则；加强对永久合同的保护。如源文本涉及《就业法》前后的法律，在子词典中注明区别。

- **通知期**：因 CCNL、雇佣级别和解雇事由而异。示例：
  * 体力劳动者（"operaio"）：通常 1-2 天通知
  * 办公室/专业（"impiegato"）：通常 1-2 个月
  * 中层管理（"quadro"）：通常 1-3 个月
  * 高管（"dirigente"）：通常 1 个月（往往短于 impiegato）
  具体通知期始终以适用 CCNL 或雇佣法为准。

- **CIG（Cassa Integrazione Guadagni，工资补充基金）**：意大利工资补充基金。政府资助的计划，为因临时经济/技术困难（CIG ordinaria）或重大重组（CIG straordinaria）而减少工时的雇员提供部分收入（通常为工资的 80%）。工人仍保持雇佣关系；不同于失业救济金。时长因类型和政府授权而异。

- **Mobilità**：意大利裁员计划，为因重组而失业的工人提供收入支持。不同于 CIG；预示重组后可能被永久解雇。

- **INPS / INAIL**：强制性保险计划：
  * INPS（Istituto Nazionale della Previdenza Sociale）：国家社会保障机构；管理养老金、失业、生育、残疾福利
  * INAIL（Istituto Nazionale per l'Assicurazione contro gli Infortuni sul Lavoro）：工伤保险；雇主缴纳保费；覆盖工伤事故和职业病

- **集体裁员程序（procedura di licenziamento collettivo）**：雇主因重组解雇多名雇员时必需。强制与工会协商、社会计划谈判、最低通知期（视受影响人数而定，通常为 1-2 个月）。未遵循程序可能使解雇无效。
