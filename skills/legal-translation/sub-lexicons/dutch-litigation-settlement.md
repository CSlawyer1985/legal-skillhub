# 荷兰语——诉讼与和解子词典

由翻译经验自动生成。将荷兰民事、行政和刑事诉讼词汇映射到正确的英语对应词。荷兰民事诉讼由《民事诉讼法典》（Wetboek van Burgerlijke Rechtsvordering，Rv）规范；刑事诉讼由《刑事诉讼法典》（Wetboek van Strafvordering，Sv）和《刑法典》（Wetboek van Strafrecht，Sr）规范；行政程序由《行政法通则》（Algemene wet bestuursrecht，Awb）规范。

## 译者说明

- **Dagvaarding 与 verzoekschrift**：荷兰民事诉讼有两条主要途径。Dagvaarding（传票令状）——适用于大多数需要司法令状启动诉讼的民事事项。Verzoekschrift（请愿书）——适用于家事、劳动（2020 年改革前）、遗嘱认证和一些公司事项。时限不同，当事人术语不同（eiser/gedaagde 对 verzoeker/verweerder）。始终识别程序并一致翻译。
- **Kort geding**：荷兰标志性程序工具。基于"spoedeisend belang"（紧急利益）在 voorzieningenrechter 面前的快速救济程序（通常 4 周内出结果）。广泛用于知识产权、不正当竞争、合同执行。译为 "preliminary relief proceedings" 并加注释——绝不可仅译为 "summary proceedings"（过于狭窄）。
- **Vonnis、arrest 与 beschikking**：Vonnis = 一审判决（传票程序）。Arrest = gerechtshof 或 HR 的判决。Beschikking = 命令/决定（请愿程序、小额事项、破产）。三个不同的术语，三套不同的规则。绝不可一律压扁为 "judgment"。
- **Hoger beroep 与 cassatie**：Hoger beroep = 向 gerechtshof 的全面上诉（事实 + 法律复审）。Cassatie = 由 Hoge Raad 仅就法律问题进行的审查（不复审事实）。性质根本不同。分别译为 "appeal" 和 "cassation"。
- **Ondernemingskamer（OK）**：阿姆斯特丹上诉法院内的专门公司法庭。管辖调查程序（enquêteprocedure）、董事免职、法定争议解决（geschillenregeling）、挤出合并。荷兰独特机构。译为 "Enterprise Chamber"（标准英语译法）。
- **Netherlands Commercial Court（NCC）**：自 2019 年 1 月起在阿姆斯特丹地方法院和阿姆斯特丹上诉法院运作的英语商事法庭。经当事人协议管辖超过 25,000 欧元的国际商事争议。译为 "Netherlands Commercial Court"——保留英语名称。
- **Awb / bestuursrecht**：荷兰行政法统一于 Awb。在向 bestuursrechter 上诉之前必须经过"bezwaar"（向行政机构本身提出异议）。起诉资格采用 belanghebbende 测试。原则不同于民事诉讼（evenredigheid、zorgvuldigheid、motivering）。绝不可用民事术语翻译行政程序。
- **Woo（Wet open overheid）**：2022 年 5 月取代 Wob。披露义务更广。译为 "Open Government Act"——2022 年前的文件注意标注过渡。
- **WAMCA（2020 年）**：重大改革，使损害赔偿的集体诉讼成为可能（此前仅限于宣告/禁令）。注册的代表组织拥有专属地位，荷兰居民的 opt-out。译为 "Collective Damages Act"；始终标注 WAMCA 的适用性。
- **WCAM（2005 年）**：全球拘束力的和解机制。和解由阿姆斯特丹上诉法院宣布对全体群体具有拘束力；群体成员有退出权。用于 Converium、Shell、Fortis 群体侵权案件。不同于 WAMCA（后者使诉讼成为可能；WCAM 使和解成为可能）。
- **Vaststellingsovereenkomst（BW 7:900）**：荷兰和解协议文书。即使基于对法律的错误理解也具拘束力。常用于解决民事和商事争议。译为 "settlement agreement"；说明其拘束性质。
- **Dwangsom（第 611a 条 Rv）**：为强制遵守判决而设的司法罚金。必须请求——非自动适用。不同于合同约定的 boete。译为 "penalty payment" 或 "astreinte"（大陆法系）并加注释。
- **Bewijslast / stelplicht**：荷兰证据法有两个不同的负担：stelplicht（在书状中充分陈述事实的义务）和 bewijslast（事实被争议时的举证责任）。stelplicht 在先——陈述不充分的，将不采证。stelplicht 译为 "duty to set out facts" 或 "pleading burden"；绝不可压扁为 "burden of proof"。
- **Verjaring、vervaltermijn 与 klachttermijn**：三个不同的时效概念。Verjaring = 时效，可通过中断行为（如书面提醒）中断。Vervaltermijn = 除斥期间，绝对的（不可中断、不可延长）。Klachttermijn = 投诉义务（BW 6:89、7:23）——沉默可能导致权利丧失。三者都重要——绝不可混同。
- **Advocaat 与 procureur**：2008 年改革前，当事人需要当地 procureur 加 advocaat。自《废除 procuraat 法》（2008 年）起，律师全国执业。"advocaat" 译为 "attorney"、"lawyer" 或 "advocate"（视受众而定）；"procureur" 仅用于历史语境。
- **OM / Officier van justitie**：Openbaar Ministerie（公诉机关）是总称；officier van justitie 是个别检察官。在 Hoge Raad，该角色为 advocaat-generaal（AG）。一致翻译并标明机构层级。
- **TBS（terbeschikkingstelling）**：荷兰刑法中对危险精神障碍犯罪人的措施——无限期安保治疗，不同于监禁。荷兰独特机构。译为 "TBS-order" 或 "placement under hospital order" 并加注释。
- **Strafbeschikking / transactie**：两种庭外刑事解决机制。Strafbeschikking = OM 发出的刑罚命令，作出有罪认定（2008 年起）。Transactie = 较旧、2008 年前的机制，避免有罪认定。两者都避免审判，但法律地位不同。注意标注并谨慎翻译。
- **Arbitragewet 2015 / NAI**：2015 年荷兰仲裁法的重大现代化（现为 Rv 第四编）。NAI（荷兰仲裁协会）是主要机构机构。阿姆斯特丹越来越常用作仲裁地。译为 "Arbitration Act 2015" 和 "Netherlands Arbitration Institute"。
- **Bindend advies 与 arbitrage**：荷兰 ADR 区分 bindend advies（有约束力的专家裁定——依 BW 7:904 可就明显错误审查）与 arbitrage（仲裁——裁决具有纽约公约可执行性）。制度不同——绝不可混淆。bindend advies 译为 "binding advice" 并加注释；arbitrage 译为 "arbitration"。
- **Proceskostenveroordeling / liquidatietarief**：荷兰费用制度不是完全赔偿——可追偿费用受法官设定的固定费率表（liquidatietarief）限制，知识产权事项（依第 1019h 条 Rv 全额费用）和某些其他特定领域除外。忠实翻译并标注费用追偿限制。
- **比利时民事诉讼**：由 Gerechtelijk Wetboek（GerW）/ Code judiciaire 规范——编号和术语不同于荷兰 Rv。比利时与荷兰类似地使用"kort geding"。比利时上诉至 Hof van Beroep / Cour d'appel；撤裁审至 Hof van Cassatie / Cour de cassation。注意标注比利时文件。
- **比利时行政程序**：由关于 Raad van State / Conseil d'État 的协调法律规范。不同于荷兰 Awb 制度——比利时有统一行政高等法院（Raad van State，Afdeling Bestuursrechtspraak）。注意标注比利时行政文件。
- **比利时刑事诉讼**：比利时使用 Wetboek van Strafvordering / Code d'instruction criminelle（拿破仑式）和 Strafwetboek / Code pénal。预审法官（onderzoeksrechter / juge d'instruction）的作用大于荷兰 R-C。术语不同。
