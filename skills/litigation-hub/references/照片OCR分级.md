# 照片 / 扫描件 OCR 分级（第三步输入方式三的做法层）

SKILL.md 只留「双级降级 + 质量门控阈值 + 归纳须确认」，本文件放分级细则、评分表与输出模板。

## 双级降级策略

`scripts/court_photo_ocr.py` 按 Tier 1 → Tier 2 顺序自动尝试，每级结果经**质量门控**判断，通过即停止降级。

```bash
# 自动双级降级（默认）
python3 scripts/court_photo_ocr.py /path/to/传票照片.jpg

# 强制指定 OCR 引擎（调试用）
python3 scripts/court_photo_ocr.py --ocr-tier tesseract /path/to/传票照片.jpg
```

| 层级 | 引擎 | 方式 | 速度 | 精度 | 依赖 | 适用场景 |
| --- | --- | --- | --- | --- | --- | --- |
| Tier 1 | **Tesseract** | 本地 | ⚡ 快 | 中 | `brew install tesseract tesseract-lang` | 清晰打印文书，自动灰度+对比度增强预处理 |
| Tier 2 | **MinerU** | 云端 | 🐢 中 | 高 | `npm install -g mineru-open-api`（自动安装） | 复杂排版、模糊照片、手写体混排 |

**Tier 1 图片预处理**：Tesseract 处理前自动对图片做灰度化 + 1.5x 对比度增强 + 超大图缩放——零额外依赖，显著提升模糊/低对比度照片成功率。

## 质量门控评分

综合中文字符数 + 占比 + 文本长度 + 案号 + 法院关键字，满分 100，≥50 分通过：

| 条件 | 分值 |
| --- | --- |
| 有中文字符（≥10 个，且占比 ≥20%） | +30 |
| 长度 > 50 字符 | +20 |
| 长度 > 200 字符 | +20 |
| 可提取案号 | +15 |
| 命中法院文书关键字 | +15 |

- ≥ 50 分 → 通过，停止降级
- < 50 分 → 自动降级到 Tier 2

> **设计理念（第一性原理）**：Tesseract 怕模糊但零网络依赖，MinerU 怕断网但对复杂排版好。双级覆盖两种失败路径，且每级都是轻量方案——不做 PaddleOCR 那种 500MB+ 的重武器下载。

## 结构化解析

提取的文字经正则匹配得到案号、案由、当事人、开庭时间/地点等，附带置信度标记。

## 后续流程

- 识别到传票 / 出庭通知 → 跳过下载步骤 → 归档 + 日历提醒
- 识别到判决书 → 计算上诉期限

1. 检查图片清晰度
2. 可考虑安装 PaddleOCR（约 500MB，中文法院文书精度最高，无需网络）作为第三级兜底
