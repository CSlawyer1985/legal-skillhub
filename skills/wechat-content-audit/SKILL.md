# 全平台内容合规审核

## 概述

该技能对拟发布内容进行全平台合规审核。默认以微信公众号为主要发布平台（严格审核），同时标注其他平台（头条/知乎/小红书/抖音/B站）的特有规则差异，实现"一次审核、全平台适配"。

支持平台：微信公众号 | 今日头条 | 知乎 | 小红书 | 抖音 | 哔哩哔哩

---

## 第一维度：政治安全审核（🔴 红线，全平台最严格）

### 通用检查项（所有平台必须通过）

- ❌ 国家领导人、政治人物负面表述
- ❌ 涉及台湾/香港/澳门的错误称谓（必须为"中国台湾""中国香港""中国澳门"）
- ❌ 涉及新疆、西藏、南海等敏感地区争议
- ❌ 意识形态争议、体制批评、历史虚无主义
- ❌ 对现行政策法规的负面评价或煽动性言论
- ❌ 涉密信息、军事敏感内容
- ❌ 民族歧视、地域攻击、宗教争端

### 各平台差异

| 平台 | 特殊规则 |
|------|---------|
| **公众号** | 最严格。历史类内容涉近现代史需格外谨慎，评论区也需监控 |
| **头条** | 算法自动巡检+人工复审。标题中的擦边表述也会被拦截 |
| **知乎** | 涉政问答易被锁定。学术讨论中的历史研究需标注"学术探讨" |
| **小红书** | 评论区政治敏感同样触发限流。涉及出境/移民话题需中性表述 |
| **抖音** | 视频+音频双重审核。背景音乐、画面中的旗帜/地图元素都会被检测 |
| **B站** | 二创内容涉政风险高。鬼畜/恶搞政治人物直接封禁 |

### 判定标准

只要涉及以上任一项 → 🔴 高风险，**必须删除或修改后重新审核**，绝不可发布。

## 第二维度：医疗健康合规审核（🔴 红线）

### 通用检查项

- ❌ "治愈""根治""特效""包好""永不复发"等绝对化疗效宣称
- ❌ 暗示替代正规医疗、"不用去医院"等引导
- ❌ 宣传未经 NMPA/FDA 批准的药品/疗法/器械
- ❌ 引用未经监管机构批准的临床数据
- ❌ 个人健康建议（"我建议你吃XX药"）
- ❌ 宣扬伪科学、偏方、玄学疗法
- ⚠️ 提及具体药品品牌/药企 + 正面评价 → 可能触发广告规则

### 制药行业特别规则（全平台通用）

- 提及药企/药品：只能引用 NMPA/FDA/EMA 公示的注册/审批信息
- 在研药物：必须明确标注"尚未获得上市批准""处于临床X期"
- 仿制药一致性评价：引用数据必须来自 CDE 公示
- GMP 合规讨论：不可暗示某企业"违规但未被发现"
- 集采相关：不可对未中标企业做负面推测

### 各平台差异

| 平台 | 特殊规则 |
|------|---------|
| **公众号** | 医疗健康类内容可能需要资质认证。非认证账号不可发布疾病诊疗建议 |
| **头条** | 健康领域需"健康资质认证"。无认证账号健康类内容会被限流 |
| **知乎** | 回答中引用医学文献需标注出处。"个人经验"需声明非医疗建议 |
| **小红书** | 最严格。任何涉及"变美""变瘦""变健康"的效果对比图都可能违规。保健品/医美/药品需特殊行业资质 |
| **抖音** | 医疗健康类账号需"黄V认证"（执业医师/医院认证）。无资质不可做任何诊疗建议 |
| **B站** | 科普类相对宽松，但涉及具体病例/治疗建议同样需资质 |

### 判定标准

发现明确违规 → 🔴 高风险，**必须删除或修改**。

## 第三维度：虚假信息审核（🟡 高）

### 通用检查项

- **数据来源可追溯**：必须标注出处（机构名+时间），不可"据研究显示""有数据表明"而无源
- **案例真实性**：不可编造企业/个人案例，真实案例需保留可查证线索
- **行业数据一致性**：以国家药监局、FDA、工信部、WEF 等权威源为准
- **未经证实的行业传言**：不可传播"据说""内部消息""知情人士透露"等
- **预测性表述**：需使用"可能""预计""或在……条件下"等限定词
- **时效性标注**：引用旧数据/旧政策时需注明时间，避免误导

### 各平台差异

| 平台 | 特殊规则 |
|------|---------|
| **公众号** | 造谣类内容可被永久封号。社会事件类内容传播谣言后果严重 |
| **头条** | 算法对标题党+假数据的组合极其敏感。被判定为虚假信息会全网降权 |
| **知乎** | 虚假信息举报机制完善。"编故事"类回答会被折叠甚至封号 |
| **小红书** | 虚假种草/虚假测评 → 限流+封禁。效果对比图如被判定造假后果严重 |
| **抖音** | AI检测+人工复审双机制。"摆拍"类内容需标注"剧情演绎" |
| **B站** | 虚假科普/伪科学内容会被社区标记。UP主信用分制度 |

---

## 第四维度：广告营销审核（🟡 高）

### 通用检查项

- ❌ 未标注的软文/植入广告（各平台均要求广告可识别）
- ❌ 直接出现手机号、微信号、二维码等联系方式引流
- ❌ 引导至外部电商平台购买链接（部分平台允许但需标注）
- ❌ 明显的自家产品/服务推销（非品牌号）
- ⚠️ 品牌名称+正面评价连用 → 可能被判定为广告

### 各平台差异

| 平台 | 特殊规则 |
|------|---------|
| **公众号** | 允许合规广告。广告需与内容有明确区隔。保健品/金融/医疗广告需特殊资质 |
| **头条** | "巨量引擎"广告系统管理。内容中嵌入广告未通过官方系统会被降权 |
| **知乎** | "好物推荐"功能可合规带货。回答中软植入未标注会被折叠 |
| **小红书** | 商业合作需通过"蒲公英"平台报备。未报备的种草笔记会被判定为违规广告 |
| **抖音** | 带货需开通"商品分享"功能。非橱窗链接引导外站 → 违规 |
| **B站** | "花火"平台管理商单。未标注"合作"的视频会被限流 |

---

## 第五维度：侵权风险审核（🟡 高）

### 通用检查项

- **图片版权**：AI 生成图片需注明；非原创图片需确认授权或使用 CC0/免版权素材
- **文字原创度**：直接翻译/大量改写他人文章需注明来源
- **商标/品牌引用**：合理引用（事实陈述）可接受；恶意贬低他人品牌 → 侵权风险
- **数据引用**：引用第三方报告/数据库需标注来源
- **肖像权**：使用他人照片/形象需授权或属新闻公开报道范畴

### 各平台差异

| 平台 | 特殊规则 |
|------|---------|
| **公众号** | 原创声明机制。抄袭被举报三次 → 永久关闭原创功能 |
| **头条** | 文章相似度检测。与已发布内容高度重合会自动判定为"非原创"降权 |
| **知乎** | 洗稿/抄袭 → 折叠+封号。"转载"需标注来源并经授权 |
| **小红书** | 图片相似度检测。盗用他人图片会被下架 |
| **抖音** | 视频查重机制极强。搬运视频会被限流至几乎零播放 |
| **B站** | 版权保护最严格。音乐/影视素材侵权直接下架。二创需符合合理使用原则 |

---

## 第六维度：低质内容审核（🟢 中）

### 通用检查项

- **标题党**：标题与正文不符、过度夸张、故意留悬念诱导点击
- **内容空洞**：大量重复、水文、无实质信息
- **恶意蹭热点**：与内容无关强行关联热点事件的标签/关键词
- **配图无关**：用吸睛但与内容完全无关的图片
- **洗稿痕迹**：大量同义词替换、段落拼接、缺乏原创观点

### 各平台差异

| 平台 | 特殊规则 |
|------|---------|
| **公众号** | 低打开率的文章可能被减少推荐 |
| **头条** | 算法对内容质量评分。低质 → 零推荐量 |
| **知乎** | "答非所问"会被折叠。高赞低质内容会被复审 |
| **小红书** | 图文不相关 → 不被推荐。内容价值低 → 限流 |
| **抖音** | 完播率/互动率为核心。低质内容算法自动淘汰 |
| **B站** | 踩数/举报影响推荐权重。"水视频"标签化 |

## 第七维度：平台特有规则（🟡 高）

### 微信公众号特有规则

- 每日群发次数限制（订阅号1次/天，服务号4次/月）
- 非认证账号不可发布时事政治评论
- 原创声明文章需≥300字
- 不可诱导分享/关注（"转发到朋友圈才能看"等）

### 今日头条特有规则

- 标题与正文需一致，不可故意制造悬念式标题
- 不可在正文开头故意重复标题
- 垂直领域匹配：账号领域与内容需一致

### 知乎特有规则

- "先问是不是，再问为什么"——回答需先回应问题核心
- 付费咨询内容不可在普通回答中推广
- 专业领域回答"资质背书"权重高

### 小红书特有规则

- 图文笔记图片≤9张。视频笔记封面需原创
- "医美/保健品/金融"等特殊行业需蓝V/行业资质
- 关键词不能堆砌（标题+正文+标签中出现相同词≥5次会被判定为SEO作弊）

### 抖音特有规则

- 视频时长≥7秒可推荐（部分领域除外）
- 硬广前3秒即判定广告 → 不推荐
- 危险动作/不良引导 → 内容下架
- 药品/医疗器械/医美 → 需行业资质+白名单

### B站特有规则

- 转载视频需标注来源
- 争议性内容需开启"争议话题"标签
- 涉及未成年人的内容审核更严格
- 鬼畜/二创类内容不可恶意丑化他人

## 判定规则

- 🔴 维度中出现 ❌ → **整体判定 ❌ 不通过**，绝不推送任何平台
- 🟡 维度中出现 3 个及以上 ⚠️ → 整体判定 ⚠️ 有条件通过
- 其他情况 → ✅ 通过

---

## 注意事项

- **逐平台适配**：同一篇文章在不同平台的容忍度不同。微信公众号最严 → 以公众号为基准审核
- **领域差异**：制药/生物医药 → 重点看医疗健康合规；制造/工业 → 重点看虚假信息（数据+案例）
- **多平台发布策略**：先公众号发布 → 再根据本文档调整各平台版本（标题/导语/配图做差异化）
- **审核顺序**：先审公众号（最严）→ 通过后标注其他平台的差异项 → 逐平台调整发布
- **红线原则**：🔴 维度任何平台不通过 = 所有平台都不发布
- **时效提醒**：平台规则持续更新，如有重大政策调整需重新审核
