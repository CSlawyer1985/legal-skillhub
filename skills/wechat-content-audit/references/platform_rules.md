# 全平台内容审核规则速查表

## 一、审核维度通用规则

### 1.1 政治安全（全平台一致红线）

以下内容在所有平台均禁止发布：

- 涉及国家领导人（含谐音/代称/外号）的负面内容
- "台湾""香港""澳门"未标注"中国"前缀
- 新疆/西藏/南海等地区的分裂主义言论
- 体制批评、意识形态攻击、历史虚无主义
- 涉密/军事/国家安全信息
- 民族歧视、地域攻击、宗教冲突煽动

发布策略：如内容哪怕只有 0.01% 的涉政风险 → 删除相关段落，全文复审后再发布。

### 1.2 医疗健康合规（行业红线）

制药/生物医药内容特别注意以下"雷区"：

| 雷区表述 | 正确替代 |
|---------|---------|
| "治愈XX病" | "用于XX病的治疗""在XX适应症中表现出临床获益" |
| "根治" | "达到临床缓解"或引用具体临床终点数据 |
| "特效药" | "在特定患者群体中显示出优效性" |
| "最新疗法" | 标注"XXXX年获批的XX疗法" |
| 在研药物疗效肯定 | "目前处于临床XX期，初步数据显示……尚待进一步验证" |
| "不用去医院" | 🚫 绝对禁止 |

### 1.3 虚假信息分类

| 类型 | 判定标准 | 处理 |
|------|---------|------|
| 数据造假 | 无法追源、与权威数据矛盾 | 删除 |
| 案例编造 | "某企业""某位高管"等无具体指向 | 改为真实案例或删除 |
| 政策误读 | 曲解政策原意、选择性引用 | 修改 |
| 时序混乱 | 旧数据/旧政策未标注时间 | 标注时间 |
| 言过其实 | 以偏概全、绝对化断言 | 添加限定词 |

### 1.4 广告营销判定标准

以下组合触发广告嫌疑：

- 品牌名称 + 正面评价（"XX药的疗效很好"）= ⚠️ 广告嫌疑
- 品牌名称 + 联系信息 = ❌ 明确广告
- 多次出现同一品牌（≥3次）= ⚠️ 广告嫌疑
- 文章中嵌入购买链接/二维码 = ❌ 明确广告

例外：新闻事实引用（"2024年NMPA批准了XX药上市"）、学术讨论中的正常引用不视为广告。

## 二、各平台规则速查

### 2.1 微信公众号

| 项目 | 规则 |
|------|------|
| 发布频率 | 订阅号 1次/天（可发多篇），服务号 4次/月 |
| 原创声明 | ≥300字可声明原创。抄袭3次 → 永久关闭 |
| 时政内容 | 非认证账号不可发布时事政治评论 |
| 医疗健康 | 需医疗健康类目资质。无资质不可发诊疗建议 |
| 广告要求 | 广告需与正文有明确区隔。保健品/金融/医疗需特殊资质 |
| 分享诱导 | 🚫 禁止（"转发朋友圈才能看全文"等） |

### 2.2 今日头条

| 项目 | 规则 |
|------|------|
| 标题规范 | 标题与正文需一致。不可故意制造悬念（"真相竟然是……"） |
| 非原创判定 | 相似度检测（与站内已发布内容对比）。高度重合 → 降权 |
| 健康领域 | 需"健康资质认证"。无资质 → 限流 |
| 广告系统 | 广告需通过"巨量引擎"投放，内容中嵌入非官方广告 → 降权 |
| 内容质量分 | 算法评分。低质 → 零推荐量 |
| 垂直度 | 账号领域与内容需匹配，跨领域发布权重低 |

### 2.3 知乎

| 项目 | 规则 |
|------|------|
| 回答规范 | 需回应问题核心。答非所问 → 折叠 |
| 原创保护 | 洗稿/抄袭 → 折叠+封号。转载需授权 |
| 专业背书 | 专业领域"资质认证"回答权重更高 |
| 广告规则 | 软植入未标注 → 折叠。"好物推荐"可合规带货 |
| 内容质量 | "编故事"被举报 → 封号。高赞低质内容会被复审 |
| 引用规范 | 引用数据/文献需标注来源 |

### 2.4 小红书

| 项目 | 规则 |
|------|------|
| 图文规范 | 图片≤9张。封面需原创。图文不相关 → 不推荐 |
| 医美/健康 | 最严。无蓝V/行业资质 → 禁止。保健品/医美需特殊资质 |
| 广告报备 | 商业合作需通过"蒲公英"平台报备。未报备 → 违规 |
| 关键词规范 | 标题+正文+标签中相同词出现≥5次 → SEO作弊判定 |
| 图片版权 | 相似度检测。盗图 → 下架 |
| 虚假种草 | 虚假测评/种草 → 限流+封禁 |

### 2.5 抖音

| 项目 | 规则 |
|------|------|
| 视频时长 | ≥7秒可推荐（部分领域除外） |
| 广告判定 | 前3秒即判定。硬广前3秒 → 不推荐 |
| 医疗健康 | 需"黄V认证"（执业医师/医院）。无资质 → 不可做诊疗建议 |
| 药品/器械 | 需行业资质 + 白名单 |
| 原创保护 | 视频查重极严。搬运 → 零播放 |
| 内容审核 | AI检测+人工复审双机制。"摆拍"需标注"剧情演绎" |
| 带货规则 | 需开通"商品分享"。引导外站链接 → 违规 |

### 2.6 哔哩哔哩

| 项目 | 规则 |
|------|------|
| 版权保护 | 最严。音乐/影视素材侵权 → 直接下架 |
| 二创规范 | 需符合合理使用原则。不可恶意丑化他人 |
| 转载规范 | 需标注来源。长期转载无原创 → 限流 |

## 三、全平台发布优先级

```
内容创作完成
    │
    ▼
【主平台】微信公众号 ── 最严格审核
    │ ✅ 通过
    ├── 今日头条 ── 调整标题（去悬念化）+ 补充数据源
    ├── 知乎 ── 调整为问答体 + 添加文献引用
    ├── 小红书 ── 缩短篇幅 + 重点配图 + 去专业化口语化
    ├── 抖音/B站 ── 转换为视频脚本（非本文档范围）
    │
    ❌ 不通过 → 修改 → 重新开始
```

## 四、常见违规案例与规避

### 案例 1：制药文章中的"疗效暗示"

❌ 违规："XX新药在临床试验中表现优异，有望成为患者的新选择"
✅ 合规："XX新药在III期临床试验中达到了主要终点（P<0.01），已于20XX年X月提交NDA申请"

### 案例 2：制造文章中的"政治擦边"

❌ 违规："中国制造业的崛起得益于廉价劳动力和环境成本的牺牲"
✅ 合规："中国制造业经历了从劳动密集型向技术密集型的转型过程"

### 案例 3：数据引用的"无源之水"

❌ 违规："据统计，95%的制造企业……"
✅ 合规："根据工信部2025年报告，国内规模以上制造企业中……"

### 案例 4：跨平台的"标题适配"

| 平台 | 同一篇文章的标题风格 |
|------|---------------------|
| 公众号 | "灯塔工厂背后，藏着一套被忽视的'笨功夫'" |
| 头条 | "全球224座灯塔工厂，中国占101座。但真正的门槛不是技术" |
| 知乎 | "为什么中国能拿下全球近一半的灯塔工厂？" |
| 小红书 | "101座灯塔工厂的秘密：不是砸钱买设备那么简单" |
| 抖音 | 视频封面文案："聪明工厂的笨办法" |
