# 法规与类案 CLI 检索式生成指南

适用于 `litigation-strategy-report` skill。目标是将案情、争议焦点、请求权基础、抗辩事由和诉讼策略问题稳定改写为 deli-cli 可执行的检索主题或事实摘要，并将返回结果映射到《诉讼策略与类案检索报告》。

使用本指南前，必须先执行 [cli-common.md](./cli-common.md) 中的前置检查和命令发现步骤。

## 一、CLI 命令使用原则

1. 先用 `npx @delilegal/deli-cli@latest cmds litigation-strategy-report@1.0.0` 获取本次 `RUN id`、命令名和参数。
2. 后续调用必须采用当次返回的 `npx @delilegal/deli-cli@latest run_... <command> [options]` 形态。
3. 不在本指南中固化真实命令名；以下示例中的 `law-search`、`case-search`、`similar-case`、`strategy-support` 仅表示可能的命令类型，实际以 `cmds` 输出为准。
4. 检索参数优先在 `cmds` 返回的 `usage` 和 `params` 中选择，不主动假设 `--query`、`--semantic`、`--long-text`、`--page`、`--size`、案由或法院筛选参数一定存在。
5. 每次调用都要记录检索目的、争议焦点、检索主题和 CLI 返回数量，便于写入报告“检索范围与效力层级说明”。

示例 `cmds` 返回后，实际调用可能形如：

```bash
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 law-search --semantic "买卖合同中买方拒绝收货，双方就合同解除条件及违约责任发生争议，需要核验请求权基础、解除条件和违约责任规则"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 case-search --query "买卖合同 货物质量瑕疵 拒付货款 举证责任"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 similar-case --long-text "卖方已交货，买方以货物质量不合格为由拒付尾款，争议焦点为质量瑕疵举证责任、验收期限和违约责任承担"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 strategy-support --semantic "原告拟主张解除合同并请求违约金，需要评估主请求、备选请求、证据补强和对方抗辩"
```

以上仅为参数组织示例。正式执行时必须替换为当次 `cmds` 返回的 `run_...`、命令名和参数。

## 二、先判断检索对象与策略

- 规范适用争议更强时，优先检索法规、司法解释和规范性文件。
- 裁判倾向、举证责任、违约责任、损失认定、责任比例或本地法院口径更重要时，优先检索案例。
- 诉讼请求设计、备选方案、程序策略或证据补强需要外部支持时，优先调用当前 `cmds` 中与策略辅助、类案匹配或综合分析相符的命令。
- 同一争议焦点可以分别检索法规和案例，但每次调用必须目的明确。
- 不把多个争议焦点混在同一检索式里；必要时拆成多个检索主题并向用户说明会产生多次调用。

## 三、争议焦点拆解

先把用户案情拆成可检索焦点，再决定调用命令。优先拆成以下类型：

| 焦点类型 | 检索目标 | 报告映射 |
| --- | --- | --- |
| 请求权基础 | 找到可主张的法律依据和构成要件 | 二、法条检索结果与适用分析 |
| 抗辩事由 | 识别对方可能抗辩及成立条件 | 四、综合诉讼策略建议 |
| 举证责任 | 判断关键证据缺口和证明标准 | 二、法条检索结果与适用分析；四、证据链完善 |
| 类案事实对照 | 找事实结构相近的裁判规则 | 三、类案检索结果与裁判规则提炼 |
| 损失与责任比例 | 判断支持范围、调整规则和风险 | 三、裁判规则抽象；四、诉请设计 |
| 程序策略 | 管辖、保全、鉴定、调解、和解窗口 | 四、程序策略与时间成本考量 |

## 四、法规检索式生成规则

### 1. 何时用短主题

出现下列信息时，可组织短主题：

- 明确提到法规名称；
- 明确提到发文字号；
- 能总结出稳定的规范关键词。

写法：

- 优先保留法规全称或常用简称；
- 能写发文字号时直接写入；
- 再补 1 到 3 个核心问题词；
- 避免口语化修饰和无关事实细节。

示例：

```text
中华人民共和国民法典 买卖合同 合同解除
法释〔2020〕17号 格式条款
民间借贷 利率上限 逾期利息
```

### 2. 何时用语义问题

出现下列情况时，使用自然语言法律问题或事实摘要：

- 用户没有给出具体法规，但能概括成规范适用问题；
- 需要围绕法律要件、责任分配或规则边界寻找依据；
- 短主题结果过窄、过散或不贴合争议焦点。

写法：

```text
<法律关系>中，因<关键事实>引发<核心争点>，需要核验<请求权基础/抗辩事由/责任规则/举证责任>
```

示例：

```text
买卖合同中，买方以货物质量不合格为由拒绝支付尾款，需要核验质量异议期限、举证责任和违约责任规则。
```

## 五、案例与类案检索式生成规则

### 1. 何时用短主题

出现下列信息时，可组织案例短主题：

- 明确提到案件名称；
- 明确提到当事人信息；
- 明确提到案号；
- 能总结出稳定的案由或争议关键词。

示例：

```text
房屋买卖合同纠纷 阴阳合同 违约金调整
竞业限制纠纷 经济补偿 违约金过高
民间借贷 利率超过四倍LPR
```

### 2. 何时用长文本事实摘要

出现下列情况时，使用长文本或事实摘要：

- 只有案情描述，没有明确案件标识；
- 需要寻找事实结构相近、裁判思路接近的类案；
- 短主题命中大量噪声；
- 用户提供了完整案件材料。

写法：

```text
<当事人关系>中，因<关键行为>引发<争议焦点>，造成<结果/后果>，需要判断<裁判倾向/举证责任/责任比例/诉请支持范围>
```

示例：

```text
卖方已交货，买方以货物质量不合格为由拒付尾款，双方争议焦点为质量瑕疵举证责任、验收期限和违约责任承担。
```

## 六、诉讼策略辅助检索式

当需要形成诉讼请求、备选方案、证据补强、抗辩预判或程序策略时，可将检索主题写成“策略问题 + 事实边界 + 目标”。实际是否存在对应命令，以 `cmds` 输出为准。

模板：

```text
<我方身份>拟主张<诉讼请求或程序动作>，核心事实为<事实边界>，需要评估<主张路径/备选请求/证据补强/对方抗辩/和解窗口>
```

示例：

```text
原告拟主张解除合同并请求违约金，核心事实为卖方已交货但买方以质量瑕疵拒付尾款，需要评估主请求、备选请求、证据补强和对方质量抗辩。
```

## 七、结果映射到报告

- 法规结果：提取规范名称、条文或要旨、效力层级、时效状态和本案适用要件，写入“法条检索结果与适用分析”。
- 案例结果：提取案号、法院、裁判日期、案由、裁判要点、相似事实和差异事实，写入“类案检索结果与裁判规则提炼”。
- 策略辅助结果：提取主张路径、程序建议、证据补强、风险提示和待核事项，写入“综合诉讼策略建议”。
- 不引用 CLI 未返回或用户未提供的法条、案号、法院、裁判日期、裁判观点、周期或成本数据。
- 对结果数量少、地域不匹配、事实差异大的类案，必须标注“类案不足”“可迁移性有限”或“需人工复核”。

## 八、无结果或结果不足

单次检索无结果或结果明显失焦时：

1. 先说明本次检索不足，不自动连续换词重试。
2. 给出一个建议改写的检索主题或事实摘要。
3. 如确需从法规检索切换到案例检索，或从短主题切换到长文本，先说明理由。
4. 在最终报告中只引用有效命中的结果；若无法取得稳定依据，标注“检索受限”“类案不足”或“结论待核”。
