# 律师函起草

基于委托人提供的案件材料，撰写结构完整、论证充分、具备法律威慑力的律师函。

| 步骤 | 要点 |
|------|------|
| 1. 信息采集 | 知识库/上传文件/用户输入三渠道收集案件材料，逐项核查信息清单 |
| 2. 强制法律检索 | 双源检索（强制，不可跳过，详见步骤 2） |
| 3. 事实梳理 | 当事方→合同约定→履约对照→违约时间线→争议焦点 |
| 4. 起草律师函 | 按标准结构撰写，`file_read ../baichen-ndr-standard/references/knowledge-letter.md §1` 获取收件人画像 |
| 5. 用户审校 | 关键数据由用户确认修正后定稿 |

## Phase 0上下文检测

执行 `ndr-standards.md` §4。搜索 outputs/*_case_profile.json → 按 type="NDR" 过滤 → ask_user 确认继承 → 未找到则创建新 Profile。本技能与 客户函告 边界参见 `ndr-standards.md` §11。

## 步骤 1信息采集

| 渠道 | 方式 |
|------|------|
| 知识库 | `ima-knowledge` skill 定位 → search(source="kb") + fetch |
| 上传文件 | file_read 读取 |
| 用户输入 | 直接接收案情陈述 |

**必须逐项核查以下清单，缺失项向用户询问**

**基础采集项（所有场景通用）**
- 委托人身份（姓名、身份证号、住址、国籍/涉外因素）
- 对方当事人身份（姓名、身份证号/统一社会信用代码、住址、联系方式）

**合同纠纷场景**
- 合同核心条款（签订日期、标的、价款、履行期限、违约责任、争议解决条款）
- 委托人履约情况（已付款项、时间、金额、凭证）
- 对方违约事实（具体行为、时间节点、沟通记录）
- 其他相关材料（居间方/抵押权/担保等）

**非合同纠纷场景（侵权、不正当竞争等）**
- 侵权行为具体事实（时间、平台/载体、具体侵权内容）
- 侵权内容真实性判定（委托人确认是否存在虚构/捏造，决定名誉权论证强度）
- 是否涉及商业秘密（隐私权侵权可叠加商业秘密保护论证）
- 侵权行为背后的商业动机/第三方委托情况（如有，影响函告要求设计）
- 委托人已采取的前期沟通或维权措施
- 其他相关材料（在先权利证明、权属文件、公证材料等）

> ⛔ **采集纪律**：委托人身份、对方当事人身份缺失**不得**进入步骤 2；材料不足时**必须**向用户询问补齐，**禁止**以推定事实起草。

## 步骤 2强制法律检索

**基座前置｜双源检索（强制，不可跳过）**：执行 `ndr-standards.md` §0（订阅检测）+ §1（双源检索：百宸库 + 互联网各 ≥2 组 + 深度fetch≥2-3件库+2件网）。业务附加：§2.3.5＋../baichen-ndr-standard/references/ndr-ai-governance.md §2–§4（验证决策树＋幻觉防范＋脱敏）。**法条核验**：引用前按 §2.1.1 标 ✅/⚠️/⛔，⚠️/⛔ 不入交付正文，与「法条锚点」表联动核验。NDR 补充实务要点（送达方式/证据固定/财产保全）。

## 步骤 3事实梳理

时间线**签约 → 付款 → 履约期满 → 违约事实 → 催告沟通 → 现状**。

五要素当事方（委托人/对方/居间方）、合同关键约定、履约对照（约定义务 vs 实际履行）、违约时间线（每节点事实与证据）、争议焦点。

**依据时效与程序前置（材料提取后强制）**：执行 `ndr-standards.md` §7.8——所引法规/监管规则/标准须标注发布或最新修订日期与「最后核验日」；涉审批/备案/登记/前置许可/第三方同意事项**必须**单列「前置条件」提示章节。

## 步骤 4起草律师函

执行 `ndr-standards.md` §8.3 交付前强制自检。通过后方可生成为 Word。

执行 `ndr-standards.md` §3。调用 `scripts/generate_letter.py` 生成 Word（meta + sections 一次性传入）。输出至 `/sandbox/workspace/outputs/律师函_[委托人]_[案由].docx`。

### 4.1 标准结构

```
# 律 师 函

（函件编号、致送对象、日期；信息块律所居中，函件编号/致送对象/日期左对齐）

## 一、引言
[律所]接受[委托人]的委托，就[对方]……等事宜，出具本律师函。郑重函告如下

## 据委托人陈述及提供的资料表明
（客观事实，自然段落。合同条款仅引核心约定，1-2句概括，不得逐款抄写。事实与法律严格分离。）
- 合同核心约定签订日期、标的、价款、付款/履约方式、违约责任条款
- 委托人履约情况已付款项、时间、金额，附证据来源
- 对方违约事实按时间线简述3-5个关键节点，每个节点注明证据来源

## 鉴此，经委托人授权，本律师认为
（法律分析，自然段落推进，不用"一、二、三"编号。法条引用精简——仅列条文号+核心内容。）
- 各项侵权/违约行为的法律定性，每个行为独立成段，以"根据《……》第X条规定，……已构成……"句式递进
- 附带的信息披露/知情权要求（如有）
- 限期履行要求（"请贵方在收到本函之日起X日内"）
- 逾期不履行的法律后果**必须 `file_read ../baichen-ndr-standard/references/knowledge-letter.md §1`，自动判定身份类型（上市公司/普通企业/个人/金融机构/房地产建筑企业/境外主体），匹配定制化警示语。** 身份无法确定时默认"普通企业"。

## 结尾敬语（强制）**特此函告敬请慎择**（独立一行，加粗，居中对齐。）

## 落款律所名称 + 两名律师签字空行 + 律师电话 + 日期

## 附联系方式（地址、联系人、电话）
```

结构要点正文~1500字，每自然段≤5句，事实与法律不重复合同条款，书信体组织。

### 实体法锚点（2026-08-31 补）

律师函法律分析段引用实体法时按下列锚点（引用前一律经 `ndr-standards.md` §2.1.1 核验标状态，⚠️/⛔ 项**不得**写入正文）：

| 场景 | 法条 | 要点 |
|------|------|------|
| 催告/时效中断 | 《民法典》第 195 条 | 诉讼时效中断四项，第（一）项「提出履行请求」——催告函构成中断，**必须**在函中载明催告标的、金额与履行期限，并保留送达凭证 |
| 催告后解除 | 《民法典》第 563 条第 1 款第（三）项 | 迟延履行主要债务，经催告后在合理期限内仍未履行的，可以解除合同 |
| 通知解除 | 《民法典》第 565 条 | 通知到达对方时解除；对方有异议可请求法院/仲裁确认；直接起诉主张解除的，起诉状副本送达视为通知 |
| 违约责任 | 《民法典》第 577 条 | 不履行/不符合约定履行的，应承担继续履行、采取补救措施或赔偿损失等违约责任 |
| 损失赔偿 | 《民法典》第 584 条 | 损失赔偿额应相当于违约造成的损失（含可得利益），以可预见规则为限 |
| 出具依据 | 《律师法》（2017 修正，2018-01-01 施行）第 28 条 | 律师七项业务，第（六）项非诉法律服务含律师函 |
| 署名与名义 | 《律师执业管理办法》（司法部令第 134 号，2016-11-01 施行）＋《律师法》第 25 条 | 律师函**必须**以**律所名义**出具、由**执业律师**署名，**不得**以律师个人名义或非执业人员名义出具；律师承办业务由律所统一接受委托 |

⛔ **禁止**引用未经 §2.1.1 核验的法条；⛔ 本技能「法条锚点」表中 ⚠️ 项**不得**进入交付正文。

### 4.2 文本规范

| 类别 | 规范要点 |
|------|---------|
| **客观准确** | 主张须建立在可查证证据基础上；金额/日期/条款与原始材料一致；关键事实注明证据来源；金额大小写兼顾，违约金注明计算公式和起止日期 |
| **禁止不当表述** | 严禁侮辱、诽谤、恐吓、夸大其词；严禁暗示律师函本身有强制执行效力；严禁"直接查封""立即拘留"等超越授权的表述（应为"将依法申请……"）；严禁情绪化煽动性语言 |
| **事实严谨** | 证据未充分证实的事实用"据委托人陈述""据目前了解"限定；未经司法裁判不得做绝对化结论（"涉嫌构成违约"√，"已构成刑事犯罪"×） |
| **连接词规范** | 正确使用"然而""因此""但是""此外""据此"；单句不超过 80 字 |
| **语气礼貌而坚定** | 威慑力通过法律后果的客观陈述传递；以"请贵方……"代替"要求贵方……" |
| **格式要求** | 法条引用具体到条款项，首次用全称后续可简称；正文仿宋 12 号 1.5 倍行距；称谓公司→"贵司"，个人→"贵方"，己方→"委托人"（律所自称"本所"/"我们"，不用"我司"）；致送机构时→"贵委"/"贵会"/"贵局"/"贵厅"（按机构性质） |

### 4.2.1 引用对方书面承诺增强催告效力

详见 ../baichen-client-notice/SKILL.md §5.2 后「引用对方书面承诺增强催告效力」节（同款规则）。注：更正说明（原文法条锚点"《最高人民法院关于民事诉讼证据的若干规定》第三条"有误，现更正）：该规定（法释〔2019〕19号，2020-05-01施行）**第3条第2款仅规范诉讼中的自认**；对方诉前函件/邮件/对账单/结算单中的确认属**诉讼外承认**，仅作书证使用，不产生免除对方举证责任的效力。律师函表述应为"贵方上述确认构成对我方主张事实的有力书证"，**不得**表述为"无需举证证明"。

按 `ndr-standards.md` §2.6 繁简标准执行（⛔ 禁注水、篇幅与内容匹配）。

### 4.4 送审提示

完成草稿后提示用户核查关键数据（金额/日期/空白字段）、篇幅是否超标、事实与法律是否重复。

### 4.5 交付纪律（2026-08-31 补·B1 全量）

⛔ **强制**交付纪律：①律师函**必须**以律所名义出具、由执业律师署名（《律师执业管理办法》司法部令第 134 号；《律师法》第 28 条第（六）项非诉法律服务），**不得**以律师个人名义或非执业人员名义出具；②法条引用**必须**逐条核验并标注状态（`ndr-standards.md` §2.1.1），⚠️/⛔ 项**不得**写入交付正文；③正文**严禁**暗示律师函具有强制执行效力、**严禁**「直接查封」「立即拘留」等超越授权表述（应为「将依法申请……」）；④未经用户确认**不得**定稿交付；⑤时效/解除/违约表述**不得**超出已核验锚点（民法典 195／563 第 1 款第（三）项／565／577／584）。

## 步骤 5用户审校

将正文呈现用户审阅，修改意见确认后立即执行。⛔ 未经用户确认**不得**定稿；定稿后**必须**执行 `ndr-standards.md` §15.4 普检，通过后方可生成 Word。常见修改金额修正（同步检查关联数据）、日期修正、事实补充（重新评估法律分析影响）、语气调整。定稿后临时脚本调用 `generate_letter()` → 生成 Word → 删除临时脚本 → provide_file 提供下载。
