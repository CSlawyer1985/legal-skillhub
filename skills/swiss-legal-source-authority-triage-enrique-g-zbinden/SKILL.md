# 瑞士法律来源与权威分流

## 目的

在给出法律答案之前，使用本 skill 绘制瑞士法律权威结构。

本 skill **不**提供瑞士法律意见。它帮助 AI 助手为瑞士法律研究和法务运营工作流确定正确的来源层面、权威层级、语言/版本核验、不确定性标记和人工复核边界。

核心论点：**对于瑞士法律 AI，在生成答案之前先路由权威。**

## 何时使用本 skill

在以下情形使用本 skill：

- 用户提出的问题涉及瑞士法律、瑞士、瑞士当事人、瑞士资产、瑞士雇佣、瑞士合同、瑞士法院、瑞士监管机构、瑞士公司、瑞士数据保护、瑞士金融监管、瑞士知识产权、瑞士税务、瑞士刑事/公法，或瑞士州/市镇法律。
- 用户询问某个法律问题是联邦、州、市镇、监管、合同、专业层面还是混合层面。
- 用户请求瑞士法律研究来源、法律来源验证或法律来源地图。
- 合同、政策、备忘录或合规工作流声称受瑞士法律管辖。
- 答案可能受官方语言版本、州际差异、监管实践、待决改革或登记簿/法律状态证据的影响。

## 安全与角色边界

不要将输出呈现为法律意见。使用如下表述：

> 这是瑞士法律来源与权威分流，而非法律意见。它识别可能的来源层面和复核点。任何具体的法律立场、提交文件、对客户的意见或运营决策，均应由合格的瑞士律师复核。

当问题涉及以下情形时，明确升级：

- 诉讼策略、时效期间、程序期限、刑事风险、监管许可、制裁、雇佣终止、移民、税务、金融市场许可、医疗/健康监管或法院提交文件。
- 对法律结果产生实质性影响的客户特定事实。
- 相关州/市镇未知时的州法或市镇法。
- 职业保密、律师-客户保密特权、法律职业监管，或可能保密的数据。
- 非公开来源、付费学理、未公开实践或近期法律改革。

## 核心原则

1. **先权威后答案**：首先确定哪个瑞士来源层面具有支配力。
2. **先官方后聚合**：以官方来源为权威；聚合器仅用于发现，除非其法律地位已独立确认。
3. **先现行法后评述**：在概括学理或实践之前，先核验现行法律、生效日期、修订和过渡规则。
4. **先州法后概括**：在州或市镇权限可能重要时，不得假定瑞士法律是统一的。
5. **先语言后确信**：德文、法文和意大利文官方版本可能很重要。英文译本通常仅为参考性质，除非其官方地位已确立。
6. **监管实践不总是约束性法律**：将指南、通函、执法报告、常见问题和自律规范与法律和行政法规分开归类。
7. **学理仅具说服力而非约束力**：只有在核验官方法律、判例和监管实践之后，才使用学理来源（评注、专著、教科书、专家意见）。将学理视为说服性权威。优先选择著作而非作者姓名，核验版本和语言，并注明学理分歧。
8. **先复核边界后结论**：说明人工法律判断在何处介入。

## 分流工作流

### 第 1 步：对问题进行分类

将用户的请求归类为以下一项或多项：

- 私法 / 合同 / 侵权 / 财产
- 公司 / 商事登记簿 / 签署权限
- 雇佣 / 社会保障 / 与移民相关
- 数据保护 / 隐私 / 信息安全
- 金融市场 / 反洗钱 / 金融科技 / 保险
- 竞争 / 消费者 / 不正当竞争
- 知识产权 / 技术 / 许可
- 税务 / 海关 / 贸易 / 制裁
- 公法 / 行政法 / 公共采购
- 刑事 / 监管执法
- 民事、刑事、行政或仲裁程序
- 州 / 市镇 / 职业监管事项
- 混合或不确定

如缺少相关州、市镇、监管机构、行业、合同类型或事实背景，则明确设定假设并标记缺口。只有当缺失的事实使来源路由无法进行时，才提出澄清问题。

### 第 2 步：绘制权威层面

识别可能支配答案的每一个层面：

| 层面 | 需核验内容 |
|---|---|
| 联邦法律 | 联邦宪法、联邦法律、行政法规、条约、联邦官方出版物 |
| 州法律 | 州宪法、法律、行政法规、法院组织、行政实践 |
| 市镇/地方法律 | 市镇规章、许可、区划、警察条例、地方公法文书 |
| 官方判例 | 联邦最高法院、联邦行政法院、联邦刑事法院、联邦专利法院、州法院 |
| 监管实践 | FINMA、FDPIC/EDÖB、COMCO/WEKO、SECO、Swissmedic、FTA/ESTV、BAKOM/OFCOM、fedpol/MROS、行业机构 |
| 登记簿/法律状态 | Zefix、各州商事登记簿、SHAB/SOGC、Swissreg、可访问的不动产登记簿、债务执行/破产公告 |
| 合同来源 | 管辖法律、管辖权/仲裁条款、优先顺序、政策、附表、通过援引并入的标准 |
| 专业/自律 | 律师/职业规则、SRO 规则、行业守则、交易所规则、协会标准 |
| 学理/专家权威 | 评注、专著、教科书、专家意见、学术文章。仅在官方来源和监管实践之后使用。核验版本、语言和学理立场。 |
| 软法 / 次级来源 | 指南、评述、律所注释、学术写作、开放获取期刊、研究指南 |

### 第 3 步：应用瑞士来源层级

决定依赖何种来源时，使用此层级：

1. **官方基础法律**：Fedlex；官方汇编；分类/系统汇编；条约；官方州法和市镇法门户。
2. **官方判例**：联邦最高法院；联邦行政法院；联邦刑事法院；联邦专利法院；州法院门户。
3. **官方立法材料**：《联邦公报》；Curia Vista；《官方公报》；征求意见材料；咨文/政府信函。
4. **官方监管实践**：FINMA、FDPIC/EDÖB、COMCO/WEKO、Swissmedic、SECO、FTA/ESTV、BAKOM/OFCOM、fedpol/MROS 及其他主管机关。
5. **登记簿和法律状态来源**：Zefix、各州商事登记簿、SHAB/SOGC、Swissreg、公开破产和公告来源。
6. **开放发现 / AI 就绪层面**：OpenCaseLaw、LexFind、Entscheidsuche、opendata.swiss 数据集、Fedlex-JOLux、开放 API 和批量数据集。
7. **学理与专家权威**：评注、专著、教科书、专家意见和学术著作。学理仅具说服力。在官方来源之后使用。见 `resources/doctrine-and-expert-authority-map.md`。
8. **次级导向**：GlobaLex、美国国会图书馆、UZH/CLDS 资源、开放获取期刊、大学指南、律所注释和实务评述。对广泛背景和发现有用，但不具权威性。
9. **商业或需登录的来源**：Swisslex、Lawsearch/Weblaw、Legalis、私营法律 AI 平台、律所知识库。视为有用，但不构成公开权威。

不得仅仅因为某个发现层可搜索或 AI 可访问，就将其视为支配性权威。

### 第 4 步：核验语言、版本和时间状态

对每个实质性来源，记录：

- 已核验的官方语言版本：德 / 法 / 意 / 罗曼什语 / 英。
- 英文版本是官方、参考性质还是不确定。
- 现行法日期、生效日期、修订日期及相关的过渡期。
- 材料属于现行法律、法律草案、征求意见材料、立法史、监管指南、判例、学理还是开放数据元数据。
- 来源属于官方、开放数据、聚合/发现、商业、学术还是次级来源。

当措辞可能影响解释时，标记多语言分歧风险。

### 第 5 步：识别瑞士特定的不确定性标记

始终考虑以下标记：

- **州权限**：答案可能因州而异。
- **市镇/地方权限**：许可、区划、公共秩序、地方法规或采购可能取决于市镇。
- **行业监管机构**：FINMA、FDPIC/EDÖB、COMCO/WEKO、Swissmedic、SECO、FTA/ESTV、BAKOM/OFCOM、fedpol/MROS 或其他机关可能具有支配力。
- **公营 vs 私营雇主/实体**：雇佣、采购、透明度和公法救济可能发生变化。
- **职业保密或特权**：尤其是律师、医疗、金融、审计师、受托人及受监管职业。
- **自律**：SRO、交易所、专业协会或行业守则可能相关，但不等同于法律。
- **待决改革**：法律草案、征求意见、联邦委员会咨文、议会事项或过渡期可能影响意见。
- **来源时效**：过时的法律、旧实践、已被替代的指南或改革前的判例。
- **登记事实 vs 法律结论**：公司/登记簿数据显示法律状态，但可能无法解决权限、可执行性或责任问题。
- **需要人工判断**：解释、风险偏好、法律策略和客户特定事实不能简化为来源查询。

### 第 6 步：以安全框架产出答案

除非用户要求不同格式，否则使用以下输出结构。

```markdown
# 瑞士法律来源地图

## 1. 问题分类
[对问题进行分类并说明关键假设。]

## 2. 可能的权威层面
| 层面 | 相关性 | 需核验的来源路径 | 状态 |
|---|---|---|---|
| 联邦法律 | ... | ... | 官方 / 基础 |
| 州法律 | ... | ... | 需确定州 |
| 监管机构 | ... | ... | 指南 / 通函 / 执法 / 约束性规则 |

## 3. 应首先核验的基础来源
[列出官方法律、行政法规、条约、法院数据库、监管材料、登记簿或州门户。]

## 4. 发现与次级来源
[列出 OpenCaseLaw、LexFind、Entscheidsuche、opendata.swiss、学术指南、评注等，并提示除非适当否则不得视为权威。]

## 5. 语言、版本和日期核验
[德/法/意/罗曼什语/英；现行法日期；修订/改革风险；翻译警示。]

## 6. 初步法律信息框架
[仅给出有来源支撑的法律信息。除非来源和事实足以支撑，否则不提供确定的客户特定法律结论。]

## 7. 瑞士特定的不确定性标记
[州、监管机构、职业保密、待决改革、来源时效、事实缺口。]

## 8. 人工复核边界
[仅提供信息 / 建议律师复核 / 必须律师复核 / 需确认权威 / 需特定监管机构意见。]

## 9. 复核回执
- 已核验来源：
- 未核验来源：
- 假设：
- 剩余缺口：
- 分流日期：
```

## 精简模式

当用户需要简短回复时，提供：

```markdown
**瑞士来源路由：** [联邦/州/监管/登记簿/合同/混合]
**首先核验的官方来源：** [来源]
**发现辅助：** [来源]
**关键瑞士标记：** [州/语言/监管/改革/事实]
**复核边界：** [需瑞士律师或机关复核的事项]
```

## 禁止的捷径

不得：

- 在绘制权威之前以确信的法律结论开头。
- 在州法或市镇法可能重要时，将瑞士视为法律统一体。
- 未经核验状态即将英文译本视为支配性。
- 未经限定即将监管指南、常见问题或律所评述视为约束性法律。
- 将 OpenCaseLaw、LexFind、Entscheidsuche 或其他聚合器视为官方来源的替代品。
- 忽略来源日期、现行法日期、过渡规定或待决改革。
- 在没有明确人工复核警示的情况下起草提交文件、监管申报或对客户的意见结论。
