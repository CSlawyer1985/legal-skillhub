# 瑞士法律来源与权威分流

一个用于瑞士法律来源路由的方法论 skill。

该 skill 帮助 AI 助手在给出法律答案之前，先确定正确的瑞士权威层级。它关注来源层级、联邦/州/市镇路由、监管机构背景、登记簿、多语言/版本核验、不确定性标记以及人工复核边界。

它被设计为后续瑞士法特定 skill 的基础设施，例如瑞士合同审查受理、瑞士数据保护分流、瑞士劳动法分流、瑞士公司权威核验、瑞士金融科技/FINMA 许可分流或瑞士诉讼研究工作流。

## 建议类别

法律方法论 / 法律研究 / 司法辖区基础设施

## 建议的收录描述

瑞士法律来源与权威分流。在生成答案之前，判定瑞士法律问题是联邦、州、市镇、监管、合同、专业、登记簿层面还是混合层面。包括官方来源层级、开放/AI 就绪的发现层、多语言/版本核验、瑞士不确定性标记以及人工复核边界。
