# 示例

这些示例演示来源路由。它们有意避免给出确定性的法律意见。

## 示例 1——工作邮箱监控

**用户问题：** 瑞士雇主可以监控我的工作邮箱吗？

```markdown
# 瑞士法律来源地图

## 1. 问题分类
雇佣 + 数据保护 + 工作场所政策。如雇主为私营、公营、受监管机构，或监控涉及刑事/程序证据，答案可能发生变化。

## 2. 可能的权威层面
| 层面 | 相关性 | 需核验的来源路径 | 状态 |
|---|---|---|---|
| 联邦法律 | 雇佣义务和人格保护；数据保护 | Fedlex：《债法典》、《联邦数据保护法》及行政法规 | 官方基础法律 |
| 监管机构 | 数据保护指南 | FDPIC / EDÖB | 官方监管材料 |
| 州法律 | 如雇主为公营部门或存在州雇佣规则则可能相关 | 相关州门户 | 需确定州 |
| 合同/内部 | 雇佣合同、IT 政策、可接受使用政策 | 雇主文件 | 合同 |
| 判例 | 人格权、监控、证据问题 | 联邦最高法院及各州判决 | 官方判例 |

## 3. 语言、版本和日期核验
核验现行联邦法律及相关工作场所指南是否最新。如措辞重要，核验德/法/意版本。

## 4. 初步法律信息框架
来源路由表明，安全的答案应把一般工作场所监控原则与具体的监控设置分开：目的、告知、比例性、访问范围、保存、私人使用政策以及公营/私营雇主身份。

## 5. 瑞士特定的不确定性标记
- 雇主类型未知。
- 州未知。
- 内部 IT 政策未知。
- 监控方法和目的未知。

## 6. 人工复核边界
在实施或质疑具体监控措施之前，建议由瑞士律师或数据保护专家复核。
```

## 示例 2——合同可执行性

**用户问题：** 此责任限制条款在瑞士法律下可执行吗？

```markdown
# 瑞士法律来源地图

## 1. 问题分类
私法合同 + 可能的强制性法律例外。合同类型和当事人很重要。

## 2. 可能的权威层面
| 层面 | 相关性 | 需核验的来源路径 | 状态 |
|---|---|---|---|
| 联邦法律 | 一般合同和责任制规则 | Fedlex：《瑞士债法典》及相关法律 | 官方基础法律 |
| 判例 | 责任排除和强制性限制的解释 | 联邦最高法院判决 | 官方判例 |
| 合同来源 | 管辖法律、管辖权、优先顺序、谈判条款 | 合同文本 | 合同 |
| 行业法律 | 如涉及雇佣、消费者、租赁、金融服务、数据处理、运输等则可能相关 | Fedlex 和监管来源 | 视情况而定 |

## 3. 语言、版本和日期核验
核验管辖法律条款和合同语言。如条款使用翻译的瑞士法律术语，注明翻译风险。

## 4. 初步法律信息框架
不要抽象地回答可执行性。首先识别合同类型、当事人成熟度、强制性法律体系、被排除的行为、责任类别，以及该条款是否与特定法定限制或公共政策冲突。

## 5. 瑞士特定的不确定性标记
- 合同类型未知。
- 完整责任架构未知。
- 未排除消费者/雇佣/租赁/数据处理例外。

## 6. 人工复核边界
确定性的可执行性意见或谈判建议需要律师复核。
```

## 示例 3——金融科技许可

**用户问题：** 瑞士金融科技公司需要 FINMA 许可吗？

```markdown
# 瑞士法律来源地图

## 1. 问题分类
金融市场监管 + 反洗钱 + 可能的银行、证券、集体投资、支付、加密/代币或保险监管。

## 2. 可能的权威层面
| 层面 | 相关性 | 需核验的来源路径 | 状态 |
|---|---|---|---|
| 联邦法律 | 金融市场法律和行政法规 | Fedlex | 官方基础法律 |
| 监管机构 | FINMA 许可类别、指南、通函、执法实践 | FINMA | 官方监管材料 |
| 自律 | 反洗钱 SRO 规则可能适用 | 相关 SRO | 软法/自律 |
| 登记簿/法律状态 | 现有许可或注册 | FINMA 持牌机构名单、商事登记簿 | 官方登记簿法律状态 |
| 判例 | 许可/范围争议 | 联邦行政法院、联邦最高法院 | 官方判例 |

## 3. 语言、版本和日期核验
金融市场规则变化频繁。核验现行法律、行政法规、FINMA 指南及任何过渡期。

## 4. 初步法律信息框架
安全的分类应在回答前先归类业务活动：客户资产托管、吸收存款、放贷、证券/中介、支付服务、代币发行、资产管理、保险、反洗钱相关活动及跨境营销。

## 5. 瑞士特定的不确定性标记
- 商业模式未知。
- 托管/支付/代币功能未知。
- 客户类型和地域未知。
- 可能需要 FINMA 的不行动函或裁决。

## 6. 人工复核边界
在启动、营销或依赖"无需许可"结论之前，必须经监管律师复核。
```

## 示例 4——公司签署权限

**用户问题：** 此人可以代表瑞士公司签署吗？

```markdown
# 瑞士法律来源地图

## 1. 问题分类
公司权限 + 商事登记簿/法律状态核验 + 合同签署。

## 2. 可能的权威层面
| 层面 | 相关性 | 需核验的来源路径 | 状态 |
|---|---|---|---|
| 登记簿/法律状态 | 当前签署权限和实体状态 | Zefix 及各州商事登记簿摘录 | 官方登记簿法律状态 |
| 联邦法律 | 公司代表规则 | Fedlex：《债法典》 | 官方基础法律 |
| 合同来源 | 签署栏、董事会批准、授权委托书 | 合同和公司文件 | 合同 |
| 公告 | 近期变更、破产、合并、清算 | SHAB/SOGC | 官方登记簿法律状态 |

## 3. 语言、版本和日期核验
核验当前官方摘录，以及是否有近期影响权限的 SHAB/SOGC 公告。

## 4. 初步法律信息框架
登记簿条目可以表明签署权限，但实际权限可能需要核验联合签署要求、授权委托书、董事会决议，以及交易本身是否需特别批准。

## 5. 瑞士特定的不确定性标记
- 官方摘录未复核。
- 交易类型未知。
- 内部批准未知。

## 6. 人工复核边界
对高价值、不寻常、受监管或跨境交易，建议人工复核。
```
