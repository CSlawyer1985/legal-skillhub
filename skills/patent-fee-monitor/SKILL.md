# 专利年费监控+IP资产台账

> 面向中小企业/个人创作者，提供轻量级的专利年费监控和IP资产台账管理工具。

## 核心能力

### 1. 年费监控
- **专利号查询**：用户输入专利号，自动识别国家/类型
- **法律状态查询**：通过免费公开数据源查询专利法律状态（多源重试策略）
- **年费到期日计算**：提取/计算年费到期日
- **剩余天数计算**：计算距离缴费截止日的剩余天数
- **风险等级判定**：绿（>90天）/黄（30-90天）/红（<30天）
- **滞纳金计算**：根据逾期天数自动计算滞纳金
- **日历提醒生成**：生成iCalendar格式的日历提醒文件

### 2. IP资产台账
- **专利管理**：发明专利、实用新型、外观设计
- **商标管理**：注册商标信息
- **软著管理**：软件著作权信息
- **资产清单**：可视化展示全部IP资产
- **状态追踪**：法律状态、年费到期日、缴费记录

### 3. 批量导入
- **CSV导入**：支持批量导入专利/商标/软著信息
- **手动录入**：也支持逐个手动录入

### 4. 到期提醒
- 自动计算每个资产的缴费截止日
- 按风险等级分级提醒（绿色/黄色/红色）
- 支持导出提醒清单
- 支持生成iCalendar日历提醒（可导入Google Calendar/Apple Calendar等）
- 推送通知列表生成

### 5. 多国专利支持
- 支持中国（CN）、美国（US）、欧洲（EP）、PCT国际（WO）
- 支持日本（JP）、韩国（KR）、英国（GB）、德国（DE）、法国（FR）、瑞士（CH）
- 欧洲专利生效国年费计算（德国/英国/法国/瑞士/意大利/荷兰/瑞典）

## 工作流程

### 第一步：用户输入专利号/商标号/软著名

用户可以说：
- "帮我查一下专利 US12345678B2 的状态"
- "监控 CN202310123456.X 的年费"
- "管理我的IP资产"
- "导入CSV文件批量监控年费"
- "看我所有的专利清单"
- "生成日历提醒"
- "查看通知"

### 第二步：自动识别国家与类型

根据专利号前缀自动识别（支持10国）：

| 前缀 | 国家 | 识别规则 |
|------|------|---------|
| **US** | 美国 | US + 6-11位数字 + 字母 |
| **CN** | 中国 | CN + 9-13位数字 + 可选.X |
| **EP** | 欧洲 | EP + 7-10位数字 + 可选字母 |
| **WO/PCT** | PCT国际 | WO + 年+数字 |
| **JP** | 日本 | JP + 7-13位数字 |
| **KR** | 韩国 | KR + 9-15位数字 |
| **GB** | 英国 | GB + 7-10位数字 |
| **DE** | 德国 | DE + 10-13位数字 |
| **FR** | 法国 | FR + 7-10位数字 |
| **CH** | 瑞士 | CH + 6-10位数字 |

### 第三步：查询法律状态与到期日

使用多源重试策略，按优先级依次查询：
1. **专用API优先**：USPTO（US）、EPO OPS（EP）、WIPO PATENTSCOPE（WO）
2. **Google Patents回退**：所有国家通用回退方案
3. **本地台账**：优先使用已录入的台账数据

### 第四步：计算并输出监控结果

输出格式：
```
📋 专利年费监控报告
────────────────────────
专利号：CN202310123456.X
专利名称：一种XXX方法及系统
法律状态：专利权维持
申请日：2023-01-15
授权日：2023-08-20
下次年费到期日：2024-08-20
剩余天数：87天
风险等级：🟡 黄色预警 （30-90天）
年费参考：第2年年费，约¥900
```

### 第五步：维护IP资产台账

用户可维护完整的IP资产清单：
```
📊 IP资产台账总览
────────────────────────
总计：12项
├─ 专利：8项（发明5，实用新型2，外观1）
├─ 商标：3项
├─ 软著：1项

⚠️ 即将到期（30天内）：2项
🟡 近期预警（90天内）：3项
✅ 正常：7项
```

## 输入格式

### 单条查询
直接输入专利号即可，支持格式：
- `US12345678B2`
- `CN202310123456.X`
- `EP12345678`
- `WO2023/123456`
- `PCT/CN2023/123456`
- `JP12345678`
- `KR1020230012345`
- `GB1234567`
- `DE102023123456`
- `FR1234567`
- `CH1234567`

### CSV批量导入
CSV文件至少包含以下列：
- `patent_no`：专利号（必填）
- `title`：名称（可选）
- `type`：类型（patent/trademark/copyright，默认patent）
- `filing_date`：申请日（可选，用于计算）
- `grant_date`：授权日（可选）
- `next_fee_date`：下次年费到期日（可选）
- `status`：法律状态（可选）
- `notes`：备注（可选）

## 年费计算规则（按国家）

### 中国专利年费
- **发明专利**：第1-3年¥900/年，第4-6年¥1200/年，第7-9年¥2000/年，第10-12年¥4000/年，第13-15年¥6000/年，第16-20年¥8000/年
- **实用新型**：第1-3年¥600/年，第4-5年¥900/年，第6-8年¥1200/年，第9-10年¥2000/年
- **外观设计**：第1-3年¥600/年，第4-5年¥900/年，第6-8年¥1200/年，第9-10年¥2000/年
- **缴费期限**：每年在授权日对应的月份前缴纳，可宽限6个月（需缴滞纳金）
- **滞纳金**：1个月内加收5%，1-2个月10%，2-3个月15%，3-6个月20%，超6个月专利权终止

### 美国专利年费（维护费）
- **第3.5年**：Small $800, Micro $400, Large $1600
- **第7.5年**：Small $1800, Micro $900, Large $3600
- **第11.5年**：Small $3700, Micro $1850, Large $7400
- **缴费期限**：到期前6个月内可缴，宽限期6个月（需缴滞纳金）
- **滞纳金**：6个月内加收5%，超6个月专利权终止

### 欧洲专利年费（生效国）
授权后在各生效国分别缴纳，年费随年限递增：

| 国家 | 第1-3年 | 第4-6年 | 第7-9年 | 第10-12年 | 第13-15年 | 第16-20年 |
|------|---------|---------|---------|-----------|-----------|-----------|
| 德国(DE) | €60 | €120 | €190 | €300 | €500 | €800 |
| 英国(GB) | €50 | €100 | €160 | €250 | €400 | €600 |
| 法国(FR) | €60 | €120 | €200 | €320 | €520 | €750 |
| 瑞士(CH) | €100 | €200 | €350 | €500 | €700 | €1000 |
| 意大利(IT) | €50 | €100 | €150 | €250 | €400 | €550 |
| 荷兰(NL) | €60 | €120 | €200 | €300 | €450 | €650 |
| 瑞典(SE) | €60 | €120 | €200 | €300 | €450 | €600 |

- 宽限期6个月
- 滞纳金：1个月内加收5%，1-2个月10%，2-3个月15%，3-6个月25%，超6个月专利权终止

## 输出格式

### 单条查询结果
用 Emoji 带结构展示，清晰易读。

### 台账总览
用表格或结构化列表展示全部资产。

### CSV导出
支持导出当前台账为CSV文件，文件名包含时间戳（如 `ip_assets_export_20240101_120000.csv`）。

### 日历提醒（iCalendar格式）
支持导出iCalendar格式的日历提醒文件（.ics），可导入Google Calendar、Apple Calendar、Outlook等。

### 推送通知
按紧急程度排序的推送通知列表：
| 优先级 | 剩余天数 | 操作建议 |
|--------|---------|---------|
| 🔴 紧急 | 已过期或≤30天 | 立即缴费 |
| 🟡 中等 | 31-90天 | 安排缴费计划 |
| 🟢 正常 | >90天 | 无需立即处理 |

## 边界情况处理

1. **无效专利号格式**：提示用户检查专利号格式，展示正确的格式示例
2. **网络查询失败**：提示用户无法查询，建议手动输入关键日期（多源重试策略自动处理）
3. **CSV格式错误**：明确提示哪一列缺失、哪一行解析失败
4. **已过期专利**：标注"已失效"，展示失效日期，计算滞纳金
5. **未查询到信息**：提示无公开数据，建议用户自行补充
6. **宽限期内**：标注"宽限期内，需缴纳滞纳金"
7. **多国家专利**：提醒在不同国家缴年费的要求不同
8. **瑞士专利**：支持CH前缀识别和年费计算
