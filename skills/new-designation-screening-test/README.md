# new-designation-screening-test

一个 Claude 技能，将每一轮新的 OFAC、OFSI 和欧盟制裁指定转化为供分析师审查的筛查测试集——原始名称、有意变体和分析师解读命中与未命中所需的元数据。

## 它的作用

被调用时，该技能：

1. 在所选回溯窗口（默认：前 7 天）内，从 OFAC 的"近期行动"、OFSI 综合清单/公告和欧盟 CFSP 综合清单拉取新指定的名称。
2. 为每个名称生成 6-8 个有意变体，每个都标记其探测的**失败模式**：换位、首字母、空格/标点、变音符号剥离、转写漂移、文字替换、常见拼写错误、尊称、截断。
3. 为每行标记**预期匹配强度**（`exact` / `strong` / `moderate` / `weak`），使命中/未命中模式读作关于筛查工具的诊断信息，而非单纯的通过/失败。
4. 输出一个单工作表 `.xlsx`，合规团队可以加载到他们的筛查引擎中进行测试。

## 适用对象

需要以下能力的制裁和金融犯罪合规团队：

- 在指定更新后核验其筛查清单是否最新。
- 针对其筛查工具运行回归测试集。
- 对照现实名称变体而非合成噪音校准模糊匹配阈值。

## 使用方法

将技能添加到 Claude（将此文件夹放在您的技能目录下），然后问 Claude 类似内容：

- "为本周生成制裁清单更新测试数据。"
- "根据最新的 OFAC 和 OFSI 新增内容为我构建一个筛查回归集。"
- "测试我的筛查清单——它是否捕获了过去 14 天的新欧盟指定？"

## 输出格式

单工作表 `.xlsx`，每个测试条目一行。列：

| # | 列 | 描述 |
|---|---|---|
| 1 | `original_name` | 监管机构列出的主要名称 |
| 2 | `variation` | 实际输入筛查的测试字符串 |
| 3 | `variation_type` | `exact`、`transposition`、`transliteration` 等 |
| 4 | `expected_match_strength` | `exact` / `strong` / `moderate` / `weak` |
| 5 | `entity_type` | 个人 / 实体 / 船舶 / 航空器 |
| 6 | `source_list` | OFAC SDN / OFAC Non-SDN / OFSI / EU CFSP |
| 7 | `program` | 制裁计划 / 主管机关 |
| 8 | `designation_date` | YYYY-MM-DD |
| 9 | `aliases_aka` | 分号分隔的别名 |
| 10 | `dob_or_incorporation` | 出生日期或注册日期 |
| 11 | `pob_or_place_of_incorporation` | 出生地或注册地 |
| 12 | `nationality_or_jurisdiction` | 国籍或司法辖区 |
| 13 | `address` | 所列地址 |
| 14 | `identifiers` | 竖线分隔的 ID（护照、国民身份证、税号、IMO、机尾号） |
| 15 | `regulator_url` | 指向列名或公告的直接链接 |

见 [`examples/sample_output.xlsx`](./examples/sample_output.xlsx)，其中包含三个说明性指定（一名伊朗个人、一家俄罗斯实体和一艘船舶）的工作示例。

## 变体分类

该技能探测筛查系统中的十种常见失败模式：

1. **换位**——词序变化（`Lee John` 由 `John Lee` 而来）
2. **首字母 / 缩写**——`J. Lee`、`John L.`
3. **空格与标点**——连字符被合并或添加、双空格、缺失空格
4. **变音符号与特殊字符剥离**——`José` → `Jose`
5. **转写漂移**——`Mohammad` / `Muhammad` / `Mohammed` / `Mohamed`
6. **文字替换**——名称以阿拉伯文、西里尔文、中文、波斯文或希伯来文呈现
7. **常见拼写错误 / 错字**——单字符替换、相邻键换位
8. **尊称与头衔**——Sheikh、Dr.、Hajji、Sayyid、Mullah
9. **截断**——省略中间名、后缀或多个名字中的一个
10. **跨监管机构变体**——同一个人被 OFAC / OFSI / EU / UN 拼写不同（如 DAGALO 与 DAGLO）

完整分类（含示例和标记规则）见 [SKILL.md](./SKILL.md)。

## 局限性

- 输出反映运行时时监管机构在来源页面上发布的内容。假日周末、系统中断或延迟的"What's New"PDF 将体现为缺口。
- 变体生成是启发式的。技能根据名称来源和结构选择模式，这是一种判断性调用——在将其视为穷尽之前，将输出与制裁分析师审查结合使用。
- v1 覆盖 OFAC、OFSI 和欧盟。联合国、加拿大（SEMA）、澳大利亚（DFAT/综合清单）、瑞士（SECO）和日本不在范围内。
- **默认范围：仅个人和实体。**船舶和航空器默认被排除，因为大多数金融交易筛查不会浮现船名或飞机名。船舶/航空器测试数据与贸易融资、船舶/飞机融资、海事和航空保险、航运和物流公司以及港口运营商相关——明确请求以为这些实体类型生成单独数据集。
- 匹配强度标记反映名称匹配算法的一般行为，而非任何特定供应商（LexisNexis、Dow Jones、Refinitiv World-Check、ComplyAdvantage 等）。对照您自己的引擎的评分分布进行校准。
