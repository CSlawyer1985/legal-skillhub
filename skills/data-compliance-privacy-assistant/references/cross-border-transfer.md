# 数据出境合规操作指南

> 法律依据：《个人信息保护法》第38-42条、《数据安全法》第31条、《数据出境安全评估办法》（2022年9月1日施行）、《个人信息出境标准合同办法》（2023年6月1日施行）、《促进和规范数据跨境流动规定》（2024年3月22日施行）。
>
> ⚠️ 免责声明：数据出境法规更新较快，本指南仅供参考，具体以国家网信部门发布的最新法规与申报指南为准。

本文档是 Phase 5「数据跨境传输合规」的核心依据，系统阐述数据出境三条路径的选择、申报/签约/认证流程及合规操作要点。

---

## 一、法律框架概览

### 1.1 核心法规体系

```
《网络安全法》第37条（CIIO数据本地化）
        │
        ▼
《数据安全法》第31条（数据出境管理制度）
        │
        ▼
《个人信息保护法》第38-42条（出境三条路径+告知同意）
        │
        ├──────────────┬──────────────┐
        ▼              ▼              ▼
  《数据出境安全     《个人信息出境    《促进和规范数据
   评估办法》         标准合同办法》     跨境流动规定》
  （2022.9.1）       （2023.6.1）      （2024.3.22）
```

### 1.2 "数据出境"的含义

数据出境包括以下情形：
1. 在境内运营中收集和产生的数据，传输、存储至境外；
2. 在境内收集和产生的数据存储在境内，但被境外的机构、组织或个人访问、查看、下载、导出；
3. 未在境内存储但涉及境内收集和产生的数据（再出境）。

> 不属于数据出境的情形：在境外收集、产生的数据传输至境内进行处理（非出境），以及境内公开数据的传输。

## 二、数据出境三条路径（个保法第38条）

个人信息处理者因业务等需要，确需向中华人民共和国境外提供个人信息的，应当具备下列条件之一（三条路径）：

| 路径 | 方式 | 适用条件 | 监管程序 |
|------|------|---------|---------|
| 路径① | 安全评估 | 达到安全评估申报门槛的强制适用 | 向国家/省级网信部门申报 |
| 路径② | 个人信息保护认证 | 经国家网信部门认定机构认证 | 完成认证 |
| 路径③ | 标准合同（SCC） | 签署网信办标准合同 | 向省级网信部门备案 |

> 三条路径满足其一即可。但触发安全评估门槛的，**必须**走路径①，不得选择路径②或③规避。

## 三、路径①：数据出境安全评估

### 3.1 须申报安全评估的情形（《数据出境安全评估办法》第4条）

| 序号 | 须申报安全评估的情形 | 备注 |
|------|------------------|------|
| 1 | 关键信息基础设施运营者（CIIO） | 一律申报 |
| 2 | 处理100万人以上个人信息的处理者 | 以总量计 |
| 3 | 自上年1月1日起累计向境外提供10万人个人信息或1万人敏感个人信息 | 累计计算 |
| 4 | 重要数据出境 | 必须申报 |
| 5 | 国家网信部门规定的其他情形 | 兜底条款 |

### 3.2 《促进和规范数据跨境流动规定》的优化（2024年3月）

该规定对数据出境管理进行了优化，明确了部分**免予申报安全评估、免予订立标准合同、免予认证**的情形（以最新规定为准）：
- 在国际贸易、跨境运输等业务中收集产生的不含个人信息或重要数据的数据出境；
- 不满一定数量个人信息的数据出境（具体数量阈值以规定为准）；
- 自由贸易试验区制定的"负面清单"外的数据出境。

> ⚠️ 具体免予情形以《促进和规范数据跨境流动规定》最新条文为准，企业应核实自身是否适用优化政策。

### 3.3 安全评估申报流程

```
准备申报材料
     │
     ▼
向所在地省级网信部门申报 ──▶ 省级网信部门受理
     │                            │
     │                    （需国家网信部门评估的，省级转报）
     ▼                            ▼
开展数据出境安全评估 ◀──── 国家网信部门
     │
     ▼
出具评估结果
  ├─ 通过 ──▶ 可依法出境（有效期2年）
  └─ 不通过 ──▶ 不得出境（或整改后重新申报）
```

### 3.4 申报材料清单

1. **申报书**；
2. **数据出境风险自评估报告**（核心材料）；
3. 数据处理者与境外接收方拟订立的数据出境相关合同（或其他具有同等效力的文件）；
4. 安全评估工作需要的其他材料。

### 3.5 数据出境风险自评估内容

自评估报告应包括：
- **出境及再转移后遭到篡改、破坏、泄露、丢失、转移或者被非法获取、非法利用等的风险**；
- 数据出境的合法性、正当性、必要性；
- 境外接收方承诺承担的数据安全保护责任，以及履行责任的管理和技术措施、能力等能否保障出境数据安全；
- 数据安全和权益维护的渠道是否畅通有效；
- 与境外接收方订立的数据出境相关合同是否充分约定了数据安全保护责任义务；
- 其他可能影响数据出境安全的事项。

### 3.6 评估结果有效期
- 安全评估结果有效期为**2年**（自评估结果出具之日起计算）；
- 有效期内出境目的、方式、类型等发生变化或到期需继续出境的，应重新申报。

## 四、路径③：个人信息出境标准合同（SCC）

### 4.1 适用条件
- 未触发安全评估申报门槛的个人信息出境；
- 未选择个人信息保护认证的；
- 可通过签署网信办发布的标准合同方式出境。

### 4.2 标准合同核心要点

**合同当事人**：
- 个人信息处理者（境内，即数据出境方）；
- 境外接收方。

**合同应包含的核心条款（《个人信息出境标准合同办法》规定不得修改的必备条款）：**
1. **个人信息处理目的、处理方式、个人信息的种类、敏感程度**，以及境外接收方处理个人信息的用途、方式；
2. **境外接收方所在国家或者地区的数据保护政策法规**对标准合同履行的影响；
3. 个人信息的**保存期限、地点及保存期限届满后的处理方式**；
4. 境外接收方应**履行的个人信息保护义务**；
5. 境外接收方**再向第三方提供个人信息**的条件和方式；
6. **个人信息主体权益**及维护合法权益的方式；
7. **救济**：个人信息主体合法权益受到损害时的救济途径；
8. **违约责任**及争议解决方式。

### 4.3 SCC备案要求
- 个人信息处理者应在标准合同**签署之日起10个工作日内**，向所在地省级网信部门备案；
- 备案材料：标准合同及个人信息保护影响评估报告。

### 4.4 标准合同使用要点
- 必须使用网信办发布的**标准合同范本**，必备条款不得删减或修改；
- 可根据实际情况增加补充条款，但不得与必备条款冲突；
- 合同变更或境外接收方所在国家地区法律环境发生重大变化时，需重新评估。

---

## 五、路径②：个人信息保护认证

### 5.1 适用场景
- 较多用于**跨国企业集团内部**的个人信息跨境传输（如母子公司之间）；
- 需经国家网信部门认定机构按照国家有关规定开展认证。

### 5.2 认证特点
- 双方（境内处理者和境外接收方）均需满足认证要求；
- 认证结果有有效期，需定期复评。

---

## 六、法定告知与单独同意（个保法第39条）

向境外提供个人信息前，个人信息处理者应当向个人**告知**以下事项，并取得**单独同意**：

| 告知事项 | 说明 |
|---------|------|
| 境外接收方的名称/姓名 | 明确接收方身份 |
| 联系方式 | 便于权益救济 |
| 处理目的、方式 | 出境用途 |
| 个人信息的种类 | 出境数据范围 |
| 向境外接收方行使本法规定权利的方式和程序 | 权益保障通道 |

> ⚠️ "单独同意"要求更高——不能与其他事项合并取得同意，须针对数据出境单独、明示地取得个人同意。

## 七、数据出境路径选择决策流程

```
                    第一步：判断是否属于数据出境
                         │
              ┌──── 是 ──┴── 否 ────┐
              ▼                      ▼
     第二步：判断是否触发        无需出境合规
     安全评估门槛？              （但须遵守其他合规要求）
              │
     ┌── 是 ──┴── 否 ──┐
     ▼                  ▼
 第三步：判断是否     第四步：选择
 属于CIIO/重要数据     路径②或③
     │                  │
     ▼                  ▼
 路径①安全评估    SC标准合同 或 保护认证
 （向网信部门申报） （签署后向省级网信备案）
     │                  │
     └──────┬───────────┘
            ▼
   第五步：履行告知+单独同意
   （个保法第39条）
            │
            ▼
   第六步：持续合规管理
   （评估有效期/变更重新申报/定期复审）
```

### 是否可适用优化政策的快速判断（参照2024年规定）

以下情形可能**免予**安全评估、标准合同、认证（须以最新规定核实）：
- ☐ 数据不含个人信息和重要数据？
- ☐ 个人信息量低于规定阈值（如低于10万人且非敏感）？
- ☐ 在自贸试验区且不在"负面清单"内？
- ☐ 属于跨境运输/国际贸易等特定业务场景？

## 八、数据出境合规检查清单

```markdown
# 🌐 数据出境合规检查清单

## 一、出境场景确认
- [ ] 明确界定数据出境的具体场景与数据范围
- [ ] 排除非出境情形（境外数据入境、公开数据等）

## 二、路径选择
- [ ] 评估是否触发安全评估门槛（CIIO/100万人/累计10万或1万敏感/重要数据）
- [ ] 确认是否适用《促进和规范数据跨境流动规定》的优化政策
- [ ] 选定合规路径（安全评估/标准合同/保护认证）

## 三、履行告知与同意
- [ ] 向个人告知境外接收方信息、处理目的、方式、信息种类
- [ ] 取得个人的单独同意

## 四、评估/备案/认证
- [ ] 路径①：完成数据出境风险自评估 → 申报安全评估
- [ ] 路径③：完成PIA → 签署标准合同 → 10个工作日内向省级网信备案
- [ ] 路径②：完成个人信息保护认证

## 五、合同保障
- [ ] 与境外接收方签署充分的数据保护合同/标准合同
- [ ] 约定再转移限制条件
- [ ] 约定个人信息主体权益救济机制

## 六、持续合规
- [ ] 安全评估结果有效期跟踪（2年）
- [ ] 出境目的/方式/类型变更时重新申报
- [ ] 定期复审出境合规状态
```

## 九、违规出境的法律后果

| 违规情形 | 法律后果 | 依据 |
|---------|---------|------|
| 未经安全评估擅自出境 | 责令改正、警告、罚款，情节严重可责令暂停业务/停业整顿/吊销许可 | 数据出境安全评估办法第15条 |
| 违反个人信息出境规定 | 责令改正、警告、没收违法所得、罚款（最高5000万元或上一年度营业额5%），可责令暂停/终止处理、吊销营业执照 | 个保法第66条 |
| 未履行告知同意义务 | 责令限期改正、警告、罚款 | 个保法第66条 |
