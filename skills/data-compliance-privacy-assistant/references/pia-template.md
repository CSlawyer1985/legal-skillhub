# 个人信息保护影响评估（PIA）模板和填写指南

> 法律依据：《中华人民共和国个人信息保护法》第55条、第56条，GB/T 39335-2020《信息安全技术 个人信息安全影响评估指南》。
>
> ⚠️ 免责声明：本模板仅供参考，具体评估要求以法律法规最新版本及国家网信部门发布的指南为准。

本文档是 Phase 4「个人信息保护影响评估（PIA）」的核心依据，提供 PIA 适用情形判断、评估方法、报告模板及填写指南。

---

## 一、法律依据

### 1.1 个保法第55条（PIA适用情形）

有下列情形之一的，个人信息处理者应当**事前**进行个人信息保护影响评估，并对处理活动进行记录：

| 序号 | 适用情形 | 条款项 |
|------|---------|--------|
| 1 | 处理敏感个人信息 | 第55条第1项 |
| 2 | 利用个人信息进行自动化决策 | 第55条第2项 |
| 3 | 委托处理个人信息、向其他个人信息处理者提供个人信息、公开个人信息 | 第55条第3项 |
| 4 | 向境外提供个人信息 | 第55条第4项 |
| 5 | 其他对个人权益有重大影响的个人信息处理活动 | 第55条第5项 |

### 1.2 个保法第56条（PIA内容与保存）

个人信息保护影响评估应当包括下列内容：
1. 个人信息的处理目的、处理方式等是否**合法、正当、必要**；
2. 对个人权益的影响及安全风险；
3. 所采取的保护措施是否**合法、有效并与风险程度相适应**。

> **保存要求**：个人信息保护影响评估报告和处理情况记录应当至少保存**三年**（第56条第3款）。

## 二、PIA 与合规审计的区别

| 维度 | PIA（个人信息保护影响评估） | 合规审计 |
|------|------------------------|---------|
| 法规依据 | 个保法第55-56条 | 个保法第54条 |
| 触发情形 | 特定高风险处理活动事前触发 | 定期开展（频次由规定确定） |
| 性质 | 事前预防性评估 | 事后/事中合规性检查 |
| 产出 | PIA评估报告 | 合规审计报告 |
| 保存 | 至少3年 | 按规定保存 |

## 三、PIA 评估方法论（参照GB/T 39335-2020）

### 3.1 评估流程

```
确定评估范围 ──▶ 数据映射与分析 ──▶ 风险识别 ──▶ 风险评价
      │                                              │
      └──────────────── 风险处置 ◀───────────────────┘
                         │
                         ▼
                  形成评估报告
```

### 3.2 评估维度

**维度一：合法、正当、必要（必要性审查）**
- 处理目的是否明确、合理且与直接相关；
- 收集的个人信息范围是否最小化；
- 处理活动是否具备合法性基础（个保法第13条）。

**维度二：对个人权益的影响**
- 影响个人信息主体的人格尊严、人身权、财产权；
- 可能产生歧视、人格贬损、财产损失等风险；
- 评估影响的严重程度与发生可能性。

**维度三：安全风险**
- 数据泄露、篡改、丢失、非法获取或使用的风险；
- 内部人员滥用风险；
- 第三方/供应链安全风险。

**维度四：保护措施有效性**
- 技术措施（加密、脱敏、访问控制、审计日志）；
- 管理措施（制度、培训、合同约束）；
- 物理措施（机房/设备安全）；
- 措施是否与风险程度相匹配。

### 3.3 风险等级判定矩阵

| 影响程度\发生可能性 | 低 | 中 | 高 |
|-------------------|----|----|-----|
| 严重 | 中 | 高 | 极高 |
| 一般 | 低 | 中 | 高 |
| 轻微 | 极低 | 低 | 中 |

## 五、PIA 填写指南与常见问题

### 5.1 填写要点

| 章节 | 填写要点 |
|------|---------|
| 评估范围 | 明确界定评估边界，避免过宽或过窄 |
| 处理活动描述 | 越详细越好，包含完整数据流转路径 |
| 合法性基础 | 准确对应个保法第13条，敏感信息须取得单独同意 |
| 必要性分析 | 逐项审查每个信息项的必要性，"可有可无"的应剔除 |
| 风险评估 | 实事求是，不回避高风险项 |
| 保护措施 | 描述具体可验证的措施，而非空泛承诺 |

### 5.2 常见错误

| 错误 | 正确做法 |
|------|---------|
| PIA在处理活动开展后补做 | 须事前完成（个保法第55条） |
| 评估流于形式，仅填模板 | 应有实质性的风险识别与分析 |
| 忽略第三方/境外接收方风险 | 须评估第三方与境外风险 |
| 评估后未落实改进建议 | 改进建议须有跟踪机制并落实 |
| 报告未保存或保存不满3年 | 至少保存3年（个保法第56条） |

### 5.3 自动化决策场景的PIA特殊要点
- 算法逻辑的透明度与可解释性；
- 是否存在歧视性结果；
- 是否提供不针对个人特征的选项或便捷的拒绝方式（个保法第24条）；
- 算法公平性评估。

### 5.4 数据出境场景的PIA特殊要点
- 境外接收方所在国家/地区的数据保护水平；
- 出境数据的合法性、正当性、必要性；
- 再转移风险；
- 与数据出境风险自评估的衔接。
