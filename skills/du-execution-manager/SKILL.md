# 执行管家 Skill

## 功能描述
自动识别民事执行文书（执行通知书、查封/冻结裁定书等），提取关键信息，根据民事诉讼法和执行规定计算各项期间，输出个性化的期间表。

## 使用场景
- 收到执行通知书，需要计算执行期限
- 收到查封/冻结裁定书，需要计算保全措施到期时间
- 管理多个执行案件的保全措施期限

## 输入
1. 上传文书图片（执行通知书、查封/冻结裁定书等）
2. 或手动输入关键信息

## 输出
- 执行案件基本信息
- 保全措施期限表（包含具体日期）
- 风险提示（即将到期需要续封/续冻的措施）
- 待办事项清单

## 工作流程

### 步骤1：识别文书类型和提取信息
- 如果用户上传图片，先进行OCR识别
- 从文字中提取关键信息：
  - 执行案号
  - 案件名称（见下方"案件名称提取规则"）
  - 法院名称
  - 申请执行人、被执行人
  - 立案日期
  - 执行标的
  - 保全措施信息：
    - 财产类型（不动产/动产/存款/其他）
    - 查封/冻结日期
    - 财产描述

**日期格式处理：**
- 法律文书的日期通常为中文格式，如"二○二六年一月二十二日"或"二〇二六年一月二十二日"
- 必须同时支持"○"（圆圈）和"〇"（零字）两种零的写法
- 提取日期后，转换为标准格式（YYYY-MM-DD）用于期间计算

**案件名称提取规则：**
执行文书中案件名称的表述方式多样，需要按以下优先级提取：

1. **执行案件标准格式**：优先使用"XXX申请执行XXX…一案"格式
   - 示例：张三申请执行李四合同纠纷

2. **从原审案件名称转换**：如果文书中提到原审案件名称（如"原告XXX与被告XXX…一案"）
   - 转换为执行格式：将"原告"改为"申请执行人"，"被告"改为"被执行人"
   - 示例：原审"张三诉李四合同纠纷" → 执行"张三申请执行李四合同纠纷"

3. **第二人称格式**：如果是"申请执行人XXX与你单位…一案"
   - 需要根据文书上下文，将"你单位"替换为实际被执行人名称
   - 示例：文书中"申请执行人张三与你单位合同纠纷一案"，根据抬头确定"你单位"是李四公司，提取为"张三申请执行李四公司合同纠纷"

4. **过滤程式化表述**：
   - 去除"申请执行人…与你单位…"等程式化表述中的"你单位"等代词
   - 去除重复拼接的当事人名称
   - 只保留核心的"申请执行人+被执行人+案由"信息

5. **最终格式要求**：
   - 案件名称必须包含申请执行人和被执行人
   - 格式：申请执行人申请执行被执行人+案由
   - 示例：张三申请执行李四合同纠纷

### 步骤2：计算期间
根据民事诉讼法和执行规定，计算以下期间：

#### 执行期间
1. **申请执行期限**：判决生效后2年
2. **通知被执行人**：收到申请后10日内
3. **执行管辖权异议**：收到通知后3日内

#### 保全措施期限（重点）
1. **冻结银行存款**：不超过1年
2. **查封动产**：不超过2年
3. **查封不动产**：不超过3年
4. **冻结其他财产权**：不超过3年

### 步骤4：保存案件信息
本步骤采用两级文件管理：

#### 4.1 本地案件文件（必须）
- 在用户@ 的文件所在目录下，创建期间表文件
- 文件名格式：`[案号]_保全措施期限表.md`
- 内容：包含步骤3输出的完整期间表

#### 4.2 全局任务管理（必须）
- 将所有期限信息写入全局任务文件：`tasks.json`（建议放在你的工作区根目录）
- 文件格式为JSON：`{"tasks": [...]}`
- 每个期限作为 tasks 数组中的一个对象，包含：
  - `case_id`：案号
  - `case_name`：案件名称（必须包含双方当事人/申请执行人+被执行人）
  - `case_type`：案件类型（诉讼/执行/劳动仲裁）
  - `deadline_name`：期间名称
  - `deadline_date`：截止日期（YYYY-MM-DD）
  - `legal_basis`：法律依据
  - `status`：pending/completed/overdue
  - `created_at`：创建日期
  - `case_folder`：案件文件夹路径

**重要说明：**
- 本地文件方便查看单个案件的完整期间信息
- 全局 `tasks.json` 供"待办管家"统一管理所有案件的期限
## 期间计算规则

### 执行期间规则

| 期间名称 | 计算规则 | 法律依据 |
|---------|---------|---------|
| 申请执行期限 | 判决生效后2年 | 《民事诉讼法》第239条（2023年修正） |
| 通知被执行人 | 收到申请后10日内 | 《最高人民法院关于人民法院执行工作若干问题的规定（试行）》第22条（1998年） |
| 执行管辖权异议 | 收到通知后3日内 | 《最高人民法院关于人民法院办理执行异议和复议案件若干问题的规定》第3条（2020年修正） |
| 执行行为异议 | 收到异议后15日内审查 | 《最高人民法院关于人民法院办理执行异议和复议案件若干问题的规定》第5条（2020年修正） |
| 执行标的异议 | 收到异议后15日内审查 | 《民事诉讼法》第227条（2023年修正） |

### 保全措施期限规则

| 措施类型 | 期限 | 续封/续冻期限 | 法律依据 |
|---------|------|--------------|---------|
| 冻结银行存款 | 不超过1年 | 不超过1年 | 《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第487条（2022年修正） |
| 查封动产 | 不超过2年 | 不超过2年 | 《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第487条（2022年修正） |
| 查封不动产 | 不超过3年 | 不超过3年 | 《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第487条（2022年修正） |
| 冻结其他财产权 | 不超过3年 | 不超过3年 | 《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第487条（2022年修正） |

## 特殊处理

### 续封/续冻提醒
- 保全措施到期前30天提醒
- 建议提前准备续封/续冻申请材料

### 期限计算
- 期间以日、月、年计算
- 节假日顺延规则同样适用

## 注意事项
1. 保全措施到期前必须及时续封/续冻，否则措施失效
2. 本Skill计算的期间仅供参考，具体以法院通知为准
3. 如有疑问，请及时咨询承办法官
