# panel-design-selection

**OCM 技能插件**——8 个技能中的第 2 个
**状态：**已完成——阶段 1 和阶段 2 已测试

---

## 本技能的用途

为正在建立或正式化其外部律师库（panel）的法务团队设计律师库结构、定义律所选聘标准、进行合理外包（right-sourcing）分析，并评估覆盖缺口。

律师库设计不是律师库评审。设计问的是：律师库应该是什么样？评审问的是：律师库表现如何？本技能构建框架。panel-review-rationalisation（技能 8）据此衡量。

---

## 模式

| 模式 | 触发词 | 输出 |
|------|---------|--------|
| 1——律师库设计 | "设计我们的律师库" / "我们需要多少家律所" / "律师库结构" | 律师库设计文件 + 总法律顾问简报 |
| 2——选聘标准框架 | "律所选聘标准" / "我们如何选择律所" / "给标准加权" | 选聘标准矩阵 + 总法律顾问简报 |
| 3——合理外包分析 | "合理外包" / "我们是否把工作送对了律所" / "这需要大型律所吗" | 合理外包分析 + 总法律顾问简报 |
| 4——覆盖缺口分析 | "律师库缺口" / "我们需要一家[领域]的律所" / "律所太多" / "整合" | 覆盖评估 + 总法律顾问简报 |

---

## 关键设计决策

**双重用途的标准框架。**选聘标准矩阵（模式 2）既用于 RFP 评估（rfp-pitch-management），也用于持续的绩效衡量（performance-scorecard）。你用来选聘律所的标准，应当就是用来评价他们的标准。如果该框架只在选聘时用一次然后归档，它就失败了。

**ABC 分级用于合理外包。**模式 3 将工作分为三个层级——复杂/战略性（A）、专业/实质性（B）、常规/批量（C）——并将当前服务商分配与之对照。最常见的错配是 C 级工作在 A 级服务商处。财务影响就在那里。

**关系维度被标记。**影响总法律顾问有深厚关系的律所的合理外包建议会被明确标记。分析针对的是工作，而非律所。如何行动由总法律顾问决定。

**试点优先的重新分配。**合理外包建议包含推荐的试点范围，而非全盘重新分配。试点产生证据，为更广泛的变革提供依据。

**按支出基准。**律师库规模建议锚定于年度支出基准，而非抽象的最佳实践。低于 200 万英镑：3-5 家律所。200 万至 1000 万英镑：5-10 家。超过 1000 万英镑：8-15 家以上。

## 跨技能连接

| 技能 | 连接 |
|-------|-----------|
| rfp-pitch-management（技能 3） | 律师库结构和选聘标准直接输入 RFP 设计和评估。 |
| engagement-terms-billing-guidelines（技能 1） | 律师库层级决定 OCG 强度。战略合作伙伴可能有谈判后的条款。 |
| performance-scorecard（技能 7） | 选聘标准框架是持续绩效衡量的基线。 |
| panel-review-rationalisation（技能 8） | 本技能构建框架；技能 8 据此评估律师库。 |
| matter-allocation-instruction（技能 5） | 律师库结构决定哪家律所获得哪种类型的事项。 |
