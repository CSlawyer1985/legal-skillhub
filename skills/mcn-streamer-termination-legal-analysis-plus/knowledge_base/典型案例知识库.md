## 十、知识库使用指引（供 Skill 运行时调用）

1. **检索匹配**：当用户陈述争议焦点（如"主播停播违约金过高""账号归谁""是否构成劳动关系""竞业限制有效吗"），WB 应优先从本知识库对应章节匹配 3-5 个最相关案例，作为第三步法律分析的"类案支撑"。
2. **引用规范**：引用时须完整标注「案号 + 审理法院 + 裁判日期 + 来源」。无案号者标注报道来源与日期，并在正式报告标注"待核实"。
3. **补充检索**：本知识库为静态沉淀；当案件具特殊性或需最新案例时，Skill 第四步仍应联动「案例检索报告（中国大陆地区法院案例检索）Plus」做动态检索（不少于5个），不以本库替代实时检索。
4. **时效提示**：案例裁判要旨基于检索时现行法；引用前应核验《民法典》及相关司法解释最新版本。
5. **补录批次**：本库经四次专项补录（均在 2026-07-16），与初始 50 条共同构成现 120 条规模：
   - **第一次「账号争夺」专项**（序号 51-59，9 条，见第四章/第五章补录标注）；
   - **第二次「劳动关系认定」专项**（序号 60-76，17 条，见第一章补录标注，分"存在/不构成劳动关系"两类）；
   - **第三次「多渠道补充」专项**（序号 77-107，31 条，分布于各章，见各章"补录三"标注；来源扩至华宇元典 MCP + 各级法院公开文书/报道 + 法治媒体与微信公众号，渠道更多元）；
   - **第四次「补充检索」专项**（序号 108-120，13 条，见各章"补录四"标注；来源华宇元典 MCP + 广东高院发布等）。

   补录条目均含 `category`/`batch` 溯源字段（JSON）。案号标注"未列明"者（如序号 64/65/66/67 二审/75/76/89/90/99/100/101/102/104/106/107）仅来源于媒体报道、未经裁判文书网核验，正式引用前须复核确切案号与现行效力。
