# 质量检查清单

## 语义保真

- [ ] 主体、行为、对象、时间、金额和地点均未改变。
- [ ] 条件、例外、否定范围和责任范围均未扩大或缩小。
- [ ] “可能、通常、据称、主张”等不确定性和立场标记均被保留。
- [ ] 未把证据、陈述或主张改写为已认定事实。
- [ ] 未新增法条、案号、来源、事实或法律结论。

## 术语与逻辑

- [ ] 同一概念和主体称谓前后一致。
- [ ] 解除、终止、无效、撤销、撤回等词未被混用。
- [ ] 每个代词均有唯一、明确的指向。
- [ ] 因果、条件、转折、并列和例外关系清楚。
- [ ] 拆句或调整语序后，条件与结论仍正确对应。

## 语言质量

- [ ] 删除了不增加信息的套话和重复表达。
- [ ] 没有为正式感而堆砌文言词或法律术语。
- [ ] 句子长度和段落节奏符合目标读者需要。
- [ ] 标点、数字、编号和引文格式一致。
- [ ] 原文已经清楚的地方没有被无意义改写。

## 输出与风险提示

- [ ] 输出模式符合用户要求。
- [ ] 实质歧义已列入“需确认事项”。
- [ ] 疑似实体法律错误仅作风险提示，没有擅自纠正或掩盖。
- [ ] 高风险文本明确提示仍需事实核查和专业法律审查。

## 失败条件

出现下列任一情形，应停止确定性改写并提出确认事项：

- 无法判断某一行为的主体或对象。
- 两种改写会产生不同法律效果。
- 原文前后事实、日期、金额或称谓冲突。
- 必须先判断实体法问题才能选择术语。
- 用户要求把未经证实的主张写成确定事实。
