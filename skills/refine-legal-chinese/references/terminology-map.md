# 术语辨析与转换

## 使用原则

本文件提供候选表达，不提供自动替换规则。先判断事实关系和法律语境，再选择术语。信息不足时保留较中性的表达并提出确认事项。

## 日常表达转法律表达

| 日常表达 | 可选法律表达 | 使用条件或风险 |
|---|---|---|
| 打官司 | 提起诉讼、参加诉讼 | 不要混同仲裁、调解或执行程序 |
| 赔钱 | 赔偿损失、支付赔偿款、承担赔偿责任 | 先确认责任性质及给付内容 |
| 没做到 | 未履行、未全面履行、履行不符合约定 | 三者法律效果可能不同 |
| 欠钱不还 | 未按期履行金钱给付义务 | 需确认是否已经到期 |
| 说谎 | 作出不实陈述、作虚假陈述 | “虚假”可能包含主观评价，谨慎使用 |
| 同意了 | 表示同意、作出承诺、达成合意 | “承诺”有特定合同法含义 |
| 改主意 | 撤回、撤销或变更意思表示 | 三者适用条件不同，不可直接替换 |
| 不干了 | 停止履行、终止合作、解除合同 | 先确认行为和法律依据 |
| 找人说理 | 协商、投诉、申请调解、寻求法律救济 | 根据实际程序选择 |
| 出事了 | 发生事故、发生争议、出现合规事件 | 应具体说明事件性质 |

## 高频近义法律词

### 解除、终止、无效、撤销

- **解除**：通常针对已经成立并生效的合同关系，使未履行部分不再履行，并产生相应清算后果。
- **终止**：上位或结果性表达，可能基于履行完毕、抵销、免除、解除等原因。
- **无效**：指法律行为不发生预期法律效力，不能作为“以后不合作”的一般表达。
- **撤销**：须有相应撤销权或程序依据，不等同于撤回或解除。

不能根据语言习惯互换；事实不足时使用“结束合同关系”等中性表达并提示确认。

### 撤回与撤销

- **撤回**通常发生在行为生效前，阻止其发生效力。
- **撤销**通常针对已经生效或成立的行为，使其效力发生变化。

具体规则依法律行为和程序而异，不仅凭时间先后判断。

### 订立、签订与签署

- **订立合同**强调合同形成的法律过程。
- **签订合同**是通行表达，可涵盖协商并签字盖章的过程。
- **签署合同**更强调签字、盖章等签署行为。

### 认可、承认与执行

- 对外国法院判决、外国仲裁裁决等使用何种术语，应遵循相应法律制度和官方文本。
- 不因日常语言相近而将“认可”“承认”“执行”合并或互换。

### 法人、法定代表人与负责人

- **法人**是组织主体。
- **法定代表人**是依法代表法人从事民事活动的自然人。
- **负责人**可能是分支机构、非法人组织或具体部门的负责人。

### 证明、认定与推定

- **证明**描述证据或举证达到某种状态。
- **认定**通常描述有权主体对事实或法律问题作出的判断。
- **推定**须有法律规则或经验法则基础，不能作为“猜测”的正式替代词。

## AI 高频空泛表达

| 原表达 | 优化方向 |
|---|---|
| 从法律角度来看 | 给出具体分析，或直接删除 |
| 存在一定风险 | 说明风险事件、触发条件和可能后果；信息不足则保留不确定性 |
| 应当予以重视 | 改为具体行动建议，或删除 |
| 值得深入探讨 | 直接提出需要分析的问题 |
| 具有重要现实意义 | 说明具体影响，或删除 |
| 提供法律保障 | 说明权利、义务、程序或责任机制 |
| 有利于维护合法权益 | 说明可以主张的权利和可采取的路径 |
| 相关法律法规 | 能明确时列明类别；不能明确时不要伪造名称 |

## 风险表达梯度

按原文证据强度选择，不主动升级：

1. 尚无法判断
2. 可能涉及
3. 存在……风险
4. 较可能构成
5. 构成或应认定为

只有原文已经给出充分事实和判断依据时，才能使用第 4 或第 5 级表达。
