# 交底书生成前摘要预览（Step 6）

## 目的

在输出完整长文前降低返工：基于用户在 Step 3–4 确认的专利点编号，展示结构化摘要，请用户 **确认 / 调整方向**。不得把已标记为“不写”或“商业秘密保护”的点重新写入摘要，除非用户明确改变取舍。

若用户明确要求跳过预览，可直接进入 `disclosure_builder.md` 生成全文。

## 摘要应包含

- 选定专利点名称（工作标题）
- 发明人/发明者：列出已确认姓名；未知时标注 `[待填写]`，不得编造
- 对应 Step 3–4 的专利点编号与取舍结论
- 解决的技术问题：对应现有技术缺点，1–3 条
- 核心技术方案预览：方法步骤、系统模块、关键子流程（3–6 条）
- 与检索到的**最相近**现有技术的区别（1 段）
- 不写入正文的技术边界：列出用户已要求秘密保护或暂不申请的技术点（仅列边界，不展开秘密细节）
- 预计正文结构：技术领域、背景技术、发明内容、附图说明、具体实施方式、摘要

## 可选确认语

```
以上方向是否确认？确认后将仅围绕已确认编号输出说明书式技术交底书，标题下写明发明人/发明者，正文含发明内容、具体实施方式、mermaid 方法流程图、系统结构图和必要的关键子流程图；已标记为不写或商业秘密保护的内容不会展开。定稿时请您选择交付 Markdown 还是 Word；若选择 Word，再选择图示使用本地 PNG 渲染、输出专利附图风格生图提示词，或调用 OpenAI-compatible 图片接口自动生成 PNG 并插入 Word，并确认是否同时导出 PDF。
```

## 禁止写入

摘要 Markdown **末尾不得**追加技能仓库名、`examples/` 路径、「教学示例」「虚构」「不构成法律承诺」等脚注（与 `disclosure_builder.md` 对定稿的要求一致）。
