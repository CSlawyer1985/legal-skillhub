# 边界与输入录入（Step 1）

## 用途

在开始专利挖掘与交底书撰写前，用**少量问题**收敛案件边界。信息不全时可跳过，由 Agent 后续推断并**注明假设**。

## 可选开场

```
为便于挖掘专利点与组织交底书，先确认几项边界；可跳过，将按已有材料推断。
```

## 问题序列

### Q1：技术主题或产品模块

```
请用一句话描述本方案所属技术主题或产品模块，例如「多模态检索排序」「工业质检缺陷分级」。
```

### Q2：专利类型倾向

```
是否已有倾向的权利要求类型？方法 / 系统 / 装置 / 暂不确定
```

### Q3：不公开边界

```
哪些技术细节不希望写入专利正文、只作为商业秘密保护？例如完整 prompt、真实规则表、真实训练数据、客户口径或内部参数。
```

### Q4：发明人/发明者

```
交底书正文标题下需要写明发明人/发明者。请提供姓名列表；若暂不确定，可先写为 [待填写]。
```

## 汇总

将已确认项用 3–6 行 bullet 复述给用户，再进入 `project_scan.md` 对应的扫描阶段。不得询问或写入技术联系人、委托确认等非技术正文信息。
