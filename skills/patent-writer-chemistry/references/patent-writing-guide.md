## 二、典型测试方法模板

### 保湿率测试（体外称重法）

在恒温恒湿环境（温度24-26℃，相对湿度42-48%）中，取等量（0.20-0.25g）各待测样品均匀涂覆于定量滤纸基材（面积为20-25cm²）上，记录涂覆前基材重量（W0），涂覆并放置15分钟后记录重量（W1），随后在各时间点记录基材重量（Wt）。保湿率（%）= [(Wt - W0) / (W1 - W0)] × 100%。

### 稳定性测试（高低温循环）

样品在-15至-10℃条件下放置24小时，转移至48-52℃条件下放置24小时，此为一个循环，连续进行5个循环后观察外观变化。

### TEWL测试（体外模型）

取胶原蛋白膜作为皮肤替代模型，恒温恒湿平衡后涂覆样品，在各时间点称重计算累计失水量。TEWL降低率（%）= [1 - (样品累计失水量 / 空白累计失水量)] × 100%。

### 中文检索关键词范式

- 产品名 + 核心成分 + 功能词 + 专利
  - 例：护手霜 芦荟多糖 保湿 专利
  - 例：洗发水 生姜 微胶囊 专利
- 核心成分 + 制备方法 + 专利
  - 例：芦荟乙酰化甘露聚糖 酶解提取 专利
- 技术特征 + 效果 + 专利
  - 例：油包水 护手霜 耐水洗 专利

## 四、权利要求书撰写快速参考

### 独立权利要求1（产品）标准模板

```
1. 一种[性能限定词]+[产品类型]组合物，其特征在于，按重量百分比计，其组成为：
   [必要组分A]    a%-b%；
   [必要组分B]    c%-d%；
   [必要组分C]    e%-f%；
   ……（仅列出必要技术特征）
   余量为水。
```

### 从属权利要求标准格式

```
2. 根据权利要求1所述的组合物，其特征在于，所述[组分A]的含量为[x]%-[y]%。
3. 根据权利要求1所述的组合物，其特征在于，还包含[含量范围]的[附加组分D]。
4. 根据权利要求1所述的组合物，其特征在于，所述[组分A]为[下位具体物质]，其[特征参数]为[范围]。
```

### 独立权利要求2（制备方法）标准模板

```
N. 权利要求1-M中任一项所述的组合物的制备方法，其特征在于，包括以下步骤：
   （1）[步骤一]；
   （2）[步骤二]；
   （3）[步骤三]；
   （4）[步骤四]；
   （5）[步骤五]，即得。
```

### 用途权利要求（如适用）

```
N. 权利要求1-M中任一项所述的组合物在制备[具体产品类型]中的应用。
```

## 五、摘要撰写快速参考

**五要素检查**：
- [ ] 发明名称（20-25字）
- [ ] 所属技术领域（15-25字）
- [ ] 要解决的技术问题（30-60字）
- [ ] 技术方案的要点（80-150字，含核心配方）
- [ ] 主要用途（15-30字）

**禁止出现在摘要中**：
- "本发明提供"、"权利要求所述"
- "优于"、"高于"等比较级
- 商业宣传语
- 分段
