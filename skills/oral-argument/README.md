以 Neal Katyal 2025 年 11 月美国最高法院关税案辩论及其 AI 陪练搭档“Harvey”为蓝本的庭审准备技能。五个阶段：(1) 依据既往意见、提问、协同意见和反对意见为每位决策者画像——揭示其法理立场和制度关切；(2) 预测法官席——每位法官 3–7 个可能问题及每个问题背后的担忧，置信度高时给出逐字措辞；(3) 绘制退路——每位持怀疑态度的法官在不放弃既有立场的前提下能够签署的最窄裁判结论；(4) 对抗性陪练——无情的追问、点破鹦鹉学舌式的复述、跟踪哪些问题击垮了律师；(5) 将律师交还给自己，附一张用于讲台的 <150 词索引卡。模型是陪练搭档。赢得案件的仍是律师。用于口头辩论、动议听证、证词取证、仲裁，或在提交前压力测试诉状。
