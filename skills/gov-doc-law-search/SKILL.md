# 政府文件法律法规标准查询

## 概述

本技能提供系统化的中国政府文件、法律法规、规范标准的搜索与整理能力。针对用户输入的任意主题关键词，从互联网权威来源进行全面检索，输出结构化的查询结果。

## 使用时机

当用户提出以下类型的需求时触发本技能：
- "帮我查一下XX相关的法律法规"
- "XX行业有什么国家标准？"
- "XX省对XX有什么规定？"
- "关于XX的最新政策文件是什么？"
- "我需要XX方面的合规依据"
- "特种设备/危险化学品/消防/建筑/环保……相关的标准有哪些？"

## 搜索策略

采用**分层次、多维度**的搜索方法，确保覆盖全面。

### 第一步：解析用户意图

从用户输入中提取以下信息：
1. **主题关键词**：核心搜索词（如"压力管道"、"危险化学品储存"）
2. **地域范围**：全国 / 特定省 / 特定市（默认全国）
3. **文件类型偏好**：法律 / 法规 / 标准 / 政府文件 / 全部（默认全部）
4. **时效性要求**：最新 / 不限（默认优先最新）

### 第二步：分维度搜索

针对每一类文件，使用独立的、精准的搜索语句。同时发起多路 WebSearch 调用以提高效率。

#### 维度1：法律法规（国家层面）
搜索语句模板：
- `{关键词} 法律 行政法规 部门规章 site:gov.cn`
- `{关键词} 条例 管理办法 规定 site:flk.npc.gov.cn`
- `{关键词} 法律法规 全文`

#### 维度2：国家标准与行业标准
搜索语句模板：
- `{关键词} 国家标准 GB site:std.samr.gov.cn`
- `{关键词} 国家标准 GB/T 强制性标准`
- `{关键词} 行业标准 {行业名} 规范`
- `{关键词} 团体标准 T/ site:ttbz.org.cn`

#### 维度3：地方政府文件
搜索语句模板：
- `{地域} {关键词} 管理规定 通知 办法`
- `{省/市} {关键词} 条例 地方性法规`
- `{关键词} 地方政府规章 site:gov.cn`

#### 维度4：政策文件与指导意见
搜索语句模板：
- `{关键词} 国务院 通知 意见 政策文件`
- `{关键词} 管理办法 实施细则`
- `{关键词} 安全技术规范 监察规程`

#### 维度5：ima 知识库全量检索（强烈推荐）

使用 ima MCP 的 `search_knowledge` 工具，在用户有权访问的**全部 ima 知识库**中搜索主题相关资料——不只是自有知识库，更包括其他用户创建并公开分享的行业知识库（如「化工装置案例库」4874项/30GB 等）。这能发现 WebSearch 难以覆盖的行业内部文档、标准汇编、专家整理的案例资料。

**知识库覆盖范围（全量）：**

| 知识库类型 | API type 参数 | 说明 |
|-----------|--------------|------|
| 我的知识库 | `KBT_MINE_KB` | 自己创建的知识库 |
| 我创建的共享知识库 | `KBT_SHARED_KB` | 自己创建并公开/分享给他人的知识库 |
| 我创建并订阅的知识库 | `KBT_SUBSCRIBED_CREATE_KB` | 自己创建且已订阅的知识库 |
| 我加入的知识库 | `KBT_SUBSCRIBED_JOIN_KB` | **其他用户分享的公开知识库**（最关键） |

> ⚠️ **核心价值在于「我加入的知识库」**——这是其他用户（如行业专家、机构）创建并公开分享的优质知识库，是 ima 最独特的差异化数据源。

**调用方法：**

1. 首先使用 `mcp__ima-mcp__get_knowledge_base_list` 批量获取全部四类知识库。可通过 `params` 数组一次性发起多个类型的查询：
   ```
   params: [
     {limit: 50, type: "KBT_MINE_KB"},
     {limit: 50, type: "KBT_SHARED_KB"},
     {limit: 50, type: "KBT_SUBSCRIBED_JOIN_KB"}
   ]
   ```

2. 合并所有来源的知识库列表，根据查询主题筛选名称/描述匹配的。例如：
   - 查询化工/特种设备/危化品相关 → 筛选含"化工""生产""管理""标准""储运""装置"的知识库
   - 查询建筑/消防相关 → 筛选含"建筑""工程""消防""施工"的知识库
   - 查询环保/安全相关 → 筛选含"环保""安全""应急""环境"的知识库
   - 查询法律/法规相关 → 筛选含"法律""法规""管理文件""制度"的知识库

3. 对筛选出的每个匹配知识库，使用 `mcp__ima-mcp__search_knowledge` 搜索，参数：
   - `knowledge_base_id`：匹配到的知识库 ID
   - `query`：与 WebSearch 相同的 `{关键词}`

4. 将知识库中的 PDF、Word、网页、笔记等搜索结果纳入输出。注意标注：
   - 来源知识库名称（如「化工装置案例库 — 来自用户：打你一下」）
   - 知识库创建者（以区分自有和他人分享的资料）

5. 每轮查询都动态读取知识库列表，不依赖硬编码 ID。

### 第三步：深度获取内容

对搜索结果中的高价值链接（官方政府网站、标准信息平台、法律法规数据库等），使用 WebFetch 工具获取页面详细内容，提取：
- 文件/标准全称
- 发布机关
- 发布日期 / 生效日期
- 文号（如有）
- 关键条款或章节的具体内容
- 适用范围

### 第四步：整理输出

将所有查询结果按以下格式结构化输出。

## 权威来源优先级

搜索和引用时，优先采用以下权威来源（详见 `references/sources.md`）：

**第一优先级（官方数据库）：**
- 国家法律法规数据库 (flk.npc.gov.cn)
- 国家标准全文公开系统 (openstd.samr.gov.cn)
- 全国标准信息公共服务平台 (std.samr.gov.cn)
- 中国政府网 (www.gov.cn)

**第二优先级（行业权威平台）：**
- 全国团体标准信息平台 (ttbz.org.cn)
- 各行业主管部门官方网站
- 各省市政府官方网站

**第三优先级（第三方收录）：**
- 北大法宝、威科先行等法律数据库
- 百度百科（仅作概述参考，不作为权威引用）

**补充来源（ima 知识库 — 全量覆盖）：**
- 自有知识库（`KBT_MINE_KB`）：用户自己创建和维护的知识库
- 共享知识库（`KBT_SHARED_KB`）：用户创建并分享给他人或公开的知识库
- 已加入知识库（`KBT_SUBSCRIBED_JOIN_KB`）：其他用户（行业专家、机构、组织）创建并公开分享的优质资源
- 资料类型涵盖 PDF、Word、PPT、Excel、网页、笔记等，可作为官方来源的补充和交叉验证
- 在搜索结果中标明来源知识库及创建者，便于区分权威等级

## 质量要求

1. **准确性优先**：信息必须来自可验证的官方来源，避免依赖非权威网站
2. **时效性标注**：明确标注文件的发布日期和当前效力状态（现行有效/已修订/已废止）
3. **完整性**：覆盖法律法规、标准、政策文件三大类别，ima 知识库作为补充
4. **可追溯**：每条结果必须提供来源链接（Web 来源）或来源知识库名称（ima 来源）
5. **实用性**：重点摘录与用户查询主题直接相关的条款，而非全文搬运
6. **地域区分**：明确区分全国性文件和地方性文件
7. **知识库融合**：Web 搜索和 ima 知识库（自有+他人分享）搜索结果去重后合并，互补呈现；注明知识库创建者以区分来源可信度。他人的行业知识库往往包含 Web 搜索难以发现的内部标准汇编和专家整理资料。
