## 四、地方性法规搜索策略

对于地方性法规，搜索时注意：
1. 省级：搜索 `{省名} 人大常委会 条例 {关键词}` 或 `{省名} {关键词} 管理规定 site:gov.cn`
2. 市级：搜索 `{市名} {关键词} 办法 通知`
3. 各省市政府门户网站格式通常为 `{省缩写}.gov.cn`（如 hebei.gov.cn、sh.gov.cn）

常用省级政府网站：
- 北京：beijing.gov.cn
- 上海：shanghai.gov.cn
- 广东：gd.gov.cn
- 江苏：jiangsu.gov.cn
- 浙江：zj.gov.cn
- 山东：shandong.gov.cn

## 六、搜索技巧

1. **site 限定**：`site:gov.cn` 限定政府网站，`site:samr.gov.cn` 限定市场监管总局
2. **filetype 限定**：`filetype:pdf` 搜索 PDF 格式的正式文件
3. **引号精确匹配**：`"压力管道安全技术监察规程"` 精确匹配完整标题
4. **时间限定**：WebSearch 支持时间过滤时，优先最近 5 年
5. **文号搜索**：已知文号时，直接搜索 `XX发〔2020〕X号`
6. **组合搜索**：`{关键词} (标准 OR 规范 OR 规程)` 覆盖多种术语

## 七、ima 知识库集成

### 概述
使用腾讯 ima（ima.qq.com）的 MCP 工具，在用户有权限访问的**全部 ima 知识库**中搜索——不只是自己的知识库，更包括其他用户（行业专家、机构、组织）创建并公开分享的优质知识库。这些他人分享的知识库往往是 ima 最独特的差异化数据源，包含 Web 搜索难以发现的行业内部文档、标准汇编、专家整理案例。

### 知识库覆盖范围（全量四类）

| 类型代码 | 含义 | 来源 | 价值 |
|----------|------|------|------|
| `KBT_MINE_KB` | 我的知识库 | 自己创建 | 个人沉淀资料 |
| `KBT_SHARED_KB` | 我创建的共享知识库 | 自己创建并公开/分享 | 自己整理的可公开资料 |
| `KBT_SUBSCRIBED_CREATE_KB` | 我创建并订阅的知识库 | 自己创建且已订阅 | 自有活跃知识库 |
| `KBT_SUBSCRIBED_JOIN_KB` | 我加入的知识库 | **其他用户/机构分享** | 🔥 最核心差异化来源——行业专家、专业机构公开的优质知识库 |

> ⚠️ **「我加入的知识库」是重点**：例如「化工装置案例库」（4874项/30GB，创建者 打你一下，459人加入）等，这些是其他专业人士长期积累的精华资料，Web 搜索几乎不可能覆盖。

### 可用工具

| 工具名称 | 用途 | 关键参数 |
|----------|------|----------|
| `mcp__ima-mcp__get_knowledge_base_list` | 获取用户可访问的全部知识库列表 | `type`: 四种类型之一；可通过 `params` 数组一次性批量查询多种类型 |
| `mcp__ima-mcp__search_knowledge` | 在指定知识库内搜索 | `knowledge_base_id`, `query` |
| `mcp__ima-mcp__get_knowledge_list` | 获取知识库内的知识列表 | `knowledge_base_id`, `limit` |

### 搜索流程

1. **批量获取全部知识库**：调用 `get_knowledge_base_list` 一次性查询四种类型（通过 `params` 数组）：
   ```
   params: [
     {limit: 50, type: "KBT_MINE_KB"},
     {limit: 50, type: "KBT_SHARED_KB"},
     {limit: 50, type: "KBT_SUBSCRIBED_JOIN_KB"}
   ]
   ```
2. **智能匹配筛选**：从合并后的全部知识库列表中，根据查询主题筛选相关的：
   - 名称/描述关键词匹配（如搜索"压力管道"→ 匹配含"化工""生产""管理""标准""储运""装置"的知识库）
   - 优先选择规模较大（知识项多）、描述专业的他人共享知识库
3. **逐库搜索**：对每个匹配的知识库调用 `search_knowledge` 检索
4. **标注来源**：输出时注明知识库名称 + 创建者，区分自有和他人来源
5. **合并去重**：将 ima 结果与 Web 搜索结果合并，去重后统一输出

### 资料类型
ima 知识库支持的文件类型（可在搜索时用 `filters.media_type_filter` 限定）：

| 类型代码 | 含义 | 适用场景 |
|----------|------|----------|
| PDF | PDF 文档 | 标准全文、法规文件扫描件 |
| WORD | Word 文档 | 管理制度、操作规程 |
| WEB | 网页 | 政策解读、新闻报道 |
| PPT | 演示文稿 | 培训材料、宣贯课件 |
| EXCEL | 电子表格 | 清单、台账 |
| WECHAT_ARTICLE | 微信公众号文章 | 官方解读 |
| NOTE | 笔记 | 学习摘要、标注 |
| TXT | 纯文本 | 法规条文 |

### 注意事项

1. **知识库 ID 是动态的**：每次查询前都应调用 `get_knowledge_base_list` 获取最新信息，不硬编码 ID；用户随时可能加入新的公开知识库
2. **全量覆盖，不遗漏**：同时查询四类知识库，特别关注 `KBT_SUBSCRIBED_JOIN_KB` 中的他人分享知识库
3. **去重处理**：ima 知识库中的内容可能与 Web 搜索结果重复（如同一标准 PDF），合并时标注双来源
4. **权威性等级**：ima 中他人分享的知识库资料属于补充参考来源，权威性低于官方数据库，但高于百度百科等泛化来源
5. **链接追溯**：ima 中网页类型的资料应提取其原始 URL 作为来源链接
6. **来源区分**：标注知识库创建者，用户可据此判断资料的整理质量和专业程度
