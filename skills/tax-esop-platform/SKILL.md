### 一、持股平台搭建与递延纳税
- 🧮 **递延纳税判定**：依据相关财税文件，逐条核验递延纳税七项条件（境内居民企业、股权激励计划、技术成果/股权奖励、对象为技术骨干或高管、持有满3年、行业属鼓励类、境内居民个人）；**有限合伙持股平台间接持有通常不满足"直接持有"要件，难以适用递延**——给出判定清单与替代方案
- 🏗️ **搭建架构税务设计**：有限合伙 vs 公司型持股平台税负对比（经营所得相应税率区间、分红穿透20%、股权转让所得），结合是否拟上市、员工人数、退出节奏给出架构建议与风险清单
- ⚠️ **风险预警**：误将合伙平台当作可递延主体、代持未还原、平台份额转让按财产转让20%或经营所得征税的分歧等高频雷区

**典型问法：**
```
"员工持股平台能不能递延纳税？"
"有限合伙持股平台搭建有什么税务风险？"
"股权激励计划怎么设计才能满足条件？"
```

### 二、分红、转让与减持的税率适用
- 🧮 **多情形税率测算**：合伙平台分红（自然人合伙人20%）、平台转让股权（经营所得相应税率区间 或 部分地区20%）、员工直接持股转让（财产转让20%）、创投单一投资基金核算（20% 至政策到期前）四类情形对照测算
- 🔍 **减持股票税率**：平台通过二级市场减持上市公司股票，区分转让所得性质与计税方式，提示"减持方式定税率"的实务要点
- ⚖️ **管理合伙人溢价收购**：GP 以明显高于净资产价格收购员工份额的定价税务处理与公允性风险

**典型问法：**
```
"有限合伙持股平台分红怎么交税？"
"员工持股平台减持股票税率多少？"
"合伙平台转让股权按相应税率区间还是20%？"
```

### 三、股份支付、股权代持与上市审核
- 📒 **股份支付处理**：依据股份支付准则及财政部应用案例，判断授予日、等待期、行权日；拟IPO企业以"上市成功"为可行权条件的会计处理与税务衔接
- ⚖️ **股权代持效力与还原**：结合《公司法解释三》《九民纪要》及最高法法答网（上市公司/新三板代持无效），厘清代持协议效力、代持还原的个税/印花税处理与证据链
- 📋 **上市审核规则**：闭环原则、36个月锁定期、股东穿透计算（政策到期前后平台原则上需包含全体员工的审核口径）、股份支付费用对盈利指标的影响

## 成果报告概要示例

> 以下为「主体公司税前利润 1000 万、企税率 25%、转让利得 500 万」参数下的成果报告概要（完整报告含四章 + 政策附录，可由系统一键生成）：

**股息分红环节（两形式税负一致）**

| 对比项 | 有限公司平台 | 有限合伙平台 |
|--------|--------------|--------------|
| 主体公司企税（25%） | 250 万 | 250 万 |
| 员工股息个税（20%） | 150 万 | 150 万 |
| 员工到手 | 600 万 | 600 万 |
| 综合税负率 | 40% | 40% |
| 个税递延 | 可（留存不分配） | 不可（先分后税） |

**股权转让（退出）环节（差异核心）**

| 对比项 | 有限公司平台 | 有限合伙平台 |
|--------|--------------|--------------|
| 平台层税负 | 企税25% = 125 万 | 经营所得35% = 175 万 |
| 穿透/分配后个人税负 | 再缴股息20% = 75 万 | （已含在经营所得） |
| 个人最终到手 | 300 万 | 325 万 |
| 综合税负率 | 40% | 35% |

**最优选择推荐**：对绝大多数以"激励+退出"为目标的员工持股平台，优先采用「有限合伙企业」形式——股权转让环节税负更低（35% vs 40%）、GP 集中控制、设立与退出简便；若核心诉求是利润长期沉淀再投资、递延个人税负，则选「有限公司」平台。实务可采用"有限公司（长期/递延）+ 有限合伙（激励/退出）"双平台架构。

## 重要提示与边界声明

**重要提示**
1. **合伙平台递延受限**：有限合伙持股平台间接持有通常不满足相关财税文件"直接持有"要件，难以适用递延纳税；拟申请递延应优先评估直接持股或符合规定的架构。
2. **减持方式定税率**：持股平台转让股权 vs 减持上市公司股票、自然人直接转让 vs 合伙份额转让，计税方式可能不同，重大退出前务必就具体路径核验。
3. **代持效力分层**：非公众公司代持一般有效但还原涉个税/印花税；上市公司、新三板代持依最高法法答网及监管规则原则上无效，上市前须彻底清理。
4. **数据以官方为准**：员工持股相关财税与上市审核政策时效性强，具体适用请核验最新文件与审核动态。

**边界（本技能不做的）**
- **不代办**：持股平台的工商登记、代扣代缴申报、基金备案等需登录系统操作的事项
- **不代理**：股权代持诉讼、股权激励法律尽调、上市保荐等需执业资质的事务
- **不担保**：递延纳税适用性、代持还原定性、股份支付费用归集等争议区最终以税务机关、证监会或司法机关认定为准
