政策依据
  • 《中华人民共和国企业所得税法》第26条——居民企业之间股息红利免税。
  • 《中华人民共和国个人所得税法》——利息股息红利所得20%；综合所得3%–45%；经营所得5%–35%。
  • 国税函〔2001〕84号——合伙企业对外投资分回股息红利，单独按"利息、股息、红利所得"20%由合伙人缴纳。
  • 财政部 税务总局公告2021年第41号——持有股权等权益性投资的合伙企业一律查账征收（2022-01-01起）。
  • 财税〔2016〕36号——股息红利不征增值税；非上市股权转让非金融商品转让，不征增值税。
  • 《中华人民共和国印花税法》——股权转让书据（非上市）按产权转移书据0.05%（双方）。
  • 小微企业所得税优惠（实际税负5%，延续至2027年底）——业务分拆须具真实商业实质。

❓ 我们准备做员工股权激励，用有限公司做持股平台还是有限合伙更合适？两种在税负上差多少？
  1. 核心差异在退出环节的转让税负：有限公司平台转让股权需先缴企业所得税25%、分红再缴个人股息20%，综合约40%；有限合伙平台按经营所得5%–35%超额累进，大额约35%。
  2. 股息分配环节两者一致：平台分回的股息红利，员工均按“利息、股息、红利所得”缴20%（依据国税函〔2001〕84号）。
  3. 递延需求不同：有限公司可留存利润不分配，个人股息个税可递延；有限合伙“先分后税”，利润留平台当年也须缴税。
  4. 控制权安排：有限合伙由GP执行事务掌握控制权，LP仅出资分收益，适合钱权分离，可据“是否急于变现、是否需递延”选择。
❓ 我们有限合伙持股平台收到被投公司的分红，给员工分配时要按什么税目、什么税率报个税？
  1. 合伙平台对外投资分回的股息红利，不并入经营所得，而应单独按“利息、股息、红利所得”由合伙人缴20%个税（国税函〔2001〕84号）。
  2. 不得错按“经营所得5%–35%”或已取消的核定征收申报，否则存在补税风险。
  3. 申报时平台须严格按84号函代扣代缴，留存分配决议与付款凭证。
  4. 增值税方面，股息红利不征增值税（财税〔2016〕36号）。
❓ 听说合伙企业的核定征收取消了，我们持股平台现在该怎么交税？
  1. 自2022年1月1日起，持有股权等权益性投资的合伙企业一律实行查账征收（财政部 税务总局公告2021年第41号）。
  2. 沿用旧核定征收政策属违规，面临重大补税风险，应立即改为查账征收。
  3. 查账征收下，转让股权利得并入经营所得按5%–35%计算，需规范账务、留存成本与所得凭证。
  4. 优惠地平台还须满足实质性运营要求，避免被认定空壳。
❓ 员工离职我们要回购他的平台份额，这笔转让在税务上怎么处理？付款有什么要注意的？
  1. 员工退伙/转让平台份额，按“财产转让所得”缴20%个税，以转让收入减除原值和合理费用后的余额为计税依据。
  2. 须签订规范的回购协议，明确转让价格与付款路径，转让定价应公允，偏低可能被调整。
  3. 严禁私户收款，应通过对公账户走账并代扣代缴，否则触碰税务红线且难举证。
  4. 股权代持在税务上以名义股东为纳税人，争议时补税风险高，应确权并留存代持协议。

💡 整改建议：股权代持税务上以名义股东为纳税人，争议风险高，应尽量还原真实持股并办理工商确权，代持协议等资料需妥善留存备查。

💡 整改建议：平台与主体公司间的关联交易须定价公允并备齐同期资料；设在优惠地的平台应满足实质性运营要求，避免被否定优惠资格。
