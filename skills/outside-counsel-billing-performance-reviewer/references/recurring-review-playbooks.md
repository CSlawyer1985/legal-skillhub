# 定期审查预案

当用户希望本技能支持每月或每季度的定期法律运营工作流时，使用本参考。

## 月度发票审查
- 收集新发票、LEDES 文件以及更新的费率或预算文件
- 规范化源数据
- 运行合规、费率、人员配置和预算检查
- 生成争议日志和简明管理层摘要
- 按律所和事项类型识别重复问题标签

## 季度律所审查或 QBR
- 收集本季度至今的支出、预算、问题日志和事项元数据
- 比较各律所在合规、人员配置效率、可预测性和折扣实现方面的表现
- 生成记分卡和高管摘要
- 为下一季度确定律所名单管理跟进事项

## 年度费率审查
- 收集上年度和本年度的已批准费率文件
- 按计时人员、角色和办公室比较年度变化
- 分离职务变动和办公室变动
- 生成谈判要点和批准例外

## 自动化适配
如果用户需要月度发票审查提醒或计划性 QBR 准备，这些预案可很好地映射到定期的 Claude 或 Codex 自动化。
