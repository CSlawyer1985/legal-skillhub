# 视觉输出规则

在生成 PDF、Word 文档、PowerPoint 演示文稿或任何其他视觉格式化报告文件时，使用以下规则。

## 通用布局规则
- 不要让文本在表格列、标签或卡片之间重叠。
- 在所有正文单元格、表格单元格、标签和提示框中换行文本。
- 保持数字列窄且右对齐。
- 保持散文列灵活且顶部对齐。
- 如果表格会超出页面宽度，减少可见列数或改用卡片布局。
- 不要在 `Amount`（金额）、`Confidence`（置信度）或标签字段等窄列中放置长段落。
- 在视觉标签中使用短显示标签。原始分类学标识符仅保留给机器可读输出。

## 表格规则
- 涉及散文时，纵向 PDF 或 Word 布局优先使用不超过 5 个可见列。
- 汇总表仅用于短短语、数值和短标签。
- 将长描述、评估或理由移至：
  - 问题卡片；
  - 表格下方的说明；或
  - 横向附页表格。
- 所有表格单元格垂直顶部对齐。
- 允许行高随换行文本扩展。

## 标签与标记规则
- 如果文本无法舒适容纳，不要使用可见的胶囊式标签。
- 使用首字母大写的显示标签，如 `Block Billing`（整体计费）或 `Vague Narrative`（模糊叙述），而非长标识符字符串。
- 如果标签仍超出可用宽度，加宽标签区域或将类别渲染为纯文本而非胶囊。为此需求调整一个标签时，对其他标签作相同调整以保持一致。

## PDF 与 HTML 规则
- 优先使用卡片布局或带显式换行的固定布局表格。
- 应用以下 CSS 规则或其等效规则：
  - `table-layout: fixed`
  - `white-space: normal`
  - `overflow-wrap: anywhere`
  - `word-break: break-word`
  - `vertical-align: top`
- 使用一致的页边距和充裕的单元格内边距。
- 如果某部分包含问题叙述，使用堆叠的问题卡片而非非常宽的表格。

## Word 文档规则
- 使用简单、专业的表格，具有首选宽度并启用换行。
- 避免在 Word 导出中可能尴尬断行的装饰性胶囊。
- 使用清晰的章节标题、汇总表，以及用于长理由文本的问题卡片或小标题。
- 保持问题标签简短易读。

## PowerPoint 规则
- 不要在幻灯片上使用密集的电子表格式表格。
- 指标使用摘要幻灯片，叙述内容使用问题突出显示幻灯片。
- 每张幻灯片限制为少量换行的项目符号或卡片。
- 保持标签在演示尺寸下简短易读。

## 回退规则
如果视觉文件仍有溢出或尴尬换行的风险，简化布局。清晰的阅读性比保留密集表格更重要。
