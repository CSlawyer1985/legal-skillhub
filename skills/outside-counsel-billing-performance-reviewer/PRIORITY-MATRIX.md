# 优先级矩阵

## 1. 发票审批 / 争议准备
最高优先级：
1. 费率高于已批准水平
2. 缺失折扣 / 折扣误用
3. 被禁止的支出和附加费
4. 未经批准的计时人
5. 分块计费 / 模糊描述
6. 重复参加 / 过度内部会议
7. 与规则不符的 AI / 数据库 / 应用程序 / 技术工具费用
8. 与可疑计费相关的预算超支

## 2. 预算控制 / 预测
最高优先级：
1. 支出对预算
2. 阶段超支
3. 预测漂移
4. 人员扩张
5. 费率上调
6. 重复研究或起草返工
7. 成本动因分析

## 3. 供应商 / 律所绩效审查
最高优先级：
1. 人员配备效率
2. 预算可预测性
3. OCG 合规率
4. 描述质量 / 可批准性
5. 折扣实现
6. 费率竞争力
7. 案件执行效率
8. 关系及律师库影响

## 4. 总法律顾问 / 高管审查
最高优先级：
1. 整体支出轨迹
2. 重大合规问题
3. 人员配备与费率组合的合理性
4. 预算与季末风险
5. 律所价值 / 可预测性指标
6. 建议的行动

## 5. 采购 / 财务审查
最高优先级：
1. 商业条款合规
2. 已实现折扣
3. 费率治理
4. 发票卫生
5. 争议金额集中度
6. 重复问题类别
