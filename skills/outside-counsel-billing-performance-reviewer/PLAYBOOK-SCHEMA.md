# OCG / 计费规则模式
将 OCG 和计费规则标准化为此模式。

## 规则模式
- 规则 ID
- 来源文件及页码或章节
- 生效日期或期间
- 规则类别
- 规则摘要
- 适用范围
- 触发条件
- 硬性禁止 / 软性指引 / 需审批
- 阈值金额、时间或数量
- 相关职级 / 职衔
- 涉及的费率类型
- 支出或附加费类别
- 例外逻辑
- 所需证据
- 默认严重程度
- 建议的补救措施

## 标准规则类别
- 费率
- 折扣
- AFA / 上限 / 区间 / 混合费率
- 人员配备审批
- 差旅
- 餐饮 / 招待
- 研究
- 内部会议
- 行政 / 事务性工作
- 培训 / 入职
- 描述具体性
- 分块计费
- 重复参加
- 计费增量
- 支出 / 管理费用
- AI / 技术 / 数据库费用
- 发票准备时间
- 预算合规
- 案件编码 / 任务编码完整性
- 发票时点 / 提交节奏

## 解释规则
- 尽可能保留规则原文表述。
- 区分硬性禁止与需审批事项。
- 单独跟踪任何经协商的例外。
- 不要将律所特定或案件特定的例外过度泛化为一般规则。

## 计费事实模式
如可用，将发票或 LEDES 数据标准化为以下字段：
- 发票 ID
- 发票状态
- 发票日期
- 计费期间
- 货币
- 案件 ID 和案件类型
- 案件阶段或任务
- 行 ID
- 行类型：费用 / 支出 / 税费 / 贷项
- 计时人姓名
- 计时人职衔或职级
- 计时人办公室
- 计时人审批状态及生效日期
- 小时数或单位数
- 标准费率
- 已批准费率
- 已计费费率
- 净有效费率（如可推导）
- 已计费金额
- 调整后金额
- 已付金额（如已知）
- 折扣或核销金额
- UTBMS 或 LEDES 代码
- 描述文本
- 预算阶段或工作流

## 比较规则
- 尽可能按案件类型、阶段、法域和费用安排进行同类比较。
- 未说明局限之前，不得将计时收费案件与固定费案件比较。
- 将税费、增值税、汇率和转付型供应商成本与律师费比较分开。
