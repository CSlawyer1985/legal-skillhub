# 参考来源
本文件区分 3 个类别：
1. 可安全嵌入的公开/内部材料；
2. 用户提供的内部来源；
3. 仅限方法论、不得嵌入的商业来源。

## A. 可安全嵌入的公开 / 内部材料
如组织拥有使用这些材料的权利，可将其嵌入、摘要化或在技能中操作化使用。

### 1. 组织自有的内部材料
- 公司外部律师指导（OCG）
- 计费指引
- 已批准的费率表
- 折扣表
- AFA / 上限 / 区间条款
- 案件分类体系与任务分类体系
- 预算模板
- 应计 / 预测模板
- 内部审计检查清单
- 内部记分卡模板
- 历史发票导出与已批准的计费规则

### 2. 公开 / 开放 / 政府 / 标准类材料
在复用权利可接受且遵守署名规则时，将其用作安全的参考类别。

#### a. FDIC 外部律师手册及相关的电子计费指引
用于：
- 预算期望
- 案件计划概念
- 电子计费控制
- 发票校验逻辑
- 记录保留与计费治理概念

#### b. 得克萨斯州公共部门外部律师合同 / 计费指引材料
用于以下方向的示例：
- 外部律师计费控制
- 审批工作流
- 发票审查要求
- 人员配备 / 缔约护栏

#### c. USAO / Fitzpatrick 费用矩阵
仅用作：
- 方向性诉讼费率参考
- 不作为普遍的市场真理
- 不作为公司特定历史基准的替代品

#### d. LEDES 标准及相关计费数据标准资源
用于：
- 发票标准化
- 逐行提取设计
- 任务/活动代码对齐
- 电子计费工作流结构

## B. 用户提供的内部来源
这些应被视为本技能最强的来源。
- 上传的发票
- LEDES 文件
- 计费系统导出
- OCG PDF / DOCX / 政策文本
- 已批准的费率与折扣
- 委托函
- AFA / 费用上限 / 混合费率条款
- 按案件或阶段划分的预算
- 应计或预测文件
- 历史发票数据集
- 计时人名册
- 已批准的计时人名单及生效日期
- 案件元数据
- 以往的发票审查或争议结果
- 内部律师库记分卡
- 允许使用的多元性数据集

## C. 仅限方法论、不得嵌入的商业来源
这些来源可以塑造技能的方法论、受理问题、分析、指标和报告设计，但除非你与用户或组织确认其拥有明确的复用权利，否则其文本、专有表格或基准内容不得嵌入技能中。

除非用户拥有相关权利，否则仅将其用于外部参考，以指导技能设计。
示例包括：
- 专有的法律市场费率报告
- 专有的外部律师对标报告
- 商业法律支出调查报告
- 带限制性复用条款的供应商白皮书
- 含专有对标主张的受版权保护的博客文章
- 付费或会员专属的法律运营对标材料

## D. 来源使用的操作规则
始终按此顺序使用来源：
1. 用户提供的来源
2. 可安全嵌入的公开/内部材料
3. 受方法论指导的逻辑
4. 公开的方向性基准
5. 启发式估算

## E. 关键警示
公开可得并不自动意味着可复用或可安全嵌入。如复用权利不明，不要嵌入该内容。仅在技能外部用它来塑造方法论。
