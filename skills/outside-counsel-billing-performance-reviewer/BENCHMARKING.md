# 对标

## 要求的对标层级
按此顺序对标，一旦有足够强的比较对象即可停止：
1. 精确的内部历史类比；
2. 同一律所、同一案件类型、同一阶段的此前的同类工作；
3. 同类案件的同一部门平均值；
4. 已批准的预算或人员配备计划；
5. 公开的方向性基准；以及
6. 启发式估算。

绝不因为外部市场数据更易引用而跳过内部比较对象。

## 比较对象匹配规则
在数据允许的情况下，尽量匹配以下尽可能多的因素：
- 案件类型；
- 案件阶段或任务；
- 法律工作的复杂程度；
- 法域或审理地；
- 利害关系、敞口或交易规模；
- 紧迫性或事件驱动的时间安排；
- 文件数量、托管人或证据开示负担；
- 费用安排类型；
- 律所层级或专业化性质；以及
- 时间期间。

匹配越弱，置信度越低。
当比较对象的契合度存在争议时，在最终确定结论之前查阅 [references/matter-complexity-factors.md](references/matter-complexity-factors.md)。

## 案件类型特定信号
仅在分母实际可得时才使用单位式比较。

### 诉讼与调查
有用的分母可能包括：
- 起草的动议；
- 取证；
- 庭审或调解日；
- 当事人数量；
- 托管人数量；
- 文件量区间；以及
- 阶段特定支出。

### 商业合同与采购
有用的分母可能包括：
- 合同族或模板类型；
- 合同 / 协议起草；
- 谈判轮次；
- 协议复杂度区间；以及
- 周转预期。

### 公司、并购与尽调
有用的分母可能包括：
- 交易规模区间；
- 证券；
- 目标公司分析 / 尽职调查；
- 被收购公司的整合；
- 实体或法域数量；
- 所审查文件的数量；以及
- 阶段特定工作流。

### 劳动用工、监管、隐私与知识产权
有用的分母可能包括：
- 索赔数量；
- 申报或答复类型；
- 行政机关；
- 专利、商标或商业外观族数量；
- DPIA、PIA、DSAR 或隐私审计；
- 访谈数量；以及
- 调查或答复的范围。

## 外部方向性基准
仅将外部材料用作方向性语境。使用时，说明：
- 来源类型；
- 年份或期间；
- 地域或法域；
- 如已知，职级组合或资历假设；以及
- 该来源为何仅是方向性参考。

不得将公开基准材料用作公司特定历史、已批准商业条款或案件特定复杂度的替代品。

## 置信度降级规则
- 高置信度：范围相似、数据可靠的有力内部比较对象。
- 中置信度：有实质性局限但可用的内部比较对象，或高度相关的同律所历史。
- 低置信度：公开方向性基准、样本过薄、标准化不完整或启发式估算。

## 要求的对标叙述
每一项对标结论都应说明：
1. 比较了什么；
2. 为什么选择该比较对象；
3. 主要局限；以及
4. 结果属于规则违反、效率问题，还是仅为方向性观察。
