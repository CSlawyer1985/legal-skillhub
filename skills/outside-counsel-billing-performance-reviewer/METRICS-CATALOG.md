# 指标目录
仅使用所提供数据支持的指标。不得虚构缺失的分母。

## 1. 支出指标
- 已计费费用：扣除贷项之前律师及专业人员费用行的总和。
- 已计费支出：扣除税费之前费用及垫付行的总和。
- 税费或增值税：税行总和；与费用和支出分开列示。
- 已计费总价值：扣除贷项之前费用加支出加税费。
- 已计费净值：已计费总价值减去发票级贷项或核销（如显示）。
- 已审查总体价值：实际审查的发票或行所代表的价值。

## 2. 费率指标
- 标准费率：律所或计时人的未折扣参考费率（如提供）。
- 已批准费率：依 OCG、委托条款或费率文件由公司授权的费率。
- 已计费费率：发票或导出上显示的行费率。
- 净有效费率：扣除折扣或逐行核销后，净费用除以小时数。
- 已批准费率偏差：已计费费率减去已批准费率。
- 已批准费率偏差百分比：`（已计费费率 - 已批准费率）/ 已批准费率`。
- 同比费率变化：在比较对象有效的情况下，比较同一计时人或同一职级与办公室。

## 3. 折扣指标
- 约定折扣百分比：委托条款或费率表中承诺的折扣。
- 已实现折扣百分比：已知标准费率时，`（标准费率 - 净有效费率）/ 标准费率`。
- 折扣缺口：约定折扣百分比减去已实现折扣百分比。
- 发票级核销价值：已在发票或导出中反映的扣减。

## 4. 人员配备指标
- 合伙人小时占比：合伙人小时数除以总计费小时数。
- 合伙人费用占比：合伙人费用除以总费用价值。
- 计时人数量：案件或发票上计费的不同专业人员的数量。
- 人员集中度：前 1、3 或 5 名计时人所占小时或费用的份额。
- 多人参加活动数：在可识别的情况下，有多个计费人参加的会议、通话、听证或取证的数量。
- 审查层级数：在可识别的情况下，触及同一工作流的计费职级数量。

## 5. 合规与卫生指标
- OCG 合规率：合规行数除以可审查行数。
- 硬性规则违反数量与金额：与明确禁止或超出批准相关联的行。
- 需澄清的数量与金额：可能不合规但需要更多事实的行。
- 分块计费率：分块计费的行数除以可审查的费用行数。
- 描述充分率：描述足够具体的行数除以可审查行数。
- 重复参加率：可论证参加人数过多的活动数除以可审查的多人参加活动数。

## 6. 预算与预测指标
- 支出对预算比：同一范围的实际支出除以预算。
- 预算偏差：实际支出减去预算。
- 消耗率：每月、每季度、每阶段或其他已批准期间的支出。
- 期末预测：当前支出加上同一范围的预计剩余支出。
- 预测偏差：期末预测减去已批准预算。

## 7. 对标指标
- 比较对象费用中位数或均值：仅在说明比较对象总体时使用。
- 比较对象区间：仅在样本足够连贯、足以支撑时显示低到高区间。
- 与比较对象偏差：当前指标减去比较对象指标。
- 与比较对象偏差百分比：`（当前指标 - 比较对象指标）/ 比较对象指标`。

始终说明比较对象基准、样本量（如已知）以及比较对象相关的原因。

## 8. 价值框架
- 审查时已识别价值：与被标记问题相关的已计费总价值。
- 潜在节省：如质疑成立可能被削减的已识别价值部分。
- 已实现节省：实际被核销、调整、贷记或降低支付的金额。

绝不可将已识别价值或潜在节省呈现为已实现节省。
