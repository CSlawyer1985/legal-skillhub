# 与外部律师打交道时应注意什么

## 发票审查检查清单
- 已计费费率是否低于或等于已批准费率？
- 经协商的折扣是否实际适用？
- 标准费率、已批准费率、已计费费率和有效费率是否被正确区分？
- 是否有未经批准的计时人？
- 是否有被禁止的差旅、餐饮或管理费用？
- AI、数据库或工具费用在 OCG 下是否允许？
- 税费、增值税、转付型供应商费用和贷项是否与律师费分开处理？
- 是否有隐藏任务细节的分块计费条目？
- 描述是否足够具体以核验所完成的工作？
- 是否有过多律师或其他法律专业人员参加同一会议？
- 合伙人时间是否被用于本可授权他人的工作？
- 案件是否呈现超预算趋势？
- 研究时间是否与新颖性和利害关系成比例？
- 重复修订或重复研究是否造成可避免的支出？

## 通用成本节省提示
- 要求按阶段编制案件预算；
- 要求人员配备计划并对新增计时人进行审批；
- 强制描述具体化；
- 对研究密集型任务设上限或预先审批；
- 质疑重复的内部会议；
- 在适当的情况下将常规工作下放至成本更低的职级；
- 每季度审计折扣实现情况；
- 每年明确审查费率上调；
- 对可预测的重复性工作考虑上限费或 AFA；以及
- 在分配新案件前跨律所比较同类工作。

## 按上传数据定制的节省提示
根据上传的数据量身定制，例如：
- 减少常规文件提交上的合伙人审查环节；
- 对重复性问题的法律研究设上限，除非预先批准；
- 限制常规通话的多人律师参加；
- 将文件提交 / 引注核查 / 常规案件管理移交给律师助理；
- 在当前有效费率超过以往可比案件时，重新谈判费率上调或强制执行折扣实现；以及
- 在升级商业讨论或谈判之前，将有争议的金额与已保证的节省分开。
