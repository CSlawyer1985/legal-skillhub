# 合同审查 Skill — 安装与配置指南

## 快速开始

1. 将整个 `contract-review/` 文件夹安装到您的 Skill 目录
2. 根据下方说明配置 references/ 中的参考文件
3. 上传合同文件，Skill 自动触发

---

## 目录结构

```
contract-review/
├── SKILL.md                          # 主 Skill 文件（核心逻辑）
├── README.md                         # 本文件（安装说明）
└── references/                       # 参考资料库（用户自行维护）
    ├── legal-kb.md                   # 法律法规知识库 ← 需要配置
    ├── risk-rules.md                 # 风险扫描规则库 ← 需要配置
    ├── review-checklist.md           # 合同审查要点知识库 ← 需要配置
    ├── client-preferences.md         # 我方客户习惯偏好 ← 需要配置
    └── lawyer-tips.md                # 律师个人审查经验 ← 需要配置
```

---

## 参考文件配置说明

### 必须配置的文件

| 文件 | 配置内容 | 优先级 |
|------|---------|-------|
| `legal-kb.md` | 更新最新司法解释、补充行业法规、填写地方性规范 | 高 |
| `risk-rules.md` | 调整风险等级阈值、添加行业特定规则 | 高 |
| `client-preferences.md` | 为每个客户填写偏好条目 | 中 |
| `lawyer-tips.md` | 填写个人审查风格和经验技巧 | 中 |
| `review-checklist.md` | 补充行业专项审查要点 | 低（已有基础内容） |

### 最低配置（快速启用）

如果想快速启用，至少完成：
1. 在 `legal-kb.md` 第8节填写您常见的行业法规
2. 在 `client-preferences.md` 为主要客户建立条目
3. 在 `lawyer-tips.md` 填写您的审查风格偏好

## 使用方式

### 标准使用

直接上传合同文件，Skill 自动：
1. 检查文件格式可读性
2. 向您收集审查立场、目的等信息
3. 执行三层审查（合法性→风险→形式）
4. 整合输出完整审查报告
5. 进行经验沉淀对话

### 自定义规则

在 `risk-rules.md` 中添加自定义规则：
```yaml
规则ID: CUSTOM-001
名称: [您的规则名称]
触发条件: [描述何时触发]
风险等级: RED/YELLOW/BLUE
修改建议: [建议措辞]
```

### 知识库更新

通过以下两种方式持续更新知识库：
1. **手动更新**：直接编辑 references/ 中的 .md 文件
2. **通过 Skill 更新**：每次审查结束后，在模块 F 对话中告诉 Agent 需要更新的内容，Agent 会生成更新后的文件内容

## 注意事项

- 本 Skill 为律师/法务专业工具，输出结果需由执业律师审核确认
- 参考文件越完善，审查质量越高
- 建议每季度检查一次法律法规知识库，确保法条时效性
- `lawyer-tips.md` 是个人经验积累的核心，坚持通过模块 F 更新
