## 8. 管理咨询/劳务外包类合同专项经验

> 本节来源于实际审查管理咨询服务协议（含类似驻场外包合同）的经验积累。

### 8.1 第一眼要看的三件事

审查此类合同，拿到文件后优先看这三处：

```
① 第一眼：服务费计算公式
   → 收入分成型？固定费用型？工时计费型？
   → 收入分成型 = 高风险，须深度拆解（见 review-checklist 3.6节）

② 第二眼：甲方解除权条款
   → 解除条件数量多、标准主观、无预告期 = 乙方处于弱势
   → 数数有几个解除触发条件，条件越多越不利

③ 第三眼：劳动争议责任条款
   → 是否所有员工争议"无论原因"都由乙方承担？
   → 是否允许甲方直接从服务费扣款（无需确认）？
```

### 8.2 服务费公式审查口诀

**"三问一算"法**：
```
问1：基数谁说了算？（甲方单方 → 高风险）
问2：乙方能不能查？（有无核查权 → 无则高风险）
问3：负值怎么办？  （乙方补款 → 必须修改）
算：  压力测试计算 → 收入下降30%时乙方实际净收入是多少？
      若为负值，合同对乙方存在存亡级风险
```

### 8.3 合同性质定性的实操判断

**"三看"定性法**（判断是外包还是派遣）：
```
一看谁发工资：乙方发（钱路在乙方）→ 倾向外包
              甲方直接发 → 高度疑似派遣

二看谁管考勤：甲方系统打卡、甲方管考勤 → 倾向派遣
              乙方自行记录、甲方只看结果 → 倾向外包

三看谁定绩效：甲方出绩效标准+甲方直接打分 → 高度疑似派遣
              乙方内部绩效体系，甲方仅验收服务成果 → 倾向外包
```

**实务提示**：名称为"管理咨询"但三看结论为"派遣"时，
须提醒客户核查乙方《劳务派遣经营许可证》，
同时评估甲方的共同用工法律风险。

### 8.4 谈判重点和让步策略

**如代表乙方（服务方）谈判**：

必须坚守的底线（按优先级）：
1. 服务费计算基数须有核查权 → 这是最核心的利益保障
2. 负值补款义务须删除 → 否则乙方面临无限经营风险
3. 甲方解除须有预告期+补偿 → 保护人员安置时间
4. 劳动争议须区分责任归属 → 避免为甲方行为买单

可以让步的方向：
- 报告频率和格式（行政性要求）
- 部分考核指标（可接受，但须约定申诉机制）
- 保密期限（在合理范围内可延长）

**如代表甲方（发包方）谈判**：

重点确保：
1. 服务内容清单须具体（"包括但不限于"须有核心清单托底）
2. 考核标准须客观（以便行使解除权时有依据）
3. 信息安全责任须落实到位（含乙方员工离职后义务）
4. 人员替换程序须明确（关键岗位须提前通知+交接）

### 8.5 此类合同的新法律服务机会识别

每次审查完此类合同后，主动评估：
- 客户是否需要**员工手册合规审查**（甲方制度文件）
- 是否需要**劳务派遣资质核查**服务
- 是否需要**批量劳动合同合规审查**（乙方与其人员的劳动合同）
- 是否存在**历史劳动争议隐患排查**需求
- 是否存在**供应商合规尽调**需求（核查乙方经营状况）

### 8.6 实战案例提示（2026年4月补充）

> 来源：甲：京北方信息技术股份有限公司 / 乙：北京小时领先科技有限公司《管理咨询服务协议》中立审查

**典型高危条款组合（合同若同时出现以下3条，即为极高风险）**：

```
① 服务费 = （收入×90% - 人力成本）× 1.06，基数由甲方单方认定
② 服务费为负值时乙方向甲方补款
③ 所有员工争议由乙方全额承担，甲方可直接从服务费扣除

以上三条同时出现 = 乙方实质是"无底薪、兜底亏损、连带无限责任"的高风险合作方，
极端情形下乙方非但没有收入，还需向甲方大额倒贴，同时应对全部劳动仲裁。
应建议客户拒绝签署，或要求全面修改上述三条后再谈。
```

**背靠背付款+人力外包的特定压力测试方法**：

```
Step 1：计算盈亏平衡点
  盈亏平衡时：（收入×90% - 人力成本）= 0
  即 收入 = 人力成本 ÷ 0.9
  若月度人力成本为 X 万元，则月收入须超过 X/0.9 万元才能有正收益

Step 2：压力测试
  如果客户方延迟付款3个月，乙方需垫付 3X 万元工资
  如果客户方扣款20%，乙方实际收费减少（收入×90%×0.8 - 人力成本），
  大概率进入负值，乙方还须向甲方补款

Step 3：结论
  如压力测试下乙方可能面临六位数以上亏损，
  合同条款风险已超出一般商业风险范畴，属于结构性不公平。
```

**"三无合同"识别口诀**（审查立即终止谈判的预警信号）：

```
无核查权（无法验证收入数据）
无底价保证（服务费可降至零甚至负数）
无责任分担（所有风险均由一方承担）

三无同时出现 → 建议不签
两无同时出现 → 谨慎，需逐条谈判
一无           → 中等风险，可谈判修改
```
