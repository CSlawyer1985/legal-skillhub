## 1. 审查前置判断

在进入实质审查前，先回答以下问题，有助于确定审查侧重点：

**关于交易性质**：
- 这是一次性交易还是持续合作关系？
  - 一次性 → 侧重付款保障、交付验收、违约责任
  - 持续合作 → 侧重关系管理、调价机制、退出条款
- 合同金额大小？
  - 大额 → 所有条款深度审查
  - 小额 → 聚焦核心条款（付款/违约/争议）

**关于双方关系**：
- 己方是强势方还是弱势方？
  - 强势方 → 有谈判空间，尽量争取有利条款
  - 弱势方 → 识别底线，重点排除高风险条款
- 是否为格式合同？
  - 是 → 重点检查格式条款效力，识别不公平条款
  - 否 → 全文审查，关注谈判遗漏点

### 2.2 常见遗漏条款清单

以下条款常被遗漏，但实践中争议频发：
- **发票条款**：发票类型、开具时间、税点
- **通知条款**：通知方式（邮件/快递/公告）和送达生效时间
- **不可抗力通知程序**：不可抗力发生后的通知义务和期限
- **保险条款**（建工/物流类合同）
- **合同变更程序**：口头修改的效力明确（通常约定无效）
- **整体合同条款**：本合同构成双方完整约定，取代此前所有沟通

## 3. 各类合同专项审查要点

### 3.1 买卖合同

**重点审查**：
- 货物描述是否精确（规格/型号/标准/产地）
- 验收标准是否客观可量化
- 质保期及质保责任
- 货物风险转移时间点（发货/到货/验收）
- 货物不符合约定时的处理：退货/换货/减价/赔偿

**常见陷阱**：
- "符合国家标准"——国标可能有多个，需指定具体标准编号
- 验收期不明确——可能导致"默示接受"风险
- 包装要求未约定——运输损坏责任不清

### 3.2 服务合同

**重点审查**：
- 服务内容描述是否足够具体（交付物清单）
- 验收标准（主观性服务如何客观验收？）
- 服务人员要求（资质/替换程序）
- 知识产权归属
- 分包是否允许

**常见陷阱**：
- 服务范围"蔓延"——原合同范围外的工作如何计费
- 甲方配合义务不明——甲方延误是否影响乙方工期
- 验收拖延处理——甲方不验收不付款的情形

### 3.3 技术开发合同

**重点审查**：
- 研发目标和技术指标（客观可验证）
- 中间成果归属
- 技术风险分配（研发失败如何处理）
- 知识产权归属（特别是职务发明与委托开发的区别）
- 保密义务与竞业限制

### 3.4 租赁合同

**重点审查**：
- 租赁物状态（交付时的现状描述，建议附照片/视频）
- 装修权利与恢复义务
- 转租权
- 维修责任划分（自然损耗 vs 人为损坏）
- 续租优先权
- 提前解约违约金计算

### 3.5 工程建设合同

**重点审查**：
- 工程范围及设计变更程序
- 工期延误责任（含甲方配合义务）
- 质量标准与验收程序
- 工程款支付节点（进度款/竣工款/质保金）
- 优先受偿权

### 3.6 管理咨询/劳务外包/驻场服务合同

> 本类合同的核心挑战：**合同性质定性**、**费用计算透明度**、**用工责任边界**。
> 典型合同结构：甲方（发包方/用人单位）委托乙方（服务方）管理并提供驻场人员，
> 按照甲方的业务收入或固定金额支付服务费。

**第一步：合同性质定性审查**

在实质审查前，必须首先判断合同的法律性质：

```
问题1：乙方提供的是"人"还是"服务成果"？
  → 提供"人"（人员在甲方工作场所，接受甲方指挥）= 接近劳务派遣
  → 提供"服务成果"（乙方独立完成，对结果负责）= 真正的服务外包

问题2：甲方是否直接管理乙方人员？
  → 甲方制定考勤制度、绩效标准、奖惩规则 → 用工主体特征显著
  → 乙方自主管理人员，甲方只验收结果 → 真正外包

问题3：合同名称与实质是否一致？
  → 名为"管理咨询"但实为人员供给 → 劳务派遣风险！
```

**核心条款审查要点**：

| 条款 | 审查要点 | 高频风险 |
|------|---------|---------|
| 服务内容 | 服务边界是否清晰，乙方义务范围是否合理 | 义务范围过宽（"包括但不限于"无边界） |
| 服务费计算 | 计算公式是否透明，基数数据乙方能否核查 | 完全依赖甲方单方数据，无核查权 |
| 人员管理权 | 谁拥有实质管理权（考勤/绩效/奖惩） | 甲方直接管理人员→劳务派遣认定风险 |
| 劳动争议责任 | 争议是否按责任归属分担 | 全部转移乙方，包括甲方原因引发的 |
| 解除条件 | 甲方解除权是否过宽、有无预告期 | 立即解除+无补偿，乙方人员安置困难 |
| 人员转移 | 合同期满/终止时人员如何处理 | 无约定导致人员安置争议 |

**必须核查的资质文件**：
- [ ] 乙方营业执照经营范围是否包含"人力资源服务"或"劳务派遣"
- [ ] 若实质为劳务派遣：乙方《劳务派遣经营许可证》（有效期/范围）
- [ ] 若涉及人员社保缴纳：乙方是否具备在项目所在地缴纳社保的资质
- [ ] 甲方是否上市公司或国企：可能涉及合规披露或特殊审批要求

**服务费公式的拆解审查**：

针对"收入分成型"服务费公式（如本案合同第七条），须逐一拆解：

```
1. 收入基数：
   - "甲方已实际收到的收入"——实收还是应收？收款延迟对乙方的影响？
   - 收入的范围：是否包含全部业务收入，还是仅部分项目？
   - 核查权：乙方能否查看对应合同/发票/流水？

2. 折扣系数（×90%）：
   - 10%扣减的依据是什么？是覆盖甲方管理成本吗？
   - 是否应书面约定用途，避免未来争议？

3. 人力成本扣除：
   - 人员清单由谁确定？变更程序是什么？
   - 社保基数是否合理？公积金比例是否按法定最低？
   - 绩效/奖金是否在扣除范围内？上限是多少？

4. 税金处理（×1.06）：
   - 确认乙方纳税人身份与适用税率
   - 差额征税选项是否考虑（劳务派遣服务适用）

5. 负值补款义务：
   - 乙方是否有能力承担无上限的补款义务？
   - 这是否实质上让乙方承担了甲方的经营风险？
```

**劳动关系风险防范清单**：
- [ ] 合同中是否有"乙方人员与甲方不存在劳动关系"的明确约定
- [ ] 乙方是否与其人员签署劳动合同并缴纳社保
- [ ] 甲方制度适用范围：仅规范工作流程/场所秩序，还是直接管控劳动关系
- [ ] 乙方是否有应急预案（人员突然离职/罢工/生病导致服务中断）
- [ ] 合同解除时人员安置方案是否有预先约定

**历史高频争议点**：
1. 甲方收入确认时间争议（甲方故意延迟确认，压低当期服务费）
2. 人力成本计算口径争议（绩效奖金是否计入扣除项）
3. 合同解除后未结算服务费追讨困难
4. 员工劳动仲裁裁决后责任归属争议（甲方vs乙方）
5. 信息安全事故责任认定（甲方制度不完善 vs 乙方员工操作失误）

## 4. 常见陷阱与历史教训

> 本节积累实践中发现的合同陷阱，审查时主动检索。

### 陷阱 T-001：看似对等实为单方权利
```
表现：合同文本使用"双方均可…"的表述，但实际只有一方在商业上会使用该权利
例子："任何一方均可提前30天书面通知解除合同"——
      实际上规模大的一方（通常是甲方）随时可以解除，对乙方影响极大
建议：区分"名义上对等"和"实质上对等"，从业务逻辑判断真实影响
```

### 陷阱 T-002：数字黑洞
```
表现：合同中出现百分比但未约定计算基数
例子："按照合同金额的10%支付违约金"——合同金额是含税还是不含税？年金额还是月金额？
建议：所有百分比条款均明确计算基数和计算方式
```

### 陷阱 T-003：时间起算点不明
```
表现：约定了天数但未约定起算点
例子："乙方应在30日内完成交付"——30日从何时起算？签约日？收到预付款？收到需求文件？
建议：所有期限均明确起算事件和起算点
```

### 陷阱 T-004：附件凌驾正文
```
表现：正文声明"附件与正文冲突以附件为准"，而附件中有大量有利于起草方的条款
建议：检查所有冲突解决条款，通常应约定以正文为准；仔细审查附件内容
```

### 陷阱 T-005：收入分成型服务费的"收入延迟确认"陷阱（外包类合同特有）
```
表现：服务费 = f(甲方收到的收入)，但甲方对"收到"的时间点有控制权
例子：甲方客户当月付款，但甲方以"对账未完成"为由推迟3个月确认，
      导致乙方当月服务费为零或极低，乙方却需按时支付工资社保。
      累积数月后乙方现金流断裂。
建议：增加"甲方有义务及时告知收款情况"的时间约束（如收款后3日内书面通知）；
      增加乙方有权查阅甲方对应项目收款凭证的权利；
      约定甲方逾期通知的违约责任。
```

### 陷阱 T-006：服务费负值时的无限补款义务
```
表现："服务费为负值时乙方按通知补足"
背景：乙方人力成本固定（工资社保必须按月支付），但甲方收入可能为零；
      乙方不仅无收入，还需向甲方补款，无上限。
建议：此条款应强烈要求删除；若甲方坚持，至少设置年度负值补款上限，
      并约定持续亏损超过[X]个月时乙方有权解除合同无需赔偿。
```

### 陷阱 T-007："立即解除"叠加"全额赔偿"的连环炸弹
```
表现：甲方可以"立即"解除合同，同时约定乙方须赔偿甲方"一切损失"。
      乙方人员安置需要时间，立即解除意味着乙方须同时承担：
      ①已付但未服务期间的退款义务
      ②人员遣散的经济补偿金
      ③甲方主张的运营损失赔偿
建议：解除前增加合理预告期（30-60个工作日）；
      解除后损失赔偿范围明确排除甲方"因解除合同而产生的运营损失"；
      经济补偿金的承担应与解除原因挂钩（甲方原因解除则甲方承担）。
```

## 5. 谈判策略提示

> 审查完成后，律师可参考以下策略建议。

### 5.1 开场定位策略
- 若己方为弱势方：优先列出红色风险点，聚焦必须修改的底线，黄色蓝色先搁置
- 若己方为强势方：提出全面修改意见，用蓝色/黄色项目为红色项目的让步留出空间

### 5.2 条款打包谈判
- 将相关联的条款打包谈判（如：违约金↔不可抗力↔免责条款）
- 在一个方向让步时，在关联条款上争取对等补偿

### 5.3 常见可接受替代方案
| 己方诉求 | 对方可能接受的替代 |
|---------|-----------------|
| 提高违约金 | 增加违约通知+整改期 |
| 改变诉讼地 | 改为中立仲裁机构 |
| 限制保密范围 | 增加保密期限上限 |
