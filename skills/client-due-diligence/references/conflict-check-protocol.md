# 利益冲突审查协议（Conflict Check Protocol）

> **承接前的强制门槛**。8 项自查任一"是"且无书面豁免，报告结论强制置为"禁止承接"，风险等级强制标红。

---

## 8 项自查清单

| # | 审查事项 | 判断 |
|---|---|---|
| 1 | 本所是否曾或正在代理目标公司 | 是 / 否 |
| 2 | 本所是否曾或正在代理其债权人（含金融债权人、供应商） | 是 / 否 |
| 3 | 本所是否曾或正在代理其竞争对手 | 是 / 否 |
| 4 | 本所是否曾或正在代理其股东、实际控制人 | 是 / 否 |
| 5 | 本所是否与临时管理人（清算组）及其成员单位存在关联或代理关系 | 是 / 否 |
| 6 | 本所是否曾或正在代理其他重整参与方（投资人、出资人等） | 是 / 否 |
| 7 | 本所律师是否存在与公司或相关方的个人利害关系 | 是 / 否 |
| 8 | 是否存在其他可能影响独立、客观履职的情形 | 是 / 否 |

## 阻断规则（Hard Rule R8）

- **任一项 = "是" 且 `waiver = false`（无书面豁免）** → 报告结论 = "禁止承接"，风险等级 = "红（冲突待决）"，正文不输出任何承接建议
- **任一项 = "是" 且 `waiver = true`（已书面豁免）** → 可继续，但须在报告显著位置标注"存在利益冲突，已取得书面豁免"
- **全部 = "否"** → 通过，正常输出承接建议

## 承接前强制动作（缺一不可）

1. 由本所风控部门完成书面利益冲突审查并留痕
2. 调取本所案件台账，逐条比对目标公司 337 件被告案件相对方
3. 书面豁免须经合伙人签字，存档备查

## 输出格式（利益冲突审查表）

| 序号 | 审查事项 | 是否存在 | 说明/豁免状态 |
|---|---|---|---|
| 1-8 | ... | 是/否 | 有书面豁免 / 无 |

## 与报告结论的联动

| 冲突状态 | 报告结论 | 风险等级 |
|---|---|---|
| 全部"否" | 正常承接评估 | 按 9 维度评分 |
| 有"是"+已豁免 | 有条件承接（标注冲突） | 按评分，加"冲突已豁免"标注 |
| 有"是"+未豁免 | **禁止承接** | **红（冲突待决）** |
