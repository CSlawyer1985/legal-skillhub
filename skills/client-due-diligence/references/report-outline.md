# 主报告章节结构（O1 - .docx）

> 主报告排版规范：封面 + 目录 + 正文（含数据对齐基准表 + 风险评级 + 法律顾问切入备忘录）。标题 1-3 级、表格边框、页眉页脚、页码。

---

## 封面页

- 律所名称（居中，加粗，二号）
- 客户背调报告（居中，一号加粗）
- 公司全称 + 证券简称/代码（居中）
- 报告编号 / 出具日期 / 项目主办律师
- 密级提示：内部文件 · 仅供承接决策 · 禁止对外提供

## 目录页

## 第一节 报告说明与方法

1. 委托背景与目的（谈客户/接法律顾问的前置背调）
2. 核查范围与期间
3. 信息源与核查方法（MCP + 权威源，屏蔽非权威）
4. 局限性声明

## 第二节 主体识别（工商登记与画像）

1. 工商登记基本信息表（含统一信用代码、法人、注册资本、成立日期、登记状态、经营范围）
2. 经营资质与荣誉
3. 上市基本信息（如适用）
4. **主体资格判断**

## 第三节 数据对齐基准表（★核心）

- 关键字段：统一信用代码、法定代表人、成立日期、实控人持股、净资产、财务数据等
- 每个字段：权威基准值 + 来源 + 时点 + 冲突说明
- 冲突字段标注"待核实"

## 第四节 股权结构与公司治理

1. 前十大股东表
2. 实际控制人与受益所有人
3. 董监高名单
4. 治理关注点（法人变更、高管异动、内控）

## 第五节 财务与资信

1. 关键财务指标（近三年 + 一期）
2. 审计意见与审计机构异动
3. 偿债能力与支付能力判断

## 第六节 风险扫描

1. 司法与执行风险（涉诉/被执行/失信/限高）
2. 破产与预重整风险（如适用）
3. 行政监管与合规风险（立案/处分/处罚）
4. 经营与退市风险
5. 舆情与声誉风险

## 第七节 综合风险评估

1. 9 维度风险评分矩阵
2. 风险等级（绿/黄/红）
3. 重大风险事项摘要 TOP 5

## 第八节 法律顾问切入备忘录（★核心）

按 `assets/memo-template.md`：
1. 切入话术（针对核心风险）
2. 需求矩阵（应急刚需 → 专项 → 常法分层）
3. 首见问题清单（经营/治理/风险/规划四组）
4. 服务角色定位与收费结构建议

## 第九节 承接建议与风险缓释

1. 客户分级建议
2. 服务合同关键条款建议
3. 持续监控要点

## 第十节 利益冲突审查结论

- 8 项自查结果
- 结论：可承接 / 有条件承接 / 禁止承接

## 第十一节 待核实事项清单

- 数据冲突、单源、无源事项汇总

## 第十二节 免责声明

固定段落（来源声明 + 不构成法律意见 + 保密提示）
