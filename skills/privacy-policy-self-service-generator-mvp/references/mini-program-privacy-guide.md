# 小程序渠道 MVP 检查

仅在产品包含微信小程序或其他小程序渠道时使用。不得复制平台示例话术或平台化章节结构。

## 最小字段

| 项目 | 需要确认 |
| --- | --- |
| 小程序范围 | 名称、所属平台、主体、与 App/网站关系 |
| 接口和组件 | 实际调用的接口、组件、权限能力和触发场景 |
| 个人信息 | 每个接口涉及的位置、手机号、头像昵称、照片视频、文件等 |
| 必要性 | 是否为核心功能必需，拒绝后的影响 |
| 插件和服务商 | 插件、云服务、内容审核、客服、支付、统计分析 |
| 权利路径 | 产品内路径、平台授权管理路径、企业联系渠道 |
| 保存更新 | 保存期限、删除条件、生效日期、更新日期 |

## 复查重点

- 小程序接口和个人信息类型是否一一对应。
- 平台授权管理路径不能替代企业自己的用户权利响应机制。
- 不得保留平台示例中的开发者信息、接口能力或固定话术。
