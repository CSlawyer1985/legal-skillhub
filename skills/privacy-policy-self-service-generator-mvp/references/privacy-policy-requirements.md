# 隐私协议 MVP 要求清单

用于生成和复查 MVP / 最小合规版隐私协议。缺少核心项时，应先追问或列为阻断问题。

## 必备章节

MVP 版本至少覆盖：

- 发布主体和适用范围；
- 摘要；
- 收集和使用个人信息规则；
- 第三方 SDK、API、插件和合作方；
- 委托处理、对外提供、公开披露和跨境；
- 个人信息安全措施；
- 用户权利路径；
- 存储期限和地域；
- 未成年人保护；
- 隐私协议更新和展示；
- 联系方式和争议解决。

## 最小事实要求

| 模块 | 最小要求 |
| --- | --- |
| 主体 | 个人信息处理者名称、联系方式、产品范围 |
| 用户 | 适用用户类型，是否可能涉及未成年人 |
| 功能 | 按核心功能列明收集的个人信息 |
| 必要性 | 区分必要和非必要个人信息 |
| 拒绝影响 | 非必要信息应说明拒绝后的影响 |
| 保存期限 | 写明期限或期限确定方法 |
| 第三方 | 明确是否存在，存在时列明名称/类别、目的、信息类型 |
| 权利路径 | 查询、更正、删除、撤回同意、注销、投诉 |
| 跨境 | 明确是否存在跨境传输或境外访问 |

## 高风险事项

出现以下情形时，MVP 版也不能只写笼统条款：

- 敏感个人信息；
- 未成年人；
- AI 训练或模型优化；
- 自动化决策或个性化推荐；
- 第三方 SDK；
- 对外提供、公开披露、委托处理；
- 跨境传输或境外访问；
- 长期保存或删除路径不清。

## 发布和可视化

MVP 协议应说明首次提示方式、长期访问入口、更新通知方式和历史版本入口。多端产品应说明各端入口。
