# 常见法律误区纠正

> 收录普通人常见的法律误解。当用户在对话中暴露这些误区时，主动纠正并说明正确法律规则。

---

## 一、劳动法常见误区

| 误区 | 真相 |
|------|------|
| ❌ "试用期公司可以随时开掉我" | ✅ 《劳动合同法》第21条：试用期解除必须证明"不符合录用条件"，且录用条件须在入职时明确告知。 |
| ❌ "没签劳动合同就没劳动关系" | ✅ 劳动关系自实际用工之日起成立。没签合同的话，满1个月不满1年可主张双倍工资（最多11个月）。 |
| ❌ "被辞退一定能拿N+1" | ✅ N+1只适用于特定情形。违法解除拿2N，主动辞职拿0，不同情形对应不同标准。 |
| ❌ "996给了加班费就合法" | ✅ 每月加班不得超过36小时（《劳动法》第41条），即使给了加班费，超时加班本身违法。 |
| ❌ "竞业限制不给钱也得遵守" | ✅ 竞业限制必须给补偿金（离职前12个月均工资30%）。3个月不付补偿金，劳动者可主张解除竞业限制。 |
| ❌ "公司可以随便调岗降薪" | ✅ 变更劳动合同需协商一致并书面确认（《劳动合同法》第35条）。单方调岗降薪属于变相逼迫离职。 |
| ❌ "年休假不休就作废了" | ✅ 未休年假，公司应按日工资的300%支付报酬。作废条款无效。 |

## 二、消费/买卖常见误区

| 误区 | 真相 |
|------|------|
| ❌ "没发票就不能维权" | ✅ 收据、转账记录、聊天记录、刷卡记录等都可作为消费凭证。 |
| ❌ "网购一概七天无理由退" | ✅ 定制商品、生鲜易腐、数字化商品等不适用七天无理由（《消法》第25条）。 |
| ❌ "定金都不能退" | ✅ "定金"（担保性质）不退，"订金"（预付款性质）可退。二字不同，结果天差地别。 |
| ❌ "打折商品不退不换" | ✅ 格式条款声明"特价商品不退不换"属于无效格式条款（霸王条款），除非是真·瑕疵品且明示。 |
| ❌ "买到假货只能退货退款" | ✅ "退一赔三"（《消法》第55条），食品领域"退一赔十"（《食安法》第148条）。 |

## 三、租房常见误区

| 误区 | 真相 |
|------|------|
| ❌ "房东不修东西我就不交房租" | ✅ 不完全对。可以催告房东修、自行修后向房东报销。暂停支付租金可以行使同时履行抗辩权，但不是无限期不交。 |
| ❌ "房东随时可以涨房租" | ✅ 合同期内不能单方涨房租。续租时涨房租需协商，上涨幅度各地有限制政策。 |
| ❌ "房东可以随时让我搬走" | ✅ 合同期内房东无权单方收回房屋。"买卖不破租赁"——房东卖房不影响你的租约。 |

## 四、交通事故常见误区

| 误区 | 真相 |
|------|------|
| ❌ "私了了就不能再追究" | ✅ 如果事后发现伤情严重（如后续诊断出内伤），可以撤销之前的私了协议并重新主张。 |
| ❌ "对方全责就什么都赔" | ✅ 赔偿限于法定项目和合理金额，不是"想赔多少赔多少"。 |
| ❌ "没报警就不能理赔" | ✅ 有照片、行车记录仪、双方确认记录等证据也可理赔，但报警拿《认定书》是最稳妥的。 |

## 五、婚姻家庭常见误区 ⚠️

| 误区 | 真相 |
|------|------|
| ❌ "分居满两年就自动离婚了" | ✅ 中国法律没有"自动离婚"。分居满2年是诉讼离婚时认定感情破裂的法定情形之一，仍需通过民政局或法院办理。 |
| ❌ "谁出轨谁净身出户" | ✅ 出轨方分割财产可能少分，但不会"净身出户"。过错方可主张离婚损害赔偿（《民法典》第1091条）。 |
| ❌ "离婚后孩子一定归妈妈" | ✅ 2周岁以下原则上随母亲；2-8周岁考虑最有利于未成年人原则；8周岁以上尊重孩子意愿。不是绝对归妈妈。 |
| ❌ "嫁妆是女方个人财产" | ✅ 婚前给的嫁妆一般属女方个人财产；婚后给的嫁妆，没有特别说明的一般视为夫妻共同财产。 |
| ❌ "家暴只是家务事" | ✅ 家暴是违法行为，可报警、验伤、申请人身安全保护令、起诉离婚并主张损害赔偿。 |

## 六、借贷常见误区

| 误区 | 真相 |
|------|------|
| ❌ "借条和欠条是一回事" | ✅ 借条 = 借贷关系（借钱），欠条 = 欠款关系（可能是货款等）。诉讼时效计算方式不同。 |
| ❌ "只要利息不太高就合法" | ✅ 民间借贷利率上限为LPR的4倍（目前约13%-14%/年），超出部分法院不支持。 |
| ❌ "有转账记录就能证明是借款" | ✅ 还需要证明有"借贷合意"（双方商量好是借款而非赠与或投资）。 |
| ❌ "帮朋友担保就是签个字" | ✅ 担保人对债务承担连带还款责任。别人不还，你要替他还。 |

## 七、新场景常见误区

### 医疗纠纷
| 误区 | 真相 |
|------|------|
| ❌ "医生没治好就是医疗事故" | ✅ 医疗事故需证明医疗机构有过错且该过错与损害有因果关系。医学有局限性，不良结果不等于医疗事故。 |
| ❌ "必须做了医疗鉴定才能告医院" | ✅ 可以先封存病历、收集证据，起诉后由法院委托鉴定。也可先向卫健委投诉。 |

### 教育培训
| 误区 | 真相 |
|------|------|
| ❌ ""包过班"不过就全退肯定能退" | ✅ 很多合同中写的是"可免费重读一次"而非"退全款"。签合同前要看清楚是"退费"还是"重读"。 |
| ❌ "培训机构跑路了就没办法了" | ✅ 可以联合其他受害者集体维权、向教育局举报、向公安机关报案（可能涉及合同诈骗）。 |

### 保险理赔
| 误区 | 真相 |
|------|------|
| ❌ "保险公司说不赔就真的赔不了" | ✅ 保险公司拒赔需出具书面拒赔通知书说明理由。不服可向银保监会12378投诉，或诉讼。 |
| ❌ "买保险时没如实告知，出事了保险公司一定不赔" | ✅ 投保人故意不告知的才可以拒赔；重大过失未告知，看该事实对保险事故是否有重大影响。 |

### 预付卡/预付费
| 误区 | 真相 |
|------|------|
| ❌ "充值卡没用完商家跑路只能自认倒霉" | ✅ 可向12315投诉、商务局举报。店家明显以非法占有为目的卷款跑路的，可能构成合同诈骗罪。 |
| ❌ "充值的钱和消费时一个价" | ✅ 预付式消费受《消法》和《单用途商业预付卡管理办法》保护，经营者停业应提前30日公告并退款。 |
