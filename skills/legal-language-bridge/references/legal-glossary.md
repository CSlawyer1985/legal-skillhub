## 三、诉讼/仲裁程序用语

| 法言法语 | 大白话 |
|---------|--------|
| 仲裁前置 | 劳动案子先走仲裁，不能直接去法院 |
| 一裁终局 | 仲裁结果就是最终决定 |
| 财产保全 | 怕对方把钱转走，先冻结 |
| 先予执行 | 判决前先把钱要一部分（救命/抚养费） |
| 缺席判决 | 对方不来法院直接判 |
| 强制执行 | 法院帮你硬要回来 |
| 失信被执行人 | 老赖，法院黑名单 |
| 限制高消费 | 不能坐飞机高铁，不能住好酒店 |
| 终本 | 法院说"找到财产了再说"（不是永久放弃） |
| 再审 | 判错了再去法院翻案 |
| 小额诉讼 | 简单的、金额小的官司，一审终审不能上诉 |
| 代表人诉讼 | 集体诉讼，一大群人一起告 |
