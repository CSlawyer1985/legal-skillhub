# 赔偿计算器参考

> 为常见纠纷类型提供赔偿项目和计算逻辑，帮助用户理解"能赔多少"。
> 计算器输出仅为参考估算，不构成法律意见。具体金额以裁判机关认定为准。

---

## 一、劳动法 N+1 与经济补偿/赔偿金

### 1.1 N+1 适用场景
- **N（经济补偿金）= 工作年限 × 月工资**：适用于合法解除（协商一致、经济性裁员等）
- **N+1（经济补偿金+代通知金）**：适用于用人单位未提前30天通知的合法解除
- **2N（违法解除赔偿金）= 2 × N**：适用于违法解除

### 1.2 计算逻辑

| 项目 | 公式 | 说明 |
|------|------|------|
| N（工作年限） | 每满1年 = 1个月；6个月以上不满1年 = 1个月；不满6个月 = 0.5个月 | 上限12年（月工资超当地社平工资3倍时） |
| 月工资 | 离职前12个月平均工资（含奖金/津贴/加班费等应发工资） | 上限为当地上年度职工月平均工资的3倍 |
| 经济补偿金 | N × 月工资 | |
| 代通知金（+1） | 1个月工资 | 未提前30日书面通知时适用 |
| 违法解除赔偿金（2N）| 2 × N × 月工资 | 违法解除时适用，与N不能同时主张 |

### 1.3 常见情形速查

| 情形 | 赔偿标准 | 法条 |
|------|---------|------|
| 协商一致解除 | N | 《劳动合同法》第36条、第46条 |
| 公司裁员（经济性裁员） | N | 第41条、第46条 |
| 合同到期不续签（公司） | N | 第44条、第46条 |
| 公司无过失单方解除+提前30天通知 | N | 第40条 |
| 公司无过失单方解除+未提前通知 | N+1 | 第40条 |
| 公司违法解除（无故辞退等）| 2N | 第48条、第87条 |
| 劳动者被迫辞职 | N | 第38条、第46条 |
| 劳动者主动辞职 | 0 | — |

## 二、工伤赔偿三金

### 2.1 工伤保险三大赔偿项目

| 项目 | 谁出钱 | 标准 |
|------|--------|------|
| **一次性伤残补助金** | 工伤保险基金 | 7-27个月本人工资（按伤残等级1-10级递减） |
| **一次性工伤医疗补助金** | 工伤保险基金 | 解除劳动关系时，各省标准不同 |
| **一次性伤残就业补助金** | 用人单位 | 解除劳动关系时，各省标准不同 |

### 2.2 伤残等级对应补助金（一次性伤残补助金）

| 等级 | 月数 |
|------|------|
| 一级 | 27个月 |
| 二级 | 25个月 |
| 三级 | 23个月 |
| 四级 | 21个月 |
| 五级 | 18个月 |
| 六级 | 16个月 |
| 七级 | 13个月 |
| 八级 | 11个月 |
| 九级 | 9个月 |
| 十级 | 7个月 |

> 1-4级伤残保留劳动关系，退出工作岗位，按月领取伤残津贴（本人工资的75%-90%）。
> 5-10级可解除劳动关系，一次性领取三项补助金。

### 2.3 其他工伤待遇

| 项目 | 说明 |
|------|------|
| 医疗费/康复费 | 实报实销（工伤保险支付） |
| 停工留薪期工资 | 原工资福利待遇不变，由单位按月支付（一般不超过12个月） |
| 护理费 | 按护理等级（完全/大部分/部分不能自理） |
| 住院伙食补助费 | 按当地标准 |
| 交通食宿费 | 到外地就医时 |
| 辅助器具费 | 假肢、轮椅等 |
| 工亡待遇 | 丧葬补助金 + 供养亲属抚恤金 + 一次性工亡补助金（全国统一为上年度全国城镇居民人均可支配收入的20倍） |

### 2.4 未参保情况

> 用人单位未依法参加工伤保险的，以上所有本应由工伤保险基金支付的费用，**全部由用人单位承担**。（《工伤保险条例》第62条）

## 三、交通事故赔偿项目

### 3.1 人身损害赔偿清单

根据《民法典》第1179条及《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释》：

| 项目 | 计算方法 | 备注 |
|------|---------|------|
| 医疗费 | 实报实销（凭票据） | 含后续治疗费 |
| 误工费 | 误工天数 × 日工资 | 有固定收入按实际减损计算；无固定收入按近3年平均或同行业标准 |
| 护理费 | 护理天数 × 当地护工标准 | 家属护理的按家属误工费 |
| 交通费 | 实报实销 | 就医转院交通 |
| 营养费 | 医嘱天数 × 当地标准（约30-50元/天） | 需医嘱 |
| 住院伙食补助费 | 住院天数 × 当地标准（约50-100元/天） | |
| 残疾赔偿金 | 当地人均可支配收入 × 20年 × 伤残系数 | 60岁以上每增加1岁减少1年 |
| 残疾辅助器具费 | 实报或标准配置 | 假肢、轮椅等 |
| 死亡赔偿金 | 当地人均可支配收入 × 20年 | 同残疾赔偿金年限规则 |
| 丧葬费 | 当地职工月平均工资 × 6个月 | |
| 被扶养人生活费 | 当地人均消费支出 × 年限 ÷ 共同扶养人数 | 未成年算到18岁，无劳动能力算20年 |
| 精神损害抚慰金 | 法院酌定（一般几千到几万元） | 构成残疾或死亡才支持 |
| 财产损失 | 车辆维修费、衣物损失等 | 凭票据 |

### 3.2 赔偿顺序

```
交强险限额（有责：死亡伤残18万 / 医疗1.8万 / 财产2000）
    ↓ 不足部分
商业三者险（按保险合同约定）
    ↓ 不足部分
侵权人个人承担
```

## 四、消费维权计算

| 情形 | 赔偿标准 | 法条 |
|------|---------|------|
| 普通欺诈 | 退一赔三，不足500元按500元 | 《消法》第55条第1款 |
| 食品安全 | 退一赔十，不足1000元按1000元 | 《食品安全法》第148条 |
| 预付卡跑路 | 退还余额 + 利息损失 | 《消法》第53条 |

## 五、加班费计算

| 加班类型 | 计算标准 | 法条 |
|---------|---------|------|
| 工作日延时加班 | 小时工资 × 1.5倍 | 《劳动法》第44条 |
| 休息日加班（不补休） | 小时工资 × 2倍 | 同上 |
| 法定节假日加班 | 小时工资 × 3倍 | 同上 |

> 小时工资 = 月工资 ÷ 21.75 ÷ 8
> 法定节假日加班不能用补休替代，必须付3倍工资。

## 六、诉讼时效速查

| 权利类型 | 时效 | 起算点 |
|---------|------|--------|
| 一般民事权利 | 3年 | 知道或应当知道权利受侵害之日 |
| 劳动仲裁申请 | 1年 | 知道或应当知道权利受侵害之日 |
| 工伤认定申请（单位） | 30天 | 事故伤害发生之日 |
| 工伤认定申请（个人） | 1年 | 事故伤害发生之日 |
| 请求支付劳动报酬 | 1年（仲裁时效） | 劳动关系终止之日起算 |
