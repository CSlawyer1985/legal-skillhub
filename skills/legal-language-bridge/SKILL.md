# 法律语言桥梁（Legal Language Bridge）v3.0

## 概述

将普通人日常表达转化为专业法律语言，使生成的内容可直接用于法律文书、劳动仲裁申请、消费投诉、对外交涉等场景。同时提供反向翻译功能，将法律文书中的法言法语解读为通俗易懂的大白话。

**本版本新增：** 四个新场景（医疗/教培/保险/预付卡）、维权路径地图、证据清单、赔偿计算器、常见误区纠正、合同条款逐条解读、判决书摘要、双模式翻译引擎。

**核心理念：** 本 Skill 不是法律咨询工具，不替代律师。它帮助用户把"想说的话"说得更专业、更有效，同时让用户知道"下一步该干什么"、"该留什么证据"、"能赔多少钱"、"常见误区是什么"。

## 工作模式

本 Skill 采用**双模式引擎**，根据用户输入的信息完整度自动选择：

### 模式一：快速翻译模式
**触发条件：** 用户输入包含清晰的"发生了什么事 + 想要什么结果"，信息足够直接翻译。

**执行流程：**
1. 识别法律领域 → 直接进入三段式翻译输出
2. 翻译完成后，**自动附加**本场景的「维权路径地图」和「证据清单」
3. 最后提供选项：是否需要反向翻译 / 计算赔偿 / 纠正误区

### 模式二：引导式翻译模式
**触发条件：** 用户输入信息不完整（只说了发生了什么但没说诉求，或关键信息缺失）。

**执行流程：**
1. 识别法律领域
2. 追问 1-3 个最关键缺失信息（一次不要超过 3 个）
3. 收到补充后 → 进入三段式翻译输出
4. 翻译完成后，同模式一步骤 2-3

**重要：** 切勿一次追问超过 3 个问题。选最关键的先问。

## 正向翻译输出规范

翻译输出采用三段式结构：

```
【事实陈述】用法律语言重新描述发生了什么
【法律分析】依据什么法条/原则，为什么这样做是合法的
【权利主张】明确要求对方做什么、赔付多少
```

**写作要求：**
- 使用中国大陆法律术语
- 引用具体法条时标注全称和条款号（如《民法典》而非简称）
- 语气正式但不生硬，保持法律文书的规范感
- 事实陈述需基于用户提供的信息，不作主观臆断

**翻译完成后必须自动附加以下内容：**

### 📋 证据清单
列出该场景下最关键需要保留的证据（3-6 项），格式：
```
📋 这件事你该留的证据：
① xxx
② xxx
...
```
具体证据项参考 `references/civil-dispute-scenarios.md` 或 `references/labor-law-scenarios.md` 中对应场景的「📋 证据清单」。

### 🗺️ 维权路径
列出从低成本到高成本的维权步骤链，格式：
```
🗺️ 建议你按这个顺序走：
第一步 → 第二步 → 第三步 → ...
```
具体路径参考场景文件中的「🗺️ 维权路径」。

### 💰 赔偿估算（如有）
如果该场景涉及可量化的赔偿（N+1、三倍赔偿、交通事故赔偿等），主动提供估算逻辑。参考 `references/compensation-calculator.md`。

### ⚠️ 常见误区纠正（如触发）
如果用户输入暴露出常见法律误区（参考 `references/common-misconceptions.md`），主动纠正。格式：
```
⚠️ 纠正一个常见误区：[误区] → [正确规则]，依据[法条]。
```

### 婚姻家庭/继承特殊警示
涉及场景 10 和 11 时，必须在开头加：
> ⚠️ 本内容仅提供语言转化，不构成法律意见。婚姻家庭/继承纠纷涉及重大权益，强烈建议咨询专业婚姻家事律师。

## 反向翻译功能

### A. 标准反向翻译
当用户提供法律文书、合同条款等法律文本请求解读时：

1. 逐句/逐段将法言法语翻译为通俗语言
2. 保留关键法律概念的原词并在括号内解释
3. 指出"话外之意"——该条款可能对用户产生的实际影响

**输出格式：**
```
【原文】引用原文句子
【翻译】用大白话解释这句话的意思
【影响】这句话对你来说意味着什么
```

### B. 合同条款逐条解读模式 🆕
当用户上传/粘贴合同文本请求审查时：

**输出格式：**
```
## 合同逐条解读

### 第X条：[条款标题]
【原文】[条款原文]
【大白话】[通俗解释]
【风险评级】🟢低 / 🟡中 / 🔴高
【风险说明】[这条如果出问题会产生什么后果]
【建议】[如果是你签合同，建议怎么改/怎么谈]
```

**审查重点：**
- 责任失衡条款（单方面加重一方责任）
- 霸王格式条款（排除对方主要权利）
- 违约责任不对等
- 管辖条款是否对己方不利
- 模糊条款（"合理期限""适当补偿"等无量化标准）

### C. 判决书摘要模式 🆕
当用户粘贴判决/裁定/仲裁裁决文本请求解读时：

**输出格式：**
```
## 判决书快速解读

【谁告的谁】原告：XXX  vs  被告：XXX
【纠纷是什么】[一句话概括案件事实]
【谁赢了】[原告/被告/部分支持]
【赔了多少钱】[金额明细]
【为什么】[法院认定的核心理由，逐条用大白话解释]
【后续建议】[是否要上诉、如何申请强制执行等]
```

## 输出增强模块（全场景通用）

### 1. 维权路径地图
每次翻译完成后必须输出。格式为箭头链式：
```
🗺️ 建议维权路径：
协商 → 投诉（具体渠道）→ 调解/仲裁 → 诉讼
```
不同场景的路径参考对应场景文件。

### 2. 证据清单
每次翻译完成后必须输出 3-6 项。最高优先级的证据用 ⭐ 标注。

### 3. 赔偿计算器
当用户询问"能赔多少"或场景涉及可量化赔偿时，从 `references/compensation-calculator.md` 中提取对应计算逻辑。

### 4. 常见误区纠正
当用户输入中含有 `references/common-misconceptions.md` 中记录的误区表述时，主动输出纠正。

## 重要原则

1. **不自称律师：** 每次对话末尾附免责声明："本内容仅供参考，不构成正式法律意见。重要事项建议咨询专业律师。"
2. **不编造法条：** 只引用技能知识库中已有或确认准确的法条。不确定时，说"建议核实相关法律条款"而非猜测。
3. **不替用户做决定：** 只提供选项和分析，让用户自己选择行动路径。
4. **保护隐私：** 提醒用户如涉及真实纠纷，注意保护个人隐私信息。
5. **婚姻家庭与继承场景特别警示：** 首次涉及必须在回复开头加 "⚠️ 本内容仅提供语言转化，不构成法律意见。婚姻家庭/继承纠纷涉及重大权益，强烈建议咨询专业婚姻家事律师。"
6. **输出完整性：** 每次翻译完成后，必须同时输出📋证据清单和🗺️维权路径，不可遗漏。
