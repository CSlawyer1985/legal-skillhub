# W1 案件解析

> 本文件定义工作流第一阶段：从用户提交的案件材料中提取结构化事实笔记。
> W1 是事实层入口，**严格止于事实层，绝不进入规范层**。所有"是否违法、是否撤销、是否赔偿"的判断留给 W2。

> **法条锚定单点源铁律**：W1 阶段事实笔记中**不应出现任何法条引用**；如果原始材料附带条文（如行政处罚决定书所引条款），仅原样转录到 `documents` 字段，不在事实笔记正文复述。本文件中出现的"§N"形式仅指本目录内部章节交叉引用（如 §6.5、§2.1），非法条编号。

---

## 零、本案格式覆盖识别（W1 起始预处理）

在启动 §一 文档解析之前，先扫描用户本次输入中是否包含单案格式覆盖指令，用于覆盖 `.user-config.md` 中的 `report_format_preference` 全局默认值（详见 SKILL.md §4.3）。识别规则：

| 指令 | 覆盖值 | 说明 |
|------|--------|------|
| `/format md` | `md_only` | 本案仅输出 Markdown，不询问 Word 转换 |
| `/format docx` | `md_and_docx` | 本案输出 MD 后自动转 Word，不再询问 |
| `/format ask` | `md_then_ask` | 本案 MD 落盘后询问是否转 Word（等同于推荐默认流程） |
| 未出现 | 沿用 `.user-config.md` 默认 | 无覆盖 |

**落盘规则**：识别到指令后，在工作目录写入 `_case_meta.md`：

```yaml
# _case_meta.md（本案元数据 · 仅本案有效）
report_format_override: md_only | md_and_docx | md_then_ask
override_source: "W1 用户指令 /format <值>"
```

未识别到指令则不生成本文件。W4 §五终稿输出阶段将**优先读取 `_case_meta.md`**，缺失时才回落到 `.user-config.md` 全局偏好。本文件仅在本案工作目录内有效，不影响后续案件。

## 一、文档解析与中性事实笔记

### 1.1 输入识别

输入文件类型：PDF（含扫描件）、Word、纯文本、图片。扫描件 PDF 无文字层时调用 OCR 或视觉读取。

### 1.2 输出：YAML 结构的中性事实笔记

关键字段：

- `parties`：原被告/第三人/复议机关的 name/type/level
- `timeline`：date + event + source
- `administrative_acts`：act_id / type / subject / content / document / date / delivery_date。`type` 字段取**双层标签**：① 理论标签（12 类，参见 `../methodology/legality-examination-engine/pipeline.md` § 二第 2 表）作为底层定性记录；② 路由标签（9 类高频之一或"其他"，参见 `../methodology/case-router.md` §2.1）作为下游 W2 双维度路由的输入。两者按 `pipeline.md` § 二第 3 表"理论类型 vs 路由高频类型对照"自动映射，W1 预识别阶段允许仅给出路由标签（9 类高频或"其他"），理论标签可留待 W2 Gate1 正式识别时补全。
- `reconsideration`：复议申请日 / 决定机关 / 决定类型 / 决定日
- `facts`：客观事实 + 争议事实双轨
- `refer_date`：法律版本锚定日期，取行政行为作出之日

---

## 二、事实缺口扫描

完成笔记后扫描以下项目：

- 当事人全称完整性
- timeline 关键节点（行为作出日 / 送达日 / 复议日 / 起诉日）
- 行为单元三要素切分
- 复议关系记录
- 历史法适用要求

缺口标注 `[事实待补]`，关键缺失时不得进入 W2。

---

## 三、行政行为实质类型预识别

W1 抽取事实完毕后，应对行政行为实质类型做**预识别**（正式识别在 W2），为 W2 双维度路由做准备。

**预识别步骤**：

1. 列出案件中所有行政行为单元（一个案件可能含多个行为）
2. 对照 `methodology/case-router.md` §2.1 速查表，为每个行为单元标记实质类型（9 类高频之一或"其他"）
3. 如识别困难，标记为"待 W2 正式识别"

**预识别输出**（嵌入 W1 出口 YAML）：

```yaml
行政行为实质类型预识别:
  行为单元1:
    行为描述: "2024-05-15 作出《行政处罚决定书》（罚字[2024]第 XX 号）"
    预识别类型: "行政处罚"
    关键法条: "《行政处罚法》"
  行为单元2:
    行为描述: "2024-06-20 作出《强制执行决定书》"
    预识别类型: "行政强制"
    关键法条: "《行政强制法》"
```

## 四、W1 门禁（事实层完整性 + 无法律污染）

- [ ] 所有当事人已识别且全称完整
- [ ] 所有行政行为单元已切分并赋 act_id
- [ ] timeline 关键节点齐全
- [ ] 复议关系已记录（事实层）
- [ ] 设问已逐字摘录
- [ ] **没有任何法条号出现**
- [ ] **没有任何"违法/合法/撤销/履行"等定性词**
- [ ] 事实缺口已扫描并处理
- [ ] ✅ 行政行为实质类型已预识别

任一项不满足则退回补全。通过后方可进入 W2。

**快速通道触发（W1 端预检）**：W1 阶段尚未执行可受理性 8 闸门预判，故 W1 端的快速通道仅做"事实层预检"。当案件同时满足以下全部条件时，W1 门禁自动检查通过后直接进入 W2，无需单独向用户确认 W1 出口：① 单一诉讼请求（无备位请求）；② 单一行政行为单元；③ 无复议维持/共同被告情形；④ 事实缺口扫描无关键 `[事实待补]` 项（W1 端预检条件）。快速通道下 W1 事实笔记仍须落盘 `case-summary.md`，但确认环节与 W2 Gate1 合并。

> **与 W2 端快速通道的关系**：W1 端预检通过仅意味着可与 W2 Gate1 合并确认；是否进一步将 Gate1 与 Gate2 合并为一次确认（即"W2 端双闸合并"），须由 W2 Gate1 阶段追加检查 SKILL.md §5.1 / W2 §阶段定位列出的条件④"8 闸门预判中无'不通过'项"后再行决定。W1 端条件④（事实层）与 W2 端条件④（规范层）分别在各自阶段独立检查，构成"双闸触发"模型，互不替代、亦不冲突。

## 五、轻量模式触发条件

当同时满足以下全部条件时，触发轻量模式：

- 预估字数 < 5000 字
- 单诉讼类型（仅撤销/仅履职/仅给付等）
- 无备位请求（无 R.subsidiary 标记）
- 无时间锚定争议（行为作出时至今未发生法律修订）
- **不属于行政公益诉讼**（公益诉讼必经诉前检察建议程序、利益面更广，不适用轻量模式）

**轻量模式行为**：单 agent 走全流程，跳过子 agent 切分。W1 → W2 预选+大纲 → 直接写作 → W4 核验 → Word 输出。W2 大纲确认不可跳过。W4 简化为形式核验 + 法条校验（策略核验可选）。字数上限 5000 字，争议级别仅保留⭐与无标记两级。

## 六、双维度路由

本工作流在 W2 预选阶段采用双维度路由：

| 维度 | 决定什么 | 识别时机 | 路由来源 |
|------|---------|---------|---------|
| 诉讼请求类型（撤销/履职/给付/确认/特殊） | 可证立性审查的程序骨架 | W2 预选 | `methodology/legality-examination-engine/pipeline.md` § 一 |
| 行政行为实质类型（处罚/强制/信息公开/征收/投诉举报/工伤/许可/协议/赔偿） | 合法性审查的实体专属要点 | W1 出口即预识别，W2 正式识别 | `methodology/case-router.md` §2 |

**双维度正交原则**：同一诉讼请求类型可能对应多种行政行为实质类型，实体审查要点完全不同。必须在 W2 阶段同时完成两类识别。

**路由器文件**：详见 `methodology/case-router.md`。

## 七、W1 落盘指令

W1 门禁全部通过后，agent **必须**将 §1.2 中性事实笔记（含 §三 行政行为实质类型预识别 YAML 块）合并写入工作目录的 `case-summary.md`，作为 W2/W3/W4 全程的事实层权威源。

```bash
# 落盘路径示意（实际路径由用户工作目录决定）
{工作目录}/case-summary.md
```

落盘内容须包含：YAML 头（parties / timeline / administrative_acts / reconsideration / facts / refer_date 全字段）+ 行政行为实质类型预识别 YAML 块 + 事实缺口扫描结果（如有 `[事实待补]` 标注）。下游 W2 Gate1 启动前会读取本文件；缺失即拒绝进入 W2。

---

## 八、与下游衔接

W1 的事实笔记是 W2（预选与大纲）的输入。如 W2 发现 W1 遗漏关键事实，应回 W1 补全，不在 W2 越界添加。
