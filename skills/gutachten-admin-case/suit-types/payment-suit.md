# 给付之诉与国家赔偿（Payment Suit & National Compensation）

给付之诉请求行政机关作出金钱、物品或行为给付；国家赔偿之诉请求因行政机关违法行使职权造成的损害获得赔偿。本文件采用**请求权审查四要件**范式（对应 `methodology/case-router.md §零` 轨道 B）。

> **法条锚定单点源铁律**：所有法条引用一律使用 `[语义名称]` 占位符，禁止出现具体条号。语义名称→现行编号的映射由 `SKILL.md §6.5 法条锚定表` 唯一维护。

---

## §一 定位与子类型

**给付之诉**：原告请求行政机关交付金钱、财产或其他对价。

**国家赔偿之诉**：给付之诉的特殊形态，请求权基础为《国家赔偿法》而非一般行政法规范。国家赔偿分为行政赔偿（本文件范围）和刑事赔偿（不在本文件范围）。

**两种关系**：
- **主从关系**：撤销 + 赔偿，先违法性确认再赔偿审查；
- **独立关系**：直接请求法定给付待遇或补偿。

行政协议中的金钱给付义务原则上嵌入行政协议之诉（C 轨）。

## §二 专属可受理性要点（嵌入 8 闸门）

### 2.1 国家赔偿先行程序（G7 形式要件）

行政赔偿需先向赔偿义务机关提出申请（[赔偿先行程序条款]）。赔偿义务机关应在收到申请之日起 **2 个月**内作出赔偿决定。逾期不作决定或赔偿请求人对数额有异议的，可向法院起诉。

**可跳过先行程序的情形**：
1. 在行政诉讼中一并提出赔偿请求（[行政赔偿/补偿判决条款] 一并提出路径）；
2. 赔偿义务机关已被撤销且无继受机关。

### 2.2 时效（G7 起诉期限的专门规则）

| 请求类型 | 时效 | 起算点 |
|---------|------|--------|
| 国家赔偿请求 | 2 年 | 知道或应当知道侵权行为之日（[赔偿请求时效条款]） |
| 须经撤销/确认违法的赔偿 | 2 年 | **撤销/确认违法判决生效之日** |
| 行政补偿请求 | 6 个月 | 适用 [起诉期限条款] |
| 法定给付请求 | 6 个月 | 适用 [起诉期限条款] |

**时效抗辩审查要点**：行政机关抗辩超过 2 年时，须先判断违法性是否须经判决确认，避免起算点错位。

## §三 请求权审查四要件（B 轨核心）

### 3.1 要件一：给付请求权基础（"原告依据什么请求给付？"）

**四类请求权基础**：

| 类型 | 内容 | 典型示例 |
|------|------|---------|
| **法定给付义务** | 单行法直接赋予公民的给付请求权 | 抚恤金、最低生活保障金、社会保险待遇、工伤补偿 |
| **行政补偿请求权** | 合法行政行为致特别牺牲 | 征收补偿（[征收决定条款] + [补偿决定条款]） |
| **国家赔偿请求权** | 违法行为致害 | [赔偿范围条款] |
| **协议约定给付** | 行政协议中的给付条款 | 行政协议之诉（C 轨）中的金钱给付 |
| **信赖利益返还** | 行政机关撤回/变更授益行为补偿 | [信赖保护条款] |

**关键判别**：请求权基础不明确或缺失的，给付之诉不成立。

### 3.2 要件二：给付要件涵摄

#### A. 法定给付的要件涵摄

审查：① 法定给付条件是否全部成就；② 给付数额的确定标准；③ 行政机关是否有权拒绝或减少给付。

**涵摄四步法标准句式**：

> **[总起]** 原告对低保金的请求权是否成立，应审查 [城市居民最低生活保障条款] 的法定条件。
>
> **[定义]** 依该条款，符合下列条件应予给付：① 户籍属本地；② 家庭人均收入低于最低生活保障标准；③ 已申请并提交全部材料。
>
> **[归入]** 本案中：① 原告户籍属 XX 区；② 家庭人均月收入 600 元，低于本市低保标准 800 元；③ 已提交申请及材料。
>
> **[结论]** 法定条件全部成就，给付请求权成立。

#### B. 国家赔偿请求权的四要件

**违法行为**：行政机关或其工作人员违法行使职权。

> **六要素违法性子骨架嵌入提示**：
>
> **独立提起赔偿之诉**（未经撤销/确认违法之诉先行确认违法）时，本"违法行为"要件须**完整嵌入 `methodology/legality-examination-engine/framework.md` §一 六要素合法性审查骨架**做违法性前置审查，按 `framework.md` §一 1.0 审查铁律 Step 0-6 推进，缺陷分级三档输出（重大且明显违法 / 一般违法 / 程序轻微违法）。
>
> **已存在生效的撤销 / 确认违法判决**时，跳过六要素嵌入，直接援引该判决主文："违法性已由 [案号] 判决确认"。

**损害事实**：客观存在的损失，包括财产损害（直接经济损失）和人身损害（人身自由受限、身体伤害、死亡）。原告承担初步证明责任。

**因果关系**：违法行为与损害之间存在相当因果关系。介入因素（受害人自身过错、第三方行为、不可抗力）可能中断或减弱因果链条。

**主体资格**：原告是合法权益主体（公民、法人、其他组织）。

**国家赔偿涵摄典型句式**：

> **[总起]** 原告 XX 公司请求 XX 局赔偿误工费 8 万元。判断该请求是否成立，应审查四要件：违法行为 / 损害事实 / 因果关系 / 主体资格。
>
> **[定义]** 依 [赔偿范围条款]，行政机关及其工作人员违法行使职权侵犯公民、法人和其他组织合法权益造成损害的，受害人有取得赔偿的权利。
>
> **[归入]** 本案中：① 违法行为经第一部分撤销之诉审查已确认违法；② 损害事实为原告因停产 7 日造成误工损失 8 万元（已提交工资发放表 / 收入证明）；③ 因果关系：违法处罚直接导致原告停产从而产生误工损失；④ 原告为合法权益主体。
>
> **[结论]** 四要件全部成立，赔偿请求应予支持。

#### C. 赔偿范围与标准

| 损害类型 | 赔偿标准 | 语义锚定 |
|---|---|---|
| 侵犯人身自由 | 每日赔偿金 = 上年全国职工日平均工资 | [人身/财产损害赔偿标准条款]人身自由项 |
| 造成身体伤害 | 医疗费 + 误工费 + 护理费 | [人身/财产损害赔偿标准条款]身体伤害项 |
| 部分/全部丧失劳动能力 | 残疾赔偿金 + 扶养费 + 康复费 | [人身/财产损害赔偿标准条款]残疾项 |
| 造成死亡 | 死亡赔偿金 + 丧葬费 + 扶养费 | [人身/财产损害赔偿标准条款]死亡项 |
| 侵犯财产权 | 返还 / 恢复原状 / 赔偿直接损失 | [人身/财产损害赔偿标准条款]财产项 |
| 精神损害（限人身权侵害） | 精神损害抚慰金 | [精神损害赔偿条款] |

**间接损失原则上不赔偿**（[人身/财产损害赔偿标准条款]财产项仅赔偿"直接损失"），但可得利益损失在征收补偿领域应予考虑。

### 3.3 要件三：履行可能性（数额可量化）

审查给付数额是否可量化、是否在行政机关履行能力范围内：

- **数额已确定**（法定给付标准、市场评估价、协议约定）→ 直接给付判决；
- **数额需重新核定**（补偿标准违法、评估有误）→ 撤销 + 重作 + 给付组合判决；
- **数额无法量化**（损害不可估算）→ 转为确认违法 + 命行政机关协商。

### 3.4 要件四：抗辩事由

**行政机关可主张的合法抗辩**：
- 时效已过（须区分起算点，详见 §2.2）；
- 给付条件未全部成就；
- 已实际给付（举证已支付凭证）；
- 原告自身过错导致损害扩大（混合过错分担）；
- 不可抗力或第三人行为（介入因素中断因果关系）。

## §四 迟延给付的扩大损失（征收补偿专项）

### 4.1 问题场景

征收补偿案件中，补偿决定因标准违法被撤销后，补偿款迟延支付期间市场上涨，导致原补偿标准已无法覆盖被征收人购买同等条件房屋的损失。该扩大损失如何分配？

### 4.2 时间锚定规则

| 时间节点 | 适用场景 | 法律效果 |
|---|---|---|
| 征收决定公告日 | 补偿标准评估基准日 | 以公告时点市场价为基准（[评估时点条款]） |
| 实际支付日 / 判决日 | 因行政机关原因迟延支付 | 迟延期间扩大损失由行政机关承担 |
| 诉讼时点 | 法院裁判时重新确定补偿 | 综合考虑迟延原因与市场变化 |

**裁判规则**：因行政机关原因导致补偿迟延的，补偿标准应以**实际支付时的市场价**为参照，确保被征收人获得的补偿不低于征收决定公告时的市场价值。

### 4.3 扩大损失责任分配

| 情形 | 责任分配 | 计算 |
|------|---------|------|
| 行政机关原因迟延 | 扩大损失全部由行政机关承担 | 实际应付 = 裁判时点市场价 × 面积 |
| 被征收人原因迟延（无正当理由拒收 / 故意拖延） | 迟延期间市场风险由被征收人自担 | 实际应付 = 原评估价 |
| 混合原因 | 按过错比例分担 | 实际应付 = 原评估价 + 增值部分 ×（1 - 被征收人过错比例） |

**法理基础**：任何人不得从自身违法行为中获益（行政机关原因）；信赖保护与诚信原则的反面（被征收人原因）。

**典型算例**：
- 原补偿决定：260 万元（2019 年评估基准日，9,285 元/㎡，280㎡）
- 2025 年裁判时同地段市场价：22,000 元/㎡
- 按裁判时点市场价重算：280 × 22,000 = 616 万元
- 若迟延完全归因于行政机关：扩大损失 356 万元由其承担
- 若被征收人有 20% 过错：实际应付 ≈ 260 + 356 × 80% ≈ 544.8 万元

## §五 判决类型映射

| 情形 | 判决类型 | 法条 |
|---|---|---|
| 法定给付条件全部成就 + 数额确定 | 给付判决 | [给付判决条款] |
| 国家赔偿四要件成立 | 赔偿判决 | [行政赔偿/补偿判决条款] + [赔偿范围条款] |
| 补偿标准违法 + 迟延扩大损失 | 重新核定补偿 + 扩大损失赔偿组合 | [撤销判决要件条款] + [给付判决条款] |
| 利息请求（迟延给付期间） | 利息判决（同期银行贷款利率 / LPR） | 学理 + 司法解释 |
| 部分要件成立 | 部分给付判决 | [给付判决条款] |
| 请求权基础不存在 / 时效已过 | 驳回诉讼请求 | [驳回诉讼请求条款] |

**利息问题**：行政机关迟延给付的，原告有权请求迟延期间利息。计算标准参照同期银行贷款利率或 LPR，自给付义务到期之日起算至实际支付之日止。

## §七 反向错误清单（D4 自检）

litigation / pre-enforcement 场景下，给付/赔偿之诉的常见错配点：

- 是否漏识别"独立赔偿之诉"应嵌入完整六要素违法性前置审查？
- 是否将"撤销 + 赔偿"误作两个独立诉讼而漏识别主从关系？
- 是否漏识别"违法性须经判决确认"的时效起算点（应从判决生效日起算）？
- 是否漏识别"迟延扩大损失"应由行政机关承担？
- 是否将"间接损失"误作"直接损失"或反之？
- 是否漏查"精神损害仅限人身权侵害"的限定？
- 是否漏识别"裁量收缩 → 直接给付"情形（应直接判决数额）？
