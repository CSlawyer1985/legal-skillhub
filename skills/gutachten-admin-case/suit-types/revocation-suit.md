# 撤销之诉（Revocation Suit）

撤销之诉是行政诉讼最典型、最高频的诉讼类型，占实务案件 60% 以上。原告请求法院撤销或部分撤销已生效的具体行政行为，并可责令行政机关重新作出行政行为。其核心法律依据为[撤销判决要件条款]（六要素合法性审查）、[部分撤销条款]、[撤销并重作判决条款]，以及行诉解释中相关撤销/重作配套条款。

> **三轨路由身份**：本之诉走 **A 轨 · 违法性审查**，调用六要素合法性审查骨架（详见 `../methodology/legality-examination-engine/framework.md`），不进入 B 轨请求权审查或 C 轨协议四阶。

> **六要素合法性审查通用涵摄骨架**已并入 `../methodology/legality-examination-engine/framework.md`，本文件仅保留撤销之诉的专属内容。

> **法条锚定单点源铁律**：本文档所有法条引用一律使用 `[语义名称]` 占位符，禁止出现具体条号。语义名称→现行编号的映射由 `SKILL.md §6.5 法条锚定表` 唯一维护。

## §一 撤销之诉定位

撤销之诉适用于对外发生法律效力的具体行政行为。原告认为行政行为侵犯其合法权益，请求法院予以撤销或部分撤销，使该行为自始丧失法律效力。

**适用对象**：已成立并对外生效的具体行政行为，包括行政处罚、行政许可、行政强制、行政征收、行政确认、行政登记等。

**诉讼目标**：撤销/部分撤销行政行为 + 可责令行政机关重新作出。

**与其他诉讼类型的根本区分**：撤销之诉针对"已经存在且尚在生效"的行政行为。若行政行为已执行完毕且无法恢复原状，应转为确认违法之诉；若行政行为重大且明显违法达到自始无效的程度，应转为确认无效之诉。

**缺陷分级三档区分**：

- **重大且明显违法** → 确认无效（"确认无效判决"条款），自始无效，不受起诉期限限制
- **一般违法** → 撤销（"撤销判决要件"条款），行政行为溯及既往失效
- **程序轻微违法且不影响实体结果** → 确认违法但保留效力（"确认违法判决"条款 第 2 项）

撤销之诉仅处理"一般违法"档。若审查中发现属于"重大且明显违法"，应释明原告变更诉讼请求为确认无效之诉；若属于"程序轻微违法"，则转为确认违法之诉。三档之间的精确判别详见§四。

## §二 撤销之诉专属可受理性要点

### 2.1 受案范围：具体行政行为四要件

被诉行为须同时满足四个要件方可纳入受案范围：

| 要件 | 含义 | 排除情形 |
|---|---|---|
| 单方性 | 行政机关单方意思表示 | 行政协议（双方合意） |
| 公权力 | 行使行政公权力 | 民事行为（政府采购） |
| 外部效力 | 对相对人产生外部法律效果 | 内部行政行为（人事任免） |
| 具体性 | 针对特定对象/特定事项 | 抽象行政行为（规范性文件） |

**排除事项**（"受案范围负面清单"条款）：国家行为、行政法规/规章、内部奖惩任免、终局裁决行为。规范性文件仅可附带审查（"附带审查"条款），不得单独作为撤销对象。

### 2.2 程序类型分支

行政行为作出程序类型直接影响程序合法性审查标准：

| 程序类型 | 适用条件 | 程序要求 |
|---|---|---|
| 简易程序 | 警告/小额罚款（公民 ≤200 元，法人 ≤3000 元） | 当场告知、当场交付决定书 |
| 一般程序 | 除简易程序外的行政处罚 | 立案、调查、告知、听取陈述申辩、决定、送达 |
| 听证程序 | 责令停产停业、吊销许可、较大数额罚款等 | 一般程序 + 告知听证权 + 组织听证 |

审查时先识别应适用的程序类型，再判断行政机关是否遵循了对应程序要求。若行政机关应当适用听证程序却适用了一般程序，构成重大程序违法。

### 2.3 复议前置与共同被告

部分案件存在复议前置要求（自然资源确权、纳税争议等）。经过复议的案件：复议维持 → 原机关与复议机关为共同被告；复议改变 → 复议机关为被告（"被告资格"条款）。

## §三 法律适用错误精细形态（撤销之诉专属增量）

> 六要素中"适用法律、法规是否正确"（"撤销判决要件"条款 第 2 项）的通用涵摄骨架见 `../methodology/legality-examination-engine/framework.md § 一`。本节提供撤销之诉特有的五种精细审查形态，是对通用骨架的深度展开。

### 3.1 五种精细形态

| 类型 | 含义 | 典型实例 | 审查要点 |
|---|---|---|---|
| **1. 适用法律性质错误** | 将行政行为定性为 A 类型而适用了 A 类型法律，实际应定性为 B 类型并适用 B 类型法律 | 将行政强制措施定性为行政处罚，适用《行政处罚法》而非《行政强制法》；将行政确认行为定性为行政许可 | 先审查行为定性是否正确，再审查法律是否与定性匹配 |
| **2. 适用法律种类错误** | 行为定性正确，但在同一法律体系中选错了应适用的法律层级或种类 | 应适用法律却适用了行政法规（越级降格）；应适用特别法却适用了一般法；应适用部门法却适用了通用法 | 审查特别法优先、上位法优先、新法优先三项规则 |
| **3. 适用法条具体条款错误** | 适用了正确的法律，但引用了错误的具体条、款、项、目 | 行政处罚时适用了"情节较轻"条款（应适用"情节较重"条款）；罚款数额对应了错误的幅度区间 | 逐项核对条、款、项、目与事实认定之间的对应关系 |
| **4. 适用法律版本错误** | 未正确适用行政行为作出时生效的法律版本 | 行政行为作出于旧法期间，却适用新法（溯及既往）；行政行为作出于新法施行后，仍沿用已被废止的旧法 | 精准锚定行政行为作出日期，适用"实体从旧、程序从新"规则及其例外 |
| **5. 援引规范性文件与上位法抵触** | 行政行为所依据的规范性文件与上位法律、法规相抵触 | 地方规范性文件增设上位法未规定的行政处罚种类；部门规定缩小上位法规定的行政许可范围 | 启动附带审查程序（"附带审查"条款），按"下位法抵触判断清单"逐项比对（详见 `../methodology/interpretation-toolkit.md` §五） |

### 3.2 "实体从旧、程序从新"规则及其例外

行政行为适用法律版本的一般规则为"实体法适用行政行为作出时的法律，程序法适用审理时的法律"。例外情形：新法对相对人更有利且新法明确规定可溯及适用的，适用新法（从新兼从轻）；法律明确规定过渡条款的，依过渡条款处理。

### 3.3 法律保留检验

行政机关以规范性文件为依据限制公民权利或增加义务时，须经法律保留检验——限制人身自由必须有法律依据（绝对保留），限制其他权利至少应有法规依据（相对保留）。规范性文件在绝对保留事项上无权设定，即使内容不与上位法抵触也构成适用法律错误。

### 3.4 常见争点

1. 新旧法律交替时的适用选择（实体从旧、程序从新；从新兼从轻例外）
2. 上位法与下位法冲突时的适用规则（上位法优先、特别法优先、新法优先三项规则的竞合处理）
3. 规范性文件的合法性（可附带审查，"附带审查"条款；详见 `special-scenarios.md` §三）
4. 法律概念的解释分歧（如"情节严重""较大数额"的认定标准）
5. 行为定性错误导致的法律性质错误（如混淆行政处罚与行政强制、行政确认与行政许可）
6. 法条具体条款的对应性审查（条、款、项、目与事实认定的逐项核对）
7. 法律保留原则的适用（绝对保留事项与相对保留事项的区分）

### 3.5 被告举证要点

被告须提交作出行政行为所依据的全部规范性文件，并说明法条选择的理由。被告未提交法律依据或提交的法律依据与行政行为决定书载明的依据不一致的，构成举证不力，法院可依职权认定适用法律错误。

## §四 缺陷分级与判决类型

行政行为违法程度决定判决类型。审查完成后须进行三档缺陷分级，以确定最终判决方式。

### 4.1 三档缺陷分级

| 缺陷等级 | 判定标准 | 判决类型 | 判决依据 |
|---|---|---|---|
| 重大且明显违法 | 违法程度严重到一般理性人即可识别 | 确认无效 | "确认无效判决"条款 |
| 一般违法 | 六要素任一不成立，但不属"重大且明显" | 撤销/部分撤销 | "撤销判决要件"条款 |
| 程序轻微违法 | 程序瑕疵轻微且不影响实体结果 | 确认违法（保留效力） | "确认违法判决"条款 第 2 项 |

> 具体条号统一参见 SKILL.md §6.5 法条锚定表。

### 4.2 三档判别决策树

```
行政行为是否存在违法？
  │
  ├── 否 → 驳回诉讼请求（"驳回诉讼请求判决"条款）
  │
  └── 是 → 违法程度判断
        │
        ├── 重大且明显违法？
        │    ├── 主体不适格（无行政主体资格）
        │    ├── 减损权利/增加义务完全无法律依据
        │    ├── 内容客观上不可能实施
        │    └── 是 → 确认无效（"确认无效判决"条款）
        │
        ├── 程序轻微违法且不影响实体？
        │    ├── 送达超期数日
        │    ├── 文号书写笔误
        │    └── 是 → 确认违法但保留效力（"确认违法判决"条款 第 2 项）
        │
        └── 其他违法 → 撤销/部分撤销（"撤销判决要件"条款）
             └── 可同时责令重新作出（"责令重作"条款）
```

**关键区分**："违反法定程序"在"撤销判决要件"条款 第 3 项 与"确认违法判决"条款 第 2 项 之间的边界——核心标准是该程序违法是否对原告的实体权利产生了实际影响。未听取陈述申辩、应听证未听证属于重大程序违法，应撤销；文书送达迟延数日属于轻微违法，确认违法但保留效力。

## §五 与其他诉讼类型的衔接

撤销之诉在实务中常与其他诉讼类型组合使用：

**撤销 + 给付（国家赔偿）**：原告请求撤销行政行为的同时请求行政赔偿。赔偿以行政行为被撤销/确认违法为前提（[赔偿先行程序条款]之一并提出例外），两部分在同一案件中分别审查。

**撤销 + 确认违法（备位）**：原告可在撤销请求之后备位主张确认违法。当法院认为行政行为违法但不宜撤销（如撤销将严重损害公共利益）时，可判决确认违法并责令补救（[确认违法判决条款]之公益限制项）。

**撤销 + 履职（责令重作）**：撤销判决可同时责令行政机关在法定期限内重新作出行政行为（[撤销并重作判决条款]）。行政机关不得以同一事实和理由作出与原行为基本相同的行政行为。

**撤销 + 复议共同被告**：复议维持的案件，原机关和复议机关为共同被告。审查时需分别判断原行政行为和复议决定的合法性：原行为违法 → 撤销原行为 + 撤销复议决定；复议程序独立违法 → 仅撤回复议决定。
