# 确认之诉（确认违法 + 确认无效）

> 本文件合并处理"确认违法之诉"与"确认无效之诉"，二者共享"补充性原则"——撤销之诉优先，仅在撤销不可能或不适当时才转入确认之诉。

> **三轨路由身份**：本类之诉与撤销之诉同属 **A 轨 · 违法性审查**，调用六要素合法性审查骨架（详见 `../methodology/legality-examination-engine/framework.md`），不进入 B 轨请求权审查或 C 轨协议四阶。

> **法条锚定单点源铁律**：本文档所有法条引用一律使用 `[语义名称]` 占位符，禁止出现具体条号。语义名称→现行编号的映射由 `SKILL.md §6.5 法条锚定表` 唯一维护。如发现本文档残留具体条号（如《国家赔偿法》§9），视为格式违规，应统一回退到语义名称。

## §一 定位

**确认违法之诉**：行政行为已无撤销意义（已执行完毕/已失效/已撤回），或程序轻微违法不影响实体结果，原告请求法院确认该行为违法。核心在于"违法性 + 不再具有可撤销性"两阶结构。

**确认无效之诉**：行政行为存在重大且明显违法（"确认无效判决"条款 + 解释"无效情形列举"条款），原告请求确认该行为自始无效。核心在于"重大 + 明显"双要件结构，不受起诉期限限制。

**补充性原则（撤销之诉优先）**：
- 行政行为仍可撤销且无利益冲突 → 应走撤销之诉（撤销判决要件条款）
- 撤销已无实际意义或违法程度达"重大且明显" → 转入确认之诉
- 原告起诉确认无效但法院判断为一般违法 → 释明转为撤销之诉或确认违法之诉

## §二 确认违法之诉专属要点

### 2.1 受案范围

已无撤销必要的行政行为。行政行为虽然违法，但因特定事由使得撤销判决失去实际意义，转而以确认违法判决替代。

### 2.2 三种典型情形

**情形一：行政行为已执行完毕且不可逆转**
- 典型：强制拆除已执行、行政拘留已服满、罚款已缴纳且标的物已处置
- 判断标准：撤销判决无法恢复原状，或恢复原状的社会成本显著高于撤销的法律价值
- 法律依据："确认违法判决"条款第 1 款第 1 项——"行政行为依法应当撤销，但撤销会给国家利益、社会公共利益造成重大损害"

**情形二：行政行为已失效**
- 典型：限期改正决定期限届满、临时许可到期、目的已达成（如应急措施疫情结束）
- 被告已自行改变原违法行政行为（"确认违法判决"条款第 2 款第 1 项）
- 被告不履行或拖延履行法定职责，判决履行已无意义（"确认违法判决"条款第 2 款第 2 项）

**情形三：程序轻微违法但不影响实体（"确认违法判决"条款第 1 款第 2 项）**
- 典型：未告知救济途径但原告已自行了解并起诉、文书送达迟延但未影响申辩权
- 判断标准：(1) 违法仅涉及"非核心程序"；(2) 对原告权利不产生实际影响
- **反对说位置**：通说认为仅非核心程序违法且不影响实体时才认定轻微；反对说主张所有程序违法均属"重大"，因程序权利本身即利益。本程式从通说。

### 2.3 可证立性审查

**违法性审查**（与撤销之诉"六要素合法性审查"同构）：
- 主体违法：超越职权/主体不适格
- 程序违法：违反法定程序/正当程序
- 实体违法：主要证据不足/适用法律错误
- 法律效果违法：明显不当/裁量瑕疵

**确认利益审查**（确认违法之诉的特殊要件）：
- 预防再发生利益：行政机关有重复违法行为的可能
- 赔偿前置利益：确认违法为国家赔偿的前提条件（[赔偿先行程序条款]）
- 恢复名誉利益：确认违法可消除行政行为对原告名誉的不利影响

### 2.4 检视程式骨架

```
（二）确认违法之诉合法性审查
  1. 全案总起句
  2. 行政行为违法性审查（同撤销之诉"六要素合法性审查"）
    (1) 主体要件  (2) 程序要件  (3) 实体要件  (4) 法律效果
  3. "确认违法判决"情形适用判断
    (1) 已执行完毕且不可逆转
    (2) 撤销将造成重大社会公共利益损害
    (3) 程序轻微违法不影响实体结果
    (4) 被告已改变原违法行为
    (5) 被告不履行/拖延履行，判决履行已无意义
  4. 确认利益判定
    (1) 预防再发生  (2) 赔偿前置  (3) 恢复名誉
  5. 赔偿请求联动审查（如有从诉）
  6. 缺陷分级与判决类型预判
```

## §三 确认无效之诉专属要点

### 3.1 "重大且明显违法"四类情形

依《行诉解释》"无效情形列举"条款列举：

**(1) 实施主体不具有行政主体资格**
- 典型：行政机关已被撤销/注销但其工作人员擅自作出决定；内设机构/临时机构未经授权擅自发文
- "重大"判定：主体不适格直接影响行政行为存续
- "明显"判定：内设机构与行政主体的区分系基本法律常识

**(2) 减损权利或增加义务的行政行为没有法律依据**
- 典型：无任何法律法规授权即要求企业定期报送商业秘密清单
- 判断标准：检索全部可能的上位法依据，均未发现授权规范
- 与"适用法律错误"的区分：后者引用了错误的法条；本项是完全没有法条可引用

**(3) 内容客观上不可能实施**
- 典型：征收已不存在的地块、对已死亡的人作出处罚、要求完成物理上不可能的行为
- 判断标准：客观物理可能性，不考虑行政机关主观意图

**(4) 其他重大且明显违法情形（兜底条款）**
- 典型：严重违反法律禁止性规定、完全跳过基本程序且实体严重错误
- 适用限制：须同时满足"重大"与"明显"双要件，不可扩大解释

### 3.2 "重大"与"明显"双要件

| 要件 | 标准 | 判断方法 |
|---|---|---|
| 重大 | 违法性影响行政行为存续或核心内容 | 学理：影响"存续 vs 内容"/"实质 vs 形式" |
| 明显 | 违法性显而易见，普通公民亦能识别 | 学理："普通人标准"/"显而易见标准" |
| 双要件 | 必须同时满足 | 累积适用，缺一不可 |

**反对说位置**：
- "明显"标准——严格说（普通公民识别）vs 宽松说（法律专业人士识别），本程式从严格说
- 程序违法是否构成无效——通说认为仅在极严重时（完全跳过基本程序 + 实体严重错误）才构成，本程式从通说

### 3.3 与撤销之诉的界限

| 维度 | 确认无效之诉 | 撤销之诉 |
|---|---|---|
| 违法程度 | 重大且明显 | 一般违法 |
| 起诉期限 | 无限制 | 6 个月/15 日 |
| 法律效果 | 自始无效 | 自判决撤销之日起失效 |
| 第三方信赖 | 通常无信赖保护 | 必要时考虑信赖保护 |
| 法律依据 | "确认无效判决"条款 + 解释"无效情形列举" | "撤销判决要件"条款 |

**诉讼转换**：原告起诉确认无效但法院判断为一般违法 → 释明由原告选择是否变更诉讼请求为撤销之诉。

### 3.4 无效确认无起诉期限限制

- 无效行政行为自始无效，不因时间经过而获得合法性
- 原告可在任何时候请求确认无效
- 但迟延起诉可能影响赔偿请求的范围（与有过失/减损义务）

### 3.5 检视程式骨架

```
（二）确认无效之诉合法性审查
  1. 全案总起句
  2. 重大且明显违法判定（无效情形四类）
    (1) 主体不适格  (2) 无法律依据  (3) 客观不可能  (4) 其他重大明显违法
  3. "重大"与"明显"双要件判定
  4. 后果与法律效力
    (1) 自始无效效果  (2) 期间效果清理  (3) 信赖保护
  5. 赔偿请求联动（如有从诉）
  6. 缺陷分级与判决类型预判
```

## §四 与其他诉讼类型的聚合

### 4.1 撤销 + 确认违法（备位）

原告主请求撤销，备位请求确认违法。法院审查后：
- 撤销成立 → 判决撤销，不处理备位
- 撤销不成立（已无可撤销内容）但违法 → 判决确认违法

### 4.2 确认违法 + 国家赔偿

确认违法常作为赔偿前置条件（[赔偿先行程序条款]）。两个请求需分别审查：
- 确认违法成立 → 触发赔偿要件之一
- 赔偿请求需独立审查：损害事实 + 因果关系 + 损害金额

### 4.3 确认无效 + 返还/恢复

确认无效后，行政行为自始无效，产生返还/恢复请求：
- 行政机关已收取的款项须返还（含利息）
- 相对人已履行的义务须恢复原状
- 第三人善意取得的财产不予追索

## §五 典型场景速查表

> 下表"判决依据"列采用语义化命名。

| 场景 | 诉讼类型 | 判决依据 | 要点 |
|---|---|---|---|
| 已拆除房屋的强拆行为 | 确认违法 | "确认违法判决"条款 第 1 项 | 已执行完毕不可逆转，撤销无意义 |
| 已执行完毕的行政拘留 | 确认违法 | "确认违法判决"条款 第 1 项 | 人身自由限制已消耗，撤销无法恢复 |
| 程序轻微瑕疵的许可决定 | 确认违法 | "确认违法判决"条款 第 2 项 | 未告知救济途径但未影响实体权利 |
| 无主体资格的行政决定 | 确认无效 | "确认无效判决"条款 + 解释"无效情形"第 1 项 | 内设机构擅自发文，自始无效 |
| 无任何法律依据增设义务 | 确认无效 | "确认无效判决"条款 + 解释"无效情形"第 2 项 | 无授权即要求报送信息 |
| 征收已不存在的地块 | 确认无效 | "确认无效判决"条款 + 解释"无效情形"第 3 项 | 内容客观不可能 |
| 行政机关已自行纠正 | 确认违法 | "确认违法判决"条款 第 3 项 | 被告已改变原行为，确认违法保留赔偿通道 |

### 判决类型预判规则

```
要件审查结果 = ?
  ├── 行政行为合法 → 驳回诉讼请求
  ├── 行政行为违法 + 仍可撤销 → 释明转为撤销之诉
  ├── 行政行为违法 + "确认违法判决"情形 → 确认违法判决
  ├── 重大且明显违法（"确认无效判决"条款 + 无效情形列举） → 确认无效判决
  └── 重大但不明显 / 明显但不重大 → 释明转为撤销之诉
```
