# 履职之诉与不作为之诉（Performance Suit & Omission Suit）

履职之诉与不作为之诉共同请求行政机关履行法定职责。本文件采用**请求权审查四要件**范式（对应 `methodology/case-router.md §零` 轨道 B），不调用六要素违法性审查骨架。

> **法条锚定单点源铁律**：所有法条引用一律使用 `[语义名称]` 占位符，禁止出现具体条号。语义名称→现行编号的映射由 `SKILL.md §6.5 法条锚定表` 唯一维护。

---

## §一 定位与轨道选择

**履职之诉**：原告请求法院判令行政机关履行法定职责，作出其应当作出的特定行政行为。诉讼目标不是"撤销已有行为"，而是促使行政机关"从无到有"地作出行为。法律依据为 [履职诉讼期限条款] + [履行判决条款]。

**不作为之诉**：履职之诉的子类型，行政机关消极沉默时适用。审查框架与履职之诉共用本文件四要件。

**与撤销之诉的关键区分**：
- 行政机关已作出明确**拒绝决定** → 撤销之诉（请求撤销拒绝决定，按 `case-router.md §零` A 轨）；
- 行政机关**应作未作 / 仅程序性回应** → 履职/不作为之诉（按本文件 B 轨）。

## §二 专属可受理性要点（嵌入 8 闸门 G7 / G8）

履职之诉除常规 8 闸门外，对 G7（起诉期限与形式要件）、G8（诉的利益）有专属审查点：

### 2.1 原告已提出申请

履职之诉以原告已向行政机关提出申请为原则。申请须满足：意思表示明确（请求做什么、范围多大）、方式合规（书面/口头/电子，依单行法规定）、提交至有权机关。**例外**：主动履职型职责（如知悉违法行为应予查处、突发事件应予应对）无需申请即触发。

### 2.2 法定履行期限届满

| 行为类型 | 法定期限 | 语义锚定 |
|---|---|---|
| 行政许可（一般） | 20 日（可延长 10 日） | [许可决定期限条款] |
| 政府信息公开 | 20 工作日（可延长 20 工作日） | [答复期限条款] |
| 投诉举报回应 | 60 日（一般） | 单行法 / 投诉举报办法 |
| 无法定期限 | 2 个月（一般起诉期限条款兜底） | [起诉期限条款] |

期限自行政机关收到申请之日起算；材料不齐备的，自合法补正之日起算。行政机关仅口头回应"在处理"不构成实质处理，不阻断不作为认定。

### 2.3 起诉期限

法定履行期限届满后 **6 个月**内起诉（[履职诉讼期限条款]）；行政机关已明确拒绝的，自收到拒绝决定之日起 6 个月内起诉（但此种情形应走撤销之诉）。

### 2.4 诉的利益

履行仍有意义：① 给付未迟延至不可挽回；② 标的仍然存在；③ 履行不违反现行法律。履行已无意义 → 诉的利益消灭，可转为确认违法 + 赔偿。

## §三 请求权审查四要件（B 轨核心）

### 3.1 要件一：请求权基础（"原告依据什么法律规范请求？"）

**总起**：审查原告的履行请求权是否有明确的法律基础。

**三类来源**：

| 来源 | 内容 | 典型情形 |
|------|------|---------|
| **法定职责** | 单行法明文赋予行政机关的具体职责 | [许可决定颁证条款]、[投诉举报处理条款] |
| **协议约定** | 行政协议中约定的行为义务 | 非金钱给付义务可走履职之诉，金钱给付优先走给付之诉 |
| **先行行为** | 行政机关先行行为创设的后续义务 | 先扣押财物 → 及时处理和返还义务 |

**关键判别**：必须定位到具体条文。仅有"组织法上的概括职权"（如"工商局监管市场"）不构成请求权基础，须有"作用法上的具体职责条款"。

**与保护规范理论的衔接**：法律规范仅赋予行政机关职权而未赋予原告主观公权利的，原告无履行请求权（如纯公益执法）。详见 `../methodology/interpretation-toolkit.md §三 保护规范理论`。

### 3.2 要件二：请求权要件涵摄（"法律条件 + 事实条件是否成立？"）

将原告所主张的请求权法律构成要件逐项与案件事实涵摄：

**法律条件**：请求权基础条文中规定的实体条件（如"申请人提交全部材料""经营场所符合规定"）。

**事实条件**：法律条件对应的事实要素（原告已提交什么材料、是否合规、是否满足专项要求）。

**举证责任**：履职之诉中原告对"申请已提出 + 法律条件成立"承担举证责任；行政机关对"合法事由抗辩"承担举证责任。

**涵摄四步法标准句式**：

> **[总起]** 原告的颁证请求权是否成立，应审查申请人是否满足 [许可决定颁证条款] 之实体条件。
>
> **[定义]** 依 [许可决定颁证条款]，符合下列条件的应予颁发：① 申请材料齐备；② 经营场所符合规定；③ 申请人具备相应资格。
>
> **[归入]** 本案中：① 原告于 X 月 X 日提交全部申请材料，材料齐备；② 经营场所经现场勘验符合规定；③ 原告具备 XX 资格证书。
>
> **[结论]** 原告颁证请求权成立。

### 3.3 要件三：履行可能性（"行政机关能否履行？"）

审查履行客观、法律、经济上的可能性：

| 可能性维度 | 审查内容 |
|-----------|---------|
| **客观可能** | 人员 / 设备 / 时间条件是否具备 |
| **法律可能** | 履行不违反其他法律规定 |
| **经济合理** | 成本不显著高于行政利益 |

履行不可能的，不得判决履行，应转为确认违法 + 赔偿。

### 3.4 要件四：抗辩事由 + 裁量收缩判定

**A. 行政机关合法抗辩事由**：
- 不可抗力（自然灾害 / 战争等客观无法履职）；
- 申请要件不齐备且已合法告知补正（依 [一次性告知补正条款]，须 5 日内一次性告知，反复要求补正不构成合法事由）；
- 已转送有权机关且无义务自行处理；
- 其他法定豁免事由（如 [重复申请处理条款]）；
- **不构成合法事由**：行政资源限制（"工作量大""人员不足"）、行政机关内部沟通不畅。

**B. 裁量空间审查（关键分流）**：

```
裁量空间判定
   │
   ├─ 法律规定"应当 + 具体内容"（羁束行为）
   │     → 行政机关无裁量空间，法院可直接判决履行特定内容
   │
   ├─ 法律规定"可以 + 多种选择"（一般裁量）
   │     → 法院通常仅判决"责令限期作出决定"，不替代行政机关
   │
   └─ 一般裁量 + 裁量收缩到零情形
         → 法院可直接判决履行特定内容
```

**裁量收缩到零的四要件**：
1. 原告的合法权益面临紧迫危险；
2. 只有该行政机关有能力排除危险；
3. 其他救济途径不可期待；
4. 行政机关明知危险存在而未行动。

## §四 "已部分履职" vs 实质履职三级判定

行政机关常以"已采取措施"抗辩。审查时按下表逐层判定：

| 判定层级 | 判定标准 | 典型情形 | 法律评价 |
|---------|---------|---------|---------|
| **形式履职**（= 仍属不作为） | 仅有程序性回应，未触及实体处理 | 仅口头答复"在处理"、仅开会研讨、仅约谈告诫、仅发通知/文件、仅转交下级而无监督 | 构成不作为，应继续履行 |
| **部分履职**（部分不作为） | 对部分请求事项处理，遗漏其他 | 答复 A 事项遗漏 B 事项；查处 B/C 主体遗漏被举报的 A 主体；罚款但未责令改正 | 对遗漏部分构成不作为 |
| **实质履职**（不构成不作为） | 对全部请求事项作出实体处理，且处理措施达到法定深度 | 依法调查 + 作出处罚 + 执行到位；或裁量已合理行使 | 不构成不作为，驳回请求 |

**形式履职 5 个红旗**（任一触发即倾向认定为不作为）：
1. 措施未指向诉争对象（检察建议指向 A，执法针对 B/C）；
2. 措施未达法定深度（应处罚而仅约谈）；
3. 措施未产生实效（违法行为仍在持续）；
4. 选择性执法（同类主体差别对待，无正当理由）；
5. 措施违反比例原则（巨额违法仅处最低罚款）。

## §五 投诉举报人原告资格三要件测试

**三要件**（基于保护规范理论 + 保护规范理论引入裁判规则，详见 `../methodology/interpretation-toolkit.md §三`）：

1. **法律规范是否赋予投诉举报人主观公权利**（保护规范理论）；
2. **投诉举报事项是否涉及投诉人自身合法权益**（区别于一般公益性举报）；
3. **行政机关的处理 / 不处理是否对投诉人权益产生实际影响**。

**典型判别**：
- 消费者权益保护型投诉（如食品安全、消费欺诈）→ 一般具备原告资格；
- 普通公益举报（如举报他人偷税）→ 一般不具备原告资格；
- 利害关系人型举报（邻居举报、同业举报）→ 须个案审查保护规范。

## §六 判决类型映射

| 情形 | 判决类型 | 法条 |
|---|---|---|
| 请求权要件成立 + 裁量收缩到零 | 直接履行判决（明确内容 + 期限） | [履行判决条款]直接履行项 |
| 请求权要件成立 + 仍有裁量空间 | 责令限期履行判决 | [履行判决条款]责令履行项 |
| 履行已无可能 / 无意义 | 确认违法判决 | [确认违法判决条款] |
| 涉及金钱给付且数额明确 | 直接判决给付 | [给付判决条款] |
| 不作为 + 造成损失 | 责令履行 + 行政赔偿 | [履行判决条款] + [行政赔偿/补偿判决条款] |
| 不构成不作为 / 合法事由成立 | 驳回诉讼请求 | [驳回诉讼请求条款] |

**判决期限**：直接履行判决参照法定期限或合理期限；责令履行判决自判决生效之日起算。

**判决执行**：行政机关拒不履行的，法院可采取 [强制执行措施条款] 规定的措施（划拨 / 按日罚款 / 公告 / 司法建议）。

## §八 反向错误清单（D4 自检）

litigation / pre-enforcement 场景下，履职之诉的常见错配点：

- 是否将"行政机关已明确拒绝"误作不作为审查（应走撤销之诉）？
- 是否漏识别"申请未到达有权机关"导致期限错算？
- 是否将"形式履职"误认为"实质履职"导致漏判不作为？
- 是否将"羁束行为"误作"一般裁量"导致漏判直接履行？
- 是否漏查投诉举报人原告资格三要件？
- 是否漏识别"裁量收缩到零"导致判决类型错配（应直接履行误判责令履行）？
