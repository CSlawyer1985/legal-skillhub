# 特殊场景（复议共同被告 + 行政协议 + 规范性文件附带审查）

> 本文件处理三类行政诉讼特殊场景。它们不是独立诉讼类型，而是叠加在主诉骨架上的"修饰器"——改变被告结构、法律适用或审查范围。

## §一 复议机关共同被告

> **法律更新说明**：本节已依据 2023 年修订的《行政复议法》（2024-01-01 施行）全面更新。新法在复议管辖、复议前置范围、决定类型体系、复议不加重原则、程序分类等方面均有重大变化，直接影响复议后行政诉讼的被告结构与审查标准。

### 1.1 定位

经行政复议的案件，被告结构因复议结果而异：
- **复议维持**（见 [复议决定类型条款]，对应"维持"分支） → 原机关 + 复议机关为**共同被告**（[复议机关共同被告条款]）
- **复议改变**（见 [复议决定类型条款]，对应"变更/撤销"分支） → **仅复议机关**为被告（[被告资格条款] 反向解释 + 行诉解释复议改变识别条款）
- **复议不作为** → 原告可选：起诉原行为（原机关为被告）或起诉复议不作为（复议机关为被告）
- **复议驳回申请**（受理后发现不符合条件、无法定职责或已履行）→ 视为维持，**共同被告**

**"维持"与"改变"的精确识别（行诉解释复议改变识别条款）**：

"维持"包括：驳回复议申请（除起诉期限届满外）、确认原行为合法、虽在事实/证据/依据方面作出补正但未改变结论。

"改变"包括：变更行政行为、撤销/部分撤销并可责令重作、确认违法。

"补正"不构成改变：仅就引用法条、表述方式、附加理由作技术性修正，未影响定性或结论。

**新法复议管辖变革（[复议管辖条款]）**：2023 新法统一复议管辖至本级人民政府——对本级政府工作部门作出的行政行为不服的，向本级人民政府申请复议（取消旧法"部门→上一级部门"双轨制）。例外：海关、金融、外汇、税务、国安等垂直领导机关仍向上一级主管部门申请。此变革导致复议机关几乎统一为同级政府，共同被告中复议机关一方的识别更为简化。

**新法复议前置范围扩张（[复议前置情形条款]）**：

| 序号 | 复议前置情形 | 旧法对应 |
|---|---|---|
| 1 | 对当场作出的行政处罚不服 | 新增 |
| 2 | 对侵犯已依法取得的自然资源所有权/使用权的决定不服 | 旧法保留 |
| 3 | 认为行政机关未履行 [复议受案范围条款] 规定的法定职责 | 新增 |
| 4 | 申请信息公开被拒 | 新增 |
| 5 | 法律、行政法规规定的其他情形 | 兜底 |

**审查关注**：复议前置案件中，复议机关不予受理/驳回/超期不答复的，申请人可在收到决定书之日起或复议期限届满之日起 15 日内起诉（[复议申请期限条款] 衔接规则）。此时法院须先审查复议机关是否依法受理，然后再审查原行为。

### 1.2 复议维持场景

**被告确定**：共同被告（原机关 + 复议机关）。

**审查范围**（行诉解释共同被告审查范围条款）：法院应**同时**审查原行政行为合法性与复议决定合法性。

**复议决定内容须对标新法决定类型体系**：[复议决定类型条款] 建立了完整的复议决定类型体系（变更/撤销/确认违法/责令履行/确认无效/维持/驳回请求），法院审查复议决定时，须判断复议机关是否选择了正确的决定类型——例如原行为属"程序轻微违法但不影响实体"，复议机关应确认违法而非维持，若复议机关错误维持，则复议决定本身构成"适用法律错误"。

**责任分配**：

| 情形 | 责任分配 | 判决类型 |
|---|---|---|
| 原行为违法 + 复议维持 | 二者共担 | 撤销原行为 + 撤销复议决定 |
| 原行为合法 + 复议程序违法 | 仅复议机关担责 | 撤销复议决定 + 维持原行为 |
| 原行为合法 + 复议选错决定类型 | 仅复议机关担责 | 撤销复议决定 |
| 双重违法 | 二者均担责 | 一并撤销 |
| 双重合法 | 无 | 驳回诉讼请求 |

**举证责任分配**：
- 原机关对原行政行为合法性承担举证
- 复议机关对复议程序合法性承担举证
- [复议审理程序条款] 明确：被申请人对其作出的行政行为的**合法性、适当性**负举证责任（较旧法增加"适当性"）
- 被申请人不按期提交证据/依据的，**视为没有证据、依据**（详见 [复议审理程序条款] 后段）

**赔偿责任**（行诉解释共同被告赔偿责任条款）：
- 均违法 → 共同赔偿
- 仅原行为违法 → 原机关赔偿
- 仅复议决定违法 → 复议机关赔偿

### 1.3 复议改变场景

**被告确定**：仅复议机关为被告。

**审查重心**：复议决定改变的合法性——改变事实认定的证据基础、改变法律适用的依据、变更处理结果的法律依据。

**"复议不加重"原则**（[复议决定类型条款] "变更"分支但书，已从旧《实施条例》升格为法律条款）：
- 行政复议机关不得作出对申请人更为不利的变更决定
- 唯一例外：第三人提出相反请求的
- 与旧法差异：旧《实施条例》尚有"依法律规定加重"例外，新法将例外限缩为仅第三人请求

**撤销复议决定后原行政行为的效力恢复规则**：
- 复议决定违法被撤销 → 原行政行为效力恢复
- 但原行政行为本身也违法时 → 法院可责令原行政机关重新作出

**责令原行政机关重作的路径**：
- 路径 A：撤销复议决定 + 恢复原行为效力（原行为合法时）
- 路径 B：撤销复议决定 + 责令复议机关重新作出复议决定（复议程序违法但实体未判定时）

**新法责令重作的限制**（[复议决定类型条款] "撤销"分支重作限制）：复议机关责令被申请人重新作出行政行为的，被申请人不得以同一事实和理由作出与被申请行政复议的行政行为相同或基本相同的行政行为，但复议机关以违反法定程序为由撤销的除外。

### 1.4 复议程序审查要点

**普通程序 vs 简易程序**（[复议审理程序条款] 程序分类）：

| 审查维度 | 普通程序 | 简易程序 |
|---|---|---|
| 适用条件 | 默认适用 | 当场行为/警告/通报批评/款额≤3000 元/信息公开 |
| 答复期限 | 收到申请书副本 10 日内 | 收到申请书副本 5 日内 |
| 审理方式 | 应当听取当事人意见；重大疑难复杂案件应当听证 | 可以书面审理 |
| 审理期限 | 60 日，延长 ≤30 日（参见 [复议决定期限条款]） | 30 日（参见 [复议决定期限条款] 简易程序例外） |

**审查关注**：复议机关是否适用了正确的程序类型——应适用普通程序却适用简易程序，可能剥夺当事人意见陈述权和听证权，构成程序违法。

**行政复议委员会咨询意见**（[复议审理程序条款] 复议委员会咨询子规则）：县级以上政府应建立行政复议委员会。涉及案情重大疑难复杂、专业性技术性较强、省级政府受理的对本机关行为的复议等情形，行政复议机构**应当**提请复议委员会提出咨询意见。复议机关应将咨询意见作为**重要参考依据**。

**审查关注**：复议机关审理重大疑难案件是否依法提请了复议委员会咨询。未提请的，是否影响复议决定的实体正确性——若实体结果正确，可能属于"程序轻微违法"；若实体结果存疑，可能构成程序违法。

### 1.5 典型场景

| 场景 | 被告 | 判决类型 |
|---|---|---|
| 复议维持后起诉（最常见） | 共同被告 | 一并撤销/驳回 |
| 复议改变后起诉 | 仅复议机关 | 撤销复议决定 + 恢复原行为 |
| 复议不作为后起诉 | 原告选择 | 责令履行（[履行判决条款]） |
| 复议改变 + 违反不加重原则 | 仅复议机关 | 撤销复议决定 |
| 复议前置不予受理后起诉 | 复议机关 | 责令受理或直接审查原行为 |
| 复议选错决定类型 | 共同被告或仅复议机关 | 撤销复议决定 |

### 1.6 检视程式骨架（共同被告改造）

```
（二）可证立性审查（共同被告情形）
  1. 全案总起句
  2. 原行政行为合法性审查（适用主诉骨架）
  3. 复议决定合法性审查
    (1) 复议机关主体合法性（[复议管辖条款] 统一管辖 + 职权范围）
    (2) 复议程序合法性（普通/简易程序选择 + 受理/审理/听证/听取意见/决定/期限）
    (3) 复议决定类型正确性（[复议决定类型条款] 决定类型体系 + 是否选对决定类型）
    (4) 复议决定内容合法性（全面审查义务 + 合法性与适当性双重审查 + 维持决定实体合法性）
    (5) [如涉及] 复议委员会咨询程序（是否依法提请）
  4. 责任分配
  5. 缺陷分级与判决类型预判
```

## §二 行政协议之诉

### 2.1 定位

行政协议：行政机关为实现行政管理或公共服务目标，与公民/法人协商订立的具有行政法上权利义务内容的协议（[行政协议案件适用条款]）。

**典型类型**：政府特许经营协议（PPP/BOT）、国有土地使用权出让合同、征收补偿协议、保障性住房买卖合同。

**协议性质识别三要件**：
- ① 行政机关一方（公权力主体）
- ② 行政管理或公共服务目标
- ③ 具有行政法上权利义务内容
- 三要件全满足 → 行政协议；全不满足 → 民事合同；部分满足 → 个案判断

### 2.2 诉讼类型分支

| 诉讼请求 | 判决类型 | 判决依据 |
|---|---|---|
| 确认协议有效/无效 | 确认判决 | [行政协议案件适用条款] 确认判决分支 |
| 请求继续履行 | 继续履行判决 | [行政协议案件适用条款] 继续履行分支 |
| 请求变更/解除 | 变更/解除判决 | [行政协议案件适用条款] 变更解除分支 |
| 请求赔偿/补偿 | 给付判决 | [行政协议案件适用条款] 给付分支 |
| 请求撤销单方变更/解除决定 | 撤销判决 | [撤销判决要件条款] |

> 具体条号统一参见 SKILL.md §6.5 法条锚定表。

### 2.3 审查要点（C 轨协议四阶）

本节按 `../methodology/case-router.md` §零 0.2 / 0.3 C 轨四阶口径展开：协议成立 → 协议效力 → 履行与变更 → 救济选择。

**第一阶 · 协议成立**：
- 主体合法：行政机关在职权范围内签订
- 程序合法：招标/听证/公示/决议程序
- 形式合法：书面形式

**第二阶 · 协议效力**：
- 内容合法：不违反法律强制性规定（含《民法典》合同效力条款）
- 真实意思：无欺诈/胁迫/重大误解等可撤销事由
- 无效情形识别：违反行政法强制规定、损害公共利益、超越法定职权

**第三阶 · 履行与变更**（[行政协议案件适用条款] 单方变更解除审查规则）：
- 公共利益必要性：须有具体公益需要的证据
- 比例原则：变更/解除是否必要、是否均衡
- 信赖保护：相对人已基于协议产生的信赖利益应予保护
- 补偿：合法变更/解除应给予合理补偿

**第四阶 · 救济选择**：
- 违约 vs 违法二分：行政机关违反协议约定 = 违约（民法典合同编路径）；行政机关违法行使优益权 = 违法（行政法路径）
- 双重适用结构：公法部分（信赖保护/公益变更/比例原则）→ 行政法；私法部分（履行/违约/解除）→ 《民法典》合同编
- 平行适用说（通说）：各自调整自己范围，必要时叠加

### 2.4 典型场景

- PPP 项目协议中政府单方缩减用地 → 审查公益必要性 + 比例原则 + 信赖保护
- 征收补偿协议签订后政府拒绝履行 → 继续履行判决
- 政府以公共利益为由解除特许经营协议 → 审查解除合法性 + 补偿
- 协议性质争议（政府办公房屋租赁合同 vs 保障房买卖合同）→ 三要件识别

## §三 规范性文件附带审查

### 3.1 定位

不能单独起诉规范性文件。公民/法人在对行政行为提起诉讼时，可一并请求对该行为所依据的规范性文件进行审查（[附带审查请求条款]）。

**可附带审查**：国务院部门/县级以上地方政府及其工作部门/乡镇政府制定的规范性文件（"红头文件"）。

**不可附带审查**：行政法规、部门规章/地方政府规章（走《立法法》备案审查）、法律法规、内部管理性文件。

### 3.2 审查范围

- 规章以下的规范性文件（识别五要件：行政机关制定 + 普遍约束力 + 反复适用 + 对外效力 + 非规章）
- 必须是作为被诉行政行为依据的文件
- 审查插入主诉实体要件中"法律适用"环节：若文件不合法 → 主诉行为失去合法实体依据

### 3.3 审查标准

**(1) 制定主体合法性**：是否在职权范围内制定、是否经集体决策。

**(2) 制定程序合法性**：调研论证、征求意见、合法性审查、集体讨论、公布。
- **强制公布原则**："未经公布不得作为行政行为依据"（硬性闸门）

**(3) 内容合法性**（最核心）：
- 是否与上位法抵触（直接冲突/扩大限制权利/缩小保护范围）
- 是否违法增设义务/减损权利（无法律法规规章依据时）——立法法规章设定边界条款：规章尚不可，规范性文件更不可
- 是否违反法律保留原则（绝对保留事项如限制人身自由不得规定）

### 3.4 裁判后果

- **不直接撤销**：法院仅"不予适用"，不直接撤销文件（[附带审查司法处置条款]）
- 文件不合法 → 不作为认定行政行为合法的依据 → 主诉行为因"适用法律错误"（[撤销判决要件条款] 适用法律错误分支）被撤销
- 法院可向制定机关提出处理建议（[附带审查司法处置条款] 处理建议子规则）

## §四 行政公益诉讼（检察机关作为起诉人）

本节主旨：行政公益诉讼是行诉法 [公益诉讼受案范围条款] 设立的特别诉讼类型，由检察机关作为"公益诉讼起诉人"提起，针对行政机关违法行使职权或不作为致使国家利益或社会公共利益受侵害的情形。其审查骨架在履职之诉/撤销之诉基础上叠加**检察建议前置程序**与**公共利益受侵害**两项专属要件。

### 4.1 法定适用领域与兜底扩张

| 领域 | 法律依据 |
|------|---------|
| 生态环境和资源保护 | [公益诉讼受案范围条款] 列举 |
| 食品药品安全 | [公益诉讼受案范围条款] 列举 |
| 国有财产保护 | [公益诉讼受案范围条款] 列举 |
| 国有土地使用权出让 | [公益诉讼受案范围条款] 列举 |
| 英雄烈士保护 | 《英雄烈士保护法》专项条款 |
| 未成年人保护 | 《未成年人保护法》专项条款 |
| 安全生产 | 《安全生产法》专项条款 |
| **个人信息保护** | **《个人信息保护法》公益诉讼专项条款**（新增） |
| 反垄断/反电信网络诈骗/妇女权益保障/无障碍环境建设等 | 单行法专项授权 |

**识别规则**：单行法明确授权检察机关提起公益诉讼的领域 → 直接适用；未列举但属于"公共利益"范畴的 → 通过 [公益诉讼受案范围条款] "等"字兜底扩张（实务中需谨慎论证）。

### 4.2 检察机关原告资格

检察机关以"公益诉讼起诉人"身份提起，**无需适用保护规范理论**（区别于普通原告适格审查）。其资格源于宪法与组织法赋予的法律监督职能 + [公益诉讼受案范围条款] 的特别授权。

审查要点（形式审查即可）：
- 起诉主体是人民检察院（基层/市级依管辖规则确定）
- 已在履行职责中发现线索（非主动"挑案"）
- 已完成诉前程序（见 §4.3）

### 4.3 诉前程序（检察建议前置，硬性闸门）

**法定流程**：

```
发现线索 → 立案调查 → 制发检察建议 → 等待 2 个月回复期 →
  ├── 行政机关依法履职 → 终结审查（不起诉）
  └── 行政机关不依法履职 → 公共利益仍受侵害 → 提起诉讼
```

**检察建议内容要求**（[公益诉讼诉前检察建议条款]）：
- 载明违法事实与证据
- 指明法律依据
- 提出具体整改建议（不得泛泛而谈）
- 载明 2 个月回复期限

**2 个月回复期的计算与例外**：
- 自检察建议送达之日起算
- 紧急情形（公共利益正在急速受损）可缩短回复期
- 行政机关申请延期且有正当理由的，可适当延长

### 4.4 "未依法履行职责"的认定标准（核心争点）

依据两高《检察公益诉讼解释》"未依法履行职责"认定条款，行政机关虽已回复但存在以下情形之一的，应认定为"不依法履行职责"：

| 认定情形 | 典型表现 |
|---------|---------|
| **未全面整改** | 检察建议指向 A 主体，仅查处 B/C 主体，遗漏 A |
| **形式整改** | 仅开会、约谈、发文件，无实质执法动作 |
| **整改无效** | 采取措施后违法行为仍在持续 |
| **逾期不回复** | 2 个月届满未书面回复 |
| **回复内容不实** | 声称已整改但证据显示未整改 |

**形式履职 vs 实质履职的判断**（实务裁判规则）：

- **"约谈不罚"≠ 依法履职**：约谈属行政指导，不替代《行政处罚法》/《个人信息保护法》等规定的行政处罚职责
- **"选择性执法"= 未全面履职**：对同类违法主体差别对待（抽查 A 不查 B），违反平等原则
- **"整改无效"= 仍不履职**：9 月后仍有同类违法事实发生，证明先前措施未达实质效果
- **"未将检察建议指向的主体纳入执法范围"**：构成对诉前程序的规避

### 4.5 国家利益/社会公共利益受侵害的持续状态

起诉时公共利益受侵害状态必须仍在持续，否则诉讼失去必要性。审查要点：

- **行为持续型**：违法行为仍在发生（如仍在泄露信息、仍在排污）
- **结果持续型**：违法行为虽停止但损害后果未消除（如污染未修复、信息未删除）
- **风险持续型**：存在高度再犯风险（如制度漏洞未修补）

**本案适用**：A 医院 2024 年 9 月仍有患者投诉信息泄露 → 行为持续型 + 结果持续型双要件成立。

### 4.6 诉讼请求结构与判决类型

**典型双请求组合**（履职型公益诉讼）：

```yaml
诉讼请求:
  R1_确认违法:
    内容: 确认被告对 [违法主体] 的 [违法行为] 未依法履行监管职责的行为违法
    性质: 确认之诉（附属）
  R2_判令履职:
    内容: 判令被告在 [期限] 内对 [违法主体] 依法履行查处职责
    性质: 履职之诉（主请求）
```

**判决类型对应**：

| 审查结论 | 判决类型 | 判决依据 |
|---------|---------|------|
| 确认不履职违法 + 裁量收缩到零 | 直接履行判决（明确履职内容） | [履行判决条款] 直接履行分支 |
| 确认不履职违法 + 仍有裁量空间 | 责令履行判决（限期作出决定） | [履行判决条款] 责令履行分支 |
| 履职已无意义（损害不可逆） | 确认违法判决 + 可并提赔偿 | [确认违法判决条款] |

> 具体条号统一参见 SKILL.md §6.5 法条锚定表。

### 4.7 检视程式骨架（行政公益诉讼叠加）

```
（二）可证立性审查（行政公益诉讼 · 履职型）
  1. 全案总起句
  2. 诉前程序合法性（检察建议送达 + 2 个月届满 + 未依法履职认定）  ← 专属要件
  3. 公共利益受侵害状态持续（行为/结果/风险三型）                   ← 专属要件
  4. 请求权基础（行政机关法定监管职责）
  5. 行政机关未履行（形式履职 vs 实质履职深度审查）
  6. 履行仍有意义
  7. 裁量权与裁量收缩（是否收缩到零 → 决定判决类型）
  8. 判决类型预判
```

### 4.8 典型场景

| 场景 | 起诉主体 | 关键争点 | 判决走向 |
|------|---------|---------|---------|
| 环保部门对污染企业未依法查处 | 检察院 | 已罚款但未责令整改是否属"未依法履职" | 责令继续履职 |
| 市场监管部门对食药违法放任 | 检察院 | 整改无效（仍销售问题产品） | 责令履职 + 明确处罚 |
| 卫健委对患者信息泄露未查处 | 检察院 | "约谈+出台规范"是否替代行政处罚 | 责令履职（裁量未全收缩） |
| 自然资源部门对国有土地出让金欠缴未追缴 | 检察院 | 未催缴 = 未全面履职 | 直接履行（裁量收缩到零） |

## §五 四类特殊场景的聚合指引

### 5.1 复议 + 规范性文件附带审查

复议维持案件中，原行政行为所依据的规范性文件可能是复议机关审查时应当发现但未发现的问题。审查路径：
- 先审查规范性文件合法性（附带审查）
- 若文件不合法 → 原行为失去依据 → 复议维持决定也失去基础
- 一并撤销原行为 + 复议决定

### 5.2 行政协议 + 规范性文件依据

行政机关单方变更/解除协议时援引规范性文件作为依据：
- 附带审查该规范性文件
- 若文件不合法 → 单方变更/解除失去依据 → 确认违法/撤销

### 5.3 复议 + 行政协议

复议机关对涉及行政协议的争议作出复议决定：
- 共同被告场景：同时审查原行为（协议争议处理）+ 复议决定
- 协议之诉的审查骨架与复议共同被告的审查骨架叠加适用

### 5.4 行政公益诉讼 + 规范性文件附带审查

检察机关在履职过程中发现行政行为所依据的规范性文件本身违法：
- 检察机关不能直接请求附带审查（其非行政相对人）
- 但可在诉状理由中主张规范性文件违法 → 法院依职权审查
- 文件不合法 → 行政行为失去依据 → 强化"未依法履职"认定
