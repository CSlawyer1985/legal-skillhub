# 行政裁量与论证深度审查

> 本文件统合行政法鉴定式报告中的两大核心方法论支柱——论证深度控制（写多少）与行政裁量实体审查（怎么审）。前者通过三层分类管理论证资源配置，后者通过比例原则四阶、裁量审查四步法、裁量收缩与信赖保护四个工具完成对行政裁量的全方位实体检视。

> **法条锚定单点源铁律**：本文档所有法条引用一律使用 `[语义名称]` 占位符，禁止出现具体条号。语义名称→现行编号的映射由 `SKILL.md §6.5 法条锚定表` 唯一维护。

## 一、论证深度三层分类

> 并非所有要件都需要穷尽论证。论证深度应当与争议强度和法律意义成正比。本节规定三层分类标准、诊断问题、写作模式和行政法专属深度调控规则。

### 1.1 三层分类

| 层级 | 特征 | 论证模式 | 典型篇幅 |
|------|------|---------|---------|
| 第一层 | 明显成立/不成立 | 裁判式一句话 | 1-2 句 |
| 第二层 | 存在合理争议 | 标准涵摄四步法 | 1-2 段（150-400 字） |
| 第三层 | 核心争议焦点 | 深度鉴定式 = 涵摄 + 法律解释 + 学说争议 + 反对说回应 | 多段（600-1500 字） |

### 1.2 四项诊断问题（Q1-Q4）

判断某一要件属于哪一层级时，逐项回答以下四个问题：

| 问题 | 第一层（明显） | 第二层（争议） | 第三层（核心） |
|------|-------------|-------------|-------------|
| Q1：案件事实是否落入要件文义的核心范围？ | 是（或明显不是） | 边缘地带 | 双方各执一词 |
| Q2：一个合理的法律人能否不假思索地把握该要件含义？ | 是 | 有分歧但可预见 | 重大分歧 |
| Q3：该要件是否存在双方实质争议？ | 无争议 | 有合理争议 | 核心争议焦点 |
| Q4：该要件的结论是否决定全案走向？ | 否 | 可能 | 是 |

**判定规则**：Q1-Q4 全部指向"第一层"→ 第一层；任一项指向"第三层"→ 第三层；其余→ 第二层。

### 1.3 两种写作模式

#### 1.3.1 裁判式——用于第一层

直接给出结论 + 简要理由，不展开假设性论证。

```
"被告市场监管局具有作出涉案行政处罚的法定职权，依据为[处罚法定条款]
 与市场监管部门作用法上的执法授权。[已校验]"
```

#### 1.3.2 鉴定式——用于第二层和第三层

假设性语气展开总起句 → 定义 → 归入 → 确定性结论。

第三层在标准四步之上叠加：法律解释工具箱展开（文义→体系→历史→目的）、学说争议显性化、反对说回应、类案引证。

### 1.4 混合写作原则

一份合格的行政法鉴定式报告必须同时使用两种模式——核心争点鉴定式、非核心要件裁判式。全文只有裁判式 = 论证不足；全文只有鉴定式 = 比例失调。

### 1.5 行政法核心争议典型分布

行政法的核心争议（第三层）通常聚集于以下方法论敏感节点：

- **裁量审查**：裁量逾越/滥用/怠惰的判别、比例原则四阶展开深度
- **保护规范理论**：利害关系人的原告资格、主观公权利 vs 反射利益
- **缺陷分级**：撤销 vs 确认违法 vs 确认无效的分界
- **程序瑕疵分级**：重大 vs 一般 vs 轻微程序违法
- **行政协议性质识别**：行政协议 vs 民事合同
- **规范性文件附带审查**：合法性判断标准
- **滥用职权 vs 明显不当区分**：故意非必备要件原则

而以下要件通常属"明显成立"（第一层）：当事人主体形式、行政机关法定职权来源、行政行为已成立、受案范围（典型行政行为）、管辖（无争议案件）。

### 1.6 反对说回应深度

| 反对说强度 | 回应深度 |
|-----------|---------|
| 弱反对说（明显不成立） | 一句话驳回 |
| 中等反对说（有一定道理但不影响结论） | 标准四步法展开后驳回 |
| 强反对说（判例已采纳的立场/主流学说） | 必须区分事实差异或提供充分理由 |

### 1.7 篇幅分配指引

| 要件层级 | 建议占比 |
|---------|---------|
| 第一层（明显成立/不成立） | 报告总篇幅的 10-15% |
| 第二层（标准争议） | 报告总篇幅的 25-35% |
| 第三层（核心争议焦点） | 报告总篇幅的 50-65% |

### 1.8 自检清单

- [ ] 每个要件均已按 Q1-Q4 分类为三层之一
- [ ] 第一层要件使用裁判式（未过度展开）
- [ ] 第三层要件使用完整深度鉴定式（未偷工减料）
- [ ] 全文深度分配合理（核心争点占比 50-65%）
- [ ] 反对说按强度分级回应（未回避强反对说）
- [ ] 未出现"回避性措辞"（如"此处不展开""有待进一步研究"）

### 1.9 各裁量审查模块的典型层级分布

| 模块 | 多数案件 | 核心争议案件 |
|------|---------|------------|
| 比例原则——目的正当性 | 第一层（1 句） | 第二层（目的争议时） |
| 比例原则——适当性 | 第一层（1 句） | 第二层（手段有效性争议时） |
| 比例原则——必要性 | 第二层（标准论证） | **第三层**（替代手段争议时） |
| 比例原则——均衡性 | 第二层（标准论证） | **第三层**（利益衡量争议时） |
| 裁量收缩 | 第一层（未触发时 1 句排除） | **第三层**（触发时深度展开） |
| 信赖保护——信赖基础/表现 | 第一层或第二层 | 第二层 |
| 信赖保护——值得保护 | 第二层 | **第三层**（善意争议时） |
| 信赖保护——利益衡量 | 第二层 | **第三层**（公益 vs 信赖利益冲突时） |

**篇幅占比参考**：

| 报告部分 | 建议占比 |
|---------|---------|
| 裁量审查（含比例原则四阶 + 裁量收缩） | 占可证立性的 20-30% |
| 信赖保护专项 | 占可证立性的 10-15%（如触发） |
| 比例原则四阶中核心争议阶 | 占裁量审查的 50-70% |

## 二、比例原则四阶审查

本节主旨：比例原则是行政裁量审查的核心工具，用于判断行政机关行使权力的手段与目的是否成比例。四阶审查逐层递进，任一阶不通过即比例原则不通过。

### 2.1 适用场景

比例原则在行政法案例分析中的契入点：

| 场景 | 触发条件 |
|------|---------|
| 撤销之诉裁量审查 | 发现行政机关有裁量空间时，在"裁量逾越/滥用/怠惰"之外独立审查 |
| 行政强制审查 | [强制比例条款]明文规定比例原则 |
| 行政处罚裁量 | 处罚种类与幅度的合理性审查 |
| 行政协议变更/解除 | 公共利益需要的变更是否合乎比例 |
| 信赖保护中的公益限制 | 限制信赖的公益手段是否合乎比例 |
| "明显不当"判断 | [撤销判决要件条款]"明显不当"项的四维度之一即比例原则 |

### 2.2 四阶审查程式

```
第一阶：目的正当性（Legitimate Aim）
├── 审查内容：行政行为追求的行政目的是否合法、正当
├── 判断标准：
│   ├── 目的是否有法律依据（法律保留）
│   ├── 目的是否属于行政机关的法定职责范围
│   └── 目的是否服务于公共利益
├── 涵摄句式：
│   "被告作出被诉行为追求的 [目的] 可能具有/不具有正当性。
│    依 [法律依据]，该目的属于 [法定职责/公共利益] 范畴，具有正当性。"
└── 不通过后果：比例原则整体不通过，无需审查后续三阶

第二阶：适当性（Suitability / Appropriateness）
├── 审查内容：行政机关采取的手段能否达到或促进目的实现
├── 判断标准：
│   ├── 手段与目的之间是否存在合理因果关系
│   ├── 手段是否客观上有助于目的实现（不要求完全实现）
│   └── 是否存在明显无效的情形
├── 涵摄句式：
│   "被告采取的 [手段] 可能具有/不具有适当性。
│    本案中，[手段] 与 [目的] 之间存在/不存在合理因果关系……"
└── 不通过后果：比例原则不通过

第三阶：必要性（Necessity / Least Restrictive Means）
├── 审查内容：是否存在对相对人权益侵害更小且能达到同样效果的替代手段
├── 判断标准：
│   ├── 是否存在其他能达到目的的替代手段
│   ├── 替代手段对相对人权益的侵害是否更小
│   └── 替代手段在实践中是否具有可行性
├── 涵摄句式：
│   "被告采取的 [手段] 可能不符合/符合必要性要求。
│    本案中存在/不存在侵害更小的替代手段 [替代方案]……"
└── 不通过后果：比例原则不通过

第四阶：均衡性（Proportionality stricto sensu / Balancing）
├── 审查内容：手段对相对人造成的损害与追求的行政目的是否成比例
├── 判断标准：
│   ├── 损害的严重程度（人身/财产/自由/经营等）
│   ├── 目的的重要性程度
│   ├── 损害与目的是否存在合理的比例关系
│   └── 是否存在"以炮打蚊"的明显失衡
├── 涵摄句式：
│   "被告采取的 [手段] 对原告造成的 [损害] 与追求的 [目的] 之间
│    可能成/不成比例。综合衡量 [损害程度] 与 [目的重要性]……"
└── 不通过后果：比例原则不通过 → 构成裁量瑕疵/明显不当
```

### 2.3 四阶审查的递进逻辑

四阶审查严格递进：目的不正当则无需审手段；手段不适当则无需审必要性；手段已为最小侵害则无需审均衡性。但实务中，法院经常在必要性阶或均衡性阶才发现问题，前两阶往往通过。

**论证深度指引**（参见本文件 §一）：

| 争议程度 | 四阶展开方式 |
|---------|------------|
| 明显成立（各方无争议） | 四阶各一句话带过 |
| 合理争议（双方有不同主张） | 四阶标准涵摄，重点展开争议阶 |
| 核心争议（案件成败关键） | 四阶深度展开，穷尽法律解释方法，显性展开学说分歧 |

### 2.4 比例原则的层级选择

用户可在 `.user-config.md` 选择比例原则的审查层级：

| 配置 | 审查内容 | 适用说明 |
|------|---------|---------|
| 四阶（默认） | 目的正当 + 适当 + 必要 + 均衡 | 当前中国行政法学主流立场 |
| 三阶 | 适当 + 必要 + 均衡（不单独审目的正当性） | 传统学理三阶模式 |

未配置时默认采四阶审查。同一报告内不得混用两种层级。

### 2.5 比例原则与明显不当的双通道分流

比例原则四阶与"明显不当"是两条相互独立的实体审查路径，所审对象、判决出口、举证负担均不相同。两路径正交并行，不得相互替代，更不得在同一争点上混用。

#### 2.5.1 双通道概览

| 维度 | 通道 A：比例原则四阶 | 通道 B：明显不当独立通道 |
|------|-------------------|----------------------|
| 审查性质 | 形式裁量审查（手段-目的结构性审查） | 实质合法性审查（结果合理性审查） |
| 审查对象 | 行政机关选择手段的逻辑结构 | 行政机关作出结果的合理性 |
| 切入点 | 目的→手段→侵害最小→利益均衡 | 结果是否畸轻畸重/显失公平 |
| 判决出口 | [撤销判决要件条款]"滥用职权"项或"明显不当"项 → **撤销** | [变更判决条款] → **变更**（仅适用于行政处罚明显不当或款额认定错误） |
| 法院权限 | 撤销后由行政机关重新作出 | 法院直接变更（受禁止不利变更约束） |
| 举证 | 原告须就手段-目的结构异常作初步论证；被告就裁量过程合法负终局证明责任 | 原告无需揭示行政机关内部动机，仅就结果不合理作客观举证 |
| 适用前提 | 行政机关有裁量空间 + 选择了某一手段 | 行政机关已作出确定的处理结果（罚款额/吊销/责令停业等） |

#### 2.5.2 通道选择规则

**通道 A（比例原则四阶）适用场景**：

- 行政强制（[强制比例条款]明文要求比例原则）
- 行政许可的限制性条件设定
- 行政协议中公益变更/解除的必要性审查
- 信赖保护中"公益限制信赖"的衡量
- 多种执法手段并存时，行政机关选择特定手段是否合理（如：可警告而处罚款、可责令改正而吊销许可）

**通道 B（明显不当独立通道）适用场景**：

- 行政处罚的具体数额（如轻微违法处以顶格罚款）
- 涉款额行政行为的认定错误（[变更判决条款]之款额认定项）
- 同案异罚（同类违法主体差别对待无正当理由）
- 结果与过错程度明显不匹配（如初犯/未造成实际损害却处以重罚）

#### 2.5.3 不可混用铁律

1. **不可越通道引用判决**：通道 A 审查不通过，法院只能撤销，不可径行变更；通道 B 审查通过，法院方得变更，且仅限于[变更判决条款]列举的两类情形（处罚明显不当 + 款额认定错误）。
2. **不可双重评价同一争点**：同一裁量瑕疵已被通道 A 审查并得出"必要性不通过"结论的，不应在通道 B 重复以"结果明显不当"再次审查。两通道应针对不同切入点分别独立运行。
3. **通道 A 的均衡性 ≠ 通道 B 的明显不当**：通道 A 第四阶（均衡性）审查的是手段对相对人造成损害与行政目的的结构性比例关系；通道 B 审查的是结果脱离合理性的"显而易见的不当"。前者是结构性失衡，后者是结果性畸形。
4. **判决主文表述区分**：通道 A 不通过 → "被诉行政行为违反比例原则，构成滥用职权（或明显不当），依[撤销判决要件条款]撤销"；通道 B 不通过 → "被诉行政处罚明显不当，依[变更判决条款]变更为……"。判决主文混用即构成判决类型错配（详见 framework.md §三.1）。
5. **比例原则四阶不得替代明显不当独立通道**：即便案件已构成"裁量结果畸轻畸重"，若原告诉请为变更判决，法院仍须按通道 B 实质合法性审查路径独立完成审查，并适用[变更判决条款]作出变更判决；不得仅以通道 A 的均衡性不通过为由直接撤销而忽略变更请求。

#### 2.5.4 双通道叠加运行示范

部分案件可能同时触发两条通道。例如：行政机关对轻微违法行为既未审查替代手段（通道 A 必要性瑕疵）又作出顶格罚款（通道 B 明显不当）。报告处理方式为：

```
[可证立性 · 法律效果与裁量]

(a) 通道 A · 比例原则四阶审查
    └─ 第一阶 目的正当：通过
       第二阶 适当性：通过
       第三阶 必要性：不通过——存在警告/责令改正等侵害更小的替代手段
       [小结] 必要性阶段不通过，构成滥用职权（[撤销判决要件条款]"滥用职权"项）

(b) 通道 B · 明显不当独立通道审查
    └─ 结果合理性：罚款 50 万元（法定幅度 5,000-500,000 元的顶格）
       违法情节：初犯 + 货值 3,000 元 + 主动改正 + 无实际损害
       [小结] 结果明显畸重，构成明显不当（[变更判决条款]之处罚明显不当项）

(c) 判决类型选择
    └─ 通道 A 指向撤销；通道 B 指向变更。
       因原告诉请为撤销 + 变更，法院依通道 B 直接变更为合理数额；
       若原告仅请求撤销，则依通道 A 撤销并由行政机关重新作出。
```

#### 2.5.5 自检清单

- [ ] 已明确本案争点应走通道 A、通道 B 或双通道叠加
- [ ] 通道 A 的四阶展开未涉及"结果畸轻畸重"等通道 B 用语
- [ ] 通道 B 的结果审查未借用"必要性""均衡性"等通道 A 工具
- [ ] 判决主文与所走通道一一对应（撤销 vs 变更）
- [ ] 若两通道同时触发，已按 §2.5.4 模式分别独立审查并在结论处协调判决类型

## 三、裁量审查方法论

本节为撤销判决要件"滥用职权"项与"明显不当"项提供精细审查工具。两者均针对裁量行为，但审查路径不同：滥用职权审查裁量目的与考虑因素，明显不当审查裁量结果的合理性。

### 3.1 滥用职权与明显不当的区分

#### 3.1.1 核心差异

| 维度 | 滥用职权（[撤销判决要件条款]"滥用职权"项） | 明显不当（[撤销判决要件条款]"明显不当"项） |
|------|---------------------|---------------------|
| 审查对象 | 裁量过程——行政机关的目的与考虑因素 | 裁量结果——处理结论是否合理 |
| 缺陷本质 | 主观层面：裁量权行使的动机或考虑因素偏离法定目的 | 客观层面：结果畸轻畸重、显失公平，理性人可直接识别 |
| 认定标准 | 须证明行政机关考虑了不应考虑的因素或未考虑应当考虑的因素 | 无需探究行政机关主观动机，仅审查结果的合理性 |
| 典型表现 | 报复性执法、以权谋私、考虑与法定目的无关的因素 | 处罚畸重（轻微违法处以顶格罚款）、同案异罚、结果与过错程度明显不匹配 |
| 举证难度 | 较高——须揭示行政机关内部动机 | 较低——结果不合理可由客观事实直接推导 |

#### 3.1.2 "故意不是必备要件"原则

行政法上的滥用职权不以行政机关主观故意为必要条件。与刑法上的滥用职权罪不同，行政法上的滥用职权重点在于裁量过程是否客观偏离法定目的，而非行政工作人员是否存在主观恶意。即使行政机关工作人员主观上无违法故意，但客观上考虑了不应考虑的因素（如案外人施压、部门利益），仍构成滥用职权。

这一区分的实践意义：原告无需证明行政机关"故意违法"，仅需证明裁量过程中存在不当考虑因素即可。

### 3.2 四步裁量审查法

#### 步骤 1：识别裁量空间

确认法律规范是否赋予行政机关裁量权。裁量权的识别标志：法条使用"可以""有权""根据情节轻重""酌情"等弹性用语；法律规定处罚幅度（如"处五千元以上五万元以下罚款"）；法律赋予行政机关在多种处理方式中选择的权限。

**注意**：若法条为羁束性规定（"应当""必须"+确定法律效果），则不存在裁量空间，不适用本审查方法，应转入"适用法律是否正确"审查。

#### 步骤 2：审查考虑因素

裁量考虑因素分为两类：

**法定因素**（法律明确列举）：如行政处罚法规定的[从轻减轻处罚情节条款]列举的"主动消除后果、受他人胁迫、主动供述、配合查处有立功表现"等情形，及[不予处罚情节条款]规定的不予处罚情形。法定因素是裁量审查的硬约束——行政机关不得忽略。

**常理因素**（法律未明确列举但合理人应当考虑）：如违法行为的社会危害程度、当事人的经济状况对罚款承受能力的影响、同类案件的既往处理惯例、执法的一致性与可预期性。常理因素是裁量审查的软约束——忽略不必然构成违法，但可能导致"明显不当"。

**审查清单**：

- 是否遗漏法定从轻/减轻/不予处罚情节？→ 滥用职权
- 是否考虑了与法定目的无关的因素（如当事人身份、行政机关创收需求）？→ 滥用职权
- 是否对同类情形作出差异化处理而无正当理由？→ 滥用职权或明显不当

#### 步骤 3：审查结果合理性

在裁量过程无明显瑕疵的前提下，仍须审查裁量结果本身。审查标准为"理性行政机关"测试——一个考虑了全部相关因素的理性行政机关，是否可能作出同样的处理决定。

**明显不当的识别信号**：

- 畸轻畸重：处罚力度与违法行为严重程度明显不匹配
- 显失公平：同一违法行为对不同当事人差异化处理且无合理理由
- 违反比例原则：所选手段的侵害程度明显超出实现行政目的的必要限度

#### 步骤 4：缺陷分级与法律后果

| 缺陷程度 | 识别标准 | 法律后果 |
|---------|---------|---------|
| 滥用职权 | 裁量过程中存在不当考虑因素或偏离法定目的 | 撤销（[撤销判决要件条款]"滥用职权"项） |
| 明显不当 | 裁量结果畸轻畸重、显失公平 | 变更（[变更判决条款]）或撤销（[撤销判决要件条款]"明显不当"项） |
| 一般不当 | 裁量结果有瑕疵但未达"明显"程度 | 法院不予干预（行政自主判断空间） |

**变更判决的特殊条件**（依[变更判决条款]）：行政处罚明显不当，或其他行政行为涉及对款额的确定、认定确有错误时，法院可以直接变更。变更判决适用"禁止不利变更"原则——法院不得加重原告的义务或减损原告的权益。

### 3.3 与其他审查要素的关系

滥用职权与明显不当审查是合法性六要素审查中的最后环节，位于主体职权、程序、事实证据、法律适用之后。逻辑上，只有在前四项审查均通过（或虽有瑕疵但不足以撤销）时，裁量审查才有独立意义。若事实认定不清或法律适用已经错误，裁量审查通常被前置瑕疵吸收。

与 `interpretation-toolkit.md` 的衔接：该文件 §一 解释方法中的目的解释用于确定"法定目的"的内涵，§二 举证责任中的倒置规则适用于被告证明裁量过程合法。

## 四、裁量收缩理论

本节主旨：裁量收缩是比例原则的特殊运用场景——当行政裁量空间在特定情形下收缩至零，行政机关负有作出特定决定的义务，此时裁量瑕疵表现为"应收缩而未收缩"。

### 4.1 裁量收缩的触发条件

裁量收缩并非普遍适用，仅在以下情形触发：

| 触发情形 | 说明 | 典型案例 |
|---------|------|---------|
| 基本权利面临紧迫危险 | 公民生命/健康/重大财产面临紧迫威胁，行政机关有保护义务 | 消防/环保/食品安全紧急事件 |
| 信赖利益已形成 | 相对人基于行政行为产生重大信赖且已采取行动 | 行政许可已投资后随意撤销 |
| 平等原则要求 | 行政机关对同类案件已形成稳定处理惯例，无正当理由偏离 | 同类处罚差异悬殊 |
| 先行行为约束 | 行政机关的先行行为（承诺/确认/指导）产生了合理期待 | 行政指导后反悔 |

### 4.2 裁量收缩的分析框架

```
第一步：确认裁量授权存在
  └─ 法律规定"可以……"而非"应当……"

第二步：判断是否存在收缩事由
  └─ 逐一检视上述四种触发情形

第三步：评估收缩程度
  ├─ 完全收缩（裁量空间归零）→ 行政机关只能作出特定决定
  ├─ 部分收缩（裁量空间缩窄）→ 行政机关的选择范围显著限缩
  └─ 未收缩（裁量空间完整）→ 按一般裁量审查

第四步：审查行政机关是否正确回应
  ├─ 应收缩而未收缩 → 裁量瑕疵（裁量怠惰/滥用）
  ├─ 已正确收缩 → 行政行为合法
  └─ 收缩方向错误 → 裁量滥用
```

### 4.3 涵摄示范

```
"被告在行使裁量权时，可能因 [基本权利紧迫危险/信赖利益/平等原则/先行行为]
 而导致裁量空间收缩。

 依裁量收缩理论，当 [触发情形] 出现时，行政机关的裁量空间收缩至仅能作出
 [特定决定] 的程度。本案中，[事实映射]……

 因此，被告应当作出 [特定决定] 而未作出，构成裁量瑕疵。"
```

### 4.4 裁量收缩与判决类型的双轨对应关系

裁量收缩的程度直接决定履职之诉的判决类型，二者必须精确对应，否则会出现"应收缩而未收缩"或"判决内容超越裁量空间"的错判风险。

**双轨对应表**：

| 收缩程度 | 判定标准 | 对应判决类型 | 语义锚定 | 判决主文表述 |
|---------|---------|------------|------|-------------|
| **完全收缩（收缩到零）** | 四要件齐备 + 仅有唯一合法选择 | **直接履行判决**（明确具体履职内容） | [履行判决条款]之直接履行项 | "判令被告于 X 日内向原告颁发 XX 许可证 / 给付 XX 款项" |
| **部分收缩（裁量缩窄）** | 触发收缩事由但具体处理方式仍有选择空间 | **责令履行判决**（限期作出决定） | [履行判决条款]之责令履行项 | "判令被告于 X 日内对原告的 XX 申请依法作出处理决定" |
| **未收缩（裁量空间完整）** | 未触发收缩事由 | 一般不支持直接履行请求，可支持责令履职（仅在行政机关完全不作为时） | [履行判决条款]之责令履行项 或 [驳回诉讼请求条款] | 视具体案情而定 |

**"收缩到零"的典型场景**（法院可直接判决具体内容）：

1. **许可申请完全符合条件**：申请人满足所有法定要件，行政机关无任何裁量空间，只能颁发许可
2. **法定给付义务明确**：法律明文规定"应当"给付且金额确定（如抚恤金、低保金）
3. **先行行为产生的返还义务**：违法扣押财物应返还、违法注销登记应恢复
4. **紧急保护义务**：公民人身安全面临紧迫危险且只有该机关能保护（如警察出警）

**"部分收缩"的典型场景**（法院仅判责令履职，保留裁量空间）：

1. **行政处罚的幅度裁量**：已认定违法事实，但罚款数额、是否责令停业等仍有选择空间
2. **公共利益衡量的裁量**：是否撤销违法许可涉及公共利益 vs 信赖利益的衡量
3. **监管措施的选择**：对违法企业可处警告/罚款/停业整顿等多种措施
4. **履职方式的裁量**：对投诉举报事项如何调查、如何处理的具体方式

**判决类型错误的识别与纠正**：

| 错误类型 | 表现 | 纠正方式 |
|---------|------|---------|
| 应收缩到零却判责令履职 | 法院以"行政机关有裁量权"为由不直接判具体履行，但实际上裁量已收缩 | 上诉理由：裁量已收缩到零，应改判直接履行 |
| 应部分收缩却判直接履行 | 法院直接判令行政机关作出特定处罚，但处罚幅度仍有裁量空间 | 上诉理由：侵犯行政机关裁量权，应改判责令履职 |
| 未收缩却判直接履行 | 法院替代行政机关作出实体决定 | 上诉理由：司法权僭越行政权，应驳回直接履行请求 |

**鉴定式写作要求**：在分析裁量收缩时，必须明确得出"收缩程度"的结论，并直接对应到 [履行判决条款] 的直接履行项或责令履行项，禁止出现"裁量已收缩，法院应责令履职"这类逻辑断裂的表述。

**与履职之诉的衔接**：本节与 `suit-types/performance-suit.md` §五 判决类型表对应——performance-suit.md 给出判决类型清单，本节给出收缩程度与判决类型的对应逻辑，二者配合使用。

## 五、信赖保护原则

本节主旨：信赖保护是限制行政机关随意变更、撤销、废止已生效行政行为的基本原则，保护相对人因行政行为产生的合理信赖。

### 5.1 法律依据与学理基础

| 来源 | 内容 |
|------|------|
| [信赖保护条款] | "依法取得的行政许可，受法律保护。行政机关不得擅自改变已经生效的行政许可。" |
| [许可撤销情形条款] | 撤销已生效许可时的信赖保护补偿规则 |
| 学理：依法行政 + 法律安定性 + 诚信原则 | 信赖保护是法治国原则的具体化 |

### 5.2 信赖保护五步审查

```
第一步：信赖基础
├── 是否存在可信赖的行政行为外观？
│   ├── 已生效的行政许可/确认/承诺
│   ├── 已发布的行政指导/政策
│   └── 已缔结的行政协议
├── 涵摄：本案中，[行政行为] 于 [日期] 作出，构成信赖基础。

第二步：信赖表现
├── 相对人是否基于信赖采取了具体行动/投入？
│   ├── 投资建设/购置财产
│   ├── 签订合同/变更经营方式
│   └── 放弃其他机会/改变生活安排
├── 涵摄：原告基于对 [行政行为] 的信赖，于 [时间] 进行了 [投入]……

第三步：信赖值得保护
├── 相对人的信赖是否善意、无过错？
│   ├── 善意取得（不知道也不应当知道行政行为违法）→ 值得保护
│   ├── 相对人欺诈/隐瞒 → 不值得保护
│   ├── 相对人重大过失 → 不值得保护
│   └── 行政机关已表示保留态度 → 不值得保护
├── 涵摄：原告在取得 [许可] 时 [是否善意]……

第四步：信赖损害
├── 行政机关变更/撤销/废止行为是否造成信赖损害？
├── 损害的范围与程度：直接投入损失 + 合理预期利益损失
└── 涵摄：若被告撤销 [行政行为]，原告将遭受 [损失金额/类型]……

第五步：利益衡量与保护手段
├── 信赖利益 vs 变更的公共利益 → 衡量
│   ├── 信赖利益 > 公共利益 → 限制变更/不得撤销
│   ├── 信赖利益 < 公共利益 → 允许变更但须补偿
│   └── 信赖利益 ≈ 公共利益 → 比例原则辅助判断
├── 保护手段选择：
│   ├── 存续保护：维持原行政行为不变
│   ├── 财产保护：允许变更但给予充分补偿
│   └── 过渡安排：设置合理过渡期
└── 涵摄：综合衡量 [信赖利益] 与 [公共利益]……
```

### 5.3 信赖保护与比例原则的协同

信赖保护审查的第五步（利益衡量）经常需要调用比例原则作为辅助工具：

```
信赖利益衡量 + 比例原则协同审查：

1. 目的正当性：行政机关变更/撤销追求的目的是否正当？
2. 适当性：变更/撤销能否实现该目的？
3. 必要性：是否存在对信赖利益侵害更小的替代方案？
   （如：不撤销而是附条件保留、设置过渡期、部分变更）
4. 均衡性：变更/撤销对信赖利益的损害与追求的公共利益是否成比例？
```

### 5.4 信赖保护的排除情形

以下情形不适用信赖保护：

| 排除情形 | 理由 |
|---------|------|
| 相对人以欺诈、胁迫或贿赂手段取得行政行为 | 恶意不值得保护 |
| 相对人对重要事项作不实陈述或隐瞒 | 主观过错 |
| 相对人明知或因重大过失而不知行政行为违法 | 非善意信赖 |
| 行政行为附有保留条款且条件成就 | 信赖基础不存在 |
| 重大公共利益迫切要求变更 | 公共利益优先（但仍须补偿） |

### 5.5 行政协议中的信赖保护特殊规则

行政协议兼具行政性与合同性，信赖保护在协议场景中有特殊表现：

1. **行政机关单方变更/解除权**：行政机关基于公共利益可以单方变更或解除协议，但须满足三个条件——① 公共利益必要；② 遵循比例原则（变更而非解除优先）；③ 给予合理补偿。

2. **信赖保护的强化**：相较于单方行政行为，协议场景中相对人的信赖通常更强（双方合意产生），保护力度相应更高。

3. **法律变动的处理**：协议缔结后法律变动导致协议内容与新规定冲突的，区分处理——
   - 法律明文规定溯及既往 → 依新法
   - 法律未规定溯及 → 信赖保护优先，维持原协议效力或给予充分补偿

## 六、裁量审查嵌入位置与判决类型对应

本节主旨：汇总比例原则四阶、裁量收缩、信赖保护三项审查在撤销之诉与履职之诉骨架中的嵌入位置，并将各项审查结论映射到具体的判决类型。具体条文编号一律以 SKILL.md §6.5 法条锚定表为准。

### 6.1 撤销之诉中的嵌入位置

裁量审查嵌入撤销之诉骨架的"法律效果与裁量"环节（撤销判决要件"滥用职权"项或"明显不当"项）：

```
#### 5. 法律效果与裁量
  ##### (1) 法定幅度内
  ##### (2) 裁量逾越判定
  ##### (3) 裁量滥用判定（对应"滥用职权"项）
  ##### (4) 裁量怠惰判定
  ##### (5) 比例原则审查（四阶）          ← 本文件 §二
  ##### (6) 裁量收缩审查（如触发条件满足） ← 本文件 §四
  ##### (7) 平等对待/类案对比
  ##### (8) 明显不当判定（对应"明显不当"项）
```

### 6.2 信赖保护审查的嵌入位置

信赖保护审查不是独立骨架，而是嵌入特定诉讼类型的审查环节中：

| 诉讼类型 | 嵌入位置 |
|---------|---------|
| 撤销之诉 | 行政机关撤销已生效许可/决定时，在"裁量审查"环节审查信赖保护 |
| 协议之诉 | 在"信赖保护"专项环节独立审查 |
| 确认违法之诉 | 行政机关废止已生效行为时，在"违法性"审查中附带审查 |
| 规范性文件变更 | 在附带审查中审查信赖保护 |

### 6.3 审查结论到判决类型的总映射

| 审查结论 | 对应语义锚定 | 判决类型 |
|---------|--------------|---------|
| 主体/职权/程序/事实/法律适用合法 + 裁量过程无瑕疵 + 比例原则通过 + 结果合理 | [驳回诉讼请求条款] | 驳回诉讼请求 |
