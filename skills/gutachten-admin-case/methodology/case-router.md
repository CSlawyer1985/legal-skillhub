# 行政行为实质类型路由

> 本文件是实质维度路由器，承担单一职责：为 9 类高频行政行为标记专属审查要点。本文件与 `legality-examination-engine/pipeline.md`（诉讼请求类型识别）正交，共同构成"双维度路由"（诉讼请求类型 × 行政行为实质类型），服务于 W2/W3 阶段的大纲生成与逐节展开。六要素合法性审查骨架作为可证立性层内嵌子骨架，详见 `legality-examination-engine/framework.md`。
> **法条锚定单点源铁律**：本文件遵循 SKILL.md §5.1 第 4 条铁律，正文一律使用语义名称（如"一事不再罚条款""听证程序条款"），不出现具体条文编号。所有语义名称的现行条号请实时查阅 `SKILL.md §6.5 法条锚定表`，由 MCP 运行时校验。

## §零 诉讼请求类型 → 审查范式分流（双轨分流入口）

本节主旨：在 W2a 阶段，按诉讼请求类型决定使用"违法性审查"还是"请求权审查"范式，二者程式截然不同，不可混用。

### 0.1 双轨分流决策树

```
诉讼请求类型识别（参见 legality-examination-engine/pipeline.md §一）
   │
   ├─ 撤销之诉 ───────┐
   │                │
   ├─ 确认违法之诉 ───┼──→ 轨道 A：违法性审查四要件
   │                │     （主体 / 程序 / 事实 / 法律适用
   ├─ 确认无效之诉 ───┘      + 裁量 + 处理结果）
   │
   ├─ 履职之诉 ───────┐
   │                │
   ├─ 给付之诉 ───────┼──→ 轨道 B：请求权审查四要件
   │                │     （请求权基础 / 请求权要件
   ├─ 一般给付之诉 ───┘      / 履行 / 抗辩与裁量）
   │
   └─ 行政协议之诉 ────→ 轨道 C：请求权基础四阶
                        （成立 / 效力 / 履行 / 救济）
```

### 0.2 三轨范式对照表

| 轨道 | 适用诉讼类型 | 核心提问 | 检视程式 | 详细文件 |
|------|-------------|---------|---------|---------|
| A 违法性审查 | 撤销 / 确认违法 / 确认无效 | "行政行为是否违法？违法到什么程度？" | 六要素合法性审查骨架（参见 `legality-examination-engine/framework.md`），含审查铁律 Step 0-6 | `suit-types/revocation-suit.md` `suit-types/declaratory-suit.md` |
| B 请求权审查 | 履职 / 给付 / 一般给付 | "原告有无请求权？请求权要件是否成立？" | 请求权基础识别 → 请求权要件涵摄 → 履行可能性 → 抗辩与裁量收缩 | `suit-types/performance-suit.md` `suit-types/payment-suit.md` |
| C 请求权基础四阶 | 行政协议 | "协议是否有效？是否被合法变更或解除？是否构成违约或违法？" | 协议成立 → 协议效力 → 履行与变更 → 救济选择（四阶审查） | `suit-types/special-scenarios.md` §二 |

### 0.3 分流操作规则

**铁律一：轨道单选 + 复合请求分别展开**

每个诉讼请求只能进入一条轨道。复合请求（如"撤销 + 赔偿"）按各自诉讼类型分别进入不同轨道，分节展开。

**铁律二：轨道与实质类型正交叠加**

本节决定"用什么范式审查"（程式骨架）；§一 决定"该范式中叠加哪些专属要点"（实质要点）。两个维度独立、缺一不可。

**铁律三：A 轨核心节奏 = 违法性审查 + 审查铁律**

A 轨完整流程：① 调用六要素骨架（`legality-examination-engine/framework.md §一`）；② 执行审查铁律 Step 0-6（同 §1.0）；③ 缺陷分级三档判定（重大且明显违法 / 一般违法 / 程序轻微违法）；④ 判决类型映射。

**铁律四：B 轨核心节奏 = 请求权审查四要件**

B 轨完整流程：① 识别请求权基础（法律规范赋予原告之主观公权利）；② 请求权要件涵摄（法律条件 + 事实条件）；③ 履行可能性（裁量空间 / 裁量收缩到零）；④ 抗辩事由（除斥期间 / 已履行 / 不可抗力等）。**不调用六要素骨架。**

**铁律五：C 轨核心节奏 = 协议四阶审查**

C 轨完整流程：① 协议成立阶段（行政机关有权签订 / 程序合法 / 内容合法）；② 协议效力（是否违反法律强制规定）；③ 履行与变更（行政机关单方变更的合法性三条件：公共利益必要 + 比例原则 + 合理补偿）；④ 违约 vs 违法救济选择。

### 0.4 与可受理性 8 闸门的关系

本节双轨分流位于 **W2a 可证立性入口**，**前置于六要素涵摄但后于可受理性 8 闸门**。可受理性 8 闸门（参见 `legality-examination-engine/admissibility-screening.md`）对所有诉讼类型统一适用，与轨道选择无关。8 闸门全部通过后，依本节双轨分流进入对应轨道的实体审查。

## §一 行政行为实质类型路由

本节主旨：为 9 类高频行政行为标记专属审查要点。这些要点叠加在 `legality-examination-engine/framework.md` 六要素通用骨架之上，构成"实质类型专属审查清单"。每个案件在 W2 Gate2 阶段识别行政行为实质类型后，必须叠加对应专属清单。

### 2.2 专属审查要点详表（每类约 300 字）

#### 类型 1：行政处罚类

**核心审查要点（叠加在六要素合法性审查骨架之上）**：

- **一事不再罚**（[一事不再罚条款]）：同一违法行为不得给予两次以上罚款；违法行为构成犯罪已判处罚金的，罚款应折抵。审查步骤：① 识别"同一违法行为"（行为同一性/法益同一性/时间连续性三要件）；② 比较两次处罚的性质（是否均为罚款）；③ 计算折抵。
- **听证程序触发**（[处罚听证条款]）：较大数额罚款/没收较大数额违法所得或非法财物/降低资质等级/吊销许可证件/责令停产停业/责令关闭/限制从业等处罚，行政机关应当告知听证权利。未告知 = 重大程序违法 = 撤销。
- **主观过错认定**（[主观过错条款]）：当事人有证据足以证明没有主观过错的，不予行政处罚。审查：① 行政机关是否主动调查过错；② 当事人是否提出无过错抗辩；③ 举证责任分配是否合法。
- **裁量基准约束**（[裁量基准公开条款]）：行政机关应当依据已公布的行政处罚裁量基准行使裁量权。偏离基准需说明理由，否则构成裁量滥用。
- **告知义务**（[告知义务条款]）：处罚前应告知事实、理由、依据、拟作出的处罚内容及当事人享有的陈述申辩权。未告知 = 重大程序违法。
- **时效**（[处罚时效条款]）：违法行为在 2 年内未被发现的不再处罚；涉及公民生命健康安全、金融安全且有危害后果的延至 5 年。

**典型争点**：一事不再罚的"同一行为"认定；主观过错举证责任分配；裁量基准的内部法效力；责令改正与行政处罚的性质区分。

#### 类型 2：行政强制类

**核心审查要点**：

- **强制措施 vs 强制执行区分**（[强制措施与强制执行区分条款]）：强制措施是暂时性控制（查封/扣押/冻结/限制人身自由），强制执行是终局性实现（划拨存款/拍卖/排除妨碍/恢复原状）。二者程序要求完全不同。
- **强制措施程序要件**（[强制措施程序要件条款]）：① 实施前向行政机关负责人报告并经批准；② 由两名以上行政执法人员实施；③ 出示执法身份证件；④ 通知当事人到场；⑤ 当场告知理由、依据、权利及救济途径；⑥ 听取陈述申辩；⑦ 制作现场笔录；⑧ 现场笔录由当事人和行政执法人员签名或盖章。
- **强制执行前置程序**（[强制执行催告条款]）：① 先催告（书面催告履行义务）；② 催告期届满仍不履行；③ 作出强制执行决定（书面）。无行政强制执行权的机关应依据 [申请法院强制执行条款] 申请法院强制执行。
- **夜间/节假日禁止**（[夜间节假日禁止条款]）：行政机关不得在夜间或者法定节假日实施行政强制执行（紧急情况除外）；不得对居民生活采取停止供水、供电、供热、供燃气等方式迫使当事人履行。
- **强拆特殊程序**（[违法建筑强拆程序条款]）：对违法建筑物强制拆除，应公告并限期自行拆除，当事人在法定期限内不复议、不诉讼且仍不拆除的，方可依法强拆。

**典型争点**：查封扣押期限（一般不超过 30 日，经批准可延长 30 日）；夜间强拆的程序违法认定；无强制执行权机关的强拆行为定性（超越职权）。

#### 类型 3：政府信息公开类

**核心审查要点**：

- **豁免三要件**（[公开豁免三要件条款]）：① 国家秘密（以保密审查结论为准）；② 商业秘密（第三方意见+公共利益衡量）；③ 个人隐私（第三方意见+公共利益衡量）。审查步骤：① 信息是否确属三类豁免之一；② 是否征询第三方意见；③ 不公开是否对公共利益造成重大影响（豁免条款但书）。
- **重复申请**（[重复申请处理条款]）：已答复过且无新理由的重复申请，可以不予重复处理。
- **咨询/信访/举报区分**（[信访举报衔接条款]）：申请人以信息公开申请的形式进行信访、投诉、举报等活动的，告知通过相应渠道提出。
- **主动公开 vs 依申请公开**（[主动公开范围条款] vs [依申请公开条款]）：属于主动公开范围的，应告知获取方式而非提供复制件。
- **期限**（[答复期限条款]）：收到申请之日起 20 个工作日内答复，可延长 20 个工作日。

**典型争点**：内部信息（过程性信息/讨论记录）的可公开性；"三需要"（生产、生活、科研）是否为申请要件；第三方意见缺失的程序后果。

#### 类型 4：房屋征收补偿类

**核心审查要点**：

- **征收决定 vs 补偿决定双轨**（[征收决定条款] vs [补偿决定条款]）：征收决定是行政行为的基础，补偿决定是征收后的具体给付。二者可分别起诉。
- **公共利益要件**（[公共利益情形条款]）：6 类公共利益情形（国防外交/基础设施/公共事业/保障房/旧城区改建/其他）。审查步骤：① 是否落入 6 类列举；② 是否有具体公共利益需要的证据；③ 是否符合比例原则。
- **评估时点**（[评估时点条款]）：不得低于房屋征收决定公告之日类似房地产市场价格。迟延支付期间的市场上涨损失应由征收方承担。
- **补偿范围**：被征收房屋价值补偿 + 搬迁及临时安置补偿 + 停产停业损失。
- **强拆前置程序**：补偿决定→催告→依据 [申请法院强拆条款] 申请法院强制执行。行政机关不得自行强拆。
- **程序要件**：征收补偿方案论证 + 公告 + 听取意见（不少于 30 日）+ 修改 + 听证（多数被征收人认为方案不符合规定时）。

**典型争点**：旧城区改建的公共利益认定；评估机构的选定程序；补偿决定的设定期限；强制执行的申请期限。

#### 类型 5：投诉举报处理类

**核心审查要点**：

- **举报人原告资格**（[投诉举报原告资格规则] + 保护规范理论）：① 法律规范是否赋予投诉举报人主观公权利；② 投诉举报事项是否涉及投诉人自身合法权益（区别于一般公益性举报）；③ 行政机关的处理或不处理是否对投诉人权益产生实际影响。消费者权益保护型投诉一般具备原告资格；普通公益举报一般不具备。
- **实质处理 vs 形式答复**：形式答复（仅告知已收到或转交处理）不构成履行法定职责；实质处理（调查+作出处理决定+反馈结果）才构成履行。
- **三要件测试**（详见 performance-suit.md §4.4）：主观公权利 + 自身权益 + 实际影响。
- **答复可诉性**：对投诉举报的答复行为本身是否可诉，取决于答复是否对投诉人权益产生实际影响（参见 [受案范围负面清单条款]）。

**典型争点**：职业打假人的原告资格；对举报不处罚的答复是否可诉；奖励请求权是否独立。

#### 类型 6：工伤认定类

**核心审查要点**：

- **三工要素**（[工伤认定情形条款]）：工作时间 + 工作场所 + 工作原因。三要素并非必须全部具备——上下班途中事故只要求"合理时间+合理路线"；工作岗位突发疾病 48 小时内死亡视为工伤（见 [视同工伤条款]）。
- **举证责任倒置**（[工伤举证责任倒置条款]）：职工认为是工伤，用人单位不认为是工伤的，由用人单位承担举证责任。
- **视同工伤边界**（[视同工伤条款]）：① 工作岗位突发疾病 48 小时内死亡；② 抢险救灾等维护公共利益活动中受伤；③ 军队服役期间因战或因公负伤致残已取得革命伤残军人证，到用人单位后旧伤复发。
- **排除情形**（[工伤排除情形条款]）：故意犯罪/醉酒或吸毒/自残或自杀。

**典型争点**：上下班途中绕道买菜是否仍属"合理路线"；48 小时起算点（诊断时还是抢救时）；在家加班期间突发疾病是否属"工作岗位"。

#### 类型 7：行政许可类

**核心审查要点**：

- **撤回 vs 撤销 vs 注销三分**：① 撤回（[信赖保护条款]）= 合法许可因公共利益变更或废止，应补偿；② 撤销（[许可撤销情形条款]）= 违法许可（滥用职权/玩忽职守/超越职权/违反法定程序/对不具备申请人资格者准予许可），可撤销；③ 注销（[许可注销情形条款]）= 许可到期/法人终止/许可被撤销吊销后的程序性终结。
- **信赖保护**（[信赖保护条款]）：撤回合法许可应对被许可人的信赖损失予以补偿。
- **听证程序**（[许可听证条款]）：涉及申请人与他人之间重大利益关系的许可，行政机关应告知听证权利。
- **延续默示批准**（[许可延续默示批准条款]）：许可届满 30 日前申请延续，行政机关在届满前未作决定的，视为准予延续。

**典型争点**：撤回与撤销的区分标准；信赖保护的补偿范围；"重大利益关系"的识别。

#### 类型 8：行政协议类

详见 `special-scenarios.md` §二 协议之诉。本处仅标记专属要点：

- **协议四阶（成立 / 效力 / 履行 / 救济）**：协议成立阶段（是否有权签订/程序合法/内容合法）+ 协议效力阶段（是否违反法律强制规定）+ 履行与变更阶段（单方变更或解除的合法性）+ 救济阶段（违约/违法选择）。
- **单方变更合法性三条件**：① 公共利益必要；② 遵循比例原则（变更优先于解除）；③ 给予合理补偿。
- **违约 vs 违法区分**：行政机关违反协议约定 = 违约（民法典合同编）；行政机关违法行使优益权 = 违法（行政法）。

#### 类型 9：行政赔偿诉讼类

详见 `payment-suit.md` §三·3.2 国家赔偿。本处仅标记专属要点：

- **赔偿 vs 补偿区分**：违法行为致害 = 赔偿（[赔偿范围条款]）；合法行为致害 = 补偿（单行法）。
- **先行处理程序**（[赔偿先行程序条款]）：赔偿请求人应先向赔偿义务机关提出，2 个月内未作决定或对决定不服方可起诉（一并提出除外）。
- **举证责任特殊规则**（[因果关系举证倒置条款]）：限制人身自由期间死亡或丧失行为能力的，赔偿义务机关应证明其行为与损害之间不存在因果关系。
- **精神损害赔偿**（[精神损害赔偿条款]）：仅适用于人身权侵害（人身自由/生命健康），不适用于财产权侵害。

### 2.3 双维度叠加规则

**核心原则**：诉讼请求类型（决定骨架）× 行政行为实质类型（决定专属要点）= 完整审查程式。

**举例**：用户提交"撤销行政处罚决定"案件——

- Step 1 诉讼请求类型识别 → 撤销之诉 → 调用 revocation-suit.md 中六要素合法性审查骨架
- Step 2 行政行为实质类型识别 → 行政处罚 → 叠加本文件 §2.2 类型 1 的 6 项专属要点
- Step 3 合成完整审查程式：六要素通用审查 + 一事不再罚/听证程序/主观过错/裁量基准/告知义务/时效 6 项专属审查

**合成示例表**：

| 诉讼类型 \ 行为类型 | 处罚 | 强制 | 信息公开 | 征收 |
|---|---|---|---|---|
| 撤销之诉 | 六要素+处罚 6 要点 | 六要素+强制 6 要点 | 六要素+豁免三要件等 | 六要素+公共利益等 |
| 履职之诉 | 少见 | 少见 | 申请公开不答复 | 申请补偿决定不答复 |
| 给付之诉 | 返还罚款 | 返还扣押财物 | 少见 | 补偿款迟延 |
| 确认之诉 | 处罚已执行完毕 | 强拆已完成 | 少见 | 强拆确认违法 |

上表为 5 种诉讼类型 × 9 类高频行政行为的核心交叉映射，完整合成逻辑参见本文件 §2.3 双维度叠加规则——诉讼类型决定审查骨架（六要素/请求权四要件/行政协议四阶），行为类型决定在该骨架上叠加的专属审查要点清单。

## §二 路由执行规范

### 2.4 W2/W3 阶段路由流程

鉴定式案例研习工作流（W0→W4）在 W2 阶段执行如下路由序列：

1. **识别诉讼请求类型** → 调用 `legality-examination-engine/pipeline.md` § 一 决策树（撤销/履职/给付/确认/特殊五类）
2. **识别行政行为实质类型** → 调用本文件 §2.1 速查表（9 类高频行为）
3. **叠加专属审查要点** → 调用本文件 §2.2 对应类型详表
4. **生成完整可证立性大纲** → 六要素合法性审查通用骨架（作为 `legality-examination-engine/framework.md §一` 内嵌子骨架被调用） + 专属要点清单

### 2.5 兜底规则

- 行为类型无法识别（罕见）：仅走六要素合法性审查通用骨架，在报告中标注"行政行为类型未识别"
- 行为类型落入"其他"（非 9 类高频）：仅走通用骨架，可提示用户补充专属要点
- 多行为类型并存（如"行政处罚+行政强制"）：分别适用各自专属要点，在报告中分节展开

## §三 场景套色（W0 scenario → W2/W3 路由偏置）

本节主旨：W0 冷启动访谈段落 0 选定的 `scenario`（`academic` / `litigation` / `pre-enforcement`）不仅影响 W4 终稿外壳，亦须在 W2 大纲生成与 W3 写作阶段以"场景套色"形式介入，弥补"中段无感知"设计缺口。**双维度路由（诉讼请求类型 × 行政行为实质类型）确定"哪些要素入审"，场景套色叠加确定"哪些要素该被前推到 ⭐ 核心争议、以何种语气展开"。**

### 3.1 场景套色矩阵

| 场景 | 视角 | ⭐ 默认前推方向 | 🔍 默认前推方向 | 写作语气 | 末段输出附加 |
|------|------|----------------|----------------|---------|------------|
| `academic` | 中立第三方学术评价 | 案件自然争议分布（不偏置） | 自然分布 | 纯第三人称评议，价值中立 | 无附加 |
| `litigation` | 律师/法务办案参考（攻防视角） | 程序违法点 + 证据缺陷 + 裁量瑕疵 + 主体瑕疵 | 法律适用争议 + 时效抗辩 + 信赖保护 | 攻防式（站位由 W1 当事人身份决定）；攻击面用"质疑/抗辩/可主张"，防守面用"可释明/可补强"；不预设胜诉 | 风险清单（攻击点 + 防守弱项） |
| `pre-enforcement` | 行政机关内部自检（盲点视角） | 职权依据 + 程序前置（论证/公告/听证/告知）+ 裁量基准内部一致性 + 规范性文件合法性 | 事实证据闭环 + 文书送达 + 救济告知 | 克制中性，使用"本机关/拟作出行为"称谓；以"是否充分""是否留痕""是否可耐受司法审查"自问 | 合法性体检清单（拟作出行为的整改提示） |

### 3.2 套色介入点

**W2 Gate1**：行政行为实质类型识别后，须读取 `.user-config.md` 的 `scenario` 字段；若非 `academic`，预选报告末尾追加"场景套色提示"一行，明确将影响 Gate2 默认标记。

**W2 Gate2**：在六要素合法性审查子骨架嵌入完成后，依 §3.1 矩阵自动为对应要素预置 ⭐/🔍 标记；用户可在 Gate2 确认时手动覆写。覆写规则：场景套色给出的是"建议默认"，案件具体证据可推翻——例如 `litigation` 场景下程序违法点默认 ⭐，但案件证据显示程序完全合规时，应降为无标记并附"程序无瑕疵"短结论。

**W3 §五 写作纪律**：写作 agent 在执行涵摄四步法时，对 ⭐ 要素须按 §3.1 写作语气列展开；末段结论须附加"诉讼策略提示"（`litigation`）或"自查整改提示"（`pre-enforcement`）一句。学术场景不附加。

**W4 §五 终稿输出**：风险清单（`litigation`）与合法性体检清单（`pre-enforcement`）的素材直接来源于 W3 写作阶段为每个 ⭐ 要素生成的提示句，无需 W4 重新分析。

### 3.3 场景套色的边界

- **不改变双层结构**：可受理性 8 闸门 + 可证立性六要素的总框架在三种场景下保持一致；套色仅影响要素级别的标记权重与展开语气。
- **不替代用户判断**：场景套色给出的是默认值，Gate2 用户确认仍是冻结大纲的最终闸门。
- **不污染事实层**：W1 事实笔记不受场景影响，仍保持中性提取。
- **不与轻量模式冲突**：轻量模式下争议级别仅保留 ⭐ 与无标记两级，场景套色的 🔍 默认推荐自动降为无标记。
- **`pre-enforcement` 的特殊性**：W2 Gate1 的"被告识别"步骤改为"拟行为相对人识别"；可受理性 8 闸门简化为"相对人救济可能性预判"（参见 W4 §五场景分支表）。
