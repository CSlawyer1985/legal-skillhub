# 可受理性 8 闸门筛查

> 可受理性是行政法鉴定式的第一根决策树。8 项独立闸门按固定顺序逐项过关，任一不通过则裁定不予受理或驳回起诉，可证立性审查不再展开。闸门对每个诉讼请求逐项筛查。

> **法条锚定单点源铁律**：本文档所有法条引用一律使用 `[语义名称]` 占位符，禁止出现具体条号。语义名称→现行编号的映射由 `SKILL.md §6.5 法条锚定表` 唯一维护。

> **排序权威源**：8 闸门固定顺序以 `../../format/format-and-template.md §三` 为唯一权威源——`生效裁判约束 → 受案范围 → 复议前置 → 原告资格 → 被告适格 → 管辖 → 起诉期限与形式要件 → 诉的利益 → 中间结论`。本目录其他文件如出现其他排序视为漂移。

---

## 引擎层输出规则

- 8 闸门均需判定（含"证据缺失"标记）；
- 否定闸门明确标"裁定不予受理"或"驳回起诉"；
- 按诉讼请求逐项输出分项报告，前一请求不通过不影响其他请求继续筛查。

## 闸门 1：生效裁判约束（一事不再理）

**法律依据**：[受案范围负面清单条款]之一事不再理项 + [一事不再理司法解释条款]

**四要件相同性测试**：当事人相同 + 诉讼请求相同 + 诉讼标的相同 + 事实理由相同。四要件全部相同 → 裁定驳回起诉。

**审查要点**：
- 是否存在前诉生效裁判（判决/裁定/调解）；
- 前诉与本诉是否构成同一案件；
- 前诉裁判效力是否覆盖本诉诉讼请求；
- 即判力（既判事项）与争点效（已决争点）的边界。

**鉴定式标准句式**：
```
"本案是否受前诉生效裁判约束，应依[一事不再理司法解释条款]四要件相同性测试审查。
 本案中，[当事人/诉讼请求/诉讼标的/事实理由]与前诉 [相同/不同]，故 [构成/不构成] 同一案件。
 因此，闸门 1 [通过/不通过]。"
```

## 闸门 2：受案范围

**法律依据**：[行政诉讼受案范围条款]（正面列举 + 负面排除）+ [受案范围负面清单条款]

**行政行为分类决策树**：
```
被诉行政行为类型 = ?
  ├─ 处罚/强制/许可/征收/确认/登记/给付/赔偿/协议 → 受案范围内
  ├─ 政府文件/行业规章 → 抽象行政行为（仅可附带审查）
  ├─ 公务员任免/奖惩/调动 → [受案范围负面清单条款]内部行政行为项 排除
  └─ 单纯事实行为（非影响权益）→ 排除
```

[受案范围负面清单条款]排除事项：国家行为（国防/外交）、抽象行政行为（除附带审查）、内部行政行为、法律规定由行政机关最终裁决。

**鉴定式标准句式**：
```
"原告本案诉讼是否属于行政诉讼受案范围，应根据[行政诉讼受案范围条款]
 与[受案范围负面清单条款]审查。
 本案中，被诉行为为 [行政行为类型]，属于受案范围正面列举的
 [行政处罚/行政许可/行政强制……]，不属于负面清单排除事项。
 因此，闸门 2 通过。"
```

## 闸门 3：行政复议前置

**法律依据**：[复议前置情形条款] + 单行法

**典型复议前置情形**：
- 自然资源所有权/使用权确认；
- 海关行政行为；
- 税务行政行为缴税争议；
- 单行法明文规定的其他情形。

**审查要点**：属于复议前置但未走复议 → 闸门否定，裁定不予受理。已走复议或非复议前置案件 → 通过。

**鉴定式标准句式**：
```
"本案是否属于法定复议前置情形，应依[复议前置情形条款]及单行法审查。
 本案被诉行为为 [行为类型]，[属于/不属于] 复议前置事项。
 [若属于：原告已于 XXXX-XX-XX 提起复议，复议机关于 XXXX-XX-XX 作出 XX 决定。]
 因此，闸门 3 通过。"
```

## 闸门 4：原告资格

**法律依据**：[原告资格条款] + [利害关系人识别条款]

**保护规范理论**：原告主张被侵害的权益 → 行政法律规范是否赋予其主观公权利？

**判断步骤**：
1. 识别拟适用的行政法律规范；
2. 该规范的保护范围是否包括原告？
   - 仅保护一般公共利益 → 原告资格否定；
   - 保护特定群体（含原告）→ 原告资格肯定；
   - 同时保护公共利益与个体利益 → 原告资格肯定；
3. 原告是否能"援引"该规范获得救济。

**关键判别**：主观公权利（有原告资格）vs 反射利益（无原告资格）。行政相对人无需保护规范理论分析；利害关系人必须经过保护规范理论分析。投诉举报人特殊规则参见 [投诉举报原告资格规则]——投诉举报权利本身受影响有原告资格，但行政机关已作出处理后无原告资格。

> 保护规范理论的强弱形式、主观公权利三要件、保护规范理论引入裁判规则等详见 `../interpretation-toolkit.md` §三。

**[利害关系人识别条款]列举的 5 种典型**：① 行政行为相对人；② 邻人/竞争同业人；③ 投诉举报权利受影响人；④ 撤销/变更行政行为请求权人；⑤ 因人身权/财产权直接受影响而主张其他权益受损人。

**鉴定式标准句式**：
```
"原告是否具有本案诉讼主体资格，应根据[原告资格条款]及保护规范理论审查。
 本案中，原告为 [相对人/利害关系人]。[若为利害关系人：]
 依保护规范理论，原告主张被侵害的 [权益] 是否为行政法律规范所保护？
 [分析规范的保护范围与原告的关系]……
 因此，原告 [具有/不具有] 主观公权利，原告资格 [成立/不成立]。"
```

## 闸门 5：被告适格

**法律依据**：[被告资格条款] + [复议机关共同被告条款] + 行诉解释相关被告认定细则

**被告判定决策树**：

| 情形 | 被告 |
|------|------|
| 一审被诉行政行为 | 作出该行为的行政机关 |
| 委托作出 | 委托机关（[被告资格条款]委托项） |
| 复议维持 | 原机关 + 复议机关共同被告（[复议机关共同被告条款]） |
| 复议改变（事实/法律/结果任一改变） | 仅复议机关 |
| 复议未作出 | 原机关 OR 复议机关不作为（双轨） |
| 行政机关被撤销/合并 | 继续行使职权的机关 |

**复议共同被告强制标记**：经复议案件须在节首明示复议结果与被告确定路径。

## 闸门 6：管辖

**法律依据**：[管辖条款]族（级别管辖 + 地域管辖 + 专属管辖 + 选择管辖）+ 行诉解释相关管辖规则

**三层管辖规则**：
- 级别管辖：中院一审 vs 基层法院一审；
- 地域管辖：行政机关所在地 / 不动产专属 / 限制人身自由选择；
- 集中管辖 / 跨区域管辖：依省高院指定。

**特殊规则**：管辖错误通常不否定全案，应移送有管辖权的法院；但故意规避管辖的可裁定不予受理。

---

## 闸门 7：起诉期限与形式要件

**法律依据**：[起诉期限条款]族 + [起诉条件条款] + 行诉解释相关起诉要件

### 7.1 起诉期限

| 情形 | 起诉期限 |
|------|---------|
| 经复议（受理后） | 15 日（自收到复议决定起） |
| 经复议（超期未作出） | 15 日（自届满之日起） |
| 直接起诉 | 6 个月（自知道或应当知道之日起） |
| 履职之诉 | 60 日未履行 → 6 个月起诉期限 |
| 不知道行政行为内容 | 不动产 20 年 / 其他 5 年最长保护期 |
| 确认无效之诉 | 无起诉期限 |

### 7.2 形式要件

- 诉讼请求具体明确（[起诉条件条款]诉讼请求具体项）；
- 起诉状具备法定要素（当事人/事实理由/证据）；
- 诉讼费用预缴或申请缓减免。

模糊的诉讼请求（如"维护合法权益"）须释明补正。

---

## 闸门 8：诉的利益

**法律依据**：诉之利益的一般法理 + [确认违法判决条款]中"不具可撤销性"分支

**审查要点**：原告通过本诉能否获得实际权益保护？是否存在权利保护必要性？

**典型情形**：
- 行政行为已被撤销/变更 → 撤销之诉无诉的利益（可转确认违法）；
- 行政行为已执行完毕且不可恢复 → 撤销之诉无诉的利益（可转确认违法）；
- 行政行为对原告不再产生实际影响 → 诉的利益消灭；
- 原告主张的权益已通过其他途径获得救济 → 诉的利益消灭。

**诉讼请求转化**：撤销之诉因"不具可撤销性"丧失诉的利益时，原告可转为确认违法之诉，主诉与备位请求分别审查诉的利益。

---

## 闸门 9：可受理性中间结论

**强制收口节**，二选一：

- **全部 8 闸门通过** → 进入可证立性审查；
- **任一闸门不通过** → 仅写"裁定不予受理 / 驳回起诉"分析，可证立性不展开。

---

## 闸门分项报告格式

```yaml
admissibility_screening:
  R1_撤销请求:
    闸门_1_生效裁判约束: 通过
    闸门_2_受案范围: 通过
    闸门_3_复议前置: 通过（非复议前置案件）
    闸门_4_原告资格: 通过
    闸门_5_被告适格: 通过
    闸门_6_管辖: 通过
    闸门_7_起诉期限与形式要件: 通过
    闸门_8_诉的利益: 通过
    闸门_9_中间结论: 全部通过 → 进入可证立性
  R2_赔偿请求:
    闸门_1_生效裁判约束: 通过
    闸门_2_受案范围: 通过
    闸门_3_复议前置: 通过
    闸门_4_原告资格: 通过
    闸门_5_被告适格: 通过
    闸门_6_管辖: 通过
    闸门_7_起诉期限与形式要件: 不通过（超过起诉期限）
    闸门_9_中间结论: 部分否定 → 该请求项裁定不予受理
    备注: R2 不影响 R1 的审查进程
```
