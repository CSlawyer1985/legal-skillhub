# 六要素通用合法性审查骨架 + 缺陷分级 + 概念纪律

> **定位**：本文件作为"可证立性层 六要素内嵌子骨架"，在撤销之诉、确认违法之诉、确认无效之诉、行政赔偿之诉的 W2b/W3 阶段嵌入使用。它不构成独立工作流，前序的可受理性筛查、诉讼请求类型识别、行政行为类型路由不得跳过；多行政行为单元的并行审查中，每个 act_id 调用一次本子骨架。本文件融合通用涵摄模板（六要素逐项展开）、缺陷分级三档（无效/撤销/确认违法）、判决类型决策树以及概念纪律守则（不确定法律概念锚定），是合法性审查的方法论总闸。

> **法条解耦原则**：本文件作为方法论文件，原则上不出现具体条文编号。语义概念（如"撤销判决要件""确认无效条款"）与具体条号（如《行政诉讼法》§70 / §75）的映射统一登记在 `SKILL.md §6.5 法条锚定表`，由 MCP 运行时核验。

## § 一 六要素通用涵摄骨架

### 1.0 审查铁律（六要素涵摄前置规则）

**铁律一：羁束 / 裁量行为判定为 Step 0**

进入六要素涵摄前，必须先判定被诉行政行为属于"羁束行为"还是"裁量行为"：

- **羁束行为**：法律条件成就即应作出特定内容的决定，无选择空间（如颁发法定证照、税额核定）；
- **裁量行为**：法律授予行政机关在多种合法选择之间作出取舍的空间（如处罚幅度、行政许可的赋予/拒绝）。

判定路径：① 检视作出依据条文是否使用"应当 + 具体内容"（羁束）还是"可以 / 给予 N 种以下"（裁量）；② 对照行政行为类型清单（参见 `../case-router.md §2.1`）；③ 不明时按"宽于授权"推定为羁束。

**铁律二：Step 1-4 任一违法即短路撤销**

主体（要素四）、程序（要素三）、事实证据（要素一）、法律适用（要素二）四个要素，**任一不满足即直接得出"撤销 / 确认违法"结论，跳过 Step 5（裁量审查）与 Step 6（处理结果）**。

理由：行政行为的主体/程序/事实/法律适用瑕疵已构成独立违法事由，无须再行裁量审查。在 W3 写作中可裁判式一句话标注"Step 5、Step 6 因前 4 要素已违法，依审查铁律不再展开"。

**铁律三：Step 5 仅对裁量行为启动**

裁量审查（要素五）仅在 Step 0 判定为"裁量行为"且前 4 要素全部通过时启动。羁束行为无裁量空间，不启动 Step 5，直接进入 Step 6。

**铁律四：Step 6 处理结果适当性兜底**

前 5 步全部通过后，仍须以处理结果（要素六）作兜底审查，识别"形式合法但实质明显不当"情形（详见 `../proportionality-and-discretion.md` 明显不当独立通道）。

**审查铁律决策树**：

```
Step 0  判定羁束 / 裁量
   │
   ▼
Step 1  主体（要素四）─ 不合法 → 短路：撤销 / 确认违法
   │ 合法
   ▼
Step 2  程序（要素三）─ 重大违法 → 短路：撤销
                       ─ 轻微违法 → 短路：确认违法
   │ 合法
   ▼
Step 3  事实证据（要素一）─ 不合法 → 短路：撤销
   │ 合法
   ▼
Step 4  法律适用（要素二）─ 不合法 → 短路：撤销
   │ 合法
   ▼
Step 5  仅裁量行为启动：裁量（要素五）─ 不合法 → 撤销 / 变更
   │ 合法 或 羁束行为跳过
   ▼
Step 6  处理结果（要素六）─ 明显不当 → 撤销 / 变更
   │ 适当
   ▼
全部要件成立 → 驳回诉讼请求
```

> 鉴定式学术报告允许在 W4 verification 阶段穿透铁律、展示全要素分析（参见 `examination-sequence.md §五 穷尽原则`）；实务写作（litigation / pre-enforcement 场景）应严格遵守铁律以提升效率。

### 1.1 六要素总览

撤销判决要件（参见 `SKILL.md §6.5` 锚定的"撤销判决要件条款"）= 行政行为合法性审查的通用骨架：

| 序号 | 对应要件 | 审查内容 | 缺陷后果 |
|------|---------|---------|---------|
| (1) 主要证据不足 | 实体要件——事实证据 | 关键事实是否查明、证据是否充分合法 | 撤销 |
| (2) 适用法律法规错误 | 实体要件——法律适用 | 引用条文是否有效、是否对应、是否遗漏 | 撤销 |
| (3) 违反法定程序 | 程序要件 | 法定程序步骤是否完整履行 | 撤销/确认违法 |
| (4) 超越职权 | 主体要件 | 行政机关是否在法定职权范围内 | 撤销 |
| (5) 滥用职权 | 裁量要件 | 裁量动机是否正当、是否考虑不当因素 | 撤销 |
| (6) 明显不当 | 处理结果适当性要件 | 处理结果是否客观合理 | 撤销/变更 |

每个要素严格按"总起句 → 定义 → 归入 → 结论"四步展开（涵摄四步法），遵循鉴定式写作规范。

### 1.2 要素一：主要证据是否确凿（事实证据要件）

**总起句**：被告作出被诉行政行为所依据的主要证据可能不足。

**定义**：依撤销判决要件中的"主要证据不足"项，包括四种形式：
① 主要事实没有相应证据；
② 证据相互矛盾未排除；
③ 证据形式/收集违法；
④ 关键事实证据缺失。

"主要证据"指对认定违法事实/许可条件成立/征收条件成立等具有决定性意义的证据。"确凿"要件包含 (a) 证据真实性；(b) 证据合法性（取证程序合法）；(c) 证据关联性；(d) 证据充分性（达到行政证据标准）。

举证责任倒置（依"被告举证责任倒置条款"）：被告应提供作出行政行为的全部证据，逾期视为无证据。被告举证不足的，无论原告是否提出反证，法院应当判决撤销。

**归入**：
- 列出被告所举主要证据清单；
- 对每项证据从 (a)(b)(c)(d) 四维评价；
- 重点审查证据收集程序是否违反行政处罚程序规范（依"非法证据排除条款"）；
- 评估证据链完整性；
- 依"被告举证责任倒置条款"，被告应当证明 [违法事实] 成立，否则承担举证不能的不利后果。

**结论**：主要证据 [确凿 / 部分不足 / 不足] + 缺陷等级判定。

**常见争点**：证据"足以认定"vs"不足以认定"争议；非法证据排除；行政机关诉讼中补证禁止（依"行政机关补证禁止条款"）。

### 1.3 要素二：适用法律、法规是否正确（法律适用要件）

**总起句**：被告作出被诉行政行为时适用的法律法规可能错误。

**定义**：依撤销判决要件中的"适用法律法规错误"项，包括五种精细形态：
- (a) 法律性质错误（援引刑法规范处理行政事项等）
- (b) 法律种类错误（应适用甲法却适用乙法）
- (c) 具体条款错误（条号、款项错误）
- (d) 法律版本错误（应适用旧法却适用新法或反之，含从旧兼从轻规则）
- (e) 规范性文件抵触（援引的下位法与上位法抵触）

亦概括为：适用了不该适用的法律、漏适用应当适用的条款、法律解释不合理、跨版本引用错误。

**归入**：
- 识别被告援引的全部法律依据；
- 逐条核对现行有效性；
- 按 (a)–(e) 五种形态逐一筛查；
- 若涉及法律解释争议，启用法律解释方法工具增强论证；
- 援引条文 [现行有效性 / 对应性 / 与上位法关系] 分析。

**结论**：法律适用 [正确 / 存在某种形态错误] + 缺陷等级判定。

**常见争点**：法条选择争议；司法解释适用错误；规范性文件合法性（嵌入附带审查）。

### 1.4 要素三：是否符合法定程序（程序要件）

**总起句**：被告作出被诉行政行为的程序可能违反法定程序。

**定义**：依撤销判决要件中的"违反法定程序"项，指行政机关未遵守法律规定的程序步骤。法定程序指相应行政行为类型的程序法规则集合，审查重点包括：
- 告知义务（处罚前告知 / 许可申请受理告知等）
- 听取陈述申辩（依"听取陈述申辩条款"）
- 听证程序（依"处罚听证条款"/"许可听证条款"）
- 回避制度
- 送达程序
- 决定的书面形式与说明理由
- 行政行为类型专属程序

程序违法分三级：重大程序违法（撤销）/ 一般程序违法（撤销）/ 程序轻微违法（确认违法）。

**归入**：
- 按程序时序逐步比对，审查每一程序节点；
- 识别程序瑕疵；
- 区分**重大程序违法**（影响实体结果或剥夺当事人核心程序权利）与**轻微程序违法**（不影响实体结果）。

**结论**：程序 [合法 / 轻微程序违法 / 重大程序违法] + 缺陷等级判定。

**常见争点**：听取陈述申辩是否实质履行；听证程序是否应当启动；程序瑕疵分级争议（撤销 vs 确认违法）。

**程序违法分级详表**：

| 违法等级 | 典型情形 | 法律后果 |
|---------|---------|---------|
| 重大程序违法 | 未听取陈述申辩；应当听证未听证；未告知作出决定的依据；未送达决定文书；应当回避未回避 | 撤销 |
| 一般程序违法 | 程序步骤遗漏；期限严重超限；通知方式不当（但相对人知情） | 撤销 |
| 程序轻微违法 | 程序文书内容轻微错误；期限轻微超限（不影响结果）；文书形式瑕疵（但相对人收到） | 确认违法（不撤销，依"确认违法判决条款"程序轻微违法分支） |

程序违法是否"影响实体结果"是分级关键：若程序违法对行政行为的实体内容没有实质影响（如告知书文号写错但当事人已实际收到并行使了权利），则归入"程序轻微违法"。

### 1.5 要素四：是否超越职权（主体职权要件）

**总起句**：被告作出被诉行政行为可能超越法定职权。

**定义**：依撤销判决要件中的"超越职权"项，指行政机关作出的行为超出其组织法或作用法授权范围。审查三个层面：组织法依据 → 作用法依据 → 管辖范围。

具体形态包括：
- (a) 主体不适格（无相应行政职权的主体作出）
- (b) 事项越权（超出本机关法定管辖事项）
- (c) 地域越权（超出本机关法定管辖地域）
- (d) 层级越权（应由上级作出却由下级作出，或反之）
- (e) 委托/授权越权（受委托/受授权范围之外）

**归入**：
- 核查被告的法定职权范围（组织法依据）：被告 [机关名称] 的组织法依据为 [XX 法 §A]，作用法依据为 [XX 法 §B]；
- 比对作出行为的事项 / 地域 / 层级；
- 若涉及委托/授权关系，核查授权依据与范围。

**结论**：被告 [具有 / 不具有] 相应职权（如不具有，指明形态）+ 缺陷等级判定（超越职权一般 → 撤销，特别严重 → 确认无效）。

**常见争点**：法定职权来源不清；派出机构 / 委托关系的主体识别；跨部门联合执法的职权归属。

### 1.6 要素五：是否滥用职权（裁量要件）

**总起句**：被告行使裁量权时可能构成滥用职权。

**定义**：依撤销判决要件中的"滥用职权"项，指行政机关在法定裁量空间内作出不当选择，形式合法但裁量过程存在重大瑕疵。裁量瑕疵识别四线索（详见 `../proportionality-and-discretion.md §三`）：

```
线索一：裁量逾越
  "被告的行政行为是否超出法定裁量空间？
   本案中，法律规定 [幅度]，被告作出 [处理结果]，[是否在幅度内]。"

线索二：裁量滥用
  "被告在法定裁量空间内的选择是否正当？
   被告是否 [违背行政目的 / 遗漏应考虑因素 / 考虑不当因素 / 违背平等对待]？"

线索三：裁量怠惰
  "被告是否应当行使裁量权而未行使？
   被告是否存在 [不作出决定 / 一刀切处理 / 机械适用内部规则] 的情形？"

线索四：比例原则（详见 ../proportionality-and-discretion.md §一）
  "被告的手段与目的是否成比例？（目的正当性 → 适当性 → 必要性 → 均衡性四阶审查）"
```

**归入**：
- 识别被告享有的裁量空间；
- 检查裁量基准是否公布并被遵守（依"裁量基准公开条款"）；
- 按四线索逐一审查；
- 若发现裁量收缩至零情形，启动比例原则与裁量收缩处理流程。

**结论**：[未滥用职权 / 构成滥用职权（指明形态）] + 缺陷等级判定。

**常见争点**：裁量审查密度（形式审查 vs 实质审查）；行政机关是否遗漏应考虑的因素；是否考虑了不应考虑的因素。

### 1.7 要素六：是否明显不当（处理结果适当性要件）

**总起句**：被诉行政行为的处理结果可能构成明显不当。

**定义**：依撤销判决要件中的"明显不当"项，指行政行为虽未违法，但客观上不合常理 / 明显失当——裁量结果显著偏离合理范围，区别于"滥用职权"侧重于裁量过程瑕疵。

判断四维度：
① 客观判断（有无法律依据）；
② 比较判断（同类案件对比）；
③ 价值判断（是否违背行政目的）；
④ 比例原则审查（详见 `../proportionality-and-discretion.md`）。

审查标准：
- (a) 处罚与违法行为情节明显不相适应；
- (b) 同类案件处理结果明显失衡；
- (c) 违反比例原则均衡性子原则导致结果显著不合理。

**归入**：
- 调取同类案件裁量基准 / 类似案件；
- 比对本案处罚幅度与 [同类案件 / 法定幅度 / 行政目的]；
- 套用比例原则均衡性子原则（损益衡量）；
- 判断是否构成"明显"不当（撤销判决要件中的"明显不当"较变更判决要件中的"明显不当"门槛更低但仍需达到显著程度）。

**结论**：[内容适当 / 明显不当] + 缺陷等级判定（明显不当 → 撤销；显著失衡且可量化 → 变更判决，依"变更判决条款"）。

**常见争点**：明显不当的判断尺度（严格说 vs 宽松说）；比例原则四阶审查的展开深度。

### 1.8 六要素协同审查

六要素并非孤立审查，而是形成完整的合法性审查链：

```
主体要件（要素四） →  确认"谁有权做"
   ↓
程序要件（要素三） →  确认"怎么做的"
   ↓
实体要件（要素一、二） →  确认"事实是否成立、法律是否适用正确"
   ↓
裁量要件（要素五、六） →  确认"做得是否
