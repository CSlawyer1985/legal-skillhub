# 民事起诉状格式规范与写作要点

## 一、标准结构

民事起诉状由以下部分组成，顺序不可调换：

```
民事起诉状（标题）

原告信息
被告信息

诉讼请求

事实与理由

此致
____人民法院

起诉人：____
____年____月____日

附：
```

## 二、各部分写作规范

### 2.1 标题

- 居中书写"民事起诉状"
- 不加书名号、不加案由
- 字体：宋体二号加粗

### 2.2 当事人信息

**自然人**：
```
原告：张三，男，1990年1月1日出生，汉族，住____省____市____区____路____号，联系方式：________
被告：李四，女，1988年5月15日出生，汉族，住____省____市____区____路____号，联系方式：________
```

**法人/非法人组织**：
```
原告：____有限公司，住所地____省____市____区____路____号，统一社会信用代码：________
法定代表人：____，职务：____
被告：____有限公司，住所地____省____市____区____路____号，统一社会信用代码：________
法定代表人：____，职务：____
```

**注意事项**：
- 有多个原告/被告时依次列出，用"原告一""原告二"或"被告一""被告二"区分
- 当事人信息缺失时用"____"占位
- 第三人列在被告之后

### 2.3 诉讼请求

**写作要求**：
- 每项请求单独编号（1. 2. 3.）
- 表述必须明确、具体、可执行
- 避免模糊表述（如"适当赔偿""合理补偿"）
- 最后一项通常为"判令被告承担本案全部诉讼费用"

**类案驱动原则（核心规则）**：
- 每项诉讼请求**必须标注对应的类案编号**和裁判要旨
- 诉讼请求的表述方式**必须参考类案中获支持请求的规范表述**
- 不得仅凭独立法律分析提出诉讼请求——必须有类案支撑
- 如果某项请求在检索到的类案中无先例支撑，应在起诉状中以注释形式标注"此项请求无直接类案支撑，存在被驳回风险"

**请求结构规则**：

1. **按被告区分请求**：不同被告对应不同请求权基础的，分别列项，不混合
   ```
   正确：请求1（针对被告C）+ 请求2（针对被告D）——不冲突，可并列
   错误：请求1（连带清偿，针对所有被告）+ 请求2（补充赔偿，针对所有被告）——冲突，后者被前者吸收
   ```

2. **主位/备位请求结构**：同一被告的竞合请求权，采用主位+备位结构
   ```
   请求2（主位）：判令被告D在未出资范围内承担补充赔偿责任
   请求3（备位）：如法院认定被告D存在[特定情形]，请求判令被告D承担[其他责任]
   ```
   备位请求以"如法院认定……"开头，表明仅在主位请求不被支持时才主张。

3. **责任类型不得混淆**：
   - **连带清偿责任**（全额）——对应人格否认、一人公司财产混同等，责任范围是全部债务
   - **补充赔偿责任**（限额）——对应出资瑕疵，责任范围仅限未出资本息
   - 两者不可对同一被告并列主张（除非采用主位/备位结构）
   - 前股东转让股权后，责任上限通常为补充赔偿，不因"恶意"升格为连带清偿

**常见请求类型与规范表述**：

| 请求类型 | 规范表述示例 |
|---------|------------|
| 确认之诉 | "请求确认原告与被告于____年____月____日签订的《____合同》有效/无效/解除" |
| 给付之诉（金钱） | "判令被告向原告支付____元（含本金____元、利息/违约金____元）" |
| 给付之诉（标的物） | "判令被告向原告交付____（标的物名称、规格、数量）" |
| 给付之诉（行为） | "判令被告停止____行为/履行____义务" |
| 形成之诉 | "请求解除原告与被告于____年____月____日签订的《____合同》" |
| 损害赔偿 | "判令被告赔偿原告经济损失____元（包括：____费____元、____费____元）" |

**金额计算**：
- 涉及利息/违约金时，注明计算方式："以____元为基数，按____标准，自____年____月____日起计算至实际付清之日止"
- 涉及多项费用时，列明明细

### 2.4 事实与理由

**事实部分**：
- 按时间先后顺序叙述
- 客观陈述，不使用主观评价性语言
- 每个事实节点标注对应证据（如"（见证据一）"）
- 突出与诉讼请求有因果关系的关键事实

**理由部分**：
- 引用具体法律条文（精确到条、款、项）
- 采用"法律规范 → 事实涵摄 → 结论"的三段论结构
- 参考类案中法院的裁判逻辑和说理方式
- 针对被告可能提出的抗辩预先回应

**法律条文引用格式**：
```
根据《中华人民共和国____法》第____条第____款规定："____（条文内容）"
```

**理由部分写作框架**：
```
综上所述，原告认为：
第一，____（事实定性）——根据《____法》第__条__款，____。
第二，____（法律适用）——本案中，被告____行为符合____，应当承担____责任。
第三，____（请求依据）——原告的诉讼请求具有事实和法律依据，依法应予支持。
```

### 2.5 尾部

```
此致
____人民法院（有管辖权的法院全称）

起诉人：____（原告签名/盖章）

____年____月____日

附：
1. 本起诉状副本____份
2. 证据材料____份
3. 原告身份证明/营业执照复印件____份
```

## 三、排版规范

- 纸张：A4 纵向
- 页边距：上下 2.54cm，左右 3.18cm
- 正文字体：宋体小四号（12pt）
- 行距：1.5 倍行距
- 标题字体：宋体二号加粗
- 段落首行缩进 2 字符
- 诉讼请求各项之间空一行

## 四、常见问题

1. **管辖法院确定**：
   - 一般地域管辖：被告住所地法院
   - 合同纠纷：被告住所地或合同履行地法院
   - 侵权纠纷：被告住所地或侵权行为地法院
   - 不动产纠纷：不动产所在地法院（专属管辖）
   - 协议管辖：依有效管辖协议确定

2. **诉讼请求金额确定**：
   - 参考类案判决中获支持的金额标准
   - 利息/违约金计算至起诉之日（实际计算至付清之日）
   - 财产保全费用的承担

3. **证据清单编写**：
   - 每份证据编号、命名
   - 注明证据来源（原件/复印件）
   - 写明证明目的（证明什么事实）

## 五、类案驱动撰写指南

### 5.1 核心原则

**起诉状的每一项内容都必须由类案材料驱动，不得仅凭独立法律分析撰写。**

| 起诉状部分 | 类案驱动要求 |
|-----------|------------|
| 诉讼请求 | 每项请求标注对应类案编号和裁判要旨；表述方式参考类案中获支持请求的规范表述 |
| 事实与理由 | 法律论证引用类案裁判要旨；法条援引参考类案中法院引用的法律依据 |
| 当事人定位 | 被告/第三人定位参考类案中的当事人结构 |
| 风险评估 | 风险点来源于类案中的争议焦点和驳回理由 |

### 5.2 撰写流程

1. **梳理类案裁判要旨**：将检索到的类案按法律关系路径分组，提取每组的核心裁判规则
2. **构建诉讼请求**：基于类案中获支持请求的表述方式，构建本案诉讼请求，标注类案支撑
3. **撰写事实理由**：以类案裁判逻辑为框架，将本案事实涵摄到法条构成要件中
4. **校验法律逻辑**：对照法律逻辑校验清单（见下方），逐项校验

### 5.3 诉讼请求标注格式

每项诉讼请求后以注释形式标注类案支撑：
```html
<li>判令被告C对A公司欠付原告的[金额]元债务承担连带清偿责任；
<span style="color:#666;font-size:9pt;">
（请求权基础：一人公司财产混同——《公司法》第23条第3款；
类案支撑：参考案例2024-08-2-084-004，一人公司现股东不能证明财产独立→对受让前后债务均承担连带责任）
</span></li>
```

## 六、法律逻辑校验规则

### 6.1 责任类型与被告匹配校验

| 责任类型 | 适用对象 | 请求权基础 | 常见错误 |
|---------|---------|-----------|---------|
| 连带清偿（全额） | 一人公司**现**股东 | 公司法§23③ | ❌ 将此责任安在前股东身上（前股东非一人公司现股东） |
| 连带清偿（全额） | 控制股东/实际控制人 | 公司法§23①② | ❌ 将此责任安在非控制股东身上 |
| 补充赔偿（未出资范围） | 未履行出资义务的股东 | 公司法§54+司法解释三§13② | ❌ 将此责任升格为全额连带清偿 |
| 对出资义务连带 | **受让人**（知情） | 司法解释三§18 | ❌ 将连带责任安在转让人身上（转让人责任上限是补充赔偿） |

### 6.2 诉讼请求冲突校验

**规则1：不同被告的请求可并列**
```
✅ 请求1：被告C承担连带清偿（人格否认/一人公司混同）
✅ 请求2：被告D在未出资范围内承担补充赔偿（出资瑕疵）
→ 针对不同被告、不同请求权基础，不冲突
```

**规则2：同一被告的竞合请求须用主位/备位**
```
❌ 请求1：被告D承担连带清偿（全额）
❌ 请求2：被告D在未出资范围内承担补充赔偿
→ 冲突：请求1吸收请求2

✅ 请求2（主位）：被告D在未出资范围内承担补充赔偿
✅ 请求3（备位）：如法院认定被告D存在[特定情形]，请求判令被告D承担连带清偿
→ 主位/备位结构，不冲突
```

**规则3：一人公司原股东的特殊规则**
```
若公司在转让前即是一人公司，原股东在持股期间不能证明财产独立的，
对持股期间债务承担连带清偿——这是举证责任倒置的结果，不是"恶意"升格。
需通过类案确认此规则是否适用于本案。
```

### 6.3 常见法律逻辑错误警示

1. **混淆连带清偿与补充赔偿**：前股东转让股权后，即使存在恶意，责任上限通常仍为补充赔偿（未出资本息范围），不升格为全额连带清偿——除非适用一人公司举证责任倒置

2. **受让人连带责任方向搞反**：司法解释三第18条的连带责任落在**受让人**头上（受让人对转让人的出资义务承担连带责任），不是转让人的责任升级

3. **一人公司财产混同责任对象错误**：公司法第23条第3款的连带责任针对的是**现一人股东**，不是前股东。前股东如需承担连带责任，须通过其他路径（如持股期间即是一人公司且不能证明财产独立）

4. **离婚财产转移的法律路径错误**：离婚财产转移通常需**另案**提起债权人撤销权诉讼（民法典§538/539），不与股东损害债权人利益纠纷合并审理。在本案中，离婚财产转移可作为佐证证据（证明C知情、证明财产混同等），但不是独立的诉讼请求

5. **遗漏关键法律关系路径**：仅从案情表面分析可能遗漏重要路径。必须通过前置搜索全面识别所有可能的法律关系路径，再通过类案检索验证
