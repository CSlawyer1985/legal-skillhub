# 案件风险评估框架

## 一、风险评估五大维度

### 1.1 诉讼主体风险

**评估清单**：

| 检查项 | 风险描述 | 应对建议 |
|--------|---------|---------|
| 原告适格性 | 原告是否为直接利害关系人 | 确认原告与案件有直接法律利害关系；如非直接权利人，考虑权利继受或代位诉讼 |
| 被告准确性 | 被告是否为正确义务主体 | 核实被告身份信息；如涉及多主体，确认责任主体；警惕主体混同情况 |
| 共同诉讼人 | 是否遗漏必要共同诉讼当事人 | 检查是否存在必要共同原告/被告；遗漏可能导致程序瑕疵或实体处理不当 |
| 诉讼代理人 | 委托代理人资格和权限 | 确认授权委托书范围；特别授权事项须明确列出 |

**常见风险场景**：
- 债权转让后受让人起诉，需确认转让通知已到达债务人
- 企业注销后诉讼主体确定，需查明清算义务人
- 合伙企业涉诉，需区分合伙企业诉讼与合伙人诉讼

### 1.2 诉讼请求风险

**评估清单**：

| 检查项 | 风险描述 | 应对建议 |
|--------|---------|---------|
| 请求明确性 | 请求是否具体、可执行 | 金额须明确，行为请求须具体；避免"适当""合理"等模糊表述 |
| 请求依据 | 请求是否有事实和法律依据 | 每项请求须有对应事实和法条支撑；参考类案获支持请求的表述 |
| 请求竞合 | 是否存在请求权竞合需选择 | 如违约与侵权竞合，须择一行使；选择更有利于原告的请求权基础 |
| 诉讼时效 | 请求是否超过诉讼时效 | 核实诉讼时效起算点、是否有时效中断/中止事由；注意特殊时效规定 |
| 金额计算 | 请求金额计算是否准确 | 核对本金、利息/违约金计算方式；注明计算公式和起止日期 |
| 保全必要性 | 是否需要申请财产保全 | 如被告有转移财产风险，建议同步申请财产保全 |

**常见风险场景**：
- 诉讼时效届满：从知道或应当知道权利受损之日起 3 年（一般时效）
- 违约金过高：法院可能依申请调减，参考类案中的支持比例
- 精神损害赔偿：仅限人身权益受损情形，金额需合理

### 1.3 事实认定风险

**评估清单**：

| 检查项 | 风险描述 | 应对建议 |
|--------|---------|---------|
| 关键事实证据 | 关键事实是否有证据支撑 | 逐项梳理事实对应的证据；无证据支撑的事实主张可能不被认定 |
| 举证责任 | 举证责任分配是否对己方有利 | 分析举证责任归属；如举证困难，寻找举证责任倒置或转移的依据 |
| 证据瑕疵 | 证据是否存在合法性/真实性/关联性问题 | 审查证据"三性"；瑕疵证据需补强或提供佐证 |
| 证据形式 | 证据形式是否符合法定要求 | 电子证据需符合电子数据存证要求；境外证据需公证认证 |
| 证人证言 | 是否有关键证人及其出庭意愿 | 证人须出庭作证（除法定例外）；提前沟通证人出庭事宜 |

**常见风险场景**：
- 现金交易无书面凭证：仅凭转账记录可能不足以证明借贷合意
- 电子数据证据：微信聊天记录需完整未经篡改，建议公证保全
- 证人不到庭：书面证言证明力较弱，可能不被采信

### 1.4 法律适用风险

**评估清单**：

| 检查项 | 风险描述 | 应对建议 |
|--------|---------|---------|
| 案由选择 | 案由是否准确反映法律关系性质 | 准确定性法律关系；参考类案法院的案由认定 |
| 管辖法院 | 管辖法院是否有管辖权 | 核实管辖依据（地域管辖+级别管辖）；协议管辖条款的有效性 |
| 法律适用 | 适用法律是否正确 | 确认适用的法律及司法解释；注意新旧法衔接问题 |
| 程序合规 | 起诉是否符合法定受理条件 | 检查起诉条件（民诉法第122条）；前置程序是否完备（如劳动仲裁前置） |

**常见风险场景**：
- 案由认定分歧：同一事实可能涉及多个案由（如"合同纠纷" vs "不当得利"），选择影响法律适用
- 管辖异议：被告可能提出管辖异议拖延诉讼，需提前准备答辩
- 劳动争议：须先经劳动仲裁，对仲裁裁决不服方可起诉

### 1.5 执行风险

**评估清单**：

| 检查项 | 风险描述 | 应对建议 |
|--------|---------|---------|
| 被告履行能力 | 被告是否有可供执行的财产 | 调查被告财产线索（房产、车辆、银行账户、股权等） |
| 财产保全 | 是否已采取保全措施 | 胜诉概率较高时建议申请诉前/诉中财产保全 |
| 被告规避执行 | 被告是否有转移财产倾向 | 关注被告近期财产变动情况；必要时申请保全 |
| 执行不能 | 判决可能无法实际执行到位 | 评估执行可行性；告知当事人执行风险 |

## 二、法官关注点预测方法

### 2.1 预测依据

基于类案检索结果，从以下角度预测法官可能重点关注的问题：

1. **类案争议焦点归纳**：统计类案中法院归纳的争议焦点，高频焦点即为法官关注重点
2. **法院说理重点**：分析法院在"本院认为"部分着重论述的问题
3. **举证责任论述**：法院对举证责任分配的论述反映其关注点
4. **驳回理由分析**：法院驳回某项请求的理由揭示其审查重点

### 2.2 常见法官关注问题类型

**事实查明类**：
- 关键时间节点是否清楚（合同签订时间、履行期限、违约时间）
- 金额计算是否有依据（本金、利息、违约金的计算方式和标准）
- 当事人之间的沟通记录是否完整（有无变更约定、催告记录）

**法律适用类**：
- 法律关系性质认定（是借贷还是投资？是买卖还是承揽？）
- 合同效力问题（是否存在无效事由）
- 责任承担方式（违约责任 vs 缔约过失责任 vs 侵权责任）
- 责任减轻/免除事由（不可抗力、过失相抵、约定免责条款）

**程序类**：
- 诉讼时效是否届满
- 管辖权问题
- 当事人适格问题

### 2.3 应对建议编写要点

针对每个预测的法官关注问题，提供简要应对建议：

```
问题：[法官可能关注的问题]
分析：[为什么法官会关注这个问题]
应对：[建议如何应对，包括举证方向、法律论证角度]
```

**示例**：
```
问题：现金交付部分借款是否实际发生
分析：法院通常对大额现金交付持审慎态度，需审查交付能力、交付场景
应对：补充取款记录、在场证人证言、借款人收款确认等证据；如证据不足，考虑降低该部分诉请金额
```

## 三、风险等级评定

对每个风险点进行等级评定：

| 等级 | 标识 | 说明 |
|------|------|------|
| 高风险 | 🔴 | 可能导致败诉或诉讼请求被驳回的风险 |
| 中风险 | 🟡 | 可能导致部分请求不被支持或诉讼周期延长 |
| 低风险 | 🟢 | 存在一定不确定性但影响可控 |

在风险分析区块中，按风险等级从高到低排列，优先提示高风险事项。
