# 法律关系分析与前置搜索策略

## 一、核心原则

**起诉状的每一项诉讼请求、事实理由、法律适用，都必须有类案材料支撑，不得仅凭独立法律分析撰写。**

正确流程：
```
案情简介 → 前置搜索（WebSearch + 微信搜索）确定关键字与法律关系 → 确认法律关系路径 → 用关键词组检索类案 → 基于类案材料撰写起诉状
```

错误流程（须避免）：
```
案情简介 → 直接凭法律知识分析 → 直接写起诉状 → 事后找类案补充
```

## 二、前置搜索策略（第零步核心环节）

### 2.1 搜索工具

| 工具 | 用途 | 适用场景 |
|------|------|---------|
| `WebSearch`（topic: legal） | 搜索法律条文、司法解释、学术文章 | 确定请求权基础、法条适用 |
| `WebSearch`（topic: general） | 搜索微信公众号法律文章、实务分析 | 了解实务做法、裁判趋势 |
| `WebFetch` | 抓取具体法律文章全文 | 深入阅读某篇分析文章 |

**微信搜索策略**：大量优质法律实务文章发布在微信公众号上。使用 `WebSearch` 搜索时，在查询词中加入"公众号""实务""案例"等词，可有效检索到微信法律文章。例如：
- `"股东损害公司债权人利益 请求权基础 公众号"`
- `"一人公司 财产混同 举证责任倒置 实务"`
- `"股权转让 出资责任 受让人连带 司法解释"`

### 2.2 搜索维度与关键词模板

对每个案情，按以下 **5 个维度** 进行大范围搜索，每个维度 1-2 次 WebSearch：

#### 维度一：案由与法律关系定性
```
搜索目的：确认本案涉及的案由名称、法律关系性质
搜索关键词模板："[案情核心事实描述] 法律关系 案由 类型"
示例："股东损害公司债权人利益责任纠纷 法律关系 请求权基础 类型"
```

#### 维度二：核心请求权基础
```
搜索目的：确认可能适用的法条和司法解释
搜索关键词模板："[法律关系/案由] [核心法律概念] 法条 司法解释"
示例："一人有限责任公司 股东财产混同 举证责任倒置 公司法 连带责任"
```

#### 维度三：特殊事实情节的法律意义
```
搜索目的：确认案情中特殊事实（如离婚转移财产、股权转让等）的法律评价
搜索关键词模板："[特殊事实] [法律后果] [相关法条]"
示例："股权转让 前股东 出资责任 补充赔偿 受让人连带 司法解释三第十八条"
```

#### 维度四：关联行为的法律路径
```
搜索目的：发现可能被忽略的请求权路径
搜索关键词模板："[关联行为] 逃避债务 债权人 [救济方式]"
示例："离婚转移财产 逃避债务 债权人撤销权 股东损害债权人利益"
```

#### 维度五：实务争议与裁判趋势
```
搜索目的：了解法院裁判倾向、实务争议焦点
搜索关键词模板："[案由/法律问题] 认定标准 裁判趋势 实务"
示例："一人公司 财产混同 连带责任 认定标准 裁判趋势"
```

### 2.3 搜索结果处理

从每次 WebSearch 结果中提取：
1. **法律条文**：具体法条编号和内容（如《公司法》第23条第3款）
2. **司法解释**：相关司法解释的编号和适用条件（如公司法司法解释（三）第18条）
3. **法律概念**：关键法律概念的准确定义（如"举证责任倒置""补充赔偿责任"）
4. **裁判规则**：法院的裁判逻辑和认定标准
5. **检索关键词**：可用于裁判文书网/案例库检索的关键词组合
6. **争议焦点**：实务中的常见争议点

### 2.4 搜索结果不足以定论时的处理

如果 WebSearch 结果不足以确认法律关系，可使用 `WebFetch` 抓取具体法律文章全文深入阅读。重点关注：
- 最高法院发布的司法解释理解与适用
- 权威法律期刊文章
- 资深法官/律师的实务分析文章

## 三、法律关系路径分析方法

### 3.1 从案情简介提取法律事实要素

阅读案情简介后，按以下维度提取关键事实：

| 维度 | 提取内容 | 示例 |
|------|---------|------|
| 主体关系 | 各当事人之间的身份/法律关系 | A公司、B公司（债权人）、C（现一人股东）、D（前股东/C前妻）、另一前股东 |
| 核心行为 | 引发纠纷的关键行为 | 股权转让、离婚财产分割、财产转移 |
| 时间线 | 关键事件的时间顺序 | 交易期间→股权转让→离婚→财产转移→起诉→执行不能 |
| 损害结果 | 债权人受到的损害 | 经强制执行无财产可供偿还 |
| 特殊情节 | 可能影响法律评价的特殊事实 | 一人公司、前妻关系、半年内转移房产 |

### 3.2 构建法律关系路径表

基于前置搜索结果，为每个可能的被告/责任主体构建法律关系路径：

```
| 路径 | 责任对象 | 请求权基础 | 责任类型 | 责任范围 | 关键举证要点 | 检索关键词组 |
|------|---------|-----------|---------|---------|------------|------------|
| 1 | [被告X] | [法条编号] | [连带/补充/赔偿] | [全额/限额] | [需证明的事实] | [用于类案检索的关键词] |
| 2 | ... | ... | ... | ... | ... | ... |
```

### 3.3 法律关系图谱

建议使用 `show_widget` 工具生成可视化法律关系图谱，帮助：
- 直观展示各主体之间的法律关系
- 标注每条路径的请求权基础和责任类型
- 确认路径之间是否存在冲突或竞合
- 确定类案检索的关键词组

### 3.4 生成检索关键词组

每条法律关系路径对应一组检索关键词。关键词组构建原则：
- **从法条概念出发**：使用法条中的核心概念作为关键词（如"一人公司""财产混同""举证责任倒置"）
- **组合检索**：将2-3个核心概念组合为一个关键词组
- **多组覆盖**：每条法律关系路径至少1组关键词，确保全面覆盖
- **降级准备**：同时准备简化版关键词（去掉修饰词），以备零结果时降级使用

## 四、常见案件类型的法律关系模板

### 4.1 股东损害公司债权人利益责任纠纷

常见法律关系路径（根据前置搜索确认，以下为参考框架）：

| 路径 | 责任对象 | 请求权基础 | 责任类型 | 关键检索词 |
|------|---------|-----------|---------|-----------|
| 一人公司财产混同 | 现一人股东 | 公司法§23③ | 连带清偿（全额） | 一人公司 财产混同 连带责任 |
| 出资义务加速到期 | 未届出资期限的转让人 | 公司法§54 | 补充赔偿（未出资范围） | 股东损害债权人利益 未出资 补充赔偿 |
| 受让人连带责任 | 知情受让人 | 司法解释三§18 | 对出资义务连带 | 股权转让 出资责任 受让人连带 |
| 恶意转让股权逃债 | 转让人 | 公司法§20 | 视情形而定（需类案确认） | 恶意转让股权 逃债 出资责任 |
| 公司人格否认 | 控制股东 | 公司法§23①② | 连带清偿（全额） | 公司人格否认 连带责任 |
| 清算义务违反 | 清算义务人 | 公司法§232 | 赔偿/连带责任 | 公司吊销未清算 股东 连带责任 |

**重要警示**：
- 前股东转让股权后，责任上限通常为**未出资本息范围内的补充赔偿责任**，不会因"恶意"升格为全额连带清偿——除非适用一人公司举证责任倒置规则
- 连带清偿责任（全额）通常仅适用于：一人公司财产混同（现股东）、公司人格否认（控制股东）、清算义务违反
- 受让人连带责任落在**受让人**头上，不是转让人的责任升级
- 离婚财产转移通常需**另案**提起债权人撤销权诉讼，不合并审理

## 五、法律逻辑校验清单

在确定法律关系路径和撰写起诉状前，逐项校验：

### 5.1 责任类型与被告匹配校验

- [ ] 连带清偿责任（全额）的被告是否确实对应全额连带责任的请求权基础？
- [ ] 补充赔偿责任（限额）的被告是否确实对应出资瑕疵的请求权基础？
- [ ] 是否存在将"补充赔偿"错误升格为"连带清偿"的情况？
- [ ] 是否存在将一人公司财产混同责任错误安在非一人公司股东身上的情况？

### 5.2 诉讼请求冲突校验

- [ ] 同时主张的诉讼请求之间是否存在吸收关系（如全额连带吸收限额补充赔偿）？
- [ ] 如存在竞合，是否采用了主位/备位请求结构？
- [ ] 针对不同被告的请求之间是否相互独立、不冲突？

### 5.3 请求权基础与事实匹配校验

- [ ] 每项诉讼请求是否有明确的法条依据？
- [ ] 事实陈述是否能够涵摄到法条的构成要件中？
- [ ] 是否有类案支撑该请求权基础在类似事实下的适用？

### 5.4 类案驱动校验

- [ ] 每项诉讼请求是否标注了对应的类案编号？
- [ ] 诉讼请求的表述方式是否参考了类案中获支持请求的规范表述？
- [ ] 事实与理由部分的法律论证是否引用了类案裁判要旨？
- [ ] 是否存在未经类案验证的法律观点？
