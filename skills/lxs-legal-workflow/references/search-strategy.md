# 类案检索策略

## 零、前置搜索策略（检索类案前的必要步骤）

**核心原则**：在打开裁判文书网/人民法院案例库之前，必须先通过 WebSearch 和微信搜索进行大范围搜索，确定关键字和法律关系路径。详见 `references/legal-relationship-analysis.md`。

### 0.1 前置搜索的目的

1. **确定案由名称**：从案情简介中无法直接确定准确案由时，通过搜索确认
2. **确认法律关系路径**：一个案情可能涉及多条法律关系路径，须全部识别
3. **确定请求权基础**：每条路径对应的法条和司法解释
4. **生成检索关键词组**：每条法律关系路径对应一组用于裁判文书网/案例库检索的关键词
5. **了解裁判趋势**：法院的裁判倾向、常见争议焦点、举证要点

### 0.2 搜索工具与方法

| 工具 | 用途 | 命令/参数 |
|------|------|---------|
| `WebSearch` (topic: legal) | 搜索法律条文、司法解释、学术文章 | `WebSearch({query: "...", topic: "legal"})` |
| `WebSearch` (topic: general) | 搜索微信公众号法律文章、实务分析 | `WebSearch({query: "... 实务 公众号"})` |
| `WebFetch` | 抓取具体法律文章全文 | `WebFetch({url: "...", prompt: "提取法律分析要点"})` |

**微信搜索技巧**：微信公众号是法律实务文章的主要发布平台。在 WebSearch 查询词中加入"公众号""实务""案例""裁判规则"等词，可有效检索到高质量法律分析文章。

### 0.3 搜索维度（5个维度，每个维度1-2次搜索）

1. **案由与法律关系定性**：`"[案情核心事实] 法律关系 案由 类型"`
2. **核心请求权基础**：`"[法律概念] 法条 司法解释 [责任类型]"`
3. **特殊事实情节的法律意义**：`"[特殊事实] [法律后果] [相关法条]"`
4. **关联行为的法律路径**：`"[关联行为] 逃避债务 债权人 [救济方式]"`
5. **实务争议与裁判趋势**：`"[案由] 认定标准 裁判趋势 实务"`

### 0.4 搜索结果处理

从搜索结果中提取：
- 具体法条编号和内容
- 司法解释编号和适用条件
- 关键法律概念定义
- 法院裁判规则和认定标准
- 可用于裁判文书网检索的关键词组合
- 实务争议焦点

### 0.5 产出：法律关系路径表

前置搜索完成后，产出一张法律关系路径表，每条路径包含：责任对象、请求权基础、责任类型、责任范围、关键举证要点、检索关键词组。此表直接驱动后续类案检索。

**示例（股东损害公司债权人利益责任纠纷）**：

| 路径 | 责任对象 | 请求权基础 | 责任类型 | 检索关键词组 |
|------|---------|-----------|---------|------------|
| 1 | 现一人股东C | 公司法§23③ | 连带清偿（全额） | 一人公司 财产混同 连带责任 |
| 2 | 前股东D+另一前股东 | 公司法§54+司法解释三§13② | 补充赔偿（未出资范围） | 股东损害债权人利益 未出资 补充赔偿 |
| 3 | 受让人C | 司法解释三§18 | 对出资义务连带 | 股权转让 出资责任 受让人连带 |

## 一、数据源概述

本技能支持以下两个类案检索数据源，建议同时检索以获取更全面的类案：

### 1.1 中国裁判文书网

- **网址**：https://wenshu.court.gov.cn
- **性质**：最高人民法院设立的裁判文书公开平台
- **收录范围**：全国各级法院的生效裁判文书
- **访问要求**：需实名注册登录（手机号 + 验证码）方可查看全文
- **特点**：文书数量大、覆盖面广，包含各级法院各类案件的判决书、裁定书等

### 1.2 人民法院案例库

- **网址**：https://rmfyalk.court.gov.cn
- **性质**：最高人民法院建设的权威案例库
- **收录范围**：经最高人民法院审核入库的参考案例和指导性案例
- **访问要求**：需注册登录（手机号注册或统一身份认证）方可查看详情
- **特点**：
  - 案例经审核筛选，质量较高，参考价值大
  - 包含最高人民法院发布的指导性案例
  - 入库案例具有更强的说理规范性和示范性
  - 支持按案由、关键词、法院层级等多维度检索

### 1.3 双数据源检索策略

- **优先级**：人民法院案例库优先（指导案例 + 参考案例），裁判文书网补充（苏州案例 + 江苏案例）
- **互补关系**：
  - 人民法院案例库收录指导案例和参考案例，案例类型优先级最高，应首先检索
  - 裁判文书网覆盖面广，适合定向检索苏州及江苏地区案例，补充地域参考
- **建议检索顺序**：
  1. 先在人民法院案例库查找指导案例和参考案例
  2. 再在裁判文书网通过"法院地域"筛选苏州地区案例
  3. 不足时在裁判文书网筛选江苏省案例
  4. 仍不足时补充其他地区案例
- **若仅一个可用**：使用可用的数据源完成检索流程，向用户说明
- **若均不可用**：停止全部后续流程（见 SKILL.md 中的硬性停止条件）

## 二、检索关键词构建

### 2.1 关键词提取方法

从案情简介中按以下维度提取检索关键词：

| 维度 | 说明 | 示例 |
|------|------|------|
| 法律关系 | 当事人之间的法律关系性质 | 借贷、买卖、租赁、侵权 |
| 核心事实 | 纠纷的关键事实特征 | 转账未签合同、货物质量不合格 |
| 争议焦点 | 双方争议的核心问题 | 逾期利息计算、违约金过高 |
| 救济方式 | 原告寻求的救济 | 返还借款、赔偿损失、解除合同 |

### 2.2 关键词组合策略

**策略一：案由 + 核心事实**
```
示例："民间借贷纠纷" + "现金交付"
```

**策略二：法律关系 + 争议焦点**
```
示例："买卖合同" + "质量不合格" + "解除合同"
```

**策略三：法条关键词**
```
示例：从案情判断可能适用的法条，用法条中的关键词检索
如《民法典》第577条 → "违约责任" "继续履行" "赔偿损失"
```

### 2.3 检索技巧

- **同义词扩展**：同一法律概念可能有多种表述
  - "借款" = "借贷" = "欠款"
  - "违约金" = "滞纳金" = "罚息"
  - "赔偿" = "补偿" = "返还"

- **排除干扰词**：使用减号排除不相关结果
  - "租赁合同 -房屋 -商铺"（排除房屋租赁，聚焦其他租赁）

- **精确匹配**：使用引号进行精确短语匹配
  - "诉讼时效届满"

## 三、筛选条件优先级

检索后按以下优先级筛选类案：

### 3.1 案例类型优先级（最高优先级，从高到低）

1. **指导案例**：最高人民法院发布的指导性案例
   - 效力最高，各级法院审理类似案件时应当参照适用
   - 主要来源于人民法院案例库"指导性案例"栏目
   - 检索时优先查找，找到即优先收录

2. **参考案例**：人民法院案例库中经审核入库的参考案例
   - 经最高法院或高级法院审核，说理规范，示范性强
   - 主要来源于人民法院案例库"参考案例"栏目

3. **苏州案例**：苏州市辖区内法院审理的案件
   - 包括苏州市中级人民法院、苏州市各区/县基层法院
   - 与本地管辖法院裁判尺度一致，实务参考价值高
   - 在裁判文书网检索时，可通过"法院地域"筛选条件筛选苏州地区

4. **江苏案例**：江苏省辖区内法院审理的案件（不含苏州）
   - 包括江苏省高级人民法院、江苏省各中级法院及基层法院
   - 省内裁判尺度相对统一，参考价值较高
   - 在裁判文书网检索时，可通过"法院地域"筛选条件筛选江苏省

5. **其他地区案例**：以上均不足时，补充其他地区案例
   - 优先选择与案件性质匹配度高、说理充分的案例

### 3.2 辅助筛选条件（同级案例内部进一步排序）

1. **文书类型**：判决书（排除裁定书、调解书、决定书）
2. **审判程序**：二审 > 一审 > 再审
   - 二审判决说理更充分，参考价值更高
   - 再审判决涉及法律适用纠正，有特殊参考价值
3. **法院层级**：中级法院 > 高级法院 > 最高法院 > 基层法院
   - 中级法院案例数量多且说理质量较高
   - 高级/最高法院案例具有更强指导意义
4. **裁判日期**：近 3 年 > 近 5 年 > 5 年以上
   - 优先选择《民法典》施行后（2021年1月1日）的案例
   - 注意法律适用变化（如《民法典》替代原《合同法》《物权法》等）

### 3.3 检索执行建议

- **人民法院案例库**：优先检索，因其收录指导案例和参考案例，案例类型优先级最高
- **中国裁判文书网**：用于补充检索苏州案例和江苏案例，通过"法院地域"筛选条件定向筛选
- **检索顺序建议**：先在案例库查找指导案例和参考案例 → 再在裁判文书网筛选苏州案例 → 不足时补充江苏案例 → 仍不足时补充其他地区案例

## 四、信息提取要点

### 4.1 必须提取的信息

进入每份判决书全文后，按以下顺序提取：

**基本信息**：
- 案号：格式"(年份)法院代字民终/民初编号号"，如"(2023)京01民终123号"
- 审理法院：全称，如"北京市第一中级人民法院"
- 裁判日期：判决作出日期
- 案由：法院认定的案由（可能与原告主张不同）
- 数据来源：标注来自"中国裁判文书网"或"人民法院案例库"

**诉讼请求**：
- 原话摘录原告一审/上诉人诉讼请求原文，不得概括或改写
- 注意请求的表述方式和逻辑结构
- 标注哪些请求获支持、哪些被驳回

**争议焦点**：
- 法院归纳的争议焦点（通常在"本院认为"部分之前）
- 如法院未明确归纳，从判决说理中提炼
- **原文摘录，不得概括、缩写或改写，保持文字数据完整性**

**法院说理**：
- 法院对每个争议焦点的分析和认定
- 引用的法律条文
- 裁判逻辑和推理过程
- **原文摘录关键段落，不得概括、缩写或改写，保持文字数据完整性**

**判决结果**：
- 判决主文原文（"判决如下："之后的内容），原话摘录
- 标注每项判决的支持/驳回情况
- 注意诉讼费用的分担

### 4.2 重点关注内容

- **案由认定**：法院如何定性案件法律关系
  - 原告主张的案由与法院认定的案由是否一致
  - 如不一致，法院的理由是什么

- **诉讼请求表述**：获支持请求的规范表述
  - 措辞方式（如"支付" vs "返还" vs "赔偿"）
  - 金额计算方式
  - 时间起算点

- **举证责任分配**：
  - 法院如何分配举证责任
  - 哪些证据被采纳/不被采纳及理由
  - 举证不能的法律后果

- **法律适用**：
  - 法院引用的具体法条
  - 对法条的解释和适用
  - 是否参照指导性案例

## 五、检索注意事项

1. **数据源访问限制（硬性停止条件）**：本技能支持中国裁判文书网和人民法院案例库两个类案数据源。若两个网站均无法访问（网络超时、服务器错误、反爬拦截、页面空白等），**立即停止全部后续流程**，不得以网页搜索或其他数据源替代。若仅一个数据源不可用，使用另一个继续流程并说明。

2. **登录操作指南（用户手动登录，反爬约束）**：

   **关键约束**：中国裁判文书网和人民法院案例库均部署了反爬系统，浏览器**必须以有头模式（headed mode，可见窗口）运行**，不得使用无头模式（headless）。登录操作**必须由用户在可见浏览器窗口中手动完成**，AI 不得自动填充手机号、自动点击发送验证码、自动提交登录表单。

   - **agent-browser 有头模式**：`agent-browser` 默认是无头模式，必须显式添加 `--headed` 参数（`agent-browser open <url> --headed`）。若 daemon 已以无头模式运行，`--headed` 会被忽略，须先 `agent-browser close --all` 再重新 `open --headed`。
   - **登录状态检测**：使用 `agent-browser snapshot`（完整快照）检测，**不要用 `snapshot -i`**（仅交互元素），后者可能捕获 iframe 内的登录表单导致已登录被误判为未登录。已登录标志：页面显示"欢迎您""用户名""退出"等字样。

   **通用登录流程（两个网站相同）**：

   1. AI 通过浏览器工具（`qqbrowser-skill` 或 `agent-browser`）以有头模式打开目标网站
   2. AI 通过 `browser_snapshot`（qqbrowser-skill）或 `snapshot`（agent-browser，**完整快照不加 `-i`**）检测当前登录状态
   3. 若已登录 → 直接进入检索流程
   4. 若未登录 → AI 向用户发送明确提示：
      - "检测到您尚未登录[网站名称]。浏览器窗口已打开该网站，请在浏览器窗口中手动完成登录（输入手机号、获取并输入验证码、完成可能的滑块/图形验证）。登录完成后请告知我，我将继续检索。"
   5. AI **暂停流程，等待用户确认登录完成**，期间不执行任何浏览器操作
   6. 用户确认后，AI 再次通过 `browser_snapshot` / `snapshot` 验证登录状态
   7. 若仍检测到未登录，再次提示用户并等待

   **注意事项**：
   - 登录过程中可能触发图形验证码、滑块验证等反爬措施，这些只能由用户在浏览器窗口中手动完成
   - 首次使用人民法院案例库需注册账号，提示用户按网站引导完成注册
   - AI 不得自动获取、猜测或代填验证码
   - 不得以无头模式（headless）运行浏览器，否则反爬系统会拦截
   - 每次页面导航或 DOM 变动后须重新 `browser_snapshot` / `snapshot` 获取新索引

3. **文书脱敏**：部分文书中的当事人信息可能被脱敏处理（如"张某某"），这是正常现象。

4. **文书更新**：裁判文书网和人民法院案例库会持续更新，部分旧文书可能被撤下或替换。

5. **类案参照**：
   - 最高人民法院发布的指导性案例具有参照效力
   - 人民法院案例库中入库的参考案例经审核，具有较强的示范意义
   - 各地法院的类案裁判尺度可能存在差异
   - 注意区分指导性案例、参考案例和普通案例的效力层级

6. **法律适用变化**：
   - 2021年1月1日前适用《合同法》《物权法》《侵权责任法》等
   - 2021年1月1日后统一适用《民法典》
   - 检索旧案例时注意法条对应关系

7. **清空搜索条件（裁判文书网特有，重要）**：
   - 中国裁判文书网的搜索框输入会**累积为 AND 条件**：如果不清空之前的搜索词就输入新词，系统会将新旧关键词做 AND 叠加，导致搜索结果为 0。
   - **每次执行新搜索前，必须先清空已有搜索条件**：
     - 在页面快照中找到"清空搜索条件"链接（通常在搜索框下方或搜索结果区域）
     - qqbrowser-skill：`browser_snapshot` → 找到"清空搜索条件"索引 → `browser_click_element --index <N>`
     - agent-browser：`snapshot` → 找到"清空搜索条件"的 `@eN` → `click @eN`
   - 若是首次搜索（页面无累积条件），可跳过此步。

8. **零搜索结果处理（关键词降级策略）**：
   - 搜索返回 0 篇结果时（页面显示"共检索到 0 篇文书"），**不要直接放弃**，按以下顺序逐步简化关键词重新搜索：
     1. **第一轮**：使用完整关键词短语（如"离婚纠纷经济补偿规则"）
     2. **第二轮**：拆分为核心词组合（如"离婚 经济补偿"）— 先清空条件再搜索
     3. **第三轮**：仅使用案由关键词（如"离婚纠纷"）— 先清空条件再搜索
     4. **第四轮**：使用案由 + 事实关键词（如"离婚 补偿 家务"）— 先清空条件再搜索
   - 每轮重新搜索前**必须先清空已有搜索条件**（见第 7 点）。
   - 若四轮均返回 0 结果，标记该数据源无相关类案，转用另一数据源。
   - 若两个数据源均无结果，向用户说明情况并停止检索流程。

9. **agent-browser 命令速查（实测验证）**：
   - 打开网页：`agent-browser open <url> --headed`（**不是** `navigate`）
   - 完整快照：`agent-browser snapshot`（获取元素引用 `@eN`）
   - 交互元素快照：`agent-browser snapshot -i`（仅交互元素，**不用于登录检测**）
   - 输入文本：`agent-browser fill @eN "text"`（**不是** `type`）
   - 点击元素：`agent-browser click @eN`
   - 等待加载：`agent-browser wait --load networkidle`（**不是** `wait --seconds`）
   - 截图：`agent-browser screenshot <path>`
   - 关闭所有会话：`agent-browser close --all`
   - **提取案件链接（推荐）**：`agent-browser eval "Array.from(document.querySelectorAll('a')).filter(a => a.href && a.href.includes('docId')).map(a => ({text: a.innerText.trim(), href: a.href}))"`
   - **提取文书正文（推荐）**：`agent-browser eval "document.body.innerText"`
