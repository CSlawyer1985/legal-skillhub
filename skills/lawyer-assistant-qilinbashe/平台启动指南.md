2. 首次对话即触发：总控路由输出固定开场白，并自动在右侧常驻交互式全景图（一键发布，用户零手动）。

## 首次使用三步（开箱即用体检）
1. **体检**：运行 ，查看就绪 / 降级 / 阻断状态（退出码 0 / 2 / 1）。
2. **按需装依赖**：只安装与您当前材料类型相关的可选依赖（如传图片装 easyocr、传 PDF 装 PyMuPDF、传录音装 openai-whisper），不强制一次安装全部重型依赖。
3. **直接用**：说您的情况即可，首轮自动出图并开始分析；上传特殊格式材料走 107 多模态解析（12 类格式，缺依赖自动降级提示）。
