# 案例引用规范

> 所有 agent 在引用司法案例时，必须使用本标准格式。
> 最后更新: 2026-07-18

---

## 一、完整引用格式（分析报告中使用）

| 字段 | 格式 | 示例 |
|------|------|------|
| 案号 | (XXXX)X法XX字第XXX号 | (2023)京0105民初12345号 |
| 审理法院 | XX省/市/区人民法院 | 北京市朝阳区人民法院 |
| 裁判日期 | YYYY-MM-DD | 2023-06-15 |
| 案由 | 标准案由名称 | 民间借贷纠纷 |
| 裁判要点 | 1-2句话概括核心裁判规则 | 借条未约定利息的，视为无息借款 |
| 与本案关系 | 1句话说明可参考性 | 本案借条同样未约定利息，可参照适用 |

---

## 二、精简引用格式（正文内引用）

```
「参考 (案号)（法院，日期）：裁判要点」
```

示例：
```
「参考 (2023)京0105民初12345号（北京朝阳法院，2023.06.15）：借条未约定利息的，视为无息借款」
```

---

## 三、权威性标注

| 等级 | 标识 | 范围 | 参考效力 |
|:----:|:----:|------|:--------:|
| ⭐⭐⭐ | 指导性 | 最高人民法院指导案例、公报案例 | 应当参照 |
| ⭐⭐ | 区域性 | 本省/直辖市高院案例 | 可以参考 |
| ⭐ | 参考性 | 其他法院案例 | 仅作参考 |

权威性标注紧跟案号：
```
「参考 ⭐⭐⭐ (2020)最高法民再xxx号」
```

---

## 四、引用规范检查清单

输出前自检：
- [ ] 案号格式是否正确（含年份+法院简称+字号+编号）
- [ ] 审理法院是否完整
- [ ] 裁判日期是否标注
- [ ] 裁判要点是否精炼（1-2句）
- [ ] 权威性是否标注⭐等级
- [ ] 与本案的关系是否说明
- [ ] MCP检索来源是否在末尾标注

---

## 五、禁止事项

- ❌ 不得引用未通过MCP核验的案例
- ❌ 不得引用已失效/被推翻的案例
- ❌ 不得虚构案号或裁判要点
- ❌ 不得将⭐级案例表述为“必须遵循”
