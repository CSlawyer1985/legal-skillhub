# 模糊输入分级引导模板



> 本模板用于统一31号总控路由和各agent的反问话术，确保模糊输入时用户获得一致、精准的引导体验。



---



## 三级递进引导



### Lv1 — 选项引导（首选）



当用户描述模糊但可以推断出大致方向时，直接给出选项：



```

您说的是不是以下几种情况之一？



1. [选项A]——例如「典型场景描述」

2. [选项B]——例如「典型场景描述」

3. [选项C]——例如「典型场景描述」

4. 都不是，我重新描述

```



**高频场景预设选项：**



| 用户关键词 | 选项A | 选项B | 选项C |

|:----------|:------|:------|:------|

| 钱/欠/借 | 民间借贷——借钱不还 | 买卖合同——货款拖欠 | 劳动争议——欠薪 |

| 合同/违约 | 买卖合同纠纷——不发货/不付款 | 房屋租赁纠纷——房东/租客违约 | 服务合同纠纷——服务不达标 |

| 被撞/受伤 | 交通事故——被车撞了 | 人身损害——被他人打伤 | 医疗纠纷——医疗事故 |

| 公司/单位 | 劳动争议——被辞退/欠薪 | 合同纠纷——公司与个人 | 工伤——工作中受伤 |

| 离婚/家庭 | 离婚纠纷——感情破裂 | 继承纠纷——遗产分配 | 抚养权——孩子归谁 |

| 被抓/拘留 | 刑事案件——家人被拘留 | 行政拘留——治安处罚 | 取保候审——能否保释 |



### Lv2 — 要素追问（Lv1无效）



当用户仍无法选择时，转为要素追问：



```

没关系，我们换个方式。请简单告诉我：



🏷️ 您遇到了什么问题？______

（例如：借钱不给/被车撞了/被辞退/合同纠纷/离婚…）



👤 对方是谁？

□ 个人  □ 公司/单位  □ 行政机关  □ 不清楚



🎯 您希望达到什么目的？

□ 拿回钱/获得赔偿  □ 解除合同/终止关系

□ 了解法律风险  □ 准备起诉/仲裁  □ 只是想咨询一下

```



### Lv3 — 最终兜底（Lv1+Lv2均无效）



当以上两级都无法获得有效信息时：



```

我暂时没能准确理解您的情况。建议您可以试试：



1️⃣ 直接用关键词说话，比如：

   「借钱不还」「交通事故」「被辞退」「离婚」「合同纠纷」

   我就能直接帮您匹配对应的法律专家



2️⃣ 拨打 **12348** 法律服务热线

   这是国家统一的法律服务热线，有专业律师在线解答



3️⃣ 去社区法律援助中心现场咨询

   带上相关材料，工作人员会指导您如何依法主张权利

```



### Lv4 — 多次失败后最终的兜底



如果经过多轮引导（Lv1→Lv2→Lv3）后用户仍无法提供有效信息：



```

我没能理解您的情况。建议直接拨打12348法律服务热线，

或到社区法律援助中心现场咨询。您也可以准备好以下信息后重新提问：

- 事情经过（时间、地点、涉及的人）

- 涉及金额（如有）

- 您希望达到什么目的

```

## 跨领域模糊识别



当用户描述可能涉及多个法律领域时：



```

您提到的情况可能涉及以下几个方向，请问更接近哪个？



A. 🏛️ **民事纠纷**——借钱不还、合同违约、侵权赔偿、物业纠纷

B. 💼 **劳动争议**——被辞退、欠薪、工伤、不签合同

C. 🚔 **刑事咨询**——被拘留/逮捕、报案依法主张权利、取保候审

D. 🏢 **行政纠纷**——被罚款、征收补偿补偿、行政复议

E. 📄 **婚姻家事**——离婚、继承、抚养权、财产分割

F. 💸 **破产**——欠债还不上、公司倒闭、个人破产

```

## 情绪化输入处理



当用户输入带有强烈情绪时，先共情再引导：



```

我理解您的心情，遇到这种事确实让人着急。

请放心，我会尽我所能帮您分析。我们先从基本情况开始：



1. 事情大概是什么时候发生的？

2. 涉及的大致金额是多少？

3. 您手头有什么材料吗？

```



---



## 前后矛盾输入处理



当用户输入存在矛盾时：



```

我注意到您说的这两点好像有些出入：

- 您说「借了他钱」

- 又提到「他没借」

	

我们重新确认一下：

🔹 是您借钱给别人，还是别人借钱给您？

🔹 对方有没有出具借条或转账记录？

```



> ⚠️ 以上引导话术由AI自动选择，不要求用户事先了解法律分类。
