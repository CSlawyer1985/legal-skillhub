# 实证样例 · 恒锦石材 vs 新德建设仲裁案攻防推演

> 用途：以真实办案骨架演示「律师助手」技能包如何参与一起商事仲裁案的处置全过程，检验“参与案件处置”实效，并反向发现包内能力缺口。
> 案情已脱敏：当事人以「恒锦石材（申请人）」「新德建设（被申请人）」代称。
> 适用节点：22-商事仲裁申请与程序 / 22A-仲裁保全指引 / 22B-仲裁员选定与组庭策略 / 08-仲裁裁决执行与撤销 / 70-案件深度分析系统 / 75-通用证据体系引擎 / 86-案件风险评估报告 / 76-期限与时效计算器。

---

## 一、案情骨架（脱敏）

| 要素 | 内容 |
|------|------|
| 申请人 | 恒锦石材（石材供货 / 工程分包实际提供方） |
| 被申请人 | 新德建设（工程总包 / 发包方） |
| 争议标的 | 119.96 万元 |
| 基础关系 | 新德建设承接工程后，将石材供应及配套施工交恒锦石材完成；双方签有书面协议并有阶段性结算 |
| 关键事实 | 恒锦已按约供货 / 施工完毕，双方签署结算确认文件，确认应付 119.96 万元 |
| 突变事件 | 新德建设进入破产程序；恒锦向管理人申报债权，但优先受偿权与债权性质存争议 |
| 协议条款 | 双方合同中含仲裁条款，约定某仲裁委员会 |

---

## 二、核心争议焦点

1. **关系定性**：双方是**买卖合同关系**还是**建设工程分包合同关系**？
   - 定性为建工分包 → 可能适用建设工程价款优先受偿权（民法典第 807 条）；
   - 定性为买卖 → 仅普通金钱债权，无优先受偿，破产中清偿顺位靠后。
2. **结算金额确认**：119.96 万元是否有充分书面依据（合同 + 送货 / 验收 + 结算协议）？
3. **破产债权确认**：新德破产后，恒锦如何确认债权性质与金额（破产法第 44、48、58 条），以及与仲裁确认的关系。

---

## 三、要件九步法推演（调用 70-案件深度分析系统）

**① 找法（请求权基础）**
- 若定性建工分包：民法典第 791、795 条（建设工程合同）、第 807 条（优先受偿权）；
- 若定性买卖：民法典第 595、626 条（买卖合同）；
- 破产维度：企业破产法第 44 条（债权申报）、第 48 条（申报期限与权利）、第 58 条（债权表核查与异议诉讼）。

**② 定性**
优先争取「建设工程分包合同关系」，以锚定优先受偿权；退而求其次为买卖关系下的普通债权。

**③ 要件拆解（以建工分包为例）**
- 合同有效成立 ✓（书面协议）
- 已履行完毕 ✓（供货 / 施工 + 验收）
- 结算金额确定 ✓（119.96 万结算确认文件）
- 债务人破产 ○（新德进入破产，影响清偿而非请求权本身）

**④ 举证责任**
- 我方：合同、送货单 / 验收单、结算协议、催款记录、破产债权申报回执；
- 对方可能抗辩：质量异议、工程量不符、超过优先受偿权行使期限（已知 18 个月，司法解释规定）。

**⑤ 攻防预判**
- 有利：书面结算确认 119.96 万，请求权基础清晰；
- 不利：①新德破产资产可能不足，即便胜裁也执行困难（衔接 08）；②若被定性为买卖，丧失优先受偿；③优先受偿权行使期限（自应付之日起算）需核实未超期。

**⑥ 程序路径**
- 有仲裁协议 → 提起商事仲裁（22）确认债权金额与性质；
- 同步向破产管理人申报债权；对债权表记载有异议 → 提起破产债权确认诉讼（破产法第 58 条第 3 款）；
- 注意一裁终局（仲裁法第 9 条），裁决后仅限撤裁 / 不予执行（08）。

**⑦ 反向修包启示**
- 包内「商事仲裁 + 破产债权」交叉场景**缺少专门衔接节点**：现有破产条线（53/51/13）与仲裁条线（22/08）各自独立，未见“仲裁确认与破产债权确认如何并行 / 先后”的专项指引。建议未来补「破产债权确认与仲裁衔接」节点。
- 22A 仲裁保全在对方已破产时意义有限（破产冻结），应提示“破产情形下保全的替代方案（债权申报 + 异议）”。

## 四、仲裁申请框架（调用 22 / 22B）

**仲裁请求示例：**
1. 确认申请人与被申请人之间就案涉工程形成的债权债务关系，确认被申请人应付申请人 119.96 万元；
2. 确认上述债权中 XX 万元就案涉工程折价 / 拍卖款享有优先受偿权（若定性建工分包）；
3. 仲裁费用由被申请人承担。

**证据清单雏形（调用 75-通用证据体系引擎）：**
| 证据 | 证明目的 | 持有方 | 状态 |
|------|---------|-------|------|
| 书面协议 | 合同关系成立 | 申请人 | 已有 |
| 送货 / 验收单 | 已履行 | 申请人 | 已有 |
| 结算确认文件 | 金额 119.96 万 | 申请人 | 已有 |
| 催款记录 | 主张权利、中断时效 | 申请人 | 已有 |
| 破产债权申报回执 | 已进入破产程序 | 申请人 | 已有 |
| 优先受偿权期限证据 | 未超 18 个月行使期 | 申请人 | 需补强 |

**组庭策略（调用 22B）：** 争取具建工背景的首席仲裁员，强化“建工分包”定性倾向；审查对方仲裁员回避情形。

## 五、风险评估（调用 86-案件风险评估报告）

| 风险 | 等级 | 应对 |
|------|------|------|
| 定性为买卖、丧失优先受偿 | 🔴 高 | 强化建工分包证据（施工内容、验收标准、合称“工程”） |
| 优先受偿权超期 | 🟡 中 | 核实应付之日，固定催款中断证据 |
| 新德破产资产不足、执行困难 | 🔴 高 | 仲裁确认后衔接 08 执行；关注破产清偿分配 |
| 仲裁协议效力瑕疵 | 🟢 低 | 仲裁前先做协议效力审查（22 第一步） |

## 六、本样例验证了什么

- ✅ 包内节点可串联参与真实仲裁案：22（申请）→ 22B（组庭）→ 70（九步法）→ 75（证据）→ 86（风险）→ 08（执行 / 撤裁）。
- ✅ 职业克制到位：各环节均提示“初稿需律师审核”“不预测胜率”“破产执行风险”。
- ⚠️ 发现缺口：仲裁与破产债权确认的交叉衔接无专项节点，是后续补强方向（已记入待办）。

> 本样例仅作方法演示，具体办案请以完整案卷与律师实质判断为准。
