# 场景速查卡

> 📌 以「我想……」为入口，快速定位操作路径。按需求查对应行即可。

---

## 常用场景（快速上手）

| 我想…… | 操作路径 | 预计耗时 | 涉及技能 |
|:--------|:---------|:--------:|:---------|
| 写一份起诉状 | 说情况→AI采集→生成初稿→说「导出Word文档」 | 5-10min | 31→41/03→72 |
| 算一下能赔多少钱 | 说「帮我算赔偿」→提供收入/医疗费等数据 | 3-5min | 05/15 |
| 被公司辞退要补偿 | 说「公司辞退不给补偿」→AI算补偿金→生成仲裁申请 | 10-15min | 31→15 |
| 离婚分财产和孩子 | 说「我要离婚，孩子X岁」→AI分析抚养权+财产分割 | ~15min | 31→54 |
| 写律师函催对方 | 说「帮我写律师函」→填对方信息→生成初稿 | 5-10min | 31→模板 |
| 审合同有没有坑 | 上传合同→说「帮我审查合同」→AI逐条分析 | 20-30min | 20 |
| 查最新法条 | 说「查一下XX法的第X条」→MCP实时查询（需联网） | 1-2min | MCP→31 |
| 我要报案（刑事） | 说「我被骗了/被打了」→AI分析是否构成犯罪→整理报案材料 | 10-15min | 31→09 |
| 物业不管事拒交费 | 说「物业不干活还要收钱」→AI分析减免依据 | 5-10min | 43 |
| 合同对方违约了 | 说「签了合同对方不履行」→AI分析违约责任→生成文书 | 10-15min | 03 |
