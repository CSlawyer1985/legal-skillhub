| 能力 | 状态 |
|:-----|:----:|
| ✅ 生成起诉状、答辩状、律师函等文书初稿 | ✅ |
| ✅ 分析案件有利因素与不利因素 | ✅ |
| ✅ 计算诉讼费、赔偿金额 | ✅ |
| ✅ 提供依法主张权利路径对比（调解/诉讼/仲裁） | ✅ |

## ⚠️ 反模式速查（AI不能做什么·集中入口）

| # | ❌ 反模式 | ✅ 正确做法 |
|:-:|:---------|:-----------|
| 1 | 问「能不能赢」「胜率多少」 | AI无法预测结果，但可分析有利/不利因素 |
| 2 | 拿AI文书直接立案 | 文书均为初稿，须执业律师实质审查后提交 |
| 3 | 跳过证据整理要起诉状 | 没有证据支撑的起诉状无法立案 |
| 4 | 把AI当法官 | AI只做分析，最终以法院认定为准 |
| 5 | 一次对话解决所有复杂问题 | 复杂案件分阶段推进 |
| 6 | 把法律咨询当心理疏导 | 情绪问题寻求专业心理帮助 |
| 7 | 对话输入真实身份信息 | 用化名，身份证号只说后4位 |
| 8 | 以为AI万能 | AI不出庭、不保证结果、不替代律师面谈 |

## 📎 文件上传能力边界（我能处理哪些文件）

| 材料类型 | 支持情况 |
|:---------|:---------|
| PDF、图片（jpg/png/bmp/tiff/webp/HEIC） | ✅ 直接解析（扫描件自动 OCR） |
| 文本（txt/md/csv）、邮件（eml） | ✅ 直接解析（零依赖） |
| Word（docx）、Excel（xlsx/xls）、PPT（pptx） | ✅ 直接解析（含表格） |
| 音频（mp3/wav/m4a/ogg/flac）、视频（mp4/mov/avi/mkv） | ✅ 转写为文字稿 |
| zip 压缩包 | ✅ 安全解包后递归解析内部文件 |
| 旧版 .doc / .ppt | ⚠️ 需先另存为 .docx / .pptx 后上传 |
| 未知 / 特殊格式 | ⚠️ 返回支持清单 + 转换建议（转 PDF / 截图 / 粘贴文字） |

**缺依赖会发生什么：** 对应格式会明确提示「缺 XX 依赖 + 安装命令或替代上传方式」，**不假装成功、不影响其他格式**；可用 `python scripts/doctor.py` 一键体检依赖状态，`python scripts/multimodal_ingest.py --supported` 查看完整格式矩阵。
