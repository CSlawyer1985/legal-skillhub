## 一、婚姻家事诉讼完整流程

### 1. 感情破裂认定
- 民法典第1079条认定标准：重婚/同居/家暴/遗弃/恶习/分居满2年/其他
- 一次性判离 vs 判不离后6个月再诉
- 军婚特殊保护（民法典第1081条）

### 2. 财产分割
- 夫妻共同财产范围（民法典第1062条）
- 个人财产范围（民法典第1063条）
- 分割原则：协议优先→均分为原则→照顾子女/女方/无过错方
- 隐匿/转移/挥霍财产的少分或不分（民法典第1092条）

### 3. 子女抚养权
- 2周岁以下随母（原则）
- 8周岁以上尊重子女意愿
- 2-8周岁综合考量：抚养能力/抚养条件/教育环境/与子女感情
- 抚养费：月收入的20%-30%，多个子女不超过50%

### 4. 损害赔偿
- 法定情形：重婚/同居/家暴/遗弃/恶习
- 精神损害赔偿参考：当地经济水平+过错程度+后果严重性

## 二、家事非诉与协议完整流程

### 1. 婚前财产协议
- 可约定内容：婚前财产归属、婚后所得归属、债务承担
- 形式要件：书面形式+双方签字
- 不得约定：限制人身自由、限制离婚自由、免除抚养义务

### 2. 婚内财产协议
- 民法典第1065条：夫妻可以约定婚姻关系存续期间所得财产归各自所有/共同所有/部分各自所有
- 协议效力：对内有效，对外不得对抗善意第三人

### 3. 离婚协议
- 必备内容：自愿离婚+子女抚养+财产分割+债务处理
- 民政局协议离婚：30天冷静期
- 法院调解离婚：出具调解书，具有强制执行力

### 4. 赡养/抚养协议
- 赡养义务人：子女对父母、孙子女对祖父母（有条件）
- 抚养义务人：父母对子女、祖父母对孙子女（有条件）
- 协议可约定方式：金钱给付+实物供给+劳务照料

## 三、知识产权诉讼完整流程

### 1. 专利侵权诉讼

#### 1.1 权利基础审查
- 专利类型：发明（20年）/实用新型（10年）/外观设计（15年），自申请日起算
- 权利有效性：年费缴纳状态、无效宣告程序进展、权利稳定性评估
- 保护范围：以权利要求书为准，说明书及附图可以解释权利要求（专利法第64条）
- 外观设计：以图片或照片中的产品外观为准，简要说明可以解释

#### 1.2 侵权比对（全面覆盖原则+等同原则）
```
判定方法：将被诉侵权技术方案与权利要求记载的全部技术特征逐一比对
- 全面覆盖原则：被诉方案包含权利要求全部技术特征（相同或等同）→ 落入保护范围
- 等同原则（专利侵权解释二第8条）：以基本相同的手段、实现基本相同的功能、
  达到基本相同的效果，且本领域普通技术人员无需创造性劳动即可联想到 → 等同侵权
- 禁止反悔原则：申请过程中放弃的技术方案不得再主张等同
- 捐献原则：说明书公开但权利要求未记载的技术方案视为捐献，不得主张

比对表输出：
| 权利要求技术特征 | 被诉方案对应特征 | 相同/等同/不同 | 结论 |
|:----------------|:----------------|:--------------|:-----|
```

#### 1.3 常见抗辩
- 现有技术抗辩：被诉侵权技术属于申请日前已公开的现有技术（专利法第67条）
- 先用权抗辩：申请日前已制造相同产品/使用相同方法，仅在原有范围内继续
- 合法来源抗辩：销售者不知道侵权且能证明合法来源 → 不承担赔偿责任（仍须停止销售）
- 科研实验例外：专为科学研究和实验目的使用
- 药品专利链接/Bolar例外：为行政审批目的制造使用

#### 1.4 赔偿计算（专利法第71条）
```
赔偿顺序（逐级适用）：
1. 权利人实际损失（侵权产品销量×利润）
2. 侵权人获利（侵权产品销量×利润率）
3. 专利许可使用费的合理倍数
4. 法定赔偿：3万-500万元（酌定：专利类型/侵权性质/情节/许可费）
惩罚性赔偿：故意侵权+情节严重 → 实际损失/侵权获利的1-5倍
举证妨碍：侵权人无正当理由拒不提供账簿 → 参考权利人主张与证据
```

### 2. 商标侵权诉讼

#### 2.1 权利基础
- 注册商标专用权（商标法第56条）
- 驰名商标：跨类保护（第13条），个案认定
- 未注册驰名商标：同类保护

#### 2.2 侵权判断（混淆可能性）
```
判断要素：
- 商标相同/近似：音/形/义/整体外观/显著部分比对
- 商品相同/类似：功能/用途/生产部门/销售渠道/消费对象关联度
- 相关公众的一般注意力（隔离观察+整体比对+要部比对）
- 驰名程度：跨类保护时考虑知名度覆盖范围

侵权行为类型（商标法第57条）：
① 未经许可在同一种商品上使用相同商标
② 在同一种商品上使用近似商标+易混淆
③ 在类似商品上使用相同/近似商标+易混淆
④ 销售侵权商品
⑤ 伪造/擅自制造注册商标标识
⑥ 反向假冒（更换商标再销售）
⑦ 帮助侵权（提供仓储/运输/邮寄/印制/隐匿等便利）
```

#### 2.3 抗辩
- 正当使用：描述性使用（叙述商品特点/产地）、指示性使用（说明商品来源）
- 商标先用权：他人在注册商标申请日前已使用+有一定影响，在原范围内继续使用
- 三年不使用撤销：连续三年未使用可申请撤销
- 合法来源抗辩（销售者）

#### 2.4 赔偿计算（商标法第63条）
- 实际损失 → 侵权获利 → 许可费倍数 → 法定赔偿（500万元以下）
- 惩罚性赔偿：恶意+情节严重 → 1-5倍
- 假冒注册商标商品销毁

### 3. 著作权侵权诉讼

#### 3.1 权利基础
- 作品类型：文字/口述/音乐/戏剧/曲艺/舞蹈/美术/摄影/视听/工程设计/地图/计算机软件（著作权法第3条）
- 权利内容（第10条）：人身权（发表/署名/修改/保护作品完整）+ 财产权（复制/发行/出租/展览/表演/放映/广播/信息网络传播/改编/翻译/汇编）
- 权利归属：作者（创作完成）+ 特殊作品规则（职务/委托/合作/视听作品）

#### 3.2 侵权判断（实质性相似+接触）
```
判定方法：
- 接触：被告有机会接触原告作品（发表时间在先+公开渠道/特定关系）
- 实质性相似：思想表达二分法（只保护表达不保护思想）
  对比方法：整体观感法/抽象过滤法/逐段对比法
- 独创性：独立完成+一定创作高度（最低限度独创性）

常见场景：
- 文字作品：逐句/段落比对，情节结构相似
- 软件：代码比对（相同率/相似函数）
- 美术/摄影：整体视觉实质相似
- 视听：实质性段落相同
```

#### 3.3 合理使用（第24条）
- 个人学习研究欣赏/适当引用/新闻报道/课堂教学/执行公务/图书馆存档/免费表演/公共场所陈列/汉语言文字作品译成少数民族文字/盲文/其他
- 三步检验：特殊情形+不损害正常使用+未不合理损害合法利益

#### 3.4 赔偿计算（第54条）
- 实际损失 → 违法所得 → 权利使用费 → 法定赔偿（500-500万元）
- 惩罚性赔偿：故意+情节严重 → 1-5倍
- 软件：可按正版价格×复制数量

### 4. 不正当竞争诉讼

#### 4.1 混淆行为（反不正当竞争法第6条）
- 擅自使用他人有一定影响的商品名称/包装/装潢/企业名称/域名/姓名
- 有一定影响=一定市场知名度（举证：销售/宣传/获奖/时间持续）

#### 4.2 虚假宣传（第8条）
- 对商品性能/功能/质量/销售状况/用户评价等作虚假或引人误解的商业宣传
- 组织虚假交易（刷单/刷评）构成虚假宣传

#### 4.3 商业秘密（第9条+反法解释）
```
构成要件：秘密性（不为公众所知悉）+价值性（商业价值）+保密措施（合理保密）
侵权行为：
① 以盗窃/贿赂/欺诈/胁迫/电子侵入等不正当手段获取
② 披露/使用/允许他人使用以不正当手段获取的商业秘密
③ 违反保密义务披露/使用
④ 教唆/引诱/帮助他人侵犯
⑤ 第三人明知非法仍获取/使用

举证：初步证据（秘密载体+保密措施+对方接触可能+信息相同/实质相同）
→ 举证责任转移（对方证明合法来源）
赔偿：实际损失→侵权获利→法定赔偿（500万元以下）；恶意侵权惩罚性赔偿1-5倍
```

#### 4.4 商业诋毁（第11条）
- 编造/传播虚假信息或误导性信息，损害竞争对手商誉
- 需证明：编造传播行为+虚伪事实+损害后果（或可能）

#### 4.5 网络不正当竞争（第12条）
- 流量劫持/恶意不兼容/误导欺骗强制跳转/妨碍破坏其他经营者合法网络产品或服务

### 5. 知识产权诉讼程序要点

#### 5.1 管辖
- 侵权行为地（实施地/结果地）或被告住所地
- 专利一审：最高法知产法庭+各地知产法庭/中院集中管辖（法释〔2022〕13号）
- 商标/著作权：中院或指定基层法院
- 互联网侵权：被侵权人住所地法院

#### 5.2 诉前/诉中禁令（行为保全）
- 条件：有权利基础+侵权行为存在+难以弥补的损害（紧急情况）
- 担保：法院可要求提供担保
- 期限：48小时内裁定（紧急）/及时审查

#### 5.3 证据保全+调查令
- 证据保全：法院查封/扣押/拍照/录像/复制（侵权产品/账册/源代码）
- 律师调查令：调取电商平台销售数据/海关扣押信息/行政机关查处材料
- 公证保全：网页/购买过程/侵权实物的公证固定（诉讼前务必固定）

#### 5.4 技术事实查明
- 技术调查官/专家辅助人（技术专家出庭辅助）
- 司法鉴定（软件代码比对/技术特征比对/商业秘密同一性鉴定）
- 专家证人意见

#### 5.5 诉讼时效
- 3年（知道或应当知道权利被侵害及义务人）
- 持续侵权：自终了之日起算
- 超过起诉的注意：专利法第74条特别规则
