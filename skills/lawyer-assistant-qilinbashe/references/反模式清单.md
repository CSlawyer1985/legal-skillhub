# 反模式与避坑指南（Anti-Patterns）

> ⚠️ 以下是最常见的10种错误用法。每条含「错误做法 → 正确做法 → 不避后果」，请在使用前阅读。

| AP编号 | ❌ 错误操作 | ✅ 正确做法 | ⚠️ 不避后果 |
|:------:|:-----------|:------------|:------------|
| AP-001 | 让AI代替出庭 | 委托执业律师代理。AI只能做庭前准备辅助（文书、策略、证据梳理） | 误以为AI可代理出庭，延误应诉/取证，错过开庭期限 |
| AP-002 | 要求AI预测胜率 | AI只做有利/不利因素分析，不做胜率预测。说「帮我分析有利和不利因素」 | 产生误导性预期，影响当事人决策，部分平台违规 |
| AP-003 | AI生成文书直接提交法院 | 所有文书均为初稿，**必须经执业律师实质审查**后提交 | 文书含事实认定错误/数字计算偏差/格式不规范，被法院打回或败诉 |
| AP-004 | 输入真实姓名/身份证号/住址 | 使用「张三」「李四」等化名，身份证号只说后4位，住址写“XX市”即可 | 网络传输/屏幕截图泄露当事人隐私，违反脱敏规范 |
| AP-005 | 一次性丢大量文件不说明案情 | 先简要描述案情（什么人+什么事+什么时候+什么证据），再附证据材料 | AI无法理解上下文，分析偏差或遗漏关键事实 |
| AP-006 | 同时问多个不相关的法律问题 | 一次只说一个法律问题。多个问题逐一咨询 | AI混淆案由，匹配错误专家，给出似是而非的分析 |
| AP-007 | 不提供任何事实只问「我能不能赢」 | 按「人物-事件-时间-证据」四要素描述案情，越详细越好 | AI缺乏关键事实，只能给出原则性法律知识，无法针对性分析 |
| AP-008 | 用AI写完后不核对引用法条 | 在「案由+地域+时效」三维度核验法条有效性。可联网MCP查询最新版本 | AI可能引用已废止或不适用的法规，影响文书合法性 |
| AP-009 | 误以为99个技能全部常驻可用 | 了解三层激活体系：🟢常驻5个优先匹配 → 🟡按需10个确认激活 → ⚪库存60个需手动调取 | 期望过高，冷门案由不能即时匹配，以为功能缺失 |
| AP-010 | 离线时依赖外置案例库和最新判例 | 离线模式仅支持包内32部法规摘要，案例检索需联网。离线输出会标注「未经实时核验」 | 离线时引用的判例可能已失效，恢复联网后须重新核实 |

## 快速自查清单

> 说任何一句话前，先看这三条：

- [ ] **我已经用化名代替了真实姓名？**（张三/李四 ✅ 真名 ❌）
- [ ] **我是一次只说一个法律问题？**（一个一个来 ✅ 一次说三个 ❌）
- [ ] **我知道这只是初稿，提交法院前要找人审核？**（知道 ✅ 直接用的想法 ❌）
