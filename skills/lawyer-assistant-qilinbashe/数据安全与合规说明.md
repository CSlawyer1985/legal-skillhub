# 律师助手技能包 · 数据安全与合规说明

> 版本：v4.1 ｜ 更新日期：2026-07-31
> 适用对象：律师、法务、律所管理者，以及评估本技能包的采购方

---

## 1. 适用范围

本说明覆盖「律师助手」技能包（含 12 大阶段 · 104 个关键节点的 Agent 集群、脚本工具与参考库）在数据安全、隐私保护与合规边界方面的设计原则与责任划分，供执业机构在采购、部署与使用前应知尽知。

---

## 2. 数据驻留与隐私保护

| 设计原则 | 具体实现 |
|---------|---------|
| **数据默认不出本机** | 技能包可完全本地运行，不强制绑定任何大厂云；对话与案情数据默认留在用户本地环境 |
| **PII 强制脱敏** | 输出交付物前执行 PII 脱敏规则（身份证保留前6后4、手机号保留前3后4、银行卡仅显末4、姓名默认代称「张三/李四」） |
| **敏感信息提示** | 各节点明示「请勿将当事人身份信息、案件细节、商业秘密直接输入非授权环境」 |
| **会话记忆本地化** | 案件状态卡以本地 Markdown 文本形式保存，不依赖中心化数据库 |

> ⚠️ 注意：若用户主动配置 MCP 双源（北大法宝 / 华宇元典）或法律法规知识库连接器，检索请求将按对应服务条款发往该服务；是否启用由用户自主决定，且离线降级时数据仍不出本机。

---

## 3. 离线降级与溯源透明性

- 本包法律结论的**权威溯源**依赖可选 MCP 双源 + 法律法规知识库。
- **未配置上述任何数据源时**，输出统一标注「未经实时核验」，仅代表基于模型知识的初步分析，**不构成已核验的权威出处**。
- 降级链：华宇元典 MCP → 北大法宝 MCP → 法律法规知识库 → 本地离线法条精华 → 法律原则回复，逐级透明降级，**严禁静默降级（假装已核验）**。
- 离线降级输出带「⚠️ 离线模式 / 未经实时核验」水印，提示律师自行核对法条原文与真实案例。

---

## 4. AI 生成内容的定位与边界

- 所有文书、分析、意见均为 **AI 初稿**，**须经主办律师实质审查**后方可作为正式法律文书使用或对外提交。
- 本包**不预测胜率、不替代律师出庭、不代理案件、不出具可直接提交法院的正式文书**。
- 越界请求（伪造证据、转移财产逃债、替代出庭等）会被主动拦截并给出合法替代方案。
- 用户应对最终用于办案的内容独立承担专业判断责任。

## 5. 备案与合规状态（如实披露）

- 本技能包当前为**技能包 / 开源形态**，尚未依《生成式人工智能服务管理暂行办法》办理生成式 AI 服务备案。
- 未备案不影响个人 / 律所内部作为辅助工具使用；但若作为**面向公众的商用服务**对外提供，须另行完成算法备案与安全评估。
- 包内法律推理依据现行有效法律（截至 2026-07），不保证覆盖最新修订，以权威数据库复核为准。

## 6. ToB 采购前建议

如拟将本包集成至律所工作流或对外商用，建议补充：

1. 完成生成式 AI 服务备案与算法安全评估；
2. 与当事人签署 AI 辅助使用告知书，明确初稿性质与责任边界；
3. 启用 MCP 双源，确保法条与案例可溯源；
4. 建立内部复核台账，留存 AI 初稿与律师终审版本；
5. 对含个人信息的训练 / 检索数据，按《个人信息保护法》做最小化处理。
