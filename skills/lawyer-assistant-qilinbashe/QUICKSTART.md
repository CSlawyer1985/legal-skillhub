# 律师助手 — 3分钟上手

## 新手只看这三份文件
| 文件 | 看什么 |
|:-----|:-------|
| 本文件（QUICKSTART.md） | 3分钟上手路径，直接说情况就能用 |
| FAQ.md | 常见问题与「不能做什么」反模式，先扫一眼避免错误用法 |
| references/反模式清单.md | 详细避坑清单（10条，含后果说明） |

> 其余 180+ 文件均为按需调用的专家技能与参考材料，分类清晰（agents / templates / references / examples），不需要提前阅读。

## 怎么用

**直接说您的情况，AI自动匹配最合适的专家。**

如：朋友欠钱不还 / 被车撞了 / 公司辞退我 / 想离婚

## 三步上手

1. **说情况**：把您的法律问题用大白话说出来
2. **看分析**：AI自动按五段式输出（事实→法条→分析→建议→计算）
3. **取文书**：说“导出Word文档”获取国标格式正式文书

> 💡 首次使用无需任何准备：首轮自动完成「启动体检 + 全景图发布」，出图与案情分析并行；也可先跑  查看依赖就绪状态。

## 常用技巧

| 您说 | 效果 |
|:-----|:------|
| 切换大白话模式 | 法律术语翻译成日常用语 |
| 帮我分析这个证据 | 跳过前置直接分析 |
| 导出Word文档 | 生成A4排版正式文书 |
| 我不会 | 转为引导模式，一步步问 |
| 重新开始 | 清空当前对话重新来 |

## 示例

> **“我借给朋友5万有借条不还”** — 5分钟后拿到起诉状初稿+证据清单
> **“被车撞了对方全责”** — 10分钟后拿到赔偿清单+起诉状
> **“公司辞退只给1个月补偿”** — 15分钟后拿到仲裁申请书+经济补偿计算表

## 注意

- 所有文书均为初稿，需律师审核后提交法院
- 不用真实姓名，用张三/李四代替
- 本工具不做胜率预测

## 能力边界小测验

**试试看：以下哪个是AI可以帮你做的？**

- A. 代你出庭打官司
- B. 生成起诉状初稿
- C. 预测你一定能赢

> 正确答案：**B**。AI可以生成法律文书初稿，但不能出庭代理，也不能预测案件结果。
