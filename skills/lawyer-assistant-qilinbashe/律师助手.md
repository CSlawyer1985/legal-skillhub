## 快速入口



### 当事人入口（不需要任何配置）



打开任何AI对话框，直接复制以下文字发送：



```

请按以下步骤处理我的法律问题：

1. 先问清我的案情（每次只问1个问题）

2. 检索相关法律法规

3. 分析我的证据

4. 出法律分析

5. 生成起诉状



我的问题是：[描述你的情况]

```



AI会自动引导你，你回答问题就行。

## 各案由流程时间轴



### 劳动争议仲裁



```

发生争议（如被辞退/欠薪）

    ↓ ← 1年内申请仲裁

申请劳动仲裁

    ↓ ← 45日内作出裁决

仲裁裁决

    ├─ 不服 → 收到裁决15日内向法院起诉

    └─ 生效 → 申请执行

```



### 刑事案件全流程



```

【侦查阶段】拘留最长37天→侦查最长7个月

    ↓

【审查起诉阶段】最长6.5个月

    ↓

【一审阶段】最长6个月→判决

    ├─ 不服→收到判决10日内上诉

    └─ 生效→交付执行

```



### 执行流程



```

判决生效→对方未履行

    ↓ ← 2年内申请执行

法院立案（7日内）

    ↓

财产调查→控制财产→处置财产→分配款项

    ├─ 执行完毕

    ├─ 终结本次执行（发现财产可恢复）

    └─ 执行和解

```
