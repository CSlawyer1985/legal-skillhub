# 律师助手 · 常见问题（FAQ）

## ⚠️ 反模式速览（先说清楚不能做什么）

| # | 反模式 | 正确做法 |
|:-:|:-------|:---------|
| 1 | 问「能不能赢」「胜率多少」 | AI无法预测诉讼结果，但可分析有利因素与不利因素 |
| 2 | 拿AI文书直接去立案 | 所有文书均为初稿，须经执业律师实质审查、修改并签字 |
| 3 | 跳过证据整理直接要起诉状 | 没有证据支撑的起诉状无法立案，先整理证据清单 |
| 4 | 把AI当成法官 | AI只做法律分析，不替代裁判结论，最终以法院认定为准 |
| 5 | 一次对话想解决所有复杂问题 | 刑民交叉、破产重整等复杂案件按阶段分步推进 |
| 6 | 把法律咨询当心理疏导 | 情绪困扰建议寻求专业心理帮助；法律问题找律师助手 |
| 7 | 对话里输入真实姓名、身份证号 | 用「张三」「李四」化名，身份证号只说后4位 |
| 8 | 以为AI万能 | AI不能出庭、不能保证结果、不能替代律师面谈，重大事项必须咨询执业律师 |

## 🤖 AI回应示例（触发反模式时AI怎么说）

- 用户问「我能赢吗」→「我无法预测诉讼结果，但可以帮您分析：本案有利因素有……不利因素有……胜诉与败诉的关键在证据。」
- 用户要「写一份完美的合同」→「合同没有“完美”一说，需要结合具体交易目的定制。我先问您三个问题：交易标的、付款方式、违约情形。」
- 用户说「直接给我起诉状」→「可以，但起诉状需要证据支撑。您先告诉我：有借条/合同吗？有转账记录吗？」

## ❓ 精选问答

**Q1：律师助手能帮我做什么？**
覆盖民事、刑事、劳动、非诉、破产、执行、行政、仲裁全领域，内置 107 个技能文件（73 个专业版 + 7 个路由/工具 + 26 个工具 + 1 个推图技能）。从案情采集、法律分析、文书生成到出庭执行、交付后续，全流程辅助。

**Q2：首次使用要注意什么？**
无需任何准备，直接说您的情况即可。首次调用会自动完成「启动体检 + 全景图发布」：系统自检依赖与包完整性（可手动运行  查看就绪状态），并自动在右侧常驻「律师助手全景图」——您不需要记住任何命令、不需要先让 AI 展示目录图，出图与案情分析并行进行，不耽误分析。全景图是能力导航，随时可点任意节点查看引导。

**Q3：我的案件材料安全吗？**
真实在审案件强制脱敏当事人信息；所有文书均标注「AI 生成初稿，不得直接使用，须经主办律师实质审查」。本工具不替代执业律师的实质判断。

**Q4：生成的内容能直接用吗？**
不能。所有交付物均为办案辅助草稿，事实认定须以原始书证与法院查明为准；重大权益事项请务必咨询执业律师，紧急情况拨打 110，法律咨询拨打 12348。

**Q5：支持哪些平台？**
支持 WorkBuddy、SkillHub 及 codebuddy / claude-code / codex / hermes / windsurf 等兼容平台（见  的 platforms 字段）。

**Q6：怎么描述我的情况最有效？**
按「谁 + 什么事 + 什么时候 + 现在什么状态」说清楚即可，例如「2023年借给朋友5万有借条，现在到期不还」。证据（借条、合同、聊天记录、转账记录）越全，分析越准。说不清也没关系，律师助手会通过追问逐步收集。

**Q7：多久能出结果？会不会很慢？**
常规咨询在对话中即时响应；复杂案件（如需要多技能联动的刑民交叉、破产重整）会分阶段推进。若工具检索较慢，可先用内置离线法条兜底，不阻塞对话。

**Q8：结果一定会准吗？**
不保证。AI 基于现行有效法律（截至法条时效基线 2026-07-01）和您提供的材料分析，不构成正式法律意见；法条时效、个案裁量均可能影响结论。重要决策前请执业律师复核。

**Q9：涉及隐私的案件（离婚、刑事等）怎么保护？**
请用化名替代真实姓名，隐去身份证号、手机号、住址等可识别信息；律师助手会输出脱敏提醒，并对敏感案件采用更严格的隐私处理。

**Q10：收费吗？要多少钱？**
本工具为免费法律服务辅助。诉讼费、律师费、保全担保费等实际费用，由相应法院、律所、机构按标准收取，律师助手可提供计算参考。

**Q11：AI 生成的分析和文书能作为证据或正式提交吗？**
不能直接提交。生成内容均为初稿，须经执业律师实质审查、修改并签字后方可用于立案、庭审等正式程序。

**Q12：遇到紧急情况怎么办？**
人身安全受威胁请立即拨打 110；需要法律援助可拨打 12348 法律服务热线（24小时），或前往当地法律援助中心现场咨询。

**Q13：全景图不显示怎么办？**
直接说“继续”即可，不影响任何分析功能。全景图是能力导航（可选辅助），其渲染与发布由脚本自动完成（，自动定位、自动渲染、自动发布， 可自检自愈）；若当前环境不支持 HTML 预览，AI 会自动输出纯文本节点树兜底——**全程不需要您手动复制文件**。

**Q14：上传的文件格式特殊（Word/Excel/PPT/压缩包/视频等）怎么处理？**
支持 12 类格式：PDF、图片（含 HEIC）、txt/md/csv、Word、Excel、PPT、HTML、音频、视频、zip 压缩包、eml 邮件（详见 107-多模态材料解析格式矩阵）。缺依赖的格式会明确提示安装命令或替代方式（转 PDF / 截图上传 / 粘贴文字），**不假装成功**；单个文件超过 100MB 会提示压缩后上传。
