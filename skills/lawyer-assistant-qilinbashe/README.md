# 律师助手 · 法律专家技能包

> 🚀 **30秒快速入门：直接说您的法律问题——比如「朋友借了我5万不还」——AI会自动匹配最佳法律专家，分析案情、生成文书初稿。说大白话就行，不用懂法律术语。**
> 不知道怎么开口？随便说一句，AI会引导你。不想打字？说「示例」查看常用场景。

## 🚀 1分钟上手

1. 打开任意AI对话界面
2. 加载「31-总控路由」技能
3. 直接用大白话说你的问题，例如：**「朋友借钱不还，只有微信转账记录，怎么办？」**
4. AI会引导你补充信息，然后给出分析

> 不用选技能，不用懂法律术语。说清楚问题就行。

## 🔧 安装前置条件（必读）

> 本包按「核心轻量化」原则，将 5 部重资料**外置到法律法规知识库**，不随包携带。安装后需先注入知识库，相关能力才完整可用。
>
> **SkillHub 提交版说明**：ZIP 共 192 个文件（173 个 .md + 1 个 .yaml + 15 个 .py + 1 个 .json + 2 个 .html，即完整可运行包）；上传 SkillHub 时按平台规则仅提交 174 个 .md/.yaml（173 md + 1 yaml），自动排除 18 个非白名单文件（15 个 .py 脚本 + 2 个 .html + 1 个 .json）。平台元数据（`.workbuddy-plugin/`、`.codebuddy-plugin/`、`_meta.json`、`_skillhub_meta.json`）保留在源目录与 Gitee，由 `_plugin_base.json` + `generate_plugins.py` 生成，WorkBuddy/CodeBuddy 安装时自动附带；ZIP 内自检请用 `verify_consistency.py`（已支持 zip 模式：无 plugin.json 时从 manifest 推导，不误报）。

| 外置资料 | 影响能力 | 注入方式 |
|:---------|:---------|:---------|
| 离线法条全集 | 离线降级 / MCP 不可用时法条兜底 | 导入知识库（见下方） |

**注入校验（安装后必跑）：**

```bash
# 校验 5 部外置资料是否已注入（缺失时给出影响范围）
python scripts/check_knowledge_base.py
# 指定知识库目录时
python scripts/check_knowledge_base.py --kb-dir <知识库根目录>
```

**校验通过（exit 0）** → 全部能力可用；**存在缺失（exit 1）** → 对应能力降级（技能包本体加载不受影响），补齐后重跑校验确认。

> 💡 知识库注入入口：Hermes/WorkBuddy 的「法律法规知识库」配置处，或桌面源目录 `法律专家/知识库/`（含 5 部合并全集原始分件备份）。

## 🔌 总控路由（语义分诊）

不确定案由？总控路由会自动匹配最合适的专家：

```
请读取 skills/legal/总控路由/SKILL.md
我遇到的问题是：[描述你的情况]
```

**匹配规则：** 语义理解，非关键词匹配。优先匹配🟢常驻技能，其次🟡按需技能。
