# 保险合同纠纷

> 覆盖财产险（车险/家财险/责任险）与人身险（重疾/医疗/意外/寿险）两大主线。核心是「责任认定 + 拒赔抗辩 + 金额计算」。

## 一、案件分析框架

### 1. 保单效力审查

| 检查项 | 要点 |
|:-------|:-----|
| 投保人如实告知义务 | 投保时未如实告知 → 保险公司可解除合同（故意=不赔不退；过失=不赔退保费），但须在知道解除事由30日内行使 |
| 两年不可抗辩条款 | 人身险合同成立超2年，保险公司不得以未如实告知解除（《保险法》第16条） |
| 保险利益 | 投保人对保险标的不具有保险利益的合同无效 |
| 代签名问题 | 人身险投保单非本人签名 → 合同效力存疑，可主张无效或撤销 |
| 未成年人投保 | 以死亡为给付条件的，须经监护人同意 |

### 2. 保险责任认定

```
财产险：事故原因是否属于承保范围（列明风险 vs 一切险除外责任）
人身险：是否符合保险条款定义的保险事故（重疾定义/意外定义/免责情形）
关键区分：
- 意外险：突发+外来的+非本意的+非疾病的 → 猝死通常不算意外（除非条款约定）
- 重疾险：确诊即赔（按条款定义的疾病/手术/状态），非"治疗后才赔"
- 医疗险：合理且必要的医疗费用，注意免赔额与赔付比例
```

### 3. 免责条款效力（高频争议点）

```
保险公司对免责条款未尽提示+明确说明义务的，该条款不产生效力（《保险法》第17条）
判断标准：
- 提示：保单中加黑加粗等足以引起注意的标示
- 明确说明：投保时对条款内容以书面/口头形式作出常人能够理解的解释
举证责任在保险公司：须提供投保人签字的《免责条款说明》/双录视频/回访录音

典型无效免责：
- 车险"驾驶证过期免赔"（与事故无因果关系的格式条款）
- 重疾险"等待期后首次确诊"的模糊定义争议
```

### 4. 理赔金额计算

```
财产险（车损）：实际损失 - 免赔额，按定损单核（全损=保险价值或实际价值）
财产险（三者）：人身伤亡（按人身损害98号标准）+ 财产损失
人身险（重疾/寿险/意外身故）：按保额一次性给付
人身险（医疗）：合理医疗费 × 赔付比例 - 免赔额（注意社保已报销部分是否扣除）
```

## 二、常见拒赔理由与破局

| 拒赔理由 | 破局思路 |
|:---------|:---------|
| “不属于保险责任” | 对照条款定义逐项反驳；格式条款不利解释规则（《保险法》第30条） |
| “未如实告知” | 询问告知原则（未询问不告知不构成）；两年不可抗辩；举证保险公司未尽说明 |
| “免责条款已提示” | 要求保险公司举证提示说明义务；未举证的条款无效 |
| “等待期内出险” | 检查等待期起算日与确诊日；条款对“确诊”定义模糊时用不利解释规则 |
| “损失夸大/鉴定不符” | 申请重新鉴定；保险公司单方定损不具当然效力 |
| “非医保用药不赔” | 医疗险拒赔非医保用药：主张“合理且必要”即可赔（最高法观点），条款明确除外才可拒 |

## 三、诉讼要点

- **管辖**：被告住所地或保险标的物所在地法院；人身险=被告住所地或被保险人住所地
- **举证责任分配**：保险公司对免责条款、除外责任、如实告知抗辩承担举证责任
- **诉讼时效**：人寿保险5年，其他保险2年（自知道保险事故发生之日）
- **常见请求**：给付保险金+利息；主张免责条款无效；确认合同解除无效

## 四、代位求偿（财产险）

```
被保险人向第三者索赔后，保险人赔付后取得代位求偿权
适用：车险中无责方被拒赔时，可先向自己保险公司索赔（代位求偿），由保险公司向对方追偿
优点：无责方不必等对方赔，快速拿钱修车；次年保费按出险次数上浮（需权衡）
```
