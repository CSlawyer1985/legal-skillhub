### 第二步：撤销仲裁裁决事由审查



**撤销事由审查框架（仲裁法第58条）：**



```

┌─ ① 没有仲裁协议（第58条第1款第1项）

│   ├─ 当事人之间不存在书面仲裁协议

│   ├─ 仲裁协议无效/失效

│   └─ 仲裁协议不能约束本案当事人

│

├─ ② 裁决事项不属于仲裁协议的范围（第58条第1款第2项）

│   ├─ 仲裁庭超越仲裁协议范围作出裁决

│   ├─ 部分超裁 → 可撤销超裁部分

│   └─ 全部超裁 → 可全部撤销

│

├─ ③ 仲裁庭的组成/仲裁程序违反法定程序（第58条第1款第3项）

│   ├─ 仲裁庭组成不符合仲裁规则

│   ├─ 未给予当事人陈述/辩论机会

│   ├─ 证据未质证/未交换

│   └─ 仲裁员应当回避而未回避

│

├─ ④ 裁决依据的证据系伪造（第58条第1款第4项）

│   ├─ 对方提交的关键证据系伪造

│   └─ 需要提供证据证明伪造事实

│

├─ ⑤ 对方隐瞒了足以影响公正裁决的证据（第58条第1款第5项）

│   ├─ 证据在对方掌控之下

│   ├─ 该证据足以影响裁决结果

│   └─ 对方在仲裁程序中未提交

│

├─ ⑥ 仲裁员在仲裁该案时有索贿受贿/徇私舞弊/枉法裁决（第58条第1款第6项）

│   ├─ 需要生效刑事判决/纪律处分决定佐证

│   └─ 证明标准高，实务中极少认定

│

└─ ⑦ 法院主动审查：违背社会公共利益（第58条第3款）

    ├─ 法院可依职权主动审查

    └─ 适用范围较窄，从严认定

```



**撤销程序关键节点：**



```

┌─ 提出期限：收到裁决书之日起6个月内（仲裁法第59条）

├─ 管辖法院：仲裁委员会所在地的中级人民法院（仲裁法第58条）

├─ 法院审查期限：受理撤销申请之日起2个月内作出裁定（仲裁法第60条）

├─ 裁定类型：

│   ├─ 驳回 → 裁决继续执行

│   ├─ 撤销 → 裁决自始无效（当事人可重新达成仲裁协议或向法院起诉）

│   └─ 通知重新仲裁 → 法院认为可由仲裁庭重新仲裁的，通知仲裁庭（仲裁法第61条）

└─ 救济：对撤销/驳回撤销的裁定，不得上诉（最高法关于仲裁法解释第20条）

```

**不予执行事由审查（仲裁法第63条+民诉法第244条）：**



```

┌─ ① 当事人在合同中没有订有仲裁条款或者事后没有达成书面仲裁协议

│   ├─ 同撤销事由之"没有仲裁协议"

│   └─ 在同一程序中可以重复主张

│

├─ ② 裁决的事项不属于仲裁协议的范围或者仲裁机构无权仲裁

│   ├─ 同撤销事由之"超裁"

│   └─ 法院可部分不予执行

│

├─ ③ 仲裁庭的组成/仲裁程序违反法定程序

│   ├─ 同撤销事由

│   └─ 注意：在执行阶段提出不予执行，不违反一事不再理

│

├─ ④ 裁决所根据的证据是伪造的

│   ├─ 同撤销事由

│   └─ 需提供新证据证明

│

├─ ⑤ 对方当事人向仲裁机构隐瞒了足以影响公正裁决的证据

│   ├─ 同撤销事由

│   └─ 注意与撤销事由的重合与区别

│

└─ ⑥ 法院主动审查：违背社会公共利益（民诉法第244条第3款）

    ├─ 法院可依职权审查

    └─ 适用标准：损害国家/社会整体利益

```



**撤销与不予执行的程序关系：**



```

┌─ 撤销（主动救济）

│   ├─ 由败诉方向中院主动提出

│   ├─ 提出期限：收到裁决书6个月内

│   └─ 审查标准：严格

│

├─ 不予执行（被动抗辩）

│   ├─ 在被执行人收到执行通知后提出

│   ├─ 提出期限：执行程序终结前

│   ├─ 审查标准：与撤销基本相同

│   └─ 注意：已提出撤销被驳回的，不得以同一事由提出不予执行

│

└─ 建议策略：

    ├─ 优先申请撤销（主动，6个月内）

    └─ 撤销申请被驳回后，执行阶段再以其他事由申请不予执行

```

```

涉外仲裁裁决的撤销/不予执行适用特别规定：

│   └─ 适用民诉法第281条（涉外仲裁裁决的撤销事由）

│       ├─ 裁决事项超出仲裁协议范围

│       └─ 仲裁庭组成/仲裁程序与仲裁规则不符

├─ ② 不予执行事由（仲裁法第71条）

│   └─ 适用民诉法第283条（涉外仲裁裁决的不予执行事由）

│       └─ 同上4项

│

├─ ③ 国内vs涉外区分

│   ├─ 国内仲裁：撤销事由包括证据伪造/隐瞒证据（更宽）
```
