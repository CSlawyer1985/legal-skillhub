# 彩礼返还纠纷

> 依据《最高人民法院关于审理涉彩礼纠纷案件适用法律若干问题的规定》（2024年2月1日施行）构建。核心是「性质认定 → 返还条件 → 比例计算」。

## 一、彩礼性质认定（先区分“彩礼”与“一般赠与”）

| 类型 | 认定 | 处理 |
|:-----|:-----|:-----|
| 彩礼（婚约财产） | 以缔结婚姻为目的按习俗给付的财物 | 符合条件可请求返还 |
| 一般赠与 | 恋爱期间表达感情的财物（520/1314转账、普通礼物） | 不返还 |
| 共同生活消费 | 已用于共同生活的部分 | 扣除 |
| 三金/首饰 | 价值较大且有缔结婚姻目的的 | 计入彩礼范围 |
| 见面礼/改口费 | 双方父母对子女的赠与 | 通常不计入彩礼（视当地口径） |

```
判断因素（2024新规）：
1. 给付目的（是否以缔结婚姻为目的）
2. 当地习俗（是否按当地彩礼习俗给付）
3. 财物价值（是否数额较大）
4. 给付时间与场合（订婚仪式/结婚前夕）
```

## 二、返还条件（2024新规核心）

### 情形一：未办理结婚登记

```
原则：应当返还（婚约财产纠纷）
例外：双方已共同生活 → 根据共同生活时间、孕育情况、过错、彩礼数额等酌定返还比例
```

### 情形二：已办理结婚登记但确未共同生活

```
原则：离婚时应当返还
例外：共同生活时间很短 + 彩礼数额过高的，酌定返还（2024新规新增：结婚时间短也可部分返还）
```

### 情形三：婚前给付并导致给付人生活困难

```
原则：离婚时应当返还
判断：给付人靠个人财产和离婚分得的财产无法维持当地基本生活水平
```

### 情形四：已办理结婚登记且共同生活（2024新规新增规则）

```
原则上不返还
例外：共同生活时间较短且彩礼数额过高的，可酌定返还部分
考量因素：
1. 共同生活时间长短
2. 彩礼数额是否过高（当地人均可支配收入倍数参考）
3. 孕育子女情况
4. 双方过错
5. 当地习俗
```

## 三、返还比例计算参考

| 场景 | 常见返还比例参考 |
|:-----|:----------------|
| 未登记+未共同生活 | 80%-100% |
| 未登记+共同生活1年内 | 50%-80%（视时间与过错） |
| 未登记+共同生活1-3年 | 30%-50% |
| 已登记+未共同生活 | 60%-90% |
| 已登记+共同生活短+彩礼过高 | 20%-50%（酌定） |
| 已登记+共同生活正常 | 一般不返还 |

> ⚠️ 比例仅为实务参考区间，各地法院裁量差异大，须结合当地近两年判例。

## 四、诉讼要点

- **案由**：婚约财产纠纷（未登记）/ 离婚纠纷（已登记离婚时一并处理）
- **管辖**：被告住所地法院（婚约财产纠纷）
- **当事人**：通常为给付方（本人或父母）起诉收受方；父母代为收受的，实际收受人列为被告
- **举证**：转账记录、取现记录、聊天记录（确认彩礼性质）、婚礼视频、证人证言、购物凭证（三金）
- **共同生活证据**：同居时间、租房合同、共同消费记录、怀孕生育记录

## 五、关联问题

| 问题 | 处理 |
|:-----|:-----|
| 借条性质的彩礼（借款买车买房） | 按民间借贷另案处理，不属彩礼返还范围 |
| 彩礼已用于共同生活消费 | 扣除已消费部分 |
| 一方出轨/家暴过错 | 作为返还比例酌定因素 |
| 订婚宴费用/旅拍等 | 视约定与凭证，通常不作为彩礼 |
| 分手后“青春损失费” | 无法律依据，不支持（可作调解筹码） |
