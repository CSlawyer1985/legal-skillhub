# 法律检索与研究报告

> 输入研究问题→输出检索路径+法律备忘录。离线也能用。

## 一、触发方式

- 用户说「查一下这个法律问题」「法律研究」「法律备忘录」自动激活
- 手动触发：说「法律检索」或「研究」

## 二、核心能力

### （甲）检索路径设计

| 检索目标 | 推荐工具/路径 | 优先级 |
|:---------|:-------------|:------|
| 法规条文最新版本 | 北大法宝(pkulaw)→法规数据库 | 首选 |
| 类案/裁判要旨 | 裁判文书网→华宇元典(yuandian) | 首选 |
| 司法解释/指导意见 | 最高法官网→北大法宝 | 首选 |
| 法学观点/学术文章 | 知网→法学期刊 | 补充 |
| 离线兜底 | 离线法条精华.md（32部核心法规） | 降级 |

### （乙）检索词扩展

- 输入关键词→输出同义词/上位词/下位词扩展

- 类案检索词（如“违约金过高”→“违约金调整”“LPR四倍”“实际损失”）

## 三、边界

- 本技能提供检索方法和报告框架，具体检索结果以实际数据库为准
- 未配置MCP时自动降级为离线法规库+检索方法论指引
- 法律备忘录中引用的法条建议联网复核最新版本
- 涉及重大复杂法律问题建议查证多个来源

## 格式依据（国家标准锚定）

本技能涉及的标准文书交付物，须严格遵循以下国家标准框架，不得使用自定义或已过时的格式：

- **文书类型**：法律检索报告、类案研究报告（内部交付，须规范）
- **国标依据**：参考最高人民法院《民事诉讼文书样式》调研报告体例与律师业务文书规范，结构清晰、引用可溯
- **强制要求**：凡输出正式文书（起诉状/答辩状/上诉状/申请书/代理词/证据清单/和解协议/裁决/判决等），一律按最高法《民事诉讼文书样式》（法〔2016〕221号 及后续修订）或对应专门样式（仲裁/行政/破产）的结构、要素、用语规范生成；当事人称谓、案由、法条引用格式均依国标。
- **交叉比对**：文书中引用的法条，须经  多源核验并标注置信度（见 ）。

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
