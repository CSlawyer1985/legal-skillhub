# 诉讼费用计算器

> 按标的额自动分段累计，输出格式化费用明细表。

## 一、触发方式

- 用户说「打官司多少钱」「诉讼费多少」「帮我算费用」自动激活
- 也可输入标的额直接计算：如「标的额50万诉讼费多少」

## 二、计算方法

### 财产案件受理费（分段累计）

| 标的额区间 | 费率 | 速算增加额 |
|:----------|:----|:----------|
| 不超过1万元 | 50元/件 | — |
| 1万-10万元 | 2.5% | — |
| 10万-20万元 | 2% | 500元 |
| 20万-50万元 | 1.5% | 1500元 |
| 50万-100万元 | 1% | 4000元 |
| 100万-200万元 | 0.9% | 5000元 |
| 200万-500万元 | 0.8% | 7000元 |
| 500万-1000万元 | 0.7% | 12000元 |
| 1000万-2000万元 | 0.6% | 22000元 |
| 超过2000万元 | 0.5% | 42000元 |

### 非财产案件

| 类型 | 费用 |
|:-----|:-----|
| 离婚案件 | 50-300元/件（涉及财产分割超20万部分×0.5%） |
| 侵害人格权 | 100-500元/件（涉赔偿超5万部分×1%） |
| 知识产权 | 500-1000元/件（涉赔偿超10万部分×0.5%） |
| 劳动争议 | 10元/件 |
| 行政案件 | 50-100元/件 |

### 其他费用

| 费用类型 | 标准 |
|:---------|:-----|
| 保全费 | 标的额×1%，**最高5000元**（不足1000元按1000元） |
| 执行费 | 分段累计，最高不超过执行标的额的1% |
| 上诉费 | 按不服部分计算，同受理费标准 |
| 仲裁费 | 按仲裁委员会标准，一般为受理费+处理费 |

## 三、输出格式

```
诉讼费用计算表
──────────────────────────────
案件类型：财产案件
标的金额：500,000 元
──────────────────────────────
受理费：50万×1.5%+1500 = 8,800 元
保全费：50万×1%=5,000（上限5,000）
执行费：50万×1%=5,000（按执行标准）
合计（不含仲裁）：约 18,800 元
──────────────────────────────
注：最终费用以法院/仲裁委实际收费为准
```

## 四、边界

- 本计算基于《诉讼费用交纳办法》，各地法院可能有地方性差异
- 实际立案时以法院核定为准，本计算仅作参考
- 涉及风险代理比例限制、法律援助费用减免等，参见「收费合规与风险代理指引」
- 劳动争议案件受理费10元（简易程序减半为5元）
