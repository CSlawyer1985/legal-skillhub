# 人身损害赔偿计算器

> 按法定赔偿项目逐项计算，输出分项明细表。赔偿标准以受诉法院所在地（省/自治区/直辖市）上一年度数据为准，本表采用全国通用计算框架，具体数额需代入当地统计局发布的最新数据。

## 一、触发方式

- 用户说「伤残X级能赔多少」「误工费怎么算」「帮我算赔偿」自动激活
- 也可直接输入：如「十级伤残，月收入6000，误工3个月」

## 二、赔偿项目与计算方法

### 1. 医疗费

| 项目 | 计算方式 |
|:-----|:---------|
| 医疗费 | 实际支出票据合计（挂号/检查/治疗/药品/住院/康复），凭票据实报实销 |
| 后续治疗费 | 凭医嘱或鉴定意见确定，可一并主张 |

### 2. 误工费

```
误工费 = 实际减少的收入 × 误工期（天）
- 有固定收入：按实际减少收入计算（需劳动合同/工资流水/完税证明）
- 无固定收入：按近3年平均收入；无法证明的按受诉法院所在地相同行业上年度平均工资
- 误工期以医嘱或鉴定意见为准
```

### 3. 护理费

```
护理费 = 护理人员收入（或当地护工劳务报酬标准）× 护理期（天）× 护理人数
- 护理人员有收入的：参照误工费标准
- 护理人员无收入/雇佣护工的：按当地护工劳务报酬标准（通常 120-200 元/天）
- 护理期与护理人数以医嘱或鉴定意见为准
```

### 4. 营养费 + 住院伙食补助费

| 项目 | 标准 |
|:-----|:-----|
| 营养费 | 当地标准（通常 30-50 元/天）× 营养期（天） |
| 住院伙食补助费 | 当地标准（通常 50-100 元/天）× 住院天数 |

### 5. 交通费 + 住宿费 + 鉴定费

| 项目 | 计算方式 |
|:-----|:---------|
| 交通费 | 就医/转院/复查实际发生的交通票据，合理范围内实报实销 |
| 住宿费 | 外地就医确需住宿的，凭票据合理主张 |
| 鉴定费 | 伤残等级/三期（误工护理营养期）鉴定费票据实报 |

### 6. 残疾赔偿金（核心大项）

```
残疾赔偿金 = 上一年度城镇居民人均可支配收入 × 伤残赔偿指数 × 20年（60周岁以下）
- 伤残赔偿指数：一级100%、二级90%、三级80%、四级70%、五级60%、六级50%、七级40%、八级30%、九级20%、十级10%
- 60周岁以上：年龄每增加1岁减少1年；75周岁以上按5年计算
- 多处伤残：以最高等级为基数，附加指数合计不超过10%（如十级+十级=10%+2%=12%）
- 注：自2022年5月起全国统一城乡标准（城镇标准），不再区分城乡
```

### 7. 被扶养人生活费

```
被扶养人生活费 = 上一年度城镇居民人均消费支出 × 扶养年限 × 扶养义务人伤残赔偿指数 ÷ 扶养义务人数
- 扶养年限：未成年人计算至18周岁；无劳动能力又无生活来源的成年人按20年（60周岁以上递减）
- 被扶养人：未成年子女 / 无劳动能力无生活来源的父母（年满60周岁或丧失劳动能力）
```

### 8. 精神损害抚慰金

| 伤残等级 | 参考区间（各地差异较大） |
|:---------|:------------------------|
| 十级 | 3,000-10,000 元 |
| 九级 | 5,000-15,000 元 |
| 八级 | 10,000-20,000 元 |
| 七级 | 15,000-30,000 元 |
| 六级 | 20,000-40,000 元 |
| 五级 | 30,000-50,000 元 |
| 四级 | 40,000-60,000 元 |
| 三级 | 50,000-70,000 元 |
| 二级 | 60,000-80,000 元 |
| 一级 | 70,000-100,000 元 |
| 死亡 | 50,000-100,000 元 |

> 精神损害抚慰金在交强险中优先赔付（死亡/伤残限额18万内），商业险与侵权人按责任比例承担。

### 9. 死亡赔偿金（死亡案件）

```
死亡赔偿金 = 上一年度城镇居民人均可支配收入 × 20年（60周岁以下）
- 60周岁以上每增1岁减1年；75周岁以上按5年
- 另有丧葬费：按上一年度职工月平均工资 × 6个月
```

## 三、责任比例调整

```
最终赔偿 = Σ(各分项) × 责任比例
- 机动车事故：先交强险（医疗1.8万/死亡伤残18万/财产2000元）内全额赔，超出部分按责任比例
- 一般侵权：按过错比例（全部责任100%/主要责任70-80%/同等责任50%/次要责任20-30%）
- 与有过失：受害人自身过错相应减轻侵权人责任
```
