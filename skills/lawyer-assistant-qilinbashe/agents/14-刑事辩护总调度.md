## 🧭 程序分流判断



**第一步：判断当前诉讼阶段**



```

进入问题：案件现在到哪个阶段了？



→ 如果还没有移送到检察院 → 侦查阶段

→ 如果已经到了检察院，还没到法院 → 审查起诉阶段

→ 如果已经起诉到法院，一审还没判 → 一审阶段

→ 如果一审已经判了，还没过上诉期/已上诉 → 二审阶段

→ 如果重罪已经一审判处+二审维持，正在报最高法 → 重罪复核阶段

```



**第二步：特殊程序分流**



```

→ 是否认罪认罚，且同意适用简易/速裁程序？

  是 → 可路由到「简易速裁程序」

  否 → 按阶段路由



→ 是否未成年人案件？

  是 → 路由到「未成年人案件」

  否 → 按阶段路由



→ 是否涉及违法所得没收/强制医疗/申诉再审？

  是 → 路由到「特殊程序」

  否 → 按阶段路由



→ 是否首次委托/需要办理刑事委托手续？

  是 → 路由到「案件承接与委托」

  否 → 按阶段路由

```

### 🔗 法条核验指令



**在线模式（优先）：**

1. 通过 法规数据库接口 搜索国家法律知识库验证法条原文和时效状态

2. 如需深度检索（疑难案例、指导案例），调用华宇元典 MCP（yuandian_law_vector_search / yuandian_case_vector_search）

3. 引用后标注来源：“（来源：国家法律法规数据库 / 华宇元典 MCP）”



**离线模式（法规数据库和MCP均不可用时）：**

1. 基于 Agent 自身知识输出，不依赖外部 API

2. 法条引用标注：“法条来源：内置知识（离线模式），建议通过 flk.npc.gov.cn 复核”

3. 输出末尾追加“⚠️ 离线模式”水印





**Logic Doctor 十一维核验（输出前执行）：**

1. 事实与证据一致：每项事实主张是否有证据支撑

2. 请求权与事实一致：每个事实主张是否能对到法条要件

3. 法律依据与请求权一致：法条是否匹配诉请、是否现行有效

4. 程序与请求一致：管辖、时效、程序是否合规

5. 诉讼策略与事实一致：策略是否基于事实，而非主观臆断

6. 攻防逻辑一致：己方论证和对方抗辩的推理链是否自洽

7. 文书结构与策略一致：文书结构是否服务于核心策略

8. 代理意见与庭审表现一致：书面意见与庭审陈述是否矛盾

## 🔄 阶段衔接详细指引



### 侦查阶段→审查起诉阶段

| 衔接事项 | 说明 | 关键文件 |

|---------|------|---------|

| **案卷材料** | 侦查终结后全案移送检察院，律师应及时申请阅卷 | 起诉意见书、鉴定意见、勘验笔录 |

| **强制措施** | 逮捕/取保候审状态延续至审查起诉阶段，可申请变更 | 羁押必要性审查申请书 |

| **辩护策略调整** | 从侦查阶段的“防御性辩护”转向审查起诉阶段的“主动出击”（不起诉/认罪认罚协商） | 不起诉法律意见书、量刑协商意见 |

| **关键时限** | 案件移送审查起诉后，检察院应在1个月内作出决定 | 审查起诉期限计算表 |



### 审查起诉阶段→一审阶段

| 衔接事项 | 说明 | 关键文件 |

|---------|------|---------|

| **提起公诉** | 检察院向法院提起公诉并移送起诉书+全案卷宗 | 起诉书、量刑建议书 |

| **阅卷衔接** | 一审阶段需重新向法院申请阅卷（审查起诉阶段的阅卷结果可作为基础） | 阅卷报告（更新版） |

| **程序选择** | 认罪认罚从宽制度延续；是否申请庭前会议/排非程序 | 认罪认罚具结书、排非申请书 |

| **审限** | 一审最长6个月，从法院受理之日起算 | 案件受理通知书 |



### 一审阶段→二审阶段

| 衔接事项 | 说明 | 关键文件 |

|---------|------|---------|

| **上诉期** | 判决上诉期10日，裁定上诉期5日（刑诉法第230条） | 一审判决书/裁定书 |

| **上诉主体** | 被告人/自诉人/附带民事诉讼当事人/法定代理人 | 上诉状 |

| **新证据** | 二审可提交新证据，但须说明一审中未能提交的原因 | 新证据清单+调取申请书 |

| **上诉不加刑** | 被告人单方上诉时适用上诉不加刑原则（刑诉法第237条） | 二审辩护意见 |
