### 第二步：救济路径规划



**救济路径选择（按异议类型区分）：**



```

┌─ ① 执行行为异议（民诉法（2021年修正）第225条）

│   ├─ 适用主体：当事人、利害关系人

│   ├─ 异议对象：执行措施违法（如超标的查封、评估程序违法、拍卖公告违法）

│   ├─ 救济路径：异议→法院裁定（7日内审查）→不服可向上一级法院申请复议（15日）

│   ├─ 是否停止执行：原则上不停止，但法院可裁定中止

│   └─ 法条依据：民诉法（2021年修正）第225条



├─ ② 案外人异议（民诉法（2021年修正）第227条）

│   ├─ 适用主体：案外人（主张对执行标的有实体权利）

│   ├─ 异议对象：对特定执行标的主张所有权/担保物权/租赁权等

│   ├─ 救济路径：异议→法院裁定→不服时

│   │   ├─ 与原判决/裁定有关→申请再审

│   │   └─ 与原判决/裁定无关→提起案外人执行异议之诉（15日内）

│   ├─ 是否停止执行：原则上不停止，但案外人提供担保可申请中止

│   └─ 法条依据：民诉法（2021年修正）第227条



├─ ③ 分配方案异议

│   ├─ 适用主体：债权人、被执行人

│   ├─ 异议对象：分配方案中的分配比例、受偿顺序等

│   ├─ 救济路径：收到分配方案后15日内提出异议→其他债权人15日反对→提起分配方案异议之诉

│   └─ 法条依据：最高法执行程序解释第25-26条



└─ ④ 追加被执行人异议

    ├─ 适用主体：被追加的第三人

    ├─ 追加法定情形（最高法变更追加执行当事人规定）：

    │   ├─ 出资瑕疵的股东（第17条）

    │   ├─ 一人公司股东不能证明财产独立（第20条）

    │   ├─ 未经清算即注销的公司股东（第21条）

    │   ├─ 合并分立的承受人（第11-12条）

    │   └─ 无偿接受财产的第三人（第25条）

    ├─ 救济路径：追加裁定→不服→提起执行异议之诉（15日内）

    └─ 法条依据：最高法变更追加执行当事人规定

```



**期限提示（强制执行！）：**

```

所有异议期限均为法定，不得延误：



├─ 执行行为异议：知道或应当知道违法执行行为之日起15日内（复议同）

├─ 案外人异议：执行标的被处置前（最晚至拍卖成交前）

├─ 案外人异议之诉：收到驳回裁定之日起15日内

├─ 分配方案异议：收到分配方案之日起15日内

├─ 追加被执行人异议之诉：收到追加裁定之日起15日内

└─ 执行复议：收到异议裁定之日起10日内（民诉法（2021年修正）第225条）
```

信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）

- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
