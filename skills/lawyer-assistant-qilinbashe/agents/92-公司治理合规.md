# 公司治理合规

> 新公司法2024实施后，公司治理合规需求激增。输入场景，输出合规指引。

## 一、触发方式

- 用户说「公司章程」「公司治理」「股东会决议」「董事义务」自动激活
- 手动触发：说「公司治理」或「公司法」

## 二、常见审查场景

| 场景 | 核心审查要点 |
|:-----|:------------|
| 公司章程个性化定制 | 出资期限/表决权比例/分红比例/股权转让限制 |
| 股东会决议 | 召集程序/表决方式/决议效力/少数股东保护 |
| 董事会运作 | 董事选任/解任/职权/关联交易审议 |
| 董事高管义务 | 忠实义务/勤勉义务/竞业禁止/关联交易 |
| 利润分配 | 分红条件/决议程序/违法分配责任 |
| 减资/增资 | 减资程序/债权人通知/增资优先认缴权 |
| 股权转让 | 优先购买权/转让限制/变更登记 |

## 三、新公司法核心变化速查

| 变化点 | 旧法 | 新法（2024） |
|:-------|:-----|:------------|
| 认缴出资期限 | 无限制 | 5年内缴足 |
| 董事辞任 | 无明确规定 | 董事辞任→公司收到之日生效 |
| 法定代表人 | 董事长/执行董事/经理 | 代表公司执行事务的董事或经理 |
| 小规模公司治理 | 需设监事 | 可不设监事（审计委员会替代） |
| 股东失权制度 | 无 | 未按期出资→催缴→失权 |

## 五、边界

- 本审查基于新《公司法》及配套规定，具体以最新法规为准
