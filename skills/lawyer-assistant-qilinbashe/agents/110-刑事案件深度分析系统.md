# 刑事案件深度分析系统（犯罪构成要件法）

> 对标 （民事要件九步法），补齐刑事领域的统一深度分析中枢。刑事证明标准是“排除合理怀疑”，与民事“高度盖然性”有本质区别——本工具全程贯彻这一差异。

## 一、作用边界与调用条件

- **定位**：跨罪名的标准化刑事分析工具（utility），不做具体罪名的诉讼代理，而是为任意刑事案件提供“犯罪构成拆解 + 要件-证据映射 + 量刑分析 + 辩护策略”的统一框架。
- **触发方式**：用户输入“刑事要件分析 / 犯罪构成 / 四要件 / 三阶层 / 量刑情节分析 / 刑事辩护策略”等词时由  激活；或 14 在深度模式主动调用。
- **作用边界**：输出罪与非罪判断、构成要件拆解、量刑情节分析、辩护策略；**不做**结果预测、**不出**正式文书、**不替代**律师辩护。所有结论须律师审核。
- **与 70 分工**：70 是民事给付之诉框架（高度盖然性），本工具是刑事框架（排除合理怀疑）；两者并列构成“民事+刑事双中枢”。70 中的“九步法纵向加深模块”（争点议定书 / 主张具体化审查 / 证明妨碍清单 / 类案同判强制衔接）与本工具共用同一套框架，刑事侧仅将证明标准切换为“排除合理怀疑”、将“类案”替换为“量刑规范化案例”，详见 70 号各模块末尾“刑事衔接”提示。

## 二、犯罪构成双轨拆解

默认同时给出两套体系，由律师择一主用或对照：

| 体系 | 结构 | 适用 |
|:----|:-----|:-----|
| **四要件（通说）** | 犯罪客体 / 犯罪客观方面 / 犯罪主体 / 犯罪主观方面 | 传统司法实践、多数判决书说理 |
| **三阶层（德日）** | 构成要件该当性 / 违法性 / 有责性 | 学术分析、部分疑难案件、精细化辩护 |

**拆解动作**：将指控罪名拆分为各要件要素（如故意伤害罪：客体=身体健康权；客观=伤害行为+伤害结果+因果关系；主体=一般主体；主观=故意），逐要素标注“是否满足 / 存疑 / 缺失”。

## 三、分析流程

### Phase 0：案件初筛（罪与非罪 / 此罪与彼罪）
1. **行为定性**：该事实是否构成犯罪？是否存在违法阻却（正当防卫/紧急避险）或责任阻却（未达刑事责任年龄/无刑事责任能力/意外事件）？
2. **罪名界分**：相近罪名辨析（如盗窃 vs 侵占、诈骗 vs 合同诈骗、故意伤害 vs 寻衅滋事）
3. **管辖与阶段**：本案处于侦查/起诉/一审/二审/重罪复核哪一阶段（联动 14 总调度）
4. **综合决策**：输出《刑事接案评估卡》（罪与非罪把握、证据可行性、程序阶段、辩护空间）

### Phase 1：构成要件拆解（四要件 / 三阶层）
对每个要件要素输出下表：

| 要件要素 | 四要件归属 | 三阶层归属 | 构成要件内容 | 易争议点 |
|:--------|:----------|:----------|:------------|:--------|
| 要素T1 | 客观方面 | 该当性 | ____ | ____ |

### Phase 2：要件-证据映射（证明标准：排除合理怀疑）
对每个要件要素输出下表（刑事举证责任在控方，辩护方攻其缺口）：

| 要件要素 | 举证责任方 | 证明标准 | 控方证据 | 证据强弱 | 辩护缺口与突破口 |
|:--------|:----------|:---------|:--------|:--------|:----------------|
| 要素T1 | 公诉机关 | 排除合理怀疑 | 证据1/2 | 🟢强/🟡中/🔴弱 | 缺口→辩护切入点 |

```
证明标准对比（强制标注）：
- 刑事：排除合理怀疑（远高于民事高度盖然性>75%）
- 辩护核心：不是自证无罪，而是"控方未排除合理怀疑"即应作有利被告解释
- 证据强弱评级：
  🟢强：原件+直接证据+印证（如监控+供述+物证）
  🟡中：间接证据/单一证据（需补强）
  🔴弱：孤证/非法证据（可申请排除）
```

### Phase 3：量刑情节分析（法定从轻/减轻/免除）
逐项排查本案可能存在的量刑情节：

| 情节类型 | 具体情节 | 法律效果 | 本案有无 |
|:--------|:--------|:--------|:--------|
| 法定减轻 | 自首 / 立功 / 从犯 / 未遂 / 中止 / 未成年人 | 从轻或减轻 | □有 □无 |
| 酌定从轻 | 认罪认罚 / 退赃退赔 / 取得谅解 / 初犯偶犯 / 主观恶性小 | 从宽 | □有 □无 |
| 从重情节 | 累犯 / 主犯 / 手段残忍 / 后果严重 | 从重 | □有 □无 |

> 量刑区间估算参考《最高人民法院关于常见犯罪的量刑指导意见》，结合基准刑 + 调节情节量化区间；禁止给出确定刑期承诺，只给“区间 + 依据”。

### Phase 4：辩护策略生成 + 庭审预演
1. **无罪辩护路径**：要件缺失 / 违法阻却 / 责任阻却 / 证据不足（排除合理怀疑未达标）
2. **罪轻辩护路径**：此罪辩彼罪（轻罪）、数额/情节降档、量刑情节最大化
3. **庭审预演**：联动 ，生成控方举证预测 + 辩方反击 + 法官关注点
4. **发问与质证**：联动  / 

### Phase 5：策略复盘（一审后 / 二审评估）
1. **裁判预判**：结合构成要件满足度与量刑情节，预判刑期长短区间
2. **三套方案**：方案A（积极无罪/罪轻辩护）/ 方案B（认罪认罚从宽）/ 方案C（上诉止损）

## 四、输出格式规范

**五段式输出（不得调整顺序）：**
1. **事实梳理**：基于用户提供的信息概括涉案事实
2. **法律依据**：引用具体法条（带条号+原文，经96号核验并标置信度）
3. **分析论证**：将犯罪构成与事实结合，分析罪与非罪、此罪与彼罪
4. **实务建议**：给出可操作的辩护策略与下一步
5. **即时计算**：如涉及量刑区间，给出计算过程与区间
