# 案件风险评估报告

> 接案/庭前必做。结构化风险矩阵输出，可交付客户。

## 一、触发方式

- 用户说「风险评估」「风险大不大」「案子能不能赢」自动激活
- 39-案件承接与委托在接案阶段引导生成风险评估
- 手动触发：说「风险评估」或「风险矩阵」

## 二、五维风险评估矩阵

| 维度 | 评估项 | 风险等级 | 说明 |
|:-----|:-------|:--------:|:-----|
| 法律风险 | 事实认定/法律适用/举证责任 | 🔴/🟡/🟢 | 核心法律争点的有利/不利 |
| 执行风险 | 对方偿债能力/财产线索 | 🔴/🟡/🟢 | 胜诉后能否执行到钱 |
| 时间成本 | 诉讼周期/鉴定周期/上诉周期 | 🔴/🟡/🟢 | 从立案到执行完毕需要多久 |
| 经济成本 | 诉讼费/律师费/鉴定费/差旅费 | 🔴/🟡/🟢 | 总投入vs预期收益 |
| 声誉风险 | 媒体关注/商业声誉/行业影响 | 🔴/🟡/🟢 | 对企业客户尤为重要 |

### 三B、五维评分卡自动评分（产出物）

**输入案情后自动对五维逐项打分并输出评估报告：**

```
【案件风险评估卡】案由：____ 标的：____
┌──────────┬──────────────┬──────┬────────┐
│ 维度     │ 评分依据      │ 得分 │ 评级   │
├──────────┼──────────────┼──────┼────────┤
│ 1.事实证据 │ 证据充分度0-10 │ __   │ □优□中□差 │
│ 2.法律依据 │ 法条明确度0-10 │ __   │ □优□中□差 │
│ 3.程序风险 │ 时效/管辖/举证 │ __   │ □低□中□高 │
│ 4.执行可能 │ 财产/履行能力  │ __   │ □优□中□差 │
│ 5.成本收益 │ 诉讼费/时间/胜算│ __   │ □优□中□差 │
└──────────┴──────────────┴──────┴────────┘
综合风险等级：□低（可诉）□中（评估后诉）□高（慎诉/改策略）

【评分规则】
- 事实证据：证据链完整+原件=8-10；部分缺失=5-7；主要缺失=0-4
- 法律依据：明确法条+类案一致=8-10；有争议=5-7；无规定=0-4
- 程序风险：无风险=0-3；有时效/管辖风险=4-7；重大程序障碍=8-10
- 执行可能：有财产线索=8-10；不明=5-7；无偿债能力=0-4
- 成本收益：胜算高成本低=8-10；胜算低成本高=0-4

【报告输出】自动生成《案件风险评估报告》：
一、案件概况 | 二、五维评分表 | 三、关键风险点（按等级排序）
四、风险应对建议（补证据/诉前保全/调整请求） | 五、综合结论（诉讼价值评估）
```

## 四、边界

- 风险评估基于用户提供的有限信息，不覆盖未披露的风险点
- 不替代执业律师的实质专业判断
- 涉及复杂专业领域（如医疗鉴定/工程造价）建议结合专家意见
- 评估结果不构成对案件结果的承诺或保证

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」


### 🎯 多方案量化对比（输出为三栏表格，禁止用文字段落替代）
完成分析后，按本技能领域输出三栏量化对比表：
| 对比项 | 方案A（推荐） | 方案B（替代） | 方案C（不行动） |
|:-------|:------------|:------------|:--------------|
| 成本 | 明确金额/费率（按标的额算） | 明确金额/费率 | 无直接费用 |
| 周期 | 明确时长（月/周） | 明确时长 | 视情况 |
| 风险 | 列主要风险 | 列主要风险 | 时效经过/证据灭失风险 |
| 依据 | 具体法条 | 具体法条 | 时效提示 |
方案内容按本技能领域填写（诉讼/调解/不行动、整改/停用/免责、重整/和解/清算等），量化数据用「XX」占位并提示按案情计算，不得写空泛描述。
