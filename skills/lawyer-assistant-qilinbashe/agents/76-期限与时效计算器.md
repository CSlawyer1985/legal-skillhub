# 期限与时效计算器

> 输入案由+关键日期，输出时效核验表，风险一目了然。

## 一、触发方式

- 用户说「帮我算时效」「看看过期没有」「还有几天」自动激活
- 31-总控路由在案由匹配后提示用户进行时效核验
- 手动触发：说「时效计算」或「期限核验」

## 二、覆盖的时效/期限类型

| 类型 | 常见的相关案由 | 期间 |
|:-----|:--------------|:-----|
| 普通诉讼时效 | 民间借贷/合同/侵权/物权 | 3年（《民法典》第188条） |
| 劳动争议仲裁时效 | 劳动纠纷 | 1年（《劳动争议调解仲裁法》第27条） |

| 上诉期限（民事） | 一审判决 | 15日 |
| 上诉期限（刑事） | 一审判决/裁定 | 10日/5日 |
| 申请执行期限 | 执行程序 | 2年 |
| 保证期间 | 保证合同 | 6个月/约定（《民法典》第692条） |
| 离婚损害赔偿 | 婚姻纠纷 | 无过错方知道/应当知道之日起1年 |
| 工伤认定申请 | 劳动争议 | 事故伤害发生之日起1年 |
| 破产债权申报 | 破产程序 | 法院公告之日起30天-3个月 |

## 三B、刑事羁押与取保时限（2024新增）

```
侦查阶段羁押期限（刑事拘留→逮捕→侦查终结）：
- 刑事拘留：一般14日（流窜/多次/结伙作案最长37日，含检察院审查批捕7日）
- 逮捕后侦查羁押期限：一般2个月 → 案情复杂可延长1个月 → 重大复杂可再延长2个月
- 侦查终结后移送审查起诉

审查起诉阶段：
- 检察院审查起诉：一般1个月，可延长15日（速裁案件10日）
- 退回补充侦查：每次1个月，最多2次（每次退侦重新计算审查期限）

审判阶段：
- 一审：普通程序一般3个月（可延长），简易程序一般20日/1.5个月，速裁程序一般10日
- 二审：一般2个月（可延长）

取保候审：
- 最长不得超过12个月（同一阶段连续计算，跨阶段重新计算）
- 监视居住最长不得超过6个月
- 解除取保候审/监视居住的，应当及时通知被取保候审人、监视居住人

羁押必要性审查：
- 逮捕后，辩护律师可随时向检察院申请羁押必要性审查
- 检察院应当在收到申请后7日内作出是否立案审查的决定
```

## 四、特别提示

- 诉讼时效可因**催讨/起诉/部分履行/书面承认**而中断，中断后重新计算
- 除斥期间（如撤销权1年/继承权60日）**不适用中断/中止**，须严格注意
- 本计算基于通用法律规定，个案具体起算点可能因事实差异而不同
- 涉及重大权益建议结合具体案情由执业律师核定

## 边界

- ✅ **本工具计算**：诉讼时效/仲裁时效/执行时效/刑事羁押期限/取保时限等法定期间
- ❌ **本工具不做**：预测案件结果、计算赔偿金额（见98号）、计算诉讼费（见77号）
- ⚠️ **注意**：期限起算点（知道或应当知道之日/履行期届满之日等）须结合具体案情确认；各地法院对时效中断证据认定有差异
