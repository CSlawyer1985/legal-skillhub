| 优先级 | 待查明事项 | 法律意义 |

|:------:|-----------|---------|

| P0 | 有没有仲裁协议/仲裁条款？ | 仲裁的前提条件（仲裁法第4条） |

**仲裁协议效力审查框架（仲裁法第16-18条）：**



```

┌─ ① 形式要件（仲裁法第16条）

│   ├─ 书面形式（合同条款/信件/数据电文等）

│   ├─ 请求仲裁的意思表示（明确+真实）

│   ├─ 仲裁事项（明确约定哪些争议提交仲裁）

│   └─ 选定的仲裁委员会（明确具体，如"中国国际经济贸易仲裁委员会"）

│

├─ ② 实质要件（仲裁法第17条）

│   ├─ 约定的仲裁事项超出法律规定的仲裁范围 → 无效

│   ├─ 无民事行为能力人或限制民事行为能力人订立的 → 无效

│   └─ 一方采取胁迫手段订立的 → 无效

│

├─ ③ 仲裁协议效力延伸

│   ├─ 合同变更/解除/终止/无效 → 不影响仲裁协议效力（仲裁法第19条）

│   ├─ 法人合并/分立 → 承继权利义务的实体受仲裁协议约束

│   └─ 合同权利义务转让 → 仲裁协议原则上随合同转让

│

└─ ④ 仲裁机构约定不明确的情形

    ├─ 约定"北京仲裁委员会/北京仲裁委/北仲" → 明确 ✅

    ├─ 约定"提交仲裁机构仲裁" → 不明确，效力待定 ❌

    ├─ 约定两个仲裁机构 → 双方可选择一个，不能达成一致则无效

    └─ 约定了仲裁地但未指定仲裁机构 → 效力存疑

```

### 第二步：仲裁申请准备



**仲裁时机判断：**



```

┌─ ① 是否已发生争议？

│   ├─ 争议事实是否已经发生

│   └─ 是否已经催告/协商（非必经，建议保留书面记录）

│

├─ ② 诉讼时效审查

│   ├─ 一般3年（民法典第188条）

│   ├─ 起算点：知道或应当知道权利受损之日

│   └─ 时效中断事由：催收/协商/仲裁

│

├─ ③ 一裁终局告知（必告知，仲裁法第9条）

│   ├─ 仲裁裁决一经作出即生效，当事人不得就同一纠纷再申请仲裁或向法院起诉

│   ├─ 撤销仲裁裁决的法定情形极其有限（仲裁法第58条）

│   └─ 建议当事人充分评估后决定是否申请仲裁

│

└─ ④ 仲裁成本评估

    ├─ 仲裁费 = 案件受理费 + 案件处理费（按争议金额累进计算）

    ├─ 各仲裁委收费标准不同（贸仲/北仲/上仲各有费率表）

    ├─ 律师费（一般由当事人各自承担，仲裁庭可裁决败诉方承担部分）

    └─ 仲裁员报酬（部分仲裁委另计）

```



**仲裁申请书准备工作：**



```

┌─ 申请人与被申请人基本信息（名称+住所+联系方式）

├─ 仲裁依据（仲裁协议/仲裁条款原文+合同编号）

├─ 仲裁请求（具体+明确+可执行）

│   ├─ 金钱请求：本金+利息/违约金+仲裁费承担

│   ├─ 非金钱请求：继续履行/解除合同/赔偿损失等

│   └─ 仲裁请求金额确定（决定仲裁费）

├─ 事实与理由（按合同约定+履行情况+违约事实+法律依据）

└─ 证据清单（按证明对象分组）

```

### 第三步：仲裁机构与仲裁庭组成



**仲裁机构确定：**



```

┌─ ① 根据仲裁协议确定仲裁机构

│   ├─ 贸仲（CIETAC）：中国国际经济贸易仲裁委员会 → 涉外/涉跨境/重大商事

│   ├─ 北仲（BAC）：北京仲裁委员会 → 一般商事

│   ├─ 上仲（SHAC）：上海仲裁委员会 → 一般商事

│   ├─ 广仲（GZAC）：广州仲裁委员会 → 一般商事

│   └─ 各地仲裁委 → 根据合同约定确定

│

├─ ② 仲裁规则选择

│   ├─ 适用该仲裁机构现行仲裁规则

│   └─ 当事人可约定修改（不违反仲裁法强制性规定）

│

└─ ③ 仲裁地确定

    ├─ 一般在仲裁机构所在地

    └─ 当事人可另行约定

```



**仲裁庭组成（仲裁法第30-33条）：**



```

┌─ ① 仲裁员人数

│   ├─ 合议仲裁庭（3名）：无特别约定时适用

│   └─ 独任仲裁庭（1名）：争议金额小+双方同意/仲裁规则规定

│

├─ ② 仲裁员选定（仲裁法第31条）

│   ├─ 双方当事人各选1名仲裁员（或委托仲裁委主任指定）

│   ├─ 第3名首席仲裁员：双方共同选定/仲裁委主任指定

│   └─ 独任仲裁员：双方共同选定/仲裁委主任指定

│

├─ ③ 仲裁员回避情形（仲裁法第34条）

│   ├─ 是本案当事人或当事人/代理人的近亲属

│   ├─ 与本案有利害关系

│   ├─ 与本案当事人/代理人有其他关系（可能影响公正）

│   └─ 私自会见当事人/代理人+接受请客送礼

│

└─ ④ 仲裁员选定策略

    ├─ 选择专业领域背景匹配的仲裁员（建设工程/金融/贸易等）

    ├─ 选择对本方有利的仲裁程序倾向

    └─ 避免选择对方可能熟悉/有利的仲裁员

```

### 第四步：仲裁程序推进



**仲裁程序时间线（以各仲裁委规则为准，以下为一般流程）：**



```

┌─ ① 申请受理

│   ├─ 提交仲裁申请书+证据材料+预缴仲裁费

│   ├─ 仲裁委5日内决定是否受理

│   └─ 受理后秘书向双方发送仲裁通知+仲裁规则+仲裁员名册

│

├─ ② 答辩与反请求

│   ├─ 被申请人15-30日内提交答辩书（以各仲裁委规则为准）

│   ├─ 被申请人可在答辩期内提出反请求

│   └─ 管辖权异议应在首次答辩前提出（仲裁法第20条）

│

├─ ③ 仲裁庭组成

│   ├─ 双方在指定期限内选定仲裁员
```

- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
