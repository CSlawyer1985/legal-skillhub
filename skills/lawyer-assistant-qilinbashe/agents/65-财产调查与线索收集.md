### 第二步：调查策略制定



**调查策略选择（按法律效力由低到高、成本由低到高排列）：**



```

第1层：被执行人自行报告（最低成本）

  1.1 申请法院发出《被执行人财产报告令》

  1.2 法条依据：最高法财产调查规定第5-10条

  1.3 法律后果：拒不报告/虚假报告→罚款、拘留、纳入失信名单



第2层：网络查控（效率最高）

  2.1 申请法院通过"总对总"网络查控系统

     - 人行征信系统（银行存款、贷款记录）

     - 不动产登记系统（房产、土地）

     - 车辆管理所（机动车）

     - 市场监管总局（股权、投资）

     - 支付宝/微信支付（电子账户余额、交易记录）

     - 证券登记结算公司（股票、基金）

     - 保险行业协会（保单信息）

     - 公积金管理中心（住房公积金）

  2.2 法条依据：最高法财产调查规定第1-4条

  2.3 效果：一次性覆盖90%以上常见财产类型



第3层：传统调查（针对性强）

  3.1 律师自行调查

     - 工商查档（查阅公司章程、股东出资、变更记录）

     - 不动产登记中心（查询房产交易记录）

     - 实地走访（经营场所、住宅地址）

  3.2 律师调查令（申请法院出具）

     - 适用对象：银行、行政机关、第三方机构

     - 适用条件：有初步线索但无法自行获取

     - 法条依据：律师法第35条、最高法财产调查规定第20条



第4层：专业调查（成本较高）

  4.1 悬赏公告（>财产线索有重大价值时适用）

     - 悬赏金比例：一般不超过执行到位金额的10%

     - 法条依据：最高法财产调查规定第21-24条

  4.2 审计调查（>怀疑被执行人通过关联公司转移财产时适用）

     - 法条依据：最高法财产调查规定第17-19条



第5层：延伸调查（深挖关联方）

  5.1 XX配偶财产调查（涉及夫妻共同债务认定）

  5.2 关联企业财产流向调查（涉及公司人格否认）

  5.3 出资瑕疵股东追加调查（涉及追加被执行人）

  5.4 第三人到期债权调查（涉及代位执行）

```



**调查策略建议规则：**

```

┌─ 目标明确且财产类型清晰 → 网络查控为主要求法院发函

├─ 目标模糊或下落不明 → 传统调查先行（工商+实地）

├─ 有具体线索但无法自行获取 → 申请调查令

├─ 涉及大额财产且线索不明 → 悬赏公告补充

├─ 怀疑财产转移至关联方 → 延伸调查+审计调查

└─ 周期长且执行法官配合度高 → 同步推进多项措施

```

### 第四步：法律分析——财产线索评估



**分析框架：**



```

┌─ ① 可执行性分析

│   ├─ 评估拍卖的预期成本

│   ├─ 预计执行到位金额

│   └─ 执行成本与价值的比例分析



├─ ③ 延伸调查必要性分析

│   ├─ 是否需追加配偶为被执行人

│   ├─ 是否需审查关联企业财产

│   ├─ 是否需追加出资瑕疵股东

│   ├─ 是否有拒执罪线索

│   └─ 法条依据：最高法变更追加执行当事人规定



├─ ④ 确定性评级

│   ├─ 确定：财产线索明确+权属清晰+无权利负担
```

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
