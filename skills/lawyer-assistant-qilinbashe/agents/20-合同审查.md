### 第三步B：风险条款自动标记引擎（产出物①）

**对合同逐条扫描，命中以下规则即自动标记风险等级：**

| 风险规则 | 判定标准 | 标记 |
|:---------|:---------|:----:|
| **格式条款无效风险** | 提供方未提示说明免除/减轻自身责任条款（民法典496条）；或格式条款排除对方主要权利（497条） | 🔴 |
| **违约金过高风险** | 约定违约金超过实际损失30%（民法典585条+合同编通则解释65条）；或日万分之五以上 | 🔴 |
| **管辖条款效力风险** | 约定“原告所在地/被告所在地/守约方所在地”法院（民诉法解释30条无效）；或既约定仲裁又约定诉讼 | 🔴 |
| **定金条款冲突** | 定金+违约金并用（民法典588条二选一）；定金超主合同标的20%（586条） | 🔴 |
| **免责条款无效** | 免除人身损害责任/因故意重大过失造成财产损失的免责（民法典506条） | 🔴 |
| **送达条款缺失** | 无送达地址确认条款（涉诉后公告送达周期长） | 🟡 |
| **付款与交付脱节** | 全额预付无节点验收、或货到全款无质保金 | 🟡 |
| **知识产权归属不清** | 委托开发/定制成果归属无约定（民法典860条补充规则风险） | 🟡 |
| **保密条款缺失** | 涉商业秘密/技术资料但无保密条款 | 🟡 |
| **不可抗力定义过窄** | 未涵盖政府行为/政策变化/疫情等（建议扩展） | 🟢 |

| 商业条款层 | 违约责任 | ①违约金比例是否过高（>损失30%可被调减，民法典585）②赔偿范围是否含间接损失 ③免责条款效力（造成对方人身损害/因故意过失造成财产损失无效，506）④定金/违约金能否并用（588）|

| 商业条款层 | 保密/知识产权 | ①保密范围/期限/违约金额 ②IP归属（委托开发默认归受托方，应约定归委托方，859/860）③背景知识产权许可 ④竞业限制合理范围（期限≤2年）|
| 合规条款层 | 格式条款 | ①是否尽提示说明义务（496，未尽则不利条款不成为合同内容）②免责/限责条款是否无效（497/506）|
| 合规条款层 | 争议解决 | ①管辖法院约定是否有效（协议管辖须与争议有实际联系，35）②约定仲裁须明确仲裁机构（否则无效，仲裁法18）③涉外准据法 |
| 效力层 | 生效/终止 | ①生效条件（签字盖章/附条件）②终止情形 ③清理结算（保密/争议/应付款继续有效）|

### 二、风险量化评级标准

每条审查发现按以下规则评级，写入审查意见：

| 等级 | 判定规则 | 处理动作 |
|:----:|:---------|:---------|
| 🔴 高 | 导致合同无效/部分无效、显失公平、重大权益敞口、管辖/时效致命缺陷 | 必须修改，否则建议暂停签署 |
| 🟡 中 | 重大不利但可补救（违约金过高、IP归属不清、解除权缺失） | 建议修改，列明谈判要点 |
| 🟢 低 | 表述优化、细节完善、风格统一 | 可选优化 |

### 三、缺失条款检测清单（民法典第470条）

审查时逐项勾选，缺失即提示补充：
- [ ] 当事人信息（名称/住所/法定代表人）
- [ ] 标的（名称/数量/质量）
- [ ] 价款或者报酬
- [ ] 履行期限、地点和方式
- [ ] 违约责任
- [ ] 解决争议的方法
- [ ] （视情形）保密、知识产权、不可抗力、终止清算

### 四、逐条修改建议（redline 模板，可直接粘贴）

**模板1｜违约金过高**
- 原条款：「违约方应支付合同总额 30% 的违约金，且赔偿一切损失。」
- 风险：30% 可能被认定过高；「一切损失」含间接损失，易引发争议（民法典585）。
- 建议改为：「违约方应支付合同总额【X】% 的违约金；违约金不足以弥补实际损失的，就不足部分赔偿直接损失（不含间接损失、预期利益）。」
- 依据：民法典第585条（违约金调整）、第584条（可预见规则）。

**模板2｜格式条款未提示**
- 原条款：小字「本公司对货物瑕疵不承担责任。」
- 风险：未尽提示说明义务，该免责条款不成为合同内容（496/497）。
- 建议改为：以加粗/下划线显著标识，并单独要求对方签字确认「已阅读并理解免责条款」。
- 依据：民法典第496、497条。

**模板3｜IP归属不清（委托开发）**
- 原条款：「开发成果归开发方所有。」
- 风险：委托方付费却无知识产权，二次使用需再付费。
- 建议改为：「本项目开发成果（含源代码/设计稿）知识产权归委托方所有；开发方保留为履行本合同必需的有限使用权。」
- 依据：民法典第859、860条。

（更多模板按合同类型在审查时由 AI 生成，所有法条均须过 96 核验。）

### 五、法条与判例锚定（输出前必过 96）

- 每条审查意见引用的法条，必须过 （华宇元典+北大法宝双源交叉，否则不得进入交付物）。
- 参考案例须来自华宇元典/北大法宝经核验，禁止 LLM 自由生成。
- 常用锚定：民法典 463-594（合同编通则）、143-160（效力）、496-498（格式条款）、563（法定解除）、585（违约金）、588（定金）、859-860（技术合同）；法释〔2023〕13号（合同编通则解释）。

### 六、结构化交付物（审查意见书标准模块）

输出审查意见时，按此模块成稿（原则上用表格，便于律师直接采用）：
1. 合同概览（类型/主体/金额/期限）
2. 条款风险评级表（条款类型｜位置｜风险点｜等级｜修改建议｜法条依据）
3. 缺失条款清单
4. 整体风险结论（高/中/低 + 核心整改项）
5. 谈判要点（按等级排序）
