## 📝 核心文书模板说明



### 1. 刑事辩护委托书



**签署主体：**

- 犯罪嫌疑人/被告人本人签署（在押的，可通过近亲属委托）

- 犯罪嫌疑人/被告人的监护人/近亲属代为委托（须提供关系证明）



**内容要点：**

- 委托人信息+被委托人信息（执业证号+律所）

- 委托阶段（侦查/审查起诉/一审/二审/重罪复核）

- 委托权限（一般代理/特别授权）

- 签署日期+签名+律所公章



### 2. 刑事辩护风险告知书



**应当告知的风险：**



| 风险项 | 说明 |

|:------:|------|

| ① 结果风险 | 律师辩护不保证结果，不能承诺“一定取保”“一定无罪” |

| ② 会见风险 | 敏感/涉恐案件会见须经侦查机关许可 |

| ③ 证据风险 | 律师不能伪造/毁灭/隐匿证据，不能帮助串供 |

| ④ 费用风险 | 委托费用不与案件结果挂钩，分段收费 |

| ⑤ 保密义务 | 律师对工作中知悉的保密信息/商业秘密/个人隐私有保密义务 |

| ⑥ 冲突风险 | 同案多名被告人的辩护策略可能存在冲突 |



### 3. 会见权告知书



**告知内容：**

- 根据刑诉法第39条，辩护律师凭“三证”（律师执业证+律所证明+委托书）即可要求会见

- 侦查阶段会见不被监听（刑诉法第39条第4款）

- 敏感/涉恐案件会见须经侦查机关许可（刑诉法第39条第3款）

- 会见时为犯罪嫌疑人提供法律咨询、代理申诉控告

## 🚦 委托流程



```

第一步：确认委托主体

  ├─ 犯罪嫌疑人/被告人本人 → 直接签署委托书

  ├─ 近亲属代为委托 → 提供亲属关系证明（户口本/结婚证/出生证明等）

  └─ 法律援助指派 → 法律援助公函



第二步：签署委托文件

  ├─ 刑事辩护委托书（一式两份）

  ├─ 刑事辩护风险告知书（委托人签字确认已阅读）

  └─ 授权委托书（明确授权范围）



第三步：身份核验

  ├─ 核验委托人身份证明

  ├─ 核验近亲属关系证明（如为近亲属委托）

  └─ 留存证件复印件



第四步：办理会见手续

  ├─ 准备"三证"（律师执业证+律所证明+委托书）

  ├─ 前往看守所/办案机关办理会见

  └─ 告知委托人会见结果



第五步：进入刑事辩护流程

  └─ 根据案件阶段路由到对应刑事辩护技能

```



> ⚠️ **复核提醒**：委托手续涉及律师职业道德和执业纪律，必须严格依法依规办理。

> 

> ⚠️ **禁止承诺结果：** 严格禁止向当事人/家属承诺“保证取保”“保证无罪”“保证缓刑”等结果性承诺，违者将面临司法行政机关的纪律处分。

## 📋 案情分析



在办理委托手续前，应对案件基本情况进行梳理分析，以评估委托的必要性和可行性：



### 案情梳理要点



| 分析维度 | 核实内容 | 法律意义 |

|---------|---------|---------|

| **当事人基本信息** | 身份、职业、有无前科、是否在押 | 影响强制措施判断和辩护策略 |

| **案件基本事实** | 涉嫌罪名、涉案金额、时间地点、行为方式 | 确定案件性质和适用法律 |

| **强制措施情况** | 是否被拘留/逮捕、羁押地点、已羁押时长 | 判断是否存在变更强制措施的空间 |

| **证据情况** | 是否已经讯问、有无口供、有无关键物证书证 | 评估辩护空间和方向 |

| **程序进度** | 案件所处的诉讼阶段（侦查/审查起诉/一审/二审） | 路由到对应阶段技能 |

| **委托人诉求** | 当事人/家属的期望目标（取保/无罪/罪轻/缓刑） | 管理预期，设定合理目标 |



### 利益冲突审查（委托前必做）



| 审查项目 | 审查标准 | 处理方法 |

|---------|---------|---------|

| 是否代理过对方当事人 | 同一律所不得代理同一案件双方 | 若存在，拒绝委托 |

| 是否代理同案其他被告人 | 同一律所同时代理同案多名被告，除非全案认罪认罚且无实质冲突 | 若存在冲突且不能豁免，拒绝委托 |

| 是否存在个人利益冲突 | 律师不得代理与本人/近亲属有利益冲突的案件 | 经当事人书面豁免后方可接受 |



> ⚠️ 利益冲突审查应在正式签约前完成，避免因冲突问题导致委托关系失效或纪律处分。

| 规范名称 | 关键内容 |

|---------|---------|

| 《律师执业行为规范》（中华全国律师协会） | 第50条（同一律所不得代理同一案件双方）、第51条（同一律所不得代理刑案同案多名被告人，除非全案认罪认罚且无实质冲突）、第80条（律师不得代理与本人/近亲属有利益冲突的案件） |

### 利益冲突审查清单

| 冲突类型 | 禁止情形 | 依据 | 例外 |

|---------|---------|------|------|

| 绝对禁止 | 同一律师/律所代理同一案件双方当事人 | 律师执业行为规范第50条 | 无 |

| 绝对禁止 | 同一律所同时代理同案多名被告人辩护 | 律师执业行为规范第51条 | 全案认罪认罚且无实质冲突 |

| 相对禁止 | 律师代理与本人有利益冲突的案件 | 律师执业行为规范第80条 | 经当事人书面豁免 |

| 相对禁止 | 律师在代理期间又代理对方当事人的其他案件 | 律师执业行为规范第50条 | 经两方当事人书面同意 |
