### 第三步：证据审查（审查起诉阶段）



**审查框架：**



```

┌─ ① 控方证据全面审查（审查起诉阶段——全卷审查）

│   ├─ 言词证据：全部讯问笔录/询问笔录/被害人陈述

│   │   ├─ 证据能力：同步录音录像是否完整？讯问程序是否合法？

│   │   ├─ 证明力：多份口供是否矛盾？与客观证据是否印证？

│   │   └─ 非法证据排除：刑讯逼供/威胁/引诱/欺骗所得口供

│   │

│   ├─ 实物证据：物证/书证/鉴定意见/勘验/检查/辨认笔录

│   │   ├─ 证据能力：提取/扣押/保管/送检程序是否合法？

│   │   └─ 证明力：鉴定意见的依据是否充分？辨认程序是否合规？

│   │

│   └─ 电子数据/技术侦查证据

│       ├─ 证据能力：提取过程是否合法？技术侦查是否经过审批？

│       └─ 证明力：内容真实性+完整性+关联性

│

├─ ② 辩方证据审查

│   ├─ 无罪证据：不在场证明/无作案时间/系他人所为

│   ├─ 罪轻证据：自首/立功/退赃/谅解/被害人过错

│   └─ 程序违法证据：超期羁押/违法取证/违规侦查

│

└─ ③ 起诉必要性审查（审查起诉阶段核心）

    ├─ 法定不起诉：没有犯罪事实/情节显著轻微（刑诉法第177条）

    ├─ 酌定不起诉：犯罪情节轻微，不需要判处刑罚（刑诉法第177条）

    ├─ 证据不足不起诉：经两次补侦仍证据不足（刑诉法第175条）

    └─ 附条件不起诉：未成年人案件（刑诉法第282条）

│

└─ ④ 证明标准审查（刑诉法第55条）

    ├─ 定罪量刑的事实是否都有证据证明？

    ├─ 据以定案的证据是否均经法定程序查证属实？

    ├─ 综合全案证据，对所认定事实是否已排除合理怀疑？

    └─ 任一答案为"否" → 建议不起诉/退回补充侦查

```



**举证责任：控方举证，辩方不承担自证无罪义务（刑诉法第51条）。**

**阶段重点审查：** 全卷阅卷+不起诉条件+认罪认罚自愿性。

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
