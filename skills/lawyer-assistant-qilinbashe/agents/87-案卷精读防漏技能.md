# 案卷精读·要件事实证据矩阵（强制必做）

## 强制触发条件
满足以下任一即触发，且**必须先跑本技能再写任何文书**：
- 用户提交了案件材料文件（PDF 证据册、庭审笔录、卷宗扫描件、图片版书证、Word/Excel 卷宗等）；
- 用户的表述中出现以下任一关键词（当事人常不懂法，需用其口语化叫法兜底）：
  **证据、笔录、庭审笔录、二次笔录、庭审、质证、案卷、卷宗、材料、资料、书面证言、书证、案情、事实、起诉状、答辩状、代理意见、要件、请求权基础**；
- 用户一次性提交多份明显属于同一案件的文档/图片（即便未明说“这是证据”，亦视为案卷，触发）。

> 关键提醒：当事人常把“证据”叫成“材料”“资料”“我发你的那些东西”“几张纸”。只要语境是看案子、写文书，且涉及上述文件或词语，**一律触发**，不得因叫法不专业而跳过。

## 🔒 脱敏强制规则（隐私底线，不可违反）
凡真实在审、未结案、含可识别自然人信息的案件，本技能**默认脱敏**，且贯穿全部环节：
1. **脱敏对象**：自然人姓名、身份证号、住址、电话、车牌、具体案号、银行账号、人脸/签名图像。
2. **脱敏方式**：姓名 → 关系标签或化名，如「产权人（甲）」「被告（乙）」「原告（丙）」「证人（丁）」「张某/李某」；保留“父子/兄弟/夫妻”等法律关系结构，不丢案件事实骨架。
3. **技能公开内容一律脱敏**：本 SKILL.md 的示例、配套脚本的示范输出、对外交付物模板，**禁止出现任何真实案子的当事人真名**。
4. **豁免（谨慎）**：仅当用户明确声明“这是我本人代理、诉讼需用真名”并经确认后，其专属交付物可保留真名；技能本身的文档/模板仍保持脱敏。

## ⚠️ 强制流程（不可跳过、不可后置）
本案工作流的第一条动作必须是「建矩阵」，最后一条动作必须是「核对矩阵」。中间才是写文书。

### 第一步：产出三件套（接案即做，必须有交付物）
收到案卷后，先跑  抽取文本与信号骨架（脱敏），再由 AI 在骨架上填出三件套，**以 Markdown 表格 / docx / HTML 形式交付（present_files 给用户，不可只停留在思考）**：

**（甲）证据与庭审笔录清单**（表格）
列：编号 | 证据名称 | 来源（原告/被告/法院） | 关键页 | 证明目的 | 三性意见 | 本方态度（认可/异议/部分认可）
- 每份证据独立成行；庭审笔录按次分列（一次庭、二次庭）。证人书面证言、村委会证明单独列并标注与当事人利害关系。

**（乙）要件事实—证据矩阵（核心，防漏细节的王炸）**（表格）
- 纵轴：以请求权基础规范拆解的**要件及待证事实**（用要件审判九步法第四步 / 王泽鉴请求权基础检索的要件）。
- 横轴每格填：证据原文摘录（尽量原文，不得掺主张）| 出处页码/行号 | 主张方（原告/被告/证人） | 对方意见 | **认定状态：已查明 / 有争议 / 待核实**。
- 凡标 / 的，文书中**不得写成确定事实**。

**（丙）矛盾与风险标记**（表格或清单）
强制标出：双方陈述冲突、真实性有争议、证人/当事人陈述 ≠ 原始书证记载、金额/时间/主体前后不一。

### 第二步：写作闸门（写任何文书前）
- 所有写进文书的事实，必须能在矩阵（乙）找到出处+认定状态。
- 标 / 的事实，文书须注明“原告主张…被告异议…”，**严禁写成铁定事实**。
- 严禁把「当事人主张/抗辩」直接当「查明事实」落笔。
- 严禁用证人随口陈述替代原始书证（房产证、契约、判决书）的记载。
- 严禁把案卷中归属一方的款项/事实写成另一方承担（归责搞反）。

### 第三步：交付核对（文书定稿前）
- 逐条比对文书事实 vs 矩阵，零遗漏、零“主张当事实”、零“证人当权证”、零“归责搞反”。
- 输出矩阵表（Markdown/Excel/HTML）一并交付。

## 常见错误类型（已踩坑，必须规避）
1. **抽样阅读**：OCR 乱文只挑读，未逐条建“争议事实→出处”索引 → 漏细节。
2. **主张当事实**：把被告答辩“无签字捺印”直接当事实写，未回原始书证核实（真实为：原告主张产权人捺印、被告对手印真实性有异议）。
3. **证人当权证**：证人随口说“三人共有”错当房产证登记记载（真实为：权证存根只写产权人（甲）一人）。
4. **归责搞反**：把案卷中归属被告的款项写成原告承担。
5. **无写作闸门**：写完才核对，而非写前从权威清单取料。
6. **未脱敏**：真实在审案子把当事人真名直接写入技能/交付物，泄露隐私。

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
