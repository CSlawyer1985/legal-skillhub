## ⏱ 劳动争议仲裁流程时间轴



```

发生争议（如被辞退/欠薪）

    ↓ ← 1年内申请仲裁（劳动争议调解仲裁法第27条）

申请劳动仲裁

    ↓ ← 45日内作出裁决（劳动争议调解仲裁法第43条）

仲裁裁决

    ├─ 对裁决不服 → 收到裁决15日内向法院起诉

    └─ 裁决生效 → 申请法院强制执行

```

### 第三步：证据审查



**审查框架：**



```

┌─ ① 劳动关系证据

│   ├─ 劳动合同（最优先）

│   ├─ 工资单/银行流水/社保记录

│   ├─ 工牌/考勤记录/工作群聊天记录

│   └─ 无合同时：可凭事实劳动关系证据主张

│

├─ ② 争议事实证据

│   ├─ 欠薪：工资单+考勤+催讨记录

│   ├─ 违法解除：解除通知/辞退证明/工作交接单

│   ├─ 加班：考勤记录+加班审批+加班费支付记录

│   └─ 工伤：工伤认定书+医疗记录+劳动能力鉴定

│

├─ ③ 举证责任分配

│   ├─ 劳动者举证：劳动关系存在+仲裁时效未过

│   ├─ 用人单位举证：已足额支付工资+解除合法+加班已调休/已支付

│   └─ 举证不力的后果：用人单位承担不利后果（劳动争议调解仲裁法第6条）

│

└─ ④ 证据风险提示

    ├─ 举证期限：仲裁阶段一般不超过15日

    ├─ 证据形式：电子证据需确认原始载体+完整性

    └─ 仲裁时效证据：最后一次主张权利的记录

```

### 第四步：法律分析



**分析框架：**



```

┌─ ① 仲裁时效审查

│   ├─ 知道或应当知道权利受损日

│   ├─ 最后一次主张权利日（时效中断）

│   ├─ 在职期间欠薪不受1年限制

│   └─ 结论：时效已过/未过

│

├─ ② 仲裁程序审查

│   ├─ 管辖审查：劳动合同履行地或用人单位所在地

│   ├─ 一裁终局可能性评估（小额争议+标准明确的争议）

│   └─ 仲裁裁决不服的救济路径：15日内向法院起诉

│

├─ ③ 争议焦点分析

│   ├─ 争议焦点一：仲裁请求是否成立

│   │   ├─ 法律依据

│   │   ├─ 本案事实

│   │   └─ 结论

│   └─ 争议焦点二：...

│

├─ ④ 赔偿计算

│   ├─ 经济补偿金（N）：按在职年限计算

│   ├─ 赔偿金（2N）：违法解除×2

│   ├─ 代通知金（N+1）：未提前30日通知

│   ├─ 加班费计算

│   └─ 其他：未休年假工资/社保损失/工伤赔偿

│

└─ ⑤ 风险提示

    ├─ 仲裁请求能否得到支持

    ├─ 一裁终局的可能性（标的较小）

    └─ 执行风险（公司经营状况）

```

- 证人证言——建议尽早固定



**财产保全建议：**

- 如发现对方有转移财产迹象，可在起诉时一并申请财产保全

- 保全措施包括：查封、扣押、冻结
