## ⏱ 刑事案件流程时间轴



```

【侦查阶段】

被采取强制措施（拘留/逮捕）

    ↓ ← 拘留最长37天

提请批准逮捕/取保候审

    ↓ ← 侦查羁押最长7个月

侦查终结→移送审查起诉

    ↓

【审查起诉阶段】

检察院审查起诉

    ↓ ← 审查起诉最长6.5个月

提起公诉/不起诉

    ↓

【一审阶段】

法院受理 → 庭前会议 → 开庭审理 → 判决

    ↓ ← 一审最长6个月

一审判决

    ├─ 不服 → 收到判决15日内上诉

    └─ 生效 → 交付执行

```

### 第三步：证据审查（一审阶段）



**审查框架：**



```

┌─ ① 控方证据审查（一审阶段——庭审质证准备）

│   ├─ 言词证据：口供/证人证言/被害人陈述

│   │   ├─ 证据能力：有无刑讯逼供/诱供？同步录音录像是否完整？

│   │   ├─ 证明力：庭审中是否翻供？与庭前笔录是否一致？

│   │   └─ 非法证据排除：申请排非（刑诉法第56条）

│   │

│   ├─ 实物证据：物证/书证/鉴定意见/勘验/检查/辨认笔录

│   │   ├─ 证据能力：提取程序是否合法？保管链条是否完整？

│   │   └─ 证明力：鉴定意见能否当庭质证？辨认程序是否合规？

│   │

│   ├─ 电子数据/技术侦查证据

│   │   ├─ 证据能力：提取过程是否合法？有无见证人？

│   │   └─ 证明力：电子数据完整性校验+技术侦查审批手续

│   │

│   └─ 量刑证据审查

│       ├─ 前科/累犯证据：判决书是否真实？

│       └─ 量刑情节：自首/立功/退赃退赔/谅解的证明材料

│

├─ ② 辩方证据审查

│   ├─ 无罪证据：不在场证明/无作案时间/系他人所为

│   ├─ 罪轻证据：自首/立功/退赃/谅解/被害人过错

│   └─ 程序违法证据：管辖权异议/超期羁押/违规取证

│

└─ ③ 庭审质证策略（一审阶段核心）

    ├─ 申请非法证据排除（庭前会议提出）

    ├─ 申请证人/鉴定人/侦查人员出庭

    ├─ 申请调取新证据/重新鉴定

    └─ 庭审质证提纲（每份证据的质证要点）

│

└─ ④ 证明标准审查（刑诉法第55条）

    ├─ 定罪量刑的事实是否都有证据证明？

    ├─ 据以定案的证据是否均经法定程序查证属实？

    ├─ 综合全案证据，对所认定事实是否已排除合理怀疑？

    └─ 任一答案为"否" → 提出证据不足的无罪辩护

```



**举证责任：控方举证，辩方不承担自证无罪义务（刑诉法第51条）。**

**阶段重点审查：** 庭审质证准备+非法证据排除+证人出庭申请。
