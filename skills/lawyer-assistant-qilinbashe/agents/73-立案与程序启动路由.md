# 立案与程序启动路由（程序阶段 · 跨案由）



把“递交法院 / 仲裁委 / 行政机关”这一步从散落的各案由技能里抽出来，统一成一条主线。本技能不重复各案由的实体分析，只负责**程序启动的通用骨架 + 路由到对应专业技能**，并补齐此前缺失的“民事立案通用框架”。



## 一、触发条件

- 律师进入“递交 / 立案 / 申请 / 启动程序”阶段；

- 或被点选目录节点“⑨ 立案与程序启动”；

- 或用户问“去哪立案 / 归哪个法院管 / 过没过时效 / 走诉讼还是仲裁”。



## 二、程序选型决策树

1. 双方有无**有效仲裁协议**？有 → 商事仲裁（22），一裁终局无上诉。

2. 争议是否**行政争议**（处罚 / 不作为 / 确权）？是 → 先判断复议前置与否 → 行政复议（61）或行政诉讼立案（63）。

3. 债务人是否**企业法人且资不抵债**？是 → 破产申请（53）。

4. 是否属于**刑事**？侦查 / 起诉阶段由刑事各阶段技能处理；本节点只覆盖“报案 / 刑事自诉立案”的程序性提醒，实体交 09 / 27 等。

5. 是否属于**特殊程序**（违法所得没收 / 强制医疗 / 申诉再审）？是 → 特殊程序（44）。

6. 其余民事权益争议 → **民事诉讼立案**（见下方通用框架）。

7. 判决 / 裁决已生效且对方不履行 → **执行启动**（36），不重新立案。



## 三、民事立案通用框架（原缺失环节，此处补齐）

> 各案由实体分析由对应专业版（如 41 民间借贷、05 交通、03 买卖…）完成，本框架只给“立案递交”的通用骨架。



**通用材料清单**

- 起诉状（原告被告信息 / 诉讼请求 / 事实理由 / 证据清单）—— 模板见 

- 主体资格证明：自然人身份证复印件 / 法人营业执照 + 法定代表人证明

- 授权手续：授权委托书 + 律所函 + 律师证（委托代理时）

- 证据复印件（立案时一般交复印件，开庭核原件）

- 管辖依据：合同履行地 / 被告住所地证明（被告外地时附其住所地信息）



**管辖速判**

- 一般：被告住所地或经常居住地法院；

- 合同：被告住所地 / 合同履行地；

- 侵权：侵权行为地或被告住所地；

- 不动产：不动产所在地专属管辖；

- 约定管辖：有效协议管辖优先（不得违反级别 / 专属管辖）。



**时效速核**（引用法条处内联“已实时核验 / 离线待核”）

- 普通诉讼时效 3 年；

- 劳动仲裁 1 年（仲裁前置）；

- 行政起诉期限 6 个月；

- 涉时效中断 / 中止的，提示律师固定中断证据（催款函 / 报案记录）。

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来

- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
