### 第二步：强制措施组合策略制定



**措施策略选择（按实施顺序和效力递进）：**



```

第1层：财产控制措施（最快、最基础）

  1.1 冻结扣划

     - 适用对象：银行存款、到期收入、第三方支付账户余额

     - 操作方式：法院通过网络查控系统在线冻结/扣划

     - 法律效果：立即控制资金，阻止转移

     - 法条依据：民诉法（2021年修正）第242条



  1.2 查封扣押

     - 适用对象：不动产（房产、土地）、动产（车辆、设备、存货）

     - 操作方式：法院现场查封、张贴封条+查封裁定

     - 法律效果：禁止处分，如需拍卖须进入处置程序

     - 法条依据：民诉法（2021年修正）第244条



第2层：财产处置措施（变现核心）

  2.1 网络司法拍卖（优先适用）

     - 流程：评估→确定保留价→首次拍卖→流拍→降价再拍→变卖→以物抵债

     - 保留价：不低于评估价的70%（最高法拍卖变卖规定第8条）

     - 降价幅度：每次不超过前次保留价的20%（第26条）

     - 法条依据：最高法拍卖变卖规定



  2.2 以物抵债（流拍后的主要出路）

     - 适用条件：拍卖流拍后，申请人同意接受财产抵债

     - 抵债价格：最后一次拍卖的保留价

     - 法条依据：最高法拍卖变卖规定第24条



第3层：信用惩戒措施（施加压力）

  3.1 限制高消费

     - 适用条件：未按执行通知书履行+财产不足或暂无财产

     - 限制内容：飞机+高铁+高级酒店+高消费+子女就读高收费私立学校

     - 解除条件：履行完毕或提供有效担保

     - 法条依据：最高法限高规定



  3.2 纳入失信被执行人名单

     - 适用条件：有履行能力拒不履行/以各种方式规避执行/违反财产报告制度/违反限高令

     - 期限：一般2年，情节严重可延长1-3年（失信规定第2条）

     - 后果：金融信贷限制+招标投标限制+出入境限制+任职资格限制

     - 法条依据：最高法失信名单规定



第4层：人身强制措施（最后手段）

  4.1 罚款/拘留

     - 适用条件：拒不履行+妨碍执行+拒不报告财产等

     - 罚款金额：个人10万以下，单位5万-100万（民诉法（2021年修正）第115条）

     - 拘留期限：15日以下（民诉法（2021年修正）第115条）

     - 法条依据：民诉法（2021年修正）第111条、第115条



  4.2 移送拒执罪

     - 适用条件：有能力履行而拒不履行+情节严重（如转移财产、隐匿财产、虚假诉讼）

     - 移送主体：法院移送公安机关，或申请执行人提起自诉

     - 刑期：3年以下/3-7年

     - 法条依据：刑法第313条

```



**措施策略组合建议规则：**

```

┌─ 有银行存款 → 优先冻结/扣划（最快变现）

├─ 有房产/车辆 → 查封→评估→拍卖（需时2-3个月）

├─ 有藏匿转移迹象 → 查封冻结优先+同步限高失信

├─ 暂无财产但有能力 → 限高+失信+罚款/拘留三板斧

├─ 明确转移财产证据 → 移送拒执罪+刑事压力促履行

└─ 被执行人为企业 → 查封资产+限高法定代表人+失信

```



**特殊处置规则适用提示：**

```

唯一住房的执行（最高法拍卖变卖规定第6条）：

  ① 申请执行人同意为被执行人提供租房租金（一般6-8年×当地租金标准）

  ② 或从拍卖款中预留租金

  ③ 租金标准：参照当地同类房屋租金水平



流拍处理规则（最高法拍卖变卖规定第24-28条）：

  ① 一拍流拍→60日内降价再拍（降价不超20%）

  ② 二拍流拍→60日内变卖

  ③ 变卖流拍→以物抵债或解除查封

```

### 第四步：法律分析——措施合法性审查与效果评估



**分析框架：**



```

┌─ ① 措施合法性审查

│   ├─ 每项措施是否满足法定条件

│   ├─ 程序是否正当（是否已送达执行通知书、是否给予合理期限）

│   ├─ 是否存在豁免执行的情形（生活必需品、唯一住房等）

│   ├─ 是否有超标的查封风险（查封财产价值是否明显超过债权额）

│   ├─ 法条依据：民诉法（2021年修正）第244条第2款（查封不得超标的）



├─ ② 措施效果评估

│   ├─ 已控财产是否足以覆盖债权

│   ├─ 已控财产变现周期预估

│   ├─ 信用惩戒措施是否已产生压力效果
```

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」

  - 低风险：本结论有明确法律依据支撑
