# 法律尽职调查

> 输入交易场景→输出尽调清单+报告框架。非诉业务核心。

## 一、触发方式

- 用户说「尽职调查」「尽调」「DD」「收购公司要查什么」自动激活
- 手动触发：说「尽调」或「DD」

## 二、覆盖场景

| 场景 | 尽调重点 |
|:-----|:---------|
| 股权收购 | 股权结构/出资/股权受限/公司治理/重大合同/诉讼仲裁 |
| 资产收购 | 资产权属/抵押/租赁/知识产权/行政许可 |

```
  1. 目标公司主体：营业执照/章程/股权结构/实缴出资/历史沿革
  2. 重大资产：房产（权属+抵押）/知识产权（权属+许可）/设备

  5. 诉讼仲裁：在诉案件/生效判决未履行/行政处罚/执行记录
  6. 税务：欠税/稽查/税收优惠资质
  7. 环保/资质：环评/排污许可/行业资质证照

【债权收购尽调清单】
  1. 债权凭证：合同/借据/转账凭证/对账单
  2. 债务人：主体/财产线索/涉诉情况/破产风险
  3. 担保：抵押登记/质押/保证人（担保时效）

【合作尽调清单】（轻量版）
  1. 主体资质/信用记录/涉诉查询
  2. 履约能力（财报/银行流水）
  3. 关键人员背景/关联关系
  4. 行业口碑/过往合作评价
```

## 四、边界

- 本技能提供尽调清单和报告框架，具体尽调工作需律师现场进行
- 尽调报告的结论以实际调查获取的资料为准
- 涉及行业特殊监管（金融/医疗/教育等）需结合行业律师意见
- 尽调中发现重大风险建议在交易文件中设置保护条款

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
