### 第二步：复议前置判断与期限审查



**判断流程：**



```

┌─ ① 是否属于复议前置情形？

│   ├─ 资源类：自然资源所有权/使用权确认（行政复议法第30条）

│   ├─ 税务类：纳税争议（必须先缴纳税款或提供担保）

│   ├─ 治安类：对治安处罚不服（治安管理处罚法第102条已取消前置，可直接诉讼）

│   └─ 其他：商标/专利复审等特别法规定

│

│   是 → 必须先申请行政复议 → 复议后不服再诉

│   否 → 可选择复议或直接起诉

│

├─ ② 起诉期限计算（行政诉讼法第46条）

│   ├─ 直接起诉 → 知道行政行为之日起6个月内

│   ├─ 经复议后起诉 → 收到复议决定书之日起15日内

│   ├─ 复议机关逾期不作决定 → 复议期满之日起15日内

│   ├─ 不知道行政行为内容 → 最长5年（一般）/ 20年（不动产）

│   └─ 未告知诉权或起诉期限 → 从知道或应当知道诉权之日起6个月，最长不超过1年

│

└─ ③ 起诉期限是否已过？

    ├─ 未过 → 可以起诉 ✅

    ├─ 已过但有正当理由 → 审查是否存在不可抗力/其他正当障碍（第48条）

    └─ 已过且无正当理由 → 不建议起诉，建议其他救济途径

```

### 第三步：被告资格与管辖审查



**被告确定规则（行政诉讼法第26条）：**



```

┌─ ① 被告资格认定

│   ├─ 一般规则 → 作出行政行为的行政机关

│   ├─ 经复议的案件 → 复议维持→原机关+复议机关为共同被告

│   │                     复议改变→复议机关为被告

│   │                     复议未作决定→起诉原行政行为告原机关

│   ├─ 委托关系 → 委托机关为被告（受委托组织不告）

│   ├─ 派出机构 → 派出机构有授权→告派出机构；无授权→告设立机关

│   ├─ 共同行为 → 共同作出行政行为的机关为共同被告

│   └─ 行政机关被撤销/合并 → 继承其职权的行政机关为被告

│

└─ ② 管辖法院确定

    ├─ 一般地域管辖 → 最初作出行政行为的行政机关所在地基层法院

    ├─ 级别管辖（行政诉讼法第15条）

    │   ├─ 基层法院 → 一般行政案件

    │   ├─ 中级法院 → 国务院部门/县级以上机关为被告；海关；本辖区内重大复杂

    │   └─ 高级法院 → 全省范围内重大复杂

    ├─ 特殊地域管辖

    │   ├─ 限制人身自由案件 → 被告所在地或原告所在地

    │   └─ 不动产案件 → 不动产所在地

    └─ 异地管辖 → 符合条件可申请指定异地法院管辖

```



> ✅ 用户确认后进入下一步。

### 第四步：法律分析



**分析框架：**



```

┌─ ① 职权依据审查

│   ├─ 行政机关是否有法定职权作出该行为

│   ├─ 是否超越职权/不当行使职权

│   └─ 行政主体是否适格

│

├─ ② 程序合法性审查

│   ├─ 是否履行法定程序（听证/告知/陈述申辩）

│   ├─ 程序是否合规（期限/方式/步骤）

│   └─ 程序违法是否影响实体决定

│

├─ ③ 事实认定审查

│   ├─ 行政行为认定的事实是否清楚

│   ├─ 证据是否充分（被告承担举证责任）

│   └─ 事实认定是否符合证明标准

│

├─ ④ 法律适用审查

│   ├─ 适用的法律是否准确

│   ├─ 适用法律是否全面（有无遗漏应适用条款）

│   └─ 是否存在法律适用错误

│

└─ ⑤ 合理性审查（行政处罚显失公正等）

    ├─ 是否符合比例原则

    ├─ 是否考虑相关因素

    └─ 是否平等适用

```



**举证责任特别提示：**

```

┌─ 被告（行政机关）举证责任（行政诉讼法第34条）

│   ├─ 证明行政行为合法性：事实证据+法律依据+程序证据

│   └─ 被告不提供或无正当理由逾期提供 → 视为没有证据

│

├─ 原告举证空间

│   ├─ 证明行政行为存在 + 证明起诉符合条件

│   ├─ 可以举证证明行政行为违法（但非义务）

│   └─ 在行政赔偿案件中，证明损害事实

│

└─ 举证期限

    ├─ 被告：收到起诉状副本之日起15日内提交证据+依据

    └─ 原告/第三人：开庭审理前或法院指定期限内

```

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
