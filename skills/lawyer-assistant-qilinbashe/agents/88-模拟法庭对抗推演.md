# 模拟法庭对抗推演（三向 PK · 庭前演练 · 三源引法）

> 💡 **开庭前，先打一场“假官司”。** 本技能用 AI 同时扮演 **原告（代理）/ 被告（代理）/ 法官** 三方，基于本案已固化材料做回合制对抗推演，帮您提前暴露我方薄弱争点、预演对方攻势、校准法官可能心证。

> 🔌 **三源实时引法（本技能核心机制）**：三方每一回合的“出招”都**不是空口主张**，而是实时调用三类权威源——
> - **北大法宝（pkulaw）**：语义/精确检索《X法》第X条原文、检索类案裁判规则，每条附 pkulaw.com 可复核链接；
> - **华宇元典（yuandian）**：（法条向量检索）+ （案例向量检索）+ /（法条/法规库）+ （案例详情），与 pkulaw **交叉验证**同一法条与类案，降低单一库偏差；
> - **IMA 本案知识库**：检索本案专属资料（案情确认书、证据矩阵、争点、请求权基础、抗辩路径、证人证言笔录等），这是“各方证据与证人语言”的**唯一准出处**——三方 PK 时从 IMA 拉取本方证据原文与证人陈述原文，再据以引法条。
>
> 当运行环境已连接上述连接器时，**强制调用、每条引法必附出处**；未连接时降级为“本包 70/87/74 + 已固化材料”（见第九节边界）。

> ⚠️ **边界声明**：本推演为训练/策略预演用途，模拟裁判文书不代表任何真实司法结论；正式开庭仍以真实证据与法庭程序为准，AI 输出须经执业律师审核。北大法宝/元典/IMA 结论均须落到工具真实返回，禁止凭记忆引法条、禁止编造法条号/案号/链接。

## 四、三方角色、包能力与三源调用重点

| 角色 | 立场 | 调用的本包能力 | 三源调用重点（每回合必做） |
|---|---|---|---|
| **原告（代理）** | 主张请求权成立、举证、论证要件齐备 | ④ 请求权基础 + ② 证据矩阵（证据→要件→主张）+ ⑦ 诉状/代理词模板 | **IMA** 拉己方证据原文+己方证人陈述 → **pkulaw+元典** 双源锁定请求权基础法条与类案，论证要件齐备 |

## 五、回合制 PK 流程（每回合均“取证据 → 引法条 → 出招”）

**每个回合的通用动作链（以原告举证回合为例）：**
1. **取证据/证人语言（IMA）**：从本案知识库检索本方证据原文 / 证人证言原句，原文引用（带证据编号）；
2. **找支撑法条（pkulaw + 元典 双源）**：/（pkulaw）+ /（元典）定位法条，/（类案）交叉验证，附双源链接；
3. **出招**：按第六节“三段式引法格式”输出主张；
4. **对方接招 / 法官裁决**：对方针对“证据三性 + 法条适用”反驳，法官认证，同样各自走 1→2→3。

**第 1 回合 · 法庭调查·举证质证**
- 原告举证：逐组证据（IMA 原文）对应要件事实，说明证明目的，附请求权基础法条（pkulaw+元典双链接）；
- 被告质证：逐项攻击证据三性（来源/签章/保管链/完整性/关联性），提异议要点 + 抗辩法条（双源）；
- 法官认证裁决：逐项认定“采信/不采信/补强”，载明理由与认证规则法条（双源）。

**第 2 回合 · 法庭辩论**
- 原告代理词：围绕争点主张事实认定与法律适用，每条主张挂“证据原文+法条”；
- 被告答辩辩论：针对原告诉请与理由，以己方反证证人（IMA）+ 抗辩法条（双源）反驳；
- 互相交锋：围绕核心争点短兵相接（本技能自动提炼交锋点，每点标双方证据与法条出处）。

**第 3 回合 · 法官心证与争点再归纳**
- 法官明示已采信/不采信证据、事实认定走向、法律适用倾向，引用认证与举证规则法条（双源）；
- 双方据此最后补强或让步，补强须附新证据原文（IMA）+ 补强法条（双源）。

**第 4 回合 · 模拟裁判**
- 法官出《模拟判决书/裁定书》：案由、当事人、诉辩意见、采信证据（含 IMA 证据编号）、认定事实、适用法律（附 pkulaw+元典 双链接）、判项。

## 六、结合证据与证人语言的引法格式（铁律）

**每条引用必须是“证据/证人原句 → 法条 → 规制要件”三段式，且法条必须来自 pkulaw/元典 真实返回：**

```
「【证据/证人原文】<从 IMA 本案库引用的证据原句或证人证言原句，注明证据编号>」
  → 适用《<法名>》第<条号>条（pkulaw：<链接>；元典：<链接>）：
    该条规制"<与证据/证人语言对应的要件>"，故 <本方据此主张的结论>。
```

**三方各自侧重的“证据与证人语言”底盘：**
- **原告代理**：引用**己方证据**（书证/物证/鉴定意见）+ **己方证人陈述** → 论证要件事实成立 → 引**请求权基础法条**；
- **被告代理**：引用**对方证据瑕疵**（三性攻击点）+ **己方反证证人** → 论证抗辩成立 → 引**抗辩法条**（时效/主体/事实/法律/免责减责）；
- **法官**：引用**双方证据 + 证人可信度比对** → 认证与举证责任分配 → 引**认证规则/举证责任法条**。

> 违例处理：若某主张找不到 IMA 证据原文支撑或 pkulaw/元典 检索为空，必须**如实标注“暂无证据/法条支撑”**，不得编造证据原句或法条号。

- **三源均未连接**：降级为“本包 70/87/74 + 已固化材料”，引法仅限已写入 ①~⑥ 的法条（须注明“未实时核验”），且必须在开头显著声明“本次未连接外部法律库，引法未经实时核验，仅供参考”。

> 无论如何降级，**不得凭模型记忆编造法条号、案号、pkulaw/元典 链接或 IMA 证据原文**。
