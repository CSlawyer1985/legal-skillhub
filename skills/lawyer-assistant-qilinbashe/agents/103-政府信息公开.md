# 政府信息公开

> 覆盖「申请 → 答复 → 救济」全流程。依据《政府信息公开条例》（2019修订）。行政律师高频基础业务，也是征收补偿、行政处罚等案件的前置取证手段。

## 一、申请要件

### 1. 申请主体

```
公民、法人或者其他组织均可申请（无需说明申请用途，但需提供身份证明）
特殊情形：
- 申请信息与自身生产生活科研需要无关的，行政机关可不提供（实践中争议大）
- 以政府信息公开申请形式进行信访、投诉举报的，告知按相应渠道办理
```

### 2. 申请范围（可申请的信息）

| 可申请 | 说明 |
|:-------|:-----|
| 行政机关在履行行政管理职能过程中制作或获取的信息 | 以一定形式记录、保存 |
| 主动公开类信息 | 可申请获取，也可直接查阅 |
| 涉及申请人自身的信息 | 如处罚决定、许可记录 |

### 3. 不予公开的情形（豁免清单）

```
1. 国家秘密
2. 商业秘密（第三方）+ 个人隐私（第三方）——除非书面同意或公共利益需要
3. 行政机关内部事务信息（人事管理、后勤管理等）
4. 过程性信息（讨论记录、过程稿、磋商信函）
5. 行政执法案卷信息（可能依法不予公开）
6. 法律、法规规定不予公开的其他情形
```

> ⚠️ **关键破局点**：对“内部事务信息”“过程性信息”“行政执法案卷”的认定，行政机关需说明理由；涉及重大公共利益或申请人重大权益的，法院倾向于要求公开。

## 二、申请程序

```
1. 提交申请：书面（邮寄/当面/网络平台/传真）均可
2. 必备要素：申请人的姓名或名称、身份证明、联系方式；申请公开的政府信息的名称、文号或特征描述
3. 行政机关答复期限：收到申请之日起20个工作日内答复（可延长20个工作日并告知）
4. 补正通知：申请内容不明确的，7个工作日内一次性告知补正（补正时间不计入答复期限）
5. 答复形式：公开决定书 / 不予公开告知书 / 部分公开告知书 / 信息不存在告知书 / 非本机关掌握告知书
```

## 三、答复类型与应对

| 答复类型 | 含义 | 应对 |
|:---------|:-----|:-----|
| 予以公开 | 提供信息或告知获取方式 | 核对是否完整，不完整可再申请 |
| 不予公开 | 属豁免情形 | 审查理由是否成立（程序+实体） |
| 部分公开 | 区分处理后公开部分 | 要求说明不公开部分理由 |
| 信息不存在 | 声称未制作/未获取 | 要求提供检索过程说明；有证据证明存在的可反驳 |
| 非本机关掌握 | 指向其他机关 | 要求告知掌握机关名称，或自行转送 |
| 逾期不答复 | 视为未履行法定职责 | 直接行政复议/诉讼 |

## 四、救济路径

```
路径A：行政复议（向本级政府或上级主管部门，60日内）
路径B：行政诉讼（6个月内，被告=作出答复的行政机关）
路径C：向政府信息公开工作主管部门（同级政府办公厅/室）举报投诉

诉讼要点：
- 案由：政府信息公开行政案件（不作为/答复违法）
- 举证：行政机关对不予公开的理由承担举证责任
- 请求类型：确认违法+责令限期公开 / 撤销答复并重作
```

## 五、实务技巧（律师高频用法）

| 场景 | 用法 |
|:-----|:-----|
| 征收补偿 | 申请公开征收决定、补偿方案、评估报告、安置房分配信息 |
| 行政处罚 | 申请公开处罚决定书全文、执法记录、检测报告 |
| 招投标 | 申请公开中标结果、评标报告（涉商业秘密部分区分处理） |
| 环保 | 申请公开环评报告、排污许可、处罚信息 |
| 市场监管 | 申请公开许可、抽检、处罚信息 |
| 行政复议前置取证 | 先信息公开取证 → 再复议/诉讼（形成证据链） |

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
