# 庭审发问提纲生成器

> 庭审发问设计工具：法官发问预判 + 己方证人主询问 + 对方证人交叉询问 + 鉴定人质询。每问标注「目的 → 预设回答 → 应变路径」，输出可直接用于庭前准备的发问提纲。

## 一、触发方式

- 用户说「帮我设计发问提纲」「交叉询问怎么问」「开庭要问什么」自动激活
- 输入：争议焦点（1-3个）+ 证人类型 + 关键案情事实；或直接说案由让引擎先归纳争点

## 二、四类发问场景

### 1. 法官发问预判（法官最可能问什么）

```
基于争点与举证责任的预判框架：
- 要件事实类："你方主张XX，证据是什么？" → 准备证据索引+质证意见
- 矛盾澄清类："你方陈述与书面证据不符，如何解释？" → 准备合理解释
- 法律适用类："你方认为应适用哪条？为什么？" → 准备法条+类案
- 金额计算类："这个数字怎么算出来的？" → 准备计算明细表
输出：预判问题清单 + 每问的标准应答要点
```

### 2. 己方证人主询问（引导作证）

```
技术要点（开放式为主）：
- 开场定身份：姓名/与当事人关系/与本案关系
- 事实经过：用"请描述…""当时发生了什么"引导完整陈述
- 关键节点：分事件问，不跳跃；每个事件按"时间-地点-人物-行为-结果"展开
- 收尾固定：对关键事实做确认式提问（"你确认刚才所说属实？"）

每问标注：
- 目的：让证人证明什么事实（对应哪个要件）
- 预设回答：证人应作出的回答（庭前已核对）
- 应变：回答偏离时如何拉回（换角度重问/提示补充）
```

### 3. 对方证人交叉询问（质询/攻击）

```
技术要点（封闭式为主，一次一问）：
- 锁定证言：先固定对方证言的明确版本（"你刚才说X，对吗？"）
- 攻击矛盾：与书面证据/其他证人/常识的矛盾点 → 逐个击破
- 攻击来源：你怎么知道的？（亲眼/听说/猜测）→ 削弱证明力
- 攻击利益：你与当事人什么关系？有无利害关系？→ 影响可信度
- 时间/细节核查：具体时间、地点、在场人 → 编造证言常在这些细节露出破绽

交叉询问黄金规则：
- 不问不知道答案的问题
- 一次只问一个事实，不解释、不总结
- 关键点放在开头和结尾（陪审团/法官记忆曲线）
```

### 4. 鉴定人质询（对鉴定意见的攻击）

```
攻击维度：
- 资质：鉴定机构/鉴定人资质是否齐备？专业领域是否匹配？
- 程序：委托程序是否合法？检材来源是否合规？是否回避？
- 方法：鉴定方法是否符合国家标准/行业规范？
- 依据：鉴定依据的材料是否真实完整？有无遗漏关键材料？
- 结论：结论与鉴定过程是否匹配？有无超出鉴定范围的意见？
```

## 四、发问策略要点

- **主询问=讲故事**：按时间顺序让己方证人完整陈述，法官爱听
- **交叉询问=拆房子**：先固定再攻击，一个问题一个钉子
- **复问（redirect）**：交叉询问后被带偏的事实，复问阶段拉回
- **异议时机**：对方诱导性提问/重复提问/假设性提问 → 及时提异议
- **法官风格预判**：争点式法官（直接问要件）vs 放羊式法官（自由陈述）→ 调整准备重心

## 五、边界

- 发问提纲为庭前准备初稿，须由主办律师结合庭审实况调整
- 诱导性提问在己方证人主询问中禁用（法律禁止），交叉询问中亦需谨慎
- 涉及刑案讯问规则（不得强迫自证其罪等）时，发问设计须符合刑诉法规范

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
