# 收费合规与风险代理指引

> 输入收费方案，输出合规审查报告。不踩红线，合规收案。

## 一、触发方式

- 用户说「看看收费合不合规」「风险代理能做吗」「收费多少合理」自动激活
- 39-案件承接与委托引导用户进行收费合规自查
- 手动触发：说「收费合规」或「风险代理」

## 二、收费方式速查

| 收费方式 | 适用场景 | 特点 |
|:---------|:---------|:-----|
| **计时收费** | 非诉/常年顾问/复杂诉讼 | 按小时计费，300-3000元/小时 |
| **计件收费** | 非财产案件/简单的法律事务 | 固定金额，1-10万元 |
| **按标的比例** | 财产案件 | 按标的额分段累进，5%-0.5% |
| **风险代理** | 财产案件（有执行可能） | 按结果收费，**有禁区** |

## 三、风险代理禁区（绝对禁止）

以下案件类型**不得**采用风险代理：

| 禁止类型 | 依据 |
|:---------|:-----|
| 刑事诉讼案件 | 《律师服务收费管理办法》第11条 |
| 行政诉讼案件 | 同上 |
| 国家赔偿案件 | 同上 |
| 群体性诉讼案件 | 同上 |
| 婚姻/继承案件 | 同上 |
| 请求社会保险待遇/最低生活保障 | 同上 |
| 请求劳动报酬/工伤赔偿 | 同上 |
| 涉及安全事故/环境污染/征地补偿赔偿 | 同上 |

## 四、风险代理比例限制

| 条件 | 限制 |
|:-----|:-----|
| 最高收费金额 | 不得高于收费合同约定标的额的**30%** |
| 不得对禁止类型做风险代理 | 违者可能受到行政处罚 |
| 部分实行政府指导价 | 按各省标准执行 |

## 五、输出格式

```
收费合规审查报告
──────────────────────────────
案件类型：民间借贷（标的50万）
建议收费方式：按标的比例 或 风险代理
比例收费参考：约8,800-13,000元（按分段累计）
风险代理可行：✅ 是（财产案件，非禁止类型）
最高风险代理费：50万×30%=150,000元
──────────────────────────────
⚠️ 提醒：务必签订书面委托合同
        明确收费方式/金额/支付时间
        风险代理还需约定风险代理比例+支付条件
```

## 六、边界

- 本技能提供收费合规指引，具体收费以委托合同约定为准
- 各省律师服务收费标准可能存在差异，建议结合当地规定
- 风险代理的具体比例和条件由双方协商确定
- 涉及法律援助案件，执行法律援助收费标准

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
