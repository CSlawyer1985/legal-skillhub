# 多模态材料解析与证据审查

> 📌 本技能是律师助手的「多模态入口 + 证据审查」。它把**图片、扫描件、PDF、语音、文件**变成结构化文字（解析），再完成**证据审查**（三性评估 / 质证意见 / 保全建议），最后交「87 案卷精读防漏」或「39 案件承接」继续办案。

> 解决的问题：过去律师只能粘贴纯文字，合同照片、证据截图、录音、扫描卷宗都「读不了」；读出来之后还得另找人做证据分析——本技能**解析与审查一条龙**补齐这块短板。

---

## 🎯 何时触发本技能

满足以下任一情况，**第一动作**就是调用本技能解析材料，再进入后续办案链路：

1. 用户上传 / 提及 **图片、照片、截图、扫描件**（合同照片、房产证照片、聊天记录截图、笔录照片等）
2. 用户上传 / 提及 **PDF**（判决书、起诉状、合同 PDF、卷宗扫描件）
3. 用户上传 / 提及 **语音、录音、音视频**（通话录音、会见录音、庭审录音）
4. 用户上传任意 **文件材料** 且未提供可编辑文字版
5. 用户提交证据图片并要求**审查**（借条照片/聊天截图/转账截图等）

> 🔒 **强规则**：用户上传材料 ≠ 直接分析。必须先把材料解析成文字（本技能解析模块），再完成证据审查（审查模块），最后按「标准办案编排链路」走「第二阶证据精读（87）」或「第一阶案情承接（39）」。

## 🛠️ 第一部分：解析能力与调用方式

配套脚本：（本地运行，依赖可选、缺失即降级）。

```bash

# 单个材料

python scripts/multimodal_ingest.py <材料路径> [--out 输出.md] [--mask-names "真名=标签,..."] [--max-size-mb 100]

# 整个材料目录（批量）

python scripts/multimodal_ingest.py <目录> --out 材料汇总.md

# 查看支持格式矩阵 / 自检解析链路

python scripts/multimodal_ingest.py --supported
python scripts/multimodal_ingest.py --self-test

```

**支持格式矩阵（12 类，v4.3.0 扩展）**：

| 材料类型 | 扩展名 | 处理方式 | 依赖 |
|:---------|:-------|:---------|:-----|
| PDF 文档 | .pdf | fitz / pdfplumber 抽文字层；扫描件逐页 OCR | PyMuPDF / pdfplumber / easyocr |
| 图片 / 扫描件 | .png .jpg .jpeg .bmp .tiff .webp | easyocr 抽取文字（含表格区域） | easyocr |
| HEIC 图片 | .heic .heif | pillow-heif 转 PNG 后 OCR | pillow-heif + easyocr |
| 纯文本 / CSV | .txt .md .csv | 编码探测后直读（零依赖） | 无 |
| Word 文档 | .docx .doc | python-docx 含表格（docx2txt 备选）；.doc 请先另存为 .docx | python-docx / docx2txt |
| Excel 表格 | .xlsx .xls | openpyxl / xlrd，含 sheet 名与单元格 | openpyxl / xlrd |
| PPT 演示 | .pptx .ppt | python-pptx 抽文本框/表格/备注；.ppt 请先另存为 .pptx | python-pptx |
| HTML 网页 | .html .htm | BeautifulSoup 抽取正文与表格 | beautifulsoup4 |
| 音频材料 | .mp3 .wav .m4a .ogg .flac | openai-whisper 转写文字稿（或 voice_transcribe.py） | openai-whisper + ffmpeg |
| 视频材料 | .mp4 .mov .avi .mkv | ffmpeg 抽音轨后 whisper 转写 | ffmpeg + openai-whisper |
| 压缩包 | .zip | 安全解包（防 zip-slip）后递归解析支持类型 | 无（zipfile 标准库） |
| 邮件 | .eml | 标准库 email 提取正文与附件清单 | 无 |

**降级策略（关键）**：

- 缺 easyocr → 图片/扫描件类返回「请上传文字稿或转文字后提交」，不影响 PDF / 语音；
- 缺 whisper 或 ffmpeg → 语音 / 视频类返回降级提示，不影响图片 / PDF；
- 缺 python-docx / openpyxl / python-pptx / bs4 → Office / HTML 类返回安装命令或替代上传方式，不假装成功；
- 未知格式 → 返回支持格式清单 + 三个可执行建议（转 PDF / 截图上传 / 粘贴文字），不再只报“不支持”；
- 文件不存在 / 无权限 / 超限（默认 100MB）/ 加密压缩包 / 损坏文件 → 结构化错误提示，给出明确替代路径；
- 任何类型解析失败，都给出明确原因与替代建议，**不静默跳过、不编造内容**。

### 步骤E：常见图片证据场景要点

| 场景 | 审查要点 | 常见坑 |
|:-----|:---------|:-------|
| **借条/欠条照片** | 金额大小写一致、签名真实性、捺印、日期 | 只拍半张/金额被遮挡 |
| **微信聊天截图** | 完整对话（含时间线）、对方身份认证、语音转文字准确性 | 只截片段断章取义 |
| **转账记录截图** | 金额/时间/双方账户/附言、与借条对应 | 截图与银行流水不符 |
| **合同扫描件** | 骑缝章、页码连续、签字页完整 | 缺页/拼接扫描 |
| **现场照片** | 拍摄时间（EXIF）、地点（定位）、连续拍摄 | 摆拍/后期处理 |
| **发票/票据** | 真伪（税务查验平台）、抬头、金额、印章 | 假发票/重复报销 |

## 🔗 与办案链路的衔接

解析与审查完成后，**不要停在「已识别文字」**，立即按编排链路分流：

1. **材料是证据 / 案卷 / 书证** → 将「抽取文本 + 关键信号 + 三性评估」交 **87-案卷精读防漏技能**，生成要件事实—证据矩阵（纵轴要件、横轴证据原文+页码+主张方+认定状态）；
2. **材料含案情陈述 / 当事人叙述** → 交 **39-案件承接与委托**，提炼《案情确认书》六维要素；
3. **材料是合同 / 协议文本** → 交 **20-合同审查**，进入条款风险评级；
4. **材料是判决书 / 裁定书** → 交 **81-裁判文书解读与上诉决策**；
5. **需要逐份质证意见深化** → 交 **104-证据三性质证引擎** 做四段审查；
6. **材料是录音 / 语音且需专项审查** → 交 **108-语音证据处理**（转写+非法证据排除+内容分析）。

> 💡 解析文本已经过脱敏（如启用 ），进入下游技能前提醒承办律师核对原件真名。
