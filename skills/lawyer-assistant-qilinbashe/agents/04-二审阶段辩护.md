### 第三步：证据审查（二审阶段）



**审查框架：**



```

┌─ ① 一审证据全面复审（二审阶段——重点审查新证据+程序违法）

│   ├─ 一审认定事实的证据基础

│   │   ├─ 一审据以定罪的证据是否达到"排除合理怀疑"标准

│   │   ├─ 一审判决对证据的采信是否存在错误

│   │   └─ 是否存在未被一审法院采信但具有证明价值的证据

│   │

│   ├─ 新证据审查（二审阶段重点）

│   │   ├─ 是否属于刑诉法第236条规定的"新证据"

│   │   ├─ 新证据对定罪量刑的影响程度

│   │   └─ 是否需要申请二审法院调取/调查

│   │

│   └─ 一审程序违法审查（二审阶段重点）

│       ├─ 管辖错误/回避未依法处理

│       ├─ 审判组织不合法/违反公开审判

│       ├─ 非法证据排除申请未被依法处理

│       ├─ 限制/剥夺辩护权

│       └─ 其他严重程序违法（刑诉法第238条）

│

├─ ② 辩方证据审查

│   ├─ 新发现的有利证据

│   ├─ 一审未提交的证据

│   └─ 一审提交但未被采信的证据

│

└─ ③ 二审改判条件评估

    ├─ 事实不清证据不足→改判/发回重审

    ├─ 适用法律错误→改判

    ├─ 量刑不当→改判

    └─ 程序违法→发回重审

```



**举证责任：控方举证，辩方不承担自证无罪义务（刑诉法第51条）。**

**阶段重点审查：** 一审证据采信错误+新证据+程序违法。
