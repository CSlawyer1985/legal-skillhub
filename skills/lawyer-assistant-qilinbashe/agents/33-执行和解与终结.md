### 第二步：和解方案设计或终结条件核验



**A. 执行和解方案设计（如选择和解路径）：**



```

┌─ ① 分期付款方案

│   ├─ 首期金额（建议不低于总债务的30%，体现诚意）

│   ├─ 剩余期数（3-12期常见）

│   ├─ 每期金额和支付日期

│   ├─ 支付方式（银行转账/法院账户/直接支付+凭证）

│   └─ 担保措施（可要求提供担保人/抵押物）

│

├─ ② 以物抵债方案

│   ├─ 抵债物类型（房产/车辆/股权/设备/存货/知识产权）

│   ├─ 抵债物估值（协商/第三方评估）

│   ├─ 差额处理（抵债物价值高于/低于债权的补差方案）

│   ├─ 办理产权过户的时间周期和费用承担

│   └─ 法条依据：最高法拍卖变卖规定第24条

│

├─ ③ 债权转让方案

│   ├─ 转让的债权类型（被执行人对第三人的应收账款/借出款/投资收益）

│   ├─ 转让债权金额和折让比例

│   ├─ 转让通知（按合同法规定通知债务人）

│   └─ 法条依据：民法典第545条（债权转让）

│

└─ ④ 混合方案

    ├─ 现金+以物抵债组合

    ├─ 即付+分期组合

    └─ 部分债权转让+部分现金支付

```



**和解协议核心条款设计：**



```

【必备条款】

├─ 双方主体信息（申请执行人+被执行人+担保人（如有））

├─ 执行依据（案号+判决/调解书/仲裁裁决）

├─ 剩余债权金额（已履行金额+剩余金额）

├─ 和解履行方案（分期/以物抵债/债权转让的具体内容）

├─ 履行期限（每期截止日）

├─ 和解协议的效力（履行完毕后申请终结执行vs不履行则恢复执行原判决）



【可选条款】

├─ 担保条款（保证人/抵押/质押）

├─ 违约责任（逾期利息/违约金）

├─ 保密条款

├─ 争议解决条款



【重要法律效果提示】

├─ 和解协议不当然解除原判决的强制执行效力（民诉法（2021年修正）第230条）

├─ 和解协议不履行→恢复执行原判决（最高法执行和解规定第15条）

├─ 和解协议中的让步≠对原判决的放弃

```



**B. 终结本次执行条件核验（如选择终结本次执行路径）：**



```

终结本次执行的法定条件（最高法终本规定第1条）：

├─ □ 已向被执行人发出执行通知+责令报告财产

├─ □ 已穷尽财产调查措施（网络查控+传统调查）

├─ □ 未发现被执行人有可供执行财产/发现的财产不能处置

├─ □ 已向申请执行人告知终结本次执行后恢复执行的权利

└─ → 全部满足后方可申请终结本次执行

```

### 第四步：法律分析——法律后果评估



**分析框架：**



```

┌─ ① 和解方案法律后果分析

│   ├─ 和解协议履行的效果：申请执行人不得再申请执行原判决

│   ├─ 和解协议不履行的效果：申请执行人可申请恢复执行原判决（最高法执行和解规定第15条）

│   ├─ 恢复执行的范围：原判决的债权金额（不含和解中作出的让步）

│   ├─ 和解协议中的让步失去效力

│   └─ 担保条款在恢复执行后仍有效（须约定）



├─ ② 终结本次执行法律后果分析
```
