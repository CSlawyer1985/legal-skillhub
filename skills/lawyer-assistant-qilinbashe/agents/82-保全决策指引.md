# 保全决策指引

> 保全时机一错过，可能执行不到一分钱。本技能帮您判断：要不要保、能不能保、怎么保。

## 一、触发方式

- 用户说「申请保全」「查封对方财产」「防止转移资产」自动激活
- 31-总控路由在财产类案件匹配后引导用户评估保全必要性
- 手动触发：说「保全决策」或「财产保全」

## 二、核心能力

### （甲）保全必要性评估

| 评估项 | 说明 |
|:-------|:-----|
| 是否有明确的财产线索 | 银行账户/房产/车辆/股权/应收账款 |
| 是否存在转移风险 | 对方经营异常/涉诉多/已失联 |
| 是否具备保全条件 | 诉前保全需提供担保，诉中保全可酌情 |
| 保全收益vs成本 | 保全费+担保费 vs 执行到位的可能性 |

### （乙）担保方案建议

| 担保方式 | 适用场景 | 成本 |
|:---------|:---------|:-----|
| 现金担保 | 小额保全 | 冻结资金利息损失 |
| 保函（保险公司） | 大额保全 | 保费约为保全金额的0.5%-1% |
| 保函（银行） | 信用良好的企业 | 手续费+保证金 |
| 房产/车辆抵押 | 有固定资产 | 评估费+登记费 |

### （丙）紧急保全路径

- 诉前保全：立案前48小时内可申请，法院48小时内裁定
- 诉中保全：立案后随时申请，法院5日内裁定
- 仲裁保全：通过仲裁委转递法院
- 证据保全：公证处/法院

### （戊）担保方案对比（产出物②）

| 担保方式 | 成本 | 速度 | 适用 |
|:---------|:-----|:-----|:-----|
| 现金/存款 | 冻结资金利息损失 | 最快（当天） | 金额小、急需 |
| 保险公司保函 | 保费约保全额0.1%-1% | 1-3天 | 金额大、主流 |
| 房产抵押 | 评估+登记费 | 3-7天 | 自有房产 |
| 担保公司 | 费用较高（1%-3%） | 1-2天 | 银行不保的大额 |

## 四、边界

- 保全申请须以法院最终裁定为准
- 错误保全造成对方损失的，申请方需承担赔偿责任
- 担保金额和方式以法院要求为准
- 紧急保全建议立即联系执业律师操作
