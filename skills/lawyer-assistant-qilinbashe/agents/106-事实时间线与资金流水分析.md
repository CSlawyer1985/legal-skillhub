# 事实时间线与资金流水分析

> 复杂案件的事实梳理引擎：把散乱的事件/流水/聊天时间点，组织成「时间轴 + 资金流向 + 异常标记 + 证据锚定」的结构化图谱，直接支撑起诉状“事实与理由”与代理意见的事实叙述。

## 一、触发方式

- 用户说「梳理时间线」「整理资金流水」「做事实图谱」自动激活
- 输入：事件清单（时间+事件+人物+金额+证据编号），或直接粘贴银行流水/聊天记录时间点

## 二、事实时间轴构建

### 1. 事件提取与排序

```
输入 → 按时间排序 → 标注事件性质：
- 合同行为：签约/变更/解除
- 履行行为：付款/交货/验收/催告
- 争议行为：违约/侵权/通知/起诉
- 程序行为：立案/保全/开庭/判决

每条事件输出：
　时间 | 事件 | 当事人 | 金额/标的 | 关联证据 | 对应法条/要件
```

### 2. 时间轴图谱输出

```
2023-05-01 ─── 签订《分包合同》(合同书·证据1) ─── 民法典第787条(分包)
2023-06-15 ─── 首笔预付款 30万 (银行流水·证据2) ─── 合同履行
2023-08-20 ─── 主体工程完工 验收单 (证据3) ─── 民法典第799条(验收)
2023-09-10 ─── 催款函 (EMS单·证据4) ─── 时效中断
2024-01-05 ─── 仲裁申请 (仲裁申请书) ─── 时效中断
──────────────────────────────
【关键时间点提示】
- 时效起算：2023-08-20（验收后应付）→ 3年时效至 2026-08-20 ✅未过
- 合同成立：2023-05-01 → 争议解决条款适用确认
```

### 3. 时间矛盾检测

```
- 时间倒挂：证据形成时间与事件逻辑矛盾（如合同签订日晚于履行日）
- 时间空白：关键时段无证据 → 补证提示
- 时间戳冲突：电子证据时间与银行流水时间不吻合 → 标记疑点
```

## 三、资金流水分析

### 1. 流水整理（输入银行流水/转账记录）

```
输出《资金流水分析表》：
　日期 | 收/支 | 金额 | 对方账户/户名 | 备注 | 证据编号 | 关联事件
按时间排序，合并同类项，标注摘要
```

### 2. 异常点自动标记（重点！）

| 异常类型 | 判定规则 | 法律意义 |
|:---------|:---------|:---------|
| **大额异常** | 单笔超过平时水平3倍以上 | 可能涉及大额借贷/工程款/隐匿财产 |
| **频繁小额** | 短期内多笔同额进出 | 可能拆借/规避监管/对倒 |
| **对倒交易** | 相同金额短时间内A→B→A | 虚假交易/资金回流 |
| **时间密集** | 深夜/节假日/凌晨转账 | 异常交易时间 |
| **整数化** | 多笔整万/整十万 | 可能为规避监控的拆分 |
| **关联人往来** | 与亲属/关联公司/员工账户往来 | 利益输送/隐匿 |
| **现金存取** | 大额现金存取无合理说明 | 账外资金/隐匿 |

### 3. 资金流向图

```
甲账户(债务人) ──30万→ 乙账户(亲属)
　　　│
　　　├─20万→ 丙公司(关联企业) ⚠️ 关联交易
　　　└─10万→ 丁账户(新开卡) ⚠️ 疑似隐匿
标记：异常流向 + 建议调查方向（申请调取/调查令/追加当事人）
```

## 四、输出格式

```
《事实时间线与资金流水分析报告》
──────────────────────────────
一、事实时间轴（N条事件，三对应）
二、资金流水表（N笔，含异常标记M处）
三、异常点清单（逐条说明+法律意义+调查建议）
四、证据缺口提示（时间空白处/无流水支撑的关键事实）
五、可直接引用的事实叙述（起诉状"事实与理由"段落初稿）
──────────────────────────────
```

## 五、边界

- 本引擎基于用户提供材料整理，不能自动获取银行流水/工商信息（需调查令/律师调查）
- 异常标记为**提示性**判断，最终认定须结合其他证据
- 涉及隐匿财产/转移财产嫌疑的，提示申请财产保全或追加当事人，不直接定性

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
