# 利益冲突自查指引

> 收案第一道合规红线。输入当事人信息，输出冲突分析报告。

## 一、触发方式

- 用户说「帮我查冲突」「能不能接这个案子」「查利益冲突」自动激活
- 39-案件承接与委托引导用户进行冲突自查
- 手动触发：说「利益冲突」或「冲突自查」

## 二、冲突类型速查表

| 冲突类型 | 适用情形 | 处理方式 |
|:---------|:---------|:---------|
| **直接冲突（绝对禁止）** | 同一案件代理双方 | 不得代理 |
| | 同一案件代理对方（已委托方未解除） | 不得代理 |
| | 在同一非诉业务中同时代理利益冲突双方 | 不得代理 |
| **间接冲突（禁止-可豁免）** | 代理当事人的近亲属 | 告知并取得书面同意可代理 |
| | 曾经代理过对方（同一所） | 审查是否涉及同一事项 |
| | 两个客户在同一事项中有利益冲突 | 告知并取得双方书面同意可代理 |
| | 律师近亲属与当事人有利益冲突 | 披露并回避 |
| **其他限制** | 曾任法官/检察官离职后两年内 | 不得在原任职法院担任代理人 |
| | 仲裁员/鉴定人 | 不得在同一案件中担任代理人 |

## 三、输出格式

```
利益冲突自查报告
──────────────────────────────
申请代理人：张三律师
案件类型：民间借贷纠纷
对方当事人：李四
──────────────────────────────
✅ 未发现直接冲突
⚠️ 提示：李四曾系本所2020年委托客户（已结案）
    建议：确认代理事项与历史委托不涉及同一案件
──────────────────────────────
处理建议：可以代理，建议书面告知李四
```

## 四、边界

- 本技能为自查指引，不替代律所OA系统的冲突检索功能
- 涉及同所其他律师的代理情况，建议与律所行政/主任核实
- 利益冲突的最终判断以《律师法》+律所内部制度为准
- 涉及复杂冲突情形建议咨询律协或司法行政部门

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」


### 🎯 多方案量化对比（输出为三栏表格，禁止用文字段落替代）
完成分析后，按本技能领域输出三栏量化对比表：
| 对比项 | 方案A（推荐） | 方案B（替代） | 方案C（不行动） |
|:-------|:------------|:------------|:--------------|
| 成本 | 明确金额/费率（按标的额算） | 明确金额/费率 | 无直接费用 |
| 周期 | 明确时长（月/周） | 明确时长 | 视情况 |
| 风险 | 列主要风险 | 列主要风险 | 时效经过/证据灭失风险 |
| 依据 | 具体法条 | 具体法条 | 时效提示 |
方案内容按本技能领域填写（诉讼/调解/不行动、整改/停用/免责、重整/和解/清算等），量化数据用「XX」占位并提示按案情计算，不得写空泛描述。
