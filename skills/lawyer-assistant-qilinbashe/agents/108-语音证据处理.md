# 语音证据处理

> 输入录音/语音材料 → 输出转写稿 + 合法性审查 + 内容分析 + 质证意见。

## 一、触发方式

- 用户提交音频/录音文件或提及录音材料
- 用户说「录音能当证据吗」「偷录的算数吗」「帮我听这段录音」
- 31-总控路由识别到语音材料自动分诊至本技能
- 手动触发：说「语音证据处理」

## 二、处理流程

### 第一步：音频转写

**转写方式（按环境选择）：**

```
方式A：有脚本环境 → 运行 scripts/voice_transcribe.py <音频文件>
  输出：带时间戳的转写稿（txt）

方式A'：视频/其他格式材料 → 先经 scripts/multimodal_ingest.py 解析
  （视频自动 ffmpeg 抽音轨转写；支持 12 类格式，详见 107-多模态材料解析 格式矩阵）

方式B：无脚本环境 → 引导用户提供录音内容或逐段播放转述
  输出：人工转写稿（标注不确定处）

转写稿格式：
[00:00-00:05] 甲：____
[00:05-00:12] 乙：____
……
（模糊处标注【听不清】，方言/专业术语标注【待核实】）
```

### 第二步：合法性审查（非法证据排除）

| 审查项 | 判断标准 | 结论 |
|:-------|:---------|:----:|
| **录音场所** | 公共场所（合法）vs 他人住宅/私密空间（可能侵犯隐私） | □合法 □存疑 |
| **录音主体** | 谈话参与方自行录音（合法）vs 安装窃听设备（违法） | □合法 □违法 |
| **录音方式** | 公开场合正常对话录音 vs 窃听/截听他人通话 | □合法 □违法 |
| **侵犯权益** | 是否侵犯他人隐私权/商业秘密/人格尊严 | □无 □有 |
| **剪辑加工** | 原始录音完整保存？有无剪辑拼接 | □完整 □存疑 |

```
合法性结论：
- 参与方录音+合法场所 → 通常合法可用（最高法证据规定第68条精神）
- 窃听/偷装设备 → 非法证据排除（最高法证据规定第68条）
- 侵犯隐私/商业秘密 → 非法证据排除
- 剪辑拼接 → 真实性存疑，可申请鉴定

⚠️ 特别注意：
- 刑事案件的"同步录音录像"与民事偷录性质不同
- 偷录录音虽违法，但实践中"以侵犯他人合法权益或违反法律禁止性规定"才排除
  （最高法《关于民事诉讼证据的若干规定》第106条）
- 合法录音不得作为唯一证据，需与其他证据印证
```

## 三、常见语音证据场景要点

| 场景 | 要点 | 常见坑 |
|:-----|:-----|:-------|
| **借贷通话录音** | 固定“借款合意+金额+还款承诺”三要素 | 只听清部分金额 |
| **家暴/威胁录音** | 固定威胁内容+时间+人物 | 情绪下表述模糊 |
| **劳动纠纷录音** | 固定加班事实/辞退通知/工资承诺 | 对方否认身份 |
| **合同谈判录音** | 固定关键条款口头确认 | 与书面合同冲突 |
| **刑事讯问同步录音录像** | 完整性/同步性/有无诱供 | 剪辑/不同步 |

## 四、边界

- 本技能输出转写稿与质证意见，最终证据效力由法院认定
- 转写稿存在识别误差可能，关键内容须人工核对原始录音
- 涉及刑事录音证据的合法性争议，建议由刑事专业律师处理
- 输出均为AI初稿，须律师实质审查后使用

## 格式依据（国家标准锚定）

本技能涉及的标准文书交付物，须严格遵循以下国家标准框架，不得使用自定义或已过时的格式：

- **文书类型**：质证意见、证据清单
- **国标依据**：最高法《民事诉讼文书样式》质证意见/证据清单样式 + 最高法《关于民事诉讼证据的若干规定》（法释〔2019〕19号）
- **强制要求**：凡输出正式文书（起诉状/答辩状/上诉状/申请书/代理词/证据清单/和解协议/裁决/判决等），一律按最高法《民事诉讼文书样式》（法〔2016〕221号 及后续修订）或对应专门样式（仲裁/行政/破产）的结构、要素、用语规范生成；当事人称谓、案由、法条引用格式均依国标。
- **交叉比对**：文书中引用的法条，须经  多源核验并标注置信度（见 ）。

---

> **离线模式**：当法规数据库和 MCP 均不可用时，基于 Agent 自身知识输出，标注法条来源为内置知识（离线模式），建议通过 flk.npc.gov.cn 复核。


### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
