# 利息与违约金计算器

> 自动分段计算利息/违约金，输出计算表 + LPR四倍上限校验 + 合规提示。

## 一、触发方式

- 用户说「利息怎么算」「逾期利息多少」「违约金怎么要」自动激活
- 也可直接输入：如「借10万，年利率12%，2024-01-01到2025-01-01」

## 二、计算框架

### 1. 借贷利息（约定利率）

```
利息 = 本金 × 约定年利率 × 实际占用天数 ÷ 365（或360，按合同约定）

利率上限校验（民间借贷）：
- 合同成立时一年期LPR 4倍以内 → 受法律保护
- 超过4倍LPR部分 → 无效，不保护（2020年8月20日后的新规）
- 2020年8月19日前的旧借款：年利率24%以内受保护，24%-36%自然债务，超36%无效
```

### 2. 逾期利息 / 资金占用费

```
逾期利息（有约定）：按约定利率或约定逾期利率计算，上限同LPR四倍
逾期利息（无约定，民间借贷）：
- 未约定借期内利率：按逾期时一年期LPR计
- 有约定借期内利率：按借期内利率计
买卖合同逾期付款（无约定）：
- 参照逾期罚息利率标准（LPR加计30%-50%），或按LPR计资金占用损失
```

### 3. 违约金

```
违约金 = 约定基数 × 违约金比例 × 违约天数
司法调整规则（《民法典》第585条）：
- 过高：超过实际损失30%的部分，法院可酌减
- 过低：低于实际损失，可请求增加
- 常见司法尺度：日万分之五（年化18.25%）以内较易获支持；日千分之一以上大概率酌减
```

### 4. 利息+违约金并存

```
- 民间借贷：逾期利息与违约金可同时主张，但合计不得超过LPR四倍上限
- 一般合同：违约金与实际损失赔偿可并存（以不重复填补为限）
- 工程款：欠付工程款利息（LPR标准）与违约金择一或并存，按合同约定
```

### 5. 迟延履行加倍利息（执行阶段）

```
加倍部分债务利息 = 债务人尚未清偿的生效法律文书确定的一般债务利息之外的金钱债务 × 日万分之一点七五 × 迟延履行期间
（依据：《最高人民法院关于执行程序中计算迟延履行期间的债务利息适用法律若干问题的解释》）
```

## 三、LPR速查（2026年参考值）

| 期限 | 参考LPR |
|:-----|:--------|
| 1年期 | 3.0% 左右（以全国银行间同业拆借中心每月公布为准） |
| 5年期以上 | 3.5% 左右（以公布为准） |

> ⚠️ LPR每月20日更新，计算时必须使用**合同成立日/逾期起始日对应的当月LPR**，并注明取值日期。四倍上限 = 该月LPR × 4。

## 五、边界

- LPR每月变化，必须按对应月份取值并注明
- 2020年8月19日前后的民间借贷利率规则不同，需按借款成立时间区分
- 金融借款（银行/小贷）适用金融机构利率监管规定，不完全等同民间借贷4倍LPR规则
- 复利（利滚利）约定：民间借贷原则上不支持复利计入本金，金融机构按监管规定
