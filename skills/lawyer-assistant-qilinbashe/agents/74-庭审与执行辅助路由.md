# 庭审与执行辅助路由（程序阶段 · 跨案由）



把“立案之后到实质拿到结果”的推进阶段统一成一条主线，串起散落在各案由里的庭审、执行、上诉能力，并补齐两项此前缺失的通用能力：**庭审通用质证辩论框架**与**上诉决策判断树**。



## 一、触发条件

- 律师进入“开庭 / 质证 / 执行 / 上诉 / 再审”阶段；

- 或被点选目录节点“⑩ 庭审与执行辅助”；

- 或用户问“开庭怎么准备 / 怎么质证 / 判了要不要上诉 / 赢了拿不到钱怎么办”。



## 二、庭审通用质证辩论框架（原缺失，此处补齐）

> 实体攻防见阶段三（争议焦点 / 攻防预判）与 70-案件深度分析。本框架给“庭审呈现”的通用骨架。



**庭前准备**

- 庭前会议事项（管辖权异议 / 证据交换 / 证人）；

- 用 70 做庭审预演，把争议焦点摊成问答脚本。



**质证三性（逐项击破）**

- 真实性：是否原件 / 有无篡改 / 来源可信；

- 合法性：取证手段是否合法（偷录 / 诱证风险）；

- 关联性：与待证事实是否相关。

- 对对方每份证据给“认可 / 不认可 + 理由”。



**辩论焦点**

- 回到阶段三提炼的争议焦点（事实 / 法律 / 程序），每点给“我方主张 + 法条 + 类案支撑”；

- 调解口径同步准备（底线 / 区间）。



**代理词 / 辩护词结构**

- 首部（到庭身份）→ 质证意见摘要 → 辩论意见（分点）→ 结论与请求。

## 四、上诉 / 再审决策判断树（原缺失，此处补齐）

收到裁判文书后：

1. **是否生效**？未生效（上诉期内）→ 进入 2；已生效 → 进入 4。

2. **上诉点有没有**？从四处挖：事实认定错误 / 法律适用错误 / 程序违法 / 量刑不当。

   - 有清晰上诉点 → 建议上诉，起草上诉状（），程序交 04-二审阶段辩护；

   - 无实质上诉点 → 提示“维持风险高，建议服判或重点谈执行”。

3. **上诉期限**：民事 / 行政 15 日、刑事 10 日，从送达日起算，提示律师固定送达日。

4. **生效后发现错** → 申诉 / 再审，交 44-特殊程序（再审）。



## 五、执行推进路线图

判决 / 裁决生效且未履行 →

1. **申请执行**（36）：条件 / 管辖 / 材料 / 可行性评估；

2. **财产调查**（64-65）：查银行存款 / 不动产 / 股权 / 到期债权，收集线索；

3. **强制措施**（35）：限高 / 失信 / 查控 / 拍卖 / 拘留，组合施策；

4. **异议与救济**（34）：案外人 / 当事人异议处理；

5. **和解与终结**（33）：履行评估 / 和解方案 / 终本与恢复；

6. **仲裁裁决执行撤销**（08）：一裁终局后的有限救济（撤销 / 不予执行）。
