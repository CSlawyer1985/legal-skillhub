# 工伤赔偿专项

> 覆盖「认定→鉴定→赔偿→争议」全链条。工伤走《工伤保险条例》单独赔偿框架，与一般人身损害赔偿（98号）标准不同，注意区分。

## 一、工伤认定（第一步）

### 应当认定工伤（《工伤保险条例》第14条）

| 情形 | 说明 |
|:-----|:-----|
| 工作时间+工作场所+工作原因受伤 | 三要素齐备 |
| 工作时间前后在工作场所从事收尾性工作受伤 | 预备性/收尾性工作 |
| 工作时间和工作场所内因履行工作职责受到暴力伤害 | 需排除故意犯罪 |
| 患职业病 | 需职业病诊断机构确诊 |
| 因工外出期间受伤或下落不明 | 因工外出全时段 |
| 上下班途中受非本人主要责任交通事故/城市轨道/客运轮渡/火车事故伤害 | 需交警责任认定非主责 |

### 视同工伤（第15条）

- 工作时间和工作岗位突发疾病死亡或48小时内抢救无效死亡
- 抢险救灾等维护国家利益/公共利益活动中受伤
- 军队服役期间负伤致残，已取得革命伤残军人证，到用人单位后旧伤复发

### 不得认定（第16条）

- 故意犯罪、醉酒或吸毒、自残或自杀

## 二、认定程序

```
1. 用人单位：事故伤害发生之日起30日内申请（逾期由单位自担费用）
2. 职工/近亲属：1年内自行申请（工会可代）
3. 提交材料：工伤认定申请表、劳动关系证明、医疗诊断证明、事故报告
4. 人社局60日内作出认定（事实清楚的可15日内）
5. 不服认定决定 → 行政复议（60日）或行政诉讼（6个月）
```

> ⚠️ **单位不配合时的破局点**：单位不申请 → 职工1年内自行申请；单位不认劳动关系 → 先仲裁确认劳动关系（最长60日）再申请工伤认定。

## 三、劳动能力鉴定（伤残等级）

```
1. 工伤认定后，伤情相对稳定即申请劳动能力鉴定
2. 鉴定内容：伤残等级（一至十级）+ 生活自理障碍等级 + 停工留薪期
3. 设区市劳动能力鉴定委员会60日内出结论，不服可15日内申请再次鉴定（省级终局）
4. 1年后伤情变化的可申请复查鉴定
```

## 四、赔偿项目与计算（核心）

### 1. 停工留薪期工资（原工资福利待遇不变）

```
- 停工留薪期一般不超过12个月，严重伤情经批准可延长不超过12个月
- 由用人单位按月支付（不是工伤保险基金支付）
```

### 2. 一次性伤残补助金（基金支付，解除/保留劳动关系时均有）

| 伤残等级 | 月数（本人工资） |
|:---------|:----------------|
| 一级 | 27个月 |
| 二级 | 25个月 |
| 三级 | 23个月 |
| 四级 | 21个月 |
| 五级 | 18个月 |
| 六级 | 16个月 |
| 七级 | 13个月 |
| 八级 | 11个月 |
| 九级 | 9个月 |
| 十级 | 7个月 |

```
本人工资 = 受伤前12个月平均月缴费工资（低于当地职工平均工资60%按60%计，高于300%按300%计）
```

### 3. 一次性工伤医疗补助金 + 一次性伤残就业补助金（解除/终止劳动关系时）

| 伤残等级 | 医疗补助金（基金付） | 就业补助金（单位付） |
|:---------|:--------------------|:--------------------|
| 五级 | 约18个月（按当地标准） | 约18个月（按当地标准） |
| 六级 | 约15个月 | 约15个月 |
| 七级 | 约12个月 | 约12个月 |
| 八级 | 约9个月 | 约9个月 |
| 九级 | 约6个月 | 约6个月 |
| 十级 | 约3个月 | 约3个月 |

> ⚠️ 各地标准差异大（山东/广东/江苏各有细规），必须代入**参保地/用人单位所在地**标准计算。一至四级伤残保留劳动关系，不适用本项。

### 4. 其他项目

| 项目 | 标准 |
|:-----|:-----|
| 医疗费 | 工伤保险目录内实报实销（基金付） |
| 住院伙食补助费 | 当地标准（基金付） |
| 交通食宿费 | 外地就医合理费用（基金付） |
| 康复费 | 签订服务协议的康复机构（基金付） |
| 辅助器具费 | 按国家标准配置（基金付） |
| 生活护理费 | 完全不能自理=统筹地区上年度职工月均工资50%；大部分40%；部分30%（基金按月付） |

### 5. 工亡待遇（职工死亡）

```
1. 丧葬补助金 = 统筹地区上年度职工月平均工资 × 6个月
2. 供养亲属抚恤金：配偶=本人工资×40%；其他亲属×30%；孤寡老人/孤儿上浮10%
   （各供养亲属合计不超过本人工资）
3. 一次性工亡补助金 = 上一年度全国城镇居民人均可支配收入 × 20
   （2025年标准约108万元，随每年公布更新）
```

## 五、争议处理路径

```
路径A（有劳动关系+单位参保）：认定 → 鉴定 → 社保基金+单位分别支付 → 不足部分仲裁
路径B（有劳动关系+未参保）：认定 → 鉴定 → 全部待遇由单位承担 → 单位拒付则仲裁/诉讼
路径C（单位不认劳动关系）：先仲裁确认劳动关系 → 再工伤认定 → 后续同上
路径D（不属工伤但单位有过错）：走人身损害赔偿（98号）或提供劳务者受害责任
```

## 六、时效与要点

- 工伤认定申请时效：单位30日 / 职工1年（超期丧失）
- 劳动能力鉴定：伤情稳定后随时可申请
- 劳动仲裁时效：1年（自知道权利被侵害之日）
- 未签劳动合同的：先确认劳动关系（工资流水/考勤/工牌/聊天记录/同事证言）
