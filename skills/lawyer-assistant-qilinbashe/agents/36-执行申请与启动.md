### 调解/和解前置评估



**在进入正式申请前确认以下事项：**



```

1. 判决生效后双方是否尝试过协商履行？

2. 被执行人是否有主动履行意愿或部分履行行为？

3. 是否存在执行和解的空间？（如分期付款、以物抵债等方案）

```



**根据评估结果分流：**

- ✅ 有履行意愿且可协商 → 建议尝试执行和解（和解后申请执行和解协议司法确认或撤回执行申请），给出和解方案建议

- ✅ 无履行意愿或协商失败 → 继续进入正式申请流程

- ⚠️ 不确定 → 建议先发《履行催告函》或《预执行通知书》，观察对方反应后再决定

### 第二步：管辖与时效核验



**核验策略（按穷尽原则）：**



```

第1层：管辖核验

  1.1 原审法院是否为一审法院？→ 查阅判决书末页

  1.2 拟申请的管辖法院是否适当？→ 一审法院 / 被执行人住所地法院 / 财产所在地法院（民诉法第224条）

  1.3 如向财产所在地法院申请，是否有财产线索证明财产在该法院辖区内？



第2层：时效核验

  2.1 法律文书确定的履行期间最后一日起算是否满2年？

  2.2 如超过2年，是否存在时效中止、中断事由？

     - 时效中断：申请执行、当事人同意履行、部分履行（民诉法第246条）

     - 时效中止：不可抗力等不能行使请求权的情形

  2.3 是否有对方同意履行或部分履行的证据？（如有，时效重新计算）

```



**核验标准：**



```

引用规范：法规名称+发布机关+发布日期+条款号

核验标准：双源交叉核验

  两源一致 → 标注「双源确认」

  不一致 → 标注差异+两源原文

  单源 → 标注「单源检索，建议人工复核」

  均不可用 → 标注「未检索到」

```

### 第三步：执行材料准备与审查



**审查框架（逐项检视）：**



```

┌─ ① 生效法律文书审查

│   ├─ 文书类型（判决/裁定/调解书/仲裁裁决/公证债权文书）

├─ ② 申请执行人资格审查
```

### 第四步：法律分析——执行可行性评估



**分析框架：**



```

┌─ ① 执行依据效力分析

│   ├─ 法律规范（民诉法第224条）

│   ├─ 本案情况：法律文书类型+生效状态

│   └─ 初步判断：可执行/不可执行/待补强



├─ ② 执行时效分析

│   ├─ 法律规范（民诉法第246条）

│   ├─ 本案情况：履行期届满日→申请日

│   └─ 初步判断：未超时效/已超时效但有中断事由/已超时效且无中断事由



├─ ③ 执行可行性预估

│   ├─ 已掌握的财产线索充足度

│   ├─ 被执行人的履行能力初步判断

│   └─ 执行难点预判（查找财产困难/异地执行/执行异议风险）



├─ ④ 确定性评级

│   ├─ 确定：执行条件全部满足，材料齐全

│   ├─ 高度盖然性：主要条件满足，个别材料待补充

│   ├─ 有待补强：关键材料缺失（如无生效证明/无法送达地址）

│   └─ 材料不足：现有材料无法判断执行可行性



└─ ⑤ 风险提示

    ├─ 执行时效风险（是否临近或超过2年）

    ├─ 管辖风险（是否选对管辖法院）

    ├─ 保全到期风险（诉前保全30日限制）

    ├─ 执行不能风险（被执行人名下无财产）

    └─ 执行救济风险（被执行人可能提异议）

```

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如「借条：有/没有/丢了？」）
- 第3次追问：转场景选单（「您的情况更接近：A借钱不还 B被撞了 C被辞退」），提示可说「转接」换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
- 超出范围：「这个情况超出了本技能领域，说『转接』可转到更合适的专家，或拨打12348。」
