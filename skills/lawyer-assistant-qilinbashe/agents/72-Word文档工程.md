# Word文档工程与修订管理



> 场景：澄明科技《2026年度客户服务运营手册》终稿交付

> 核心能力：分节修复 · 页眉页脚 · 自动目录 · 表格修订 · 修订批注管理 · 交付质检



## 作用边界与调用条件



- **定位**：文书导出与排版工具 Agent（utility），接收其他 Agent（如 41-民间借贷纠纷）生成的 Markdown 法律文书，转换为规范 DOCX 并做排版质检。

- **触发方式**：用户说“导出Word文档 / 转Word / 文档工程 / 生成docx”时激活；或 31 在文书生成节点（㉗）主动调用。

- **作用边界**：仅做格式排版、修订管理、目录/页眉页脚/表格修复、交付质检；**不做**法律分析或事实判断，**不替代**人工审阅与专业校对。

- **与其他工具分工**：案件分析交 70，竞合识别交 71；本 Agent 只做“Markdown → DOCX”的排版落地。



## 触发条件



当其他Agent（如41-民间借贷纠纷）生成Markdown格式法律文书后，用户说“导出Word文档”时自动激活本技能进行DOCX格式排版。

### Step 1：文档结构修复



**分节检查与修复：**

1. 遍历所有分节，检查分节类型

2. 确定分节用途：封面 / 目录 / 正文 / 附录

3. 修正分节符位置和类型

4. 设置首页不同（封面页）



**页眉页脚修复：**

1. 检查每节页眉的  属性

2. 断开错误的继承关系

3. 根据节内容设置正确的页眉文本

4. 封面页清除页眉页脚



**页码修复：**

1. 目录节：罗马数字页码

2. 正文节：阿拉伯数字，从1开始

3. 附录节：接续正文页码



### Step 2：正文修改



**核心原则：保持样式，只改内容**



```python

def find_and_replace_preserve_style(doc, old_text, new_text):

    """保持原样式的文本替换"""

    for para in doc.paragraphs:

        if old_text in para.text:

            # 逐run替换，保持每个run的字体/大小/颜色/加粗

            for run in para.runs:

                if old_text in run.text:

                    run.text = run.text.replace(old_text, new_text)

```

- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）

- 信息不足：「您提供的信息还差关键一点，我先问一个最重要的问题：……」
- 信息矛盾：「您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？」
