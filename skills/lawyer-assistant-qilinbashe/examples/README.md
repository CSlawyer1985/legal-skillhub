## 示例1：民间借贷纠纷（基础流程）

### 场景
朋友借了5万，有借条，说好2025年底还，到现在没还，电话不接了。

### 完整对话
```
用户：朋友借了我5万，有借条，说好去年底还，现在电话不接了

AI：您好！我将协助您处理这个民间借贷问题。

    我先帮您梳理一下：
    1. 您有借条（关键证据）
    2. 对方已逾期未还（违约事实）
    3. 从2025年底到现在，诉讼时效仍在3年内
    
    请问：
    - 对方的全名您知道吗？
    - 借款时有没有约定利息？

用户：他叫李四，没约定利息，就是朋友间借的

AI：好的。那您的借款属于无息借款，但逾期后可以主张逾期利息（按LPR计算）。
    现在您有两个选择：
    A. 先发律师函催告（给对方最后一次机会）
    B. 直接起诉
    
    您倾向哪个？

用户：直接起诉吧

AI：好的。我需要补充以下信息来准备起诉状：
    1. 您的身份信息（姓名、住址，用化名代替）
    2. 您手上还有哪些证据（转账记录、聊天记录等）
    3. 对方知道您起诉这件事了吗？
    
    请逐一回复，不方便说的可以跳过。

用户：我叫张三，住XX市XX区。有银行转账记录，借条照片也有。还没告诉他。

AI：好的，证据很齐全。现在为您生成：

    📄 **民事起诉状（初稿）**
    📋 **证据清单**
    📌 **诉讼步骤指引**（含管辖法院、诉讼费、立案材料清单）
    
    您看是先查看起诉状内容，还是直接导出Word文档？

用户：先看看起诉状

AI：[输出民事起诉状预览]
    
    ⚠️ 提醒：所有文书均为AI初稿，须经律师审核后提交法院。
    需要修改什么部分直接说。满意的话说「导出Word文档」获取国标格式。
```

### 产出物
- 民事起诉状初稿
- 证据清单（含借条、转账记录）
- 诉讼指引（管辖法院、诉讼费、立案材料）
- 可选：导出国标Word文档

### 用时参考：5-10分钟

## 示例2：劳动争议（中等复杂度）

### 场景
在公司干了2年半，有劳动合同，公司以「能力不行」为由辞退，不给补偿。

### 完整对话
```
用户：公司说我不合适，让我明天别来了，不给补偿

AI：您在这家公司工作多久了？有劳动合同吗？

用户：干了2年半，有合同

AI：公司给您的辞退理由具体是什么？

用户：就说能力不行，但之前从来没说过我不行

AI：根据《劳动合同法》，公司以「不能胜任」为由辞退必须：
    1. 证明您不胜任（要有考核标准）
    2. 培训或调岗后仍然不胜任
    3. 提前30天通知或支付1个月代通知金
    
    如果公司没走这些程序，属于违法解除！
    
    ✔ 赔偿金 = 工作年限 × 月工资 × 2倍
    ✔ 您工作2.5年，按3年算
    ✔ 就是3个月工资 × 2 = 6个月工资
    
    您月工资大概多少？

用户：月薪8000

AI：好的，那您的赔偿金初步计算：
    - 工作年限：2.5年（按3年计算）
    - 月平均工资：8,000元
    - 赔偿金：3 × 8,000 × 2 = **48,000元**
    
    我还需要知道：您有公司辞退的书面通知吗？微信聊天记录也行。

用户：有微信聊天记录，领导说的让我明天不用来了

AI：证据有效。
    
    接下来为您生成：
    📄 **劳动仲裁申请书（初稿）**
    📊 **经济补偿/赔偿金计算表**
    📌 **劳动仲裁全流程指引**
    
    ⚠️ 提醒：仲裁时效1年，从知道被辞退之日起算。建议尽快申请。

用户：好，导出Word文档

AI：[调用72-Word文档工程导出国标格式]
```

### 产出物
- 劳动仲裁申请书初稿
- 经济补偿金/赔偿金计算表
- 劳动仲裁全流程指引（管辖、时效、材料）
- 国标Word文档

### 用时参考：10-15分钟

## 示例3：建设工程纠纷（高级功能全流程）

### 场景
某建设工程项目，对方拖欠工程款3555万，涉及优先受偿权起算与期限争议。

### 完整流程
```
第1步 → 通过总控路由描述案情
第2步 → 走70-案件深度分析系统做九步法分析
第3步 → 走87-案卷精读建证据矩阵和风险标记
第4步 → 走88-模拟法庭做三方PK推演
第5步 → 通过72-Word文档工程导出全套文书
```

**详细操作：**

```
用户：工程款被拖欠3555万，有合同，已经完工了对方不给钱

→ 31-总控路由自动匹配到30-建设工程施工合同纠纷

用户：帮我深度分析这个案子

→ 70-案件深度分析系统启动九步法：
  第一步：固定权利请求——请求支付工程款3555万及逾期利息
  第二步：请求权基础——《民法典》第807条（工程款优先受偿权）
  ...（逐层推进）

用户：我把合同、结算单、催款函都上传了，帮我精读

→ 87-案卷精读防漏启动：
  甲表：证据清单（15份证据）
  乙表：要件事实-证据矩阵（9大要件）
  丙表：风险标记——优先受偿权起算时间存在争议

用户：用这些材料做个模拟法庭

→ 88-模拟法庭对抗推演启动：
  第1回合：举证质证
  第2回合：法庭辩论
  第3回合：法官心证
  第4回合：模拟裁判
  输出：攻防清单+弱点扫描+模拟判决

用户：把所有文书导出Word

→ 72-Word文档工程自动排版为国标格式
```

### 产出物（全套）
- 九步法分析报告
- 证据清单与要件矩阵
- 三方对抗记录与弱点扫描
- 模拟裁判文书
- 国标格式全套文书

### 用时参考：约120分钟
