# 律师函信息采录（Demand Intake）

## 目的

起草是下游动作，真正的价值在于前期——提出草率律师函所忽视的问题。谈判筹码、BATNA（最佳替代方案）、底线容忍度、保密义务边界、实际受众。一个发出去之前没有考虑这些因素的律师函，可能比不发更糟。

## 加载上下文

- 加载 `$LEGAL_AGENT_PROFILE_HOME/litigation-legal/profile.md` → 律师函实务规范（保险索赔通知时机、重要性门槛/重大性认定、内部审批流程）、业务图谱（相对方类型、重复对抗模式）、风险定级（预评估重大性）、机构风格。

**重要提示：语气、合规期限、保密标记、签署人不是实务层面的默认设置——需要在下方"本案姿态"步骤中针对每个事项单独确定。**

## 标记说明

- `--full` → 无论重要性启发规则如何，均执行完整采录（适用于希望每次都全面梳理的情形）

## 信息采录框架

### 本案姿态（第一步询问，核心模块之前）

> **本案姿态。** 律师函的语气和条款因案而异，而非实务默认值。请确认：
> - **语气：** 克制 / 明确 / 强硬？（取决于双方关系、金额大小、诉讼可能性）
> - **回复期限：** 根据请求事项，什么是合理的？（支付催告通常14天；整改通知通常30天；停止侵权通知通常7天——但合同或协议可能另有约定）
> - **保密标记：** 是否需要注明"本函仅为调解/和解协商目的"？（诉讼中的和解通讯可依据《民诉法解释》第107条获得一定保护；权利主张通常不适用；需根据具体情况判断——如有疑问请明确标注）
> - **签署人：** 您、客户、总法律顾问/法务总监、委托的外部律师？
> - **仲裁条款检查：** 合同是否约定了仲裁条款？律师函发出前需确认是否有仲裁管辖约定。
> - **管辖法院/仲裁机构：** 合同是否约定了管辖法院或仲裁机构？需确认。

**请勿假设。** 如事项文件中存在先前的律师函往来，请先查阅——它确立了本案的沟通基调。

将答案记录在采录文档中"## 本案姿态"章节（位于"## 当事人"之前）。这些答案将指导后续采录和下游起草工作——如果用户遗漏任何一项，请重新询问，不要回退到实务层面的默认值。

### 核心模块——必问项目（8项）

**1. 律师函类型**
`支付催告 | 违约整改 | 停止侵权 | 离职后义务催告 | 证据保全 | 其他`

**2. 当事人**
- **发函方：** 本公司（如涉及多主体，请指明具体实体）
- **收函方：** 相对方——名称、主体类型、地址
- **收函方实际读者：** 谁会实际阅读？（法务总监？法定代表人？自然人？内部法务？）
- **双方关系：** `客户 | 供应商 | 离职员工 | 竞争对手 | 第三方 | 其他`

**3. 触发事件**
- 发生了什么，何时发生（日期很重要——涉及诉讼时效、通知期限）
- 现有证据（合同、函件、记录、证人）

*参考文书提示："如能提供相关合同、往来函件或证据，起草质量将显著提升。可以通过上传附件分享。"*

**4. 法律/合同依据**
- 具体条款——适用合同的具体章节（如有）
- 准据法（管辖、法律选择条款）
- 所依据的法律条文或规则（占位符亦可——起草时将标注`[待核实：___]`）

**5. 期望结果**
- 具体请求。不是说"解决争议"——而是"于某日前支付X元"、"停止特定活动Z"、"于N天内完成整改"、"返还特定财物"。
- 如有多项请求，请排序（主要请求与备选请求）。

**6. 期限**
- 外部驱动期限（诉讼时效、持续损害期限、业务事件）
- 要求对方履行的期限——参照上方"## 本案姿态"中确认的回复期限；不回退到实务默认值。

**7. 先前接触**
- 是否已非正式提出？何时、何人、以何种形式？
- 对方是否有回应？
- 为何此时升级到律师函？

**8. 发送安排**
- 送达方式（需确认；无实务默认值）
- 签署人——已在"## 本案姿态"中确认
- 抄送——内部相关方、保险公司（如按实务通知时机规则在发函前需先通知保险人）、外部律师

### 战略模块——重要性事项或`--full`时询问

重要性启发规则：如满足以下任一条件，则触发战略模块询问。

- 律师函类型为`停止侵权`、`违约整改`、`离职后义务催告`或`证据保全`
- 期望结果金额≥`$LEGAL_AGENT_PROFILE_HOME/litigation-legal/profile.md`风险定级中的中等严重区间
- 相对方为客户、竞争对手，或根据`$LEGAL_AGENT_PROFILE_HOME/litigation-legal/profile.md`业务图谱属于频繁对抗方
- 用户使用了`--full`参数

**明确跳过选项。** 触发战略模块时，用户可选择不回答。直接询问：

> 根据重要性启发规则，这属于重要事项。战略模块（谈判筹码、BATNA、语气、保密义务审查）是前期价值的主要所在。跳过将导致起草内容不够充分。
> - **现在回答**——完整走一遍战略模块（约5-7分钟）
> - **部分回答**——只回答您目前能够回答的部分
> - **跳过**——仅使用核心模块内容进入起草；我将在采录中标注`战略模块: 已跳过`

如用户选择跳过，采录文件记录如下：

```yaml
战略模块: 已跳过        # 已完成 | 部分完成 | 已跳过
跳过原因: string | null   # 如用户提供了原因则记录
```

起草技能尊重跳过决定——起草前审查仍会执行，但依赖战略模块回答的部分将标注`[专业核实：谈判筹码/语气/保密义务未在采录中采集]`。`/demand-draft`命令也将再次提示，询问用户是否希望在起草前完成战略模块。

**9. 谈判筹码与BATNA（最佳替代方案）**
- 我方的谈判筹码是什么？（合同权利、事实优势、商业声誉等）
- 如对方拒绝，我们将如何应对？准备好诉讼了吗？公开披露？接受较小让步？
- 对方可能的BATNA——他们最好的替代方案是什么？（如果他们认为我们不会起诉，律师函就缺乏力度。）
> **注：** BATNA（Best Alternative to a Negotiated Agreement，最佳替代方案）是谈判分析核心概念，中文表述为"最佳替代方案"，保留英文缩写但加中文说明。

**10. 底线容忍度**
- 如事件公开，声誉风险如何？
- 先例风险——本函是否设定了可能影响其他事项的模式？
- 监管/信息披露影响（这是否属于可能影响信息披露义务的争议？）
  - 上市公司：依据《证券法》第78条及相关信息披露规则判断
- 保险影响——是否需要先向保险公司报案？未及时通知是否影响理赔？

**11. 语气姿态**
- 已在"## 本案姿态"中确认。此处如用户选择的语气与事实支撑力度不符，请提示权衡考量。
- 值得明确指出：强硬的语气会损害双方关系。如果希望保持商业合作关系但同时需要保护法律立场，"克制"通常是更合适的选择。

**12. 和解通讯保护状态**
> ⚠️ **重要差异提示：** 美国联邦证据规则FRE 408覆盖诉前和诉中和解通讯；中国《民诉法解释》第107条仅覆盖**诉讼中**的和解通讯。律师函发出时尚未进入诉讼程序，本函不适用该保护条款。
- 本函是否需要注明"本函仅为调解/和解协商目的"？
- 如已进入诉讼阶段，需检索确认相关保护规则——通过**元典法规案例检索接口和工具**检索《民诉法解释》第107条及相应司法实践。
- 保护依附于行为和语境，而非仅仅依赖标注。标注是"双保险"选择。

**13. 保密义务审查**
- 我方内部分析中有哪些内容**绝不能**出现在函件中？（未经核实的事实、我方对案件的疑虑、策略推理、先前和解讨论）
- 中国《律师法》第38条规定律师对执业活动中知悉的商业秘密、个人隐私予以保密；《刑事诉讼法》第46条也规定了辩护律师的保密义务。
- 一句措辞不当的表述可能泄露应保密的工作成果。请明确指出必须排除的内容。

**14. 自认风险与权利放弃风险**
- 函件中是否有任何内容可能被对方日后定性为承认事实或责任？
- 本函是否可能无意中被理解为满足或接受对方某项权利？（以物抵债/权利放弃风险：依据《民法典合同编通则解释》第27-28条及《民法典》第557条审查）
- ⚠️ 中国无"privilege waiver"（保密义务弃权）概念，但需注意保密义务边界——律师函内容可能超出保密范围被对方利用。

### 法律检索工具

### 关键中国法条索引

| 事项 | 法规依据 |
|------|----------|
| 诉讼时效 | 《民法典》第188-199条（3年普通时效/特殊时效） |
| 和解通讯保护（仅限诉讼中） | 《民诉法解释》第107条 |
| 以物抵债/权利义务终止 | 《民法典》第557条、《民法典合同编通则解释》第27-28条 |
| 律师保密义务 | 《律师法》第38条、《刑事诉讼法》第46条 |
| 上市公司信息披露 | 《证券法》第78条及相关信息披露规则 |
| 保险索赔通知 | 《保险法》第21-22条 |
| 争议解决方式 | 《仲裁法》、《民事诉讼法》管辖相关规定 |

### 中国法与美国法主要差异提示

1. **和解通讯保护范围不同**：美国FRE 408覆盖诉前+诉中；中国《民诉法解释》第107条仅覆盖诉讼中。律师函发出前通常不适用。
2. **无"Privilege Waiver"概念**：中国律师保密是义务而非权利，但需注意保密义务边界，律师函内容可能被对方利用。
3. **无"Without Prejudice"标记制度**：中国最接近做法是注明"本函仅为调解/和解协商目的"，但保护力度弱于英美法WP标记。
4. **诉讼时效制度**：中国采用诉讼时效（可变期间），不同于美国固定时效（Statute of Limitations）。
5. **无一般性律师费转移规则**：中国仅在特定法定情形下支持由败诉方承担律师费。
