# 执行案件助手 Skill 安装说明

**版本**：v1.1.0（市场上传版·无二进制文件）｜ **适用**：WorkBuddy / Kimi Code CLI 等支持 SKILL.md 的 AI 智能体环境

## 这是什么

执行领域全流程律师助手（债权人 + 被执行人/案外人双向）：
- **案件诊断**：描述案情 → 定位执行阶段 → 输出行动清单+期限警告
- **流程导航**：申请→查控→处置→惩戒→终本→恢复→拒执罪 全周期指引
- **文书生成**：19 份执行文书模板智能填空，**只输出 Word（docx）成品**；强制执行申请书默认同时出 **传统叙述式 + 要素式表格版** 两版
- **法条类案联动**：生成文书时自动检索配套法条与拒执罪/执行类案

## ⚠️ 首次使用必做（一步）

本上传版为规避平台二进制文件限制，19 份 docx 模板以 base64 文本存放（`assets/templates_b64/`）。安装后请让 AI 执行：

```bash
python3 scripts/bootstrap_templates.py
```

一键还原全部模板到 `assets/templates/`（已还原则自动跳过，只跑一次）。

## 安装方法

**WorkBuddy**：技能市场 → 添加技能 → 上传技能，选择整个文件夹或压缩包。
**Kimi Code CLI**：将整个文件夹复制到 `~/.kimi/skills/` 下即可。

**环境要求**：Python 3.8+，依赖 `python-docx`（文书生成脚本用）。
