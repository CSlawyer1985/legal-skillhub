# 财产调查实战策略

## 调查阶梯（从免费到深入）

**第一层：法院网络查控（总对总）**
覆盖：主要银行存款、微信零钱/支付宝余额、车辆、证券、部分不动产、部分保险
盲区：流水明细、已销户账户、理财通/余额宝明细、保单现金价值、现金、代持财产

**第二层：调查令补盲（模板2/3/4）**
| 查什么 | 用哪个 | 关键写法 |
|---|---|---|
| 银行开户+流水+销户 | 调查令（银行流水） | 期间覆盖疑似转移前后1-3年；要求含已销户账户及销户前流水 |
| 微信实名+零钱+流水 | 调查令（微信） | 被调查人=财付通支付科技有限公司；写明微信号/绑定手机号 |
| 支付宝账户+流水 | 调查令（支付宝） | 被调查人=支付宝（中国）网络技术有限公司 |

**第三层：悬赏与审计**
- 悬赏令（模板5）：人找不到或财产找不到时用；写明赏金比例（常见执行到位金额 5%-10%）
- 对公司被执行人：申请审计调查（账册去向、抽逃出资线索）

**第四层：外围摸排（律师自己做）**
- 婚姻登记 → 夫妻共同债务/共同财产线索
- 工商内档 → 股东出资、股权转让记录（认缴未实缴=追加对象）
- 裁判文书网/执行信息公开网 → 被执行人其他案件、债权（可代位/参与分配）
- 抖音/朋友圈/小红书 → 高消费痕迹（违反限高令证据）
- 社保/个税缴纳单位 → 工资收入线索

## 发现转移财产后的组合拳
1. 无偿/低价转让 → 撤销权之诉（模板15）+ 同步保全（模板7）
2. 转移至案外人名下 → 案外人代持证据固定 → 拒执罪控告（模板11/12）
3. 离婚析产转移 → 确认夫妻共同债务之诉（模板16）+ 撤销离婚协议财产条款

## 常被忽略的可执行财产
- 保单现金价值（模板6）、公积金、养老金（超基本生活部分）、知识产权、域名/虚拟财产、应收账款（发履行到期债务通知）、拆迁补偿款、继承份额
