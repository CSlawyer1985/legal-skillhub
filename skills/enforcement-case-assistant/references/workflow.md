# 执行全流程指引

## 全流程地图

```
生效文书 → ①申请执行（2年时效）→ ②立案查控（总对总网络查控）
→ ③财产处置（评估→拍卖/变卖/以物抵债）→ ④案款发放
   ↘ 无财产 → ⑤惩戒施压（限高/失信/拘留罚款）→ ⑥终本
→ ⑦终本后管理（每6个月查控/发现财产随时恢复）→ ⑧恢复执行
→ ⑨拒执罪追责（移送/控告/自诉）
```

## 各阶段要点

### ① 申请执行
- **管辖**：一审法院，或与一审法院同级的被执行财产所在地法院
- **时效**：2 年，自法律文书规定履行期间最后一日起算；分期履行的自每期届满起算
- **材料**：强制执行申请书（模板1）、生效文书原件、生效证明、申请人身份证明
- 同时提交财产线索清单，争取立案即查控

### ② 立案查控
- 法院「总对总」网络查控：银行存款、微信/支付宝余额、车辆、证券、不动产（部分地区）
- 查控之外的盲区用调查令补：流水明细、销户记录、理财、保单（模板2/3/4）
- 申请人应同步自行摸排：婚姻状况（追配偶）、工商登记（追股东）、社交账号消费痕迹

### ③ 财产处置
- 查封 → 评估（网络询价/委托评估）→ 一拍（70%起）→ 二拍（再降≤20%）→ 变卖 → 以物抵债
- 唯一住房：符合法定条件可执行（预留 5-8 年租金或提供周转房）
- 保单现金价值可强制退保划扣（模板6）；理财、公积金、养老金（预留基本生活费外）均可执行

### ④ 案款发放
- 多个债权人：查参与分配（references/debtor-side.md 亦有）
- 优先受偿顺序：执行费用→优先权人（抵押等）→普通债权按比例

### ⑤ 惩戒施压
- 限高+失信（模板9）是基础动作，立案后即可申请
- 拒不申报财产、隐匿转移、违反限高令 → 拘留罚款（模板8）
- 对法定代表人/实控人的「限制出境」也可申请

### ⑥ 终本
- 条件：穷尽调查措施无财产可供执行
- 终本≠结束：5 年内法院每 6 个月自动网络查控；申请人发现财产随时申请恢复（不受 2 年时效限制）

### ⑦-⑧ 恢复执行
- 发现新财产线索 → 提交线索+恢复执行申请 → 恢复后重新查控处置
- 常见恢复线索：新开账户、新购房产车辆、股权变动、微信支付宝活跃流水

### ⑨ 拒执罪追责（刑法第313条）
三条路径，按证据强度选择：
1. **法院移送**（模板10）：成本最低，执行法官移送公安
2. **公安控告**（模板11/12）：自己备好证据链控告
3. **刑事自诉**（模板13/14）：前置条件=曾控告且公安/检察不予追究（需不予立案决定书等书面凭证）
构成要件关键：**有能力执行而拒不执行**——隐藏、转移、故意毁损财产，无偿转让、明显不合理低价转让，担保人隐匿已担保财产等

## 扩大责任主体的三把刀
1. **追加配偶**：执行依据只有一方 → 确认夫妻共同债务之诉（模板16）；或直接申请追加（各地口径不一，诉讼更稳）
2. **追加股东**：公司无财产 → 未实缴出资股东在未出资范围内担责（认缴加速到期：公司不能清偿到期债务）；抽逃出资、一人公司财产混同
3. **撤销权之诉**（模板15+7）：无偿转让/明显低价转让/放弃债权 → 撤销后执行该财产
