# 调查令申请书（支付宝）

> **使用场景**：需调取对方支付宝账户、余额、余额宝及交易流水
> **注意事项**：被调查人写支付宝（中国）网络技术有限公司

## 占位符清单（2处）

- `【案由：被代理人姓名 与  被申请人姓名案由 】`
- `【男/女】`
