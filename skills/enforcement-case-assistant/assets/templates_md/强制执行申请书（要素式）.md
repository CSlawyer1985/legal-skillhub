# 强制执行申请书（要素式·官方表格版）

> **使用场景**：与申请执行传统叙述式并行，系最高法推广的要素式表格文书，多数法院执行立案窗口优先要求。与谁使用：拿到生效法律文书后向执行法院立案庭提交。
> **注意事项**：① 表格结构、要素、格式**不得改动**，只可填内容/扩容栏目（模板说明第4条明确要求）；② 勾选项把对应项的□改为"√"（不用☑，避免字体缺字）；③ 与案件无关的栏目填"无"或留空；④ 自然人/法人两套当事人栏目只填适用的一套；⑤ 生效日期以《生效证明》为准填写；⑥ 需随附：身份证明材料、生效法律文书副本及生效证明、（继承/承受权利证明如有）；⑦ 追加内容必须沿用表格样式：段落用 pStyle=5、run 加 color=231F20，确保字体大小与原表一致。

## 表格结构（19行，填写指引）

| 栏目 | 填写内容 |
|---|---|
| 说明 | 固定文本，不改动 |
| 当事人信息 | — |
| 申请执行人（自然人） | 自然人时填：姓名/性别/出生日期/民族/工作单位/职务/电话/住所地/经常居住地/证件/银行账号/开户名/开户行；法人申请时留空 |
| 申请执行人（法人、非法人组织） | 名称/住所地/注册地/法定代表人/职务/电话/统一社会信用代码/银行账号/类型（勾选）/所有制性质（勾选） |
| 委托诉讼代理人 | 有☑：姓名/单位/职务/电话/代理权限（一般授权□ 特别授权□，代为申请执行须特别授权） |
| 被执行人（自然人） | 同自然人格式 |
| 被执行人（法人、非法人组织） | 同法人格式（无银行账号栏） |
| 执行依据信息 | — |
| 文书类型 | 民事类：判决书□ 裁定书□ 调解书□ 支付令□ / 刑事类 / 行政类 / 仲裁公证类（勾选） |
| 执行依据作出机构 | 如：安徽省怀远县人民法院 |
| 案由 | 如：合伙合同纠纷 |
| 文书号 | 如：（2025）皖0321民初11805号 |
| 生效日期 | 以生效证明为准 |
| 执行依据判项主文 | 抄录判决/调解主文及诉讼费负担 |
| 申请执行事项（概括描述） | 一段概括请求+事实理由 |
| 申请执行事项（勾选+金额） | 金钱给付☑：本金/一般债务利息/迟延履行利息/其他费用（受理费、执行费）；或行为执行/交付特定物 |
| 是否有诉前/诉讼保全 | 有☑（写保全案号+最早到期时间）/ 无☑ |
| 其他财产线索 | 逐条列明（房产、土地、设备、股权、应收账款等） |

落款：申请执行人（签字、盖章）+ 日期（表格下方固定文本，手签）。
