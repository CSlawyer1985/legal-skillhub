## 审查要点

### 规则1：摘要附图与说明书附图的依赖关系
- 说明书附图章节无图片 → 摘要附图章节也不得有图片
- 说明书附图章节有图片 → 摘要附图章节必须有且仅有1张图片
- 检查方法：从 `image_analysis_<timestamp>.json` 获取"说明书附图"和"摘要附图"的图片数量进行对比

### 规则2：摘要附图数量限制
说明书附图有图片时，摘要附图只能有1张图片。
- 说明书附图数量 > 0 且摘要附图数量 = 0 → 提醒用户从说明书附图中引用1张图作为摘要附图
- 说明书附图数量 > 0 且摘要附图数量 > 1 → 提醒用户仅保留1张最能说明技术方案主要技术特征的图片，删除其余

### 规则3：摘要附图来源约束
摘要附图必须是说明书附图章节中的其中一张图，不得使用其他来源的图片。
- 检查方法：从 `image_analysis_<timestamp>.json` 获取摘要附图的源文件，确认其也在说明书附图的源文件列表中

### 规则4：附图标记编号与一致性（委托给图片审查子Agent）
说明书附图中的附图标记应使用阿拉伯数字编号。说明书文字部分未提及的附图标记不得在附图中出现，反之亦然。
- 元数据级前置检查：从 `section_description_<timestamp>.json` 提取所有附图标记模式（如"图1"、"(1)"、"（1）"等），整理后传递给图片审查子Agent供交叉验证

### 规则5：专利类型与附图要求
发明专利申请可以无附图，但实用新型专利申请必须有附图。
- 检查方法：从说明书文本判断申请类型（出现"实用新型"→实用新型；仅出现"发明"→发明）
- 若为实用新型且说明书附图数量 = 0 → 问题

### 规则6：附图注释规范（委托给图片审查子Agent）
说明书附图中除必需的词语外不应含有其他注释；流程图、框图应在框内给出必要的文字或符号。

### 规则7：说明书附图不得有重复图片
同一张图片（以源文件名/哈希为判定依据）在说明书附图章节中最多出现1次。
- 若同一源文件在说明书附图中出现多次 → 重复图片问题

### 规则8：摘要附图章节无文字时的处理
若摘要附图章节有图片但无任何文字，应添加批注提醒用户。批注自动定位到"摘要附图批注"锚定文字上。
- 输出格式：`action_type` 为 `comment`，`context` 填写简要描述，`highlight_text` 无需填写

### 规则9：说明书附图每幅图应有对应名称
说明书附图中的每一幅图片下方应有文字标注（如"图1"、"图2"等）。缺少名称或格式不符合"图N"规范的均属问题。

### 规则10：说明书附图应当顺序编号
说明书附图应按阿拉伯数字从"图1"开始连续顺序编号，不得跳跃、乱序或重复。
- 检查方法：提取所有"图N"中的数字N，验证是否从1开始连续递增

### 规则11：附图说明与图片内容的对应性（委托给图片审查子Agent）
附图说明章节中的文字描述应与说明书附图中图片的实际内容相对应。
- 元数据级前置检查：提取附图说明内容，解析每幅图的说明文字传给图片审查子Agent；同时检查附图说明中提及的图号与说明书附图中实际图号是否一致（多说/少说均为问题）

### 规则12：说明书附图章节无锚定文本时的处理
若说明书附图章节无可用锚定文字，使用页眉中的"说明书附图"章节标题作为批注定位点。`context` 和 `highlight_text` 均设为"说明书附图"。

## 返回图片列表信息给主Agent

完成规则1-3、5、7-10、12的检查后，须执行以下步骤（禁止自行创建图片审查子Agent，由主Agent在第7批统一创建）：

1. 从 `image_analysis_<timestamp>.json` 获取"说明书附图"图片列表
2. 若说明书附图数量 N > 0：
   - 整理每张图片的绝对路径、逻辑名称/序号、fig_text_name（如图1、图2）、附图标记列表、附图说明文字列表，通过返回值传递给主Agent
   - 主Agent将根据返回信息在第7批动态创建N个图片审查子Agent，并行执行规则4、6、11
3. 若 N = 0：在返回值中告知主Agent，跳过规则4、6

## context 字段锚定规范

**核心原则**：`context` 必须是文档 `extracted_text` 中实际存在的文本（逐字 verbatim copy），禁止使用自行构造的描述性文本。

| 规则 | 问题类型 | 错误 context | 正确 context |
|:-----|:---------|:-------------|:------------|
| 规则1/3/8 | 摘要附图相关问题 | 描述性文本 | 简要描述（自动定位到"摘要附图批注"锚定文字） |
| 规则4 | 附图标记缺失 | 描述性文本 | 图号实际文本（如"图1"） |
| 规则5 | 实用新型缺附图 | 描述性文本 | 说明书中"实用新型"字样所在句子 |
| 规则7 | 附图重复 | 描述性文本 | 重复图片对应的图号（如"图2"） |
| 规则9 | 附图缺少名称 | 描述性文本 | 相邻图的图号或章节标题 |
| 规则10 | 编号不连续 | 描述性文本 | 编号跳跃处的图号（如"图4"） |
| 规则11 | 附图说明缺失 | 描述性文本 | 对应图号实际文本（如"图3"） |
| 规则12 | 说明书附图无锚定 | 描述性文本 | `"说明书附图"`（页眉章节标题） |

对于图片级问题（规则4、6、11），汇总时必须逐条检查并修正 context：若包含描述性或非文档原文内容，必须替换为文档实际文本。此步骤必须在保存最终JSON前执行。
