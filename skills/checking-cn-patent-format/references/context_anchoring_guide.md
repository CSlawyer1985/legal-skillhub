# Context锚定最佳实践指南

**版本**: v2.0 (2026-05-10 优化版)  
**目的**: 确保所有审查Agent输出的context字段符合锚定要求（摘要附图section可使用简要描述，其余section必须verbatim copy）  
**适用对象**: 所有参与专利申请文件审查的Agent（Agent 1-13）

---

## 核心原则

### 必须遵守（MANDATORY）

1. **Context必须是文档extracted_text中的逐字复制（verbatim copy）**（摘要附图section例外：可填写简要描述）
2. **禁止Agent自行构造、改写、概括或总结任何文本作为context**
3. **Context长度不得超过200字符**
4. **Context中禁止包含换行符`\n`**
5. **如果确实无法找到精确锚点文本，使用最接近的实际文本并设置action_type="comment"**

### 绝对禁止（FORBIDDEN）

以下类型的文本**不得**作为context：

| 类型 | 错误示例 | 正确做法 |
|:-----|:-----------|:-----------|
| 描述性文字 | "摘要附图引用了不存在的图5" | "摘要附图来源异常"（摘要附图类问题可使用简要描述） |
| 分析性文字 | "说明书附图中声明7张但实际只有4张" | "由图1至图7给出" |
| 技术参数类 | "image1.png (96 DPI)" | "图1" |
| 概括性文字 | "该处存在编号重复问题" | "图2" |
| 超长文本 | (>200字符的任意文本) | 截断至200字符内 |
| 包含换行 | (含\n的文本) | 拆分为多条审查意见 |
| 添加原文不存在的标点 | "所述设备壳体（1）的内部固定安装有CPU、"（原文无句号但添加了"。"） | 逐字复制原文标点 |

## 分场景锚定策略库

### 场景1：摘要审查（Agent 1-2）

#### 摘要格式问题
**问题类型**：摘要字数超标、缺少技术要点等

**推荐锚定**：
```json
{
  "context": "本发明公开了一种",
  "highlight_text": "本发明公开了一种",
  "issue": "摘要开头使用了'本发明公开了一种'，应改为'本发明的实施例公开了一种'"
}
```

#### 摘要商业用语
**问题类型**：摘要中包含商业宣传用语

**推荐锚定**：
```json
{
  "context": "千杯不醉的",
  "highlight_text": "千杯不醉",
  "action_type": "comment",
  "issue": "摘要中使用了商业宣传用语'千杯不醉'"
}
```

### 场景2：权利要求书审查（Agent 3-8）

#### 格式检查问题（Agent 3-4）
**问题类型**：句号使用错误、序号格式不规范

**推荐锚定**：
```json
{
  "context": "所述设备壳体（1）的内部固定安装有CPU、导料挤压管（2）",
  "old_text": "CPU、",
  "new_text": "",
  "issue": "权利要求正文中使用了顿号连接技术特征，应改为逗号或分号"
}
```

**关键约束**：权利要求书正文中仅允许在权利要求的结尾处使用句号"。"，正文中间禁止使用句号。

#### 所述引用基础问题（Agent 5）
**问题类型**：首次出现使用"所述"、引用基础缺失

**推荐锚定**：
```json
{
  "context": "所述排油口",
  "old_text": "所述排油口",
  "new_text": "排油口",
  "issue": "'排油口'首次出现不应使用'所述'"
}
```

#### 引用与主题问题（Agent 6）
**问题类型**：多引多、引用不同独立权利要求

**推荐锚定**：
```json
{
  "context": "根据权利要求3-4所述的",
  "highlight_text": "根据权利要求3-4所述的",
  "action_type": "comment",
  "issue": "权利要求5引用权利要求3-4，存在'多引多'问题"
}
```

### 场景3：说明书审查（Agent 9-10）

#### 撰写规范问题（Agent 9）
**问题类型**：错别字、用语不当、缺少章节

**推荐锚定**：
```json
{
  "context": "所述设备壳体（1）的内部固定安装有CPU、导料挤压管（2）",
  "highlight_text": "CPU",
  "action_type": "comment",
  "issue": "使用了非技术特征词汇'CPU'"
}
```

**"本发明"批量替换策略**：
- 推荐策略A：全部使用comment类型，建议用户使用Word查找替换功能
- 禁止对超过5处的"本发明"问题全部使用replace类型

#### 公开充分性问题（Agent 10）
**问题类型**：技术手段含糊不清、缺少关键步骤

**推荐锚定**：
```json
{
  "context": "通过挤压部件进行挤压处理",
  "highlight_text": "挤压部件",
  "action_type": "comment",
  "issue": "技术手段'挤压部件'描述含糊不清，未说明具体结构和操作方式"
}
```

### 场景4：全文跨章节审查（Agent 11-12）

#### 术语不一致问题（Agent 11）
**问题类型**：同一术语在不同章节使用不同表述

**推荐锚定**：
```json
{
  "context": "本实用新型",
  "highlight_text": "本实用新型",
  "action_type": "comment",
  "issue": "摘要使用'本实用新型'但说明书使用'本发明'，申请类型用语不一致"
}
```

#### 权利要求书得不到说明书支持（Agent 12）
**问题类型**：权利要求的技术方案在说明书中无充分支持

**推荐锚定**：
```json
{
  "context": "碳毡电极",
  "highlight_text": "碳毡电极",
  "action_type": "comment",
  "issue": "权利要求11保护'碳毡电极'，但说明书中仅详细公开了'山茶油设备'，权利要求得不到说明书支持"
}
```

### 场景5：附图审查（Agent 13）

#### 元数据级问题（Agent 13自身负责）
**问题类型**：摘要附图来源异常、编号不连续、缺少名称

**摘要附图类问题锚定**：
摘要附图section的批注不再寻找锚定文字，而是自动在摘要附图章节结尾插入"摘要附图批注"文字作为批注的锚定文字。因此context字段可填写与问题相关的简要描述文本，无需为文档verbatim copy。

```json
{
  "context": "摘要附图来源异常",
  "highlight_text": null,
  "issue": "摘要附图标记为'图5'，但说明书附图中不存在图5"
}
```

**说明书附图元数据级问题锚定**（仍需verbatim copy）：
```json
{
  "context": "图5",
  "highlight_text": "图5",
  "issue": "说明书附图中不存在图5"
}
```

**错误示例（绝对禁止）**：
```
context = "摘要附图图5（源文件：image1.png）"  // 包含分析性源文件信息
context = "图1\n图2\n图3"  // 包含换行符
```

#### 图片级问题（图片子Agent负责）
**问题类型**：附图标记不一致、图片质量问题

**推荐锚定**：
```json
{
  "context": "图1",
  "highlight_text": "图1",
  "action_type": "comment",
  "issue": "图1分辨率不足：当前96 DPI，最低要求300 DPI"
}
```

#### 说明书附图章节无锚定文本（规则12场景）
**问题类型**：说明书附图章节中没有文字内容，无法定位到具体锚定文本

**推荐锚定**：
```json
{
  "context": "说明书附图",
  "highlight_text": "说明书附图",
  "action_type": "comment",
  "issue": "说明书附图章节缺少可锚定的文字内容，建议添加对附图的文字标注"
}
```

## 高级技巧

### 技巧1：长文本截断策略

当原始句子超过200字符时，以关键词为中心向两边扩展截断：

```python
def truncate_context(long_text, keyword, max_len=200):
    if len(long_text) <= max_len:
        return long_text
    kw_pos = long_text.find(keyword)
    if kw_pos == -1:
        return long_text[:max_len-3] + '...'
    half_max = (max_len - len(keyword)) // 2
    start = max(0, kw_pos - half_max)
    end = min(len(long_text), kw_pos + len(keyword) + half_max)
    result = long_text[start:end]
    if start > 0:
        result = '...' + result
    if end < len(long_text):
        result = result + '...'
    return result
```

### 技巧2：多关键词提取优先级

| 优先级 | 关键词类型 | 示例 | 权重 |
|:------:|:---------|:-----|:----:|
| 1 | 图号 | 图5、Fig.1 | 10 |
| 2 | 附图标记编号 | （34）、201 | 8 |
| 3 | 特殊术语 | CPU、UFO | 6 |
| 4 | 章节名称 | 权利要求书、背景技术 | 4 |
| 5 | 组件名称 | 导料挤压管、转动空心管 | 3 |

### 技巧3：边界案例处理

| 案例 | 处理方式 | 示例 |
|:-----|:---------|:-----|
| 纯理论性检查项 | 使用章节标题，action_type=comment | 规则2.4 |
| 跨段落问题 | 选择最具代表性的实例 | 编号体系混乱 |
| 图片独有问题 | 使用图号 | 分辨率不足 |
| 全文范围问题 | 使用"全文"作为section | 术语一致性 |
| 无法定位的问题 | 在issue中说明原因，跳过批注 | 极少数情况 |

## 自检清单

在提交输出前，请逐条确认：

### 格式自检
- [ ] 输出是有效的JSON数组（不是单个对象）
- [ ] 数组不为空（除非确认无问题）
- [ ] 每条记录都有必填字段（section, context, action_type, issue, suggestion）
- [ ] replace类型有old_text和new_text
- [ ] 所有字符串值都不为null或空字符串

### Context质量自检
- [ ] context长度 <= 200字符
- [ ] context中无换行符（\n或\r）
- [ ] context不是Agent构造的描述性文字（摘要附图section例外：可使用简要描述）
- [ ] context看起来像是文档中的原始句子/片段（摘要附图section例外：可为简要描述）
- [ ] highlight_text是context的子集或相同
- [ ] old_text是context的子串（replace/delete类型）
- [ ] context中无HTML/XML标签
- [ ] context中无原文不存在的标点符号

### 语义自检
- [ ] section字段与实际问题所在章节匹配
- [ ] action_type与问题性质匹配
- [ ] issue和suggestion内容清晰、可操作
- [ ] suggestion的修改方向与issue诊断一致
- [ ] old_text→new_text的替换与issue描述的问题一致

## 常见错误及修正

### 错误#1：过度概括
```
错误：context = "说明书标题与实际主题不符"
正确：context = "一种用于液流电池的碳毡电极及电堆"  （标题原文）
```

### 错误#2：包含分析结论
```
错误：context = "图5不存在于说明书附图列表中"
正确（摘要附图类问题）：context = "摘要附图来源异常"（简要描述，批注自动定位到"摘要附图批注"锚定文字）
正确（说明书附图类问题）：context = "图5"（说明书附图章节实际存在的文本）
```

### 错误#3：混合来源信息
```
错误：context = "image3.png重复出现两次（均标记为图2）"
正确：context = "图2"  （第二次出现图2的位置）
```

### 错误#4：超长未截断
```
错误：context = "根据本发明实施例所述的一种山茶油双螺杆低温冷榨设备..." (300字符)
正确：context = "...一种山茶油双螺杆低温冷榨设备，其特征在于..." (198字符)
```

### 错误#5：使用非文档字符
```
错误：context = "圆牌27"  （如果文档中实际是"圆盘27"）
正确：context = "圆盘27"  （必须与文档完全一致，即使文档本身有错别字）
```

### 错误#6：添加原文不存在的标点
```
错误：context = "所述设备壳体（1）的内部固定安装有CPU、导料挤压管（2）。"  （原文无句号）
正确：context = "所述设备壳体（1）的内部固定安装有CPU、导料挤压管（2）"  （逐字复制原文）
```
