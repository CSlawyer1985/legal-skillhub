# 政采响应文件合规检查专家 · 测试用例

> 用于回归验证技能的"精准度"与"丝滑度"。每个用例给输入要点 + 期望命中 + 易错点。覆盖四级判定、必查盲区（含政采特有政策功能）、多轮状态、内置库离线、边界校准、招投标硬隔离。

## 用例 T01 · 完整清单生成（基础）
- **输入**：提供完整采购文件关键要求（保证金/授权/营业执照/份数/密封/有效期 + 资质清单 + 截止时间，竞争性磋商）
- **期望**：生成 🔴/🟡/🟢/⏰ 四级清单；🔴 含保证金/授权/密封/份数/报价超预算；输出 📌项目回显；跑完五类必查盲区无遗漏
- **易错点**：漏掉"密封""份数"等低级高危项（盲区②）；未回显项目档案

## 用例 T02 · 必查盲区·电子化平台专项
- **输入**：声明"本次电子化平台"，但未给 CA/签章/文件大小信息
- **期望**：清单含 🖥️电子化平台专项，且红字标注「⚠️ 未确认 CA/签章/文件大小，该项风险未知」
- **易错点**：按纸质流程查，漏掉电子化平台专属必检项（盲区④）

## 用例 T03 · 必查盲区·政策功能（中小声明函/信用查询）
- **输入**：声明"专门面向中小企业"，但未给中小企业声明函与信用查询结果
- **期望**：清单 🟡 含中小企业声明函与信用双网查询，且红字标注「⚠️ 未确认 中小企业声明函/信用记录，该项风险未知」
- **易错点**：漏掉政采特有政策功能盲区（盲区③），按普通招投标思维查

## 用例 T04 · 资质临界·截止日当日到期（FS-1 变体）
- **输入**：资质证书有效期至响应截止当日
- **期望**：标⚠️不擅自升🔴；建议续期/澄清
- **易错点**：直接判无效→🔴（违反 §5 分级不越权）

## 用例 T05 · 格式项挂无效响应后果
- **输入**：采购文件"未胶装装订的响应文件按无效响应处理"
- **期望**：装订动态升🔴，纳入无效响应清单
- **易错点**：当🟢格式项忽略（违反 标尺 动态规则）

## 用例 T06 · 电子化平台未提前上传
- **输入**：计划截止前 1 小时才上传
- **期望**：标🔴级时效风险，强制建议提前 4h 上传并下载验证
- **易错点**：当普通格式项

## 用例 T07 · 中小企业声明函数据存疑（FS-1 / 红线）
- **输入**：货物项目声明函按"供应商自身"划型，且营业收入与佐证不一致
- **期望**：标⚠️并强烈提示核对事实，提示不实触发第77条处罚，建议撤回更正；不轻判为🟢
- **易错点**：当普通格式瑕疵放过（违反 政策功能真实性红线）

## 用例 T08 · 政采规则对照·报价与异常低价（FS-4）
- **输入**：报价明显低于其他供应商但未超预算
- **期望**：不判"低于成本否决"（政采无此规定），标🟢或提示"可能要求说明合理性"；若超预算则🔴出局
- **易错点**：照搬招投标"低于成本应否决"

## 用例 T09 · 招投标硬隔离（红线）
- **输入**：用户问"依法必须招标的工程施工项目废标条款"
- **期望**：拒绝并引导至「投标文件合规检查助手（bidding-compliance-advisor）」，不引《政府采购法》处理工程招投标
- **易错点**：跨体系引用政采法处理招投标（行业笑柄级错误）

## 用例 T10 · 不捏造（边界）
- **输入**：一份条款中性的正常采购文件
- **期望**：清单项均基于真实条款；不强行把中性表述说成无效响应项
- **易错点**：为凑数硬判违规（违反 §5 "只检查不捏造"）

## 回归红线
- 不得编造不存在的无效响应项（§5 护栏）。
- 法条只给方向/条号，不写定论条文；附现行有效性核验。
- 风险分级不越权（🔴≠必然无效响应）。
- 清单 >15 项须折叠 🟢（输出长度控制）。
- 政策功能/电子化平台/联合体等盲区未确认须红字警告，不得静默假装查完。
- 招投标问题硬隔离，绝不跨体系引用。
- 中小企业声明函/信用记录等真实性红线须重点提示，不得轻判。
