# 合规检查判定标尺（检测引擎核心 · 政府采购版）

本文件是 SKILL.md §3 的**完整展开**。生成检查清单时，**四级必须逐类过**，不得只看"签字盖章"这类明显无效项，也不得漏掉"政策功能真实性""信用查询""电子化平台 CA/签章"等隐蔽高危点。

> ⚠️ **时效性**：本标尺整理截止 **2026-07**，法规/平台惯例可能变化。涉及法条的结论须附核验提示（见 `legal_core.md`），以现行有效法 + 外部知识库核实为准。

---

## 级别 🔴 · 无效响应/废标风险项（一项不满足即无效响应/废标）

| 项目 | 内容 |
|---|---|
| **判定标准** | 采购文件明确列为"★实质性条款 / 无效响应 / 废标 / 投标无效 / 不可偏离"的条目；或法定强制要件（响应保证金、授权、营业执照/身份证明、联合体协议等）缺失即丧失资格；或报价超过预算/最高限价；或信用记录不合格；或中小企业声明函弄虚作假 |
| **典型内容** | 响应保证金（金额/形式/到账）、法定代表人授权委托书（原件+签字+公章）、营业执照或事业单位法人证书、响应函/报价函签字盖章、响应文件份数与密封（纸质）、报价（超预算/最高限价即出局）、未响应★实质性要求、迟到、信用中国/中国政府采购网失信记录、进口产品未经财政核准、专门面向项目但供应商非中小企业、强制节能品目未提供认证 |
| **误判边界** | ❌ 把"采购文件写了'须'但非★号"的普通要求**误升**为🔴；✅ 仅当文件**明示**无效响应/废标或属法定强制要件才定🔴。存在歧义时标注"建议澄清确认"，不擅自升级 |
| **风险** | 🔴 高危；必须 100% 到位 |

## 级别 🟡 · 资质与政策功能文件项（缺失/不实→无效响应或丧失优惠）

| 项目 | 内容 |
|---|---|
| **判定标准** | 证书、业绩、人员、财务等"证明履约能力"的材料；以及政采特有的**政策功能证明**——缺失或不实直接影响资格、评审优惠，甚至触发处罚 |
| **典型内容** | 各类资质证书、近 X 年类似业绩合同、财务审计报告、人员注册证/职称、**中小企业声明函（划型+数据真实）**、**监狱企业证明**、**残疾人福利单位声明函**、**节能/环境标志产品认证证书**、**信用中国+中国政府采购网查询截图**、**进口产品财政核准文件**、联合体各方资质 |
| **误判边界** | ❌ 把"中小企业声明函数据存疑"轻判为普通格式瑕疵；✅ 声明函须与佐证事实一致，**不实构成"提供虚假材料谋取中标成交"（政府采购法第77条）**，须标⚠️并强烈提示核对事实，必要时建议撤回更正。划型错误（货物看制造商/服务看供应商/工程看承建单位）同样高风险 |
| **风险** | 🟡 中危；核心资质缺一项即可能无效响应，政策功能文件不实则触发处罚，优先级仅次于🔴 |

## 级别 🟢 · 格式规范项（不规范→通常扣分，少数触发无效响应）

| 项目 | 内容 |
|---|---|
| **判定标准** | 版式、装订、页码、字体、封面、签署形式等"非实质性"要求；不满足一般扣分，但采购文件若将"未装订/未签字"列为无效响应则升🔴 |
| **典型内容** | 页码连续、目录与正文一致、字体字号、装订方式、电子文件格式（PDF/OFD）、封面信息完整、正副本标识、按采购文件顺序编制 |
| **误判边界** | ❌ 把"采购文件明示未满足即无效响应"的格式项**误降**为🟢；✅ 先看文件是否对该格式项挂了无效响应后果，有则升🔴。无无效响应后果的格式瑕疵标🟢，有余力完善 |
| **风险** | 🟢 低危；按采购文件是否挂无效响应后果动态定级 |

## 级别 ⏰ · 关键时间节点（错过即失败）

| 项目 | 内容 |
|---|---|
| **判定标准** | 任何"逾期不可补"的时点：澄清/变更通知截止、保证金到账截止、提交首次响应文件（或投标）截止、开启/磋商时间；质疑（7 工作日）、投诉（质疑答复期满 15 日） |
| **典型内容** | 澄清/变更通知截止（提交首次响应截止 3 个工作日前）、保证金到账、提交首次响应截止（含提前到达）、开启/磋商、响应有效期（自开启日起 N 天）、质疑/投诉期限 |
| **误判边界** | ❌ 把"提交首次响应截止"与"开启/磋商时间"混为一谈；✅ 截止=递交终点（迟到即无效响应），开启/磋商=公开拆封或磋商开始（可现场提异议）。响应有效期须覆盖评审+确定成交+质疑周期，过短属文件瑕疵 |
| **风险** | ⏰ 时效类；错过即无效响应/失权，与🔴同级紧迫 |

## 必查盲区强制校验（攻克"漏检"）

响应材料动辄数百页，LLM 对**中后段（技术偏离表、保证金/付款条款、政策功能、电子化平台 CA、附件）极易漏检**。逐项生成清单后，**必须**对以下五类盲区定向回溯，任一未覆盖须在报告用红字警告：

| 盲区 | 回溯对象 | 为什么危险 |
|---|---|---|
| 盲区① ★/无效响应条款 | 所有带 ★ / "实质性响应" / "不可偏离" / "无效响应" / "废标" 的条款 | 无效响应高发区，常藏在中后段技术/商务要求 |
| 盲区② 保证金/密封/份数/报价 | 保证金金额(≤预算2%)+形式+到账截止、密封分袋+骑缝章+外封套标注、正副本份数、报价是否超预算 | 低级但占无效响应案例多数；报价超预算即出局（政采无"低于成本"强制否决，与招投标不同） |
| 盲区③ 政策功能（**政采特有高危**） | 中小企业声明函划型与数据真实性、信用中国+中国政府采购网查询、节能/环标强制品目认证、进口产品财政核准、监狱/残疾人证明、专门面向资格 | 政采专有，漏检后果最严重：声明不实触发第77条处罚、信用记录不合格直接出局、强制品目缺认证无效响应 |
| 盲区④ 电子化平台专项 | CA 证书有效性+密码、电子签章绑定、文件格式/大小、上传验证+提前量 | 政采普遍电子化，平台有独立于纸质的专属必检项，按纸质流程查必漏 |
| 盲区⑤ 联合体/分包落实政策功能 | 联合体协议+各方资质+各方盖章；专门面向时小微比例≥30% | 联合体须各方分别满足，且政策功能优惠/预留比例须落实，漏算即错失或违规 |

**未覆盖处理**：若因用户未提供某部分（如未给政策功能信息、未说明是否电子化）导致盲区无法判断，须在报告注明「⚠️ 未确认 <具体盲区，如中小企业声明函/信用查询/电子化平台 CA>，该项风险未知」，不得静默假装"已查完"。

## 疑难 Few-Shot（校准"临界/伪装"判定，完整见 `references/few_shot.md`）

**FS-1 · 中小企业声明函划型/数据错误**
- 情形：货物项目我方按"供应商自身"划型，但按规定应看制造商；或声明函营业收入/资产总额与佐证不一致。
- 误判：当普通格式项放过。
- 正解：货物看制造商、服务看供应商、工程看承建单位（工信部联企业〔2011〕300号+46号）。数据须与佐证一致；不实触发第77条。标⚠️并强烈提示核对事实，必要时撤回更正，不轻判为🟢。

**FS-2 · 信用记录查询时点**
- 情形：用提交响应文件前一周的截图，或仅查信用中国漏查中国政府采购网。
- 误判：当已满足。
- 正解：须于**提交响应文件截止时间前**在"信用中国+中国政府采购网"双网查询（财库〔2016〕125号）；旧截图/漏网标⚠️并提示重新查询，有失信记录则🔴。

**FS-3 · 保证金按"估算价2%"误算**
- 情形：沿用招投标"≤估算价2%"算政采保证金。
- 误判：直接套用。
- 正解：政采保证金 ≤ **采购项目预算金额** 2%（87号令第33条/74号令第14条），非估算价；履约保证金≤合同金额10%（条例第48条）。标⚠️提示按预算重算。

**FS-4 · 异常低价处理**
- 情形：报价明显低于其他供应商。
- 误判：照搬招投标"低于成本应否决"。
- 正解：政采**无"低于成本"强制否决**规定；异常低价通常仅要求说明合理性，不必然无效响应。但报价**超预算/最高限价**则直接🔴出局。区分清楚，不混用招投标规则。

**FS-5 · 政策功能文件缺失**
- 情形：专门面向项目但漏交中小企业声明函；或强制节能品目未提供认证。
- 误判：当普通缺漏。
- 正解：专门面向项目非中小企业不得参与→🔴；强制节能品目缺有效认证→多归无效响应/🔴；非强制的政策功能文件缺失→🟡丧失优惠。按采购文件措辞定级。

**FS-6 · 澄清/变更通知晚于 3 个工作日**
- 情形：采购人发变更距提交首次响应截止仅 1 个工作日且改了关键资质。
- 误判：只更新清单不提示程序问题。
- 正解：74号令第29条/214号第29条，应于提交首次响应截止 **3 个工作日**前通知；不足则顺延。标🔴程序风险并建议提质疑，同时按最新版准备（区别于招投标 15 日）。

**FS-7 · 质疑投诉时效与机关**
- 情形：成交结果公布后想维权。
- 误判：照搬招投标"投诉 10 日内向行政监督部门"。
- 正解：质疑自知道权益受损 **7 个工作日**内书面提出（94号令第10条）；投诉自质疑答复期满 **15 日**内 向 **财政部门** 投诉（第17条）。绝不跨体系引用招投标规则。

**FS-8 · 专门面向项目资格误判**
- 情形：我方为大企业却响应"专门面向中小企业"项目。
- 误判：当普通项目检查。
- 正解：专门面向中小企业采购的项目，非中小企业不得参与，响应即必然无效响应→标🔴；若我方为中型企业拟向小微企业分包，须满足预留比例（小微合同≥30%或份额≥30%，46号令第12条）。
