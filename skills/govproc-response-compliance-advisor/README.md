# 政采响应文件合规检查专家

> 供应商侧独立技能（`slug: govproc-response-compliance-advisor`）。对照政府采购采购文件（以竞争性谈判/竞争性磋商/询价/单一来源为主的响应文件，亦兼容政采公开招标文件）系统检查响应文件的格式、资质、政策功能、签字盖章、密封、份数、实质性响应等完整性，输出可直接打印打勾的结构化检查清单，提前发现无效响应风险点；并支撑采购文件合法性审查、法条问答、违规识别、质疑投诉辅助。

## 与「投标文件合规检查助手」的关系（体系互补）
- **本技能**：看**政府采购响应文件**（政采法体系），防无效响应/废标，重点覆盖中小企业声明函、信用查询、节能环标、进口核准、专门面向等政采特有盲区。
- **投标文件合规检查助手（bidding-compliance-advisor）**：看**工程招投标投标文件**（招标投标法体系）。
- 两者**体系硬隔离**：依法必须招标的工程项目归 bidding-compliance-advisor；本技能仅处理《政府采购法》体系的采购文件与响应文件。

## 能力边界
| 做 | 不做 |
|---|---|
| 响应文件完整性检查（四级风险 + 倒计时冲刺） | 不代替法务正式审核、不下法定结论 |
| 判定标尺逐类过、必查盲区（含政策功能）强制校验 | 不对"我方是否必然无效响应"下法定结论 |
| 采购文件合法性审查 / 法条问答 / 违规识别 / 质疑投诉辅助 | 不处理依法必须招标的工程项目（→ 投标文件合规检查助手） |
| 内置法条/案例库离线兜底 | 不提供规避合规、钻空子、骗分建议 |

## 快速使用
1. 触发技能（见 SKILL.md §7 触发词）。
2. 按 §2.1 预检清单提供关键要求（截止时间/保证金/份数/密封/采购方式/是否电子化/政策功能）。
3. 技能自动提取要求 → 跑 §3 判定标尺 → 五类必查盲区校验 → 按 §4 输出契约出清单。

## 部署建议
- `references/` 作确定性标尺随技能走，不依赖外部；外部知识库运行时核实层已挂载：
  - **政府采购实务与合规**（kb_id `7463496212028405`）——核心法条、政策功能、资格条件、无效响应判定。
  - **政府采购投诉AI知识库**（kb_id `7450416392468005`）——质疑投诉辅助（94号令）。
  - **招标文件、采购文件汇集**（kb_id `7439473860155957`）——采购文件条款/模板/案例辅助参考；含招标/采购混合内容，检索结果须按政采语境过滤。
- 触发即抛 §2.1 预检清单作 Welcome Message。
- 发现某类"临界判定"仍看不准 → 在 `compliance-signals.md` / `few_shot.md` 追加 Case。
