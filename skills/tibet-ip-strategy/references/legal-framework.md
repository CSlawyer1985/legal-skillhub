# 中国知识产权法律体系参考（藏药相关）

本文档提供中国现行知识产权法律体系中与藏药保护直接相关的核心法律依据。供技能执行过程中快速引用。

---

## 一、专利法

### 1.1 法律框架

| 法规 | 版本/要点 |
|------|-----------|
| 《中华人民共和国专利法》 | 2020年第四次修订，2021年6月1日起施行 |
| 《中华人民共和国专利法实施细则》 | 2023年修订版（国务院令第769号） |
| 《专利审查指南（2023）》 | 国家知识产权局，2024年1月20日起施行 |
| 《专利优先审查管理办法》 | 涉及节能环保、新一代信息技术等，藏药是否适用需个案判断 |
| 《专利合作条约（PCT）实施细则》 | 中国于1994年加入PCT |

### 1.2 保护客体（《专利法》第2条）

**发明**：对产品、方法或者其改进所提出的新的技术方案。
- 藏药组合物、提取物、制备方法、新用途、检测方法均属可授权客体

**实用新型**：对产品的形状、构造或者其结合所提出的适于实用的新的技术方案。
- 藏药炮制设备、给药装置、包装结构等
- 注意：方法、组合物本身不属于实用新型保护范围

**外观设计**：对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。
- 药品包装、标签、容器造型、UI界面

### 1.3 授权条件（《专利法》第22条）

| 条件 | 定义 | 藏药领域的特殊考量 |
|------|------|---------------------|
| **新颖性** | 不属于现有技术；没有同样的发明或实用新型在申请日以前被公开 | 传统方剂记载在藏药典籍（《四部医典》《晶珠本草》《月王药诊》等）中，属于现有技术——需判断权利要求限定的方案是否已为典籍所公开 |
| **创造性** | 与现有技术相比，具有突出的实质性特点和显著的进步 | 藏药复方的创造性争辩通常依赖"协同增效"数据和"出乎意料的技术效果" |
| **实用性** | 能够制造或者使用，并且能够产生积极效果 | 通常较易满足 |

### 1.4 不授予专利权的客体（《专利法》第5条、第25条）

**第5条**：
- 对违反法律、社会公德或者妨害公共利益的发明创造，不授予专利权
- 依赖遗传资源完成的发明创造，该遗传资源的获取或者利用违反有关法律、行政法规的，不授予专利权

**第25条**（与藏药相关）：
- 科学发现——不授权（如：新发现的藏药活性成分本身）
- 智力活动的规则和方法——不授权
- 疾病的诊断和治疗方法**——不授权**（关键！）
  - 藏医的特定诊断方法、治疗方案、手术方法等不能获得专利
  - 但"用于诊断或治疗的药物组合物/物质"可以授权（瑞士型权利要求）

### 1.5 中药领域专利审查特殊规定（《专利审查指南》2023）

**第二部分第十章"关于中药发明的审查"**：

1. **中药组合物的创造性**：
   - 如果组合物是已知方剂的加减方，但产生了预料不到的技术效果，可以认可创造性
   - 对比实验数据是关键证据

2. **中药提取物的创造性**：
   - 提取物与现有技术相比具备新颖性，且具有预料不到的技术效果或显著的工艺进步

3. **中药制备方法的创造性**：
   - 方法本身的选择非常规技术手段
   - 方法导致产品产生预料不到的技术效果

4. **已知中药材的新用途**：
   - 发现已知药材在治疗不同疾病中的新用途，通常可以认可创造性
   - 需要药效学数据支持

5. **实验数据的补充**：
   - 2017年后，中国允许在专利审查程序中补充实验数据（用于证明技术效果）
   - 但补充数据不能超出原申请文件记载的范围
   - **策略**：先提交有基础实验数据的申请，再后续补充完整数据

### 1.6 优先权与宽限期

| 制度 | 期限 | 要点 |
|------|------|------|
| 外国优先权 | 12个月（发明/实用新型），6个月（外观设计） | 基于首次在外国申请 |
| 本国优先权 | 12个月 | 基于首次在中国申请 |
| 宽限期（不丧失新颖性公开） | 6个月（申请日前） | 限三情形：中国政府主办的国际展览会、规定学术/技术会议、他人未经同意泄露 |
| PCT进入中国国家阶段 | 30个月（优先权日起） | 可申请恢复（+2个月） |

### 1.7 专利权保护与侵权

- **保护期**：发明20年，实用新型10年，外观设计15年（均自申请日起算）
- **药品专利补偿**（《专利法》第42条第3款）：
  - 新药上市审评审批占用的时间，可给予专利权期限补偿
  - 补偿期限不超过5年，新药批准后总有效期不超过14年
- **侵权判定原则**：
  - 全面覆盖原则（All Elements Rule）
  - 等同原则（Doctrine of Equivalents）
  - 捐献规则、禁止反悔规则
- **专利链接制度**（《药品专利纠纷早期解决机制实施办法》）：
  - 针对化学药和生物制品，中药目前不完全适用
  - 但中药品种保护有类似的"避专利"机制

### 1.8 药品专利期限补偿（Patent Term Extension）

2021年《专利法》第四次修订引入，仅限于：
- 在中国获得上市许可的新药
- 发明专利（不含实用新型）
- 补偿期限不超过5年，且总有效期不超过上市批准日起14年

## 二、商标法

| 法规 | 版本/要点 |
|------|-----------|
| 《中华人民共和国商标法》 | 2019年第四次修订 |
| 《中华人民共和国商标法实施条例》 | 2014年修订 |
| 《类似商品和服务区分表》 | 基于尼斯分类第11版 |

### 2.1 藏药相关主要类别

| 类别 | 内容 | 重要性 |
|------|------|--------|
| 第5类 | 医药制剂、藏药、中药、营养补充剂 | ⭐核心 |
| 第35类 | 广告、商业管理、替他人推销 | ⭐重要（防御性） |
| 第44类 | 医疗服务、保健、理疗 | ⭐重要 |
| 第3类 | 化妆品（若涉及护肤品线） | ⭐分线产品 |
| 第29类 | 肉、鱼、食用油脂、加工过的干果等（若涉及食品线） | ⭐分线产品 |
| 第30类 | 茶、咖啡、米、面粉等（若涉及保健茶/药茶） | ⭐分线产品 |
| 第32类 | 啤酒、饮料（若涉及功能饮料） | ⭐分线产品 |
| 第10类 | 医疗器械 | ⭐分线产品 |
| 第42类 | 科学研究、技术研究 | ⭐分线产品 |

### 2.2 藏文/少数民族文字商标

- 藏文文字可作为商标注册（《商标法》第8条）
- 需提供藏文含义说明
- 藏文音译汉字也可注册
- **风险提示**：藏文名称容易被他人在先注册，布局前必须做在先权利检索

### 2.3 地理标志证明商标

- 《商标法》第16条：商标中有商品的地理标志，而该商品并非来源于该标志所标示的地区，误导公众的，不予注册并禁止使用
- 地理标志证明商标由对商品有监督能力的组织（通常为行业协会）注册，供成员使用
- 注册材料需包括：地理标志所标示地区的范围、该商品的特定质量/信誉/特征与地理环境的关联性

## 三、反不正当竞争法（商业秘密）

| 条文 | 内容 |
|------|------|
| 第9条 | 商业秘密定义与侵权行为列举 |
| 第17条 | 民事赔偿责任（惩罚性赔偿：恶意侵权可1-5倍） |
| 第32条 | 举证责任转移——权利人提供初步证据后，举证责任转移至涉嫌侵权人 |

### 3.1 商业秘密构成要件

根据《反不正当竞争法》第9条，商业秘密指：
- **不为公众所知悉**（秘密性）
- **具有商业价值**
- **权利人采取了相应的保密措施**

### 3.2 改进后的举证规则（2019年修订）

- 权利人提供初步证据证明采取保密措施且存在侵权可能
- 举证责任转移至被控侵权人
- 显著降低权利人的维权难度

## 四、中药品种保护

《中药品种保护条例》（国务院令第106号，1992年颁布，目前正在修订中）

| 保护级别 | 保护期限 | 条件 | 法律效果 |
|----------|----------|------|----------|
| 一级保护 | 30年→可续延10年→总≤20年 | 特定疾病用、处方药 | 其他企业7年内不得仿制 |
| 二级保护 | 7年 | 已上市品种 | 其他企业需取得保护证书 |

**与专利保护的关系**：
- 中药品种保护是行政保护，与专利保护并行不悖
- 专利过期后，品种保护可能仍在有效期内
- 正在修订中的新条例预计会强化与专利制度的协调

## 六、植物新品种保护

《中华人民共和国植物新品种保护条例》

- 适用于人工选育的藏药材新品种（如人工选育的红景天、雪莲等）
- 保护期：木本植物20年，草本植物15年
- 申请流程：农业农村部或国家林业和草原局植物新品种保护办公室
- 条件：新颖性、特异性、一致性、稳定性、适当命名
- **注意**：野生藏药材的大规模采集/引种不产生新品种权；需要人工选育出区别于已有品种的新品系

## 七、地理标志保护

目前中国存在三种路径（正在逐步整合为国家知识产权局统一管理）：

1. **地理标志保护产品**（国家知识产权局）
   - 依据：《地理标志产品保护规定》
   - 保护方式：产品名称保护，仅产自特定区域并符合特定质量标准的产品可使用

2. **地理标志证明商标/集体商标**（国家知识产权局）
   - 依据：《商标法》第16条
   - 保护方式：商标法体系

3. **农产品地理标志**（农业农村部，正在整合中）
   - 依据：《农产品地理标志管理办法》
   - 注：该制度已逐步整合到国家知识产权局统一管理框架下

## 八、遗传资源相关法规

| 法规 | 要点 |
|------|------|
| 《专利法》第5条 | 违法获取遗传资源的发明不授权 |
| 《专利法》第26条第5款 | 依赖遗传资源的发明需披露直接来源和原始来源 |
| 《专利法实施细则》第27条 | 披露的具体要求——来源无法说明时需说明理由 |
| 《生物遗传资源获取和惠益分享管理办法》（征求意见稿） | 尚未正式颁布，需关注进展 |
| 《中华人民共和国野生动物保护法》 | 涉及珍稀藏药材时适用 |
| 《中华人民共和国野生植物保护条例》 | 涉及国家重点保护野生植物时适用 |
