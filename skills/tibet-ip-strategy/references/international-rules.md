# 国际知识产权规则参考（藏药相关）

本文档提供藏药产品在国际市场中可能适用或需要遵守的国际知识产权规则。供技能执行过程中在涉及目标市场为海外时引用。

---

## 一、美国专利实践

### 1.1 法律框架

| 法规 | 要点 |
|------|------|
| 美国专利法（35 U.S.C.） | 2011年《莱希-史密斯美国发明法》（AIA）重大修订 |
| 美国专利商标局（USPTO）审查指南（MPEP） | 专利审查程序手册 |
| 美国联邦法规（37 CFR） | 专利实务规则 |
| 美国联邦巡回上诉法院（CAFC）判例 | 对专利有效性解释有重大影响 |

### 1.2 与中国的关键差异

| 内容 | 美国 | 中国 |
|------|------|------|
| **发明人申请原则** | 先发明制（AIA后改为先申请制，但仍保留发明人宣誓要求）| 先申请制 |
| **宽限期** | 1年（发明人自己的公开，或他人从发明人处获知后的公开）| 6个月（限定三种情形）|
| **实用性要求**（35 U.S.C. §101） | 严格——要求"具体、实质、可信的实用性" | 相对宽松 |
| **可授权客体** | 自然法则、自然现象、抽象概念除外（Alice/Mayo测试） | 相对宽松 |
| **补充数据** | 不允许——原始申请文件必须包含足够的支持数据 | 允许（2021年后放宽） |
| **信息披露义务（IDS）** | 发明人有义务披露所有已知的现有技术 | 无类似严格制度 |
| **续案/分案** | 灵活——可提交延续申请（continuation）、分案申请（divisional）、部分延续申请（CIP） | 只有分案申请 |
| **外观设计** | 15年（2015年5月13日后申请） | 15年 |
| **临时申请** | 可提交临时申请确立优先权日（无需权利要求等正式要素），12个月内转正式申请 | 无临时申请制度 |

### 1.3 中药（藏药）在美国的专利特殊问题

**可授权客体（§101）问题**：
- 天然物质的提取物如果与天然状态基本相同，可能被认定为"自然产物"而被排除
- 争辩策略：证明提取物具有与天然状态不同的结构、性质或更优的活性
- 需要具体、实质、可信的实用性数据

**传统知识作为现有技术**：
- 美国对印刷出版物（printed publications）的认定范围较广
- 如果传统藏药典籍藏于美国图书馆（如国会图书馆、哈佛燕京图书馆），可被视为现有技术
- 翻译版藏药典籍同样构成现有技术

**Hatch-Waxman法案与专利链接**：
- 仿制药简化申请（ANDA）及专利挑战制度
- 中药/藏药在美国通常不按NDA申请，而是按膳食补充剂（DSHEA），不适用Hatch-Waxman
- 若作为植物药（Botanical Drug）申请NDA，则适用专利链接制度

### 1.4 与藏药在美国的保护路径

| 产品类型 | 监管路径 | 知识产权关联 |
|----------|----------|-------------|
| 植物药（Botanical Drug）| IND → NDA（505(b)(1)或505(b)(2)） | 适用专利链接、数据保护（新化学实体5年，新适应症3年） |
| 膳食补充剂（Dietary Supplement） | DSHEA 1994，NDI通知 | 专利保护（不能通过监管独占期获得非专利保护）|
| 食品/功能食品 | FDA GRAS | 专利保护为主 |
| 化妆品 | FD&C Act | 专利+商标 |

## 二、欧洲专利实践

### 2.1 法律框架

| 法规/条约 | 要点 |
|-----------|------|
| 欧洲专利公约（EPC） | 统一专利申请和审查程序 |
| 欧盟药品指令（2001/83/EC） | 药品上市许可统一规则 |
| 欧盟传统草药指令（2004/24/EC） | **藏药进入欧盟的关键路径** |
| 补充保护证书（SPC，Regulation (EC) 469/2009） | 药品专利期限补偿 |
| 统一专利法院（UPC） | 2023年6月1日起正式运作 |

### 2.2 与中国的关键差异

| 内容 | 欧洲 | 中国 |
|------|------|------|
| **宽限期** | 无（与EPC大多数缔约国一致）——任何形式的公开即丧失新颖性 | 6个月（限三种情形）|
| **疾病的诊断和治疗方法** | 不授权（EPC第53(c)条，比中国更严格）| 不授权 |
| **人体外科手术/治疗/诊断方法** | 不授权（范围更宽）| 同 |
| **植物品种** | 不授权（可通过《欧共体植物品种保护条例》保护）| 可以授权 |
| **第二医药用途** | 使用EPC 2000格式——"物质X，用于治疗疾病Y"（目的限定的产品权利要求）| 中国接受瑞士型权利要求和"药物组合物"写法 |
| **补充实验数据** | 不允许超出原始申请内容的范围 | 允许（2021年后） |
| **单一性要求** | 严格——一件申请只能涉及一个发明或一组相互关联的发明 | 相对宽松 |

### 2.3 传统草药指令（2004/24/EC）概要

欧盟为简化传统草药（含民族药）注册专门制定的制度：

| 条件 | 要求 |
|------|------|
| 使用历史 | 在欧盟境内至少使用30年，或在其中一个成员国至少使用15年+在欧盟外至少使用30年 |
| 适应症 | 仅限无需医生处方、无需医疗监督的传统用途（不能标注"治疗"性表述）|
| 证据要求 | 充分的文献证据或专家证词证明长期安全使用 |
| 不要求 | 不需要完整的毒理和临床试验 |
| 注册类型 | 简化注册（简化申请/传统应用注册） |

**对藏药的实用性提示**：
- 藏药在欧盟的30年使用历史通常难以满足
- 可考虑通过"在欧盟一个成员国使用至少15年 + 在欧盟外使用至少30年"路径
- 印度/尼泊尔等南亚国家的藏药使用记录也可作为证据
- 简化注册下的适应症表述受限（不能标注"治疗糖尿病"，只能是"辅助降血糖"类）

### 2.4 补充保护证书（SPC）

- 相当于中国的药品专利期限补偿
- 条件：在欧盟获得上市许可 + 已授权的欧洲专利涵盖该产品
- 期限：从专利申请日至首次上市许可日减5年，最长不超过5年
- 总有效期：上市许可日起不超过15年

## 三、印度专利实践

### 3.1 法律框架

| 法规 | 要点 |
|------|------|
| 《印度专利法》（1970年，2005年TRIPS合规修订） | 现行法律框架 |
| 《印度专利实施细则》 | 印度专利局（CGPDTM）执行规则 |
| 《印度传统知识数字图书馆》（TKDL） | 重要的现有技术数据库 |

### 3.2 与中国的关键差异

| 内容 | 印度 | 中国 |
|------|------|------|
| **第3(d)条** | **关键条款**——已知物质的盐、酯、醚、同质异形体、代谢物、混合物、衍生物不视为新物质，除非证明其疗效显著提升。对藏药提取物/活性成分的授权影响大 | 无类似严格限制 |
| **第3(e)条** | 简单混合得到的混合物（已知组分简单混合，各自发挥已知功效）不视为发明——对藏药复方影响大 | 允许，需证明协同效果 |
| **第3(i)条** | 传统知识（包括已知传统组分的任何形式）不授权 | 无类似专门条款 |
| **宽限期** | 12个月（仅限于在印度政府认可的期刊/会议上公开，或作为论文提交） | 6个月（三种情形） |
| **强制许可** | 较宽松——满足"合理需求未满足"或"价格不合理"即可申请 | 较严格（仅在公共健康危机等情形下） |
| **提交地址** | 印度专利局（孟买、德里、钦奈、加尔各答四个区域局） | CNIPA |

### 3.3 传统知识数字图书馆（TKDL）

- 印度政府建立的传统知识数据库
- 编入了阿育吠陀（Ayurveda）、尤那尼（Unani）、瑜伽、藏药（Amchi/Sowa Rigpa）等传统系统的知识
- 包含约34万种药用植物配方
- **藏药（Sowa Rigpa）相关内容已被纳入**（包括《四部医典》等典籍的数字化）
- 与中国专利局（CNIPA）、欧洲专利局（EPO）、美国专利商标局（USPTO）等签署了访问协议
- 审查员在审查涉及传统知识的专利申请时，将TKDL作为现有技术检索资源

**对藏药专利申请的影响**：
- 以藏药典籍中已记载的组方直接申请专利，在印度和美国/欧洲审查中很可能因TKDL而被驳回
- 必须证明"相对于TKDL公开内容的实质性创新改进"

### 3.4 印度对藏药（Sowa Rigpa）的认可

- 印度于2010年正式承认藏医（Sowa Rigpa）为传统医学体系
- 喜马偕尔邦（Himachal Pradesh）、拉达克（Ladakh）、锡金（Sikkim）、阿鲁纳恰尔邦（Arunachal Pradesh）等地为藏药传统使用区域
- 藏药在印度的传统使用记录可作为"传统知识"证据，也可作为"长期安全使用"的证据支持注册申请

## 四、《生物多样性公约》与《名古屋议定书》

### 4.1 核心原则

| 原则 | 内容 | 对藏药的影响 |
|------|------|-------------|
| **国家主权**（CBD第3条） | 各国对其生物资源拥有主权 | 中国境内的藏药材资源由中国管辖；获取需获中国主管机关批准 |
| **事先知情同意（PIC）**（CBD第15条） | 获取遗传资源需资源提供国的事先知情同意 | 涉及境外藏药来源（如印度的喜马拉雅地区）时，需与印度政府和当地社区协商 |
| **共同商定条件（MAT）**（CBD第15条） | 遗传资源的获取和利用需双方协商条件 | 涉及惠益分享条款的约定（货币/非货币） |
| **惠益分享（ABS）**（CBD第15条+名古屋议定书） | 利用遗传资源所产生的惠益应公平分享 | 利用传统藏药知识进行的商业化开发，需与知识持有者分享收益 |

### 4.2 《名古屋议定书》要点

- 中国于2016年9月6日正式加入
- 印度于2014年批准
- 核心要求：
  1. 获取遗传资源前需获取PIC
  2. 双方签订MAT明确惠益分享条款
  3. 使用遗传资源后，需在相关知识产权申请中披露来源
- **对藏药的实操提示**：
  - 从西藏/青海/四川等藏区采集藏药材进行研发，需获得当地林业或农业部门许可
  - 使用藏医院或老藏医的传统配方，需获得其PIC并商定惠益分享方案
  - 若从印度/尼泊尔获取藏药材或传统知识，需遵守该国ABS立法

### 4.3 合规路径（整合版）

```
信息收集
   ├→ 境内资源？
   │   ├→ 列入CITES？ → CITES许可证
   │   ├→ 国家重点保护？→ 省级林业/农业主管许可
   │   ├→ 一般药材 → 可自由获取（但仍建议记录来源）
   │   └→ 传统配方（来自藏医院/老藏医）→ 签订PIC+MAT协议
   │
   └→ 境外资源？
       ├→ 来自印度 → 遵守印度《生物多样性法》（2002）+ 规则（2004）
       │   → 向印度国家生物多样性管理局（NBA）申请许可
       ├→ 来自尼泊尔 → 遵守尼泊尔ABS立法
       └→ 来自其他CBD缔约国 → 遵守该国ABS法律
```

## 五、WIPO相关条约

| 条约 | 要点 | 对藏药的意义 |
|------|------|-------------|
| **专利合作条约（PCT）** | 统一国际专利申请程序，中国1994年加入 | 藏药国际专利申请的标准路径 |
| **巴黎公约** | 优先权原则，中国1985年加入 | 12个月优先权的法律基础 |
| **商标国际注册马德里协定/议定书** | 单一国际申请可覆盖多个国家 | 藏药品牌的多国商标注册路径 |
| **TRIPS协议**（WTO） | 最低知识产权保护标准 | 影响各成员国的专利保护期（20年）和强制许可制度 |
| **WIPO IGC**（政府间委员会） | 讨论传统知识、遗传资源、民间文艺的保护 | 关注能否形成传统知识国际保护新条约的进展 |
| **WIPO传统知识条约（2024年通过）** | 关于知识产权、遗传资源及其相关传统知识的条约——要求依赖遗传资源/传统知识的专利申请披露来源 | **2024年5月通过**，正式文本已公布。中国为该条约积极推动者。藏药专利申请将受此条约约束，需在专利文件中披露遗传资源和传统知识的来源信息 |

## 六、重要国际公约

| 公约 | 要点 | 对藏药的影响 |
|------|------|-------------|
| **CITES**（濒危野生动植物种国际贸易公约） | 管制珍稀物种及其衍生物的国际交易 | 含附录II物种（如部分雪莲、冬虫夏草）的藏药产品国际流通受限 |
| **WHO传统医学战略（2014-2023）** | 推动传统医学标准化、安全性和有效性研究 | 部分国家可能以其为依据，对藏药注册提供专门通道 |
| **ITPGRFA**（粮食和农业植物遗传资源国际条约） | 植物遗传资源的获取和惠益分享 | 涉及藏药植物种质资源的国际交换 |
