# 诉讼管家 Skill

## 功能描述
自动识别民事诉讼文书（传票、受理通知书、应诉通知书等），提取关键信息，根据民事诉讼法规定计算各项期间，输出个性化的期间表。

## 使用场景
- 收到法院传票，需要计算答辩期、举证期限、开庭时间等
- 收到受理通知书，需要计算审理期限
- 收到判决书，需要计算上诉期

## 输入
1. 上传文书图片（传票、通知书等）
2. 或手动输入关键信息

## 输出
- 案件基本信息
- 关键期间表（包含具体日期）
- 风险提示（即将到期或已过期的期间）
- 待办事项清单

## 工作流程

### 步骤1：识别文书类型和提取信息
- 如果用户上传图片，先进行OCR识别
- 从文字中提取关键信息：
  - 案号
  - 案件名称（见下方"案件名称提取规则"）
  - 法院名称
  - 程序类型（简易/普通）
  - 原告、被告
  - 受理日期
  - 送达日期
  - 举证期限（如果有）
  - 开庭时间（如果有）

**日期格式处理：**
- 法律文书的日期通常为中文格式，如"二○二六年一月二十二日"或"二〇二六年一月二十二日"
- 必须同时支持"○"（圆圈）和"〇"（零字）两种零的写法
- 提取日期后，转换为标准格式（YYYY-MM-DD）用于期间计算

**案件名称提取规则：**
法律文书中案件名称的表述方式多样，需要按以下优先级提取：

1. **标准格式**：优先提取"原告XXX与被告XXX…一案"或"XXX诉XXX…一案"格式
   - 示例：张三诉李四合同纠纷

2. **第二人称格式**：如果是"你与XXX…一案"或"XXX与你…一案"
   - 需要根据文书上下文，将"你"替换为实际当事人名称
   - 示例：文书中"你与李四合同纠纷一案"，根据抬头确定"你"是张三，提取为"张三诉李四合同纠纷"

3. **执行案件格式**：执行文书中使用"XXX申请执行XXX…一案"格式
   - 示例：张三申请执行李四合同纠纷

4. **过滤程式化表述**：
   - 去除"申请执行人…与你单位…"等程式化表述
   - 去除重复拼接的当事人名称
   - 只保留核心的"当事人+案由"信息

5. **最终格式要求**：
   - 案件名称必须包含双方当事人（或申请执行人+被执行人）
   - 格式：原告诉被告+案由，或：申请执行人申请执行被执行人+案由
   - 示例：张三诉李四合同纠纷、张三申请执行李四合同纠纷

### 步骤2：计算期间
根据民事诉讼法规定，计算以下期间：

#### 一审阶段
1. **答辩期**：收到起诉状副本后15日（涉外30日）
2. **举证期限**：法院指定，不少于15日
3. **一审审限**：
   - 简易程序：立案后3个月
   - 普通程序：立案后6个月
4. **上诉期**：收到判决书后15日（裁定10日）

#### 二审阶段
1. **上诉期**：收到判决书后15日（裁定10日）
2. **二审审限**：判决3个月，裁定30日

### 步骤4：保存案件信息
本步骤采用两级文件管理：

#### 4.1 本地案件文件（必须）
- 在用户@ 的文件所在目录下，创建期间表文件
- 文件名格式：`[案号]_期间表.md`
- 内容：包含步骤3输出的完整期间表

#### 4.2 全局任务管理（必须）
- 将所有期限信息写入全局任务文件：`tasks.json`（建议放在你的工作区根目录）
- 文件格式为JSON：`{"tasks": [...]}`
- 每个期限作为 tasks 数组中的一个对象，包含：
  - `case_id`：案号
  - `case_name`：案件名称（必须包含双方当事人/申请执行人+被执行人）
  - `case_type`：案件类型（诉讼/执行/劳动仲裁）
  - `deadline_name`：期间名称
  - `deadline_date`：截止日期（YYYY-MM-DD）
  - `legal_basis`：法律依据
  - `status`：pending/completed/overdue
  - `created_at`：创建日期
  - `case_folder`：案件文件夹路径

**重要说明：**
- 本地文件方便查看单个案件的完整期间信息
- 全局 `tasks.json` 供"待办管家"统一管理所有案件的期限
## 期间计算规则

### 一审阶段期间规则

| 期间名称 | 计算规则 | 法律依据 |
|---------|---------|---------|
| 立案 | 收到起诉状后7日内 | 《最高人民法院关于严格执行案件审理期限制度的若干规定》第6条（2000年） |
| 答辩期 | 收到起诉状副本后15日（涉外30日） | 《民事诉讼法》第125条、第268条（2023年修正） |
| 管辖权异议 | 答辩期内提出，法院15日内裁定 | 《民事诉讼法》第130条（2023年修正） |
| 举证期限 | 法院指定，不少于15日 | 《关于民事诉讼证据的若干规定》第33条（2019年修正） |
| 传唤期限 | 开庭前3日 | 《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第227条（2022年修正） |
| 一审审限 | 简易3个月，普通6个月 | 《民事诉讼法》第149条、第161条（2023年修正） |
| 上诉期 | 判决15日，裁定10日（涉外30日） | 《民事诉讼法》第164条、第269条（2023年修正） |

### 二审阶段期间规则

| 期间名称 | 计算规则 | 法律依据 |
|---------|---------|---------|
| 上诉期 | 判决15日，裁定10日 | 《民事诉讼法》第164条（2023年修正） |
| 答辩期 | 收到上诉状后15日 | 《民事诉讼法》第167条（2023年修正） |
| 二审审限 | 判决3个月，裁定30日 | 《民事诉讼法》第183条、《审理期限规定》第2条（2023年修正） |

## 特殊处理

### 节假日顺延
- 期间届满日是节假日的，顺延至节假日后第一日
- 法律依据：《民事诉讼法》第84条（2023年修正）

### 邮寄期间
- 外地当事人加邮寄期间（3-15日，根据距离）
- 法律依据：《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第83条（2022年修正）

### 工作日计算
- 期间以日、月、年计算，开始的当日不计入
- 法律依据：《民事诉讼法》第84条（2023年修正）

## 注意事项
1. 本Skill计算的期间仅供参考，具体以法院通知为准
2. 涉及重要期限时，建议提前准备，避免临近截止日期
3. 如有疑问，请及时咨询承办法官或书记员
