# 法院文书下载与归档

从人民法院电子送达平台（zxfw.court.gov.cn）自动下载传票、判决书等司法文书 PDF，归档到本地案件文件夹，解析文书内容，设置开庭日历提醒，自动计算上诉期限。

## 功能

- **短信原文解析**：粘贴法院短信即可自动提取案号、当事人、法院名称和下载链接参数
- **纯链接处理**：直接发送送达链接也可以，跳过短信解析直接下载
- **双重下载策略**：优先使用 API 直连（快速、无需浏览器），失败后自动降级到浏览器自动化
- **批量文书处理**：一次送达通常含多份文书（传票、起诉状、应诉通知书等），全部自动下载
- **智能案件匹配**：根据原被告名自动匹配已有案件文件夹（原被告须同时命中，支持全称/简称），未匹配则按命名规则自动创建
- **文书内容解析**：自动提取 PDF 文字（含 WPS 生成 PDF 的 CID 字体解码），呈现关键信息
- **开庭日历提醒**：传票自动向 Apple Calendar 添加开庭事件（提醒天数可配置，默认提前 7 天 + 提前 2 天）
- **上诉期限计算**：判决书/裁定书自动按案件类型计算上诉截止日期
- **归档追溯记录**：每次处理写入 JSON 记录，方便日后查询
- **结构化汇报**：四段式汇报模板，传票提醒和上诉期限按条件触发
- **可配置工作目录**：首次使用时设置工作文件夹（含路径确认环节），默认桌面，支持自定义路径、归档方式、日历名称和提醒时间

## 项目结构

```
court-document-downloader/
├── SKILL.md                          # Skill 主文件（全部指令）
├── README.md
├── config.example.json               # 配置模板（复制为 config.json 后修改）
└── .gitignore                        # 排除敏感文件和历史记录
```

> **隐私设计**：归档记录（JSON）和用户配置均存储在用户本地，不随本仓库分发。首次使用时 skill 会自动引导配置工作目录。

## 安装

1. 将 `SKILL.md` 复制到 WorkBuddy 的 skills 目录：

```bash
mkdir -p ~/.workbuddy/skills/court-document-downloader
cp SKILL.md ~/.workbuddy/skills/court-document-downloader/
```

2. （可选）提前创建配置：

```bash
mkdir -p ~/.config/court-document-downloader
cp config.example.json ~/.config/court-document-downloader/config.json
# 编辑 config.json，设置你的工作目录
```

> 如果跳过此步骤，首次使用时 skill 会自动引导配置（包含路径确认环节）。

## 使用方式

### 自动触发

向 workbuddy 发送包含以下关键词的消息即可自动加载：

- `zxfw.court.gov.cn`
- 人民法院电子送达
- 法院 + 传票/文书/送达/判决书

### 方式一：粘贴法院短信

```
收到法院短信，内容如下：
【xx市人民法院】某某，您好！您有（2025）苏0981民初1234号案件文书送达，
请点击链接查收：https://zxfw.court.gov.cn/zxfw/#/pagesAjkj/app/wssd/index?qdbh=XXX&sdbh=XXX&sdsin=XXX
```

### 方式二：直接发送送达链接

```
https://zxfw.court.gov.cn/zxfw/#/pagesAjkj/app/wssd/index?qdbh=XXX&sdbh=XXX&sdsin=XXX
```

### 首次使用：配置工作目录

skill 首次运行时会引导配置保存路径，流程如下：

**第一轮 — 选择路径：**

```
⚠️ 首次使用，需要设置诉讼文书的保存位置。

请选择保存路径：
  1. 保存到桌面（默认）— ~/Desktop/诉讼案件/
  2. 自定义路径 — 回复一个本地文件夹路径

同时请选择归档方式：
  A. 按年份分层（默认）— 自动创建 2026/、2027/ 等年份子文件夹
  B. 不分年份 — 所有案件文件夹直接放在工作目录下
```

**第二轮 — 确认配置：**

系统展示完整配置摘要（保存路径、归档方式、日历名称、提醒设置、文件夹结构预览），用户确认后才保存。如需修改日历名称或提醒时间，可回复"高级配置"。

配置保存在 `~/.config/court-document-downloader/config.json`，可随时手动修改或删除后重新触发配置引导。

## 工作流程

1. **输入解析** — 判断短信原文还是纯链接，提取案号、当事人、法院名称
2. **工作目录确认** — 首次使用时引导配置（含路径选择 + 确认环节），后续自动读取
3. **API 直连下载**（优先）— 调用 zxfw 后端 API 获取文书列表，curl 批量下载
4. **浏览器降级**（备选）— API 不可用时用浏览器提取 OSS 直链后下载
5. **确定归档路径** — 按配置模式归入 `${WORK_DIR}/{年份}/`（按年份）或 `${WORK_DIR}/`（不分年份）
6. **匹配案件文件夹** — 按当事人名匹配现有文件夹，或自动创建
7. **文件命名归档** — `{文书标题}（{当事人+案由}）_{YYYYMMDD}收.pdf`
8. **解析文书内容** — pymupdf 提取 PDF 文字（含 CID 字体解码）
9. **设置开庭提醒** — 传票自动添加 Apple Calendar 事件（日历名和提醒天数从配置读取）
10. **计算上诉期限** — 判决书/裁定书按送达时间自动计算
11. **写入归档记录** — 存入 `${WORK_DIR}/${ARCHIVE_SUBDIR}/`（默认 `.archive`）
12. **结构化汇报** — 归档清单 → 传票提醒 → 上诉期限
13. **清理临时文件** — 删除 `/tmp/court-sms-staging/`

## 归档路径规范

支持两种归档模式，首次配置时可选：

### 模式一：按年份分层（默认）

```
${WORK_DIR}/                          # 用户配置的工作目录
├── 2026/
│   ├── 某某诉某某房屋租赁合同纠纷/
│   │   ├── 传票（某某诉某某房屋租赁合同纠纷）_20260610收.pdf
│   │   └── 民事判决书（某某诉某某房屋租赁合同纠纷）_20260610收.pdf
│   └── 某某建设工程有限公司诉某某建设施工合同纠纷/
│       └── ...
├── 2027/
│   └── ...
└── .archive/                          # 归档追溯记录（JSON）
    └── 20260610_143025_1234.json
```

### 模式二：不分年份（flat）

```
${WORK_DIR}/                          # 用户配置的工作目录
├── 某某诉某某房屋租赁合同纠纷/
│   ├── 传票（某某诉某某房屋租赁合同纠纷）_20260610收.pdf
│   └── 民事判决书（某某诉某某房屋租赁合同纠纷）_20260610收.pdf
├── 某某建设工程有限公司诉某某建设施工合同纠纷/
│   └── ...
└── .archive/                          # 归档追溯记录（JSON）
    └── 20260610_143025_1234.json
```

> `WORK_DIR` 默认为 `~/Desktop/诉讼案件/`，首次使用时通过两轮交互配置（选择路径 → 确认配置）。归档子目录名可通过配置的 `archive_subdirectory` 字段自定义（默认 `.archive`）。

## ⚠️ 案件文件夹命名规则（重要）

为了让 skill 能自动匹配已有案件文件夹、避免重复创建，**请务必按以下规则命名案件文件夹**：

### 命名格式

```
{原告名}诉{被告名}{案由}
```

### 命名要求

1. **必须同时包含原告名和被告名** — skill 搜索时会同时匹配原被告，两者都命中才会复用已有文件夹，只命中一方会新建
2. **名称可以是全称或简称** — skill 会自动去掉以下部分进行模糊匹配：
   - 公司后缀：「有限公司」「有限责任公司」「股份有限公司」「集团」
   - 地域前缀：省份（江苏/浙江/广东/北京...）、「XX市」、「XX省XX市」、「XX市XX区」
3. **用"诉"字连接原被告** — 便于阅读和匹配

### 简称匹配示例

| 文书中的当事人名 | 文件夹中的名称 | 是否匹配 | 说明 |
|----------------|--------------|---------|------|
| 江苏天下无敌建设工程有限公司 | 天下无敌建设工程 | ✅ | 去地域前缀 + 去公司后缀 |
| 天下无敌建设工程有限公司 | 江苏天下无敌建设工程 | ✅ | 反向同理 |
| 某某建设工程有限公司 | 某某建设工程 | ✅ | 去公司后缀 |
| 南京市某某科技有限公司 | 某某科技 | ✅ | 去「南京市」前缀 + 去公司后缀 |

### 命名合规示例

| 文件夹名称 | 原告 | 被告 | 案由 | 是否合规 |
|-----------|------|------|------|---------|
| `某某建设工程有限公司诉某某科技合同纠纷` | 某某建设工程有限公司 | 某某科技 | 合同纠纷 | ✅ 全称 |
| `某某建设工程诉某某科技合同纠纷` | 某某建设工程有限公司 | 某某科技 | 合同纠纷 | ✅ 简称（自动匹配） |
| `某某诉某某房屋租赁合同纠纷` | 某某 | 某某 | 房屋租赁合同纠纷 | ✅ 个人名 |
| `2025苏1002民初31号` | — | — | — | ❌ 缺少原被告名，无法匹配 |
| `合同纠纷案件` | — | — | 合同纠纷 | ❌ 缺少原被告名，无法匹配 |
| `某某建设工程合同纠纷` | 某某建设工程有限公司 | — | 合同纠纷 | ❌ 缺少被告名 |

### 匹配逻辑

当收到新文书时，skill 会：
1. 从文书内容提取原告名和被告名
2. 对每个当事人名生成匹配变体（全名 → 去公司后缀 → 去地域前缀）
3. 在工作目录下搜索已有文件夹
4. 判断文件夹名是否**同时包含**原告和被告的任意变体
5. 都命中 → 复用已有文件夹，直接存入
6. 只命中一方或都未命中 → 新建 `{原告名}诉{被告名}{案由}` 文件夹

> 💡 **提示**：如果你手动创建了案件文件夹，请按上述规则命名，这样后续同一案件的文书会自动归入同一文件夹。即使文件夹用了简称（如"天下无敌建设工程"而非"江苏天下无敌建设工程有限公司"），skill 也能自动匹配。

| 平台 | 域名 | 下载方式 |
|------|------|----------|
| 全国法院统一送达平台 | zxfw.court.gov.cn | API 直连 / 浏览器 |

## 支持的文书类型

传票、起诉状、应诉通知书、举证通知书、小额诉讼程序告知书、原告举证材料、民事判决书、民事裁定书、合议庭组成人员通知书、受理案件通知书、诉讼费用交费通知书、廉政监督卡等。

## 隐私与安全

- **不存储敏感数据**：本仓库仅包含 skill 指令文件，不含任何案件数据
- **归档记录本地存储**：所有 JSON 归档记录保存在用户指定的 `${WORK_DIR}/.archive/` 目录下
- **配置本地存储**：工作目录配置保存在 `~/.config/court-document-downloader/config.json`
- **Git 排除**：`.gitignore` 已配置排除 `archive/`、`config.json`、`.DS_Store` 等敏感文件
- **首次配置**：引导用户设置自己的工作目录，默认使用桌面，不强制固定路径

## 注意事项

- OSS 签名链接有时效（约 1 小时），获取后应尽快下载
- 法院送达链接中的参数是一次性/有时效的，过期需重新获取
- 归档年份按下载日期确定，非案号年份
- Apple Calendar 提醒的 `trigger interval` 单位是**分钟**，不是秒
- 文件命名统一加"收"字日期后缀，区别于文书本身的日期
