# 审查文件处理流程

> 本文件定义审查文件（审查意见通知书/驳回决定/复审决定书/无效宣告请求审查决定书）的完整处理步骤。当文件类型识别程序判定输入文件为审查文件时加载本文件。

---

## 适用范围

| 文档类型 | 文档性质 | 主体字段 | PDF 类型 |
|---------|---------|---------|---------|
| 审查意见通知书 | 审查员意见 | 申请人 | 通常图像型（需 OCR） |
| 驳回决定 | 驳回申请决定 | 申请人 | 通常图像型（需 OCR） |
| 复审决定书 | 复审委员会决定 | 复审请求人 | 通常图像型（需 OCR） |
| 无效宣告请求审查决定书 | 复审委员会决定 | 无效宣告请求人/专利权人 | 通常图像型（需 OCR） |

---

## 文档类型自动检测

程序通过 OCR 提取文本的前 3000 字符自动检测文档类型，检测优先级：

1. 包含"无效宣告请求审查决定书"或"无效宣告请求审查决定" → 无效宣告请求审查决定书
2. 包含"复审决定书"或"复审请求审查决定" → 复审决定书
3. 包含"驳回决定"（不含"复审"） → 驳回决定
4. 包含"审查意见通知书" → 审查意见通知书
5. 以上均无 → 按专利公开/公告文件处理（转至 [patent-publication-workflow.md](patent-publication-workflow.md)）

---

## 处理步骤

### 步骤 1：文本提取

与专利公开/公告文件相同，根据输入格式选择 `PDFReader` 或 `DocxReader`。

```bash
cd "<skill_root>/scripts" && python -m patent_extractor.main \
  --input "<input_file>" \
  --output "<work_dir>"
```

### 步骤 2：审查文件解析

使用 `OfficeActionParser` 解析审查文件，流程：

1. **检测文档类型**：按上述优先级自动判定
2. **提取首页头部信息**：申请号、发明创造名称、申请人/复审请求人、发文日等
3. **提取文档特有字段**：
   - 审查意见通知书：审查次数、对比文件、结论性意见、通知书首页事项
   - 驳回决定：驳回依据、针对的申请文件、对比文件、驳回决定首页事项、审查员代码
   - 复审决定书：决定号、决定日、决定结果、法律依据、决定要点、合议组、复审决定首页简述
   - 无效宣告请求审查决定书：决定号、决定日、决定结果、法律依据、决定要点、合议组、专利号、无效决定首页简述
4. **提取正文章节**：按中文数字章节标题拆分（如"一、案由"、"二、决定理由"）
5. **数据清洗**：修正 OCR 错误、统一格式

`<base_name>` 由脚本根据解析出的著录项目自动生成，格式按文档类型不同：
- 审查意见通知书：`{申请号}-{审查次数}{文档类型}-{发文序号}`
- 驳回决定：`{申请号}-{文档类型}-{发文序号}`
- 复审决定书：`{申请号}-{文档类型}-{发文序号}-{案件编号}`
- 无效宣告请求审查决定书：`{申请号}-{文档类型}-{决定日}-{案件编号}`

### 步骤 3：保存原始提取文本

将提取的原始文本保存为 `<work_dir>/<base_name>.txt`。

### 步骤 4：JSON 生成

将结构化信息输出为 `<work_dir>/<base_name>.json`。每种审查文件拥有独立的 JSON 结构（扁平化顶层字段）。

### 步骤 5：Markdown 生成

将结构化信息输出为 `<work_dir>/<base_name>.md`。

---

## 输出文件

| 文件 | 说明 |
|------|------|
| `<work_dir>/<base_name>.txt` | 原始提取文本 |
| `<work_dir>/<base_name>.json` | 结构化 JSON |
| `<work_dir>/<base_name>.md` | 结构化 Markdown |
| `<work_dir>/logs/` | 运行日志 |

> `<base_name>` 由脚本自动生成并通过 `BASE_NAME:` 标准输出返回。
> Agent 需在脚本执行后将临时工作目录重命名为 `<input_dir>/<base_name>`。
> 注意：审查文件无附图提取步骤，不生成 `images/` 目录。

## 代码模块

| 模块 | 职责 |
|------|------|
| `main.py` | 主入口，自动检测文档类型并编排对应流程 |
| `pdf_reader.py` | PDF 文本提取 |
| `docx_reader.py` | DOCX/DOC 文本提取 |
| `office_action_parser.py` | 审查文件解析（文档类型检测、著录项目提取、正文解析） |
| `json_generator.py` | 结构化 JSON 生成（支持审查文件格式） |
| `markdown_generator.py` | Markdown 生成（支持审查文件格式） |
