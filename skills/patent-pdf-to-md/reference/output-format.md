# 输出格式规范

> 本文件包含专利公开/公告文件和审查文件的 JSON Schema 及 Markdown 格式定义。当需要了解输出格式细节或排查 JSON/Markdown 生成问题时加载本文件。

    "申请号": "201420522729.0",
    "申请日": "2014.09.11",

    "授权公告日": "2015.01.21",
    "专利权人": "源德盛塑胶电子（深圳）有限公司",
    "发明人": "李正良",
    "IPC分类号": "H04N 5/247(2006.01)"
  },
  "摘要": "本实用新型公开了一种一体式自拍装置...",
  "权利要求书": "1.一种一体式自拍装置，其特征在于...",
  "说明书": {
    "说明书标题": "一种一体式自拍装置",
    "技术领域": "本实用新型涉及拍摄辅助器材技术领域...",
    "背景技术": "...",
    "实用新型内容": "...",
    "附图说明": "图1是本实用新型的结构示意图...",
    "具体实施方式": "..."
