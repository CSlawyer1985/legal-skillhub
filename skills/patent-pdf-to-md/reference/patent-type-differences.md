# 专利类型差异参考

> 本文件包含三种专利公开类型的详细对比、著录项目 INID 代码及图片提取边界规则。当需要了解专利类型差异或排查著录项目提取问题时加载本文件。

---

## 三种类型对比

| 特征 | 发明公开 (A) | 发明公告 (B) | 实用新型公告 (U) |
|------|-------------|-------------|-----------------|
| 页眉标识 | (12)发明专利申请 | (12)发明专利 | (12)实用新型专利 |
| 公告号字段 | 申请公布号 | 授权公告号 | 授权公告号 |
| 权利人字段 | (71)申请人 | (73)专利权人 | (73)专利权人 |
| 名称字段 | (54)发明名称 | (54)发明名称 | (54)实用新型名称 |
| 内容子章节 | 发明内容 | 发明内容 | 实用新型内容 |
| PDF 类型 | 通常文本型 | 通常文本型 | 可能为扫描件 |

## 著录项目 INID 代码

| INID | 字段 | 适用类型 |
|------|------|---------|
| (21) | 申请号 | 全部 |
| (22) | 申请日 | 全部 |
| (43) | 申请公布号/日 | 仅 A |
| (45) | 授权公告号/日 | 仅 B/U |
| (54) | 发明/实用新型名称 | 全部 |
| (57) | 摘要 | 全部 |
| (71) | 申请人 | 仅 A |
| (73) | 专利权人 | 仅 B/U |
| (72) | 发明人 | 全部 |
| (74) | 专利代理机构/师 | 全部 |
| (51) | IPC分类号 | 全部 |
| (56) | 对比文件 | 仅 B/U |
| (65) | 同一申请的已公布的文献号 | 仅 B |

## 四种审查文件对比

| 特征 | 审查意见通知书 | 驳回决定 | 复审决定书 | 无效宣告请求审查决定书 |
|------|--------------|---------|-----------|-------------------|
| 文档性质 | 审查员意见 | 驳回申请决定 | 复审委员会决定 | 复审委员会决定 |
| 主体字段 | 申请人 | 申请人 | 复审请求人 | 无效宣告请求人/专利权人 |
| 审查人员 | 审查员 | 审查员 | 合议组组长/主审员/参审员 | 合议组组长/主审员/参审员 |
| 特有字段 | 审查次数、对比文件、结论性意见 | 驳回依据、针对的申请文件 | 决定号、决定日、决定结果、法律依据、决定要点 | 决定号、决定日、决定结果、法律依据、决定要点、专利号 |
| 正文结构 | 审查意见详细分析 | 一、案由；二、驳回理由 | 一、案由；二、决定理由 | 一、案由；二、决定的理由；三、决定 |
| PDF 类型 | 通常图像型（需OCR） | 通常图像型（需OCR） | 通常图像型（需OCR） | 通常图像型（需OCR） |

---

## 图片提取边界

- **摘要附图**：第 1 页摘要文本旁的图片，**不纳入**说明书附图
- **说明书附图**：以页眉"说明书附图"标记的章节，仅提取此范围内的图片
- Skill 通过章节页码范围自动区分，无需手动干预
