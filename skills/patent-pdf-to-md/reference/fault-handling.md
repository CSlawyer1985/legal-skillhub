## 文本提取故障

### PDF 文本提取完全失败

**症状**：`pages` 列表为空，日志显示"文本提取完全失败"

**原因**：
- PDF 文件损坏或加密
- 所有 OCR 引擎均不可用

**处理方式**：
1. 确认 PDF 文件可正常打开（非加密/非损坏）
2. 尝试强制指定 OCR 引擎：`--ocr-engine mineru` 或 `--ocr-engine tesseract`
3. 如 MinerU 不可用，参考 [ocr-engine.md](ocr-engine.md) 安装或排查
4. 如所有引擎均失败，建议用户使用其他 PDF 阅读器确认文件可读

### 部分页面提取失败

**症状**：提取页数少于 PDF 实际页数

**处理方式**：
1. 检查日志中哪些页面提取失败
2. 使用 `--verbose` 参数获取详细日志
3. 对失败页面尝试切换 OCR 引擎

## OCR 引擎故障

详细排查步骤见 [ocr-engine.md](ocr-engine.md)。

| 故障 | 原因 | 解决 |
|------|------|------|
| `mineru-open-api: command not found` | 未安装 MinerU | `npm install -g mineru-open-api` |
| 退出码 4 | 文件超 10MB/20 页 | Skill 已自动逐页提取，若仍超限则降级到 Tesseract |
| 退出码 5 | 提取失败 | 检查 PDF 是否损坏，或降级到 Tesseract |
| 退出码 6 | 超时 | 增加 `--timeout` 或降级到 Tesseract |
| HTTP 429 | 速率限制 | 等待几分钟后重试 |
| OCR 降级到 Tesseract | MinerU 不可用 | 如需提升质量，参考 ocr-engine.md 安装 MinerU |

## 章节识别故障

### 首页页数信息提取失败

**症状**：日志显示"首页未找到'权利要求书X页 说明书Y页 附图Z页'信息"

**原因**：
- OCR 识别质量差，首页文本不完整
- 非标准格式专利（如早期专利无此著录项目）

**处理方式**：
- 系统自动降级到页眉检测策略，无需手动干预
- 如页眉检测也失败，检查 OCR 提取质量

### 页眉检测章节边界错误

**症状**：章节内容混淆（如权利要求书内容出现在说明书中）

**处理方式**：
1. 使用 `--verbose` 查看章节检测结果
2. 尝试切换 OCR 引擎提升文本质量
3. 手动指定 OCR 引擎：`--ocr-engine mineru`（推荐，质量最高）

### 说明书子章节拆分不完整

**症状**：部分子章节（如"背景技术"）内容为空

**处理方式**：
1. 检查原始提取文本中子章节标题是否被正确识别
2. OCR 识别的标题可能包含多余空格，系统已内置容错处理
3. 如仍失败，建议使用 MinerU 引擎重新提取

## 附图提取故障

### 附图页数不一致

**症状**：`ValueError: 附图页数不一致！著录项目记载附图X页，实际提取Y张图片`

**原因**：
- PDF 文件不完整（部分页面缺失）
- 附图章节范围识别错误
- OCR 识别错误导致首页信息提取不准确

**处理方式**：
1. 确认 PDF 文件完整性
2. 检查附图章节范围是否正确（查看日志中的页码范围）
3. 如首页页数信息提取有误，尝试切换 OCR 引擎

### 附图提取为空

**症状**：`images/` 目录无图片文件

**原因**：
- DOCX/DOC 格式不支持附图提取
- 附图页码范围为 (0, 0)
- MinerU 单页模式下无法获取分页信息

**处理方式**：
1. DOCX/DOC 格式：正常现象，不支持附图提取
2. PDF 格式：检查日志中的附图页码范围，尝试使用 `--ocr-engine mineru`
3. MinerU 单页模式：系统会自动尝试通过页数信息推算附图范围

### 附图质量差

**症状**：提取的 PNG 图片模糊

**处理方式**：
- 使用 `--dpi 300` 或更高值提升渲染分辨率（默认 200）

## JSON/Markdown 生成故障

### 著录项目字段缺失

**症状**：JSON 中部分著录项目字段为空

**原因**：
- OCR 识别质量差
- 非标准格式专利

**处理方式**：
1. 检查 `output.txt` 中对应字段是否存在
2. 尝试使用 MinerU 引擎提升 OCR 质量
3. 部分字段仅特定专利类型存在（如"对比文件"仅公告类型有）

### 正文内容包含页眉/页码残留

**症状**：正文文本中混入"权利要求书"、"CN XXXXXXXXX"等页眉文字

**处理方式**：
- 系统已内置页眉清理逻辑
- 如仍有残留，可能是非标准页眉格式，需人工清理

## DOCX/DOC 格式故障

### .doc 文件转换失败

**症状**：提示"未检测到任何办公软件"

**处理方式**：
1. 安装 WPS Office（推荐）、Microsoft Office 或 LibreOffice
2. 或手动将 `.doc` 另存为 `.docx`

### DOCX 文本提取不完整

**症状**：文本框、形状、脚注、尾注中的文字未被提取

**原因**：python-docx 库无法提取这些元素

**处理方式**：
- 建议用户将 DOCX 转为 PDF 后处理，可获取更完整的文本

## 多文件并行处理故障

### SubAgent 执行超时

**症状**：某个 SubAgent 长时间无响应

**处理方式**：
1. 检查输入文件大小，超大文件可能需要更长的处理时间
2. 对超时的文件单独重试
3. 考虑使用 `--ocr-engine tesseract`（离线模式，不受网络限制）

### SubAgent 执行失败

**症状**：SubAgent 返回非零退出码

**处理方式**：
1. 查看该 SubAgent 的日志输出
2. 根据上述对应故障类型排查
3. 修复后单独重新处理该文件

### 部分文件处理失败

**症状**：多个文件中部分成功部分失败

**处理方式**：
1. 收集所有失败文件的错误信息
2. 按故障类型分类处理
3. 对失败文件逐一重试
4. 向用户报告成功和失败的文件清单
