# 同音错字对照库与专有名词校验流程

> 口述稿 / 录音转写与会议纪要同源，同音错字模式一致，本库的对照表可复用于同类语音转写场景。

---

## 一、四步校验流程（成稿前必跑）

1. **第一步：对照表过滤**——拿本库两张表把全文过一遍，命中即修。附录、标题、图表标注也不能漏（实测教训：附录标题曾用拼音 Mita 而非"秘塔"，靠对照表自动拦截）。
2. **第二步：联网查证所有不确定的专有名词**——提取全文产品名/公司名/人名，对每个不确定的主动搜索验证；**不要只查"是什么"，要查"官方正确写法"**（大小写、空格、中文名）。不要等用户要求，第一轮就查。
3. **第三步：处理全网叫法不统一**——有的产品叫法不一（如 metalaw vs MetaLaw），查证后按最主流/官方写法修正，并主动向用户说明"存在多种叫法，已采用 XXX"。
4. **第四步：修正并汇报**——列出"已修正错误"清单；汇报口径：**"已联网查证 X 项，修正 Y 项，存疑 Z 项"**。

## 二、校验规则

- 搜索结果能确认的 → 直接修正
- 搜索结果无法确认的 → **保留原文**，在旁边加 `[存疑：可能为XXX]` 标注，交用户决策
- 同一产品在不同段落出现不同写法 → 全文统一为正确名称（微科/威科、metalaw/MetaLaw 混用是高频事故）
- 存疑时主动告诉用户：哪些查证了、哪些没查到

## 五、维护机制

- 每次整理任务中发现新的同音错字对照项 → **当次任务结束前更新本表**
- 表中产品名以官方最新写法为准；产品改名时更新对应行而非新增行
