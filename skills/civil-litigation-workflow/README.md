# 民商事诉讼全流程办案工作流（civil-litigation-workflow）

> v1.0 正式版 | 自包含全流程 skill | 思维底座：邹碧华《要件审判九步法》

> **版权与使用声明**：本工作流由 **左丽丽律师（浙江六和律师事务所）** 设计并维护，基于邹碧华《要件审判九步法》与多年民商事诉讼实务沉淀而成。比赛评审、学习交流可免费使用；未经授权，禁止整体搬运、二次分发或用于商业培训。引用请注明出处。

## 这是什么

一个民商事诉讼案件的**全流程办案工作流**，自包含、开箱即用。以邹碧华《要件审判九步法》为思维底座，按民商事诉讼的本质设计：

| 设计特点 | 说明 |
|-------|--------|
| 思维主线 | 九步法（立请求权 / 破对方要件） |
| 视角 | **双轨**（原告轨/被告轨，攻防两套方法论） |
| 终点 | **执行到位**（判后还有执行模块，不止于判决） |
| 全程机制 | **诉讼/和解双账本**（判决预期值台账） |
| 知识建设 | **自包含**：模块、能力组件、知识库、模板全部内置于包内，无外部依赖 |

## 架构（四层）

```
SKILL.md（主控：路由 + 死刑条款 + 全局规范）
├── sub-skills/（13 个模块，按诉讼阶段解耦）
│   01 接案评估 / 02 请求权基础与诉讼方案⭐ / 03 起诉与应诉 / 04 保全
│   05 证据组织 / 06 质证 / 07 庭前争点（附录含提纲八段规范）/ 08 庭审发问辩论
│   09 代理词 / 10 调解和解 / 11 裁判分析与上诉再审 / 12 执行 / 13 归档复盘
├── capabilities/（能力组件，由模块调度）
│   ├── 大事记构建.md          时间线整理方法与输出格式
│   ├── 证据三性审查.md        真实性/合法性/关联性审查框架与审查表
│   └── 案件登记与简报.md      登记表 + _log.yaml 台账 + 简报/周报模板
└── references/（知识库与模板，按"读取时机"惰性加载）
    ├── framework/         要件审判九步法（思维底座全文）
    ├── claim-basis/       请求权基础库（建工/合同/借贷/公司）
    ├── defense/           抗辩三类型 + 举证责任分配
    ├── procedure/         财产保全 + 执行程序指引
    ├── cross-disciplinary/ 工程造价鉴定
    ├── legal/             民事案件案由规定（2025第三次修正）修改要点
    ├── quality/           质控三规范（输出标准/来源标签/风险评级）
    └── templates/         起诉状/答辩状/代理词/证据清单/质证意见/案件简报模板
                           + 诉讼程序文书 20 份（保全/举证调查/上诉再审/执行）
```

## 案件文件夹

采用标准六目录结构（`[案件名称]/00-案件登记/ 01-大事记/ 02-证据材料/ 03-法律文书/ 04-往来函件/ 05-庭审材料/ 06-案件简报/`），枢纽文件为 `办案记录.md`（状态头 + 判决预期值台账 + 工作日志）。

## 使用

触发词示例："接了个买卖合同纠纷帮我分析"（→01→02）、"对方证据帮我质证"（→06）、"判决下来了要不要上诉"（→11）、"申请强制执行"（→12）。
详细路由见 SKILL.md 第四节。
