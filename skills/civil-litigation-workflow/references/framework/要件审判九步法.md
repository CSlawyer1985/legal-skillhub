## 一、为什么要学九步法

### 1.1 现实中的审判/代理乱象

**场景A：庭审混乱**
> 原告："被告欠我钱，我要他还钱！"
> 法官："是什么钱？借款？货款？工程款？违约金还是损害赔偿？"
> 原告："就是钱啊！他答应给我的！"
> —— 权利请求不固定，庭审无法进行。

**场景B：法律适用错误**
> 原告以"买卖合同"起诉，实际应该是"承揽合同"，举证责任完全不同。
> 法官没识别出来，按买卖合同判了，结果错了。

**场景C：遗漏要件**
> 原告主张违约赔偿，但没说"损失是多少"，也没举证。
> 法官直接判了赔偿金额 —— 这等于替原告主张，违反了中立性。

### 1.2 九步法的价值

| 价值 | 说明 |
|------|------|
| **标准化** | 每个案件都按同一套流程处理，减少随意性 |
| **可视化** | 把法官脑子里的思维过程写出来，当事人看得懂 |
| **防遗漏** | 要件清单确保关键要素不被漏掉 |
| **可复制** | 年轻法官/助理可以快速上手 |
| **讲理** | 裁判文书逻辑链条清晰，当事人服判率提高 |

### 1.3 核心理念

**"法律适用不是从事实到结论的跳跃，而是从事实到要件、从要件到法律的逐步归入。"**

## 二、九步法总览图

```
【起点】原告起诉 → 被告答辩
    ↓
【Step 1】固定权利请求（原告到底想要什么？）
    ↓
【Step 2】确定请求权基础规范（依据哪条法律？）
    ↓
【Step 3】确定抗辩权基础规范（被告怎么抗辩？）
    ↓
【Step 4】基础规范构成要件分析（这条法律要满足哪些条件？）
    ↓
【Step 5】诉讼主张检索（双方主张是否覆盖了所有要件？）
    ↓
【Step 6】争点整理（双方争议焦点是什么？）
    ↓
【Step 7】要件事实证明（围绕争点举证质证）
    ↓
【Step 8】事实认定（法官认定事实）
    ↓
【Step 9】要件归入并作出裁判（事实套进法律，得出结论）
    ↓
【终点】裁判文书
```

**口诀版**：
> 固定请求 → 找对法律 → 看看抗辩 → 拆开要件 → 检查主张 → 聚焦争点 → 查证据 → 定事实 → 套法律下结论

## 三、第一步：固定权利请求

### 3.1 为什么放在第一步

权利请求是诉讼的起点。原告不知道自己要什么，或者要的自相矛盾，整个诉讼就没有方向。

### 3.2 "固定"的三层含义

#### ① 明确含义

**例子**：
> 原告："要求被告赔偿损失。"
> 法官需要明确：什么损失？直接损失还是间接损失？多少金额？

**做法**：通过询问、释明，让原告把模糊表述具体化。

#### ② 剔除矛盾

**例子**：
> 原告既要求"继续履行合同"，又要求"解除合同"。
> 这两个请求在法律上是矛盾的，不能同时主张。

**做法**：要求原告选择其一。如果原告坚持都要，告知其法律后果。

#### ③ 更正错误

**例子**：
> 原告："要求被告返还定金并双倍赔偿。"
> 实际上合同约定的是"订金"而非"定金"，不适用定金罚则。

**做法**：释明告知原告"定金"与"订金"的法律区别，建议其调整请求。

### 3.3 诉的类型识别

这是固定请求的前提。必须分清原告提的是什么类型的诉：

| 诉的类型 | 定义 | 例子 | 关键点 |
|---------|------|------|--------|
| **确认之诉** | 请求确认某种法律关系存在/不存在 | "请求确认双方存在劳动关系" | 无执行内容 |
| **给付之诉** | 请求对方履行某种义务 | "请求支付工程款100万元" | 有执行内容 |
| **形成之诉** | 请求变更/消灭某种法律关系 | "请求解除合同" | 依判决生效 |

**常见错误**：把确认之诉当成给付之诉，或者遗漏形成之诉的前置步骤。

### 3.4 多个请求的处理

#### 对抗关系（只能选一个）
> 请求A：确认合同无效
> 请求B：要求继续履行合同
> —— 如果合同无效，就不存在"继续履行"。二者对抗，只能选一个。

#### 补充关系（可以一起主张）
> 请求A：解除合同
> 请求B：返还已付款项
> 请求C：赔偿损失
> —— 解除是前提，返还和赔偿是后果，可以一起主张。

#### 备选关系（主请求不行时 fallback）
> "如果法院认为合同有效，请求继续履行；如果认为合同无效，请求返还财产。"
> —— 这是允许的，但必须在固定请求时明确表达。

### 3.5 请求权竞合

**定义**：同一事实，可以适用多个不同的请求权基础，当事人只能选一个。

**经典例子**：
> 车停在小区停车场后丢失，起诉物业公司：
> - 路径A：侵权损害赔偿（物权法/侵权责任法）
> - 路径B：场地租赁合同违约（合同法）
> - 路径C：物业管理合同违约（合同法）
> —— 三条路都能走，但选了A就不能再主张B/C。

**为什么重要？**
- 不同路径 → 不同构成要件 → 不同举证责任 → 不同结果
- 法官有义务释明，让当事人明确选择。

## 四、第二步：确定权利请求基础规范

### 4.1 什么是请求权基础

**请求权基础 = 支持原告权利主张的法律条文**

**不是**：原告说的道理、常情、公平感。
**是**：具体的法律条文，如《民法典》第XXX条。

### 4.2 为什么要确定

**例子对比**：

| 案情 | 路径A | 路径B |
|------|-------|-------|
| 建设工程欠款 | 建设工程合同（民法典第788条） | 普通承揽合同（民法典第770条） |
| 举证责任 | 发包人证明质量合格才能拒付 | 定作人证明质量不合格才能拒付 |
| 优先受偿权 | 有（建工合同特有） | 无 |
| 结果 | 可能完全不同 | |

**结论**：请求权基础不同，整个案件走向可能完全不同。

### 4.3 请求权基础的层次

```
第一层次：合同请求权（基于合同约定）
    ↓ 没有合同或合同无效
第二层次：类合同请求权（缔约过失、无权代理等）
    ↓ 不适用
第三层次：物权请求权（返还、排除妨害等）
    ↓ 不适用
第四层次：侵权请求权（损害赔偿）
    ↓ 不适用
第五层次：不当得利（无法律依据获得利益）
```

**检索顺序**：合同 → 类合同 → 物权 → 侵权 → 不当得利

### 4.4 法律观点开示

**法官的义务**：确定请求权基础后，应当告知当事人。

**为什么**：
- 让当事人围绕正确的法律关系举证
- 避免突袭裁判（当事人不知道法官按哪条法律判）
- 给当事人调整诉讼策略的机会

## 五、第三步：确定抗辩权基础规范

### 5.1 抗辩 vs 否认

| 概念 | 定义 | 例子 |
|------|------|------|
| **否认** | 不承认对方主张的事实 | "我没借过钱" |
| **抗辩** | 承认事实，但主张权利不成立/已消灭 | "借了，但已经还清了" |

**关键区别**：抗辩需要被告主张并证明；否认只需否认，由原告证明。

### 5.2 抗辩的类型

#### 权利妨碍抗辩（权利自始不成立）

| 抗辩事由 | 法律依据 |
|---------|---------|
| 无行为能力 | 民法典第144条 |
| 限制行为能力+未追认 | 民法典第145条 |
| 合同内容违法 | 民法典第153条 |
| 违反公序良俗 | 民法典第153条 |
| 无权代理 | 民法典第171条 |
| 合同不成立 | 民法典第490条 |
| 欺诈/胁迫/重大误解 | 民法典第148-150条 |

#### 权利消灭抗辩（权利曾经存在，现已消灭）

| 抗辩事由 | 法律依据 |
|---------|---------|
| 债务已清偿 | 民法典第557条 |
| 债务已免除 | 民法典第575条 |
| 债务混同 | 民法典第576条 |
| 提存 | 民法典第570条 |
| 抵销 | 民法典第568条 |
| 诉讼时效届满 | 民法典第188条 |
| 给付不能 | 民法典第580条 |

#### 权利阻止抗辩（权利存在，但暂时不能行使）

| 抗辩事由 | 法律依据 |
|---------|---------|
| 同时履行抗辩 | 民法典第525条 |
| 先履行抗辩 | 民法典第526条 |
| 不安抗辩 | 民法典第527条 |
| 先诉抗辩（保证） | 民法典第687条 |

### 5.3 抗辩权的识别方法

**提问法**：
1. 被告是否承认原告主张的事实？
   - 不承认 → 否认（不是抗辩）
   - 承认 → 进入下一步
2. 被告是否主张了新的法律效果？
   - 没有 → 单纯否认
   - 有 → 抗辩
3. 是什么类型的抗辩？（妨碍/消灭/阻止）
4. 对应的法律依据是什么？

## 六、第四步：基础规范构成要件分析

### 6.1 什么是要件的"构成要件"

**构成要件 = 法律条文规定的、适用该法律必须满足的全部条件**

**例子：违约责任（民法典第577条）**
> 当事人一方不履行合同义务或者履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者赔偿损失等违约责任。

拆分为要件：
1. 合同有效成立
2. 一方不履行或不适当履行
3. 无免责事由

**例子：不当得利（民法典第985条）**
> 得利人没有法律根据取得不当利益的，受损失的人可以请求得利人返还取得的利益。

拆分为要件：
1. 一方获得利益
2. 他方受到损失
3. 获利与受损之间有因果关系
4. 获利无法律根据

### 6.2 如何拆解构成要件

**Tarski公式法**：
> "某人因某行为而负有某义务"可以拆解为：
> 1. 某人是义务主体
> 2. 某行为是义务产生的事实基础
> 3. 某义务是法律后果

**实际操作**：
1. 找到法律条文中的"主语"（谁）
2. 找到"谓语"（做了什么/符合什么条件）
3. 找到"宾语/法律后果"（产生什么权利义务）
4. 把条件全部列出来

### 6.3 要件分析的实务表格

**以"建设工程价款优先受偿权"为例：**

| 要件 | 法律依据 | 具体条件 | 举证责任 |
|------|---------|---------|---------|
| 主体要件 | 民法典第807条 | 承包人（与发包人订立合同者） | 原告证明合同关系 |
| 客体要件 | 最高院批复 | 建设工程（不宜折价、拍卖的除外） | 原告证明工程性质 |
| 前提要件 | 民法典第807条 | 发包人未按照约定支付价款 | 原告证明欠款事实 |
| 程序要件 | 最高院批复 | 自发包人应当给付之日起18个月内行使 | 原告证明起算时间 |
| 限制要件 | 最高院批复 | 已支付价款中工人工资部分优先 | 被告可主张 |

### 6.4 多个法律条文的组合

复杂案件可能需要多个条文组合：

**例子：建设工程施工合同纠纷**
- 基础条文：民法典第788条（建设工程合同定义）
- 权利条文：民法典第807条（优先受偿权）
- 程序条文：最高院建设工程司法解释一第41条（行使期限）
- 抗辩条文：民法典第803条（发包人提供基础资料的义务）

**做法**：把所有相关条文都找出来，逐一拆解要件。

## 七、第五步：诉讼主张的检索

### 7.1 什么是"主张责任"

**核心原则**：当事人没有就对自己有利的要件事实加以主张，法院不会适用相应法律规范，当事人会因此败诉。

**通俗理解**：法院不会替你说好话。该你主张的事实你不说，法院就当不存在。

### 7.2 检索方法

**对照表法**：

| 要件 | 原告主张 | 被告主张 | 是否覆盖 | 缺口 |
|------|---------|---------|---------|------|
| 合同成立 | "我们有合同" | "合同是假的" | ✓ 有争议 | 需要证据证明 |
| 已履行义务 | "我交了货" | "没收到" | ✓ 有争议 | 需要物流单 |
| 对方违约 | "他没付款" | "货有质量问题" | ✓ 有争议 | 需要付款记录 |
| 损失金额 | "损失100万" | "最多20万" | ✓ 有争议 | 需要评估报告 |

### 7.3 法官的释明义务

**什么情况下释明**：

| 情形 | 做法 |
|------|------|
| 原告遗漏关键要件 | "你主张违约赔偿，但没有说明损失金额，请补充。" |
| 原告主张相互矛盾 | "你既要求继续履行又要求解除，请明确选择。" |
| 原告主张明显错误 | "你依据的是已废止的法律条文，建议调整为..." |
| 原告主张不明确 | "你所说的'相关损失'具体包括哪些？" |

**注意**：释明不是帮原告打官司，是指明方向，举证责任仍在原告。

### 7.4 实务中的常见问题

**问题1：原告死活不补充**
> 法官释明后，原告仍不补充主张。
> 后果：法院可以对该要件事实作出不利于原告的认定。

**问题2：被告提出新的抗辩**
> 庭审中被告突然提出新的抗辩事由。
> 做法：给原告答辩机会，必要时休庭，让原告准备反驳证据。

## 八、第六步：争点整理

### 8.1 什么是争点

**争点 = 当事人对案件事实或法律适用存在分歧的地方**

**不是争点的地方**：
- 双方都承认的事实（无需审理）
- 与请求权基础无关的事实（无需审理）
- 已经查清的事实（无需再查）

### 8.2 争点的类型

#### 事实争点（最常见）

| 争点 | 原告主张 | 被告主张 |
|------|---------|---------|
| 合同是否签订 | 签订了 | 签字是伪造的 |
| 货物是否交付 | 交付了 | 没收到 |
| 款项是否支付 | 没付 | 已付现金 |
| 工程是否竣工 | 已竣工 | 有质量问题未修复 |

#### 法律争点

| 争点 | 原告观点 | 被告观点 |
|------|---------|---------|
| 合同性质 | 建设工程合同 | 承揽合同 |
| 法律适用 | 适用民法典 | 适用合同法（旧法） |
| 解释方法 | 文义解释 | 体系解释 |

### 8.3 争点整理的方法

**步骤**：
1. 列出所有要件
2. 逐个检查双方主张是否一致
3. 不一致的 → 标记为争点
4. 整理成争点清单

**争点清单模板**：

```
案件争点清单

【事实争点】
1. 合同是否实际签订？
   - 原告：有合同书为证
   - 被告：合同书上的签字是伪造的
   - 需要查明：签字真实性

2. 工程是否存在质量问题？
   - 原告：已通过验收
   - 被告：存在渗漏、空鼓
   - 需要查明：质量鉴定结果

【法律争点】
3. 本案应适用建设工程合同还是承揽合同？
   - 原告：建设工程合同（有优先受偿权）
   - 被告：承揽合同（无优先受偿权）
```

### 8.4 争点整理的作用

| 作用 | 说明 |
|------|------|
| 聚焦审理 | 双方围绕争点发言，不跑题 |
| 指导举证 | 只需要就争点举证，节省资源 |
| 预判裁判 | 争点查清了，结论基本就出来了 |
| 撰写文书 | 裁判文书围绕争点展开，逻辑清晰 |

## 九、第七步：要件事实证明

### 9.1 举证责任分配

**一般原则：谁主张，谁举证**

| 主张者 | 举证内容 | 法律依据 |
|--------|---------|---------|
| 原告 | 请求权基础的全部要件事实 | 民事诉讼法第67条 |
| 被告（抗辩） | 抗辩权基础的全部要件事实 | 同上 |

**特殊规则（举证责任倒置）**：

| 情形 | 倒置内容 | 法律依据 |
|------|---------|---------|
| 环境污染 | 因果关系由被告证明 | 民法典第1230条 |
| 医疗损害 | 因果关系+过错由医疗机构证明 | 民法典第1222条 |
| 建筑物倒塌 | 建设单位/施工单位证明无过错 | 民法典第1252条 |
| 劳动争议 | 部分事实由用人单位证明 | 劳动争议调解仲裁法第6条 |

### 9.2 证据的种类与效力

| 证据类型 | 效力层级 | 注意事项 |
|---------|---------|---------|
| 书证（合同、发票等） | 较高 | 原件优先，复印件需核对 |
| 物证 | 较高 | 需当庭出示或拍照 |
| 证人证言 | 较低 | 证人需出庭，书面证言效力弱 |
| 鉴定意见 | 较高 | 需双方认可或法院委托 |
| 勘验笔录 | 较高 | 法院现场勘验制作 |
| 电子数据 | 中等 | 需证明真实性、完整性 |

### 9.3 法官的四个任务

#### 任务1：帮助当事人理清举证任务

**做法**：
> "关于工程质量问题，原告需要证明：1. 工程存在哪些质量问题；2. 质量问题的原因是什么；3. 修复费用是多少。请围绕这三点举证。"

#### 任务2：分配举证责任

**做法**：
> "被告主张已付款，请提供付款凭证。如不能提供，将承担举证不能的后果。"

#### 任务3：心证公开

**定义**：法官将自己对证据的内心确信程度告知当事人。

**例子**：
> "目前原告提供的证据可以证明合同存在，但无法证明已实际交货。如果后续没有补充证据，这一点可能无法认定。"

**作用**：让当事人知道哪里薄弱，及时补充证据。

#### 任务4：审查证明方法是否用尽

**做法**：
> "原告主张损失金额，但仅提供了自己制作的清单，没有评估报告。是否申请司法鉴定？如不申请，可能按被告认可的金额认定。"

### 9.4 证明标准

| 程序 | 证明标准 | 说明 |
|------|---------|------|
| 民事诉讼 | 高度盖然性 | 可能性大于不可能性 |
| 刑事诉讼 | 排除合理怀疑 | 几乎确定 |
| 行政诉讼 | 优势证据 | 比对方更有说服力 |

## 十、第八步：事实认定

### 10.1 事实认定的层次

```
第一层：有证据证明的事实
    ↓ 双方有争议
第二层：根据证据证明力判断的事实
    ↓ 证据不足
第三层：根据举证责任分配认定的事实
    ↓ 仍无法认定
第四层：推定的事实（法律推定/事实推定）
```

### 10.2 证据的证明力判断

**原则**：
- 国家机关制作的公文书证 > 其他书证
- 原件 > 复印件
- 无利害关系证人 > 有利害关系证人
- 直接证据 > 间接证据
- 数个种类不同、内容一致的证据 > 数个种类相同的证据

### 10.3 事实真伪不明的处理

**概念**：双方都有证据，但法官仍无法确定真相。

**处理方法**：
> 根据举证责任分配原则，由负有举证责任的一方承担不利后果。

**例子**：
> 原告主张借款10万元，提供了借条。
> 被告主张已还，提供了收条。
> 两张都是真的。
> 但借条日期在收条之后。
> —— 法官认定：借款事实存在，但已还清（根据收条）。

### 10.4 裁判中的事实表述

**要求**：
- 写明"本院认定以下事实："
- 逐一列明认定的事实
- 写明证据来源
- 对不认定的事实说明理由

## 十一、第九步：要件归入并作出裁判

### 11.1 什么是"要件归入"

**定义**：将查明的案件事实，逐一与法律规范的构成要件进行比对，看是否满足。

**比喻**：法律规范是一个模具，案件事实是材料，看看材料能不能装进模具。

### 11.2 归入方法

**制作归入表**：

| 构成要件 | 案件事实 | 是否满足 | 结论 |
|---------|---------|---------|------|
| 要件1：合同有效 | 双方签订了书面合同，内容合法 | ✓ 满足 | |
| 要件2：一方违约 | 被告未按约定付款 | ✓ 满足 | |
| 要件3：造成损失 | 原告因资金占用产生利息损失 | ✓ 满足 | |
| 要件4：因果关系 | 违约行为直接导致损失 | ✓ 满足 | |
| 结论 | | | 违约责任成立 |

### 11.3 裁判文书的三段论结构

```
大前提（法律规范）：根据民法典第577条...
    ↓
小前提（案件事实）：本案中，原被告签订了...，被告未...
    ↓
结论：被告应承担违约责任，向原告支付...
```

### 11.4 裁判说理的要点

1. **引用的法律条文要具体**：不能只说"根据有关法律规定"
2. **事实认定要对应要件**：不要罗列无关事实
3. **逻辑链条要完整**：不要跳步
4. **对争议焦点要回应**：逐一说明支持或反对的理由

## 十二、律师代理视角：逆向运用九步法

### 12.1 接案评估：从第9步倒推

**步骤**：
1. **预判结果**：如果走到第9步，当事人能赢吗？
2. **检查要件**：哪些要件已经满足？哪些有缺口？
3. **评估风险**：缺口的证据能不能补上？对方有什么抗辩？

**接案评估表**：

| 要件 | 现有证据 | 缺口 | 能否补上 | 风险等级 |
|------|---------|------|---------|---------|
| 合同成立 | 合同书 ✓ | | | 低 |
| 已履行 | 送货单 ✓ | | | 低 |
| 对方违约 | 对账单 ✓ | | | 低 |
| 损失金额 | 无 | 需评估 | 可申请鉴定 | 中 |

### 12.2 起诉前：制作"要件-证据"对照表

**目的**：起诉前就发现证据缺口，及时补强。

**模板**：

```
案件：XXX诉XXX建设工程施工合同纠纷

请求权基础：民法典第788条 + 第807条（优先受偿权）

【要件-证据对照表】

要件1：合同关系存在
  - 证据：建设工程施工合同 ✓
  - 风险：无

要件2：工程已竣工并验收
  - 证据：竣工验收报告 ✓
  - 风险：报告上签字不全

要件3：发包人欠付工程款
  - 证据：结算单（双方未签章）⚠️
  - 风险：结算金额可能有争议
  - 补强：申请造价鉴定

要件4：优先受偿权未超期
  - 证据：工程交付日期2023年6月1日
  - 计算：18个月 → 2024年12月1日前
  - 风险：起诉日期2024年11月15日 ✓
```

### 12.3 庭审中：围绕争点发言

**不要**：
- 念起诉状/答辩状
- 讲故事
- 发泄情绪

**要**：
- "关于争点1（合同是否成立），我方认为..."
- "对方主张的XX要件，证据不足，理由是..."
- "我方已就XX要件完成举证，对方未提出有效反驳..."

### 12.4 庭后：核对要件归入

**拿到判决后**：
1. 法院认定的事实是否对应了要件？
2. 法律适用是否正确？
3. 有无遗漏争点？
4. 上诉的重点是什么？（哪个要件认定错了？）

## 十三、建工案件特别应用

### 13.1 建工案件的复杂性

建工案件为什么难？因为涉及多个法律关系：

- 建设工程合同关系
- 分包合同关系
- 劳动关系（农民工工资）
- 材料供应合同关系
- 融资租赁关系
- 担保关系
- 优先受偿权关系

### 13.2 建工案件的请求权基础检索

**第一层：合同内请求权**
- 发包人请求权：质量瑕疵修复、工期延误赔偿
- 承包人请求权：工程款、变更价款、索赔

**第二层：法定请求权**
- 优先受偿权（民法典第807条）
- 实际施工人突破合同相对性（建工司法解释一第43条）
- 代位权（民法典第535条）

**第三层：侵权责任**
- 工程缺陷导致人身损害
- 建筑物倒塌责任（民法典第1252条）

### 13.3 建工案件的常见争点

| 争点 | 原告立场 | 被告立场 |
|------|---------|---------|
| 合同效力 | 有效 | 无效（无资质/挂靠/必须招标未招标） |
| 工程价款 | 按合同约定/鉴定金额 | 按实结算/扣除质量修复费 |
| 工期延误 | 发包人原因/不可抗力 | 承包人原因 |
| 质量责任 | 已验收合格 | 存在隐蔽瑕疵 |
| 优先受偿权 | 在期限内行使 | 超期/已放弃 |

### 13.4 建工案件的证据组织

**承包人起诉发包人，证据分组建议**：

```
第一组：主体证据
  - 营业执照（证明资质）
  - 合同（证明法律关系）

第二组：履约证据
  - 施工日志
  - 监理签字文件
  - 验收报告

第三组：价款证据
  - 结算单
  - 付款凭证
  - 催款函

第四组：索赔证据
  - 变更指令
  - 签证单
  - 损失计算依据

第五组：优先受偿权证据
  - 工程交付日期证明
  - 起诉时间证明
```

### 14.4 常见问题FAQ

**Q1：九步法只适用于法官吗？**
A：不是。律师、法务、仲裁员都可以运用。律师是"逆向运用"——从第9步倒推，提前准备证据。

**Q2：所有案件都必须严格走九步吗？**
A：简单案件可以简化，但思维框架不能丢。复杂案件建议严格走。

**Q3：九步法和传统审判方法有什么区别？**
A：传统方法是从"事实"出发找"法律"，九步法是从"请求"出发找"法律"再查"事实"，方向相反，逻辑更严密。

**Q4：助理最快多久能掌握？**
A：理论学习1周，实操练习1个月，基本能上手。精通需要持续办案积累。
