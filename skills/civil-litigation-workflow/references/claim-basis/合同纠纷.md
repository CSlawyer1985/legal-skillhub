# 合同纠纷 请求权基础

> 供模块 02 确定合同类案由后**强制加载**。本文件覆盖合同通则层级（违约/解除/赔偿体系），具体有名合同（买卖、租赁、承揽等）遇案时在"复盘沉淀"增补专节。
> 法源：民法典合同编 + 合同编通则司法解释（法释〔2023〕13号）。引用条文前按防幻觉机制核验。

## 一、请求权基础清单（按检索顺序）

**第一层：合同内请求权**
- 继续履行：民法典第577、580条（非金钱债务继续履行的三种排除情形：法律/事实不能、标的不适于强制履行、合理期限内未请求）
- 赔偿损失：民法典第577、584条（**可预见性规则**：不超违约方订立合同时预见到或应当预见到的损失）
- 支付违约金：民法典第585条 + 合同编通则解释第65条（**超过损失30%一般认定"过分高于"**，可请求酌减；恶意违约方请求酌减的从严）
- 定金罚则：民法典第586、587条（**不得超过主合同标的额20%**，超出部分不产生定金效力）
- 价款/报酬请求权：有名合同特别条款（买卖第626条等）

**第二层：合同效力变动后的请求权（类合同）**
- 合同无效/被撤销后的返还财产、折价补偿、过错赔偿：民法典第157条
- 缔约过失：民法典第500条（恶意磋商、隐瞒重要事实）、第501条（泄露商业秘密）
- 合同不成立时的费用与信赖利益赔偿：合同编通则解释相关规定

**第三层：债权保全（代位/撤销）**
- 债权人代位权：民法典第535条（债务人怠于行使到期债权影响债权实现）
- 债权人撤销权：民法典第538、539条（无偿转让/明显不合理低价），**除斥期间：知道撤销事由1年、行为发生5年**（第541条）

**第四层：违约救济的前置形成权**
- 法定解除权：民法典第563条（不可抗力/预期违约/迟延履行经催告仍不履行/根本违约）
- 约定解除权：第562条
- 解除程序：第565条（通知到达生效；对方异议可诉请确认解除效力）
- 解除后果：第566条（恢复原状、补救、赔偿；**合同解除不影响违约金条款适用**——第566条第2款）

## 二、构成要件表

### 2.1 违约责任（第577条）

| 要件 | 法律依据 | 具体条件 | 举证责任 |
|------|---------|---------|---------|
| 合同有效成立 | 第143、502条 | 主体适格、意思表示真实、内容合法；书面/口头/其他形式均可 | 原告：合同文本/订单/往来记录/履行事实 |
| 违约行为 | 第577条 | 不履行 / 履行不符合约定（迟延、瑕疵、部分履行） | 原告：交付记录/验收记录/催告函 |
| 无免责事由 | 第590条 | 不可抗力须同时满足：不能预见、不能避免、不能克服 + 及时通知 + 证明 | **被告**就免责事由举证 |

### 2.2 赔偿损失（第577+584条，在2.1基础上追加）

| 要件 | 法律依据 | 具体条件 | 举证责任 |
|------|---------|---------|---------|
| 损失实际发生 | 第584条 | 实际损失 + 可得利益（履行后可以获得的利益） | 原告：发票/合同/审计报告/同类交易价格 |
| 因果关系 | 第584条 | 违约行为与损失之间相当因果 | 原告主张，被告可攻击介入因素 |
| 可预见性 | 第584条但书 | 以违约方**订立合同时**预见为标准 | 被告可抗辩不可预见 |
| 减损规则 | 第591条 | 守约方未采取适当措施致损失扩大的部分不得请求 | **被告**举证 |
| 过失相抵 | 第592条第2款 | 守约方对损失发生有过错的减少相应赔偿 | **被告**举证 |

### 2.3 合同解除（第563条）

| 要件 | 具体条件 | 举证责任 |
|------|---------|---------|
| 解除事由 | 五种法定情形之一（重点：迟延履行**经催告后**合理期限内仍未履行 / 致使不能实现合同目的） | 原告：催告函及送达证据、违约证据 |
| 解除权未消灭 | 知道解除事由后**1年内**行使（解除权除斥期间，第564条） | 被告可就超期举证 |
| 解除通知到达 | 通知到达对方时解除；直接起诉的，起诉状副本送达时解除 | 原告：送达凭证 |

## 三、常见抗辩（被告轨检索用）

**妨碍**：合同不成立（未达成合意/要约承诺未完成）、无效（第153条恶意串通/违反效力性强规）、可撤销（欺诈/胁迫/重大误解/显失公平——注意90日/1年除斥期间）、无权代理（反向核查表见代理第172条）、格式条款未提示说明（第496条）。

**消灭**：清偿、抵销（第568条，**可在答辩中直接主张**）、免除、混同、提存、诉讼时效届满（3年，合同请求权自履行期届满起算；分期履行自最后一期起算）。

**阻止**：同时履行（第525条）/先履行（第526条）/不安（第527条，**须中止+及时通知，否则反成违约方**）。

**减额抗辩（违约方专用四件套）**：
1. 违约金过高酌减（30%规则，合同编通则解释第65条）——**主动提出**，法院不主动调整；
2. 损失不可预见（第584条但书）；
3. 守约方未减损（第591条）；
4. 过失相抵（第592条）。

## 四、此诉彼诉辨析

| 易混淆 | 区分要点 | 后果差异 |
|--------|---------|---------|
| 买卖 vs 承揽 | 标的物是种类物还是按特定要求完成工作成果 | 承揽有定作人任意解除权（第787条）；检验规则不同 |
| 委托 vs 行纪 vs 中介 | 以谁名义、是否自担交易后果、促成交易还是处理事务 | 费用承担、责任归属完全不同 |
| 预约 vs 本约 | 是否约定将来一定期限内订立合同 | 预约违约只能请求订立本约或赔偿信赖利益，不能直接请求履行本约内容 |
| 借款 vs 投资/合伙 | 是否固定收益、是否共担风险、是否参与经营 | 投资亏损不得请求返还本金；借贷可 |
| 继续履行 vs 解除 | 合同目的能否实现、当事人意愿 | 二者对抗，起诉时必须择一（可备选主张） |

## 五、特殊利益提示

1. **违约金30%规则是攻防双向杠杆**：守约方主张损失举证从严把握（法院对"损失"认定含可得利益）；违约方必须主动提出酌减请求，且恶意违约从严。
2. **定金与违约金只能择一适用**（第588条）——起诉时算清楚哪个高选哪个。
3. **检验期间是买卖合同的生命线**：约定检验期间的从约定；未约定的，买受人应在合理期间内通知，最长自收到标的物之日起**2年**（第621条）；质保期另算。代理卖方——买方超期未提异议视为质量合格；代理买方——固定检验和通知证据。
4. **管辖协议审查**：约定管辖法院须与争议有实际联系（被告住所地/合同履行地/合同签订地/原告住所地/标的物所在地），格式条款中的管辖条款未提示说明的可被排除。
5. **利息/资金占用费**：无约定时按同期LPR主张资金占用损失，起算点结合催告时间确定。

### 投标保证金纠纷（串标不退型）｜2026-08-03 回写自（2024）浙1023民初2031号

**场景**：投标人串标被作无效标，招标人不予退还投标保证金，投标人诉请返还。代理招标人（被告轨）全胜经验：

1. **约定依据链四环节**（缺一不可，庭审要焊死）：招标文件保证金处理条款（如 3.4.4）+ 前附表对保函内容的要求 + 诚信投标承诺书（“愿意接受投标担保的处理”）+ 保函担保范围条款；再叠加地方公管办文件（如台公管办〔2022〕2号第11条）作行业明知佐证。
2. **胜负手是自认固定**：投标人付款回单备注“保证金没收”+ 收据载明“没收”= 接受处置结果的禁反言证据；答辩时先纠正起诉状事实表述偏差（“缴纳保证金”实为保函），把叙事主导权拿过来。
3. **风险点**：串标非法定没收情形（实施条例列举不含串标），裁判有分歧；法院可能绕开合同分析仅以诚信原则（民法典第7条）定案——胜诉但说理脆弱，二审须把裁判依据抬回合同约定。行政处罚与民事处置并行不悖（不因已罚款而免除民事后果）。
4. **原告轨反向提示**：若代理投标人，攻击点为约定未明示“不予退还”、付款系保函索赔压力下的非真实意思、基本原则不得迳行裁判。

### 设备买卖合同（分期付款+违约金+利息并用场景）｜2026-08-06 回写自（2024）湘0104民初22319号

**场景**：卖方诉买方拖欠设备货款，合同约定逾期付款违约金（2‰/天上限 5%），原告同时主张 1.5 倍 LPR 利息+违约金。代理原告（卖方）经验：

1. **利息+违约金并用风险实证**：约定了违约金条款再主张法定利息损失，法院立场是违约金吸收利息（违约金=迟延损失预定填补）；本案诉中以变更诉请打包方式放弃了利息违约金单列。原告轨仍应主张（原则 11），但预期值测算中利息按“被吸收”口径给概率。
2. **检验期间是卖方护城河**：买方使用设备多年未书面提质量异议，检验期（无约定最长 2 年，第 621 条）+保修期均过，付款条件“投用一年后无质量问题”视为成就——无需验收报告。
3. **无送货单的交货证明**：间接证据链可达高度盖然性——买方投入使用（官网新闻/订房平台）+部分付款+对方函件不否认收货+设备实物在用（必要时现场证据保全）。
4. **付款给离职项目经理个人不构成清偿**：合同载明公司账户+大额付个人+卖方无授权 → 表见代理（第 172 条）难成立（相对人非善意）；但此类争议在调解中通常折中收场（本案双方 190 万/324 万主张折中为 292 万）。
5. **“设备买卖+安装施工”双合同分管辖区案件**：买卖合同约定法院管辖、安装合同约定仲裁的，必须分案处理；但调解阶段可跨程序打包（见模块 10“扩围打包和解”），把仲裁线弱债权并入诉讼调解书确认。
6. **对方盖章回函的三重价值**：承认债务（时效中断，第 195 条）+锁定对方付款口径+暴露其内部人员离职导致的结算困难——催收函件务必争取对方书面回复。
