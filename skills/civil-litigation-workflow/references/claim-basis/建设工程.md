## 〇、法规版本警示（2026 年必读）

**建工解释二已于 2026-06-30 施行**，以下规则发生实质变化，禁止机械援引旧规：

| 变化 | 旧规 | 新规（解释二） |
|------|------|--------------|
| 实际施工人告发包人 | 解释一第43条：可在发包人欠付范围内直接担责 | **路径收窄**：解释二第6条——接受转包/违法分包者只能向合同相对方（承包人）请求折价补偿；对发包人原则上只能走**代位权**（第7条+民法典第535条，须证明转包人怠于行使到期债权） |
| “实际施工人”概念 | 笼统使用 | 不再使用，按“转包”“违法分包”分别配置救济 |
| 借用资质 | 合同无效 | 无效+借用费不受保护；**质量合格时借用方可参照约定请求折价补偿**（第3条）；借用方以出借方名义采购租赁，出借方可能承担**表见代理**责任（第5条） |
| 必须招标未招标 | 一律无效 | 订立时应招标但**起诉时已不属必须招标范围**的，不因此无效（第1条） |
| 优先受偿权判决 | 可笼统确认 | **判决主文必须写明数额与对应工程**（第17条）；停工窝工损失**不享有**优先受偿权（第17条2款）；可物上代位于保险金/赔偿金/补偿金（第20条） |
| 优先受偿权起算 | 自应付工程价款之日起18个月 | 协商变更付款日期的从变更后起算；结算协议约定付款日期的从该日起算（第21条） |
| 固定总价解除 | 按实结算争议大 | 可按主管部门计价标准算已施工比例×固定总价（第10条） |
| 以审计为结算依据 | 审计久拖不决无解 | 非因承包人原因逾期未出具或明显不符的，准许造价司法鉴定（第13条） |
| 质量修复费用 | 承包人拒绝修复→可减少价款 | 发包人须**先通知修复**，承包人拒绝/逾期未修复才能自行修复后追偿（第16条） |

## 一、主体识别（先定身份，再谈请求权）

| 主体 | 识别要点 | 诉讼地位规则 |
|------|---------|------------|
| 发包人 | 与承包人订施工合同、负付款义务 | — |
| 承包人 | 有资质、直接承揽 | 优先受偿权主体（解释一第35条） |
| 分包人 | 专业分包（合法）/ 劳务分包 | 向合同相对方主张 |
| 转承包人 / 违法分包人 | 接受转包、违法分包的单位或个人 | 解释二后：原则只能告合同相对方；对发包人走代位权（举证“发包人欠付转包人/违法分包人工程款”） |
| 借用资质的实际施工人 | 以他人名义签约施工 | **发包人知道或应当知道借用资质的，可直接以发包人为被告**（解释二第4条但书）；不知道的，只能告出借资质方（解释二第3条） |

## 二、请求权基础清单（按检索顺序）

**第一层：合同请求权**
- 工程款请求权：民法典第788条 + 施工合同付款条款
- 停窝工损失：民法典第803条（未按约提供资料/场地）、第804条（发包人原因停建缓建）
- 逾期付款利息：合同条款 + 解释一第26、27条
- 工期索赔/质量修复：合同条款 + 民法典第801条
- 解除合同：民法典第806条（对方转包违法分包 / 发包人不履行协助义务经催告仍不履行）

**第二层：合同无效时的折价补偿（类合同）**
- 民法典第793条第1款：合同无效但**验收合格**→可**参照合同约定折价补偿**（“参照合同关于工程价款的约定”范围含金额、计价方式、支付时间、调整与结算方法——解释二第11条）
- 验收不合格：修复后合格→发包人可请求承包人承担修复费用；修复后仍不合格→无权请求折价补偿（民法典第793条第2款、解释一第6条）
- 无效后双方达成折价补偿协议的，按协议（解释二第12条）

**第三层：法定特别请求权**
- **建设工程价款优先受偿权：民法典第807条 + 解释一第35–42条 + 解释二第17–21条**（见第五节，本案由最大杠杆）
- 代位权：民法典第535条 + 解释一第44条（解释二后实际施工人对发包人的主通道）

**第四层：侵权 / 不当得利**（补充，少用）
- 工程缺陷致人身财产损害：民法典第802条、第1252条（建筑物倒塌）

## 三、构成要件表

### 3.1 工程款请求权（核心）

| 要件 | 法律依据 | 具体条件 | 举证责任 |
|------|---------|---------|---------|
| 合同关系 | 民法典第788条 | 施工合同或事实施工关系 | 原告（承包人）：合同/中标通知书/进场施工事实 |
| 质量合格 | 民法典第799条、解释一第14条 | **质量合格是付款前提**；未经竣工验收发包人擅自使用的视为认可（**地基基础和主体结构除外**） | 原告：竣工验收报告/擅自使用证据 |
| 价款确定 | 合同 + 解释一第28条 | 固定价/可调价/结算协议/鉴定；**约定固定价的原则上不准鉴定** | 原告：结算书/签证/鉴定意见 |
| 欠付事实 | — | 应付 − 已付；已付款项注意区分借款、往来款、走账、代付 | 原告：结算+收款凭证；被告主张已付的就被告举证 |
| 应付时间 | 解释一第27条 | 有约从约；无约：交付之日 / 提交结算文件之日 / 起诉之日 | 原告 |

### 3.2 优先受偿权

| 要件 | 法律依据 | 具体条件 | 举证责任 |
|------|---------|---------|---------|
| 主体 | 民法典第807条、解释一第35条 | 与发包人订约的承包人（装饰装修承包人限装饰装修部分，解释一第37条） | 原告 |
| 质量合格 | 解释二第18条 | 施工工程质量合格 | 原告 |
| 发包人欠付 | 民法典第807条 | 经催告后合理期限仍未支付 | 原告：催告函留痕 |
| 范围 | 解释一第40条、解释二第17条 | 限工程价款本身；**利息、违约金、损害赔偿金、停窝工损失不在优先范围** | — |
| 期限 | 解释一第41条、解释二第21条 | **最长18个月**，自发包人应付工程价款之日起算（变更/结算协议约定的新起算点可用） | 原告：起算点证据 |
| 顺位 | 解释一第36条 | 优于抵押权和其他债权 | — |
| 判决形式 | 解释二第17条 | **诉请中明确要求判决主文写明优先受偿数额与对应工程** | 原告 |

### 3.3 停窝工损失

| 要件 | 法律依据 | 具体条件 | 举证责任 |
|------|---------|---------|---------|
| 发包人原因 | 民法典第803、804条 | 未按约提供场地/图纸/资金/甲供材，或停建缓建 | 原告：停工指令/监理日志/往来函件 |
| 损失实际发生 | — | 人工、机械台班、周转材料租赁、管理费 | 原告：考勤/租赁合同/付款凭证 |
| 因果关系与减损 | 民法典第591条 | 停工期间与损失对应；原告负减损义务 | 原告主张，被告可攻击 |

## 四、常见抗辩（被告轨检索用）

### 权利妨碍抗辩（合同不成立/无效 → 转入折价补偿轨道）
- 无资质、超越资质（竣工前取得资质的除外）：解释一第1条
- 借用资质：解释一第1条、解释二第3条
- 必须招标未招标或中标无效：解释一第1条（注意解释二第1条的动态范围例外）
- 支解发包、转包、违法分包：民法典第791条、解释一第1条
- 串通投标、明招暗定、确定中标人前实质性谈判：解释二第2条

### 权利消灭抗辩
- 已清偿（注意“部分清偿”“第三人代付”“以房抵债”的认定）
- 抵销（反诉质量修复费、逾期违约金）
- 诉讼时效届满：工程款请求权时效3年，自应付之日起算；分期履行的自最后一期届满起算（民法典第188、189条）

### 权利阻止抗辩
- 先履行抗辩：承包人未先完成施工/未提交竣工资料（民法典第526条）
- 质量抗辩：质量不合格→拒绝付款/减少价款（民法典第801条、解释一第12条；**发包人须先通知修复**——解释二第16条）
- 同时履行抗辩：约定“先开票后付款”条款的效力与适用

### 程序性抗辩
- 管辖：**建设工程施工合同纠纷按不动产纠纷专属管辖**（民诉法解释第28条）——工程所在地法院
- 仲裁条款审查：合同约定有效仲裁条款的，法院无管辖权

## 五、此诉彼诉辨析

| 易混淆 | 区分要点 | 后果差异 |
|--------|---------|---------|
| 建设工程合同 vs 承揽合同 | 标的是否为不动产建设工程、是否需要施工资质 | 建工有优先受偿权、专属管辖、质量规则；承揽没有 |
| 施工合同 vs 劳务分包/劳务合同 | 是否包工包料、是否承担工程质量责任 | 劳务无优先受偿权 |
| 转包 vs 内部承包 | 内部承包人有劳动关系、受发包企业管理、自担盈亏 | 内部承包合同原则有效。**内部承包认定五要素**（（2022）粤0784民初3314号实证）：①劳动合同+社保+按月工资（排除挂靠）②发包人对施工过程监督管理、提供设备主材办证等核心支持③双方就其他项目有成本核算惯例互印证④承包人自认（书面申请/庭审陈述中认可成本核算结算方式）⑤独立核算、自负盈亏。内部承包成立的：**员工身份排除解释一第43条“实际施工人”路径**，结算按内部制度（用款制+成本核算差额），建工分包规则不适用 |
| 借用资质 vs 转包 | 名义承包人是否参与管理、谁与发包人缔约 | 救济路径不同（见主体识别表） |
| 工程款 vs 借款/投资款 | 资金流向、是否有施工事实、结算文件 | 案由不同→要件、管辖、利息规则全不同 |

## 六、特殊利益提示（本案由特有杠杆）

0. **指定分包/通谋虚假结构专项**（案例A复盘新增）：业主指定分包 + 总包仅转付的结构下——①名义分包合同可能被认定**三方通谋虚假表示无效**（民法典第 146 条），但法院会进一步认定分包人与发包人之间的**事实施工合同关系有效**，由发包人直接担责；②接案**必须先 OCR/调取三方备忘录、分包人承诺书**——若存在“建设方未支付，分包人不得要求总包支付”的背靠背承诺，总包基本免责，主攻方向就是发包人；③此结构下分包人的优先受偿权**预判不支持**（（2023）苏 0115 民初 12978 号：被指定分包人不享有 + 房屋已售完不具行使条件）——但属争议问题，诉请仍应主张并披露风险留痕（核心原则 11）；④案由与叙事选择“装饰装修合同纠纷 + 分包人=承包人”更利于向发包人主张。
1. **优先受偿权是最大杠杆**：优于抵押权！接案第一件事核对18个月期限是否经过（起算点按解释二第21条动态确定）。分包人（含指定分包）的优先权**预判不支持**（（2023）苏0115民初12978号），但**预判≠放弃**：诉请中仍应主张并向当事人书面披露风险、留痕确认（主控核心原则第11条）。
2. **质量合格是付款前提，也是双刃剑**：代理承包人——固定“验收合格”证据；代理发包人——地基基础/主体结构质量主张不受擅自使用影响。
3. **固定价 vs 鉴定**：约定固定价的，对方申请鉴定原则上不准（解释一第28条）——代理被申请方要主动提出异议。
4. **利息规则**：有约从约（注意LPR四倍上限不适用于工程款，但过高违约金可调整）；无约按同期LPR（解释一第26条），起算按第27条三个时点。**⚠️ 混合支付条款联动评估**（案例A教训）：合同约定“现金+工抵”混合支付的，法院可能认定货币支付达约定现金比例即不构成违约，利息请求大幅压缩；“未付足部分不计息”条款直接排除部分利息。做利息预判前必须同时扫描付款方式条款与不计息条款，三者联动评估。
5. **价款含税推定规则**（案例D复盘新增，(2024)渝01民终12145号实证）：合同未明确约定价款为不含税价的，依《价格管理条例》第6条**推定为含税价**（价格构成=成本+税金+利润+流通费用）——一审以主合同计税习惯/内部表格“未注明含税”推定分包价不含税被二审纠正（违反合同相对性、交易习惯无事实依据，可用另案判决反证无此习惯）。配套武器：①合同约定“先开票后付款”+承包人系无开票能力自然人的，主张含税价同时锁死税金利益归属；②合同外新增工程双方明确“不含税、含税加9%”的属特别约定，**应付款按不含税价确定**（发包人已向业主开票的，税金成本由未开票的承包人承担），且对方起诉状按不含税价主张的构成自认；③税率变动“税差”扣除主张缺乏合同及法律依据，二审明确不支持（附带主张即可，别指望）。
6. **效力定性与利息防线联动**（案例D教训）：内部承包有效 vs 违法分包无效的定性**不只是金额问题**——无效则“先开票后付款”条款无效→利息防线崩塌；有效则条款有效→未开票→付款条件未成就→利息不支持。裁判分析/上诉点检索时，无直接金额的定性点若与对方武器库联动，必须列入主张或防守清单（川渝地区内部承包有效另有地方规则加持：川渝高院建工解答第8条、浙江高院2012解答第1条、住建部建市施函〔2014〕163号释义、最高法3784号答复）。**补强（案例D模块09盲测对照实证）**：即使一审未采纳内部承包定性、认定合同无效，“先开票后付款”条款仍可能被判决引用说理驳回利息（(2023)渝0109民初8839号：认定无效但仍以承包人未开票为由全驳利息诉请）——无效认定不必然击穿利息防线，利息防线应独立主张、不与效力定性捆绑。
7. **证据组织分组**（援引九步法建工应用）：主体证据 / 履约证据（施工日志、监理签字、验收报告）/ 价款证据（结算单、付款凭证、催款函）/ 索赔证据（变更指令、签证单）/ 优先受偿权证据（交付日期、起诉时间）。
8. **28项要素表**：接案后逐项核对《建设工程合同案件要素表（原告联/被告联）》（可选扩展资料，见第七节）。
