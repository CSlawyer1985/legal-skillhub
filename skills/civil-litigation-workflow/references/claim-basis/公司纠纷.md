## 一、请求权基础清单（按纠纷对象分组）

### 1.1 股东 vs 公司
| 请求权 | 法律依据（公司法） | 要点 |
|--------|------------------|------|
| 知情权（查阅复制权） | 第57条 | 章程/名册/决议/财报可复制；**会计账簿、会计凭证**可查阅（书面请求+说明目的；公司15日内答复，以"不正当目的"拒绝的须举证） |
| 利润分配请求权 | 第210条 | 原则须股东会决议为前提；例外：滥用股东权利不分配利润致损的可司法强制分配（九民纪要规则） |
| 异议股东回购请求权 | 第89条 | 连续5年盈利不分红、合并分立转让主要财产等情形，投反对票股东可请求公司回购；60日协商期+90日起诉期 |
| 请求公司回购（对赌/禁止性回购情形另论） | 第89、161条 | 有限公司与股份公司规则不同 |
| 公司决议无效/可撤销/不成立确认 | 第25、26、27条 | 内容违法=无效；程序违法或内容违章=可撤销（**60日**除斥期间，自决议作出起算）；未开会/未表决/出席或表决未达比例=不成立 |
| 解散公司之诉 | 第229、231条 | 经营管理发生**严重困难**+持股10%以上+通过其他途径不能解决 |
| 涤除登记之诉 | 第10、70条+案由新规 | 辞任法代/董监高后公司拒不办理变更登记，可诉请涤除（2025案由新规已单列四级案由） |

### 1.2 股东 vs 股东 / 董监高
| 请求权 | 法律依据 | 要点 |
|--------|---------|------|
| 出资违约（对已缴股东） | 第49条 | 未按期足额缴纳的股东向已足额缴纳的股东承担违约责任 |
| 股东失权 | 第52条 | 公司书面催缴+**不少于60日宽限期**+董事会决议+书面失权通知；失权股东有异议的30日内起诉 |
| 股权转让纠纷 | 第84、88条 | 对外转让：书面通知其他股东+优先购买权；**第88条：未届出资期限的股权转让，受让人承担出资义务，转让人补充责任** |
| 董监高损害赔偿（信义义务） | 第180–184条 | 忠实勤勉义务、关联交易报告与回避（182）、篡夺公司机会（183）、同业竞争（184） |
| 股东代表诉讼 | 第189条 | 前置程序：书面请求监事会/董事会起诉，拒绝或30日未起诉或情况紧急，股东以自己名义起诉（有限公司任一股东；股份公司连续180日+1%） |

### 1.3 债权人 vs 公司/股东（追债路径图——代理债权人必读）

```
第一层：公司有钱？ → 执行公司财产
第二层：股东出资到位？ → 未出资/抽逃：第53条（抽逃返还）+ 第54条（加速到期）
        + 执行追加（变更追加规定第17/18条）或另诉（2025案由新规已有"股东出资加速到期纠纷"独立四级案由）
第三层：纵向人格否认 → 第23条第1款（股东滥用→连带责任）
第四层：横向人格否认 → 第23条第2款（姐妹公司混同→相互连带）⭐ 新公司法新增
第五层：一人公司 → 第23条第3款（股东自证财产独立，举证责任倒置）
第六层：代位权（民法典535）/ 撤销权（538-542）/ 清算责任（232条：董事为清算义务人）
```

**加速到期是新公司法最大变化**：公司不能清偿到期债务，债权人即可要求未届出资期限的股东提前缴纳出资（第54条）——认缴制的"期限利益"保护大幅弱化。

## 二、构成要件表（选高频三类）

### 2.1 公司决议纠纷（第25/26/27条）

| 要件 | 无效 | 可撤销 | 不成立 |
|------|------|--------|--------|
| 事由 | 内容违反法律法规 | 程序违反法律法规或章程 / 内容违反章程 | 未召开会议 / 未表决 / 出席人数或表决权未达规定 / 表决结果未达通过比例 |
| 期限 | 无 | **60日**（自决议作出之日起，除斥期间） | 无 |
| 原告 | 利害关系人 | 起诉时具有股东资格 | 利害关系人 |
| 宽宥 | — | 程序瑕疵轻微且未产生实质影响的，可裁量驳回 | — |

### 2.2 股东代表诉讼（第189条）

| 要件 | 具体条件 | 举证责任 |
|------|---------|---------|
| 原告资格 | 有限公司任一股东 / 股份公司连续180日以上单独或合计持股1%以上 | 原告：股东名册/持股证明 |
| 前置程序 | 书面请求监事会（或董事会）起诉 + 被拒/30日未诉/情况紧急 | 原告：书面请求及送达证据 |
| 被告侵权事实 | 董监高/他人损害公司利益 | 原告初步举证 |
| 利益归属 | 胜诉利益归**公司**（非原告），合理费用公司承担 | — |

### 2.3 人格否认（第23条）——要件速览，详见公司法详解文件

| 形态 | 要件核心 | 举证责任 |
|------|---------|---------|
| 纵向（1款） | 滥用行为（人格/财产混同、过度控制、资本显著不足）+ 逃避债务 + 严重损害债权人 + 因果 | 债权人 |
| 横向（2款） | 同一股东控制两个以上公司 + 滥用 + 损害 | 债权人 |
| 一人公司（3款） | 只有一个股东 + 财产不独立 | **股东自证独立**（年度审计报告须无保留意见+独立账簿+资金往来有据） |

## 三、常见抗辩（被告轨检索用）

**妨碍**：决议撤销超60日除斥期间 / 起诉时已无股东资格 / 知情权查阅有"不正当目的"（公司举证：竞业、泄密前科）/ 代表诉讼前置程序未履行（裁定驳回）。

**消灭**：出资已缴纳或已补足（验资报告+银行流水）/ 股权已合法转让且受让人缴资（第88条责任转移）/ 债务已清偿 / 时效届满（注意：知情权、决议确认类形成权之诉不适用时效；出资责任原则上不受时效限制）。

**程序**：原告主体资格（隐名出资人须先确权）/ 仲裁条款（章程或股东协议中的仲裁条款对公司决议纠纷的适用有争议，多数观点认为决议效力之诉不可仲裁）/ 重复起诉。

**人格否认的防御**（代理股东/公司）：审计报告连续无保留 + 独立账簿 + 股东借款有合同有利息 + 经营场所人员独立的证据链；补充性原则抗辩（债权人有代位权等其他救济未用尽）。

## 四、此诉彼诉辨析

| 易混淆 | 区分要点 | 后果差异 |
|--------|---------|---------|
| 股东出资纠纷 vs 执行追加 | 法定可追加情形走执行程序（快）；争议大/情形外的另诉（稳） | 追加被驳回不影响另诉；另诉可一并保全股东财产 |
| 决议不成立 vs 可撤销 | 程序"有无"问题=不成立；程序"好坏"问题=可撤销 | 不成立无60日限制，选错案由可能因超期败诉 |
| 解散之诉 vs 回购请求 | 解散是"同归于尽"，回购是"体面退出" | 回购对股东更优时优先评估第89条 |
| 名义股东 vs 实际出资人 | 代持协议效力原则有效（公司法解释三）；显名须其他股东过半数同意 | 实际出资人不能直接对抗公司债权人 |
| 股权转让 vs 股权让与担保 | 是否真实买卖意思、是否办理变更+参与经营 | 让与担保按担保规则处理，流质条款无效 |

## 五、特殊利益提示

1. **案由新规联动**（2025第三次修正）：股东失权纠纷（294）、董监高解任纠纷（300）、涤除公司登记备案纠纷（292项下四级）、决议不成立确认纠纷（299项下四级）、出资加速到期（293项下四级）——起诉状案由按新规定填写；
2. **横向否认+纵向否认可并用**（最高院（2020）民申1106号）——被告列明策略：公司+滥用股东+混同姐妹公司一并起诉；
3. **一人公司举证倒置是最锋利的刀**：发现被告是一人公司（含一人股份公司），直接在诉请中列股东为共同被告，让对方自证财产独立；
4. **失权制度攻防**：代理公司——宽限期不少于60日、书面通知、董事会决议程序缺一不可；代理股东——失权通知送达起30日内起诉异议；
5. **时间效力**：新公司法施行前的法律事实引起的纠纷，适用当时的法律，但新增规定明显更有利于当事人的情形除外（《公司法时间效力规定》）——接案先锚定法律事实发生时点。
