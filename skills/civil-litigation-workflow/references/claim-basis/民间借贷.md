# 民间借贷 请求权基础

> 供模块 02 确定民间借贷案由后**强制加载**。
> 法源：民法典第667条以下 + 民间借贷司法解释（法释〔2015〕18号，2020年第二次修正）。引用条文前按防幻觉机制核验。

---

## 一、请求权基础清单

**第一层：合同内请求权**
- 返还本金：民法典第675条（期限届满返还；未约定期限的，催告后合理期限内返还）
- 借期内利息：民法典第680条 + 民间借贷解释第25条（**有约从约，但不得超过合同成立时一年期LPR四倍**；未约定利息的视为无息）
- 逾期利息/资金占用费：民法典第676条 + 解释第28条：
  - 约定逾期利率的从约定（不超四倍）；
  - 只约定借期利率未约定逾期利率的，按借期利率主张资金占用期间利息；
  - 均未约定的，可主张自逾期之日起参照当时一年期LPR计算的利息。

**第二层：合同无效后的返还**
- 无效情形（解释第13条）：套取金融机构贷款转贷 / 以借贷集资等取得的资金转贷 / **职业放贷**（未依法取得放贷资格，以营利为目的向不特定对象放贷）/ 明知用于违法犯罪仍出借 / 违反强制性规定 / 违背公序良俗；
- 无效后果：返还本金 + 按LPR支付资金占用费（约定高息不适用）。

**第三层：担保从权利**
- 保证责任：民法典第686条（**保证方式约定不明=一般保证**，有先诉抗辩权）、第692条保证期间（无约定或约定不明为主债务履行期届满6个月）；
- 让与担保：以签订买卖合同作为担保的，按借贷关系审理（解释第23条）。

## 二、构成要件表（借贷合意 + 交付 双要件）

| 要件 | 具体条件 | 举证责任 |
|------|---------|---------|
| 借贷合意 | 借条/借款合同/微信聊天记录/录音；**仅有转账凭证的举证分配见下** | 原告 |
| 款项交付 | 转账凭证/取现记录/指示交付证据；大额现金交付须辅助证据（取现流水、资金来源、交付场景） | 原告 |
| 到期未还 | 约定到期日 or 催告后合理期限经过 | 原告：催告记录 |
| 利息约定 | 书面明确约定；口头利息主张须有付息规律等佐证 | 原告 |

**转账凭证案件的举证分配（解释第16条）**：原告仅凭转账凭证起诉 → 被告抗辩系偿还先前借款或其他债务的，**被告先举证** → 被告举证后，**原告仍应就借贷关系成立承担举证责任**。（被告轨要点：先提出具体抗辩并举初步证据，把举证责任推回去）

## 三、常见抗辩（被告轨检索用）

**妨碍**：
- 非借贷关系：投资/合伙/赠与/货款/还款（先举证具体法律关系线索，触发解释第16条第2款的举证回转）；
- 合同无效：职业放贷（查出借人涉诉记录——同一原告多起借贷案件）、套取金融机构贷款转贷（出借资金来源于银行贷款/信用卡套现）、赌债等非法债务；
- 借贷合意不存在：借条系受胁迫出具、虚假意思表示。

**消灭**：
- 已清偿（还款指向争议：先息后本规则——给付不足清偿全部债务时，先抵充实现债权费用→利息→本金，民法典第561条）；
- 诉讼时效届满（3年；未约定履行期限的，自催告宽限期届满起算；借条重新出具/部分还款均中断）；
- 抵销（对方欠我方款项时）。

**减额抗辩**：
- **砍头息**：预先扣除利息的，按实际出借金额认定本金（解释第26条）；
- **利率超四倍部分无效**：超过合同成立时LPR四倍的利息约定无效，已支付的超限部分可主张抵扣本金；
- **复利限制**：前期利息计入后期本金的，前期利率不得超四倍，且最终本息和受四倍上限总量控制（解释第27条）；
- **费用打包上限**：逾期利息+违约金+其他费用**合计**不得超过四倍（解释第29条）；
- 夫妻一方借款：**共债共签**——未共签的，债权人须举证用于夫妻共同生活、共同生产经营（民法典第1064条），配偶被告轨重点抗辩。

## 四、此诉彼诉辨析

| 易混淆 | 区分要点 | 后果差异 |
|--------|---------|---------|
| 借贷 vs 投资/合伙 | 固定收益+保本 → 借贷；共担风险 → 投资 | 投资亏损不得请求返还；定性看实质不看名称 |
| 借贷 vs 委托理财 | 是否保本保收益（保底条款） | 委托理财保底条款效力有争议；定性借贷更稳 |
| 借贷 vs 不当得利 | 只有转账无借条时原告退而求其次的路径 | **陷阱**：不当得利须证明"无法律根据"，对方一举证存在基础关系即败诉——原告轨慎选 |
| 借贷 vs 买卖（让与担保） | 名为买卖实为担保 | 按借贷审理，流质条款无效 |
| 企业间借贷 | 为生产经营需要 → 原则有效（解释第11条） | 与职业放贷/套取转贷的界限 |

## 五、特殊利益提示

1. **LPR四倍是动态标准**：按**合同成立时**的一年期LPR计算，起诉前先查当时LPR数值（全国银行间同业拆借中心公布）；
2. **虚假诉讼高压线**：借贷案件是虚假诉讼重灾区，法院对现金交付、亲属间借贷、原被告配合默契的案件严格审查（解释第18、19条）——原告轨备齐证据链；被告轨怀疑虚假诉讼的可申请法院调取流水、要求当事人本人到庭；
3. **刑民交叉**：借贷涉嫌非法集资等犯罪的，法院可能驳回起诉移送或中止审理（解释第5–7条）——接案时评估刑事风险对民事路径的影响；
4. **保证期间是隐形杀手**：无约定=6个月，期间内未向保证人主张即免责——代理债权人务必核查对保证人的催收留痕；
5. **管辖**：接收货币一方所在地为合同履行地——出借人可在**自己所在地**法院起诉追款（民诉法解释第18条），原告轨的管辖红利。
