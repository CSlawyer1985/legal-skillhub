# claim-basis 请求权基础库

> 每个案由一份文件，由模块02（请求权基础分析）确定案由后**强制加载**。
> 内容由模块13复盘回写机制持续增补。

## 每份文件的统一结构

```markdown
# [案由] 请求权基础

## 一、请求权基础清单
（按检索顺序：合同→类合同→物权→侵权→不当得利，每条到具体条款项）

## 二、构成要件表
（要件 × 法律依据 × 具体条件 × 举证责任）

## 三、常见抗辩
（妨碍/消灭/阻止三类型 × 法律依据 × 应对）

## 四、此诉彼诉辨析
（易混淆案由的区分要点，如买卖vs承揽、借贷vs投资）

## 五、特殊利益提示
（如建工优先受偿权、利息上限、违约金调整规则等该案由特有杠杆）

## 六、复盘沉淀
（由模块13回写的实务经验，标注日期与案件）
```
