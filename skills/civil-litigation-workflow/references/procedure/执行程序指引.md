## 一、执行启动

| 事项 | 规则 | 依据 |
|------|------|------|
| 执行依据 | 生效判决书/裁定书/调解书、仲裁裁决、公证债权文书、支付令 | 民诉法执行编 |
| 申请执行期间 | **2 年**，自履行期届满之日起算；适用时效中止中断（每次催告留痕） | 民诉法第246条 |
| 管辖 | 一审法院 或 与一审法院同级的**被执行财产所在地**法院 | 民诉法第231条 |
| 生效证明 | 判决书须开生效证明；调解书签收即生效 | — |

**接案先查**：是否超 2 年？期间有无中断证据（催款函/对方部分履行/承诺还款）？超期但有中断证据的仍可申请。

## 二、执行措施工具箱

| 措施 | 要点 |
|------|------|
| 网络查控 | 法院总对总系统查存款、房产、车辆、证券、网络资金——**主动提交财产线索清单可显著提速** |
| 查封/冻结/扣划 | 不动产查封后进入评估拍卖程序（一拍→二拍→变卖） |
| 限制高消费 | 被执行人不得坐飞机高铁、子女不得就读高收费私立学校等 |
| 失信名单 | 有履行能力拒不履行、妨碍执行等情形纳入，影响信贷与任职资格 |
| 限制出境 | 对被执行人或其法定代表人申请 |
| 罚款、拘留 | 拒不申报财产、妨碍执行 |
| 拒执罪移送 | 有能力执行而拒不执行情节严重的，申请移送公安（刑法第313条） |
| 悬赏公告 | 部分法院支持发布悬赏，赏金从执行款中支付 |
| 迟延履行利息 | 加倍支付迟延履行期间债务利息（民诉法第260条）——执行申请中**不要漏算** |

## 三、扩大责任主体（追加被执行人）

| 追加事由 | 依据 | 要点 |
|---------|------|------|
| 未届出资期限股东**加速到期** | 公司法（2023）第54条 | 公司不能清偿到期债务，债权人可要求未届期股东提前缴纳出资——新公司法重大变化，**不再受认缴期限保护** |
| 未出资/未足额出资股东 | 变更追加规定第17条 | 在未出资范围内担责 |
| 抽逃出资股东 | 变更追加规定第18条 | 在抽逃范围内担责 |
| 未依法出资即转让股权的原股东 | 变更追加规定第19条 | 与受让人责任分配 |
| 一人公司股东 | 变更追加规定第20条 + 公司法人格否认 | 股东不能证明财产独立的承担**连带责任**（举证责任在股东） |
| 合伙企业普通合伙人 | 变更追加规定第14条 | 无限连带责任 |
| 夫妻共同债务 | 一般须**另行诉讼**确认，执行程序不直接追加配偶 | 例外情形谨慎适用 |

**追加 vs 另诉选择**：法定可追加情形走执行追加程序（快）；法定情形之外的（如人格混同的证据复杂情形）另诉更稳。

## 四、执行异议与救济

| 救济 | 主体 | 期限与路径 |
|------|------|-----------|
| 执行行为异议 | 当事人、利害关系人（认为执行行为违法） | 民诉法第232条：书面异议→15日审查→不服 10 日内向上一级**复议** |
| 案外人异议 | 案外人对执行标的主张权利（如被查封房产的实际权利人） | 民诉法第234条：异议被驳回后 **15 日内**提起执行异议之诉（与原判决无关）或申请再审（认为原判决错误） |
| 执行分配方案异议 | 债权人/被执行人对分配方案 | 异议→分配方案异议之诉（15 日） |

## 五、参与分配与执转破

- **参与分配**：被执行人为**公民或其他组织**（非企业法人），财产不足清偿全部债务时，已取得执行依据的债权人可申请参与分配（民诉法解释第508条起）；**首封与优先权人优先受偿，普通债权按比例**；
- **执转破**：被执行人为**企业法人**且资不抵债的，经申请执行人之一或被执行人同意，移送破产审查（民诉法解释相关条款）；
- **抉择要点**：企业法人无参与分配制度——轮候在后的普通债权人，推动破产可能比干等更有利（破产撤销权可追回偏颇清偿、加速到期股东出资归池）；首封债权人则倾向执行程序快速处置。

## 六、终本管理（终本≠结束）

| 事项 | 规则 |
|------|------|
| 终本条件 | 经财产调查未发现可供执行财产，约谈申请执行人后裁定终结本次执行程序 |
| 恢复执行 | 发现财产线索可随时申请恢复，**不受申请执行期间限制** |
| 续查机制 | 终本后 5 年内法院每 6 个月网络查控一次；**己方每季度主动排查**（新涉诉、新中标、股权变动、新增不动产） |
| 台账 | 终本裁定日期、已查控情况、下次复查日——写入办案记录"程序期限台账" |

## 七、接案评估输出（执行案件专属）

执行案件接案时填《执行可行性评估表》：被执行人主体性质（企业/个人）→ 已知财产 → 涉诉与终本记录（裁判文书网/执行信息公开网）→ 追加空间 → 预计回收率 → 收费模式建议（风险代理比例）。
