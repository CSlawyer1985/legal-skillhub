# 财产保全操作指引

## 一、保全类型与选择

| 类型 | 依据 | 适用场景 | 关键约束 |
|------|------|---------|---------|
| 诉前财产保全 | 民诉法第104条 | 情况紧急，不立即保全将难以弥补损害 | **须全额担保**；采取保全措施后 **30 日内**必须起诉/申请仲裁，否则解除 |
| 诉讼中财产保全 | 民诉法第103条 | 立案后任何时候 | 担保数额一般不超过请求保全数额的 **30%**（保全规定）；保险保函普遍接受 |
| 行为保全 | 民诉法第103条 | 责令作出/禁止作出一定行为（如禁止转让股权、禁止施工） | 要件更严：损害的紧迫性与难以弥补性 |
| 证据保全 | 民诉法第84条 | 证据可能灭失或以后难以取得 | 与财产保全程序类似 |

## 二、申请要件与裁定审查逻辑

法院审查三点：**①胜诉可能性（初步证据）②保全必要性（转移财产风险）③担保**。
- 必要性举证：被申请人涉诉记录、经营异常、失信被执行记录、财产异动（急售房产/注销公司/抽逃出资）、失联跑路迹象；
- 保全范围：**限于请求的范围或与本案有关的财产**（民诉法第105条）——超额保全是错误保全赔偿的高发点。

## 三、财产线索排查（八类财产清单）

| 类别 | 排查渠道 |
|------|---------|
| 银行账户 | 开户行线索（合同/发票/往来流水）、基本户信息 |
| 不动产 | 不动产登记中心查询（凭立案通知书/补充材料通知书） |
| 股权 | 企业信用信息公示系统、工商内档（出资/质押/冻结情况） |
| 应收账款 | 对方的下游合同、中标记录、在建工程（对发包人的工程款债权） |
| 车辆 | 车管所查询 |
| 网络资金 | 微信/支付宝/证券账户（执行阶段网络查控系统覆盖更全） |
| 知识产权 | 商标/专利登记信息（转让或许可收益） |
| 对外债权 | 裁判文书网查对方作为原告/申请执行人的案件 |

## 四、担保方案比较

| 方式 | 成本 | 适用 |
|------|------|------|
| 保险公司保函（诉责险） | 约保全金额的 0.5%–1.5% | **首选**，快捷、不占用资金 |
| 银行保函 | 手续费+占用授信 | 大额保全 |
| 现金/存款 | 全额或 30% 冻结 | 小额的 |
| 实物担保 | 评估+登记成本 | 较少用 |

## 五、常见被驳回/出错原因

1. 财产线索不具体（只写"请求冻结被申请人银行账户"而无账号/开户行——部分法院接受网络查控申请，须单独提交《网络查控申请书》）；
2. 超额保全（保全金额明显高于诉请且无依据）；
3. 诉前保全后 30 日内未起诉 → 解除，且可能赔偿；
4. 保全错误赔偿：申请有错误的，申请人赔偿被申请人损失（民诉法第108条）——败诉≠必然错误保全，但**恶意或重大过失超标的保全**风险高；
5. 轮候查封误当首封：首封法院处置权优先，轮候只排队。

## 六、期限管理（写入办案记录"程序期限台账"）

| 事项 | 期限 |
|------|------|
| 冻结银行存款 | 不超 1 年 |
| 查封动产 | 不超 2 年 |
| 查封不动产/其他财产权 | 不超 3 年 |
| 续封 | 期限届满前申请，续行期限不得超上述期限（民诉法解释第487条）——**届满前 30 日设提醒** |
| 保全裁定复议 | 当事人不服可申请复议一次，复议期间不停止执行（民诉法第111条） |

## 七、被告轨应对（被保全方）

1. 审查裁定：是否超额、是否超出"与本案有关的财产"范围、担保是否足额；
2. 救济三选：**复议**（快，但不停止执行）／**提供担保解除保全**（民诉法第107条——用保证金换出经营账户）／**置换被保全财产**（以等值且便于执行的财产置换基本户、经营必需的账户）；
3. 基本户被冻的应急：申请保留职工工资、税费等必要支出通道；以置换方式解冻；
4. 保全错误的，固定损失证据（利息损失、经营损失），为将来索赔留证。
