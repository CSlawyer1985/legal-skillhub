# 工程造价鉴定

> 触发：建工案件涉及造价争议时，在办案记录状态头登记"涉及专业领域：工程造价"，模块 05/06/08 执行前强制加载本文件。
> 红线：**AI 不替代造价专业人士**。涉及具体算量、套价、取费判断的结论必须标注"需咨询造价工程师"。
> 法源：民诉法 + 新证据规定（法释〔2019〕19号）+ 建工解释一/二 + GB/T 50500 清单计价标准。

## 一、审查要点清单（拿到鉴定意见书后逐项过）

### 1.1 主体与启动
| 检查项 | 要点 |
|--------|------|
| 鉴定是否必要 | **约定固定价的，原则上不准鉴定**（建工解释一第28条）——对方申请时主动提异议；约定"以审计/财评为准"但久拖不出或明显不符的，准许司法鉴定（建工解释二第13条） |
| 鉴定范围 | **仅对有争议的事实进行鉴定**，无争议部分不鉴定（避免全案鉴定推高费用）——审查鉴定委托书范围是否被扩大 |
| 机构选定 | 双方协商 → 协商不成法院摇号/随机选定；鉴定机构应在法院名册内 |
| 人员资质 | 造价咨询企业资质已取消审批，审查重点是：**注册造价工程师**资格、专业匹配（土建/安装/市政）、与本案有无利害关系（回避） |

### 1.2 检材
| 检查项 | 要点 |
|--------|------|
| **未经质证的材料不得作为鉴定依据** | 新证据规定第34条——鉴定意见书引用了未经质证的签证单/结算书的，直接打掉对应部分 |
| 检材完整性 | 合同、补充协议、中标通知书、图纸、变更、签证、会议纪要、甲供材清单、影像资料是否齐备 |
| 检材真实性 | 鉴定机构不负责甄别检材真伪——有争议的检材必须先由法庭认定再移送鉴定 |

### 1.3 程序
| 检查项 | 要点 |
|--------|------|
| 现场勘验 | 应通知双方当事人到场，勘验笔录双方签字；未到场的不影响勘验进行但须留痕 |
| 征求意见稿 | 正式报告前应发征求意见稿，**异议期是己方最重要的修正窗口** |
| 鉴定人出庭 | 对鉴定意见有异议的，申请鉴定人出庭；**拒不出庭的，鉴定意见不得作为认定事实的根据**（民诉法第78条） |
| 鉴定时限与费用 | 费用按争议金额比例预收，通常由申请方预交、败诉方负担；超期可催办 |

## 二、常见错误与造假模式

| 类型 | 表现 | 攻击点 |
|------|------|--------|
| 计价依据错误 | 信息价期数用错、定额套用错误、取费类别错档 | 合同约定的计价条款 vs 实际采用依据逐项比对 |
| 工程量错误 | 重复计量、按图纸量而非实际量、隐蔽工程量无依据 | 签证/影像/监理日志反证 |
| 合同条款漏用 | 未按约定下浮率下浮、甲供材未扣除、风险包干费重复计取 | 合同专用条款逐条核对 |
| 签证处理错误 | 无效签证（无授权人签字）被计入 / 有效签证被剔除 | 签证效力规则（授权范围、监理权限） |
| 争议项未分列 | 把争议事项直接按一方主张计入总价 | 要求**确定项与争议项分列**，争议项由法庭认定后加减 |
| 越权鉴定 | 对合同效力、责任归属、违约金发表意见 | 鉴定只能解决造价专门问题，法律判断属法庭职权——"以鉴代审"直接异议 |

## 三、质证与庭审发问角度（成稿问句示例）

**发问顺序：先资质程序 → 再检材 → 再依据方法 → 最后具体计算与越权表述。**

1. （资质）"您是本次鉴定的注册造价工程师吗？报告中的算量、套价是您本人完成的还是助理完成的？"
2. （检材）"鉴定依据中的第×号签证单，在移送鉴定前是否经过庭审质证？"
3. （依据）"本工程合同约定按××年×月信息价计价，您采用××年×月信息价的依据是什么？"
4. （方法）"对没有签证支撑的××工程量，您是通过什么方式确认的？现场实测了吗？"
5. （争议项）"××事项双方存在争议，您在报告中是计入还是未计入？为什么没有将争议项单独列示？"
6. （越权）"报告第×页关于'××损失应由××承担'的表述，属于造价专业判断吗？"
7. （中立性）"鉴定过程中，您是否单独接触过一方当事人？"

**发问要领**：只问封闭式问题；每个问题服务于一个质证点；鉴定人回答出现矛盾立即请求记入笔录。

## 四、救济路径

| 情形 | 救济 |
|------|------|
| 征求意见稿阶段 | 书面异议（附替代计算书），逐项列明——**最经济有效的战场** |
| 正式报告有异议 | 申请鉴定人出庭 + 申请**专家辅助人**出庭质证（民诉法第79条） |
| 鉴定人无资格/程序严重违法/依据明显不足/意见不能作为证据使用 | 申请**重新鉴定**（新证据规定第40条）——门槛高，只对根本性缺陷 |
| 局部错漏 | 申请**补充鉴定**或补正，不轻易申请重新鉴定（重新鉴定=推翻重来，时间长费用高） |

## 五、红线与专家辅助人指引

1. 己方造价分析（异议计算书、替代测算）必须由造价工程师或专家辅助人背书，AI 生成的测算仅作底稿参考；
2. 鉴定费动辄数万至数十万，启动前向当事人书面说明费用与风险；
3. 复杂造价案件**尽早聘请专家辅助人**，介入时点：鉴定启动前（参与鉴定范围确定）> 征求意见稿阶段 > 庭审质证；
4. **鉴定不能解决“事实归属”问题**（案例B教训，双方鉴定费合计 15.2 万全部沉没）：多合同混同、实际履行范围不清、用款真实性存疑的场景，鉴定机构只能“整理数据”，无法证明“谁实际履行、费用是否真实发生”。申请鉴定前先回答“事实归属能否查清”——归属未清的，先打事实认定（举证责任规则+证据审查），不是先送鉴定；
5. 本文件未覆盖的专业问题，一律标注"需咨询造价工程师"。
