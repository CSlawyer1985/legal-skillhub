# cross-disciplinary 跨专业知识库

> 触发机制：接案时在办案记录状态头登记"涉及专业领域"，后续所有模块执行前检查对应文件已加载。
> 红线：AI 不替代专业人士。涉及专业判断的结论必须标注"需咨询专业人士"。

## 每份文件的统一四段结构

1. **审查要点**：鉴定/审计的资质、检材、程序合法性检查清单；
2. **常见错误与造假模式**；
3. **质证与庭审发问角度**（含成稿问句示例）；
4. **红线与专家辅助人指引**（含何时申请专家辅助人出庭）。
