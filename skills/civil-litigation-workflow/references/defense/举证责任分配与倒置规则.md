# 举证责任分配与倒置规则

> 加载时机：模块 05（证据组织与举证）逐要件核对举证责任时强制加载；被告轨评估"只需否认、无须举证"范围时加载。
> 引用条文前按主控"防幻觉三机制"核验现行有效（条文号以民诉法 2023 修正、民法典为准）。

---

## 一、一般原则

| 规则 | 内容 | 依据 |
|------|------|------|
| 谁主张谁举证 | 当事人对自己提出的主张，有责任提供证据 | 民诉法第67条 |
| 法律关系存在 | 主张法律关系**存在**的当事人，对产生该法律关系的基本事实举证 | 民诉法解释第91条 |
| 法律关系变动 | 主张法律关系**变更、消灭**或权利受妨害的当事人，对变动/消灭/妨害的基本事实举证 | 民诉法解释第91条 |

**九步法对应**：原告对请求权全部要件事实举证；被告对**抗辩权**全部要件事实举证；被告对请求权要件只须**否认**（使事实真伪不明即可），无须举证。（详见 `抗辩权三类型与诉讼时效.md` 总纲）

## 二、证明标准（决定"要证明到什么程度"）

| 标准 | 适用 | 依据 |
|------|------|------|
| **高度盖然性**（原则） | 一般待证事实：存在具有高度可能性即可认定 | 民诉法解释第108条 |
| **排除合理怀疑**（提高） | 欺诈、胁迫、恶意串通事实；口头遗嘱、赠与事实 | 民诉法解释第109条 |
| 较大可能性（降低） | 诉讼保全、回避等程序事项 | 民诉法解释第108条 |

**实务要点**：主张对方欺诈/恶意串通的，证明标准被提高到排除合理怀疑——举证难度陡增，起诉时慎用该定性，除非证据过硬。

## 三、法定倒置/特殊分配情形清单

| 情形 | 倒置内容 | 依据 |
|------|---------|------|
| 环境污染、生态破坏 | 行为人就**不存在因果关系**及免责/减责事由举证 | 民法典第1230条 |
| 医疗损害 | 违反诊疗规范/隐匿拒绝提供病历/遗失伪造销毁病历的，**推定医疗机构有过错** | 民法典第1222条 |
| 建筑物/构筑物倒塌塌陷 | 建设单位和施工单位对**无质量缺陷**举证（除非能证明无过错） | 民法典第1252条 |
| 物件脱落坠落 | 所有人/管理人/使用人对**自己无过错**举证 | 民法典第1253条 |
| 堆放物倒塌、林木折断 | 堆放人/林木所有人管理人对无过错举证 | 民法典第1255、1257条 |
| 高度危险作业 | 受害人故意或不可抗力由作业人举证 | 民法典第1236–1240条 |
| 劳动争议 | 与争议事项有关的证据属**用人单位掌握管理**的，由用人单位提供；不提供承担不利后果 | 劳动争议调解仲裁法第6条 |
| 公司人格否认（一人公司） | 一人公司股东对**财产独立于公司**举证 | 公司法第63条（2018）/新公司法对应条款（引用前核验） |

## 四、举证不能的缓冲机制（证明手段用尽前的救济）

1. **书证提出命令**：证据由对方控制时，申请法院责令对方提交；对方无正当理由拒不提交的，可认定我方主张的书证内容为真实（《新证据规定》书证提出命令规则）；
2. **申请法院调查取证**：因客观原因不能自行收集的证据（银行账户、档案等），书面申请法院调查（民诉法第67条第2款）——**申请本身要留痕**，败诉时可作上诉理由；
3. **证明妨害**：对方毁损、隐匿证据或实施其他妨害行为的，可主张对其作不利认定；
4. **举证期限与逾期后果**：逾期提供证据须说明理由；拒不说明或理由不成立的，法院可以不采纳（但与案件基本事实有关的应当采纳，可训诫罚款——民诉法解释第102条）。**底线：基本事实证据逾期仍应提交，挨罚也要交**。

## 五、操作清单（模块05逐要件核对用）

- [ ] 每个要件标注举证责任归属（我方/对方/倒置）
- [ ] 我方负担的：评估证明标准（高度盖然性 or 提高到排除合理怀疑？）
- [ ] 举证不能的：已穷尽四种缓冲机制（书证命令/调查申请/证明妨害/鉴定）
- [ ] 对方负担的：我方只需组织"使事实真伪不明"的反证，不越俎代庖替对方补证
- [ ] 倒置情形已核对，反向利用（我方是被倒置方时提前备证）
