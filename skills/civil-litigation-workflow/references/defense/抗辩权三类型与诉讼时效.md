# 抗辩权三类型与诉讼时效

> 加载时机：被告轨模块 02/03 **强制加载**；原告轨预判对方抗辩时加载。
> 思维底座：九步法第 3 步（确定抗辩权基础规范）。
> 引用条文前按主控"防幻觉三机制"核验现行有效。

---

## 〇、总纲：先分"否认"与"抗辩"

| 概念 | 定义 | 举证责任 | 示例 |
|------|------|---------|------|
| **否认** | 不承认对方主张的要件事实 | 对方（原告） | "没借过钱" |
| **抗辩** | 承认事实，但主张权利不成立/已消灭/暂不能行使 | **我方（抗辩方）** | "借了，但已还清" |

**操作铁律**：能用否认解决的，不轻易用抗辩——抗辩把举证责任揽到自己身上。检索顺序：**先逐要件找可否认点 → 再按妨碍→消灭→阻止检索抗辩**。

## 一、权利妨碍抗辩（权利自始不成立）

| 抗辩事由 | 法律依据（民法典） | 要件要点 | 实务提示 |
|---------|------------------|---------|---------|
| 无民事行为能力 | 第144条 | 行为时无行为能力 | 8周岁以下/不能辨认自己行为的成年人 |
| 限制行为能力未经追认 | 第145条 | 超越能力范围 + 法定代理人未追认 | 纯获利益或与其能力相适应的除外 |
| 虚假意思表示 | 第146条 | 双方通谋虚伪 | 隐藏行为按其实际性质处理（阴阳合同常用） |
| 违反强制性规定/公序良俗 | 第153条 | 效力性强制规定 | 管理性规定不导致无效，需论证规定性质 |
| 恶意串通 | 第154条 | 双方恶意 + 损害他人合法权益 | 举证难，常用间接证据链 |
| 欺诈 | 第148、149条 | 欺诈行为 + 因果关系 + 对方陷入错误认识 | **撤销权**，除斥期间 1 年（第152条），须在诉讼中主张撤销或另诉 |
| 胁迫 | 第150条 | 胁迫手段 + 违背真实意思 | 除斥期间：胁迫终止之日起 1 年 |
| 重大误解 | 第147条 | 对行为性质/对方/标的物认识错误 | 除斥期间仅 **90 日**（第152条）——最易超期！ |
| 显失公平 | 第151条 | 危困状态/缺乏判断能力被利用 + 成立时显失公平 | 除斥期间 1 年 |
| 无权代理 | 第171条 | 无代理权 + 未追认 | 反向核查：是否构成**表见代理**（第172条）——构成则合同有效 |
| 合同不成立 | 第490条 | 未签名盖章按指印，且未履行主要义务 | 已履行主要义务对方接受的，合同成立（第490条2款但书） |
| 格式条款无效 | 第496、497条 | 未尽提示说明义务 / 不合理免除己方责任 | 对方为格式条款提供方时威力大 |
| 通谋/虚假诉讼、债权不存在 | — | 基础事实造假 | 结合证据三性攻击 |

## 二、权利消灭抗辩（权利曾经存在，现已消灭）

| 抗辩事由 | 法律依据（民法典） | 要件要点 | 实务提示 |
|---------|------------------|---------|---------|
| **清偿** | 第557条 | 履行完毕 | 付款凭证是王道；注意区分还款指向（先息后本规则，第561条） |
| 抵销 | 第568条（法定）/第569条（约定） | 互负到期债务 + 标的物种类相同 | **主动行使**：通知到达生效；诉讼中可以抗辩或反诉方式主张 |
| 免除 | 第575条 | 债权人明确意思表示 | 微信/录音中的"算了""不用还了"的认定 |
| 混同 | 第576条 | 债权债务同归一人 | 公司合并场景 |
| 提存 | 第570–574条 | 债权人无正当理由拒收/下落不明等 + 公证提存 | 标的物不适于提存的可拍卖变卖提存价款 |
| 合同解除 | 第562、563条 | 约定/法定解除权已行使 | 解除后转入恢复原状/损害赔偿轨道，原履行请求权消灭 |
| **诉讼时效届满** | 第188、192条 | 时效期间经过 | 见第二节专章——民商事被告轨**首选检索项** |
| 保证期间经过 | 第693条 | 保证期间内未依法主张 | 保证案件的"时效"，法院可主动审查（与时效不同！） |
| 债权人死亡无继承人等 | 第557条 | 法定消灭事由 | 较少见 |

## 三、权利阻止抗辩（权利存在，但暂不能行使）

| 抗辩事由 | 法律依据（民法典） | 要件要点 | 实务提示 |
|---------|------------------|---------|---------|
| 同时履行抗辩 | 第525条 | 双务合同 + 无先后履行顺序 + 对方未履行 | 对方部分履行的，只能相应部分拒绝 |
| 先履行抗辩 | 第526条 | 有先后履行顺序 + 先履行方未履行或履行不符 | 建工"先提交竣工资料后付款"、买卖"先票后款"高频使用 |
| 不安抗辩 | 第527、528条 | 先履行方 + 对方有丧失履行能力的确切证据 | **程序刚性**：须中止履行并**及时通知**；未通知擅自不履行=己方违约 |
| 先诉抗辩权 | 第687条 | 仅限**一般保证** | 连带保证无此抗辩；先审查保证方式约定（无约定或约定不明=一般保证，第686条） |
| 情事变更（准用） | 第533条 | 订立后基础条件重大变化 + 不可预见 + 非商业风险 | 严格适用（须报高院审核），慎作为主要防线 |

## 四、诉讼时效专章（被告轨首选检索项）

### 4.1 期间类型

| 类型 | 期间 | 依据 | 适用 |
|------|------|------|------|
| 普通时效 | **3 年** | 民法典第188条 | 一般债权 |
| 特别时效 | 4 年 | 民法典第594条 | 国际货物买卖、技术进出口合同 |
| 最长保护期 | 20 年 | 民法典第188条 | 自权利受损害之日起，不适用中止中断 |
| 不适用时效 | — | 民法典第196条 | 停止侵害/排除妨碍/消除危险；不动产物权和登记的动产物权的返还财产；抚养费/赡养费/扶养费 |

### 4.2 起算规则

- 一般：自权利人**知道或应当知道权利受损及义务人**之日起（第188条）；
- 分期履行：自**最后一期**届满之日起（第189条）——滚动结算的工程款、租金重点核查；
- 未定履行期限：债权人可随时要求履行，时效自宽限期届满起算；
- 无/限制行为能力人对其法定代理人：自法定代理终止之日起（第190条）。

### 4.3 中止与中断

| 制度 | 事由 | 效果 | 依据 |
|------|------|------|------|
| 中止 | 时效**最后 6 个月内**：不可抗力、无/限制行为能力人无法定代理人、继承未确定继承人、被控制等 | 障碍消除后**补足 6 个月** | 第194条 |
| 中断 | ①提起诉讼/仲裁；②向义务人提出履行请求；③义务人同意履行 | **重新起算 3 年**，可多次中断 | 第195条 |

**中断留痕（原告轨必做动作）**：催款函 EMS 寄送（注明文件名称）+ 签收记录 / 对账单对方签章 / 部分还款 / 对方微信承诺付款 / 起诉后又撤诉的裁定。

### 4.4 届满后果与抗辩操作（被告轨铁律）

1. **法院不得主动释明/适用时效**（第193条）——时效抗辩必须由被告**主动提出**；
2. **必须在一审期间提出**（时效司法解释）：一审未提，二审提出的原则上不支持（除非基于新证据）；一审不提 = 永久放弃；
3. 届满后义务人**同意履行或自愿履行**的，不得再以时效抗辩（第192条2款）——超时效债务人在**催款通知/对账单上签字盖章**，司法实践倾向认定重新确认债务（原告轨补强手段）；
4. 时效利益**不得预先放弃**，期间不得约定变更（第197条）——合同中"放弃时效抗辩"条款无效；
5. 届满后果是**抗辩权发生**而非权利消灭——债权本体仍在，自愿履行后不得请求返还。

### 4.5 原告轨反向检查清单（接案时必查）

- [ ] 请求权类型 → 适用期间（3年/4年/不适用）
- [ ] 起算点（含分期履行最后一期规则）
- [ ] 期间内有无中断事由，证据是否留痕
- [ ] 已届满的：有无对方"重新确认债务"的补救证据（对账单/还款承诺/部分履行）
- [ ] 时效风险等级写入《初步评估报告》并向当事人书面告知
