# 答辩状模板

## 一、格式

```
                民事答辩状

答辩人：________，住所地：________，统一社会信用代码：________
法定代表人：________，职务：________

被答辩人（原告）：________，住所地：________

答辩人因被答辩人诉答辩人建设工程施工合同纠纷一案【案号：（2026）吉01民初XX号】，现提出答辩如下：

一、关于原告诉称的合同签订情况

答辩人对双方于____年__月__日签订《________合同》的事实无异议，但对原告诉称的合同条款理解有异议。

（如：原告主张合同价款为固定总价，但合同第X条明确约定为可调价格，原告遗漏了材料价差调整条款。）

二、关于原告诉称的合同履行情况

1. 原告并未依约完成全部工程内容。根据工程签证记录，尚有__项工程内容未完成或存在质量缺陷，具体如下：
   - ________
   - ________

2. 工程竣工验收存在程序瑕疵。竣工验收报告上签字的验收组成员中，__人并非合同约定的验收代表，其签字效力存疑。

三、关于原告诉称的结算金额

1. 答辩人对《结算书》的签署背景有异议。该结算书系原告以停工相要挟，答辩人在被迫情形下签署，并非真实意思表示。

2. 结算书中存在明显错误：
   - 第X项工程量重复计算，多计________元；
   - 第Y项单价适用错误，应按合同附件X执行，而非结算书所载价格；
   - 材料调差计算基数有误，应以信息价为准，而非市场价。

答辩人已委托第三方造价咨询机构进行审核，审核结论为结算金额应为________元，而非________元。

四、关于付款情况

1. 答辩人已付款金额应为________元，而非原告诉称的________元。除银行转账外，答辩人还曾以以下方式支付：
   - ____年__月__日，现金支付________元（收款人：________，有收条为证）；
   - 以材料抵款________元（有双方签字确认的抵款协议）。

2. 根据合同约定，质保金比例为__%，质保期尚未届满，质保金________元不应计入应付工程款。

五、关于违约责任的抗辩

1. 答辩人未按期付款事出有因。原告存在以下违约行为在先：
   - 工期延误__天，导致答辩人向第三方承担逾期交房违约金________元；
   - 工程质量不合格，答辩人已发生维修费用________元；
   - 原告未按约定提交竣工资料，导致答辩人无法办理竣工验收备案。

2. 根据民法典第526条，答辩人有权行使先履行抗辩权，在原告未纠正违约行为前，有权拒绝支付相应款项。

六、关于利息起算时间

答辩人认为，即便存在欠付工程款，利息起算时间也应为起诉之日，而非原告主张的结算之日。理由：
- 双方对结算金额存在争议，付款金额尚未最终确定，不具备起算利息的前提；
- 根据建工司法解释（一）第27条，利息从应付工程价款之日开始计付，而应付时间因结算争议尚未确定。

七、反诉请求（如提起反诉）

答辩人同时提起反诉，请求：
1. 判令原告向答辩人支付工期延误违约金人民币________元；
2. 判令原告向答辩人赔偿质量缺陷维修费用人民币________元；
3. 判令原告向答辩人提交完整的竣工资料并配合办理竣工验收备案；
4. 反诉费用由原告承担。

综上所述，原告的诉讼请求缺乏事实和法律依据，请求贵院依法驳回原告全部诉讼请求，并支持答辩人的反诉请求。

此致

________人民法院

                                答辩人：________（盖章）

                                法定代表人/授权代表（签字）：

                                ____年__月__日

附件：
1. 本答辩状副本__份
2. 证据清单及证据材料
3. 反诉状（如提起反诉）
4. 答辩人营业执照复印件、法定代表人身份证明书
5. 授权委托书、律师证复印件、所函
```

## 二、起草要点

### 答辩策略选择

| 策略 | 适用情形 | 风险 |
|------|---------|------|
| **全面否认** | 原告主张基本不成立 | 激进，需充分证据支撑 |
| **部分承认+部分否认** | 部分事实无误，部分有争议 | 稳妥，法官易接受 |
| **承认事实但否认法律后果** | 事实清楚，但不应承担责任 | 需强法律依据 |
| **提起反诉** | 我方也有向对方主张的权利 | 增加诉讼成本，但可制衡对方 |

### 建工案件答辩要点

| 常见原告主张 | 典型答辩角度 |
|-------------|------------|
| 要求支付工程款 | 质量不合格、工期延误、结算金额争议、已付款争议、质保期未满 |
| 要求支付利息 | 起算时间争议、利率标准争议、结算未完成导致付款条件未成就 |
| 主张优先受偿权 | 已过18个月除斥期间、工程未竣工、质量不合格、仅享有债权不享有物权 |
| 主张实际施工人身份 | 存在转包/违法分包、突破合同相对性需严格审查 |

### 注意事项
- 答辩状中的事实陈述要简洁，详细论证留给代理词
- 每个抗辩点都要有证据或法律依据支撑，不能只喊口号
- 如提起反诉，必须在答辩期内提出，逾期只能另案起诉

---

*本模板适用于建设工程施工合同纠纷一审答辩*
