# 质证意见模板

## 一、格式

> 质证意见（关于对方证据）
>
> 案号：（2026）吉01民初XX号
> 质证方：________（当事人名称）
> 日期：2026年__月__日

---

### 对对方第一组证据的质证意见

**对方证据1-1：《建设工程施工合同》复印件**

1. **真实性**：不予认可。该证据为复印件，无法与原件核对；合同第5页与第6页之间骑缝章不连续，疑似拼接。请求法庭要求对方出示原件。
2. **合法性**：无异议。合同签署主体适格，内容不违反法律强制性规定。
3. **关联性**：认可真实性关联，但不认可证明目的。该合同仅能证明双方存在合同关系，但不能证明我方存在违约行为。
4. **总结**：对该证据的真实性不予认可，请求法庭不予采纳；即便采纳，也不能证明对方主张的违约事实。

**对方证据1-2：《竣工验收报告》**

1. **真实性**：无异议。
2. **合法性**：无异议。
3. **关联性**：认可，但对其证明目的有异议。该验收报告恰恰证明工程已经通过验收，对方以质量不合格抗辩不能成立。
4. **总结**：认可真实性、合法性、关联性，但不认可对方"工程未经验收"的证明目的。该证据反而证明我方已完成合同义务。

---

### 对对方第二组证据的质证意见

**对方证据2-1：《质量检测报告》**

1. **真实性**：形式真实，但内容真实性存疑。该报告为对方单方委托，检测时间距工程完工已逾3年，无法反映完工时的质量状况。
2. **合法性**：有异议。检测机构是否具备资质、鉴定人是否回避，对方未予说明；检材来源未经双方质证，程序违法。
3. **关联性**：有异议。工程已竣工验收并投入使用，根据《建工司法解释（一）》第13条，发包人擅自使用后又以质量不合格主张权利的，不予支持。
4. **总结**：真实性、合法性、关联性均不予认可，请求法庭不予采纳。

## 二、质证策略口诀

| 对方证据 | 策略 |
|---------|------|
| 对方核心证据 | **重点攻击**：找真实性漏洞、合法性瑕疵、关联性偏差 |
| 对方对我方有利的证据 | **借力打力**：认可三性，但不认可对方证明目的，转而支持我方主张 |
| 对方瑕疵证据 | **直接排除**：真实性不认可，请求法庭不予采纳 |
| 对方无关证据 | **切割隔离**：关联性不予认可，与本案争议焦点无关 |
| 对方补强证据 | **质疑链条**：指出其不能补强主证据的哪个缺陷 |

## 三、常见质证用语

### 真实性
- "该证据为复印件，无法与原件核对，真实性不予认可。"
- "该微信聊天记录截图不完整，无法确认是否经过删减，真实性存疑。"
- "该证人系对方员工，与对方存在利害关系，其证言真实性较弱。"

### 合法性
- "该证据系以非法手段取得，侵犯了他人合法权益，合法性不予认可。"
- "该鉴定意见系单方委托，检材未经质证，鉴定程序不合法。"
- "该证据形成于境外，未经公证认证，不符合法定形式要求。"

### 关联性
- "该证据与本案争议焦点无关，关联性不予认可。"
- "即便该证据真实，也只能证明XX事实，不能证明对方主张的YY事实。"
- "该证据属于另一法律关系，不应在本案中审查。"

### 证明目的
- "认可真实性、合法性、关联性，但不认可对方的证明目的。该证据恰恰证明……"
- "该证据不能单独证明待证事实，需要与其他证据结合，但对方未提供补强证据。"

## 四、庭审质证流程

1. **对方出示证据**：对方举证时，仔细听证据名称和证明目的
2. **快速判断**：该证据属于哪种类型？核心/辅助/瑕疵/无关？
3. **发表意见**：按"真实性→合法性→关联性→总结"发表，不要展开辩论
4. **书记员记录**：确保书记员把你的质证意见完整记入笔录
5. **庭后核对**：庭审结束后核对笔录，质证意见记录不完整的要补正

---

*质证不是辩论，是对证据的"体检"。每一句质证意见都应指向"这份证据能不能用"这个问题。*
