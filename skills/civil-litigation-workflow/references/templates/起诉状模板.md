# 起诉状模板

## 一、格式

```
                民事起诉状

原告：________，住所地：________，统一社会信用代码：________
法定代表人：________，职务：________
联系电话：________

被告：________，住所地：________，统一社会信用代码：________
法定代表人：________，职务：________

案由：建设工程施工合同纠纷

诉讼请求：

1. 判令被告向原告支付工程款人民币________元；
2. 判令被告向原告支付逾期付款利息（以________元为基数，自____年__月__日起至实际付清之日止，按全国银行间同业拆借中心公布的贷款市场报价利率（LPR）计算，暂计至起诉之日为________元）；
3. 判令被告承担本案全部诉讼费用、保全费用、保全担保费用。

（注：如主张优先受偿权，增加第X项：判令原告对案涉工程折价或拍卖所得价款在欠付工程款范围内享有建设工程价款优先受偿权。）

事实与理由：

一、合同签订情况

____年__月__日，原告与被告签订《________合同》（合同编号：________），约定由原告承包被告发包的________工程，合同价款为人民币________元，付款方式为________。

（引用合同核心条款：工程范围、工期、价款、付款节点、违约责任）

二、合同履行情况

合同签订后，原告依约进场施工，于____年__月__日完成全部工程内容，并于____年__月__日通过竣工验收。

____年__月__日，双方签署《结算书》，确认结算金额为人民币________元。

三、付款及欠款情况

截至起诉之日，被告累计支付工程款人民币________元，尚欠________元未付。具体付款明细如下：

| 序号 | 付款时间 | 付款金额（元） | 付款方式 | 备注 |
|------|---------|--------------|---------|------|
| 1 | ____.__.__ | ____________ | 银行转账 | |
| 2 | ____.__.__ | ____________ | 银行转账 | |
| ... | ... | ... | ... | |

四、违约事实

根据合同约定，被告应于____年__月__日前支付至结算金额的__%，但被告至今未足额支付，已构成根本违约。

原告多次催告，被告仍未履行付款义务。____年__月__日，原告向被告发送《催款函》，被告于____年__月__日签收，但仍未付款。

五、法律依据

1. 根据《中华人民共和国民法典》第788条、第807条，被告应当支付工程款；
2. 根据《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》第27条，被告应当支付逾期付款利息；
3. 如主张优先受偿权：根据民法典第807条及建工司法解释（一）第35-42条，原告享有建设工程价款优先受偿权。

综上所述，被告拖欠工程款事实清楚，证据充分，请求贵院依法支持原告全部诉讼请求。

此致

________人民法院

                                具状人：________（盖章）

                                法定代表人/授权代表（签字）：

                                ____年__月__日

附件：
1. 本起诉状副本__份（按被告人数）
2. 证据清单及证据材料
3. 原告营业执照复印件、法定代表人身份证明书
4. 授权委托书、律师证复印件、所函
5. 财产保全申请书（如申请保全）
```

## 二、起草要点

### 诉讼请求
- 金额必须具体、明确，不能写"约""左右"
- 利息要有计算公式或计算方式，不能笼统
- 诉讼费、保全费、担保费要单独列明

### 事实与理由
- 按"合同签订→履行→结算→付款→违约→催告"顺序叙述
- 每一句话都要有证据支撑（后面证据清单要对应）
- 不要写"我们认为""被告显然"等主观评价，用客观陈述
- 法条引用要精确到条款号

### 建工案件特别注意事项

| 事项 | 处理 |
|------|------|
| 实际施工人起诉 | 列明发包人、转包人/违法分包人为共同被告 |
| 主张优先受偿权 | 必须在诉讼请求中明确提出，不能漏 |
| 优先受偿权期限 | 自发包人应当给付建设工程价款之日起算18个月 |
| 工程质量抗辩 | 预判对方可能主张的质量问题，在起诉状中提前回应 |
| 工期延误索赔 | 如对方可能反诉，在起诉状中先固定工期顺延的事实 |

---

*本模板适用于建设工程施工合同纠纷一审起诉*
