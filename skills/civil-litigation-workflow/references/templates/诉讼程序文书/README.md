# 08-诉讼程序文书 模板库

> 来源：最高法院诉讼文书样式体系，由 .doc/.docx 转换为 Markdown 入库。
> ⚠️ 通用注意：各文书"制作说明"所引民诉法条文号为**旧编号（2017版）**，现行法（2023修正）条文号已变动（如诉讼保全 100→103、诉前保全 101→104、申请执行2年期间 239→246），**引用前必须重新核验条文号**。

## 目录与 skill 模块映射（civil-litigation-workflow）

### 01-保全与先予执行（→ 模块04）
| 文件 | 用途 |
|------|------|
| 财产保全申请书（诉讼中）.md | 诉中保全（诉前保全参照改首部与依据条款） |
| 行为保全申请书.md | 责令/禁止特定行为 |
| 解除财产保全申请书.md | 被告轨：提供担保解除 |
| 先予执行申请书.md | 追索赡养费/医疗费/劳动报酬等紧急情况 |
| 保全或先予执行裁定复议申请书.md | 对保全裁定不服 |
| 保全担保书（案外人）.md | 第三人提供担保 |
| 延长财产保全期限申请书.md | 续封（届满前30日提交） |

### 02-举证与调查（→ 模块05）
| 文件 | 用途 |
|------|------|
| 调查取证申请书.md | 客观原因不能自行收集的证据 |
| 延长举证期限申请书.md | 举证期限届满前申请 |
| 通知证人出庭作证申请书.md | 举证期限届满前申请 |
| 鉴定申请书.md | 专门性问题鉴定 |
| 证据保全申请书.md | 证据可能灭失/以后难以取得 |

### 03-上诉与再审（→ 模块11）
| 文件 | 用途 |
|------|------|
| 民事上诉状.md | 判决15日/裁定10日内 |
| 民事再审申请书.md | 生效后6个月内（法定例外自知道之日起算） |

### 04-执行（→ 模块12）
| 文件 | 用途 |
|------|------|
| 申请执行书.md | 生效后2年内 |
| 被执行人财产状况表.md | 财产线索清单（配合申请执行提交） |
| 追加被执行人申请书.md | **自建**（源库无），含追加事由对照表 |
| 执行异议书（当事人及利害关系人）.md | 执行行为异议（民诉法第232条） |
| 执行异议书（案外人）.md | 案外人异议（民诉法第234条） |
| 执行复议申请书.md | 异议裁定不服向上一级复议 |
| 分配方案异议书.md | 参与分配方案异议（15日异议之诉前置） |

## 源库未转换但可用的其他模板

源库还含：管辖权异议书（1.1）、反诉状（10.2）、追加当事人申请（10.4/10.5）、增加/变更诉请（10.6/10.7）、撤诉（10.9）、第三人撤销之诉（14.1）、执行异议之诉起诉状（15.1/15.2）、宣告失踪/无行为能力（17.1/17.2）、司法确认调解协议（17.3）、实现担保物权（17.4）、支付令（19.1）、公示催告（20.1）、回避申请（2.1）、法代身份证明/授权委托书（3.1/3.2）、缓减免诉讼费（9.1）、和解/调解协议（23.3/23.4）等——需要时按同法从源库转换补充。
