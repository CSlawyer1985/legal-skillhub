# 追加被执行人申请书

> 来源：自建模板（源文本库无此文书）。依据《最高人民法院关于民事执行中变更、追加当事人规定》（法释〔2016〕21号，2020修正，下称《变更追加规定》）及司法实践通用格式。
> 法律依据列明为 2023 修正民诉法及现行司法解释条文号，引用前按防幻觉机制核验。

## 制作说明

### 一、常用追加事由与依据对照

| 事由 | 依据 | 责任范围 |
|------|------|---------|
| 股东未缴纳/未足额缴纳出资 | 《变更追加规定》第17条 | 未出资范围内 |
| 股东抽逃出资 | 《变更追加规定》第18条 | 抽逃出资范围内 |
| 未依法出资即转让股权 | 《变更追加规定》第19条 | 原股东在未依法出资范围内 |
| 一人公司股东财产混同 | 《变更追加规定》第20条 | 连带责任（股东自证财产独立） |
| 未届出资期限股东加速到期 | 《公司法》（2023）第54条 | 提前缴纳出资 |
| 个人独资企业投资人 / 合伙企业普通合伙人 | 《变更追加规定》第13、14条 | 无限/无限连带责任 |
| 法人分支机构财产不足 | 《变更追加规定》第15条 | 追加该法人 |
| 未经清算即注销 | 《变更追加规定》第21条 | 股东、董事、控股股东等相应责任 |

### 二、实务要点

1. **程序路径**：向执行法院书面申请 → 法院组成合议庭审查并公开听证（争议较大的）→ 裁定；对裁定不服的，区分情形走**执行异议之诉**（第14、17–21条事由，15日内）或**向上一级法院复议**（其他事由，10日内）。
2. **加速到期两条路**：可执行中追加，也可诉讼中直接诉请——执行追加被驳回不影响另诉权利。
3. **证据关键**：工商内档（章程、出资信息）、验资报告、银行流水（抽逃痕迹）、财务资料（一人公司混同）。
4. **查控联动**：申请追加同时，可申请对被申请追加人财产采取**保全性查控**（实践中部分法院支持，需个案沟通）。
5. 夫妻共同债务**不适用**执行追加，须另行诉讼确认。
