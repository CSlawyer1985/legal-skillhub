# 案件登记与简报（能力组件）

> 作用：新案件统一登记格式 + 定期案件简报模板 + 案件台账 _log.yaml 规范。由模块 01/13 调度。

## 一、新案件登记（ intake ）

### 什么时候登记

- 接到客户初步咨询，判断是否接案时
- 决定接受委托后，正式建立案件档案时
- 收到对方律师函，需要建立应诉档案时

### 登记后动作

1. **在飞书/案件管理系统录入**：按多维表格框架录入案件信息
2. **创建案件文件夹**：按标准六目录案件文件夹结构创建
3. **启动大事记构建**：读取大事记构建 SKILL，开始整理时间线
4. **设定 deadline 提醒**：下次行动日期录入日历/飞书表格
5. **利益冲突确认**：如存在冲突，48小时内报告合伙人

### 案件台账格式（_log.yaml 结构）

> 用于：多案件组合管理、风险分布统计、deadline 预警

#### 台账条目格式

```yaml
- matter_id: 2026-JG-001        # 案件编号
  name: 甲建设公司诉乙地产公司案    # 案件名称
  client: 甲建设公司             # 客户名称
  counterparty: 乙地产公司        # 对方当事人
  case_type: 建设工程施工合同纠纷 # 案由
  forum: 某市中级人民法院     # 管辖法院
  stage: 一审                   # 当前阶段
  status: active                # 状态：active | pending | closed
  risk: medium                   # 风险等级：low | medium | high | critical
  exposure_cny: 1418            # 争议金额（万元）
  theory: 发包方拖欠工程款      # 案件理论（一句话）
  lead_counsel: 张三             # 主办律师
  next_deadline: 2026-06-15      # 下一个 deadline
  next_action: 开庭审理          # 下一个行动
  legal_hold: false             # 是否有证据保全
  opened_date: 2026-04-20       # 收案日期
  last_updated: 2026-05-24       # 最后更新日期
  related_matters: []            # 关联案件（如反诉、系列案）
```

#### 台账用途

| 场景 | 使用方法 |
|------|---------|
| **案件组合总览** | 读取全部 active 案件，按 risk 分组统计：🔴 critical N件、🟠 high N件、🟡 medium N件、🟢 low N件 |
| **deadline 预警** | 筛选 next_deadline ≤ 7天的案件，生成预警清单 |
| **停滞案件识别** | 筛选 last_updated ≥ 30天未更新的案件，提醒跟进 |
| **客户维度汇总** | 按 client 分组，统计每个客户的在办案件数量和总风险敞口 |
| **月度报告** | 统计本月新增、结案、风险升级的案件数量 |

#### 飞书多维表格适配

飞书多维表格不支持 YAML 格式，但可以通过以下字段对应：

| YAML 字段 | 飞书字段 | 字段类型 |
|-----------|---------|---------|
| matter_id | 案件编号 | 文本 |
| name | 案件名称 | 文本 |
| client | 客户名称 | 单选/文本 |
| risk | 风险等级 | 单选（🔴🟠🟡🟢） |
| exposure_cny | 争议金额（万元） | 数字 |
| stage | 当前阶段 | 单选 |
| status | 状态 | 单选 |
| next_deadline | 下一个 deadline | 日期 |
| next_action | 下一个行动 | 文本 |
| last_updated | 最后更新 | 日期 |

## 二、案件深度简报（ matter-briefing ）

### 什么时候写简报

- **接案后1周内**：向合伙人/客户提交初步分析简报
- **重大节点前**（开庭前、调解前、上诉前）：提交策略简报
- **客户要求汇报时**：提交进展简报
- **案件交接时**：提交移交简报

### 简报结构

```
【案件深度简报】
案件名称：________________
简报日期：________________
简报人：________________
简报对象：□ 合伙人  □ 客户  □ 外部合作律师

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

一、案件概述（1页以内）

用"5W1H"一句话说完：
Who（谁告谁）→ What（什么纠纷）→ When（什么时间发生）
→ Where（哪个法院/仲裁机构）→ Why（为什么发生）→ How（目前进展）

示范：
"甲建设公司（承包方）诉乙地产公司（发包方）建设工程施工合同纠纷案，
因发包方拖欠工程款1418万余元，承包方已向某市中级人民法院提起诉讼，
目前处于证据交换阶段，预计2026年6月开庭。"

二、事实时间线（大事记摘要）

| 日期 | 事件 | 证据 |
|------|------|------|
| 2016.03 | 签订合同 | 合同书 |
| 2019.08 | 完成结算 | 结算书 |
| ... | ... | ... |

三、争议焦点

1. ________________（我方有利程度：□ 强  □ 中  □ 弱）
2. ________________
3. ________________

四、我方优劣势分析

优势：
- ________________
- ________________

劣势/风险：
- ________________
- ________________

五、案件理论（30秒陈述）

________________

六、下一步策略与时间安排

| 事项 | 负责人 | 截止日期 | 状态 |
|------|--------|---------|------|
| ________________ | ______ | ______ | □ 待办  □ 进行中  □ 完成 |

七、需要决策的问题（如向合伙人/客户简报）

□ 是否同意调解？调解底线：______
□ 是否申请财产保全？
□ 是否追加被告/第三人？
□ 其他：________________

八、预估结果与风险提示

最佳结果：________________
最可能结果：________________
最坏结果：________________

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

附件：□ 大事记  □ 证据清单  □ 法律文书  □ 其他：______
```

### 不同受众的版本调整

| 受众 | 调整要点 |
|------|---------|
| **合伙人/资深律师** | 侧重法律分析、风险判断、策略选择，省略基础事实 |
| **客户（企业法务/高管）** | 用通俗语言，多图表少法条，明确行动建议和费用 |
| **外部合作律师** | 侧重事实梳理、证据清单、已做工作，便于接手 |
| **法院/仲裁庭** | 这不是简报，是代理词/法律意见书，换用对应模板 |

## 四、在工作流中的位置

- 接案登记后 → **模块 01**（接案评估）与 **capabilities/大事记构建**（整理事实时间线）
- 简报准备前 → **模块 05/06**（确保证据清单准确）
- 开庭前简报 → **模块 07**（转化为庭审策略）
- 案件结案后 → **模块 13**（归档复盘），更新台账 status
