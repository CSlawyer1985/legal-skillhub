# 07 庭前准备与争点整理

## Step 0 强制检查

加载本文件 → 读办案记录.md → 确认代理轨 → 确认开庭日期已明确 → **门禁：要件-证据对照表（模块05）与质证意见（模块06）已产出**。缺任一者先回补前置模块——争点由要件比对生成，凭空整理 = 凭感觉罗列。

## 任务目标

开庭前回答三个问题：**本案争什么（争点清单）、法官会怎么归纳（我方版本预置）、庭上拿什么打（庭前准备提纲）**。庭前防线质量决定全案走向——案例B实证：一审事实认定（对方举证不能）在二审、再审、检察监督中均未被撼动；一审庭前锁死争点=锁定全案。庭前准备的终极目标：让法官庭后写判决时，**不自觉地引用你准备好的观点和逻辑**。

## 定位

- **本模块自包含**：争点清单制法、法官争点归纳预判与我方版本预置、类案检索入提纲、庭前行动清单闭环管理、庭前准备提纲八段规范（见文末附录）；
- **与模块08分工**：本模块出争点清单+庭前提纲（含发问提纲框架），庭审现场的发问执行、应变与辩论归模块08。

## 一、争点清单制法（本模块核心增量）

### 1.1 争点的定义

**争点 = 双方主张的碰撞点，不是议题清单。**"合同效力"只是议题；"补充协议第三条是否因违反招标投标法第46条而无效"才是争点。检验标准：能用"是否""应否"表述且双方答案相反。无碰撞事项列入"无争议事实"请法官当庭确认固定，压缩战场。

### 1.2 生成方法

以要件-证据对照表为轴，逐要件比对双方主张：一致则排除，不一致则标记为争点；再补法律争点（合同性质、法律适用）与程序争点（管辖、鉴定、举证期限）。

### 1.3 五标注（每个争点必填）

| 标注 | 内容 |
|------|------|
| 我方立场 | 一句话结论 + 依据到条款项 |
| 对方立场 | 提炼其最强版本（不稻草人化） |
| 证据落点 | 双方证据编号，标注谁有原件、谁有缺口 |
| 举证责任归属 | 真伪不明时谁败诉——被告轨据此决定"攻击"还是"另证" |
| 胜诉贡献度 | 高/中/低：该争点胜了对判决主文影响多少金额 |

### 1.4 排序公式

**争点权重 = 胜诉贡献度 × 法官关注度。**排序决定庭审火力分配：首位争点 = 本案胜负手，配最强证据+类案+模拟攻防；末位争点一句话兜底。案例D实证：按此公式把金额主战场锁定为唯一高权重争点，火力全向其倾斜。法官关注度来源：庭前会议流露、类案裁判规则、法官既往判决（联网检索核验并标注来源）。

## 二、预判法官争点归纳，预置"我方版本"

**争点怎么归纳，判决就怎么写。**法官通常庭前或开庭伊始归纳争议焦点，必须预置"我方版本"表述，争取按我方框架归纳：

1. 同一碰撞点，措辞不同则隐含前提不同——把对我方有利的前提写进争点措辞（案例B规范样本："争议焦点四分法"逐一回应法官归纳，结构为"焦点表述→我方立场→证据落点→结论"，每焦点闭环）；
2. 法官归纳与我方版本不一致时，当庭礼貌提出修正并记入笔录，不争论但必留痕；
3. 法官之问正面回应（案例D实证）：不回避、不糊弄，当庭答不准的承诺庭后核实——收款比例97.4%经庭后核实以显式更正段更正为100%，反而强化可信度。

## 三、庭前准备提纲（按附录八段规范生成）

生成《庭前准备提纲》，八段结构按文末附录执行。本模块只提三项增量要求：

1. **案件理论30秒陈述**：有主角（我方守约）、有反派（对方违约/滥诉）、有结局（应胜诉），脱稿能讲；
2. **要件分析表随身**：打印交叉矩阵，法官问到任一要件事实，3秒内指到证据编号与页码；
3. **发问提纲只出框架**：问题清单与设计目的入本提纲，现场执行技巧归模块08。

## 四、类案检索入提纲

- 法律争点（效力性/管理性规定之争、解释分歧）必须配类案，权威层级优先（指导性案例→最高法裁判→受诉法院上级案例）；
- 类案不进附件吃灰，**进提纲正文**：在对应争点的"我方立场"后直接引用案号+裁判规则一句话（案例E实战：（2015）最高法民申字第280号支撑"46条系管理性规定"、苏05民终11957号支撑"已确认结算不推翻"，嵌入反驳表对应行）；
- 检索报告单独成文，提纲只留索引；**案号与规则交付前强制联网核验，禁止凭记忆引用**（核心原则7、8）。

## 五、庭前行动清单闭环管理

提纲之外，凡需线下完成的事项单列《庭前行动清单》，逐项标注责任人与状态，开庭前一日逐项核销（案例E实证：调取原件、条款页贴标签、文书盖章定稿三项线下事项的闭环）：

- [ ] **原件调取**：全部证据原件向当事人调取到位，列缺失清单限期补齐（原件是质证生命线）；
- [ ] **关键条款页贴标签**：胜负手条款所在页贴索引标签，庭审引导法官直接翻阅（案例E：招标文件"法定节假日期间空调不开启"条款页）；
- [ ] **文书定稿盖章**：出庭文书盖章版+Word版定稿，杜绝庭前夜改版本混乱；
- [ ] **材料打印**：质证意见（对方每份证据对应一页）、发问提纲、关键法条原文（标注条款号）、大事记最新版；
- [ ] **装订携带**：按"法官一册、我方一册"装订（答辩状/证据清单/要件表/质证意见/类案报告/提纲）；如需展示图纸/PPT，设备提前测试；
- [ ] **程序事务**：授权手续、所函、律师证、当事人/证人出庭通知、行程住宿。

## 六、庭前会议专项（如召开）

议题预判：管辖、证据交换、鉴定、争点固定；程序申请（证人出庭/鉴定人出庭/专家辅助人）须此前书面提出（入03-法律文书/）。庭前会议是观察法官关注点的最佳窗口——散会后24小时内回写争点权重排序，并联动模块10更新判决预期值台账（庭前是和解高发节点）。

## 双轨差异

| | 原告轨 | 被告轨 |
|---|--------|--------|
| 争点生成视角 | 对方否认/抗辩攻击了哪个要件，即生争点 | 对方哪个要件有缺口，即推为争点 |
| 举证责任运用 | 己方要件全部需证成，争点=补强清单 | 举证责任在对方的争点，主张"真伪不明即胜" |
| 提纲重心 | 主张-证据对应表（攻势链条完整） | 反驳策略表+质证要点（拆对方链条） |
| 首位争点形态 | 多为付款/违约事实（金额主战场） | 多为效力/责任前提（一战定全案，案例B） |

## 附录：庭前准备提纲八段规范

### 提纲结构

```
【庭前准备提纲】
案件名称：XXX诉XXX纠纷案
开庭日期：202X年XX月XX日
承办法官：XXX（如有信息）

一、案件理论（30秒说清本案）
二、争议焦点清单
三、我方主张与证据对应表
四、对方主张与反驳策略
五、质证意见要点
六、发问提纲（向对方/证人/鉴定人）
七、法官可能追问的问题
八、最后陈述要点
```

### 一、案件理论（The Theory of the Case）

用**一句话**概括核心主张，再用**三句话**展开。要求：法官听完就能在脑子里画出的故事——有主角（我方守约）、有反派（对方违约）、有结局（我方应胜诉）。

**示范（原告轨建工案）**：
> **一句话**：本案是发包方拖延结算、拒不支付工程款的典型违约案件，承包方已完成全部工程并通过验收，发包方应当全额支付结算款并承担逾期利息。
> **三句话**：①合同关系清晰：双方签订施工合同，约定工程范围、价款和付款节点；②履约事实完整：承包方按期完工并通过结算；③违约事实明确：发包方仅支付部分款项，余款拖欠至今，构成根本违约。

### 二、争议焦点清单

从起诉状和答辩状中提炼真正的争议点（按本模块第一节"碰撞点"标准），每点用"是否""应否"表述，格式：

| 序号 | 争议焦点 | 我方立场 | 对方立场 |
|------|---------|---------|---------|
| 1 | 案涉工程是否已经竣工验收合格？ | 已验收，有竣工验收报告为证 | 主张存在质量问题，未真正验收 |

### 三、我方主张与证据对应表

**一个主张 → 一组证据 → 一条法条**：

| 我方主张 | 证据 | 证据在卷位置 | 证明目的 | 对应法条 |
|---------|------|------------|---------|---------|
| 合同关系成立 | 《施工合同》 | 原告证据1 | 双方存在合法有效的施工合同关系 | 民法典第788条 |

### 四、对方主张与反驳策略

预判对方庭上观点，提前准备反驳弹药：

| 预判对方主张 | 我方反驳策略 | 支撑证据/法条 |
|-------------|-------------|--------------|
| "工程质量不合格" | 已通过竣工验收且发包方已投入使用，擅自使用后又以质量抗辩的不予支持 | 建工司法解释（一）第13条 |
| "另有现金支付" | 要求出示收条/取款记录/在场证人；大额现金支付不符合交易习惯 | 证据规则+交易习惯 |

### 五、质证意见要点

对对方每份证据预置质证意见（三性分层，格式与火力分级见模块06）：
> 真实性：不予认可（复印件无法与原件核对）；合法性：……；关联性：……；总结：请求法庭不予采纳。

策略：核心证据重点攻击、辅助证据弱化处理（"即便真实也不足以证明……"）、瑕疵证据直接排除。

### 六、发问提纲

- **向对方当事人**：全部设计为**封闭式**（是/否/不知道），避免开放式让对方发挥；每问附设计目的（如"确认擅自使用事实，锁死质量抗辩"）；
- **向证人**：先问无可否认的事实建立可信度 → 再问与书面证据矛盾的问题制造冲突 → 最后动摇证言基础（"你没亲眼看到吧？"）；
- **向鉴定人**：资质与回避 → 检材来源是否经质证 → 方法是否符合国家标准 → 结论是否唯一（成稿问句见 `references/cross-disciplinary/工程造价鉴定.md`）。

### 七、法官可能追问的问题

站在法官角度预判其最关心的问题（金额构成、对账经过、利息起算、效力前提、质保、和解可能等），**每问提前写好答案**，控制在3句话以内。

### 八、最后陈述要点

不是重复辩论意见，而是**情感升华+利益平衡**：事实清楚→我方诚信履约→对方违约失信→恳请支持诉请，三句话收束。
