# 11 裁判分析与上诉/再审

## Step 0 强制检查

加载本文件 → 读办案记录.md → 确认代理轨与**判后身份**（后缀见“双轨差异”节）→ 确认已有判决书/裁定书**原文全文**（含判项、本院认为、诉讼费分担）→ 确认**送达日期**（上诉期起算点）。

## 任务目标

收到裁判文书后回答三个问题：**改判空间在哪（五层核对＋金额拆解）、值不值得上诉（利益测算）、对方会不会上诉（预判防守）**。无论是否上诉，均须向当事人交付《裁判分析报告》。

## 核心方法：要件归入五层核对（九步法第 9 步的逆向检验）

**判决书的本质是一次要件归入，分析判决书就是检验这次归入的每一步。**

| 检查层 | 检查内容 | 对应上诉理由类型 |
|-------|---------|----------------|
| 请求层 | 判决是否漏判/超判诉请 | 遗漏或超出诉讼请求 |
| 规范层 | 请求权基础选错？法条引用错误/失效？**定性认定（合同效力、法律关系性质）是否错误？——即使无直接金额影响，若与对方武器库联动（如无效→先开票条款无效→利息防线崩），必须列入主张/防守清单**（案例D教训） | 适用法律错误 |
| 要件层 | 要件拆解是否完整？要件认定有无证据支撑？**金额拆解法：判付金额 − 我方自认金额，逐项拆到具体计算项，差值即二审主战场**（案例D实证：173,600.47=106,423.31+67,177.16，精确锁定全部改判点） | 认定事实错误/证据不足 |
| 事实层 | 认定事实与证据是否对应？举证责任分配是否正确？交易习惯/间接证据推定是否违反合同相对性？ | 举证责任分配错误 |
| 程序层 | 管辖/回避/送达/举证期限/鉴定程序违法？ | 程序违法 |

**上诉点 = 定位到具体要件的认定错误**，禁止笼统称“事实不清、证据不足”。
**检索法条不得局限于民法典/建工解释**：价款含税与否等计价问题须同步检索《价格管理条例》等经济行政法规（第 6 条：未明确约定不含税→推定含税，案例D二审致胜依据）。
**判决内部逻辑矛盾单列**（案例D实证）：同一判决内同一事实的认定前后不一致（开票义务在利息部分被认定、在税金部分被无视），系二审最易接受的攻击角度，与改判逻辑同向。

## 操作步骤

1. **逐层核对**填五层表，无问题层标注“无问题”，判决内部矛盾单列；
2. **金额拆解法定战场**：判付金额 − 我方自认金额 = 二审主战场，逐项拆到具体计算项（案例D：差额 173,600.47 锁定全部改判点，与实际改判幅度吻合度 94%）；被上诉人轨反向拆解对方攻击金额；
3. **上诉点识别与分级**：改判级/发回级/说理瑕疵级，每点定位到具体要件＋金额＋证据/法条，按改判概率排序。⚠️ 两项概率校准（案例D教训）：
   - **附带小项**采纳率一律标“低”：为凑整附带主张的税差、口径差（案例D税差 10,272.73 被明确驳回“缺乏合同及法律依据”），不改变改判结论；
   - **无直接金额影响的定性点不得轻易放弃**：合同效力、程序认定等若与对方武器库联动，必须列入主张/防守清单——案例D一审“内部承包无效”认定对我方金额无害，但系利息防线前提（无效→发票条款无效→利息防线崩），且违反本地裁判规则（川渝高院解答第 8 条），密封预判“不主张”系盲测最大偏差，实际该点被二审主动采纳并纠正；
4. **上诉利益测算**：上诉净利益区间 = Σ（各改判点金额 × 改判概率）− 上诉成本，对比**对方上诉风险敞口**（案例D：净利益区间 ＋67,177~＋179,150 元 vs 对方利息敞口约 5–6 万元 → 建议上诉）；**上诉期 15 日/裁定 10 日立即写入待办并双重提醒**；无改判利益不启动（案例D：二审全面胜诉仅小项未获支持，无再审利益）；
5. **对方上诉点预判（必要组成，不得省略）**：站在对方立场跑一遍五层核对，列出其可能上诉点与改判概率；**镜像攻击检查**——我方发现的判决内部矛盾与说理漏洞，对方同样可能从反方向利用（案例D：对方承包人“合同无效→先开票条款亦无效→利息应付”的攻击与我方“判决内部矛盾”分析镜像同向，预判未覆盖该路径系教训）；
6. **出《裁判分析报告》（不上诉也要出）**：判决结论速览、归入链还原、五层核对表、我方上诉点表（金额＋概率）、对方上诉预判、净评估与明确建议——向当事人交代输赢原因与是否建议上诉；**不上诉建议须当事人留痕确认**；
7. **起草《民事上诉状》检查点**：上诉请求明确（撤销/改判/发回，改判须写明具体金额）、理由按检查层组织、每个理由落到具体要件/证据/法条、金额附计算过程；**判后委托边界核对**（案例A教训：判后解除风险委托的衔接——上诉/再审属新阶段，先核对委托授权是否覆盖，解除或变更风险委托的须先办衔接手续，避免无授权推进）；
8. **再审专项**（裁判生效后）：法定事由逐项对照（民诉法第 211 条，条文号引用前核验）——新证据/基本事实缺证据/主要证据伪造或未经质证/法律适用错误/程序违法/审判人员违法；6 个月申请期限审查（自知道或应知之日起算的例外）；**再审 vs 检察监督路径**：再审被驳回、法院逾期未处理或仍不服再审裁判的，可申请抗诉或检察建议——检察监督系再审后的兜底路径，先再审后监督。

## 双轨差异

| | 上诉人轨 | 被上诉人轨 |
|---|---------|-----------|
| 目标 | 改判/发回重审 | 维持原判、封堵对方攻击 |
| 核心动作 | 五层核对找错误点 ＋ 金额拆解锁战场 | 复核一审说理薄弱点、逐项拆解对方上诉点 |
| 首要文书 | 民事上诉状 ＋ 裁判分析报告 | 二审答辩意见 ＋ 裁判分析报告 |
| 利益测算 | 净利益区间 vs 对方上诉敞口 | 维持概率 vs 对方改判空间（对方不上诉则免战） |
| 特别警惕 | 附带小项概率评高；定性点漏判 | 只守不攻——镜像攻击路径须逐项封堵 |

**身份后缀切换**：一审 _原代/_被代 → 上诉阶段按是否上诉变为 _上诉人/_被上诉人；双方均上诉时以主程序身份后缀为准（案例D：被代→上诉人轨）。

## 自检清单

- [ ] 五层核对全部完成（无问题层标注“无问题”）
- [ ] 判决内部逻辑矛盾已单列分析
- [ ] 金额拆解法完成（判付 − 自认逐项拆解，锁定主战场）
- [ ] 每个上诉点定位到具体要件与证据/法条，分级有依据
- [ ] 附带小项采纳率按“低”校准，未改变结论
- [ ] 无金额影响的定性点已检查与对方武器库的联动
- [ ] 对方上诉点预判完成（含镜像攻击检查）
- [ ] 上诉利益测算已向当事人说明并留痕（净利益区间 vs 对方敞口）
- [ ] 上诉/再审期限已写入待办并双重提醒
- [ ] 不上诉建议经当事人留痕确认
- [ ] 判后阶段委托授权/风险委托衔接已核对
- [ ] 法条检索未局限于民法典/部门解释（经济行政法规同步检索）
