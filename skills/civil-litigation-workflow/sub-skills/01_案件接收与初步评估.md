# 01 案件接收与初步评估

## Step 0 强制检查

加载本文件 → 确认代理轨（原告轨/被告轨/未定）→ 利冲预检索通过。**首次接案豁免读办案记录.md（案件尚无），但本模块结束必须创建**——它是后续模块入口与跨会话恢复枢纽，未创建即模块 01 未完成。

## 定位与复用

- **案件登记**：路由 `capabilities/案件登记与简报.md`——登记表、委托阶段与收费方式、台账 `_log.yaml` 直接套用，不重复定义；
- **大事记**：接案后启动 `capabilities/大事记构建.md`（产出至 `01-大事记/`），本模块只负责前置——全量材料文本化（第三节）；
- **预期值公式**：公式与系数档位路由模块 10，本模块只初始化台账并封存基线。

## 任务目标

三问：①**能不能赢**——要件缺口初判（九步法第 9 步倒推）；②**值不值得打**——预期值 × 可执行性 − 成本；③**怎么打**——代理轨确认 + 衔接模块 02。前置门槛：**能不能接**（利冲/时效/管辖）不过关，三问不问。

## 一、利益冲突审查（任一命中即红灯）

- [ ] 本所/本人是否已代理本案对方当事人（含关联案件）
- [ ] 对方当事人是否为本所现有/曾有客户
- [ ] 本人曾在对方单位任职或参与本案相关事务（含前法官/检察官回避）
- [ ] 本人及近亲属与本案标的有无直接利害关系
- [ ] 同一案件中被双方同时委托（绝对禁止）
- [ ] 曾代理对方其他案件且掌握其未公开信息
- [ ] 同所其他律师代理对方，是否可豁免（书面知情同意且非同一案件对立双方）

命中红线：拒绝委托或依法退出；可豁免的**书面**留痕；潜在冲突 48 小时内报告合伙人。

## 二、案件登记与程序门槛

1. **登记**：调用 capabilities/案件登记与简报.md 生成《案件登记表》→ `00-案件登记/`，台账 `_log.yaml` 同步追加；
2. **诉讼时效审查**：请求类型 → 时效期间 → 起算点 → 中止中断 → 届满分级（安全/临界/已届满）。**被告轨反向用：时效抗辩**——成立即防线核心；
3. **管辖初判**：协议/专属管辖/仲裁条款排查——有仲裁条款而径行起诉 = 程序自杀；被告轨评估管辖异议（答辩期内提出，即日期限台账）。

## 三、材料完整录入规则（案例A教训 → v0.3.4 固化为规则）

接案材料**全部文件必须文本化（提取/OCR），不得按文件名预判重要性跳过任何文件**——未录入的事实 = 后续判断盲区。

- **教训**：案例A备忘录/承诺书漏 OCR 导致被告主次预判颠倒；背靠背承诺、混合支付条款可能藏在任何文件里；
- **无法识别的文件**：登记《未录入文件清单》→ `00-案件登记/`，相关判断**置信度降级**，补录后复核；
- **案例C范式**：137 个文件全量 OCR 后再做评估+方案+预期值封存——全量录入是盲测协议起点。

## 四、初步评估三问方法

### 4.1 能不能赢：九步法倒推

- 从第 9 步倒推：预判请求权基础 → 列构成要件 → 逐项对照现有证据 → 填《接案评估表》（要件 × 证据 × 缺口 × 能否补强 × 风险等级）；**无缺口要件也标注“无缺口”**；
- **被告轨**：逆向检索抗辩权三类型（妨碍/消灭/阻止）+ 否认，加载 `references/defense/`；
- **对方抗辩预判**：三类型各是什么、成立概率，写入评估报告。

### 4.2 值不值得打：预期值封存

- 预期值 = Σ（结果金额 × 概率）× 可执行性系数 − 剩余诉讼成本（路由模块 10）；
- 初始化台账：乐观/中性/悲观三分支，**概率须有要件依据**（引用 4.1），拿不准给区间不给点值；
- **封存基线**（案例C盲测协议起点）：评估当日封存台账第一行（日期+依据），**禁止修改**，后续更新只新增行留轨迹。

### 4.3 怎么打：代理轨与下一步

- 确认代理轨写入状态头；出具策略建议（诉讼/先发函/和解/不接）；
- 路由：**原告轨** → 模块 02（无方案不起诉）；**被告轨** → 模块 02 抗辩 + 模块 03 管辖异议/反诉评估。

## 五、创建办案记录.md 与状态头规范

案件根目录创建 `办案记录.md`，模板：

```markdown
# 办案记录 —— [案件名称]
> 【状态头】当前阶段：诉前评估 | 代理轨：原代 | 已完成模块：01 | 进行中：— | 下一步：02请求权分析 | 涉及专业领域：—

## 案件基本信息
（当事人、案由、标的额、时效截止日、管辖法院）

## 判决预期值台账
| 日期 | 乐观/中性/悲观结果 | 预期值 | 对方和解报价 | 我方底线 | 结论 |
（第一行封存基线；重大节点新增行留依据）

## 程序期限台账
| 期限事项 | 截止日 | 依据 | 状态 | 提醒 |
|---------|--------|------|------|------|
| 上诉期（判决15日/裁定10日） | | 民诉法 | ☐ | 届满前3日双重提醒 |
| 举证期限 | | 举证通知书 | ☐ | |
| 答辩期/管辖异议（15日） | | 民诉法 | ☐ | 被告轨接案即登记 |
| 保全续封（存款1年/动产2年/不动产3年） | | 民诉法解释第487条 | ☐ | 届满前30日申请 |

（风险偏好 / 和解授权底线 / 沟通方式与频率 / 特别指示）
```

**状态头规范**：跨会话恢复唯一枢纽，六项每次任务结束必须更新；**涉及专业领域**（造价鉴定/司法会计/资产评估）一经识别即登记，非空时后续模块执行前加载 `references/cross-disciplinary/`。

**期限台账规则**：每次会话先扫台账；新收程序文书当日更新；届满按提醒列执行。

## 六、当事人偏好与授权边界访谈

接案时访谈并**留痕**（微信确认亦可），写入办案记录：

1. **风险偏好**：保守/中性/进取——决定模块 10 底线调整方向；
2. **和解授权底线**：金额底线 + 让步决策程序（律师可拍板幅度 vs 必须请示红线）；
3. **沟通方式与频率**；4. **特别指示**：商业关系、保密、时间偏好。

**门禁**：未留痕的，模块 10 拒绝评估和解方案。**放弃性决策**（不主张有依据的权利、接受低于底线方案）须当事人书面/留痕确认（核心原则 11）。

## 输出文件

- `00-案件登记/YYYYMMDD_案件登记表.md`（capabilities/案件登记与简报.md 格式）
- `00-案件登记/YYYYMMDD_初步评估报告_原代.md`（轨后缀 `_原代`/`_被代`；含评估表、三问结论、策略建议）
- `00-案件登记/未录入文件清单.md`（如有）
- `办案记录.md`（案件根目录，本模块创建）
- 台账 `_log.yaml` 追加一条

## 自检清单

- [ ] 利冲七项已排除（或书面知情同意已留痕）
- [ ] 材料全量文本化；无法识别的已登记《未录入文件清单》并置信度降级
- [ ] 时效已分级（被告轨含时效抗辩）；管辖/仲裁条款已排查
- [ ] 接案评估表逐项填写（无缺口也标注）；对方抗辩三类型已预判
- [ ] 代理轨已确认并写入状态头；办案记录.md 已创建，状态头六项完整
- [ ] 预期值台账已初始化并封存基线（日期+依据，基线不可改）
- [ ] 期限台账已建立（被告轨答辩期/管辖异议期已登记）
- [ ] 当事人偏好与授权边界已访谈留痕
