# 08 庭审发问与辩论

## Step 0 强制检查

加载本文件 → 读办案记录.md → 确认代理轨 → 确认已有《争点清单》《庭前准备提纲》。

## 定位与复用

- **复用** 模块 07 附录的发问提纲与质证要点规范；
- **本模块新增**：发问技术规范、辩论结构设计、庭审突发应对。

## 发问规范

- **明知故问**：只问知道答案或答案无害的问题；禁止开放式提问（“请你说说当时的情况”）；
- 一问一事实；逻辑递进（铺垫问 → 关键问 → 锁定问）；
- 分对象设计：对方当事人 / 证人 / 鉴定人（鉴定人发问路由跨专业 references 的质证发问章节）；
- 标注体系：【必问】【追问】【备选】【禁忌】；
- 目的导向：每个问题的目的只能是三种之一——固定有利事实 / 暴露对方矛盾 / 为辩论埋伏笔。

## 辩论结构设计

1. **围绕争点，不念文书**：“关于争点一（合同是否成立），我方认为……”——发言结构 = 争点清单的顺序；
2. 每个争点的辩论单元：我方主张 → 证据支撑（证据编号）→ 对方主张的错误 → 法律适用；
3. **对方观点预判与反驳表**（庭前填好，庭上对照使用）；
4. 预判法官提问并准备应答（法官问什么 = 判决写什么的信号）；
5. 最后陈述要点化（三句话以内，呼应首位争点）。

## 庭审突发应对

| 突发情形 | 应对动作 |
|---------|---------|
| 对方当庭提交新证据 | 不当场实质质证；声明“超过举证期限+需要质证准备期”，申请书面质证或另定质证时间；证据与基本事实有关的，庭后书面质证并申请给予反驳举证期 |
| 对方变更/增加诉讼请求 | 要求重新给予答辩期与举证期（民诉法及举证规则）；评估是否触发案由变更与管辖变化 |
| 法官释明拟变更案由/请求权基础 | 不即兴表态；请求休庭或庭后书面意见；评估对我方要件体系、举证责任的影响后再回应 |
| 对方突袭申请证人出庭 | 审查是否在举证期限内申请；超期的提出异议；对证人发问改为封闭式锁定身份与利害关系 |
| 调解试探（法官或对方） | 路由模块 10；当庭不作实质承诺，标准话术：“愿意调解，具体方案需与当事人核实后书面回复” |
| 对方当庭自认有利事实 | 立即请求书记员记入笔录，并在辩论阶段复述固定（“对方在庭审中已确认……”） |
| 法官诱导性/倾向性提问 | 识别信号（法官问什么=判决写什么）；对不利提问不硬顶，用“该事实应以证据×为准”回落到证据 |
| 当事人/旁听人员情绪激动、不当发言 | 及时制止己方当事人发言冲动；必要时申请休庭 |
| 庭审笔录 | 庭审结束**逐页核对**，我方关键陈述、对方自认、法官释明漏记的当场要求补正后再签字 |
| 线上开庭设备故障/掉线 | 立即电话联系法庭说明；掉线期间进行的程序要求确认或重新进行；重要庭审提前测试设备并准备备用网络 |
