# 03 起诉与应诉（双轨）

## Step 0 强制检查

加载本文件 → 读办案记录.md → 确认代理轨 → 前置产出物门禁（不齐的回模块 02 补齐，禁止动笔）：

- **原告轨**：模块 02《诉讼方案》已经用户确认（**无方案不起诉**），且已按案由加载 `references/claim-basis/` 对应案由文件；
- **被告轨**：已完成抗辩权检索（强制加载 `references/defense/抗辩权三类型与诉讼时效.md`，妨碍→消灭→阻止逐类过筛，时效单独核），《应诉方案》已经用户确认（**无方案不答辩**）。

## 任务目标

把《诉讼方案》/《应诉方案》落地为可受理的程序动作：**诉请项项有请求权基础托底，答辩层层有抗辩梯队设防，程序先手（管辖、期限）不失手。**

## 二、原告轨：起诉状 + 管辖选择 + 立案策略

### 2.1 起诉状起草检查点（格式见模板）

1. **诉请逐项回溯**：每项诉请对应《诉讼方案》请求组合的具体行 + 一条明确请求权基础（到条款项）；禁止超出方案，也禁止擅砍方案——**有依据但结果存争议的请求（如优先受偿权），披露风险后照主张，不替当事人放弃**（原则 11）；
2. **事实与理由按要件组织，不写成编年体**：每个构成要件一段，段内事实主张标注证据编号；时间线叙事是模块 05 大事记的活；
3. **金额精确到分**，本金/利息/违约金分项，计算过程附后（暂计类写明截止日与持续计算表述）；
4. 主体信息（名称/统一社会信用代码/住所）与工商登记核对一致。

### 2.2 管辖选择（原告的程序先手）

盘点全部法定连接点并择优：被告住所地 / 合同履行地 / 约定管辖（先审查效力）/ 专属管辖（**建工按不动产所在地专属管辖，无选择空间时跳过**）。择优标准：己方诉讼便利、财产所在地与保全配合（衔接模块 04）。风控：选连接点薄弱的法院 = 送给对方成立率高的管辖异议，反拖慢自己（案例D反向教训）。选择理由写入办案记录。

### 2.3 立案策略

1. 材料包：起诉状（被告人数+1 份）、主体资格证明、授权委托、证据复印件、送达地址确认书；网上立案先行；
2. 诉讼费测算 + 缓减免评估（符合条件的路由源库 9.1 模板）；
3. **同步评估诉前/诉中保全**（路由模块 04）——先立案后补保全的窗口期对方可能转移财产；
4. 立案受阻时记录过程，评估投诉或向上一级反映。

## 三、被告轨：答辩状 + 管辖异议 + 反诉 + 期限管理

### 3.1 期限管理（收到诉状第一件事，先于任何文书起草）

全部写入办案记录待办并倒排：**答辩期 15 日**；**管辖异议期 = 答辩期内**，逾期失权；**举证期限**以举证通知书为准，延期/调查取证申请须届满前提出；**反诉**以举证期限届满前提出最稳妥（最迟法庭辩论终结前），越晚越被动。

### 3.2 答辩状起草检查点

1. **逐项回应，不留空白**：对每项诉请、每段事实逐一表态——承认/限定承认/否认三档，漏答的事实可能被拟制无异议；
2. **自认禁区**：对己方不利且无证据翻盘的事实，用“由原告举证证明”的否认表述，不作解释性展开；拿不准的一律降档为否认，自认撤回极难；
3. **先程序后实体**：主管/管辖、主体不适格、时效届满等前置，实体抗辩随后；
4. **多层防线梯队**（案例E实战验证）：按“第一层失守后第二层仍独立成立”组织——案例E三层防线：新增服务事实 → 管理性规定不否定结算效力 → 结算确认独立有效。每层单独成立即可守住结果，避免单点防御一击即溃；
5. 答辩状只亮防线轮廓，证据细节与攻击点排序留给模块 07，不过早暴露底牌。

### 3.3 管辖权异议评估（案例D实战校准）

异议是程序先手，但**先算时间成本账再决定**。评估三问：成立概率（对照约定管辖/专属管辖/连接点强度）？移送法院是否真更有利？拖延的时间对己方是资产还是负债（保全解封、融资节点、证据补强需求）？

案例D教训：异议被驳后上诉，重庆中院仍维持——异议+上诉走完，案件原地踏步数月，时间成本沉没而管辖未动。**成功概率低的异议不是免费的**，决策计入双账本并报当事人知情。操作：答辩期内书面提出；驳回裁定 10 日内可上诉，上诉与否同样过三问，禁止为拖而拖。

### 3.4 反诉评估与操作

- **决策标准路由模块 02 反诉证据链闭合标准**（案例B教训：不闭合时全驳 + 反诉费沉没 11.4 万；不闭合的降级为抗辩性抵销主张或另诉）；
- 决定反诉后，反诉状**走本模块原告轨全流程**；反诉费/鉴定费计入预期值成本项（联动模块 10）；
- 反诉 vs 另诉：合并审理的抵销便利 vs 另诉的管辖自由与节奏自主；
- **原则 11 适用**：反诉请求的纳入/放弃须当事人知情留痕（案例E被代+反诉原告双身份已验证）。

### 3.5 举证期限管理

收到举证通知书当日登记并倒排证据组织任务（路由模块 05）；证据无法按期备齐的**届满前**申请延期，关键证据在对方控制下的同期申请调查取证；逾期举证可被训诫、罚款甚至不采纳——书面告知当事人，别把关键证据拖成逾期证据。

## 四、双轨差异

| | 原告轨 | 被告轨 |
|---|--------|--------|
| 思维方向 | 正向构建：要件→事实→诉请 | 逆向攻击：逐项回应+抗辩梯队 |
| 首要文书 | 起诉状+证据清单（初版） | 答辩状（先程序后实体） |
| 程序先手 | 管辖选择、诉前/诉中保全 | 管辖异议（先算时间账）、期限管理 |
| 事实表述 | 按要件组织，主张到证据编号 | 三档表态、自认禁区 |
| 金额动作 | 诉讼费测算+缓减免评估 | 反诉费/鉴定费计入预期值成本 |
| 特别警惕 | 诉请超方案或擅砍方案 | 漏答被拟制无异议、反诉链不闭合 |
