# 09 代理词撰写

## Step 0 强制检查

加载本文件 → 读办案记录.md → 确认代理轨 → **前置产出物齐备**：争点清单、要件-证据对照表、质证意见、庭审复盘记录（已开庭的）。缺任一即停，先补齐。

## 定位与复用

- **复用** `references/templates/代理词格式规范与生成指令.md`：排版、五段式结构、语言风格（先驳后立/标题即论点/综上所述收尾）不重复定义；
- **本模块新增**：论证方法论、写作顺序、生成流程、庭后衔接。

## 一、写作前的三个决策

1. **交不交**：庭审已充分发表且法官无要求的，可只交书面要点；法官当庭给期限的，死期限登记进办案记录期限台账。
2. **写什么**：代理词 ≠ 辩论提纲复读。只写**法官存疑的、庭上没说透的、对方庭后可能补刀的**内容；庭上已固定且法官明显接受的，一句带过。
3. **什么顺序**：争点排序 = **胜诉贡献度 × 法官关注度**（据庭审复盘记录中法官提问密度判断），不是起诉状顺序。首位争点必须是我方最强点。

## 二、论证方法论

### 2.1 基本单元：三段论 × 争点

每个争点一个论证单元：

```
大前提：法律规范 + 构成要件（法条到条、款、项）
小前提：已查明/已举证事实（每个事实主张证据编号回指）
结  论：该要件成立/不成立 → 归入请求权基础/抗辩权
```

- **原告轨**：逐要件正向归入，全部要件闭环后落到“请求成立”；
- **被告轨**：只需攻破对方**一个**必要要件即胜——代理词应把所有火力压在选定的突破口要件上，其余要件简要否认即可，**禁止平均用力**；
- 有反诉/抗辩的，按“先破后立”排列：先瓦解对方请求，再立我方主张。

### 2.2 四种强化技术

| 技术 | 适用场景 | 写法 |
|------|---------|------|
| 反推论证 | 攻击对方核心主张 | 假设对方主张成立 → 应有结果 X → X 不存在/与证据Y矛盾 → 主张不成立 |
| 举证责任收尾 | 事实真伪不明的争点 | 落点必须是“举证不能的后果由对方承担”（引民诉法解释第90/91条） |
| 庭审自认固定 | 对方庭上有利陈述 | 引庭审笔录页码：“庭审笔录第 X 页记载，对方确认……” |
| 法官之问回应 | 庭上法官追问的问题 | 专设段落正面回应——法官问了就说明判决要写，回避等于放弃该争点 |

### 2.3 数据精确性

- 金额主张必须展示计算过程（基数 × 标准 × 期间），禁止直接给结论数；
- 利息/违约金计算路由 4.3 工具表的计算器，计算过程写入文书附注。

### 2.4 要件归入表收尾

全文末尾附《要件归入表》，让法官可以直接搬进判决书：

| 要件 | 我方主张的认定事实 | 支撑证据（编号） | 对方抗辩及回应 | 是否满足 |
|------|------------------|----------------|--------------|---------|
| 要件1 | …… | 证据3、5 | 对方称……，但…… | ✅/❌ |

## 三、庭后特殊情形处理

| 情形 | 处理 |
|------|------|
| 庭后补充举证（法院准许的） | 代理词相应章节以“庭后补充证据显示”改写，禁止装作庭上已质证 |
| 庭上自认了不利事实 | 不回避；转入“次位抗辩”或“责任减轻”的论证，丧失诚信比失掉一个事实更糟 |
| 法官释明变更案由/请求权基础 | 代理词按释明后的体系重写论证，同时保留对原体系的意见（防止二审口径翻转） |
| 对方庭后提交代理词 | 读完后只回应**新增攻击点**，写《补充代理意见》，不重复全文 |
| 金额计算存在备选路径（与在卷证据口径不完全一致） | 正文用在卷口径，备选路径以“备选路径”显式双轨入正文，禁止只留工作底稿（案例D教训：增项“不含税”路径仅留底稿，一审“9% 税差点”落败，二审恰按该备选路径改判） |

## 四、生成流程（防上下文失真）

1. 列提纲（到三级标题）→ 用户确认；
2. **分段生成**：每次只写一节，每节显式从案件文件夹调取所需材料，禁止一次性生成全文；
3. 每节完成后自检：事实主张有证据编号 / 法条到条款项 / 与前文术语一致；
4. **一致性回读**：全文生成后通读校验——金额、日期、当事人称谓、证据编号、争点序号前后一致；
5. 法条核验：全部法条联网核验现行有效；
5.1. **claim-basis 落笔核对**：代理建工/合同/借贷/公司案由案件时，生成后逐条核对 references/claim-basis 对应文件“复盘沉淀”节，确认相关规则已落笔或显式放弃（案例D教训：价款含税推定规则、最高法3784号答复已入库但代理词未落笔，一审113万被认定不含税多判10.6万）；
5.2. **交易习惯法据**：以交易习惯/结算惯例为论据的，必须引《民法典》第10条、第510条作为法据层，禁止只做事实描述（案例D实际代理词结构实证）；
6. 过 `references/quality/` 质控三规范（输出标准/来源标签/风险评级）后交付；需 Word 版的按主控 Word 规范输出。
