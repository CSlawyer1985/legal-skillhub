# 05 证据组织与举证

## Step 0 强制检查

加载本文件 → 读办案记录.md → 确认代理轨与当前阶段。**门禁：模块 02《诉讼方案》已产出、要件清单已定——无要件清单不组织证据，先回模块 02。** 逐要件核对举证责任时强制加载 `references/defense/举证责任分配与倒置规则.md`。

## 任务目标

每个要件事实都有证据或补强方案，每个事实主张都能出处回指（证据编号+页码），举证期限内提交且全程留痕。

## 一、定位与复用（编排不复制）

- **大事记先行**：时间轴全部委托 `capabilities/大事记构建.md` 技能（操作第 1 步调用），产出落 `01-大事记/`，作为证据编组的叙事骨架；本模块不重复其方法。
- **证据清单格式**：套用 `references/templates/证据清单模板.md`（分组、编号、编页、法院提交版要素）。
- **程序文书**：调查取证、延长举证期限、证人出庭、鉴定、证据保全五份申请书路由 `references/templates/诉讼程序文书/README.md` 之“02-举证与调查”组（库内条文号为旧编号，引用前核验）。
- **举证责任落点**：逐要件核对“我方/对方/倒置”时加载上述 references 文件。
- **本模块增量**：要件-证据对照表制法、原件调取、举证期限台账、庭后补证、自认固定。

## 二、核心方法：要件-证据对照表（举证组织主线）

以《诉讼方案》要件清单的每个要件为一行，填五列：

| 要件 | 待证事实 | 证据（编号） | 举证责任归属 | 证明力评估 | 缺口与补强措施 |
|------|---------|------------|------------|-----------|--------------|

**制法要点**（案例E实战，被代）：

1. 对照表分两层——**否认层**（对方要件×我方立场：承认/否认/法律争点）与**抗辩层**（我方抗辩要件×证据，责任在我方）；原告轨为“请求权要件×证据”单层表；
2. 证明力分强/中强/中/弱档并注明理由（如“招标人自制文件”“无签收章”），不写空泛结论；
3. 每个缺口挂补强措施+责任人+期限；
4. 表尾固定“开庭前待办”一节（案例E实证：第一优先项就是**调取原件**）。

## 三、操作步骤

1. **大事记先行**：调用 capabilities/大事记构建.md 产出时间轴（来源锁定到页、正反两造均记）。
2. **逐要件填对照表**：识别缺口，举证责任归属逐行标注（含倒置）。
3. **缺口补强**：补充收集 → 书证提出命令/申请法院调查取证（民诉法第67条第2款，**申请本身留痕**，可作上诉理由）→ 证据保全 → 鉴定（路由跨专业 references）。调查取证、证人出庭申请须在**举证期限届满前**书面提出。
4. **证据编组与清单**：按证明目的分组（不按时间），组号-序号编号（如 1-3），套用证据清单模板；每份标注名称/来源/证明对象/要件编号/原件复印件。
5. **编页规范**：每份证据自“第1页”重新编页，装订页右上角标“组号-序号-页码”（如 1-1-1），与清单“共X页”一致；核心条款页加贴标签（案例E：招标文件运行时间条款）。
6. **原件原物核对**：庭前向当事人**调取全部原件**逐份核对（扫描件存档≠有原件），列庭前待办第一优先项，开庭随身带庭；确无原件的提前准备形成与保存情况说明。
7. **大案卷分工**：证据超 300 页按“合同/履约/款项/往来函电”分组并行提取，但要件归入与矛盾比对必须由单一全局视角集中完成。
8. **被告轨附加**：同步组织抗辩要件举证 + 对方证据弱点标注（产出喂给模块 06）。

## 四、举证期限台账（被告轨程序先手）

在办案记录“程序期限台账”建举证期限条目：

| 事项 | 截止日 | 动作要点 |
|------|--------|---------|
| 举证期限届满 | 以举证通知书为准 | 入账即设提前 5 日内部死线；届满前一次性提交，不挤牙膏 |
| 延期/调查取证/证人出庭申请 | 届满前 | 书面提出并留痕，逾期法院可不准许；被告轨收到起诉状即评估 |
| 逾期举证应对 | — | 对方逾期：当庭要求说明理由并主张不采纳；我方逾期：基本事实证据**挨罚也要交**（民诉法解释第102条），非基本事实的权衡放弃 |

## 五、庭后补充证据操作（案例D实战，被代）

1. 庭审暴露的薄弱链（如扣减链证据不足）庭后立即补强，补充证据按原编号续编（案例D：补充证据 5–8 接原 1–4）；
2. 同步制作《补充证据清单》，写明每份补证目的与对应争点；
3. **寄出留痕**：EMS 寄法院，保留面单与妥投记录，记入办案记录；
4. 法官已给补证期限的严格按期；无指令的在评议前尽快提交并附补证理由说明。

## 六、自认固定与禁反言（案例D实战）

1. 对方自制文件（如原告《结算情况说明》）载明对我方有利事实的，**原件索取+笔录固定**：庭审中就该文件发问，使对方确认“系我方制作、内容属实”；
2. 自认固定必须**笔录页码回指**：自认内容所在笔录页码记入对照表与办案记录，代理词引用格式“庭审笔录第X页：……”（出处回指）；
3. 禁反言：对方前后陈述矛盾的（诉状/庭审/自制文件口径），列表比对、逐项回指出处，主张按最不利于对方的口径认定；
4. 我方防自认：庭前书面提示当事人——自制说明、微信回复、庭审回答均可能构成自认，未经律师审核不出具任何事实性书面材料。

## 双轨差异

| | 原告轨 | 被告轨 |
|---|--------|--------|
| 举证范围 | 请求权**全部要件**逐项举证，缺一不可 | 仅抗辩权要件负举证责任；对方要件只需**攻击**（使事实真伪不明），攻击≠举证 |
| 对照表结构 | 单层：请求权要件×证据 | 双层：否认层（对方要件×立场）+ 抗辩层（我方要件×证据） |
| 责任标注 | 全部标“我方”，缺口即败诉风险点 | 逐行标“我方/对方”，对方负担的只组织反证，不替对方补证 |
| 程序先手 | 诉前证据保全、证据公证 | 举证期限管理（入账+逾期攻击）、管辖异议期内评估取证需求 |
| 原件策略 | 起诉即备齐，立案后核对 | 按对方证据清单逐项核对原件必要性 |
