# 10 调解与和解评估（贯穿全程）

## Step 0 强制检查

加载本文件 → 读办案记录.md（重点读“判决预期值台账”）→ 确认代理轨 → 确认当前阶段 → 确认当事人**风险偏好与授权边界**已访谈留痕（模块 01 办案记录模板“当事人偏好授权边界”板块）。未留痕的，先补访谈再谈方案。

## 任务目标

任何和解节点都能回答：**这个方案，比继续打下去划算吗？**

## 一、触发节点（主动想起本模块，而非等用户问）

| 节点 | 动作 |
|------|------|
| 接案评估时 | 初始化判决预期值台账（模块 01 联动） |
| 起诉/答辩完成时 | 首次更新：诉讼方案落定后重算 |
| 保全裁定作出后 | 更新：保全到手 = 筹码变化 |
| 庭审结束后 24h 内 | 更新：法官关注点、对方底牌已暴露，概率重估 |
| 法官组织调解 / 对方抛出方案 | 全量运行本模块，产出方案对比表 |
| 判决宣判前 / 上诉期内 | 终审前最后一次谈判窗口评估 |

## 二、核心方法：判决预期值

```
判决预期值 = Σ（各结果金额 × 概率）× 可执行性系数 − 剩余诉讼成本
```

### 2.1 结果分支与概率

- 分支：全胜 / 部分胜诉（逐情形列明）/ 败诉；
- 概率**必须有依据**：引用要件缺口分析与争点强弱（“对方要件2缺直接证据，仅有间接证据链”），禁止拍脑袋写“七成胜算”；
- 概率来源存疑时，给区间（如 50%–70%）而非点值。
- **支付方式条款扫描**（案例A教训）：测算前必须扫描合同付款方式条款——“现金+工抵”混合支付、“未付足部分不计息”、背靠背条款会结构性改变现金回收额与利息空间，利息不得按缺口全额机械计算；
- **对方主张口径滚动修正**（同上）：对方实际答辩/反诉口径明朗后立即修正预期值——预判的大额反索赔对方未主张的，上修并标注；惩罚性违约金（如日 2‰）对方“会提”≠“敢提”（对方同样评估调减风险与反诉费），扣减不宜过度保守；
- **被告轨证据审查→胜率映射**（案例B教训：盲测防守预期 80–150 万支出，实际零支出）：对方关键证据系单方制作（自报台账、无签章联系单）且无补正可能的，防守胜率直接上调一档；同时“事实真伪不明”双刃效应须同时评估对本诉与反诉的影响；

### 2.2 可执行性系数

| 对方财产状况 | 建议系数 |
|-------------|---------|
| 已足额保全到位 | 0.9–1.0 |
| 有公开财产线索未保全 | 0.6–0.8 |
| 经营困难/多起被执行记录 | 0.3–0.5 |
| 空壳/失联 | ≤0.2 |

**最低档强制触发**（案例C教训，2026-08-06 回写）：以下三项命中两项即直接取 ≤0.2，不再按中间档估计——①股权已全额出质给银行等第三方；②注册资本大额认缴未实缴（实缴<20%）；③首轮总对总查控无银行存款/不动产/车辆。案例C：被执行人三中三，调解后仅自动履行 40 万，执行到位 0、终本——盲测时按 0.5–0.7 估计严重偏乐观。

依据来源：模块 04 财产线索、公开执行信息检索（需联网核验并标注来源与查询日期）。**判 100 万拿不到，不如和解 60 万现金。**

### 2.3 剩余诉讼成本

律师费尾款 + 诉讼费 + 时间精力 + 商业关系损耗（持续诉讼对招投标、授信的影响，视当事人行业而定）。

## 三、操作步骤

1. **计算/更新预期值** → 写入办案记录“判决预期值台账”（每次更新留日期与依据，形成过程轨迹）；
2. **设定底线**：底线 = 预期值 ± 风险偏好调整 → **当事人书面/留痕确认**（微信确认亦可，但必须留痕）；
3. **方案对比表**（六维）：

   | 维度 | 判决预期 | 对方方案 | 差额/风险 |
   |------|---------|---------|----------|
   | 金额 | | | |
   | 支付期限 | 判决+执行周期 | | |
   | 担保/保障 | 无（靠执行） | | |
   | 违约责任 | 迟延履行利息 | | |
   | 保密/商誉 | 判决公开上网 | | |
   | 诉讼费分担 | 按败诉比例 | | |

4. **谈判策略**：
   - 筹码盘点：保全在手 / 对方败诉风险点 / 时间压力在谁（对方上市、融资、招投标节点 = 我方筹码）；
   - 报价阶梯：开价 → 让步节点 → 底线，每次让步必须换对价（付款提前、增加担保），**不做无条件让步**；
   - 让步节奏：幅度递减（如 20→10→5），给对方“逼近底线”的信号。
5. **调解/和解文件审查**（见第四节清单）；
6. 调解结案效力核对：法院调解书有强制执行力；庭外和解协议没有——须衔接撤诉、司法确认或赋强公证。

### 3.1 扩围打包和解（案例C教训，2026-08-06 回写）⭐主动选项

己方对同一对方有**多条平行债权线**（诉讼/仲裁/未起诉，尤其弱线存在结算未定、鉴定风险、优先权超期、管辖分割等问题）且对方有谈判意愿时，主动评估**把弱线债权打包进强线案件的调解书**：

- **价值**：弱线债权从“要打官司/仲裁+鉴定才可能确认”变成“调解书直接确认、可强制执行”，省程序费用、消灭不确定性；对方获得一次性了断与分期，谈判有对价。
- **算法**：打包价基准 = Σ各线（判决预期值×可执行性系数），在此基础上折让（折让即弱线省下的程序成本+时间+风险的对价）。
- **操作**：诉中变更/增加诉请把关联合同纳入（案例C：设备案诉中变更诉请至 400 万，将购销+联动+安装结算打包确认为 692 万总结算，仲裁线撤回），调解书主文须逐合同列明结算金额与付款安排，避免“另行协商”表述。
- **风控**：打包后弱线即终局了结——打包价折让幅度须经当事人书面/留痕确认（核心原则 11：放弃性决策留痕）。

## 四、和解协议/调解书审查清单（可执行性为核心）

**⚠️ 分期方案两条硬底线**（案例C实证：首付 12.5%+无担保的分期调解，第一期即违约、执行到位 0、终本）：

- [ ] **首付比例**：无担保分期首付 ≥30–40%；低于此比例 = 对方零成本展期，宁可不谈或要求补足担保
- [ ] **担保到位**：分期必须配担保（连带保证人/物保登记/股权质押）；加速到期条款只是兜底程序入口，**不能替代担保**——违约后仍要走执行，对方无财产时加速条款一文不值

- [ ] 支付条款：金额、期限、账户明确；分期的必须有**加速到期条款**（任一期逾期，余款全部到期并可一并申请执行）
- [ ] 违约条款：逾期违约金/利息标准明确，高于迟延履行利息才有威慑
- [ ] 担保条款：保证人主体适格、保证方式（连带）、保证期间明确；物的担保须登记
- [ ] 撤诉/结案安排：我方收款到账前**不撤诉、不解除保全**（先撤后付 = 重大风险，须用户书面确认才接受）
- [ ] “一次性了结”条款：放弃范围逐字审查——是否连带放弃反诉、另案权利、未发现的损失
- [ ] 调解书主文表述可直接作为执行依据（给付内容具体确定，无“双方另行协商”类条款）
- [ ] 司法确认/赋强公证的适用性已评估（庭外和解时）

## 五、双轨差异

| | 原告轨 | 被告轨 |
|---|--------|--------|
| 和解目标 | 快速回款、落袋为安 | 减额、争取付款期限 |
| 核心筹码 | 保全 + 胜诉概率 | 程序时间 + 执行不能风险 |
| 底线形态 | 最低受偿额 | 最高支付额 + 最长期限 |
| 特别警惕 | “以调解拖执行”——调解分期 = 变相展期 | 调解书违约金过高 + 加速到期条款 |
