# 02 请求权基础分析与诉讼方案设计 ⭐

## Step 0 强制检查

加载本文件 → 读办案记录.md → 确认**三项前置**，缺一不得开工：

1. ✅ 模块 01《初步评估报告》已产出（无评估不做方案）；
2. ✅ 代理轨已确认（原代/被代，或“被代+反诉原告”复合身份）；
3. ✅ **案由对应的 `references/claim-basis/` 文件已加载**（建工/合同/借贷/公司已填充；侵权/劳动按其 README 结构现场构建并回写）；**被告轨另强制加载** `references/defense/` 两份文件。案由核对：`references/legal/民事案件案由规定（2025年第三次修正）修改要点.md`（由低到高选择）。

## 任务目标

产出《诉讼方案》，回答五问：**打什么**（请求组合）、**依据什么**（请求权基础+要件）、**告谁**、**去哪告**（管辖）、**先锁什么**（保全建议）。原则第 1 条：无方案不起诉、无方案不答辩。

## 一、原告轨四步（九步法第 1–4 步正向）

### 第 1 步：固定权利请求

- 识别诉的类型（确认/给付/形成）；剔除矛盾请求；多请求关系按对抗/补充/备选处理（备位单列）；
- **纳入铁律（原则 11）**：每个请求必须有明确的合同或法律依据（请求权基础），无依据不得纳入——无例外；
- **主张检索**：从生活事实穷尽权利主张点，逐项对照请求权基础筛选防漏项——**应主张而未主张 = 执业风险**。

### 第 2 步：请求权基础检索

按序检索——**合同 → 类合同（缔约过失/无权代理/无效折价补偿）→ 物权 → 侵权 → 不当得利**；候选路径列条文到条款项，**排除的也写明排除理由**。要件表、举证责任直接引用 claim-basis 案由文件，不复制。

### 第 3 步：竞合与案由选择

竞合按四维比较：**举证难度 × 赔偿范围 × 特殊利益（如建工优先受偿权）× 管辖差异**，定主路径+备选路径。

- **案由即叙事**（案例A实证）：案由同时决定适用规则与法官第一观感。该案放弃“分包”定性、选择**装饰装修**案由，构建“服务承包人”叙事——分包人在建工规则下多处受限，装饰装修承包人反而独享优先受偿权规则（解释一第 37 条）。选案由时同时问：**哪个身份对我方最有利？** 易混淆案由查 claim-basis 文件第四节“此诉彼诉辨析”，选定理由写入方案。

### 第 4 步：要件拆解与对方抗辩预判

1. 逐一拆解构成要件，填《要件分析表》（要件 × 法律依据 × 具体条件 × 举证责任 × 现有证据 × 缺口）——**缺口要件必须给出补证路径**（书证提出命令/调查取证申请）；
2. **对方抗辩预判**：用“否认+三类型”反向扫描自己的请求写入“风险与应对”节——**自己先当一遍对方律师**；
3. 当事人设计（共同被告、第三人）、管辖与仲裁条款审查、保全建议（→ 路由模块 04）。

## 二、被告轨四步（九步法第 3 步逆向）

1. **先分否认与抗辩**（铁律：能否认不抗辩——抗辩把举证责任揽到己方）：对方哪个要件事实可直接否认，逐一列出（举证责任在对方）；
2. **抗辩权三类型检索**：妨碍（无效/不成立/无权代理…）→ 消灭（清偿/抵销/免除/时效届满…）→ 阻止（同时履行/先履行/不安/先诉…），逐类过筛，**不适用的标注“不适用”而非跳过**（案例E应诉方案同此留痕）；
3. **要件缺口攻击图**：复刻对方《要件分析表》，最弱环节按**致命/重大/一般**排序——致命点（举证责任在对方且其必然举证不能）排前，攻击图即庭审主线；
4. 反诉评估（见第四节）+ 管辖异议 + 举证任务分配。

## 三、多层防线梯队结构设计（案例E实证）⭐

被告轨方案不得只有一道防线。案例E（被代）三层防线：

- **一线（事实层）**：新增服务事实坐实——非工作日服务不在招投标范围内，未背离中标实质性内容；
- **二线（法律定性层）**：招标投标法第 46 条系管理性规定而非效力性规定（（2015）最高法民申字第 280 号），即使违反也不无效；
- **三线（兜底合意层）**：结算确认行为独立有效（苏 05 民终 11957 号），即使条款无效，已确认金额仍应付。

**梯队设计三规则**：

1. **逻辑独立**：各层互不依赖——一线崩塌退二线、二线失守三线兜底，任一层成立即保住核心利益；
2. **层序固定**：事实层 → 法律定性层 → 兜底合意/金额层，与审理顺序同向，不与对方主战场正面消耗而是**错开战场**；
3. **对方预判入图**：对方文书中预防性反驳的点 = 其最怕的点，标注并打透（案例E起诉状预防性反驳“实际履行多年”，恰暴露软肋）。

## 四、反诉评估与证据链闭合标准（案例B教训）⭐

反诉请求权基础走原告轨全流程自检；反诉 vs 另诉须比较（牵连性、费用、审级利益）。

**反诉证据链闭合标准**（案例B：反诉与本诉同属“事实归属不清”，反诉全驳+费用沉没 11.4 万）：反诉金额主张必须预先回答“事实归属 ↔ 金额”的对应证据链是否闭合（如：实际履行部分 ↔ 支出明细）。不闭合的——尤其“双方都无法区分”的事实状态，对本诉有利（对方举证不能）但对反诉同样致命（举证责任在反诉原告）——反诉应降级为**抗辩性抵销主张**（不缴反诉费）或另诉待证据补强；反诉费+鉴定费须计入预期值成本项（联动模块 10）。

**“事实真伪不明”双刃效应须同时评估对本诉与反诉两个方向**，禁止只算对本诉有利的一面。

## 五、原则 11 落地操作（争议权利不放弃）

1. **有依据但结果存争议的请求，照主张**（案例A教训：分包人优先受偿权预判不支持，仍应写入诉请）——本模块职责是预判结果+披露风险+供预期值台账使用，**不是替当事人放弃**；起诉状不按预测的判决结果起草；
2. **定性点不放**（案例D教训）：无直接金额的定性请求（如合同效力确认）若与对方武器库联动（效力定性是对方全部请求的根基），方案阶段即应识别为必争点，不得因“不产生金额”而放弃；
3. **留痕闭环**：风险写入“风险分级”节 → 当事人知情确认；任何放弃性决策**必须当事人书面/微信留痕**，否则一律主张。

## 六、方案落盘与联动

方案确认后：① 更新状态头；② **触发模块 10 首次预期值更新**（方案 vs 和解双账本）；③ 风险分级向当事人书面披露留痕。

## 双轨差异

| | 原告轨 | 被告轨 |
|---|--------|--------|
| 思维方向 | 正向构建：请求→基础→要件→主张 | 逆向拆解：否认→三类型抗辩→要件缺口 |
| 举证任务 | 请求权全部要件事实 | 仅抗辩权要件事实；对方要件只攻击 |
| 方案核心 | 请求组合+竞合选择+要件闭合 | 防线梯队+攻击点排序+反诉评估 |
| 独有检查 | 竞合四维、案由叙事、原则 11 漏项扫描 | 能否认不抗辩、反诉闭合标准、双刃效应 |
