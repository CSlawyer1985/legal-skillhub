# 律师接待笔录
[meta]时间：[接待日期]
[meta]地点：[接待地点]
[meta]接待律师：[律师姓名]
[meta]当事人：[当事人姓名]
[meta]接待内容：案件沟通
当事人就其与[被告姓名/名称]之间的[案由]一案向本所进行咨询，本所律师就有关事项制作本笔录。
[qa_gap]
律师：我是[律师事务所全称]的律师，请你把案件的基本情况向我介绍一下好吗？
[qa_gap]
当事人：[案件事实陈述]
[qa_gap]
律师：[法律风险提示]
当事人：我了解的。
[qa_gap]
律师：你应保证向我们所陈述的情况完全真实，否则，你将可能承担由此造成的不利后果。你是否清楚？
当事人：清楚的。
[qa_gap]
律师：根据你所陈述的情况，我们可以为你提供法律服务。在接受委托之前，我们要向你告知如下法律服务风险和法律服务要求：
一、律师不承担办案风险，律师不能承诺办案结果，也无法承诺办结案件的具体期限；
二、在胜诉的情况下，如对方当事人缺乏履行能力，你的合法利益可能难以实现；
三、律师只能依法维护你的合法权益，不能为你弄虚作假和提供伪证；
四、律师只能依法提供法律服务，不负责向办案人员请客送礼和行贿；
五、你本人应当积极举证，需要律师为你调查取证的，你应全力配合律师调查取证；
六、如果你隐瞒重要事实或委托的事项违法或者利用律师提供的服务从事违法活动，律师有权拒绝辩护或代理。
以上告知事项，你是否清楚？
当事人：清楚了。
[qa_gap]
律师：那你需要委托我们处理吗？
当事人：需要委托的。
[qa_gap]
律师：本笔录将作为我们签订的委托代理合同的附件，与其具有同等的效力。请核对以上谈话笔录，如果无误，请签字确认。
当事人：（当事人签名）
