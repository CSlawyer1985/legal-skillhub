# 庭审准备指引

## 一、庭审前准备清单

### 1.1 材料准备

| 材料 | 数量 | 备注 |
|:---|:---|:---|
| 辩护词 | 3份 | 法庭、公诉人、自己各1份 |
| 质证意见 | 3份 | 同上 |
| 发问提纲 | 2份 | 法庭、自己各1份 |
| 辩论提纲 | 2份 | 同上 |
| 证据材料 | 若干 | 按顺序编号 |
| 法律依据 | 1份 | 重点法条摘录 |
| 类案判决 | 若干 | 支持辩护观点的案例 |

### 1.2 物品准备

- [ ] 律师执业证
- [ ] 授权委托书
- [ ] 律师事务所函
- [ ] 笔记本电脑（如需多媒体示证）
- [ ] U盘（备份材料）
- [ ] 纸笔（记录）
- [ ] 计算器（金额计算）

### 1.3 心理准备

- 熟悉庭审流程
- 预判控方观点
- 准备应对突发情况
- 保持冷静、自信

## 二、庭审流程

### 2.1 开庭准备阶段

1. **书记员宣布**：请诉讼参与人入庭
2. **审判长宣布开庭**：查明被告人身份，宣布案由
3. **告知权利**：告知被告人诉讼权利
4. **询问是否申请回避**

### 2.2 法庭调查阶段

1. **公诉人宣读起诉书**
2. **被告人陈述**：对指控的意见
3. **辩护人发问**：向被告人发问
4. **公诉人举证**：出示证据
5. **辩护人质证**：对证据发表意见
6. **辩护人申请**：申请证人、鉴定人出庭
7. **法庭询问**：向被告人、证人发问

### 2.3 法庭辩论阶段

1. **公诉人发表公诉意见**
2. **辩护人发表辩护意见**（第一轮）
3. **被告人自行辩护**
4. **公诉人答辩**
5. **辩护人发表辩护意见**（第二轮）
6. **法庭辩论终结**

### 2.4 最后陈述阶段

1. **被告人最后陈述**
2. **法庭宣布休庭**（定期宣判）或**当庭宣判**

## 三、庭审中的辩护技巧

### 3.1 发问技巧

- **简洁明确**：一个问题只问一个事实
- **控制证人**：防止证人说出不利内容
- **灵活应变**：根据证人回答调整问题
- **记录要点**：记录证人回答的关键内容

### 3.2 质证技巧

- **抓住重点**：对关键证据重点质证
- **指出矛盾**：指出证据间的矛盾
- **引用法条**：质证时引用具体法条
- **简明扼要**：不要冗长，抓住要害

### 3.3 辩论技巧

- **观点明确**：先亮明观点，再展开论述
- **逻辑清晰**：层层递进，环环相扣
- **证据支撑**：每个观点都有证据支撑
- **语言规范**：使用法律术语，避免口语化

### 3.4 应对突发情况

| 突发情况 | 应对方法 |
|:---|:---|
| 法庭打断 | 简要回应，继续论述 |
| 控方突袭 | 请求法庭给予回应时间 |
| 新证据出现 | 申请质证时间 |
| 法官提问 | 直接回答，不绕弯子 |
| 被告人翻供 | 与被告人沟通，调整策略 |

## 四、庭审记录

### 4.1 记录内容

- 庭审时间、地点、审判人员
- 公诉人、辩护人、被告人
- 关键发问和回答
- 质证要点
- 辩论要点
- 法庭决定

```
地点：XXX人民法院第X审判庭

公诉人：XXX

被告人：XXX

   ...

   ...

   ...

   ...
```

## 五、庭后工作

### 5.1 及时整理

- 整理庭审记录
- 补充完善辩护词
- 准备补充材料（如需）

### 5.2 与被告人沟通

- 告知庭审情况
- 说明下一步安排
- 安抚情绪（如需要）

### 5.3 等待判决

- 关注判决时间
- 准备上诉材料（预判）
- 与家属沟通

## 六、常见错误

### 6.1 发问错误

- 问开放式问题
- 问不知道答案的问题
- 问复合型问题
- 与证人争论

### 6.2 质证错误

- 对所有证据都详细质证（时间不够）
- 质证时情绪化
- 质证没有重点
- 忘记引用法条

### 6.3 辩论错误

- 观点不明确
- 逻辑混乱
- 没有证据支撑
- 语言口语化
- 情绪化表达
