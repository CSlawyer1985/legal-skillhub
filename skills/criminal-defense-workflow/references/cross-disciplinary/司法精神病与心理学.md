# 司法精神病与心理学（跨专业知识）

## 一、司法精神病鉴定审查要点

### 1.1 规范依据

- 《刑法》第18条：精神病人刑事责任能力的基本规定
- 《刑事诉讼法》第146条：鉴定的启动（指派、聘请有专门知识的人进行鉴定）
- 《刑事诉讼法》第148条：鉴定意见的告知，补充鉴定、重新鉴定的申请
- 《刑事诉讼法》第149条：对犯罪嫌疑人作精神病鉴定的期间不计入办案期限
- 《刑事诉讼法》第192条：鉴定人出庭及拒不出庭的后果
- 《刑事诉讼法》第197条第2款：申请有专门知识的人出庭
- 《精神疾病司法鉴定暂行规定》
- 《精神障碍者刑事责任能力评定指南》
- 《司法鉴定程序通则》
- 《全国人民代表大会常务委员会关于司法鉴定管理问题的决定》

### 1.2 刑事责任能力的双重标准

刑事责任能力的判断必须同时满足两个标准，缺一不可：

| 标准 | 内容 | 判断依据 |
|:---|:---|:---|
| **医学标准** | 行为人是否患有精神障碍，以及精神障碍的种类与严重程度 | 通行精神障碍诊断分类（ICD-10／ICD-11、CCMD-3），结合病史与检查 |
| **法学标准** | 作案时的辨认能力与控制能力是否丧失或者削弱 | 作案动机、预谋、对象选择、逃避侦查等行为表现，结合医学判断 |

- 只成立医学标准而未分析法学标准，不能得出有无刑事责任能力的结论
- 间歇性精神障碍者，必须判断“作案当时”的精神状态，而非鉴定当时的状态
- 醉酒的人犯罪，应当负刑事责任（《刑法》第18条第4款）；“病理性醉酒”等实体争议需咨询司法精神病学专业人士

### 1.3 《刑法》第18条的三种情形

| 类型 | 条文要点 | 法律后果 |
|:---|:---|:---|
| **完全无刑事责任能力** | 在不能辨认或者不能控制自己行为的时候造成危害结果，经法定程序鉴定确认 | 不负刑事责任；责令其家属或者监护人严加看管和医疗，必要时由政府强制医疗 |
| **限制刑事责任能力** | 尚未完全丧失辨认或者控制自己行为能力 | 应当负刑事责任，但是可以从轻或者减轻处罚 |
| **间歇性精神病人在精神正常时犯罪** | 精神正常的时候犯罪 | 应当负刑事责任 |

### 1.4 鉴定程序审查清单

| 审查项目 | 审查内容 | 常见问题 |
|:---|:---|:---|
| **鉴定启动** | 是否由办案机关依法委托；辩护方提出鉴定申请后办案机关的处理 | 应启动而不启动；无理由驳回申请 |
| **鉴定人资质** | 是否具有法医精神病鉴定执业类别；人数、签名是否符合《司法鉴定程序通则》 | 超执业范围鉴定；鉴定人少于2人 |
| **鉴定材料** | 病史资料、讯问笔录、同监室人员证言、家属证言、作案前后表现材料是否全面、客观 | 只移送办案机关单方收集的材料，检材片面 |
| **鉴定时机** | 鉴定时间与作案时间的间隔；是否在治疗之后鉴定 | 间隔过长，精神状态已发生变化 |
| **鉴定文书** | 是否分别说明医学标准与法学标准的分析过程 | 以医学诊断直接代替责任能力结论 |
| **鉴定人出庭** | 对鉴定意见有异议时是否申请鉴定人出庭 | 经人民法院通知拒不出庭的，鉴定意见不得作为定案的根据（《刑事诉讼法》第192条） |

### 1.5 常见问题（质证靶点）

- 以医学诊断直接替代法学判断：鉴定书只给出疾病诊断，未分析作案时的辨认、控制能力
- 鉴定材料片面：仅依据讯问笔录和办案机关的说明，未收集病史、亲属证言、同监室人员证言
- 以鉴定时的精神状态倒推作案时的状态
- 鉴定意见与在案证据（预谋、踩点、毁灭证据、逃避抓捕等）存在矛盾而未作说明
- 鉴定人未签名、未附资质证明，或者鉴定事项超出登记范围

## 二、供述自愿性与讯问心理

### 2.1 非法讯问手段与供述自愿性

| 手段 | 心理机制 | 法律后果 |
|:---|:---|:---|
| **刑讯逼供（肉刑、变相肉刑）** | 为终止痛苦而供述，真实性让位于趋避 | 供述应当排除（《刑事诉讼法》第56条） |
| **威胁** | 以对本人或者近亲属的不利后果相要挟 | 依《严格排除非法证据规定》应当排除 |
| **非法限制人身自由** | 以剥夺自由形成强制 | 依《严格排除非法证据规定》应当排除 |
| **引诱、欺骗** | 以虚假利益或者虚假信息换取供述 | 影响供述自愿性与真实性，结合同步录音录像审查 |
| **重复性供述** | 受先前刑讯逼供行为影响而重复供述 | 依《严格排除非法证据规定》一并排除（法定例外情形除外） |

### 2.2 供述心理学常识

- 供述稳定性不等于真实性：反复训练、复制笔录同样可以形成“稳定”的供述
- 迎合型供述：为迎合讯问人员预期、争取从宽处理或者结束讯问而按暗示供述；认罪认罚从宽制度背景下尤其需要注意
- 记忆是重构而非回放：细节会在复述中被修改、填补，越晚的陈述未必越准确
- 虚假供述现象：无罪的人也可能因疲劳、压力、迎合而作出有罪供述，不能仅凭认罪定案
- 《刑事诉讼法》第55条：重证据，重调查研究，不轻信口供；只有被告人供述，没有其他证据的，不能认定被告人有罪和处以刑罚

### 2.3 讯问笔录审查的心理学视角

- 供述内容的细节是否超出当事人的认知能力、亲历范围
- 多次供述的措辞是否大段雷同：复制粘贴式笔录的典型表征
- 先供后证还是先证后供：供述中隐蔽性细节的来源是否可靠，有无讯问人员泄露的可能
- 翻供的时点与理由：是否在进入看守所、律师会见之后翻供，结合同步录音录像审查
- 讯问的时段与时长：深夜连续讯问形成的疲劳状态
- 笔录记载的表达方式与被告人的文化程度、表达能力是否匹配
- 笔录是如实记录原话，还是被讯问人员概括、改写

## 三、证人证言与辨认可靠性

### 3.1 目击证人记忆的心理学局限

| 现象 | 心理学原理 | 质证方向 |
|:---|:---|:---|
| **记忆衰减** | 记忆随时间快速遗忘 | 首次询问距案发的时间间隔 |
| **事后信息污染** | 案后与他人讨论、接触媒体报道会改写记忆 | 证人之间是否交流，是否接触媒体信息 |
| **武器聚焦效应** | 注意集中于武器，削弱对行为人面部的记忆 | 暴力犯罪案件中目击细节的可信度 |
| **跨种族辨认困难** | 对本族群面孔的辨认优于异族群 | 跨族群辨认的误差风险 |
| **应激与创伤** | 高度惊恐损害记忆编码 | 被害人惊恐状态下陈述的细节 |
| **暗示感受性** | 儿童等更易受提问方式影响 | 未成年证人、特殊证人的询问方式 |

### 3.2 询问中的暗示问题

- 诱导性提问会把信息“植入”证人陈述，证人此后可能把被暗示的内容当作自己的记忆
- 未成年证人、被害人：适用未成年人特别程序（《刑事诉讼法》第281条，通知法定代理人或者合适成年人到场等）
- 多次重复询问会强化错误记忆，并造成记忆来源混淆：证人分不清细节来自亲历还是来自提问
- 审查询问是否个别进行、有无同步录音录像、提问方式是否开放

### 3.3 辨认程序的心理学要求

| 要求 | 内容 | 违反后果 |
|:---|:---|:---|
| **辨认前隔离** | 辨认前不得使辨认人见到辨认对象 | 辨认笔录不得作为定案的根据 |
| **个别辨认** | 辨认活动个别进行，多名辨认人分别辨认 | 同上 |
| **混杂辨认** | 辨认对象混杂于具有类似特征的陪衬对象中；依《公安机关办理刑事案件程序规定》，辨认犯罪嫌疑人时被辨认人不得少于7人，辨认照片不得少于10张 | 同上 |
| **陪衬相似** | 陪衬对象与辨认对象在年龄、体貌等特征上相似 | 同上 |
| **不得暗示** | 不得给辨认人明显暗示或者明显有指认嫌疑 | 同上 |
| **规范主持** | 侦查人员依法主持，规范制作辨认笔录 | 不能补正或者作出合理解释的，不得作为定案的根据 |

### 3.4 证人证言的心理学质证角度清单

- 感知条件：距离、光线、遮挡、观察持续时间、证人视力与当时状态
- 注意状态：是否醉酒、恐惧，注意力是否集中于他物
- 陈述间隔：首次陈述距案发的时间
- 陈述变化：多次陈述中新增、改变细节的来源
- 信息来源：系亲历亲闻，还是转述他人
- 熟悉性偏差：亲友辨认既可能因熟悉而准确，也可能因偏见而“认出”
- 利害关系：证人与当事人、案件处理结果有无利害关系
- 记录方式：笔录是如实记录原话，还是被概括改写

## 四、红线与专家辅助人指引

### 4.1 三条红线

1. 本知识仅用于审查、质证、发问，不得据此直接否定或者替代司法精神病鉴定结论，不得对被告人的精神状态、证人的心理作实体判断
2. 涉及刑事责任能力等实体争议的，正确出口是程序手段：申请补充鉴定或者重新鉴定（《刑事诉讼法》第148条）、申请鉴定人出庭（第192条）、申请有专门知识的人出庭（第197条第2款）
3. 本文件未覆盖的专业问题，必须标注“需咨询司法精神病学、心理学专业人士”，严禁编造专业意见、诊断名称或者评定标准

### 4.2 专家辅助人出庭要点

| 事项 | 要点 |
|:---|:---|
| **法律依据** | 《刑事诉讼法》第197条第2款 |
| **申请主体** | 公诉人、当事人、辩护人、诉讼代理人 |
| **申请时机** | 庭前会议或者庭审中，宜书面申请并说明理由 |
| **人选** | 司法精神病学、心理学等领域具有专门知识的人 |
| **作用范围** | 就鉴定人作出的鉴定意见提出意见，不直接作出实体鉴定结论 |

### 4.3 申请重新鉴定的常见理由

- 鉴定机构、鉴定人不具备法定资质，或者超出执业范围
- 鉴定人应当回避而没有回避
- 鉴定程序违反规定：检材来源不明、鉴定人少于2人等
- 鉴定意见明显依据不足，或者与在案其他证据存在无法解释的矛盾
- 鉴定文书未分别论证医学标准与法学标准
- 出现新的病史材料、新的证人等足以影响鉴定结论的材料
