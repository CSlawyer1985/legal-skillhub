# 司法会计与财务（跨专业知识）

> 本文件供辩护人在办理经济犯罪、职务犯罪案件（合同诈骗、非法集资、职务侵占、挪用资金、贪污等）时调用。核心定位是帮助律师**审查、质证、发问**，发现审计报告和司法会计鉴定中的问题，**而非替代会计师作出实体专业结论**。

## 一、审查要点

### 1.1 鉴定机构与鉴定人资质

| 审查项目 | 审查内容 | 发现问题后的辩护方向 |
|:---|:---|:---|
| **司法鉴定许可** | 机构是否列入司法行政机关公告的司法鉴定机构名册，执业类别是否包含司法会计鉴定 | 无相应资质出具的“鉴定意见”，申请不作为鉴定意见采信 |
| **鉴定人执业证** | 鉴定人是否具有司法鉴定执业资格，执业范围是否匹配 | 超范围执业的，对鉴定资质提出异议 |
| **注册会计师资格** | 以会计师事务所名义出具的审计报告，签字人是否为注册会计师 | 非注册会计师签字的报告，质疑其专业意见效力 |
| **回避情形** | 鉴定人、鉴定机构与案件当事人有无利害关系，是否为侦查机关顾问单位 | 申请回避或质疑鉴定中立性 |
| **委托程序** | 鉴定由侦查机关、检察机关还是法院委托，委托事项是否明确 | 委托事项不明的，质疑鉴定范围失据 |

### 1.2 检材完整性与来源

| 审查项目 | 审查内容 |
|:---|:---|
| **检材清单** | 鉴定依据的账册、凭证、银行流水是否逐一列明，能否与案卷材料对应 |
| **检材来源** | 检材系侦查机关依法调取，还是由被害人、控告单位单方提供 |
| **质证情况** | 作为鉴定基础的财务资料是否经被告人一方核对、质证；未经质证的检材能否作为鉴定依据 |
| **完整性** | 账册凭证是否齐全，有无断档、缺页；银行流水是否覆盖全部涉案账户 |
| **电子数据** | 电子账套、财务软件数据的提取、固定程序是否合法，有无同步校验完整性 |

### 1.3 鉴定范围与意见边界

| 审查项目 | 审查内容 | 典型问题 |
|:---|:---|:---|
| **鉴定事项** | 鉴定意见是否限于“资金收付情况、金额核算”等会计事实问题 | 鉴定人越权作出法律判断 |
| **越权认定** | 鉴定意见是否直接认定“非法占有目的”“系诈骗所得”“构成挪用”等 | 属法律判断，应申请剔除或不予采信该部分 |
| **审计基准日** | 金额计算的截止时点、期间起止是否明确，与指控的犯罪时间是否对应 | 基准日与指控期间不匹配的，金额核算失据 |
| **签名盖章** | 是否有鉴定人本人签名、机构盖章，附页是否有鉴定人资质证明复印件 | 形式要件不全的，依法不得作为定案根据 |

> 依据《刑事诉讼法》及《最高人民法院关于适用〈中华人民共和国刑事诉讼法〉的解释》关于鉴定意见审查的规定，鉴定机构、鉴定人不具备法定资质，或者鉴定程序违反规定的，鉴定意见不得作为定案的根据。

### 1.4 辩方程序权利速查

| 程序权利 | 适用情形 | 操作要点 |
|:---|:---|:---|
| **申请鉴定人出庭** | 对鉴定意见有异议，且有必要当庭质证 | 书面申请并说明异议要点；经法院通知拒不出庭的，主张鉴定意见不得作为定案根据 |
| **申请重新鉴定** | 资质不符、程序违法、依据明显不足、检材虚假 | 列明具体理由并附线索，不宜仅以“不认可结论”为由 |
| **申请补充鉴定** | 遗漏事项、检材补充、计算错误可补正 | 指明需补充的具体事项，避免扩大为全面重做 |
| **申请专家辅助人出庭** | 需要专业人员就鉴定意见提出意见 | 依据《刑事诉讼法》第197条关于“有专门知识的人”出庭的规定提出申请 |
| **调取鉴定底稿** | 需要核对计算过程 | 申请法院调取鉴定工作底稿、计算明细、数据来源表 |

## 二、常见错误与造假模式

### 2.1 审计报告常见技术错误

| 错误类型 | 具体表现 | 审查方法 |
|:---|:---|:---|
| **重复计算** | 同一笔资金经多个账户周转被多次计入“涉案金额” | 绘制资金流向图，比对转账链条，剔除循环环节 |
| **本金利息混同** | 将利息、手续费、罚息计入本金或损失 | 逐笔区分本金与息费，核对合同约定利率 |
| **已归还款项未扣除** | 案发前已返还部分未从损失金额中扣减 | 收集还款凭证、收条、流水记录，逐笔对应扣减 |
| **往来款性质误判** | 将正常借款、代收代付、临时拆借认定为犯罪金额 | 调取借款合同、记账凭证、双方陈述佐证款项性质 |
| **现金交易遗漏** | 仅统计银行流水，遗漏现金交付部分 | 核对收条、证人证言、取款记录 |
| **关联方交易处理不当** | 关联公司之间资金往来应合并而未合并（虚增规模），或不应合并而合并（虚增金额） | 梳理关联关系图，逐笔判断往来性质 |
| **借贷方向颠倒** | 将被告人付款误记为收款 | 以银行流水方向为准逐笔复核 |
| **时间错位** | 将指控期间外的正常业务往来计入 | 按指控时间范围重新筛选 |

### 2.2 常见财务造假识别（用于反向审查指控证据，也用于识别控告方材料问题）

| 造假模式 | 识别特征 | 辩护运用 |
|:---|:---|:---|
| **虚增收入** | 无真实物流、发票流、资金流“三流”不一致 | 证明指控的“业务量”不实 |
| **账外资金循环** | 资金在体外账户循环走账，制造流水假象 | 揭示“交易规模”系人为制造 |
| **阴阳合同** | 同一交易存在两份金额不同的合同 | 质疑以哪份合同为核算基础 |
| **公款私存** | 单位资金存入个人账户，但用途仍为公务 | 区分“存放方式违规”与“非法占有” |
| **资金回流** | 资金转出后短期内又转回原单位或原账户 | 证明款项未被实际占有、控制 |
| **虚构交易背景** | 无真实货物或服务交付的合同、发票 | 核对物流单据、验收记录、仓储凭证 |

> 注意：识别控告方提交的财务材料造假，可直接动摇指控基础；识别被告人一方材料的造假风险，则用于评估辩护方案的可采性与执业风险，不得协助当事人制造、提交虚假材料。

## 三、资金流向分析与质证发问角度

### 3.1 资金流向分析方法

以银行流水为主轴，按“来源—去向—用途”三段梳理：

```
资金流向梳理模板

一、来源
   每笔入账：时间、金额、付款方、摘要、对应合同或事由

二、去向
   每笔出账：时间、金额、收款方、摘要、对应凭证

三、用途归类
   □ 经营支出（进货、工资、租金、税费、偿还经营债务）
   □ 还本付息（向出资人、借款人返还）
   □ 个人消费（购房、购车、奢侈品、赌博、赠与他人）
   □ 去向不明（大额取现、转给无关联第三方）
```

- 资金最终用途是经营支出还是个人挥霍，对“非法占有目的”的认定至关重要：大量资金用于维持经营、还本付息的，应当作为否定“非法占有目的”的重要辩点。
- 对“去向不明”款项，应核查是否存在侦查机关未追查的账户或取现用途，避免简单归入“挥霍”。

### 3.2 涉案金额核算辩护

基本公式：

> **损失金额 = 涉案总额 − 已归还金额 − 可抵扣项**

| 核算项目 | 核对要点 |
|:---|:---|
| **涉案总额** | 是否剔除重复计算、期间外往来、正常业务款项 |
| **已归还金额** | 案发前返还的本金、利息，以物抵债部分，有无凭证 |
| **可抵扣项** | 被告人一方已交付的货物、已提供的服务、被害人已取得的其他利益 |
| **逐笔核对** | 制作对照表：指控金额 → 对应凭证 → 异议理由 → 应核减金额 |

> 逐笔核对应形成书面《涉案金额核对异议表》，作为质证意见附件提交。具体数额的定罪量刑标准，以最新司法解释及当地标准为准。

### 3.3 庭审向鉴定人发问的问题示例

1. 你是何时、经哪个机关委托进行本次鉴定的？委托事项的具体表述是什么？
2. 鉴定所依据的全部财务资料有哪些？其中哪些系被害人或控告单位单方提供？这些资料是否经过被告人一方质证？
3. 你是否核对过原始凭证，还是仅依据侦查机关整理的汇总表、电子表格进行计算？
4. 银行流水覆盖了涉案主体的全部账户吗？你是否知悉被告人名下或关联公司还有其他账户未被纳入？
5. 对于同一笔资金在多个账户之间的周转，你采用了什么方法避免重复计算？
6. 案发前被告人已经归还的款项，在你的计算中是否予以扣除？依据什么材料认定“未归还”？
7. 你采用何种方法区分经营支出与个人消费？大额取现部分你是如何认定其用途的？
8. 鉴定意见中的金额计算截止到哪一天？审计基准日与起诉书指控的犯罪期间是否一致？
9. 鉴定意见中关于“具有非法占有目的”“系犯罪所得”的表述，是否属于会计专业事实问题？你作出该判断的依据是什么？
10. 对涉案往来款项的性质（借款、货款、投资款），你是依据什么资料作出判断的？是否听取过被告人一方的说明？
11. 鉴定报告所附的明细表与你当庭陈述的金额不一致的，以哪个为准？能否当庭说明差异原因？
12. 你的鉴定机构是否同时为侦查机关或控告方提供过其他财务顾问服务？

> 发问要领：先问资质与委托（程序），再问检材与方法（基础），再问具体计算（实体），最后问越权表述（边界）。每问一个问题，落脚到“鉴定意见能否作为定案根据”。

## 四、红线与专家辅助人指引

### 4.1 本知识的使用边界

- 本知识仅用于**审查、质证、发问**，帮助发现审计报告和司法会计鉴定中的问题。
- **不得**据此直接否定或替代专业鉴定结论；律师发现的问题应通过质证意见、发问、申请重新鉴定等法定程序表达，而非以律师名义作出会计专业判断。
- **不得**协助当事人隐匿、销毁、伪造账册凭证，或指使当事人作虚假说明。

### 4.2 应当寻求专业支持的情形

| 情形 | 应对方式 |
|:---|:---|
| 审计方法本身的科学性存在争议（如抽样方法、测算模型） | 申请专家辅助人出庭，依据《刑事诉讼法》第197条关于“有专门知识的人”出庭的规定 |
| 复杂会计准则适用问题（收入确认时点、合并范围、金融工具计量等） | 委托司法会计专业人士出具专业咨询意见，必要时申请重新鉴定 |
| 鉴定意见明显依据不足或程序严重违法 | 依据《刑事诉讼法》及相关司法解释申请重新鉴定或补充鉴定 |
| 需要独立核算涉案金额 | 建议聘请会计师事务所出具专项审计报告作为辩方证据 |

### 4.3 强制声明

- 本文件未覆盖的专业问题（具体准则适用、特殊行业会计处理、税务处理等），必须标注“**需咨询司法会计专业人士**”，严禁编造专业意见。
- 涉及具体数额标准、量刑档次的，一律以最新司法解释及当地标准为准，不得凭记忆引用具体数字。
