# 法医学（跨专业知识）

本文件供辩护人在办理暴力犯罪案件（故意伤害、故意杀人、寻衅滋事、聚众斗殴、过失致人死亡等）时调用。核心定位是帮助律师**审查、质证、发问**，发现伤情鉴定、死亡原因鉴定中的程序与实体疑点，而非替代法医作出专业结论。

## 一、鉴定意见审查要点

### 1.1 形式与程序审查清单

| 审查项目 | 审查内容 | 常见问题 |
|:---|:---|:---|
| **鉴定机构资质** | 是否经司法行政机关审核登记，是否具备法医临床鉴定、法医病理鉴定等相应业务范围 | 机构超业务范围受理鉴定 |
| **鉴定人资质** | 是否持有司法鉴定人执业证，执业类别是否涵盖委托鉴定事项 | 鉴定人已注销、转所或执业类别不符 |
| **委托事项与鉴定范围** | 鉴定意见是否超出委托事项（如委托伤情鉴定，意见却涉及责任划分、精神状态评价） | 超范围部分不具有证据能力 |
| **鉴定时机** | 伤情鉴定应在原发性损伤及并发症治疗终结或临床效果稳定后进行 | **过早鉴定是常见问题**：治疗未终结、功能未稳定即出具结论 |
| **检材** | 病历（急诊记录、住院志、手术记录、出院小结）是否完整；影像资料（X光、CT、MRI）是否为原始资料 | 仅凭复印件或报告单鉴定，原始影像缺失 |
| **签名与盖章** | 是否两名以上司法鉴定人签名，是否加盖司法鉴定专用章 | 单人签名、无专用章、鉴定人未实际参与 |
| **资质证明附件** | 鉴定文书是否附鉴定机构许可证、鉴定人执业证复印件 | 附件缺失，无法当庭核实资质 |

### 1.2 程序权利提示

- 侦查机关应当将用作证据的鉴定意见告知犯罪嫌疑人、被害人（《刑事诉讼法》第148条）
- 犯罪嫌疑人、被害人提出申请，可以补充鉴定或者重新鉴定（《刑事诉讼法》第148条）
- 辩护人应注意核对告知笔录，审查当事人是否在法定期限内知悉鉴定意见并提出异议

### 1.3 鉴定时机重点提示

- 以原发性损伤为主要鉴定依据的，伤后即可进行鉴定
- 以损伤所致的并发症为主要鉴定依据的，应在伤情稳定后进行鉴定
- 以容貌损害或者组织器官功能障碍为主要鉴定依据的，通常需在损伤九十日后进行鉴定
- **辩护意义**：鉴定时机过早可能导致等级偏高或偏低，是申请重新鉴定的常见理由

## 二、损伤程度与死亡鉴定的实体常识

### 2.1 损伤程度分级框架（《人体损伤程度鉴定标准》）

| 等级 | 概述 | 辩护意义 |
|:---|:---|:---|
| **重伤一级** | 严重危及生命；遗留肢体严重残废或者重度容貌毁损；严重丧失听觉、视觉或者其他重要器官功能 | 故意伤害罪最高量刑档次的伤情基础 |
| **重伤二级** | 危及生命；遗留肢体残废或者轻度容貌毁损；丧失听觉、视觉或者其他重要器官功能 | 重伤档次起点，对应《刑法》第234条第2款三年至十年档 |
| **轻伤一级** | 组织器官结构、功能中度损害或明显影响容貌 | 影响量刑轻重 |
| **轻伤二级** | 组织器官结构、功能轻度损害或影响容貌 | 故意伤害罪的入罪门槛（《刑法》第234条第1款） |
| **轻微伤** | 组织器官结构轻微损害或轻微功能障碍 | 不构成故意伤害罪，是出罪辩护与治安处罚界限的关键 |

- 等级直接决定定罪量刑档次：**等级之辩即档次之辩**
- 致人死亡或者以特别残忍手段致人重伤造成严重残疾的，处十年以上有期徒刑、无期徒刑或者死刑（《刑法》第234条第2款）

### 2.2 成伤机制分析常识

| 鉴别问题 | 一般常识 | 辩护意义 |
|:---|:---|:---|
| **损伤形态与致伤物对应** | 钝器伤多呈挫裂创、皮下出血、骨折；锐器伤创缘整齐（切创、砍创、刺创）；创口形态可推断致伤物种类 | 与指控凶器比对，无法对应时质疑作案工具认定 |
| **自己伤/他人伤** | 自己伤常表浅、排列整齐、方向一致、分布于本人手可及部位；他人伤常伴抵抗伤（前臂、手掌的防御性损伤） | 自伤诬告、互殴中各自身份的认定 |
| **生前伤/死后伤** | 生前伤有生活反应（出血、凝血、炎症反应、组织收缩）；死后伤无生活反应 | 区分打击次数、打击顺序与死亡结果的对应关系 |

### 2.3 死亡原因与死亡时间推断

- **常见死亡原因分类**：暴力性死亡（机械性损伤、机械性窒息、中毒、高低温、电击等）与非暴力性死亡（疾病、衰老等）
- **死因层次**：根本死因、直接死因、辅助死因、诱因应予区分；鉴定意见仅写直接死因而回避根本死因的，应重点追问
- **死亡方式**：他杀、自杀、意外的区分直接影响罪与非罪
- **死亡时间推断方法**：尸温、尸斑、尸僵、角膜混浊、胃内容物消化程度、腐败征象、嗜尸性昆虫发育等，均属区间估计

| 推断指标 | 一般特点 |
|:---|:---|
| **尸温** | 死亡后早期较常用，受环境温度、衣着、体型影响大 |
| **尸斑、尸僵** | 出现与消退时间个体差异大，仅作参考 |
| **胃内容物消化程度** | 可结合末次进餐时间推断，受个体差异影响 |
| **腐败征象、昆虫发育** | 用于死亡时间较长的推断，误差以天计 |

- **误差常识**：早期尸体现象推断误差通常以小时计，死亡时间越长误差越大
- **辩护意义**：推断的死亡时间区间若与指控作案时间不能闭合，直接影响不在场证明与因果关系的认定

### 2.4 伤病关系与损伤参与度

- 被害人自身疾病与外伤共同作用导致死亡或重伤时，鉴定应当分析损伤参与度
- 参与度表述惯例：完全作用、主要作用、同等作用、次要作用、轻微作用、无作用（或对应百分比区间）
- 可参考《人身损害与疾病因果关系判定指南》等司法鉴定技术规范
- **辩护意义**：参与度是因果关系辩护的关键——损伤仅起次要或轻微作用时，直接影响故意伤害致人死亡的认定与量刑；鉴定意见未作参与度分析的，是重要质证突破口

## 三、质证与庭审发问角度

### 3.1 质证角度清单

| 质证角度 | 具体表现 | 质证方向 |
|:---|:---|:---|
| **鉴定时机不当** | 治疗未终结、伤情未稳定即出具结论 | 结论不可靠，申请补充鉴定或重新鉴定 |
| **病历来源不完整** | 缺少急诊初诊记录、手术记录；复印件未经核对 | 检材真实性、完整性存疑 |
| **影像资料未经质证** | 鉴定依据的CT、MRI未当庭出示质证 | 鉴定依据未经查证属实，不得作为定案根据 |
| **鉴定标准适用错误** | 引用条款与损伤部位、类型不符；适用已废止标准 | 逐条比对《人体损伤程度鉴定标准》原文 |
| **伤病关系未分析参与度** | 被害人患有严重疾病而鉴定未加区分 | 因果关系认定依据不足，申请重新鉴定 |
| **超范围鉴定** | 意见超出委托事项 | 超范围部分无证据能力 |
| **鉴定人未出庭** | 对鉴定意见有异议，经法院通知鉴定人拒不出庭 | 鉴定意见不得作为定案的根据（《刑事诉讼法》第192条） |
| **形式瑕疵** | 单人签名、无资质附件、无司法鉴定专用章 | 程序违法，证明力受限 |

### 3.2 庭审向鉴定人发问示例

1. 鉴定时被害人的治疗是否已经终结？临床效果是否已经稳定？判断依据是什么？
2. 你作出鉴定依据的病历是否完整？是否包括急诊初诊记录和手术记录？你所见的是原件还是复印件？
3. 鉴定所依据的影像资料是原始片还是报告单？你是否亲自阅片？
4. 你是否对被害人进行了活体检查？检查距受伤间隔多长时间？检查时伤痕是否已愈合？
5. 你引用《人体损伤程度鉴定标准》的具体条款是什么？该条款要求的测量数据或功能障碍标准是什么？你的测量方法和结果各是什么？
6. 你是否分析了被害人自身疾病对死亡结果（或损伤后果）的参与度？如未分析，原因是什么？
7. 死者身上的损伤能否区分生前伤与死后伤？你认定生活反应的具体依据是什么？
8. 创口形态与你推断的致伤物之间有哪些对应特征？能否排除其他种类的致伤物？
9. 死亡时间是如何推断的？采用了哪些指标？该方法的误差范围是多少？推断区间是否包含指控的作案时间？
10. 本案损伤的形成机制是什么？是否符合自己伤的特征？是否发现抵抗伤？
11. 你的结论与初次鉴定结论不一致的，差异原因是什么？
12. 你和参与鉴定的其他鉴定人的执业类别是否涵盖本案委托的鉴定事项？

### 3.3 与辩护论证的结合

| 辩护目标 | 运用方法 |
|:---|:---|
| **因果关系中断或减弱** | 以伤病参与度分析论证损伤仅起次要、轻微作用，动摇故意伤害致人死亡的认定 |
| **正当防卫与防卫过当** | 双方伤情对照：申请固定被告人伤情，以伤情轻重与行为强度的对照论证防卫必要性（《刑法》第20条） |
| **量刑档次降档** | 通过重新鉴定争取重伤降轻伤、轻伤一级降轻伤二级，直接降低量刑档次 |
| **不在场与作案时间** | 以死亡时间推断误差论证指控作案时间不在推断区间内，无法排除合理怀疑 |
| **罪与非罪** | 轻微伤结论直接否定故意伤害罪的成立（《刑法》第234条） |

## 四、红线与专家辅助人指引

### 4.1 红线

- 本知识仅用于审查、质证、发问，**不得据此直接否定或替代法医学鉴定结论**
- 不得向当事人作出“肯定构不成轻伤”“肯定是病死”等实体承诺
- 本文件未覆盖的专业问题，必须标注“需咨询法医学专业人士”，严禁编造专业意见、数据或标准条款
- 引用《人体损伤程度鉴定标准》具体条款前，必须核对现行有效文本

### 4.2 专家辅助人与重新鉴定

- 涉及**伤情等级实体判断、成伤机制争议、死亡原因争议、伤病参与度争议**的，应建议申请重新鉴定，或申请专家辅助人出庭
- 法律依据：《刑事诉讼法》第197条——公诉人、当事人和辩护人、诉讼代理人可以申请法庭通知有专门知识的人出庭，就鉴定人作出的鉴定意见提出意见
- 专家辅助人意见的落点：鉴定时机、检材完整性、标准适用、参与度分析等，可作为申请重新鉴定的理由或质证意见的支撑
- 补充鉴定、重新鉴定的申请权见《刑事诉讼法》第148条；重新鉴定的受理情形与程序见《司法鉴定程序通则》
