# 阅卷分析指引

## 一、阅卷目标

全面掌握案件事实与证据状况，建立案件信息全景图，为后续质证和辩护奠定基础。

## 二、材料读取与预处理

1. **读取工具**：优先使用 `pdf-reader` 读取 PDF 案卷，使用 `docx-reader` 读取 Word 材料；图片材料可先用 OCR 工具提取文字。
2. **建立索引**：材料较多时，先建立《卷宗目录索引表》，记录每卷/每份材料的编号、名称、页数、关键内容摘要。
3. **分工处理**：超过 500 页的大型案卷按卷分工并行阅卷（供述卷、证言卷、书证卷、鉴定勘验卷分别提取，矛盾比对由掌握全局的单一视角集中完成），每批完成后更新索引和要点摘要，避免遗漏；全部摘录落盘至 `02_工作底稿/`。
4. **出处标注**：所有摘录必须标注出处，格式为“卷X第X页”或“证据编号X”。
5. **缺省处理**：若用户未上传完整材料，应在报告中明确标注“待补充材料清单”。

## 三、阅卷顺序与方法

### 3.1 阅卷顺序

严格按照以下顺序阅读案卷材料：

1. **诉讼文书卷**：立案决定书、强制措施文书、起诉意见书/起诉书 → 了解指控全貌
2. **供述与辩解卷**：全部讯问笔录、亲笔供词 → 掌握被告人陈述的变化
3. **证人证言卷**：被害人陈述、证人证言 → 了解指控证据
4. **书证物证卷**：合同、账册、凭证、物证照片 → 核实客观证据
5. **鉴定与勘验卷**：鉴定意见、勘验笔录、检查笔录 → 审查专业意见
6. **程序卷**：搜查、扣押、冻结文书 → 审查取证合法性

### 3.2 阅卷方法

**三遍阅卷法**：

- **第一遍（通览）**：快速浏览全部材料，建立案件整体印象，标注疑点
- **第二遍（细读）**：逐份精读，提取关键信息填入《阅卷摘录表》
- **第三遍（比对）**：横向比对证据间矛盾，纵向梳理时间线冲突

### 4.2 指控事实要素提取

对起诉书指控的每一项犯罪事实，提取以下要素：

1. **时间要素**：具体日期、时间段、持续时间
2. **地点要素**：具体地点、场所
3. **人物要素**：行为人、被害人、证人、关系人
4. **手段要素**：行为方式、方法、工具
5. **金额/数量要素**：涉案金额、损失数额、物品数量
6. **主观要素**：主观故意、明知、目的
7. **结果要素**：危害后果、社会影响

## 五、时间轴整理方法

### 5.1 建立多轨时间轴

```
日期         案件事实              取证活动              程序节点
YYYY-MM-DD   [事实描述]            [取证活动]            [程序事项]
```

### 5.2 标注关键节点

- 用 **【矛盾】** 标注矛盾时间点（供述时间冲突、转账时间异常等）
- 用 **【违规】** 标注程序违规时间点（先取证后立案、超期羁押等）
- 用 **【有利】** 标注对被告人有利时间点

## 六、矛盾点识别方法

### 6.1 证据间矛盾

- 被告人供述 vs 证人证言：内容冲突之处
- 被告人供述（前次）vs 被告人供述（后次）：翻供或变化之处
- 证人证言 vs 证人证言：不同证人之间的矛盾
- 言词证据 vs 客观证据：陈述与书证/物证的矛盾

### 6.2 金额/数量矛盾

- 不同证据对同一金额的表述是否一致
- 计算过程是否正确（特别关注审计报告）
- 币种、汇率、计价方式是否统一

### 6.3 程序性矛盾

- 取证时间是否在立案之后（是否存在先取证后立案）
- 搜查是否有搜查证
- 扣押清单是否有见证人签名
- 辨认程序是否符合规定
- 讯问是否超过法定时限（单次讯问不得超过24小时，连续传唤间隔不少于12小时）
- 是否存在应当同步录音录像而未录像的情形
- 首次讯问是否告知了诉讼权利

### 6.4 辩护突破口发现（策略导向，必选）

在提取信息的同时，实时评估每个信息点的辩护价值：

| 突破口类型 | 识别标准 | 示例 |
|------------|----------|------|
| **非法证据排除** | 取证程序严重违法，可能严重影响司法公正 | 无搜查证搜查、刑讯逼供取得供述 |
| **核心事实推翻** | 控方认定的事实缺乏证据支撑或存在反证 | 审计报告显示资金用于经营而非个人消费 |
| **主观故意否定** | 被告人主观上不具备犯罪故意 | 张某始终想完成项目，有前期履约行为 |
| **法定从宽情节** | 法律明文规定的从轻、减轻或免除情节 | 自首、立功、从犯、未遂 |
| **金额/数量降档** | 降低涉案金额至更低量刑档次 | 审计金额低于指控金额，可能影响数额认定 |
| **证据链断裂** | 关键证据缺失或无法形成完整链条 | 仅有被害人陈述，无其他证据印证 |

**要求**：在阅卷过程中，对发现的每个突破口标注在对应证据旁边，并在初步分析意见中汇总。

## 七、阅卷报告撰写模板

### 7.1 报告结构

```
阅卷分析报告

一、案件基本信息
   [填写案件基本信息表]

二、指控事实梳理
   按指控罪名列举，逐项梳理事实要素

三、证据清单总表
   按证据类型分类列表

四、案件时间轴
   多轨时间轴展示

五、关键矛盾与疑点
   5.1 证据间矛盾
   5.2 金额/数量疑点
   5.3 程序瑕疵

六、待核实问题清单
   列出需进一步调查核实的问题

七、初步分析意见
   7.1 控方有利点
   7.2 控方薄弱点
   7.3 辩护切入点建议
   7.4 法律依据初步检索
   7.5 辩护策略初步建议
   7.6 量刑初步评估
```

### 7.2 初步分析意见撰写要求

**7.3 辩护切入点建议**：
- 每个切入点须具备"事实依据 + 法律逻辑 + 预期效果"三要素
- 按重要性排序，最重要的切入点放在首位
- 切入点之间应形成互补体系，而非孤立论点

**7.4 法律依据初步检索**（必选）：
- 列出本案涉及的罪名条文（如《刑法》第224条合同诈骗罪）
- 列出相关司法解释（如最高法关于合同诈骗的认定标准）
- 列出有利于被告人的程序法条文（如自首、立功相关规定）
- 法律依据引用格式：`《XXX法》第XX条`

**7.5 辩护策略初步建议**（必选）：
- 提出明确的辩护方向选择（无罪辩护 / 罪轻辩护 / 复合策略）
- 说明策略选择的事实和法律依据
- 预判控方可能的反驳及应对方案

**7.6 量刑初步评估**（必选）：
- 法定刑幅度分析
- 各项从重/从轻/减轻情节及其预估减刑幅度
- 综合量刑区间预测

示例：
> **量刑评估**：合同诈骗罪，数额巨大（或特别巨大），法定刑为三年以上十年以下有期徒刑（或十年以上），并处罚金。本案存在以下从宽情节：①自首（电话通知到案，可减少基准刑20%-30%）；②无前科劣迹（可减少10%）；③资金用于经营而非个人挥霍（可酌情减少10%-15%）；④可能退赃（可减少20%）。预估综合量刑区间：有期徒刑三年至四年。

### 7.3 撰写规范

- 客观中立：如实记录，不加入主观评价
- 条理清晰：分类明确，编号统一
- 标注出处：每项信息注明案卷页码
- 突出疑点：用醒目的方式标注发现的矛盾和问题
