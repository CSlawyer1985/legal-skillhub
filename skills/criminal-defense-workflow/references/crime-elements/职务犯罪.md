# 职务犯罪要件库

## 一、滥用职权罪（《刑法》第397条）

### 1.1 构成要件

| 要件 | 内容 | 辩护要点 |
|:---|:---|:---|
| **客体** | 国家机关的正常管理活动 | 是否侵害国家机关管理活动 |
| **客观方面** | 滥用职权，致使公共财产、国家和人民利益遭受重大损失 | 是否滥用职权；是否造成重大损失 |
| **主体** | 国家机关工作人员 | 主体身份认定 |
| **主观方面** | 故意（包括直接故意和间接故意） | 主观心态认定 |

### 1.2 量刑标准

| 情节 | 量刑幅度 |
|:---|:---|
| 致使公共财产、国家和人民利益遭受重大损失 | 3年以下有期徒刑或拘役 |
| 情节特别严重 | 3年以上7年以下有期徒刑 |
| 徇私舞弊 | 5年以下有期徒刑或拘役 |
| 徇私舞弊，情节特别严重 | 5年以上10年以下有期徒刑 |

### 1.3 "重大损失"认定标准

| 情形 | 标准 |
|:---|:---|
| 造成死亡 | 1人以上 |
| 造成重伤 | 3人以上 |
| 造成轻伤 | 9人以上 |
| 造成经济损失 | 30万元以上 |
| 造成恶劣社会影响 | 严重损害国家声誉等 |

## 二、玩忽职守罪（《刑法》第397条）

### 2.1 构成要件

| 要件 | 内容 | 辩护要点 |
|:---|:---|:---|
| **客体** | 国家机关的正常管理活动 | 是否侵害国家机关管理活动 |
| **客观方面** | 严重不负责任，不履行或不认真履行职责，致使公共财产、国家和人民利益遭受重大损失 | 是否严重不负责任；是否造成重大损失 |
| **主体** | 国家机关工作人员 | 主体身份认定 |
| **主观方面** | 过失 | 主观心态认定（与滥用职权罪区分） |

### 2.2 与滥用职权罪的区分

| 区分点 | 滥用职权罪 | 玩忽职守罪 |
|:---|:---|:---|
| **主观方面** | 故意 | 过失 |
| **行为方式** | 积极作为（越权、滥权） | 消极不作为（不履行、不认真履行） |
| **认识因素** | 明知自己的行为会侵害国家机关管理活动 | 应当预见自己的行为可能造成危害结果 |

---

## 三、徇私枉法罪（《刑法》第399条第1款）

### 3.1 构成要件

| 要件 | 内容 | 辩护要点 |
|:---|:---|:---|
| **客体** | 国家司法机关的正常活动和司法公正 | 是否侵害司法公正 |
| **客观方面** | 在刑事诉讼中徇私、徇情枉法，对明知是无罪的人而使他受追诉，或对明知是有罪的人而故意包庇不使他受追诉，或在刑事审判活动中故意违背事实和法律作枉法裁判 | 是否徇私徇情；是否枉法 |
| **主体** | 司法工作人员 | 主体身份认定 |
| **主观方面** | 直接故意 | 是否具有枉法故意 |

### 3.2 量刑标准

| 情节 | 量刑幅度 |
|:---|:---|
| 一般情节 | 5年以下有期徒刑或拘役 |
| 情节严重 | 5年以上10年以下有期徒刑 |
| 情节特别严重 | 10年以上有期徒刑 |

---

## 四、民事、行政枉法裁判罪（《刑法》第399条第2款）

### 4.1 构成要件

| 要件 | 内容 | 辩护要点 |
|:---|:---|:---|
| **客体** | 国家司法机关的正常活动和司法公正 | 是否侵害司法公正 |
| **客观方面** | 在民事、行政审判活动中故意违背事实和法律作枉法裁判，情节严重 | 是否违背事实和法律；是否情节严重 |
| **主体** | 司法工作人员 | 主体身份认定 |
| **主观方面** | 直接故意 | 是否具有枉法故意 |

### 4.2 "情节严重"认定

| 情形 | 说明 |
|:---|:---|
| 枉法裁判，致使当事人或近亲属自杀、自残造成重伤、死亡或精神失常 | |
| 枉法裁判，造成个人财产直接经济损失10万元以上，或直接经济损失不满10万元但间接经济损失50万元以上 | |
| 枉法裁判，造成法人或其他组织财产直接经济损失20万元以上，或直接经济损失不满20万元但间接经济损失100万元以上 | |
| 伪造、变造有关材料、证据，制造假案枉法裁判 | |
| 串通当事人制造伪证，毁灭证据或篡改庭审笔录而枉法裁判 | |

## 五、执行判决、裁定失职罪（《刑法》第399条第3款）

### 5.1 构成要件

| 要件 | 内容 | 辩护要点 |
|:---|:---|:---|
| **客体** | 国家司法机关的正常活动和司法权威 | 是否侵害司法权威 |
| **客观方面** | 在执行判决、裁定活动中，严重不负责任或滥用职权，不依法采取诉讼保全措施、不履行法定执行职责，或违法采取诉讼保全措施、强制执行措施，致使当事人或其他人利益遭受重大损失 | 是否严重不负责任；是否造成重大损失 |
| **主体** | 司法工作人员 | 主体身份认定 |
| **主观方面** | 过失或故意 | 主观心态认定 |

---

## 六、私放在押人员罪（《刑法》第400条第1款）

### 6.1 构成要件

| 要件 | 内容 | 辩护要点 |
|:---|:---|:---|
| **客体** | 国家监管机关的正常活动和监管秩序 | 是否侵害监管秩序 |
| **客观方面** | 利用职务上的便利，私自将在押的犯罪嫌疑人、被告人或罪犯放走，使其逃离监管 | 是否利用职务便利；是否私自放走 |
| **主体** | 司法工作人员 | 主体身份认定 |
| **主观方面** | 直接故意 | 是否具有放走故意 |

---

## 七、失职致使在押人员脱逃罪（《刑法》第400条第2款）

### 7.1 构成要件

| 要件 | 内容 | 辩护要点 |
|:---|:---|:---|
| **客体** | 国家监管机关的正常活动和监管秩序 | 是否侵害监管秩序 |
| **客观方面** | 由于严重不负责任，致使在押的犯罪嫌疑人、被告人或罪犯脱逃，造成严重后果 | 是否严重不负责任；是否造成严重后果 |
| **主体** | 司法工作人员 | 主体身份认定 |
| **主观方面** | 过失 | 主观心态认定 |

### 7.2 与私放在押人员罪的区分

| 区分点 | 私放在押人员罪 | 失职致使在押人员脱逃罪 |
|:---|:---|:---|
| **主观方面** | 直接故意 | 过失 |
| **行为方式** | 积极主动放走 | 消极失职导致脱逃 |

---

## 八、徇私舞弊减刑、假释、暂予监外执行罪（《刑法》第401条）

### 8.1 构成要件

| 要件 | 内容 | 辩护要点 |
|:---|:---|:---|
| **客体** | 国家监管机关的正常活动和司法公正 | 是否侵害司法公正 |
| **客观方面** | 司法工作人员徇私舞弊，对不符合减刑、假释、暂予监外执行条件的罪犯，予以减刑、假释或暂予监外执行 | 是否徇私舞弊；是否符合条件 |
| **主体** | 司法工作人员 | 主体身份认定 |
| **主观方面** | 直接故意 | 是否具有徇私舞弊故意 |

---

## 九、国家机关工作人员签订、履行合同失职被骗罪（《刑法》第406条）

### 9.1 构成要件

| 要件 | 内容 | 辩护要点 |
|:---|:---|:---|
| **客体** | 国家机关的正常管理活动和国家利益 | 是否侵害国家利益 |
| **客观方面** | 国家机关工作人员在签订、履行合同过程中，因严重不负责任被诈骗，致使国家利益遭受重大损失 | 是否严重不负责任；是否被诈骗；是否造成重大损失 |
| **主体** | 国家机关工作人员 | 主体身份认定 |
| **主观方面** | 过失 | 主观心态认定 |

## 十、常见职务犯罪对比

| 罪名 | 主体 | 行为方式 | 主观方面 | 关键区分点 |
|:---|:---|:---|:---|:---|
| 滥用职权罪 | 国家机关工作人员 | 滥用职权 | 故意 | 积极越权、滥权 |
| 玩忽职守罪 | 国家机关工作人员 | 严重不负责任 | 过失 | 消极不作为 |
| 徇私枉法罪 | 司法工作人员 | 徇私徇情枉法 | 直接故意 | 刑事诉讼中枉法 |
| 民事、行政枉法裁判罪 | 司法工作人员 | 违背事实和法律裁判 | 直接故意 | 民事、行政审判中枉法 |
| 私放在押人员罪 | 司法工作人员 | 私放在押人员 | 直接故意 | 积极主动放走 |
| 失职致使在押人员脱逃罪 | 司法工作人员 | 严重不负责任 | 过失 | 消极失职导致脱逃 |
