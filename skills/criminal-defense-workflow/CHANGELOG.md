## v3.0.0 (2026-06-03)

**重大重构：从单文件架构升级为模块化子技能架构**

### 架构变更
- 从 1 个 SKILL.md + 3 个 references 重构为 13 个子技能模块
- 新增 `sub-skills/` 目录，每个子技能独立成文
- 新增 `_skillhub_meta.json` 元数据文件
- 新增 `CHANGELOG.md` 版本记录

### 新增子技能模块
- **01 案件接收与初步评估**：建立案件档案，评估辩护空间
- **02 会见当事人与笔录整理**：会见准备、笔录规范、信息提取
- **03 强制措施变更申请**：取保候审、监视居住申请
- **04 阅卷分析与案件全景图**：系统化阅卷，建立案件全景图
- **05 证据分析与质证意见**：三性质证，证据链分析
- **06 庭前会议准备**：管辖异议、回避、证人出庭、非法证据排除申请
- **07 庭审发问提纲**：向被告人、证人、鉴定人发问
- **08 庭审辩论提纲**：构建辩论体系，反驳控方
- **09 辩护词撰写**：基于阅卷和质证撰写辩护词
- **10 量刑辩护专项**：量刑情节识别、量刑计算
- **11 上诉状撰写**：一审判决后的上诉
- **12 申诉与再审申请**：判决生效后的救济
- **13 案件归档与复盘**：卷宗归档、经验总结

### 新增参考资料
- `references/procedural-defense/illegal-evidence-exclusion.md`：非法证据排除规则
- `references/trial-preparation-guide.md`：庭审准备指引
- `references/crime-elements/经济犯罪.md`：经济犯罪要件库
- `references/crime-elements/职务犯罪.md`：职务犯罪要件库

### 新增机制
- **执行前强制检查（死刑条款）**：每个子技能必须执行的 Step 0
- **文件命名与归档规范**：统一的文件夹结构和命名规则
- **模块路由规则**：用户输入与技能文件的匹配表
- **自检清单**：每个子技能末尾的完整检查清单

### 完善内容
- 证据分析：新增审计报告/司法会计鉴定质证要点
- 电子数据：扩充质证要点，增加远程勘验、区块链存证等
- 量刑辩护：增加量刑计算方法、缓刑适用、认罪认罚从宽
- 程序辩护：增加管辖异议、回避申请、证人出庭等
