# 06 庭前会议准备

## Step 0：执行前强制检查

1. **⚠️ 加载本 skill**：确认已读取本文件
2. **检查偏好**：读取 `办案记录.md`
3. **确认角色**：确认我方为辩护人
4. **确认阶段**：确认案件处于审判阶段

## 一、任务目标

充分准备庭前会议，就程序性事项和证据问题与控方、法庭沟通，为庭审奠定基础。

## 二、庭前会议内容（《刑事诉讼法》第187条、最高法解释第226-230条）

### 2.1 管辖问题

- **级别管辖**：案件是否应由当前法院审理？
- **地域管辖**：犯罪地、被告人居住地是否正确？
- **指定管辖**：是否存在管辖争议需要上级指定？

### 2.2 回避问题

- 审判人员、检察人员、侦查人员是否应当回避？
- 是否存在利害关系或其他可能影响公正处理的情形？

### 2.3 出庭人员名单

- 申请证人出庭作证
- 申请鉴定人出庭
- 申请有专门知识的人出庭（专家辅助人）
- 申请侦查人员出庭说明情况

### 2.4 非法证据排除

- 明确提出排除非法证据的申请
- 提供相关线索或材料
- 申请法庭调查取证

### 2.5 举证质证方式

- 确定证据展示顺序
- 确定质证方式
- 确定是否需要多媒体示证

### 2.6 庭审重点

- 确定控辩双方争议焦点
- 确定法庭调查重点
- 确定是否需要庭前会议报告

## 四、庭前会议策略

### 4.1 程序性辩护策略

| 策略 | 适用情形 | 预期效果 |
|:---|:---|:---|
| 管辖异议 | 管辖明显错误 | 移送管辖，争取有利法院 |
| 回避申请 | 审判人员有利害关系 | 更换审判人员 |
| 非法证据排除 | 存在刑讯逼供等 | 排除关键证据 |
| 证人出庭 | 书面证言矛盾或不充分 | 当庭质证，揭示真相 |
| 鉴定人出庭 | 鉴定意见存疑 | 质疑鉴定意见 |
| 专家辅助人 | 需要专业意见 | 补强辩护观点 |

### 4.2 庭前会议发言要点

1. **简明扼要**：庭前会议时间有限，抓住重点
2. **有理有据**：每项申请都要有法律依据和事实基础
3. **留有余地**：不要一次性抛出所有底牌
4. **记录完整**：详细记录法庭和对方的回应
