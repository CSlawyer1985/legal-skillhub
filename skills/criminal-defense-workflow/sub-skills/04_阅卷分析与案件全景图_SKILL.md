# 04 阅卷分析与案件全景图

## Step 0：执行前强制检查

1. **⚠️ 加载本 skill**：确认已读取本文件
2. **检查偏好**：读取 `办案记录.md`
3. **确认角色**：确认我方为辩护人
4. **确认阶段**：确认案件所处阶段（审查起诉/审判）

## 一、任务目标

全面掌握案件事实与证据状况，建立案件信息全景图，为后续质证和辩护奠定基础。

## 二、阅卷前准备

### 2.1 材料整理

- 确认已收到全部案卷材料
- 按卷宗顺序编号
- 建立案卷目录索引

### 2.2 工具准备

- 阅卷摘录表模板
- 时间轴记录表
- 矛盾点标注表
- 法律依据速查表

### 2.3 专业证据识别与知识加载

阅卷前根据案由和起诉书识别案件涉及的专业领域，**强制加载**对应跨专业知识文件（见 SKILL.md 6.4）：

| 案件特征 | 加载文件 |
|:---|:---|
| 有审计报告、司法会计鉴定、涉案金额争议 | `references/cross-disciplinary/司法会计与财务.md` |
| 有伤情鉴定、死亡原因鉴定 | `references/cross-disciplinary/法医学.md` |
| 有刑事责任能力鉴定、供述自愿性争议、目击辨认 | `references/cross-disciplinary/司法精神病与心理学.md` |

识别结果记入 `办案记录.md` 状态头的「涉及专业领域」。

### 2.4 大型案卷分工阅卷

- **提取并行化**：案卷量大（约 500 页以上）时，可按卷分工——供述卷、证言卷、书证卷、鉴定勘验卷分别阅卷，各自按统一模板输出结构化摘录
- **比对集中化**：矛盾点识别（供述 vs 证言、言词证据 vs 客观证据）必须由掌握全局的单一视角完成，不得拆分
- 全部中间产物（摘录表、时间轴、矛盾清单）**落盘至 `02_工作底稿/`**，后续阶段从文件调取，不依赖对话记忆

## 三、阅卷顺序与方法

### 3.1 阅卷顺序

严格按照以下顺序阅读：

1. **诉讼文书卷**：立案决定书、强制措施文书、起诉意见书/起诉书
2. **供述与辩解卷**：全部讯问笔录、亲笔供词
3. **证人证言卷**：被害人陈述、证人证言
4. **书证物证卷**：合同、账册、凭证、物证照片
5. **鉴定与勘验卷**：鉴定意见、勘验笔录、检查笔录
6. **程序卷**：搜查、扣押、冻结文书

### 3.2 三遍阅卷法

- **第一遍（通览）**：快速浏览全部材料，建立案件整体印象，标注疑点
- **第二遍（细读）**：逐份精读，提取关键信息填入《阅卷摘录表》
- **第三遍（比对）**：横向比对证据间矛盾，纵向梳理时间线冲突

## 五、时间轴整理

### 5.1 建立多轨时间轴

```
日期         案件事实              取证活动              程序节点
YYYY-MM-DD   [事实描述]            [取证活动]            [程序事项]
```

### 5.2 标注关键节点

- **【矛盾】**：矛盾时间点（供述时间冲突、转账时间异常等）
- **【违规】**：程序违规时间点（先取证后立案、超期羁押等）
- **【有利】**：对被告人有利时间点

## 六、矛盾点识别

### 6.1 证据间矛盾

- 被告人供述 vs 证人证言
- 被告人供述（前次）vs 被告人供述（后次）
- 证人证言 vs 证人证言
- 言词证据 vs 客观证据

### 6.2 金额/数量矛盾

- 不同证据对同一金额的表述是否一致
- 计算过程是否正确（特别关注审计报告）
- 币种、汇率、计价方式是否统一

### 6.3 程序性矛盾

- 取证时间是否在立案之后
- 搜查是否有搜查证
- 扣押清单是否有见证人签名
- 辨认程序是否符合规定
- 讯问是否超过法定时限
- 是否应当同步录音录像而未录像
- 首次讯问是否告知了诉讼权利

## 七、辩护突破口发现

在提取信息的同时，实时评估每个信息点的辩护价值：

| 突破口类型 | 识别标准 | 示例 |
|:---|:---|:---|
| **非法证据排除** | 取证程序严重违法 | 无搜查证搜查、刑讯逼供 |
| **核心事实推翻** | 控方事实缺乏证据支撑 | 审计报告显示资金用于经营 |
| **主观故意否定** | 不具备犯罪故意 | 有前期履约行为 |
| **法定从宽情节** | 法律明文规定 | 自首、立功、从犯 |
| **金额/数量降档** | 降低至更低量刑档次 | 审计金额低于指控金额 |
| **证据链断裂** | 关键证据缺失 | 仅有被害人陈述 |

## 八、阅卷报告撰写

### 8.1 报告结构

```
阅卷分析报告

一、案件基本信息
二、指控事实梳理（按指控罪名列举，逐项梳理事实要素）
三、证据清单总表（按证据类型分类列表）
四、案件时间轴（多轨时间轴展示）
五、关键矛盾与疑点
   5.1 证据间矛盾
   5.2 金额/数量疑点
   5.3 程序瑕疵
六、待核实问题清单
七、初步分析意见
   7.1 控方有利点
   7.2 控方薄弱点
   7.3 辩护切入点建议
   7.4 法律依据初步检索
   7.5 辩护策略初步建议
   7.6 量刑初步评估
```

### 8.2 初步分析意见撰写要求

**辩护切入点建议**：
- 每个切入点须具备"事实依据 + 法律逻辑 + 预期效果"三要素
- 按重要性排序
- 切入点之间应形成互补体系

**法律依据初步检索**：
- 列出本案涉及的罪名条文
- 列出相关司法解释
- 列出有利于被告人的程序法条文
- 引用格式：`《XXX法》第XX条`

**辩护策略初步建议**：
- 提出明确的辩护方向（无罪/罪轻/复合）
- 说明策略选择的事实和法律依据
- 预判控方可能的反驳及应对方案

**量刑初步评估**：
- 法定刑幅度分析
- 各项从重/从轻/减轻情节及预估减刑幅度
- 综合量刑区间预测
