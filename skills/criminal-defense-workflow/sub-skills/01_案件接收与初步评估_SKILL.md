# 01 案件接收与初步评估

## Step 0：执行前强制检查

1. **⚠️ 加载本 skill**：确认已读取本文件
2. **检查偏好**：读取案件文件夹中的 `办案记录.md`，确认用户是否有格式/风格偏好
3. **确认角色**：确认我方代理角色（辩护人）
4. **确认阶段**：确认案件当前所处阶段

## 一、任务目标

建立案件档案，完成初步评估，为后续辩护工作奠定基础。

## 二、操作步骤

### Step 1：建立案件文件夹结构

按照 SKILL.md 规定的文件夹结构创建：

```

├── 00_案件信息/
├── 01_原始材料/
├── 02_工作底稿/
├── 03_正式文书/
├── 04_参考资料/
└── 办案记录.md
```

### Step 3：初步法律分析

#### 3.1 罪名初步判断

- 涉嫌罪名的构成要件初步分析
- 可能涉及的此罪与彼罪辨析
- 是否存在无罪可能

#### 3.2 量刑初步评估

- 法定刑幅度
- 可能的量刑情节（从重/从轻/减轻）
- 初步量刑区间预测

#### 3.3 辩护空间评估

| 评估维度 | 评估内容 | 辩护空间 |
|:---|:---|:---:|
| 事实层面 | 指控事实是否有争议 | 大/中/小 |
| 证据层面 | 证据是否确实充分 | 大/中/小 |
| 法律层面 | 法律适用是否有争议 | 大/中/小 |
| 程序层面 | 是否存在程序违法 | 大/中/小 |

### Step 4：制定初步辩护策略

根据评估结果，提出初步辩护方向：

1. **无罪辩护**：事实不清、证据不足或法律适用错误
2. **罪轻辩护**：罪名成立但存在从轻、减轻情节
3. **复合策略**：程序辩护 + 实体辩护 + 量刑辩护
