# 12 申诉与再审申请

## Step 0：执行前强制检查

1. **⚠️ 加载本 skill**：确认已读取本文件
2. **检查偏好**：读取 `办案记录.md`
3. **确认角色**：确认我方为申诉人/再审申请人辩护人
4. **确认阶段**：确认判决已生效

## 一、任务目标

针对已生效判决中的错误，撰写申诉状或再审申请书，启动审判监督程序。

## 二、申诉与再审的区别

| 项目 | 申诉 | 再审申请 |
|:---|:---|:---|
| **受理机关** | 各级法院、检察院 | 作出生效裁判的法院或其上级法院 |
| **程序性质** | 民主权利 | 诉讼权利 |
| **期限** | 无期限限制 | 刑罚执行完毕后2年内 |
| **效力** | 不停止执行 | 不停止执行 |
| **次数** | 无次数限制 | 一般一次 |
| **审查结果** | 驳回或启动再审 | 裁定再审或驳回 |

## 三、再审法定事由（《刑事诉讼法》第253条）

| 事由 | 内容 | 本案是否符合 |
|:---|:---|:---:|
| **新证据** | 有新的证据证明原判认定的事实确有错误 | |
| **证据不确实充分** | 据以定罪量刑的证据不确实、不充分 | |
| **主要证据矛盾** | 主要证据之间存在矛盾 | |
| **适用法律错误** | 原判适用法律确有错误 | |
| **程序严重违法** | 审判程序严重违法，影响公正裁判 | |
| **审判人员违法** | 审判人员有贪污受贿、徇私舞弊、枉法裁判行为 | |

## 四、申诉/再审申请策略

### 4.1 向法院申诉

- 向作出生效判决的法院提出
- 向上一级法院提出
- 向最高人民法院提出（重大疑难案件）

### 4.2 向检察院申诉

- 向同级检察院提出
- 向上一级检察院提出
- 向最高人民检察院提出

### 4.3 策略选择

| 情形 | 建议策略 |
|:---|:---|
| 有新证据 | 同时向法院和检察院申诉 |
| 法律适用错误 | 向法院申诉 |
| 审判人员违法 | 向检察院申诉 |
| 程序严重违法 | 同时向法院和检察院申诉 |

## 六、配套材料

申诉/申请再审时需提交：

1. **申诉状/再审申请书**（正本 + 副本）
2. **原审判决书/裁定书**（复印件）
3. **新证据**（如有）
4. **证据目录**
5. **辩护人授权委托书**
6. **律师事务所函**
7. **申诉人身份证明**

## 七、后续跟进

### 7.1 法院审查

- 法院收到申诉后，进行审查
- 符合再审条件的，裁定再审
- 不符合的，驳回申诉

### 7.2 检察院审查

- 检察院收到申诉后，进行审查
- 认为需要再审的，提出抗诉
- 认为不需要的，不予抗诉

### 7.3 再审审理

- 裁定再审的，另行组成合议庭审理
- 可以开庭审理，也可以书面审理
- 再审判决为终审判决
