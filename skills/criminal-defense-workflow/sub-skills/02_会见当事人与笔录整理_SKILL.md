# 02 会见当事人与笔录整理

## Step 0：执行前强制检查

1. **⚠️ 加载本 skill**：确认已读取本文件
2. **检查偏好**：读取 `办案记录.md`
3. **确认角色**：确认我方为辩护人
4. **确认阶段**：确认案件所处阶段（侦查/审查起诉/审判）

## 一、任务目标

通过会见获取第一手信息，整理规范化的会见笔录，为后续辩护工作提供基础。

## 二、会见前准备

### 2.1 准备材料清单

- [ ] 授权委托书
- [ ] 律师事务所函
- [ ] 律师执业证复印件
- [ ] 会见介绍信（看守所要求）
- [ ]  questions list（问题清单）

### 2.2 问题清单模板

#### 通用问题（所有阶段）

1. **身份确认**：姓名、年龄、职业、住址
2. **到案经过**：何时、何地、如何到案
3. **强制措施**：何时被拘留/逮捕，是否收到通知书
4. **身体状况**：是否有疾病、是否被刑讯逼供
5. **家庭情况**：家庭成员、经济状况

#### 侦查阶段特有问题

6. **讯问情况**：被讯问几次、时间、地点、人员
7. **供述内容**：每次供述的核心内容
8. **辩解内容**：是否有无罪/罪轻的辩解
9. **证据情况**：知道哪些证据、证据是否属实
10. **同案犯**：是否认识同案犯、关系如何

#### 审查起诉/审判阶段特有问题

11. **起诉意见**：是否收到起诉意见书/起诉书
12. **证据变化**：是否有新证据
13. **认罪态度**：是否认罪、对指控的意见
14. **量刑预期**：对量刑的期望
15. **和解意愿**：是否愿意赔偿/和解

## 三、会见笔录整理规范

### 3.1 笔录结构

```
会见笔录

时间：YYYY年MM月DD日 HH:MM - HH:MM
地点：XXX看守所/监狱
会见人：XXX律师
记录人：XXX
被会见人：XXX（犯罪嫌疑人/被告人）

一、告知事项
   1. 律师身份告知
   2. 权利义务告知
   3. 保密义务告知

二、案件情况询问
   [按问题清单逐项记录]

三、律师初步意见
   [根据阶段提供相应法律意见]

四、后续工作安排
   [告知下一步工作计划]

五、其他事项
   [家属转达、生活需求等]

被会见人签名：_________
会见人签名：_________
记录人签名：_________
日期：_________
```

### 3.2 记录要点

- **客观记录**：如实记录当事人陈述，不加个人评价
- **重点标注**：对辩护有利的内容用【】标注
- **矛盾标注**：当事人陈述与案卷矛盾处用※标注
- **待核实项**：需要进一步核实的内容用？标注

### 3.3 敏感信息处理

- 涉及国家秘密、商业秘密的，注明"涉密，不记录具体内容"
- 涉及其他同案犯可能串供的，谨慎记录
- 当事人承认未被掌握的犯罪事实的，单独记录并提示风险

## 四、会见后工作

### 4.1 信息提取

从会见笔录中提取：

| 信息类型 | 具体内容 | 辩护价值 |
|:---|:---|:---:|
| 到案经过 | 自首/立功线索 | 高 |
| 刑讯逼供线索 | 时间、地点、人员、方式 | 高 |
| 无罪辩解 | 事实版本、证据线索 | 高 |
| 量刑情节 | 退赃、赔偿、谅解可能性 | 中 |
| 程序违法 | 超期羁押、违法取证 | 高 |

### 4.2 与案卷比对

将会见获取的信息与案卷材料比对：

- 供述是否一致
- 是否有新的事实线索
- 是否有新的证据线索
- 是否存在翻供及理由

### 4.3 更新办案记录

在 `办案记录.md` 中记录：
- 会见时间、地点
- 核心信息摘要
- 发现的辩护线索
- 下一步工作计划

## 五、输出文件
