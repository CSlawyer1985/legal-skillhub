# 07 庭审发问提纲

## Step 0：执行前强制检查

1. **⚠️ 加载本 skill**：确认已读取本文件
2. **检查偏好**：读取 `办案记录.md`
3. **确认角色**：确认我方为辩护人
4. **确认阶段**：确认案件处于审判阶段
5. **⚠️ 加载跨专业知识**：涉及鉴定人、专家辅助人发问且 `办案记录.md` 状态头标注「涉及专业领域」的，强制加载 `references/cross-disciplinary/` 对应文件（见 SKILL.md 6.4）

## 一、任务目标

准备系统性的庭审发问提纲，通过发问揭示有利于被告人的事实，质疑控方证据。

## 二、发问原则

### 2.1 基本原则

- **明知故问**：只问你知道答案或能够推断答案的问题
- **简洁明确**：一个问题只问一个事实
- **避免开放式问题**：不用"为什么""怎么样"，用"是不是""有没有"
- **逻辑递进**：由浅入深，层层推进
- **控制证人**：防止证人说出不利内容

### 2.2 禁止事项

- 不问你不知道答案的问题
- 不问可能引出不利事实的问题
- 不问复合型问题（一个问句包含多个问题）
- 不问假设性问题（除非必要）
- 不与证人争论

## 三、向被告人发问

### 3.1 发问目的

- 让被告人陈述有利于自己的事实
- 解释供述中的矛盾之处
- 展示被告人的认罪态度或辩解理由

### 3.2 发问结构

```
一、身份与基本情况
   1. 姓名、年龄、职业
   2. 与案件相关人的关系

二、到案经过
   1. 何时、何地、如何到案
   2. 是否主动投案
   3. 到案后是否如实供述

三、案件事实（按时间顺序）
   1. 事情的起因
   2. 事情经过（分段发问）
   3. 事情的结果

四、主观方面
   1. 行为时的主观心态
   2. 对行为性质的认识
   3. 对后果的预见

五、量刑情节
   1. 是否初犯、偶犯
   2. 是否有退赃、赔偿意愿
   3. 是否取得谅解
   4. 家庭情况、社会表现
```

### 3.3 发问示例

**关于到案经过**：
- "2024年3月15日，你是如何到公安机关的？"
- "是公安机关打电话通知你去的，还是你自己主动去的？"
- "你到公安机关后，是否如实说明了情况？"

**关于主观故意**：
- "你当时是否知道这种行为是违法的？"
- "你收取这笔费用的目的是什么？"
- "你是否打算归还这笔款项？"

## 四、向证人发问

### 4.1 发问目的

- 揭示证人证言的矛盾之处
- 展示证人与案件的利害关系
- 获取有利于被告人的事实

### 4.2 发问结构

```
一、证人的身份与关系
   1. 姓名、职业
   2. 与被告人/被害人的关系
   3. 是否认识控方其他证人

二、感知能力
   1. 事发时的距离、角度、光线
   2. 是否佩戴眼镜
   3. 是否存在影响感知的因素

三、记忆能力
   1. 距离事发时间多久作证
   2. 是否受到他人影响
   3. 是否与其他证人讨论过

四、陈述内容
   1. 具体看到了什么
   2. 具体听到了什么
   3. 是否存在推断、猜测

五、利害关系
   1. 与被告人是否有矛盾
   2. 与被害人是否有关系
   3. 作证是否受到压力
```

### 4.3 质疑性发问示例

**关于感知能力**：
- "事发当时是晚上几点？"
- "现场的光线条件如何？"
- "你距离事发地点大约多远？"
- "你是否能看清对方的面部特征？"

**关于记忆可靠性**：
- "你是在事发后多久向公安机关陈述的？"
- "在这之间，你是否与其他人讨论过这件事？"
- "你的陈述是否受到他人的提示或影响？"

**关于利害关系**：
- "你与被害人是什么关系？"
- "你与被告人之前是否有过矛盾？"
- "你作证是否受到任何人的压力或诱导？"

## 五、向鉴定人发问

> 涉及司法会计、法医学、司法精神病等专业领域的，发问问题必须结合对应跨专业知识文件（SKILL.md 6.4）设计，确保专业上站得住。

### 5.1 发问目的

- 质疑鉴定方法和过程
- 揭示鉴定意见的局限性
- 提出替代性解释

### 5.2 发问结构

```
一、鉴定人资质
   1. 专业背景
   2. 执业资格
   3. 从业年限
   4. 是否接受过专门培训

二、鉴定过程
   1. 接受的鉴定委托
   2. 使用的鉴定方法
   3. 依据的检材
   4. 是否遵循操作规程

三、鉴定意见
   1. 鉴定结论的依据
   2. 是否存在多种可能
   3. 鉴定意见的确定性程度
   4. 是否存在相反结论的可能
```

### 5.3 质疑性发问示例

**关于鉴定方法**：
- "你使用的鉴定方法是否符合国家标准？"
- "这种鉴定方法的准确率是多少？"
- "是否存在其他可行的鉴定方法？"

**关于检材**：
- "你鉴定的检材是如何提取和保管的？"
- "检材在送检前是否可能被污染？"
- "检材的量是否足够进行准确鉴定？"

**关于结论**：
- "你的鉴定意见是确定性结论还是可能性结论？"
- "是否存在与你的结论相反的其他可能？"
- "在什么情况下你的鉴定结论可能不成立？"

## 六、向侦查人员发问

### 6.1 发问目的

- 审查取证程序的合法性
- 发现非法取证的线索
- 质疑证据的可靠性

### 6.2 发问要点

```
一、身份与权限
   1. 姓名、职务
   2. 是否参与本案侦查
   3. 具体负责的工作

二、取证过程
   1. 取证的时间、地点
   2. 是否有见证人在场
   3. 是否制作笔录
   4. 是否全程录音录像

三、讯问过程
   1. 讯问的时间、地点
   2. 讯问的时长
   3. 是否告知诉讼权利
   4. 是否存在刑讯逼供
```

## 七、发问提纲撰写

### 7.1 格式

```
庭审发问提纲

一、向被告人发问
   （一）身份与基本情况
       1. ...
       2. ...
   （二）到案经过
       1. ...
   ...

二、向证人XXX发问
   （一）身份与关系
       1. ...
   （二）感知能力
       1. ...
   ...

三、向鉴定人XXX发问
   （一）资质
       1. ...
   （二）鉴定过程
       1. ...
   ...

四、向侦查人员发问
   （一）取证过程
       1. ...
   ...
```

### 7.2 标注说明

- **【必问】**：必须发问的核心问题
- **【追问】**：根据回答可能追问的问题
- **【备选】**：视情况决定是否发问
- **【禁忌】**：绝对不能问的问题
