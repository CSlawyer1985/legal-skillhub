# 03 强制措施变更申请

## Step 0：执行前强制检查

1. **⚠️ 加载本 skill**：确认已读取本文件
2. **检查偏好**：读取 `办案记录.md`
3. **确认角色**：确认我方为辩护人
4. **确认阶段**：确认案件所处阶段

## 一、任务目标

为犯罪嫌疑人/被告人申请变更强制措施，争取取保候审或监视居住。

## 二、申请条件分析

### 2.1 取保候审适用条件（《刑事诉讼法》第67条）

| 条件 | 具体情形 | 本案是否符合 |
|:---|:---|:---:|
| 可能判处管制、拘役或独立适用附加刑 | 罪名较轻，法定刑在三年以下 | |
| 可能判处有期徒刑以上，采取取保不致发生社会危险性 | 有固定住所、工作，无前科 | |
| 患有严重疾病、生活不能自理 | 提供病历、诊断证明 | |
| 怀孕或正在哺乳自己婴儿的妇女 | 提供医学证明 | |
| 羁押期限届满，案件尚未办结 | 计算羁押期限 | |

### 2.2 监视居住适用条件（《刑事诉讼法》第74条）

- 符合逮捕条件，但患有严重疾病、怀孕等特殊情况
- 符合取保候审条件，但无法提出保证人或交纳保证金
- 羁押期限届满，案件尚未办结

### 2.3 社会危险性评估

| 评估因素 | 有利因素 | 不利因素 |
|:---|:---|:---|
| 再犯可能性 | 无前科、有正当职业 | 有前科、无固定住所 |
| 妨碍诉讼可能性 | 愿意配合调查 | 可能串供、毁灭证据 |
| 危害社会可能性 | 罪名非暴力性 | 可能报复被害人 |

## 三、申请策略

### 3.1 侦查阶段策略

- **黄金37天**：拘留后30天内报捕，检察院7天内决定是否逮捕
- **时间节点**：
  - 拘留后3日内：首次申请取保候审
  - 报捕前：再次申请，强调不予批捕理由
  - 批捕后：申请羁押必要性审查

### 3.2 审查起诉阶段策略

- 证据已固定，申请取保不致妨碍诉讼
- 认罪认罚从宽，配合调查
- 退赃退赔，取得谅解

### 3.3 审判阶段策略

- 可能判处缓刑的，应当取保
- 羁押期限可能超过刑期的
- 患有严重疾病的

## 四、申请书撰写

### 4.1 结构

```
取保候审申请书

申请人：XXX律师事务所律师
被申请人：XXX（犯罪嫌疑人/被告人）

申请事项：
对犯罪嫌疑人/被告人XXX申请取保候审

事实与理由：

一、案件基本情况
   [简要介绍案件事实和阶段]

二、符合取保候审的法定条件
   [逐条分析符合的条件]

三、采取取保候审不致发生社会危险性
   [详细论证无社会危险性]

四、取保候审的保证方式
   [保证人/保证金]

五、法律依据
   [引用具体法条]

此致
XXX公安局/检察院/法院

申请人：XXX（签名）
XXX律师事务所（盖章）
日期：YYYY年MM月DD日
```

### 4.2 论证要点

**社会危险性论证**：
- 固定住所：提供房产证/租赁合同
- 稳定职业：提供工作证明
- 家庭纽带：提供家庭成员信息
- 配合态度：愿意随传随到

**特殊情形论证**：
- 疾病：提供诊断证明、病历
- 怀孕/哺乳：提供医学证明
- 未成年人：提供出生证明、学校证明

## 五、配套材料

申请时需准备：

1. **取保候审申请书**（正本）
2. **保证人材料**（如采用保证人）：
   - 保证人身份证明
   - 保证人收入证明
   - 保证人承诺书
3. **保证金**（如采用保证金）：
   - 交纳凭证
4. **证明材料**：
   - 疾病诊断证明
   - 怀孕医学证明
   - 家庭情况证明
   - 工作证明
   - 无前科证明

## 六、后续跟进

### 6.1 不予取保的应对

- 了解不予取保的具体理由
- 补充新的证明材料
- 申请复议或向上级机关申诉
- 申请羁押必要性审查（批捕后）

### 6.2 羁押必要性审查

依据《刑事诉讼法》第95条，向检察院申请：
- 案件事实、证据发生变化
- 犯罪嫌疑人身体状况恶化
- 达成和解、退赃退赔
- 可能判处缓刑
