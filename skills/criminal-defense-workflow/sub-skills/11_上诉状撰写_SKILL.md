# 11 上诉状撰写

## Step 0：执行前强制检查

1. **⚠️ 加载本 skill**：确认已读取本文件
2. **检查偏好**：读取 `办案记录.md`
3. **确认角色**：确认我方为上诉人辩护人
4. **确认阶段**：确认一审判决已作出

## 一、任务目标

针对一审判决中的错误，撰写上诉状，提出上诉理由，争取二审改判或发回重审。

## 二、上诉期限

- **判决上诉期**：接到判决书第二日起 **10日内**
- **裁定上诉期**：接到裁定书第二日起 **5日内**
- **逾期后果**：超过上诉期未上诉的，一审判决生效

## 三、上诉理由类型

### 3.1 事实认定错误

| 错误类型 | 具体表现 | 上诉要点 |
|:---|:---|:---|
| **事实不清** | 关键事实未查清 | 指出未查清的事实及影响 |
| **证据不足** | 认定事实缺乏证据 | 指出证据缺口 |
| **矛盾未排除** | 证据间矛盾未解决 | 指出矛盾及合理怀疑 |
| **新证据** | 发现新证据 | 说明新证据内容及证明力 |

### 3.2 证据采信错误

| 错误类型 | 具体表现 | 上诉要点 |
|:---|:---|:---|
| **非法证据未排除** | 应排除的非法证据被采信 | 指出非法取证情形 |
| **证据真实性错误** | 虚假证据被采信 | 指出证据虚假之处 |
| **证据关联性错误** | 无关证据被采信 | 指出证据与案件无关 |
| **孤证定案** | 仅有孤证认定事实 | 指出证据不足 |

### 3.3 法律适用错误

| 错误类型 | 具体表现 | 上诉要点 |
|:---|:---|:---|
| **罪名错误** | 此罪判成彼罪 | 指出罪名认定错误 |
| **量刑过重** | 超出法定刑幅度 | 指出量刑不当 |
| **情节认定错误** | 从轻情节未认定 | 指出应认定的情节 |
| **法律条文引用错误** | 引用法条不当 | 指出正确法条 |

### 3.4 程序违法

| 违法类型 | 具体表现 | 上诉要点 |
|:---|:---|:---|
| **管辖错误** | 无管辖权或管辖不当 | 指出管辖问题 |
| **回避未处理** | 回避申请未处理 | 指出回避事由 |
| **剥夺辩护权** | 限制辩护人权利 | 指出被剥夺的权利 |
| **审判组织不合法** | 合议庭组成不当 | 指出组成问题 |
| **未公开审理** | 应公开而未公开 | 指出公开要求 |

## 四、上诉状撰写

### 4.1 结构

```
刑事上诉状

上诉人（原审被告人）：XXX
身份证号：XXX
住址：XXX

辩护人：XXX，XXX律师事务所律师

上诉人不服XXX人民法院（20XX）X刑初字第XX号刑事判决，
现依法提起上诉。

上诉请求：
1. 请求撤销原判，依法改判（或：发回重审）
2. 具体请求（如：改判无罪/改判轻罪/减轻刑罚）

上诉理由：

一、原判事实认定错误
   [详细阐述事实错误]

二、原判证据采信错误
   [详细阐述证据错误]

三、原判法律适用错误
   [详细阐述法律错误]

四、原审程序违法
   [详细阐述程序违法]

五、量刑过重
   [详细阐述量刑不当]

综上所述，原判存在XXX错误，恳请二审法院依法改判（或发回重审）。

此致
XXX中级人民法院

上诉人：XXX（签名）
辩护人：XXX（签名）
日期：YYYY年MM月DD日
```

### 4.2 撰写要点

- **针对性强**：每个上诉理由针对一审判决的具体内容
- **逻辑清晰**：事实→证据→法律，层层递进
- **依据充分**：引用具体法条和司法解释
- **请求明确**：明确请求改判或发回重审

### 4.3 常见上诉理由表述

**事实不清**：
> "原判认定'被告人于2024年3月15日收取被害人款项50万元'，但卷内银行流水显示当日仅转账30万元（卷二第45页），另有20万元无转账记录，原判对该20万元的资金来源未查清。"

**证据不足**：
> "原判认定被告人具有非法占有目的，但仅有被害人陈述（卷三第20页），无其他证据印证，且被告人始终辩解系借款（卷一第15页），原判在证据不足的情况下认定诈骗罪，违反《刑事诉讼法》第55条。"

**量刑过重**：
> "原判认定被告人具有自首情节（卷一第10页），但在量刑时未予体现，根据《刑法》第67条及量刑指导意见，自首可减少基准刑40%以下，原判量刑明显过重。"

## 五、上诉策略

### 5.1 全面上诉 vs 部分上诉

| 策略 | 适用情形 | 优点 | 风险 |
|:---|:---|:---|:---|
| **全面上诉** | 事实、证据、法律均有问题 | 不留死角 | 可能被认为认罪态度不好 |
| **部分上诉** | 仅量刑或某一方面有问题 | 针对性强 | 可能遗漏重要理由 |

### 5.2 二审辩护重点

- **不开庭审理**：重点提交书面辩护意见
- **开庭审理**：重点准备庭审辩论
- **发回重审**：指出程序违法或事实不清
- **直接改判**：指出法律适用错误或量刑不当

## 六、配套材料

上诉时需提交：

1. **上诉状**（正本 + 副本，副本数量 = 对方当事人人数 + 法院）
2. **一审判决书**（复印件）
3. **新证据**（如有）
4. **辩护人授权委托书**
5. **律师事务所函**

1. **《刑事上诉状》** → `03_正式文书/YYYYMMDD_上诉状_上诉人辩护人.md`
