# 09 辩护词撰写

## Step 0：执行前强制检查

1. **⚠️ 加载本 skill**：确认已读取本文件
2. **检查偏好**：读取 `办案记录.md`
3. **确认角色**：确认我方为辩护人
4. **确认阶段**：确认案件处于审判阶段

## 一、任务目标

基于阅卷报告和质证意见，构建完整的辩护体系，形成书面辩护词。

## 二、资料准备

撰写辩护词前，必须完成以下准备：

1. **阅卷报告**：完整阅读《阅卷分析报告》，掌握案件全景
2. **质证意见**：完整阅读《证据分析报告（质证意见）》，了解证据问题
3. **会见笔录**：回顾会见中获取的信息
4. **法律检索**：检索相关法律规定、司法解释、指导性案例
5. **类案检索**：检索相似案例的裁判结果和理由

## 三、辩护词结构

辩护词采用**“两部为基础、程序阶段可调整”**的结构（调整规则详见 `references/defense-brief-writing-guide.md`）：

- **默认结构**（一审、简单案件）：首部 + 第一部分 + 第二部分 + 尾部
- **二审/再审案件**：可在第二部分内增设“一审/原审认定错误”“程序违法”等专节，无需机械拆分
- **多罪名/多人复杂案件**：可在第一部分内设“罪名一/被告人一”“罪名二/被告人二”等分节

### 第一部分：事实与证据分析

**功能**：先破后立——先推翻或削弱控方事实主张，再建立有利于被告人的事实框架。

**内容组织**：

1. **指控事实梳理**：简要概括控方指控的核心事实
2. **证据质证综述**：基于《质证意见》，提炼关键证据问题
   - 非法证据排除（如有）：优先提出，釜底抽薪
   - 核心证据质疑：针对定罪关键证据进行深度分析
   - 证据链断裂：论证控方证据体系存在无法弥补的漏洞
3. **事实重构**：在质疑控方事实的基础上，提出更有利于被告人的事实版本
4. **数据论证**（经济犯罪等）：展示完整计算过程，用数据说话

### 第二部分：法律分析

**功能**：基于已厘清的事实，进行法律适用分析。

**内容组织**：

1. **罪名构成要件分析**：逐一拆解犯罪构成要件
   - 客体要件：侵害的法益是什么？是否实际侵害？
   - 客观要件：行为是否符合该罪的客观特征？
   - 主体要件：被告人是否符合特殊主体要求？
   - 主观要件：是否具有故意/过失？是否具有特定目的？

2. **此罪与彼罪辨析**：是否构成其他罪名而非指控罪名？

3. **犯罪形态分析**：
   - 既遂/未遂/中止
   - 共同犯罪中的地位（主犯/从犯/胁从犯）
   - 是否构成单位犯罪

4. **量刑情节分析**：
   - 法定从轻/减轻情节
   - 酌定从轻情节
   - 是否存在加重情节的争议

5. **结论**：以“综上所述”段落嵌入法律分析的末尾，总结辩护意见

## 四、撰写规范

### 4.1 标题层级与编号

| 层级 | 格式 | 示例 |
|------|------|------|
| 大标题 | 第一部分/第二部分 | 第一部分 事实与证据分析 |
| 一级标题 | 一、二、三… | 一、关于起诉书指控事实的认定问题 |
| 二级标题 | （一）（二）（三）… | （一）关于被告人供述的采信问题 |
| 三级标题 | 1. 2. 3.… | 1. 第一次供述的取得程序 |

**禁止**：
- 一级标题/二级标题跳号
- 默认结构中出现独立“第三部分”
- 使用“第一”“第二”等不规范编号

### 4.2 格式参数

正式 Word 版统一按本技能 SKILL.md 第 5.4 节规范生成（`md2docx_formal.py`）：

| 元素 | 设置 |
|------|------|
| 字体 | 全文仿宋（含中英文、数字），四号（14pt） |
| 文档标题 | 居中、加粗（仍为仿宋四号） |
| 大标题（第一部分/第二部分） | 居中、加粗 |
| 一级/二级标题 | 加粗、首行缩进两字符 |
| 正文 | 首行缩进两字符 |
| 行距 | 固定值27磅 |
| 段间距 | 段前0、段后0 |
| 页面 | A4，标准页边距（上下2.54cm、左右3.17cm） |
| 表格 | 实线边框，表头加粗，单元格内同样仿宋四号、固定27磅、段距0 |

### 4.3 数据精确性原则

- 不得直接给出计算结果，必须展示完整计算过程
- 金额计算须列明公式：损失金额 = 总数 - 已归还 - 可抵扣
- 数据引用须注明来源（审计报告第X页、银行流水第X页）
- 同一数字全文保持一致

### 4.4 反推论证方法

当控方事实难以正面推翻时，采用反推法：

1. 假设控方主张成立
2. 推导应当存在的结果或证据
3. 指出实际不存在该结果或证据
4. 论证控方主张不成立

示例：
> “若如起诉书所述，被告人以非法占有为目的骗取资金，则其在获得资金后应当具有转移、隐匿、挥霍等逃避返还的行为。但案卷材料显示，被告人将所收款项全部用于公司正常经营支出（详见审计报告第XX页），并无任何转移或隐匿行为。据此，控方关于被告人具有非法占有目的的主张不能成立。”

### 4.5 证据引用规范

- 引用证据须注明案卷编号和页码：如“（卷三第45页）”
- 对证据内容的概括须准确，不得歪曲
- 多份证据支持同一观点时，逐一列明
- 引用法律条文须注明全称和条号

### 4.6 语言风格

- 使用规范法律术语，避免口语化
- 论证严谨，逻辑清晰，层次分明
- 禁止情绪化表达和攻击性语言
- 禁止堆砌政策性套话
- 禁止评价被告人“反复无常”，应客观表述供述变化
- 同一论证点不得在辩护词中重复出现
- 禁止使用英文标点符号混入中文文本

## 五、字数要求

| 案件类型 | 建议字数 |
|----------|----------|
| 简单案件 | 12000-15000字 |
| 复杂案件 | 15000-18000字 |
| 重大疑难案件 | 18000字以上 |

## 六、撰写流程

1. **搭建框架**：按照结构指引列出详细提纲，经用户确认后定稿
2. **分段生成**：按提纲分节撰写，每节生成前从 `02_工作底稿/` 调取该节所需的阅卷摘录与质证点，不依赖对话记忆；万字以上长文禁止一次性生成
3. **法律论证**：检索法律依据，撰写第二部分
4. **数据校验**：核对所有金额、日期、证据引用
5. **逻辑检查**：检查论证链条的完整性
6. **一致性回读**：全文重读一遍，核对金额、日期、编号、术语前后一致
7. **格式排版**：按照格式参数调整文档
8. **终稿审查**：执行交付检查清单
