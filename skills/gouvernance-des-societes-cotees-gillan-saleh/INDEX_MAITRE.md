## 7. 选择帮助——什么问题查哪个索引？

- **董事独立性** → AMF 2020-2025（立场、点名通报）+ HCGE（统计）+ `code-afep-medef-references.md`（第 10.3、10.5 条）。
- **薪酬 / 薪酬表决 / 公平比率** → AMF + HCGE（薪酬部分，第二部分统计）；公平比率 = 第 L. 22-10-9 条。
- **气候投票 / 可持续性 / CSRD** → AMF（F）+ HCGE（J）+ `index_AMF_DURABILITE_2024`、`index_AMF_CSRD_WAY_FORWARD_2025`、`index_ESMA_ECEP_2025`。
- **股东大会 / 股东权利** → AMF（F）+ `references/droits-actionnaires-cotees.md` + `index_PARIS_EUROPLACE_DIALOGUE_2024`。
- **投票顾问机构（proxy advisors）** → `index_AMF_2025`（第三部分）。
- **AI / 网络安全（新兴主题）** → `index_HCGE_2024`、`index_HCGE_2025`、`index_AMF_2025` + 外部来源（语料有限，以检索补充）。
- **公共援助 / 危机中的股息** → `index_Senat_Rietmann_2025`。
- **某公司的具名重复** → `recurrences_nominatives.md`（交叉 AMF + HCGE）。
- **准则某条款的引用** → `code-afep-medef-references.md`。

> 提示：语料截至 2025 年。现行法律状态和时事请按 SKILL.md 以互联网检索补充（Légifrance、EUR-Lex、官方网站）。
