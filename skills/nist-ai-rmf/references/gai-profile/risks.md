## 1. CBRN 信息或能力 <a id="1-cbrn-information-or-capabilities"></a>

未来，GAI 可能使恶意行为者更容易获取 CBRN 武器和/或可能被滥用以协助设计、开发、生产或使用 CBRN 武器或其他危险材料或制剂的相关知识、信息、材料、工具或技术。虽然相关的生物和化学威胁知识和信息通常可公开获取，但 LLM 可以促进其分析或综合，尤其是对未经正式科学训练或不具备专业知识的个人而言。

近期关于该主题的研究发现，LLM 关于生物威胁制造和攻击策划的输出，相比传统搜索引擎查询提供的帮助甚微，这表明在进行这些研究时，最先进的 LLM 并不会实质性提高此类攻击发生的操作可能性。化学或生物制剂的实际合成开发、生产和物理使用将继续同时需要适用的专业知识和配套材料与基础设施。GAI 对化学或生物制剂滥用的影响，将取决于恶意行为者的关键障碍是什么（例如信息获取是否就是这样的障碍），以及 GAI 能在多大程度上帮助行为者克服这些障碍。

此外，化学和生物设计工具（BDT）——基于科学数据训练的高度专业化人工智能系统，辅助化学和生物学设计——可能在化学和生物学领域增强超越基于文本的 LLM 所能提供的设计能力。随着这些模型变得越来越有效（包括用于有益用途），评估其被用于伤害的潜在可能性（例如构思和设计新型有害化学或生物制剂）将非常重要。

虽然上述部分能力超出现有 GAI 工具的能力范围，但持续评估该风险可通过同时监测人工智能工具促进 CBRN 武器策划的能力，以及 GAI 系统与相关数据和工具的连接或访问情况而得到加强。

**可信赖人工智能特征：** 安全、可解释和可解读

## 2. 虚构（Confabulation） <a id="2-confabulation"></a>

"虚构"是指 GAI 系统在回应提示时生成并自信地呈现错误或虚假内容的现象。虚构还包括生成的输出偏离提示或其他输入，或与同一语境中先前生成的陈述相矛盾的情况。这些现象口语中也称为"幻觉"或"捏造"。

虚构可能发生在各类 GAI 输出和语境中。9,10 虚构是生成模型设计方式的自然结果：它们生成的输出近似其训练数据的统计分布；例如，LLM 预测句子或短语中的下一个标记或单词。虽然这种统计预测可以产生事实准确且一致的输出，但它也可能产生事实不准确或内部不一致的输出。这一动态在开放式提示要求长篇回应，以及在需要高度语境化和/或领域专业知识的领域尤其相关。

当用户相信虚假内容时——通常是因为回应显得自信——就可能产生虚构风险，导致用户据此行动或传播虚假信息。这对许多现实世界应用构成挑战，例如在医疗保健领域，虚构的患者信息报告摘要可能导致医生作出错误的诊断和/或推荐错误的治疗。在将 GAI 集成到涉及重大决策的应用中时，监控虚构内容的风险可能尤为重要。

GAI 输出还可能包含旨在证明或解释系统答案的虚构逻辑或引用，这可能进一步误导人类不适当地信任系统输出。例如，LLM 有时会提供其如何得出答案的逻辑步骤，即使答案本身是错误的。同样，LLM 可能虚假地声称自己是人类或具有人类特征，可能欺骗人类，使其相信自己正在与另一个人交谈。

人类在多大程度上会被 LLM 欺骗、这种欺骗可能发生的机制，以及对抗性提示此类行为带来的潜在风险，是正在兴起的研究领域。鉴于 GAI 下游影响的广泛性，很难估计虚构的下游规模和影响。

**可信赖人工智能特征：** 公平且有害偏见得到管理、安全、有效和可靠、可解释和可解读

## 4. 数据隐私 <a id="4-data-privacy"></a>

GAI 系统带来若干隐私风险。GAI 系统训练需要大量数据，在某些情况下可能包含个人数据。将个人数据用于 GAI 训练，会对广泛接受的隐私原则带来风险，包括透明度、个人参与（包括同意）以及

目的限定。例如，大多数模型开发者不披露模型训练所依据的具体数据来源，限制了用户对是否使用了个人身份信息（PII）进行训练、以及如果是、如何收集的知情程度。

模型可能泄露、生成或正确推断关于个人的敏感信息。例如，在对抗性攻击期间，LLM 曾泄露了其训练数据中包含的敏感信息（来自公共领域）。这个问题被称为数据记忆（data memorization），即使数据只出现在少量训练样本中，也可能带来加剧的隐私风险。

除了泄露 GAI 训练数据中的敏感信息外，GAI 模型还可能通过拼接来自不同来源的信息，正确推断出其训练数据中没有、也未被用户披露的 PII 或敏感数据。这些推断即使不准确（例如虚构），也可能对个人产生负面影响，尤其是在它们揭示个人视为敏感的信息，或被用于对个人不利或伤害时。

除了信息暴露带来的伤害（如勒索或尊严伤害）外，错误或不恰当的 PII 推断还可能导致下游或二次有害影响。例如，GAI 模型基于 PII 或受保护属性作出的预测性推断可能导致不利决策，从而对个人或群体造成表征性或分配性伤害（见下文"有害偏见与同质化"）。

**可信赖人工智能特征：** 可问责和透明、隐私增强、安全、可靠和强韧

## 5. 环境影响 <a id="5-environmental-impacts"></a>

训练、维护和运行（执行推理）GAI 系统是资源密集型活动，可能产生较大的能源和环境足迹。能源和碳排放因 GAI 模型的处理内容（即预训练、微调、推理）、内容的模态、所使用的硬件以及任务或应用类型而异。

目前的估计表明，训练单个 transformer LLM 的碳排放量可能相当于旧金山和纽约之间 300 次往返航班。在一项比较 LLM 推理能源消耗和碳排放的研究中，生成式任务（如文本摘要）被发现比判别式或非生成式任务（如文本分类）更耗能、碳强度更高。

创建已训练模型较小版本的方法，如模型蒸馏或压缩，可以减少推理时的环境影响，但训练和调优此类模型本身仍可能对其环境影响有贡献。目前尚无公认的方法来估计 GAI 的环境影响。

**可信赖人工智能特征：** 可问责和透明、安全

## 6. 有害偏见与同质化 <a id="6-harmful-bias-and-homogenization"></a>

偏见以多种形式存在，并可能在自动化系统中根深蒂固。人工智能系统（包括 GAI 系统）可以加快有害偏见显现和被依循的速度与规模，可能使对个人、群体、社区、组织和社会的伤害得以延续和放大。例如，当被提示生成 CEO、医生、律师和法官的图像时，当前的文生图模型对女性和/或少数族裔以及残障人士的代表不足。图像生成器模型也针对各种人口群体产生了有偏见或刻板化的输出，并且即使在提示明确要求与刻板印象不一致的图像特征时，也难以生成非刻板化的内容。GAI 模型中的有害偏见（可能源于其训练数据）还可能造成表征性伤害，或延续和加剧基于种族、性别、残障或其他受保护类别的偏见。

GAI 系统中的有害偏见还可能通过模型对不同亚群体或语言的表现差异（例如，LLM 对非英语语言或某些方言的表现可能较差）导致伤害。此类差异可能导致歧视性决策或放大现有社会偏见。此外，GAI 系统可能被不适当地信任为在所有亚群体中表现相似，这可能使表现不佳的群体获得比不使用 GAI 系统更差的结果。对低资源语言的表现差异或下降也给模型的采用、包容性和可及性带来挑战，并且如果 GAI 系统嵌入到原本可以成为使用这些语言机会的日常流程中，可能使濒危语言的保护更加困难。偏见与不良同质化问题相互强化，在同质化中 GAI 系统产生过度统一的偏斜输出分布（例如，重复的审美风格

和内容多样性降低）。过度同质化的输出本身可能是错误的，或可能导致不可靠的决策或放大有害偏见。这些现象可以从基础模型流向下游模型和系统，基础模型充当"瓶颈"或单点故障。

过度同质化的内容可能导致"模型崩溃"（model collapse）。当模型训练过度依赖合成数据，导致数据点从新模型输出的分布中消失时，就可能发生模型崩溃。除了威胁模型的整体稳健性外，模型崩溃可能导致同质化输出，包括放大用于生成合成训练数据的模型所带来的任何同质化。

**可信赖人工智能特征：** 公平且有害偏见得到管理、有效和可靠

## 7. 人机配置 <a id="7-human-ai-configuration"></a>

GAI 系统的使用可能涉及系统与其交互的人之间的配置错误和不良互动的各种风险。人类将自己的独特视角、经验或领域专业知识带入与人工智能系统的互动，但可能没有关于人工智能系统及其运作方式的详细知识。因此，人类专家可能不必要地对 GAI 系统"反感"，从而使自己或他人丧失 GAI 的有益用途。

相反，由于 GAI 技术的复杂性和日益提高的可靠性，随着时间的推移，人类可能过度依赖 GAI 系统，或不合理地认为 GAI 内容比其他来源产生的内容质量更高。这种现象是自动化偏见（automation bias）的一个例子，即对自动化系统过度遵从。自动化偏见可能加剧 GAI 的其他风险，如虚构风险或偏见或同质化风险。

人类与 GAI 系统之间的情感纠缠也可能引发担忧，可能导致负面心理影响。

**可信赖人工智能特征：** 可问责和透明、可解释和可解读、公平且有害偏见得到管理、隐私增强、安全、有效和可靠

## 8. 信息完整性 <a id="8-information-integrity"></a>

信息完整性描述"社会中信息的范围及其产生、交换和消费的相关模式。"高完整性信息可以信赖；它"区分事实与虚构、观点和推断；承认不确定性；并对其审查水平保持透明。此类信息可以附适当证据关联到原始来源。高完整性信息还准确可靠、可验证和可认证、具有清晰的保管链，并就其有效性何时可能过期建立合理预期。"11

11 该信息完整性定义源自 2022 年白宫《信息完整性研发优先事项研究人员路线图》。

GAI 系统可以轻松地大规模无意产生或传播虚假、不准确或误导性内容（misinformation，错误信息），尤其是当内容源于虚构时。

GAI 系统还可以轻松地大规模故意产生或传播虚假或误导性信息（disinformation，虚假信息），此时行为者具有明确欺骗或伤害他人的意图。即使对文本或图像非常细微的更改，也能操纵人类和机器的感知。

同样，GAI 系统可能使恶意行为者能够以更高程度的复杂性制作针对特定人群的虚假信息。当前和新兴的多模态模型使得既能够生成基于文本的虚假信息，也能够生成高度逼真的"深度伪造"（deepfakes）——即合成视听内容和照片级逼真的图像。12 未来的 GAI 模型基于新数据模态训练后，还可能带来额外的虚假信息威胁。

虚假信息和错误信息——两者都可能得到 GAI 的助长——可能侵蚀公众对真实或有效证据和信息的信任，并产生下游效应。例如，一张五角大楼爆炸的合成图片在网络上疯传，曾短暂导致股市下跌。生成式人工智能模型还可以帮助恶意行为者制作引人注目的图像和宣传材料以支持虚假信息活动，这些材料可能并非照片级逼真，但可能使这些活动在社交媒体平台上获得更广的传播和参与。此外，生成式人工智能模型可以帮助恶意行为者制作旨在冒充他人的欺诈性内容。

**可信赖人工智能特征：** 可问责和透明、安全、有效和可靠、可解读和可解释

## 9. 信息安全 <a id="9-information-security"></a>

计算机系统和数据的信息安全是一个成熟领域，在进攻和防御网络能力方面拥有广泛接受和标准化的实践。基于 GAI 的系统带来两个主要的信息安全风险：GAI 可能通过降低进攻性能力的门槛或使其易于自动化行使，来发现或促成新的网络安全风险；同时，它扩大了可用的攻击面，因为 GAI 本身容易受到提示注入或数据投毒等攻击。

GAI 系统增强的进攻性网络能力可能增强黑客攻击、恶意软件和网络钓鱼等网络安全攻击。有报告指出，LLM 已经能够发现系统中的一些漏洞（硬件、软件、数据）并编写代码加以利用。复杂的威胁行为者可能通过开发 GAI 驱动的安全副驾驶并将其用于攻击链的多个环节来加剧这些风险，包括指导攻击者如何主动规避威胁检测以及在获得系统访问权限后提升权限。

GAI 模型和信息安全还包括维护 GAI 系统的可用性，以及 GAI 代码、训练数据和模型权重的完整性以及（适用时）保密性。为了识别和保护人工智能系统或人工智能

价值链特定组件（例如数据输入、处理、GAI 训练或部署环境）中的潜在攻击点，传统网络安全实践可能需要进行调整或演进。

例如，提示注入涉及修改提供给 GAI 系统的输入，使其以非预期方式行事。在直接提示注入中，攻击者可能制作恶意提示并直接输入 GAI 系统，对互联系统产生各种下游负面后果。间接提示注入攻击发生在对手远程（即没有直接接口）利用 LLM 集成应用，通过将提示注入到可能被检索的数据中。安全研究人员已经证明间接提示注入如何通过窃取专有数据或在机器上远程运行恶意代码来利用漏洞。仅仅查询一个封闭的生产模型，就能引出该模型此前未披露的信息。

GAI 面临的另一个网络安全风险是数据投毒（data poisoning），即对手破坏模型使用的训练数据集，以操纵其输出或操作。对数据或模型部分进行恶意篡改，可能加剧与 GAI 系统输出相关的风险。

**可信赖人工智能特征：** 隐私增强、安全、可靠和强韧、有效和可靠

## 10. 知识产权 <a id="10-intellectual-property"></a>

当使用受版权保护的作品不属于合理使用原则下的合理使用时，GAI 系统可能产生知识产权风险。如果 GAI 系统的训练数据包含受版权保护的材料，则 GAI 输出中展示训练数据记忆实例（见上文"数据隐私"）的情况可能构成版权侵权。

GAI 与版权的关系，包括与受版权保护的作品相似但未严格复制的内容的状态，目前正在法律论坛中讨论。关于未经许可使用或模仿个人身份、肖像或声音，也正在进行类似讨论。

**可信赖人工智能特征：** 可问责和透明、公平且有害偏见得到管理、隐私增强

## 11. 淫秽、贬损和/或辱骂性内容 <a id="11-obscene-degrading-and-or-abusive-content"></a>

GAI 可以轻松地生产和获取成人的非法非自愿私密影像（NCII）和/或儿童性虐待材料（CSAM）。GAI 生成的淫秽、辱骂或贬损内容可能造成隐私、心理和情感甚至身体伤害，在某些情况下可能违法。

生成的人工智能露骨或淫秽内容可能包括对真实个人（包括儿童）的高度逼真"深度伪造"。此类材料的传播可能产生下游负面后果：就 CSAM 而言，即使生成的图像不像特定个人，此类图像的盛行也可能转移寻找现实世界受害者的努力所需的时间和资源。在 CSAM 之外，NCII 的创作和传播对女性和性少数群体造成不成比例的影响，并可能产生后续负面后果，包括整体心理健康下降、药物滥用，甚至自杀念头。用于训练 GAI 模型的数据可能无意中包含 CSAM 和 NCII。近期一份报告指出，几个常用的 GAI 训练数据集被发现包含数百张已知的

CSAM 图像。即使在"干净"数据上训练，能力日益增强的 GAI 模型也可以合成或产生合成 NCII 和 CSAM。生成合成 NCII 的网站、移动应用和定制模型已经从利基网络论坛发展为主流的、自动化和规模化的在线业务。

**可信赖人工智能特征：** 公平且有害偏见得到管理、安全、隐私增强

## 12. 价值链与组件集成 <a id="12-value-chain-and-component-integration"></a>

GAI 价值链涉及许多第三方组件，如采购的数据集、预训练模型和软件库。这些组件可能被不当获取或未经适当审查，导致下游用户透明度和问责制下降。虽然这对传统人工智能系统和其他一些数字技术也是一种风险，但对 GAI 而言，由于训练数据的规模（可能大到人类无法审查）、基础模型训练的难度（导致有限数量模型被广泛复用），以及 GAI 可能被集成到其他设备和服务的程度，该风险被加剧。由于 GAI 系统通常涉及许多不同的第三方组件和数据来源，将系统行为中的问题归因于其中任何一个来源可能很困难。

第三方 GAI 组件中的错误也可能对准确性和稳健性产生下游影响。例如，常用于基准测试或验证模型的测试数据集可能包含标签错误。这些标签的不准确可能影响这些基准的"稳定性"或稳健性，许多 GAI 从业者在模型选择过程中会考虑这一点。

**可信赖人工智能特征：** 可问责和透明、可解释和可解读、公平且有害偏见得到管理、隐私增强、安全、可靠和强韧、有效和可靠
