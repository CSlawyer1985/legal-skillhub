# 对照表——NIST 风险名称 ↔ 常见政策别名

NIST 对风险和特征使用特定术语。大多数组织的 AI 政策使用重叠但不同的词汇。本文件将 NIST 语言映射到你在公司政策、监管机构指引和学术文献中最常见的别名——使技能能使用用户的语言，同时仍锚定于 NIST。

本文件为手工构建，非提取。看到值得记录的新别名时更新它。

## 12 项 GAI 风险（NIST AI 600-1）

| NIST 风险 | 常见别名 / 出现之处 |
|---|---|
| **CBRN 信息或能力** | "武器升级"、"两用风险"、"生物安全/化学安全风险"。欧盟《人工智能法》高风险类别；EO 14110 强调。 |
| **虚构（Confabulation）** | "幻觉（hallucination）"、"捏造"、"编造内容"、"虚假输出"。大多数消费者政策使用"幻觉"。 |
| **危险、暴力或仇恨内容** | "有害内容"、"不当内容"、"信任与安全违规"。常细分为"暴力"、"自残"、"仇恨言论"类别。 |
| **数据隐私** | "个人数据风险"、"PII 暴露"、"隐私损害"、"记忆化风险"。GDPR/CCPA 框架：法律依据、数据最小化、主体权利。 |
| **环境影响** | "可持续性"、"计算足迹"、"碳影响"、"训练/推理的能源使用"。 |
| **有害偏见与同质化** | "歧视"、"公平"、"算法偏见"、"差异性影响"、"模型崩溃"（特指同质化）。EEOC/民权框架常用"歧视"。 |
| **人机配置** | "自动化偏见"、"过度依赖"、"拟人化"、"人工监督范围"、"人在环内/人在环上设计"。 |
| **信息完整性** | "错误信息（misinformation）"、"虚假信息（disinformation）"、"合成媒体风险"、"深度伪造"、"选举完整性"。 |
| **信息安全** | "模型安全"、"提示注入"、"越狱"、"经模型的数据外泄"、"对抗性攻击"。与 OWASP LLM Top 10 重叠。 |
| **知识产权** | "版权风险"、"训练数据侵权"、"输出侵权"、"许可合规"、"商业秘密泄露"。 |
| **淫秽、贬损和/或辱骂性内容** | "CSAM"、"NCII"、"非自愿私密影像"、"辱骂性内容"。许多辖区有强制报告义务。 |
| **价值链与组件集成** | "供应链风险"、"第三方/供应商风险"、"开源模型风险"、"依赖风险"、"模型溯源"。与 NIST SSDF/SBOM 对照。 |

## 7 项可信赖人工智能特征（NIST AI 100-1）

| NIST 特征 | 常见别名 |
|---|---|
| **有效和可靠** | "准确性"、"稳健性"、"性能"、"泛化"。常为 PRD 中的首要指标。 |
| **安全** | "安全"、"伤害预防"、"护栏"、"不予部署标准"。 |
| **可靠和强韧** | "安全（security）"、"对抗稳健性"、"事件弹性"、"故障安全行为"。 |
| **可问责和透明** | "可审计性"、"文件化"、"披露"、"模型卡"、"系统卡"、"解释权"。 |
| **可解释和可解读** | "可解释性"、"可解读性"、"XAI"、"决策理由"、"知道原因的权利"。 |
| **隐私增强** | "设计隐私"、"数据最小化"、"差分隐私"、"PET"（隐私增强技术）。 |
| **公平——有害偏见得到管理** | "公平"、"平等"、"非歧视"、"人口统计均等/机会均等/等"。 |

## 风险族分组（非正式但有用）

当用户的政策使用宽泛类别而非 NIST 的 12 项时，这些分组通常可映射：

- **"信任与安全"** → 通常涵盖：危险/暴力/仇恨内容；淫秽/贬损/辱骂性内容；信息完整性（滥用）；人机配置（滥用）。
- **"负责任 AI / 公平"** → 通常涵盖：有害偏见与同质化；人机配置；可问责和透明特征。
- **"安全（Security）"** → 通常涵盖：信息安全；数据隐私（泄露意义上）；价值链（供应链受侵意义上）。
- **"知识产权/法律"** → 通常涵盖：知识产权；数据隐私（法律依据意义上）；常含信息完整性（滥用/诽谤意义上）。
- **"合规/监管"** → 视制度跨越全部 12 项；在 GOVERN 1.1 / GOVERN 6 子类别中明确点名。

## 技能如何使用本文件

当用户描述系统或政策时，查找上表右列的关键词并映射回左列的 NIST 术语。输出中逐字引用 NIST 术语，但首次出现时在括号中附用户的别名，例如：

> "**虚构（Confabulation）**（有时称为"幻觉"）：……"

这避免强迫用户改变词汇，同时保持权威锚定于 NIST。
