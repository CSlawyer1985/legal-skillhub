# 输出模板——模式 3（评估）

仅在输出影响评估时加载本文件。技能程序细节在 `SKILL.md` 中；本文件是输出骨架。

**来源纪律（本模式中最为重要——评估日后会被未参与会话的读者引用）：**

- 下文每个子类别 ID（如 `GOVERN 1.1`）和行动 ID（如 `GV-1.2-001`）都是来自 `references/core/` 或 `references/gai-profile/` 的**逐字引用**。不得编造或改写。
- 子类别下的每段"评估段落"都是**模型发现**，而非 NIST 文本。子类别陈述是逐字的；对照其评估系统的段落是模型撰写的。通过将每段评估段落斜体化并加前缀 *评估：* 或标记 `[模型评估 —— 须对照系统文档核实]`，使边界明确。
- 建议（部署 / 有条件部署 / 不部署）是**模型判断**，利害关系重大。标记为 `[模型建议 —— 所有者必须独立核实]`，并使条件指向具体子类别以便审计。
- 如果缺乏评估某子类别的输入，写"输入不足——见未决事项"，而非猜测。
