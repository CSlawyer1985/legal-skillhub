# 交通事故赔偿计算器 (traffic-accident-calculator)

当用户说「交通事故赔偿 / 车祸赔多少 / 伤残赔偿金 / 误工费怎么算 / 护理费 / 被扶养人生活费 / 责任比例怎么折算 / 交强险赔多少 / 对方保险公司只赔这么点」时触发。

## 适用场景
出了车祸，人受了伤，对方保险公司报来一个数字，受害人完全不知道这个数是高是低。这个技能不谈感受只算账：把伤情、天数、伤残等级、被扶养人、责任比例全部代入司法解释的法定公式，算出每一项该拿多少，再按交强险和责任比例分层还原成"实际能到手多少"。

它解决的具体困境：
- 保险公司报一个总数，不给明细，你无从判断哪一项被压低了
- 只知道有"伤残赔偿金"，不知道被扶养人生活费、营养费、住宿费也能主张
- 自己也有部分责任，误以为全部损失都要打折，把交强险这一层白让掉
- 家人不幸身故，死亡赔偿金、丧葬费、供养亲属的账算不出来

## 三个决定结果的关键变量
金额差距往往就出在这三个数上，问的时候必须问准：

1. **伤残等级**——决定赔偿系数。一级 100%，每降一级减 10%，十级 10%。一个等级之差，残疾赔偿金相差整整一年可支配收入的十倍。
2. **当地上年度居民人均可支配收入**——残疾赔偿金和死亡赔偿金的基数。2022 年司法解释修正后城乡标准已统一，不再区分农村户口和城镇户口，这一点很多人还停留在旧观念里。
3. **事故责任比例**——以交警的《道路交通事故认定书》为准。全责、主要责任（一般 70%）、同等责任（50%）、次要责任（30%）。

## 输入规范（逐项问全，缺一项就少一笔钱）
必填：
- 受害人年龄（决定赔偿年限：60 岁以下 20 年，60 岁以上每增 1 岁减 1 年，75 岁以上按 5 年）
- 伤情类型：构成伤残 / 死亡 / 仅治疗未评残
- 伤残等级（可多处，如七级加两个十级）
- 对方责任比例
- 事故发生地上年度居民人均可支配收入、居民人均消费支出

选填（有就问，直接影响金额）：
- 医疗费、后续治疗费金额
- 住院天数、营养期天数
- 误工天数与日收入（有固定收入按实际减少，无固定收入按人均可支配收入折算）
- 护理天数与护理日标准
- 交通费、住宿费、鉴定费、残疾辅助器具费
- 被扶养人：姓名、年龄、是未成年人还是无劳动能力的成年人、有几名扶养人分摊
- 商业三者险保额、财产损失金额

## 输出规范（每次按这个结构）
1. 基本情况：年龄、伤情、伤残系数怎么来的、赔偿年限、责任比例、使用的收入基数
2. 损失项目明细：项目、金额、算式、司法解释条文出处，逐项列全不合并，并标明属于"医疗费用类"还是"死亡伤残类"
3. 赔付分层结算：交强险限额内先行全额赔付 → 超出部分按责任比例 → 商业三者险与侵权人各自承担多少
4. 实际可获赔偿合计
5. 主张路径：事故认定书 → 伤残鉴定 → 证据归集 → 向保险公司主张 → 诉讼
6. 时效提醒与免责声明

## 一条最容易被忽略的规则（务必在输出里点明）
**交强险在责任限额内不按责任比例分摊，由保险公司先行全额赔付**；只有超出交强险限额的部分，才按事故责任比例由商业三者险和侵权人承担。

有责情形下的交强险限额是：死亡伤残 18 万、医疗费用 1.8 万、财产损失 2000 元。也就是说，即便受害人负主要责任，18 万以内的死亡伤残类损失照样能全额拿到。直接把损失总额乘以责任比例，是最常见也最亏钱的算法错误。

## 成果物（这是本技能的交付重点）
计算完成后，运行 `scripts/calculator.py` 的 `to_html_report()` 生成一份《交通事故人身损害赔偿测算报告》：
- A4 版式的自包含 HTML 文件，含损失明细表、赔付分层表、法律依据、主张路径、时效提醒、报告编号与生成时间
- 用户在浏览器中打开后按 Ctrl+P（Mac 为 Cmd+P）选择"另存为 PDF"，即得到一份可存档、可打印、可发给保险公司理赔员或律师的正式测算报告
- 包内 `sample-report.html` 是一份真实生成的样例，可直接查看版式

运行环境若装有 weasyprint 或 wkhtmltopdf，调用 `report.py` 的 `html_to_pdf()` 可一步直出 PDF；没有则自动回退到浏览器打印路径，不报错。

## 边界与免责
- 不代理案件、不介入理赔谈判、不承诺任何赔付结果
- 各省市的居民人均可支配收入、人均消费支出、精神损害抚慰金标准每年更新且差异较大，须以事故发生地或受诉法院所在地的上年度统计公报和当地裁判口径为准
- 伤残等级必须以有资质的司法鉴定机构出具的鉴定意见为准，用户自述等级仅供测算
- 涉及重伤、死亡、多方责任或对方拒赔的案件，明确建议委托执业律师
- 每次输出结尾附免责声明与"12348 法律援助热线"提示
