# 交通事故赔偿计算器

出了车祸，对方保险公司报来一个数字，你不知道这个数是高是低。这个技能把每一项都摊开算给你看，再告诉你实际能拿到多少。

## 它做什么

输入伤情、伤残等级、误工护理天数、被扶养人情况和事故责任比例，输出：

- 逐项损失明细，每一笔都附算式和司法解释条文出处
- 交强险与责任比例的分层结算，还原成"实际到手多少"
- 一份 A4 版式的测算报告，可打印、可存 PDF、可发给理赔员或律师

## 为什么需要它

大多数人在车祸赔偿上吃亏，不是因为不会争，是因为不知道该争什么。三个最常见的亏法：

**第一，把总损失直接乘以责任比例。** 交强险在限额内不打责任折扣，死亡伤残 18 万、医疗 1.8 万这两个额度是全额赔的。包里案例一算过一笔账，用错误算法比正确算法少了 55,310 元。

**第二，漏项。** 被扶养人生活费、营养费、住宿费、残疾辅助器具费，这些项目理赔员不会主动提。

**第三，评残等级没争取。** 一级之差就是十几万，多处伤情没有全部做进鉴定，附加指数也会白白丢掉。

## 包含什么

| 文件 | 内容 |
|------|------|
| SKILL.md | 技能定义、触发词、输入输出规范 |
| formulas.md | 全部公式速查：赔偿年限、伤残系数、逐项算法、交强险限额、分层结算顺序 |
| examples.md | 三个完整案例（十级伤残主责、多处伤残全责、死亡同责），数字均由引擎实跑 |
| scripts.md | 理赔沟通话术：明细怎么要、责任折扣怎么顶、误工费怎么争、什么时候该起诉 |
| disclaimer.md | 免责边界与地区差异说明 |
| scripts/calculator.py | 计算引擎，Python 3.8+，无第三方依赖 |
| scripts/report.py | A4 报告渲染器 |
| sample-report.html | 一份真实生成的报告样例 |

## 怎么跑

```bash
python scripts/calculator.py
```

会输出案例一的完整测算并在当前目录生成 HTML 报告。浏览器打开后按 Ctrl+P 选"另存为 PDF"即可。

## 不做什么

不代理案件，不介入理赔谈判，不承诺任何赔付结果。各省市的收入标准和精神抚慰金尺度每年更新且差异较大，测算结果是谈判和诉讼准备的参考基准，不是判决书。伤情严重或争议较大的案件，找执业律师。
