# 法规引用验证 (Legal Citation Verify)

对文章中引用的法律法规、政策文件、司法解释进行系统性多维度验证，确保每一条引用**真实存在、现行有效、条款准确、适用恰当**。

## 核心能力

- **6组18项检查**：来源溯源 → 元数据核验 → 效力与版本 → 法理一致性 → 适用条件 → 引用质量
- **两层验证模式**：底线层(G1-G3) 默认启用，深度层(G4-G6) 按需触发
- **6类引用分类路由**：法律/行政法规/部门规章/司法解释/政策文件/地方性法规，各有差异化验证管道
- **司法解释五步特殊路径**：母法追溯 → 替代版本 → 条款反查
- **政策文件官方门户优先**：优先从制定机关官方门户获取原文（国务院/部委/省级政府/自贸港政策库等）
- **引用归并 + 三阶段验证**：减少 75% API 调用量
- **三级工具降级链**：北大法宝(pkulaw) → 华宇元典(yuandian) → 官方 WebSearch

## 适用场景

- AI生成文章的法规引用准确性验证
- 政策报告/研究报告的法规引用核查
- 政府公文的法规依据验证
- 学术论文的法规引用校验
- 法律文书的引用准确性检查

## 验证准确率

| 维度 | 准确率 |
|:---|:---:|
| 硬错误检出（法规不存在/已废止/条款号编造） | 90%+ |
| 软判断（法理冲突/适用优先级） | 50-80%（需人工复核） |
| 综合置信度 | 75-85% |

## 安装方式

1. 下载本仓库
2. 将 `legal-citation-verify/` 文件夹放入 `~/.workbuddy/skills/`
3. 重启 WorkBuddy 即可在技能列表中看到"法规引用验证"

```bash
# 方式一：git clone
git clone https://github.com/LQ10178/legal-citation-verify.git ~/.workbuddy/skills/legal-citation-verify

# 方式二：下载 ZIP 后解压到 ~/.workbuddy/skills/
```

## 触发方式

在对话中写文章引用法规时，直接说"帮我验证这段引用"或提交包含法规引用的文档，技能会自动触发。

## 前置依赖

本技能依赖以下 MCP 连接器：

- **pkulaw**（北大法宝）：法规检索、条款原文、效力状态
- **yuandian-mcp**（华宇元典）：法律语义检索、幻觉检测
- **WebSearch**：官方 gov.cn 交叉验证

请确保在 WorkBuddy 中已连接上述工具。

## 免责声明

本技能输出不构成法律意见，仅供引用核查参考。对于法理一致性（G4）和复杂法律判断，建议由执业律师人工复核。
