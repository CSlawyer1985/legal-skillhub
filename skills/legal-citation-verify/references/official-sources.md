## 政策文件专用验证流程

**核心原则**：政策文件（含政府通知、意见、决定、公告、函等）的原文必须优先从**制定机关的官方门户网站**获取，不得依赖非官方转载或数据库摘要。

政策文件的特殊性在于：
- 发布渠道分散（各级政府官网、部门子站），数据库覆盖率远低于法律法规
- 有效期、废止状态等无统一标注，需从官方门户核实
- 内容可能被非官方渠道截取、改写、过时传播

### 政策文件验证优先级

```
第1优先级（强制）：制定机关官方门户原文
  ↓ 制定机关：国务院 → gov.cn
  ↓ 制定机关：海南省人民政府 → hainan.gov.cn
  ↓ 制定机关：海南自贸港 → wjk.hnftp.gov.cn（自贸港法规政策库）
  ↓ 制定机关：XX省政府 → XX.gov.cn（省级政府官网）
  ↓ 制定机关：XX市政府 → XX.gov.cn（市级政府官网）
  ↓ 制定机关：XX部委 → XX.gov.cn（部委官网）
  ↓ 无法定位官方门户
第2优先级：pkulaw / yuandian 数据库（标注"数据库来源，建议补充官方验证"）
  ↓ 数据库无收录
第3优先级：WebSearch 多源交叉检索（标注"多源互联网验证，建议补充官方原文"）
```

### 各级政府官网检索策略

**中央文件**：
```
检索词："{文件标题}" "{发文字号}" site:gov.cn
备用检索："{文件标题}" site:gov.cn/zhengce
```

**省级文件**：
```
检索词："{文件标题}" site:{省份域名}    # 如 site:hainan.gov.cn
备用检索："{文件标题}" "{发文机关}"
```

**市级/区级文件**：
```
检索词："{文件标题}" site:{市区域名}
备用检索：发文机关门户站内搜索
```

**海南自贸港特殊来源**：
```
优先渠道：wjk.hnftp.gov.cn（自贸港法规政策文件库）
检索方式：直接在该站内按标题/发文字号检索
说明：该库为海南自贸港法规政策的官方集中发布平台，
     覆盖自贸港条例、实施方案、配套政策等，
     对海南相关引用具有最高验证优先级
```

### 政策文件官方验证通过标准

| 标准 | 要求 |
|:---|:---|
| 来源域名 | 必须为 .gov.cn 域名（或经确认的政府官方子域名） |
| 内容完整性 | 原文包含文件标题、发文字号、发文机关、发布日期、正文 |
| 页面标识 | 页面明确标注为政府公开发布（含"政府信息公开""政策文件"等标识） |
| 内容一致性 | 数据库检索结果与官方门户原文一致（不一致时以官方门户为准） |
| 废止/替代核实 | 官方门户检索同主题文件，确认未被后续文件替代 |

### 降级处理

当官方门户无法找到原文时，不直接判定"错误"，而是执行降级验证：

1. **数据库验证（第2优先级）**：通过 pkulaw/yuandian 检索原文，确认基本元数据
2. **多源交叉验证（第3优先级）**：WebSearch 检索多个独立来源，比对一致性
3. **报告中标注**：明确标注"官方门户未找到原文，以下验证基于数据库/互联网来源"，降低置信度评分
4. **建议用户补充**：提示用户如有条件，可通过政务公开渠道申请获取原文

以下来源的法规文本**不能作为原文依据**，仅可作为检索线索：

| 来源类型 | 示例 | 风险 |
|----------|------|------|

| 百科类 | baike.baidu.com, zhihu.com | 用户编辑，可能不准确或过时 |
| 民间法律网站 | 找法网、华律网等 | 可能有解读偏差，非官方原文 |

| 转载媒体 | 新闻网站、自媒体 | 可能截取/修改原文 |

## 交叉验证逻辑

### 验证优先级

```
第1优先级：官方渠道原文（gov.cn 域名）
  ↓ 无法找到
第2优先级：权威数据库（pkulaw / yuandian）
  ↓ 无法找到
第3优先级：多源互联网检索（WebSearch）
  ↓ 多源一致
通过验证
  ↓ 多源不一致
标记"来源存疑"
```

### 交叉验证流程

对每条引用，执行以下交叉验证：

1. **数据库获取**（Pass 1 已完成）：通过 pkulaw/yuandian 获取法规原文和元数据
2. **官方验证**（G1-1 执行）：
   - 如果 LawRecord 中已有 `official_source_url` 且为 gov.cn → 直接通过
   - 如果无官方URL → WebSearch 检索 `"法规全称" site:gov.cn`
   - 找到官方页面 → WebFetch 获取页面内容，比对关键信息（标题、文号、施行日期、效力状态）
3. **比对结果处理**：
   - 数据库与官方信息一致 → 标记 `source_confidence: "high"`
   - 数据库与官方信息不一致 → 以官方信息为准，标记 `source_confidence: "medium"`
   - 官方来源未找到 → 标记 `source_confidence: "medium"`（仅数据库验证）
   - 数据库和官方均未找到 → 标记 `source_confidence: "low"`，仅互联网检索

### 抽检策略

对"通过"状态的引用，不需要逐条进行官方交叉验证（性能考虑）。抽检规则：

- 底线层验证全部通过 → 抽检 20% 的引用进行官方交叉验证
- 底线层有存疑项 → 存疑项 100% 进行官方交叉验证
- 政策文件类 → **100% 强制进行官方门户验证**（政策文件数据库覆盖较差，且原文必须从制定机关官方门户获取，不能仅依赖数据库摘要。详见"政策文件专用验证流程"章节）
- 司法解释 → 100% 进行官方交叉验证（因为母法有效性至关重要）
- 法规涉及重大行政处罚/刑事处罚 → 100% 进行官方交叉验证

## WebSearch 检索策略

### 官方来源检索模板

```
# 检索法规官方发布页面
"{法规全称}" site:npc.gov.cn          # 法律
"{法规全称}" site:gov.cn               # 行政法规/国务院文件
"{法规全称}" "废止" OR "失效" site:gov.cn  # 废止状态核实
"{司法解释全称}" site:court.gov.cn      # 司法解释
"{法规全称}" "{制定机关}" site:gov.cn   # 指定机关
```

### 政策文件检索模板

```
# 检索政策文件官方发布（优先从发文机关官网获取）
"{文件标题}" "{发文字号}" site:gov.cn                    # 中央政府门户
"{文件标题}" site:hainan.gov.cn                            # 海南省政府
"{文件标题}" site:wjk.hnftp.gov.cn                         # 海南自贸港法规政策库
"{文件标题}" site:{发文机关域名}                             # 发文机关官网
"{文件标题}" "废止" OR "失效" OR "停止执行"                  # 效力状态
"{文件标题}" 替代 OR 修订 OR 新版                           # 替代文件
"{文件标题}" 信息公开 site:gov.cn                           # 政务公开页面
```

### 注意事项

1. WebSearch 的 `site:` 限定不总是精确，需人工判断结果页面是否确实来自官方域名
2. 部分政府网站可能有多个域名（如 mnr.gov.cn 和 mlr.gov.cn 都指向自然资源部），需要识别
3. 地方性法规的官方来源为地方人大/政府网站，检索时使用 `"法规名称" site:{地方域名}`
4. 较老的法规可能没有电子版官方原文，此时以数据库为准，标注"官方原文未找到，以数据库为准"
