# 引用分类路由规则

## 分类优先级

分类按以下优先级判定，匹配到任一层级即停止向下匹配：

```
第1优先级：发文机关（最可靠）
第2优先级：文号格式（高可靠）
第3优先级：标题后缀（中可靠）
第4优先级：pkulaw 检索确认（兜底）
```

## 六类引用识别规则

### 1. 法律

**识别条件（满足任一）**：
- 发文机关为"全国人民代表大会"或"全国人民代表大会常务委员会"
- 文号格式为"主席令第X号"
- 标题以"法"结尾（如《中华人民共和国民法典》《中华人民共和国劳动法》）

**验证管道**：全量 G1-G6

**特殊处理**：
- 民法典、刑法等大型法典包含编/章/节/条四级结构，条款引用可能为"第X编第X章第X条"
- 检索时使用法规全称，不使用简称

### 2. 行政法规

**识别条件（满足任一）**：
- 发文机关为"国务院"
- 文号格式为"国务院令第X号"
- 标题以"条例"结尾且发文机关为国务院系统

**验证管道**：全量 G1-G6

**歧义处理**：
- "条例"既可能是行政法规（国务院）也可能是地方性法规（地方人大）。优先看发文机关：国务院 → 行政法规；省市人大 → 地方性法规
- 文号含"国务院令" → 一定是行政法规
- 无发文机关信息时 → 调用 pkulaw 确认

### 3. 部门规章

**识别条件（满足任一）**：
- 发文机关为国务院各部委（教育部/工信部/市场监管总局等）
- 文号格式为"XX部令第X号"或"XX局令第X号"
- 标题以"办法/规定/细则"结尾且发文机关为部委

**验证管道**：G1-G5 + 部分 G6（跳过 G6 的"兜底条款风险标记"，因为部门规章较少使用兜底条款）

**歧义处理**：
- "规定"既可能是部门规章也可能是规范性文件。区分标准：
  - 有"部令/局令"文号 → 部门规章
  - 仅有"X发〔XXXX〕X号"等公文文号 → 规范性文件（归入政策文件类）
- "实施细则"可能是行政法规的配套（国务院发布）或部门规章（部委发布），看发文机关

### 4. 司法解释

**识别条件（满足全部）**：
- 发文机关为"最高人民法院"或"最高人民检察院"（或两者联合）
- 标题包含"关于" + ("解释"或"规定"或"批复"或"决定")

**验证管道**：特殊五步路径 + G1-G6

**标题格式变体**：
- 标准格式：《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》
- 变体1：《最高人民法院关于审理XX案件适用法律若干问题的解释》
- 变体2：《最高人民法院关于XX的规定》
- 变体3：《最高人民检察院关于XX的批复》

**母法提取规则**：
1. 标题含"《XX法》" → 直接提取书名号内的法律名称
2. 标题含"XX法"但无书名号 → 提取"法"字前的文字 + "法"
3. 标题无明确法律名称 → 调用 LLM 从标题和首段内容中推断母法
4. LLM 推断失败 → 标记"母法未识别"，跳过步骤2-4，直接执行常规验证

**发文机关白名单**：
- 最高人民法院
- 最高人民检察院
- 最高人民法院 + 最高人民检察院（联合发布）
- 其他机关 → 不是司法解释，重新分类

### 5. 政策文件（规范性文件）

**识别条件（满足全部）**：
- 标题包含"通知/意见/决定/公告/函/纲要/方案/规划/通报"等公文类型词
- 无"部令/局令/主席令/国务院令"等法规文号
- 无条款结构（无"第X条"），或虽有条款但属于段落内编号

**验证管道**：G1-G3 + G5 + 官方门户强制验证（跳过 G2 条款精确性基础检查、G4 法理一致性基础检查、G6 兜底条款风险基础检查，但后置规则可自动升级管道）

**官方门户优先验证规则**（政策文件核心规则）：

政策文件与法律法规不同，其原文分散在各级政府门户网站，数据库覆盖率有限。验证时必须遵循以下规则：

1. **制定机关门户定位**：根据 LawRecord.`issuing_authority` 确定官方域名：
   - 国务院 → gov.cn（中华人民共和国中央人民政府）
   - 海南省人民政府 → hainan.gov.cn
   - 海南自贸港相关 → wjk.hnftp.gov.cn（自贸港法规政策库，最高优先级）
   - 其他省级政府 → XX.gov.cn
   - 市级/区级政府 → XX.gov.cn
   - 各部委 → 对应部委官网 .gov.cn

2. **检索策略**：WebSearch `"{文件标题}" "{发文字号}" site:{域名}`，确认原文存在

3. **验证通过标准**：原文来自 .gov.cn 域名 + 标题/文号/发文机关/正文完整 + 页面明确为政务公开发布

4. **降级处理**：官方门户未找到 → 降级为数据库/互联网验证，标注"官方门户未找到原文"

**后置规则——条款结构检测**：
分类完成后，对政策文件的引用文本和 Pass 1 获取的原文进行条款结构扫描：
1. 如果引用中包含"第X条""第X条第X款"等条款编号 → **自动启用 G2 条款精确性检查**（G2-1 条款号存在性 + G2 条款原文比对），验证管道升级为"G1-G3 + G5 + G2 条款精确性"
2. 如果原文中存在条款结构但引用未指定条款号 → 保持原管道，但在报告中标注"该文件含条款结构，建议补充具体条款号"
3. 如果引用和原文均无条款结构 → 保持原管道，G2 条款精确性检查跳过，改为段落级内容匹配

**触发示例**：
- 《国务院关于XX的若干规定》第5条 → 检测到条款号 → 启用 G2 条款精确性
- 《XX部关于XX的通知》第三段 → 无条款号，按段落匹配
- 《国务院关于XX的决定》（无条款引用）→ 保持原管道

**子类型识别**：
- 中央文件：中共中央/国务院联合发文 → 效力层级最高
- 国务院文件：国务院发文 → 效力层级高
- 部委文件：各部委发文 → 效力层级中
- 地方文件：地方政府发文 → 效力层级低，注意地域限制

**有效期判断规则**：
1. **优先从官方门户检索**：`"{文件标题}" "废止" OR "失效" OR "停止执行" site:{域名}` → 确认是否已废止（不可仅依赖数据库结论）
2. 搜索同主题后续文件 → 判断是否被替代（官方门户站内搜索优先）
3. 标题含"暂行/试行" + 发布超过5年 → 标记"效力待定"
4. 以上均无 → 默认"现行有效"，标注"未发现废止声明（官方门户检索确认）"

### 6. 地方性法规

**识别条件（满足任一）**：
- 发文机关为省/市/自治区人民代表大会或其常务委员会
- 文号格式为"XX省/市人大常委会公告第X号"
- 标题含省/市/自治区名称 + "条例/规定/办法"

**验证管道**：全量 G1-G6（G4 和 G5 加地方特殊性标记）

**地方特殊性标记**：
- G4：地方性法规与全国性法律冲突时，不是简单判定"无效"，而是标注"地方特别规定，需结合具体地域判断适用优先级"
- G5：强制检查适用地区是否与文章讨论的地域匹配

### 7. 其他（兜底分类）

**识别条件**：以上六类均不匹配

**验证管道**：G1 + G2 + G3 基础验证 + 人工复核提示

**处理方式**：
- 标记为"未识别类型"
- 尝试调用 pkulaw `search_article` 搜索法规名称，如果能找到则按数据库返回的类型重新分类
- 如果 pkulaw 也找不到 → 标记"法规存疑"，在报告中提示用户核实

## 模糊匹配与名称规范化

### 名称规范化流程

```
原始引用名称
  ↓
去除书名号、空格、特殊字符
  ↓
简称映射表匹配（如"劳动法" → "中华人民共和国劳动法"）
  ↓
pkulaw search_article 精确查询
  ↓ 匹配成功
返回标准全称
  ↓ 匹配失败
yuandian law_vector_search 语义检索
  ↓ 匹配成功
返回标准全称
  ↓ 匹配失败
标记"法规名称未确认"，进入兜底验证
```

### 变体写法归并

同一法规的不同写法归并为同一 CitationGroup：

| 写法 | 归并到 |
|------|--------|
| 《中华人民共和国劳动法》 | 中华人民共和国劳动法 |
| 《劳动法》 | 中华人民共和国劳动法 |
| 劳动法 | 中华人民共和国劳动法 |
| 《劳动法》(2018修正) | 中华人民共和国劳动法（2018修正版） |
| 《劳动法》（1994年） | 中华人民共和国劳动法（1994原版） |

注意：不同版本的同一法规不归并（如1994版和2018修正版分别建组），因为条款内容可能不同。

## 归并规则

### 归并键

```
merge_key = 标准全称 + "|" + 版本标识
```

版本标识规则：
- 无版本提示 → "latest"（默认最新版）
- 含"(XXXX修正)" → 该修正年份
- 含"(XXXX修订)" → 该修订年份
- 含"(XXXX年)" → 该年份版本

### 归并示例

```
归并前（5条引用）：
  cit_01: 《劳动法》第39条
  cit_02: 《中华人民共和国劳动法》第40条
  cit_03: 《劳动法》第42条
  cit_04: 《劳动合同法》第4条
  cit_05: 《劳动合同法》第八条

归并后（2个组）：
  group_01: 中华人民共和国劳动法 | latest
    → [cit_01(第39条), cit_02(第40条), cit_03(第42条)]
  group_02: 中华人民共和国劳动合同法 | latest
    → [cit_04(第4条), cit_05(第8条)]

检索次数：5次 → 2次
```

### 时间语境影响归并

时间语境的置信度分为三级，影响版本选择和归并策略：

**置信度：明确**（文章中有具体年份/日期）

示例：文章讨论的是2010年的事件，且引用了"劳动法"但未指定版本：
1. 检查劳动法的修订历史：1994年发布，2018年修正
2. 2010年时点适用的是1994年原版（2018年修正尚未发布）
3. 归并时版本标识设为"1994原版"而非"latest"
4. 在报告中提示"检测到文章时间语境为2010年（明确），已自动匹配1994年版劳动法"

**置信度：模糊**（文章中有"近年来""此前"等模糊时间词）

1. 默认使用最新版本进行归并和验证
2. 同时检索该法规是否有近年重大修订
3. 如果有重大修订 → 同时验证最新版本和最近一个旧版本，在报告中对比差异
4. 报告标注"时间语境：模糊（检测到'近年来'等表述），默认使用最新版本"

**置信度：未检测到**（文章中无时间线索）

1. 默认使用"latest"版本
2. 归并时版本标识设为"latest"
3. 报告标注"未检测到明确时间语境，默认使用最新版本"
4. 如果该法规近年有重大修订 → 额外标注修订提示（见 SKILL.md 时间语境感知部分的降级处理）
