## 目标

本行为准则（"准则"）的总体目标是改善内部市场的运作，促进以人为本和值得信赖的人工智能（"AI"）的采用，同时确保《宪章》所载的健康、安全、基本权利（包括民主、法治和环境保护）在欧盟境内免受 AI 有害影响的高水平保护，并依据《人工智能法案》第 1 条第(1)款支持创新。

为实现这一总体目标，本准则的具体目标是：

```
A. 作为证明遵守《人工智能法案》第 53 条和第 55 条规定义务的指导文件，同时承认遵守本准则不构成对这些义务在《人工智能法案》下合规的确凿证据。
```
```
B. 确保通用人工智能模型提供者遵守其在《人工智能法案》项下的义务，并使人工智能办公室能够评估选择依赖本准则证明其履行《人工智能法案》项下义务的通用人工智能模型提供者的合规情况。
```

## 序言

_鉴于：_

```
(a) 签署方认识到通用人工智能模型提供者在 AI 价值链中的特殊角色和责任，因为他们提供的模型可能构成一系列下游 AI 系统的基础，这些系统通常由需要充分了解模型及其能力的下游提供者提供，既为了将此类模型集成到其产品中，也为了履行其在《人工智能法案》项下的义务（见《人工智能法案》序言第 101 段）。
```
```
(b) 签署方认识到，在对通用人工智能模型进行微调或其他修改的情况下，修改模型的自然人或法人、公共机关、机构或其他主体成为修改后模型的提供者，承担通用人工智能模型提供者的义务，其在准则透明度章项下的承诺应限于该修改或微调，以符合相称性原则（见《人工智能法案》序言第 109 段）。在此背景下，签署方应考虑欧盟委员会的相关指引。
```
```
(c) 签署方认识到，在不超出本准则透明度章承诺的情况下，在向人工智能办公室或下游提供者提供信息时，可能需要考虑市场和技术发展，以便信息继续服务于其目的——允许人工智能办公室和国家主管机关履行其在《人工智能法案》项下的任务，并允许下游提供者将签署方的模型集成到 AI 系统中并履行其在《人工智能法案》项下的义务（见《人工智能法案》第 56 条第(2)款(a)项）。
```
```
本准则本章侧重于《人工智能法案》第 53 条第(1)款(a)和(b)项中适用于所有通用人工智能模型提供者的文档义务（不影响《人工智能法案》第 53 条第(2)款规定的例外），即涉及附件十一第一节和附件十二的义务。仅适用于具有系统性风险的通用人工智能模型提供者的附件十一第二节相关文档义务，由本准则安全与安保章措施 10.1 涵盖。
```

## 承诺 1 文档

```
法律文本：《人工智能法案》第 53 条第(1)款(a)项、第 53 条第(1)款(b)项、第 53 条第(2)款、第 53 条第(7)款及附件十一和附件十二
```
```
为履行《人工智能法案》第 53 条第(1)款(a)和(b)项的义务，签署方承诺按照措施 1.1 编制并保持最新的模型文档，按照措施 1.2 向拟将通用人工智能模型集成到其 AI 系统中的 AI 系统提供者（以下简称"下游提供者"）以及应请求（可能代表国家主管机关——在国家主管机关向人工智能办公室提出请求且该请求对于其行使《人工智能法案》项下监督任务（特别是评估基于通用人工智能模型构建的高风险 AI 系统的合规性——当系统提供者与模型提供者不同时^1）严格必要时）向人工智能办公室提供相关信息，并按照措施 1.3 确保所记录信息的质量、安全和完整性。依据《人工智能法案》第 53 条第(2)款，这些措施不适用于以免费开源许可发布、满足该条款规定条件的通用人工智能模型提供者，除非该模型是具有系统性风险的通用人工智能模型。
```
### 措施 1.1 编制并保持最新模型文档

```
签署方在将通用人工智能模型投放市场时，至少应已记录下文《模型文档表》中提及的所有信息（以下简称"模型文档"）。签署方可选择填写附录中提供的《模型文档表》以履行本承诺。
```
```
签署方将更新模型文档，以反映模型文档所含信息的相关变化，包括同一模型的更新版本，同时将模型文档的先前版本保留至模型投放市场后 10 年期满。
```
### 措施 1.2 提供相关信息

```
签署方在将通用人工智能模型投放市场时，将通过其网站公开披露（如无网站，则通过其他适当方式）联系信息，供人工智能办公室和下游提供者请求访问模型文档所含相关信息或其他必要信息。
```
```
签署方将依据《人工智能法案》第 91 条或第 75 条第(3)款提出的请求，就人工智能办公室履行其在《人工智能法案》项下任务或国家主管机关行使其在《人工智能法案》项下监督任务（特别是评估基于通用人工智能模型构建的高风险 AI 系统的合规性——当系统提供者与模型提供者不同时^2）所必需的模型文档一项或多项要素或任何附加信息，在人工智能办公室依据《人工智能法案》第 91 条第(4)款在其请求中指定的期限内，以最新形式提供所请求的信息。
```
(^1) 见《人工智能法案》第 75 条第(1)和(3)款及第 88 条第(2)款。
(^2) 见《人工智能法案》第 75 条第(1)和(3)款及第 88 条第(2)款。


签署方将向下游提供者提供最新模型文档中面向下游提供者的信息，但须遵守《人工智能法案》第 53 条第(7)款和第 78 条规定的保密保障和条件。此外，在不影响依据欧盟和国家法律遵守和保护知识产权及保密商业信息或商业秘密的需要的前提下，签署方将应下游提供者的请求提供附加信息，只要该等信息对于使其充分了解与将其集成到下游提供者 AI 系统相关的通用人工智能模型的能力和局限，并使这些下游提供者能够履行其依据《人工智能法案》的义务是必要的。签署方将在合理时限内提供此类信息，且除特殊情况外不迟于收到请求后 14 天。

鼓励签署方考虑是否可以将所记录的信息全部或部分向公众披露，以促进公开透明度。其中一些信息也可能以摘要形式作为训练内容摘要的一部分被要求提供——依据《人工智能法案》第 53 条第(1)款(d)项，提供者必须按照人工智能办公室将提供的模板公开发布该摘要。

### 措施 1.3 确保信息的质量、完整性和安全性

```
签署方将确保所记录的信息经过质量和完整性控制，作为《人工智能法案》义务合规的证据保留，并受到保护免受意外修改。在编制、更新和控制信息与记录的质量和安全时，鼓励签署方遵循既定协议和技术标准。
```
