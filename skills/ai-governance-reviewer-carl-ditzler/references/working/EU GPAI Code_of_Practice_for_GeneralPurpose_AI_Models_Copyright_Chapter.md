## 目标

本行为准则（"准则"）的总体目标是改善内部市场的运作，促进以人为本、值得信赖的人工智能（"AI"）的普及，同时确保对宪章所载健康、安全和基本权利（包括民主、法治和环境保护）提供高水平的保护，使其免受联盟内 AI 的有害影响，并依据《AI 法案》第 1 条第 1 款支持创新。

为实现这一总体目标，本准则的具体目标是：

```
A. 作为证明遵守《AI 法案》第 53 条和第 55 条所规定义务的指导文件，同时承认遵守本准则不构成《AI 法案》下这些义务已获遵守的确凿证据。
B. 确保通用人工智能模型提供者遵守其在《AI 法案》下的义务，并使 AI 办公室能够评估选择依赖本准则证明遵守其在《AI 法案》下义务的通用人工智能模型提供者的合规情况。
```

## 序言

_鉴于：_

```
(a) 本章旨在促进《AI 法案》第 53 条第 1 款第(c)项所规定义务的正确适用，依据该规定，将通用人工智能模型投放联盟市场的提供者必须制定遵守联盟版权和相关权利法的政策，特别是通过最先进技术识别并遵守权利人依据 (EU) 2019/790 号指令第 4 条第 3 款表达的保留权。签署方将实施本章所列措施以证明遵守《AI 法案》第 53 条第 1 款第(c)项，但遵守本准则不构成对联盟版权和相关权利法的遵守。
```
```
(b) 本章绝不影响联盟版权和相关权利法的适用和执行，该法律应由成员国法院并最终由欧洲联盟法院解释。
```
```
(c) 签署方特此承认，联盟版权和相关权利法：
```
```
(i) 由针对成员国的指令规定，就目前而言，2001/29/EC 号指令、(EU) 2019/790 号指令和 2004/48/EC 号指令最为相关；
```
```
(ii) 规定的专有权利具有预防性质，因此以事先同意为基础，除非适用例外或限制；
```
```
(iii) 在 (EU) 2019/790 号指令第 4 条第 1 款中规定了文本和数据挖掘的例外或限制，该例外或限制应在合法访问的条件下适用，且该款所述的作品和其他客体未被其权利人依据 (EU) 2019/790 号指令第 4 条第 3 款以适当方式明确保留。
```
```
(d) 本章中要求采取相称措施的承诺，应与提供者的规模相称、成比例，并适当考虑中小企业（包括初创企业）的利益。
```
```
(e) 本章不影响签署方与权利人之间授权使用作品和其他受保护客体的协议。
```
```
(f) 本章中为证明遵守《AI 法案》第 53 条第 1 款第(c)项义务而作出的承诺，是对提供者依据《AI 法案》第 53 条第 1 款第(d)项所负义务的补充，该项义务要求提供者按照 AI 办公室将提供的模板，编制并公开提供关于签署方用于训练其通用人工智能模型的内容的充分详细摘要。
```

## 承诺 1 版权政策

```
法律文本：《AI 法案》第 53 条第 1 款第(c)项
```
```
(1) 为证明遵守《AI 法案》第 53 条第 1 款第(c)项关于制定遵守联盟版权和相关权利法政策的义务，特别是通过最先进技术识别并遵守依据 (EU) 2019/790 号指令第 4 条第 3 款表达的保留权，签署方承诺制定、保持更新并实施此类版权政策。下文各项措施不影响对联盟版权和相关权利法的遵守。它们规定了签署方可以藉以证明遵守为其投放联盟市场的通用人工智能模型制定版权政策义务的承诺。
```
```
(2) 此外，签署方仍负责在相关成员国领土内实施任何与版权相关的行为之前，核实其版权政策中所载的下述各项措施符合成员国对联盟版权和相关权利法的实施，特别是但不限于 (EU) 2019/790 号指令第 4 条第 3 款，因为未这样做可能依据联盟版权和相关权利法产生责任。
```
#### 措施 1.1 制定、保持更新并实施版权政策

```
(1) 签署方将为其投放联盟市场的所有通用人工智能模型制定、保持更新并实施一项遵守联盟版权和相关权利法的政策。签署方承诺在单一文件中描述该政策，纳入本章所列各项措施。签署方将在其组织内为实施和监督该政策分配责任。
```
```
(2) 鼓励签署方公开提供并保持更新其版权政策的摘要。
```
#### 措施 1.2 在抓取万维网时仅复制和提取合法可访问的受版权保护内容

```
(1) 为帮助确保签署方在使用网络爬虫或委托他人使用网络爬虫为 (EU) 2019/790 号指令第 2 条第 2 款定义的文本和数据挖掘及训练其通用人工智能模型的目的而抓取或以其他方式汇编数据时，仅复制和提取合法可访问的作品和其他受保护客体，签署方承诺：
a) 不规避 2001/29/EC 号指令第 6 条第 3 款定义的有效技术措施，这些措施旨在防止或限制针对作品和其他受保护客体的未经授权行为，特别是尊重订阅模式或付费墙施加的任何技术性拒绝或访问限制，以及
b) 将其网络抓取排除在向公众提供内容、且在被抓取时已被欧盟和欧洲经济区法院或公共机构认定为持续且反复地以商业规模侵犯版权和相关权利法的网站之外。
```

```
为遵守本措施，由欧盟和欧洲经济区相关机构发布的这些网站清单的超链接动态清单将在欧盟网站上公开提供。
```
#### 措施 1.3 在抓取万维网时识别并遵守权利保留

```
(1) 为帮助确保签署方在使用网络爬虫或委托他人使用网络爬虫为 (EU) 2019/790 号指令第 2 条第 2 款定义的文本和数据挖掘及训练其通用人工智能模型的目的而抓取或以其他方式汇编数据时，通过最先进技术识别并遵守依据 (EU) 2019/790 号指令第 4 条第 3 款表达的机器可读权利保留，签署方承诺：
a) 采用读取并遵循按照互联网工程任务组（IETF）请求评论第 9309 号规定的机器人排除协议（robots.txt）所表达指令的网络爬虫，以及 IETF 证明 AI 提供者和内容提供者（包括权利人）在技术上可行且可实施的该协议的任何后续版本，以及
b) 识别并遵守依据 (EU) 2019/790 号指令第 4 条第 3 款表达权利保留的其他适当机器可读协议，例如基于资产或位置的元数据，这些协议要么已由国际或欧洲标准化组织采纳，要么属于最先进（包括技术上可实施的）且被权利人广泛采用，同时考虑不同文化部门，并通过在欧盟层面推动的、有权利人、AI 提供者和其他相关利益相关者参与的、基于善意讨论的包容性过程普遍达成一致，作为更直接的解决方案，同时预期标准的发展。
```
```
(2) 本承诺不影响权利人依据 (EU) 2019/790 号指令第 4 条第 3 款以任何适当方式（例如就公开可在线获取的内容采用机器可读手段，或通过其他方式）明确保留作品和其他受保护客体用于文本和数据挖掘目的的权利。
```
```
此外，本承诺不影响联盟版权和相关权利法对第三方从互联网抓取或爬取、并由签署方用于文本和数据挖掘及训练其通用人工智能模型目的的受保护内容的适用，特别是关于依据 (EU) 2019/790 号指令第 4 条第 3 款表达的权利保留。
```
```
(3) 鼓励签署方支持本措施第一段第(a)和(b)项所述进程，并自愿与权利人和其他相关利益相关者进行善意讨论，旨在制定适当的机器可读标准和协议，以表达依据 (EU) 2019/790 号指令第 4 条第 3 款的权利保留。
```

```
(4) 签署方承诺采取适当措施，使受影响的权利人能够获得关于所使用的网络爬虫、其 robots.txt 功能以及签署方为识别和遵守依据 (EU) 2019/790 号指令第 4 条第 3 款表达的权利保留而采取的其他措施的信息，办法是在抓取时公开此类信息，并提供手段使受影响的权利人在此类信息更新时自动收到通知（例如通过聚合网络馈送），且不影响 2004/48/EC 号指令第 8 条规定的知情权。
```
```
(5) 同时提供 (EU) 2022/2065 号条例第 3 条第(j)项定义的在线搜索引擎或控制此类提供者的签署方，鼓励采取适当措施，确保其在文本和数据挖掘活动及本措施第一段所述通用人工智能模型训练背景下对权利保留的遵守，不会直接对其搜索引擎中已表达权利保留的内容、域名和/或 URL 的索引产生不利影响。
```
#### 措施 1.4 降低侵犯版权输出的风险

```
(1) 为降低下游 AI 系统（其中集成了通用人工智能模型）生成可能侵犯受联盟版权或相关权利法保护的作品或其他客体权利的输出之风险，签署方承诺：
a) 实施适当且相称的技术保障措施，防止其模型以侵权方式生成复制受联盟版权和相关权利法保护的训练内容的输出，以及
b) 在其可接受使用政策、条款和条件或其他等效文件中禁止对模型的版权侵权使用，或者在依据自由和开源许可证发布的通用人工智能模型的情况下，在随附模型的文档中提醒用户禁止对模型的版权侵权使用，且不影响许可证的自由和开源性质。
```
```
(2) 本措施无论签署方是否将模型纵向集成到其自身的 AI 系统中，或该模型是否基于合同关系提供给另一实体，均适用。
```
#### 措施 1.5 指定联系点并支持投诉的提出

```
(1) 签署方承诺指定一个用于与受影响权利人电子通信的联系点，并提供易于获取的关于该联系点的信息。
(2) 签署方承诺建立一种机制，使受影响的权利人及其授权代表（包括集体管理组织）能够以电子方式提交关于签署方不遵守其本章承诺的、足够精确且充分佐证的投诉，并提供易于获取的关于该机制的信息。签署方将以勤勉、非任意的方式并在合理时间内处理投诉，除非投诉明显无依据或签署方已对同一权利人的相同投诉作出过回应。本承诺不影响依据联盟和国内法执行版权和相关权利的可用的措施、救济和制裁。
```
