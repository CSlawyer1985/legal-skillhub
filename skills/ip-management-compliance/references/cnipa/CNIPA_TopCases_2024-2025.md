### 案例1：磷酸芦可替尼发明专利权无效宣告请求案

| 项目 | 内容 |
|------|------|
| **专利号** | ZL200880102903.3 |
| **决定号** | 第580173号 |
| **结果** | **维持专利权有效** |
| **技术领域** | 医药（JAK激酶抑制剂） |
| **核心特征** | 芦可替尼的三种盐形式（马来酸盐、硫酸盐、磷酸盐） |
| **争议焦点** | 优先权是否成立、化合物充分公开 |
| **无效理由** | 优先权文件未记载JAK抑制活性具体实验数据 |
| **证据组合** | 证据1（优先权文件）+ 证据2（US申请，公开日晚于优先权日） |
| **关键论据** | 优先权文件通过引证已隐含表明芦可替尼具备JAK抑制活性；补充数据属于"确证"而非"新增" |
| **法律依据** | 《专利法》第29条第1款（优先权）、充分公开三要素 |
| **典型意义** | 优先权"相同主题"认定：引证文献效力、"从旧兼有利"原则、确证vs新增效果 |

**证据组合策略启示**：
- 医药专利无效中，优先权文件的引证结构是关键
- 活性数据补充需区分"确证"与"新增"

| 项目 | 内容 |
|------|------|
| **专利号** | ZL200980104713.X |
| **决定号** | 第568709号 |
| **结果** | **宣告专利权全部无效** |
| **技术领域** | 医药（前列腺癌治疗药物） |
| **核心特征** | 地加瑞克 + S-ALP水平限定 + 给药方案 |
| **争议焦点** | 权利要求保护范围、创造性判断 |
| **无效理由** | 缺乏创造性（第22条第3款） |
| **证据组合** | 最接近现有技术（III期临床数据，转移期患者约20%，97.2%应答率）+ 公知常识（S-ALP为疾病进展指标） |
| **关键论据** | 现有技术已公开地加瑞克对转移期前列腺癌有效；S-ALP作为指标公知；所属领域技术人员有动机验证 |
| **法律依据** | 《专利法》第22条第3款（创造性） |
| **典型意义** | 制药用途权利要求的创造性判断：给药剂量对制药用途无实质性限定；疾病分期限定具有限定作用 |

**证据组合策略启示**：
- 医药用途专利：疾病分期 + 生理指标组合时，需证明技术启示
- 公知常识在填补证据链中的作用

- 机械领域：找准最接近现有技术是关键

- 通信标准专利：代际差异可能构成结合障碍

| **专利号** | ZL201580047368.6 |
| **决定号** | 第581990号 |
| **结果** | **宣告专利权全部无效** |
| **技术领域** | 医药（晶型药物） |
| **核心特征** | 呋喹替尼特定晶型形式 |
| **争议焦点** | 使用公开认定；补交实验数据采纳；晶型创造性判断 |

- 晶型专利：证据链完整性是关键

### 案例7：玩具（泡泡战车）外观设计专利权无效宣告请求案 ⭐

| 项目 | 内容 |
|------|------|
| **专利号** | ZL202230164195.9 |
| **决定号** | 第567442号 |
| **结果** | **维持专利权有效** |
| **技术领域** | 外观设计（玩具） |
| **涉案产品** | 泡泡战车玩具 |
| **争议焦点** | 组合对比是否成立；是否属于现有设计的简单拼凑 |
| **无效理由** | 缺乏明显区别（第23条第2款） |
| **证据组合** | 组合对比（具体对比设计未详列） |
| **关键论据** | 组合后设计需形成外观和功能协调统一的整体，不能仅简单拼凑；组合需符合一般消费者认知 |
| **法律依据** | 《专利法》第23条第2款 |
| **典型意义** | 外观设计组合对比的成立条件：物理/视觉可自然区分 + 用途功能相近/有组合先例 + 组合手法符合一般消费者认知 |

**证据组合策略启示**：
- 外观设计组合对比三要素：
  1. 设计特征可自然区分
  2. 用途功能相近或有组合先例
  3. 组合手法无需较大再设计
