## Excel版本结构建议

### Sheet 1: 风险登记册

| 列名 | 类型 | 说明 |
|------|------|------|
| 风险ID | 文本 | 自动编号 |
| 风险类别 | 下拉 | 侵权/被侵权/无效/确权/流失/时限/权属/海外 |
| 风险描述 | 文本 | 具体风险描述 |
| 涉及专利/产品 | 文本 | 关联的专利号或产品名称 |
| 可能性(P) | 数字 | 1-5 |
| 影响程度(I) | 数字 | 1-5 |
| 风险值 | 公式 | =P*I |
| 风险等级 | 公式 | 根据风险值自动判断 |
| 应对策略 | 下拉 | 规避/降低/转移/接受 |
| 具体措施 | 文本 | 详细的应对措施 |
| 责任人 | 文本 | 负责人员 |
| 状态 | 下拉 | 待处理/处理中/已完成/已关闭 |
| 更新日期 | 日期 | 最后更新时间 |

### Sheet 2: 风险矩阵热力图

- 使用条件格式按风险值(1-25)设置颜色
- 极高(红) → 高(橙) → 中(黄) → 低(蓝) → 极低(绿)

### Sheet 3: 监控计划

| 列名 | 类型 | 说明 |
|------|------|------|
| 监控频次 | 下拉 | 每月/每季度/每年度 |
| 监控内容 | 文本 | 监控的具体内容 |
| 监控方式 | 文本 | 监控方法 |
| 预警阈值 | 文本 | 触发预警的条件 |
| 责任人 | 文本 | 监控负责人 |

### Sheet 4: 统计仪表板

- 各类别风险数量饼图
- 风险等级分布柱状图
- 风险趋势折线图
