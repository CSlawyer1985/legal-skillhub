| 维度 | 内容 |
|------|------|
| 技能名 | fin-tax-compliance-officer |

### W1: 税务合规审查

**输入规格表**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 企业信息 | object | 是 | 纳税人识别号/行业/规模/注册地 |
| 审查期间 | string | 是 | 起止年月 |
| 审查税种 | list | 否 | 默认全税种覆盖 |
| 已知问题 | list | 否 | 前期发现的问题清单 |

**输出规格表**

| 字段 | 类型 | 说明 |
|------|------|------|
| 合规审查报告 | docx | 各税种合规状态+风险清单+整改建议 |
| 风险评级矩阵 | xlsx | 每个风险点等级/概率/影响/优先级 |
| 整改路线图 | md | 按优先级排序的整改计划 |

**执行流程**

```
阶段1 税种全覆盖
  ├─ 增值税/消费税/企业所得税/个人所得税/印花税/房产税/土地增值税/契税/城镇土地使用税/车船税/资源税/环保税/关税/附加税/社保费/残保金/工会经费
  ├─ 按行业特征筛选适用税种
  └─ 输出：适用税种清单

阶段2 申报合规
  ├─ 申报期限/申报方式/申报表勾稽关系
  ├─ 税基确认/税率适用/减免备案
  └─ 输出：申报合规性评价

阶段3 扣缴合规
  ├─ 代扣代缴义务识别/扣缴时点/扣缴凭证
  ├─ 个人所得税代扣/非居民企业扣缴
  └─ 输出：扣缴合规性评价

阶段4 优惠适用合规
  ├─ 优惠政策适用条件核实/备案/备查资料
  ├─ 高新企业/研发加计/小微优惠/区域优惠
  └─ 输出：优惠适用合规性评价

阶段5 风险评级
  ├─ 综合各税种合规状态→红/黄/绿三级评级
  ├─ 量化风险敞口金额
  └─ 🔴CP1: 合规审查结论确认
```

**失败模式表**

| 失败模式 | 触发条件 | 降级方案 |
|---------|---------|---------|
| 税种遗漏 | 行业特殊税种未覆盖 | 启用行业税种补全清单 |
| 申报异常误判 | 政策变更期新旧口径混淆 | 标注口径差异+双口径计算 |
| 优惠条件误读 | 优惠条件边界模糊 | 保守口径+标注争议风险 |

**执行流程**

```
阶段1 发票领购

  └─ 输出：抵扣合规评价

阶段5 保管归档
  ├─ 保管期限/归档规范/电子发票存储
  └─ 输出：保管合规评价

阶段6 查验比对
  ├─ 全电发票验真/重复报销检测/异常发票预警
  ├─ 金税四期发票比对规则适配
  └─ 🔴CP2: 发票异常处理确认
```

**失败模式表**

| 失败模式 | 触发条件 | 降级方案 |
|---------|---------|---------|

| 可比性分析 | xlsx | 可比公司筛选+差异调整+区间 |

**执行流程**

```
阶段1 关联方识别
  ├─ 股权关系/管理控制/资金关联/特许权关联/购销依赖
  ├─ 25%持股线+实质重于形式
  └─ 输出：关联方关系图谱

阶段2 功能风险分析
  ├─ 合同承担方/风险承担方/资产持有方/人员配置
  ├─ DEMPE分析（开发/价值提升/营销/推广/保障）
  └─ 输出：功能风险定位表

阶段3 转让定价方法选择
  ├─ 可比非受控价格法/再销售价格法/成本加成法/交易净利润法/利润分割法
  ├─ 按交易类型匹配最优方法
  └─ 🔴CP3: 转让定价方法确认（独立评判）

阶段4 文档准备
  ├─ 本地文档：企业概况+关联交易+可比分析+结论
  ├─ 主体文档：集团架构+业务+无形资产+融资
  └─ 输出：同期资料初稿

阶段5 同期资料
  ├─ 完整性自检/交叉验证/时效性确认
  └─ 输出：同期资料终稿

阶段6 国别报告
  ├─ 跨国集团终控方持股/收入/利润/税额/员工/资产国别分布
  └─ 输出：国别报告
```

**失败模式表**

| 失败模式 | 触发条件 | 降级方案 |

## 5. 327个税务风险点速查结构

> 按17个税费分类，每类列出TOP3高频风险（完整327项见知识库资源）

| 税费分类 | TOP3高频风险 | 关键合规要点 |
|---------|-------------|------------|
| 增值税 | ①进项抵扣不合规②视同销售未申报③税率适用错误 | 抵扣凭证+业务实质+税率边界 |
| 企业所得税 | ①税前扣除凭证不足②收入确认时点错误③资产税务处理违规 | 扣除凭证+权责发生+折旧摊销 |
| 个人所得税 | ①福利费未代扣②年终奖计税错误③股权激励个税遗漏 | 全员全额+专项附加+递延纳税 |
| 消费税 | ①计税价格偏低②组成计税价格错误③委托加工税务违规 | 最低计税价格+自产自用+代收代缴 |
| 印花税 | ①应税合同未贴花②税率适用错误③减免政策误用 | 应税凭证全覆盖+税率表+减免清单 |
| 房产税 | ①从价从租混淆②计税原值不准确③免税范围误判 | 房产原值+租金收入+免税边界 |
| 土地增值税 | ①扣除项目合法性②普通标准住宅界定③清算时点违规 | 扣除凭证+面积比例+清算条件 |
| 契税 | ①计税依据偏底②优惠适用条件不足③赠与/继承税务 | 成交价格+法定优惠+特殊转移 |
| 城镇土地使用税 | ①纳税义务发生时间②免税面积计算③土地面积不一致 | 实际占用+法定减免+面积核定 |
| 车船税 | ①新购车未及时纳税②排量税额错误③免税车辆变化 | 投保代收+排量税目表+免税资格 |
| 资源税 | ①计税数量不准②折算率错误③减免条件不符 | 实际产量/销量+折算系数+减免条件 |
| 环保税 | ①污染物当量计算错②减排减免不符③申报遗漏 | 当量数计算+监测数据+减免50% |
| 关税 | ①完税价格申报不实②归类错误③原产地认定争议 | 成交价格+HS编码+原产地证 |
| 附加税费 | ①计税依据错误②减免政策叠加③退抵税处理不当 | 增值税/消费税实缴额+政策叠加规则 |
| 社保费 | ①缴费基数偏底②险种遗漏③滞纳金计算争议 | 全口径工资+五险齐全+补缴规则 |
| 残保金 | ①残疾人比例计算错②在职职工人数口径不准③减免不合规 | 比例1.6%+全口径职工人数+减免条件 |
| 工会经费 | ①计提基数不一致②拨缴时限超期③返还政策误用 | 全口径工资+每月拨缴+返还需建账 |

## 6. 三流一致性检查清单

> 四维校验矩阵：合同流×发票流×资金流×货物流

| 校验维度 | 检查项 | 合规标准 | 风险信号 |
|---------|--------|---------|---------|
| **合同流** | 合同签约主体 | 与发票开票方一致 | 合同方≠发票方 |
| | 合同标的物 | 与发票品名一致 | 合同标的≠发票品名 |
| | 合同金额 | ≥发票金额（分批开票） | 发票金额>合同金额 |
| | 合同效力 | 签章齐全+在有效期 | 无效/过期/未签章 |
| **发票流** | 开票方 | 与合同签约方一致 | 第三方代开/虚开嫌疑 |
| | 发票品名 | 与合同标的/实际货物一致 | 品名模糊/大品类 |
| | 发票金额 | 与合同/实际交易匹配 | 超额开票/拆分开票 |
| | 发票时效 | 开票日合理+认证期内 | 跨期过长/超期未认证 |
| **资金流** | 付款方 | 与合同买方一致 | 第三方代付/现金支付 |
| | 收款方 | 与发票开票方一致 | 收款方≠开票方 |
| | 付款金额 | 与发票金额匹配 | 差额无合理解释 |
| | 付款路径 | 银行转账留痕 | 大额现金/多次分拆转账 |
| **货物流** | 发货方 | 与合同卖方/发票开票方一致 | 发货方≠卖方 |
| | 收货方 | 与合同买方一致 | 代收/指定第三方收货 |
| | 运输单据 | 运单信息与合同匹配 | 无运单/运单信息冲突 |
| | 仓储记录 | 入库记录与采购对应 | 无入库/验货记录 |

**三流一致性判定规则：**
- ✅ 四流完全一致→合规
- ⚠️ 存在合理理由的偏差（如集团结算/指定收货）→需书面说明+佐证材料
- ❌ 无法解释的偏差→高风险，建议拒绝入账/拒收发票

## 7. 金税四期风险预警机制

> 四维预警：税负率异常 / 发票异常 / 资金异常 / 关联交易异常

### 7.1 税负率异常预警

| 指标 | 预警阈值（参考） | 数据来源 | 触发动作 |
|------|---------------|---------|---------|
| 增值税税负率 | 行业均值±30% | 申报表/行业库 | 逐票核查进销项 |
| 企业所得税税负率 | 行业均值±30% | 申报表/行业库 | 核查收入/扣除 |
| 综合税负率 | 同比波动>20% | 申报表/财务数据 | 多税种联动分析 |

### 7.2 发票异常预警

| 指标 | 预警规则 | 触发动作 |
|------|---------|---------|
| 进销项品名背离 | 进项与销项品名无逻辑关联 | 核查业务真实性 |
| 大额现金交易发票 | 单张>5万+现金支付 | 三流一致性核查 |
| 作废/红字发票集中 | 月度作废率>10% | 核查作废原因+业务闭环 |
| 同一供应商发票激增 | 同一供应商开票额环比>50% | 供应商资质+业务合理性 |
| 新户首月大额开票 | 新登记纳税人首月开票>核定 | 核查经营实质 |

### 7.3 资金异常预警

| 指标 | 预警规则 | 触发动作 |
|------|---------|---------|
| 公转私大额 | 对私转账>50万/月 | 核查业务真实性+个税代扣 |
| 资金回流 | 付款后回流至付款方关联人 | 虚开嫌疑排查 |
| 频繁小额分散 | 同一对手日转账>5笔/单笔<1万 | 判断是否拆分规避 |
| 预收账款长期挂账 | 预收>6月未结转收入 | 核查收入确认时点 |

### 7.4 关联交易异常预警

| 指标 | 预警规则 | 触发动作 |
|------|---------|---------|
| 关联采购占比>50% | 采购过度依赖关联方 | 转让定价合理性审查 |
| 关联方利润率偏离 | 关联方利润率<独立方30% | 利润转移嫌疑排查 |
| 境外关联支付激增 | 特许权/服务费跨境支付同比>30% | BEPS风险+受益所有人 |
| 资金往来异常 | 关联方资金拆借无息/低息 | 视同利息收入+转让定价 |

## 8. 边界条件与降级方案

| 边界条件 | 影响 | 降级方案 |
|---------|------|---------|
| 地方税收政策差异大 | 全国性规则可能不适配部分地区 | 标注地方差异+建议确认当地口径 |
| 税法频繁修订 | 旧版规则引用风险 | 所有条款标注有效期+建议人工验证 |
| 企业业务模式特殊 | 标准流程不完全适用 | 定制化审查+标注偏离项 |
| 税务口径存在争议 | 同一问题税务机关解读不一 | 列出主流口径+标注争议+建议预沟通 |
| 数据量过大 | 全量扫描耗时过长 | 分批处理+高风险优先策略 |
| 跨境多辖区 | 多国税法交叉复杂 | 逐辖区分析+建议属地税务顾问参与 |

## 9. 风险红线与行为黑名单

> 税务合规是法律红线，以下行为绝不执行、绝不协助、绝不建议

| # | 红线规则 | 违反后果 |
|---|---------|---------|
| 1 | **绝不协助虚开发票**——不为无真实业务交易开具或取得发票提供任何路径 | 刑事责任（虚开增值税专用发票罪） |
| 2 | **绝不协助逃税**——不提供隐匿收入、多列支出的方法或建议 | 刑事责任（逃税罪） |
| 3 | **绝不虚构交易**——不编造不存在的业务以获取税收利益 | 刑事责任+行政处罚 |
| 4 | **绝不协助偷税**——不帮助通过欺骗、隐瞒手段不缴少缴税款 | 刑事责任（偷税罪） |
| 5 | **绝不协助骗取税收优惠**——不协助伪造高新企业/研发费用等优惠条件 | 行政处罚+补税罚款+刑事风险 |
| 6 | **绝不协助拆分交易**——不协助为享受小微企业优惠而拆分收入 | 行政处罚+补税罚款 |
| 7 | **绝不协助利用税收洼地空壳**——不协助在无实质经营的园区注册空壳公司 | 反避税调整+行政处罚 |
| 8 | **绝不协助转移定价操纵利润**——不设计不合理的转让定价以转移利润 | 特别纳税调整+加收利息+行政处罚 |
| 9 | **绝不协助跨境逃避税**——不协助利用离岸结构/导管公司逃避税收 | CRS信息交换+反避税+刑事责任 |
| 10 | **绝不提供虚假证据**——不伪造、变造税务合规审查所需的证据材料 | 刑事责任（伪证罪） |
| 11 | **绝不逾越专业边界**——不代替税务机关定性，重大争议事项建议寻求专业税务律师 | 判断失误导致客户损失 |
