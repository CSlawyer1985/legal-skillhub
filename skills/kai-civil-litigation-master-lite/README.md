## 使用方法

### 安装与导入

1. 将整个 `Kai·民商事诉讼律师助手` 文件夹打包为 ZIP 文件
2. 在您的 AI 助手平台中进入 Skill 管理界面
3. 选择"导入 Skill"或"上传 Skill"
4. 上传 ZIP 文件

### 使用 Skill

上传后，AI 助手将根据 SKILL.md 中的规则自动处理民商事案件相关任务。

**核心模块包括：**

| 模块 | 功能 |
|------|------|
| 案件立项建档 | 整理案件文件、建立标准文件夹结构 |
| 案情梳理 | 梳理时间轴、识别法律关系 |
| 诉讼方案 | 请求权基础分析、动态攻防推演 |
| 文书起草 | 起诉状、答辩状、上诉状等（严格遵循通用格式标准） |
| 证据整理 | 要件分组、证明力评级 |
| 庭审准备 | 模拟法庭、庭审提纲 |
| 执行与归档 | 申请执行、结案归档、复盘总结 |

## 核心特性

1. **请求权基础分析法**：以"谁得向谁，依据何种法律规范，主张何种权利"为思考起点
2. **要件审判方法**：将生活事实提炼为要件事实，证据与要件严格对应
3. **格式统一原则**：所有文书严格遵循通用排版格式标准，确保专业规范
4. **八个一致自检**：请求、依据、要件、事实、证据、结论、论证、形式的全面校验
5. **文档同步机制**：SKILL.md更新时自动同步更新README.md、CHANGELOG.md和对应的references规则文件，确保整个文档体系一致性
6. **最高人民法院文书样式全面参考**：整合最高人民法院官方网站（https://www.court.gov.cn/susong.html）发布的"当事人参考民事诉讼文书样式"（22个类别），为各类文书制作提供权威样式参考

## 版本管理

为确保每次技能文档修改后，界面显示的技能名称版本号同步更新，本技能包提供自动化版本管理工具。

### 版本管理脚本
- **位置**：`scripts/version_manager.py`
- **功能**：
  - `--current`：显示当前版本号
  - `--bump minor --desc "更新描述"`：递增版本号并添加变更日志
  - 支持 major/minor/patch 三种递增类型（语义化版本控制）

### 自动化工作流
1. **AI 操作规范**：每次修改技能文件后，必须运行版本管理脚本
2. **版本递增规则**：
   - **major**：重大架构变更，向后不兼容
   - **minor**：新增功能，向后兼容（如本次文档管理三场景集成）
   - **patch**：bug修复、小优化
3. **文件自动更新**：
   - SKILL.md（version 字段、名称字段、主标题）
   - README.md（标题版本号）
   - CHANGELOG.md（添加新条目框架）

### 使用示例
```bash
cd ~/.workbuddy/skills/KAI·民商事诉讼律师助手
python3 scripts/version_manager.py --current  # 显示当前版本
python3 scripts/version_manager.py --bump minor --desc "新增功能描述"
```

详细说明见 [scripts/版本管理使用说明.md](./scripts/版本管理使用说明.md)。

### 强制读取技能文档规则
**在执行任何任务之前，都必须先调取阅读子技能目录（`sub-skills/`）下面的对应技能文档。**

#### 核心要求：
1. **前置读取**：每次执行子技能任务前，必须根据任务类型从 `sub-skills/` 目录读取对应的 `*_SKILL.md` 文件

3. **死刑条款**：若未加载skill就执行任务，等同于违反死刑条款。必须立即停止，读取skill后再继续

- **SKILL.md**：在"模块路由规则"和"执行前强制检查"部分明确此要求
- **所有子技能文件**：已包含"执行前强制检查（Step 0）"，其中第一条即为"加载本skill"

#### 设计目的：
- 确保AI严格遵循最新技能规则执行任务
- 避免因技能更新未同步导致的执行偏差
- 提高任务执行的准确性和一致性
