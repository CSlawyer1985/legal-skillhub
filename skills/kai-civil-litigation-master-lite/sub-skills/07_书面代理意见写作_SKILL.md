# 书面代理意见写作

## 强制约束

1. **正文必须围绕庭审归纳的争议焦点展开，严格写成流水账**。
2. **每个争议焦点须使用加粗段落式长句作为论点标题**，明确表明立场（如"**一、案涉合同系双方真实意思表示，合法有效**"）。Markdown层级（`#`/`##`/`###`）根据实际需要灵活选用，不必一律固定为三级标题；论点标题的格式核心在于**加粗段落式长句**，而非具体Markdown层级。
3. **每个论点必须包含完整的逻辑闭环**：法律依据 + 案件事实与证据 + 针对性反驳 + 结论。缺一不。
4. **必须专门回应法官在庭审中的重点发问**和对方在庭审中提出的新主张。
5. **严格出现"关于……的认定/问题/分析"类标题**，也使用"就XXX问题的意见"等中性表述。标题必须是加粗段落式长句，直接亮明我方立场。
6. **语言去情感化、去评价性，证据引述具体化但不逐条列举。** 严格禁止出现"明显""显然""赖账""恶意""太清爽了"等评价性词汇；不逐条罗列证据编号后简单拼接，应以归纳综合方式论证；不引用未作为证据提交的材料；人称表述中立客观，不指向个人。

> ✅ **正确示范（论点句）**：
> ### **一、揭露日应认定为某年某月某日，"至今未揭露"的主张无法律依据**
> ### **二、某数量股票申购发生在虚假陈述实施日之前，不具备交易因果关系**
> ### **三、案涉事件属于法定一般事件，不具备虚假陈述重大性**
>
> ❌ **错误示范**：
> ### 一、关于揭露日的认定
> ### 二、关于交易因果关系的分析
> ### 三、虚假陈述重大性的问题
>
> **注**：论点标题的格式核心在于**加粗段落式长句**，Markdown层级根据实际需要灵活选用。Word排版中呈现为"一、二、三"样式由markdown-to-word转换脚本控制。

## 执行步骤

### Step 1：读取 `./办案记录.md`
读取案件基本信息、代理方身份、诉讼方案、庭审记录、庭审情况报告、已整理文件清单。

### Step 2：对比庭前与庭后，找出新争议点
- 对比原始起诉状/答辩状与庭审笔录/庭审情况报告。
- 标记：庭审中新产生的争议点、法官反复追问的细节、对方的新主张、法官的法律释明。

### Step 3：按需读取知识库
- **必须读取**：`references/请求权基础检索总表.md`，用于确认本案核心请求权/抗辩权基础，确保代理意见法律框架无偏差。
- **要件基础继承（强制）**：优先读取 `工作底稿/` 下最新的案情分析报告，获取其中的「要件映射表」（02 Step 7.A 输出）。以映射表为涵摄论证的规范基础——每个争议焦点按"大前提（要件）→ 小前提（本案事实）→ 结论"三段论展开。若映射表不存在（02 未输出），按以下步骤自行加载：读取 `references/请求权基础检索总表.md` → 读取对应的 `references/案件类型要件库_{{类型}}.md` → 逐要件对照本案事实输出要件映射。若 10 个要件库均未覆盖，自动加载 `案由请求权基础检视总览.md`。
- **严格禁止行为**：不照搬知识库原文，只提取"构成要件"和"证明要点"融入三段论论证。

### Step 4：法条与案例检索（强制触发）
代理意见是最终说理文书，应当主动检索以增强说服力：
- **大前提强化**：对每个争议焦点涉及的法律概念不确定时，检索 `laws` 和 `books`，获取精准的法条解释与适用要件。
- **类案支撑**：对每个核心论点，检索 `cases`（按案由打 `--tag` 过滤），引用 1-3 个最高人民法院裁判要旨作为类推支撑。
- **庭审新主张回应**：对方在庭审中提出新抗辩时，检索 `laws`、`cases`、`books` 寻找切断依据。
- **引用纪律**：仅引用 top 3 最相关结果，在代理词中明确标注来源（如"最高人民法院（2023）最高法民终XX号裁判观点认为……"），严格编造。
- **法条引用强制核验**：凡引用具体法条，必须先通过北大法宝 MCP / 人民法院案例库 / 国家法律法规数据库 / Web 检索核验条文原文，方可写入文书。
- **案例引用强制核验**：凡引用具体案例，必须先检索人民法院案例库或北大法宝案例库，确认案号真实存在，方可写入文书。
- **不确定性标注**：检索无结果或结果冲突时，不自行取舍；必须标注"【待核实】"并向用户报告。

### Step 5：提炼争议焦点与论点句
- 针对每个争议焦点，提炼一句高度概括的"论点句"作为 `###` 三级标题。
- 标题必须是**加粗段落式长句**，表明明确立场。

### Step 6：为每个论点构建三段论
每个论点下必须包含：
1. **大前提（法律依据）**：引用具体法律条文或司法解释。
2. **小前提（案件事实与证据）**：结合庭审证据重构事实。
3. **针对性反驳（庭审回应）**：指出对方逻辑谬误或证据瑕疵。
4. **结论**：得出有利于我方的具体结论。

### Step 7：生成代理词

```markdown
# 代理意见

**案号：**（XXXX）XX民XX字第XXXX号
**案件：**XXX诉XXXXXXXXXXX纠纷案件
**提交方：**XXX（被申请人/上诉人/被上诉人）
**代理律师：**XXX

**尊敬的审判长、审判员：**

受[委托人]的委托，我就[案件]一案，就本院庭审确定的争议焦点发表如下代理意见，请合议庭参考。

### **一、……（论点句，亮明我方立场）**

[连贯段落：从法律规定的实质含义出发，阐明大前提的规范目的；再将案件事实与规范要件逐一对应，形成完整的涵摄链条；同时针对对方可能提出的异议展开预判性反驳；最后得出有利于我方的具体结论。整段文字一气呵成，不分点，不列项，不以表格或时间线代替论证。]

### **二、……（论点句）**

[连贯段落]

### **三、……（论点句）**

[连贯段落]

综上，……

[律师事务所名称]
[律师姓名] 律师
[日期，如：2026年5月28日]
```

格式要求：
- 一级标题 `#`：民事代理词
- 二级标题 `##`：代理意见（如有需要）
- 论点标题：加粗段落式长句，Markdown层级（`##`/`###`/`####`）根据实际需要灵活选用
- 不使用无意义的层级嵌套
- **正文默认为连贯段落**，一气呵成，严格以表格、时间线分列呈现论证逻辑；论点内部的所有转折、对抗、递进均须通过段落语句自然完成。
- **子论点格式（例外允许）**：当一个大论点下包含多个并列子论点，且用户明确要求公文式序号时，允许使用（一）（二）（三）或1. 2. 3. 作为子标题，但须保持归纳综合的论证方式，不逐条列举证据编号后简单拼接。

**文书首部规范（强制）**：代理词首部仅列提交方及案件基本信息，无需列明其他诉讼主体：
- 案号
- **案件**（使用"案件："标签，完整表述为"某某诉某某……案件"，不再使用"案由"标签）
- 代理词提交方（上诉人/被上诉人/原审原告/原审被告等）的全称
- 委托诉讼代理人
- **Word排版要求**：首部信息行中，冒号前的标签（如"案号：""案件：""上诉人（原审原告）：""被上诉人（原审被告）：""委托诉讼代理人："）必须加粗，冒号后的内容不加粗；首行缩进两个汉字字符（14pt×2）。
- **致文抬头**："尊敬的审判长、审判员："须单独成段、加粗、顶格（无缩进）。
- **简称定义**：当事人简称统一在正文第一段开头集中定义，首部信息行仅列全称。例如："北京天驰君泰（杭州）律师事务所接受甲新能源科技股份有限公司（以下简称“甲公司”）的委托，指派本所律师担任其与张三、乙证券股份有限公司（以下简称“乙证券公司”）证券虚假陈述责任纠纷二审一案的诉讼代理人。"

**文书落款规范（强制）**：代理词落款采用三行右对齐格式：
- 第一行：律师事务所全称
- 第二行：律师姓名 + " 律师"
- 第三行：日期（如：2026年5月28日）
- Word排版要求：右对齐、加粗、宋体四号(14pt)、"此致"与落款之间空一行

### Step 8：格式规范化检查（输出前必做）

在生成最终Markdown之前，执行以下文本规范化：

1. **引号方向检查**：全文搜索 `"`（直双引号）和 `"`（右弯引号）。若发现所有引号方向相同（缺少左引号 `"`），须手动或使用脚本将引号对修复为 `"` + `"`。
2. **案号/案由/当事人信息排版**：如用户有特定排版要求（如分行显示、标签加粗、小四字号），应在Markdown中通过独立段落实现，以便后续Word转换脚本正确识别：
   ```markdown

   案件：合同纠纷
   提交方：马秀英（上诉人）
   代理律师：XXX
   ```
3. **"此致"与落款之间须有空行**，确保Word转换时正确识别为独立段落。

## 特殊情形一：对"驳回起诉"裁定提起上诉的代理意见

当本案系对一审"驳回起诉"裁定提起的上诉（二审程序审查类案件）时，代理意见应特别注意以下要点：

1. **核心争议焦点单一**：此类二审通常只审查"一审裁定是否具备事实和法律依据"，代理意见应围绕《民事诉讼法》第177条及相关司法解释展开，避免陷入实体争议。
2. **重点论证"不构成重复起诉"的三要件**：
   - **当事人不同**：前后诉被告范围、诉讼地位、责任主体是否实质不同
   - **诉讼标的不同**：前后诉争议的实体法律关系是否不同（不将法律关系物化为金额概念）
   - **未否定前诉裁判结果**：后诉是否遵循前诉生效裁判的释明提起；前诉若为"驳回起诉"的程序性裁定，不产生实体既判力
3. **补强"程序正当性"**：如本案系遵循上级法院释明另行提起的诉讼，应强调遵循释明起诉的程序正当性。
4. **归谬论证**：如一审裁定不予纠正将导致当事人实体权利无法获得司法救济，与民事诉讼制度基本功能相悖。

## 特殊情形二：再审审查程序（听证/询问）的代理意见

当本案系再审审查程序（如案号为"民申"字）时，代理意见应特别注意以下要点：

1. **程序定位**：再审审查并非完整庭审，通常以书面审查为主，必要时组织听证或询问。代理意见应围绕"是否符合《民事诉讼法》第207条规定的再审法定事由"展开。
2. **回应结构**：针对再审申请书列明的每一项法定事由，逐一回应：
   - 该事由是否成立
   - 原审判决/裁定是否存在适用法律错误或认定事实错误
   - 是否属于"足以影响裁判结果"的重大瑕疵
3. **证据策略**：再审审查阶段通常不组织实质性质证，代理意见中的证据引用应聚焦于原审已提交且经质证的证据，以及新证据（如有）是否符合《民诉法解释》第388条"新的证据"标准。
4. **篇幅控制**：再审审查代理意见宜简明扼要，直击法定事由成立与否，避免冗长的实体争议论述。
