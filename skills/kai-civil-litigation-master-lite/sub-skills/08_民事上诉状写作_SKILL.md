# 民事上诉状写作

## 强制约束

1. **严格简单重复一审观点**。上诉状必须围绕"一审哪里判错了"展开，突出"纠错"价值。
2. **每个上诉理由必须使用`###`三级标题作为论点句**，标题格式为**加粗段落式长句**，直接指向一审判决的错误（如"### **一、一审判决认定合同已解除属于事实认定错误，案涉解除通知并不发生解除效力**"）。
3. **上诉请求必须明确具体**：写明"请求撤销/改判/发回重审"的具体一审判决主文；若请求改判，必须写明具体改判方案。
4. **上诉理由必须完成"一审判决如何错误 → 正确认定应当是什么 → 法律依据/证据支撑"的闭环**。缺一不。
5. **法律依据必须精确到条款项**，使用"依照法律规定"等笼统表述。

## 执行步骤

### Step 1：读取 `./办案记录.md`
读取案件基本信息、代理方身份、一审判决内容、诉讼方案。

### Step 2：确认上诉条件
1. **上诉期限**：判决送达之日起15日内，裁定送达之日起10日内。
2. **上诉利益**：改变一审判决对上诉人是否有利。
3. 若不符合，立即告知用户并停止执行。

### Step 3：定位一审裁判错误类型
将错误精准归类为：
- **事实认定错误**：关键事实遗漏、证据采信错误、事实推定缺乏依据。
- **法律适用错误**：请求权基础援引错误、法律解释偏差。
- **程序违法（如有）**：遗漏当事人、违法缺席判决、未经质证的证据作为定案依据、超诉请裁判。

### Step 4：按需读取知识库
- **必须读取**：`references/请求权基础检索总表.md`，用于核对一审法律适用是否存在请求权基础选择错误。
- **要件基础继承（强制）**：优先读取 `工作底稿/` 下最新的案情分析报告，获取其中的「要件映射表」（02 Step 7.A 输出）。以映射表中的正确构成要件为基准，逐项对比一审判决的事实认定与法律适用是否存在偏差。若映射表不存在（02 未输出），按以下步骤自行加载：读取 `references/请求权基础检索总表.md` → 读取对应的 `references/案件类型要件库_{{类型}}.md` → 逐要件对照本案事实输出要件映射。若 10 个要件库均未覆盖，自动加载 `案由请求权基础检视总览.md`。
- **严格禁止行为**：不照搬知识库原文，只提取"正确构成要件/法律解释"作为上诉理由的规范基础。

### Step 5：法条与案例检索（强制触发）
上诉状涉及对一审判决的"纠错"，应当检索权威资料强化论证：
- **法律适用纠错**：对一审援引的法条或解释有异议时，检索 `laws` 和 `books`，获取正确的规范解释。
- **类案纠错**：检索 `cases`（按案由打 `--tag` 过滤），寻找与本案关键事实类似但判决结果相反的最高人民法院案例，或支持我方上诉观点的裁判要旨。
- **程序违法依据**：对程序违法主张，检索 `laws` 获取《民事诉讼法》及司法解释的精确条文。
- **引用纪律**：仅引用 top 3 最相关结果，标注来源，严格编造。
- **法条引用强制核验**：凡引用具体法条，必须先通过北大法宝 MCP / 人民法院案例库 / 国家法律法规数据库 / Web 检索核验条文原文，方可写入文书。
- **案例引用强制核验**：凡引用具体案例，必须先检索人民法院案例库或北大法宝案例库，确认案号真实存在，方可写入文书。
- **不确定性标注**：检索无结果或结果冲突时，不自行取舍；必须标注"【待核实】"并向用户报告。

### Step 6：设计上诉请求
- 明确上诉对象：撤销/改判/发回重审的具体一审判决主文。
- 明确改判内容：若改判，写清具体改判方案（如"改判被上诉人向上诉人支付违约金50万元"）。
- 上诉请求不超过一审诉讼请求范围（有例外需说明）。

### Step 7：撰写上诉理由
结构模板：

```markdown
### **一、一审判决认定事实错误**
[自然段落：指出哪一关键事实认定错误 → 陈述正确事实及证据 → 说明该错误如何导致裁判结果错误]

### **二、一审判决适用法律错误**
[自然段落：指出错误援引的法律规范 → 阐明正确的请求权基础或法律解释 → 援引正确的法律条文]

### **三、一审判决程序违法（如有）**
[自然段落：指出违反的具体程序规则 → 说明对实体裁判的影响 → 援引《民事诉讼法》相关条文]
```

写作要求：
- 标题必须是加粗段落式长句，直接指向一审判决错误。
- 每个标题下为自然段落，不使用"一、二、三"内部列举。
- 引用一审证据或新证据时必须精准指示页码。
- 站在二审法院视角，提前补强一审薄弱环节。

### Step 8：反自认审查与法条核对
- 删除任何对己方不利的事实自认。
- 对所有引用的法条进行检索核对，确保准确有效。

### Step 9：生成标准格式上诉状

```markdown
# 民事上诉状

## 当事人信息
| 身份 | 姓名/名称 | 住所地 | 原审诉讼地位 |
|:----:|:----------|:-------|:-------------|
| 上诉人 | | | 原审原告/被告 |
| 被上诉人 | | | 原审被告/原告 |

## 上诉请求
1. 请求撤销[法院名称]（XXXX）民初X号民事判决第X项；
2. 请求改判[具体改判内容]；
3. [或]请求发回重审。

## 事实与理由

### **一、……**
[自然段落]

### **二、……**
[自然段落]

### **三、……**
[自然段落]

综上所述，一审判决认定事实不清/适用法律错误/程序违法，恳请贵院依法改判/发回重审。

此致
**××××人民法院**

上诉人：（签名/盖章）
日期：××××年××月××日
```
