# Kai·民商事诉讼律师助手 - Lite版子技能说明

本目录包含 **Kai·民商事诉讼律师助手·Lite版** 的**8个核心子技能**。每个子技能聚焦于诉讼流程中的关键环节，文件体积精简、执行精准。

> **关于 Pro 版**：完整版（Pro）包含 19 个核心子技能，覆盖诉讼全流程（含材料审阅、法律分析报告、庭审提纲、庭审报告、案件判决情况报告、案件代理工作报告、结案归档、法律服务报价函、法律检索报告、法律服务方案制作等）以及 10 个案件类型要件库。法院短信与送达处理已整合至 01 立项建档和文件管理模块。如需了解 Pro 版，请联系作者。

## 使用方式

### 直接使用子技能

用户可以在指定案件文件夹后，直接调用特定子技能：

```
使用 [子技能名称] 处理 [案件文件夹路径]
```

例如：
```
使用 民事起诉状写作 处理 /Users/律师/案件/某某合同纠纷案
使用 证据目录写作与证据册生成
```

### 配合案件文件夹使用

每个子技能都会**强制读取**案件文件夹中的 `./办案记录.md` 文件：
- 若 `办案记录.md` 已存在 → 读取并理解案件上下文
- 若 `办案记录.md` 不存在 → 在子技能 01 中会创建该文件

## 核心设计原则

### 1. 强制读取 `./办案记录.md`

每个子技能的第一条规则都是：**在执行任何操作前，必须先读取当前案件文件夹下的 `./办案记录.md`**。

这确保：
- AI了解案件基本信息、代理方身份、已完成的分析结论
- 避免重复询问已确认的信息
- 保持案件全生命周期信息的连续性

### 2. 文件体积精简

每个子技能约 10-40KB：
- 减少 token 消耗
- 提高执行精准度
- 避免"注意力稀释"导致的执行跑偏

### 3. 独立但协调

每个子技能都可以独立执行，但彼此之间通过 `./办案记录.md` 保持协调：
- 模块 02（案情梳理和法律分析）完成后更新 `办案记录.md`
- 模块 03/04（起诉状/答辩状）读取 `办案记录.md` 中的分析结论
- 模块 07（书面代理意见写作）读取 `办案记录.md` 中的诉讼方案
