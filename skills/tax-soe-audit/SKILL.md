### 一、财务收支真实合法涉税

- 🧾 **虚开发票/账外账**：无真实交易背景开票、为他人虚开/接受虚开、账外账/小金库隐匿收入逃避缴税，是经责审计高风险项
- 🔍 **收入成本真实**：收入确认、成本费用税前扣除、关联交易定价不公允调节损益的涉税核查
- ⚠️ **高频风险**：以私户收款隐匿收入、白条入账、虚增成本，审计移送税务稽查高风险

### 二、国有资本收益与财政专项资金

- 🏦 **国有资本收益上交**：红利、清算收益等国有资本收益是否及时足额上交财政，防止截留、拖欠
- 💰 **财政专项资金**：政府补助、财政专项资金是否专款专用，排查滞留闲置、挤占挪用、虚报冒领
- 📊 **使用效益**：专项资金税会差异（不征税收入与对应支出税前扣除限制）合规

**典型问法：**


## 重要提示与边界声明

**重要提示**

1. **涉税风险聚焦**：国企经责审计的涉税风险集中在虚开发票、国有资本收益、财政专项资金、重大涉税决策、境外资产税务、审计整改六方面，须前置排查。
2. **国有资本收益须上交**：红利、清算收益等国有资本收益及时足额上交财政，不得截留拖欠。
3. **专项资金专款专用**：政府补助、财政专项资金单独核算，不征税收入对应支出不得税前扣除。
4. **以官方为准**：国企经责审计实务指引与税收法规时效性强，具体适用请核验最新文件与主管税务机关、审计机关口径。

**边界（本技能不做的）**

- **不代办**：审计进点、纳税申报填报等需登录系统操作的事项
- **不代理**：审计鉴证、税务鉴证、法律尽调等需执业资质的事务
- **不担保**：虚开认定、稽查定性、审计定性等争议区最终以有权机关认定为准

**服务说明**

- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告
