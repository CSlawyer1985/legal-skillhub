# 行业股权激励实践指南

## 一、12行业激励特征矩阵

### 1.1 互联网/科技 — 高期权池 + 快速迭代

| 阶段 | 期权池 | 典型工具 | 关键实践 |
|:-----|:------:|:--------|:--------|
| 天使/种子 | 15-20% | 期权(SO) | 联合创始人3-5%，早期员工1-3% |
| A轮 | 12-15% | SO | 4年标准归属，cliff 1年 |
| B/C轮 | 10-12% | SO+ESOP | 期权池refresh，核心团队ESOP锁定 |
| Pre-IPO | 8-10% | RSU+ESOP | 期权清理，转换为RSU |
| 上市后 | 3-5% | RSU | 年度grant，按薪酬比例分配 |

**标杆案例参考：**
- 某互联网大厂：上市前期权池15%，员工人均期权市值约300万（上市后）
- 某独角兽：B轮后每年新增1-2%期权池用于新入职核心人才
- 薪酬结构典型参考：年薪 = 现金(60-70%) + 期权/RSU(30-40%)

### 1.2 芯片/半导体 — 重仓核心技术

| 特点 | 说明 |
|:-----|:-----|
| 期权池比例 | 12-15%（行业最高一档） |
| 核心人才授予 | CTO级别可达2-3% |
| 归属机制 | 4年标准 + 里程碑加速（流片成功/量产） |
| 税务考量 | 国家大基金参股企业需额外合规审查 |
| 退出预期 | 5-8年（研发周期长） |

**风险提示：**
- 国家大基金及国资股东对股权变动有审批要求
- 技术出口管制(美国EAR/ITAR)可能影响境外架构IPO
- 建议采用境内ESOP结构而非VIE+境外期权

### 1.3 金融/保险 — 强监管约束

| 特点 | 说明 |
|:-----|:-----|
| 期权池比例 | 5-8%（受监管限制） |
| 典型工具 | RSU为主，辅以递延奖金 |
| 监管框架 | 银保监会「商业银行稳健薪酬监管指引」 |
| 递延支付 | 高管奖金40%+递延3年以上 |
| 追索扣回 | 风险暴露后薪酬追索机制 |

**合规红线：**
- 金融机构股权激励方案需监管审批/报备
- 国有金融机构严格受限
- 注意与「绩效薪酬延期支付+追索扣回」制度的衔接

### 1.4 医疗/健康 — 里程碑驱动

| 里程碑 | 激励释放 | 说明 |
|:-------|:--------|:-----|
| IND获批 | 授予20-30%加速归属 | 临床前阶段 |
| 临床I/II期 | 授予30-40%加速 | 研发关键节点 |
| NDA/上市获批 | 全额加速归属 | 商业化里程碑 |
| 销售过亿 | 额外追加期权 | 商业化成功 |

**行业特殊考量：**
- 药物研发周期6-10年，归属期需匹配
- 存在研发失败风险，期权可能归零
- 建议采用「基础归属+里程碑加速」双轨制
- FDA/CE等国际监管可能影响跨境期权

### 1.5 餐饮/消费 — 门店合伙人制

```
        ┌──────────────────┐
        │   总部股权激励    │ ← ESOP（核心管理层）
        │   期权池 8-10%    │
        └────────┬─────────┘
                 │
        ┌────────┴─────────┐
        │   门店合伙人制    │ ← 虚拟股/利润分红
        │   单店20-40%分红  │
        └──────────────────┘
```

**门店合伙人虚拟股典型设计：**
- 店长：单店15-25%利润分红权（虚拟股）
- 区域经理：区域内门店3-5%总利润分红权
- 总部核心：ESOP持股
- 退出机制：离职时按约定倍数（通常3-5倍年均利润）回购

### 1.6 制造业 — 稳健分红导向

| 特点 | 说明 |
|:-----|:-----|
| 期权池比例 | 5-8% |
| 典型工具 | ESOP为主，虚拟股为辅 |
| 激励重点 | 利润分红权 > 资本增值 |
| 归属期 | 3年（偏短），强调持续服务 |
| 退出机制 | 退休/离职按净资产回购 |

**制造业特殊性：**
- 重资产行业，估值增长有限，期权资本增值空间小
- 员工对「分红」的感知远强于「期权」
- 建议：ESOP持股 + 年度利润分红双轨制
- 注意国有资产保值增值要求（国企/央企）

### 1.7 咨询/服务 — 合伙制深度绑定

| 级别 | 典型激励 | 授予比例 |
|:-----|:--------|:--------|
| 合伙人 | ESOP权益份额 | 1-5% |
| 总监/VP | 期权+ESOP | 0.5-2% |
| 经理 | 期权+业绩奖金 | 0.1-0.5% |
| 顾问 | 纯现金+小额期权 | <0.1% |

**行业实践：**
- 「Up-or-Out」机制与股权激励深度绑定
- 晋升合伙人 = 获得ESOP份额，退出时按估值回购
- 合伙制企业注意GP/LP权责划分及无限连带责任
- 服务型企业估值波动大（人合性>资合性），估值方法需约定

### 1.8 物流/供应链 — 新业态挑战

| 场景 | 推荐方案 | 说明 |
|:-----|:--------|:-----|
| 总部管理层 | ESOP | 标准持股平台 |
| 区域/枢纽负责人 | 虚拟股+利润分红 | 按区域核算 |
| 一线员工(快递员/司机) | 计件+增量分红 | 股权激励不适用 |
| 技术/算法团队 | 期权(SO) | 对标互联网行业 |

### 1.9 传媒/文娱 — IP绑定型

**特殊激励结构：**
- 核心IP创作人：项目收益5-15%分成（基于IP贡献度）
- 导演/制作人：项目利润分配+公司期权
- 艺人/KOL：经纪约收益分成，股权激励较少
- 公司股权激励：仅适用于全职管理/技术核心

**法律注意点：**
- IP权属必须在劳动合同/合作协议中明确约定
- 项目制团队注意「职务作品」vs「个人创作」的权属划分
- 股权激励退出时，IP使用权归属需要约定

### 1.10 教育/培训 — 长期服务绑定

- 教师群体流动性适中，3年归属期为主
- 更重视「持续服务奖励」而非一次性大额授予
- 建议：小额定投式授予（每年grant + 递延分红）
- 双减后合规风险需评估

### 1.11 建筑/房地产 — 项目制

- 期权池较小(3-5%)，项目跟投+虚拟股为主
- 项目周期3-5年，归属与项目结算匹配
- 建筑企业资质要求影响股权结构（自然人持比限制）
- 垫资施工模式下，股权激励现金分红难

### 1.12 农业/食品 — 利润共享

- 期权池较小(3-5%)
- 适合利润分享型虚拟股
- 注意农村土地权益与公司股权的切割
- 农业补贴对利润的影响需计入分红核算

## 二、跨行业通用最佳实践

### 2.1 期权池设计三原则

1. **金字塔分配：** CEO/CTO > VP > 总监 > 经理 > 骨干
2. **预留未来：** 每轮融资后保留至少30%未分配期权池
3. **动态调整：** 每年业绩review后追加/调整授予

### 2.2 行权窗口期最佳实践

| 企业阶段 | 行权窗口期 | 说明 |
|:--------|:----------|:-----|
| 天使~A轮 | 无固定窗口 | 早期灵活 |
| B~C轮 | 每季度一次 | 限制流动性 |
| Pre-IPO | IPO前一次 | 清理历史期权 |
| 上市后 | 每季度（窗口期限制） | SEC/合规要求 |

### 2.3 退出条款设计要点

1. **Good Leaver（正常离职）：** 已归属期权保留（通常90天行权），未归属期权作废
2. **Bad Leaver（因故离职）：** 全部期权作废，已行权股份按成本价回购
3. **IPO退出：** 标准6-12个月锁定期，锁定期后按减持规则逐步退出
4. **死亡/残疾：** 加速归属，由继承人继承（12-24个月行权窗口）
5. **退休：** 按Good Leaver处理，已归属期权保留

### 2.4 估值方法对照

| 企业阶段 | 推荐估值方法 | 典型折扣率 |
|:--------|:-----------|:----------|
| 天使轮 | 最近一轮融资估值（折扣） | 80-90%折扣 |
| A轮 | 融资估值 + DCF辅助 | 60-80%折扣 |
| B轮 | 融资估值为主 | 50-70%折扣 |
| Pre-IPO | 上市可比法 | 30-50%折扣 |
| 上市 | 市场价格（无折扣） | 0 |
