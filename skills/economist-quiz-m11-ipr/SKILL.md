# 中级经济师刷题库·模块：知识产权

## 定位
本 Skill 是「中级经济师刷题库」系列的专业科目模块之一，覆盖《知识产权专业知识和实务》。用户指定「章节 / 题型 / 数量 / 模式」，即生成对应考点题目、标准答案与解析。

> ⚠️ 红线：本 Skill 是**练习与巩固工具**，不是押题，不替代官方教材与真题；题目依据通用考纲由 AI 生成，请务必以当年官方教材与最新考纲为准。

## 适用边界
- **适用**：中级经济师《知识产权专业知识和实务》的日常刷题、考点自测、解析学习、错题管理
- **不适用**：经济基础公共课（见系列「模块：经济基础」）；其他专业科目（工商/农业/财政税收/金融/保险/运输/人力/旅游/建筑房地产）—— 见系列对应模块；不作为真题来源；不用于押题预测
- **推荐配合**：
  - 导出 PDF → 配合 `pdf` / `pdfkit-py` skill
  - 导出 Word → 配合 `docx` / `docx-cn` skill
  - 导出 Markdown → 直接输出，无需额外工具
- **用户群**：中级经济师备考者；无个人 / 平台标签，任何人可装可用

## 《知识产权》章节地图
按通用考纲（章节数以当年官方教材为准），核心章节分组：
1. **知识产权基础**：知识产权的概念、性质（无形性/专有性/地域性/时间性）、范围（专利/商标/著作权/商业秘密等）
2. **专利申请**：专利类型（发明/实用新型/外观设计）、授权条件（新颖性/创造性/实用性）、申请文件（请求书/说明书/权利要求书）
3. **专利保护**：专利权内容（独占实施权）、专利权限制（强制许可/合理使用）、专利侵权（构成要件/赔偿）、保护期限
4. **商标**：商标注册（条件/禁止情形）、商标权内容、商标侵权（混淆/淡化）、保护期限（10 年续展）
5. **著作权**：著作权客体与主体、权利内容（人身权/财产权）、保护期限、著作权侵权、邻接权
6. **商业秘密**：构成要件（秘密性/价值性/保密措施）、侵权与保护
7. **其他知识产权**：地理标志、集成电路布图设计、植物新品种、原产地名称等

## 工作流程

### 主流程（8 步 + 内嵌安全校验）

1. **明确需求**：科目 = 知识产权（本模块固定）；确认章节、题型（单选 / 多选 / 案例）、数量、模式（自测 or 直接全出）。信息不全先问，不猜。
   - **快速路径**：用户说"快速出 N 道"/"随便来几道"时 → 默认：单选 + 知识产权基础 + 中等难度 + 直接模式 → 跳到步骤 3
2. **定位考点**：按「考点选取指南」从目标章节抽取高频考点，优先选取高优先级考点；避免与本次会话已出主题重复。
3. **生成题目**：按「题目生成质量标准」构造题目。
   - 单选：题干 + 4 选项（A / B / C / D）
   - 多选：题干 + 5 选项（A–E），正确项 2~5 个
   - 案例分析：背景材料 + 若干小题（不定项选择）
4. **配答案与解析**：每题给标准答案 + 解析（必须包含四要素：正确项依据 + 错误项辨析 + 易混点 + 关联考点）。
5. **🔒 内容校验（安全检查步骤）**：
   - 核查关键数据 / 公式 / 法条是否标注来源与年份
   - 核查是否含有"押题""必考""真题"等误导性表述 → 有则替换为中性表述
   - 核查难度是否对标中级（不过易 / 不超纲）
   - 不通过 → 回到步骤 3 修正后重新校验
6. **模式切换**：
   - **自测模式**：先只给题干 + 选项，用户作答后再揭开答案 + 解析
   - **直接模式**：题目 + 答案 + 解析一并给出
7. **错题记录**：自测 / 做题确认答案后，若用户答错或指明确实做错 → 按「错题本」章节格式自动追加到本地错题库 JSON 文件。
8. **可选导出**：用户要导出时，整理为 Markdown；需要 PDF 时进一步转换（推荐配合 pdf skill）；需要 Word 时转为 .docx（推荐配合 docx-cn skill）。
9. **收尾提示**：附「以当年官方教材为准」提醒；可问是否继续出题或换章节。

## 输出样例

> 以下样例展示实际输出长什么样，照此格式执行。

### 样例 1：单选题（完整输出）

```
1.【单选】知识产权基础 · 知识产权的性质

关于知识产权特征的说法，下列正确的是：
A. 知识产权具有有形性，可独立占有
B. 知识产权具有地域性，仅在授权国/地区有效
C. 知识产权没有时间限制，永久有效
D. 知识产权可任意复制，不受专有性约束

答案：B

解析：
① 正确项依据：知识产权具有地域性，其效力受地域限制，仅在授予权利的国家或地区内受保护（B 对）。
② 错误项辨析：A 错——知识产权客体是无形财产，具有非物质性（非有形）；C 错——多数知识产权有保护期限（如发明专利 20 年）；D 错——知识产权具专有性，未经许可不得复制使用。
③ 易混点：无形性（非物质性）vs 有形财产可占有，是最易混淆点；地域性常与"国际条约自动保护"误解混淆。
④ 关联考点：知识产权范围、著作权/专利权/商标权保护期（第 1、3、4、5 章）。
```

### 样例 2：多选题（完整输出）

```
2.【多选】专利保护 · 专利侵权

下列各项中，属于专利侵权行为的有：
A. 未经许可制造专利产品
B. 为科研实验使用专利
C. 未经许可销售专利产品
D. 使用专利方法
E. 进口依专利方法直接获得的产品

答案：ACDE

解析：
① 正确项依据：未经专利权人许可，为生产经营目的制造、使用、许诺销售、销售、进口专利产品或使用专利方法（A/C/D/E），均构成侵权。
② 错误项辨析：B 不侵权——专为科学研究和实验而使用有关专利，属《专利法》规定的不视为侵权的例外情形。
③ 易混点："为科研实验使用"vs"为生产经营使用"是判定侵权的高频易混点，前者免责后者侵权。
④ 关联考点：专利权限制、强制许可（第 3 章）。
```

## 题目生成质量标准

> 解决"题目怎么才算好题"的操作化标准，每道题生成后对照检查。

### 选项设计原则
| 要求 | 标准 | 反例（禁止） |
|------|------|-------------|
| **正确项** | 有明确的教材/法条依据，可直接引用出处 | 模糊表述、"一般来说""通常" |
| **干扰项 A** | 对应常见错误理解（典型误区） | 明显荒谬的选项（一眼就能排除） |
| **干扰项 B** | 对应高频易混点（考生最容易混淆的概念） | 与题干无关的内容 |
| **干扰项 C/C+** | 部分正确但不完整（多选特有陷阱） | 全错或全对的干扰项 |
| **长度均衡** | 各选项字数大致相当（±30%） | 一个选项明显比其他长/短很多 |

### 难度分级标准
| 等级 | 定义 | 出题比例建议 | 示例 |
|------|------|-------------|------|
| **简单** | 直接考查定义 / 分类 / 特征，教材原文即可作答 | ~30% | "下列属于知识产权性质的是？" |
| **中等** | 需要理解概念间关系 / 做简单辨析 / 记忆细节 | ~50% | "关于专利授权三性说法正确的有？" |
| **困难** | 综合应用多个知识点 / 案例分析 / 侵权判定 | ~20% | 给定情形判定是否构成商标侵权并说明理由 |

### 解析质量四要素（必须全部满足）
1. **正确项依据**：引用具体理论/法条/公式，说明为什么对
2. **错误项辨析**：逐个分析每个错误选项为什么错（不能只说"错误"而不解释）
3. **易混点**：指出本题涉及的高频易混概念，帮助举一反三
4. **关联考点**：列出相关的其他考点（注明所在章节），方便延伸学习

### 自检清单（每道题生成后勾选）
- [ ] 题干表述清晰无歧义？
- [ ] 4/5 个选项都有存在价值（无废选项）？
- [ ] 正确答案确信无误且有据可查？
- [ ] 解析包含四要素？
- [ ] 无"押题""必考""100%原题"等表述？
- [ ] 关键数据/法条标注了来源年份？

## 红蓝对抗自检（题目质量双保险）

> 每批题目生成后、交付前，按"红军出题 / 蓝军找茬 / 优化落点"三段式自检，确保题目经得起推敲。对应专家规则 **R2 红蓝对抗前置**。

### 红军（出题方 · 立标准）
- 每题必须有明确教材 / 法条依据，可直接引用出处
- 选项全部有效（无废选项），正确答案唯一
- 解析必须含四要素（正确依据 + 错误辨析 + 易混点 + 关联考点）
- 难度分布对标 3:5:2（简单:中等:困难）

### 蓝军（找茬方 · 攻弱点）
| 攻击点 | 典型问题 | 自检动作 |
|--------|----------|----------|
| 考纲偏差 | AI 编造了不存在的考点 / 法条 | 核对「考点选取指南」优先级；存疑处标注「请核对最新教材」 |
| 错题漏记 | 用户答错却没写入错题库 | 自测提交后立即比对，错误必入错题库（以 `stem` 去重） |
| 重复出题 | 同一会话反复出同一考点 | 维护会话已出主题集合，跨请求去重 |
| 边界误用 | 被要求出其他专业 / 经济基础题 | 触发词限定知识产权；其他科目引导至系列对应模块 |
| 误导表述 | 出现"押题""必考""真题" | 内容校验步骤（主流程第 5 步）替换为中性表述 |
| 解析空泛 | 只给答案不给为什么 | 强制四要素；缺一项则退回重生成 |

### 优化落点（交付前必过）
- 三步走：**生成 → 红蓝对抗自检 → 内容校验（主流程第 5 步）→ 交付**
- 任一项不通过 → 回到生成步骤修正，不带着问题交付
- 红蓝对抗结果可记入「错题本」外的临时自检备注，便于本次会话持续改进

## 错题本（v1.1.0 架构同步）
错题本是本 Skill 的持久化错题管理功能：自动记录做错的题目，支持下次重练与导出 PDF / Word。

### 存储路径
- 错题库文件：`~/.workbuddy/skills/中级经济师刷题库·模块：知识产权/mistakes/mistakes.json`
- 首次使用时自动创建 `mistakes/` 目录与 JSON 文件
- 跨会话持久保留；纯 JSON 格式，用户可手动查看 / 备份

### 错题记录字段（每道错题为一条 JSON 对象）
| 字段 | 说明 | 示例 |
|------|------|------|
| `id` | 唯一标识（M + 3 位序号） | `M001` |
| `module` | 所属模块 | `知识产权` |
| `chapter` | 所属章节 / 考点 | `知识产权基础` |
| `type` | 题型 | `单选` / `多选` / `案例分析` |
| `stem` | 题干原文 | `关于知识产权特征的说法……` |
| `options` | 所有选项 | `{"A":"...","B":"...","C":"...","D":"..."}` |
| `correct` | 正确答案 | `B` |
| `user_answer` | 用户作答 | `A` |
| `explanation` | 解析原文 | `正确选项 B 的原因是……` |
| `added` | 记录时间（ISO 8601） | `2026-07-21T22:00:00+08:00` |
| `status` | 掌握状态 | `未掌握` / `已掌握` |
| `replay_count` | 重练次数 | `0` |

### 触发词与工作流程

#### 自动记录
- **时机**：自测模式用户提交答案后比对错误、或直接模式用户明确说「这道题我错了」时
- **动作**：按上述字段构造错题条目，追加入 `mistakes.json`（保留已有数据，不覆盖）
- **记录前**：确认用户答案与正确答案不一致；以 `stem` 去重，避免重复记录同一题目

#### 训练错题
- **触发词**："训练错题" / "练错题" / "错题重练"
- **流程**：
  1. 读取 `mistakes.json`，筛选 `"status": "未掌握"` 的错题
  2. 按用户要求（默认全部，可指定章节 / 数量 / 难度）抽取错题重新出题，**自测模式（先不显示答案）**
  3. 用户作答 → 比对正确答案 → 更新错题库：
     - 答对 → `status` 改为 `已掌握`，`replay_count +1`
     - 答错 → `status` 保持 `未掌握`，`replay_count +1`
  4. 提示本次重练结果统计（掌握 X 题 / 总 X 题）
- **支持限定**："练 5 道专利保护的错题" / "练中等难度的错题"

#### 导出错题本
- **触发词**："导出错题本" / "导出错题本 PDF" / "导出错题本 Word" / "我的错题本"
- **动作**：读取全部错题，按章节 / 题型整理为格式文档：
  - 默认输出 **Markdown**
  - 用户指定 PDF → 转换为 PDF（推荐配合 `pdf` skill）
  - 用户指定 Word → 转为 **.docx**（推荐配合 `docx-cn` skill）
- **文档结构**：章节标题 → 每题（题干 + 选项 + 正确答案 + 你的答案 + 解析 + 状态 / 重练次数）

#### 错题统计
- **触发词**："错题统计" / "错题分布"
- **动作**：读取错题库，输出按章节、按题型的错题数量、掌握率；格式为表格

#### 错题管理扩展
- **删除错题**：用户说"删除错题 M003" → 从 JSON 中移除该条目（需二次确认）
- **标记已掌握**：用户说"这道题我已经掌握了" → 更新对应错题 status 为"已掌握"
- **重置错题库**：用户说"重置错题库" → 清空 mistakes.json（需二次确认⚠️高风险操作）
- **容量预警**：错题超过 300 条时提示「错题库较大，建议导出归档」

### 红线
- 错题库仅与本模块绑定；不与其他模块共享（系列各模块各有独立错题库）
- 不自动上传 / 同步云端；用户自行备份 `mistakes.json`（或通过导出功能留存）
- 导出的错题本文档不得含「押题」「真题」等误导性标注
- 删除 / 重置操作必须二次确认

## 注意事项
- **关键数据 / 公式 / 法条**：标注来源与年份，不确定时明示「请核对最新教材」
- **难度对标**：严格按「题目生成质量标准」的难度分级出题，简单:中等:困难 ≈ 3:5:2
- **避免重复**：记录本次会话已生成章节 / 主题，跨请求去重；错题以 `stem` 去重，不重复追加
- **中立准确**：不杜撰法条与数据；模糊处宁可标注「建议核对教材」
- **通用化**：不含任何人名 / 昵称 / 专属平台标签
- **错题记录**：记录到本地 JSON 文件，确保路径可写；记录前确认用户答案与正确答案不一致
- **重练提示**：重练错题时提醒用户「复习后重新作答，争取彻底掌握」
- **异常兜底**：任何步骤遇到异常（文件写失败 / 用户中断等），给出友好提示并提供下一步建议，不让流程静默失败

## 安全审查
- **等级**：P2（安全）
- **依据**：纯文本指令型 Skill；无脚本、无外部调用、无 MCP、无个人标签；内容为教育性 Q&A；错题记录仅读写本地 JSON 文件（`~/.workbuddy/skills/中级经济师刷题库·模块：知识产权/mistakes/mistakes.json`），不涉及网络 / 外部服务
- **嵌入位置**：主流程第 5 步「🔒 内容校验」——每批题目生成后、交付用户前执行
- **风险点与缓解**：
  - AI 生成内容可能与最新考纲 / 法条有偏差 → 通过内容校验步骤（标注来源年份 + 中性表述）缓解
  - 错题 JSON 文件为本地 I/O，路由权限由 WorkBuddy 沙盒控制
  - 删除/重置操作有二次确认机制
