# 使用说明 · 中级经济师刷题库·模块：知识产权

## 这是什么
一个帮你刷《知识产权专业知识和实务》考点的 Skill：你说要练哪章、什么题型、几道，它就出题并给答案 + 解析；还能模拟考场（先答题后看解析）、自动收录错题、重练错题、导出错题本（PDF / Word）。

**核心亮点**：按高频考点精准出题 → 自测模拟考场 → 错题自动收录 → 重练直到掌握 → 导出随身复习，完整闭环。

## 安装（新用户照做）
1. 打开 `中级经济师刷题库·模块：知识产权` 文件夹，把里面的 `V1.0.0` 文件夹中全部文件（SKILL.md、USAGE.md、icon.png）复制到 `~/.workbuddy/skills/中级经济师刷题库·模块：知识产权/`（系统目录用中文名顶层，不嵌套版本号）
2. 重启或刷新 WorkBuddy，使其加载新 Skill
3. 在对话里说触发词即可使用

## 常见问题

### 出题相关
- **题目和教材不一致？** Skill 依据通用考纲生成，请以当年官方教材为准；有出入请告知具体章节和教材说法，可调整。
- **能押题吗？** 不能，也不建议依赖任何押题；本 Skill 用于练习巩固。
- **想练其他专业（人力 / 金融 等）？** 本模块只覆盖知识产权；其他专业见系列对应模块（模块：人力资源 / 金融 等）。
- **能控制难度吗？** 可以。说"出 3 道困难级别的题"或"来点简单的"，Skill 会调整难度比例。
- **能混合章节出题吗？** 可以。说"专利保护 + 商标，各 3 道"即可跨章节组合。

### 错题本相关
- **错题库存在哪？** `~/.workbuddy/skills/中级经济师刷题库·模块：知识产权/mistakes/mistakes.json`，初次使用自动创建。
- **重装/换设备会丢错题吗？** 会的。建议定期「导出错题本」留存，或手动备份 `mistakes.json` 文件。
- **错题能删除吗？** 能。说"删除错题 M003"即可（需二次确认）。
- **错题库太大了怎么办？** 超过 300 条时 Skill 会提示归档；你也可以随时"导出错题本"后说"重置错题库"清空（需二次确认⚠️）。
- **如何标记某道题已掌握？** 说"错题 M002 我已经掌握了"即可更新状态。
- **能按难度筛选错题重练吗？** 可以。说"练中等难度的错题"。

### 安装与技术
- **安装后不生效？** 确认文件夹在正确路径（`~/.workbuddy/skills/中级经济师刷题库·模块：知识产权/`）；重启 WorkBuddy 后再试。
- **导出 PDF/Word 失败？** 推荐配合 `pdf` skill（导出 PDF）或 `docx-cn` skill（导出 Word）使用。

## 小贴士
- 🎯 **最佳刷题节奏**：自测模式 + 错题本重练 —— 先做一遍，错的隔天重练，循环直到掌握
- 🔍 **深挖易混点**：每道题的解析都含"易混点"字段，做完后可追问「这题易混点再讲细点」
- 📊 **跨章节混合**：说"专利保护 + 商标，各 3 道"可以一次覆盖多个章节
- 🖨️ **考前冲刺**：导出错题本 PDF 打印出来，考前重点翻一翻错题
- ⚡ **随手练**：没时间走完整流程就说"快速出 3 道"，3 秒开始做题
