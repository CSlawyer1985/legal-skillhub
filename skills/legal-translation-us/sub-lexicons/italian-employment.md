# 意大利语子词典：雇佣/劳动

从 employment.md 提取的意大利语到英语映射。这些术语为意大利特有，应映射到主词典中的通用英语对应词，而不应原样出现在为英语读者撰写的雇佣合同中。

## 意大利雇佣合同类型

| 意大利语术语 | 英语对应 | 注释 |
|---|---|---|
| contratto di lavoro subordinato | employment contract / employment agreement | 意大利法律术语，指从属性雇佣关系；“subordinazione”表示雇员身份 |
| contratto di lavoro a tempo indeterminato | permanent employment contract | 无固定终止日期的雇佣；意大利雇佣法中的标准形式 |
| contratto di lavoro a tempo determinato | fixed-term employment contract | 有明确终止日期的雇佣（受欧盟指令 1999/70/EC 限制） |
| contratto di lavoro part-time | part-time employment contract | 工时缩减的雇佣；意大利法律单独规制 |
| contratto di collaborazione | consultancy agreement / contractor agreement | 准雇佣安排；可为“collaborazione coordinata e continuativa”（co.co.co.）或“contratto a progetto” |
| collaborazione coordinata e continuativa / co.co.co. | coordinated and continuous collaboration | 意大利特有安排（2015年前）；劳动者无雇佣身份但持续提供协调性服务；大部分已被2015年《就业法》改革取消 |
| contratto a progetto | project-based contract | 意大利特有的、针对特定项目的准雇佣；经2015年《就业法》修改，与“真正独立”标准对齐 |
| lettera di assunzione | letter of appointment / offer letter | 载明雇佣条款和开始日期的文书 |
| patto di non concorrenza | non-compete agreement / non-competition covenant | 防止竞争的竞业限制条款；意大利法律下如范围/期限合理则可执行 |
| patto di non sollecitazione | non-solicitation agreement | 防止招揽客户/雇员的条款；区别于竞业限制 |
| patto di riservatezza | confidentiality agreement | 保护雇主保密信息和商业秘密 |
| clausola di stabilità | minimum term clause / lock-in clause | 要求最低雇佣期限或要求雇员偿还培训费用的条款 |
| periodo di prova | probationary period / trial period | 初始雇佣期（通常1-6个月，由 CCNL 确定），期间任一方可无需通知终止 |
| accordo di risoluzione consensuale | mutual termination agreement | 雇主与雇员就约定条款终止雇佣的协议 |
| accordo di buonuscita | severance agreement | 终止时提供遣散费的协议，往往以竞业限制/保密承诺为交换 |
| transazione in sede protetta | protected-venue settlement | 通过正式场所的调解或斡旋达成的雇佣争议和解（不同于英国的“settlement agreement”） |

## 意大利薪酬术语

| 意大利语术语 | 英语对应 | 注释 |
|---|---|---|
| retribuzione / compenso | remuneration / salary | 所完成工作的全部报酬 |
| retribuzione annua lorda / RAL | gross annual salary | 扣除（税、社保）前的年薪总额；意大利 HR 标准术语“RAL” |
| retribuzione netta | net salary | 扣除后的工资 |
| busta paga | payslip | 月工资单 |
| tredicesima mensilità | thirteenth month's salary | 年终发放的第十三个月工资（意大利及其他欧洲实务） |
| quattordicesima mensilità | fourteenth month's salary | 特定时间发放的第十四个月工资（意大利及其他欧洲实务）；不如第十三个月工资常见 |
| TFR / trattamento di fine rapporto | severance indemnity / end-of-service allowance | 《意大利民法典》第2120条的法定权利；整个雇佣期间累积（名义上每年约1个月），在终止时（退休、辞职、解雇、死亡）支付；转入补充养老基金或 TFR 基金；无精确普通法对应 |
| indennità di fine rapporto | severance pay | 终止时的支付（可为法定 TFR 或合同约定的遣散费） |
| indennità sostitutiva del preavviso | payment in lieu of notice | 雇主以支付代替实际通知期 |
| buonuscita / incentivo all'esodo | severance package / ex gratia payment | 酌情遣散或提前退出激励（常用于裁员计划，“esodo incentivato”） |
| superminimo | supplementary allowance | 超出 CCNL 要求的基本工资的额外固定支付 |
| premio di risultato / bonus | performance bonus | 实现目标的浮动报酬 |
| MBO / management by objectives | MBO / management bonus | 与组织/个人目标挂钩的管理奖金 |
| stock option | stock options | 以指定价格购买公司股份的权利 |
| piano di incentivazione | incentive plan | 提供绩效激励的结构化方案 |
| benefit / fringe benefit | benefit / fringe benefit | 非现金报酬（汽车、保险、养老金等） |
| auto aziendale | company car | 雇主提供的用于商务/个人用途的车辆 |
| assicurazione sanitaria integrativa | supplementary health insurance | 强制性国家体系之外的医疗保障 |
| fondo pensione complementare | supplementary pension fund | 强制性 INPS 之外的职业养老金 |
| contributi previdenziali | social security contributions | 意大利社会保障（INPS、INAIL 等）的强制性雇主/雇员缴款 |
| contributi a carico del datore di lavoro | employer contributions | 雇主向 INPS、INAIL 等的强制性缴款 |
| contributi a carico del lavoratore | employee contributions | 雇员缴款，通常从工资中扣除 |
| INPS | INPS (Italian Institute for Social Security) | 意大利国家社会保障机构（Istituto Nazionale della Previdenza Sociale） |
| INAIL | INAIL (Italian workplace insurance institute) | 意大利工伤/职业病保险机构（Istituto Nazionale per l'Assicurazione contro gli Infortuni sul Lavoro） |

## 意大利工作条件术语

| 意大利语术语 | 英语对应 | 注释 |
|---|---|---|
| orario di lavoro | working hours | 合同和 CCNL 规定的每周标准工时 |
| orario a tempo pieno | full-time hours | 标准全职工时（意大利通常为每周35-40小时） |
| lavoro straordinario | overtime | 超出合同工时的劳动；按加价费率支付 |
| lavoro notturno | night work | 在指定夜间时段（意大利法律通常为22:00-06:00）的工作 |
| lavoro festivo | work on public holidays | 法定公共假日的工作；需额外补偿 |
| ferie / congedo annuale | annual leave / holiday entitlement | 带薪休假（意大利最低20天，CCNL 通常更多） |
| permessi retribuiti | paid leave | 为指定目的提供的带薪休假 |
| congedo di maternità | maternity leave | 女雇员产前/产后带薪休假（意大利约5个月） |
| congedo di paternità | paternity leave | 父亲在子女出生时的强制性带薪陪产假（自第234/2021号法律起意大利为10个工作日；另加1天可选假） |
| congedo parentale | parental leave | 可休至子女年满12岁的育儿假（经修订的第151/2001号立法法令）；父母双方合计上限10个月（如父亲休满3个月可延长至11个月）；每位父母个人最多6个月；其中三个月按80%给付（2024年奖金）后续月份按30%，受收入条件限制 |
| malattia / assenza per malattia | sick leave | 因病缺勤；部分带薪（由 CCNL 和法律确定） |
| periodo di comporto | protected sick leave period | 雇主在解雇前必须容忍病假的最高期间（意大利法律概念；依《民法典》第2110条通常为180天）；给付和期间由 CCNL 确定 |
| infortunio sul lavoro | workplace accident / occupational injury | 由工作引起的人身伤害（通过 INAIL 承保） |
| sede di lavoro | place of work | 雇员履行职责的指定地点 |
| trasferta | business travel / posting | 需要在不同地点工作的临时派遣（不同于“secondment”/“distacco”） |
| smart working / lavoro agile | remote working / agile working | 利用电子通信在雇主场所之外的地点工作；由意大利法律（第81/2017号法律）规制 |
| telelavoro | telework | 定期在家或远程地点工作；意大利法律中的正式安排 |
| mansioni | duties / role | 分配给雇员的任务和职责；变更受意大利法律规制（雇员有权抵制不合理的降职） |
| inquadramento | classification / grading | 依适用 CCNL 将雇员归入合同级别/类别 |
| livello contrattuale | contractual grade / pay grade | CCNL 下的特定工资类别（例如“impiegato di 2° livello”） |
| qualifica | job title / qualification | 职位及所需资格的正式称谓 |

## 意大利雇佣类别（法定分类）

| 意大利语术语 | 英语对应 | 注释 |
|---|---|---|
| dirigente | executive / senior manager | 意大利法定雇佣类别（不仅是职衔）；解雇、通知期（通常1个月）、遣散费和福利适用不同规则；要求重大决策权；高薪；无权领取 TFR（TFR 等价物作为独立基金或转入补充养老金支付）；相当于“C-suite”或高级管理层，但法律定义更明确 |
| quadro | middle manager | 意大利法定雇佣类别；介于“impiegato”和“dirigente”之间；决策角色；有时称为“quadri”（复数）；解雇和通知规则不同 |
| impiegato | white-collar employee | 意大利法定雇佣类别；办公室职员、专业人员、行政角色；CCNL 下可有子级别（例如1°、2°、3°级）；有权领取 TFR；标准解雇/通知规则 |
| operaio | blue-collar worker | 意大利法定雇佣类别；体力/生产工人；CCNL 下可有子级别；有权领取 TFR；标准解雇/通知规则 |

## 意大利解雇与终止术语

| 意大利语术语 | 英语对应 | 注释 |
|---|---|---|
| licenziamento | dismissal / termination | 雇主发起的雇佣终止 |
| licenziamento per giusta causa | dismissal for just cause / summary dismissal | 因雇员严重不当行为而解雇；立即终止、无需通知（意大利法律，《民法典》第2119条）；区别于“giustificato motivo” |
| licenziamento per giustificato motivo soggettivo | dismissal for justified subjective reason | 基于未达严重不当行为的雇员行为而解雇（第604/1966号法律第3条）；需要通知期；区别于“giusta causa”（《民法典》第2119条） |
| licenziamento per giustificato motivo oggettivo | dismissal for justified objective reason | 基于经营需要、技术变革、裁员、公司重组而解雇（第604/1966号法律第3条）；需要通知和合规程序；区别于主观理由 |
| licenziamento collettivo | collective dismissal / redundancy | 因业务关闭、重组或重大改组而解雇多名雇员；受特殊程序约束（通知、磋商、社会计划） |
| licenziamento disciplinare | disciplinary dismissal | 对雇员不当行为经正式纪律程序后解雇 |
| dimissioni | resignation | 雇员发起的终止；通常需要通知期 |
| dimissioni per giusta causa | constructive dismissal / resignation for just cause | 因雇主严重违约而由雇员发起的辞职；雇员可能有权获得如同被解雇的遣散费；意大利概念与推定解雇法理一致 |
| preavviso | notice period | 终止生效前的期间；长度因 CCNL、雇佣级别和解雇理由而异（蓝领最低1天；其他类别不同） |
| periodo di preavviso | notice period | 终止通知后雇员/雇主必须等待的期间 |
| impugnazione del licenziamento | challenge of dismissal / unfair dismissal claim | 雇员质疑解雇效力的法律诉讼 |
| reintegrazione | reinstatement | 将被解雇雇员恢复原职或等效职位的救济（意大利法律视情况可裁定“复职”或补偿） |
| indennità risarcitoria | compensatory indemnity / damages | 对不当/不公平解雇向雇员支付的金钱赔偿（意大利法律根据解雇理由和程序合规性确定适用“复职”或“补偿”救济） |
| tutela reale | real protection (reinstatement remedy) | 要求恢复被不当解雇雇员职位的救济（意大利法律区分；适用于程序违规或不合理解雇） |
| tutela obbligatoria | obligatory protection (compensation remedy) | 以金钱补偿代替复职（意大利法律区分；在某些情况下可替代复职适用） |

## 意大利集体劳动术语

| 意大利语术语 | 英语对应 | 注释 |
|---|---|---|
| CCNL / contratto collettivo nazionale di lavoro | national collective bargaining agreement (NCBA) | 雇主协会与工会谈判达成的国家级主集体协议；规定整个部门/行业的最低条款（例如零售业“CCNL Commercio”、工程业“CCNL Metalmeccanica”）；在意大利具有强制性；适用于覆盖部门的所有雇员，除非更高层级的公司协议提供更优条款；载明雇佣类别（dirigente、quadro、impiegato、operaio）、工资等级、工时、休假、通知期、TFR 处理、纪律程序等 |
| contratto integrativo aziendale | company-level collective agreement | 雇主与工会/工人代表在公司层面谈判达成的协议；补充或改进适用 CCNL |
| accordo sindacale | trade union agreement | 雇主与工会就特定雇佣事项达成的协议 |
| sindacato | trade union | 代表工人与雇主谈判的正式组织 |
| rappresentanza sindacale aziendale / RSA | company trade union representation | 公司层面的工会提名工人代表（意大利法律概念） |
| rappresentanza sindacale unitaria / RSU | unified trade union representation | 公司层面的多工会工人代表结构（意大利法律概念；跨多个工会的统一代表） |
| assemblea dei lavoratori | workers' assembly | 雇员讨论集体事务的正式会议 |
| diritto di sciopero | right to strike | 采取产业行动的法定权利；在基本服务中受限 |
| cassa integrazione guadagni / CIG | wage supplementation fund / short-time working scheme | 意大利政府支持计划，在雇主因经济/技术困难减少工时时提供部分收入 |
| CIG ordinaria | ordinary wage supplementation | 针对暂时性经济困难的 CIG（最长12个月，可延长） |
| CIG straordinaria | extraordinary wage supplementation | 针对重大重组或危机的 CIG（期间较长，通常长于 ordinaria） |
| mobilità (storica) | redundancy scheme (historic) | 曾经的意大利计划，援助因重组而失业的工人；大体被第92/2012号法律废除，并依《就业法》于2017年1月1日前逐步取消；现行对应物为 NASpI（失业保险金，第22/2015号立法法令）及针对重大重组的 CIGS |
| procedura di licenziamento collettivo | collective redundancy procedure | 大规模解雇的法定程序（需要通知、磋商、社会计划；通常最少1-2个月通知，视受影响人数而定） |
| consultazione sindacale | trade union consultation | 雇主就重大雇佣决策（例如重组、大规模解雇）与工会/工人代表进行强制性磋商 |

## 意大利借调与派遣术语

| 意大利语术语 | 英语对应 | 注释 |
|---|---|---|
| distacco | secondment | 雇员由原雇主临时派往接收公司工作，同时保留与原雇主的雇佣关系；意大利概念（第276/2003号立法法令第30条——Biagi 改革）；如跨境则可能触发欧盟《派遣工人指令》（96/71/EC，经2018/957更新） |
| distacco transnazionale | cross-border posting / transnational secondment | 跨境借调；适用欧盟《派遣工人指令》（指令 96/71/EC），要求母国雇佣/派遣条件；经指令 2018/957/EU 更新 |
| impresa distaccante | seconding company | 与被借调工人保留雇佣关系的雇主；支付工资/福利；对雇佣法合规负责 |
| impresa utilizzatrice | host company | 使用被借调工人服务的雇主；通常不是雇佣合同当事人（尽管可指导工作） |
| lavoratore distaccato | seconded employee / posted worker | 被派遣公司保留、临时为接收公司工作的雇员 |
| somministrazione di lavoro | temporary agency work | 由劳务派遣机构向客户雇主提供工人；目前由第276/2003号立法法令（Biagi 改革）第30条起各条规制，经第81/2015号立法法令（《就业法》）修订。较早的“lavoro interinale”由第196/1997号法律（Pacchetto Treu）引入，此后已被取代 |
| agenzia per il lavoro | temporary employment agency | 获许可向客户雇主招聘和提供临时工人的企业（意大利受监管职业） |
| lavoratore somministrato | agency worker / temporary worker | 由劳务派遣机构提供的工人；技术上受雇于派遣机构，但为客户履行工作 |

## 关键翻译注释

- **CCNL（Contratto Collettivo Nazionale di Lavoro）**：规范整个部门/行业的主集体协议。在意大利雇佣法下具有强制性。英文翻译中，保留 CCNL 缩写并在首次使用时附英文全称（例如“CCNL Commercio, the National Collective Bargaining Agreement for the Retail Sector”）。关键内容：雇佣类别、工资等级、工时、休假权利、通知期、TFR 处理、纪律程序等。

- **“Giusta causa”与“giustificato motivo”**：意大利法律中的关键区分，法律后果不同：
  * Giusta causa（《民法典》第2119条）：严重不当行为；允许立即解雇且无需通知；雇员无权获得通知补偿；遣散费较低
  * Giustificato motivo（第2119条、第604/1966号法律）：较轻的理由；需要通知期；全额遣散费/TFR；程序要求较宽松
  不得将两者混同或都译为“dismissal for cause”；保持意大利法律框架。

- **雇佣类别**（dirigente、quadro、impiegato、operaio）：CCNL 下的意大利法定分类，通知、遣散费、解雇、福利规则各不相同。并非任意职衔。英文翻译中：
  * Dirigente = executive/senior manager（规则不同；通知期较短；TFR 不直接支付；薪酬往往较高；通常1个月通知）
  * Quadro = middle manager（中间地位；增强的通知/解雇保护；有权领取 TFR）
  * Impiegato = white-collar/professional（CCNL 下可有1°、2°、3°子级别；有权领取 TFR）
  * Operaio = blue-collar/manual worker（CCNL 下可有子级别；有权领取 TFR）
  在子词典中注明意大利类别；在主词典中译为英文描述。

- **TFR（Trattamento di Fine Rapporto）**：《意大利民法典》第2120条。每年累积的法定遣散费（每年约月薪的1/13.5），在终止时（退休、辞职、解雇、死亡）支付。无精确普通法对应。译为“severance indemnity”或“end-of-service allowance”，首次使用时括号保留“TFR”。注意：Dirigente 可能不直接领取 TFR（TFR 等价物支付给养老基金或另行安排）。

- **“Comporto”（受保护病假期间）**：意大利法律概念。雇主在解雇合法前必须容忍的最高累计期间（依《民法典》第2110条通常为180天，但由 CCNL 和判例确定；因部门和公司协议而异）。不同于英美语境中的“protected sick leave”。

- **解雇救济**：意大利法律对程序无效/不合理解雇提供两种救济：
  * Tutela reale（复职救济）：恢复原职或等效职位并补发工资
  * Tutela obbligatoria（补偿救济）：以金钱补偿代替复职
  两者视解雇理由和程序违规情况适用。除非源文件明确指向英国“unfair dismissal”标准，否则不要使用。

- **“Somministrazione di lavoro”**（劳务派遣）：由第276/2003号立法法令（Biagi 改革）第30条起各条规制，经第81/2015号立法法令（《就业法》）修订；较早的“lavoro interinale”由第196/1997号法律引入，此后已被取代。区别于借调（distacco）。派遣机构是法定雇主；客户只是服务使用方。受同等待遇规则约束（工资、福利、工作条件与客户直接雇员相比）。

- **“Distacco”**（借调）：保留原雇主关系的临时派遣。由第276/2003号立法法令（Biagi 改革）第30条规制。如跨境，适用欧盟《派遣工人指令》（96/71/EC，经2018/957更新）。不同于“trasferta”（商务差旅）。

- **《就业法》引用**：意大利雇佣法经第23/2015号立法法令（《就业法》）发生重大改革。关键变化：取消 co.co.co. 作为标准形式；为合同引入“真正独立”标准；修改小公司的解雇救济（不同补偿上限）；改变试用规则；加强对固定期限合同的保护。如源文件引用《就业法》前或后的法律，在子词典中注明区别。

- **通知期**：因 CCNL、雇佣级别和解雇理由而异。示例：
  * 蓝领（“operaio”）：通常1-2天通知
  * 办公室/专业人员（“impiegato”）：通常1-2个月
  * 中层管理（“quadro”）：通常1-3个月
  * 高管（“dirigente”）：通常1个月（往往短于 impiegato）
  具体通知期始终援引适用 CCNL 或雇佣法。

- **CIG（Cassa Integrazione Guadagni）**：意大利工资补充基金。政府资助计划，向因暂时性经济/技术困难（CIG ordinaria）或重大重组（CIG straordinaria）而工时缩减的雇员提供部分收入（通常为工资的80%）。工人仍受雇；不同于失业救济金。期间因类型和政府授权而异。

- **Mobilità**：意大利裁员计划，为因重组而失业的工人提供收入支持。区别于 CIG；表明重组后可能永久解雇。

- **INPS / INAIL**：强制性保险计划：
  * INPS（Istituto Nazionale della Previdenza Sociale）：国家社会保障机构；管理养老金、失业、生育、伤残救济金
  * INAIL（Istituto Nazionale per l'Assicurazione contro gli Infortuni sul Lavoro）：工伤保险；雇主缴费；承保工伤和职业病

- **集体裁员程序（procedura di licenziamento collettivo）**：雇主因重组解雇多名雇员时适用。须与工会磋商、谈判社会计划、最低通知期（因受影响人数而异，通常1-2个月）。未遵循程序可能使解雇无效。
