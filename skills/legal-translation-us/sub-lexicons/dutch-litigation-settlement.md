## 翻译者注释

- **Dagvaarding 与 verzoekschrift 之别**：荷兰民事诉讼有两条主要路径。Dagvaarding（传唤令状）——适用于大多数以司法令状启动诉讼的民事事项。Verzoekschrift（请愿书）——适用于家庭、雇佣（2020 年改革前）、遗嘱认证及部分公司事项。时间线不同，当事方术语不同（eiser/gedaagde 与 verzoeker/verweerder）。始终识别程序类型并一致翻译。
- **Kort geding**：标志性的荷兰程序工具。向 voorzieningenrechter 以"spoedeisend belang"（紧急利益）为由提起的快速救济程序（通常 4 周内出结果）。大量用于知识产权、不正当竞争、合同执行。译为"preliminary relief proceedings"并加注——绝不要只译成"summary proceedings"（过于狭窄）。
- **Vonnis 与 arrest 与 beschikking 之别**：Vonnis = 一审判决（dagvaarding 程序）。Arrest = gerechtshof 或 HR 的判决。Beschikking = 命令/决定（请愿程序、小事项、破产）。三个不同术语、三套不同规则。绝不要扁平化为"judgment"。
- **Hoger beroep 与 cassatie 之别**：Hoger beroep = 向 gerechtshof 的全面上诉（事实 + 法律审查）。Cassatie = 由 Hoge Raad 仅就法律问题进行的审查（无事实审查）。性质根本不同。分别译为"appeal"和"cassation"。
- **Ondernemingskamer (OK)**：阿姆斯特丹上诉法院内的专门公司审判庭。管辖调查程序（enquêteprocedure）、董事罢免、法定争议解决（geschillenregeling）、强制挤出（squeeze-out）。荷兰独特机构。译为"Enterprise Chamber"（标准英文译法）。
- **Netherlands Commercial Court (NCC)**：2019 年 1 月起在阿姆斯特丹地方法院和阿姆斯特丹上诉法院运作的英语商事法庭。经当事方约定管辖超过 25,000 欧元的国际商事争议。译为"Netherlands Commercial Court"——保留英文名称。
- **Awb / bestuursrecht**：荷兰行政法整合于 Awb。向行政法院起诉前须先"bezwaar"（向行政机关本身提出异议）。诉讼资格须通过 belanghebbende 测试。与民事诉讼原则不同（evenredigheid、zorgvuldigheid、motivering）。绝不要用民事术语翻译行政程序。
- **Woo（Wet open overheid）**：2022 年 5 月取代 Wob。披露义务更广。译为"Open Government Act"——如文件为 2022 年前则标注过渡。
- **WAMCA（2020）**：重大改革，使损害赔偿集体诉讼成为可能（此前限于确认性/禁令性救济）。登记代表组织享有排他地位，荷兰籍适用退出制。译为"Collective Damages Act"；始终标注 WAMCA 适用性。
- **WCAM（2005）**：全球约束力和解机制。由阿姆斯特丹上诉法院宣告和解对全体集体成员有约束力；集体成员有退出权。用于 Converium、Shell、Fortis 大规模侵权案件。与 WAMCA 不同（后者使诉讼成为可能；WCAM 使和解成为可能）。
- **Vaststellingsovereenkomst（BW 7:900）**：荷兰和解协议文书。即使基于对法律的错误理解也具约束力。常用于解决民事和商事争议。译为"settlement agreement"；说明其约束性质。
- **Dwangsom（Rv 第 611a 条）**：为强制遵守判决而设的司法罚款。须经请求——并非自动。不同于合同违约金（boete）。译为"penalty payment"或大陆法系用语"astreinte"并加注。
- **Bewijslast / stelplicht**：荷兰证据法有两种不同的负担：stelplicht（在诉状中充分陈述事实的义务）和 bewijslast（事实有争议时的举证责任）。stelplicht 在前——主张不充分则不会采证。stelplicht 译为"duty to set out facts"或"pleading burden"；绝不要扁平化为"burden of proof"。
- **Verjaring 与 vervaltermijn 与 klachttermijn 之别**：三个不同的时效概念。Verjaring = 消灭时效，可因中断行为（例如书面催告）而中断。Vervaltermijn = 失权期限，绝对性（不可中断、不可延长）。Klachttermijn = 投诉义务（BW 6:89、7:23）——沉默可能导致权利丧失。三者均重要——绝不可混同。
- **Advocaat 与 procureur 之别**：2008 年改革前，当事方需要当地 procureur 加 advocaat。自《废止 procuraat 法》（2008）起，律师全国准入。"advocaat"按受众译为"attorney""lawyer"或"advocate"；"procureur"仅在历史语境中使用。
- **OM / Officier van justitie**：Openbaar Ministerie（公诉机关）是总称；officier van justitie 是个别检察官。在 Hoge Raad，该角色为 advocaat-generaal（AG）。一致翻译并识别机构层级。
- **TBS（terbeschikkingstelling）**：荷兰刑法中针对危险精神障碍罪犯的措施——有别于监禁的不定期强制治疗。荷兰独特机构。译为"TBS-order"或"placement under hospital order"并加注。
- **Strafbeschikking / transactie**：两种庭外刑事解决机制。Strafbeschikking = OM 签发的刑事处罚令、定罪认定（2008 年起）。Transactie = 较旧的、2008 年前的机制，避免定罪认定。两者都避免庭审，但法律地位不同。标注并谨慎翻译。
- **Arbitragewet 2015 / NAI**：2015 年荷兰仲裁法的重大现代化（现为 Rv 第四编）。NAI（荷兰仲裁协会）是主要机构机构。阿姆斯特丹日益被用作仲裁地。译为"Arbitration Act 2015"和"Netherlands Arbitration Institute"。
- **Bindend advies 与 arbitrage 之别**：荷兰 ADR 区分 bindend advies（具有约束力的专家裁定——可按 BW 7:904 就明显错误审查）与 arbitrage（仲裁——裁决具有纽约公约可执行性）。不同制度——绝不可混淆。bindend advies 译为"binding advice"并加注；arbitrage 译为"arbitration"。
- **Proceskostenveroordeling / liquidatietarief**：荷兰费用制度非全额赔偿——可追偿费用受法官设定的固定费率（liquidatietarief）上限约束，知识产权事项除外（按 Rv 第 1019h 条全额费用）及若干其他特定领域。忠实翻译并标注费用追偿限制。
- **比利时民事诉讼**：由《司法法典》（Gerechtelijk Wetboek——GerW / Code judiciaire）管辖——编号和术语与荷兰 Rv 不同。比利时与荷兰类似地使用"kort geding"。比利时上诉至 Hof van Beroep / Cour d'appel；撤销审至 Hof van Cassatie / Cour de cassation。标注比利时文件。
- **比利时行政诉讼**：由关于 Raad van State / Conseil d'État 的协调法律管辖。与荷兰 Awb 制度不同——比利时设有统一的行政最高法院（Raad van State，Afdeling Bestuursrechtspraak）。标注比利时行政文件。
- **比利时刑事诉讼**：比利时使用《刑事诉讼法典》（Wetboek van Strafvordering / Code d'instruction criminelle，拿破仑式）和《刑法典》（Strafwetboek / Code pénal）。预审法官（onderzoeksrechter / juge d'instruction）的作用比荷兰 R-C 更大。术语不同。
