# 日本税法——分词典

与 `references/taxes.md`（主税法词典）和 `sub-lexicons/japanese-corporate-ma-jv.md`（公司法/并购接口）配套使用。

本分词典涵盖日本税法。

## 2. 直接税——税基、税率、分配

| 日文术语 | 中文释义（英文对应） |
|---|---|
| 課税所得 | 应税所得（taxable income） |
| 益金 | 收益（gross income items，正数基项调整） |
| 損金 | 损失/可扣除项目（loss/deductible items） |
| 益金算入 / 益金不算入 | 计入收益/不计入收益（inclusion / exclusion from gross income） |
| 損金算入 / 損金不算入 | 计入损失/不计入损失（deductibility / non-deductibility） |
| 受取配当等の益金不算入 | 收取股息等不计入收益（dividend-income exclusion from gross income，参股免税机制） |
| 完全子法人株式等 / 関連法人株式等 / その他株式等 / 非支配目的株式等 | 全资子公司股份等/关联法人股份等/其他股份等/非支配目的股份等（wholly-owned subsidiary stock / related-corporation stock / other stock / non-controlling stock，四档决定股息剔除比例） |
| 完全子法人株式等 (100%益金不算入) | 全资子公司股份等（wholly-owned-subsidiary stock，100% 剔除；持股须达 100% 且贯穿始终） |
| 関連法人株式等 (100%益金不算入、関連利子控除後) | 关联法人股份等（related-corporation stock，100% 剔除但扣除关联利息；持股 >1/3 且达 6 个月以上） |
| その他株式等 (50%益金不算入) | 其他股份等（other stock，50% 剔除；持股 >5% 至 ≤1/3） |
| 非支配目的株式等 (20%益金不算入) | 非支配目的股份等（non-controlling-purpose stock，20% 剔除；持股 ≤5%） |
| 繰越欠損金 | 亏损结转（loss carry-forward，2018 财年起为 10 年；此前为 9 年） |
| 欠損金の繰戻還付 | 亏损结转退还（loss carry-back refund，原则上暂停；中小企业/上市公司减资情形可适用） |
| 青色申告 | 蓝色申报（blue-form return，可享受亏损结转、准备金选择、加计扣除） |
| 白色申告 | 白色申报（white-form return） |
| 減価償却 | 折旧（depreciation） |
| 定額法 / 定率法 | 定额法/定率法（straight-line / declining-balance method） |
| 一括償却資産 | 一次性摊销资产（lump-sum depreciable assets） |
| 少額減価償却資産 | 小额折旧资产（low-value depreciable assets，低于 10 万日元，或依 STML 中小企业最高 30 万日元） |
| 交際費 | 交际费（entertainment expenses，大企业不可扣除；中小企业限额扣除） |
| 寄附金 | 捐款（donations，按公式限额扣除） |
| 役員給与 | 高管薪酬（director remuneration，扣除须符合规定形式：定期同额、业绩联动、事前确定申报） |
| 定期同額給与 / 事前確定届出給与 / 業績連動給与 | 定期同额薪酬/事前确定申报薪酬/业绩联动薪酬（regular-fixed salary / pre-notified fixed salary / performance-linked salary，三种可扣除的高管薪酬形式） |
| 同族会社 | 同族公司（closely-held corporation，家族控制） |
| 特定同族会社 | 特定同族公司（specified closely-held corporation，顶层股东集中；留存收益课税） |
| 留保金課税 | 留存收益课税（retained-earnings tax，针对特定同族公司） |
| 国際戦略総合特区 | 国际战略综合特区（International Strategic Comprehensive Special Zone） |
| 総合課税 / 分離課税 | 综合课税/分离课税（comprehensive taxation / separate taxation，个人所得税下不同所得类别合并或单独计税） |
| 10種類の所得区分 | 十类所得（interest, dividend, real-estate, business, employment, retirement, timber, transfer, occasional, miscellaneous，即利息、股息、不动产、事业、工资、退休、山林、转让、临时、杂项） |
| 利子所得 / 配当所得 / 不動産所得 / 事業所得 / 給与所得 / 退職所得 / 山林所得 / 譲渡所得 / 一時所得 / 雑所得 | 利息所得/股息所得/不动产所得/事业所得/工资所得/退休所得/山林所得/转让所得（资本利得）/临时所得/杂项所得（interest / dividend / real-estate / business / employment / retirement / timber / transfer / occasional / miscellaneous income） |

译者注：**收取股息剔除（受取配当等の益金不算入）**是日本的参股免税机制——通过将股息从收益中剔除实现，而非税率层面的免税。现行法律下（2015 年 STML 改革后）分四档：**全资子公司 100%**（完全母子公司关系，持股 ≥1/3）、~~第三档已删除~~、其他持股（>5% 但非全资/关联）50%、非支配持股（<5%，持股不足 6 个月）20%。翻译须精确并标注年份，因为 2015 年改革大幅收窄了剔除范围。外国子公司股息自 2009 年起依 STML 23-2 另行适用 95% 剔除制度（见第 4 节）。

个人所得税的**十类所得**极具日本特色——每类各有其计算规则，部分与累进税级合并计税（総合課税），部分按各自的统一税率单独计税（分離課税）。务必明确所涉所得类别。

## 3. JCT（消費税）——日本消费税

| 日文术语 | 中文释义（英文对应） |
|---|---|
| 消費税 (国 7.8% + 地方 2.2% = 10%) | 消费税（Consumption Tax，JCT；国税 7.8% + 地方 2.2% = 合计标准税率 10%） |
| 軽減税率 (8%: 国 6.24% + 地方 1.76%) | 轻减税率（reduced rate，8%；供家庭消费的食品饮料、非酒精饮料；报纸） |
| 非課税 | 免税（exempt） |
| 不課税 | 非课税范围（out of scope，不在法律适用范围内的非应税项目） |
| 免税 | 零税率（zero-rated，如出口） |
| 課税売上 | 应税销售额（taxable sales） |
| 課税仕入 | 应税采购额（taxable purchases） |
| 仕入税額控除 | 进项税额扣除（input tax credit，采购税额扣除） |
| 課税事業者 | 应税经营者（taxable person） |
| 免税事業者 | 免税（小规模）经营者——营业额 ≤1000 万日元门槛（exempt (small) business） |
| みなし仕入率 | 视同采购率（deemed purchase rate，简易课税方式下） |
| 適格請求書等保存方式 (インボイス制度) | 合格请求书等保存方式（Qualified Invoice System，即“发票制度”；自 2023 年 10 月 1 日起施行） |
| 適格請求書発行事業者 | 合格请求书发行经营者（qualified invoice-issuing business，已登记） |
| 適格請求書 | 合格请求书（qualified invoice） |
| 請求書等 | 请求书等（invoice etc.） |
| 特定仕入れ / リバースチャージ | 特定采购/反向征收（specified purchase / reverse charge，适用于海外 B2B 数字服务及某些其他入境供应） |
| 電気通信利用役務の提供 | 电信利用服务的提供（supply of telecommunication-utilizing services，电子服务） |
| 事業者向け電気通信利用役務 | B2B 电子服务（B2B e-services，适用反向征收） |
| 消費者向け電気通信利用役務 | B2C 电子服务（B2C e-services，海外供应商须在日本登记为应税经营者） |

译者注：**合格请求书等保存方式（適格請求書等保存方式）**，俗称“发票制度”，于 **2023 年 10 月 1 日**施行——要求发票载有已登记的合格请求书发行经营者编号，方可享受进项增值税抵免。译为“Qualified Invoice System”或“Invoice System”（保留）。跨境 B2B 电子服务的**反向征收机制**于 2015 年 10 月引入，至今仍很重要。

自 2023 年 10 月 1 日起，日本 JCT 为单阶段凭发票抵扣的增值税；**税率**：标准 10%、轻减 8%（家庭消费食品+报纸）。2019 至 2023 年间曾采用过渡性记账方法（区分记载请求书等）。务必标注适用期间。

译者注：日本于 **2009 年废止间接外国税额抵免**，以 STML 23-2 项下的 **95% 外国子公司股息剔除**取代。持有外国子公司 ≥25% 股份且持股 ≥6 个月的，股息按 95% 从收益中剔除（5% 视为不可扣除的费用分摊）。务必标注年份及 25%/6 个月条件，并注意协定降低的股息预提税门槛在有利协定适用时可能改变 25% 的门槛。

**2.1% 复兴附加税**适用于所有国家所得税/预提税税基，直至 **2031 年 12 月 31 日**（已延长；原为 25 年）。例如，上市股息 15% 的预提税率变为 15.315%。为 2013 年后文件引用税率时务必计入附加税。

## 15. 注释与注意事项

- **引用格式。** 日本税法的引用为*法律名称 + 条文*：例如 *法人税法 22 条* = “Corporation Tax Act Art. 22”；*租税特別措置法 42 の 4* = “STML Art. 42-4”。款项使用 項（款）和 号（项）。完整引用如 *法人税法 132 条の 2 第 1 項第 1 号* = “CIT Act Art. 132-2(1)(i)”。日文使用“条の”时保留“Article X-Y”格式（如 132 条の 2 → Art. 132-2）。
- **判例引用。** 日本最高法院案例引用为 *最判 [日期] 民集 [卷]-[页]* 或 *最判令和 [年] [月] [日]*。有时也使用案件俗称（如“Yahoo! Japan 案”“IBM 案”）——英文译文通常使用俗称。
- **年号引用 → 公历。** 日本税法经常按年号引用年份（如 令和 5 年度税制改正 = “FY 2023 tax reform”）。按照 `references/general-legal.md` 的通用规则和 `japanese-general-legal.md` 中的年号表，英文输出中每个此类引用均应完整转换为公历——绝不使用 `Reiwa`、`Heisei`、`Showa`、`Taisho` 或 `Meiji`（严格规则，无首次出现例外）。
- **年度税制改革（税制改正）。** 日本税制改革周期为每年一次——“令和 X 年度税制改正大綱”（X 财年税制改革大纲）于财年之前的 12 月发布，春季实施（对 4 月 1 日开始的财年，最迟于 3 月 31 日）。规则可能逐年变化——务必核实具体规则的生效日期。
- **第二支柱。** IIR（“所得合算规则”）由 2023 年第 3 号法实施，自 2024 年 4 月 1 日以后开始的财年起施行。UTPR 和国内 QDMTT 在 2024 至 2025 财年改革中审议，生效日期分别延至 2025 年 4 月 1 日（UTPR）及更晚（QDMTT）。鉴于变化速度较快，务必核实最新状态。
- **消费税“发票制度”过渡期。** 发票制度于 2023 年 10 月 1 日施行。2023 至 2029 年过渡期规则允许对未登记供应商开具的发票按比例享受进项税抵免（2023 年 10 月 1 日至 2026 年 9 月 30 日为 80%；2026 年 10 月 1 日至 2029 年 9 月 30 日为 50%；此后为 0%）。标注交易日期。
- **集团通算制度。** 自 2022 年 4 月 1 日以后开始的财年起施行，取代旧的合并纳税制度（連結納税）。新制度要求每个集团成员自行计算其应税所得和税额，集团层面就亏损进行通算调整。可选适用。不同于强制性的 100% 集团法人税制（グループ法人税制）。
- **同族公司留存收益课税（留保金課税）。** 对特定同族公司超过门槛的累计留存收益加征 10/15/20% 法人税。中小企业（注册资本 ≤1 亿日元）免征。翻译须精确并标注规模门槛。
- **复兴附加税。** 对所有国家所得税（含预提税）征收的 2.1% 特别所得税。适用于 2013 年 1 月 1 日起至 2037 年 12 月 31 日止的款项（已延长）。引用净税率时务必计入。另有“复兴特别法人税”（復興特別法人税）——但该税已对 2014 年 4 月 1 日以后开始的财年废止（仅征收 3 年）。注意区分。
- **易混词（false friends）。**
  - *税* → tax（常用汉字；注意：*課税* = 课税，*非課税* = 免税，*脱税* = 逃税）。
  - *法人税* → Corporation Tax（日本的惯用英文；“corporate income tax”亦可接受，但“Corporation Tax”是日本国税厅译文的惯用表达）。
  - *事業税* → Enterprise Tax（县级税；不是旧中国营业税意义上的 business tax）。
  - *消費税* → Consumption Tax / JCT（不是“sales tax”——JCT 是凭发票抵扣的增值税）。
  - *印紙税* → Stamp Duty（不是“stamp tax”——惯例）。
  - *登録免許税* → Registration and License Tax（复合：登记+许可）。
  - *源泉徴収* → withholding at source。
  - *益金 / 損金* → gross income items / deductible-loss items（税收专用术语，非字面的“收益金/损失金”）。
  - *適格 / 非適格* → qualified / non-qualified（重组和薪酬语境中）。
  - *組織再編成* → organizational restructuring。
  - *繰延* → deferral（损益的递延）。
  - *受取配当等の益金不算入* → dividend-income exclusion from gross income（日本的参股免税机制）。
  - *合算* → aggregation / inclusion（所得的合算；如 CFC *合算課税* = CFC inclusion）。
  - *措置法* / *租特* → Act on Special Measures Concerning Taxation（STML）——简称。
  - *確定申告* → final tax return（年度申报；与 *修正申告* amended return 相对）。
  - *更正* → correction（税务机关作出；不是“renewal”）。
  - *同族会社* → closely-held corporation（不是“same-tribe”；判定标准为 ≤3 个股东群体合计持股 >50%）。
  - *国外転出時課税* → exit tax on emigration。
  - *ふるさと納税* → Furusato Nozei（家乡纳税捐赠；作为专有名词保留）。
