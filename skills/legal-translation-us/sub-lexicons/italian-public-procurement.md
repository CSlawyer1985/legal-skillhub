# 意大利公共采购子词典

意大利特有的公共采购术语和参考。这些实体、法规和程序为意大利特有，应在主词典中译为英文。

## 意大利特有实体与机关

| 意大利语术语 | 英文对应词 | 备注 |
|---|---|---|
| ANAC | ANAC（意大利国家反腐败局） | 意大利监管机构；依 190/2012 号法律设立。首次出现时解释为“负责采购监督和腐败预防的意大利监管机构”。 |
| SOA / attestazione SOA | SOA certification / works qualification（SOA 认证 / 工程资格） | 意大利特有的建筑承包商认证体系。SOA = Società di Attestazione（认证机构）。类别 I–VIII 依合同价值划分。 |
| categoria e classifica SOA | SOA category and classification（SOA 类别与分级） | 意大利评定建筑工程承包商能力的体系。 |
| Codice dei Contratti Pubblici (D.Lgs. 36/2023) | Public Contracts Code（《公共合同法典》，第 36/2023 号立法法令） | 意大利主要公共采购立法，自 2023 年 1 月 1 日起施行。转化实施指令 2014/24、2014/25、2014/23。此前法典为 D.Lgs. 50/2016。 |
| D.Lgs. 50/2016 | Legislative Decree 50/2016（第 50/2016 号立法法令，已被取代） | 意大利此前的公共采购法典。检查文件日期以确定适用哪部。 |
| Certificazione Antimafia | Anti-mafia certification（反黑手党认证） | 意大利要求的、由反黑手党部门出具的确认无黑手党关联的认证。某些公共工程合同需要。 |

## 意大利采购程序与概念

| 意大利语术语 | 英文对应词 | 备注 |
|---|---|---|
| Responsabile Unico del Progetto (RUP) | Project Manager (contracting authority) / Contract Manager（项目经理〈采购方〉/ 合同经理） | 意大利术语，指代表采购方负责管理和监督采购及合同的唯一官员。英文合同中通常不使用；请改指具体角色。 |
| Stazione appaltante | Contracting authority（采购机关） | 意大利术语；负责委托采购的实体。 |
| Amministrazione aggiudicatrice | Contracting authority（采购机关） | stazione appaltante 的同义词，用于欧盟指令语境。 |
| Ente aggiudicatore | Contracting entity（采购实体） | 用于公用事业或其他受《公用事业指令》约束的实体。 |
| Operatore economico | Economic operator（经济经营者） | 提供货物或服务的任何自然人或法人。 |
| Appalto pubblico | Public contract（公共合同） | 所有公共采购合同的总称。 |
| Appalto di lavori | Works contract（工程合同） | 建筑/基础设施工程合同。 |
| Appalto di servizi | Service contract（服务合同） | 服务（设计、咨询、维护等）合同。 |
| Appalto di forniture | Supply contract（供应合同） | 货物合同。 |
| Concessione | Concession（特许经营） | 将运营/财务风险转移给特许经营者的协议。 |
| Concessione di lavori | Works concession（工程特许经营） | 基础设施建设和运营的特许经营。 |
| Concessione di servizi | Service concession（服务特许经营） | 公共服务运营的特许经营。 |
| Partenariato pubblico-privato (PPP) | Public-private partnership（公私合作，PPP） | 公共机关与私营实体之间的结构化合作。 |
| Project financing | Project finance（项目融资） | 大型 PPP/特许经营项目的融资结构。 |
| Finanza di progetto | Project finance（项目融资） | project financing 的同义词。 |
| Raggruppamento temporaneo di imprese (RTI) / Associazione temporanea di imprese (ATI) | Temporary grouping / joint venture / consortium（临时联合体 / 合资 / 联营体） | 为单一招标而组成的经济经营者联合。合同完成后解散。ATI 是 109/1994 号法律下的传统名称；现行《公共合同法典》下使用 RTI。 |
| Raggruppamento orizzontale | Horizontal grouping（横向联合） | 成员承担同类型工程/服务，按比例分摊。 |
| Raggruppamento verticale | Vertical grouping（纵向联合） | 牵头成员承担主要工程；mandanti（成员）承担附属工程。 |
| Raggruppamento misto | Mixed grouping（混合联合） | 结合横向和纵向安排。 |
| Consorzio stabile | Permanent consortium（常设联营体） | 承包商的长期联合，跨多个项目保持存续。 |
| Avvalimento | Reliance on third-party resources（依赖第三方资源） | 经营者依赖另一实体的技术/财务能力；由 D.Lgs. 36/2023 第 104 条规范（转化实施指令 2014/24/EU 第 63 条）。 |
| Avvalimento operativo | Operational reliance（运营性依赖） | 辅助企业以自身资源参与履行的依赖。 |
| Avvalimento di garanzia | Guarantee-based reliance（担保性依赖） | 辅助企业仅提供其财务实力（而非运营资源）的依赖。 |
| Soccorso istruttorio | Remedial documentation procedure（补正程序） | 采购机关给予投标人修正投标中轻微文件缺陷的正式机会。 |
| MEPA | Mercato Elettronico della Pubblica Amministrazione（公共行政电子市场，MEPA） | 低于阈值合同的国家电子采购平台。 |
| Consip | Consip S.p.A. | 意大利经济和财政部的中央采购机构。 |

## 意大利招标与采购程序

## 备注

- **ANAC 指引**：意大利 ANAC 发布采购规则指南和解释。这些可能比欧盟最低标准更严格。

- **SOA 体系**：意大利 SOA 认证对意大利大多数公共工程合同是强制性的，但为意大利特有。翻译意大利文件时务必在首次使用时加以解释。

- **RUP 指定**：意大利法律要求每次采购指定一名单一项目经理（RUP）。该角色没有直接的普通法对应物；请描述具体职责而非翻译缩写。

- **Decreto-legge 与 Decreto legislativo 的区别**：意大利紧急法令（“decreto-legge”）是临时性的，必须转化为法律；立法法令（“decreto legislativo”）用于转化实施指令。务必说明适用的是哪种。

- **内部提供**：“Teckal 豁免”（源自 CJEU 判例法，而非意大利法律）允许公共机构不经采购而与另一公共机构缔约。常与意大利法下的“affidamento in house”概念混淆。

- **Ricorso / 上诉**：意大利行政法使用“ricorso”（上诉/复审），由专门法院审理（TAR = Tribunale Amministrativo Regionale，大区行政法院）。英文合同中译为“procurement challenge”或“review proceedings”。
