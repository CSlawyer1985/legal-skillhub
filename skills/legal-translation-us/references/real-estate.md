# 房地产词典

房地产协议的标准英语术语：租赁（商业和住宅）、购买协议、财产转让、地役权、所有权、分区、施工许可、物业管理及相关文书。

## 转让与所有权术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| ownership / title / right of ownership | 拥有和控制财产的法律权利。 | — |
| freehold / full ownership | 对土地和建筑无期限限制的所有权。英式："freehold"；美式："fee simple"。 | — |
| leasehold | 在固定期限内占用财产的权利的所有权；复归利益仍归 freeholder。英国概念；大陆法系长期土地租赁见下方 "long lease / ground lease / emphyteusis"。 | — |
| bare ownership / naked ownership | 无使用或收益权的财产所有权；用益权人有权使用。大陆法系概念。 | — |
| usufruct / life interest | 在指定期限或终身使用和收益他人财产的权利。英式："life interest"；美式：罕见。大陆法系概念。 | Right of enjoyment（不够精确）；Beneficial interest（信托中概念不同） |
| right of superficies / building right | 在他人土地上或地下建造并保留结构所有权的权利。大陆法系概念。 | Building lease（概念不同）；Ground lease（美式，相关但不同） |

| easement / servitude | 为特定目的（通行、公用事业、道路通行、修路）使用他人土地的权利。英/美式："easement"；大陆法系："servitude"。 | Right of use（过于宽泛）；Licence（可撤销，不同于 easement） |
| right of way | 允许穿越他人土地的地役权。 | Access right（不够精确）；Right of passage（较不标准） |
| right of light / right of view | 保护相邻土地采光或视野权利的地役权。 | — |
| covenant / restrictive covenant | 对土地使用施加的义务或限制，约束权利承继人。 | — |
| mortgage / mortgaged property | 为担保贷款而授予贷款人的财产担保权益。 | charge（不够精确）；lien（美式） |
| voluntary mortgage | 所有者自愿授予贷款人的抵押。 | — |
| judicial mortgage / charging order | 法院命令为担保判决债务而设立的抵押。 | court-ordered security（不够精确） |
| mortgage registration / registration of charge | 在土地登记处记录抵押以保护贷款人利益。 | — |
| conveyancing | 将财产所有权从卖方转移给买方的法律过程，包括查询、交换和交割 | Property transfer（不够精确） |

## 说明

- **Freehold 与 leasehold**：这些是英国概念。在美国，fee simple 所有权最常见，leasehold 罕见。在大陆法系国家，对等物是完全所有权，替代方案为 usufruct 和 superficies。始终指明司法辖区。

- **所有权与所有权契据**：所有权证明因司法辖区而异。有些使用托伦斯（Torrens）制度（澳大利亚、美国部分地区），有些使用契据登记（美国县），还有些使用土地登记制度（英国、欧盟）。始终指明所有权的证明方式。

- **Earnest money 与 penalty deposit**：许多大陆法系司法辖区区分两种缔约前定金：（1）确认性定金，既作为承诺又作为买方违约时的预定损害赔偿；（2）罚金/退出定金，允许任一方通过没收或返还定金退出。这些大陆法系概念没有精确的普通法对应物。使用英语描述；子词典提供源语言映射。

- **Conveyancing**：转移财产所有权的过程，涉及法律、财务和行政步骤。"conveyancer" 或 "solicitor" 在英国实务中处理此事；角色因司法辖区而异。

- **Completion 与 closing**：英国使用 "completion"；美国和其他司法辖区使用 "closing"。两者都指交换款项和契据的最后步骤。

- **Exchange of contracts**：英国概念，买方和卖方交换已签署合同，在最终交割前形成有约束力协议。在美国或大陆法系司法辖区不标准。

- **Restrictive covenants**：英国概念，限制土地使用（如"此土地上不得商业使用"）。这些随土地转移并约束承继人。在美国不是标准术语（限制很常见）；许多大陆法系制度中不存在。

- **Usufruct 和 superficies**：大陆法系概念。Usufruct 是使用和收益财产的权利；虚有权人保留所有权。Superficies 是在他人土地上建造的权利。首次提及解释。

- **Easements 和 servitudes**："easement" 用于普通法；"servitude" 用于大陆法系。两者都指使用他人土地的权利（通行、公用事业、停车、采光）。默认英语术语使用 "easement"；子词典提供源语言映射。

- **Zoning 和土地使用**：分区法律规范允许用途和密度。许多源语言对土地分区（监管分类）和租赁场所的合同允许用途使用单一术语；语境对区分至关重要。

- **地籍引用**：财产通过土地登记或地籍记录识别，因司法辖区而异。数字标识符（地块、地段、子单元编号）在翻译中应原样保留；提供英语标签但保留原始引用编号。

- **租金指数化**：许多司法辖区使用国家消费者价格指数每年调整租金。翻译时，保留国家指数缩写并在首次使用时解释（如英国 "CPI"，其他司法辖区国家统计机构指数）。子词典提供源语言映射。

- **能源绩效证书**：欧盟强制要求的建筑能效认证。术语各异：EPC（欧洲）、EPB（比利时）、DPE（法国）、APE（意大利）。标准英语术语使用 "energy performance certificate (EPC)"。
