# 知识产权、技术与信息技术术语词典

知识产权与信息技术协议的标准英文术语。第一部分涵盖专利、商标、版权、外观设计、商业秘密、许可和技术转让。第二部分涵盖软件许可、SaaS、云服务、数据处理、开发协议及相关 IT 文书。

---

## 第一部分——知识产权与技术

## 核心知识产权术语

| 规范英文术语 | 用法 / 含义 | 避免使用 |
|---|---|---|
| intellectual property (IP) | 涵盖所有知识产权权利的总称 | 仅指财产权；工业产权（范围较窄） |
| intellectual property right (IPR) | 单项知识产权权利（专利、商标、版权） | 仅指工业产权 |
| patent | 对发明授予的权利；20 年后到期 | 专利申请（使用单独术语） |
| patent application | 授权前的待审申请；启动申请程序 | 已提交专利（含义模糊） |
| granted patent | 已获批准且有效的专利 | 已颁发专利（不够正式） |
| patent holder / patentee | 拥有专利的个人或实体 | 专利所有人（不够精确） |
| claim (patent) | 专利说明书中的单项权项主张 | 权项语言 |
| patent specification | 向专利局提交的完整技术文件 | 专利文件（过于笼统） |
| priority | 主张在先申请更早申请日的权利 | 申请优先 |
| priority date | 最早申请的日期（优先权主张的基础） | 首次申请日（可能产生歧义） |
| filing date | 专利申请提交至专利局的日期 | 提交日 |
| patent term | 专利保护期限（通常自申请日起 20 年） | 专利期限；专利寿命 |
| European patent | 欧洲专利局（EPO）授予的专利；覆盖多个地区 | 欧盟专利（不精确） |
| Unitary Patent | 覆盖所有参与欧盟成员国、具有集中保护的单一专利 | 统一欧洲专利 |
| supplementary protection certificate (SPC) | 药品/农化产品的专利期限延长 | 补充保护证书 |
| invention | 可获得专利的技术创造；专利权的客体 | 发现（技术性区分） |
| patentable invention | 满足新颖性、创造性步骤和工业适用性的发明 | 可获专利的客体 |
| novelty | 第一项要求：发明在全球范围内无在先公开 | 新颖度（不够技术化） |
| inventive step | 第二项要求：对本领域技术人员而言非显而易见 | 创造性；非显而易见性 |
| industrial applicability | 第三项要求：能够进行工业应用 | 实用性（美国术语）；有用性 |
| prior art | 先于发明存在的现有知识/出版物；在新颖性检索中审查 | 现有技术水平；申请前已知技术 |
| freedom to operate (FTO) | 使用技术而不侵犯第三方专利的权利 | FTO 审查；FTO 分析 |
| FTO analysis | 识别侵权风险的全面专利布局研究 | 审查检索；布局检索 |
| prior art search | 识别与发明类似的现有专利/出版物的检索 | 专利检索；现有技术检索 |
| patent family | 覆盖同一发明在各司法管辖区的专利组 | 专利组合（范围更广） |
| infringement | 未经授权制造、使用或销售专利发明 | 违反；专利违反 |
| infringement action | 针对被指控侵权人的法律诉讼 | 侵权诉讼 |
| patent invalidity | 认定专利不符合法定要求 | 专利撤销；专利注销 |
| patent revocation | 司法或行政程序取消专利权 | 专利无效（类似） |
| compulsory license | 政府未经专利权人同意授予的许可（紧急情况等） | 强制许可（另一说法） |

## 商标术语

| 规范英文术语 | 用法 / 含义 | 避免使用 |
|---|---|---|
| trademark (US default) / trade mark (UK) | 用于区分商品/服务的标志；"trademark"（一词）为美国标准拼写；"trade mark"（两词）为英国/EUIPO 标准拼写；在本技能美国默认设置下默认使用美国拼写，使用英国变体时用英国拼写 | 标记（过于笼统） |
| registered trade mark | 在商标局正式注册的商标 | 已注册标记 |
| unregistered trade mark | 无注册的普通法保护；英国称为 "passing off"（假冒） | 未注册商标；商业外观（美国） |
| EU trade mark (EUTM) | 通过 EUIPO 覆盖所有欧盟成员国的单一注册 | 欧洲商标（不够精确） |
| international trade mark | 在多个国家注册的商标；通常通过 WIPO 马德里体系 | 多地区商标 |
| trade mark application | 向商标局提交的注册申请 | 标记申请 |
| registration | 审查后商标权的正式授予 | 商标注册（范围更广） |
| renewal | 维持权利的定期重新注册（通常每 10 年） | 重新注册；维护 |
| Nice classes | 商标商品/服务的国际分类体系（45 个类别） | 分类类别 |
| goods and services | 商标注册所保护的商品与服务类别 | 产品与服务 |
| word mark | 仅由文字/文本构成、无图形设计的商标 | 文字商标；文本商标 |
| figurative mark / device mark | 文字和/或视觉设计元素结合的商标 | 设计商标；标识 |
| three-dimensional mark / shape mark | 保护独特产品形状或包装的商标 | 3D 商标；形状商标 |
| domain name | 互联网地址（如 www.example.com）；与商标不同但通常协调管理 | 网站名称 |
| business sign / trade name | 企业经营的名称；保护程度低于商标 | 商号 |
| company name | 法律实体的注册名称；与商标保护不同 | 商业称谓 |
| designation of origin | 证明商品产自特定地区的认证（如香槟） | 地理标志（范围更广） |
| geographical indication (GI) | 表明商品/服务产自具有声誉的特定地点的标志 | 原产地标志 |
| genericization / loss of distinctiveness | 商标成为商品类别的通用名称时发生。美国拼写：genericization；英国拼写：genericisation | 商标淡化（美国术语） |
| likelihood of confusion | 标准测试：普通消费者是否会混淆两个商标 | 混淆性近似；混淆测试 |
| opposition | 在授权前阻止或挑战商标注册的程序 | 异议程序 |
| revocation (for non-use) | 因连续 5 年以上未使用而撤销商标权 | 因不使用而注销 |
| passing off | 英国普通法侵权：使用造成消费者混淆的商标/装潢 | 盗用（美国对应概念） |
| trade dress | 受类似商标保护的产品/包装独特视觉外观；注意 "trade dress" 主要是美国概念——英国对应概念是通过假冒（passing off）保护的未注册商标 | 商业外观（作为英国术语——应使用 passing off / get-up） |

## 版权术语

| 规范英文术语 | 用法 / 含义 | 避免使用 |
|---|---|---|
| copyright | 控制创作作品复制、发行、改编的权利 | 作者权（大陆法系术语） |
| copyright work / work of authorship | 固定在媒介中的原创创作表达（文学、音乐、艺术等） | 受版权保护的作品（并非所有作品都受保护） |
| original work | 体现独立创作并达到最低创作门槛的作品 | 新颖作品（不同概念） |
| author | 版权作品的创作者；版权的第一所有人（雇佣作品除外） | 创作者（不够技术化） |
| moral rights | 保护完整性、署名、隐私、名誉的非经济权利 | 精神权利（法文术语） |
| economic rights / exploitation rights | 控制复制、发行、改编、传播的权利 | 财产权利（大陆法系） |
| reproduction right | 以任何媒介制作作品副本的权利 | 复制权（不精确） |
| distribution right | 控制实物副本首次销售/发行的权利 | 销售权；出租权 |
| right of communication to the public | 广播或按需提供（互联网、流媒体）的权利 | 公开表演权（范围较窄） |
| adaptation right | 修改、翻译或创作衍生版本的权利 | 修改权；翻译权 |
| derivative work | 基于或改编自现有作品的作品；需经原作品许可 | 改编（不够精确） |
| collective work | 由多位作者的贡献整合为单一作品 | 汇编（结构不同） |
| joint work | 由两位或以上作者创作、贡献不可分割的作品 | 合著作品 |
| assignment of rights | 版权所有权从作者转移给另一方 | 版权转让；让与 |
| license to use | 允许使用作品而不转移所有权的许可 | 许可（缩写形式） |
| exclusive license | 授予单一被许可人排除所有其他人（包括许可人）的权利 | 独家许可（可能保留许可人权利） |
| non-exclusive license | 多个被许可人可同时获得相同权利 | 标准许可；开放许可（不精确） |
| fair remuneration | 对作者使用作品的公平补偿（法定概念） | 公平赔偿 |
| public domain | 不再受保护的作品（版权已到期、不符合条件、自愿放弃） | 公共获取（与公有领域不同） |

## 许可与技术转让

| 规范英文术语 | 用法 / 含义 | 避免使用 |
|---|---|---|
| license agreement (US default) / licence agreement (UK) | 授予知识产权（专利、商标、版权、专有技术）使用许可的合同；在本技能美国默认设置下默认使用美国拼写，使用英国变体时用英国拼写 | 许可合同（不精确）；知识产权授权协议 |
| patent license (US default) / patent licence (UK) | 允许使用专利技术的特定许可 | — |
| trademark license (US default) / trade mark licence (UK) | 允许使用注册商标的许可；许可人保留所有权 | 标记许可 |
| cross-license / cross-licensing | 双方之间相互交换许可（技术领域常见） | 相互许可 |
| sublicense (US default) / sub-licence (UK) | 被许可人授予第三方的许可（除非获准，否则需许可人许可） | 次级许可 |
| royalty | 被许可人就使用知识产权向许可人支付的定期款项 | 持续许可费（特定类型）；费用 |
| lump-sum royalty | 一次性固定许可付款（相对于销售额百分比） | 一次性费用；固定费用 |
| running royalty | 按许可期内销售额/收入百分比计算的许可费 | 百分比许可费 |
| minimum guarantee | 无论实际销售额如何都应付的最低年许可费 | 保证最低额；下限 |
| know-how | 保密的技术信息、技能、经验；未获专利 | 商业秘密（范围较窄） |
| trade secret | 具有商业价值的保密商业/技术信息；可包含专有技术 | 保密专有技术 |
| technology transfer | 当事方之间技术知识、专利或专有技术的传递 | 技术许可（范围较窄） |
| R&D agreement | 规范联合研发合作的合同 | 研究协议 |
| ownership of results | 研发协议项下产生作品的知识产权分配 | 改进成果所有权；知识产权分配 |
| background IP | 合同/合作开始前已有的知识产权；在附表中列明 | 先前知识产权；既有知识产权 |
| foreground IP | 合同/合作期间产生的知识产权；所有权通常予以分配 | 项目知识产权；开发知识产权 |
| sideground IP | 被许可人使用许可人背景知识产权但在不同领域产生的知识产权 | 衍生知识产权；周边知识产权 |
| improvement | 对现有许可技术的增强或修改 | 改进知识产权；升级版本 |
| right of first offer | 被许可人必须先向许可人提供新改进，然后才能独立商业化 | ROFO |
| right of first refusal | 许可人/被许可人有权在第三方之前获得改进的许可 | ROFR |
| field-of-use restriction | 许可限于特定行业或应用（如"仅限制药用途"） | 领域限制；有限领域许可 |
| open source license | 允许自由使用、修改和分发软件的许可；区分宽松型（MIT、Apache、BSD）与著佐权型（GPL、AGPL、LGPL） | 自由软件许可（不同运动）；免费软件（不同概念） |
| copyleft | 要求衍生作品以相同许可条款分发的开源许可（如 GPL）；对专有软件是关键的合规风险 | 病毒式许可（非正式）；限制性开源 |
| source code escrow | 源代码交由保管代理人保管，在触发事件（如许可人资不抵债、重大违约）发生时向被许可人释放的安排 | 代码托管；软件托管（不够精确） |
| change of control | 参见 finance-banking.md 中的规范定义。知识产权许可情境：许可协议可约定控制权变更时的终止权或同意权。 | — |
| articles of association (UK) / by-laws (US) | 参见 corporate-ma-jv.md 中的规范定义。知识产权情境：当章程规范知识产权所有权政策或知识产权交易的董事会批准门槛时可能相关。 | — |

## 外观设计与商业秘密术语

| 规范英文术语 | 用法 / 含义 | 避免使用 |
|---|---|---|
| design | 工业产品的装饰性外观；在欧盟可作为"注册外观设计"注册 | 美学设计；外观设计权 |
| registered design | 在知识产权局正式注册的外观设计；提供排他权 | 外观设计专利（美国）；保护性设计 |
| Community design | 通过 EUIPO 在欧盟制度下注册的外观设计（注意：英国脱欧后术语可能变化） | 欧盟外观设计 |
| utility model | 功能创新的知识产权保护形式（期限短于专利）；部分欧盟/亚洲司法管辖区可用，但英国和美国不可用 | 小专利 |
| confidential information | 标记为保密并按秘密处理的商业/技术信息 | 专有信息（范围更广） |
| trade secret | 因未披露而提供竞争优势的保密信息；英国法定依据是实施欧盟第 2016/943 号指令的《2018 年商业秘密（执法等）条例》 | 工业秘密（旧式大陆法系直译）；保密数据（不精确） |
| protective measures | 维持保密性的物理、技术、组织措施 | 安全措施；保护程序 |
| non-disclosure agreement (NDA) | 对保密信息接收方施加保密义务的合同；首次全称使用后可将 "NDA" 作为定义术语使用 | 保密协议（同义词，但在交易实践中较少使用）；保密合同 |
| confidentiality obligation | 不披露或不滥用以保密信息义务的合同义务 | 不使用义务；保密义务 |

## 注释

- **"Intellectual property"（知识产权）范围**：涵盖专利、商标、版权、外观设计、商业秘密及其他知识产权权利。许多大陆法系司法管辖区历史上将工业产权（专利、商标、外观设计）与作者权（版权）分开，但英文对所有类型使用单一总括术语 "intellectual property"。

- **"Trade mark"（英国）与 "trademark"（美国）**：美式英语使用 "trademark"（一词）；英式英语（及 EUIPO）使用 "trade mark"（两词）。默认以美国拼写为主，并注明英国替代拼写。

- **"Licence"（英国名词）与 "license"（美国名词/动词）**：美国：名词和动词均为 "license"（本技能的默认）；英国："licence"（名词）和 "license"（动词）。默认使用美国 "license"。

- **"FRAND" 条款**：公平、合理且非歧视——标准必要专利（SEP）的标准许可义务，以防止专利劫持。

- **"SEP"（标准必要专利）**：实施技术标准（如电信、汽车）所必需的专利；须承担 FRAND 许可义务。

- **"Freedom to operate"（FTO，自由实施）**：使用技术而不侵犯第三方知识产权的许可状态；需要进行覆盖相关专利布局的 FTO 分析。

- **"Prior art search"（现有技术检索）**：识别先于发明的专利和出版物的全面检索；对新颖性评估和可专利性认定至关重要。

- **"Patent family"（专利族）**：跨司法管辖区保护同一发明的相关专利组（如美国专利 + 欧洲专利 + 日本专利）；作为单一知识产权资产管理。

- **"Trade dress"（商业外观）**：产品或包装的独特视觉外观（形状、颜色、设计），受类似商标的保护；不同于外观设计注册；该概念主要用于美国法律；英国对应概念可指普通法"假冒"下的"未注册商标"。

- **"Passing off"（假冒，英国）**：英国（及部分其他司法管辖区）的普通法侵权，通过阻止第三方使用造成消费者欺骗的混淆性近似商标来保护未注册商标/装潢；美国对应概念为 "misappropriation"（盗用）或 "false passing off"（虚假假冒）。

- **大写规范**：在法律起草中，"License"、"Patent"、"Trade Mark"、"Licensor"、"Licensee" 等定义术语应在整个协议中一致使用大写。

- **缩写**：首次使用时展开全称：EPO（European Patent Office，欧洲专利局）、EUIPO（European Union Intellectual Property Office，欧盟知识产权局）、WIPO（World Intellectual Property Organization，世界知识产权组织）。

## 第二部分——IT、软件与 SaaS

## 核心 IT/SaaS 术语

| 规范英文术语 | 用法 / 含义 | 避免使用 |
|---|---|---|
| software license agreement (US default) / software licence agreement (UK) | 授予软件使用权的合同；在本技能美国默认设置下默认使用美国拼写，使用英国变体时用英国拼写 | 软件使用协议 |
| end-user license agreement (EULA) | 面向软件最终用户的标准化许可协议；通常为点击式（click-through） | EUA（仅缩写）；许可协议（过于宽泛） |

## 注释

- **"Licence"（英国名词）与 "license"（美国名词/动词）**：美国：名词和动词均为 "license"（本技能的默认）；英国："licence"（名词）和 "license"（动词）。法律术语词典中默认使用美国 "license"。

- **"EULA"（最终用户许可协议）**：面向最终用户的标准软件许可合同；通常以点击式协议呈现。区别于开发/企业协议。

- **"Acceptable Use Policy"（AUP，可接受使用政策）**：定义允许和禁止的用途；通常包括对反向工程、竞争性使用、非法活动的限制。

- **"Service credit" 与 "liquidated damages"**：SaaS 协议通常对服务故障使用"服务抵扣"（发票抵扣）；传统 IT 外包使用"约定损害赔偿"（违约的合同损害赔偿）。二者不可互换。

- **"Service level agreement"（SLA，服务级别协议）结构**：应定义指标（正常运行时间百分比）、计量期间、故障服务抵扣以及除外情形（计划维护、不可抗力、客户行为）。

- **"Staging environment"（暂存环境）**：亦称"测试环境""预生产环境""开发环境"；用于生产部署前的测试。与生产环境不同。

- **"Data migration"（数据迁移）**：通常在合同开始（接入）和结束（迁出）时需要；协议应明确迁移期间的格式、时间表和安全性。

- **"Data portability"（数据可携权）**：与 GDPR 要求相关；客户应能在合理时间内以机器可读格式提取数据。

- **"Backup and recovery"（备份与恢复）与 "disaster recovery"（灾难恢复）与 "business continuity"（业务连续性）**：备份 = 数据副本；灾难恢复 = 重大故障后的恢复能力；业务连续性 = 更广泛的运营韧性。

- **"Indemnity"（赔偿，知识产权侵权）**：开发方就第三方关于开发软件侵犯知识产权的索赔对客户进行赔偿；开发协议中的标准条款。

- **"Force majeure"（不可抗力）**：对超出当事方控制的不可预见事件（战争、自然灾害、疫情）的合同救济；通常排除经济困难。

- **"Change of control"（控制权变更）**：合并、收购或所有权变更；因保密/安全考虑通常触发重新谈判权或终止权。

- **"Right to audit"（审计权）**：客户检查服务提供商运营以核实 SLA 合规、安全标准、数据处理等的权利；通常受通知和保密要求约束。

- **"Work made for hire"（雇佣作品）**：受委托创作人的作品所有权归属雇主（而非创作者）的法律概念；因司法管辖区而异；应在开发协议中明确约定。

- **大写规范**：在法律起草中，"Services"、"Software"、"Customer Data"、"Confidential Information"、"SLA"、"Deliverables" 等定义术语应在整个协议中一致使用大写。

- **翻译中服务抵扣与约定损害赔偿的区分**：部分源语言用单一术语涵盖两个概念。在英文中，"service credits"（SaaS/云标准）和 "liquidated damages"（传统外包）是不同的；务必根据情境识别适用哪一个。
