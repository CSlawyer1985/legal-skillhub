# 金融/银行业术语词典

金融和银行文件的英语术语：项目融资担保包（security packages）、授信协议（facility agreements）、质押（pledges）、抵押（mortgages）、债券（bonds）、贷款协议（loan agreements）、债权人间协议（intercreditor agreements）、银团授信（syndicated facilities）、巴塞尔协议 III/CRR、反洗钱/客户尽职调查（AML/KYC）、制裁合规、银行牌照及相关文书。统一词典涵盖项目融资/担保（原 `finance.md`）和一般银行业/监管（原 `banking-regulatory.md`）两部分。

> **各语言子词典说明。** 本英语参考文件仅涵盖金融与银行业；交易与资本市场术语见 `references/trading-capital-markets.md`。在各语言子词典中，两个领域合并处理：`sub-lexicons/<language>-finance-banking.md` 涵盖两者。处理资本市场文件时，阅读两份英语参考文件，但只需阅读单一的各语言子词典。

## 核心金融术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| facility agreement | 规范贷款/信贷授信（credit facility）的协议（LMA 标准） | "financing agreement"、"loan contract" |
| loan agreement | 针对直接（通常为双边）贷款的特定协议 | "loan facility"（如是框架协议）；"credit contract"（非正式） |
| facility | 授信额度本身（定期授信 Term Facility、增值税授信 VAT Facility、偿债储备授信 DSR Facility） | "financing"、"loan"（项目融资语境下） |
| lender | 提供授信的银行或机构 | "financing bank" |
| borrower | 接受授信的一方 | — |
| secured party / secured parties | 从担保中获益的一方/多方 | "secured creditor"（可接受，但在 LMA 中较不标准） |
| security interest | 为担保债务而就资产授予的任何权利——涵盖质押、抵押、charge、留置（lien）等的统称 | — |
| security package | 交易中全部担保文件和担保权益的完整组合 | — |
| enforcement event | 触发担保执行权利的事件 | "cause of enforcement" |
| event of default | 引发加速到期/终止权利的违约或事件 | "relevant event" |
| potential event of default | 经通知或时间流逝后将成为违约事件的事件 | "potential relevant event" |
| security period | 担保持续有效的期间 | "guarantee period" |
| maximum secured amount | 被担保金额的上限 | "maximum guaranteed amount" |
| subject matter of the security | 被担保的资产或权利 | "subject matter of guarantee" |
| perfection | 使担保权益可对抗第三方的程序，通常通过登记或备案完成 | — |
| mortgage loan | 以不动产 charge/信托契据担保的贷款 | "home loan"（过于非正式）；"real estate loan"（不够具体） |
| unsecured loan | 无抵押物担保的贷款 | "clean loan"；"signature loan"（非正式） |
| credit facility / overdraft facility | 预先批准的可用借款金额（通常为短期） | "overdraft account"；"credit line"（可接受，但 "facility" 为标准用法） |
| overdraft | 账户余额的临时赤字（可能未经授权） | "overdraw"（动词形式） |
| letter of credit (L/C) | 凭提交装运单据保证付款的单证文书 | "credit letter"（不精确） |
| documentary credit | 以所有权单据（提单等）担保的信用证 | "trade credit"（过于宽泛）；"commercial credit"（不精确） |
| bank guarantee | 银行在受益人索赔时见索即付的承诺 | "bank's guarantee"（语法上可接受） |
| comfort letter / letter of awareness | 母公司就子公司履约情况作出的非正式陈述 | "letter of comfort"（可接受）；"parent company letter"（较不正式） |

## 授信类型、提款与金融工具

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| term facility | 一次性提取并随时间偿还的不可循环授信 | "cash facility" |
| revolving facility | 可提取、偿还、再提取的信贷授信 | — |
| credit facility | 贷款安排的通用术语 | "credit line"（非正式场合可接受） |
| syndicated facility | 多个贷款人参与的授信，通常由安排行/代理行组织 | "syndication"（是过程，不是产品） |
| club deal | 为多个贷款人安排但无正式银团结构的授信 | "syndicated deal"（不够精确） |
| commitment | 贷款人已同意提供的最高金额（LMA 定义术语） | 不要与口语含义混淆 |
| drawdown / utilization | 在授信项下借入资金的行为 | "take-down"（较不正式） |
| utilisation request (英) / utilization request (美) | 请求提款的正式通知 | — |
| interest rate | 授信项下应付的利率 | — |
| margin | 在基准/参考利率之上加收的点差 | — |
| default interest | 违约后适用的提高利率 | — |
| principal amount | 贷款本金面值，不含利息 | — |
| repayment schedule | 偿还本金的时刻表 | "repayment plan" |
| amortisation (英) / amortization (美) | 本金的按期偿还 | — |
| prepayment | 提前自愿偿还（可能产生罚金） | "early repayment"（可接受）；"redemption"（法律含义不同） |
| refinancing | 以新授信替换旧授信（通常有新的贷款人） | "refi"（非正式） |
| financial covenants | 借款人必须维持的财务比率/阈值 | — |
| material adverse change (MAC) / material adverse effect (MAE) | 对借款人履行义务能力产生重大不利影响的事件或情况 | "Adverse change"（过于模糊） |
| intercreditor agreement | 债权人之间规范其相对权利的协议 | "creditor agreement" |
| subordination | 某一债权人的债权受偿顺位居于另一债权人之后 | "subordinated position" |
| pari passu ranking | 债权之间的平等受偿顺位 | "pro-rata" |
| senior debt | 优先于次级债务受偿的债务 | "senior tranche"（如分层时） |
| subordinated debt / mezzanine debt | 顺位居于高级债务之后但可能优先于股权的债务 | "junior debt"；"sub-debt"（非正式） |
| tranche | 授信中条款不同的独立部分（如 A 期、B 期） | "slice"（非正式） |
| negative pledge | 不为了第三方利益就资产设立担保的承诺 | — |
| mandatory prepayment | 由特定事件触发的强制提前偿还 | — |
| voluntary prepayment | 借款人自行选择的任意提前偿还 | — |
| clean-down period | 要求循环授信在指定期间内全部偿还的期间 | — |
| change of control | **权威定义**——合同一方所有权或实际控制权的变更。按语境的典型触发情形：违约事件/强制提前还款（本文件）；终止/同意权（ip-it-technology、ndas-service-agreements、consumer-retail）；主管机关同意（public-procurement、energy-infrastructure）；转让限制（real-estate）；承保连续性事项（transport-and-insurance）；加速归属（employment）；看跌期权交叉参见 corporate-ma-jv。 | "change control"（指范围/变更管理）；ownership change（过于模糊）；acquisition（范围更窄——控制权变更也可能因内部重组发生） |
| conditions precedent | 首次提款前必须满足的条件 | "suspensive conditions" |
| representations and warranties | 借款人的事实陈述和承诺 | "declarations and warranties" |
| recitals | 协议的引言部分 | "preambles"、"premises" |
| schedules | 协议的附件 | "annexes"（欧盟/国际文件中可接受） |
| waiver | 债权人同意忽略违约行为（通常单独书面记录） | "forbearance"（技术性较低） |
| amendment and restatement | 以修订形式全面替换授信协议 | "modification"（较不正式） |
| commitment fee | 对授信未提取部分支付的费用 | "standby fee"（较不标准） |
| arrangement fee | 为安排行构建和安排授信支付的前期费用 | "front-end fee"（非正式） |
| information undertaking | 借款人提供定期财务信息的义务 | "Reporting obligation"（LMA 语境中不够精确） |
| majority lenders | 控制批准修订/豁免所需比例表决权的贷款人 | "lenders in majority" |

|---|---|---|
| pledge | 就动产或权利设立的担保权益（大陆法系概念，各法域具有广泛对应性） | — |
| mortgage | 就不动产（房地产）设立的担保权益 | — |
| special lien | 对特定资产的法定优先权 | "special privilege" |
| deed of special lien | 设立特殊留置权的文件 | "deed of establishment of privilege" |
| assignment of receivables | 为担保目的转让收取付款的权利 | — |

| guarantee | 从属性义务——保证人的责任以主债务人违约为前提。具有附随性：其随主债务而存在。 | 与 "on-demand guarantee"（见下）混淆 |
| on-demand guarantee / demand guarantee | 独立的、主债务性质的义务——见索即付，无需证明主债务人违约。不具有附随性。 | "autonomous guarantee at first demand"（仿译） |
| surety / suretyship | 同等范围的义务——保证人与主债务人承担连带责任。比 guarantee 更严格。 | 将 "surety" 与 "guarantee" 视为同义词 |
| enforcement of the security | 变现担保权益的过程 | — |
| lien / charge | 为担保债务而就资产设立的权利 | — |
| encumbrance | 负担于资产之上的任何第三方权利 | — |
| pledge of quotas | 就有限责任类实体中的所有权权益设立的质押 | — |
| share pledge | 就公司股份设立的质押 | — |
| account pledge | 就银行账户及其余额设立的质押 | — |
| charged account / pledged account / blocked account | 受担保权益约束的银行账户 | — |
| voting rights | 附属于被质押股份/份额的表决权 | — |
| lien assets | 受留置权约束的特定资产 | "privilege subject matter" |
| release of the lien | 留置权的解除/注销 | "cancellation of privilege" |
| registration and publicity | 在公共登记簿中登记担保权益的程序 | "transcription and publication" |

## 英国法担保概念

这些术语特定于英国法金融文件。仅当源文件的担保结构确实映射到英国法概念时使用。大陆法系担保概念往往不能整齐地映射到普通法类别。

| 正确英语术语 | 用法/含义 | 说明 |
|---|---|---|
| debenture | 就公司全部或实质性全部资产设立固定和浮动 charge 的文件 | LMA 交易中的标准英国法担保文书 |
| fixed charge | 附着于特定、已识别资产的 charge（设保人不得自由处置该资产） | 可很好地映射大陆法系针对特定资产的质押 |
| floating charge | 悬浮于某类变动资产（如存货、应收账款）之上直至固化的 charge | 无直接的大陆法系对应物——仅当源概念涉及对波动性资产池的担保时使用 |
| crystallization | 浮动 charge 转化为针对特定资产的固定 charge 的时刻 | — |
| security trustee | 为所有贷款人的利益以信托方式持有担保的实体（英国法项目融资结构） | 与 "security agent"（以代理人而非受托人身份行事）相区别 |

## 银团、转让与让与

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| syndication agreement | 安排行与贷款人之间规范授信参与的协议 | "master syndication agreement" |
| transfer of participation | 贷款人向另一贷款人出售或转让其参与份额 | "lender exit"（非正式） |
| assignment of claim / debt assignment | 贷款权利义务向受让人的法律转让 | "novation"（法律效力不同——更换债权人） |
| sub-participation | 贷款人在另一贷款人头寸中的参与，无需借款人同意/知情 | "participation sharing" |
| consent | 贷款人/代理行对特定行动的批准 | "approval"（可接受） |

## 监管与审慎术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| banking supervision | 监管机构对银行机构的监督 | "prudential supervision" |
| supervisory authority | 监督银行/金融机构的监管机构 | "regulator"（较不正式） |
| national central bank / national banking regulator | 各国货币当局和/或银行业监管者 | "central bank"（未指明国家则过于笼统） |
| European Central Bank (ECB) | 欧元区货币当局（亦通过单一监管机制 SSM 担任银行业监管者） | "central bank"（过于笼统） |
| Single Supervisory Mechanism (SSM) | 由欧洲央行主导的监督欧元区重要银行的安排 | "unified supervision"（不够精确） |
| Single Resolution Mechanism (SRM) | 针对参与国问题银行的欧盟层面处置机构 | "resolution authority"（不够精确） |
| banking license | 从事银行业务的监管授权 | "bank charter"（美国特有） |
| capital requirements | 监管规定的最低资本水平 | "capital adequacy requirements"（巴塞尔协议 III 用语） |
| own funds | 监管认可的自有资金（一级资本与二级资本之和） | "equity"（会计术语） |
| Common Equity Tier 1 (CET1) | 最高质量的资本 | "core capital"（非正式） |
| Additional Tier 1 (AT1) | 次级资本（应急可转换债、混合债务） | "Tier 1 hybrid"（非正式） |
| Tier 2 (T2) | 期限更长/顺位次于 AT1 的次级资本 | — |
| solvency ratio | 自有资金与风险加权资产的比率 | "capital ratio"（可接受） |
| leverage ratio | 一级资本与总资产（非风险加权）的比率 | "simple leverage ratio"（非正式） |
| capital conservation buffer | 银行必须在最低要求之上保持的资本 | "buffer capital" |
| countercyclical buffer | 信贷繁荣期适用的额外缓冲 | "CCB"（缩写可接受） |
| systemic risk buffer | 针对系统重要性机构的额外资本 | "SRB" |
| minimum requirement for own funds and eligible liabilities (MREL) | 要求银行保持自有资金 + 可进行内部纾困（bail-in）的合格负债以备处置 | "bail-in capacity"（相关但不等同） |
| total loss-absorbing capacity (TLAC) | 针对全球系统重要性银行（G-SIB）的国际标准 | "loss-absorbing capacity" |
| stress test | 监管机构对银行在不利情景下偿付能力的评估 | — |
| supervisory review and evaluation process (SREP) | 欧洲央行/SSM 对单个银行资本充足率的评估 | "supervisory review"（较不正式） |
| Capital Requirements Regulation (CRR) | 欧盟条例 (EU) No. 575/2013 | "capital regulation"（模糊） |
| Capital Requirements Directive (CRD) | 欧盟指令 2013/36/EU（治理、薪酬、制裁） | "capital directive"（模糊） |
| Basel III | 国际审慎监管框架 | "Basel 3"（非标准） |
| bail-in | 将银行负债转换为股权或予以注销的监管权力 | "depositor haircut"（不精确） |
| resolution plan / living will | 银行快速有序处置的书面计划 | "resolution strategy" |
| passporting | 欧盟银行牌照在其他欧盟成员国经营的通行权 | "EU passport right" |
| ring-fencing | 零售/支付银行业务与交易/投资银行业务的结构性分离 | "banking separation"（技术性较低） |

## 说明

- **"Beneficiary" 在担保语境中有歧义**："授信受益人"是借款人（收款方），但"担保受益人"是担保权人（持有担保权益的一方）。务必根据语境消除歧义。绝不可两者都译为 "borrower"。

- **LMA 标准**：英语金融文件一般遵循贷款市场协会（LMA）惯例。术语尽可能与 LMA 标准保持一致。

- **贷款协议与授信协议**：许多源语言区分特定贷款合同（双边、本金金额）与更宽泛的信贷授信。英语中，银团/结构化贷款使用 "facility agreement"（LMA 标准），简单双边贷款使用 "loan agreement"。不要将源语言的区别强加于英语；根据文件结构和经济实质翻译。

- **项目融资特定事项**：在项目融资文件中，"Facility" 始终指特定授信额度（定期授信、增值税授信、偿债储备授信）。绝不使用 "Loan"——"Facility" 是市场标准。

- **"Article"、"Clause" 与 "Section"**：文档内部交叉引用使用 "Section"（美式默认）或 "Clause"（英式/LMA 传统）。"Article" 仅在指称立法时使用。

- **大陆法系与普通法担保**：许多大陆法系担保概念（如意大利 "privilegio speciale"、法国 "nantissement"、德国 "Sicherungsübereignung"）不能整齐映射到英国法类别。翻译时，仅在概念真正对等的情况下使用最接近的英国法术语。否则，使用描述性英语翻译，并考虑加译者注。绝不可将普通法术语强行套用于根本不同的大陆法系概念。

- **国家银行业立法**：翻译对国家银行法典或综合法规的引用时，首次提及提供官方英语译文，后附原文引注。子词典提供源语言映射。

- **资本要求术语**：使用精确的巴塞尔协议 III/CRR 术语（CET1、AT1、T2、MREL、TLAC、SREP）。这些是国际标准化的。不要改写或翻译缩写——它们在所有司法辖区都同样使用。

- **欧盟监管框架**：欧盟指令/条例（CRR、CRD、AMLD、PSD2）是多国标准，保留在主英语词典（而非子词典）中。国家特定主管机关和立法仅进入子词典。

- **反洗钱指令版本**：欧盟反洗钱框架正在演变。文件可能引用 AMLD4（2015）、AMLD5（2018）、AMLD6（2022）或即将出台的 AML 条例（AMLA）。务必确认适用哪个版本并在翻译中注明。

- **内部纾困（bail-in）与处置**："Bail-in" 是银行联盟框架（SRM/SSM）下欧盟特有的恢复/处置工具。不同于美国的破产/接管。"Resolution plan" / "living will" = 银行倒闭策略的必需书面文件。

- **通行权（passporting）与围栏隔离（ring-fencing）**："Passporting" = 欧盟银行牌照权利（脱欧后仅适用于欧盟内部，不适用于英国）。"Ring-fencing" = 英国维克斯报告（Vickers Report）建议（已在英国实施，不同于欧盟的结构性分离提案）。

- **美式与英式英语**：本词典默认使用美式惯例（如 "recognized"、"license"、"organization"、"utilization"）。实质性差异处注明英式替代（如美式 "authorization" 对英式 "authorisation"）。
