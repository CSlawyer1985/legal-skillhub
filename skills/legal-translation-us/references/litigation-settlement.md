# 诉讼与和解术语词典

争议性法律工作的标准英文术语：民事诉讼、行政诉讼、刑事诉讼，以及和解协议、责任免除、弃权、合意判决、争议解决条款、调解和仲裁。

本综合术语词典涵盖诉讼的完整生命周期（起诉 → 答辩状 → 庭审 → 判决 → 上诉 → 执行），以及用于在不进入终局判决的情况下解决争议的交易性文书（和解协议、责任免除契据、合意判决）。许多术语（judgment、costs、jurisdiction、enforcement）在两种语境中都会出现——应将其视为一个统一的术语体系。

## 核心和解术语

| 标准英文术语 | 用法/含义 | 避免 |
|---|---|---|
| settlement agreement | 当事人之间为解决争议而达成的具有约束力的协议 | accord、settlement contract |
| settlement record | 记录已达成的和解事项的文件（例如在调解中达成的） | conciliation record（范围更窄） |
| deed of settlement | 记录和解条款的正式签署契据 | settlement deed、settlement instrument |
| general release and settlement | 一次性消灭所有相关请求的综合性和解 | settlement only、release only |
| release and waiver | 相互免除请求并放弃进一步权利 | waiver and release（英国：优先用 release and waiver） |
| release / discharge | 对责任或义务的正式免除 | waiver（不同概念） |
| waiver of claims | 自愿放弃已知的请求 | release of all claims（范围更广） |
| mutual release | 双方/所有当事人相互免除 | single release、unilateral release |
| receipt and discharge | 确认付款并同时消灭义务 | receipt and release |
| full and final release | 完全免除，就同一标的物排除一切进一步请求 | final release、complete release |
| full and final settlement | 完整且有约束力的和解；不再可能提出进一步请求 | complete settlement、final settlement |
| nothing further to claim | 双方确认不再欠付任何款项 | nothing further owing、no further claims |
| mutual concessions | 当事人的相互妥协（大陆法系的要求） | concessions、mutual give-and-take |
| settlement amount | 和解协议约定的金钱数额 | settlement sum（未限定——可用但不够精确） |
| settlement consideration | 为换取和解而提供的对价（不限于金钱——可能包括非金钱承诺，如责任免除、保密、联合声明） | consideration（未限定——在合同成立意义上具有歧义） |
| settlement payment | 依据和解协议支付的款项 | settlement sum（仅指金额） |
| settlement installment | 依据和解协议分期支付的款项 | installment payment |
| satisfaction | 对请求/义务已获满足的正式确认 | satisfaction and release |
| full and final | 完整且终局的（描述和解的质量） | full、final |
| accord and satisfaction | 以提供新对价换取责任免除的和解 | accord、satisfaction |
| without prejudice | 以陈述不可作为证据采信为基础进行的法律和解商谈 | privileged discussion |
| without prejudice save as to costs | 和解商谈后仍可就费用问题提出主张（英国） | without prejudice only |
| Tomlin order | 争议条款予以保密的和解合意命令（英国程序） | consent order（泛指） |
| no admission of liability | 载明和解不构成对过错承认的和解条款 | settlement without admission、non-admission clause |
| entire agreement | 确认和解协议构成关于该事项全部协议的条款 | complete agreement、whole agreement |
| res judicata | 已经裁判的事项不得再行审理的法律原则 | judgment bar、final determination |
| Part 36 offer | 依据英国《民事诉讼规则》（CPR）第36部分作出的正式和解要约，若在庭审中未能超越该要约则产生自动的费用后果；英国特有的程序概念 | Without prejudice offer（不同的机制） |
| Calderbank offer | “保留费用抗辩的免诉权”和解要约（用于仲裁及不适用 Part 36 的法域） | Without prejudice offer（不够精确） |
| penalty clause | 约定对违约行为施加过高款项的条款（在普通法上，如非对损失的真实预先估算则不可执行）；大陆法系法域可能执行违约金条款 | Punitive clause（不够标准） |
| set-off | 一方以其对对方的应收款项抵销其应付对方款项、从而减少应付净额的权利；区别于 netting（金融市场） | Offset（不够正式）；Compensation（大陆法术语，在英文中有歧义） |
| compromise / compromise agreement | 通过相互妥协解决争议的协议；在英国劳动法领域，自2013年起已由“settlement agreement”取代 | Transaction（许多源语言的民法假朋友） |

## 争议解决术语

| 标准英文术语 | 用法/含义 | 避免 |
|---|---|---|
| dispute resolution | 一切解决争议方法的统称 | conflict resolution（可能仅指调解） |
| dispute | 当事人之间的分歧或争议 | conflict、disagreement（不够正式） |
| litigation | 法院诉讼程序；在法院进行的正式争议解决 | court proceedings、legal action |
| legal proceedings | 在法院启动的正式程序 | court action、legal action |
| action / claim | 向法院提起的法律请求 | suit（古旧）、cause of action |
| counterclaim | 被告在同一程序中向原告提起的请求 | cross-claim（程序变体） |
| third-party claim | 一方在既有程序中向第三人提起的请求 | third-party notice、interpleader |
| defense / objection | 否认责任或提出法律异议的应诉答辩 | answer（美国程序变体） |
| preliminary objection | 庭审前对管辖权、可受理性或程序瑕疵提出的异议 | jurisdictional objection |
| jurisdiction | 法院审理案件（实体与属人）的权力 | competence（大陆法术语） |
| competent court / forum | 对争议享有管辖权的法院 | proper forum、forum of competence |
| arbitration clause | 约定争议通过仲裁解决的合同条款 | submission to arbitration（不同概念） |
| submission to arbitration | 将争议提交仲裁的协议（可能在争议发生后达成） | arbitration agreement、compromis |
| arbitral award | 仲裁员或仲裁庭作出的裁决 | award、arbitral decision |
| arbitration | 由中立第三方进行的私人争议解决 | arbitral proceedings |
| sole arbitrator | 被指定解决争议的单一中立人士 | single arbitrator |
| arbitral tribunal | 仲裁员合议庭（通常为3人） | arbitration panel、tribunal |
| arbitration rules | 规范仲裁程序的程序规则（ICC、UNCITRAL 等） | rules of arbitration、arbitral rules |
| seat of arbitration | 决定准据法和执行事宜的仲裁法律所在地 | arbitration seat、place of arbitration |
| mediation | 由中立第三方促成的协助式谈判 | conciliation（部分重叠，但某些法域中含义不同） |
| conciliation | 由中立调解人提供不具约束力建议的和解促成程序 | mediation（大体同义） |
| mediator | 促成和解商谈的中立第三方 | conciliator（如其提供建议） |
| mandatory mediation attempt | 诉讼/仲裁前必须尝试调解的要求（程序性） | compulsory mediation、stay for mediation |
| assisted negotiation | 有中立协助者的谈判（不如调解正式） | facilitated negotiation |
| multi-tier dispute resolution clause | 要求先协商、再调解、后仲裁/诉讼的升级条款 | escalation clause、tiered dispute resolution |

## 民事诉讼——当事人、诉讼文书与程序

| 标准英文术语 | 用法/含义 | 避免 |
|---|---|---|
| civil proceedings | 私人当事人之间就私法权利（合同、侵权、财产、家庭）进行的法院程序 | civil cause（直译）、civil case（不够正式） |
| claimant (UK) / plaintiff (US) | 提起民事诉讼的一方 | actor（民法直译）、applicant（留给行政/司法审查） |
| defendant | 被提起民事诉讼的一方 | respondent（留给上诉/行政程序）；convenuto（不得直译） |
| respondent | 对申请、上诉或仲裁作出回应的一方（不用于普通民事请求） | defendant（一审民事请求中应使用“defendant”） |
| joinder | 将另一方或另一请求加入既有程序 | intervention（见下——不同概念） |
| intervener / intervening party | 经准许加入进行中的程序以保护自身利益的第三人 | joinder（不同——程序性追加） |
| claim form / particulars of claim (UK) / complaint (US) | 启动民事诉讼并载明请求的文书 | citation（民法直译）、petition（留给特定程序） |
| statement of case / pleadings | 当事人陈述己方案情的正式书面文件 | memorials（投资条约仲裁）、briefs |
| statement of claim | 原告关于其请求的正式陈述 | petition、request for judgment |
| defence / statement of defence (UK) / answer (US) | 被告的正式应诉答辩 | response、objection（仅限初步异议） |
| reply | 原告对答辩的回应 | rejoinder（见下——更后阶段） |
| rejoinder | 被告对 reply 的进一步回应 | surrejoinder（美国；很少使用） |
| counterclaim / cross-claim | 被告在同一程序中对原告提起的请求 | counter-action、reconventional claim（民法直译） |
| set-off (as defense) | 作为抗辩提出的交叉请求，用于减少或消灭原告请求 | counterclaim（不同——交叉请求是独立的） |
| amendment of pleadings | 经法院许可对诉讼文书进行的正式修改 | variation of claim（不精确） |
| service of process / service of proceedings | 向对方正式送达法院文书 | notification（在英国程序中不够精确） |
| substituted service / alternative service | 以标准方式以外的方法送达（例如通过电子邮件、依法院命令） | alternative notification |
| cross-border service | 向位于其他法域的当事人送达程序文书（例如《海牙送达公约》、欧盟送达条例） | international notification |
| joinder of parties | 将其他当事人加入程序的程序 | integration of parties（直译） |
| case management conference (CMC) | 法院就案件审理方式作出指示的程序性聆讯（英国；许多法域类似） | preliminary hearing（不同概念） |
| directions | 法院规范案件程序进行的命令 | instructions、procedural orders |
| disclosure (UK) / discovery (US) | 要求当事人识别并出示相关文件的程序 | disclosure of documents、document production |
| inspection of documents | 一方查阅对方披露的文件的权利 | examination of documents |
| privilege / legal professional privilege | 对特定类别的通信（例如法律意见、诉讼）免于披露的保护 | professional secrecy（民法直译） |
| witness statement | 附真实声明签署的证人证言书面陈述 | witness declaration |
| expert report | 指定专家就其专业领域事项出具的书面报告 | technical report（过于含糊） |
| court-appointed expert | 法院指定的独立专家（大陆法系法域常见） | judicial expert（直译） |
| single joint expert (SJE) | 当事人共同委托的唯一专家（英国 CPR 实务） | joint expert（不够精确） |
| party-appointed expert | 当事人委托出庭作证的专家 | technical consultant（民法直译） |
| evidence | 用于证明或反驳争议事实的材料 | proofs（法语/意大利语直译） |
| documentary evidence | 由文件构成的证据 | document proofs |
| oral evidence / testimony | 证人在法庭上提供的证据 | verbal evidence |
| examination-in-chief / direct examination | 当事人对本方证人的询问 | initial examination |
| cross-examination | 对方当事人对证人的询问 | contested examination |
| re-examination | 交叉询问后原当事人对证人的进一步询问 | re-direct（美国） |

## 民事诉讼——庭审、判决与救济

| 标准英文术语 | 用法/含义 | 避免 |
|---|---|---|
| trial / hearing | 法院审理案件的实体聆讯 | final audience（直译） |
| adjournment | 将聆讯推迟至以后日期 | suspension of hearing |
| judgment (UK) / judgement / decision | 法院确定当事人权利义务的正式裁定 | sentence（民法直译——留给刑事） |
| reasoned judgment | 载明法院推理过程的判决 | motivated judgment（直译） |
| interim judgment / interlocutory judgment | 在最终裁判前就初步问题作出的判决 | partial judgment |
| default judgment | 对未提交答辩或未出庭的一方作出的缺席判决 | contumacious judgment（直译） |
| summary judgment | 在没有真实胜诉前景/抗辩时不经完整庭审作出的判决 | abbreviated judgment |
| declaratory judgment / declaration | 宣告当事人权利或地位的判决 | declarative judgment |
| final judgment | 最终确定程序中实体问题的判决 | definitive judgment（直译；可用但不那么地道） |
| consent order / judgment by consent | 记录当事人达成和解条款的法院命令 | agreed judgment |
| damages | 对损失的金钱赔偿 | indemnities（易混淆——留给赔偿条款） |
| general damages | 对非金钱损失（痛苦、折磨、生活乐趣丧失）的赔偿 | — |
| special damages | 对具体、可量化的金钱损失的赔偿 | — |
| nominal damages | 权利受到侵害但无实质损失时的象征性赔偿 | symbolic damages |
| aggravated damages | 反映被告行为方式的赔偿 | — |
| exemplary / punitive damages | 旨在惩罚被告的赔偿（限于少数普通法案件） | — |
| costs | 判归胜诉方的律师费与垫付费用 | expenses（范围更窄） |
| costs follow the event | 败诉方承担胜诉方费用的默认规则 | costs to the victor（口语化） |
| indemnity costs / costs on the indemnity basis | 因一方不合理行为而对其作出的加重费用裁定 | — |
| specific performance | 要求履行合同义务的衡平救济 | enforced performance（直译） |
| injunction | 要求一方作为或不作为的法院命令 | interdict（苏格兰/荷兰语直译） |
| mandatory injunction | 要求作出积极行为的禁令 | performance injunction |
| prohibitory injunction | 禁止某一行为的禁令 | negative injunction |
| interim injunction / interlocutory injunction | 庭审前作出的禁令 | preliminary injunction（美国；可接受） |
| freezing order / freezing injunction（旧称 Mareva） | 在判决作出前冻结一方资产的命令 | asset-freezing order |
| search order（旧称 Anton Piller） | 允许进入场所检查并扣押证据的命令 | inspection order（过宽） |
| rectification | 更正未反映当事人真实合意的书面文书的衡平救济 | correction（过于非正式） |
| rescission | 因虚假陈述、胁迫等原因解除合同的衡平救济 | annulment（留给特定的法定撤销） |
| restitution | 要求返还不当取得的利益的救济 | restitution of the indebitum（直译） |
| stay of proceedings | 中止法院程序的命令 | suspension（有歧义） |
| strike out | 法院以程序或实体瑕疵为由驳回请求或答辩的权力 | dismissal（用于实体判决） |
| dismissal of claim | 驳回请求（通常在聆讯后） | rejection of claim |

## 民事诉讼——上诉与执行

| 标准英文术语 | 用法/含义 | 避免 |
|---|---|---|
| appeal | 对下级法院裁判提出异议的程序 | recourse（民法直译） |
| appellant | 提起上诉的一方 | appealing party |
| respondent (on appeal) | 应对上诉的一方 | appealed party |
| grounds of appeal | 上诉中提出的具体法律或事实异议 | reasons of appeal |
| permission to appeal / leave to appeal | 提起上诉所需的司法许可（必要时） | authorization to appeal |
| notice of appeal | 启动上诉的文书 | appeal declaration |
| appeal on a point of law | 仅限于法律错误的（不再审理事实的）上诉 | appeal of law（直译） |
| cassation | 大陆法系中，向最高法院提出的仅限于法律错误的上诉；非普通法概念——可能需要译者注释 | — |
| Court of Cassation / Supreme Court | 大陆法系中审查法律问题的最高法院 | cassation court（保留大写） |
| setting aside / annulment of judgment | 正式撤销判决（例如因根本程序瑕疵） | vacatur（美国特有） |
| revision / retrial | 因新证据而重新开庭审理（普通法上范围较窄；大陆法中范围较宽） | review（有歧义） |
| final and binding judgment | 不得上诉或上诉期限已届满的判决 | res judicata（原则，而非判决本身） |
| enforcement / execution | 执行判决或裁决的程序 | execution of judgment（可用但不够正式） |
| writ of execution | 授权执行判决的法院文书 | execution title（民法直译） |
| enforceable title | 具有直接执行效力的文书（例如判决、公证文书）——大陆法概念；在英文中需要解释 | executive title（直译） |
| recognition and enforcement | 外国判决或仲裁裁决在另一法域发生效力的程序 | exequatur（大陆法术语；可保留并加解释） |
| attachment / freezing order | 扣押或冻结资产的法院命令 | seizure（范围更窄） |
| charging order | 以判决债务人在土地或证券上的权益设定负担以担保付款的命令 | — |
| third-party debt order / garnishee order | 将第三方欠付判决债务人的债务转付给判决债权人的命令 | garnishment order（美国） |
| order for possession | 将财产占有权判给一方的法院命令 | repossession order |
| judgment creditor | 有权执行判决的一方 | — |
| judgment debtor | 可对其执行判决的一方 | — |
| insolvency / bankruptcy proceedings | 处理破产问题的法院监督程序 | receivership（留给特定的普通法救济） |
| receiver | 法院指定管理资产的官员 | — |

## 行政诉讼

| 标准英文术语 | 用法/含义 | 避免 |
|---|---|---|
| administrative proceedings | 涉及行使公权力/政府行为的程序 | administrative cause（直译） |
| administrative court (UK) / administrative tribunal / administrative law court | 审理公法事项的专门法院或裁判所（例如意大利 TAR/Consiglio di Stato、法国 Conseil d'État、德国 Verwaltungsgericht） | administrative jurisdiction（直译——留给管辖意义上的用法） |
| judicial review | 对公共机构决定、行为或不作为合法性的审查 | control of legitimacy（直译） |
| application for judicial review | 启动司法审查的程序机制 | judicial review recourse |
| applicant (judicial review) | 提起司法审查申请的一方 | claimant（留给普通民事） |
| interested party | 对司法审查具有充分利益的一方 | counter-interested party（“controinteressato”的直译） |
| public authority / public body | 受行政法约束的决策主体（例如政府部门、机构、监管机关） | public administration（在大陆法语境中可用，但范围更广） |
| administrative act / administrative decision | 公共机构作出并产生法律效果的决定、措施或行为 | administrative provision（“provvedimento”的直译） |
| regulatory act / regulation | 公共机构作出的普遍适用性行为 | normative act（直译） |
| statutory instrument | 委任立法行为（英国术语） | secondary legislation（范围更广） |
| ultra vires | 超出公共机构法定权力的行为 | excess of power（美国：可接受；英国程序语言：ultra vires） |
| illegality | 公共机构超出法定权力行事时的审查事由 | unlawfulness（范围更广） |
| irrationality / Wednesbury unreasonableness | 决定极不合理、任何理性的机关都不可能作出时的审查事由 | absurd decision |
| procedural impropriety | 未遵循正当程序（例如咨询、自然正义）时的审查事由 | procedural unfairness（范围更广） |
| proportionality | 要求措施与其目标相称的审查事由（欧盟/《欧洲人权公约》及许多大陆法系） | — |
| legitimate expectation | 保护由公共机构诱导产生的期待的法理 | reliance expectation |
| duty to give reasons | 公共机构说明决定理由的义务 | duty of motivation（直译） |
| annulment of administrative act | 法院撤销行政行为 | cassation of the act（直译） |
| suspension of administrative act | 在聆讯前中止行政行为效力的临时命令 | precautionary suspension |
| quashing order / quashing of decision（英国：“quash”） | 撤销行政决定的法院命令 | cancellation（过宽） |
| mandatory order (UK) / mandamus (US) | 要求公共机构作为的法院命令 | injunction to perform |
| prohibiting order (UK) / prohibition | 阻止公共机构非法作为的法院命令 | — |
| declaration of unlawfulness / declaration of invalidity | 宣告行为或决定违法的司法宣告 | declaration of illegitimacy |
| administrative appeal / hierarchical appeal | 司法审查前在行政层级内部提出的上诉 | gerarchico recourse（直译） |

## 注释

- **Settlement 与 transaction 的歧义**：许多源语言用一个词同时表示“settlement”（争议的法律解决）和“transaction”（商业交易）。由语境决定：在争议解决语境中，一律使用“settlement”；在商业语境中，使用“transaction”。

- **Full and final settlement**：一些源语言有专门术语（往往偏口语）指代完整并排除一切进一步请求的和解。正确英文为“full and final settlement”或“complete release”。

- **“Accord and satisfaction”**：普通法原则，以提供新对价换取对既有请求的免除。大陆法系中的对应概念是“settlement”，其生效要件不同（例如相互让步）。仅在普通法语境中使用“accord and satisfaction”。

- **“Without prejudice”/“without prejudice save as to costs”**：英国诉讼特权，保护和解通信不被作为证据采纳。“Without prejudice save as to costs”允许在和解商谈后仍就费用问题保留争辩余地。在非英国语境中，应说明是否存在对等的特权。

- **“Tomlin order”**：英国程序，争议条款以另行封存的文书保密，而主协议存档于法院。通用对应词为“consent order”，但指称英国特有程序时应使用“Tomlin order”。

- **“No admission of liability”**：标准和解条款，明确和解不构成对过错或责任的承认。在诸多法域中，为在相关程序中保留抗辩至关重要。

- **Consent orders**：在普通法法域，和解可记录为“consent order”（经法院批准）。在大陆法法域，对应物是经法院批准的和解或提交法院的调解记录。子词典提供源语言映射。

- **和解语境中的“Entire agreement”**：确认和解协议构成关于争议的完整协议并取代此前一切谈判、谅解和副函的条款。对可执行性至关重要。

- **“Sentence”——假朋友**：许多大陆法源语言使用“sentence”的同源词指称任何终局司法裁判（民事、行政或刑事）。英文中“sentence”专用于刑事诉讼（定罪后施加的刑罚）。民事和行政语境应使用“judgment”。这是最需警惕的常见直译错误之一。

- **“Imputation”/“imputato”——假朋友**：大陆法系中，被告常被称为“imputato”（意大利语）、“imputé”（法语）等，动词“to impute”用于表示“指控”。英文刑事诉讼中，正确术语是“defendant”/“accused”和“to charge”（名词：“charge”或“indictment”）。绝不直译为“imputation”/“imputed”。

- **“Legitimate interest”与“legitimate expectation”**：这是两个常被混淆的不同概念。“Legitimate interest”（interesse legittimo）是行政法上关于起诉资格的大陆法概念，无直接普通法对应。“Legitimate expectation”是保护公共机构诱导产生的期待的英国法理。不得混同。

- **刑事诉讼中的民事当事人**：被害人加入刑事诉讼索赔损害赔偿的大陆法概念（“partie civile”、“parte civile”、“Nebenkläger”）无直接普通法对应（美国有“victim impact statements”；英国有独立的民事诉讼）。在技术性区别重要时，保留源术语并加译者注释。

- **“Court of cassation”**：大陆法系最高法院（Cour de cassation、Corte di Cassazione、Tribunal Supremo）仅审查法律问题，不重审事实。这与英国最高法院和美国最高法院不同——后两者在适当案件中可考虑事实。保留专有名称（“Court of Cassation”），在程序角色重要时加译者注释。

- **“Judicial review”与“appeal”**：在英国行政法中，“judicial review”是审查决定合法性（而非实体）的独立公法程序。大陆法系中，行政法院往往同时审查合法性与实体——翻译时须谨慎；如源文件设想的审查涉及实体，可考虑“administrative appeal”或加译者注释。

- **Exequatur / recognition and enforcement**：许多大陆法系用“exequatur”指称外国判决/裁决的承认与执行。在英文法律写作中，优先使用“recognition and enforcement”，仅在该程序被明确如此命名时（例如在欧盟条例中）保留“exequatur”。
