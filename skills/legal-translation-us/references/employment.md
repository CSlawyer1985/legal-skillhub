# 就业 / 劳动词汇表

就业协议的标准英文术语：劳动合同、高管服务协议、限制性契约、离职协议、集体谈判协议、职工委员会文件、借调协议及相关文书。

## 核心雇佣术语

| 正确英文术语 | 用法 / 含义 | 避免 |
|---|---|---|
| employment contract / employment agreement | 在雇主与雇员之间创设法律关系的协议 | "employment arrangement"（非正式）；"service agreement"（历史术语） |
| permanent employment contract | 无固定结束日期的雇佣合同；仅可因正当理由或双方同意而终止 | "indefinite contract"（不够精确）；"open-ended contract" |
| fixed-term employment contract | 有明确结束日期的雇佣合同；除续签外自动终止 | "temporary contract"（可能暗示短期）；"time-limited contract" |
| part-time employment contract | 约定低于全职标准工作时间的雇佣合同 | "part-time agreement"（不够正式） |
| consultancy agreement / contractor agreement | 在不建立雇佣关系的情况下，聘请独立承包商提供特定服务的合同 | "independent contractor agreement"（更精确但冗长）；"service agreement"（有歧义） |
| project-based contract | 聘请劳动者完成特定项目或特定交付成果的合同 | "project contract"（非正式）；"task-based agreement" |
| letter of appointment / offer letter | 载明关键雇佣条款、薪资和入职日期的文件 | "employment offer"（不够正式）；"offer of employment" |
| non-compete agreement / non-competition covenant | 禁止雇员在雇佣期间/雇佣结束后与雇主竞争的限制性契约 | "non-compete clause"（不够正式）；"restrictive covenant"（更宽泛的类别） |
| non-solicitation agreement | 禁止雇员招揽雇主客户或雇员的限制性契约 | "non-poaching agreement"（非正式） |
| confidentiality agreement | 保护雇主保密商业信息和商业秘密的协议 | "non-disclosure agreement"（NDA）（通常更宽泛）；"secrecy agreement"（非正式） |
| minimum term clause / lock-in clause | 要求雇员在最短期限内保持受雇或偿还培训费用的条款 | "lock-in provision"（非正式）；"minimum service period"（不够法律化） |
| probationary period / trial period | 初始雇佣期（通常 1-6 个月），期间任一方可不经通知终止 | "trial employment"（非正式）；"probation period" |
| mutual termination agreement | 雇主与雇员按约定条款终止雇佣的协议 | "severance agreement"（特指付款）；"termination settlement" |
| severance agreement | 以放弃索赔为交换，在终止时提供付款/福利的协议 | "settlement agreement"（英国术语，更精确）；"settlement arrangement"（非正式） |
| whistleblowing / protected disclosure | 雇员举报法律、监管或道德违规行为；依据 EU 指令 2019/1937 及国内立法受保护免遭报复（英国：《公共利益披露法》1998） | Reporting violations（不够精确）；Informing（过于笼统） |
| settlement agreement | 英国雇佣法中的和解协议（2013 年后取代"compromise agreement"），以付款为交换解决争议/索赔 | "compromise agreement"（英国旧术语，2013 年前）；"settlement package"（非正式） |

## 薪酬与福利

| 正确英文术语 | 用法 / 含义 | 避免 |
|---|---|---|
| remuneration / salary | 雇主为雇员完成的工作支付的全部报酬 | "pay"（非正式）；"compensation"（可能包含福利） |
| gross annual salary | 扣除（税、社保等）前的年薪总额 | "annual salary"（有歧义）；"base salary"（可能不含奖金） |
| net salary | 所有法定和自愿扣除后的薪资 | "take-home pay"（非正式）；"actual salary" |
| payslip | 显示计薪期内总薪资、扣除项和净支付的单据 | "pay stub"（美式用语）；"salary statement"（不够正式） |
| thirteenth month's salary | 年底或节假日向雇员支付的额外一个月薪资（欧洲惯例） | "13th month bonus"（不够精确）；"year-end bonus"（不同概念） |
| fourteenth month's salary | 在第二个指定时间支付的额外一个月薪资（欧洲惯例） | "14th month bonus"（不够精确） |
| severance indemnity / end-of-service allowance | 在整个雇佣期间累积、终止时支付的法定权利；存在于许多大陆法系司法辖区，计算方法各异 | "severance pay"（更窄）；"termination payment"（非正式） |
| severance pay | 终止/裁员时向雇员支付的款项（可为法定或合同约定） | "termination payment"（不够正式）；"exit payment"（非正式） |
| payment in lieu of notice | 雇主以付款代替实际履行通知期的形式向雇员支付 | "PILON"（英国缩写）；"notice payment"（不够精确） |
| severance package / ex gratia payment | 终止时超出法定权利的自愿额外付款 | "goodwill payment"（非正式）；"separation incentive" |
| supplementary allowance | 基本薪资之外的额外固定付款（行业特定） | "top-up"（非正式）；"supplementary pay"（不够正式） |
| performance bonus | 基于达成特定绩效目标的浮动付款 | "bonus"（有歧义）；"performance incentive" |
| MBO / management bonus | 将奖金与组织/个人目标挂钩的目标管理制度 | "objectives-based bonus"（不够标准）；"goal-based bonus" |
| stock options | 在指定期限内以指定价格购买公司股份的权利 | "share options"（不够精确）；"equity options" |
| incentive plan | 为绩效提供现金/股权激励的结构化方案 | "incentive scheme"（不够正式）；"performance plan" |
| benefit / fringe benefit | 雇主提供的非现金报酬（保险、退休、车辆等） | "perk"（非正式）；"indirect compensation"（不够精确） |
| company car | 雇主提供用于公务和私人用途的车辆 | "company vehicle"（更宽泛）；"executive car"（更窄） |
| supplementary health insurance | 法定覆盖范围之外的健康保险，由雇主出资或共同承担 | "additional health coverage"（不够精确）；"top-up health insurance" |
| golden parachute | 高管在控制权变更或无因终止时触发的加强版离职/薪酬方案 | Golden handshake（不同——一般离职金）；Executive severance（不够具体） |
| clawback | 雇主在特定事件（不当行为、账目重述）发生时收回已付奖金或激励报酬的合同或监管权利 | Recovery of bonus（不够标准）；Repayment clause（不够具体） |
| vesting / equity vesting | 雇员对股票期权或股权奖励的权利随时间无条件化（例如 4 年分期归属、1 年悬崖）的过程 | Share vesting（可接受）；Option vesting（更窄） |
| supplementary pension fund | 法定国家计划之外的职业或个人养老金计划 | "private pension"（不够精确）；"additional pension" |
| social security contributions | 雇主/雇员向社会保障体系缴纳的强制性款项 | "social contributions"（不够精确）；"payroll taxes"（非正式） |
| employer contributions | 雇主向社保/养老金缴纳的强制性款项 | "employer taxes"（非正式）；"employer payroll contributions" |
| employee contributions | 雇员向社保/养老金缴纳的强制性款项（通常从薪资中扣除） | "employee taxes"（非正式）；"payroll deductions"（更宽泛） |

## 工作条件

| 正确英文术语 | 用法 / 含义 | 避免 |
|---|---|---|
| working hours | 雇员执行工作的时间；可包括标准工时和加班时间 | "work hours"（非正式）；"hours of work" |
| full-time hours | 每周标准工作小时数（通常 35-40 小时；视辖区而定） | "full hours"（非正式） |
| overtime | 超出标准工时执行的工作；通常按溢价费率支付 | "extra hours"（非正式）；"additional hours"（有歧义） |
| night work | 在指定夜间时段（通常 22:00-06:00 或类似）执行的工作 | "night shift"（不够精确，可能指班次模式）；"night-time work" |
| work on public holidays | 在法定公共假日执行的工作；可能按溢价支付或给予补休 | "holiday work"（有歧义）；"work on holidays" |
| annual leave / holiday entitlement | 用于休息和休养的带薪假期；法定最低通常为每年 20-30 天 | "vacation"（美式用语）；"holiday"（英式用语，可能有歧义） |
| paid leave | 继续支付薪资的休假 | "paid time off (PTO)"（不够正式）；"paid absence" |
| maternity leave | 女性雇员生育前后享有的带薪假期 | "pregnancy leave"（不够精确）；"maternity absence" |
| paternity leave | 男性雇员在孩子出生时享有的带薪假期 | "parental leave"（更宽泛）；"father's leave"（非正式） |
| parental leave | 雇员（父母任一方）为照护幼儿享有的带薪/无薪假期 | "childcare leave"（不够精确）；"family leave"（更宽泛） |
| sick leave | 因病缺勤；可在法定上限内带薪 | "illness leave"（不够精确）；"absence due to illness" |
| protected sick leave period | 雇主在雇员因病缺勤时仍须继续支付薪资的最长期间；因辖区和集体协议而异 | "sickness period"（有歧义）；"illness protection period" |
| workplace accident / occupational injury | 雇员因工作或工作相关活动遭受的身体伤害 | "work-related injury"（更宽泛）；"occupational accident"（不够精确） |
| place of work | 雇员执行工作的地点（办公室、工厂、现场等） | "work location"（非正式）；"workplace"（更宽泛，含设施） |
| business travel / posting | 要求雇员在不同地点工作的临时派驻 | "business trip"（不够精确）；"work posting"（正式，但特指被派驻工人） |
| remote working / agile working | 在雇主场所之外通过电子通信执行工作 | "work from home"（不够正式）；"flexible working"（可能包含其他安排） |
| telework | 定期通过电信在家或远程地点工作 | "remote work"（更现代的说法）；"work from home"（不够正式） |
| duties / role | 分配给雇员的职责和任务 | "job duties"（非正式）；"functions"（不够精确） |
| classification / grading | 为薪资/福利目的将雇员分配到组织层级/类别 | "job classification"（更宽泛）；"grade level" |
| contractual grade / pay grade | 根据集体协议分配给雇员的特定工资类别 | "pay level"（不够正式）；"salary level"（非正式） |
| job title / qualification | 雇员职位的正式名称及所需资质 | "position title"（不够正式）；"job description"（不同概念） |

## 限制性契约

| 正确英文术语 | 用法 / 含义 | 避免 |
|---|---|---|
| restrictive covenant | 限制雇员离职后行为的条款的通用类别 | "non-compete"（更窄，特定类型） |
| non-compete clause | 禁止雇员在雇佣关系终止后与雇主竞争的契约 | "non-competition clause"（变体）；"restrictive covenant"（更宽泛的类别） |
| non-solicitation covenant | 禁止雇员在终止后招揽雇主客户或雇员的契约 | "non-solicit clause"（非正式）；"non-poaching covenant" |
| non-dealing covenant | 禁止雇员在终止后与雇主客户订立合同的契约 | "customer non-dealing clause"（不够标准）；不得与 non-solicitation 混淆 |
| garden leave | 雇主在通知期内要求雇员留在家中并维持薪资和福利的权利；实际上在通知期内执行竞业禁止 | Gardening leave（变体，可接受）；Paid suspension（不同概念） |

## 终止条款

| 正确英文术语 | 用法 / 含义 | 避免 |
|---|---|---|
| dismissal / termination | 雇主终止雇佣 | "firing"（非正式）；"discharge"（陈旧） |
| dismissal for just cause / summary dismissal | 雇主因严重不当行为不经通知立即终止 | "dismissal for cause"（有歧义）；"termination for cause"（可能包含其他理由） |
| dismissal for justified subjective reason | 雇主基于雇员的个人行为终止雇佣；大陆法系概念，具有与"just cause"不同的特定法律后果 | "dismissal for gross misconduct"（更窄）；"disciplinary dismissal"（可能指正式程序） |
| dismissal for justified objective reason | 雇主基于业务需要/重组终止雇佣；大陆法系概念，不同于普通法系的裁员 | "dismissal for redundancy"（更窄，后果不同）；"layoff"（非正式） |
| collective dismissal / redundancy | 因企业关闭/重组而终止多名雇员的雇佣 | "group termination"（不够法律化）；"mass layoff"（非正式） |
| disciplinary dismissal | 因雇员不当行为经正式纪律程序后的终止 | "dismissal for discipline"（不够正式）；"termination for cause"（有歧义） |
| resignation | 雇员终止雇佣；通常需要通知期 | "quitting"（非正式）；"giving notice"（更窄，描述发出通知） |
| constructive dismissal / resignation for just cause | 雇员因雇主严重违约而有理由辞职；可能使雇员有权获得离职金 | "constructive termination"（不够精确）；"forced resignation"（非正式） |
| notice period | 终止生效前雇员/雇主必须等待的期间；依合同/法律而异 | "notice"（非正式）；"advance notice"（冗余） |
| challenge of dismissal / unfair dismissal claim | 雇员质疑解雇合法性/公正性的法律行动；救济因辖区而异 | "wrongful termination claim"（美式用语，法律标准更窄）；"dismissal dispute" |
| reinstatement | 要求雇主将遭解雇雇员恢复原职位或同等职位的救济 | "reemployment"（不够精确）；"restoration" |
| compensatory indemnity / damages | 雇员在非法/不公平解雇时获得的赔偿款项 | "severance"（可能为合同约定）；"damages"（更宽泛的法律概念） |
| reinstatement remedy | 要求恢复被非法解雇雇员职位的救济；在一些大陆法系司法辖区可用 | "substantive protection"（不够精确）；"specific performance"（更宽泛） |
| compensation remedy | 在不公平解雇时提供赔偿而非恢复职位的救济；许多辖区中为恢复职位的替代方案 | "financial protection"（非正式）；"damages award"（更宽泛） |
| change of control | 参见 finance-banking.md 中的权威定义。雇佣语境：高管合同可在控制权变更时规定加速归属、加强离职待遇或终止权。 | — |

## 集体劳动术语

| 正确英文术语 | 用法 / 含义 | 避免 |
|---|---|---|
| national collective bargaining agreement (NCBA) | 雇主协会/工会在全国层面谈判达成的总集体协议 | "national labor agreement"（非正式）；"sectoral agreement"（范围更窄） |
| company-level collective agreement | 雇主与工会/工人代表在公司层面谈判达成的集体协议 | "site agreement"（非正式）；"enterprise agreement" |
| trade union agreement | 雇主与工会就雇佣事项达成的协议 | "union agreement"（非正式）；"collective agreement"（更宽泛的术语） |
| trade union | 代表工人在与雇主谈判中的利益的正式组织（美式："labor union"同样标准；英式：偏好 "trade union"，拼写用 "organisation"） | "union"（作为主要术语非正式） |
| company trade union representation | 公司层面代表工人利益的职工委员会等效机构；结构因辖区而异 | "union representation"（不够精确）；"worker representatives"（更宽泛） |
| unified trade union representation | 公司层面多工会的工人代表结构；常见于大陆法系司法辖区 | "unified representation"（非正式）；"joint union representation" |
| workers' assembly | 雇员讨论集体事务的正式会议 | "employee assembly"（不够正式）；"staff meeting"（目的不同） |
| right to strike | 工人以工业行动方式停止劳动的法律权利 | "strike right"（不够正式）；"strike protection" |
| wage supplementation fund / short-time working scheme | 雇主减少工时时为工人提供部分收入的政府支持计划；许多欧盟司法辖区有等效方案 | "unemployment insurance"（更窄）；"job protection scheme"（非正式） |
| ordinary wage supplementation | 针对暂时性经济困难的工资补贴；通常期限较短、标准较宽松 | "regular benefit"（不够精确）；"ordinary support"（非正式） |
| extraordinary wage supplementation | 针对重大重组/危机的工资补贴；期限更长、要求更严格 | "extended benefit"（非正式）；"crisis support" |
| redundancy scheme | 协助因重组而失业的工人的政府计划；可能包括再培训、就业安置和收入支持 | "retraining program"（目的不同）；"displacement scheme"（不够标准） |
| transfer of undertakings / TUPE (UK) | 企业出售/转让时雇佣合同的自动转移（EU 指令 2001/23/EC；英国：《2006 年企业转让（雇佣保护）条例》） | Business transfer（不够精确）；Succession（更宽泛） |
| collective redundancy procedure | 终止多名雇员雇佣的法律程序；通常要求通知、协商、社会计划 | "layoff procedure"（非正式）；"mass dismissal process" |
| trade union consultation | 雇主在重大雇佣决定上必须与工会/工人代表进行的讨论 | "union meeting"（非正式）；"worker consultation"（不够精确） |

## 借调与派遣术语

| 正确英文术语 | 用法 / 含义 | 避免 |
|---|---|---|
| secondment | 雇员从原雇主临时调往宿主公司工作；原雇主通常保留雇佣关系 | "detachment"（大陆法系直译）；"posting"（更窄，欧盟特定） |
| cross-border posting / transnational secondment | 雇员从一国借调至另一国工作（适用欧盟被派驻工人指令） | "international posting"（不够精确）；"cross-border assignment" |
| seconding company | 保留与借调工人法律雇佣关系的雇主 | "home employer"（不够正式）；"original employer" |
| host company | 使用借调工人服务但通常不是雇佣合同一方的雇主 | "receiving company"（不够正式）；"destination employer" |
| seconded employee / posted worker | 由借调公司保留、临时为宿主公司工作的雇员 | "seconded worker"（变体）；"posted worker"（欧盟术语，特定法律地位） |
| temporary agency work | 劳务派遣机构向客户雇主提供工人从事临时工作的行为 | "temp work"（非正式）；"temporary staffing" |
| temporary employment agency | 受聘为客户雇主招募和提供临时工人的企业 | "staffing agency"（不够正式）；"employment agency"（更宽泛） |
| agency worker / temporary worker | 由劳务派遣机构提供给客户雇主在确定期限内工作的工人 | "temp"（非正式）；"temporary employee"（不够精确，可能是直接雇佣） |

## 注释

- **雇佣类别**：许多大陆法系司法辖区使用法定雇员分类（例如高管、经理/主管、白领、蓝领），在解雇、通知、福利和合同待遇上有不同规则。在英国/美国语境中，按功能描述分类（高管、经理、专业人员、体力劳动者）。子词汇表提供源语言类别映射。

- **解雇理由**：大陆法系司法辖区通常区分"just cause"（正当理由，严重不当行为立即终止）和"justified reason"（合理理由，因行为或业务原因经通知终止），二者法律后果不同。除非源文件明确映射，不要将普通法系术语（"unfair dismissal""wrongful termination"）强加到大陆法系类别上。保持源管辖区的法律框架。

- **限制性契约类别**：竞业禁止（non-compete）、禁止招揽（non-solicitation）和禁止交易（non-dealing）是三种不同的限制性契约。不要用"non-compete"泛泛涵盖三者。三种同时出现时分别建条目。

- **Settlement agreement（英国）** / **"Compromise agreement"**：在英国雇佣法中，"settlement agreement"（2013 年 4 月后）取代了"compromise agreement"（2013 年 4 月前）。当前英语交易中使用"settlement agreement"。

- **PILON**："Payment in lieu of notice"（代通知金）是标准英国术语；其他辖区可能使用"payment instead of notice"或类似表述。翻译时在英国语境中使用 PILON 并加解释。

- **Garden leave**：英国概念，允许雇主在通知期内让雇员离岗但维持薪资（限制性契约）。源文件讨论此内容时纳入；并非所有大陆法系司法辖区的标准做法。

- **TUPE / transfer of undertakings**：EU 指令 2001/23/EC 规定的企业出售时雇佣关系自动转移。英国语境中使用"transfer of undertakings"/"TUPE"；其他语境使用"business transfer"或"succession in business"。

- **Whistleblowing / protected disclosure**：现代雇佣法对举报法律/监管违规行为的雇员的保护。使用"whistleblowing"（非正式、现代）或"protected disclosure"（正式，英国《公共利益披露法》下的术语）。源文件涉及此概念时纳入。

- **全国性集体协议**：许多辖区的雇佣合同并入适用的全国或行业集体谈判协议。英文翻译中，首次提及时保留原文名称/缩写，但增加英文描述（例如"[行业]全国集体谈判协议"）。子词汇表提供源语言映射。

- **辖区特定规则**：解雇理由、通知期、离职金和救济因辖区而异。不要将源辖区法律类别强加到英国/美国法律上。准确翻译并在子词汇表中注明源辖区。

- **法定离职补偿金**：一些大陆法系司法辖区有独特的法定离职权利，在整个雇佣期间累积，无论终止原因如何均须支付。普通法系无精确对应。译为"severance indemnity"或"end-of-service allowance"，并在首次使用时以括号保留源语言缩写。子词汇表提供源语言映射。
