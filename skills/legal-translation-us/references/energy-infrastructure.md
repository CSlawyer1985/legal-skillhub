# EPC / 能源 / 基础设施术语表

用于 (a) 工程、采购和施工合同（EPC）、交钥匙合同、建设工程协议、辅助设施（BOP）合同、运营与维护协议（O&M）；以及 (b) 能源与基础设施协议——购电协议（PPA）、电网接入、承购协议、特许经营协议、监管与电价事项、可再生能源及相关文书的英文术语。

本综合术语表将建设与调试术语与运营、监管和商业能源/基础设施术语统一起来。许多术语跨越这两类合同家族之间的界面（性能保证、可用性保证、接收与商业运营日期、法律变更、违约金、特许经营介入权），应作为一个术语系统对待。

|---|---|---|

| construction contract / building contract | 建设工程施工合同 | — |
| works contract | 为执行工程而签订的合同 | — |
| subcontract | 主承包商与分包商之间的合同 | — |
| balance of plant (BOP) | 主要设备之外的所有配套系统和基础设施（如电气、土建、互联） | — |
| O&M agreement | 设施运营与维护协议 | — |
| contractor / EPC contractor | 负责执行工程的一方 | — |
| subcontractor | 在主承包商之下履行部分工程的一方 | — |

## 核心能源术语

| 正确英文术语 | 用法/含义 | 避免 |
|---|---|---|
| power purchase agreement (PPA) | 基础性能源销售合同；应注明类型（企业、商户、实物、虚拟/合成） | energy purchase contract；energy supply contract（不够精确） |
| corporate PPA | 终端用户/企业买家长期承购；通常涉及向买方设施的实物交付 | merchant PPA；spot purchase |
| merchant PPA | 以浮动价格向批发市场销售；发电商承担市场风险 | corporate offtake；firm offtake |
| physical PPA | 能源实物交付至约定交付点；实际电力流向买方 | virtual PPA；financial PPA |
| virtual PPA / synthetic PPA | 无实物交付的差价合约（CFD）；作为金融对冲工具 | physical offtake；actual delivery agreement |
| energy supply agreement | 向消费者/终端用户供应能源；区别于发电商 PPA | PPA（将买方承购与发电商销售混淆） |
| offtake agreement | 能源销售协议的总称；常用于项目融资 | energy purchase；energy sales contract |
| bankability | PPA 或项目结构对项目融资债务的适用性；由贷款人评估 | financeable；lendable（非标准） |
| deemed generation / deemed energy | 当发电被削减或阻止时计入发电商的名义产出；作为补偿的基础 | lost generation；foregone energy（含糊） |
| grid connection agreement | 将发电商/消费者接入电网的技术和商业条款；对 PPA 至关重要 | network connection contract；grid access agreement |
| connection charge | 为电网接入基础设施及其维护支付的费用 | grid fee；access fee（不够精确） |
| balancing / dispatch agreement | 实时能源供需平衡的管理 | dispatch contract；load-following agreement |
| grid curtailment / production curtailment | 因电网约束而临时减少发电产出；可能触发约束补偿 | supply restriction；reduction（过于含糊） |
| constraint payments / constraint costs | 因电网拥堵而被迫削减时对发电商的补偿；英国术语为“constraint payments”；美国为“congestion costs” | congestion charges（有歧义） |
| energy storage system / battery | 储存电能的设施；对可再生能源整合很重要 | accumulation facility；energy bank |
| distribution agreement | 通过本地配电电网供应能源；受 DSO 管辖 | retail supply agreement（与零售销售混淆） |

| contractor's proposal | 承包商对雇主要求的回应，详细说明其将如何设计和建造工程（FIDIC 黄皮书/银皮书） | “contractor's offer”、“technical offer” |

### 设计阶段层级（关键）

| 阶段 | 正确英文 | 避免 |
|---|---|---|
| 阶段 1 — 概念 | preliminary design | “preliminary project” |
| 阶段 2 — 中间 | detailed design | “definitive project”（直译词）、“preliminary design”（错误阶段） |
| 阶段 3 — 施工就绪 | construction design | “executive project”（直译词）、“detailed design”（留给阶段 2） |

**警告**：混淆阶段 2（详细设计）与阶段 1（初步设计）是实质性错误。层级为：初步设计 → 详细设计 → 施工设计。

## 可再生能源术语

| 正确英文术语 | 用法/含义 | 避免 |
|---|---|---|
| renewable energy | 来自自然补充来源（风能、太阳能、水能、生物质、地热）的能源 | clean energy；green energy（技术精确性较差） |
| renewable source / renewable resource | 用于发电的自然资源 | renewable input；energy source（过于含糊） |
| photovoltaic (PV) plant / solar PV facility | 使用光伏电池将阳光转化为电能的设施 | solar facility；PV installation（不够精确） |
| wind farm / wind energy plant | 拥有多台风力涡轮机发电的设施 | wind park；eolian facility |
| wind turbine | 单个发电涡轮机；应注明容量（MW、kW） | wind generator；wind device |
| biomass plant | 从有机物中产生能源的设施；应注明燃料类型（林业废弃物、农业残余物等） | bioenergy facility；biological fuel plant |
| hydroelectric plant / hydro facility | 从水流中产生电能的设施；应注明类型（径流式、水库式、抽水蓄能式） | water power plant；dam facility（不精确） |
| concentrated solar power (CSP) plant | 使用镜子/透镜汇聚阳光产生热能的设施；区别于光伏 | thermal solar；solar thermal facility |
| energy storage system | 储存电能的技术（电池、抽水蓄能、压缩空气、热能） | battery；storage facility（过于含糊） |
| installed capacity | 设施在理想条件下的最大总发电输出；以 MW 计量 | rated power；nameplate capacity（不够标准） |
| rated capacity / nameplate capacity | 制造商规定的标准条件下的最大输出 | designed capacity；nominal power |
| capacity factor (%) | 实际能量输出与理论最大值的比值；例如风电场 35% 的容量系数 | efficiency ratio；output percentage（不精确） |
| expected generation / expected output | 基于资源评估预测的年发电量 | expected yield；estimated production |
| equivalent hours (full load hours) | 以额定容量运行、产生实际年输出的年运行小时数；用于性能评估 | effective hours；operating hours |
| capacity market | 为可用性而非发电量向发电商付费的市场机制；通常用于电网稳定 | reserve market；standby payment（不够标准） |
| ancillary services | 支持电网稳定的服务（电压控制、频率调节、无功功率）；区别于能源本身 | grid services；system services（含糊） |
| self-consumption | 直接使用发电商自身的产出；对屋顶光伏和微电网很重要 | self-use；onsite generation（不精确） |
| energy community | 共享可再生能源基础设施的公民/小企业群体；欧盟定义的概念 | community energy；collective generation（含糊） |
| green certificate | 可再生能源发电的金融工具；在很大程度上已被 GO 和 REC 取代 | renewable certificate；eco-certificate |
| guarantee of origin (GO) | 证明可再生能源来源的欧盟证书；可交易和转让 | renewable credit；origin certificate |
| renewable energy certificate (REC) / green energy credit | GO 的国际对应物；主要在美国和澳大利亚市场；1 REC = 1 MWh 可再生能源 | green tag；renewable energy credit（地区术语） |
| white certificate / energy efficiency certificate | 奖励能效改进的金融工具；用于多个欧盟成员国的市场 | EEC；efficiency certificate |
| feed-in tariff (FIT) | 向可再生能源发电商支付的固定价格；许多国家历史上的支持机制 | fixed feed-in payment；guaranteed price |
| feed-in premium / incentive tariff | 可再生能源发电在市场价格之上的浮动溢价 | feed-in subsidy；price support |
| contract for difference (CfD) | 当市场价格低于履约价格时由政府支付差额的金融协议；英国的现代支持机制 | strike price agreement；price floor contract |
| net metering / net billing | 将自耗客户馈入电网的多余发电计入其账户的机制 | smart metering；billing offset（不够精确） |
| regulated offtake / dedicated offtake | 以受监管价格直接向公用事业/承购方销售发电；PPA 或 FIT 的替代方案 | simplified sale；utility sale（含糊） |

## 电网术语

| 正确英文术语 | 用法/含义 | 避免 |
|---|---|---|
| electricity grid / power grid | 发电、输电、配电的互联系统 | electrical system；power system（过于含糊）；electrical network |
| transmission grid / high-voltage grid | 高压（通常 >100 kV）远距离输电的系统 | transmission system；backbone network |
| distribution grid / low-voltage grid | 以较低电压（通常 <35 kV）向终端用户配电的本地电网 | retail network；final-mile system |
| transmission system operator (TSO) | 管理输电网的实体；在大多数司法辖区具有垄断地位 | transmission grid operator；national grid |
| distribution system operator (DSO) | 管理配电网的实体；通常为市政或区域公用事业 | distribution utility；local grid operator |
| connection point / grid connection point | 发电商/消费者接入电网的物理位置；对技术规范至关重要 | injection point（含义不同）；offtake point（含义不同） |
| delivery point / offtake point / metering point | 能源被计量并转移给买方的位置；界定计量责任 | consumption point；settlement point |
| injection point | 发电能源进入电网的位置；用于发电商（区别于交付点） | export point；feed-in point |
| meter / electricity meter | 计量能量流的设备（MWh、kWh）；应注明类型（模拟、数字、智能） | measuring device；consumption counter |
| metering | 计量电力消费/发电的过程；计费和结算的基础 | measurement；monitoring（不够精确） |
| balancing / dispatch services | 确保实时供需平衡的服务；包括频率调节、备用提供 | grid support；system services（含糊） |
| system charges / grid charges | 维护电网基础设施和运营的费用；区别于能源成本 | network fee；transmission charge（不精确） |
| transmission charge | 使用输电网的费用；通常按 MWh 计算或按月容量费 | grid fee；access charge（有歧义） |
| grid losses / network losses | 输配电中以热量形式损失的电力；通常占总流量 3-10% | system loss；transmission loss（不够完整） |
| zonal price / nodal price | 电网特定位置的批发电力价格；随拥堵情况而变化 | location price；regional price（不精确） |
| day-ahead market (DAM) | 次日交付电力的批发市场；主要的价格发现机制 | morning market；forward market（不精确） |
| intra-day market (IDM) | 更短期电力交易的批发市场；允许最后一刻调整 | continuous trading；short-term market |
| balancing market / real-time market | 实时平衡服务的市场；由于紧急性质，价格通常最高 | regulation market；frequency response market |
| balancing responsible party (BRP) | 对计划与实际能量流之间的不平衡承担财务责任的实体；可能是发电商、供应商或交易商 | balance responsible；scheduling agent（不够精确） |
| frequency containment reserve (FCR) | 一次频率响应；频率偏差后数秒内自动响应 | primary reserve；automatic frequency response |
| automatic frequency restoration reserve (aFRR) | 二次频率响应；数分钟内自动恢复；由 TSO 集中启动 | secondary reserve；automatic generation control (AGC) |
| manual frequency restoration reserve (mFRR) | 三次频率响应；由 TSO 在 15 分钟内手动启动 | tertiary reserve；manual reserve |
| frequency reserve | 维持电网频率在 50 Hz 的备用储备总称（FCR、aFRR、mFRR）；应注明类型 | ancillary services（更宽泛）；grid services |
| mark-to-market (MtM) | 按当前市场价格对能源交易头寸进行估值；用于抵押品和追加保证金 | market valuation；fair value（会计术语） |
| collateral / margin | 为覆盖能源交易头寸潜在损失而要求的保证金；可以是现金或银行保函 | security deposit；guarantee（过于含糊） |

## 注释

- **FIDIC 对齐**：许多国际 EPC 合同遵循 FIDIC 标准格式。当源文本遵循该结构时，使用 FIDIC 术语：“Engineer”（而非“Director of Works”）、“Taking-Over Certificate”（而非“Provisional Acceptance Certificate”）、“Defects Notification Period”（FIDIC 2017 版）。

- **“Employer”与“Owner”**：FIDIC 使用“Employer”；许多美国合同使用“Owner”。国际/欧洲合同默认使用“Employer”。

- **违约金（Liquidated damages）**：始终使用“liquidated damages”（而非“penalties”），以保留在英国法下的可执行性。

- **BOT/BOOT/BOO**：对于基于特许经营的建设项目（建设-运营-移交等），适用额外的特许经营特定术语。

- **“施工设计”与“竣工图”**：这是完全不同的东西。施工设计文件在施工前编制；竣工图在施工后编制，显示实际建造情况。混淆它们是实质性错误。

- **O&M 与 EPC 界面**：从 EPC 到 O&M 的移交是关键的项目里程碑。确保 EPC 合同与 O&M 协议之间的术语一致，特别是性能保证、缺陷责任和保修条款。

- **容量与电量**：切勿混淆两者。容量 = 最大输出（以 MW、GW 计量）。电量 = 一段时间内的实际输出（以 MWh、GWh 计量）。一座 100 MW 的风电场每年产生约 350 GWh（40% 容量系数），而不是“100 MWh”。

- **PPA 类型**：现代 PPA 差异很大。始终注明：(1) 企业 vs. 商户承购，(2) 实物 vs. 虚拟/金融，(3) 固定 vs. 可变定价，(4) 期限（通常 10-25 年）。

- **电网削减**：区分 (a) 计划/计划内削减（维护），(b) 强制削减（电网约束并有补偿），(c) 弃水（水坝；无补偿）。

- **可再生能源证书**：GO（来源保证）是欧盟特有的。REC（可再生能源证书）是国际标准，主要用于美国、澳大利亚、印度。在欧盟合同中，通常指 GOs，除非涉及跨境/国际买家。

- **支持机制**：现代机制包括 FIT（递减）、上网电价溢价（带市场价格下限）、CfD（英国模式）、招标式（拍卖）、净计量（分布式发电）和简单销售（商品费率）。识别适用哪种。

- **国家监管机构**：翻译合同时，保留国家监管机构缩写（如意大利的 GSE、GME、Terna、ARERA；英国的 Ofgem、National Grid ESO；美国的 FERC、NERC），并在英文语境中首次出现时加以解释。子词表提供源语言映射。
