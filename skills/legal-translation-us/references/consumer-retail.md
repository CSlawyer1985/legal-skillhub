# 消费者/零售词典

面向消费者的商业协议的标准英语术语：条款与条件、特许经营协议、经销协议、供应协议、代理协议、产品责任、消费者保证及相关文书。

## 核心消费者/零售术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| general terms and conditions of sale | 规范货物零售的标准商业条件 | "conditions of sale"（过于模糊） |
| general terms and conditions | 适用于多种合同类型的宽泛合同条件 | 不含 "terms" 的 "general conditions" |
| franchise agreement | 授予被特许人依特许人品牌/体系经营权利的法律安排 | "franchise contract"（不够精确） |
| distribution agreement | 向最终客户或下级经销商持续供应和分销货物的合同 | "distribution contract"（非正式） |
| supply agreement | 定期或连续供应货物的框架合同 | "supply contract"（不够精确） |
| agency agreement | 依欧盟指令 86/653/EEC 委任商务代理人的合同 | "sales agency"；"representation agreement"（法律上不等同） |
| framework supply agreement | 按约定条款持续定期供应货物的合同；区别于单项供应合同 | "supply contract"（不够精确）；"periodic supply"（过于模糊） |
| purchase order | 载明数量、价格和交货条款的书面购货请求 | "order"（过于模糊） |
| order confirmation | 卖方对采购订单的书面接受与确认 | "order acceptance"（不够精确） |
| price list | 列明货物/服务标准销售价格的文件 | "price schedule"（通常有时间限制） |
| discount | 低于标准牌价的降价 | "rebate"（通常基于数量且追溯支付） |
| retail price | 货物销售给最终消费者的价格 | "consumer price"（不够精确）；"consumer price index"（不同概念） |
| wholesale price | 货物销售给经销商/零售商以供转售的价格 | "trade price"（不精确） |
| commercial margin | 进货价与销售价之间的利润差额 | "mark-up"（计算方式不同） |
| mark-up | 在成本价之上加成以确定销售价的金额 | "margin"（包含其他成本） |
| exclusivity / exclusive right | 在限定地域或客户细分中的独家经销/销售权 | "exclusive privilege"（过时） |
| territory | 经销/销售权利适用的地理区域 | "zone"（非正式） |
| territorial exclusivity | 在限定地理区域内经销/销售的独家权利 | "geographic exclusivity"（较不标准） |
| sales channel | 货物分销给消费者的途径（直销、零售、线上等） | "distribution route"（不够精确） |
| point of sale / retail outlet | 直接向消费者销售货物的实体场所 | "sales point"（非正式） |
| online sales / e-commerce | 通过互联网向消费者或企业销售货物 | "internet sales"（过于宽泛）；"online trade" |
| online marketplace / marketplace | 使多个第三方卖家能够向买家提供货物或服务的电子平台。"Online marketplace" 是欧盟法律用语（如指令 (EU) 2019/2161、《数字服务法》）；数字语境已明确时可单独使用 "marketplace"。 | 实体市场（不同——实体市场）；e-commerce platform（更窄——自营库存平台不是市场） |

## 特许经营特定术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| franchisor | 授予被特许人经营商业模式权利的个人或实体 | "franchise grantor"（较不标准） |
| franchisee | 获授经营特许经营业务权利的个人或实体 | "franchise holder"（非正式） |
| initial franchise fee / entry fee | 被特许人向特许人支付的特许经营权利前期款项 | "franchise fee"（有歧义）；"setup fee" |
| royalty | 被特许人向特许人定期持续支付的款项，通常基于销售额 | "license fee"（不够精确）；"franchise contribution" |
| advertising fee / marketing contribution | 被特许人为特许人集体广告/营销支付的款项 | "marketing fee"（不够精确） |
| operations manual | 载明特许经营运营程序、标准和指示的文件 | "operations handbook"；"operations guide" |
| know-how | 转移给被特许人的经营经验、方法和技术信息 | "expertise"（法律性较弱）；"technical knowledge" |
| trade mark / brand | 识别特许人业务的注册或未注册商标；许可给被特许人 | "brand name"（非正式）；"trading name" |
| business format | 特许经营业务据以运营的完整体系、方法和品牌 | "franchise system"（不够精确） |
| quality standards | 对产品/服务质量、呈现和客户服务的要求 | "quality control"（描述的是过程，而非标准） |
| centralized procurement | 特许经营体系为规模化采购货物的集中采购安排 | "central buying"（非正式） |
| pre-opening | 正式开业前被特许人筹备场所和接受培训的期间 | "pre-launch"（不够精确） |
| right of first refusal | 特许人或被特许人在第三方之前购买资产/权利的权利 | "pre-emption right"（英国术语，法律上等同） |
| non-compete clause / non-competition clause | 限制一方在合同期内和/或期后从事竞争业务的条款。英式和美式起草中 "non-compete" 与 "non-competition" 均可接受；"non-compete" 是现代较短形式。 | restrictive covenant（更宽泛的概念——涵盖禁止招揽、禁止挖角、保密） |
| change of control | 见 finance-banking.md 中的权威定义。特许经营/经销语境：通常要求特许人/供应商同意，并可能触发终止权。 | — |

## 经销与供应术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| distributor | 从供应商采购货物并转售给零售商或其他经销商的实体 | "distribution company"（不够精确） |
| commercial agent | 代表委托人洽谈买卖的独立中间人（欧盟指令 86/653/EEC） | "sales agent"；"representative"（在欧盟法律下不等同） |
| representative | 代表他人行事的人（通用术语；可能包括员工） | 未指明类型的 "agent"（有歧义） |
| dealer / concessionaire | 获授在限定地域销售特定品牌/产品独家权利的实体 | "dealership"（非正式）；"distributor"（更宽泛） |
| wholesaler | 批量采购货物以供转售给零售商的实体 | "wholesale distributor"（冗余） |
| retailer | 直接向最终消费者销售货物的实体 | "retail outlet"（描述场所，而非实体） |
| distribution chain / supply chain | 从制造商到最终消费者的一系列实体 | "chain of distribution"（较不标准） |
| product / goods | 受买卖、供应或经销约束的有形物品 | "merchandise"（非正式）；"commodities"（通常指原材料） |
| goods | 受合同约束的有形动产 | "products"（法律语境中不够精确）；"merchandise"（非正式） |
| sample | 为展示质量/性质而提供的货物样品 | "trial unit"（不够精确） |
| catalog (美式默认) / catalogue (英式) | 列出可用产品及描述/价格的印刷或数字文件 | "product list"（较不正式） |
| stock / inventory | 为销售或分销而存放在仓库或仓储中的货物 | "supplies"（不够精确） |
| minimum order quantity (MOQ) | 买方单笔订单必须采购的最低货物数量 | "minimum purchase"（不够精确） |
| minimum order | 构成有效采购订单的最低货物数量 | "minimum purchase order quantity"（冗余） |
| lead time / delivery time | 下单与收货之间的期间 | "delivery period"（不够精确）；"supply time" |
| shipment | 依单笔订单从供应商运输给买方的货物 | "delivery"（更宽泛）；"consignment"（特定类型的安排） |
| delivery terms / Incoterms | 指明运输期间哪一方承担成本和风险的规格（ICC Incoterms 标准） | "shipping terms"（不够精确）；"terms of delivery" |
| EXW (ex works) | Incoterm：买方在卖方场所接收货物；买方承担全部运输风险/成本 | "ex factory"（较不标准的缩写） |
| DAP (delivered at place) | Incoterm：卖方承担成本/风险直至货物交付至指定地点；买方安排卸货 | "delivered at point"（不精确）；"delivery at place" |
| freight collect | Incoterm 变体：买方支付运输费用（DDU——未完税交货） | "carriage forward"（英国术语，不够精确） |
| freight prepaid / carriage paid | Incoterm：卖方支付运输成本；买方承担运输途中风险 | "postage paid"（非正式） |
| lack of conformity / non-conformity | 货物不符合合同规格或质量标准（《消费品销售指令》2019/771/EU） | "defective goods"（不够精确）；"deviation from contract" |
| defect | 货物中降低价值或可用性的物理或功能瑕疵 | "fault"（非正式）；"imperfection"（技术性较低） |
| latent defect | 销售时经合理检查无法发现的隐藏缺陷 | "hidden defect"（法律性较弱）；"concealed fault" |
| apparent defect | 销售时可见且经合理检查可发现的缺陷 | "obvious defect"（不够精确）；"patent defect"（较不常见） |
| selective distribution | 供应商基于定性标准（如专业员工、场所标准）选择经销商的经销体系；受欧盟竞争规则（纵向集体豁免条例）约束 | Restricted distribution（不够精确） |
| minimum annual purchase obligation / minimum purchase commitment | 经销商每年采购最低数量/金额货物的义务；未达标可能触发终止 | Annual quota（非正式）；Minimum volume（不够精确） |
| goodwill indemnity / compensation on termination | 终止时因带给委托人的商誉/客户而依法向商务代理人支付的款项（欧盟指令 86/653/EEC 第 17 条）；代理人可选择赔偿或补偿模式 | Termination indemnity（不够精确）；Agency compensation（过于模糊） |
| notice of defects | 买方在法定时限内向卖方发出的不合格货物正式通知 | "defect notification"（较不正式）；"notice of non-conformity" |

## 消费者保护术语

| 正确英语术语 | 用法/含义 | 避免 |
|---|---|---|
| consumer | 出于贸易、商业或职业之外目的行事的自然人（欧盟《消费者权利指令》2011/83/EU） | "customer"（包括企业）；"buyer"（过于宽泛） |
| trader / professional | 以商业/职业身份行事的自然人或法人 | "supplier"（不够精确）；"seller"（非正式） |
| unfair term | 违反诚信原则、造成当事人权利重大失衡的合同条款（《不公平合同条款指令》93/13/EEC） | "unfair clause"（不够精确）；"unreasonable term"（标准不同） |
| unfair terms / abusive clauses | 符合不公平条款定义的多个合同条款 | "onerous clauses"（不同概念）；"burdensome terms"（主观） |
| right of withdrawal / cooling-off right | 消费者在法定期限内无需罚金取消远程/营业场所外合同的权利（欧盟《消费者权利指令》2011/83/EU） | "right of cancellation"（较不标准）；"rescission right"（不同概念） |
| cooling-off period | 消费者可以行使撤回权的法定期限（通常 14 天） | "reflection period"（不够精确）；"cancellation period"（较不标准） |
| statutory guarantee of conformity | 卖方保证货物符合合同且适合用途的法律义务（《消费品销售指令》2019/771/EU） | "warranty of title"（不同概念）；"merchantability guarantee"（不够精确） |
| commercial warranty | 交易者就货物作出的超出法定保证的自愿承诺 | "manufacturer's warranty"（通常两者兼具）；"express warranty"（更宽泛） |
| product liability | 制造商/供应商对缺陷产品造成人身伤害/损害的法律责任 | "product defect liability"（冗余） |
| defective product | 因制造/设计/说明缺陷造成伤害或损害的产品 | "faulty product"（非正式） |
| product recall | 制造商/卖方将缺陷产品撤出流通并提供救济的程序 | "product withdrawal"（不同的法律程序）；"market recall"（不够精确） |
| safety notice | 关于产品安全危害和推荐消费者行动的公告 | "product safety alert"（较不正式）；"recall notice" |
| unfair commercial practices | 违反诚实/公平交易标准、实质性扭曲消费者行为的商业行为（《不公平商业行为指令》2005/29/EC） | "misleading practices"（更窄）；"unfair competition"（不同概念） |
| misleading advertising | 含有影响消费者购买决策的虚假/欺骗性信息的商业传播 | "deceptive advertising"（不够精确）；"false claims"（非正式） |
| distance selling | 买卖双方无同时物理在场而订立合同的货物销售 | "distance sale"（非正式）；"remote sale" |
| distance contract | 交易者与消费者使用远程通信手段（电子邮件、电话、网站等）订立的合同 | "distance agreement"（消费者语境中较不标准） |
| off-premises contract | 在交易者营业场所之外（家中、街头等）订立的合同（欧盟《消费者权利指令》2011/83/EU） | "out-of-store contract"（较不标准）；"doorstep sale"（非正式） |
| pre-contractual information | 消费者在承诺远程/营业场所外合同之前必须收到的信息（合同条款、交易者身份、撤回权等） | "pre-contract disclosure"（不够精确）；"pre-sale information" |
| withdrawal form | 使消费者能够行使撤回权的标准表格（欧盟《消费者权利指令》2011/83/EU） | "cancellation form"（较不标准）；"notice of withdrawal"（可以是其他格式） |
| refund | 对已取消或未供应的货物/服务退还消费者支付的款项 | "reimbursement"（正式）；"money back"（非正式） |
| replacement | 以符合要求的货物替换不符合要求的货物提供给消费者 | "substitute goods"（不够精确） |
| repair | 将缺陷/不合格货物恢复到符合状态 | "fixing"（非正式）；"restoration"（更宽泛的概念） |
| warranty / guarantee | 卖方/制造商保证货物达到特定标准/性能的承诺 | "assurance"（法律性较弱） |
| merchantability / satisfactory quality | 货物质量达到普通用途可接受水平的法定保证（英国《消费者权利法》2015 年；satisfactory quality 为英国术语） | "fitness for purpose"（不同概念）；"acceptable quality"（不够精确） |
| fitness for purpose | 卖方保证货物适合已告知卖方的特定用途 | "suitability"（非正式）；"appropriateness"（法律性较弱） |
| consumer rights | 消费者的法定权利（撤回、保证、救济、安全等） | "consumer protections"（不够精确）；"consumer remedies"（更窄） |
| unfair contract terms | 在实质内容或谈判中不公平地使交易者优于消费者的合同条款（《不公平合同条款指令》93/13/EEC） | "unreasonable terms"（测试不同）；"oppressive terms"（不够精确） |

## 说明

- **"Commercial agent"（商务代理人）与其他角色**：依欧盟指令 86/653/EEC，"商务代理人"具有区别于代表、经销商或员工的特定法律地位。精确使用以保留关于通知期、佣金和法定义务的法律后果。

- **不公平合同条款（指令 93/13/EEC）**：这些条款按实质内容和谈判进行评估：造成重大失衡、违反诚信的条款。不要译为 "onerous" 或 "burdensome"——这些是主观的。远程销售参考欧盟《消费者权利指令》2011/83/EU。

- **消费者定义（指令 2011/83/EU）**：消费者是出于贸易/商业/职业之外目的行事的自然人。B2B 交易，即使与小企业，也不属于消费者保护范围，除非特别约定。翻译中保持这一区分。

- **Incoterms**：保留 ICC Incoterms 缩写（EXW、FCA、DAP、DDP 等）为英文——它们是国际标准化的。首次使用时加完整英语名称："EXW (ex works)"。

- **法定保证与商业保证（指令 2019/771/EU）**：法定符合性保证是强制性的；商业保证是交易者的自愿承诺。两者都可能适用；不要混同。

- **"Satisfactory quality"（英国）与 "merchantability"**：英国《消费者权利法》2015 年使用 "satisfactory quality"；较旧的判例法和美国法律使用 "merchantability"。英国语境优先 "satisfactory quality"。

- **产品召回**：区别于自愿市场撤出的正式程序。强制撤出或严重安全危害使用 "product recall"；自愿或自愿合规使用 "withdrawal"。

- **远程/营业场所外的区分**：远程合同 = 无同时在场订立的协议（线上、电话、邮件）。营业场所外 = 在营业场所之外订立（家中、街头）。两者均触发冷静期；不要混同。

- **国际指令**：欧盟指令用英语名称和编号引用（《不公平合同条款指令》93/13/EEC；《消费者权利指令》2011/83/EU；《消费品销售指令》2019/771/EU），而非逐字翻译国家立法引用。
