# 公共采购词典

公共采购的标准英文术语：招标、特许经营、PPP/PFI、国家援助、欧盟采购指令、公共合同及相关文件。

## 核心采购术语

| 规范英文术语 | 用法/含义 | 避免 |
|---|---|---|
| public contract / public procurement | 以订约当局（contracting authority）为买方的所有合同的通用术语。 | procurement（过于含糊） |
| works contract | 为执行建筑工程而提供劳动力和材料的合同。 | construction contract（不够精确） |
| service contract | 提供服务（services）的合同。 | services agreement（不够精确） |
| supply contract | 提供货物（goods）的合同。 | goods contract（不够精确） |
| concession | 将经营风险转移给特许经营人的协议；区别于采购合同。 | award agreement（过于含糊） |
| works concession | 工程基础设施建设和/或经营的特许经营。 | — |
| service concession | 服务供应和经营的特许经营。 | — |
| public-private partnership (PPP) | 公共机关与私营实体之间提供服务的结构性安排。英国：PFI（私人融资倡议）。 | partnership（不够精确） |
| project finance / PFI | 大型项目（尤其是 PPP）的融资结构。 | — |
| contracting authority | 负责委托公共合同的公共实体。 | purchasing authority（不够精确） |
| contracting entity | 公用事业或其他受《公用事业指令》约束的实体。 | contracting body（不够精确） |
| economic operator | 在招标中提供货物或服务的任何自然人或法人。 | market participant（不够精确） |
| tenderer / bidder | 响应招标提交报价的当事方。 | offeror（在采购语境中不够精确） |
| successful tenderer / contractor | 被授予合同的当事方。 | awardee（在采购之外含义模糊） |
| subcontractor | 由主承包商签约承担部分工作/服务的当事方。 | subcontracted party（不够精确） |
| temporary grouping / joint venture / consortium | 为参与招标而组成的经济经营者联合体。 | partnership（不够精确） |
| reliance on third-party resources | 经营者对另一实体技术、财务或专业能力的依赖（欧盟采购概念）。 | outsourcing capacity（不够精确） |
| permanent consortium | 长期性的经营者联合体；区别于临时性联合体。 | persistent partnership（含义模糊） |
| social value / social considerations | 作为评标标准或合同条件一部分的社会成果要求（就业、培训、环境可持续性）。 | Social impact（不够精确） |
| reserved contract | 为庇护工场、社会企业或雇用弱势人群的经营者保留的合同（欧盟第 2014/24/EU 号指令第 20 条）。 | Protected contract（不够标准） |

|---|---|---|
| procurement procedure / tender procedure | 合同授予方式的通用术语。 | — |
| open procedure | 对所有有兴趣的经济经营者开放的采购。 | — |
| restricted procedure | 仅对通过资格预审或被邀请的经营者开放的采购。 | — |
| negotiated procedure | 与选定经营者谈判条款的采购。 | — |

| contract award notice | 合同授予后发布的公告。 | award announcement（不够精确） |
| tender specifications / tender rules | 载明合同要求和条件的文件。 | bid rules; bid specifications（不够精确） |
| specifications | 货物或服务的技术和性能要求。 | specifications document（过于含糊） |
| special conditions / particular conditions | 适用于特定合同的特定合同条款。 | contract schedule（不够精确） |

| invitation to tender | 正式请求选定经营者提交投标书。 | request for proposal（不够精确） |
| tender / bid | 经济经营者响应采购公告提交的报价。 | offer（在采购语境中不够精确） |
| financial offer / price tender | 投标书的成本/价格部分。 | price proposal（不够精确） |
| technical offer / technical proposal | 投标书的技术和质量部分。 | technical submission（不够精确） |
| envelope | 投标文件的封装容器；常作隐喻使用。 | package; submission（不够精确） |
| opening of tenders | 开标和登记投标书的正式程序。 | bid opening（不够精确） |
| evaluation committee / tender board | 负责按评标标准评审投标书的委员会。 | procurement committee（不够精确） |
| award criterion | 选择中标者的依据。 | selection basis（不够精确） |
| most economically advantageous tender (MEAT) | 平衡价格与质量（或其他非价格因素）的评标标准。欧盟标准。 | best value（含义模糊） |
| lowest price | 选择成本最低的投标的评标标准。 | minimum cost（不够精确） |
| best price-quality ratio | 在成本与技术优势或其他因素之间权衡的评标标准。 | price-quality balance（不够精确） |
| abnormally low tender | 价格或成本大幅低于市场水平的投标，触发调查。 | unusually low bid（不够精确） |
| abnormality check / tender verification | 核实投标是否异常偏低的程序。 | price verification（不够精确） |
| award | 选定中标者的决定。 | selection decision（不够精确） |
| provisional award | 待停滞期或其他程序要求满足后的有条件授予。 | conditional award（不够精确） |
| final award / contract award | 所有停滞/审查期届满后确认的授予。 | binding award（不够精确） |
| execution of the contract | 合同的签署和开始。 | contract signature（不够精确） |

| procurement challenge / review proceedings | 落标者挑战采购决定的正式程序。 | legal challenge（不够精确） |
| framework agreement | 与一家或多家供应商达成的长期协议，约定在特定期间内以约定价格供应货物/服务；用于后续的单项订单。欧盟采购概念。 | — |
| dynamic purchasing system (DPS) | 采购常用、现成的货物和服务的电子系统；随时对新供应商开放。欧盟采购概念。 | — |
| Teckal exemption / in-house exception | 允许订约当局不经招标将合同授予其控制的实体的例外（须满足所有权+活动测试）；欧洲法院概念。 | in-house award; direct award（不够精确） |
| division into lots | 将合同划分为若干标段以便利中小企业参与（欧盟第 2014/24/EU 号指令第 46 条）；订约当局必须说明不划分的理由。 | Splitting of contract（非正式） |

| variant / alternative bid | 提供与规定不同技术方案的替代投标；必须由订约当局明确允许。 | Alternative offer（不够精确） |
| e-procurement / electronic procurement | 采购程序强制使用电子方式（提交、通信、发布）；自 2018 年起欧盟全面强制。 | Online procurement（非正式） |
| electronic submission | 通过电子平台提交投标书。 | Online submission（非正式）; Digital tender |

## 注释

- **欧盟与国内采购**：三部指令（2014/24、2014/25、2014/23/EU）设定了欧盟范围内采购规则的最低标准。国内法典往往规定更严格的要求或额外程序。始终识别管辖该交易的框架。

- **合同与特许经营**：公共合同将货物/服务转移给当局；特许经营将经营和/或财务风险转移给特许经营人。这一区别是欧盟所有采购框架的基础。

- **MEAT 与评标标准**：从"最低价"转向"最具经济效益的投标"反映现代采购对质量、可持续性和创新的偏好。始终明确适用哪种标准。

- **停滞期（Alcatel 期）**：授予公告后的 10 天强制等待期是关键的程序性保障。未遵守可使授予无效。

- **框架协议与动态采购系统**：这些是现代的欧盟采购工具，可实现灵活性和物有所值，尤其适用于重复采购标准货物和服务。

- **ESPD**：取代多份国家表格；在整个欧盟大幅标准化了资格证据，但国内解释可能有所不同。

- **国家援助与公共采购**：公共采购规则规范当局*如何*采购；国家援助规则规范支持*是否*符合市场要求。两者都可能适用。
