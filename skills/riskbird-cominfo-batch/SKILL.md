# 风鸟企业信息查询

通过风鸟（riskbird.com）批量查询全国企业联系方式、社保参保人数。
无需付费、无需API Key，利用CDP浏览器自动化操作已登录用户Chrome。

## 适用场景

需要批量查企业电话、邮箱、地址、社保人数，但不想花钱买企查查会员。
适用数据源：风鸟（riskbird.com）免费版，每日50次详情页额度。

## 前置条件

1. **用户的Chrome已打开风鸟网站**（任意页面即可）
2. CDP Proxy已运行（localhost:3456，系统自带）
3. 公司名单已准备为 JSON 格式，如 `/tmp/companies.json`

## 执行步骤

### 第一步：加载公司名单

确保名单文件为 JSON 数组格式：
```json
["企业名称1", "企业名称2", ...]
```

### 第二步：运行批量查询脚本

以下脚本会：
1. 获取用户Chrome中已打开的风鸟标签页
2. 搜索每个公司 → 从搜索结果页提取电话/邮箱/地址/法人/资本
3. 仅当需要社保人数时进入详情页（消耗额度）
4. 检测额度耗尽自动停止

使用方法：

1. 在公司名单 JSON 文件中写入要查询的企业
2. 打开风鸟网站（https://www.riskbird.com）
3. 调用本 Skill

### 第三步：检查结果

结果文件在 `/tmp/riskbird_results.json`

## 提取逻辑

### 搜索结果页提取（不消耗额度）

页面结构示例：
```
为您找到 N 条相关结果
企业全称             ← 企业名行
在营 / 正常           ← 状态行
法定代表人：张三      ← 以下逐行
注册资本：1000万元
成立日期：2020-01-01
统一社会信用代码：913...
电话：13800138000更多   ← 注意"更多"后缀
邮箱：xxx@yyy.com更多
官网：www.xxx.com
通信地址：XXX省XXX市...
```

### 详情页提取（消耗额度，仅用于社保）

搜索页没有社保人数，进入详情页后找"参保人数"字段。

### 额度耗尽检测

如果页面含"今日查询额度已用完"文本，立即停止并保存已查数据。

## 关键注意事项

1. **curl必须加 `--noproxy '*'`** — 用户系统有代理，否则超时
2. **JS中不要用 `//` 注释** — 用 `/* */` 替代，避免脚本自动压缩换行时被破坏
3. **搜索结果页优先** — 电话/邮箱/地址/法人/资本都能搜到，无需进详情页
4. **复用现有标签页** — 用 `/navigate` 而非 `/new`，避免标签页堆积
5. **断点续传** — 每查完一家立即保存到结果文件
