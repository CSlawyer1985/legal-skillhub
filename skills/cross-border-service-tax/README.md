# cross-border-service-tax

> **跨境服务贸易涉税业务操作指引 Skill** —— 协助律师/税务师完成中国跨境服务贸易涉税业务的尽调、协定审查、税款计算与申报备案

基于律协《律师办理跨境服务贸易涉税业务操作指引(2026)(试行)》提炼,聚焦中国大陆跨境服务贸易(咨询 / 技术服务 / 特许权使用费 / 租金 / 股息 / 利息等)。

---

## 这能做什么

回答这类问题:

- "我司向美国公司付 100 万美元咨询费,要代扣什么税?"
- "付香港公司特许权使用费,协定能优惠几个点?备案怎么办?"
- "新加坡公司派人来华调试设备 8 个月,有没有常设机构?"
- "公司被约谈说技术服务费定价偏高,怎么自查?"

产出结构化分析报告(含 PE 判断、协定待遇、税额测算、风险清单)。

## 核心判断链(贯穿全流程,不跳步)

```
居民身份认定 → 交易定性 → PE判断 → 协定适用 → 税种/税率 → 申报或代扣方式
```

**PE(常设机构)是锚点**:有 PE → 就 PE 归属利润按查账/核定 25% 征税;无 PE → 就来源于境内所得源泉扣缴(10% 或协定优惠)。两条路径的税种、税率、申报方式完全不同,必须先定 PE。

## 快速开始

```bash
# 1. 环境检查(Python 3 + PyYAML + python-docx)
bash scripts/setup.sh

# 2. 代扣税款测算(例:香港特许权使用费,净价 100 万,协定 7%)
python scripts/tax_calc.py wht.calc --income 1000000 --legal-rate 0.10 --treaty-rate 0.07 --net --apply-treaty

# 3. 协定税率查询(含持股条件、风险警示)
python scripts/tax_calc.py treaty.lookup --country 中国香港 --income-type dividend

# 4. 增值税归类
python scripts/tax_calc.py vat.classify --service-type 技术咨询 --consumption-location outbound

# 5. 协定表时效性检查
python scripts/tax_calc.py treaty.check
```

在 ZCode 中直接描述业务(如"我司向香港公司付特许权使用费,怎么代扣税"),Skill 会自动触发并引导 6 步工作流。

## 6 步工作流

| Step | 对应指引章节 | 目标 | 主要产出 |
|---|---|---|---|
| 1. 业务承接与利益冲突审查 | 第2章 | 确定委托范围、团队配置 | 委托范围确认书 |
| 2. 尽职调查 | 第3章 | 居民身份 / 交易实质 / **PE 判断** / 关联交易 | 尽调要素表 |
| 3. 税收协定待遇审查 | 第4章 | 协定适用、优惠税率、LOB/PPT 限制 | 协定待遇分析 |
| 4. 纳税申报与税收优惠备案 | 第5章 | 税种税率、**脚本算税**、备案流程 | 申报方案 + 税额测算 |
| 5. 合规与风险应对 | 第6章 | 自查、转让定价、CRS、稽查应对 | 风险清单 + 应对建议 |
| 6. 业务总结与归档 | 第7章 | 工作底稿、经验沉淀 | 归档文件 + 经验条目 |

## tax_calc.py —— 6 个确定性计算子命令

涉税金额计算**禁止口算**(涉及税费转嫁 net/gross、多税种叠加),一律调用脚本输出 JSON:

| 子命令 | 功能 |
|---|---|
| `wht.calc` | 代扣代缴企业所得税:法定 vs 协定税率对比,支持 net/gross 转换 |
| `vat.classify` | 增值税归类:零税率 / 免税 / 一般计税(精确匹配,防子串误判) |
| `vat.calc` | 增值税应纳税额(一般计税:销项 − 进项) |
| `treaty.lookup` | 协定税率查询(含持股条件、受益所有人/LOB/PPT 警示、时效标注) |
| `treaty.check` | 协定税率表时效性检查(超 12 个月未核实报警) |
| `ftc.calc` | 境外税收抵免(直接/间接/分国vs综合/饶让/境外亏损,5 种模式;政策口径部分待核实) |

## 质量保障

本 Skill 经过多轮验证:

- **crit 对抗性审查**:发现并修复了协定税率表事实性错误(港股息持股条件、德国利息 15%、印度特许权 10% 等)、`vat.classify` 子串误匹配等问题
- **真实案例验收**:通过国税总局官网公开案例验证(埃森哲爱尔兰特许权预提税案、印度外派员工 PE 判例、境外维修费劳务发生地案)
- **法条文号补全**:操作步骤均可回溯到具体法条/公告文号(企税法实施条例第7/41/91条、财税36号、2018年第9号、2019年第35号等)
- **税率表时效管理**:每条协定税率标注 `source` 与 `last_verified`,可定期用 `treaty.check` 检测过期

## 关键边界

- ⚠️ **定位**:律师办案的**首轮辅助筛查**,不替代税务师/律师专业判断,不构成正式税务意见
- ⚠️ **最终以主管税务机关认定为准**
- ⚠️ **法条/协定时效性**:增值税法 2026 施行,协定动态修订,引用前请核实现行有效文本
- ⚠️ **协定税率表为归纳参考,非权威** —— 以国家税务总局公布协定原文及议定书为准
- **不处理**:纯境内业务、关税与海关估价、纯个税居民个人综合事务
