# 参赛作品说明文档

## 跨境服务贸易涉税智能办案助手(cross-border-service-tax)

> 一个可运行、可验证、可持续进化的律师办案智能体。基于中华全国律协《律师办理跨境服务贸易涉税业务操作指引(2026)(试行)》构建,将 8 章 114 条指引转化为 AI 可执行的六步工作流。

- **作品仓库(可下载)**:https://atomgit.com/dc686868/cross-border-service-tax(公开,匿名可访问)
- **演示视频**:见提交材料(视频依据随附《Demo 演示视频脚本》录制,脚本中所有数字均为仓库脚本真实输出)
- **版本**:2026-08(v1 参赛版,commit 43f9932)

## 一、作品解决什么问题

跨境服务贸易涉税业务(向境外付汇、代扣代缴、协定待遇、常设机构认定等)是律师税务业务中**出错代价最高**的领域之一:

| 现实痛点 | 后果 |
|---|---|
| 判断链条长(居民身份→交易定性→常设机构→协定→税率→申报),环节互为前提 | 前环节没定就套协定税率,是实务中最典型的错误 |
| 税额计算涉及税费转嫁(net/gross)、抵免还原、超限结转等多步确定性运算 | 人工口算易漏——例如间接抵免的"超限结转额",本作品案例库中就有权威教学材料**漏算了该步骤** |
| 口径随协定修订、公告废止而变化 | 引用过期口径的风险长期存在 |
| 边界判例多(受益所有人被否定、混合合同重新定性、PE 天数累计) | 通用 AI 缺乏判例基准,回答不可验证 |

本作品的回答:**把指引变成强制工作流、把计算交给脚本、把判例变成回归测试集、把办案经验沉淀成可防污染的经验库**。

## 二、作品核心能力(六项)

### 1. 强制判断链,不跳步

核心方法论贯穿全部六步(业务承接→尽调→协定审查→申报备案→风险应对→归档):

```
居民身份认定 → 交易定性 → PE判断 → 协定适用 → 税种/税率 → 申报或代扣方式
```

其中 **PE(常设机构)是锚点**:有 PE 走归并申报(25% 查账/核定),无 PE 走源泉扣缴(10%/协定优惠)——两条路径税种、税率、申报方式完全不同。作品在工作流中强制先定 PE 再谈税率。

### 2. 确定性计算全部脚本化,禁止口算

`tax_calc.py` 提供 6 个子命令,输出 JSON(金额/公式/法条依据):

| 子命令 | 功能 | 防错点 |
|---|---|---|
| `wht.calc` | 代扣代缴企税 | net/gross 税费转嫁还原 |
| `vat.classify` / `vat.calc` | 增值税归类与计算 | 零税率与免税的进项处理差异 |
| `treaty.lookup` | 协定税率查询 | 条件性税率(股息持股门槛)、时效标注 |
| `treaty.check` | 协定表时效检查 | 超 12 个月未核实报警 |
| `ftc.calc` | 境外税收抵免(5 种模式) | **间接抵免超限结转、饶让差额补税**等人工高频漏点 |

真实输出示例(间接抵免,数据取自权威教学案例):

```
$ python scripts/tax_calc.py ftc.calc --type indirect \
    --dividend-gross 3000000 --foreign-corp-rate 0.30 --withholding-rate 0.10 --holding 0.50

归属税: 1285714.29 | 限额: 1071428.57 | 抵免: 1071428.57
★ 超限结转: 514285.71   ← 该教学材料原文漏算了此步骤,脚本强制输出
```

### 3. 经典案例回归测试集(23 案 + 15 教学模型)

`assets/经典案例库/` 收录 23 个**真实可核实**经典案例(CC01-CC23,含最高人民法院公报案例、山东省高院终审判决、国家税务总局官网案例库判例)与 15 个教学计算模型,按统一结构(事实要素表 / 判断链权威结论 / Skill 期望行为 / 指引挑战)结构化。

案例库不是展示品,而是**测试基准**:把"事实要素表"喂给智能体、隐去"判断链权威结论",比对输出——每次修改后可回归,防止退化。案例库与对抗性复查已驱动发现并登记 **14 项缺陷(V 编号 10 项 + I 级 4 项),其中 9 项已修复或处置**,修复历史完整记录于 `Skill_验收测试报告.md`(含"某次登记未落盘、按可复核口径重计"的诚实说明)。

### 4. 双循环经验库,越用越准且防污染

`references/experience/` 实现"复用+沉淀"双循环:办案权威读 `_index.yaml` 匹配场景经验;新发现写成带法条溯源的 YAML 经验,经 `exp_upsert.py` 校验入库。内置**四道防线**防"错误归纳→反复引用→升级"的正反馈污染:

- 高置信须 ≥2 个**独立**来源(同源多表述不算)
- 模型最高只能标 provisional,verified 须税务师/律师人工确认
- provisional 被引用 ≥3 次强制触发复核提示,并用案例库交叉验证
- 冲突检测:同场景不同结论须显式 `override_of` 标记口径变更

当前 13 条种子经验(PE/抵免/饶让/受益所有人/转让定价/重新定性等)。经对抗性复查(crit),3 条因来源实质独立度不足被**诚实降级**为 medium(6 high / 7 medium)——宁可自降等级,不虚标置信。

### 5. 边界意识,拒绝越界作答

智能体内置 scope 边界(聚焦中国大陆跨境服务贸易,不处理纯境内业务、海关估价、纯个税综合事务),并配备**边界拒绝测试案例**(如纯境内探矿权划转案):测试智能体能否识别超范围请求、说明理由并转介,而非强行套用跨境判断链乱答。

### 6. 工程化质量门

- `exp_lint.py`:经验库质量门(id 唯一性/置信↔来源匹配/过期复核),支持 `--strict`(CI 门禁)与 `--json`(机器可读)
- `postcheck.py`:报告交付前检查必要要素(税率/法条/免责声明)+ 引用纪律(引用经验须标注)
- `setup.sh`:环境自检,自动跑协定时效检查与经验库质量门
- `SECURITY.md`:安全考量与已知局限的完整披露

## 三、与现有工具相比的创新性(对应要求二)

| 对比维度 | 法律数据库(北大法宝/威科先行等) | 通用大模型直接问答 | 单一税务计算器 | **本作品** |
|---|---|---|---|---|
| 专业判断链引导 | ✗(只检索) | ✗(无强制流程) | ✗ | ✓ 六步强制不跳步,PE 锚点分路 |
| 税额计算 | ✗ | △(口算,多步易错) | ✓ | ✓ 确定性计算全部脚本化并带法条输出 |
| 判例可验证性 | △(有判例,无基准化) | ✗(不可验证) | ✗ | ✓ 23 案结构化为回归测试基准 |
| 经验积累 | ✗ | ✗(无记忆) | ✗ | ✓ 双循环经验库+四道防线防污染 |
| 边界意识 | — | ✗(常越界硬答) | — | ✓ 显式 scope+边界拒绝测试 |
| 时效风控 | △ | ✗ | ✗ | ✓ 协定表 12 个月时效报警+经验过期复核 |

**核心创新点**(按重要性):

1. **"指引→可执行工作流"的转化方法**:把行业操作指引(8 章 114 条)转译为 AI 强制工作流,而非自由问答——这一方法可复制到其他法律业务领域
2. **"法律判断与确定性计算分离"**:涉税金额一律脚本输出 JSON(金额/公式/法条),模型只做法律判断不改数字
3. **判例驱动的自进化闭环**:案例库发现缺陷(V 问题)→ 修复指引/脚本 → 案例回归验证 → 新口径沉淀入经验库 → 复用时引用计数 → 达阈值触发人工复核——完整闭环且全程留痕(14 项缺陷,9 项已修复/处置)
4. **对抗性自审机制**:作品自身经过系统性批判审查(crit),主动降级虚高的经验置信度、修复多处文档不一致——**结论是"校准过的可信",不是"表演性的完美"**

## 四、原创性说明(对应要求一)

- 判断链方法论、六步工作流、经验库 schema 与四道防线、全部 8 个脚本、案例结构化模板均为参赛者原创实现
- 案例库**内容**引自公开权威渠道(国家税务总局官网案例库/税路通、最高人民法院公报、省级法院裁判文书、上市公司公告、中国税务报),每案带 `sources` 字段标注来源与核实状态,符合引用规范;已去重的 2 个重复案例在文档中留有记录
- 部分政策口径(财税〔2017〕84 号等 5 项)因 2026-08 联网核实受限,在脚本输出(`verify_status` 字段)与 references 中**显著标注"待人工核实"**,不作虚假权威

## 五、保密处理说明(对应要求三)

经全面扫描确认,**本作品不含国家秘密,不含当事人保密信息**:

1. **无个人隐私**:无身份证号、手机号等个人信息;涉个人案例均已化名(富某/王先生/S先生)
2. **企业主体均为公开披露案件当事人**(挚文集团=上市公司公告、山东黄金=上市公司公告临2025-076、天齐锂业=年报披露、意迩瓦/张裕=裁判文书(2015)芝行初字第16号、淄博案=山东高院终审判决等),依据"公开裁判文书/上市公司公告当事人不脱敏"的行业惯例保留名称,便于评审核实
3. **无任何真实客户委托数据**:作品内置的示例报告使用虚构的 A/B 公司;SKILL.md 明确"不内置企业隐私数据,生成报告时对当事人信息脱敏"
4. 未公开来源的案例(教学模型 EX 系列)一律使用"某企业/A公司"脱敏表述

## 七、边界与局限(诚实披露)

1. 定位为律师办案的**首轮辅助筛查**,不替代税务师/律师专业判断,最终以主管税务机关认定为准(所有输出带免责声明)
2. 内置协定税率表为归纳参考,以国家税务总局公布原文为准;5 项政策口径待人工复核(已显著标注)
3. 13 条经验全部为 provisional(待专业人士复核后升级)——这是防污染设计的代价,也是诚实性的体现
4. 覆盖范围为中国大陆跨境服务贸易,不含关税/海关估价/纯个税综合事务
