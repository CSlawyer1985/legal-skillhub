## 分镜 1|核心方法论:强制判断链(50 秒)

**画面**:打开仓库 `SKILL.md`,滚动到"核心判断链"一节,停留在判断链代码块

**台词**:
> 作品的方法论核心,是这条贯穿全流程的判断链:居民身份认定、交易定性、常设机构判断、协定适用、税种税率、申报方式。**前一个环节没定,后一个环节就没有意义**——居民身份没定就套协定税率,是实务中最典型的错误。
> 其中常设机构是锚点:有 PE 走归并申报,按 25%;无 PE 走源泉扣缴,10% 或者协定优惠。两条路径完全不同,所以必须先定 PE 再谈税率。
> 这条链来自全国律协的操作指引,我们把 8 章 114 条,转译成了 AI 必须执行的六步工作流。

## 分镜 2|Demo 一:协定查询+代扣计算(60 秒)

**画面**:终端,依次输入两条命令

```bash
python scripts/tax_calc.py treaty.lookup --country 美国 --income-type royalty
python scripts/tax_calc.py wht.calc --income 1000000 --legal-rate 0.10 --gross
```

**预期真实输出**(录制时照常展示 JSON,旁白读关键值):
```
国家: 美国 | 协定税率: 10.0% | 节税: 0.0%
100万美元企税代扣: 100000.0 元
```

**台词**:
> 先看一个最常用的场景:境内公司要向美国支付一百万美元咨询服务费。
> 查协定——中美协定特许权和劳务都是 10%,没有优惠,系统会直接告诉你"节税为零",避免律师空跑备案。
> 再算代扣——注意,作品规定**所有涉税金额一律走脚本、禁止模型口算**。脚本输出的是 JSON:金额、公式、法条依据,模型只能引用,不能改数。为什么这么严格?下一个演示告诉你。

## 分镜 3|Demo 二:间接抵免的"易漏点"(70 秒)★重点

**画面**:终端输入:

```bash
python scripts/tax_calc.py ftc.calc --type indirect \
  --dividend-gross 3000000 --foreign-corp-rate 0.30 \
  --withholding-rate 0.10 --holding 0.50
```

**预期真实输出**:
```
归属税: 1285714.29 | 限额: 1071428.57 | 抵免: 1071428.57
★ 超限结转: 514285.71
```

**画面**:切到 `assets/经典案例库/教学模型与计算示例.md`,滚动到 EX-02 的"复算核对"部分

**台词**:
> 这个场景是:境内集团从境外子公司分得股息三百万,子公司税率 30%,回来做间接抵免。
> 间接抵免要先把下层公司的税"还原"出来:归属税 128 万,加上预提税,境外税合计超过限额——所以能抵的只有 107 万。
> **关键来了:超限的 51 万要结转**。这个数字,我们案例库里那份权威教学材料的原文恰恰漏算了——是作品做复算时发现、并补上的。
> 这就是"计算交给脚本"的价值:人工和通用大模型口算多步税务,漏一步没人知道;脚本每一步都强制输出。我们还给这个案例登记了缺陷编号 V13,永久留痕。

## 分镜 4|Demo 三:23 个真实判例构成的回归测试集(60 秒)

**画面**:打开 `assets/经典案例库/经典案例汇编.md`,快速滚动展示 CC01-CC23 标题;停在 CC15(意迩瓦案)的"税率修正"引用块

**台词**:
> 法律智能体最被质疑的问题:你怎么知道它答得对?
> 我们的回答是**用真实判例当测试基准**。案例库收录 23 个可核实的经典案例:最高人民法院公报的间接转让案、山东省高院终审的受益所有人案、国家税务总局官网案例库的境外判例,每个都结构化成"事实要素表+判断链权威结论"。
> 测试时把事实喂给智能体、把结论藏起来,比对输出——改了代码随时回归。
> 顺便说个细节:这个 2015 年的吸收合并案,原始材料的结论写的是"按 25% 征收",但我们复算发现补税额精确等于计税基础乘以 10%——**结论文字和自己的金额打架**。按金额修正为源泉扣缴 10%,修正过程完整记录在案。案例库不只是资产,也是质检器。

## 分镜 6|持续进化:经验库与质量门(60 秒)

**画面**:终端跑两条命令:

```bash
python scripts/exp_lint.py
bash scripts/setup.sh
```

**预期真实输出**(节选):
```
检查 13 条经验
⚠️ [ftc-sparing-not-exempt] provisional 经验被引用 3 次,未复核——建议强制复核
结果: ⚠️ 1 个 warning(非阻断)

✅ treaty.check: 协定税率表 0 个月前核实,状态 fresh(13 国)
⚠️ exp_lint: ... 1 个 warning(需复核)
```

**台词**:
> 最后是让它越用越准的机制:经验库双循环。办案权威匹配历史经验,新发现写成带法条溯源的条目入库。
> 防污染有四道防线:高置信必须两个以上**独立**来源;模型最高只能标"待验证";被引用满三次强制触发复核;结论冲突必须显式登记。
> 看这个 warning——一条饶让抵免的经验被引用了三次,系统主动报警要求人工复核。而且我们对标榜 high 的经验做过对抗性复查,**主动把三条来源成色不足的降成了 medium**。宁可自降等级,不虚标置信。
> 这套质量门已经接进环境自检,未来一行命令接入 CI。
