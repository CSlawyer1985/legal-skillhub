# 设计说明 — cross-border-service-tax Skill

## 一、设计目标

将律协《律师办理跨境服务贸易涉税业务操作指引(2026)(试行)》(8章114条)提炼为**全功能型** ZCode Skill,协助律师/税务师完成跨境服务贸易涉税业务的尽调、协定审查、税额计算、申报备案与合规应对。

## 二、设计灵魂:核心判断链

```
居民身份认定 → 交易定性 → PE判断 → 协定适用 → 税种/税率 → 申报或代扣方式
```

这条链贯穿指引第3-5章,是跨境服务贸易涉税的方法论核心。Skill 的 6 步工作流严格映射这条链,**强制不跳步**——前环节不定则后环节无意义(如居民身份没定就套协定税率是典型错误)。

**PE 是锚点**:有 PE(常设机构)→ 归并申报查账/核定(25%);无 PE → 源泉扣缴(10%/协定)。两条路径的税种、税率、申报方式完全不同。

| 级别 | 触发 | 加载 |
|---|---|---|
| **Light** | 查协定税率、单一税额、增值税归类 | 仅 SKILL.md + tax_calc.py |

## 五、确定性计算(tax_calc.py)

涉税金额计算**禁止口算**(涉及税费转嫁 net/gross、多税种叠加)。脚本 6 个子命令:
- `wht.calc` — 代扣企税(支持 net/gross、法定vs协定对比)
- `vat.classify` — 增值税归类(零税率/免税/一般计税)
- `vat.calc` — 增值税应纳税额(销项-进项)
- `treaty.lookup` — 协定税率查询(内置常见协定,非权威)
- `treaty.check` — 协定税率表时效性检查
- `ftc.calc` — 境外税收抵免(直接/间接/分国vs综合/饶让/境外亏损,5 种模式;2026-08 V12 补全,政策口径部分待核实)

输出 JSON,退出码语义化(0/1/2/3/4)。

## 六、经验库(双循环学习)

复用 labor-dispute-case-search 的成熟架构:
- **复用循环**:分析前先查经验库,引用带 sources,provisional 须标注
- **沉淀循环**:有新发现才入库,status 分级(draft→provisional→verified),模型不得自封 verified
- **防污染**:provisional 累计被引用≥3次提示强制复核,避免正反馈放大错误
- **外部校验锚**:经验库是模型归纳,有"错误归纳→误导分析→生成同向证据→升级"的正反馈污染风险。`assets/经典案例库/`(真实公开判例)作为**外部权威校验源**,用于复核 provisional 经验——案例结论与经验一致方可升级,反驳则触发重写。形成"归纳(经验库)↔ 校验(经典案例库)"的双轨制衡

## 六-2、经典案例库(回归测试与矫正,2026-08 新增)

**设计动机**:口语化测试用例(`assets/测试用例.md` TC1–TC4)只测"正常路径";跨境涉税的真正风险在**边界判例**(受益所有人被否定、混合合同重新定性、PE 天数累计、双重居民加比规则)。2026-08-04 首轮验收(`Skill_验收测试报告.md`)用 3 个真实案例就揪出 4 个实质问题(V1–V4),证明这条路径有效。案例库把该做法系统化。

**架构**:
- `assets/经典案例库/README.md` — 覆盖矩阵(判断链×案例)+ 索引 + 使用方法(回归测试/经验复核/盲区发现三步)
- `assets/经典案例库/经典案例汇编.md` — 13 案(CC01–CC13)+ 2 备选,按模板结构化(来源/案情/事实要素表/判断链权威结论/争议点/Skill期望行为/指引挑战/经验线索)
- `assets/经典案例库/案例模板.md` — 新增案例的填写模板

**覆盖盲区**(TC1–TC4 完全未碰的高危区):
- 反协定滥用:受益所有人(CC01/CC02/CC-B1)、LOB(CC03)、PPT(CC02)
- 居民身份:双重居民加比规则(CC04)、实际管理机构(CC05)
- 交易定性:混合合同分劈(CC06)、嵌入式特许权(CC07)、利息vs股息(CC09)、间接转让重新定性(CC10)
- PE 边界:代理人型 commissionaire(CC11)、派遣员工归属测试/disposal test(CC12,关联 V2/V4)、劳务型天数累计滚动(CC13)

**与三个体系的闭环**:
- → `Skill_验收测试报告.md`:案例的 `challenge_to_guidance` 记入"问题项"表(V1–V11),修复后回归
- → `references/experience/`:案例的 `scenario_key` 与经验库 key 对齐,做复核交叉验证
- → 指引修订:每个案例定位到 `references/` 具体文件的小节,指导精准补全

**权威性约定**:国税总局官网"海外税收案例库/税路通"收录的境外判例,代表中国税务机关参考口径;最高人民法院公报案例为最高权威;自媒体案例须人工核实后才转正。

## 七、与 labor-dispute-case-search 的异同

| 维度 | labor-dispute | cross-border-service-tax |
|---|---|---|
| 领域 | 劳动争议类案检索 | 跨境服务贸易涉税 |
| 核心计算 | 赔偿金(N/2N/二倍工资) | 代扣税款(企税+增值税) |
| 锚点概念 | 请求权基础 | **PE(常设机构)** |
| 判断链 | 要素→请求权→检索→规则→测算 | 居民身份→定性→PE→协定→税率→申报 |
| 经验库 | 裁判规则 | 协定口径/PE场景/定性方法 |

## 八、免责与边界

- 定位为律师办案**首轮辅助筛查**,不替代税务师/律师专业判断
- 最终以主管税务机关认定为准
- 法条/协定时效性:增值税法2026施行,协定动态修订,引用前核实
- 协定税率表为归纳参考,**以国家税务总局原文为准**
