整理这批案例时发现两个必须修复的问题,已登记到 `Skill_验收测试报告.md` 问题项:

### V12(新)— `tax_calc.py` 缺 `ftc.calc` 境外税收抵免命令

SKILL.md Key Principles 第 5 条:"凡涉税额计算一律用 `scripts/tax_calc.py`,不口算"。但境外税收抵免是**确定性计算**(直接/间接抵免、分国不分项、饶让、超限结转),`tax_calc.py` 现有子命令(`wht.calc`/`vat.calc`/`treaty.lookup`)**完全不覆盖抵免**。本文件 7 个案例的 `script_expected` 全部是"待脚本开发",证明这是个真实的功能缺口。

**修复建议**:新增 `ftc.calc` 子命令,支持:
- `--type direct|indirect`(直接/间接抵免)
- `--method per-country|aggregate`(分国/综合)
- `--foreign-income/--foreign-tax-paid/--sparing-rate`(饶让视同税率)
- 输出:抵免额、超限结转额、境内补税额

### V13(新)— 源数据不完整风险(逐案标注)

复算发现 2 个案例源数据表述不完整,已在各案例"复算核对"小节标注:
- **案例 34**(饶让):源数据只说"视同已缴 400 万可抵免",**漏说差额 100 万需境内补税**
- **案例 31**(间接抵免):源数据只说"不需再补税",**漏说超限 51.43 万需结转**

这提示:教学模型也须复算,不能直接采信。

## EX-01 — G 集团受控外国企业(CFC)利润堆积案

> **scenario_key**: `cfc-profit-hoarding` · **chain_dimension**: 风险应对-CFC · **来源**: 无(教学模型)

### 事实
境内 G 集团在低税地(实际税负<12.5%)设立全资子公司从事投资管理,收入为股息、利息等消极所得,多年堆积利润不分配。

### 判定要点(回归基准)
| 要件 | 满足情况 | 依据 |
|---|---|---|
| 1. 控制(持股/实际控制) | ✅ 全资 | 企业所得税法第 45 条 |
| 2. 实际税负<12.5% | ✅ | 实施条例第 118 条 |
| 3. 主要收入为消极所得 | ✅ 股息/利息 | 国税发〔2009〕82 号 |
| 4. 利润不合理堆积不分配 | ✅ | |
| **结论** | 视同已分配股息计入 G 公司当期收入征税 | 企业所得税法第 45 条 |

### Skill 期望行为
- Step 5 须识别 CFC 红旗:低税地 + 消极所得 + 不分配
- 触发四要件测试,满足则提示视同分配征税

## EX-02 — 王氏集团境外股息直接抵免 vs 间接抵免案

> **scenario_key**: `foreign-tax-credit-indirect` · **chain_dimension**: 风险应对-境外税收抵免(直接/间接) · **来源**: 无(教学模型)

### 事实
王氏集团持有境外 A 公司 50% 股权。A 公司应纳税所得额 1000 万(税率 30%),税后 700 万,分配 600 万,王氏分得 300 万(扣缴 10% 预提税后实收 270 万)。

### 复算核对(⚠️ 源数据不完整,已补全)

**直接抵免**(只抵预提税):
| 项目 | 金额 | 说明 |
|---|---|---|
| 毛股息 | 300 | |
| 中国抵免限额 | 75 | 300 × 25% |
| 实缴预提税 | 30 | |
| 抵免 | 30 | |
| **境内补税** | **45** | 75 - 30 ✅ 与源数据一致 |

**间接抵免**(还原下层归属税):
| 项目 | 金额(万) | 计算 |
|---|---|---|
| 还原税前利润 | 428.57 | 300 ÷ (1-30%) |
| 间接归属 A 公司所得税 | 128.57 | 428.57 × 30% |
| 预提税 | 30 | |
| 境外税合计 | 158.57 | 128.57 + 30 |
| 还原后境内应税所得 | 428.57 | 300 + 128.57 |
| 中国抵免限额 | 107.14 | 428.57 × 25% |
| **抵免** | **107.14** | 取小值 |
| **超限结转** | **51.43** | 158.57 - 107.14 ⚠️ **源数据漏说** |
| 境内补税 | 0 | 境外税合计>限额,不补 |

> ⚠️ **源数据不完整(V13)**:源数据只说"间接抵免不需再补税",**漏说超限 51.43 万需结转**。本文件已补全。

### Skill 期望行为
- 须区分直接抵免(只抵预提)与间接抵免(还原下层税),给出两种结果对比
- 间接抵免须计算还原税前利润、间接归属税、超限结转额
- **必须用脚本**(V12 修复后):禁止口算这种多步还原

### script_expected
```bash
# 待脚本开发(V12)
python scripts/tax_calc.py ftc.calc \
  --type indirect \
  --dividend-gross 3000000 \
  --holding 0.50 \
  --foreign-corp-rate 0.30 \
  --withholding-rate 0.10 \
  --china-rate 0.25
# expected: { imputed_tax: 128.57万, total_foreign: 158.57万, limit: 107.14万, credit: 107.14万, carryforward: 51.43万, domestic_supplement: 0 }
```

## EX-03 — A 公司甲乙两国子公司分国 vs 综合抵免案

> **scenario_key**: `foreign-tax-credit-split` · **chain_dimension**: 风险应对-境外税收抵免(分国 vs 综合) · **来源**: 无(教学模型)

### 事实
境内居民 A 公司:甲国子公司所得 100 万(税率 10%),乙国子公司所得 200 万(税率 35%),税后利润分配回 A 公司。

### 复算核对(✅ 源数据自洽)

**分国不分项**:
| 国家 | 所得 | 实缴税 | 限额(25%) | 抵免 | 结果 |
|---|---|---|---|---|---|
| 甲国 | 100 | 10 | 25 | 10 | 差额 15 境内补税 |
| 乙国 | 200 | 70 | 50 | 50 | 超限 20 结转 |
| 合计 | 300 | 80 | 75 | 60 | 境内补 15 + 结转 20 |

**综合(不分国不分项)**:
| 项目 | 金额 |
|---|---|
| 合并所得 | 300 |
| 综合限额 | 75(300×25%) |
| 实缴合计 | 80 |
| 抵免 | 75 |
| 超限结转 | 5 |

> ✅ 与源数据一致(甲抵免限额 25 全抵;乙限额 50 抵 50 结转 20;综合限额 75 抵 75 结转 5)。

### Skill 期望行为
- 须计算两种方法对比,选对企业有利的方法(本案综合法结转更少但甲国差额补税更大,需权衡)
- 提示:2017 年起居民企业可选择"不分国不分项"或"分国不分项",一经选择 5 年不变

### script_expected
```bash
# 待脚本开发(V12)
python scripts/tax_calc.py ftc.calc --type compare \
  --countries "甲:1000000:0.10, 乙:2000000:0.35" \
  --china-rate 0.25
# expected: { per_country: {甲:{...},乙:{...}}, aggregate: {...}, recommendation: ... }
```

## EX-06 — 境外分支机构亏损弥补案

> **scenario_key**: `overseas-loss-carryforward` · **chain_dimension**: 风险应对-境外亏损弥补 · **来源**: 无(教学模型)

### 事实
中国居民 A 企业:境内所得 300 万,甲国分支机构所得 100 万,乙国分支机构亏损 300 万,乙国利息所得 60 万。

### 复算核对(✅ 源数据自洽)
| 项目 | 金额(万) | 处理 |
|---|---|---|
| 乙国净亏 | -240 | 60(利息)弥补 300(亏损)后仍亏 240 |
| 乙国未弥补亏损 | 240 | **不得用境内或甲国盈利抵减**,无限期结转(限乙国未来盈利) |
| 境内应税所得 | 400 | 境内 300 + 甲国 100(乙国负数不计入) |

**依据**:企业所得税法第 17 条;财税〔2009〕125 号(境外亏损分国弥补,不得抵减境内或他国盈利)。

### Skill 期望行为
- 须强调:境外亏损分国弥补,不得抵减境内或他国盈利(常见误区)
- 非实际亏损部分(资产未处置实现的账面亏损)无限期结转,实际亏损有 10 年限制

## EX-08 — 关联交易超额特许权使用费扣缴案 ⚠️ 计算口径待核实

> **scenario_key**: `royalty-excess-fair-price-related-party-withholding` · **chain_dimension**: 交易定性-嵌入式特许权 + 协定适用-受益所有人 · **来源**: 无(学术教材模型)

### 事实
境内居民公司向境外关联公司(协定受益所有人)支付专利许可费 200 万元 + 专利指导服务费 50 万元。专利许可费公允价 100 万元,超额 150 万属关联交易超额支付。协定限制税率 5%(公允价部分),国内法 10%。

### ⚠️ 计算口径存疑(核心警示)

原教材模型给出的结论:`代扣企税 = 100万×5% + 150万×10% = 20万元`(公允价享协定、超额部分按国内法 10%)。

**但这个口径我没有把握,需人工核实**。标准实务做法通常是:
- **方案A(教材口径,存疑)**:公允价 100 万享协定 5%,超额 150 万按国内法 10% 分段计征
- **方案B(转让定价调整口径,更常见)**:超额 150 万不予税前扣除(或视同股息/赠与分配),而非"按国内法 10% 代扣"
- **方案C(全额协定口径)**:若受益所有人认定通过,全额 250 万享协定 5%(但关联交易超额本身可能触发转让定价调整)

三种口径结果不同(方案A=20万,方案C=12.5万,方案B涉及不允许扣除),**教材模型的"拆分计征"口径未经真实案例验证**。

### 指导服务费的定性(较明确)
专利许可配套的"指导服务费"50 万元,按国税发〔2010〕75 号第 12 条,若与专有技术许可不可分,应**并入特许权使用费**(不单列技术服务费)。这部分口径相对明确。

### Skill 期望行为(谨慎)
- Step 2 须识别混合合同(许可+服务),判断服务费是否并入特许权
- Step 3 受益所有人审查通过后,关联交易超额部分**须提示"可能触发转让定价调整",不应简单按教材口径算**
- ⚠️ **本案例不当回归基准**,仅作教学:测试 Skill 能否识别"关联交易超额 + 协定优惠"的交互,以及能否对存疑口径主动提示"待核实"

### script_expected
- ⚠️ 不提供脚本期望输出(口径未定)。`wht.calc` 只能按单一税率算,无法直接表达"公允价×5% + 超额×10%"的拆分;若需复算教材结论,需手动两次调用:
  ```bash
  python scripts/tax_calc.py wht.calc --income 1000000 --legal-rate 0.10 --treaty-rate 0.05 --gross --apply-treaty
  python scripts/tax_calc.py wht.calc --income 1500000 --legal-rate 0.10 --gross
  # 教材合计 = 5万 + 15万 = 20万(但此口径待核实)
  ```

### 转正条件
- 找到真实案例/官方解读证实"公允价享协定、超额按国内法 10%"的拆分计征口径
- 或确认实际是转让定价调整路径(则重写本案定性)
