### CC01 — 挚文集团(陌陌)香港导管公司受益所有人被否定案 {#cc01}

> **判断链维度**: 协定适用 — 受益所有人  ·  **scenario_key**: `bo-red-chip-shell`
> **来源核实时点**: 2026-08-07

#### 一、来源与权威性
| 字段 | 内容 |
|---|---|
| 来源 URL | https://news.sohu.com/a/1053215939_120875566 (搜狐);https://baijiahao.baidu.com/s?id=1871211152491462447 (百家号)互证 |
| 来源类型 | 专业媒体/新闻通讯社转载(央广网、人民网系) |
| 披露日期 | 2026-07-22 |

| 权威等级 | ★★★(媒体,但系公开上市公司的法定披露事项) |

#### 二、案情摘要
挚文集团(NASDAQ:MOMO)采用经典红筹架构"开曼上市主体→香港控股公司→北京运营实体"。税务机关核查认定香港中间控股公司为典型空壳导管:无固定办公场地、无全职员工、不开展投融资管理决策、分红资金到账后短期内划转至开曼母公司、不承担经营与投资风险。依《国家税务总局公告 2018 年第 9 号》否定受益所有人身份,不得适用《内地-香港税收安排》5% 股息优惠税率,改按 10% 法定税率。补税合计 **5.479 亿元**(已分配股息补税 3.561 亿 + 待分配利润计提预提税准备金 1.918 亿)。

#### 三、事实要素表
| 要素 | 事实 |
|---|---|
| 居民身份 | 香港中间控股公司(主张香港税收居民) |
| 交易定性 | 跨境股息分配(《内地-香港安排》股息条款) |
| PE 有无 | 不涉及(被动所得) |
| 关联交易 | 开曼←香港←北京三层红筹架构 |
| 单证 | 无办公场地、无员工、资金快速转出记录、无投资决策记录 |
| 其他 | 持股≥25% 满足 5% 优惠税率的形式要件 |

#### 四、判断链权威结论(回归基准)
| 步骤 | 结论 | 依据 |
|---|---|---|
| 居民身份 | 形式上为香港公司 | 形式合规仅是门槛 |
| 协定适用前提 | 持股≥25%,满足 5% 税率形式要件 | 内地-香港安排股息条款 |
| **受益所有人** | **不符合** — 9 号公告不利因素全命中:无场地/无员工/无实质业务/资金收到即转出/不担风险 | 国家税务总局公告 2018 年第 9 号 |
| 协定优惠 | 不适用 5% → 改按 10% | 国内法法定税率 |
| 税率 | 5% → 10% | |
| 申报方式 | 溯源补税 + 待分配利润计提预提税准备金 | |

#### 五、核心争议点
近年最具标志性的中概股红筹架构受益所有人否定案。体现"形式合规但无商业实质"的中国执法口径,以及"已分配补缴 + 未分配计提"双重处置的征管实践。

#### 六、Skill 期望行为
- **判断链完整性**: 居民身份→股息定性→受益所有人实质审查→税率→申报,完整不跳步
- **关键判断**: 在 Step 3 必须主动触发受益所有人审查,逐项核对 9 号公告不利因素清单;形式持股比例达标 ≠ 可享优惠
- **应当显著提示**: 9 号公告全部不利因素命中是**红旗**;红筹/VIE 架构是受益所有人被否定的系统性高风险场景
- **税额测算**: `wht.calc --income <股息基数> --legal-rate 0.10 --treaty-rate 0.05 --gross`,对比 5% vs 10% 差额

#### 七、对指引的潜在挑战 / 关联问题
- **关联问题**: 无(现行 V1–V4 未涉及),但暴露**新问题 V5 候选**:9 号公告"资金收到即转出"的时间阈值(12 个月内 50% vs 本案"短期内")需明确
- **指引挑战**: `references/风险与合规要点.md` 应补充红筹/VIE 架构专项风险清单;`references/税收协定待遇审查指引.md` 受益所有人小节应补充"待分配利润计提预提税准备金"这一处置手段

#### 八、经验沉淀线索
- **scenario_key**: `bo-red-chip-shell`
- **可沉淀口径**: 红筹架构香港导管公司,9 号公告不利因素全命中即否定受益所有人,5%→10% 并追溯补缴
- **sources**: 国家税务总局公告 2018 年第 9 号;《内地与香港税收安排》股息条款

> **判断链维度**: 协定适用 — 受益所有人 + PPT  ·  **scenario_key**: `bo-and-ppt-stacked`
> **来源核实时点**: 2026-08-07

#### 一、来源与权威性
| 字段 | 内容 |
|---|---|
| 来源 URL | https://www.chinatax.gov.cn/chinatax/c102448/c5248452/content.html |
| 来源类型 | 国税总局官网"海外税收案例库" |
| 披露日期 | 国税总局收录披露 |
| 核实状态 | ✅ 正文已核实 |
| 权威等级 | ★★★★★(国税总局官网案例库,代表中国税务机关参考口径) |

#### 二、案情摘要
塞浦路斯 A 公司(毛里求斯母公司全资子公司,主营股票债券投资)2014-15 财年从印度关联公司 B 取得利息 130,225,834 印度卢比,依《印度-塞浦路斯税收协定》第 11 条按 10% 优惠税率申报预提税。印度税务局以其缺乏实质经营为由否定受益所有人身份,A 公司上诉至 ITAT 德里分庭,法庭支持税务局,改按 20% 法定税率征税。

#### 三、事实要素表
| 要素 | 事实 |
|---|---|
| 居民身份 | 塞浦路斯 A 公司,持塞浦路斯税务局出具的税收居民身份证明 |
| 交易定性 | 跨国关联方利息(协定第 11 条) |
| PE 有无 | 不涉及(被动所得) |
| 关联交易 | A 的唯一投资即印度 B 公司;股东为毛里求斯母公司 |
| 单证 | **缺**:股东协议、投资详情、员工构成、董事居住地证明 |
| 其他 | A 公司曾**自认"股东才是受益所有人"** |

#### 四、判断链权威结论(回归基准)
| 步骤 | 结论 | 依据 |
|---|---|---|
| 居民身份 | 形式合规(持居民证明),但仅为门槛 | 协定第 4 条 |
| 实质审查 | 仅做过一项投资 → 无实质经营活动 | |
| **受益所有人** | **不符合** — 不拥有支配/收益权与风险承担;且自认股东为受益所有人 | 印度国内法 + 协定第 11 条议定 |
| **PPT(主要目的测试)** | **触发** — 法庭认定设立主要目的在利用协定优惠 | MLI PPT 条款 |
| 税率 | 10%(协定)→ 20%(印度《1961 年所得税法》115A 条法定) | |
| 申报方式 | 溯源补征预提税 | |

#### 五、核心争议点
少有的"BO 否定 + PPT"两步串联适用案例。争议焦点:① 持有对方税务当局居民身份证明是否就一定能享协定待遇(答案:否);② 纳税人自认陈述的证据权重;③ 既往年度享受优惠能否形成"延续性预期"。

#### 六、Skill 期望行为
- **判断链完整性**: 居民身份→利息定性→受益所有人→**PPT**→税率,必须两道反滥用都走
- **关键判断**: 在 Step 3 同时检查受益所有人(实质)与 PPT(目的),不能只查其一
- **应当显著提示**: "持居民身份证明"仅是门槛;无实质经营 + 唯一投资 + 自认股东为受益所有人 = PPT 红旗
- **税额测算**: `wht.calc --income 130225834 --legal-rate 0.20 --treaty-rate 0.10`,节税额为负(被否定)

#### 七、对指引的潜在挑战 / 关联问题
- **关联问题**: V1 候选延伸 — 协定表应标注哪些协定含 PPT 条款(MLI 引入)
- **指引挑战**: `references/税收协定待遇审查指引.md` 受益所有人与 PPT 的**适用先后顺序、举证转移规则**未明确;纳税人自认陈述的权重口径缺失

#### 八、经验沉淀线索
- **scenario_key**: `bo-and-ppt-stacked`
- **可沉淀口径**: 受益所有人被否定后,可再叠加 PPT 双重拒绝优惠;居民身份证明不等于最终居民身份
- **sources**: 印度-塞浦路斯协定第 11 条;MLI PPT 条款;国税总局海外税收案例库

### CC03 — 美国-卢森堡 LOB 商业实质测试案 {#cc03}

> **判断链维度**: 协定适用 — LOB(利益限制)  ·  **scenario_key**: `lob-commercial-substance`
> **来源核实时点**: 2026-08-07

#### 一、来源与权威性
| 字段 | 内容 |
|---|---|
| 来源 URL | https://www.sc.gov.cn/10462/10778/10876/2024/4/30/3640e46e7f9644e688a79c415a6365ae.shtml |
| 来源类型 | 省级政府转载国税总局"税路通·安企心"海外税收案例库④ |
| 披露日期 | 2024-04-30 |
| 核实状态 | ✅ 正文已核实 |
| 权威等级 | ★★★★(省级政府转载国税总局案例库) |

#### 二、案情摘要
2020 年,X 国 A 公司在卢森堡设立全资控股平台 B 公司,将商标授权给 B,B 再转授权给美国 C 公司(B 的控股子公司)并收取特许权使用费。C 公司自行依《美国-卢森堡税收协定》享受 0% 免税。美国税务机关核查认为 B 缺乏积极商业实质、A 以避税为主要目的设立 B,要求 C 代扣代缴。**结果分年度相反**:2020 年度(首位商标管理人员 11 月才入职、缺转让定价文档)认定无商业实质,补税及利息约人民币 450 万元;2021 年度(资料完整、清晰反映功能风险)未要求补税。B 公司未上诉。

#### 三、事实要素表
| 要素 | 事实 |
|---|---|
| 居民身份 | 卢森堡 B 公司(主张卢森堡居民) |
| 交易定性 | 跨境特许权使用费(协定第 12 条类) |
| PE 有无 | 不涉及 |
| 关联交易 | A→B→C 商标转授权链条;C 为 B 控股子公司 |
| 单证 | 2020 年缺人员/缺转让定价文档;2021 年资料完整 |
| 其他 | 比例测试:相关资产/收入/薪金各占 7.5% 以上,三项均值达 10% |

#### 四、判断链权威结论(回归基准)
| 步骤 | 结论 | 依据 |
|---|---|---|
| 居民身份 | 卢森堡 B 公司 | |
| **LOB 客观测试**(比例) | 通过 — 资产/收入/薪金比例达标(均值 10%>7.5%) | 美卢协定第 24 条 |
| **LOB 主观测试**(积极商业行为) | **2020 年不通过**(无配置常驻资深人员);**2021 年通过**(资料完整反映功能风险) | |
| 商业实质 | 2020 年否(导管)→ 10% 代扣;2021 年是 → 0% 免税 | |
| 税率 | 0%(协定免税)vs 10%(美国-X 国协定税率) | |
| 申报方式 | C 公司代扣代缴(2020);免税(2021) | |

#### 五、核心争议点
LOB 条款下"客观测试"(比例测试)与"主观测试"(积极商业行为/商业实质)的关系——**比例达标 ≠ 商业实质达标**。同一主体不同年度因证据完备度差异得出相反结论,极具教学价值。

#### 六、Skill 期望行为
- **判断链完整性**: 特许权定性→LOB 客观测试→LOB 主观测试→商业实质→税率
- **关键判断**: Step 3 涉及含 LOB 条款的协定(中美、中韩、美卢等)时,必须走"合格居民/所有权基数/衍生利益/积极商业行为"四项测试,不能只看持股比例
- **应当显著提示**: 比例测试通过≠安全;**同期资料/转让定价文档的完备程度**直接决定商业实质认定(2020 vs 2021 反转)
- **税额测算**: `wht.calc --income <使用费> --legal-rate 0.10 --treaty-rate 0.00 --gross`(2020 失败);`--treaty-rate 0.00`(2021 成功)

#### 七、对指引的潜在挑战 / 关联问题
- **关联问题**: 无现有编号 — **新问题 V6 候选**:中国现行指引主要覆盖 BO 与 PPT,对含 LOB 条款的协定的四项测试缺细化口径
- **指引挑战**: `references/税收协定待遇审查指引.md` 应新增"LOB 条款"小节,覆盖四项测试 + 年度证据动态评估维度

#### 八、经验沉淀线索
- **scenario_key**: `lob-commercial-substance`
- **可沉淀口径**: LOB 客观比例测试通过 ≠ 主观商业实质测试通过;商业实质按年度动态评估,同期资料完备度是决定性证据
- **sources**: 美国-卢森堡协定第 24 条 LOB 条款;国税总局税路通案例库④

### CC04 — S 先生内地 vs 香港双重居民加比规则案 {#cc04}

> **判断链维度**: 居民身份 — 双重居民 tie-breaker(加比规则)  ·  **scenario_key**: `dual-resident-tiebreaker`
> **来源核实时点**: 2026-08-07

#### 一、来源与权威性
| 字段 | 内容 |
|---|---|
| 来源 URL | https://www.bilibili.com/opus/1039373006076379139 ;http://baijiahao.baidu.com/s?id=1662768808177807695 |
| 来源类型 | 《税收协定执行案例集-01》(多平台转载) |
| 披露日期 | 2020-04-01 |
| 核实状态 | ✅ 正文已核实(多源一致) |
| 权威等级 | ★★★(税收协定执行案例集,非单方自媒体) |

#### 二、案情摘要
S 先生 2013 年与内地 C 公司签无固定期限劳动合同任运营总监,2014 年起兼任 C 公司香港子公司 D 公司常务理事并在港履职,2014 年取得香港居民身份证(非永久性)及香港税务局 2014、2015 年度税收居民身份证明。S 据此申请退还两年因未享受《安排》待遇而多缴的个税约 **40 万元**。税务机关依《内地与香港税收安排》第四条"居民"条款加比规则,逐级穿透判定为内地居民,**不予退税**。

#### 三、事实要素表
| 要素 | 事实 |
|---|---|
| 居民身份争议 | 同时构成内地税收居民(户籍内地、被内地公司派港)与香港税收居民(居民身份证+税收居民身份证明) |
| 交易定性 | 受雇所得(工资薪金),主张适用 2012 年第 16 号公告港澳受雇所得优惠计算法 |
| 住所事实 | 内地某市有 **3 套自住房产**;香港为工作长期租住一处房屋 |
| 天数事实 | 2014 年在内地停留 220 天,2015 年在内地停留 160 天 |
| 其他 | 主要收入由内地 C 公司支付;在内地缴社保公积金;多数亲属及主要资产(存款、股票、车辆、3 套房产)均在内地 |

#### 四、判断链权威结论(回归基准)
| 步骤 | 结论 | 依据 |
|---|---|---|
| 国内法居民身份 | 依"住所+停留"标准,S 户籍内地、被内地公司派港 → 内地税收居民 | 个人所得税法 |
| 香港法居民身份 | 居民身份证+税收居民身份证明 → 同时香港居民 → 双重居民 | 香港法律 |
| **加比规则第 1 级**(永久性住所) | 内地 3 套自住 + 香港长期租住,两地均有 → 无法判定 → 进下一级 | 协定第 4 条 |
| **加比规则第 2 级**(重要利益中心) | 受雇于内地 C、主要收入由其支付、内地缴社保、多数亲属及主要资产在内地 → **重要利益中心在内地** | |
| 最终居民身份 | **内地居民**(无需进入习惯性居所/国籍/协商层级) | |
| 协定待遇 | 不符合享受《安排》待遇条件 | |
| 申报/退税 | **不予退税** | |

#### 五、核心争议点

#### 六、Skill 期望行为
- **关键判断**: Step 2 须区分"取得版权使用权"(特许权)与"仅转售广告位"(营业利润/分销)
- **应当显著提示**: 非独家授权 ≠ 特许权使用费;数字化服务的定性是新兴争议点

#### 七、对指引的潜在挑战 / 关联问题
- **关联问题**: V8(混合合同分劈)延伸 — 数字化分销收入定性,`references/尽职调查要素清单.md` 交易实质章节可补"数字化服务定性"要点

#### 八、经验沉淀线索
- **scenario_key**: `non-exclusive-distribution-vs-royalty`
- **可沉淀口径**: 非独家授权分销,分销商未取得版权使用权的,分销收入不构成特许权使用费,按营业利润处理
- **sources**: 印度版权法第 14 条;印爱协定第 7、12 条;卡纳塔克邦高等法院判决

### CC22 — 大连 H 公司境外设备采购合同隐含安装服务费未代扣案 {#cc22}

#### 一、来源与权威性

| 步骤 | 结论 | 依据 |

| **交易定性(核心)** | 设备采购合同中嵌入式安装服务,合同未定价的由税务机关核定劳务收入 | 国税发〔2010〕19 号 |
