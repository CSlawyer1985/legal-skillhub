# 经典案例库 — 回归测试集

> **用途**:用真实可核实的公开案例,对 Skill 的核心判断链做**回归测试与矫正**。每个案例都已沉淀为结构化 YAML,可重复执行、可比对脚本输出、可追踪修复历史。
> **来源**:国家税务总局官网"海外税收案例库/税路通"、最高人民法院公报案例、shui5.cn、税收协定执行案例集等公开渠道。
> **版本**: 2026-08-07(v1,首发 15 案 + 2 备选)

---

## 为什么需要案例库

口语化测试用例(`assets/测试用例.md` TC1–TC4)只能测"正常路径";跨境涉税业务的**真正风险在边界判例**——受益所有人被否定、混合合同重新定性、PE 天数累计、双重居民加比规则。这些只有真实案例能逼出来。

2026-08-04 首轮验收(`Skill_验收测试报告.md`)已用 3 个真实案例揪出 4 个实质问题(V1–V4),证明这条路径有效。本库把该做法**系统化**:固定案例、固定结构、可回归。

---

## 使用方法(三步)

### 1. 回归测试(修 bug 后防退化)

修复 V1–V4 或指引更新后,挑出 `linked_issues` 命中的案例,在新的 ZCode 会话中执行:

然后比对 Skill 输出与 `chain_results`(权威结论)是否一致。

### 2. 经验库复核(制衡 provisional 污染)

经验库的 `provisional` 条目若累计被引用 ≥3 次,挑覆盖相同 `scenario_key` 的案例做复核:
- 案例结论与经验一致 → 可建议升级 `verified`
- **案例结论反驳经验** → 加 `override_of` 重写经验,或标注口径已变

### 3. 指引盲区发现

新增案例时,若 `challenge_to_guidance` 指出现有指引未覆盖的口径(如 disposal test、员工归属测试),记录到 `Skill_验收测试报告.md` 的"问题项"表,形成"案例→问题→修复→回归"闭环。

## 案例时效性与核实约定

1. **税收协定会修订**:案例引用的协定条文、公告文号,使用前须核实现行有效(参考 `references/法规与协定索引.md` 更新日期)
2. **境外案例的背书价值**:印度 ITAT、西班牙最高法院等境外判例,凡经国家税务总局官网"海外税收案例库"收录,即代表中国税务机关的**参考口径**,可作为 Skill 分析的权威参照
3. **核实优先级**:`source.type=国税总局官网` > `最高人民法院公报` > `省级政府转载` > `学术期刊/专业媒体` > `自媒体`;自媒体案例(CC-B2)须人工核实后才可纳入正式库
4. **脱敏**:案例中当事人全称若涉及未公开隐私,按原披露脱敏;公开判决书/行政处罚书的当事人不脱敏
