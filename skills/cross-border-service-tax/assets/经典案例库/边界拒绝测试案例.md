# 边界拒绝测试案例 — 测 Skill 的 scope 意识

> **用途**:`in_scope=false` 的真实案例不入正式回归库,专用于测 Skill 的**边界意识**——能否正确识别并拒绝超出自身 scope 的请求,给出边界说明和转介建议。
> **为什么需要**:现有 TC1-4 和 CC01-14 都测"Skill 应该做什么",但没测"Skill 应该**拒绝**什么"。一个没有边界意识的 Skill 会把纯境内重组、出口骗税、纯海关事项强行套用跨境判断链,产出错误分析。
> **版本**: 2026-08-07 v1

---

## 测试方法

把案例的"事实要素表"喂给 Skill,**期望 Skill 输出**:
1. **识别**出该案超出 scope(不应强行套用跨境服务贸易判断链)
2. **说明**为什么超 scope(指向 SKILL.md `## Notes` 第 1 条边界条款)
3. **转介**到合适的方向(如"纯境内重组建议找企业重组/资本运作专业支持;出口骗税涉海关刑事建议找海关/刑事专业支持;纯个税居民个人综合事务建议找个税专业支持")

**反向断言**(Skill 不应做的事):
- ❌ 强行套用"居民身份→定性→PE→协定→税率→申报"判断链
- ❌ 假装这是跨境服务贸易并给出代扣/协定分析
- ❌ 不加说明地直接拒答(应给出边界理由 + 转介)

## OOS-01 — 山东黄金子公司探矿权无偿划转不符合特殊性税务处理补税案

> **判断链维度**(若被误套): 重组税务处理 — 特殊性处理认定 · **in_scope**: **false**(纯境内)

### 一、来源与权威性
| 字段 | 内容 |
|---|---|
| 来源 | 山东黄金矿业股份有限公司公告(临2025-076),2025-11-10 |
| 来源类型 | 企业公开披露(上市公司公告) |
| 文书号/文号 | 临2025-076 |
| 核实状态 | ✅ 已核实(上市公司公告,有明确文号) |
| 权威等级 | ★★★(企业公开披露) |

### 二、案情摘要
山东黄金全资子公司山东黄金矿业(莱州)有限公司的原全资子公司章鉴公司(2021年)、鲁地公司(2022年)将探矿权无偿划转给莱州公司。经自查,上述划转不符合特殊性税务处理要求,应按一般性税务处理申报缴纳企业所得税。章鉴公司、鲁地公司均已注销,所涉税款由吸收合并后的母公司莱州公司承担。

### 三、事实要素表(喂给 Skill 的部分)
| 要素 | 事实 |
|---|---|
| 居民身份 | 山东黄金矿业(莱州)有限公司(中国居民企业);章鉴/鲁地(中国居民企业,已注销) |
| 交易定性 | 全资子公司向母公司无偿划转探矿权 |
| PE | 不涉及 |
| 关联交易 | 100%直接控制的母子公司之间资产划转 |
| 单证 | 上市公司公告、矿产资源整合文件、税务自查报告 |
| 其他 | 补税 5.08 亿元 + 滞纳金 2.30 亿元 = 约 7.38 亿元 |

### 四、超 scope 理由
- **无跨境要素**:交易各方均是中国居民企业,资产(探矿权)在中国境内,资金/服务/所得均不跨境
- **核心争议是国内重组税法**:是否满足国家税务总局公告 2015 年第 40 号特殊性税务处理条件(具有合理商业目的、连续12个月不改变实质性经营活动等),属于纯境内企业重组范畴
- **与 SKILL.md scope 不符**:第 406 行明确"聚焦中国大陆跨境服务贸易涉税,不处理纯境内业务"

### 五、Skill 期望行为(回归断言)
- ✅ **识别**:应判断"本案各方均为中国居民企业、资产在境内、无付汇/代扣/协定/PE 要素",识别为非跨境服务贸易
- ✅ **说明**:指向 SKILL.md Notes 第 1 条"聚焦跨境服务贸易涉税,不处理纯境内业务"
- ✅ **转介**:建议"特殊性税务处理认定(59号文/40号文)属于企业重组/资本运作范畴,建议咨询企业重组或资本运作税务专业支持"
- ❌ **不应**:强行套用判断链分析"居民身份→交易定性→PE→协定→税率"——本案没有 PE、没有协定、没有跨境付汇,套用毫无意义

### 六、价值说明
本案虽超 scope,但有**反向测试价值**:它涉及"特殊性税务处理认定"这一概念,容易和 Skill 核心的"一般反避税重新定性"(CC10 TCI 案)混淆。一个边界意识清晰的 Skill 应能区分:
- **特殊性税务处理认定**(重组方选择何种税务处理的资格,59/40 号文)= 纯境内重组范畴,**超 scope**
- **一般反避税重新定性**(税务机关否定交易形式,47 条/7 号公告)= 跨境场景下可能触发,**在 scope 内**(如 CC10)

这种区分能力是 Skill 专业度的体现。
