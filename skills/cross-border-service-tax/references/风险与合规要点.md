# 风险与合规要点（对应指引第6章）

> **何时读**:Step 5 做合规自查/稽查应对/转让定价审查时。

---

## 一、薄弱环节自查清单

### 1.1 申报合规自查

| 自查项 | 风险点 |
|---|---|
| 是否按时申报/代扣 | 逾期加收滞纳金(每日万分之五)、罚款 |
| 税率适用是否正确 | 协定优惠适用错误→补税+滞纳金 |
| 备案资料是否齐全 | 资料缺失→追补税款,丧失协定优惠 |
| 扣缴时点是否准确 | 实际支付 vs 到期应支付孰早,误判→漏扣 |
| 汇率折算是否正确 | 非当日中间价→计税基础错误 |

### 1.2 受益所有人自查

- 收款方是否有**实质性经营活动**(办公场所、员工、决策记录)?
- 所得是否在短时间内**转付**给第三方?
- 对方国家对该所得是否**征税**(税率是否过低)?
- 是否存在**回流安排**(资金最终回流到境内关联方)?

> 任一不利因素显著 → 协定待遇被否定的风险高,须补充实质证据或调整架构。

### 1.3 交易实质自查

- 合同名称与实际履行是否一致(防"名服务实特许权")?
- 有无**合理商业目的**?
- 混合合同是否合理分劈?
- 关联交易定价是否偏离独立交易原则?

### 1.4 协定时效与终止风险(高频盲区)

> ⚠️ **中美税收协定终止风险(2025-2026 高度现实)**
>
> 2025年2月美国发布《美国优先投资政策备忘录》,引发中美税收协定可能被终止的关注。**若协定终止**:
> - 股息、利息、特许权使用费的预提所得税将从优惠税率(最高10%)**恢复至美国法定30%**
> - 跨境投资税负将显著增加(2-3倍)
> - 在美中资企业向中国母公司分红、中国企业在美取得所得的税负剧增
>
> **应对**:涉及中美跨境的,务必在报告与测算中显著提示此风险,测算时建议**同时给出协定有效(10%)与协定终止(30%)两套情景**,并建议用户持续关注国税总局与美国财政部公告。参考:[汉坤法律分析](https://hankunlaw.com/portal/article/index/cid/8/id/15038.html)、[通商律所分析](https://www.tylaw.com.cn/Content/202502261030335481.html)。

**通用协定时效自查**:
- 协定是否有新签/修订/议定书?(以国税总局公布最新版本为准)
- 协定是否被 MLI(多边公约)修改?(PPT 等最低标准已普遍引入)
- 受益所有人/LOB/PPT 审查口径是否有新公告?(如2018年第9号公告)

## 二、转让定价（关联交易）

> **法定根基**:关联企业之间的业务往来须符合**独立交易原则**——依据**《企业所得税法》第41条**;不符合的,税务机关有权按合理方法调整(第42条授权特别纳税调整,具体程序见国家税务总局公告2016年第64号)。

### 2.1 风险触发情形(转让定价形态识别清单)

> 按"交易形态"分类识别。以下 7 种形态基于实务案例归纳(教学模型 EX-09~15),Step 5 审查时优先对照。

| 形态 | 核心红旗 | 常用调整方法 |
|---|---|---|
| **1. 职能定位失衡(销售型)** | 境外空壳销售公司占集团高比例利润,实际客户开发维护在境内;合同形式(以谁名义签约)≠ 利润归属 | TNMM / 利润分割 |
| **2. 采购型(高买转移)** | 关联采购价高于独立交易价/原采购价,通过"高买"将利润留在低税地 | CUP(可比非受控价) |
| **3. 优惠到期即亏损** | "两免三减半"等优惠结束立即亏损;出口毛利率显著低于内销,出口对象为关联方(时间序列红旗) | TNMM(历史可比) |
| **4. 服务费型(超额)** | 跨境服务费/品牌费超同业标准(如 3 倍) | CUP / TNMM |
| **5. 无形资产型(低价授权)** | 向关联方授权专利/商标的费率低于可比中位数(如 <50%) | CUP(可比许可费率) |
| **6. 管理费型(虚假服务)** | 声称母公司提供管理指导但实际未提供;**股东活动不应向子公司收费** | 实质审查→不允许扣除 |
| **7. 海外特别纳税调整** | 中国"走出去"企业的境外子公司被东道国调查(反向,框架通用) | 视东道国规则;MAP 救济 |

其他笼统红旗:
- 利润长期留在低税率地区关联公司
- 关联融资利率偏离市场(资本弱化,见 4.2)
- 成本分摊安排不合理

> ⚠️ **审查顺序提示**:先识别交易形态(上表 7 种)→ 再选调整方法 → 再核同期资料门槛。管理费型(形态 6)须先做**实质审查**(服务是否真实提供),与定价调整(形态 4/5)逻辑不同。

### 2.2 合规要求（国家税务总局公告2016年第42号）

| 同期资料 | 触发门槛(关联交易金额) |
|---|---|
| 本地文档 | 关联交易总额 ≥ 4000万元(有形资产)+其他 ≥ 1000万元;或无形资产/关联劳务特定门槛 |
| 主体文档 | 跨境关联交易 ≥ 10亿元 |
| 国别报告 | 跨国集团合并收入 ≥ 55亿元 |

> 上述门槛与关联申报要求依据:**国家税务总局公告2016年第42号**《关于完善关联申报和同期资料管理有关事项的公告》。转让定价调整方法与特别纳税调查程序依据:**国家税务总局公告2016年第64号**《特别纳税调查调整及相互协商程序管理办法》。

### 2.3 转让定价方法

| 方法 | 适用 |
|---|---|
| 可比非受控价格法(CUP) | 有可比独立交易价格 |
| 再销售价格法 | 购销中间商 |
| 成本加成法 | 制造、服务提供方 |
| 交易净利润法(TNMM) | 常用,功能风险简单一方 |
| 利润分割法 | 双方均贡献独特价值 |

> 税务机关常用 TNMM 检查关联方利润水平是否合理(如同行业利润率中位值)。

### 2.4 预约定价安排(APA)

- 企业与税务机关**事先**约定关联交易定价原则
- 单边/双边/多边
- 适合关联交易大、争议风险高的企业

## 三、情报交换（CRS）

### 3.1 CRS（金融账户涉税信息自动交换）

- 中国自2017年加入 CRS(共同申报准则)
- 金融机构向税务机关报送**非居民**金融账户信息
- 税务机关自动交换给账户持有人的**居民国**税务机关

### 3.2 尽调与报送义务

- 金融机构须识别账户持有人税收居民身份
- 新开账户:自2017年起收集自我声明
- 存量账户:电子记录阈值(个人100万美元,机构25万美元)以上须尽调

### 3.3 风险

- 通过境外账户隐匿收入→被交换回国→补税+滞纳金+罚款
- 双重居民身份→两地同时获知

## 四、反避税

### 4.1 一般反避税（《企业所得税法》第47条）

- 企业实施**不具有合理商业目的**的安排,减少应税收入/所得
- 税务机关有权按合理方法调整
- 须报国家税务总局批准后实施(程序严格)

### 4.2 特别纳税调整

| 类型 | 要点 |
|---|---|
| 转让定价调整 | 关联交易不符合独立交易原则 |
| 受控外国企业(CFC) | 设在低税率地区、无合理商业理由不分配利润。**四要件**(企税法第45条+实施条例第118条,⚠️待核实):① 居民企业/个人**控制**(单一持股≥10%且居民合计≥50%,或实质控制)② 设在**实际税负<12.5%**国家(地区)③ 收入**主要为消极所得**(股息/利息/特许权/租金)或**减少税款** ④ **无合理经营需要**不分配/少分配利润 → 视同已分配计入居民企业当期收入征税。判定题(非计算),触发后用 `ftc.calc` 不适用 |
| 资本弱化 | 关联债权性投资超过权益投资2倍(非金融)/5倍(金融)部分利息不得扣除 |
| 成本分摊 | 共同开发/受让无形资产的成本分摊须符合独立交易原则 |
| 一般反避税 | 其他避税安排 |

## 五、税务稽查应对

### 5.1 程序合法性核查

| 阶段 | 合法性要点 | 法律依据 |
|---|---|---|
| 检查通知 | 是否出具《税务检查通知书》、检查人员≥2人、出示证件 | 《税收征管法》第59条 |
| 询问 | 是否制作笔录、被询问人签字 | 《税收征管法》第57条(调查取证) |
| 调取账簿 | 是否经批准(县以上税务局长)、是否在期限内退还 | 《税收征管法》第54条 |
| 查封扣押 | 是否超范围、是否给生活保障 | 《税收征管法》第38条(税收保全) |

### 5.2 证据梳理

- 交易实质证据:合同、履行记录、沟通函件
- 同期资料(关联交易)
- 合理性说明:商业目的、定价依据
- 专业意见:税务师/律师意见

### 5.3 救济路径

| 阶段 | 期限 | 要点 | 法律依据 |
|---|---|---|---|
| 陈述申辩 | 处罚决定前 | 提出事实/法律异议,税务机关不得因申辩加重处罚 | 《税收征管法》第56条 |
| 听证 | 符合条件(较大数额罚款等) | 申请听证 | 《行政处罚法》 |
| **税务行政复议** | 知道具体行政行为之日起 **60日内** | 须先缴清税款/担保(纳税争议) | 《税收征管法》第88条 |
| **行政诉讼** | 复议决定之日起 **15日内**,或直接知道行为之日起**6个月内** | 纳税争议须先复议 | 《税收征管法》第88条、《行政诉讼法》 |

> ⚠️ 纳税争议"先缴税/担保再复议",金额大时担保是关键。时效极易错过,**收到决定书即计期**。

## 六、风险等级矩阵

| 风险 | 概率 | 影响 | 应对优先级 |
|---|---|---|---|
| 协定优惠被否定(受益所有人) | 中 | 高(补税10%差+滞纳金) | 高 |
| 转让定价调整 | 中 | 高(补税+加收利息) | 高 |
| PE 被认定(本以为是无 PE) | 中 | 高(改征税路径) | 高 |
| 申报逾期/漏扣 | 中 | 中(滞纳金) | 中 |
| CRS 信息交换触发 | 低-中 | 高(历史问题暴露) | 中 |
| 单证缺失丧失优惠 | 中 | 中 | 中 |
