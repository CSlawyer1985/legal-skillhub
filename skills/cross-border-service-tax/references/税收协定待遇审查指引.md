# 税收协定待遇审查指引（对应指引第4章）

> **何时读**:Step 3 做税收协定待遇审查时。
> 协定以国家税务总局公布原文为准,本文件为通用框架与常见口径归纳。

---

## 一、协定适用前提

享受税收协定待遇须**同时满足**:

1. 中国与对方国家/地区有**生效**的税收协定(或安排,如内地-香港、内地-澳门税收安排)
2. 收益所有人(受益所有人)是**对方税收居民**
3. 取得对方税务机关开具的**税收居民身份证明**
4. 通过**反协定滥用**审查(受益所有人 + LOB/PPT)

---

## 二、按所得类型的协定待遇

### 2.1 股息（协定第10条）

| 持股情况 | 协定通常税率 | 说明 |
|---|---|---|
| 直接持有 ≥25%(多数协定) | **5%** | 港/澳/新/德/英/荷/韩等 |
| 其他(持股<25%) | **10%** | |
| **中法协定** | **10%**(无论持股比例) | 法国无5%优惠档 |
| **中美协定** | **10%**(无论持股比例) | 美国无5%优惠档;且⚠️2025终止风险 |
| 中国国内法法定税率 | 10% | 协定优惠 ≤ 法定 |

> ⚠️ **并非所有协定都有5%优惠档**——中法、中美的股息一律10%,无持股比例优惠。使用前须查具体协定。
> 部分协定(如中德)的5%档另有"控股价值≥8万欧元"等附加条件。

**受益所有人审查**:导管持股结构(如通过香港/新加坡持股)常被质疑受益所有人。

### 2.2 利息（协定第11条）

| 情形 | 协定通常税率 | 说明 |
|---|---|---|
| 一般利息 | **10%** | 多数协定(美/日/英/法/荷/韩/俄等) |
| 香港/澳门/新加坡 | **7%** | 少数协定较低 |
| 德国 | **15%**(但≥法定10%时按10%征) | 政府/央行/政策性银行/政府全资金融机构等免税 |
| 政府/央行/完全拥有金融机构 | **免税(0%)** | 各协定普遍列名免税 |
| 中国国内法法定税率 | 10% | 协定优惠≤法定;若协定税率>10%(如德国15%),仍按法定10%征收 |

> ⚠️ 注意:协定税率若**高于**中国法定10%(如中德利息15%),来源国仍按法定10%征收("税不重征")。协定提供的是**上限**保护,实际取低者。

### 2.3 特许权使用费（协定第12条）

| 协定类型 | 通常税率 | 说明 |
|---|---|---|
| 多数协定 | **10%** | 美/日/德/英/法/荷/韩等 |
| 香港/澳门 | **7%**(香港)/10%(澳门) | 香港飞机/船舶租赁特许权5% |
| 中国国内法法定税率 | 10% | |

**范围**:使用或有权使用文学、艺术、科学作品、专利、商标、设计、专有技术、商业秘密等支付的款项;以及设备租赁。

**特殊**:中德协定对工业/商业/科学设备租赁,按特许权使用费**总额的60%**计征(实际有效税率6%)。

### 2.4 技术服务费

> ⚠️ 技术服务费在协定中的处理**不统一**,是实务争议点。

| 协定类型 | 处理 | 典型 |
|---|---|---|
| 并入"特许权使用费"合并条款 | 限制税率10% | **中印协定**第12条(特许权与技术服务费合并) |
| 并入"特许权使用费" | 按特许权税率 | 多数协定 |
| 并入"营业利润",无 PE 不征税 | 0%(无 PE 时) | 中美等部分协定 |

> 须查具体协定有无第12条之二或第13条对技术服务的专门规定。
> ⚠️ 中印协定第12条的**协定限制税率为10%**(非7.5%);7.5%是印度国内法预提税率,适用孰低原则。

### 2.5 营业利润（协定第7条）

- **无 PE → 不征税**(来源国不征税,仅居民国征税)
- **有 PE → 就归属于 PE 的利润征税**,按查账或核定
- PE 利润须按**独立交易原则**分摊(独立企业原则)

### 2.6 财产收益（协定第13条）

| 财产类型 | 征税条件 |
|---|---|
| 不动产 | 不动产所在国征税 |
| 常设机构/固定基地动产 | 机构/基地所在国征税 |
| 公司股权(主要价值为不动产) | 公司所在国征税 |
| 公司股权(其他,持股≥25%) | 部分协定:来源国征税;多数协定:转让方居民国征税 |
| 其他财产 | 转让方居民国征税 |

### 2.7 独立个人劳务（协定第14条）

- 通常设有**固定基地**或**在任何12个月内停留≥183天**才在来源国征税
- 否则仅居民国征税

### 2.8 非独立个人劳务（受雇所得,协定第15条）

- 通常在**受雇活动发生地**征税
- 但同时满足三条件则**仅居民国**征税:① 12个月内停留≤183天 ② 报酬非由来源国居民雇主支付 ③ 报酬非由雇主在来源国的 PE/固定基地负担

### 2.9 消除双重征税（协定第22/23条）

- 中国采用**抵免法**:居民企业就境外所得已缴境外税款,在汇总申报时抵免
- **两种方法可选**(财税〔2017〕84号,2018-01-01生效,⚠️待核实):① 分国不分项(原方法,财税〔2009〕125号)② 综合抵免法(不分国不分项)。**一经选择 5 年不变**(⚠️5年vs3年待核实,采skill资产口径5年)
- 超限结转(5年)
- 部分协定对特定所得采用免税法
- **税收饶让**(协定条款,非国内法单方给予):协定含饶让条款时,境外减免税视同已缴,可在限额内抵免。⚠️**饶让≠免税**:中国仍按25%限额补差额。非所有协定都有饶让(需逐协定核查)。用 `scripts/tax_calc.py ftc.calc --type sparing` 计算

### 2.10 非歧视待遇（协定第24条）

- 国籍无差别
- 常设机构无差别(PE 的税负不应高于类似居民企业)
- 子公司无差别
- 付给非居民的款项的扣除无差别

## 三、反协定滥用条款

### 3.1 受益所有人（Beneficial Owner）— 2018年第9号公告

**核心**:享受股息、利息、特许权使用费条款优惠,申请人必须是该所得的**受益所有人**(对所得及所得据以产生的权利或财产具有**所有权和控制权**)。

**不利因素**(税务机关审查时考量,9 号公告第 2 条):
1. 申请人有义务在规定时间(如 12 个月)内将所得支付给第三方(**转付义务**)
2. 申请人从事的经营活动**不构成实质性经营活动**(无办公场所/员工/业务/决策)
3. 对方国家对所得**不征税或税率极低**(避税地)
4. 在据以支付所得的合同之外,存在**与第三方之间的合同或安排**(回流/近似合同)
5. 申请人**应收款项及所得**,在对方国家/地区**不征税或税率极低**

> 🚩 **红旗速判**:转付义务 + 无实质经营 + 避税地 + 近似合同 + 低税负,命中 2 项以上即高风险。CC01/CC17/CC23 均为多因素命中。

**安全港规则**(9 号公告第 4 条,⚠️ 待核实确切条款号):属于正面清单,满足可不进行不利因素分析:
- 申请人所在国家/地区与我国**协定税率 ≥ 对方法定税率**;或
- 申请人**被对方政府/政府机构、上市公司全资拥有**;或
- 申请人**被与我国有协定的缔约对方居民上市公司全资拥有**

> ⚠️ 安全港规则适用有严格条件,不满足即回到不利因素分析。具体条件与除外情形以 9 号公告原文为准(待核实)。

**穿透规则**(9 号公告第 3 条,多层架构核心,⚠️ 待核实):申请人本身不满足受益所有人时,**可穿透至上层股东**判断:
- 适用于**多层控股架构**(如"开曼-BVI-香港-内地"),任一层股东不满足实质的,可能影响认定
- **CC23(山东省高院 2024-10 终审)**确立:F 公司及其**直接或间接控股股东均未实际履行功能**,投资控股管理活动不具有实质性 → 否定受益所有人
- 穿透的边界:不是所有中间层都要审查,但**声称享受优惠的直接申请人 + 上层关键控制层**是审查重点

**实质审查清单**(基于 CC01/CC17/CC23 归纳):
| 维度 | 实质要件 | 导管红旗 |
|---|---|---|
| 人员 | 有与功能匹配的员工 | 仅 1-2 人/无员工 |
| 资产 | 固定资产/无形资产与经营匹配 | 固定资产占总资产<1% |
| 决策 | 有独立的投融资/经营决策 | 决策由上层做出 |
| 风险 | 承担经营/投资风险 | 不承担风险,纯通道 |
| 业务 | 有实质性经营活动(非纯控股) | 仅控股、收付、记账 |
| 资金 | 所得用于自身经营 | 收到即转付(12 个月内 50%+) |

> ⚠️ **多层架构特别注意**(CC23 判例):投资控股公司的"实质"要求——不能只做"收息转发",须有**承担风险能力 + 融资能力 + 人员资产匹配**。纯控股架构是受益所有人审查的重灾区。

**举证责任**(CC18 判例):享受协定优惠改为"自行判断+留存备查"(35 号公告)后,**举证责任在纳税人**。拒绝提供资料/资料不完整 = 不能证明 = 不享优惠。

### 3.2 LOB（利益限制,Limitation on Benefits）

- 部分协定(如中美、中韩、中智)含 LOB 条款
- 要求受益所有人满足**合格居民**测试之一:
  - 上市公司(股票在认可交易所公开交易)
  - 政府
  - 主动经营测试(ownership/base erosion test)
  - 衍生利益测试
- 不满足 → 不能享受协定优惠

### 3.3 PPT（主要目的测试,Principal Purpose Test）

- MLI(多边公约)引入,**普遍适用**
- 若可合理认定获取协定优惠是交易安排的**主要目的或主要目的之一**,主管当局可**拒绝**给予优惠
- 与受益所有人、LOB 共同构成反滥用三重审查

> ⚠️ **Step 3 必查**:若 LOB/PPT/受益所有人任一有风险,**报告中显著提示**,并建议补充实质经营证据(办公场所、员工、业务记录、决策记录等)。

## 四、协定待遇的程序性要求（2019年第35号公告）

| 步骤 | 内容 |
|---|---|
| 1. 自行判断 | 非居民纳税人/扣缴义务人**自行判断**是否符合协定优惠(非审批) |
| 2. 填报信息报告表 | 填《非居民纳税人享受协定待遇信息报告表》 |
| 3. 归集留存备查资料 | 税收居民身份证明、合同、受益所有人证明等,**留存7年** |
| 4. 申报时报告 | 扣缴义务人在代扣代缴申报时填报;非居民自行申报的在申报时填报 |

> "自行判断+留存备查"改革后,**资料是享受优惠的实质要件**,缺资料=未享受,事后补开证明效力受限。
