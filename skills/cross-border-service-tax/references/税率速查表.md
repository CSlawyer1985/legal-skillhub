### 1.3 代扣代缴计算公式

```
应纳税额 = 收入全额 × 适用税率(法定10% 或 协定优惠)
```

**税费转嫁(net)实际成本**:
```
实际支付总额 = 合同净价 ÷ (1 - 适用税率)
税款 = 实际支付总额 - 合同净价
```

**算例**:
- 特许权使用费合同净价(net)= 100万元,协定税率 7%
- 实际支付总额 = 100 ÷ (1 - 0.07)= 107.53万元
- 税款 = 107.53 - 100 = 7.53万元
- 若不享受协定(10%):总额 = 100 ÷ 0.90 = 111.11万元,税款 11.11万元

## 二、增值税

### 2.1 境内销售服务税率（一般计税,代扣时常用）

| 服务类型 | 税率 |
|---|---|
| 研发技术服务、信息技术服务、文化创意服务、鉴证咨询服务等(现代服务) | **6%** |
| 交通运输、邮政、基础电信、建筑、不动产租赁、不动产销售 | 9% |
| 销售货物、加工修理修配、有形动产租赁 | 13% |
| 出口货物 | 0%(零税率) |

### 2.2 跨境服务处理

| 处理 | 税率/方式 | 适用 |
|---|---|---|
| 零税率 | 销项 0%,进项可抵退 | 国际运输、研发设计、软件、广播影视等特定跨境服务 |
| 免税 | 销项免,进项不可抵 | 多数跨境服务(完全在境外消费) |
| 一般计税 | 销项 6% 等,进项可抵 | 不符合零税率/免税 |

### 2.3 增值税应纳税额

```
一般计税:应纳税额 = 当期销项税额 - 当期进项税额
销项税额 = 不含税销售额 × 税率
不含税销售额 = 含税销售额 ÷ (1 + 税率)
简易计税:应纳税额 = 销售额 × 征收率(3% 或 5%)
```

## 五、综合税负测算示例

**情形**:境内 A 公司向境外 B 公司(中国香港税收居民)支付特许权使用费,**合同净价(net)= 100万元人民币**。

| 项目 | 计算 | 金额 |
|---|---|---|
| 实际支付总额(net 转 gross) | 100 ÷ (1 - 综合税率) | — |
| 企业所得税(协定7%) | gross × 7% | 7.53万 |
| 增值税(6%) | gross × 6% ÷ (1+6%) | — |

> ⚠️ 综合税负需用脚本测算,因 net→gross 转换涉及多税种叠加(企税+增值税+附加)。**一律调用 `scripts/tax_calc.py wht.calc`**,不口算。
