# clause-library · 条款库模板

> 定位：审查发现遗漏条款时，从本库匹配模板补充（建议改级遗漏，附完整条款文案）。
> 编号规则：纯数字序号（01-11），不带前缀编码。
> 复杂度分级：每模板分「基础版」（精简条款，快审/标准审档位用）与「完整版」（详细条款，深度审档位用）。
> 使用三步法：①理解场景（合同类型/风险点）→ ②匹配模板（选对应编号）→ ③适配调整（当事人/金额/期限/管辖地）。
> ⚠️ 本库条文为通用参考模板，使用前必须按项目主体/金额/场景校准，不得直接照搬交付。

## 01 不可抗力

**基础版（精简条款）**：因不可抗力（指不能预见、不能避免且不能克服的客观情况）致使本合同不能履行或迟延履行的，受影响方应在事件发生后【5】个工作日内书面通知对方，在影响范围内免除违约责任，但不免除金钱给付义务；不可抗力持续超过【30】日的，任何一方可书面通知解除合同，双方按已履行部分结算。

**完整版（详细条款）**：
1. 不可抗力定义：指不能预见、不能避免且不能克服的客观情况，包括但不限于自然灾害（地震、台风、洪水）、政府行为（征收、征用、管制）、社会异常事件（战争、罢工、疫情及防控措施）。
2. 通知义务：受不可抗力影响一方应在事件发生后【5】个工作日内书面通知对方，并在【10】个工作日内提供事件证明（政府公告/公证/第三方证明）。
3. 责任豁免：因不可抗力导致迟延履行或不能履行的，受影响方在影响范围内免除违约责任，但不免除金钱给付义务。
4. 持续处理：不可抗力持续超过【30】日的，任何一方有权书面通知解除合同，双方按已履行部分结算，互不承担违约责任。
5. 关联损失：因不可抗力产生的额外费用（仓储/保管/人员安置）由双方合理分担，具体分担比例【由双方协商确定】。

## 02 管辖与争议解决

**基础版（精简条款）**：因本合同发生的争议，双方应友好协商解决；协商不成的，〔向合同履行地人民法院提起诉讼／提交××仲裁委员会仲裁〕。（二选一，不得并存，仲裁条款须写明仲裁地、仲裁规则、裁决终局性）

**完整版（详细条款）**：
1. 争议解决方式（三选一，不得并存）：□ 协商 → 调解 → 诉讼；□ 协商 → 仲裁（机构全称：______仲裁委员会）；□ 协商 → 诉讼。
2. 诉讼管辖（如选诉讼）：由【合同签订地/被告住所地/合同履行地】人民法院管辖；须写明法院全称 + 审级（如「××市××区人民法院」），禁止仅写「甲方所在地法院」。
3. 仲裁条款（如选仲裁）：仲裁机构须为法定名称全称（如「××仲裁委员会」），并写明仲裁地、仲裁规则、仲裁庭组成（1 名/3 名）、裁决终局性。
4. 禁止「或裁或诉」并存表述；禁止「可诉讼亦可仲裁」的选择性条款（依《最高人民法院关于适用〈中华人民共和国仲裁法〉若干问题的解释》第 7 条此类约定无效）。
5. 涉外合同：明确适用法律（中华人民共和国法律）+ 管辖地 + 公证认证要求。

## 03 解除终止与退场移交

**基础版（精简条款）**：合同解除或终止后【10】日内，乙方应向甲方移交全部工作成果、资料、设备、场地，结清未付费用，并签署《退场移交确认单》；解除/终止不影响保密条款、知识产权归属条款、争议解决条款的效力。

**完整版（详细条款）**：
1. 解除权：发生下列情形之一的，守约方有权书面通知解除合同：【根本违约/逾期履行超过【30】日/丧失履约能力/发生不可抗力超过【30】日/法律规定的其他情形】。
2. 解除程序：书面解除通知送达后【5】日内启动清算，双方按已履行部分结算款项，违约金与损失赔偿另行主张。
3. 退场移交：合同解除或终止后【10】日内，乙方须完成下列移交事项并办理书面签收：①全部工作成果/交付物（含电子数据、源代码、文档、图纸）；②甲方提供的资料、设备、场地；③未结费用清单与结算单；④人员撤离与门禁/账号权限注销；移交完成后双方签署《退场移交确认单》。
4. 善后义务：解除/终止不影响保密条款、知识产权归属条款、争议解决条款的效力；乙方须配合甲方过渡期安排，过渡期最长不超过【30】日。
5. 资料返还：乙方留存甲方资料的，须在退场时一次性返还或销毁，并出具书面承诺。

## 04 保密义务

**基础版（精简条款）**：双方对履行本合同知悉的对方商业秘密及未公开信息负有保密义务，未经对方书面同意不得向第三方披露、复制、使用；保密义务自本合同签署之日起【3】年内持续有效，违反的应赔偿由此造成的全部直接损失。

**完整版（详细条款）**：
1. 保密范围：包括但不限于合同内容、商业信息、技术资料、客户数据、价格信息、履行过程中知悉的一切非公开信息。
2. 保密期限：保密义务自签署之日起【3】年内持续有效（涉商业秘密/个人信息的按法定要求延长）。
3. 保密义务内容：未经对方书面同意，不得向第三方披露、复制、使用；仅限于为履行本合同之目的使用。
4. 违约责任：违反保密义务的，违约方赔偿由此造成的全部直接损失；情节严重的，守约方有权解除合同并追究责任。
5. 第三方泄密：因违约方员工/分包方/关联方泄密的，视为违约方泄密，由违约方承担全部责任。
6. 例外：法律要求披露（依法院/监管机构指令）的，披露方提前书面通知对方并尽量缩小披露范围。

## 05 履约保障（公共场景）

**基础版（精简条款）**：乙方应在合同生效后【10】日内投保【雇主责任险、公众责任险】并提交投保凭证；乙方应向甲方提供履约保证金（合同金额【5-10】%）或银行履约保函，验收合格后【30】日内无息退还；留取合同金额【5-10%】作为质保金，质保期满且无质量问题后【30】日内无息支付。

**完整版（详细条款）**：
1. 保险义务：乙方应在合同生效后【10】日内投保【雇主责任险、公众责任险】（保额不低于人民币【___】万元），保险期间覆盖合同履行期，投保凭证交甲方备案；保险到期前【10】日续保并提交新凭证。
2. 禁止转包/分包：乙方不得将合同项下义务转包给第三方；确需分包的，须经甲方书面同意，且分包方须具备相应资质并承担连带责任；违反本条的，甲方有权解除合同并要求支付合同总额【20%】的违约金。
3. 工伤事故责任：履行期间发生人员伤亡/财产损失的，由乙方承担全部责任并负责妥善处理（含医疗救治、赔偿、劳动仲裁/诉讼应对）；因甲方原因导致的事故除外，但乙方仍负有先行救治与协助义务。
4. 履约担保（可选）：乙方应向甲方提供履约保证金（合同金额【5-10】%）或银行履约保函；保证金在验收合格后【30】日内无息退还。
5. 发票与付款：乙方按合同约定开具合规发票（发票类型与计税方式一致），甲方在收到发票后【___】日内付款；发票与付款条件不得附加其他前提。
6. 质保金：留取合同金额【5-10%】作为质保金，质保期满且无质量问题后【30】日内无息支付。

## 06 验收与质保

**基础版（精简条款）**：乙方完成交付后【5】个工作日内书面通知甲方验收；甲方应在收到通知后【10】个工作日内组织验收并出具书面意见，逾期未提出的视为验收通过；验收合格后【10】日内甲方支付至合同金额的【90-95】%，剩余【5-10】%作为质保金，质保期满且无未决质量问题后【30】日内无息退还。

**完整版（详细条款）**：
1. 验收节点与程序：乙方完成交付后【5】个工作日内书面通知甲方验收；甲方应在收到通知后【10】个工作日内组织验收并出具书面验收意见，逾期未提出的视为验收通过【或：不视为验收通过，双方另行约定】。
2. 验收标准：以【合同附件技术规格/双方确认的验收标准/国家标准】为准；验收不合格的，甲方书面列明不合格事项，乙方应在【10】日内整改后重新提交验收，整改次数累计不超过【2】次。
3. 付款与验收绑定：验收合格并签署《验收确认单》后【10】日内，甲方支付至合同金额的【90-95】%；剩余【5-10】%作为质保金。
4. 质保期与质保金：质保期自验收合格之日起【12/24】个月；质保期内出现质量问题的，乙方应在【7】日内免费修复/更换；质保期满且无未决质量问题的，甲方在【30】日内无息退还质保金。
5. 不合格的最终处理：整改仍不合格或超过整改次数的，甲方有权解除合同、要求乙方返还已付款项并赔偿损失。

## 07 违约金体系

**基础版（精简条款）**：一方违约的，按日支付未履行部分价款【0.5‰】的违约金，累计不超过合同总金额【10%】；违约金以实际损失为参照，因故意或重大过失造成损失的，违约金条款不限制守约方另行主张损失赔偿。

**完整版（详细条款）**：
1. 单一标准：本合同违约金统一适用单一标准（如「每日按合同总金额的【0.5‰】计算，累计不超过合同总金额的【10%】」），不得多标准并存。
2. 比例合规：约定违约金应合理（参照实际损失；过高部分可能依《民法典》第 585 条被请求调减，司法实践一般以不超过实际损失的 30% 为参考），不建议约定日千分之三以上（年化逾 100%）的过高标准。
3. 口径统一：违约金的计算基数、起算时点、截止时点须全文一致（禁止「滞纳金」「罚款」等与违约金混用——民事合同应为违约金）。
4. 上限与例外：违约金累计不超过合同总金额的【10-20%】；因故意或重大过失造成损失的，违约金条款不限制守约方另行主张实际损失赔偿。
5. 与保证金关系：履约保证金可优先用于抵扣违约金；违约金与保证金不重复计算，避免双重处罚。

## 08 知识产权与数据留存

**基础版（精简条款）**：履行本合同产生的全部工作成果（含文档、数据、源码、设计）的知识产权归【甲方】所有；乙方可留存履行过程中形成的通用方法论与底层数据模型，但不得用于与甲方竞争的业务；乙方保证交付成果不侵犯第三方知识产权。

**完整版（详细条款）**：
1. 成果归属：履行本合同产生的全部工作成果（含文档、数据、源码、设计）的知识产权归【甲方/双方按约定比例】所有。
2. 底层数据与方法论留存：乙方有权留存履行过程中形成的通用方法论、底层数据模型与经验沉淀，但不得用于与甲方竞争的业务，不得泄露甲方商业秘密；甲方有权要求乙方交付完整的过程性资料（含设计文档、代码注释、配置说明）。
3. 侵权担保：乙方保证交付成果不侵犯第三方知识产权；因侵权引发第三方主张的，由乙方负责处理并赔偿甲方损失。
4. 许可边界（若 IP 归甲方）：甲方授权乙方在【非商业/内部培训】范围内使用该成果，不得转授权。
5. 保密延续：IP 条款效力不因合同解除/终止而消灭。

## 09 履约期限与顺延

**基础版（精简条款）**：本合同履行期限为【　年　月　日】至【　年　月　日】（总时长【　】日/月）；因甲方原因（变更指令/迟延提供资料/未按期付款）导致顺延的，乙方应在事件发生后【5】日内书面通知甲方并提交顺延申请，甲方【5】日内书面确认；乙方自身原因导致的迟延不属于顺延事由。

**完整版（详细条款）**：
1. 期限明确：本合同履行期限为【__年月日】至【年月日】（总时长【】日/月）；关键节点【列明里程碑：_、_、____】。
2. 顺延机制：因甲方原因（变更指令/迟延提供资料/未按期付款）导致工期顺延的，乙方应在事件发生后【5】日内书面通知甲方并提交顺延申请，甲方【5】日内书面确认；未经确认的顺延不成立。
3. 免责边界：乙方自身原因（含人员安排、资金、技术能力）导致的迟延不属于顺延事由；禁止约定「任何原因均可免责/顺延」的过宽免责条款。
4. 催告义务：一方迟延履行的，守约方应书面催告并给予合理宽限期（一般不少于【10】日）；宽限期届满仍未履行的，守约方有权解除合同。
5. 逾期后果：逾期履行的，按 07 违约金条款执行；逾期超过【30】日的，守约方有权解除合同。

## 10 发票与税务

**基础版（精简条款）**：乙方按【增值税专用发票】开具合规发票，计税方式为【一般计税】，开票类型与计税方式须与合同价款口径一致；甲方在收到合规发票后【　】日内付款，付款以收到合规发票为前提。

**完整版（详细条款）**：
1. 发票类型与计税方式匹配：乙方按【增值税专用发票/增值税普通发票】开票，计税方式为【一般计税/简易计税】；开票类型与计税方式须与合同价款口径一致（如约定 3% 专票 + 一般计税 = 矛盾，应修正）。
2. 开票时限与信息：乙方应在【收款前/收款后【5】日内】开具合规发票，发票信息（名称/税号/开户行）以甲方书面确认为准；发票不合规的，甲方有权拒付或要求重开。
3. 付款以发票为前提（可选）：甲方付款以收到合规发票为前提；因乙方未开票导致的付款迟延，甲方不承担违约责任。
4. 税率变动：合同履行期间税率发生调整的，按调整后的税率执行，含税总价不变的，相应调整不含税价；双方另有约定的除外。
5. 费用边界：除合同价款外，双方各自承担按税法规定应由己方承担的各项税费；合同价款包含/不包含【运输/安装/检测/维保】等费用（须明确）。

## 11 分包与转包管理

**基础版（精简条款）**：乙方不得将合同项下的全部或主要义务转包给第三方；确需分包的，须经甲方书面同意，分包方须具备完成该部分工作所需的法定资质/许可，乙方对分包方的工作成果向甲方承担连带责任。

**完整版（详细条款）**：
1. 禁止转包：乙方不得将合同项下的全部或主要义务转包给第三方；转包行为无效，甲方有权解除合同并要求乙方支付合同总额【10-20%】违约金。
2. 分包前置条件：确需分包的，须经甲方书面同意；分包方须具备完成该部分工作所需的法定资质/许可；乙方对分包方的工作成果向甲方承担连带责任。
3. 分包清单报备：乙方应在分包前向甲方提交分包方名称、资质证明、分包内容与金额清单，经甲方书面确认后方可实施；未经确认的分包视为违约。
4. 禁止再分包：分包方不得将其承接部分再次分包。
5. 人员与现场管理：分包方人员须遵守甲方的现场管理规定与安全要求；因分包方人员导致的工伤、侵权责任由乙方承担。

## 使用说明

- 遗漏条款优先从本库匹配模板，匹配后必须按项目校准当事人/金额/期限/管辖地等参数；
- 模板编号规则：纯数字序号（01-11），与主控文档《命名与语言规范》编号规则一致；
- 基础版用于快审/标准审档位（精简条款直接补充），完整版用于深度审档位（详细条款按需组合）；
- 模板用于「遗漏补充意见」（建议改级），随审查意见交付时须附适配说明。
