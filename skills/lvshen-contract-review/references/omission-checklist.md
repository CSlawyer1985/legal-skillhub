# omission-checklist · 遗漏项核对清单

> 定位：core-checklist 各模块的高频遗漏补充 + 招标/租赁/服务/技术专项。标⭐ = 高频实践项，优先排查。
> 说明：通用高频遗漏基于合同审查实务通用规律，按合同条款模块逻辑展开；场景专项为特定交易类型的高发遗漏。仅收录通用、可跨行业复用的遗漏项；特定项目/特定交易结构的过细内容不收录。

## 一、通用高频遗漏（按合同条款模块）

### 主体与授权
- ⭐ 分公司/项目部签约未核实总公司授权或负责人签字权限
- ⭐ 关联公司主体混同：合同对接人与实际签约主体不一致

### 标的与质量
- ⭐ 验收标准引用失效版本或已撤销机构名称（质监局/工商局已并入市场监管局）
- 质量标准表述模糊（仅写"按行业惯例"）

### 价款与支付
- ⭐ 税率与发票类型不匹配（如约定 3% 增值税专用发票 + 一般计税，矛盾）
- ⭐ 一次性付款无验收闭环：付款触发条件未约定审核期，缺验收确认节点或质保金
- ⭐ 违约金体系不自洽：多标准并存/口径不一/无上限/「滞纳金」误用（民事合同应为违约金）
- ⭐ 违约金比例过高（如日千分之三≈年化 109.5%，远超司法保护上限，过高部分可被调低）
- 赔偿总额封顶条款：一方赔偿不超合同总额，对受损方不利（建议删除上限或约定故意/重大过失不受限）

### 履行
- ⭐ 履约期限不明或顺延机制缺失（单方原因致延误的免责条款过宽 + 缺催告义务）
- 交付物/成果形式、份数未明确

### 解除与善后
- ⭐ 解除/终止后善后义务缺失（资料返还/IP 清算/保密延续）
- 不可抗力条款不完整（缺通知义务、责任豁免边界、持续处理）

### 知识产权与保密
- ⭐ 知识产权「全部归甲方」无底层数据/方法论留存约定，易致乙方合理抗辩
- ⭐ 保密义务无保密期限/保密违约金/第三方泄密责任划分

### 争议解决
- ⭐ 管辖仅写「甲方所在地人民法院」未细化法院全称 + 审级（管辖连接点：被告住所地/合同履行地/签订地/标的物所在地）
- ⭐ 「或裁或诉」并存（删除未选项，争议解决方式单一确定）
- 送达地址、争议解决费用承担缺失

### 格式条款
- ⭐ 提供方未就免责条款尽提示说明义务（《民法典》第 496 条）
- 不合理免除/减轻己方责任、加重对方责任、排除对方主要权利（第 497 条）

### 程序性
- 合同编号、签订时间、签字盖章空白待补
- 附件占位符（项目名称/份数）未填实

## 二、招标/政府采购专项

1. ⭐ 前附表跨条款一致性（履约保证金时间/有效期等矛盾）
2. ⭐ 冲突规则矛盾（删除「以时间后者为准」，统一优先顺序条款）
3. ⭐ 「或裁或诉」风险（删除未选项）
4. ⭐ 招标投标法第 46 条合规（补充一致性声明防背离实质性内容：中标人/金额/工期/履约保证金交叉核对）
5. ⭐ 履约担保形式范围不一致（合同正文收窄招标文件允许的担保形式 → 实质性偏离风险，须与招标文件完全一致）
6. ⭐ 验收章节与违约责任章节同一行为重复设定处罚 → 增加「不叠加适用」衔接语
7. ⭐ 计价标准版本核验（建设工程/修缮/维修类）：GB50500-2013 已被 GB/T50500-2024 替代，引用 2013 版 = 引用失效标准
8. ⭐ 机构存续性核验：合同引用的政府机构名称须核验存续（引用已撤销机构名称即条款无法执行）

## 三、租赁专项

- ⭐ 划拨用地房屋出租合规前置（出租方视角）：证载权利性质「划拨」+ 证载用途 vs 约定租赁用途不一致 → 重大合规前置风险，须核验规划用途变更、划拨用地出租报批、土地收益上缴（《城镇国有土地使用权出让和转让暂行条例》第 44、45 条、《城市房地产管理法》第 55 条）
- ⭐ 承租方实缴资本/参保人数与长租期大额租金体量不匹配 → 要求履约担保（银行保函/股东连带保证）或提高保证金
- 履约保证金与违约金并用：司法实践存在争议，最高法倾向不宜重复主张，违约金可先从保证金抵扣

## 四、服务类缺漏专项（服务合同高发遗漏）

- ⭐ 服务范围界定不清：服务内容、边界、除外事项未明确（"负责相关事务"式模糊表述）
- ⭐ 服务成果形式未约定：成果形式（报告/方案/数据）、份数、交付时限未明确
- ⭐ 验收标准缺失：服务成果的验收标准、验收程序、验收主体未约定
- 服务人员要求：人员资质、驻场/到场频次、人员更换审批未约定
- 转包/分包：服务方擅自转包分包无制约（须经书面同意 + 资质要求）
- 数据安全与个人信息：涉及客户数据/个人信息的处理边界、保密、删除义务未约定
- ⭐ 责任边界削弱条款：服务方「仅对当时状态负责」「检测当天出具报告」等表述削弱责任/不现实，须明确责任范围与合理期限
- ⭐ 资质条款过泛：仅写「具备相应资质资格」未列具体从业条件/备案/人员证书交付义务 → 须按行业法规列明具体要求
- 附件兜底陷阱：附件后另附「说明」兜底甲方全责属重大陷阱（主合同权利义务被附件单方扩大的，须审查附件与正文冲突）
- 付款与交付绑定：付款节点与服务成果交付/验收绑定

## 五、技术类缺漏专项（技术合同高发遗漏）

- ⭐ 技术成果归属未明确：开发/服务过程中产生的技术成果（含中间成果、文档、数据、源码）归属
- 底层技术与方法论留存：一方留存通用方法论/底层数据模型的边界与使用限制
- ⭐ 开发风险分担缺失：技术开发失败/不能实现约定技术目标的损失分担（参照民法典第 858 条）
- 技术验收标准：技术成果的验收标准、验收程序、验收时限
- 技术资料交付：技术资料（设计文档、代码注释、配置说明）交付义务与完整性
- ⭐ 保密与技术保护：技术秘密的保密范围、期限、违约后果；竞业限制衔接
- 知识产权侵权担保：技术成果不侵犯第三方知识产权的担保与责任承担
- 后续改进成果：技术后续改进成果的归属与使用安排
- 技术服务边界：技术咨询/服务与开发成果的边界（避免"咨询变开发"责任不清）
