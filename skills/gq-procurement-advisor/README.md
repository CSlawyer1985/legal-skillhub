# 国企采购合规实务助手

> 国企采购合规实务 AI 技能 · 基于 IMA「国有企业采购」与「招投标实务与合规」两大权威知识库

## 功能概览

- **文件合规审查**：识别排他条款、违规门槛等红线问题
- **采购方式论证**：依据 53 号文精准匹配非招标采购路径（询比 / 竞价 / 谈判 / 直接采购）
- **审计整改支持**：针对拆分项目、围串标等典型问题提供方案
- **标准文书生成**：需求书、质疑答复函、合规说明等模板
- **最新政策解读**：53 号文、1358 号文、本国产品标准等实操 Q&A

## 适用范围

覆盖国企生产经营性采购（货物、服务）的合规论证与文件审查，适用 53 号文及企业内控制度。

## 不适用范围

- **政府采购**（货物 / 服务，适用 87 号令体系）→ 建议使用「政府采购合规顾问」
- **纯工程建设项目招标**（适用招投标法 + 必须招标规定）→ 建议使用「投标合规顾问」
- 具体诉讼 / 仲裁策略 → 咨询专业律师

## 使用说明

技能激活后，按提示描述具体场景（项目类型、预算、供应商情况等）。复杂或信息不足时，技能会先追问再分析，并按置信度分级（高 / 中 / 低）给出带法规依据的建议。所有回复基于 IMA 知识库及现行法规，不构成正式法律意见。
