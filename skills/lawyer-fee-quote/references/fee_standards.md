## 各省市律师费政府指导价概览

### 浙江省律师服务收费标准

**适用范围**：浙江省行政区域内律师事务所提供法律服务

**财产案件分段累进收费标准**：

| 标的额区间 | 收费标准 |
|-----------|---------|
| 10万元以下 | 8%-10%（最低不低于2500元） |
| 10万元-50万元 | 5%-7% |
| 50万元-500万元 | 3%-5% |
| 500万元-1000万元 | 2%-3% |
| 1000万元-5000万元 | 1%-2% |
| 5000万元以上 | 0.5%-1% |

**计时收费标准**：
- 主任（一级）律师：500-1000元/小时
- 二级律师：400-800元/小时
- 三级律师：300-600元/小时
- 律师助理：100-300元/小时

### 北京市律师服务收费标准

**财产案件政府指导价**：

| 标的额区间 | 收费标准 |
|-----------|---------|
| 10万元以下 | 8%-10% |
| 10万元-100万元 | 5%-7% |
| 100万元-1000万元 | 3%-5% |
| 1000万元以上 | 1%-3% |

**注**：北京市已逐步放开律师服务收费市场化，但重大疑难复杂案件仍可参照政府指导价。

### 上海市律师服务收费标准

**计时收费**：
- 一级律师：3000-5000元/小时
- 二级律师：2000-4000元/小时
- 三级律师：1000-3000元/小时

**计件收费**：
参照全国平均水平，结合上海市经济水平确定。

### 广东省律师服务收费标准

## 财产案件分段累进收费计算方式

### 计算公式

```
总费用 = Σ(各区段金额 × 对应费率)
```

### 示例计算（标的额500万元）

**浙江省标准**：

| 区段 | 金额 | 费率（取中间值） | 费用 |
|------|------|-----------------|------|
| 10万以下 | 10万 | 9% | 0.9万 |
| 10-50万 | 40万 | 6% | 2.4万 |
| 50-500万 | 450万 | 4% | 18万 |
| **合计** | | | **21.3万** |

## 重大疑难复杂案件上浮规则

### 上浮条件

符合以下条件的案件，可在标准费率基础上上浮一定比例：

1. **涉及境外/跨境法律问题**（上浮20%-50%）
2. **涉及重大利益争议**（上浮20%-50%）
3. **涉及多方利益协调**（上浮15%-30%）
4. **证据收集困难或需要专项调查**（上浮20%-40%）
5. **法律适用存在争议需要专家论证**（上浮30%-50%）

### 上浮比例上限

- 一般疑难案件：上浮不超过30%
- 重大疑难复杂案件：上浮不超过50%
- 特别重大疑难案件：可一事一议

### 上浮计算示例

```
基础费用：45.3万元
上浮50%后：45.3 × 1.5 = 67.95万元
```

## 备注

1. 以上标准仅供参考，实际收费应根据案件具体情况协商确定
2. 部分省市已逐步放开律师服务收费市场化，具体请咨询当地律协
3. 风险代理、计时收费等特殊收费方式可另行约定
4. 跨境案件、涉外案件可能涉及境外律师费用，需另行计算
