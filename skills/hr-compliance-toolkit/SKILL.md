# HR Compliance Toolkit — 企业劳动人事合规风控SOP工具包

> **一句话：** 把9部劳动法和13份HR文书模板装进AI，你用大白话提问，它用法律条文原文回答并生成合规文件。无需法律背景，照着问就能用。

## Overview

此技能提供一套完整的、可立即使用的企业劳动人事合规知识体系和工作流程。覆盖员工从入职到离职全生命周期的8大核心场景，内置9部劳动法规的结构化条文（精确到条）和场景→条款映射索引，以及13份可直接打印/填写的HTML模板。目标是让非法律专业人员也能准确引用法律条款、生成合规文书。

## Quick Start — 核心工作流

收到用户关于劳动人事合规的请求后，遵循以下步骤：

1. **识别场景** — 判断用户需求属于8大场景中的哪一个（查看下方的场景速查表）
2. **检索条款** — 读取 `references/scene-mapping.json` 获取该场景涉及的所有法律条款号
3. **精读原文** — 读取 `references/laws/` 下对应法规文件，提取条款原文（绝不凭记忆引用条款）
4. **生成交付物** — 根据用户需求输出：合规检查清单 / 法律分析 / 模板文书
5. **提供模板** — 如需生成文书，从 `assets/hr-templates/` 中选择对应模板，修改填写后交付

## 如何使用 references/

### 1. 场景→条款映射 (`references/scene-mapping.json`)

**这是整个技能的路由器。** 收到用户请求后，第一步就从这里查找该场景涉及的所有法律条款。

结构：
```json
{
  "scene3": {
    "name": "入职资料标准化办理",
    "laws": [
      {"law": "劳动合同法", "article": 8, "purpose": "如实告知义务"},
      {"law": "劳动合同法", "article": 9, "purpose": "禁止扣押证件/收取财物"},
      {"law": "劳动合同法", "article": 91, "purpose": "双重劳动关系连带赔偿"},
      {"law": "个人信息保护法", "article": 6, "purpose": "最小必要原则"},
      ...
    ],
    "checklist": [...]
  }
}
```

每个场景包含：
- `laws`: 该场景涉及的每部法律的每一条，含用途说明
- `checklist`: 可直接输出的合规检查清单
- `key_risks`: 高频违规点

### 2. 法规条文 (`references/laws/`)

9部法律文件，文件名格式为 `序号的-法名.md`（如 `02-劳动合同法.md`）。文件内部按章节和条目组织，每一条都标注了精确的条款编号。

**使用规则（必须遵守）：**

- **绝不凭记忆引用条款** — 用户要求查询某法第X条时，必须去 `references/laws/` 中读取对应法条的原文
- **引用时标注完整来源** — 输出法律分析时，逐条标注"依据XX法第XX条"
- **场景分析时一次读取** — 如果用户问"入职需要注意什么法律问题"，先去 `scene-mapping.json` 找到 scene3 的所有条款列表，然后去 `references/laws/` 中逐一读取原文，再组织回答
- 文件较大时的搜索策略：先 Grep 定位条款号所在行，再 Read 截取上下文

## 常见任务的处理模式

### 任务A：查询法律条款

- 用户："帮我查劳动合同法第X条"
- 操作：Read `references/laws/02-劳动合同法.md` → 定位条款 → 输出原文 + 简要解读

### 任务B：场景合规分析

- 用户："入职办理需要注意哪些法律"
- 操作：Read `references/scene-mapping.json` → 定位 scene3 → 获取条款列表 → 逐一去 laws/ 读取原文 → 输出完整的法律依据 + 检查清单

### 任务C：生成文书/模板

- 用户："帮我生成一份Offer"
- 操作：Read `assets/hr-templates/02-Offer录用通知书模板.html` → 了解模板结构 → 要求用户提供具体信息（公司名、岗位、薪资等）→ 生成填写完成的版本 → 保存并呈现

### 任务D：合规检查

- 用户："我们的调岗流程合不合规"
- 操作：从 scene-mapping.json 获取 scene7 的 checklist → 对照清单逐一询问用户确认 → 标注合规/不合规项 + 法律依据

## 核心法律原则速记

以下原则在任何回答中都必须遵守，不可违背：

1. **不签合同=双倍工资**（劳动合同法第82条）— 用工满1个月不签触发
2. **试用期最多6个月，同一人只能一次**（劳动合同法第19条）
3. **不得扣押证件/收取财物**（劳动合同法第9条）
4. **不得招用未离职员工**（劳动合同法第91条）— 连带赔偿责任
5. **个人信息最小必要**（个人信息保护法第6条）— 入职登记表不能乱问
6. **调岗降薪须协商一致**（劳动合同法第35条）— 用人单位不能单方决定
7. **竞业限制最长2年，须按月给补偿**（劳动合同法第24条）
8. **员工手册须经民主程序+公示**（劳动合同法第4条）— 缺少任一程序则无效
9. **试用期辞退须证明"不符合录用条件"**（劳动合同法第39条）— 且录用条件已在入职时公示
10. **离职不出具证明=赔偿责任**（劳动合同法第89条）
