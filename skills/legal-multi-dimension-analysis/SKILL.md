# 法律多维协同分析（Multi-Dimension Legal Analysis）

## Overview

本技能提供案件与法律咨询的**多维度协同分析编排框架**：当一个问题不能只从一个法律视角回答时（如民事违约背后可能隐藏刑事诈骗，行政违法可能同时触发刑事立案，或综合题涉及合同×公司×担保多重法律关系），按统一方法完成**维度路由 → 逐维分析 → 跨域协调 → 综合研判 → 质量自检**五步闭环，输出结构化的"维度矩阵 + 协同结论"。

本技能是**编排/协同层**，不重复承载各领域的法条与构成要件（那属于民事、刑事、行政、司法实务、律师实务等垂直领域 Skill），而是调度它们、识别冲突、整合结论。

## When to use

在以下任一情形启用本技能：
- 用户要求"多维分析""全面分析""综合研判""多视角""刑民交叉""行刑衔接""民行交叉""联动分析""全维度风险评估"。
- 单一领域分析不足以覆盖案件（如合同纠纷但可能涉及合同诈骗；行政处罚但可能涉嫌犯罪）。
- 综合题/复杂案件涉及多个法律部门交叉（合同×公司×担保×侵权）。
- 需要输出"维度矩阵"或"各视角协同结论"供决策参考。

不在以下情形启用：纯单点法律问答（如"某条文含义""某案由管辖"），直接交给对应垂直领域 Skill 即可。

## Core principle（三条铁律）

1. **离线优先 / 涉密不触网**：本框架服务于法律实务，默认不依赖联网大模型；如需调用外部检索引擎，须可降级，缺失时回退本地知识。
2. **强事实双校验防幻觉**：所有法条引用执行"条号—内容—时效性"三校验，且必须标注来源；禁止引用未检索、条号错误或内容张冠李戴的法条。
3. **线索发现非定罪护栏**：分析结论为"线索/可能性/分级建议"，不是定罪结论。输出须带红/黄/蓝分级 + 核查指引，不下越界定性。

## Workflow

### Step 1 — 维度路由（Dimension Routing）

Read `references/dimension-routing.md` for the full routing table.

依据案情要素，识别本案**应当覆盖的法律维度**集合，而非默认全开。维度包括：
- 民事维度（合同/侵权/物权/公司/婚姻家庭等）
- 刑事维度（自然犯/法定犯，是否触及刑法分则某章）
- 行政维度（行政处罚/行政许可/行政强制/行政复议）
- 程序维度（诉讼程序/执行/保全/民刑交叉程序/行刑衔接程序）
- 经侦维度（经济犯罪侦查管辖罪名、立案追诉标准、侦查方向）
- 律师实务维度（诉略/举证/抗辩策略/文书）

输出"维度路由表"：本案拟启用维度 + 启用理由 + 关键触发关键词。

### Step 2 — 逐维度专家分析（Per-Dimension Analysis）

对每个启用的维度，按统一分析范式产出该维度的独立意见：
- 强制 **IRAC 结构**（Issue–Rule–Analysis–Conclusion）：规则须拆解要件，事实须逐一涵摄。
- 强制 **多视角对抗**：每个子问题的 Analysis 环节拆分为【正方视角】→【反方视角】→【综合判断】，结论果断不模糊。
- 强制 **法条双校验**：条号、内容、时效性三校验 + 来源标注（见 Core principle 第 2 条）。

各维度产物彼此独立，但须标注"本维度内的关键事实依赖点"，供 Step 3 协调使用。

### Step 3 — 跨域冲突识别与协调（Cross-Domain Coordination）

Read `references/cross-domain-coordination.md` for templates.

识别维度间冲突并协调：
- **刑民交叉**：以"事实是否依赖"为核心标准判断是否先刑后民/刑民并行，不机械套用"先刑后民"；分析双向影响与先行判决可能。
- **行刑衔接**：行政违法达到刑事立案标准的，标记"应移送刑事"并提示立案追诉标准；反向亦须识别"刑事撤案后行政追责"。
- **民行交叉**：民事裁判与行政决定冲突时的效力优先与救济路径。
- **经侦与其他维度**：凡确认涉经济犯罪，必须转向经侦维度获取刑事立案标尺，不得仅以民事/行政路径作答。

输出"冲突协调表"：冲突点 + 协调规则 + 协调后结论。

### Step 4 — 多维研判整合（Synthesis）

Read `references/dimension-matrix-template.md` for the report template.

整合各维度独立意见与冲突协调结论，产出：
- **维度矩阵**：行=启用维度，列=争议焦点/风险点，单元格=该维度下的结论与置信度。
- **协同结论**：综合全维度的最优解判定，明确各维度如何相互支撑或制约。
- **分级与核查指引**：红（高危/应立案或起诉）/黄（需补充证据或进一步查证）/蓝（低风险的合规建议），每级附核查动作。
- **风险提示**：跨维度连锁反应（如刑事判决对民事执行的影响）。

### Step 5 — 质量自检（Quality Gate）

Read `references/quality-checklist.md` and execute all 8 checks before output. 仅当全部通过，方可输出最终研判。

## Boundaries（边界，避免重复造轮子）

- 本技能**不**内置各领域法条库与构成要件模板——那属于垂直领域 Skill（civil/criminal/administrative-case-analysis 等）。需要具体法条时，检索对应领域知识库或调用连接器（如北大法宝、威科、华宇元典）。
- 本技能**不**绑定特定知识库路径；维度路由与协调模板为政方法论，可独立运行。
- 若已安装 `legal-case-analysis` 等上游 Skill，本技能与其协作：上游负责单维度深度，本技能负责多维编排。
