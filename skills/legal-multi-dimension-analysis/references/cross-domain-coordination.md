# 跨域冲突识别与协调模板（Cross-Domain Coordination）

本文件供 Step 3 使用。目标是识别不同法律维度之间的**冲突点**并给出**协调规则**，避免各维度结论相互打架。

## 一、刑民交叉协调

**核心标准**：以"事实是否依赖"判断程序走向，不机械套用"先刑后民"。

| 情形 | 协调规则 | 程序结论 |
|------|---------|---------|
| 民事案件的事实认定**依赖**刑事判决结果 | 中止民事审理，待刑事终结 | 先刑后民 |
| 民事侵权事实相对独立，刑事仅涉及其中一方行为 | 刑民并行，互不等待 | 刑民并行 |
| 民事紧迫需求（如行为保全/停止侵权） | 就"停止侵害"部分可先行判决 | 先行判决 |

**必须分析双向影响**：不仅分析"刑事影响民事"，还要分析"民事紧迫需求是否影响刑事节奏"。

**输出格式**：
```
刑民交叉协调
- 冲突点：合同效力认定依赖行为人是否构成合同诈骗
- 协调规则：民事事实依赖刑事结论 → 先刑后民
- 双向影响：受害人财产保全需求紧迫，可先行查封
- 协调结论：中止民事违约之诉，移送刑事；保全措施并行
```

## 二、行刑衔接协调

**核心标准**：行政违法达到刑事立案追诉标准的，必须标记"应移送刑事"。

| 情形 | 协调规则 |
|------|---------|
| 行政违法数额/后果达到刑事立案标准 | 标记"应移送刑事"，列明立案追诉标准条文 |
| 刑事撤案/不诉后仍需追责 | 反向衔接：启动行政处罚（如罚款、吊销许可） |
| 同一行为已被刑事处罚金 | 行政罚款可折抵，避免重复处罚 |

**输出格式**：
```
行刑衔接协调
- 冲突点：偷逃税款 X 万元，已达逃税罪立案标准
- 协调规则：行政违法→刑事追诉阈值触发 → 应移送
- 协调结论：税务机关移送公安；已缴税款可作为量刑情节
```

## 三、民行交叉协调

**核心标准**：民事裁判与行政决定冲突时，审查行政行为效力优先性与救济路径。

| 情形 | 协调规则 |
|------|---------|
| 行政登记/许可被撤销，影响民事权属 | 以生效行政判决为民事裁判前置 |
| 民事确权与行政登记不一致 | 引导当事人先行政救济（复议/诉讼）或直接提起行政诉讼 |

## 四、经侦维度与其他维度

**铁律**：凡确认涉经济犯罪，必须转向经侦维度获取刑事立案标尺，不得仅以民事/行政路径作答。

协调规则：在综合建议中增设"经侦专家补：本案已达 XX 罪立案门槛，建议同步报案/移送并启动资金分析鉴定"段落。

## 五、冲突协调表输出格式

```
冲突协调表
| 冲突点 | 涉及维度 | 协调规则 | 协调后结论 |
|-------|---------|---------|-----------|
| 合同效力依赖诈骗认定 | 民事×刑事 | 先刑后民 | 中止民事，先刑 |
| 偷税达立案标准 | 行政×刑事 | 应移送 | 移送公安 |
```
