# 多维质量自检清单（Quality Gate）

本文件供 Step 5 使用。所有多维分析在完成前必须逐项正确执行以下 8 项检查，并输出检查过程与结论（禁止走过场打勾）。

## 检查项目

### 1. 主体身份识别是否正确？
- 是否建立了"主体身份矩阵"（各维度下的主体是否一致）？
- 是否存在"权利人同时是加害人"的矛盾？（如有，必须重新分析）

### 2. 构成要件是否齐全？（各维度分别检查）
- 刑法维度：是否使用构成要件检查模板？各要件是否同时具备？
- 民法维度：是否使用侵权责任/合同责任构成要件模板？
- 行政维度：是否对照法定违法构成要件？

### 3. 罪数形态 / 责任形态是否分析？（刑事维度）
- 同一主体数个行为时，是否分析想象竞合/牵连犯/吸收犯/数罪并罚？
- 是否确定处理原则（从一重罪 or 数罪并罚）？

### 4. 跨域程序是否正确？
- 刑民交叉：是否以"事实是否依赖"为核心标准？是否明确先刑后民/刑民并行？
- 行刑衔接：行政违法达刑事标准的，是否标记"应移送"并给出立案追诉标准？
- 是否分析了双向影响与先行判决可能？

### 5. 法条引用是否准确？（强事实双校验）
- 条号校验：条号是否准确（防止"第5条是数额计算规则"类错误）？
- 内容校验：内容是否与引用目的一致（防止张冠李戴）？
- 时效校验：法条是否现行有效（未被修订/废止）？
- 来源标注：是否标注来源（知识库/条文）？

### 6. 多视角对抗是否真正执行？
- 每个子问题的 Analysis 是否含【正方】→【反方】→【综合判断】三部分？
- 综合判断是否果断、有无最优解判定？

### 7. 禁止超越事实（防幻觉）
- 是否出现"证据不足""需充分证据"等无依据结论？（除非案情明确给出证据情况）
- 如需假设性分析，是否明确标注"题目/案情未提供，此处为假设性分析"？

### 8. 维度覆盖与分级护栏
- 维度路由表中的所有启用维度是否均有对应分析，无遗漏？
- 最终结论是否带红/黄/蓝分级 + 核查指引？
- 是否明确"线索发现非定罪"定位，未越界下定罪结论？

## 自检结论格式

```
多维质量自检
1. 主体身份：正确
2. 构成要件：民事/刑事均齐全
3. 罪数形态：牵连犯，从一重
4. 跨域程序：先刑后民
5. 法条引用：条号/内容/时效/来源 四校验通过
6. 多视角对抗：已执行，结论果断
7. 禁止超越事实：无无依据结论
8. 维度覆盖与分级：六维全覆盖，结论红色分级
最终结论：全部通过，可输出。
```

**只有当所有 8 项均通过后，方可输出最终研判报告。**
