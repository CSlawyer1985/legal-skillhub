# 筛查警报裁决（Screening Alert Adjudication）

一个确定性、标准驱动的技能，用于裁决针对制裁名单、政治公众人物（PEP）名单、负面媒体报道来源及类似观察名单的筛查命中。设计目标为自动排除明显误报、确认明显真报，并将真正模糊的案件连同完整证据包交由人工审查。

作为 [Claude Skill](https://docs.claude.com/en/docs/claude-code/skills) 构建，采用 [Agent Skills](https://agentskills.io/) 开放标准。

## 本技能做什么

当筛查系统将某个姓名标记为与观察名单可能的匹配时，分析师通常必须决定该匹配是真实的（真报）、虚假的（误报），还是需要进一步调查。这些警报中有很大比例明显是错误匹配——实体类型错误、常见姓名但标识符无重叠、忽略命名惯例的部分姓名匹配——但分析师仍花费大量时间将其排除。

本技能对每个警报应用确定性决策树，并得出三种结果之一：

- **真报**——被筛查方即为名单所列方
- **误报**——被筛查方并非名单所列方
- **升级**——证据不足以确定性得出任一结论；连同完整证据记录移交人工处理

## 设计属性

两项属性不可妥协：

1. **确定性。** 给定相同证据，技能得出相同结论。技能绝不权衡概率，也不使用“似乎为”/“大概为”之类的模糊措辞。规则要么触发，要么不触发。
2. **保守性。** 升级是安全的默认。除非每个前提条件均满足，否则任何规则不触发。宁可升级一个清晰案件，也不错误排除一个模糊案件。

每次裁决都产出结构化 JSON 记录和人类可读叙述，两者源自同一底层状态。JSON 用于系统摄入、质检抽样和跨案件查询。叙述用于分析师审查和案件档案。

## 组织方式

裁决按层级运行，层级越高升级的令牌消耗越高。较早层级在可行时尽早退出。

- **第 0 层**——解析与规范化。检测文字系统、语言、命名惯例；识别锚定与非锚定姓名组成部分；盘点标识符和别名。不作认定。
- **第 1 层**——硬性误报触发（无网络访问）：类型不匹配、姓名-角色不匹配（如“Jose Andrea”与“Jose Andrea Coronado”匹配）、硬性出生日期矛盾。
- **第 2 层**——结构化标识符佐证（无网络访问）：政府证件匹配、完整身份三角验证、标识符不匹配。
- **第 3 层**——定向外部研究，采用四级语言阶梯（原生文字 → 原生语言拉丁转写 → 英文区域 → 转写变体），按来源排序（仅一手/主流新闻来源可驱动认定），每个案件最多 8 次页面检索。

一份独立参考覆盖西班牙语、葡萄牙语、阿拉伯语、波斯语、俄语、东亚、日语、印尼/缅甸语及西方默认形式等命名惯例。另一份覆盖跨文字转写变体。第三份覆盖历史地名对应关系（列宁格勒/圣彼得堡、孟买/新孟买、波斯/伊朗等）。

## 安装

本技能采用 [Claude Skills 格式](https://docs.claude.com/en/docs/claude-code/skills)。使用方法：

1. 克隆或下载本仓库。
2. 将其打包为 `.skill` 文件（重命名的 zip）：`zip -r screening-alert-adjudication.skill screening-alert-adjudication/ -x "*/evals/*"`。
3. 通过你的 Claude 环境的技能安装流程上传，或将其放入适合你的设置的技能目录。

你也可以直接将技能内容用于任何支持 Anthropic 风格技能的 LLM，或将参考文件改编为用于分析师培训的独立文档。

## 范围外（v1 中有意为之）

- **行业所有权分析（OFAC 50% 规则及等效规则）。** 技能将所有权链匹配标记交人工审查。
- **负面媒体报道行为评估。** 技能确认媒体条目中的身份匹配，但不评估该行为是否构成相关风险。
- **PEP 风险分级。** 身份匹配——是；风险处置——否。
- **评分调优反馈。** 裁决记录以后可为评分调优提供输入，但那是独立分析。
- **船舶与航空器深挖。** 处理类型不匹配误报；IMO 链及更名但 IMO 相同的案件不在范围内。
