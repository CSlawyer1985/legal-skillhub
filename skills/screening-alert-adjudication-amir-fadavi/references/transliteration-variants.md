# 转写变体

同一个源语言姓名根据所用转写系统（学术、新闻、移民文件、基于发音）可产生多种拉丁拼写。当比较两个源自非拉丁来源的拉丁字母姓名时，拼写差异可能并不表示身份不同——它们可能只是表示不同的转写。

本参考收录有记录的变体模式。在以下环节使用：
- **第 0 层解析** —— 评估两个姓名成分相同或不同时
- **FP-2、FP-6、FP-7 触发决定** —— 这些规则要求明确不同，而不仅仅是拼写不同
- **第 3 层第 4 阶梯** —— 变体扫描循环遍历有记录的拼写

## 阿拉伯语来源姓名

**Mohammed 及变体** —— 均源自 محمد：
- Mohammed、Mohammad、Muhammad、Mohamad、Mohamed、Mohamet、Mehmed（土耳其语）、Mehmet（土耳其语）、Mahomet（古法语/西班牙语）

**Ahmed / Ahmad** —— 源自 أحمد：
- Ahmed、Ahmad、Achmed、Achmad

**Hassan / Hasan** —— 源自 حسن：
- Hassan、Hasan、Hassen

**Hussein / Hussain / Husayn** —— 源自 حسين：
- Hussein、Hussain、Husayn、Husein、Hosein、Hossein（波斯语拼写）

**Khalid / Khaled** —— 源自 خالد：
- Khalid、Khaled、Halid、Halit（土耳其语）

**Yusuf / Yousef / Yousaf** —— 源自 يوسف：
- Yusuf、Yousef、Yousaf、Yousuf、Yousif、Youcef（马格里布法语拼写）

**Abdullah / Abdallah** —— 源自 عبد الله：
- Abdullah、Abdallah、Abdulla、Abdalla、Abdul（截短）

**Abdul + [属性]** —— 这些是复合名，"Abd" = 仆人，"ul/al" = 冠词，属性是安拉之名。将整个复合词视为单一锚点：
- Abdul Rahman / Abdurrahman / Abdulrahman / Abd ar-Rahman —— 均为同一姓名
- Abdul Aziz / Abdulaziz / Abd al-Aziz
- Abdul Karim / Abdulkarim / Abd al-Karim

**Saleh / Salah / Saleh** —— 源自 صالح：
- Saleh、Salih、Salah（与 الصلاح 是不同姓名，但转写可能碰撞）

**Omar / Umar** —— 源自 عمر：
- Omar、Umar、Oumar（法语拼写）

**Ali** —— 源自 علي：
- 通常为 Ali；有时为 Aly。在阿拉伯语、波斯语、土耳其语、南亚语中常见——如此对待。

**定冠词 "Al-" / "El-" / "Ul-"**：前缀变体属风格差异，绝不表示身份不同。"Al-Tikriti" = "El-Tikriti" = "At-Tikriti"（转写中的太阳字母同化）。

**定冠词的连字符和大写**："Al-Qaeda" = "al-Qaeda" = "Al Qaeda" = "AlQaeda"。变体等价。

## 波斯语来源姓名

波斯语使用扩展阿拉伯字母（پ گ چ ژ）。转写有时遵循阿拉伯惯例（丢失波斯语独特字母），有时保留波斯语发音。

**Pourya / Puria / Pouria** —— 源自 پوریا：
- Pourya、Puria、Pouria、Porya

**Behzad** —— 源自 بهزاد：
- Behzad、Behzaad

**Reza** —— 源自 رضا：
- Reza、Ridha（阿拉伯语拼写）、Riza（土耳其语拼写）

**Hossein**（حسين 的波斯语拼写）：
- Hossein、Hosein、Hussein（阿拉伯化时）

**姓氏后缀：**
- -zadeh（"之子"）= 受突厥影响的转写中为 -zada、-zade
- -pour = -pur、-poor（پور 的转写）

## 西里尔字母来源姓名（俄语、乌克兰语、白俄罗斯语、保加利亚语、塞尔维亚语等）

**Alexander** —— 源自 Александр：
- Aleksandr（现代转写）、Alexander（英语化）、Aleksander、Alexandr、Olexandr（乌克兰语）

**Vladimir** —— 源自 Владимир：
- Vladimir；有时为 Volodymyr（同一斯拉夫词根的乌克兰语拼写）

**Yury / Yuri / Iurii** —— 源自 Юрий：
- Yury、Yuri、Yurii、Iurii（学术转写）、Iouri（法语拼写）

**Mikhail / Michael** —— 源自 Михаил：
- Mikhail；极少为 Michael（英语化时）

**姓氏词尾：**
- 俄语：-ov（男）/ -ova（女）、-ev（男）/ -eva（女）——男女形式指同一家族
- 乌克兰语：-enko、-uk、-chuk
- 白俄罗斯语：-onok、-enka
- 波兰语（斯拉夫语但本族拉丁字母）：-ski / -ska、-cki / -cka

**"э" / "е" / "ё" 问题：** 俄语 ё 常转写为 e（因为 ё 即使在俄语中也很少写出）。"Gorbachev" / "Gorbachëv" —— 等价。

**硬音符号（ъ）和软音符号（ь）：** 转写中常省略。不要因其缺失而扣分。

## 中文来源姓名

存在多种转写系统。同一姓名根据所用系统以及被转写的汉语方言（普通话、粤语、闽南语等）可产生差异很大的拉丁拼写。

**汉语拼音（中华人民共和国标准，现代多数语境使用）：**
- 王 → Wang；李 → Li；张 → Zhang；陈 → Chen；刘 → Liu

**威妥玛拼音（较旧，用于台湾和 1979 年前来源）：**
- 王 → Wang；李 → Li；张/張 → Chang（非 Zhang）；陳 → Ch'en；劉 → Liu

**粤语转写（香港、澳门、海外侨民）：**
- 陈/陳 → Chan（非 Chen）；黄/黃 → Wong（非 Huang）；刘/劉 → Lau（非 Liu）；周 → Chow（非 Zhou）；张/張 → Cheung（非 Zhang）

**同一人的姓名在筛查数据中可能以汉语拼音或威妥玛拼音或粤语出现**，取决于所用证件。在语境支持时将之视为变体：
- 持中国内地护照者：预期汉语拼音
- 持香港或新加坡护照者：预期粤语或闽南语拼写
- 持台湾护照者：预期威妥玛拼音或修正威妥玛拼音

**声调符号（ā á ǎ à）：** 姓名的拉丁转写中几乎从不保留。忽略。

## 朝鲜语来源姓名

存在多种罗马化系统：国语罗马字表记法（韩国现行标准，2000 年后）、McCune-Reischauer（较旧，部分语境仍使用），以及护照上的个人拼写。

- 김 → Kim（通用）
- 이 → Lee、Yi、Rhee、Ri（朝鲜拼写）、I
- 박 → Park、Pak、Bak
- 정 → Jung、Jeong、Chung、Chong
- 강 → Kang、Gang
- 조 → Cho、Jo、Joh

韩国护照常保留持有人偏好的拼写，包括较旧的 McCune-Reischauer 形式。"Lee" / "Yi" / "Rhee" 可能都是同一姓氏。

## 日语来源姓名

在赫本罗马化中大多稳定。注意：
- 长音符号：ō / ou / oh。"Saitō" / "Saitou" / "Saito" / "Saitoh" —— 同一姓名。
- "Tu" 与 "Tsu"："Matsumoto" / "Matumoto"（旧日本式罗马字）。后者在现代文件中罕见。

## 南亚来源姓名

高度多变。同一姓名来自印地语、乌尔都语、旁遮普语、孟加拉语、泰米尔语等，可有多种转写。宗教和地区模式：

- "Singh" —— 男性锡克教姓氏，非常常见
- "Kaur" —— 女性锡克教姓氏
- "Khan" —— 泛伊斯兰，南亚穆斯林社区广泛使用
- "Rahman" / "Rehman" / "Ur-Rehman" —— رحمن 的变体转写

## 希伯来语来源姓名

- "Yehuda" / "Yehudah" / "Judah" / "Juda"
- "Yosef" / "Yossef" / "Joseph"
- "Avraham" / "Abraham" / "Abram"
- "Yitzhak" / "Yitschak" / "Yitzchak" / "Isaac"

现代以色列护照使用受英语影响的拼写；较旧的宗教文件使用学术希伯来语转写。

## 如何在规则触发中使用本参考

**FP-2 / FP-6 触发决定：** 当一侧不匹配的锚点成分是另一侧成分的有记录转写变体时，这些成分**并非**明确不同。该规则**不**触发。

示例：筛查"Muhammad Yousef"对照名单上的"Mohammed Yusuf"。两个锚点（Yousef / Yusuf）都是同一阿拉伯语姓名的有记录变体。"差异"是转写，而非身份。FP-2/FP-6 不就 Yusuf/Yousef 差异触发。进入更高层。

**第 3 层第 4 阶梯变体扫描：** 循环遍历锚点姓名 + 相同语境词的有记录变体。上表是有记录变体的来源。不要发明此处未记录的变体。

## 存疑时

如果两个锚点成分之间的差异可能是转写但不确定，将其视为模棱两可（不据此触发 FP 规则），让第 2/3 层证据解决。保守姿态：升级一个误报的成本远低于放行一个真命中的成本。
