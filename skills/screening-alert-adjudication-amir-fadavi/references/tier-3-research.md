# 第三层级——定向外部研究

仅在第二层级未达成判定且案件具有现实研究路径时运行第三层级。本层级使用网络搜索和抓取来确认或否定身份。令牌高效、语言感知、来源分级、完全快照记录。

## 门禁——何时才尝试第三层级

仅在以下至少一项成立时进入第三层级：

- **G-1：至少一方存在足够独特的标识符，网络搜索可以合理地锚定。** 示例：带日期的具体职务/头衔（"2014-2017 年能源部前副部长"）、狭窄的地理足迹（有据可查运营的单一小型司法辖区）、独特职业、具名的组织隶属关系、与另一已识别方有据可查的关系。

- **G-2：名单条目中的特定可验证主张可通过一手来源确认或否定。** 示例：名单条目载明的死亡日期可通过一手来源核实；制裁解除或除名日期可通过发布机构核实；政府登记簿记录的角色变更。

- **G-3：来自第零层级的音译歧义是唯一障碍。** 源语言搜索很可能解决被筛查姓名与名单姓名是否代表同一源语言姓名的问题。

如果 G-1、G-2、G-3 **均**不成立 → 不进入第三层级直接升级。不要在网络研究无法得出结论的案件上消耗令牌。升级记录必须说明门禁未通过。

## 来源分级

只有来自分级来源的证据才能进入第三层级的判定：

- **A 级**——名单发布方自身的条目详情页；主要政府记录（公司登记簿、法院卷宗、官方公报、制裁机构新闻稿、中央银行出版物、议会记录）
- **B 级**——具有编辑标准的主流新闻媒体：路透社、美联社、法新社、BBC、金融时报、华尔街日报、彭博社，以及国家级一级媒体（《世界报》、南德意志报、NHK、读卖新闻、朝日新闻、圣保罗页报等）
- **C 级**——专业行业媒体（具有编辑标准的行业出版物）、区域内有声誉的媒体、非政府组织和政府间组织报告（FATF、联合国专家小组报告、透明国际国家报告、OCCRP 调查）
- **D 级**——其他一切（博客、社交媒体、论坛、内容农场、来源不明的网站）

**规则：**
- TP-3 和 FP-7 仅在 A 级或 B 级证据上触发。
- C 级佐证 A/B 级，但绝不单独驱动判定。
- D 级绝不进入判定记录。D 级页面可能出现在搜索结果中，但在作出贡献前即被过滤。

## 四层语言阶梯

按顺序执行各层。仅当当前层结果不足时进入下一层。"足够"指至少检索到一份直接针对身份的 A 级或 B 级来源。"不足"指：全部为 C/D 级结果，或 A/B 级结果涉及同名不同人，或无实质性命中。

### 第 1 层——母语文字、母语

**触发：** 第零层级将至少一个姓名归类为起源于非拉丁文字（阿拉伯语、波斯语、俄语、中文、韩语、日语、希伯来语、泰语、希腊语等），或将语言提示标记为非英语。

**查询构造：** 以母语文字呈现的锚定姓名 + 最具区分性的语境标识符（职务、雇主、司法辖区），自然时亦以母语呈现。

示例：
- 名单所列德黑兰个人"Mohammad Reza Hashemi，X 控股前董事"：波斯语查询，将 محمد رضا هاشمی 与组织名称的波斯语呈现组合。
- 名单所列中国实体"北京 X 贸易有限公司"：简体中文查询，将 北京……贸易有限公司 与相关行业术语组合。
- 名单所列俄罗斯个人：西里尔字母查询。

### 第 2 层——母语、拉丁字母

**触发：** 第 1 层不足，或源语言本为带变音符号的拉丁字母（土耳其语、越南语、印度尼西亚语、波兰语、捷克语等），或该语言在正式来源中同时使用两种文字（塞尔维亚语、阿塞拜疆语）。

**查询构造：** 以源国官方记录使用的标准拉丁音译呈现锚定姓名，加上以拉丁字母书写的母语语境词。

### 第 3 层——相关区域/部门的英语报道

**触发：** 第 1-2 层不足（或不适用，因为姓名本为拉丁字母英语）。

**查询构造：** 锚定姓名标准拉丁形式 + 英语语境词，偏向区域报道强的媒体。示例：路透社和美联社区域分社；全球商业的金融时报；中东北非的 Al-Monitor 和 Middle East Eye；大中华区的南华早报；俄罗斯的莫斯科时报；东亚/东南亚的日经亚洲。

### 第 4 层——音译变体扫查

**触发：** 第 1-3 层不足，且第零层级标记该姓名有据可查的音译变体（见 `transliteration-variants.md`）。

**查询构造：** 循环使用锚定姓名的有据可查变体拼写 + 前几层使用的相同语境词。不要尝试每个理论变体——只尝试变体参考文档记载为实务中常见的那些。

**注意：** 如果第零层级未标记音译歧义，则跳过第 4 层。西方起源的英语姓名不需要第 4 层。

## 检索上限

硬性上限：每个案件 **所有层级合计** 最多 8 次不同的页面抓取。指示性预算分配（按案件需要调整）：

- 第 1 层：2-3 次抓取
- 第 2 层：2-3 次抓取（如启用）
- 第 3 层：2 次抓取
- 第 4 层：1 次抓取

如果某一层解决了案件，剩余预算不使用。

如果达到上限仍未解决 → 附完整检索记录升级。

## 令牌高效搜索姿态

- 从最便宜的信息性查询开始：锚定姓名 + 单一最具区分性的语境标识符。不要以长消歧查询开场——让第一个结果告诉你简单路径是否有效。
- 如果第一个查询无结果或有歧义，通过添加第二个语境词扩展第二个查询，而非添加布尔运算符或引号。
- 不要对失败的查询以细微变体重复查询。改为向上移动阶梯。
- 如果搜索结果在标题/摘要层面看起来有希望，完整抓取该页面一次。不要抓取同一来源的多个变体。

## 快照记录

每份为判定作出贡献的检索页面都被捕获进证据记录：

- URL（精确）
- 检索时间戳（ISO 8601 UTC）
- 来源等级（由你评估的 A/B/C/D）
- 提取段落（支持判定的具体文本）
- 贡献标记（该检索是否促成 TP-3 或 FP-7 触发，或促成其不触发）

这就是使"相同证据 → 相同决定"可执行的原因。即使实时网络已变化，案件仍可对照快照记录重新审计。

## TP-3——外部佐证的身份匹配

**前置条件：**
- 已检索到至少一份直接针对身份的 A 级或 B 级来源
- 检索到的来源确认名单一方的特定识别事实，且这些事实与被筛查方匹配（如特定期间在特定组织的职务；相关时点的国籍；有据可查的人生事件）

**触发条件：**
- **两个独立的 A 级或 B 级来源**各自确认至少一个特定识别事实，且这些事实共同将名单一方与同名其他人区分开
- 且检索记录中没有 A 级或 B 级来源与身份相矛盾

**结果：** TP（命中），已确认

**审计：** 列出每份作出贡献的 A/B 级检索（URL + 时间戳 + 提取段落）、各自确认的特定识别事实，以及综合事实将被筛查方识别为名单一方的明确推理。

**为何需要两个独立来源：** 单一来源确认容易受来源错误、来源复用（一家媒体抄袭另一家）和来源操纵的影响。两次独立的 A/B 级确认为保守标准。

## FP-7——外部确立的独立身份

**前置条件：**
- 已检索到至少一份 A 级或 B 级来源，确立被筛查方为有据可查的独立个人或实体

**触发条件：**
- 检索到的来源确立的被筛查方传记事实与名单一方在至少一个锚定标识符上相矛盾——相关期间的职业、相关时点的国籍、年龄段、有据可查的人生事件
- 且该矛盾是直接的，而非从证据缺失推断

**结果：** FP（误报），已排除

**审计：** 作出贡献的检索、具体矛盾、确认矛盾是正面的（而非"未找到证据表明他们是同一人"），以及明确推理。

**为何要求"正面识别"：** 没有证据表明被筛查方是名单一方，不同于有证据表明他们是不同的人。FP-7 要求后者。示例：

- 被筛查的"Hassan Rouhani"与同名名单一方匹配：一份 A 级检索确立被筛查方为曼彻斯特一名 28 岁软件开发者，无任何政治角色，而名单一方是伊朗前总统。直接矛盾。FP-7 触发。
- 检索到一份关于名单一方的 A 级来源，但未找到任何关于被筛查方的信息。这**不是** FP-7——这是证据缺失。升级。

## 多名单与跨名单信号

如果同一被筛查姓名在多个名单上都有命中（如 SDN + PEP + 负面媒体），且不同名单上的条目在标识符上存在差异，这表明匹配发生在通用姓名上，支持对全部命中的 FP。如果不同名单上的条目显然是同一目标（标识符一致），且被筛查方与一致画像匹配，则支持 TP。

这是语境推理，而非独立规则。它以"跨名单相关性"进入审计记录，并告知 TP-3 或 FP-7 是否拥有其所需证据。

## 退出第三层级

- **TP-3 触发** → 输出 TP 判定，停止，制作审计记录
- **FP-7 触发** → 输出 FP 判定，停止，制作审计记录
- **达到检索上限或所有适用层级耗尽而未触发** → 附完整检索记录升级

升级记录明确说明运行了哪些层级、每层检索到什么、为何判定每层不足，以及何种具体信息本可使判定达成。这是分析师的起点。
