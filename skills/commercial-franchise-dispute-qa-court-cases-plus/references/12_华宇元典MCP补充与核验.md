# 华宇元典法律数据 MCP · 知识库动态补充与核验通道

> **定位**：本知识库（01-11）为静态底稿。对知识库中缺失或需更新的法律、法规、司法解释、法院案例，通过**华宇元典法律数据 MCP**（连接名 `yuandian-mcp`，当前状态：connected）实时补充；并用其**幻觉检测**能力兜底核验本库及生成内容中的法条/案号引用准确性。
> **信源性质**：MCP 返回内容属**动态外部数据库检索结果**，非本库预置权威底稿。引用时须标注"华宇元典法律数据 MCP 检索（检索时间：YYYY-MM-DD）"，并区分"MCP检索补充"与"本库预置文件"。

---

## 一、可用工具清单（与商业特许经营问答直接相关）

### A. 法律法规检索与核验
| 工具（MCP 名） | 用途 | 特许经营问答场景 |
|---|---|---|
| `yuandian_law_vector_search` | 法律法规**语义检索**（法条级），可按时效性、一级效力级别、实施日期范围过滤 | 补充本库缺失的法规/司法解释条文；核实某法条现行有效版本 |
| `yuandian_rh_ft_search` / `yuandian_rh_ft_detail` | 法规主题检索 / 法规详情 | 检索特定法规全文及修订沿革 |
| `yuandian_rh_fg_search` / `yuandian_rh_fg_detail` | 法律释义/法理检索与详情 | 条文理解与适用争议 |
| `yuandian_rh_qwal_search` | 裁判文书以外其他权威文献检索 | 学术观点、审判参考 |

### B. 法院案例检索与详情
| 工具（MCP 名） | 用途 | 特许经营问答场景 |
|---|---|---|
| `yuandian_case_vector_search` | 案例文书**语义相似检索**，默认覆盖普通案例+权威案例，支持按案件类别、案由、法院层级、审判程序、地域、结案年份过滤 | **核心**：补充本库 `08` 未收录的特许经营/加盟合同纠纷案例、最新裁判要旨 |
| `yuandian_rh_case_details` | 案例/文书**详情**（需先由检索取得文档 ID） | 获取命中案例的全文、裁判理由、"本院认为"原文 |

### C. 幻觉检测（兜底核验）
| 工具（MCP 名） | 用途 | 特许经营问答场景 |
|---|---|---|
| `yuandian_hall_detect` | 自动抽取文本中引用的**法规/法条/案号**，与权威库比对语义一致性、核验时效性，输出"一致/不一致/未命中"+权威原文 | **强制**：生成任何含法条/案号的法律意见前，先经此工具校验本库 `01-11` 及草稿中的引用，防止编造或过期引用 |

### D. 企业合规尽调（加盟主体核查）
| 工具（MCP 名） | 用途 | 特许经营问答场景 |
|---|---|---|
| `yuandian_rh_company_info` / `yuandian_rh_company_detail` | 企业名称/信用代码检索与聚合详情 | 核查特许人是否为"企业"、是否存续、有无行政处罚/失信（验证"两店一年"、主体资格、诚信状况） |
| `yuandian_rh_enterpriseWritList` / `WritAgg` | 企业涉诉文书列表 / 分布统计 | 核实特许人诉讼仲裁情况（条例第22条第10项披露义务） |
| `yuandian_rh_enterprisePunishment` / `ExecutedPerson` / `Executions` 等 | 行政处罚、被执行人、失信名单等 | 特许人合规风险画像 |

> 注：D 类工具为企查查/元典企业库接口，用于具体案件的特许人尽调，非知识库规范内容，但在代理具体加盟纠纷时可配合本库规范使用。

## 二、使用工作流（每次问答触发）

1. **先查本库**：问答时先在 `09_裁判规则速查表.md` + `01-11` 预置文件中检索，命中则直接引用并标注本库文件。
2. **MCP 补缺**：出现以下任一情形，调用对应 MCP 工具补充，并将结果**回写本库对应文件或新建增补小节**：
   - 本库无相关法规/司法解释条文 → `yuandian_law_vector_search`
   - 本库 `08` 未收录某类案例或需最新裁判 → `yuandian_case_vector_search` → 必要时 `rh_case_details` 取全文
   - 用户问及具体特许人主体资格/合规 → D 类企业接口
3. **幻觉检测（强制）**：对将交付给用户、且含法条/案号/裁判要旨的内容，先经 `yuandian_hall_detect` 校验；若输出"不一致/未命中"，须复核修正后方可交付。
4. **标注与溯源**：MCP 补充内容须标注"华宇元典法律数据 MCP 检索（YYYY-MM-DD）"；回写知识库时注明来源，便于后续复核。

## 四、引用与合规提示

- **信源区分**：本库 `01-11` 为预置权威底稿；`12` 所述 MCP 通道为**动态外部检索**，二者信源性质不同，正式文书引用时须分别标注。
- **时效性**：MCP 检索结果以检索时点为准；法规/案例可能更新，重要结论仍建议通过官方公报/裁判文书网最终核验。
- **禁止编造**：MCP 未检索到的内容，不得凭记忆生成法条或案号；`hall_detect` 判"未命中"的引用须删除或注明"待人工复核"。
- **企业数据隐私**：通过 D 类接口核查特许人信息时，仅用于受托案件办理，遵守用户隐私与文件操作规则，不主动向无关方披露。

> 以上内容基于华宇元典法律数据 MCP 当前可用工具集整理（连接名 `yuandian-mcp`），工具名以 MCP 实际注册名为准；接口若有增减，应通过 `yuandian_list_apis` / `yuandian_get_api_doc` 核验最新清单。
