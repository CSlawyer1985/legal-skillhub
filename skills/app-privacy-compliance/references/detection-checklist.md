# App/小程序 隐私合规检测清单

> 适用范围：国内上架 App（iOS/Android）、微信小程序、其他平台小程序
> 版本：2025 年版（已更新《个人信息保护合规审计管理办法》相关要求）

---

## 模块 A：隐私政策/协议文本检测

### A1 基础存在性
- [ ] App/小程序内有独立可见的隐私政策入口（首次启动弹窗 + 设置页常驻链接）
- [ ] 隐私政策文本语言为简体中文（面向中国大陆用户）
- [ ] 隐私政策发布日期和版本号清晰
- [ ] 首次使用前必须展示且须主动确认（禁止默认勾选）

### A2 必要内容完整性
- [ ] 运营者名称、联系方式、地址
- [ ] 收集的个人信息类型（逐一列明）
- [ ] 每类信息的收集目的和使用方式
- [ ] 数据保存期限
- [ ] 数据共享/委托处理/转让说明（含第三方 SDK 列表）
- [ ] 跨境传输说明（如有）
- [ ] 未成年人保护专项条款
- [ ] 用户权利说明（查阅/复制/更正/删除/撤回同意/注销账号）
- [ ] 投诉举报渠道（含监管部门渠道）
- [ ] 更新/通知机制说明

### A3 敏感信息专项
- [ ] 精确位置信息处理有单独告知
- [ ] 生物特征信息（如人脸）有单独告知+同意
- [ ] 健康医疗信息有单独告知+同意
- [ ] 金融账户信息有单独告知+同意
- [ ] 未成年人信息有监护人同意机制

---

## 模块 B：权限合规检测

### B1 权限声明
- [ ] App 的 AndroidManifest.xml / iOS Info.plist 中权限声明与实际使用一致
- [ ] 每个权限均有对应的使用说明（Purpose String/理由说明）
- [ ] 无"预置"但从不使用的权限

### B2 权限申请时机
- [ ] 敏感权限在功能触发时才申请（非安装启动时批量申请）
- [ ] 申请前有弹窗解释用途
- [ ] 用户拒绝权限后 App 不强制退出、不频繁重复申请

### B3 权限最小化验证

## 模块 C：SDK 合规检测

### C1 SDK 清单盘点
- [ ] 已梳理 App 集成的全部第三方 SDK 列表
- [ ] 确认每个 SDK 的个人信息收集范围
- [ ] 隐私政策中已列明所有 SDK（名称+目的+收集类型）

### C2 高风险 SDK 核查
- [ ] 广告 SDK 版本已通过广告联盟官方合规认证
- [ ] 统计分析 SDK（友盟等）已开启合规模式
- [ ] 推送 SDK 已配置合规参数（不在后台静默激活）
- [ ] 支付 SDK 数据处理协议已签署

### C3 SDK 初始化时机
- [ ] 所有 SDK 在用户同意隐私政策后才初始化（禁止在用户同意前初始化收集数据的 SDK）

## 模块 D：用户权利机制检测

### D1 权利行使入口
- [ ] 查阅个人信息的路径（设置 > 个人信息 > 查看）
- [ ] 复制/导出个人信息的功能
- [ ] 更正/修改个人信息的入口
- [ ] 删除个人信息的明确操作流程
- [ ] 撤回同意（具体到每类权限/功能）
- [ ] 注销账号功能（含注销后数据处理说明）

### D2 响应机制
- [ ] 用户权利请求响应时限承诺（建议≤15个工作日）
- [ ] 有人工客服或在线渠道接收权利请求

---

## 模块 E：技术安全检测

### E1 传输安全
- [ ] 全站 HTTPS（禁止 HTTP 明文传输个人信息）
- [ ] 证书有效且未过期
- [ ] TLS 版本 ≥ 1.2

### E2 存储安全
- [ ] 敏感信息本地存储加密（密码/Token/证件号等）
- [ ] 无日志明文记录敏感信息
- [ ] 数据库敏感字段加密存储

### E3 数据最小化技术实现
- [ ] 前端不收集超出业务需要的字段
- [ ] 接口返回值经过脱敏处理
- [ ] 设备标识符使用 OAID（Android）替代 IMEI

---

## 模块 F：特殊场景检测

### F1 未成年人保护
- [ ] 注册时有年龄验证机制
- [ ] 14岁以下用户需监护人同意
- [ ] 针对未成年用户有数据最小化处理

### F2 定向推送/算法推荐
- [ ] 用户可关闭个性化推送
- [ ] 基于个人信息的广告推送有退出机制
- [ ] 符合《互联网信息服务算法推荐管理规定》

### F3 人脸识别专项
- [ ] 有替代方案（非强制使用人脸）
- [ ] 单独告知 + 单独同意
- [ ] 存储有加密保护
- [ ] 满足《人脸识别技术应用安全管理规定》（2025年生效）

### F4 微信小程序专项
- [ ] wx.getUserProfile 接口调用前有明确告知
- [ ] 已配置《小程序隐私保护指引》并通过微信审核
- [ ] getLocation 接口说明已填写
- [ ] 涉及敏感信息的 API 均已在隐私协议中声明

---

## 模块 G：上架审核材料清单

### G1 应用市场通用
- [ ] 隐私政策 URL（外链形式，可访问）
- [ ] 应用功能描述与实际功能一致
- [ ] 截图中无违规信息

### G2 iOS App Store 专项
- [ ] App Privacy Details 填写完整（数据类型/用途/是否关联用户）
- [ ] ATT 权限使用了标准弹窗（如需追踪）
- [ ] NSPrivacyAccessedAPITypes 隐私清单（Privacy Nutrition Label）已更新

### G3 工信部 App 备案
- [ ] ICP 备案主体信息完整
- [ ] App 功能分类正确
- [ ] 开发者资质文件齐全
- [ ] 已提交 App 备案（2023年后上线 App 强制要求）

## 检测结果评级

| 等级 | 标准 | 建议 |
|------|------|------|
| 🟢 合规 | 全部模块无问题 | 维持现状，定期复查 |
| 🟡 低风险 | 存在形式瑕疵，无实质违规 | 30天内完成整改 |
| 🟠 中风险 | 存在被投诉/被通报风险 | 7天内启动整改 |
| 🔴 高风险 | 存在被下架/被行政处罚风险 | 立即整改后才能上架/运营 |
