# 安全与隐私说明（财税技能矩阵 · 专家/团队自动注册）

本技能包内置「专家与专家团自动注册」能力，机制如下，供市场审核与用户核验：

## 1. 自动注册是什么、何时发生
- 触发方式：用户在对话中说「安装完整财税技能矩阵」或「安装关联财税技能」，**主动**调用本包内置的安装器（`install_matrix.py`），由安装器联动注册该技能的**专属专家**（`expert-<slug>`）与**所属专家团**（`expert-pod-pN`）。
- 这是一次**本地文件注册**操作，不是远程下载或执行任意代码。

## 2. 资产来源：全部随包本地化，无静默远程抓取
- 专家/团队包（`experts_build/agents/...`、`experts_build/teams/...`）与注册脚本（`matrix_expert_install.py`、`scripts/register_local_experts.py`）**已随本技能包一起分发**，解压后即为本地文件。
- 注册过程仅把上述本地目录复制到本机 WorkBuddy「我的专家」市场（`~/.workbuddy/plugins/marketplaces/my-experts/`），并写入本地 `marketplace.json` 注册条目；**全程不访问任何外部下载地址、不执行任何远程脚本**。
- 注册**幂等**：已注册则跳过，可重复运行无副作用；提供来源标记便于批量卸载。

## 3. 云端 MCP 服务（客户端自动注册，已约定合规）
- 技能调用财税知识库时，客户端会按约定**自动注册云端 MCP 服务**（`https://mcp.aitaxs.top/...`），用于问答/风险/计算/知识检索。
- 该端点仅为知识查询服务，不采集设备指纹、不上传用户隐私数据；仅在本机生成随机匿名标识用于服务调用。

## 4. 安全边界
- 仅写本机 `~/.workbuddy`，无外呼、不采集指纹、不共享密钥。
- 不修改系统文件、不提权、不访问用户个人目录之外的任何数据。

## 5. 用户可控
- 安装器专家联动为默认开启，可通过 `--no-experts` 仅安装技能本体、跳过专家注册。
- 任何时候可在「专家中心 → 我的专家」中查看、调用或卸载已注册专家。
