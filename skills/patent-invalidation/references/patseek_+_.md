# PatSeek 检索式语法详细参考

> 本文档详细说明 PatSeek Bool 检索接口（`POST /v1/search`）支持的检索式语法。

---

## 布尔运算符

| 写法 | 含义 | 示例 |
|---|---|---|
| `A B`（空格） | AND，所有词都必须出现 | `固态电池 电解质` |
| `A AND B` | 显式 AND，效果相同 | `低空空域 AND 无人机` |
| `A OR B` | 任一出现即命中 | `人工智能 OR 机器学习` |
| `(A OR B) C` | 括号控制优先级 | `(固态 OR 全固态) 电池` |

---

## 字段前缀

| 前缀 | 字段 | 匹配方式 |
|---|---|---|
| `AP=(...)` | 申请人 | match_phrase |
| `IPC=(...)` | IPC 分类号 | match + and |
| `PID=(...)` | 公开号 | term 精确 |
| `AN=(...)` | 申请号 | match_phrase |
| `AD` | 申请日 | range |
| `PD` | 公开日 | range |
| `NOT=(...)` | 排除 | must_not |

前缀支持 `=` 和 `:` 两种写法，如 `AP=(华为)` 等同于 `AP:(华为)`。

---

## 各字段详细用法

### 申请人 AP=

```
AP=(华为)                          # 单个申请人
AP=(比亚迪)                        # 单个申请人
AP=(上海交通大学)                   # 单个申请人
AP=(华为 OR 中兴)                  # 多个申请人用 OR 连接
AP=(上海市第一人民医院 OR 上海交通大学附属第一人民医院)
```

- 多个申请人用 `OR` 连接，不支持 `AND`
- 全称/简称均可尝试，取决于数据库存储
- match_phrase 匹配，名称须与数据库一致

### IPC 分类号 IPC=

```
IPC=(H01M)                         # 单个 IPC
IPC=(H01M OR H02J)                 # 多个 IPC
IPC=(B60W OR G05D1 OR G08G)        # 多个领域
```

⚠️ **只用前 4 位**，6 位或更长的代码在部分数据上会漏匹配：

```
✅ IPC=(H01M)
❌ IPC=(H01M10)
❌ IPC=(H01M10/0525)
```

常用 IPC 速查表：

| 领域 | 代码 | 领域 | 代码 |
|---|---|---|---|
| 电池 | H01M | 通信 | H04L, H04W |
| 储能/充电 | H02J | 生物医药 | A61K, A61P |
| 人工智能 | G06N | 机器人 | B25J |
| 图像处理（软件） | G06T, G06V | 光学 | G02B |
| 图像采集（硬件） | G03B, H04N23 | 半导体 | H01L |
| 自动驾驶 | B60W, G05D1 | | |

### 日期 AD= / PD=

`AD` = 申请日，`PD` = 公开日。

```
AD>=2020              # 2020 年及以后
AD>2019               # 同上（2019年底之后）
AD<2015               # 2015 年初之前
AD<=2015              # 2015 年底及以前
AD=2023               # 2023 整年
AD=202301             # 2023 年 1 月
AD=20230115           # 精确日期
AD=2020-2023          # 范围：2020 到 2023
AD=2020 to 2023       # 范围（to 写法）
```

日期格式支持：`YYYY`、`YYYYMM`、`YYYYMMDD`、`YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY.MM.DD`

### 公开号 PID=

```
PID=(CN101971633A)
PID=(CN101971633A OR CN222118806U)
```

- `pid` 是 keyword 类型，term 精确匹配，速度最快
- 大小写不敏感，系统自动匹配原样/大写/小写变体

### 申请号 AN=

```
AN=(CN200980108398)
AN=(CN200980108398 OR CN202110012345)
```

⚠️ 13 位申请号需去掉最后一位（校验位）：`2019205174826` → `201920517482`

### 排除 NOT=

```
固态电池 NOT=(液态)
图像识别 NOT=(医疗 OR 医学)
```

### 专利号自动识别（无需前缀）

直接输入专利号，系统自动识别并同时检索 pid 和 appnum：

```
CN101971633A       # 中国专利（带后缀）
CN101971633        # 中国专利（无后缀）
101971633          # 纯数字，默认补 CN
201920517482       # 申请号（12位）
US10234567B2       # 美国专利
```

## 关键词全文检索

无字段前缀时，在以下字段全文检索（权重从高到低）：

```
title^3 > abstract^2 > claims > description > pid > appnum
```

匹配规则：所有关键词都必须出现（`operator:and`），不要求连续或顺序。引号内视为精确短语。

```
固态电池              # "固态" 和 "电池" 都必须出现
"固态电解质"          # 精确短语匹配
(固态 OR 全固态) 电池  # 括号分组 + OR 扩展
```

## 完整组合示例

```
# 关键词
固态电池 电解质

# 申请人限定
AP=(华为) 5G

# 多申请人
AP=(华为 OR 中兴 OR 爱立信) 通信

# IPC 领域
IPC=(H01M) 固态电池

# IPC 多领域
IPC=(H01M OR H02J) 储能

# 日期范围
飞行汽车 AD>=2020

# 日期区间
IPC=(H01M) AD=2018-2023

# 公开日
AP=(华为) PD>=2024

# 申请人 + IPC + 日期（三重限定）
AP=(比亚迪) IPC=(H01M) AD>=2020

# 精确专利号
PID=(CN101971633A)

# 多个专利号
PID=(CN101971633A OR CN222118806U OR CN115036562A)

# 申请号
AN=(CN200980108398)

# 关键词语义扩展（推荐写法）
(狗 OR 猫 OR 宠物) (清洗 OR 洗浴 OR 护理) (装置 OR 设备 OR 机器)

# 排除
(固态 OR 全固态) 电池 NOT=(液态 OR 液体)

# 组合
AP=(华为) IPC=(B60W OR G05D1) AD>=2022 NOT=(仿真 OR 模拟)
```

## 注意事项

1. **发明人无专用前缀**：`inventors` 字段存在但没有 `IN=` 处理，只能通过关键词全文命中（精度有限）。
2. **IPC 用 4 位**：`H01M10` 等长代码可能漏匹，统一用 `H01M`。
3. **申请人用短语匹配**：名称须与数据库一致，全称/简称效果可能不同。
4. **13 位申请号去末位**：校验位需手动去掉。
5. **page_size 上限 100**：单次最多返回 100 条。

## 日期字段实测要点（v1.0.9）

- **现有技术死线 `PD<YYYYMMDD`**：实测有效（光学案 `PD<20160218` 命中 4867 条）。无效检索务必加此死线，否则混入申请日后文献全部不可用。
- **申请日范围 `AD=YYYY-YYYY`**：文档支持，用于重复授权检索（同申请人±2 年）。若返回异常，回退为两个 `AD>=` / `AD<=` 组合或逐年检索。
- **抵触申请组合 `AD<申请日 PD>申请日`**：实测可返回结果，但需逐条用 `is_conflict`（申请日早于目标 + 公开日晚于目标）二次判定，不可仅凭 total 计数。
- **多特征严格 AND 返回 0**：冷门领域/特征过多时易过约束。`run_all.py` v1.0.9 已支持自动降级为 OR 宽松式（见 `scripts/run_all.py` `build_prior_art_query_loose`）；手工检索时建议先跑宽式（少 AND、OR 同义扩展）再逐步收紧。
