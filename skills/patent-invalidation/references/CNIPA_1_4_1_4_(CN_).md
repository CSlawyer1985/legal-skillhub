# CNIPA 公布公告系统获取（CN 全文与附图）· G6 落地

> 适用：本技能 G6「检索数据源」条款中，**针对中国专利（CN）的官方全文 PDF 与原始附图获取通道**。
> 配套脚本：`scripts/cnipa_epub.py`

## 1. 为什么需要这条通道

内置 PatSeek 引擎的 `patent` 详情接口目前**仅稳定返回 CN 文本**（权利要求、说明书文字、著录项），
**不含原始附图**，也不返回可直接标注的 PDF 图像。而无效分析的两个核心环节都依赖附图/全文：

- **G7 特征比对同色标注**：需要在涉案专利与对比文件的**附图**上用同色引线/色块标同一特征；
- **G2 证据具体出处**：需要精确到"对比文件说明书段落号 / 图号 / 权利要求号"。

因此，凡涉及 **中国专利**（无论是目标专利本身，还是作为对比文件的 CN 文献）需要权威全文与原始附图时，
应优先经 **国家知识产权局「中国专利公布公告系统」** 取得——它是官方的、社会公众免注册的权威来源。

## 2. 系统说明（epub.cnipa.gov.cn）

- 网址：`http://epub.cnipa.gov.cn/`（建议用现代浏览器访问）
- 性质：国家知识产权局官方「中国专利公布公告系统」，**无需注册**即可查询与下载单件 PDF。
- 数据范围：1985-09-10 至今的**发明公布、发明授权（1993 年前为发明审定）、实用新型**
  的著录项目、摘要、摘要附图及相应**专利单行本**（含说明书全文 + 附图）；外观设计单行本/全部图形。
- 提供：高级查询、IPC/LOC 分类查询、事务数据查询。

## 3. 获取流程（两种路径）

### 路径 A：下载 PDF（权威专利单行本，含说明书 + 附图）
1. 打开 `http://epub.cnipa.gov.cn/`；
2. 在「专利公报查询」框输入**公开号**（如 `CN111121359A`）或**申请号**，点击查询；
3. 在结果页点击对应条目进入文献页；
4. 点右上角 **「下载PDF」** → 弹出**图形验证码**（"请输入图片中的四字成语或阿拉伯数字答案"）→
   输入答案（四字成语用简体；阿拉伯数字题中 `减=−`、`乘=×`、`除以=÷`）→ 确认后下载。

> ⚠️ **验证码是自动化主要障碍**：纯脚本下载会被验证码拦截。需要批量/全自动时，
> 采用"浏览器（Playwright/ Selenium）+ 人工或打码服务过验证码"的方案作为扩展，
> 本技能默认提供"尽力尝试 + 明确手工回退"的稳健策略。

### 路径 B：在线浏览附图（无需下载 PDF、无需验证码）
- 检索结果页点击条目后，系统提供**在线图像浏览器**，可直接逐页查看说明书与附图图像。
- 做 G7 同色标注时，可在此**截图或另存附图页**，再在图像上叠加同色标注（见 `特征比对与附图标引.md`）。
- 该路径不受 PDF 验证码限制，是**快速取得附图**的首选。

## 4. 配套脚本 `scripts/cnipa_epub.py`

```bash
# 打印检索主页 / 直达链接 / 在线浏览与下载说明（最常用，无需联网即可给出指引）
python cnipa_epub.py url CN111121359A

# 尽力下载专利单行本 PDF（联网且未触发验证码时成功；否则回退手工步骤）
python cnipa_epub.py pdf CN111121359A --out ./pdfs

# 批量：从文件逐行读取公开号（# 开头为注释）
python cnipa_epub.py batch pub_list.txt --cmd pdf --out ./pdfs
```

脚本行为：
- 自动归一化公开号（`111121359A` → `CN111121359A`）；
- `pdf` 子命令先取首页提取 token，再尝试 `patentPdf?pubNo=...&token=...`；
- 若返回非 PDF（验证码/访问限制），**明确打印手工下载步骤**，绝不静默伪造成功；
- 请在国家知识产权局可达的网络环境中运行（开发沙箱通常不可达，属正常）。

## 5. 证据清单中的标注规范

经本通道取得的文献，在证据清单与比对表中应注明来源与日期，例如：

> 证据 X：CN111121359B《冷却系统》，国家知识产权局中国专利公布公告系统
> （epub.cnipa.gov.cn）专利单行本 PDF，授权公告日 2021-10-12，下载日期 2026-07-30。

该 PDF 本身即**官方专利单行本**（含说明书全文与附图），作为对比文件时其附图页可直接用于 G7 同色标注；
作为目标专利时其全文用于权利要求解构与特征映射。

## 6. 与其他途径的关系（G6 总览）

| 文献类型 | 首选通道 | 备注 |
|----------|----------|------|
| 中国专利 文本/检索 | PatSeek `bool` / `patent` | 快速画像、检索式、相似度 |
| 中国专利 全文 PDF / 附图 | **CNIPA 公布公告系统（本通道）** | PatSeek 无附图，故 CN 全文/附图走官方 |
| 国外/全球专利 | PatSeek `semantic` | 覆盖 JP/US/EP/KR 等 |
| 国外文献 缺全文/附图 | Google Patents / JPO / Espacenet 等官方途径 | G6 不排斥，按可访问性选择 |
| 涉案自认引用国外文献 | 直接采用涉案说明书背景技术 | 自认效力，无需另行检索 |
