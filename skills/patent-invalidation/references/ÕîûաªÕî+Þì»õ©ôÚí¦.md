## 〇、为什么需要这个专项

化学 / 医药 / 生物领域是**专利无效宣告的高发地**和**高难度地**：
- 占 CNIPA 年度十大案件 / 最高法知识产权法庭典型案例的**约 40%**
- 攻击点与机械 / 软件领域**显著不同**：化合物确认、晶型表征、马库什支持、补充实验数据、医药用途、组合物协同效果等均为**化学医药专属议题**
- 证据形态特殊：实验数据（X-射线衍射、活性测试、药代动力学、生物利用度等）须符合**形式完整性**
- 创造性判断有特殊规则：**合理成功预期**、**改进动机**、**预料不到的技术效果**
- 优先权"相同主题"在化学领域有**专门细化**（化合物、马库什、晶型、数值范围各自规则不同）

把通用 M0–M11 直接套用到化学医药案件会**漏掉关键攻击点 / 用错证据 / 误判创造性**。本文件给出：
1. 化学医药专利的 **5 大攻击维度** vs 通用 8 条理由
2. **化合物 / 晶型 / 马库什 / 医药用途 / 组合物** 5 类专项规则
3. **实验数据** 形式完整性（7 个雷区）
4. **补充实验数据** 可补的边界
5. **优先权"相同主题"** 化学领域细化
6. **典型案例索引**（真实可溯源）
7. **化学医药专项攻击点 checklist**（与 `analyze_target_patent.py --domain chem` 联动）

## 一、化学医药专利的 5 大攻击维度

| 维度 | 适用 | 关键条款 | 化学医药特殊性 |
|------|------|----------|----------------|
| **充分公开（化合物质）** | 化合物专利 | 法26.3 | 确认 + 制备 + 用途效果三维度（详见 §二） |
| **支持（马库什/晶型/医药用途）** | 宽概括专利 | 法26.4 | 效果实施例分布 / 晶型表征 / 用途机理（详见 §三、四、五） |
| **创造性（合理成功预期）** | 化合物 / 医药用途 | 法22.3 | 不以"无合理预期"推翻最接近现有技术（指导案例276号） |
| **补充实验数据** | 任何化学医药专利 | 《审查指南》第二部分第十章 3.5.1 | 仅可证明"本领域技术人员从原申请可得"的效果 |
| **形式完整性** | 实验数据类证据 | 司法解释 + 审查指南 | 样品/测量/人员/方法/数据处理（详见 §七） |

## 二、化合物专利 · 充分公开三维度

### 2.1 核心规则

《审查指南》第二部分第十章 3.1 明确：化合物专利的充分公开须覆盖**三个维度**——

1. **确认（identity）**：能确认请求保护的化合物本身
2. **制备（preparation）**：能制备该化合物
3. **用途 / 效果（use / effect）**：能确认化合物的用途和/或效果

> 三维度中任一**实质性缺失** → 法26.3 充分公开不成立。

### 2.2 进攻要点

| 三维度 | 缺失情形 | 攻击方向 |
|--------|----------|----------|
| **确认** | 仅给出化合物名称/分子式/结构式，无表征数据 | 主张"所属领域技术人员无法唯一确认"（典型：自造型号/代号无定义） |
| **制备** | 仅有路线图无具体步骤，或关键中间体 / 试剂 / 条件缺失 | 主张"无法实现"；或具体实施例无法重复 |
| **用途 / 效果** | 用途宽泛（如"用于治疗疾病"）无效果数据；医药用途仅有机制推断无活性数据 | 主张"无法确认能否实现所述用途"（典型：仅有 IC50 体外数据无体内数据） |

### 2.3 经典反面教材

**磷酸芦可替尼（第 580173 号，CNIPA 十大案件）**——维持有效。
请求人主张化合物未充分公开，合议组认为：化合物结构 + 关键中间体 + 制备方法 + 用途效果均完整 → 维持。

**马昔腾坦（第 48183 号，2021 十大）**——维持有效（修改文本）。
表格化合物充分公开判断：**"从优先权制度目的出发明确马库什/具体化合物优先权认定规则；从确认、制备、用途效果三维度阐明表格化合物充分公开判断规则"**。

### 2.4 进攻策略

- **优先攻"用途 / 效果"维度**：化合物专利最常见的弱点是用途宽泛 + 缺效果数据
- **"确认"维度可从"自造代号"切入**（如"SAM910"型化合物，参玛巴洛沙韦前药案）
- **"制备"维度要找出关键缺失**（如关键中间体未公开 / 反应条件超出常规）

## 三、马库什权利要求 · 支持问题

### 3.1 何为马库什

马库什权利要求（Markush claim）是用**共同的结构特征 / 共同的作用方式**将多个化学实体集合在同一权利要求中，常见表达：
> "一种化合物，其为通式 I 所示化合物、其药学上可接受的盐、其溶剂化物、其前药……其中 R₁ 选自 H、C₁–C₆ 烷基、卤素……；R₂ 选自……"

### 3.2 攻击方向 · 三种情况

| 情况 | 攻击方向 | 判例 |
|------|----------|------|
| **马库什过宽** | 法 26.4 支持：效果实施例不足以覆盖所有涵盖的化合物 | 玛巴洛沙韦前药（第 47328 号）维持：前药与母体效果分布足以支持 |
| **马库什 vs 具体化合物优先权** | 法 29 优先权：在后申请为具体化合物，前申请为马库什——能否享有优先权？ | 马昔腾坦：马库什 → 具体化合物享优先权需"相同主题"判断 |
| **马库什 vs 生物电子等排** | 法 22.3 创造性：不能机械以"生物电子等排"反推显而易见 | 马昔腾坦案：警惕后见之明 |

### 3.3 关键判例

**玛巴洛沙韦前药（第 47328 号，2021 十大）**——维持有效：
> "基于说明书公开整体内容（尤其效果实施例分布），厘清前药与母体化合物及各自效果关系，准确评价能得到的技术效果，从而认定马库什权利要求是否得到支持。"

**马昔腾坦（第 48183 号，2021 十大）**——维持有效（修改文本）：
> "从优先权制度目的出发明确马库什/具体化合物优先权认定规则；从确认、制备、用途效果三维度阐明表格化合物充分公开判断规则；围绕区别特征引入是否显而易见展开，**避免机械以'生物电子等排'反推后见之明**。"

### 3.4 进攻 checklist

- [ ] **效果实施例数量**：马库什涵盖 N 个具体化合物，效果实施例数 < N×0.3 通常支持不充分
- [ ] **效果分布均匀性**：实施例集中在某一子结构 / 取代基，**其他子结构无代表数据** → 支持受限
- [ ] **结构 vs 效果可预期性**：马库什范围内的结构差异是否会导致效果不可预期？如可预期则支持更宽
- [ ] **优先权文件对应**：在后申请的具体化合物是否在前申请的马库什"明确记载"或"直接、毫无疑义确定"
- [ ] **生物电子等排陷阱**：自己不要被"反推显而易见"反噬——严格过技术启示三校验

## 四、晶型专利 · 特殊规则

### 4.1 晶型专利的特殊性

晶型（多晶型物）是化合物的特定固体形态，由晶格结构决定：
- **特性表征**：X-射线粉末衍射（PXRD）、差示扫描量热（DSC）、热重分析（TGA）、红外光谱（IR）
- **稳定性 / 溶解度 / 生物利用度**：可与无定形 / 其他晶型有显著差异
- **制备方法**：结晶溶剂、温度、搅拌速率、晶种等关键参数

### 4.2 充分公开的特殊要求

- **晶型确认**：必须给出可重复的 PXRD 图（峰位 2θ + 相对强度），不能仅"得到一种晶型"
- **晶型稳定性 / 效果**：仅给"晶型 I"不够，需说明与已知晶型相比的**实质优势**（稳定性、溶解度、纯化便利等）
- **制备可重现**：结晶条件须可重复

### 4.3 攻击方向

| 攻击点 | 法条 | 主张 |
|--------|------|------|
| 晶型无法唯一确认 | 法26.3 | PXRD 数据不全 / 峰位不唯一 / 含重叠峰 |
| 晶型效果无优势 | 法26.4 / 法22.3 | 与已知晶型相比无可测量的优势（稳定性、溶解度等） |
| 制备不可重现 | 法26.3 | 结晶条件缺失 / 关键参数未公开 |
| 预料不到技术效果未证实 | 法22.3 | 仅给"晶型 I"的存在，无"晶型 I 比晶型 II / 无定形更好"的数据 |
| 使用公开 + 补交实验数据 | 法26.3 / 法22.3 | 攻击补交数据"与原申请公开内容紧密关联"的成立性（见 §六） |

### 4.4 经典案例

**呋喹替尼晶型（第 581990 号，CNIPA 十大）**——宣告无效：
> "使用公开 + 补交实验数据 + 已知化合物晶型创造性"。主攻"使用公开证据链"与"预料不到技术效果"门槛。

## 五、医药用途发明 · 瑞士型与第二医药用途

### 5.1 权利要求形态

- **"化合物 X 在制备治疗 Y 疾病药物中的应用"**（瑞士型，瑞士 1970s 判例）
- **"化合物 X 用于治疗 Y 疾病的方法"**（方法权利要求，2017 审查指南修订后受保护）
- **"化合物 X 的第二医药用途"**（已知化合物 X 治疗新的疾病 Y）

### 5.2 创造性判断特殊规则

> **核心判例**：缬沙坦 / 沙库巴曲组合物（指导案例 276 号，最高法 (2019)最高法知行终 235 号）

最高法明确：
- **"合理成功预期"是判断有无技术启示（第三步）的考量因素**，**而非**确定最接近现有技术（第一步）的要件
- 合理成功预期只需达到"**有尝试的必要**"，不要求"成功的确定性/高度盖然性"
- 最高法明确：请求人**不要企图以"无合理成功预期"推翻最接近现有技术的认定**，应在**第三步围绕技术启示与尝试动机**组织论证

### 5.3 进攻策略

- **主攻现有技术是否给出"改进动机"**：对比文件是否提出"该化合物还可用于 X 疾病"？
- **主攻"合理成功预期"在第三步的位置**：不能作为第一步"最接近现有技术"的反驳点
- **效果数据是核心**：第二医药用途的创造性多依赖"在 Y 疾病上效果优于现有治疗手段"
- **数据完整性**：剂量、给药方式、患者群体、终点指标、对照——缺一不可

### 5.4 经典案例

**贝达喹啉（喹啉衍生物，第 47812/48150 号）**——修改文本基础上维持有效：
> "医药用途发明创造性；改进动机与合理成功预期。基于说明书实验数据证明力，客观评价技术贡献。"

**索磷布韦前药（4W118971，第 588818 号，2025 典型案例）**——维持专利权有效：
> "手性化合物权利要求保护范围理解；新颖性评价中现有技术认定；化合物创造性。"

## 六、补充实验数据 · 可补的边界

### 6.1 规则

《审查指南》第二部分第十章 **3.5.1**：
> 申请日后补交的实验数据，所证明的技术效果须是**本领域技术人员能从原申请公开内容中得到的**。

### 6.2 进攻方向

- **补交数据超过原申请可得范围** → 不能被采信，相应效果主张不成立
- **补交数据 vs 原申请数据** 体系不一致（如不同实验模型 / 不同指标 / 不同处理）→ 不可比较
- **补交数据是"事后验证"而非"本领域技术人员能预期"** → 不能承认其证明力

### 6.3 经典案例

**依达拉奉右莰醇注射用浓溶液（4W119517，第 588094 号，2025 典型案例）**——维持有效：
> "优先权'相同主题'；组合物协同增效作用认定；组合物创造性。基于优先权立法本意，明晰在后申请新增效果数据、数值范围不同情形下的'相同主题'判断；**厘清协同效果判断思路与证明规则**。"

**克唑替尼 / C-MET 多晶型物（第 581892 号）**——维持有效：
> "证据 8 与本专利效果数据来自**不同实验模型**，无法直接换算比较。"

## 七、实验数据 · 形式完整性

### 7.1 7 个雷区（数据被不予采信的高频原因）

| # | 雷区 | 后果 | 防范 |
|---|------|------|------|
| 1 | **样品来源不明** | 不可重复 / 不可比 | 写明"X 化合物，批号 Y，购自 Z 厂商 / 自行合成" |
| 2 | **测量条件缺失** | 数据不可信 | 仪器型号、参数（波长、流速、温度）、时间点 |
| 3 | **实验人员 / 主体不明** | 真实性存疑 | 标注"实验由 XX 实验室完成 / XX 人员操作" |
| 4 | **方法不公开** | 不可重复 | 引用文献 / 自创方法须详细写明步骤 |
| 5 | **数据处理缺失** | 结果不可信 | 统计方法、n 值、SD / SE、显著性检验 |
| 6 | **孤立图谱 / 单一数值** | 无上下文 | 给原始数据 + 处理后的图表 + 文字解读 |
| 7 | **不同模型数据直接换算** | 不可比 | 严格用同一实验模型做对照 |

### 7.2 进攻策略

- **孤立图谱攻击**：实验数据仅给单一图谱无上下文字段 → 不予采信
- **不同模型攻击**：对比文件效果数据 vs 本专利数据来自不同实验体系 → 不可换算
- **保密数据攻击**：以"保密"为由不开示 → 不能作为授权 / 维持依据（《审查指南》第二部分第十章 3.5.1）

### 7.3 进攻 checklist

- [ ] 实验数据是否给出**样品来源**（批号、厂商、自行合成路径）？
- [ ] 测量条件（仪器、参数、时间点）是否完整？
- [ ] 实验人员 / 主体是否可追溯？
- [ ] 方法是否可重复（步骤详细 / 引用公开方法）？
- [ ] 数据处理（统计方法、n、SD/SE、显著性）是否透明？
- [ ] 是否含**孤立图谱 / 单一数值**而无上下文？
- [ ] 与最接近现有技术对比的数据是否来自**同一实验模型**？

## 八、优先权"相同主题" · 化学领域细化

### 8.1 规则

《审查指南》第二部分第十章 4.1：
> 在后申请要求在先申请的优先权，须满足"**相同主题**"——在后申请的发明人 / 申请人 / 主题与在先申请**完全一致**，或为在先申请的**直接、毫无疑义确定**的变体。

### 8.2 化学领域四类情形

| 情形 | 能否享优先权 | 判例 |
|------|--------------|------|
| **化合物 → 同一化合物** | ✅ 享 | 通常情形 |
| **化合物 → 不同盐 / 酯 / 前药** | ⚠️ 视具体 | 若盐 / 酯在前申请"明确记载或直接、毫无疑义确定"则享 |
| **马库什 → 马库什内具体化合物** | ⚠️ 视具体 | 若具体化合物在前申请马库什"明确记载"则享；隐含公开不够 |
| **晶型 → 另一晶型** | ❌ 通常不享 | 晶型独立于化合物，需前申请明确记载该晶型 |
| **化合物 → 医药用途** | ⚠️ 视具体 | 若前申请已给出该医药用途则享 |
| **数值范围 → 端点 / 子范围** | ⚠️ 视具体 | 端点在前申请明确记载则享；中间值不一定 |
| **组合物 → 协同效果数据** | ⚠️ 视具体 | 协同数据不能补交扩大保护范围（见 §六） |

### 8.3 进攻 checklist

- [ ] **化合物层**：在后申请化合物是否在前申请"明确记载"或"直接、毫无疑义确定"？
- [ ] **晶型层**：前申请是否给出该晶型的 PXRD / DSC 等表征数据？**仅给化合物不给晶型不享**
- [ ] **马库什层**：在后申请具体化合物在前申请马库什中是否"明确记载"？
- [ ] **数值范围层**：端点值是否在前申请明确？子范围是否可"直接、毫无疑义"推出？
- [ ] **医药用途层**：前申请是否披露该医药用途？

### 8.4 经典案例

**依达拉奉右莰醇注射用浓溶液（4W119517，第 588094 号）**——维持：
> "明晰在后申请新增效果数据、数值范围不同情形下的'相同主题'判断。"

## 十、化学医药专项 · 攻击点 checklist（`analyze_target_patent.py --domain chem` 联动）

### 10.1 化合物层

- [ ] 权利要求是否覆盖**多个化合物 / 一类化合物**（如马库什 / 表格 / 通式）？
- [ ] 独立权利要求的化合物是**新化合物**还是**已知化合物的新用途 / 新晶型 / 新盐**？
- [ ] 化合物确认数据是否完整（核磁 / 质谱 / 元素分析 / 红外）？
- [ ] 制备方法是否**可重复**（关键中间体、试剂、反应条件）？
- [ ] 用途 / 效果数据是否齐备（活性、选择性、毒性、药代）？

### 10.2 晶型层

- [ ] 权利要求是否限定**特定晶型**（如"晶型 I"）？
- [ ] 晶型表征数据是否齐备（PXRD / DSC / TGA）？
- [ ] 晶型 vs 其他晶型 / 无定形**优势数据**是否给出？
- [ ] 制备方法（结晶溶剂、温度、晶种）是否可重复？

### 10.3 马库什层

- [ ] 权利要求是马库什式？涵盖化合物数量级？
- [ ] 效果实施例数 vs 涵盖化合物数（建议 ≥ 0.3）？
- [ ] 效果实施例分布是否均匀？或集中在某一子结构？
- [ ] 共同结构 / 共同作用方式是否明确？
- [ ] 优先权文件（前申请）是否给出马库什 / 涵盖哪些具体化合物？

### 10.4 医药用途层

- [ ] 权利要求是**化合物 / 组合物** 还是**瑞士型医药用途**？
- [ ] 用途是"已知化合物的第二医药用途" 还是"新化合物 + 用途"？
- [ ] 用途效果数据是否齐备（剂量、给药方式、患者群体、终点指标、对照）？
- [ ] 是否可主张"现有技术无改进动机 / 无合理成功预期"？——**注意是第三步**（参指导案例 276 号）

### 10.5 组合物层

- [ ] 权利要求是组合物（多组分）？各组分范围？
- [ ] 组合物是否主张**协同效果**？协同证据是否齐备？
- [ ] 与各组分单独使用 vs 组合使用的对比数据？

### 10.6 优先权层

- [ ] 在后申请是否要求优先权？优先权日？
- [ ] 化合物 / 晶型 / 马库什 / 数值范围 / 医药用途的"相同主题"判断（详见 §八）

### 10.7 实验数据层

- [ ] 实验数据是否齐备（样品来源、测量条件、人员、方法、数据处理）？
- [ ] 是否含孤立图谱 / 单一数值？
- [ ] 与最接近现有技术的对比数据是否来自**同一实验模型**？
- [ ] 是否为申请日后补交？补交数据是否"本领域技术人员从原申请可得"？

### 10.8 创造性辅助判断

- [ ] 是否陷入"生物电子等排"式后见之明？（自我警告）
- [ ] 技术启示三校验（问题同源 / 结构兼容 / 公知常识证据化）是否过？

## 十三、常见误区（化学医药特有）

| 误区 | 错误 | 正确 |
|------|------|------|
| ❌ 用"无合理成功预期"反推最接近现有技术 | 第一步就被驳回 | 合理成功预期是**第三步**判断技术启示的考量（指导案例276号） |
| ❌ 攻击"马库什化合物都应能制备" | 攻击不到点 | 应攻"效果实施例分布不足" / "马库什涵盖化合物不享有优先权" |
| ❌ 攻击"晶型表征数据不全"但本专利已给 PXRD | 攻击失败 | 应攻"晶型 vs 其他晶型 / 无定形的优势无数据" |
| ❌ 用"不同实验模型数据"主张创造性 | 数据不可比 | 须用**同一实验模型**做对照实验（克唑替尼案） |
| ❌ 攻击"申请日后补交数据不采信" | 普遍错误 | 补交数据**可被采信**只要"本领域技术人员从原申请可得"（《审查指南》3.5.1） |
| ❌ 攻击"医药用途专利创造性"忽略第三步 | 论证不完整 | 必须过技术启示三校验（问题同源 / 结构兼容 / 公知常识证据化） |
| ❌ 攻击"晶型专利仅给晶型 I 存在" | 攻击点偏 | 须攻"晶型 I 比已知晶型 / 无定形**实质优势**"无数据 |
| ❌ 用孤立的图谱 / 数值主张攻击 | 不予采信 | 须有完整上下文字段支持 |

## 十四、推荐工作流（M0–M11 化学医药特化版）

1. **M0 任务确认**：化合物 / 晶型 / 马库什 / 医药用途 / 组合物？商业目的？
2. **M1 目标专利解构**：
   - `analyze_target_patent.py --domain chem`（专项 checklist）
   - 识别权利要求类型（化合物 / 晶型 / 马库什 / 医药用途 / 组合物）
   - 检索优先权文件 + 审查档案
3. **M2 法律状态**：无效宣告历史（如有则不可重复）
4. **M3 证据检索**：
   - PatSeek + IPC A61K/C07D/C12N 主路径
   - **化学医药专项关键词扩展**（§12）
   - 化合物通用名 + 商品名 + 药理机制名（多角度）
   - 晶型：用 PXRD 表征数据反查
5. **M4 理由组合**：
   - 主攻：化合物充分公开三维度 / 马库什支持 / 晶型效果门槛
   - 辅助：创造性（第三步 + 合理成功预期）/ 优先权不成立
6. **M5 特征映射**：
   - 化合物层：结构特征 + 取代基 + 立体化学
   - 晶型层：PXRD 峰位 + DSC 熔点
   - 医药用途层：疾病 + 给药方式 + 剂量
7. **M6 各理由论证**（按 §一–§十专项规则）
8. **M7 证据链组织**：
   - 实验数据形式完整性（§七）
   - 补交数据边界（§六）
9. **M8 请求书整合**
10. **M9 程序策略**：化学医药案件口审技术辩论多，**优先安排有技术背景的代理人**
11. **M10 质量自检**：过 §10 化学医药专项 checklist
12. **M11 交付**
