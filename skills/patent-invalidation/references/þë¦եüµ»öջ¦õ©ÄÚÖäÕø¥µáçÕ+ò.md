# 特征比对与附图标引（同色标注）规范

> 本规范为 v1.0.3 新增改进（G7），与 §3.5「特征映射比对」、§3.3「证据体系」、M5「特征映射比对」配套使用。
> 目的：无效宣告请求的核心说服点在于"对比文件公开了涉案专利的哪些技术特征"。单纯文字比对易被合议组认为"指向模糊"而不予考虑（见 §3.5 与第七节避坑）。本规范要求特征比对时**结合附图**、对**相同技术特征采用统一彩色标记**，生成可直观对照的"特征对照图"，使同一特征在涉案专利附图与对比文件附图上以同色呼应，便于合议组一眼看出对应关系。

---

## 一、色板（全案统一，不得混用）

| 颜色 | 十六进制 | 含义 | 适用特征示例 |
|------|----------|------|--------------|
| 红 | `#E63946` | 散热器 / 冷凝器（制冷剂散热部件） | 散热器、冷凝器、放热器、热交换器 |
| 蓝 | `#1D6FB8` | 压缩机 | 压缩机、压缩机构部 |
| 绿 | `#2A9D4A` | 送风装置 / 叶轮 / 风扇 | 送风机、离心风扇、轴流风扇、叶轮 |
| 紫 | `#7B4FB5` | 旋转轴线 / 方向轴 | 旋转轴线、第1方向、第2方向、法线 |
| 橙 | `#E08A1E` | 分隔部 / 面板 / 壁部 | 分隔部、面板、壁部、挡板、分隔板 |
| 灰 | `#6B7280` | 安装面 / 壳体 / 收纳室 | 设置面、安装面、壳体、机械室、收纳室 |
| 青 | `#0FA3B1` | 气流方向 | 吸气口、排气口、气流路径、风路 |

**硬性规则**：
1. 同一技术特征在所有图中（涉案专利图、各对比文件图、对照图）必须使用**同一颜色**。
2. 不同特征不得混用同色；颜色仅用于"对应关系"标注，不改变原图技术含义。
3. 色板在全案（请求书、比对表、对照图、口审PPT）中保持一致，首次出现处附"图例/色板说明"。

---

## 二、附图结合比对步骤（M5 必做）

1. **标图号**：列出涉案专利权利要求每一项关键技术特征，标注其在说明书附图中的**图号与标号**（如"散热器1，见说明书图1、图2"）。
2. **定位对比文件对应特征**：对每件对比文件，定位同一/对应特征所在的**图号与标号**。
3. **同色标注 + 并排成图**：在涉案专利附图与对比文件附图上，以同色引线/色块标注同一特征，左右或上下并排生成"特征对照图"。
4. **比对表增列**：在特征映射比对表中增列 **"附图依据（涉案图号 / 对比文件图号）"** 列，与 §3.5 的"证据具体出处（文献段落号/图号/权利要求号）"列互补——前者解决"在图里哪个位置"，后者解决"对比文件哪里公开了"。

---

## 三、特征对照图生成指引

- **优先**：使用涉案专利 / 对比文件**原始附图**（PDF 页或图片）叠加同色标注（引线 + 色块 + 标号）。应**尽量取得原始附图**——若 PatSeek 未返回附图 / 全文（如国外文献 `patent` 接口仅稳定返回 CN），依 G6 启用其他检索途径（专利局官方公报、专利数据库门户等）补全原始附图与说明书全文。
- **原始附图确实不可得时**（经其他途径亦无法获取）：依据说明书**文字描述绘制示意性 SVG schematic**，按上述色板标注各特征位置与相对关系（上/下/侧/轴向），并明确注明"**示意图，依据说明书附图 X–Y 绘制，非原图**"。
- 对照图须直观呈现：相同特征**同色**、相对位置关系（上/下/侧/轴向）一致或可对应；可在图旁以文字点出"差异特征"（未以同色呼应的特征）。

---

## 四、与"证据具体出处"（G2）的关系

- **证据具体出处（G2，§3.5）**：解决"对比文件**哪里**公开了"——填列文献段落号 / 图号 / 权利要求号。
- **附图依据（G7，本规范）**：解决"在**图里哪个位置**"——填列涉案图号 / 对比文件图号，并以同色标注。
- 二者在比对表中并列，共同满足 M10 自检第 6 项（特征映射表完整 + 每项特征标注具体出处），并额外提供可视化对照图，显著降低"指向模糊"风险。

---

## 五、示例（冰箱冷却系统类）

涉案专利 Claim 1 关键特征与色板映射（示意）：

| 特征 | 色板 | 涉案图号/标号 | 对比文件1（CN1877232A）图号/标号 |
|------|------|---------------|-----------------------------------|
| 散热器（冷凝器） | 红 | 图1–2，标号1 | 说明书，冷凝器13 |
| 压缩机 | 蓝 | 图1–2，标号2 | 冷媒压缩机12 |
| 送风装置（离心风扇） | 绿 | 图1–2，标号3（叶轮31） | 散热风扇18（轴流） |
| 旋转轴线（第1方向） | 紫 | 图1–2，RA | —（对比文件为水平轴流，轴线方向不同→差异特征） |
| 分隔部/面板 | 橙 | 图1–2，标号5（面板51） | 罩体/管道（非同一构造） |

> 注：上表中"旋转轴线（紫）"在对比文件中为水平方向，与涉案专利"垂直（法线方向）"不同，故在对照图中以紫线分别标出"方向不同"这一**区别特征**，正是创造性三步法第②步要剥离的区别技术特征。
