# 理由组合策略（无效宣告的复杂性核心）

无效宣告区别于答复/复审的关键在于**理由可组合、可佯攻、可博弈**。本文件给出组合设计的决策框架。

## 一、组合设计总原则
1. **主攻过硬**：至少一条理由证据确凿、论证充分（通常新颖性或创造性，证据最硬）。
2. **辅助牵制**：1–2 条辅助理由用于牵制专利权人、引出有利事实、覆盖不同审查维度。
3. **避免逻辑冲突**：多项理由的论证前提不得互斥。例如同时主张"权利要求不清楚(无法确定的含义A)"与"依含义A不具备创造性"——须先解决清楚性再谈创造性，或明示"即便依专利权人可能解释"。
4. **不为数量**：理由多≠胜率高；证据薄弱的理由稀释整体说服力。
5. **商业目的匹配**：全无效→多理由全覆盖；部分无效/缩权→聚焦特定权利要求；谈判筹码→保留强力理由作为威慑。

## 二、典型组合模板
| 场景 | 主攻 | 辅助 | 目的 |
|------|------|------|------|
| 有单篇实质相同文献 | 新颖性(法22.2) | 创造性(兜底)、清楚性 | 一击致命，创造性兜底 |
| 仅有多篇组合 | 创造性(法22.3) | 充分公开(法26.3)、支持(法26.4) | 攻不显而易见 + 说明书层面削弱 |
| 授权时补入特征 | 修改超范围(法33) + 新颖性(法22.2) | 创造性 | **两难陷阱**：承认其一即陷另一 |
| 说明书披露不足 | 充分公开(法26.3) | 创造性、缺必特(细则23.2，旧20.2) | 从"无法实现"与"缺特征"双杀 |
| 权利要求含糊 | 不清楚(细则22，旧20.1) + 创造性 | 支持(法26.4) | 佯攻引出唯一解释便于比对 |
| 专利权人可能缩权 | 创造性(针对原文本) | 预备：针对修改后文本补证/超范围 | 反向利用修改 |
| 外观设计 | 不相同/不近似(法23.1) | 组合对比不成立(法23.2) | 双维度攻 |

## 三、两难陷阱（高阶）
针对授权程序中补入的权利要求特征 X：
- 主张 A：X 超出原始申请记载 → 法33修改超范围 → 专利权无效。
- 主张 B：X 已被对比文件 Y 公开 → 法22.2 无新颖性 → 专利权无效。
- 专利权人若承认"X 从原申请可得"（反驳 A），则等于承认 X 被 Y 公开（坐实 B）；若否认则陷于 A。
- 注意：提出 A 常作**佯攻**，真实主攻为 B；口审中借专利权人自述锁定事实。

## 三·甲、优先权基础不支持（窗口期攻击 · 法29 / 细则34-36，旧细则31-33）

**定位与法律落点（v1.1.0 明确）**：当目标专利要求优先权（外国优先权 / 本国优先权 / PCT）时，**优先权基础是否"清楚地记载"了在后申请请求保护的技术方案（相同主题）**是一项关键攻击点。注意：**"优先权不成立"本身不是法定无效理由**（细则69.2 无效理由清单中无此项），其法律落点必须表述为——**某项权利要求不能享受优先权 → 其现有技术判断基准日从优先权日退回申请日 → 优先权日与申请日之间的"窗口期"内公开的证据成为可用现有技术 → 该权利要求相对于窗口期证据不具备新颖性（法22.2）/创造性（法22.3）**。请求书中不得将"优先权不成立"写作独立无效理由，否则可能被指理由表述不规范。

**请求书标准表述句式（模板）**：
> "证据X的公开日（YYYY-MM-DD）介于本专利优先权日（YYYY-MM-DD）与申请日（YYYY-MM-DD）之间。经逐项核验，优先权基础（优先权申请号××）并未清楚地记载权利要求Y的技术方案（具体：特征Z未记载/新增数值范围/新增效果），故权利要求Y不能享受优先权，其新颖性、创造性的判断基准日应为申请日。证据X构成权利要求Y的现有技术，权利要求Y相对于证据X（或证据X与公知常识的结合）不符合专利法第22条第2款/第3款的规定。"

**适用情形**：
- 要求 PCT / 外国优先权，但优先权基础文本未明确记载某从属权利要求的具体特征（数值范围、子结构、子组合）。
- 在后申请新增效果实验数据 / 数值范围（医药化学领域多见，参 2025 年度 4W119517 依达拉奉右莰醇案）。
- 本国优先权基础在先申请已授权缴费领证 → 依规视为未要求优先权。

**攻击路径**：
1. 调取优先权基础全文（WIPO PATENTSCOPE / 各国专利局）。
2. 逐项核验目标权利要求特征是否在优先权基础中"清楚地记载"（相同主题，含明确的效果/数值）。
3. 未记载的特征 → 该权利要求不能享受优先权 → 判断基准日退回申请日。
4. **用优先权日—申请日窗口期的公开文献，以法22.2/22.3 攻击该项权利要求**（检索时在 PatSeek 检索式中用 `AD<申请日 PD>=优先权日` 圈定窗口期）。

**与主攻的关系**：与创造性/充分公开等主攻不冲突、可独立成立，适合作为"主攻+佯攻+独立"三层包围中的独立攻击点，迫使专利权人就优先权基础逐项举证；但请求书表述上必须挂上窗口期证据与法22.2/22.3 落点（见上方句式）。

**skill 落点**：M1 须尽量获取优先权日与优先权基础编号；M3 对"可能不享受优先权"的从属权利要求，专门检索优先权日—申请日窗口期文献；M4 将其列为独立攻击点并按标准句式落成请求书表述。注：优先权核验高度依赖优先权基础全文，skill 检索能力可定位编号与同族，但**全文逐字核验须人工**（尤其 PCT 文本）。


## 四、逻辑冲突自查
- 同时主张"不清楚"与"依某含义无创造性"：须先处理清楚性，或声明"退一步讲即便作某解释"。
- 同时主张"不支持(概括宽)"与"新颖性(某具体实施例被公开)"：概括宽针对整体，新颖性针对具体实施，通常可并存，但表述需分层。
- 同时主张"重复授权"与"本专利自身不具备新颖性"：指向不同（重复授权比的是另一专利，新颖性比的是现有技术），可并存。

## 五、决策输出物
完成组合设计后，产出《理由组合与策略建议书》含：
- 主攻理由 + 证据 + 把握度评估
- 辅助理由 + 作用（佯攻/兜底/牵制）
- 逻辑冲突说明与规避
- 证据检索缺口与补充方向
- 程序节奏（补充窗口、口审、诉讼）
