# 证据组合与证明标准

## 一、证据类型与适用场景
| 类型 | 说明 | 典型用途 | 形式注意 |
|------|------|----------|----------|
| 专利文献 | 公开日明确、最稳 | 新颖性/创造性主证 | 公开日须早于申请日（优先权日） |
| 非专利文献 | 论文/手册/标准/会议 | 创造性辅助、公知常识 | 发表日核查 |
| 使用公开 | 销售发票、产品、展会、宣传册、检测报告 | 新颖性/创造性（无文献时） | 须固定来源与时间，形成证据链 |
| 优先权文件/原始申请 | 原始申请文本、优先权证明 | 法33超范围、法26.3/26.4、优先权 | 调阅授权档案 |
| 公知常识证据 | 技术词典、手册、教科书 | 证明区别特征属常规手段 | 口审辩论终结前可补 |

## 二、时间节点硬约束
- 所有现有技术/使用公开证据的**公开日（或销售/使用日）必须早于目标专利申请日**；有优先权的，早于**优先权日**。
- 这是新颖性、创造性、使用公开类证据的生命线，检索与固定时第一优先核查。

## 三、证据链组织（使用公开尤其关键）
单份证据薄弱时，用多维度证据相互印证：
- 产品销售：合同 + 发票 + 物流 + 产品实物/照片 + 检测报告
- 展会公开：展位图 + 宣传册 + 媒体报道 + 参展记录
- 技术文献：论文 + 引用 + 同期产品手册
达到**"高度盖然性"**证明标准（参考"涂装后耐蚀性高强度部件"案、"呋喹替尼晶型"案）。

## 四、形式合法性
- **域外证据**：经所在国公证机关公证，并经中华人民共和国驻该国使领馆认证；**2023-11-07 起《取消外国公文书认证要求的公约》对中国生效，公约成员国的域外证据可以 Apostille（海牙认证/附加证明书）替代领事认证**，办理周期与费用显著降低，但仍须预留认证时间（建议证据固定后尽早启动）；非公约成员国仍走领事认证。外文附规范中文译本。
- **译文**：外文证据须提交中文译文，译文本体与原文一致。
- **公证/原件**：完善证据法定形式的公证文书、原件可在口审辩论终结前补充。

## 五、证据组合策略
- **新颖性**：优先找"单篇实质相同"文献，避免用组合去否新颖性。
- **创造性**：2+篇现有技术与公知常识组合；设计"最接近现有技术 + 区别特征来源 + 结合动机"的完整链条。
- **反向利用专利权人修改**：专利权人缩范围后，可补新证证明修改后方案仍缺创造性，或揭露其修改超范围（细则73（2024版；旧细则69）/法33 瑕疵——无效程序中修改不得扩大保护范围）。
- **禁反言利用**：授权审查中申请人对技术效果/范围的限制性陈述，用于解释权利要求或证伪创造性。

## 六、证明标准小结
- 文献类：公开日清晰 → 高度盖然性易达。
- 使用公开类：须证据链闭合、相互印证、无合理疑点 → 达高度盖然性。
- 专利权人仅质疑但未举证的，若请求人已尽举证责任，不足以否定证明力（参考"高强度部件"案）。

## 七、化学/医药领域实验数据反证的形式规范（高风险雷区）

化学、医药、生物领域常以实验数据证明或反证技术效果（尤其公开不充分 法26.3、创造性 法22.3 的效果比对）。此类数据须满足形式完整性，否则合议组不予采信：

1. **信息完整**：数据须包含样品来源、测量/实验条件、实验人员（或实验主体）、具体实验方法与数据处理过程；孤立的数据图谱、无上下文的单一数值通常不被采信。
2. **实验可比性**：用于与最接近现有技术进行效果比对的数据，须来自**同一实验模型/方法**；将不同实验（不同原理、条件、表达方式）得到的结果用公式换算后直接比较，不符合本领域常规认知，缺乏比较基础（参考"克唑替尼/C-MET 多晶型物"案，第 581892 号：证据8 与本专利效果数据来自不同实验模型，无法直接换算比较）。
3. **可验证与可质证**：实验过程、各批次结果、数据处理应清晰记载、相互印证；主张保密的实验数据，与无效理由/答辩有关的内容须向对方开示并给予质证机会，拒绝开示的保密内容不能作为授权/维持依据。
4. **补交数据边界**：申请日后补交的实验数据，所证明的技术效果须是本领域技术人员能从原申请公开内容中得到的（《专利审查指南》第二部分第十章 3.5.1）。

> 实务提示：化学/医药案件请求人若仅以"公式换算""申请日后他人文献的数值"主张无预料不到效果，而未提供同实验基础的可比对数据，该主张通常被合议组否定。证据组织时应优先采用与最接近现有技术相同的实验方法做对照实验，并完整披露实验过程与数据处理。
