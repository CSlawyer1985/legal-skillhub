# 参数特征实质公开（软件复现）· 专项

> 适用：以**参数/数值范围**限定权利要求保护范围的专利（光学成像系统、镜头、半导体结构、机械尺寸公差等）。
> 配套：`references/无效理由体系与论证要点.md` §2.1、`references/特征比对与附图标引.md`（G7）。
> 典型案件：第 581571 号无效决定（4W117759「光学成像系统」ZL201610090398.1，2025 年度十大案件，宣告全部无效）。

## 1. 为什么需要这条专项

该类专利的**结构特征**往往已被现有技术公开，真正的保护重心落在**参数范围**（如 f/HEP、HOS/f、矢高位移比、曲率半径比、光学总长等）。而现有技术文件通常**不会用文字直接记载全部参数**。争议焦点即：**对比文件未文字记载的参数，能否被认定为"实质公开"**。

专利法意义上的现有技术公开，不限于对比文件**直接记载**的内容，还包括**本领域技术人员可从对比文件直接地、毫无疑义地确定的内容**。当参数为结构参数（曲率、厚度、材料、间隔）确定后可由本领域**通用软件**直接仿真求得的导出量时，该参数即属于对比文件实质公开的内容。

## 2. 官方"四维度"审查规则（第 581571 号决定确立）

当事人自行通过软件仿真复现所得计算结果，其可靠性从四个维度审查：

| 维度 | 审查要点 | 通过标准 |
|---|---|---|
| ① 软件来源 | 是否合法、安装是否规范无瑕疵 | 排除人为编造/修改软件风险 |
| ② 软件类型 | 是否本领域权威通用类型 | 结果具公信力（如光学领域 ZEMAX） |
| ③ 软件功能 | 是否用基础功能复现（非自编程序/二次设计） | 结果不受版本差异影响 |
| ④ 操作适配 | 是否准确采用对比文件记载的数据、默认设置更改是否符合对比文件实际情形 | 结果不受操作人变化干扰 |

**补强**：多版本软件（如 ZEMAX2014 + ZEMAX2024）计算结果相互印证，进一步验证可靠性。

**反证规则**：若有相反证据证明建模存在实质性偏差、计算结果偏离对比文件真实参数，其证明力应重新评估。

## 3. 在 skill 工作流中的落点

| 模块 | 动作 |
|---|---|
| M1 目标解构 | 识别权项是否为"参数限定型"；标注参数为结构导出量还是独立测量量 |
| M3 检索 | 用结构特征（透镜片数/屈光力/非球面/反曲点等）检索最接近现有技术，而非仅按参数检索 |
| M5 特征映射 | 结构特征逐项映射（G2 出处 + G7 附图依据）；参数特征标注为"实质公开（需软件复现）" |
| M6 理由 | **主攻创造性（法22.3）**：区别=参数范围，实际解决=参数区间设定，启示=参数为结构导出量、常规优化；**辅助新颖性（法22.2）**：参数被对比文件实质公开（软件复现路径） |
| M7 证据 | 附软件复现报告（建模数据来源、软件版本、计算过程、结果），或在 1 个月补充期内补 |

## 4. skill 能力边界（重要）

**本技能不具备光学/结构仿真计算能力**（无 ZEMAX 等专业软件集成）。因此：
- skill 能完成：结构特征检索与映射、定位区别特征为参数、构造创造性论证（参数=结构导出量→常规优化/公知常识）、识别新颖性的软件复现路径。
- skill 不能完成：实际运行 ZEMAX 对对比文件实施例复现并输出数值结果。

**实务建议**：参数限定型案件在 skill 产出请求书骨架后，须由**人工/光学专家**用通用软件对对比文件实施例建模复现，取得数值结果作为证据补强；并在口审中演示。skill 应在请求书与策略备忘录中**明确标注"需软件复现报告补强"**的待办。

## 5. 论证句式模板

**创造性（主攻）**：
> 权利要求1相对于证据1（最接近现有技术）的区别仅在于参数范围 P1–P3。该等参数为透镜曲率/厚度/材料/间隔等基础结构参数确定后、可由本领域通用光学设计软件（ZEMAX）直接仿真求得的导出量，属常规优化手段。证据2、3（大立光 2013）均以参数限定保护范围，表明该撰写模式为本领域惯常。本领域技术人员在证据1公开结构基础上经常规仿真调整即可得到落入所述范围的参数，无需创造性劳动，故权利要求1不具备创造性。

**新颖性（辅助，对齐官方路径）**：
> 证据1实施例公开了完整结构。权利要求1所限定的 f/HEP、HOS/f、Σ│InRS│/InTL 等参数，本质上为前述结构参数确定后经本领域通用软件可直接、毫无疑义地确定的导出量，构成证据1的实质公开。据此权利要求1相对于证据1不具备新颖性。（附 ZEMAX 复现报告，见证据X）
