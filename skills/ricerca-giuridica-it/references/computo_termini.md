# 期限计算：规则，而非算术

正确计算期限的规则，附规定这些规则的条款出处。**本文件不计算到期日**：本技能绝不凭记忆计算具体日期（见 SKILL.md"效力核验"和"程序策略"部分）。它展示*方法*——适用哪条规则、需要哪些数据、在哪里核实——以便专业人士在日历、实际天数和案件通知上自行计算。计数结果始终为"待核实"。

带 Normattiva 永久链接的条款出处已在语料库中核实；标记 *(待核实)* 的条目不在语料库中，使用前须在官方来源上确认。

## 1. 三条一般计算规则

| 领域 | 规则 | 出处 |
|---|---|---|
| 民事程序期限 | 起算日（dies a quo）不计入；末日计入；节假日计入期限；如**到期日**适逢节假日，依法顺延至下一个非节假日；对在庭外进行的文书，顺延同样适用于**星期六** | 《民事诉讼法典》第155条（1940年10月28日第1443号皇家法令）—— https://www.normattiva.it/uri-res/N2Ls?urn:nir:stato:regio.decreto:1940-10-28;1443~art155!vig= |
| 刑事程序期限 | 通用日历；按日计算的期限适逢节假日时顺延至下一个非节假日；起始日不计入，末日计入（文书可以在末日24时前完成）；以电子方式提交的适用电子刑事诉讼规则，须在来源上核实 | 《刑事诉讼法典》第172条（1988年9月22日第447号共和国总统令）—— https://www.normattiva.it/uri-res/N2Ls?urn:nir:stato:decreto.del.presidente.della.repubblica:1988-09-22;447~art172!vig= |
| 时效（实体法） | 通用日历；起始日不计入；时效在末日最后时刻届满时完成；末日适逢节假日则顺延；按月计算的期限适用到期月份中的对应日 | 《民法典》第2963条（1942年3月16日第262号皇家法令）—— https://www.normattiva.it/uri-res/N2Ls?urn:nir:stato:regio.decreto:1942-03-16;262~art2963!vig= |

注意**程序期限**（在程序中进行文书：第155条 c.p.c. / 第172条 c.p.p. 的规则）与时效或除斥期间的**实体期限**（第2963条 c.c. 的规则，除斥期间为第2964条及以下 c.c.）之间的区别：两者并不总是一致。

## 2. 程序期限的假日中止 *(待核实)*

每年8月1日至8月31日，程序期限中止（**1969年10月7日第742号法律**；期间由最初的46天经2014年9月12日第132号法令（经第162/2014号法律转化）缩减为31天）。该规定**不在语料库中**：须在 Normattiva 核实其文本、范围与例外。始终对照文本检查以下各点，而非凭记忆：
- 哪些期限被排除在中止之外（紧急事项和紧急程序）；
- 期限在假日期间开始起算时对起算日（dies a quo）的影响；
- 与长上诉期限（见下文）的相互作用。

## 3. 强制期限（perentorio）、指示期限（ordinatorio）、期限恢复（rimessione in termini）

- **强制期限（Termini perentori）**：既不能缩短也不能延长，即使当事方合意也不行；违反即产生失权。c.p.c. 第153条第1款。
- **期限恢复（Rimessione in termini）**：因不可归责于自身的原因而失权的当事方可以请求法官恢复其期限（援引 c.p.c. 第294条第2、3款）。c.p.c. 第153条第2款—— https://www.normattiva.it/uri-res/N2Ls?urn:nir:stato:regio.decreto:1940-10-28;1443~art153!vig=
- **刑事中以失权为后果的期限**：法律规定时即为强制期限（如上诉期限，c.p.p. 第585条第6款）。
- **倒算期限**（相对于某次庭审或最终到期日向后计算）：节假日顺延规则反向运作，即提前；这是判例法发展出的原则，而非条文规定——如此说明并核实。

## 5. 技能的使用规则

当请求涉及到期日时：
1. 确定适用的**计算规则**（民事程序/刑事程序/实体）并按出处引用；
2. 从规定该期限的条款中确定期限的**期间**，区分强制期限与指示期限；
3. 列出计数所需的**数据**（起算日及其性质、是否处于假日中止期内、到期日是否适逢节假日、送达情况）；
4. **不要将计算出的日期提供为最终结果**：将其呈现为须在日历和实际日期上核实的计数，或者向用户说明规则后由其自行计算。对专业人士而言，错误的期限是最严重的损害之一。
