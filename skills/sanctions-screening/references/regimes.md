## 1. 总体法律架构

```
联合国（安理会——第七章）——非自动执行——对联合国所有成员国具有约束力
    ↓ 由以下机构实施：
欧盟（共同外交与安全政策条例——直接适用）  |  美国（OFAC + EAR/BIS）  |  英国（FCDO/OFSI）
    ↓ + 国家层面
法国（《货币与金融法典》第 L. 562-1 条及以下——DGT）  |  + 双重用途物品清单（SBDU/BDU）
```

**欧盟阻断条例**（第 2018/1100 号条例）：原则上禁止欧盟实体遵守与美国利益相悖的美国域外制裁——主要适用于古巴/伊朗。由于存在被切断美国金融体系的风险，实践中很少适用。

## 2. 主要专题制度

### 2.1 俄罗斯/乌克兰——欧盟迄今通过的最广泛制度

**个人制裁**（第 269/2014 号条例）：对寡头、政府官员、军人、国家媒体宣传人员实施资产冻结 + 签证禁令。

**部门制裁**（第 833/2014 号条例 + **19 个一揽子方案**——最新：欧盟第 2025/2033 号条例及相关法案，2025年11月3日发布于《欧盟官方公报》）：
- 能源：原油和成品油、煤炭、天然气（新限制）；自2025年2月27日起禁止石油服务（美国 OFAC）
- 金融：禁止被指定银行进入欧盟资本市场；存款、贷款限制
- 运输：禁止飞越欧盟领空、进入港口和机场
- 技术：双重用途物品清单（BDU）、半导体、先进电子（自第 2022/699 号条例起俄罗斯被移出 EU001-EU008 通用授权）
- 奢侈品：禁止出口单价超过300欧元的物品
- 服务：禁止法律咨询、会计、公关、云、IT 服务，且自第19个一揽子方案起禁止**商业空间服务**（对地观测、卫星导航）
- 黄金、钢铁、木材、化学品、橡胶、建筑材料（附件XXIIIG）：限制
- G7 石油价格上限（60美元/桶）
- "禁止向俄罗斯再出口"条款（第12g条）——2024年3月生效
- **交易禁令**（第 2025/1494 号条例，2025年7月）：全面禁止与50多家被指定的俄罗斯银行交易
- **扩展至 Mir 系统和 SBP**（俄罗斯快速支付系统），自**2026年1月25日**起（第19个一揽子方案）
- **自2024年6月起禁止 SPFS**；**自2025年11月25日起禁止俄罗斯加密货币 A7A5**
- **俄罗斯液化天然气（LNG）禁运**（CN 2711.11.00）：对2025年6月17日前订立的短期合同，自**2026年4月25日**起生效；对2025年6月17日前订立的超过一年的合同，自**2027年1月1日**起生效
- **禁止为影子船队（shadow fleet）船舶提供再保险**（第19个一揽子方案）
- 禁止向俄罗斯供应欧元纸币
- 冻结俄罗斯中央银行在欧盟的储备——自2024年5月起收益用于支持乌克兰
- 影子船队：**557 艘被指定船舶**（截至2025年10月23日）+ 禁止进入欧盟港口
- **附件四新增 45 个实体**（其中12个在中国、3个在印度），涉及规避双重用途限制（第19个一揽子方案）
- **向俄罗斯政府提供任何尚未被禁止的服务均须事先授权**（第 833/2014 号条例第5n条，2026年1月生效）
- **Lukoil 和 Rosneft 被 OFAC 指定**（2025年10月——SDN 名单）：Rosneft Deutschland 的 General License 缩减期至2026年4月29日

**俄罗斯针对"不友好国家"的反制措施**：
- 第95号和254号法令（2022年3月/5月）：向外国人的分红仅以卢布支付至"C"型账户
- 第618号法令（2022年9月）：涉及俄罗斯公司股权交易须经政府批准
- 第302号法令（2023年4月）：可扣押"不友好国家"国民持有的俄罗斯资产

**双重用途制度**：俄罗斯被移出 EU001-EU008 通用授权（第 2022/699 号条例）。Russia/Belarus FDP Rule（美国 BIS）：世界上任何使用美国技术生产的物品，向俄罗斯/白俄罗斯出口均受 EAR 管辖。

### 2.2 伊朗

**联合国恢复制裁（2025年9月28日）**：E3（法国、德国、英国）于2025年8月28日激活第 2231 号决议机制后，经认定伊朗存在重大不履行，联合国制裁重新施加。

**美国（OFAC）**：最广泛的制度——几乎全面（能源、金融、海事、贵金属）。次级制裁：非美国实体可能因与伊朗的美元交易而受影响。

**欧盟（第 267/2012 号条例）**：冻结 + 部门禁令（核、弹道导弹、伊斯兰革命卫队 IRGC）。

### 2.3 朝鲜

联合国近乎全面的禁运（第 1718、2087、2094、2270、2321、2371、2375、2397 号决议）。煤炭、钢铁、铁、铅、海产品禁止进口。石油设定上限。在国外的朝鲜工人（IT、工程）：禁止雇佣（第 2397 号决议）——这是有记录的创汇渠道。

### 2.4 叙利亚——大规模解除制裁（2025年）

**截至2026年4月14日的情况：** 随着阿萨德政权垮台（2024年12月），对叙利亚的几乎所有经济制裁都已解除。

**美国（OFAC）**：2025年6月30日的行政命令正式**终止了叙利亚制裁计划**（2025年7月1日生效）。《叙利亚制裁条例》（31 CFR part 542）已从 CFR 中移除。该计划更名为**PAARSS**（Promoting Accountability for Assad and Regional Stabilization Sanctions，促进对阿萨德追责与地区稳定制裁）。《凯撒法案》经2025年12月 NDAA 正式废止。**仅剩**：阿萨德及其同伙、侵犯人权者、毒品贩子（Captagon）、ISIS/基地组织关联方、伊朗/代理人——依据其他 SDN 权限。

**欧盟**：所有经济制裁于**2025年5月28日**解除（第 2025/1094 和 2025/1098 号条例——能源、运输、银行、贸易）。**仅剩**：针对阿萨德政权成员的制裁（至2026年6月1日）、武器禁运、镇压装备、化学武器。

**英国**：2025年3月至4月大规模除名（24 个实体，包括叙利亚中央银行、商业银行、叙利亚阿拉伯航空、能源公司）。部门制度由 UK Syria (Sanctions) (EU Exit) (Amendment) Regulations 2025（2025年4月25日）解除。仅剩：阿萨德/人权/武器制裁。

**对本技能的影响**：叙利亚**不再是受全面部门禁运的国家**。仅对以下交易需要进行尽职调查：与前阿萨德政权成员的交易、军事装备、化学武器、ISIS/基地组织关联方。仍需核查个人名单。

### 2.5 白俄罗斯

欧盟（第 765/2006 号条例，2021年后加强）：个人冻结 + 部门制裁（钾肥、石油、烟草）。2021年后加强（瑞安航空航班改道事件 + 选举后镇压）。

### 2.6 恐怖主义（横向）

- 欧盟：第 2580/2001 号条例（共同外交与安全政策恐怖主义名单）+ 第 881/2002 号条例（基地组织/ISIL——源自安理会第1267号）
- 美国 OFAC：SDGT（经修正的第 13224 号行政命令）+ FTO（国务院）
- 法国：TRACFIN——反洗钱/反恐融资可疑交易报告。可能进行行政冻结（《货币与金融法典》第 L. 562-2 条）

### 2.7 人权——《马格尼茨基法案》制度

- 欧盟全球人权制裁（第 2020/1998 号条例）：冻结 + 适用于所有国籍的签证禁令
- 美国全球马格尼茨基（第 13818 号行政命令——OFAC 的 GLOMAG）
- 英国《2020年全球人权制裁条例》

## 3. 按地区的地理地图

### 3.1 欧洲

**欧盟（27个成员国）**：共同外交与安全政策条例直接适用——自动义务，无须国内转化。成员国之间在法律义务上没有差别。

**非欧盟的欧洲经济区/欧洲自由贸易联盟国家（挪威、冰岛、列支敦士登）**：声明与欧盟制裁保持一致——通过定期声明正式化。形式上各自有独立法律文书，但实践中趋同。按"准欧盟"处理；对特定业务建议单独核查。

**瑞士**：SECO（联邦禁运法——LEmb）。在俄罗斯、白俄罗斯、伊朗、缅甸问题上与欧盟高度趋同。SECO 名单 ≠ 欧盟名单——需在 sesam.search.admin.ch 单独核查。

**欧盟候选国（塞尔维亚、黑山、阿尔巴尼亚、北马其顿、摩尔多瓦、乌克兰、波斯尼亚和黑塞哥维那、格鲁吉亚）**：声明在政治上与欧盟制裁保持一致——通过欧盟高级代表的定期声明正式化。具有约束力的法律基础较弱。执行能力不一——须逐笔交易评估残余风险。

**土耳其**：适用联合国制裁。未对俄罗斯采取自主制裁——在此问题上与欧盟/美国制度不同。2022年以来土俄双边贸易量可观。

**英国（脱欧后）**：SAMLA 2018（《制裁与反洗钱法》）——FCDO + OFSI。自2026年1月28日起：统一 FCDO 名单（UK Sanctions List）。与 G7 高度一致，但名单不同——必须在 search-uk-sanctions-list.service.gov.uk 单独核查。OFSI 实行严格责任。

### 3.2 北美

**美国**：OFAC（制裁）+ BIS/EAR（出口管制）+ DDTC/ITAR（国防物品）。最广泛且具有域外效力的制度。适用于美国人士 + 美元交易 + 与美国有联系的实体。次级制裁。30多个活跃的 OFAC 计划。欧盟阻断条例（第 2018/1100 号条例）原则上适用于古巴/伊朗。

**加拿大**：LMES（《特别经济措施法》）——Global Affairs Canada。EIPA（出口管制）。2022年以来与 G7 高度一致。名单 ≠ 欧盟名单——在 international.gc.ca 单独核查。

### 3.3 亚太

**澳大利亚**：《2011年自主制裁法》——DFAT。DEC（国防出口管制）+ DSGL。2022年以来与 G7/五眼高度一致。DFAT 名单 ≠ 欧盟名单——在 dfat.gov.au 单独核查。

**日本**：FEFTA（《外汇及对外贸易法》）——METI + MOFA + MOF。2022年后史无前例地与 G7 保持一致。2025年10月修订兜底出口管制（核心物项）。自2024年12月起对关键技术实行优先报告。自2024年4月起金融机构承担内部合规冻结义务。没有自主次级制裁，没有阻断法令。

**新加坡**：MAS（新加坡金融管理局）。联合国制裁 + 恐怖主义。自主制度有限。作为主要金融中心，通过美元交易暴露于 OFAC 指定风险。

**韩国**：《对外贸易法》——朝鲜、伊朗、俄罗斯（G7 一致）。有专门名单。

**中国**：ECL（《出口管制法》）——2020年12月1日生效。2024年《两用物项出口管制条例》（第49条——域外效力正在发展）。有选择性地适用联合国制裁（2022年对俄罗斯问题投弃权票/反对票 = 无决议 = 无须转化）。不适用西方单边制裁。《反外国制裁法》2021 + 2021年《阻断办法》 + 2023年《对外关系法》。不可靠实体清单（UEL）——透明度低。稀土、锂电池、超硬材料：2025年引入了专门的域外措施。

**印度**：适用联合国制裁。自主制度有限。未对俄罗斯采取制裁。2022年以来印俄双边贸易大幅增长（尤其是石油）。

### 3.4 中东

**阿联酋**：联合国成员国——适用联合国制裁 + 通过 ECON（管制与防扩散执行办公室）实行自主恐怖主义制裁。未对俄罗斯采取制裁。作为主要金融中心（迪拜），因伊朗/俄罗斯交易暴露于 OFAC 指定风险——OFAC 已为此指定了在阿联酋的实体和个人。ECON 指南于2025年9月更新。

**卡塔尔**：联合国成员国——适用联合国制裁。NCTC（国家反恐委员会）名单：该地区结构最好的名单（标准化程度高、检索工具好用）。卡塔尔金融中心监管局于2025年发布新的制裁合规指引。无扩大的自主制裁。

**沙特阿拉伯**：联合国成员国——适用联合国制裁的正式法律框架，安理会第1267号指定后自动冻结。PSS（恐怖主义）名单结构不佳——以自由文本发布，条目记录不全。不对其他主权国家适用自主制裁。

**以色列**：有自主制裁国家名单。对某些联合国制度持自身立场。

**伊朗**：有自己的国家制裁名单。对欧盟/法国合规分析不相关（伊朗本身处于制裁之下）。

### 3.5 非洲

**南非**：撒哈拉以南非洲唯一有公开自主制裁名单的国家——FIC（金融情报中心）。适用联合国制裁。

**撒哈拉以南非洲其他国家**：绝大多数情况下没有可查询的公开自主制裁名单。作为联合国成员国负有转化联合国制裁的义务——执行情况因机构能力而异。有记录的事实：针对非洲国家施加的制裁方案中约95%由非洲区域组织自身（非盟 AU 或西共体 CEDEAO）发起，之后才被联合国层面采纳。由联合国/欧盟/OFAC 对非洲国民实施的个人指定基于专题（侵犯人权、恐怖主义、武装冲突）。

**非洲联盟（AU）**：制裁框架处于制度建设阶段——PSC 议定书、《洛美宣言》、ACDEG、《非盟组织法》。PSC 制裁小组委员会正在运作化。安理会非洲成员（A3）在涉及非洲的联合国制裁谈判中发挥作用——有时与西方常任理事国立场分歧（如2025年南苏丹第 2781 号决议投票：9票赞成，6票弃权，包括阿尔及利亚、中国、俄罗斯、巴基斯坦、索马里、塞拉利昂）。

**西非国家经济共同体（西共体 CEDEAO）**：有自己的区域制裁制度——尤其在政变时使用（马里、布基纳法索、尼日尔、几内亚）。西共体制裁 ≠ 联合国制裁——独立的区域基础。

**北非**：摩洛哥、突尼斯、埃及适用联合国制裁。埃及有国家名单。突尼斯：欧盟 101/2011 号预防性冻结已逐步解除。

|-------------|-----------------|---------------------|----------------------|--------------------------|
| **欧盟27国** | 自动 | 是——广泛 | 第 2021/821 号条例 + 第 833/2014 号条例第12g条 | 基准——直接义务 |
| **英国** | 是（SAMLA） | 是——2026年1月统一 FCDO 名单 | 英国战略出口管制 | 低——单独核查 FCDO |
| **挪威/冰岛/列支敦士登** | 是（一致） | 准欧盟 | 与瓦森纳安排一致 | 低 |
| **瑞士** | 是（SECO） | 是——与欧盟高度趋同 | 与瓦森纳安排一致 | 低——核查 SECO |
| **美国** | 是 | 是 + 域外（次级） | EAR（BIS）+ ITAR（DDTC）+ OFAC | 中到高——美元 + FDPR |
| **加拿大/澳大利亚/日本** | 是 | 是——G7 一致，名单不同 | 与瓦森纳安排一致的各自名单 | 低——核查各自名单 |
| **新加坡** | 是（联合国 + 恐怖主义） | 有限 | MAS | 中——美元/OFAC 风险敞口 |

| **土耳其** | 是（联合国） | 在俄罗斯问题上制度不同 | 自有 | 中——俄土交易 |
| **阿联酋** | 是（联合国 + 恐怖主义/ECON） | 有限 | 自有 | 中——暴露于 OFAC 指定 |
| **卡塔尔** | 是（联合国 + NCTC） | 仅恐怖主义 | 自有 | 低到中 |
| **沙特阿拉伯** | 是（联合国——正式框架） | PSS 恐怖主义结构不佳 | 自有 | 中 |
| **南非** | 是 | 是（FIC） | 自有 | 低——核查 FIC |

| **印度** | 是 | 有限 | 自有 | 中——在俄罗斯问题上制度不同 |
| **中国** | 选择性 | ECL 2020 + 2024年条例（域外效力发展中） | ECL + 2021年《反外国制裁法》 | 如涉美元/美国实体则高 |
