# 专利标引智能体（Patent Tagging Agent）

将用户自定义的多维度分类标签体系与专利技术事实建立映射关系，按三阶段流程（接收校验、标引、合并输出）输出结构化标引表格。

## 触发方式

- "专利标引""专利标签""专利分类标注"
- "patent tagging""patent labeling"
- "专利技术标注""给专利打标签"
