## 起诉状结构

起诉状必须遵循以下精确结构：

### 文书抬头
```
向劳资调解委员会（CONSEIL DE PRUD'HOMMES）提起的起诉状
兼作原告方首份诉讼请求书
（《民事诉讼法典》第 57 条及《劳动法典》第 L.1411-1 条及以下、
第 R.1452-1 条及以下）

劳资调解委员会所在地：[城市]
地址：[CPH 完整地址]

传唤至：调解与引导庭（Bureau de conciliation et d'orientation）

劳资调解委员会专用栏
登记号（Numéro RG）：
庭（Section）：
分庭（Chambre）：
开庭日期（Audience）：
```

### 第 1 部分：当事人身份

#### A. 原告（DEMANDEUR(ESSE)）
以结构化方式列明：
- 姓名
- 出生日期和地点
- 国籍
- 地址
- 职业
- 入职日期
- 用工性质
- 管理岗/非管理岗
- 月平均毛工资
- 工龄
- 解雇程序（传唤、面谈、通知日期）
- 劳动关系解除的理由

如员工由律师代理，列明：
```
委托律师：
Maître [名 姓]
[城市]律师公会律师
[律所地址]
电话：[电话] / 邮箱：[邮箱]
```

#### B. 被告（DÉFENDEUR(ESSE)）
以结构化方式列明：
- 名称
- 法律形式
- 注册地址
- 商业与公司登记（RCS）及编号
- SIRET 号
- 员工人数
- 集体协议
- APE 代码
- 由其法定代表收受，法定代表人住所位于上述注册地址

### 第 2 部分：法律告知

必须包含以下告知内容：

```
* * *
非常重要
* * *

兹提醒被告，如其不出庭，将面临法院仅依据对方提供的材料作出对其不利判决的风险。

此外，兹提醒，根据《劳动法典》第 R.1453-1 条，当事人自行进行辩护，并有权获得他人协助或代理。

最后兹提醒，根据同法典第 R.1453-2 条：
“有权协助或代理当事人的人员为：
1° 属于同一业务领域的员工或雇主；
2° 工会辩护人；
3° 配偶、缔结民事互助契约（PACS）的伴侣或同居人；
4° 律师。

雇主亦可由企业或机构内经授权或获权之成员协助或代理。

代理人如非律师，须出示特别授权书。在调解与引导庭，该书面授权须允许其以委托人的名义和账号进行调解，并参与引导措施。”

本请求所依据的证据材料按随附于本文书之清单（bordereau）逐项列明。
```

### 第 3 部分：基本要素回顾

以汇总表格形式列明：
- 入职日期
- 用工性质
- 管理岗/非管理岗
- 岗位资质
- 平均毛工资
- 工作地点
- 工龄
- 预备面谈传唤日期
- 预备面谈日期
- 解雇通知日期
- 所援引的理由

### 第 4 部分：敬请法庭

```
敬请法庭（PLAISE AU CONSEIL）
```

### 第 5 部分：事实与程序回顾

本部分应为叙事性、按时间顺序的叙述。通常包括：

#### 一、双方关系介绍
- 入职日期和初始职务
- 劳动关系的演变
- 工作背景
- 适用的集体协议

#### 二、合同关系演变
- 劳动关系的进展
- 工作质量
- 此前无事故记录（如适用）
- 导致解雇的背景

#### 三、关于解雇
- 预备面谈传唤日期（+ 证据第 X 号）
- 预备面谈的日期和过程
- 面谈中提及的过错
- 解雇通知日期（+ 证据第 X 号）
- 解雇信函中援引的理由
- 员工的异议

#### 四、关于和解尝试（如适用）
- 催告函（mise en demeure）日期
- 雇主的答复（或无答复）

**本部分结论：**
“正是在此背景下，[先生/女士] [姓] 拟向本庭劳资调解委员会提起诉讼。”

### 第 6 部分：诉讼请求理由陈述

本部分是起诉状的法律核心。应以带有清晰小标题的章节形式组织。

**引言：**
```
原告请求劳资调解委员会受理其全部主张和请求，即：
```

随后列出主要请求及金额：
- 将因严重过错解雇重新定性为无真实且严肃理由的解雇
- 无真实且严肃理由解雇赔偿金：[金额] 欧元
- 法定解雇补偿金：[金额] 欧元
- 预告期补偿金：[金额] 欧元
- 相应带薪休假补偿：[金额] 欧元
- 其他请求（如适用）

#### 第一节：将因严重过错解雇重新定性为无真实且严肃理由的解雇

本部分应包括：

**A. 法律原则回顾**

援引《劳动法典》相关条文：

```
法律方面（EN DROIT），

根据《劳动法典》第 L.1232-1 条，任何因个人原因作出的解雇均须有真实且严肃的理由。

根据《劳动法典》第 L.1234-1 条，当解雇因严重过错而具有正当性时，员工既无权获得预告期，
也无权获得解雇补偿金。

严重过错是指可归责于员工的某一事实或一系列事实，构成对劳动合同或劳动关系所生义务的违反，
其严重程度达到即使在预告期内也使得员工无法继续留在企业（法国最高法院社会庭，2007 年 9 月 27 日，
第 06-43867 号）。

对所指责过错的证明责任完全由雇主承担（法国最高法院社会庭第六分庭第十一庭，2023 年 1 月 17 日，
第 20/07683 号）。

只要雇主已采取纪律处分路径，法官即不得将解雇重新定性为因职业能力不足而解雇
（法国最高法院社会庭第六分庭第十一庭，2023 年 1 月 17 日，第 20/07683 号）。
```

**B. 适用本案 —— 过错分析**

对雇主援引的每一项过错，进行结构化分析：

1. **过错第 1 项：[过错名称]**

   *雇主指控的过错：*
   准确陈述雇主的指责内容。

   *员工的异议：*
   - 说明为何对该过错提出异议
   - 提出相反的事实要素
   - 如适用，援引卷宗中的证据材料

   *法律分析：*
   - 说明为何该过错不构成严重过错
   - 如可获得，援引相关判例

2. **过错第 2 项：[等等]**

**C. 关于严重过错要件不成立**

就以下事项作出结论：
- 过错未获证明，或
- 过错获证明但不构成严重过错
- 雇主未完成举证责任
- 员工留在企业并非不可能

**D. 关于程序瑕疵（如适用）**

如存在瑕疵（未遵守期限、传唤不规范等），在此处列明，并援引适用的《劳动法典》条文。

**本部分结论：**
```
因此，向[先生/女士] [姓] 通知的因严重过错解雇不基于真实且严肃的理由，
应重新定性为无真实且严肃理由的解雇。
```

#### 第二节：赔偿请求

**A. 无真实且严肃理由解雇赔偿金**

*法律方面：*

根据企业员工人数区分：

**如企业员工少于 11 人：**
```
根据《劳动法典》第 L.1235-5 条，如通常雇用少于十一名员工的企业中，员工的解雇
没有真实且严肃的理由，法官可提议员工复职，并保留其既得利益。

如任何一方拒绝复职，法官判给员工由雇主负担的赔偿金，金额为每一年工龄一个月工资
最低至两个月工资之间，且不得低于三个月工资。
```

**如企业员工为 11 人或以上：**
```
根据《劳动法典》第 L.1235-3 条，如通常雇用至少十一名员工的企业中，员工的解雇
没有真实且严肃的理由，法官可提议员工复职，并保留其既得利益。

如任何一方拒绝复职，法官判给员工由雇主负担的赔偿金。该赔偿金不得低于最近六个月的工资。
该赔偿金不影响（如适用）第 L.1234-9 条规定的解雇补偿金。

赔偿金额根据所遭受的损害确定，尤其考虑：
- 参考工资；
- 员工的工龄；
- 员工的年龄及其再就业的困难；
- 劳动关系解除的情形。

法定最低标准由《劳动法典》第 L.1235-3-1 条规定 [按工龄援引赔偿等级表]。
```

*本案情况：*

计算并说明所请求的金额：
```
[先生/女士] [姓] 在解雇时具有 [X] 年 [X] 个月的工龄。
其参考工资为 [金额] 欧元（毛额）。

按照法定赔偿等级表 [或：考虑到其工龄、年龄、解雇情形]，[先生/女士] [姓] 请求判令
[名称]公司支付 [金额] 欧元，作为无真实且严肃理由解雇赔偿金。
```

**B. 法定解雇补偿金**

*法律方面：*
```
根据《劳动法典》第 R.1234-2 条，法定解雇补偿金不得低于以下金额：
- 十年以内每一年工龄为四分之一月工资；
- 十年以上每一年工龄为三分之一月工资。

法定解雇补偿金按《劳动法典》第 R.1234-4 条定义的参考工资计算，即以下两者中较高者：
- 解雇前最近十二个月的月平均工资；
- 最近三个月工资的三分之一（例外性或年度性奖金及津贴按实际工作时间比例计入）。
```

*本案情况：*

进行详细计算：
```
[先生/女士] [姓] 累计工龄 [X] 年 [X] 个月。
其参考工资为 [金额] 欧元（毛额）。

计算：
[按档次详细列明计算过程]

法定解雇补偿金合计：[金额] 欧元。
```

**C. 预告期补偿金及相应带薪休假**

*法律方面：*
```
《劳动法典》第 L.1234-5 条规定，解雇以附收件回执的挂号信通知员工。在不影响
第 L.1234-1 条适用的前提下，解雇信须载明雇主援引的一项或多项理由。
信函还应明确预告期的期限。

根据《劳动法典》第 L.1234-1 条，当解雇因严重过错而具有正当性时，员工既无权获得预告期，
也无权获得预告期补偿金。

但一旦严重过错要件不成立，且解雇被重新定性为无真实且严肃理由的解雇，员工即有权获得
预告期补偿金以及相应带薪休假补偿。

预告期的期限由 [适用的集体协议 / 法律规定 / 惯例 / 劳动合同] 确定。
```

*本案情况：*

计算补偿金：
```
在本案中，[先生/女士] [姓] 适用 [集体协议 [名称]，该协议规定预告期为 [期限] /
规定预告期为 [期限] 的法律规定]。

其月平均毛工资为 [金额] 欧元，预告期补偿金为 [金额] 欧元（毛额）。

与预告期相应的带薪休假补偿为该金额的 10%，即 [金额] 欧元。
```

**D. 保守性停职期间工资补发（如适用）**

如员工曾被保守性停职（mise à pied conservatoire）且严重过错要件不成立：

*法律方面：*
```
保守性停职不构成处分，而仅是一种等待性措施，使雇主能够在通知解雇前进行必要调查。

一旦严重过错要件不成立，保守性停职即属无正当理由，员工应获得与停职期间相对应的工资补发。
```

*本案情况：*
```
[先生/女士] [姓] 于 [日期] 至 [日期] 被保守性停职，共计 [X] 天。

因严重过错要件不成立，该停职无正当理由，[先生/女士] [姓] 请求补发相应工资，
即 [金额] 欧元（毛额），另加 [金额] 欧元的相应带薪休假补偿。
```

**E. 独立损害的精神损害赔偿（如适用）**

如存在特定损害（解雇方式、骚扰、名誉损害等）：

*法律方面：*
```
根据《民法典》第 1240 条（原第 1382 条），任何致他人损害的行为，均使过错行为人
负赔偿责任。

员工可就与失业所致损害相独立的损害请求精神损害赔偿，前提是该等损害已获证明。
```

*本案情况：*

陈述损害：
```
[先生/女士] [姓] 因 [解雇的粗暴性 / 劳动关系解除的羞辱性方式 / 对其名誉的损害 / 等]
遭受了独立损害。

[展开相关情节及所遭受的损害]

为赔偿该损害，[先生/女士] [姓] 请求判令 [名称]公司支付 [金额] 欧元作为精神损害赔偿金。
```

**F. 失业救济金偿还（如适用）**

*法律方面：*
```
根据《劳动法典》第 L.1235-4 条和第 L.1235-5 条，除非员工工龄不满两年或企业通常雇用
少于十一名员工，法官应判令雇主向相关机构（尤其是 Pôle emploi 就业中心）偿还自解雇之日
至判决之日向被解雇员工支付的失业救济金的全部或部分，以六个月救济金为限。
```

*本案情况：*
```
[先生/女士] [姓] 累计工龄超过两年。
企业雇用员工超过十一人。

因此，应判令 [名称]公司向相关机构（尤其是 Pôle emploi）偿还自 [日期] 起向 [先生/女士] [姓]
支付的失业救济金，以六个月救济金为限。
```

### 第 7 部分：附带请求

**A. 关于临时执行**

*法律方面：*
```
根据《劳动法典》第 R.1454-28 条：“除非法律或法规另有规定，劳资调解委员会的决定
不当然具有临时执行效力。劳资调解委员会可命令其决定临时执行。”

当然具有临时执行效力的情况尤其包括：
- 仅因反诉而无法上诉的判决；
- 命令交付工作证明、工资单或雇主负有交付义务的任何文件的判决。
```

*本案情况：*

说明请求的理由：
```
[先生/女士] [姓] 的请求具有正当性，旨在赔偿重大损害。

存在判决款项不被支付的风险，构成采取执行措施的理由。

因此，[先生/女士] [姓] 请求对将作出的全部裁判命令临时执行。
```

**B. 关于《民事诉讼法典》第 700 条及诉讼费用**

*法律方面：*
```
根据《民事诉讼法典》第 700 条：“如由一方承担其已支出且未计入诉讼费用的款项显失公平，
法官可判令另一方支付其确定的金额。”
```

*本案情况：*
```
[先生/女士] [姓] 证明已向雇主尝试进行和解。

[其] 亦证明对其采取的措施具有滥用性质。

因此，如由其自行承担在本程序中支出的费用，显失公平。

因此，[先生/女士] [姓] 请求判令 [名称]公司向其支付 [金额] 欧元，作为《民事诉讼法典》
第 700 条项下的款项。
```

**C. 判令偿还 Pôle emploi 补偿金（如适用）**

沿用上文第 6 部分 F 节的内容。

**D. 交付劳动合同终止文件（如适用）**

如文件尚未交付：

```
命令在逾期罚款（每份文件每日 [15] 欧元）下交付符合本裁判的以下文件：
- 全部更正后的工资单
- 面向 France Travail 的雇主证明
- 符合规定的工作证明
- 全部账目结清凭证（Solde de tout compte）
```

### 第 8 部分：据此理由

以清晰、列明金额的方式汇总全部请求：

```
据此理由（PAR CES MOTIFS）

[先生/女士] [姓] 请求各位审判员：

■ 认定于 [日期] 通知的因严重过错解雇缺乏真实且严肃的理由；

■ 判令 [名称]公司向 [先生/女士] [姓] 支付以下款项：

关于劳动合同履行（如适用）：
- [金额] 欧元，作为 [理由] 的工资补发
- [金额] 欧元，作为相应带薪休假补偿
- [金额] 欧元，作为 [其他请求]

关于劳动合同解除：
- [金额] 欧元，作为无真实且严肃理由解雇赔偿金
- [金额] 欧元，作为法定解雇补偿金
- [金额] 欧元，作为预告期补偿金
- [金额] 欧元，作为与预告期相应的带薪休假补偿
- [金额] 欧元，作为无正当理由保守性停职期间的工资补发
- [金额] 欧元，作为相应带薪休假补偿
- [金额] 欧元，作为赔偿所遭受独立损害的精神损害赔偿金

■ 判令 [名称]公司承担诉讼费用（dépens）；

■ 命令在逾期罚款（每份文件每日 [15] 欧元）下交付符合本裁判的以下文件：
- 全部更正后的工资单
- 面向 France Travail 的雇主证明
- 符合规定的工作证明
- 全部账目结清凭证

■ 命令对将作出的裁判临时执行，并计收利息复利。
```
