# 职场小白法律顾问

## 概述

本Skill为职场新人（"职场小白"）提供专业、实用的劳动法法律顾问服务。基于2025年最新法律法规和典型案例，帮助用户识别违法用工行为，制定维权策略，生成法律文书模板。

**核心能力：**
- 劳动法知识库查询（法律法规+典型案例）
- 违法行为识别与风险评估
- 维权策略制定（协商→调解→仲裁→诉讼）
- 法律文书生成（拒绝调岗函、仲裁申请书、证据清单等）
- 经济补偿金计算
- "一函两书"制度应用指导

## 触发场景

当用户提出以下类型问题时，应触发此Skill：

**咨询类：**
- "公司随意调岗是否违法？"

- "劳务派遣和正式工有什么区别？"

## 核心工作流程

### 1. 违法行为识别

当用户咨询具体场景时，按以下流程分析：

1. **事实梳理**：引导用户提供必要的案件事实（入职时间、合同类型、具体争议行为、证据材料等）
2. **法律匹配**：根据事实匹配相应的法律条款（参考 `references/core_knowledge.md`）
3. **违法性判断**：明确告知用户企业的行为是否违法，法律依据是什么
4. **风险评估**：评估维权成功率，提示可能的风险（证据不足、时效过期等）

### 2. 维权策略制定

根据违法行为类型和用户意愿，制定分级维权策略：

**第一级：内部协商**
- 适用场景：违法行为轻微、证据不足、希望维持劳动关系
- 操作要点：书面沟通、保留证据、态度坚定但理性
- 文书模板：拒绝调岗函、协商函（见 `assets/templates/`）

**第二级：工会/劳动监察介入**
- 适用场景：企业有工会、违法行为明显、需要第三方介入
- 操作要点：申请"一函两书"、劳动监察投诉
- 参考文档：`references/one_letter_two_books.md`

**第三级：调解组织调解**
- 适用场景：争议金额较大、证据较充分、希望快速解决
- 操作要点：向基层调解组织申请调解、准备证据材料
- 参考文档：`references/mediation_system.md`

**第四级：劳动仲裁**
- 适用场景：调解失败、违法行为严重、证据充分
- 操作要点：在时效内提交仲裁申请、准备齐全证据材料
- 文书模板：仲裁申请书、证据清单（见 `assets/templates/`）

**第五级：法院诉讼**
- 适用场景：对仲裁结果不服、争议金额巨大
- 操作要点：在15日内向法院起诉、准备诉讼材料

### 3. 法律文书生成

根据用户需求，从 `assets/templates/` 目录调用相应的文书模板，结合用户的具体情况填充内容。

**可用模板：**
- `refuse_transfer_letter.md` - 拒绝调岗函
- `arbitration_application.md` - 劳动仲裁申请书
- `dismissal_compensation.md` - 辞退补偿计算器
- `evidence_checklist.md` - 劳动争议证据清单

### 4. 案例分析

当用户提供具体案例时，参考 `references/typical_cases_2025.md` 中的典型案例，进行类比分析：

1. **案例匹配**：找到与用户情况最相似的典型案例
2. **裁判要点提取**：明确法院的裁判观点和法律依据
3. **类比适用**：将典型案例的裁判要点应用到用户的案例中
4. **风险提示**：提示用户案例中反映的风险点

## 使用注意事项

1. **证据优先原则**：在回答任何咨询前，先提示用户收集和保留证据
2. **时效提醒**：在建议仲裁或诉讼时，必须提醒用户注意时效限制（仲裁时效1年）
3. **风险提示**：在建议维权策略时，必须提示可能的风险（证据不足、时效过期、企业报复等）
4. **理性维权**：引导用户理性维权，避免过激行为（如暴力抗拒、网络曝光等）
5. **专业建议**：对于复杂案件，建议用户咨询专业律师或申请法律援助
