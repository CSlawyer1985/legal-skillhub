# 劳动争议处理流程图

**工具名称**：劳动争议处理流程图  
**适用场景**：快速了解劳动争议处理的完整流程  
**法律依据**：《劳动争议调解仲裁法》

---

## 一、劳动争议处理全流程

```
劳动争议发生
       ↓
┌─────────────────────────────────────────────────────────┐
│                      第一级：协商                        │
│  双方自行协商，达成和解协议                              │
│  优点：快速、成本低、维护关系                            │
│  缺点：无强制力，依赖双方自愿                            │
│  时效：无限制，但建议尽快协商                            │
└─────────────────────────────────────────────────────────┘
       ↓（协商不成）
┌─────────────────────────────────────────────────────────┐
│                  第二级：工会/劳动监察介入                 │
│  向工会求助，申请"一函两书"监督                          │
│  向劳动行政部门投诉（劳动监察）                            │
│  优点：第三方介入、舆论压力、可能启动行政程序                │
│  缺点：无强制力（提示函、意见书），依赖企业自愿              │
│  时效：无限制，但建议尽快申请                            │
└─────────────────────────────────────────────────────────┘
       ↓（仍不成功）
┌─────────────────────────────────────────────────────────┐
│                  第三级：调解组织调解                      │
│  向企业劳动争议调解委员会申请调解                          │
│  向基层人民调解组织申请调解                                │
│  向乡镇、街道具有劳动争议调解职能的组织申请调解              │
│  优点：专业、快速、成本低、维护关系                        │
│  缺点：调解协议无强制力（但可申请司法确认）                  │
│  时效：无限制，但应当在仲裁时效内调解                      │
│  期限：调解应当自受理之日起15日内结束，可延长10日           │
└─────────────────────────────────────────────────────────┘
       ↓（调解不成）
┌─────────────────────────────────────────────────────────┐
│                  第四级：劳动仲裁                          │
│  向劳动争议仲裁委员会申请仲裁                              │
│  优点：权威、法律效力强、前置程序（诉讼前必须仲裁）          │
│  缺点：时间较长（45日+可延长15日）、需要证据                │
│  时效：1年（从知道或应当知道权利被侵害之日起计算）           │
│  期限：仲裁庭应当自受理之日起45日内结束，可延长15日         │
└─────────────────────────────────────────────────────────┘
       ↓（对仲裁裁决不服）
┌─────────────────────────────────────────────────────────┐
│                  第五级：法院诉讼                          │
│  向人民法院提起诉讼                                        │
│  优点：终审、法律效力最强                                  │
│  缺点：时间最长、成本最高、程序最复杂                      │
│  时效：收到仲裁裁决书之日起15日内                          │
│  期限：一审普通程序6个月，简易程序3个月                     │
└─────────────────────────────────────────────────────────┘
       ↓
   强制执行（如对方不履行生效判决）
```

## 二、各环节的时效限制

| 环节 | 时效/期限 | 法律依据 |
|------|-----------|----------|
| 协商 | 无明确时效限制，但建议尽快协商 | - |
| 工会/劳动监察介入 | 无明确时效限制，但建议尽快申请 | - |
| 调解 | 无明确时效限制，但应当在仲裁时效内调解 | 《劳动争议调解仲裁法》第14条 |
| 劳动仲裁 | 1年（从知道或应当知道权利被侵害之日起计算） | 《劳动争议调解仲裁法》第27条 |
| 法院诉讼 | 收到仲裁裁决书之日起15日内 | 《劳动争议调解仲裁法》第48条 |

---

## 三、各环节的优缺点对比

| 环节 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 协商 | 快速、成本低、维护关系 | 无强制力，依赖双方自愿 | 违法行为轻微、希望维持劳动关系 |
| 工会/劳动监察介入 | 第三方介入、舆论压力、可能启动行政程序 | 无强制力（提示函、意见书），依赖企业自愿 | 企业有工会、违法行为明显 |
| 调解 | 专业、快速、成本低、维护关系 | 调解协议无强制力（但可申请司法确认） | 争议金额较大、希望快速解决 |
| 劳动仲裁 | 权威、法律效力强、前置程序（诉讼前必须仲裁） | 时间较长（45日+可延长15日）、需要证据 | 调解失败、违法行为严重、证据充分 |
| 法院诉讼 | 终审、法律效力最强 | 时间最长、成本最高、程序最复杂 | 对仲裁结果不服、争议金额巨大 |

## 四、流程图使用说明

### 1. 根据争议类型选择流程

**违法调岗**：
- 第一步：发《拒绝调岗函》（协商）
- 第二步：向工会求助（申请"一函两书"监督）
- 第三步：申请调解（向调解组织申请）
- 第四步：申请劳动仲裁（如调解不成）
- 第五步：法院诉讼（如对仲裁结果不服）

**违法辞退**：
- 第一步：协商（要求恢复劳动关系或支付赔偿金）
- 第二步：向工会求助（申请"一函两书"监督）
- 第三步：申请调解（向调解组织申请）
- 第四步：申请劳动仲裁（如调解不成）
- 第五步：法院诉讼（如对仲裁结果不服）

**拖欠工资**：
- 第一步：协商（要求支付拖欠工资）
- 第二步：向工会求助（申请"一函两书"监督）
- 第三步：向劳动监察部门投诉
- 第四步：申请劳动仲裁（如调解不成）
- 第五步：法院诉讼（如对仲裁结果不服）

### 2. 注意时效限制

**劳动仲裁时效**：1年
- 从知道或应当知道权利被侵害之日起计算
- 劳动关系存续期间因拖欠劳动报酬发生争议的，不受1年仲裁时效期间的限制；但是，劳动关系终止的，应当自劳动关系终止之日起1年内提出

**法院诉讼时效**：15日
- 从收到仲裁裁决书之日起计算
- 15日内不起诉的，仲裁裁决书发生法律效力

### 3. 收集并保留证据

**证据类型**：
- 证明劳动关系存在的证据（劳动合同、工作证、考勤记录等）
- 证明争议事实的证据（调岗通知、辞退通知、工资条等）
- 证明损失存在的证据（工资条、医疗费用单据等）

**证据保留**：
- 书面证据：保留原件或复印件
- 电子证据：保留截图、录音、录像等
- 证人证言：保留证人联系方式

---

## 五、注意事项

1. **协商和调解不是必经程序**：当事人可以选择直接申请仲裁。
2. **仲裁是诉讼的前置程序**：未经仲裁不得直接提起诉讼。
3. **注意时效限制**：劳动仲裁时效为1年，法院诉讼时效为15日。
4. **收集并保留证据**：证据是维权成功的关键。
5. **理性维权**：避免过激行为（如暴力抗拒、网络曝光等）。
