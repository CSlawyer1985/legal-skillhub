# 经济补偿金计算速查表

**工具名称**：经济补偿金计算速查表  
**适用场景**：快速计算经济补偿金或赔偿金  
**法律依据**：《劳动合同法》第47条、第87条

---

## 一、计算年限速查

| 工作年限 | 计算年限 |
|----------|----------|
| 不满6个月 | 0.5年 |
| 6个月以上不满1年 | 1年 |
| 1年以上不满1.5年 | 1年 |
| 1.5年以上不满2年 | 2年 |
| ... | ... |
| N年以上不满N+0.5年 | N年 |
| N年以上N+0.5年以上 | N+1年 |

**示例**：
- 工作3年2个月 → 计算年限：3年
- 工作3年8个月 → 计算年限：4年

---

## 二、月工资标准计算规则

**计算公式**：
```
月工资 = 劳动合同解除或者终止前12个月的平均工资
```

**包括项目**：
- 基本工资
- 绩效工资
- 奖金
- 津贴
- 补贴

**不包括项目**：
- 加班工资

**高收入劳动者的限制**：
- 劳动者月工资高于用人单位所在直辖市、设区的市级人民政府公布的本地区上年度职工月平均工资三倍的，向其支付经济补偿的标准按职工月平均工资三倍的数额支付
- 向其支付经济补偿的年限最高不超过十二年

---

## 三、补偿金额计算公式

### 1. 经济补偿金

```
经济补偿金 = 计算年限 × 月工资
```

**示例**：
- 计算年限：5年
- 月工资：10000元
- 经济补偿金 = 5 × 10000 = 50000元

### 2. 违法解除劳动合同赔偿金

```
赔偿金 = 2 × 计算年限 × 月工资
```

**示例**：
- 计算年限：5年
- 月工资：10000元
- 赔偿金 = 2 × 5 × 10000 = 100000元

---

## 四、特殊情况处理

### 1. 高收入劳动者的限制

**适用条件**：
- 劳动者月工资 > 当地上年度职工月平均工资 × 3

**计算规则**：
- 计算月工资标准 = 当地上年度职工月平均工资 × 3
- 计算年限最高不超过12年

**示例**：
- 当地上年度职工月平均工资：5000元
- 3倍平均工资：5000 × 3 = 15000元
- 劳动者月工资：20000元（高于15000元）
- 计算月工资标准：15000元（按3倍平均工资计算）
- 计算年限：15年（但最高不超过12年）
- 经济补偿金 = 12 × 15000 = 180000元

### 2. 试用期辞退

**适用情形**：
- 在试用期间被证明不符合录用条件的

**法律后果**：
- 用人单位无需支付经济补偿金或赔偿金

**注意事项**：
- 用人单位应当证明劳动者不符合录用条件
- 录用条件应当明确、具体，且事先告知劳动者

### 3. 劳动者主动辞职

**一般情形**：
- 劳动者提前三十日书面通知用人单位解除劳动合同的
- 劳动者在试用期内提前三日通知用人单位解除劳动合同的

**法律后果**：
- 用人单位无需支付经济补偿金或赔偿金

**特殊情形（用人单位违法，劳动者即时解除）**：
- 未按照劳动合同约定提供劳动保护或者劳动条件的
- 未及时足额支付劳动报酬的
- 未依法为劳动者缴纳社会保险费的
- 用人单位的规章制度违反法律、法规的规定，损害劳动者权益的
- 因本法第二十六条第一款规定的情形致使劳动合同无效的
- 法律、行政法规规定劳动者可以解除劳动合同的其他情形

**法律后果**：
- 用人单位应当支付经济补偿金

## 六、注意事项

1. **月工资的计算**：前12个月的平均工资，包括所有货币性收入，但不包括加班工资。
2. **高收入劳动者的限制**：月工资高于当地上年度职工月平均工资3倍的，按3倍计算，且计算年限最高不超过12年。
3. **经济补偿金与赔偿金的适用**：用人单位合法解除或终止劳动合同的，支付经济补偿金；违法解除劳动合同的，支付赔偿金（经济补偿金的2倍）。
4. **试用期辞退**：在试用期内，用人单位以"不符合录用条件"为由辞退劳动者的，无需支付经济补偿金或赔偿金。
5. **劳动者主动辞职**：劳动者主动辞职的，用人单位无需支付经济补偿金或赔偿金。但劳动者依照《劳动合同法》第38条规定（用人单位违法）解除劳动合同的，用人单位应当支付经济补偿金。
