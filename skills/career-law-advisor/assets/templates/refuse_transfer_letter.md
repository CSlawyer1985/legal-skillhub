# 拒绝调岗函模板

**文书名称**：拒绝调岗函  
**适用场景**：企业单方面调岗，劳动者不同意时  
**法律依据**：《劳动合同法》第35条

---

## 模板内容

```
拒绝调岗函

致：[公司名称]

本人[姓名]，身份证号：[身份证号码]，于[入职日期]与贵公司签订劳动合同，目前在[当前部门]担任[当前岗位]工作。

[日期]，贵公司向本人发出《调岗通知》，通知本人自[调岗生效日期]起调至[新岗位/新部门]工作，[是否变更工作地点：是/否，新工作地点为：______]。

本人认为，此次调岗不符合《劳动合同法》第35条的规定，具体情况如下：

一、调岗未经双方协商一致

根据《劳动合同法》第35条规定："用人单位与劳动者协商一致，可以变更劳动合同约定的内容。变更劳动合同，应当采用书面形式。"

贵公司此次调岗，未与本人协商一致，单方面变更劳动合同，违反了法律规定。

二、调岗缺乏合理性

此次调岗[选择以下一项或多项]：
1. 降低了本人的工资待遇（原工资：______元/月，新工资：______元/月）
2. 增加了本人的通勤距离（原通勤距离：______公里，新通勤距离：______公里）
3. 变更了本人的工作性质（原工作内容：______，新工作内容：______）
4. 对本人的职业发展造成不利影响（具体说明：______）
5. 其他原因（具体说明：______）

根据《劳动合同法》的规定，调岗应当具有合理性，不得损害劳动者的合法权益。贵公司的调岗决定缺乏合理性，严重损害了本人的合法权益。

三、本人不同意此次调岗

鉴于此次调岗未经双方协商一致，且缺乏合理性，本人不同意此次调岗。请贵公司继续履行原劳动合同，安排本人在原岗位工作。

四、要求

请贵公司在收到本函后[3日/5日/7日]内给予书面答复，并撤销此次调岗决定。如贵公司坚持调岗决定，本人将依法维权，包括但不限于：
1. 向工会组织求助（申请"一函两书"监督）
2. 向劳动行政部门投诉
3. 申请劳动争议调解
4. 申请劳动仲裁
5. 向人民法院提起诉讼

由此产生的一切法律后果，由贵公司承担。

特此函告！

附件：
1. 本人身份证复印件
2. 劳动合同复印件
3. 调岗通知复印件
4. 其他证据材料

函告人（签名）：__________
日期：______年______月______日

联系方式：______________
电子邮箱：______________
```

## 使用说明

### 1. 填写变量部分

**必填项**：
- [公司名称]：填写公司的全称
- [姓名]：填写劳动者姓名
- [身份证号码]：填写劳动者身份证号码
- [入职日期]：填写与公司建立劳动关系的日期
- [当前部门]、[当前岗位]：填写调岗前的部门和岗位
- [日期]：填写收到调岗通知的日期
- [调岗生效日期]：填写公司通知的调岗生效日期
- [新岗位/新部门]：填写公司通知的新岗位或新部门
- 是否变更工作地点：如变更，填写新工作地点

**选填项（二、调岗缺乏合理性）**：
- 选择符合自己情况的选项，删除不符合的选项
- 在空白处填写具体的数据或说明

**要求部分**：
- 选择合适的期限（3日/5日/7日）
- 根据实际情况选择维权途径

### 2. 准备附件材料

**必备材料**：
- 本人身份证复印件
- 劳动合同复印件
- 调岗通知复印件

**其他证据材料（如有）**：
- 工资条（证明工资标准）
- 考勤记录（证明工作地点）
- 工作邮件（证明工作内容）
-  communications with the company（与公司沟通的记录）

### 3. 发送方式

**推荐方式**：
- 顺丰快递（保留快递单作为证据）
- EMS快递（保留快递单作为证据）
- 当面送达（要求公司出具收件回执）

**不推荐方式**：
- 普通信件（无法证明公司收到）
- 电子邮件（可能无法证明收件人身份）
- 微信、短信（可能无法证明收件人身份）

### 4. 保留证据

**保留以下证据**：
- 拒绝调岗函的原件或复印件
- 发送凭证（快递单、收件回执等）
- 公司收到调岗函的证据（快递签收记录、收件回执等）
- 公司的答复（如有）

---

## 注意事项

1. **及时发出**：收到调岗通知后，应当及时发出拒绝调岗函，避免被认为同意调岗
2. **态度坚定**：拒绝调岗函应当态度坚定，明确表示不同意调岗
3. **理由充分**：应当充分说明拒绝调岗的理由（法律依据、事实依据等）
4. **保留证据**：应当保留拒绝调岗函的发送凭证和公司收到的证据
5. **依法维权**：如公司坚持调岗，应当依法维权，不得采取过激行为

---

## 法律风险提示

1. **公司可能强行调岗**：发出拒绝调岗函后，公司可能强行调岗。此时，劳动者可以继续在原岗位上班，并保留相关证据（考勤记录、工作记录等）
2. **公司可能违法辞退**：发出拒绝调岗函后，公司可能以"不服从工作安排"为由违法辞退劳动者。此时，劳动者可以申请劳动仲裁，要求公司支付违法解除劳动合同赔偿金
3. **公司可能打击报复**：发出拒绝调岗函后，公司可能对劳动者进行打击报复（如克扣工资、安排脏累苦工作等）。此时，劳动者可以收集相关证据，依法维权
