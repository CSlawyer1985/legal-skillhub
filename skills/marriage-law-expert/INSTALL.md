# 婚姻法专家 Skill — 安装指南

## 快速安装

```bash
# 1. 解压到AI助手的skills目录
unzip marriage-law-skills-v4.0.0.zip -d /path/to/your/ai/skills/

# 2. 安装Python依赖
pip install python-docx
```

## 功能模块

### 模块A：婚姻家庭法律咨询
- 结婚：结婚条件、无效婚姻、可撤销婚姻
- 离婚：协议离婚（冷静期）、诉讼离婚（感情破裂标准）
- 财产：夫妻共同财产、个人财产、离婚财产分割
- 子女：抚养权、抚养费、探望权
- 债务：夫妻共同债务、个人债务
- 损害赔偿：出轨、家暴等过错的赔偿
- 家庭暴力：报警、伤情鉴定、人身安全保护令
- 国家法律法规数据库API实时法条查询
- Logic Doctor五维自检机制
- 诉讼时效追踪提醒

### 模块B：离婚起诉状起草
- 使用最高人民法院标准要素式离婚起诉状模板
- 三步工作流：案由确认→信息追问→模板填充
- 一键生成 docx 格式离婚起诉状

## 使用方式

直接描述您的婚姻家庭法律问题，或说"帮我写离婚起诉状"即可开始。

## 法律依据

- 核心法律：《中华人民共和国民法典》婚姻家庭编
- 行政法规：《婚姻登记条例》
- 司法解释：《最高人民法院关于适用〈民法典〉婚姻家庭编的司法解释（一）》、《最高人民法院关于适用〈民法典〉婚姻家庭编的司法解释（二）》
- 专项法律：《中华人民共和国反家庭暴力法》
- 法律法规可随时通过国家法律法规数据库API实时查询
- 具体适用请以官方最新文本为准
