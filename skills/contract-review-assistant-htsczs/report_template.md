## 七、综合建议

### 7.1 是否建议签署

- [ ] **建议签署**：所有高风险项已修改，无重大法律风险
- [ ] **需修改后签署**：需与对方协商修改上述X项后签署
- [ ] **不建议签署**：存在重大法律风险或明显不公平条款

### 7.2 签署前注意事项

1. 确认以上高风险项已修改
2. 与业务负责人确认待确认事项
3. 确保签字盖章流程符合公司规定

## 九、飞书审批说明

### ⚠️ 发起审批前必须确认

| 确认项 | 说明 | 如何获取 |
|--------|------|---------|
| **审批模板 Code** | 飞书审批后台的合同审批模板唯一标识 | 飞书管理后台 → 审批 → 找到模板 → 查看详情中的 Code |
| **审批人** | 指定审批人（通常是法务负责人） | 法务负责人姓名或邮箱 |

### 一键发起审批

确认以上两项后，可一键发起审批：

```
/发起审批 approval_code=模板Code approver=审批人姓名
```
