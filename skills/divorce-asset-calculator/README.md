# 离婚财产计算器

一个把"离婚能分多少"算清楚的技能。输入房产、存款、股权、债务、结婚年限和各自出资，自动生成结构化的财产分割明细，并给出谈判要点，是离婚谈判前理清账目的好助手。

## 为什么做这个

离婚谈判里最容易乱的就是钱。一方说"房子归我你拿点补偿就行"，另一方往往不知道自己该拿多少。本技能把法律上的通用分割规则变成可填表、可计算的引擎，让双方在签协议前先对齐数字，避免被带节奏。

## 覆盖的财产类型

- 房产：婚前首付婚后共贷、婚后共买两种典型情形
- 存款：婚后积累原则上各半
- 股权：婚后取得整体均分；婚前取得仅婚后增值部分均分
- 债务：共同债务各半、个人债务各自承担、房贷随房产归属

## 文件结构

- SKILL.md：触发词、输入输出规范、红线
- formulas.md：计算规则与公式详解
- examples.md：三个完整案例（含输入与结构化输出）
- scripts.md：谈判话术与要点生成逻辑
- disclaimer.md：免责声明与法条索引
- scripts/calculator.py：可运行的计算引擎（Python 3.8+，无第三方依赖）

## 和劳动维权避坑的关系

同属"我的权益到底是多少"这一焦虑切口。劳动维权算"被辞退能拿多少"，本技能算"离婚能分多少"，底层都是"输入事实 → 结构化金额"的引擎，未来都能封装为按次付费服务（Pay Skill）。

## 使用方式

直接描述你的财产情况，例如"结婚 8 年，婚前男方首付 120 万买了一套房现在值 600 万，婚后共同还贷 80 万，还剩 100 万贷款；婚后存款 50 万，丈夫公司股权婚后取得现值 200 万；有 30 万共同经营贷"。技能会按公式给出每项分割明细和双方净得。
