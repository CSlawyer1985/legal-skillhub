# 谈判话术与要点生成

本技能不只是算数，还把结果翻译成"能拿去谈"的话。下面是可复用的一套谈判话术框架，按场景组织。用户拿到分割明细后，据此开口。

## 一、开场：把账摆上桌

- "我们先不谈感情，先把账算清楚。这是按法律通用规则算出的分割方案，你看看哪里不对，我们一项项对。"
- 作用：把谈判锚定在"数字"而非"情绪"，防止对方用模糊话术压你。

## 二、房产归属怎么谈

- 若是你婚前首付、婚后共贷：房子归你，但你要把"共同还贷及增值"的一半补给对方，这是法定标准，不是让利。
- 若是婚后共买：谁拿房谁补对方净值的一半；拿不出补偿金的一方，可考虑把房折价给另一方或出售分款。
- 话术："房子归我，我按共同还贷加增值补你 XX 万，这个数有依据，你可以自己验算。"

## 三、补偿金额怎么压 / 抬

- 补偿不是越低越好，要看整体。若你在房产上多付了补偿，可在存款、股权上少让一步，整体平衡。
- 对方若狮子大开口，用净值对半这条底线回："婚后共买这部分按净值各半，这是基准，超出部分你要给理由。"

## 四、股权 / 投资的处理

- 婚后取得的股权：整体均分或折价补偿，别被"公司是我的"带偏，婚后增值部分配偶有份。
- 婚前股权：只婚后增值部分均分，婚前部分不碰，但增值证据要留（财报、估值记录）。

## 五、债务切割（最容易被坑的一块）

- 共同债务（共签、家庭日常）：各半，别一个人扛。
- 对方私下借的、没用于家庭的债：主张为个人债务，不背。
- 话术："这笔债我没签字也没用于家里，按规则是你要自己还的。"

## 六、防被忽悠清单

- 对方说"婚前房全是我的，你一分没有"——错，婚后共同还贷及增值你有一半。
- 对方说"公司股权跟你没关系"——婚后取得的部分你有份；婚前取得的婚后增值你也有份。
- 对方隐瞒存款/理财——可主张分割时少分或不分，并另行追讨。
- 任何口头承诺必须落进离婚协议书面条款，否则无效。

## 七、何时该停手找律师

出现以下任一情况，别自己谈，带上本测算去找执业律师：
- 涉及过错赔偿、隐匿转移财产
- 有未成年子女抚养费争议
- 存在婚内财产协议约定
- 对方请了律师而你没请
