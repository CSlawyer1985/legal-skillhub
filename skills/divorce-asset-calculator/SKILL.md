# 离婚财产计算器 (divorce-asset-calculator)

当用户说「离婚 / 财产分割 / 离婚谈判 / 婚前财产 / 共同还贷 / 离婚计算器 / 房产怎么分 / 离婚能分多少 / 婚内财产」时触发。

## 适用场景
本技能帮面临离婚的人，在签协议或上法庭之前，先算清"我能分多少、要补多少"。它把房产、存款、股权、债务按《民法典》通用规则拆成结构化分割明细，并给出谈判要点，让你带着数字去谈，而不是被对方带节奏。

典型用法：
- 婚前一方首付、婚后共同还贷的房子，想知道该补偿对方多少
- 婚后买房/存钱/持股，想知道各半分割的具体金额
- 有几笔债，分不清哪些是共同债、哪些是个人的
- 想生成一份能直接拿去谈的分割方案

## 输入规范（让用户逐项给）
收集以下信息，越具体算得越准：
- 结婚年限
- 房产：每套的现值、原购价、取得时间（婚前首付/婚后共买）、首付出资方、婚后共同还贷本息、剩余贷款、登记在谁名下
- 存款：婚后累计金额（婚前指定为个人的请说明）
- 股权/投资：现值、取得时间、若婚前取得请说明婚后增值额
- 债务：金额、性质（共同债务/个人债务/房产附随贷款）
- 其他：是否有过错、隐匿财产、财产约定制等（本工具默认不计入，需另行评估）

## 输出规范（每次按这个结构）
1. 各项分割明细：每项资产的归属、现值、应付补偿、一句话依据
2. 债务承担：共同债各半、个人债各自承担、房贷随房走
3. 双方净得汇总：男方/女方各净得多少（资产 - 补偿 - 债务 - 房贷）
4. 谈判要点：先锁房产补偿、再用补偿平衡其他项、过错另行主张
5. 免责声明：非法律意见，建议咨询律师

输出必须是结构化明细（表格或 JSON），不是一段散文。

## 成果物（这是本技能的交付重点）
计算完成后，运行 `scripts/calculator.py` 的 `to_html_report()` 生成一份《离婚财产分割测算报告》：
- A4 版式的自包含 HTML 文件，含分割明细表、债务承担表、双方净得汇总、谈判要点、报告编号与生成时间
- 用户浏览器打开后按 Ctrl+P 选择"另存为 PDF"，即得一份可保存、可打印、可发给对方或律师的正式报告
- 环境若装有 weasyprint 或 wkhtmltopdf，调用 `to_pdf_report()` 可直接产出 PDF

给用户结果时，务必告诉他报告文件在哪、怎么转 PDF。谈判桌上摊开一份带明细和依据的报告，和口头报个数字，是两回事。

## 引擎说明
`scripts/calculator.py` 是可运行的计算引擎（Python 3.8+，纯标准库）：
```
from calculator import new_case, run, to_report, to_html_report
case = new_case(); case["marriage_years"] = 8 ...
result = run(case)          # 结构化 JSON
print(to_report(result))    # 可读文本
to_html_report(result)      # 生成成果物报告
```
输入结构化参数即返回 JSON，便于将来封装为按次调用的服务（per_call）。

## 红线提醒
- 不承诺"你一定能拿这么多"，只给典型情形下的建模估算
- 不替代律师；涉及过错赔偿、隐匿财产、抚养费、财产约定制时需另行专业评估
- 所有数字基于通用规则，个案以法律和证据为准
