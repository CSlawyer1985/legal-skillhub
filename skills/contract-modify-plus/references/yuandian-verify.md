# yuandian-verify.md — 华宇元典法律数据 MCP 校验规范

> 本技能强制要求：凡修改建议涉及法律引用，必须经华宇元典核验。本文定义调用流程与结果处理。
> 本规范服务于三方法论融合的修改逻辑（《三观四步法（第五版）》+《完美的合同（第四版）》+《合同审查与修改实务》杨司和2022）：法条核验集中于 Step 4（微观"与法律比"与宏观/中观合法性判断的支撑），确保所有写入修订的 `legal_basis` 真实有效。

## 一、前置：确认可用工具
调用前用 `ToolSearch` 查询 `yuandian-mcp` 当前暴露的工具名（工具名可能随版本变化）。常见能力（以实际返回为准）：
- 法条语义检索：`yuandian_law_vector_search`
- 法律幻觉检测：`yuandian_hall_detect`
- 法条关键词检索：`yuandian_rh_ft_search`
- 法条详情：`yuandian_rh_ft_detail`
- 案例检索：`yuandian_rh_ptal_search`

## 二、校验流程
1. 提取 `modify-plan.json` 中所有 `legal_basis` 非空的 finding。
2. 对每个 finding：
   - 调用法条语义检索，传入"法规全称 + 条号 + 关键表述"。
   - 调用法律幻觉检测，传入"该修改建议的完整依据文本"。
3. 结果判定：
   - **一致**：`verify_status=verified`，修订说明标"✅ 引用一致（华宇元典核验）"。
   - **不一致/修正**：以华宇元典返回为准修正 `legal_basis`，再标 verified。
   - **未命中**：`verify_status=unverified`，标"⏳ 待人工复核"，不得写入修订依据。

## 三、成本与降级
- 仅对含法律引用的 finding 校验；纯商业条款跳过。
- MCP 未连接：全部 finding 标 `unverified`，并在交付报告中醒目提示"法条未经核验，须人工复核"。
- 单次幻觉检测调用额度较高，禁止对整份合同批量盲检。

## 四、引用标注格式（写入修改说明）
```
依据：《中华人民共和国民法典》第XXX条（现行有效，华宇元典核验✅）
案例：（如有）案号 — 裁判要点（华宇元典检索）
未核验：⏳ 待人工复核
```
