# 劳动争议纠纷——要素式起诉状模块速览

> **模板文件**: assets/01-劳动争议纠纷-民事起诉状.docx
> **表格结构**: 28行 × 4列
> 
> ⚠️ **重要提示**: 劳动仲裁是诉讼前置程序！必须先申请劳动仲裁，对仲裁裁决不服才能向法院起诉。

---

## 一、特色模块（Row09–Row18）

| 行号 | 模块 | 说明 |
|:---:|------|------|
| Row09 | **是否主张工资支付** | 确认是否主张用人单位支付欠付工资 |
| Row10 | **是否主张未签书面合同双倍工资** | 依据《劳动合同法》第82条主张未签合同的双倍工资差额 |
| Row11 | **是否主张加班费** | 确认是否主张加班工资，需明确加班事实 |
| Row12 | **是否主张未休年休假工资** | 确认是否主张未休年休假的300%工资报酬 |
| Row13 | **是否主张未缴纳社保造成的经济损失** | 因用人单位未缴社保导致的实际损失索赔 |
| Row14 | **是否主张解除劳动合同经济补偿** | 依据《劳动合同法》第46条主张经济补偿金（N） |
| Row15 | **是否主张违法解除劳动合同赔偿金** | 依据《劳动合同法》第87条主张赔偿金（2N） |
| Row16 | **未列明请求** | 兜底条款，用于列明以上未覆盖的其他诉讼请求 |
| Row17 | **诉讼费用承担** | 明确诉讼费用的承担方式 |
| Row18 | **是否已经申请诉前保全** | 确认是否已向法院申请诉前财产保全 |

## 二、事实理由特色（Row20–Row27）

| 行号 | 模块 | 说明 |
|:---:|------|------|
| Row20 | **劳动合同签订情况** | 是否签订书面合同、合同类型、签订时间等 |
| Row21 | **劳动合同履行情况** | 工作岗位、工作地点、工资标准、实际履行情况 |
| Row22 | **解除或终止劳动关系情况** | 解除方式（协商/单方/违法解除）、解除时间、解除理由 |
| Row23 | **工伤情况** | 是否发生工伤、工伤认定结论、伤残等级、工伤待遇 |
| Row24 | **劳动仲裁相关情况** ❗必填 | 仲裁申请时间、仲裁裁决文号、裁决结果、裁决送达时间 |
| Row25 | **其他相关情况** | 其他与争议相关的事实 |
| Row26 | **诉请依据** | 各项诉讼请求对应的具体法律条文 |
| Row27 | **证据清单** | 起诉所依据的全部证据材料清单 |

## 三、核心法律依据

### 《中华人民共和国劳动合同法》

| 条文 | 内容要点 |
|:----:|----------|
| **第七条** | 用人单位自用工之日起即与劳动者建立劳动关系 |
| **第十条** | 建立劳动关系应当订立书面劳动合同；已用工未签的应在**一个月内**订立 |
| **第四十六条** | 应当支付经济补偿的七种情形 |
| **第四十七条** | 经济补偿按劳动者在本单位工作年限计算（**N**标准） |
| **第八十二条** | 未签书面合同超过一个月不满一年的，应支付**双倍工资** |
| **第八十七条** | 违法解除或终止合同的，应支付**二倍经济补偿金（2N）** |

### 《中华人民共和国劳动争议调解仲裁法》

| 条文 | 内容要点 |
|:----:|----------|
| **第二十七条** | 劳动争议仲裁时效为**1年**，从知道或应当知道权利被侵害之日起计算 |

## 四、使用说明

1. 本模板为要素式起诉状，逐项填写即可形成完整的民事起诉状
2. **Row24（劳动仲裁相关情况）** 为必填项——劳动仲裁是法院受理劳动争议诉讼的前置条件
3. 每一项请求均需在 Row26（诉请依据）中注明对应的法律条文
4. Row27（证据清单）应附上劳动仲裁裁决书、送达回证等关键证据
5. 起诉时需特别注意是否超过**15日**的法定起诉期限（自收到仲裁裁决书之日起算）
