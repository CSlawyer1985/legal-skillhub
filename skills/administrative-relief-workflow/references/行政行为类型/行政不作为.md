# 行政不作为类案件要点

## 法律依据
- 《行政诉讼法》第12条第6项
- 《行政复议法》第11条第7项
- 各单行法律法规中的职责条款

## 不作为的构成要件

| 要件 | 说明 |
|:---|:---|
| **有法定职责** | 法律、法规、规章明确规定该行政机关有该项职责 |
| **当事人提出申请** | 依申请的职责需要当事人先提出过申请（依职权的除外） |
| **逾期未履行** | 超过法定期限仍未作出处理 |
| **无正当理由** | 不存在不可抗力等阻却事由 |

## 法定职责的来源

| 来源 | 示例 |
|:---|:---|
| 法律 | 《治安管理处罚法》规定公安机关有维护治安的职责 |
| 法规 | 《政府信息公开条例》规定行政机关有公开信息的义务 |
| 规章 | 部门规章规定的审批/许可职责 |
| 行政承诺 | 行政机关公开承诺的办理期限（可构成自设义务） |
| 先行行为 | 行政机关已受理申请后产生的处理义务 |

## 法定期限

| 行为类型 | 法定期限 | 法律依据 |
|:---|:---|:---|
| 行政许可 | 受理后**20个工作日**（可延长10个工作日） | 《行政许可法》第42条 |
| 政府信息公开 | 收到申请之日起**20个工作日**（可延长20个工作日） | 《政府信息公开条例》第33条 |
| 履行保护人身权/财产权职责 | 接到申请后**及时**履行 | 各单行法 |
| 其他 | 看各单行法律法规的具体规定 | — |
| 无明确规定的 | 合理期限内（一般不超过2个月） | 司法解释 |

## 不作为案件的举证责任

| 举证方 | 举证内容 |
|:---|:---|
| **原告/申请人** | ①曾向行政机关提出申请 ②行政机关逾期未履行 |
| **被告/被申请人** | ①没有该项法定职责 ②已经履行 ③有正当理由（如不可抗力/申请人材料不全需补充等） |

## 常见抗辩及反驳

| 行政机关抗辩 | 反驳思路 |
|:---|:---|
| 没有法定职责 | 查找法律依据，证明该机关有该职责 |
| 申请人材料不全 | 行政机关应一次性告知补正，未告知则不能以此为由不处理 |
| 正在办理中 | 是否超过法定期限？超期即构成不作为 |
| 不属于本机关管辖 | 应告知当事人向有权机关申请，不能置之不理 |
| 已经口头答复 | 是否出具了书面决定？口头答复不等于依法履职 |

## 诉讼请求/复议请求

- 责令被告/被申请人在一定期限内履行法定职责
- 如有损害→可同时请求赔偿
