# 行政协议类案件要点

## 定义

行政协议是指行政机关为了实现行政管理或者公共服务目标，与公民、法人或者其他组织之间，经过协商一致达成的具有行政法上权利义务内容的协议。

## 法律依据

- 《行政诉讼法》第12条第1款第11项：认为行政机关不依法履行、未按照约定履行或者违法变更、解除政府特许经营协议、土地房屋征收补偿协议等协议的
- 《行政复议法》第11条第9项：认为行政机关不依法履行或者未按照约定履行行政协议
- 《最高人民法院关于审理行政协议案件若干问题的规定》（法释〔2019〕17号）

## 行政协议的识别标准

根据最高法司法解释，认定行政协议需同时满足以下要素：

| 要素 | 说明 |
|:---|:---|
| **主体要素** | 一方必须是行政机关（或法律法规授权的组织） |
| **目的要素** | 目的是实现行政管理目标或公共服务目标 |
| **意思要素** | 经双方协商一致达成（区别于单方行政行为） |
| **内容要素** | 协议内容具有行政法上的权利义务（区别于民事合同） |

## 常见类型

| 类型 | 典型情形 | 法律依据 |
|:---|:---|:---|
| **政府特许经营协议** | 城市供水/供气/公交等特许经营 | 《基础设施和公用事业特许经营管理办法》 |
| **土地房屋征收补偿协议** | 国有土地上房屋征收补偿、集体土地征收补偿 | 《国有土地上房屋征收与补偿条例》 |
| **矿业权等国有自然资源使用权出让协议** | 矿业权出让、海域使用权出让 | 《矿产资源法》《海域使用管理法》 |
| **政府与社会资本合作协议（PPP）** | PPP项目合同 | 相关PPP政策法规 |
| **保障性住房的建设和运营协议** | 保障性住房建设/运营/租赁协议 | 住房保障相关法规 |
| **招商引资协议** | 地方政府与企业的投资合作协议 | 各地招商引资政策 |
| **土地/林地承包经营合同** | 农村土地承包、林地承包 | 《农村土地承包法》 |

## 行政协议的可诉性分析

### 受案范围

| 行为类型 | 是否可诉 | 法律依据 |
|:---|:---|:---|
| 行政机关不依法履行行政协议 | ✅ 可诉 | 《行政诉讼法》第12条第11项 |
| 行政机关未按约定履行行政协议 | ✅ 可诉 | 同上 |
| 行政机关违法变更行政协议 | ✅ 可诉 | 同上 |
| 行政机关违法解除行政协议 | ✅ 可诉 | 同上 |
| 行政机关单方调整协议条款 | ✅ 可诉 | 属于"不依法履行"的范畴 |
| 行政协议的订立争议（如缔约过失） | ⚠️ 有争议 | 需具体分析 |
| 行政机关行使行政优益权 | ✅ 可诉 | 属于行政行为的审查范畴 |

### 行政优益权的审查

行政机关在行政协议中享有优益权（为公共利益需要可单方变更/解除协议），但该权力的行使受严格限制：

| 审查要素 | 要求 |
|:---|:---|
| 目的正当性 | 必须是为了公共利益需要 |
| 必要性 | 变更/解除是否确有必要 |
| 比例原则 | 是否选择了对相对人损害最小的方式 |
| 补偿义务 | 因优益权行使导致相对人损失的，应当补偿 |
| 程序合法性 | 是否履行了必要的程序（告知、听取意见等） |

## 合法性审查要点

### 1. 协议效力审查
- 协议是否属于行政协议？（与民事合同的区分是关键）
- 行政机关是否有权签订该协议？
- 协议是否存在无效情形（重大且明显违法、违反强制性规定等）

### 2. 履行情况审查
- 行政机关是否按照约定全面履行了义务？
- 是否存在不履行、迟延履行、瑕疵履行等情形？
- 相对人是否已经履行了自己的义务？

### 3. 变更/解除合法性审查
- 变更/解除是否有合法依据？
- 是否为了公共利益需要？
- 是否遵循了法定程序？
- 是否给予了合理补偿？

### 4. 行政优益权行使审查
- 行使优益权是否有事实和法律依据？
- 是否符合比例原则？
- 是否给予了充分补偿？

## ⚠️ 行政协议案件的特殊注意事项

1. **行政协议 vs 民事合同的区分**：这是行政协议案件的首要问题。如果法院认定协议属于民事合同，将裁定不予立案或驳回起诉，当事人需要走民事诉讼途径
2. **举证责任**：
   - 对行政协议的订立、变更、解除等行政行为的合法性，由行政机关举证
   - 对协议的履行情况，双方各自承担举证责任
3. **诉讼时效**：适用行政诉讼的起诉期限（6个月），而非民事诉讼时效（3年）
4. **判决类型**：法院可以判决继续履行、采取补救措施、赔偿损失等
5. **仲裁条款的效力**：行政协议中约定仲裁条款的，仲裁条款无效（行政争议不可仲裁）
6. **行政复议与行政诉讼并行**：2024年新法将行政协议纳入复议受案范围，当事人可以选择先申请复议

## 行政协议案件中的律师工作要点

1. **首先确认协议性质**：是行政协议还是民事合同？这决定了整个救济路径
2. **审查协议条款**：明确行政机关的具体义务是什么
3. **收集履行证据**：行政机关的哪些承诺没有兑现？
4. **注意起诉期限**：行政协议案件适用行政诉讼的起诉期限，比民事诉讼时效短得多
5. **合理设计诉讼请求**：可以继续履行、可以请求赔偿、可以确认违法，需根据具体情况选择
6. **关注行政优益权**：如果行政机关以公共利益为由单方变更/解除，需要重点审查其理由是否成立
