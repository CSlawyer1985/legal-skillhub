# 行政处罚类案件要点

## 法律依据
- 《行政处罚法》（2021年修订）
- 各单行法律法规中的处罚条款

## 处罚种类（《行政处罚法》第9条）

1. 警告、通报批评
2. 罚款
3. 没收违法所得、没收非法财物
4. 暂扣许可证件、降低资质等级、吊销许可证件
5. 限制开展生产经营活动、责令停产停业、责令关闭、限制从业
6. 行政拘留
7. 法律、行政法规规定的其他行政处罚

## 处罚程序要求

### 一般程序（第54-60条）

| 程序环节 | 要求 | 违反后果 |
|:---|:---|:---|
| 立案 | 发现违法行为→立案 | — |
| 调查取证 | 2名以上执法人员、出示执法证件 | 程序违法 |
| 告知权利 | 作出处罚决定前告知当事人拟作出的处罚内容及事实、理由、依据，告知享有陈述/申辩权 | 程序违法 |
| 听取陈述/申辩 | 必须充分听取，不得因申辩加重处罚 | 程序违法 |
| 法制审核 | 重大处罚决定作出前须经法制审核（第58条） | 程序违法 |
| 集体讨论 | 情节复杂/重大违法行为给予较重处罚→负责人集体讨论 | 程序违法 |
| 送达 | 决定书在宣告后当场交付；不在场的→7日内送达 | 影响生效时间 |

### 听证程序（第63-65条）

**应当告知听证权的情形**：
- 较大数额罚款
- 没收较大数额违法所得/非法财物
- 降低资质等级、吊销许可证件
- 责令停产停业、责令关闭、限制从业
- 其他较重的行政处罚
- 法律、法规、规章规定的其他情形

**违反听证程序的法律后果**：行政处罚决定不能成立（第63条）

### 简易程序（第51-53条）

适用条件：违法事实确凿+有法定依据+处罚较轻（对公民200元以下/对法人3000元以下罚款或警告）

## 处罚的合法性审查要点

### 实体审查

| 审查项 | 常见问题 |
|:---|:---|
| 事实认定 | 违法事实是否清楚？证据是否充分？ |
| 法律适用 | 适用法条是否正确？是否存在新法优于旧法的问题？ |
| 处罚幅度 | 是否在法定幅度内？是否过罚相当？ |
| 从轻/减轻/不予处罚 | 是否存在应当从轻/减轻/不予处罚的情形？ |

### 程序审查

| 审查项 | 常见问题 |
|:---|:---|
| 执法主体 | 执法人员是否有执法资格？是否2人以上？ |
| 权利告知 | 是否告知了陈述/申辩权？ |
| 听证 | 是否属于应当听证的情形？是否告知了听证权？ |
| 法制审核 | 是否属于重大处罚需要法制审核？ |
| 期限 | 是否超期作出处罚决定？ |
| 送达 | 是否依法送达？ |

## 过罚相当原则（第5条第2款）

- 设定和实施行政处罚必须以事实为依据
- 与违法行为的事实、性质、情节以及社会危害程度相当
- 明显不当的→可以撤销或变更

## 常见违法情形

1. 未告知陈述/申辩权→程序违法
2. 拒绝听取陈述/申辩→程序违法
3. 应当听证而未告知听证权→处罚决定不能成立
4. 未经法制审核的重大处罚→程序违法
5. 处罚明显过重→违反过罚相当原则
6. 超期作出处罚决定→程序违法
