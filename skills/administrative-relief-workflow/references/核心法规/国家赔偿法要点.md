# 国家赔偿法要点（行政赔偿部分）

> 详见《中华人民共和国国家赔偿法》（2012年修正）

## 行政赔偿范围（第3-4条）

行政机关及其工作人员在行使职权时，侵犯人身权或财产权的，受害人有取得赔偿的权利。

## 赔偿请求人

- 受害的公民/法人/其他组织
- 受害公民死亡的→其继承人和其他有扶养关系的亲属
- 受害法人/组织终止的→承受其权利的法人/组织

## 赔偿义务机关（第7-8条）

| 情形 | 赔偿义务机关 |
|:---|:---|
| 行政机关单独侵权 | 该行政机关 |
| 共同侵权 | 共同赔偿义务机关（连带责任） |
| 法律法规授权组织侵权 | 被授权的组织 |
| 复议维持 | 原行政机关 |
| 复议加重 | 复议机关对加重部分承担 |

## 赔偿方式

- **支付赔偿金**（主要方式）
- **返还财产**
- **恢复原状**

## 赔偿标准（第33-36条）

| 损害类型 | 赔偿标准 |
|:---|:---|
| 人身自由受限 | 每日赔偿金按国家上年度职工日平均工资计算 |
| 生命健康损害 | 医疗费+误工费+残疾赔偿金/死亡赔偿金+丧葬费 |
| 精神损害 | 造成严重后果的→支付精神损害抚慰金 |
| 财产损害 | 直接损失 |

## 赔偿程序

- 可以单独提出赔偿请求（先向赔偿义务机关提出）
- 也可以在行政复议/行政诉讼中一并提出

## 举证责任

- 赔偿请求人应对损害事实提供证据
- 赔偿义务机关对减免责任的事由提供证据
