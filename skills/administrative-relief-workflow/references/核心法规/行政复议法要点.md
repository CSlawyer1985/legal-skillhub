# 行政复议法要点（2024年新修订版）

> 《中华人民共和国行政复议法》2023年9月1日修订通过，2024年1月1日起施行。

## 第一章 总则

- **第1条**：立法目的——防止和纠正违法的或不当的行政行为
- **第2条**：公民/法人/其他组织认为行政行为侵犯其合法权益，有权申请行政复议
- **第4条**：行政复议机关办理复议案件，应当合法、公正、公开、高效、便民、为民

## 第二章 行政复议申请

### 受案范围（第11条，15类）

1. 行政处罚
2. 行政强制措施、行政强制执行
3. 行政许可（申请许可被拒绝或不予答复）
4. 自然资源所有权/使用权确权决定
5. 征收征用及补偿决定
6. 行政赔偿决定
7. 不履行保护人身权/财产权/受教育权等法定职责
8. 不依法发放抚恤金/社会保险待遇/最低生活保障
9. 行政协议（不依法/按约定履行）
10. 政府信息公开
11. 滥用行政权力排除/限制竞争
12. 违法集资/摊派/违法要求履行义务
13. 其他行政行为侵犯合法权益（兜底条款）
14-15. （扩展空间）

### 不属于复议范围（第12条）

- 国防、外交等国家行为
- 行政法规、规章或具有普遍约束力的决定/命令（抽象行政行为不能直接复议）
- 行政机关对工作人员的奖惩/任免等内部行为
- 行政机关对民事纠纷的调解

### 申请期限（第20条）

- **一般期限**：知道该行政行为之日起**60日**内
- **例外**：法律规定的申请期限超过60日的，从其规定
- **不作为案件**：履职期限届满之日起算
- **未告知期限/诉权**：从知道或应当知道之日起算，最长不超过1年

### 申请人资格（第13-16条）

- 行政相对人
- 利害关系人
- 有权申请的公民死亡的，其近亲属可以申请
- 有权申请的法人/组织终止的，承受其权利的法人/组织可以申请

### 申请方式（第22条）

- 可以书面申请，也可以口头申请
- 口头申请的，复议机关应当当场记录

## 第三章 行政复议受理

### 受理条件（第28条）

- 有明确的申请人和符合本法规定的被申请人
- 申请人与被申请复议的行政行为之间有利害关系
- 有具体的复议请求和理由
- 在法定申请期限内提出
- 属于本法规定的复议范围
- 属于本机关的管辖范围
- 其他复议机关或法院尚未受理

### 审查期限

- 收到申请之日起**5个工作日**内审查
- 符合条件的→受理
- 不符合条件的→决定不予受理并说明理由
- 材料不齐全的→一次性告知需要补正

## 第四章 行政复议管辖（第24条，重大修改）

### ⚠️ 新法重大变化：统一管辖

**旧法**：可以选择向本级政府或上一级主管部门申请复议
**新法**：**原则上统一由县级以上地方各级人民政府管辖**

| 被申请人 | 复议机关 |
|:---|:---|
| 县级以上政府部门 | **本级人民政府** |
| 县级以上地方政府 | **上一级人民政府** |
| 乡镇政府 | **上一级（县级）人民政府** |
| 海关/金融/外汇/税务/国安等垂直管理机关 | **上一级主管部门** |
| 法律法规授权的组织 | **直接管理该组织的机关的同级政府或上一级主管部门** |

## 第五章 行政复议审理

### 审理方式（第41条）

- **原则上书面审查**
- 但有以下情形之一的，应当听取当事人意见：
  - 当事人要求听证的
  - 案情重大、复杂的
  - 复议机关认为需要听证的其他情形

### 被申请人的举证责任（第44条）

- 被申请人应当自收到申请书副本/笔录复印件之日起**10日**内提出书面答复并提交证据依据
- 被申请人不按时提交的→视为没有证据，复议机关可决定撤销该行政行为

### 审查范围（第49条）

- 既审查**合法性**，也审查**合理性**（适当性）
- 这是复议优于诉讼的重要特点之一

### 审理期限（第62条）

- 自受理之日起**60日**内作出复议决定
- 情况复杂的，经批准可延长，但最多不超过**30日**

## 第六章 行政复议决定

### 决定类型（第64-71条）

| 决定类型 | 适用条件 | 法律条文 |
|:---|:---|:---|
| **维持** | 认定事实清楚，证据确凿，适用依据正确，程序合法，内容适当 | 第65条 |
| **撤销** | 主要事实不清/证据不足；适用依据错误；违反法定程序；超越/滥用职权；明显不当 | 第64条 |
| **变更** | 认定事实清楚但适用依据错误/内容不当 | 第64条 |
| **确认违法** | 撤销/变更已无实际意义等 | 第66条 |
| **责令履行** | 被申请人不履行法定职责 | 第67条 |
| **驳回** | 申请人认为不作为但被申请人已履行/无此职责/超过期限等 | 第69条 |

### 撤销+重作的限制（第65条第2款）

- 复议机关决定撤销的，可以责令被申请人在一定期限内重新作出行政行为
- 被申请人不得以同一事实和理由作出与原行为相同/基本相同的行政行为

## 第七章 附则

- 复议不收费（第85条）
