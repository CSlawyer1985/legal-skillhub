# 行政诉讼法要点

> 《中华人民共和国行政诉讼法》2014年修正，2017年修正。

## 第一章 总则

- **第2条**：公民/法人/其他组织认为行政机关和行政机关工作人员的行政行为侵犯其合法权益，有权提起诉讼
- **第6条**：人民法院审理行政案件，对行政行为是否合法进行审查（合法性审查原则）

## 第二章 受案范围

### 受案范围（第12条）

与行政复议法第11条大体一致，以下为重点项：
1. 行政处罚
2. 行政强制措施/执行
3. 行政许可
4. 自然资源确权
5. 征收征用及补偿
6. 不履行法定职责
7. 不依法发放抚恤金/社保/低保
8. 行政协议（特许经营/征收补偿等）
9. 侵犯经营自主权/农村土地承包经营权
10. 滥用行政权力排除限制竞争
11. 违法集资/摊派
12. 其他侵犯人身权/财产权等合法权益

### 不受案范围（第13条）

1. 国防、外交等国家行为
2. 行政法规/规章/具有普遍约束力的决定/命令
3. 行政机关对工作人员的奖惩/任免
4. 法律规定由行政机关最终裁决的行为

## 第三章 管辖

### 级别管辖

| 法院 | 管辖案件 | 条文 |
|:---|:---|:---|
| **基层人民法院** | 一般行政案件 | 第14条 |
| **中级人民法院** | ①对国务院部门或县级以上地方政府提起诉讼的案件 ②海关处理案件 ③本辖区重大复杂案件 | 第15条 |
| **高级人民法院** | 本辖区重大复杂的第一审案件 | 第16条 |
| **最高人民法院** | 全国范围内重大复杂的第一审案件 | 第17条 |

### 地域管辖

| 情形 | 管辖法院 | 条文 |
|:---|:---|:---|
| 一般案件 | 最初作出行政行为的机关所在地 | 第18条 |
| 经复议案件 | 原机关所在地 或 复议机关所在地 | 第18条 |
| 限制人身自由 | 被告所在地 或 原告所在地 | 第19条 |
| 不动产 | 不动产所在地（专属管辖） | 第20条 |

## 第四章 诉讼参加人

### 原告（第25条）

- 行政相对人
- 利害关系人
- 有权起诉的公民死亡→近亲属
- 有权起诉的法人/组织终止→承受其权利的法人/组织

### 被告（第26条）⚠️ 重点

| 情形 | 被告 |
|:---|:---|
| 直接起诉 | 作出行政行为的行政机关 |
| 经复议，复议维持 | **原机关 + 复议机关 = 共同被告** |
| 经复议，复议改变 | 复议机关 |
| 复议机关逾期不作决定 | 可选择告原机关或复议机关 |
| 两个以上机关共同作出 | 共同被告 |
| 委托的组织作出 | 委托的行政机关 |
| 行政机关被撤销 | 继续行使其职权的行政机关 |

## 第五章 证据

- **第34条**：被告对作出的行政行为负有举证责任，应当提供作出该行政行为的证据和所依据的规范性文件
- **第35条**：被告不提供或无正当理由逾期提供→视为没有相应证据
- **第37条**：原告可以提供证明行政行为违法的证据。原告提供的证据不成立的，不免除被告的举证责任
- **第38条**：行政赔偿/补偿案件中，原告应对损害事实提供证据

## 第六章 起诉和受理

### 起诉期限（第46条）

| 情形 | 期限 | 起算点 |
|:---|:---|:---|
| 直接起诉 | **6个月** | 知道或应当知道行政行为之日 |
| 复议后起诉 | **15日** | 收到复议决定书之日 |
| 复议机关不作为后起诉 | **15日** | 复议期满之日 |
| 最长保护期（一般） | **5年** | 行政行为作出之日 |
| 最长保护期（不动产） | **20年** | 行政行为作出之日 |

### 起诉条件（第49条）

1. 原告适格
2. 有明确的被告
3. 有具体的诉讼请求和事实根据
4. 属于法院受案范围和受诉法院管辖

## 第七章 审理和判决

### 一审审理期限

- 立案之日起**6个月**内作出判决（第81条）
- 有特殊情况可延长

### 判决类型（第69-78条）

| 判决类型 | 适用条件 | 条文 |
|:---|:---|:---|
| **驳回诉讼请求** | 行政行为证据确凿、适用法律法规正确、符合法定程序 | 第69条 |
| **撤销** | 主要证据不足；适用法律法规错误；违反法定程序；超越职权；滥用职权；明显不当 | 第70条 |
| **部分撤销+责令重作** | 撤销部分+责令重新作出 | 第70条 |
| **变更** | 行政处罚明显不当；其他行政行为涉及款额确定/认定有误 | 第77条 |
| **履行判决** | 被告不履行/拖延履行法定职责 | 第72条 |
| **确认违法** | 撤销/变更已无实际意义等 | 第74条 |
| **确认无效** | 行政行为有重大且明显违法 | 第75条 |
| **给付判决** | 被告应给付抚恤金/社保/低保/赔偿等 | 第73条 |

### 撤销+重作限制（第71条）

- 判决被告重新作出行政行为的，被告不得以同一事实和理由作出与原行为基本相同的行政行为

## 第八章 执行

- **第94条**：当事人必须履行生效判决/裁定/调解书
- **第96条**：行政机关拒绝履行的，法院可以采取的措施（划拨罚款/按日罚款/向监察机关提出司法建议/拘留/追究刑事责任）
- **第97条**：公民/法人申请强制执行期限：判决规定的履行期间最后一日起**2年**内
