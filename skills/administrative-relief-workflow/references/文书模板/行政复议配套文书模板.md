## 1. 行政复议申请书（不服行政行为）

```
行政复议申请书

申请人：（姓名）    性别    出生年月
身份证号码          工作单位
住所（联系地址）    邮政编码  电话
[法人或其他组织：名称、住所、法定代表人/主要负责人姓名及职务]
委托代理人：（姓名）  电话

被申请人：（名称）

行政复议请求：
[明确具体，如：撤销被申请人于X年X月X日作出的（文号）XXX决定]

事实和理由：
[详细陈述案件事实，阐明申请复议的理由和法律依据]

此致
（行政复议机关名称）

附件：1. 申请书副本  份
      2. 申请人身份证明材料复印件
      3. 其他有关材料  份
      4. 授权委托书（有委托代理人的）

申请人（签名或者盖章）：
          年  月  日
```

**说明**：依据《行政复议法》第11条、第14条、第17条、第19条、第22条第1款制定。

## 2. 行政复议申请书（不履行法定职责）

```
行政复议申请书

申请人：（基本信息同上）
被申请人：（名称）

行政复议请求：
[明确请求，如：确认被申请人不履行XXX法定职责的行为违法，并责令被申请人在
X日内履行XXX法定职责]

事实和理由：
[重点说明：何时向被申请人提出了什么申请、被申请人在法定期限内未履行、
相关法定职责的法律依据]

此致
（行政复议机关名称）

附件：（同上）

申请人（签名或者盖章）：
          年  月  日
```

**说明**：适用于申请人认为行政机关不履行法定职责的情形。需附上申请人曾向被申请人提出申请的证据。

## 3. 行政复议申请书（不服行政协议）

```
行政复议申请书

申请人：（基本信息同上）
被申请人：（名称）

行政复议请求：
[明确请求，如：确认被申请人于X年X月X日作出的（文号）XXX决定违法，
该决定系违法变更/解除XX行政协议]

事实和理由：
[重点说明：行政协议的签订情况、协议主要内容、被申请人不依法履行/
违法变更/违法解除协议的具体事实]

此致
（行政复议机关名称）

附件：1.（同上）
      5. 行政协议原件/复印件

申请人（签名或者盖章）：
          年  月  日
```

**说明**：依据《行政复议法》第11条第9项制定。需附上行政协议文本。

## 4. 行政复议代表人推选书

```
行政复议代表人推选书

申请人（姓名）    性别    出生年月
身份证号码        联系电话
住所

[全体申请人共同推选，逐一列明]

代表人权限：
□ 一般授权（代为参加复议活动）
□ 特别授权（代为承认、放弃、变更复议请求，进行和解）

全体申请人签名：
          年  月  日
```

## 5. 第三人参加行政复议申请书

```
第三人参加行政复议申请书

申请人：（基本信息同上）

与被申请人（名称）于X年X月X日作出的（行政行为名称及文号）
有利害关系，申请作为第三人参加行政复议。

理由：
[说明与被申请复议的行政行为之间存在利害关系的具体事实]

此致
（行政复议机关名称）

附件：1. 身份证明
      2. 与行政行为有利害关系的证据材料

申请人（签名或者盖章）：
          年  月  日
```

## 6. 行政复议授权委托书

```
行政复议授权委托书

委托人：（姓名/名称）
受托人：（姓名）  工作单位    职务    联系电话

现委托上列受托人在（申请人）与（被申请人）
（案由）行政复议一案中，作为（申请人）的代理人。

代理权限：
□ 一般代理（代为参加复议活动、提交材料、发表意见）
□ 特别代理（代为承认、放弃、变更行政复议请求，进行和解，
  撤回行政复议申请）

委托人（签名或者盖章）：
          年  月  日
```

## 7. 法定代表人（负责人）身份证明书

[姓名] 在我单位任 [职务] 职务，是我单位的法定代表人（负责人）。

特此证明。

单位（盖章）：
          年  月  日

此致
（行政复议机关名称）

申请人（签名或者盖章）：
          年  月  日

## 10. 撤回行政复议申请书

```
撤回行政复议申请书

申请人：（基本信息同上）

申请人于X年X月X日向贵机关提出行政复议申请（案件编号：XXX），
因[撤回原因]，申请撤回行政复议申请。

此致
（行政复议机关名称）

申请人（签名或者盖章）：
          年  月  日
```

**⚠️ 注意**：撤回后不得以同一事实和理由再次申请行政复议，除非能够证明撤回不是申请人的真实意思表示。

## 13. 停止执行行政行为申请书

```
停止执行行政行为申请书

申请人：（基本信息同上）
被申请人：（名称）

被申请人于X年X月X日作出（行政行为名称及文号），申请人不服，
已向贵机关申请行政复议。

申请停止执行的理由：
[说明该行政行为的执行将造成难以弥补的损失，且停止执行不损害
社会公共利益]

此致
（行政复议机关名称）

附件：1. 证明将造成难以弥补损失的证据
      2. 行政复议申请受理通知

申请人（签名或者盖章）：
          年  月  日
```

**法律依据**：《行政复议法》第56条

## 14. 行政复议和解协议

```
行政复议和解协议

申请人：（基本信息）
被申请人：（名称）

因[案由]，申请人与被申请人达成如下和解协议：

一、[和解的具体内容]
二、[和解的具体内容]
三、[其他约定事项]

申请人确认：本和解协议系本人真实意思表示。
被申请人确认：本协议系本机关在法定权限范围内作出。

申请人（签名或者盖章）：          被申请人（盖章）：
          年  月  日                      年  月  日

行政复议机构确认（盖章）：
          年  月  日
```

## 15. 行政复议监督申请书

```
行政复议监督申请书

申请人：（基本信息同上）

贵机关已于X年X月X日作出（行政复议决定书文号）。
申请人认为被申请人[名称]未依法履行该行政复议决定，
申请贵机关责令被申请人履行。

未履行情况：
[详细说明被申请人未履行的具体事实]

此致
（行政复议机关名称）

附件：1. 行政复议决定书
      2. 被申请人未履行的证据

申请人（签名或者盖章）：
          年  月  日
```
