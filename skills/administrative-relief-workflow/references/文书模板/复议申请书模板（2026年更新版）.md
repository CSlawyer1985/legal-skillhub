# 行政复议申请书模板（2026年更新版）

> **来源**：根据司法部《行政复议文书示范文本》（2025年8月）及行政复议网上服务平台整理

---

## 模板一：不服行政行为申请行政复议（最常用）

适用情形：收到行政处罚决定书、行政强制决定书、不予认定工伤决定书等书面行政行为后，认为该行为违法或不当。

```
行政复议申请书

申请人：[姓名]，性别[男/女]，[出生年月]，身份证号码：[号码]，
工作单位：[单位名称]，住所：[有效证件上的住所地址]。
委托代理人（如有）：[姓名]，[基本情况]
邮寄地址及联系电话：[接收法律文书的地址和电话]

被申请人：[行政机关全称]
住所：[地址]
法定代表人：[姓名]，[职务]

行政复议请求：
一、[撤销/部分撤销/责令重做/变更/确认违法/确认无效/采取补救措施/给予行政赔偿]
    被申请人于[YYYY]年[MM]月[DD]日作出的[文书全称]（[文号]）；
二、[如有赔偿请求，列明具体请求]；
三、[其他请求]。

事实与理由：

被申请人于[YYYY]年[MM]月[DD]日向申请人送达了[文书名称及文号]，
认定申请人[简述被申请人认定的事实]。

申请人认为该行政行为存在以下违法或不当之处：

一、事实认定方面
[写明被申请人认定的事实是否清楚、证据是否充分。
如：被申请人认定申请人存在××行为，但申请人并未实施该行为/
被申请人所依据的证据不足。]

二、法律适用方面
[写明被申请人适用的法律是否正确。
如：被申请人依据《××法》第×条作出处罚，但该条款并不适用于本案情形。]

三、程序方面
[写明被申请人的程序是否合法。
如：被申请人在作出处罚前未告知申请人享有陈述、申辩和听证的权利，
违反了法定程序。]

四、合理性与适当性方面
[写明处罚是否过重、是否合理。
如：即便申请人存在轻微违法行为，被申请人作出的××万元罚款也明显过重，
与违法行为的事实、性质、情节不相适应。]

综上所述，被申请人作出的[具体行政行为名称]认定事实不清/适用法律错误/
违反法定程序/处罚明显不当，严重侵害了申请人的合法权益。
恳请复议机关依法[撤销/变更/确认违法]该行政行为。

此致
[行政复议机关名称]

                                        申请人（签名或盖章）：
                                        日期：    年  月  日

附件：
1. 行政复议申请书副本[  ]份
2. 申请人身份证明材料复印件（公民为身份证复印件；
   法人或其他组织为营业执照复印件及法定代表人身份证明）[  ]份
3. 被申请人作出的行政行为法律文书复印件[  ]份
4. 其他证据材料[  ]份（共[  ]页）
5. 授权委托书（如有委托代理人）[  ]份
```

```

申请人：[姓名]，性别[男/女]，[出生年月]，身份证号码：[号码]，

邮寄地址及联系电话：[接收法律文书的地址和电话]

被申请人：[行政机关全称]
住所：[地址]
法定代表人：[姓名]，[职务]

行政复议请求：
一、责令被申请人限期履行[具体法定职责名称]法定职责；
二、[确认违法/采取补救措施/给予行政赔偿等]。

事实与理由：

申请人于[YYYY]年[MM]月[DD]日通过[方式]向被申请人提出[履行法定职责的申请内容]。

被申请人于[YYYY]年[MM]月[DD]日收到申请人的申请（如能确认）。
```

## ⚠️ 重要提示：复议机关确认（2024年新法变化）

根据2024年1月1日起施行的新《行政复议法》第24条，复议管辖已做重大调整：

| 被申请人类型 | 复议机关 | 法律依据 |
|:---|:---|:---|
| 县级以上地方各级政府部门（如区人社局、区市场监管局） | **本级人民政府**（如区人民政府） | 第24条第1款 |
| 县级以上地方各级政府 | **上一级人民政府** | 第24条第2款 |
| 乡镇人民政府 | **上一级（县级）人民政府** | 第24条第2款 |
| 海关、金融、外汇、税务等垂直领导机关 | **上一级主管部门** | 第24条第3款 |

**⚠️ 常见错误**：
- ❌ 错误：对区人社局不服 → 找市人社局复议（这是旧法规则）
- ✅ 正确：对区人社局不服 → 找区人民政府复议（新法规则）

**示例**：
- 对"上海市浦东新区人力资源和社会保障局"的工伤认定不服 → 复议机关为"上海市浦东新区人民政府"
- 对"北京市朝阳区市场监督管理局"的处罚不服 → 复议机关为"北京市朝阳区人民政府"

## 法律依据

本模板根据以下法律法规制定：
- 《中华人民共和国行政复议法》（2023年9月1日修订，2024年1月1日施行）
  - 第11条：受案范围
  - 第14条：申请人资格
  - 第17条：被申请人
  - 第19条：第三人
  - 第22条：申请方式
  - 第24条：复议管辖

## 使用说明

1. **选择合适的模板**：根据案件类型选择模板一、二或三
2. **填写完整信息**：所有方括号[]内的内容都需要填写
3. **复议机关必须正确**：务必按照新法确认复议机关，不要按旧法习惯写上级主管部门
4. **事实与理由要具体**：每个理由都要引用具体法律条文
5. **附件要齐全**：按照清单准备附件材料
6. **份数要求**：申请书一般一式两份（复议机关留存+送达被申请人）
