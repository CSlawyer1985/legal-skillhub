# 行政复议申请书模板

```
行政复议申请书

申请人：[姓名]，[性别]，[民族]，[出生日期]，住[地址]。
身份证号：[号码]
联系电话：[号码]

（法人/组织：名称[全称]，住所地[地址]，统一社会信用代码[代码]。
法定代表人：[姓名]，[职务]。联系电话：[号码]。）

被申请人：[行政机关全称]
住所地：[地址]
法定代表人：[姓名]，[职务]

行政复议请求：

一、[撤销/变更/确认违法]被申请人于[YYYY]年[MM]月[DD]日作出的
    [文书全称]（[文号]）；
二、[如有赔偿请求，列明具体请求]；
三、[其他请求，如责令重新作出行政行为等]。

事实与理由：

一、基本事实

[按时间顺序叙述案件事实。包括：
1. 申请人的基本情况及其与被行政行为的利害关系；
2. 被申请人作出行政行为的背景和过程；
3. 行政行为的具体内容；
4. 该行政行为对申请人合法权益造成的影响。
注意：只叙述客观事实，不做法律评价。]

二、行政行为违法/不当的具体理由

（一）[程序违法方面]
[具体指出违反了什么法定程序，引用具体法律条文。
例如："被申请人在作出处罚决定前，未依法告知申请人享有陈述、申辩
的权利，违反了《行政处罚法》第四十四条的规定。"]

（二）[实体违法方面]
[具体指出事实认定错误/证据不足/适用法律错误等问题，引用具体法律条文。
例如："被申请人认定申请人[某事实]所依据的证据仅有[某证据]，
该证据不足以证明[待证事实]，属于事实认定不清、证据不足。"]

（三）[合理性方面（如适用）]
[如存在明显不当/过罚不相当等问题，指出并论证。]

三、结论

综上所述，被申请人作出的[行政行为名称]存在[列举主要违法情形]，
违反了《[法律名称]》第[X]条的规定，依法应予[撤销/变更/确认违法/
责令履行]。申请人依据《中华人民共和国行政复议法》第十一条的规定，
向贵机关申请行政复议，请依法支持申请人的复议请求。

此致
[复议机关全称]

                                        申请人（签名/盖章）：
                                        日期：    年  月  日

附件：
1. 申请人身份证明复印件 1份
2. [被诉行政行为文书复印件] 1份
3. [证据材料清单及复印件] X份
4. 授权委托书及代理人身份证明（如有代理人） 1份
```

---

## 使用说明

1. **请求项选择**：
   - 撤销：最常用，适用于行政行为存在违法情形
   - 变更：适用于处罚过重/明显不当（复议特有，诉讼一般不能变更）
   - 确认违法：适用于撤销已无实际意义的情形
   - 责令履行：适用于不作为案件
   - 赔偿：可以一并提出

2. **事实部分**：客观叙述，不带情绪，不带法律评价

3. **理由部分**：每个理由必须有法律依据，不要笼统说"违反法律规定"

4. **份数**：申请书一式两份（复议机关留存+送达被申请人）
