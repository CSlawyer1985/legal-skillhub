# 行政诉讼文书样式参考

> **来源**：最高人民法院《行政诉讼文书样式（试行）》（2015年发布）
> **用途**：律师参考法院裁判文书格式，辅助制定诉讼策略、预判法院审理思路
> **注意**：本文件为法院内部裁判文书样式参考，律师不需要按照此格式撰写文书，
> 但了解法院裁判文书的结构和关注要点，有助于有针对性地准备诉讼材料

---

## 一、一审行政判决书样式

### 1. 一审请求撤销、变更行政行为类案件判决书

**案号格式**：(××××)×行初字第××号

**结构**：
```
首部：
├── 法院名称
├── 案号
├── 原告基本情况（公民/法人/其他组织）
├── 被告基本情况（行政主体名称、地址、法定代表人、委托代理人）
├── 第三人基本情况
└── 案件由来（起诉时间、立案时间、送达时间、开庭时间）

正文：
├── 被诉行政行为概述（名称、认定事实、处理结果）
├── 原告诉称（诉讼请求、主要理由、证据）
├── 被告辩称（答辩请求及理由）
├── 第三人述称
├── 被告提交的证据及依据
├── 法院调取的证据
├── 质证意见
├── 法院认证意见
├── 经审理查明（事实认定）
├── 本院认为（裁判理由）
│   └── ⚠️ 律师重点研究部分：法院的审查逻辑和裁判思路
└── 判决结果
    ├── 驳回诉讼请求（行政行为合法）
    ├── 撤销行政行为（主要证据不足/适用法律法规错误/
    │   违反法定程序/超越职权/滥用职权/明显不当）
    ├── 变更行政行为（行政处罚明显不当/其他行政行为
    │   涉及对款额的确定有误）
    └── 确认违法/确认无效

尾部：
├── 诉讼费负担
├── 上诉权利告知（15日内向本院递交上诉状）
├── 审判长、审判员
├── 日期、院印
└── 书记员
```

**法律依据**：《行政诉讼法》第69条、第70条、第77条

### 2. 一审不作为类行政案件判决书

**结构特点**：
- 重点审查被告是否具有法定职责
- 重点审查原告是否提出申请
- 重点审查被告是否在法定期限内履行
- 判决结果包括：驳回请求/责令履行/确认违法/赔偿

**判决结果类型**：
1. 驳回原告诉讼请求
2. 责令被告在一定期限内履行法定职责
3. 确认被告不履行法定职责行为违法
4. 驳回赔偿请求
5. 判决被告赔偿

**法律依据**：《行政诉讼法》第72条、第74条、第75条

### 3. 一审请求确认行政行为违法/无效类判决书

**结构特点**：
- 先审查行政行为是否合法（参照撤销类判决书的审查方法）
- 再判断是否属于"重大且明显违法"（确认无效的标准）
- 如确认无效，还需考虑是否责令采取补救措施

**法律依据**：《行政诉讼法》第74条、第75条

## 二、二审行政判决书样式

**案号格式**：(××××)×行终字第××号

**结构特点**：
- 体现上诉审特点：针对性和说服力
- 重点围绕上诉请求和争议焦点
- "经审理查明"部分可简化无争议事实
- "本院认为"部分重点回应上诉理由

**判决结果类型**：
1. 驳回上诉，维持原判
2. 部分维持、部分撤销
3. 撤销原判，驳回原审原告诉讼请求
4. 撤销原判，同时撤销或变更行政行为

## 三、律师策略参考要点

### 从判决书样式反推诉讼准备

| 判决书要素 | 律师应准备的材料 |
|:---|:---|
| 经审理查明 | 证据清单要完整，预判法院可能关注的事实问题 |
| 质证意见 | 准备详细的质证意见，对每份证据的三性逐一发表意见 |
| 本院认为 | 预判法院的审查逻辑，提前准备应对方案 |
| 超越职权审查 | 重点准备职权依据分析，明确是否存在越权 |
| 程序合法性审查 | 逐项对照正当程序要求，找出程序违法点 |
| 比例原则审查 | 行政处罚案件重点准备"过罚相当"的论证 |

### 起诉状撰写要点（与判决书结构的对应关系）

律师撰写的行政起诉状应当让法官能够方便地填入判决书框架：
- **诉讼请求**要具体明确，对应判决结果的类型
- **事实部分**要围绕"经审理查明"的格式组织
- **理由部分**要围绕法院的审查维度展开（主体→职权→行为→程序→实体）
