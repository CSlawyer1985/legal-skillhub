# FAQ 与反模式清单

## 常见问题

### Q1：这个技能能直接提交给法院/复议机关吗？

**不能。** 所有产出都是工作辅助材料（工作母版），必须经过律师审核、修改、签名后才能提交。AI 产出不等于法律意见。

### Q2：案件材料不全怎么办？

按模块01的指引，列出缺失材料清单，说明对产出质量的影响，由律师决定补充后继续还是基于现有材料先行处理。产出中标注「⚠️ 基于现有材料，待补充XX后可进一步完善」。

### Q3：法条引用不确定怎么办？

每个法条引用标注来源。如未经联网核验→标注「⚠️ 未经核验，交付前必须人工核实」。交付前必须经检索核验。

### Q4：涉及其他法律领域（民事/刑事交叉）怎么办？

本技能只处理行政救济部分。如存在交叉问题→提示律师注意→建议咨询相应专业律师。不跨领域处理。

### Q5：复议和诉讼可以同时走吗？

不可以。已申请复议且复议机关已受理的，在复议期间不能同时起诉。但复议决定作出后不服的，可以在法定期限内起诉。

### Q6：对"红头文件"不服能直接告吗？

不能直接对规范性文件（抽象行政行为）提起复议或诉讼。但可以在对具体行政行为提起复议/诉讼时，一并请求审查该具体行政行为所依据的规范性文件（规章以下）。

## 反模式清单（禁止行为）

| 反模式 | 正确做法 |
|:---|:---|
| 未经律师审核直接提交AI产出的文书 | 所有产出必须经律师审核修改后提交 |
| 凭记忆引用法条 | 必须经检索核验 |
| 手动推算期限 | 必须用代码验证日期 |
| 不区分作为和不作为 | 两类案件分析框架完全不同 |
| 遗漏复议前置判断 | 必须先判断路径类型 |
| 笼统说"违反法律规定" | 必须指出具体违反哪部法律哪一条 |
| 编造不存在的案例或法条 | 严禁，宁可标注"待核实" |
| 在办案记录之外依赖对话记忆 | 中间产物必须落盘到文件 |
