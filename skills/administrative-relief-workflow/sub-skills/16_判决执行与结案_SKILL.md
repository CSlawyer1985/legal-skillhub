# 模块 16：判决执行与结案

## 适用阶段

执行与结案阶段。判决生效后执行。

## 任务目标

协助判决执行、案件归档、复盘总结。

## 前置要求

- 判决已生效（一审判决过上诉期/二审判决/再审判决）

## 执行步骤

### Step 1：判决执行

#### 1.1 胜诉后的执行

| 判决类型 | 执行方式 |
|:---|:---|
| 撤销判决 | 行政机关自动恢复原状/重新作出行为/退还罚款 |
| 变更判决 | 行政机关按变更后的内容执行 |
| 履行判决 | 行政机关在判决指定期限内履行 |
| 确认违法判决 | 如涉及赔偿→执行赔偿；如涉及恢复→要求恢复 |
| 赔偿判决 | 行政机关支付赔偿金 |

#### 1.2 行政机关不履行的处理

- 向法院申请强制执行
- 申请期限：判决规定的履行期限届满后2年内

#### 1.3 败诉后的处理

- 告知当事人判决结果及法律后果
- 分析是否有上诉/再审的可能
- 如当事人接受结果→结案

### Step 2：案件归档

#### 2.1 整理归档材料

```
案件归档清单

一、案件信息材料
□ 委托合同
□ 授权委托书
□ 当事人身份证明
□ 被申请人/被告信息

二、原始材料
□ 被诉行政行为文书
□ 复议决定书（如有）
□ 一审判决书
□ 二审判决书（如有）
□ 其他原始材料

三、工作底稿
□ 四维分析报告
□ 受案范围分析
□ 被申请人分析
□ 路径选择分析
□ 期限计算
□ 管辖确认
□ 证据清单
□ 质证意见
□ 庭审提纲

四、正式文书
□ 复议申请书
□ 行政起诉状
□ 代理意见
□ 上诉状/再审申请书（如有）
```

#### 2.2 归档位置

所有材料按文件夹结构归档，保持完整。

### Step 3：复盘总结

```
案件复盘

一、案件概况
[简述案件从接案到结案的过程]

二、关键节点回顾
[哪些节点做了关键决策？效果如何？]

三、经验教训
1. [做得好的地方]
2. [可以改进的地方]
3. [类似案件的建议]

四、知识更新
[本案涉及的新法规/新裁判规则/新的法律理解]
```

### Step 4：更新办案记录

更新 `办案记录.md` 的最终状态为"已结案"。

## 产出文件

| 文件 | 存放位置 |
|:---|:---|
| 归档清单 | `02_工作底稿/` |
| `YYYYMMDD_案件复盘_代理人.md` | `02_工作底稿/` |
| 更新后的 `办案记录.md`（状态=已结案） | 案件文件夹根目录 |

## 注意事项

1. **及时归档**：结案后立即归档，避免材料丢失
2. **保留电子档**：所有文书保留 Markdown 母版和 Word 正式版
3. **复盘要有价值**：不是走形式，而是真正提炼可复用的经验
4. **保密**：归档材料妥善保管，遵守律师保密义务
