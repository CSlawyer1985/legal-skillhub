# 模块 13：一审庭审准备

## 适用阶段

行政诉讼一审阶段。立案后、开庭前执行。

## 任务目标

准备庭审所需的全部材料：证据清单、质证意见、庭审发问提纲、庭审辩论提纲。

## 前置要求

- 模块12已完成，案件已立案
- 已完成证据交换（如法院组织了庭前证据交换）
- 已收到被告的答辩状

## 执行步骤

### Step 0：加载知识库

- `references/核心法规/行政诉讼法要点.md`（举证+庭审条款）
- 按行为类型加载对应知识库

### Step 1：分析被告答辩状

1. 梳理被告的主要抗辩观点
2. 找出答辩中的漏洞和矛盾
3. 准备反驳要点

### Step 2：整理庭审证据清单

```
原告证据清单

| 序号 | 证据名称 | 证据类型 | 证明目的 | 页码 |
|:---:|:---|:---|:---|:---:|
| 1 | ... | 书证 | ... | ... |
```

### Step 3：质证意见

针对被告提交的证据，逐项准备质证意见：

```
质证意见

针对被告证据一（名称）：
- 真实性：[认可/不认可]，理由：[...]
- 合法性：[认可/不认可]，理由：[...]
- 关联性：[认可/不认可]，理由：[...]
- 证明力：[认为该证据不能证明...]
```

### Step 4：庭审发问提纲

**⚠️ 采用"先开放后封闭"结构**（参考刑事Skill的庭审发问规范）

```
庭审发问提纲

一、对原告（己方）的发问
1. [开放式] 请讲述一下[某事实]的经过……
   → 预期回答：[...]
   [封闭式追问] 当时[某细节]，是不是这样的？
2. ...

二、对被告的发问
1. [封闭式] 作出处罚决定前，是否告知了当事人听证权利？
   → 预期回答：是/否
   → 如答"是"：请出示告知听证的证据
2. ...
```

### Step 5：庭审辩论提纲

```
庭审辩论提纲

一、事实争议焦点
1. [焦点1]
   - 我方观点：[...]
   - 对方可能观点：[...]
   - 我方反驳：[...]

二、法律适用争议焦点
1. [焦点1]
   - 我方观点：[...]
   - 法律依据：[具体条文]
   - 对方可能观点：[...]
   - 我方反驳：[...]

三、总结陈述
[简明扼要总结我方核心观点]
```

### Step 6：输出与归档

所有材料存入 `02_工作底稿/`。

## 产出文件

| 文件 | 存放位置 |

| `YYYYMMDD_质证意见_原告代理人.md` | `02_工作底稿/质证意见/` |

| `YYYYMMDD_庭审辩论提纲_原告代理人.md` | `02_工作底稿/庭审提纲/` |

## 注意事项

1. **知己知彼**：庭审准备的核心是分析对方答辩状，找到突破口
2. **发问要有目的**：每个问题都要服务于证明某个事实
3. **质证要具体**：不能笼统说"不认可"，要说明不认可的具体理由
4. **准备预案**：预判对方可能的反驳，提前准备应对
