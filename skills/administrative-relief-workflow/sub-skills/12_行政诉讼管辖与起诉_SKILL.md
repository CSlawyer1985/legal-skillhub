# 模块 12：行政诉讼管辖与起诉

## 适用阶段

行政诉讼立案阶段。路径选择为"直接诉讼"或"复议后起诉"时执行。

## 任务目标

确认管辖法院，撰写行政起诉状，整理立案材料。

## 前置要求

- 接案评估完成，路径确定为诉讼
- 或模块11决定起诉

## 执行步骤

### Step 0：加载知识库

- `references/文书模板/行政起诉状模板.md`
- `references/核心法规/行政诉讼法要点.md`（管辖+起诉条件）
- 如涉及共同被告：`references/special-paths/共同被告规则.md`

### Step 1：确认起诉条件

| 条件 | 要求 | 法律依据 |
|:---|:---|:---|
| 原告适格 | 行政行为的相对人或利害关系人 | 第25条 |
| 被告明确 | 有明确的被告（见模块03） | 第49条第2项 |
| 有具体诉讼请求和事实根据 | 请求明确+有基本事实 | 第49条第3项 |
| 属于法院受案范围和受诉法院管辖 | 属于行政诉讼受案范围+该法院有管辖权 | 第49条第4项 |

### Step 2：确认管辖法院

调用模块07的管辖确认结论。

### Step 3：撰写行政起诉状

```
行政起诉状

原告：[姓名/名称]，[基本信息]
身份证号/统一社会信用代码：[号码]
住所地：[地址]
联系电话：[号码]

被告：[行政机关全称]
住所地：[地址]
法定代表人：[姓名]，[职务]

[如有共同被告]
共同被告：[复议机关名称]
住所地：[地址]
法定代表人：[姓名]，[职务]

诉讼请求：
一、撤销/变更/确认[行政行为文书名称及文号]违法；
二、[责令被告履行法定职责/赔偿损失/其他请求]；
三、本案诉讼费由被告承担。

事实与理由：
[事实叙述+法律论证，结构同复议申请书但更深入]

此致
[管辖法院名称]

                                        具状人：[签名]
                                        日期：YYYY年MM月DD日

附件：
1. 本起诉状副本X份
2. 原告身份证明
3. 被诉行政行为文书
4. 复议决定书（如经过复议）
5. 证据材料
6. 授权委托书（如有代理人）
```

### Step 4：整理立案材料

| 序号 | 材料 | 份数 | 说明 |
|:---:|:---|:---:|:---|
| 1 | 行政起诉状 | 正本1份+副本N份 | 被告人数决定副本数 |
| 2 | 原告身份证明 | 1份 | 身份证/营业执照 |
| 3 | 被诉行政行为文书 | 1份 | 处罚决定书等 |
| 4 | 复议决定书 | 1份 | 如经过复议 |
| 5 | 证据材料 | 按清单 | 详见证据清单 |
| 6 | 授权委托书 | 1份 | 如有代理人 |

### Step 5：输出与归档

起诉状存入 `03_正式文书/`，工作底稿存入 `02_工作底稿/`。

## 产出文件

| 文件 | 存放位置 |
|:---|:---|
| `YYYYMMDD_行政起诉状_原告代理人.md` | `03_正式文书/` |
| `YYYYMMDD_立案材料清单_原告代理人.md` | `02_工作底稿/` |
| 更新后的 `办案记录.md` | 案件文件夹根目录 |

## 注意事项

1. **起诉状副本份数**：按被告人数提交副本（1个被告1份，2个被告2份）
2. **起诉期限**：直接起诉6个月，复议后起诉15日——必须用代码验证
3. **诉讼请求要明确**：撤销就是撤销，确认违法就是确认违法，不能含糊
4. **诉讼费**：行政案件受理费一般50元，部分案件不收费（如不作为案件）
