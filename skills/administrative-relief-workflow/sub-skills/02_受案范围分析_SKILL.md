# 模块 02：受案范围分析

## 适用阶段

接案阶段。在模块01完成信息采集后执行。

## 任务目标

判断涉案行政行为是否属于行政复议或行政诉讼的受案范围，给出明确的"可救济/不可救济/需进一步确认"结论。

## 前置要求

- 模块01已完成，`办案记录.md` 已建立
- 已知行政行为的基本信息（行为类型、内容、作出机关）

## 执行步骤

### Step 0：加载知识库

按需读取：
- `references/核心法规/行政复议法要点.md`（第11条受案范围部分）
- `references/核心法规/行政诉讼法要点.md`（第12条受案范围部分）
- 按行为类型加载 `references/行政行为类型/` 对应文件

### Step 1：行政复议受案范围判断

#### 1.1 正面清单（《行政复议法》第11条，15类）

逐一比对，看涉案行为是否属于以下任一类：

| 序号 | 受案类型 | 典型情形 |
|:---:|:---|:---|
| 1 | 行政处罚 | 警告、罚款、没收、责令停产停业、暂扣/吊销许可证、行政拘留等 |
| 2 | 行政强制 | 限制人身自由、查封/扣押/冻结财产等行政强制措施；行政强制执行 |
| 3 | 行政许可 | 申请许可证/资质/审批，被拒绝或不予答复 |
| 4 | 行政确认 | 自然资源所有权/使用权确权决定 |
| 5 | 行政征收 | 征收征用决定及补偿决定 |
| 6 | 行政赔偿 | 行政机关决定赔偿/不予赔偿 |
| 7 | 不履行法定职责 | 申请保护人身权/财产权/受教育权等，行政机关不履行 |
| 8 | 行政给付 | 不依法发放抚恤金/社会保险待遇/最低生活保障等 |
| 9 | 行政协议 | 认为行政机关不依法/按约定履行行政协议 |
| 10 | 政府信息公开 | 认为侵犯知情权 |
| 11 | 滥用行政权力排除竞争 | 反垄断相关 |
| 12 | 违法要求履行义务 | 集资、摊派等违法要求履行义务 |
| 13 | 其他侵犯合法权益 | 兜底条款（人身权、财产权等合法权益） |
| 14 | — | （兜底扩展空间） |
| 15 | — | （兜底扩展空间） |

**判断逻辑**：涉案行为能归入上述任一类 → ✅ 属于复议受案范围。

#### 1.2 负面清单（不可复议的事项）

即使行为看起来像行政行为，以下事项**不属于**复议受案范围：

| 排除事项 | 法律依据 | 替代途径 |
|:---|:---|:---|
| 国防、外交等国家行为 | 行政行为不可复议的性质 | — |
| 行政法规、规章 | 抽象行政行为，不能直接复议 | 可在复议具体行为时附带审查规范性文件（规章以下） |
| 行政机关内部人事处理决定 | 内部行为 | 申诉 |
| 行政机关对民事纠纷的调解 | 行政调解不具有强制力 | 民事诉讼/仲裁 |
| 行政机关作出的信访处理意见 | 信访答复不创设新的权利义务 | 信访复查/复核 |
| 行政指导行为 | 不具有强制力 | — |
| 重复处理行为 | 未创设新的权利义务 | 对原行为寻求救济 |

**判断逻辑**：涉案行为属于排除事项 → ❌ 不属于复议受案范围。告知当事人替代途径。

### Step 2：行政诉讼受案范围判断

#### 2.1 正面清单（《行政诉讼法》第12条）

与复议受案范围大体一致，但有以下**额外可诉事项**：
- 认为行政机关侵犯其经营自主权/农村土地承包经营权/农村土地经营权
- 认为行政机关滥用行政权力排除或限制竞争
- 认为行政机关违法集资、摊派或违法要求履行其他义务
- 认为行政机关没有依法支付抚恤金、最低生活保障待遇或社会保险待遇
- 认为行政机关不依法履行、未按照约定履行或违法变更、解除政府特许经营协议/土地房屋征收补偿协议等行政协议

#### 2.2 负面清单（不可诉的事项）

| 排除事项 | 法律依据 |
|:---|:---|
| 国防、外交等国家行为 | 《行政诉讼法》第13条第1项 |
| 行政法规、规章或行政机关制定、发布的具有普遍约束力的决定、命令 | 第13条第2项 |
| 行政机关对行政机关工作人员的奖惩、任免等决定 | 第13条第3项 |
| 法律规定由行政机关最终裁决的行政行为 | 第13条第4项 |

### Step 3：输出结论

向用户输出以下结论之一：

#### 结论A：✅ 属于受案范围

```
【受案范围分析结论】
涉案行为：[具体描述]
受案范围判断：✅ 属于[行政复议/行政诉讼]受案范围
法律依据：《[行政复议法/行政诉讼法]》第XX条第X款第X项
下一步建议：模块03（确认被申请人适格性）→ 模块05（路径选择）
```

#### 结论B：❌ 不属于受案范围

```
【受案范围分析结论】
涉案行为：[具体描述]
受案范围判断：❌ 不属于[行政复议/行政诉讼]受案范围
排除原因：该行为属于[排除事项类型]
替代途径：建议通过[替代途径]解决
```

#### 结论C：⚠️ 需进一步确认

```
【受案范围分析结论】
涉案行为：[具体描述]
受案范围判断：⚠️ 存在争议/不够明确
争议点：[说明争议所在]
需要补充的信息：[列出需要进一步了解的事实]
```

## 注意事项

1. **兜底条款的适用**：如果涉案行为不属于明确列举的类型，但确实侵犯了当事人的合法权益，可以适用兜底条款（《行政复议法》第11条第14项"认为行政机关的其他行政行为侵犯其合法权益的"），但需提示"存在不被受理的风险"
2. **规范性文件不能直接诉**：提醒当事人，对"红头文件"不服不能直接起诉，但可以在诉具体行政行为时附带要求审查
3. **多行为并存**：如果一个案件中涉及多个行政行为（如处罚+强制），分别分析每个行为的可复议性/可诉性
4. **不作为的特殊性**：不作为案件中，受案范围的关键是"是否有法定职责"——需要先确认该机关有该职责，才能分析是否构成不作为
