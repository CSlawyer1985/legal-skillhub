# 模块 06：期限计算

## 适用阶段

决策阶段。在模块05确定路径后执行。**本模块涉及紧急期限判断，必须用代码验证日期，禁止手动推算。**

## 任务目标

精确计算复议申请期限、起诉期限，判断是否超期，提示紧急程度。

## 前置要求

- 模块01已完成（已知送达日期）
- 模块05已完成（已知走复议还是诉讼路径）

## 执行步骤

### Step 0：关键日期确认

向用户确认以下日期（至少确认一项）：
- 行政行为文书的**送达日期**（当事人签收的日期）
- 如果是**不作为**案件：当事人的**申请日期**
- 如果已经走过复议：复议**申请日期**、复议**决定送达日期**

### Step 1：计算复议申请期限

#### 1.1 一般规则

| 情形 | 期限 | 起算点 | 法律依据 |
|:---|:---|:---|:---|
| 一般规定 | **60日** | 知道该具体行政行为之日 | 《行政复议法》第20条 |
| 文书送达 | 60日 | 签收决定书之日 | — |
| 公告送达 | 60日 | 公告期满之日 | — |
| 未告知诉权/期限 | 从知道或应当知道诉权或期限之日起算，但最长不超过**1年** | — | 司法解释 |

#### 1.2 特殊情况

| 情形 | 期限处理 |
|:---|:---|
| 不可抗力导致超期 | 期限中止，障碍消除后继续计算 |
| 行政机关不作为 | 从履职期限届满之日起算 |
| 行政行为内容未告知 | 从知道或应当知道内容之日起算 |

#### 1.3 ⚠️ 代码验证要求

**所有日期计算必须使用Python datetime模块验证**，不得手动推算。计算逻辑：

```
申请期限截止日 = 起算日 + timedelta(days=期限天数)
剩余天数 = 申请期限截止日 - 今日
是否超期 = 剩余天数 < 0
```

如果剩余天数 ≤ 7日，输出⚠️ 紧急提示。

### Step 2：计算起诉期限

#### 2.1 一般规则

| 情形 | 期限 | 起算点 | 法律依据 |
|:---|:---|:---|:---|
| 直接起诉 | **6个月** | 知道或应当知道行政行为之日 | 《行政诉讼法》第46条 |
| 复议后起诉 | **15日** | 收到复议决定书之日 | 《行政诉讼法》第45条 |
| 复议机关不作为后起诉 | **15日** | 复议期满之日 | 第45条 |
| 未告知诉权/期限 | 从知道或应当知道之日起算，最长不超过**1年** | — | 司法解释 |
| 涉及不动产 | 最长不超过**20年** | 行政行为作出之日 | 第46条第2款 |
| 其他案件最长保护期 | **5年** | 行政行为作出之日 | 司法解释 |

#### 2.2 期限中断/中止

| 情形 | 处理 |
|:---|:---|
| 不可抗力 | 期限中止，障碍消除后10日内可申请顺延 |
| 向复议机关申请复议 | 起诉期限中断，从复议决定送达后重新起算15日 |

### Step 3：判断与输出

#### 结论A：未超期

```
【期限计算结果】
行政行为送达日期：YYYY-MM-DD
救济路径：[行政复议/行政诉讼]
法定期限：[60日/6个月/15日]
期限截止日：YYYY-MM-DD（星期X）
今日：YYYY-MM-DD
剩余天数：XX 天
状态：✅ 未超期
紧急程度：[正常/注意（≤30天）/紧急（≤7天）]
```

#### 结论B：已超期

```
【期限计算结果】
⚠️ 已超过法定期限！
法定期限：[XX日]
期限截止日：YYYY-MM-DD
超期天数：XX 天
状态：❌ 已超期
建议：[是否存在中止/中断事由可主张 / 是否还有其他救济途径]
```

#### 结论C：信息不足

```
【期限计算结果】
⚠️ 无法精确计算
缺少的关键信息：[列出]
建议：请确认以上日期后重新计算
临时判断：按已知信息初步估算，[可能未超期/可能已超期/无法判断]
```

## 注意事项

1. **必须用代码验证**：这是本技能中少数强制要求代码验证的模块，日期计算不能手动推算
2. **"知道"的认定**：实践中争议很大。文书送达日最明确；如果当事人说"我不知道"，需要了解具体情形
3. **工作日vs自然日**：行政复议申请期限按自然日计算；但期限最后一日是法定休假日的，以休假日后的第一个工作日为截止日
4. **同时考虑两条路径的期限**：如果走自由选择路径，建议同时算出复议期限（60日）和诉讼期限（6个月），供当事人参考
5. **紧急案件立即行动**：如果剩余天数≤7天，必须用醒目方式提示当事人立即行动
