# 模块 07：管辖确认

## 适用阶段

决策阶段。在模块05确定路径后执行。

## 任务目标

确认复议管辖机关和/或诉讼管辖法院，给出明确的管辖结论。

## 前置要求

- 模块03已完成（已知被申请人/被告身份）
- 模块05已完成（已知走复议还是诉讼路径）

## 执行步骤

### Step 0：加载知识库

- `references/核心法规/行政复议法要点.md`（第24条管辖规则）
- `references/核心法规/行政诉讼法要点.md`（管辖部分，第14-24条）

### Step 1：行政复议管辖

#### 1.1 一般规则（《行政复议法》第24条，2024年新修订）

新修订的行政复议法对管辖做了重大调整，**原则上由县级以上地方各级人民政府统一管辖**：

| 被申请人 | 复议机关 | 法律依据 |
|:---|:---|:---|
| 县级以上地方各级政府部门 | **本级人民政府** | 第24条第1款 |
| 县级以上地方各级政府 | **上一级人民政府** | 第24条第2款 |
| 乡镇人民政府 | **上一级（县级）人民政府** | 第24条第2款 |
| 海关、金融、外汇、税务等垂直领导机关 | **上一级主管部门** | 第24条第3款 |
| 国家安全机关 | **上一级主管部门** | 第24条第3款 |
| 法律法规授权的组织 | **直接管理该组织的行政机关的本级政府或上一级主管部门** | 第24条第4款 |

**⚠️ 重要变化**：新法取消了"本级政府或上一级主管部门"的选择权（除垂直管理部门外），统一由本级政府管辖。

#### 1.2 特殊管辖

| 情形 | 复议机关 |
|:---|:---|
| 两个以上行政机关以共同名义作出 | 共同上一级行政机关 |
| 行政机关被撤销 | 继续行使其职权的行政机关的相应管辖机关 |
| 对派出机关（如街道办）不服 | 设立该派出机关的政府的本级政府 |

### Step 2：行政诉讼管辖

#### 2.1 级别管辖

| 被告类型 | 管辖法院 | 法律依据 |
|:---|:---|:---|
| 县级以上地方人民政府为被告 | **中级人民法院** | 《行政诉讼法》第15条 |
| 国务院部门或省级政府为被告 | **中级人民法院** | 第15条 |
| 海关处理的案件 | **中级人民法院** | 第15条 |
| 其他一般行政案件 | **基层人民法院** | 第14条 |

#### 2.2 地域管辖

| 情形 | 管辖法院 | 法律依据 |
|:---|:---|:---|
| 一般案件 | 最初作出行政行为的行政机关**所在地**法院 | 第18条 |
| 经复议的案件 | 原机关所在地 或 复议机关所在地（均可） | 第18条 |
| 对限制人身自由的行政强制措施不服 | 被告所在地 或 原告所在地（均可） | 第19条 |
| 因不动产提起的行政诉讼 | **不动产所在地**法院（专属管辖） | 第20条 |

#### 2.3 集中管辖/跨行政区划管辖

**⚠️ 注意**：很多地区已实行行政案件集中管辖（交叉管辖），即行政案件由非被告所在地的法院管辖。具体需要查询当地的高级人民法院关于行政案件管辖的规定。

- 如已实行集中管辖 → 按当地规定确定管辖法院
- 如未实行 → 按上述一般规则确定

## 注意事项

1. **新法管辖变化**：2024年新修订行政复议法对管辖做了重大调整（统一由地方政府管辖），不要用旧法规则
2. **集中管辖查询**：各地的集中管辖规定不同，本技能无法覆盖所有地区的集中管辖安排。如不确定，提示用户查询当地高院规定
3. **被告所在地 vs 行为发生地**：地域管辖一般按被告所在地，不是按行为发生地
4. **复议后诉讼的管辖选择**：经复议的案件，原机关所在地和复议机关所在地的法院都有管辖权——这对原告是有利的，可以选择
5. **级别管辖容易出错**：以县级政府为被告的案件归中院，不是基层——这是常见错误
