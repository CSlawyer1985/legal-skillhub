# 模块 04：行政行为分析

## 适用阶段

接案阶段。在模块03确认被申请人后执行。

## 任务目标

按四维分析框架（主体→职权→行为→违法理由）对涉案行政行为进行全面分析，形成完整的四维分析报告。

## 前置要求

- 模块01-03已完成
- 已知：当事人信息、行政行为基本信息、被申请人身份

## 执行步骤

### Step 0：加载知识库

按行为类型加载对应知识库：
- `references/行政行为类型/[行为类型].md`
- `references/核心法规/行政复议法要点.md`（违法情形相关条文）

### Step 1：行为定性（维度三先行）

先确定行为的法律性质，再分析其合法性。

#### 1.1 作为 vs 不作为

| 分类 | 判断标准 | 后续分析重点 |
|:---|:---|:---|
| **作为** | 行政机关作出了某个具体决定（有文书） | 决定的合法性 |
| **不作为** | 当事人提出申请后，行政机关未在法定期限内履行 | 是否有法定职责+是否逾期+有无正当理由 |

#### 1.2 作为类行为的细分

| 行为类型 | 关键特征 | 分析重点 |
|:---|:---|:---|
| 行政处罚 | 制裁性、不利处分 | 事实依据、程序合规、裁量适当 |
| 行政许可 | 依申请、准予从事特定活动 | 是否符合许可条件、是否超期、是否说明理由 |
| 行政强制（措施） | 临时性、限制性 | 是否有法定权限、是否符合比例原则、程序 |
| 行政强制（执行） | 强制执行已生效决定 | 是否有执行依据、是否超范围、程序 |
| 行政征收 | 公共利益、给予补偿 | 征收依据、补偿标准、程序 |
| 行政确认 | 确认法律关系或事实 | 确认依据、事实认定 |

#### 1.3 不作为类行为的分析要点

| 分析项 | 内容 |
|:---|:---|
| 法定职责来源 | 法律、法规、规章的哪一条规定了该职责 |
| 当事人是否提出申请 | 依申请的职责需要当事人先申请（有申请记录吗？） |
| 法定期限 | 法律规定的履职期限是多久（如许可法20日、信息公开20个工作日） |
| 是否已超期 | 从申请日/知道之日起算，是否超过法定期限 |
| 正当理由 | 是否有不可抗力等正当理由 |

### Step 2：职权分析（维度二）

#### 2.1 职权来源审查

- 该行政机关的职权来源是什么法律/法规/规章？
- 具体是哪个条文授权？
- 该条文是否仍然有效（是否被修订/废止）？

#### 2.2 越权分析

| 越权类型 | 表现 | 法律后果 |
|:---|:---|:---|
| **事项越权** | 管了不该管的事（如市场监管局管交通违章） | 可撤销 |
| **地域越权** | 管了辖区外的事（如A县公安局在B县执法） | 可撤销 |
| **级别越权** | 下级做了上级才能做的事（如派出所拘留15日） | 可撤销 |
| **时间越权** | 在授权期限外行使（如许可被吊销后仍执法） | 可撤销 |

#### 2.3 滥用职权分析

- 行为目的是否正当？（是否出于打击报复、地方保护等不当目的）
- 是否违反平等原则？（相同情况不同对待）
- 是否违反比例原则？（手段明显超出必要限度）
- 是否考虑了不相关因素或未考虑相关因素？

### Step 3：程序分析（维度四之程序违法）

#### 3.1 正当程序基本要求

| 程序要素 | 要求 | 违反后果 |
|:---|:---|:---|
| 告知权利 | 作出决定前告知当事人享有的权利 | 程序违法 |
| 听取陈述/申辩 | 给予当事人陈述和申辩的机会 | 程序违法（处罚案件尤为严格） |
| 听证 | 重大处罚（吊销许可证、较大数额罚款、责令停产停业等）应告知听证权 | 程序违法 |
| 说明理由 | 决定文书应载明事实根据和法律依据 | 程序违法 |
| 送达 | 依法送达决定书 | 影响期限起算和决定生效 |
| 期限 | 在法定期限内作出决定 | 程序违法 |
| 回避 | 利害关系人应回避 | 程序违法 |
| 执法人数 | 一般要求2名以上执法人员 | 程序违法 |
| 执法证件 | 出示执法证件 | 程序违法 |

#### 3.2 不同行为类型的特殊程序

按行为类型加载知识库后，对照该类型特有的程序要求逐项检查。

### Step 4：实体分析（维度四之实体违法）

| 违法情形 | 判断标准 | 法律后果 |
|:---|:---|:---|
| 主要事实不清 | 认定的事实缺乏充分证据支持 | 可撤销 |
| 证据不足 | 证据不能形成完整的证据链 | 可撤销 |
| 适用法律错误 | 适用了不应当适用的法律条文/条款 | 可撤销 |
| 超越职权 | 见Step 2 | 可撤销 |
| 滥用职权 | 见Step 2 | 可撤销 |
| 明显不当 | 处罚结果与违法事实严重不匹配 | 可撤销/可变更 |

### Step 5：输出四维分析报告

```
【四维分析报告】

案件名称：XXX 诉 XXX 行政机关 XXX 案

一、主体分析
[被申请人身份、主体资格、是否适格的分析]

二、职权分析
[职权来源、是否越权、是否滥用职权的分析]

三、行为分析
[行为类型、作为/不作为、行为内容的概述]

四、违法理由分析
（一）程序违法
[逐项列出发现的程序问题]
（二）实体违法
[逐项列出发现的实体问题]

结论：
- 可撤销理由：[列出]
- 可变更理由：[列出]
- 确认违法理由：[列出]
- 建议救济请求：[撤销/变更/确认违法/责令履行/赔偿]
```

### Step 6：更新办案记录

将四维分析结论写入 `办案记录.md` 的「四维分析摘要」部分。

## 注意事项

1. **先定性再分析**：先确定行为类型（维度三），再分析职权（维度二）和违法理由（维度四）
2. **作为和不作为的分析框架完全不同**：不作为案件的核心是"有没有职责+有没有逾期"，不是"行为合不合法"
3. **程序违法的独立价值**：即使实体处理正确，严重程序违法本身也构成撤销理由。不要把程序问题附属于实体分析
4. **比例原则**：行政处罚类案件要特别关注处罚与违法事实是否匹配，"过罚相当"是行政法基本原则
5. **禁止编造**：对于行政行为文书中的事实，只能摘录分析，不能编造或猜测案卷中不存在的内容
