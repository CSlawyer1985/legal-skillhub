# 模块 11：复议决定分析与后续策略

## 适用阶段

枢纽阶段。收到复议决定后执行。本模块是衔接复议→诉讼的关键节点。

## 任务目标

分析复议决定的类型和内容，评估后续策略（是否起诉、告谁、怎么告）。

## 前置要求

- 已完成复议程序
- 已收到复议决定书

## 执行步骤

### Step 0：加载知识库

- 如涉及共同被告：`references/special-paths/共同被告规则.md`
- `references/核心法规/行政诉讼法要点.md`

### Step 1：分析复议决定类型

| 复议决定类型 | 含义 | 后续路径 |
|:---|:---|:---|
| **维持** | 原行政行为合法 | ✅ 可以起诉→告原机关+复议机关（共同被告） |
| **变更** | 改变原行政行为内容 | ⚠️ 分析是否有利→有利则接受；不利则可起诉→告复议机关 |
| **撤销** | 原行政行为违法 | ✅ 有利→通常不需要再诉；如赔偿问题未解决→可继续 |
| **确认违法** | 认定违法但不撤销 | ⚠️ 分析是否需要赔偿→如赔偿问题未解决→可诉 |
| **责令履行** | 责令被申请人在一定期限内履行 | ✅ 有利→等待履行；不履行→起诉不作为 |
| **驳回申请** | 认为申请不符合条件 | ✅ 可以起诉→告原机关（诉原行为）或告复议机关（诉驳回） |

### Step 2：策略评估

#### 2.1 复议维持后起诉

```
后续策略建议：
- 被告：[原行政机关] + [复议机关] = 共同被告
- 管辖：原机关所在地 或 复议机关所在地的法院
- 起诉期限：收到复议决定书之日起15日内
- 诉讼请求：撤销原行政行为+撤销复议决定
- 举证策略：复议机关需对复议决定的合法性举证
```

#### 2.2 复议变更后是否起诉

- 变更后的内容对申请人更有利 → 建议接受
- 变更后的内容仍不满意 → 可以起诉（告复议机关）
- 评估：变更是否解决了核心诉求

#### 2.3 驳回后的选择

- 对原行政行为不服 → 起诉原机关
- 对驳回决定不服 → 起诉复议机关
- 可以二选一，也可以根据具体情况选择更有利的路径

### Step 3：输出结论

```
【复议决定分析与后续策略】

一、复议决定概况
决定类型：[维持/变更/撤销/确认违法/责令履行/驳回]
决定日期：YYYY-MM-DD
收到日期：YYYY-MM-DD

二、决定内容分析
[对决定内容的简要分析]

三、后续路径建议
推荐路径：[起诉/接受/其他]
被告：[谁]
管辖法院：[哪个法院]
起诉期限截止：YYYY-MM-DD
剩余天数：XX天

四、风险提示
[列出注意事项]
```

更新阶段为"行政诉讼"（如决定起诉）。

## 注意事项

1. **15日起诉期限非常短**：复议后起诉只有15天，必须立即行动
2. **复议维持=共同被告**：这是新行政诉讼法的重要规则，不能遗漏复议机关
3. **复议决定的送达日期是关键**：起诉期限从收到复议决定书之日起算
