# 模块 03：被申请人适格性确认

## 适用阶段

接案阶段。在模块02确认属于受案范围后执行。

## 任务目标

准确识别被申请人（复议阶段）或被告（诉讼阶段），判断其是否适格。特别关注复议后诉讼时的共同被告规则。

## 前置要求

- 模块01已完成，已知行政行为文书上的盖章机关
- 模块02已完成，确认属于受案范围

## 执行步骤

### Step 0：加载知识库

按需读取：
- `references/核心法规/行政复议法要点.md`（被申请人/复议机关部分）
- `references/核心法规/行政诉讼法要点.md`（被告部分，第26条）
- 如涉及复议后诉讼：`references/special-paths/共同被告规则.md`

### Step 1：确认行政主体身份

#### 1.1 识别行政行为的作出主体

根据行政行为文书上的**盖章/署名**，确定名义上的行为主体：
- 文书上的印章名称是什么？
- 是否有法定代表人签名？

#### 1.2 判断主体性质

| 主体类型 | 判断标准 | 谁当被申请人/被告 |
|:---|:---|:---|
| **行政机关** | 政府及其工作部门（如公安局、市场监管局） | 该行政机关 |
| **法律法规授权的组织** | 法律、法规明确授权（如证监会、银保监会） | 该被授权的组织 |
| **行政机关委托的组织** | 行政机关依照法律/法规/规章委托 | **委托的行政机关**（不是受托组织） |
| **派出机构** | 政府派出（如街道办事处）或部门派出（如派出所） | 见下方详细规则 |
| **被撤销的机关** | 作出行为后该机关被撤销 | 继续行使其职权的行政机关 |

#### 1.3 派出机构的主体资格（高频考点）

| 派出机构类型 | 是否有独立主体资格 | 谁当被申请人/被告 |
|:---|:---|:---|
| **公安派出所** | 有（《治安管理处罚法》授权，但仅限警告和500元以下罚款） | 以自己名义作出的处罚→派出所；超出授权范围→所属公安局 |
| **市场监管所** | 视授权情况 | 有授权的→自己；无授权的→所属市场监管局 |
| **街道办事处** | 有（政府派出机关，具有主体资格） | 街道办事处 |
| **开发区管委会** | 视设立依据 | 有法律法规授权的→管委会；无授权的→设立该管委会的政府 |
| **税务所** | 有（《税收征收管理法》授权） | 以自己名义作出的行为→税务所 |

### Step 2：判断主体是否适格

#### 2.1 适格的判断标准

- 该主体是否为行政行为的**实际作出者**（以文书盖章为准）
- 该主体是否具有**行政主体资格**（行政机关或法律法规授权的组织）
- 该主体是否对涉案事项有**管辖权**（职权范围）

#### 2.2 常见主体不适格的情形

| 情形 | 分析 | 正确被申请人/被告 |
|:---|:---|:---|
| 以内设机构名义作出 | 内设机构无主体资格 | 该内设机构所属的行政机关 |
| 以临时机构名义作出 | 临时机构无主体资格 | 设立该临时机构的行政机关 |
| 受委托组织以自己名义作出 | 受委托组织不能以自己名义 | 委托的行政机关 |
| 多个机关联合执法 | 共同作出 | 共同被申请人/共同被告 |

### Step 3：复议后诉讼的特殊规则（共同被告）

**⚠️ 这是行政案件特有的重要规则，如案件经过复议必须触发此步骤**

| 复议决定类型 | 诉讼被告 | 法律依据 |
|:---|:---|:---|
| **复议维持原行政行为** | **原行政机关 + 复议机关 = 共同被告** | 《行政诉讼法》第26条第2款 |
| **复议改变原行政行为** | **复议机关为被告** | 第26条第2款 |
| **复议机关不作为**（逾期不决定） | 当事人可选择：告原机关（诉原行为）或告复议机关（诉不作为） | 第26条第3款 |
| **复议机关不予受理** | 对不予受理决定可单独起诉复议机关 | — |

**策略提示**：
- 复议维持→起诉时列共同被告，复议机关要承担举证责任
- 复议改变→只告复议机关，原行为被替代
- 复议不作为→策略选择：如果原行为本身问题大，告原机关；如果复议机关程序违法明显，告复议机关

### Step 4：输出结论

```
【被申请人/被告适格性分析】
涉案行政行为：[描述]
行为作出主体：[文书上的盖章机关]
主体性质：[行政机关/授权组织/派出机构/...]
被申请人/被告：[正确的被申请人/被告名称]
是否适格：✅ 适格 / ⚠️ 需注意[具体问题]
复议后诉讼：[是否经过复议]→[共同被告/单独被告/选择性被告]
法律依据：[具体条文]
```

将主体分析结论写入 `办案记录.md`：
- 更新「四维分析摘要」→「主体」字段
- 更新「当事人信息」→ 被申请人/被告字段

## 注意事项

1. **以文书盖章为准**：不要根据当事人描述判断谁是作出机关，以文书上的印章/署名为准
2. **委托vs授权的区分**：关键是看有没有法律、法规的明确授权。委托不需要法律法规依据，授权必须有
3. **共同执法**：两个以上行政机关以共同名义作出的行政行为，为共同被申请人/共同被告
4. **经过上级批准的**：以在文书上署名的机关为被申请人/被告（不管内部是否经过审批）
5. **行政复议机关的确定**：复议被申请人是作出原行为的机关，复议机关是受理复议的上级机关/本级政府——这是两个不同概念，不要混淆
