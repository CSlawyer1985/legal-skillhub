# 模块 05：救济路径选择

## 适用阶段

决策阶段。在模块02-04完成后执行，是接案评估阶段的最终决策模块。

## 任务目标

判断涉案案件应走的救济路径（复议前置/自由选择/复议终局），给出明确的路径建议和风险提示。

## 前置要求

- 模块02（受案范围）、模块03（主体）、模块04（行为分析）已完成
- 已知行为类型、当事人诉求、期限状态

## 执行步骤

### Step 0：加载知识库

- `references/核心法规/行政复议法要点.md`（复议前置条款）
- 如涉及特殊路径：`references/special-paths/复议前置情形.md`

### Step 1：判断路径类型

#### 1.1 复议前置（必须先复议，不服才能诉讼）

**⚠️ 如属于此类，必须单独提示用户，不可跳过直接诉讼**

| 情形 | 法律依据 | 典型案件 |
|:---|:---|:---|
| 纳税争议 | 《税收征收管理法》第88条第1款 | 对税务机关的纳税决定不服（税额、税率、纳税方式等） |
| 自然资源确权 | 《行政复议法》第23条 | 对自然资源所有权或使用权的确权决定不服 |
| 部分社保争议 | 各单行法规定 | 对社保经办机构的具体行政行为 |

**复议前置的法律后果**：
- 不经过复议直接起诉 → 法院不予受理
- 复议后不服 → 可以在收到复议决定之日起15日内起诉
- 复议机关不作为 → 可以选择起诉原行政行为或起诉复议机关不作为

#### 1.2 自由选择（复议或直接诉讼均可）

**大多数行政案件属于此类**

- 可以选择先复议，不服再诉讼
- 也可以直接诉讼
- 但一旦选择复议且复议已受理，复议期间不能同时诉讼

| 路径 | 优势 | 劣势 |
|:---|:---|:---|
| 先复议 | ① 期限更宽裕（60日vs6个月）；② 复议机关全面审查（合法+合理）；③ 不收费；④ 程序简便 | ① 多一个程序环节；② 复议维持率高；③ 复议机关可能"官官相护" |
| 直接诉讼 | ① 少一个环节；② 司法独立性更强；③ 可以申请人法院调查取证 | ① 法院只审查合法性（不审查合理性）；② 诉讼成本；③ 起诉期限更短 |

**策略建议**：
- 涉及合理性问题（处罚过重、明显不当）→ 优先复议（复议可审查合理性）
- 涉及程序违法或法律问题 → 可直接诉讼（法院审查更专业）
- 期限紧张 → 看哪个期限更宽裕
- 涉及专业性强 → 复议（复议机关更了解业务）
- 涉及地方保护 → 直接诉讼或异地管辖

#### 1.3 复议终局（复议后不能再诉）

**⚠️ 极少数情形，必须单独提示**

| 情形 | 法律依据 |
|:---|:---|
| 国务院部门的复议决定（可选择向国务院申请终局裁决） | 《行政复议法》相关规定 |
| 省级政府对自然资源权属的复议决定 | 特别规定 |
| 法律明确规定复议终局的其他情形 | 各单行法 |

## 注意事项

1. **复议前置是硬门槛**：搞错路径直接丧失救济机会，务必谨慎
2. **复议和诉讼不能同时进行**：已申请复议且复议机关已受理的，在复议期间不能起诉
3. **期限差异很大**：复议60日 vs 诉讼6个月，需要根据案件情况选择更有利的路径
4. **复议审查范围更广**：复议可以审查合理性（如处罚过重），诉讼原则上只审查合法性
5. **选择性告知**：自由选择的情况下，要向当事人说明两种路径的利弊，由当事人决定
