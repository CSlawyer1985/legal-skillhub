# 模块 08：行政复议申请

## 适用阶段

行政复议阶段。路径选择为"先复议"或"复议前置"时执行。

## 任务目标

撰写行政复议申请书，整理申请材料清单。

## 前置要求

- 模块01-07已完成（接案评估阶段完成）
- 办案记录.md 中四维分析摘要和路径决策已填写
- 已确定走复议路径

## 执行步骤

### Step 0：加载知识库

- `references/文书模板/复议申请书模板.md`
- 按行为类型加载 `references/行政行为类型/[类型].md`
- `references/核心法规/行政复议法要点.md`（申请书要求相关条款）

### Step 1：撰写行政复议申请书

#### 1.1 申请书结构

```
行政复议申请书

申请人：[姓名/名称]，[性别]，[民族]，[出生日期]，住[地址]。
        （法人：名称、住所、法定代表人姓名及职务）
身份证号/统一社会信用代码：[号码]
联系电话：[号码]

被申请人：[行政机关全称]
地址：[地址]
法定代表人：[姓名]，[职务]

行政复议请求：
一、[撤销/变更/确认违法/责令履行]被申请人于YYYY年MM月DD日作出的
    [文书名称及文号]；
二、[如有赔偿请求，列明]；
三、[其他请求]。

事实与理由：

一、基本事实
[按时间顺序叙述案件事实，包括：
 1. 申请人与行政行为的关系
 2. 行政行为的作出过程
 3. 行政行为的内容
 4. 对申请人的影响]

二、行政行为违法的具体理由
[按四维分析框架展开：
 （一）主体方面：[如主体不适格]
 （二）职权方面：[如超越职权/滥用职权]
 （三）程序方面：[如违反法定程序的具体表现]
 （四）实体方面：[如事实不清/证据不足/适用法律错误/明显不当]
 每个理由须引用具体法律条文]

三、结论
综上所述，被申请人作出的[行政行为]存在[列举违法情形]，
违反了[具体法律条文]，依法应予[撤销/变更/确认违法/责令履行]。
申请人依据《中华人民共和国行政复议法》的相关规定，向贵机关申请
行政复议，请依法支持申请人的复议请求。

此致
[复议机关名称]

                                        申请人：[签名]
                                        日期：YYYY年MM月DD日

附件：
1. 申请人身份证明
2. [被诉行政行为文书]
3. 相关证据材料
4. 授权委托书（如有代理人）
```

#### 1.2 撰写要求

| 要求 | 说明 |
|:---|:---|
| 请求明确 | 复议请求必须具体、明确——是撤销还是变更还是确认违法，不能含糊 |
| 事实清楚 | 按时间顺序，客观叙述，不带主观评价 |
| 理由具体 | 每个违法理由必须指出违反了哪部法律的哪一条 |
| 法条引用 | 必须引用具体条文，不能笼统说"违反相关法律" |
| 逻辑清晰 | 事实→理由→结论，层层递进 |

### Step 2：整理材料清单

| 序号 | 材料名称 | 份数 | 备注 |
|:---:|:---|:---:|:---|
| 1 | 行政复议申请书 | 一式两份 | 申请人签名 |
| 2 | 申请人身份证明 | 1份 | 身份证复印件/营业执照副本 |
| 3 | 被诉行政行为文书 | 1份 | 处罚决定书/不予许可决定书等 |
| 4 | 证据材料 | 按清单 | 详见证据清单 |
| 5 | 授权委托书 | 1份 | 如有代理人 |
| 6 | 代理人身份证明 | 1份 | 如有代理人 |
| 7 | 律师执业证复印件 | 1份 | 如有律师代理 |

### Step 3：输出与归档

1. 将复议申请书 Markdown 母版存入 `03_正式文书/`
2. 将撰写过程中的分析记录存入 `02_工作底稿/`
3. 材料清单存入 `02_工作底稿/`

## 注意事项

1. **请求项的选择**：撤销（最常用）、变更（复议特有，诉讼一般不能变更）、确认违法、责令履行——根据案件情况选择
2. **赔偿请求可以一并提**：如果行政行为造成了实际损害，可以在复议申请中一并提出赔偿请求
3. **不要遗漏关键证据**：行政行为文书（如处罚决定书）是必须提交的，没有它复议机关可能不予受理
4. **份数要求**：各地要求可能不同，一般申请书一式两份（复议机关留存+送达被申请人）
5. **提交方式**：可以现场提交、邮寄提交、或在部分地方通过网上平台提交
