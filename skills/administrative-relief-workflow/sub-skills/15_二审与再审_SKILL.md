# 模块 15：二审与再审

## 适用阶段

救济阶段。一审判决后提起上诉或判决生效后申请再审时执行。

## 任务目标

撰写上诉状或再审申请书。

## 前置要求

- 一审判决书已收到
- 已分析判决内容，决定上诉或申请再审

## 执行步骤

### Step 0：加载知识库

- `references/文书模板/上诉状模板.md`（上诉时）
- `references/文书模板/再审申请书模板.md`（再审时）

### Step 1：一审判决分析

| 分析项 | 内容 |
|:---|:---|
| 判决结果 | 胜诉/败诉/部分胜诉 |
| 事实认定 | 法院认定了哪些事实？遗漏了哪些？ |
| 法律适用 | 法院适用了哪些法律？适用是否正确？ |
| 程序问题 | 一审是否存在程序违法（如遗漏当事人、未质证等） |
| 上诉/再审理由 | 事实认定错误/法律适用错误/程序违法 |

### Step 2A：撰写上诉状（如上诉）

```
上诉状

上诉人：[基本信息]
被上诉人：[基本信息]

上诉人因与被上诉人[案由]一案，不服[一审法院][判决书文号]
行政判决，现提起上诉。

上诉请求：
一、撤销[一审判决文号]；
二、[改判支持上诉人的一审诉讼请求/发回重审]；
三、一审、二审诉讼费由被上诉人承担。

上诉理由：
一、一审判决事实认定错误
[具体说明]
二、一审判决适用法律错误
[具体说明]
三、[如有]一审程序违法
[具体说明]

此致
[二审法院名称]

                                        上诉人：[签名]
                                        日期：YYYY年MM月DD日
```

**上诉期限**：收到判决书之日起15日内（裁定10日内）

### Step 2B：撰写再审申请书（如再审）

```
再审申请书

再审申请人：[基本信息]
被申请人：[基本信息]

再审申请人因[案由]一案，对[法院][判决/裁定文号]不服，
依据《行政诉讼法》第91条之规定，申请再审。

再审请求：[同上]

再审理由：
[必须符合第91条列举的再审事由之一]

此致
[再审法院名称]

                                        再审申请人：[签名]
                                        日期：YYYY年MM月DD日
```

**再审期限**：判决/裁定生效后6个月内

### Step 3：输出与归档

## 产出文件

| 文件 | 存放位置 |
|:---|:---|
| `YYYYMMDD_上诉状_上诉人代理人.md` 或 `YYYYMMDD_再审申请书_再审申请人代理人.md` | `03_正式文书/` |

## 注意事项

1. **上诉理由要有针对性**：针对一审判决的错误，不是重复一审主张
2. **再审门槛很高**：必须符合法定再审事由，不是所有案件都适合再审
3. **期限严格**：上诉15天，再审6个月
