# 行政救济全流程

**版本**：v1.1.0
**适用范围**：中国大陆行政案件·申请人端（公民/企业/其他组织）

一套覆盖行政复议与行政诉讼全链路的 AI 技能，以「主体→职权→行为→程序」四维分析框架为核心，适用于各类行政案件。

---

## 一、整体架构

```
SKILL.md（主控：意图识别 + 模块路由 + 四维分析框架 + 全局规范）
├── sub-skills/          16 个子技能模块（按程序阶段+分析维度组织）
└── references/          按需加载的知识库
    ├── 核心法规/         行政复议法+行政诉讼法+国家赔偿法+司法解释
    ├── 行政行为类型/     处罚/许可/强制/征收/确认/不作为/信息公开
    ├── 文书模板/         复议申请书/起诉状/上诉状/再审申请书/代理意见
    └── special-paths/   特殊分支（复议前置/共同被告/附带审查/赔偿/保全）
```

## 三、核心创新

1. **矩阵式结构**：四维分析框架（横轴）× 程序阶段链（纵轴），比纯线性结构更适合行政案件
2. **五个特殊分支模块**：复议前置、共同被告、规范性文件附带审查、行政赔偿、停止执行与保全
3. **知识库按行为类型组织**：处罚/许可/强制/征收/确认/不作为/信息公开——律师拿到案件首先知道行为类型
4. **期限强制代码验证**：禁止手动推算日期，用 Python datetime 精确计算

## 四、使用方式

直接说需求即可，例如：
- "帮我分析这个行政处罚能不能复议"
- "写行政复议申请书"
- "这个案件走复议还是直接诉讼"
- "帮我准备行政案件庭审"
- "写行政诉讼代理词"

## 五、边界

- ✅ 行政案件（处罚/许可/强制/征收/确认/不作为/信息公开等）
- ✅ 只做申请人端（公民/企业/其他组织）
- ❌ 刑事案件、民商事案件
- ❌ 不代理政府机关
- ❌ 非中国大陆法域
