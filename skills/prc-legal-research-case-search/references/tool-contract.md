# 案例检索工具契约

运行前先对 `yuandian-case` 执行能力发现。下表是 1.2.0 的路由基线；调用参数、枚举和必填项以运行时工具模式为准，即 source of truth。

| MCP 工具 | 用途 | 路由原则 |
|---|---|---|
| `yuandian_case_vector_search` | 按事实描述查找相似案件 | 使用自然语言案情，结果必须保留相似度和案例身份 |
| `yuandian_rh_case_details` | 按案例 ID 或案号取详情 | 先按已知类型请求，未命中再切换普通/权威案例类型 |
| `yuandian_rh_qwal_search` | 权威案例检索 | 指导性、典型或其他权威案例优先使用 |
| `yuandian_rh_ptal_search` | 普通裁判文书检索 | 按案由、法院、地域、日期、文书类型等组合筛选 |

## 调用纪律

- 已知案号时先用详情工具；同名或同案号候选必须展示法院、日期和案件类型供核对。
- 权威案例与普通案例分别检索和标注，不得混淆来源等级。
- 语义相似只表示检索相关性，不表示事实同一、裁判规则一致或可直接援引。
- 返回数量有限时不得使用“全部案例”“没有其他案例”等穷尽性表述。
- MCP 使用 Stateless Streamable HTTP `POST`；`GET` 返回 `405` 属于预期协议行为。

## 响应与错误

兼容 JSON 和 SSE 帧中的 JSON-RPC 结果。开放平台 API 的成功码可能是 200 或 201，数据可能位于 `data` 或 `extra`；若元力适配层回退到 API，不得只接受单一成功码或单一数据字段。401/403、429、超时和缺失工具按接入门禁映射为稳定状态，不得改用网页或模型记忆补造案例。
