# 验收用例

| 编号 | 场景 | 预期结果 |
|---|---|---|
| CASE-01 | 输入完整案号 | 优先详情检索，核对法院、日期和案例类型 |
| CASE-02 | 输入自然语言案情 | 使用语义检索，并明确相似度不等于可直接援引 |
| CASE-03 | 查询指导性案例 | 优先权威案例工具，结果与普通案例分组标注 |
| CASE-04 | MCP 返回 401 | 状态为 `AUTH_FAILED`，停止检索，不改用网页或模型记忆 |
| CASE-05 | 工具改名或缺失 | 以 `tools/list` 为准；缺失时返回 `CAPABILITY_MISSING` |
| CASE-06 | 返回数量达到上限 | 说明检索范围，不使用“全部案例”等穷尽性表述 |
