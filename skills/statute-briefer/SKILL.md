# 法规简报器（MAPS + RULES）

产出结构化法规/法案简报，其（a）映射整个法规/法案的架构，且（b）将操作性条款表述为规则模块。可选地将条款应用于场景并附逐字引文。

## 输入模式

**模式 A：仅文本简报**
- 必需：法规文本（或定界摘录）
- 可选：引注信息、版本类型（已颁布/已法典化/修正案）、长度约束（简短/标准/详细）

**模式 B：场景驱动简报**
- 必需：法规文本 + 场景描述
- 可选：决策姿态（建议/合规/诉讼）、长度约束

引注/版本缺失时，将简报标注为“text-as-provided”（按所提供文本），不作时效性声明。

## 输出结构

每份简报产出两层。模式 B 中，前置场景模块。

### 场景模块（仅模式 B）

详细模板见 [references/scenario-template.md](references/scenario-template.md)。

六个组成部分：
1. **场景概要** ——仅法律上显著的事实
2. **以法规问题表述的争点** ——将争议表述为法规解释问题
3. **相关摘录（逐字）** ——带精确定位引用的块引用文本；包含相邻的定义/例外
4. **适用图谱（法规到事实）** ——对每个争点：要件已满足、不明或存争议；识别缺失事实
5. **背景图谱（摘录所在位置）** ——每个摘录的篇/章/节路径
6. **未触发但结构上重要** ——场景未触发的重大法案组成部分

### MAPS（系统级图谱）

五个组成部分：
1. **引注与文本状态** ——引注块或“未提供引注”；注明是否部分文本
2. **目的** ——存在明示目的/认定时引用（附引注）；否则标注为推断
3. **结构图谱（整个法案）** ——带功能性标签（“定义”“禁止”“执行”等）的层级大纲；大法规提供主要分部概览加放大细节
4. **范围与覆盖** ——覆盖的行为人、行为、地域、时间、管辖钩子、明示排除
5. **定义与解释规则** ——定义术语索引；解释性条款；交叉引用

### RULES（操作模块）

对每项主要操作性条款（或场景相关条款），产出规则模块。

详细模板见 [references/rule-module-template.md](references/rule-module-template.md)。

**规则模块必填字段：**
1. **条款** ——精确定位引用
2. **触发条件（要件）** ——什么激活该条款
3. **法律效果** ——命令 / 许可 / 禁止 / 权利
4. **例外 / 抗辩 / 安全港** ——规则中的除外情形
5. **程序 / 决策者** ——期限、通知、标准
6. **后果** ——处罚、救济、无效、丧失利益
7. **管辖 / 执行者** ——机构、法院、私人原告
8. **交互规则** ——优先/保留、可分割性、生效日期、交叉引用

## 强制约束

### 逐字纪律
- 绝不编造法规语言
- 明确标记所有引文并附精确定位引用
- 文本缺失时说明，并以所提供内容继续

### 交叉引用纪律
- 法规定义操作性条款所用术语时，纳入该定义
- 标记外部交叉引用：“cross-reference not included in provided materials”（所提供材料中未包含交叉引用）

### 分层分离
- 将“引文文本”与“解释/翻译”分开
- 使用块引用或清晰标记

### 不得过早窄化
- 即使在场景模式中，也在主要分部层面纳入 MAPS 结构图谱

## 选择规则

**模式 A（无场景）：** 主要操作性条款 = 主要禁止/要求/权利 + 执行/救济 + 关键定义 + 优先/保留/可分割/管辖地

**模式 B（有场景）：** 优先处理管辖场景争点的条款 + 条件性定义/执行/例外。仍包含完整结构图谱。

## 长度控制

| 约束 | 结构图谱 | 规则模块 | 定义 |
|------------|---------------|--------------|-------------|
| 简短 | 仅主干大纲 | 仅最相关的 | 仅关键范围术语 |
| 标准 | 主要分部完整 | 核心操作性条款 | 影响范围的术语 |
| 详细 | 全细节 | 所有操作性条款 | 全面索引 |

## 不确定性处理

- 事实不足 → 标注“Fact needed: [具体缺失事实]”（需要的事实：[具体缺失事实]）
- 部分法规 → 标注“based on provided excerpt only”（仅基于所提供摘录）
- 绝不填补缺失条款

## 精确标题（供解析）

```
Scenario Module（场景模块）
  Scenario synopsis（场景概要）
  Issues framed as statutory questions（以法规问题表述的争点）
  Relevant excerpts (verbatim)（相关摘录（逐字））
  Application map (statute-to-facts)（适用图谱（法规到事实））
  Context map (where excerpts live)（背景图谱（摘录所在位置））
  Not used but structurally important（未触发但结构上重要）

MAPS
  Citation and text status（引注与文本状态）
  Purpose（目的）
  Structure map (entire Act)（结构图谱（整个法案））
  Scope and coverage（范围与覆盖）
  Definitions and interpretive rules（定义与解释规则）

RULES
  Rule-Module: [Provision cite]（规则模块：[条款引注]）
```

## 边界

- 仅简报法规和立法法案
- 除非被要求，不作政策评论
- 不作评分或教学评论
- 不生成新的法规文本
- 除非明确要求，不引案例；可将“interpretive pressure points”（解释压力点）作为歧义标记注明
