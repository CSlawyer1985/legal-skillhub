# 商标侵权判断标准核心参考文档

> 来源：《商标侵权判断标准》（国知发保字〔2020〕23号）及《〈商标侵权判断标准〉理解与适用》

---

## 一、商标侵权判断总体框架

判断是否构成商标侵权，须按以下逻辑层层递进：

```
第一步：是否构成"商标的使用"（商标法意义上）
         ↓ 是
第二步：是否"未经商标注册人许可"
         ↓ 是
第三步：使用的商品/服务 与 权利人核定商品/服务 是否构成同一种或类似
         ↓ 是
第四步：使用的商标 与 权利人注册商标 是否相同或近似
         ↓ 相同（同一商品/服务）→ 直接认定侵权（商标法第57条第1项）
         ↓ 近似（同一商品/服务），或 相同/近似（类似商品/服务）→
第五步：是否容易导致混淆 → 是则认定侵权（商标法第57条第2项）
```

---

## 二、商标的使用（第3-7条）

### 定义
将商标用于商品、商品包装、容器、服务场所及交易文书上，或用于广告宣传、展览及其他商业活动中，**用以识别商品或者服务来源**的行为。

### 具体表现形式
**商品商标使用形式：**
- 直接贴附、刻印、烙印、编织等方式附着于商品/包装/容器/标签/附加标牌/说明书/价目表
- 使用在商品销售合同、发票、票据、收据、进出口检验检疫证明、报关单据等交易文书

**服务商标使用形式：**
- 直接用于服务场所：介绍手册、工作人员服饰、招贴、菜单、名片、奖券、办公文具、信笺
- 用于服务交易文书：发票、收据、汇款单据、服务协议、维修维护证明等

**广告宣传/展览/其他商业活动形式：**
- 广播、电视、电影、互联网、公开出版物、广告牌、邮寄广告
- 展览会、博览会上的印刷品、展台照片、参展证明
- 网站、即时通讯工具（如微信）、社交网络平台、APP
- 二维码等信息载体
- 店铺招牌、店堂装饰装潢

> **特别注意**：互联网广告关键词搜索中，若搜索结果页面的标题等显著位置出现他人商标文字，该商标具备了识别来源功能，应认定为商标的使用。

### 判断"商标使用"的考量因素
综合考虑以下因素：
1. **使用人主观意图**：是否有意将该标志用于识别自身商品/服务
2. **使用方式**：是否对消费者明显可见，是否具有稳定性和一致性
3. **宣传方式**：是否持续、连贯地使用
4. **行业惯例**：所处行业的商标使用习惯
5. **消费者认知**：消费者是否会将其识别为商标而非商品形状、广告词或通用名称

> **注意**：商标法第57条第4项（伪造、擅自制造他人注册商标标识）无需判断是否构成商标的使用，可直接认定侵权。

## 三、未经商标注册人许可（第8条）

包括两种情形：
1. **未获得许可**：完全未经授权
2. **超出许可范围**：超出许可的商品/服务类别、期限、数量、特许经营店铺数量等

---

## 四、同一种商品/服务 vs 类似商品/服务（第9-12条）

### 同一种商品/服务的认定
| 情形 | 认定标准 |
|------|---------|
| 名称相同 | 直接认定为同一种商品/服务 |
| 名称不同 | 在功能、用途、主要原料、生产部门、消费对象、销售渠道等方面相同或基本相同，相关公众一般认为是同种商品 |

### 类似商品/服务的认定
- **类似商品**：在功能、用途、主要原料、生产部门、消费对象、销售渠道等方面具有一定共同性
- **类似服务**：在服务的目的、内容、方式、提供者、对象、场所等方面具有一定共同性

### 判断依据与原则
1. **参照现行《类似商品和服务区分表》**（区分表具有法定效力）
2. 区分表未涵盖的商品：基于相关公众一般认识，综合考虑上述因素
3. **比对对象**：权利人注册商标**核定使用的商品/服务** vs **涉嫌侵权的商品/服务**（不以权利人实际使用的商品为准）
4. 遵循"从新兼从轻"原则：原则上参照商标权利人请求保护时的区分表，但如案件发生时区分表认定为不类似，则参照案件发生时的区分表

> **常见误区**：不得将涉案商品与权利人实际生产销售的商品比对，应与核定使用的商品比对。

---

## 五、商标相同的认定（第13-14条）

### 定义
涉嫌侵权商标与注册商标**完全相同**，或虽有不同但**视觉效果/听觉感知基本无差别、相关公众难以分辨**。

### 各类商标相同的认定情形

**文字商标相同：**
- 文字构成、排列顺序均相同
- 改变字体、字母大小写、文字横竖排列，基本无差别
- 改变文字/字母/数字间距，基本无差别
- 改变颜色，不影响显著特征
- 仅增加商品通用名称、图形、型号等缺乏显著特征内容，不影响显著特征（如"GXG"与"GXG FASHION"）

**图形商标相同：**
- 构图要素、表现形式等视觉上基本无差别

**文字图形组合商标相同：**
- 文字构成、图形外观及排列组合方式相同，整体视觉上基本无差别

**立体商标相同：**
- 显著三维标志和显著平面要素均相同或基本无差别

**颜色组合商标相同：**
- 颜色和排列方式相同或基本无差别

**声音商标相同：**
- 听觉感知和整体音乐形象相同或基本无差别

## 六、商标近似的认定（第15-18条）

### 定义
- 文字商标：字形、读音、含义近似
- 图形商标：构图、着色、外形近似
- 文字图形组合商标：整体排列组合方式和外形近似
- 立体商标：三维标志的形状和外形近似
- 颜色组合商标：颜色或组合近似
- 声音商标：听觉感知或整体音乐形象近似

### 判断方法（三合一原则）
参照《商标审查审理指南》，以**相关公众的一般注意力和认知力**为标准，综合运用：

| 方法 | 说明 |
|------|------|
| **隔离观察** | 不将两商标摆在一起对比，而是凭借对一方商标的印象去判断另一方，模拟消费者实际购买场景 |
| **整体比对** | 将商标作为整体观察外观、整体构成和表现形式，不能仅因某一部分相同就认定整体近似 |
| **主要部分比对** | 提取发挥主要识别作用的部分进行比对，不能仅因非主要部分不近似就排除整体近似 |

### 关键注意事项
- **比对对象**：权利人**核准注册**的商标 vs 涉嫌侵权商标（不以权利人实际使用的商标为准）
- **商品价值影响注意力**：贵重商品（汽车、房屋）消费者注意力更高，不易产生混淆
- 四字及以上商标完整包含他人在先两字商标，**一般不判为近似**，但以下情况除外：
  - 加上本商品通用名称、型号
  - 加上直接表示质量、原料、功能的文字
  - 加上修饰性形容词/副词或显著性较弱的文字
  - 包含他人具有一定知名度或显著性较强的在先文字商标

## 七、容易导致混淆的判断（第19-21条）

### 适用场景
- 同一种商品/服务 + 近似商标
- 类似商品/服务 + 相同或近似商标

> 注：在同一种商品/服务上使用**相同**商标，**无需**判断混淆，直接认定侵权。

### 混淆的两种情形
1. **来源混淆**：足以使相关公众认为涉案商品/服务由注册商标权利人生产或提供
2. **关联混淆**：足以使相关公众认为涉案商品/服务提供者与注册商标权利人存在**投资、许可、加盟或合作**等关系

> **重要**：混淆不以实际发生为要件，只需具有**混淆的可能性**即可。

### 综合考量因素
| 因素 | 说明 |
|------|------|
| 商标近似程度 | 近似度越高，混淆可能性越大 |
| 商品/服务类似程度 | 类似度越高，混淆可能性越大 |
| 注册商标显著性 | 显著性越强（尤其臆造词），混淆可能性越大 |
| 注册商标知名度 | 知名度越高，混淆可能性越大 |
| 商品/服务特点及使用方式 | 专业性强、价值高的商品（如汽车），消费者注意力高，混淆可能性小 |
| 相关公众的注意和认知程度 | 注意程度越高，混淆可能性越小 |
| 攀附意图 | 有攀附意图者，认定混淆的门槛降低 |

### 商标显著性判断维度
- **标志独特性**：臆造词 > 固有词；虚构图案 > 客观存在事物图案
- **与商品/服务的关联性**：关联性越弱，显著性越强（如"苹果"用于手机）
- **可识别性**：过于复杂或简单的标志显著性弱
- **后天显著性**：通过长期使用获得的显著性（综合考虑使用时间、范围、广告宣传）

## 八、特殊侵权情形（第22-31条）

### 自行改变注册商标或组合使用（第22条）
- 改变/组合后与他人在同一种商品/服务上相同 → 第57条第1项
- 改变/组合后与他人在同一种或类似商品/服务上近似且易混淆 → 第57条第2项

### 字号突出使用（第23条）
- 在同一种商品/服务上将企业字号突出使用，与他人注册商标相同 → 第57条第1项
- 在同一种或类似商品/服务上突出使用字号，与他人近似且易混淆 → 第57条第2项

### 不指定颜色商标附着颜色（第24条）
- 以**攀附为目的**附着颜色，与他人在同一种或类似商品/服务上近似且易混淆 → 第57条第2项
- **攀附意图认定**：注册商标知名度较高 + 处于同一行业或关联行业 + 无正当理由使用近似标志

### 包工包料加工承揽（第25条）
- 承揽人使用侵权商品 → 第57条第3项

### 销售时附赠侵权商品（第26条）
- 经营者附赠侵权商品 → 第57条第3项

### 销售不知道是侵权商品的认定（第27-29条）
**不属于"不知道"的情形（即认定为明知）：**
1. 进货渠道不符合商业惯例，且价格明显低于市场价格
2. 拒不提供账目、销售记录等会计凭证，或弄虚作假
3. 案发后转移、销毁物证，或提供虚假证明
4. 类似违法情形受到处理后再犯
5. 其他可认定当事人明知或应知的情形

**"说明提供者"的认定：**
- 必须主动提供供货商**准确**的名称、经营地址、联系方式等信息或线索
- 提供虚假或无法核实的信息，不视为"说明提供者"

### 市场主办方/平台经营者的责任（第30条）
市场主办方、展会主办方、柜台出租人、电商平台等：
- **明知或应知**商标侵权而不制止 → 第57条第6项
- 经商标执法部门通知或权利人持生效行政/司法文书告知后，**仍未采取必要措施** → 第57条第6项

### 域名侵权（第31条）
将与他人注册商标相同或近似的文字注册为域名，并通过该域名进行相关商品/服务电子商务，**容易使相关公众产生误认** → 第57条第7项

## 九、其他重要规则（第32-36条）

### 在先权利保护（第32条）
- 以外观设计专利权、著作权抗辩他人注册商标专用权的：
  - 若注册商标申请日**先于**外观设计专利申请日或著作权作品创作完成日 → 可对商标侵权案件查处

### 有一定影响的商标（第33条）
- 指在国内在先使用并为一定范围内相关公众所知晓的**未注册商标**
- 认定考虑：持续使用时间、销售量、经营额、广告宣传
- **不视为在原使用范围内继续使用的情形**：
  1. 增加该商标使用的具体商品/服务
  2. 改变商标的图形、文字、色彩、结构、书写方式（以与他人注册商标相区别为目的的改变除外）
  3. 超出原使用范围的其他情形

### 五年内两次以上侵权（第34条）
- 同一当事人被认定侵权的行政处罚或判决**生效之日起五年内**又实施商标侵权行为

### 案件中止（第35条）
可适用中止的情形：
1. 注册商标处于无效宣告中
2. 注册商标处于续展宽展期
3. 注册商标权属存在其他争议情形

### 权利人辨认意见（第36条）
- 商标执法部门可要求权利人出具书面辨认意见
- 权利人须对辨认意见承担相应法律责任
- 执法部门须审查辨认人主体资格及意见真实性
- 涉嫌侵权人无相反证据推翻的，辨认意见作为证据采纳

## 十、典型案例摘要

| 案例 | 核心要点 |
|------|---------|
| 虾香稻米案 | "虾香稻米"用于描述种植方法，非商标性使用，不构成侵权 |
| 苹果维修案 | 在服务场所装潢、员工服饰、POS机签购单上使用他人商标，构成服务商标侵权 |
| 邓白氏关键词案 | 在百度搜索结果显著位置使用他人商标作为关键词，构成商标使用 |
| GXG案 | "GXG FASHION"与"GXG"，"FASHION"缺乏显著性，二者为相同商标 |
| 鲍师傅案 | "鳕鱼小贝""玫瑰鲜花饼"与"糕点"在主要原料等方面相同，属同一种商品 |
| SANTAK案 | "SANTAKUPS"与"SANTAK"，"UPS"为产品名称缩写缺乏显著性，构成近似商标 |
| 青岛啤酒瓶案 | 回收旧酒瓶未有效遮盖浮雕商标，瓶体浮雕更醒目，构成商标侵权 |
| 泰山酒案 | 自行改变注册商标，突出使用"泰山"，与他人注册商标近似，构成侵权 |
| 蜜妍案 | "兰蔻蜜妍滋养精华乳"不构成侵权（显著部分为"兰蔻蜜妍"，销售渠道不同，消费者注意力高）|
| 水密码案 | 在商品名称中使用"水密码柔肤乳"，完整包含他人知名商标，构成侵权 |
| 爱莲巧案 | 涉案当事人曾是代理销售商并曾申请近似商标被驳回，主观恶意明显，构成侵权 |
