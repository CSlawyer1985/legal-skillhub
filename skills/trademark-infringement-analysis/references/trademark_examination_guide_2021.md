# 商标审查审理指南（2021版）- 商标注册检索判断指引要点

## 一、商标相同判断标准

### 1.1 文字商标相同

**认定标准**：
- 文字构成、排列顺序完全相同
- 改变字体、字母大小写、文字横向或竖向排列、间隔、颜色、添加通用名称或修饰性词汇，但**显著特征无差别**

**具体情形**：
| 情形 | 示例 | 是否相同 |
|------|------|----------|
| 仅改变字体 | "ABC" vs "ABC"（不同字体） | 是 |
| 大小写变化 | "abc" vs "ABC" | 是 |
| 添加通用名称 | "苹果" vs "苹果牌" | 是 |
| 添加修饰词 | "美丽" vs "美丽的" | 是 |
| 横竖排列变化 | 横向"ABC" vs 竖向"ABC" | 是 |
| 间隔变化 | "A B C" vs "ABC" | 是 |

### 1.2 图形商标相同

**认定标准**：
- 构图要素、表现形式等视觉上基本无差别
- 细微差别不影响整体视觉效果的，仍认定为相同

### 1.3 组合商标相同

**认定标准**：
- 文字构成、图形外观及其排列组合方式相同
- 整体视觉基本无差别

## 二、商标近似判断标准

### 2.1 判断原则（三合一方法）

1. **隔离观察**：模拟消费者真实场景，不直接对比，凭借记忆印象判断
2. **整体比对**：观察整体构成和外观给人的整体印象
3. **主要部分比对**：提取发挥主要识别作用的部分进行比较

**判断标准**：以**相关公众的一般注意力和认知力**为标准

### 2.2 文字商标近似判断

#### 2.2.1 文字字形近似
- 字形相近，易使相关公众对商品/服务来源产生混淆
- 示例："土"与"士"、"未"与"末"、"己"与"已"

#### 2.2.2 文字读音近似
- 读音相同或相近，易使相关公众对商品/服务来源产生混淆
- 示例："华为"与"华唯"、"小米"与"晓米"

#### 2.2.3 文字含义近似
- 含义相同或相近，易使相关公众对商品/服务来源产生混淆
- 示例："太阳"与"SUN"、"长城"与"GREAT WALL"

#### 2.2.4 文字排列顺序不同
- 文字构成相同但排列顺序不同，整体无含义或含义无明显区别
- 示例："新康得"与"康得新"

### 2.3 图形商标近似判断

**判断要点**：
- 构图要素、整体外观是否近似
- 设计风格、表现手法是否近似
- 整体视觉效果是否容易引起混淆

### 2.4 组合商标近似判断

**判断要点**：
1. 文字部分是否近似
2. 图形部分是否近似
3. 整体排列组合方式是否近似
4. 显著识别部分是否近似

## 三、商品/服务类似判断

### 3.1 判断依据

**主要依据**：《类似商品和服务区分表》（尼斯分类）

**补充判断因素**：

**商品类似考虑因素**：
- 功能、用途
- 主要原料
- 生产部门
- 销售渠道
- 消费对象
- 消费习惯

**服务类似考虑因素**：
- 服务目的
- 服务内容
- 服务方式
- 服务提供者
- 服务对象
- 服务场所

### 3.2 类似商品判断示例

| 商品A | 商品B | 类似性判断 | 理由 |
|-------|-------|------------|------|
| 服装 | 鞋 | 类似 | 同属穿戴类，销售渠道、消费对象相同 |
| 咖啡 | 茶叶 | 类似 | 同属饮品，消费场景、消费对象相同 |
| 手机 | 手机壳 | 类似 | 配套使用，关联性强 |
| 汽车 | 自行车 | 不类似 | 功能、价格、消费对象差异大 |

## 四、混淆可能性判断

### 4.1 混淆类型

1. **来源混淆**：误认为商品/服务来源于同一主体
2. **关联混淆**：误认为商品/服务提供者之间存在特定联系（投资、许可、加盟等）

### 4.2 混淆可能性判断因素

#### 4.2.1 商标因素
- 商标近似程度
- 商标显著性（固有显著性/获得显著性）
- 商标知名度

#### 4.2.2 商品/服务因素
- 商品/服务类似程度
- 商品/服务特点
- 商品/服务之间的关联性

#### 4.2.3 市场因素
- 销售渠道
- 销售场所
- 消费群体重叠度
- 价格区间

#### 4.2.4 主观因素
- 使用人的主观意图（是否具有攀附故意）
- 是否造成实际混淆的证据
- 商标使用方式

#### 4.2.5 其他因素
- 商标使用历史
- 市场共存情况
- 相关公众的注意程度

### 4.3 知名度对混淆判断的影响

**高知名度商标**：
- 保护范围更广
- 类似商品/服务范围更宽
- 混淆可能性认定标准相对宽松

**普通商标**：
- 按常规标准判断
- 需更强的近似性和类似性证据

## 五、特殊情形判断

### 5.1 驰名商标保护

**跨类保护原则**：
- 已注册驰名商标：可禁止他人在不相同/不类似商品上注册/使用复制、摹仿、翻译的商标
- 未注册驰名商标：可禁止他人在相同/类似商品上注册/使用复制、摹仿、翻译的商标

**认定因素**：
- 相关公众知晓程度
- 使用持续时间
- 宣传工作的持续时间、程度和地理范围
- 受保护记录
- 其他因素

### 5.2 在先权利保护

**在先权利类型**：
- 在先著作权
- 在先外观设计专利权
- 在先企业名称权
- 在先姓名权
- 在先肖像权
- 在先域名权
- 在先知名商品特有名称/包装装潢权

### 5.3 正当使用抗辩

**描述性正当使用**：
- 使用注册商标中含有的本商品的通用名称、图形、型号
- 直接表示商品的质量、主要原料、功能、用途、重量、数量及其他特点
- 含有的地名

**指示性正当使用**：
- 为说明商品来源而使用他人商标
- 使用方式合理，不会造成混淆

## 六、检索判断实务要点

### 6.1 检索范围

**相同/近似商标检索**：
- 相同商品/服务上的相同商标
- 相同商品/服务上的近似商标
- 类似商品/服务上的相同商标
- 类似商品/服务上的近似商标

**在先权利检索**：
- 在先商标权
- 在先著作权
- 在先企业名称权
- 其他在先权利

### 6.2 检索策略

**文字商标检索**：
- 完全相同检索
- 读音近似检索
- 字形近似检索
- 含义近似检索
- 逆序检索

**图形商标检索**：
- 要素分解检索
- 整体外观检索
- 构图方式检索

**组合商标检索**：
- 文字部分单独检索
- 图形部分单独检索
- 整体检索

### 6.3 判断流程

```
第一步：确定商品/服务类别
    ↓
第二步：检索相同/近似商标
    ↓
第三步：判断是否构成商标相同
    ↓ 是 → 存在冲突
    ↓ 否
第四步：判断是否构成商标近似
    ↓ 否 → 不存在冲突
    ↓ 是
第五步：判断商品/服务是否类似
    ↓ 否 → 不存在冲突
    ↓ 是
第六步：判断是否容易导致混淆
    ↓ 是 → 存在冲突
    ↓ 否 → 不存在冲突
```

## 七、典型案例参考

### 案例1：文字商标近似判断
**案情**："新百伦" vs "纽巴伦"
**判断要点**：
- 读音相近（Xīn Bǎi Lún vs Niǔ Bā Lún）
- 均为运动鞋品牌
- 易使消费者混淆
**结论**：构成近似商标

### 案例2：图形商标近似判断
**案情**：两个鸟类图形商标
**判断要点**：
- 整体外观相似
- 构图要素相似
- 设计风格相似
**结论**：构成近似商标

### 案例3：组合商标近似判断
**案情**：文字+图形组合商标
**判断要点**：
- 文字部分为主要识别部分
- 文字构成近似
- 整体印象近似
**结论**：构成近似商标

### 案例4：商品类似判断
**案情**："服装"与"鞋"是否类似
**判断要点**：
- 同属穿戴类商品
- 销售渠道相同（商场、电商平台）
- 消费对象相同
- 消费习惯相近
**结论**：构成类似商品
