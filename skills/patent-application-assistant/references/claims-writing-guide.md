# 权利要求书撰写方法与技巧

> 📌 本文档系统讲解权利要求书的撰写方法，包括独立权利要求与从属权利要求的结构、保护范围界定技巧、撰写常见错误及规避，是专利代理实务的核心技能。
> 法律依据：《专利法》第26条第4款（权利要求清楚、简明、得到说明书支持）、第56条（保护范围）、第59条（解释规则）。

## 一、权利要求书的本质与作用

权利要求书是界定专利保护范围的**法律文件**，是维权时判断侵权的唯一依据（第64条："专利权的保护范围以其权利要求的内容为准"）。

**核心矛盾**：
- 保护范围**过宽**：易因新颖性/创造性不足被驳回或无效（第22条）；
- 保护范围**过窄**：授权容易，但保护力度不足，容易被规避。

> 💡 **撰写目标**：在能够授权的前提下，争取尽可能宽的保护范围，并通过从属权利要求构建多层级防御体系。

## 二、权利要求的类型

| 类型 | 定义 | 作用 |
|------|------|------|
| 独立权利要求 | 从整体上反映发明/实用新型的技术方案，记载解决技术问题的必要技术特征 | 界定最宽保护范围 |
| 从属权利要求 | 包含引用的权利要求的所有特征，并增加附加技术特征 | 缩小范围、增加防御层级、备用 |

依据《专利法》第31条，一件申请一般限于一项发明（单一性原则），但可有多个独立权利要求和多个从属权利要求。

## 三、独立权利要求撰写

### 结构：前序部分 + 特征部分

依据实施细则，独立权利要求分两部分：

```
"一种[产品/方法名称]，[前序部分：写明现有技术共有的技术特征]，
 其特征在于：[特征部分：写明区别于现有技术的必要技术特征]。"
```

### 撰写示例（以无线充电装置为例）
```
一种无线充电装置，包括发射线圈和接收线圈（前序部分：现有技术共有特征），
其特征在于，还包括温度传感器和功率调节电路（特征部分：区别必要特征），
所述温度传感器设置于接收线圈附近，所述功率调节电路
根据温度传感器的检测信号调节发射线圈的输出功率。
```

### 独立权利要求撰写要点
1. **前序部分**：仅写现有技术已有的共有特征，不要写入创新特征（否则限制保护范围）；
2. **特征部分**：写入解决技术问题的**全部必要技术特征**，用"其特征在于"引出；
3. **必要技术特征**：为解决技术问题所必不可少的技术特征，缺少则无法解决技术问题；
4. **语言**：用"包括""包含"（开放式，保护范围宽）而非"由……组成"（封闭式，保护范围窄），根据需要选择。

## 四、从属权利要求撰写

### 结构：引用部分 + 限定部分

```
"根据权利要求1所述的[产品/方法名称]，[引用部分]，
 其特征在于：[限定部分：附加技术特征]。"
```

### 撰写示例
```
根据权利要求1所述的无线充电装置，其特征在于，
所述温度传感器为热敏电阻，所述功率调节电路包括PWM控制器，
所述PWM控制器根据热敏电阻的阻值变化调节占空比。
```

### 从属权利要求的作用与策略

| 层级 | 内容 | 作用 |
|------|------|------|
| 独立权利要求（权1） | 最宽保护范围 | 主权利要求，最易被攻击 |
| 第一层从属（权2-3） | 核心实施例的特征 | 独权被无效时的第一道防线 |
| 第二层从属（权4-6） | 优选实施例的特征 | 进一步细化，增加防御 |
| 末端从属（权7-10） | 具体参数、数值范围 | 最窄但最稳定的兜底权利 |

### 从属权利要求撰写要点
1. **引用关系正确**：明确引用哪个在前的权利要求，编号不能跳跃或矛盾；
2. **附加技术特征**：增加新的限定，使范围比引用的权利要求更窄；
3. **多项从属**：可引用多个在先权利要求（"根据权利要求1或2所述的……"），但不能作为其他多项从属权利要求的基础；
4. **数据范围**：用范围表达（如"频率为10-100kHz"），给出多个实施例数值。

## 五、保护范围界定技巧

### 1. 开放式与封闭式表达
| 表达方式 | 含义 | 保护范围 | 适用 |
|---------|------|---------|------|
| 开放式"包括/包含" | 还可有其他未列出的成分/特征 | 宽 | 一般产品/组合物优选 |
| 封闭式"由……组成" | 仅限于列出的成分/特征 | 窄 | 特定组合物/明确排除其他 |

### 2. 上位概念与下位概念
- **上位概念**（保护范围宽）："金属" "气体" "弹性部件"；
- **下位概念**（保护范围窄）："铜""氮气""弹簧"；
- **撰写策略**：独立权利要求用上位概念，从属权利要求用下位概念，实现范围梯度；
- ⚠️ 上位概念必须得到说明书支持（第26条第4款），说明书需有足够实施例支撑。

### 3. 功能性特征
- 用功能/效果而非结构限定的特征，如"用于……的装置"；
- 保护范围以说明书描述的对应结构及其等同方式为准；
- ⚠️ 功能性特征过多会导致保护范围难以确定，慎用。

### 4. 数值范围的撰写
- 给出范围："温度为50-200℃"；
- 提供端点和优选值："优选100-150℃"；
- 在不同从属权利要求中给出不同子范围，构建保护梯度。

## 六、权利要求撰写常见错误

| 错误类型 | 表现 | 后果 | 纠正方法 |
|---------|------|------|---------|
| 缺少必要技术特征 | 独权未包含解决技术问题的全部特征 | 无法解决技术问题，不符合实施细则 | 补充缺失的必要特征 |
| 包含非必要特征 | 独权写入了非关键的优选特征 | 保护范围过窄，易被规避 | 将非必要特征移至从属权利要求 |
| 未得到说明书支持 | 权利要求范围宽于说明书公开内容 | 第26条第4款驳回 | 增加说明书实施例或缩小权利要求范围 |
| 引用关系错误 | 从属权利要求引用编号错误/矛盾 | 格式缺陷、不清楚 | 检查引用编号的逻辑关系 |
| 保护范围不清楚 | "大约""左右""等"模糊用语 | 第26条第4款不清楚驳回 | 使用明确数值范围或明确表述 |
| 缺乏单一性 | 一件申请含多个无单一性发明的独权 | 第31条驳回，要求分案 | 拆分为多个申请 |
| 上位概念无支撑 | 独权用"金属"但说明书仅有"铜" | 第26条第4款驳回 | 补充多种金属实施例或限定具体金属 |

## 七、权利要求层级设计实例

以"一种智能温控无线充电装置"为例，展示完整层级设计：

```
权1（独立权利要求-最宽）：
  一种无线充电装置，包括发射线圈、接收线圈、温度传感器和功率调节电路，
  所述功率调节电路根据温度传感器信号调节输出功率。

权2（从属-核心实施例）：
  根据权1，其特征在于温度传感器为热敏电阻。

权3（从属-核心实施例）：
  根据权1，其特征在于功率调节电路包括PWM控制器。

权4（从属-优选实施例）：
  根据权2或3，其特征在于还包括散热风扇，所述散热风扇
  在温度超过阈值时启动。

权5（从属-数值范围）：
  根据权1，其特征在于输出功率调节频率为10-100kHz。

权6（从属-具体参数）：
  根据权5，其特征在于温度阈值为45-60℃。
```

> 💡 **设计逻辑**：权1最宽（易被攻击但保护范围大）→ 权2-3细化核心特征（防御）→ 权4-5增加优选特征（进一步防御）→ 权6最具体数值（兜底，最稳定）。审查/无效时若权1不保，依次退守权2-6。

## 八、权利要求项数与费用

依据收费标准，权利要求超过10项会产生附加费：
- **从第11项起**，每项加收 **150元** 申请附加费；
- 例如15项权利要求 → 附加费 =（15-10）×150 = 750元。

> 💡 一般建议权利要求总数控制在10项以内，既充分保护又避免额外费用。核心发明可适当增加项数。

## 九、特殊权利要求撰写

### 1. 方法权利要求
```
一种[工艺/方法名称]，包括以下步骤：
步骤1：……；
步骤2：……；
其特征在于[步骤的特定条件/顺序]。
```
- 注意步骤顺序是否是必要技术特征；
- 工艺参数（温度、时间、压力）是关键技术特征。

### 2. 用途权利要求
- "化合物X在制备治疗Y疾病药物中的应用"；
- 用于医药、化工领域的第二医药用途发明。

### 3. 外观设计权利要求
- 外观设计无传统权利要求书，以图片/照片为准；
- 简要说明可写明设计要点、请求保护色彩等。

## 十、权利要求书质量自检清单

撰写完成后逐项检查：
- [ ] 独立权利要求是否包含全部必要技术特征？
- [ ] 是否有非必要特征混入独立权利要求？
- [ ] 每项权利要求是否得到说明书支持（第26条第4款）？
- [ ] 保护范围是否清楚（无模糊用语）？
- [ ] 从属权利要求引用关系是否正确、无矛盾？
- [ ] 是否构建了从宽到窄的多层级保护体系？
- [ ] 上位概念是否有足够实施例支撑？
- [ ] 关键参数是否给出数值范围？
- [ ] 各权利要求间是否具备单一性（第31条）？
- [ ] 权利要求项数是否合理（控制附加费）？

> 💡 **专业提示**：权利要求书撰写是专利代理的核心技能，直接决定专利的价值。建议由专业专利代理师撰写，发明人充分沟通技术细节。一份精心设计的权利要求书，往往决定了专利在市场竞争中的实际保护力度。
