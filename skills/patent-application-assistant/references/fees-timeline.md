# 专利费用明细与时间线

> 📌 本文档提供专利申请全流程的官费明细、缴费时间线、费用减缴政策及年费缴纳规则，所有费用依据国家知识产权局2024年8月最新标准（财税〔2024〕23号等）。
> 法律依据：《专利法》第43条（年费）、《专利收费减缴办法》（财税〔2016〕78号）、财税〔2019〕45号、财税〔2024〕23号。

## 一、费用减缴政策（重要）

### 1. 减缴条件
| 申请人类型 | 减缴条件 |
|----------|---------|
| 个人 | 上年度月均收入低于5000元（即年收入≤6万元） |
| 企业 | 上年度企业应纳税所得额低于100万元 |
| 事业单位/社会团体/非营利性科研机构 | 符合条件即享受 |

### 2. 减缴比例
| 申请人数量 | 减缴比例 |
|----------|---------|
| 单个符合条件的申请人 | **减缴85%** |
| 两个或两个以上申请人（均须符合条件） | **减缴70%** |

### 3. 可减缴的费用种类
- ✅ 申请费（不含公布印刷费、申请附加费）；
- ✅ 发明专利申请实质审查费；
- ✅ 复审费；
- ✅ 年费（自授予专利权当年起**10年内**的年费）；
- ✅ 指定中国的单独指定费（第一期、第二期）。

> ⚠️ **不予减缴**：公布印刷费、申请附加费、年费滞纳金、恢复权利请求费等。

### 4. 减缴办理
- 申请时或在缴费前办理"费减备案"；
- 个人提供收入证明，企业提供年度纳税申报表；
- 费减备案审核通过后，系统自动按减缴比例计算。

## 五、年费缴纳规则与滞纳金

### 1. 缴纳时间
- 依据《专利法》第43条，专利权人应自授予专利权的当年开始缴纳年费；
- **缴纳日**：每年的申请日对应日为年费缴纳日（如申请日为3月15日，则每年3月15日为缴费日）。

### 2. 滞纳金规则
- **滞纳金**：每超过规定缴费时间1个月，加收**当年全额年费的5%**；
- 滞纳金按月累计，最高6个月；
- 超过6个月未缴费（含滞纳金），**专利权终止**（第44条）。

### 滞纳金计算示例
假设某发明专利第5年年费1200元，缴费日为3月15日：
| 缴费时间 | 滞纳金 | 应缴总额 |
|---------|--------|---------|
| 3月15日前 | 0 | 1200 |
| 4月（超1个月） | 60（5%） | 1260 |
| 5月（超2个月） | 120（10%） | 1320 |
| … | … | … |
| 9月（超6个月） | 360（30%） | 1560（最后期限） |
| 9月后未缴 | — | **专利权终止** |

### 3. 年费维持成本预估（发明专利，个人减缴85%）
| 年度区间 | 年费/年 | 小计 |
|---------|--------|------|
| 第1-10年（减缴） | 135-600 | 约3075元（10年合计） |
| 第11-20年（不减缴） | 4000-8000 | 约48000元（10年合计） |
| **20年合计** | — | **约51075元** |

> 💡 **决策提示**：发明专利后期年费较高（第11年起4000-8000元/年），是否维持需结合专利的商业价值。许多专利在第7-10年因技术过时或商业价值下降而被放弃。

## 七、专利申请全流程时间线

### 发明专利时间线
```
申请日（Day 0）
  │
  ├─ +1个月：缴纳申请费（申请日起2个月内）
  │
  ├─ +18个月：申请公布（第34条，可申请提前公布）
  │
  ├─ +3年内：提出实质审查请求（第35条，逾期视为撤回）
  │           缴纳实质审查费
  │
  ├─ 实质审查阶段（约1-2年）：
  │    一通 → 答复（4个月）→ 二通 → 答复（2个月）→ ...
  │
  ├─ 授权通知 → +2个月内缴纳登记费 → 发证（第39条）
  │   （整个流程约2-3年）
  │
  └─ 授权当年起：每年缴纳年费（第43条）
```

### 实用新型/外观设计时间线
```
申请日（Day 0）
  │
  ├─ +2个月内：缴纳申请费
  │
  ├─ 初步审查（形式审查）
  │
  ├─ 授权通知 → +2个月内缴纳登记费 → 发证（第40条）
  │   （实用新型约6-8个月，外观设计约4-6个月）
  │
  └─ 授权当年起：每年缴纳年费（第43条）
```

## 八、关键法定期限汇总（务必牢记）

| 事项 | 期限 | 逾期后果 | 法律依据 |
|------|------|---------|---------|
| 缴纳申请费 | 申请日起2个月内 | 视为撤回 | 实施细则 |
| 提出实质审查请求（发明） | 申请日起3年内 | 视为撤回 | 第35条 |
| 审查意见答复（一通） | 收到通知4个月（可延2月） | 视为撤回 | 第37条 |
| 审查意见答复（后续） | 收到通知2个月 | 视为撤回 | 第37条 |
| 缴纳授权登记费 | 收到授权通知2个月内 | 视为放弃 | 第39条 |
| 驳回复审请求 | 收到驳回决定3个月 | 丧失复审权 | 第41条 |
| 年费缴纳 | 每年申请日对应日 | 滞纳金，超6个月终止 | 第43、44条 |
| 无效宣告请求 | 授权公告后任意时间 | — | 第45条 |
| 侵权诉讼时效 | 知道侵权起3年 | 丧失胜诉权 | 第74条 |

> ⚠️ **期限预警**：所有法定期限逾期后果严重（多为"视为撤回"不可恢复），建议建立期限台账，提前1个月预警。因不可抗拒事由延误可申请恢复（第29条实施细则），但条件严格。

## 九、费用总览（发明专利，个人减缴85%）

| 阶段 | 费用项目 | 金额 |
|------|---------|------|
| 申请 | 申请费+公布印刷费 | 185元（135+50） |
| 审查 | 实质审查费 | 375元 |
| 登记 | 登记费+印花税 | 约200元+5元 |
| 维持 | 第1-10年年费（减缴） | 约3075元 |
| **前10年合计** | — | **约3840元** |

> 💡 以上为官费，不含代理服务费。委托代理机构办理还需支付代理服务费（市场价数千至数万元不等，视复杂程度）。

## 十、缴费方式

- **网上缴费**：专利业务办理系统（cponline.cnipa.gov.cn）电子申请，推荐；
- **银行汇款**：汇至国家知识产权局指定账户，须注明申请号/专利号；
- **窗口缴费**：国家知识产权局及各地代办处窗口；
- **邮局汇款**：传统方式。

> 📌 办理专利费用减缴须先完成"费减备案"（个人/单位分别提交证明材料），审核通过后缴费时自动适用减缴比例。
