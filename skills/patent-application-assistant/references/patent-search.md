# 专利检索方法与策略

> 📌 本文档指导如何开展专利申请前检索，评估新颖性与创造性，涵盖检索渠道、检索式构建、分类号运用、对比文件分析方法。
> 法律依据：《专利法》第22条（新颖性、创造性、实用性）、第22条第2款（新颖性定义）、第22条第3款（创造性定义）。

## 一、为什么需要专利检索

专利检索的核心目的：
1. **评估新颖性**（第22条第2款）：是否存在申请日前已公开的相同技术；
2. **评估创造性**（第22条第3款）：相对于现有技术是否具备"突出的实质性特点和显著的进步"；
3. **优化申请文件**：了解现有技术边界，精准界定保护范围，提高授权率；
4. **避免重复研发**：了解行业技术现状，避免侵权与重复投入；
5. **FTO（自由实施）分析**：上市/出海前排查侵权风险。

## 三、检索式构建方法

### 1. 关键词检索
提取技术方案的核心关键词，构建检索式：

**关键词提取维度**：
| 维度 | 示例（以"无线充电装置"为例） |
|------|---------------------------|
| 技术主题 | 无线充电、无线电能传输、感应充电 |
| 技术手段 | 电磁感应、磁共振、线圈、谐振 |
| 技术效果 | 高效率、低损耗、快速充电 |
| 应用对象 | 手机、电动汽车、可穿戴设备 |

**关键词扩展技巧**：
- **同义词/近义词**：无线充电 = 无接触充电 = 非接触式供电；
- **中英文对照**：无线充电 = wireless charging = wireless power transfer；
- **上下位概念**：无线充电（下位）← 电能传输（上位）；
- **缩写与全称**：WPT = Wireless Power Transfer。

**逻辑运算符**：
- `AND`（与）：两个关键词同时出现，如"无线 AND 充电"；
- `OR`（或）：任一关键词出现，如"无线 OR 无接触"；
- `NOT`（非）：排除某关键词，如"充电 NOT 有线"；
- `()`：组合优先级。

### 2. 分类号检索
专利按技术领域分配分类号，是提高检索精准度的关键。

| 分类号体系 | 说明 | 示例 |
|----------|------|------|
| IPC（国际专利分类） | 国际通用，按部-大类-小类-大组-小组层级 | H02J 50/00（无线供电） |
| CPC（联合专利分类） | 欧美主导，比IPC更细化 | H02J 50/10（电磁感应式） |
| FI/F-term | 日本分类 | — |
| LOC（洛迦诺） | 外观设计分类 | 14-02（通信设备外观） |

**IPC分类号结构解读**（以 H02J 50/80 为例）：
- H：电学（部）
- H02：发电、变电或配电（大类）
- H02J：供电或配电的电路装置或系统（小类）
- 50/00：无线供电（大组）
- 50/80：通用电路装置细节（小组）

### 3. 组合检索（推荐）
**关键词 + 分类号组合**是最有效的检索策略：
```
检索式示例：(无线 OR 无接触) AND (充电 OR 供电) AND IPC=(H02J50)
```

### 4. 引证追踪法
- **向前引证**：某专利被后续专利引用（说明是基础技术）；
- **向后引证**：某专利引用的在先专利（寻找更早的现有技术）；
- 适用于发现关键基础专利和扩展检索范围。

## 四、新颖性评估（第22条第2款）

### 新颖性定义
新颖性指该发明或实用新型不属于现有技术，也没有任何单位或个人就同样的发明或实用新型在申请日以前向国务院专利行政部门提出过申请，并记载在申请日以后公布的专利申请文件或公告的专利文件中。

### 新颖性判断步骤
1. **确定对比文件**：检索到的申请日前的公开技术（专利、论文、产品等）；
2. **技术方案对比**：逐技术特征比对；
3. **判断结论**：
   - ✅ **具备新颖性**：检索到的对比文件未公开全部技术特征；
   - ❌ **不具备新颖性**：存在对比文件公开了相同技术方案（"同样的发明"）。

### 新颖性判断示例
| 权利要求技术特征 | 对比文件D1 | 结论 |
|----------------|-----------|------|
| 特征a：无线充电线圈 | ✅已公开 | — |
| 特征b：温度检测电路 | ❌未公开 | D1未公开全部特征 |
| 特征c：智能功率调节 | ❌未公开 | 相对于D1具备新颖性 |

> 💡 **抵触申请**（第22条第2款）：他人申请日在前、公布日在后的专利申请，可用来评价新颖性（但不能评价创造性）。

## 五、创造性评估（第22条第3款）

### 创造性定义
创造性指与现有技术相比，该发明具有**突出的实质性特点和显著的进步**，该实用新型具有实质性特点和进步。

### 创造性判断"三步法"（核心）
```
步骤1：确定最接近的现有技术（对比文件D1）
            │
            ▼
步骤2：确定发明的区别特征→归纳实际解决的技术问题
            │
            ▼
步骤3：判断要求保护的发明对本领域技术人员是否显而易见
       （是否有结合启示：D1+D2或其他公知常识）
            │
      ┌─────┴─────┐
   非显而易见      显而易见
   ✅有创造性     ❌无创造性
```

### 三步法应用示例
1. **最接近现有技术**：D1公开了无线充电线圈（特征a），未公开温度检测和功率调节；
2. **区别特征**：特征b（温度检测）、特征c（功率调节）；
3. **实际解决的技术问题**：如何防止无线充电过热；
4. **结合启示判断**：
   - 若D2公开了温度检测+功率调节用于有线充电，本领域技术人员有动机结合 → ❌无创造性；
   - 若无任何文件给出结合启示，且效果出乎意料 → ✅有创造性。

### 创造性抗辩常见理由
- 区别特征并非本领域常规技术手段；
- 现有技术无结合动机（解决不同技术问题）；
- 取得了预料不到的技术效果；
- 克服了技术偏见。

## 七、检索常见陷阱

| 陷阱 | 后果 | 规避方法 |
|------|------|---------|
| 仅用中文关键词 | 漏检海外对比文件 | 中英文双语检索 |
| 忽略分类号 | 命中率低、噪音大 | 关键词+IPC/CPC组合 |
| 只检索专利库 | 漏检非专利现有技术（论文/产品） | 补充万方、CNKI、网络公开 |
| 忽略同族专利 | 漏检国外对应技术 | 检索专利族（INPADOC） |
| 盲期未考虑 | 检索不到近2-3个月申请 | 知晓盲期局限，结果仅供参考 |

## 八、FTO（自由实施）分析要点

FTO分析用于评估实施某技术是否会侵犯他人有效专利：
1. **检索有效专利**：关注目标市场（中国/美国/欧洲等）的有效专利；
2. **权利要求比对**：用全面覆盖原则判断是否落入他人权利要求范围；
3. **专利有效性评估**：若疑似侵权，可评估对方专利是否可被无效；
4. **规避设计**：调整技术方案以避开他人专利。

> ⚠️ FTO分析是上市、出海、融资前的重要风险排查手段，建议由专业代理师/律师出具正式意见。
