# 审查意见答复策略与模板

> 📌 本文档系统讲解发明专利实质审查意见通知书的答复方法，涵盖新颖性、创造性、充分公开等常见缺陷的答复策略与模板，以及修改原则、驳回复审程序。
> 法律依据：《专利法》第22条（三性）、第26条第3款（充分公开）、第33条（修改）、第37条（答复）、第41条（复审）。

## 一、审查意见通知书概述

发明专利申请经实质审查后，审查员若认为不符合授权条件，会发出**审查意见通知书**，指出缺陷并给出倾向性意见（授权/驳回）。

| 审查意见类型 | 含义 | 应对 |
|------------|------|------|
| 第一次审查意见（一通） | 首次指出缺陷 | 答复期限4个月（可延长2个月） |
| 第二次审查意见（二通） | 一通答复后仍有缺陷 | 答复期限2个月 |
| 第三次及以后（三通+） | 多轮仍未克服缺陷 | 驳回风险高，需慎重 |

> ⚠️ **答复期限极其重要**：一通4个月、后续2个月，逾期未答复视为撤回（第35条）！可申请延长，但须在期满前办理。

## 二、常见审查意见类型与答复策略

### 1. 新颖性缺陷（第22条第2款）

**审查意见**：权利要求的技术方案已被对比文件D1完全公开，不具备新颖性。

**答复策略**：逐技术特征对比，找出区别特征。

#### 答复模板
```
关于权利要求1的新颖性：

审查员引用对比文件D1（公开日：___）评价权利要求1的新颖性。
申请人认为，权利要求1相对于D1具备新颖性，理由如下：

权利要求1包含以下技术特征：特征a、特征b、特征c。
经对比：
- 特征a（无线充电线圈）：D1说明书第X段已公开，认可；
- 特征b（温度检测电路）：D1未公开。D1仅公开了电压检测，
  并未公开温度检测的技术手段，二者技术特征不同；
- 特征c（智能功率调节）：D1未公开。

由于D1未公开权利要求1的全部技术特征（特别是特征b、c），
权利要求1相对于D1具备新颖性，符合《专利法》第22条第2款。
```

#### 新颖性答复要点
- 必须逐特征对比，不要笼统辩解；
- 重点论证对比文件**未公开**的特征；
- 注意"抵触申请"（申请日在前、公布日在后的专利申请）的特殊性。

### 2. 创造性缺陷（第22条第3款，最常见）

**审查意见**：权利要求相对于D1+D2（公知常识）显而易见，不具备创造性。

**答复策略**：运用"三步法"反推，论证非显而易见性。

#### 答复模板（三步法反驳）
```
关于权利要求1的创造性：

审查员引用D1作为最接近现有技术，结合D2（或公知常识）认定
权利要求1显而易见。申请人认为权利要求1具备创造性，理由如下：

【步骤1：最接近现有技术】
认可D1为本申请最接近的现有技术。

【步骤2：实际解决的技术问题】
权利要求1与D1的区别特征为：特征b（温度检测）和特征c（功率调节）。
基于上述区别特征，本发明实际解决的技术问题是：
如何在无线充电中实现过热保护。

【步骤3：非显而易见性论证】
审查员认为D2公开了特征b、c，本领域技术人员有动机结合D1和D2。
申请人对此有不同意见：
(1) D2公开的温度检测用于有线充电的短路保护（技术场景不同），
    D2并未给出将其用于无线充电过热保护的技术启示；
(2) D2与D1的工作原理不同，本领域技术人员无合理动机将二者结合；
(3) 本发明取得了预料不到的技术效果：充电效率提升30%的同时
    温度降低15℃，这是D1、D2简单结合无法预期的。

因此，权利要求1对本领域技术人员而言并非显而易见，
具备《专利法》第22条第3款规定的创造性。
```

#### 创造性答复常见成功理由
| 理由类型 | 论证要点 |
|---------|---------|
| 无结合动机 | D1、D2解决不同技术问题，无结合启示 |
| 区别特征非公知 | 区别特征非本领域常规手段 |
| 克服技术偏见 | 突破了本领域固有认知 |
| 预料不到效果 | 取得了超出预期的技术效果（需数据） |
| 商业成功 | 因技术优势取得商业成功（辅助证据） |

### 3. 充分公开缺陷（第26条第3款）

**审查意见**：说明书未充分公开，本领域技术人员无法实现。

**答复策略**：补充说明，论证已充分公开；或提交补充数据。

#### 答复模板
```
关于充分公开（第26条第3款）：

审查员认为说明书未公开___的具体参数，导致无法实现。
申请人认为说明书已充分公开，理由如下：

(1) 说明书第X段已公开了___的完整技术方案，包括___；
(2) ___属于本领域公知技术，本领域技术人员根据说明书
    公开的内容结合公知常识能够实现，无需重复记载；
(3) 补充提交实验数据（见附件），证明按说明书方法能够实现
    且达到预期效果。

因此，说明书符合《专利法》第26条第3款的充分公开要求。
```

> ⚠️ **注意**：答复充分公开缺陷时，补充的实验数据通常应为申请日前的数据，或属于本领域技术人员可合理预期（2020年新增药品专利纠纷早期解决机制相关数据补充规则）。

### 4. 权利要求不支持（第26条第4款）

**审查意见**：权利要求保护范围过宽，未得到说明书支持。

**答复策略**：增加限定特征，缩小至说明书支持的范围。

#### 答复模板
```
关于权利要求1未得到说明书支持（第26条第4款）：

审查员认为权利要求1的"金属"范围过宽，说明书仅公开了铜的实施例。
申请人同意审查员意见，现修改权利要求1如下：
将"金属"修改为"铜或铝"（说明书实施例1-3已公开铜、铝的实施例），
使权利要求得到说明书支持。

修改后的权利要求1：……（具体内容）
此修改未超出原说明书和权利要求书记载的范围，符合《专利法》第33条。
```

### 5. 修改超范围（第33条）

**审查意见**：权利要求/说明书的修改超出了原说明书和权利要求书记载的范围。

**答复策略**：撤回超范围修改，回归原始记载。

#### 答复要点
- 修改只能基于原说明书和权利要求书记载的内容；
- "记载的范围"包括明确记载和本领域技术人员能直接、毫无疑义确定的内容；
- 若审查意见正确，应主动撤回超范围修改内容。

## 三、修改申请文件的原则

依据《专利法》第33条：
- **修改不得超出原说明书和权利要求书记载的范围**；
- 答复审查意见时可对申请文件进行修改，但须符合修改方式要求：
  - **权利要求修改**：删除、合并、进一步限定（不能增加新内容）；
  - **说明书修改**：限于澄清、订正明显错误，不能增加实质内容。

## 四、答复信标准结构

```markdown
意见陈述书

申请号：___
发明名称：___
代理人：___

审查员于___年___月___日发出的第___次审查意见通知书收悉。
申请人经认真研究，现陈述意见如下：

一、关于新颖性（第22条第2款）
（逐特征对比论证）

二、关于创造性（第22条第3款）
（三步法论证）

三、关于修改
（说明修改内容，声明符合第33条）

综上，申请人认为修改后的申请文件符合《专利法》及其实施细则
的有关规定，请求授予专利权。

此致
国家知识产权局

申请人：___（签章）
日期：___
```

## 五、驳回复审程序（第41条）

若审查员维持驳回意见，发出**驳回决定**：

| 程序 | 内容 | 时限 |
|------|------|------|
| 收到驳回决定 | — | — |
| 提出复审请求 | 向专利复审委员会（现专利局复审和无效审理部） | **收到驳回决定3个月内** |
| 复审审查 | 前置审查+合议审查 | — |
| 复审决定 | 撤销驳回/维持驳回 | — |
| 起诉（可选） | 对维持驳回的复审决定，向北京知识产权法院起诉 | 收到复审决定3个月内 |

### 复审请求要点
1. **时限**：收到驳回决定3个月内（逾期不可恢复，除非有正当理由）；
2. **复审费**：发明1000元，实用新型/外观设计300元（符合条件可减缴）；
3. **复审理由**：针对驳回决定逐条反驳，可修改申请文件；
4. **复审成功率**：约30-40%的复审请求能撤销驳回。

## 六、答复策略总原则

| 原则 | 说明 |
|------|------|
| 逐条回应 | 对审查意见每一点都明确表态（认可/不认可） |
| 有理有据 | 用技术事实、对比文件原文、数据论证，避免空泛辩解 |
| 适时修改 | 该退让时主动修改权利要求，争取授权 |
| 留有余地 | 从属权利要求作为退路，避免独权修改过度 |
| 遵守期限 | 严格在答复期限内提交，可申请延长 |

## 七、实用新型/外观设计的审查特点

- **无实质审查**，仅形式审查+明显缺陷审查，授权快；
- **授权后风险**：易被无效，维权前通常需出具**专利权评价报告**（请求费2400元）；
- 评价报告为负面（"不符合授予专利权条件"）则维权困难，需谨慎。

## 八、答复常见错误

| 错误 | 后果 | 纠正 |
|------|------|------|
| 笼统辩解"本发明有创造性" | 无法说服审查员 | 用三步法逐点论证 |
| 拒绝任何修改 | 容易被驳回 | 必要时主动修改退让 |
| 忽视答复期限 | 视为撤回 | 设提醒，可申请延长 |
| 修改超范围 | 违反第33条 | 严格基于原始记载 |
| 未充分分析对比文件 | 反驳无力 | 精读对比文件，找区别 |
