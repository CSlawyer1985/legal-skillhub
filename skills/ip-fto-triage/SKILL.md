# 专利侵权风险初步排查（FTO Triage）

**本技能不构成自由实施法律意见。** 正式的FTO意见需要由具备专利代理资质的律师进行全面检索、完整的权利要求解释和逐要素侵权分析。专利侵权为严格责任；故意侵权可适用惩罚性赔偿（《专利法》第71条，最高五倍）。本技能得出"未发现明显障碍专利"仅表示排查未发现——不代表产品可以自由实施。

## 操作指引

1. 读取业务配置文件（如 `legal_practice.config`）。若包含 `[PLACEHOLDER]`，停止并引导用户完成初始配置。
2. 按以下流程执行。
3. 执行信息采集（产品/工艺、技术细节、地域、已知专利、时间节点）。
4. 若有专利检索工具可用，执行初步专利检索。否则在输出中说明，并基于用户提供的专利继续分析。
5. 对2–5件最相关的专利，逐独立权利要求构建权利要求对照表——逐要素分析。先做相同侵权判定；等同侵权单独标注；帮助侵权/教唆侵权单独标注。
6. 列出正式FTO研究需要解决的开放性问题（权利稳定性、审查历史、无效宣告结果、许可可能性、专利权人维权记录）。
7. 将排查备忘录写入指定输出路径，添加工作成果页眉。
8. 以建议后续步骤、故意侵权提示（知悉特定专利后继续推进可能构成故意侵权因素）和非律师门禁收尾。

本技能绝不得出"产品不侵权"的结论。不确定时标注——由专利律师决定。

## 使用示例

```
用户：我们的智能手表语音识别模块要在中国上市，帮我看看有没有侵权风险
```

```
用户：我们开发了一种新的电池快充方案，准备在国内生产和销售
```

## 重要声明

**本技能中最强的安全护栏。在每次输出的顶部展示。不得省略。不得弱化。不得让读者略过。**

> **本排查不构成自由实施法律意见。** 正式的FTO意见是由具备资质的专利代理师或律师，基于全面检索、完整权利要求解释和逐要素侵权分析作出的专业法律判断。本排查是对可能存在的障碍专利的结构化初筛。"未发现明显障碍专利"仅表示排查未发现——不代表产品可以自由实施。专利侵权为严格责任；故意侵权（知悉专利后仍继续实施）可根据《专利法》第71条适用惩罚性赔偿，最高可达五倍。是否制造、使用、许诺销售、销售或进口，是由正式FTO研究和律师判断指导的商业决策——而非本排查。产品决策前应由具备资质的专利代理师或律师进行评估。[模型知识 — 需核验]

低估障碍专利是不可逆的——产品一旦上市，可能面临诉讼和高额赔偿。高估是可逆的——律师在审阅时缩小范围。始终站在高估一侧。

### 关于故意侵权

阅读本排查即接触了专利相关信息。在某些情况下，接触专利信息可能成为后续故意侵权分析的考量因素。这是本输出在律师使用时标注为保密的原因之一，也是非律师输出被定位为"提交给律师的研究材料"的原因。不要在保密渠道之外讨论本排查中发现的具体专利。

## 信息采集

一次性提问：

> 我将运行专利侵权风险排查。先确认几个问题：
>
> 1. **产品、工艺或功能。** 将要制造、使用、许诺销售、销售或进口的是什么？用技术语言描述——技术实质，不是营销话术。
> 2. **技术细节。** 有无架构图、与权利要求相关的规格说明、公开产品页面或规格文档？（细节越充分，排查越真实。）
> 3. **地域。** 将在哪些地域制造、使用、销售、许诺销售、进口？（每项是《专利法》第11条下独立的侵权行为。未指定则默认中国。）
> 4. **已知专利。** 是否已有专利在关注——竞争对手专利组合、已知标准必要专利池、NPE函件、工程师提到的专利？
> 5. **时间节点。** 距离上市多近？若尚有数月，排查是早期阶段，规避设计仍有空间。若已发货，进入风险控制模式。

等待回答。若描述模糊（"一个AI智能体"、"一个数据库"），追问一次：

> 请提供技术实质——这个产品做什么、怎么做、以及你认为可能新颖的部分。专利权利要求在这个粒度上运作。

## 范围——发明专利与实用新型

**本技能分析发明专利和实用新型。** 若已知的专利是外观设计，标注并转出，不做权利要求对照：

- **外观设计专利。** 判定标准不同——以一般消费者为视角、整体观察综合判断（最高人民法院关于审理侵犯专利权纠纷案件应用法律若干问题的解释），整体外观设计对比，无权利要求对照表。转出至外观设计侵权排查专业流程和外观设计专利律师。**外观设计专利不在本FTO排查范围内**——外观设计重叠应标注为单独工作流。
- **实用新型。** 纳入排查范围，但注意：实用新型保护客体限于产品的形状、构造或其结合（排除方法），且在侵权诉讼中法院可能要求提供专利权评价报告（《专利法》第66条第2款）。在权利要求对照表中标注实用新型身份及评价报告需求。

同时交叉标注**外观设计/包装装潢**：若产品外观是风险点，同一事实可能构成《反不正当竞争法》第7条的混淆行为主张，需要商品形状具有一定影响和非功能性。标注为并行工作流。

## 检索

### 可用工具

读取业务配置中的集成工具：

- **专利检索工具可用：** 基于技术描述运行初步检索。记录检索日期、查询词、覆盖地域和日期窗口（当前有效专利；近期公开申请）。
- **无上述工具：** 明确说明。不得从模型知识推断专利并作为检索结果呈现。

### 无专利数据库时的回退

在输出中写入以下声明：

> **未执行专利数据库检索。** 本排查未使用CNIPA专利检索及分析系统、中国及多国专利审查信息查询、智慧芽或任何其他专利数据库。在依赖本排查做出任何上市决策前，需要在排查范围内进行结构化检索。以下分析限于用户提及或在对话中出现的专利和申请。

然后继续。权利要求对照初筛工作仍有价值——只需如实标注范围。

### 补充信号（非替代）

若可用且用户允许，扫取非专利信号：

- **竞争对手专利申请**——产品领域附近的公开
- **已知NPE/职业专利权人**在该技术领域的维权记录
- **标准必要专利声明**（3GPP、ITU、CCSA等）——若产品涉及相关标准

每个信号是进一步查找的理由，不是专利命中。在输出中标注为信号，不是已识别专利。

## 对每件已发现或已提供的专利

记录：

- **专利号**（申请号若不同）和**地域**
- **名称**
- **专利权人和发明人**
- **申请日和授权公告日**
- **届满日**（依据CNIPA信息——注意发明专利20年/实用新型10年，自申请日起算，检查是否享有优先权）
- **年费缴纳状态**——中国专利未缴年费且超过6个月滞纳期即失效，不再构成障碍 [模型知识 — 需核验]
- **权利要求数——独立权利要求和从属权利要求**
- **授权公告的独立权利要求**（及无效宣告程序中修改的权利要求）
- **相关程序**——无效宣告请求、复审决定、诉讼历史、行政裁决结果
- **审查档案要点**——审查过程中的限缩性修改、关于保护范围的陈述

**不得静默补充。** 若检索发现专利，标注来源。若用户提及专利，说明。绝不编造专利号，绝不"填充"文件不支持的权利要求要素，绝不臆测届满日。若年费状态无法获取，写"年费缴纳状态未经检索验证——依赖有效状态前请在CNIPA确认"。

## 权利要求对照初筛

这是排查的核心。选取与产品最可能匹配的专利——通常2–5件技术映射最接近的——逐独立权利要求逐要素分析。

**对每件选定的专利，每个独立权利要求写一份对照表：**

| 权利要求要素 | 产品是否实施？ | 依据 |
|---|---|---|
| "[前序部分]" | [是 / 否 / 可能 / 取决于解释] | [一句话——产品中什么对应；什么不对应；什么存疑] |
| "包含[要素1]" | [是 / 否 / 可能] | [映射或差距] |
| "其中[要素2]" | [是 / 否 / 可能] | [映射或差距] |
| [继续每个要素] | | |

**对照表规则：**

- **每个要素都必须分析。** 根据《专利法》及全面覆盖原则，被诉侵权产品需实施至少一项权利要求的全部要素方构成侵权（全面覆盖原则）。缺少一个要素即不构成相同侵权。不得跳过。
- **等同侵权是单独一步。** 先做相同侵权对照。然后对任何"否"的要素，标注等同侵权的可能性（以基本相同的手段、实现基本相同的功能、达到基本相同的效果，且本领域普通技术人员无需创造性劳动即可联想到）。将等同侵权分析标注为需要律师判断——审查档案禁反言和权利要求实质性缩限是常见障碍，本排查不作裁定。详见 [references/cn-patent-law-reference.md](references/cn-patent-law-reference.md)。
- **权利要求解释是律师的工作。** 若某个术语可被窄义或广义解释且解释不同会影响侵权判定，标注该术语并注明两种解释。不得静默选择一种。
- **帮助侵权和教唆侵权仅标注。** 不做完整分析；标注这些可能适用并需要专利律师进一步分析（参见最高人民法院关于审理侵犯专利权纠纷案件应用法律若干问题的解释(二)第21条）。
- **多主体实施仅标注。** 若侵权判定取决于多个主体共同实施权利要求，标注多主体实施问题并注明需要律师进一步分析。

> **不同法域的专利制度存在差异。** 中国的权利要求对照框架（全面覆盖原则、等同原则、审查档案禁反言、《专利法》第71条赔偿）与其他体系不同：
> - **美国：** 全要素规则、等同原则、审查历史禁反言、§284/§289赔偿。
> - **欧洲（统一专利法院）：** UPC程序（2023年起）。
> - **日本：** 等同原则适用范围较窄。
>
> 若涉及中国以外地域："本分析使用中国专利侵权判定框架。在美国制造和销售的产品需要美国法分析，不是中国权利要求对照表。我可以标注中国分析发现的问题，但侵权和有效性的判断需要对应法域的专业审查。"

**决策姿态：** 依据业务配置，本技能绝不得出"不侵权"结论。只能是：

- "产品实施了权利要求X的全部要素；需律师复核后方可继续推进。"
- "一个或多个要素未明确存在；需律师复核以评估相同侵权和等同侵权。"
- "权利要求解释对要素[Y]具有决定性影响；需律师解释后方可继续推进。"

## 开放性问题

排查中发现的每件专利都应产生正式FTO研究需要回答的问题列表。例如：

- 专利是否有效——专利权人是否正确登记、有无主体资格问题、有无发明人资格缺陷？
- 申请人在审查中关于术语[X]说了什么，是否限制了权利要求范围？
- 该权利要求是否经过无效宣告程序——专利复审和无效审理部对范围或有效性作出了什么认定？
- 是否已有许可（标准池、专利标记、开放专利不主张承诺）？
- 该专利权人的实际维权历史如何？

直接列出。

## 建议后续步骤

按排查结果分桶：

- **若独立权利要求的全部要素均映射到产品（相同侵权）：** *停止并咨询专利律师。* 选项通常包括正式FTO意见、规避设计、获取许可、挑战有效性（无效宣告请求），或（罕见）风险下推进。选择是由律师意见指导的商业决策。
- **若要素映射各有方向或权利要求解释具有决定性：** 由具备资质的专利律师完成正式FTO研究。不得仅依据本排查做出上市决策。
- **若专利似已过期、放弃或不可执行：** 律师确认有效状态——本排查不确认。
- **若检索未发现专利但无法访问数据库：** 正式检索是下一步，不是上市决策。
- **始终：** 标注故意侵权风险。若排查发现特定专利，公司已知悉该专利。未经进一步分析即继续推进可能支持故意侵权认定。律师应记录后续路径。
