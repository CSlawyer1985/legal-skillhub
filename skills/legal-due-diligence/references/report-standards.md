# 尽职调查报告写作规范

> 本文件在 report 模式下加载，指导从底稿到报告的转化。

---

## 一、报告总体结构

```
法律尽职调查报告

一、声明与限定条件
二、目标公司基本信息与主体资格
三、股权结构与股东信息
四、公司治理与组织结构
五、核心资产
六、业务经营与合同管理
七、财务与税务
八、劳动人事管理
九、重大债权债务与担保
十、诉讼、仲裁与行政处罚
十一、其他重要文件
十二、结论与建议
附件：文件清单
```

---

## 二、封面格式

```
                [律师事务所名称]

              关于[目标公司全称]的
              法 律 尽 职 调 查 报 告

              委托人：[委托人名称]
              报告日期：[年] 年 [月] 月 [日] 日
```

## 三、声明与限定条件（标准模板）

以下为标准声明模板，根据项目实际情况调整：

```markdown
## 一、声明与限定条件

### （一）报告出具主体

本报告由[律师事务所全称]（以下简称"本所"）出具。本所接受[委托人全称]
（以下简称"委托人"）的委托，就委托人拟[交易目的，如"收购[目标公司全称]
（以下简称'目标公司'）[X]%股权"]事宜，对目标公司进行法律尽职调查，
并出具本法律尽职调查报告（以下简称"本报告"）。

### （二）调查范围

本次法律尽职调查的范围包括但不限于：目标公司的主体资格、股权结构、
公司治理、核心资产、业务经营、财务税务、劳动人事、债权债务与担保、
诉讼仲裁与行政处罚等方面的法律事项。

本次法律尽职调查的基准日为[日期]（以下简称"基准日"）。
除特别注明外，本报告所述的事实和发表的意见均以基准日的状态为准。

### （三）调查方法

本所律师在本次尽职调查过程中采取了以下调查方法：
1. 审阅目标公司及其股东提供的文件资料；
2. 查询国家企业信用信息公示系统、中国裁判文书网、中国执行信息公开网、
   信用中国等公开信息平台；
3. 对目标公司管理层进行访谈（如有）；
4. 其他本所律师认为必要的调查方法。

### （四）限制条件与免责声明

1. 本报告系根据委托人及目标公司提供的文件资料作出。本所律师已对上述
   文件资料进行了形式审查，但未对其真实性、准确性和完整性进行独立的
   实质性验证。如上述文件资料存在虚假、遗漏或误导，可能影响本报告的
   结论。

2. 本报告仅就法律事项发表意见，不涉及财务、税务、评估等专业事项的
   判断。涉及财务数据的引用系来源于目标公司提供的财务资料，本所律师
   不对其准确性承担责任。

3. [如有未获取材料：]由于下列文件资料未能获取，本所律师无法就相关事项
   发表完整意见：
   - [列明未获取的重要材料]

4. 本报告仅供委托人用于[目的]之用途，未经本所书面同意，不得向第三方
   披露或用于其他目的。

5. 本报告中的法律意见系基于中国现行有效的法律、法规、规章及规范性文件
   作出。如前述法律法规发生变化，可能影响本报告的结论。

### （五）经办律师

本次法律尽职调查由本所[律师姓名]律师负责。
```

## 四、各章节报告格式

每章的报告格式为三段式结构：

```markdown
## [编号]. [章节名称]

### （一）调查范围
简述本章调查的范围和采用的方法。1-2段即可。

### （二）基本情况 / 调查结果
客观陈述调查发现。这是报告的主体内容。
- 使用事实性陈述
- 引用具体数据和文件
- 以表格形式呈现结构化信息
- 不作评价性判断

### （三）律师意见
基于调查结果的法律分析和意见。
- 确认合规/不合规的事项
- 提示风险事项
- 提出具体建议
```

## 五、结论与建议（标准模板）

```markdown
## 十二、结论与建议

### （一）主要结论

基于本次法律尽职调查的结果，本所律师的主要结论如下：

1. **主体资格**：目标公司系依法设立并有效存续的[公司类型]，
   具备从事其主营业务的合法主体资格。[如有问题补充]

2. **股权结构**：目标公司的股权结构清晰/存在[问题]，
   各股东的出资[已/未]足额缴纳。

3. **公司治理**：目标公司的公司治理结构[健全/有待完善]。

4. **核心资产**：目标公司的主要资产权属[清晰/存在瑕疵]。

5. **业务经营**：目标公司[具备/缺少]从事主营业务所需的资质许可。

6. **财务税务**：[简述财税合规情况]。

7. **劳动人事**：[简述劳动用工合规情况]。

8. **债权债务**：目标公司的负债总额为人民币[金额]万元，
   [不存在/存在]对外担保。

9. **诉讼仲裁**：截至基准日，目标公司[不存在/存在]未决诉讼/仲裁。

10. **其他事项**：[如有]。

### （二）重大风险提示

本所律师特别提请委托人关注以下重大风险事项：

[从各章节风险提示中汇总高风险事项，按重要性排序]

1. [风险事项1]：[简述风险及建议]
2. [风险事项2]：[简述风险及建议]
...

### （三）建议

基于上述调查结果和风险评估，本所律师提出以下建议：

1. **交易前置条件建议**：建议将下列事项作为交易的前置条件：
   [列明需在交割前解决的重大问题]

2. **交易文件建议**：建议在交易文件中约定以下条款：
   [列明需要在合同中设置的保护条款，如陈述与保证、赔偿条款等]

3. **交割后事项**：建议在交割后关注并推动解决以下事项：
   [列明交割后需要整改的问题]
```

## 六、语言规范

### 6.1 人称与主语

| 正确 | 错误 |
|------|------|
| 本所律师 | 我们、我 |
| 目标公司 | 该公司、他们 |
| 委托人 | 客户、甲方 |
| 本报告 | 这份报告 |

### 6.2 调查行为的表述

| 正确 | 错误 |
|------|------|
| 经本所律师查验 | 经查阅 |
| 根据目标公司提供的…… | 根据提供的…… |
| 经查询[平台名称] | 经网上查询 |
| 经本所律师审阅 | 看了一下 |

### 6.3 确认性表述

| 正确 | 错误 |
|------|------|
| 截至本报告基准日 | 目前 |
| 根据目标公司提供的资料及声明 | 据了解 |
| 本所律师未发现…… | 没有…… |
| 上述情况符合……的规定 | 合法合规 |

### 6.4 风险提示表述

| 场景 | 标准表述 |
|------|---------|
| 高风险 | 本所律师**特别提请**委托人关注：…… |
| 中风险 | 本所律师**提示**委托人注意：…… |
| 低风险 | 本所律师**建议**委托人关注：…… |
| 无法核实 | 因未获取[材料]，本所律师**无法就此事项发表意见** |
| 存在瑕疵但可整改 | 上述瑕疵**不构成实质性法律障碍**，建议目标公司于[期限]前完成整改 |
| 可能影响交易 | 上述事项**可能对本次交易产生不利影响**，建议委托人…… |

### 6.5 限定性表述

在下列情况下必须使用限定性表述：

1. **材料不完整时**：
   > 基于目标公司截至[日期]提供的有限资料，本所律师初步认为……

2. **涉及事实判断时**：
   > 根据目标公司的陈述及提供的[文件名称]，……

3. **涉及未来预测时**：
   > 上述税收优惠政策能否持续适用，存在不确定性。

4. **公开查询有局限时**：
   > 经查询[系统名称]（查询日期：[日期]），未发现目标公司存在[事项]的记录。因公开查询系统的信息可能存在延迟或遗漏，上述查询结果仅供参考。

### 6.6 禁止使用的表述

| 禁止 | 原因 |
|------|------|
| 保证、确保 | 律师不对事实作保证 |
| 绝对、肯定、一定 | 避免绝对化表述 |
| 合法合规（笼统使用） | 应具体说明符合哪条法律 |
| 没有任何问题 | 过于绝对 |
| 据我所知 | 不规范 |
| 风险很大/很小 | 应使用定性评估 |

## 七、格式要求

### 7.1 编号体系

```
一、二、三、……          （章级，中文数字）
（一）（二）（三）……     （节级，中文数字加括号）
1. 2. 3.                 （条级，阿拉伯数字）
(1) (2) (3)              （款级）
① ② ③                   （项级，极少使用）
```

### 7.2 法律引用格式

```
《中华人民共和国公司法》（以下简称"《公司法》"）第X条
《中华人民共和国民法典》第X条
《最高人民法院关于适用〈中华人民共和国公司法〉若干问题的规定（三）》第X条
```

注意：
- 法律名称首次出现用全称并注明简称，后文用简称
- 书名号内的书名号用单书名号 `〈〉`
- 条文号使用中文数字（第一条、第二条）或阿拉伯数字（第1条、第2条），全文保持一致

### 7.3 金额格式

- 大写：人民币壹佰万元整（￥1,000,000.00）
- 小写：人民币100万元 或 人民币1,000,000.00元
- 报告中一般使用小写，重大金额或合同金额首次出现时大小写并用

### 7.4 日期格式

- 报告正文：2026年3月20日
- 表格中可简写：2026.03.20 或 2026/03/20
- 全文格式保持一致

### 7.5 表格规范

- 表格应有表头
- 数据对齐
- 金额右对齐
- 日期左对齐或居中
- 空单元格填写"/"或"-"或"不适用"
