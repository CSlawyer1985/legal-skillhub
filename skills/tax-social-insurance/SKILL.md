## 能为你做什么（社保合规四大场景）
---

### 一、缴费基数真实合规
- 📊 **基数核定**：按实际工资总额申报，建立工资—个税—社保三方勾稽
- ⚠️ **高频风险**：按最低基数而非实际工资申报，少缴社保费
- 🛡️ **合规申报**：避免基数偏低触发预警与补缴

**典型问法：**
```
"社保缴费基数怎么算？"
"社保入税后有什么变化？"
```

### 二、个税与社保匹配
- 🔗 **数据比对**：个税申报工资与社保缴费基数差异过大将触发预警
- 📋 **一致管理**：保持两基一致，对合理差异留存说明与证据
- ⚠️ **风险点**：基数不匹配导致稽核与补缴

**典型问法：**
```
"个税和社保基数不一致怎么办？"
"社保基数和个税申报要一致吗？"
```

### 三、灵活用工与用工分类
- 👥 **准确分类**：区分劳动关系、劳务关系、灵活用工，依法参保
- 🛡️ **防规避**：真实劳动关系通过外包、合作掩盖以规避社保的仍须依法参保
- 📑 **全口径**：临时工、实习生、返聘人员依法分类管理

**典型问法：**
```
"灵活用工要交社保吗？"
"劳务外包能规避社保吗？"
```

### 四、社保稽核与历史补缴
- 🔍 **稽核应对**：社保稽核、补缴通知的合规应对与陈述申辩
- 💱 **补缴风险**：历史基数不足被要求补缴并加收滞纳金
- 🧭 **自查整改**：主动开展社保合规自查，及时补缴完善内控

**典型问法：**
```
"企业社保合规怎么自查？"
"社保稽核怎么应对？"
```

### 五、社保基数合规自查与测算（新增）
- 🧮 **七步自查**：核范围—核基数—核上下限—核差异—核期间—核关系—出报告，标准化 SOP。
- 📐 **差异测算**：基数缺口、少缴金额、滞纳金（每日万分之五）量化模型，支撑存量整改决策。
- 🚨 **动态预警**：社保基数/个税工资比值、未参保比例、低于下限比例、调基补差完成率四项阈值。
- 🛠️ **整改路径**：存量补缴、增量合规、争议处理三路径闭环。

**典型问法：**
```
"社保缴费基数怎么自查？"
"社保基数差异怎么测算？"
"社保合规预警阈值是多少？"
```

### 六、个税社保不一致与风险分级（新增）
- 🔗 **不一致应对**：个税工资与社保基数差异成因（口径/节奏/变动/拆分）、金税四期双向比对预警、主动补缴降低处罚。
- 📊 **风险分级**：按差异率、涉及人数、主观恶意、历史违规四维分 A/B/C/D 级（SI-R07~R10），量化补缴规模与整改优先级。
- 🧾 **CPA 账务调整**：历史少缴的以前年度损益调整、个人部分收回/代扣、滞纳金营业外支出（纳税调增）分录。
- 🕵️ **稽查方法**：个税 vs 社保基数、人数三方、电子底账+发票、银行流水四维交叉；四川2026上下限费率实务。

**典型问法：**
```
"个税和社保基数不一致风险多大？"
"社保合规风险怎么分级？"
"CPA怎么调社保补缴账？"
"社保稽查怎么查隐性少缴？"
```

## 重要提示与边界声明

**重要提示**
1. **基数须真实**：按实际工资总额申报，建立工资—个税—社保三方勾稽。
2. **匹配须一致**：个税申报工资与社保基数保持一致，差异留存说明。
3. **用工须分类**：准确判定劳动关系，真实劳动关系依法参保。
4. **以官方为准**：社保征管规则时效性强，具体以经办机构与税务机关口径为准。

**边界（本技能不做的）**
- **不代办**：社保参保、缴费系统等需登录操作的事项
- **不代理**：社保争议代理等需执业资质的事务
- **不担保**：社保稽核结论、补缴认定等最终以经办机构为准

**服务说明**
- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告

**隐私保护**
- 仅在本机生成随机匿名标识用于服务调用，不会采集任何设备信息或个人隐私数据。
