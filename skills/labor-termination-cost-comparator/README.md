# 劳动关系解除成本方案比较

这是一个面向中国大陆劳动关系解除/终止场景的法律 Skill 包。它把文字、DOCX、PDF、工资数据和程序材料整理为可回查的 N、N+1、2N 及附随项目情景比较，并分别生成客户版 Word 和内部 Word 底稿。

## 使用边界

- 法律依据、地方工资数据、解除类型、工龄和工资基数都必须在具体项目内重新核验。
- `scripts/calculate_termination_options.py` 只做显式输入的算术，不判断解除是否合法。
- 原始材料只读；项目运行时使用 `01_输入材料`、`02_处理过程`、`03_输出交付` 三个顶层目录。
- Office CLI 可用时优先使用；客户版必须经过批注、修订、隐藏内容、敏感元数据、OpenXML 和视觉检查。

## 包内资源

- `SKILL.md`：运行入口和触发边界。
- `references/`：劳动解除专项方法、法源注册表、文件和 Word 契约。
- `scripts/`：项目初始化、金额算术计算和 DOCX 清洁检查。
- `assets/templates/`：客户版报告和内部底稿结构。
- `evals/`：触发用例、法律输出断言和七个合成输出用例。
- `reports/`：创建交接、取舍、信任边界和 IR 导出。

## 创建期证据状态

本包已完成结构、能力配置和静态触发/输出评测设计；提供方模型实跑、独立人工盲评、真实脱敏项目回归、真实 Word 视觉交付和地方口径全覆盖仍属于 `missing evidence`，不得仅凭本包文件声明已取得这些证据。
