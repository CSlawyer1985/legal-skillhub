# 法律方法核心规则

本文件是 [通用法律能力模型](universal-legal-capability-model.md) 的标准化"条件展开"目录：十二模块的最低契约不变，本文件提供每个模块之上可选用的方法纪律。方法提炼自中国最高人民法院审判方法（会议纪要理解与适用、证据规则、审判实务）、诉讼实务方法（请求权基础办案、类案检索报告、庭审对抗）与合同实务方法（合同审查准则、法律评估意见结构），经重写为领域无关的规则句。

本文件只规定**方法纪律与检查问句**，不提供任何现成法律结论。具体法条、司法解释、期限、案例、裁判规则、监管口径和地方实践必须结合法域与法律时点在运行时独立核验；任何方法规则不得以模型知识替代核验。下游 Skill 可在最低契约上选用本文件的增强检查，但不得因采用增强检查而降低 [法律核心规则](legal-core-rules.md) 的真实性、时效性、可追溯性、四层分离和人工复核底线。

## 1. 找法与定性

### 1.1 请求权基础主轴

- 争议与评价类分析的骨架是"请求 → 规范基础 → 构成要件 → 要件事实 → 证据"映射链；每个结论必须能回答"挂在哪个请求权基础的哪个要件上"。
- 反模式：法条堆砌式分析——罗列相关条文但不说清各自主持的请求、要件和事实该当性。
- 检查问句：输出的每个结论能否沿映射链反向定位到规范条文和要件事实？被告视角是否逐一拆解了全部要件（含"不能确定该当"也列为争点），而非整体否认？

### 1.2 定性优先

- 先按当事人实际设立的权利义务内容定性法律关系，再展开找法、要件与效力分析；不得以合同标题、文件名称或当事人自称代替定性。
- 定性须写明依据的权利义务特征（谁担风险、谁享收益、有无保本安排、有无真实标的物流转）；存在多种合理定性且材料不足时，并行展开备选定性，不擅自选定唯一结论。
- 反模式：跳过定性直接适用某类合同/某类关系的规则；见到"名为 X 实为 Y"结构仍按名称分析。
- 检查问句：输出是否先完成关系定性并说明特征依据？定性结论是否决定了后续找法范围？

### 1.3 找法顺序纪律（禁止向一般原则逃逸）

- 找法顺序：具体规则穷尽 → 类推适用、目的性限缩等漏洞填补 → 仍不能解决才可适用基本原则。引用诚实信用、公序良俗等一般条款时，必须同时说明"无具体规则且漏洞填补不可行"的排除过程。
- 反模式：以"依据利益平衡/诚信原则/公平原则"直接下结论；把学理概括（外观主义、刺破面纱）当作可直接援引的裁判依据，而不落到具体规则的构成要件。
- 检查问句：凡引用一般条款或学理原则的结论，是否附带了具体规则缺位的论证？

### 1.4 规范性质辨识前置

- 效力判断前先给规范定性：强行性规定、赋权性（权限性）规定、任意性规定、倡导性规定、警示性规定的违反后果迥异；警示性规定与正面要件宣示条款不是认定无效的裁判依据。
- 反模式：见到"应当""不得"就得出无效结论；沿用《民法典合同编通则解释》已不再采用的"效力性/管理性强制性规定"二分直接下效力结论，而不分析规范目的、保护法益、违法后果与交易安全。
- 检查问句：每个被援引为效力依据的条文，是否先完成了规范类型定性？

### 1.5 体系化找法

- 识别总则与分则、一般法与特别法的统辖关系：特别法优先，但特别法无规定或不明确时回填一般法；不因找到一条特别法即终止检索。
- 规范冲突显式处理：上位法优先、同一机关新法优先、特别法优先及其例外；无法自行解决的冲突（如新一般规定与旧特别规定）如实记录并转人工或有权机关路径，不悄悄选一个有利口径。
- 检查问句：法源清单是否体现层级与序位意识？是否存在"特别法无规定 → 回归一般法"的完整链路？

### 1.6 时间效力三轨制

- 以**法律事实发生时间**（而非起诉时间或检索时间）为基准点，区分：法不溯及（原则）、有利溯及（须符合法定条件且不损害他方）、空白溯及（新增规定填补规则真空可用，改变要件或后果的规定不可用）。
- 持续性法律事实跨新旧法时一般适用新法，并显式说明衔接处理。
- 检查问句：时间分析是否完成"事实时点定位 → 新/旧/持续三分 → 溯及类型判定"，而非只查"条文是否现行有效"？

## 2. 效力与评价

### 2.1 效力阶梯

- 效力判断是阶梯式状态机，逐层标注结论所在层级：成立 → 生效（附批准、附条件的"未生效"独立存在）→ 有效 / 无效 / 可撤销 / 效力待定 → 对抗力与物权变动（区分原则：合同效力与物权变动、对抗效力分开）。
- 反模式：把"未生效""可撤销""无效""不对抗"混用；以合同无效直接推论物权未变动或反之。
- 检查问句：每个效力结论是否标注了所处层级？不同层级的请求权基础与证明责任是否分别处理？

### 2.2 准法源分级与引用姿态

- 中国法语境下须区分四档引用姿态，不得混用：
  1. **裁判依据**：法律、行政法规、司法解释——可直接引用为裁判依据；
  2. **应当参照**：指导性案例——只能作为裁判理由引述并注明编号，不得作裁判依据引用；
  3. **仅能说理**：会议纪要、答记者问、理解与适用、权威著述——用于把握立法真意与裁判口径，不是裁判依据；
  4. **须举证查明**：习惯、外国法、地方口径——由主张方举证或由查明路径确认其存在与内容。
- 反模式：把会议纪要当作裁判依据直接引用；引用指导性案例不注明编号与参照姿态；把实务文章观点写成"司法实践认为"。
- 检查问句：输出引用的每一项法源是否标注了其引用姿态？准法源是否都被要求运行时核验现行有效与未被推翻？

### 2.3 利益衡量规制

- 需要价值判断时，按三步展开：指认冲突的具体利益 → 对照可核查的评价序列（立法已确定的评价、效力层级、体系一致性）→ 把衡量落地为具体解释或漏洞填补的技术操作。
- 反模式："综合考虑各方利益，故……"式修辞化衡量；以利益衡量替代事实认定（事实有无只能由证明责任解决）。
- 检查问句：价值判断结论是否指明了被衡量的具体利益和所依据的评价序列？

### 2.4 结论可接受性回检

- 交付前对最终结论做 sanity check：逻辑自洽但明显违背常识或实质公平的结论，必须回查定性、找法或涵摄环节，而不是直接交付。
- 以下五种情形必须充分说理而非结论跳步：法律适用有争议；存在复数解释；解释结论与文义明显不一致；不确定概念具体化；规范竞合或冲突。
- 检查问句：输出是否经过"这个结论在常识和实质公平上说得过去吗"的回检？五种情形出现时是否展开了说理？

## 3. 证明与证据

### 3.1 证明责任双重结构

- 区分行为意义举证责任（随主张随时发生、可在双方间流动）与结果意义证明责任（要件事实真伪不明时的法定败诉风险分配）。
- 输出必须区分两种失败语义："证据不足（可补强，列补强动作）"与"真伪不明（按证明责任分配承担不利后果）"；每个待证事实显式标注当前处于哪种状态。
- 证明责任分配以现行规范为准并注明依据；注意分配规则随规范变迁而变化，不得沿用过时分配口径。
- 检查问句：输出写"证据不足"时，是否说清了是可补强缺口还是真伪不明的败诉后果？举证责任归属是否逐项给出并附现行依据？

### 3.2 证明标准二维分层

- 证明标准按"程序阶段 × 事实类型"二维确定：一般民事事实采高度盖然性；欺诈、胁迫、恶意串通等特定事实类型适用更高标准；立案阶段仅形式审查，起诉证据仅为初步证据。
- 反模式：阶段错配——在立案咨询中输出实体胜负定论；在执行阶段重新争论实体是非；用实体审理标准要求程序申请材料。
- 检查问句：输出的确定性措辞是否与任务所处程序阶段匹配？特殊事实类型是否标注了更高证明标准？

### 3.3 推定二分法

- 区分法律推定（实体法规范，基础事实证明后必须认定推定事实，对方须以本证形成相反确信）与事实推定（经验法则加自由心证，对方反证使事实回到真伪不明即可）。
- 检查问句：输出出现"推定"时，是否区分了类型并正确表述了反驳方的举证要求（本证推翻 vs 反证动摇）？

### 3.4 证据综合审查与心证公开

- 禁止孤立评判单一证据证明力；事实认定须呈现"证据链相互印证"结构，运用逻辑与经验法则，并公开判断理由。
- 事实梳理应有时间轴/大事记结构；每个事实主张锚定到具体证据位置（编号、页码、段落）；识别并呈现对方叙述的内部矛盾及证据与陈述的冲突。
- 检查问句：事实认定是逐证据打勾式罗列，还是证据链印证结构？推理理由是否公开？是否存在无证据锚定的事实主张？

## 4. 程序与对抗

### 4.1 程序阶段—结论深度耦合

- 程序阶段决定可输出结论的类型与确定性：立案阶段评受理可行性，实体审理评要件该当与胜负区间，执行阶段评可执行性（执行依据须主体与给付内容明确，执行程序不解决实体争议），再审阶段评估法定事由与纠错可能性。
- 检查问句：输出是否存在阶段错配？各阶段结论是否使用了与阶段匹配的确定性等级？

### 4.2 类案一致性硬约束

- 引用案例前完成三项核验：裁判已生效（一审文书须查二审结果）、未被再审或撤销程序推翻、全文无对本案不利的风险内容；并做相似性与可适用性论证，不得把案例当论据随意摘取。
- 发现与上级法院或本院生效类案、指导性案例不一致时，触发升级路径：显式披露分歧、强化说理、转人工或集体讨论，不得隐藏冲突。
- 检查问句：每个被引案例是否通过三核验并附可适用性论证？是否存在未披露的类案冲突？

### 4.3 交叉程序识别

- 同一事实可能触发民行交叉、刑民交叉、民商交叉等多重程序时，显式识别各程序路径、先后关系与相互影响（如先刑后民、行民并行），而非默认单一程序。
- 检查问句：输出是否检查过"同一事实是否触发其他程序"这一问？多程序并存时的路径选择是否有依据？

## 5. 交付与表达

### 5.1 商业目的转译与备选路径

- 先明确委托人（用户）的商业目的或决策目标，再倒推法律路径；法律评估不利但程序动作本身能服务合法目的时，如实说明并比较。
- 主路径受阻时提供 back-up plan：转换请求权基础、转换权利客体、另案救济或程序替代方案；不把单一路径包装成唯一答案。
- 检查问句：输出是否先回答"客户要什么"？是否至少给出主路径加一条替代路径，并比较成本、时效、风险与可逆性？

### 5.2 受众工程与表达分层

- 同一分析按读者调整形态：对决策者结论先行、对裁判者降低阅读成本（主张旁注依据、数字附计算过程、证据标页码）、对后审审查视角预设冗余论证（让步式、饱和式）。
- 支持按场合伸缩的多粒度表达（摘要/标准/完整三档）；表达以忠实为前提——图表与摘要不夸大、不隐瞒、不掺入立场性评述。
- 检查问句：输出的详略、术语密度、结论前置程度是否与声明的受众匹配？每个数字结论是否附计算口径？

### 5.3 风险四问与意见结构

- 法律意见的风险分析必须回答四问：什么风险、因何发生；法律后果是什么；发生概率与敞口多大；有无降低后果或概率的措施——最后落到"采取措施后风险是否可容许"的决策建议。
- 意见须旗帜鲜明给出定性结论（内部评估场景），配套合规措施与预案，并限定适用范围与前提假设；信息不全时以书面声明审查前提代替沉默。
- 反模式：只有"存在风险，建议注意"；两头占的模糊定性；无适用范围限定的开放式意见。
- 检查问句：每条风险是否四问齐全？意见是否含定性、措施、可容许性判断和范围限定？

## 6. 检索质控与留痕

### 6.1 法条识别与效力甄别四问

- 识别规范的真实身份：全称、文号、制定机关、公布与施行日期；区分司法解释、批复、规范性文件的不同效力。
- 对每项依据做效力甄别四问：文本是否真实准确；是否现行有效（无废止、修订、失效）；对本事项是否有效力（适用范围、层级）；时间效力是否覆盖本案事实时点。
- 检查问句：每条被引规范是否通过四问并记录核验状态与日期？

### 6.2 双源交叉验证与检索留痕

- 核心依据至少经两个独立来源交叉验证；对书面规定与实务做法的地域差、时间差保持警觉，纯文义推理的结论须标注待验证。
- 保留检索记录（检索路径、来源、时点、命中与未命中），使第三方可复核；检索失败如实说明缺什么、如何补。
- 反模式：以单一来源或模型记忆作为核心依据；虚构文号、条文或案号（本 Skill 体系的绝对红线）。
- 检查问句：核心结论的每个依据是否可溯源到两个独立来源？检索过程是否留有可复核记录？
