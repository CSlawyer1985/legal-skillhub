# 法律资源与核查路由

## 路由原则

先根据任务目的和法律能力模块识别“必须核查”的事实或法源，再选择来源。权威来源不足时停止确定性结论或明确降级；不得把搜索结果摘要、导航页、商业数据库摘要或模型记忆当作已核验依据。

## 核查器选择

| 场景信号 | 建议强制核查器 | 最低核查内容 |
|---|---|---|
| 主体资格、股权、法定代表人 | 主体登记核查 | 登记状态、统一社会信用代码、代表人、查询时点 |
| 诉讼、仲裁、执行 | 裁判与执行核查 | 案件/执行状态、裁判文书定位、时点与程序阶段 |
| 行政处罚、失信、信用 | 行政监管与信用核查 | 处罚决定、信用状态、机关和日期 |
| 知识产权 | 知识产权权属核查 | 权利人、状态、类别、期限、许可/质押 |
| 许可、资质、行业监管 | 许可资质核查 | 许可主体、范围、有效期、主管机关 |
| 证券、资本市场 | 披露与监管核查 | 公告、监管措施、披露时点、适用主体 |
| 医疗、药品、生命科学 | 专业监管核查 | 批件、注册/备案、监管状态和适用范围 |
| 数据、隐私、网络合规 | 数据合规核查 | 数据类别、处理活动、跨境/安全要求、监管依据 |

每个核查器都应记录：来源类型、具体网址或接口、访问时间、查询条件、原始快照或定位、结果、失败原因、替代来源、人工复核人。

## 工具接入

可接入司法或政务官网、商业法律数据库供应商 MCP、文档处理工具和 Office CLI 等。接入前由使用者确认账号权限、地域可用性、数据出境和费用。Skill 只输出接入建议和降级路径，不自动索取凭证或开通商业服务。Word 文稿优先使用已获授权的 Office CLI；不可用时再选择 LibreOffice 或其他兼容工具，并在审计记录中说明渲染差异。
