# 劳动解除法源注册表与运行时核验路由

本注册表只规定优先级和核验路径，不把创建期检索结果当作每个案件的现行法证明。每次运行必须以案件法律时点为基准重新核验。若官方文本、司法解释和地方规则发生冲突，保留冲突记录，暂停受影响的确定性结论并提交律师判断。

## 一、优先法源层级

1. 全国性法律及行政法规：以中国人大网、国务院/中国政府网、司法部或依法公开的政府法库全文为优先。
2. 最高人民法院司法解释、规范性文件和官方发布：以最高人民法院官网、公报为优先；注意施行日期、清理和新旧衔接。
3. 人力资源和社会保障部及地方人力资源和社会保障部门的官方规范、政策解读和公开数据：解读只作为说理或核验线索，不能替代法律文本；地方数据只在地域和年度对应时使用。
4. 指导性案例、典型案例和公报案例：记录案号、裁判层级、生效状态、相似性和引用姿态；不把普通案例或网络文章当作裁判依据。
5. 用户指定的本地知识库：优先用于发现、历史版本和内部方法，但具体法条、现行效力、司法解释和地方口径必须回溯官方或其他独立权威来源。

## 三、运行时检索步骤

1. 先把用户问题改写为检索表达：解除类型、法律后果、工作地点、法律时点、工资基数、工龄、程序和附随项目。
2. 在用户指定的本地知识库中做发现检索，记录文件路径、版本、段落和是否为原始法源；不得把知识库命中直接写成已验证。
3. 对每个核心依据回溯至少两个独立权威来源，至少核对：文本真实性、现行有效性、事项适用性、时间效力。
4. 对地方工资数据和程序规则，优先查询用人单位所在地或劳动合同履行地的政府/人社部门，记录公布年度、指标名称和访问日期。
5. 记录未命中、超时、权限不足和冲突；检索失败只表示本次未成功，不表示法律不存在。
6. 形成来源台账后再计算。任何未核验的核心法源、地方数据或时点都进入 `blocked` 或条件化路径。

## 四、底稿字段

每条来源至少记录：`source_id`、文件全名、制定机关/发布机关、文号或网页标题、条文/段落/案号定位、来源 URL 或本地定位、来源类型、效力层级、发布时间/施行日期、检索日期、核验人、核验状态、与案件事实的适用理由、冲突来源和下一步复核动作。

准法源引用姿态固定区分：法律/行政法规/司法解释为“裁判依据”；指导性案例为“应当参照”；会议纪要、答记者问、理解与适用和权威实务为“仅能说理”；习惯、外国法和地方实务口径为“须举证查明或需核验”。
