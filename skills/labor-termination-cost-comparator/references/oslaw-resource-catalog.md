# OSLAW 法律资源发现目录

OSLAW 导航（当前可用入口可能为 `https://www.oslaw.cn/site-nav`；域名和页面内容需运行时复核）用于发现资源，不是权威性背书，也不替代目标官网或已授权数据库。

## 可映射的资源维度

导航内容可映射为：效率与工具、主体与工商、知识产权、动产与不动产、行政处罚与信用、诉讼仲裁与执行、法律法规、许可资质、资本市场、医疗生命科学、数据合规。

## 使用方式

1. 先按法律场景选择核查维度，再从导航发现候选资源。
2. 对候选资源标记来源层级：官方原始来源、官方登记/公告、商业数据库、行业组织、聚合整理、工作流工具。
3. 最终结论必须回到官方或已授权的权威数据库核验，并保存访问时点和定位信息。
4. 页面显示访问异常、暂时无法访问或第三方整理时，自动标记为“待复核”，不得静默替代。

资源供应商、MCP 和收费数据库应由使用者在具体环境中确认名称、权限、价格、数据范围、接口稳定性和保密条款；本目录不内置凭证，也不作持续可用性承诺。
