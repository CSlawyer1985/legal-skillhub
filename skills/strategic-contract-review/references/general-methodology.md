# 合同审查通用方法论

本文档包含合同审查的底层方法论，供第三、四阶段审查时参考。

---

## 一、四大主题框架详解

突破传统"逐条罗列"的审查方式，从交易本质出发将合同内容归纳为四大主题，确保审查的系统性和周延性。每个主题下按主体/交易类型做逐级细化，避免"一刀切"式审查。

### 1. 交易主体

先判断主体类型，再按对应细项逐项核查。

#### 1.1 自然人

| 核查项 | 审查要点 | 为什么重要 |
|--------|---------|-----------|
| 姓名 | 与身份证件完全一致（含生僻字和简繁体），不能用"王总""李工"等简称 | 诉讼时被告主体错误导致驳回 |
| 身份证号码 | 留存复印件或拍照核验（原件核对+复印件留存） | 唯一标识自然人，用于诉讼和执行 |
| 住址 | 填写身份证住址或经常居住地，建议附加"如发生变化应书面通知" | 法院管辖和送达依据 |
| 联系方式 | 手机号+电子邮箱，至少两种 | 紧急通知和日常沟通 |
| 民事行为能力 | 年龄≥18且无明显精神障碍；与未成年人或限制行为能力人签约需其法定代理人共同签署 | 否则合同效力可能不被认可 |
| 婚姻状况 | 涉及重大资产处置时（如卖房/股权转让），要求配偶出具知情同意书 | 避免夫妻共同财产处分争议 |

#### 1.2 法人（公司/企业）

| 核查项 | 审查要点 | 为什么重要 |
|--------|---------|-----------|
| 准确全称 | 与营业执照完全一致，括号格式统一（中文全角/英文半角） | 合同主体与诉讼主体必须一致 |
| 统一社会信用代码 | 18位，必填 | 企业唯一标识，用于工商查档、诉讼、执行 |
| 法定代表人/负责人 | 姓名+职务，核实是否在工商登记中、签约人是否为法定代表人 | 法定代表人以公司名义签约当然有效；非法定代表人签约须有授权 |
| 住所/经营场所 | 填写营业执照登记住所或实际经营地 | 法律文书送达和管辖依据 |
| 联系方式 | 至少两种（固话/手机+邮箱） | 日常沟通和紧急通知 |
| 存续状态 | 通过"国家企业信用信息公示系统"核查：是否在业？是否被列入经营异常名录或严重违法失信名单？ | 注销/吊销主体不能作为签约方 |
| 经营范围 | 核查合同项下业务是否超出经营范围——超出不自动导致合同无效，但可能涉及行政许可/资质违规 | 超出许可范围可能导致行政处罚 |
| 资质许可 | 是否需要建筑业资质、医疗器械经营许可、食品经营许可等行业准入？ | 无资质则合同可能无效或面临处罚 |

#### 1.3 非法人组织（合伙企业/个人独资企业/分支机构/分公司）

| 核查项 | 审查要点 |
|--------|---------|
| 合伙企业 | 普通合伙人承担无限连带责任——必须核实合伙人身份和偿债能力 |
| 分支机构/分公司 | 不具有独立法人资格，其民事责任由总公司承担（《民法典》第74条）；要求提供总公司授权书，合同尾部同时盖总公司和分支机构公章 |
| 个人独资企业 | 投资人承担无限责任——审查投资人个人身份信息 |

#### 1.4 通用核查项（所有主体类型均适用）

| 核查项 | 审查要点 |
|--------|---------|
| 通讯地址与送达 | 合同中是否明确载明双方的所有联系方式？变更通知期限是否约定？送达条款直接决定违约通知、解约通知等关键法律行为能否有效到达 |
| 第三人履约约定 | 合同义务是否由第三方实际履行？《民法典》第523条：第三人违约时，债务人仍须向债权人承担违约责任——不能因为有第三方就误以为风险已转移 |
| 征信/涉诉 | 通过"国家企业信用信息公示系统""中国执行信息公开网""中国裁判文书网"交叉核查对方是否有未执行案件、是否为失信被执行人、近三年涉诉频率 |

### 2. 交易内容

按合同类型细分审查重点。

#### 2.1 标的物类（买卖/租赁/赠与）

| 审查子维度 | 审查要点 |
|-----------|---------|
| 规格/型号/数量 | 逐一列明，不可用"一批""一套"概括；有国家/行业标准的引用标准编号 |
| 质量标准 | 避免"合格""优质"等主观词；约定验收标准和验收程序 |
| 权利负担 | 出卖人是否对标的享有完整处分权？是否存在抵押/质押/查封？——担保物权不因所有权转移而自动消灭 |

#### 2.2 服务类（物业/维保/咨询/代理/外包）

| 审查子维度 | 审查要点 |
|-----------|---------|
| 服务范围与边界 | 是否明确"含XX、不含YY"？避免"等"字导致范围争议 |
| 服务标准 | 可否量化？（响应时间≤X小时、巡检频次≥Y次/月）不可量化的标准等于无标准 |
| 交付成果 | 服务交付物是什么？（报告/图纸/数据/账户权限） |
| 服务期限与计费模式 | 固定期限or自动续期or按量计费？自动续期须有退出机制 |

#### 2.3 工程类（建设/装修/EPC）

| 审查子维度 | 审查要点 |
|-----------|---------|
| 工程范围和承包方式 | 总承包/施工总包/专业分包/劳务分包/EPC——不同承包方式权利义务差异极大 |
| 工期 | 开工日+竣工日+中间节点（正负零/封顶/机电安装/竣工），每个节点是否可验证 |
| 质量标准 | 引用国家/行业/地方质量标准编号；"合格"应明确"合格"的标准文件 |

#### 2.4 知识产权类（许可/转让/开发）

| 审查子维度 | 审查要点 |
|-----------|---------|
| 权属证明 | 专利权证书/商标注册证/著作权登记证书——编号、有效期、权利人 |
| 许可方式与范围 | 普通/排他/独占？地域范围？商品/服务类别？许可期限？分许可权？ |
| 成果归属 | 委托开发/合作开发——无约定时权利归属差异巨大（《民法典》第859-861条） |

#### 2.5 通用（所有类型）

| 审查子维度 | 审查要点 |
|-----------|---------|
| 价款构成 | 是否含税（专票/普票/税率）？是否含运输/安装/培训/差旅？计价货币？ |
| 付款节奏 | 付款比例是否与交付/验收节点挂钩？避免全额预付 |
| 术语定义 | 合同中反复出现的核心概念是否定义？定义是否与行业通行含义一致？ |

### 3. 交易方法

#### 3.1 交付/履行时间与方式

| 审查子维度 | 审查要点 |
|-----------|---------|
| 履行期限 | 是否有时序图或里程碑表？每个节点的开始和截止时间是否明确加减天数（工作日/日历日）？ |
| 交付地点 | 精确到门牌号/仓库名称；多个地点分批次交付的需列明 |
| 交付方式 | 实物：运输方式、承运人指定权、投保义务；虚拟物：交付平台（邮箱/网盘/系统）、交付确认方式 |
| 风险转移 | 明确风险转移时点（交付时/验收时/所有权转移时），与《民法典》第604条衔接 |

#### 3.2 验收

| 审查子维度 | 审查要点 |
|-----------|---------|
| 验收标准 | 客观可操作（含测试方法、抽样比例、合格率标准） |
| 验收程序 | 谁发起、谁参与、时限（超过N日不验收视为验收合格or视为不合格？）、异议期 |
| 验收不合格的后果 | 返工/退款/扣款/解除——是否明确 |

#### 3.3 结算与付款

| 审查子维度 | 审查要点 |
|-----------|---------|
| 付款条件 | 是否与明确可验证的事件挂钩（非主观判断） |
| 发票 | 类型（专票/普票）、税率、开具时点（先票后款or先款后票）、与付款的顺序关系 |
| 迟延付款 | 逾期利息/违约金比例 |

### 4. 问题处理

#### 4.1 违约

| 审查子维度 | 审查要点 |
|-----------|---------|
| 违约情形 | 是否穷尽主要场景？（迟延交付/质量不合格/不付款/违反保密/违反竞业等）——未穷尽则不构成违约 |
| 违约金 | 是否约定具体金额或计算方式？过高→《民法典》第585条：法院可调减至实际损失1.3倍；过低→不足以约束对方 |
| 违约与解除的关系 | 什么程度的违约可触发解除权（根本违约）？与一般违约的后果有何区别？ |
| 减损义务 | 《民法典》第591条：守约方须采取合理减损措施——合同中是否体现 |

#### 4.2 合同解除

| 审查子维度 | 审查要点 |
|-----------|---------|
| 约定解除情形 | 是否列举？是否对等（双方均可行使or仅一方可行使）？ |
| 解除程序 | 通知期（提前X日书面通知）？解除后清算条款（已付款退还/已完成工作折价/资料交还） |
| 解除后存续条款 | 哪些义务不因解除而终止（保密/知识产权/争议解决/清算） |

#### 4.3 不可抗力/情势变更

| 审查子维度 | 审查要点 |
|-----------|---------|
| 不可抗力定义 | 是否仅"自然灾害、战争"？应包含"政策变化/政府禁令/疫情/供电限制"等 |
| 通知与减损义务 | 发生不可抗力后的通知时限和减损措施 |
| 后果 | 免责范围（部分/全部/延期）；超过X日可解除 |

#### 4.4 争议解决

| 审查子维度 | 审查要点 |
|-----------|---------|
| 管辖方式 | 仲裁or诉讼？两者只能选一（同时约定则仲裁无效） |
| 管辖地点 | 甲方所在地/乙方所在地/合同签订地/合同履行地——选己方所在地 |
| 仲裁条款要件 | 仲裁机构全称必须准确（如"中国国际经济贸易仲裁委员会"而非"贸仲"），仲裁规则和仲裁地明确 |

#### 4.5 生效/失效

| 审查子维度 | 审查要点 |
|-----------|---------|
| 生效条件 | 签字盖章之日/审批通过/首付款到账——明确约定，避免歧义 |
| 合同期限 | 起止日期明确，到期后续签/自动续期机制 |
| 失效后处理 | 已留存文件/资料/数据/密钥的返还或销毁 |

## 二、法务审核合同的商业底层逻辑

### 3.1 目标决定行动方案

审核合同前必须了解：这份合同的签订目的是什么？多个诉求的优先级排序是什么？

- 越缺乏经验的法务越把合同改越厚——试图穷尽所有风险
- 有经验的法务把合同改越薄——风险可控前提下，内容越少成交率越高、谈判时间越短
- 核心区别在于：是否充分知悉"合同签订的目标到底是什么"
- 法务审核合同的目标是**风险得到有效控制的前提下，如何有效地促成双方合同的签订**

### 3.2 外部律师 vs 内部法务的审查差异

- 外部律师：规避自身执业风险 + 对商业信息了解有限 → 审核意见更多、风险提示更全面
- 内部法务：更应关注合同履行的风险与效率、效益之间的平衡
- 风险越大潜在收益越高，审查严格程度应随行业景气度、企业地位、交易对象而调整

### 3.3 合同质量的评价标准

**外在质量是表述**：任何一位看到同一份合同的人在阅读时均不会产生歧义。
**内在质量是合规**：条款不违反法律法规的强制性规定。

### 3.4 审查前必须搞清楚的事

1. **根据不同合同主体确定不同风险点及发生概率**：如与外企交易→付款风险较低；与民企交易（尤其房地产企业）→付款风险可能是最核心风险。不同交易对象的风险画像不同，不可用同一模板套所有。
2. **根据交易双方优劣势地位确定修改策略**：强势方示范文本中，要找到自己交易的特殊性→说明"我们是一份特别的合同，不适用一般条款"→说服对方同意修改。
3. **先将风险有序罗列，加入谈判筹码条款**：哪些是对我方不重要但对方可能在意→可作为交换筹码。形成清晰的谈判优先级：先谈什么、后谈什么、哪些该重点争取、哪些可放弃。

### 3.5 优秀法务的五项能力

1. **持续学习能力**：快速梳理合同涉及的法律法规+高频风险点+同类交易司法判例（最高院+对方所在地高院）。
2. **对行业周期的认知**：上行期→适度容忍风险抢效率；下行期→提高风险预警。同一条款在不同经济周期下的风险权重完全不同。
3. **语言表达能力**：以最简短的话把意思表述清楚。复杂价格变动条款→直接写入计算公式+举例演算，消除歧义。
4. **有效沟通能力**：与业务部门充分交流，审核前全面了解该合同所对应交易的全貌。
5. **跨专业知识**：财税——合同分拆（买卖合同13%增值税 vs 技术服务合同6%增值税）可大幅降低企业成本。技术——理解标的物特性才能审查技术条款。

### 3.6 说"行"的能力

法务不能只做"说'不'的人"。对合同主要条款提出否定意见时，**必须尽一切可能为业务部门想到替代解决方案**。否定了一个交易模式之后，如果能提出更合规、更快捷的交易路径，法务才真正有价值——"有作为才能有地位，有更大的话语权。"

这在审查报告中体现为：不是只给"这个条款有问题"，而是在A/B/C路径中始终包含"替代方案"——即使现有的交易结构有风险，是否存在另一种合法实现商业目的的方式。

## 四、持续性服务合同的特殊审查维度

本维度是对四大主题框架的**叠加补充**，适用于合同周期≥1年的持续性服务合同（物业服务、设备维保、IT外包、SaaS订阅、安保/保洁服务、咨询服务等）。

### 为什么需要单独叠加

一次性交易合同（如买卖、技术开发交付）的核心风险在"签约时点"——价款是否公平、交付是否明确、违约是否有救济。合同签署后，风险窗口逐步收窄。

持续性服务合同不同——签约只是开始。核心风险不在签约时点，而在履约阶段逐步累积：
- 服务标准不量化 → 第三年敷衍了事，业主无从追责
- 价格锁定不科学 → 三年后物业费跑输CPI，服务质量断崖下降
- 没有退出机制 → 被劣质服务"绑架"，更换成本极高
- 单方修改管理规则 → 签了一份合同，履约中被改成了另一份

### 五个叠加审查维度

| 叠加维度 | 审查要点 | 为什么重要 |
|---------|---------|-----------|
| **服务质量可持续性** | 服务标准是否量化可验证？有无定期评估机制？有无渐进退化的防范措施（如抽查/神秘访客/业主打分与费用挂钩）？ | 服务标准不可量化 = 标准不存在。3年合同期内服务商有自然动力降低投入——成本归己、收益归人 |
| **中期调整机制** | 价格是否锁死？如可调价，触发条件是客观标准（CPI指数、最低工资标准）还是主观判断（"服务成本变化"）？调价是否需要业主方单独同意还是多数决？ | "服务成本变化"是万能调价理由——任何变化都可以解释为成本变化。CPI挂钩是最低底线 |
| **退出/交接机制** | 解约条件是否明确？业主是否有单方解约权（如服务质量不达标累计N次）？解约后交接义务是否约定（资料/图纸/档案/客户数据/预付款清算）？ | 物业合同最大的摩擦点不是"涨价"而是"不让你走"和"走也不好好交接" |
| **商业连续性保障** | 服务中断有无应急措施？更换服务商过渡期如何保障？服务商破产/退出有无预案？关键数据/资料有无备份和移交机制？ | 研发办公楼、数据中心、生产厂房等对连续性敏感的场景尤需关注 |
| **单方规则变更限制** | 服务商是否有权单方修改服务标准/管理规则？若有，是否需业主方确认？新规则是否具有溯及力（约束已签署的合同）？ | 常见于物业合同（《业主手册》可被单方修改）和SaaS合同（《服务条款》定期更新） |

### 在审查报告中的体现

- 第三阶段（结构完整性校验）：对照五大维度，标注本合同缺失哪些维度
- 第五阶段（五性校验）：在五性之外单独标注"持续性维度缺失"

## 五、弱势方合同审查策略

本策略适用于委托人谈判地位极弱、对方使用不可协商的格式合同的场景。核心逻辑来自《合同审查的三个基本前提》（张海燕，全国律协）和实务经验。

### 5.1 三层分级法

弱势方审查不是"全盘接受"，而是"分级应对"：

| 层级 | 定义 | 识别标准 | 应对策略 |
|------|------|---------|---------|
| **底线条款** | 不改会导致合同目的落空或遭受重大损失 | ①违反效力性强制性规定；②涉及商业存亡（付款周期致资金断裂、违约责任过重致一违约全崩塌、核心知识产权流失、赔偿上限无限制）；③不满足客户签约的商业核心目的 | 必须修改。不改→建议客户不签 |
| **权利条款** | 不涉及存亡但明显不对等 | 单方解除权、无限连带责任、管辖约定不利、质保期过长、验收标准对方单方决定 | 以"合理化建议"方式提出（非"修改要求"，对方更可能接受）。无法修改则记录风险并出具履约注意事项 |
| **接受条款** | 对方商业模式核心条款，无法撼动 | 定价机制、付款节点、交付标准（如对方为行业龙头） | 接受。但须出具风险提示函——明确条款内容、风险后果、最坏情况，由客户书面确认知晓 |

### 5.2 不能修改时四条替代防线

当底线条款也遭到拒绝修改时，不等同于束手无策。启动四层递进防线：

**第一防线：补充协议。** 不修改主合同，以"补充协议"形式与原合同同时签署，把核心保护条款写入补充协议。"补充协议与本合同不一致的，以补充协议为准。"

**第二防线：书面确认。** 对方不接受补充协议时，通过邮件对关键承诺进行书面确认——"经贵司确认：XX事项的处理方式为YY"。对方回复确认即构成合意（《民法典》第469条：书面形式包括电子邮件）。

**第三防线：内部风险提示函。** 逐条列明不可修改条款、风险后果、最坏情况、履约注意事项，提交业务负责人签字确认。法律意义：法务已尽告知义务，后续风险由业务决策层承担。

**第四防线：履约过程管控。** 签约后：严格按合同约定履行己方义务（弱势方自身的违约可能触发严重责任）、保留全部履约凭证、关注对方违约迹象并及时固定证据、在关键时间节点主动书面确认。

### 5.3 风险提示函模板

```
致：[业务负责人姓名及职务]
自：[法务姓名]
事由：关于[合同名称]的风险提示

经审查，本合同为对方格式合同，我方已就以下条款尝试协商修改，但对方坚持不接受修改：

一、不可修改的条款及风险（逐条列出）：
条款X：[内容] → 风险：[后果] → 最坏情况：[ ]
条款Y：...

二、履约注意事项（逐条列出）：
1. [注意点]
2. ...

三、决策建议：
□ 接受合同，按上述注意事项严格履约
□ 补充以下书面确认：[ ]
□ 搁置签约

请签字确认：

[签字栏]
```

### 5.4 签约前尽职调查

弱势方往往缺乏对对方的制约能力，尽职调查是唯一的"事前防线"：核查对方是否存在大量被执行记录、近三年是否涉诉频发、行业信誉是否良好。若对方已存在大量违约纠纷，即使合同条款再差也不应签约——条款保护弥补不了主体信用缺陷。

## 第六章A：商业模式解读——改不了条款时，先让客户看清地形

### 6A.0 为什么需要这一步

替代控制（第六章）解决"怎么防"。但**在告诉客户怎么防之前，先要让他看清自己面对的是什么。** 单条条款的风险提示不足以揭示格式合同的系统性格局——分散的不平等条款合在一起，可能构成一套完整的商业压榨机器。

### 6A.1 分析框架：从分散条款到权力地图

面对弱势方且条款不可改时，审查报告必须包含一个「整体商业格局解读」，回答三个递进问题：

| 层次 | 问题 | 分析方法 |
|------|------|---------|
| **第一层：风险串联** | 这些不利条款如果合在一起，对客户意味着什么？ | 按交易流程串联——下单→生产→交货→验收→付款→争议，画出完整的风险传导链 |
| **第二层：商业模式推演** | 对方为什么设计这样的条款结构？ | 从条款反推对方的核心商业逻辑——是在靠产品赚钱，还是在靠占用供应商资金/免费获取技术/风险全部外部化？ |
| **第三层：极端场景** | 最坏情况下会发生什么？ | 用具体数字构造一个可感知的灾难场景——不是"可能产生经济损失"，而是"如果你投入X万建产线，第3个月对方取消订单，你面临的是……" |

### 6A.2 输出格式

在审查报告的决策提示中增加以下段落：

```
## 整体商业格局解读

### 风险串联图
[下单→生产→交货→验收→付款→争议，逐节点标注控制权归属]

### 对方的商业逻辑
[从条款配置反推对方商业模式，例如：
- 无最低采购承诺 + 独家供应 = 锁定产能但不承担需求风险
- 180天账期 + 单方验收权 = 用供应商资金周转
- 知识产权全收 = 免费获取技术升级]

### 最坏情况推演
假设投入X万元建产线，第3个月采购量归零：
- 已发货：180天账期，回款最早9个月后
- 在制品/库存：对方无收购义务，全部沉没
- 专用模具：无法转用，报废
- 诉讼：须在对方所在地提起
→ 预计损失XXX万元，约合公司X个月净利润
```

### 6A.3 触发条件

| 条件 | 是否需要 |
|------|:---:|
| 客户是格式合同接受方，无修改筹码 | ✅ 必须 |
| 5条以上条款存在单方倾向性 | ✅ 必须 |
| 涉及付款/验收/知识产权/违约责任等核心维度 | ✅ 必须 |
| 客户谈判地位相当或更强 | ❌ 不要 |
| 仅有1-2条次要条款不利 | ❌ 不要 |

### 6A.4 与第六章的关系

**先读6A（看清地形），再读第六章（部署防御）。** 顺序不能反。看不清地形就做防御部署，是凭运气。

## 第六章：替代控制方法论——改不了条款时怎么保护自己

### 6.0 核心原则

当条款因谈判地位、格式合同、行业惯例等原因无法修改时，审查不停止于"记录风险"。替代控制的核心思维是：**改不了条款，就改操作方式。** 通过签约前后的操作性动作，在不改动合同文本的前提下实现等效风险控制。

### 6.1 五类替代控制工具

| # | 工具类型 | 核心逻辑 | 法律依据 | 典型场景 |
|---|---------|---------|---------|---------|
| 1 | **书面锁定事实** | 用邮件/函件将合同中模糊的约定书面化、确证化 | 《民法典》第469条——电子邮件、数据电文为书面形式 | 验收标准模糊→邮件确认"以XX为标准"；交付期限不明→邮件明确具体日期并获得对方回复确认 |
| 2 | **履约流程改造** | 调整己方的履约节奏、付款节点、验收程序来降低风险暴露 | — | 款到发货→将大单拆为小单分批付款分批收货；对方无质保金→从尾款中留存一定比例至质保期满 |
| 3 | **第三方对冲** | 通过保险、担保、保函、第三方托管等外部工具转移风险 | — | 运输风险在对方→甲方自行购买运输险；对方可能断供→锁定备选供应商并保持最低采购量 |
| 4 | **证据固化** | 在履约全程主动留存可追溯的证据链，降低纠纷时的举证难度 | — | 无书面验收标准→每次收货拍照/视频留档+要求司机签收时标注外包装状态；无交接单→自行制作《包材交接单》并要求对方签字 |
| 5 | **分批操作** | 将单次大额交易拆分为多次小额交易，控制每次的风险暴露上限 | — | 首次合作无信任基础→首次下单量控制在可承受损失范围内；无违约金保障→每批次验收合格后再下下一批订单 |

### 6.2 针对常见不可改条款类型的对照表

| 不可改条款类型 | 首选替代控制 | 具体操作 |
|-------------|------------|---------|
| 违约金过低/缺失 | 证据固化 + 书面锁定事实 | 每批交货邮件确认交期，逾期自动生成证据链；损失发生时第一时间书面通知对方并保留损失凭证 |
| 违约责任不对等（对方责任轻） | 履约流程改造 + 第三方对冲 | 减少己方预付款比例；购买履约保险；拆分合同为多批次 |
| 验收标准模糊 | 书面锁定事实 + 证据固化 | 签约后邮件发送详细验收标准并请求确认；每次验收制作验收记录并经双方签字 |
| 管辖/仲裁约定不利 | 书面锁定事实 | 明确送达地址并在合同中约定；履约过程中所有通知均以EMS/挂号信寄送并保留凭证 |
| 知识产权归属未约定 | 书面锁定事实 + 证据固化 | 邮件明确声明知识产权归甲方；保留开发过程记录、图纸、邮件往来作为创作过程证据 |
| 保密条款缺失或不足 | 书面锁定事实 | 在提供保密信息前要求对方邮件确认保密义务；标注"机密"水印；记录每次信息披露的内容、时间和接收人 |
| 质保期缺失或过短 | 履约流程改造 | 从尾款中留存质保金；验收阶段加大抽检比例和检测项目 |
| 合同解除后处理不明 | 履约流程改造 | 控制单次下单量；避免大量备货；合同中约定或履约中邮件确认库存包材的处理方式 |

### 6.3 文件化要求

替代控制措施必须形成可追溯的书面记录，不能停留在口头或内部决策层面：

```
替代控制措施清单
├── 风险条款：[条款位置+问题描述]
├── 不可改原因：[对方强势/格式合同/行业惯例/协商失败]
├── 选用的替代控制：[工具类型+具体操作]
├── 法律依据：[支撑法律条文]
├── 执行节点：[在签约前/签约时/首次履约前/每批次发货前 执行]
├── 失效条件：[什么情况下替代措施会失效]
└── 升级路径：[如后续谈判地位改善，应优先推动条款正式修改]
```

### 6.4 替代控制的局限性

- 替代控制不能改变合同文本的法律效力——对方仍可依据原条款主张权利
- 替代控制的证据效果依赖于执行记录完整性——执行了但没留痕等于白做
- 部分替代控制（如分批操作）可能增加己方管理成本和操作复杂度
- **替代控制是权宜之计，不是终局方案。** 一旦谈判地位改善，仍应推动条款的正式修改
