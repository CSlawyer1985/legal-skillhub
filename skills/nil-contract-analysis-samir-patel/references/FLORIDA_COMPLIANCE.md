# 佛罗里达州 NIL 合规参考

## 快速参考：佛罗里达州 NIL 法（FL SB 646 / F.S. 1006.74）

| 事项 | 佛罗里达州要求 |
|--------|-------------------|
| **生效法规** | F.S. § 1006.74（经修订）；原为 FL SB 646 |
| **合格运动员** | 佛罗里达州高等教育机构的校际学生运动员 |
| **机构披露** | 运动员须向机构披露 NIL 合同；机构可要求事先通知 |
| **禁止的冲突** | NIL 合同不得与运动员的球队合同冲突 |
| **代理人注册** | 代理人和中间人须依佛罗里达州法律（F.S. 第 468 章第八部分）注册 |
| **机构参与** | 机构不得充当运动员的代理人或直接安排 NIL 交易 |
| **禁止类别** | 合同不得推广机构政策禁止的产品/服务 |
| **补偿结构** | 必须用于合法的 NIL 使用；不得是变相付费参赛或入学诱导 |
| **期限** | 应与运动员剩余资格年限相称 |
| **法律代理** | 运动员有权为合同审查获得法律代理 |
| **税务义务** | 运动员负责适用的税款；合同应明确税务处理 |

## 佛罗里达州合规审查检查清单

当合同受佛罗里达州法律管辖或涉及佛罗里达州机构/运动员时，逐项核查以下内容：

### 法定合规（F.S. 1006.74）

| 要求 | 核查内容 | 不合规情形 |
|-------------|---------------|---------------------|
| 机构披露 | 合同允许/要求运动员向机构披露 | 保密条款阻止机构披露 |
| 无球队合同冲突 | 条款与运动员既有球队合同一致 | 排他性、时间安排或品牌条款与球队义务冲突 |
| 代理人注册 | 代理人/中间人依 F.S. 第 468 章第八部分注册 | 代理人未注册或注册无法核实 |
| 无机构参与 | 机构不是交易的当事方、促成者或受益者 | 机构安排、指示或从交易中获得财务利益 |
| 禁止类别 | 交易不推广机构政策禁止的产品 | 合同推广酒精、烟草、赌博、大麻或其他禁止类别 |
| 合法 NIL 使用 | 补偿针对姓名、形象或肖像的真实使用 | 补偿结构类似付费参赛或入学诱导 |
| 合理期限 | 期限与运动员剩余资格年限相称 | 期限无正当理由大幅超出剩余资格年限 |
| 律师帮助权 | 合同不限制运动员获得法律代理的权利 | 合同放弃或限制运动员的独立法律审查权 |

### 机构政策合规
- 合同是否与机构发布的 NIL 政策冲突？
- 机构是否要求在签署前事先批准或通知？
- 是否有超出州法律的机构特定禁止品牌类别？
- 合同的时间安排要求是否与球队活动冲突？
- 机构的合规办公室是否知悉并能够审查该交易？

### NCAA 规章合规
- 任何条款是否可能危及运动员的 NCAA 资格？
- 补偿结构是否有被归类为不允许利益的风险？
- 是否存在可能触发 NCAA 审查的资助人（booster）参与关切？
- 合同是否以运动表现或入学作为付款条件？
- 该交易是否可能被解释为诱使就读或留读特定机构？
