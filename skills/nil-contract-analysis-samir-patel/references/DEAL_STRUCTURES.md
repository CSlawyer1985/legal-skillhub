# 交易结构与集体交易

## 常见 NIL 交易结构参考

| 交易类型 | 关键风险领域 | 主要关切 |
|-----------|---------------|------------------|
| **社交媒体代言** | 内容量、批准权、超出运动员渠道的使用 | 永久内容权、未经同意重新利用 |
| **个人出场** | 日程冲突、差旅义务、取消罚金 | 运动员承担差旅费用、不合理取消费用 |
| **商品/许可** | 版税税率、审计权、质量控制 | 低于市场版税、无最低保证、无质量批准 |
| **签名/纪念品** | 排他范围、活动频率、库存权 | 过宽排他、无限制签名义务 |
| **训练营/诊所** | 责任、保险、机构批准 | 运动员承担活动责任、无保险要求 |
| **团体许可/集体** | 收入分成、治理、退出 | 不透明分配、无个人同意、无退出机制 |
| **品牌大使** | 范围蔓延、排他宽度、期限长度 | 模糊交付物随时间扩大、宽泛类别锁定 |

## 团体许可 / NIL 集体交易

当合同涉及 NIL 集体、团体许可安排或多运动员交易时的额外要求：

### 1. 收入分成透明度
- 分配公式必须明确说明（均分、基于绩效、分层）
- 运动员必须能够核验计算（审计权或定期会计报告）
- 行政费用和集体开销必须披露并设上限

### 2. 个人义务与集体义务
- 区分运动员个人承担的义务与集体管理的义务
- 运动员不应为他运动员未履行而承担责任
- 个人营销义务必须明确界定范围

### 3. 退出机制
- 运动员必须有权经合理通知退出集体
- 退出不应触发已赚取报酬的没收
- 评估退出是否影响其他个人 NIL 交易

### 4. 分配方法
- 核验分配的时间和方式（每月、每季度、按事件）
- 标示任何酌情分配措辞（「由集体单方酌情决定」）
- 确认分配是保证最低额还是可变的

### 5. 税务处理
- 核验运动员是否被归类为独立承包商
- 标示任何暗示雇佣关系的措辞
- 确认集体是否签发 1099 表及预期时间

### 6. 多运动员同意与治理
- 集体能否未经个人同意约束运动员接受新交易？
- 运动员在集体决策中是否有投票权或发言权？
- 谁控制集体的品牌合作关系和交易流？

### 7. 合规协调
- 集体是否已注册并遵守州 NIL 法律？
- 集体是否代表运动员处理机构披露？
- 如集体在期限内失去合规状态怎么办？

## 文件请求清单

### 来自品牌/公司
- 已签署或最终合同草案及所有附件和附表
- 品牌指南和内容标准（如合同中引用）
- 与此运动员或类似运动员的先前 NIL 交易（用于市场比较，如有）
- 实体设立和良好存续证明
- 保险证明（如品牌要求运动员出场或参加活动）
- 活动简报或工作范围（如被引用但未附上）

### 来自运动员/家庭
- 当前队伍/机构合同（检查冲突）
- 现有 NIL 交易清单（检查排他冲突）
- 机构 NIL 政策（来自合规办公室）
- 代理人代理协议（如适用）
- 运动员迄今的 NIL 披露提交
- 与品牌的任何先前通信

### 来自机构
- 当前机构 NIL 政策
- 所需披露表格和时间表
- 任何预先批准要求
- 禁止品牌类别清单（如有）
- 机构合规办公室联系信息

### 来自集体（如属团体许可 / 集体交易）
- 集体的组织文件（设立、治理）
- 分配方法文件
- 州注册和合规记录
- 最近的财务报表或会计报告
- 当前品牌合作伙伴和进行中活动清单
- 个人参与协议模板
