# 分析协议

审查关键合同领域的详细分步协议。在逐条审查（工作流的第 3 步）期间适用每项协议。

---

## 合同页眉审查检查清单

| 项目 | 核实 | 标准要求 |
|------|--------|---------------------|
| 当事方 | 完整法定名称，而非昵称或缩写 | 必须与身份证件一致；核实实体类型（LLC、公司、个人） |
| 生效日期 | 明确说明；不依赖于未定义的事件 | 必须是确定的日期或“经双方签署后” |
| 期限/存续期 | 固定期限，起止日期明确 | 无正当理由不得超过剩余资格期 |
| 定义部分 | 关键术语已定义（交付物、商标、地域等） | 未定义术语产生歧义；缺失时标注 |
| 序言 | 准确描述交易目的 | 不应包含伪装成序言的约束性义务 |
| 运动员身份 | 将运动员识别为独立承包商 | 拒绝雇佣分类；核实税务处理 |
| 代理/中介 | 如存在，核实授权和注册 | 必须按适用的州法注册 |

## 报酬分析协议

**对每个报酬要素，进行以下分析：**

### 第 1 步：识别所有报酬组成部分
- 基础费用/固定费率
- 按交付物付款
- 绩效奖金（社交媒体指标、销售额等）
- 特许权使用费或收入分成
- 实物报酬（产品、服务、体验）
- 费用报销

### 第 2 步：评估付款确定性
| 组成部分 | 有保证？ | 条件 | 风险等级 |
|-----------|-------------|------------|------------|
| [每个组成部分] | 是 / 否 / 部分 | [什么触发付款] | 高 / 中 / 低 |

### 第 3 步：评估付款条款
- 付款何时到期？（Net 30、Net 60、交付时等）
- 什么触发付款？（交付物完成、发布、活动结束）
- 品牌方延迟或拒绝付款时怎么办？（滞纳金、救济）
- 是否存在追回或抵销条款？（如有则标注）

### 第 4 步：确定公允市场价值评估
- 报酬是否与所授予权利的范围相称？
- 报酬是否反映运动员当前的市场价值？
- 是否存在由运动员承担的隐性成本？（差旅、服装、制作）
- 标注任何以“曝光”或“体验”替代报酬的情况

## 肖像权分析协议

**对每项权利授予，进行以下分析：**

### 第 1 步：界定授予范围
| 要素 | 合同如何规定 | 可接受？ |
|---------|-------------------|-------------|
| **授予的权利** | 姓名 / 形象 / 肖像 / 声音 / 签名 | 是否针对交易量身定制？ |
| **媒体/渠道** | 社交媒体 / 印刷 / 数字 / 广播 / 所有媒体 | 与报酬相称？ |
| **地域** | 本地 / 州内 / 全国 / 全球 | 与报酬相称？ |
| **使用期限** | 仅合同期限 / 延长 / 永久 | 终止时必须恢复 |
| **排他性** | 排他 / 非排他 | 如排他，是否狭义界定？ |

### 第 2 步：评估保留的控制权
- 运动员是否在发布前批准内容？
- 运动员能否要求下架特定内容？
- 运动员是否保留其个人社交媒体账户的所有权？
- 品牌方能否在初次批准后修改内容？
- 品牌方能否使用运动员的肖像创建 AI 生成或合成内容？

### 第 3 步：评估可转让性
- 品牌方能否将权利分许可给第三方？
- 品牌方能否未经运动员同意转让合同？
- 分被许可人是否受相同限制约束？
- 运动员是否知道谁可能最终使用其肖像？

### 第 4 步：确定终止后义务
- 终止后品牌方还能使用既有内容多久？（收尾期）
- 品牌方是否必须在终止后移除/删除内容？
- 是否有任何权利在终止后存续？（如有则标注——应属狭窄）
- 已经“在外流传”的内容（第三方分享、转发）怎么办？

## 终止条款分析协议

### 第 1 步：识别所有终止触发条件

| 触发条件 | 可供谁使用 | 所需通知 | 后果 |
|---------|-------------|-----------------|--------------|
| 任意（无原因） | 运动员 / 品牌方 / 双方 | [天数] | [罚则？] |
| 重大违约 | 运动员 / 品牌方 / 双方 | [补救期] | [救济] |
| NCAA 资格丧失 | 运动员 / 品牌方 / 双方 | [通知] | [效果] |
| 道德品质 / 行为 | 仅品牌方？ | [程序] | [主观？] |
| 不可抗力 | 双方 | [通知] | [效果] |
| 破产 / 无力偿债 | 双方 | [自动？] | [效果] |

### 第 2 步：评估平衡性
- 运动员能否像品牌方一样容易地退出？
- 补救期是否合理且对称？
- 终止罚则是否相称？

### 第 3 步：评估终止后事项
- 哪些义务存续？（保密、竞业限制、知识产权限制）
- 存续条款持续多长时间？
- 已赚取但未支付的报酬是否仍应支付？
- 品牌方是否必须返还运动员提供的材料？

### 第 4 步：确定所需行动
关于终止问题的首选修订和后备立场，参见 [RED_FLAGS.md](references/RED_FLAGS.md) 中的主谈判表。
