# 严重程度评级与默认负责人

## 严重程度评级

| 评级 | 标准 | 示例 |
|--------|----------|---------|
| **高** | 立即的法律风险、资格影响或重大财务敞口 | 永久知识产权授予、无补偿、付费参与结构 |
| **中** | 应谈判但非交易破坏者的不利条款 | 过宽的排他性、遥远的地点、单方道德条款 |
| **低** | 次要问题或缺失最佳实践 | 无可分割条款、缺少不可抗力、无电子签名条款 |

## 默认负责人与截止期限

如用户未指定，在问题日志中使用以下默认值：

| 问题类型 | 默认负责人 | 默认截止期限 |
|------------|--------------|-----------------|
| 红线 / 条款修订 | 法律 | 签署前 |
| 合规 / 资格问题 | 合规 + 法律 | 签署前 |
| 商业条款（补偿、排他性） | 商业 + 法律 | 签署前 |
| 机构披露 | 合规 | 签署后 48 小时内 |
| 经纪人注册核验 | 法律 | 签署前 |
