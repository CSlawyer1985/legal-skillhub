# 合同审查要点提示助手（非律师版） · 使用说明（USAGE）

## 🗣️ 这玩意儿是干嘛的（大白话）
不是法务，但经常要签合同（合作/租房/采购），看得头晕怕踩坑？把合同贴给它，它用大白话告诉你：哪里权责不清、付款条件有没有坑、违约怎么赔、保密和终止条款全不全。它不替你做法律判断，但能帮你把“该找律师确认的点”先圈出来，别稀里糊涂就签了。

**一句话总结**：签合同看不出坑？给你标出常见风险条款，签字前多道保险。

## 适用人群
非法律岗的职场人（合作/采购/租房等常签合同者）

## 怎么用（步骤）
1. 在对话中说出触发词或直接描述需求（例如：“帮我看下这份合同有啥风险点”）。
2. 按提示补充背景信息（目标、阶段、数据等）。
3. 查看 AI 生成的产物，按需微调。
4. 复制到你的协作工具 / 邮件 / 文档中使用。

## 触发示例
- “看合同”
- “合同风险”
- “审合同”
- “条款注意”

## 注意事项与红线
- 非法律意见，重大合同须专业审核。
- 提醒不替代律师。
- 禁止声称提供法律意见。
- 禁止生成规避法律的建议。
