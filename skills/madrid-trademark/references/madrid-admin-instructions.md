## 各条要点详解

### 第一部分：总则（第1条）

**第1条 — 定义**
- "实施细则"指《马德里议定书实施细则》
- "Chapter / Section"指实施细则的章/节
- 行政规程中的其他定义同实施细则第1条

### 第二部分：规程（第2-5条）

**第2条 — 规定规程**
- 为执行实施细则规定的程序，国际局应制定规程（Procedures）
- 规程涵盖国际局日常操作中的标准化流程

**第3条 — 选择规程**
- 国际局可制定实施细则**未要求**的可选规程
- 给予各主管局灵活性

**第4条 — 规程的公布和提供**
- 国际局应在**WIPO网站**上公开所有规程和选择规程

**第5条 — [已删除]**

### 第三部分：通信、签名、商标图形（第6-11条之二）

**第6条 — 电子通信**
- 国际局的通信均以**电子方式**进行
- 使用文字处理或打印文本，**免除签名**
- 关键：电子化已覆盖全流程

**第7条 — 签名**
- 签名可为**手写、印刷或电子方式**
- 局与局之间使用**商定的识别方式**
- 与申请人的通信使用国际局确定的识别方式
- **共同申请人**：一人签名即可，无需全体签名

**第11条 — 电子传送和收到确认**
- 局与局之间：使用国际局与主管局**商定的电子方式**
- 国际局与申请人/注册人之间：使用国际局确定的方式和格式
- 国际局通过**自动方式**确认收到
- **发送日期**以原始发送日期为准

**第11条之二 — 商标图形（★技术规范核心）**

| 商标类型 | 格式要求 | 最大尺寸/大小 |
|---------|---------|--------------|
| 图形商标 | JPEG、PNG或TIFF（WIPO标准ST.67） | 不超过20cm × 20cm |
| 声音商标 | MP3或WAV | 不超过5MB |
| 动态多媒体商标 | MP4格式，AVC/H.264或MPEG 2/H.262编码 | 不超过20MB |

- WIPO标准引用：
  - **ST.67**：商标图形电子处理与交换推荐标准
  - **ST.68**：声音商标电子处理与交换推荐标准
  - **ST.69**：动态多媒体商标电子处理与交换推荐标准

### 第四部分：名称和地址的要求（第12-13条）

**第12条 — 名称和地址**
- **自然人**：指明**姓氏和名字**
- **法律实体**：**正式全称**
- 使用**非拉丁字母**的名称：须提供**拉丁字母音译**或翻译
- 地址应便于快速邮寄，至少包含：
  - 街道名称和门牌号
  - 城市
  - 国家
- **中文实务要点**：中国申请人名称须同时提供中文和拉丁字母音译

**第13条 — 通讯地址**
- 申请人或注册人有不同地址时，可指定一个**通讯地址**
- 如未指定，以最先列出的地址为通讯地址

### 第五部分：临时驳回通知（第14-15条）

**第14条 — 通知的要求**
- 须以实施细则第17条(2)和(3)指定的**期限**为准

**第15条 — 驳回通知的内容（★实务重点）**
- 临时驳回通知须包含以下内容：
  1. 驳回的**具体理由**
  2. 涉及的法律依据（如与在先商标权利冲突、缺乏显著性、功能性等）
  3. 如涉及**在先权利冲突**，应简要指明在先权利及其权利人
- **不得包含**：案卷或证据的附文
- **实务操作**：驳回通知中不应附送详细证据材料，证据应在后续程序中另行提交

### 第六部分：国际注册的变更（第16-18条）

**第16条 — 分割或部分转让后的变更**
- 因所有权变更或分割登记产生的**新国际注册**
- **编号规则**：使用**原国际注册号 + 大写字母**（如：A、B、C...）

**第17条 — 合并后的变更**
- 合并后的国际注册，使用**被转让或被分割的国际注册号 + 大写字母**

**第18条 — 驳回/无效宣告后的变更**
- 在实施细则第27条(4)(e)项下登记的新国际注册
- 使用被转让的原始注册号 + 大写字母

### 第七部分：规费的缴纳（第19条）

**第19条 — 缴付方式（★三种途径）**

| 方式 | 说明 |
|------|------|
| **活期账户取款** | 从国际局开设的活期账户（Current Account）中自动取款 |
| **往来账户扣款** | 从国际局接受的任何指定往来账户（Deposit Account）中扣款 |
| **信用卡支付** | 通过电子通信系统使用信用卡支付 |

- **缴费实务**：代理机构通常开立**活期账户**，可实现自动扣款，避免逾期

## 实务操作要点总结

### 电子通信规范
1. 全部电子化 — 所有文件均以电子方式传送
2. 电子签名有效 — 手写、印刷或电子签名均可
3. 共同申请人一人签名即可

### 商标图样提交（★关键）
1. **静态商标**：JPEG/PNG/TIFF，不超过20cm×20cm
2. **声音商标**：MP3/WAV，不超过5MB
3. **动态多媒体**：MP4（H.264/H.262），不超过20MB
4. 中国申请人在提交声音/动态商标前应确认原属局支持相应格式

### 名称地址填写
1. 中国申请人须提供中文名称 + 拉丁字母音译
2. 法律实体须使用正式全称，不可使用简称
3. 通讯地址须完整（街道、城市、国家）

### 驳回应对
1. 驳回通知中不应附送证据材料
2. 需关注驳回的具体法律依据
3. 如涉及在先权利冲突，尽快获取在先权利信息

### 注册号规则
1. 分割注册 → 原注册号 + 大写字母后缀
2. 合并注册 → 被合并注册号 + 大写字母后缀
3. 代理师在处理转让和分割时需注意注册号的追踪

### 缴费方式
1. 推荐开立国际局活期账户，实现自动扣款
2. 支持信用卡在线支付（电子通信系统）
3. 注意瑞士法郎计价及汇率波动
