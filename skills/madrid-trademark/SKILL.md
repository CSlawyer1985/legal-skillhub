# 马德里商标国际注册实务技能

## 一、技能概述

### 1.1 技能定位

本技能面向**中国商标代理师和专利代理师**，提供马德里商标国际注册的全流程实务支持。技能覆盖马德里体系的全部四层法律文件，并整合中国国家知识产权局（CNIPA）的实务操作衔接。

### 1.2 法律层级关系

```
马德里协定（1891/1979） —— 基础条约，18条
        │
        ▼
马德里议定书（1989/2007） —— 现代补充，16条，议定书优先
        │
        ▼
实施细则（2025.11.1生效） —— 操作规则，9章41条+费用表
        │
        ▼
行政规程（2023.2.1生效） —— 日常操作指南，7部分19条
```

本技能以以下六份官方文件为法律基础：
1. **马德里协定**（1979年9月28日修改）—— `references/madrid-agreement.md`

3. **马德里实施细则**（2025年11月1日生效）—— `references/madrid-regulations.md`

## 三、体系概览

### 3.1 马德里联盟

马德里联盟由**马德里协定成员国**和**马德里议定书缔约方**共同组成。需注意，马德里体系存在三种不同的"数量"口径，实务中极易混淆，必须区分清楚：

| 口径 | 当前数值 | 含义 | 数据基准 |
|------|:--------:|------|---------|
| **缔约方（成员）数** | **116 个** | 加入马德里体系的政治实体（含 3 个政府间组织：欧盟 EU、比荷卢 BX、非洲知识产权组织 OAPI） | WIPO 成员页面 /《Madrid Yearly Review 2026》，最新成员：格林纳达（2025-12-15 交存，2026-03-15 生效） |
| **可指定缔约方数** | **≈118 个** | WIPO 规费计算器（Fee Calculator）等工具中可勾选的"指定项"总数 = 116 个成员 + 可被单独指定的属地（如荷兰王国下属的阿鲁巴 AW、库拉索 CW、圣马丁 SX 等） | 实时工具枚举口径，随属地指定状态浮动 |
| **覆盖国家/地区数** | **132 个** | 在 116 个成员项下可实际获得商标保护的国家/地区（EU 成员 27 国、OAPI 成员 17 国等合并计入） | WIPO 成员页面 |

> **关键说明**：
> 1. 全部 116 个成员**均为《马德里议定书》缔约方**（议定书已成为管辖条约，已无纯协定成员）。
> 2. **中国（CN）指定不延伸至香港、澳门**——香港、澳门不是马德里可指定缔约方，须通过单一国家/地区途径申请。

### 3.2 中国在马德里体系的地位

- 中国同时加入**马德里协定**和**马德里议定书**
- 中国同时加入马德里协定与议定书；指定中国的国际注册依**议定书**产生效力（中国为议定书缔约方，保护期、驳回期、规费均按议定书规则，见议定书第6条），故中国相关实务优先适用议定书框架
- 中国国家知识产权局（CNIPA）作为**原属局**和**指定局**

### 3.3 协定与议定书核心差异

| 对比项 | 马德里协定 | 马德里议定书 |
|--------|-----------|-------------|
| 保护期限 | **20年** | **10年** |
| 基础要求 | 须有已注册的国家商标 | 允许以国家**申请**为基础 |
| 驳回期限 | **12个月** | **18个月**（异议可延长） |
| 规费制度 | 仅补充费（固定） | 可选择**单独规费** |
| 成员资格 | 仅限国家 | 国家 + **政府间组织** |
| 转化救济 | 无 | **第9条之五**：可转为国家申请 |

## 四、国际注册申请

### 4.1 申请资格

满足以下**连接条件**之一：
1. 在中国（原属国）设有**真实有效工商营业所**
2. 在中国境内有**住所**
3. 为中国**国民**

### 4.2 基础要求

| 情形 | 基础 |
|------|------|
| 仅适用议定书的国家 | 中国商标**申请**即可 |
| 仅适用协定的国家 | 须有中国**注册商标** |
| 同时适用两者 | 以议定书为准，中国商标申请即可 |

### 4.3 申请流程

```
Step 1: 申请人在中国提交基础商标申请/获得注册
           │
           ▼
   🔴 CHECKPOINT：确认基础申请/注册信息（申请人名称、地址、商品/服务范围）
           │
           ▼
Step 2: 申请人通过 CNIPA（原属局）提交马德里国际申请
           │
           ▼
   🔴 CHECKPOINT：确认指定国清单、商品服务分类、规费计算无误
           │
           ▼
Step 3: CNIPA 审查申请文件合规性后转交国际局
           │
           ▼
   🔴 CHECKPOINT：国际局须在 CNIPA 收到申请之日起 **2个月内** 收到申请，才能保留原属局收到日作为注册日（议定书第3条(4)）。超期则以国际局实际收到日为准 → 尽早催促转交
           │
           ▼
Step 4: WIPO 国际局进行形式审查
           │
           ▼
   🔴 CHECKPOINT：收到国际局不规范通知后 → 3个月内补正，否则视为放弃
           │
           ▼
Step 5: 国际注册日确定 → 在国际注册簿注册
           │
           ▼
Step 6: 国际局通知各指定局（各缔约国）
           │
           ▼
Step 7: 各指定局在法定期限内决定是否给予保护
           │
           ▼
   🔴 CHECKPOINT：监控各指定局12/18/25个月驳回期 → 到期未驳回则获得保护
```

### 4.4 申请文件要求

**必需内容：**
- 申请人名称和地址（中文+拉丁字母音译）
- 商标图样（JPEG/PNG/TIFF，不超过20cm×20cm）
- 商品和服务清单（按**尼斯分类**归类）
- 指定缔约方
- 基础申请/注册的日期和号码
- 规费计算

**可选内容：**
- 颜色主张（需声明并附彩色图样）
- 声音商标（MP3/WAV，不超过5MB）
- 动态多媒体商标（MP4，H.264/H.262，不超过20MB）
- 代理人信息

### 4.5 国际注册日确定

- **一般规则**：原属局收到申请之日
- **例外**：如国际局在原属局收到日后**超过2个月**才收到，以国际局收到日为准

### 4.6 商品和服务分类规则

- 须按尼斯分类 **第13版（NCL13-2026，2026年1月1日生效）** 进行分类。**注意**：NCL 版本每年1月1日可能更新，实务中请以 MGS 数据库显示的当前版本为准
- 商品和服务名称须使用 **WIPO 标准化表述**（通过 MGS 工具查询验证，见 §4.8）
- 超过3个类别的，每增加一类需缴纳**附加费**
- 分类不规范时，国际局将通知补正，须在 3 个月内按标准化表述修改

> **分类审查权威细则**：国际局对商品/服务清单的分类审查政策（实施细则第12条「分类错误」与第13条「名称不规范」、分类一般原则、可接受性标准、格式句法、依职权修改、特定商品分类及34项常见不规范速查）详见官方《马德里体系国际申请商品和服务分类审查指南（第五版，2026年）》—— `references/madrid-goods-services-classification-guide.pdf`，配套可直接检索的提炼版见 `references/madrid-goods-services-classification.md`。该指南为 §4.7 异常场景与 §4.8 MGS 工具提供底层规则依据；**指南不高于尼斯分类，冲突以尼斯分类为准**。

### 4.7 申请异常场景与 fallback

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 原属局指出商品服务范围超基础 | 删减超范围项目，重新提交 | 将超范围项目单独提中国申请，后通过后期指定追加至国际注册 |
| 国际局通知分类不规范 | 3个月内按 WIPO 接受的标准化表述重新分类 | 未纠正 → 国际局自行分类，保护范围可能缩窄 |
| 原属局超过 2 个月未转交 | 立即催促原属局转交 | 注册日以国际局实际收到日为准，原属局收到日的优先权丧失 |
| 规费不足 | 收到通知后 3 个月内补缴差额 | 未补足 → 申请视为放弃，已缴部分退回（扣除手续费） |
| 申请人与基础不一致 | 核实基础申请/注册的申请人信息，保持一致 | 无法修正 → 国际局退回申请 |
| 商标图样格式不合格 | 按行政规程第 11 条之二调整：JPEG/PNG/TIFF ≤20cm×20cm；声音 MP3 ≤5MB；动态 MP4 ≤20MB | 格式持续不合规 → 申请日起算受影响 |

### 4.8 MGS 商品/服务核实工具

**MGS**（Madrid Goods & Services Manager）是 WIPO 官方提供的商品和服务标准化术语数据库，用于核实马德里国际注册申请中使用的术语是否为 WIPO 接受的标准化表述。

**工具网址**：https://webaccess.wipo.int/mgs/

**当前版本**：**NCL13-2026**（尼斯分类第 13 版，2026 年生效）

**功能说明：**

| 模式 | 操作方式 | 适用场景 |
|------|---------|---------|
| **BROWSE**（浏览） | 选择类别编号，浏览该类中所有 WIPO 验证的标准化术语 | 需要完整了解某类别涵盖哪些可接受术语 |
| **SEARCH**（搜索） | 输入关键词，查找包含该关键词的标准化术语 | 需要确认某具体商品/服务的标准化表述 |

**语言支持**：页面右上角下拉菜单可选择界面语言，术语本身以英文为主并支持多语种对照。

**使用 MGS 的必要性：**

1. **避免不规范通知**：使用非标准化术语会导致国际局发出不规范通知（Irregularity Notice），要求在 3 个月内补正，否则影响注册日
2. **注册日的风险**：不规范通知可能导致注册日以补正日计算，丧失优先权
3. **对接 CNIPA 审查**：CNIPA 在审查马德里申请时会核查商品/服务是否为标准化表述

**实务操作流程：**

```
开列商品/服务清单（按类别分组）
           │
           ▼
逐项访问 MGS (https://webaccess.wipo.int/mgs/)
           │
           ├── 已知类别 → 使用 BROWSE 按类查找
           │
           └── 具体商品 → 使用 SEARCH 输入关键词
           │
           ▼
   🔴 CHECKPOINT：逐项确认每一项的标准化表述是否与 MGS 一致
           │
           ▼
记录 MGS 中的标准化英文表述 → 按类别填入马德里申请书（MM2 表格）
           │
           ▼
提交前二次核对：每项商品/服务表述必须与 MGS 完全一致
```

> **提示**：当用户要求查询某商品/服务的标准化表述时，可直接引导用户访问 MGS 网站，或通过 WebSearch 搜索 WIPO MGS 数据库获取当前可接受术语。

**马德里分类服务台（MCH / Madrid Classification Helpdesk）**：对尚未在尼斯《字母顺序表》、Madrid Monitor 或 MGS 中体现的**新、新兴商品和服务**，国际局设 MCH 提供专家分类指导（依据《分类审查指南》审查，决定须与尼斯分类一致，冲突以尼斯分类为准）。提交途径为马德里体系网页"联系我们"在线表单。详见 `references/madrid-goods-services-classification.md` §十。

### 4.9 Madrid Monitor（国际注册状态查询工具）

**Madrid Monitor** 是 WIPO 官方提供的马德里商标国际注册状态实时查询系统，用于追踪已提交或已注册的马德里商标的当前状态、指定国保护情况和驳回答复期限。

**工具网址**：https://www3.wipo.int/madrid/monitor/en/

**支持查询方式：**

| 查询方式 | 操作入口 | 适用场景 |
|---------|---------|---------|
| **By number**（按注册号） | 直接输入国际注册号 | 已知注册号后快速定位 |
| **By trademark**（按商标名称） | 输入商标文字 | 查询某一商标的所有国际注册 |
| **By holder**（按注册人） | 输入注册人名称 | 查询某注册人名下全部国际注册 |

**可获取的信息：**

| 信息类别 | 内容说明 |
|---------|---------|
| **注册基础信息** | 国际注册号、注册日、到期日、注册人、代理人 |
| **商标图样与细节** | 商标图样、颜色主张、保护类别（尼斯分类） |
| **指定国状态** | 各国保护状态（已保护/临时驳回/驳回答复期限/驳回终局） |
| **后期指定** | 所有后期指定的国家和日期 |
| **变更记录** | 变更、转让、续展、许可等后续管理历史 |
| **期限信息** | 各指定国的驳回期限截止日和当前状态 |

**实务操作流程：**

```
客户要求查询商标国际注册状态
           │
           ▼
   🔴 CHECKPOINT：确定查询条件（注册号/商标名称/注册人名称）
           │
           ▼
访问 Madrid Monitor (https://www3.wipo.int/madrid/monitor/en/)
           │
           ├── 有注册号 → 使用 By number 直接输入号码
           │
           ├── 有商标名 → 使用 By trademark 输入文字
           │
           └── 查全案状态 → 使用 By holder 输入注册人
           │
           ▼
   🔴 CHECKPOINT：逐一核查各指定国状态：
       ① 是否有"Provisional refusal"（临时驳回）→ 确认答复截止日
       ② 是否"Protected"（已获得保护）→ 确认保护范围
       ③ 是否有驳回终局 → 评估后续策略
       ④ 续展到期日是否临近 → 安排续展计划
           │
           ▼

```

> **实务提示**：Madrid Monitor 的数据具有官方效力，与 WIPO 国际注册簿实时同步。建议在以下节点主动使用 Madrid Monitor 查询：① 提交国际申请 3-6 个月后核查状态；② 各指定国驳回期截止前后；③ 收到国际局转发的驳回通知后确认详情；④ 续展到期前 6 个月核查。

## 五、驳回与异议

### 5.1 驳回期限

| 情形 | 期限 |
|------|------|
| 协定国家 | **12个月** |
| 议定书国家（一般） | **18个月** |
| 议定书国家（含异议） | 最长约**25个月**（18个月+7个月） |

### 5.2 驳回理由

**绝对理由：**
- 缺乏显著性
- 具有功能性
- 违反公序良俗
- 欺骗性描述
- 违反法律禁止性规定

**相对理由：**
- 与在先商标权利冲突
- 与他人其他在先权利冲突
- （驳回通知中应简要说明在先权利及其权利人）

### 5.3 驳回应对策略

#### Step 1: 收到通知 → 分析驳回理由

```
收到国际局转发的临时驳回通知
           │
           ▼
   🔴 CHECKPOINT：确认通知日期、答复截止日（按指定国国内法计算）
           │
           ▼
分析驳回理由和法律依据
           │
           ├── 绝对理由 → 准备法律论证或限制性修改
           │
           └── 相对理由 → 收集在先权利信息，评估和解或争辩策略
           │
           ▼
   🔴 CHECKPOINT：在答复截止日前至少留出2周 → 若不足2周立即申请延期（如该国允许）
           │
           ▼
在指定局规定的期限内提交答复
           │
           ▼
   🔴 CHECKPOINT：答复后跟踪指定局状态 → 如3个月无回音，询问进展
           │
           ▼
如最终被驳回 → 在各国法定期限内：
  1. 申请复审/上诉（依各国法律）
  2. 缩减商品/服务范围后重新指定
  3. 放弃该指定国
  4. 如该国有异议程序 → 评估和解或撤回指定
```

#### Step 2: 异常场景及 fallback

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 指定局驳回通知未说明具体理由 | 请求国际局要求指定局补充理由（不规范驳回 → 视为未提出） | 申请人在指定局规定期限内请求明确理由 |
| 答复时限不足（非工作日造成） | 按行政规程第5条申请顺延至下一个工作日 | 在到期日前至少提前5个工作日提交答复 |
| 指定局同时对多个类别发出驳回 | 逐类分析：对可争辩的类别提交答复，对难以争辩的类别先放弃 | 保留争议最小类别，放弃高争议类别 |
| 在先权利人提出异议 | 评估和解可能性（共存协议/限制商品范围） | 异议无法解决 → 放弃该指定国，转为单独国家申请 |
| 指定局审查员认定混淆可能性 | 提交市场共存证据、消费者认知调查、差异化使用证据 | 限缩商品描述，增加区分性限定语 |

### 5.4 驳回通知内容规范（行政规程第15条）

驳回通知应包含：
1. **具体驳回理由**
2. 涉及的法律依据
3. 如涉及在先权利冲突，指明在先权利及其权利人
4. **不得包含**案卷或证据附文

### 5.5 异议程序（Opposition）

> **关键区分**：异议（Opposition）与临时驳回（Ex Officio Refusal）是**两种不同程序**。临时驳回由指定局审查员依职权发出；异议由**第三方**向指定局提出。国际局不参与异议实质审理，仅负责延长驳回期限。

**异议对驳回期的影响：**

```
指定局收到国际局通知
       │
       ▼
18个月基本驳回期（议定书国家）
       │
       ├── 审查员主动驳回 → 18个月内发出通知
       │
       └── 第三方提出异议 → 最长可延至约25个月
                              （18个月+7个月异议期）
```

**异议程序特点：**

| 事项 | 说明 |
|------|------|
| 提出主体 | 第三方（在先权利人、利害关系人） |
| 审理机构 | 各指定国商标主管机关（非WIPO） |
| 法律依据 | 各指定国国内法（非马德里统一规则） |
| 延长期限 | 18个月基本期 + 最长7个月异议期 ≈ 25个月 |
| 国际局角色 | 仅转发期限延长通知，不参与审理 |

**异议应对策略：**

``` 
收到异议通知（通过指定局转交）
       │
       ▼
   🔴 CHECKPOINT：确认异议截止日（按指定国国内法计算）
       │
       ▼
       评估异议理由
       │
       ├── 共存可能性 → 与异议方协商共存协议
       │   （限制商品范围/附加区分标识）
       │
       ├── 异议理由不成立 → 提交争辩意见
       │   （举证市场共存/使用证据/不混淆证据）
       │
       └── 异议风险高 → 评估放弃该指定国的成本
       │
       ▼
   如异议无法解决：
     ① 放弃该指定国，转为单独国家申请
     ② 缩减商品/服务范围后重新指定
     ③ 如指定国允许，申请分割（将争议类别与非争议类别分离）
       │
       ▼
   🔴 CHECKPOINT：在指定局规定的异议答复期限内提交答辩或和解方案
```

**异议与临时驳回的区别：**

| 对比项 | 临时驳回（Ex Officio Refusal） | 异议（Opposition） |
|--------|-------------------------------|-------------------|
| 发起方 | 指定局审查员 | 第三方 |
| 理由类型 | 绝对理由为主（显著性、功能性等） | 相对理由为主（在先权利冲突） |
| 基本期限 | 18个月（议定书） | 18个月 + 异议延长 |
| 最长时限 | 18个月 | 约25个月 |
| 应对方式 | 法律论证/限制性修改 | 和解/争辩/放弃指定 |
| 和解可能性 | 低（审查员受法律约束） | 高（可与第三方协商共存） |

> **实务提示**：收到异议通知后，**首先确认异议方身份和理由**。多数异议基于在先商标权利冲突，可通过限制商品范围或取得共存同意书解决。直接放弃指定国应是最后选项。

## 六、续展

### 6.1 续展基本规则

| 项目 | 协定国家 | 议定书国家 |
|------|---------|-----------|
| 保护期 | **20年** | **10年** |
| 每次续展保护期 | 20年 | 10年 |
| 续展要求 | 不得修改注册现状 | 不得修改注册现状 |
| 宽限期 | 6个月（加收附加费） | 6个月（加收附加费） |

### 6.2 续展费用

- **续展基本费**：653 CHF（电子申请）
- **续展附加费**（第4类起每类）：100 CHF
- **续展补充费**（每指定一国）：100 CHF
- **单独规费**（如有）：各指定国自定
- **宽限期附加费**：续展应缴总额的**50%**

### 6.3 续展操作要点

1. **提前6个月**可缴纳续展费
2. 可**部分续展**（仅续展部分商品/服务）
3. 宽限期内续展需多缴**50%附加费**
4. 续展登记日为**应续展之日**（即使在宽限期内缴纳）
5. 续展后国际局发放**续展注册证**并通知各指定局

## 七、变更与后续管理

### 7.1 变更类型

| 变更类型 | 提交方式 | 说明 |
|---------|---------|------|
| 注册人名称/地址变更 | 通过原属局或直接向国际局 | 须提供变更证明 |
| 商品和服务删减 | 通过原属局，或直接向国际局 | 不可增加，仅可删减 |
| 部分放弃（Renunciation） | 通过原属局，或直接向国际局 | 放弃在指定国的部分或全部保护 |
| 所有权变更（转让） | 通过原属局或直接向国际局 | 受让人须具备申请资格 |
| 分割 | 通过原属局 | 子注册=原注册号+大写字母 |
| 合并 | 通过原属局 | 使用被合并注册号+大写字母 |

### 7.2 注册号规则（行政规程第16-18条）

| 操作 | 新注册号规则 |
|------|-------------|
| 分割 | 原号 + 大写字母（A/B/C...） |
| 部分转让 | 原号 + 大写字母 |
| 合并 | 被合并注册号 + 大写字母 |
| 驳回/无效后的变更 | 原始注册号 + 大写字母 |

### 7.3 中心攻击（Central Attack）应对

**中心攻击原理：**
- 国际注册在**5年内**依赖于基础注册/基础申请
- 如基础注册被撤销/无效，国际注册随之失效
- 5年后国际注册完全独立

**应对策略：**

```
基础注册被撤销/无效
           │
           ▼
   🔴 CHECKPOINT：确认国际注册是否仍在5年依赖期内
           │
           ├── 已满5年 → 国际注册独立，不受影响 ✅
           │
           └── 未满5年 → 进入转化程序
           │
           ▼
   Step 1: 确认基础注册撤销/无效的正式生效日期
           │
           ▼
   🔴 CHECKPOINT：从生效日起算3个月倒计时 → 设日历提醒
           │
           ▼
   Step 2: 识别哪些指定国是议定书缔约方（可转化）
           │
           ▼
   🔴 CHECKPOINT：纯协定国家不可转化 → 单独评估该国保护策略
           │
           ▼
   Step 3: 为每个可转化的指定国准备转化申请文件
           │
           ▼
   Step 4: 在3个月内直接向各指定局提交转化申请
           │
           ▼
   Step 5: 跟踪各指定局对转化申请的处理结果
           │
           ▼
   🔴 CHECKPOINT：转化后 → 转化后的国家申请享有原国际注册日和优先权日
```

**转化要求**（议定书第9条之五）：
1. 基础注册在5年内被撤销
2. 相关指定国为**议定书缔约方**
3. 在**3个月**内向各指定局提出
4. 转化后的申请享有**原国际注册日**和**优先权日**

**转化异常场景及 fallback：**

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 基础注册在5年后被撤销 | 国际注册已独立，不受影响 — 无需转化 | — |
| 指定国为纯协定国家（非议定书缔约方） | 议定书第9条之五不适用 → 在该国转为直接国家申请，请求保留原注册日 | 如该国不允许保留原日，则重新提交该国申请 |
| 错过3个月转化期限 | 立即提交转化申请并说明迟延理由（部分国家允许酌情接受） | 转为常规国家申请，丧失原国际注册日优先权 |
| 转化后指定局要求提交翻译/认证文件 | 在指定局规定的期限内补交 | 转化申请可能被退回，恢复原国际注册日的主张失效 |
| 转化申请的商品/服务范围超出原国际注册范围 | 按基础注册"原样"限定转化范围 | 超范围部分须另行单独提交国家申请 |

### 11.1 规费计算器

```python
"""

用法: python madrid_fee.py --countries US,JP,KR --classes 8 --mode electronic
提示: 也可使用 WIPO 官方 Fee Calculator 在线计算:
      https://madrid.wipo.int/feecalcapp/
"""

def calculate_madrid_fee(countries: list[str], num_classes: int,
                         mode: str = "electronic", renewal: bool = False,
                         late: bool = False, later_designation: bool = False) -> dict:
    """
    参数:
        countries: 指定国ISO代码列表, e.g. ["US","JP","KR"]
        num_classes: 商品/服务类别数
        mode: "electronic" | "paper"
        renewal: True=续展, False=新申请
        late: True=宽限期续展（加收50%）
        later_designation: True=后期指定（基本费按300 CHF计）
    返回:
        dict 含各费用项及合计
    """
    # 基本费
    base_fee_map = {
        ("electronic", False): 653,
        ("paper", False): 903,
        ("electronic", True): 653,
        ("paper", True): 903,
    }
    if later_designation:
        base = 300  # 后期指定基本费
    else:
        base = base_fee_map[(mode, renewal)]

    # 附加费（超过3类后每类100 CHF）
    surcharge = max(0, num_classes - 3) * 100

    # 补充费：每指定一国 100 CHF（仅适用于协定国家）
    # 注意：本估算假设指定国均为协定国或未启用单独规费；

    supp_fee = len(countries) * 100

    subtotal = base + surcharge + supp_fee
    late_penalty = 0
    if late:
        late_penalty = subtotal * 0.5  # 宽限期加收50%

    total = subtotal + late_penalty

    return {
        "基本费": base,
        "附加费": surcharge,
        "补充费(暂估)": supp_fee,
        "小计": subtotal,
        "宽限期附加费(如有)": late_penalty,
        "合计 CHF": total,
        "说明": "补充费按100 CHF/国估算；实际单独规费请查询WIPO官网或使用联网搜索"
    }
```

### 11.2 驳回期限计算器

```python
"""
马德里驳回期限计算器
用法: python madrid_deadline.py --register 2026-01-15 --country JP --opposition true
"""

from datetime import datetime, timedelta
import calendar

def calculate_refusal_deadline(registration_date: str, country_type: str,
                               has_opposition: bool = False) -> dict:
    """
    参数:
        registration_date: 国际注册日 (YYYY-MM-DD)
        country_type: "agreement" (协定国家, 12个月)
                    | "protocol" (议定书国家, 18个月)
        has_opposition: 是否涉及第三方异议且该国已依议定书第5条(2)(c)作出延长声明（仅议定书国家适用）
    返回:
        dict 含基本驳回期、截止日、剩余天数等
    """
    reg_date = datetime.strptime(registration_date, "%Y-%m-%d")

    if country_type == "agreement":
        base_months = 12
    elif country_type == "protocol":
        base_months = 18
    else:
        raise ValueError("country_type 须为 'agreement' 或 'protocol'")

    # 计算基础驳回截止日
    # 马德里细则第17条 / 协定第5条 / 议定书第5条(2)(b)：
    # 12/18个月期自「国际注册日」起算（国际局向指定局发出通知视为注册日发出），
    # 不取"注册月1号"，否则会少算最多约30天
    deadline_months = base_months
    # 异议延长（议定书第5条(2)(c)）：仅当该国作出该声明且本案确有第三方异议时适用
    extra_months = 7 if (country_type == "protocol" and has_opposition) else 0

    def add_months(source_date, months):
        month = source_date.month - 1 + months
        year = source_date.year + month // 12
        month = month % 12 + 1
        day = min(source_date.day, calendar.monthrange(year, month)[1])
        return datetime(year, month, day)

    base_deadline = add_months(reg_date, deadline_months)
    max_deadline = add_months(reg_date, deadline_months + extra_months)

    today = datetime.now().replace(hour=0, minute=0, second=0, microsecond=0)
    remaining_base = (base_deadline - today).days
    remaining_max = (max_deadline - today).days

    # 状态判断：以最迟截止日为准（异议延长情形下，basic expired ≠ final expired）
    if remaining_max <= 0:
        status_label = "最迟驳回期已过 ✅"
    elif remaining_base <= 0:
        status_label = "基本驳回期已过，异议延长中 ⏳"
    else:
        status_label = "仍在驳回期内 ⏳"

    return {
        "国际注册日": registration_date,
        "起算日(国际注册日)": registration_date,
        "基本驳回期(月)": base_months,
        "基本驳回截止日": base_deadline.strftime("%Y-%m-%d"),
        "基本驳回剩余天数": max(0, remaining_base),
        "异议延长(月)": extra_months,
        "最迟驳回截止日": max_deadline.strftime("%Y-%m-%d"),
        "最迟驳回剩余天数": max(0, remaining_max),
        "当前状态": status_label
    }
```

### 11.3 续展提醒

```python
"""
马德里国际注册续展提醒
用法: python madrid_renewal.py --register 2016-07-01 --countries CN,US,JP
"""

from datetime import datetime, timedelta

def check_renewal_status(registration_date: str, protection_years: int = 10):
    """
    参数:
        registration_date: 国际注册日 (YYYY-MM-DD)
        protection_years: 10 (议定书国家) 或 20 (协定国家)
    返回:
        dict 含续展相关日期、当前阶段、状态提示
    """
    reg = datetime.strptime(registration_date, "%Y-%m-%d")

    # 到期日
    expiry = reg.replace(year=reg.year + protection_years)
    # 提前续展开始日（到期前6个月）
    early_start = expiry - timedelta(days=182)
    # 宽限期截止日（到期后6个月）
    grace_end = expiry + timedelta(days=182)

    today = datetime.now().replace(hour=0, minute=0, second=0, microsecond=0)

    if today < early_start:
        phase = "正常期"
        days_to_early = (early_start - today).days
        tip = f"距可提前续展还有 {days_to_early} 天"
    elif early_start <= today <= expiry:
        phase = "提前续展期 ✅"
        days_left_expiry = (expiry - today).days
        tip = f"可续展！距到期还有 {days_left_expiry} 天"
    elif expiry < today <= grace_end:
        phase = "宽限期 ⚠️"
        days_left_grace = (grace_end - today).days
        tip = f"宽限期中！需缴纳50%附加费，还剩 {days_left_grace} 天"
    else:
        phase = "已过期 ❌"
        tip = "注册已失效，不可恢复。如需保护须重新申请"

    return {
        "注册日": registration_date,
        "保护期(年)": protection_years,
        "到期日": expiry.strftime("%Y-%m-%d"),
        "提前续展开始日": early_start.strftime("%Y-%m-%d"),
        "宽限期截止日": grace_end.strftime("%Y-%m-%d"),
        "当前阶段": phase,
        "提示": tip
    }
```

## 十三、常见问题（FAQ）

### Q1: 中国申请人是否必须先获得中国商标注册才能申请马德里？
> 不需要。如果指定国均为议定书成员，仅凭中国商标**申请**即可；如果指定国中有纯协定成员，则需中国**注册商标**为基础。

### Q2: 马德里国际注册的保护期是多久？
> 取决于指定国：根据**议定书**为10年，根据**协定**为20年。续展后保护期分别相应延长。

### Q3: 什么是"中心攻击"？如何应对？
> 国际注册前5年依赖于基础注册/申请。如基础被撤销，国际注册随之失效。应对方式：通过**议定书第9条之五**在3个月内将国际注册转化为各指定国的国家申请。

### Q4: 驳回期限如何计算？
> 协定国家：**12个月**；议定书国家：**18个月**；议定书国家（有异议）：最长约**25个月**。如指定局在规定期限内未通知驳回，商标在该国视为获得保护。

### Q5: 可以在国际注册后增加指定国吗？
> 可以，通过**后期指定**（Subsequent Designation）程序。后期指定须在数据库的录入时限为**3个工作日**。

### Q6: 马德里国际注册费用如何计算？
> 费用 = 基本费（653 CHF电子申请）+ 附加费（超过3类商品/服务，每类100 CHF）+ 补充费（每指定一国100 CHF，协定国家）/ 单独规费（由指定国自定）。

### Q7: 续展可以在什么时候办理？
> 可在到期前**6个月**内办理。到期后仍有**6个月宽限期**，但需缴纳50%的宽限期附加费。

### Q8: 中国申请人名称使用中文，如何在马德里申请中填写？
> 须同时提供**中文名称**和**拉丁字母音译**（拼音）。地址须完整包含街道、城市和国家。

### Q9: 国际注册能在多个国家之间转让吗？
> 可以。转让后的受让人须具备申请资格。所有权变更登记后，各指定局有**18个月**通知期决定是否拒绝承认转让效力。

### Q10: 马德里国际注册与欧盟商标（EUTM）关系？
> 欧盟是马德里议定书缔约方。可以通过马德里国际注册指定欧盟，也可以通过后期指定延伸至欧盟。EUTM申请可以作为马德里申请的基础。

### 16.1 申请阶段的反模式

| # | 反模式（不要做） | 什么情况下触发 | 正确做法 |
|---|----------------|--------------|---------|
| 1 | **商品服务描述直接翻译中文名称** | 提交的商品项目使用CNIPA的中文表述直接译成英文 | 使用WIPO接受的标准化表述（Madrid Goods & Services Database） |

|---|----------------|--------------|---------|
