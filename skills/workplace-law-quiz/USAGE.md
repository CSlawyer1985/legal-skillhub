# 使用指南 · 职场法律常识测验（弹窗问答｜检测报告）

## 安装（多客户端）
复制本文件夹到对应客户端的 skills 目录：
- WorkBuddy：`~/.workbuddy/skills/`
- Claude：`~/.claude/skills/`
- Cursor：`~/.cursor/skills/`
- 其他兼容客户端：放置于各自 `skills/` 目录

## 使用步骤
1. 对话中说"职场法律测验 / 劳动法常识 / 测测法律常识"
2. 逐题作答（其他客户端回选项字母）
3. 即时得到判分与法条要点
4. 结束得到总分与常识盲区方向
5. 可选：导出 MD 报告

## 注意
- 结果为**普法自查参考，不构成法律意见**；个案请咨询律师/仲裁。
- 具体适用以最新法规及当地规定为准。
