# 财税合规报告生成技能

## 技能描述

本技能专门用于根据企业的财务数据（序时账、发票数据、资产负债表、利润表等），自动生成财税合规分析报告（Word + Excel格式），识别税务风险点，提供合规建议。

**适用场景**：
- 年度财税合规审计
- 税务稽查应对准备
- 企业财税健康检查
- 出具财税顾问报告

## 功能特性

### 1. 数据读取与整合
- 读取序时账（Excel）
- 读取进销项发票数据
- 读取资产负债表、利润表
- 读取科目余额表

### 2. 合规风险识别

| 风险类别 | 检查内容 |
|---------|---------|
| 增值税风险 | 销项税额与开票系统比对、进项税额抵扣合规性、税率适用正确性 |
| 企业所得税风险 | 收入确认时点、成本费用扣除凭证、税收优惠适用 |
| 个人所得税风险 | 工资薪金扣缴、股东借款、福利费列支 |
| 发票管理风险 | 发票开具规范性、发票取得真实性、红字发票管理 |
| 账务处理风险 | 科目使用正确性、往来科目清理、固定资产折旧 |
| 财务报表风险 | 表间勾稽关系、数据一致性、异常波动 |

### 3. 双格式输出

**Excel报告**：
- 合规风险清单（按风险等级排序）
- 税务指标计算表
- 调整分录建议
- 合规时间计划表

**Word报告**：
- 报告摘要
- 企业基本情况
- 财税合规总体评价
- 具体风险事项说明
- 整改建议与时间计划
- 附件（计算过程、法规依据）

## 合规风险检查规则

### 增值税风险检查

| 检查项 | 判断规则 | 风险等级 |
|--------|---------|---------|
| 销项税额异常 | 销项税额 ÷ 不含税销售额 < 适用税率 × 0.95 | 🔴 高 |
| 进项税额异常 | 进项税额 ÷ 不含税采购额 > 适用税率 × 1.05 | 🔴 高 |
| 税负率异常 | 应缴增值税 ÷ 销售收入 < 同行业平均税负率 × 50% | 🟡 中 |
| 发票取得不合规 | 取得发票的销方与付款对手方不一致 | 🔴 高 |
| 红字发票管理 | 开具红字发票但未保留红字信息表 | 🟡 中 |

### 企业所得税风险检查

| 检查项 | 判断规则 | 风险等级 |
|--------|---------|---------|
| 收入确认时点 | 资产负债表日后的收入确认在当期 | 🟡 中 |
| 成本费用扣除凭证 | 大额成本费用无发票或发票不合规 | 🔴 高 |
| 税收优惠适用 | 不符合优惠条件但享受了优惠 | 🔴 高 |
| 关联交易定价 | 关联交易定价明显偏离市场价格 | 🟡 中 |
| 固定资产折旧 | 折旧年限明显短于税法规定 | 🟢 低 |

### 个人所得税风险检查

| 检查项 | 判断规则 | 风险等级 |
|--------|---------|---------|
| 工资薪金扣缴 | 工资表人员与社保名单不一致 | 🟡 中 |
| 股东借款 | 其他应收款-股东 年末余额 > 0 且未归还 | 🔴 高 |
| 福利费列支 | 福利费支出 > 工资薪金总额 × 14% | 🟡 中 |
| 业务招待费 | 业务招待费支出 > 销售收入 × 5‰ 且 > 实际发生额 × 60% | 🟡 中 |

### 修改合规得分计算规则

```python
def calculate_compliance_score(risks):
    """
    计算合规得分（百分制）
    基础分100分，按风险等级扣分
    """
    score = 100
    
    for risk in risks:
        if risk['risk_level'] == '高':
            score -= 10  # 高风险扣10分
        elif risk['risk_level'] == '中':
            score -= 5   # 中风险扣5分
        elif risk['risk_level'] == '低':
            score -= 2   # 低风险扣2分
    
    return max(score, 0)  # 最低0分
```
