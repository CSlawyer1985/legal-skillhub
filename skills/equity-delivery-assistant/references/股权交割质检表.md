> 本表为律师内部工作底稿，不直接替代法律意见或交割文件。
> 本文件是《股权交割质检表.docx》（同名原件存于 `references/股权交割质检表.docx`，为底稿排版参照）的结构化基准版，自技能 v1.3 起作为"第六步：交付前质检"的**唯一内容基准**：跑质检时逐项对照本表，**不得凭记忆增删、改写质检项或降低标准**；质检表更新时只需替换本文件并同步修订第六步引用。

## 二、当前交割状态

请选择一项，并在"状态说明"中写明决定性理由、关键缺口和下一步安排。

| 当前状态 | 状态说明 |
|---------|---------|
| ☐ 已完成交割 | 【　　】 |
| ☐ 附条件完成交割 | 【　　】 |
| ☐ 交割延期或中止 | 【　　】 |
| ☐ 未完成交割 | 【　　】 |
| ☐ 交割存在争议 | 【　　】 |

**状态含义**：
- **已完成交割**：交易文件定义的必要交割事件均已完成，证据形成闭环，不存在未完成的交割日必须完成事项或不可豁免的法定障碍；
- **附条件完成交割**：交易主体交割已完成，但存在经有权主体书面确认且依法可以保留的事项；
- **交割延期或中止**：交割未完成、延期或中止，文件、款项、公司动作或控制权未释放，或已按约定回退；
- **未完成交割**：存在阻断条件、关键证据缺失或交易文件完成标准未达成；
- **交割存在争议**：各方对完成标准、事实、授权、履行情况或法律效果存在实质争议。

## 三、条件状态用语

| 条件状态 | 含义 |
|---------|------|
| 已满足 | 有证据证明条件已经完成 |
| 交割日必须完成事项 | 必须在交割日实际签署、交付、核对、释放或完成；未完成不得宣告已完成交割 |
| 已有效豁免 | 有权主体依交易文件书面豁免，且不属于不可豁免的法定审批、第三人权利或权利限制 |
| 交割后办理事项 | 依法律或交易文件可在交割后完成；应列入交割后跟踪表 |
| 待核 | 证据不足、查询未完成或事实无法确认 |
| 未满足 | 条件未完成或已失败 |
| 不适用 | 经事实说明不适用于本次交易；不得留空 |
