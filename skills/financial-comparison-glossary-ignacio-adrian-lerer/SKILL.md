# 财务对比术语表（Financial Comparison Glossary）

使用本技能以防止财务工具、尽职调查报告、风险筛查、计算器和客户解释中的概念混淆。它是公开/可移植的术语层，而非完整财务模型审计的替代品。

本文件对仅读取 `SKILL.md` 的加载器自成一体。如计算器/模型完整性技能可用，在构建或核实数字时也应使用它们；否则直接应用下述检查。

## 核心规则

不要让精美的界面或备忘录模糊财务类别。如果两个概念不同，就要以不同方式标注，并让模型/报告显示差异。

## 需区分的概念

- `现金流` 对比 `利润`：现金流是现金流入/流出的时点；利润是扣除费用后的会计结果。盈利的模型可能有现金压力；正向现金流并不自动等于已批准的股息。
- `EBIT` 对比 `EBITDA`：EBIT 包含折旧/摊销影响；EBITDA 排除利息、税项、折旧和摊销。EBITDA 不是自由现金流。
- `资本支出（CapEx）` 对比 `运营支出（OpEx）`：CapEx 购置长期资产，在购置时影响现金；OpEx 支持持续运营，影响当期经营业绩。
- `债务` 对比 `股权`：债务有偿还/利息义务；股权共享所有权/风险/上行收益，通常无固定偿还义务。
- `市场价值` 对比 `账面价值`：市场价值反映感知的/当前的价值；账面价值反映会计账面价值。
- `资产` 对比 `负债`：资产创造或保值；负债需要未来清偿。
- `ROI` 对比 `ROE`：ROI 衡量投资/项目的回报；ROE 衡量股东权益上产生的回报。
- `会计` 对比 `金融`：会计记录和报告过去/当前的交易；金融对决策、风险、资本配置和未来价值进行建模。

## 计算器与仪表盘检查

审查模型或仪表盘时，询问：

- EBITDA 是否在无桥接的情况下被呈现为可用现金、股息或价值？如是，重新标注或添加桥接。
- 债务（RF/debt）是否被当作股权收益处理？如是，显示利息、到期日、偿还/拨备和风险。
- 资本支出/资产是否被当作费用处理，而无使用年限或退出？如是，定义购置、运营启动和退出/残值。
- 股息/分配是否在法律、税务、债务、准备金和现金约束之前显示？如是，标注为经济模拟，而非已批准股息。
- 名义价值是否与折现价值混用？如是，两者都显示并标注 WACC/折现率。
- 第三方毛收入是否在公司仅获得佣金/抽成时被显示为公司收入？如是，更正为净佣金。
- 会计拨备、准备金和实际现金支付是否被混为一谈？如是，将留存/储备现金、会计拨备和现金流出分开。

## 面向客户的解释模式

使用此结构：

1. 用一句话定义该术语。
2. 说明它不是什么。
3. 解释该区分为何对决策重要。
4. 指出它在模型中的行/控件位置。

示例：

```text
EBITDA is operating performance before interest, taxes, depreciation and amortization. It is not cash available for distribution, because debt service, reserves, reinvestment and taxes may still reduce cash. In this calculator, EBITDA is an operating metric; cash available and distributions are separate outputs.
```

## 依赖边界

本技能可安全用于公开解释和通用客户交付物。不得包含机密事实、客户特定的谈判策略，或最终的会计、税务、法律或投资建议。
