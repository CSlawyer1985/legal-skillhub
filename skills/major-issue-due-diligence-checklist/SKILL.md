# 法律尽职调查材料核查清单（重大问题提示专用）

> 依据：《【修订版】万源生态股份有限公司法律尽职调查报告（征求意见稿）》及青训营尽调报告文件夹内各项目报告梳理。
> 用途：接到新项目时，按本清单向客户/目标公司/管理人收集材料并自行核查，每项材料直接对应报告正文章节及"重大问题提示"的风险点来源。

---

## 一、"重大问题提示"的写作逻辑（先掌握方法）

万源生态报告的重大问题提示共 14 项，其内在顺序是律师排布风险的典型范式：

1. **程序性风险置顶**——破产重整程序及重整计划表决未通过（决定交易能否做成）
2. **主体与股权**——实控人股份全部质押/冻结＋刑事处罚（决定控制权能否交接）
3. **核心资产瑕疵**——最大单项应收款（行贿中标取得＋未达排放标准，回收需诉讼）
4. **财务可信度（法律视角）**——审计无法表示意见、重大前期差错更正、保留意见+持续经营重大不确定性
5. **外部信用**——被执行/终本/限高、欠税
6. **权利负担**——专利质押/司法保全、体系认证撤销
7. **资质与人员**——核心资质维持（注册建造师配备）、员工骤减、社保公积金合规
8. **一致性核对**——工商登记 vs 公开披露（中登名册）不一致
9. **优惠政策资格**——高新技术企业资格被取消

**每项提示的固定句式**："根据【某材料】+ 经本所律师核查【某官方渠道】→ 事实 → 法律后果 → 对本次交易的影响 → 建议补充核实事项"。材料缺口要如实写明（如"扫描件缺合同条款页""待取得不动产登记查询结果后补充"），这本身就是风险提示的一部分。

## 二、通用材料核查清单（按报告章节）

### （一）主体资格与公司治理
| 材料/核查 | 支撑的重大风险点 |
|---|---|
| 营业执照、工商内档全套（含历次章程及修正案） | 主体资格、历史沿革出资瑕疵（万源案例：章程对实物/货币出资记载前后不一致） |
| 国家企业信用信息公示系统核查 | 年报公示、经营异常、股权出质登记 |
| 董监高名单、工商备案职务 vs 公司实际任职/公开披露（三方比对） | 工商与披露不一致的风险提示 |
| 三会决议、董监高变动情况及委派方 | 治理僵局、委派董事背后的股东关系（国资股东兼质权人） |
| **挂牌/上市公司加查**：中登公司《全体股东名册》《证券质押及司法冻结明细表》、停牌/风险警示公告 | 股权结构认定基准、实控人股份受限、ST/终止挂牌风险 |

### （二）股权与历史沿革
| 材料/核查 | 支撑的重大风险点 |
|---|---|
| 历次增资/股权转让协议＋**验资报告**＋**非货币出资的评估报告、财产权转移证明** | 出资不实、抽逃出资（万源案例：4,000万知识产权出资无评估验资、后以减资核减） |
| 减资的股东会决议＋报纸公告 | 减资程序合规 |
| 受让股权的转让协议及价款支付凭证 | 沿革中"差额"解释（赵仁川受让童才平股权无凭证） |
| 代持核查：承诺函＋访谈＋亲属关系（挂名股东） | 股权代持效力、实控人认定 |
| 出资到位及抽逃出资专项审计（破产/重整场景由管理人委托） | 追缴出资、追责股东 |

### （三）业务资质与行业监管
| 材料/核查 | 支撑的重大风险点 |
|---|---|
| 全部资质证书原件扫描件＋有效期＋换证记录 | 资质过期、被撤销 |
| **资质维持人员**：注册建造师/注册人员名册＋社保缴纳记录＋资质动态核查记录 | "人员流失→资质失效→丧失投标资格"连锁风险（万源案例：公司自述"满配"与此前汇总表"仅3人"矛盾，必须穿透核实） |
| 体系认证证书状态（质量/环境/职业健康安全，认监委网站核查） | 认证撤销影响投标资信 |
| 高新技术企业证书＋取消资格通告核查 | 税率优惠丧失＋资信受损 |
| **串通投标/围标行政处罚查询**（住建部门、信用中国）＋刑事判决核查 | 中标无效、投标资格取消、行贿中标取得的核心合同效力风险（万源最大单项资产即此情形） |

### （四）主要资产
| 材料/核查 | 支撑的重大风险点 |
|---|---|
| 不动产权属证书＋**不动产登记中心查询结果（抵押、查封、限制转让记载）** | 权属负担、划拨地/总部经济用地转让限制 |
| 租赁合同（尤其长期租约、装修投入大的） | "买卖不破租赁"对资产处置的约束、提前解除补偿 |
| 商标/专利/软著：官方检索＋**逐件法律状态**（质押、司法保全、终止、年费、驳回） | 知识产权权利负担、无核心专利（万源案例：60项专利中32项被质押/保全、25项已终止） |
| 域名/ICP备案核查 | 网站合规 |
| 固定资产台账＋评估报告＋实物抽盘 | 账实不符、资产灭失（园林类：苗木灭失） |

### （五）重大合同及债权债务（律师核查重心）
| 材料/核查 | 支撑的重大风险点 |
|---|---|
| **人行《企业信用报告》**（必查！）：未结信贷余额、五级分类、逾期、对外担保、民事判决/强制执行记录 | 债务全貌、隐性担保、不良记录（万源8户未结信贷全为不良） |
| 全部借款合同、融资租赁合同、保理合同**逐份核查** | ①**控制权变更/股权变动/破产申请条款**及违约后果；②提前到期、交叉违约；③**租赁物取回权、约定租赁物不属于破产财产**；④扫描件缺页的补查（万源案例：农商300万借款缺条款页） |
| 对应担保合同（保证/抵押/质押）＋登记情况，注意"债务转移无需保证人同意"等持续性条款 | 担保责任存续、担保登记与合同口径差异 |
| 应收账款台账（分户、账龄、项目状态、结算条款）＋**应收账款质押登记（中登网）** | 应收款回收风险、最大单项资产、质押应收款的实现路径 |
| 其他应收/应付台账、对分公司及关联方往来 | 内部往来真实性、民间借贷未入账 |
| 供应商/客户集中度明细＋建设单位信用核查 | 大额应付的形成原因（万源：单一户占应付近半） |

### （六）诉讼、仲裁、行政处罚
| 材料/核查 | 支撑的重大风险点 |
|---|---|
| 裁判文书网、执行网、终本案件、限制消费令公开核查（企查查等汇总＋官方复核） | 被执行、终本、限高清单 |
| 审计报告披露的未结诉讼清单＋管理人/公司确认 | 或有负债全貌（万源：111件未结诉讼、1.7亿） |
| 行政处罚核查（环保、住建、市监、税务） | 处罚及整改义务 |
| **董监高及实控人刑事判决核查** | 行贿/串通投标犯罪对中标合同效力、投标资格、市场形象的影响 |
| 破产场景：债权申报表、债权审查结果、职工债权确认表、取回权/别除权纠纷 | 债务规模与清偿顺位、未申报债权预留 |

### （七）劳动人事
| 材料/核查 | 支撑的重大风险点 |
|---|---|
| 历年社保参保人数（年报公示）＋社保部门参保证明 | 员工规模骤减反映经营状况（万源：2,033人→47人） |
| 公积金花名册/缴存证明（注意基数是否最低、是否全员） | 未全员未足额缴纳的补缴风险 |
| 欠付薪酬明细＋管理人职工债权确认表 | 职工债权规模、安置安排、职工债权确认口径争议 |

### （八）税务
| 材料/核查 | 支撑的重大风险点 |
|---|---|
| 欠税公告查询（税务局网站） | 欠税及滞纳金 |
| 纳税信用等级 | 投标资信 |
| 高新资格/税收优惠资格核查 | 补税风险（资格取消是否追溯） |

### （九）破产/重整项目专项加查
- 预重整/重整受理裁定、管理人决定书、自行管理许可裁定
- 《重整计划（草案）》及**各表决组表决结果**（未通过时的再次表决/强裁路径）
- 管理人招募重整投资人公告及程序安排（保证金、失权条款）
- 清算状态下清偿率测算 vs 重整清偿率（估值谈判基础）
- 证券端：终止挂牌规则触发情形（财务类/规范类）

## 三、按项目类型加查（结合青训营其他报告）

### 水务/环保（特许经营）
特许经营合同及全部补充协议（特许期表述、保底水量、转让/质押限制、移交条款）、招投标文件、政府欠费对账单与还款协议、排污许可证、污泥处置合同、项目不动产权登记、收费权质押、改制遗留人员安置。

### 科技/医疗（VC/PE）
核心IP权属链条（境外授权的地域/期限/排他性、职务发明、高校成果转化协议）、核心技术人员劳动合同+竞业限制+原雇主核查、历次投资协议中的对赌/回购/特殊权利条款、数据合规（伦理批件、算法备案）、招商承诺函、收入真实性（框架合同 vs 已确认收入）。

### 工业/新能源项目
项目全审批链条（备案≠开工：用地预审、规划许可、环评、水保、施工许可、电网接入）、土地是否仅缴保证金、征迁补偿是否书面化、是否必须招标的定性。

## 四、实务要点

1. **核查方法分层**：官方渠道核查（公示系统、商标局/专利局、执行网、征信中心）→ 现场核验原件（合同、名册、回执）→ 访谈 → 外部比对。结论的可信度取决于核查层级。
2. **材料缺口如实标注**并转化为风险提示＋补充核查建议，不替客户"脑补"。
3. **每个数字都要有出处**：重大问题提示中的金额、比例、期限均须注明来源文件（如"尤振审字[2025]第0677号""中登名册权益登记日2026年7月20日"）。
4. **前后一致性核对是律师价值所在**：工商内档 vs 章程历次版本、公司自述 vs 审计报告、台账 vs 征信报告——万源报告14项提示中至少4项来自"口径打架"。
5. **风险提示与交易文件联动**：控制权变更债权人同意/豁免列为先决条件、陈述与保证＋赔偿条款覆盖未披露诉讼、重整计划中对租赁物继续履行/回购作出安排。
