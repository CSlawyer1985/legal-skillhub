# 专利交底说明书

将任意技术方案按标准 Part A/B/C 骨架自动生成发明专利交底书，输出 .docx 文件。

---

## 安装

将本文件夹完整复制到 `~/AppData/Roaming/LobsterAI/SKILLs/` 目录。

## 功能

自动将技术方案生成符合中国发明专利申请格式的交底书文档，支持两种模式：

1. **有源文档**：已有技术说明文档 → 自动提取内容并重排为标准 Part A/B/C 格式
2. **无源文档**：仅提供技术名称 + 原理 + 场景 → 从零生成完整交底书

### 核心格式

**★ Part A — 通讯信息**：专利名称、类型、发明人、撰写人、联系方式

**★ Part B — 附图图纸**：白底黑线工程图规范 + 8张 `【图片内容描述: ...】` 占位符

**★ Part C — 技术方案**：C1创新点 / C2结构模块 / C3工作流程 / C4技术问题

**补充章节**：有益效果 / 具体实施方式 / 技术边界条件 / 检索关键词 / 应用场景图
