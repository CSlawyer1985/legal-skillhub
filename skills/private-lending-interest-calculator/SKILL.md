# 民间借贷利息计算

## 定位

本 skill 用于民间借贷利息、逾期利息、违约金合并上限、还款冲抵和特殊利率风险测算，属于**计算类 skill**。

命中本 skill 后，必须以 `npx @delilegal/deli-cli@latest` 为默认入口发现和调用当前可用的后端 MCP 计算命令；不得调用法规检索或案例检索命令。稳定规则、LPR 参数口径和法条索引以本 skill 的 `references/` 为准；用户事实必须来自用户或其材料。

---

## 数据源与前置要求

1. **deli-cli 前置检查**：先执行 [deli-cli 通用前置](./references/cli-common.md)，获取当前 `RUN id`、命令名、参数形态和描述。
2. **CLI 场景指南**：按 [民间借贷利息 CLI 场景指南](./references/cli-interest-guide.md) 将用户事实组织为后端计算任务。
3. **稳定规则**：法律适用时段、LPR 四倍、24%/36% 规则、砍头息、复利和冲抵顺序来自 [计算规则](./references/calculation_rules.md) 与 [法律依据索引](./references/legal_basis.md)。
4. **LPR 数据**：本地 [LPR 数据表](./references/lpr_data.md) 可作为稳定参数来源；动态或缺失 LPR 以 CLI 返回或用户官方材料为准。
5. **禁止事项**：不得读取、创建或提示用户配置 skill 目录内旧 `config.json`；不得编造 CLI 未返回或 references 未载明的 LPR、历史基准利率、还款记录、利息金额或裁判口径。

## 工作流程

### 1. 抽取用户事实

先识别计算目标，再抽取必要事实；缺关键事实时只追问缺失项。

| 事实字段 | 说明 |
| --- | --- |
| 实际到账本金 | 利息和上限审查以实际出借金额为基础 |
| 合同载明本金 | 用于识别砍头息或预扣利息 |
| 借款日期 | 用于判断法律适用时段和合同成立时 LPR |
| 借款到期日 | 用于区分借期内与逾期 |
| 截止计算日期 | 用于确定计算终点 |
| 借期内约定利率 | 年化或月利率需统一换算口径 |
| 逾期起算日与逾期利率 | 无约定时需按规则判断 |
| 违约金或其他费用 | 与逾期利息合并审查 |
| 还款记录 | 日期、金额、性质或备注；用于费用、利息、本金冲抵 |
| 复利/结息转本 | 结息日、转本金额、是否重新出具凭证 |
| 2015-09-01 前案件 | 需用户提供银行同期贷款利率或可核验材料 |
| 特殊风险 | 职业放贷、砍头息、展期、自然人利息约定不明等 |

用户只提供合同本金而未说明实际到账金额时，必须追问是否存在砍头息或预扣利息。

### 2. 调用计算能力

完成事实抽取后，按 `cli-common.md` 发现当前 skill scope 的可用命令，再按 `cli-interest-guide.md` 组织参数。

计算类流程固定为：

```text
用户事实
  -> Agent 抽取/追问
  -> npx @delilegal/deli-cli@latest 发现命令
  -> 本地 references 获取稳定规则和参数口径
  -> 后端计算命令返回分段、上限、冲抵、风险
  -> Agent 输出计算书
```

如 CLI 暂不可用或当前 skill scope 未返回可用计算命令，不得自行补算或寻找本地执行入口；应说明计算服务不可用或参数不足，并基于 `references/` 提示用户需要补充的事实或待后端计算确认的字段。

### 3. 生成最终输出

根据用户问题深度，输出可以简洁或完整，但必须包含以下核心项：

| 模块 | 要求 |
| --- | --- |
| 案件事实摘要 | 本金、借款日期、到期日、计算截止日、利率和还款记录 |
| 法律适用 | 1991 旧规、2015 规则或 2020 后 LPR 四倍规则 |
| 分段明细 | 每段期间、计息本金、天数、适用利率、上限、金额 |
| 还款冲抵 | 按费用、利息、本金顺序列明 |
| 合计金额 | 尚欠本金、借期内利息、逾期利息、违约金、费用和总额 |
| 风险提示 | 砍头息、超上限、复利、职业放贷、旧规基准利率缺失等 |

---

## 质量控制

- 计算类 skill 不调用法规检索或案例检索命令。
- LPR、旧规银行同期贷款利率、还款记录和费用必须来自 CLI、用户材料或本地 references。
- 2015-09-01 前案件缺银行同期贷款利率时，不得给出确定金额。
- 逾期利息、违约金和其他费用必须合并审查是否超过保护上限。
- 已还款项必须按费用、利息、本金顺序处理；用户另有明确约定时应提示差异。
- CLI 返回结果与本地 references 口径不一致时，标注差异并建议人工复核。
