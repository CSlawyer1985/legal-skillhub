# 民间借贷利息 CLI 场景指南

适用于 `private-lending-interest-calculator` skill。目标是将用户提供的借贷事实整理为 deli-cli 可执行的利息计算任务，并将返回结果映射为最终计算书。

使用本指南前，必须先执行 [cli-common.md](./cli-common.md) 中的前置检查和命令发现步骤。

## 一、CLI 命令使用原则

1. 先用 `npx @delilegal/deli-cli@latest cmds private-lending-interest-calculator@1.0.0` 获取本次 `RUN id`、命令名和参数。
2. 后续调用必须采用当次返回的 `npx @delilegal/deli-cli@latest run_... <command> [options]` 形态。
3. 不在本指南中固化真实命令名；以下示例中的 `calculate`、`interest-calc`、`loan-calc` 仅表示可能的计算命令类型，实际以 `cmds` 输出为准。
4. 参数优先在 `cmds` 返回的 `usage` 和 `params` 中选择，不主动假设 `--query`、`--semantic`、`--long-text`、`--amount`、`--json` 或结构化字段一定存在。
5. 不调用法规检索或案例检索命令；如果 `cmds` 只返回检索类命令，应停止并说明当前 skill scope 未提供可用计算命令。

示例 `cmds` 返回后，实际调用可能形如：

```bash
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 calculate --long-text "实际到账本金10万元，合同本金11万元，2024年1月1日出借，2024年7月1日到期，借期利率12%，逾期利率18%，违约金折算3%，截至2025年4月20日，期间两笔还款，需要分段计算利息并做冲抵"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 interest-calc --long-text "2014年6月1日民间借贷，本金10万元，年利率18%，截至2015年6月1日，用户提供银行同期贷款年利率6%，需按旧规四倍上限计算"
```

以上仅为参数组织示例。正式执行时必须替换为当次 `cmds` 返回的 `run_...`、命令名和参数。

## 二、用户事实组织

每次 CLI 调用只聚焦一个计算任务。优先按以下字段整理事实摘要：

| 字段 | 写法 |
| --- | --- |
| 本金事实 | 实际到账本金、合同载明本金、是否预扣利息 |
| 时间事实 | 借款日期、到期日、逾期起算日、截止计算日期、展期日期 |
| 利率事实 | 借期内利率、逾期利率、违约金或其他费用折算利率 |
| 还款事实 | 每笔还款日期、金额、备注、是否指定冲抵项目 |
| LPR/旧规参数 | 合同成立时 LPR、旧规银行同期贷款利率、来源 |
| 特殊安排 | 复利、结息转本、职业放贷、债权实现费用 |
| 计算目标 | 尚欠金额、分段明细、冲抵明细、上限审查、风险提示 |

不得把合同载明本金直接视为实际到账本金；不得自行补写还款记录或旧规银行同期贷款利率。

## 三、CLI 结果映射

- `segments` 或等价字段：映射为分段计息明细。
- `repayments`、`allocations` 或等价字段：映射为还款冲抵明细。
- `rate_cap`、`lpr_used`、`regime` 或等价字段：映射为法律适用和上限。
- `totals`、`total_due` 或等价字段：映射为尚欠本金、利息、费用和总额。
- `rule_refs`、`basis`、`articles` 或等价字段：映射为依据来源；未返回时只能引用本地 references 中对应索引。
- `warnings`、`risks`、`assumptions` 或等价字段：映射为风险提示和前提。

CLI 未返回的 LPR、历史基准利率、还款记录、费用、法院口径或额外计算结果不得自行补写。

## 四、后端计算服务边界

发布给 CLI 客户端的 skill 包只包含 `SKILL.md` 和 `references/`。计算逻辑由 CLI 命令调用后端 MCP 计算服务完成，不存在可供 agent 调用的本地计算入口。

调用后端计算服务时：

1. 只使用当次 `cmds` 返回的 `run_...`、命令名和参数形态。
2. 只采纳 CLI 返回的结构化计算字段，例如分段、利率上限、还款冲抵、合计和风险提示。
3. 稳定规则和 LPR 口径以本地 references 或 CLI 返回字段为准。
4. CLI 未返回计算结果或必要字段时，不得自行补算；应说明缺失字段并要求补充事实或等待后端计算服务支持。

## 五、无结果或参数不足

单次调用无结果、计算命令不可用或参数不足时：

1. 明确缺少的事实、LPR/旧规参数或命令能力。
2. 优先追问用户可提供的借贷事实、还款记录或官方参数。
3. 可基于本地稳定规则说明计算口径和所需参数，但不得输出自行补算的确定金额。
4. 不连续换词调用检索命令，也不将检索结果替代计算结果。
