# 引导呈现规范（默认文本模式）

> 本文件由 SKILL.md 按需加载，四阶段引导统一遵循本规范。
> **2026-08-18 定版**：本 Skill 一律使用文本模式呈现，不渲染任何对话内 HTML/SVG 组件。

## 呈现模式（固定文本模式，无检测环节）

**固定文本模式**：所有引导与概念讲解一律用 Markdown 文本呈现，不渲染对话内联 HTML/SVG。

定版原因（2026-08-18 实测）：
1. 对话消息中的内联 HTML 组件在主流对话平台（含 WorkBuddy）不被渲染为组件，呈现不可控；
2. SVG 等对话内渲染兜底效果同样不佳，且拖慢「验证可用」类场景；
3. 文本模式在所有平台行为一致、零渲染风险、速度最快。

**边界（不冲突）**：本规范仅约束「对话内联可视化」。**文件产出可视化不受影响**——诉讼时间轴 PNG 等生成文件照常使用。

**用户随时可调整**：用户说「切换呈现方式」时，可在文本细节上调整（更简洁 / 更详细），不改变文本模式本身。

## 引导呈现规范（可视化词汇，四阶段通用）

1. **进度提示**：每个引导步骤回复开头附进度，格式：`【引导进度 · 阶段1 模板制作 · 步骤③/⑥ 变量化】`
2. **步骤卡结构**：标题 → 说明 → 操作区（选项列表 A/B/C）→ 跳过链接（步骤末尾）
3. **状态徽章**（用于清单与核对表，与置信度标准一致）：✅ 已识别 / ⚠ 待复核 / ❓ 待补充 / ☐ 可选跳过
4. **清单呈现**：分组标题 + 条目行（徽章 + 内容 + 右对齐说明），行间分隔

**交互原则**：每个引导步骤末尾提供跳过/前进选项（"已理解，继续" / "跳过此步骤" / "直接进入模板制作"等），用户可在任意节点选择加速或退出引导流程。选项回复一律在聊天框输入（如：A），组件不做点击交互。

## 彩蛋触发规则（克制，一句收束）

触发即回一句，不打断流程、不弹卡片、不加 emoji。仅以下四处：

| 触发 | 时机 | 回应 |
|------|------|------|
| 「全权代理」 | 处理勾选框 / 授权权限时提到 | 只写"全权代理"而无具体授权的，视为一般代理——这是第 62 条，也是这个 Skill 替您守住的边界。 |
| 「孵化完成」「母版库建成」 | 任意环节输入 | 孵化完成。从此刻起，每一单委托，都不必再从头写文书。 |
| 「零改动」/ 询问格式会否变化 | 任意环节输入 | 零改动，是这个 Skill 的终极目标——连一个空格、一条下划线都不会被碰。 |
| 第一份母版入库 | 里程碑（非输入触发） | 第一份母版入库——母版库有了第一块砖。 |
| 22:00 后仍在建库 | 时间触发（本地时间，仅当天首次） | 夜深了还在建库。母版库不会辜负认真的人。 |
