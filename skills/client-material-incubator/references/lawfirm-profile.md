# 律所画像（所内固定值）

> 一次性采集（阶段0），阶段1/2 自动读取。**只存"全所一致的固定值"**——可随母版库安全分享。
> **随人而变的值**（承办律师、告知人、授权书电话）**不在此文件**——存于本机「终端固定值」，见下方说明。
> **本文件是「空模板」**：律所填写后的实际值存母版库空间 / 本机，**不得回写进 skill 包内本文件**——否则复制 skill 目录或分发 skill 包会把本所数据带给他人。
> 隐私边界：只记律所自身信息，不记任何客户信息。

## 终端固定值（本机专属，不随母版库/不随包分发）

> **位置**：存于本机 Skill 包目录之外，**不在本包内**——这是防止「复制 skill 目录 / 分享母版库」把个人值带给他人的关键。落点默认 `~/.workbuddy/委托材料孵化器-local.json`，**可用环境变量 `WBM_DELEGATE_LOCAL_PATH` 或启动参数指定**；**写入失败时降级为系统临时目录或仅会话内记忆（提示下次重输），绝不落回 Skill 包目录**。

| 变量 | 说明 |
|------|------|
| 承办律师姓名 | 本机律师自己，生成时自动带出 |
| 承办律师联系电话 | 即授权委托书电话栏，随承办律师变 |

**工作流**：律师首次在本机生成时，检测无本地终端配置 → 问一次「承办律师姓名 + 联系电话」→ 存本机；之后每次自动带出；换人 / 换号时说一声即更新。
