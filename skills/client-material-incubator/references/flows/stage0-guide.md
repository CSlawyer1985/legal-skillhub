# 阶段0 · 上手引导（详细流程）

> 本文件由 SKILL.md 按需加载。适用：首次使用本 Skill 的律师。

## 简介（入口确认前，帮助律师理解"这个 Skill 能帮我做什么"）

> **先从委托材料开始，把手中的模板变成可复用的 AI 母版库，让每一单成套高效产出。这里孵化的不是文书，是您驾驭 AI 的那份从容。**
>
> 本 Skill 帮助贵所将**自有委托材料模板**变成 AI 可复用的母版库。
>
> **它做什么**：导入您的模板 → 引导您做变量化 → 建成母版库。之后每接一单，上传笔录/录音或直接描述案件，成套产出委托代理合同、风险告知书、授权委托书、送达地址确认书等。
>
> **它不做什么**：本 Skill 不替您撰写模板内容、不替您做法律判断。方法分享给您、您掌握后自行维护母版库——模板资产始终归贵所。
>
> **为什么是"分享"而非"代做"**：市面上有一些"输入信息直接生成合同"的工具，但法律实践中每家律所的委托材料格式、条款措辞、合规要求都不同。与其给您一个不贴合的黑盒模板，不如把方法分享给您，让您把自家模板变成 AI 可理解的变量化版本——您掌控一切，AI 负责高效执行。

## 入口确认

**简介必展示（硬约束）**：无论用户以何种方式进入阶段0——包括主动说「想看示范」触发快速体验——入口确认前都必须先把上方「简介」完整展示给用户。简介是用户理解「本 Skill 能帮我做什么」的唯一入口，跳过它用户会不明所以地直接面对投喂。**任何选项都只能跳过「概念教学」，不能跳过「简介」。**

简介后询问用户背景 + 是否收到母版库分享，提供选项——
- **无 AI 模板化基础** → 进入概念教学
- **了解概念，直接看示范** → 跳过「概念教学」，进入示范演示（示范后继续走「准备清单 → 律所画像 → 进度登记」，不得直接投喂）
- **熟悉模板化流程，直接开始制作** → 跳过阶段0，登记后进入阶段1
- **收到母版库分享** → 进入下方「分享接入」分支

## 分享接入（收到母版库分享时）

适用：律师从同事或他所收到**线上母版库分享**（腾讯文档模板库空间 / 金山文档云盘目录），在「复用生成」与「建自己的库」之间选择。

1. **确认分享来源**：请律师提供分享的母版库位置（空间/文件夹链接）；读取其 manifest（变量字典 + 材料包清单），了解母版构成；
2. **两条路径（可并行，不互斥）**：
   - **A. 复用生成（即用即走）**：直接基于分享的母版库，进入**阶段2**生成委托材料——生成结果归本人（存本人空间/本地），**不写入分享方母版库**；
   - **B. 建自己的库（教学型核心）**：以分享的母版为**参考范例**，走**阶段1**六步——投喂**自己的**模板 → 变量化 → 建成**自己的**母版库（存本人空间）。分享的母版仅作示范，**教方法、不替做**；
3. **资产归所铁律**：复用不复制母版、不覆盖分享方空间；自建库存本人空间；分享方母版库保持原样。

## 流程（各步骤均可选择跳过）

1. **概念教学**（可选）：讲解变量、母版、材料包三个核心概念（文案见 `references/teaching/concepts.md`）。每个概念讲完**必须确认理解**——要求律师用自己的话复述概念要点，或回答一个确认问题。用户可选择跳过剩余概念。

2. **示范演示**（可选）：展示内置脱敏示范包。

   **执行要点**（务必主动，不等待用户询问）：
   - 先读取 `references/demo-pack/demo-manifest.json`，列出示范包清单——包含哪几份母版、每份的变量数与教学难点（如计件合同 34 变量含勾选框/日期拆分、授权委托书+律所函 20 变量含特别授权权限清单）；
   - 明确告知用户**文件在 Skill 包的 `references/demo-pack/` 目录内**，可自行打开查看母版效果（示范母版由 `scripts/generate_demo_pack.py` 一键重建）；
   - 完成后**继续引导进入「准备清单」（第3步）**，**不得直接进入模板制作/投喂**——示范演示只是阶段0 的一步，看完示范仍须走完「准备清单 → 律所画像 → 进度登记」，再进阶段1。

3. **准备清单**：引导用户对照 `references/teaching/prep-checklist.md` 确认手头模板储备。

4. **律所画像 + 终端固定值**（约 2 分钟）：
   - **所内固定值**：引导律师填写 `references/lawfirm-profile.md` 的「所内固定值」——律所名称、注册地址、办公地址、律所电话（合同用）、管辖法院（合同争议）+ 常用收费方式。采集后告知："这些全所一致的值已记入画像，之后生成会自动引用，后续修改只需改这一个文件。"
   - **终端固定值**：引导填写**本机**承办律师姓名 + 联系电话（存于 Skill 包目录之外，默认 `~/.workbuddy/委托材料孵化器-local.json`，不随母版库/不随包分发；隔离沙盒无用户目录写入权限时，可用环境变量 `WBM_DELEGATE_LOCAL_PATH` 指定落点，写入失败则降级为系统临时目录或仅会话内记忆并提示"下次需重输"，**不落回包目录**）。告知："这是您本机的信息，生成时落款自动带出您自己；换人换号时说一声即可。"

5. **进度登记**：在 `references/lawfirm-progress.md` 更新状态为「阶段0 完成」。
