# 常见问题应对指南

> 这份清单来自真实测试踩过的坑。遇到问题时，先按「症状」对照，再照「怎么说」对 AI 说——多数能当场解决；解决不了再看「应对」。它是「精准指令手册」的姊妹篇：一个教"正确怎么用"，一个教"出错怎么办"。

---

## 一、母版与格式

### Q1 填空线消失（下划线丢失）

- **症状**：变量化后，原本的填空下划线不见了。
- **怎么说**：「第 X 页的填空线在变量化后丢了，请检查下划线继承」
- **应对**：若 AI 说已修复但仍丢，说明该下划线是特殊实现（样式继承 / 段落边框），把该填空位截图或定位给 AI 复查。

### Q2 正文出现重复变量

- **症状**：出现「{{委托人电话}}{{委托人电话}}」这类重复。
- **怎么说**：「XX 变量重复了，映射的 old 是不是 new 的前缀？」
- **应对**：检查映射规则，old 不要写成 new 的一部分。

### Q3 真实值残留（没变成变量）

- **症状**：某个人名 / 金额还是原文，没变成 `{{变量}}`。
- **怎么说**：「"××贸易有限公司、张某某" 没被变量化，请处理跨节点替换」
- **应对**：这类多为顿号 / 空格 / 数字被 Word 拆节点，引擎已支持；若仍漏，把该段落定位给 AI。

### Q4 第二份文书抬头串页

- **症状**：授权委托书 + 律所函等两套文书，第二套抬头跑到第一页。
- **怎么说**：「两套文书之间没有分页符，请补分页符让第二套从新页开始」
- **应对**：确认套与套之间分页符 / 分节符在位。

### Q5 落款署名单独成页

- **症状**：甲方 / 乙方 / 日期悬空在单独一页。
- **怎么说**：「署名被挤到下一页了，请微调行距 / 页边距让署名上移，不要截断正文、不要单独成页」
- **应对**：正确做法是微调格式（行距缩至 22pt / 微调页边距），**禁止截断正文、禁止强制换页**。

### Q6 勾选框状态每案都一样

- **症状**：生成后勾选框永远勾同一个。
- **怎么说**：「请检查勾选框是否都变量化了，□/☑ 要成对替换」
- **应对**：勾选框必须建 `{{勾选_*}}` 变量，未变量化的建库时补上。

### Q7 多人被拆成多个变量

- **症状**：出现「{{被执行人一}}、{{被执行人二}}」，单人间顿号悬空。
- **怎么说**：「请把被执行人合并成一个变量，值内顿号分隔」
- **应对**：多人角色一律单一变量（`{{被执行人}}` = `张三、李四`）。

## 二、告知笔录

### Q8 正文残留真实案情

- **症状**：告知笔录母版正文还有真实陈述（人名 / 金额）。
- **怎么说**：「正文个案问答请整段删除，通用问答保留，通用问 + 个案答只留问、清空答」
- **应对**：按问答三类规则处理（通用问答保留 / 通用问 + 个案答留空 / 个案问答删除）。

### Q9 告知人 / 记录人并成一个变量

- **症状**：「告知人」「记录人」变成同一个变量。
- **怎么说**：「告知人和记录人是两个语义，请用上下文前缀拆成两个变量」
- **应对**：同值不同语义的位置，old 要带前缀（如「告知人：张三」）。

## 三、生成与通道

### Q10 录音通道首次下载失败

- **症状**：转写首次运行下载模型超时。
- **怎么说**：「模型下载源不可达，请走备用源」
- **应对**：已内置 hf-mirror → modelscope 备用源；仍失败检查网络。

### Q11 变量确认时有字段没填

- **症状**：成品有 `{{变量}}` 没替换。
- **怎么说**：「XX 变量还没填，帮我确认该填什么」
- **应对**：按"一次确认表"核对缺失项，直接说"XX 改成 YY"。

### Q12 文件无法打开 / 打开后内容丢失（段落被截断）

- **症状**：Word 打开提示「文件已损坏」，或内容明显变少（如授权书只剩半份、落款消失）。
- **怎么说**：「成品打不开/段落丢失，请诊断段落数并重新生成」
- **诊断**：对比成品与源模板的段落数——`python -c "from docx import Document; print(len(Document('x.docx').paragraphs))"` 不一致（如 18 vs 8）即 XML 被截断。
- **应对**：多为 XML 修改实现错误（典型：分页符插入用逐段偏移替换导致偏移错位）。修复路径：① 从源模板重新 `build_master.py` 生成干净母版；② 用 `scripts/insert_page_break.py` 插入分页符（自带三重自检）；③ 重新生成成品；④ 文件被预览/编辑器占用时（PermissionError WinError 5），先产出「·修复版」再替换。

---

## 一句心法

> **先查症状、再照「怎么说」说、最后才动手改**。多数问题用一句精准指令就能让 AI 定位修复，不必自己钻进 XML 里排查。
