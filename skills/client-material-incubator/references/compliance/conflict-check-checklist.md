# 利益冲突审查 要素审核清单

> 用途：①阶段1 审核律所的利冲检索记录/收案审查表模板；②阶段2 生成委托材料前提示利冲审查时点。
> 核心依据：《浙江省律师执业利益冲突认定和处理规则（试行）》（2025-01-01 施行），已经事实核查官验证（2026-08-07）。

---

## 一、时点要求（最重要的审核项）

| # | 要素 | 法条来源 | 审核方式 |
|---|------|----------|----------|
| L1 | **接受委托前**完成利冲审查 | 浙江利冲规则第5条 | 律所流程/模板是否明确"委托前"——实践中部分中小所将系统检索放在确定委托时，应提示规范要求时点 |
| L2 | 形成书面审查记录 | 上海指引第13条 | 是否有书面/电子留痕（非"脑海里过一遍"） |
| L3 | 承办律师主动申报义务 | 浙江利冲规则第5条 | 模板是否有律师申报栏 |

## 二、审查范围（绝对禁止 15 种 + 相对禁止 7 种）

模板/记录应体现对以下情形的排查（浙江利冲规则第3、4条）：

### 绝对禁止（发现即不得接受委托）

| # | 情形摘要 |
|---|---------|
| D1 | 同一案件为双方代理 |
| D2 | 本人/近亲属与案件有利害关系 |
| D3 | 曾处理/审理该事项的审判、仲裁、调解人员转任律师后代理同一事项 |
| D4 | 曾任案件代理人/辩护人（原审判、检察人员、公司律师或非律师身份），转所后在后续程序中接受对方委托 |
| D5 | 同一刑事案件接受两名以上嫌疑人/被告人委托（同一人辩护） |
| D6 | 同一律所分别担任同一刑案被害人代理人和嫌疑人辩护人（一县一所+同意除外） |
| D7 | 刑案辩护人同所人员是被害人 |
| D8 | 同一民/仲/行案件中同所律师双方代理 |
| D9 | 非诉业务中同时接受有利害关系各方委托 |
| D10 | 委托终止后同一案件后续程序中接受对方委托 |
| D11 | 法律顾问期间为顾问客户对方代理 |
| D12 | 审判、检察人员离任后两年内代理诉讼 |
| D13 | 担任本所其他律师为仲裁员/听证员案件的代理人 |
| D14 | 调解员所在律所就该争议接受一方委托指派其他律师 |
| D15 | 其他依经验和常识应回避情形 |

### 相对禁止（可豁免，须签署知情同意书）

| # | 情形摘要 |
|---|---------|
| R1 | 同所人员是对方当事人近亲属（民/仲） |
| R2 | 同所人员是被害人近亲属（刑事） |
| R3 | 同所接受对方当事人其他法律业务 |
| R4 | 同所其他律师担任对方代理人（委托人未委托该律师情形） |
| R5 | 非诉委托终止一年内接受对方同一事务委托 |
| R6 | 同所接受同一刑案两名以上嫌疑人委托（分派不同律师） |
| R7 | 其他类似情形 |

## 三、审查主体范围（"同一律所"认定，浙江利冲规则第13条）

审核提示：检索范围必须覆盖——

| # | 范围 |
|---|------|
| S1 | 本所总部 |
| S2 | 本所设立的所有分所 |
| S3 | 其他可认定为同一律所的机构 |

## 四、配套文书

| # | 文书 | 适用情形 |
|---|------|----------|
| L4 | 知情同意书（含豁免内容的书面文件/邮件/电子数据） | 相对禁止情形获委托人豁免时必备（第10条） |
| L5 | 收案审查表 | 所内审查留痕，含利冲排查结论栏 |
| L6 | 持续监控机制 | 案件承办期间主体变动时重新评估（上海指引第15条） |

## 五、免责边界

- 接受委托时因客观原因未发现利冲，发现后**及时终止委托**的，不构成违规（浙江利冲规则第16条）——可写入教学脚本，缓解律师焦虑
