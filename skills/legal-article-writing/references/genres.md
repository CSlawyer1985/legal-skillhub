# 八类体裁的骨架

每类给出：适用场景 → 标题范式 → 骨架 → 小标题模板 → 该体裁的专属要求。

**模块标记**：骨架中标 `【必备】` 的模块不得删除或换序；标 `【可选】` 的可按材料充分度删除。
**不得因篇幅不足删除证据、反面论证、局限或合规建议。** 硬门槛必须满足；骨架和示例可按事实与用户要求调整，**不得为贴模板牺牲准确性和论证顺序**。

## 钩子的六种做法（SKILL.md §3 引用）

| 做法 | 例 |
|---|---|
| 四字格对仗 | 穿透到底、追索到人 |
| 化用成语／反用俗谚 | 小而自有操守 |
| 设问 | AI 责任谁买单？ |
| 事件＋后果断言 | FCC 新规落地，机器人行业需作好应对准备 |
| 意象比喻 | 融资寒冬中的一道"南洋暖流" |
| 从 X 到 Y | 从纸面合规到实质合规 |

界定语三式：`简评《X》` ／ `从 A 看 B` ／ `X 中的 Y 边界`。
系列标注：`（上篇）`／`（五）`／`一线观察丨`。

## A 境内新规简评

**场景**：国内部委/监管机构发布规章、意见、办法、指引。

**标题范式**：`[四字格对仗或核心判断]——简评《[文件全称]》`
> 穿透到底、追索到人——简评《关于健全金融机构治理的实施意见》

**必选招式**：源流—增量【必备】＋ 对照表【必备】

**骨架**

```
导语（落锚→报事→称重→点名→交底）【必备】

一、文件定位：[规格与制度坐标]【必备】
   1. 发文主体：[从主体构成读出文件属性]
   2. 适用范围：[从分业到全口径 / 扩围到哪些主体]
   3. 效力层级：[是否直接创设处罚依据；靠什么工具落地]
   4. 时间坐标：[目标时点与上位政策的关系]
   → 附「新规与既有规则源流对照表」

二～N、[按新规自身的章节顺序逐块拆解]【必备】
   每块内部：源流（哪部旧规已有）→ 增量（真正新的是什么）→ 落地形式（预计通过什么工具考核）

N+1、[归结]规范对象：新规到底在防什么【可选】
   把散落的条文归到 2–3 类风险，指出它们的共同实现通道

N+2、合规提示：机构与股东的整改清单【必备】
   立即整改项 / 制度建设项

结语（归结实质 → 点名真正增量 → 前瞻 → 促行动）【必备】
```

**小标题模板**
- `[主题]：从"[旧定位]"升格为"[新定位]"`
- `[主题]：[准入、识别、行为、追责]的全周期闭环`
- `[主题]：[上位经验]的量化参照`

**专属要求**
- 必须有一处集中回答"真正新设的要求集中在哪几处"。
- 每个"增量"判断都要指名对照的旧规（全称＋文号＋条款）。
- 区分"新表述"与"新义务"——换个说法不算增量。

## B 域外监管应对

**场景**：外国监管新规、执法动向冲击中国企业海外业务。

**标题范式**：`[事件]，[对象]需作好应对准备` ／ `[新规]详解，[对象]应如何应对`
> FCC 新规落地，机器人行业需作好应对准备

**骨架**

```
导语（事件＋日期＋机关＋所纳入的对象；置于该机关近期动作序列中；点明为何对中国企业实质影响；交底）

一、[新规的]监管逻辑：与[既有同类管制]相同/不同的机制
   讲清法律授权来源、判断标准、演变趋势
   若与前例同构，明确列出共用的 2–4 条管控逻辑

二、[新规]的主要内容
   1. 受限范围——[定义]：[N]要件与排除项
   2. [豁免机制]——需谨慎判断[关键概念]
   3. [合规标准]——审慎评估[企业动作]
   4. [个案救济]——难度较高的个案尝试
   每小节结构：规则怎么写 → 实操中的陷阱在哪 → 我们建议怎么做

三、中国企业应如何应对
   先说清"为什么不能照搬老办法"，再给路径
   1. [路径一] —— 可行性、条件、风险
   2. [路径二] —— 同上
   3. 其他注意事项（排查清单）

结语（该监管**预计**不止于本次动作 → 还有哪些工具在推进中【须为已核事实：在审法案、已启动的调查、已公布的时间表】→ 我们会持续关注）
   注：不得写成“必将”“势必”；未经核实的后续动作不得写入。
```

**专属要求**
- 必须点出"该管制与传统关税/贸易壁垒的逻辑差异"，防止读者误用旧方案。
- 给出的每条路径都要配"但是"——列出落地时需论证的事项。
- 要提示中国侧的对应监管（出口管制、技术出口、对外投资审查），双向合规。
- **执法案例（按可得性降级，不得编造）**：
  优先用同一规则下的真实执法案例；
  尚无案例时，可用同一机关、相邻制度或同构管制下的案例，**必须标注"类比参考"及不可直接类推之处**；
  没有可靠类比案例时，明确写"截至 [日期] 未确认有公开执法案例"，改以规则要件推演替代。
  **不得为满足骨架补造案例。**

## C 问答型专题

**场景**：向陌生市场/产品做系统性科普，通常是系列首篇。

**标题范式**：`[领域]新思路：[路径]——[对象]基本情况问答`
> 房地产融资新思路：海外融资之新加坡 REITs ——新加坡 REITs 上市基本情况问答

**骨架**

```
导语（行业变革与困境 → 传统路径为何收窄 → "然而，[新路径]……" ＋ 一个意象比喻 → 系列说明与本篇定位）

问：什么是 X，与 Y、Z 有什么不同？        ← 先立概念，用对比划清边界
问：什么是[本文的 X]，与[其他辖区版本]有什么不同？
问：哪些[资产/主体]适合[做这件事]？       ← 分"类型"与"规模"两层，给可量化门槛
问：[该市场]表现如何？                     ← 市值/募资/收益/流动性，逐项给数据
问：[我方主体]选择这条路径有什么优势？     ← 分 4–6 个带小标题的优势点
问：已有哪些[先例]？
问：流程有哪些，需要多少时间？             ← 分阶段，每阶段给时长区间与总时长

（可选）结语或系列预告
```

**专属要求**
- 每个"问"都是读者会真问的问题，不是为了铺陈知识点而设的问题。
- 概念一律用**对比**定义：`REITs 是"资产上市"，ABS 是"资产结构化融资"`。
- **量化门槛按客观存在与否处理**：该主题客观存在且对决策有意义的金额、比例、期限、规模、时点门槛，必须量化并注明**数据截止时点与来源**；
  不存在统一量化门槛时，**明确写"现行规则未设统一量化门槛"**，转而列出可核验的定性要素。
  **不得为满足体裁要求补造数字或引用无关市场数据**——"没有统一门槛"本身可能就是重要结论。
- 优势点用短句小标题分块（如"资金双向跨境畅通，实现全球资产配置与风险对冲"），不要堆成一段。
- 系列首篇要在导语交代系列规划。

## D 判例评析

**场景**：境内外新判决，对读者所在辖区有参考价值。

**标题范式**：`[实务设问]？从[某判决]看[读者辖区]的风险与应对`
> 员工跨境工作，应适用哪国劳动法？从欧盟最新判决看香港雇主的风险与应对

**骨架**

```
引言（这个问题为什么是基础而关键的 → 判错的后果是什么 → 引出判决 → 说明对读者辖区的参考价值）

一、[案件名]案：案件概要
   当事人与事实 → 争议点 → 法院说理 → 判决要旨
   ★ 插入「实务启示」小段——从本案抽出一句可迁移的规则

二、[读者辖区]法院的立场
   现行原则 → 判例分歧（甲案怎么判、乙案怎么判、分歧未决）→ 主流实务观点
   ★ 与第一部分做明确对照：谁更有弹性，谁更直接

三、[将案件置于当下场景]
   把判决接到读者真实面临的情形上（如疫情后远程办公），用两三个具体设问推演

四、那么，雇主/企业可以采取哪些措施？
   1. [方案一]  —— 优势 → 局限 → 需一并处理的问题
   2. [方案二]  —— 同上
   3. [方案三]  —— 同上

结语（没有放诸四海皆准的规则 → 本案提醒了什么 → 早识别者更有利 → 业务推介【默认省略，见 boilerplate.md】）
```

**专属要求**
- 案情只写与裁判要旨相关的事实，且要把"连接因素"逐条列出（工资币种、社保、税务、通讯方式……）。
- 判例分歧要如实呈现"至今尚未获得最终解决"，不要替法院下结论。
- 方案部分必须写"局限"，只写优势的方案建议是不合格的。
- 涉香港必加香港表述声明。

## E 责任边界论证

**场景**：新业态尚无明确规则，需要在现行法框架内构建分析方法。

**标题范式**：`[责任设问]？——[场景]中的责任边界`
> AI 责任谁买单？——AIGC 生成与传播中的责任边界

**骨架**

```
导语（技术形态发生了什么演化 → 因此旧的笼统概括为何失效 → 提出本文的分析方法：功能/行为/主体三层对应 → 声明同一主体可具多重身份 → 界定本文讨论对象的内涵与外延及技术事实前提）

一、拆功能：[对象]的功能分层
   1. [N]类基础功能模块
   2. 不同产品是上述功能的不同组合
   → 结论：参与运营 ≠ 对所有功能有同等控制

二、[场景一]：[两个阶段]可能对应不同责任
   1. [阶段一]：[技术属性]的影响
   2. 不能仅凭"[笼统标签]"概括所有主体的行为
      （1）与行业多主体分工模式不匹配
      （2）会削弱[另一方]自身的注意义务
      （3）从"[替代框架]"视角审视
      （4）[阶段二]：[适用的既有规则]

三、[场景二]：结合具体架构判断[主体]角色
   1. [各方如何共同影响结果]
   2. [某行为]不当然形成[某法律定性]
   3. 注意义务应与具体风险和可采取措施相匹配
   4. "[某抗辩]"影响措施范围，但未必排除其他义务

结语：责任分层后如何控制风险
   分层 ≠ 免责 → 对 A 方的建议 → 对 B 方的建议 → 落回具体产品与业务场景
```

**专属要求**
- 先声明技术事实前提，再做法律评价——事实前提变则结论变，要写明这一点。
- 每一处归责都落到"谁控制了什么"，不落到"谁在技术上参与了"。
- 反面论证要写足：如果采用某个宽泛标准，会导致什么荒谬后果（举链条）。
- 结论用"不宜""未必""可能更接近"，因为无明确规则时过度断言是硬伤。
- 给"必要措施"清单时，要列出删除以外的梯度措施。

## F 制度反推

**场景**：出台了针对特定主体的豁免/简化/试点规则。

**标题范式**：`[化用成语]——从[特殊主体的简化措施]看[一般主体]的[义务]`
> 小而自有操守——从小型个人信息处理者合规简化措施看一般个人信息处理者的合规义务

**骨架**

```
引言
   新规基本情况（日期、机关、名称、施行日）
   → 用官方统计数据证明该领域监管并未放松（执法数量、专项行动）
   → 因此"从严态势与简化措施并不冲突"
   → 界定适用主体的量化门槛
   → 亮出本文方法：从简化措施反推一般主体的合规重点
   → 列出本文要点清单（6 条左右，编号，与下文各节一一对应）

一～N、[逐项议题]——[该议题的一句话判断]
   每节固定三拍：
   （1）新规怎么简化的（可用对照表）
   （2）先看豁免了什么
   （3）★再重点看没有豁免什么 —— 这里才是文章的价值
   并写出反推句：「从简化措施的角度反推，非[特殊主体]显然不能仅仅通过……」

N+1、对企业合规的启示【必备】
   对特殊主体：如何用足政策红利（含如何让监管知道你属于该类主体）
   对一般主体：没被豁免的即是监管视角下的合规重点
   ★ 收尾给**动宾式行动清单**（谁该做什么），不要停在原则表述

结语【必备】
   归结实质 → 点名真正的制度增量 → 前瞻（配套细则/执法动向）→ 促行动判断句
```

**专属要求**
- 每一节都要出现"反推"动作；只讲新规内容不反推的节应删除或合并。
- 同一要求在多部法规中重复出现时，要点出重复次数并解读其分量：`从 A 到 B 到 C 再到 D，同样的规定出现四次，其重要性不言而明`。
- 注意"没有重复规定"≠"不适用"——要按体系解释补上。
- 结尾要给特殊主体一条别人想不到的实操建议（如"通过隐私政策声明自身属于小型处理者，避免信息误差导致简化措施失配"）。

## G 实务方法论 / 体系建设指南

**场景**：不解读单一新规，而是就"某件事该怎么做"给出**单一路径的方法论**——如何搭建合规体系、如何做尽调、如何执行某套流程。常见于"一线观察"栏目，多为个人署名。

> **G vs H 边界**：文章围绕**一条路径怎么做好**（要素清单、执行要点、失效形态）→ **G**；围绕**几条路径选哪条**（对象比较、条件权衡）→ **H1**。
> 二者兼有时按主要论证任务定主体裁；但两边的硬门槛都按**实际使用的模块**触发（SKILL.md §1 末的黄框），不因标签而豁免。

**标题范式**：`一线观察丨[主题]（上篇）：从[虚]到[实]`
> 一线观察丨出口管制内部合规体系建设（上篇）：从纸面合规到实质合规

**人称**：单作者署名 → 全文用**笔者**。这是它与其余体裁最显著的差异。

**必选招式**：失效形态【必备】＋ 源流—增量或对照表【必备】

**骨架**

```
导语（本体裁例外：允许三段）【必备】
  段一 落锚：宏观格局 → 本国法律体系加速完善（列举法律＋施行时间）→ 域外同步升级
        → "已不再是'可选项'，而是关系企业生存发展的'必答题'"
  段二 痛点诊断（本体裁的灵魂）：
        "然而，笔者在服务[对象]的实践中发现，许多企业存在'重[虚]、轻[实]''重[X]、轻[Y]'的问题——
         有的企业[具体失败形态一]，有的企业[具体失败形态二]。
         问题的根源不在于企业缺乏[表层原因]，而在于[真实原因]。"
  段三 交底：分上下篇说明；本篇以《[官方指引]》确立的[N]项基本要素为框架

一、[做这件事]：企业必须跨越的门槛【必备】
   1. 法律基础与激励逻辑 —— 引条文，说清"不是普遍强制义务，但做好了有可期待利益"
   2. 战略价值的三个层面：
      其一，防御价值——…… 其二，激励价值——…… 其三，商业价值——……（客户尽调把它当准入硬条件）

二、[N]项基本要素【必备】
   先总述：这 N 项不是彼此独立的清单，而是一个以 A 为起点、以 B 为保障、以 C 为核心、最终由 D 集成的运行系统
   1. [要素一]——[一句话点破它的实质]
   ★ 每项固定三拍：
     （1）规范怎么要求的（引指引/条例要点）
     （2）它的实务价值常被低估 / 它的真实难点在哪
     （3）实务中最常见的失效形态是什么

三、[做这件事]的[四]个常见误区【可选，但强烈建议】
   误区一：重[A]，轻[B]。……本质上是一种[标签]。
   误区二：重形式，轻实质。…… 误区三：重静态，轻动态。…… 误区四：[视野缺陷]。……

四、落地清单：从哪几件事开始【必备】
   动宾式行动清单（谁、做什么、按什么顺序），可按"先建机制／再补文档／持续运行"分组
   —— SKILL.md §9 对 A/B/F/G 都要求这一节，不要停在原则表述

结语【必备】
  趋势观察（笔者注意到一个显著趋势：越来越多的……选择……）
  → "不是一蹴而就的'运动战'，而是需要持续投入的'持久战'"
  → 合规不再仅仅是"为了不被处罚"，而日益成为[更高层次的定位]
  → 回到立法目的收束
```

**专属要求**
- 痛点诊断段必须写**具体的失败形态**（"照搬模板编写了一本合规管理手册却束之高阁"），不能写"合规意识不足"。
- **每个要素都要有"最常见的失效形态"**——这是本体裁区别于法规复述的唯一凭据。缺此则该节应删或合并。
- 误区用「重A，轻B」四字对仗，A 为形式、B 为实质。
- 上下篇分工在导语交代清楚（如：上篇立足中国法，下篇聚焦欧盟 ICP 与美国体系）。
- 结语的价值升华要落回立法目的，不要空喊口号。

## H 综合实务指南 / 比较分析（兜底体裁）

**场景**：无单一新规、新判决或豁免事件的**常青型**对外文章。**任务不属于 A–G 时选 H。**

H 有两个子型，按任务的实际形态择一，**不得为套模板制造不存在的比较对象**：

- **H1 比较型**（默认）：几条路径选哪条——交易路径比较、架构选择、跨法域制度对比。用下方骨架。
- **H2 自由型**：监管趋势综述、多案例归纳、专题综述、访谈整理等**不以"官方要素清单＋失效形态"为骨架**的常青文章。**保留导语、带判断的小标题、断言强度、引注纪律、结语前瞻与全部收尾件要求，骨架自拟**；不适用下方比较骨架，也不要求事实假设与对照表。

> **H2 vs G 的分界**：只要文章围绕某套官方要素/步骤讲"这件事怎么做好"，就是 **G**（必须写失效形态），不是 H2。
> H2 留给那些既不比较路径、也没有可依托要素清单的常青文章。

若连 H2 也不合身（例如用户要的根本不是对外实务文章），**停下来向用户确认**，不要硬套。

**标题范式**：`[设问或核心权衡]——[比较对象]的[维度]比较`

**必选招式**：对照表【必备】

**骨架**

```
导语【必备】（问题从哪来 → 谁在面对它 → 本文比较什么、基于什么事实假设）
   明确标注"无单一触发事件"，不得虚构监管动态

一、问题与受众：什么情况下需要作这个选择【必备】

二、比较的维度与事实假设【必备】
   先把假设摆明（交易规模、主体性质、目标法域、时间约束），因为假设变则结论变

三、各路径逐项比较【必备】
   1. [路径一]：机制 → 适用条件 → 优势 → 局限
   2. [路径二]：同上
   → 附维度对照表

四、选择条件与权衡【必备】
   不给"最优解"，给"什么情况下选什么"的条件式结论

五、执行清单【可选】

结语【必备】（归结判断标准 → 提示假设变化时结论如何移动 → 促行动）
```

**专属要求**
- **必须写明事实假设**，并说明假设变化时结论如何移动。
- 不得因为"没有新规"就虚构一个"近期监管趋严"的伪由头。
- 每条路径都要给局限，不得只写优势。
- 常青型文章所引规则同样要核对现行有效性——常青不等于可以引过期规则。

## 跨体裁通用：表格用法

| 用途 | 放在哪 |
|---|---|
| 新旧规则源流对照 | 体裁 A 第一节末 |
| 要件清单／排除项 | 体裁 B 定义小节 |
| 辖区/产品三方对比 | 体裁 C 概念节、体裁 D 对照节 |

| 整改清单（分优先级） | 结语前 |
