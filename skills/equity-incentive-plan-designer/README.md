# 股权激励方案设计器（Equity Incentive Plan Designer）

> 📊 把"创始人拍脑袋定期权 → 员工看不懂 → 离职扯皮"的非标操作，升级为标准化、可解释、可落地的股权激励方案。

---

## 这是什么？

一个基于三维系数模型（职级×贡献度×稀缺度）的股权激励方案设计工具。输入公司估值、ESOP 池比例和激励对象列表，输出：

1. **期权池总览**（池规模、使用率、稀释预测、扩池预警）
2. **个人授予方案**（每个激励对象的授予股数 + 占股比 + 合理性校验）
3. **归属计划**（cliff 时间线 + 归属进度条 + 加速触发条件）
4. **行权与税务**（行权成本 + ISO/NSO 税务对比估算）
5. **退出机制**（四种离职场景的处理方案 + 回购价公式）
6. **估值模拟与回报测算**（保守/中性/乐观三档退出回报 + 稀释后实际占股）

```

公司：星辰科技 | A轮 | 估值 5亿 | 总股本 1亿股 | ESOP 15%

激励对象：
张三,联合创始人&CTO,入职3年,极度稀缺
李四,技术VP,入职2年,高度稀缺
王二,产品VP,入职1.5年,中度稀缺
赵六,高级工程师,入职1年,一般
钱七,市场经理,入职8个月,一般

策略：向关键岗位倾斜
归属：标准4年+cliff1年
加速：单触发
```

## 输入说明

### 必填

| 字段 | 示例 | 说明 |
|------|------|------|
| 公司阶段 | `A 轮` | 天使 / A / B / C / Pre-IPO |
| 当前估值 | `5 亿人民币` | 决定期权价值基准 |
| 总股数 | `100,000,000 股` | 计算每股价值 |
| ESOP 池比例 | `15%` | 已预留或计划预留 |
| 激励对象 | `张三,CTO,入职3年,极度稀缺` | 姓名,职级,入职时长,稀缺度 |
| 策略偏好 | 四选一 | 早期优先 / 关键岗位 / 广覆盖 / 保守 |

### 可选

- 归属计划（默认标准 4 年 + cliff 1 年）
- 行权价折扣（默认 FMV × 70%）
- 加速归属（默认单触发）
- 退出机制（默认无过错 90 天行权）

## 能力边界

### 能做的

- 期权池规模建议和稀释预测
- 个人授予份额计算（三维系数模型）
- 归属计划时间线设计
- 行权成本和税务估算
- 退出机制（四种场景）
- 估值模拟和回报测算

### 不能做的

- 不替代法律意见书
- 不替代 409A 估值
- 不处理 VIE 架构税务细节
- 不能作为正式授予协议
