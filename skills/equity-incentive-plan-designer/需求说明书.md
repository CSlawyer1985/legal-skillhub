# 股权激励方案设计器 - 需求说明书

## 1. 产品定位

面向创业公司创始人、CEO、CFO 和 HRD 的股权激励方案设计工具。股权激励是薪酬全生命周期中最复杂的一环——给多少、怎么给、什么时候给、人走了怎么办，四个问题任何一个处理失误都可能导致团队分裂或法律纠纷。本工具将"创始人拍脑袋定期权 → 员工看不懂 → 离职扯皮"的非标操作，升级为标准化、可解释、可落地的股权激励方案。

## 2. 痛点

1. **期权池不知道切多少**：10% 还是 15%？给了融资方怎么办？ESOP 池预留多少够用到下一轮？没有基于公司阶段和估值的动态分配模型。

2. **谁该拿多少没标准**：联合创始人拿 5%，早期核心员工拿 0.5%，后来招的 CTO 拿 2%——每个人来谈的时候都是"我觉得我值 X%"，没有基于职级×贡献度×稀缺度的量化模型。

3. **归属计划说不清楚**：4 年归属、cliff 1 年，这些概念员工听不懂。"为什么我要等 4 年才能全拿？""走了还能拿吗？"没有可视化的归属时间线。

4. **退出机制缺失**：无过错离职（被裁）和有过错离职（违纪）怎么处理？期权是否加速归属？回购价怎么定？没有预设方案，每次都是现谈，扯皮成本极高。

5. **估值说不清楚**：公司现在值 1 亿，期权行权价 1 元/股，员工问"我的期权现在值多少钱？以后值多少钱？"没有估值模拟和退出回报测算。

## 3. 目标用户

- 创始人/CEO（主决策人，负责期权池规模和授予审批）
- CFO（负责估值模型和财务影响分析）
- HRD（负责激励方案执行和员工沟通）
- 法务（负责协议条款合规审查）

## 4. 核心功能

### 4.1 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 公司基本信息 | 是 | 公司阶段（天使/A/B/C/Pre-IPO）、当前估值、总股数 |
| ESOP 池比例 | 是 | 预留期权池占总股本比例（如 15%） |
| 激励对象列表 | 是 | 姓名、职级、入职时间、岗位稀缺度、创始人主观评分 |
| 策略偏好 | 是 | 早期员工优先 / 向关键岗位倾斜 / 广覆盖平衡 / 保守（少给） |
| 归属计划 | 否 | 默认 4 年标准归属（cliff 1 年 + 月度归属） |
| 行权价 | 否 | 默认取最近一轮估值的 FMV 折扣价 |

### 4.2 输出结构（六板块）

#### 第一板块：期权池总览

- ESOP 池规模（股数 + 占股比 + 当前估值下的总价值）
- 已授予/未授予占比
- 各轮次融资对期权池的稀释预测（天使 → A → B → C → IPO）
- 预留是否够用到下一轮融资的判断

#### 第二板块：个人授予方案

- 个人授予份额 = 基准份额 × 职级系数 × 贡献度系数 × 稀缺度系数
- 激励对象明细表（姓名/职级/占比/股数/当前估值下价值）
- 授予合理性校验（创始人 vs 高管 vs 核心员工梯度是否合理）

#### 第三板块：归属计划（Vesting Schedule）

- 标准 4 年归属时间线（cliff 1 年 + 36 月线性归属）
- 个人归属进度表（已归属/未归属/下次 cliff 日期）
- 加速归属触发条件（双触发：公司被并购 + 个人被裁）
- 可视化归属进度条

#### 第四板块：行权与税务

- 行权价设定（基于 409A 估值或 FMV）
- 行权成本计算（行权价 × 股数）
- 税务处理（ISO vs NSO，行权时点 vs 卖出时点的税务差异）
- 行权窗口期建议（离职后 90 天）

#### 第五板块：退出机制

- 四种退出场景处理：无过错离职 / 有过错离职 / 死亡伤残 / 公司并购
- 各场景下的期权处理（已归属保留/加速/作废）
- 回购价格计算公式
- 竞业限制与期权的关联说明

#### 第六板块：估值模拟与回报测算

- 基于不同估值假设的退出回报（保守/中性/乐观三档）
- 个人行权成本 vs 退出回报对比
- 稀释后的实际回报率
- 一句话 ROI：如果公司估值翻 10 倍，你的期权值多少钱

### 4.3 异常处理

- **公司从未做过 409A 估值**：提示先完成估值，提供替代方案（按最近一轮融资估值折扣）
- **激励对象已离职但期权未处理**：按退出机制补处理，追溯计算
- **多轮授予（老员工已有一笔期权）**：合并计算，输出总额和两笔分别的归属进度
- **中外员工混合（ISO/NSO 区分）**：美国员工走 ISO，中国员工走 NSO 或虚拟股，分别计税
- **ESOP 池耗尽**：输出"池已用 X%，需在下一轮融资前扩池"警告
- **创始人期权未设 cliff**：警告"创始人未设 cliff 存在单点风险"
