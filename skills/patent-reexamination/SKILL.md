# 专利复审请求技能（针对驳回决定）

## 一、概述

本技能面向"专利申请被驳回后请求复审"这一行政救济程序。驳回决定通常是审查员对技术方案创造性（亦含新颖性、清楚性等）发表意见并认为不具备授权条件；因此本技能的**实质论证与 `patent-oa-response`（答复审查意见）高度同源**——都围绕"区别特征→技术启示→整体创造性"展开。

本技能在复用该论证方法论的基础上，叠加**复审程序特有**的内容：严格的 3 个月时限、前置审查策略、复审阶段权利要求修改的特殊纪律（细则第66条）、复审请求书的结构与"双受众"（原审查部门 + 合议组），以及典型翻盘案例的论证范式。

## 二、适用场景

- 收到**驳回决定**（实质审查驳回 / 初步审查驳回），对驳回不服，拟在**收到之日起 3 个月内**请求复审。
- 需撰写**复审请求书**（含复审请求理由）并/或提出**权利要求书修改建议**（修改文本）。
- 驳回理由为创造性、新颖性、清楚性、不支持、缺少必要技术特征、修改超范围等。
- 需要评估"修改换撤驳"策略（前置审查第(2)类）还是"纯抗辩"策略（前置审查第(1)类）。
- 需要判断是否请求口头审理、是否补充证据（实验数据、技术原理说明等）。

不适用：针对已授权专利的无效宣告（见 `patent-invalidation` 无效宣告技能，方向相反、支持多理由组合与证据链策略）；复审失败后的行政诉讼（一审北京知识产权法院，收到复审决定起 3 个月内）可本技能提示但不代写诉状。

## 三、与"答复审查意见"的异同（务必先读）

| 维度 | 答复审查意见（OA） | 复审请求（本技能） |
|------|-------------------|-------------------|
| 对象 | 审查意见通知书 | **驳回决定**（终局驳回） |
| 提交时限 | 指定期限（通常 4 个月） | **收到驳回决定起 3 个月（刚性）** |
| 受众 | 实审审查员 | **原审查部门（前置审查）+ 复审合议组** |
| 修改自由度 | 较宽（可删、可加特征） | **窄**：仅限于消除驳回决定/合议组所指缺陷（细则66），**不得扩大保护范围** |
| 核心文书 | 意见陈述书 | **复审请求书（含理由）+ 修改对照** |
| 取胜路径 | 说服审查员 | **说服原审查部门在修改文本基础上撤驳（前置审查第2类）最省力**；否则说服合议组 |
| 论证内核 | 区别特征+技术启示+整体性 | **完全相同**，但需先"解构驳回决定" |

**结论**：创造性/新颖性类驳回，直接复用 `patent-oa-response` 的论证链模板（见本技能 `references/创造性论证链速查.md`）；本技能重点补"程序+文书+修改纪律+前置审查策略"。

## 四、核心理念（在 OA 理念之上新增 4 条）

1. **程序意识第一**：3 个月时限刚性、不可延期（仅特定情形可恢复权利）；超期=救济权灭失。所有工作先排期。
2. **善用前置审查（修改换撤驳）**：复审请求书+修改文本转原审查部门作前置审查。若修改克服缺陷（第2类），复审委不再合议，直接依前置意见作"在修改文本基础上撤销驳回决定"——**最快、最稳的翻盘路径**。优先设计"可让原审查员体面撤回"的修改。
3. **双受众写作**：文字既要让原审查员（前置审查）能接受修改，又要让合议组（若进入合议）看到法律与事实的完整论证。结构上"先修改铺垫、再技术阐释、后抗辩"（结论先行、分点、图文结合）。
4. **修改纪律铁律**：复审修改只能"消除驳回决定所指缺陷"，**不得扩大保护范围、不得引入无单一性方案、不得改无关权利要求**；且必须不超原申请记载范围（法33）。修改建议须逐条说明依据与合规。

复用 OA 理念：逻辑严密、针对性强、说理充分、策略灵活、整体性原则、程序合规意识（见 `patent-oa-response`）。

## 五、关键方法论

### 5.1 解构驳回决定（复审特有起点）
用 `scripts/analyze_rejection.py` 或人工提取：①驳回针对的权利要求；②每条驳回理由（法条）；③引用的对比文件及具体段落/标号；④审查员关键认定（如"区别特征A属常规技术手段""对比文件2给出启示"）；⑤审查员是否指出修改超范围等程序问题。产出结构化清单，作为后续索引（模板见 `references/驳回决定深度分析模板.md`）。

### 5.2 合规性审查（找驳回决定的违法/违规点）
除 OA 的"偏离指南"外，复审额外关注：
- **适用法律错误**（如本应评创造性却以不支持驳回，或反之）；
- **违反法定程序**：以申请人放弃的文本/不要求保护的技术方案为依据；未给予针对驳回所依事实/理由/证据陈述意见的机会；未评价申请人提交的与驳回理由有关的证据；
- **事实认定错误**：区别特征认定错误、割裂特征、作用不同却认定有启示、随意认定常规技术手段、事后诸葛亮。

### 5.3 创造性/新颖性论证（复用 OA）
直接用 `references/创造性论证链速查.md` 的 5 条核心链：否定最接近现有技术、区别特征协同、技术启示（作用不同则无启示）、常规手段驳斥、整体性/事后诸葛亮。典型翻盘范式（见 `references/复审典型案例.md`）：**多维度对比（对象/问题/手段/效果四异）+ 原理剖析（揭示手段本质差异）+ 效果论证（数据支撑显著进步）**。

### 5.4 权利要求修改建议（复审纪律）
依据 `references/复审阶段修改规则.md`：仅在消除驳回缺陷范围内修改；给出"修改前→修改后"对照；说明每处修改源自原申请何处（法33不超范围）；论证未扩大保护范围。优先给出"最小且足以克服缺陷"的修改方案，作为前置审查第2类的筹码。

### 5.5 前置审查策略定调
- **修改型**（推荐）：提出修改文本消除缺陷 → 争取前置审查第2类 → 直接撤驳。
- **抗辩型**：不修改，纯论证驳回错误 → 争取前置审查第1类（成功率低于修改型）。
- **组合型**：修改+抗辩并行（既给筹码又保留法律论证），最稳妥。

### 5.6 证据与附图
复审可补充证据（实验数据、技术原理、产业价值、演进历程）。附图并列比对（复用本技能的 `scripts/extract_figs.py`）增强"图文结合"说服力——主动把关键差异呈现给审查员，不依赖其翻说明书。

## 六、标准工作流程（模块化）

**M0 收文与排期**：记录收到驳回决定日期，倒排 3 个月（及缴费/补正 15 日）节点；读取驳回决定、本申请、对比文件。
**M1 解构驳回决定**：结构化清单（权利要求/理由/证据/关键认定）。
**M2 策略定调**：选修改型/抗辩型/组合型；决定是否请求口头审理、补证据。
**M3 合规性审查**：找驳回决定的违法/违规/事实错误点（含程序问题）。
**M4 区别特征对比表**：本申请 vs 最接近现有技术，标注差异与作用。
**M5 协同性核查**：回击割裂评价、忽略特征间相互作用。
**M6 对比文件作用核查**：作用不同→无启示（最硬核反驳）。
**M7 常规手段驳斥**：质疑随意认定，论证属贡献特征。
**M8 整体性/事后诸葛亮**：重申整体判断，梳理逆向拼凑情形。
**M9 权利要求修改建议**：依细则66提出"修改前→后"对照与合规说明（如采用修改/组合策略）。
**M10 撰写复审请求书**：按 `assets/复审请求书_模板.docx` 结构——结论先行、分点、图文结合；含请求事项、事实与理由（修改说明+技术阐释+抗辩）、修改对照表、证据清单。
**M11 质量自检**：见 §八。
**M12 交付与归档**：复审请求书、修改后权利要求书、证据、附图比对；记录策略与关键点。

## 七、输入输出规范

**输入**：驳回决定（PDF/Word）、本申请（权利要求/说明书/附图）、对比文件、可选（实验数据/技术原理/产业证据）、原审查过程文件（审查意见通知书及答复）。
**输出**：`复审请求书_答复驳回决定.docx`（主交付）、`权利要求书_修改后.docx` 及修改对照、`附图比对材料/`、证据清单、项目工作日志。

## 八、质量检查节点（复审质量自检）

- [ ] **时限**：确认在收到驳回决定起 3 个月内提交，并预留缴费/补正时间。
- [ ] **全覆盖**：M1 清单每一条驳回理由均有针对性回应。
- [ ] **可映射**：每观点有"指南条款→事实（原文/标号）→推理→结论"论证链。
- [ ] **修改合规（若修改）**：修改仅消除驳回缺陷；未扩大保护范围；依据原申请（法33）；有"前→后"对照。
- [ ] **前置审查利用**：修改型已设计"让原审查员可体面撤驳"的方案；组合型抗辩与修改自洽。
- [ ] **引用准**：指南条款号、对比文件段落/标号、说明书段落可复核。
- [ ] **附图对**：嵌入附图图号正确、左右对照与文字一致。
- [ ] **不矛盾**：抗辩理由与修改方案不自相矛盾；未同时主张"区别特征不存在"与"区别特征有贡献"。
- [ ] **文书结构**：复审请求书含请求事项、理由、修改对照、证据清单；结论先行、分点、图文结合。
- [ ] **兜底提示**：已提示若复审失败可在收到决定起 3 个月内向北京知识产权法院提起行政诉讼。

## 九、注意事项

1. **3 个月刚性时限**优先于一切打磨——宁可先交合格文本再补强，不可超期。
2. **复审修改≠实审修改**：复审修改受细则66严限，且不得扩大保护范围；不要照搬实审中的宽修改思路。
3. **前置审查是主战场**：原审查部门若在第2类（修改克服）撤驳，案件止步前置、省力高效；把"好修改"作为首选筹码。
4. **双受众措辞**：抗辩部分既要法理严密（给合议组），又要给原审查员留有接受修改的台阶。
5. **作用不同则无启示**：创造性反驳的硬核，对比文件须"公开且作用相同"。
6. **产业价值是辅助**：国产化/产业价值可增强说服力，但创造性法定判断仍基于技术方案本身。
7. **尊重用户把关**：结构/拓扑类结论（尤其附图）建议请用户目检关键标记；不确定时主动说明。
8. **复审失败有司法救济**：收到复审决定起 3 个月内可向北京知识产权法院起诉（被告国家知识产权局），本技能仅提示，不代写诉状。
