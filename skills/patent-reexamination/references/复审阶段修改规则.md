# 复审阶段权利要求修改规则

> 复审修改受《专利法》第33条（不超范围）与《实施细则》第66条（仅消除驳回缺陷）双重约束，自由度远窄于实审。本文件给出允许/禁止清单与"修改前→后"对照范式。

---

## 一、总则

- 可在**提出复审请求、答复复审通知书（含口头审理通知书）、参加口头审理**时修改申请文件。
- 修改须同时满足：
  - **法33**：不超出原说明书和权利要求书记载的范围（含直接、毫无疑义确定的内容）。
  - **细则66**：修改**仅限于消除驳回决定或合议组指出的缺陷**。

## 二、通常不符合细则66 的情形（禁止）

1. 修改后权利要求相对**被驳回权利要求扩大了保护范围**；
2. 将与驳回权利要求**缺乏单一性**的技术方案作为修改后的权利要求；
3. （针对缺陷未涉及的权利要求/说明书进行修改——但**明显文字错误**、或与指出缺陷**性质相同**的修改除外）；
4. 其他明显超出"消除缺陷"目的之修改。

> 合议组对不符合细则66的修改文本**一般不予接受**，以之前可接受的文本审查；部分合规的可对该部分提意见，要求改正其余部分。

## 三、允许的修改类型（建议优先）

- **缩小/限定**：在驳回权利要求基础上增加从属权利要求的特征或说明书具体实施例特征，使方案区别于现有技术（最常见的"翻盘修改"）。
- **澄清**：对含义不确定用语作明确限定（不扩大范围）。
- **编排调整**：在不扩大保护范围前提下调整权1表述逻辑（形式修改）。
- **删除**：删除被驳回的独立权利要求（保留从属），或删除无关权利要求（消除缺陷相关）。
- **纠正明显文字错误**。

## 四、"修改前 → 后"对照范式

```
修改对照表
┌────────────┬────────────────────────────┬────────────────────────────┬──────────────────┐
│ 权利要求项 │ 修改前（被驳回文本）        │ 修改后                      │ 修改依据（法33） │
├────────────┼────────────────────────────┼────────────────────────────┼──────────────────┤
│ 权利要求1  │ "……减振结构……"            │ "……减振结构，其中所述冷头   │ 原说明书[0028]段  │
│            │                            │   向下穿过所述下减振波纹管   │ + 图1标号26/27   │
│            │                            │   进入真空腔……"            │                  │
└────────────┴────────────────────────────┴────────────────────────────┴──────────────────┘
```

每处修改须说明：
- 来源：原权利要求__/说明书第__段/图__标号__（证明不超范围）；
- 目的：消除驳回决定关于"____"的缺陷；
- 范围：修改后保护范围 ≤ 修改前（未扩大）；
- 效果：使本申请与对比文件__形成明确区别，克服创造性/新颖性缺陷。

## 五、修改建议的输出

向用户交付：
1. **修改方案**（含"前→后"对照 + 合规说明）；
2. **策略说明**：该修改旨在争取前置审查第(2)类（在修改文本基础上撤驳）；
3. **风险提示**：若修改仍不足，保留 M3–M8 抗辩作为兜底。

## 六、常见误区

- 照搬实审宽修改（加特征扩场景）→ 复审中扩大范围/超缺陷，文本不被接受。
- 修改引入新技术方案/新效果 → 超法33。
- 仅改从属权利要求却未触及被驳回独立权利要求的缺陷 → 未消除缺陷。
- 忘记标注"未扩大保护范围"与"法33依据" → 合规论证缺失。
