# 复审请求书撰写要点

> 复审请求书是请求人向复审和无效审理部提交的正式文书，须含"请求事项、事实与理由"。撰写须同时满足**原审查部门（前置审查）**与**合议组**双受众。

---

## 一、总体结构（结论先行、分点、图文结合）

```
复审请求书
├─ 请求事项（一句话：撤销驳回决定 / 在修改文本基础上撤销驳回决定）
├─ 事实与理由
│   ├─ 一、对本申请权利要求做进一步修改（若采用修改策略）★前置铺垫
│   │     · 修改对照表（修改前 → 修改后）
│   │     · 每处修改的依据（原申请何处，法33不超范围）
│   │     · 修改仅消除驳回缺陷、未扩大保护范围（细则66）
│   ├─ 二、对本申请技术方案的进一步阐释说明 ★技术铺垫
│   │     · 发明点、实际解决的技术问题
│   │     · 附图并列比对（本申请 vs 对比文件）
│   └─ 三、关于对驳回决定的抗辩说明 ★法律抗辩
│         · 逐条回应驳回理由（创造性/新颖性/…）
│         · 论证链：指南条款→事实→推理→结论
│         · 指出驳回决定的违法/违规/事实错误
├─ 证据清单（实验数据、技术原理、产业价值等，注明来源）
└─ 附件：修改后权利要求书、说明书替换页、附图比对材料等
```

> 排序逻辑（来自实务翻盘案例）：**先修改、再阐释、后抗辩**。先以"创新内容+修改"做心理铺垫，再针对驳回不合理处抗辩，说服力更强。

## 二、请求事项写法

- 抗辩型：`请求撤销国家知识产权局于____年__月__日作出的驳回决定。`
- 修改型：`请求在申请人提交的修改文本（见附件）的基础上，撤销上述驳回决定。`

## 三、创造性抗辩的"四异+原理+效果"范式（翻盘核心）

针对创造性驳回，除复用论证链外，强烈建议采用多维度对比：

| 对比维度 | 本申请 | 对比文件 |
|----------|--------|----------|
| 针对对象 | （如：生长完成的晶锭/凸起端部） | （如：已切割的晶片） |
| 解决的技术问题 | （如：粗加工阶段避免开裂） | （如：后处理阶段改善表面） |
| 采用技术手段 | （如：磨削与反应同步） | （如：先腐蚀后研磨） |
| 获得的技术效果 | （如：应力实时释放、防裂） | （如：去除改质层） |

- **原理剖析**：不止于表面特征对比，揭示采用不同技术手段的**本质差异**（如"动态磨削+实时腐蚀"协同 vs "阶段性处理"）。
- **效果论证**：用说明书实验数据/实施例证明"显著进步"，反驳"效果可预期/常规选择"。
- **逻辑链条**：技术问题→技术方案→方案区别→技术效果，形成闭环。

## 四、图文结合

- 主动把关键差异以**左右并列附图**呈现（复用 `patent-oa-response` 的 `extract_figs.py`），不依赖审查员翻说明书。
- 每幅对比图下加"【附图对比小结】"一句点明本质差异。
- 重要发明点"先说、多角度印证、总结强调"，重视审查员顺序阅读的心理。

## 五、证据组织

复审可补充证据增强说服力：实验数据、技术原理说明、研发/产业现状、商业价值、司法/复审案例、技术演进历程。证据须与理由对应，外文证据附中文译文（部分译文亦可，但未被译文部分不作为证据）。

## 六、常见误区

- 只"不认可"不论证：抗辩须结合对比文件技术内容+法规依据，寻找审查漏洞（法律思维而非仅技术思维）。
- 修改扩大保护范围或改无关权利要求：违反细则66，文本不被接受。
- 把产业价值当创造性要件：仅作辅助。
- 超 3 个月才提交：救济权灭失，不可逆。

## 七、撰写检查清单

- [ ] 请求事项明确（撤驳 / 修改基础上撤驳）
- [ ] 修改说明在前、技术阐释居中、抗辩在后
- [ ] 每条驳回理由均有对应抗辩段落
- [ ] 四异对比表 + 原理剖析 + 效果论证齐备（创造性）
- [ ] 附图并列比对已嵌入且图号正确
- [ ] 证据清单与理由对应
- [ ] 修改对照表体现"前→后"且标注法33依据
