# 创造性论证链速查（复审复用 OA 方法论）

> 驳回决定多为创造性评述，其论证内核与"答复审查意见"完全相同。本文件浓缩 5 条核心论证链；完整可套用句式见本技能的 `references/论证链模板.md`。复审场景：把"审查意见"替换为"驳回决定"，受众增加原审查部门（前置审查）。

---

## 链1：否定最接近现有技术（起点错误）

```
【前提】审查指南：最接近现有技术应与发明技术领域/问题/效果相同、公开特征最多且最接近。
【事实】驳回决定以对比文件X为起点。但X解决的技术问题/效果与本申请根本不同；
        X自身背景技术明确批判/抛弃了本申请采用的路线；X缺少本申请核心要素，
        从X得到本申请需重建而非改进，无改进基础。
【推理】X不符合选择标准，不能作为评述创造性的技术原点。
【结论】基于X的"不具备创造性"结论不成立。
```

## 链2：区别特征协同（防割裂）

```
【前提】应从发明整体评价，不得割裂彼此关联的特征，须考察协同作用与整体效果。
【事实】驳回决定将"A+B+C"归纳为"A"孤立评价；但B/C是____（必要角色/物理机制），
        A/B/C协同实现____整体效果，缺一不可。
【推理】割裂导致对区别特征贡献与整体效果认定失真。
【结论】应作为整体区别特征评价，具备创造性。
```

## 链3：技术启示（作用不同则无启示）

```
【前提】对比文件须"公开该特征且起相同作用"才构成启示；作用不同则无启示。
【事实】驳回引用Y教导____。但Y中相关结构实际用于____，非本申请____；
        几何为____（如竖直）vs 本申请____（如水平），方向/位置/功能三重不同；
        Y未公开____（关键子特征）。
【推理】Y未公开相同特征、更未起相同作用，依法无启示。
【结论】相对"X+Y"具备创造性。
```

## 链4：常规技术手段驳斥

```
【前提】主张特征属公知常识/常规手段的，应举证或充分说理，不得仅以"常规"否定。
【事实】驳回认定____为常规。但该特征在____（真空/低温/动态载荷）环境下非理所当然；
        具体实现____（材料/参数/布置）系针对性设计；解决了____具体问题、有实质贡献；
        驳回未提供任何教科书/工具书证据，亦未说明为何"常规"。
【推理】认定缺乏证据与说理，违反公知常识认定要求。
【结论】该特征属对现有技术有贡献的特征，不应认定为常规；具备创造性。
```

## 链5：整体性原则与事后诸葛亮

```
【前提】须从整体出发、从发明完成时技术水平正向理解，禁止从结果反推（事后诸葛亮）。
【事实】驳回将各特征分别比对后拼凑"显而易见"；但各特征协同产生____整体效果，
        非线性叠加；申请日前无动机将____组合解决____问题；以事后视角裁剪事实属事后诸葛亮。
【推理】割裂+逆向拼凑违反整体性原则与禁止事后诸葛亮规则。
【结论】具备创造性，恳请撤销驳回决定。
```

## 复审特化补充

- 除上述 5 链，复审须额外在"事实与理由"中**点明驳回决定的违法/违规/事实错误**（见 `references/复审程序与前置审查.md` 第三节）：适用法律错误、违反法定程序（以放弃文本为依据、未给陈述意见机会、未评价有关证据）、事实认定错误。
- 撰写时 5 链可组合使用（创造性驳回常组合 链1+2+3+4+5）。
- 所有【前提】须引用具体指南条款（见本技能的 `references/审查指南条款速查.md`），不得省略；【事实】段落/标号须可复核。
- 附图并列比对（复用 `patent-oa-response` 的 `extract_figs.py`）增强直观性。
