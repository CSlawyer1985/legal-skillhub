# 驳回决定深度分析模板

> 复审的起点是"解构驳回决定"。用本模板把驳回决定拆成结构化清单，作为后续所有论证的索引。可用 `scripts/analyze_rejection.py` 辅助提取。

---

## 一、结构化清单字段

对驳回决定的**每一条驳回理由**建立一条记录：

| 字段 | 说明 | 示例 |
|------|------|------|
| 涉及权利要求 | 被驳回的权利要求号 | 权利要求1-10 |
| 驳回理由（法条） | 法22.3 / 22.2 / 26.4 / 26.4不支持 / 缺少必要技术特征 / 33等 | 法22.3 创造性 |
| 引用证据 | 对比文件编号 + 具体段落/标号 | 对比文件1（CN…）说明书[0025]段、标号7/9 |
| 审查员关键认定 | 摘录原文关键句 | "区别特征A属常规技术手段""对比文件2给出将上述特征用于D1的启示" |
| 技术起点认定 | 审查员选的最接近现有技术 | 对比文件1（D1） |
| 区别特征归纳 | 审查员认定的区别特征 | "特征A+特征B" |
| 实际解决的技术问题 | 审查员定义 | "如何……" |
| 可能偏差/违规点 | 初步判断（留待M3-M8填实） | 选错最接近现有技术 / 作用不同却认定有启示 / 随意认定常规手段 / 割裂特征 / 事后诸葛亮 / 程序违法 |

## 二、填写示例（创造性驳回）

```
【驳回理由记录 #1】
涉及权利要求：1-10
驳回理由：法22.3 创造性
技术起点（最接近现有技术）：对比文件1（CN121534801A，框架悬挂式光学恒温器）
区别特征归纳：审查员认定为"特征A及相关连接"
审查员关键认定：
  - "对比文件1已公开冷头与波纹管减振结构"
  - "区别特征属常规技术手段/惯用设置"
  - "对比文件2（CN109654786A）给出增设多级波纹管的启示"
  - "对比文件3（US8746008B1）的对置波纹管可用于消除轴向力"
初步偏差判断：
  - 起点错误：D1自身背景技术批判并抛弃了本申请的"冷头穿越波纹管"路线
  - 作用不同：D2为湿式液氦、冷头在上；D3对置波纹管为竖直同轴，均非本申请水平侧向第二波纹管
  - 常规手段无证据：未举证、未说理
  - 割裂特征：将协同的"弹簧+氟橡胶阻尼+柔性连接管"打包为"相关连接"
```

## 三、深度分析的四个追问（逐条）

1. **起点追问**：审查员选的最接近现有技术，是否与本申请技术领域/问题/效果相同、公开特征最多？若其自身批判本申请路线，则起点错误。
2. **特征追问**：审查员归纳的区别特征是否准确？是否把应协同的多个特征割裂、打包或遗漏子特征？
3. **启示追问**：其余对比文件是否**真实公开**该特征且**作用相同**？作用不同则无启示（硬核反驳）。
4. **程序追问**：驳回决定是否适用法律错误、违反法定程序（如以放弃文本为依据、未给陈述意见机会、未评价有关证据）？

## 四、输出

将清单交付为 `驳回决定分析.md` 或作为复审请求书"事实与理由"的提纲，确保 M3–M8 的每条论证都能映射回清单某条记录，**无遗漏**。
