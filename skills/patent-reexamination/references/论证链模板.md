# 论证链模板（按审查意见类型）

> 每个反驳观点按"前提→事实→推理→结论"组织，确保逻辑闭合、可复核。以下为可直接套用的句式模板，填空即可。

---

## 一、创造性——否定最接近现有技术

```
【前提】《专利审查指南》规定，最接近的现有技术应与发明技术领域相同（或相近）、
      所要解决技术问题相同（或相似）、技术效果相当，且公开特征最多、最接近；
      选择偏离上述标准的对比文件作为起点，评述根基不成立。

【事实】审查员以对比文件X作为最接近现有技术。但：
      (1) 对比文件X公开的是______（技术领域/方案），其要解决的技术问题是
          ______，与本申请所要解决的技术问题______根本不同；
      (2) 对比文件X自身背景技术中明确批判/抛弃了______路线（见其说明书第__段），
          而本申请正采用该路线；
      (3) 对比文件X缺少本申请的______等核心要素，从X出发得到本申请需
          ______（重建而非改进），无改进基础。

【推理】对比文件X不符合最接近现有技术选择标准，不能作为评述创造性的技术原点。

【结论】权利要求N的创造性评述起点错误，在此基础上得出的"不具备创造性"结论不成立。
```

## 二、创造性——区别特征准确性（防割裂、重协同）

```
【前提】审查指南要求从发明整体评价创造性，不得将彼此关联的技术特征割裂评价，
      应考察特征间的协同作用与整体技术效果。

【事实】审查员将本申请的"特征A+特征B+特征C"归纳为区别特征"特征A"并孤立评价，
      但：
      (1) 特征B、C并非附加装饰，而是______（说明其在系统中的必要角色与
          物理机制，如耗散振动能量、平衡压差）；
      (2) A/B/C共同作用实现______整体效果，三者缺一不可、相互依存；
      (3) 审查员忽略了______（具体协同关系）。

【推理】割裂评价导致对区别特征的技术贡献与整体效果认定失真。

【结论】应将该组特征作为整体区别特征评价，本申请具备创造性。
```

## 三、创造性——技术启示核查（作用不同则无启示）

```
【前提】只有当对比文件公开了区别特征且其在该文件中起相同作用时，才构成
      将该特征引入最接近现有技术的启示；作用不同则无启示。

【事实】审查员引用对比文件Y教导______。但：
      (1) 对比文件Y中相关结构（标号__）实际用于______，并非本申请的______；
      (2) 其几何布置为______（如竖直/水平），本申请为______（如水平/竖直），
          方向/位置/功能三重不同；
      (3) 对比文件Y未公开______（本申请关键子特征）。

【推理】对比文件Y既未公开相同特征，更未起相同作用，依法不能给出技术启示。

【结论】权利要求N相对于"对比文件X+对比文件Y"具备创造性。
```

## 四、创造性——驳斥"常规技术手段"

```
【前提】审查指南要求，主张某特征属公知常识/常规技术手段的，应举证或充分说理，
      不得仅以"常规""惯用"笼统否定。

【事实】审查员认定______为常规技术手段。但：
      (1) 该特征在本申请特定环境（如真空、低温、动态载荷）下并非理所当然；
      (2) 其具体实现（如材料/参数/布置______）并非唯一或公知，而是针对性设计；
      (3) 该特征解决了______具体问题，对克服现有技术缺陷有实质贡献；
      (4) 审查员未提供任何教科书/工具书证据，亦未说明为何"常规"。

【推理】"常规技术手段"认定缺乏证据与说理，违反指南关于公知常识认定的要求。

【结论】该特征属于对现有技术作出贡献的特征，不应被认定为常规技术手段；
      权利要求N具备创造性。
```

## 五、创造性——整体性原则与事后诸葛亮

```
【前提】创造性评价须从整体出发，且应从发明完成时的技术水平正向理解创造过程，
      禁止从结果反推（事后诸葛亮）。

【事实】审查员将各特征分别比对后拼凑出"显而易见"结论，但：
      (1) 各特征在本案中协同产生______整体效果，单独看均属"已知元件"，
          组合后的技术效果非线性叠加；
      (2) 申请日前本领域并无动机将______组合以解决______问题；
      (3) 若以申请日后视角裁剪事实、逆向拼凑，恰属事后诸葛亮。

【推理】割裂+逆向拼凑的评述违反整体性原则与禁止事后诸葛亮规则。

【结论】权利要求N具备创造性，恳请撤销原认定。
```

## 六、新颖性——逐项比对

```
【前提】新颖性须单独对比，权利要求每一技术特征须被一篇对比文件同一技术方案
      公开且作用/效果相同，方丧失新颖性。

【事实】审查员以对比文件Z否定新颖性。逐项核对：
      特征1：Z公开（标号__），作用相同 ✓
      特征2：Z公开（标号__），作用相同 ✓
      特征3：Z未公开 / Z中______作用为______（不同于本申请______）✗
      ……

【推理】存在特征__未被Z公开或作用不同，不满足单独、完整公开。

【结论】权利要求N相对于对比文件Z具备新颖性。
```

## 七、清楚性 / 支持

```
【前提】权利要求应清楚、以说明书为依据；概括应得到说明书支持。

【事实】审查员指______不清楚/不支持。但：
      (1) 术语______在说明书中明确定义为______（第__段），结合语境含义明确；
      (2) 说明书实施例__、__均支持该概括，本领域技术人员能确定保护范围；
      (3) （若修改）已将______限定为具体实施例特征，范围清晰且获支持。

【推理】术语含义可确定/概括合理，或经修改已克服。

【结论】权利要求N清楚/得到支持（或经修改后符合规定）。
```

---

## 八、修改超范围

```
【前提】修改不得超出原说明书和权利要求书记载的范围（含直接、毫无疑义确定的内容）。

【事实】本次修改将______补入权利要求N，依据为：
      (1) 原权利要求__/说明书第__段明确记载______；
      (2) （或）本领域技术人员可直接、毫无疑义确定______；
      (3) 未引入新技术方案/新效果。

【推理】修改在原记载范围内，不超范围。

【结论】修改符合《专利法》第33条。
```

## 使用约定

- 每个模板的【前提】必须引用具体指南条款（见 `审查指南条款速查.md`），不得省略。
- 【事实】中的段落/标号必须来自真实文档，引用后可复核；不确定的标号以"约第__段"标注并提示用户核对。
- 多个模板可组合使用（如创造性答复常组合 一+二+三+四+五）。
