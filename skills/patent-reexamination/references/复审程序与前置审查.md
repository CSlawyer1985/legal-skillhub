# 复审程序与前置审查（法定程序速查）

依据《专利法》第41条、《专利法实施细则》及《专利审查指南》第四部分第一章。

---

## 一、启动与时限（刚性）

- **请求期限**：对驳回决定不服，应自**收到驳回决定之日起 3 个月内**向复审和无效审理部请求复审。该期限刚性、不可延期；仅符合细则第6条/第116条恢复权利规定的，可在被视为未提出后请求恢复。
- **费用**：期限内提出请求但未缴/未缴足复审费的，请求视为未提出。
- **形式补正**：格式不符的，通知 15 日内补正；期满未补正或两次补正仍缺陷的，视为未提出。
- **委托**：委托代理机构且仅限于复审程序的，手续在复审和无效审理部办理，无需著录项目变更。

## 二、审查流程

```
收到驳回决定
   │  (3个月内) 提交复审请求书+理由+修改文本(可选)+复审费
   ▼
形式审查 → 受理通知书 / 补正 / 视为未提出
   ▼
转原审查部门 →【前置审查】→ 前置审查意见(3类)
   │                         │
   │(第1/2类)                │(第3类) 坚持驳回
   ▼                         ▼
复审委依前置意见作决定    进入【合议审查】
(不再合议)                 (一般仅针对驳回决定所依理由/证据)
   │                         │
   ▼                         ▼
复审决定(3类)            复审决定(3类)
```

## 三、前置审查（主战场）

复审请求书（含修改文本）形式合格后经转原审查部门，由原审查部门提出前置审查意见，**分三类**：

1. **第(1)类**：复审请求成立，同意撤销驳回决定（纯抗辩成功）。
2. **第(2)类**：提交的修改文本克服了缺陷，**同意在修改文本基础上撤销驳回决定**（修改换撤驳——最省力路径）。
3. **第(3)类**：意见与修改文本均不足以撤销驳回，坚持驳回。

**关键规则**：前置审查意见属第(1)或第(2)类的，复审和无效审理部**不再进行合议审查**，直接依前置意见作复审决定；原审查部门不得未经复审决定直接审批。

**策略含义**：把"好修改"作为首选筹码——让原审查员能在修改文本基础上体面撤驳，案件止步前置、高效翻盘。

## 四、合议审查范围

- 合议组**一般仅针对驳回决定所依据的理由和证据**审查。
- 例外可审查：驳回决定未指出但足以用已告知过的事实/理由/证据驳回的缺陷；与指出缺陷性质相同的缺陷；其他明显实质性缺陷（如永动机、公开不充分根源）；以及适度调整证据使用方式（如变更最接近现有技术）。
- 合议组可引入公知常识并补入技术词典/手册/教科书等证据。

## 五、复审阶段修改规则（细则第66条）

- 修改须符合**法第33条**（不超原记载范围）与**细则第66条**。
- 修改**仅限于消除驳回决定或合议组指出的缺陷**。
- **通常不符合**的情形：
  - (1) 修改后权利要求相对被驳回权利要求**扩大了保护范围**；
  - (2) 将与驳回权利要求缺乏单一性的技术方案作为修改后的权利要求；
  - (4) 针对缺陷未涉及的权利要求或说明书进行修改（明显文字错误、或与指出缺陷性质相同的修改除外）。
- 不符合细则66的修改文本合议组一般**不予接受**，以之前可接受的文本审查。

## 六、复审决定类型与效力

三种类型：
1. 复审请求不成立，驳回复审请求；
2. 复审请求成立，撤销驳回决定；
3. 申请文件经修改克服缺陷，**在修改文本基础上撤销驳回决定**。

撤销原驳回决定的，案卷退回原审查部门继续审查程序；原审查部门**必须执行**，不得以同样事实、理由、证据作出相反决定。

可撤销驳回决定的法定情形包括：**适用法律错误**；审查**违反法定程序**（如以放弃的文本为依据、未给予陈述意见机会、未评价与驳回理由有关的证据等）。

## 七、后续救济（兜底提示）

对复审决定不服，自收到决定起 **3 个月内**向**北京知识产权法院**提起行政诉讼（被告：国家知识产权局）；一审判决不服可上诉至北京市高级人民法院。本技能仅作提示，不代写诉状。

## 八、给智能体的操作要点

- 收到任务先**记录收文日、倒排 3 个月节点**，时限优先于一切打磨。
- 默认推荐"组合型"策略（修改+抗辩），但修改必须严守细则66与法33。
- 撰写时把"修改说明"放在理由前部，先给原审查员台阶，再加法律/技术抗辩。
- 所有时限、条款号引用须准确，不确定时标注"请核对最新版本"。
