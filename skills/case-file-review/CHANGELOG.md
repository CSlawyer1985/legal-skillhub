# CHANGELOG

## 1.0.0 (2026-07-22)

- 初始版本发布
- 支持两种输入模式：仅证据 / 起诉状+证据
- OCR 全程强制，支持 MinerU / PaddleOCR / legal-ocr
- 事实提取五维度（时间、主体、金额、行为、权利义务）
- 证据矛盾自动检测（5 类：时间、事实、金额、主体、证据链断裂）
- 矛盾三级标注（🔴严重 🟡一般 🟢轻微）
- HTML 时间轴生成 + agent-browser 截图转 PNG + Mermaid 备选
- 每条结论强制标注证据来源
- 内置常见案由构成要件框架（民间借贷、买卖合同、劳动争议、侵权）
- 双模板：模式 A 报告 / 模式 B 报告
