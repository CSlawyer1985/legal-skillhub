# 阅卷报告格式规范

## 通用要求

1. **文件格式**：Markdown（.md），层级清晰，可直接阅读或导入 Word
2. **文件命名**：`[案号或案件简称]_阅卷报告.md`，如无案号则用 `[当事人名称]_阅卷报告.md`
3. **语言风格**：专业但清晰，结论先行，每个判断都有依据
4. **必含元素**：每条结论必须标注证据来源（证据编号-页码-段落）
