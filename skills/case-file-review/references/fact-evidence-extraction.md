# 事实与证据提取规则

## 提取维度

对每份经过 OCR 的证据材料，按以下五个维度系统提取信息：

### 1. 时间节点

- 提取所有明确标注的日期和时间
- 区分"确定时间"（如"2024年3月15日"）与"模糊时间"（如"2024年3月中旬""约半年前"）
- 标注时间的确定性：`确定` / `推断` / `模糊`
- 交叉验证：同一事件在不同证据中的时间是否一致

### 2. 主体信息

- 自然人：姓名、身份证号（如有）、联系方式、住址
- 法人/组织：全称、统一社会信用代码（如有）、法定代表人、注册地址
- 主体关系：合同相对方、雇佣关系、代理关系、担保关系等
- 注意：同一主体在不同证据中可能以不同名称出现（如"张三"和"张先生"），需要统一

### 3. 金额/数量

- 提取所有具体数字：金额、数量、比例、期限
- 标注币种（人民币/美元/欧元等）
- 标注数字类型：`约定金额` / `实际金额` / `计算金额` / `争议金额`
- 注意大小写差异（如"伍拾万元整" vs "500,000元"）

### 4. 行为/事件

- 谁（主体）在什么时候做了什么
- 行为类型：签约、付款、交货、通知、催告、违约、协商等
- 行为结果：完成/未完成/部分完成/存在争议
- 行为是否有对应证据支撑

### 5. 权利与义务

- 合同/协议中约定的权利条款
- 各方承担的义务
- 违约责任条款
- 权利是否已行使、义务是否已履行

## 提取格式要求

每条提取的事实必须使用以下格式：

```
[证据编号-页码-段落] 时间 | 主体 | 行为/事件 | 金额/数量（如有）
```

示例：
```
[证1-第3页-第2段] 2024年3月15日 | 张三（出借人）向李四（借款人）转账 | 人民币50万元
[证2-第1页-第3段] 2024年3月10日 | 张三与李四签署《借款合同》 | 约定借款50万元，年利率12%，期限12个月
[证3-第5页-微信记录] 2024年9月15日 | 张三微信催告李四还款 | 要求"尽快还钱"
```

## 证据信息完整性评估

对每份证据评估其信息完整性：

| 评估维度 | 完整 | 部分完整 | 缺失 |
|---|---|---|---|
| 主体信息 | 各方主体明确可识别 | 部分主体信息不全 | 无法确定主体 |
| 时间信息 | 有明确日期 | 仅有模糊时间 | 无时间标记 |
| 金额信息 | 金额明确 | 金额可推算 | 无金额信息 |
| 签署/确认 | 有签名/盖章 | 仅有打印文本 | 无任何确认标记 |
| 原件/复印件 | 明确为原件 | 标注为复印件 | 无法判断 |

## 证据间关联关系

分析证据之间的关联关系：

- **直接印证**：证据 A 的内容与证据 B 完全一致（如合同金额与转账金额一致）
- **间接佐证**：证据 A 的某部分与证据 B 的某部分相关但不完全相同
- **补充关系**：证据 A 提供了证据 B 缺少的信息
- **冲突关系**：证据 A 与证据 B 在同一事实上不一致（→ 进入矛盾检测）
