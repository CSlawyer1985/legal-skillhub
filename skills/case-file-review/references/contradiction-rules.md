# 证据矛盾检测规则

## 检测方法

对所有证据进行两两交叉比对（N 份证据 = N×(N-1)/2 组比对），逐组检测是否存在矛盾。

## 矛盾类型

### 1. 时间矛盾

同一事件在不同证据中被记录为不同的时间。

**检测方法**：
- 提取所有证据中对同一事件的时间描述
- 比较日期/时间是否一致
- 允许 ±1 天的合理误差（如"次日"的理解差异）

**示例**：
```
矛盾点：借款日期
- 证1（借款合同）：2024年3月10日
- 证2（转账凭证）：2024年3月15日
→ 🟡 一般矛盾 — 合同签署日与打款日相差5天，需确认哪一天为借款生效日
```

### 2. 事实陈述矛盾

同一事实在不同证据中被描述为不同的版本。

**检测方法**：
- 提取所有证据中描述同一事实的陈述
- 比较关键要素（主体、行为、对象、结果）是否一致

**示例**：
```
矛盾点：违约原因
- 证3（甲方函件）：乙方未按时交货导致项目延期
- 证4（乙方回函）：甲方未按约支付进度款，乙方暂停交货
→ 🔴 严重矛盾 — 双方对违约责任的归属相互矛盾
```

### 3. 金额/数量矛盾

同一项目在不同证据中被记录为不同的金额或数量。

**检测方法**：
- 提取所有证据中的金额数字
- 匹配同一交易/事项的金额
- 比较数字是否一致（注意大小写差异）

**示例**：
```
矛盾点：借款本金
- 证1（借款合同）：人民币伍拾万元整（500,000元）
- 证2（转账凭证）：人民币300,000元
→ 🔴 严重矛盾 — 合同约定金额与实际转账金额相差20万元
```

### 4. 主体矛盾

同一角色在不同证据中被记录为不同的人或实体。

**检测方法**：
- 提取所有证据中的主体信息
- 比对同一法律关系中各方主体的名称/身份

**示例**：
```
矛盾点：收款方
- 证1（合同）：收款方为"A公司"
- 证2（转账凭证）：收款账户名为"张三（个人账户）"
→ 🟡 一般矛盾 — 合同约定的收款方与实际收款人不一致
```

### 5. 证据链断裂

证据之间存在逻辑断层，缺少中间的连接环节。

**检测方法**：
- 按事件发展顺序排列证据
- 检查相邻事件之间是否有合理连接
- 标注缺失环节

**示例**：
```
矛盾点：交货到验收之间的证据缺失
- 证5（发货单）：2024年4月1日发货
- 证6（验收单）：2024年4月20日验收
→ 🟡 一般矛盾 — 签收记录缺失，无法确认货物是否完好到达
```

## 矛盾等级判定

| 等级 | 标识 | 判定标准 | 处理建议 |
|---|---|---|---|
| 🔴 严重 | 致命矛盾 | 直接影响关键事实认定；可能导致诉讼请求无法成立 | 必须在报告中突出显示，建议优先调查核实 |
| 🟡 一般 | 普通矛盾 | 影响次要事实或细节；不改变案件基本定性但可能影响金额/责任比例 | 报告中列出，建议补充证据或要求当事人说明 |
| 🟢 轻微 | 可解释差异 | 存在合理解释空间的差异（如表述方式不同、四舍五入差异等） | 报告中备注，开庭时向法庭说明即可 |

## 输出格式

每个矛盾点必须包含以下信息：

```markdown
### 矛盾点 #N [矛盾等级]

- **涉及证据**：证X（证据名称）vs 证Y（证据名称）
- **矛盾类型**：时间矛盾 / 事实陈述矛盾 / 金额矛盾 / 主体矛盾 / 证据链断裂
- **矛盾内容**：[具体描述两份证据在同一事实上记载的不同内容]
- **来源**：[证X-页码-段落] vs [证Y-页码-段落]
- **可能影响**：[该矛盾对案件可能产生的影响]
- **建议处理**：[如何核实或弥补该矛盾]
```

## 自动检测提示词

在实际执行矛盾检测时，按以下步骤逐一扫描：

1. "逐份列出每份证据中的所有时间节点，然后交叉比较同一事件的时间是否一致"
2. "逐份列出每份证据中关于事实的陈述，比较同一事件的描述是否一致"
3. "逐份列出每份证据中的所有金额数字，匹配同一交易的金额是否一致"
4. "逐份列出每份证据中出现的所有主体名称，检查同一角色是否有不同主体"
5. "按时间顺序排列所有事件，检查是否存在逻辑断层"
