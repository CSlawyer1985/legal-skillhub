# 证券虚假陈述投资者损失计算表（可视化）

> 面向证券虚假陈述民事赔偿案件的投资者损失测算。本技能产出一份**单文件、可离线打开、可编辑、可打印（Ctrl/Cmd+P 导出 PDF）的交互式 HTML 计算表**，口径与律师常用的附件 Excel 一致。

## 一、定位与强制规则

- 立场：本工具为**中立计算辅助**，不预设立场；最终索赔金额与可赔范围以司法裁判为准。
- 关键事实（实施日、揭露日/更正日、基准日、基准价）属法院认定事项，**须以行政处罚决定书、刑事判决书或法院文书为准**，工具仅作计算，不得直接采信示意值。
- 事实与观点分离：工具输出为计算结果（事实性数值），法律可赔性判断为观点，须另行说明依据。
- 风险提示常态化：两种口径的差异、差额损失不为负、利息未含等，均须在交付/说明中提示。

## 二、计算口径（与附件 Excel 一致）

1. **买入均价（移动加权平均法）**：逐笔四舍五入，权重采用"持仓"（含卖出影响），即
   `新均价 = ROUND((原均价×原持仓 + 本笔数量×本笔价格) ÷ 新持仓, 2)`，卖出不改变均价。
   - 采用整数分（cents）精确运算消除浮点漂移，确保与 Excel `ROUND` 逐笔结果一致。
2. **可索赔股数** = 实施日之后、揭露日之前净买入数量 − 揭露日前已卖出数量（即揭露日时仍持有的净头寸）。
3. **本表口径（基准价法，保守）**：投资差额损失 = 可索赔股数 ×（买入均价 − 基准价）。
4. **严格司法解释口径（法释〔2022〕2号 第二十七条）**：
   投资差额损失 = Σ（买入均价 − 实际卖出价）× 揭露日~基准日卖出量 +（买入均价 − 基准价）× 基准日仍持有量。
5. **佣金 / 印花税** = 投资差额损失 × 对应比例（本表按差额损失估算，非实际发生费用；亦可改为按实际已付费用列示）。
6. **总损失** = 投资差额损失 + 佣金 + 印花税（司法解释另可主张利息，本表未含，按需补充）。

## 三、使用方法（Agent 调用流程）

1. 调用本技能时，将附带的 `template.html` 复制到当前工作区（如 `/Users/.../证券虚假陈述投资者损失计算表.html`）。
2. 若用户提供了交易记录 Excel：
   - 用 Python/openpyxl 解析，提取每笔：日期、买卖类别、成交数量、成交价格（及手续费/印花税）。
   - 提取关键参数：证券代码/名称、实施日、揭露日、基准日、基准价（如 Excel 中已填）。
   - 将解析结果注入 `template.html` 顶部的 `EXAMPLE` 数组与"基本参数"默认值（或直接告知用户打开后粘贴）。
3. 用 `present_files` 打开/预览该 HTML 交付用户。
4. 提示两种口径差异与风险（见第四节）。

> 注：HTML 内表格、参数、利率均可直接在浏览器中编辑，改动即重算，无需改代码。

## 四、风险提示（必须随交付说明）

- **口径差异**：附件所用"全部可索赔股数按基准价"为保守口径；对揭露日~基准日期间已实际卖出的部分，严格司法解释应按**实际卖出价**计算，金额可能更高（示例差约 7,504.50 元）。实际以法院认定为准，建议就差额部分作区间主张或沟通。
- **差额损失不为负**：若（买入均价 − 基准价）或（买入均价 − 实际卖价）为负，该部分无差额损失。
- **利息未含**：本表未计资金占用利息，按需补充。
- **费用口径**：佣金/印花税按差额损失比例估算；亦可改为按实际交易费用列示，两种列示可能影响总额。
- 本工具为办案辅助，**不构成法律意见**。

## 五、交付物

- `证券虚假陈述投资者损失计算表.html`：交互式可视化计算表（含交易记录表、参数、结果卡片、价格走势图、持仓图、损失构成图、方法说明与风险提示）。
- 可选：将计算结果誊写为 Word/Excel 正式损失计算表（按用户后续要求）。
