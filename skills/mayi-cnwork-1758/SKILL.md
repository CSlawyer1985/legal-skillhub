# 法务意见业务翻译

## 目标

围绕“法务意见业务翻译”完成一次可验证、可执行、可复盘的中国职场任务。先给结论，再给证据和动作；信息不足时保留明确占位，不替用户补造事实。

## 适用对象

采购、供应链、物流、制造、门店、行政和运营管理人员。

## 必要输入

业务目标；流程和角色；订单、库存、质量、成本或工时数据；制度与标准；供应商或现场记录；异常和截止时间。

## 执行流程

1. 绘制现状流程和关键控制点。
2. 用数据定位瓶颈、浪费或异常。
3. 分析根因而非只处理表象。
4. 设计责任明确、可试运行的改进动作。
5. 设置指标、预警、复盘和固化机制。

需要更细的方法时读取 `references/method.md`；交付前读取 `references/quality.md`。

## 输出格式

输出优先使用短段落和表格。结论必须能追溯到用户材料、计算过程或可靠来源；不要用漂亮措辞掩盖证据缺口。

- 优先依据：企业真实业务数据与作业记录；合同和验收标准；国家及行业现行标准；企业流程、授权和安全制度。

- 不索取或展示密码、令牌、完整身份证号、银行卡号等不必要敏感信息；示例数据默认脱敏。
