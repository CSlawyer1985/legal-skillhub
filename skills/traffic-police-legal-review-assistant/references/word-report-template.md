# 审核报告 Word 模板与编号规则

本文件供 Step 7「审核报告出具询问」环节使用。当用户确认需要 Word 格式审核报告时，按本文件的编号规则和模板结构，调用 **ima-docx** 技能生成 `.docx` 文件。

---

## 一、报告编号规则

### 编号格式
```
FZ-[办案单位代码]-[年份]-[序号]
```

| 字段 | 含义 | 取值规则 |
|:----:|:-----|:--------|
| FZ | 固定前缀 | "法制审核"拼音首字母 |
| 办案单位代码 | 交警大队/中队代码 | 取办案单位简称拼音首字母或数字代号（如：HHHT=呼和浩特、XXD=XX大队） |
| 年份 | 审核年度 | 4位年份（如2026） |
| 序号 | 当年流水号 | 3位补零（001起，按当年累计） |

### 编号示例
- `FZ-HHHT-2026-001` —— 呼和浩特支队2026年第1份审核报告
- `FZ-XXD-2026-012` —— XX大队2026年第12份审核报告
- `FZ-NMG-2026-108` —— 内蒙古（省级）2026年第108份审核报告

### 编号生成逻辑
1. 读取办案单位名称 → 映射为单位代码（见下方对照表，未列出的取名称拼音首字母）
2. 读取审核年份 → 取当前年份
3. 序号 = 该单位当年已出具报告数 + 1（从会话记录/输出目录中累计；若无法获知历史，从001起并提示用户确认）

### 常用单位代码对照表
| 办案单位 | 代码 |
|:--------|:----:|

## 三、Word 生成操作指引

1. **确认编号**：按第一节规则生成 `FZ-单位-年份-序号`
2. **组织内容**：将对话中的审核结论按第二节省结构填充
3. **调用 ima-docx**：使用 ima-docx 技能创建 .docx 文档，应用以下格式：
   - 标题：黑体二号，居中
   - 一级标题：黑体三号
   - 二级标题：楷体小三号
   - 正文：仿宋小三号
   - 表格：单倍行距，边框完整
4. **输出路径**：保存至 `/sandbox/workspace/outputs/` 目录，文件名格式：`法制审核报告-FZ-单位-年份-序号.docx`
5. **返回用户**：报告编号 + 文件路径

## 四、报告状态标识

| 审核意见 | 封面标识色 | 说明 |
|:--------|:----------|:-----|
| 通过 | 绿色 | 案件审核通过，可进入下一步 |
| 补正 | 黄色 | 需办案单位补充材料后重新审核 |
| 退补 | 红色 | 存在重大程序违法/事实不清，退回重办 |
| 撤销 | 灰色 | 案件不应处罚，建议撤销 |
