# 证据闭环强化指引

## 核心理念：结论→证据 双向追溯

法制审核的核心原则是**"每一条结论，必须有对应证据支撑"**。本指引提供结论-证据对照表和回溯核查机制，确保审核意见的每项判断均有据可查。

## 二、五维审核结论-证据映射标准

### 维度一：证据审查

| 审核项 | 审核结论 | 必须对应的证据 | 常见缺失 |
|:------|:--------|:-------------|:---------|
| 证据充分性 | 证据足以证明违法事实 / 证据不足 | 全部证据清单 | 仅有当事人陈述无其他佐证 |
| 证据合法性 | 收集程序合法 / 存在非法取证情形 | 执法记录、提取笔录 | 无执法记录/无见证人 |
| 证据真实性 | 证据真实可信 / 存在伪造嫌疑 | 原始证据、鉴定意见 | 复印件无原件核对 |
| 证据关联性 | 证据与违法事实关联 / 无关证据已排除 | 证据与违法行为的逻辑连接说明 | 关联性说理不足 |

### 维度二：主体审核

| 审核项 | 审核结论 | 必须对应的证据 | 常见缺失 |
|:------|:--------|:-------------|:---------|
| 当事人身份 | 身份确认无误 / 身份存疑 | 身份证、驾驶证原件核对记录 | 无身份证件复印件 |
| 驾驶证状态 | 驾驶证有效 / 已注销/扣留/吊销 | 驾驶证查询记录、公安网信息截图 | 仅凭当事人自述无系统查询 |
| 车辆状态 | 车辆状态正常 / 存在异常 | 行驶证、车辆查询记录 | 未核实车辆年检/保险状态 |
| 准驾车型 | 准驾相符 / 准驾不符 | 驾驶证准驾车型+车辆类型 | 未核对驾驶证背面准驾车型 |

### 维度三：量罚审核

| 审核项 | 审核结论 | 必须对应的证据 | 常见缺失 |
|:------|:--------|:-------------|:---------|
| 违法事实定性 | 定性准确 / 需重新定性 | 违法事实证据链 | 定性缺少法条依据 |
| 处罚幅度 | 在法定幅度内 / 超出法定幅度 | 对应法条原文 | 引用法条与事实不匹配 |
| 从轻/减轻 | 有/无从轻减轻情节 | 当事人立功/配合记录等 | 从轻理由无证据支撑 |
| 从重 | 有/无从重情节 | 后果证据、历史记录 | 从重情节未在案卷中载明 |
| 一案双罚 | 需/不需一案双罚 | 企业信息、单位证明 | 遗漏企业处罚 |
| 多违法并罚 | 并罚方案合规 / 需调整 | 违法行为清单+并罚规则 | 遗漏某项违法或处罚重复 |

### 维度四：程序审查

| 审核项 | 审核结论 | 必须对应的证据 | 常见缺失 |
|:------|:--------|:-------------|:---------|
| 受案登记 | 已按规定受案 | 受案登记表 | 无受案登记直接进入调查 |
| 告知程序 | 已履行告知义务 | 告知笔录/告知记录 | 无当事人签字确认 |
| 听证权 | 已告知/无需告知 | 听证权告知记录 | 应告知未告知（程序违法） |
| 扣证期限 | 未超期/已超期 | 强制措施凭证日期 | 超期未说明理由/未续批 |
| 办案期限 | 未超期/已超期 | 受案日期+结案日期 | 超期无延期审批 |
| 送达程序 | 送达合规/需补正 | 送达回执 | 公告送达前未尝试直接送达 |

### 维度五：综合结论

| 审核项 | 审核结论 | 支撑证据汇总 |
|:------|:--------|:------------|
| 案件定性 | 准确 / 需重新定性 | 汇总C-01至C-XX证据审查结论 |
| 法条匹配 | 匹配 / 不匹配 | 汇总量罚审核结论 |
| 审核意见 | 通过/补正/退补/撤销 | 汇总全部维度结论 |
| 意见书出具 | 已出具/待出具 | 审核意见书文本 |

## 三、证据闭环检查清单

审核完成后，逐项自查以下闭环问题：

### 🔄 正向检查（结论→证据）
```
□ 每一条审核结论是否都有对应的证据编号？
□ 量罚建议是否有对应的法条依据（精确到款/项）？
□ 程序合规判断是否有对应的办案文书日期？
□ 综合结论是否建立了前四个维度结论的综合映射？
```

### 🔄 反向检查（证据→结论）
```
□ 案件中的每份证据是否都已纳入审核（无遗漏）？
□ 是否有证据被列入清单但未在审核结论中体现？
□ 是否有证据存在三性瑕疵但未在审核意见中说明？
□ 关键证据（检测单/鉴定意见/执法记录）是否都已审核？
```

### 🔄 缺口检查
```
□ 是否存在"结论有、证据无"的情况？（结论无支撑→退补）
□ 是否存在"证据有、结论无"的情况？（证据遗漏→补充审核）
□ 是否存在"当事人陈述vs客观证据不一致"的情况？（矛盾→标注需核实）
□ 审核意见书中的"建议补正"项是否有对应的证据缺口说明？
```

## 四、证据闭环级别判定

| 闭环级别 | 判定标准 | 对应审核意见 |
|:--------:|:--------|:------------|
| 🔵 **A级（完全闭环）** | 每条结论均有≥1个证据支撑；证据覆盖全部违法事实 | 审核通过 |
| 🟡 **B级（基本闭环）** | 主要结论有证据支撑；个别次要结论需补充证据 | 审核通过（附补正建议） |
| 🟠 **C级（部分闭环）** | 关键结论有证据支撑；部分证据缺失/三性存疑 | 审核意见：补正 |
| 🔴 **D级（未闭环）** | 关键结论无证据支撑；证据链断裂；存在重大矛盾 | 审核意见：退补 |

## 五、常见证据闭合失误示例

| 失误类型 | 表现 | 后果 | 纠正方法 |
|:--------|:-----|:----|:---------|
| 孤证定案 | 仅凭当事人陈述认定违法事实 | 证据不足，无法排除合理怀疑 | 要求补充执法记录/证人证言 |
| 超期证据 | 以超过办案期限后收集的证据定案 | 证据合法性受影响 | 标注超期，说明是否补救 |
| 矛盾证据未排除 | 两份证据存在重大矛盾未核查 | 事实认定不清 | 备注矛盾项，建议调取第三方证据 |
| 间接证据推断 | 用间接证据推断直接违法事实 | 证明力度不足 | 标注为"需进一步核实" |
| 证据来源不明 | 证据无制作人/提取人/来源说明 | 真实性无法确认 | 要求补充来源说明 |
| 缺乏原件核对 | 复印件/截图无原件核对记录 | 真实性存疑 | 标注"待核对原件" |
| 鉴定资质缺失 | 鉴定机构/人员无资质证明 | 鉴定意见无效 | 要求补充资质证明 |

#### 四类逻辑论证失误专项补充（证据推理专项，v1.4.4新增）

在证据闭合中，除上表列示的取证类失误外，以下四类**逻辑论证失误**最常导致退补，须专项排查（对应 `evidence-reasoning-guide.md` 第三节约六红线）：

| 失误类型 | 表现 | 后果 | 纠正方法 |
|:---|:---|:---|:---|
| 过度推断 | 由"事故后饮过酒"跳跃至"事故前必已醉酒" | 实体要件无支撑 | 标注为待证，退回补查事故前饮酒证据 |
| 违背经验法则 | 忽略酒精代谢速率，以查获值倒推驾驶时血醇 | 推算无依据 | 须有回溯推算支撑且锚点成立 |
| 因果未锚定 | 将二次饮酒程序性推定等同于实体因果认定 | 因果力不当放大 | 区分程序性拟制与实体因果，锚定具体事实 |
| 主观未锁定 | 以推测替代对"逃避目的"等主观要件证据锁定 | 主观要件缺失 | 补充前科/躲避过程等客观线索 |
