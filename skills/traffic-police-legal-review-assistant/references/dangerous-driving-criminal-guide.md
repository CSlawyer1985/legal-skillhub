# 危险驾驶罪全类型刑事立案审查指南

> **定位**：本指南覆盖《刑法》第一百三十三条之一规定的全部四类危险驾驶行为，供交警队法制员在行政案件审核中发现可能构成刑事犯罪的，进行刑事立案/移送审查。
> **与 `drinks-driving-procedure-guide.md` 的关系**：醉驾型（第二类）的详细办案流程、证据规格、强制措施、快速办理、行政处罚衔接等已在该指南系统写入；本指南侧重另三类（追逐竞驶、严重超员超速、违规运输危化品）的立案标准与审核要点，并对四类作体系化归纳。
> **数据基准**：《刑法》第133条之一（2011年《刑法修正案（八）》增设第1、2项；2015年《刑法修正案（九）》扩充第3、4项）；公传发〔2015〕708号《严重超员、严重超速危险驾驶刑事案件立案标准（试行）》；《危险化学品安全管理条例》；**《危险化学品安全法》（2026年5月1日施行，危化品安全领域首部基础性专门法律）**；《道路交通安全法》及其实施条例。
> **版权合规**：本指南内容以刑法条文、公安部立案标准、最高法指导性案例及官方裁判规则为依据，不引用任何非官方公众号署名。

## 第一部分：危险驾驶罪罪名体系总览

### 一、四类行为（刑法第133条之一第1款）

| 序号 | 行为类型 | 核心要件 | 本罪性质 |
|:---:|------|------|:------:|
| （一） | 追逐竞驶 | 情节恶劣 | 抽象危险犯 |
| （二） | 醉酒驾驶机动车 | 血醇≥80mg/100ml（详见醉驾指南） | 抽象危险犯 |
| （三） | 校车/客运严重超员或严重超速 | 从事校车业务或旅客运输中严重超员/超速 | 抽象危险犯 |
| （四） | 违规运输危险化学品 | 违反危化品安全管理规定，危及公共安全 | 具体危险犯 |

### 二、双罚主体（第2款）

机动车所有人、管理人对第（三）项、第（四）项行为负有直接责任的，依照第1款的规定处罚。

> **审核要点**：除驾驶人外，应审查车辆所有人/管理人是否负有直接责任——包括企业安全管理制度缺失、调度指令要求超员/超速、明知无资质仍派车运输危化品等。应启动对单位责任人员的双罚审查，避免只罚驾驶人漏罚责任人。

### 三、数罪处罚原则（第3款）

有前两款行为，同时构成其他犯罪的，依照处罚较重的规定定罪处罚。

> **审核要点**：追逐竞驶/超员超速/危化品运输若引发事故致伤死或重大财产损失，可能同时构成交通肇事罪或以危险方法危害公共安全罪，应提示按重罪论处（见第六部分）。

## 第二部分：追逐竞驶型危险驾驶（第1项）

### 一、概念认定（最高人民法院指导案例32号 张某某、金某某危险驾驶案）

**裁判要点**：
1. 机动车驾驶人员出于竞技、追求刺激、斗气或者其他动机，在道路上曲折穿行、快速追赶行驶的，属于"追逐竞驶"。
2. 追逐竞驶虽未造成人员伤亡或财产损失，但综合超速、闯红灯、强行超车、抗拒交通执法等严重违反道路交通安全法的行为，足以威胁他人生命、财产安全的，属于"情节恶劣"。

**认定要素**：
- **互动性**：是否存在相互追赶、超越、并行等有对抗、比赛性质的行为。
- **目的性**：是否有比拼速度、车技、追求刺激的目的。
- **常见辩护点**：论证行为人仅超速但无追逐。要注意区分单纯超速行政违法与追逐竞驶犯罪——无互动性、无竞速目的的单纯超速，不构成此罪（按超速行政违法处理）。

### 二、"情节恶劣"认定标准

一般追逐竞驶不构成犯罪，须达到情节恶劣。参照最高法在危险驾驶罪司法裁判中确立的情节恶劣认定标准，以下情形可认定为情节恶劣：

1. **严重超速追逐**：超过规定时速50%且超过每小时90公里行驶（衔接道交法第99条第1款第4项；实践中以城市道路最高限速60km/h为基准把握，超速50%且达90km/h作为参考最低值）。
2. **造成事故**：追逐竞驶造成交通事故致他人轻微伤以上，或公私财产损失5万元以上，且负事故同等及以上责任（尚未构成其他犯罪）。
3. **无证追逐**：未取得驾驶证，或准驾不符，或驾驶证被吊销、扣留期间仍驾驶而追逐竞驶。
4. **涉牌违法追逐**：伪造变造、使用其他车辆号牌，或故意遮挡、污损、未悬挂号牌而追逐竞驶（反映逃避责任的主观恶性）。
5. **饮酒/服药后追逐**：饮酒、服用精神药品或麻醉药品后追逐竞驶（衔接道交法第22条第2款）。
6. **特殊车辆追逐**：驾驶客运汽车、校车、重载货车、危化品运输车等负有更高注意义务车辆追逐竞驶。
7. **聚众追逐**：聚众要求3人以上。组织者、指挥者、非驾驶人积极参加者可作为共犯追责；从犯原则不再追究。
8. **屡犯**：1年内多次追逐竞驶未被处罚，或因追逐竞驶被给予2次行政处罚仍追逐竞驶（反映主观恶性）。
9. **其他恶劣情形**：在学校、医院、市中心等人流量大的道路追逐竞驶；追逐中反复变道、逆行、闯红灯等（结合实际案情判断）。

> **审核提示**：上述情形为情节恶劣的综合判断参考，并非法定封闭清单。审核时应结合案情，重点审查"是否足以威胁公共安全"。

### 三、证据审查要点

1. **监控视频与行车轨迹**：是最重要客观证据，应提取沿途卡口、社会监控、行车记录仪。
2. **主观目的认定**：高度依赖间接证据与客观行为反推（鸣笛、并排行驶、连续闪大灯、相互别车等）。
3. **案发环境证据**：调取案发路段道路性质、案发时间车流量人流量，用于判断危险程度。

### 四、定性区分（三阶体系）

危险驾驶罪（抽象危险犯，拘役）— 交通肇事罪（过失实害犯，致伤亡）— 以危险方法危害公共安全罪（具体危险/实害，重罪）。三者构成递进的罪名体系。

> **审核提示**：追逐竞驶若对不特定多数人安全持故意（如闹市区高速逆行、冲撞），可能升格为以危险方法危害公共安全罪，应在审核意见书中提示，避免漏罪（见第六部分）。

## 第三部分：校车/客运严重超员超速型（第3项）

### 一、立案标准（公传发〔2015〕708号《严重超员、严重超速危险驾驶刑事案件立案标准（试行）》）

**（一）严重超员**（从事校车业务或者公路客运、旅游客运、包车客运）：

| 车型 | 刑事立案标准 |
|------|------|
| 大型载客汽车 | 载客超过额定乘员 **50%以上**，或超过额定乘员 **15人以上** |
| 中型载客汽车 | 载客超过额定乘员 **80%以上**，或超过额定乘员 **10人以上** |
| 小型、微型载客汽车 | 载客超过额定乘员 **100%以上**，或超过额定乘员 **7人以上** |

**（二）严重超速**（同上业务类型）：

| 道路情形 | 刑事立案标准 |
|------|------|
| 高速公路、城市快速路 | 超过规定时速 **50%以上**，且行驶时速达到 **90公里以上** |
| 高速公路、城市快速路以外道路 | 超过规定时速 **100%以上**，且行驶时速达到 **60公里以上** |
| 铁路道口、急弯路、窄路、冰雪泥泞道路，或掉头/转弯/下陡坡，或低能见度气象条件 | 超过规定时速 **50%以上**，且行驶时速达到 **30公里以上** |
| 傍山险路、连续下坡、连续急弯等事故易发路段 | 超过规定时速 **50%以上**，且行驶时速达到 **30公里以上** |

### 二、审核要点

1. **业务范围限定**：仅"校车业务""公路客运/旅游客运/包车客运"的旅客运输业务适用刑事立案。社会车辆（私家车超员、非营运面包车超员）一般按行政超员处罚（C类），不构成本罪——除非达到极端程度且明显危及公共安全。
2. **核定人数计算**：以车辆行驶证核定载客人数为准，含驾驶人。
3. **双罚审查**：机动车所有人/管理人对严重超员超速负有直接责任的，追究刑责（审查单位安全制度、调度指令、明知超载仍派车等）。
4. **行政与刑事衔接**：C类行政超员记分标准（如超员20%以上记12分）与刑事立案标准不同，审核时应先判断是否达到刑案标准，达到则移送，避免"以罚代刑"。

### 三、证据审查要点

1. 车辆行驶证（核定人数）、实际载客清点记录/照片/视频。
2. 行驶速度鉴定意见（GPS轨迹、测速设备数据）。
3. 营运资质证明（校车使用许可、道路运输证）。
4. 所有人/管理人责任证据（派车单、调度记录、安全管理制度文件）。

## 第四部分：违规运输危化品型（第4项）

> **⚠️ 法规时效提示**：《中华人民共和国危险化学品安全法》已于 **2026年5月1日施行**（2025年12月27日第十四届全国人大常委会第十九次会议通过，共10章127条），系危化品安全领域首部基础性专门法律，将危化品安全管理由行政法规（条例）提升至法律层级。刑法第133条之一第4项"违反危险化学品安全管理规定"中的"规定"，现应**同时包含《危险化学品安全法》与新法施行后继续有效的《危险化学品安全管理条例》及配套规章**。本部分审核依据已同步更新。

### 一、立案情形（违反《危险化学品安全法》及《危险化学品安全管理条例》等规定）

依据新法第六章"运输安全"（第64-84条）及刑法第133条之一第4项，以下情形属于违规运输危险化学品、危及公共安全的，构成本罪：

1. 未取得道路危险货物运输许可，擅自从事道路危险货物运输（新法第65条：须取得危险货物道路运输许可，其他单位和个人不得承运）；
2. 使用失效、伪造、变造、被注销等无效道路危险货物运输许可证件从事运输；
3. 超越许可事项从事道路危险货物运输；
4. 非经营性道路危险货物运输单位从事道路危险货物运输经营；
5. 配套违法情形（可作为"危及公共安全"的危险性佐证）：未依新法第66条配备持证驾驶人/押运员；违反第68条未悬挂/遮挡拆除警示标志；违反第70条未经公安批准进入限行区；违反第71条无剧毒化学品道路运输通行证运输剧毒化学品。

> **注意**：本罪为危险犯，以"危及公共安全"为要件，不以实际发生危害后果为前提。

### 二、审核要点

1. **危化品认定**：依据《危险化学品目录》核实运输物质是否属于危险化学品（含易燃、易爆、有毒、有腐蚀性等）。
2. **许可审查**：运输企业是否取得《道路危险货物运输许可证》；驾驶人是否具备危险货物运输从业资格。
3. **双罚审查**：机动车所有人/管理人对违规运输负有直接责任的，追究刑责。
4. **与行政违法衔接**：O类行政违法（未按指定时间/路线/速度行驶、未悬挂警示标志、未经批准进入限行区等，记6分）属一般性违法；若达到"未取得许可擅自运输且危及公共安全"，则刑事移送。
5. **与治安管理处罚法衔接**：非法运输危险物质未达犯罪程度的，可能适用《治安管理处罚法》第30条。
6. **🆕 部门监管边界（新法厘清）**：审核移送时应注意职责划分——**公安交管**负责车辆限行通行、剧毒化学品道路运输通行证、车身警示标志遮挡/拆除、途中长时间停车报备等；**交通运输部门**负责经营许可、人车动态实时监控（新法第109条，罚款5万-50万）等。同一违规运输行为可能涉及两部门，审核时应厘清，避免越权查处或漏管。

### 三、证据审查要点

1. 危化品性质鉴定/目录比对。
2. 运输许可资质（许可证真伪、有效期限、许可范围）。
3. 运输合同/订单、车辆营运证、驾驶人资格。
4. 两法衔接材料：交通运管、应急管理部门移送线索及查获经过。

## 第五部分：两法衔接（行政→刑事移送）通用审查要点

（适用于四类危险驾驶罪的刑事移送审查）

1. **移送条件**：行政机关在查处行政违法中发现涉嫌危险驾驶罪，应在规定期限内移送公安机关刑侦/法制部门。
2. **移送材料**：现场检查笔录、视听资料、鉴定意见、询问笔录、车辆/人员资质证明等。
3. **证据转化**：行政执法证据在刑事诉讼中经审查可转化为刑事证据，应注意取证主体与程序合法性。
4. **时效衔接**：刑事追诉时效（危险驾驶罪最高刑拘役6个月，追诉时效5年）与行政处罚时效并行计算。
5. **不重复处罚**：同一行为已作行政处罚的，刑事判决罚金时应依法折抵（《行政处罚法》第35条）。

## 第六部分：四类竞合与数罪处罚

（刑法第133条之一第3款：同时构成其他犯罪的，从一重处断）

1. **危险驾驶 + 交通肇事**：致人重伤/死亡且负主要责任，以交通肇事罪论处（最高可至有期徒刑）。
2. **危险驾驶 + 以危险方法危害公共安全**：主观故意明显、危害极端，以以危险方法危害公共安全罪论处。
3. **醉驾 + 追逐竞驶**：同一行为兼具的，按一罪（危险驾驶罪）从重，不数罪并罚。
4. **审核提示**：发现可能升格为重罪的，应在审核意见书中明确提示，避免漏罪、避免降格处理。

## 第七部分：毒驾（吸食毒品后驾驶）独立审查（最高人民法院指导案例268号）

> 毒驾虽不单独构成危险驾驶罪，但属严重危害公共安全的违法驾驶行为，常与醉驾、无证等并罚或作为从重处罚情节。本部分独立审查毒驾证据链，与醉驾证据审查并行。

### 一、毒驾认定依据
- 依据《道路交通安全法》第22条（饮酒、服用国家管制的精神药品或麻醉药品不得驾驶机动车）及第90条处罚；涉及毒品违法的，依《治安管理处罚法》《禁毒法》处理。
- 最高人民法院指导案例268号确立毒驾相关裁判/审查规则，作为毒检证据审查与量刑评价的参照。

### 二、毒驾独立毒检证据审查要点
1. **检测对象**：尿液/血液/毛发毒品检测；毛发检测可反映较长时段用药史，血液/尿液反映近期。
2. **程序合规**：由具备资质机构检测，使用合格试剂与标准操作；采样须有见证、封存、送检链条完整。
3. **结果采信**：鉴定意见须载明检材、方法、检出物及含量；阳性结果须排除医用处方（如持处方服用管制药品）情形。
4. **驾驶时状态锚定**：毒驾认定须锚定"驾驶时"是否处于被管制药品影响状态；事后检测须结合代谢窗口说明与驾驶时点的关联。
5. **与醉驾竞合**：毒驾+醉驾并存时，分别评价；毒驾可作为醉驾量刑从重情节，并依 `multi-violation-guide.md` 第四部分（量刑竞合分析）处理。

### 三、毒检程序瑕疵分级处理（P0-P3，参照 drinks 血样瑕疵分级）
| 等级 | 情形 | 处理 |
|:---|:---|:---|
| P0 | 检材来源不明、无资质机构/人员、采样无封存链条 | 毒检意见无效，须重新鉴定或退补 |
| P1 | 送检链条存在可补正瑕疵（如见证人签字缺失） | 补正或合理解释后可采信 |
| P2 | 检测方法/试剂记录不完备但不影响结论 | 补充说明后认定 |
| P3 | 仅形式瑕疵（如文书格式） | 综合认定 |

### 四、审核结论衔接
- 毒驾本身不构罪，但应作为违法事实在审核意见书中载明，并提示行政处罚（拘留/罚款）与可能的刑事牵连（如同时构成以危险方法危害公共安全）。
- 证据缺口参照 `evidence-reasoning-guide.md` 灵魂三击与六红线审查。
