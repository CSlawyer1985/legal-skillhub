# 饮酒驾驶与醉酒驾驶案件办理流程指南

> **定位**：本指南为"交管智辅·法制审核助手"的专项流程参考，覆盖饮酒驾驶行政案件和醉酒驾驶刑事案件的完整办理流程、最新司法解释及法理释义。
> **数据基准**：本指南依据《道路交通安全法》（2021年修正）、《道路交通安全违法行为处理程序规定》（公安部令第157号，2020.5.1施行）、《公安机关办理行政案件程序规定》、《最高人民法院、最高人民检察院、公安部、司法部关于办理醉酒危险驾驶刑事案件的意见》（高检发办字〔2023〕187号，2023.12.28施行）、《车辆驾驶人员血液、呼气酒精含量阈值与检验》（GB19522-2024）、《交通警察道路执勤执法工作规范》（公通字〔2008〕58号）等。

---

## 第一部分：饮酒驾驶（行政案件）办理流程

### 一、查处前准备

1. **警力配置**：两名以上民警，警务辅助人员不限
2. **装备配备**：除日常警用装备外，应配带呼气酒精测试仪、呼气酒精含量检测仪、约束带、警绳、照相机、摄像机、发光指挥棒、停车示意牌、破胎器等
3. **执勤点设置**：
   - 在距执勤点至少200米处开始摆放发光或反光的警告标志、警示灯
   - 间隔设置减速提示标牌、反光锥筒等安全防护设备
   - 分设提示减速区、检查区、处置区三个功能区
   - 每次集中行动时间不得超过两小时
   - 依据：《交通警察道路执勤执法工作规范》（公通字〔2008〕58号）

### 二、发现嫌疑人

1. 发现有酒后驾驶嫌疑的，指挥机动车驾驶人立即靠路边停车，熄灭发动机，接受检查
2. 要求出示驾驶证、行驶证
3. 对确认没有酒后驾驶行为的，立即放行
4. **初检流程**：
   - 检查区民警使用酒精检测棒对驾驶人实施初检筛查
   - 初检无酒驾的立即放行
   - 初检涉嫌酒驾的，立即要求驾驶人下车，实施人车分控，带至处置区

### 三、呼气式酒精检测

1. **检测规范**：
   - 每测试一人更换一次新的吹嘴，并在被测试人面前开启吹管包装
   - 酒检仪应使用符合卫生条件的一次性吹管，单独封装
   - 酒检仪应采用单向吹管
   - 依据：GB/T 21254-2017《呼出气体酒精含量检测仪》

2. **检测结果处理**：
   - 检测结束后告知检验结果
   - 当事人违反检验要求的，当场重新检验
   - 打印呼气酒精测试单
   - 由两名民警分别签名后交驾驶人签名确认
   - 依据：《车辆驾驶人员血液、呼气酒精含量阈值与检验》GB19522-2024

3. **阈值标准**：
   - 饮酒驾驶：≥20mg/100ml 且 ＜80mg/100ml（行政处罚）
   - 醉酒驾驶：≥80mg/100ml（涉嫌危险驾驶罪，刑事移送）

4. **必须立即提取血样的情形**（程序规定第95条）：
   - 当事人对呼气酒精测试结果有异议的
   - 当事人拒绝配合呼气酒精测试的
   - 涉嫌醉酒驾驶机动车的
   - 涉嫌饮酒后驾驶机动车发生交通事故的

### 四、全程录音录像与拍照

应当通过现场拍照或摄像记录以下内容：
1. 当事人停车接受检查的过程
2. 有当事人面貌特征的驾车情形
3. 所驾机动车号牌、车型、颜色等基本特征
4. 当事人接受呼气酒精检测的过程
5. 当事人抽取血样的过程
6. 有证人的，应当拍摄询问证人的情况
7. 能够反映查处过程的其他内容

依据：《交警系统执勤执法记录仪使用管理规定》（公交管〔2019〕132号）

### 五、开具强制措施凭证扣留驾驶证/车辆

1. 发现当事人涉嫌饮酒后或者醉酒驾驶机动车的，依据《道路交通安全法》第110条先予扣留机动车驾驶证
2. 发生交通事故需扣留车辆的，依据《道路交通安全法》第72条扣留事故车辆
3. 扣留机动车及驾驶证的，依《程序规定》第23条开具强制措施凭证

### 六、血样提取（适用于需血检情形）

1. **抽血地点**：通知医疗机构或具备资格的检验鉴定机构，由不少于两名民警将当事人带到上述机构
2. **消毒要求**：抽血时不应采用醇类药品对皮肤进行消毒
3. **血样要求**：
   - 抽取两份血样，每份不低于3毫升
   - 一份备案，一份送检
   - 添加抗凝剂（或使用抗凝管），防止血液凝固
   - 全程录像监督
4. **封装与标识**：
   - 使用洁净、干燥的容器封装
   - 容器分别使用塑料物证袋封装，封口处加盖封章
   - 血样容器上注明被抽血人姓名、抽血时间
   - 塑料物证袋上注明被抽血人姓名、抽取时间、血样用途
   - 由被抽血人、民警和抽血人员签名
5. **送检保管**：
   - 由2名民警立即送检
   - 因特殊原因不能立即送检的，应在4℃±2℃条件下冷藏保存
   - 经上级公安机关交通管理部门负责人批准，可在3日内送检

### 七、醒酒约束

1. 违法嫌疑人在醉酒状态中，对本人有危险或对他人人身、财产或公共安全有威胁的，可采取保护性措施约束至酒醒
2. 可通知家属、亲友或所属单位领回看管，必要时送医院醒酒
3. 对行为举止失控的醉酒人，可使用约束带或警绳进行约束，但不得使用手铐、脚镣等警械
4. 约束过程中指定专人严加看护
5. 确认酒醒后立即解除约束
6. 约束时间不计算在询问查证时间内
   - 依据：《公安机关办理行政案件程序规定》第58条

### 八、查获经过制作

1. 《查获经过》应由参与执行的民警书写，载明以下内容：
   - 查获犯罪嫌疑人的时间、地点及查获过程
   - 犯罪嫌疑人基本情况及机动车车型、号牌、颜色等基本特征
   - 现场采取行政强制措施、呼气酒精测试、抽血、口头传唤、固定证据等处置情况
   - 其他与案件有关的情况
2. 查获经过以办案民警名义出具，除民警签名外，注明"××为我队民警"并加盖办案单位印章

### 九、传唤与询问

1. 对现场发现涉嫌醉酒驾驶的当事人，经出示工作证件，可口头传唤到指定地点接受调查
2. 及时将传唤原因和处所通知被传唤人家属
3. 及时询问查证，制作《询问笔录》
4. 询问笔录中注明当事人到案经过、到案时间和离开时间

### 十、检验报告与送达

1. 检验鉴定机构应当在3日内出具检验报告
2. 办案部门应在收到检验报告之日起2日内制作《鉴定结论通知书》并送达当事人
3. 当事人对鉴定结论有异议的，应在送达之日起3日内书面提出重新检验鉴定申请
4. 重新鉴定以一次为限
   - 依据：《公安部关于公安机关办理醉酒驾驶机动车犯罪案件的指导意见》（公交管〔2011〕190号）

### 十一、处罚决定与执行

#### （一）饮酒驾驶非营运机动车（首次）
- 处罚：罚款1000-2000元 + 暂扣驾驶证6个月 + 记12分
- 依据：道交法第91条第1款

#### （二）二次饮酒驾驶
- 处罚：罚款1000-2000元 + 拘留≤10日 + 吊销驾驶证 + 记12分
- 依据：道交法第91条第5款

#### （三）饮酒驾驶营运机动车
- 处罚：罚款5000元 + 拘留15日 + 吊销驾驶证5年 + 记12分
- 依据：道交法第91条第3款

#### （四）执行要求
1. 暂扣驾驶证期间不得驾驶机动车
2. 吊销驾驶证的当场交回驾驶证
3. 罚款在15日内到指定银行缴纳
4. 行政违法记录永久留存于交管系统，作为再次酒驾处罚依据

## 第二部分：醉酒驾驶（刑事案件）办理流程

### 一、立案标准

1. 经呼气酒精含量检测，显示血液酒精含量达到80mg/100ml以上的，公安机关应当依照刑事诉讼法和本意见的规定决定是否立案
2. 对情节显著轻微、危害不大，不认为是犯罪的，不予立案
3. 醉酒标准未变化，仍是血液酒精含量达到80mg/100ml
   - 依据：两高两部2023年意见第4条

### 二、醉酒认定依据

#### （一）以血液酒精含量鉴定意见为主要依据
- 公安机关应当及时提取犯罪嫌疑人血样送检
- 提取血样必须"及时"，具备条件时要"立即"提取
- 提取血样是否及时是检察机关重点审查对象
- 依据：两高两部2023年意见第4条第2款

#### （二）以呼气酒精检测结果定案的情形（特例）
- 犯罪嫌疑人经呼气酒精含量检测显示≥80mg/100ml，在提取血样前脱逃或者找人顶替的，可以以呼气检测结果作为认定依据
- 依据：两高两部2023年意见第4条第3款

#### （三）二次饮酒的认定处理
- 犯罪嫌疑人在依法检查时或发生交通事故后，为逃避法律追究，在呼气检测或提取血样前故意饮酒的，以查获后血液酒精含量鉴定结果作为认定依据
- 依据：两高两部2023年意见第4条第4款

#### （三·续）二次饮酒边界红线与鉴定锚点边界

**边界红线（适用第4条第4款的前提与限制）**：
1. 拟制单向性：仅拟制"驾驶时血醇≥查获值"，**不得反向推定事故前已醉酒**；实体要件仍须由证据支撑。
2. 主观要件锁定：须以"逃避法律追究"目的被证据锁定为前提（前科、现场躲避过程等）；仅凭推测不适用。
3. 与无证驾驶无关：本款仅关乎饮酒与血醇认定，与是否无证无关——检察院"再次饮酒与逃避无证驾驶无关"之意见不构成本款适用障碍，但真问题在于无"事故前饮酒"证据。
4. 不得替代查清：二次饮酒推定不能替代对"事故前是否饮酒"的查证；两条路径须并行印证。

**鉴定饮酒时间（回溯性血醇推算）与锚点边界**：
- 原理：以抽血 BAC 为基准，按酒精代谢动力学逆推驾驶时血醇（Widmark 公式 / BAC 逆向外推，β≈15-20 mg/100ml/h）；由具备资质机构出具，载明前提与不确定性。
- 锚点边界：推算以"饮酒结束时间"为锚点。若确系**事故后饮酒**，反推结果指向"饮酒后至抽血前"区间，**不能直接作为驾驶时（事故前）血醇确定值**；须与时间轴证据交叉印证，且不能替代查清事故前饮酒。
- 衔接：详见 `evidence-reasoning-guide.md` 第十三节；与补侦意见书序号1（回溯推算）、序号2（事故前饮酒）、序号3（时间轴）共同闭环"驾驶时是否醉酒"。

### 三、"道路"与"机动车"认定

1. 适用道路交通安全法有关"道路""机动车"的规定
2. 单位管辖范围内路段是否认定为"道路"，以是否具有"公共性"、是否"允许社会机动车通行"为判断标准
3. 只允许单位内部机动车、特定来访机动车通行的，可以不认定为"道路"
   - 依据：两高两部2023年意见第5条

### 四、刑事强制措施

1. **拘留或取保候审**：根据案件具体情况依法决定
2. **一般予以取保候审的情形**：
   - 因本人受伤需要救治的
   - 患有严重疾病，不适宜羁押的
   - 系怀孕或正在哺乳自己婴儿的妇女
   - 系生活不能自理的人的唯一扶养人
   - 其他需要取保候审的情形
3. **监视居住**：符合取保候审条件但无法提供保证人也不交纳保证金的
4. **逮捕**：违反取保候审、监视居住规定，情节严重的
   - 依据：两高两部2023年意见第6条

### 五、证据收集要求

#### （一）应当收集的证据（必备）
1. 证明犯罪嫌疑人情况的证据材料（身份信息、驾驶证记录、前科记录等）
2. 证明醉酒检测鉴定情况的证据材料（呼气检测结果、标定证书、血样提取笔录、鉴定委托书、鉴定意见、鉴定意见通知书等）
3. 证明机动车情况的证据材料（行驶证、信息查询记录、照片等）
4. 证明现场执法情况的照片（检查机动车、呼气检测、血样提取封装等环节的照片，并保存录音录像）
5. 犯罪嫌疑人供述和辩解

#### （二）特殊情形还需收集的证据
1. 是否饮酒、驾驶机动车有争议的：收集同车人员、目击证人、共同饮酒人员证言、监控记录等
2. 道路属性有争议的：收集管理人员、业主等证言、管理单位或有关部门证明等
3. 发生交通事故的：收集事故认定书、监控记录、伤情鉴定意见、被害人陈述等
4. 可能构成自首的：收集到案经过等材料

- 依据：两高两部2023年意见第7条

### 六、讯问要点

第一次讯问应问明：
1. 犯罪嫌疑人取得机动车驾驶证情况
2. 犯罪嫌疑人驾驶机动车基本情况
3. 被查获的时间、地点及过程
4. 醉酒驾驶机动车的事实、动机、目的等情况
5. 饮酒的时间、地点、酒的种类和数量以及有无见证人等情况
6. 其他与犯罪事实有关的情况

### 七、快速办理机制

#### （一）适用条件（须全部满足）
1. 现场查获，未造成交通事故的
2. 事实清楚，证据确实、充分，法律适用没有争议的
3. 犯罪嫌疑人、被告人自愿认罪认罚的
4. 不具有刑事诉讼法第223条规定情形的

#### （二）办案期限
- 一般应在立案侦查之日起30日内完成侦查、起诉、审判工作

#### （三）简化措施
1. 取保候审措施可跨阶段连续适用（无需重新作出）
2. 缓刑社会调查评估一般可不进行
3. 可采用合并式、要素式、表格式等简化文书
4. 可通过一体化网上办案平台流转

- 依据：两高两部2023年意见第21-26条

### 八、刑事追究要点

#### （一）从重处理情形（第10条）
醉驾具有下列情形之一，尚不构成其他犯罪的，从重处理：
1. 造成交通事故且负事故全部或者主要责任的
2. 造成交通事故后逃逸的
3. 未取得机动车驾驶证驾驶汽车的
4. 在高速公路、城市快速路上驾驶的
5. 驾驶载有乘客的营运机动车的
6. 严重超员、超载或者超速驾驶的
7. 驾驶机动车从事校车业务且载有师生的
8. 在服药后驾驶的（服用管制精神药品或麻醉药品）
9. 曾因饮酒后驾驶机动车被处罚的（含二次酒驾、前科）
10. 曾因危险驾驶行为被判决有罪或作相对不起诉的
11. 其他情节恶劣的情形

#### （二）从宽处理情形（第11条）
1. 自首、坦白、立功的
2. 自愿认罪认罚的
3. 造成交通事故，赔偿损失或取得谅解的
4. 其他需要从宽处理的情形

#### （三）情节显著轻微不认为是犯罪的情形（第12条）
醉驾具有下列情形之一，且不具有第10条规定情形的：
1. 血液酒精含量不满150mg/100ml的
2. 出于急救伤病人员等紧急情况驾驶机动车，且不构成紧急避险的
3. 在居民小区、停车场等场所因挪车、停车入位等短距离驾驶机动车的
4. 由他人驾驶至居民小区、停车场等场所短距离接替驾驶停放机动车的，或为了交由他人驾驶，自居民小区、停车场等场所短距离驶出的
5. 其他情节显著轻微的情形

#### （四）一般不适用缓刑的情形（第14条）
1. 造成他人轻伤或轻微伤，且负事故全部或主要责任的
2. 造成事故且负事故全部或主要责任，未赔偿的
3. 事故后逃逸的
4. 血液酒精含量超过180mg/100ml的
5. 未取得机动车驾驶证驾驶汽车的
6. 服用管制精神药品或麻醉药品后驾驶的
7. 采取暴力手段抗拒公安机关依法检查，或实施妨害司法行为的
8. 五年内曾因饮酒后驾驶机动车被查获或受过行政处罚的
9. 曾因危险驾驶行为被判决有罪或作相对不起诉的
10. 其他情节恶劣的情形

#### （五）罚金标准（第15条）
- 起刑点一般不应低于道路交通安全法规定的饮酒后驾驶机动车相应情形的罚款数额
- 每增加一个月拘役，增加1000元至5000元罚金

#### （六）自首认定（第17条）
- 现场查获后经允许离开，再经通知到案或主动到案的，不认定为自动投案
- 造成事故后保护现场、抢救伤者，向公安机关报告并配合调查的，认定为自动投案

#### （七）🆕 从重从轻情节竞合分析模型

当醉驾案件同时存在多个从重情形和/或从宽情形时，应按以下模型进行综合裁量分析：

**第一步：情节分类统计**

| 类型 | 来源（2023意见） | 条款 |
|:----|:---------------|:----|
| 🔴 从重情形（从重处理） | 第10条 | 共11项（含兜底） |
| 🟢 从宽情形（从宽处理） | 第11条 | 共4项（含兜底） |
| 🔵 情节显著轻微（不作为犯罪处理） | 第12条 | 共5类（须同时不具从重情形） |
| ⚫ 一般不适用缓刑 | 第14条 | 共10项（含兜底） |

**第二步：情节竞合分级处理**

| 竞合类型 | 情形描述 | 处理规则 |
|:--------|:---------|:---------|
| 🅰 仅从重、无从宽 | 仅具有第10条情形，无第11条情形 | 依法从重，一般不适用缓刑（如有第14条情形→明确排除缓刑） |
| 🅱 仅从宽、无从重 | 仅具有第11条情形，无第10条情形 | 依法从宽；如同时符合第12条→可作情节显著轻微处理 |
| 🅲 **从重+从宽并存** | 同时具有第10条和第11条情形 | ⚠️ **最常见也最复杂的类型**，按以下规则处理 |
| 🅳 情节显著轻微门槛 | 血检<150mg+无第10条情形+特殊场景（挪车/急救等） | 按第12条不作为犯罪处理（不受从重/从宽影响） |

**第三步：从重+从宽并存（🅲型）的综合裁量规则**

1. **优先判断是否触发"一般不适用缓刑"情形（第14条）**
   - 如触发→一般不适用缓刑，即使有从宽情节，缓刑也应谨慎适用
   - 从宽情节仅影响拘役刑期和罚金数额的裁量

2. **从重情节的叠加效应**
   - 多个从重情形并存的，量刑时逐项叠加考虑
   - 血检值+事故+特殊路段+前科+其他 → 每多一项，刑期和罚金应阶梯式上升

3. **从宽情节的抵减效应**
   - 自首：可减少基准刑的30%以下
   - 赔偿谅解：可减少基准刑的20%以下
   - 认罪认罚：可减少基准刑的10%以下
   - 多种从宽情形并存的，总减少幅度一般不超过基准刑的50%

4. **综合裁量参考矩阵**

   ```
   从重情形数量 →  0项        1-2项       3项+
   从宽情形     ↓
   无从宽       →  标准刑     从重刑      顶格刑
   1项从宽     →  从轻刑     标准刑      从重刑
   2项+从宽    →  显著从轻   从轻刑      标准刑
   （情节显著轻微→不作为犯罪处理，不在此表）
   ```

**第四步：法制审核中的审查要点**

- 逐项核验：是否遗漏从重/从宽情形？（常见遗漏：前科记录、吸毒史、特殊路段认定）
- 竞合判定：是否正确识别从重+从宽并存的综合裁量路径？
- 缓刑审查：是否正确判断"一般不适用缓刑"情形是否触发？
- 罚金审查：起刑点是否≥酒驾对应的罚款数额？
- 文书留痕：审核意见书应载明各项情节的认定依据和综合裁量理由，确保结论可复核

**第五步：典型案例分析**

> **示例1**（从重+从宽并存）：血检160mg+高速驾驶+事故全责+自首+赔偿谅解
> - 从重：高速（第10条⑨）、事故全责（第10条①）→2项
> - 从宽：自首（第11条①）、赔偿谅解（第11条④）→2项
> - 缓刑：事故全责→一般不适用缓刑（第14条①）
> - 综合：从重2项+从宽2项→标准刑至从重刑区间；因缓刑排除，建议1-3个月拘役+罚金

> **示例2**（仅从重）：血检160mg+高速驾驶+无证驾驶+无事故
> - 从重：高速（第10条⑨）、无证驾驶（第10条③）→2项
> - 从宽：无
> - 缓刑：无证驾驶→一般不适用缓刑（第14条⑤）
> - 综合：从重2项+无从宽→从重刑区间；建议2-3个月拘役+罚金

> **示例3**（仅从宽）：血检85mg+在小区停车场挪车+无前科+无事故
> - 审查是否属于第12条第③项（小区挪车）：血检85mg<150mg+无第10条情形+小区挪车→**情节显著轻微，不作为犯罪处理**
> - 行政处罚衔接：吊销驾驶证+罚款+拘留（按酒驾行政处罚）

### 九、行政处罚衔接（刑事程序中的行政处罚）

1. 血液酒精含量达到80mg/100ml以上，公安机关应当在决定不予立案、撤销案件或移送审查起诉前，给予行为人**吊销机动车驾驶证**行政处罚
2. 对于适用"但书"不立案的案件，公安机关还应当按照酒驾相应情形给予罚款、行政拘留的行政处罚
3. 人民法院、人民检察院作不起诉、免予刑事处罚等处理的，应提出检察意见或司法建议，移送公安机关处理
   - 依据：两高两部2023年意见第20条

### 十、🆕 辅助驾驶/自动驾驶场景下的醉驾认定

#### （一）背景与意义

随着智能网联车辆快速普及，辅助驾驶（L2级）和有条件自动驾驶（L3级）车辆逐年增多，实践中已出现驾驶人利用辅助驾驶功能从事醉酒驾驶的新型案件。2026年2月13日，最高人民法院发布**指导性案例271号（王某群危险驾驶案）**，首次就对辅助驾驶场景下的醉驾认定作出裁判规则指引，对基层执法和法制审核具有重要指导意义。

#### （二）驾驶自动化等级概述（GB/T 40429-2021）

| 等级 | 名称 | 说明 | 驾驶主体 |
|:---:|:-----|:-----|:--------|
| L0 | 应急辅助 | 系统仅提供预警/瞬时辅助 | 驾驶人 |
| L1 | 部分驾驶辅助 | 系统辅助横向或纵向运动控制 | 驾驶人 |
| L2 | 组合驾驶辅助 | 系统同时控制横向和纵向运动，驾驶人须监管 | **驾驶人** |
| L3 | 有条件自动驾驶 | 系统执行全部动态驾驶任务，驾驶员须随时接管 | 系统（驾驶员备份） |
| L4 | 高度自动驾驶 | 系统执行全部动态驾驶任务，特定条件下无需接管 | 系统 |
| L5 | 完全自动驾驶 | 系统在任何条件下执行全部动态驾驶任务 | 系统 |

**关键分界线**：L2及以下（辅助驾驶）→ **驾驶人仍是驾驶主体**；L3及以上（自动驾驶）→ 驾驶主体转移至系统。

当前市面主流量产车辆的辅助驾驶功能（如特斯拉Autopilot、蔚来NOP、小鹏NGP、理想AD等）均属于**L2级组合驾驶辅助**，驾驶人仍是法定驾驶主体和责任主体。

#### （三）最高法指导性案例271号裁判规则

**案件索引**：王某群危险驾驶案（最高人民法院审判委员会讨论通过，2026年2月13日发布）

**关键词**：刑事/危险驾驶罪/醉酒驾驶/辅助驾驶/自动驾驶

**裁判要点**：
> 车载辅助驾驶系统不能代替驾驶人成为驾驶主体，驾驶人激活辅助驾驶功能后，仍是实际执行驾驶任务的人，负有确保行车安全的责任。行为人激活辅助驾驶功能，并利用私自安装的配件逃避辅助驾驶系统监测的，即使其不在主驾驶位实际操控机动车，仍应作为驾驶主体承担相应法律责任。

**基本案情**：
1. 王某群饮酒后驾车回家，后又驾车离开小区
2. 激活L2级辅助驾驶功能，设置目的地
3. 使用私自安装的"智驾神器"配件逃避辅助驾驶系统的手离方向盘监测
4. 从主驾驶位移至副驾驶位睡觉（双手脱把）
5. 行驶至目的地后因车辆挡道被群众发现报警
6. 血检114.5mg/100ml，且2024年7月曾因饮酒驾驶被处罚

**裁判结果**：以危险驾驶罪判处拘役一个月十五日，并处罚金人民币四千元

**裁判理由**：
1. **驾驶行为认定**：王某群的行为分两个阶段——第一阶段以传统人工方式驾驶，第二阶段激活辅助驾驶后由系统执行驾驶任务。因所驾车辆安装的系L2级辅助驾驶系统（不能脱离驾驶人监管），王某群仍然是负责执行驾驶任务的驾驶人，其使用非法配件逃避监测、移至副驾驶位睡觉的行为属于违规驾驶，不能否认其驾驶人身份
2. **罪名成立**：血检114.5mg/100ml≥80mg，属醉酒；虽血检<150mg/100ml（按2023意见第12条属于情节显著轻微的门槛之一），但王某群二年内曾因饮酒驾驶受过行政处罚（2023意见第10条第(十三)项），故不认定为情节显著轻微，应以危险驾驶罪定罪

#### （四）辅助驾驶场景醉驾的认定框架

**第一步：确认驾驶自动化等级**
- 核查车辆行驶证/用户手册，确定该车辅助驾驶系统的等级（L0-L5）
- 市面主流量产车：均为L2级（组合驾驶辅助），驾驶人仍是法定驾驶主体

**第二步：审查"驾驶"行为**
- 即使驾驶人未在主驾驶位操控方向盘，只要车辆处于其启动、激活辅助驾驶并设置目的地的状态下行驶，仍应认定为"驾驶机动车"
- L2级辅助驾驶不能取代驾驶人成为驾驶主体
- 驾驶人是否在手握方向盘、是否在观察路况，不影响其驾驶主体身份的认定

**第三步：审查"智驾神器"等非法改装**
- 私自安装逃避辅助驾驶系统监测的配件（如模拟手握方向盘的配重块、传感器欺骗装置等），属于**非法改装**行为
- 违反道交法第16条（擅自改变机动车已登记的结构、构造或特征）
- 可依据《机动车登记规定》第78条予以罚款+责令恢复原状
- 该行为同时可作为**主观恶性大**的量刑考量因素

**第四步：综合运用2023意见进行审查**
- 血检≥80mg/100ml：应当立案
- 血检<150mg/100ml：审查是否属于情节显著轻微（须同时满足不具备第10条从重情形）
- 二年内饮酒前科：构成从重情形（第10条第(十三)项）
- 辅助驾驶+非法改装：属于"其他情节恶劣的情形"（第10条第(十四)项，兜底条款）

#### （五）法制审核专项检查清单

| 审查项 | 标准 | 常见问题 |
|:------|:----|:---------|
| 驾驶自动化等级 | 确认车辆L0-L5等级（以行驶证/用户手册为准） | 误将L2当作"自动驾驶" |
| 驾驶主体认定 | L2及以下驾驶人仍是法定驾驶主体 | 以"不是我在开车"为由否认驾驶 |
| "智驾神器"等非法改装 | 是否私自安装逃避监测的配件 | 漏查非法改装行为 |
| 辅助驾驶系统状态 | 是否激活辅助驾驶功能、设置目的地 | 忽略系统激活状态的证据固定 |
| 驾驶人位置 | 主驾驶位/副驾驶位/后排 | 坐副驾驶不等于不是驾驶人 |
| 二年内饮酒前科 | 系统核查前科记录 | 漏查前科导致从重情节遗漏 |
| 并罚审查 | 是否同时涉及非法改装独立违法 | 漏查非法改装的行政处罚 |

#### （六）典型案例参考

**案例1**：驾驶人激活L2辅助驾驶后饮酒，车辆在辅助驾驶模式下行驶被查获 → 仍构成危险驾驶罪（驾驶主体仍是驾驶人）

**案例2**：驾驶人使用"智驾神器"逃避脱手监测，坐在副驾驶位睡觉 → 构成危险驾驶罪（指导案例271号规则）

**案例3**：L3级有条件自动驾驶车辆，驾驶人激活系统后饮酒，系统完全接管驾驶，驾驶人未干预 → 理论争议较大，按当前法律框架仍在驾驶主体认定上存有争议空间，但实务中建议从严认定

**案例4**：驾驶人在主驾驶位激活辅助驾驶功能，但全程手握方向盘、注视路况，仅车辆自行操控方向盘和踏板 → 驾驶人仍是驾驶主体，辅助驾驶不影响醉驾认定

## 第四部分：法理释义与审核要点

### 一、"隔夜酒"认定规则

- 判定标准：血液中酒精含量，而非饮酒距驾驶的时间间隔
- 次日晨间驾车，若血液酒精仍≥20mg/100ml（饮酒）或≥80mg/100ml（醉酒），仍构成违法/犯罪
- 审核关注：血检提取时间与查获时间的间隔，间隔过久可能受代谢影响，需结合查获时呼气值综合判断

### 二、呼气检测与血检的关系（证据规则）

- **原则**：以血液酒精含量鉴定意见为主要认定依据
- **呼气检测功能**：现场初筛 + 行政案件定性 + 行政强制措施（扣留驾驶证）的初步证据
- **呼气结果不作为刑事定罪依据**（但脱逃/顶替特例除外）
- **冲突处理**：当事人对呼气结果有异议或与血检差异较大时，以血检结论为准

### 二-乙、🆕 呼气-血检差异分析指南

#### （一）呼气检测与血检的生理学基础

酒精在人体内的代谢遵循以下规律：吸入肺泡中的酒精浓度与血液酒精浓度之间存在一个相对稳定的比例关系（血-气分配比），约为1:2100。呼气酒精检测仪正是基于这一原理，通过测量呼出气体中的酒精浓度来推算血液酒精含量。

**注意**：这一换算关系是基于群体统计数据的近似值，个体差异、环境温度、检测条件等因素均可能导致偏差。

#### （二）正常差异范围参考

| 差异方向 | 差异程度 | 判断 | 可能原因 |
|:--------|:--------|:----|:---------|
| 呼气≈血检 | 差异<5mg | ✅ 正常 | 检测条件良好，两者一致 |
| 呼气略低于血检 | 血检比呼气高5-15mg | ✅ 常见正常 | 从呼气到抽血的时间差内酒精仍在吸收期 |
| 呼气略高于血检 | 呼气比血检高5-20mg | ⚠️ 偶见 | 口腔残留酒精、仪器误差、检测时间差 |
| **呼气明显高于血检** | **呼气比血检高>20mg** | **🔴 需审查** | 见下（三） |
| **血检明显高于呼气** | **血检比呼气高>20mg** | **🟡 需关注** | 吸收期影响、呼气检测过早 |

#### （三）呼气值明显高于血检值的可能原因清单

当呼气检测结果明显高于血检结果（差异>20mg/100ml）时，应按以下清单逐项排查：

| 序号 | 可能原因 | 核查方法 | 对证据效力的影响 |
|:---:|:---------|:---------|:---------------|
| 1 | 口腔内残留酒精（刚饮酒不久即检测） | 核查查获时间与末次饮酒时间的间隔（<15分钟可能性大） | 呼气偏高，应以血检为准 |
| 2 | 呼气检测仪未按期标定/校准 | 核查仪器检定证书（应在有效期内） | 如已过期→呼气结果不可靠 |
| 3 | 呼气检测环境温度异常 | 核查检测记录中的环境温度描述 | 极端温度可能导致偏差 |
| 4 | 当事人使用含酒精的漱口水/口腔喷雾 | 询问当事人、核查随身物品 | 呼气偏高，应以血检为准 |
| 5 | 当事人存在胃食管反流/嗳气 | 询问病史（少见） | 呼气偏高，应以血检为准 |
| 6 | 血样提取晚于呼气检测时间过长（酒精代谢下降） | 核查呼气时间与采血时间差 | 如间隔>30分钟，代谢导致血检偏低 |
| 7 | 血样保存/送检不当导致酒精挥发或降解 | 核查保存温度、送检时限 | 如超期/保存不当→鉴定意见效力存疑 |

#### （四）差异程度分级处理规则

| 差异程度 | 等级 | 处理规则 |
|:--------|:----|:---------|
| 呼气与血检差异≤10mg | 🟢 正常 | 以血检为准，无需特别说明 |
| 呼气比血检高10-20mg | 🟡 轻度异常 | 以血检为准，在审核意见中注明差异情况 |
| 呼气比血检高20-30mg | 🟠 中度异常 | 以血检为准，建议核查呼气检测仪标定证书和检测环境条件 |
| 呼气比血检高>30mg | 🔴 **重大异常** | **必须核查**呼气仪标定证书、检测环境、口腔残留可能；如血检程序合规，仍以血检为准；如血检程序也存在瑕疵，应作有利于当事人的认定 |
| 血检比呼气高>20mg | 🟡 需关注 | 优先考虑吸收期因素（从呼气到采血的时间差内酒精继续吸收）；审查采血时间是否处于吸收高峰 |

#### （五）呼气检测仪标定证书审查要点

| 审查项 | 标准 | 法律依据 |
|:------|:----|:---------|
| 标定有效期 | 应在有效期内（通常为6个月或1年） | 计量法 |
| 标定机构 | 具有法定资质的计量检定机构 | GB/T 21254-2017 |
| 标定结果 | 误差应在允许范围内 | 该型号仪器的技术标准 |
| 日常自检 | 检测前是否用标准气体自检 | 使用说明书 |

#### （六）审核示例

> **示例1**：呼气95mg/100ml（醉酒），血检65mg/100ml（饮酒），差异30mg，当事人对呼气结果不认可
> - 差异等级：🔴 重大异常（呼气>血检30mg）
> - 处理：以血检65mg为准，定性为饮酒驾驶
> - 需核查：呼气检测仪标定证书、检测时有无口腔残留、采血时间与呼气时间差
> - 审核意见：补正——建议办案单位补充呼气仪标定证书，注明差异原因

> **示例2**：呼气88mg/100ml（醉酒），血检82mg/100ml（醉酒），差异6mg
> - 差异等级：🟢 正常（差异<10mg）
> - 处理：以血检82mg为准，定性为醉酒驾驶
> - 无需特别说明，正常进入醉驾刑事程序

> **示例3**：呼气50mg/100ml（饮酒），血检75mg/100ml（饮酒），差异25mg（血检>呼气）
> - 差异等级：🟡 需关注（血检>呼气25mg）
> - 处理：以血检75mg为准，定性为饮酒驾驶
> - 审查：采血时间是否在酒精吸收高峰期（饮酒后30-90分钟血检可能持续升高）

### 三、血液检材效力审查要点

1. 提取是否及时（查获后立即/尽快提取）
2. 消毒是否规范（非醇类消毒液）
3. 是否使用抗凝管
4. 封装是否规范（密封、标识、签名）
5. 送检是否及时（3日内）
6. 保存温度是否合规（4℃±2℃）
7. 全程是否有录像
8. 鉴定机构是否具有资质
9. 排除情形（第9条）：
   - 血液样本未依法提取、封装、保管、送检的
   - 血液样本污染或变质无法作出准确鉴定的
   - 鉴定机构或人员不具备法定资质的
   - 鉴定程序违法的
   - 其他应当排除的情形

### 三-乙、🆕 血样程序瑕疵分级处理指引

血样提取、封装、保管、送检、鉴定过程中可能出现的程序瑕疵，按其对证据效力的影响程度分为四级处理：

#### （一）P0级——证据绝对排除（不可补正）

瑕疵导致血检鉴定意见**不得作为定案依据**，且无法通过补正或合理解释恢复证据效力。

| 序号 | 瑕疵情形 | 法律依据 |
|:---:|:---------|:---------|
| 1 | 血样污染或变质，无法作出准确鉴定 | 2023意见第9条第2项 |
| 2 | 鉴定机构不具备法定资质 | 2023意见第9条第3项 |
| 3 | 鉴定人不具备法定资质 | 2023意见第9条第3项 |
| 4 | 鉴定程序严重违法（如血样被调包、使用非抗凝管导致凝血） | 2023意见第9条第4项 |
| 5 | 无法证明血样与当事人的同一性（无标识/标识错误） | 2023意见第9条第1项 |
| 6 | 无正当理由血样已灭失或无法复检 | 一般证据规则 |

**处理规则**：血检鉴定意见不得作为定案依据。刑事路径下，如无其他证据可独立证明醉酒（仅有呼气值且不符合脱逃/顶替特例），应撤销案件或作不起诉处理。

#### （二）P1级——可补正（需补正或合理解释后可作为证据）

瑕疵不影响证据的根本真实性，但需补正或作出合理解释后，鉴定意见方可作为定案依据。

| 序号 | 瑕疵情形 | 补正/解释方法 |
|:---:|:---------|:-------------|
| 1 | 血样提取笔录缺少被抽血人签名（被抽血人拒绝签名的已注明除外） | 说明拒签原因+执法记录佐证 |
| 2 | 送检人员仅1名民警（未达到2名） | 说明原因+其他证据补强 |
| 3 | 封装标签信息不完整（如缺抽血时间） | 依据执法记录补充确认 |
| 4 | 血样送检超期（超过3日但未超过7日） | 说明原因（如交通不便）并提供冷藏证明 |
| 5 | 血样保存温度记录缺失 | 提供保存场所温度记录或情况说明 |

**处理规则**：在审核意见中标注瑕疵，要求办案单位提供补正材料或情况说明。补正完成后鉴定意见可作为定案依据。

#### （三）P2级——不影响认定（瑕疵存在但不影响证据效力）

瑕疵不影响鉴定意见的科学性和真实性，无需补正，在审核意见中注明即可。

| 序号 | 瑕疵情形 | 说明 |
|:---:|:---------|:-----|
| 1 | 血样提取笔录未注明见证人（有全程录像的） | 录像可替代见证人 |
| 2 | 封装袋封口处封章不清晰（内容物完整无损的） | 不影响血样完整性 |
| 3 | 送检登记表填写不规范（关键信息已填） | 形式瑕疵，不影响实质 |
| 4 | 血样提取笔录与执法记录时间存在微小差异（<5分钟） | 可合理解释 |
| 5 | 血样提取时使用醇类消毒液，但血检结果与呼气值一致性好，可排除污染影响 | 污染可能性低，可综合认定 |

**处理规则**：在审核意见中备注程序瑕疵，但不影响鉴定意见的证据效力。

#### （四）P3级——综合认定（结合其他证据综合判断）

当血检因程序瑕疵证据效力下降，但其他证据足以独立证明违法事实时，可进行综合认定。

**补强路径**：
1. 呼气检测值+当事人无签名确认+执法记录完整 → 呼气值可作为行政案件认定依据
2. 呼气值+当事人陈述+证人证言+执法记录 → 可综合认定饮酒/醉酒事实
3. 脱逃/顶替情形 → 按2023意见第4条第3款以呼气结果定案

**综合认定示例**：
> 血检因醇类消毒+超期送检（P1级），但呼气检测值88mg/100ml+当事人现场承认饮酒+执法记录完整+当事人对呼气结果无异议 → 综合认定醉酒驾驶（呼气+当事人陈述+执法记录形成证据链）

#### （五）分级处理速查表

| 级别 | 证据效力 | 处理方式 | 对案件定性的影响 |
|:----|:--------|:---------|:---------------|
| P0 | ❌ 排除 | 不得作为定案依据 | 🔴 可能导致撤案/不起诉 |
| P1 | ⚠️ 待补正 | 要求补正或合理解释 | 🟡 暂不影响定性，需跟进 |
| P2 | ✅ 有效（注明瑕疵） | 备注即可 | 🟢 不影响定性 |
| P3 | 🟢 综合认定 | 结合其他证据综合判断 | 🟢 可维持定性 |

| 情形 | 性质 | 处理路径 |
|:----|:----|:--------|
| 饮酒驾驶（首次） | 行政违法 | 罚款+暂扣驾驶证+记分 |
| 二次饮酒驾驶 | 行政违法 | 罚款+拘留+吊销驾驶证+记分 |
| 饮酒驾驶营运车辆 | 行政违法 | 罚款+拘留+吊销驾驶证5年 |
| 醉酒驾驶（≥80mg，一般情形） | 刑事犯罪 | 吊销驾驶证+刑责（拘役+罚金） |
| 醉酒驾驶营运车辆 | 刑事犯罪 | 吊销驾驶证10年+刑责+禁驾营运 |
| 饮酒/醉驾发生重大事故构成犯罪 | 刑事犯罪 | 吊销驾驶证+终生禁驾+刑责 |

### 五、核心程序合法性审查要点（法制审核适用）

| 审查项 | 标准 | 常见问题 |
|:------|:----|:---------|

| 吊销驾驶证 | 不立案/撤案/移送前必须作出 | 遗漏或延迟 |
| 快速办理适用 | 四条件同时满足 | 不符合条件仍适用 |

## 第六部分：常见阻碍执法情形的处置

### 一、拒不配合酒精检测
1. **告知**：告知拒不配合呼气检测的，将进行抽血检验
2. **警告**：警告拒不配合抽血检验的，将采取强制措施
3. **约束**：警告无效的，使用约束带、警绳等约束性警械（不得使用手铐）
4. **制服**：遇反抗或攻击的，按实战处置要点处置

### 二、强行闯卡逃逸
1. **预判**：对驾驶人神情或车行轨迹异常的提高防范意识
2. **破胎**：出现闯卡苗头时迅速铺设破胎器
3. **查缉**：向指挥中心报告详情，不应试图追缉车辆
4. **调查**：弃车逃逸的应积极查找并通知家属
5. 闯卡行为依据《治安管理处罚法》第50条从重处罚；构成犯罪的追究刑事责任
