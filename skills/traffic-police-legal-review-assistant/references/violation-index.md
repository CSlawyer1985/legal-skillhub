# 交通违法类型全口径分类框架索引

> **定位**：本索引为"交管智辅·法制审核助手"的违法类型分类地图，覆盖交通管理行政违法的**全口径大类**，用于审核时快速定位"案件属于哪一类、对应核心法条与裁量要点在哪"。
> **与 penalty_reference.md 的关系**：本文件提供"分类框架 + 代表性违法 + 法条指向"；具体罚款金额、记分分值、拘留等裁量明细见 `penalty_reference.md`（高频违法裁量表）。
> **与 legal_basis.md 的关系**：法条原文、款/项精度、法理释义见 `legal_basis.md`。
> **数据基准**：本索引依据《道路交通安全法》《道路交通安全法实施条例》《道路交通安全违法行为记分管理办法》（公安部令第163号，2022.4.1施行）、《道路交通安全违法行为处理程序规定》（公安部令第157号，含2025年修改决定）。
> **说明**：全口径违法类型逾数百种（含地方细化标准），本索引按执法实务聚类为以下大类，每类列举代表性违法。未穷尽的个别情形，按"行为性质归入最接近类别 + 检索权威执法指引库"处理。

## A. 酒驾醉驾与毒驾类

**核心法条**：道交法第91条（各款）、第22条第2款（服用管制药品/饮酒不得驾驶）；《关于办理醉酒危险驾驶刑事案件的意见》（高检发办字〔2023〕187号）

**代表性违法**：
- A1 饮酒后驾驶（非营运，血检≥20且＜80mg/100ml）→ 罚款1000-2000元+暂扣证6个月+记12分
- A2 二次饮酒驾驶 → 罚款1000-2000元+拘留≤10日+吊销证+记12分
- A3 醉酒驾驶（血检≥80mg/100ml）→ 吊销证（5年）+刑责+记12分（刑事移送）
- A4 饮酒驾驶营运车辆 → 罚款5000元+拘留15日+吊销证（5年）+记12分
- A5 醉酒驾驶营运车辆 → 吊销证（10年）+刑责+不得驾驶营运车辆
- A6 服用国家管制精神药品/麻醉药品后驾驶 → 按毒驾处置，可拘留
- A7 饮酒后/醉酒驾驶发生重大事故构成犯罪 → 吊销证+终生禁驾+刑责

**🆕 升级审核要点**：

**（一）证据审核**
1. 呼气检测→血检的程序衔接是否合规（程序规定第95条四种必须血检情形）
2. 血样提取是否规范（非醇消毒、抗凝管、双份≥3ml、全程录像）
3. 血样送检是否及时（3日内、2名民警、4℃±2℃保存）
4. 鉴定意见是否合法（机构资质、鉴定人资质、排除情形——2023意见第9条）
5. 执法记录仪全程录像是否完整（公交管〔2019〕132号）
6. 2023意见第7条规定的五类必备证据是否齐全

**（二）实体认定**
1. 以血检为主要认定依据；呼气仅初筛
2. 隔夜酒：按血中含量认定，不以饮酒时间判断
3. 脱逃/顶替情形：可以呼气检测结果定案（2023意见第4条第3款）
4. 二次饮酒：为逃避追究在检查/事故后故意饮酒的，以实测结果为准（2023意见第4条第4款）
5. "二次"以处罚记录认定（系统可查的饮酒驾驶处罚记录）

**（三）法律性质区分**
- 饮酒驾驶→行政违法→罚款+暂扣/吊销驾驶证（+拘留）
- 醉酒驾驶→刑事犯罪→吊销驾驶证+刑事移送（拘役+罚金）
- 醉驾一律刑事移送，行政案件终止
- 醉驾情节显著轻微可不立案（2023意见第12条：血检＜150mg、挪车、急救等5类）
- 行政处罚与刑事处罚的衔接：吊销驾驶证前置（2023意见第20条）

**（四）2023意见核心变化**
- 立案门槛调整：不是一律立案，情节显著轻微可不立案
- 缓刑排除细化：10项一般不适用缓刑情形（血检＞180mg、无证驾驶、暴力抗法等）
- 从重情形11项（对照2023意见第10条审查）
- 从宽情形4项（自首/坦白/认罪认罚/赔偿谅解等）
- 快速办理机制：30日办结（2023意见第22-23条）
- 详细流程指引见 `references/drinks-driving-procedure-guide.md`

## B. 超速行驶类

**核心法条**：道交法第42条、第90条、第99条第1款第4项；记分办法第8-12条

**代表性违法**（按车型与路段组合，记分见 penalty_reference）：
- B1 普通机动车在高速/城市快速路超速50%以上 → 记12分
- B2 校车/中型以上客货/危化品车在高速/城市快速路超速20%以上 → 记12分
- B3 校车等以外机动车在高速/城市快速路超速20%-50% → 记6分
- B4 校车等在高速/城市快速路以外道路超速50%以上 → 记9分
- B5 普通机动车在普通道路超速20%-50% → 记3分
- B6 普通机动车在普通道路超速10%-20% → 记1分
- B7 超速50%以上（非高速特定情形）→ 罚款500-2000元+可吊销证（道交法第99条）

**审核要点**：区分车型（校车/中型以上客货/危化品车 vs 其他）、路段（高速/城市快速路 vs 普通道路）、超速比例三档；超速合并记分与罚款。

## C. 超员载客类

**核心法条**：道交法第49条、第92条第1款；记分办法第8-11条

**代表性违法**：
- C1 公路客运/旅游客运/校车超员20%以上，或其他载客汽车超员100%以上 → 记12分
- C2 7座以上载客汽车超员50%-100% → 记9分
- C3 公路客运等超员未达20%，或7座以上超员20%-50%，或其他载客汽车超员50%-100% → 记6分
- C4 其他载客汽车超员20%-50% → 记3分
- 罚款：按超员幅度200-2000元（道交法第92条各档）

**审核要点**：按"核定人数百分比"计算；区分车辆类型（校车/公路客运/旅游客运/7座以上/其他）；注意与"客运企业一案双罚"。

---

## D. 超载货运类

**核心法条**：道交法第48条、第92条第2款；记分办法第10-12条

**代表性违法**：
- D1 载货汽车载物超最大允许总质量50%以上 → 记6分
- D2 载货汽车载物超总质量30%-50% → 记3分
- D3 载货汽车载物超总质量未达30% → 记1分
- 罚款：按超载幅度200-2000元（道交法第92条各档）

**审核要点**：以"最大允许总质量百分比"计算；注意"载货汽车违反规定载客"另计（记3分）；货运超载一案双罚（驾驶人+运输企业）。

---

## E. 涉牌证类（伪造变造/无牌/遮挡污损）

**核心法条**：道交法第95、96条；记分办法第8-11条

**代表性违法**：
- E1 使用伪造/变造号牌、行驶证、驾驶证、校车标牌，或使用其他机动车号牌/行驶证 → 记12分+罚款2000-5000元+可拘留≤15日
- E2 驾驶未悬挂号牌或故意遮挡/污损号牌机动车 → 记9分+罚款200元
- E3 不按规定安装机动车号牌 → 记3分+罚款200元
- E4 未随车携带行驶证/驾驶证 → 警告或罚款20-200元+可扣留车辆/驾驶证

**审核要点**：伪造变造与"未悬挂/遮挡"性质不同（前者记12分且可拘留，后者记9分）；注意扣车/扣证程序。

---

## F. 涉驾驶证类（无证/准驾不符/暂扣期驾驶）

**核心法条**：道交法第99条第1款第1项；记分办法第9-10条

**代表性违法**：
- F1 未取得驾驶证驾驶机动车（无证驾驶）→ 罚款200-2000元+可拘留≤15日
- F2 驾驶与准驾车型不符的机动车（准驾不符）→ 罚款200-2000元+可拘留≤15日+**记9分**
- F3 驾驶证被暂扣/扣留期间驾驶机动车 → 记6分+罚款200-2000元+可拘留≤15日
- F4 将机动车交由无证/吊销/暂扣人驾驶 → 罚款200-2000元+可吊销证（道交法第99条第2款）
- F5 驾驶证被吊销期间驾驶 → 罚款200-2000元+可拘留≤15日

**审核要点**：准驾不符现行记9分（163号令）；区分"未取得"（从未取得）与"被吊销/暂扣"（曾取得）；注意出借车辆的责任（道交法第99条第2款）。

## G. 信号灯与标志标线类

**核心法条**：道交法第38条、第90条；记分办法第11-12条

**代表性违法**：
- G1 不按交通信号灯指示通行（闯红灯）→ 记6分+罚款
- G2 违反禁令标志指示 → 记1分+罚款
- G3 违反禁止标线指示（压黄实线等）→ 记1分+罚款

**审核要点**：闯红灯记6分；违反禁令标志/禁止标线记1分；注意与"不按规定车道"区分。

---

## H. 让行与礼让类（行人/校车/让行）

**核心法条**：道交法第47条；记分办法第11条

**代表性违法**：
- H1 行经人行横道不减速/不停车/不避让行人 → 记3分+罚款
- H2 不按规定避让校车 → 记3分+罚款
- H3 不按规定超车、让行 → 记3分+罚款

**审核要点**：礼让行人记3分；遇行人正在通过人行横道必须停车让行（道交法第47条）。

---

## I. 高速公路与城市快速路类

**核心法条**：道交法第67、90条；记分办法第8-11条

**代表性违法**：
- I1 在高速/城市快速路倒车、逆行、穿越中央分隔带掉头 → 记12分+罚款200元
- I2 在高速/城市快速路违法停车 → 记9分+罚款
- I3 在高速/城市快速路违法占用应急车道行驶 → 记6分+罚款
- I4 在高速/城市快速路不按规定车道行驶 → 记3分
- I5 在高速公路上行驶低于规定最低时速 → 记3分
- I6 实习期驾驶人在高速驾驶无持相应/更高准驾车型3年以上驾驶人陪同 → 罚款

**审核要点**：高速倒车/逆行/掉头记12分（最严重）；注意"城市快速路"与"高速公路"同等对待的记分条款。

---

## J. 违法超车/变道/逆行类

**核心法条**：道交法第43、90条；记分办法第11条

**代表性违法**：
- J1 在高速/城市快速路以外道路逆向行驶 → 记3分+罚款
- J2 不按规定超车 → 记3分+罚款
- J3 遇前方停车排队/缓慢行驶，借道超车或占用对面车道、穿插等候车辆 → 记3分+罚款
- J4 违法变更车道影响正常行驶 → 罚款

**审核要点**：逆行与"不按规定超车"均记3分；高速逆行记12分（见I类）。

---

## K. 违法停车类

**核心法条**：道交法第56、93条；记分办法第9、12条

**代表性违法**：
- K1 在高速/城市快速路违法停车 → 记9分
- K2 在禁停路段违法停车 → 罚款（一般20-200元），可拖移
- K3 人行横道/网状线/消防通道停车 → 罚款+可拖移

**审核要点**：普通道路违停一般不记分；高速/城市快速路违停记9分；注意拖移程序（道交法第93条）。

---

## L. 驾驶行为类（电话/安全带/疲劳/灯光）

**核心法条**：道交法第22、51、90条；记分办法第11-12条

**代表性违法**：
- L1 驾驶时拨打/接听手持电话等妨碍安全驾驶行为 → 记3分+罚款
- L2 驾驶时未按规定系安全带 → 记1分+罚款
- L3 连续驾驶载货汽车超4小时未停车休息或休息<20分钟 → 记3分
- L4 连续驾驶中型以上客货/危化品车超4小时未休息 → 记9分
- L5 不按规定使用灯光 → 记1分+罚款
- L6 车辆故障/事故停车后不按规定使用灯光或设置警告标志 → 记3分

**审核要点**：手持电话记3分；安全带记1分；疲劳驾驶按车型记3分或9分。

---

## M. 货运规范类（载物/改装/违规载客）

**核心法条**：道交法第48、50条；记分办法第11-12条

**代表性违法**：
- M1 载货长度/宽度/高度超过规定 → 记1分+罚款
- M2 载货汽车违反规定载客 → 记3分+罚款
- M3 擅自改变已登记的载货汽车结构/构造/特征 → 记1分+罚款+责令恢复原状
- M4 货运机动车超载（见D类）

**审核要点**：改装货车记1分；注意"载货汽车违规载客"与客车超员性质区分。

---

## N. 客运与校车类

**核心法条**：道交法第49条；记分办法第9-11条

**代表性违法**：
- N1 公路客运汽车违反规定载货 → 罚款
- N2 驾驶校车上路前未检查车况或驾驶安全隐患校车 → 记3分
- N3 未取得校车驾驶资格驾驶校车 → 记9分
- N4 客运超员（见C类）

**审核要点**：校车相关违法记分重；注意校车驾驶资格专项审核。

---

## O. 危化品与超限运输类

**核心法条**：道交法第48条；记分办法第10条

**代表性违法**：
- O1 载运爆炸/易燃易爆/剧毒/放射性等危险物品，未按指定时间/路线/速度行驶或未悬挂警示标志+未采取安全措施 → 记6分
- O2 运载超限不可解体物品，未按指定时间/路线/速度行驶或未悬挂警示标志 → 记6分
- O3 运输危险化学品未经批准进入限制通行区域 → 记6分
- O4 危化品运输车超载（见D类，叠加）

**审核要点**：危化品运输多项记6分；注意与治安管理处罚法、危险化学品安全管理条例的衔接。

---

## P. 交通事故类（逃逸/破坏现场）

**核心法条**：道交法第70、99、101条；记分办法第8-10条

**代表性违法**：
- P1 造成致人轻伤以上或死亡的交通事故后逃逸，尚不构成犯罪 → 记12分+罚款200-2000元+可拘留≤15日
- P2 造成致人轻微伤或财产损失的交通事故后逃逸，尚不构成犯罪 → 记6分+罚款200-2000元+可拘留≤15日
- P3 发生交通事故后故意破坏/伪造现场/毁灭证据 → 罚款200-2000元+可拘留≤15日（道交法第99条）
- P4 交通肇事构成犯罪 → 吊销证+终生禁驾（道交法第101条）
- P5 发生事故不按规定撤离/不设置警告标志 → 记3分

**审核要点**：逃逸按后果严重程度区分记12分（轻伤以上/死亡）或记6分（轻微伤/财产损失）；构成犯罪的吊销+终生禁驾。

---

## Q. 车辆技术状态类（未检/拼装报废/安全设施）

**核心法条**：道交法第13、14、21条；记分办法第11-12条

**代表性违法**：
- Q1 驾驶未按规定定期安全技术检验的公路客运/旅游客运/危化品运输车辆上路 → 记3分
- Q2 驾驶未按规定定期检验的其他机动车上路 → 记1分
- Q3 驾驶拼装/已达报废标准机动车 → 罚款200-2000元+吊销证+收缴车辆（道交法第100条）
- Q4 驾驶安全设施不全/机件不符合技术标准机动车 → 罚款

**审核要点**：未检车辆记分按车型区分；拼装/报废车吊销证（道交法第100条）；注意与强制报废标准衔接。

## R. 非机动车与行人违法类

**核心法条**：道交法第57-61条、第89条；实施条例相关

**代表性违法**：
- R1 非机动车逆向行驶 → 警告或罚款5-50元
- R2 非机动车不按信号灯通行 → 警告或罚款
- R3 醉酒驾驶非机动车（电动自行车超标按机动车论） → 罚款
- R4 行人跨越道路隔离设施 → 警告或罚款5-50元
- R5 行人不按人行横道过街/闯红灯 → 警告或罚款

**审核要点**：非机动车/行人违法处罚幅度低（道交法第89条）；注意"超标电动自行车"按机动车认定的边界。

## S. 买分卖分类（代替处罚牟利）

**核心法条**：记分办法第8条第（七）项、第30条

**代表性违法**：
- S1 代替实际驾驶人接受交通违法处罚和记分牟取经济利益 → 记12分+违法所得3倍以下罚款（≤5万）+撤销原处罚决定
- S2 请他人代接受处罚和记分并支付经济利益 → 所支付经济利益3倍以下罚款（≤5万）
- S3 组织他人实施买分卖分牟利 → 违法所得5倍以下罚款（≤10万）

**审核要点**：买分卖分系严重失信行为；注意撤销原行政处罚决定；与治安管理处罚法衔接。

---

## T. 其他专项类（摩托头盔/电动自行车等）

**核心法条**：道交法第51条；记分办法第12条

**代表性违法**：
- T1 驾驶摩托车不戴安全头盔 → 记1分+罚款
- T2 乘坐摩托车不戴安全头盔 → 罚款
- T3 电动自行车违规载人/载物/不按车道行驶 → 按地方规定处罚
- T4 擅自改装电动自行车 → 按地方规定处罚

**审核要点**：摩托不戴头盔记1分；电动自行车处罚以地方立法为准。

## U. 危险驾驶罪刑事立案审查类（刑案移送）

**核心法条**：《刑法》第133条之一；公传发〔2015〕708号《严重超员、严重超速危险驾驶刑事案件立案标准（试行）》；最高人民法院指导案例32号（张某某、金某某危险驾驶案）

**四类行为与刑事移送要点**：

- **U1 追逐竞驶，情节恶劣** → 依据指导案例32号认定"追逐竞驶"（竞技/刺激/斗气动机下的曲折穿行、快速追赶）；情节恶劣参照最高法标准（严重超速≥90km/h、造成事故、无证、涉牌、饮酒服药、特殊车辆、聚众3人以上、屡犯等）；证据重监控视频、行车轨迹、主观目的反推
- **U2 醉酒驾驶** → 血醇≥80mg/100ml，详见 `drinks-driving-procedure-guide.md`（已系统覆盖，含2023意见、指导案例271号）
- **U3 校车/客运严重超员超速** → 大型超员50%或15人以上 / 中型80%或10人以上 / 小微型100%或7人以上；高速超速50%且≥90km/h等（公传发〔2015〕708号，仅限校车/公路客运/旅游客运/包车客运业务）
- **U4 违规运输危化品，危及公共安全** → 未取得/无效/超越许可或非法营运（依据含2026-05-01施行《危险化学品安全法》第六章运输安全；公安交管负责限行/通行证/警示标志，交通部门负责经营许可/动态监控）

**审核要点**：
1. 行政查处中发现上述情形，应先判断是否达到刑事立案标准，达到则移送，避免"以罚代刑"
2. 第3、4项须审查双罚（机动车所有人/管理人直接责任）
3. 同时构成交通肇事罪或以危险方法危害公共安全罪的，按重罪论处（刑法133条之一第3款）
4. 详细立案标准、证据审查、两法衔接见 `references/dangerous-driving-criminal-guide.md`

## 使用指引（审核员操作）

1. **定位大类**：先判断案件违法性质归入 A-T 哪个大类。
2. **查裁量表**：进入 `penalty_reference.md` 对应大类获取罚款/记分/拘留明细。
3. **查法条原文**：进入 `legal_basis.md` 获取条款款/项精度与法理释义。
4. **罕见/未列情形运行期核对**：本索引未穷尽个别违法类型时，先按"行为性质归入最接近类别"处理；对确属罕见/未列的违法，执行**两级检索核对**（不得凭记忆臆断）：
   - **一级源（优先）**：`search(source='kb', kb_id='UMmkv4zp81dFPymM8rAxhqyrZXy-1dWsEx-72SxJ7ts=', question='<违法名称或违法代码> 处罚 记分 执法指引')` ——检索用户教研知识库（含500种典型违法处罚指引、内蒙古违法代码、道交法释义等权威资料）
   - **二级源（兜底）**：一级无结果时，`search(source='web', question='<违法名称> 处罚 道交法 公安部令')` ——检索政府官网（gov.cn / mps.gov.cn / 国家法律法规数据库 flk.npc.gov.cn）
   - **版权要求**：核对结果引用时**不得出现"两拐"等特定公号/来源署名**，以法规原文或用户库条目为依据；本技能不静态全量写入500种指引，仅运行期调用
5. **多项违法**：跨大类多项违法，调用 `multi-violation-guide.md` 走并罚规则。
