# 抖音短剧合规检查系统 v2.0

## 核心定位

**创作前审核 → 创作中约束 → 创作后自检** 三位一体的短剧创作体系，确保内容既精彩又合规。

---

## 一、七大合规禁区（必须遵守）

### 🔴 禁止领域速查表

| 序号 | 禁止类别 | 具体要求 |
|-----|---------|---------|
| 1 | **不良价值观** | 禁止持续/极端侮辱他人、宣扬/放大社会阴暗、错误伦理观、错误金钱观、暴力仇恨 |
| 2 | **封建迷信** | 禁止宣扬迷信糟粕、法术玄学；玄幻题材需把握尺度，核心应是破除迷信 |
| 3 | **观感不适** | 禁止过度血腥暴力、恶心行径、恶劣观感画面 |
| 4 | **低俗色情** | 禁止挑逗性画面/情节、性暴力情节 |
| 5 | **不良导向** | 禁止危害国家安全、煽动民族仇恨、歪曲历史英雄 |
| 6 | **未成年负面** | 禁止过度呈现未成年相关负面情节 |
| 7 | **敏感题材** | 涉及政治/军事/宗教/司法等需特别把控尺度 |

### ✅ 核心创作原则

1. **立意正向**：主线剧情、人物塑造、结局走向必须传递向善价值观
2. **三观正确**：杜绝低俗恶俗媚俗，遵循公序良俗
3. **尺度合规**：避免任何可能引发审核风险的内容表达

## 二、题材合规对照

| 题材类型 | 合规写法 | 违规红线 |
|---------|---------|---------|
| **重生复仇** | 主角通过智慧和努力改变命运，最终释怀成长 | 极端暴力报复、侮辱折磨、持续羞辱 |
| **豪门总裁** | 平等尊重的爱情关系，互相成就 | 强制囚禁、性暴力暗示、践踏尊严 |
| **穿越玄幻** | 利用智慧勇气改变命运，破除迷信 | 宣扬封建迷信、法术害人、歪曲历史 |
| **悬疑惊悚** | 揭露真相、正义终将胜利 | 过度血腥、恐怖画面、心理不适 |
| **家庭伦理** | 化解矛盾、和谐相处、正向引导 | 狗血撕逼、三观扭曲、渲染仇恨 |
| **都市情感** | 积极向上的情感发展 | 拜金主义、物质至上、不正当关系 |

## 三、创作工作流

### Step 1: 选题策划（合规预审）
```
□ 确定题材类型
□ 评估敏感度等级（低/中/高）
□ 检查是否涉及敏感领域
□ 输出：题材方案 + 风险评估
```

### Step 2: 角色设计（价值观审查）
```
□ 主角：动机正向，有成长弧光
□ 反派：不能只有脸谱化恶意，需有合理动机
□ 配角：服务于剧情，不渲染负面形象
□ 关系：符合公序良俗
□ 输出：角色小传 + 关系图谱
```

### Step 3: 分集大纲（冲突审查）
```
□ 每集一个核心冲突
□ 反转需有逻辑支撑
□ 付费钩子设置合理
□ 无狗血注水内容
□ 输出：分集目录 + 关键节点
```

### Step 4: 单集剧本（内容自检）
```
□ 开场抓人（前3秒有冲突/悬念/反差）
□ 冲突密度适中
□ 爽点频率合理
□ 对白短、狠、准
□ 结尾留钩子
□ 无违规内容表达
□ 输出：完整剧本 + 自检报告
```

### Step 5: 合规终审（必须执行）
```
□ 立意导向审查
□ 价值观合规检查
□ 内容尺度评估
□ 敏感题材复核
□ 输出：合规审核报告
```

- [ ] 题材是否涉及敏感领域？

### 创作中
- [ ] 无极端暴力/侮辱场景？

### 完成后
- [ ] 全部场景通过合规自检？
- [ ] 输出完整审核报告？

## 六、使用说明

**触发场景**：
- 短剧选题、故事方案、角色设计
- 分集目录、单集剧本创作
- 剧本合规审核、修改建议
- 抖音短剧内容自查

**执行顺序**：建议按工作流顺序执行，也支持单独使用某个环节。

**特殊说明**：玄幻/灵异/重生等高敏感题材，需额外进行合规审查，重点检查迷信元素和暴力尺度。
