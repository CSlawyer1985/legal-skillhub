# share-fraction-calc（股权份额精算）

## 目标

用 fraction.js 精确计算份额/股权比例与分摊。

## 适用场景

- 合伙人占比
- 按份分摊金额

## 方法摘要

`Fraction` 约分比 + 百分比；`splitByShares` 分摊。
