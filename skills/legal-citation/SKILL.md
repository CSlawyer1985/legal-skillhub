# 法学引注生成器（基于《法学引注手册（第二版）》）

依据《法学引注手册（第二版）》为学术写作生成规范脚注。覆盖手册第 1–150 条全部体例，不遗漏任何文献类型。

## 一、工作流程（每次生成都按此执行）

### 步骤 1：识别输入形式并提取要素
- **文字 / 文献片段**：直接解析作者、标题、出处、年份、卷期、页码等。
- **链接（URL）**：必须先用 WebFetch 读取页面，提取标题、作者/账号、网站名称、上传日期、URL；判断是网页、博客、微博、微信公众号、App 还是 PDF 全文。
- **图片**：必须用 Read 读图，识别版权页 / 论文首页 / 截图中的文献信息。
- **即使是链接，也要实际读取识别**，不得仅凭 URL 猜测。
- 提取完成后，先回显「已识别要素」表，便于用户核对。

### 步骤 2：判断文献类型并加载规则
按下表路由，**读取对应 reference 文件后再生成**（规则细节都在 references 里，不要凭记忆）：

| 文献类型 | 加载文件 | 手册条号 |
|---|---|---|
| 通用原则、引领词、标点、文中夹注 | `references/core.md` | 第 1–24 条 |
| 中文图书 / 期刊论文 / 报纸 / 古籍 / 台湾地区文献 | `references/cn-print.md` | 第 25–49 条 |
| 网络电子文献（网页/博客/微博/公众号/App/影像/音像） | `references/cn-online.md` | 第 50–58 条 |
| 未发表文献 / 访谈 / 私人通讯 / 内部资料 / 会议论文 / 学位论文 / 档案 | `references/cn-unpublished.md` | 第 59–65 条 |
| 法律法规 / 规范性文件 / 官方文件 / 港澳台与外国国际法律 / 司法案例 / 统计数据 | `references/cn-legal.md` | 第 66–93 条 |
| 英文文献（著作/法律/案例）+ 外文通则 | `references/en.md` | 第 95–115 条 |
| 法文 / 德文 / 意大利文 / 俄文 / 日文文献 | `references/other-lang.md` | 第 116–150 条 |
| 任意类型的「再次引用 / 重复引用」简写 | `references/repeat-cite.md` | 第 13/101/122/128/134/142/150 条 |

类型不明确时，先向用户澄清，或同时给出最可能的两种类型的脚注。

### 步骤 3：按「三段式 + 提示」输出
**每次生成都包含以下内容，用表格或分段清晰呈现：**

1. **【主脚注】** —— 标准格式，自动套用引领词（见步骤 4）。
2. **【可选写法】** —— 当手册对该类型存在多种合规写法时列出。**英文期刊默认采用第 105 条第二种方法**（`作者, 斜体标题, 期刊名, Vol. X: 期, p. 页 (年份).`），同时附上第一种方法供选择。
3. **【再次引用 / 重复引用简写】** —— 必给。按语种给出该文献被再次引用时的简写形式（见 `repeat-cite.md`）：
   - 中文：`同前注〔n〕，作者：《某文》，第 x 页。`；紧邻同一文献用「同上注」，仅页码不同用「同上注，第 x 页」。
   - 英文：`作者姓, supra note n, at x.`；紧邻同一文献用 `Ibid.`。
   - 法文 `op. cit.` / `Ibid.`；德文按 a.F./i.d.F.v. 体例再引；意大利文 `cit.`；俄文/日文「前揭注」。
4. **【缺失提示】** —— 见步骤 5。
5. 必要时从 `core.md` 通用规则补充判断（标点、引领词选择、节制引用等）。

### 步骤 4：自动选择引领词（第 8 条）
- 直接引用原文 / 引用法条、案例 → 省略引领词（或不加「见」）。
- 概括引用文献观点 → 加「参见」。
- 文章来源于期刊、报纸、网络、文集 → 文献来源前加「载」。
- 通过二手文献查到并已核实原文 → 在原始文献后用「转引自」标注二手文献。
- 同一文献多个出处互相印证 → 「又见」；正文叙述一观点并提及其他相关文献 → 「另见」。

### 步骤 5：信息缺失处理（先生成 + 占位提示）
- **先按已知信息生成主脚注**，缺失字段用占位符就地标出：`[缺页码]`、`[缺出版社]`、`[缺年份]`、`[缺卷期]`、`[缺译者]`、`[缺案号]`、`[缺访问日期]` 等。
- 生成后在末尾**明确列出**：「⚠️ 缺少 X、Y，请补充」，并对照该类型「必填要素清单」逐项核对。
- 能从链接 / 图片 / 上下文推断的，尽量补全；仅真正无法获取时才提示。

## 二、各类型必填要素清单（缺失校验用）

- **中文图书**：主要作者、《书名》、出版社、出版年份；引用特定内容须有页码；再版注「第×版/修订版」。作者与作品间用冒号，其他要素间用逗号。
- **中文期刊论文**：作者、《篇名》、期刊名、「××年第×期」、页码。
- **报纸**：作者、《篇名》、报纸名、年月日、版次。
- **古籍**：（朝代）作者、《书名》、卷次/篇名、点校者、出版社、年份、页码（常用经典可文中夹注、省出版信息）。
- **网络文献**：作者/账号、《篇名》、网站名称、上传日期、URL（公众号可省 URL；无上传日期则标访问日期）。用「载」引领，网站名与上传日期间不加逗号。
- **会议/学位论文**：作者、《篇名》、会议名称+举办单位+时间地点 / 学位授予单位+答辩年份+学位层级。
- **英文文献**：作者（名前姓后）、斜体标题、卷号、期刊名、页码、(年份)；日期用「日—月—年」；页码 `p./pp.`。
- **法律法规**：《法律名》（修改年份）第×条第×款第×项。
- **规范性文件**：制定机关、《文件名》、发文字号〔六角括号年份〕。
- **司法案例**：案例名称、审判法院（全称）、案号〔年份用圆括号〕、文书类型。

## 三、关键格式锚点（必须严格遵循）
- 中文纸质文献：主要作者与作品间用**冒号**；其他要素间用**逗号**；同一要素多信息间用**顿号**（第 25 条）。
- 外籍作者在姓名前用方括号注国籍：`[德]`、`[美]`；中文古籍作者前用圆括号注朝代：`（清）`。
- 英文期刊默认（第 105 条第二种）：`Charles A. Reich, The New Property, Yale Law Journal, Vol. 73: 3, p. 733 (1964).`
- 发文字号年份用六角括号 `〔 〕`；案号年份用圆括号 `( )`。
- 标点用全角中文标点；外文文献用外文标点，一般不翻译。

## 四、注意事项
- 引注信息原则上「从原文从原著」，图书以版权页为准，论文以首页为准；署名/标题有明显错误可更正并说明（第 26 条）。
- 节制引用：业内周知的知识无须引注；同一脚注所引文献一般不超过 5 个；多条同类文献按时间顺序排列、用分号隔开。
- 有纸质出版文献的一般不引网络文献；同一文献多个来源引用最早的（第 2、12 条）。
- 引注信息应真实、相关、权威、准确、完整、简洁。
