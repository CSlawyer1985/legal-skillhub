# repeat-cite.md —— 再次引用 / 重复引用简写形式（跨语种汇总）

> 当同一文献在文中**第二次及以后被引用**时，可略写。本文件汇总各语种简写形式。
> 原则（第 13 条）：第一次引用必须完整；再次引用可略写；是否略写宜考虑引用频次，由期刊/出版社规定为准。为防引注信息在修改中错乱，不建议定稿前或投稿时使用略写。

## 一、中文学术文献（第 13 条）

### 1. 非紧邻再次引用 → 「同前注」
格式：`同前注〔n〕，作者：《文献名》，第 x 页。`
- `n` = 该文献第一次出现的脚注序号。
- 外籍/古代作者前**不加**国籍和朝代；作者三人以上可只写第一作者 + 「等」；可省副标题。
- 示例：`同前注〔16〕，[德]鲁道夫·冯·耶林：《为权利而斗争》，第 3 页。` → 略写为 `同前注〔16〕，耶林：《为权利而斗争》，第 3 页。`
- 不引起误解时可进一步省为：`同前注〔16〕，张文显、于宁文，第 69 页。` 甚至「某某书」「某某文」。

### 2. 紧邻同一文献（前后紧邻两个引注、文献完全相同、无其他文献干扰）→ 「同上注」
- 仅出处相同：`同上注。`
- 仅页码不同：`同上注，第 213-214 页。`

### 3. 法律文件 / 官方报告略写
- 应标明制定机关（报告人）和文献名称。
- 示例：`同前注〔5〕，信春鹰：《关于〈中华人民共和国行政诉讼法修正案（草案）〉的说明》。`

## 二、英文文献（第 101 条）

### 1. 再次引用学术文献 → `supra`
- 只写姓氏，文献名和来源省略，用 `supra` 引上一条文献并标其序号。
  `Alford, supra note 11, p. 110.`
- 同一姓氏有不同人 → 再引时标作者名或名的首字母以区别。
- 同一作者有多篇文献 → 再引时标文献名（可省副标题）。
  `Alford, To Steal a Book Is an Elegant Offense, supra note 11, p. 110.`

### 2. 紧邻同一文献且无其他文献干扰 → `Ibid.`
- `Ibid., p. 106.`

### 3. 再次引用法规或案例
- 只标法规/案例名称，省略编号和来源；第一次已标首字母缩写的，再引可仅标缩写。
  `GDPR, art. 60.`

## 三、法文（第 122 条）
- 作者只写首字母、省副标题和出版信息，用 `op. cit.`：`J. Chevallier, L'État de droit, op. cit., p. 212.` → 可进一步 `Chevallier, op. cit., p. 251.`
- 紧邻同一文献用 `Ibid.`：`Ibid., p. 213-214.`

## 四、德文（第 128 条）
- 再引按德文习惯：作者姓 + 缩写文献名 + `(Fn. n)` + 位置；紧邻同一文献用 `Ebenda` / `Ders.`；注意 `a.F.`（旧版）与 `i.d.F.v.`（某日期版本）的版本标注。

## 五、意大利文（第 134 条）
- 用 `cit.`（`op. cit.` / `loc. cit.`）；紧邻同一文献用 `Ibid.` / `Ivi`。

## 六、俄文（第 142 条）
- 用「前揭」`Указ. соч.` 等俄文习惯写法 + 页码 `С.`。

## 七、日文（第 150 条）
- 用「前揭注」+ 序号 + 作者 + 页码：`前揭注（n）我妻·第 52 页`。

---
**输出要求**：每次生成脚注时，都要在「主脚注」之后附上该文献对应语种的**再次引用简写形式**，让用户知道在文中重复引用时如何书写。
