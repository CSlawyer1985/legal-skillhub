# 法律影响与咨询意见模板

本文档提供针对不同制裁/管控清单命中时的标准法律影响分析和建议模板。报告生成时应根据实际命中清单组合本模板内容。

## 模板结构

每个命中清单应输出以下结构：

```
#### N. [清单全名] ([机构缩写])
- **法律影响 (Legal Impact):** [引用具体法规/行政令号]
- **审批政策 (Licensing Policy):** [推定拒绝/逐案审查等]
- **咨询建议 (Advisory):** [面向客户的具体行动建议]
```

## 各清单法律影响模板

### OFAC SDN List
- **法律影响:** 依据 IEEPA，美国人与 SDN 实体进行任何交易均构成违法。该实体在美资产须冻结。
- **审批政策:** 全面禁止，需 OFAC 特别许可 (Specific License)
- **咨询建议:** 立即冻结一切在途交易。评估现有合同中的制裁条款和终止权。通知外部法律顾问。

### OFAC Non-SDN CMIC
- **法律影响:** 依据 EO 13959 / EO 14032，美国人严禁买卖或持有该实体公开交易证券或衍生金融工具。
- **审批政策:** 证券投资禁令（非全面交易禁令）
- **咨询建议:** 清查美元基金或含美国投资者架构中是否持有该实体证券头寸。确认无一级/二级市场股权交易。

### BIS Entity List
- **法律影响:** 受 EAR 管辖。出口/再出口/国内转让受控物项须向 BIS 申请许可证。
- **审批政策:** 推定拒绝 (Presumption of Denial)
- **咨询建议:** 全面清查涉及该实体的产品/技术。适用 25% De Minimis Rule 判断。若受控，必须立即终止。

### DoD 1260H CMC List
- **法律影响:** 依据 NDAA §1260H，被认定为"中国涉军企业"。目前无直接交易禁令。
- **审批政策:** 无许可要求，但释放强烈政策信号
- **咨询建议:** 虽无强制义务，但该认定通常是后续 SDN 制裁的前导。建议升级风险评估级别。

### SAM.gov Exclusions
- **法律影响:** 不得参与美国联邦政府合同、赠款和合作协议。
- **审批政策:** 联邦采购全面排除
- **咨询建议:** 如参与联邦资金项目竞标，严禁在履约环节涉及该实体。

### FCC Covered List
- **法律影响:** 使用 USF 资金不得采购该清单上通信设备。部分实体通过 NDAA 条款类别性列入。
- **审批政策:** 通信设备准入限制（非贸易禁令）
- **咨询建议:** 清查供应链中是否涉及该实体生产的通信/无人机/监控设备。

### UK OFSI Sanctions
- **法律影响:** 依据英国制裁法案，英国人/实体与被制裁方的交易构成刑事犯罪。
- **咨询建议:** 若在英国有关联实体或经由英国金融体系汇款，须遵守 OFSI 合规要求。

### EU Sanctions
- **法律影响:** 依据欧盟共同外交与安全政策 (CFSP)，所有 EU 成员国须执行资产冻结和交易限制。
- **咨询建议:** 涉及欧元区的支付、贸易或投资须确认合规。

### UN Security Council Sanctions
- **法律影响:** 依据联合国宪章第七章，所有成员国有义务执行安理会制裁决议。
- **咨询建议:** UN 制裁具有全球约束力，即使实体注册地不在主要制裁发起国。

## 管理层行动建议模板 (Executive Action Plan)

在所有命中情况的最后，添加以下总结性建议区块：

```markdown
> [!CAUTION]
> **管理层底线结论 (Executive Action Plan):**
> [根据命中清单的严重程度，给出一个明确的、可执行的管理层决策建议]
```

示例：
- 仅 Non-SDN CMIC → "限制证券投资，一般贸易需审查美国技术成分"
- Entity List + CMIC + DoD → "升级审批，暂停涉美技术链的全部交易"
- SDN 命中 → "立即冻结一切交易，终止合同，通知法律顾问"
