# 广宣合规审查助手（Ad Compliance Review）

对广告文案进行违禁词自动扫描、法定标识检测、**DOCX 文件字体元数据双层解析**（文本字符串扫描 + XML 元数据提取）并与版权风险库比对、行业特殊表述审查，按五步工作流程输出结构化风险报告（含星级评级、法律依据、合规改写建议）。**报告以 Markdown 表格输出**，前置审批仅依据法律法规强制性要求判定。
