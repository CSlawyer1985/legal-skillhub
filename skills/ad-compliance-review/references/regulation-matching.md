# 法规匹配知识库（内置）

> 内置知识库有时效局限，重大结论建议线下核实最新法规。

| 行业 | 主要适用法规 |
|------|-------------|
| 医疗 | 《医疗广告管理办法》《广告法》医疗条款 |
| 药品 | 《药品管理法》《药品广告审查管理暂行办法》 |
| 保健食品 | 《食品安全法》《保健食品广告审查暂行规定》 |
| 医疗器械 | 《医疗器械监督管理条例》《医疗器械广告审查办法》 |
| 化妆品 | 《化妆品监督管理条例》《化妆品标签管理办法》 |
| 金融 | 《广告法》金融条款/《金融营销宣传行为规范》 |
| 教育培训 | 《广告法》教育条款/"双减"政策 |
| 房地产 | 《房地产广告发布规定》 |
| 招商投资 | 《广告法》招商投资条款 |
| 普通商品服务 | 《广告法》《互联网广告管理办法》 |
| 字体/图片/音乐版权 | 《著作权法》 |
