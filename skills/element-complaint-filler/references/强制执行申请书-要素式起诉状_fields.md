# 强制执行申请书-要素式起诉状 — 字段坐标快查

跳过 inspect_template，直接用以下坐标。

## 模板特征
- 1 个表格，19 行 × 2 列
- 字体: 仿宋，样式 ID: 1 / 7（混合），**不要统一改 pStyle**
- 模板通常已预填当事人信息、案号、判决主文，只改需要改的字段

| 字段 | Cell | 说明 |

### 申请执行事项段落结构（[16,1]）

| 段落 | 标签 | 操作 |
|------|------|------|
| P0 | 金钱给付： | 不动 |
| P1 | 本金：100000元 | run 级替换数值 |
| P2 | 一般债务利息：... | run 级追加（暂算至...为 XX 元）|
| P3 | 迟延履行利息：... | run 级追加具体期间和金额 |
| P4 | 其他费用：... | 不动（已预填） |
| P5 | 行为执行□ | 不动 |
| P6 | 交付特定物□ | 不动 |
| P7 | 其他□ | 不动 |

| [3,1] | 申请执行人（法人） | "/" |
| [4,1] | 委托诉讼代理人 | "/" |
| [6,1] | 被执行人（法人） | "/" |
| [17,1] | 诉前/诉讼保全 | ghost，不写 |

## 已知陷阱
- **性别勾选必须用 cell_gender**，仿宋字体下 □=☑ 不可区分
- **申请执行事项绝对不要 cell_set**，会毁掉 8 段结构
- **已有数据的 cell 不要调 ensure_font**，字体走样式继承
- 该模板使用混合 pStyle（Normal + style 7），不要统一设置
