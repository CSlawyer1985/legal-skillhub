# 法律研究备忘录 — 分析论证框架（CRAC 内化 + 叙事规范）

> 本文件由 SKILL.md Step 3 抽取而来，进行叙事化分析论证时读取，含 §3.1 CRAC 内化方式对比与示例、§3.2 叙事规范。

## 3.1 核心原则：CRAC是思维工具，不是输出格式

> **这是本次修订的核心变更。旧版要求每个子问题输出四个独立标签段落（法律依据/事实适用/风险判断/结论），导致输出带有强烈的"AI生成"模板感。新版要求 CRAC 内化为思维框架，在单一叙事段落中自然呈现，读者看到的是一段完整的律师分析，而非填表式报告。**

**CRAC 内化方式：**

| 环节 | 旧版（标签化输出） | 新版（叙事化输出） |
|------|-------------------|-------------------|
| **C**onclusion | 独立"结论"标签段落 | 开门见山的第一句话即为判断 |
| **R**ules | 独立"法律依据"标签段落 | 在分析中自然引用法条，不标"法律依据" |
| **A**nalysis | 独立"事实适用"标签段落 | 事实与法律交织论证，用"首先/其次/再次"递进 |
| **C**onclusion | 独立"结论"标签段落 | "综上"一句话收束 |

**示例对比：**

❌ 旧版（标签化）：
> 问题：以物抵债协议的法律性质是什么？
> 法律依据：《合同编通则解释》第二十七条第一款……
> 事实适用：在以物抵债协议签署后、抵债物尚未交付的阶段……
> 风险判断：法律定性明确，不存在分歧……
> 结论：履行期届满后达成的以物抵债协议为诺成合同……

✅ 新版（叙事化）：
> 一、以物抵债协议的法律性质
> 履行期届满后达成的以物抵债协议属于诺成合同，自双方意思表示一致时即成立并生效，不以抵债物的实际交付为成立要件。依据《合同编通则解释》第二十七条第一款，只要不存在影响合同效力的情形，协议"自当事人意思表示一致时生效"。最高人民法院在通州建总案〔(2016)最高法民终字第484号〕中也明确，以物抵债协议"并不以债权人现实地受领抵债物，或取得抵债物所有权、使用权等财产权利，为成立或生效要件"。因此，"物没交付"不是协议未生效的理由，不能以此为由主张协议无约束力。

## 3.2 叙事规范

| 要素 | 规范 |
|------|------|
| 子标题 | 中文序号"一、""二、""三、……"（不写"问题1""子问题一"） |
| 递进 | "首先……其次……再次……"或自然因果词（"据此""基于以上"） |
| 风险提示 | "在此需提醒贵司注意"引出 |
| 段末收束 | "综上，"或"据此，"一句话概括 |
| 全文收束 | "综上所述，"起头 |
| 简短回答 | "我们的初步判断是："起头，3-5句概括核心结论，让客户不必翻到末尾就能获得答案 |
| 语气 | "我们建议贵司""我们认为""贵司可考虑"——面向客户说话 |
| 段落 | 每段一个核心观点，段落间用空行分隔 |
