# engagement-terms-billing-guidelines

**OCM Skills 插件**——8 个技能中的第 1 个
**状态：** 已完成——第一阶段和第二阶段已测试

---

## 本技能的用途

起草、审查和维护外部律师指引（outside counsel guidelines，OCG）——即设定外部律所如何计费、配备人员、沟通和交付法律服务预期的操作性文件。

OCG 是法务运营职能可用成本最低、影响最大的干预手段。60% 的法务团队没有 OCG。在拥有 OCG 的 40% 中，87% 几乎没有执行。本技能固化了构建与团队成熟度水平相匹配的 OCG、并产出内部商业论证以推动其获得采纳的方法论。

---

## 模式

| 模式 | 触发 | 输出 |
|------|---------|--------|
| 1——起草 OCG | "起草计费指引" / "我们没有计费指引" / "撰写一份 OCG" | OCG 文件 + 总法律顾问（GC）简报 + 封面邮件 |
| 2——审查与差距分析 | "审查我们的指引" / "我们的 OCG 缺什么" | 差距分析 + GC 简报 |
| 3——定向更新 | "更新 AI 条款" / "增加多元化与包容性（D&I）要求" / "加强费率审查条款" | 替换章节文本 + GC 说明 |
| 4——内部商业论证 | "关于计费指引的 GC 简报" / "我如何让 OCG 获得支持" | GC 决策备忘录 |

---

## 关键设计决策

**成熟度校准。** 输出长度、组成部分覆盖和执行强度由成熟度水平（早期 / 中期 / 高级）驱动。早期团队获得一份简洁、协作性的 OCG。高级团队获得具有正式执行机制的全面条款。从低起点开始——提升成熟度比在律所已提出反对后撤回条款更容易。

**15 个组成部分框架。** 差距分析（模式 2）对照一个结构化的最佳实践框架进行评估，涵盖费率治理、计费格式、禁止收费、人员配备、AI 透明度、D&I 等。进行逐项评估而非总体评分——用户需要知道具体应修改哪些条款。

**每种模式都面向 GC 输出。** 每种模式既产出操作性文件，也产出面向 GC/领导层的文件。用户需要工具，也需要使用该工具的内部论证。

**AI 计费条款。** 所有成熟度水平均包含 AI 政策条款。59% 的法务不知道律所是否在其案件中使用了 AI。披露要求和 AI 计费规则正是在 OCG 中确立的。

**已有 OCG 的路由。** 如果用户提供了现有的 OCG，本技能默认进入模式 2（差距分析），即使他们说的是"帮我起草指引"。改进现有内容比从头开始更快、破坏性更小。

## 跨技能关联

| 技能 | 关联 |
|-------|-----------|
| fee-arrangement-structuring（技能 4） | OCG 设定 AFA（替代收费安排）政策偏好。技能 4 为具体案件设计具体安排。 |
| matter-allocation-instruction（技能 5） | OCG 是常设文件；案件委托按每个委托引用它。 |
| invoice-review-compliance（技能 6） | OCG 定义发票审查所执行的规则。薄弱的 OCG = 没有可衡量的基准。 |
| performance-scorecard（技能 7） | OCG 合规率是记分卡指标。记分卡识别不合规 → OCG 更新强化条款。 |
| panel-review-rationalisation（技能 8） | OCG 遵守情况是律师库保留标准。 |
