## 起草要点

### 风格与语气

- **严格编号**：主要部分（1.、2.）、子部分（1.1、1.2）、次子部分（2.1.1、2.1.2）
- **系统性地引用证据材料**：提及文件后始终加括号注明
- **中立称呼**：使用"Madame ou Monsieur le Président"（庭长先生/女士）（绝不使用"Votre Honneur"（法官大人）或其他称呼）
- **指定受诉法院**：对受诉法院使用"de céans"（本院）
- **当事人指定**：全篇使用一致简称
- **法律表述**：优先使用"Il est demandé"（请求……）而非"Nous demandons"（我们请求……）
- **论证结构**：En droit / En l'espèce（法律上/本案中）（系统性使用）

## 强制与建议要素

### 强制要素

**传票有效性绝对必需的要素：**

1. ✅ **当事人完整身份信息**（身份信息、RCS 商业登记号、地址）
2. ✅ **开庭日期、时间和地点**
3. ✅ **强制警告**（《民事诉讼法典》第 853 条和第 861-2 条）
4. ✅ 当事人的 **Kbis 工商登记摘录**（材料 1 和 2）
5. ✅ 确立关系的**合同或订货单**
6. ✅ 作为证据材料的**全部未付发票**
7. ✅ 客户账户的**会计总账**
8. ✅ **服务/交付已履行的证明**
9. ✅ **证明债权具有确定性、金额明确且已到期**
10. ✅ **证明不存在实质性争议**
11. ✅ **证据材料完整清单**

### 强烈建议的要素

**为强化案卷的稳固性：**

- 📌 **书面催告**（挂号信或电子邮件），证明付款请求
- 📌 关于付款方式的**合同条款**
- 📌 合同约定的**罚金条款或逾期利息**
- 📌 **经签署的送货单**或收件回执
- 📌 **活动报告**或已完成服务的报告
- 📌 先前**部分付款的证明**（证明债务承认）
- 📌 确认良好履行的**往来函件**

## 应避免的陷阱

❌ **不要混淆**：
- Provision（临时款项——等待实体判决的暂定金额）与最终判令（condamnation définitive）
- Référé（紧急程序）与 fond（普通程序）
- 确定性债权与可争议债权

❌ **不要忘记**：
- 判决主文末尾的"SOUS TOUTES RESERVES"（保留一切权利）表述
- "Lequel se constitue par la présente assignation et ses suites"（其以本传票及其后续程序构成）格式
- 用于识别当事人的"Ci-après désignée"（以下简称）表述
- 如请求复利（anatocisme）的资本化

❌ **不要包含**：
- 缺乏明确证据的实体争议事项
- 需要鉴定或长时间调查的请求
- 债务人对服务质量的无记录异议

❌ **不要过度论证**：
- "FAITS"（事实）部分保持事实性
- 将法律论证保留在"DISCUSSION"（论证）部分
- 避免各部分的重复

## 常用金额与期限

**临时款项/债权：**
- 任何由发票 + 会计总账证实的金额
- 通常为几千至几万欧元
- 债权成立则无理论上限

**不可追偿费用（《民事诉讼法典》第 700 条）：**
- 小额债权（< 10,000 欧元）：1,500 至 2,500 欧元
- 中等债权（10,000 - 50,000 欧元）：2,500 至 4,000 欧元
- 大额债权（> 50,000 欧元）：3,000 至 5,000 欧元

**合同逾期利息：**
- 欧洲央行利率 + 10 个百分点（法定最低）
- 或合同约定利率（如更高，在合理限度内）

**传唤期限：**
- 送达与开庭之间至少 15 天
- 建议：3 至 4 周，以便律师接受委托

## 发送前最终检查清单

### 形式核查

- [ ] 当事人身份信息完整且准确
- [ ] 公司 RCS 号码正确
- [ ] 地址完整且最新
- [ ] 开庭日期、时间和地点精确
- [ ] 律师联系方式完整（含 toque 律师袍号）
- [ ] 强制警告存在（《民事诉讼法典》第 853 条和第 861-2 条）
- [ ] "Lequel se constitue par la présente assignation et ses suites" 格式
- [ ] 判决主文末尾的"SOUS TOUTES RESERVES"格式
- [ ] 律师签名（如为纸质版）

### 实质核查

- [ ] 所有未付发票均已列出并注明引用
- [ ] 请求总额正确
- [ ] 到期日已注明
- [ ] 服务履行的证明已提供
- [ ] 会计总账已作为证据材料
- [ ] 不存在实质性争议已证明
- [ ] 催告已记录（如已进行）
- [ ] 合同要素引用正确
- [ ] 定额追偿补偿金已计算（40 欧元 × 发票数量）
- [ ] 警告类型与债务人身份（公司或自然人）相符
- [ ] 个体工商户：SIRENE 通知作为证据材料（不一定需要 Kbis）

### 法律核查

- [ ] 《民法典》条文引用正确（1101、1103、1104、1212）
- [ ] 提及《民事诉讼法典》第 873 条（判决主文中不带"第 2 款"）
- [ ] 引用《商法典》第 L. 441-6 条（定额补偿金）
- [ ] 确定性、金额明确、已到期的条件已展开
- [ ] 不存在不履行抗辩已证明
- [ ] 相关时引用判例
- [ ] 法定利率利息请求已明确（是否按倍数）
- [ ] 利息起算点已注明（催告或最后一张发票）
- [ ] 复利请求已提及（如希望）
- [ ] 定额追偿补偿金已请求（40 欧元 × 发票数量）
- [ ] 第 700 条费用已请求（合理金额）
- [ ] 判决主文使用"临时款项"（somme provisionnelle）表述

### 证据材料核查

- [ ] 材料 1：债权人 Kbis（3 个月内）
- [ ] 材料 2：债务人 Kbis（3 个月内）
- [ ] 材料 3：合同或订货单或销售条款
- [ ] 材料 4 及以后：全部未付发票
- [ ] 材料 X：履行证明（报告、送货单等）
- [ ] 材料 X+1：会计总账
- [ ] 材料 X+2：催告（如适用）
- [ ] 证据材料清单完整且一致

### 整体一致性

- [ ] 全文金额一致
- [ ] 日期一致且按时间顺序
- [ ] 证据材料引用准确
- [ ] 当事人简称使用一致
- [ ] 各部分之间无矛盾
- [ ] 判决主文与论证部分相符
- [ ] 请求清晰且已计金额

## 程序策略说明

### 紧急程序中的临时款项与最终判令

**关键原则**：紧急程序法官（juge des référés）可以作出两类决定：

#### 1. Provision（临时款项）

**何时使用：**
- 债权明确但可能成为后续异议对象
- 精确金额可能受争议
- 希望为实体程序留出空间

**判决主文中的表述：**
```
CONDAMNER [债务人] 向 [债权人] 支付临时款项
[金额] 欧元（含税）……
```

**优点：**
- 法官更容易批准
- 当然具有临时执行力

**缺点：**
- 债务人可以向实体法官起诉异议

#### 2. 最终判令（Condamnation définitive）

**何时使用：**
- 债权完全不可争议
- 履行的证据无可辩驳
- 债务人完全无异议
- 金额精确且不可争辩

**判决主文中的表述：**
```
CONDAMNER [债务人] 向 [债权人] 支付 [金额] 欧元（含税）……
```
（注意无"临时"（provisionnelle）一词）

**优点：**
- 具有权威性的最终决定
- 终结争议

**缺点：**
- 更难获得（证明要求更严格）

#### 实务建议

**在大多数情况下，请求"临时款项"（somme provisionnelle）：**
- 法律上更审慎
- 法官更倾向批准
- 不阻碍立即执行
- 如债务人不提出实体异议，临时款项成为终局

### 何时选择紧急程序而非支付令（injonction de payer）

**紧急程序的优点：**
- 对席决定 = 当然具有临时执行力
- 附理由的决定 = 更难异议
- 有可能获得最终判令（不仅是裁定）
- 可处理更复杂的债权

**紧急程序的缺点：**
- 成本更高（律师委托强制）
- 期限更长（开庭 + 判决）
- 要求不存在实质性争议

**何时优先选择紧急程序：**
- 债权较大（> 10,000 欧元）
- 已建立的商业关系
- 需要稳固且最终的决定
- 预期债务人会异议
- 还需要获得诉讼费用和第 700 条费用的判令

### 与实体程序的衔接

**如果已存在实体程序：**
```
特此说明，[债权人] 已就实体问题于 [日期] 向 [城市] [商事/司法]法院
向 [债务人] 送达传票，登记号 RG 第 [号码] 号。

但是，鉴于实体程序的不可压缩期限以及 [债权人] 债权追偿的紧迫性，
现送达本紧急程序传票，以便在等待实体判决期间获得一笔等于无实质性
争议债权金额的临时款项。

向紧急程序法官提出的请求丝毫不妨碍实体程序中作出的决定，仅为一项
旨在保障 [债权人] 权利的临时措施。
```

**如果紧急程序是唯一程序：**

无需特别说明。债权不可争议时，紧急程序可导致最终判令。

### 异议风险管理

**预期可能的异议：**

起草时就识别债务人可能援引的抗辩：
- 品质缺陷 → 纳入品质证明 + 无投诉记录
- 不符合要求 → 纳入无保留签署的送货单
- 施工瑕疵 → 纳入满意度证明 + 后续使用
- 缺乏授权 → 纳入已签署的订货单
- 抵销 → 证明所援引的债权并非确定

**开庭准备：**

预期法官的问题：
- 债务人为何不付款？
- 是否曾有投诉？
- 服务是否已完整提供？
- 债务人是否有财务困难？
- 是否存在平行诉讼？

准备基于证据材料的清晰、事实性的回答。

## 关键原则总结

1. **债权确定、金额明确、已到期**：不可或缺的三要素
2. **不存在实质性争议**：紧急程序的决定性标准
3. **履行证明**：全面记录
4. **会计总账**：必不可少的证据材料
5. **严格结构**：En droit / En l'espèce（法律上/本案中）系统性使用
6. **证据材料引用**：始终加括号
7. **中立事实语气**：事实部分避免价值判断
8. **结论坚定**："Par conséquent, [明确请求]"（因此，[明确请求]）

## 起草协助

当用户要求起草债权追偿紧急程序传票时，遵循以下流程：

1. **提出工作流问题**（见 `workflow-collecte.md`）
2. **收集所有可用文件**
3. **严格遵循结构起草**（见 `structure-assignation.md`）
4. **根据债权类型调整**（见 `variantes-cas-particuliers.md`）
5. **逐一核查最终检查清单的每个要素**
6. **复核整体一致性**和引用的准确性

**重要**：绝不可即兴编造结构或法律表述。坚持本 skill 已经验证并符合法国司法实践要求的模板。
