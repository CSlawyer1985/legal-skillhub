## 按债权类型划分的变体

### A. 智力服务

**特殊性：**
- 强调智力性质和要求具备的专业知识
- 详述所提供的交付物（报告、研究、咨询意见）
- 强调无法"收回"已提供的服务
- 提及默示接受（采纳咨询意见、实际实施）

**表述：**
```
[债权人]服务的特点在于提供其具备[领域]专业知识的员工，特别是为了实现
[目标]。

这些智力服务本质上无形且不可返还，已完整提供给[债务人]，[债务人]已将其
用于[具体用途]并从中受益。
```

### B. 商品销售

**特殊性：**
- 强调已签署的送货单
- 如适用，提及所有权保留条款
- 详述产品的数量和规格
- 说明货物是否仍由债务人占有

**表述：**
```
[债权人]已按照订单单据向[债务人]交付以下货物：

- [数量][产品描述]，金额为 [X] 欧元（不含税）
- [...]

[债务人]已无保留地接收这些货物，由[收货人姓名]于[日期]签署的送货单为证。

证据第 [X] 号：已签署的送货单
```

**如存在所有权保留条款：**
```
兹明确，所交付货物在价款完全付清前仍归[债权人]所有，此与[债务人]已接受的
销售一般条款中所载的所有权保留条款一致。

但是，[债权人]优先请求支付销售价款，并保留在未获付款时行使货物取回权
的权利。
```

### C. 持续服务（维护、订阅）

**特殊性：**
- 建立月度服务的时序
- 显示履行的规律性
- 证明服务已被使用（日志、工单、介入记录）
- 提及前期应付期限的既往付款

**表述：**
```
合同约定[服务类型]持续服务，期限为[期限]，按月定额报酬 [金额] 欧元
（不含税）。

[债权人]自[开始日期]起至[结束日期/当前日期]，即[期限]期间，不间断地提供了
全部约定服务。

已履行服务尤其包括：
- [所提供服务/介入的描述]
- [...]

[债务人]且已支付前 [X] 个月度期限，从而承认合同的良好履行和债权的合理性。

只是自[日期]起，[债务人]才在毫无任何理由的情况下停止履行其合同义务。
```

### D. 承揽合同（工程）产生的债权

**特殊性：**
- 提及已接受的报价单
- 详述工程验收（有保留或无保留）
- 如有保留：证明其已被消除
- 强调债务人对工程的投入使用

**表述：**
```
在[债务人]接受[日期]第[编号]号报价单后，[债权人]实施了以下工程：

- [工程描述]

工程于[日期]完工，并于[日期]由[债务人][有保留/无保留]地验收。

[如有保留：]
验收时提出的保留涉及[描述]，经[债权人]补充施工后已于[日期]全部消除，
以保留消除笔录为证。

证据第 [X] 号：验收笔录[附保留消除]

[债务人]此后一直使用已完工程，未对其符合性或质量提出任何异议。
```

## 按金额调整

### 小额债权（< 5,000 欧元）

**特点：**
- 可适用简化程序
- 论证更简洁
- 判例论述较少
- 第 700 条费用：1,500 至 2,000 欧元

**建议：**
- 法律部分直奔要点
- 优先采用清晰的书证
- 避免过长的论述

### 中等债权（5,000 - 50,000 欧元）

**特点：**
- 建议采用完整结构
- 全部法律论述
- 详尽文件
- 第 700 条费用：2,500 至 4,000 欧元

**建议：**
- 遵循本技能的标准范本
- 包含判例引用
- 展开全部法律要点

### 大额债权（> 50,000 欧元）

**特点：**
- 非常充分的论证
- 非常深入的文件
- 预判可能的争议
- 第 700 条费用：3,000 至 5,000 欧元

**建议：**
- 每个要点以多个判例来源展开
- 多方举证履行事实
- 准备备用论点
- 如案情复杂，考虑事先鉴定

## 特殊情况

### 部分被争议的债权

**如债务人已对债权的一部分提出保留：**

```
兹为既成事实：[债务人]已就[描述被争议部分]提出保留，金额为 [X] 欧元
（含税）。

但是，即使将这些保留视为严肃（事实并非如此），[债务人]也绝不否认债权
余额 [金额 - X] 欧元（含税）。

因此，至少[债权人]有权请求判令[债务人]支付这一未被争议的 [金额 - X] 欧元
（含税）款项。

作为补充请求，[债权人]请求判令支付全部债权，[债务人]提出的保留不构成
严肃的争议，理由如下：

[展开证明保留不成立的论点]
```

### 无书面合同但已建立商业关系所产生的债权

**在无正式合同的情况下：**

```
虽然双方之间未订立任何书面合同，但[债权人]与[债务人]之间已形成惯常的
商业关系，其特征为：

- [债务人]自[日期]起向[债权人]定期下单；
- [债权人]系统性地履行这些订单；
- [债务人]直至[日期]定期支付发票。

该商业关系受[债权人]销售一般条款约束，[债务人]已知悉这些条款并以其行为
默示接受，特别是通过无异议地支付前几笔发票。

证据第 [X] 号：[债权人]的销售一般条款
证据第 [X+1] 号：订单和付款记录

判例承认由双方持续行为产生的意思合意的有效性（最高法院商事庭，2015 年
6 月 16 日，第 14-14.729 号）。
```

### 债务人主张抵销的债权

**如债务人声称对债权人享有反向债权：**

```
[债务人]已[在交流中/在函件中]主张其对[债权人]享有金额为 [X] 欧元的所谓
债权，理由为[所声称的理由]。

该所谓债权不能妨碍请求的判令，理由如下：

i) 该债权在原则上不确定：[解释其为何不存在或未被证实]；

ii) 即使假定其存在（事实并非如此），其在数额上也不确定：[债务人]对其
    所称损害未提供任何有数字依据的证明；

iii) 无论如何，《民法典》第 1347 条的法定抵销仅能适用于两笔确定、数额
     明确且已到期的债务之间，本案显然并非如此。

最高法院认为，在紧急审理中，仅当据以主张抵销的债权本身满足确定性、
数额明确性和到期性条件时，抵销才可被对抗（最高法院商事庭，2016 年 3 月
8 日，第 14-24.425 号）。

而本案中，[债务人]仅停留在声称，对其所谓债权的存在和金额未提供任何
初步证据。

因此，任何抵销均不可对抗，[债权人]有权获得判令[债务人]支付其全部债权。
```

### 含解除条款或违约金条款的债权

**如合同规定解除条款：**

```
合同第 [X] 条规定了到期未付款情形下的解除条款：

「[引用精确条款]」

[债权人]未启用该解除条款，而是选择请求强制履行合同和支付价款。

但[债权人]保留如下权利：如在本决定后仍未付款，援引合同解除并请求返还
[服务/货物]，以及损害赔偿。
```

## 表述示例

### 合同关系引入的表述

**书面合同版本：**
```
在其经营活动中，[债务人]公司于[年份]期间请求[债权人]提供[描述]服务。
正是在这一背景下，双方于[日期]约定订立一份涉及[标的]的合同。
```

**无书面合同的订单版本：**
```
[债务人]公司于[日期]通过[订单单据/电子邮件/电话]向[债权人]订购
[描述]。该订单已被[债权人]接受，[债权人]已按照约定条款进行[履行/交付]。
```

**既有商业关系版本：**
```
双方自[日期]起保持既定的商业关系。在此框架内，[债务人]定期向[债权人]
下单，[债权人]按照[债务人]接受的价目表和销售一般条款提供[服务/交付]。
```

### 履行情况的描述表述

**智力服务：**
```
[债权人]已向[债务人]提供其在[领域]的专业知识，并完成了全部约定任务，
即：[交付物清单]。这些服务已于[日期]完成，交付物已交给[债务人]，
[债务人]已将其用于[具体用途]。
```

**商品销售：**
```
[债权人]已于[日期]交付所订购的货物。货物已由[收货人姓名]、[职务]无保留
接收，随附的已签署送货单为证。[债务人]此后一直在其经营活动中使用这些
货物。
```

**持续服务：**
```
自[日期]至[日期]的整个期间，[债权人]以持续且符合合同约定条款的方式
提供了全部[性质]服务。该履行以[月度报告/介入工单/系统日志]为实证，
表明所提供服务的规律性和质量。
```

### 无争议的定性表述

**标准版本：**
```
值得注意的是，[债务人]从未在任何时候对以下事项提出任何保留或争议：
(i) 债权原则，(ii) 所提供[或：所交付]服务的质量，(iii) 发票金额，
(iv) 履行方式。
```

**带既往付款的版本：**
```
此外，[债务人]无异议地支付了[债权人]开具的前 [X] 笔发票，总额为 [X] 欧元。
这一行为毫不含糊地证明[债务人]承认债权的合理性，且服务履行不存在任何
瑕疵或缺陷。
```

**带使用/利用的版本：**
```
不存在严肃争议的最明显证明在于：[债务人]继续使用[所提供服务/所交付货物/
服务]，从未提出任何异议。此种行为与任何争议的存在均不相容。
```

### 结论表述

**事实部分的结论：**
```
因此，综合全部事实要素，[债权人]已完美履行其合同义务，而[债务人]在
无合法理由、且经多次催告的情况下，拒不支付到期款项。
```

**法律部分的结论：**
```
因此，综合上述全部论述和提交庭审的证据，[债权人]的债权原则确定、
数额明确、期限已届至，且无任何严肃争议可予对抗。[债权人]有权在紧急
审理中获得其付款的判令。
```
