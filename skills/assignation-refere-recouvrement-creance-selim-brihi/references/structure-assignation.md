### 2. 论证（DISCUSSION）

#### 2.1. 主位请求：关于【债务人】未遵守合同义务

##### 2.1.1. 援引适用法律

**法律方面：**

援引《民法典》相关条文：

```
《民法典》第 1101 条规定：

"合同是两人或多人之间旨在设立、变更、转让或消灭
债务的意思表示合意。"

《民法典》第 1103 条规定：

"依法成立的合同对订立合同的当事人具有法律效力。"

《民法典》第 1104 条规定：

"合同的谈判、订立和履行均须秉持善意。
该规定属于强制性规定。"

《民法典》第 1212 条规定：

"合同约定固定期限的，各方当事人必须
履行至期限届满。"
```

**判例（可选但建议）：**

```
判例认为，定期限合同必须履行至
期限届满（最高法院第一民事庭，2001 年 2 月 27 日，第 98-22.346 号）。

在约定期间内，双方当事人因此必须履行合同，各自
承担其应负担的部分。
```

##### 2.1.2. 适用于本案

**本案中：**

**• 关于【债权人】的合同义务**

```
就其自身而言，【债权人】公司的义务是【描述义务：
提供服务/交付货物/提供人员等】。

[简要描述这些义务如何被履行]

为【债务人】提供的服务进行得毫无
困难。

事实上，【债权人】自【日期】起并未疏于
【记录其服务/出具交货单/提供约定的交付物】。

证据【X】号：【证明履行的文件】

正因如此，经【债权人】催告的【债务人】从未对
【债权人】债权的成立或
【债权人】所提供【服务/交付货物】的质量提出任何
异议。

尽管如此，【债务人】仍拒绝支付与【合同/订单】
相关的未付发票余额。

因此，应当指出【债权人】已完美履行其
合同义务，如今没有任何事项可被有效归咎于其。

【债务人】方面不存在任何异议或批评，更广泛而言，
鉴于所提供的服务 [或：所交付的货物]，
如有必要证明，这正是后者的满意证明。

因此，【债权人】已完美履行其合同义务。
```

**• 关于【债务人】的义务**

```
作为对价，【债务人】的义务是支付【合同/订单/销售一般条款】
中约定的报酬。

该债权显然成立，鉴于：

- 【债务人】签署的【日期】合同 [或：被接受的订单]；
- 依据合同 [或：按约定费率] 开具的发票；
- 客户总账。

毋庸置疑，【债务人】已作出坚定且不可撤销的承诺
支付【债权人】的发票，【对首批发票的已付部分款项/
对条款的接受】即为证明。
```

**如约定违约金条款或合同逾期利息：**

```
未付发票【仅涉及/涉及】【债权人】所提供服务的报酬，
【不包括/包括】逾期付款的违约金【超过合同约定到期日后 X 天】。
```

**阶段性结论：**

```
因此，对【债权人】金额为【金额】欧元（含税）的
债权余额的概然性，不存在任何争议。

显然，【债务人】没有任何理由可用来争议
【债权人】的债权。

【债务人】未能充分履行其合同约定的
付款义务，且其从未提出过
任何异议，故其存在过错。

无论如何，【债务人】方面不存在任何异议或批评，
更广泛而言，鉴于已完成的服务 [或：所交付的货物]，
如有必要证明，这正是后者的满意证明。

因此，【债务人】在没有任何理由或正当理由的情况下
违反了其合同义务。
```

#### 2.2. 关于【债权人】付款请求的成立

**引言：**

```
既然【债权人】已履行其合同义务，其债权即应被视为
金额确定、确定存在、已到期且无可争议。因此，
在债务人未主动清偿的情况下，其有权
通过司法途径主张该债权，而债务人不得援引任何
不履行抗辩。
```

##### 2.2.1. 一项确定、金额明确且已到期的债权

**法律方面：**

```
要构成债权，必须证明其符合三项条件，
即确定性、金额明确性和到期性。
```

**❖ 一项确定的债权**

```
就债权的确定性而言，这意味着其不容
置疑。该要求意味着债权必须具有现实的
且无可争议的存在。因此，这涉及债权的实体性：已
提供货物或服务，作为对价，有权
期待获得约定价款。

该要求对合同债权具有充分重要性。
事实上，如果一份合同在意思表示交换
并不完整的情况下订立（《民法典》第 1128 条的条件），各方当事人将
有权请求撤销其承诺，该债权即不再
具有确定性。

最后，无论债权的性质如何（法定、合同、
准合同、侵权或准侵权），均由债权人
证明其主张的债权的确定性。

债权的确定性在判例中无可争议
（最高法院第一民事庭，1966 年 5 月 3 日，D. 1966. 649，J. Mazeaud 注释。——最高法院商事庭，1988 年
6 月 14 日，第 86-15.640 号——最高法院商事庭，2013 年 3 月 26 日，第 12-12.204 号）。
```

**❖ 一项金额明确的债权**

```
其次，就债权的金额明确性而言，其必须以金钱
估量。该要求意味着债权金额必须能够
以具有法定清偿力的货币计价（里昂商事法院，1951 年 9 月 21 日，D. 1952.
26，H. L. 注释——凡尔赛上诉法院，2004 年 10 月 14 日，第 2003-02593 号）。
```

**❖ 一项已到期的债权**

```
最后，债权不得附有延缓期限。该要求
意味着债权相对于约定的付款日期必须已经到期
（参见《商法典》第 L. 441-3 条）。

只有在约定的付款日期过后而未获遵守，
债权人才能要求适用双方商定的约定条款，
特别是关于逾期利息计算、违约金条款，
甚至所有权保留条款的特定合同条款或
销售一般条款等。

无论如何，债权人不得
对附期限的债权（除非已达成丧失期限利益的约定条款），
或履行附有条件成就停止条件的债权进行追偿。

判例在此问题上立场一致（最高法院商事庭，1992 年 1 月 7 日，第 89-20.968 号。——
凡尔赛上诉法院，2004 年 10 月 14 日，见前引。——凡尔赛
上诉法院，2000 年 6 月 15 日，第 1998-8574 号）。

此外，最高法院认为，要求支付未付发票的
服务提供者必须证明相关服务确实被
订购，而且已经完成（最高法院商事庭，2021 年 3 月 10 日，
第 19-14888 号）。
```

**本案中：**

```
【债权人】的债权具备上述 3 项特征。
```

**❖ 一项确定的债权**

```
就债权的确定性而言，鉴于【债权人】已完成
服务 [或：货物已交付]，依据【合同/订单】、
【其补充协议】、【债权人】的【活动报告/交货单/证明】，
以及向【债务人】开具的发票，该确定性已经确立。

因此，【债权人】的债权是确定的、不容争议的。
```

**❖ 一项金额明确的债权**

```
就金额明确性而言，本案系以欧元
计价的发票。因此，该特征不构成困难。
```

**❖ 一项已到期的债权**

```
就到期性而言，只要债权对应双方明示
接受的合同条款，规定依【合同/销售一般条款】于
【X 天内/按约定条件】付款，该债权即完全
到期。

此外，服务已全部完成 [或：货物已
```

```
徒劳地试图逃避其合同义务。《民法典》第
```

#### 2.3. 关于不存在实质性争议

**【非常重要的章节——必须包含】**

```
法律方面，《民事诉讼法典》第 873 条第 2 款规定：

"在义务的存在不容严重置疑的情况下，
[商事法院院长] 可以向债权人授予临时款项，
或命令履行义务，即使该义务属于作为义务。"

最高法院一贯裁判认为，在紧急程序中，法官
只有在认定不存在实质性争议时才能判令
支付金钱款项（最高法院商事庭，2015 年 10 月 13 日，第 14-18.227 号）。

实质性争议是指建立在明确且可信的事实或法律
要素之上的争议，而非单纯的指控（最高法院
第二民事庭，2019 年 10 月 17 日，第 18-20.306 号）。

本案中，【债权人】的债权不存在任何实质性争议：

- 【债务人】从未争议债权的成立；
- 【债务人】从未对发票提出保留；
- 【债务人】从未提及任何施工质量瑕疵 [或：货物不符
  合约定/履行瑕疵]；
- 【债务人】从未援引任何不履行抗辩；
- 【债务人】【无保留地接受了服务/无异议地签收了货物/使用了所提供的服务】。

[如有部分付款：]
此外，【债务人】已对部分发票进行了部分支付，
从而默示承认债权的成立且不存在任何
瑕疵或缺陷。

因此，在不存在任何实质性争议的情况下，【债权人】完全
有权在紧急程序中获得对【债务人】支付其债权的判令。
```
