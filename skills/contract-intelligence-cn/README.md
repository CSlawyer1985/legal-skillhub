# 合同智审（SkillHub下载版）

面向中国民商事合同审核与Word原文留痕修改的可执行Skill。下载后保留目录结构，即可读取专业规则、运行文档执行器并复现公开示例。

## 安装

解压后，将整个 `contract-intelligence-cn/` 目录放入Hermes当前配置的skills目录，重新加载技能；也可将该目录提交至受支持的Skill仓库后通过Hub安装。

最低环境与平台兼容说明见 `references/installation-compatibility.md`。

## 快速验证

在技能目录中运行：

```bash
python scripts/run_demo.py
python scripts/run_tests.py
```

通过标准：两个命令均退出0；红线版存在红色修改，清洁版无红色残留，两版正文一致，负向测试能够失败。

## 主要能力

- 按特定当事人立场审查中国民商事合同；
- 建立请求—抗辩—再抗辩链条；
- 将审核意见转化为可直接执行的条款；
- 基于唯一原文锚点生成红线版和待签署清洁版；
- 检查金额、日期、旧条款残留、颜色及双版本一致性；
- 对DOCX转PDF后执行页数检查，并要求律师完成视觉复核；
- 设置客户保密、脱敏、上传授权及数据生命周期规则。

## 目录

- `SKILL.md`：核心工作流；
- `references/`：审查矩阵、Word留痕指南、安全及兼容说明；
- `templates/`：审核意见与法律依据核验模板；
- `scripts/`：通用执行器、Demo和测试；
- `examples/`：全部为虚构数据的可复现示例。

## 边界

本Skill辅助法律专业人员工作，不替代律师独立判断。法律依据须核实现行有效性；不得未经授权上传真实客户材料；清洁稿不得误称已签署版。
