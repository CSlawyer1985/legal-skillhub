# 国家法律法规数据库（flk.npc.gov.cn）使用说明（2026-07-15 重测修订）

> 本文件为「律典·法律检索」的按需加载参考资料。

## 一、定位
国家法律法规数据库是全国人大常委会办公厅官方库，权威性最高。**本技能所有法条输出必附其跳转链接**（满足全局"凡含法条必附 flk 链接"规则）。flk 在本技能中的角色 = **必附的权威跳转入口**（用户浏览器打开可看官方有效性标签与公报/ WPS 原版），而非 AI 侧的全文/元信息拉取源。

## 二、实测结论（2026-07-15 重测，重要）
- ❌ **旧方法已失效（勿用）**：`search`(web) 搜不到 flk 的 `detail?id=` 链接（SPA 不被搜索引擎索引），且 flk detail 页的法条正文与元信息均为 JS 动态加载，AI 侧 `fetch` 只能拿到空壳 HTML，拿不到任何内容。
- ✅ **正确方法**：调用 flk 后端检索 API（见第三节）。返回 JSON 中每条法规带 `bbbs`（即 detail id），据此构造 detail 链接。
- ⚠️ **flk 元信息不可靠**：`search/list` 返回的 `sxx`（时效性码）、`sxrq`（施行日期）等字段不准（实测《劳动合同法》2012 修正版现行有效却 `sxx=3`、部分法规 `sxrq=null`）。**AI 不得仅凭 `sxx`/`sxrq` 下有效性结论**。
- ⚠️ **flk 收录范围**：以法律、行政法规、地方性法规、司法解释为主；部门规章可能未独立收录（如《企业职工带薪年休假实施办法》人社部令 1 号），此时以国家规章库/部委公报为准并注明"flk 未收录"。
- ⚠️ **total 字段不稳**：搜索返回的 `total` 可能虚高（实测同一词多次返回 3545/146 等差异），须遍历结果页、过滤 `title`（去 `<em>` 高亮标签后）精确匹配目标法规名，再取 `bbbs`。

## 三、正确检索流程（shell 执行）
flk 后端接口：`POST https://flk.npc.gov.cn/law-search/search/list`

请求体（JSON，**关键词字段是 `searchContent`，不是 `key`** —— 用错字段会退化为返回全库）：
```json
{
  "searchContent": "法规全称，如 职工带薪年休假条例",
  "searchRange": 1,
  "sxrq": [],
  "gbrq": [],
  "sxx": [],
  "searchType": 1,
  "page": 1,
  "pageSize": 10,
  "sortType": 1
}
```
- `searchType=1`：标题搜索（优先，匹配更准）；`searchType=2`：全文搜索（更宽泛）。
- 返回 `rows[]` 中关键字段：
  - `bbbs`：**detail id**，构造链接 `https://flk.npc.gov.cn/detail?id={bbbs}`
  - `title`：含 `<em class='highlight'>…</em>` HTML 高亮，需去标签后比对
  - `gbrq`/`sxrq`/`sxx`/`zdjgName`/`flxz`：辅助元信息（**仅供参考，有效性不以 `sxx` 为准**）

可直接执行（**唯一入口，禁手写请求**）：

```bash
python3 scripts/flk_search.py --name "中华人民共和国行政处罚法"
python3 scripts/flk_search.py --name "工伤保险条例" --name "劳动合同法"        # 多法规
python3 scripts/flk_search.py --name "养犬" --fulltext --pages 5            # 全文搜索（默认 3 页）
```

- **统一参数（P3-1 修订）**：`flk_search.py` 默认 `pages=3`、`timeout=20`、标题搜索（`searchType=1`）精确匹配优先、过滤 `len(title)<40`；标题搜索第 1 页出现精确匹配即早停（不再空翻页）。**禁止按本文件旧版参数（pages=4/timeout=30/过滤 len<60）手写请求**——与本技能 G2 门禁（铁令「必须调 flk_search.py」）冲突，且两套筛选逻辑可能返回不同条目。
- 脚本输出为「候选直链（有效性未核验）」，并附免责声明；`sxx`/`sxrq` 仅供候选排序，**不得据此判定现行有效**（见第四节）。
- **检索行为增强**：
  - **候选分级**：脚本区分国家层（法律/行政法规）与地方层（省/市地方性法规）命中。检索国家层法规名时若仅命中地方性法规，输出「未检索到国家层面法规」显式警示，**禁止把地方条例当国家条例直链引用**（实测教训：搜「城市房屋拆迁管理条例」7 条全为地方条例，旧版直接取江苏省条例当候选）；
  - **新法替代追踪**：检索词或命中标题命中已被新法取代的旧法规（如《危险化学品安全管理条例》→《危险化学品安全法》2026-05-01 施行；《城市房屋拆迁管理条例》→《国有土地上房屋征收与补偿条例》）时，输出「新法替代警示」，提示改用新法依据、不得沿用旧法处罚幅度；
  - **标题搜索单页化**：第 1 页非空即停（flk pageSize=200 已覆盖单法规全部同名版本/近似条目，翻页仅重复）。实测 flk **拒绝并发连接**（并发即 RST/ConnectionReset），故批量检索保持串行 + 单页化：4 部法规 28s → 约 5s。全文搜索（--fulltext）仍按 --pages 翻页。

## 四、用法要点
1. **取 bbbs 构造链接**：对目标法规名调用 `scripts/flk_search.py`，拿到 `bbbs` 后即得 `https://flk.npc.gov.cn/detail?id={bbbs}`，输出必附。
2. **正文/有效性不依赖 flk**：条文正文用可用 MCP（如 pkulaw `get_article`/`search_article`）拉取；有效性结论以可用 MCP 的时效性标注（如 pkulaw `timeliness`）为准，无可用 MCP 时以政府公报/人大公告为准，flk 链接仅作权威跳转与用户自核。
3. **flk 未收录时**：以对应权威源（部门规章→国家规章库/部委公报）为准 + 注明"flk 未收录该部门规章，建议人工复核"兜底，不得静默。
4. **多结果时过滤**：遍历 `rows`，取 `clean(title)==目标法规名` 的那条，避免误用同名/近似条目（如多地同名"实施办法"）。
5. **条文级深链如实告知（不可省略）**：实测 flk detail 页为 SPA 空壳（AI 侧 `fetch` 仅得约 437B 空 HTML，条文正文与锚点均为 JS 动态加载），**flk 链接只能定位到"该法规整页"，无法深链到具体条文**。输出法条卡时须如实告知，统一话术：

   > **条文定位说明**：国家法律法规数据库链接定位到该法规整页（动态加载、无条文级锚点），请于页面内按条号定位第 X 条核对；AI 侧已按权威原文核验条文内容。

   不得宣称链接可直达条文，也不得省略该说明（防止用户误以为 AI 附了"条文级直达链接"）。

## 五、健壮性（2026-08-17 补强）

- **超时重试**：flk 后端偶发 Timeout（实测同批请求可能部分超时），调用时应**对单条目标法规失败自动重试 2 次**；仍失败再降级。
- **降级兜底**：脚本持续不可达（环境无外网等）时，**禁止输出 `law-search` 检索式 URL（避免用户二次搜索）**，在来源链接处标注「flk 链接待人工补全（于 flk 官网检索该法规名）」；法条原文与有效性结论仍正常输出，flk 链接缺失仅影响跳转自核，**不得静默跳过**。
- **环境依赖提示**：本方案依赖沙箱外网访问 flk.npc.gov.cn；若环境受限，按 SKILL.md **铁律三（最后防线）** 处置（标 `[待核实]` + 转人工 / 人大官网复核），**绝不降级到被禁第三方站点**。
