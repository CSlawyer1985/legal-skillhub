# 现行有效性核验清单与判定标准

> 本文件为「律典·法律检索」的按需加载参考资料。核心价值：用户硬要求"不接受引用过期或已废止法规"，故每次输出法条前必须完成核验。

## 一、核验清单（每次输出法条前必跑）

- [ ] 该法条所属法规的"有效性"状态（有效 / 已修改 / 已废止）
- [ ] 施行日期 vs 当前日期（系统时间见运行环境，输出时以真实当前日为准）
- [ ] 是否已被新法修订或吸收（比对历史沿革）
- [ ] 地方性法规在用户执业地省/市层面是否仍有效
- [ ] 引用最高法批复/答复类文件时，核验文号全文（含「字第 X 号」）与原文——文号年份为立案/收案编号年份，可能与落款日期年份不一致，禁止凭落款日期反推文号年份或省略编号
- [ ] 输出时**强制标注**有效性结论

## 二、状态判定标准

| 状态 | 判定阈值 | 输出标注 |
|------|----------|----------|
| ✅ 现行有效 | 未被废止/修订，且施行日 ≤ 当前日 | `✅ 现行有效` |
| 🟡 已修订 | 有新法替代部分/全部条文，旧条文对应部分失效 | `🟡 已修订（新法：《XX法》YYYY-MM-DD施行）` |
| 🔴 已废止 | 整部或该条已被明文废止 | `🔴 已废止（YYYY-MM-DD废止）` |

## 三、常见陷阱（必查）

1. **整部法有效 ≠ 某条有效**：单条可能被后续单行法修订，须逐条核对。
2. **行政法规被新条例吸收**：旧条例名义存续但实质被替代，应标注"已被《XX条例》吸收"。
3. **地方性法规与上位法冲突**：冲突部分自动无效，须提示"因与《XX法》冲突，该规定相关条款不予适用"。
4. **试行/暂行期满**：标题含"试行""暂行"且期满未转正，视为失效，须核实续期文件。
5. **公布日 ≠ 施行日**：很多法规公布后数月才施行，引用时两个日期都要给。
6. **批复/答复文号年份 ≠ 落款日期年份**：最高法批复/答复类文件（如〔2011〕行他字第100号）的文号年份为立案编号年份（2011），落款日期可能为次年（2012），二者不一致。引用时须回原文核验文号全文（含「字第 X 号」），严禁凭落款日期反推年份或省略编号。

## 四、交叉核验流程

1. 用可用 MCP（如 pkulaw）拉取法规元信息（有效性/施行日期/历史沿革）；无可用 MCP 时改以政府公报/人大公告核验。
2. 通过 flk 后端 API（见 `references/flk-guide.md`：`POST /law-search/search/list`，关键词字段 `searchContent`，取返回 `bbbs` 构造 `https://flk.npc.gov.cn/detail?id=...`）获取官方 detail 链接；⚠️ flk 返回的 `sxx`/`sxrq` 元信息不可靠，**有效性结论以可用 MCP 的时效性标注（如 pkulaw `timeliness`）为准，无可用 MCP 时以政府公报/人大公告为准**，flk 链接仅作权威跳转与用户自核。
3. 两源不一致时，**以政府公报/人大公告（官方原文）为准**并在输出中提示差异。
4. 无法取得 flk 元信息时，至少标注"有效性以可用 MCP 标注为准（无可用 MCP 时以政府公报/人大公告为准），建议用户于 flk 复核"，不得静默输出。
