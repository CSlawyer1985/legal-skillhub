# 常用法规索引（common-laws）

> **用途**：律典的"高频法规快捷索引"。出法条卡时优先查本表，秒调 flk 精确 id + 北大法宝检索词，避免每次现搜赌搜索引擎给不给 detail 链接，并锁死"现行有效版本"防拿错。
>
> **分区原则**：按执业领域分区固化。行政法 / 劳动法 等多领域并存，互不干扰、可插拔。
> - 发布到广场时：通用核心（检索逻辑+双链接+有效性核验）必带；**个人/执业领域分区**可作为"可选示范层"，私人高频内容留本地不强制发布。
>
> **维护铁律**：法规修订/废止须同步更新 flk id 与版本标注（本 skill 核心价值 = 不引过期法规）。每部法记录：现行有效版本、flk 精确 detail id（点开可查阅/下载 WPS 版、公报原版）、北大法宝检索词、关键条。

  - flk 精确链接（可查阅/下载）：https://flk.npc.gov.cn/detail?id=2c909fdd678bf17901678bf72f7a0613

## 三、劳动法（高频：劳动报酬 / 年休假 / 劳动合同）

  - flk 精确链接：https://flk.npc.gov.cn/detail?id=ff8080816f3e98bd016f420b9b460371 （已验证 bbbs）

- **企业职工带薪年休假实施办法（人社部令1号，2008-09-18 施行，现行有效）**

## 四、地方规定（jurisdiction 已配置：zhejiang，默认触发浙江层）
> 用户执业地默认浙江省，检索时优先本层（省政策文件库 + 各地市政府网站/政府公报/人大公报 + 浙江司法口径）。

- 浙江省政策文件库入口（省人大/省政府规章/规范性文件）：https://www.zj.gov.cn/col/col1229577560/index.html
- **各地市政府官网 / 政府公报（市层面规范性文件）**：按 jurisdiction 匹配省下辖各地市，以对应市政府官网为准
- **各地市人大常委会法规数据库 / 人大公报（设区的市地方性法规全文权威源）**：以各地市人大官网最新入口为准
- **浙江省人大常委会官网（省级地方性法规）：以浙江人大网最新入口为准**
- **浙江地方司法口径（劳动争议）**：
  - 浙高法民一〔2024〕7号《浙江省高级人民法院民事审判第一庭、浙江省劳动人事争议仲裁院关于审理劳动争议案件若干问题的解答（二）》第十九条：就未休年休假工资报酬发生争议的，仲裁时效及起算点——浙江口径按《劳动争议调解仲裁法》第27条把握，劳动关系终止的应自终止之日起一年内提出（未休年休假工资报酬是否适用"拖欠劳动报酬"特殊时效各地有分歧，以浙江该解答为准）。⚠️ 该解答为司法文件，flk 不收录，以浙江法院/仲裁院发布文本为准。
- 浙江省地方性法规（如《浙江省数字经济促进条例》等）—— 待补 flk id
