# 法规检索信源目录（source-catalog）

本文件列出律典·法律检索的信源体系详细目录。所有信源以"权威、可追溯、现行有效"为原则，各库入口以官网最新发布为准。

**检索总原则**：官方权威库优先 → 按法规类型路由到对应权威源 → MCP 作补充兜底交叉验证。不同信源职能不同，不按单一优先级排序，而按"目标法规类型"路由。

## A. 国家层面权威库（最权威官方数据库）

### 1. 国家法律法规数据库（flk.npc.gov.cn）
- URL：https://flk.npc.gov.cn
- 层级：法律、行政法规、监察法规、司法解释、地方性法规、自治条例和单行条例、经济特区法规
- 角色：国家层面最权威官方库；必附的权威跳转入口
- ⚠️ 实测（2026-07-10）：detail 页法条正文为 JS 动态加载，AI 侧 fetch 只能拿到元信息（有效性/施行日期/制定机关/分类/历史沿革），**拉不到条文全文**；`sxx`/`sxrq` 等元信息字段也不准，**有效性以政府公报/人大公告或可用 MCP 时效性标注为准**
- 检索：调后端 API `POST /law-search/search/list`（关键词字段 `searchContent`，返回 `bbbs`=detail id 用于构造链接），详见 `references/flk-guide.md`；⚠️ 勿用 web 搜索/fetch 方式（SPA 不索引、已实测失效）

### 2. 国家行政法规库
- URL：https://www.gov.cn/zhengce/xxgk/fzfgk/（以官网最新为准）
- 层级：行政法规
- 角色：行政法规权威源

### 3. 国家规章库
- URL：https://www.gov.cn/zhengce/zzhg/（以官网最新为准）
- 层级：部门规章 + 地方政府规章
- 角色：规章检索补充源（国务院办公厅汇编）——**部门规章以部委官网/公报为准（优先），本库作补充检索与多版本对照**；对用户人社/住建/城管执法依据尤为重要

## B. 地方层（jurisdiction 配置后触发）

### 4. 省政策文件库
- URL：浙江省 https://www.zj.gov.cn/col/col1229577560/index.html（已确认稳定入口）；其他省份按 jurisdiction 匹配
- 层级：省级地方性法规、政府规章、规范性文件
- 角色：省级政策权威源

### 5. 各地市政府网站 / 政府公报
- URL：按 jurisdiction 匹配省下辖各地市，以对应市政府官网为准（示例：杭州市 https://www.hangzhou.gov.cn）
- 层级：市/区规范性文件、政府公报
- 角色：**地方政府规章以该地方政府公报为准**；政府公报为地方规范性文件的权威原文源

### 6. 人大公报 / 人大法规库
- 入口：省人大网、各地市人大常委会官网法规数据库及人大公报（以官网最新为准）
- 层级：省 / 设区的市地方性法规
- 角色：**地方性法规以人大公报/人大法规库为准**（设区的市人大通过、省人大批准的条例全文的最权威源）

## C. 部委 / 部门

### 7. 部委官网 / 公报
- 示例：人社部 https://www.mohrss.gov.cn ｜ 住建部 https://www.mohurd.gov.cn ｜ 司法部 https://www.moj.gov.cn
- 层级：部委规章、规范性文件
- 角色：**部门规章权威源（优先于国家规章库），以部委公报/官网正式公布文本为准**；特定领域执法依据

## D. MCP（补充、兜底、交叉验证）

### 8. 已接入的法律检索 MCP（如北大法宝 pkulaw）
- 类型：结构化 API（MCP 工具），非网页；**仅当用户智能体配置了该 MCP 才可用**
- 工具：`get_article`（法条精确查询）、`search_article`（法条语义检索）、`get_law_list`（法规列表）、`search_case` / `get_case_list`（案例）
- 输出：法条全文 + 原文链接 + 元信息；单次上限 10 条
- 角色：① 补充官方库未覆盖的全文（如部分部门规章）② 与官方源交叉验证有效性 ③ 全文拉取辅助；**不可用时不影响主路径（官方权威库）**

## 法规类型 → 权威源 路由表

| 目标法规类型 | 权威源 |
|---|---|
| 法律 | 国家法律法规数据库（flk.npc.gov.cn） |
| 行政法规 | 国家行政法规库 |
| 部门规章 | **部委官网 / 公报（优先）** / 国家规章库（补充） |
| 地方政府规章 | **该地方政府公报** |
| 地方性法规（省/设区的市） | 人大公报 / 人大法规库 |
| 司法解释 | 国家法律法规数据库 / 最高法官网 |

## 排除

- ❌ 第三方法律问答网站（找法网/110ask/华律网/律图等，含其"法规条文转载页"）：无论"问答页"还是"法规全文/条文转载页"，凡域名属上述第三方站点，**一律不得作为法条来源或引用依据**；仅可作线索提示并须注明"源自第三方、未经验证、不作为依据"
