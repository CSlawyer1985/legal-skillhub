# 输出格式完整模板（法条卡 + 合并引用清单）

> 本文件为「律典·法律检索」的按需加载参考资料。
> **输出纪律（强制，唯一维护源）**：① 禁止代码块 ``` 或引用块 > 包裹整张法条卡（渲染灰色、链接不可点）；② 链接必须用 `[库名全称](https://example.com)` 超链接格式，可点击跳转；③ 库名/法规名必须全称（禁止"flk"等简称；法律须带"中华人民共和国"前缀）；④ 单条法条禁表格，多条用「合并引用清单」；**「层级覆盖自检表」仅可置于全部法条卡之后**（validate C2 只查法条卡区域内表格，不拦截自检表）；⑤ 链接优先给国家法律法规数据库直链（可核验有效性），政府官网仅作核对/补充（若附须确认现行版本并标注）；⑥ 地方性法规/政府规章正文无法从权威源直接拉取时，直接给数据库 detail 直链即可（点击跳转界面查看原文/下载），不尝试拉取 PDF/WPS 正文，也不重复标注"无法拉取"——直链即交付。

## 二、多条法条：合并引用清单（不用表格）

当一次检索返回多条相关法条时，用「合并引用清单」逐条列引用格式 + 可点击链接，**禁止用表格**（表格换行难看）：

**合并引用清单**（可直接复制进文书）：

1. 《中华人民共和国行政处罚法》（2021修订）第六十三条——较大数额罚款等决定，当事人要求听证的应当组织听证
   - [国家法律法规数据库](https://flk.npc.gov.cn/detail?id=xxx)
2. 《中华人民共和国行政处罚法》（2021修订）第六十四条——听证程序
   - [国家法律法规数据库](https://flk.npc.gov.cn/detail?id=xxx)

清单后附"合并说明"（如：上述条款共同构成听证制度，适用时注意第六十四条对第六十三条的细化）。

## 三、场景变体

- **精确查询**：直接给单条法条卡。
- **语义检索（模糊主题式）**：**每条命中条款给精简法条卡（原文 + 有效性 + 引用格式 + 可点击链接）**，末尾附合并引用清单供复制——原文供律师先行阅读，链接供核验，缺一不可。
- **法规清单**：给法规列表（名称/制定机关/有效性/可点击链接），不展开条文。
- **地方规范**：法条卡中"地方层提示"必填，注明对应省/市具体规定及"严于国家法部分优先适用"提示。
- **有效性专项核验**：可只输出"有效性结论 + 依据"，省略全文（用户仅问"还有效吗"时）。
- **深度解读**：在法条卡基础上，追加"深度解读"四字段（构成要件/适用范围/例外情形/实务要点）。
- **案例联动**（待启用）：在深度解读基础上，追加"案例联动"三字段（类案/裁判范式/风险提示）。

## 四、层级覆盖自检（模糊 / 主题式问题必附）

|---|---|---|
| 国家层面（法律/行政法规） | ✅ 已检索并命中 / 🟡 未命中 | 《建设工程质量管理条例》第29、30条 |
| 部门规章层 | ✅ / 🟡 | 住建部令57号、建建〔2000〕211号 |
