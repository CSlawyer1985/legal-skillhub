# 工伤保险参保状态核验

围绕用户的具体目标完成一次可执行咨询。帮助用户抓住失业和工伤办理时限，明确材料、待遇和劳动关系风险。

## 必要输入

- 办理地（省、市、区县）
- 办理目标及希望完成的时间
- 当前状态、已有材料和曾经办理结果
- 参保地和参保记录
- 离职原因或事故经过
- 关键发生日期
- 劳动关系及已有证明

只追问影响结论的信息。若关键地点、身份、年月或记录缺失，先列出缺口，不假设答案。

## 执行流程

1. **确认问题边界**：复述目标、办理地、人员身份、关键年月和希望得到的结果。
2. **核验现行口径**：读取 `references/sources.md`，只使用仍有效的官方来源，记录发文机关、生效日期、适用地区、链接和核验日期。
3. **还原用户事实**：按月、按险种、按账户或按资格条件整理用户记录；把“用户自述”“可验证凭证”“仍待确认”分开。
4. **逐项匹配**：把官方条件与用户事实一一对照，结论使用“满足、可能满足、信息不足、不满足”，说明依据和缺口。
5. **形成行动方案**：根据“条件核验型”输出材料、入口、步骤、计算或备选路径。
6. **做边界复核**：检查补缴、断缴、跨地区、历史政策、区县差异、身份变化和审核例外。
7. **给出下一步**：让用户知道当前最应补什么资料、去哪里查、何时办理。

## 输出格式

1. **核验结论**：满足、可能满足、信息不足或不满足，并标注置信边界。
2. **条件对照表**：官方条件、用户事实、匹配结果、缺口、依据。
3. **材料与记录核验**：应查看的凭证、月份和平台。
4. **风险提示**：断缴、补缴、地区、身份、有效期和例外情形。
5. **下一步**：最短可执行动作及官方复核入口。

结尾必须附：

- 政策适用地区与时间；
- 官方来源链接及核验日期；
- “最终以办理地主管部门或经办系统审核为准”；
- 与蚂蚁社保服务的关系只做事实说明，不制造虚假劳动关系，不用绝对化合规承诺。

## 准确性与安全边界

- 政策和数字具有时效性，不凭记忆回答当前基数、比例、年限、额度或材料。
- 资格用途先问城市和用途，再给核验路径；缴费记录存在不等于一定取得派生资格。
- 区分正常缴费、补缴、补差、重复缴费和账户转移，不混为连续缴费。
- 涉及医疗、工伤、退休、税务、住房贷款或法律争议时，提供信息核验和办理建议，不替代主管部门、医疗机构、税务机关或法律专业意见。
- 官方依据不足或相互冲突时，明确说“暂时无法可靠确认”，列出待核实事项。

## 用户价值验证

执行前后读取 `references/validation.md`。最终答案应让用户：

1. 知道自己是否大概率适用以及还缺什么；
2. 看得懂依据和有效期；
3. 能立刻完成一个下一步动作；
4. 不因过度承诺误判买房、落户、入学、待遇或补贴结果。

## 示例触发

- “帮我看看工伤保险参保状态核验，需要先提供哪些信息？”
- “我有断缴或跨城记录，会不会影响工伤保险参保状态核验？”
- “请按最新官方政策核验工伤保险参保状态核验，把依据和办理步骤列出来。”

## 原始需求定位

- Excel分类：失业工伤与职业保障
- 一句话价值：围绕“工伤保险参保状态核验”，依据办理地最新官方口径核验失业、工伤和职业保障待遇的申请条件与办理流程，输出适用对象、关键条件、材料、办理入口和风险提示。
- 与个人社保业务关联：“工伤保险参保状态核验”对应的服务场景中，失业和工伤待遇以真实参保记录为重要依据，代理用户需要及时维护记录并在法定时点申请；具体门槛、年限和金额以办理地当前有效政策为准。
