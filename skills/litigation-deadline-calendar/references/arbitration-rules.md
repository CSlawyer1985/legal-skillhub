# 仲裁规则——期限参考

本参考涵盖 AAA《商事仲裁规则》和 JAMS《综合仲裁规则》，用于期限日历目的。这些规则管辖仲裁程序中的程序性期限。

**与诉讼的关键区别**：仲裁期限由适用的仲裁规则和仲裁员的日程安排命令（scheduling order）驱动，而非民事诉讼法规则。除非仲裁员的命令明确并入，绝不将 CRCP 或 FRCP 的时间计算规则适用于仲裁期限。

**规则版本**：
- AAA《商事仲裁规则》：2022年9月1日生效
- AAA《雇佣仲裁规则》：2025年5月1日更新
- JAMS《综合仲裁规则》：2021年6月1日修订

## AAA 商事仲裁规则 {#aaa-commercial}

### 时间计算
- 除非另有规定，AAA 规则中的期间按**日历日**计算。
- 如期限适逢周末或节假日，一般顺延至下一个工作日（检查具体规则条款）。

### 关键期限

**听讯前阶段**：
- **答辩陈述**：在收到请求书（Demand）提交通知后**14天**内（R-5条）。
- **反请求**：须与答辩陈述一并提交，或在 AAA 或仲裁员设定的时间内提交。
- **仲裁员选定**：当事方通常有**14天**返回仲裁员排序名单。
- **预备听讯**：通常在仲裁员指定后尽快安排；仲裁员将在该听讯中设定案件管理期限。

**证据开示/信息交换**：
- AAA 商事规则不提供像诉讼那样广泛的证据开示权利。信息交换由仲裁员酌情决定（R-22条）。
- 仲裁员可在预备听讯中设定文件交换、证人名单和专家报告的期限。
- **快速程序案件**（请求额低于10万美元）：一般禁止证据开示；仅可在听讯前**2天**交换证物（E-5(a)条）。

**听讯阶段**：
- **听讯日期**：由仲裁员与当事方协商确定。
- **听讯后书状**：如允许，通常在听讯结束后**14-30天**内提交（由仲裁员设定）。

**裁决**：
- **裁决期限**：仲裁员必须在听讯结束后（或收到所有书状/呈文后）**30天**内作出裁决（R-43条）。
- **快速程序案件**：裁决必须在听讯结束后**14天**内作出（E-9条）。

### 大型复杂案件程序（请求额超过100万美元）
- 请求额超过300万美元的适用三人仲裁庭（除非当事方另有约定）。
- 更结构化的预备听讯，附详细日程安排。
- 仲裁员可以允许证言笔录（depositions）和更广泛的文件证据开示。

## AAA 雇佣仲裁规则 {#aaa-employment}

### 关键期限
- **答辩陈述**：在提交通知后**14天**内。
- **证据开示**：比商事规则更宽松；仲裁员可以允许证言笔录和文件请求。
- **裁决**：听讯结束后**30天**内。
- **司法干预的中止**：**90天**（2025年更新）。

### 2025年更新（2025年5月1日生效）
- 默认使用虚拟听讯。
- 扩大仲裁员在传票、证言笔录和制裁方面的权限。
- 仲裁员可以主动修改或澄清裁决。

## JAMS 综合仲裁规则 {#jams-comprehensive}

### 时间计算
- 除非另有规定，所有期间均按**日历日**计算。
- 最后一日适逢非工作日时适用周末/节假日顺延。

### 关键期限

**启动仲裁**：
- **对请求书的答复**：收到请求书后**14天**内（规则9(a)）。
- **反请求**：与答复一并提交，或在仲裁员设定的时间内。
- **仲裁员选定**：JAMS 将提出名单；当事方有**7天**排序和剔除（规则15）。

**预备会议（规则16）**：
- 通常在仲裁员指定后**14天**内举行。
- 仲裁员在该会议上设定所有案件管理期限，包括：
  - 证据开示范围和期限
  - 专家披露期限
  - 听讯前书状期限
  - 听讯日期

**证据开示/信息交换（规则17）**：
- JAMS 赋予仲裁员管理证据开示的广泛裁量权。
- 仲裁员可以允许证言笔录、文件请求和书面质询。
- 范围和期限在预备会议上设定。
- 无约定时，各方有权进行**1次**证言笔录（大型案件为**3次**）。

**听讯**：
- **听讯前书状**：按仲裁员设定的时间提交，通常在听讯前**14-21天**。
- **证物交换**：通常在听讯前**7-14天**。
- **证人名单**：通常在听讯前**7-14天**。

**裁决（规则24）**：
- **终局裁决**：听讯结束后（或收到听讯后书状后）**30天**内。
- **快速程序案件**：按约定或仲裁员设定的更短时间线。

### 快速程序（规则16.1、16.2）
- 当事方约定或请求总额低于25万美元时适用。
- 听讯必须在**1天**内完成。
- 裁决在听讯后**14天**内作出。
- 证据开示有限（通常仅文件交换）。

## JAMS 简化仲裁规则 {#jams-streamlined}

适用于25万美元及以下的请求：
- 简化程序，时间线更短。
- **对请求书的答复**：**14天**。
- **听讯**：通常在**1天**内完成。
- **裁决**：听讯后**14天**内。
- 证据开示有限；主要为文件交换。

---

## 与诉讼的关键区别 {#differences}

| 方面 | 诉讼（CRCP/FRCP） | 仲裁（AAA/JAMS） |
|--------|----------------------|----------------------|
| **证据开示权利** | 广泛的法定权利 | 有限；由仲裁员酌情决定 |
| **答辩期限** | 由规则固定（30-35天） | 由仲裁员在预备听讯设定 |
| **时间计算** | 复杂（CRCP 有"少于11天"规则） | 简单的日历日计算 |
| **专家期限** | 由规则固定（审判前90-126天） | 由仲裁员设定 |
| **处分性动议** | 有权提交 | 允许但可能不中止程序 |
| **裁决/判决时间** | 审判后，无固定期限 | 听讯结束后14-30天 |

### 对本技能的意义
处理仲裁日程安排命令时：
1. **不要**适用 CRCP/FRCP 的倒推计算规则来计算中间期限。
2. **要**按仲裁员日程安排命令中所述的日期提取并加入日历。
3. **要**对日程安排命令未涵盖的任何程序性期限（如听讯后仲裁员的裁决期限）适用仲裁机构的规则（AAA 或 JAMS）。
4. **要**在日程安排命令似乎与仲裁机构规则冲突时予以标注。
5. 仲裁员的日程安排命令是首要权威；仲裁机构规则填补空白。
