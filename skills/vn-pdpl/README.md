# 越南 PDPL 技能

一个面向**越南《个人数据保护法》第 91/2025/QH15 号法律**及其实施细则**第 356/2025/ND-CP 号法令**（2026 年 1 月 1 日生效）的 Claude 技能。

---

## 1. 本技能做什么？

本技能将 Claude 转变为越南首部综合性个人数据保护法的专家顾问。它为在越南运营或处理越南公民个人数据的组织提供合规义务的可操作指引，涵盖：

- 对照 VN-PDPL 和第 356 号法令评估合规差距
- 在法律要求的时间范围内管理数据主体权利请求
- 起草和提交影响评估（DPIA 和跨境传输）
- 撰写符合 PDPL 的隐私通知、同意书和内部政策
- 以 72 小时通知工作流应对个人数据泄露
- 针对金融、AI、云计算、区块链和大数据的行业特定指引
- 评估数据保护官（DPO）任命要求和资格
- 解释中小企业豁免和过渡条款

---

## 2. 目标受众

- **法律和合规团队**，服务于越南公司或拥有越南数据主体的外国公司
- **隐私官和 DPO**，构建或管理 VN-PDPL 合规计划
- **初创企业和中小企业的创始人及高管**，评估其义务和适用豁免
- **技术团队**，构建在越南处理个人数据的产品或服务
- **顾问和律所**，就越南数据隐私为客户提供建议
- **跨国组织**，处理越南公民数据的跨境传输

## 3. 常见用例

1. **差距分析**——“我们是拥有越南用户的新加坡 SaaS 公司。VN-PDPL 要求我们做什么？”
2. **跨境传输**——“我们将越南客户数据存储在新加坡的 AWS 上。需要提交影响评估吗？”
3. **泄露应对**——“我们 48 小时前发现影响越南用户的数据泄露。现在需要做什么？”
4. **同意审查**——“我们当前的同意机制符合 VN-PDPL 吗？我们使用预勾选复选框。”
5. **DPIA**——“我们正在越南推出基于 AI 的信用评分产品。需要什么影响评估？”
6. **数据主体权利**——“一位越南用户要求删除其所有数据。我们如何处理此请求？”
7. **中小企业豁免**——“我们是一家小企业。哪些 VN-PDPL 义务可以推迟 5 年？”
8. **隐私通知起草**——“为我们的电商平台起草符合 VN-PDPL 的隐私通知。”
9. **DPO 任命**——“我们需要数据保护官吗？他们必须有什么资格？”
10. **敏感数据处理**——“我们收集健康数据和财务数据。适用哪些额外义务？”

## 4. 使用方法

### 安装技能

**选项 A——直接安装（推荐）：**

1. 打开 Claude 桌面应用
2. 进入 **设置 → 技能（Settings → Skills）**
3. 点击 **添加技能（Add Skill）** 并上传 `vn-pdpl.skill`

**选项 B——通过 GRC 插件市场：**

1. 打开 Claude 桌面应用
2. 进入 **设置 → 插件（Settings → Plugins）**
3. 搜索“GRC Skills”或“Vietnam PDPL”
4. 安装 `vn-pdpl` 技能

### 示例提示

安装后，尝试如下提示：

- _"对我们的电商业务进行 VN-PDPL 差距分析，该业务从越南客户收集姓名、电子邮件、电话号码和购买历史。"_
- _"我们在远程医疗应用中处理越南患者的健康数据。适用哪些敏感数据义务？"_
- _"起草将越南员工 HR 数据传输到我们位于美国的 Workday 系统的跨境传输影响评估卷宗。"_
- _"一位越南数据主体已请求删除其所有个人数据。带我走一遍履行流程和所需时间线。"_
- _"我们发生了影响 15,000 名越南用户财务数据的泄露。我们需要通知什么、通知谁、何时通知？"_

## 5. 技能实现细节

| 属性                    | 值                                            |
| --------------------------- | ------------------------------------------------ |
| **技能标识符**        | `vn-pdpl`                                        |
| **涵盖的法律**             | 《个人数据保护法》第 91/2025/QH15 号法律 |
| **实施细则**     | 第 356/2025/ND-CP 号法令（2025 年 12 月 31 日）         |
| **生效日期**          | 2026 年 1 月 1 日                                   |
| **主管机关** | 越南公安部           |
| **技能版本**           | 1.6.2                                            |
| **文件**                    | `vn-pdpl.skill`                                  |

**技能中捆绑的参考文件：**

- `references/articles-overview.md` — 关键条款完整分解：定义、数据类别（基本 11 项 / 敏感 13 项）、数据主体权利、同意规则、处理依据、跨境传输、DPIA、泄露通知、处罚和过渡条款
- `references/decree-356-implementation.md` — 第 356 号法令的实施细节：回应时间范围、有效同意方式、行业特定规则（金融/银行、大数据、AI/自动化处理、区块链、云计算）和 DPO 资格

**关键法律事实：**

- 6 项数据主体权利（知情、同意/撤回、访问/更正、删除/限制/反对、投诉、保护）
- 72 小时向公安部通知泄露
- 首次传输后 60 天内提交跨境传输影响评估
- 首次处理后 60 天内提交国内 DPIA
- 中小企业豁免：第 21、22、33(2) 条 5 年，除非处理敏感或大规模数据
- 最高处罚：组织最高 30 亿越南盾；跨境违规为越南收入的 5%；数据买卖为所得的 10 倍
