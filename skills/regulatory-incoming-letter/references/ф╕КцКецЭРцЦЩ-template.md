# 上报材料模板（对外提交监管的整改 / 自查 / 回函）

**对应技能**：`regulatory-incoming-letter`（监管来函处置）第 6 步
**用途**：根据收集到的 `inspection-task` 反馈，自动生成对外上报草稿

本模板覆盖 4 种典型对外提交场景。技能按函件类别选用对应模板生成草稿，**最终由法务总监 + 首席合规官会签后由法定代表人 / 法务联系人签发**。

---

## 模板选择对照

| 函件类别 | 用本模板的 ... 段 |
|---|---|
| 第 1 类 行政处罚 | 模板 D 复议申请书框架（**仅作框架，正文应由律师起草**） |
| 第 2 类 行政监管措施（2a 责令整改） | 模板 A 整改报告 |
| 第 2 类 行政监管措施（2b 现场检查反馈） | 模板 A 整改报告（加检查问题逐项回应） |
| 第 3 类 监管谈话 | 通常**不需要**正式上报；如要求出具承诺函，用模板 B |
| 第 4 类 程序性通知 | 模板 C 听证申请书 / 陈述申辩书框架（**仅作框架**） |
| 第 5 类 专项自查 / 工作函 | 模板 A 自查报告 |
| 第 6 类 监管问询 | 模板 B 问询回函 |

---

## 模板 A：整改 / 自查报告

```markdown
[本公司红头公文模板 —— 如使用]

# [函件名称] 整改报告 / 自查报告

文号：[本公司编号，如有]
致：[来文单位全称]
关于：贵 [局 / 委] 《[函件名称]》（[原文号]）的整改 / 自查情况报告

---

尊敬的 [来文单位]：

[本公司全称] 收到贵 [局 / 委] 于 [收文日期] 下发的《[函件名称]》（[原文号]）以来，
高度重视，立即组织相关部门成立专项工作组，对照贵 [局 / 委] 提出的事项逐项开展
整改 / 自查工作。现将相关工作情况报告如下：

## 一、整改 / 自查工作组组成

按照贵 [局 / 委] 要求，本公司由 [职务，如：分管副总经理] 牵头，成立专项整改 /
自查工作组，成员包括：

- 组长：[姓名]，[职务]
- 成员：[业务部门负责人] / [合规部门负责人] / [法务部门负责人] / [其他相关部门]

工作组于 [日期] 召开首次会议，明确整改 / 自查目标、进度安排和责任分工。

## 二、整改 / 自查事项明细

[对每条 inspection-task 逐项展开]

### 事项 1：[要求事项 1 全文]

**自查 / 整改情况**：

[业务部门反馈内容 —— 由 task_owner 填写，法务核校]

**整改完成度**：[已完成 / 进行中 / 风险接受]

**核心数据**：

- [量化指标 1]：[数值]
- [量化指标 2]：[数值]

**支持材料**：见附件 [X]

---

### 事项 2：[要求事项 2 全文]

...（逐条）

## 三、整体结论

经本次整改 / 自查，本公司发现 / 确认以下情况：

1. **已整改完毕**：[N] 项，详见附件
2. **进行中**：[N] 项，预计 [日期] 前完成，进度详见附件
3. **风险接受**：[N] 项，已经过本公司风险评估 / 合规评审，详细论证见附件

整体而言，本公司在 [相关业务领域] 的合规水平 [评估表述]，针对贵 [局 / 委] 指出
的问题已采取实质性整改措施。

## 四、本公司承诺

针对本次整改 / 自查发现的问题，本公司承诺：

1. **常态化合规检查**：将本次自查事项纳入本公司内控制度，开展常态化合规检查
2. **责任落实**：对相关业务部门的合规职责进行细化，明确责任人
3. **持续改进**：根据本次工作发现，对相关流程 / 制度进行优化
4. **配合后续监管**：如贵 [局 / 委] 后续有进一步要求或检查，本公司将全面配合

[根据具体函件要求，可增加更具体的承诺，如"X 月 X 日前提交 [某材料]"]

## 五、联系方式

如贵 [局 / 委] 对本报告内容需要进一步说明或补充材料，请联系本公司：

- 联系人：[姓名]，[职务]
- 电话：[电话]
- 邮箱：[邮箱]
- 通讯地址：[地址]

特此报告。

---

附件：

1. 附件 1：[支持材料 1，如自查表 / 整改证据]
2. 附件 2：[支持材料 2]
3. 附件 3：[支持材料 3]

---

公司公章：[公章位置]

法定代表人 / 签发人：[签字]

日期：[日期]
```

## 模板 B：问询回函

```markdown
# [函件名称] 回函

文号：[本公司编号]
致：[来文单位全称]
关于：贵 [局 / 委 / 所] 《[函件名称]》（[原文号]）的回函

---

尊敬的 [来文单位]：

[本公司全称] 收到贵 [局 / 委 / 所] 于 [收文日期] 下发的《[函件名称]》（[原文号]）。
对贵 [局 / 委 / 所] 关注的事项，本公司逐项回应如下：

## 问题 1：[问询事项 1 全文]

**回应**：

[本公司就该事项的具体说明 —— 按 task_owner 提供的资料整理，**仅限问询范围内**]

**支持材料**：[列举支持本回应的文件 / 数据]

---

## 问题 2：[问询事项 2 全文]

...（逐条）

---

如贵 [局 / 委 / 所] 需要进一步说明或补充材料，请与本公司联系：

- 联系人：[姓名]
- 电话：[电话]
- 邮箱：[邮箱]

特此回函。

---

附件：

1. ...

公司公章：[位置]
签发人：[签字]
日期：[日期]
```

**关键提示**：

- **不超出问询范围**：仅回应问询函中列出的事项，**不主动**披露其他事项
- **数据脱敏**：涉及具体客户的，用编号 / 类别替代
- **避免与历史立场矛盾**：回函前应检查本公司就该事项的历史表态

[简述被告知事实]

（二）关于法律适用

1. 受理本听证申请

申请人：[本公司全称]（公章）

日期：[日期]

代理人（如有）：
- 姓名：[律师姓名]
- 律师事务所：[所名]
- 联系电话：[电话]
- 律师证号：[证号]

## 上报材料的会签流程

任何上报材料**必须**走完以下流程才能对外提交：

1. **起草**：`regulatory-incoming-letter`（监管来函处置）技能按本模板生成草稿 + 各 `task_owner` 反馈填充
2. **法务初审**：法务负责人（首道审核，按 `escalation_path.首道审核`）
3. **法务总监审定**：实质内容审定 + 法律风险评估
4. **首席合规官复审**：合规视角审定
5. **总经理 / 法定代表人签发**：用印 + 签字
6. **法务联系人 / 综合管理部对外提交**

按 `escalation_path` 配置的具体角色 + 流程时间，技能在第 6 步自动触发逐级审签。

## 提交方式与回执

按函件指定的提交方式：

| 方式 | 注意 |
|---|---|
| 密码邮件 | 按函件指定邮箱发送；保留发件记录 + 已读回执 |
| 监管平台提交 | 按监管平台指引上传；保留提交编号 / 回执号 |
| 现场提交 | 派人送达 + 拿监管单位**收文回执** |
| 挂号信 | 保留邮戳 / 寄送回执 + 跟踪号 |

无论何种方式，**提交后立即**在 `letter.yaml` 中记录：

```yaml
submission:
  date: 2026-06-22
  method: 密码邮件
  recipient: xxx@xxx.gov.cn
  receipt_id: REC-XXXX                  # 如有回执号
  receipt_file: receipt-2026-06-22.pdf  # 回执文件路径
```
