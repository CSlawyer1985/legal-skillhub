# 小红书法律博主内容风格指南

## 定位

- **赛道：** 法律科普（劳动合同、实习协议、三方协议、租房合同等）
- **受众：** 应届生、职场新人、大学生、打工人
- **内容形式：** 纯图文笔记，"合同截图 + 红字手写批注 + 说明文案"
- **调性：** 收藏型自查清单，实用导向，不说教，不恐吓。标题不用"千万别签"，而用"先查这X项"

## 图文结构模板

每条笔记结构：

| 位置 | 内容 | 格式要求 |
|------|------|---------|
| 封面 | 合同封面做底图，大字标题，红色横线或圈注强调关键词 | 手写风格字体 |
| 第2页 | X步自查总清单列表 | 大字标题 + 9项关键词列表 |
| 第3-N页 | 每页聚焦1个检查点 | 大字标题 + 3-6条红字批注 + 补充小字说明 |
| 最后一页 | 签字页提醒 | 盖章、日期、留存提醒 |
| 正文文案 | 问题导入 → 清单式说明 → 评论区引导 → 免责声明 | 不超过300字精简版 |

## 标题风格

- 疑问句式："应届生签劳动合同前，先查这9项"
- 反常识式："还没毕业去实习？三方协议先查这8项"
- 清单式："法律博主提醒：第一份劳动合同别只看工资"

🔴 避免：恐吓型标题（"千万别签""被骗了"）

## 文案写作规范

### 开头（Hook）
1-2句话切入痛点，不说废话。用具体场景而非抽象道理。

❌ "在当今就业形势下，应届生面临诸多挑战..."
✅ "应届生签第一份劳动合同，真的不要只看'工资多少'。"

### 主体（Body）
清单式罗列，每条1-2句话讲清要点，不用法条原文，用"你"直接对话。

格式：
```
签之前重点看这8项：

① 三方是谁
甲方一般是学校，乙方是实习单位，丙方是学生本人。信息别空着。

② 实习时间
开始日期、结束日期、实习几个月，都要写清楚。

...
```

### 结尾（CTA/评论区引导）
选择题式引导 > 开放式提问。给出明确的字母选项或关键词提示。

示例：
"评论区可以留你最看不懂的关键词：实习补助、保险谁买、中介收费、学校强制实习..."

或：
"你们合同里最看不懂的是哪一项？A.试用期 B.违约金 C.发薪日 D.社保 E.竞业限制。评论区留字母，我整理下一篇。"

### 置顶评论
必须包含：隐私提醒（打码）+ 关键词引导 + 免责声明
格式固定："大家不要直接发完整合同截图！涉及公司名称、姓名、身份证号...一定要打码。可以只说关键词...具体个案要结合完整材料判断，本篇只做通用自查参考。"

### Hashtag
3-5个核心tag，覆盖赛道标签 + 受众标签 + 形式标签
示例：`#应届生 #劳动合同 #职场新人 #法律博主 #打工人`

## 批注文案规范

### 红字批注（每页3-6条）
- 每条约10-15字
- 动词开头，祈使句
- 手写口语感，不用法言法语

示例：
✅ "公司全称要写清楚"
✅ "看到'服从安排'要问清楚"
❌ "根据《劳动合同法》第十七条，工作地点应明确约定"

### 补充小字（1段）
- 50-80字
- 解释"为什么这个检查点重要"
- 从用户视角出发，不是从法条视角

示例：
"很多同学签实习协议时只看'能不能盖章''能不能拿实习证明'，但真正要先看的是：你到底去哪个单位、哪个部门、哪个岗位、实习多久。"

## 法律红线

1. 不做个案法律咨询（"发合同我帮你看"不可）
2. 不用绝对化表述（"一定""肯定""包赢"等）
3. 不制造对立（不渲染"公司都在坑你"）
4. 必须附免责声明（"本篇只做通用自查参考，具体纠纷请结合完整材料判断"）

## 选题优先级

按数据潜力：
1. 签约场景（劳动合同、租房合同、三方协议、offer） — 面向受众最大
2. 离职场景（竞业限制、离职证明、赔偿金） — 焦虑驱动
3. 维权场景（工资条扣款、试用期辞退、社保不交） — 愤怒驱动
4. 职场规则（加班费、年假、工伤） — 收藏驱动

## 封面图设计要求

- 合同/协议封面做底图
- 大字标题居中，红色手写体
- 红色横线/圈注标记关键区域
- 小字标注"法律博主整理"
- 红字批注一句话钩子
