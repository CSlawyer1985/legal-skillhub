# 监管信息源目录（source-catalog）

本文件提供 `regulatory-reg-feed-watcher`（监管动态监测）的整理过的信息源目录，按类别组织。**用于覆盖核查与建议补源**，不是必须接入的全集。

**注**：当前为 v1 框架版。详细的源 URL、API 端点、聚合服务清单将在阶段 2 与团队对齐元典开放平台覆盖范围后逐步完善。可通过 `regulatory-cold-start-interview --redo` 让用户根据实际工作中遇到的具体监管 / 协会补充。

---

## 1. 中央层级一手出处

### 立法 / 法规

| 源 | 类型 | URL | 说明 |
|---|---|---|---|
| 国家法律法规数据库 | 公开 web | flk.npc.gov.cn | 全国人大及其常委会立法、行政法规、地方性法规等一手数据库；标签 `[国家法律法规数据库]` |
| 国务院政策文件库 / 中国政府网 | 公开 web | gov.cn | 国务院政策、规范性文件、新闻、答记者问；标签 `[政府网/政策文件库]` |

### 部委公开栏目

| 部委 | 监管覆盖 | 备注 |
|---|---|---|
| 中国人民银行 | 支付、跨境、人民币、金融市场 | 需搜索确认当前"政策法规"栏目页 URL |
| 国家金融监督管理总局 | 银行、保险、消金、信托 | 官网多为 SPA，优先用元典 MCP；如需直抓需搜索确认当前栏目入口 |
| 中国证监会 | 证券、基金、上市公司 | 子页面改版频繁，需搜索确认当前"监管措施"入口 |
| 国家网信办 | 数据、个人信息、网络安全、算法、生成式 AI | 需搜索确认当前"通知公告"或"执法监督"栏目页 URL |
| 国家市场监督管理总局 | 反垄断、广告、消费者权益、产品质量 | 需搜索确认当前"法规"或"处罚公示"栏目页 URL |
| 工业和信息化部 | 通信、电子、APP 治理、工业 | 旧子页面路径多失效，需搜索确认当前有效入口 |
| 国家药品监督管理局 | 药品、医疗器械、化妆品 | 需搜索确认 |
| 生态环境部 | 环保、碳排放 | 需搜索确认 |
| 人力资源和社会保障部 | 劳动、社保、人事 | 需搜索确认 |
| 国家发改委 | 价格、规划、新兴产业 | 需搜索确认 |
| 国家税务总局 | 税收、税务行政处罚 | 需搜索确认 |

**重要**：上表**不含**可直接使用的 URL。所有部委栏目页 URL 必须在 cold-start 时通过 `WebSearch` + `browser_navigate` 验证当前有效性后才能登记到 profile.md。禁止硬编码或照搬历史 URL。

## 使用说明

reg-feed-watcher 在 Step 0 覆盖核查中参考本目录，发现用户关注清单中某类别配置稀薄时呈现建议。本目录**不是**自动接入的清单 —— 接入需要用户在 cold-start 中确认。

阶段 2 与元典开放平台对齐 API 覆盖范围后，本目录中部分条目可标注"通过元典集成已覆盖" / "需要通过元典集成接入" / "公开 web 源直抓"等接入路径。
