# 财税风控差异化技能矩阵（人读版）

> 本文件与 `skill-matrix.json` 配套，说明三个财税技能如何「差异化定位 + 动态关联 + 智能推荐」。
> 三者**共享同一云端财税知识库 MCP 服务**，不重复建设知识库。

---

## 一、三个技能的定位（为什么差异化）

| 技能 | 视角粒度 | 核心价值 | 调用云端知识库 |
|------|----------|----------|----------------|
| 🧾 **发票经济风险管控** (本技能) | 微观·发票/交易级 | 15 项发票专项指标，逐张发票 + 买卖方关系扫描 | ✅ 命中指标自动补强政策依据 |
| 🏢 **财税风险扫描与合规处理** | 中观·企业/报表级 | 14 条企业级规则，问卷/文件式体检（增值税/所得税/个税/优惠） | ❌ 本地规则库 |
| 📚 **财税政策知识库 MCP版** | 宏观·政策/税率级 | 全税费种政策问答、税额计算、风险预警，云端知识库本体 | ✅ 本体 |

**不重复开发**：发票风控与政策知识库都连同一个云端 MCP 服务（`tax-policy-knowledge`）。
发票风控复用政策知识库已注册的 API Key，无需各自建库。

---

## 二、动态关联（相互怎么推荐）

```
        ┌─────────────────────────────┐
        │   用户提出财税/发票问题       │
        └──────────────┬──────────────┘
                       │ 智能路由（按关键词/意图）
          ┌────────────┼────────────────────┐
          ▼            ▼                     ▼
   ① 发票专项     ② 企业体检          ③ 政策溯源
  发票经济风控   财税风险扫描         财税政策知识库
        │            │                     │
        │ ──推荐──▶  │ ──推荐──▶           │
        │            │                     │
        └────────────┴──── 命中后溯源 ──────┘
```

**典型联动场景**
1. **发票扫描命中 → 溯源政策**：发票经济风控命中「顶格开票/税负率预警」，自动调用云端知识库补强政策依据；并推荐「财税风险扫描」做企业级体检。
2. **企业体检发现发票风险 → 下钻**：财税风险扫描提示发票类风险，推荐「发票经济风险管控」对发票明细做 15 项指标扫描。
3. **问政策 → 落到风险**：财税政策知识库查到某条款，推荐「发票经济风控」或「财税风险扫描」把结论落到具体风险体检。

## 四、引导顺序（复合问题时）

> 微观发票扫描 → 中观企业体检 → 宏观政策溯源

先用发票经济风控定位**具体**风险，再用财税风险扫描做**整体**体检，最后由财税政策知识库给出**政策依据**。三层闭环，互不重复、相互补强。
