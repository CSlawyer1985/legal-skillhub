### 1.3 专利延续时间可行性评估

```
距离核心专利到期时间 = 核心专利到期日 - 当前日期

策略选择判断：
- 距到期 > 5年 → 新适应症、新制剂、新联合用药均可考虑
- 距到期 3-5年 → 新晶型、新制剂、新给药方案
- 距到期 1-3年 → 仅新晶型、新给药方案（如已有研发基础）
- 距到期 < 1年 → 专利延续策略基本不可行，转向品牌防御/AU策略
```

## 二、独占权获取路径

### 2.1 美国市场独占权体系

| 独占权类型 | 法定依据 | 保护期 | 获取条件 | 可叠加性 |
|-----------|---------|-------|---------|---------|
| NCE（新化学实体） | FD&C Act §505(c)(3)(E) | 5年 | 首次获批的全新活性成分 | 可与PTE叠加 |
| NCE-1（新临床调查） | FD&C Act §505(c)(3)(E)(ii) | 3年 | 需新的临床研究支持获批 | — |
| PTE（专利期延长） | 35 U.S.C. §156 | 最长5年 | FDA审批导致的专利期损失 | 与其他独占权叠加 |
| 孤儿药独占期 | Orphan Drug Act | 7年 | 用于罕见病（<20万患者） | 不与同类叠加 |
| 儿科独占期（PED） | FDA BA/PED Rule | 6个月 | 完成FDA要求的儿科研究 | 与所有其他独占权叠加 |
| GLP-1 专属 | FD&C Act §505A | 1年 | 首次获批的GLP-1受体激动剂 | — |
| QIDP（合格传染病产品） | GAIN Act | 5年附加 | 用于严重/威胁生命的感染 | 与其他叠加 |

### 2.2 欧盟市场独占权体系

| 独占权类型 | 保护期 | 获取条件 | 备注 |
|-----------|-------|---------|------|
| SPC（补充保护证书） | 最长5年 | EMA审批导致的专利期损失 | 总保护期≤15年 |
| PUMA（儿科使用上市许可） | 1年 | 完成儿科研究计划（PIP） | 可与SPC叠加 |
| 孤儿药独占期 | 10年 | 用于罕见病（<5/10000患病率） | 可缩短至6年 |
| 数据独占期 | 8+2+1年 | 新化学实体（10年）+仿制药挑战（8+2年） | 仿制药企业数据独占2年 |

### 2.3 中国市场独占权体系

| 独占权类型 | 保护期 | 获取条件 | 法规依据 |
|-----------|-------|---------|---------|
| 数据独占期 | 6年 | 首次在中国获批的创新药 | 《药品注册管理办法》 |
| 市场独占期 | 不超过首次上市至获批日期 | 首个儿童专用药 | 《药品注册管理办法》 |
| 专利链接等待期 | 9个月 | 专利纠纷期 | 《药品专利纠纷早期解决机制》 |

### 2.4 独占权叠加策略

最大化保护期的独占权叠加示例（美国市场）：

```
核心化合物专利到期日：2028年12月31日
+
PTE延长：+36个月 → 2032年6月30日
+
PED（儿科独占期）：+6个月 → 2032年12月31日
+
孤儿药独占期（如适用）：+7年（从获批日起独立计算）

累计额外保护：42个月（PTE + PED）
```

## 三、品牌药-to-OTC 转换策略

### 3.1 OTC 转换适用性评估标准

| 评估维度 | 适用条件 | 不适用条件 |
|---------|---------|-----------|
| 适应症 | 常见轻症（疼痛、过敏、消化不良等） | 严重/危及生命疾病 |
| 安全性 | 长期使用安全性良好，无严重不良反应 | 有严重副作用/黑框警告 |
| 用药复杂性 | 简单剂量方案，患者可自主判断 | 需要监测/剂量调整 |
| 患者能力 | 一般患者可正确自我诊断与用药 | 需要专业判断 |

### 3.2 OTC 转换时间线参考

| 阶段 | 活动 | 典型周期 |
|------|------|---------|
| 市场评估 | 评估OTC市场潜力与竞争格局 | 3-6个月 |
| 法规准备 | 准备OTC转换申请材料 | 6-12个月 |
| 审评审批 | FDA/监管机构审评 | 12-18个月 |
| 品牌过渡 | 品牌从处方药转向OTC定位 | 6-12个月 |
| 市场推广 | OTC渠道建设与消费者营销 | 持续 |

## 四、专利悬崖应对策略组合矩阵

| 悬崖风险等级 | 推荐策略组合 |
|------------|------------|
| 🔴 极高 | AU（核心策略）+ 品牌防御 + 专利延续 + 集采应对 + 组织精简 |
| 🟠 高 | AU（重要策略）+ 品牌防御 + 专利延续 + 集采评估 |
| 🟡 中 | 品牌防御（核心策略）+ AU（备选）+ 专利延续评估 |
| 🟢 低 | 品牌防御为主 + 监测仿制药动态 + 预案准备 |
