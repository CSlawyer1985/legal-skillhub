# 专利悬崖风险评估方法论

## 一、专利到期时间线分析

### 1.1 核心专利分类体系

专利悬崖分析需覆盖以下十大专利类型：

| 专利类型 | 保护对象 | 典型保护期 | 对仿制药阻断力 |
|---------|---------|-----------|---------------|
| 化合物专利 | 活性成分分子结构 | 20年 | ★★★★★ |
| 晶型专利 | 特定结晶形态 | 20年 | ★★★★☆ |
| 制剂专利 | 特定剂型/给药系统 | 20年 | ★★★☆☆ |
| 方法专利 | 制备工艺/合成路线 | 20年 | ★★☆☆☆ |
| 用途专利 | 特定适应症使用 | 20年 | ★★★★☆ |
| 装置专利 | 药物递送装置 | 20年 | ★★☆☆☆ |
| 前药专利 | 前体药物形式 | 20年 | ★★★☆☆ |
| 中间体专利 | 关键合成中间体 | 20年 | ★★☆☆☆ |
| 联合用药专利 | 特定药物组合方案 | 20年 | ★★★☆☆ |
| 代谢产物专利 | 活性代谢产物 | 20年 | ★★★☆☆ |

### 1.2 专利期延长机制（中美欧对比）

| 延长类型 | 美国（PTE） | 欧洲（SPC） | 中国 |
|---------|------------|------------|------|
| 延长原因 | FDA审批延迟 | EMA审批延迟 | 无正式PTE制度 |
| 最长延长期 | 5年 | 5年 | — |
| 总保护期上限 | 14年（从获批日起） | 15年（从获批日起） | — |
| 申请时机 | 获批后60天内 | 获批后6个月内（部分国家） | — |
| 延长对象 | 一项专利 | 一项基础专利 | — |
| 药品类型 | 处方药/OTC/生物制品 | 同左 | — |

### 1.3 专利到期甘特图模板

绘制时应标注以下关键节点：
- 各专利的原始到期日
- PTE/SPC 延长后的实际到期日
- "专利悬崖日"（最后一项核心专利到期日）
- 各专利之间的保护重叠区间
- ANDA Paragraph IV 挑战日（如有）

## 二、仿制药竞争威胁评估模型

### 2.1 ANDA 竞争评估框架

**Paragraph IV 挑战流程**：
1. 仿制药企业提交 ANDA + Paragraph IV 认证（声称原研专利无效或不被侵犯）
2. 原研企业在 45 天内提起专利侵权诉讼
3. FDA 审批自动暂停 30 个月（或诉讼解决/专利到期，以先到者为准）
4. 首仿申请人获批后享有 180 天独占期
5. 180 天独占期可因多种原因触发或失去

**首仿 180 天独占期评估要素**：
- 独占期归属企业及其市场能力
- 独占期启动条件与可能的丧失因素
- 多家首仿共享独占期的可能性

### 2.2 中国市场仿制药风险评估

| 风险维度 | 评估要素 | 数据来源 |
|---------|---------|---------|
| 一致性评价 | 通过评价的仿制药数量与质量 | NMPA 公告 |
| 集采风险 | 是否纳入国家/省级集采目录 | 联合采购办公室公告 |
| 专利链接 | 仿制药企业的声明类型（I-IV） | 上市药品专利信息登记平台 |
| 上市许可 | 是否已有仿制药获批上市 | NMPA 药品注册数据库 |

### 2.3 仿制药产能与价格战评估

- 评估已获批仿制药企业的**实际产能**
- 分析各企业的**定价策略倾向**（激进低价 vs 温和跟进）
- 预测仿制药上市后 **6/12/24个月内的竞争者数量**

## 三、收入影响情景分析模型

### 3.1 品牌药份额流失曲线

仿制药上市后品牌药典型份额变化：

| 时间（仿制药上市后） | 品牌药份额保留率（基准情景） |
|---------------------|--------------------------|
| 1个月 | 85%-90% |
| 3个月 | 70%-80% |
| 6个月 | 50%-65% |
| 12个月 | 35%-50% |
| 24个月 | 25%-35% |
| 36个月 | 20%-30% |

### 3.2 价格降幅参考

| 市场类型 | 首仿价格降幅 | 多仿价格降幅 |
|---------|------------|------------|
| 美国 | -30%~-50%（首仿） | -70%~-90%（6-12个月内） |
| 欧洲 | -40%~-60%（首仿） | -80%~-95% |
| 中国（集采） | -50%~-80%（中标价） | — |
| 中国（非集采） | -30%~-50% | -60%~-80% |

### 3.3 累计 5 年收入损失计算公式

```
年度损失 = (品牌药到期前收入 - 仿制药上市后收入) × 损失比例
累计5年损失 = Σ(第1年损失 + 第2年损失 + ... + 第5年损失)
企业营收影响占比 = 累计5年损失 / 企业5年预期总营收 × 100%
```

## 四、悬崖风险等级评定标准

| 风险等级 | 判定标准 | 颜色标识 |
|---------|---------|---------|
| 极高风险 | 单产品收入损失 > 企业总营收 20% | 🔴 |
| 高风险 | 单产品收入损失占企业总营收 10%-20% | 🟠 |
| 中风险 | 单产品收入损失占企业总营收 5%-10% | 🟡 |
| 低风险 | 单产品收入损失占企业总营收 < 5% | 🟢 |
