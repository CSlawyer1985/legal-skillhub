# 场景⑥ 劳动用工合规审查 — 文件起草/审查详情

> 本文件是 `劳动人事/SKILL.md` Phase 4.6 的外置子文件。处理「劳动用工合规审查」场景（合规审查报告 + 整改路线图）时读取并按结构输出。

## 审查报告结构模板

```
审查报告结构
  一、审查范围与方法
  二、适用法规体系（全国基准 + 地方裁量指引）
  三、逐项对标审查（合同管理/社保公积金/加班与工资/劳务派遣/特殊人群就业/竞业限制/离职流程）
  四、差距汇总与风险评估（高风险中风险低风险）
  五、整改路线图（P0/P1/P2）
  六、结论

逐项审查关键指标
  - 劳动合同签署率（必须100%）
  - 社保公积金缴纳（缴纳地/基数/比例合规）
  - 加班费计算基数（各地裁量差异大）
  - 劳务派遣比例（≤10%）+ 岗位"三性"要求
  - 试用期约定（3月/1年/3年对应试用期上限）
  - 竞业限制适用对象（非高管/非技术人员慎用）
  - 外国人就业许可
```
