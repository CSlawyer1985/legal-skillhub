# 场景⑤ 职场调查 — 文件起草/审查详情

> 本文件是 `劳动人事/SKILL.md` Phase 4.5 的外置子文件。处理「职场调查」场景（调查方案 / 访谈记录模板 / 调查报告 / 处理建议）时读取并按流程输出。

## 调查工作流程模板

```
调查工作流程
  1. 接收投诉 → 确认投诉范围与证据
  2. 制定调查计划（访谈对象/证据收集清单/时间表）
  3. 证据收集（文档/邮件/聊天记录/音视频/实物）
  4. 访谈（投诉人→被投诉人→证人；逐人单独进行；告知调查保密义务）
  5. 事实认定（证据对照分析、证据标准优势证据/高度盖然性）
  6. 调查报告（事实背景→调查方法→证据与事实分析→结论→处理建议）
  7. 建议处理措施（制度层面/管理层/法律层面）

程序正当性要求
  - 被投诉人有答辩/申辩权
  - 调查人员中立无利害关系
  - 调查过程保密
  - 证据固定留存
```
