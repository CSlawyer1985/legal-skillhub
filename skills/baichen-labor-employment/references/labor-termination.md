# 场景③ 解除与协商解除 — 文件起草/审查详情

> 本文件是 `劳动人事/SKILL.md` Phase 4.3 的外置子文件。处理「解除与协商解除」场景（起草解除通知书 / 协商解除协议 / 离职结算清单）时读取并按模板输出。

## 协商解除协议结构模板

```
协商解除协议结构
  一、解除事实基础
  二、解除日期
  三、经济补偿金额与支付时间
  四、费用结算与交接（工资/加班费/年假/社保公积金/报销）
  五、离职后义务（竞业限制是否启动/保密/禁止诋毁）
  六、免责与弃权条款（双方不再追究）
  七、争议解决

单方解除评估框架
  严重违纪 → 必须有制度依据 + 事实证据 + 程序正当（通知工会）
  不胜任 → 调岗或培训后仍不胜任（三步证明）
  医疗期满 → 不能从事原工作也不能从事另行安排的工作
  评估结论通过合法 / 有一定风险 / 未通过违法解除风险高（赔偿2N）
```
