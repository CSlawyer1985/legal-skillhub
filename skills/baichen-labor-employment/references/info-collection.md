# Phase 2 信息收集 — 按场景必须收集（深度参考）

> 本文件是 `劳动人事/SKILL.md` Phase 2「按场景必须收集」的外置子文件。执行 Phase 2 材料提取时，按所确认场景读取对应「必须收集」清单逐项收集；通用多渠道收集表见主文件 Phase 2。

## 按场景必须收集

| 场景 | 必须收集 |
|------|---------|
| ① 竞业限制 | 拟竞业员工岗位说明、已有保密/竞业协议、公司业务范围与竞业地域、行业竞业补偿惯例 |
| ② 经济性裁员 | 财务报表/亏损证明（如适用）、职工名册、工会/职代会信息、拟裁减人员名单及岗位分布 |
| ③ 解除 | 解除事由相关证据材料、员工工资单/考勤记录/绩效评估、现行劳动合同、是否有服务期/竞业限制 |
| ④ 员工手册 | 现行员工手册全文、规章制度制定说明、民主程序记录（职代会/工会讨论纪要）、公示/签收记录 |
| ⑤ 职场调查 | 投诉材料/邮件/聊天记录、被投诉人说明、相关证人信息、公司反骚扰/行为准则、过往类似处理 |
| ⑥ 合规审查 | 员工花名册（脱敏）、劳动合同范本、社保公积金缴纳凭证、劳务派遣协议、加班制度、竞业限制协议 |

**缺少材料标注"待补充"**，明确向用户请求。不得凭空假设企业劳动合规状态。
