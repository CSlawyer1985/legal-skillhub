## §3.2 检索要点（按场景聚焦）

| 场景 | 强制检索要点 | 来源 |
|------|-------------|------|
| ① 竞业限制 | 竞业范围合理性司法标准、补偿金全国统一裁判基准（月均工资比例）、未支付补偿金×3个月解除权、竞业限制与商业秘密关系 | web + kb |
| ② 经济性裁员 | 法定人数门槛（20人/10%）、优先留用规则、禁止裁减对象（医疗期/三期/职业病）、听证/报告程序合规案例 | web + kb |
| ③ 解除 | 严重违纪认定裁量标准、不胜任工作"调岗+再培训+仍不胜任"三步证明、经济补偿金计算（社平3倍封顶）、违法解除2N | web + kb |
| ④ 员工手册 | 民主程序（职代会讨论/工会协商）裁判标准、公示/签收效力争议案例、制度内容合理性审查 | web |
| ⑤ 职场调查 | 调查程序正当性（证据收集/被投诉人答辩权/保密义务）、调查结论认定标准、相关刑事/行政边界（诽谤/侵犯名誉权） | web + kb |
| ⑥ 合规审查 | 社保未足额缴纳处罚标准、劳务派遣超比例（10%）处罚、未签书面合同双倍工资裁量、加班费计算基数地方裁量 | web |
