# invoice-review-compliance

**OCM 技能插件**——8 个技能中的第 6 个
**状态：** 已完成——第 1 阶段和第 2 阶段已测试

---

## 本技能的功能

对照计费准则审查外部律师的发票，按类别标记不合规条目，并生成批准、调减、拒绝和传达这些决定所需的文件。覆盖完整的发票合规工作流：从逐条审查到正式的律所升级沟通。

有电子计费平台或无电子计费平台均可使用。已部署电子计费系统时，LEDES 格式和 UTBMS 编码是硬性门槛。无电子计费系统时，电子邮件提交发票是沟通渠道，UTBMS 编码作为尽力标记。

## 模式

| 模式 | 触发语 | 输出 |
|------|---------|--------|
| 1——发票逐条审查 | “审查这份发票”/“标记计费问题”/“对照我们的准则检查” | 逐条审查报告 + 发票批准通知 |
| 2——发票拒绝沟通 | “写拒绝函”/“向律所传达调减决定” | 发票拒绝函 + 内部拒绝记录 |
| 3——审查流程搭建 | “建立发票检查清单”/“我们应该如何审查发票？”/“搭建我们的审查流程” | 发票审查检查清单 + 审查员指引说明 |
| 4——合规模式分析 | “这家律所总是这样”/“反复违规”/“升级计费问题” | 合规模式摘要 + 正式不合规通知 |

模式 5——对话指南：为尚未成熟的团队提供结构化指南，准备与外部律师的计费对话；当团队需要提出合规问题但尚不具备发出正式不合规通知的流程成熟度时使用。

## 关键设计决策

**规则与准则之分。** 四种行动值——拒绝（REJECT）、调减（REDUCE）、附注批准（APPROVE WITH NOTE）、批准（APPROVE）——对应规则/准则之分。对硬性 OCG 违反（禁止费用、费率违规、合并计费）用拒绝。对裁量性判断（时间过长、描述质量差）用调减。这一区分使审查决定站得住脚。

**七阶段审查检查清单。** 模式 3 按审查员实际工作顺序排列审查：机械性检查 → 逐条审查 → 禁止费用 → 费用支出 → UTBMS 编码 → 内部沟通阈值 → 预算。拒绝密集型阶段前置。

**上游原因记录在案。** 领域知识明确将计费合规失败与指令质量联系起来。模式 4 模式分析提示：这是律所失职还是指令缺口？交叉引用 matter-allocation-instruction 模式 4（指令审计）。

**PDF 发票摄取。** 模式 1 接受上传的 PDF 发票。技能直接从 PDF 提取条目并对照计费准则进行映射，无需用户重新格式化。

## 违规类别

| 类别 | 行动 | 示例 |
|----------|--------|---------|
| 合并计费 | 拒绝 | 单一条目内多个任务对应不同 UTBMS 编码 |
| 禁止费用 | 拒绝 | 发票准备、冲突检索、培训、爬坡期、文书性工作 |
| 费率违规 | 拒绝 | 未经批准的费率、未经批准的计时人员、未适用批量折扣 |
| 人员配置违规 | 拒绝或调减 | 未经批准多名计时人员参加活动、超出每日工时上限 |
| 描述违规 | 调减或附注批准 | “服务已提供”“文件审查”——未描述具体任务 |
| 内部沟通超额 | 调减 | 律所内部沟通超过发票总额的 10% |
| 费用支出违规 | 拒绝或调减 | 间接费用、头等舱差旅、费用加价 |
| 逾期提交 | 调减 | 逾期 60 天以上：调减 20%；逾期 90 天以上：可能拒绝 |
