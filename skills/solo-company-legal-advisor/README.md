## 快速开始

### 1. 安装 Skill

```bash

```

```bash

cp -r solo-company-legal-advisor ~/.qclaw/skills/
```


## 2. 使用示例

### 示例 1：咨询法律问题

**用户输入：**
```
我是一人有限公司的股东，公司欠债100万，
债权人能直接要求我用个人财产偿还吗？
```

**Agent 回答：**
```
根据《公司法》规定，一人有限责任公司的股东通常仅以
认缴的出资额为限对公司债务承担**有限责任**。

但是，如果出现以下情况，你可能被追究**连带责任**：

### ⚠️ 财务风险混同（最常见风险）
如果你无法证明公司财产独立于个人财产（财务混同），
法院可以"揭开公司面纱"，要求你承担连带责任。

**典型情形：**
- 用个人银行卡收公司款项
- 公司支出与个人消费混在一起
- 没有规范的财务账簿
- 没有每年审计

### 📋 合规建议
1. **开设独立账户**：公司资金往来必须通过公司账户
2. **规范记账**：聘请会计建立完整账簿
3. **年度审计**：每年聘请会计师事务所审计（法律强制要求）
4. **保留证据**：保存所有公司决策的书面股东决定

### 💡 你的情况分析
- 如果你的公司财务规范、账目清晰 → 债权人**不能**追讨你的个人财产
- 如果财务混同、无法区分 → 你**可能**承担连带责任

需要我帮你：
1. 评估你目前的财务风险？
2. 制定财务规范方案？
3. 起草股东会决定规范模板？

⚖️ **免责声明**：本回复基于公开法律法规提供一般性参考意见，
不构成正式法律意见。建议咨询专业律师。
```

```markdown
3. **经营范围**：[[    ]]
4. **住所**：[[    ]]
5. **股东姓名**：[[    ]]
6. **法定代表人**：[[    ]]（通常就是股东本人）
```

**用户补充信息后，Agent 生成：**

```markdown
需要我继续生成配套的《股东决定》文件吗？
```

### 示例 3：审查合同

**用户输入：**
```
[上传合同文件：销售合同.pdf]
帮我审查这份合同有什么法律风险？
```

**Agent 分析：**
```markdown
已读取你的合同文件。以下是风险分析：

## 🔴 高风险条款（建议修改）

### 1. 违约责任过重（第8条）
**原文**："违约方需赔偿守约方的一切损失，上不封顶"

**风险**：可能被判巨额赔偿，影响公司生存

**修改建议**：
```
违约方应赔偿守约方的实际损失，但赔偿总额不超过
合同总金额的 [[建议：30%-50%]]。
```

### 2. 争议解决地点不利（第12条）
**原文**："争议由甲方所在地法院管辖"

**风险**：如果甲方在外地，你需要到外地打官司，成本高

**修改建议**：
```
争议由合同签订地或被告住所地法院管辖。
```
（或改为"由原告所在地法院管辖"）

## 🟡 中风险条款（建议明确）

### 3. 付款期限不明确（第5条）
**原文**："乙方应在合理期限内付款"

**风险**："合理期限"模糊，易产生争议

**修改建议**：
```
乙方应在收到发票后 [15/30] 个工作日内付款。
```

## 🟢 低风险提示（仅供参考）

### 4. 缺少保密条款
建议增加：
```
双方对合作中获知的对方商业秘密负有保密义务，
保密期限为合同终止后 [3/5] 年。
```

---

需要我：
1. 生成修改后的合同文本？
2. 解释如何与对方协商修改？
3. 提供谈判话术建议？

⚖️ **免责声明**：本合同审查仅供参考，不构成正式法律意见。
重大合同建议委托专业律师全面审查。
```

## 5. 自定义配置

### 修改回答风格
编辑 `SKILL.md` 中的"语言风格"部分，调整：
- 专业度（更专业 / 更通俗）
- 详细程度（简明扼要 / 详细解释）
- 输出格式（是否使用表格、编号等）

### 添加专业知识库
在 `knowledge/` 目录添加：
- 地方性政策（如北京/上海的公司注册特殊规定）
- 行业特定法规（如餐饮、医疗、教育等）
- 你自己的案例库

### 集成外部工具（高级）
如果需要联网查询法规、生成 PDF 合同等，可以：
1. 在 `SKILL.md` 中添加工具调用逻辑
2. 配置 API 密钥（如有需要）

## 6. 常见问题

**Q1：这个 Skill 能替代律师吗？**
A：不能。本 Skill 提供**一般性法律参考**，对于重大、复杂的法律事务，强烈建议咨询执业律师。

**Q2：生成的法律文书有法律效力吗？**
A：文书模板符合法律格式要求，但**必须根据实际情况填写并签字/盖章**才能生效。建议由律师审核后再使用。

**Q3：如何保持法规知识的时效性？**
A：法律会修订，建议定期：
1. 使用 `web_search` 工具查询最新法规
2. 更新 `knowledge/` 目录中的法规摘要
3. 关注全国人大、最高法院的官方发布

**Q4：可以用于商业用途吗？**
A：可以，但请：
1. 标注来源（本 Skill 基于 QClaw 构建）
2. 根据实际使用场景调整免责声明
3. 如作为产品提供给客户，建议增加专业律师审核环节
