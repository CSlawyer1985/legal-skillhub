## 为什么要使用案例库？

### 传统"规则推理"的局限

传统法律顾问基于**法条推理**：

```
用户提问 → 查找法条 → 基于法条回答
```

**问题**：
- ❌ **机械、僵化**：只告诉用户"法条怎么写"，不告诉"实际中法院怎么判"
- ❌ **缺乏务实建议**：只说"应当怎样"，不说"怎样避免风险"
- ❌ **无法识别风险模式**：无法从过去的判例中学习

---

### 案例库 + 神经网络式学习

案例库是 Skill 的"**神经网络**"——通过学习大量真实案例，Skill 能够：

1. **基于案例推理**（Case-Based Reasoning）
   - 遇到新问题时，查找类似案例
   - 引用其**裁判要点**（如"财务混同 → 连带责任"）
   - 进行**类比推理**（"你的情况和案例 1 类似，可能被认定为..."）

2. **识别法律风险模式**
   - 从案例中总结常见风险点
   - 例如："财务混同 → 承担连带责任"（案例 1）
   - 例如："未签劳动合同 → 双倍工资"（案例 3）

3. **提供务实解决方案**
   - 基于案例中的"**案例启示**"
   - 给出**可操作的合规建议**（而不只是法条引用）

4. **自我迭代优化**
   - 每次对话后**保存问答对**到 `cases/learned/`
   - 下次回答时**检索过去经验**
   - 回答质量**不断提高**（类似神经网络训练）

---

### 案例推理 vs 规则推理

| 特性 | 规则推理（传统） | 案例推理（神经网络式） |
|------|----------------|----------------------|
| **依据** | 法条 | 法条 + 真实案例 |
| **推理方式** | 演绎推理（法条 → 结论） | 类比推理（案例 A → 案例 B） |
| **回答内容** | "根据《XX 法》第 X 条..." | "根据《XX 法》第 X 条 + 案例 1（北京朝阳区法院，2022）..." |
| **务实性** | ⭐⭐ (机械) | ⭐⭐⭐⭐⭐ (务实) |
| **风险预警** | 一般 | 强（基于真实判例） |
| **自我学习** | ❌ 不支持 | ✅ 支持（保存问答对） |

## 案例库的工作流程

### 完整流程（从问题到回答）

```
用户提问："一人公司用个人卡收公司款有什么风险？"
       │
       ▼
Skill 触发（关键词："一人公司"、"个人卡"、"风险"）
       │
       ▼
第一步：问题识别
       │- 涉及法律领域：公司法、财务合规
       │- 问题类型：财务混同风险
       │
       ▼
第二步：查询案例库（基于案例推理）⭐
       │
       ├─ 检查 cases/ 目录
       │   │
       │   ├─ 找到类似案例（如 案例1-财务混同）
       │   │   │
       │   │   ▼
       │   │ 使用 read 工具读取案例文件
       │   │   │
       │   │   ▼
       │   │ 提取案例中的"事实模式"和"裁判要点"
       │   │   - 事实模式："股东用个人卡收公司款"
       │   │   - 裁判要点："财务混同，股东承担连带责任"
       │   │   │
       │   │   ▼
       │   │ 将案例作为**类比推理**的依据
       │   │   - "你的情况与案例 1 类似"
       │   │   - "根据案例 1，可能被认定为财务混同"
       │   │   - "建议：开设对公账户，避免连带责任"
       │   │
       │   └─ 未找到类似案例
       │             │
       │             ▼
       │         使用规则推理（仅基于法条）
       │
       ▼
第三步：法律分析（综合）
       │
       ├─ 法规依据（knowledge/ 或 内置知识库）
       │   └─ 《公司法》第 63 条："一人公司股东不能证明公司财产独立于个人财产的..."
       │
       ├─ 案例依据（cases/）
       │   └─ 案例 1（北京朝阳区法院，2022）："股东用个人卡收公司款，被判连带责任"
       │
       └─ 过去经验（cases/learned/）⭐
           └─ 读取过去类似问题的回答（如果有）
               - 例如：learned-20260519-2130-个人卡收公司款的风险.md
               - 基于过去经验，优化本次回答
       │
       ▼
第四步：生成回答
       │
       ├─ 1. 问题确认
       │   └─ "您关心的是一人公司用个人卡收公司款的法律风险，正确吗？"
       │
       ├─ 2. 案例引用（⭐ 核心优势）
       │   └─ "根据真实案例（案例 1：北京朝阳区法院，2022）：
       │       某股东用个人卡收公司款，被法院判决对公司债务承担**连带责任**。"
       │
       ├─ 3. 法律分析
       │   └─ "根据《公司法》第 63 条 + 案例 1：
       │       - 如果你用个人卡收公司款，可能被认定为'财务混同'
       │       - 法律后果：公司债务 → 你个人承担连带责任（用个人财产偿还）"
       │
       ├─ 4. 解决方案（基于"案例启示"）
       │   └─ "✅ 合规建议（基于案例 1 的'案例启示'）：
       │       1. 开设独立对公账户
       │       2. 建立规范财务制度（聘请会计）
       │       3. 每年进行财务审计
       │       4. 保留证据（银行流水、审计报告）"
       │
       ├─ 5. 风险提示
       │   └─ "⚠️ 高风险行为（务必避免！）：
       │       - 用个人卡收公司款
       │       - 公司支出与个人消费混同
       │       - 财务账簿不完整"
       │
       └─ 6. 免责声明
           └─ "⚖️ 免责声明：本回复基于公开法律法规和真实案例提供一般性参考..."
       │
       ▼
返回给用户
       │
       ▼
第五步：自我学习（迭代优化）⭐
       │
       ├─ 1. 保存问答对到 cases/learned/
       │   └─ 文件名：learned-20260519-2130-个人卡收公司款的风险.md
       │
       ├─ 2. 提取法律要点，保存到 cases/learned/rules.md
       │   └─ 规则："财务混同 → 股东承担连带责任"（法条 + 案例）
       │
       └─ 3. 下次回答时检索 cases/learned/（迭代优化）
           └─ 如果遇到类似问题，直接引用过去经验（回答质量更高）
```

### 为什么这是"神经网络"？

| 神经网络概念 | 对应 Skill 功能 |
|-------------|----------------|
| **训练**（Training） | 保存问答对到 `cases/learned/`（每次对话后） |
| **推理**（Inference） | 遇到新问题时，检索 `cases/learned/` 中的类似问题 |
| **模式识别**（Pattern Recognition） | 从案例中识别"事实模式 → 法律后果"的映射 |
| **在线学习**（Online Learning） | 每次对话都更新 `cases/learned/rules.md`（持续优化） |
| **迭代优化**（Iterative Optimization） | 随着问答对增加，回答质量不断提高 |

## 如何使用案例库？

### 对于 Skill 开发者（你）

#### 步骤 1：准备案例文件

**来源**：
- 中国裁判文书网（https://wenshu.court.gov.cn/）
- 北大法宝（https://www.pkulaw.com/）
- 无讼案例（https://www.itslaw.com/）

**操作步骤**：
1. 搜索"一人公司"相关判例
2. 下载判决书（PDF 或 HTML）
3. 将判例**摘要**为 Markdown 格式（参考 `cases/` 目录中的示例）
4. 保存到 `cases/` 目录

**案例文件格式规范**（见"案例文件格式规范"章节）

---

#### 步骤 2：案例命名规范

**文件名格式**：
```
案例X-案例类型-简短描述.md
```

**示例**：
- `案例1-财务混同-股东个人承担连带责任.md`
- `案例2-年度审计-未审计被列入异常名录.md`
- `案例3-劳动用工-未签劳动合同双倍工资.md`
- `案例4-合同纠纷-公章管理不善被判承担责任.md`
- `案例5-税务合规-公私账户混同被认定偷税.md`

---

#### 步骤 3：测试案例推理

**操作**：
1. 重启 QClaw Gateway
   ```bash
   openclaw gateway restart
   ```
2. 提问："一人公司用个人卡收公司款有什么风险？"
3. 检查 Skill 是否：
   - 读取了 `cases/案例1-财务混同-股东个人承担连带责任.md`
   - 引用了案例中的"案例启示"
   - 基于案例进行推理（而不仅仅是基于法条）

---

### 对于 Skill 用户（一人公司经营者）

#### 开箱即用！

- Skill 安装后，已内置 **5 个典型案例**（在 `cases/` 目录）
- 直接提问法律问题，Skill 会自动读取案例库，基于案例推理
- 如果遇到类似案例中的情况，Skill 会**主动引用案例**，提醒你注意风险

---

#### （可选）添加自己的案例

**操作**：
1. 如果你有类似的法律纠纷，可以将案例摘要保存到 `cases/` 目录
2. 或者上传到 ima 知识库（Skill 也会读取）

**案例摘要格式**（见"案例文件格式规范"章节）

## 自我学习机制（迭代优化）⭐

### 🧠 每次回答后，自动执行以下操作

#### 1. 保存问答对到 `cases/learned/` 目录

**操作**：
- 使用 `write` 工具
- 文件名格式：`learned-YYYYMMDD-HHMM-问题摘要.md`
- 内容包含：
  - **用户问题**
  - **我的回答**（含法规依据、案例分析、解决方案）
  - **用户反馈**（如果有的话）
  - **标签**（如"财务混同"、"劳动用工"等）

**示例文件**：`cases/learned/learned-20260519-2130-个人卡收公司款的风险.md`

```markdown
# 学习记录：一人公司用个人卡收公司款的风险

**时间**：2026-05-19 21:30
**问题类型**：财务混同 / 公司人格否认
**标签**：`财务混同` `公司人格否认` `连带责任` `公司法第63条`

---

## 用户问题

"我是一人公司，平时用个人卡收公司款，有什么风险？"

---

## 我的回答（摘要）

### 法律风险（高风险 ⚠️）

根据《公司法》第 63 条 + 案例 1（北京朝阳区法院，2022）：
- 如果公司财产与个人财产混同，股东需对公司债务承担**连带责任**
- 真实案例：某股东用个人卡收公司款，被判对公司 80 万元债务承担连带责任

### 合规建议

1. **开设独立对公账户**
   - 公司资金往来必须通过对公账户
   - 不要用个人卡收公司款、付公司账

2. **建立规范财务制度**
   - 聘请专业会计（或委托代理记账公司）
   - 建立完整账簿，保存所有凭证（发票、合同、银行流水）

3. **每年进行财务审计**
   - 法律强制要求（《公司法》第 62 条）
   - 出具《审计报告》并保存

4. **保留证据**
   - 所有公司决策形成**书面股东决定**
   - 保存《审计报告》、财务报表、银行流水等
```

## 常见问题（FAQ）

### Q1：案例库中的案例是真实的吗？

**A**：是的！基于"中国裁判文书网"的公开判例，经过摘要和脱敏处理。

---

### Q2：Skill 怎么知道要读取哪个案例？

**A**：根据问题类型判断。例如：
- 涉及"个人卡收公司款" → 读取案例 1（财务混同）
- 涉及"未签劳动合同" → 读取案例 3（双倍工资）
- 涉及"未审计" → 读取案例 2（异常名录）

Skill 会扫描 `cases/` 目录中的所有文件，根据**文件名**和**案例类型**进行判断。

---

### Q3：我可以添加自己的案例吗？

**A**：可以！将案例摘要（Markdown 格式）保存到 `cases/` 目录即可。

**建议**：
- 如果你有类似的法律纠纷，可以自己写案例摘要
- 或者请专业律师帮你摘要判例
- 保存到 `cases/` 目录，Skill 会自动读取

---

### Q4："自我学习"会占用很多存储空间吗？

**A**：不会。`cases/learned/` 中的文件都是**文本**（Markdown），每个文件只有 **几 KB**。

**估算**：
- 每个问答对：~5 KB
- 每天 10 个问答对：~50 KB
- 一年 365 天：~18 MB

完全没问题！

---

### Q5：如何查看 Skill 的"学习成果"？

**A**：读取 `cases/learned/rules.md`（规则库），查看提取的法律规则。

**操作**：
```bash
cat ~/.qclaw/skills/solo-company-legal-advisor/cases/learned/rules.md
```

或者直接在 QClaw 聊天界面中提问：
```
请读取 cases/learned/rules.md，告诉我你学到了哪些法律规则？
```

---

### Q6：Skill 会自动删除旧的学习记录吗？

**A**：不会。所有学习记录都会保存（除非你手动删除）。

**建议**：
- 定期查看 `cases/learned/` 目录
- 删除不正确的学习记录（如果 Skill 学到了错误的规则）
- 保留正确的学习记录（用于持续优化）

---

### Q7："自我学习"功能可以关闭吗？

**A**：可以。修改 `SKILL.md`，删除"第五步：自我学习（迭代优化）"即可。

**但不建议关闭**，因为：
- 自我学习能让 Skill 的回答质量**不断提高**
- 对于常见问题，Skill 能**快速给出准确答案**
- 类似"神经网络"的训练过程，越用越聪明
