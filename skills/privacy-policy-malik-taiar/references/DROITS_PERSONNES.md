# 数据主体权利

> 参考：GDPR 第 15-22 条
>
> **文档**：[CNIL_droits_personnes.pdf](assets/CNIL_droits_personnes.pdf)

## 概览

GDPR 赋予个人对其个人数据的权利。这些权利必须在隐私政策中连同行使方式一并明确载明。

---

## 八项基本权利

### 1. 访问权（第 15 条）

**定义**：任何人可以请求了解其数据是否被处理，如被处理，可以获得其数据副本以及关于处理的 信息。

**须提供的信息**：
- 处理目的
- 相关数据类别
- 接收方
- 保存期限
- 个人权利
- 数据来源（如间接收集）
- 是否存在自动化决策

**答复期限**：1 个月（如复杂可延长至 3 个月）

**典型表述**：
```
访问权：您可以向我们询问我们是否处理与您相关的数据，如处理，可以获得
这些数据的副本以及关于我们如何使用这些数据的信息。
```

---

### 2. 更正权（第 16 条）

**定义**：任何人可以请求更正不准确的数据或补全不完整的数据。

**方式**：
- 尽快更正
- 告知接收方（如可能）

**典型表述**：
```
更正权：如您发现您的数据不准确或不完整，您可以请求我们更正或补全。
```

---

### 3. 删除权 / 被遗忘权（第 17 条）

**定义**：任何人可以在某些情况下请求删除其数据。

**适用情形**：
- 数据对目的不再必要
- 撤回同意
- 反对处理
- 非法处理
- 法定义务要求删除
- 向未成年人收集的数据（在线服务）

**例外**（以下情形可拒绝删除）：
- 行使言论自由
- 法定义务
- 公共利益（健康、档案、研究）
- 法律权利的确认、行使或抗辩

**典型表述**：
```
删除权：当您的数据不再必要、您撤回同意或您反对处理时，您可以请求我们
删除您的数据。该权利不是绝对的，可能受我们的法定义务限制。
```

---

### 4. 限制处理权（第 18 条）

**定义**：任何人可以请求"暂停"其数据的处理。

**适用情形**：
- 质疑数据准确性（核实期间）
- 处理非法，但个人更倾向于限制而非删除
- 数据非必要但对诉讼有用
- 反对正在核实中

**效果**：数据被保存但不能被处理（保存、诉讼、保护第三方权利、公共利益除外）。

**典型表述**：
```
限制处理权：您可以请求我们暂时冻结您数据的使用，例如当您质疑其准确性
或反对其删除时。
```

---

### 5. 可携权（第 20 条）

**定义**：任何人可以请求以结构化、机器可读的格式取回其数据，并将其传输给另一控制者。

**条件**：
- 处理基于同意或合同履行
- 自动化处理
- 个人提供的数据

**格式**：结构化、常用、机器可读（CSV、JSON、XML...）

**典型表述**：
```
可携权：您可以请求我们以结构化、常用的格式向您传输您的数据，以便您
重新使用或将其转移至另一服务。
```

---

### 6. 反对权（第 21 条）

**定义**：任何人可以在某些情况下反对其数据的处理。

**适用情形**：
- 基于合法利益的处理（除非有令人信服的合法理由）
- 商业营销（当然反对权，无需理由）
- 与营销相关的画像

**注意**：对营销，反对必须简便且免费（退订链接）。

**典型表述**：
```
反对权：您可以随时反对为商业营销目的处理您的数据。对基于我们合法利益
的其他处理，您可以基于您的特殊情况提出反对。
```

---

### 7. 撤回同意权（第 7.3 条）

**定义**：当处理基于同意时，可以随时撤回。

**条件**：
- 撤回必须与给予同样简便
- 撤回不影响先前处理的合法性
- 关于该权利的信息必须在同意**之前**提供

**典型表述**：
```
撤回同意：当您的数据处理基于您的同意时，您可以随时撤回。撤回不影响
撤回前已进行的处理的合法性。
```

---

### 8. 向 CNIL 申诉的权利（第 77 条）

**定义**：任何人如认为其数据处理违反 GDPR，可以向 CNIL 提出申诉。

**CNIL 联系方式**：
- 网站：www.cnil.fr
- 地址：3 Place de Fontenoy, TSA 80715, 75334 Paris Cedex 07

**典型表述**：
```
申诉：如您认为您的数据处理违反法规，您可以向 CNIL（www.cnil.fr）或任何
其他欧洲监管机构提出申诉。
```

---

## 特别权利：自动化决策（第 22 条）

**定义**：任何人有权不受完全基于自动化处理、产生法律效力或对其产生重大影响的决定的约束。

**例外**：
- 为订立/履行合同所必需
- 法律授权
- 基于明确同意

**如适用，须载明**：
- 自动化处理的存在
- 底层逻辑
- 重要性和后果

## 行使权利的方式

### 联系

预留专门联系点：
```
为行使您的权利，您可以通过以下方式联系我们：
- 电子邮件：dpo@entreprise.com（或 privacy@...）
- 邮寄：[完整地址]
- 通过我们的在线表格：[链接]
```

### 身份核实

对身份存疑时：
```
出于安全原因，我们可能在处理您的请求前要求您证明身份。此核实旨在保护
您的数据免受未授权访问。
```

### 期限

| 行动 | 期限 |
|--------|-------|
| 收悉确认 | 立即 / 48 小时内（良好实践） |
| 答复 | 最多 1 个月 |
| 延长 | 复杂时 +2 个月（须告知） |

### 免费

```
行使您的权利是免费的。但如请求明显无据或过度（尤其重复性请求），我们
可以收取合理的行政费用或拒绝处理。
```

## 汇总表

| 权利 | 条件 | 企业可否反对 |
|-------|-----------|-------------------------------------|
| 访问 | 无 | 否（过度请求除外） |
| 更正 | 数据不准确 | 否 |
| 删除 | 第 17 条条件 | 是（法定义务、司法） |
| 限制 | 第 18 条条件 | 核实期间不可 |
| 可携 | 同意/合同 + 自动化 | 否 |
| 反对 | 合法利益或营销 | 营销：绝不 / 其他：令人信服的理由 |
| 撤回同意 | 基于同意的处理 | 否 |
| 向 CNIL 申诉 | 无 | 否（绝对权利） |

## 用于政策的完整表述

```
7. 您享有哪些权利？

依据适用法规，您享有以下权利：

• 访问权：获得您的数据被处理的确认并接收其副本。

• 更正权：请求更正不准确或不完整的数据。

• 删除权：在法律规定的案件中请求删除您的数据。

• 限制权：请求暂时冻结您的数据处理。

• 可携权：以结构化格式接收您的数据并将其传输给第三方。

• 反对权：反对处理，尤其是商业营销。

• 撤回同意权：随时撤回，不影响先前处理的合法性。

8. 如何行使您的权利？

您可以通过以下方式联系我们行使权利：
- 电子邮件：privacy@[entreprise].com
- 邮寄：[完整地址]

我们承诺在一个月内答复。如请求复杂，该期限可延长两个月。

如您认为您的权利未得到尊重，您也可以向 CNIL（www.cnil.fr）提出申诉。
```
