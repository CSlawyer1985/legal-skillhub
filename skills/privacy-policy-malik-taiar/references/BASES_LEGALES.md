# 处理的法律依据

> 参考：GDPR（RGPD）第 6 条
>
> **文档**：[RGPD_texte_officiel.pdf](assets/RGPD_texte_officiel.pdf)

## 概述

为合法起见，任何个人数据处理必须依据 GDPR 第 6 条规定的 6 种法律依据之一。法律依据的选择必须在开始处理**之前**作出，并应予以记录。

---

## 6 种法律依据

### 1. 同意（第 6.1.a 条）

**定义**：个人已明确同意为一项或多项特定目的处理其数据。

**有效性条件**（GDPR 第 7 条）：
- **自由**：无权力失衡，拒绝无负面后果
- **特定**：为每项不同目的
- **知情**：事先清晰完整的信息
- **明确**：明确积极的行为（无预先勾选的方框）

**特征**：
- 可随时撤回
- 企业必须能够证明同意
- 撤回必须与给予一样简便

**使用示例**：
```
- 订阅通讯
- 广告和分析 Cookie
- 与商业伙伴共享数据
- 以广告个性化为目的的画像
- 向欧盟外传输数据（最后手段）
```

**典型表述**：
```
"我同意通过电子邮件接收 [公司] 的商业报价。"
□ 是

"我同意我的数据与 [公司] 的合作伙伴共享，
以接收其报价。"
□ 是
```

---

### 2. 合同履行（第 6.1.b 条）

**定义**：处理对于履行数据主体为当事方的合同，或执行应其请求采取的缔约前措施是必要的。

**条件**：
- 存在合同或正在谈判中
- 处理客观上对其履行是必要的
- 无侵入性更小的替代方案

**使用示例**：
```
- 订单配送（姓名、地址、电话）
- 创建客户账户
- 开票（支付数据）
- 售后服务
- 保修管理
- 提供已订购的 SaaS 服务
```

**注意**：商业开拓**不能**基于此依据。

**典型表述**：
```
"我们处理您的识别和配送数据，以执行您的订单并向您交付所购产品。
该处理对于履行约束我们的销售合同是必要的。"
```

---

### 3. 法律义务（第 6.1.c 条）

**定义**：处理对于遵守控制者所负的法律义务是必要的。

**条件**：
- 义务须由欧盟或国家法律规定
- 义务须具有约束力
- 处理须与义务目的相称

**使用示例**：
```
- 发票保存（10 年——《商法典》）
- 连接日志保存（1 年——LCEN《数字经济信任法》）
- 向税务机关通报
- 社保申报（URSSAF 等）
- Tracfin 报告（反洗钱）
- 回应司法要求
```

**典型表述**：
```
"我们依据会计和税务义务（《商法典》第 L123-22 条）将您的发票保存 10 年。"
```

---

### 4. 切身利益保护（第 6.1.d 条）

**定义**：处理对于保护数据主体或另一自然人的切身利益是必要的。

**条件**：
- 涉及个人生命的紧急情况
- 仅在任何其他依据均不适用时使用
- 例外性依据

**使用示例**：
```
- 向急救服务传输医疗数据
- 定位处于危险中的人
- 自然灾害时访问数据
```

**备注**：该依据在商业语境中很少使用。

---

### 5. 公共利益使命（第 6.1.e 条）

**定义**：处理对于执行公共利益使命或行使公共权力的必要。

**条件**：
- 以欧盟或国家法律为基础
- 通常保留给公共机关
- 数据主体可提出反对

**使用示例**：
```
- 公共行政部门进行的处理
- 公共利益科研
- 公共统计（INSEE）
- 公共卫生
```

**备注**：除例外外，私营企业很少使用。

---

### 6. 合法利益（第 6.1.f 条）

**定义**：处理对于控制者或第三方所追求的合法利益是必要的，除非数据主体的利益或基本权利优先。

**3 步测试**（强制）：
1. **识别利益**：是否合法？（合法、清晰、真实）
2. **必要性**：处理是否确实必要？
3. **利益衡量**：个人的权利是否优先？

**使用示例**：
```
- 网络安全和防欺诈
- B2B 商业开拓（附反对权）
- 匿名化统计
- 服务改进
- 人力资源管理
- 集团内部转让用于行政管理
```

**注意**：
- 记录利益衡量测试
- 在政策中提及合法利益
- 保障有效的反对权

**典型表述**：
```
"我们处理您的浏览数据用于统计和网站改进。该处理基于我们了解
平台使用情况并加以改进的合法利益。您可以随时联系我们提出反对。"
```

## 汇总表

| 法律依据 | 性质 | 可否反对 | 典型示例 |
|-------------|-----------|---------------------|-----------------|
| 同意 | 可撤回 | 是（撤回） | 通讯 |
| 合同履行 | 强制性 | 否 | 订单 |
| 法律义务 | 强制性 | 否 | 发票 10 年 |
| 切身利益 | 例外性 | 否 | 医疗紧急情况 |
| 公共使命 | 公共性 | 是 | 行政部门 |
| 合法利益 | 条件性 | 是 | 统计 |

---

## 常见错误

| 错误 | 后果 | 解决方案 |
|--------|-------------|----------|
| 一切均用同意 | 同意无效 | 选择适当依据 |
| 以"合同履行"为基础的开拓 | 非法处理 | 同意或合法利益 |
| 无衡量测试的合法利益 | 不合规 | 记录测试 |
| 同意的预先勾选方框 | 同意无效 | 由用户勾选 |
| 未确定法律依据 | 非法处理 | 在处理**之前**确定 |

---

## 良好实践

### 1. 记录选择

对每项处理，记录：
- 选定的法律依据
- 选择理由
- 衡量测试（如为合法利益）

### 2. 清晰沟通

在隐私政策中：
- 为每项目的指明法律依据
- 如为合法利益：指明所追求的利益

### 3. 预见变更

法律依据不能中途变更。如同意被撤回，处理必须停止（不能切换为合法利益）。

## 政策表述

```
3. 我们为何以及在何种依据上处理您的数据？

| 目的 | 法律依据 | 说明 |
|----------|-------------|--------------|
| 管理您的订单 | 合同履行 | 交付所必需 |
| 发送通讯 | 您的同意 | 您可随时退订 |
| 浏览统计 | 我们的合法利益 | 改进我们的网站。您可提出反对 |
| 发票保存 | 法律义务 | 10 年（《商法典》） |
| B2B 开拓 | 我们的合法利益 | 发展我们的业务。反对权 |
```
