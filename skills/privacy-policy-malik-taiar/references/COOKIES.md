# Cookie 与跟踪器

> 参考：CNIL 指南（2020）+ ePrivacy 指令
>
> **文档**：[CNIL_transparence.pdf](assets/CNIL_transparence.pdf)

## 概览

Cookie 和跟踪器受 ePrivacy 指令衍生的特定规则约束，并由 CNIL 的建议补充。除例外情形外，大多数 Cookie 需要同意。

---

## 监管框架

### 原则：事先同意

在放置非必要 Cookie 之前，网站编辑者必须：
1. 告知用户 Cookie 的目的
2. 取得其同意
3. 使拒绝与接受一样简便

### 参考处罚

| 公司 | 罚款 | 事由 |
|------------|--------|-------|
| Google | 1.5 亿欧元 | 拒绝 Cookie 比接受更难 |
| Facebook | 6000 万欧元 | 无可见的"全部拒绝"按钮 |
| Amazon | 3500 万欧元 | 未经事先同意放置 Cookie |
| Microsoft | 6000 万欧元 | 未经同意放置 Cookie |

## Cookie 类别

### 1. 严格必要的 Cookie（豁免）

**定义**：网站运行不可或缺的 Cookie，没有它们用户将无法使用服务。

**示例**：
```
- 会话 Cookie（维持登录状态）
- 购物车 Cookie
- 认证 Cookie
- 安全 Cookie（CSRF）
- 语言偏好 Cookie
- 记忆 Cookie 选择的 Cookie（！）
```

**无需同意**：这些 Cookie 可在用户一到达网站时即放置。

---

### 2. 受众测量 / 分析 Cookie

**定义**：用于测量网站访问量和使用的 Cookie。

**示例**：
```
- Google Analytics
- Matomo（原 Piwik）
- AT Internet
- Adobe Analytics
```

**同意**：**需要**，除非：
- 目的严格限于受众测量
- 数据已匿名化
- 不与其他处理交叉比对
- 不传输给第三方

> **CNIL 提示**：以豁免模式配置的 Matomo 可无需同意运行。

---

### 3. 功能 Cookie

**定义**：改善用户体验但不严格必要的 Cookie。

**示例**：
```
- 记忆显示偏好
- 界面个性化
- 在线聊天
- 嵌入式视频播放器
```

**同意**：**需要**

---

### 4. 广告 / 营销 Cookie

**定义**：用于展示定向广告或衡量营销活动效果的 Cookie。

**示例**：
```
- Google Ads / DoubleClick
- Facebook Pixel
- LinkedIn Insight Tag
- Criteo
- 再营销
```

**同意**：**始终需要**——无任何例外可能

---

### 5. 社交网络 Cookie

**定义**：由分享按钮或社交网络集成放置的 Cookie。

**示例**：
```
- Facebook "点赞"按钮
- Twitter/LinkedIn 分享按钮
- 嵌入的 YouTube 视频
- Instagram 嵌入
```

**同意**：**需要**

> **提示**：使用两步点击分享按钮（先激活后分享），避免自动放置。

## 同意横幅

### CNIL 要求（2020）

1. **拒绝与接受一样简便**
   - "全部拒绝"按钮与"全部接受"按钮位于同一层级且可见
   - 不使用欺骗性设计（dark patterns）

2. **事先告知**
   - Cookie 的目的
   - 责任方身份（或指向清单的链接）
   - 拒绝的后果

3. **颗粒化同意**
   - 可按类别接受
   - 无默认全盘接受

4. **原则上无 cookie wall**
   - 网站访问不得以接受 Cookie 为条件
   - 例外：提供公平的替代方案

5. **同意的证明**
   - 在有效期内保存证明
   - 能够证明：谁、何时、何事

### 合规横幅示例

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│  🍪 我们使用 Cookie                                                     │
│                                                                         │
│  我们使用 Cookie 以改善您的体验、分析我们的流量并用于广告目的。          │
│                                                                         │
│  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐       │
│  │  全部接受        │  │  全部拒绝        │  │  个性化设置      │       │

│                                                                         │
```

## Cookie 的生命周期

### CNIL 建议：最长 13 个月

| 类型 | 建议时长 |
|------|-------------------|
| 同意 Cookie | 6 至 13 个月 |
| 分析 Cookie | 最长 13 个月 |
| 广告 Cookie | 最长 13 个月 |
| 会话 Cookie | 会话期间 |

超过 13 个月须重新征得同意。

```
浏览相关的信息。

严格必要的 COOKIE
```

## 常见错误

| 错误 | 可能的处罚 | 解决方案 |
|--------|-------------------|----------|
| 同意前放置 Cookie | 罚款 | 等待点击"接受" |
| 无可见"拒绝"按钮 | 罚款 | 按钮与"接受"同一层级 |
| 严格 cookie wall | 罚款 | 提供替代方案 |
| 时长超过 13 个月 | 整改令 | 遵守最长时长 |
| 无 Cookie 清单 | 不合规 | 详细表格 |
| Dark patterns | 罚款 | 中性清晰的设计 |
