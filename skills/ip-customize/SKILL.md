# /customize（中国法版本）

## 触发时机

用户输入了 `ip-customize`。他们想修改实务配置中的某一项——风险态度、升级联系人、组合范围、维权策略——而无需重新运行初始访谈，也无需手动编辑配置文件。

## 操作步骤

1. **读取配置。** 读取知识产权实务配置文件（以及上一级的公司概况配置文件）。如果配置文件不存在或仍包含 `[PLACEHOLDER]` 值，则回复：

   > 您尚未运行初始配置。请先运行 `ip-cold-start-interview`——customize 仅用于调整已有配置。

2. **展示可修改项。** 以分组形式列出配置中的内容，每项附一行当前值摘要：

   - **公司/身份** — 名称、行业、管辖区域、发展阶段、执业环境 *(跨所有插件共享——修改会同步到 `company-profile` 配置)*
   - **知识产权实务配置** — 纳入范围的知识产权类型（专利[发明专利/实用新型/外观设计]、商标[注册商标/驰名商标]、著作权[作品/软件]、商业秘密、集成电路布图设计），执业方向（申请确权 / 交易许可 / 维权诉讼 / 企业知识产权管理）
   - **风险态度** — 保守 / 中庸 / 激进，每种态度对检索阈值、FTO 自由实施意见、律师函升级的影响
   - **人员** — 知识产权顾问、按知识产权类型分的外部代理机构（专利代理师/商标代理机构/律师事务所）、维权升级链、发明评审委员会
   - **组合** — 专利族（含 PCT 进入中国国家阶段）、商标类别、核心标识、注册国家/地区、监测服务
   - **品牌保护** — 电商平台投诉（阿里巴巴/京东/拼多多等平台投诉策略）、域名抢注处理、合理使用/戏仿判断标准
   - **维权策略** — 何时发律师函 vs. 行政投诉 vs. 民事诉讼 vs. 仲裁；按侵权类型区分的升级触发条件
     - 行政执法：向市场监督管理部门投诉 `[模型知识 — 需核验]`
     - 民事诉讼：向有管辖权的人民法院起诉
     - 仲裁/调解：提交仲裁委员会或调解机构
   - **检索与 FTO** — 检索数据源（国家知识产权局专利检索系统 `[国家知识产权局]`、商标查询系统等）、检索置信阈值、FTO 意见格式
   - **开源审查** — 许可证分级策略、阻断发布许可证清单、新依赖的审查频率
   - **工作流** — 案件工作区（案号、族号）、期限提醒、发明交底表
   - **集成** — 专利管理系统 / 商标管理系统 / 企业通讯工具 / 文档存储状态及备用方案

3. **询问要修改的内容。**

   > 您想调整哪一项？选择一个节，或用自己的话描述修改内容。

4. **执行修改。** 展示当前值，询问新值，说明下游影响，确认后写入配置。

   示例：
   - *添加新的商标监测类别：* "品牌保护将把第 XX 类纳入监测报告，侵权分流将按该类别路由。"
   - *维权策略从激进改为中庸：* "律师函起草将优先提供整改通知选项，而非直接发送停止侵权律师函。"
   - *新增阻断发布的开源许可证：* "开源审查将把含此许可证的依赖标记为阻断，而非警告。"

5. **共享配置修改**（公司名称、行业、管辖区域、执业环境、发展阶段）：写入公司概况配置文件并注明：

   > 此修改影响所有插件——任何读取您管辖区域的插件现在都会看到 [新值]。

6. **结束。**

   > 完成。您的下一次输出将反映此修改。还需要其他调整吗？您可以随时运行 `ip-customize`。

## 护栏

- **禁止删除配置节。** 如果用户想将某个知识产权类型"移除"出范围，将其设为 `[不在当前范围内]` 并说明哪些下游功能将失效。
- **标记内部矛盾。** 如果修改导致配置不一致（例如：商标不在范围内 + 已配置商标监测服务；或激进维权策略 + "所有律师函均由外部律所处理"），标记矛盾。
- **标记护栏降级。** `[需审查]` 标记、来源归属标签、引用法条的 `[需核验]` 标记是承重结构——不得移除。检索置信阈值对 FTO 输出具有承重作用——不得抑制。
- **每次只改一项。** 不要重新发起整个访谈。

## 使用示例

- 示例 1：
  - 场景/输入：用户说"把我的维权策略改成激进"
  - 预期产出：展示当前值（中庸），说明激进策略对律师函、行政投诉、诉讼的影响，确认后写入
  - 关键要点：需确认用户理解激进策略意味着更早发起律师函和诉讼，需标记下游影响

- 示例 2：
  - 场景/输入：用户说"把著作权从范围内移除"
  - 预期产出：将著作权设为 `[不在当前范围内]`，说明著作权相关的监测和维权功能将失效
  - 关键要点：禁止直接删除节，须用占位标记替代

- 示例 3：
  - 场景/输入：用户说"添加一个新的专利族 CN2024XXXXXX"
  - 预期产出：展示当前专利族列表，添加新族，说明对 FTO 和监测的影响
  - 关键要点：需确认专利号格式有效性 `[模型知识 — 需核验]`
