# 法律公众号周报 Skill 安装说明

**版本**：v4.1.1 ｜ **适用**：WorkBuddy / Kimi Code CLI 等支持 SKILL.md 的 AI 智能体环境

## 这是什么

面向法律人（律师/法官/检察官/法务）的公众号实务文章周报助手：

- 首次使用自动引导：选身份（4 种）→ 选执业方向（多选）→ 推荐阅读偏好 → 推荐关注账号
- 已内置 212 个精选法律公众号清单（两高/省高院/头部律所/学术/法律媒体/实务自媒体）
- 每周全量扫描近 7 天新文章 → 五维评分分层（⭐必须看/📌值得看/📄扫一眼）
- 每期 20 篇轻量版或 40 篇完整版，自动生成 Markdown + 浅色 HTML 周报
- 支持手动添加公众号、对标账号分析、反馈自动迭代（越看越准）
- 高价值文章（⭐+📌）可自动入库 IMA 知识库（需自行配置，见 `references/ima-integration.md`）

## 安装方法

**WorkBuddy**：将整个 `法律公众号周报` 文件夹复制到 `~/.workbuddy/skills/` 下（或在技能管理页导入），重启对话后说「帮我做公众号监测」即可。

**Kimi Code CLI**：将整个文件夹复制到 `~/.kimi/skills/` 下，同样以「帮我做公众号监测」触发。

**环境要求**：Python 3.8+（仅标准库，零依赖）；无需任何 API Key。

## 首次使用

对 AI 说「帮我做公众号监测」或「设置公众号监控」，它会引导你完成身份、执业方向、阅读偏好、篇数与推送方式的选择，然后生成第一期周报。按 `references/push-setup.md` 可配置每周一 08:00 自动推送。

## 注意

- `scripts/` 下两个 Python 脚本带完整性自锁，**请勿修改脚本文件本身**，否则脚本将拒绝运行。
- 日常配置请通过 `mpwatch.py` 子命令进行（init/list/add/remove/profile/feedback/stats），不要手改 `assets/accounts.json` 与 `state/` 下的 JSON。
- 个人数据（关注清单、已见库、反馈库）都在技能目录内，更新版本时保留 `assets/accounts.json` 与 `state/` 即可无缝升级，详见 `references/update-guide.md`。
- 问题反馈/获取更新：通过技能市场页面联系作者；版本检查可在技能目录运行 `python3 scripts/mpwatch.py update --check`。
