# 法律公众号推荐目录（按执业方向）

> 用途：用户说「推荐公众号 / 我该关注哪些号」时，按执业方向从本目录挑选推荐。
> 使用前须知：公众号可能改名、停更或主体变更。推荐前用 WebSearch 核实账号当前状态；
> 告知用户「以微信内搜索到的账号主体为准」，不要保证每个号都还存在且活跃。
> 
> **首次部署时**：按用户的执业方向从对应领域各推荐 10-15 个账号，总计可达 99 个。
> 每个号附一句话理由，让用户勾选确认后批量加入关注清单。

## 使用方法

1. 读取用户执业方向（`mpwatch.py profile`；首次部署必先询问）。
2. 首次部署：展示 5 个左右执业方向 +「不区分方向」选项，多选。
3. 按用户所选方向，从对应表格中挑出账号，逐一附理由。
4. 给用户选择：「全部加入 / 挑几个加入 / 分方向选择」。
5. 确认后用 `mpwatch.py add <name> --category <分类> --tags <标签>` 批量写入。
6. 通用础石（法院/检察/媒体）默认清单已有，不重复推荐，除非用户删过。

## 通用础石（任何方向都建议）

最高人民法院、最高人民检察院、本地省高院（按用户城市替换）、人民法院报、法律读库、无讼。
