# 持续更新指南

> 法律公众号周报 v4.0.0 起全部功能免费开放，所有用户均可享受**永久免费更新**。

## 更新机制

| 环节 | 说明 |
|------|------|
| **版本发布** | 作者发布新版本（修复 bug / 新增功能 / 优化算法） |
| **邮件通知** | 作者向所有用户发送更新邮件 |
| **用户更新** | 用户按指南下载并覆盖安装 |
| **验证** | 运行 `selftest` 验证新版本正常 |

## 用户端：如何更新

### 方式一：邮件通知（推荐）

1. 你激活时提供的邮箱会收到更新邮件
2. 邮件包含：新版本号、更新内容、下载链接
3. 按邮件指南下载并覆盖安装

### 方式二：主动检查

```bash
# 检查当前版本
python3 scripts/mpwatch.py update --check

# 查看更新指南
python3 scripts/mpwatch.py update --download
```

### 方式三：GitHub 下载

1. 访问 GitHub 仓库（作者提供链接）
2. 下载最新版本 zip
3. 解压覆盖到 `~/.workbuddy/skills/法律公众号周报/`
4. **保留你的个人数据**：
   - `assets/accounts.json`（你的 212 个关注账号）
   - `state/seen.json`（已见文章库）
   - `state/feedback.json`（你的反馈数据）

### 方式四：一键更新脚本

```bash
# 备份当前版本
cp -r ~/.workbuddy/skills/法律公众号周报 ~/.workbuddy/skills/法律公众号周报-backup

# 下载新版本（作者提供链接后替换 URL）
curl -L -o /tmp/legal-mp-weekly-new.zip <下载链接>
unzip -o /tmp/legal-mp-weekly-new.zip -d ~/.workbuddy/skills/

# 验证
python3 ~/.workbuddy/skills/法律公众号周报/scripts/mpwatch.py selftest
```

## 作者端：如何发布更新

### 发布流程

1. **修改代码**：修复 bug 或新增功能
2. **更新版本号**：
   - 修改 `VERSION` 文件（如 `3.4.0` → `3.5.0`）
   - 修改 `SKILL.md` 中的 `version` 字段
3. **测试**：运行 `selftest` 验证
4. **打包**：`zip -r 法律公众号周报-v3.5.0.zip 法律公众号周报/`
5. **通知用户**：
   - 向订阅更新的用户发送邮件（含下载链接 + 更新内容）
6. **上传**：将新版本上传到 GitHub / 百度网盘 / 小鹅通 / 技能市场

## 常见问题

**Q: 更新会丢失我的数据吗？**
A: 不会。只要保留 `assets/accounts.json` 和 `state/` 目录，你的关注清单、已见文章库、反馈数据都不会丢失。

**Q: 如何回退到旧版本？**
A: 更新前备份了旧版本，直接恢复备份目录即可。

**Q: 多久更新一次？**
A: 根据用户反馈和需求，通常每 2-4 周发布一次小版本更新。
