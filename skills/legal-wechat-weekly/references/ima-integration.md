# IMA 知识库集成指南

法律公众号周报 支持将周报中的高价值文章（⭐ 必须看 + 📌 值得看）自动入库 IMA 知识库，供后续 RAG 检索。

## 前置条件

1. IMA 账号（ima.qq.com 注册，免费）
2. 自建个人知识库（⚠️ 必须是自己的，不能是他人分享的）
3. API 凭证：`client_id` + `api_key`（IMA 开发者设置中获取）
4. 知识库 ID：`knowledge_base_id`（知识库设置中获取）

## 配置步骤

1. 登录 IMA → 左侧「知识库」→「新建」→ 记住名称（如「律师实务文章」）
2. 打开 IMA 开发者设置 → 复制 `client_id` 和 `api_key`
3. 进入知识库 → 设置 → 复制 `knowledge_base_id`
4. 将三个值告诉 Agent，Agent 写入 `~/.config/ima/` 配置

## 入库规则

| 评分档位 | 是否入库 | 说明 |
|---------|---------|------|
| ⭐ 必须看 | ✅ 入库 | 裁判规则、司法解释等最高价值内容 |
| 📌 值得看 | ✅ 入库 | 实务技能、典型案例 |
| 📄 扫一眼 | ❌ 不入库 | 背景参考，避免知识库膨胀 |

## 分类规则

入库时按 `taxonomy.yaml` 关键词自动分配到对应文件夹。10 个分类按优先级排序：

专业领域（建筑工程/劳动法/交通事故 priority=9）> 通用兜底（合同借贷 priority=8）

## 未配置时的行为

如果用户未配置 IMA，自动化流程会：
- 跳过 IMA 入库步骤
- 在最终回复中注明「IMA 未配置，跳过入库」
- 不影响周报生成和 HTML 推送

## 安全

- `client_id` / `api_key` 仅请求 IMA 官方 API（`ima.qq.com`），不发送到其他服务器
- 凭证仅本地存储在 `~/.config/ima/`
- 文章导入的是**你自己的知识库**，不在第三方服务器上
