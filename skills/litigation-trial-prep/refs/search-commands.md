# 元典 MCP 检索命令速查（新增方向）

> 阶段 3.4（承办法官预研）与 3.5（地方司法实践预研）的检索链路。
> 能力边界（2026-08-03 核实）：`rh_ptal_search` 检索列表**不含法官字段**，法官姓名仅在 `rh_case_details` 详情返回；无法官专用过滤字段，须用两步间接法。

## 试点修正（2026-08-03，实跑验证后固化）

1. **法条定位优先 `rh_ft_detail`**：`fgmc`(法规全名)+`ftnum`(条号) 精确命中；`rh_ft_search` 的 `fgmc` 过滤对括号格式（如"解释(一)"半角/全角）敏感易落空，仅作关键词短语辅助。
2. **3.4 一审/二审策略区分**：一审案件公开文书少、承办法官难预先锁定 → 改做**条线画像**（法院/审判条线倾向），个体待传票确认后以 `qw` 反查；标注 `[法官信息未获取]`，不以条线画像冒充个体画像。
3. **3.5 结果过滤**：`xljb_1`=地方司法文件 混入典型案例汇编；按 `xljb_2` 区分——`地方司法文件`=裁判指引/审理意见/会议纪要（有口径价值），`地方典型案例`=案例汇编（按类案处理）。
4. **位阶原则**：地方裁判指引/审判纪要**不得作为裁判依据**，仅作说理参考；与司法解释冲突以司法解释为准（法〔2016〕221号、法释〔2009〕14号第1/7条）。

## 一、地方司法文件检索（阶段 3.5）

**工具：** `mcp__yuandian__yuandian_rh_fg_search`

```jsonc
{
  "dy": "广东",                              // 地域=管辖省（必填方向）
  "xljb_1": "地方司法文件",                   // 效力级别：高院指导意见/审判纪要/裁判指引
  "keyword": "买卖合同 违约金",              // 案由或法律问题关键词（可空，仅过滤）
  "sxx": "现行有效",
  "top_k": 20
}
```

**补充效力级别：** `地方性法规`、`地方政府规章`、`地方规范性文件`、`地方律协规定`。
**返回要点：** `fgmc`(法规名)、`fbbm`(发文机关)、`fwzh`(发文字号)、`sxx`(时效性)、`fbrq/ssrq`、`dy`(地域)。失效文件标注 `[已失效：需核实现行口径]`。全文需再调 `rh_fg_detail`。

## 二、本法院/上级法院同类裁判检索（阶段 3.4 第一步 + 3.5 本地口径）

**工具：** `mcp__yuandian__yuandian_rh_ptal_search`（普通）/ `yuandian_rh_qwal_search`（权威）

```jsonc
{
  "ay": ["离婚纠纷"],
  "jbdw": ["深圳市中级人民法院"],           // 经办法院
  "xzqh_p": ["广东"],                        // 省级行政区
  "wszl": ["判决书"],
  "ja_start": "2023-01-01",                  // 近 N 年
  "top_k": 20
}
```

**注意：** 列表项不含法官字段。`judge[]` 仅在详情接口返回。

## 三、法官姓名提取（阶段 3.4 第二步）

**工具：** `mcp__yuandian__yuandian_rh_case_details`

```
按 id 拉详情 → data[].judge[]（name + role：审判长/审判员）
```

**局限：** `id` 与 `ah` 至少传一个，一次最多返回 10 条。批量确认法官需对每个检索命中逐条拉详情。

## 四、以法官姓名为线索反查（阶段 3.4 第三步）

无专用字段，用全文关键词（间接）：

```jsonc
{
  "ay": ["离婚纠纷"],
  "jbdw": ["深圳市中级人民法院"],
  "qw": "审判员 张三",                      // 全文关键词（该法官历史裁判常出现）
  "search_mode": "or",
  "top_k": 20
}
```

**局限性提示：** 全文检索命中法官姓名不保证其一定是承办法官（可能以合议庭成员、被引案例出现）；最终须以详情接口 `judge[]` 确认。检索不到时标注 `[法官信息未获取]`，不臆造。

## 五、权威案例裁判要点（3.5 第 4 步）

**工具：** `mcp__yuandian__yuandian_rh_qwal_search`

```jsonc
{
  "ay": ["离婚纠纷"],
  "source": ["指导性案例", "公报案例", "典型案例"],
  "top_k": 10
}
```

返回 `content` 优先为裁判要旨/摘要，适合提炼裁判规则。

## 六、新案由画像建设检索清单（阶段 1.5 遇未收录案由时）

| 步 | 目标 | 工具与参数 |
|---|---|---|
| 1 | 管辖规则 | `rh_ft_detail`：fgmc=民事诉讼法/民诉法解释，ftnum=管辖相关条号 |
| 2 | 核心法条 | `law_vector_search`：query="案由+核心争议+请求权基础"，return_num=8；命中后用 `rh_ft_detail` 锚定现行有效条文 |
| 3 | 程序/证据要求 | `rh_ft_search`：keyword="案由+程序节点/证据规则" |
| 4 | 类案规则 | `case_vector_search`：query="案由+常见争议+裁判规则"，return_num=8 |
| 5 | 地方文件 | `rh_fg_search`：xljb_1=地方司法文件 + keyword=案由，逐省扫描；按 xljb_2 区分 `地方司法文件`（口径）与 `地方典型案例`（案例汇编） |
