# 案由画像：机动车交通事故责任纠纷

> 状态：✅ 完整 | 编写日期：2026-08-03 | 法律依据均经元典 MCP 核实（`[法条原文]`）
> 适用范围：机动车之间、机动车与非机动车/行人之间因交通事故引发的损害赔偿，含保险赔付次序。

## 一、案由定位

- **一级案由：** 侵权责任纠纷
- **管辖规则：** 一般由侵权行为地或被告住所地法院管辖 [实务经验 — 需审查]
- **核心特征：** 侵权责任 + 保险赔付次序交织；人身损害赔偿项目多、计算细，城乡标准统一是现行规则。

## 二、核心法律框架速览

| 争议类型 | 请求权/抗辩权基础 | 法条 | 要点 |
|---|---|---|---|
| 侵权责任 | 过错责任 | 第一千一百六十五条 [法条原文] | 过错侵害民事权益担责；过错推定依规定 |
| 赔付次序 | 交强险→商业险→侵权人 | 第一千二百一十三条 [法条原文] | 交强险限额内先行；不足商业险按约；再不足侵权人 |
| 人身损害赔偿 | 医疗/护理/交通/误工等 + 残疾/死亡赔偿金 | 第一千一百七十九条 [法条原文] | 治疗康复合理费用 + 误工；致残辅助器具费+残疾赔偿金；致死丧葬费+死亡赔偿金 |
| 机动车事故责任 | 机动车交通事故责任 | 第一千二百零八条 [法条原文：依照道路交通安全法律和本法承担赔偿责任] | 归责原则与责任形态 |
| 责任认定书 | 交管部门事故认定 | [实务经验 — 需审查] | 作为证据可申请复核 |

## 六、常见陷阱（新手高频错误）

- [ ] **误以为交强险有责才赔** —— 交强险无责任限额内也要赔付 [实务经验 — 需审查]
- [ ] **城乡标准未统一计算** —— 残疾/死亡赔偿金应按统一标准计算 [需审查：现行口径]
- [ ] **赔偿项目遗漏** —— 被扶养人生活费、精神损害抚慰金、营养费、交通费漏算 [实务经验 — 需审查]
- [ ] **赔付次序错误** —— 未按交强险→商业险→侵权人顺序主张 [法条原文：第1213条]
- [ ] **误工费举证不足** —— 无稳定收入证明时标准确定困难 [实务经验 — 需审查]
- [ ] **工伤/交通事故竞合处理不清** —— 通勤途中事故的竞合与并存主张 [实务经验 — 需审查]

## 七、高频争议焦点

1. 事故责任划分（认定书与过错）
2. 各赔偿项目的计算（医疗、误工、护理、残疾/死亡赔偿金等）
3. 交强险、商业险赔付次序与限额
4. 伤残等级鉴定意见的采信
5. 责任主体（驾驶人/车主/挂靠人/雇主）
6. 精神损害抚慰金与其他项目并存

## 八、本案由特有的事实盲区

| 盲区 | 预判发问方向 | 补证建议 |
|---|---|---|
| 事故经过 | "事故怎么发生的？车速多少？有无违章？" | 现场照片、行车记录、目击者 |
| 治疗与康复 | "住了多久院？后续还需治疗吗？" | 病历、医嘱、费用票据 |
| 工作与收入 | "受伤前做什么工作？月收入多少？" | 劳动合同、流水、单位证明 |
| 车辆与保险 | "车谁开的？谁的车？保了什么险？" | 证件、保单、挂靠协议 |
| 责任认定 | "对认定书服不服？申请复核了吗？" | 认定书、复核结果 |
