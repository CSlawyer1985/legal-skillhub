## 六、常见陷阱（新手高频错误）

> 每条标注来源。

- [ ] **只主张"虚假出资"却未准备"加速到期"论证**：被告以出资期限未届（期限利益）抗辩时，若无执行终本+破产原因，补充赔偿请求会被驳回。须同时准备九民纪要§6例外 / 新法54条 `[实务经验 — 需审查]`
- [ ] **未调取银行流水**：仅凭"无验资报告"认定虚假出资，证明力弱于"股东与公司间无出资款项往来"的银行流水证据 `[类案裁判 — yuandian检索]`
- [ ] **遗漏发起人连带责任**：设立时其他发起人对设立时出资瑕疵连带，勿遗漏 `[法条原文]`
- [ ] **未区分"未届期转让"与"已届期未缴即转让"**：二者原股东责任不同 `[法条原文]`
- [ ] **破产受理后仍以个人名义追缴**：构成个别清偿，被驳回起诉 `[类案裁判 — yuandian检索]`——**最高风险**
- [ ] **混淆未出资与抽逃出资**：证明路径不同（未出资=从未缴纳；抽逃=缴纳后转出）
- [ ] **以"公司尚有应收款/对外债权"视为有清偿能力**：法院明确"应收款未实际实现前不能视为可供执行财产" `[类案裁判 — yuandian检索]`

## 七、高频争议焦点

1. **股东是否已实际履行出资义务**（举证责任在股东，解释三20条）
2. **未届出资期限的股东出资义务是否加速到期**（九民纪要§6例外/新法54条/时间效力）
3. **公司是否"不能清偿到期债务"**（执行终本=穷尽执行措施；破产原因；多案未履行）
4. **名义股东/代持抗辩是否成立**（解释三26条：不免责）
5. **未出资股权转让后原股东与受让人的责任划分**（解释三18条、新法88条不溯及）
6. **公司破产受理后追缴主体与个别清偿禁止**（破产法35条）
