# GitHub 自助上传指引

作者：李时瑀律师

本文件只说明本地准备步骤，不代表已经发布。

## 发布前

1. 确认仓库名称和公开范围仅为普通直租。
2. 确认最终许可证，并把对应许可证正文保存为仓库根目录 `LICENSE`。
3. 运行 `python3 scripts/validate-release.py . --for-publication`；许可证未确认时该命令应保持发布 HOLD。
4. 检查 `SKILL.md`、`README.md`、`llms.txt`、`llms-full.txt` 与 `knowledge/` 内部链接。
5. 核验 `checksums.sha256`、三份 DOCX 模板和 ZIP 解压结果。
6. 确认仓库中没有 private/pro 内容、源映射、原始路径、案件正文或识别信息。

## 本地 Git 初始化

完成上述门禁后再初始化本地 Git。不要把令牌、Cookie、会话文件或本机配置写入仓库。

然后在 GitHub 新建空仓库，按 GitHub 页面给出的命令添加远程并推送。包内没有自动发布脚本，任何远程写入都需要单独授权。

## 上传后

- 在 GitHub 页面复查文件树和许可证展示；
- 从仓库重新下载一次，复跑隐私和链接审计；
- 对任何法律命题仍以现行权威文本回读为准；
- 发现泄漏或错误时先暂停公开，再修复并重新审查。
