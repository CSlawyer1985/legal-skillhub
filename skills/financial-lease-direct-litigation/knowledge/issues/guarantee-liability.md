# 保证责任审查

## 基础问题

1. 保证文件是否与主合同和具体债务清晰关联；
2. 保证方式、范围和期间如何约定；
3. 签署权限和形式是否符合要求；
4. 主合同变更、展期、调解或其他后续安排是否影响保证责任；
5. 催告、通知和权利主张是否有证据；
6. 是否存在多个增信主体及责任重叠问题。

## 使用纪律

历史裁判或旧模板中的保证结论不得直接移用于当前案件。应结合签署时间、合同文本、后续变更及现行规则逐项核验。
