# 所有权、取回与价值清算

## 审查对象

- 租赁物所有权取得与保留；
- 登记或其他公示材料；
- 承租人的占有、使用、维修和保险义务；
- 租赁物现状、位置、控制和第三人权利；
- 返还、取回、保管、评估、处分和价款冲抵。

## 状态必须分开

申请保全不等于法院已经查控；法院控制不等于已完成返还；取回不等于已经处分；处分不等于价款已实际到账；部分回款不等于债权已全部实现。
