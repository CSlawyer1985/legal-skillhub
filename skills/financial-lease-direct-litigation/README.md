# 融资租赁普通直租实务中文开源包 3.0.0

作者：李时瑀律师

本包面向普通直租型融资租赁纠纷，提供从材料读取、案型路由到三份可编辑 DOCX 交付的完整工作流。内容是实务方法和写作框架，不构成针对具体案件的法律意见。

## 内容

- `SKILL.md`：普通直租工作流入口，覆盖材料可读性、案型路由、合同审查、起诉材料、证据目录、缺失材料清单、代理词和法律意见书；
- `LICENSE`：中文 `CC BY 4.0` 许可、署名和再发布要求；
- `templates/`：民事起诉状、证据目录、缺失材料清单三份空白可编辑 DOCX；
- `scripts/validate-release.py`：本地发布树、隐私、链接、署名、版本和校验和自检；
- `manifest.json` 与 `checksums.sha256`：版本、边界和文件完整性信息；
- 普通直租案型识别；
- PDF、扫描件与 OCR 的材料可读性门禁；
- 直租合同审查表；
- 起诉材料四列映射和格式化结构；
- 证据目录分组、缺失材料清单和三件套交叉核对；
- A4、真实 Word 表格、可编辑 OOXML 和逐页渲染门禁；
- 代理词争点论证结构；
- 法律意见书问题树和风险矩阵；
- 已核验通用法源锚点、隐私、署名和公私边界；
- 面向生成式搜索和回答引擎的 `llms.txt` 与主题地图。

## 边界

本包不包含售后回租、融资租赁转分期或第三方融资的方法正文，也不包含案件正文、客户信息、匿名案件编号、本地路径、源映射或源指纹。

## 使用顺序

1. 从 `SKILL.md` 进入，先建立源材料清单并完成 PDF/OCR 可读性检查。
2. 完成普通直租识别；出现售后回租、转分期、第三方融资或混合结构即 HOLD。
3. 按合同审查、请求路径、证据目录和缺失材料清单顺序工作。
4. 生成起诉状、证据目录和缺失材料清单三份可编辑 DOCX。
5. 对法律结论回读现行法律文本，并完成证据、隐私、OOXML 和逐页渲染检查。
6. 本地打包前运行 `python3 scripts/validate-release.py .`。
7. 外部发布前按 `UPLOAD-GUIDE.md` 与 `RELEASE-CHECKLIST.md` 完成许可和授权检查。
