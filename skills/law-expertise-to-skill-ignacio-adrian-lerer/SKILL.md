# 法律专业知识转化为 Skill

使用本 skill 将法律专业人员的知识转化为简单、安全的 skill 包。

## 输入

接受：

- 法律工作流笔记、备忘录、意见、检查清单、模板、谈判立场、审计标准或审查标准。
- 目标法律任务的简短描述。
- 用户关于该 skill 应做或不应做什么的反馈。

除非用户确认有权使用，否则不使用私人客户材料、律所保密知识、受特权保护的通信或个人痕迹。

## 工作流

1. 定义法律能力：该 skill 帮助做什么、为谁、在哪个法律体系或执业领域下。
2. 定义来源边界：使用了哪些材料、排除了哪些材料，以及证据是第一手的、公开的、生成的还是用户描述的。
3. 仅提取可复用的能力：
   - 问题发现标准；
   - 审查顺序；
   - 风险分类法；
   - 起草或谈判启发式；
   - 升级阈值；
   - 必需的免责声明或来源核验。
4. 将能力与声音分离：
   - 能力是允许的。
   - 专业语气指引是允许的。
   - 人设模拟或身份替代是不允许的。
5. 添加安全边界：
   - 不提供超出 skill 范围的法律意见；
   - 不作无支撑的辖区主张；
   - 不进行隐藏的来源推断；
   - 不复用保密数据；
   - 实质性决定需要人工律师复核。
6. 产出一份紧凑的 skill，包含：
   - 清晰的触发条件；
   - 负面范围；
   - 分步方法；
   - 输出格式；
   - 核验检查清单。

## 输出

返回：

- `What this skill does`（该 skill 做什么）：简短的市场描述。
- `How to use`（如何使用）：面向用户的说明。
- `SKILL.md`：可移植的 skill 文本。
- `Source boundaries`（来源边界）：使用了哪些证据、未使用哪些。
- `Human review points`（人工复核点）：需要律师作出的决定。

## 拒绝 / 升级

当用户要求以下内容时，拒绝或请求澄清：

- 未经同意模仿真实律师；
- 无权限使用他人的私人痕迹；
- 隐藏来源限制；
- 从高风险法律工作中移除人工复核要求；
- 将 skill 呈现为真实个人本人或保证的法律意见。
