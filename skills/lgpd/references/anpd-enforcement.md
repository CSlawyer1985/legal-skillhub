# ANPD 执法参考

## 国家数据保护局（ANPD）

巴西国家数据保护机构，由第 13,853/2019 号法律设立，为联邦政府组成部分，具有技术和决策自主权。

**网站：** https://www.gov.br/anpd/pt-br
**联系方式：** anpd@anpd.gov.br

---

## ANPD 组织结构

- **董事会（Conselho Diretor）：** 5 名董事，由巴西总统任命；4 年交错任期
- **国家个人数据与隐私保护委员会（CNPD）：** 咨询机构；由公民社会、政府和专家代表组成
- **内部结构：** 执法、监管、国际事务、通信部门

---

## 执法程序

### 阶段 1——初步调查（Processo Administrativo Preliminar）
1. ANPD 收到投诉、监测信号或自行启动的移送
2. 初步调查以决定是否启动正式程序
3. 期限：通常 60 天（可延长）
4. 可联系控制者/处理者索取信息

### 阶段 2——行政调查（Processo Administrativo Sancionador）
1. 向被指控方发出正式通知
2. 辩护权：15 个工作日提交答辩
3. 证据收集，必要时举行听证
4. 报告官员起草决定草案
5. 董事会表决决定
6. 作出最终行政决定

### 阶段 3——上诉
1. 决定可在 10 个工作日内向 ANPD 董事会内部上诉
2. ANPD 上诉后：可在联邦区法院进行司法审查

### 时间线
- **时效：** 自 ANPD 知悉之日起 5 年（第 54 条）
- **投诉回应：** ANPD 旨在 30 天内回应投诉（实践中各异）

## 罚款计算方法

### 简单罚款（第 52 条第 II 项）
**上限：** 巴西收入（上一财政年度）的 2% 或每次违规 5000 万雷亚尔，取较低者。

**对于公司集团：** 集团巴西收入的 2%。

**考虑因素（第 52 条第 1 款）：**

| 因素 | 影响 |
|--------|--------|
| 违规的严重性和性质 | 越严重 → 罚款越高 |
| 数据主体的善意 | 减轻 |
| 从违规中获得的利益 | 利益越大 → 罚款越高 |
| 控制者的状况（规模、经济地位） | 相称性 |
| 累犯 | 加重 |
| 损害程度 | 损害越大 → 罚款越高 |
| 与调查的合作 | 减轻 |
| 善意和内部控制 | 减轻 |
| 纠正措施的及时性 | 减轻 |
| 相称性和必要性 | 基准考量 |

### 日罚款（第 52 条第 III 项）
每日累加以强制合规；同一每次违规 5000 万雷亚尔上限。

### 多项违规
每项违规可分别处理。多项罚款可叠加。

## 执法优先事项（ANPD 战略议程）

ANPD 已指明优先关注领域：
1. **大规模数据泄露**——影响众多巴西人的事件
2. **无法律依据的敏感数据处理**——健康、生物识别、金融
3. **儿童数据**——无可验证父母同意的处理
4. **国际传输**——向无充分保护国家的传输
5. **未回应数据主体权利**——特别是访问和删除
6. **未指定 DPO**——对须指定 DPO 的控制者

## 值得注意的 ANPD 执法行动

### 电话营销/呼叫中心行业（2023）
ANPD 调查多家公司未经充分法律依据为电话营销非法处理个人数据。发出警告和整改令。

### 卫生部门数据共享（2022-2023）
ANPD 调查未经明确同意与第三方共享健康数据（敏感数据）。发出合规令。

### 大规模数据泄露调查
ANPD 在影响数百万巴西人 CPF（纳税人识别号）的重大数据泄露后启动调查。截至 2025 年罚款状态待定。

### 澄清令
ANPD 已发出大量“Comunicados”和“Notas de Esclarecimento”，就特定主题（面部识别、Cookie、员工监测）设定部门预期。

## 与其他机构的合作

### 巴西机构
- **SENACON（国家消费者秘书处）：** 消费者保护——在影响消费者的事项上联合执法
- **CADE（经济防卫行政委员会）：** 竞争——数据与市场支配力互动
- **中央银行：** 金融数据监督
- **ANS/ANVISA：** 卫生部门数据

### 国际合作
ANPD 已与以下机构签署谅解备忘录：
- 葡萄牙 DPA（CNPD——葡萄牙）
- 乌拉圭机构（URCDP）
- CNIL（法国）
- 英国 ICO
- 伊比利亚-美洲数据保护网络（RIPD）

ANPD 参与全球隐私大会（GPA）。

## 投诉提交程序

数据主体可向 ANPD 提交投诉：https://www.gov.br/anpd/pt-br/assuntos/peticoes

**所需信息：**
- 数据主体身份（巴西居民须提供 CPF）
- 控制者身份（CNPJ/名称）
- 涉嫌违规的说明
- 如有证据请提供
- 已向控制者行使的权利

**ANPD 首先将投诉转交控制者**（给予解决机会）；如未解决则升级为调查。

## LGPD 与巴西其他法律义务

| 法律 | 与 LGPD 的相互作用 |
|-----|----------------------|
| 《消费者保护法典》（CDC） | LGPD 就数据补充 CDC；CDC 救济仍适用 |
| 《互联网民典》（MCI） | MCI 管辖互联网中介机构；LGPD 适用于个人数据 |
| 金融部门 LGPD | 中央银行法规 + LGPD |
| 卫生部门 | ANVISA/ANS 规则 + LGPD（对健康/敏感数据更严格） |
| 信用报告（正向征信） | 第 7 条第 X 项——信用保护的特定法律依据 |
