# 巴西《通用数据保护法》（LGPD）技能

> ⚠️ **免责声明：**本技能基于经 2019 年第 13,853 号法律修正的第 13,709/2018 号法律（LGPD）及 ANPD 决议提供信息性指引。不构成法律意见。涉及 ANPD 执法、高风险处理或复杂国际传输安排的事项，请咨询合格的巴西数据保护律师或您指定的 DPO（Encarregado）。

---

## 1. 本技能做什么？

LGPD 合规技能将 Claude 转变为具备《通用数据保护法》（LGPD）——经 2019 年第 13,853 号法律修正的第 13,709/2018 号法律——全面知识以及所有相关 ANPD（国家数据保护局）决议（包括设定 3 个工作日泄露通知要求的 CD/ANPD 第 15/2024 号决议）的巴西数据保护专家顾问。

> **2026 年更新——巴西-欧盟相互充分性认定：**2026 年 1 月 26-27 日，欧盟委员会根据 GDPR 第 45 条正式通过了针对巴西的充分性认定决定，同时巴西 ANPD 承认欧盟为充分的传输目的地。这种相互充分性**消除了巴西 ↔ 欧盟个人数据流动对 SCC、BCR 或其他传输保障措施的需要**。本技能已更新（v1.5.0，2026 年 7 月），在国际传输部分、LGPD 与 GDPR 对比表以及差距评估工作流中反映了这一变化。

本技能覆盖完整的 LGPD 合规生命周期。它对照常规个人数据的全部 10 种法律依据（第 7 条）和敏感数据更严格的依据（第 11 条）分析处理活动，指导组织履行第 17-22 条下的数据主体权利，生成包含第 9 条所有要求要素的 LGPD 合规隐私通知，并协助第 48 条下的数据泄露通知工作流。本技能还支持第 41 条下的 DPO（Encarregado）任命、第 37 条下的处理活动记录（RoPA）、第 38 条下的数据保护影响评估（RIPD/DPIA）以及第 33-36 条下的国际数据传输合规——包括 2026 年 1 月具有里程碑意义的巴西-欧盟充分性认定。

本技能对同时横跨巴西和欧盟运营的组织尤其有价值，因为它明确将 LGPD 要求与 GDPR 对应物映射——突出关键差异，包括 10 种与 6 种法律依据、3 个工作日与 72 小时的泄露通知时限、始终强制的 DPO 与 GDPR 有条件性的 DPO 义务，以及 5000 万雷亚尔与 2000 万欧元的罚款上限。

所有回复都引用与问题相关的具体 LGPD 条文（如"第 7 条第 IX 项"或"第 48 条第 1 款"）。输出格式随任务调整：评估用结构化差距表、泄露响应和数据主体请求用分步工作流、隐私通知和 RIPD 用完整文档模板、一般问题用带条文引用的清晰叙述。

## 2. 目标受众

| 受众 | 使用方式 |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **数据保护官（Encarregados）** | 起草隐私通知、管理 DSR 工作流、协调 ANPD 泄露通知、维护 RoPA |
| **法律顾问** | 分析处理的法律依据、审查处理者协议、评估第 52 条下的处罚敞口 |
| **合规经理** | 开展 LGPD 差距评估、构建合规路线图、为 ANPD 调查做准备 |
| **软件工程师和架构师** | 理解隐私设计义务（第 49 条）、评估数据流是否符合 LGPD |
| **产品经理** | 确定新功能的法律依据、确保同意机制符合第 8 条标准 |
| **人力资源团队** | 理解员工数据处理中的 LGPD 义务、处理员工的 DSR |
| **市场营销团队** | 评估同意的有效性、管理退出机制、理解儿童数据规则（第 14 条） |
| **跨国公司** | 比较 LGPD 与 GDPR 义务、协调双法域合规计划 |

## 4. 如何使用本技能

### 安装

1. 从本文件夹下载 `lgpd.skill`
2. 在 Claude 中，进入**设置 → 技能**
3. 点击**上传技能**并选择 `lgpd.skill`
4. 该技能现在在所有 Claude 会话中生效

### 触发技能

当您提出 LGPD 或巴西数据保护话题时，技能自动激活。无需特殊命令。触发技能的示例自然语言短语：

- _"这是 LGPD 合规的吗？"_
- _"我们为巴西用户处理数据"_
- _"ANPD 对泄露通知有什么要求？"_
- _"为我们的巴西业务起草一份隐私通知"_
- _"我们在巴西的数据主体权利义务是什么？"_
- _"LGPD 与 GDPR 相比如何？"_
- _"我们需要为巴西任命一名 DPO"_

### 示例提示

```
我们是一家总部位于美国的 SaaS 公司，最近开始为巴西客户提供服务。
我们收集姓名、电邮和使用分析数据。我们受 LGPD 管辖吗？如果受管辖，
我们应该采取的前五个合规步骤是什么？
```

```
我们在巴西制造工厂使用生物识别数据（指纹）进行员工考勤。
第 11 条下我们可以使用什么法律依据，我们需要实施哪些额外保障措施？
```

```
为我们的巴西 B2C 移动应用起草一份 LGPD 合规隐私通知。
我们收集姓名、电邮、电话号码、位置数据和购买历史。
我们与支付处理商和分析服务商共享数据。
```

```
我们发现了一起勒索软件攻击，加密了包含约 50,000 名巴西客户个人数据的
数据库。请带我们走完完整的 ANPD 泄露通知流程，包括初步和完整报告要求。
```

```
将我们的 GDPR 合规计划与 LGPD 要求进行比较，并识别我们需要弥合的差距。
重点关注：DPO 义务、法律依据、泄露通知时限、儿童数据规则和处罚敞口。
```

## 5. 技能实现细节

### 架构

```
plugins/lgpd/
└── skills/
    └── lgpd/
        ├── SKILL.md                        # 核心技能——响应格式规则、LGPD 结构
        │                                   #   概览、所有法律依据、数据主体权利、
        │                                   #   控制者/处理者义务、6 个核心工作流、
        │                                   #   LGPD 与 GDPR 对比表
        └── references/
            ├── lgpd-articles.md            # LGPD 逐条摘要（第 1-55-L 条）
            │                               #   包括截至 2025 年的所有 ANPD 决议
            ├── anpd-enforcement.md         # ANPD 组织结构、执法流程
            │                               #   （3 个阶段）、罚款计算方法、
            │                               #   执法优先项、重大行动、
            │                               #   投诉提交流程
            └── compliance-program.md       # 4 阶段合规路线图、RoPA 模板、
                                            #   DSR 程序、RIPD/DPIA 模板、
                                            #   泄露通知模板（初步
                                            #   和完整）、DPO 职位描述、差距检查清单
```

### SKILL.md 的内容

- 专家角色：具备 LGPD 和 ANPD 知识的巴西数据保护顾问
- 将任务类型映射到结构化输出的响应格式表（差距评估、法律依据分析、政策起草、DSR 工作流、RIPD、泄露响应、处罚敞口、问答）
- LGPD 范围和外域效力（第 3 条）及豁免（第 4 条）
- 全部 10 项第 6 条原则及描述
- 常规个人数据的全部 10 种第 7 条法律依据及关键要求
- 第 11 条敏感个人数据依据及类别
- 完整的数据主体权利表（第 17-22 条）及响应时限
- 控制者和处理者义务（第 37-41 条）
- 同意要求（第 8 条）——六项有效性标准
- 国际传输机制（第 33-36 条）
- 安全和事件响应（第 46-48 条），包括 3 天初步通知
- ANPD 制裁表（第 52 条），含全部 8 种制裁类型
- 6 个详细工作流（法律依据、差距评估、隐私通知、DSR、泄露响应、LGPD 与 GDPR）
