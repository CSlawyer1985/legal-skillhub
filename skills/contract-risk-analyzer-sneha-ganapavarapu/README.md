# 合同风险分析器（Contract Risk Analyzer）

一个为没有法律培训的创始人和早期公司打造的实用合同分析技能。

## 本技能做什么

分析决定交易成败的五类关键条款：
- **责任限制（Limitation of Liability）** —— 财务敞口上限
- **赔偿（Indemnities）** —— 出问题时谁买单
- **知识产权所有权（IP Ownership）** —— 你创造的东西归谁
- **数据保护（Data Protection）** —— 数据处理的法律义务
- **终止（Termination）** —— 退出灵活性和合同后义务

对每个条款，您会得到通俗英语的解释、需要注意的具体危险信号，以及您可以实际使用的谈判语言。

## 适用对象

正在审查供应商协议、服务合同和合作伙伴交易、但没有常聘律师的创始人和早期创业者。

## 使用方法

1. 上传或粘贴您的合同
2. 回答关于该交易的澄清问题
3. 审查五个条款的风险分析
4. 使用建议的谈判语言对不利条款进行反驳
5. 签署前请律师审查

## 免责声明

本技能提供分析和指导，**不构成法律意见**。每份合同都不同。请用本分析为您的决策提供信息，而非替代专业法律顾问。您对自己所同意内容的后果负责。
