# AI数据合规冷启动（Skill 参赛说明）

> **一句话定位**：律师说一句话，四步交付一套完整的 AI 数据合规尽调启动包——从零到"可以进企业访谈"。

---

## 一、解决什么问题

律师接到 AI+产业合规需求（智能客服、AI 陪伴、医疗 AI、金融风控……）时，面对的是从零开始的庞大工程：

- 不知道要问客户哪些问题、问多细
- 不知道数据流向图、三层流程图怎么画才专业
- 106 项调研表、319 项风险指标从哪来、怎么用
- 每项调研背后的法律依据是什么、条款号对不对（法规还在修订）
- 进企业调研前要准备哪些文件、访谈问什么

传统做法：靠律师个人经验 + 大量人工整理，周期以周计，质量因人而异。

## 二、核心工作流：四步冷启动

```
律师一句话描述产业
  ↓ ① intake 对话式引导（按需追问，信息足够自动收口）
  ↓ ② kb-build 知识库引用复用（论文/实务/法规三库，零复制）
  ↓ ③ model-generate + render（三层流程图 + 数据流图 + 评估报告）
  ↓ ④ field-pack 进企文件包（7 份 Word，一次生成）
交付：全景交付.html（三图合一）+ 7 份 Word + 评估报告
```

## 三、突出特点

### 1. 确定性制图：同输入必同输出

数据流图与三层流程图采用**模板画布 + 坐标契约**架构：固定画布、参数化场景视图、确定性路由公式。换一个产业只改场景 JSON，出图质量恒定——**零重叠、零斜线、端口锁定、标签永不碰撞**，并通过 fail-fast 校验器与自检脚本双重验证。渲染引擎内嵌开源 diagram-design（MIT），视觉为编辑器级设计系统（发丝线、直角、语义色 token），可直接用于正式交付。

### 2. 规则驱动的行业定制：全局领域规则库

`field-extensions.json` 全局规则库承载 AI 嵌入领域的**专项合规知识**：医疗健康（7 项专项调研 + 5 项专项指标 + 3 部专项法规）、拟人化互动类 AI（12 + 7 + 5）。律师的 intake 描述命中领域关键词，专项调研项/评估指标**自动追加**到文件包；新增领域只需复制 JSON 条目。规则全局共享，改一次、全项目生效。

### 3. 法律依据全程核验：不靠记忆写条款

调研表 106 项、风险指标 319 项**全部挂接现行有效法律条款**（个保法/数安法/网安法/生成式AI暂行办法），条款内容与编号经元典法律数据库逐条核验。核验中实际发现：**网安法 2025 修正版将等级保护义务从第 21 条移位至第 23 条**——凭记忆写旧条款号即错。文件底部附核验声明，可直接引用。

### 4. 情形化裁剪：不给客户灌全套

106/319 全量项按 intake 信号**自动标记"不适用"**（已确认无跨境 → 出境项裁剪；不处理生物识别 → 相关项裁剪；不面向未成年人 → 保护项裁剪）。**不物理删除、保留复核痕迹、事实变化可恢复**——符合法律工作纪律。

### 5. 强制边界与独立验证

AIDC-001~008 强制边界贯穿全程：候选材料标注、五类证据标签、事实门禁（门禁未过不产出结论）、本地数据处理、相对路径记录、独立验证器验收。端到端验收脚本、三场景回归、三轮稳定性测试持续通过。

## 四、使用方式

用户只需要一句话：

> 帮我启动一个AI数据合规项目，产品是拟人化互动类AI（面向C端用户的AI陪伴产品，有拟人形象和语音互动）

Skill 自行完成追问、建库、出图、生成文件包。

## 五、技术底座

- **渲染**：内嵌 diagram-design（MIT，vendor 化）Data flow / Swimlane 类型，确定性公式实现（Python）
- **文档**：python-docx 生成 7 份 Word（表格宽度 A4 校验、字体/版式统一）
- **法条核验**：元典开放平台 API（条文全文拉取 + 条款核验，检索记录本地归档）
- **验收**：`run_coldstart_acceptance.py`（四步端到端）、`self_check.py`（可访问性 SVG 合同）、三轮稳定性哈希回归

## 六、成果形态

一次运行产出：

| 类别 | 产物 |
|---|---|
| 图 | 三层流程图（Swimlane）、数据流图（Data flow）、全景交付.html（三图合一页签） |
| 报告 | 评估报告（六节：概览/风险清单/书面闸门/文书清单/法源引用/待核验项） |
| Word | 信息调研表、风险识别表、访谈提纲（90 行）、进企文件清单、数据资产盘点清单、现场核查表、保密承诺与进场授权函 |
