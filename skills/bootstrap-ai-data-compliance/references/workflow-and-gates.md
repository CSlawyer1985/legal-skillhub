# 工作流和门禁

## 阶段

| 阶段 | 生产动作 | 独立验收属性 |
|---|---|---|
| initialized | 建立配置、状态和目录 | 配置完整、目录相对、无覆盖 |
| baseline_locked | 盘点输入文件并计算SHA-256 | 清单非空、路径唯一、哈希有效 |
| evidence_ready | 建立五类CSV和SQLite | ID唯一、引用可达、证据标签合法 |
| startup_pack_ready | 生成7份客户启动Word文件 | 文件齐全、候选边界存在、ZIP可读 |
| facts_verified | 核验客户事实门禁 | 7项门禁全部满足、事实记录已确认 |
| candidate_ready | 生成候选交付Word包 | 候选标识、证据索引和未决事项齐全 |
| validated_archived | 独立验证并归档 | 当前产物通过、哈希清单与ZIP一致 |

## 事实门禁

`04_fact_verification/gate_evidence.json`必须明确记录：P0资料、访谈确认、数据地图、系统地图、角色矩阵、授权和供应商、未确认事实清单、范围变化以及律师复核字段。全部布尔条件为真，且`fact_records.csv`不存在“待核实”或空状态，才允许推进。

## 错误语义

- 0：命令成功或重复执行无变化。
- 2：输入、配置或命令错误。
- 3：门禁阻断。
- 4：成果冲突或基线变化。
- 5：独立验收失败。

不得使用自动修复掩盖门禁错误。修正输入后重新运行相同阶段。
