## 1. 分类备忘录

对正式法律/合规评估使用本模板。这是主要记录。

```markdown

| 字段 | 值 |
|-------|-------|
| **系统名称** | [AI 系统名称] |
| **版本/发布** | [版本标识符] |
| **提供者** | [法人名称、国家] |
| **部署者** | [法人名称、国家] |
| **评估日期** | [YYYY-MM-DD] |
| **评估人** | [姓名、职务] |
| **审查日期** | [YYYY-MM-DD——建议在12个月内或在重大变更时] |

## 系统描述

**预期用途：** [系统设计用于做什么]

**输入：** [数据类型和来源]

**输出：** [决定、建议、评分、内容等]

**受影响人员：** [系统输出影响的对象——员工、客户、公民等]

**部署地域：** [系统在何处运行及在欧盟影响谁]

**GPAI 模型依赖：** [如适用：模型名称、提供者、版本]

## 分类决策树

- [ ] 系统投放欧盟市场或在欧盟投入服务

- **角色认定：** 提供者 / 部署者 / 进口商 / 分销商

**结论：** [范围内 / 范围外——附理由]

### 第2步——禁止行为（第5条）
对每个第5条类别记录评估：

| 类别 | 是否适用？ | 理由 |
|----------|------------|-----------|
| 操纵/欺骗 | 是 / 否 | [简要理由] |
| 利用脆弱性 | 是 / 否 | [简要理由] |
| 社会评分 | 是 / 否 | [简要理由] |
| 个体预测性警务 | 是 / 否 | [简要理由] |
| 无针对性面部图像抓取 | 是 / 否 | [简要理由] |
| 工作场所/教育中的情绪识别 | 是 / 否 | [简要理由] |
| 生物特征分类（敏感） | 是 / 否 | [简要理由] |
| 实时远程生物特征识别（执法） | 是 / 否 | [简要理由] |

**结论：** [不属禁止 / 依第5(1)(x)条属禁止——如属禁止则停止]

### 第3步——高风险评估

**附件 I（受监管产品）：**
- 产品制度： [MDR / 机械 / 航空 / 不适用]
- 安全组件： [是 / 否]
- 第三方合格评定： [是 / 否]

**附件 III（用例）：**
- 匹配类别： [类别编号和名称，或不适用]
- 决策影响： [AI 如何影响已识别领域的决策]

**主张第6(3)条例外：** [是 / 否]
- 如是： [该例外适用的详细理由]

**结论：** [高风险（附件 I/III，类别 X）/ 非高风险]

### 第4步——GPAI 评估
- 使用 GPAI 模型： [是 / 否]
- 模型： [名称、提供者]
- 系统性风险分类： [是 / 否 / 未知]
- 第53条文档可用： [是 / 否 / 部分]

**结论：** [GPAI 义务适用 / 不适用]

### 第5步——有限风险（第50条）
- 需披露的 AI 互动： [是 / 否]
- 深度伪造/合成内容： [是 / 否]
- 情绪识别： [是 / 否]
- 生物特征分类： [是 / 否]

**结论：** [第50条透明度义务适用 / 不适用]

| 分类 | 结果 |
|---------------|--------|
| **风险等级** | [禁止 / 高风险 / 有限风险 / 最低风险] |

[基于现行法时间线的适用期限——例如“附件 III 高风险系统为2026年8月2日”。如用户正在规划长期工作，还须注明2026年5月7日的临时性《数字综合法案》协议——如正式通过，附件 III 将推迟至2027年12月2日，同时明确该协议尚非有约束力的法律。]

## 假设与缺口

[记录因信息不完整而作出的任何假设，并标注需要解决的缺口]

1. [具体后续步骤]
2. [待解决的未决事项]
```

## 4. 使用说明

### 何时使用哪个模板

| 交付物 | 受众 | 时机 |
|------------|----------|------|
| **分类备忘录** | 法务、合规、内部审计 | 每次分类——这是正式记录 |
| **风险登记簿条目** | 合规团队、风险管理 | 分类之后——维护活登记簿 |
| **高管摘要** | 高管层、董事会、业务领导 | 需要高管关注的高风险或禁止性结论 |

### 格式指引

- 填写所有字段。使用“N/A”或“不适用”，而非留空。
- 对假设，明确说明假设了什么以及何种证据可解决该假设。
- 所有评估标注日期并设定审查日期（最少每年一次，或在系统重大变更时）。
- 链接至支持证据（风险管理文件、技术文档、测试结果），而非复制内容。

### 定稿前质量检查

- [ ] 每条条款引用均已对照条例 (EU) 2024/1689 核实
- [ ] 所有八个第5条类别均已明确评估（即使明显不适用）
- [ ] 即使未使用 GPAI 模型，也纳入 GPAI 评估
- [ ] 如在德国/奥地利/瑞士部署，已处理 DACH 专项考量
- [ ] 合规期限已按时间线正确识别
- [ ] 假设和缺口已明确标注
- [ ] 已包含免责声明
