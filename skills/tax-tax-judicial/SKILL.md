## 能为你做什么（涉税司法四大场景）
---

### 一、虚开专票罪量刑与出罪规则
- ⚖️ **三档量刑**：虚开税款数额对应不同量刑档次，须准确评估风险级别
- 🛡️ **出罪规则**：不以骗抵税款为目的、未造成税款被骗损失的（虚增业绩、融资、贷款等），不以本罪论处
- ⚠️ **刑事红线**：虚开、骗退、逃税触及刑法，单位与个人双罚

**典型问法：**
```
"虚开专票罪怎么量刑？"
"什么情况不构成虚开？"
```

### 二、下游受票方权利保护
- 🛡️ **复议诉权**：上游虚开认定对下游构成直接实际影响的，下游企业具有复议申请权
- 📋 **善意取得抗辩**：证明不知情、真实交易、合理对价，争取不罚仅补税
- 🔗 **证据链**：留存完整业务证据链应对牵连

**典型问法：**
```
"下游受票方有什么权利？"
"收到异常凭证怎么办？"
```

### 三、税务争议与程序合法性
- 🏛️ **机械征税撤销**：税务机关事实不清、程序瑕疵的征税行为可被撤销，须按实际占有使用情况公正执法
- ⚖️ **行政诉讼**：纳税人可对不当税务处理提起行政诉讼
- 🔍 **合法性审查**：评估税务处理的事实与程序合法性

**典型问法：**
```
"机械征税可以起诉吗？"
"税务处理被撤销的情形有哪些？"
```

### 四、危害税收征管犯罪典型案例
- 📚 **典型案例**：逃税（阴阳合同）、骗取出口退税、非法出售专票、虚开等定罪边界
- 🧭 **界分规则**：虚开与逃税界分坚持主客观相统一
- 🛡️ **合规防火墙**：建立内控防范刑事与行政风险

**典型问法：**
```
"阴阳合同逃税怎么判？"
"最高法涉税典型案例有哪些？"
```

---

### 最高法1669/1671号：虚开改判逃税与逃税二元框架
- ⚖️ **虚开改判逃税**：最高法典型案例明确虚开与逃税罪边界，部分情形虚开被改判逃税，影响定性、量刑与出罪路径
- 🔀 **二元框架**：逃税“原则不追、例外可追”的二元处理框架细化，初犯补缴可不予追究刑事责任的适用边界更清晰
- 🛡️ **出罪策略**：结合交易真实性与税款损失结果，评估虚开/逃税定性对下游受票方诉权与刑事责任的影响

**典型问法：**
"虚开和逃税怎么区分？"
"最高法案例对虚开定罪有什么影响？"

## 重要提示与边界声明

**重要提示**
1. **刑事红线须避**：虚开、骗退、逃税触及刑法，须确保交易真实、目的正当。
2. **出罪证据须备**：无骗抵目的且未造成损失的情形须留存证据链。
3. **程序权利须用**：下游受票方善用复议申请权与诉权，主张善意取得。
4. **以官方为准**：司法裁判规则持续演进，具体以最新司法解释与生效判决为准。

**边界（本技能不做的）**
