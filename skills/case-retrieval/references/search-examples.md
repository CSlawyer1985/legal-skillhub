# 案例检索 CLI 场景指南

本指南承接 `case-retrieval` 的可变命令示例、参数组织和结果映射。使用前必须先执行 [cli-common.md](./cli-common.md) 中的前置检查和命令发现步骤。

## 一、CLI 命令使用原则

1. 先用 `npx @delilegal/deli-cli@latest cmds case-retrieval@1.0.0` 获取本次 `RUN id`、命令名和参数。
2. 后续调用必须采用当次返回的 `npx @delilegal/deli-cli@latest run_... <command> [options]` 形态。
3. 不在本指南中固化真实命令名；以下示例中的 `case-list`、`case-search`、`similar-case` 仅表示可能的命令类型，实际以 `cmds` 输出为准。
4. 检索参数优先在 `cmds` 返回的 `usage` 和 `params` 中选择，不主动假设 `--long-text`、`--query`、`--page`、`--size` 或排序参数一定存在。
5. 一个检索目标默认只调用一次；结果不足时先说明不足，并提出建议改写检索式，等待用户确认。
6. 当用户提供事实经过、诉请抗辩、争议焦点或材料摘要，且 `cmds` 同时支持 `--long-text` 和 `--keywords` 时，首次必须使用 `--long-text`；不得先执行 `--keywords` 预检索。
7. 长文本检索已有有效命中时，停止继续检索；不得再拆成关键词追加调用。

示例 `cmds` 返回后，实际调用可能形如：

```bash
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 case-list --query "民间借贷 利率上限"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 case-list --query "(2023)粤03民终12345号"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 similar-case --long-text "自然人之间签订借款协议，借款本金120万元，约定年利率10%，借款期限届满后借款人未归还本金和利息，出借人起诉主张本金、期内利息和逾期利息。"
```

以上仅为参数组织示例。正式执行时必须替换为当次 `cmds` 返回的 `run_...`、命令名和参数。

## 二、关键词与长文本组织

### 关键词检索

适用于用户明确给出短检索标签：

- 案由：民间借贷纠纷、房屋买卖合同纠纷、劳动争议
- 法院或法院层级：深圳中院、最高人民法院、广东高院
- 案号：完整案号
- 年份、文书类型、核心争议焦点

组织规则：

- 控制在 2-8 个核心词。
- 把法院、年份、文书类型等筛选信息写入同一个检索主题，除非 `cmds` 明确返回结构化筛选参数。
- 不把案件事实拆成大量关键词堆叠。

示例主题：

```text
深圳市中级人民法院 小产权房买卖合同 判决书 2023
最高人民法院 民间借贷 利率上限
(2023)粤03民终12345号
```

### 长文本或事实摘要检索

适用于用户提供案件材料、事实经过、履行过程、诉请抗辩或多个争议焦点，需要匹配相似案例。

组织规则：

- 提炼 100-800 字事实摘要。
- 包含主体关系、法律关系、关键行为、诉讼请求、抗辩理由和争议焦点。
- 删除无关背景、情绪表达和重复附件内容。
- 将事实摘要直接传给 `--long-text`、相似案例或事实摘要参数；不要先拆成 `--keywords`。
- 如果 `--long-text` 返回有效结果，不再执行关键词检索。

示例摘要：

```text
劳动者入职后长期加班，公司未足额支付加班费，后以绩效不达标为由解除劳动合同。劳动者主张违法解除赔偿金和加班工资，公司抗辩绩效考核不合格且已履行通知程序，争议焦点为解除理由是否成立、加班事实如何举证以及赔偿金计算。
```

## 三、典型场景

### 1. 案由或争议焦点检索

用户输入：

```text
查一下借款合同纠纷的案例
```

处理：

1. 抽取案由或争议焦点。
2. 用 `cmds` 返回的案例检索命令执行一次关键词检索。
3. 输出案例列表、关键字段和可进一步查看的方向。

建议检索主题：

```text
借款合同纠纷
```

### 2. 法院、时间和文书类型组合检索

用户输入：

```text
找一下深圳中院近三年关于小产权房买卖合同纠纷的判决书
```

处理：

1. 抽取法院、时间、案由、文书类型。
2. 若 `cmds` 支持结构化筛选，按返回参数传入；否则合并为一个检索主题。
3. 如首次结果不理想，只给出一个建议改写主题，不自动追加多次检索。

建议检索主题：

```text
深圳市中级人民法院 小产权房 买卖合同纠纷 判决书 近三年
```

### 3. 案号精准检索

用户输入：

```text
帮我查一下案号 (2023)粤03民终12345号的判决
```

处理：

1. 保留完整案号。
2. 使用案例检索命令执行一次检索。
3. 若无结果，说明数据库可能未收录或案号有误，并建议用户核对案号。

### 4. 类案匹配

用户输入：

```text
我上传了一份劳动争议案件材料，帮我找类似案例
```

处理：

1. 从材料中提取事实摘要。
2. 优先使用 `cmds` 返回的长文本、相似案例或事实摘要参数，并只调用一次。
3. 如果长文本参数不可用，才降级为关键词检索；降级时说明原因。
4. 输出相似案例列表、相似点、差异点和可参考裁判规则。

本用户输入属于类案匹配：

```text
劳动者入职后长期加班，公司未足额支付加班费，后以绩效不达标为由解除劳动合同。劳动者主张违法解除赔偿金和加班工资，公司抗辩绩效考核不合格且已履行通知程序，争议焦点为解除理由是否成立、加班事实如何举证以及赔偿金计算。
```

若 `cmds` 返回的案例检索命令支持 `--long-text`，应直接执行一次长文本检索，不得先拆成“加班费 绩效不达标 违法解除劳动合同 赔偿金”等关键词组合。

### 5. 翻页或查看更多

用户输入：

```text
再看一些
```

处理：

1. 先说明继续查看会产生一次新的 CLI 调用。
2. 用户确认后，沿用上一轮检索条件。
3. 按 `cmds` 当前返回的分页参数形态请求下一页。

## 四、CLI 返回结果映射

将 CLI 返回内容写入最终答复时，优先保留：

- 案号
- 案件名称
- 案由
- 审理法院
- 审理程序
- 文书类型
- 裁判日期
- 公布类型
- 裁判观点、法院认为或内容摘要
- 数据来源或收录说明

如果 CLI 未返回某字段，不要补写。可标注“CLI 未返回”或省略该列。

## 五、无结果或结果不足

出现无结果、结果明显失焦、字段缺失或命令不可用时：

- 标注“检索受限”“结果不足”或“命令不可用”。
- 给出一个建议改写的检索主题或事实摘要。
- 不自动连续换词重试。
- 不编造案号、法院、裁判日期、裁判结果或裁判观点。
