# 特殊场景附录

步骤 1 信息采集完成后，根据发函方/致送对象的特殊身份/状态匹配对应场景规则。

## 一、破产/清算场景

**触发信号**发函方处于破产清算/重整/和解程序中；或致送对象已进入破产程序。

### 发函方处于破产清算中

| 要素 | 补充规则 |
|------|---------|
| **法律依据** | 优先引用《企业破产法》第 31 条（管理人撤销权）、第 32 条（个别清偿撤销）、第 16 条（个别清偿无效）、第 112 条（变价出售）、第 113 条（清偿顺序） |
| **措辞限定** | 涉及资产处置、权利处分时须加"以不违反破产法及破产管理人审查要求为限"等限定语；避免作出超出破产程序框架的承诺 |
| **风险提示** | 主动披露破产程序对函告事项的约束——如资产移交可能触发管理人审查、无偿转让面临撤销风险 |
| **债权人利益** | 涉及资产处置或权利让渡时须点明"保障全体债权人合法权益"的原则约束 |
| **姿态** | 客观陈述破产程序的法定限制，不做超出权限的承诺，也不以此为由回避应尽的配合义务 |

### 致送对象处于破产清算中

| 要素 | 补充规则 |
|------|---------|
| **申报指引** | 催告函/通知函中增加债权申报提示告知对方应依破产法第 45 条向管理人申报债权 |
| **程序优先** | 明确"个别追偿须中止，统一通过破产程序处理" |
| **警示调整** | recipient-profiles.md 的定制化警示语中，诉讼/执行类后果替换为破产程序后果（债权申报期限、分配比例不确定性、未申报失权等） |

### 破产场景常见措辞参考

- "我方目前处于破产清算程序中，所有资产处置须经受破产管理人审查，以保障全体债权人公平受偿。"
- "根据《中华人民共和国企业破产法》第三十一条，人民法院受理破产申请前一年内涉及债务人财产的无偿转让行为，管理人有权请求人民法院予以撤销。"
- "前述安排须以不违反破产法关于债务人财产变价与分配的相关规定为前提。"

## 二、国资/政府背景交易对手

**触发信号**致送对象为国有企业、事业单位、政府机关；或合同涉及财政资金/政府采购。

| 要素 | 补充规则 |
|------|---------|
| **法律依据** | 除合同法和行业法外，补充引用国资监管法规（如《企业国有资产法》《企业国有资产交易监督管理办法》） |
| **程序提示** | 主动提示对方须履行的内部审批/报备程序；涉及国有资产处置时提示评估、进场交易等法定要求 |
| **信访/监察** | 适当提示对方"亦可向贵单位上级主管部门/纪检监察机构反映" |
| **措辞** | 保持对公权力主体的基本尊重；不越权指导对方内部管理；不渲染"行政问责""纪委调查"等超越民事函告范畴的后果 |
| **语气** | 正式、克制，减少商业修辞，增加程序性/合规性表述 |

## 三、群体性纠纷场景

**触发信号**致送对象为业主委员会、业主大会、村民委员会、居民委员会等群体性组织；或函告事项涉及众多利害关系人。

| 要素 | 补充规则 |
|------|---------|
| **公共利益** | 权衡"个体权益"与"公共利益/多数人利益"的平衡，不因维护己方权益而忽视公共影响 |
| **程序合规** | 强调己方行为的程序合规性（经XX程序/XX表决），不给对方以"程序瑕疵"的攻击点 |
| **建设性姿态** | 主动提出不损害公共利益的折中方案，避免将所有争议捆绑逼迫对方全盘接受 |
| **措辞** | 避免"贵方代表""个别人"等可能被视为人身指向的表述；对群体性组织以全称/法定称谓为准 |
| **后续动作** | 优先安排双方正式会议/沟通，提示"避免影响广大业主/居民/商户正常秩序" |
| **文风铁律** | 铁律④「共情仅限一句」在群体性场景可适度放宽开篇可表达对公共利益的理解，但正文仍须以事实和法律为中心 |

### 群体性纠纷常见措辞参考

- "为保障广大业主/商户的正常用水用电，我方愿意先行配合办理……，此系基于公共利益考量的善意安排。"
- "上述安排不构成对任何一方实体权利的确认或放弃，旨在避免争议期间影响[商贸中心/小区]的正常运营秩序。"

## 四、跨场景叠加

当函告同时触发多个特殊场景，须叠加适用各场景规则。冲突时按以下优先序位

1. 破产/清算场景（最高优先——法定程序约束不可逾越）
2. 群体性纠纷场景
3. 国资/政府背景场景

叠加时，措辞和依据取各场景中更严格/更正式的要求，避免"合意优先于法定"或"商业修辞冲淡程序合规"。

## 五、承诺函特殊场景适配

### 承诺人处于破产清算中

| 要素 | 补充规则 |
|------|---------|
| **效力限定** | 承诺函末尾须加注"本承诺函项下承诺人的义务以不违反《中华人民共和国企业破产法》及破产管理人审查要求为限。" |
| **撤销风险提示** | 涉及无偿/低价转让、个别清偿等行为须提示破产管理人撤销权（破产法第 31、32 条） |
| **措辞限定** | 涉及资产处置、权利处分时避免绝对化承诺，加"以破产管理人许可为前提"等限定语 |
| **不可撤销条款调整** | L2 强化承诺的"不可撤销的承诺"表述须调整为"除破产法另有规定外，本承诺不可撤销" |

### 致送对象为国资/政府背景

| 要素 | 补充规则 |
|------|---------|
| **法律依据** | 在风险披露或法律适用段中补充引用《企业国有资产法》《企业国有资产交易监督管理办法》等 |
| **程序提示** | 提示对方履行的内部审批/报备程序 |
| **语气** | 保持对公权力主体和国有资产监管体系的基本尊重，措辞正式克制 |

## 六、步骤集成

1. **检测时机**步骤 1 信息采集完成后检测
2. **规则叠加**匹配后从本文件读取对应规则，叠加至步骤 4（策略定级）和步骤 5（起草）
3. **向用户提示**检测到特殊场景时在步骤 4 说明适用规则，征得确认后继续
4. **不确定时**默认不适用特殊场景规则，但提示用户可指定
