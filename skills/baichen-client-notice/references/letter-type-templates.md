# 八类函告结构模板速查

步骤 4-5 提供八类客户自署函告的结构定义。

**通用原则**
- 标题默认「关于……的[函告类型]」，可切换两字空格格式（如「说 明 函」）
- 标题后必须加独立**称谓行**「致[致送对象全称]」（支持多对象并列）
- 除承诺函外均须含「拟采取的后续动作」段落；承诺函以「法律适用与争议解决」替代
- 常规 ~1200-2000 字（承诺函 ~800-1500 字），复杂可至 3000-4000 字
- 己方称"我方"/"本公司"/"我司"/"本人"，对方公司称"贵司"，个人称"贵方"，对公机构（仲裁委／监管机关／行业协会）按性质称"贵委"/"贵会"/"贵局"/"贵厅"
- **发函方信息块**支持落款模式（默认）和置顶模式

## 段落排列规则

正文段落 → [后续动作+保留权利声明（催告/通知/声明）| 举报请求（举报函）| 法律适用与争议解决（承诺函）] → 敬语 → 落款

| 规则 | 说明 |
|------|------|
| 后续动作 | 可独立成段（五类默认）或嵌入各主题段（回复函）。承诺函以「法律适用与争议解决」替代 |
| 保留权利声明 | 仅催告/通知/声明三类需要。催告/通知用标准模板；声明函用自定义模板 |
| 敬语→落款 | 八类统一置于函件末尾 |

## 编号使用原则

| 编号模式 | 适用类型 | 特征 |
|---------|---------|------|
| **自然段落流** | 催告函、**说明函（默认）** | 因果/递进连接推进，全文不启用段落编号；说明函仅在事项≥3 项且确需分条时改用「（一）（二）」编号 |
| **主题编号** | 回复函、（可选）说明函 | 按争议/事项主题分节（说明函默认不用，见上） |
| **结构化编号** | 通知函、声明函、汇报函 | 保留「一、二、三……」编号 |
| **条款式编号** | 承诺函 | 承诺事项以编号条款推进，每条可独立执行 |
| **叙事驱动** | 举报函 | "首先、其次、最后"递进；请求段编号；证据编号 |

## 开篇模式四分类

| 开篇模式 | 适用类型 | 示例 |
|---------|---------|------|
| **自发型** | 催告函、通知函、声明函 | "[发函方]就……事宜，特此函告如下" |
| **回应型** | 回复函、说明函 | "贵方于[日期]发来的《……》已收悉" |
| **汇报型** | 汇报函 | "现就……汇报如下" |
| **鉴于型** | 承诺函 | "经审慎考虑，承诺人在此郑重承诺如下" |

## 一、催告函

**结构**标题 → 称谓行 → [信息块] → 段1（函告事由）→ 段2（合同核心约定）→ 段3（我方履约+对方违约+金额明细）→ 段4（法律定性+催告要求）→ 段5（后续动作，**必须**匹配 recipient-profiles.md 定制警示语）→ 保留权利声明 → 敬语 → 落款+联系方式

| 要素 | 要求 |
|------|------|
| 语气 | 礼貌而坚定，"请贵方…"代替"要求贵方…"，威慑力靠法律后果客观陈述 |
| 篇幅 | ~1200-2000 字 |
| 叙事线 | 合同约定→我方履约→对方违约→金额明细→法律定性→催告要求，连续叙事 |
| 后续动作 | 单层（对方不履行的应对），**必须**匹配 recipient-profiles.md |
| 事实 | 按时间线叙事，每个违约节点标注证据来源；合同条款不逐款抄写 |
| 金额 | 大小写兼顾，违约金注明计算公式和起止日期 |
| 要件拆解 | 对方可能提出抗辩时，拆解违约构成要件为独立要素逐条对照论证 |

---

## 二、回复函

**结构**标题 → 称谓行 → [信息块] → 开篇段（来函引述+核心立场概括+回函目的）→ 各主题段（每段内闭环引述对方主张→事实与合同分析→该主题结论与后续安排）→ 敬语 → 落款+联系方式

回复函以**争议主题**为组织骨架。对核心争议启用深度论证（拆解为逻辑层，逐层递进反驳），非核心争议可主动让步或释放善意。

| 要素 | 要求 |
|------|------|
| 语气 | 理性克制，以事实和合同回应，不逐条激辩 |
| 篇幅 | ~1200-2000 字，多争议主题可至 3500 字 |
| 叙事线 | 开篇引述→主题1（引述→分析→结论→后续）→主题2→……→结尾总结 |
| 后续动作 | 嵌入各主题段结论中 |
| 引述 | 准确引用来函原文要点，不可曲解 |
| 论证 | 对方核心主张须**深度论证**（拆解为逻辑层逐层递进反驳） |
| 条件分析 | 对方援引条款时，拆解触发条件逐条匹配事实 |

---

## 三、说明函

**结构** 标题 → 称谓行 → [信息块] → 开篇（身份＋事由＋目的，可合一段）→ 事项说明（**默认自然段落流**：以因果/递进连接推进；事项≥3 项且确需分条时用「（一）（二）」编号，每条 3-5 句，附客观依据）→ [相关依据（如与说明已融合可省略）] → 结论 → 拟采取的后续动作（双轨：对方有疑问／无法达成一致）→ 敬语 → 落款+联系方式

> 与 ../SKILL.md 铁律①「以逻辑代编号」一致：说明函**默认不启用**「一、二、三」段落编号；编号仅为事项≥3 项时的可选手段。

| 要素 | 要求 |
|------|------|
| 语气 | 平实、坦诚、不卑不亢 |
| 篇幅 | ~1200-2000 字，多事项可至 3500 字 |
| 叙事线 | 背景 → 事项说明（事实+依据，因果/递进推进）→ 结论 |
| 后续动作 | 双轨（对方有疑问/无法达成一致），体现合作姿态 |
| 客观性 | 不回避不利事实但措辞得体 |

---

## 四、通知函

**结构**标题 → 称谓行 → [信息块] → 一、通知事项（首段点明核心，合同+法律双支撑）→ 二、事实与依据 → 三、生效与期限（明确收到之日/具体日期）→ 四、拟采取的后续动作（双轨）→ 五、保留权利声明 → 敬语 → 落款+联系方式

| 要素 | 要求 |
|------|------|
| 语气 | 明确而克制，通知事项不容含糊 |
| 篇幅 | ~1200-2000 字 |
| 叙事线 | 通知事项→事实与依据→生效与期限→配合要求 |
| 后续动作 | 双轨（正常流程/对方不配合应对） |
| 要件拆解 | 行使合同解除权须拆解法定/约定解除要件逐条匹配事实 |

---

## 五、声明函

**结构**标题 → 称谓行 → [信息块] → 一、声明背景 → 二、声明内容（逐条核心声明+简要事实支撑）→ 三、拟采取的后续动作（证据保全→平台投诉→诉讼，路径清晰）→ 四、保留权利声明（自定义模板）→ 敬语 → 落款+联系方式

| 要素 | 要求 |
|------|------|
| 语气 | 严肃而有分寸，措辞克制而有分量 |
| 篇幅 | ~1200-2000 字 |
| 叙事线 | 声明背景→逐条声明→后续止损路径 |
| 后续动作 | 单层（侧重止损和追责路径） |
| 要件拆解 | 驳斥不实信息时，将对方陈述拆解为可证伪的独立事实命题逐一回应 |

---

## 六、汇报函

**结构**标题 → 称谓行 → [信息块] → 一、汇报背景 → 二、进展情况（数据化，按时间/模块组织）→ 三、存在的问题与风险（每问题附原因+影响；涉及法律风险须法条→判例→判断）→ 四、拟采取的后续动作（下一步计划+需对方配合事项）→ 敬语 → 落款+联系方式

| 要素 | 要求 |
|------|------|
| 语气 | 平实、坦诚、职业化 |
| 篇幅 | ~1200-2000 字，涉及核查/审计数据时可至 4000 字 |
| 叙事线 | 汇报背景→进展（数据化）→问题与风险（含法律分析）→后续工作计划 |
| 后续动作 | 双轨（下一步工作计划/需对方配合事项），列明时间节点 |
| 第三方背书 | 涉及核查/审计时，精确引用报告全称+编号+出具日期+核心结论 |

## 七、承诺函

**适用场景**十大场景域——私募/投资、并购交易、公司治理、合规/监管、融资/担保、知识产权、劳动/人事、房地产/工程、政府/行政、诉讼/争议。

**通用骨架**（按场景域变体速查表调整鉴于段和承诺条款重心）

标题 → 称谓行 → [信息块] → 鉴于/背景段（按场景域选择变体，风险告知用精准限定语）→ "经审慎考虑，承诺人在此郑重承诺如下" → 一、核心承诺事项 → 二、责任/义务条款 → 三、违约/损失赔偿条款 → 四、兜底条款（含"不可撤销的承诺"+"不因[情形]而免除"）→ 法律适用与争议解决 → 敬语 → 落款+联系方式

| 场景域 | 鉴于段核心 | 承诺条款重心 |
|--------|----------|------------|
| 私募/投资 | 风险披露文件→知情确认 | 按比例承担返还→依通知返还→退出不免除 |
| 并购交易 | 交易概要+承诺人角色 | 配合反垄断审查→过渡期行为约束→违约赔偿 |
| 公司治理 | 主体关系+承诺事由 | 一致行动/不竞争/关联交易回避→期限与地域 |
| 合规/监管 | 适用法规依据+合规现状 | 持续合规义务→接受检查/审计→违规报告 |
| 融资/担保 | 主债务描述+增信目的 | 流动性支持/连带责任→追偿路径→主债务变更不影响 |
| 知识产权 | 权利状况+出具目的 | 权属无瑕疵→不侵犯第三方→侵权赔偿 |
| 劳动/人事 | 劳动关系+义务范围 | 竞业范围+期限/保密→违约金（须符合《劳动合同法》第22/23条） |
| 房地产/工程 | 项目概况+承诺事由 | 质量达标→按期交付→农民工工资支付→安全施工 |
| 政府/行政 | 申报项目+真实性声明 | 材料真实性→后续配合核查→虚假申报的行政/刑事责任 |
| 诉讼/争议 | 争议背景+和解概要 | 履行和解方案→逾期违约责任→不可撤销 |

| 要素 | 要求 |
|------|------|
| 语气 | 郑重而审慎 |
| 篇幅 | ~800-1500 字（承诺事项 3-5 条），融资/并购可至 2500 字 |
| 叙事线 | 身份声明→鉴于→经审慎考虑→承诺事项（编号条款）→兜底→法律适用/管辖→落款 |
| 后续动作 | **不适用**。以「法律适用与争议解决」替代 |
| 鉴于段 | **必须**要素，风险告知使用精准限定语 |
| 承诺事项 | 编号条款推进，每条可独立执行，金额大小写兼顾 |
| 兜底条款 | **必须**含"不可撤销的承诺"+"不因[情形]而免除" |
| 法律适用+争议解决 | **必须**独立段落。劳动类注意仲裁前置 |

## 八、举报函

**标题双模式**极简型「举 报 函」（默认）/ 描述型「关于……的举报信」
**称谓双模式**简洁型「致[部门全称]」（默认）/ 正式型「尊敬的[部门]领导」

**结构**标题 → 称谓行 → [信息块（推荐含举报人/电话/被举报人/任职单位/职务/举报事由）] → 开篇（身份自适应，协助性姿态）→ 被举报人信息块（如信息块已含可跳过）→ 事实与理由（完整叙事+「首先其次最后」分析→综上→结论）→ 举报请求（「现要求一、二、三、」与致送部门一一对应）→ [配合承诺段（可选）] → [如实举报提示段（**强制**）] → 敬语 → 落款 → 附证据

| 要素 | 要求 |
|------|------|
| 语气 | 正式克制。允许适度评价（"严重违反""公然藐视"）和正面定性（"涉嫌构成……"），禁止侮辱、诽谤、恐吓 |
| 篇幅 | ~800-1200 字（不含附证据和附法条） |
| 叙事线 | 被举报人信息→事实叙事→分析（首先其次最后→综上）→引法条→请求编号→证据 |
| 开篇 | 身份嵌入首句，协助性姿态（"为协助贵[部门]维护……"） |
| 分析 | 「首先其次最后」三段递进，法条首次引用全称+标注简称 |
| **如实举报提示**（强制） | 必须附《刑法》第243条诬告陷害罪提示 |
| **禁止绝对化** | 禁止"肯定""一定""绝对"等无证据支撑的断言 |

## 通用落款格式

**落款模式**函件编号+日期在落款区。公司→全称+（公章）+法定代表人/授权代表签字行+日期+联系方式；个人→签名行+日期+联系方式。

**置顶模式**信息块已含全部信息，落款仅保留署名+联系方式。
