# 可复用用语库

步骤 5 起草时引用，确保跨函件语言一致。
## 一、风险披露用语（承诺函/汇报函 L2）

精准限定语充分披露而不越位定性。

| 用语文类 | 标准表述 | 适用场景 |
|---------|---------|---------|
| 法律状态不确定 | "……的法律定性存在不确定性" | 减资/回购/合规状态待厘清 |
| 可能性限定 | "可能构成……" | 行为定性不确定 |
| 风险存在声明 | "存在……的风险" | 前瞻性风险 |
| 追索风险 | "面临……追索" | 债权人/第三方主张 |
| 障碍风险 | "……存在推进障碍的风险" | 程序/审批障碍 |
| 延伸风险兜底 | "包括但不限于……或其他原因" | L2 强化承诺/风险预警汇报 |
| 知情确认 | "承诺人已知悉，[文件]对[事项]所涉全部风险事项已作完整披露" | 承诺函鉴于段 |
| 自愿声明 | "在对上述风险充分知悉并认可的前提下，自愿参与……" | 承诺函知情确认后 |
## 二、后果清单用语（催告函/通知函/声明函）

商业+法律后果叠加构建施压，替代法条引用。
### 2.1 商业后果

| 后果类型 | 标准表述 |
|---------|---------|
| 合作影响 | "可能影响双方后续合作的正常推进" |
| 信用影响 | "可能对贵方商业信用记录造成不利影响" |
| 行业影响 | "此举可能引起行业主管部门/行业协会关注" |
| 供应中断 | "我方将暂停后续供货/服务" |
| 额外成本 | "贵方将额外承担因延期产生的仓储费/保管费/资金占用成本" |
| 违约金 | "按合同第[X]条约定的每日万分之[五]计收违约金（自[起始日]起至实际履行日止，计算公式[本金]×[万分之X]×[天数]）" |
### 2.2 法律后果

| 后果类型 | 标准表述 |
|---------|---------|
| 委托律师 | "我方将委托律师启动全部法律程序" |
| 费用承担 | "届时贵方除应付款项外还将承担逾期利息、诉讼费、保全费、律师费等全部费用" |
| 财产保全 | "我方将依法申请财产保全，贵方银行账户及资产可能被冻结/查封" |
| 执行后果 | "判决生效后如贵方未主动履行，我方将申请强制执行，届时贵方将面临限制消费、纳入失信被执行人名单等后果" |
### 2.3 后果清单模板（催告函尾部）

```
如贵方未能在上述期限内履行义务，我方将
一、按合同第[X]条约定的每日万分之[五]标准计收违约金（自[起始日]至实际履行日）；
二、暂停后续批次供货/服务，并保留就停产/停服损失另行索赔的权利；
三、委托律师启动全部法律程序，届时贵方除应付款项及违约金外，还将承担我方为实现债权而支出的诉讼费、保全费、律师费等全部费用。
```
## 三、合同→事实对照用语

不下结论，让合同约定与事实的差距自己说话。

| 话术模式 | 示例 |
|---------|------|
| 合同约定 → 实际情况 | "根据双方《XX合同》第[X]条，贵方应于[X月X日]前支付[XX元]。截至本函发出之日，我方尚未收到上述款项。" |
| 期限逾期陈述 | "自合同约定的付款期限届满至今已逾[XX]天。" |
| 多次催告记录 | "我方分别于[X月X日]、[X月X日]通过[微信/邮件/电话]方式与贵方沟通，但至今未收到实质性回复。" |
| 金额对照（大小写） | "截至本函发出之日，贵方应付未付金额合计人民币[XX元]（[大写]整）。" |
## 四、开篇模式用语

| 开篇模式 | 适用类型 | 标准表述 |
|---------|---------|---------|
| 自发型 | 催告/通知/声明 | "[发函方]就[事项]事宜，特此函告如下" |
| 回应型 | 回复/说明 | "贵方于[日期]发来的《[来函标题]》已收悉。就来函所涉[事项]，现函复/说明如下" |
| 汇报型 | 汇报 | "根据[约定/要求]，现就[事项]的进展汇报如下" |
| 鉴于型 | 承诺 | "[承诺人]作为[身份]，已收到并审慎阅读[文件]。承诺人已知悉……经审慎考虑，承诺人在此郑重承诺如下" |

## 六、过渡连接用语

| 逻辑关系 | 推荐用词 | 避免用词 |
|---------|---------|---------|
| 转折 | "然而""但" | "但是令人遗憾的是""岂料" |
| 因果 | "据此""因此""有鉴于此" | "所以" |
| 递进 | "此外""同时""进一步而言" | "然后""而且" |
| 列举 | "其一……其二……"（仅金额分列/条款拆解时） | 全文"第一……第二……" |
| 限定 | "据了解""据我方记录""目前" | "显然""毫无疑问" |
## 七、称谓一致性

| 对象 | 称谓 |
|------|------|
| 己方（公司） | "我方"/"本公司"/"我司" |
| 己方（个人） | "本人" |
| 对方（公司） | "贵司" |
| 对方（个人） | "贵方" |
| 机构／主管机关 | "贵委"/"贵会"/"贵局"（按机构性质；仲裁机构→"贵委"） |
| 承诺人（公司） | "承诺人"/"本公司" |
| 承诺人（个人） | "承诺人"/"本人" |
## 八、举报函用语
### 8.1 开篇（身份自适应）

| 举报人类型 | 标准表述 |
|-----------|---------|
| 个人 | 「为协助贵[部门]维护[领域]秩序，保障[利益]，本人[姓名]（身份证号[号码]）现就[被举报人][事项]举报如下。」 |
| 公司 | 「为协助贵[部门]维护[领域]秩序，保障[利益]，[公司全称]（统一社会信用代码[代码]）现就[被举报人][事项]举报如下。」 |
### 8.2 被举报人信息块

| 被举报人类型 | 标准表述 |
|-------------|---------|
| 个人 | 「被举报人[姓名]，身份证号[号码]，户籍地[地址]，居住地[地址]，关联主体[公司]」 |
| 公司 | 「被举报单位[全称]，统一社会信用代码[代码]，住所地[地址]，负责人[姓名]」 |
### 8.3 递进分析

「本人认为/本公司认为，首先、[事实对照，指出矛盾]。其次、[引用法律禁止性规定，精确到条款项]。最后、[综合违法后果]。综上，[结论]。」
### 8.4 举报请求

「根据[法条依据]，本人/本公司特向贵[部门]提出实名举报，现要求」
### 8.5 结尾敬语

「此致 敬礼」（举报函唯一敬语，不适用其他变体）
### 8.6 证据列表

「附证据如下」
「1、[证据1]」
「2、[证据2]」
### 8.7 称谓

| 对象 | 称谓 |
|------|------|
| 己方（个人） | "本人" |
| 己方（公司） | "本公司"/"我司" |
| 监管部门 | "贵会"/"贵厅"/"贵局"（按惯例） |
| 被举报人 | 直呼姓名/公司全称 |
### 8.8 标题双模式

| 模式 | 标准表述 |
|------|---------|
| 极简型（默认） | 「举报信」 |
| 描述型 | 「关于[被举报人][事项]的举报信」 |
### 8.9 称谓双模式

| 模式 | 标准表述 |
|------|---------|
| 简洁型（默认） | 「致[部门全称]」 |
| 正式型 | 「尊敬的[部门]领导」 |
### 8.10 配合承诺段（可选）

「举报人愿以公民身份，积极配合监管部门提供相关线索与证据，坚决维护国家金融法治与[领域]安全。」
### 8.11 评价性用语

举报函允许适度评价，区别于其他函告的严格中立

| 用语文类 | 标准表述 | 适用场景 |
|---------|---------|---------|
| 严重性评价 | 「此举不仅是对法律的公然藐视，更给国家财政资金安全埋下巨大隐患」 | 描述违法情节严重时 |
| 定性结论 | 「涉嫌构成……」「依法应予查处」 | 分析段结论处 |
| 力度结尾 | 「国家金融秩序不容破坏，国有资产不容侵犯」 | 配合承诺段前 |
| 禁止越界 | 禁止侮辱、诽谤、恐吓、情绪失控；禁止「必将」「一定」「毫无疑问」等绝对化判断 | 全程 |
### 8.12 如实举报提示（举报函强制）

举报函生成后须在合适位置附加如实举报义务提示

「举报人已知悉并承诺以上举报内容均有真实证据支撑，举报人愿对所举报内容的真实性承担法律责任。根据《中华人民共和国刑法》第二百四十三条，捏造事实诬告陷害他人，意图使他人受刑事追究，情节严重的，处三年以下有期徒刑、拘役或者管制；造成严重后果的，处三年以上十年以下有期徒刑。」
## 使用指引

1. 按需引用对应语类，标准表述须嵌入具体案情数据后使用
2. 风险披露用语在承诺函鉴于段和汇报函 L2 问题段中**强制**使用
3. 后果清单在催告函/通知函尾部**强制**使用
4. 合同→事实对照在催告函/回复函/通知函中**强制**使用，替代法律定性结论
5. 开篇模式和结尾敬语按函告类型匹配，严禁混用
6. 举报函开篇和递进分析用语**强制**使用
7. 举报函标题和称谓按用户偏好选择模式，默认极简型+简洁型
8. 举报函**强制**在正文末尾或配合承诺段后附加如实举报义务提示
