# 致送对象身份定制警示语库（客户自署函适配版）

> **共享警示语正文**：6 类身份的标准警示语见 ../baichen-ndr-standard/references/knowledge-warning-phrases.md §二。本适配层仅说明客户自署函的称谓替换与嵌入方式。

## 称谓适配
所有警示语中的"[发函方]"在本技能（客户自署函）中统一替换为"我方 / 我方委托的律师"；原文"委托人 / 本律师"亦作同样替换。

## 身份检测
身份类型（上市公司 / 普通企业 / 个人 / 金融机构 / 房地产·建筑企业 / 境外主体）的检测规则与优先顺序见 ../baichen-ndr-standard/references/knowledge-warning-phrases.md §一。

## 使用规则
1. **身份检测**步骤 1 完成信息采集后自动判定身份类型
2. **警示语匹配**从共享版 §二 匹配对应身份的"强制警示"段
3. **嵌入位置**将匹配到的警示语嵌入函告正文"五、拟采取的后续动作"
4. **增强叠加**根据案情严重程度，选择性叠加共享版对应身份的"增强表述"
5. **不确定时**默认使用"普通企业"警示语，同时提示用户可指定具体身份
6. **混合身份**如致送对象同时为上市公司高管个人（如追索个人担保），可分别引用"个人"和"上市公司"警示语，但须明确区分适用对象
