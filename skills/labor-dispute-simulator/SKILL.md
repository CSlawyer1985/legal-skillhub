# 劳动纠纷法律程序模拟器

## Purpose

本 Skill 用于模拟中国大陆劳动纠纷从仲裁到二审的完整法律程序。通过多角色扮演和证据对抗，帮助用户理解劳动法律实务、准备诉讼材料、评估案件胜算。

## When to Use This Skill

- 员工需要准备劳动仲裁或诉讼材料
- 需要模拟庭审流程、提前演练质证环节
- 评估劳动纠纷案件的胜诉概率和赔偿金额
- 学习劳动法律实务操作流程
- 需要生成规范的劳动法律文书

## Instructions

> **核心交互原则**：采用**向导式分步问答**收集信息。每次只问一组问题，等用户回答后再进入下一步。不要一次性抛出所有问题。使用友好、通俗的语言，让用户感觉像在和一个耐心的法律助手对话。

### 第六步：生成员工方文书（仲裁/起诉阶段）

如果用户扮演员工方或选择全自动模式：

1. 根据收集的事实，生成《劳动仲裁申请书》或《民事起诉状》
2. 文书格式要求：
   - 使用 Markdown 格式
   - 包含完整的当事人信息、请求事项、事实与理由
   - 法律依据引用准确（《劳动合同法》《劳动法》等）
   - 赔偿金额计算清晰（N、N+1、2N、加班费等）

3. 生成《证据清单》：
   - 按序号列出证据名称
   - 说明证明目的
   - 标注证据来源

4. 将文书保存到 `/workspace/` 目录，文件名格式（以仲裁阶段为例）：
   - `仲裁_申请书_员工姓名_日期.md`
   - `仲裁_证据清单_员工方_日期.md`

### 第七步：生成公司方答辩文书

AI 扮演公司方时：

1. 分析员工方主张的漏洞和薄弱环节
2. 生成《答辩状》，包含：
   - 针对每项请求的答辩意见
   - 事实反驳和法律依据
   - 公司方的证据清单

3. 保存文件（以仲裁阶段为例）：`仲裁_答辩状_公司方_日期.md`

### 第八步：证据对抗环节

进入模拟庭审的证据质证阶段：

1. **员工方举证**：逐一说明每份证据的证明目的
2. **公司方质证**：对每份证据发表真实性、合法性、关联性质证意见
3. **公司方举证**：提交反驳证据
4. **员工方质证**：对公司方证据进行质证

**质证要点**：
- 真实性：证据是否真实、有无篡改
- 合法性：证据来源是否合法
- 关联性：证据与争议焦点是否相关
- 证明力：证据能否证明待证事实

**质证完成后，必须生成《证据认定清单》并保存为 Markdown 文件**，格式如下：

```markdown

| 序号 | 证据名称 | 质证意见 | 是否采信 | 认定理由 |
|------|---------|---------|---------|---------|
| 1 | 劳动合同 | 双方无异议 | ✅ 采信 | 真实合法，与本案关联 |
| 2 | 考勤记录 | 公司方对关联性有异议 | ✅ 采信 / ❌ 不采信 | {{详细理由}} |
| 3 | {{证据名}} | {{质证意见}} | ✅ 采信 / ❌ 不采信 | {{详细理由}} |

## 三、证据认定综合说明

基于以上质证情况，仲裁庭/法庭认定如下事实：
1. {{依据采信证据认定的事实1}}
2. {{依据采信证据认定的事实2}}
3. {{依据采信证据认定的事实3}}

**未采信证据说明**：
- {{证据名称}}：不予采信，理由：{{理由}}
- {{证据名称}}：不予采信，理由：{{理由}}
```

保存文件：`{{阶段}}_证据认定清单_日期.md`（如 `仲裁_证据认定清单_20250115.md`、`一审_证据认定清单_20250613.md`、`二审_证据认定清单_20260413.md`）

### 第九步：胜诉率评估

基于双方证据和主张，进行专业分析：

1. **争议焦点归纳**：列出本案核心争议点
2. **双方优劣势分析**：
   - 员工方有利因素
   - 员工方不利因素
   - 公司方有利因素
   - 公司方不利因素
3. **胜诉概率评估**：
   - 每项请求的胜诉概率（百分比）
   - 可能的判决/裁决结果预测
4. **赔偿金额计算**：
   - 支持金额预测
   - 计算依据和公式

将评估报告保存为：`{{阶段}}_胜诉率评估报告_日期.md`（如 `仲裁_胜诉率评估报告_20250115.md`）

## 法律计算规则

### 经济补偿金/赔偿金计算

| 情形 | 计算标准 | 法律依据 |
|------|---------|---------|
| 协商解除（员工提出） | 无补偿 | - |
| 协商解除（公司提出） | N | 《劳动合同法》第36、46条 |
| 员工被迫解除 | N | 《劳动合同法》第38、46条 |
| 公司无过错辞退 | N 或 N+1 | 《劳动合同法》第40、46条 |
| 公司违法解除 | 2N | 《劳动合同法》第87条 |
| 合同到期终止 | N | 《劳动合同法》第44、46条 |

**N 的计算**：
- N = 工作年限（满1年算1年，6个月以上不满1年算1年，不满6个月算0.5年）
- 月工资 = 离职前12个月平均工资
- 上限：月工资超过当地社平工资3倍的，按3倍计算，且补偿年限最高12年

### 加班费计算

| 加班类型 | 计算标准 | 法律依据 |
|---------|---------|---------|
| 工作日延时 | 小时工资 × 150% | 《劳动法》第44条 |
| 休息日加班 | 小时工资 × 200%（或调休） | 《劳动法》第44条 |
| 法定节假日 | 小时工资 × 300%（不可调休） | 《劳动法》第44条 |

**小时工资计算**：月工资 ÷ 21.75天 ÷ 8小时

### 未休年假工资

- 计算：日工资 × 300%（含正常工作期间工资，实际额外支付200%）
- 日工资 = 月工资 ÷ 21.75天

## 区域差异说明

不同地区可能有特殊规定，需根据用户指定的地区调整：

- **北京**：高温津贴、最低工资标准等
- **上海**：加班费计算基数有特殊规定
- **广东**：停工留薪期工资标准
- **其他省份**：根据当地劳动法规调整

## Examples

### 示例 1：违法解除 2N 赔偿

**案情**：员工工作3年2个月，月薪8000元，公司无合法理由解除劳动合同。

**计算**：
- N = 3.5年
- 赔偿金 = 8000 × 3.5 × 2 = 56,000元

**文书要点**：
- 请求事项：支付违法解除劳动合同赔偿金56,000元
- 事实理由：入职时间、解除时间、公司未提供合法解除依据
- 法律依据：《劳动合同法》第87条

### 示例 2：加班费争议

**案情**：员工月薪6000元，每周六加班8小时，持续1年，公司未支付加班费。

**计算**：
- 小时工资 = 6000 ÷ 21.75 ÷ 8 ≈ 34.48元/小时
- 加班费 = 34.48 × 8 × 52 × 200% ≈ 28,648元

### 示例 3：证据对抗

**员工方证据**：考勤打卡记录（证明加班事实）

**公司方质证意见**：
- 真实性：认可打卡记录真实性
- 关联性：打卡不等于实际工作，员工可能在公司做私事
- 证明力：不能单独证明加班事实，需结合工作成果等证据
