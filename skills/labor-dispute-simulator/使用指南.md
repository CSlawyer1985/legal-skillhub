# 劳动纠纷法律程序模拟器 - 使用指南

## 📖 简介

本 Skill 是一个专业的劳动纠纷法律程序模拟工具，帮助用户：
- 模拟劳动仲裁 → 一审 → 二审的完整法律流程
- 扮演多方角色进行对抗演练
- 生成规范的劳动法律文书
- 评估案件胜诉率和赔偿金额
- 输出专业的 HTML 总结报告

---

## 🚀 快速开始

### 安装 Skill

1. 将 `labor-dispute-skill` 文件夹复制到你的 Skill 目录：
   - Claude Code: `~/.claude/skills/`
   - VS Code: `.github/skills/` 或 `.claude/skills/`

2. 重启你的 AI 助手，Skill 将自动加载

### 启动 Skill

直接对 AI 说：
- "我要使用劳动纠纷模拟器"
- "帮我模拟一个劳动仲裁案件"
- "我想练习劳动纠纷诉讼"

## 🎯 使用流程

> Skill 采用**向导式分步问答**收集信息，每次只问一组问题，简单友好，跟着提示走就行。

### 📋 第1步 / 共4步：选择角色扮演模式

启动 Skill 后，首先看到欢迎信息，然后选择角色扮演方式：

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **模式A · 对抗模式** | 你扮演员工方，AI 扮演公司方 + 裁判者 | 准备维权，练习陈述和质证 |
| **模式B · 演示模式** | AI 全自动扮演所有角色 | 学习观摩，了解完整流程 |
| **模式C · 自由指定** | 你来决定谁扮演什么角色 | 针对性练习特定角色 |

👉 回复编号（1、2 或 3）即可选择。

### 📋 第2步 / 共4步：输入案件基本信息

提供员工和公司的基本信息：
- 员工姓名、入职时间、岗位、离职时间、月平均工资
- 公司名称、所在地（如"陕西西安"）

👉 可以一次性回复所有信息，也可以逐项说明，暂时不清楚的可以跳过。

### 📋 第3步 / 共4步：选择纠纷类型与描述事实

**选择纠纷类型**（可多选，回复编号如"1,3"）：
1. 违法解除劳动合同
2. 拖欠/克扣工资
3. 加班费争议
4. 未休年假工资
5. 经济补偿金/赔偿金争议
6. 社保/公积金争议
7. 工伤赔偿争议
8. 其他

**描述事实经过**：简要说明发生了什么、公司怎么做的、你的诉求是什么。

**列出现有证据**：如劳动合同、工资条、考勤记录、聊天记录等。

### 📋 第4步 / 共4步：选择程序阶段

选择从哪个法律程序开始：

| 阶段 | 说明 | 前置条件 |
|------|------|---------|
| ① 劳动仲裁 | 向劳动仲裁委员会申请仲裁 | 无（必经程序） |
| ② 一审诉讼 | 对仲裁结果不服，向法院起诉 | 需先完成仲裁 |
| ③ 二审诉讼 | 对一审判决不服，向上级法院上诉 | 需先完成一审 |

### ✅ 信息确认

四步完成后，Skill 会输出一份**案件信息汇总表**，请你确认是否准确。
- 信息有误 → 告诉 Skill 需要修改的内容
- 确认无误 → 回复"开始"进入模拟

### 🔄 进行模拟

确认信息后，Skill 将引导你完成以下环节：

#### 1. 文书生成
- 生成仲裁申请书/起诉状
- 生成证据清单
- 生成答辩状（AI 扮演对方时）

#### 2. 证据对抗
- 举证：展示你的证据
- 质证：对对方证据发表意见
- 辩论：就争议焦点展开辩论

#### 3. 胜诉率评估
- 分析双方证据强弱
- 评估各项请求的胜诉概率
- 预测可能的裁判结果

#### 4. 模拟裁判
- AI 扮演仲裁员/法官作出裁决
- 包含事实认定、法律适用、裁判结果

### ⏭️ 阶段切换

每个阶段结束后，Skill 会询问是否进入下一阶段：
- **继续**：进入下一法律程序
- **结束**：生成总结报告，完成模拟

### 📄 获取报告

模拟结束后，Skill 会生成：
- 所有法律文书（Markdown 格式）
- HTML 总结报告（包含完整模拟记录）

## 📋 功能详解

### 1. 多角色扮演

#### 你可以扮演的角色：
- 员工委托律师
- 公司法律顾问
- 仲裁员/法官（在模式B中）

#### AI 可以扮演的角色：
- 员工委托律师
- 公司律师
- 仲裁员
- 一审法官
- 二审法官

### 2. 文书生成

Skill 可以生成以下文书：

| 文书类型 | 适用阶段 | 说明 |
|---------|---------|------|
| 劳动仲裁申请书 | 仲裁阶段 | 员工方提起仲裁 |
| 仲裁答辩状 | 仲裁阶段 | 公司方答辩 |
| 民事起诉状 | 一审阶段 | 不服仲裁结果起诉 |
| 民事答辩状 | 一审阶段 | 被告方答辩 |
| 民事上诉状 | 二审阶段 | 不服一审判决上诉 |
| 证据清单 | 各阶段 | 列举证据及证明目的 |
| 模拟裁决书/判决书 | 各阶段 | AI 作出的模拟裁判 |

### 3. 证据对抗

证据对抗包含四个维度：

1. **真实性**：证据是否真实、有无篡改
2. **合法性**：证据来源是否合法
3. **关联性**：证据与争议焦点是否相关
4. **证明力**：证据能否证明待证事实

### 4. 胜诉率评估

评估因素包括：
- 证据的充分性和证明力
- 法律适用的准确性
- 类似案例的裁判趋势
- 当地司法实践特点

### 5. 赔偿计算

自动计算以下赔偿项目：

| 赔偿项目 | 计算标准 | 法律依据 |
|---------|---------|---------|
| 违法解除赔偿金 | 2N | 《劳动合同法》第87条 |
| 经济补偿金 | N 或 N+1 | 《劳动合同法》第46、47条 |
| 加班费 | 150%/200%/300% | 《劳动法》第44条 |
| 未休年假工资 | 300%（实际200%） | 《职工带薪年休假条例》 |
| 拖欠工资 | 全额 + 可能加付赔偿金 | 《劳动合同法》第85条 |

**N 的计算**：
- 每满1年支付1个月工资
- 6个月以上不满1年按1年计算
- 不满6个月支付0.5个月工资

## 💡 使用技巧

### 1. 准备充分的信息

开始前准备好以下材料：
- 劳动合同
- 工资流水或工资条
- 考勤记录
- 解除通知（如有）
- 其他相关证据

信息越完整，模拟效果越好。

### 2. 善用模式B学习

如果你是第一次接触劳动纠纷，建议先使用**模式B（AI 全自动）**观看完整演示，了解流程后再亲自参与。

### 3. 重点关注证据对抗

证据是劳动纠纷的核心，在质证环节：
- 仔细思考对方证据的漏洞
- 准备对自己证据的补充说明
- 学会用"三性"（真实性、合法性、关联性）分析证据

### 4. 保存好生成的文书

Skill 生成的文书可以作为：
- 正式文书的基础模板
- 学习法律写作的参考
- 与律师沟通的素材

⚠️ **注意**：正式提交前务必请专业律师审核。

### 5. 注意时效

Skill 会提醒你注意以下时效：
- **仲裁时效**：1年（从知道或应当知道权利被侵害之日起）
- **诉讼时效**：15日（对仲裁裁决不服）
- **上诉期限**：15日（对一审判决不服）

## 🆘 常见问题

### Q1: Skill 生成的文书可以直接提交吗？

**不建议直接提交**。Skill 生成的文书是模拟性质的模板，正式提交前应当：
- 请专业律师审核修改
- 根据当地仲裁委员会/法院要求调整格式
- 补充具体的证据材料

### Q2: 模拟结果和实际结果会有多大差异？

模拟结果基于：
- 你提供的事实和证据
- 一般性的法律规定
- 典型案件的裁判趋势

实际结果可能因以下因素而不同：
- 法官的自由裁量
- 新证据的出现
- 当地司法实践的特殊性
- 双方诉讼策略的变化

### Q3: 可以模拟多个纠纷类型吗？

可以。在输入案件信息时，可以选择多个纠纷类型（如同时主张违法解除和加班费），Skill 会综合处理。

### Q4: 如何保存模拟进度？

Skill 支持断点续传：
- 每个阶段结束后，你可以要求暂停
- 下次使用时提供案件编号或关键信息，可以从上次位置继续
- 所有生成的文件都会保存在 `/workspace/` 目录

### Q5: 可以修改已经生成的文书吗？

可以。你可以：
- 直接要求 AI 修改某份文书的具体内容
- 提供新的信息让 AI 重新生成
- 在 Markdown 文件中手动编辑后让 AI 审核
