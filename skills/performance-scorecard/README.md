# performance-scorecard

**OCM 技能插件** — 8 项技能中的第 7 项
**状态：** 已完成 — 第一阶段和第二阶段均已测试

---

## 本技能的功能

为评估外部律师的企业内部法律运营团队设计绩效记分卡、收集事后反馈、准备季度业务回顾（QBR）并进行律所比较。

将整个关系生命周期中收集、汇总和运用律所绩效数据的方法论编码化——从建立初步评估框架，到为律师库（panel）留任和退出决策提供依据的比较分析。

---

## 模式

| 模式 | 触发方式 | 产出 |
|------|---------|--------|
| 1 — 记分卡设计 | "帮我们建一个记分卡" / "我们如何评估律所" / "设计一个绩效记分卡" | 绩效记分卡框架 + 总法务（GC）实施说明 |
| 2 — 事后反馈 | "事后反馈表" / "收集对律所的反馈" / "在案件结案时反馈" | 案件反馈表 + 反馈收集说明 |
| 3 — QBR 准备 | "准备律所评审" / "与[律所]进行季度业务回顾" / "季度业务回顾" | QBR 包（议程 + 数据摘要 + 谈话要点）+ 内部简报说明 |
| 4 — 律所比较 | "比较这些律所" / "哪家律所表现更好" / "对我们的律师库排名" | 比较记分卡表格 + 选择建议说明 |

---

## 关键设计决策

**成熟度校准作为主要设计变量。** 四种模式都按成熟度水平（按 ACC 框架分为早期 / 中期 / 高级）进行校准。对早期团队应用模式 1 会产出含 5 项标准的、可直接用于 Excel 的记分卡；对高级团队应用则产出带竞争性基准的仪表盘集成框架。

**模式 4 能处理部分数据。** 律所比较的输入可靠地稀疏——所有律所同时具备完整记分卡数据的情况很少见。该模式使用 [Data gap]（数据缺口）标记，而不是拒绝产出比较。

**双层产出。** 每种模式都产出操作性文件（用户用以运行流程的工具）和决策者文件（推动行动的总法务/领导层摘要）。

**QBR 常设结构。** 模式 3 编码了标准的 QBR 议程：绩效回顾、账单合规、进行中的事项、未来业务管道、关系与团队问题、行动事项。谈话要点经过校准以处理已知问题，而非泛泛的例行检查。

## 跨技能连接

| 技能 | 连接 |
|-------|-----------|
| invoice-review-compliance（技能 6） | 账单合规率和拒付记录为定量记分卡标准提供输入。直接输入模式 1、3 和 4。 |
| matter-allocation-instruction（技能 5） | 事项结案触发模式 2 的事后反馈。 |
| panel-review-rationalisation（技能 8） | 累积的记分卡数据为定期正式的律师库评审提供输入。本技能负责收集；技能 8 负责评估。 |
| rfp-pitch-management（技能 3） | 历史记分卡数据为 RFP 评估标准和入围筛选提供信息。 |
| panel-design-selection（技能 2） | 记分卡产出（尤其是模式 4 的比较数据）为律师库留任和退出决策提供信息。 |
| engagement-terms-billing-guidelines（技能 1） | OCG 合规率是记分卡的一项指标。 |
