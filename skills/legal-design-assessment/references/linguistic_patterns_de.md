# 德语语言模式——参考

当审计到达第 3 步且文档语言为德语时加载。

本文件记录了德语法律设计实践（依 Fischer-Dieskau、Eichhoff-Cyrus、Lerch、Roelcke、Wagner，以及联邦政府"贴近公民的行政语言"）视为法律设计债务的模式。检测、计数、评分——不重写。

这些模式适用于标准的法律高地德语。奥地利和瑞士德语的立法起草共享该基线；具体分歧在**地区差异**一节中注明。

## 待识别的模式

### 1. 官腔/法律套话（Behördensprache / juristische Floskeln）

在德语法律语言中存留但不履行任何法律功能的词和短语。每次使用均计数。

- **Hier-/Da-词。** *hiermit、hierdurch、hieraus、hierfür、hierauf、hierin、hierzu、hierüber、hierunter、davon、daran、darauf、daraus、dafür、dazu、darüber、darunter*——作为不必要的连词替代词。（有些不可或缺，如 *daran erinnern* 中的 *daran*；仅标记纯套话性质的用法。）
- **回指古语。** *vorgenannt、vorbenannt、vorbezeichnet、vorstehend、vorerwähnt、obig、obenstehend、vorliegend、gegenständlich*（奥地利）、作为形容词的 *betreffend*。
- **套话性名词。** *Vorgang、Sachverhalt*（作为通用占位词）、*Maßgabe、Maßnahme*（如用作内容占位词）。
- **无功能的强调小品词。** *grundsätzlich、im Wesentlichen、in der Regel、gegebenenfalls、soweit、sofern、etwaig*。每一个在具体情形中都可能是合理的；**高密度**是无实质内容的防御性起草的可靠信号。
- **合同文本中的礼貌套话。** *gerne、sehr geehrt、in Anbetracht*——在序言之外的合同中出现显得尴尬。
- **固定术语之外的拉丁语和法语残留。** *ipso iure、ex nunc、ex tunc、mutatis mutandis*——真正的术语保留；仅标记用作装饰的用法。

**计数。** 套话密度 =（命中数）/（总词数）× 1,000。

| 密度（每 1,000 词） | 级别 |
| --- | --- |
| 0–3 | 绿 |
| 4–7 | 黄 |
| 8–12 | 琥珀 |
| 13+ | 红 |

### 2. 名词化（Nominalstil）

德语法律语言最突出的特征。将动词转化为名词短语迫使读者重构实际发生的事件。

信号（计数）：

- 空动词后的 *-ung、-heit、-keit、-nis、-tum* 结尾名词，如 *vornehmen、durchführen、erfolgen、vorliegen、gegeben sein、in Anspruch nehmen、zur Anwendung bringen、in Kraft setzen、zur Verfügung stellen、in Anwendung kommen、zur Zahlung bringen*。

  示例：*die Vornahme der Kündigung（实施解雇）、die Durchführung der Zahlung（执行付款）、die Inanspruchnahme des Rechts（行使权利）、die Zurverfügungstellung der Räumlichkeiten（提供场所）、das In-Kraft-Setzen（使生效）。*

- **功能动词结构（FVG）**——语言学意义上的定义：语义淡化的动词与承载实际动词内容的名词的组合。经典清单：

  *zur Anwendung bringen / kommen*（anwenden 适用）；*in Anwendung bringen*（anwenden 适用）；*zur Durchführung gelangen*（durchgeführt werden 被执行）；*Ausdruck verleihen*（ausdrücken 表达）；*Beachtung schenken*（beachten 注意）；*Entscheidung treffen*（entscheiden 决定）；*Erwägung ziehen*（erwägen 考虑）；*Geltung verschaffen*（gelten 生效）；*Hilfe leisten*（helfen 帮助）；*in Erfahrung bringen*（erfahren 获悉）；*in Frage kommen / stehen*（möglich sein 可能）；*in Kraft treten / setzen*（gelten / inkrafttreten 生效）；*in Rechnung stellen*（berechnen 计算）；*Kenntnis nehmen / erlangen*（erfahren 获悉）；*Nutzen ziehen*（nutzen 利用）；*Rücksicht nehmen*（berücksichtigen 考虑）；*unter Beweis stellen*（beweisen 证明）；*zum Abschluss bringen*（abschließen 完成）；*zur Anzeige bringen*（anzeigen 举报）；*zur Auszahlung bringen*（auszahlen 支付）；*zur Kenntnis bringen*（mitteilen 告知）。

  每个 FVG 均计数。

密度 =（FVG + 名词化风格典型结构）/（总词数）× 1,000。

| 密度（每 1,000 词） | 级别 |
| --- | --- |
| 0–6 | 绿 |
| 7–12 | 黄 |
| 13–18 | 琥珀 |
| 19+ | 红 |

### 3. 被动结构

德语区分：

- **过程被动（Vorgangspassiv）**（*werden* + 第二分词）：*wird gekündigt、wurde mitgeteilt。*
- **状态被动（Zustandspassiv）**（*sein* + 第二分词）：*ist gekündigt、ist eingeräumt。*
- **情态被动结构**（*sein* + zu + 不定式；*sich lassen* + 不定式）：*ist zu kündigen、lässt sich vereinbaren。*

三种形式均计数。情态 *sein-zu-* 结构对法律文本尤其典型，应单独计数，因为它模糊了道义情态（*muss* 必须、*darf* 可以）。

被动密度 =（过程被动 + 状态被动 + 情态被动）/（限定动词）× 100。

| 被动密度 | 级别 |
| --- | --- |
| 0–15% | 绿 |
| 16–25% | 黄 |
| 26–35% | 琥珀 |
| 36%+ | 红 |

对于经验丰富的合同当事人之间的 B2B 合同，每个阈值提高 5 个百分点。

### 4. 句长与嵌套句（Satzlänge und Schachtelsätze）

嵌套句是德国官腔和法律风格最突出的识别特征。主动词前的多重插入和跨多层的后置关系从句是可靠信号。

计算：

- 平均句长（词数）。
- 中位数。
- 超过 30 词的句子（"长句"）。
- 超过 50 词的句子（"超长句"）。
- 最长句子及出处。

| 平均句长 | 级别 |
| --- | --- |
| 0–15 | 绿 |
| 16–22 | 黄 |
| 23–32 | 琥珀 |
| 33+ | 红 |

**附加分析"括号结构"（Klammerstellung）：** 在德语中，主句通常以动词括号为特征（*Der Mieter hat … zu erbringen*）。如果括号第一部分与最后一部分之间超过 20 个词，则该句无论其总长度如何均视为超载——单独标记。

### 5. 复合词长度（Komposita-Länge）

德语可形成任意长的复合词。超出正常构词之外，法律超长复合构词（*Grundstücksverkehrsgenehmigungszuständigkeitsübertragungsverordnung*——并非虚构示例）是可读性问题。

计数符合以下条件的复合词：

- 4 个以上组成部分。
- 超过 25 个字母。

| 每 1,000 词中 4 个以上组成部分的复合词 | 级别 |
| --- | --- |
| 0–3 | 绿 |
| 4–7 | 黄 |
| 8–12 | 琥珀 |
| 13+ | 红 |

### 6. 双重否定与分级条件句

*"Keine Partei darf, soweit es ihr nicht unzumutbar wäre, die Mitteilung nicht in einer dem Vertrag entsprechenden Weise unterlassen."*

识别：

- *nicht un-*（作为对冲的否定之否定）。
- *nicht … es sei denn …*
- *niemand darf … außer …*

每 1,000 词一条链 = 黄。两条或以上 = 琥珀。三重嵌套否定 = 红。

### 7. 赘词与笨拙表达（Pleonastische und schwerfällige Wendungen）

当较短的词承载相同内容时：

- *zum Zwecke* + 属格 → für / um zu（为了）。
- *im Hinblick auf* → für / wegen（鉴于/因为）。
- *unter Berücksichtigung* → angesichts（鉴于——视语境而定）。
- *im Zuge* → bei / während（在……过程中）。
- *seitens / vonseiten* → von（由……方面）。
- *im Sinne des* → nach（按照）。
- *gemäß / nach Maßgabe* → nach（按照——视语境而定——*gemäß* 常应作为法律术语保留）。
- *insoweit* → soweit（在……范围内——视语境而定）。
- *insofern* → soweit（在……范围内）。
- *im Übrigen* → sonst（否则——如风格上可接受）。
- *erforderlichenfalls* → wenn nötig（必要时）。
- *zwecks* → für / um zu（为了）。

计数，并在注意要点总结清单中列出。

### 8. 交叉引用密度（Querverweisdichte）

内部引用计数："im Sinne des § 5 dieser AGB"（按本一般条款第 5 条之意）、"vorbehaltlich Ziffer 7"（以第 7 款为准）、"gemäß Anlage B"（按附件 B）。

| 每 1,000 词交叉引用数 | 级别 |
| --- | --- |
| 0–6 | 绿 |
| 7–12 | 黄 |
| 13–20 | 琥珀 |
| 21+ | 红 |

特别标记：
- 引用链（引用某一条款，而该条款本身又引用他处）。
- 引用未附上的附件。

## "语言模式"支柱的评分（德语）

八个子分数等权映射到 0–100：

1. 套话密度
2. 名词化密度
3. 被动密度
4. 句长（平均）
5. 复合词长度
6. 双重否定
7. 赘词表达
8. 交叉引用密度

每个子分数的转换：

- 绿 → 90。
- 黄 → 70。
- 琥珀 → 45。
- 红 → 20。

支柱分数 = 四舍五入的平均值。

## 地区差异

- **德国。** BGB 第 305–310 条规定了格式条款法的标准；根据这些规定无效的法律条款应归入"隐藏条件"或"法律重复"支柱——而非语言模式。
- **奥地利。** 独立词汇：*Erkenntnis* 而非 *Urteil*（行政法）、*Pönale* 而非 *Vertragsstrafe*、*Vorlagebeschluss*（术语上相同但更常用）。以 KSchG 而非德国的 AGG 标准为基准。
- **瑞士（德语区）。** 以 OR（《债法》）而非 BGB 为准；*ß* 一律改为 *ss*。瑞士法律语言中的标准德语包含瑞士特有词（*allfällig* 而非 *etwaig*、*anbegehren*、特定含义下的 *vorgenommen werden*）。
- **列支敦士登。** PGR（《人与公司法》）为独立结构；其余受奥地利影响。
