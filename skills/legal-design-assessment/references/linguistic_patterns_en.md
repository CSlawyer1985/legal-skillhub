# 英语语言模式——参考

当审计进入第 3 步且文档语言为英语时加载。

本文件清点法律设计实践（依 Wydick、Garner、Kimble、Tiersma、Adler）视为起草债务的模式。任务是**检测**、**计数**和**评分**——而非改写。

## 待检测的模式

### 1. 古旧法律行话

在法律英语中存续但不承担法律功能的词语和短语。起草人可以将其删除而无意义损失。标记每次出现。

- **Here-词。** *herein, hereinafter, hereto, herewith, hereunder, hereinabove, hereinbefore, heretofore.*（在本文件/以下/至此/随附/依此/上文/此前等）
- **There-词。** *therein, thereof, thereto, thereafter, theretofore, thereunder, therewith.*（在其中/其/至其/此后/此前/在其下/随附等）
- **Where-词。** *whereas*（在序言位置之外——在序言位置它具有惯例功能——仅在中途使用时标记）、*whereof, whereby, wherein*。
- **Said / aforesaid / aforementioned（所述/前述）。** 用作定冠词的替代。标记每次出现。
- **Witnesseth（兹证明）。** 中世纪起草的序言块遗存。标记。
- **Such（用作定冠词）。** "Such Party shall…"（该方应……）而"the Party"或"that Party"即可。逐条款标记；并非每个 "such" 都有问题，只有作限定词替代的用法有问题。
- **Provided that / provided however（但规定/但）。** 常用于引出操作条款上的重大限制。并非总是错误，但高频使用是结构不良的信号。计数出现次数。
- **Notwithstanding（尽管）。** 适度允许；如果文档每约 1,500 词使用超过一次则标记。
- **Subject to / without prejudice to（在不抵触/在不影响……的前提下）。** 同样——标准是适度，而非完全不用。
- **成对词和成三词。** *null and void; cease and desist; aid and abet; give, devise and bequeath; covenant and agree; alter, modify or amend; any and all; full force and effect; final and binding; terms and conditions.*（无效的；停止并终止；帮助和教唆；赠与、遗赠并继承；约定并同意；变更、修改或修正；任何和所有；完全效力；最终且具有约束力；条款和条件）每次冗余存续都是一笔起草债务。
- **术语之外拉丁语和古法语的存续。** *inter alia, mutatis mutandis, ipso facto, force majeure*——*force majeure* 和 *mutatis mutandis* 确实没有英文对应词，通常没问题；*inter alia* 和 *ipso facto* 几乎总有平实替代（"including"、"automatically"）。标记后一类。

**计数。** 计算古语密度 =（被标记项出现次数）/（总词数）× 1,000。解释区间：

| 古语密度（每 1,000 词） | 区间 |
| --- | --- |
| 0–2 | 绿 |
| 3–5 | 黄 |
| 6–9 | 琥珀 |
| 10+ | 红 |

### 2. 被动语态

被动语态并非绝对错误，但其**密度**是官僚式起草的可靠信号。计数每个限定被动结构（助动词 "be" + 过去分词："shall be deemed"、"is hereby agreed"、"was notified"、"has been served"）。

排除：
- 施动者未知或不相关的真正无施动者被动（如"the document was signed in 1995"，该文件于 1995 年签署）。
- 作系词的 "be" 后接形容词（"shall be liable"、"is responsible"）。这些是静态被动，而非施动者被动。

计算被动密度 =（限定被动结构）/（限定动词总数）× 100，以百分比表示。

| 被动密度 | 区间 |
| --- | --- |
| 0–10% | 绿 |
| 11–20% | 黄 |
| 21–30% | 琥珀 |
| 31%+ | 红 |

对于 B2B 精明当事人合同，将每个区间阈值上移 5 个百分点（被动语态是该体裁的典型特征）。

### 3. 名词化

名词化是将动词转换为名词短语："the determination of"（对……的确定）而非 "to determine"（确定），"the imposition of liability"（责任的施加）而非 "imposing liability"（施加责任），"make payment of"（进行支付）而非 "pay"（支付），"give consideration to"（予以考虑）而非 "consider"（考虑）。高度名词化的行文迫使读者重建动作。

检测信号（计数实例）：

- 空动词（"make"、"give"、"provide"、"effect"、"perform"、"undertake"、"have"、"be"）后接带 *-tion, -ment, -ance, -ence, -al, -ity, -ure, -age* 后缀的名词短语动词。示例：*make a determination, give notification, provide indemnification, effect cancellation, perform the calculation, undertake the assessment, have an obligation, be in receipt of.*
- "The X of Y" 结构，其中 X 是派生名词，Y 是自然施动者或宾语：*the resolution of the dispute, the execution of this Agreement, the termination of the relationship.*

计算名词化密度 =（被标记结构）/（总词数）× 1,000。

| 名词化密度（每 1,000 词） | 区间 |
| --- | --- |
| 0–4 | 绿 |
| 5–9 | 黄 |
| 10–14 | 琥珀 |
| 15+ | 红 |

### 4. 句子长度

长句是影响最大的单一问题。计算：

- 平均句子长度（词数）。
- 中位句子长度（词数）。
- 超过 40 词的句子数量（"长句"）。
- 超过 60 词的句子数量（"超长句"）。
- 文档中最长的句子及其位置。

| 平均句子长度 | 区间 |
| --- | --- |
| 0–18 | 绿 |
| 19–24 | 黄 |
| 25–32 | 琥珀 |
| 33+ | 红 |

注：平均值和中位数应一起报告。中位数 18 但平均值 32 表明少数超长句拉高了平均值——这本身就是结构性问题，应予标记。

### 5. 双重否定和"not unless"结构

*"No Party shall not, except in circumstances where it is not unreasonable to do so, fail to provide notification..."*（任何一方不得，除非在此举并非不合理的情形下，未能提供通知……）每层否定都大致线性地增加理解成本。检测：

- 用作回避的 "not un-" 前缀。
- "no … shall not"、"shall not … unless"。
- 三重否定链（罕见但极具破坏性）。

每 1,000 词计数。即使一条链通常也是琥珀；两条或以上为红。

### 6. 词和短语长度

依 Wydick 的长期启发式方法，在传达相同含义时优先使用较短的词。标记高频违规者：

- *utilise / utilisation* → use（使用）。
- *prior to* → before（在……之前）。
- *subsequent to* → after（在……之后）。
- *in the event that / in the event of* → if（如果）。
- *for the purpose of* → for（为了）。
- *in order to* → to（为了）。
- *with respect to / with regard to / in relation to* → about / on / for（关于/就）。
- *due to the fact that / by reason of / by virtue of* → because（因为）。
- *at the present time* → now（现在）。
- *in the absence of* → without（在没有……的情况下）。
- *commence / commencement* → begin / start（开始）。
- *terminate / termination* → end（终止，在情境允许处）。
- *furnish* → provide / give（提供/给予）。
- *render* → make / give（作出/给予）。
- *endeavour* → try（努力）。

计数出现次数并以"速成成果"表呈现；这作为输入之一进入语言模式评分，在优先关注清单中也有用。

### 7. 交叉引用密度

计数内部交叉引用（"as defined in clause 4.2"、"as set forth in Schedule B"、"subject to clauses 7 through 11"）。交叉引用在长合同中不可避免，但超过阈值后成为导航负担：

- 每 1,000 词交叉引用：0–5 绿；6–10 黄；11–18 琥珀；19+ 红。

专门标记：
- 链条（交叉引用到自身又向前交叉引用的条款）。
- 指向未附上或未提供的附表或附录的交叉引用。

## 语言模式支柱评分（英语）

使用相等权重组合七个子分数，然后映射到 0–100：

1. 古语密度
2. 被动密度
3. 名词化密度
4. 句子长度（平均值）
5. 双重否定
6. 词/短语长度（Wydick 违规者，按每 1,000 词归一化）
7. 交叉引用密度

每个子分数转换为 0–100 的分项：

- 该指标的绿区间 → 90。
- 黄 → 70。
- 琥珀 → 45。
- 红 → 20。

支柱分数 = 七项分项的均值。四舍五入为整数。

## 在支柱表中报告的内容

对每个被标记的段落，包括：

| # | 模式 | 引用（逐字） | 位置 | 严重程度 | 注释 |
| --- | --- | --- | --- | --- | --- |
| 3.1 | 古旧法律行话 | "Whereas the Parties have heretofore entered into…" | 序言 A | 黄 | "heretofore" 不承担法律功能；"previously" 即可。 |
| 3.2 | 长句（78 词） | "[全文]" | 第 12.3 条 | 红 | 单句含 4 层从属；考虑拆分为 3 句。 |
| 3.3 | 被动密度 34% | — | 全文 | 红 | 见摘要中的汇总计数；仅第 8 条就在 11 个限定动词中有 7 个被动。 |

逐字引用是强制性的。如果引用超过 25 词，用"…"截断，但保留足够的上下文以便读者定位。
