# 可读性指标——参考

审计进入第4步时加载。根据文档语言计算一个或多个可读性分数，并显示底层计数以便用户核实。

## 计数原语

本文件中的所有公式都依赖五个计数。计算一次并复用。

- **W** ——总词数。一个词是字母字符（Unicode 字母）的最大连续序列，带连字符的形式计为单个词。
- **S** ——总句数。句子以 `.`、`!`、`?` 或 `;` 结尾，且后接空白和大写字母。编号列表项如每项语法完整，计为独立句子。
- **Sy** ——总音节数（英语和法语）或 **CH** ——总字符数（德语 Amstad 使用音节变体；LIX 使用长词计数）。
- **LW** ——"长词"= 超过6个字符的词（LIX 惯例）。
- **C** ——从句数（用于维也纳科技文本公式 Wiener Sachtextformel）。

对所有语言：从 W 和 S 中排除标题、页码、签名块和目录条目。在各支柱间保持相同的排除规则，使计数一致。

## 英语

### Flesch 阅读易读性

```
FRE = 206.835 − 1.015 × (W/S) − 84.6 × (Sy/W)
```

其中 Sy 为总音节数。分数范围：实际为0–100，极难文本可为负，极简单文本可超过100。

解释区间（Flesch 原始）：

| 分数 | 区间 | 典型读者 |
| --- | --- | --- |
| 90–100 | 极易 | 五年级儿童 |
| 80–89 | 易 | 六年级 |
| 70–79 | 较易 | 七年级 |
| 60–69 | 标准 | 八至九年级 |
| 50–59 | 较难 | 高中 |
| 30–49 | 难 | 大学 |
| 0–29 | 很难 | 大学毕业生/专业人士 |

参考典型分数：

- 起草良好的通俗语言消费者条款和条件：55–65。
- 一般报纸文章：60–70。
- 一般美国法律合同：25–45。
- 美国最高法院判决意见：30–40。

### Flesch–Kincaid 年级水平

```
FKGL = 0.39 × (W/S) + 11.8 × (Sy/W) − 15.59
```

以美国学校年级水平表示。FKGL 16 ≈ 大学四年级；FKGL 12 ≈ 高中毕业。

### LIX（跨语言适用，对英语也有用）

```
LIX = (W/S) + 100 × (LW/W)
```

其中 LW = 超过6个字符的词。区间：

| LIX | 区间 |
| --- | --- |
| < 30 | 极易 |
| 30–39 | 易 |
| 40–49 | 标准 |
| 50–59 | 难 |
| 60+ | 很难 |

## 法语

### Flesch 的 Kandel–Moles 改编（1958年）

```
FRE_FR = 207 − 1.015 × (W/S) − 73.6 × (Sy/W)
```

针对法语音节结构调整（法语词每词平均音节多于英语）。使用与英语 Flesch 相同的解释区间，但需谨慎：法语文本由于音节密度更高，自然比同等难度的英语文本低5–10分。

参考典型分数：

- 起草良好的法语消费者 CGU（通用使用条件）：50–60。
- 一般法语报刊文章（《世界报》）：50–60。
- 一般法语商业合同：20–40。

### LIX

与英语公式相同，法语的"长词"阈值也为超过6个字符。法语平均词长比英语长，因此 LIX 略高。

区间同英语。

### 法语改编版 Gunning 指数（可选）

```
IG_FR = 0.4 × ((W/S) + 100 × (HW/W))
```

其中 HW = 3个及以上音节的词（不含复合词和屈折形式）。用于交叉核对——应与 Kandel–Moles 方向一致。

## 德语

### Flesch 的 Amstad 改编（1978年）

```
FRE_DE = 180 − (W/S) − 58.5 × (Sy/W)
```

注意与英语不同的常数。分数范围0–100。

解释区间（Amstad）：

| 分数 | 区间 | 典型读者 |
| --- | --- | --- |
| 90–100 | 很容易（Sehr leicht） | 小学 |
| 80–89 | 简单（Einfach） | 六年级 |
| 70–79 | 较简单（Eher einfach） | 七年级 |
| 60–69 | 中等（Mittel） | 八至九年级 |
| 50–59 | 较难（Eher schwer） | 实科中学/中学阶段 |
| 30–49 | 难（Schwer） | 高中毕业（Abitur） |
| 0–29 | 很难（Sehr schwer） | 高等教育 |

典型分数：

- 《图片报》：65–75。
- 《法兰克福汇报》/《南德意志报》：45–55。
- 一般德语 AGB（一般交易条款）：15–35。
- 《德国民法典》本身：15–25。

### 维也纳科技文本公式（Bamberger & Vanecek，1984年）

专为德语非小说散文设计。有多个变体；WSTF 1 是标准：

```
WSTF = 0.1935 × MS + 0.1672 × SL + 0.1297 × IW − 0.0327 × ES − 0.875
```

其中：
- **MS** = 三个及以上音节的词的百分比。
- **SL** = 平均句长（以词计）。
- **IW** = 超过六个字母的词的百分比。
- **ES** = 单音节词的百分比。

输出为从4（易）到15（很难）的年级水平。作为 Amstad 的补充很有用，因为它独立捕捉句长和词长。

### LIX

公式相同。德语平均词长比英语长，因此 LIX 偏高；区间上移：

| LIX（德语） | 区间 |
| --- | --- |
| < 35 | 很容易（Sehr leicht） |
| 35–44 | 容易（Leicht） |
| 45–54 | 标准 |
| 55–64 | 难（Schwer） |
| 65+ | 很难（Sehr schwer） |

## 将原始分数转换为支柱分数

对每个计算的指标，将区间映射为0–100的分项：

| 区间 | 分项 |
| --- | --- |
| 极易（Very Easy / Sehr leicht） | 95 |
| 易（Easy / Einfach / Leicht） | 85 |
| 较易（Fairly Easy / Eher einfach） | 75 |
| 标准（Standard / Mittel） | 65 |
| 较难（Fairly Difficult / Eher schwer） | 50 |
| 难（Difficult / Schwer） | 30 |
| 很难（Very Difficult / Sehr schwer） | 15 |

然后**根据第1步识别的受众进行校准**：

- **面向消费者的文件。** 按原样应用分项分数。
- **面向员工的文件。** 分项加5（消费者基线略严于员工基线）。
- **B2B 成熟当事方。** 分项加15（B2B 的体裁典型分数较低；不要因此惩罚它们）。
- **法院文件、法规、内部法律顾问文件。** 分项加25。

校准后的分项上限为100。

支柱分数 = 所有计算的可读性指标的校准分项平均值。取整为整数。

## 支柱报告部分应包含的内容

对每个指标，报告：

```
指标：Flesch 阅读易读性（英语）
计数：W=4,812；S=215；Sy=8,037
原始分数：28.4
区间：很难
受众：消费者（无校准调整）
分项分数：15
```

然后在部分末尾汇总：

```
支柱分数：18 / 100
解释：文档在应用的每个指标上都处于"很难"区间。对于面向消费者的
文档，这实质性低于起草良好的同类条款和条件的标准（后者在 Flesch
阅读易读性上通常为55–65分）。
```

## 边缘情形

- **少于100词的文档。** 不产生分数。注明"文档过短，无法进行有意义的可读性评估"。
- **含表格或大量项目符号部分的文档。** 仅对散文段落计算指标，从 W 和 S 计数中排除表格和项目符号列表。在方法说明中注明。
- **含大量数学符号或代码的文档。** 从 W 中排除代码块；在方法说明中注明。
- **混合语言文档。** 仅对主导语言部分计算指标；注明排除。
- **带连字符的词。** W 中计为一个词。
- **数字。** "1,000,000"计为一个词，FRE 计一个音节（因渲染形式超过6个字符，LIX 中计为长词）。

## 音节计数启发式（英语）

当无法获得精确计数时用于自动化估算：

1. 统计元音组（`aeiouy`，`y` 仅在辅音之间）。
2. 每个静默的末尾 `e` 减1（但不在 `le` 中）。
3. 词以辅音加 `le` 结尾的加1。
4. 每词最少1个音节。

这是教科书式启发式；是近似值。在方法说明中注明所用启发式。

## 音节计数启发式（法语）

1. 统计元音组，将 `oi`、`ai`、`ei`、`au`、`eau`、`ou`、`eu` 视为单个元音组。
2. 现代法语中静默的末尾 `e` 一般不发音——减1（诗歌/礼仪语境除外）。
3. 以 *-tion*、*-sion* 结尾的词，最后一组计为一个音节而非两个。
4. 每词最少1个音节。

## 音节计数启发式（德语）

1. 统计元音组，将 *au*、*ei/ai*、*eu/äu*、*ie* 视为双元音（各一个音节）。
2. 德语中的 Schwa 词尾（*-e*、*-en*、*-er*、*-el*）一般计为一个音节（不同于法语的静默 e）。
3. 复合词：分别统计每个组成部分的音节并求和。
4. 每词最少1个音节。
