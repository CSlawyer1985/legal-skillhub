## 二、筛查技术要点

### 精确匹配 vs 模糊匹配

**精确匹配：**
- 姓名完全一致
- 证件号码完全一致
- 地址/公司名完全一致

**模糊匹配（必须覆盖）：**
- 姓名变体：姓前名后 / 名前姓后、中间名缩写/全称
- 拼写差异：音译差异（如 Muhammad / Mohammed / Mohammad）
- 字符变体：特殊字符、空格、连字符、大小写
- 相似发音：Metaphone/Soundex 算法匹配
- 常见别名：曾用名、化名、昵称

### 筛查场景

| 场景 | 筛查对象 | 时机 |
|------|---------|------|
| 新客户准入 | 客户姓名、UBO、法定代表人、代理人 | 开户前 |
| 存量客户回溯 | 全量客户及 UBO | 名单更新后即时；至少每季度 |
| 交易发起 | 交易对手、收款人、中间行 | 交易前 |
| 跨境汇款 | 汇款人、收款人、受益人、往来行 | 汇款前 |
| 新增关联方 | 担保人、受益人、信托受托人 | 关联时 |

### 筛查阈值设定

- 精确匹配：100% 命中必须拦截
- 高相似度（≥85%）：人工复核
- 中等相似度（70%-85%）：结合国籍、出生日期、地址等辅助信息判断
- 低相似度（<70%）：记录日志，一般放行

## 三、命中处理流程

```
系统预警 / 人工发现命中
    ↓
立即冻结交易 / 暂停业务办理
    ↓
启动人工复核（不得由原经办人员复核）
    ↓
复核要点：
  - 是否为真实命中（同名不同人？）
  - 辅助信息交叉验证（出生日期、国籍、地址、证件号）
    ↓
结论判断：
  ├─ 确认命中 → 立即冻结资产，24小时内报告监管
  ├─ 疑似命中 → 暂停交易，要求客户提供补充证明
  └─ 误命中 → 记录误命中原因，放行并更新白名单
    ↓
报告与记录：
  - 监管报告（涉恐24小时内，其他及时）
  - 内部记录保存至少5年
```

## 四、常见误命中及排除方法

| 误命中类型 | 排除方法 |
|-----------|---------|
| 同名不同人 | 核对出生日期、国籍、证件号码、地址 |
| 常见姓名 | 对常见姓名（如张伟、王磊）提高阈值 |
| 公司名称相似 | 核对注册地、注册号、法定代表人 |
| 音译差异 | 要求客户提供护照原件核对 |
| 名单信息不完整 | 联系名单发布机构核实 |

## 五、白名单管理

**可纳入白名单的情形：**
- 经严格核实确认系同名不同人
- 有充分辅助信息证明非名单主体
- 经高级管理层审批

**白名单管理要求：**
- 定期复核（至少每半年）
- 名单更新后必须重新筛查
- 白名单记录完整保存
- 严禁未经复核擅自放行

## 六、制裁合规红线

**绝对禁止：**
- 为制裁名单主体新开账户或维持现有关系
- 协助制裁名单主体转移、隐匿资产
- 向制裁国家/地区提供被禁止的金融产品/服务
- 绕过制裁的"拆解交易"（stripping）
- 删除、修改交易中的制裁相关信息

**涉俄/涉伊/涉朝特别提示：**
- 注意行业制裁（SSI）与全面制裁的区别
- 警惕通过第三国中转规避制裁
- 对涉及上述国家的交易执行强化审查
