# 客户尽职调查深度指引与风险评级矩阵

## 一、客户身份核验清单

### 自然人客户
| 核验项 | 必查内容 | 常见风险信号 |
|--------|---------|-------------|
| 身份证件 | 真伪核验（联网核查/二代证阅读器） | 伪造、变造、过期、已挂失 |
| 人脸识别 | 活体检测 + 证件照比对 | 非本人、照片翻拍、戴口罩/墨镜 |
| 联系方式 | 手机号实名制核验、地址可送达 | 虚拟号、异地号、地址不存在 |
| 职业/收入 | 与交易规模是否匹配 | 无业但大额交易、职业与资金来源矛盾 |
| 开户目的 | 投资、结算、储蓄、消费等 | 含糊不清、前后矛盾 |

### 非自然人客户
| 核验项 | 必查内容 | 常见风险信号 |
|--------|---------|-------------|
| 营业执照/登记证书 | 真伪、有效期、状态（存续/吊销） | 刚注册即大额交易、注册地址虚假 |
| 法定代表人/负责人 | 身份核验、权限确认 | 挂名法人、年龄异常（过大/过小） |
| 股权结构 | 穿透至最终受益所有人 | 多层嵌套、循环持股、离岸架构 |
| 经营范围 | 与实际交易是否匹配 | 贸易公司频繁投资交易、空壳特征 |
| 经营场所 | 实地或视频核查 | 注册地址为住宅/集群注册/无实际办公 |

## 二、受益所有人（UBO）识别

**穿透规则：**
- 直接或间接拥有 ≥25% 股权/合伙权益
- 通过人事、财务等方式实施控制的自然人
- 如无符合上述条件者，识别高级管理人员

**高风险 UBO 特征：**
- PEP（政治公众人物）及其近亲属
- 来自 FATF 高风险国家/地区
- 涉及负面媒体（涉腐、涉恐、涉毒、制裁）
- 频繁变更 UBO 信息
- 无法合理解释控制权来源

## 三、客户风险评级矩阵

### 基础风险因子（总分 100）

| 因子类别 | 权重 | 评分标准 |
|---------|------|---------|
| 客户身份 | 25% | 本地居民(0) / 外地居民(5) / 外籍(10) / 匿名/假名(25) |
| 业务性质 | 20% | 低风险行业(0) / 一般行业(5) / 高风险行业(15) / 现金密集型(20) |
| 交易行为 | 25% | 正常(0) / 偶尔异常(5) / 多次异常(15) / 高度异常(25) |
| 地域风险 | 15% | 低风险国家(0) / 中风险(5) / 高风险(10) / 制裁国家(15) |
| 产品/渠道 | 15% | 低风险产品(0) / 中等(5) / 高风险(10) / 匿名产品(15) |

### 风险等级划分
| 分值区间 | 等级 | 审查周期 | 措施 |
|---------|------|---------|------|
| 0-25 | 低风险 | 3年复核 | 简化尽调 |
| 26-50 | 中风险 | 2年复核 | 标准尽调 |
| 51-75 | 高风险 | 1年复核 | 强化尽调 + 持续监测 |
| 76-100 | 极高风险 | 持续监测 | EDD + 限制业务/退出 |

### 高风险行业清单（示例）
- 虚拟货币/数字货币兑换
- 贵金属/珠宝/艺术品交易
- 房地产中介/开发商
- 赌场/博彩/游戏币
- 进出口贸易（尤其转口贸易）
- 第三方支付/预付卡发行
- 慈善/非营利组织
- 空壳公司/咨询/投资管理（无实质经营）

## 四、强化尽职调查（EDD）要点

### 对 PEP 客户
1. 确定 PEP 身份及职位层级（国家级/地区级/国际机构）
2. 识别其近亲属及密切关系人
3. 了解资金来源及财富来源合法性
4. 获得高级管理层批准方可建立/维持关系
5. 持续监控交易，至少每半年审查一次

### 对高风险国家/地区客户
1. 参考 FATF 灰名单/黑名单
2. 了解客户在当地的具体业务及交易目的
3. 增加交易真实性审查（合同、发票、物流单据）
4. 限制部分高风险产品使用

### 对复杂所有权结构
1. 绘制股权架构图，标注各层持股比例
2. 识别每层实际控制人的身份及背景
3. 评估架构复杂性的商业合理性
4. 如无合理解释，拒绝开户或提升风险等级

## 五、持续尽职调查触发条件

以下情形应立即重新评估客户风险等级：
- 客户信息发生变更（国籍、职业、股权结构等）
- 交易行为出现重大变化
- 触发系统预警或人工发现异常
- 收到监管通报或外部负面信息
- 制裁名单更新后筛查命中
- 客户被其他机构报送可疑交易涉及
