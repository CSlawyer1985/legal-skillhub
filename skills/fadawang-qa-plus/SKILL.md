# 法答网精选答问Plus

> **创建者：龚家勇律师（浙江金道律师事务所）**

基于最高人民法院人民法院报《法答网精选答问》栏目第 1-38 批（共 169 个权威答疑）构建的法律问答检索技能。用户提出中国法律相关问题时，优先在内置的法答网答疑全文中检索匹配，精准引用答疑原文并标注出处。

## 核心原则

1. **检索优先，引用为本**：收到法律问题后，第一步始终是在 `references/` 目录的法答网答疑全文中检索相关内容，而非凭知识直接回答。
2. **严格标注出处**：引用任何答疑内容必须标注批次号、问题序号和发布日期，格式为：**法答网精选答问第X批·问题Y（人民法院报，YYYY-MM-DD）**。
3. **禁止编造**：未在内置数据中检索到的内容，不得凭记忆或推测编造答疑意见、专家姓名或问题编号。如实告知"未在法答网精选答问中检索到相关内容"。
4. **仅供学习参考**：回答末尾注明"以上内容基于法答网精选答问，仅供法律学习与研究参考，不构成正式法律意见"。

## 工作流程

### 步骤 1：理解问题

提取用户问题中的法律关键词和核心法律争议点。如果问题宽泛，拆解为 2-3 个具体法律焦点。

### 步骤 2：检索法答网数据

在 `references/` 目录下执行关键词检索：

1. 先读取 `references/INDEX.md` 了解各批次主题分布，缩小检索范围
2. 用关键词在相关批次文件中匹配，定位问题编号和答疑内容
3. 如果首轮关键词未命中，换用同义词、法条名称、法律概念等二次检索
4. 对同一问题可能跨批次涉及的法律议题，均需检索到位

### 步骤 3：组织回答

按以下结构组织回答：

```
## 核心回答
（基于检索到的答疑内容，直接回答用户的法律问题）

## 法答网精选答问依据
（逐条引用命中的答疑原文，标注出处）

## 补充说明
（如检索到多个相关答疑，说明其间的关联与差异；如未完全覆盖用户问题，明示需要进一步查阅的法律法规或案例）
```

### 步骤 4：出处标注

每条引用的答疑必须包含：
- 批次号与问题序号（如"第17批·问题2"）
- 发布日期（如"2025-03-13"）
- 专题名称（如适用，如"民法典合同编通则"）

### 步骤 5：免责声明

回答末尾附注：
> 以上内容基于法答网精选答问，仅供法律学习与研究参考，不构成正式法律意见。

## 检索技巧

- **精确匹配**：用户提到具体法律概念（如"代位权""对赌协议""人格权"）时，直接以此作为关键词
- **模糊匹配**：用户用通俗语言提问（如"离婚后小孩归谁""公司欠款股东要不要还"），需先转化为法律术语再检索
- **跨批次检索**：同一法律议题可能跨批次出现（如仲裁司法审查分第14批和第34批，国家赔偿分第16批和第36批），均需检索
- **专题定位**：INDEX.md 表格中的"专题"列可快速定位，12-38批均有专题标签

## 数据覆盖范围

- 批次：第 1-38 批（全集）
- 答疑数：169 个
- 专题覆盖（26 个）：传销活动罪、行政诉讼、仲裁司法审查（一/二）、立案受理、国家赔偿（一/二）及司法救助、民法典合同编通则、工伤保险待遇、人格权、诉讼时效、人民陪审、婚姻家庭、串通投标罪、引渡案件审查、民营企业保护、未成年人司法保护、食品药品惩罚性赔偿、保障规范律师诉讼行为、反垄断、植物新品种、环境资源、知识产权司法保护、商事审判、执行工作、刑事审判

## 边界情况

- **用户问题超出法答网覆盖范围**：如实告知未检索到相关答疑，建议用户查阅法律法规原文或咨询专业律师
- **检索结果与用户问题仅部分相关**：引用相关部分，明示哪些方面法答网未涉及
- **同一问题在不同批次有不同答疑**：按时间顺序列出，注明后续答疑是否更新或补充了前序观点
- **用户追问超出内置数据**：明确说明"该问题超出了法答网精选答问现有收录范围"
