# 合同脱敏技能（Contract Desensitization）

## 功能概述

将企业合同转化为可对外发布的脱敏版本，在保留合同法律框架、句法结构与可读性的前提下，剔除一切可能导致商业秘密泄露、隐私暴露或商业战略暴露的敏感信息。

### 支持场景

| 场景 | 说明 |
|------|------|
| 中文合同脱敏 | 公司名、人员、金额、账户等全量敏感信息替换 |
| 外文合同脱敏 | 英文/其他语言合同的主体、财务、商业条款脱敏 |
| 中外文对照合同 | 双语同步脱敏，禁止跨语残留 |
| 涉外合同专项 | 境外主体、跨境财务、数据跨境传输等涉外敏感信息处理 |

### 工作流程

1. **接收识别** — 识别合同类型、语言类型、是否涉外
2. **客体清单** — 以表格输出全部敏感信息供用户确认（禁止直接脱敏）
3. **用户确认** — 用户增删条目、调整替代词后回复"确认脱敏"
4. **生成交付** — 按确认清单执行替换，生成 .docx 文件交付

### 脱敏范围

主体信息、人员信息、项目信息、财务信息、客户/供应商信息、商业敏感信息、涉外敏感信息（境外主体、跨境财务、数据跨境传输等）。

### 交付格式

最终交付物为完整的 Word（.docx）文件，包含脱敏后合同正文。
