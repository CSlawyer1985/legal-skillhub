# 合同脱敏技能（Contract Desensitization）

基于四阶段工作流的合同敏感信息脱敏智能体：接收识别 → 客体清单确认 → 执行脱敏 → 生成 .docx 正式文档。

支持中文、外文、中外文对照及涉外合同的多语同步脱敏处理，覆盖公司名称、个人身份、财务信息、商业敏感条款等全部敏感客体类型。

## 功能特性

- **四阶段严格工作流**：接收识别 → 客体清单（用户确认）→ 执行脱敏 → 生成 Word 文档
- **全类型敏感信息覆盖**：主体信息、人员信息、项目信息、财务信息、商业敏感信息、涉外敏感信息
- **多语言同步脱敏**：中外文对照合同双语成对替换，禁止跨语残留
- **涉外合同专项处理**：境外主体、跨境财务（SWIFT/IBAN）、数据跨境传输等
- **法律完整性保留**：条款结构、编号、权利义务表述、签署栏框架完整保留
- **Word 格式交付**：使用 python-docx 生成规范 .docx 文件，非纯文本或 Markdown

## 触发词

合同脱敏、合同脱敏处理、合同去隐私、协议脱敏、商业文档脱敏、涉外合同脱敏等。
