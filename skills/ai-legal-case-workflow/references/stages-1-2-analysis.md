## 阶段1：诉前案情分析

**目标**：通读全部原始材料，建立案件全貌认知，输出结构化概要报告，为后续所有阶段提供事实锚点。

**输入**：原始卷宗目录下的全部文件（MD/PDF/图片/音频转写文本/视频）

**操作步骤**：

1. **读取卷宗结构**
   - 读取 `00_卷宗目录与阅读说明.md`，了解文件夹结构和阅读建议
   - 确认材料清单与实际文件是否一致（有无缺失或多余）

2. **逐份读取全部材料**
   - MD文件：直接 Read
   - PDF 文件：先尝试直接读取文字层；为空或明显缺页时，使用当前平台已提供且已验证的 PDF 渲染或 OCR 能力，将相关页面按约 200dpi 转为图片后读取；无转换能力时记录文件并请用户提供图片版、OCR 版或文本版，不自动安装未授权工具
   - 图片文件：直接 Read（多模态读取）
   - 音频/视频文件：转文字后 Read；标注关键时间段（如"03:15 对方承认未付款"）

3. **提取关键信息**
   - 当事人信息：名称、住所地、法定代表人、联系方式
   - 合同条款：标的、价款、付款节点、交付条件、违约责任、争议解决条款
   - 付款记录：金额、时间、方式、对应合同节点
   - 沟通记录：催款、协商、承诺、拒绝等关键对话
   - 时间节点：签约、交付、催告、违约、解除、起诉等

4. **构建结构化时间线**
   - 按时间顺序排列所有关键事件
   - 每个节点标注证据来源（文件名/页码/段落）
   - 分类标注：合同事件（签约/变更/解除）| 履行事件（交付/验收/付款）| 违约事件（逾期/拒绝/瑕疵）| 诉讼事件（催告/起诉/反诉）
   - 区分"事实事件"与"诉讼事件"

5. **梳理主体关系**
   - 绘制当事人关系图（文字描述）
   - 识别实际控制人、关联方、利益相关方
   - 标注合同签署主体与实际履行主体是否一致

6. **诉讼时效分析**
   - 先判断请求权是否适用诉讼时效。请求停止侵害、排除妨碍、消除危险，不动产物权和登记的动产物权的权利人请求返还财产，请求支付抚养费、赡养费或者扶养费等，不适用诉讼时效（《民法典》第一百九十六条）。该条第二项不包括未登记的普通动产返还请求权，须先核对财产属性和登记制度
   - 适用诉讼时效的，逐项确定起算点、期间和届满日。一般期间为三年，自权利人知道或者应当知道权利受到损害以及义务人之日起计算；同步核算自权利受到损害之日起二十年的最长保护期间（第一百八十八条）
   - 区分中止与中断。中止事由须发生在时效期间的最后六个月内；中断后，从中断或者有关程序终结时起重新计算（第一百九十四条、第一百九十五条）
   - 说明届满效果：义务人取得不履行义务的抗辩权，权利本身不当然消灭；义务人自愿履行后不得请求返还，人民法院不得主动适用诉讼时效（第一百九十二条、第一百九十三条）
   - 风险预警写明“存在被提出诉讼时效抗辩的风险及后果”，不得写成“不能起诉”或“必然败诉”

7. **管辖初步评估**
   - 审查合同争议解决条款（协议管辖/仲裁条款）
   - 无协议时按法定管辖（被告住所地/合同履行地/侵权行为地）
   - 评估管辖权异议风险

8. **识别争议焦点**
   - 从材料中提炼核心分歧点
   - 每个焦点标注双方主张和对应证据

9. **编制证据清单**
   - 列明所有证据：编号、名称、来源、形式、证明目的、证明力评级（强/中/弱）
   - 标注待补充证据及获取方式
   - 评估证据链完整性（有无断裂环节）

10. **诉讼成本预估**
    - 诉讼费（按标的额计算）
    - 保全费+担保费（如需保全）
    - 律师费（按律师事务所备案、公示的收费标准和委托代理合同约定核算，并复核本地现行规定。拟采用风险代理的，先核验《司法部、国家发展和改革委员会、国家市场监督管理总局关于进一步规范律师服务收费的意见》规定的禁止案件范围、专门书面合同和分段最高比例，不能继续沿用旧的统一 30% 上限）
    - 时间成本（结合案件程序、法院审理情况和当前规定核验，不使用固定时长承诺）

11. **提出策略建议**
    - 方案A：直接起诉（适用条件+预期效果+风险）
    - 方案B：先发律师函（适用条件+预期效果+风险）
    - 方案C：协商和解（适用条件+预期效果+风险）
    - 推荐方案及理由

**输出模板**：详见 `references/templates.md` 中的"案件概要报告模板"

**关键经验**：
- PDF扫描件：优先转图片 Read，优于 tesseract OCR
- 不跳过任何文件：即使文件名看似不重要
- 时间线是所有后续分析的锚点，务必准确、完整、可追溯
- 诉讼时效分析必须在阶段1完成，避免立案后才发现时效已过
- 管辖评估同步进行，避免阶段3才发现管辖问题

## 阶段2：对方主体核查与财产保全

**目标**：对对方当事人进行全面背景调查，评估财产保全的必要性和可行性，为起诉/应诉策略提供数据支撑。

**输入**：对方当事人名称 + 阶段1案件概要报告

**操作步骤**：

### 企业被告核查路径

| 步骤 | 操作 | 工具 |
|------|------|------|
| 2.1 | 工商基本信息查询 | 企查查 MCP |
| 2.2 | 股权结构穿透（股东、持股比例、变更历史） | 企查查 MCP |
| 2.3 | 企业风险扫描（涉诉、失信、行政处罚、经营异常） | 企查查 MCP |
| 2.4 | 司法涉诉查询（案件列表、裁判文书、执行信息） | 元典 MCP |
| 2.5 | 信用风险评估 | 元典 MCP |
| 2.6 | 空壳化特征识别（实缴vs注册资本、参保人数、经营场所） | 综合分析 |
| 2.7 | 股权变动时间线与诉讼时间线交叉比对 | 综合分析 |
| 2.8 | 知识产权资产查询（商标、专利、著作权） | 企查查 MCP |
| 2.9 | 责任主体扩张路径排查。区分：（a）执行程序可依《最高人民法院关于民事执行中变更、追加当事人若干问题的规定》第十七条至第二十条追加的法定情形；（b）关联公司人格混同、法人人格否认等原则上须另行起诉的路径。认缴期限未届满股东的出资加速到期，依《公司法》（2023修订）第五十四条单独论证 | 综合分析 |
| 2.10 | 保全方案设计（结合标的额、资产状况、可行性） | 综合分析 |

### 个人被告核查路径

| 步骤 | 操作 | 工具 |
|------|------|------|
| 2.1 | 身份信息记载核对（姓名、身份证件号码、户籍地址）。仅依据委托人合法提供的在案材料核对，不通过非正规渠道查询；信息不足时依法申请法院调查核实 | 在案材料 |
| 2.2 | 涉诉记录查询 | 元典 MCP |
| 2.3 | 失信/限消记录查询 | 元典 MCP |
| 2.4 | 关联企业任职/持股查询 | 企查查 MCP |
| 2.5 | 住所与财产线索整理。区分委托人合法持有材料、本人书面授权信息、依法公开登记信息和依法申请法院调查的信息。银行账户、社保、户籍等受限信息依法申请法院调查令或通过法院查控程序获取；禁止通过非正规渠道获取，禁止仅凭社保缴纳地推断经常居住地 | 在案材料 + 依法查询 + 依法申请法院调查 |
| 2.6 | 保全方案设计（银行存款/不动产/车辆/工资收入） | 综合分析 |

### 跨境与区际要素检查

本版只做要素识别、风险提示和专项核验闸门，不替代涉外、港澳台区际法律专项分析。识别到下列要素时，标记 `specialist_review_required=true`，在完成现行法、条约或安排及个案连接点核验前，不输出确定性程序结论：

- 对方是外商投资企业、外国企业或港澳台企业：分别评估管辖、送达方式与期间。外商投资企业不当然等于涉外案件；是否具有涉外因素须依据个案事实判断
- 对方财产在境外或港澳台地区：区分外国法院判决、香港判决、澳门判决和台湾地区判决的认可与执行路径，不混用规则
- 合同约定境外仲裁或境外法院管辖：核验条款效力、仲裁地或法院地、平行程序以及裁决或判决的承认与执行路径

### 专门领域识别闸门

识别到知识产权、海事海商、破产衍生诉讼等专门领域要素时，本版只形成要素清单、程序风险提示和待核验问题，标记 `specialist_review_required=true`。在专项律师或现行专门法源复核前，不直接套用普通合同纠纷的管辖、期限、证据或保全结论。未来可由专项模块或衍生 Skill 承接完整处理。

**输出模板**：详见 `references/templates.md` 中的"主体核查报告模板"

**关键经验**：
- 多维交叉验证：企查查 + 元典双重验证
- 关注诉讼期间股权/法人变更（资产隔离信号）
- 参保人数、经营场所和实缴情况都只是风险信号，应结合经营、资产、人员、交易和多来源数据综合判断，不能凭单一指标认定空壳化
- 零涉诉不等于低风险：追溯更名前信息
- 追加被执行人线索在阶段2就应排查，不要等到执行阶段才发现
- 涉及只有一个股东的公司时，《公司法》（2023修订）第二十三条第三款以股东不能证明公司财产独立于股东自己的财产为连带责任前提，属于举证责任倒置。核验个案事实后再提出责任承担方案，不得直接下连带责任结论
- 涉及自然人身份、社保、不动产、账户等个人信息时，先核验《个人信息保护法》第十三条规定的处理依据，并遵守目的明确、直接相关和最小必要原则；对个人自行公开或其他合法公开的信息，也只在合理范围内处理（第二十七条）。金融账户、行踪轨迹等敏感个人信息还须满足特定目的、充分必要性和严格保护要求（第二十八条）；无合法渠道的，只能依法申请法院调查
