## 通用首页状态块与失败回执

每份阶段产出首页先放状态块。完整字段含义和恢复规则见 `references/tooling-and-fallbacks.md`。

```yaml
run_status: in_progress | completed | partial | blocked | waiting_external
completed_scope:
  - <本次实际完成的阶段或文书>
lawyer_review_status: pending | reviewed | finalized
law_source_status: verified | partial | unverified | not_applicable
unreadable_or_unverified_items:
  - <无法读取、缺失或未经核验的事项>
resume_from: <下一步或恢复位置>
```

发生异常或外部等待时追加：

```yaml
failed_step: <阶段和步骤；外部等待时写 waiting_for>
attempts: <实际尝试次数>
completed_outputs:
  - <已完成最低检查的产出>
fallback_taken: <已执行的降级动作；没有则写 none>
safe_to_retry: true | false | unknown
user_action_required:
  - <需要用户补充、确认或授权的动作>
```

不要用 `completed` 代替律师审核、格式验证或外部提交状态。完整填充样例见 `references/complete-output-example.md`。

## 阶段3：起诉材料包模板

### 3.1 民事起诉状.md

```
民事起诉状.md
├── 一、当事人信息
│   ├── 原告：法人或非法人组织写明名称、住所、法定代表人或主要负责人姓名及职务、联系方式；自然人写明姓名、性别、年龄、民族、职业、工作单位、住所、联系方式（《民事诉讼法》第一百二十四条第一项）
│   ├── 被告：法人或非法人组织写明名称、住所等信息；自然人写明姓名、性别、工作单位、住所等信息（同条第二项）
│   ├── 身份核验信息：统一社会信用代码、身份证件号码等不是法定起诉状记载事项，但法院表单或在线立案系统可能要求。按受理法院现行要求准备；无法取得的，说明情况并依法申请法院调查
│   └── 委托诉讼代理人：姓名、执业机构、联系方式
├── 二、诉讼请求
│   ├── 请求一：[具体请求，含金额]
│   ├── 请求二：[具体请求，含金额]
│   ├── 请求N：...
│   └── 本案诉讼费、保全申请费由被告负担；保全担保费仅在具备请求权基础及必要性、实际发生、因果关系证据时另行主张（最终均由法院依法裁判）
├── 三、事实与理由
│   ├── 事实部分（按时间线叙述，每段标注证据编号）
│   │   ├── 合同关系成立阶段
│   │   ├── 合同履行阶段
│   │   ├── 违约/侵权发生阶段
│   │   └── 催告与协商阶段
│   ├── 理由部分（法律定性 + 法条引用 + 论证）
│   └── 小结（归纳事实与法律的对应关系）
├── 四、管辖法院
│   ├── 管辖依据（协议管辖/被告住所地/合同履行地）
│   └── 管辖条款原文引用（如适用）
├── 五、此致
│   └── XX人民法院
├── 六、附件清单
│   ├── 本诉证据目录及证据材料
│   ├── 当事人主体材料
│   └── 授权委托书
└── 七、落款
    ├── 起诉人（盖章/签名）
    ├── 法定代表人/委托代理人
    └── 日期
```

## 阶段7：格式转换指南

### MD → HTML

- 前提：当前平台能够创建文件并使用浏览器或等效能力验证结果；不满足时保留 Markdown 并说明限制
- 卡片式布局、渐变背景、响应式设计、打印友好
- 必须处理：表格渲染、中文排版（字体、行距）、响应式图片
- 推荐模板结构：头部概览 → 主体卡片 → 侧边导航 → 底部附注

### MD → Word (.docx)

- 工具：优先使用当前平台已有且可验证的文档工具；经用户授权后可在 managed venv 中使用 python-docx
- 格式规范：
  - 正文：宋体 12pt，1.5倍行距
  - 一级标题：黑体 16pt 加粗
  - 二级标题：黑体 14pt 加粗
  - 三级标题：黑体 13pt 加粗
  - 页边距：上下2.54cm，左右3.17cm
  - 页眉：案件名称 + 文书名称
  - 页脚：页码（"第X页/共Y页"）
- 安装命令（仅在用户授权后执行）：`<managed-python-venv-pip> install python-docx`

### MD → PDF

- 工具：当前平台已提供且已验证的 PDF 转换能力；不可用时保留 Markdown 或 DOCX 并说明限制

### PDF → 图片（扫描件处理）

- 工具：当前平台已提供且已验证的 PDF 渲染或 OCR 能力，约 200dpi；不可用时请求用户提供图片版、OCR 版或文本版
- 参数：dpi=200
- 输出后使用 Read 工具直接读取图片
