# 质量控制检查清单

本文件用于民事一审七阶段。识别为 `procedure=second_instance` 时，改用 `appeal-quality-checklist.md` 的通用门和 D0–D6，不得把一审检查项代替二审入口、期限和裁判审计质量门。

本文档定义 AI 辅助民事诉讼办案工作流各阶段的专项质量检查点。
每完成一个阶段，按对应清单逐项检查，确认通过后方可进入下一阶段。

## 阶段通用检查（每阶段结束时必做，先于专项检查）

- [ ] 材料完整性：该阶段相关文件均已读取，无法读取的已记录原因
- [ ] 事实准确性：每项事实陈述均可回链到证据文件名、页码或段落
- [ ] 法源有效性：引用的法条、司法解释、判例均已取现行文本核实，并按统一标注串标注
- [ ] 逻辑一致性：本阶段各部分论证自洽，与前序阶段产出无冲突
- [ ] 格式规范性：文件命名、章节结构和标题层级统一
- [ ] 状态标注：已区分 AI 草稿、律师待复核和律师已定稿
- [ ] 运行状态：`run_status` 与实际完成范围一致；`partial`、`blocked`、`waiting_external` 已列出未完成事项和恢复位置
- [ ] 失败回执：发生异常时已记录实际尝试次数、降级动作、是否可安全重试和用户待办，没有把降级包装成完成

## 阶段1：诉前案情分析专项检查

### 材料完整性
- [ ] 是否按卷宗目录逐一确认了所有文件均已读取
- [ ] 是否存在因格式问题被跳过的文件（如有，记录原因）
- [ ] PDF扫描件是否已通过转图片方式成功读取

### 时间线准确性
- [ ] 时间线节点是否覆盖了合同签订、履行、争议、诉讼全周期
- [ ] 每个时间节点是否标注了证据来源（文件名 + 段落位置）
- [ ] 时间线是否存在逻辑矛盾（如原因在结果之后）

### 争议焦点质量
- [ ] 争议焦点是否从材料中自然提炼，而非预设
- [ ] 每个焦点是否有双方主张的对照
- [ ] 焦点数量是否合理（不宜过多也不宜过少）

### 证据清单完整性
- [ ] 是否覆盖了所有出现在材料中的证据
- [ ] 每项证据的证明目的和证明力评级是否合理
- [ ] 是否标注了待补充证据

### 策略建议可行性
- [ ] 诉讼策略是否有具体操作步骤，而非泛泛之谈
- [ ] 风险点是否逐一列出并有应对建议

### 诉讼时效与管辖
- [ ] 是否先判断各请求权是否适用诉讼时效，再核算起算点、期间和届满日
- [ ] 是否分析了各请求权的诉讼时效起算点和届满日
- [ ] 是否区分时效中断与中止，并核算二十年最长保护期间
- [ ] 是否把届满后果写成抗辩风险，而非“不能起诉”或“必然败诉”
- [ ] 是否完成了管辖初步评估（协议管辖/法定管辖）
- [ ] 涉外、港澳台、知识产权、海事海商或破产衍生诉讼要素是否已触发 `specialist_review_required=true`，未越过专项核验闸门输出确定结论
- [ ] 是否预估了诉讼成本（诉讼费+保全费+律师费+时间）

## 阶段2：被告主体核查专项检查

### 数据覆盖完整性
- [ ] 是否同时使用了企查查和元典两个来源交叉验证
- [ ] 是否追溯了企业更名前的信息（如曾用名不为空）
- [ ] 是否有 MCP 返回空数据的情况（如有，是否已标注并说明）

### 股权分析深度
- [ ] 是否穿透到了最终自然人股东或国资主体
- [ ] 股权变更时间线是否与诉讼时间线进行了交叉比对
- [ ] 是否评估了代持风险（如适用）

### 空壳化评估客观性
- [ ] 是否使用了多指标综合评估而非单一指标判断
- [ ] 实缴资本、参保人数、注册地址、经营活跃度是否全部核查
- [ ] 是否有"零涉诉 = 低风险"的误判（需结合经营活跃度判断）

### 保全方案可行性
- [ ] 保全金额建议是否有标的额依据
- [ ] 保全金额是否未超出请求范围或与本案有关财物范围
- [ ] 保全对象是否具体明确
- [ ] 是否评估了保全的执行难度
- [ ] 是否提供了替代方案
- [ ] 是否已向当事人书面告知申请错误的赔偿风险并留存确认
- [ ] 是否建立保全期限台账和续行申请提醒

### 追加被执行人线索
- [ ] 是否区分“执行程序可依法定情形追加”与“须另行起诉主张”两条路径，未把关联公司人格混同直接写成追加事由
- [ ] 涉及股东出资责任时，是否区分未届出资期限与已届期未缴，并核验现行《公司法》的认缴期限和加速到期规则
- [ ] 涉及只有一个股东的公司时，是否说明股东责任以不能证明公司财产独立为前提，未直接下连带责任结论
- [ ] 知识产权资产是否纳入财产线索范围

### 个人信息合规
- [ ] 自然人身份、户籍、社保、账户和不动产信息是否逐项记录合法来源、处理必要性与授权边界
- [ ] 无合法公开或授权渠道的信息是否改为依法申请法院调查，未通过非正规渠道获取或用间接数据作确定性推断

## 阶段3：起诉材料制作专项检查

### 起诉状质量
- [ ] 诉讼请求是否具体明确（金额、利息计算方式、起止日期）
- [ ] 事实部分是否与证据目录逐项对应（无"有事实无证据"情况）
- [ ] 理由部分引用的法条是否经当前可用的权威法源工具核实
- [ ] 管辖法院确定是否有法律依据

### 证据目录质量
- [ ] 证据分组是否按证明目的清晰分类
- [ ] 对外证据目录是否只列编号、名称、来源或提供人、形式、页数和证明对象
- [ ] 证明力评级、薄弱环节和使用策略是否仅保留在内部证据分析表
- [ ] 是否标注了待补充证据及获取方式
- [ ] 证据与诉讼请求对应关系是否完整

### 保全申请书质量（如适用）
- [ ] 保全金额是否有明确计算依据
- [ ] 保全必要性是否由可查证的客观事实支撑，对外文书未直接作“空壳公司”“资产隔离”等定性
- [ ] 担保方式是否已向受理法院确认可接受，担保数额是否区分诉中与诉前并符合现行规则，相关机构是否提供实际报价
- [ ] 财产线索是否具体（银行名称、不动产地址、车牌号等）

### 立案材料完整性
- [ ] 起诉状份数是否正确（正本1份+被告人数副本）
- [ ] 证据材料份数是否与起诉状一致
- [ ] 当事人主体材料是否齐全
- [ ] 诉讼费是否已按标的额计算并告知当事人

---

## 阶段4：反诉分析专项检查

### 请求权基础分析完整性
- [ ] 是否逐一分析了对方每项反诉请求
- [ ] 每项请求的法律规范构成要件是否标注完整
- [ ] 是否逐要件分析了对方的举证满足程度

### 对方证据分析深度
- [ ] 是否识别了对方证据的薄弱环节
- [ ] 是否对损失金额主张进行了逐项核查（无明细/含无关费用/未扣残值）
- [ ] 是否区分了行政认定与质量认定

### 不利证据识别
- [ ] 是否识别了所有可能被对方利用的我方证据（"双刃剑"）
- [ ] 每项不利证据是否有具体的化解方案

### 应对策略质量
- [ ] 是否逐项给出了应对策略（而非笼统策略）
- [ ] 每项策略是否包含反驳思路 + 法律依据 + 证据运用
- [ ] 是否考虑了举证时序对可信度的影响
- [ ] 是否分析了管辖权异议理由和应对方案
- [ ] 是否分析了诉讼时效抗辩的事由和证据

---

## 阶段5：应诉材料包专项检查

### 答辩状质量
- [ ] 是否逐条回应了对方的全部反诉请求
- [ ] 每条回应是否有事实依据和法律依据
- [ ] 是否经主代理审核并修改定稿

### 证据目录质量
- [ ] 是否按本诉/反诉清晰分类
- [ ] 每项证据是否列明名称、来源、证明目的、证明力
- [ ] 是否标注了待补充证据

### 法源核实完整性
- [ ] 是否覆盖了答辩状引用的全部法条
- [ ] 每条法条是否经当前可用的权威法源工具验证效力状态
- [ ] 每条法条是否标注了核实来源和核实时间
- [ ] 是否检索了支持性判例
- [ ] 是否检索了不利判例并提供了区分理由

### 对抗复核质量
- [ ] 是否站在对方角度逐条审查了我方材料
- [ ] 是否对对方证据进行了三性分析
- [ ] 是否制定了庭审交叉询问预案
- [ ] 调解方案是否包含三套梯度方案

### 发问提纲与调解预研
- [ ] 发问提纲是否具体到每个问题的预期答案和追问方向
- [ ] 是否预测了对方可能的发问及我方回应策略
- [ ] 调解预研是否包含底线方案、目标方案、开价方案
- [ ] 调解时机评估是否有理由支撑

### 子代理管理（仅在实际启用并行协作时适用）
- [ ] 所有子代理是否已发送关闭请求，并确认产出已保存
- [ ] 是否已使用平台实际支持的能力清理协作资源；无法清理时是否如实报告真实状态
- [ ] 是否存在未完成的子代理任务
- [ ] 串行执行的案件：本节整体标注“不适用”，不得虚构子代理管理动作

---

## 阶段6：庭审文书专项检查

### 庭前准备文书
- [ ] 庭审提纲是否覆盖争议焦点、举证顺序、质证要点、辩论框架
- [ ] 发问提纲是否具体到预期答案和追问方向
- [ ] 质证意见是否覆盖对方全部证据的三性分析
- [ ] 代理词初稿是否留有庭审调整空间

### 庭审分析准确性
- [ ] 争议焦点是否与法庭归纳的焦点一致
- [ ] 对法庭关注点的分析是否限于庭后补强方向，已标注为推测并写明依据，且未向委托人转述为结果预测
- [ ] 是否识别了庭审中出现的所有新情况

### 庭后代理意见书质量
- [ ] 是否回应了庭审中的新证据、新论点
- [ ] 是否补充了庭审中未能充分展开的论证
- [ ] 法律依据是否经当前可用的权威法源工具验证（新增引用部分）

### 调解方案务实性
- [ ] 三套方案是否构成合理的梯度
- [ ] 每套方案是否包含了金额、条件、风险评估
- [ ] 是否提供了具体的谈判节奏建议
- [ ] 最积极方案是否留有回旋余地

---

## 阶段7：格式转换专项检查

### 交付物完整性
- [ ] 法院交付物是否按受理法院或网上立案系统要求准备为 DOCX、PDF、扫描件或纸质件；自然人按要求签名，企业或其他组织按要求盖章或完成系统规定的签署方式，未把“签名并盖章”设为所有主体的统一要求
- [ ] 客户交付物是否使用用户要求且当前平台实际可生成、可验证的格式；面向客户的内容是否已适当解释法律术语
- [ ] 团队内部留存是否为完整 MD 格式
- [ ] 客户友好版摘要是否包含案件现状、建议方案、主要风险情景与不确定因素，且不含胜诉概率、结果区间或对判决结果的预测与承诺
- [ ] 请求的格式无法生成时，是否保留 Markdown 或其他可验证降级件，标注 `run_status=partial` 并说明缺失工具和恢复方式

### 归档标准
- [ ] 目录结构是否符合归档标准（01-08分类）
- [ ] 归档清单是否包含全部文件索引
- [ ] 文件命名是否统一（阶段_文书类型-版本号格式）

### HTML 文件检查
- [ ] 是否在浏览器中正确渲染
- [ ] 中文排版是否正常（字体、行距、换行）
- [ ] 表格是否完整显示
- [ ] 是否支持打印（@media print）

### Word 文件检查
- [ ] 字体设置是否正确（宋体正文/黑体标题）
- [ ] 行距是否为 1.5 倍
- [ ] 页边距是否为标准尺寸
- [ ] 页眉页脚是否正确
- [ ] 目录是否可自动更新

### PDF 文件检查
- [ ] 是否可正常打开
- [ ] 中文是否正常显示
- [ ] 页数是否合理

## 法定期限专项检查（每阶段均须执行）

- [ ] 是否核算并书面告知当事人本阶段全部法定或法院指定期限、起算点、届满日及最后办理日期
- [ ] 被告方答辩期是否按收到起诉状副本之日起十五日核算（《民事诉讼法》第一百二十八条）；涉外当事人在境内无住所等特别情形是否另行核验
- [ ] 管辖权异议是否在提交答辩状期间提出（第一百三十条）。未提异议并应诉答辩或提出反诉的，是否识别默示管辖后果及级别、专属管辖例外
- [ ] 举证期限和证据交换时间是否已确认；确有困难时是否在期限届满前申请延长
- [ ] 反诉是否在案件受理后、法庭辩论结束前提出（《民诉法解释》第二百三十二条），当事人范围、法律关系、因果关系或事实基础是否符合第二百三十三条规定的合并审理条件；是否自提起反诉次日起七日内预交受理费或遵守法院通知
- [ ] 诉前保全后是否在法院采取措施之日起三十日内起诉或申请仲裁（《民事诉讼法》第一百零四条）
- [ ] 保全措施是否临近期限，是否至少在期限届满七日前申请续行；期限届满前七日内才收到法律文书等情形是否立即处理并记录原因
- [ ] 一审判决或裁定送达后是否分别按十五日、十日核算上诉期（第一百七十一条）；是否识别小额诉讼一审终审或其他不可上诉情形
- [ ] 生效后是否告知申请执行期间；出现再审需求时是否转入专门程序核验，不套用本版一审期限表

> 上述固定条号已于 2026-08-02 依据当时现行官方文本校准。实际案件仍须结合送达方式、在途期间、法定休假日、涉外身份、法院通知和后续修法逐案复核。

## 跨阶段一致性检查

当完成全部阶段后（或任两相邻阶段产出关联时），执行以下检查：

- [ ] 后续阶段引用的事实是否与阶段1时间线一致
- [ ] 不同阶段引用的法条版本是否一致
- [ ] 证据编号在不同文档中是否统一
- [ ] 当事人名称、金额数字是否前后一致
- [ ] 文件命名规则是否统一
