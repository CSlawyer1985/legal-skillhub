## 阶段3：起诉阶段材料制作

> **适用条件**：`role=plaintiff` 时执行。被告方代理跳过此阶段，从阶段4开始。

**目标**：准备向法院提交的全部立案法律文书，完成起诉材料包。

**输入**：阶段1案件概要报告 + 阶段2主体核查报告

**子代理架构**（可并行）：

```
主代理（协调者）
├── complaint-drafter      → 民事起诉状.md
├── evidence-cataloger     → 本诉证据目录.md
├── preservation-applicant  → 财产保全申请书.md（如需）
├── property-investigator   → 申请法院调查收集证据申请书.md / 财产线索清单.md（如需）
└── legal-verifier          → 起诉阶段法源核实报告.md
```

**操作步骤**：

1. **确定诉讼请求**
   - 逐项论证请求权基础，不套用“本金+利息+违约金+律师费”的固定组合：
     - 本金或主给付义务：核对合同约定、履行状态和到期条件
     - 利息或资金占用损失：有约定的先核验效力与司法保护上限；无约定的，按买卖、建设工程、融资租赁、民间借贷等具体法律关系核验现行规则，不套用统一 LPR 答案。民间借贷合同成立于 2020 年 8 月 20 日之后的，司法保护上限为合同成立时一年期 LPR 的四倍；合同成立于此前且案件在该日之后新受理的，只有符合《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》第三十一条条件时才分段计算。该规则不得移用于金融借款或其他合同纠纷
     - 违约金：以合同明确约定为前提，并评估对方依据《民法典》第五百八十五条请求增加或适当减少的空间
     - 律师费：仅在合同明确约定、法律或司法解释有特别规定，并有实际发生及合理性证据时评估主张
     - 诉讼费和保全申请费：可提出由对方负担，最终由法院依法决定。保全担保费或保全责任保险费不当然属于诉讼费用，只有具备合同依据或损失赔偿请求权基础，并能证明必要性、实际发生和因果关系时才单独评估主张
   - 对具备依据的利息请求，逐项写明基数、计算基准、起算日、暂计截止日以及继续计算至实际清偿之日的表述；不存在依据时不得机械主张
   - 确认诉讼标的额并预估诉讼费，记录计算口径和核验日期

2. **确定管辖法院**
   - 审查协议管辖条款效力
   - 无协议管辖时按被告住所地或合同履行地确定
   - 评估管辖权异议风险

3. **起草核心文书**（是否启用子代理按阶段5步骤1的四项判断执行，`parallel_enabled=true` 只表示具备资格，不表示直接启动）
   - `complaint-drafter`：起草起诉状（事实+理由+请求），事实部分与证据目录严格对应
   - `evidence-cataloger`：编制对外证据目录，按证明对象分组，每项列明编号、名称、来源或提供人、形式、页数和证明对象；证明力评级与薄弱环节另记内部证据分析表
   - `legal-verifier`：通过当前可用的权威来源核实起诉状引用的全部法条

4. **保全与调查申请**（根据阶段2评估结果）
   - 如需保全：`preservation-applicant` 起草保全申请书，确定担保方式（财产担保/保险公司保函/担保公司担保），附财产线索
   - 如需调查收集案件证据：`property-investigator` 起草申请法院调查收集证据申请书，写明具体证据、持有单位、关联待证事实以及因客观原因不能自行收集的理由
   - 如需保全查控：`property-investigator` 起草财产线索清单随保全申请提交，逐项注明线索来源；不得与调查收集证据申请混为一份文书

5. **编制立案材料清单**
   - 起诉状：正本1份（法院留存）+ 按被告人数提出副本（《民事诉讼法》第一百二十三条）；有第三人的按受理法院要求增加相应份数，最终以法院或网上立案系统通知为准
   - 证据目录+证据材料（同上份数）
   - 当事人主体材料（营业执照/身份证复印件）
   - 授权委托书+律师执业证复印件
   - 送达地址确认书
   - 诉讼费缴费计算单

**输出模板**：详见 `references/templates.md` 中的"起诉材料包模板"

**关键经验**：
- 诉讼请求金额覆盖利息计算到实际清偿日，避免立案后变更请求
- 起诉状事实部分必须与证据目录逐项对应，防止"有事实无证据"
- 保全申请尽早提交，避免被告收到起诉状后转移财产
- 保全担保形式与材料要求因法院而异。先确认受理法院接受的现金、实物、第三方财产担保、担保公司担保、财产保全责任保险保函或金融机构独立保函，再比较实际报价，不以记忆费率向当事人报价
- 诉讼中法院责令提供财产保全担保的，担保数额不超过请求保全数额的百分之三十；保全财产系争议标的的，不超过争议标的价值的百分之三十。诉前财产保全原则上应提供相当于请求保全数额的担保，特殊情况由法院酌情处理（法释〔2016〕22号第五条）
- 财产保全责任保险合同担保和金融机构独立保函分别有法释〔2016〕22号第七条、第八条依据，但法院是否接受及材料要求仍须个案确认
- 法释〔2016〕22号第五条仍使用修订前《民事诉讼法》第一百条的编号，对应现行《民事诉讼法》（2023修正）第一百零三条。引用时须换算，不得把现行第一百条误写为财产保全条款
- 建立保全期限台账。申请续行保全原则上应在期限届满七日前向法院提出；临近届满才收到法律文书等特殊情形立即申请并记录原因（法释〔2016〕22号第十八条）
- 证据目录按"合同关系成立→违约事实→损失计算→其他"分组，逻辑清晰
- 起诉状提交份数 = 正本1份 + 被告人数份副本。正本即法院留存份，不再另加；律师自留份不计入提交份数

**异常处理**：

| 异常场景 | 检测方式 | 回退策略 |
|----------|----------|----------|
| 管辖权异议风险高 | 协议管辖条款可能无效，或存在多个有管辖权法院 | 先核验专属管辖和级别管辖限制，不得通过协议或选择规避；只在法定或有效约定的多个法院之间依法选择，不得虚构履行地或追加无实质关联被告制造连接点；同步准备管辖异议答辩 |
| 证据不足 | 关键事实无证据支撑 | 列出待补充证据清单，建议补充后再立案 |
| 保全担保困难 | 当事人无法提供现金担保 | 先向受理法院确认替代担保方式和材料要求，再向相应机构取得实际报价并书面告知当事人 |
| 诉讼费过高 | 标的额大导致预缴诉讼费超出当事人承受能力 | 先按主体和具体情形分别核验司法救助路径：免交只适用于自然人（《诉讼费用交纳办法》第四十四条）；减交、缓交分别依第四十六条、第四十七条核验，社会福利机构、救助管理站等符合列举情形的组织不得被遗漏，缓交也不得仅因申请主体是企业或其他组织而直接排除。普通企业仅有标的额大或资金紧张，不当然符合司法救助条件，不得把司法救助作为常规诉讼资金安排。不得为规避预交义务而人为拆分同一法律关系项下同一笔已到期债权，也不得仅为降低预交金额而压低请求。请求在法律关系、履行期或事实基础上客观可分时，才逐项评估分别主张，并书面提示诉讼时效、重复起诉或既判力、重复成本及未主张部分的后续救济风险 |

## 阶段4：反诉分析与应对策略

**目标**：系统分析对方反诉/答辩的请求权基础，识别薄弱环节，制定应对策略。

**输入**：阶段3起诉材料（原告方）或 收到起诉状（被告方） + 对方反诉/答辩材料

**场景分支**：

| 场景 | 条件 | 处理方式 |
|------|------|----------|
| 有反诉 | 对方提起反诉 | 完整执行本阶段全部步骤 |
| 仅答辩无反诉 | 对方仅提交答辩状 | 跳过反诉分析，执行答辩分析和庭审准备步骤 |
| 对方未提交答辩状 | 答辩期届满未收到答辩状 | 不等于对方不应诉。仍按对方可能到庭抗辩准备全套材料，同时排查是否存在送达瑕疵 |
| 对方经合法传唤未到庭 | 法院通知或庭审当日确认 | 核实送达是否合法，包括公告送达期间是否届满；缺席审理时强化举证充分性和法律论证，不得降低准备标准 |

**操作步骤**：

1. **读取对方材料**
   - 按顺序读取全部起诉与反诉/答辩材料（先本诉后反诉）
   - 标注对方新提交的证据（对比我方证据清单）

2. **逐项拆解反诉/答辩请求**
   - 请求事项 + 事实依据 + 法律依据
   - 区分"否认型答辩"（否认我方主张）和"主张型反诉"（独立请求）

3. **请求权基础构成要件分析**
   - 分析每项请求的请求权基础（识别法律规范构成要件）
   - 逐要件评估对方举证满足度
   - 标注对方举证不能的要件（攻击点）

4. **管辖权异议分析**
   - 对方是否提出管辖权异议
   - 评估异议理由是否成立
   - 准备管辖权异议答辩（如法院移送管辖）

5. **诉讼时效抗辩分析**
   - 对方是否提出诉讼时效抗辩
   - 我方时效中断/中止事由是否充分
   - 如时效届满，评估对方放弃时效抗辩的可能性

6. **识别对方证据薄弱环节**
   - 无明细损失主张
   - 缺乏因果关系证明
   - 举证不能
   - 证据形式瑕疵（复印件、无签字）

7. **识别我方不利证据**
   - "双刃剑"证据（如通话录音中不利表述）
   - 每项不利证据制定化解方案

8. **举证安排与出示节奏**
   - 确认法院指定的举证期限和证据交换时间，全部证据原则上在期限内提交，不以策略为由故意超期
   - 逾期后果分层处理：因客观原因逾期，或者对方对逾期未提出异议的，视为未逾期；非因故意或重大过失逾期的，法院应当采纳并予以训诫；因故意或重大过失逾期的，法院原则上不予采纳，但证据与案件基本事实有关的仍应采纳，并可依法训诫、罚款（《民诉法解释》第一百零一条、第一百零二条）
   - 确有正当理由需要延期的，在期限届满前书面申请延长；已经逾期的，提交客观原因说明及证明材料，不因逾期当然放弃举证
   - 可以策略性安排的是期限内的提交顺序、质证展开顺序和论证重点，不是超期出示
   - 对方逾期举证时及时决定是否提出异议；不提出异议将视为未逾期

9. **制定逐项应对策略**
   - 反驳思路 + 法律依据 + 证据运用方案
   - 区分"可全部否认""部分承认""需另行主张"

10. **评估调解空间**
    - 双方强弱态势分析
    - 预判调解可能性和条件
    - 调解底线建议

**输出模板**：详见 `references/templates.md` 中的"反诉分析报告模板"

**关键经验**：
- 双刃剑证据提前识别并准备化解方案
- 损失金额逐项核查：无明细、含无关费用、未扣残值是常见问题
- 区分行政认定与质量认定
- 质量异议先做实体失权分析：核查合同约定的检验期间或质量保证期、买受人的通知时间和内容、合理期间及两年最长通知期间。逾期未通知可能产生“视为数量或者质量符合约定”的后果；出卖人知道或者应当知道标的物不符合约定的，不受通知期间限制（《民法典》第六百二十条至第六百二十三条）
- 完成实体规则核验后，再评估“付款到期后才提质量问题”对抗辩可信度的影响，不以可信度判断替代失权分析
- 管辖权异议是程序性武器，不要因急于实体辩论而忽略
- 诉讼时效抗辩即使不成立也要准备，对方可能不知道时效已中断

## 阶段5：应诉材料包制作（协作可选）

**目标**：完成答辩与庭审准备的成套材料。角色分工固定，串行或并行按下列步骤1的判断确定，不预设必须并行。

**输入**：阶段4策略报告 + 全部案卷材料

**架构设计**：

```
主代理（协调者）
├── defense-drafter       → 答辩状/代理词.md
├── evidence-organizer    → 证据目录与质证意见.md
├── legal-researcher      → 法源核实报告.md
├── counter-analyst       → 对抗复核与抗辩策略报告.md
├── trial-questioner      → 庭审发问提纲.md
└── mediation-assessor    → 调解预研报告.md
```

**操作步骤**：

1. 依次判断四项：任务是否复杂到需要拆分、是否存在两个以上可独立执行的子任务、平台是否具备多代理能力、并行是否会突破既有数据和工具授权边界。四项全部满足才启动并行，任一不满足由主代理串行执行，角色分工不变。启动前告知资源消耗可能明显增加
2. 使用平台对应能力创建协作空间，并为每个子代理创建边界清楚的任务
3. 在平台支持的范围内并行启动全部子代理，记录实际启动状态
4. 各子代理独立读取材料、完成任务、提交产出
5. 主代理审核各子代理产出，提出具体修改意见
6. 整合为应诉材料包，编制总目录
7. 向所有子代理发送关闭请求，确认产出已保存后使用平台对应能力清理资源

**子代理详细职责**：

- **defense-drafter**：逐条回应反诉请求/答辩意见，每条附法律依据，经审核修改后定稿。区分"否认型答辩"和"主张型反诉"的回应方式
- **evidence-organizer**：按本诉/反诉分类编制对外证据目录，每项列明名称、来源或提供人、形式、页数和证明对象；证明力分析留在内部证据分析表，同时准备对对方证据的质证意见（真实性/合法性/关联性）
- **legal-researcher**：通过当前可用的权威来源逐条验证法条效力，检索支持性判例，标注不利判例，准备管辖权异议和诉讼时效的法条支撑
- **counter-analyst**：站在对方角度审查材料，逐项质证对方证据，制定庭审对抗预案，识别对方在举证期限内可能提交的关键证据
- **trial-questioner**：设计庭审发问提纲（向对方当事人/证人发问的问题清单），预测对方可能的发问及我方回应
- **mediation-assessor**：基于阶段4的调解空间评估，进一步细化调解方案（含底线方案、目标方案、开价方案），评估调解时机和策略

**输出模板**：详见 `references/templates.md` 中的"应诉材料包模板"

**关键经验**：
- 并行启动：只有任务复杂、存在两个以上独立子任务、平台支持且不突破既有数据和工具授权边界时才启用；否则保持同一角色分工，改为串行执行
- 审核闭环：主代理必须审核并提出具体修改意见
- 法源核实是底线：禁止凭记忆引用，必须通过当前可用的权威来源验证；核实通过的逐条标注 `【已核实：<来源名称>，YYYY-MM-DD】`，日期写实际核实日期，不得使用占位符
- 子代理完成后立即关闭，避免资源占用
- 发问提纲要具体到每个问题的预期答案和追问方向
- 调解预研在此阶段完成，不要等到庭审后才考虑调解
