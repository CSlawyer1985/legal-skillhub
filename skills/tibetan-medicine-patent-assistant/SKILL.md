# 藏药专利助手

## 概览

藏药专利初稿生成技能。通过结构化收集处方、剂型、工艺、质量标准四大输入，结合中国发明专利的格式规范，生成可直接编辑的 Word (.docx) 专利初稿。内置藏药专利特有的三因理论框架、质量标准体系、炮制工艺描述等模板。

## 触发条件

当用户表达以下任一意图时触发本技能：
- "帮我写一个藏药专利"
- "生成专利初稿"
- "写一份发明专利"
- "把XX（处方）写成专利"
- 提供处方组成并要求生成专利文本
- 提供工艺参数并要求撰写专利
- 涉及藏药/中药组合物的专利申请

## 工作流程

### 第一步：收集输入信息

向用户系统性地收集以下信息（除非用户已一次性提供完整信息）：

#### 核心输入（必填）

| 信息类别 | 关键字段 | 说明 |
|---------|---------|------|
| 发明名称 | title | 不超过25字，格式如"一种XX组合物及其制备方法" |
| 处方组成 | formula | 各味药材名称、重量份数或范围；藏药需含藏文名/拉丁学名 |
| 剂型特征 | dosage_form | 剂型类型（散/丸/膏/贴/喷/胶囊等）及特征描述 |
| 制备工艺 | process | 关键工艺步骤、参数（温度、时间、压力等） |
| 质量标准 | quality_standard | 鉴别、检查、含量测定方法与标准 |
| 有益效果 | beneficial_effects | 药效学/临床数据，与现有技术对比优势 |
| 权利要求 | claims | 独立权利要求+从属权利要求 |

#### 可选但推荐的补充信息

- `background`：背景技术（现有技术及不足）
- `technical_problem`：要解决的技术问题
- `embodiments`：多个实施例
- `pharmacology_data`：药效学实验详情

### 第二步：补充专利框架

根据收集到的信息，按照以下框架填充缺失内容：

1. **背景技术** — 如用户未提供，结合藏医药理论（三因学说、经典典籍等）自动生成基础框架
2. **技术问题** — 从现有技术不足和本发明优势中提炼
3. **技术方案** — 结构化表述处方+剂型+工艺+质量标准
4. **具体实施方式** — 将处方转化为至少1个实施例，含完整工艺参数
5. **权利要求** — 按保护层级排列（组合物→剂型→方法→用途）
6. **摘要** — 凝练技术方案和主要效果（300字内）

### 第三步：生成专利初稿

1. 将完整信息整理为 JSON 输入结构
2. 调用 `scripts/generate_patent.py` 生成 Word 文档
3. 向用户提供生成的文件路径，并提示需要人工审查的内容

### 第四步：输出与提示

生成完成后，向用户说明：
- 文档中各章节标注了 `（待补充）` 的部分需人工完善
- 权利要求书的保护范围需专利代理师确认
- 实验数据需确保真实完整

## 脚本与资源

### `scripts/generate_patent.py`
核心专利初稿生成脚本。使用 python-docx 生成格式化的 Word 文档。
- 调用方式：`python scripts/generate_patent.py --input input.json --output output.docx`
- 支持从 Python 代码中直接调用：`generate_patent_from_input(data, output_path)`
- 自动生成完整的八节说明书

### `references/patent_structure.md`
中国发明专利说明书结构参考。包含：
- 各章节的标准写法规范
- 藏药专利的特殊注意事项（三因理论、药材基源、炮制要求等）
- 权利要求布局策略

## 使用示例

### 完整流程示例

用户说："我有一个藏药处方，含翼首草10份、兔耳草8份、榜嘎5份、红花3份，准备做外用贴剂，工艺是热熔压敏胶法，想写个专利。"

按以下步骤处理：
1. 确认处方、剂型、工艺细节
2. 询问质量标准、药效学数据、权利要求意图
3. 必要时引导补充藏医理论依据
4. 构造 JSON 输入 → 调用生成脚本 → 输出 docx
5. 交付并标注待完善项

### 简化流程示例

用户一次性提供完整的 JSON 数据：
1. 直接将 JSON 写入临时文件
2. 调用 `generate_patent.py` 生成
3. 交付文件

## 输出注意事项

- 生成的文档是初稿模板，**必须**提示用户进行人工审查
- 权利要求书的范围和措辞需专利代理师最终确认
- 实施例中的实验数据需用户确保真实可验证
- 藏药专利特有的药材基源、炮制工艺、质量标准描述需用户复核
