# 企业法务 - corporate-legal

面向企业法务人员的综合法务工作台。覆盖企业背调、合规审查、案例检索、法律文书、电子签章和风险评估，一站式支撑企业日常法务工作。

## 子技能列表

| 子技能 | 功能 | 触发关键词 |
|--------|------|-----------|
| 企业背景调查 | 输入公司名称，查询工商信息、诉讼记录和经营风险 | 企业背调, 尽职调查, 供应商准入 |
| 公司决议 | 输入决议事项，自动生成股东会/董事会决议 | 公司决议, 股东会决议, 董事会决议 |
| 合规审查 | 按领域逐项检查个保合规、广告合规等 | 合规审查, 个保合规, 数据出境 |
| 查案例 | 输入案情描述，匹配类似案例并提炼裁判观点 | 案例检索, 查案例, 裁判文书 |
| 法务日报 | 聚合法务工作信息，生成结构化日报 | 法律日报, 法律速递, 新法速览 |
| 法律文书 | 自动适配文书类型，生成律师函、起诉状等初稿 | 法律文书, 起诉状, 法律意见书 |
| 电子签发起 | 准备合同签署并生成签署配置方案 | 电子签章, 电子合同, 在线签署 |
| 风险评估 | 构建法律风险矩阵（可能性x严重度x可控性） | 风险评估, 法律风险, 诉讼风险 |

## 使用方法

通过 Marvis 对话自然触发，说出需求即可自动匹配对应子技能。

## 协同技能

- 合同管理：风险评估需以合同审查结果为输入
- 企业财税：合规审查涉及税务事项时需财税数据支撑
