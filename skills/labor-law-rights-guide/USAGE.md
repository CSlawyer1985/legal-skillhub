# 劳动法权益科普 使用说明

## 安装
将本文件夹整体复制到所用智能体客户端的 skills 目录（见 SKILL.md「跨平台说明」）。

## 新用户步骤
1. 复制文件夹到客户端 skills 目录（如 ~/.workbuddy/skills/劳动法权益科普/）
2. 重启或刷新客户端，确认技能已加载
3. 用触发词唤起，如：「被辞退有赔偿吗」
4. 按提示提供必要信息，获取结果
5. 参考 SKILL.md 的「红线与免责」「适用边界」合规使用

## 示例
- 提问：被辞退有赔偿吗
- 预期：按流程给出结构化结果 + 风险提示

## 注意事项
- 严格遵守 SKILL.md 的 P0 免责与适用边界
- 法律/税务/行业数据类：本技能不联网、不编造，关键结论请核实官方或咨询专业人士
- 命名/口号类：使用前自行查重与合规审查
