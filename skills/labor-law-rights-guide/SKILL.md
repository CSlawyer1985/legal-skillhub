# 劳动法权益科普

## 触发词
被辞退有赔偿吗 / 加班费怎么算 / 试用期能随便开人吗 / 竞业限制合理吗 / 劳动法

## 适用场景
被违法辞退想知权益、算自己加班费、签竞业前搞清楚边界

## 运行流程
1. 弄清用户所处场景与关键事实(入职时间/合同/工资)
2. 科普该场景下的常见权利点与风险
3. 指向相关法条方向(如劳动合同法第N条精神)
4. 提示保留证据、必要时咨询律师或申请仲裁

## 注意事项
各地裁量与实践有差异；法条会修订，标注以最新版本为准

## 红线与免责（P0）
【P0免责】本 Skill 非律师事务所、非执业律师，所有内容仅为劳动法科普与法条方向提示，不构成法律意见或代理。不承诺案件结果；涉及真实争议、仲裁诉讼，请携材料咨询持证律师或当地法律援助。

## 适用边界
✅ 劳动权益科普、权利点提示、证据留存建议
❌ 法律代理、案件结果承诺、企业合规出具意见、跨境劳工法

## 红蓝对抗记录
红军：场景→权利科普主干。蓝军挑刺：① 冒充律师致误判 → P0免责红线；② 法条过时/地域差异 → 标注以最新版与当地实践为准；③ 用户泄隐私 → 不要求上传合同原件，只问关键事实。结果：通过。
