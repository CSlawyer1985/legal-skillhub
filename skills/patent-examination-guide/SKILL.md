# 专利审查指南助手 (Patent Examination Guide Assistant)

基于国家知识产权局《专利审查指南2023》的智能审查辅助技能，为专利代理师、发明人、审查员提供专业的审查规则查询和实务指导。

## When to use

当用户涉及以下场景时使用本技能：

- **专利申请文件撰写**：说明书、权利要求书、摘要的格式要求和内容规范
- **初步审查咨询**：形式审查、明显实质性缺陷、补正程序
- **实质审查咨询**：新颖性、创造性、实用性判断标准，检索策略
- **特殊领域审查**：计算机程序、化学、中药领域的特殊审查规定
- **程序性问题**：优先权、分案申请、著录项目变更、期限恢复
- **复审与无效**：复审请求、无效宣告、口头审理
- **国际申请**：PCT进入国家阶段、外观设计国际申请

## Capability routing

### 主要工作路径

1. **规则查询路径**（最常用）
   - 用户提出专利审查相关问题
   - 使用 `search_in_file` 在参考文件中搜索关键词
   - 从 `references/patent-examination-rules.md` 提取相关规则
   - 必要时从原始文档补充细节
   - 返回结构化的审查意见或操作指引

2. **文件审核路径**
   - 用户提交专利申请文件内容进行审核
   - 对照 `references/writing-standards.md` 中的撰写规范
   - 检查是否符合专利法及实施细则要求
   - 输出缺陷清单和修改建议

3. **流程指导路径**
   - 用户询问特定审查程序的步骤
   - 参考 `references/procedures.md` 获取流程信息
   - 提供时间节点、所需材料、注意事项

```

```

## Key Legal Provisions Quick Index

### 专利授权条件（法22）
- 新颖性 (Novelty): 法22.2
- 创造性 (Inventiveness): 法22.3
- 实用性 (Utility): 法22.4

### 不授予专利权的情形
- 法5: 违反法律/社会公德/公共利益、遗传资源违规
- 法25: 科学发现、智力活动规则、诊断治疗方法、动植物品种、核变换

### 申请文件要求（法26）
- 法26.3: 说明书充分公开
- 法26.4: 权利要求书以说明书为依据
- 法26.5: 先申请原则

### 重要期限
- 优先权期: 外国12个月/外观设计6个月（法29）
- 实质审查请求: 自申请日起3年（法35）
- 公布: 自申请日起18个月（法34）

## Failure handling

- **规则未找到**: 扩大搜索关键词，尝试同义词/上位概念；如仍无果，告知用户该问题可能在指南中未明确规定，建议咨询国家知识产权局
- **条款冲突**: 明确标注不同条款的适用条件和优先级，提供权威解释来源
- **复杂案例**: 对于涉及多个技术领域或多个程序交叉的复杂问题，建议分步处理，先解决主要矛盾
- **时效性提醒**: 本技能基于2023版指南，如法规更新需提示用户核实最新版本

## Tips for Effective Use

1. **精确提问**: 尽量包含专利类型（发明/实用新型/外观设计）和具体审查阶段
2. **提供上下文**: 如有具体技术方案描述，可一并提交以便精准分析
3. **分层追问**: 可先获取总体框架，再深入具体条款
4. **交叉验证**: 重要决策建议对照原始文档验证，避免遗漏例外情形
