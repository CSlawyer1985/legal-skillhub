## 一、专利授权实质条件（法22）

### 1.1 新颖性（Novelity）- 法22.2

**定义**：发明或者实用新型不属于现有技术，也没有任何单位或者个人就同样的发明或者实用新型在申请日以前向国务院专利行政部门提出过申请，并记载在申请日以后公布的专利申请文件或者公告的专利文件中。

**判断标准**：
- **现有技术**：申请日（有优先权日的指优先权日）以前在国内外为公众所知的技术
- **抵触申请**：他人就同样发明在先申请、在后公布/公告的专利文件
- **单独对比原则**：将发明与一项现有技术或抵触申请单独对比

**不丧失新颖性的公开（法24）** - 申请日前6个月内：
1. 在国家出现紧急状态/非常情况时为公共利益目的首次公开
2. 在中国政府主办/承认的国际展览会上首次展出
3. 在规定的学术会议/技术会议上首次发表
4. 他人未经申请人同意而泄露其内容

### 1.2 创造性（Inventiveness）- 法22.3

**发明专利**：与现有技术相比具有突出的实质性特点和显著的进步
**实用新型**：与现有技术相比具有实质性特点和进步

**判断方法（三步法）**：
1. 确定最接近的现有技术
2. 确定发明的区别特征和实际解决的技术问题
3. 判断要求保护的发明对本领域技术人员来说是否显而易见

**创造性判断的辅助考虑因素**：
- 发明是否解决了长期的技术难题
- 是否克服了技术偏见
- 是否取得了预料不到的技术效果
- 是否在商业上获得成功（由技术原因导致）

### 1.3 实用性（Utility）- 法22.4

**定义**：能够制造或者使用，并且能够产生积极效果。

**不具备实用性的情形**：
- 无再现性（重复实施结果不一致）
- 违背自然规律（如永动机）
- 利用独一无二的自然条件完成
- 人体/动物体的非治疗目的的外科手术方法
- 无积极效果（明显无益、脱离社会需要）
- 测量人体在极值条件下的生理参数的方法

## 二、不授予专利权的主题

### 2.1 根据法5不授予的情形

| 类型 | 说明 | 示例 |
|------|------|------|
| 违反法律 | 与法律相违背 | 赌博设备、吸毒器具、伪造货币工具 |
| 违反社会公德 | 违背公认伦理道德 | 暴力凶杀内容、克隆人方法、非医疗目的的人造性器官 |
| 妨害公共利益 | 给公众/社会造成危害 | 致人伤残防盗装置、严重污染环境 |
| 遗传资源违规 | 违法获取/利用遗传资源 | 未审批出口畜禽遗传资源、违规提供人类遗传信息 |

### 2.2 根据法25不授予的情形

| 序号 | 不授权客体 | 可授权例外 |
|------|-----------|-----------|
| (1) | 科学发现 | 基于发现的用途发明可授权 |
| (2) | 智力活动的规则和方法 | 包含技术特征的商业模式等可授权 |
| (3) | 疾病的诊断和治疗方法 | 用于诊断治疗的仪器/装置/材料可授权 |
| (4) | 动物和植物品种 | 非生物学生产方法可授权 |
| (5) | 原子核变换方法及获得的物质 | 为实现核变换的设备仪器可授权 |

### 2.3 智力活动规则和方法的具体示例

**不可授权**：
- 审查专利申请的方法
- 组织、生产、商业管理方法及制度
- 交通行车规则、时间调度表、比赛规则
- 演绎、推理和运筹的方法
- 图书分类规则、字典编排方法
- 计算机程序本身
- 各种游戏、娱乐的规则和方法
- 统计、会计和记账的方法

**可授权（包含技术特征）**：
- 涉及商业模式的权利要求包含商业规则+技术特征
- 控制工业过程、改善计算机系统功能的方案

### 2.4 疾病诊断治疗方法

**属于诊断方法（不可授权）**：
- 以有生命人体/动物体为对象
- 以获得疾病诊断结果或健康状况为直接目的
- 例：诊脉法、X光诊断法、基因筛查诊断法

**属于治疗方法（不可授权）**：
- 外科手术治疗方法、药物治疗方法
- 以治疗为目的的针灸、麻醉、推拿按摩
- 预防疾病的免疫方法
- 以治疗为目的的整容、肢体拉伸、减肥方法

**不属于诊断/治疗（可授权）**：
- 制造假肢/假体的方法
- 动物屠宰方法
- 单纯的美容方法（非介入式）
- 杀灭体表细菌/病毒的方法

## 三、说明书撰写规范（法26.3 + 细则20）

### 3.1 必须满足的要求

#### 清楚
- **主题明确**：反映出发明要做什么和如何去做
- **表述准确**：使用所属技术领域的技术术语

#### 完整
应当包含：
1. 帮助理解发明不可缺少的内容（技术领域、背景技术、附图说明）
2. 确定新颖性/创造性/实用性所需的内容（技术问题、技术方案、有益效果）
3. 实现发明所需的内容（具体实施方式）

#### 能够实现
- 技术人员按照说明书记载内容能够实现该技术方案
- **不能实现的情形**：
  - 只给出任务/设想，未给出任何技术手段
  - 技术手段含糊不清，无法具体实施
  - 采用的技术手段不能解决所述技术问题
  - 多个技术手段中某个无法实现
  - 缺乏实验证据且必须依赖实验证实

### 3.2 撰写顺序（细则20.1）

```
1. 名称（与请求书一致，≤25字，必要时≤60字）
2. 技术领域（具体技术领域，非上位领域）
3. 背景技术（引证最接近现有技术，指出问题和缺点）
4. 发明/实用新型内容
   ├── 要解决的技术问题（针对现有技术缺陷，正面客观描述）
   ├── 技术方案（至少反映独立权利要求的全部必要技术特征）
   └── 有益效果（由技术特征直接带来，可与现有技术比较）
5. 附图说明（对所有附图作简略说明）
6. 具体实施方式（详细描述优选方式，必要时举例，对照附图）
```

### 3.3 其他要求
- 不得使用"如权利要求……所述的…"引用语
- 不得使用商业性宣传用语
- 使用国家法定计量单位
- 使用中文（个别词语可用非中文但不产生歧义）
- 第一次使用非中文技术名词时应加中文注释

## 四、权利要求书撰写规范（法26.4 + 细则22-25）

### 4.1 基本类型

| 类型 | 定义 | 示例 |
|------|------|------|
| 产品权利要求 | 物的权利要求 | 物品、物质、材料、工具、装置、设备 |
| 方法权利要求 | 活动的权利要求 | 制造方法、使用方法、通讯方法、处理方法、用途 |

### 4.2 独立权利要求 vs 从属权利要求

**独立权利要求**（细则23.2）：
- 从整体上反映发明/实用新型的技术方案
- 记载解决技术问题的**必要技术特征**
- 保护范围最宽

**从属权利要求**（细则23.3）：
- 包含另一项同类型权利要求的所有技术特征
- 用附加技术特征作进一步限定
- 保护范围落在引用权利要求之内

### 4.3 应当满足的要求

#### 以说明书为依据（法26.4）
- 权利要求应得到说明书的支持
- 概括不得超出说明书公开的范围
- 功能性限定需谨慎：覆盖所有能实现该功能的方式

#### 清楚（细则22.1）
- 权利要求的类型清楚
- 每项权利要求应当明确
- 简要（细则22.2）：避免不必要的重复和冗余

### 4.4 特殊类型权利要求

**用途权利要求**：
- "用于…的物质X"——用途限定对化合物本身的影响决定其限定作用
- 物质的医药用途——可写成"化合物X在制备治疗Y病的药物中的应用"

**马库什权利要求**（化学领域）：
- 可选择要素的并列选择方式
- 所有可选择要素具有共同性能/作用
- 单一性判断的特殊规则

## 五、初步审查要点

### 5.1 审查原则
1. **保密原则**：对未公布申请负有保密责任
2. **书面审查原则**：以书面文件为基础，原则上不进行会晤
3. **听证原则**：驳回前应通知申请人陈述意见/修改的机会
4. **程序节约原则**：尽可能提高审查效率，一次通知书指出全部缺陷

### 5.2 申请文件形式审查

#### 请求书关键点
| 项目 | 要求 |
|------|------|
| 发明名称 | ≤25字（必要时≤60字），不得含非技术词/商标/代号 |
| 发明人 | 必须是个人，不得填单位/AI名称，用真实姓名 |
| 申请人 | 本国人用真实姓名/正式全称；外国人需符合条约/互惠 |
| 地址 | 符合邮件投递要求，本国地址含邮编+省市区街道门牌+电话 |
| 代理机构 | 使用登记全称+机构代码；代理师≤2人 |

#### 说明书摘要
- 写明名称、技术领域、技术问题、技术方案要点、主要用途
- **≤300字**（含标点），不得使用标题
- 不得使用商业性宣传用语

### 5.3 明显实质性缺陷审查范围
- 法5（违反法律/社会公德/公共利益/遗传资源）
- 法25（不授权客体）
- 法17、18.1、19.1（申请人资格）
- 法2.2（保护客体）
- 法26.5（先申请）、31.1（单一性）、33（修改超范围）
- 细则20（说明书）、细则22（权利要求书）
- 细则11（诚实信用原则）

### 5.4 特殊申请审查

#### 分案申请
- 应以原申请为基础提出，类别一致
- 最迟在收到授权通知书之日起**2个月**届满前提出
- 驳回决定后**3个月**内可提出分案
- 申请人应与原申请相同，发明人可为原发明人或部分成员

#### 生物材料保藏
- 申请日/优先权日前提交至认可的国际保藏单位
- 请求书和说明书注明保藏信息（单位、地址、日期、编号、分类命名）
- **4个月内**提交保藏证明和存活证明

#### 遗传资源披露
- 请求书中说明遗传资源来源
- 填写遗传资源来源披露登记表（直接来源+原始来源）
- 无法说明原始来源的应陈述理由

## 六、优先权制度

### 6.1 外国优先权（法29.1 + 细则34-35）

**条件**：
- 在巴黎公约成员国/ WTO成员首次提出申请后**12个月内**（外观设计**6个月**）
- 在中国提出申请时要求优先权

**要求**：
1. 在请求书中声明（写明在先申请日、申请号、原受理机构）
2. 在**16个月内**提交在先申请文件副本（通过电子交换的可免交）
3. 在后申请人与在先申请人一致（或提供转让证明）

### 6.2 本国优先权（法29.2 + 细则35）

**条件**：
- 在中国首次提出发明/实用新型申请后**12个月内**
- 在先申请未要求过外国/本国优先权
- 在先申请未被授予专利权

**特殊规定**：
- 要求本国优先权的，**在先申请视为撤回**
- 已被视为撤回的在先申请**不得请求恢复**

### 6.3 优先权的恢复

| 恢复依据 | 适用情形 | 期限 |
|---------|---------|------|
| 细则6（恢复权利） | 未答复补正通知书、未提交副本/证明、未缴费、分案申请 | 可依细则6条恢复 |
| 细则36（恢复优先权） | 12个月期限届满后在公布准备前 | 届满起**2个月内**请求恢复 |

## 七、著录项目变更

### 7.1 变更手续
- 提交**著录项目变更申报书**
- 缴纳**著录事项变更费**（自提出请求起**1个月内**缴纳）
- 提交相应证明文件

### 7.2 各类变更所需证明

| 变更类型 | 所需证明文件 |
|---------|-------------|
| 姓名/名称变更（个人） | 户籍管理部门证明 / 本人签字声明+身份证明 |
| 名称变更（企业） | 工商行政管理部门证明 |
| 权利转移（协议） | 双方签字盖章转让合同 |
| 权利转移（纠纷-协商） | 全体当事人签字权利转移协议书 |
| 权利转移（纠纷-调解/判决） | 调解书/生效判决书 |
| 权属继承 | 公证的唯一合法继承人/全部法定继承人证明 |
| 发明人变更 | 全体申请人+变更前后全体发明人签字证明（注明变更原因） |
| 国籍变更 | 身份证明文件 |

### 7.3 涉外转让特殊要求

| 转让方向 | 额外要求 |
|---------|---------|
| 内地→外国 | 商务主管部门颁发的技术出口许可证/合同登记证 |
| 外国→内地 | 双方签字转让合同 |
| 内地↔港澳台 | 参照内地→外国/外国→内地规定处理 |

## 八、复审与无效宣告

### 8.1 复审请求（第四部分第二章）

**提起条件**：
- 对驳回决定不服
- 在收到驳回决定之日起**3个月内**提出
- 向专利复审委员会提出

**前置审查**：
- 原审查部门进行前置审查
- 维持驳回决定的，移交合议组审查
- 撤销原决定的，恢复原程序

### 8.2 无效宣告请求（第四部分第三章）

**请求人资格**：
- 任何单位或者个人（自公告授权日起）

**理由限制**：
- 仅限于法5、法9、法20.1、法22、法23.1-2、法26.3-4、法33、细则10-11、20-24、44-45、68的规定
- **已放弃的授权理由不得再提出**

**审理程序**：
- 形式审查 → 合议组受理 → 通知答辩 → 口头审理（可选） → 作出决定

### 8.3 口头审理（第四章）

**类型**：
- 当事人请求的口头审理
- 合议组依职权召集的口头审理

**注意事项**：
- 当事人可委托代理出席
- 可进行证据交换和质证
- 审查员记录审理过程

## 九、期限与权利恢复

### 9.1 主要期限汇总

| 事项 | 期限 | 起算日 |
|------|------|--------|
| 申请公布 | 18个月 | 申请日 |
| 实质审查请求 | 3年 | 申请日（有优先权的指优先权日） |
| 外国优先权 | 12个月 | 在先申请日 |
| 外观设计/本国优先权 | 6/12个月 | 在先申请日 |
| 优先权文件副本 | 16个月 | 最早优先权日 |
| 不丧失新颖性证明 | 2个月 | 申请日 |
| 补交生物材料保藏证明 | 4个月 | 申请日 |
| 复审请求 | 3个月 | 收到驳回决定之日 |
| 分案申请 | 授权通知书日起2个月届满前 | — |
| 无效宣告 | 授权公告日后任何时候 | — |
| 著录事项变更费 | 1个月 | 提出变更请求之日 |

### 9.2 权利恢复（第五部分第七章第6节）

**适用情形**：
- 因不可抗拒事由耽误期限
- 因其他正当理由耽误期限

**不予恢复的情形**：
- 丧失的不可恢复权利（如视为撤回的在先申请本国优先权）
- 不适用恢复的特定条款（如细则36、37、45规定的某些期限）

## 十、特殊领域审查要点

### 10.1 计算机程序发明（第二部分第九章）

**可授权客体**：
- 涉及技术方案的计算机程序（作为产品/方法的组成部分）
- 包含算法特征但整体构成技术方案的发明
- 包含商业规则和方法特征但有技术特征的发明

**审查基准**：
- 解决技术问题 + 采用技术手段 + 获得技术效果 = 技术方案
- 仅涉及算法/计算规则/编码方法本身 = 不可授权

**撰写建议**：
- 将计算机程序的功能与技术硬件结合描述
- 明确技术问题和技术效果
- 避免仅描述算法流程

### 10.2 化学领域发明（第二部分第十章）

**充分公开要求**：
- 化学产品：结构确认 + 制备方法 + 性能/用途
- 化学方法：工艺条件和参数完整
- 用途发明：实验数据支持

**权利要求特点**：
- 马库什权利要求（选择性并列）
- 参数表征（结构不清楚时）
- 中间体与最终产物的单一性

**补交实验数据**：
- 一般不允许（除非原申请已暗示）
- 药品专利有特殊规定

### 10.3 中药领域发明（第二部分第十一章）

**可授权客体**：
- 中药组合物及其制药用途
- 中药材的提取/加工方法
- 中药制剂及其制备方法

**不可授权客体**：
- 医生处方
- 从动物体获取中药原料的方法

**撰写注意**：
- 使用规范化中药材名称
- 明确组分用量配比
