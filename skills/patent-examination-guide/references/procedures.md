# 专利审查程序流程指南

> 本文件详细说明各类审查程序的时间节点、所需材料和操作步骤，供实务操作参考。

---

## 一、发明专利申请完整生命周期

```
申请日（T=0）
    │
    ├── 初步审查阶段 ──────────────────────────────┐
    │   • 形式审查                                    │
    │   • 明显实质性缺陷审查                           │
    │   • 补正/审查意见通知书                          │
    │   • 初步审查合格通知书                           │
    │                                                │
    ├── 公布（T+18个月 或 提前公布）                   │
    │                                                │
    ├── 实质审查请求期限（T+3年内）                    │
    │   • 提交实质审查请求书 + 实质审查费              │
    │   • 提交参考资料                                 │
    │                                                │
    ├── 实质审查阶段 ──────────────────────────────┤
    │   • 检索                                       │
    │   • 审查意见通知书（可能有多次）                  │
    │   • 申请人修改/陈述意见                          │
    │   • 授权/驳回决定                               │
    │                                                │
    ├── 办理登记手续（收到授权通知后2个月内）          │
    │   • 缴纳年费/印花税                             │
    │   • 办理登记手续                                 │
    │                                                │
    └── 授权公告 → 专利权维持（缴纳年费）              │
                                                    │
    ┌─── 复审路径（对驳回不服）─────────────────────→│
    │   • 收到驳回决定后3个月内提出复审                │
    │   • 前置审查 → 合议组审查                       │
    │   • 复审决定（撤销原决定/维持驳回）             │
    │                                                │
    └─── 无效宣告路径（授权后）────────────────────→│
        • 任何时间可提出                               │
        • 复审/无效部门审理                            │
        • 口头审理（可选）                              │
        • 无效/部分无效/维持有效决定                   │
```

## 二、初步审查程序详解

### 2.1 发明专利初步审查流程

```
受理申请
    ↓
形式审查 ──缺陷？──是──→ 发出补正通知书
    │                        ↓
    否                  申请人补正（指定期限内）
    │                        ↓
    ↓                  审查员审核补正结果
明显实质性缺陷审查            │
    │                 ──仍有缺陷？──是──→ 再次补正（最多2次）
    ↓                 │                      ↓
有缺陷？──是──→ 发出审查意见通知书     超过2次仍不合规 → 驳回
    │               ↓                      │
否           申请人陈述意见/修改             │
    ↓               │                      │
发出初步审查合格通知书    ──消除？──是──→ 合格进入公布程序
    │               │                      │
    ↓              否 → 驳回                │
进入公布程序                                │
```

### 2.2 关键时限

| 事项 | 时限 | 起算点 | 法律依据 |
|------|------|--------|---------|
| 补正答复 | 通常1个月 | 通知书发文日 | 细则 |
| 审查意见答复 | 通常4个月 | 通知书发文日 | 法37 |
| 延长期限请求 | 可延长1-3个月 | 原期限届满前 | 细则 |
| 权利恢复请求 | 合理理由+2个月 | 期限届满后 | 细则6 |

### 2.3 初步审查结果类型

| 结果类型 | 后续程序 |
|---------|---------|
| 初步审查合格通知书 | 进入公布程序 |
| 补正通知书 | 申请人补正 |
| 审查意见通知书 | 申请人陈述意见或修改 |
| 视为撤回通知书 | 可恢复权利（符合条件时） |
| 驳回决定 | 可提起复审 |

## 三、实质审查程序详解

### 3.1 实质审查启动

**启动条件**：
1. 申请人在**自申请日起3年内**提出实质审查请求
2. 缴纳实质审查费

**提交材料**：
- 实质审查请求书
- 在申请日前与其发明有关的参考资料

**提前启动**：申请人可以提前提出实质审查请求

### 3.2 实质审查主要步骤

```
收到实质审查请求并缴费
    ↓
进行检索（第七章）
    ├── 现有技术检索
    ├── 对比文件筛选
    └── 检索报告制作
    ↓
发出第一次审查意见通知书
    ├── 引用对比文件
    ├── 指出权利要求的问题
    └── 给予至少4个月的答复期限
    ↓
申请人答复
    ├── 修改权利要求书（针对通知书指出的问题）
    ├── 陈述意见（不同意审查员观点）
    └── 两者结合
    ↓
审查员审核答复
    ├── 问题已解决 → 发出授予专利权通知书
    ├── 部分解决 → 发出再次审查意见通知书
    └── 未解决 → 发出驳回决定
    ↓
[循环直至授权或驳回]
```

### 3.3 实质审查中的修改限制

**基本原则**：
- 修改不得超出原说明书和权利要求书记载的范围（法33）
- 应针对通知书指出的问题进行修改

**允许的修改**：
- 删除并列技术方案中的一项或多项
- 从独立权利要求中增加技术特征（缩小保护范围）
- 改正错别字或明显的语法错误
- 修改从属权利要求的引用关系

**不允许的修改**：
- 增加新的技术内容
- 将未在原申请中记载的技术特征加入权利要求
- 改变发明的技术领域
- 扩大保护范围

### 3.4 实质审查结果与后续

| 结果 | 后续选择 |
|------|---------|
| 授予专利权通知书 | 办理登记手续（2个月内） |
| 驳回决定 | 3个月内提出复审请求 |

## 四、优先权程序

### 4.1 外国优先权操作流程

```
外国首次申请日（D0）
    ↓
12个月内（外观设计6个月内）向中国提交申请
    ↓
提交申请同时在请求书中声明优先权
    ├── 写明在先申请日
    ├── 写明在先申请号
    └── 写明原受理机构名称
    ↓
16个月内提交在先申请文件副本
    ├── 由原受理机构出具
    ├── 中文译文（如外文）
    └── 电子交换途径可免交
    ↓
缴纳优先权要求费（与申请费同时）
```

### 4.2 本国优先权操作流程

```
中国首次申请日（D0）
    ↓
12个月内再次提交申请并要求优先权
    ↓
在请求书中声明优先权
    ├── 写明在先申请日
    ├── 写明在先申请号
    └── 原受理机构写"中国"
    ↓
缴纳优先权要求费
    ↓
【重要】在先申请视为撤回
```

### 4.3 优先权恢复流程

```
发现错过优先权期限或视为未要求优先权
    ↓
判断恢复依据
    ├── 细则6条（一般恢复）：因正当理由耽误
    │   └── 如：未及时答复补正通知书导致视为未要求
    │       未按时缴费、未提交副本等
    │
    └── 细则36条（特殊恢复）：12个月期满后在公布准备前
        └── 仅适用于期限届满后的恢复
    ↓
提交恢复请求
    ├── 恢复权利请求书
    ├── 说明理由
    ├── 缴纳恢复权利请求费
    ├── 缴纳优先权要求费（如未缴）
    └── 补交相关文件（副本/证明等）
    ↓
审查员审批
    ├── 符合条件 → 发出恢复权利请求审批通知书
    └── 不符合 → 说明不予恢复的理由
```

## 五、分案申请程序

### 5.1 分案申请时机

```
原申请（首次申请）
    │
    ├── 正常审查期间 ──→ 可主动分案 / 根据审查意见分案
    │
    ├── 收到授权通知书后2个月内 ──→ 最后分案机会
    │
    ├── 收到驳回决定后3个月内 ──→ 仍可分案（不论是否复审）
    │
    ├── 复审期间 ──→ 可分案
    │
    ├── 复审决定后3个月内 ──→ 可分案
    │
    └── 行政诉讼期间 ──→ 可分案
```

### 5.2 分案申请注意事项

| 项目 | 要求 |
|------|------|
| 类别 | 与原申请一致（发明→发明） |
| 原申请信息 | 必须填写原申请号和申请日 |
| 申请人 | 与原申请相同 |
| 发明人 | 原发明人或其中部分成员 |
| 期限 | 从原申请日起算各种法定期限 |
| 费用 | 视为新申请收取全部费用 |

### 5.3 再次分案的特殊规定

- 再次分案的递交时间以**原申请**为基准审核
- 因单一性缺陷导致的再次分案，可以该分案申请为基础审核

## 六、著录项目变更程序

### 6.1 变更流程图

```
准备变更材料
    ↓
提交著录项目变更申报书
    ↓
缴纳著录事项变更费（1个月内）
    ↓
提交证明文件
    ├── 姓名/名称变更：户籍/工商证明
    ├── 权利转移：转让合同/判决书/调解书
    ├── 发明人变更：全体签字证明
    └── 代理机构变更：委托书/解聘书
    ↓
专利局审批
    ↓
发出手续合格通知书 → 变更生效
```

### 6.2 各类变更的处理时间

| 变更类型 | 一般处理周期 |
|---------|-------------|
| 姓名/名称变更 | 1-2周 |
| 地址变更 | 1周左右 |
| 代理机构变更 | 1-2周 |
| 权利转移 | 2-4周（需核实证明文件） |
| 发明人变更 | 2-3周 |

## 七、复审程序

### 7.1 复审请求提交流程

```
收到驳回决定
    ↓
3个月内提出复审请求
    ↓
提交复审请求书
    ├── 说明理由
    ├── 提供证据（如有）
    └── 缓纳复审费
    ↓
形式审查合格 → 受理
    ↓
前置审查（原审查部门）
    ├── 维持原决定 → 移交合议组
    └── 撤销原决定 → 恢复原审查程序
    ↓
合议组审理
    ├── 发出复审通知书（可选）
    ├── 口头审理（可选）
    └── 作出复审决定
        ├── 撤销驳回 → 原审查部门继续审查
        └── 维持驳回 → 可起诉（6个月内）
```

### 7.2 复审请求的形式要求

| 项目 | 要求 |
|------|------|
| 对象 | 针对驳回决定的专利申请 |
| 期限 | 收到驳回决定之日起3个月 |
| 费用 | 复审请求费 |
| 内容 | 陈述理由、反驳驳回决定的事实和理由 |
| 代表人 | 已委托代理机构的由代理机构办理 |

## 八、无效宣告程序

### 8.1 无效宣告请求流程

```
准备无效宣告请求
    ↓
向专利复审委员会提交
    ├── 无效宣告请求书
    ├── 证据（对比文件等）
    └── 无效宣告请求费
    ↓
形式审查
    ├── 不合格 → 通知补正/不予受理
    └── 合格 → 受理并通知专利权人
    ↓
专利权人答辩（指定期限内）
    ↓
合议组审理
    ├── 文件审理
    ├── 口头审理（当事人请求或合议组认为必要时）
    └── 调查取证（必要时）
    ↓
作出无效宣告决定
    ├── 全部无效
    ├── 部分无效
    └── 维持有效
    ↓
起诉（3个月内，仅针对专利权人起诉的情形）
```

### 8.2 无效宣告理由限制

**允许提出的理由**（法5、9、20.1、22、23.1-2、26.3-4、33；细则10-11、20-24、44-45、68）：

| 类型 | 具体理由 |
|------|---------|
| 主体问题 | 不属于专利保护客体（法25）、违反法5 |
| 实质条件 | 不具备新颖性/创造性/实用性（法22） |
| 公开充分 | 说明书公开不充分（法26.3） |
| 权利要求 | 权利要求不支持/不清楚/不简要（法26.4） |
| 修改超范围 | 修改超出原始范围（法33） |
| 单一性 | 缺乏单一性（法31.1） |
| 先申请原则 | 同样的发明创造（法9） |
| 诚实信用 | 弄虚作假（法20.1、细则11） |

**注意**：已放弃的授权理由不得再提出！

### 8.3 口头审理

**类型**：
1. **依请求的口头审理**：当事人在期限内提出请求
2. **依职权的口头审理**：合议组认为有必要时召集

**准备工作**：
- 提前阅读全部案卷材料
- 准备证据原件供核对
- 准备辩论要点
- 如委托代理人，需有特别授权

**审理过程**：
1. 调查阶段（事实调查、证据质证）
2. 辩论阶段（双方发表意见）
3. 最后陈述
4. 宣布休庭

## 九、PCT国际申请进入国家阶段

### 9.1 进入国家阶段的流程

```
国际申请日（PCT申请日）
    ↓
30个月（或32个月，视情况）内向中国进入国家阶段
    ↓
提交必要文件
    ├── 国际申请进入中国国家阶段声明（中文）
    ├── 原始国际申请的中文译文/中文文本
    ├── 国际申请文件的副本（可能需要）
    └── 有关费用
    ↓
初步审查（参照第一部分）
    ├── 形式审查
    ├── 译文改正
    └── 超期处理
    ↓
符合要求 → 进入实质审查程序
```

### 9.2 特殊规定

| 项目 | 要求 |
|------|------|
| 期限 | 自优先权日起30个月（非国际申请为20个月） |
| 译文 | 必须使用中文 |
| 修改 | 可以在进入国家阶段时进行修改 |
| 费用 | 申请费、公布印刷费、实质审查费（减缴适用） |

## 十、期限管理速查表

### 10.1 主要期限一览

```
┌─────────────────────────────────────────────────────────────┐
│                     期限速查表                               │
├──────────────┬──────────────┬──────────────┬────────────────┤
│ 事项          │ 期限         │ 起算点       │ 备注           │
├──────────────┼──────────────┼──────────────┼────────────────┤
│ 申请公布      │ 18个月       │ 申请日       │ 可提前公布     │
│ 实质审查请求  │ 3年          │ 申请日       │ 逾期视为撤回   │
│ 外国优先权    │ 12个月       │ 在先申请日   │ 外观设计6个月  │
│ 本国优先权    │ 12个月       │ 在先申请日   │               │
│ 优先权文件    │ 16个月       │ 最早优先权日 │               │
│ 不丧失新颖性  │ 2个月        │ 申请日       │ 声明+证明      │
│ 生物材料保藏证│ 4个月        │ 申请日       │ 含存活证明     │
│ 复审请求      │ 3个月        │ 驳回决定日   │               │
│ 无效宣告      │ 授权后 anytime│ —            │               │
│ 分案申请      │ 授权通知后2月 │ 授权通知日   │ 特殊情况见正文 │
│ 登记手续      │ 2个月        │ 授权通知日   │ 含年费         │
│ 著录变更费    │ 1个月        │ 变更请求日   │               │
│ 起诉(行政诉讼)│ 6个月        │ 复审决定日   │ 仅专利权人     │
└──────────────┴──────────────┴──────────────┴────────────────┘
```

### 10.2 期限延误的补救措施

| 情形 | 救济方式 | 条件 |
|------|---------|------|
| 因不可抗拒事由耽误 | 恢复权利 | 事由消除后2个月+障碍存续期内 |
| 因正当理由耽误 | 恢复权利 | 期限届满后2个月内 |
| 未缴费导致视为撤回 | 恢复权利 | 符合细则6条规定 |
| 优先权期限届满 | 恢复优先权 | 届满后2个月内（细则36） |
| **不可恢复情形** | — | 已放弃的在先本国申请、已届满的复审期等 |

---

*本指南基于《专利审查指南2023》整理，具体操作请以国家知识产权局最新要求和官方表格为准。*
