# 特殊领域发明专利申请审查规定

> 本文件汇总计算机程序、化学、中药三大特殊领域的专利审查特殊规定，供实务操作参考。

---

## 一、涉及计算机程序的发明专利申请（第二部分第九章）

### 1.1 基本原则

**核心规则**：
- **专利法保护的是技术方案**，单纯的智力活动规则不属于可专利主题
- 涉及计算机程序的发明，如果其解决方案是**利用计算机程序处理外部技术数据**、解决**技术问题**并获得了**符合自然规律的技术效果**，则属于可专利的技术方案
- 如果仅仅是智力活动规则的实现方式，则不授予专利权

### 1.2 可专利性判断框架

```
┌─────────────────────────────────────────────────────┐
│           计算机程序发明可专利性判断流程              │
├─────────────────────────────────────────────────────┤
│                                                     │
│  第一步：确定权利要求请求保护的方案                    │
│    ↓                                                │
│  第二步：判断是否属于法25条排除的客体？                │
│    ├── 是 → 不授予专利权                             │
│    └── 否 → 进入第三步                               │
│    ↓                                                │
│  第三步：是否解决了技术问题？                         │
│    ├── 否 → 不授予专利权                             │
│    └── 是 → 进入第四步                               │
│    ↓                                                │
│  第四步：是否采用了利用了自然规律的技术手段？          │
│    ├── 否 → 不授予专利权                             │
│    └── 是 → 进入第五步                               │
│    ↓                                                │
│  第五步：是否获得了技术效果？                         │
│    ├── 否 → 不授予专利权                             │
│    └── 是 → ✅ 属于可专利的技术方案                   │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 1.3 典型案例分类

#### ✅ 可以授予专利权的情形

| 类型 | 示例 | 理由 |
|------|------|------|
| 工业过程控制 | 控制机床加工的计算机程序 | 解决了加工精度等技术问题，获得技术效果 |
| 测量/测试 | 对物理量进行测试的程序 | 处理外部技术数据，产生技术效果 |
| 数据处理 | 改善计算机系统内部性能 | 提高了计算机运行效率/可靠性 |
| 外部数据处理 | 图像数据压缩方法 | 减少了存储空间占用 |
| 通信控制 | 数据传输中的纠错编码 | 提高传输可靠性 |

#### ❌ 不能授予专利权的情形

| 类型 | 示例 | 理由 |
|------|------|------|
| 商业方法 | 电子交易方法 | 属于商业规则和方法 |
| 数学算法 | 单纯的数值计算 | 属于智力活动的规则和方法 |
| 游戏规则 | 游戏策略 | 属于智力活动的规则和方法 |
| 信息呈现 | 信息显示格式 | 未解决技术问题 |
| 管理方法 | 人事管理方法 | 属于人为规定的管理规则 |

### 1.4 权利要求撰写要点

#### （1）方法权利要求

**推荐写法**：明确写出"一种[技术]方法"，步骤中体现技术特征。

**示例**：
> "1. 一种图像数据处理方法，其特征在于，包括以下步骤：
> 获取待处理的图像数据；
> 对所述图像数据进行离散余弦变换；
> 根据预设的量化表对变换后的系数进行量化；
> 对量化后的系数进行熵编码，得到压缩后的图像数据。"

**注意**：
- 步骤应反映完整的技术方案
- 避免使用纯功能性限定
- 明确输入输出数据的性质

#### （2）产品（装置）权利要求

**两种撰写方式**：

**方式A——功能模块构架**：
> "1. 一种图像数据处理装置，其特征在于，包括：
> 获取模块，用于获取待处理的图像数据；
> 变换模块，用于对所述图像数据进行离散余弦变换；
> 量化模块，用于根据预设的量化表对变换后的系数进行量化；
> 编码模块，用于对量化后的系数进行熵编码。"

**方式B——对应方法步骤**：
> "1. 一种图像数据处理装置，包括处理器和存储器，其特征在于，
> 所述处理器执行所述存储器中存储的计算机程序时实现权利要求1所述方法的步骤。"

### 1.5 说明书中应包含的内容

1. **技术领域**：明确说明涉及的具体技术领域
2. **背景技术**：指出现有技术的缺陷（技术层面）
3. **发明内容**：
   - 要解决的技术问题（必须是技术问题）
   - 技术方案（必须包含技术特征）
   - 有益效果（必须是技术效果）
4. **具体实施方式**：
   - 详细描述算法流程
   - 必要时给出流程图
   - 说明各步骤如何实现
   - 给出具体的数据处理实例

### 1.6 常见驳回理由及应对

| 驳回理由 | 应对策略 |
|---------|---------|
| 属于智力活动规则 | 强调技术问题+技术手段+技术效果；修改权利要求加入更多技术特征 |
| 缺乏创造性 | 补充实验数据证明技术效果的显著性；强调非显而易见性 |
| 说明书公开不充分 | 补充具体实施方式的细节描述 |
| 权利要求不支持 | 缩小范围或增加技术特征 |

## 二、化学领域发明专利申请（第二部分第十章）

### 2.1 化学发明的特殊性

```
┌─────────────────────────────────────────────────────┐
│            化学领域发明专利的特殊性                  │
├─────────────────────────────────────────────────────┤
│                                                     │
│  1. 发明难以预测                                    │
│     • 结构微小的变化可能导致性能巨大差异             │
│     • 无法仅凭结构推断性能                           │
│                                                     │
│  2. 实验验证必不可少                                │
│     • 必须提供实验数据支持有益效果                   │
│     • 仅理论分析不足以证明                          │
│                                                     │
│  3. 参数范围需要充分公开                            │
│     • 数值范围的端点值需要实施例支持                 │
│     • 中间值也需要至少一个实施例                     │
│                                                     │
│  4. 生物材料保藏的特殊要求                          │
│     • 公众无法获得的生物材料需保藏                  │
│     • 保藏单位需为指定机构                          │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 2.2 化合物发明的审查要点

#### （1）化合物的新颖性

**判断标准**：
- 结构不同 → 一般具有新颖性
- 结构相同但用途/形态不同 → 需具体分析

**特殊情况**：

| 情形 | 判断 | 说明 |
|------|------|------|
| 同分异构体 | 新颖 | 不同异构体视为不同化合物 |
| 手性化合物 | 新颖 | 对映异构体视为不同化合物 |
| 盐形式 | 新颖 | 化合物与其盐视为不同 |
| 溶剂化物 | 新颖 | 与原化合物不同 |
| 多晶型 | 新颖 | 不同晶型视为不同产品 |

#### （2）化合物的创造性

**判断要素**：
1. **结构上的非显而易见性**
   - 是否与已知化合物结构接近？
   - 是否有结构改造启示？

2. **用途/效果上的预料不到性**
   - 是否具有预料不到的性能/用途？
   - 效果是否显著优于已知化合物？

**常见创造性的认定情形**：
- 已知化合物发现了全新的、预料不到的用途
- 已知化合物通过修饰产生了预料不到的效果
- 创造性地合成了全新结构的化合物

#### （3）说明书充分公开的要求

**必须披露的内容**：
1. 化合物的确认方式（结构表征）
2. 制备方法（合成路线、反应条件、原料来源）
3. 用途和/或有益效果（**必须有实验数据！**）

**实验数据要求**：

| 项目 | 要求 |
|------|------|
| 测试方法 | 公知方法或详细描述新方法 |
| 对照组 | 通常需与已知化合物对比 |
| 数据完整性 | 至少一个完整的实施例 |
| 重复性 | 应能重复出类似结果 |

### 2.3 组合物发明的审查要点

#### （1）组合物的组分

**开放式 vs 封闭式表述**：

| 表述方式 | 含义 | 示例 |
|---------|------|------|
| 开放式（"含有"、"包括"） | 还可以含其他未列出的组分 | "组合物含有A和B" |
| 封闭式（"由…组成"） | 只含所列组分 | "组合物由A和B组成" |
| 半封闭式（"主要由…组成"） | 含所列组分+不影响基本特性的其他组分 | "组合物主要由A和B组成" |

#### （2）选择发明的创造性判断

**定义**：从现有技术的较宽范围中选择特定的窄范围或点。

**判断标准**：
1. 选择所产生的效果是预料不到的
2. 所作的选择是现有技术没有给出的技术启示
3. 该选择能够解决现有技术存在的技术问题

**示例**：
> 现有技术公开温度范围为10-100℃，
> 本申请选择30-35℃并证明在此范围内反应产率显著提高。
> 如果该提高是预料不到的，则具有创造性。

### 2.4 高分子化合物发明的特殊规定

#### （1）高分子化合物的确认

**必须明确的信息**：
- 分子结构式（重复单元）
- 分子量（数均/重均）及其分布
- 聚合度或聚合方法
- 必要时还需提供微观结构信息

#### （2）参数限定的使用

**允许使用的参数**：
- 分子量（Mn, Mw, PDI）
- 玻璃化转变温度（Tg）
- 熔融指数（MI）
- 特性粘度等

**注意事项**：
- 参数必须能够准确测定
- 参数与结构/性能之间应有对应关系
- 参数范围需要有足够的实施例支持

### 2.5 生物材料保藏规定

#### （1）需要保藏的情形

当满足以下**全部条件**时，需要进行生物材料保藏：
1. 申请涉及的生物材料是公众无法直接获得的
2. 该生物材料对于实现发明是必需的
3. 说明书中对该生物材料的记载不足以使技术人员获得它

#### （2）保藏要求

| 项目 | 要求 |
|------|------|
| 保藏时机 | 最迟在申请日（或优先权日） |
| 保藏单位 | 国家知识产权局认可的保藏中心（如CGMCC、CCTCC） |
| 保藏号 | 在申请文件中注明 |
| 存活证明 | 申请时或审查期间提交 |
| 保藏期限 | 至少30年 |

#### （3）常用保藏机构

| 机构名称 | 代号 | 地点 |
|---------|------|------|
| 中国普通微生物菌种保藏管理中心 | CGMCC | 北京 |
| 中国典型培养物保藏中心 | CCTCC | 武汉 |
| 中国微生物菌种保藏管理委员会普通微生物中心 | CGMCC | 北京 |

### 2.6 医药用途发明的特殊规定

#### （1）瑞士型权利要求

**格式**：
> "化合物X在制备治疗Y疾病的药物中的应用"

**注意**：
- 必须明确疾病类型
- 制药用途必须在说明书中充分公开
- 需要提供药效学实验数据

#### （2）制药用途的实验数据要求

| 数据类型 | 内容 |
|---------|------|
| 体外实验 | 细胞活性、酶抑制活性等 |
| 体内实验 | 动物模型疗效数据 |
| 临床试验 | 人体安全性/有效性数据（可选但有说服力） |

## 三、中药领域发明专利申请（第二部分第十一章）

### 3.1 中药发明的特点与难点

```
┌─────────────────────────────────────────────────────┐
│            中药领域发明专利的特点                     │
├─────────────────────────────────────────────────────┤
│                                                     │
│  特点：                                             │
│  • 组分复杂（多成分协同作用）                       │
│  • 质量受产地/采收时间/炮制方法影响                 │
│  • 作用机理往往不完全清楚                           │
│  • 传统经验与现代科学证据的结合                     │
│                                                     │
│  难点：                                             │
│  • 如何充分公开使得能够重现                         │
│  • 如何证明有益效果                                 │
│  • 如何界定保护范围                                 │
│  • 如何应对创造性质疑                               │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 3.2 中药产品的充分公开要求

#### （1）必须记载的内容

**药物组合物**：
1. **组成**：各味药材的名称和用量（重量份/重量比）
2. **原料规格**：药材的基原（拉丁学名）、产地、采收期、炮制方法
3. **制备工艺**：提取溶剂、提取方法、浓缩干燥方法、成型工艺
4. **剂型**：片剂、胶囊、颗粒剂、口服液等
5. **质量标准**：鉴别、含量测定、检查项目等

**用量表示方式**：

| 方式 | 适用情况 | 示例 |
|------|---------|------|
| 重量份 | 固定处方 | "黄芪10g、当归8g、川芎6g" |
| 重量比 | 比例可调 | "黄芪:当归:川芎 = 5:4:3" |
| 百分比含量 | 有效部位/提取物 | "总黄酮含量≥50%" |
| 范围 | 有变化空间 | "黄芪8-15g" |

#### （2）中药材的规范记载

**必须明确的药材信息**：

| 信息项 | 要求 | 示例 |
|--------|------|------|
| 名称 | 使用法定标准名称 | "甘草"（而非"甜草根"） |
| 基原 | 拉丁学名 | Glycyrrhiza uralensis Fisch. |
| 入药部位 | 根/茎/叶/花/果实/种子 | 根及根茎 |
| 产地 | 道地产区优先 | 内蒙古、甘肃等地 |
| 炮制方法 | 生用/炙用/酒制等 | 蜜炙 |
| 质量标准 | 符合《中国药典》 | 干燥品计，甘草酸≥2.0% |

### 3.3 中药发明的有益效果证明

#### （1）实验数据要求

**最低要求**：
- 至少**一个完整的实施例**（含对照）
- 实验设计科学合理
- 数据真实可靠
- 统计分析方法正确

**推荐的实验类型**：

| 实验类型 | 目的 | 适用阶段 |
|---------|------|---------|
| 药效学实验 | 证明治疗效果 | 必须 |
| 毒理学实验 | 证明安全性 | 推荐 |
| 质量研究 | 证明质量可控 | 必须 |
| 稳定性考察 | 证明有效期合理 | 推荐 |

#### （2）临床数据的作用

| 数据类型 | 作用强度 | 说明 |
|---------|---------|------|
| 个案报告 | 较弱 | 仅供参考 |
| 小样本观察 | 中等 | 有一定参考价值 |
| 随机对照试验(RCT) | 强 | 最具说服力 |
| 系统评价/Meta分析 | 很强 | 高级别证据 |

### 3.4 中药复方发明的创造性判断

#### （1）判断思路

```
第一步：确定最接近的现有技术（通常为已知方剂）
    ↓
第二步：区别技术特征是什么？（加减味、剂量变化、工艺改变等）
    ↓
第三步：该区别特征是否解决了技术问题？
    ↓
第四步：是否有技术启示？
    ↓
第五步：是否产生了预料不到的技术效果？
```

#### （2）常见的创造性认定情形

| 情形 | 创造性认定 | 说明 |
|------|-----------|------|
| 新组方（无先例） | 通常具有创造性 | 需证明配伍合理性 |
| 已知方剂的加减味 | 视情况而定 | 加减味后效果显著提升则可能有创造性 |
| 剂量优化 | 较难认定创造性 | 需证明特定比例产生了预料不到的效果 |
| 工艺改进 | 可能具有创造性 | 如提高了有效成分含量或生物利用度 |
| 新适应症 | 可能具有创造性 | 发现了新的治疗用途 |

#### （3）配伍关系的论证

**论证要点**：
1. 君臣佐使的理论依据
2. 各成分的协同作用机制
3. 配伍后的增效减毒效果
4. 与单味药作用的对比

### 3.5 中药提取物的保护策略

#### （1）有效部位/有效成分的保护

**层级递进保护策略**：

```
全方（粗提物）
    ↓
有效部位群（如总黄酮、总皂苷）
    ↓
单一有效成分（单体化合物）
    ↓
衍生物/前药
```

**建议**：根据研发阶段选择合适的保护层级

#### （2）提取物权利要求的撰写

**示例**：
> "1. 一种中药提取物，其特征在于，它是从下述重量份的中药原料中提取得到的：
> 黄芪20-40份、当归10-20份、川芎5-15份；
> 其中所述提取物中总黄酮含量不低于40%，总皂苷含量不低于15%。"

### 3.6 中药发明专利常见问题及对策

| 问题类型 | 具体表现 | 对策 |
|---------|---------|------|
| 公开不充分 | 药材基原不清、制备工艺不详 | 补充详细信息，引用药典标准 |
| 缺乏实验数据 | 仅陈述传统功效而无现代验证 | 补充药效学实验数据 |
| 保护范围过宽 | 概括到整个科属 | 收窄至具体种属，增加限定特征 |
| 创造性不足 | 与古方/公知常识过于接近 | 强调新的技术效果或新的用途 |
| 权利要求不清楚 | 使用模糊术语如"适量"、"少许" | 改用具体的数值范围 |

## 四、跨领域通用审查要点对比

### 4.1 三大特殊领域对比表

| 审查要点 | 计算机程序 | 化学 | 中药 |
|---------|-----------|------|------|
| **客体判断** | 技术方案vs智力活动规则 | 无特殊限制 | 无特殊限制 |
| **新颖性** | 方法/装置均需判断 | 结构/参数/用途 | 组成/工艺/用途 |
| **创造性** | 技术效果的非显而易见性 | 预料不到的技术效果 | 配伍合理性/新效果 |
| **实用性** | 可制造/使用 | 可再现性 | 可重现性 |
| **充分公开** | 流程图+具体实施例 | 结构确证+制备方法+实验数据 | 药材详情+工艺+药效数据 |
| **实验数据** | 性能测试数据 | **必须**（化学领域） | **必须**（中药领域） |
| **权利要求** | 方法/装置/介质 | 产品/用途/方法 | 组合物/方法/用途 |
| **特殊制度** | — | 生物材料保藏 | — |

### 4.2 各领域共通的审查原则

1. **以说明书为依据**：所有领域的权利要求都必须得到说明书的支持
2. **充分公开**：所属领域技术人员能够实现
3. **清楚简要**：保护范围清晰、边界明确
4. **不超范围**：修改不得超出原始申请文件的范围
