# 诉讼与仲裁核心差异对照表

## 制度差异

| 维度 | 民事诉讼 | 商事仲裁 |
|------|---------|---------|
| **终局性** | 二审终审（可申请再审） | 一裁终局（《仲裁法》第 9 条） |
| **管辖权来源** | 法定管辖（被告住所地/合同履行地等） | 约定管辖（仲裁条款/仲裁协议） |
| **审判/仲裁庭组成** | 法院指定合议庭或独任法官 | 当事人选定仲裁员（《仲裁法》第 31 条） |
| **公开性** | 公开审理为原则 | 不公开审理为原则（《仲裁法》第 40 条） |
| **证据规则** | 严格适用《民诉法》及司法解释 | 仲裁庭可自行决定证据规则（较灵活） |
| **保全措施** | 法院直接裁定 | 通过仲裁机构转交法院裁定（《仲裁法》第 28 条） |
| **撤销/不予执行** | 上诉或再审 | 申请撤销仲裁裁决（《仲裁法》第 58 条）或不执行（第 63 条） |
| **境外执行** | 需双边司法协助条约 | 《纽约公约》（1958）170+ 缔约国，更便捷 |

## 主要仲裁机构规则要点

### CIETAC（中国国际经济贸易仲裁委员会）

- 规则：CIETAC 仲裁规则（2024 版）
- 特色：紧急仲裁员程序、合并仲裁、追加当事人、第三方资助披露
- 默认仲裁地：北京/上海/深圳/香港等

### HKIAC（香港国际仲裁中心）

- 规则：HKIAC 仲裁规则（2024 版）
- 特色：紧急仲裁员、简易程序（争议金额 < 2500 万港币）、第三方资助需披露
- 默认仲裁地：中国香港
- 适用《香港仲裁条例》（以 UNCITRAL 示范法为基础）

### SHIAC（上海国际经济贸易仲裁委员会）

- 规则：SHIAC 仲裁规则（2024 版）
- 特色：自贸区仲裁规则、航空仲裁、临时仲裁（自贸区试点）

## 适用法律选择考量

| 情形 | 注意事项 |
|------|---------|
| 纯国内纠纷 | 必须适用中国法，不得约定外国法（《涉外民事关系法律适用法》第 4 条） |
| 涉外因素纠纷 | 可约定适用外国法或国际惯例，但不得违反中国强制性规定和社会公共利益 |
| 仲裁地在中国 | 程序法为中国《仲裁法》，实体法可依约定 |
| 仲裁地在境外 | 程序法为仲裁地法，需确认该国仲裁法与中国《仲裁法》的核心差异 |
| 境外裁决在华执行 | 适用《纽约公约》，审查限于第 V 条规定的拒绝承认与执行事由 |

## 策略选择建议

### 适合仲裁的场景

- 当事人希望保密（不公开审理）
- 跨境交易，仲裁裁决更易在境外执行（《纽约公约》）
- 当事人需要选定专业领域仲裁员
- 追求效率（一裁终局）

### 适合诉讼的场景

- 需要财产保全/证据保全的及时性（法院可直接裁定）
- 争议金额较小（仲裁费用通常高于诉讼）
- 需要二审救济机会
- 对方资信差，需要利用法院执行力量
