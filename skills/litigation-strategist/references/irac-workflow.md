# IRAC 方法论详细工作流

## Issue — 争议焦点提炼

从案情中识别双方的核心分歧点，提炼为 1-3 个法律争点：

1. **事实争点**：双方对关键事实的认定是否存在分歧？
2. **法律争点**：双方对法律适用的理解是否存在分歧？
3. **证据争点**：关键证据的真实性、合法性、关联性是否存在争议？

每个争点表述应简洁，使用法律术语，不夹杂事实陈述。

## Rule — 法律依据锁定

### 实体法检索顺序

1. 《民法典》（合同编、物权编、侵权责任编、婚姻家庭编等）
2. 相关特别法（如《公司法》《合伙企业法》《商标法》等）
3. 最高人民法院司法解释（关注时效性，标注"请核实最新修订"）
4. 最高人民法院指导性案例/公报案例（注明案号、裁判要旨）

### 程序法依据

1. 《民事诉讼法》及《民诉法司法解释》
2. 《仲裁法》及《仲裁法司法解释》
3. 各仲裁机构规则（CIETAC/HKIAC/SHIAC 等）
4. 《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》

## Analysis — 双向分析

### 请求权构成要件核查（以合同纠纷为例）

| 构成要件 | 是否满足 | 证据支撑 |
|---------|---------|---------|
| 合同有效成立 | □ | ... |
| 我方已履行义务 | □ | ... |
| 对方构成违约 | □ | ... |
| 损害结果发生 | □ | ... |
| 因果关系 | □ | ... |

### 抗辩权分析

- 时效抗辩（诉讼时效是否经过）
- 履行抗辩（同时履行/先履行/不安抗辩）
- 抵销抗辩（是否存在互负债务）
- 违约金过高抗辩（《民法典》第 585 条）

## Conclusion — 结论

- 基于上述分析给出预判
- 标注"基于一般司法实践的倾向性判断"
- 量化胜诉率：高（>70%）/ 中（40-70%）/ 低（<40%）
- 指出不确定性因素和关键变量
