# 民事证据规则要点

## 举证责任分配

### 一般规则

- **谁主张谁举证**：《民诉法司法解释》第 90 条
- 主张法律关系存在的当事人，对该法律关系的基本事实承担举证责任
- 主张法律关系变更、消灭或权利受到妨害的当事人，对该事实承担举证责任

### 举证责任倒置情形

| 情形 | 法律依据 |
|------|---------|
| 环境污染侵权 | 《民法典》第 1230 条 |
| 医疗损害（推定过错情形） | 《民法典》第 1222 条 |
| 高度危险作业 | 《民法典》第 1239 条 |
| 饲养动物损害 | 《民法典》第 1245-1247 条 |
| 建筑物等脱落坠落 | 《民法典》第 1253 条 |

## 证据三性评判标准

### 真实性

1. **原件优先**：书证应提供原件，物证应提供原物（《民诉法》第 70 条）
2. **复制件的证明力**：无法与原件核对的复制品不能单独作为认定事实的依据
3. **电子数据**：需关注原始存储介质的完整性、MD5/Hash 一致性

### 合法性

1. **取证手段**：不得以严重侵害他人合法权益、违反法律禁止性规定或严重违背公序良俗的方法取证（《民诉法司法解释》第 106 条）
2. **私录视听资料**：未经对方同意私自录制的对话，如在公共场所或不涉及隐私，一般不因取证手段不合法而被排除
3. **公证取证**：公证文书具有较高的证明力（《民诉法》第 69 条）

### 关联性

1. **直接证据 vs 间接证据**：直接证据单独即可证明待证事实；间接证据需形成链条
2. **经验法则**：法院可运用经验法则判断证据关联性
3. **品格证据**：一般与待证事实无关联，但特定案件中可能相关

## 证明力与盖然性

### 证明力高低判断

| 证明力等级 | 证据类型举例 |
|-----------|------------|
| 极高 | 公证文书、生效判决认定的事实、对方自认 |
| 较高 | 书面合同原件、银行转账凭证、国家机关公文 |
| 中等 | 微信聊天记录（可核验）、证人证言（出庭作证）、邮件往来 |
| 较低 | 利害关系人证言、无法核实的复印件、模糊的录音 |

### 盖然性标准

- **民事诉讼标准**：高度盖然性（《民诉法司法解释》第 108 条）——待证事实的存在具有高度可能性
- **与刑事诉讼的区别**：刑事诉讼要求"排除合理怀疑"，民事诉讼仅需"高度盖然性"

## 质证策略模板

```
针对对方提交的 [证据名称]：

1. 真实性异议：
   - 非原件/原始载体
   - 签章疑似伪造/不完整
   - 电子数据未经公证保全

2. 合法性异议：
   - 取证手段违反《民诉法司法解释》第 106 条
   - 未经当事人同意获取隐私通讯记录

3. 关联性异议：
   - 与待证事实之间不存在逻辑关联
   - 仅能证明间接事实，无法直接证明核心事实
   - 属于品格证据，应予排除
```
