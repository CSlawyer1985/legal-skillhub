# 任务 10——引用格式统一

> **环境前提**：COWORK 或 CHAT_CU **必须**——本任务通过 XML 编辑生成带注释的镜像文档。在 CHAT 模式下，**立即中断**并要求启用 computer use 或切换到 Cowork。如文档超过 15 页，建议使用 COWORK（与任务 9 的逻辑相同）。

## 目标

依据 RefLex SNE 2022 指南确保法律文件中所有引用的形式一致性。检测不一致之处，向用户提出形式选择建议，然后系统性地应用。

## 原则

RefLex 指南在多个形式要点上留有一定自由（见 `references/format-citations.md`"允许的变体"一节）。变体之间的选择属于作者。统一不在于强加单一规范，而在于确保文件的**内部一致性**。

## 流程

### 第 1 步——提取与清点

**执行：**
1. 通读整个文档（正文、脚注、参考书目、附录）
2. 提取所有引用（如可用，使用 `scripts/extract_references.py`）
3. 对每处引用：记录其在文档中出现的精确形式

### 第 2 步——检测不一致

按类别对引用分组，识别每类内部的形式变体：

**需检查的类别：**

| 类别 | 常见变体 |
|---|---|
| 作者姓名 | `BRUN Ph.` 与 `Brun (Ph.)` 与 `Ph. Brun` 与 `Philippe Brun` |
| 最高法院分庭 | `Cass. civ. 1re` 与 `Cass. 1re civ.` 与 `Cass. civ. 1ère` 与 `Civ. 1re` |
| 最高行政法院 | `CE` 与 `Cons. d'Ét.` 与 `Conseil d'État` |
| 日期 | `12 juillet 2023` 与 `12 juill. 2023` 与 `12/07/2023` |
| 上诉编号 | `n° 21-12.345` 与 `n° 21-12345` 与 `pourvoi n° 21-12.345` |
| 期刊名称 | `RTD civ.` 与 `Rev. trim. dr. civ.` 与 `Revue trimestrielle de droit civil` |
| 引号 | `« … »` 与 `"…"` 与 `"…"` |
| 法典条款 | `art.` 与 `Art.` 与 `article` |
| 交叉引用 | `V.` 与 `v.` 与 `Voir` 与 `Cf.` |
| 多作者分隔 | `et` 与 `&` 与 `,` |
| 页码 | `p.` 与 `pp.` 与 `page` 与 `pages` |

### 第 3 步——呈现与选择（唯一中断点）

**仅中断一次**，向用户呈现检测到的变体表格并征询其选择：

```
引用格式统一——检测到的变体

我在文档中识别出以下不一致之处。对每个类别，请指明您希望采用的形式
（或确认我的 RefLex 建议）。

| 类别 | 形式 A（N 处） | 形式 B（N 处） | RefLex 建议 |
|---|---|---|---|
| 作者姓名 | BRUN Ph.（12 处） | Brun (Ph.)（3 处） | BRUN Ph. |
| 最高法院分庭 | Cass. civ. 1re（8 处） | Civ. 1re（2 处） | Cass. civ. 1re |
| 日期 | 12 juill. 2023（15 处） | 12 juillet 2023（5 处） | 12 juill. 2023 |
| … | … | … | … |

您希望采纳 RefLex 建议还是修改某些选择？
```

等待用户答复。记录选择。

### 第 4 步——系统性应用

**不间断执行：**

对文档中的每处引用，应用用户确认的形式选择。产出更正后的文档。

### 第 5 步——镜像文档标注

如单独执行（不结合任务 9），产出带注释的镜像文档。如与任务 9 结合，将统一注释添加到共同镜像文档。

**统一注释格式：**
```
📐 统一
之前：[文档中的原始形式]
之后：[更正后的形式]
规则：[RefLex 规则或用户选择的引用]
```

**⚠️ 强制性规则——位于脚注中的引用：**
如待统一的引用位于脚注（存储在 `footnotes.xml` 中），注释**必须**锚定在 `document.xml` 中脚注引用标记处——即包含对应 `<w:footnoteReference w:id="N"/>` 的 `<w:r>` 处——而**非**在 `footnotes.xml` 中。注释文本必须提及所涉脚注编号（如"注 n° 12——"）。

**示例：**

```
📐 统一
之前：Cass. civ. 1ère, 12 juillet 2023
之后：Cass. civ. 1re, 12 juill. 2023
规则：序数缩写"1re"（非"1ère"）+ 月份缩写（RefLex §3.2）
```

```
📐 统一
之前：Brun (Ph.), « La responsabilité... »
之后：BRUN Ph., « La responsabilité... »
规则：用户选择——姓氏 首字母形式。
```

### 与核查（任务 9）的交互

当任务 9 和 10 结合时：

1. **如核查发现 ERREUR_CITATION（引用错误）**：统一提供更正后的形式（不仅是统一形式，而且是事实准确的形式）。注释合并两类信息：
```
⚠️ 引用错误 + 📐 统一
标准化引用：Cass. civ. 1re, 20 sept. 2017, n° 16-19.109
检测到的错误：上诉编号有误（16-19.019 → 16-19.109）
统一：日期缩写（septembre → sept.），形式 Cass. civ. 1re
链接：[URL]
```

2. **如核查返回 NON_TROUVEE（未找到）**：该引用被标记为未核实，但其形式仍予以统一。不将其视为不合法。
```
❌ 未找到 + 📐 统一
标准化引用：CA Lyon, 3e ch., 12 mars 2019, n° RG 17/05432
在 Legifrance 和 web 搜索中均未找到。
已应用统一：日期和法院形式标准化。
该引用不被视为不合法——无结果可能有技术原因。
```

## 交付物

**如单独执行：**
- 更正后文档：`[AAAA-MM-JJ]-harmonise-[nom-doc].docx`
- 镜像文档（注释）：`[AAAA-MM-JJ]-miroir-harmo-[nom-doc].docx`

**如与任务 9 结合：**
- 单一镜像文档：`[AAAA-MM-JJ]-miroir-verif-harmo-[nom-doc].docx`
- 更正后文档（已应用统一）：`[AAAA-MM-JJ]-harmonise-[nom-doc].docx`
