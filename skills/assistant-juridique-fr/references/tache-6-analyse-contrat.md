# 任务6——合同分析

> **环境前提**：交付 Word 文件需要 COWORK 或 CHAT_CU。在 CHAT 模式下，如合同在上下文窗口中可见则可执行（对话式回答）——否则，中断并要求启用 computer use。

## 目标

全面分析合同，识别其合规性、问题条款、法律风险，并提出改进建议。

## 流程

### 1. 执行流程手册（任务0）

流程手册在此尤为重要：它识别合同适用的制度和优先关注点（应首先核实的条款、强制载明事项、特殊制度）。

### 2. 扫描工作目录（深入）

**合同是本任务的主要材料。** 如存在相关文件（谈判函件、补充协议、先前合同、需求说明书），将其纳入分析。

执行：
1. 完整阅读合同
2. 识别当事人、标的、价格、期限
3. 记录合同结构（条款、附件）
4. 依据定性识别适用制度（见流程手册）

### 3. 检索适用法律框架

**经 OpenLegi 执行：**
- 合同一般制度（《民法典》第1101条起）
- 适用的特殊制度（租赁、买卖、劳动、消费等）
- 该类型合同的强制载明事项
- 视为未写入或禁止的条款
- 关于该类型合同争议条款的近期判例

### 4. 逐条分析

对每项重要条款：

| 条款 | 合规性 | 风险 | 建议 |
|---|---|---|---|
| 第X条——[标的] | 合规 / 不合规 / 含糊 | 无 / 中等 / 高 | 保留 / 修改 / 删除 |

**系统关注点：**
- 不公平条款（B2C 依《消费者法典》，B2B 依判例）
- 责任条款和责任限制条款
- 违约金条款（司法酌减权，《民法典》第1231-5条）
- 终止条款（条件、通知期、后果）
- 竞业限制条款（有效性条件）
- 不可抗力（合同定义 vs 法律定义）
- 适用法律和管辖法院
- 个人数据保护（适用时依 GDPR）

### 5. 全局风险分析

在逐条分析之外：
- 合同整体平衡（是否存在重大失衡？）
- 内部一致性（条款之间是否存在矛盾？）
- 缺口（该类型合同必备的条款是否缺失？）
- 是否符合法律的最新演进

### 6. 交付

Word 文档包括：
1. **综述**：合同定性、整体合规性、主要风险
2. **逐条分析表**
3. **全局风险分析**
4. **建议**：拟议修改、应添加的条款
5. **注释和引用**

命名：`[AAAA-MM-JJ]-analyse-contrat-[type-ou-parties].docx`
