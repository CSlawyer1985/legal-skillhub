# 基本原则——反幻觉与核验

<!-- NOYAU-ANTIHALLUCINATION v3 — 与 mandarinat 1.4.0 / assistant-juridique-fr 7.4.0 同步。本文件为两个 skill 共用：任何修改必须以完全相同的方式同步到另一个。 -->

## 适用范围

以下规则适用于本 skill 产出的交付物中提及的**任何法律引用**。其无差别涵盖：

1. **判例**——任何法院的判决（最高法院、最高行政法院、宪法委员会、欧洲人权法院、欧盟法院、下级法院），以其日期、上诉/请求/案件编号和审判组织为识别。
2. **规范性文本**——宪法、条约、欧盟条例和指令、法律、法令（ordonnance）、政令（décret）、部令（arrêté）、各法典的编号条款、集体协议。
3. **学说**——期刊文章、著作、论文、判例评注、集体著作中的章节。捏造一个看似合理的学说引用（真实的作者、真实的期刊、虚构的标题和页码，或将某篇论文错误归于某作者）是特别隐蔽的幻觉载体，因为没有哪个数据库是穷尽的，审阅者难以轻易证伪。任何被引用的学说引用必须通过实际检索找到（`scripts/doctrine_search.py`、`scripts/hal_search.py`、对可识别来源的 web_search），并带有**可验证的标识符**：DOI、HAL 标识符，或公认数据库（Cairn、Persée、OpenEdition、Dalloz）的 URL。否则，该引用应标注为“未核验”或删除。

明确扩展到规范性文本是有意为之：条款编号经常被重新编号（2016 年 2 月 10 日第 2016-131 号关于合同法改革的法令——<https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000032004939>——即以《民法典》第 1240 条取代旧第 1382 条，以第 1242 条取代旧第 1384 条；此后的法典重构产生类似效果），条文措辞也在演变（《民法典》第 1242 条第 4 款——<https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006437058>——已被 2025 年 6 月 23 日第 2025-568 号法律实质性修改——<https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000051782996>），而凭空捏造一个条款编号或引用已废止的措辞，与捏造一个上诉编号具有完全相同的严重性。

## 基本规则

**严格禁止**生成、创建或捏造法律引用。任何被引用的引用都必须同时满足：

1. 先前已通过实际检索找到（OpenLegi、HAL、LegalDataHunter、web_search）；
2. 法国来源附带有效的 Légifrance 链接（非法国来源附带相应的官方链接：HUDOC、Curia、EUR-Lex 等）。

对某引用的熟悉程度**绝不**免除核验义务：幻觉恰恰就藏身于此。

## 强制五步流程

顺序是强制性的，不允许任何例外：

1. **检索（CHERCHER）**——发起检索（优先 OpenLegi，学说用 HAL，外国或超国家法律用 LegalDataHunter，web_search 作为补充）。
2. **找到（TROUVER）**——识别匹配的结果，核验其元数据：存在性、日期、法院或发布机关、编号、时间状态、适用文本版本。
3. **阅读内容（LIRE LE CONTENU）**——实际获取工具返回的判决或条款文本。元数据卡片不够：必须访问判决主文、判决理由，或条款全文。
4. **核验内容是否支撑所主张的观点（VÉRIFIER QUE LE CONTENU SOUTIENT L'ASSERTION）**——将返回的内容与该引用旨在支撑的命题进行逐字对照。形式上的可追溯性（引用确实在本会话中被工具调用过）**绝不**免除这种对照：形式上可追溯但实质上不一致的引用构成**错误归因型幻觉**。
5. **引用（CITER）**——按检索工具响应中出现的原样，附带指向官方来源的超链接转载该引用。

倒置顺序（先引用后核验）被禁止。凭记忆、类比或插值重建 Légifrance URL 被禁止。引用未经阅读内容并与命题对照的引用同样被禁止。

## 错误归因型幻觉——实例演示

形式可追溯性不够。典型场景如下：本 skill 通过会话内检索识别出某法典条款（工具调用确实存在），然后引用该条款来支撑某大前提，而该大前提的实际内容与所引文本无关。该引用形式上合规——标识符存在、Légifrance 链接有效——但归属于该条款的大前提并非其真正内容。

**错误**：“故意解除限速、违反《道路交通法典》第 R. 412-43-3 条驾驶代步工具”。

实际上，《道路交通法典》第 R. 412-43-3 条规定的是驾驶个人机动代步工具（EDPM）的最低年龄为十四岁，并要求夜间穿戴反光装备；该条完全不涉及解除限速或出厂最高时速。因此，它不支撑此处旨在支撑的命题。

**正确**：“故意解除限速、违反 EDPM 管理规定驾驶代步工具，依《道路交通法典》第 R. 311-1 条第 6.15 项，EDPM 的出厂最高时速为 25 km/h”。

《道路交通法典》第 R. 311-1 条第 6.15 项定义了 EDPM 类别，并将出厂最高时速定为 25 km/h；因此所引文本确实支撑了关于解除限速的命题。

**引用前必须做的事**：打开 OpenLegi 返回的条款卡片，阅读实际内容，并核验其所确立的规则是否涵盖要表述的命题。否则，三种出路之一：更换引用（补充检索）、改写命题使其与实际内容相符、改用非人称表述。

## Légifrance 链接强制要求

任何法国司法判决或法国规范性文本的引用——无例外——都必须附带有效的 Légifrance 链接。预期的 URL 格式如下：

| 引用类型 | URL 模式 |
|---|---|
| 司法判例 | `https://www.legifrance.gouv.fr/juri/id/JURITEXT…` |
| 行政判例 | `https://www.legifrance.gouv.fr/ceta/id/CETATEXT…` |
| 宪法委员会决定 | `https://www.legifrance.gouv.fr/jorf/id/JORFTEXT…`（或宪法委员会网站专门页面） |
| 法典条款 | `https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI…` |
| 法律条款和综合文本（LODA） | `https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI…` 或 `https://www.legifrance.gouv.fr/loda/id/LEGITEXT…` |
| 发布于官方公报的文本 | `https://www.legifrance.gouv.fr/jorf/id/JORFTEXT…` |

这一规则产生四个实务后果。

**（a）无 Légifrance 链接的引用。** 如果某引用未能生成 Légifrance 链接，则要么将其从交付物中删除，要么明确标注为不确定（注明“待核验的引用”）。任何无链接的引用不得在未加该明确标注的情况下出现在交付物中。

**（b）“经典”判决或条款没有例外。** 该规则适用于所有引用，包括：

- 本 skill 自以为熟记于心的原则性判决（Costedoat、Bertrand、Lemaire、Blieck、Jand'heur、Franck 等）；
- 《民法典》（1240、1241、1242、1245 及以下、1103、1104 等）、《刑法典》、《商法典》及任何其他法典中“超级经典”的条款，其现行编号和措辞可能与本 skill 自以为知道的不同。

熟悉感会制造虚假的可靠信号：幻觉恰恰藏身于此。该规则以完全相同的严格度适用于生僻引用和著名引用。

**（c）链接之外还必须进行时间核验。** 对任何规范性文本，在 Légifrance 上核验**在相关日期有效**的措辞：争议事实发生之日（回溯性查询）、今日（前瞻性查询或讲授现行法的课程）。当文本经历过可能影响论证的近期修改时，明确注明适用的版本。示例：“《民法典》第 1242 条第 4 款——<https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006437058>——2025 年 6 月 23 日第 2025-568 号法律所修订的文本——<https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000051782996>”。

**（d）合法的替代路径。** 如果本 skill 希望在未核验具体引用的前提下援引某项原则或规则，应使用非人称表述，不引用上诉编号或条款编号：

- “司法先例一贯认为……”；
- “司法先例已确立……”；
- “侵权责任的一般法规定……”；
- “主流学说承认……”。

编号只有在已核验时才出现。这一路径是合法的，且优于任何冒险的引用。

## 链接主动核验与引用日志

在 COWORK 和 CHAT_CU 模式（可访问文件系统）下：

- **随时维护引用日志**，在**每次工具调用之时**记录（而非事后凭记忆），通过 `scripts/reference_journal.py add` → `verification/journal-references.ndjson`。每条记录记载引用、工具、标识符、URL、相关文本摘录、所支撑的命题以及（在最高法院层级）陈述主体。随后检查清单表格**从该日志生成**（`reference_journal.py table`），从而禁止凭记忆填写“摘录”列。
- **在任何实际交付之前**，对交付物中出现的全部 Légifrance URL 运行 `scripts/verify_links.py`。该脚本：
  - 核验每个 URL 是否对应已识别的 Légifrance 模式（`JURITEXT`、`CETATEXT`、`JORFTEXT`、`LEGIARTI`、`LEGITEXT`）；
  - 核验每个 URL 是否可访问（HTTP 200）；
  - 在 `--check-content` 模式（默认启用）下，获取 Légifrance 页面并核验其确实包含预期的上诉编号、条款编号或标题。

在 CHAT 模式（无文件系统）下，以显式方式逐条引用进行同样的核验：对每条引用，识别在会话中产生该引用的 OpenLegi（或其他检索工具）调用，并确认交付物中转载的 Légifrance 链接确实来自该响应——而非凭记忆重建。

→ 步骤详情：`references/checklist-pre-livraison.md`。

## 禁止事项

- 先创建引用再“核验”它（流程倒置）。
- 未经事先检索凭记忆引用，即使主观确信度很高。
- 为凑足用户要求的数量而捏造引用。
- 生成上诉编号、RG 编号、请求编号、决定编号。
- 捏造或臆断条款编号，例如从相邻的已知编号插值，或假设某个本 skill “知道”旧编号的条款在改革后保留了该编号。
- 以未核验或被臆断为稳定的措辞引用条款，而法典经常经历重新编号和修改。
- 未经查阅即为判决附加日期、审判组织或摘要。
- 凭类比或记忆重建 Légifrance URL，而非从当前会话中为这条具体引用执行的检索工具响应中直接取用。
- **引用在会话中经工具调用形式上可追溯、但未经阅读其内容并核验其确实支撑其所旨在支撑之命题的引用**（错误归因型幻觉）。工具调用的存在不免除内容匹配义务。
- 引用无可验证标识符（DOI / HAL / 公认数据库 URL）的学说引用（文章、著作、论文、评注），或捏造页码、卷号或作者归属。
- 在最高法院（Themia）语境中，将 `passage_motifs_ca`（上诉法院理由）或 `passage_moyens` / `passage_moyens_annexes`（当事人主张）中的摘录表述为**法院的立场**。陈述主体归属错误属于错误归因型幻觉。

## 引用不足的处理

如果找到的引用数量少于期望数量：

1. 只引用实际找到并核验过的引用。
2. 说明实际数量：“我就此点找到了 N 条引用。”
3. 建议扩大检索范围（其他期间、其他法院、相关术语）。
4. 绝不为补足而捏造。

## 术语

- **已核验的引用**——经检索找到、元数据一致、Légifrance 链接（或同等官方链接）存在且可访问。
- **未找到的引用**——经检索未能定位（≠ 虚假，≠ 不存在）。
- **待核验的引用**——其存在性未被可用工具确证；须在交付物中明确标注。

绝不要将引用称为“虚假”“不正确”或“错误”——只能说“未找到”“未核验”或“待核验”。

## 来源与工具

**OpenLegi（法国法优先）**——通过 OpenLegi 访问的任何来源均可靠（Legifrance 官方数据）。

- 文本：`rechercher_code`、`rechercher_dans_texte_legal`、`recherche_journal_officiel`
- 司法判例：`rechercher_jurisprudence_judiciaire`
- 行政判例：`rechercher_jurisprudence_administrative`
- 宪法委员会：`rechercher_decisions_constitutionnelles`
- CNIL：`rechercher_decisions_cnil`
- 集体协议：`rechercher_conventions_collectives`

所有 OpenLegi 响应都在其元数据中包含一个 Légifrance 链接：该链接必须从响应中**提取**并无任何变造地**转载**到交付物中。

**学说（多源检索）**——`scripts/doctrine_search.py` 是**主要工具**：它查询 HAL、OpenAlex 和 Isidore，通过 DOI（Crossref）解析和去重，并为每条引用返回一个**可验证的标识符**（DOI / HAL / URL）。`scripts/hal_search.py` 对针对性 HAL 查询仍然有用（通过 `--pourvoi` 按上诉编号检索判例评注）。无法访问的来源会被标注（`sources_failed`）而不阻断。无可验证标识符的学说引用属于“未核验”：标注为未核验或删除，绝不作为已确认引用。

**HAL（学说）**——元数据可靠（经核验的存储库）。覆盖不完整（作者自行存储的出版物；商业期刊往往只有书目记录）。是 `doctrine_search.py` 和 web_search 的补充，绝非替代。

**LegalDataHunter（欧洲人权法院、欧盟法院、外国法）**——HUDOC、Curia 及同等的官方网站链接对这些法院而言相当于 Légifrance 链接；同样适用官方链接规则。

**web_search（补充）**——仅可靠来源（见 `references/sources-fiables.md`）。对未存入 HAL 的学说、2015 年以前的欧洲人权法院、2015 年以前的欧盟法院以及法律新闻不可或缺。官方链接规则同样适用：绝不引用没有相应官方数据库链接的外国判决。

## 时间核验（浓缩提示）

每个被引用的文本都须作时间定性（现行有效、已废止、未来生效）。利用 OpenLegi 元数据（法律状态、生效开始/结束日期）。方法论细节见 `SKILL.md` 第 7 节。当文本近期被修改时，明确注明适用的措辞版本。

## JORF 来源的定性

《官方公报》包含性质各异的文件。须系统性定性：

- **规范性**（法律、法令、政令、部令）——可作为现行法引用。
- **议会工作文件**（书面问题、报告、意见）——仅可作为解释要素引用。
- **行政文件**（通函、公报）——逐案定性。

绝不笼统引用“据《官方公报》”而不说明文件的性质。
