# 任务 3——法律文书起草

> **环境前提**：COWORK 或 CHAT_CU 用于 Word 交付物。在无 computer use 的 CHAT 模式下，可以对短文书进行对话式起草，但无法专业排版——向用户说明这一点，并提议启用 computer use。

## 目标

起草一份符合现行法律的法律文书（合同、催告函、代理意见、传唤状、申请书、法律函件等）。

## 流程

### 1. 执行 playbook（任务 0）

### 2. 扫描工作文件夹

如文件夹中存在**框架或模板**：遵循之。将模板适配到个案事实，而非凭空创建。保留模板的风格和结构。

如存在**材料**：利用它们提取起草所需的事实数据（姓名、日期、金额、地址、事实）。

### 3. 识别与定性

精确确定文书类型：
- 程序文书：传唤状、代理意见、申请书、诉状
- 保全文书：催告函、通知、催告
- 合同：买卖、租赁、借款、服务、委托
- 单方文书：遗嘱、债务确认、解约通知

对当事方和适用制度进行定性（特别 vs 一般）。

### 4. 检索法律要求

**通过 OpenLegi 执行：**
- 必备记载事项（《民事诉讼法典》、领域特定法典）
- 规定期限和形式
- 实体有效条件（同意、能力、内容合法且确定）
- 依制度规定的强制／禁止条款

### 5. 起草

**强制性规则：**
- 语言适配接收方：程序文书用技术法律术语；面向非专业人士时用清晰语言（ISO 24495-2:2025 标准）
- 必备法律记载事项完整
- 援引适用文本
- 结构符合所涉文书职业惯例

**对代理意见／诉状：**
- 清晰区分：事实／法律论证／主文
- 每个理由使用严格的三段论
- 援引每项文本和判例依据

**对合同：**
- 当事方精确识别
- 标的和价款确定或可确定
- 该合同类型的关键条款
- 适配制度（消费、劳动等）的保护性条款

### 6. 交付

将 Word 文件写入工作文件夹。命名：`[AAAA-MM-JJ]-[acte-type]-[parties-ou-objet].docx`。
