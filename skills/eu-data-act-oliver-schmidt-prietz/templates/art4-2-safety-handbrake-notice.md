# 模板：第 4(2) 条安全/安保限制通知

产出数据持有者与用户之间的双边通知，依据《欧盟法规 (EU) 2023/2854》（《数据法案》）第 4(2) 条的安全/安保紧急制动，通过合同限制或禁止对某些数据的访问、使用或进一步共享。包括数据持有者以此为由拒绝共享数据时，向主管机关进行的并行第 37 条通知。

形式：双输出。(i) 简短的双边通知或合同修改，以及 (ii) 主管机关通知函。数据持有者依赖第 4(2) 条拒绝数据共享时，两者均为必需。默认为 Markdown。

在数据可能因以下理由受限制时使用本模板：处理可能损害欧盟或国家法律规定的物联网产品安保要求，从而对自然人的健康、安全或安保造成严重不利影响。不要将本模板用作第 4(6)–(8) 条商业秘密紧急制动（trade-secret handbrake）的替代；两种制度截然不同。

---

## 第一部分：双边通知或合同修改

```
[数据持有者信头占位符]

致：[用户，完整法定实体名称 / 自然人姓名及地址]

日期：[日期]

编号：[内部编号；援引任何基础用户请求]

主题：依据《欧盟法规 (EU) 2023/2854》（《数据法案》）第 4(2) 条
      关于数据访问、使用或进一步共享的合同限制通知

1. 背景与范围

   本通知涉及 [数据持有者] 与 [用户] 之间 [合同编号] 项下的
   物联网产品 [标识符] 及相关服务 [标识符]。

   [如适用，概述促使本通知发出的第 4(1) 条基础数据请求；或如该
   限制系依据第 3 条在订约前约定，概述涵盖的数据类别。]

2. 限制的第 4(2) 条依据

   数据持有者依赖《数据法案》第 4(2) 条，该条规定：

   > “用户和数据持有者可以合同方式限制或禁止访问、使用或进一步
   > 共享数据，前提是该等处理可能损害欧盟或国家法律规定的物联网
   > 产品安保要求，从而对自然人的健康、安全或安保造成严重不利
   > 影响。”

   两个操作性条件为：

   - (a) 该处理可能损害欧盟或国家法律规定的物联网产品安保要求。

   - (b) 该损害将对自然人的健康、安全或安保造成严重不利影响。

3. 安保要求的识别

   本限制所涉及的物联网产品安保要求规定于以下欧盟或国家法律
   文书：[列明文书，并引用具体条款。示例：法规 (EU) 2024/2847
   （《网络弹性法案》）附件一和附件三中该物联网产品的基本要求；
   指令 (EU) 2022/2555（NIS2）对 [涵盖类别] 的技术与组织措施；
   法规 (EU) 2019/2144（《一般安全法规》）对车辆的要求；法规
   (EU) 2017/745（《医疗器械法规》）对医疗器械的要求；特定的
   国家安全法律文书 [识别]]。

4. 严重不利影响的识别

   [具体事实论证，说明相关数据访问、使用或共享可能对自然人的
   健康、安全或安保造成严重不利影响。该论证应将第 3 节识别的
   安保要求与具体数据和具体场景相连接。]

   [行业主管机关依据第 4(2) 条第二句提供技术专业意见时：“数据
   持有者依据第 4(2) 条第二句咨询了 [行业主管机关]，该机关已于
   [日期] 就所请求访问的安全/安保影响提供技术专业意见。所依赖
   的专业意见摘要随附。”]

5. 限制的范围

   数据持有者与用户特此约定：

   [具体合同限制或禁止。示例：

   - 用户不得在 [运营阶段] 期间实时访问 [具体数据字段 / 类别]，
     因为该等访问将 [具体安全/安保机制]。
   - 用户仅可以 [匿名化 / 汇总 / 延迟] 形式访问 [具体数据字段 /
     类别]，因为直接实时披露将 [具体安全/安保机制]。
   - 用户不得将 [具体数据字段 / 类别] 进一步共享给第三方，
     因为该等共享将 [具体安全/安保机制]。]

   该限制不得超出解决已识别的严重不利影响所必需的范围。不受本
   限制涵盖的数据继续受数据持有者第 4(1) 条义务的约束。

6. 期限与复审

   本限制自 [生效日期] 起生效，持续至 [终止日期 或 “第 3 节识别的
   安保要求被修改或第 4 节识别的严重不利影响不再适用”]。数据持有
   者与用户同意 [定期、至少每 [数字] 个月一次 / 在物联网产品、
   相关服务或基础安保要求发生任何重大变化时] 复审本限制。

7. 救济

   在用户与数据持有者就本合同限制发生的任何争议中，用户在不
   影响其在成员国法院或裁判机构寻求救济的权利的前提下，可以：
   (a) 依据第 4(3) 条和第 37(5)(b) 条，向 [数据持有者设立地]
       成员国中依据《数据法案》第 37 条指定的主管机关提出投诉；
       或
   (b) 与数据持有者约定，按照第 10(1) 条将争议提交争议解决
       机构。

8. 主管机关通知

   数据持有者已在本通知发出之同时，依据第 4(2) 条第三句，将
   基于第 4(2) 条拒绝共享数据一事通知 [设立地成员国] 的主管机关。

[签署栏占位符，双方]
```

## 第二部分：主管机关通知函

```
[数据持有者信头占位符]

致：[设立地成员国中依据《数据法案》第 37 条指定的主管机关，
     全称及地址]
    [如该成员国已依据第 37(2) 条指定数据协调员，将通知致送
    数据协调员。]

日期：[日期]

编号：[内部编号]

主题：依据《欧盟法规 (EU) 2023/2854》（《数据法案》）第 4(2) 条
      拒绝共享数据的通知

1. 通知实体

   [数据持有者，完整法定实体名称、注册地址，如有依据第 37 条
   设立的联系点。]

2. 拒绝背景

   数据持有者已通过日期为 [日期] 的致 [用户] 通知，依据《数据
   法案》第 4(2) 条对数据的访问、使用或进一步共享施加合同限制。
   双边通知副本随附。

3. 安保要求与严重不利影响的识别

   该限制所涉及的物联网产品安保要求为：[列明文书及条款]。
   无限制的处理可能对自然人健康、安全或安保造成的严重不利
   影响为：[具体事实论证；与第一部分第 4 节相同]。

4. 限制的范围与期限

   [摘要；全文交叉援引双边通知。]

5. 用户信息

   限制对其生效的用户为 [姓名，如适当可含联系方式]。用户已获
   告知其依据第 4(3) 条和第 37(5)(b) 条的救济选项。

6. 行业主管机关专业意见（如适用）

   [数据持有者依据第 4(2) 条第二句咨询行业主管机关时：识别该
   行业主管机关并简要援引所依赖的专业意见。]

[签署栏占位符]

附件：
- 日期为 [日期] 的致用户双边通知副本
- 如适用：行业主管机关技术专业意见副本
```

- 第 37(5)(b) 条、第 37(7) 条：`sources/regulation-2023-2854.md` 第 37 条。
- 第 10 条（争议解决）：`sources/regulation-2023-2854.md` 第 10 条。
- 第一部分第 3 节引用的行业文书为示例性质；实际引用取决于物联网产品。映射关系见 `references/gates/sectoral-lex-specialis.md`。
