# 委员会《数据法》配套车辆数据指引——指针文件

**本文件不转载指引文本。** 它记录委员会部门性车辆数据指引的存在、状态和预期用途，并指向权威的委员会来源。本技能将部门特别法仅作为门禁处理：输出警告用户车辆数据情景涉及部门叠加，并引导其参阅委员会指引和车辆专业律师，而非试图在技能内进行完整的车辆特定分析。

## 本技能为何仅将其作为门禁

车辆数据是在横向《数据法》规则之上叠加的部门特别法领域。要做好它，需要了解：

- （EU）2018/858 号条例——机动车批准和市场监督（车辆型式认证框架）。为维修人员和独立运营者提供先于《数据法》存在的某些访问权。
- （EU）2019/2144 号条例——一般安全型式认证要求（事件数据记录器、驾驶员监测等）。
- 这些文书下的部门特定授权和实施细则。
- 可追溯至 2010 年代的扩展车辆数据（ExVe）和车载数据访问争论中的长期市场实践。
- 委员会在本指引中表达的观点，即《数据法》第 3、4、5 条如何适用于联网车辆，以及型式认证制度如何与之互动。

这是专业领域。不具备该部门知识、试图就联网车辆交付物发表意见的一般《数据法》技能会产生错误答案。本技能在此的角色是识别情景、予以门禁并转引。

## 本技能应如何使用本指引

- **识别门禁。** 如情景涉及联网车辆、联网车队、车辆远程信息处理、ExVe、车载访问，或与车辆关联的相关服务（如联网车辆应用、车辆售后市场服务），本技能应检测到这一点并路由至下述门禁行为。
- **门禁行为。** 输出应：
  1. 确认用户所要求的横向《数据法》分析，表述为“这是一般《数据法》立场；部门叠加可能改变分析”。
  2. 提示（EU）2018/858 号条例、（EU）2019/2144 号条例及任何实施细则可能施加与《数据法》回答互动的特定义务或授予特定权利。
  3. 指向上述 URL 的委员会《车辆数据指引》，作为委员会对互动的已发表观点。
  4. 建议用户就任何将触及交付物、合同或产品决定的事项咨询汽车行业专业律师，尤其是型式认证、安全召回和 ExVe 情景。
- **不转载。** 技能输出不应将本技能中的指引文本粘贴进交付物；权威版本是委员会页面上的版本。
- **常见问题解答 Q12 支持该门禁。** （本技能中的）常见问题解答 Q12 确认《数据法》适用于须经合格评定或型式认证的互联产品，但合格评定的具体需要由《数据法》之外的立法确定。本技能的车辆门禁与此一致：横向《数据法》规则适用，但部门型式认证规则管辖具体事项。
