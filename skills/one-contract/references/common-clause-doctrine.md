# 通用条款审查原则

> 用途：跨合同类型的通用条款（争议解决与管辖、付款节奏、变更、通知送达、完整协议等）的统一审查处理。
> 适用：所有合同类型的审查，不因合同类型而改变处理策略。
> 来源：2026-08-20 设备原材料采购盲测反馈，经元典核验民诉法（2023修正）第 24、35 条、民诉法解释第 30 条。

## 一、争议解决与管辖

### 审查目标

让管辖约定明确、有效、可执行，并使争议解决地点对我方**实质有利**——不只停留在"不无效"。

### 判断坐标

1. 原文约定的是诉讼还是仲裁（必须唯一）；
2. 原文是否**构成有效的协议管辖**——注意：「向**有管辖权的**人民法院起诉」等于**没有约定**，不是"约定不明"；
3. 约定的管辖地点是否属于民诉法第 35 条明列的可选地点（被告住所地、合同履行地、合同签订地、原告住所地、标的物所在地等**与争议有实际联系**的地点）；
4. **我方在该类交易中大概率是原告还是被告**——这决定哪个管辖地点对我方有利；
5. 我方立场与议价能力；
6. 是否违反级别管辖、**专属管辖**——专属管辖优先于协议管辖，**当事人约定无效**。
   落入专属管辖的三类（《民事诉讼法（2023修正）》第 34 条，经核验现行有效）：
   - 因**不动产**纠纷提起的诉讼 → **不动产所在地**法院；
   - 因**港口作业**中发生纠纷提起的诉讼 → **港口所在地**法院；
   - 因**继承遗产**纠纷提起的诉讼 → 被继承人死亡时住所地或主要遗产所在地法院。

   **常见落入点**（审查时须主动识别，不能只看标题）：房屋租赁、房屋买卖、建设工程施工、
   土地使用权、车位/商铺租赁等以不动产为标的的合同。

   ⚠️ **与本节默认倾向的关系**：本节第一档"不改变归属、只明确化"**不适用于专属管辖**。
   不动产类合同即使原文约定了"甲方所在地"且表述清楚，该约定**也无效**——此时不是
   "改不改归属"的问题，而是"必须回到不动产所在地"。识别到落入专属管辖的，
   **直接修订为不动产所在地法院并批注说明**。

### 默认倾向

**管辖是可以争取的条款，不是只能批注的结构性安排。** 分三档：

**① 原文无有效协议管辖**（典型：「向有管辖权的人民法院起诉」）
→ **落笔新增**对我方有利的管辖，并在批注中说明。此时不是"改动对方的权利"，而是**替客户争取一个本就不存在的条款**。

**② 原文有合法管辖但对我方不利**
→ **落笔改为对我方有利的管辖**，并在意见书首部「改变了权利归属的条款」中列明。理由见下。

**③ 原文有合法管辖且对我方无不利**（已是我方主场；或约定"原告住所地"而我方通常是原告）
→ **只做明确化，不改归属**——没有理由动它。

**方向判断（坐标 4 的用法）**：
- 我方通常**被诉**（收款方、供货方、出租方）→ 争取**我方所在地**
- 我方通常**主动起诉**（追债方、要求继续履行方）→ 争取**原告住所地**
- **机械改成"我方所在地"并不总是有利**：先判断诉讼位置，再定方向。

**为什么管辖可以落笔改**（这是它与违约金、责任封顶等商业取舍的分界）：
- 违约金定多少、责任封顶设在哪，是**双向**的商业判断，不存在"对所有人都更差"的默认值。替客户定，是替他下了一个他可能不同意的注 → 仍按批注、由客户决策。
- 异地应诉**对任何当事人都是负面的**，而当事人往往不知道这个成本有多大（时间、当地裁判倾向、执行便利度）。改管辖是**纠正信息不对称**，不是替客户做商业取舍。
- 且**改的下行风险等于不改的现状**：客户若不同意，拒绝这一条修订即回到原文，正是"只批注"的结果。故为**单边占优**。

**本档不外推**：不得以"客户不看批注"为由，把违约金、责任封顶、付款比例等商业取舍条款直接改成对我方有利——那些仍按"批注提示、由客户决策"处理。

### 动作建议

| 情形 | 动作 |
|---|---|
| 原文无有效协议管辖（"向有管辖权的法院起诉"） | **落笔新增**对我方有利的管辖，批注说明 |
| 原文有合法管辖但对我方不利 | **落笔改**为对我方有利的管辖，**意见书首部列明** |
| 原文有合法管辖且对我方无不利 | 只做明确化表述，不改变归属 |
| 管辖地点合法但表述有解释分歧（如"各自所在地"） | 直接修订为明确化表述（如"原告住所地"），不改变归属 |
| 管辖地点合法且表述清晰 | 不修改 |
| 约定与争议无实际联系的地点 | 批注提示无效风险，按法定管辖处理 |
| 诉讼与仲裁同时约定（或裁或审） | 直接修订为唯一方式，批注说明 |
| **原文约定仲裁，我方立场认为诉讼更有利（如小额订单仲裁不经济）** | **不默认把仲裁改为诉讼**——这里动的是**争议解决方式本身**（仲裁与诉讼在成本、保密性、审级、执行上各有取舍），客户选择仲裁通常有其考量，与"管辖地点"不是同一个问题。以批注提示成本与替代方案，由客户决策 |

### 硬边界

- **凡改变了管辖归属的，必须在意见书首部「改变了权利归属的条款」中显著列明**（原文约定 / 改为 / 理由 / 如不同意可改回）——**不得闷头改**；
- 不得违反级别管辖和专属管辖；
- 不得虚构"约定不明必然无效"的结论——民诉法解释第 30 条允许约定多个有实际联系地点的管辖，原告可择一起诉；
- **本档只适用于管辖。** 不得以本档规则为由，把违约金、责任封顶、付款比例等商业取舍条款单方改成对我方有利——那些仍按"批注提示、由客户决策"处理。
  **但要知道本档限制的是什么**：它限制的是"**以管辖档为由外推**"，不是"命中规则也不许落笔"。
  若某商业条款**命中了三层架构中的明确规则且方向明确**（例如"责任限制／赔偿／保险"联动组下的保险安排），
  按 `redline-comment-policy.md` **1.5** 直接修订 + 批注；需要填数时按 **1.6** 的三条线
  （天数与比例可填并注明可调整，**具体金额留 `【待填：金额】`**）。

## 二、付款节奏与对价平衡（立场相关）

### 审查目标

付款安排应与交付、验收、发票、质保联动，维持对价平衡，同时尊重当事人既有的付款结构选择。

### 判断坐标

1. 我方是收款方（供货方/服务方）还是付款方（采购方/委托方）；
2. 原文付款结构（一次性、分期、预付+尾款、货到付款等）；
3. 付款节点与交付/验收/发票/质保的先后关系；
4. 大额交易中资金压力与对价杠杆的平衡；
5. 双方议价能力与交易惯例。

### 默认倾向

- **付款方（采购方）立场**：默认将付款与交付、验收、发票、质保联动，避免一次性付清全款失去对价杠杆。可落笔为"预付款+验收后付尾款"的阶梯式付款，比例用 `【待填：】` 标记。**这是采购方立场专用倾向。**
- **收款方（供货方）立场**：**不主动把一次性付款改为阶梯式付款**——那会增加我方收款周期与资金压力。默认保留原文付款结构，重点保障付款期限明确、逾期付款责任清晰。若原文是阶梯式，才审查各节点是否合理。
- **原文已有付款结构**：尊重既有安排，只在明显失衡（如付款方先付全款且无任何交付/验收保障）时提示并落笔调整。
- 付款条款的修改方向**由我方身份决定**，不得机械套用"阶梯式更好"。

### 动作建议

| 我方身份 | 付款失衡情形 | 动作 |
|---|---|---|
| 采购方 | 先付全款、无交付/验收保障 | 直接修订为预付款+验收后付尾款（比例待填） |
| 采购方 | 付款与验收/发票脱节 | 直接修订建立联动 |
| 供货方 | 付款期限不明或过长 | 直接修订明确期限，保障收款 |
| 供货方 | 原文一次性付款 | 不改为阶梯式，保留原文 |
| 任一方 | 付款结构调整涉及重大商务决策 | 批注提示，由客户决策 |

### 硬边界

- 不虚构付款比例、期限、账户等事实，未知用 `【待填：】`；
- 不因我方是收款方就把阶梯式付款强加给付款方（立场错误）；
- 不越过当事人既有付款结构做无必要的重构。

## 三、通用条款分章速查

按合同条款的七个通用模块分章。前两章（争议解决、付款节奏）已单列深挖，此处不重复；本章覆盖其余模块，每章以「审查目标 → 判断坐标 → 默认倾向 → 硬边界」的紧凑形式列出。

**与第一层其他文档的分工**：本章给的是**跨类型的通用判断**；`review-doctrine.md` 给审查方法与验收标准；`redline-comment-policy.md` 给落笔方式。具体类型的深化见 `assets/knowledge_v2/` 中的原则卡与条款模块——**专项的场景化深化优先于本章的通用默认，但不得突破本章的法律边界**。

### 3.1 主体条款

**审查目标**：确认签约方是真实、适格、能承担责任的唯一主体，避免合同因主体问题不成立、无效或无法执行。

**判断坐标**
- 签约方是自然人、法人还是非法人组织；
- 签署人本人签署、法定代表人签署，还是代理人签署；
- 交易是否属需行政许可/经营资质的特殊行业；
- 相对方是否处于吊销、清算等非正常存续状态。

**默认倾向**
- **主体审查按「真实性 → 资质 → 履约能力」三步闭环**，不跳步；
- 主体信息以达到**唯一性**为准，不以"能联系上"为准；
- 履约能力通过公开渠道（涉诉、失信、行政处罚、注册资本、股东情况）收集后**提示委托人参考**，不代为作商业判断。

**硬边界**
- 合同未载明主体的，提示补正；主体不明时合同不成立；
- **不得以业务部、办事处、项目部作为合同主体**——此类机构不是独立签约主体；以其名义签约的，提示主体不适格；
- 以第三方名义签署的，须核实授权委托书是否合法有效、授权范围是否覆盖本合同；无授权或超授权即提示无权/越权代理风险；
- 被吊销营业执照或处于清算状态的法人**不得再签经营性合同**；
- 机关法人（经国务院批准为使用外国政府或国际经济组织贷款转贷的除外）、以公益为目的的非营利法人及非法人组织**不得为保证人**（《民法典》第683条，经核验现行有效）；
- 特殊行业（金融、医疗、教育、运输、危险品、特种设备等）无相应行政许可或经营资质的，提示影响合同成立或效力。

**必填信息的最低标准**
- 自然人：姓名、住所地、身份证号**三要素**齐备方可唯一识别；
- 法人及非法人组织：单位名称、住所地、法定代表人（负责人）、统一社会信用代码**四要素**；
- 名称须与证照全称**逐字一致**，禁用简称、笔名、别名；近似名称（一字之差的主体）须核实全称后再落笔。

### 3.2 标的条款

**审查目标**：把「交易什么」锁死到唯一、可交付、可验收的程度；标的不明则合同不成立，标的不特定则履行必生争议。

**判断坐标**
- 标的是物、行为还是权利（三者特定化的方法完全不同）；
- 是否属禁止流通物或限制流通物；
- 我方或对方对标的是否有合法处分权；
- 是买卖合同还是服务合同（服务类的特定性最易缺失）。

**默认倾向**
- **标的特定性是本模块的审查重点**，高于其他形式问题；
- 物：以规格、型号、颜色、成分、产地、等级等**多指标交叉锁定**，必要时配图或封存样品；
- 行为：详尽列明服务内容、方式与标准，不写「提供相关服务」式表述；
- 权利：明确权利载体、对应权利人、权利证书（如有）及所处状态。

**硬边界**
- 合同未写明标的的，提示补正；无标的不成立。标的与当事人名称、数量同属认定合同成立的基本要素，三者须齐备；
- 以**禁止流通物**为标的的合同无效，应拒签，且不得通过约定规避其禁止流通属性；
- **限制流通物**仅在特定主体与范围内有效；主体或范围不适格的，提示效力瑕疵；
- 行为标的不违反法律、行政法规，也不违背公序良俗；
- **无权处分**的合同效力待定；不以「事后能补正」为由默认其有效。

### 3.3 质量条款

**审查目标**：让「什么叫合格」在签约时就确定下来，避免落入「约定不明 → 法定兜底 → 裁量黑洞」的连锁。

**判断坐标**
- 标的是物品、服务还是权利（三类各有其质量维度）；
- 是否存在强制性国家标准或行业标准；
- 引用的是现行标准还是已作废/被修改的标准；
- 检验期与质量保证期是否分得清。

**默认倾向**
- **质量约定不明的后果比多数人预想的严重**：兜底次序本身难确定，诉讼举证困难、裁判难裁断——故须从「明确性、合理性、可操作性」三维度细审；
- 质量条款必须**质量标准与检验两部分俱全**，不可偏废；
- 引用标准写全**标准名称与标准代号**，并确认为**现行有效版本**。

**硬边界**
- 物品类有**强制性国家标准**的必须适用，**不得以约定排除**；
- 约定的检验期过短、依标的物性质和交易习惯难以完成全面检验的，**该期限仅视为外观瑕疵异议期**；隐蔽瑕疵仍适用合理期限；
- 约定的检验期或质量保证期**短于法律、行政法规规定期限的，以法定为准**（《民法典》第622条，经核验现行有效）；
- 未约定检验期时，买受人应在发现或应当发现的**合理期限**内通知；自收货起**二年**内未通知的视为符合约定；**有质量保证期的适用质保期，不适用该二年**（《民法典》第621条，经核验现行有效）；
- 出卖人知道或应当知道标的物不符合约定的，买受人**不受前述通知期限限制**；
- 质量不符的**救济依据须齐备**：拒收/解除的情形与违约责任的情形都要覆盖，并与违约条款衔接，不留单向救济。

**标准体系的识别（写法与时效）**

引用标准是质量条款最常出问题的地方，问题不在"有没有引用"，在**引对没引对、失效没失效**。

- **效力层级**（《标准化法（2017修订）》第 2 条，经核验现行有效）：标准分国家标准、行业标准、地方标准、团体标准、企业标准。**国家标准**分强制性与推荐性；**行业标准、地方标准是推荐性标准**；**强制性标准必须执行**。
  - ⚠️ **口径提示**：《标准化法实施条例（2026修订）》第 18 条仍保留"国家标准、行业标准分为强制性和推荐性"的表述，与上位法《标准化法》第 2 条存在张力。**引用时以上位法为准**——即只有**强制性国家标准**是必须执行的；声称"强制性行业标准"时须先核验该标准本身是否被法律、行政法规或国务院决定赋予强制力，**不得仅凭标准代号（如 AQ/DL/JG）推断其强制性**。
- **下限规则**（《标准化法》第 21 条，经核验现行有效）：推荐性标准的技术要求**不得低于**强制性国家标准。
- **引用写法**：写全**标准名称 + 标准代号 + 年份号**；只写"符合国家标准"等于没写。
- **时效核验**：**引用的标准须确认为现行有效版本**。标准换版频繁（尤其 GB/T、JGJ 系列），约定已废止版本会导致"约定不明 → 回到法定兜底"，反而更不利。
- **约定严于标准是允许的**：当事人可约定高于强制性标准的要求，该约定有效；但**不得约定低于强制性标准**。

**"通常标准"与"特定标准"**：合同未约定质量标准时，依次按强制性国家标准 → 推荐性国标 → 行业标准 → 通常标准或符合合同目的的特定标准确定。故**约定了质量标准**才是把裁量权收回自己手里；**约定不明**则交给这条链去兜底——这是质量条款必须写死的根本理由。

### 3.4 权利义务条款

**审查目标**：把交易目的转成可履行、可追责的义务分配，并把「己方能不能做到」提前想清楚。

**判断坐标**
- 己方在交易中的核心目的是什么，哪些是核心、哪些可以交换；
- 每项义务的**内容、履行时间、程序、方式**是否落实；
- 义务落在哪一方，己方承担的义务是否超出自身履约能力；
- 对方义务是否足以支撑己方的合同目的。

**默认倾向**
- **对己方：权利与义务同等关注，且对己方义务尤为注意**——义务过重会直接导致履约障碍，进而触发己方违约；
- **对相对方：重点看其义务**（决定己方目的能否实现，也是己方权利之源）；相对方的**权利**即使未约定，也不必替其补充——这是立场使然，不是遗漏；
- 区分「不可让步项」与「可让步项」：非核心目的所需的条件可作谈判筹码。

**硬边界**
- 权利义务条款须合法；**法定义务不得被约定排除**——以约定免除法定强制义务的，该约定不生效力；
- 格式条款不得具有无效情形（不合理免除或减轻提供方责任、加重对方责任、限制或排除对方主要权利）；
- 己方义务的表述不得作出超出实际履约能力的承诺。

#### 3.4.1 组织／协调角色与第三方专业服务的责任隔离

**触发条件**（三者同时成立时适用）：

1. 我方承担**组织、协调、促成、转介、对接**一类的中介性义务；
2. 实际的专业服务由**具备资质的第三方**实施（医疗机构、检测检验、监理、评估、教育培训、
   金融代销、危险品运输等）；
3. 该服务需**法定资质**，或其实施后果可能落在客户／消费者的人身、财产或数据权益上。

**风险（失败模式）**

- **角色被实质化**：合同写"甲方组织、协调"，但对外以我方名义呈现、由我方定价收费、
  由我方安排人员与流程——一旦被认定"名为组织、实为提供"，就要承担提供方的责任；
- **客户／消费者的第一顺位主张**：患者或客户通常不知道、也不关心谁是签约主体，
  品牌方与组织方最容易被一并主张；
- **选任与监督连带**：服务方由我方选任时，选任过失与监督不到位同样可能被主张。

**默认倾向：三段式表述（直接落笔）**

1. **角色限定**——我方"以协调、组织并促成与已确认服务方的服务衔接为限"；
2. **身份否定**——不因该等协调、组织行为"被视为该服务的提供方或实施主体"；
3. **责任归属**——因该服务方的专业行为引发的责任，"由该服务方**依法**承担"。

**硬边界（缺一不可）**

| # | 边界 | 依据 |
|---|---|---|
| 1 | **不得写成免责条款**：不能表述为"我方不承担任何责任"——造成对方人身损害、因故意或重大过失造成对方财产损失的免责约定无效 | 《民法典》第506条，经核验现行有效 |
| 2 | **不得对抗第三人**：合同**仅对当事人**具有法律约束力。本表述是**内部角色说明与责任分担**，不能对抗患者／客户的法定请求权——故写"**依法**承担"，不写"第三方承担即免我方" | 《民法典》第465条，经核验现行有效 |
| 3 | **不得掩盖实质**：我方实际控制人员、定价、流程与风险时，本表述可能被穿透（按实际法律关系认定）——此情形**只批注、不落笔**，落笔反而给客户错误的安全感 | 实务判断 |
| 4 | **与资质条款口径一致**：谁确认服务方资质（如"双方书面确认"）、谁承担选任责任，须与资质条款一致 | 实务判断 |
| 5 | 医疗场景可另援引：患者在诊疗活动中受到损害，医疗机构或其医务人员有过错的，**由医疗机构承担赔偿责任** | 《民法典》第1218条，经核验现行有效 |

**配套联动（缺一处，三段式就没有依托）**

- **实施主体条款**：合同须另有一处写明"该专业服务由具备资质的服务方实施"；
- **宣传与名义条款**：对外用谁的名义、谁做宣传，直接影响"提供方"的认定；
- **收费与开票路径**：由谁收费、由谁开票是判断"谁是提供方"的**事实依据**；
  若由我方代收转付，须写明代理关系与费用性质；
- **责任事件的通知与协助**：约定服务方责任事件发生后我方的通知、协助、配合义务——
  否则"切割"读起来像推责，反而在争议中被用来证明我方在主导。

**动作建议**

| 情形 | 动作 |
|---|---|
| 我方仅为组织／协调，**实际实施与专业判断在第三方** | **直接修订 + 批注**（落笔三段式，批注说明不得对抗第三人） |
| 我方虽写"协调"，但**人员、定价、流程、风险均由我方控制** | **仅批注**：提示实质认定风险 |
| 合同未约定专业服务的实施主体 | **先补实施主体条款（补增），再落三段式**；顺序颠倒会写出无依托的切割句 |

**可接受变体**：服务方由双方指定时，写"由双方确认的 XX 机构实施，我方仅承担组织与衔接义务"；
服务方由客户自选时，写"由客户自行选定并直接与其建立服务关系，我方不参与选任"——
**是"不参与选任"而不是"不承担责任"**；涉及多类第三方（检测＋医疗＋物流）时按类分写，
不合并成一句"其他专业服务方"。

### 3.5 违约条款

**审查目标**：让每一项义务都有对应的责任，且责任额度经得起调整审查——违约条款的失败模式不是「不够狠」，而是「不配套」和「不可执行」。

**判断坐标**
- 相对方的每项义务是否都有对应的违约责任；
- 违约金的计算基数是否确定、可算；
- 定金与违约金是否同时约定；
- 继续履行的请求是否落在法律允许的范围内。

**默认倾向**
- **先梳理相对方义务的内容、履行时间、程序、方式，再逐一核对是否设置了违约责任**——缺则补增。「有义务就应有责任」是本模块的第一原则，无责任则义务缺乏约束力；
- 违约金以**补偿为主、惩罚为辅**：明确且可预期，不宜畸高畸低；约定惩罚性违约金的须注明性质；
- 继续履行：金钱债务一律可请求支付；非金钱债务原则上可请求履行。

**硬边界**
- 非金钱债务**三项除外**：法律上或事实上不能履行；标的不适于强制履行或履行费用过高；债权人在合理期限内未请求履行（《民法典》第580条，经核验现行有效）。有除外情形致合同目的不能实现的，可请求终止合同关系，**但不影响违约责任承担**；
- 赔偿范围含合同履行后**可得利益**，但不得超过违约方订立合同时**预见或应当预见**的损失（可预见规则，见 `review-doctrine.md` 的责任限制讨论）；
- **违约金过高或过低可请求调整**：以实际损失为基础，兼顾履行情况、过错程度、预期利益，按公平与诚信原则衡量；**一般以超过损失 30% 为「过分高于」的参考线**——它是可调整的信号，不是无效的界限；
- **定金合同自实际交付时成立**：只约定未交付的，定金合同未成立，不能主张定金责任；
- **定金数额不得超过主合同标的额的 20%**，超过部分不产生定金效力（《民法典》第586条，经核验现行有效）；
- **定金与违约金不得并用**；但违约金或定金不足以弥补损失时，可与赔偿损失并用。

#### 3.5.1 责任限制（赔偿上限）：先判方向，再定基数与倍数

责任限制属联动组「责任限制、违约金、赔偿与保险」的核心，**可落笔**——但先判方向。

**第一步：方向**（这一步决定落笔还是提示）

| 我方位置 | 动作 |
|---|---|
| **我方是可能被索赔的一方**（提供方、保管方、承运方、施工方） | **落笔设上限**，保护自己 |
| **我方是索赔方**（受损方、被欠款方、被侵权方） | **不替对方设限**；识别对方的封顶陷阱（见 3.7 三类陷阱），**提示上限是否过低、是否与风险敞口相称** |

**第二步：基数与倍数（我方为被索赔方时，直接落笔）**

- **基数**：以**引发责任的那一单（订单／项目）的合同金额或服务费**为基数——
  不写"全部合同金额"（把无关订单也拉进上限里，对索赔方不合理，容易被认定为不公平），
  也不写"已付费用"（我方交付后已付费用通常远低于合同额，白白压低自己的回收）；
- **倍数**：默认 **1×**，批注注明可调整（1.6：比例类可填）；
- **间接损失**：明确排除可得利益等间接损失——这是上限之外的第二道闸，须单独写；
- **例外情形（必写，法定）**：**造成对方人身损害、因故意或重大过失造成对方财产损失的，
  责任限制不适用**（《民法典》第506条，经核验现行有效）。

**硬边界**

- 不得写成"不承担任何责任"（免责条款，506 条项下无效）；
- 不得排除依法不得排除的责任；上限过低在不平等谈判地位下可能被认定为不合理免责；
- **额度是商业取舍（1.4），基数口径、例外情形与间接损失条款有专业默认，可直接落笔**——
  两者不要混为一谈："额度归客户、口径归审查人"。

#### 3.5.2 保险安排：只加对方义务，且必须可验证

**站位原则（本规则的核心）**

> **保险义务按"谁控制风险、谁承担义务"分配；站在我方立场起草时，只写明"要求相对方投保"的险种，不为我方创设投保义务。**

理由：我方为**采购方／委托方／服务提供方**时，风险敞口（设备是我的、交付责任是我的、
被索赔的第一顺位是我）落在**我方**；让**实际控制标的与作业的一方**投保，风险才真正转出去。
写成"双方各自投保"，等于给自己加了一项持续花钱的义务，而对方那份保单通常覆盖不了
对方作业给我方造成的损失。

**五要素写法（缺一即空转）**

| 要素 | 要求 |
|---|---|
| **险种** | 与标的与风险匹配，**按标的分别写明**：设备财产险、第三者责任险、雇主责任险、货物运输险、职业责任险等——不写"相关保险" |
| **保额口径** | 财产险不低于标的**实际价值／重置价值／货值**；责任险按**单次事故限额**表述。**不写具体金额**（1.6），用比例或"不低于标的实际价值"承载 |
| **被保险人与受益人** | 明确被保险人（投保方）；**我方应列为共同被保险人或受益人**（否则赔款到不了我方） |
| **保险期间** | **覆盖标的处于对方控制／使用期间**（交付起至返还止），并写明**续保义务** |
| **证据与后果** | 投保凭证的**提交时限**（如交付前）与**维持义务**；未投保或断保的后果（暂停交付／暂停服务、赔偿前置、构成违约）；事故后的**理赔协作**义务；**保险赔付不免除责任**（不足部分仍由责任方承担） |

**硬边界**

- 不得约定"投保后免除一切责任"；不得以保险替代法定的安全、资质与检验义务；
- 保额数字属商业安排（1.6：写比例，不写金额）；投保义务方一经确定，与该方控制的风险要对应得上
  （要求无控制权的一方投保，条款往往落空）。

### 3.6 程序条款

**审查目标**：让合同「立得住、改得动、停得下、送得到」——生效、变更、通知、终止、免责五类机制形成闭环。

#### 3.6.1 通知与送达

- 明确双方送达地址、联系人、方式（书面/电子）与生效时间；
- 变更联系方式应在约定期限内书面通知，否则承担不利后果；
- 约定"以快递发出后第 X 日或邮件发出后 X 小时视为送达"式兜底。

#### 3.6.2 合同变更

- 变更须书面（补充协议/变更单），口头变更无效（民法典 543-544）；
- 明确有权提出和确认变更的人员/岗位；
- 重要微信/邮件最终回填补充协议或变更单，防止默许形成不利履行证据；
- 主合同、订单、技术附件、变更文件标注版本关系。

#### 3.6.3 完整协议

- 约定"本合同（含附件）构成双方就本交易的完整协议，取代先前口头或书面沟通"；
- 防止对方以"之前谈好的条件"主张权利。

#### 3.6.4 合同终止与清算

- 约定终止情形（履行完毕、协商解除、违约解除、不可抗力解除）；
- 明确终止后清算：未履行部分、已付款项退还、库存/资料处理。

#### 3.6.5 免责与不可抗力

- 不可抗力：列举+兜底定义，明确通知时限与证明要求，区分不可抗力（民法典 590）与情势变更（533）；
- 责任限制：明确是否含间接损失、赔偿上限，避免"赔偿一切损失"式笼统表述。

**不可抗力的三条硬边界**
- **范围限于「订立时不能预见、不能避免且不能克服」的客观情况**——订立时已能预见的灾害不属之；
- **迟延履行后才发生不可抗力的，不免除违约责任**（《民法典》第590条第2款，经核验现行有效）；
- 受影响方负有**及时通知、减轻损失、合理期限内提供证明**三项义务；只写"不可抗力免责"而不写这三项义务的，机制不完整。

**不得把商业风险写进不可抗力**：客户取消、客流不足、经营困难、设备丢失等，属当事人可预见或可控制的经营风险，不因写入"不可抗力"定义而改变性质。

#### 3.6.6 生效条款与附条件

- 生效方式（签字/盖章/两者兼备）须与签署栏设置**一致**；「签字**或**盖章」与「签字**并**盖章」一字之差，效力后果不同；
- 附**生效条件**的，条件须为**将来发生、可能发生、发生与否不可预见、合法、且属当事人可约定范畴**的事实；不符即改；
- 附生效条件的合同自条件成就时生效（《民法典》第158条，经核验现行有效）；根据行为性质不得附条件的除外。

#### 3.6.7 行为能力与代理

- 相对方为**限制民事行为能力人**的：纯获利益或与其年龄、智力、精神健康状况相适应的行为有效；其他行为经法定代理人同意或追认后有效；相对人可**催告 30 日内追认**，未作表示视为拒绝；追认前善意相对人有撤销权；
- 相对方以**第三方名义**签署的：应提示更换合同主体、核实有无合法授权，或在 **30 日内催告追认**；
- 无权代理在未获追认前对被代理人不发生效力，由行为人承担责任。

#### 3.6.8 鉴于与背景陈述

"鉴于"（前言、背景陈述）不是装饰，它是**合同目的的载体**——目的决定合同解释方向，也决定"合同目的不能实现"能否成立（进而决定法定解除权）。

- **要写明交易目的**：双方为何做这笔交易、期望达成什么。缺目的的合同，在"是否构成根本违约""能否解除"上会失据。
- **要提纲挈领**：鉴于条款概括交易背景与结构，不与正文重复、不塞入实质权利义务。
- **要与正文一致**：鉴于里的陈述若与正文冲突，须消除矛盾；**不得把未落实的商业承诺写进鉴于**（它同样可能被作为合同内容主张）。
- **反向用法**：在争议中，鉴于条款是解释"当事人真实意思"的重要依据。**己方不利的事实不要主动写入**。

#### 3.6.9 附件与文件组成

- **明确文件组成与优先顺序**：主合同、附件、订单、技术规范、变更文件的效力顺位须写明（推荐：补充协议 ＞ 正文 ＞ 专项附件 ＞ 执行性文件）。
- **附件须与正文引用一一对应**：正文提到的每一个附件都要真实存在、名称与正文一致、编号不重不漏。
- **术语统一**：同一事物在正文与附件中**用同一个词**（"交接明细"与"交付明细"混用会产生解释争议）。
- **关键附件不可缺**：租赁类的交接清单与返还标准、服务类的成果与验收标准、买卖类的技术规格与样品——缺附件的条款等于没有标准。
- **附件标注版本号**，防止多版本并存。

#### 3.6.10 签署与用印

- **签署栏与生效条款必须一致**：约定"签字**或**盖章"而签署栏只留盖章位的，或反之，都会在成立时点上产生争议。
- **用印类型**：公章、合同专用章、法定代表人签字、授权代表签字——**谁签、盖什么章、是否需授权文件**须与主体条款（3.1）对齐。
- **签署日期填写实际日期**，不留空、不倒签（倒签见 3.7 三类陷阱）。
- **骑缝与页码**：多页合同应有页码与骑缝章安排，防止换页争议。
- **份数与持有一致**：约定"一式 X 份，各方各持 Y 份"，与实际签署份数相符。

#### 3.6.11 保密条款（指向通用条款库）

通用商事保密条款已有现成文本，**不必重写**：见 `templates/clause-library.md` 1.2「保密条款」
（保密信息定义含技术/商业/财务/客户信息、四项例外、终止后延续期限、法律要求披露的通知与协助）。

审查时只需核对三处：
- **范围是否覆盖本合同实际交换的信息**——尤其**非签约方**的信息（如目标公司信息、第三方合同细节）是否被定义涵盖；
- **期限**是否与本类信息的寿命匹配（商业秘密可长，普通商业信息不必永久）；
- **保密义务是否与竞业限制混同**——保密**不以支付保密费为前提**；限制**竞业**则须依法支付补偿，二者不得写成一回事。

### 3.7 商务条款

**审查目标**：商务条款是「提高班」的分水岭——法律上有效不等于商务上合规，也不等于对己方安全。

**判断坐标**
- 我方是收款方还是付款方、是采购方还是供货方；
- 相对方是机关、事业单位、大型企业还是中小企业；
- 合同文本由谁提供；
- 是否触及相对方的内部管理规定（母公司授权、集团采购制度等）。

**默认倾向**
- **商务条款的合规性要求高于合法性**：不仅要符合法律，还须符合规章、政策、规范性文件乃至相对方内部管理规定；「法不禁止即自由」有边界，不得违反禁止性规定；
- **相对方提供的文本尤须谨慎**，重点识别三类陷阱：责任封顶、客观上无法完成的期限、倒签日期。

**硬边界**
- **委托合同的任意解除权是法定的**：约定"不得单方解除"不受法律保护，属无效约定（《民法典》第933条，经核验现行有效）。解除造成对方损失的，无偿委托赔直接损失、有偿委托赔直接损失与可得利益；
- **租赁期限不得超过 20 年**，超过部分无效；续订的租期自续订之日起亦不得超过 20 年（《民法典》第705条，经核验现行有效）；
- **机关、事业单位**从中小企业采购货物、工程、服务，自交付之日起 **30 日**内付款；合同另有约定的从其约定，但**最长不得超过 60 日**。**大型企业**自交付之日起 **60 日**内付款，且**不得约定以收到第三方付款作为向中小企业付款的条件、或按第三方付款进度比例支付**（即「背靠背」条款，最高人民法院已明确此类条款无效）——《保障中小企业款项支付条例》（2025.6.1 施行）；
- 迟延支付应支付逾期利息，约定利率不得低于合同订立时 1 年期贷款市场报价利率；
- **企业内部管理规定构成合规边界**：如母公司规定子公司采购超一定金额须报批，子公司签约前须核实并提示——否则经办负责人受罚，顾问律师亦不利。

**相对方文本的三类陷阱**
| 陷阱 | 识别特征 | 处置 |
|---|---|---|
| 责任封顶 | "仅赔直接损失"＋"总额不超过已付费用 100%"式组合 | 提示上限过低，评估是否与风险敞口相称 |
| 客观不能 | 交货期/工期短于合理生产或实施周期 | 提示签字即违约，要求调整 |
| 倒签日期 | 签署日早于实际签署日 | 提示签字即构成违约，或影响期间起算 |

**政府与公共主体的承诺类条款（投资、招商、合作开发中最常见）**

相对方是政府、开发区管委会、事业单位、平台公司时，合同里的"承诺"要分两类看，**处理方式完全不同**：

| 类型 | 例 | 审查动作 |
|---|---|---|
| **政府法定职权范围内可以做、且依法定程序作出的** | 依法定权限与程序给予的财政奖补、土地出让安排、基础设施配套 | 落到**附件**（政策依据、批复文号、兑付条件、时限），不写"给予最大优惠"式空话 |
| **政府无权自行承诺的** | 税收减免、"先征后返"、突破法定权限的优惠 | **不得作为可执行承诺写入合同**，见下 |

- **税收减免的权限红线**（《税收征收管理法》第 3 条，经核验现行有效）：税收的开征、停征以及减税、免税、退税、补税，**依照法律的规定执行**；法律授权国务院规定的，依照行政法规执行。**任何机关、单位和个人不得违反法律、行政法规的规定，擅自作出**减免税等**同税收法律、行政法规相抵触的决定**。
  - 因此：政府或管委会在合同中承诺"免征企业所得税""税收返还""财政扶持按纳税额比例兑付"的，**该承诺不因此产生可强制执行的税收效果**，且作出承诺的一方可能构成违法。**应提示不得作为可执行承诺，并改按依法定程序的财政奖补路径处理**（附依据、走预算与审批程序）。
  - 反向提醒：**不要把"政策变化"一概写成不可抗力**（见 3.6.5）——政府依新政策调整原承诺，属可预见的政策风险，通常应由**明确的责任分担与退出机制**承接，而非免责。
- **"政策依据附件化"**：凡依赖政策给予的优惠，须把**政策名称、文号、有效期、兑付主体与程序**作为附件固定；不附件的政策承诺，在争议中难以证成。
- **政策变化的处理**：约定政策调整或取消时的**通知、协商、补偿或退出**路径，不写单方免责句。
- **行政协议 vs 民事合同**：以政府为一方、内容涉及行政法上权利义务的（如特许经营、土地出让、招商引资中的行政管理内容），**可能被认定为行政协议**——**不可仲裁**，争议解决路径与民事合同不同。合同定性存疑时须先判断，再定争议解决条款。

前面 3.1–3.7 按**条款机制**组织，回答「这一类条款有哪些要素」。
本节的切法不同：按**「每种情形下风险落在谁身上、对价归谁」**组织，回答「这个机制启动时谁得利、谁受损、谁有能力翻转局面」。
两种切法不是粗细之分，是切面不同——尤其在**立场翻转**时，本节的结论会整批反转，而前七节的判断坐标不会。

| 章 | 风险净流向 | 由此得到的审查次序 |
|---|---|---|
| 3.1 主体 | **全部流向验证不足的一方**，且事后救济最弱（主体不存在＝没有适格被告） | 主体是唯一「必须签约前做完、事后无法补救」的模块，不跳步、不合并 |
| 3.2 标的 | **单向流向付款方** | 己方为付款方时，标的特定性排本模块第一；为收款方时改查「己方能否交付该特定物」 |
| 3.3 质量 | **法律单向向买受人回补**（621／622 均往买受人方向纠偏） | 买受人的重点不是「要更长检验期」而是**「把质量标准写死」**——标准写不死，回补失去比较基准；出卖人的重点是让检验期清晰及时 |
| 3.4 权利义务 | 己方风险来自**己方义务**，己方收益来自**相对方义务** | 对双方都看义务、不给相对方补权利——这是利益流向决定的正确做法，不是遗漏 |
| 3.5 违约 | **双向陷阱**：既会「定了拿不到」（畸高被调、并用被择一、定金未交付），也会「没定啥都没有」 | 审查目标不是把违约金调高，而是**让每项义务配一份确定能拿到的责任**。可预期 > 额度高 |
| 3.6 程序 | **几乎全部落在援引该机制的那一方**（想送达的、想变更的、想免责的、想主张生效的） | 不按机制清单核对，**先问「己方将来要靠哪一条」，再把那条写全**。完整不是目的，可用才是 |
| 3.7 商务 | 由**双方市场地位**决定，不由条款文字决定 | 市场地位是判断该条款可否接受的**前提**，不是背景信息 |

**用法**：先按 3.1–3.7 逐模块过一遍找缺项，再用本节做一次**立场翻转检查**——
把「己方」与「相对方」对调重读上表，凡是翻转后结论变化的条目，就是本次谈判真正要让步或要争的地方。

## 四、合同形式与要式

**为什么单列一章**：多个类型各自的书面形式要求（融资租赁、借款、广告）此前在本库无处安放——
它们是**同一类审查动作**，只是触发条件不同。归到通用层，避免每个类型卡重写一遍。

### 一般规则

《民法典》第 135 条（经核验现行有效）：民事法律行为**可以采用书面形式、口头形式或者其他形式**；
**法律、行政法规规定或者当事人约定采用特定形式的，应当采用特定形式**。

**先问一句：这个类型是不是要式合同？** 是要式的，才进入下面的检查。

### 已知的法定书面形式要求（按需扩充）

| 类型 | 依据 | 要点 |
|---|---|---|
| **融资租赁合同** | 《民法典》第 736 条第 2 款 | **应当采用书面形式** |
| **借款合同** | 《民法典》第 668 条第 1 款 | **应当采用书面形式**；**自然人之间借款另有约定的除外** |
| **广告活动合同** | 《广告法》第 30 条 | 广告主、广告经营者、广告发布者之间**应当依法订立书面合同** |

> 上表不封闭。遇其他类型时先检索该类型是否有法定形式要求，**不凭印象认定"没有要求"**。

### 审查动作

1. **识别**：本类型是否属要式合同；
2. **核查**：是否已采用书面形式；**口头合作不得作为审查对象**，须先书面化；
3. **补正路径**：未采用书面形式的，**后果不必然是无效**——《民法典》第 490 条第 2 款（经核验现行有效）：
   法律、行政法规规定或者当事人约定应当采用书面形式订立，**当事人未采用书面形式但是一方已经履行主要义务，对方接受时，该合同成立**。
   故正确动作是**补书面化 + 固定已履行事实的证据**，而不是直接告知"合同不成立/无效"。
4. **留痕**：微信、邮件等非正式往来已达成的合意，回填为书面合同或补充协议（呼应 3.6.2）。

### 硬边界

- 是要式合同而未采用书面形式的，**提示补书面化并固定履行证据**，不得径行认定合同不成立；
- **不得以"口头已谈妥"为由跳过书面化**——要式要求的作用正是在争议时提供确定的事实基础；
- 自然人之间借款的书面要求**可以另有约定**，不得一概要求书面。

## 五、合同效力的通用排查

**这是本库此前缺失的一个入口**：整体无效情形零散分布在各类型卡里，没有一个"先过一遍效力"的通用清单。
本节补上。**顺序上应当先于条款审查**——无效的合同，逐条改措辞没有意义。

### 五类无效情形（通用排查清单）

| # | 情形 | 依据 | 审查动作 |
|---|---|---|---|
| 1 | **无民事行为能力人**实施的民事法律行为 | 《民法典》第 144 条 | 核查签约方行为能力（与 3.6.7 衔接） |
| 2 | **虚假意思表示**实施的民事法律行为 | 《民法典》第 146 条第 1 款 | 核查交易是否真实发生；**名为甲实为乙**的，按被隐藏的行为定性（第 146 条第 2 款） |
| 3 | 违反法律、行政法规的**强制性规定** | 《民法典》第 153 条第 1 款 | 判断该强制性规定是否**导致行为无效**（效力性 vs 管理性之分） |
| 4 | 违背**公序良俗** | 《民法典》第 153 条第 2 款 | 内容是否触及公共秩序与善良风俗 |
| 5 | **恶意串通**，损害他人合法权益 | 《民法典》第 154 条 | 核查双方是否合谋损害第三方（债权人、股东、其他权利人） |

（以上五条均经元典核验，现行有效。）

### 审查动作

1. **先过一遍这张表**，再进入逐条条款审查；
2. 命中 1／2／5 的，**告知委托人效力问题本身**，不必在措辞上打转（呼应 `review-doctrine.md` 九：整体无效的直接告知，无须修改文本）；
3. 命中 3 的，**区分效力性强制规定与管理性强制规定**——
   - 效力性：违反即无效 → 阻断；
   - 管理性：违反通常不导致无效，但**可能招致行政责任** → 提示（呼应 3.7"合规性高于合法性"）；
   - **不得虚构"约定不明必然无效"或"违法必然无效"的结论**——第 153 条第 1 款自带"该强制性规定不导致该民事法律行为无效的除外"。
4. 命中 4 的，公序良俗是**兜底条款**，适用须审慎，不得作为"我看不惯就否定"的工具。

### 与"待填/材料缺失"的关系

**效力判断需要事实**。事实缺失时**只记录证据状态、提示补材料**，
**不得把"材料未提供"当作"效力有问题"**——也不得反过来当作"没有问题"（三态：真／假／未确定）。

## 六、文字与用语审查

**定位**：本章产出**归入格式级**（呼应 `review-doctrine.md` 九的分级用法），
**与实质意见分开归集**，不混排——混排会稀释实质问题的可见度。

**为什么仍要单列**：文字问题是"看起来都懂、实际没查"的重灾区。且判断标准客观，适合做成清单。

### 审查项

| 项 | 检查内容 |
|---|---|
| **称谓体系统一** | 全篇用同一组称谓（"甲方/乙方"或"委托方/受托方"），**不混用、不中途换**；代称与首次定义一致 |
| **定义与释义** | 术语多时在首部单列定义条款，少时在首次出现处界定；**同一术语不得有两种含义**，不同概念不得共用一个词 |
| **条款编号与引称** | 编号连续不重不漏；引称准确（"第 X 条"确指该条）；**修订后须回头检验被引用的条号是否位移** |
| **标点与数字** | 顿号/逗号/分号的使用规范；金额同时写**大写与小写**；日期写明"××年××月××日"；计量单位用法定单位 |
| **法言法语** | 用规范法律用语（"定金"不写"订金"、"抵销"不写"抵消"、"应当"与"可以"不混用）；**避免口语、歧义与情绪化表述** |
| **简称与全称** | 主体首次出现用**证照全称**，之后可定义简称；简称须与全称对应无歧义 |

### 硬边界

- **"定金"与"订金"不得混用**——前者有罚则、后者通常只有预付款效力（呼应 3.5）；
- 金额大小写不一致时，**不擅自择一**，须回问当事人真实金额后再改；
- **文字问题不得单独升级为 P0/P1**——它是格式级；但**同一处文字问题若导致权利义务歧义**（如"可以"写成"应当"），则按实质问题处理。

## 七、约定优先与法定补位

**这一节回答一个具体问题**：某一处缺项，是"有任意性规范兜底、可以只批注"，还是"没有兜底、必须落笔补上"？

### 原则

- **有约定从约定**：当事人的约定优先于任意性规范。
- **无约定从法定**：未约定时，**不当然等于"没有规则"**——合同编的大量条款是任意性（示范性、补充性）规范，在无约定时自动适用。
- **强制性规范不得以约定排除**：这部分不适用"有约定从约定"。

### 常见"已有法定兜底"的缺项（可只批注）

| 缺项 | 法定兜底 |
|---|---|
| 未约定检验期 | 合理期限；自收货起 2 年内未通知视为符合约定；有质保期的适用质保期（《民法典》621、622 条，见 3.3） |
| 约定违约金过高/过低 | 可请求调整，以实际损失为基础（《民法典》585 条，见 3.5） |
| 未约定保证方式 | 推定为一般保证（见 EC-07 担保类资产） |
| 未约定履行期限 | 可随时履行/随时请求，但应给必要准备时间 |
| 未约定质量标准 | 依次按强制性国标 → 推荐性国标 → 行业标准 → 通常标准或符合合同目的的特定标准（见 3.3） |
| 未约定争议解决 | 回到法定管辖 |

### 判断动作

1. **先问：这一项有没有任意性规范兜底？**
   - **有** → 缺项的后果是"按法定走"，未必对我方不利。**只批注说明法定后果即可**，不必强求落笔；
   - **没有兜底，或兜底结果对我方明显不利** → **落笔补上并给出具体措辞**。
2. **不得把"有兜底"当作"不必审"**：法定兜底往往只是把裁量权交给法院，而**明确约定可以把裁量权收回自己手里**——这是质量、检验期、违约金条款必须写死的共同理由。
3. **不得把"法定兜底对我方有利"当作"不用改"**：法律变更会改变兜底结果，约定才是稳定的。

## 八、履约链条上的八类典型缺口（可直接落笔的补法）

**为什么单列一章**：这八项在实测中反复出现、**方向明确、有通行做法**，却常常被当成"商业取舍"
只留一条批注。它们不是取舍，是**机制**——机制缺失时，风险单向落在守约方。

> 来源：2026-09-17 睡眠监测运营服务合作协议的两次独立审查（两位审查者各自推导，互不通气）
> 比对出的差集：其中八项只有一位审查者看到。凡"换个人就看不到"的结论，说明它还没被规则兜住。

### 8.1 对账程序缺"默认确认"

- **触发**：合同设了周期对账，但只写"乙方核验"，未写不提异议的后果；
- **风险**：付款义务被程序无限期悬置（"我还在核验"）；
- **落笔**：`乙方对服务明细有异议的，应在收到后【待填：期限，通行5个工作日】内书面提出并指明订单与理由；逾期未书面提出的，视为确认该明细。局部争议不影响无争议款项结算。`
- **口径**：期限可填（1.6 天数类），注明可调整。

### 8.2 「有效完成」在**客户原因**下的认定

- **触发**：结算单位是"完成一例／一单"，而交付的一部分依赖客户配合（接受解读、随访、验收）；
- **风险**：客户不配合 → 我方拿不到钱，而设备、数据、报告都已实际投入；
- **落笔**：`因客户自身原因未按期接受约定的解读、随访或验收，经书面通知后【待填：15】日内仍未接受的，视为该例已完成；其他情形按已交付项目占该服务包全部项目的比例结算。`
- **边界**：**不得**写成"客户不提异议即视为满意"——那是替客户放弃权利；本规则只解决"我方已完成主要交付"的那部分。

### 8.3 第三方原因造成延误的顺延

- **触发**：交付依赖第三方（医疗机构、检测机构、承运人、审批机关），而期限写在我方头上；
- **落笔**：`因【第三方】的原因或者对方未按约配合，导致交付或响应延误的，相应期限顺延；我方应及时通知对方并协助督促完成。`
- **依据**：《民法典》第593条——因第三人原因造成违约的，**仍应向对方承担违约责任**；
  故顺延只能靠**约定**取得，不能靠法条自动免责；
- **硬边界**：顺延 ≠ 免责，**不得**写成"第三方原因我方不承担责任"。

### 8.4 相对方原因致我方对外担责的追偿（indemnity）

- **触发**：我方面向客户或第三方是第一顺位主张对象（品牌方、名义主体、报告出具方）；
- **落笔**：`因相对方或其人员、客户的原因，致使我方对第三方承担赔偿责任、受到行政处罚或遭受其他直接损失的，相对方应负责处理并在我方实际支出后【待填：10】日内予以赔偿，包括我方为此支出的合理律师费、诉讼费与保全费用。`
- **边界**：**不是免责条款**——是我方先对外赔付、再向相对方追偿的约定；不得据此排除我方依法应负的责任。

### 8.5 资产所有人的现场核查权

- **触发**：我方资产（设备、货物、样品）长期处于对方控制之下，合同只写"有权了解情况／要求纠正"；
- **落笔**：`我方有权在合理时间提前通知后，进入资产存放、展示及使用场所核查资产状态、保管条件与登记记录，相对方应予配合；发现缺失、违规使用或保管条件不符的，有权要求限期整改，逾期未整改的可暂停相应交付或服务。`
- **口径**：**必须与"暂停履行"联动**才有牙齿；只写"有权核查"等于没有。

### 8.6 隐蔽瑕疵不受"外观签收"限制

- **触发**：返还／收货时只确认数量与可见状态，而隐蔽故障（进液、内部损坏）在回库检测时才显现；
- **落笔**：`归还／收货签收确认数量及可见状态；隐蔽瑕疵不受签收时外观确认的限制，我方在收到返还物后【待填：15】日内发现隐蔽瑕疵的，仍有权依约主张，相对方应予配合核查。`
- **依据参照**：《民法典》第621条关于检验期间与合理期限的口径（经核验现行有效）。

### 8.7 长期投放资产的赔偿不得归零

- **触发**：赔偿上限按"原值 − 月折旧 × 已满月数、最低为 0"计算；
- **风险**：投放期长于折旧期时上限归零，资产损失无从弥补；
- **落笔**：`…赔偿上限不低于交付现有价值的【待填：通行 10%】`，或约定最长折旧月数；
- **方向警告**：这与 **3.5.1** 的责任上限**不是一回事**——3.5.1 是**我方对外赔偿**的上限（对我方有利），
  本项是**相对方对我方**的赔偿下限（同样对我方有利）；方向不要搞反。

### 8.8 逾期占用的成本：把"不重复救济"与"零成本"分开

- **触发**：合同写"不重复收取整机赔偿及无限期占用费用"或类似排除，使逾期归还**没有任何成本**；
- **风险**：相对方无按期归还动力；而资产少一日周转就是少一日收益——**灭失赔偿与占用损失是两件事**；
- **落笔**：`逾期归还超过【待填：7】日仍未返还的，除损失核定外，应按该资产交付现有价值的日万分之【待填：五】支付占用费，直至返还或完成赔偿之日止；占用费总额以该资产赔偿上限为限，不与整机赔偿重复计算。`
- **口径**：写成**比例**不写金额（1.6）；**必须保留"不与整机赔偿重复计算"**——原条款排除占用费
  有它的正当理由（防重复救济），要保留它防的那件事，只去掉"零成本"。

### 8.9 不可抗力的三项义务（只写"免责"等于没写）

- **触发**：合同写了不可抗力免责，但没写受影响方**该做什么**；
- **风险**：双方都不知道该履行什么义务，事后也无法证明对方是否本可减损；
  且**迟延履行后才发生不可抗力的，不免除违约责任**（《民法典》第590条第2款，经核验现行有效）；
- **落笔**：`受不可抗力影响的一方应在【待填：3】日内书面通知对方，说明影响范围与预计持续时间，
  并在【待填：15】日内提供可核验的证明；受影响方应采取合理措施减轻损失，
  未采取措施而扩大的损失不得要求对方承担。迟延履行后发生不可抗力的，不免除违约责任。`
- **边界**：不得把客户取消、客流不足、一般经营困难、设备丢失写进不可抗力定义（见 3.6.5）。
- **实证**：本条是**唯一一条"库里有规则、两次审查都漏掉、第三次才被抓住"**的条目——
  它原先只写在 3.6.5 的硬边界段落里。位置影响命中率：**"必须补什么"要写成清单，不要埋在硬边界里。**

### 8.10 质量条款：标准与检验两部分俱全

- **触发**：以"符合国家标准／行业标准""质量合格"式表述代替具体质量标准；
- **风险**：标准不写死 → 争议时回到"约定不明 → 法定兜底 → 裁量"的链条，
  **621／622 条向买受人的回补也失去比较基准**；
- **落笔**：① **标准写死**：`【标的】应符合【标准名称＋代号＋年份】；无对应标准的，
  按【双方确认的技术要求／附件】执行`；② **检验期与质保期分开**：
  `外观瑕疵异议期【待填：X】日；隐蔽瑕疵在合理期限内提出；
  质保期【待填：X】个月，自【验收合格／交付】之日起算`；
- **边界**：约定检验期／质保期短于法定期限的以法定为准（《民法典》第622条）；
  有强制性国家标准的不得以约定排除；**不得只写"按国家标准"**（等于没写，见 3.3）。

### 8.11 终止后的清算清单（终止条款只写"解除"不够）

- **触发**：合同写了终止情形，但没写终止后要处理哪些事；
- **风险**：真到终止时，"没履约的部分怎么算、已付款退不退、库存／资料／账号怎么交割"全无约定，
  只能事后协商——**协商不成时，先动的一方吃亏**；
- **落笔**：`本协议终止后【待填：X】日内，双方应完成：① 未履行部分的处理（继续履行至节点／
  停止并结算）；② 已付款项的结算与退还；③ 在途货物、设备、资料的清点与返还；
  ④ 对外合同与客户关系的承接安排；⑤ 押金／保证金的退还。`
- **边界**：不得写成"合同终止后双方互不承担任何责任"——那是终止后义务的真空。

### 8.12 违约金的三件套：可算、可比、可执行

- **触发**：合同只写"违约方承担违约责任"或"赔偿一切损失"；
- **风险**：违约条款的失败模式不是"不够狠"，而是**"不配套"和"不可执行"**——
  "定了拿不到"（畸高被调整）与"没定啥都没有"同样常见；**可预期性优先于额度高低**；
- **落笔**：① **基数确定、可算**：`以【逾期未付金额／订单金额／实际损失】为基数`；
  ② **标准**：`按日万分之五`（比例，可填、可调整）；③ **与定金、赔偿的关系**：
  `违约金不足以弥补损失的，守约方可就差额部分另行主张；定金与违约金不并用`；
- **边界**：不得写"赔偿一切损失"；约定惩罚性违约金的须注明性质（见 3.5）。

### 8.13 送达的"视为规则"（单方通知能否生效全靠它）

- **触发**：合同有催告、通知、解除机制，但没写"何时视为送达"；
- **风险**：对方一句"没收到"，催告与解除就可能被认定为尚未生效；地址变更不告知时同理——
  **机制写了，却按不下去**；
- **落笔**：`以专人送达的，签收之日视为送达；以快递送达的，交寄后第三日视为送达；
  以电子邮件送达的，发送成功后二十四小时视为送达。一方变更住所、联系人或电子邮箱
  未按前述方式书面通知对方的，按原址、原方式送达仍视为有效送达，由此产生的不利后果由变更方承担。`
- **依据**：《民法典》第137条（非对话的意思表示到达生效）、第565条（解除通知到达生效）。

### 8.14 附件的引用对应与效力顺位

- **触发**：正文引用了附件，或正文与附件可能冲突；
- **风险**：正文引用而清单没有（断链）；或冲突时不知以谁为准（各自援引有利的那份）；
- **落笔**：① **一一对应**：正文提到的每一个附件都要在附件清单中列明，**名称与编号一致**；
  ② **效力顺位**：`补充协议 ＞ 正文 ＞ 专项附件 ＞ 执行性文件；同一文件内特别约定优于一般约定`；
  ③ 附件标注**版本号与日期**，防止多版本并存；
- **边界**：关键附件（交接清单、验收标准、技术规格）缺失，等于对应条款没有标准（见 3.6.9）。

> **体例说明（为什么 8.x 用清单而 3.x 用硬边界）**：3.x 的"硬边界"回答**不许做什么**（效力、强制性规定、
> 不得排除的责任），适合用**禁令式**表述；8.x 回答**必须补什么、怎么落笔**，必须给触发条件与成文措辞。
> 实测（2026-09-18，同一份合同的三次独立审查）证明：**把"必须补什么"埋在硬边界段落里，命中率显著低于清单式条目**
> ——8.9 就是从硬边界里挪出来的那一条。
