# 保险纠纷分析及法院案例 Plus · 安装与使用说明

## 一、技能简介

本技能面向 **车辆商业保险纠纷、重大疾病保险（健康保险）纠纷及其他保险合同纠纷**，提供「保险纠纷相关问题分析 + 华宇元典法律数据 MCP 检索 5 个类似法院案例 + 管辖与程序问题分析」三段式结构化报告。

- 知识库融合：龚家勇律师两篇 DOCX 研究文章要点 + 华宇元典核验的《保险法》现行规范、司法解释及典型案例。
- 立场中立、结构清晰、可复核，符合法律分析的基本规范。

## 二、安装方式（WorkBuddy）

本技能为 WorkBuddy 用户级技能，安装步骤如下：

1. 将解压后的文件夹（即 `保险纠纷分析及法院案例Plus/`，内含 `SKILL.md` 与 `README.md`）整体复制到 WorkBuddy 的技能目录：
   - **用户级（推荐，全项目可用）**：`~/.workbuddy/skills/`
   - **项目级（仅当前项目可用）**：`<你的工作区>/.workbuddy/skills/`
2. 复制完成后，在 WorkBuddy 对话框中通过 `@skill:"保险纠纷分析及法院案例Plus"` 或在技能列表中找到本技能即可启用。
3. 无需修改 `SKILL.md` 的 frontmatter；技能名称以 frontmatter 中 `name` 字段为准。

> 说明：Skills 目录若不存在，请手动新建。技能文件夹名称可与 frontmatter 的 `name` 不同，但建议保持一致以免混淆。

## 三、依赖说明（重要）

本技能第二段「检索 5 个类似法院案例」依赖 **华宇元典法律数据 MCP（`yuandian-mcp`）**：

- 若接收方已连接 `yuandian-mcp`，则案例检索功能可直接使用。
- 若接收方未连接该 MCP，案例检索段将无法正常调用；分析报告仍可基于内置知识库（第一、三段）完成，但会自动提示"案例检索不可用，需人工补充"。

如接收方需要连接华宇元典法律数据 MCP，请在 WorkBuddy 的 Connector 管理中添加并授权。

## 四、内置内容（无需联网即可使用）

- `SKILL.md`：完整工作流、知识库（一）两篇 DOCX 文章要点、知识库（二）现行保险法规范体系、知识库（三）精选与权威典型案例、知识库（四）金融产品网络营销相关规定（互联网保险/网络投保场景，见 `knowledge_base/`）、输出规范与红线。
- `knowledge_base/`：参考资料原件，目前含《金融产品网络营销管理办法》（公告〔2026〕第9号，2026-09-30 施行）原始 `.doc` 及清洗版 `.txt`，供分析涉互联网保险营销、网络投保、直播/短视频卖保险、第三方平台代销保险等纠纷时查阅。
- 知识库内容均已随技能打包，离线可读、可复核。

## 五、作者与署名规范

- 技能作者信息记录于 `SKILL.md` 的 frontmatter `author` 字段，**仅供内部标识与维护使用**。
- 依技能规范，对外生成的分析报告**不得署名、不得展示作者姓名或联系方式**，统一标注「本分析由 AI 法律助理基于公开法律法规及案例数据库生成」。
