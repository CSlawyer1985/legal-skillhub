# 驳回复审与异议答辩指南

> 本指南详细说明商标被驳回后的复审策略和商标异议/答辩的操作流程。

## 一、商标驳回复审

### 1.1 驳回类型

| 类型 | 说明 | 后续选择 |
|------|------|---------|
| 全部驳回 | 商标在所有商品/服务项目上均被驳回 | 复审或放弃 |
| 部分驳回 | 商标在部分商品/服务项目上被驳回 | 复审或接受部分驳回 |

### 1.2 常见驳回原因及复审策略

#### 原因一：与在先商标近似

**驳回理由**：申请商标与在先注册/申请的商标在相同或类似商品/服务上构成相同或近似商标。

**复审策略**：
1. 分析引证商标（在先商标）的具体情况
2. 评估商标之间的实际差异程度
3. 主张商标的整体视觉效果和含义不同
4. 提交商标实际使用证据，证明消费者能够区分
5. 如引证商标已满三年未使用，可申请撤销（三撤）
6. 如引证商标可转让，协商购买

#### 原因二：缺乏显著性

**驳回理由**：商标过于简单或仅描述商品特点，不具备区分商品来源的功能。

**复审策略**：
1. 主张商标经过长期使用已获得显著性（第二含义）
2. 提交大量使用证据（广告、销售数据、媒体报道等）
3. 证明消费者已将该标志与特定来源建立联系

#### 原因三：违反禁用条款

**驳回理由**：商标含有商标法第十条禁止使用的标志。

**复审策略**：
1. 主张商标整体含义与禁用标志无关联
2. 提供相关权威机构的解释或证明
3. 此类复审成功率通常较低，需慎重考虑

### 1.3 复审流程

**时效**：收到驳回通知书之日起15日内提出复审申请

**申请材料**：
1. 《商标驳回复审申请书》
2. 驳回通知书原件
3. 申请人的主体资格证明
4. 委托代理的需提交委托书
5. 复审理由书
6. 相关证据材料

**复审机关**：国家知识产权局（原商评委）

**审理周期**：约6-9个月（有加快审查机制可用）

**复审结果**：
- **复审成功**：撤销驳回决定，商标进入初审公告
- **复审失败**：维持驳回决定（可向北京知识产权法院提起行政诉讼）

### 1.4 复审证据材料

| 证据类型 | 具体内容 |
|---------|---------|
| 使用证据 | 商标在实际使用中的照片、广告宣传材料 |
| 销售证据 | 销售合同、发票、销售数据 |
| 知名度证据 | 行业排名、获奖证书、媒体报道 |
| 区分性证据 | 消费者调查报告、市场反馈 |
| 第三方证据 | 行业协会证明、消费者证明 |

## 二、商标异议

### 2.1 异议人（提出异议方）

**异议期限**：初审公告期内3个月

**异议理由**：
1. **绝对理由**：
   - 商标违反禁用条款（商标法第十条）
   - 商标缺乏显著性（商标法第十一条）
   - 商标以三维标志申请但缺乏显著性（商标法第十二条）

2. **相对理由**：
   - 与异议人在先注册/申请的商标近似
   - 损害异议人在先权利（著作权、商号权、肖像权等）
   - 属于恶意抢注（以不正当手段抢注他人已使用并有一定影响的商标）
   - 违反诚实信用原则

**异议材料**：
1. 《商标异议申请书》
2. 异议人的主体资格证明
3. 异议理由书
4. 相关证据材料
5. 委托代理的需提交委托书

**异议费用**：500元/件（网上申请450元）

### 2.2 被异议人（答辩方）

**答辩期限**：收到异议通知之日起30日内

**答辩材料**：
1. 《商标异议答辩书》
2. 被异议人的主体资格证明
3. 答辩理由书
4. 相关证据材料
5. 委托代理的需提交委托书

**答辩策略**：
1. 逐一回应异议人的理由和证据
2. 提供商标设计创意和来源说明
3. 提交实际使用证据和知名度证据
4. 证明商标之间的差异性
5. 反驳恶意抢注的指控

### 2.3 异议审理结果

**审理周期**：约12-18个月

**结果**：
- **异议成立**：商标不予注册
- **异议部分成立**：商标在部分商品/服务上不予注册
- **异议不成立**：商标核准注册

**后续救济**：
- 异议人对裁决不服：可以向国家知识产权局提起行政复议，或向北京知识产权法院提起行政诉讼
- 被异议人对裁决不服：同上

## 三、商标无效宣告

### 3.1 无效宣告概述

商标注册后，特定主体可以在一定期限内向国家知识产权局申请宣告该注册商标无效。

**申请时限**：
- 基于绝对理由：无时间限制
- 基于相对理由（恶意抢注除外）：自商标注册之日起5年内

### 3.2 无效宣告理由

**绝对理由**：
- 违反禁用条款
- 缺乏显著性
- 以欺骗手段取得注册

**相对理由**：
- 与在先注册/申请商标冲突
- 损害他人在先权利
- 恶意抢注他人已使用并有一定影响的商标
- 地理标志保护冲突

## 四、行政复议与诉讼

### 4.1 行政诉讼

对国家知识产权局的复审决定、异议裁定或无效宣告裁定不服的，可以向北京知识产权法院提起行政诉讼。

**诉讼时效**：收到决定/裁定之日起30日内

**上诉**：对一审判决不服，可以向北京市高级人民法院上诉

### 4.2 民事诉讼

商标权侵权纠纷可以通过民事诉讼途径解决：
- 向侵权行为地或被告住所地的中级人民法院起诉
- 可请求停止侵权、赔偿损失、消除影响
- 赔偿额可按实际损失、侵权获利或商标许可使用费计算
