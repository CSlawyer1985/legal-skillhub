# 商标续展、变更与转让指南

> 本指南详细说明商标注册后的维护管理，包括续展、变更、转让和许可使用。

## 一、商标续展

### 1.1 续展基本规定

**有效期**：商标注册有效期为10年，自核准注册之日起计算

**续展申请时间**：
- **正常续展期**：注册有效期届满前12个月内
- **宽展期**：注册有效期届满后6个月内（需缴纳宽展费）
- **逾期未续展**：商标注销，不再受保护

**续展有效期**：每次续展有效期为10年，续展次数不限

### 1.2 续展申请材料

| 材料 | 要求 |
|------|------|
| 《商标续展注册申请书》 | 填写完整，加盖公章/签字 |
| 申请人身份证明 | 营业执照复印件/身份证复印件 |
| 商标注册证复印件 | 或注册号 |
| 委托代理的需提交委托书 | 加盖公章/签字 |

### 1.3 续展费用

| 项目 | 纸质申请 | 网上申请 |
|------|---------|---------|
| 续展注册费 | 500元/类 | 450元/类 |
| 宽展费（逾期续展） | 250元/类 | 225元/类 |

### 1.4 续展流程

1. 在续展期内向商标局提交续展申请
2. 缴纳续展费用
3. 商标局审查（一般不再进行实质审查）
4. 审查通过后发放《商标续展注册证明》
5. 续展后商标有效期延长10年

### 1.5 续展注意事项

- **提前规划**：建议在到期前6个月开始准备续展
- **信息核对**：确认注册人名称、地址等信息是否有变化，如有变更需先办理变更手续
- **多类商标**：如有多类别注册商标，逐一办理续展
- **宽展期内保护**：宽展期内商标仍受保护，他人不得使用
- **未续展后果**：商标注销后有1年的过渡期，在此期间其他人仍不能注册相同/近似商标

## 二、商标变更

### 2.1 变更类型

| 变更类型 | 适用场景 |
|---------|---------|
| 注册人名义变更 | 企业更名、个人改名 |
| 注册人地址变更 | 企业搬迁、个人搬家 |
| 代理人变更 | 更换代理机构 |
| 商品/服务删减 | 删除部分商品/服务项目 |
| 共有人变更 | 增减共有商标的共有人 |

### 2.2 变更申请材料

**名义变更**：
1. 《变更商标申请人/注册人名义/地址申请书》
2. 登记主管机关出具的变更证明（企业更名需工商局出具证明）
3. 变更后的营业执照/身份证复印件
4. 商标注册证原件（需要更换的）
5. 委托代理的需提交委托书

**地址变更**：
1. 变更申请书
2. 变更后的营业执照/身份证复印件
3. 委托代理的需提交委托书

### 2.3 变更费用

- 不变更注册证的变更（仅地址变更等）：150元/类（纸质）/135元/类（网上）
- 需更换注册证的变更：另缴换证费

### 2.4 变更注意事项

- **一并变更**：注册人名下所有注册商标应一并变更
- **证明文件**：企业更名需提供工商（市场监管）部门出具的变更证明
- **先行变更**：在办理续展、转让等手续前，应先完成信息变更

## 三、商标转让

### 3.1 转让概述

商标注册人可以通过签订转让合同，将其注册商标专用权转让给他人。

**转让类型**：
- **合同转让**：通过签订转让合同实现
- **继承转让**：因自然人死亡由继承人继承
- **行政命令转让**：因行政区划调整等行政命令导致

### 3.2 转让要求

**同类一并转让**：转让注册商标的，商标注册人对其在同一商品/服务上注册的相同或近似商标，应当一并转让。

**不能转让的情形**：
- 容易导致混淆或有其他不良影响的
- 对可能导致混淆的转让，商标局可以要求其改正

### 3.3 转让流程

1. **签订转让协议**：明确转让的商标、范围、价格、交付方式
2. **共同申请**：转让人和受让人共同向商标局提交转让申请
3. **审查核准**：商标局审查转让申请
4. **核准公告**：转让经核准后予以公告
5. **效力产生**：受让人自公告之日起享有商标专用权

### 3.4 转让申请材料

| 材料 | 要求 |
|------|------|
| 《转让/移转商标申请书》 | 双方签字/盖章 |
| 转让协议 | 原件或公证副本 |
| 双方身份证明 | 营业执照/身份证复印件 |
| 商标注册证复印件 | |
| 委托代理的需提交委托书 | |

### 3.5 转让费用

- 官费：500元/类（纸质）/450元/类（网上）
- 代理费：500-2000元/类
- 公证费（如需）：500-2000元

### 3.6 转让注意事项

- **尽职调查**：受让方应核实商标的法律状态（有效、无质押、无冻结）
- **关联商标**：检查是否有相同/近似商标需要一并转让
- **许可状态**：如商标已许可他人使用，需明确许可关系的处理
- **转让对价**：建议合理评估商标价值后再确定转让价格
- **保密条款**：在转让完成前注意保密

## 四、商标使用许可

### 4.1 许可类型

| 类型 | 含义 | 独占性 |
|------|------|--------|
| 独占许可 | 许可后仅被许可人可以使用，许可人自己也不能使用 | 最高 |
| 排他许可 | 许可人和被许可人都可以使用，但不能再许可第三方 | 中等 |
| 普通许可 | 许可人可以继续许可给其他人使用 | 最低 |

### 4.2 许可合同要点

1. **许可范围**：明确许可使用的商品/服务范围和地域范围
2. **许可期限**：不得超过商标注册有效期
3. **许可类型**：明确独占/排他/普通
4. **质量控制**：许可人有权监督被许可人使用商标的商品质量
5. **许可费**：约定许可费的计算方式和支付时间
6. **违约责任**：约定违约情形和违约责任

### 4.3 许可备案

- 商标使用许可合同应当报商标局备案
- 备案后商标局予以公告
- 未备案不影响许可合同的效力，但不得对抗善意第三人

### 4.4 许可备案材料

1. 《商标使用许可合同备案申请书》
2. 商标使用许可合同
3. 双方身份证明
4. 委托代理的需提交委托书

### 4.5 许可费用

- 官费：150元/类（纸质）/135元/类（网上）
- 代理费：500-1500元/类

## 五、商标质押

### 5.1 商标权质押概述

商标注册人可以将其注册商标专用权出质，作为债权的担保。

### 5.2 质押登记流程

1. 签订质押合同
2. 双方共同向商标局提出质押登记申请
3. 商标局审查核准
4. 发放《商标专用权质押登记证》

### 5.3 注意事项

- 质押后未经质权人同意，不得转让或许可他人使用
- 债务履行完毕后应及时办理质押注销登记
- 一个商标上可以设定多个质押，但总额不得超过商标评估价值
