# 审查流程与时间节点

> 本指南详细说明商标注册的完整审查流程、各阶段时间节点和注意事项。

## 一、审查流程总览

```
提交申请 → 形式审查 → 实质审查 → 初审公告 → 注册公告 → 发放证书
   |          |          |          |           |          |
  即时      1个月     4-6个月    3个月      1-2个月    1-2个月
```

**总周期**：约8-12个月（从申请到获得商标注册证）

## 二、各阶段详解

### 第一阶段：形式审查

**时间**：约1个月（网上申请可能缩短至2-3周）

**审查内容**：
1. 申请人资格是否符合规定
2. 申请文件是否齐全、格式是否规范
3. 商标图样是否符合要求
4. 商品/服务分类是否正确
5. 缴费是否完成

**审查结果**：
- **通过**：发放《商标注册申请受理通知书》，分配申请号
- **不通过**：要求补正或不予受理

**形式审查补正常见原因**：
- 申请书填写不完整或有误
- 图样不符合规格要求
- 营业执照/身份证不清晰
- 商品/服务项目名称不规范
- 委托书信息不一致

### 第二阶段：实质审查

**时间**：约4-6个月（从形式审查通过后开始）

**审查内容**：

#### 2.1 显著性审查
商标是否具备区分商品/服务来源的功能。

**具备显著性的商标**：
- 臆造词（如"KODAK"）
- 随意词（如"苹果"用于电脑）
- 暗示性商标（暗示商品特点但不直接描述）

**缺乏显著性的情形**：
- 仅有本商品的通用名称、图形、型号
- 仅直接表示商品的质量、主要原料、功能、用途、重量、数量及其他特点
- 其他缺乏显著特征的标志

#### 2.2 禁用条款审查（商标法第十条）

**绝对禁用**：
- 同国家名称、国旗、国徽、军旗、勋章相同或近似的
- 同外国国家名称、国旗、国徽相同或近似的（该国政府同意除外）
- 同政府间国际组织名称、旗帜、徽记相同或近似的（该组织同意除外）
- 与官方标志、检验印记相同或近似的（经授权除外）
- 同"红十字""红新月"标志名称相同或近似的
- 带有民族歧视性的
- 带有欺骗性，容易使公众对商品质量等特点产生误认的
- 有害于社会主义道德风尚或有其他不良影响的

**地名禁用**：
- 县级以上行政区划名称或公众知晓的外国地名不得作为商标
- 但地名具有其他含义或作为集体商标/证明商标组成部分的除外

#### 2.3 相对理由审查（商标法第三十条/三十一条）
- 是否与已注册或初步审定的商标相同或近似
- 是否与他人在先权利（著作权、商号权、肖像权等）冲突
- 是否属于恶意抢注

**审查结果**：
- **通过**：进入初审公告程序
- **部分驳回**：部分商品/服务上的注册被驳回
- **全部驳回**：发放《商标驳回通知书》

### 第三阶段：初审公告

**时间**：3个月公告期

**公告内容**：
- 商标图样
- 注册申请人信息
- 核定使用的商品/服务项目
- 申请号和日期

**公告期间**：
- 任何人均可在公告期内提出商标异议
- 异议期为3个月，自公告之日起计算
- 公告期内无人异议或异议不成立的，商标予以核准注册

### 第四阶段：注册公告与发证

**时间**：初审公告期满后1-2个月

**流程**：
1. 发布《商标注册公告》
2. 制作《商标注册证》
3. 证书发放给申请人或代理机构

**注册有效期**：自核准注册之日起10年

## 三、时间节点汇总表

| 阶段 | 起始时间 | 预计时长 | 关键事件 |
|------|---------|---------|---------|
| 提交申请 | T日 | 即时 | 获得申请号 |
| 形式审查 | T+1日 | 约1个月 | 收到受理通知书 |
| 实质审查 | 受理后 | 约4-6个月 | 审查通过或驳回 |
| 初审公告 | 审查通过后 | 3个月 | 公告期（异议期） |
| 注册公告 | 公告期满后 | 1个月 | 核准注册 |
| 发放证书 | 注册公告后 | 1个月 | 收到商标注册证 |
| **总计** | | **约8-12个月** | |

## 四、加急和优先审查

### 4.1 优先审查
商标局对以下情形可以优先审查：
- 涉及国家重大利益的商标申请
- 涉及重大公共利益的商标申请
- 其他需要优先审查的特殊情形

### 4.2 马德里国际注册优先权
- 在中国首次提出商标申请后6个月内，在其他马德里联盟成员国提出申请，可享有优先权
- 优先权日为中国首次申请的申请日

## 五、各阶段注意事项

### 5.1 形式审查阶段
- 保持联系方式畅通，及时响应补正通知
- 补正通知通常要求在规定期限内回复
- 如有代理机构，确认代理机构是否收到相关通知

### 5.2 实质审查阶段
- 此阶段无法主动干预审查进度
- 关注商标局网站查询申请状态
- 如收到审查意见通知，及时配合代理机构准备答辩

### 5.3 初审公告阶段
- 密切关注公告期，如有他人提出异议，需及时应对
- 也可以在此阶段关注是否有与自己商标近似的商标公告
- 如发现近似商标公告，可考虑提出异议

### 5.4 注册后
- 妥善保管商标注册证原件
- 记录注册有效期，提前准备续展
- 规范使用注册标记（R标或注字标记）
- 建立商标使用证据档案

## 六、商标申请加速建议

1. **网上申请**：网上申请比纸质申请审查速度更快
2. **规范填报**：确保申请材料规范完整，减少补正环节
3. **专业代理**：委托有经验的代理机构，提高申请质量
4. **预查检索**：提交前充分检索，降低驳回风险
5. **合理分类**：准确选择商品/服务类别，避免因分类问题被驳回
