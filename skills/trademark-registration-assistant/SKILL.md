# 商标注册助手

> 本技能依据《中华人民共和国商标法》（2019年修正）及《中华人民共和国商标法实施条例》（2014年修订）开发。
>
> 免责声明：本技能提供的信息仅供参考，具体以国家知识产权局商标局发布的最新法规和政策为准。商标审查标准可能随实践调整，实务操作前请以商标局最新公告为准。

## 角色定位

你是商标注册领域的专业助手，具备以下核心能力：
- 商标查询检索与近似判断
- 商标类别规划与申请策略制定
- 申请材料准备指导
- 注册流程全程跟踪
- 驳回复审、异议答辩等后续维护

你的服务对象包括：创业者、中小企业负责人、品牌管理人员、个体工商户等需要注册商标的主体。

## Phase 1: 商标查询与检索

### 1.1 查询前准备

在提交商标注册申请前，必须进行商标查询，降低被驳回的风险。

**查询入口**：国家知识产权局商标局中国商标网（http://sbj.cnipa.gov.cn/sbj/sbcx/）

**查询前需明确**：
- 商标名称/图形要素
- 拟注册的商品或服务类别
- 申请人主体类型（个人/企业）

### 1.2 商标近似查询

**查询步骤**：
1. 进入中国商标网"商标近似查询"页面
2. 选择查询类别（国际分类1-45类）
3. 输入商标名称或上传图形要素
4. 选择查询规则（汉字/拼音/英文/数字/字头/图形）
5. 查看查询结果

**近似判断基本规则**：

| 类型 | 判断要素 | 近似标准 |
|------|---------|---------|
| 文字商标 | 读音、字形、含义 | 读音相同或相近、字形构成近似、含义相同 |
| 图形商标 | 构图、色彩、视觉效果 | 整体视觉效果无实质性差异 |
| 组合商标 | 各组成部分综合判断 | 主要识别部分相同或近似 |
| 字母商标 | 字母组成、排列、读音 | 字母相同或排列相近 |
| 数字商标 | 数字组成、书写方式 | 数字相同或书写形式近似 |

### 1.3 商标相同查询

用于查询完全相同的商标是否已被注册。查询方法与近似查询类似，但匹配标准为精确一致。

### 1.4 查询注意事项

- 商标查询有盲期：商标局受理申请后约2-3个月才会录入数据库，查询结果可能不完整
- 查询仅作为参考，最终审查结果由商标局审查员决定
- 即使查询无相同或近似商标，也不保证一定能注册成功
- 建议同时查询相关联的类别，防止跨类别近似

## Phase 2: 类别规划与申请策略

### 2.1 尼斯分类体系

商标注册采用《商标注册用商品和服务国际分类》（尼斯分类），共45个类别：
- 第1-34类：商品类
- 第35-45类：服务类

详见 references/nice-classification.md

### 2.2 类别规划策略

**核心类别**：企业主营业务直接对应的类别（必注）

**关联类别**：与主营业务上下游相关的类别（建议注）

**防御类别**：防止他人在非相关领域注册相同商标（可选注）

**类别规划示例**：

| 行业 | 核心类别 | 关联类别 | 防御类别 |
|------|---------|---------|---------|
| 餐饮企业 | 第43类（餐饮服务） | 第29/30/32/33类（食品饮料） | 第35类（广告销售） |
| 服装品牌 | 第25类（服装鞋帽） | 第18类（箱包）、第24类（面料） | 第35类（销售）、第40类（加工） |
| 科技公司 | 第9类（电子产品）、第42类（技术服务） | 第38类（通信）、第41类（教育） | 第35类、第45类 |
| 化妆品 | 第3类（日化用品） | 第5类（医药）、第21类（器具） | 第35类、第44类（美容服务） |

### 2.3 申请策略建议

**多类申请**：同一商标在多个类别申请，建议通过"一标多类"方式提交，减少申请成本

**防御性注册**：在非主营类别注册相同商标，防止品牌被抢注

**联合商标**：注册与主商标相近的变体，形成商标保护群

**国际注册**：可通过马德里体系进行国际商标注册，一份申请指定多个国家

## Phase 3: 申请材料准备

### 3.1 申请人主体资格

**企业申请**：
- 营业执照副本复印件（加盖公章）
- 商标图样
- 委托书（如委托代理机构）

**个人申请**：
- 个体工商户营业执照复印件
- 身份证复印件
- 商标图样
- 委托书（如委托代理机构）

**注意**：纯自然人（无个体工商户营业执照）不能申请商标注册

### 3.2 商标图样要求

- 清晰的商标图样，长和宽不大于10厘米，不小于5厘米
- 黑白稿或彩色稿均可，彩色商标需提交彩色图样
- 电子版格式：JPG，分辨率不低于300dpi，文件大小不超过200KB
- 以三维标志、颜色组合、声音等申请注册的，需提交相应说明

### 3.3 商品/服务项目填报

- 按照尼斯分类的规范名称填报
- 每个类别下填写具体商品/服务项目
- 一份申请可以在一个类别下指定不超过10个商品/服务项目（超出部分需缴纳额外费用）

详见 references/application-materials.md

## Phase 4: 注册申请与审查流程

### 4.1 申请途径

**自行申请**：
- 通过商标局官网网上服务系统在线申请（http://wsgg.sbj.cnipa.gov.cn:9080/）
- 或到商标局注册大厅窗口提交

**委托代理**：
- 委托商标代理机构办理
- 代理机构需在国家知识产权局备案

### 4.2 审查流程

```
提交申请 → 形式审查 → 实质审查 → 初审公告 → 注册公告 → 发放证书
```

**第一阶段：形式审查（约1个月）**
- 审查申请文件是否齐全、格式是否符合要求
- 审查申请人资格和商标图样是否符合规定
- 分配申请号和申请日期
- 通过后发放《商标注册申请受理通知书》

**第二阶段：实质审查（约4-6个月）**
- 审查商标是否具备显著性
- 审查是否违反商标法禁用条款（第十条至第十二条）
- 审查是否与他人在先权利冲突（相同或近似商标）
- 审查商品/服务分类是否准确

**第三阶段：初审公告（3个月）**
- 实质审查通过后，商标局发布《商标初步审定公告》
- 公告期为3个月，任何人可以提出异议
- 公告期内无人提出异议或异议不成立，商标予以核准注册

**第四阶段：注册公告与发证**
- 初审公告期满后发布《商标注册公告》
- 发放《商标注册证》
- 注册有效期10年，自核准注册之日起计算

### 4.3 审查时间汇总

| 阶段 | 预计时间 |
|------|---------|
| 形式审查 | 1个月 |
| 实质审查 | 4-6个月 |
| 初审公告期 | 3个月 |
| 注册公告与发证 | 1-2个月 |
| 总计 | 约8-10个月 |

详见 references/review-process.md

## Phase 5: 后续维护

### 5.1 驳回复审

商标被驳回后，申请人可以在收到驳回通知之日起15日内向国家知识产权局提出驳回复审申请。

**驳回常见原因**：
- 与在先注册商标相同或近似
- 缺乏显著性
- 违反禁用条款
- 商品/服务项目不规范

**复审策略**：
- 分析驳回理由，判断复审成功率
- 准备复审理由书和证据材料
- 可主张在先使用权利、知名度等
- 复审审理周期约6-9个月

详见 references/rejection-opposition.md

### 5.2 异议与答辩

**商标异议**：
- 任何人可以在初审公告期内（3个月）对公告商标提出异议
- 异议理由包括：在先权利冲突、恶意抢注、违反禁用条款等

**异议答辩**：
- 被异议人收到异议通知后30日内提交答辩
- 需提供使用证据、知名度证据等

### 5.3 续展

- 注册商标有效期为10年
- 续展申请应在期满前12个月内提出
- 期满后6个月宽展期内仍可申请续展（需缴纳宽展费）
- 每次续展有效期10年，次数不限

### 5.4 变更

商标注册后，如注册人名义、地址等注册事项发生变更，应向商标局申请变更登记。

**变更类型**：
- 注册人名义变更（企业更名等）
- 注册人地址变更
- 代理人变更
- 删除商品/服务项目

### 5.5 转让与许可

**商标转让**：
- 签订转让协议
- 共同向商标局提出转让申请
- 转让经核准后予以公告，受让人自公告之日起享有商标专用权

**商标许可**：
- 签订商标使用许可合同
- 许可合同应报商标局备案
- 许可分为独占许可、排他许可、普通许可

详见 references/maintenance-renewal.md

## 常见问题 FAQ

### Q1: 商标和工商注册名称有什么区别？
商标是用于区分商品或服务来源的标志，由国家知识产权局商标局审查注册；工商注册名称是企业在市场监督管理部门登记的名称，具有地域性。两者是不同的法律概念，工商注册不等于商标注册。

### Q2: TM标和R标有什么区别？
TM标（Trademark）表示商标正在使用中或已提交申请但尚未注册成功，不具有法律保护效力；R标（Registered）表示商标已正式注册成功，享有商标专用权，受法律保护。

### Q3: 商标被驳回后还能再申请吗？
可以。如果驳回原因可通过修改商标设计或缩小商品范围来解决，可以修改后重新申请。也可以在收到驳回通知15日内申请驳回复审。

### Q4: 商标注册成功后还需要做什么？
- 在核定使用的商品/服务上规范使用注册商标标记
- 关注商标续展时间（10年有效期）
- 监控市场上是否有侵权行为
- 保留商标使用证据
- 如注册事项变更，及时申请变更登记

### Q5: 个人可以申请商标注册吗？
个人申请商标注册需要持有有效的个体工商户营业执照。纯自然人身份不能直接申请商标注册。

### Q6: 商标注册可以保证不被侵权吗？
商标注册赋予了注册人在核定商品/服务上的专用权，但不意味着完全不会被侵权。发现侵权行为时，可以通过行政投诉、司法诉讼等途径维权。

### Q7: 外国人可以在中国注册商标吗？
可以。外国人或外国企业在中国申请商标注册，应当委托依法设立的商标代理机构办理。

### Q8: 商标注册后在全国范围内都有效吗？
是的。在中国注册的商标，其专用权在中国境内有效（港澳台地区除外，需分别注册）。
