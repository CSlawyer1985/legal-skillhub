## 🔍 搜索纪律（最重要 — 防止数据错误）

```
1. 每个关键数据点 → 必须先 web 搜索，禁止用模型记忆的数字
2. query 必须带年份 + 权威机构名（"2025年XX市场规模 IDC"）
3. 核心数据至少 2 个来源交叉验证
4. 找不到的数据标注"待验证"，绝不编造
5. 来源排序：政府官网 > 国际权威 > 年报 > 券商 > 研究机构 > 媒体 > 自媒体
```

## 产业生命周期判断（渗透率法）

```
导入期        成长期          成熟期          衰退期
  0% ──── 15% ──── 40% ──────────── → → → → →

  重点看：   重点看：       重点看：         重点看：
  可行性     规模性         防守性+盈利性    替代品
```

## 七步研究法

```
Step 1  定位       → 行业定义 + 生命周期阶段
Step 2  可行性     → 商业模式画布 + UE模型
Step 3  规模性     → TAM/SAM/SOM 测算
Step 4  防守性     → 护城河清单（资源垄断/网络效应）
Step 5  盈利性     → 竞争格局 + 产业链利润分配
Step 6  时机       → PEST + 景气度指标
Step 7  估值       → 估值锚 + 预期差
```

## 商业模式可行性判断

```
销售可行性：
  时间对标（过去有没有类似需求？）
  +
  空间对标（成熟市场有没有成功案例？）

利润可行性：
  定性：频次高 或 弹性小（至少取其一）
  定量：UE模型 → 单店/单客/单品 能不能赚钱？
```

## 护城河 = 资源垄断 + 网络效应

```
资源垄断（生产要素）：
  劳动力 · 土地 · 资本 · 技术 · 数据

网络效应（生产关系）：
  用户网络 · 生态网络 · 双边市场
```

## 假设驱动三步法

```
1. 做出假设："核心驱动力是XX"
2. 拆解假设（MECE：不重不漏）
3. 验证子假设（找数据/新闻/专家验证或证伪）
```

## PEST 外部因素

```
P 政治：监管/补贴/反垄断/贸易壁垒
E 经济：周期/利率/汇率/通胀
S 社会：人口/消费习惯/社会思潮
T 技术：替代技术/颠覆创新/技术路线
```

## 景气度跟踪

```
纵向（产业链）：先行指标 → 同步指标 → 滞后指标
横向（关键指标）：行业最关键的高频数据
```

## 估值方法（按生命周期）

```
导入期 → VC法（看用户/技术/团队）
成长期 → PEG、PS
成熟期（稳定）→ DCF、PE
成熟期（周期）→ PB、产能周期
衰退期 → 低PE ≠ 便宜
```

## Porter 五力（竞争格局必须包含）

```
供应商议价能力 → 哪个环节卡脖子？
买方议价能力   → 客户集中度？有替代选择？
替代品威胁     → 哪些技术/产品可能替代？
新进入者威胁   → 进入壁垒的具体构成？
同业竞争强度   → 行业增速 vs 产能扩张？
```

## 三种特殊模式

```
快速扫描 → 一句话本质 + 规模 + Top3 + 投资判断
对比模式 → 统一维度并排对比表
追踪更新 → 最近1个月事件 + 格局影响判断
```
