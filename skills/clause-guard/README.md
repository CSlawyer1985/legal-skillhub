# 措辞别找官司 · Clause Guard

**把 HR 写的文本贴进来，告诉你哪些措辞可能会被告，并给出安全的改写方案。**

---

## 怎么用

把你起草的辞退通知、PIP、离职协议、内部公告、邮件等 HR 文本贴给 AI，它会逐句扫描：
- 哪些措辞在法律上站不住
- 每个风险点引用哪条法条
- 怎么改写才安全

---

## 适用场景

- 辞退/裁员通知起草
- 绩效改进计划（PIP）撰写
- 离职协议/协商解除协议拟定
- 内部制度公告发布前审查
- HR 对外邮件措辞检查

---

## 限制

- 仅针对中国大陆劳动法律体系
- 不构成正式法律意见，重大事项请咨询律师
- 单次扫描建议不超过 3000 字
