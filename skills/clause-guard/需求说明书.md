# 措辞别找官司 · Clause Guard — 需求说明书

> 版本 1.0 · 2026-07-15

---

## 一、背景

HR 日常需要撰写大量对内对外的书面沟通：辞退通知、绩效改进计划（PIP）、离职协议、内部公告、邮件回复等。这些文本一旦措辞不当，可能在劳动争议中成为不利证据，甚至直接触发仲裁或诉讼。现实中，大部分中小企业的 HR 没有法务实时审稿支持，往往凭经验和网上的模板自行判断，踩坑率极高。

## 二、核心需求

用户将一段 HR 场景的书面文本粘贴给 Skill，Skill 自动扫描其中可能与劳动法律法规冲突的措辞，逐条标注风险等级、引用法律依据、并给出安全的替代表述。

## 三、用户场景

1. **辞退/裁员通知**：HR 起草了一封裁员通知邮件，想知道措辞是否会构成"违法解除劳动合同"
2. **PIP 文档**：HR 写了一份绩效改进计划，想知道其中描述是否会被认定为变相降薪或歧视
3. **离职协议**：HR 草拟了一份协商解除协议，想知道补偿条款是否写漏了法定项目
4. **内部公告**：HR 发布了一则考勤新规通知，想确认措辞是否违反劳动基准法
5. **面试沟通**：HR 准备发给候选人的拒信或 offer letter，想确认是否含有歧视性表述
6. **日常邮件**：HR 与员工的争议沟通邮件，想扫描是否有可被截屏取证的风险措辞

## 四、产品调性

- **严肃专业但不恐吓**：指出风险时像法务同事提醒，而非威胁性警告
- **可操作**：每个风险点都配安全改写版本，用户不是"被指出问题"而是"获得解决方案"
- **克制边界**：明确不是律师意见，不替代正式法律审查

## 五、技术约束

- 依赖 LLM 对中国劳动法律法规的知识，无需外部 API 调用
- 法律依据限于《劳动合同法》《劳动合同法实施条例》《社会保险法》《劳动争议调解仲裁法》《女职工劳动保护特别规定》《工伤保险条例》等常用法规
- 不处理跨司法管辖区问题，仅限中国大陆劳动法
- 单次输入建议不超过 3000 字，超出时降级为摘要扫描
