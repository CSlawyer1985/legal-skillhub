# 海外招聘合规指引

## 用户入口

用户可以直接说：“请帮我完成海外招聘合规指引：跨国招聘→各国劳动法差异/签证要求/跨境薪酬支付/社保缴纳规则。”也可以直接上传现有文件。先从用户原话或文件提取信息，只追问缺少的最少必要项；不要让用户填写内部JSON，也不要把员工编号设为通用必填。

最少需要：

- 目标岗位或招聘场景
- 现有招聘要求或数据
- 适用地区和时间

可选信息：

- 用户已有模板、历史数据或官方政策原文
- 希望的输出格式

## 执行

1. 从用户自然语言或上传文件提取已确认事实，只追问完成任务所缺的最少信息
2. 执行当日核验政府、人社、医保、税务、公积金中心等官方来源的现行口径和生效期
3. 把事实、计算参数、判断依据、待确认项和下一步行动分开呈现

需要确定性计算或结构化检查时，将已确认信息写入内部临时JSON并运行：

`python scripts/run.py --input <内部临时JSON> --output <结果.md>`

内部JSON只用于脚本调用，不向用户展示或要求用户手填。涉及政策、费率、期限、材料或办理入口时，执行当日查询政府、人社、医保、税务、公积金中心等官方来源，并记录机构、标题、发布日期、生效期和链接；无法核验时明确写“待官方确认”。

## 交付

- 可直接使用的招聘交付物
- 结构化评估或流程明细
- 偏差、风险和下一步行动清单

先在对话中给结论和关键明细，再按任务生成可下载的Markdown、CSV、XLSX、DOCX、PDF、Mermaid或图片。

## 边界

- 不要求蚂蚁HR账号、内部员工编号或用户手写JSON
- 动态政策、费率、期限和入口无法从当日官方来源核验时，明确标记“待官方确认”
- 输入不足时输出待补充清单，不用看似精确的内容替代未知事实
- 结果是合规辅助和文书草稿，不替代律师、仲裁机构或主管部门的个案结论
- 只处理任务所需的最少个人信息，不索要无关身份证号、账号密码或完整病历
- 不得依据性别、年龄、婚育、籍贯、民族、健康等敏感属性作出不当人员决策
