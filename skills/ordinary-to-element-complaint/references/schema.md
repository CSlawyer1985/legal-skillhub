# 要素式起诉状数据模型（JSON Schema）

`fill_element_complaint.py` 读取一份结构化 JSON，把数据填入 `assets/template.docx`
（最高人民法院《要素式起诉状示范文本·金融借款合同纠纷》空白模板）。

## 顶层字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `case_type` | string | 案由，写入副标题“（案由）”。模板默认“金融借款合同纠纷”，可改。 |
| `plaintiffs` | array | 原告列表 |
| `defendants` | array | 被告列表 |
| `third_parties` | array | 第三人列表（可空 `[]`） |
| `agent` | object\|null | 委托诉讼代理人 |
| `sections` | object | 诉讼请求 / 管辖 / 事实与理由 / 调解意愿 等要素项 |
| `signer` | string | 具状人落款（可选） |
| `date` | string | 日期落款，如“2023年9月26日”（可选） |

> **多当事人规则**：任一分组（原告 / 被告 / 第三人）内数量 > 1 时，脚本按模板
> 既有格式**克隆对应当事人行**（重复同名标签行，不做重新编号），完整保留表格线。
> 分组内顺序固定为「自然人在前、法人在后」，与模板一致。

## 当事人对象

每个当事人为 `{ "type": "自然人" | "法人", "fields": { ... } }`。

### 自然人 `fields`

| 键 | 说明 | 示例 |
|----|------|------|
| `name` | 姓名 | 张三 |
| `gender` | 性别，取值 `男` / `女`（自动打勾 ☑） | 男 |
| `birth` | 出生日期 | 1980年5月1日 |
| `nation` | 民族，缺省“汉族” | 汉族 |
| `address` | 住所地（户籍所在地） | 贵州省贵阳市… |
| `id_type` | 证件类型，缺省“居民身份证” | 居民身份证 |
| `id_number` | 证件号码 | 5201… |
| `phone` | 联系电话 | 139… |
| `work_unit` | 工作单位（可选） | |
| `title` | 职务（可选） | |
| `residence` | 经常居住地（可选） | |

### 法人 / 非法人组织 `fields`

| 键 | 说明 | 示例 |
|----|------|------|
| `name` | 名称 | 贵州某有限公司 |
| `address` | 住所地（主要办事机构所在地） | |
| `reg_address` | 注册地 / 登记地（可选） | |
| `legal_rep` | 法定代表人 / 负责人 | 李四 |
| `credit_code` | 统一社会信用代码 | 9152… |
| `org_type` | 类型勾选项（自动打勾）：`有限责任公司` / `其他企业法人` / `社会服务机构` / `股份有限公司` / `上市公司` / `事业单位` / `社会团体` / `基金会` / `机关法人` / `农村集体经济组织法人` / `城镇农村的合作经济组织法人` / `基层群众性自治组织法人` / `个人独资企业` / `合伙企业` / `不具有法人资格的专业服务机构` | 有限责任公司 |
| `ownership` | 所有制性质勾选项（自动打勾）：`国有` / `民营` / `其他` | 民营 |
| `rep_title` | 法定代表人职务（可选） | 总经理 |
| `phone` | 联系电话（可选） | |

## 委托诉讼代理人 `agent`

```json
{ "has": true, "name": "王五", "unit": "贵州某律所", "title": "律师", "phone": "139…", "authority": "特别授权" }
```
`has:false` 或省略时，保留模板原“有□/无□”选项不填。

## 要素章节 `sections`

键为**行首标签的子串**（模板中标签常含空格，脚本会自动去除空格再做包含匹配）；
值为要写入该单元格的文本（需自行带上 `☑` / `□` 标记）。常见键：

- 诉讼请求：`1. 本金`、`2. 利息`、`3. 是否要求提前还款或解除合同`、
  `4. 是否主张担保权利`、`5. 是否主张实现债权的费用`、`6. 是否主张诉讼费用`、
  `7. 其他请求`、`8. 标的总额`，以及自由表述摘要 `可完整表述诉讼请求`
- 约定管辖和诉前保全：`1. 有无仲裁、法院管辖约定`、`2. 是否已经诉前保全`
- 事实与理由：`1. 合同签订情况`、`2. 合同主体`、`3. 借款金额`、`4. 借款期限`、
  `5. 借款利率`、`6. 借款提供时间`、`7. 还款方式`、`8. 还款情况`、
  `9. 是否存在逾期还款`、`14. 是否签订保证合同`、`15. 保证方式` … `19. 证据清单`，
  以及自由表述摘要 `可完整表述纠纷`
- 对纠纷解决方式的意愿：`是否考虑先行调解`（等）

> 找不到匹配标签的行不会被改动；一个标签只匹配首个命中键。
