# 建设工程合同 / 装修合同 法律参考

## 适用法律
- 《中华人民共和国民法典》第七百八十八至八百一十八条（建设工程合同）
- 《中华人民共和国建筑法》（1997年，2019年修订）
- 《建设工程质量管理条例》（2000年）
- 《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》（2021年）
- 《建设工程施工合同（示范文本）》（GF-2017-0201）

---

## 一、建设工程合同必查要点

### 1.1 承包方资质（强制性要求）
- 施工企业必须具备**相应等级的建筑业企业资质证书**
- 特殊行业（消防、电气等）需相应专业资质
- **无资质或资质不符的合同无效**（民法典第 791 条）

### 1.2 工程转包与违法分包（第 791-794 条）
- **禁止**：总承包人将承包的工程整体转包给第三人
- **禁止**：分包给不具备资质条件的单位
- 违法分包/转包：合同无效，且承包人承担安全责任

## 二、工程款支付风险

### 2.1 付款节点与竣工结算
- 进度款支付节点必须**明确**（形象进度/时间节点）
- 竣工验收后结算款支付期限（建议：验收后 30-60 天）
- **竣工结算争议**：发包人在约定期限内不答复，视为认可承包人结算（司法解释第 21 条）

### 2.2 优先受偿权（民法典第 807 条）
- 建设工程承包人对工程折价/拍卖价款享有**优先受偿权**
- 优先于普通债权人，仅次于有担保债权
- 行使期限：**6 个月**（自竣工日或应当竣工日起算）

### 2.3 质量保证金
- 预留比例：工程款的 3%-5%（不超过工程价款的 3%，2022年后）
- 保证期限：缺陷责任期（一般 1-2 年）届满后退还
- 保证期满无缺陷应**无条件返还**

---

## 三、工程变更与签证

- **口头变更无效**：所有工程变更必须有书面签证
- 变更申请期限：发生后 X 天内提出，逾期视为放弃
- 签证单的审批流程和有权签字人必须明确
- 工程量增减超过合同金额 15% 时的价格调整机制

---

## 四、工程质量与验收

### 4.1 质量保修期（建设工程质量管理条例第 40 条）
| 部位 | 最低保修期 |
|------|-----------|
| 地基基础和主体结构 | 设计文件规定的合理使用年限 |
| 屋面防水、厨卫防水 | **5 年** |
| 供热/供冷系统 | **2 个采暖期/供冷期** |
| 电气管线、给排水管道 | **2 年** |
| 其他项目 | **2 年** |

### 4.2 装修合同特殊风险
- 装修公司资质：必须具备**装饰装修施工资质**
- 甲供材与乙供材：明确材料品牌、型号、质量等级
- 工程量清单：必须详细，防止追加费用
- 完工验收标准：参照国家标准或合同约定标准

## 五、常见高风险条款

| 条款内容 | 风险等级 | 建议处理 |
|---------|---------|---------|
| 施工方无相应资质 | 🔴高 | 合同无效，必须核资质 |
| 整体转包给第三方 | 🔴高 | 违法，明确禁止 |
| 结算款无支付期限 | 🔴高 | 明确验收后付款期限 |
| 质量保证金不返还条件苛刻 | 🟡中 | 约定客观返还条件 |
| 变更无书面签证流程 | 🟡中 | 约定书面变更确认机制 |
| 装修材料品牌可"同等替换" | 🟡中 | 明确具体品牌和型号 |
| 验收标准不明确 | 🟡中 | 约定参照国家标准 |
