# 股权转让合同 / 增资扩股协议 / 合伙协议 法律参考

## 适用法律
- 《中华人民共和国公司法》（2024年修订版）
- 《中华人民共和国合伙企业法》（2006年）
- 《中华人民共和国民法典》（合同编通则）
- 《最高人民法院关于适用公司法若干问题的规定（四）》

## 一、股权转让合同核心风险

### 1.1 转让限制（公司法第 84-88 条）
- **有限责任公司**：向股东以外的人转让股权，须经其他股东**过半数同意**
- 其他股东有**优先购买权**，同等条件下优先购买
- 转让未经董事会/股东会决议可能无效，须核查公司章程

### 1.2 股权权属核查
- 股权是否已**出质**（质押给他人）
- 股权是否被**司法冻结**
- 转让人是否已**足额缴纳出资**（未实缴部分的处理）
- 工商登记信息与实际情况是否一致

### 1.3 标的公司尽职调查
- 负债情况（包括**或有负债**：未决诉讼、税务争议、担保义务）
- 知识产权权属是否清晰
- 主要合同是否在股权变更时触发变更/终止条款
- 员工劳动合同是否连续，有无劳资纠纷

### 1.4 价格与支付
- 股权转让价格的确定依据（净资产/评估价/协商价）
- 分期付款的各期金额和时间节点
- 逾期付款是否触发股权回购

## 二、增资扩股协议核心风险

### 2.1 估值确认
- 投后估值的计算方式必须明确
- 投资款计入注册资本和资本公积的比例
- 增资后各方持股比例

### 2.2 对赌条款（回购条款）
- 业绩承诺的指标和计算方式（净利润/营收等）
- 未达标时的补偿方式（现金补偿/股份回购）
- 回购价格计算公式（通常为投资金额 + 利息 - 已分配利润）
- **股权回购向创始人的对赌有效，向公司的对赌可能违法**（公司法第 89 条）

### 2.3 反稀释条款
- 后续融资估值低于本轮时的股权调整机制
- 加权平均/完全棘轮条款的差异

### 2.4 投资人权利保护
- 信息权（定期财务报告、重大事项知情权）
- 共同出售权（跟售权）
- 优先分配权（清算优先权）
- 反稀释权

## 三、合伙协议核心风险（合伙企业法）

### 3.1 出资与利润分配
- 出资额、出资形式（货币/实物/知识产权/劳务）
- 利润分配比例（可与出资比例不同，但须明确）
- 亏损分担比例

### 3.2 合伙人责任
- **普通合伙**：合伙人对合伙债务承担**无限连带责任**（风险极高）
- **有限合伙**：有限合伙人以出资额为限（须严格遵守不参与管理）
- 有限合伙人参与管理视同普通合伙人，承担无限责任

### 3.3 退伙与解散
- 退伙条件和通知期限
- 退伙时财产份额的计算和支付
- 解散条件和清算程序

## 四、常见高风险条款

| 条款内容 | 风险等级 | 建议处理 |
|---------|---------|---------|
| 未经其他股东同意的对外股权转让 | 🔴高 | 须取得其他股东同意 |
| 向公司的股权回购对赌 | 🔴高 | 可能违反公司法，改为向创始人 |
| 未披露或有负债即签约 | 🔴高 | 设置承诺赔偿条款 |
| 对赌业绩指标定义不明确 | 🟡中 | 明确计算口径和审计方式 |
| 反稀释条款未约定触发条件 | 🟡中 | 明确触发条件和调整公式 |
| 退伙时财产计算方式不明 | 🟡中 | 明确评估方法和支付期限 |
