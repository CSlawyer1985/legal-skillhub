# 买卖合同 / 采购合同 / 销售合同 / 服务合同 法律参考

## 适用法律
- 《中华人民共和国民法典》第五百九十五至六百一十七条（买卖合同）
- 《中华人民共和国民法典》第七百七十九至八百一十七条（委托合同/技术服务等）
- 《产品质量法》（1993年，2018年修订）
- 《消费者权益保护法》（1993年，2013年修订）

---

## 一、买卖/采购合同必查要点

### 1.1 标的物描述（民法典第 598 条）
- 品名、规格、型号、数量必须**明确具体**
- 质量标准：国标/行标/企标/合同约定标准，必须明确
- 计量单位、计量方式必须明确

### 1.2 价格与支付（第 609-610 条）
- 价格是否明确（含税/不含税、运费包含情况）
- 支付方式（现金/转账/支票）、支付期限、分期付款安排
- 逾期付款违约金标准

### 1.3 交付（第 599-607 条）
- 交付时间、地点、方式（送货上门/自提/第三方物流）
- **风险转移时间点**：交付完成时风险转移给买方（第 604 条）
- 验收标准和验收期限（超期不异议视为接受）

## 二、关键风险条款

### 2.1 质量保证与验收
- 验收期限：**必须明确**（建议：到货后 X 个工作日内完成验收）
- 质量异议期限：超过异议期视为质量合格
- 隐蔽质量缺陷的处理：发现时起 X 日内提出
- 质保期：明确起算点和持续时长

### 2.2 违约责任
- 逾期交货违约金标准（通常为逾期金额的 0.1%-0.5%/天，上限 30%）
- 逾期付款违约金标准
- 质量不符合约定的处理：退货/换货/修复/减价

### 2.3 所有权保留（第 641 条）
- 采购方**付清全款前**，出卖人可约定保留货物所有权
- 影响：采购方破产时，出卖人可取回货物

### 2.4 不可抗力条款
- 应明确不可抗力的定义（自然灾害、政府行为、疫情等）
- 通知义务：发生后 X 天内书面通知对方
- 持续 X 天以上可解除合同

## 三、服务合同特殊风险点

### 3.1 服务内容与标准
- 服务范围必须**详细列明**（附件/清单）
- 服务质量标准：明确可量化的验收标准，不能仅用"令甲方满意"
- 服务人员要求（资质、人数、响应时间）

### 3.2 服务费用与结算
- 费用构成（人工费/材料费/差旅费）必须明确
- 结算时间节点（里程碑付款/完工付款/月结）
- 追加费用的审批流程和权限

### 3.3 知识产权归属
- 服务过程中产生的**技术成果、报告、文档**归属
- 使用权和所有权的区分
- 第三方工具/组件的许可证合规性

### 3.4 保密条款
- 服务商接触的客户数据、商业信息保密义务
- 保密期限（服务结束后延续 X 年）
- 违反保密的赔偿标准

## 四、常见高风险条款

| 条款内容 | 风险等级 | 建议处理 |
|---------|---------|---------|
| 验收标准由甲方单方认定 | 🔴高 | 约定客观可量化标准 |
| 所有知识产权归甲方（服务外包） | 🟡中 | 区分原有知识产权和新成果 |
| 违约金无上限约定 | 🟡中 | 设置合理上限（损失的30%） |
| 不可抗力条款过于宽泛 | 🟡中 | 明确列举具体情形 |
| "同类商品市场价"结算 | 🟡中 | 约定具体参考标准 |
| 无验收期限 | 🟡中 | 明确验收期，超期视为通过 |
| 产品规格描述模糊 | 🟢低 | 附上详细规格清单 |
