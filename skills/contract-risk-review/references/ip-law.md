# 保密协议 / 竞业限制协议 / 技术开发合同 法律参考

## 适用法律
- 《中华人民共和国劳动合同法》第 23-24 条（竞业限制）
- 《中华人民共和国反不正当竞争法》（2019年修订）
- 《中华人民共和国民法典》第八百五十一至八百八十八条（技术合同）
- 《中华人民共和国专利法》（2020年修订）
- 《中华人民共和国著作权法》（2020年修订）

---

## 一、保密协议核心风险

### 1.1 保密信息定义
- 保密信息范围必须**明确具体**（不能仅写"所有信息"）
- 建议明确列举：技术方案、源代码、客户名单、定价策略、商业计划等
- 排除条款（以下信息不属于保密信息）：
  - 公开发布的信息
  - 独立开发的信息
  - 从合法来源获取的信息

### 1.2 保密期限
- 商业秘密：建议约定长期保密（永久/合同终止后 X 年）
- 一般商业信息：通常 2-5 年
- 不得设置过短的保密期（如仅 1 年），无法充分保护

### 1.3 接收方义务
- 不得向第三方披露（须明确"第三方"的范围，包含关联公司吗？）
- 最小必要原则：仅向需要知晓的员工披露
- 员工也需签署保密协议
- 合同终止后的销毁/返还义务

### 1.4 违反保密的赔偿
- 需约定**明确的赔偿标准**（固定赔偿金或实际损失，选其高者）
- 反不正当竞争法第 17 条：实际损失 + 调查取证合理支出
- 权利人可申请法院禁止侵权

## 二、竞业限制协议核心风险

### 2.1 适用人员范围（劳动合同法第 23 条）
**只能**对以下人员约定竞业限制：
- 高级管理人员
- 高级技术人员
- 其他负有保密义务的人员

> ⚠️ 对普通员工设置竞业限制存在效力风险

### 2.2 经济补偿（必须支付）
- **每月不得低于劳动者离职前 12 个月平均工资的 1/3**（司法解释标准）
- 未约定补偿金额：劳动者可要求按 30% 月工资支付
- **不支付补偿金时，竞业限制协议对劳动者无约束力**

### 2.3 竞业限制期限（第 24 条）
- **最长不超过 2 年**
- 超过 2 年的部分无效

### 2.4 违约金标准
- 须与补偿金保持合理比例（通常为补偿金总额的 2-3 倍）
- 过高违约金法院可调减

## 三、技术开发合同核心风险

### 3.1 知识产权归属（民法典第 859-861 条）

| 情形 | 归属规则 |
|------|---------|
| 执行单位任务的职务发明 | 归**单位**所有 |
| 利用单位资源完成的发明 | 归**单位**所有（单位可约定报酬） |
| 纯个人行为的发明 | 归**个人**所有 |
| 委托开发 | 默认归**受托方**，可约定归委托方 |
| 合作开发 | 归**合作方共有**，可约定 |

> ⚠️ 委托开发合同**必须明确约定**知识产权归属，否则默认归受托方

### 3.2 技术开发合同必查条款
- 开发目标（可验收的技术指标）
- 里程碑和验收标准
- 技术交付物（源代码/文档/设计图纸）的交付要求
- 测试环境和验收流程
- Bug 修复义务和维护期

### 3.3 技术秘密保护
- 受托方接触的技术信息保密义务
- 研发人员离职后的保密约束
- 第三方工具/开源代码的使用合规性（GPL等开源协议风险）

### 3.4 开发失败的风险分配（第 855 条）
- 风险承担方（委托方/受托方/共担）
- 已发生费用的分摊
- 合同解除条件

## 四、常见高风险条款

| 条款内容 | 风险等级 | 建议处理 |
|---------|---------|---------|
| 竞业限制无经济补偿 | 🔴高 | 无效，必须约定补偿 |
| 委托开发未约定知识产权归属 | 🔴高 | 默认归受托方，须明确 |
| 保密范围为"所有信息" | 🟡中 | 明确具体范围 |
| 竞业限制超过2年 | 🟡中 | 超出部分无效 |
| 验收标准不明确 | 🟡中 | 约定可量化指标 |
| 开源组件使用未声明 | 🟡中 | 梳理开源协议合规风险 |
| 保密期限过短（<2年） | 🟢低 | 延长至合理期限 |
