# 条件性正式质证意见生成门

- document_id: `GATE-01`
- layer: `GATE`
- audience: `承办律师团队`
- filing_status: `DISABLED-NO-OPPONENT-EVIDENCE`
- required_gates: `P0-1, P0-3, FORMAL-CROSS-GATE`
- required_law_source_ids: `LAW-006`

## 控制字段

- 模式：【production-intake / retrospective-benchmark】
- 主路由：【ordinary-goods-sale / installment-title-retention / mixed-cause-boundary / HOLD-ROUTE】
- SSOT 冻结版本：【待核】
- court_profile_id：【COURT-PROFILE-SALES-2025-GENERIC】
- 法源层：【current_law_layer / cutoff_law_layer】
- 总体门禁：【PASS / HOLD / FAIL】

## 正文占位

本模板的 DOCX 版本提供可编辑结构。所有事实、证据、金额、条款、页码、计算和法源适用结论均须从冻结 SSOT 派生；未知或冲突项目保持 HOLD。

## 禁区

- 不得写入原始案卷、真实身份映射、答案键、历史结局、凭证、令牌或本机绝对路径。
- 不生成执行程序文书。
- 未收到并登记对方证据时，不生成正式质证意见。
