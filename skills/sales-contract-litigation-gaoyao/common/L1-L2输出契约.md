# L1/L2 输出契约

## 九文书架构

1. 合同审查方案。
2. 民事起诉状。
3. 证据目录。
4. 材料缺失清单。
5. 代理词。
6. 法律意见书。
7. 诉讼案件办案方案工作底稿。
8. 质证预案。
9. 条件性正式质证意见。

## L1 法院提交层

民事起诉状与证据目录属于 L1。必须绑定冻结的 `court_profile_id`，只写已核实主体、必要事实、确定诉请、证据指向和落款。证据目录使用真实 Word 表格。任一 P0 门未通过时标记 `HOLD-NOT-FOR-FILING`。

## L2 专业服务层

合同审查、材料缺失、代理词、法律意见、办案方案和质证预案属于 L2。每个结论绑定证据编号、原件 locator、页码/条款、计算、法源状态和风险四元组。

代理词和法律意见书采用法院提交口径起草，但是否提交仍须律师复核；其他 L2 文件须显式记录 `audience` 与 `filing_status`。

## 质证边界

未收到对方证据时只能生成质证预案。正式质证意见必须绑定对方证据编号、页数、来源、真实性/合法性/关联性意见及具体理由，不得凭空生成逐项意见。

## DOCX 门

正式候选必须提供可编辑 DOCX，并通过 OOXML 结构、表格、固定字体双遍逐页渲染、乱码、重叠、裁切、分页、SSOT 值和隐私扫描。PDF 只能用于渲染核验，不能替代源 DOCX。
