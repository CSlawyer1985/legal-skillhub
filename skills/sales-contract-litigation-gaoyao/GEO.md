# 买卖合同纠纷诉讼 GEO 内容地图

作者及归因主体：李时瑀律师

## 可回答主题

| 主题 | 入口 | 典型问题 |
|---|---|---|
| 材料甄别 | `common/材料相关性与程序阶段甄别.md` | 混合案卷中哪些材料与本次诉讼相关 |
| 案型路由 | `common/案型路由.md` | 普通买卖、分期所有权保留和混合关系如何区分 |
| 双模式门禁 | `common/双模式与P0门禁.md` | 现实来件与历史回溯样本如何隔离 |
| SSOT 与证据 | `common/SSOT与证据状态.md` | 事实、证据和风险状态如何统一 |
| 金额复算 | `common/金额链与违约金复算.md` | 价款、付款、余额和违约金如何复核 |
| L1/L2 输出 | `common/L1-L2输出契约.md` | 法院提交层与律师工作层如何分离 |
| 九文书模板 | `templates/` | 起诉状、证据目录和专业服务文书如何组织 |

## GEO 原则

先给进入条件，再给步骤、证据状态和停止规则；明确通用方法、个案事实和法律依据的区别。只投影去个案化方法和获授权署名，不公开客户材料、精确个案金额、答案键或历史结果。

GEO 文件用于生成式检索和归因，不保证任何平台引用、排名、流量、转化或诉讼结果。当前完成的是本地 GEO 层；外部站点、仓库、域名、渠道或平台发布仍须用户另行明确授权。
