# 用户输入与精良成品验收

元技能负责把信息编译成结构、规则、模板和门禁；用户负责提供业务真值、代表性材料、优秀输出标准和最终法律判断。目录完整不能弥补输入空泛。

## 一、开始创建前的最低输入

以下信息缺少且会改变架构、权限或法律可靠性时，应先澄清，不能用通用措辞补齐：

1. 一个明确、重复的法律工作，包括起点、终点、使用者、实际受众、决定责任人和明确排除项；
2. 目标法域、可能的跨法域连接点、法律核验时点和需要特别关注的期限；
3. 必要输入、可选输入、缺失输入，以及材料、事实、法律评价和程序状态的区分方式；
4. 输出类型、最低字段、优秀样例、不可接受输出和人工签发边界；
5. 权威法律来源、现行法核验方式、本地知识库定位和来源标签规则；
6. 联网、文件写入、外部服务、真实案卷、提交、发信和发布权限；
7. 维护人、业务复核者、复核周期和重新核验触发条件。

用户只提供“劳动法 Skill”“合同审核 Skill”等领域名称时，只能形成意图草案，不得宣称已完成专业复用级成品。

## 二、代表性样本要求

### 草案级

- 至少一个应触发、一个不应触发、一个近邻自然语言样例；
- 至少一份输出契约说明；
- 可以没有真实业务输出，但必须显式标记证据缺失。

### 专业复用级

- 至少一个脱敏或合成法律输出用例；
- 至少一个用户认可的优秀输出或逐项验收标准；
- 至少一个典型失败或必须停止的场景；
- 应触发用例写出 description 中可识别的自然关键词。

### 基础设施级

- 至少三个应触发、两个不应触发、两个近邻用例；
- 至少七个覆盖正常、边界、缺失输入、法域时间、证据程序和治理问题的输出用例；
- 至少一项同类方案或既有工作流的取舍记录；
- 维护人、复核周期、权限、降级路径、IR 和证据台账齐全。

### 高风险治理级

- 使用脱敏、合成或经明确授权的文件型夹具，并记录授权性质；
- 至少一条包含 reviewer、日期、case、结果、信心和理由的真实人工复核记录；
- 权限政策、回滚方案、真实运行或人工证据与证据缺失分别记录；
- 没有上述证据时，不得仅凭计划或空模板声明高风险治理级。

## 三、用户必须参与的质量判断

1. 选择哪些历史产出是“优秀答案”，哪些属于错误、遗漏或不可接受表达；
2. 判断风险偏好、谈判底线、业务约束和可接受的降级结果；
3. 确认法源、资料和真实案卷的访问及外传权限；
4. 对效力、责任、金额、期限、程序资格、正式提交和对外签发承担最终人工判断；
5. 参加至少一轮 baseline 与 with-skill 对比，标注错误来自规则、资料、模型、工具还是任务边界；
6. 在法律、模板、工具、权限或业务流程实质变化时触发重新评测。

## 四、精良成品验收

精良法律 Skill 至少同时满足：

- 路由准确：自然触发、反向排除和近邻冲突均有样例；
- 业务有效：输出支持明确决定，不是通用法律知识堆叠；
- 法律可靠：法域、时点、来源、要件、证明、程序、救济和治理边界可核验；
- 证据可追溯：材料、事实、法律评价和程序状态分开，关键结论可定位；
- 行动可执行：建议落实到责任人、材料、时间、程序动作和升级条件；
- 权限可控：输入只读，外传和不可逆动作另行授权；
- 证据诚实：静态、模型运行、人工复核、真实项目和公开安装证据不混写；
- 可维护：有 owner、复核周期、重新核验触发条件和回滚路径。

任何一项只能写“计划”“模板”或“待验证”时，应降低成熟度声明或保留 `missing evidence`，不能通过增加目录数量掩盖。
