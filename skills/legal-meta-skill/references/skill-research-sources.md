# 同类 Skill 研究来源

本指南用于发现和比较同类 Skill，不构成安装清单或运行依赖。研究时使用宿主已经具备的只读网页、GitHub 或本地检索能力；不得为了发现候选方案而安装或调用 discovery Skill。

## 来源与职责

| 来源 | 主要用途 | 证据边界 |
|---|---|---|
| [Legal SkillHub](https://skill.chenshi.ai/) | 优先发现法律垂直领域和中文法律表达下的候选 Skill | 聚合页用于发现；能力与安全结论仍回到原始仓库核验 |
| [GitHub](https://github.com/) | 查找规范来源、原始仓库、许可证、提交记录、问题单、脚本和评测 | 仓库存在不等于质量可靠；必须核对具体 Skill 路径和版本 |
| [skills.sh](https://www.skills.sh/) | 发现国际社区常见 Skill、分类和采用信号 | 排名与安装量只作线索，不作为法律质量或安全证明 |
| [SkillHub 中文社区](https://skillhub.cn/) | 发现中文场景、中文说明和本地化候选方案 | 聚合说明或安全报告需与原始仓库和本地静态审查交叉验证 |

## 中英文分路检索

1. 先从目标任务提取 2—4 个中文意图词，例如“合同审查、证据映射、法规核验、诉讼策略”。
2. 再独立生成 2—4 个英文意图词，例如“contract review, evidence mapping, legal authority verification, litigation strategy”。英文词不是中文结果的机械翻译，应覆盖国际社区常用表达。
3. 在法律垂直平台、中文社区、国际目录和 GitHub 分别检索；中文结果与英文结果先分开记录，再合并比较。
4. 按“原始仓库地址 + Skill 相对路径”去重；同一仓库的镜像、聚合页和转载不重复计为独立方案。
5. 搜索词不得含客户名称、真实案号、当事人身份、未公开交易信息或案卷原文。

## 只读审查顺序

1. 阅读入口 `SKILL.md`、manifest、interface 和目录结构。
2. 阅读许可证、维护状态、最近变更和公开问题。
3. 静态阅读脚本、依赖声明、安装钩子、网络端点、写入范围和权限要求。
4. 阅读触发用例、输出评测和失败路径，区分作者声明与可复核证据。
5. 用“直接纳入 / 转化后纳入 / 明确不纳入 / 针对缺口新增”记录结论，并标注设计优势、已验证优势、假设或证据缺失。

研究阶段不得克隆后自动安装、导入包、执行脚本、运行安装钩子或打开陌生程序。确需动态验证时，必须由用户另行明确授权，并先完成来源、许可证、权限和入口审查；随后仅在临时隔离环境中使用合成数据，禁止真实密钥和案卷材料，限制网络、写入范围与超时，并保留执行记录。

## 降级与停止路径

- 无网络或目标站点不可用：继续使用目标包、用户提供资料和本地已有候选；在交接中标注哪些平台未核验及其影响。
- 只能看到聚合页、无法定位原始仓库：可以记录为发现线索，但不得作为采用证据。
- 许可证缺失、权限过宽、脚本不可读或维护状态不明：默认明确不纳入；不得以高安装量覆盖该缺口。
- 法律依据研究必须另走法律来源核验流程；上述平台只研究 Skill 机制，不证明法条、案例或法律结论有效。

## 领域方法论研究（第 3 层提问的兜底来源）

当目标领域超出包内场景原型与规则的覆盖（原型为 `other`，或原型虽有但领域专项角度不足）时，可在创建期研究权威法律来源，提取该领域"应关注的角度、方法与底线"，转化为意图阶段的第 3 层问题。本研究区别于上文的同类 Skill 机制研究：对象是法律方法论，不是 Skill 方案。

来源分级（高到低，低层级不得对抗高层级）：

1. 最高人民法院司法解释、司法解释理解与适用、审判实务丛书、会议纪要及其理解与适用；
2. 指导性案例、公报案例、典型案例及官方答记者问；
3. 权威实务出版物、头部律所或专业机构的方法论文章；
4. 普通网络文章——仅作线索，不得作为问题设计依据。

规则：

- 须用户明确授权联网；使用宿主已有的只读检索能力，不安装、不执行陌生代码。
- 研究只发生在创建期；提取的问题与结论须内化进目标 Skill 包（写入 intake 的 `domain_supplement` 或目标包 `references/`），不得把在线来源写成运行时依赖。
- 每个研究得来的问题须记录来源（`authorized-research`）并在交接中提示人工确认；来源只覆盖到"应问什么"，具体法条、口径和结论仍在目标 Skill 运行时独立核验。
- 无法联网或来源不足：以包内通用规则和原型兜底，并在交接中如实记录证据缺失；不得用模型常识编造领域方法论。
