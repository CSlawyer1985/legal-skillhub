# DOCX 审阅、修订与批注场景检查清单

适用于合同、法律文书和其他 DOCX 文件的审阅、修订、批注及版本交付。

## 基准文件与版本

- [ ] 原始 DOCX 以只读方式保存，未被覆盖或重命名丢失
- [ ] 新建独立版本副本，并记录源文件、目标文件、版本号和哈希
- [ ] 输出明确区分内部审阅版、清洁版和最终分发版

## 修订与批注

- [ ] 插入、删除、格式修改使用可复查的 Track Changes 或等价修订记录
- [ ] 重大判断、法律依据、待确认事项使用批注留痕
- [ ] 批注作者、时间、锚点、修订数量和批注数量均可核对
- [ ] 中文跨 run 文本、WPS 兼容性和编号连续性已检查
- [ ] 接受或拒绝修订前保留原始审阅版，禁止静默合并

## OOXML 与视觉检查

- [ ] DOCX ZIP 完整，关系文件、编号、样式和批注部件可解析
- [ ] 能渲染时检查分页、表格、页眉页脚、批注标记和修订显示
- [ ] 不能渲染时明确记录限制，不把 XML 校验当作视觉通过
- [ ] 元数据清理只作用于最终分发副本，不破坏内部审阅证据

## 法律与交付边界

- [ ] 每个修改可追溯到条款、材料、法律依据或用户指令
- [ ] 事实、法律评价、修改建议和待确认事项分层
- [ ] 未经责任人复核不得对外签发、发送或覆盖基准文件
