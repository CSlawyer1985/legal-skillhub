# 合同审查场景检查清单

适用于合同、协议、交易文件的风险审查与修改建议。本清单叠加在十二模块最低契约之上；具体法条与监管口径须运行时独立核验。

## 前提

- [ ] 已问清交易背景、商业目的与所代表的一方立场；信息不全时书面声明审查前提
- [ ] 识别交易类型与适用法律关系（先定性，穿透合同名称看权利义务实质）

## 查漏（双弦结构 + 四法）

- [ ] 正常交易安排弦：主体、标的、价格、支付、交付、验收、开票、通知送达
- [ ] 意外预防安排弦：违约、解除、不可抗力、争议解决、保密、知识产权、合规
- [ ] 时间顺序法：按交易履行时间轴逐节点核对
- [ ] 办事流程法：按实际操作流程核对可落地性
- [ ] 权利义务对等法：逐条核对双方权利义务是否失衡
- [ ] 假设法：假设各环节出问题时合同是否有答案

## 风险与修改

- [ ] 重要性原则：先抓最大风险，不以面面俱到代替重点
- [ ] 每条风险写明类型、触发条件、后果、概率/敞口、可规避性
- [ ] 违约条款可执行性终检：违约责任能否在诉讼/仲裁中实际落地
- [ ] 修改建议分必须/建议/可选三级，并给可谈判替代方案
- [ ] 检查条款一致性（专用条款与通用条款、正文与附件、前后文引用）
