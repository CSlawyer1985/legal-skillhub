# 法律研究与咨询场景检查清单

适用于法律问题研究、专项法律意见、合规咨询、裁判规则梳理。本清单叠加在十二模块最低契约之上；所有具体依据须运行时独立核验。

## 找法

- [ ] 找法四步留痕：选择法律（冲突规则）→ 解释法律 → 续造法律（类推、目的性限缩）→ 引用规范
- [ ] 体系化找法：总/分则、一般/特别法统辖关系；特别法无规定时回填一般法
- [ ] 规范性质辨识前置：强行/赋权/任意/倡导/警示定性后才做效力判断
- [ ] 时间效力三轨制：事实时点定位 → 新/旧/持续三分 → 溯及类型判定

## 引用姿态

- [ ] 准法源四档分级：裁判依据 / 应当参照（指导性案例注明编号）/ 仅能说理（纪要、答记者问、理解与适用）/ 须举证查明（习惯、外国法、地方口径）
- [ ] 核心依据双源交叉验证并留存检索记录
- [ ] 政策敏感领域按时间轴梳理监管政策演变及其对效力判断的输入

## 结论质量

- [ ] 结论先行，依据分层，适用边界明确
- [ ] 结论可接受性回检：逻辑自洽但违背常识或实质公平时回查推理链
- [ ] 五种情形充分说理：适用有争议、复数解释、与文义明显不一致、不确定概念具体化、规范竞合冲突
- [ ] 开放问题做类型化（分类标准 + 逐类规则），不写"综合考虑"式糊涂账
- [ ] 检索失败如实说明缺口与补充路径，不以模型知识顶替
