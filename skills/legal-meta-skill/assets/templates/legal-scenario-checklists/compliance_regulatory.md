# 合规与监管场景检查清单

适用于合规义务识别、监管检查应对、整改方案、合规监测。本清单叠加在十二模块最低契约之上；监管规则与口径须运行时独立核验。

## 规范覆盖

- [ ] 多层级规范逐层识别：法律、行政法规、司法解释、部门规章、自律规则、监管政策、地方口径
- [ ] 层级口径不一致时显式披露冲突与选择依据，不悄悄选用有利口径
- [ ] 存疑从严：规则不明确或监管态度含糊时按从严口径处理并书面声明
- [ ] 规章违规经公序良俗等通道影响民事效力时充分说理

## 动向与时点

- [ ] 跟踪监管动向（答记者问、征求意见稿、执法与处罚案例）并标注知识时点
- [ ] 政策时间轴：政策敏感领域按时间轴梳理监管演变
- [ ] 监测类任务声明监测时点、数据来源与下次核验触发条件

## 整改落地

- [ ] 义务清单逐项完整：义务—来源—适用条件—现状—缺口—整改动作
- [ ] 每项整改落到责任部门、时限、所需材料与验证方式
- [ ] 风险分级与整改优先级明确；区分法律后果与商业/操作摩擦
- [ ] 识别违规的民事效力后果、行政责任与信用影响的完整后果链

## 边界

- [ ] 不把一次性合规意见当作持续监测结论
- [ ] 涉及执法调查、听证、处罚程序时启用程序模块专项检查
