# 法律检索与知识管理场景检查清单

适用于法规检索、类案检索报告、裁判规则提炼、法律知识库构建。本清单叠加在十二模块最低契约之上。

## 检索质控流程

- [ ] 法条识别：全称、文号、制定机关、公布与施行日期；区分司法解释、批复、规范性文件
- [ ] 效力甄别四问：文本真实准确；现行有效；对本事项有效力；时间效力覆盖本案事实时点
- [ ] 规范冲突按冲突规则处理并说明理由
- [ ] 核心依据至少两个独立来源交叉验证
- [ ] 检索留痕：检索式、数据库、时点、命中与未命中均可复核

## 类案检索报告

- [ ] 素材三核验：裁判已生效（一审须查二审结果）；未被再审或撤销程序推翻；全文无对本方不利风险内容
- [ ] 精选排序五维：效力层级、地域、时间、程序、背景；同争点 3-5 个为宜，不以数量压势
- [ ] 开篇即给检索结论并落到本案处理建议
- [ ] 不利类案显式处理（事实差异、已被修正、地域局限），不隐藏
- [ ] 指导性案例只作裁判理由引述并注明编号；案例不作裁判依据引用

## 来源标注

- [ ] 每项来源标注类型与核验状态标签（法条原文 / 裁判文书 / 权威数据库检索 / 本地知识库 / 联网检索—需复核 / 已验证—日期）
- [ ] 区分"规范文本"与"实务做法"，提示地域差与时间差
- [ ] 检索失败或未命中如实说明缺口与补充路径
