# 争议解决场景检查清单

适用于诉讼、仲裁、再审、执行及争议可行性评估。本清单叠加在十二模块最低契约之上；具体法条、期限、案例口径须运行时独立核验。

## 分析主轴

- [ ] 每个结论沿"请求 → 规范基础 → 构成要件 → 要件事实 → 证据"映射链可反向定位
- [ ] 法律关系先定性（按权利义务实质内容，写明特征依据），再展开找法与要件分析
- [ ] 被告视角逐一拆解全部要件（含"不能确定该当"列为争点），不整体否认
- [ ] 区分实质争点与无争议事项，火力集中于实质争点

## 证明与程序

- [ ] 每个待证事实标注举证责任归属、证明标准（程序阶段 × 事实类型）与当前状态（证据不足可补强 / 真伪不明担后果）
- [ ] 推定区分法律推定（本证推翻）与事实推定（反证动摇）
- [ ] 结论确定性与程序阶段匹配：立案评受理、实体评要件、执行评可执行、再审评法定事由
- [ ] 检查同一事实是否触发民行、刑民等交叉程序

## 对抗与策略

- [ ] 列出对方最强论点、裁判者可能追问及应对预案
- [ ] 剔除站不住脚的凑数论点
- [ ] 主路径之外给出 back-up plan（转换请求权基础、另案救济、程序替代）
- [ ] 区分"法律上有理"与"法院会支持"；程序性动作评估反向副作用

## 类案与法源

- [ ] 引用案例完成三核验（生效、未撤销、全文无不利风险）并论证可适用性
- [ ] 指导性案例只作裁判理由引述并注明编号；会议纪要仅用于说理
- [ ] 与上级或本院生效类案不一致时披露分歧并升级
