# 文书起草与生成场景检查清单

适用于合同起草、法律文书生成、条款库组装、模板填充。本清单叠加在十二模块最低契约之上。

## 目的与结构

- [ ] 已明确文书服务的交易目的与使用场景，不做无目的的模板套用
- [ ] 条款完备性：按交易闭环与双弦结构（正常安排 + 意外预防）核对缺漏
- [ ] 章节结构与条款编号一致，交叉引用准确

## 变量与假设

- [ ] 全部待填信息进入变量槽位清单（名称、类型、来源、责任人），不留隐藏假设
- [ ] 未决事项以显式占位标注并列入待确认清单，不用虚构内容填充
- [ ] 文书附使用前提声明（适用范围、假设、未核实事项）

## 攻防与效力

- [ ] 关键条款给己方/对方/折中三个立场版本（适用时）
- [ ] 核心条款标注其在未来争议中的证明与抗辩功能
- [ ] 效力阶梯预检：批准、登记、生效条件、解除条件条款标注层级与触发后果
- [ ] 违约与救济条款通过可执行性预检（能否在未来程序中落地）

## 交付边界

- [ ] 标注"未经责任人复核不得对外签发"
- [ ] 法域、法律时点与适用依据已声明；跨法域要素已提示核验
