## 【作品简介】

本作品是一款面向中国刑事辩护场景的AI专业辅助工具，基于《刑法》《刑事诉讼法》及现行有效司法解释（动态更新），为刑事案件提供科学化、可解释的量刑预测与全流程辩护策略支持。

**核心功能**包含六大模块：①量刑预测——采用五步计算法（含基准刑锚定优先级链与规范时效核验），结合三层情景预测，输出可解释刑期区间；②缓刑评估——量化评分模型生成缓刑适用性分析与补强建议；③辩护策略——覆盖侦查至减刑假释全流程行动清单；④证据分析——控方证据漏洞排查与非法证据排除路径；⑤协商策略——认罪认罚最优路径与谈判要点；⑥风险评级——红/橙/黄/绿四级综合风险画像。

**作品亮点**：①可解释性强——五步计算法使AI预测过程透明可追溯；②三层情景预测——充分考虑司法实践不确定性；③踩坑经验库——总结实务常见量刑计算陷阱与定罪认定误区；④地域覆盖广——含31个省市量刑数额标准，区分特殊区域规则；⑤持续迭代——设"补充记录区"与"更新日志"；⑥扩展性强——即便针对未覆盖罪名，亦可依托五步计算法框架与基准刑锚定优先级链，强制检索最新司法解释与地方细则，实现准确预测；⑦规范时效硬核验——每次分析实时核验"现行有效+最新版本"，禁止凭记忆引用阈值。

**使用场景**：当事人及家属可快速估刑、了解案件走向，避免因信息差被误导；刑事辩护律师可获取量刑预测参考与辩护要点，提升工作效率；公检法人员可作为办案参考，促进司法尺度统一。

## 6. 受贿罪 / 贪污罪（刑法第382、385条）

### 法律依据

- 《刑法》第382条（贪污罪）、第385条（受贿罪）
- 《关于办理贪污贿赂刑事案件适用法律若干问题的解释（一）》（2016年）
- 《关于办理贪污贿赂刑事案件适用法律若干问题的解释（二）》（法释〔2026〕6号，2026年5月1日施行）

### 数额标准（全国统一）

| 档次                 | 数额      | 法定刑                         |
| ------------------ | ------- | --------------------------- |
| 数额较大 / 有其他较重情节     | **3万元以上** | 3年以下有期徒刑或者拘役，并处罚金           |
| 数额巨大 / 有其他严重情节     | **20万元以上** | 3年以上10年以下有期徒刑，并处罚金或没收财产     |
| 数额特别巨大 / 有其他特别严重情节 | **300万元以上** | 10年以上有期徒刑、无期徒刑或死刑，并处罚金或没收财产 |

> ⚠️ **终身监禁制度**（刑法第383条第4款）：\
> 数额特别巨大，对国家和人民利益造成特别重大损失，判处死刑缓期执行的，可以同时决定终身监禁。

> ⚠️ **司法解释二新增认定规则**：\
> - 斡旋受贿：明知请托人有不正当请托事项而收受财物，视为"承诺谋取不正当利益"\
> - 预期收益型受贿：按案发时实际获利认定数额；未实际获利的按案发时市场价格与支付价格的溢价认定

### 量刑计算参考

以第二档"数额巨大"为例（销售金额25万以上）：

**基准刑起点**：约5年（60个月）

**从宽情节及减刑幅度**：

| 情节       | 减刑幅度         | 备注                  |
| -------- | ------------ | ------------------- |
| 认罪认罚    | 10%～30%       | 越早认罪认罚，幅度越大        |
| 退赃退赔    | 5%～30%        | 全额退赔可争取高幅度         |
| 取得谅解    | 5%～25%        | 书面谅解书是关键筹码         |
| 初犯偶犯    | 5%～10%        | —                   |

**三层情景预测**（以基准刑60个月计算）：

| 情景       | 计算                          | 预测刑期      | 缓刑可能 |
| -------- | --------------------------- | --------- | ---- |
| 乐观情景   | 全额退赃+谅解+认罪认罚均被采纳（合计约-60%）   | ≈24个月   | ✓ 可争取 |
| 基准情景   | 主要情节被采纳（合计约-55%）            | ≈27个月   | ✓ 有希望 |
| 保守情景   | 情节打折（合计约-25%）                | ≈45个月   | ✗ 无望  |

### 缓刑适用要点

- **硬门槛**：必须判处3年以下有期徒刑
- **关键**：将刑期压到3年以下，缓刑才有可能
- **东莞地区提示**：广东一类地区对知识产权犯罪缓刑适用相对谨慎，书面谅解书是关键筹码

### 销售金额 vs 违法所得

| 概念       | 含义                  | 用途           |
| -------- | ------------------- | ------------ |
| 销售金额   | 已售出商品的总价款           | 定罪量刑的基准      |
| 违法所得   | 销售金额 - 进货成本（即利润）    | 仅用于没收/追缴     |

> 依据：2004年两高司法解释第9条——"销售金额"是指销售假冒注册商标的商品后所得和应得的全部违法收入，不扣除成本。

### 刷单金额的处理

- 刷单支出是经营成本，**不能从销售金额中扣除**
- 但若销售额中含有刷单产生的**虚假交易流水**，这部分并非真实销售收入，**应当申请从销售金额中剔除**

### 库存货值的影响

- **对量刑档次**：已销售达到25万"数额巨大"门槛后，库存不影响档次认定
- **对罚金数额**：库存大说明犯罪规模大，法官在法定幅度（销售金额50%～200%）内倾向于取较高倍数

# 第二部分：量刑情节调节参数库与计算规则（v3.0 重构）

> ⚠️ **v3.0 核心重构**：本部分将量刑情节按"修正/一般"二分，并配套计算公式与效果域矩阵，杜绝"所有情节混层加减/全连乘"的计算错误。**AI 在每次分析时，须先完成全部情节的"修正/一般"分类，再套用对应公式。**

## 一、量刑情节分类体系（四维度，AI 必须先行标注）

**维度1：修正量刑情节 vs 一般量刑情节（决定计算顺序与公式）**
- **修正量刑情节（先处理，参与基准刑构造，采用连乘法）**：
  犯罪预备、犯罪未遂、犯罪中止、从犯、胁从犯、教唆犯、未成年人、已满75周岁老年人、限制行为能力的精神病人、又聋又哑的人或者盲人犯罪、防卫过当、避险过当
- **一般量刑情节（后处理，在基准刑上乘减，采用连加法）**：
  累犯、自首、坦白、立功、和解、赔偿（退赃退赔）、认罪认罚

**维度2：法定情节 vs 酌定情节**
- 法定：法律明文规定（从轻/从重/减轻/免除均有条文依据）
- 酌定：法官自由裁量参考（见第五部分枚举清单）

**维度3：应当 vs 可以**
- 应当：法院必须适用；可以：法院有裁量空间

**维度4：效果域（从轻/从重/减轻/免除）**
- 从轻/从重 = 同一法定刑档位内上下浮动；减轻 = 降到更低一档法定刑（可破下限）；免除 = 免予刑事处罚；缓刑 = 执行方式而非量刑情节
- 同一法定情节可能有多种效果可选（如从犯 = {从轻, 减轻, 免除} 三选一），**禁止简化为单一固定乘数**

## 二、计算公式体系（强制，禁止混用）

```
公式一·同类特别（仅修正情节）→ 连乘法：
  调整后基准刑 = 基准刑 × (1 ± 特别情节A比例) × (1 ± 特别情节B比例)

公式二·同类一般（仅一般情节）→ 连加法：
  调节后基准刑 = 基准刑 × (1 ± 一般情节A比例 ± 一般情节B比例)

公式三·混合（修正+一般同时存在）→ 先乘后加：
  宣告刑预报 = 基准刑 × (1 ± 特别A) × (1 ± 特别B) × (1 ± 一般A ± 一般B)
```
**【禁止规则】**：① 一般情节禁止写成连乘因子；② 修正/一般情节禁止混在同一层级做简单加减；③ 计算前必须完成"修正/一般"分类。

> ⚠️ **计算顺序铁律**：修正情节（第三部分·步骤三第一轮·连乘）必须先于一般情节（第二轮·连加）处理；二者不得混层。

## 五、酌定量刑情节枚举清单（9类，逐案对照，不写死乘数）

1. 犯罪的动机
2. 犯罪的手段
3. 犯罪的时间、地点、工具、方法
4. 犯罪结果
5. 犯罪对象
6. 犯罪分子的一贯表现

→ 在报告中逐条对照本案事实，标注是否有利被告，作为「待确认事项/从宽主张」呈现，**不写死乘数、不替律师定性**。

## 0. 基准刑锚定优先级链与规范时效性硬规则（Module F，强制）

> 🛑 **本规则为 v3.0 新增，旨在根治"凭记忆引用/相对滚动估算"类错误。凡确定基准刑、引用任何规范，必须执行。**

**【基准刑锚定优先级链】**（禁止仅用案例反推、禁止基于上一版预测值相对滚动加减）
1. 国家级通用框架：2021《关于常见犯罪的量刑指导意见（试行）》(法发〔2021〕21号) Part III 常见量刑情节（自首/认罪认罚/累犯等乘数，适用所有罪）
2. 国家级专项规范：若罪名在《量刑指导意见（二）》七罪之列 → 采用其量刑起点幅度；**须核验当前是否仍现行有效**
3. 司法解释：法释〔2017〕10号等（现行有效）
4. 地方实施细则：按案件省份检索省级法检细则（如广东 粤高法发〔2017〕7号等）
5. 同类判例：仅作**独立校验项**（即"区间校验/尺度参考"），**禁止作为基准刑的计算依据或锚定来源**——判例的作用是交叉验证 Module F 前述层级得出的基准刑是否合理，而非反推基准刑。引用判例须标注：参考地、涉案金额/情节、认定档次、宣告刑、关键从宽/从重情节，供律师独立判断。

**【规范时效性硬规则】**
- 凡定基准刑/引用规范，必须先核验「现行有效」，引用须标注 **doc_no + 时效 + 检索日期**
- 凡标注「试行」且有明确试行期的规范，期满即失效，即使数据库标"现行有效"也**禁止引用**
- **禁止凭训练记忆直接引用任何数额标准/情节比例**
- **数据源优先级**：① Alpha Lawyer（首选，待链接 MCP）→ ② 北大法宝 + 华宇元典法律数据（当前已连）交叉核验 → ③ 三者皆无则联网搜索核验国家级通用量刑指导意见及地方专项罪名细则
- 凡分析时点半年内有新规范可能影响本案，须**主动提示用户**

## 0.5 金额临界分叉预测规则（Module G，强制护栏）

> 🛑 **本规则针对"涉案金额/情节接近升档门槛且存在争议"的高发错误场景。触发时 AI 必须执行分叉预测，禁止统一锚定单一基准刑。**

**【触发条件】**：涉案金额/情节数量接近某一量刑档次的升档门槛（如抽头渔利接近3万、盗窃数额接近数额巨大标准），且控辩双方对是否达门槛存在分歧、或证据本身不足以精确认定。

**【强制动作】**：
1. **分叉为两条独立预测路径**，各自完整走五步法：
   - 路径A（未达门槛）：按较低档次法定刑预测
   - 路径B（已达门槛）：按较高档次法定刑预测
2. **两条路径分别给出基准刑、情节调节、三层情景与宣告刑校验**，不得只把另一档作为"风险场景"一笔带过。
3. 在报告【量刑预测】栏并列呈现两条路径结果，并标注法院最终可能认定的关键变量（如金额认定口径）。
4. 若控方指控已达高档、辩方主张未达，须以"辩方成立所需压低至何值"为辩护主攻点单列。

**【禁止规则】**：
- ✗ 禁止在金额是否达门槛未明时，默认采用某一档并统一锚定一个基准刑
- ✗ 禁止将"更高档"仅作为风险附注而弱化其为主线预测

## 标准五步计算法

### 步骤一：确定起刑点（裸刑）

```
依据：罪名 + 基本犯罪构成事实 → 法定刑幅度（暂不考具体案情细节）
例：侵犯公民个人信息罪 情节严重 → 3年以下有期徒刑、拘役，并处罚金
```

### 步骤二：确定基准刑

```
基准刑 = 量刑起点 + 数额/后果增量（按地方细则或司法解释）
数据源：Module F 锚定优先级链（禁止仅用案例倒推）
```
> ⚠️ **档内梯度锚定铁律**：法定刑幅度（如"5年以下有期徒刑"）内部跨度极大（拘役1月至5年），**禁止因法定下限低而一律从低位锚定**。"基本档≠轻刑档"。
> - 对具备较强组织性/开放性/营利性、持续时间长、涉案规模大、或金额已接近升档门槛的案件，基准刑应锚定在**该档法定上限的 1/2～2/3 处**（如基本档上限5年→锚30～40个月），而非接近下限。
> - 锚定时须结合：① 本罪在当地的同类已决判决尺度（仅校验，见 Module F 第5点）；② 案件在组织规模、持续时间、参与人数、获利体量等"规模维度"的相对位置。

### 步骤三：调节基准刑（套用第二部分公式）

```
第一轮（修正情节，连乘法 · 公式一）：
  调整后基准刑 = 基准刑 × (1 ± 修正A%) × (1 ± 修正B%)

第二轮（一般情节，连加法 · 公式二）：
  预测刑期 = 调整后基准刑 × (1 ± 一般A% ± 一般B%)

混合（公式三）：先乘后加
```

### 步骤四：再次调节基准刑（类案检索 + 综合权衡）

```
① 类案检索：同类案件量刑尺度校验（与 Module F 判例锚点交叉）
② 酌定情节9类综合权衡，整体微调（体现法官裁量空间）
```

### 步骤五：确定宣告刑（最终校验）

```
① 罪责刑相适应原则最终校验
② 缓刑 / 免予刑事处罚等特殊情况判断（执行方式，非量刑情节）
③ 输出：建议宣告刑区间 + 理由
```

### 边界检验

```
规则1：宣告刑不得低于该档次法定刑下限、不得超过上限（升档则取上一档下限）
规则2：认罪认罚下，检察院量刑建议通常高于法院实际判决5%～10%
规则3：叠加从轻情节合计原则上不超过60%
规则4：累犯不适用缓刑
```

## 数罪并罚计算（刑法第69条）

```
规定：
1. 数罪中有判处死刑或者无期徒刑的，执行死刑或者无期徒刑
2. 判决执行的刑期不得超过20年有期徒刑
3. 数罪都在3年有期徒刑以下的，执行最高刑

并罚公式（有期徒刑）：
并罚刑期 = 最高单罪刑期 × 0.7 + 次高单罪刑期 × 0.3（实践中的合并幅度参考）

注意：并罚结果须在各罪刑期总和以下、数罪中最高刑期以上，且不超过20年
```

# 第八部分：三层情景预测模型

# ══════════════════════════════

## 情景定义

| 情景       | 含义                  | 概率权重参考  |
| -------- | ------------------- | ------- |
| **乐观情景** | 所有有利情节均被采纳，法官倾向从宽   | 20%～30% |
| **基准情景** | 主要有利情节被采纳，按指导意见中值   | 50%～60% |
| **保守情景** | 有利情节打折或不被采纳，法官偏中间偏上 | 20%～30% |

## 情景差异化参数

| 参数     | 乐观   | 基准   | 保守   |
| ------ | ---- | ---- | ---- |
| 从犯减幅   | 50%  | 35%  | 20%  |
| 自首减幅   | 40%  | 25%  | 10%  |
| 认罪认罚减幅 | 30%  | 20%  | 10%  |
| 坦白减幅   | 20%  | 12%  | 5%   |
| 退赃从宽   | 30%  | 18%  | 5%   |
| 谅解从宽   | 25%  | 15%  | 5%   |
| 累犯加重幅度 | +10% | +25% | +40% |

> ⚠️ **情节打折收敛提示**：多个"可以"型从宽情节并存时，法院实际综合减幅通常**收敛于基准刑的 20%～40%**，而非各情节幅度简单连加（即使数学上限更高）。乐观情景不宜机械封顶60%；保守情景应反映"情节打折或不被采纳"的现实。具体幅度须结合当地司法尺度（判例校验）与既有从宽情节的重叠度判断。
