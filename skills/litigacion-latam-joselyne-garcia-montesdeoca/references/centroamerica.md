# 中美洲——民事诉讼参考

## 危地马拉

### 法律框架
- **《民事和商事诉讼法典》（CPCM）**——第 107/1964 号法令
- **《民法典》**——第 106/1963 号法令

### 民事司法结构
| 审级 | 机构 |
|-----------|---------|
| 一审 | 民事一审法院 |
| 二审 | 上诉法院的庭（民事和商事） |
| 撤销之诉（casación） | 最高法院民事庭 |
| 保护令（amparo） | 宪法法院（特别保护令）/ 各庭（普通保护令） |

### 主要程序
- **普通程序**：起诉状 → 送达（9 天）→ 答辩 → 抗辩 → 举证（30 天）→ 辩论 → 判决
- **执行程序**：针对执行文书（公证书、具有执行力的文件）。执行令 → 异议 → 拍卖
- **简易程序**：针对驱逐、追收费用、占有令。期限缩短。

### 救济
- 上诉：3 天内提起，6 天内在庭前陈述损害
- 撤销之诉：15 天内提起；事由为穷尽列举（违反法律、评价证据中的事实或法律错误、不一致）
- 保护令：向民事上诉庭提出；向宪法法院提起上诉

### 时效（危地马拉《民法典》）
- 人身之诉：5 年（第 1508 条）
- 执行之诉：5 年
- 非合同责任：2 年（第 1512 条）

## 哥斯达黎加

### 法律框架
- **《民事诉讼法典》**——第 9342 号法律（2018 年）——**口头程序**逐步实施
- **《民法典》**——第 63/1887 号法律

### 重要特点：口头性
哥斯达黎加于 2018 年实施了新的民事诉讼法典，采用**听证式口头程序**，类似于哥伦比亚模式（CGP）。大多数审理程序通过口头听证进行。

### 主要程序
- **口头普通程序**：起诉状 → 受理 → 预备听证（整理 + 确定争点 + 调解 + 证据受理）→ 庭审听证（证据调查 + 辩论 + 口头宣判）→ 救济
- **督促程序**：针对金钱债务追收。督促令 → 异议（10 天）→ 如无异议：执行文书。如有异议：转为普通程序。
- **执行程序**：针对判决和具有执行力的文书。

### 救济
- 上诉：5 个工作日内向上诉法院提起
- 撤销之诉：向最高法院第一庭提出。事由：违反程序或实体规范。

### 时效（哥斯达黎加《民法典》）
- 普通人身之诉：10 年（第 868 条）
- 非合同责任：4 年（第 875 条）

## 巴拿马

### 法律框架
- **《司法法典》**——第二编关于民事诉讼程序
- **《民法典》**

### 司法结构
| 审级 | 机构 |
|-----------|---------|
| 一审 | 民事巡回法院 |
| 二审 | 高等法院（民事庭） |
| 撤销之诉 | 最高法院（民事庭） |

### 特点
- **撤销之诉**：最高法院管辖。事由：违反法律、评价证据中的法律错误、明显的事实错误。
- **宪法保障保护之诉**：针对行政机关行为向最高法院提起；针对下级法官行为向上级法院提起。期限短暂（3 个月）。

### 时效
- 一般规则：人身债务 5 年（《民法典》第 1703 条）
- 非合同责任：1 年（较短——请核实）

## 萨尔瓦多

### 法律框架
- **《民事和商事诉讼法典》（CPCM）**——第 712/2008 号法令（**采用口头程序**）
- **《民法典》**

### 特点：口头性
萨尔瓦多 2008 年的 CPCM 在民事和商事领域实施了**听证式口头程序**。这是一个与哥伦比亚相当的现代制度。

**普通程序阶段：**
1. 起诉状
2. 补正（预防）和受理
3. 准备听证（整理、调解、确定诉讼标的、提出证据）
4. 证据听证（证据调查、辩论、口头或延期宣判）
5. 救济

### 救济
- 上诉：自判决通知起 5 天，向二审法院提起
- 撤销之诉：向最高法院民事庭提出。期限：15 天。

## 多米尼加共和国

### 法律框架
- **法国法影响**（《拿破仑法典》）——该地区唯一有此直接传承的国家
- **《民事诉讼法典》**——基于 1806 年法国 CPC
- **《民法典》**——受法国影响

### 特点
- 书面制度，程序术语与西班牙传统的拉美国家不同
- **向最高法院（民事庭）提起撤销之诉**
- 救济：异议、上诉、撤销之诉、民事再审、第三人异议
- 一般时效：20 年（《多米尼加民法典》第 2262 条——直接受法国影响；请核实近期改革）
