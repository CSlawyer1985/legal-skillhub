# 当事人自助材料模板

以下模板用于普通当事人整理材料。替换方括号占位符，并保持表达清楚易懂。

## 离婚准备清单

- 当前阶段：[考虑离婚 / 协议离婚 / 冷静期中 / 诉讼中 / 调解中]。
- 安全风险：[暂未发现 / 家暴 / 威胁 / 儿童安全 / 财产转移 / 其他]。
- 主要未解决问题：[子女 / 财产 / 债务 / 是否愿意离婚 / 其他]。
- 已准备材料：[身份证件 / 结婚证 / 离婚协议 / 子女材料 / 财产材料 / 债务记录]。
- 下一步：[确认是否一致 / 准备清单 / 咨询律师 / 查询当地民政或法院要求]。

1. 根据我的情况，协议离婚是否现实，还是应准备诉讼？
2. 子女、财产、债务方面最重要的证据是什么？
3. 是否需要考虑保全、保护令或其他紧急措施？
4. 我需要向当地法院或民政部门确认哪些具体要求？
5. 目前拟定的子女、财产、债务和付款安排中，哪些事项需要进一步明确？
