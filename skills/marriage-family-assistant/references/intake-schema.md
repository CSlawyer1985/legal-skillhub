# 统一离婚案件数据模型

使用本 schema 将长文本、上传材料和问答结果整理为结构化案件对象。所有后续分析、协议生成和文书生成，都基于这个结构化对象，而不是每次重新理解原始材料。只询问当前产物真正需要的信息，不要一次性要求用户填写所有字段。

## 动态 intake 原则

不要把本文件当成一次性问卷发给用户。每次只根据当前上下文选择一个小型 intake 表单：

- 最多 3-6 个字段。
- 优先问会改变路径判断、风险判断或输出质量的字段。
- 已经知道的信息不重复问。
- 可以用表格、勾选项或短填空，降低填写负担。
- 允许用户填“不清楚”“暂无材料”“稍后补”。
- 若存在家暴、人身危险、子女安全、财产紧急转移、法院期限等，先处理风险，不继续普通表单。

## 多轮问询原则

多轮问询只基于当前对话中用户已经提供的信息推进。

- 每轮先简要归纳当前已知事实和待补充事项。
- 不声称保存长期记忆、案件状态或跨会话追踪。
- 每轮只补充 3-6 个关键缺口，避免让用户重复填写已经说明的信息。
- 用户补充后，先更新当前轮事实摘要，再进入路径判断、争点分析、材料清单或离婚协议草案。

推荐开场：

```text
我先用一个小表单补齐关键事实。可以只填你知道的部分，不清楚的写“不清楚”。
```

推荐表格：

| 需要补充 | 怎么填写 |
| --- | --- |
| [字段] | [示例/选项] |

## 常用小表单

### 路径判断表

| 需要补充 | 怎么填写 |
| --- | --- |
| 双方是否都同意离婚 | 都同意 / 一方不同意 / 还没谈 |
| 子女安排是否谈妥 | 无子女 / 已谈妥 / 有争议 |
| 财产债务是否谈妥 | 已谈妥 / 部分谈妥 / 有争议 |
| 是否有紧急情况 | 家暴 / 子女安全 / 财产转移 / 法院期限 / 暂无 |

### 子女安排表

| 需要补充 | 怎么填写 |
| --- | --- |
| 孩子年龄 | 例如：6 岁 |
| 目前主要照护人 | 我 / 对方 / 双方 / 祖父母等 |
| 双方想法 | 都同意 / 抚养权有争议 / 探望或抚养费有争议 |
| 主要担心 | 抚养权 / 探望 / 抚养费 / 学校医疗 / 其他 |

### 房产处理表

| 需要补充 | 怎么填写 |
| --- | --- |
| 房子购买时间 | 婚前 / 婚后 / 不清楚 |
| 登记在谁名下 | 我 / 对方 / 双方 / 其他 |
| 出资来源 | 双方收入 / 一方婚前财产 / 父母出资 / 不清楚 |
| 是否有贷款 | 无 / 有，谁在还 / 不清楚 |
| 你希望怎么处理 | 一方要房补偿 / 出售分款 / 暂不处理 / 不确定 |

### 协议起草表

| 需要补充 | 怎么填写 |
| --- | --- |
| 双方是否都同意离婚 | 都同意 / 一方不同意 / 还没完全谈妥 |
| 子女安排 | 无子女 / 已谈妥 / 仍有争议 |
| 财产和债务 | 已谈妥 / 部分谈妥 / 仍有争议 |
| 补偿或款项支付 | 无 / 已谈妥 / 金额或时间未定 |
| 尚未明确的事项 | 房产 / 抚养费 / 探望 / 债务 / 付款时间 / 其他 |

### 律师办案表

| 需要补充 | 怎么填写 |
| --- | --- |
| 代理立场 | 男方 / 女方 / 原告 / 被告 / 中立分析 |
| 当前阶段 | 咨询 / 协商 / 准备起诉 / 诉讼中 / 调解中 |
| 核心目标 | 判离 / 子女 / 房产 / 债务 / 协议起草 / 文书 |
| 已有材料 | 客户陈述 / 证据 / 房产材料 / 债务材料 / 起诉材料 |
| 希望交付 | 争点 / 证据矩阵 / 处理方案 / 文书底稿 / 客户清单 |

## 案件基础信息

- 用户身份：律师、律师助理、当事人、亲友、调解人员、其他。
- 适用法域：默认中国大陆；如有涉外、港澳台或跨境事实需单独标注。
- 当前阶段：考虑离婚、协商中、申请协议离婚、冷静期中、诉讼中、调解中、执行中、离婚后纠纷。
- 紧急事项：家暴、威胁、儿童危险、财产转移、证据灭失、期限、诉讼时效、开庭日期。
- 所在地区及拟办理机构：民政部门、基层法院、中院、调解组织或其他机构。

## 当事人与婚姻基础

- 双方姓名或占位符。
- 身份信息、户籍地、经常居住地。
- 结婚登记日期和地点。
- 共同生活、分居、复合的时间线。
- 既往离婚诉讼、判决、调解、协议或和解材料。
- 离婚原因以及是否有一方不同意离婚。

## 子女

- 子女姓名或占位符、出生日期、当前主要照护人、就学和居住情况。
- 当前抚养或事实照护安排。
- 双方工作时间、收入、住房、照护历史、健康状况、行为风险。
- 子女达到相应年龄和成熟程度时的真实意愿。
- 拟定抚养、探望、寒暑假、教育、医疗、旅行、迁居安排。
- 抚养费金额、支付方式、调整机制和特殊支出分担。

## 财产

- 房产：购买时间、登记情况、出资来源、贷款和还款、当前使用、估值、父母出资、相关约定。
- 车辆和高价值动产。
- 银行存款、微信/支付宝等支付账户、基金、股票、理财、保险现金价值、养老金、公积金、数字资产。
- 经营权益：公司、股权、实际控制、出资、分红、关联交易。
- 对外借款、知识产权收益、境外资产。
- 收入记录和疑似隐匿财产线索。
- 赠与、继承、人身损害赔偿、婚前财产、夫妻财产约定。

## 债务

- 债权人、债务人、金额、日期、用途、签署材料、资金流向、偿还情况、担保情况。
- 是否双方共同签名或事后追认。
- 是否用于家庭日常生活、共同生活或共同生产经营。
- 是否涉及赌博、毒品、个人消费、恶意转移或虚假债务风险。

## 过错、安全与特别请求

- 家暴、虐待、遗弃、威胁、跟踪、强控制。
- 重婚、与他人同居、重大婚姻过错。
- 隐藏、转移、变卖、毁损、挥霍夫妻共同财产。
- 军婚、涉外婚姻、一方失联。
- 一方重大疾病、精神障碍或行为能力争议。
- 家务贡献明显失衡和家务补偿可能性。
- 经济困难和经济帮助需求。

## 事实关联对象

对重要事实建立关联，不只做摘要：

- 事实：时间、地点、参与人、事实内容、来源材料。
- 财产：财产类别、权属、取得和处分事实、对应证据。
- 主张：用户希望达成的法律或协商目标。
- 证据：证据名称、来源、证明目的、真实性和完整性问题。
- 争议点：双方分歧、法律规则、证明责任和风险。

## 证据

- 现有文件、原件/复印件、证据保管人。
- 电子数据：聊天记录、转账记录、邮件、云文件、平台记录。
- 证人和机构：学校、医院、公安、社区、单位、银行、不动产登记机构。
- 证据保全需求和删除、转移、灭失风险。

## 目标产物

- 访谈纪要。
- 争点矩阵。
- 证据清单。
- 谈判方案。
- 协议条款要点。
- 离婚协议草案。
- 起诉状或诉讼请求框架。
- 律师咨询简报。
- 法院/民政部门材料准备清单。
- 离婚准备度评估。
- 律师转介包。

## 最小 intake 表单

用户信息很少且无法判断表单类型时，使用最小表单：

| 需要补充 | 怎么填写 |
| --- | --- |
| 你是本人处理还是律师办案 | 本人/亲友 / 律师/助理 |
| 双方是否都愿意离婚 | 都同意 / 一方不同意 / 还没谈 |
| 子女、财产、债务是否谈妥 | 都谈妥 / 部分谈妥 / 有争议 |
| 是否有紧急情况 | 家暴 / 威胁 / 子女安全 / 财产转移 / 法院期限 / 暂无 |
| 你最想先解决什么 | 路径判断 / 材料清单 / 协议要点 / 证据方案 / 诉讼准备 |
