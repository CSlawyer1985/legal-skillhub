# NIST SP 800-53 修订版 5 技能

> ⚠️ **免责声明：** 本技能基于 NIST SP 800-53 Rev 5、SP 800-53B、SP 800-53A Rev 5 和 SP 800-37 Rev 2 提供信息性指引。它不构成权威的 NIST 指引或法律意见。正式的 FISMA 授权决定、FedRAMP 评估和 ATO 文件包，请咨询您的授权官员（Authorizing Official）、ISSO 和经认可的 3PAO。

---

## 1. 本技能做什么？

NIST SP 800-53 Rev 5 合规技能将 Claude 变成具备特别出版物 800-53 修订版 5——《信息系统和组织的安全和隐私控制》（NIST 2020 年 9 月发布）——全面知识的联邦信息安全控制专家顾问。技能引导联邦机构、承包商、云服务提供商和系统所有者完成完整的风险管理框架（RMF）生命周期，从系统分类到授权和持续监控。

技能涵盖 SP 800-53B 定义的**低、中、高影响基线**下全部 20 个控制族（AC 至 SR）。它支持使用机密性、完整性和可用性三个影响等级的 FIPS 199 系统分类；基线选择和裁剪，包括组织定义值（ODV）分配、范围考量和覆盖应用；以及含实施描述、责任角色和证据产物三个必要组件的 SSP 叙述写作。

技能纳入 Rev 5 的关键增强：新的隐私（PT）控制族，含 8 项涉及 PII 同意、最小化和透明度的控制；新的供应链风险管理（SR）控制族，含 12 项控制；基于结果的控制陈述；以及基线分离至 SP 800-53B。它还涵盖使用检查、访谈和测试方法的 SP 800-53A Rev 5 评估程序、POA&M 管理和持续监控策略。

跨框架映射是核心能力：技能将 SP 800-53 控制映射到 FedRAMP 参数、FISMA 要求、CMMC 2.0 第 2 级（源自 SP 800-171）、ISO 27001:2022、NIST CSF 2.0、HIPAA 安全规则和 PCI DSS v4.0。这使得技能对寻求 ATO 的联邦机构、寻求 FedRAMP 授权的云提供商，以及对照联邦安全标准进行基准测试的私营部门组织同样有用。

## 2. 目标受众

| 受众                                         | 如何使用本技能                                                                                     |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| **ISSO（信息系统安全官）** | 撰写 SSP 叙述、管理 POA&M、准备评估文件包、就控制实施提供建议         |
| **系统所有者**                                | 了解其系统的控制义务、作出裁剪决定、回应评估发现 |
| **授权官员**                        | 从评估发现了解风险态势、评估 ATO 建议                             |
| **3PAO 和独立评估者**              | 参考评估程序（SP 800-53A）、评估控制充分性、撰写 SAR 发现             |
| **FedRAMP 云服务提供商**              | 应对中/高基线、应用 FedRAMP 叠加参数、准备授权文件包      |
| **联邦机构 IT 团队**                      | 实施 FISMA 要求的控制、建立持续监控计划、分类系统              |
| **CMMC 从业者**                           | 经 SP 800-171 派生将 CMMC 2.0 第 2 级要求映射到 SP 800-53 控制                          |
| **安全架构师**                          | 设计带控制继承的系统、应用叠加（OT/SCADA、医疗、云）                      |

## 4. 如何使用本技能

### 安装

1. 从本文件夹下载 `nist-800-53.skill`
2. 在 Claude 中进入 **设置 → 技能**
3. 点击**上传技能**并选择 `nist-800-53.skill`
4. 技能现已在所有 Claude 会话中激活

### 触发技能

当您提出 NIST SP 800-53、RMF、FISMA 或联邦安全控制话题时，技能自动激活。无需特殊命令。触发技能的自然语言示例：

- *“NIST 800-53 对……有什么要求？”*
- *“我需要为……撰写 SSP 叙述”*
- *“帮我在 FIPS 199 下对这个系统分类”*
- *“我们正在经历 FedRAMP 授权”*
- *“中影响系统适用哪些基线控制？”*
- *“带我过一遍 RMF 步骤”*
- *“我们即将进行 FISMA 评估”*

### 示例提示

```
我们正在为一个处理员工 PII（包括姓名、SSN、薪资信息和绩效评估）的新联邦
HR 系统进行分类。带我过一遍 FIPS 199 分类流程，并告诉我应选择哪个
SP 800-53B 基线。
```

```
为我们托管在 AWS GovCloud 的系统的以下三项控制撰写 SSP 叙述：AC-2
（账户管理）、IA-2(1)（特权账户 MFA）和 SC-28(1)（静态加密）。遵循标准
三组件格式。
```

```
我们是寻求 FedRAMP 中授权批准的云服务提供商。我们的评估者发现了 12 项
OTS 发现。帮我为每项发现构建一份带适当风险等级、补救时间线和里程碑
描述的 POA&M。
```

```
将以下 SP 800-53 Rev 5 控制族映射到它们的 ISO 27001:2022 附录 A 对应物，
并识别每个目录中无直接映射对应物的控制：AC、AU、IA、SC 和 SI 族。
```

```
我们需要为联邦系统应用供应链风险管理（SR）族控制。解释全部 12 项 SR
控制、它们适用于哪个基线，并为中影响系统提供实施指引。
```

```
                                            #   OSCAL、跨框架映射细节
```

### SKILL.md 中的内容

- 专家角色：具备 SP 800-53/53A/53B 和 SP 800-37 知识的 NIST SP 800-53 合规顾问
- 响应格式表，将 6 种任务类型映射到结构化输出（控制族深入解析、基线选择、差距评估、SSP 叙述、RMF 指引、问答）
- 引注标准：控制 ID + 增强（如 AC-2(3)、SI-3(10)）及基线标识
- 框架概述：授权依据（FISMA 2014）、发布历史、现行 Rev 5 版本
- 关键 Rev 5 变更表（相对 Rev 4 的 6 项重大变更）
- 8 步实施指南：FIPS 199 分类 → 基线选择 → 20 个控制族 → 裁剪 → 叠加 → SSP 叙述 → SP 800-53A 评估 → RMF 集成
- FIPS 199 冲击等级表（C/I/A 的低/中/高）
- SP 800-53B 基线比较（低约 156、中约 323、高约 422 项控制）
- 全部 20 个控制族及 ID、控制范围和关键重点领域
- 裁剪行动（5 种类型）和 ODV 示例表
- 叠加类型和用例
- SSP 叙述结构（三组件）和常见陷阱
- SP 800-53A 评估方法和发现格式
- RMF 7 步表（名称、输出和角色）
- 跨框架映射表（FedRAMP、FISMA、CMMC 2.0、ISO 27001、CSF 2.0、HIPAA、PCI DSS）
