# 评审办法 / 评审标准合规设计助手（政采货物服务版）

政府采购（货物、服务）综合评分法评审办法与评审标准的合规设计与审查助手。聚焦 87 号令第 55 条等高频违规点：分值权重、价格分下限（货物≥30%、服务≥10%）、主观分占比与量化、量化指标、评审因素禁止项。输出风险等级 + 法条方向 + 可落地改写建议。

## 版本区分与法律依据
本助手为**政采货物服务版**；另有规划中的**招投标版**，二者不混用：

| 维度 | 政采货物服务版（本版） | 招投标版（规划中） |
|---|---|---|
| 适用对象 | 政府采购货物、服务 | 依法必须招标的工程项目 |
| 术语 | 评审办法 / 评审标准；采购人 / 供应商 | 评标办法 / 评标标准；招标人 / 投标人 |
| 核心法律依据 | 《政府采购法》、财政部令第87号《政府采购货物和服务招标投标管理办法》第55条等 | 《招标投标法》《招标投标法实施条例》、发改委令第16号《必须招标的工程项目规定》等 |

- 本版仅处理政采货物服务；工程招投标请使用招投标版。
- 法条编号、款项以现行有效文本及法律顾问意见为准。

## 能力
- 价格分下限核查（货物≥30% / 服务≥10%，含磋商、政务信息系统、固定价格等特殊场景）
- 主观分占比与量化标准审查
- 评审因素量化程度审查
- 评审因素禁止项识别（资格条件、特定区域/行业业绩奖项、规模条件、特定品牌/产地等）
- 风险定级 P0/P1/P2 + 可替换改写建议
- 低价优先法计算示例与梯度模拟
- 审计防御备忘录与专家打分路径推演
- 输出结构化合规诊断报告、重构评审标准与 JSON 交接物；风险清单遵循统一 6 列 Schema（定位原文 / 风险点 / 命中依据 / 严重等级 / 整改建议 / 实战预警），禁止散文式罗列，并附发布前输出自检矩阵

## 适用边界
- 默认服务政府采购（货物、服务）综合评分法。
- 工程招投标、竞争性谈判/询价/单一来源等不适用，会提示并确认。
- 锁定采购人/招标人视角。
