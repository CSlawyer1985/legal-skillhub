# 案件分析报告（参考王泽鉴请求权基础分析法）Plus

## 使用前提醒

> ⚠️ **使用前提示**：本技能最佳使用效果，需要您提前在 WorkBuddy「专家」→「连接器」中手动连接 **"华宇元典法律数据"MCP**。连接完成后再使用本技能，可实现法律法规、案例、法答网答问的自动检索。如尚未连接，仍可进行案件分析，但需您手动提供相关法律法规和案例材料。

## 本地知识库

本技能内置以下本地参考文件，分析案件时优先查阅：

| 文件 | 内容 | 优先使用场景 |
|------|------|-------------|
| `references/construction-judicial-interpretation-ii.md` | 《建工解释二》（法释〔2026〕12号）全文23条 | 建设工程施工合同纠纷 |
| `references/construction-judicial-interpretation-ii-qa.md` | 最高法民一庭庭长答记者问（7个问题） | 建设工程施工合同纠纷 |
| `references/construction-judicial-interpretation-ii-cases.md` | 最高法配套六个典型案例（含速查表） | 建设工程施工合同纠纷 |
| `references/fada-batch-38.md` | 法答网精选答问第三十八批（刑事审判专题） | 刑事案件 |

**知识库优先检索规则：**

处理案件时，必须首先判断案件类型并遵循以下优先级：

1. **建设工程施工合同纠纷案件**：
   - 在法律法规检索和案例检索之前，必须先通读上述三份建工知识库文件
   - 法律分析直接引用《建工解释二》相关条文，并标注"法释〔2026〕12号"
   - 类似案例优先从 `construction-judicial-interpretation-ii-cases.md` 中的6个典型案例选取，再以华宇元典MCP检索补充
   - 《建工解释二》与《建工解释一》不一致的，以《建工解释二》为准
   - **重要**：《建工解释一》第四十三条（实际施工人可突破合同相对性）已被《建工解释二》第六条废止，不再适用
   - **重要**：《建工解释二》不再使用"实际施工人"表述，应按法律关系区分：借用资质的单位或个人、接受转包的单位或个人、接受违法分包的单位或个人

2. **刑事案件**：
   - 本技能核心分析框架（请求权基础六层检查）为民商事方法，刑事案件的法答网检索可引用本地知识库，但请求权基础分析框架不适用于纯刑事案件
   - 在法答网检索之前，必须先查阅 `references/fada-batch-38.md`
   - 如涉及该批次4个问题，直接引用并标注"来源：最高人民法院《法答网精选答问》第三十八批"

3. **其他案件**：
   - 本地知识库无覆盖内容的，按常规流程使用华宇元典MCP检索

## 一、工作准备

### 1. 收取案件材料并判断案件类型
- 如用户已上传案件材料（合同、判决书、聊天记录等），直接进入分析。
- 如用户尚未提供，引导用户上传或描述以下信息：
  - **当事人信息**（原告/被告/第三人，自然人或法人）
  - **案件事实**（时间、地点、行为、结果，按时间顺序简述）
  - **争议焦点**（各方主要分歧）
  - **已采取的措施**（是否起诉、是否已开庭等）
  - **管辖法院**（如已知，用于挑选对应省份参考案例）

**案件类型判断**：根据案卷材料，第一时间判断案件是否属于以下类型，以便后续步骤正确选择检索路径：
- 建设工程施工合同纠纷 → 适用本地知识库建工三件套优先 + MCP补充
- 刑事案件 → 适用本地知识库法答网第三十八批优先 + 法答网Plus技能补充
- 其他民商事案件 → 适用华宇元典MCP检索

### 2. 确认管辖法院所在省
- 用于后续案例检索：优先选取该省法院裁判的案例
- 如用户不明确，默认选取 **浙江省** 法院案例

## 二、法律法规与案例检索

### 检索优先级

**建设工程案件优先查阅本地知识库**：
- 法律法规：先通读 `references/construction-judicial-interpretation-ii.md`（《建工解释二》全文）和 `references/construction-judicial-interpretation-ii-qa.md`（答记者问），直接引用相关条文
- 参考案例：先查阅 `references/construction-judicial-interpretation-ii-cases.md`（最高法6个典型案例），标准格式不变，仍按以下**【强制】案例勾选确认步骤**执行
- 本地知识库不足时，再通过华宇元典MCP补充检索

**非建设工程案件**：直接按以下流程使用华宇元典MCP检索。

### 检索要求
| 检索类型 | 具体要求 |
|---------|-----------|
| 法律法规 | 中华人民共和国现行有效法律、行政法规、司法解释，重点检索与本案案由相关的条文。建设工程案件优先引用《建工解释二》（法释〔2026〕12号），标注施行日期2026-06-30 |
| 司法解释 | 最高人民法院相关司法解释及理解与适用。建设工程案件：《建工解释二》与《建工解释一》不一致的，以《建工解释二》为准 |
| 参考案例 | **仅限2021年1月1日及之后裁判的案例**；按管辖法院所在省挑选；如该省案例不足，可补充邻近省份；**建议选取3个案例，用户可自行决定纳入数量（可多于3个）**。建设工程案件优先从最高法6个典型案例选取（不受省份限定限制） |
| 法答网答问 | 刑事案件优先查阅 `references/fada-batch-38.md`；本地知识库未覆盖时，调用 `技能：法答网精选答问Plus` 或 MCP 工具检索 |

### 检索步骤（如已连接华宇元典法律数据MCP）
1. 调用 MCP 工具检索与本案相关的法律法规（建设工程案件已从本地知识库获取的，此步仅补充检索未尽问题）
2. 调用 `技能：法答网精选答问Plus` 检索法答网精选答问（刑事案件已从 `references/fada-batch-38.md` 获取的，此步仅补充检索未覆盖问题）
3. 调用 MCP 工具检索参考案例（注意时间过滤：2021-01-01 之后；建设工程案件已从典型案例获取的，此步补充检索供用户选择）
4. **【强制】案例勾选确认步骤**：
   - 将检索到的所有候选案例以**编号列表**呈现给用户，每个案例列出：序号、案例名称、审理法院、裁判日期、核心裁判要点摘要
   - 明确提示用户：**"请勾选您希望纳入报告的案例（可多选，建议3个，您也可以选择超过3个），未勾选的案例将不出现在报告中"**
   - **等待用户勾选确认后**，仅将用户勾选的案例纳入最终报告的「参考案例」部分
   - **绝对禁止**将用户未勾选的案例写入报告的任何部分
   - 如检索结果为0，在报告中注明"未检索到符合条件的参考案例"
   - 建设工程案件从典型案例直接选取的，标注"来源：最高人民法院建设工程施工合同纠纷典型案例"
5. 如 MCP 连接失败或未连接，在报告中注明"本案法律法规检索由用户自行补充"

## 三、王泽鉴请求权基础分析法框架

本报告采用王泽鉴先生提出的**请求权基础分析方法**，结合中国大陆现行法，按以下结构展开：

### 核心分析框架（六层检查次序）

```
第一层：契约上请求权（原给付请求权 + 次给付请求权）
         ↓ 理由：契约存在则排除无因适用
第二层：类似契约请求权（缔约过失、无权代理等）
         ↓ 理由：与缔约过程有关，接近契约
第三层：无因管理请求权
         ↓ 理由：无因管理是不当得利的法律上原因
第四层：物权请求权（所有物返还请求权等）
         ↓ 理由：物权变动决定不当得利/侵权是否成立
第五层：不当得利请求权
         ↓ 理由：契约、无因管理是其前提
第六层：侵权行为请求权
         ↓ 理由：非以上任何请求权之前提，放最后
```

### 辅助方法：历史方法
当涉及物权变动、合同成立过程等**时间顺序问题**时，辅以历史方法（按事实发生时间顺序检讨法律关系），以检验请求权基础构成要件的成立。
