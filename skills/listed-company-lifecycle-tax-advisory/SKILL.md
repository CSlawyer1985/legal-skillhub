## 能为你做什么（七大痛点场景）

### 一、板块定位与上市路径论证

- 🧭 **多板块对比**：结合行业属性、科创属性、规模与财务指标，论证主板 / 科创板 / 创业板 / 北交所 / 新三板的适配性，并给出境外（H股 / 红筹）备选路径。
- ⏱️ **时间表**：形成倒排时间表与多路径备选，降低中途换板延误风险。

**典型问法：**

```
"新三板公司适合转哪个板块？"
"科创板与创业板定位差异？"
"境外上市 H股和红筹怎么选？"
```

### 二、上市前财税规范与历史清理

- 🧹 **倒排清理**：T-3 自查清理（历史补税 / 社保欠缴）→ 财务规范提升 → 个人卡清零 → 第三方回款整改 → 票据与资金占用清理。
- 📜 **合规凭证**：取得税务合规证明、个人卡注销证明、往来清理台账与内控运行留痕。

**典型问法：**

```
"上市前三年财税怎么规范？"
"历史补税问题怎么清理？"
"个人卡收支怎么整改？"
```

### 三、内部控制框架设计（协助设计）

- 🧱 **五要素 + 业务循环**：以企业内部控制基本规范五要素为底座，落到销售 / 采购 / 资金 / 资产 / 投融资五大业务循环，制度 + 流程 + 留痕三件套。
- 📋 **可交付**：协助搭建并实际运行足够期间，出具内控自我评价，最终由申报会计师取得无保留结论的内控鉴证报告（避免"纸上内控"）。

**典型问法：**

```
"怎么帮企业设计内控框架？"
"内控五要素怎么落地到业务循环？"
"内控评价报告要什么结论？"
```

### 四、股改与上市审核税务

- 🏛️ **股改折股**：股票溢价转增免征个税；留存收益 / 其他资本公积转增按 20%，中小高新可 5 年分期并备案。
- 🔍 **审核高频**：税收优惠依赖与可持续性、全链条实质合规、红筹架构完税、股份支付利润影响、关联交易与资金占用——形成穿透自查底稿。

**典型问法：**

```
"有限公司整体变更股份公司自然人股东要交个税吗？"
"上市审核税务高频问询有哪些？"
"税收优惠依赖怎么处理？"
```

### 五、再融资 / 并购重组 / 分拆 / 转板 / 收购（资本运作）

- 🔁 **再融资**：增发 / 配股 / 可转债的企业所得税、个税（送转）、印花税影响前置测算并披露。
- 🤝 **并购重组**：按重组政策论证特殊性税务处理（股权支付比例、经营 / 权益连续性）并备档，不达标转一般性处理。
- 🪓 **分拆 / 转板**：母子架构税务规划、并表口径与计税基础延续；转板前后税收优惠与激励个税递延衔接。
- 🎯 **收购**：要约 / 协议收购对价税务、一致行动人认定与披露合规。

**典型问法：**

```
"增发可转债税务怎么处理？"
"并购重组特殊性税务处理条件？"
"企业分立税务怎么走？"
"分拆上市母子税务怎么规划？"
"要约收购税务怎么处理？"
```

### 六、境外上市架构与跨境税务合规

- 🌐 **架构合规**：红筹 / VIE 返程投资外汇登记（37号文）、境外间接转让境内资产（7号公告）、居民境外所得申报、受控外国企业（CFC）规则。
- 📑 **备案**：境内企业境外发行上市向证监会备案，上市前完成架构梳理与税务补正。

**典型问法：**

```
"红筹架构外汇登记怎么做？"
"境外间接转让境内资产涉税吗？"
"境外上市架构怎么税务合规？"
```

### 七、持续督导与股权激励

- 🛡️ **持续督导**：关联交易公允、资金占用清零、信披及时、内控持续有效，建立监控台账与定期内审。
- 📒 **股权激励**：限制性股票 / 股票期权 / 持股平台的个税递延、股份支付费用按等待期分摊并前置测算利润影响。

**典型问法：**

```
"上市后关联交易怎么合规？"
"资金占用怎么防？"
"股权激励持股平台税务？"
```

## 重要提示与边界声明

**重要提示**

1. **路径早论证**：结合板块定位与财务指标早期论证上市路径，避免中途换板延误。
2. **规范须早启**：报告期首年即启动财务清理与内控搭建，避免后期整改不及。
3. **内控要落地**：制度 + 流程 + 留痕三件套，关键控制点实际运行并取得无保留结论鉴证报告。
4. **重组先论证**：并购重组 / 分立先论证特殊性税务处理条件并备档，不达标按一般性处理。
5. **跨境要登记**：红筹 / VIE 架构须办妥外汇登记、评估间接转让并完成境外所得申报。

**边界（本技能不做的）**

- **不代办**：上市申报、辅导验收、境外备案等需登录操作的事项
- **不代理**：上市审计鉴证、内控审计、法律尽调等需执业资质的事务
- **不担保**：审核结果、税收优惠认定、重组税务处理等最终以监管与税务机关为准

**服务说明**

- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告

**隐私保护**

- 仅在本机生成随机匿名标识用于服务调用，不会采集任何设备信息或个人隐私数据。
