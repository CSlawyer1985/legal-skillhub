# IPC分类号参考指南

## IPC分类体系概述

国际专利分类法(International Patent Classification, IPC)是根据1971年签订的《国际专利分类斯特拉斯堡协定》编制的,是目前国际通用的专利分类系统。

## IPC分类号结构

IPC分类号采用等级结构,由部、大类、小类、大组、小组组成:

```
示例: G06N 3/08

G        - 部(Section)
06       - 大类(Class)
N        - 小类(Subclass)
3        - 大组(Main Group)
/08      - 小组(Subgroup)
```

## 使用建议

1. **优先使用细分类号**: 越细的分类号检索越精准
2. **组合使用**: 一个专利通常有多个IPC分类号
3. **参考相似专利**: 查看相似专利的IPC分类号
4. **定期更新**: IPC分类表每修订一次,注意更新
