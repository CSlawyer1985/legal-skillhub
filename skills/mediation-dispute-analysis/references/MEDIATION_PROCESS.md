## 1. 调解的核心原则 <a name="core-principles"></a>

调解是争议当事方之间在无决策权的中立第三方协助下进行的谈判。主要特征如下：

**自愿性：** 任何当事方均不被强迫参与或接受任何特定和解。调解决定和任何协议的条款完全由当事方自主决定。

**非强制性：** 调解员进行促成但不作决定。调解员帮助当事方作出自己的决定，而非强加结果。

**协助式谈判：** 调解员提供程序性协助、帮助建立关系，并可能提出实质性选项——但当事方保留对结果的支配权。

**非正式性：** 与法院或仲裁不同，调解没有规定的程序规则。当事方设计适合其需求的程序。

**保密性：** 调解一般保密，保密限度由当事方共同设定。保密条款应以书面形式正式化。注意：具体立法要求（如信息获取法、隐私法）可能影响保密范围，尤其是涉及政府实体时。

**以解决为导向：** 目标是超越基于过错的法务分析，转向理解各方当事人的实际需求和利益，使结果真正解决根本问题。

## 2. 调解的 12 个阶段 <a name="twelve-stages"></a>

虽然每次调解都因复杂程度、个性和立场僵化程度而异，但成功的调解通常涉及以下阶段：

### 调解前阶段

**阶段 1：与争议当事方的初次接触**
- 与双方建立可信度
- 建立融洽关系和信任
- 向当事方说明调解程序
- 确定是否应让法律顾问参与
- 增强对程序的承诺

**阶段 2：选择策略**
- 帮助当事方评估各种争议解决方法
- 协助选择最适合其具体情况的方法

**阶段 3：收集和分析背景信息**
- 收集并核验涉及人员、背景和争议实质的准确数据
- 审查相关文件、通信和证据

**阶段 4：设计详细计划**
- 确定能使当事方走向协议的策略
- 规划会议结构（联合会议、私下会晤、顺序）
- 处理后勤需求

### 调解期间

**阶段 5：建立信任与合作**
- 使当事方准备好处理困难的实质性问题
- 建设性地处理强烈情绪
- 识别并处理成见或误解
- 建立对合法性的相互承认
- 明确沟通渠道

**阶段 6：开始会议**
- 开启当事方之间的沟通和谈判
- 建立开放、积极的基调
- 设定基本规则和行为准则
- 允许建设性的情绪宣泄

**阶段 7：界定议题并设定议程**
- 识别广泛关切领域
- 就讨论哪些议题达成一致
- 确定处理议题的顺序

**阶段 8：揭示隐藏利益**
- 识别各方当事人的实质性、程序性和心理性利益
- 让各方当事人了解对方的利益和需求
- 区分立场（他们说想要什么）与利益（他们为什么想要）

**阶段 9：生成和解选项**
- 培养对多个选项必要性的认识
- 帮助当事方脱离僵化立场
- 通过对话集思广益创造性解决方案

**阶段 10：评估选项**
- 审查每个选项如何满足当事方的利益
- 评估每个选项的成本和收益
- 对照诉讼替代方案进行现实检验（BATNA/WATNA）

### 结束阶段

**阶段 11：最终谈判**
- 汇集当事方的利益
- 激发妥协意愿
- 方法包括：渐进趋同、一揽子和解、共识公式或进一步协议的框架

**阶段 12：达成正式和解**
- 起草谅解备忘录或和解协议
- 确定实施协议的步骤
- 建立评估和监测程序
- 创设执行机制

## 3. 调解员的角色 <a name="role-mediator"></a>

调解员的角色存在于一个谱系中——从完全中立和促进性，到更具评价性和指示性。无论采用何种方法，调解员都无权强加决定。

### 调解员的关键职能

**促进性：**
- 鼓励当事方之间的信息交流
- 帮助当事方理解彼此的观点
- 确认各方当事人的关切被理解（积极倾听）
- 促进情绪的建设性表达
- 呈现认知和利益上的差异

**程序性：**
- 识别并缩小议题范围
- 谈判陷入僵局时建议休息
- 必要时与各方当事人举行私下会晤（单独会议）
- 管理讨论的顺序和节奏

**评价性（适当时）：**
- 帮助当事方现实地评估和解的替代方案
- 鼓励灵活性和创造性
- 将焦点从过去的指责转向未来的问题解决
- 提出满足所有当事方根本利益的解决方案

### 调解员风格

| 风格 | 说明 | 最佳使用时机 |
|-------|-------------|----------------|
| **促进式** | 聚焦程序；帮助当事方找到自己的解决方案 | 当事方能沟通；关系维系很重要 |
| **评价式** | 就案情发表意见；对立场进行现实检验 | 复杂的法律问题；当事方需要专家评估 |
| **转化式** | 聚焦赋权和相互承认 | 关系密集的争议；情感冲突 |

## 4. 律师在调解中的角色 <a name="role-counsel"></a>

律师的参与应在开始时确定。选项包括：

**作为法律顾问：** 调解期间在场，就法律权利、风险和拟议和解的影响向客户提供建议。可以审查拟议协议的法律充分性。

**作为积极参与者：** 代表客户发言、陈述论点、直接谈判。在法律复杂性高或客户情绪不堪重负时有用。

**作为代理人：** 在情绪高度激动的案件中，律师可在会议期间全面代理客户。这带来重大的伦理义务——律师必须与客户沟通、理解其观点，并确保程序满足其需求。

**不参加：** 律师在前后提供建议，但不出席谈判桌。在较非正式的调解中常见。

### 律师最佳实践
- 指导客户如何有效陈述其观点
- 训练得体的举止（面向发言者、保持目光接触、控制音量、开放姿态）
- 关注客户反应，需要时建议休息
- 在困难时刻后帮助平复情绪、保全颜面
- 提醒客户一个议题上的僵局不意味着调解失败
- 帮助客户理解其立场与利益之间的区别

## 5. 权力失衡与沟通困难 <a name="power-imbalance"></a>

调解员有责任确保权力失衡不会损害调解程序。

### 识别权力失衡
- 组织层级（雇主与员工、上级与下级）
- 资源差距（大公司与个人）
- 性别、种族或文化动态
- 知识不对称（一方掌握更多信息）
- 情绪脆弱性（骚扰、歧视案件）

### 缓解策略

**私下会晤（Caucusing）：** 调解员与各方当事人单独会面。适用于：
- 僵局威胁解决
- 沟通破裂
- 一方在联合会议中感到受胁迫
- 敏感信息需要私下探讨
- 情绪过于激动，无法进行建设性对话

**共同调解：** 两名或以上调解员平等参与程序。理由：
- 帮助自认较弱的一方感到更自在
- 可以解决人口统计代表性（如骚扰案件中不同性别的共同调解员）
- 提供更均衡的程序管理
- 允许一名调解员观察动态，另一名进行促成

**确保律师在场：** 对较弱一方，独立法律顾问在场有助于平衡知识和辩护力量。

**程序调整：** 分开房间、书面交流、与各方当事人的调解前会议、允许支持人员在场。

## 6. 调解的优势与局限 <a name="advantages-limitations"></a>

### 优势
- **关系维系：** 合意程序避免了诉讼后使持续关系难以维持的对抗性要素
- **灵活性：** 无严格程序规则；当事方设计适合其需求的程序
- **保密性：** 私人程序（受适用法律约束）
- **速度与成本：** 通常比诉讼更快、更便宜
- **创造性结果：** 不限于法律救济；可以处理法院无法处理的利益
- **当事方支配权：** 双方定义条款，提高对协议的遵守
- **复杂争议：** 当多个议题允许权衡取舍时尤为有效
- **情绪管理：** 当先前谈判失败或情绪高涨时，中立第三方能够实现受控对话

### 局限
- **权力失衡风险：** 面对面会议可能使较弱方处于不利地位（通过私下会晤、共同调解、律师参与缓解）
- **无先例：** 无法确立法律先例
- **调解员影响：** 意志坚强的调解员可能施加过度控制
- **恶意风险：** 非约束性质可能被利用来拖延解决
- **权限问题：** 机构当事方可能面临多层级批准要求
- **不适用于所有争议：** 需要公共问责、法律先例，或一方未以诚信行事的案件可能更适合其他程序

## 7. 调解协议检查清单 <a name="agreement-checklist"></a>

开始调解前，应处理以下事项：

### 参与者
- 所有直接相关当事方出席谈判桌（或有代表）
- 确定额外参与者（律师、专家、高级管理人员）
- 调解员是否可在需要时引入额外当事方
- 代表具有同意最终解决方案的充分权限

### 程序设计
- 商定调解员遴选程序
- 当事方无法就调解员达成一致时的备用机制
- 考虑语言/双语要求
- 签订调解协议，涵盖：
  - 调解员的任务和范围
  - 争议解决时书面协议的约定
  - 保密条款
  - 调解员报酬
  - 调解员和当事方的责任
  - 均摊费用安排

### 后勤
- 设定日期、时间和时长限制
- 选择中立地点
- 满足特殊要求（翻译、无障碍、技术）
- 确定并商定程序（或授权调解员决定）

### 披露
- 建立披露程序（提前交换或按调解员要求）
- 识别并共享关键文件

### 调解后
- 任何协议是否需独立法律意见？
- 谁将起草协议/谅解备忘录？
- 若调解不成功，是否阐明备用流程（仲裁、诉讼、进一步协商）
