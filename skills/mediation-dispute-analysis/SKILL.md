# 调解争议分析

## 概述

本技能帮助律师和调解员快速分析案件材料，产出结构化的争议分析——识别核心问题、各方立场及其深层利益、相关法律原则，以及调解或和解的可能方向。

本技能适用于各种民事和商事争议：合同纠纷、商业分歧、财产冲突、劳动问题、消费者索赔等。它采取以解决为导向的方法，不仅关注法律权利，还关注达成协议的务实路径。

调解，其核心是由中立第三方协助争议各方进行谈判。与仲裁或诉讼不同，调解员没有决定权——解决方案由当事人自己打造。本技能帮助律师或调解员准备使该解决方案成为可能的分析性基础工作。

## 为何重要

调解员或律师准备调解时面临一个常见挑战：他们收到一堆材料——诉状、合同、电子邮件、发票——需要快速提炼争议的本质。各方到底在哪些问题上意见不合？每方真正想要什么？哪里有妥协空间？本技能自动化分析性的繁重工作，使律师可以专注于策略和人的判断。

好的调解准备意味着不仅要理解法律立场，还要理解深层利益、关系动态以及各方面临的现实约束。目标是超越过错之类的法律概念，走向对各方实际需求的共同理解——这正是使调解结果比强加结果更持久的原因。

## 两种操作模式

本技能根据用户的接洽方式支持两种工作流：

### 模式 A：引导式信息收集

当用户没有预先提供案件材料，或材料不完整时使用此模式。在生成分析之前，引导用户完成结构化的受理过程。

### 模式 B：直接分析

当用户已提供所有相关案件材料（上传文件、粘贴文本或详细描述）时使用此模式。跳过受理，直接进入分析。

**如何决定：** 如果用户在第一条消息中上传文件或提供详细的案件描述，使用模式 B。如果他们说了"我有一个调解案件"或"帮我准备调解"但未提供材料，使用模式 A。

## 模式 A：引导式信息收集

### 第 1 步：案件概览

以自然、对话式的方式向用户询问以下内容：

**基本信息：**
- 争议性质（合同、劳动、财产、商业等）
- 涉及的当事人（姓名/角色，他们之间的关系）
- 简要事实背景——发生了什么？
- 关键事件的时间线
- 当前状态（诉前、诉讼进行中、法院委托调解、自愿调解等）

**提示示例：**
> "为准备一份彻底的争议分析，我需要了解案件。您能否告诉我：
> 1. 这是什么类型的争议（如合同、劳动、商业）？
> 2. 当事人是谁，他们之间是什么关系？
> 3. 发生了什么——关键事实和时间线？
> 4. 当前状态如何——诉讼已开始，还是诉前？
>
> 您有尽可能多的细节都可以分享。您也可以上传任何案件文件（诉状、合同、往来信函），我会提取相关信息。"

### 第 2 步：深入挖掘

基于初步信息，提出有针对性的后续问题：

- 各方各主张什么？他们寻求什么结果？
- 之前是否有任何和解尝试或谈判？
- 关键文件是什么（合同、电子邮件、发票）？
- 是否存在情感或关系因素（持续的商业关系、家庭纽带、声誉关切）？
- 是否有时间压力或外部约束（截止日期、现金流问题、监管要求）？
- 用户是否已识别任何潜在的妥协领域？
- 各方之间是否存在感知到的权力失衡？（如大公司与个人、雇主与雇员、资深方与资浅方）
- 权限情况如何——谈判桌上的人是否有权同意最终解决方案？

根据具体案件调整这些问题——并非所有问题每次都有相关性。

### 第 3 步：进入分析

一旦收集到足够信息，进入下文的分析框架。

## 模式 B：直接分析

当用户预先提供案件材料时，在生成输出之前彻底阅读和分析。材料可能包括：

| 材料类型 | 需提取的内容 |
|---|---|
| 诉状 / 书面陈述 | 各方的事实主张、法律论证和请求的救济 |
| 合同 / 协议 | 相关条款、义务、违约指控、歧义条款 |
| 往来信函（电子邮件、信件） | 事件时间线、自认、语气/关系动态、谈判历史 |
| 证据（发票、照片、报告） | 支持性事实、损害赔偿数额、可信度指标 |
| 先前的和解沟通 | 先前的要约、被拒绝的提案、接近一致的领域 |

审查材料后，直接进入分析框架。

## 分析框架

这是本技能的核心。无论信息是通过模式 A 还是模式 B 收集的，输出都遵循此结构：

### 1. 案件摘要

撰写一份简洁、中立的事实摘要（通常 1-2 段）。应：
- 识别当事人及其关系
- 按时间顺序描述关键事件
- 说明当前程序状态
- 注明任何先前的谈判或和解尝试
- 以中立语言撰写——不偏向任何一方的叙事

### 2. 争议问题

识别并列出各方意见不合的每个独立问题。对每个问题：

**问题[编号]：[描述性标题]**
- **A 方立场：** A 方在此问题上的主张及理由
- **B 方立场：** B 方在此问题上的主张及理由
- **关键证据：** 与该问题最相关的文件或事实
- **强度评估：** 对各方立场坦诚、平衡的评估（强 / 中 / 弱），附简要论证

按重要性组织问题——最重要或最有价值的问题优先。

通常一个争议有 2-6 个核心问题。如果识别出超过 6 个，考虑是否可以将一些归组。如果似乎只有 1 个，更仔细地看——通常有值得拆分的子问题（如责任与金额，或不同的违约指控）。

列出个别问题后，建议在调解中处理这些问题的顺序。考虑从最可能达成一致的问题开始以建立势头，或如果各方需要看到核心问题取得进展后才参与次要事项，则从最关键的问题开始。说明推荐顺序背后的理由。

### 3. 深层利益分析

此节超越法律立场，识别各方实际需要或想要什么。理解利益而非仅理解立场，是使调解结果成为可能——且比强加结果更持久——的原因。

**A 方的利益：**
- 法律利益（权利、应得权益、先例）
- 商业利益（金钱、业务连续性、市场地位）
- 关系利益（声誉、持续关系、信任）
- 情感利益（认可、道歉、公正感、保全面子）
- 程序利益（对公平程序的渴望、被倾听、有发言权）

**B 方的利益：**
- 与上述相同的框架

**共同或相容的利益：**
- 识别双方共同拥有的任何利益（如双方都想维护商业关系、双方都想避免公开、双方都面临时间压力、双方都想最小化法律成本）
- 这些共同利益是建立协议的基础

**潜在障碍：**
- 可能阻碍理性谈判的强烈情绪
- 各方之间的成见或误解
- 沟通困难（语言、文化差异、敌意）
- 外部压力（利益相关方、公众关注、监管约束）

### 4. 法律分析

对每个关键问题，提供简要的法律分析。应：
- 识别适用的通用法律原则（合同法、侵权法、衡平法等）
- 注明案件如果进入庭审可能的法律结果（以帮助校准和解预期）
- 标注任何一方的重要法律不确定性或风险
- 以名称引用相关法律原则（如"减损义务"、"合同受挫"、"不当得利"），除非用户指定了司法辖区，否则不引用具体法条

法律分析应务实且以结果为导向——聚焦于帮助用户理解诉讼风险格局，而非提供学术论文。重点是为调解策略提供信息：理解自身诉讼风险的当事人更有能力作出理性的和解决定。

**重要提示：** 如果用户指定了司法辖区，相应调整法律分析。如果未指定司法辖区，适用公认的普通法和大陆法原则，并注明应寻求特定司法辖区的意见。

### 5. 调解策略与和解方向

这是对用户最有价值的部分。提供：

**BATNA/WATNA 分析：**
- **A 方的 BATNA**（谈判协议的最佳替代方案）：如果调解失败，A 方会发生什么？考虑诉讼成本、时间、成功可能性和非金钱后果。
- **A 方的 WATNA**（最差替代方案）：A 方最差的现实结果
- **B 方的 BATNA 和 WATNA：** 相同分析

**可能协议区（ZOPA）：**
- 基于法律分析和利益映射，各方的可接受结果可能在哪里重叠？
- 如果争议涉及金钱索赔，建议一个现实的和解区间并附论证

**拟议和解方向：**
呈现 2-3 个具体的和解情景，从保守到有创意：

1. **直接折中：** 折中方案或经风险调整的金钱和解
2. **基于利益的解决方案：** 超越纯法律应得权益、回应深层利益的创意选项（如重组商业条款、分期付款、未来合作、正式道歉、调整工作安排）
3. **一揽子交易**（如适用）：将多个问题的解决合并为单一协议，允许跨问题权衡

对每个情景，简要注明：
- 它为何可能有效（满足哪些利益）
- 潜在障碍
- 给调解员的建议框架

**流程建议：**

根据案件特征推荐调解形式和方式：

- **会议形式：** 联合会议、以个别会谈为主（与各方分别会面），或组合形式。当情绪高涨、存在权力失衡或各方难以直接沟通时，以个别会谈为主的形式效果良好。当关系修复是目标，或各方需要直接听到彼此的观点时，联合会议有价值。
- **共同调解：** 在存在重大权力失衡关切时推荐（如骚扰案件中的性别动态、大公司与个人）。两位调解员可以帮助较弱的一方感到更自在，并确保平衡的程序管理。
- **会议规划：** 单次会议 vs 多次会议、预计时长、与各方分别进行调解前会议是否有益。
- **调解前步骤：** 文件交换、获得专家估值、冷静期、初步会议以建立融洽关系并解释程序。
- **问题排序：** 推荐应处理问题的顺序（参考第 2 节建议的顺序）。
- **僵局策略：** 如果谈判在某个特定问题上停滞，建议方法——休息一下、转向不同问题、引入折中提案、从过去的指责转向面向未来的问题解决。

### 6. 调解准备就绪检查清单

根据具体案件提供定制检查清单。从以下项目中选取相关项：

**当事人与权限：**
- [ ] 所有直接相关当事人已识别并愿意参与
- [ ] 谈判桌上的代表有权同意最终解决方案
- [ ] 已决定律师是否出席及其角色（顾问、积极参与者、代表）
- [ ] 权力失衡考量已处理（共同调解、律师出席、个别会谈形式）

**流程设计：**
- [ ] 待调解的问题已识别并达成一致
- [ ] 调解员遴选程序已确定
- [ ] 调解协议已起草（涵盖授权、保密、费用分担、程序）
- [ ] 日期、时间和中立场地已安排
- [ ] 特殊要求已处理（翻译、无障碍、远程参与）
- [ ] 保密条款已商定并签署

**准备：**
- [ ] 关键文件已整理并按约定分享
- [ ] 披露程序已建立（预先交换或按需）
- [ ] 各方已准备开场陈述
- [ ] 调解不成功时的回退流程已确定（仲裁、诉讼等）
- [ ] 谅解备忘录框架草稿已准备
- [ ] 费用分担安排已确认

并非所有项目适用于每个案件——只纳入相关的项目。

## 语气与风格指引

- **中立且平衡：** 绝不为一方辩护。公平呈现双方。调解员的角色是公正——分析应反映这一点。
- **务实而非学术：** 聚焦于可操作的洞见，而非理论讨论。律师需要知道该做什么，而不仅仅是法律怎么说。
- **对不确定性坦诚：** 当法律立场不清楚时，直说。调解员和律师需要诚实的评估，而非虚假的信心。诚实的确定性有助于当事人作出现实的和解决定。
- **以解决为导向的语言：** 在可能的情况下，以"利益"和"选项"而非"主张"和"抗辩"的角度构建问题。将焦点从过去的指责转向未来的解决方案。
- **简洁但彻底：** 每节内容应恰到好处，但不冗长。律师的时间宝贵。
- **对动态敏感：** 注意权力失衡、情感因素和关系动态。在相关处注明，而非将争议纯粹视为法律问题。

## 免责声明

始终在分析末尾包含一条简短的免责声明：

> *本分析旨在协助调解准备，不构成法律意见。它仅基于所提供的材料和信息。应咨询相关司法辖区的合格法律专业人士以获取特定司法辖区的法律意见。本文件为保密文件，仅为调解目的而准备。*

## 处理边界情形

- **信息不足：** 如果用户提供的信息非常有限，生成你能生成的，但清楚标注分析的哪些部分是推测性的，以及哪些额外信息会提高准确性。
- **多方争议：** 调整框架以适应两方以上的当事人。每一方都有其自身的立场/利益分析。考虑当事人子群体是否共享利益并可能作为一个集团进行谈判。
- **权力失衡：** 如果材料表明存在重大权力失衡（如大公司与个人、雇主与雇员），在流程建议中突出注明。建议以个别会谈为主的形式、共同调解，或确保较弱的一方有独立法律顾问。调解员有责任确保权力失衡不损害程序。
- **情绪化/高冲突案件：** 如果争议看起来高度情绪化（家族企业破裂、就业歧视、骚扰等），强调基于利益的分析，推荐以个别会谈为主的调解形式，并建议调解前会议以建立融洽关系和管理预期。在实质谈判开始之前，强烈情绪需要先被承认和验证。
- **跨境争议：** 标注潜在的司法辖区复杂性，并注明适用法律的确定本身可能就是一个争议问题。考虑各方之间的文化差异是否可能影响调解动态。
- **先前谈判失败：** 如果先前的和解尝试失败，分析原因并建议对方法进行调整（不同的调解员风格、创造新契机的情况变化、重新构建问题）。
- **政府或机构当事人：** 注明机构当事人可能面临和解权限方面的约束（多重审批层级、政策要求、公共问责）。建议在开始时确认和解权限。
