# 法律日报

每日自动聚合中国法律领域最新资讯，生成精美的单文件 HTML 仪表盘。

## 触发条件

以下任一表达即触发：
- "法律日报" / "法律晨报" / "今日法律圈"
- "生成法律日报" / "法律资讯仪表盘" / "法律新闻汇总"
- "今天法律圈有什么新闻" / "最近法律行业动态"
- 任何请求"以仪表盘形式展示法律资讯"的表述

## 工作流程

### 第一步��并行检索数据

读取 `references/search-strategy.md` 了解完整搜索策略。

通过 WebSearch 分 5 组并行检索，每组覆盖多个子维度：

| 组号 | 版块 | 搜索主题 | topic |
|------|------|----------|-------|
| 1 | 法律发布/更新 | 2026年中国新法规+司法解释+部门规章 | news |
| 2 | 产品发布/更新 | 法律科技+法律AI产品发布+智慧法院 | news |
| 3 | 行业动态 | 律所动态+律师行业+典型案例+合规监管 | news |
| 4 | 论文研究 | 法学期刊+法学论文+学术动态 | news |
| 5 | 技巧与观点 | 法律实务+律师技巧+合规观点+辩护策略 | news |

每组必须使用 `query_keyword_groups` 覆盖 4–5 个子维度。每组返回 5 条结果。

**降级**：若某组返回不足 3 条有效结果，以更宽泛的关键词补搜一次。详见 `references/search-strategy.md`。

### 第二步：数据筛选

从返回结果中，每版块筛选 3 条最相关、最高质量的条目。筛选标准：
1. 优先来自 L1（官方）和 L2（主流媒体）来源
2. 优先时间最近的条目
3. 优先内容完整、可提取摘要的条目
4. 每个版块至少 2 条，目标 3 条
5. 如果某版块确实缺乏数据，标注"暂无当日更新"并说明原因

### 第三步：构建 HTML 仪表盘

读取 `assets/dashboard-template.html` 了解完整的 HTML 结构和样式规范。

生成单文件 HTML 的核心原则：

**数据注入**：
- 从搜索结果中为每条资讯提取：标题、来源名称、来源 URL、发布时间、不超过 60 字的中文摘要
- 根据版块名称分配 `chip-legal` / `chip-product` / `chip-industry` / `chip-paper` / `chip-tips` CSS 类
- 所有条目按版块顺序全局连续编号（#1–#N），不在版块内重新计数

**HTML/CSS 规范**（严格遵循，见模板获取准确代码）：
- 纯 HTML/CSS/JS 单文件，所有样式与脚本内联
- 不引入任何外部资源（无 CDN、无外部字体链接）
- 使用系统字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", ...`
- CSS 变量定义在 `:root` 中：`--bg`, `--card-bg`, `--text`, `--accent`, `--border` 等
- 每张卡片包含：全局序号水印（绝对定位、右上角、半透明）、来源 chip、60 字内摘要、原文链接
- 原文链接必须设置 `target="_blank" rel="noopener noreferrer"`
- 浅色主题（Light theme），白色卡片、暖灰色背景、棕色系强调色

**页面结构**（四段式）：
1. **Hero 区域**：深色渐变背景，显示"法域资讯 · 法律日报"、日期、总条数（大号渐变金色数字）、五个版块统计 chip
2. **锚点导航**：粘性定位（sticky），毛玻璃效果，5 个锚点链接，滚动高亮当前版块
3. **正文区域**：5 个 section，每个包含标题行（图标 + 标题 + 计数）和卡片网格（`grid-template-columns: repeat(auto-fill, minmax(320px, 1fr))`）
4. **页脚**：总条数统计 + 数据来源列表

**响应式断点**：
- ≤768px：Hero 缩小、标题字号调整、卡片单列
- ≤480px：进一步缩小字号和间距

**JavaScript 交互**：
- IntersectionObserver 实现卡片滚动渐入动画
- 滚动监听实现导航高亮切换
- 导航链接点击平滑滚动到对应版块

**时间格式**：
- 所有时间转换为北京时间（CST/UTC+8）
- 使用自然语言展示："今天 HH:MM"、"昨天 HH:MM"、"MM月DD日"、"近期"
- 禁止展示 ISO 时间字符串或 Unix 时间戳

### 第四步：输出结果

1. 将完整的 HTML 写入工作区根目录的 `legal-morning-briefing.html`
2. 使用 `present_files` 展示文件，触发浏览器预览
3. 以简洁文字告知用户本日条目总数和各版块分布

## 版块分类速查

读取 `references/categories.md` 了解详细定义。

| 版块 | 编号前缀 | chip 类 | 典型标签 |
|------|----------|---------|----------|
| 法律发布/更新 | #1 开始 | chip-legal (绿) | 立法动态、行政法规、新规施行 |
| 产品发布/更新 | 接上 | chip-product (蓝) | 硬件发布、平台发布、智能体 |
| 行业动态 | 接上 | chip-industry (琥珀) | 律师峰会、公共法律、实务指南 |
| 论文研究 | 接上 | chip-paper (粉) | 法学研究、核心期刊 |
| 技巧与观点 | 接上 | chip-tips (紫) | 跨境合规、刑事辩护、企业法务 |

## 数据来源声明

页脚必须注明数据来源。L1 优先来源：全国人大、国务院、最高人民法院、最高人民检察院、司法部。L2：新华网、央视网、人民网。L3：法学研究、各法学期刊、专业法律平台。

## 工作区保存

生成日报后，在工作区 `.workbuddy/memory/YYYY-MM-DD.md` 追加一条记录，简述本日生成的日报概况（总条数、各版块数量、是否有数据不足的版块）。

## 注意事项

- 若当天为周末或节假日，法律新闻量会偏少，在 Hero 区或文末可以温馨说明
- 摘要必须精炼、有信息量，禁止重复标题内容
- 同一主题的多篇报道只选取最权威的来源，避免重复
- 每个版块至少 2 条，总量控制在 10–18 条之间
