# 绩效制度合规审查器

## 概述

面向 HRBP、绩效 COE 和法务合规人员的绩效管理制度合规审查工具。逐条扫描 PIP、末位淘汰、试用期评估、调岗降薪等绩效制度条款，对照现行法律法规识别合规风险，给出分级修改建议和替代方案。

绩效制度的合规性往往被忽视——等到争议发生时才发现制度存在硬伤，已经付出了管理成本、员工关系和潜在的法律代价。本工具在制度发布前完成审查，将风险消灭在设计阶段。

## 解决的核心问题

| 痛点 | 审查方式 |
|------|---------|
| 制度起草者不懂法、懂法者不参与起草 | 逐条对照法律法规扫描，覆盖程序+实体+措辞 |
| PIP 被写成变相劝退 | 专项检查：目标可达性、周期合理性、培训/调岗前置 |
| 末位淘汰直接套用外部实践 | 专项检查：末位≠不胜任的法律界定、法定程序完整性 |
| 试用期录用条件无法举证 | 专项检查：录用条件的可量化程度、证据链完整性 |
| 调岗降薪踩中单方变更雷区 | 专项检查：调岗合理性、降薪限度、员工同意 |

## 四大高风险场景

| 场景 | 核心审查点 |
|------|----------|
| PIP | 目标可达性、周期合理性、培训/调岗前置、告知义务、特殊保护例外 |
| 末位淘汰 | 末位是否等同不胜任、法定程序完整性、特殊保护、补偿义务 |
| 试用期评估 | 录用条件可量化、评估时限、证据链、告知义务 |
| 调岗降薪 | 调岗合理性、薪酬调整限度、员工同意、书面记录 |

## 输入要求

- **必填**：制度文本、制度类型（PIP / 试用期评估 / 绩效分布与淘汰 / 调岗调薪 / 综合）
- **可选**：适用地区范围、制度用途（初次发布/修订对比）

## 输出内容（五板块）

1. **条款逐条审查**：原文 + 🔴/🟡/🟢/⚪ 定级 + 合规依据 + 风险说明 + 修改建议 + 改写示例
2. **整体合规评分**：五维评分（实体/程序/完整性/可操作性/措辞）+ 合规等级
3. **高风险条款汇总**：按严重度排序 + 法律后果 + 整改紧急度 + 工作量评估
4. **专项场景检查清单**：按制度类型输出逐项 ✅/⚠️/❌ 检查清单
5. **制度优化路线图**：紧急修复（1 周）→ 制度完善（下次修订）→ 长期建设（按需）

## 适用场景

- 新绩效制度发布前的合规自检
- 现有制度年审时做合规扫描
- 制度修订时做修改前后的差异合规审查
- 被员工发起争议后的制度补救性审查
- 跨地区制度适用性审查

审查意见为基于通用法律法规的分析参考，不构成正式法律意见。高风险条款建议咨询专业法律顾问。
