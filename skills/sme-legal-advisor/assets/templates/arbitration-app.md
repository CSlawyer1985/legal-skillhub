# 劳动仲裁申请书 模板

> 劳动仲裁是劳动争议诉讼的前置程序，大多数劳动争议必须先经过仲裁才能起诉法院。

---

**劳动仲裁申请书**

**申请人**：[姓名]，[性别]，[民族]，[出生日期]，
身份证号：[号码]，住址：[地址]，
联系电话：[电话]。

**被申请人**：[单位全称]，
统一社会信用代码：[代码]，
住所地：[地址]，
法定代表人：[姓名]，职务：[职务]，
联系电话：[电话]。

**仲裁请求**：

1. 裁决被申请人向申请人支付 [款项性质，如：未签订劳动合同的双倍工资差额/违法解除劳动合同赔偿金/拖欠工资/加班费/工伤赔偿] ¥[金额]；
2. 裁决被申请人向申请人支付 [其他请求] ¥[金额]；
3. 裁决被申请人为申请人补缴自[开始日期]至[结束日期]的[社会保险/公积金]；
4. 以上合计 ¥[总金额]。

**事实与理由**：

| 项目 | 内容 |
|------|------|

| 离职时间（如在职则不填） | [年]年[月]月[日] |
| 工作岗位 | [岗位名称] |
| 月工资标准 | ¥[金额]（[税前/税后/到手]） |
| 劳动合同签订情况 | [已签/未签]，签订时间：[日期] |
| 社保缴纳情况 | [已缴/未缴/部分缴纳] |
| 离职原因 | [主动辞职/公司辞退/协商解除/到期终止/其他] |

二、争议经过

**[按时间线描述，可直接引用下方模板]**

在职期间，被申请人存在以下违法行为：

1. **[争议事项1]**：[具体描述]

综上，为维护申请人的合法权益，依据《中华人民共和国劳动争议调解仲裁法》第2条之规定，特向贵委申请仲裁，请依法裁决。

**附件**：
1. 本申请书副本 [1] 份
2. 申请人身份证复印件
3. 被申请人工商登记信息
4. 证据清单：
   - 证据1：[证据名称]，证明：[事实]
   - 证据2：[证据名称]，证明：[事实]
   - 证据3：[证据名称]，证明：[事实]

---

> ⚠️ 注意事项：
> 1. 劳动仲裁对劳动者免费，不收仲裁费
> 2. 仲裁时效：知道或应当知道权利被侵害之日起 **1年内**
> 3. 管辖：劳动合同履行地或用人单位所在地的劳动仲裁委
> 4. 申请书需本人签名，按被申请人数量+1份提交副本
> 5. 一般仲裁申请后45日内裁决，可延长15日
