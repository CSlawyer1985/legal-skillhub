# 诉讼决策知识库

## 一、诉讼胜算评估框架

### 四维评分模型

| 维度 | 满分 | 评估细则 |
|------|------|---------|
| 证据强度 | 35分 | 关键证据完整性、真实性、合法性、证明力 |
| 法律依据 | 30分 | 法条明确性、司法实践一致性、是否存在争议 |
| 程序合规 | 15分 | 时效、管辖、主体适格 |
| 对方状况 | 20分 | 偿债能力、下落、对抗能力 |

### 证据强度评分细则

| 证据类型 | 证明力 | 评分 |
|----------|--------|------|
| 书面合同（有签字/盖章） | ★★★★★ | +15~20分 |
| 银行转账记录 | ★★★★★ | +10~15分 |
| 微信/邮件记录 | ★★★★ | +8~12分 |
| 录音/录像 | ★★★ | +5~10分（需合法取得） |
| 证人证言 | ★★ | +3~5分（辅证，不能独立证明） |
| 单方记录（自己的账本等） | ★ | +1~3分（证明力弱） |

### 法律依据打分细则

| 法律状态 | 评分 |
|----------|------|
| 法条明确规定支持 | +25~30分 |
| 司法解释明确支持 | +22~28分 |
| 一般性规定可类推适用 | +15~20分 |
| 存在争议/各地判决不一 | +8~15分 |
| 法律无明确规定 | +0~5分 |

## 二、民事诉讼费速算

财产案件按争议金额分段计收（《诉讼费用交纳办法》第13条）：

| 争议金额区间 | 收费比例 | 累进加法 |
|------------|---------|---------|
| ≤1万元 | 50元 | 固定 |
| 1万-10万 | 2.5% | 50 + (金额-1万)×2.5% |
| 10万-20万 | 2% | 2300 + (金额-10万)×2% |
| 20万-50万 | 1.5% | 4300 + (金额-20万)×1.5% |
| 50万-100万 | 1% | 8800 + (金额-50万)×1% |
| 100万-200万 | 0.9% | 13800 + (金额-100万)×0.9% |
| 200万-500万 | 0.8% | 22800 + (金额-200万)×0.8% |

### 劳动争议案件
- 诉讼费每件 **10元**（适用简易程序减半为5元）
- 仲裁阶段 **免收仲裁费**（劳动仲裁对劳动者免费）

|----------|---------|---------|------|
| 劳动争议（仲裁+一审） | 6-12个月 | 3-6个月 | 仲裁45日+一审6个月 |

## 四、替代方案决策树

```
纠纷发生
├── 证据充分 + 对方有偿还能力 ?
│   ├── YES → 争议金额 > 诉讼成本 ?
│   │   ├── YES → 建议起诉/仲裁 ✅
│   │   └── NO  → 建议谈判/发律师函 ⚠️（如果不差钱也要争 → 起诉）
│   └── NO  → 先收集证据 + 发律师函固定证据
├── 证据不足 + 对方有偿还能力 ?
│   └── 先沟通留痕 → 收集证据 → 再评估
└── 对方无偿债能力 ?
    ├── 有可供执行的财产 → 起诉 + 申请诉讼保全
    └── 无任何财产 → 不建议诉讼（赢了也执行不了，白花诉讼费）
```

## 五、各类纠纷评估要点摘要

### 合同纠纷
- 关键证据：合同原件、付款凭证、交付记录、催款记录、对方确认对账单
- 常见抗辩理由：合同无效（欺诈/胁迫/无资质）、已履行、诉讼时效已过、质量不合格
- 评估重点：合同是否有效 → 违约事实是否成立 → 损失能否量化 → 对方有无抗辩空间

### 借款纠纷
- 关键证据：借条/借款合同、转账记录、利息约定证明、催款记录
- 利率审查：年利率 > LPR 4倍（当前约13%-14%）的超出部分不受保护
- 特殊情形：非法借贷（赌博欠款、走私资金等）、明知他人用于违法活动仍出借
- 诉讼时效：借条约定了还款日期的，从到期日起算3年；未约定的，从出借人主张还款的宽限期满起算

### 劳务/劳动纠纷
- 先判定是劳动关系还是劳务关系（关键区别：是否接受管理、是否固定报酬、是否有社保）
- 劳动关系 → 仲裁前置（必须先仲裁才能诉讼）
- 劳务关系 → 直接诉讼

### 贷款纠纷中的特殊保护
- 金融机构贷款：按合同约定利率，但须符合监管规定
- 小额贷款公司：利率参照民间借贷（LPR 4倍）
- 非法放贷（无金融牌照机构放贷）→ 可主张合同无效

## 六、常见"值不值得打"判断表

| 争议金额 | 是否值得起诉 | 理由 |
|----------|------------|------|
| < 1000元 | 一般不推荐 | 诉讼费+时间成本 > 争议金额 |
| 1000-5000元 | 视情况 | 简易程序可快速处理，但时间成本较高 |
| 5000-5万元 | 推荐 | 劳动争议直接推荐，合同案件看证据 |
| 5万-50万元 | 强烈推荐 | 律师费物有所值 |
| > 50万元 | 必须打 | 建议必须委托律师处理 |
