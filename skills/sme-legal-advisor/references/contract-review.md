# 合同审查方法论

## 合同审查的思维框架

### 四步审查法

1. **定性**：这是什么类型的合同？（买卖/服务/租赁/借款/劳动/合伙/装修/运输/承揽）
2. **定向**：用户是哪一方？（甲方/乙方）→ 立场决定审查重点
3. **定锚**：核心权利义务是什么？（付多少钱/提供什么/何时交付/质量如何）
4. **定钉**：违约和争议如何解决？（违约责任条款+争议解决条款）

## 不同合同类型的高危清单

### 买卖合同
| 高危点 | 表现 | 提示 |
|--------|------|------|
| 质量标准模糊 | "符合质量标准"未指明标准编号 | 要求注明 GB/T 或行业标准号 |
| 验收期限过短 | "货到24小时内提出异议" | 建议至少5-7个工作日 |
| 违约金单向 | 只约束卖方不约束买方 | 要求对等设置违约金 |
| 管辖在卖方 | 由卖方所在地法院管辖 | 争取在买方/合同履行地 |
| 付款条件苛刻 | 全额预付 | 建议分批次付款，保留部分尾款 |

### 服务合同
| 高危点 | 表现 | 提示 |
|--------|------|------|
| 服务标准不明确 | "高质量""优质服务"等主观词 | 要求KPI化、可量化 |
| 单方变更权 | "甲方有权随时变更服务内容" | 要求变更须双方同意或补差价 |
| 知识产权归属模糊 | 成果归谁没写清楚 | 明确约定归属和许可范围 |
| 验收标准缺失 | 没有验收程序 | 设定验收节点和验收标准 |

### 借款合同
| 高危点 | 表现 | 提示 |
|--------|------|------|
| 利率超过LPR4倍 | 年利率超过约14% | 超出部分法院不支持 |
| 砍头息 | 借款金额扣除利息后发放 | 实际到账金额才是本金 |
| 担保约定不清 | 未明确是一般保证还是连带责任保证 | 债权人尽量争取连带责任保证 |
| 还款方式不明确 | 等额本息or先息后本未约定 | 明确约定避免争议 |

### 租赁合同
| 高危点 | 表现 | 提示 |
|--------|------|------|
| 转租权未约定 | 未说明能否转租 | 明确是否允许转租及条件 |
| 维修责任不清 | 大修小修归属模糊 | 出租方承担主要维修 |
| 装修归属 | 退租后装修归谁 | 明确拆除/补偿/折价方案 |
| 押金退还条件 | "有损坏即不退" | 按合理损耗与人为损坏区分 |

### 劳动合同
| 高危点 | 表现 | 提示 |
|--------|------|------|
| 试用期过长 | 3年合同约6个月试用期 | 3年合同试用期不超2个月（法律已规定，此配置合法但建议缩减） |
| 不定额工作制 | 随意约定"不定时工作制" | 须经劳动部门审批 |
| 竞业限制过宽 | 限制所有员工 | 只适用于高管、高技、保密人员 |
| 扣押证件/押金 | 要求交押金或抵押证件 | 绝对禁止（第9条） |
| 放弃社保条款 | 约定"员工自愿放弃社保" | 无效！社保是法定强制义务 |

## 格式条款判例规则（《民法典》第496-498条）

以下情形格式条款无效：
1. 排除对方主要权利
2. 免除自身责任（"概不负责"类条款）
3. 加重对方责任（违约金离谱）
4. 不合理限制对方权利

## 合同扫描快速检查清单

每次审查合同必须逐项检查以下 10 项：

- [ ] 1. 合同主体信息是否完整（名称、住所、统一社会信用代码/身份证号、联系方式）
- [ ] 2. 标的/商品/服务描述是否明确无歧义
- [ ] 3. 价款/酬金金额、税率（含税/不含税）、支付节点是否清晰
- [ ] 4. 质量标准和验收方式是否有客观标准
- [ ] 5. 交付/履行期限和地点是否明确
- [ ] 6. 违约责任是否对等、合理
- [ ] 7. 争议解决方式是否对己方有利（诉讼/仲裁、管辖地）
- [ ] 8. 合同解除条件是否合理
- [ ] 9. 送达地址条款是否存在
- [ ] 10. 有无模糊/空白处
