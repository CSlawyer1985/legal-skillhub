# 薪酬合规审查器（Compensation Compliance Auditor）

> ⚖️ 把"等员工举报才知道有问题 → 仲裁输了才想起改"的被动补救，升级为"一键扫描 → 风险分级 → 整改方案 → 法律依据引用"的主动防御体系。

---

## 这是什么？

一个薪酬合规风险扫描工具。输入公司所在城市和员工薪酬明细，自动逐人逐项比对法规，按风险等级排序输出：

1. **审查总览**（风险仪表盘 / 合规率 / Top 3 风险项）
2. **最低工资审查**（实发 vs 当地最低工资，低于即标红）
3. **社保公积金合规审查**（基数 vs 实际工资 / 低缴 / 漏缴 / 公积金比例）
4. **加班费合规审查**（计算基数是否合规 / 差额预估 / 潜在赔偿）
5. **同工同酬与薪酬公平审查**（同岗位薪资离散度 / 差异可解释性）
6. **其他合规项**（试用期工资 / 经济补偿金 / 工资支付周期 / 特殊津贴）

## 适用场景

| 你遇到的情况 | 怎么用 |
|-------------|--------|
| 不知道公司社保基数有没有问题 | 输入员工工资+社保基数，自动比对并标注低缴/漏缴 |
| 担心加班费基数用错了 | 输入加班费计算方式，自动判断是否合规 + 预估差额 |
| 准备融资/IPO，需要合规底稿 | 全量扫描 → 输出完整合规审查报告（投资方尽调可用） |
| 同岗位薪资差异大，怕被举报 | 同工同酬分析 → 离散系数 + 差异可解释性审查 |
| 试用期工资设了八折，怕违规 | 自动比对 80% 红线 + 最低工资红线 |
| 解除劳动合同，补偿金算对没 | 经济补偿金基数审查（基本工资 vs 12个月均资） |
| 想定期自检，不知道检查什么 | 一键全量扫描，按严重/较高/中等/合规四级输出 |

## 输入说明

### 员工数据格式（每条一行，逗号分隔）

```
姓名,岗位,职级,合同工资,实发月工资,社保月缴费基数,公积金月缴费基数,公积金比例(%),加班费计算基数说明,入职日期,试用期月工资
```

### 必填 vs 可选

| 字段 | 必填 | 说明 |

| 公司所在城市 | 是 | 匹配当地最低工资/社保基数/公积金比例 |
| 姓名/岗位/合同工资/实发工资/社保基数 | 是 | 核心审查字段 |
| 公积金基数/比例 | 是 | 公积金合规必填 |
| 加班费计算基数说明 | 是 | 加班费合规必填 |
| 试用期工资 | 是 | 试用期审查必填 |
| 绩效数据 | 否 | 做薪酬公平性分析用 |
| 性别/年龄/户籍 | 否 | 做就业歧视风险扫描 |

## 风险分级

| 等级 | 定义 | 示例 |
|------|------|------|
| 🔴 严重 | 明确违法，面临行政处罚或仲裁败诉 | 实发 < 最低工资、社保未开户、试用期 < 80% |
| 🟡 较高 | 灰色地带，有被稽查/仲裁风险 | 社保低缴、加班费基数不合规、同岗位差 > 50% |
| 🟠 中等 | 接近红线，需尽快整改 | 公积金 5%（虽合法但偏低）、试用期正好 80% |
| 🟢 合规 | 符合法规要求 | — |

## 能力边界

### 能做的

- 七维度合规审查（最低工资/社保/公积金/加班费/同工同酬/试用期/其他）
- 逐人逐项扫描 + 差额预估 + 滞纳金估算
- 内置主要城市法规数据（最低工资/社保上下限/公积金比例）
- 整改优先级排序 + 预估整改成本 + 时间线建议
- 法律条文原文引用

### 不能做的

- 不能替代律师出具正式法律意见书
- 不处理劳动仲裁案件
- 不处理非中国法规（外资企业海外员工）
