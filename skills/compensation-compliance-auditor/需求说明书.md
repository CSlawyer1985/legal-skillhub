# 薪酬合规审查器 - 需求说明书

## 1. 产品定位

面向 HR、法务和 CFO 的薪酬合规风险扫描工具。薪酬合规是 HR 的"地雷区"——最低工资没达标、加班费基数用错了、社保按最低交但实际工资高出一大截、试用期工资低于转正的 80%、同岗位薪资差一倍被员工举报到仲裁。这些坑任何一个踩中，轻则补缴罚款，重则劳动仲裁赔几倍工资。

本工具将"等员工举报才知道有问题 → 仲裁输了才想起改"的被动补救模式，升级为"一键扫描 → 风险分级 → 整改方案 → 法律依据引用"的主动防御体系。

## 2. 痛点

1. **最低工资红线不清楚**：全国各省市最低工资标准不一样（北京/上海/深圳/广州/各省），HR 不知道当前员工有没有达标，尤其是扣完社保公积金后的实发工资是否 >= 最低工资。

2. **加班费基数用错了**：很多公司用"基本工资"或"最低工资"作为加班费计算基数，但实际上加班费基数是"劳动合同约定的工资"，如果合同没约定应该是"实际工资"。用错基数 = 少付加班费 = 一旦仲裁判赔 2 倍差额。

3. **社保公积金基数不合规**：实际月薪 2 万但社保按最低基数 5000 交、公积金按 5% 最低比例交。表面省了公司成本，一旦被稽查要补缴 + 滞纳金 + 罚款。

4. **同工同酬隐患**：同岗位、同绩效、同资历，一个拿 1.5 万一个拿 2.5 万，差了一倍。如果拿低的是女性/年长者/非本地户籍，还可能叠加就业歧视。

5. **试用期工资违规**：试用期工资 < 转正后的 80%，或者 < 当地最低工资。很多公司试用期打 7 折甚至 6 折，属于违规。

6. **经济补偿金基数用错了**：解除劳动合同时，经济补偿金的计算基数应该是"离职前 12 个月的平均工资"（含奖金/提成/津贴），而不是基本工资。很多 HR 只用基本工资算，少付了补偿金。

## 3. 目标用户

- HR 负责人（主使用者，定期合规自检）
- 法务/合规部门（年度审计、并购尽调）
- CFO（薪酬成本合规风险评估）

## 4. 核心功能

### 4.1 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 员工薪酬数据 | 是 | 姓名/岗位/职级/合同工资/实发工资/社保基数/公积金基数/公积金比例/加班费计算方式/入职日期/试用期工资 |
| 地区信息 | 是 | 公司所在城市（用于匹配当地最低工资标准） |
| 行业信息 | 否 | 行业（用于判断是否有行业特殊规定） |
| 审查范围 | 否 | 全量审查 / 仅高风险项 / 指定审查维度 |

### 4.2 输出结构（六板块）

#### 第一板块：审查总览

- 风险统计仪表盘（高风险/中风险/低风险/合规，四类计数）
- 合规率（合规员工数 / 总员工数）
- 最易踩中的 Top 3 风险项

#### 第二板块：最低工资审查

- 逐一比对：实发工资 vs 当地最低工资标准
- 标注低于标准的员工（红标）
- 标注接近标准的员工（距离标准 ≤ 10%，黄标预警）
- 引用当地最低工资文件号和生效日期

#### 第三板块：社保公积金合规审查

- 逐一比对：社保缴费基数 vs 实际工资
- 标出低缴（基数 < 实际工资 70%）/ 漏缴（未申报）的员工
- 公积金比例检查（是否低于当地最低比例）
- 预估补缴金额和滞纳金
- 引用《社会保险法》第十二条、《住房公积金管理条例》第二十条

#### 第四板块：加班费合规审查

- 检查加班费计算基数是否合规
- 工作日加班 1.5 倍 / 休息日 2 倍 / 法定节假日 3 倍是否执行
- 综合工时制审批状态检查（未审批但按综合工时制发加班费 → 违规）
- 预估加班费差额及潜在赔偿金额
- 引用《劳动法》第四十四条

#### 第五板块：同工同酬与薪酬公平审查

- 同岗位同职级的薪资差距分析（离散系数 CV > 30% 高亮）
- 按性别/年龄/户籍维度的薪酬差异显著性检查
- 绩效与薪酬相关性分析（高绩效低薪酬 = 异常）
- 引用《劳动合同法》第六十三条（同工同酬）

#### 第六板块：其他合规项扫描

- 试用期工资（是否 ≥ 转正工资 80%，是否 ≥ 最低工资）
- 工资支付周期（是否按时足额发放）
- 经济补偿金基数（解除合同场景下计算是否正确）
- 高温津贴/夜班津贴等特殊津贴是否合规
- 综合报告：整改优先级排序 + 预估整改成本 + 整改时间线建议

### 4.3 风险分级标准

| 等级 | 定义 | 示例 |
|------|------|------|
| 🔴 严重 | 明确违法，面临行政处罚或仲裁败诉 | 实发工资 < 最低工资、社保未开户、试用期工资 < 80% |
| 🟡 较高 | 灰色地带，有被稽查/仲裁风险 | 社保基数按最低缴但工资高、加班费基数用基本工资、同岗位薪资差 > 50% |
| 🟠 中等 | 接近合规红线，需尽快整改 | 公积金比例低于当地推荐、试用期工资刚好 = 80% |
| 🟢 合规 | 符合法规要求 | — |
