# 通过增益分享激励减排

## 条款名称

Zeela's Clause（泽拉条款）

## 摘要

本条款激励相对方减少温室气体排放，以换取按其所提供商品或服务价值计算的增益分享付款。

## 本条款的作用

在合同期内以减少温室气体（也称 GHG）排放换取增益分享付款，是促使缔约方脱碳的有力激励——尤其是在利润微薄的行业（如建筑业）或正经历激进成本节约的商业环境中。

## 条款内容

*\[起草注：大写术语与本条款中的定义术语或本条款拟插入的主协议中的定义术语相关。\]*

**1. 测量、管理和报告温室气体排放**

1.1 乙方应在合同期内测量、管理和书面报告其温室气体排放，并按本条款的规定进行。

1.2 乙方应在其温室气体报告中正式采纳碳足迹标准。

1.3 乙方董事会应指定一名董事或高级管理人员，负责确保乙方在期限内遵守碳足迹标准和本条款的要求。

1.4 \[在本协议日期每个周年日后的 3（三）个月内\] 或 \[每年 3 月 1 日前\] 或 \[*其他日期*\]，乙方应向甲方提交温室气体报告。

**2. 温室气体报告的内容**

2.1 本条款 \[2\] 载明温室气体报告内容的最低要求。

2.2 温室气体报告应报告并在\[适当处\]说明：

2.2.1 乙方在前一合同年度遵循的管理和减少温室气体排放的行业最佳实践，以及乙方如何适用；

2.2.2 乙方测量的范围 1、2 和 3 排放；

2.2.3 测量的服务碳足迹；

2.2.4 测量的供应链碳足迹；\[以及\]

2.2.5 与先前温室气体报告所述范围 1、2 和 3 排放相比并按本条款 \[2.2\] 计算，乙方实现的温室气体排放减少量；

2.2.6 乙方减少范围 1、2 和 3 排放的现有和未来举措及其预期影响；

2.2.7 任何可能帮助或阻碍乙方减少范围 1、2 和 3 排放能力的法律法规；以及

2.2.8 减少范围 1、2 和 3 排放的任何障碍。

2.2.9 \[*其他要求*\]

**3. 核验**

3.1 乙方应与甲方在以下方面合作和协作：

3.1.1 乙方如何测量、管理和报告其温室气体排放；

3.1.2 乙方编制每份温室气体报告；以及

3.1.3 乙方在本条款下的其他义务。

3.2 如甲方在任何时候合理要求（且每个合同年至多一次），乙方应指定一名具备适当资质的外部审计师或其他核验机构认证其温室气体报告的内容和准确性。

3.3 乙方应承担温室气体报告外部审计和核验的所有相关费用。

\[*起草注：为更进一步，甲方可要求外部审计师或核验机构须为甲方可接受者，且不得无理拒绝或拖延同意。乙方也可要求对审计成本设定上限。*\]

**4. 温室气体排放的减少**

4.1 乙方应在每份温室气体报告所涉的每个期间内，将其温室气体排放减少不少于第 4.2 条所示百分比。

4.2 在期限内，乙方应在每个合同年度（与上一年度相比）将服务碳足迹减少 \[●\]%。

**5. 增益分享**

5.1 如乙方在任何一年内将服务碳足迹减少超过第 \[4.2\] 条所述百分比，则以下增益分享机制应适用（增益分享机制）。

5.2 YX = X 年的服务碳足迹（以吨二氧化碳当量计）

YX+1 = X+1 年的服务碳足迹（以吨二氧化碳当量计）

\[●\]% x YX = 第 4 条载明的约定服务碳足迹减少量（约定服务碳足迹减少量）（以吨二氧化碳当量计）

YX – YX+1 = X 年与 X+1 年之间服务碳足迹的绝对减少量（以吨二氧化碳当量计）（总服务碳足迹减少量）

总服务碳足迹减少量 – 约定服务碳足迹减少量 = 超过第 4 条要求的约定 \[●\]% 之上的服务碳足迹绝对减少量（额外服务碳足迹减少量）

额外服务碳足迹减少量 x 抵消 1 吨二氧化碳当量的市场费率 x 50% = 依增益分享机制支付给乙方的款项（增益分享付款）。

5.3 合同任何年度内应付给乙方的任何增益分享付款的累计最高价值，应等于乙方就该年度向甲方提供服务的价值的 \[●\]%。

5.4 增益分享付款仅在依第 \[3\] 条的任何核验流程完成后才应付。

5.5 乙方应在增益分享付款到期应付后向甲方开具发票，且在无关于增益分享付款水平的争议的情况下，甲方应将其作为服务付款的一部分支付。

\[*起草注：对上述第 5.5 节，如发生争议，双方可选择加入争议解决语言以处理该等争议。此外，双方应明确付款到期时间。*\]

5.6 甲方可要求乙方将乙方收到的任何增益分享付款的至少 \[●\]% 投资于绿色或可持续性倡议。甲方保留要求乙方提供其遵守该要求的书面证据的权利。

\[*起草注：增益分享条款也可构建为激励达成原始目标，而非仅适用于一方超额达成目标的情形——对某些当事方而言这可能更现实。*\]*
