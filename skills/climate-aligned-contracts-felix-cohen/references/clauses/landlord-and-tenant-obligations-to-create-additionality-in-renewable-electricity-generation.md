# 房东与租户创造可再生能源发电增量的义务

## 子条款名称

Oisín’s Clause

## 摘要

一系列面向商业租赁的阶梯式选项，帮助企业房东和租户为其租赁物业所在地的电网创造额外的“绿色”电子。

## 本条款的作用

本条款为企业房东和租户提供逐步降级的选项，使其拥有采纳本条款的多条路径和多个机会。一方以证据向另一方证明更高雄心的选项不切实际和/或成本过高时，另一方须合理行事，允许降级。

## 条款内容

*\[起草注：首字母大写的术语或指本条款中的定义术语，或指本条款拟插入的主协议中的定义术语。\]*

**房东的义务**

1. 房东应：

1.1 通过第2.1至2.4条中的一个或多个采购选项，确保\[租期\]期间向物业供应的\[100%\]/\[至少\[●\]%\]电力为100%可再生能源；且

1.2 仅与绿色供应商就物业订立电力供应协议。

2. 房东应通过以下采购选项采购第1.1条所述向物业供应的电力：

2.1 房东应在物业上安装能够发电和/或储存100%可再生能源的设备。

2.2 如房东向租户（合理行事）解释并提供令其满意的证据，证明依第2.1条为物业采购100%可再生能源不切实际和/或成本过高\*，房东应：

2.2.1 促成在物业外安装能够发电和/或储存100%可再生能源的设备。这包括房东取得可再生能源项目的全部或部分权益。如房东取得的部分权益，该安装按相关所有权权益比例分摊的产出（以 MWh 计）不得低于年消耗量；且

2.2.2 与可再生能源项目开发商订立 PPA，从第2.2.1条所述可再生能源项目购买不低于年消耗量（及相关环境属性）的100%可再生能源（以 MWh 计）。

\* \[*起草注：如房东与租户对“不切实际和/或成本过高”的定义或范围无法达成一致，应诉诸主租赁协议中载明的争议解决机制或条款。如未约定争议解决条款或机制、或其对解决 Oisín 条款产生的争议不充分，考虑在主租赁协议中增加适当的争议解决条款以处理此问题。本起草注适用于 Oisín 条款中所有“不切实际和/或成本过高”的使用。*\]

2.3 如房东向租户（合理行事）解释并提供令其满意的证据，证明第2.1和2.2条不切实际和/或成本过高：

2.3.1 房东应与可再生能源项目开发商订立 PPA，购买不低于年消耗量的100%可再生能源（连同相应数量的适用环境属性）；

2.3.2 房东可按其认为合适的方式构建该 PPA，包括在适当时以虚拟 PPA 或套接（即经绿色零售商）方式；且

2.3.3 该 PPA 应产生若非该 PPA 即不会产生的额外可再生能源容量。

2.4 如房东向租户（合理行事）解释并提供令其满意的证据，证明第2.1至2.3条不切实际和/或成本过高，房东应向绿色零售商支付绿色能源电价。

**租户的义务**

3. 租户应：

3.1 通过第4.1至4.4条中的一个或多个采购选项，确保\[租期\]期间向场所供应的\[\[100%\]/\[至少\[●\]%\]\]电力为100%可再生能源；且

3.2 仅与绿色供应商就场所订立电力供应协议。

4. 租户应通过以下采购选项采购第3.1条所述向场所供应的电力：

4.1 租户应在场所上安装能够发电和/或储存100%可再生能源的设备。

4.2 如租户向房东（合理行事）解释并提供令其满意的证据，证明依第4.1条为场所采购100%可再生能源不切实际和/或成本过高，租户应：

4.2.1 促成在场所外安装能够发电和/或储存100%可再生能源的设备。这包括租户取得可再生能源项目的全部或部分权益。如租户取得的部分权益，该安装按相关所有权权益比例分摊的产出（以 MWh 计）不得低于年消耗量；且

4.2.2 与可再生能源项目开发商订立 PPA，从第4.2.1条所述可再生能源项目购买不低于年消耗量（及相关环境属性）的100%可再生能源（以 MWh 计）。

4.3 如租户向房东（合理行事）解释并提供令其满意的证据，证明第4.1和4.2条不切实际和/或成本过高：

4.3.1 租户应与可再生能源项目开发商订立 PPA，购买不低于年消耗量的100%可再生能源（连同相应数量的适用环境属性）；

4.3.2 租户可按其认为合适的方式构建该 PPA，包括在适当时以虚拟 PPA 或套接（即经绿色零售商）方式；且

4.3.3 该 PPA 应产生若非该 PPA 即不会产生的额外可再生能源容量。

4.4 如租户向房东（合理行事）解释并提供令其满意的证据，证明第4.1至4.3条不切实际和/或成本过高，租户应向绿色零售商支付绿色能源电价。
