# 重大合同或交易董事会文件模板

## 条款名称

Griff 条款

## 摘要

董事会文件模板，附详细提示，用于考虑重大合同和交易的气候影响以及企业面临的相应气候风险。

## 本条款的作用

在正常的治理结构内实现与业务一致的气候对话，支持公司履行其脱碳或净零承诺并建立气候韧性。

## 条款内容

**议题：\[重大合同或交易\]的重要气候方面**

\[*起草说明：插入董事会文件其余部分所使用的描述。*\]

**\[复述《气候转型行动计划》（CTAP）\* 或企业社会责任、负责任经营或 ESG 计划的减排目标介绍\]**

*\**\[*起草说明：示例参见* [*联合利华《气候转型行动计划》*](https://www.unilever.com/Images/unilever-climate-transition-action-plan-19032021_tcm244-560179_en.pdf)*。*\]

**1. 战略影响**

**一致性**

1.1 订立\[重大合同或交易\]的提议与我们商定的\[脱碳或净零\]目标\*\*、中期减排目标、与巴黎协定一致的气候变化业务战略和运营计划\[完全或部分或未\]一致，特别是作为实现较长期\[脱碳或净零\]目标之前提的近期和中期里程碑的交付，理由如下。\[*解释并插入理由。如果合同在一方面一致但在另一方面不一致，请解释。*\]

*\*\** \[*起草说明：净零目标指设定一个日期（理想情况下在 2050 年之前），以 (i) 减少温室气体排放（排放）并 (ii) 清除排放，在日历年度及此后每一年实现公司排放源与排放汇（所有气体类型和所有范围）之间的平衡，以实现《巴黎协定》的目标。清除通过从已根据志愿标准核证或根据联合国气候变化框架公约清洁发展机制核证的项目购买碳信用额（抵消）来实现。抵消应仅在公司已尽一切合理努力减少包括价值链和供应链在内的所有运营的排放之后，用于处理剩余排放。*\]

1.2 该\[重大合同或交易\]将通过使我们能够实现与我们近期和中期减排目标相一致的中间工业或并购（M&amp;A）目标，帮助我们实现净零战略，理由如下。\[*解释并插入理由。*\]

1.3 该\[重大合同或交易\]可能阻碍我们实现\[脱碳或净零\]战略以及中间工业、并购和减排目标。

1.3.1 这是必要的，因为 \[*插入理由*\]。

1.3.2 这可以通过以下方式缓解 \[*插入缓解方案*\]。

1.3.3 \[这些缓解方案不涉及使用抵消，或包括对采用最佳可用技术后仍无法缓解的剩余排放的有限使用的最优质抵消，因此与国际净零战略最佳实践保持一致。\]\[这些缓解方案涉及使用抵消来缓解全部或大部分排放，而未使用最佳可用技术，因此与国际净零战略最佳实践不一致。它们受制于以下风险 \[*插入抵消带来的声誉风险，以及如果成本假设和抵消持续可用性与实际结果存在重大差异时的商业风险。*\]\]

1.4 \[我们的范围 3 排放目标\[已或未\]作为\[重大合同或交易\]的一部分级联给交易对手方，因此\[会或不会\]使我们更接近实现近期\[和/或\]中期范围 3 排放目标。

1.5 一旦签署，我们\[将能够或无法\]终止\[重大合同或交易\]以转向替代的低碳交易对手方。

1.6 已对交易对手方进行了以下尽职调查，以确保其与我们的\[脱碳或净零\]目标和公司气候战略保持一致：

1.6.1 \[我们的\[脱碳或净零\]和中期目标保持一致\]；

1.6.2 交易对手方的 SECR 碳强度比率在过去\[*数字*\]年中已有所下降；

1.6.3 交易对手方的脱碳战略主要侧重于温室气体减排，对剩余排放有限使用高质量抵消，而非将大规模抵消作为减缓的替代；以及

1.6.4 \[气候或可持续性\]团队已审查其\[转型或脱碳\]计划，并得出结论认为其\[可信或不可信或需要完善\]。

**排放**

1.7 \[我们对\[重大合同或交易\]产生的排放的最佳估计为：

\[ \] 范围 1：\[*数字*\]；

\[ \] 范围 2：\[*数字*\]；以及

\[ \] 范围 3：*\[数字\]。*\] 或

\[由于 \[*插入理由*\]，无法估计\[重大合同或交易\]产生的排放。\]

\[*起草说明：范围 1、2 和 3 排放按*[*《温室气体核算体系：企业核算与报告标准》*](https://ghgprotocol.org/sites/default/files/standards/ghg-protocol-revised.pdf)*（经不时更新）分类。关于范围 1、2 和 3 排放的更多信息，参见 TCLP 术语表：[范围 1、2 和 3 排放](https://chancerylaneproject.org/glossary/scope-1-2-and-3-emissions/)*。\]

1.8 这意味着我们的碳足迹将\[增加或减少\]\[*数字*\]吨二氧化碳当量 \[*参见 TCLP 术语表：[二氧化碳当量](https://chancerylaneproject.org/glossary/carbon-dioxide-equivalent-co2e-or-co2eq/)*\]*。*

\[*起草说明：碳足迹指 \[参见 TCLP 术语表：[*碳足迹*](https://chancerylaneproject.org/glossary/carbon-footprint/)*\]。\]*

1.9 该\[重大合同或交易\]预计将使我们的净零目标或中期目标的实现\[延迟或提前\]\[*数字*\]年。这将向股东\[和或\]市场公布。

**测量与进展**

1.9.1 该\[重大合同或交易\]包含信息获取的合同权利，以支持我们\[脱碳或净零\]目标、中期减排目标、与巴黎协定一致的气候变化业务战略和运营计划的测量和进展。\[*解释*\]。

\[*起草说明：巴黎一致性指 \[参见 TCLP 术语表：[巴黎一致性](https://chancerylaneproject.org/glossary/paris-alignment-or-paris-aligned/)*\]。\]*

**商业机遇**

1.9.2 该\[重大合同或交易\]产生的气候考量和净零减排为公司带来以下商业机遇。\[*解释。例如，如果管理层认为一项交易将提前实现脱碳目标、净零目标或中期目标，是否存在共享价值的机会？*\]。

**2. 财务影响**

2.1 该\[重大合同或交易\]涉及或将导致与我们商定的\[脱碳或净零\]目标、中期减排目标、与巴黎协定一致的气候变化业务战略和运营计划\[完全或部分或未\]一致的资本或运营支出。\[*解释。*\]

2.2 该\[重大合同或交易\]背后的气候风险和问题已被识别，\[可能或不太可能\]需要根据 [IFRS《关于气候相关事项影响的教育材料》](https://www.ifrs.org/news-and-events/news/2020/11/educational-material-on-the-effects-of-climate-related-matters/)在国际财务报告准则基金会（IFRS）一致的披露或财务报表中具体提及。

2.3 \[本次交易没有"绿色溢价"\]。\[该\[重大合同或交易\]具有\[*数字*\]百分比的"绿色溢价"。该绿色溢价将通过\[*解释*\]\[回收或缓解\]。

\[*起草说明："绿色溢价"指因减少某些负面环境影响（包括排放）而在交易中产生的额外成本，或附着于交易的价值。*\]

**3. 风险分析**

**我们业务面临的气候风险**

3.1 该\[重大合同或交易\]可能导致我们业务面临以下气候相关财务风险：

\[*根据公司的企业风险管理框架，插入与气候变化和向脱碳经济转型相关的实体、经济转型或诉讼风险的风险分析。*\]

**合同风险分配**

3.2 气候变化持续显著改变重大合同风险的性质和分配。该\[重大合同或交易\]涉及以下气候相关合同风险。

\[*插入气候相关合同风险的风险分析。特别是，识别：*

- *实体风险——例如存在长期参与、与实体资产或运营相关的合同、需要较长供应链距离的商品、位于海洋或河流附近或水资源稀缺地区的资产、关键投入供应合同；*
- *转型风险——例如高碳商品的销售合同、长期项目、不可转让投入、包括可能引入碳边境调节机制的跨境交易、项目融资和保险的持续成本和可用性、交易对手方信用评级；以及*
- *气候交易对手方声誉风险——例如交易对手方以阻碍而非加速转型的方式行事，这可能给公司带来不良影响，或其更广泛的业务与交易对手方的行为不符*。\]

**风险缓解策略**

3.3 这些风险已通过尽职调查过程识别，通过合同起草和谈判处理，并将由 \[*插入风险管理和缓解策略*\] 在合同存续期间进行管理。

\[*起草说明：参见* [*Gordon 的 DDQ*](https://chancerylaneproject.org/clauses/esg-due-diligence-questionnaire-for-ma-and-capital-markets/)*。*\]

**4. 三重底线影响**

4.1 除上述核心战略和财务影响外，该\[重大合同或交易\]可能导致与可持续利益相关方和企业价值以及我们的文化和宗旨相关的更广泛环境和社会影响。这些不同于标准的 [ESG](https://chancerylaneproject.org/glossary/esg/) 考量，包括：

4.1.1 公正转型——\[*描述对公司为员工、供应链和社区实现公正转型所作贡献的任何正面或负面影响*\]；

*\[起草说明：公正转型指 \[参见 TCLP 术语表：[公正转型](https://chancerylaneproject.org/glossary/just-transition/)。\]\]*

4.1.2 文化——\[*描述对公司的\[脱碳或净零\]文化、员工参与度和满意度、人才招聘和保留、技能提升或再培训的任何正面或负面影响*\]；以及

4.1.3 生物多样性和自然——\[*描述对生物多样性丧失和生态系统服务的任何正面或负面影响*\]。

*\[起草说明：生物多样性指 \[参见 TCLP 术语表：[生物多样性](https://chancerylaneproject.org/glossary/biodiversity-and-biological-diversity-or-biodiversity-loss/)\]。\]*

**5. 公司治理与监管合规**

5.1 就《2006 年公司法》第 172 条而言，兹指出，该\[重大合同或交易\]可能对以下利益相关方群体产生影响：\[*插入与本董事会文件语境相关的利益相关方群体的详情（例如，投资者、员工、客户、供应商、社区、环境）、他们为何重要以及他们就重大合同或交易可能持有的问题或关切。如相关，交叉引用上文 4.1.1 关于公正转型的讨论。*\]

5.2 为处理此类利益相关方关切\[和或\]为此类利益相关方创造价值，已采取或将采取以下行动 \[*添加所采用的任何相关权衡或让步，或可能为处理利益相关方关切而定制的重大合同或交易部分的详情。*\]

5.3 此类行动将创造价值创造机会，并\[\[完全或部分\]一致\]\[没有影响\]\[将帮助我们实现\]我们的\[脱碳或净零\]战略或中期减排目标或与巴黎协定一致的业务战略或气候变化运营计划或长期可持续成功\]。\[*添加详情，包括对利益相关方影响的分析和为处理这些影响所采取的措施如何使重大交易或合同与业务战略保持一致。*\]

5.4 该\[重大合同或交易\]\[不\]引起监管合规问题。\[*详述。*\]

\[*指明负责气候相关战略和运营问题的经理或委员会，如果与负责\[重大合同或交易\]其他商业方面的经理或委员会不同。*\]。
