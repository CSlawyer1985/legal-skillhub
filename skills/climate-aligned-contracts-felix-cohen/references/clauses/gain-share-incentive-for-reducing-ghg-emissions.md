# 减少温室气体排放的增益分享激励

## 条款名称

Jess and Rory's Clause（杰斯与罗里条款）

## 摘要

本条款激励相对方减少温室气体排放，以换取按其所提供商品或服务价值计算的增益分享付款。

## 本条款的作用

本条款在合同中引入增益分享付款。在合同期内以减少温室气体排放换取增益分享付款，是促使一方脱碳的有力激励——尤其是在利润微薄的行业（如建筑业）或正经历激进成本节约的商业环境中。

## 条款内容

\[*起草注：大写术语与本条款中的定义术语或本条款拟插入的主协议中的定义术语相关。*\]

**1. 测量、管理和报告温室气体排放**

1.1 自\[*插入日期*或本协议日期\]起并在整个期限内，乙方应按\[本条款 \[ \] 或第 \[ \] 至 \[ \] 条\]的规定测量、管理和报告其[温室气体排放](https://chancerylaneproject.org/glossary/greenhouse-gas-emissions/)。

1.2 \[自本协议日期起或在本协议日期后 \[*数字*\] 天内\]乙方应正式采纳并实施碳足迹标准。

1.3 乙方董事会应指定 1（一）名董事负责确保乙方在期限内遵守碳足迹标准和本条款 \[1\] 的要求。

1.4 在本协议日期每个周年日后的 3（三）个月内，乙方应向甲方提交温室气体报告。

**2. 温室气体报告的内容**

2.1 本条款 \[2\] 载明温室气体报告内容的最低要求。

2.2 温室气体报告应就温室气体报告期报告并在\[适当处\]说明：

2.2.1 乙方已适用的管理和减少[温室气体排放](https://chancerylaneproject.org/glossary/greenhouse-gas-emissions/)的行业最佳实践，以及乙方如何适用；

2.2.2 乙方测量的[范围 1、2 和 3 排放](https://chancerylaneproject.org/glossary/scope-1-2-and-3-emissions/)；

2.2.3 测量的服务碳足迹；

2.2.4 测量的供应链碳足迹；\[以及\]

2.2.5 与每个先前温室气体报告期温室气体报告中所载范围 1、2 和 3 排放相比，乙方实现的[温室气体排放](https://chancerylaneproject.org/glossary/greenhouse-gas-emissions/)减少量 \[；以及

2.2.6 \[*插入附加要求*\]\]。

**3. 核验**

3.1 为确保温室气体报告的准确性和可靠性，乙方应按合理要求在以下方面与甲方合作和协作：

3.1.1 乙方如何测量、管理和报告其[温室气体排放](https://chancerylaneproject.org/glossary/greenhouse-gas-emissions/)；

3.1.2 乙方编制每份温室气体报告；以及

3.1.3 乙方在本条款下的其他义务。

3.2 如甲方合理要求，并在温室气体报告日期后 \[*数字*\] 天内\]通知乙方（且对任一温室气体报告期至多一次），乙方应指定独立外部审计师或核验机构（由双方商定）认证其温室气体报告。

3.3 乙方应承担依第 \[3.2\] 条委托的温室气体报告外部审计和核验的所有相关费用。

**4. 温室气体排放的减少**

4.1 乙方应在每份温室气体报告所涉的每个温室气体报告期内，将其[温室气体排放](https://chancerylaneproject.org/glossary/greenhouse-gas-emissions/)减少不少于第 4.2 条所示百分比。

4.2 在期限内，乙方应在每个温室气体报告期（与前一温室气体报告期相比）将服务碳足迹减少 \[●\]%。

**5. 增益分享机制**

5.1 如乙方在某温室气体报告期内将服务碳足迹减少超过第 \[4.2\] 条所述百分比，则以下增益分享机制应适用（**增益分享机制**）：

**总减少量** = \[年度\] 与\[下一年度\]之间[碳足迹](https://chancerylaneproject.org/glossary/carbon-footprint/)的绝对减少量 \[以温室气体报告所述为准\]

**额外减少量** = 总减少量减去约定减少量（见第 4.2 条）

**增益分享付款** = 额外减少量 x \[*插入商定费率\**\] 以抵消 1（一）吨[二氧化碳当量](https://chancerylaneproject.org/glossary/carbon-dioxide-equivalent-co2e-or-co2eq/) x 50（五十）%。

\[\**起草注：费率应与依《牛津净零对齐碳抵消原则》（经修订）的高质量、已核验项目费率一致*\]

**6. 增益分享付款**

6.1 增益分享付款应按第 \[5\] 条所述增益分享机制计算（**增益分享付款**）。

6.2 在不违反第 \[6.3 和 6.4\] 条的前提下，甲方应按第 \[6.5\] 条向乙方支付增益分享付款。

6.3 在一个温室气体报告期内甲方应付给乙方的增益分享付款总额不得超过同期乙方在温室气体报告期所涉合同年度内向甲方提供服务的年度价值的 \[●\]%。

6.4 如甲方依第 \[3.2\] 条要求外部审计师或核验机构认证相关温室气体报告，增益分享付款仅在第 \[3.2\] 条项下任何核验流程完成后才应付。

6.5 乙方应在增益分享付款依本条款 \[6\] 到期应付后向甲方开具发票，甲方应按\[协议条款或 *插入相关付款条款引用*\]将其作为服务付款的一部分支付。

6.6 乙方应将收到的任何增益分享付款的至少 \[●\]% 投资于绿色或可持续性倡议（该等倡议由双方商定）。甲方保留要求乙方提供其遵守该要求的证据的权利，乙方应在合理请求下及时提供该等书面证据。

6.7 因增益分享付款产生或与之相关的任何争议（包括但不限于与其计算、支付和适用相关的争议）应按\[协议或 *插入替代性争议解决条款引用*\]解决。
