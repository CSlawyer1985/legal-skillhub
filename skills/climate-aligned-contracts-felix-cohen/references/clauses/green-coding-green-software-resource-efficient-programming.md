# 绿色编码 / 绿色软件 / 资源高效编程

## 条款名称

Enzo's Clause

## 摘要

这是一项绿色编码条款，要求公司以节能和可持续的方式开发软件（或委托开发软件）。

## 本条款的作用

鼓励 IT 和软件开发合同的当事人采取积极行动，减少软件开发（尤其是定制软件）和软件使用的碳足迹。

## 条款内容

1\. \[开发团队/开发者\]负责在软件开发中应用绿色编码标准，并减少所开发软件的碳足迹。

2\. \[开发团队/开发者\]承诺其自身及其使用的所有分包商实施以下绿色编码标准：

2.1 集成软件在不使用时\[部分\]自动关闭或切换至省电模式的功能，并合理捆绑自动执行的操作；

2.2 开发优化且直观的 UI/UX 设计，实现快速、节约资源的软件可用性；

2.3 在考虑能源效率的前提下开发软件，例如避免冗余、优化数据库查询或改善内存使用；

2.4 使用最大限度减少 CPU、RAM 和网络带宽等系统资源消耗的资源高效算法、文件格式和库；

2.5 执行自动化测试和版本控制，并使用敏捷软件开发以最小化代码浪费，避免可能导致高能耗调试的错误；

2.6 使用通过移除未使用代码（“死代码”）来优化所开发软件的应用（“摇树引擎”），尤其是在使用开源软件时；

2.7 \[定期举行内部团队会议，并创建一个向开发团队所有成员开放的数据室，存放所有已开发软件，以便在需要时回收利用其他团队成员创建的代码，并将经验教训提供给整个团队；\]

2.8 通过对代码进行有意义的注释、编制文档和系统存储所创建文件，确保软件的可维护性和可复用性；以及

2.9 按照预期工作量设计系统，并使用模块化方案和精确工作量控制的可能性，例如通过云计算。

3\. 承包商承诺在考虑所开发软件知识产权约定的前提下，确保软件的最佳可维护性和可复用性，并应允许客户在支持期结束后更新和修改所开发软件，包括由第三方进行。

4\. 承包商承诺，在软件交付后 \[X 年\] 期间内，一旦软件的关键安全漏洞公开披露，立即予以修复，从而确保软件在长期内也能无 IT 安全风险地使用。双方应在合同中为承包商就此约定适当的报酬。

5\. \[承包商承诺，在交付软件或更新之前，按照资源节约和能源高效软件产品蓝天使（Blue Angel）奖项标准（DE-UZ 215）附件 A 和附件 B 规定的规格，在参考系统上安装软件产品，测试软件产品在空闲模式和标准使用场景下引起的硬件负载，并尽可能保持其低水平，报告其绿色编码活动及由此实现的具体改进，并应客户要求提供信息。\]
