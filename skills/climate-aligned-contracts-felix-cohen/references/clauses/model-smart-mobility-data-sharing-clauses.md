# 智能出行数据共享示范条款

## 子条款名称

Olga's Clause

## 摘要

欧盟各地城市可在其标准数据共享协议中采用这些开源数据共享协议条款，以推动可持续出行部门的发展。

## 本条款的作用

保障长期数据流，并确保出行服务提供商向需要将此类数据纳入精心起草的数据共享协议的市政当局输送出行数据。城市和组织可在公共采购协议和数据处理协议中采纳该起草文本。

## 条款内容

\[*起草注：本条款以欧盟视角起草，用于美国、英国或世界其他地区时需要调整。起草假定这些条款将被插入标准数据共享协议，该协议将包含关于数据保护影响评估、处理合法依据、具体技术和组织措施以及所有与数据处理协议相关的标准定义、条款和样板条款的全部正常数据共享规定。*\]

**1. 目的**

1.1 本协议规定了数据披露方向数据接收方披露个人数据时共享个人数据的框架。\* 它界定了各方应遵守的原则和程序以及各方相互负有的责任。数据披露方同意按本协议所载条款与数据接收方共享共享个人数据。

1.2 各方认为此项数据共享举措是必要的，因为\[插入理由，例如：智能出行数据共享对数据接收方创建可持续市政当局、特别是打造更绿色\[地点\]城市的政策目标至关重要\]。它将通过\[插入益处，例如：通过减少交通拥堵来减少碳排放\]造福社会。\*\*

1.3 数据接收方将利用从共享个人数据中得出的洞见作出循证决策和制定政策。数据接收方同意仅为本协议第2.1、2.2和2.3条所述目的（合称**气候目的**）处理共享个人数据：

1.3.1 \[目的，例如：监测数据接收方\[出行方案接入\]的环境绩效\]；

1.3.2 \[目的，例如：增加\[●\]交通使用者、特别是服务不足社区的出行机会\]；

1.3.3 \[目的：电气化\]；

1.3.4 \[目的：减少汽车使用和拥堵\]；

1.3.5 \[目的：空气质量\]；

1.3.6 \[目的，例如：以匿名化和汇总形式用于公共统计和/或学术研究\]；\[及\]

1.3.7 \[目的：\[插入有助于数据接收方可持续发展目标或可持续发展对齐（包括助力《巴黎协定》目标和识别具体减排要求）、但范围有限且界定清晰、足以符合数据保护法规目的限制方面的任何相关而具体的用途\]\]。

数据接收方不得以与气候目的不相容的方式处理共享个人数据。

1.4 各方应指定一名具备气候、出行和数据专长的单一联络点（**SPoC**），共同就数据共享产生的任何问题达成协议，并积极提高数据共享举措的成效。各方 SPoC 为：

1.4.1 数据披露方：\[插入数据披露方 SPoC 的姓名、职务、团队和联系方式\]；

1.4.2 数据接收方：\[插入数据接收方 SPoC 的姓名、职务、团队和联系方式\]。

\* \[*起草注：本起草假定数据为单向传输。如拟双向流动，条款须相应修改。*\]

\*\* \[*起草注：在此插入协议特定信息，处理以下问题：*

- *产生的分析结果能否共享和发布；以及*
- *数据与其他数据集合并分析及商业化之处，是否应就分析产生的任何成本节省支付费用，以与配合数据共享协议运行的商业协议条款保持一致。*\]

**2. 共享个人数据**

2.1 在本协议期限内，各方之间仅共享以下类型的个人数据：

2.1.1 \[位置数据\]\[注明 GPS 精度水平\]；

2.1.2 \[车辆登记和/或车辆排放数据\]；

2.1.3 出行路线和时间戳数据；

2.1.4 车内乘客人数；

2.1.5 \[姓名\]\[*起草注：如所有数据将匿名化或假名化则删除*\]；

2.1.6 出行起点和终点位置\[；及\]

2.1.7 \[添加为实现目的所需共享的任何其他数据类别\]，连同附表\[1\]中详述的进一步细节，即**共享个人数据**。

2.2 各方分别同意不向本协议任何其他方共享以下类型的数据：

2.2.1 刑事犯罪数据；

2.2.2 特殊类别个人数据，包括但不限于生物识别和面部识别信息；各方应在共享前检查个人数据，确保其不直接或间接包含或有风险包含这些类别的数据，并应在共享前从个人数据中删除或移除任何此类数据。

2.3 共享个人数据应按附表\[1\]所列的访问和处理限制处理。

2.4 \[各方/数据披露方\]应确保共享个人数据就气候目的而言不属无关或过度。

\[*起草注：如协议尚未涵盖，插入细节以明确各方中哪一方就共享个人数据担任数据控制者，须符合协议的具体情况*\]。

**3. 合法、公平和透明处理**

\[*起草注：在标准数据共享规定之外添加。*\]

3.1 数据披露方应就共享个人数据确保：仅在需要数据主体同意的情况下，依据数据保护立法，向数据主体提供清晰充分的信息，说明其将处理其个人数据的目的、这些目的的法律依据以及 GDPR 第13条及其他法律和标准要求的信息（包括但不限于），方与数据主体同意共享个人数据：

3.1.1 向第三方传输的目的是气候目的 \[*起草注：考虑插入将级联传达给数据主体、以强调对社会和气候益处的商定措辞*\]；

3.1.2 如共享个人数据将传输给第三方，则说明该事实及该传输的充分信息，使数据主体能够理解该传输的目的和风险。

3.2 如出于任何原因，一方合理认为本协议项下的数据共享不合法、不公平或不透明，该方的 SPoC 应立即联系其他方的 SPoC，告知其该关切并考虑需要采取的行动，包括暂停任何未来的数据共享。\*

\* \[*起草注：考虑添加进一步条款以全面落实此流程。*\]

**4. 数据互操作性**

4.1 为高效合作实现气候目的和可持续发展目标，各方同意使用兼容数据集，并按附表\[2\]所列方法记录所有共享个人数据。

4.2 数据披露方应确保在开始日期前共享个人数据准确无误，并已建立适当的内部程序，使数据接收方能在开始日期前抽检共享个人数据；如需要，数据披露方将在传输共享个人数据前予以更新。

**5.** **数据保留与删除**\*

5.1 数据接收方保留或处理共享个人数据的时间不得超过实现气候目的所必需的时间。

5.2 尽管有第5.1条，各方仍应被允许依适用于其的任何法定或监管保留期限继续保留共享个人数据。各方可为共享个人数据的保留和删除制定共同规则。

5.3 数据接收方应确保在以下情形下将任何共享个人数据返还数据披露方或予以销毁：

5.3.1 共享个人数据的处理不再为实现气候目的所必需；或

5.3.2 \[本协议终止时\]。

5.4 依第5.3条删除共享个人数据后，数据接收方应通知数据披露方相关共享个人数据已被删除。

\* \[*起草注：使这些条款与详述数据可作何用途的条款对齐。例如，如数据可与其他数据集合并或匿名化，本条6应相应修改。*\]

**6.** **新增方与协议终止**

\[*起草注：考虑纳入明确条款处理：*

*(a) 终止；*

*(b) 各方在考虑对方履约问题期间暂停数据共享；和/或一方作出使另一方声誉受损的行为时的终止权，例如一方使用个人数据的方式冒犯了对数据合乎道德使用的认知。*\]

6.1 任何希望加入本数据共享举措和协议的新增数据接收方应填写并提交数据共享请求。新增方加入本协议须征得各方以及数据主体的同意。\*

6.2 如一方终止协议或新数据接收方依第6.1条加入协议，应尽快起草经修订更新的本协议版本并分发给所有其他方。

\* \[*起草注：考虑让每位数据接收方各自完成独立协议是否更简单，以避免连带责任方面的潜在问题。*\]
