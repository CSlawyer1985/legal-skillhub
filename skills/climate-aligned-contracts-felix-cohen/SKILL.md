# 气候对齐合同

## 概述

本技能支持起草、调整和审查与 The Chancery Lane Project 通过法律协议减少碳排放的方法论相一致的合同和条款。它提供经过验证的条款模板、风格规范指引，以及将气候目标嵌入合同关系的最佳实践。

## 核心能力

### 1. 起草新的气候对齐条款

创建支持脱碳目标的新合同条款：

- 净零承诺与转型规划
- 碳核算与报告义务
- 供应链脱碳要求
- 循环经济与资源效率条款
- 气候相关不可抗力与适应条款
- 绿色融资与可持续发展挂钩条款

**流程：**
1. 识别条款类型和合同背景
2. 查阅 `references/` 中的相关示例条款以了解既定模式
3. 将方法适配到具体司法辖区和合同类型
4. 应用风格规范和起草原则（见"风格规范"一节）
5. 如果司法辖区特定立法相关，使用 web_search 查找当前要求

### 2. 调整现有合同

修改现有合同语言以纳入气候目标：

- 审查现有条款结构和法律框架
- 识别加强气候对齐的机会
- 提议保持法律可执行性的修改
- 平衡商业目标与气候目标
- 确保与更广泛的合同体系一致

### 3. 审查和分析条款

评估拟议或现有条款的气候对齐度：

- 评估条款推进脱碳的有效性
- 识别气候承诺中的缺口或弱点
- 建议改进或替代方法
- 考虑可执行性和实际实施
- 检查与 The Chancery Lane Project 方法论的一致性

## 风格规范与起草原则

### 语气与语言

- **精确且可执行**：使用清晰、无歧义的语言创设具有约束力的义务
- **平衡**：在保持气候雄心的同时承认商业现实
- **务实**：确保义务可衡量、可核实且可实现
- **易懂**：在可能的情况下，在保持精确的同时避免不必要的法律术语

### 结构要求

- **明确义务**：区分强制性要求（"应"）、愿望性目标（"宜"）和裁量性行为（"可"）
- **定义术语**：使用一致的定义，尤其是气候相关术语（如"净零"、"范围 1/2/3 排放"、"科学碳目标"）
- **可衡量结果**：包含具体指标、时间框架和报告机制
- **救济与执行**：考虑不合规的适当后果

### 气候方法论

The Chancery Lane Project 的方法强调：

1. **将气候嵌入核心义务**：而不仅是附加函或附属条款
2. **与科学对齐**：引用可信框架（《巴黎协定》、科学碳目标倡议等）
3. **问责机制**：定期报告、核实，以及未履行的后果
4. **转型规划**：认识到脱碳是一个需要分阶段承诺的历程
5. **合作重于惩罚**：鼓励联合解决问题和持续改进

## 司法辖区考量

气候对齐合同必须考虑当地法律要求：

- **何时司法辖区重要**：如果用户提及特定司法辖区、国家或法律体系，或条款类型是司法辖区特定的（如监管合规、披露要求）
- **如何处理**：使用 web_search 查找该司法辖区的现行气候立法、披露要求和相关法律框架
- **搜索什么**：气候披露法、净零立法、碳定价机制、强制报告框架、行业特定法规

## 示例条款库

`references/clauses/` 目录包含按类别组织的示例条款。起草或审查条款时：

1. 查阅相关示例以了解既定模式
2. 将方法适配到具体背景
3. 不要逐字复制——根据特定合同和当事人定制语言
4. 考虑条款如何与其他合同条款相互作用

## 资源

### references/clauses/

包含 The Chancery Lane Project 的示例气候对齐条款库（markdown 格式），按条款类型和合同类别组织。处理相关条款类型时加载这些文件，以了解经过验证的方法和风格规范。

**注意：** 更多条款文件将添加到该目录。引用条款时，先使用 `view` 工具检查 `references/clauses/` 中有哪些可用文件。
