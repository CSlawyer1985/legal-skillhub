# 全能法律助手 (legal-assistant-pro)

## 概述

全能法律助手是一个面向执业律师及企业法务的综合性法律 AI 技能，融合**法律咨询、证据分析、文书生成、合同审阅、案由速查、合规尽调、法律检索、案件管理、知识产权专项、产品法务、劳动法专项**十一大能力，覆盖民事、商事、劳动、知识产权、行政、刑事、执行及国家赔偿全领域。

## 核心特色

### 双分支运行架构

- **诉讼分支**：案由判定 → 证据固定 → 要件分析 → 证人询问 → 文书起草
- **非诉分支**：合同审核/起草/律师见证/法律意见书/尽调/律师函/调查令分流

### 十一大能力模块

| 模块 | 说明 |
|------|------|
| 📋 法律咨询 | 分级定性（L1-L3）、六步定性工作流、SPIKES沟通法 |
| 📝 文书生成 | 起诉状/答辩状/反诉状/上诉状/再审申请书/代理词/仲裁申请书/和解协议/执行异议等 |

### 文书生成能力

- **传统格式**：完整叙事性法律文书，三段式/五段式写作法
- **要素式文书**：113个最高人民法院要素式模板索引，含买卖合同、民间借贷、劳动争议等
- **双文书生成**：同时生成传统格式 + 要素式格式，覆盖法院双重要求

### 案件评估体系

- **五维风险评估**：证据强度(30%) + 法律依据(25%) + 对方实力(20%) + 执行可能(15%) + 时间成本(10%)
- **诉讼费用速算**：财产案件（10档速算公式）+ 非财产案件 + 保全/执行/鉴定/公证费
- **不利事实分析**：8类不利事实识别 + 三级严重度评估 + 三种应对策略

## 安装要求

### 必需技能
- `minimax-docx` — 用于生成 .docx 格式法律文书
- `markitdown-skill` — 用于文档格式转换

### 可选技能
- `qcc-company` — 企业工商信息查询（企查查）
- `pkulaw` — 法律数据库检索（北大法宝）
- `digital-evidence-analyzer` — 电子数据分析
