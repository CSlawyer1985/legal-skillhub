# 进度映射与汇报指引

## 百分比 → 步骤映射

| assemble.js 输出 step | 百分比 | 显示消息 |
|----------------------|--------|---------|
| （启动前） | 0% | 启动专利任务（文件格式处理） |
| `STEP_1` | 5% | 校验交底材料中 |
| `STEP_1_PASS` | 8% | 校验合格，开始生成 |
| `STEP_1_FAIL` | 8% | **终止流程**，仅转述错误信息 |
| `STEP_2` | 15% | 生成初稿中 |
| `STEP_2_DONE` | 50% | 初稿已完成 |
| `STEP_3` | 55% | 质检进行中 |
| `STEP_3_DONE` | 70% | 质检完成 |
| `STEP_4` | 75% | 修复终稿中 |
| `COMPLETE` | 100% | 专利申请文件生成完成 |

## 剩余时间估算

基于总耗时约 8-15 分钟动态调整：

| 进度 | 剩余时间 |
|------|---------|
| 0% | 约 13-15 分钟 |
| 5% | 约 12-14 分钟 |
| 8%（合格） | 约 11-13 分钟 |
| 8%（不合格） | **流程终止**，显示错误 |
| 15% | 约 10-12 分钟 |
| 50% | 约 5-7 分钟 |
| 55% | 约 4-6 分钟 |
| 70% | 约 2-4 分钟 |
| 75% | 约 1-3 分钟 |
| 100% | 已完成 |

## 汇报话术模板

每条消息独立发送，不堆叠，避免重复汇报同一进度。

```
🚀 0% 启动专利任务（剩余约13分30秒）
📋 5% 校验交底材料中（剩余约12分30秒）
✅ 8% 校验合格，开始生成（剩余约11分30秒）
📝 50% 初稿已生成，开始质检（剩余约6分15秒）
🔍 55% 质检进行中（剩余约5分钟）
✅ 70% 质检完成，开始修复终稿（剩余约3分钟）
🔧 75% 修复终稿中（剩余约2分钟）
✅ 100% 专利申请文件生成完成
共 X,XXX 字，包含 X 张附图
```

## 进展中的特殊规则

- **上传 PDF 前**：发送「🚀 0% 启动专利任务（剩余约13分30秒）」覆盖 DOCX→PDF 转换等静默阶段
- **第 8% 校验不合格**：**只转述接口返回的错误信息**，不要猜测可能原因或给建议
