# SSP 撰写指南

系统安全计划（SSP）是 FedRAMP 授权包的核心。它讲述云服务产品（CSO）的完整安全故事：架构、数据流、控制实施、角色和边界。许多 SSP 超过 500 页。

> 始终使用官方 FedRAMP SSP 模板。一个模板涵盖所有基线（LI-SaaS、低、中、高）。模板见：https://www.fedramp.gov/rev5/documents-templates/

---

## SSP 逐节指南

### 第 1 节：信息系统名称和标题
- CSO 的正式名称
- 唯一标识符（在 FedRAMP 流程中分配）
- 服务模式（IaaS / PaaS / SaaS）
- 部署模式（公有 / 私有 / 社区 / 混合云）

### 第 2 节：系统分级
- FIPS 199 影响确定：保密性 / 完整性 / 可用性
- 总体影响级别 = 三个值的最高水位
- 以处理的联邦信息类型证明每次分级的合理性

### 第 3 节：系统所有者 / 授权官员
- 列出 CSP 系统所有者、ISSO 和机构 AO 联系人
- 对于机构授权，包括主办机构的 AO

### 第 4 节：安全责任分配
- 指定 ISSO（信息系统安全官）
- 记录 CSP 安全团队联系人

### 第 5 节：系统使命 / 目的
- 系统功能的简要说明
- 它支持的联邦机构/计划
- 它处理的联邦数据类型

### 第 6 节：系统描述
- 系统的叙述性描述
- 技术栈概述
- 关键系统组件

### 第 7 节：一般系统描述 / 系统环境
**这是最受审查的章节之一。**
- 详细架构描述
- 授权边界叙述——明确定义范围内和范围外
- 网络架构图（嵌入）
- 数据流图（嵌入）
- 端口、协议和服务表
- 外部连接表（所有连接边界内外部的服务）

**常见错误：**
- 含糊的边界描述（“云环境”）——要具体
- 缺少管理/运维流量的数据流
- 未记录外部服务（DNS、NTP、更新服务器、管理员使用的 SaaS 工具）

### 第 8 节：系统环境 / 互连
- 每个外部系统的互连安全协议（ISA）
- 利用的 FedRAMP 服务（IaaS/PaaS）及其授权状态
- 来自利用服务的继承控制必须在 CIS/CRM 工作簿中记录

### 第 9 节：法律、法规、标准（附录 B）
- 必需附件：SSP 附录 B（法律与法规）——使用 FedRAMP 模板
- 列出适用的联邦法律（FISMA、《隐私法》等）
- 可包括机构特定要求（HIPAA、CJIS，如适用）

### 第 10 节：最低安全控制
**最大的章节——每项控制一个叙述。**

对于适用基线中的每项控制：

```
[控制 ID] [控制名称]
实施状态：已实施 | 部分实施 | 计划中 | 不适用 | 替代实施

[控制实施陈述]
说明控制是如何实施的。要具体：
- 什么工具、政策或流程实施这项控制？
- 谁负责？
- 证据在哪里？
- 对于共享控制：CSP 的责任与客户的责任是什么？

客户责任（如适用）：
[说明客户/机构必须做什么]
```

**撰写提示：**
- 涵盖控制要求中的每个动词——如果控制要求“监测并记录”，则同时描述监测和记录
- 引用具体的政策文件名称、工具名称、配置设置
- 对于从 FedRAMP IaaS/PaaS 继承的控制：说明“该控制全部/部分继承自 [提供者]。见 CIS/CRM 工作簿。”
- 将未实施的控制标记为“计划中”，并确保它们出现在 POA&M 中

### SSP 附录（A 至 Q）

| 附录 | 内容 | 必需？ |
|---|---|---|
| A | 缩写和术语表 | 是 |
| B | 相关法律与法规（附件 12） | 是 |
| C | 安全政策与程序 | 是（CSP 编写） |
| D | 用户指南 | 是 |
| E | 行为规则 | 是（FedRAMP 模板） |
| F | IT 应急计划 | 是（FedRAMP ISCP 模板，2024 年 12 月更新） |
| G | 配置管理计划 | 是（CSP 编写） |
| H | 事件响应计划 | 是（CSP 编写） |
| I | 控制实施摘要（CIS）/ CRM 工作簿 | 是（FedRAMP 模板） |
| J | FIPS 199 分级 | 是 |
| K | 综合清单工作簿（IIW） | 是（FedRAMP 模板，2024 年 12 月更新） |
| L | 加密模块表 | 是 |
| M | 持续监测计划 | 是 |
| N | 职责分离矩阵 | 视情况 |
| O | POA&M | 是（FedRAMP 模板） |
| P | 供应链风险管理计划 | 是（修订版 5） |
| Q | 隐私影响评估（PIA） | 如范围内有 PII |

## SSP 质量检查清单

提交前核实：
- [ ] 适用基线的所有控制都有实施陈述
- [ ] 没有控制将未来/计划状态描述为当前已实施
- [ ] 所有“计划中”控制出现在 POA&M 中
- [ ] 架构图和控制叙述一致
- [ ] 外部连接表与数据流图匹配
- [ ] 所有共享/继承控制的 CIS/CRM 工作簿完整
- [ ] IIW 列出边界内的每项资产
- [ ] 加密模块表列出所有在用的 FIPS 140-2/3 验证模块
- [ ] 所有必需附录（如适用 C 至 Q）均已附上
- [ ] SSP 附录 A-12 是当前的 FedRAMP 法律与法规模板
