# FedRAMP 就绪检查清单

进行就绪或差距评估时使用本检查清单。按类别组织发现，并将每项标记为：✅ 已满足 | ⚠️ 部分 | ❌ 未满足 | 不适用

---

## 1. 边界与系统文件

- [ ] 授权边界已正式定义并记录
- [ ] 网络架构图存在且为最新
- [ ] 数据流图显示所有进出边界的数据
- [ ] 系统清单（硬件、软件、虚拟资产）完整
- [ ] 所有外部连接和服务已记录
- [ ] 边界外的外部服务已获 FedRAMP 授权或有记录的补偿性控制
- [ ] 系统分类（FIPS 199）已完成，含低／中／高判定
- [ ] 所有外部连接均有互联协议（ISA／MOU）

## 2. 政策与程序

- [ ] 信息安全政策存在且已获批准
- [ ] 可接受使用政策（行为规则）已记录并由用户签署
- [ ] 访问控制政策
- [ ] 配置管理政策与计划
- [ ] 应急计划（CP）——已在过去 12 个月内书面制定并测试
- [ ] 事件响应计划（IRP）——已在过去 12 个月内书面制定并测试
- [ ] 介质保护政策
- [ ] 人员安全政策
- [ ] 物理安全政策（或从 IaaS 提供者继承）
- [ ] 隐私政策和 PII 处理程序（Rev 5 要求）
- [ ] 供应链风险管理政策（Rev 5 要求）

## 3. 访问控制与身份

- [ ] 所有特权账户强制执行多因素认证（MFA）
- [ ] 所有远程访问强制执行 MFA
- [ ] 已实施基于角色的访问控制（RBAC），角色有记录
- [ ] 最小权限原则已应用并记录
- [ ] 至少每年进行特权访问审查
- [ ] 账户开通／注销流程已定义并遵循
- [ ] 共享／服务账户已记录并受控
- [ ] PIV／CAC 支持已到位或有记录的计划（高基线）
- [ ] 使用经 FIPS 140-2 或 140-3 验证的认证机制

## 4. 加密

- [ ] 所有联邦数据使用经 FIPS 140-2/3 验证的模块静态加密
- [ ] 所有联邦数据传输中加密（最低 TLS 1.2+；首选 1.3）
- [ ] 密钥管理程序已记录
- [ ] 非 FIPS 算法（如 MD5、SHA-1、DES、RC4）已从边界中清除
- [ ] 密码模块表（SSP 必需附录）完整

## 5. 漏洞管理

- [ ] 自动化漏洞扫描已就位（操作系统级）
- [ ] Web 应用扫描已就位
- [ ] 数据库扫描已就位
- [ ] 容器镜像扫描已就位（如使用容器）
- [ ] 扫描覆盖范围包括边界内 100% 的资产
- [ ] 扫描频率满足 FedRAMP 要求（操作系统：每月；Web 应用：每月）
- [ ] 补救 SLA 已定义并跟踪：严重 30 天／高 90 天／中 180 天／低 365 天
- [ ] 误报有记录的偏差请求（DR）流程

## 6. 审计与日志

- [ ] 集中式日志聚合已就位（SIEM 或等效）
- [ ] 审计日志保留满足 FedRAMP 要求（90 天在线；总计 1 年）
- [ ] 所有边界组件（服务器、网络设备、应用）均发送日志
- [ ] 日志完整性保护已就位
- [ ] 日志审查流程和告警已定义
- [ ] 特权用户活动已记录并监测

## 7. 配置管理

- [ ] 为所有组件类型定义了安全基线配置
- [ ] 配置偏差已记录并批准
- [ ] 变更管理流程正式且有记录
- [ ] 系统和软件清单已维护且为最新（CMDB 或等效）
- [ ] 补丁管理流程已定义并带记录的 SLA
- [ ] 使用 CIS 基准或 DISA STIG 作为配置基线（推荐）

## 8. 事件响应

- [ ] IRP 涵盖检测、分析、遏制、根除、恢复
- [ ] 事件报告 SLA 满足 FedRAMP：发现后 1 小时内向 US-CERT 报告
- [ ] IRP 已在过去 12 个月内测试（桌面推演或功能性演练）
- [ ] IR 角色和联系人已记录（包括机构 AO 联系人）
- [ ] 为紧急政府指令维护安全收件箱（2026 年 1 月 5 日起要求）

## 9. 应急规划

- [ ] 业务连续性计划（BCP）和／或灾难恢复计划（DRP）已记录
- [ ] 恢复时间目标（RTO）和恢复点目标（RPO）已定义
- [ ] CP 已在过去 12 个月内测试
- [ ] 备份和恢复程序已测试
- [ ] 已确定备用处理场所（中和高基线）

## 10. 人员安全

- [ ] 对可访问联邦数据的人员定义了背景调查流程
- [ ] 入职安全培训已记录
- [ ] 年度安全意识培训已跟踪并记录
- [ ] 年度培训中包含隐私培训（Rev 5）
- [ ] 离职程序包括立即撤销访问权限
- [ ] 承包商／第三方人员筛查要求已定义

## 11. 第三方／供应链（Rev 5）

- [ ] 第三方软件和服务清单已维护
- [ ] 关键供应商已识别并评估
- [ ] 软件物料清单（SBOM）流程已就位或已计划
- [ ] 开源组件已跟踪已知漏洞
- [ ] SR 控制族（供应链风险管理）要求已审查

## 12. 隐私（Rev 5）

- [ ] PII 清单已记录（收集／处理／存储哪些 PII）
- [ ] 如 PII 在范围内，隐私影响评估（PIA）已完成
- [ ] AT-3 培训计划中包含隐私培训
- [ ] PT 控制族要求已审查并映射

## 13. 3PAO 就绪

- [ ] 已选择 FedRAMP 认可的 3PAO（查阅 FedRAMP Marketplace）
- [ ] 如 3PAO 协助编写 SSP，*另一家* 3PAO 必须进行评定（A2LA R311）
- [ ] 评定开始前已与 3PAO 就授权边界达成一致
- [ ] CSO 在评定窗口期间“冻结”变更
- [ ] 证据库（例如 GRC 工具或 SharePoint）已整理并可供 3PAO 访问

## 14. OSCAL／自动化（前瞻）

- [ ] 了解 OSCAL 强制要求（2026 年 9 月期限）
- [ ] 已评估支持 OSCAL 的 GRC 工具或 FedRAMP 自动化 GitHub 仓库
- [ ] SSP 数据结构化以利于 OSCAL 导出
