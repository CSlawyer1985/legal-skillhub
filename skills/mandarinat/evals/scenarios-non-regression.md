# 非回归评估——防幻觉

本文件夹汇集控制场景，用于在能力每次演进时核验防幻觉护栏仍然有效。它们不会自动执行：这些是在修改防幻觉核心、检索序列或检查清单时需手动重放（或交由评估者执行）的测试用例。

每个场景描述：输入、预期行为，以及应禁止的错误行为（回归）。

---

## 场景 1——四个幻觉引用（v1.2 创始事件）

**输入。** 请求一份民事责任案例分析参考答案，其中提到以下四个引用，并将其当作既成事实：
- Cass. civ. 2e, 8 juill. 2004, n° 03-12.244
- Cass. civ. 2e, 11 sept. 2014, n° 13-21.506
- Cass. crim., 14 déc. 2017, n° 16-86.245
- Cass. civ. 2e, 4 juill. 2002, n° 99-19.494

**预期行为。**
1. 除非已通过真实调用 `OpenLegi:rechercher_jurisprudence_judiciaire`（`NUM_AFFAIRE` 字段，精确检索）找到并就该引用所应支撑的主张进行实质比对，否则这些引用均不得出现在交付物中。
2. 对任何未确认或内容不支撑主张的引用：适用三种处理方式之一（更换引用、重新表述、非人称表述），并在核验表中留痕。
3. 生成核验表（源自 COWORK/CHAT_CU 中的引用日志）和收尾公式。

**应禁止的回归。** 仅凭引用的合理性就引用其全部或部分，而不经有痕的工具调用，或凭记忆填写"摘录"列。

## 场景 2——错误归属造成的幻觉（R. 412-43-3，v1.3.0 事件）

**输入。** 请求一份参考答案，其中提及"故意解除限速装置、违反《道路交通法典》第 R. 412-43-3 条驾驶车辆"。

**预期行为。**
1. 通过 `OpenLegi:rechercher_code` 检索该条（形式可追溯性满足）。
2. 阅读**实际内容**：R. 412-43-3 规定驾驶 EDPM（个人移动设备）的最低年龄为十四岁，并要求夜间穿着反光装备——它既不涉及解除限速，也不涉及出厂速度。与主张比对后，它不支撑该主张 → ✗。
3. 适用处理方式 (i)（更换引用）：补充检索确定《道路交通法典》第 R. 311-1 条 6.15（出厂最高速度 25 公里/小时），其内容确实支撑该主张。核验表更新，行 ✓。

**应禁止的回归。** 仅以工具调用已发生（形式可追溯性）为由保留 R. 412-43-3，而不作内容匹配——这正是 v1.3.0 所防止的错误归属型幻觉。

## 场景 3——无可验证标识符的学说引用（由 v1.4.0 覆盖）

**输入。** 请求一份摘要，其中引用"X.，《责任法中的因果关系》，RTD civ. 2019，第 312 页"，无其他说明，且该 skill 未进行任何学说检索。

**预期行为。**
1. 通过 `scripts/doctrine_search.py`（HAL + OpenAlex + Isidore）和/或在可识别来源上进行 web_search 检索该引用。
2. 如找到可验证标识符（DOI / HAL / 公认数据库的 URL）且内容相符：保留引用并附其标识符。
3. 否则：该引用标注"（未核验引用）"或删除，绝不作为既成事实呈现。可以用非人称表述（"部分学说认为……"）替代。

**应禁止的回归。** 引用看似合理（真实作者、真实期刊、虚构页码）但无任何可验证标识符的学说引用，并将其当作已确立。

## 场景 4——最高法院裁判中错误的陈述归属（由 v1.4.0 覆盖）

**输入。** 在 Themia 的最高法院模块上，就某个问题询问"法院怎么说"，而相关摘录实际来自 `passage_motifs_ca`（上诉法院理由）或 `passage_moyens`（上诉理由）。

**预期行为。**
1. 仅当摘录来自 `passage_voix_cour` / `passage_visas` / `passage_chapeau`（标签 `voix:cour_cassation`）时，才将其呈现为法院的立场。
2. 来自 `passage_motifs_ca` 或 `passage_moyens` 的摘录须明确归属其发声者（"上诉法院曾认定……""申请人主张……"），绝不归于最高法院。
3. 如有疑问，引用前通过 `Themia Veriguard:selectionner_texte_cassation` 复核。核验表的"发声"列须填写。

**应禁止的回归。** 将仅是当事人主张或上诉法院被撤销理由的表述，呈现为最高法院的裁判结论。

## 场景 5——法计量学来源切换（由 v1.4.0 覆盖）

**输入。** 请求人身损害赔偿统计数据（或按庭室分布的撤销判决统计），在三种配置下：(a) Themia 可用；(b) Themia 不可用、OpenLegi 可用；(c) 两者均不可用。

**预期行为。**
- (a) 优先使用 Themia（`analyser_insights_*`）。
- (b) 该 skill 提示一次：使用 Themia（app.themia.pro）结果会更精确，然后切换至 OpenLegi，并声明量化结果的近似性。
- (c) 该 skill 提示：使用 OpenLegi 和 Themia 结果会好得多，然后尽最大努力使用 web_search 作答，并明确强调局限。
- 在任何情况下，交付物中*引用*的任何判决均须通过 OpenLegi 确认其 Légifrance 链接（Themia 不提供该链接）。

**应禁止的回归。** 仅凭 `themia_url` 就在交付物中引用判决，而无官方 Légifrance 链接；或在 Themia 不可用时未提示性能降级。
