# 抄袭与 AI 生成迹象检测方法

> 本文档定义任务 2（复核）用于识别抄袭或人工智能生成迹象的启发式协议。**不推荐任何外部检测工具**：现有工具（GPTZero、Turnitin AI 等）不可靠，且经常产生误报。

## 基本原则

### 强制术语
- ✅“迹象”“提示性要素”“信号”
- ❌“证据”“确定”“已确认检测”

### 认知姿态
- 写得很好的文本本身**不**可疑
- 写得很差的文本**不**排除抄袭
- 检测基于**迹象的汇聚**，绝不基于单一指标
- 结果**始终**是定性评价，绝非分数或百分比
- 目标是提醒，而非指控

### 本方法**不**做什么
- 断言文本系抄袭或 AI 生成
- 产出“抄袭率”或“AI 分数”
- 推荐外部检测工具
- 取代教师的人工判断

---

## 抄袭迹象检测协议

### 1. 内部文体分析

**查找文档内部的风格断裂：**
- 语言语域的突然变化（非常正式的段落与口语化的段落交替）
- 写作质量的突然变化（优秀的段落与薄弱的段落交替）
- 技术词汇的变化（专业术语后接不精确表述）
- 引用体系的不一致（格式突然改变）
- 排版的差异（先法语引号后英语引号，先有不间断空格后没有）

**评估表：**
| 迹象 | 强度 |
|---|---|
| 孤立的风格断裂 | 弱 |
| 多处且局部的风格断裂 | 中 |
| 整个段落的风格与其余部分截然不同 | 强 |

### 2. 文本相似度检索（web_search）

**对可疑段落（经文体分析识别）进行：**
1. 从可疑段落中提取一个**有辨识度的 n-gram**：一段 6 到 10 个词的罕见序列（少见表达、不寻常搭配、特定连接），最好不含常见专有名词。
2. 通过 web_search 检索该 n-gram，**不带引号、不用精确检索操作符**：当前搜索引擎会严重弱化（甚至忽略）引号内的精确短语检索，因此“精确短语”查询往往返回零结果，而来源其实存在。对有辨识度 n-gram 的关键词查询能更稳健地找到来源。
3. 如有来源出现：打开页面并**逐字比较**文本与可疑段落（对应关系通过阅读验证，而非仅凭搜索引擎有响应）。
4. 对同一段落的 3 至 5 个不同 n-gram 重复，最好分散分布。

**解读：**
- 与未引用的来源存在强文本对应 → 强抄袭迹象
- 部分对应（轻微改写、观点和结构相同）→ 中等迹象
- 无对应 → 无迹象（但非原创的确定性；无结果可能源于搜索引擎的限制）

### 3. 参考文献分析

**核验参考文献与撰写者水平的相符性：**
- 整体肤浅的作品中却有非常专业的参考文献 → 迹象
- 参考文献全部来自同一来源（抄录书目）→ 迹象
- 无法核验的参考文献（标题看似合理但找不到）→ AI 生成迹象

## AI 生成迹象检测协议

### 1. 过度的文体统一性

LLM 生成的文本常表现为：
- **异常的句法规律性**（句子长度相似、重复的平行结构）
- **词汇一律圆滑得体**（缺乏个人印记、犹豫、个人风格选择）
- **标点过度规整**（系统性地使用插入语逗号、无偏差）
- **语气持续克制**（缺乏激情、立场、鲜明表述）

### 2. LLM 特征性标记

**常见的生成结构：**
- 在学术文本应用散文处系统使用项目符号列表
- 过于圆滑的引入句（“值得注意的是……”“必须强调……”）
- 机械地概括每个部分的结论
- 人为对称的过渡

**特征性词汇（须权衡——单独不足）：**
- “必须……”“应当……”“不得不承认……”
- 频繁使用“特别是”“此外”“另外”作为机械连接词
- 过度平衡的表述（“一方面……另一方面……”）

### 3. 结构迹象

- **缺乏个人锚点**：文本从不提及所受教学、个人阅读、实习或法律诊所经历
- **可疑的全面性**：文本覆盖“所有方面”却未真正深入任何一方面
- **看似合理但无法核验的参考文献**：引用真实存在的作者却配上不存在的文章标题（LLM 幻觉）

### 4. 标点定量分析

对 50 个句子的样本：
- 计算**句子长度方差**（以词计）
- 计算**逗号/句子比率**
- 人类文本方差高；AI 文本趋向统一

**指示性阈值（非绝对）：**
| 指标 | 典型人类文本 | 典型 AI 文本 |
|---|---|---|
| 句子长度方差 | > 100 | < 50 |
| 逗号/句子比率 | 多变（1.5-4） | 规整（2-3） |
| >30 词的句子占比 | 10-25% | <10% |

## 结果呈现

### 迹象报告格式

```
## 抄袭 / AI 生成迹象

### 总体观察
[整体定性评价：无迹象 / 弱迹象 / 显著迹象]

### 已发现的迹象（如有）

**迹象 1**：[描述]
- 位置：[页、段落]
- 类型：[抄袭 / AI / 不确定]
- 强度：[弱 / 中 / 强]
- 依据：[文体分析 / web_search / 参考文献分析 / 标点]

[...]

### 结论
[审慎的综合。提醒这些迹象不构成证据。]
```

### 可接受的表述

- ✅“多项汇聚的迹象表明，该段落可能并非出自署名作者之手”
- ✅“本文档的文体统一性具有与 AI 生成相符的特征，但无法断言确定”
- ✅“文本相似度检索发现了与 [来源] 的显著对应，而文档中未引用该来源”
- ❌“本文本由 ChatGPT 生成”
- ❌“该学生抄袭了此段落”
- ❌“抄袭率为 X%”
