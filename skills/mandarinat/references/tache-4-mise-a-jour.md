# 任务 4——法律文件更新

> **环境前提**：COWORK **强制**。本任务需要完整阅读源文件、生成编号修改文件，并可能整合修改。如文件超过 10 页，在 CHAT 和 CHAT_CU 模式下**阻止**。

## 目标

更新既有法律文件（课程、著作、文章、习题辅导材料、摘要卡），识别自上一版本以来发生的立法、判例和学说演变。

## 基本规则：绝不直接修改文件

**禁止**直接修改源文件。流程始终分两步：
1. **生成编号修改文件**（Markdown），呈现每项拟议修改及其可复制粘贴的内容
2. **在用户验证后提出整合**

## 流程

### 1. 文件预先分析

**执行：**
1. 完整阅读源文件
2. 识别：
   - 文件性质（课程、著作、文章、摘要卡、习题辅导材料）
   - 科目和子科目
   - 估计的最后更新日期（日期提及、最新引用）
   - 文件结构和提纲
   - 语言风格和语域
   - 文件使用的引用格式
3. 盘点所处理的法点
4. 列出所有现有引用（文本、判例、学说）

### 2. 执行 playbook（任务 0）

对文件涵盖的主题进行快速法律框架界定，以确定更新研究的检索方向。

### 3. 时效性检索

对文件中的每个法点：

**3a. 规范性文本核验**，通过 OpenLegi：
- 对每个引用的条款 `rechercher_code` → 核验现行版本、近期修改
- `rechercher_dans_texte_legal` → 关于该主题的新法律、法令、部长令
- `recherche_journal_officiel` → 尚未编入法典的近期文本
- **提示**估计最后更新日期之后的任何立法修改

**3b. 判例检索**，通过 OpenLegi：
- `rechercher_jurisprudence_judiciaire` / `_administrative`，配关键词 + 最后更新日期之后的日期过滤
- 识别：新原则性判决、改判、重大演变
- 区分：奠基性判决（应保留）与示例性判决（如有更新且更相关则可替换）

**3c. 学说检索**，通过 HAL + web_search：
- `scripts/doctrine_search.py` → 关于文件主题的近期学说（多来源、可核验标识符）；`scripts/hal_search.py` 作为针对性补充
- web_search → Cairn、Dalloz Actualité、Persée
- 识别重大学说演变、新争论

**3d. 比较法**（如文件包含比较法要素）：
- `LegalDataHunter:search` 核验外国法要素的时效性

### 4. 现有引用核验

对文件中的每条引用：
1. 通过 OpenLegi 或 web_search 核验存在性和准确性
2. 核验时间状态（文本仍然有效？判例未被推翻？）
3. 如错误：在修改文件中更正
4. 如引用过时：提议替换

### 5. 生成修改文件

**单个文件** `[AAAA-MM-JJ]-modifications-[nom-doc].md`，结构如下：

```
# 拟议修改——[文件名称]

**日期**：[AAAA-MM-JJ]
**源文件**：[文件名]
**估计最后更新**：[日期]

**摘要**：
- 修改总数：X
- 主要更新：[简要清单]
- OpenLegi 核验：[已完成 / 不可用]

---

## 修改 1——章节：[章节确切名称]

### [添加 / 替换 / 删除] [插入点说明]

**旧文本**（如为替换）：
[文件中现有文本]

**新文本**：
[格式化内容，可复制粘贴，符合文件风格]

**理由**：[简要说明，1-3 句]

**已核验来源**：[URL 或所用 OpenLegi 工具]

---

## 修改 2——章节：[...]
[...]
```

### 修改文件原则

**顺序**：严格遵循文件顺序（自上而下）。

**操作类型**：
- **添加**：插入新内容（注明插入点）
- **替换**：替换（始终注明旧文本和新文本）
- **删除**：移除（必须有充分理由）

**内容格式**：
- 文本直接按源文件风格格式化
- 可复制粘贴（无需任何处理）
- 遵守语言语域、引用体系和文件结构

**判决的区别处理**：
- 奠基性判决（Teffaine、Jand'heur、Franck 等）：**不替换**
- 示例性判决：如有更近判决（< 3 年）且更相关则替换
- 有疑问时：向用户提出多个选项

### 6. 交付与整合建议

1. 将修改文件交付到工作文件夹
2. 向用户提议：
   - 将修改整合到文件（如为 Word：验证后直接编辑）
   - 待讨论或拒绝的修改
   - 对特定要点的补充检索

提议相关任务：更新关联的 PPTX 辅导材料、生成更新的 QCM（转至 `qcm-generator`）、就更新后的主题创建新考试题。
