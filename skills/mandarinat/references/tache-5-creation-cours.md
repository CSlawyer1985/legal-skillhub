# 任务 5——课程创建

> **环境前提**：COWORK **必需**。本任务产出一个或多个大文件（Word + 可能的 PPTX）。**阻止**在 CHAT 和 CHAT_CU 模式下执行。

## 目标

创建完整的法律课程或教学序列，附书面支持（Word）并可选择演示支持（PPTX）。

## 流程

### 1. 需求定性

向用户收集（或从上下文推断）：
- **学科**：民法、行政法、刑法、商法等。
- **子学科/主题**：民事责任、特别合同、城市规划法等。
- **级别**：L1 / L2 / L3 / M1 / M2 / 继续教育 / 考试备考
- **课时量**：大课和/或辅导课的时数
- **格式**：仅大课 / 大课+辅导课 / 教学序列
- **预期支持**：仅 Word / Word + PPTX / Word + PPTX + 练习

如缺少不可或缺的要素：请求澄清。

### 2. 执行 playbook（任务 0）

主题的法律框架界定。识别结构主轴、关键问题、近期演变。

### 3. 深入文献检索

完整遵循 SKILL.md 第 3 节的检索序列：
- 规范性文本（OpenLegi）
- 最高法院判例然后是基层判例（OpenLegi）
- 学说（`scripts/doctrine_search.py` 多来源 + web_search）——**完整课程至少 15 个学说来源**，每个都带有可核验的标识符（DOI/HAL/URL）
- 比较法（LegalDataHunter）（如与主题相关）

**具体目标**：不仅识别法律现状，还要识别教学问题（学生理解困难之处、常见混淆、争议点）。

### 4. 课程计划设计

**课程的标准结构：**
```
总体引言
  - 定义
  - 学科的意义
  - 历史演变（简明）
  - 课程计划

第一部分——[分析性标题]
  第 1 章——[标题]
    第 1 节——[标题]
    第 2 节——[标题]
  第 2 章——[标题]
    第 1 节——[标题]
    第 2 节——[标题]

第二部分——[分析性标题]
  [相同结构]

参考书目
```

**规则：**
- 部分层面为二元结构（法国传统）
- 标题不含变位动词
- 逻辑递进（从一般到具体，从简单到复杂）
- 各部分平衡
- 适应课时量（一章 ≈ 视级别 3-6 小时）

### 5. 撰写书面支持（Word）

**调用 `docx` 技能生成文档。**

**课程内容：**
- 完整撰写的文本（非提纲式笔记）
- 规范性文本和判例的精确引用（带尾注）
- 学说引用融入论述
- 教学框：
  - "要记住"（要点综合）
  - "示例"（简要评注的判例）
  - "注意"（陷阱、常见混淆）
  - "深入阅读"（深化、推荐阅读）
- 课程末尾的参考书目

**引用格式**：见 `references/format-citations.md`

### 6. 创建 PPTX 支持（如要求）

**调用 `pptx` 技能生成演示文稿。**

**PPTX 支持的原则：**
- PPTX 是**演示支持**，而非课程的复制
- 内容精简：标题、示意图、要点、醒目标语
- 幻灯片上不放长段落文本
- 1 张幻灯片 ≈ 1 个观点
- 用示意图表现法律机制（如：责任链条、规范层级）
- 包含关键判例的引用（不展开——以 Word 课程为准）

**PPTX 的标准结构：**
- 标题幻灯片（学科、主题、教师、年份）
- 计划幻灯片
- 内容幻灯片（每个要点或每节一张）
- "示例"幻灯片（判例 + 所提问题）
- 每章综合幻灯片
- 参考书目幻灯片

### 7. 核验

交付前：
1. 核验所有引用的参考（反幻觉，SKILL.md 第 2 节）
2. 核验文本的时效性（SKILL.md 第 7 节）
3. 核验计划的一致性和各部分的平衡
4. 核验对所述级别的适应性
