# 预置案例一：民间借贷纠纷

## 案例概要

原告张三诉被告李四民间借贷纠纷一案。

---

## 一、基本信息

| 项目 | 内容 |
|:-----|:------|
| **案例编号** | MT-CASE-001 |
| **类型** | 民事·民间借贷 |
| **难易等级** | ⭐初级（适合新人/实习生） |
| **预计时长** | 标准模式3h / 快速模式1.5h |
| **核心训练点** | 证据审查/借款事实认定/利息计算/质证基础 |
| **角色配置** | 审判长1+审判员2+原告代理人2+被告代理人2+书记员1+观察员1（共9人） |

---

## 二、当事人

| 角色 | 姓名 | 身份 |
|:-----|:-----|:------|
| 原告 | 张三 | 男，1985年生，个体经营者 |
| 被告 | 李四 | 男，1983年生，公司职员 |
| 原告代理人 | 【参训者】 | 律师 |
| 被告代理人 | 【参训者】 | 律师 |

---

## 三、案件事实

张三与李四是中学同学。2024年3月，李四以"家中装修急需用钱"为由向张三借款人民币50万元，双方于2024年3月15日签署《借款协议》，约定：

1. 借款金额：人民币50万元
2. 借款期限：6个月（2024年3月15日至2024年9月14日）
3. 月利率：1.5%（年利率18%）
4. 还款方式：到期一次性还本付息

张三于2024年3月16日通过银行转账向李四支付50万元。

李四在借款到期后未还款。张三于2024年10月、2025年1月、2025年6月多次通过微信催收，李四以"手头紧"为由拖延。2025年12月，张三正式委托律师向李四发出律师函，李四收到后仍未还款。

张三遂于2026年1月向法院起诉，要求李四偿还借款本金50万元及利息（按月利率1.5%，从2024年3月16日计算至实际清偿之日）。

李四辩称：确实收到50万元，但该款项并非借款，而是张三对李四的**赠与**，用于李四的孩子出国留学。李四称双方之间并无借贷合意。

---

## 四、争议焦点

**焦点一**：原被告之间是否成立借款合同关系（资金往来性质认定）
**焦点二**：如构成借款，利息是否应当支持（利率是否超过法定上限）
**焦点三**：原告的诉讼请求是否超过诉讼时效

---

|:-----|:-----|:------|

| 《民法典》 | 第188条 | 诉讼时效期间 |
| 《民法典》 | 第195条 | 诉讼时效中断 |

## 六、原告方证据

| 编号 | 证据名称 | 类型 | 证明目的 | 设计瑕疵 |
|:----:|:---------|:-----|:---------|:---------|
| P-1 | 《借款协议》原件 | 书证 | 证明双方存在借贷合意 | ✅ 无 |
| P-2 | 银行转账凭证 | 书证 | 证明张三已支付50万 | ✅ 无 |
| P-3 | 微信聊天记录截图（共8页） | 电子数据 | 证明多次催收+中断诉讼时效 | ✅ 部分截图不完整 |
| P-4 | 律师函及快递签收回执 | 书证 | 证明正式催收 | ✅ 无 |
| P-5 | 李四的朋友圈截图 | 电子数据 | 证明借款期间李四在出国旅游而非"手头紧" | ✅ 关联性可能存疑 |

### 证据瑕疵说明

**P-3 微信聊天记录**：张三仅提供了聊天记录截图（打印件），未提供原始微信聊天记录载体（手机）。截图中部分时间戳不完整，有些对话缺乏上下文。被告可在质证时质疑证据的完整性和真实性。

**P-5 朋友圈截图**：截图显示借款期间李四在出国旅游，用以反驳李四"手头紧"的主张。但该证据与本案核心争议（借贷vs赠与）关联性较弱，属于间接证据。

---

## 七、被告方证据

| 编号 | 证据名称 | 类型 | 证明目的 | 设计瑕疵 |
|:----:|:---------|:-----|:---------|:---------|
| D-1 | 张三与李四的微信聊天记录（2024年2月） | 电子数据 | 证明张三曾口头表示"孩子留学的事我支持你" | ✅ 完整记录（与P-3形成对比） |
| D-2 | 李四孩子国外学校录取通知书 | 书证 | 证明留学事实的存在（与赠与目的相符） | ✅ 间接证据 |
| D-3 | 张三妻子王五的证人证言（书面） | 证人证言 | 证明张三在家说过"送李四的孩子出去" | ✅ 传闻/间接/利害关系 |
| D-4 | 张三2024年银行流水 | 书证 | 证明张三资金充足，赠与经济合理 | ✅ 无 |

### 证据瑕疵说明

**D-1 微信聊天记录**：被告提供了2024年2月的完整聊天记录（含原始手机载体），显示张三曾发语音说"孩子留学的事我支持你"。但该表述语境模糊——"支持"可以是情感支持，也可以是经济支持，存在解释空间。

**D-3 证人证言**：王五是张三的妻子，与案件有直接利害关系。她提到张三在家说"送李四的孩子出去"——"送"这个词有歧义（送行vs资助）。

---

## 八、参考答案与评分要点（仅供教练使用）

### 争点倾向性分析

| 争点 | 倾向分析 |
|:-----|:---------|
| **借贷vs赠与** | 张三有《借款协议》明确约定→法律形式完整，举证充分。李四主张赠与但无书面证据→举证难度大。"我支持你"的表述歧义大，难以证明赠与合意。**倾向于认定借贷关系成立** |
| **利息是否支持** | 月利率1.5%（年利率18%）——2024年3月时LPR为3.45%，LPR四倍为13.8%。18%超出LPR四倍。**超出部分法院不予支持**，应按LPR四倍计算。此题考察参训者是否熟练掌握利率保护上限的最新数值。 |
| **诉讼时效** | 借款到期日：2024年9月14日。诉讼时效3年（2027年9月14日届满）。张三2024年10月/2025年1月/2025年6月多次催收→诉讼时效多次中断。**时效未过** |

### 评分特别关注点

```
质证环节重点关注：
  □ 被告方是否抓住P-3的电子数据完整性缺陷？
  □ 原告方是否成功反击D-1的表述歧义？
  □ 双方是否注意到诉讼时效问题？

辩论环节重点关注：
  □ 对利率上限的引用是否准确（LPR四倍及其数值）
  □ 对"借贷vs赠与"的核心论证是否有力
```
