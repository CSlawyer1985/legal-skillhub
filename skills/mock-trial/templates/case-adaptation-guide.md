# 案例改编指引

## 模板说明

指导如何将真实案例改编为适合模拟法庭的训练案例。

---

## 一、案例改编原则

### 1.1 核心原则

```
✅ 真实是基础，改编是手段，训练是目的
✅ 对抗性优先——给双方均有胜诉空间
✅ 难易可控——根据参训者水平调整复杂度
✅ 逻辑自洽——改编后的事实需符合常理和证据
✅ 脱敏处理——隐去真实的当事人身份信息
```

### 1.2 改编尺度

| 改编程度 | 适用场景 | 改编范围 | 优缺点 |
|:---------|:---------|:---------|:-------|
| **微调** | 策略预演/真实案件模拟 | 仅模糊当事人信息+简化非核心事实 | 最接近真实、但对抗空间有限 |
| **中度改编** | 常规培训/技能训练 | 重构部分事实+增加可辩论空间+调整证据 | 对抗性好、但需注意逻辑自洽 |
| **深度改编** | 新人入门/教学案例 | 仅保留核心法律关系+全面重构事实 | 容易控制难度、但可能偏离真实 |

## 二、改编六步法

### 第一步：选案

```
选案标准：
□ 法律关系有代表性（常见案由优先）
□ 核心事实有争议空间（非一边倒）
□ 法律适用有可辩驳余地（存在法律理解分歧）
□ 证据材料可转化为模拟证据（不过于复杂）
□ 案件规模适中（3-5个法律争点为佳）

推荐案由：
民事：借贷/买卖/租赁/侵权/劳动/建设工程
刑事：盗窃/诈骗/故意伤害/交通肇事
行政：行政处罚/信息公开/行政许可
```

### 第二步：拆案

```
拆解案件的核心要素：

1. 事实层
   □ 时间线整理（关键时间节点）
   □ 当事人关系（合同关系/亲属关系/侵权关系）
   □ 核心事件（引发纠纷的关键行为）

2. 法律层
   □ 法律关系定性（合同vs侵权/罪名的认定）
   □ 主要法律争点（2-3个）
   □ 法律适用分歧点

3. 证据层
   □ 双方各自的有利证据
   □ 对证据的不同解释空间
   □ 证据链中的薄弱环节
```

### 第三步：重构

```
重构要点：

1. 简化非核心事实
   □ 去掉不影响法律判断的次要细节
   □ 合并多个同类事实

2. 均衡对抗性
   □ 确保双方各有有利和不利证据
   □ 设置至少一个"两边都讲得通"的争点
   □ 控制证据的强弱对比（不要太悬殊）

3. 设置"训练点"
   □ 设置需要质证技巧的证据瑕疵
   □ 设置需要辩论技巧的法律模糊地带
   □ 设置需要发问技巧的事实矛盾
```

### 第四步：脱敏

```
脱敏检查清单：
□ 当事人姓名→改为化名/无指代性名称
□ 身份证号/手机号→完全替换（随机生成）
□ 公司名称→改为同行业无对应关系的名称
□ 具体地址→改为虚构地址（保持逻辑合理）
□ 案件号→完全删除
□ 法官/律师姓名→完全删除
□ 可能推断出真实当事人的情节→模糊处理
```

### 第五步：配证

```
证据配置策略：

双方证据比例 → 建议4:3或5:4（原告略多）

原告方证据配置：
  □ 2-3份核心证据（证明基本事实）
  □ 1-2份辅助证据（佐证核心证据）
  □ 1份有瑕疵的证据（供质证训练）

被告方证据配置：
  □ 1-2份直接反驳的证据
  □ 1-2份间接证据/旁证
  □ 1份有争议的证据

证据类型多样化：
  ☐ 书证（合同/收据/函件）
  ☐ 电子数据（聊天记录/邮件/转账记录）
  ☐ 证人证言（目击/专家）
  ☐ 视听资料（录音/录像/照片）
  ☐ 鉴定意见（评估报告/鉴定书）
```

### 第六步：验案

```
改编完成后的验证：

□ 1. 事实逻辑验证
   → 时间线是否自洽？
   → 因果关系是否合理？
   → 当事人的行为是否符合正常人逻辑？

□ 2. 法律逻辑验证
   → 法律关系是否清晰？
   → 适用的法条是否准确？
   → 争议焦点是否具有辩论价值？

□ 3. 对抗性验证
   → 原被告双方是否均有一定的获胜可能？
   → 是否存在"一边倒"的证据？
   → 庭审表现是否可能影响结果？

□ 4. 可行性验证
   → 常规模式下是否可以在3-4小时内完成？
   → 证据是否清晰可理解？
   → 角色数量是否合适？

□ 5. 训练价值验证
   → 本次训练的核心目标是否可以通过本案例实现？
   → 参训者可以学到什么？
   → 哪些技能可以被充分训练？
```

## 三、常见改编问题

| 问题 | 表现 | 解决方案 |
|:-----|:------|:---------|
| 案例过于复杂 | 参训者花大量时间理解事实，没时间训练技能 | 简化事实、删减非核心情节 |
| 一方明显占优 | 对抗性不足，参训者失去动力 | 增加弱势方有利证据/削弱强势方证据 |
| 证据过于完美 | 质证训练不充分 | 加入有瑕疵证据（签名不清/复印件/不一致） |
| 争议点过多 | 辩论分散、时间不够 | 聚焦2-3个核心争议点 |
| 改编后不合常理 | 参训者质疑案例真实性 | 请同事试读+逻辑复盘 |
| 脱敏不彻底 | 真实当事人信息泄露风险 | 三层脱敏核查（姓名/地址/可识别细节） |
