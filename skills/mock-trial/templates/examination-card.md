# 庭审发问专项训练卡

## 模板说明

适用于模拟法庭中发问环节的专项技能训练。覆盖直接询问、交叉询问、反对发问三大核心技能。

---

## 一、发问基础概论

### 1.1 发问类型对比

| 维度 | 🔵 直接询问（己方证人） | 🔴 交叉询问（对方证人） |
|:-----|:-----------------------|:-----------------------|
| **发问对象** | 己方申请的证人/当事人 | 对方申请的证人/对方当事人 |
| **发问目的** | 展现证言、加固可信度 | 找矛盾、削弱可信度、锁定不利事实 |
| **问题类型** | **开放式问题为主** | **封闭式问题为主** |
| **诱导性询问** | ❌ 禁止（对方会反对） | ✅ 允许 |
| **发问节奏** | 舒缓、有叙事感 | 快速、步步紧逼 |
| **典型错误** | 问诱导性问题被打断 | 问开放式问题失去控制 |

### 1.2 发问的基本原则

```
❶ 不要问你不知道答案的问题（交叉询问的铁律）
❷ 每个问题只包含一个事实点（不要复合问题）
❸ 用封闭式问题控制回答（是/否即可）
❹ 达到目的就停（不追问、不多说）
❺ 倾听回答（根据回答调整下一个问题）
❻ 始终服务你的论证目标（不发无关问题）
```

## 二、直接询问技巧

### 2.1 直接询问的叙事策略

```
开场定向
  "请向法庭介绍你自己。"
  "你今天要就什么事情向法庭作证？"

建立可信度
  "你从事XX工作多少年了？"
  "你当时距离现场多远？光线条件如何？"
  → 目的：让法官相信证人具备感知和记忆能力

引导叙事（开放性问题+顺序引导）
  "请你回忆一下，____年__月__日那天发生了什么？"
  "你到了现场之后看到了什么？"
  "然后你做了什么？"
  "之后又发生了什么？"

加固关键事实（封闭式锁定）
  "你确实看到了被告在那个时间出现在现场？"
  "你看清楚了他的脸？"
  "距离不到3米？"
  → 目的：让法官对关键事实印象深刻

补强可信度（应对预期的攻击）
  "你和本案的当事人是什么关系？"
  "你有没有受到任何人的指使或压力来改变你的证言？"
  → 目的：对方会问的，我先问（抢先堵住攻击点）
```

### 2.2 直接询问的禁忌

```
❌ 诱导性询问——"你是不是看到他拿着刀冲过去？"
   ✓ "你当时看到了什么？"

❌ 复合问题——"你到了现场看到了什么、听到了什么、然后做了什么？"
   ✓ 拆成一个个简单问题

❌ 律师替证人回答问题——"所以你当时觉得很害怕，对吧？"
   ✓ "你当时感觉怎么样？"（让证人自己说）

❌ 打断证人——证人在组织语言时抢话
   ✓ 给证人时间，除非跑题或不应答
```

## 三、交叉询问技巧

### 3.1 交叉询问的"漏斗法"

```
宽口开（建立基础事实，证人无法否认）
  "案发那天你在现场，对吗？"
  "你看到了原告和被告在争吵？"
  "你听到了被告说了一些话？"

收窄（锁定关键事实，证人只能说"是"）
  "你距离他们不到5米？"
  "当时光线很好？"
  "你的视力正常？"
  "你没有戴眼镜？"

致命一击（结论或矛盾）
  "所以你清楚地看到了整个过程？"
  "但你的证词里却说'没看清楚'——这两者是矛盾的，对吗？"
```

### 3.2 交叉询问八大策略

| 策略 | 适用场景 | 话术示例 |
|:-----|:---------|:---------|
| **① 锁定式** | 确定基础事实 | "你当时在现场，对吗？"——只有"是"或"否" |
| **② 渐进式** | 步步紧逼到矛盾点 | "你认识被告"—"你们有合作"—"你们有经济往来"—"他欠你钱？" |
| **③ 二难式** | 给对方两个选项，两边都是坑 | "你看到被告动手了？还是你其实没看到？" |
| **④ 对比式** | 与庭前证言/客观证据对比 | "你的证词里说时间是下午3点，但通话记录显示是2点——你怎么解释？" |
| **⑤ 披露式** | 揭露证人的偏见/利害关系 | "你和原告认识多久了？你们是什么关系？" |
| **⑥ 揭疵式** | 揭露证人感知/记忆的不可靠 | "事发到现在已经过去两年了，你是如何记得这么清楚的？" |
| **⑦ 以子之矛** | 用对方自己的证据攻击 | "你方提交的证据上写着——你自己看看第2行，写的是什么？" |
| **⑧ 遏制式** | 阻止不利证言的全面展开 | 对敏感点点到为止，不要追问 |

### 3.3 交叉询问话术模板

```
【锁定基础事实】
"证人，____年__月__日你在XX现场，对吗？"
——"是的。"
"你看到了____在发生？"
——"是的。"

【揭露矛盾】
"你刚才说你'看得很清楚'？"
——"是的。"
"但你之前的证词里写的是'距离大概20米'？"
——"……是。"
"20米的距离，在晚上，你能看清楚一个人的脸？"
——"……"

【揭露利害关系】
"你和原告是怎么认识的？"
——"我们是同学/同事/朋友。"
"你们认识多久了？"
——"____年。"
"你们平时经常联系？"
——"是的。"
"所以你希望原告赢这个官司？"
——"……我……"
```

### 3.4 交叉询问禁忌

```
❌ 问开放式问题——"请你解释一下当时发生了什么？"
   → 对方会借机展开长篇大论，你失去控制

❌ 问你不知道答案的问题
   → 对方可能给出你意想不到的答案，让你措手不及

❌ 情绪化——对证人生气、嘲讽、人身攻击
   → 法官会反感，陪审团（如果有）会同情证人

❌ 追问到底——明明已经达到目的，还要再追问
   → 给证人翻盘的机会

❌ 和证人争论——"你撒谎！""你胡说！"
   → 有效的方式是让证人和自己之前的证词矛盾，而不是直接说对方撒谎
```

## 四、法庭发问反对训练

### 4.1 常见反对理由

| 反对理由 | 法律依据 | 适用场景 | 话术 |
|:---------|:---------|:---------|:------|
| **诱导性发问** | 直接询问中对己方证人不可诱导 | 己方证人→对方用诱导性问题 | "反对！辩护人对己方证人进行诱导性发问。" |
| **无关联** | 发问内容与案件无关 | 发问偏离争议焦点 | "反对！该发问与本案无关。" |
| **复合问题** | 一个问题包含多个事实点 | 同时问两件以上事情 | "反对！该问题为复合问题。" |
| **推测** | 要求证人推测而非陈述事实 | "你觉得……" | "反对！要求证人对未经证明的事实进行推测。" |
| **传闻** | 证人陈述非亲身感知的事实 | "我听说……" | "反对！该陈述为传闻证据。" |
| **重复** | 已经问过且已回答的问题 | 反复纠缠同一问题 | "反对！该问题已问过并已得到回答。" |
| **缺乏基础** | 发问的前提事实未经证明 | "你拿了钱之后……"（前提未经证明） | "反对！发问缺乏事实基础。" |

### 4.2 反对话术练习

```
场景一：公诉人对己方证人直接询问时
  公诉人："你看到被告拿着刀冲向你，对吗？"
  辩护人："反对！公诉人对己方证人进行诱导性发问。"
  审判长："反对有效。请公诉人调整发问方式。"

场景二：辩护人对对方证人交叉询问时
  辩护人："你觉得原告是不是在撒谎？"
  公诉人："反对！要求证人进行推测。"
  审判长："反对有效。辩护人，请围绕事实发问。"
```

## 五、发问实战演练

### 演练1：直接询问——构建叙事

```
场景：你是原告代理人，申请原告出庭作证，证明被告未按合同交付货物。

任务：准备5-8个直接询问问题，引导原告完整陈述：
  ① 与被告的合同关系
  ② 被告未交付货物的具体情形
  ③ 原告因此遭受的损失
  ④ 原告催收的过程

要求：
  ✓ 先开放式问题引导叙事
  ✓ 再用封闭式问题锁定关键事实
  ✓ 不能使用诱导性问题
```

### 演练2：交叉询问——揭露矛盾

```
场景：被告方证人（被告员工）作证说："被告按时交付了货物，
是原告拒绝签收。"

你发现以下矛盾点：
  A. 该证人在庭前证词中说"我当时不在现场"
  B. 物流记录显示被告发货时间晚于合同约定期限
  C. 证人曾因工作失误被原告投诉

任务：设计5个以上交叉询问问题，逐层揭露证人的不可信。
```

### 演练3：反对发问——临场反应

```
训练规则：
  两人一组，A对B发问，B在适当时候提出"反对"。
  A的发问中故意加入：诱导性问题、复合问题、推测问题、
  无关问题各至少1个。
  B须准确识别并反对。
  
  计时：每轮3分钟，然后互换角色。
```

### 演练4：发问vs防御——攻防对抗

```
场景：故意伤害案
  公诉人指控被告故意伤害。
  被告主张正当防卫。
  关键证人是现场唯一的目击者——便利店的老板。

角色分配：
  A = 公诉人（交叉询问证人——削弱可信度）
  B = 辩护人（直接询问证人——加固可信度）
  C = 证人（持证人证言）

准备时间：10分钟
对抗时间：每方发问5分钟（共10分钟）

训练目标：
  ✓ 同一位证人，双方如何通过发问达到相反的证明效果
  ✓ 如何控制发问节奏
  ✓ 如何在发问中嵌入论证
```
