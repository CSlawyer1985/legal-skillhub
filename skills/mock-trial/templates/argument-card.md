# 辩论训练卡

## 模板说明

适用于模拟法庭中的法庭辩论专项技能训练。

---

## 一、辩论结构模板

### 标准辩论结构

```
一、开头称谓
  "审判长、审判员：/ 仲裁庭："

二、开门见山（表明立场+核心论点）
  "就本案第__个争议焦点，原告/被告/辩护人发表如下意见："
  "核心观点是：……"

三、事实论证（按争点逐项展开）
  "首先，关于……的事实认定问题。"
  "已查明的事实表明……（引用证据1、2）"
  "对方关于……的主张与在案证据不符。（证据3证明了……）"

四、法律适用（将事实与法律关联）
  "其次，关于本案的法律适用问题。"
  "根据《______法》第__条……（引用法条）"
  "结合本案事实，……（将事实与法条建立联系）"
  "因此，……（得出法律结论）"

五、驳斥对方（针对对方核心论点）
  "针对对方提出的……，我方认为："
  "第一，……；第二，……；第三，……"
  "对方的观点存在以下逻辑错误：……"

六、概括总结（提炼核心优势+呼应诉求）
  "综上所述，……（总结核心论点）"
  "恳请合议庭依法支持我方的【诉讼请求/答辩意见】。"

七、结束语
  "以上代理/辩护意见，恳请合议庭采纳。谢谢！"
```

## 二、辩论修辞技巧

### 逻辑论证工具

```
三段论（最常见也最有效）：
  大前提：法律规定……（引用法条）
  小前提：本案事实是……（引用证据）
  结论：因此，……（得出法律结论）

例：
  大前提：《民法典》第577条规定，当事人一方不履行合同义务的，应当承担违约责任。
  小前提：被告在2024年6月30日未按约定交付货物，且无免责事由。
  结论：因此，被告应当向原告承担逾期交货的违约责任。
```

### 反驳策略

```
直接反驳 ── 正面否定对方的论据或论证过程
  "对方主张……，但这一主张缺乏事实依据……"

归谬法 ── 将对方的逻辑推演到极致，显示出荒谬性
  "如果按照对方的逻辑，那么……，这显然是不合理的。"

举轻以明重 ── 用更轻微的情形反证
  "连……（更轻微的情形）都被认定为……，本案中……（更严重的情形）更应……"

类比推理 ── 用相似案例或情形进行类比
  "（2023）最高法民申XX号案中的情形与本案高度类似，该案认定……，本案亦应……"
```

## 三、辩论常见错误

```
❌ 1. 念代理词（不是辩论，是宣读）
   → 应当对着对方讲、对着法官讲，不是对着稿子念

❌ 2. 不回应对方（各说各话，没有交锋）
   → 辩论的灵魂在于"回应"，要针对对方的论点进行反驳

❌ 3. 人身攻击（针对对方代理人而非针对其论点）
   → "对方代理人的说法缺乏基本逻辑"——不要评价人，要评价论点

❌ 4. 情绪化（拍桌子、提高音量、人身攻击）
   → 保持理性、专业、有风度的辩论

❌ 5. 跑题（脱离争议焦点）
   → 紧扣焦点，对焦发言

❌ 6. 啰嗦重复（同一个论点反复说）
   → 精炼表达，不说第二遍

❌ 7. 超时（占用对方的时间）
   → 尊重时间控制，超时即扣分

❌ 8. 事实与法律脱节（只讲法律不沾事实，或只讲事实不谈法律）
   → 事实+法律必须有机结合
```

## 四、辩论实战演练

### 演练1：即兴反驳

```
对方论点："原告的诉讼请求已经超过诉讼时效，不应得到支持。"

你的反驳（60秒内）：
请从以下角度准备：
A. 诉讼时效的起算点（何时知道或应当知道权利受损）
B. 诉讼时效中断（是否有催收记录/对方承认债务）
C. 诉讼时效的例外（人格权侵权不适用诉讼时效等）
```

### 演练2：三轮交锋

```
第1轮（各2分钟）
  原告方陈述核心论点
  被告方陈述核心论点

第2轮（各1.5分钟）
  原告方针对被告的论点进行回应
  被告方针对原告的论点进行回应

第3轮（各1分钟）
  原告方最后反驳+总结
  被告方最后反驳+总结

训练目标：
  ✓ 精准捕捉对方的核心论点
  ✓ 有针对性的反驳（不回避）
  ✓ 时间控制（在规定时间内说完）
  ✓ 总结提炼（最后一句要有力）
```

### 演练3：限定条件辩论

```
场景：借贷纠纷
角色：你是被告方代理人
不利条件：原告有借条（真实），但被告主张已还清（但无转账记录）
有利条件：原告无法证明催收记录，被告主张超过诉讼时效

任务：制定辩论策略——既然无法否认借贷事实，如何通过
"已还清"和"诉讼时效"两个角度进行辩护？
```
