# 角色任务卡

## 模板说明

模拟法庭中分发给各角色的任务指引卡片，帮助参训者快速理解自身职责和准备方向。

---

## 一、审判长/首席仲裁员

### 你的角色

你是法庭的主持者，负责控制庭审程序、引导法庭调查、维护法庭秩序。你的核心职责是确保庭审高效、有序进行，最终作出裁判。

### 庭前准备

```
□ 熟读案例材料和证据
□ 明确本案的争议焦点（通常2-3个）
□ 准备庭审提纲（程序推进的步骤）
□ 准备法庭发问提纲（对双方的发问方向）
□ 预审判阶段可能出现的问题
```

### 庭审中你需要做

```
1. 开庭
   □ 宣布开庭
   □ 核对当事人身份
   □ 告知权利义务
   □ 询问是否申请回避

2. 法庭调查
   □ 引导原告陈述诉讼请求
   □ 引导被告答辩
   □ 组织举证质证（控制节奏）
   □ 对关键事实进行发问
   □ 决定是否准许证人出庭/调取新证据

3. 法庭辩论
   □ 归纳争议焦点
   □ 引导双方围绕争点辩论
   □ 控制辩论时间和轮次
   □ 制止不当发言

4. 最后陈述+调解征询
   
5. 休庭合议
   □ 组织合议庭评议
   □ 发表评议意见

6. 宣判
```

### 评分观察点

```
□ 庭审掌控力（节奏是否恰当、程序是否完整）
□ 中立性（是否给予双方平等的发言机会）
□ 发问质量（是否抓住关键事实）
□ 裁判说理（法律适用是否准确、论证是否充分）
```

## 二、原告代理人/公诉人

### 你的角色

你是进攻方，你的任务是向法庭清晰地展示你的诉讼请求/指控，通过证据证明你主张的事实，并说服合议庭支持你的立场。

### 庭前准备

```
□ 撰写起诉状/起诉书（规范格式+事实清晰+诉求明确）
□ 整理证据目录（分组+按逻辑顺序排列）
□ 准备代理词/公诉词（核心论点+法律依据）
□ 预判被告的抗辩方向+准备反驳
□ 预判合议庭可能的发问
□ 准备对己方证人的发问提纲
□ 准备对对方证人的交叉询问提纲
```

### 庭审中你需要做

```
1. 陈述诉讼请求/指控
   □ 清晰表述请求事项
   □ 简述事实与理由

2. 举证
   □ 按组/按顺序出示证据
   □ 说明每份证据的名称+来源+证明目的
   □ 将证据与争议焦点建立联系

3. 质证
   □ 对对方证据进行三性审查
   □ 提出有依据的质证意见
   □ 阐述质证意见对事实认定的影响

4. 发问
   □ 对己方证人进行直接询问（开放性问题）
   □ 对对方证人进行交叉询问（封闭性问题）
   □ 对对方代理人进行询问（针对矛盾点）

5. 辩论
   □ 围绕争议焦点展开
   □ 回应对方的论点
   □ 总结己方的核心优势
```

### 评分观察点

```
□ 诉讼请求是否清晰明确
□ 举证是否有逻辑、是否与争点相关
□ 质证是否精准、有策略
□ 辩论是否有说服力
□ 临场应变能力
```

## 三、被告代理人/辩护人

### 你的角色

你是防守方，你的任务是回应原告/公诉人的指控，通过证据和法律论证削弱对方的攻击，提出己方的抗辩理由，说服合议庭不支持对方的请求。

### 庭前准备

```
□ 撰写答辩状/辩护词
□ 整理己方证据目录
□ 准备质证提纲（对每份对方证据的质证要点）
□ 预判对方的核心论点+准备反驳
□ 准备法庭辩论提纲
□ 预判合议庭可能的发问
□ 准备对己方证人的发问提纲
```

### 庭审中你需要做

```
1. 答辩
   □ 针对对方的诉求/指控逐项回应
   □ 提出己方的抗辩理由

2. 质证
   □ 对每份对方证据进行系统性质证
   □ 准确把握打压/削弱/接受的策略选择

3. 举证
   □ 按逻辑顺序出示己方证据
   □ 说明证据与抗辩理由的关联

4. 发问
   □ 交叉询问对方证人（找矛盾+削弱可信度）
   □ 对己方证人发问

5. 辩论
   □ 反驳对方的核心论点
   □ 阐述己方的法律和事实依据
```

### 评分观察点

```
□ 答辩是否全面（对诉求/指控的逐项回应）
□ 质证是否有策略（不是全部否认，而是有选择有重点）
□ 辩论是否针对对方的核心论点（不回避不跑偏）
□ 临场应变和情绪控制
```

## 四、观察员/评分员

### 你的角色

你是全程观察并记录的关键第三方。你的评分和点评是整个模拟法庭训练质量的重要保障。你需要在庭审中保持高度专注，记录关键表现，并在点评环节给出有建设性的反馈。

### 准备

```
□ 熟悉案例材料
□ 理解评分维度和评分标准
□ 准备记录用纸/电子设备
□ 熟悉各角色的核心职责（以便准确评价）
```

### 观察重点

```
1. 庭前准备
   - 文书质量（格式/逻辑/完整性）
   - 证据准备（证据目录/证据分组）
   - 策略清晰度

2. 法庭表现
   - 语言表达（音量/语速/清晰度/用词）
   - 逻辑能力（论证是否严密）
   - 临场应变（遇到意外时的反应）

3. 对抗质量
   - 是否针对对方论点回应
   - 是否抓住关键争点
   - 交锋的深度和精彩度
```

```

✅ 亮点2：
❌ 待改进1：
❌ 待改进2：
💡 建议：

[角色名]：
...
```
