# 行政庭审流程脚本

## 模板说明

适用于模拟行政庭审的主持脚本。参照《行政诉讼法》及相关司法解释编制，核心差异：被告承担举证责任、规范性文件附带审查、不适用调解（赔偿/补偿除外）。

---

## 一、庭前准备

**书记员**：
"请旁听人员就座，保持肃静。宣布法庭纪律：
一、诉讼参与人应当遵守法庭规则；
二、旁听人员不得随意走动、鼓掌、喧哗、吸烟；
三、未经法庭许可不得录音、录像、摄影；
四、将手机调至静音。
全体起立！请审判长、审判员入庭。"

**书记员**：
"报告审判长，原告、被告及其他诉讼参与人已到庭，庭前准备工作就绪，可以开庭。"

---

## 二、开庭

**审判长**："【敲法槌】现在开庭。"

### 2.1 核对当事人身份

**审判长**："首先核对当事人身份。请原告报告姓名（名称）、住址（住所地）等身份信息。"

**原告方**："……"

**审判长**："请被告报告行政机关名称、住所地、法定代表人姓名及出庭应诉人员身份。"

**被告方**："……"

**审判长**："请第三人（如有）报告身份信息。"

**第三人**："……"

### 2.2 告知合议庭组成+权利义务

**审判长**："根据《中华人民共和国行政诉讼法》的规定，本案由审判员【姓名】担任审判长，与审判员【姓名】、【姓名】组成合议庭。书记员【姓名】担任法庭记录。"

**审判长**："当事人在行政诉讼中享有以下权利：
一、申请回避的权利；
二、委托诉讼代理人的权利；
三、提出证据、申请调取证据、申请证人出庭的权利；
四、进行辩论的权利；
五、最后陈述的权利；
六、提起上诉的权利（如适用）。
诉讼义务包括：依法行使诉讼权利、遵守诉讼秩序、履行发生法律效力的判决书。
各方是否听清？"

**双方**："听清了。"

**审判长**："各方是否申请回避？"

**原告方**："不申请/申请（说明理由）。"
**被告方**："不申请/申请（说明理由）。"

---

## 三、法庭调查

### 3.1 原告陈述

**审判长**："现在进行法庭调查。先由原告陈述诉讼请求及所依据的事实和理由。"

**原告方**："诉讼请求：一、撤销被告作出的【行政行为名称】；二、……事实与理由：……"

### 3.2 被告答辩

**审判长**："由被告进行答辩。"

**被告方**："答辩意见：……"

### 3.3 归纳争议焦点

**审判长**："根据双方的诉辩意见，本案争议焦点归纳如下：
第一、……（被诉行政行为的职权依据）；
第二、……（被诉行政行为的事实认定和证据）；
第三、……（被诉行政行为的法律适用和程序）；
第四、……（规范性文件是否合法有效，如涉及）。
双方对以上争议焦点有无补充？"

**双方**："无异议/有补充……"

### 3.4 被告举证+原告质证

**审判长**："根据《行政诉讼法》第34条，被告对作出的行政行为负有举证责任。现在由被告出示证据，说明作出行政行为的依据。"

**被告方**："证据一：【证据名称】，证明目的：……（行政行为的事实依据）"
**被告方**："证据二：【证据名称】，证明目的：……（行政行为的法律依据）"
**被告方**："证据三：【证据名称】，证明目的：……（行政行为的程序依据）"

**审判长**："请原告对被告出示的证据发表质证意见。"

**原告方**："（质证意见：对证据的真实性/合法性/关联性……）"

### 3.5 原告举证+被告质证

**审判长**："现在由原告出示证据。"

**原告方**："证据一：【证据名称】，证明目的：……（证明行政行为违法/越权/滥用职权等）"

**审判长**："请被告发表质证意见。"

**被告方**："（质证意见）……"

（循环至举证质证完毕）

### 3.6 规范性文件附带审查（如有）

**审判长**："原告方主张被诉行政行为所依据的【规范性文件名称】不合法，请求本院一并审查。原告方的具体理由是什么？"

**原告方**："（提出具体理由：上位法违反/超越权限/程序违法等）"

**审判长**："被告方对原告的主张发表意见。"

**被告方**："（回应）……"

### 3.7 法庭发问

**审判长**："现在本庭就本案有关事实和法律问题向双方发问。"

**审判长**："请原告回答：……"
**审判长**："请被告回答：……"

**审判员**：（补充发问）"……"

**审判长**："现在双方可以相互发问。"

**原告方**："请问被告……"
**被告方**："请问原告……"

---

## 四、法庭辩论

**审判长**："法庭调查结束。现在进行法庭辩论。请原告发表辩论意见。"

**原告方**：（辩论意见——围绕被诉行政行为的合法性展开，包括职权依据/事实认定/法律适用/程序合法性等）

**审判长**："请被告发表辩论意见。"

**被告方**：（辩论意见）

**审判长**："第二轮辩论。原告先发言。"

**原告方**：（针对被告的辩论意见进行回应）

**被告方**：（针对原告的辩论意见进行回应）

**审判长**："各方还有无新的辩论意见？"

**双方**："没有了/还有。"

**审判长**："法庭辩论结束。"

---

## 五、最后陈述

**审判长**："根据法律规定，双方有最后陈述的权利。请原告作最后陈述。"

**原告方**："……"

**审判长**："请被告作最后陈述。"

**被告方**："……"

---

## 六、调解征询（赔偿案件适用）

**审判长**："根据《行政诉讼法》第60条，行政案件不适用调解。但行政赔偿、补偿以及行政机关行使法律法规规定的自由裁量权的案件可以调解。本案是否属于上述可以调解的情形？如是——双方是否愿意调解？"

**双方**："愿意/不同意。"

---

## 七、休庭评议

**审判长**："现在休庭，合议庭进行评议。【敲法槌】"

---

## 八、宣判

**审判长**："【敲法槌】现在继续开庭。经合议庭评议，本院认为……（认定事实+适用法律）……判决如下：
一、……（维持/撤销/部分撤销/确认违法/责令履行等判决内容）；
二、……
本案系模拟法庭，本判决仅为本次训练使用。"

**审判长**："各方当事人如不服本判决，可在判决书送达之日起十五日内向上一级人民法院提起上诉。"

**审判长**："闭庭。【敲法槌】"

## 行政庭审 vs 民事庭审关键差异提示

```
┌──────────────────────┬──────────────────────────┐
│ 行政庭审              │ 民事庭审差异             │
├──────────────────────┼──────────────────────────┤
│ 被告举证为原则        │ 谁主张谁举证              │
│ 可附带审查规范性文件  │ 无此程序                  │
│ 不适用调解（原则）    │ 可调解（全程）            │
│ 可提起行政附带赔偿    │ 赔偿为独立诉请            │
│ 须审查行政行为合法性  │ 审查民事法律关系          │
│ 被告的行政机关负责人  │ 无此要求                  │
│ 应出庭（至少委托工作人员）│                     │
│ 可提行政公益诉讼      │ 无此制度                  │
│ 判决类型特殊           │ 维持/撤销/确认违法/      │
│ （维持/撤销/确认违法） │ 责令履行等                │
└──────────────────────┴──────────────────────────┘
```
