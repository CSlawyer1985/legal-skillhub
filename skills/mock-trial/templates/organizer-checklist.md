## 一、T-14天：准备阶段

### 1.1 确定训练目标

```
核心训练目标（单选）：
  □ 新人入门（感受庭审氛围+理解庭审程序）
  □ 技能训练（聚焦质证/辩论/发问的某一项或多项）
  □ 策略预演（测试重大疑难案件的诉讼策略）
  □ 考核评估（选拔/晋升/评优）
  □ 综合（涵盖以上多个目标）

目标说明和监督指标：
  _________________________________
```

### 1.2 确定模拟类型

```
□ 民事（最通用）
□ 刑事（适合有刑辩团队的律所）
□ 行政（适合有行政法业务的团队）
□ 仲裁（适合商事诉讼团队）
```

### 1.3 案例设计/选择

```
□ 案例来源确定：
   □ 真实案例改编
   □ 指导案例改编
   □ 虚构案例设计
   □ 从案例库中选择

□ 案例要素检查：
   □ 事实逻辑自洽
   □ 法律关系清晰
   □ 对抗空间充分
   □ 证据配置合理
   □ 训练目标匹配
   □ 时间可控
   □ 脱敏处理完成
```

### 1.4 其他准备

```
□ 确定参训者名单
□ 确定角色数量（根据参训人数调整）
□ 准备参考答案/评分要点（仅教练使用）
□ 准备评分表（打印足够份数）
□ 准备案例材料（打印/电子版）
□ 预订场地
```

## 二、T-7天：角色分配与下发材料

### 2.1 角色分配

```
参训者名单：
  1. 【姓名】—【角色】— 理由：________
  2. 【姓名】—【角色】— 理由：________
  3. 【姓名】—【角色】— 理由：________
  ...

分配原则：
  □ 考虑个人特长（口才好→辩论位、逻辑强→质证位）
  □ 补充短板（平时质证弱的→安排质证多的角色）
  □ 挑战性（给新人稍多的准备时间）
  □ 公平性（轮流担任不同角色）
```

### 2.2 材料下发

```
□ 给所有参训者：
   □ 案例事实（双方版本一致的基础事实）
   □ 法律依据参考
   □ 时间安排和准备要求

□ 给原告方（单独）：
   □ 原告方专属证据材料
   □ 原告方角色指引

□ 给被告方（单独）：
   □ 被告方专属证据材料
   □ 被告方角色指引

□ 给合议庭（单独）：
   □ 全部证据材料（双方证据）
   □ 庭审提纲模板
   □ 评议指引

□ 给观察员/评分员：
   □ 全部案例材料
   □ 评分表+评分标准说明
```

## 三、T-3天：准备跟进

### 3.1 庭前准备确认

```
□ 发出提醒（1次）
□ 收取法律文书（起诉状/答辩状/代理词） → 确认质量
□ 确认各方准备就绪
□ 解答参训者提问
□ 调整角色（如有必要）
□ 确认场地和设备
```

### 3.2 材料打印准备

```
□ 庭审流程脚本（审判长用）
□ 评分表（每个评分员1份+备用）
□ 计时器
□ 角色名牌（审判长/审判员/原告/被告/书记员）
□ 证据材料（一式多份：合议庭/对方/存档）
□ 法槌（如有）
□ 记录纸笔
```

---

## 四、T-0天：现场执行

### 4.1 场地布置

```
□ 审判席（居中高位）：审判长席+审判员席
□ 原告席（左侧）：原告代理人席+当事人席
□ 被告席（右侧）：被告代理人席+当事人席
□ 书记员席（审判席前下方）
□ 证人席（审判席对面/侧面）
□ 旁听席（后方）
□ 观察员/评分员席（最佳观察位置）
□ 名牌摆放
□ 证据材料就位
□ 茶水准备
```

### 4.2 活动流程

```
□ 开场说明（5分钟）
   □ 欢迎+训练目标重申
   □ 规则说明（时间控制/评分/点评流程）
   □ 角色确认

□ 模拟庭审（按流程进行）
   □ 时间控制提醒（各环节到时提醒）
   □ 及时处理程序异常（如有）
   □ 记录关键表现

□ 评分环节（休庭期间）
   □ 评分员填写评分表
   □ 合议庭进行评议

□ 点评环节（认真对待——这是最重要的部分）
   □ 合议庭先点评（裁判思路说明）
   □ 观察员/评分员逐一点评
   □ 教练综合点评
   □ 程序纠正

□ 颁奖/总结
   □ 公布最佳表现等奖项
   □ 技能转化建议
   □ 下次活动预告
```
