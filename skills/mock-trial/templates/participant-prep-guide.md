## 一、你的角色和核心任务

### 我的角色

□ 审判长/首席仲裁员 □ 审判员/仲裁员 □ 原告代理人/公诉人
□ 被告代理人/辩护人 □ 当事人/被告人 □ 证人 □ 书记员 □ 观察员

### 我的核心任务（一页速览）

**如果你扮演审判长/首席仲裁员：**
1. 熟读案例+证据（双方证据都要看）
2. 准备好庭审提纲（程序推进步骤）
3. 准备好发问提纲（向双方问什么）
4. 准备好合议庭评议思路（裁判方向）
5. 时间控制+程序控制+中立公正

**如果你扮演原告代理人/公诉人：**
1. 撰写起诉状/公诉词（按规范格式）
2. 整理证据目录+证据分组
3. 准备代理词/公诉词初稿
4. 准备质证提纲（对对方证据的质证要点）
5. 准备对己方证人的发问提纲（如有证人）

**如果你扮演被告代理人/辩护人：**
1. 撰写答辩状/辩护词
2. 整理己方证据目录
3. 准备质证提纲（对每份对方证据的攻击点）
4. 准备辩论提纲（核心抗辩方向+法律依据）
5. 准备对己方证人的发问提纲（如有证人）

## 二、倒计时准备清单

### T-7天：案例下发

```
□ 通读案例全部材料（至少2遍）
  ☐ 第一遍：了解案件全貌和基本事实
  ☐ 第二遍：标记关键事实和争议点
□ 确认理解：我清楚我的角色和任务了吗？
□ 如有疑问，向教练提问
```

### T-5天：初稿完成

```
□ 完成法律文书初稿（起诉状/答辩状/代理词等）
□ 完成证据目录初稿
□ 梳理己方的核心论点（用一句话能说清楚）
□ 梳理对方最可能使用的论点（预判）
□ 开始准备质证提纲
```

### T-3天：完善+演练

```
□ 法律文书定稿
□ 质证提纲完成（对每份对方证据的质证要点）
□ 辩论提纲完成（核心论点+法律依据+对对方论点的反驳）
□ 自我演练1次（对着镜子/录音）
  - 重点检查：我是否能在3分钟内说清核心论点？
  - 重点检查：我对质证和辩论是否准备充分？
```

### T-0天：最后准备

```
□ 打印全部材料（案卷+文书+证据目录+质证提纲）
□ 材料分类整理（按庭审环节排好顺序）
□ 着正装/律师袍（检查着装）
□ 提前到庭（至少提前15分钟）
□ 深呼吸——相信自己准备好了！
```

## 三、庭审流程一页图

```
【民事/行政标准流程】
 ① 核对身份 → ② 原告陈述 → ③ 被告答辩
 → ④ 归纳争点 → ⑤ 举证质证（原告→被告→原告→被告）
 → ⑥ 法庭发问 → ⑦ 法庭辩论（两轮）
 → ⑧ 最后陈述 → ⑨ 调解征询 → ⑩ 休庭评议 → ⑪ 宣判

【刑事标准流程】
 ① 核对身份 → ② 公诉人宣读起诉书 → ③ 被告人陈述
 → ④ 公诉人讯问 → ⑤ 辩护人发问 → ⑥ 举证质证
 → ⑦ 排非（如有）→ ⑧ 法庭辩论（公诉词→辩护词→辩论）
 → ⑨ 最后陈述 → ⑩ 休庭评议 → ⑪ 宣判

【仲裁标准流程】
 ① 核对身份 → ② 请求与答辩 → ③ 无争议事实确认
 → ④ 举证质证 → ⑤ 仲裁庭询问 → ⑥ 仲裁庭辩论
 → ⑦ 最后陈述 → ⑧ 调解征询 → ⑨ 休庭评议 → ⑩ 裁决
```

## 五、发言话术模板

### 开庭陈述

```
"审判长/首席仲裁员，原告方/申请人方现就本案发表如下意见：
本案的性质是……
核心事实是……
因此，我方的诉讼请求/仲裁请求是……"
```

### 举证

```
"审判长，原告方现出示第____号证据，即【证据名称】。
该证据证明了……（证明目的）。
该证据的原始载体在……（说明原件位置）。"
```

### 质证

```
"对【方】出示的第____号证据【证据名称】，
（如打压）我方对该证据的真实性/合法性不予认可，理由如下：……
（如削弱）我方对该证据的证明目的不予认可，该证据不能证明……
（如接受）我方对该证据的真实性予以认可，但对证明目的有异议……"
```

### 辩论开头

```
"审判长/审判员，就本案第__个争议焦点，我方发表如下辩论意见：
核心观点是……"
```

### 最后陈述

```
"综上所述，我方坚持（诉讼请求/仲裁请求/答辩意见）。
恳请（合议庭/仲裁庭）依法支持我方的主张。谢谢！"
```

## 六、自我检查清单

```
庭前最后确认：

□ 我理解案例的全部事实（包括有利和不利的事实）
□ 我清楚我的核心论点（一句话能说清楚）
□ 我能预判对方的核心论点并做了准备
□ 我的证据都熟悉了——每份证据的名称+内容+证明目的
□ 我的质证提纲写好了（每份对方证据的质证要点）
□ 我的文书已经定稿
□ 我能控制发言时间（不超时）
□ 我知道庭审的流程顺序
□ 我的着装符合法庭礼仪
□ 我提前到庭

✅ 我准备好了！
```
