# X/Y 文献与自适应查新检索

## 1. 目标

查新检索的首要目标不是把命中数降到某个区间，而是尽快完成两件事：

1. 找到可能单独影响新颖性的 **X候选文献**；
2. 找到最接近现有技术及可能补足区别特征的 **关键Y候选文献组合**。

X/Y 是检索相关性代码，不是最终法律结论。必须核对全文、关键日期、公开充分性和组合启示后才能定性。

## 2. X/Y 候选标准

| 代码 | 候选标准 | 不得仅凭 |
|---|---|---|
| X | 单篇关键日前文献明确或隐含公开拟议权利要求全部必要特征、必要关系，且公开达到可理解/可实施程度 | 标题、摘要相似度、同词数量 |
| Y-Base | 关键日前、领域/问题最接近，公开大部分必要特征和核心机制，是最接近现有技术候选 | 覆盖率高但技术问题完全不同 |
| Y-Comp | 关键日前，公开 Y-Base 缺失的关键区别特征；与 Y-Base 之间存在需要复核的结合线索 | 仅仅能与另一篇“拼出”全部词 |
| A | 背景相关、关键日后、证据不足或不能支持 X/Y 的普通候选 | 高语义分 |

Y组合只有在以下信息至少有一项时才能进入“关键Y”清单：文献自身的引用/交叉提示、相同技术问题、相同功能关系、相邻领域的明确迁移理由、标准/公知常识证据。没有结合理由时只能报告“特征分别已见”，不能直接标 Y组合。

## 3. 特征优先级

为每个必要特征记录三项：

| 项目 | 含义 |
|---|---|
| 法律必要性 | 是否属于拟议独立权利要求不可缺少的限定 |
| 区分力 | 是否能排除大量同领域噪声 |
| 表达稳定性 | 是否能用稳定术语、关系短语、参数或分类表达 |

首轮 Bool 不一定加入“最重要但无法稳定表达”的特征。优先选择同时具有高必要性、高区分力和高表达稳定性的1个特征，配合对象和机制构成三块式。

## 4. 三种检索角色

### QX：X定位式

使用“对象/领域 × 核心机制 × 1-2个高区分关键特征”，必要时增加关系短语或准确下位IPC。目标是让可能的完整披露文献进入前20，而非追求最大召回。

### QY-Base：最接近现有技术式

使用“对象/领域 × 核心机制 × 技术问题/效果”，不强制加入全部区别特征。目标是找到公开大部分特征、技术问题最接近的基础文献。

### QY-Comp：区别特征补充式

从 Y-Base 的缺失特征出发，使用“缺失特征 × 所实现功能/解决问题 × 准确分类或相邻领域”。不要继续重复 QX 的完整方案措辞。

三类检索式必须分别记录。不能只跑越来越窄的单一路径，否则容易找到 X 风格高度相似文献，却漏掉创造性分析需要的关键Y文献。

## 5. 每轮结果诊断

每条 Bool 式至少抽样前10篇；结果不足10篇时检查全部。H/M必须按当前检索角色标记，不能沿用一个通用相关度：

- QX的H：同领域/同问题，覆盖≥70%必要特征或命中核心关系；M：覆盖40%-69%；
- QY-Base的H：同领域/问题接近且覆盖大部分核心机制；M：可作为相邻基础方案；
- QY-Comp的H：明确公开当前目标缺失特征及其功能/关系；M：明确公开目标缺失特征但迁移关系待证；
- N：明显噪声；
- D：日期不适格或重复同族。

QY-Comp结果即使总体覆盖很多，只要没有在返回原文中明确命中目标缺失特征，就对该角色标N，不优先调用详情。中文单字分析造成的“查询命中”不能代替特征证据。

QY-Comp也必须通过独立质量门：命中量低于5,000，且前10中“目标缺失特征”和“该特征的功能/关系”分别至少50%可观察，并且二者在同一篇文献中的联合可观察率至少50%。只满足两个边际比例、但分别来自不同文献，仍不能进入Y-Comp候选表。结果达到上限或缺少功能关系时，只能作为取词池。QY-Base与QY-Comp各自通过检索门，也仍只构成特征互补；没有结合启示证据不得输出创造性组合风险。

Bool与world英文均失败后，执行多个相互独立的去标识化语义角度，例如完整方案、缺失区别特征×功能关系、相邻领域机制。提交响应仍记录`credits_charged`用于审计，但用户确认接口免费时不得以费用为由缩减必要召回。语义前10同样计算目标、功能和同篇联合可观察率；联合率低于50%时提取术语/分类并回到Bool。禁止只改写措辞的近似重复，使用“连续两轮没有新增术语、分类或高覆盖候选”作为语义角度的停止条件，不把相似度或边际比例写成Y-Comp成功。

语义任务串行执行，相邻提交至少间隔60秒；不限总次数，但不得并发批量提交。缓存命中或任务快速失败时也保持提交间隔。

计算前10篇 H率和 H+M率，并记录 X/Y候选是否出现。

| 观察 | 下一步 |
|---|---|
| 总量≥5,000或H率<30% | 识别占比最高的噪声类型，增加一个能排除此噪声的关键关系/结构/参数；必要时加准确IPC |
| 总量合适但前20无X、H+M率≥50% | 不继续盲目收窄；从H/M文献提取真实术语、下位IPC、申请人和引证线索，换一个特征组合 |
| 0-5条且无X | 先检查IPC格式/层级和日期条件；确认无误后去掉最低置信限定或增加严格同义OR，保留至少一个关键关系 |
| 找到Y-Base但缺少区别特征 | 启动QY-Comp，不用完整方案语义重复检索 |
| QY-Comp目标/功能/同篇联合可观察率任一<50%或总量≥5,000 | 更换目标特征表达、功能关系、相邻分类或world语言；当前批次只用于取词 |
| 中国库无X且术语/申请人有国际线索 | 用world、英文/当地语言和分类号重构，不直译整句 |
| Bool多轮无X | 使用语义检索补召回；对语义高分结果提取术语后回到Bool验证 |

新增关键词只有在以下任一条件满足时才进入下一式：来自至少2篇H/M文献、来自权利要求/分类定义/标准、或发明人确认。不要把单篇噪声文献中的偶然词加入核心式。

CN分类进入复合式前必须先用 `IPC=(...)` 单独预检。主组写成 `H01M 10/0525` 一类带空格格式；预检0条时修复格式或逐级回退，禁止继续叠加关键词。关键日期明确时，普通现有技术QX精度块加入 `PD<关键日`；关键日前申请、关键日后公开的抵触申请候选另用申请日/公开日组合检索，不与普通现有技术混为一组。

## 6. 调整顺序

按以下顺序调整，每轮只解决一个明确问题：

1. 修复概念边界：删除把不同概念混在同一OR组的词；
2. 增加关键关系/结构/步骤或参数；
3. 使用准确下位IPC或精确关系短语；
4. 更换特征组合，而不是只在原式尾部不断加词；
5. 从相关文献提取术语、申请人、分类、引证和同族线索；
6. 切换world/多语言或语义补召回；
7. 针对Y-Base缺失特征执行QY-Comp。

NOT只用于含义稳定、确认造成大量噪声的术语。不要用NOT排除可能包含相关实施方式的整个技术领域。

## 7. 候选晋级

对H/M候选调用详情，建立特征证据矩阵。只有详情核对后才能晋级：

| 晋级 | 条件 |
|---|---|
| X候选 | 全部必要特征及关系有证据位置；日期适格；无实质缺失 |
| Y-Base候选 | 同领域/问题接近，覆盖大部分特征，缺失项清楚 |
| Y-Comp候选 | 覆盖缺失区别特征，并记录潜在结合理由及证据 |

详情核验时分别记录“目标区别特征证据”和“功能/关系证据”。两者不能只由分散单字、分类号或模型推断支持。只有目标特征而没有功能关系的文献可保留为普通补充线索，不晋级Y-Comp。

每轮详情调用优先级：日期适格且覆盖最高/关系最接近的H候选；一个来自新分类、申请人或引证路径的多样性候选；一个明确命中目标缺失特征的QY-Comp候选。通常每轮先核对不超过3篇，依据新增证据再扩展。QY-Comp前10没有明确目标特征时跳过详情并调整术语/分类。关键日后文献只用于取词时不优先消耗X核验名额。QY-Base与QY-Comp分别命中只构成“特征互补线索”；必须核对结合理由和证据后才进入关键Y清单。

使用 `scripts/xy_evaluator.py` 对结构化证据做一致性检查。脚本只执行规则校验，不替代代理人判断。
每轮抽样后可将命中总量、H/M/N/D标签、已用/可用特征及X/Y状态交给
`scripts/search_strategy.py`，生成唯一且可审计的下一步动作。脚本不会自动把未确认词加入Bool式。

## 8. 中止条件

查新不能因为“命中数已下降”就停止。至少满足：

- QX、QY-Base和必要的QY-Comp均已执行；
- 每个必要特征至少在一个独立检索角度中出现；
- 对前排H/M文献完成详情核对；
- 已处理新出现的高价值术语、分类、申请人和引证线索；
- 连续两轮不再出现新的X/Y候选；
- 找到X，或完整记录未找到X时已经覆盖的特征组合、市场和限制。

## 9. 报告

分别输出：

1. X候选表：单篇覆盖矩阵、日期和证据位置；
2. Y-Base表：已公开/缺失特征、技术问题和效果；
3. Y-Comp表：补充特征、潜在结合理由及不确定性；
4. 检索策略演进表：每轮诊断、调整理由、前10 H率、X/Y新增情况；
5. 未找到X时的检索覆盖声明，禁止写成“具备新颖性”。
