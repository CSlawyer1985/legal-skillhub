# 可专利性查新工作流

## 1. 边界与输入

本流程回答“在本次检索范围内是否发现影响新颖性/创造性的现有技术”，不回答 FTO。

先记录：

| 项目 | 内容 |
|---|---|
| 拟保护主题 | 产品、方法、用途或组合 |
| 目标申请日 | YYYY-MM-DD；未知则标注未知 |
| 最早优先权日 | YYYY-MM-DD；无则填无 |
| 检索截止日 | 通常取关键日期前；抵触申请另行标注 |
| 宽限期事件 | 展会、论文、销售、演示、开源等 |
| 数据范围 | CN/world、语言、专利/非专利来源 |

若关键日期未知，可以先做技术调研，但不得给出新颖性结论。

## 2. 权利要求式拆解

把方案整理为一个“拟议独立权利要求”及可选特征，不把所有细节都称为必要特征。

| ID | 必要特征 | 结构/步骤关系 | 参数 | 技术效果 | 术语块 | 分类号 |
|---|---|---|---|---|---|---|
| F1 | … | … | … | … | 严格同义/缩写 | 下位+上位 |

先向发明人展示拆解。只有拆解错误会实质改变结果时才暂停等待确认；否则说明假设后继续。

## 3. 分块检索

执行本节前读取 `adaptive_xy_search.md`，把检索块明确分成 QX、QY-Base、QY-Comp 三种角色。

一次规划下列检索块，记录每条式子与目的：

1. **QX全要素/高区分块**：全部必要特征或对象×机制×1-2个高区分特征，定位X候选。
2. **QY-Base核心组合块**：对象×核心机制、问题×机制、结构×效果，定位最接近现有技术。
3. **QY-Comp区别特征块**：针对Y-Base缺失特征，与功能、问题、分类或相邻领域组合。
4. **分类块**：准确下位 IPC 查准，上位 IPC 补召回。
5. **申请人/发明人/引证线索块**：从结果中顺藤摸瓜；API 不支持时用外部来源或报告限制。
6. **国际与多语言块**：world + 当地语言/英文 + 分类号。
7. **语义块**：完整且去标识化的方案；只用于召回。
8. **非专利文献块**：按领域检索标准、论文、产品资料等；无法执行时明确列为未覆盖。

不要因全要素0条就停止。逐级拆到部分组合，直到结果开始重复且不再产生新术语、分类、申请人或引证线索。

### Bool块构造硬约束

除明确用于发现术语/分类的探索块外，每条 Bool 式通常包含“对象×机制/问题×关键区别特征”三个 AND 块。关键区别特征优先使用结构/步骤关系、特定部件、控制逻辑或参数，不使用通用名词凑条件。

CN精度检索先执行低成本预检：

1. 单独运行拟采用的IPC，主组前保留空格（如 `G01N 33/543`）；0条时先修复格式或回退层级；
2. 关键日期明确时，在普通现有技术精度块加入 `PD<关键日`，把抵触申请候选另列检索；
3. 最多执行一条宽发现式；若达到上限且前10 H率<30%，下一轮直接使用已验证IPC+日期+关键关系，不连续追加中文词；
4. CN普通关键词和引号都不保证短语匹配；对象/关系是否真实出现必须以返回原文和详情为准。

若任一块命中≥5,000条，或显示10,000条上限：

1. 不把该批结果直接并入候选池，也不以命中数作统计结论；
2. 查看前5-10篇，记录主要噪声类型；
3. 从F1-Fn中选择一个能排除该噪声的必要/区别特征，以独立 AND 块加入；
4. 优先同时采用准确下位IPC或精确关系短语；
5. 只执行一条规划好的收窄式，记录收窄前后命中数和抽样相关性。

高精度块目标约20-500条；发现型块目标约100-2,000条。目标区间用于控制核对规模，不替代检索饱和和法律判断。

每轮必须记录前10篇H/M/N/D比例。命中数合适但前20无X时，先从H/M结果提取真实术语、下位IPC、申请人和引证线索，再更换特征组合；不得只继续向原式末尾叠加关键词。

## 4. 日期适格性

每篇候选至少记录：最早优先权日、申请日、公开日、与关键日期的关系。区分：

- 关键日期前公开的普通现有技术候选；
- 关键日期前申请但之后公开、可能涉及抵触申请的候选；
- 关键日期后公开，仅用于了解技术或撰写策略，不能直接作为普通现有技术结论依据；
- 日期缺失或来源不可靠，待官方复核。

## 5. 同族聚合与中止

优先按最早优先权/同族标识聚合。若只有 `family_count` 而无成员清单，不得宣称完成同族去重。

满足以下条件才可初步中止：

- 每个必要特征和核心组合至少有一个检索块；
- 已覆盖准确下位分类及至少一个上位/相邻分类切角；
- 已检查关键候选的后续页或扩展线索；
- 连续两轮或两页没有出现新的关键分类、术语、申请人或高覆盖文献；
- 报告清楚列明未覆盖的库和文献类型。

固定 Top 20/30 不能作为中止标准。

## 6. 单篇文献披露表

| 特征 | 原文位置 | 原文要点 | 明确/隐含 | 日期适格 | 可信度 |
|---|---|---|---|---|---|
| F1 | 权1/段[0032]/图2 | … | 明确 | 是 | 高 |

新颖性使用单独对比：只有同一适格文献公开全部必要特征及其必要关系时，才报告“发现可能破坏新颖性的文献”。披露在实施例或附图中不因位置而机械降权，关键是是否构成可理解、可实施的公开。

## 7. 创造性分析

针对拟议权利要求整体执行：

1. 选择与技术问题相关、整体最接近的现有技术，不只按共有词数量。
2. 确定区别特征及其在本方案中的技术效果。
3. 客观表述实际解决的技术问题，不把区别特征或答案写进问题。
4. 检查其他文献、公知常识或领域知识是否给出结合启示，同时记录反向教导、技术偏见、预料不到效果和组合障碍。
5. 公知常识必须说明证据来源；不能由模型自行断言。

可以把特征标成“已见/待证/未见”用于沟通，但不得用 A/B/C 单特征等级代替整体创造性判断。

## 8. 输出口径

使用以下结论之一：

- “发现一篇可能影响新颖性的文献，需代理人复核披露与日期”；
- “未发现单篇文献公开全部必要特征，但发现以下创造性组合风险”；
- “在本次范围内未发现；由于[未覆盖项]，不能据此保证新颖性或授权前景”。

报告必须附检索日期、数据库、市场、语言、全部检索式、候选排除理由、证据位置和局限。

### 申请交底与撰写支持

申请前查新报告把三类内容分开：

1. **现有技术证据**：适格文献实际公开的特征、关系、参数和位置；
2. **发明人待确认问题**：针对未观察或表达不清的必要特征，询问具体结构、失效状态、控制逻辑、参数依据、实验效果和替代实施方式；
3. **撰写选项**：仅基于发明人已确认的自身方案组织独立/从属层次，不复制候选权利要求，也不把“检索未见”自动写成区别特征。

全要素Bool式即使命中数处于20—500条，若跨页抽样中任一必要条件可观察率低于50%或没有单篇完整覆盖，仍判定该式“约束无效/未形成X候选”，不能把命中量当作组合已被检索。针对缺失特征单独执行QY-Comp、语义、分类和相邻领域检索；连续两个独立角度仍无高覆盖候选时记录“本次范围未见”，不得改写为“该特征具有新颖性”。

输出交底补强问题时，每个问题必须关联`F编号 + 候选文献/缺口 + 回答将影响的权利要求层级`。没有发明人确认的推测性结构只列问题，不进入拟议权利要求。
