# 专利全景分析与FTO评估方法论

## 一、专利全景扫描方法论

### 1.1 核心专利分类体系

| 专利类型 | 保护对象 | 典型保护期限 | 保护强度 | 常见挑战 |
|---------|---------|------------|---------|---------|
| **化合物专利** | 活性分子结构（通式/具体化合物） | 20年（自申请日） | ★★★★★ | 先导化合物优化规避 |
| **盐/酯/前药专利** | 药学上可接受的盐/酯/前药 | 20年 | ★★★★☆ | 现有技术覆盖 |
| **晶型专利** | 特定晶型/溶剂合物/水合物 | 20年 | ★★★★☆ | 多晶型现象/新颖性 |
| **制剂组成专利** | 配方、辅料组合 | 20年 | ★★★★☆ | 公知辅料选择 |
| **方法/工艺专利** | 合成方法、制备工艺 | 20年 | ★★★☆☆ | 替代工艺路线 |
| **用途专利** | 新适应症、给药方案 | 20年 | ★★★★☆ | 医学实践例外 |
| **给药装置专利** | 注射器、吸入器、植入系统 | 20年 | ★★★★★ | 替代设计方案 |
| **联合用药专利** | 固定剂量复方或联合方案 | 20年 | ★★★☆☆ | 替代组合 |
| **生物标志物专利** | 伴随诊断、患者分层 | 20年 | ★★★★☆ | 自然产物例外 |
| **手性专利** | 对映体/非对映体 | 20年 | ★★★★☆ | 消旋体拆分策略 |

### 1.2 专利族图谱构建方法

```
优先权文档（Priority）
  ├── PCT申请（12个月内）
  │   ├── US进入国家阶段（30个月）
  │   ├── EP进入国家阶段（31个月）
  │   ├── CN进入国家阶段（31个月）
  │   └── JP进入国家阶段（31个月）
  ├── 继续申请（US：Continuation / Continuation-in-Part）
  │   └── 分案申请（各国的Divisional）
  └── 后续改进申请
      ├── 新晶型专利
      ├── 新制剂专利
      └── 新适应症专利
```

### 1.3 专利到期时间线模板

| 年份 | 到期专利 | 专利类型 | 影响评估 |
|------|---------|---------|---------|
| YYYY | US XXXXXXX（化合物） | 核心化合物 | ⚠️ 专利悬崖 |
| YYYY+2 | EP XXXXXXX（晶型） | 晶型 | 中等影响 |
| YYYY+3 | CN XXXXXXX（制剂） | 制剂组成 | 较小影响 |
| YYYY+5 | US XXXXXXX（新适应症） | 用途 | 竞争缓冲 |

### 1.4 关键保护期限计算要素

- **基本保护期**：自申请日起20年
- **PTE（Patent Term Extension）**：美国因FDA审批延迟的专利期延展（Hatch-Waxman Act，最长5年，延展后不超过14年）
- **SPC（Supplementary Protection Certificate）**：欧洲因EMA审批延迟的保护期补充（最长5年）
- **中国专利期限补偿**：自2021年6月1日起适用新专利法，因新药审批延迟可获最多5年补偿
- **数据独占期**：中国市场（创新药6年/儿童药12个月）、美国（NCE 5年/孤儿药7年）

## 二、FTO（Freedom to Operate）分析标准流程

### 2.1 FTO分析步骤

```
步骤1：界定FTO范围
  → 明确目标产品/工艺/服务的具体技术特征
  → 界定目标地域（中国/美国/全球）
  → 界定目标行为（制造/使用/销售/进口）

步骤2：专利检索
  → 关键词检索（技术术语 + 同义词 + 中英文）
  → 分类号检索（IPC/CPC分类号）
  → 重点专利权人检索（竞品企业专利组合）
  → 时间范围：近20年有效专利

步骤3：筛选相关专利
  → 初筛：标题+摘要相关性
  → 精筛：权利要求逐条比对
  → 高价值专利：授权且有效的核心专利

步骤4：权利要求比对（Claim Chart）
  → 权利要求解构（分解为技术特征要素）
  → 逐一比对目标产品特征
  → 判定：字面侵权（Literal Infringement）/ 等同侵权（Doctrine of Equivalents）/ 不侵权

步骤5：风险评估与建议
  → 高风险专利列表及应对策略
  → 回避设计方案
  → 无效挑战可行性
  → 综合风险评级
```

### 2.2 权利要求比对表（Claim Chart）模板

| 权利要求要素 | 目标产品特征 | 是否覆盖 | 侵权判定 |
|------------|------------|---------|---------|
| Element 1: 化合物A | 目标产品含有化合物A | ✅ 是 | — |
| Element 2: 含有辅料X | 目标产品含有辅料Y（结构相似） | ≈ 类似 | 等同原则 |
| Element 3: 剂量为X-Y mg | 目标产品剂量为Z mg（超出范围） | ❌ 否 | — |
| **综合判定** | — | — | **低风险** |

### 2.3 风险评级标准

| 风险等级 | 判定标准 | 建议行动 |
|---------|---------|---------|
| 🔴 高风险 | 目标产品落入有效专利权利要求字面范围 | 必须回避设计/许可/无效挑战，不可直接上市 |
| 🟡 中风险 | 存在等同侵权可能（1-2个特征类似） | 建议寻求法律意见，准备回避方案 |
| 🟢 低风险 | 未落入权利要求范围或专利可能被无效 | 可正常推进，持续监控 |

### 2.4 应急响应SOP（收到侵权指控后）

```
T+0：收到律师函/诉讼通知
  → 立即转交公司法务/外部IP律师
  → 停止相关宣传和商业化行为（如需要）
  → 启动专利无效检索（72小时内启动）

T+7天：初步评估
  → 评估对方专利有效性（prior art检索）
  → 评估自身不侵权论点（Claim Chart反驳）
  → 评估回避设计可行性

T+30天：策略制定
  → 制定应对方案（无效/回避/许可/诉讼）
  → 评估各方案成本与风险
  → 提交管理层决策

T+90天：方案执行
  → 执行选定策略
  → 持续监控对方后续动作
```
