## 2. 字体与排版系统 (Typography & Layout)

大成品牌字体兼具传统律所的尊贵感与现代专业机构的清晰度。在 PPT 制作中，应采用双字体搭配策略。

### 2.1 字体选择
- **标题字体（中文）**：**思源宋体 (Source Han Serif CN)**
  - *字重推荐*：大标题使用 `Bold` 或 `Heavy`，小标题使用 `Medium`。
  - *设计意图*：宋体字形端庄、典雅，体现律师事务所的严谨、权威与深厚底蕴。
- **正文字体（中文）**：**思源黑体 (Source Han Sans CN)** 或 **微软雅黑**
  - *字重推荐*：正文使用 `Regular` 或 `Normal`，重点强调使用 `Medium`。
  - *设计意图*：黑体字形现代、易读性高，适合大段文字和数据的清晰呈现。
- **英文字体**：与中文保持一致，标题使用 **Source Han Serif**，正文使用 **Source Han Sans** 或 **Arial**。

### 2.2 四级字号层级体系与自适应算法 (Typography Hierarchy)

大成 PPT 必须建立清晰的四级字号层级，确保视觉层次分明。各级字号必须严格遵守以下规则，严禁随意调整。

#### 标准内容页四级字号层级（L1 - L4）

| 层级 | 名称 | 字号 | 计算方式 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **L1** | **页面标题** | **24 pt** | 全局硬性固定 | 内容页页面标题，跨页面绝对统一 |
| **L2** | **区块大标题** | **18 pt** | 全局硬性固定 | 卡片标题、区块标题、左右栏标题 |
| **L3** | **正文内容** | **自适应，上限 16 pt** | fit_pt(75%)，平行取最小值 | 卡片正文、段落说明 |
| **L4** | **附注/说明** | **11 pt** | 全局硬性固定 | 法条引用、页脚信息、辅助说明 |

#### 封面/目录/过渡页独立字号规范（硬性固定）

对于非标准内容页，必须使用以下独立字号规范，以保证页面饱满、大气：

| 页面类型 | 元素名称 | 硬性固定字号 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **封面页** | 主标题 | **44 - 46 pt** | 封面最核心的中文标题（允许自适应） |
| **封面页** | 英文副标题 | **16 pt** | 封面主标题下方的英文翻译 |
| **封面页** | 汇报信息 | **14 - 15 pt** | 汇报人、时间等基本信息 |
| **目录页** | CONTENTS | **30 pt** | 目录页左侧装饰英文标题 |
| **目录页** | 目录条目主标题 | **20 pt** | 目录中每个章节的主标题 |
| **目录页** | 目录条目副标题 | **13 pt** | 目录中每个章节的简要说明 |
| **过渡页** | 章节大序号 | **80 pt** | 过渡页中巨大的装饰数字（如 01） |
| **过渡页** | 章节主标题 | **56 pt** | 过渡页中的章节名称（如 引言） |
| **过渡页** | 章节说明 | **20 pt** | 过渡页中对本章节内容的简要描述 |

#### 容器与序号排版规范

- **序号容器双向居中**：当数字或字母序号外面有容器（如色块、圆形）时，**文字必须在容器内实现水平和垂直方向的双向绝对居中**。
  - *实现方法*：设置文本框的 `vertical_anchor` 为 `MIDDLE`，且段落对齐方式 `alignment` 设置为 `CENTER`。
- **竖向分割线严格不溢出**：在绘制多行列表前的竖向装饰条或分割线时，其起止点必须精确匹配内容，严禁超出外部卡片容器的上下边界。
  - *实现方法*：使用 python-pptx 的 `add_connector(MSO_CONNECTOR.STRAIGHT)` 绘制精确线段，或将矩形高度严格绑定为标题高度与正文高度之和。

> **层级差异规则**：L1(24pt) − L2(18pt) = 6pt；L2(18pt) − L3上限(16pt) ≥ 2pt；L3 − L4(11pt) ≥ 3pt。必须保证每级之间具有明显的视觉差异。

#### 自适应字号核心算法实现
通过 Python-pptx 制作或美化 PPT 时，应调用以下算法计算最佳字号：

```python
from PIL import ImageFont
import os

def fit_font_size(text: str, box_w_inch: float, box_h_inch: float,
                  target_ratio: float = 0.75, min_pt: float = 7, max_pt: float = 80,
                  pad_ratio: float = 0.06) -> float:
    """
    计算最佳字号，使文字实际渲染面积占容器可用面积的 target_ratio 左右。
    """
    # 转换为 96 DPI 下的像素尺寸
    uw = (box_w_inch * (1 - pad_ratio * 2)) * 96
    uh = (box_h_inch * (1 - pad_ratio * 2)) * 96
    target_area = uw * uh * target_ratio

    # 二分搜索字号
    lo, hi, best = min_pt, max_pt, min_pt
    for _ in range(25):
        mid = (lo + hi) / 2
        # 测量 mid 字号下自动换行后的实际宽高
        tw, th = measure_text_px(text, mid, int(uw))
        if th > uh:  # 超出容器高度，必须缩小
            hi = mid
        elif tw * th <= target_area:
            best = mid
            lo = mid
        else:
            hi = mid
    return round(best, 1)
```

#### 平行容器字号统一规则（硬性规范）

同一组平行容器（如同一行的多张卡片）内，**同类文字元素（标题对标题、正文对正文）的字号必须完全一致**，不允许各自独立计算后出现大小不一的情况。

正确做法：先对该组所有容器分别调用 `fit_font_size` 计算各自的最优字号，然后取**所有结果中的最小值**作为统一字号，再统一应用到每个容器中。

```python
# 正确示例：平行四栏卡片正文字号统一
body_texts = [card["body"] for card in cards]
body_pts = [fit_font_size(t, card_w_inch, body_h_inch) for t in body_texts]
unified_pt = min(body_pts)  # 取最小值，保证最长文字也不溢出
for card in cards:
    add_textbox(..., font_size=unified_pt)  # 所有卡片使用同一字号
```

## 3. 典型页面版式设计 (Slide Layouts)

大成 PPT 的版式应当克制、留白充足，避免过度装饰。以下是四种核心页面的设计模版规范：

### 3.1 封面页 (Title Slide)
- **极简深底版（推荐，最显尊贵）**：
  - **背景**：纯黑 (#1A1A1A) 或大成深紫 (#6B2D8B) 纯色背景。
  - **主标题**：思源宋体 Bold，白色，居中或靠左。
  - **副标题**：思源黑体 Regular，米金 (#F5E6C8)，字号为主标题的 1/2。
  - **装饰**：在左侧或顶部边缘，可使用一条极细的米金色装饰线（1-2pt）。

### 3.2 目录页与过渡页 (Agenda & Transition Slide)
- **背景**：采用极浅灰 (#F8F8F8) 或纯白 (#FFFFFF)。
- **版式**：
  - 左侧为大成深紫 (#6B2D8B) 的宽色块，内嵌白色“CONTENTS”或章节序号（如 “01”）。
  - 右侧为具体的目录列表，序号使用大成深紫，文字使用纯黑，采用思源宋体。

### 3.3 标准内容页 (Content Slide)
- **背景**：纯白 (#FFFFFF)。
- **硬性位置与尺寸规范 (Hard Layout Constraints)**：
  - **页面标题 (Slide Title)**：每一页标题的位置、大小和字号必须保持全局绝对一致（除封面、目录/过渡页、总结封底页外），严禁动态计算。
    - *硬性位置*：左上角 `Left: 0.83" (2.11 cm)`, `Top: 0.42" (1.07 cm)`，`Width: 11.67" (29.64 cm)`, `Height: 0.75" (1.91 cm)`。
    - *硬性字号*：**全局固定 24.0 pt**（确保即使是最长标题也能在单行内完美容纳，同时在所有页面间保持绝对统一的视觉锚点）。
    - *字体与颜色*：大成深紫 (`#6B2D8B`)，思源宋体 Bold。
  - **页脚 (Footer)**：每一页页脚的位置、大小和规范必须完全一致。
    - *硬性位置*：`Left: 0.83"`, `Top: 7.05"`, `Width: 11.67"`, `Height: 0.3"`。
    - *内容*：大成律师事务所（左侧对齐），页码（右侧对齐），字号 `11pt`，中灰 (`#808080`)。
    - **严禁在任何页面上添加 Logo 图标或文字**。
  - **分割线**：标题下方配有一条极细的浅灰色 (#E0E0E0) 分割线，位置保持一致。
- **内容区**：
  - 采用**两栏**或**三栏**网格布局。
  - 重点内容或结论性文字，可使用薰衣草浅紫 (#F5EDFC) 作为底色块进行封装，四周留出足够的内边距。

### 3.4 封底页 (Ending Slide)
- **背景**：与封面页保持一致，采用深色底。
- **文字**：
  - 居中书写“谢谢！”或“致谢”，使用思源宋体 Bold，白色。
  - 下方可使用较小字号书写大成律所的 Slogan：“**全球资源 本土智慧**”（米金色）。

## 4. 图表与表格规范 (Charts & Tables)

### 4.1 表格设计
表格应体现专业数据分析的严谨性，严禁使用 PPT 默认的刺眼配色表格：
- **表头**：大成深紫 (#6B2D8B) 背景，白色文字，居中对齐。
- **斑马线**：奇数行使用白色背景，偶数行使用极浅灰色 (#F8F8F8) 或薰衣草浅紫 (#F5EDFC) 背景。
- **边框**：仅保留横向边框（使用浅灰色 #E0E0E0），取消所有竖向边框，使表格视觉上更轻盈。

### 4.2 数据图表（柱状图、折线图、饼图等）
- **配色顺序**：大成深紫 (#6B2D8B) -> 大成亮紫 (#8B2FC9) -> 大成米金 (#F5E6C8) -> 深灰 (#404040)。
- **图表背景**：一律透明或纯白，无边框。
- **网格线**：使用极淡的灰色，或直接隐藏。

## 5. 页面元素与装饰规范 (Elements & UI)

- **按钮与标签**：
  - 核心标签使用大成深紫 (#6B2D8B) 实色填充，白色文字，微圆角（角半径约 4-6px）。
  - 辅助标签使用大成深紫线框，紫色文字。
- **图标 (Icons)**：
  - 一页 PPT 内的图标必须风格统一（统一为线性线框风格或扁平单色风格）。
  - 图标颜色应统一为大成深紫 (#6B2D8B) 或深灰 (#404040)。
- **严禁使用的元素**：
  - 严禁使用任何高饱和度的红、绿、蓝等非品牌色（除非用于特定法律合规红线警示，此时应使用克制的暗红色）。
  - 严禁使用复杂的渐变色、3D 阴影或浮雕效果。
  - 严禁使用花哨的页面切换动画和声音效果。
