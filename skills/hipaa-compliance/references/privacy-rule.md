## 1. 适用性与范围

**受隐私规则约束的涵盖实体（CE）：**
- 健康计划（保险公司、HMO、50 名以上参与者的雇主资助计划）
- 医疗保健结算所
- 以电子方式传输健康信息的医疗保健提供者

**业务伙伴（BA）：**
- 代表 CE 创建、接收、维护或传输 PHI 的实体
- 在共享 PHI 之前必须签署**业务伙伴协议（BAA）**
- 受《安全规则》约束；《隐私规则》的部分内容通过 BAA 适用

**PHI 定义**（§164.501）：
受保护健康信息（Protected Health Information）= 符合以下条件的健康信息：
- 由 CE/BA 创建或接收
- 与过去/现在/未来的身体或心理健康状况、医疗保健提供或付款有关
- 能够识别或合理可能识别个人身份

**不适用：**
- 以雇主身份行事的雇主
- 人寿保险公司（除非同时也是健康计划）
- 工伤赔偿承保人（在大多数州，不直接受 HIPAA 约束）
- 教育记录（改用 FERPA）

## 2. 使用与披露——一般规则

### 一般禁止（§164.502(a)）
CE/BA 不得使用或披露 PHI，但《隐私规则》允许或要求的除外。

### 必须披露的情形（§164.502(a)(2)）
- 向**个人本人**（应访问或会计请求）
- 向**HHS**（用于合规调查/执法）

### 同意 vs 授权 vs 协议
| 机制 | 何时要求 | 备注 |
|-----------|--------------|-------|
| 书面授权 | 超出 TPO 的使用/披露、营销、出售 PHI | 必须满足 §164.508 要求 |
| 同意/反对的机会 | 设施名录、向参与护理的家庭成员/朋友披露 | 非正式；口头亦可 |
| 无需许可 | TPO、公共卫生、执法（有限）等 | 见 §164.512 |

## 3. 无需授权的允许使用

### 治疗、付款、运营（TPO）（§164.506）
- **治疗**：提供、协调、管理医疗保健
- **付款**：计费、理赔处理、使用审查
- **运营**：质量评估、培训、审计、法律、业务规划

### 其他允许的披露（§164.512）
| 目的 | 要求 |
|---------|-------------|
| 公共卫生（§164.512(b)） | 向获授权的公共卫生机构 |
| 虐待/忽视报告（§164.512(c)） | 向获授权接收的政府机关 |
| 健康监督（§164.512(d)） | 监督机构的审计、检查、执照 |
| 司法/行政（§164.512(e)） | 法院命令或传票并附令人满意的保证 |
| 执法（§164.512(f)） | 有限；适用特定条件（如法院命令、场所内犯罪） |
| 研究（§164.512(i)） | 经 IRB/隐私委员会豁免或个人授权 |
| 严重威胁（§164.512(j)） | 为防止对个人或他人造成迫在眉睫的严重伤害 |
| 工伤赔偿（§164.512(l)） | 依工伤赔偿法律授权 |
| 死者（§164.512(g)） | 向验尸官、法医、殡葬从业者 |
| 有限数据集（§164.514(e)） | 去除直接标识符；要求《数据使用协议》（DUA） |

### 附带披露（§164.502(a)(1)(iii)）
满足以下条件时允许：
- 已采取合理保障措施
- 满足最低必要标准
- 示例：患者在候诊室听到另一名患者的对话

## 4. 患者权利

### 访问权（§164.524）
- 个人有权检查并获得其在**指定记录集**中 PHI 的副本
- **时限**：在 **30 天**内提供访问（允许一次 30 天延期，须书面通知）
- **格式**：如易于生成，必须以请求的格式提供；如请求，以电子格式提供
- **费用**：可以收取合理、基于成本的费用（仅人工 + 耗材 + 邮费）；不得收取检索费
- **拒绝**：心理治疗记录、为法律程序汇编的信息、可能危及生命/安全的 PHI 可以拒绝；部分拒绝可申请复核

> **2021 年规则更新**：HHS 强调费用必须限于成本；EHR 患者门户访问必须免费。

### 修正权（§164.526）
- 个人可以请求修正其在指定记录集中的 PHI
- **时限**：60 天内处理（允许一次 60 天延期）
- 在以下情况下可以拒绝：CE 未创建该记录；记录准确且完整；不属于指定记录集

### 披露会计权（§164.528）
- 有权获得此前 6 年披露的清单
- **排除**：TPO 披露、向本人披露、经授权的披露、附带披露、国家安全
- **时限**：60 天（允许一次 60 天延期）

### 请求限制的权利（§164.522(a)）
- 个人可以请求限制 TPO 或向家人/朋友的使用/披露
- CE **没有义务**同意——**但**：必须尊重对健康计划披露的限制，如果服务系自费全额支付

### 保密通信权（§164.522(b)）
- 个人可以请求以替代方式或地点进行通信
- CE 必须满足**合理请求**；个人无需说明理由
- 如个人声明披露可能危及自身，健康计划必须满足

### 通知权（§164.520）
- 有权收到《隐私实践通知》（见第 5 节）

### 退出筹款的权利（§164.514(f)）
- 每份筹款通信中必须包含退出机制

## 5. 隐私实践通知（NPP）

### 要求：所有涵盖实体（不含 BA）

### 必须提供（§164.520(c)）：
- 首次提供服务时（当面）
- 应请求
- 在 CE 的网站上（如存在）
- 健康计划：投保时，如有重大变更则每 3 年

### NPP 的必需内容（§164.520(b)）：
1. **标题**："本通知说明您的医疗信息可能被使用和披露的方式以及您如何获得对这些信息的访问。请仔细阅读。"
2. 说明 CE 可能使用/披露 PHI 的方式（附 TPO 和其他示例）
3. 说明需要授权的其他使用
4. 个人权利（访问、修正、会计、限制、保密通信、退出筹款）
5. CE 的义务（维护隐私、通知泄露、遵守 NPP）
6. 如何投诉（向 CE 和 HHS；禁止报复）
7. 更多信息的联系人/部门
8. 生效日期

### 电子 NPP：
- 如个人同意，可以电子方式提供
- 必须使用通俗语言

## 6. 最低必要标准

### 规则（§164.502(b)、§164.514(d)）：
使用或披露 PHI，或向另一 CE 请求 PHI 时，应作出合理努力，将 PHI 限制在实现预期目的所需的**最低必要**范围内。

### 适用于：
- 常规披露 → 制定识别需要访问的人员 + PHI 类型的政策
- 非常规披露 → 逐案审查
- 向他人提出的请求 → 将请求限制在最低必要范围

### 不适用于：
- 向治疗提供者的披露或治疗提供者的请求
- 向个人本人的披露
- 依据个人授权
- 法律要求
- 用于 HHS 合规活动

### 实务实施：
- EHR 系统中基于角色的访问控制
- 对工作人员的按需知悉培训
- 在不需要完整 PHI 时对数据进行去标识化

## 7. 授权要求

### 何时需要（§164.508）：
- 大多数未被 TPO 或 §164.512 允许披露涵盖的使用/披露
- **始终需要**：心理治疗记录（例外有限）、涉及财务报酬的营销、出售 PHI

### 有效授权必须包含（§164.508(c)）：
1. 拟使用/披露的 PHI 说明（具体、有意义）
2. 获授权作出披露的人的名称/类别
3. 可向其披露的人的名称/类别
4. 使用/披露各项目的的说明
5. 有效期届满日期或事件
6. 个人签名和日期
7. 如由个人代表签署：权限说明
8. 声明个人可以撤销
9. 关于再披露风险的声明（如适用）
10. 附带条件声明（如授权以治疗/付款为条件）

### 缺陷授权（§164.508(b)(2)）：
授权在以下情况下有缺陷：
- 有效期已过
- 未完整填写
- CE 知道其已被撤销
- 在不允许时构成合并授权（与另一文件合并）

## 8. PHI 的特殊类别

以下类别受到**加强保护**（通常州法亦如此）：

| 类别 | 备注 |
|----------|-------|
| **心理治疗记录** | 单独存放；几乎所有使用/披露都需要特定授权 |
| **HIV/AIDS 信息** | 大多数州在 HIPAA 之外还有额外限制 |
| **物质使用障碍**（42 CFR Part 2） | 独立的联邦法律，规则比 HIPAA 更严格 |
| **精神健康记录** | 州法通常增加限制 |
| **生殖健康** | Dobbs 案后指引；HHS 发布规则限制对合法生殖保健的披露 |
| **遗传信息**（GINA） | 健康计划不得用于核保 |
| **未成年人** | 一般而言父母是个人代表；已解除监护的未成年人和敏感服务有例外 |

> **重要**：州法律可以比 HIPAA 更具保护性。HIPAA 设定最低标准。始终核查州法律。

## 9. 行政要求

### 政策与程序（§164.530(i)）：
- 必须实施符合《隐私规则》的书面政策和程序
- 必须记录政策；自创建或最后生效之日起保存 6 年

### 工作人员培训（§164.530(b)）：
- 培训所有工作人员成员了解其履行职责所需的隐私政策
- 新成员加入后在合理时间内接受培训
- 记录培训情况

### 制裁（§164.530(e)）：
- 对违反隐私政策的工作人员成员实施适当制裁
- 记录制裁情况

### 投诉程序（§164.530(d)）：
- 为个人提供投诉程序
- 记录所有投诉及其处理结果

### 隐私官（§164.530(a)）：
- 指定负责制定和实施政策的隐私官
- 指定接收投诉的联系人

### 禁止报复（§164.530(g)）：
- 不得因个人行使 HIPAA 权利而对其进行报复
- 不得因工作人员成员提出投诉或参与调查而对其进行报复

### 禁止放弃权利（§164.530(h)）：
- 不得要求个人以放弃 HIPAA 权利作为治疗/付款/投保的条件

## 10. 营销与筹款

### 营销定义（§164.501）：
鼓励接收者购买或使用产品或服务的、关于产品或服务的通信。

### 营销需要授权，但以下除外：
- 与个人的面对面沟通
- 价值名义的促销礼品
- 补药提醒（如财务报酬与 CE 成本合理相关）
- 关于 CE 提供的健康相关产品或服务的通信（自有服务、治疗替代方案、个案管理）——如无第三方财务报酬

### 出售 PHI（§164.502(a)(5)(ii)）：
- 未经授权一般禁止
- 例外：公共卫生、研究、治疗、业务出售/合并、BAA、向个人提供访问

### 筹款（§164.514(f)）：
- 可以不经授权使用人口统计信息 + 服务日期
- 每份通信中必须包含退出机制
- 不得以捐款作为治疗的条件
