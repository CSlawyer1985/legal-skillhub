#差旅费报销单自动生成方案｜我把经验做成了一个AI技能包

我是江澜，一名律师助理。

团队律师常出差办案，差旅费由当事人**实报实销**。案子结完后，要把所有行程开销整理成报销文档给客户看——既要真实可信，又要一目了然。

以前只能靠手动：截图一张张看、时间一条条对、金额一个个加，再复制粘贴到Word和Excel。

后来我把自己这套流程做成了 AI 技能包。

## 它能做什么

你只需要把行程截图按案件分文件夹放好——高铁票、打车记录、酒店账单、飞机行程单都可以。如果文件夹里还有之前整理好的Word报销文档，AI会自动提取里面的截图一起合并。交给AI后自动完成：

- ✅ **扫描文件夹内所有资料**（图片、Word文档、Excel等），不遗漏任何凭证来源
- ✅ 如有Word文档（.docx），自动提取内嵌截图并读取
- ✅ **同一案件多批次行程自动合并汇总**（如1月+7月出差合并为一份报销单）
- ✅ 逐张读取截图，提取日期/时间/起终点/金额/车次信息
- ✅ 按时间顺序排序编号，自动发现异常并提醒确认
- ✅ 生成 **Word报销单**（明细表 + 预支凭证 + 原始凭证附件，带页脚页码）
- ✅ 生成 **Excel明细表**（含预支 / 实际 / 补交 / 退还费用结算区）
- ✅ 文件名自动包含核心金额数据

## 效果

最终生成的报销文档如下：
- 自动从截图提取信息，按时间排序编号
- 生成带页脚页码的Word报销单（明细表→预支凭证→原始凭证，附件顺序清晰）
- 生成带费用结算区的Excel明细表
- 文件名自动包含预支/实际/补交/退还金额

给客户看的时候，一份文档里行程明细、原始凭证、费用结算全在一起。客户一看就清楚，不需要额外解释。

## 谁适合用

- 在律所做助理，经常要帮律师整理差旅费
- 需要给当事人做报销单，想做得专业又省时间
- 经常出差、需要整理差旅费实报实销的，不限于律师等职业

### 手动使用

如果你习惯自己操作，也可以手动运行：

1. 安装依赖：
   ```bash
   npm install docx
   pip install openpyxl Pillow
   ```
2. 扫描文件夹内所有文件（自动分类+提示哪些需要提取截图）：
   ```bash
   python scan_folder.py "文件夹路径"
   ```
3. 如文件夹内有Word文档，提取内嵌截图（scan_folder.py会自动调用，也可手动运行）：
   ```bash
   python extract_docx_images.py "已有文档.docx" --output images/案件简称/docx_extracted/
   ```
4. 按模板编辑 `expense_data_template.json`
5. 校验数据（推荐）：`python validate_data.py`
6. 生成Word报销单：`node generate_docs.js`
7. 生成Excel明细表：`python generate_excel.py`

## 文件说明

| 文件 | 说明 |
|------|------|
| `SKILL.md` | AI agent的操作说明书（告诉AI怎么一步步完成报销单生成） |
| `scan_folder.py` | 文件夹扫描程序（Python）——自动扫描文件夹内所有文件，按类型分类并提示哪些需要提取截图 |
| `generate_docs.js` | Word 报销单生成程序（Node.js） |
| `generate_excel.py` | Excel 明细表生成程序（Python） |
| `validate_data.py` | 数据校验程序（Python）——生成前检查数据完整性，按截图分组复核防止日期填错 |
| `extract_docx_images.py` | Word文档内嵌图片提取程序（Python）——从已有报销文档中提取截图，避免遗漏凭证 |
| `expense_data_template.json` | 数据结构模板（手动使用时按此编辑） |
| `package.json` | Node.js 依赖声明（`npm install` 自动安装 docx） |
| `README.md` | 本文件——项目介绍和使用说明 |
