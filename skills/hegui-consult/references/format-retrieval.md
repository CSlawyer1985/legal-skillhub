# 公告格式补取契约

查询法规后，**根据法规返回 JSON 的内容**判断本次事项是否需要一份正式「公告格式」（交易所规定的公告编制模板），需要则补取，并在答复中给出格式文件与可下载附件。公告格式是「怎么写这份公告」的模板，区别于「公告参考案例」（别人怎么披露的实践）。

## 一、何时补取（触发条件）

首次法规调用完成后，优先读结构化信号 `regulation_search.query_plan`/`regulations[].coverage`/`quality.answerability.format`，辅以 `regulations[].excerpt` 语义(**不扫描 draft_answer**)，满足**任一**即补取：

1. **法规正文指向格式**：某条 `excerpt`（或正文）出现指向规范格式的表述，例如：
   - “公告格式”“本所制定的公告格式”“本所公告格式”；
   - “按照……格式予以披露”“参照……格式编制”“依照……格式编制并披露”；
   - “编制指引”“格式指引”“公告格式模板”。
   （典型：上市规则常写“重大事项公告应当按照……本所制定的公告格式予以披露”。）
2. **事项本身是“发布/披露一份公告”**：某披露子问题为 `required`，或 `conditional` 且用户事实已满足触发条件，用户实际要出具该公告——此时即便正文没写“格式”二字，也需要给出对应的公告格式模板。

**不要补取**的情形：

- 纯任职资格 / 程序 / 时效 / 一般合规子问题，且不涉及出具某份公告；
- 首次调用返回的 `query_plan` 已含 `format` plan（即用户本就直接在问格式，格式文件已在首次结果里，无需再调）；
- 披露子问题为 `unknown`（没检索到披露条款）——先按主流程补问，不要用格式文件反推披露义务。

## 二、如何补取（follow-up 调用）

再次调用 `hegui_consult`，**查询词必须含格式类词**（“公告格式”或“格式模板”）以命中服务端 `format` 召回：

```json
{
  "query": "<板块> <公告类型/核心事件> 公告格式",
  "bankuai": ["<用户板块>"],
  "effective_status": [1, 2],
  "search_announcements": false,
  "strict": false,
  "regulation_limit": 5,
  "regulation_detail_count": 3
}
```

- `<公告类型/核心事件>` 用具体事项收窄，如“关联交易 公告格式”“对外担保 公告格式”“股东大会通知 公告格式”；拿不准时用“<板块> 公告格式”。
- 保持 `search_announcements:false`（格式是法规侧材料，与公告案例无关）。
- 服务端会返回 `query_plan=[format]`、`quality.answerability.format`，命中的格式文件 `coverage` 含 `"format"`。

## 三、采信闸门

只采用同时满足的格式文件：

- `applicability.passed=true` 且板块与用户一致（服务端已剔全国股转/银行保险/基金/境外及错误交易所）；
- `coverage` 含 `"format"`，或标题即为“……公告格式……”；
- 有可下载的 `pdf`（附件模板地址）。`content_status` 为 `parsed`（正文型 DOCX）或 `attachment_parsed`（发布通知型，服务端 §四 已跟进到交易所官网实际格式文件）均可。

库中检索不到对应板块的现行公告格式时，如实说明“未在库中检索到该板块对应的现行公告格式文件”，**不得凭记忆或联网编造格式条目**。

## 四、板块与格式文件对应（便于核对）

- **深主板 / 创业板** → 深交所《自律监管指南第2号——公告格式》，附件为 DOCX 模板本体（`content_status=parsed`）。
- **沪主板 / 科创板** → 上交所《自律监管指南第1号——公告格式》。库内附件是一份 HTML 发布通知，服务端 §四 已跟进到 `sse.com.cn` 上的实际格式文件并解析（`content_status=attachment_parsed`）；`pdf` 指向发布通知，实际格式文件由服务端解析呈现。
- **北交所** → 北交所《持续监管临时公告格式模板》，附件为 DOCX。

多数交易所公告格式是**分号模板**（第一号购买/出售资产、第X号关联交易、第X号对外担保……）。事项明确时，用 `excerpt`/事项名对应到具体“第几号”，指给用户对应那一份，别只丢整册。

## 五、如何在答复中呈现

在最终答复的「正式法规依据」之后、单列一小节「适用的公告格式」：

```markdown
### 适用的公告格式

依据上述条款，本事项的公告应按交易所规定格式编制：

- 《深圳证券交易所上市公司自律监管指南第2号——公告格式（2026年7月修订）》（深证上〔2026〕920号，现行有效）
  对应模板：第X号 ×××公告
  [下载公告格式模板（DOCX）](附件地址)
```

要点：写清格式文件全名 + 文号 + 生效状态 + 可下载附件地址；能对应到具体“第几号”就指明；说明该格式与前述披露义务的对应关系。格式文件是「按什么模板写」，仍以法规条款作为「要不要披露」的依据，二者不混淆。
