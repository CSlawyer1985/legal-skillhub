# 法规原文完整引用规范（强制执行）

适用于所有涉及法律、行政法规、部门规章、规范性文件、证券交易所业务规则、自律监管指引、公告格式指引及其他监管文件的回答。

**最关键的一条**：`regulations[].excerpt` 是**检索线索**，不是默认可直接引用的法规原文。只有从正式法规原件确认完整条文边界后，才能进入最终回复的原文引用。

## 一、核心原则

凡答复中使用“法规原文”“条款原文”“原文规定”“相关条款如下”等表述，或用 Markdown 引用格式展示法规内容，**必须引用正式法规原件中的完整条文**，不得摘录、缩写、改写或用省略号代替任何内容。无论条文长短，都不得为控制回复长度而删减法规原文。

## 二、“完整条文”的定义

默认以**完整条**为最小引用单位：

1. 从条号及条文标题开始；
2. 引用该条全部正文；
3. 包括该条下的全部款、项、目；
4. 包括前置条件、适用范围、但书、例外、排除情形、计算口径和时限；
5. 直至下一条条号出现前结束。

例如引用“第六条”，应展示完整第六条，不得只摘其中第一款或某一项。

若结论同时依赖被引用条文指向的其他条文（如“按照本规则第10.3.2条规定”“本条第一款规定”“除本办法第十五条规定的情形外”），应继续核验被指向的条文；被指向条文直接影响结论的，也应完整引用。

“完整条文”不是要引用整部法规，只需完整引用与当前法律问题**直接相关**的全部条文。

## 三、禁止行为

严禁：

1. 在法规原文中人为加入“……”“…”“略”“以下省略”“节选”等；
2. 只引用对结论有利的部分，删掉条件、但书、例外或排除规定；
3. 把多个不连续片段拼成一段，让用户误认为连续原文；
4. 修改原文的用词、语序、数字、比例、日期、标点、条号或项号；
5. 把繁体字、异体字、全角标点擅自规范化后仍标注为“原文”；
6. 把模型总结、数据库结构化结论、`draft_answer`、检索摘要或公告案例写成法规原文；
7. 仅凭法规标题或搜索摘录作确定结论；
8. 未取得完整正文却凭模型记忆补写条文；
9. 因条文过长而缩短、概括或省略原文；
10. 用“该条主要规定……”同时把后续概括内容放入原文引用框。

原件本身确实含省略号的，保持原样，可在引用框外注明“省略号为法规原件自带，并非答复删节”。

## 四、法规原文与分析必须分开

- **条款完整原文**：逐字复制正式法规原件，不得加入模型解释；
- **规则概括**：允许用简明语言总结，但必须明确标注“规则概括”，不得放入原文引用框；
- **适用分析**：将用户事实与条款构成要件逐项对应，指明哪些已满足、哪些仍需核实。

不得把规则概括或适用分析包装成法规原文。

## 五、证据来源要求

法规原文只能来自：① hegui MCP 返回的完整数据库正文；② hegui 数据库记录对应的正式 PDF/HTML/DOCX/TXT 原件；③ hegui 返回并解析出的正式附件。

`excerpt` 仅为检索摘录，不当然代表完整条文。`excerpt` 出现下列任一情形时，**不得直接当完整原文引用**，须读原件全文定位完整条文后再引用：

- 从条文中间开始；在条文结束前停止；
- 缺少部分款、项或但书；拼接了多个不连续条文；混入其他章节内容；
- 使用省略号或存在明显截断；没有显示完整条号；无法确认下一条条号位置。

## 六、原件全文核验流程

每次引用法规原文前完成：① 确认法规完整名称；② 正式文号；③ 生效状态；④ 发布/施行日期；⑤ 适用板块与主体；⑥ 在正式原件中定位条号；⑦ 从该条条号开始读取；⑧ 读至下一条条号出现；⑨ 检查是否含全部款、项、但书、例外；⑩ 检查是否存在内部交叉引用；⑪ 与原件逐字核对；⑫ 确认无人工添加省略号后才输出。

## 七、扫描件与 OCR 处理

原件为扫描件、无文字层或只能 OCR 识别时：① 必须查看对应页面原图；② 核对条号、数字、金额、比例、日期、否定词；③ OCR 有错字/乱码/无法确认时，不得标注为准确法规原文；④ 可说明“原件为扫描件，本次未能可靠取得完整原文”；⑤ 不得凭上下文猜测、修补或补写缺失文字；⑥ 经页面原图逐字核对后使用 OCR 文本的，在引用框外标注“以下文字由法规原件扫描页 OCR 识别并经页面核对”。

## 八、无法取得完整原文时的处理

技术故障、附件损坏、扫描件无法识别或数据库只返回不完整摘录时：① 明确说明“本次未能取得足够完整的法规正文”；② 不输出不完整的法规原文；③ 不用省略号掩盖缺失；④ 不凭记忆补写；⑤ 不据此给确定性合规结论；⑥ 可列出已核验的法规名称、文号与材料不足情况。

**“未取得完整正文”不等于“法律没有规定”。**

## 九、固定输出格式

每项法规按此输出：

```markdown
### 《法规完整名称》（正式文号，现行有效）

- 发布日期：
- 施行日期：
- 适用范围：
- 具体条款：
- 法规原文件：

**条款完整原文：**

> 第×条　……
>
> （一）……
>
> （二）……

**规则概括：**

用非引用格式概括该条规则。

**适用分析：**

将用户事实与条款的主体、行为、条件、比例、时限、例外逐项对应。
```

不得在“条款完整原文”引用框内夹入解释、括号备注、加粗提示或人工省略内容。

## 十、回复生成后的强制自检

发送前逐项确认，任何一项不满足即不得输出该段法规原文：

- [ ] 每段法规原文都有完整法规名称和文号；
- [ ] 每段法规原文都有明确条号；
- [ ] 引用从条号开始、到下一条条号前结束；
- [ ] 没有遗漏任何款、项、目；
- [ ] 没有遗漏但书、例外或排除情形；
- [ ] 没有人工加入“……”或其他省略标记；
- [ ] 数字、比例、期限和否定词与原件完全一致；
- [ ] 原文、规则概括、适用分析已分开；
- [ ] 数据库摘录发生截断时已核验正式附件；
- [ ] 无法核验完整原文时，没有作确定性引用或结论。

## 十一、需要同步替换的既有措辞

把“条款原文摘录”“相关原文摘录”“摘录/引用对应条款原文”统一改为：“**条款完整原文**”“逐字引用正式法规原件中的完整条文”“不得使用摘要、截断摘录或省略号代替完整条文”。最终答复不得再把不完整的 `excerpt` 直接作为法规原文展示。
