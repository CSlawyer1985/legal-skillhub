## 能为你做什么（五大重组场景）
---

### 一、破产重整涉税
- 📑 **税收债权梳理**：欠税本金/滞纳金/罚款的债权性质与清偿顺位判定，准确归集税务机关应申报债权
- ⚖️ **重整税务合规计划**：债务豁免所得、债转股、以资抵债等多重组方式组合的纳税义务测算与计税依据确认
- 🔧 **破产程序办税**：管理人实名办税、发票领用开具、破产费用与共益债务税费处理、纳税信用修复与死欠核销流程
- ⚠️ **涉税风险预警**：滞纳金以税款本金为限、受理后滞纳金不属破产债权、重整形成欠税等高频雷区

**典型问法：**
```
"破产企业税收债权清偿顺序怎么排？"
"破产程序中欠税滞纳金如何处理？"
"债务重组所得怎么确认和计税？"
"破产企业纳税信用修复怎么操作？"
```
---

### 二、上市公司重组涉税
- 📋 **重组方案设计**：重大资产重组认定标准、交易结构设计、发行股份定价、支付方式选择
- 🔍 **资产交易合规**：独立财务顾问、审计评估、内幕信息防控、信息披露与审核注册程序
- 💡 **重组税务合规计划**：一般性 vs 特殊性税务处理适用判定、股权/资产收购比例门槛、递延纳税与计税基础延续
- ⚡ **审核提速适配**：分期支付、简易审核程序、锁定期规则等新规要点

**典型问法：**
```
"上市公司重大资产重组基本流程是什么？"
"借壳上市税务处理要点有哪些？"
"上市公司重组特殊性税务处理条件？"
"重组审核简易程序适用哪些情形？"
```
---

### 三、企业分立涉税
- 🧮 **分立税务处理**：一般性 vs 特殊性税务处理适用判定，分立企业计税基础延续、亏损限额结转
- 🏛️ **优惠适用**：分立环节契税免征、土地增值税暂不征收、资金账簿印花税处理
- ⚠️ **风险预警**：股权支付比例不足、原主要股东短期转让、以分立之名转移资产避税被穿透

**典型问法：**
```
"企业分立特殊性税务处理条件是什么？"
"派生分立和存续分立有什么区别？"
"企业分立要交哪些税？"
"分立后原主要股东3年内转让有什么后果？"
```

### 四、企业合并涉税
- 🧮 **合并税务处理**：吸收合并/新设合并、同一控制下合并的税务处理，合并企业计税基础延续
- 📉 **亏损弥补**：被合并企业亏损限额结转测算（按净资产公允价值与国债利率限额）
- 🏛️ **优惠适用**：合并环节契税免征、土地增值税暂不征收

**典型问法：**
```
"企业合并特殊性税务处理条件是什么？"
"同一控制下合并怎么交税？"
"合并企业亏损怎么弥补有限额吗？"

```

### 五、跨境重组涉税
- 🌐 **间接转让穿透**：非居民间接转让中国应税财产的穿透认定与报告义务
- 🔁 **红筹回归**：境外注册中资控股居民企业认定与税务后果
- 🤝 **协定与转让定价**：受益所有人判定、税收协定待遇申请、转让定价与CFC、预约定价安排
- ⚠️ **风险预警**：间接转让被穿透补税、受益所有人被否定、协定滥用反制

**典型问法：**
```
"非居民间接转让中国财产怎么穿透征税？"
"受益所有人认定标准是什么？"
"跨境重组能适用特殊性税务处理吗？"

```

### 六、配套税种与改制重组专项
- 🏗️ **资产重组增值税**：整体改制、资产重组、资产划转环节的增值税处理规则与不征税适用判定
- 🏘️ **土地增值税预征**：改制重组涉及不动产过户的土地增值税预征口径与暂不征收适用
- 🚗 **新能源车购税**：新能源汽车车辆购置税减半等绿色消费税收激励的合规适用
- 📊 **保险会计转换**：保险合同准则转换涉及的企税处理衔接
- ⚠️ **风险预警**：重组配套税种适用错误、优惠衔接断档、预征口径偏差

**典型问法：**
```
"整体改制资产重组要交增值税吗？"
"资产划转环节增值税怎么处理？"
"土增税预征口径有什么变化？"
"新能源汽车车购税减半怎么适用？"
```

### 土地增值税征管口径新规（重组资产划转/整体改制）
- 🏗️ **土增口径**：重组中资产划转、整体改制的土地增值税处理口径明确，须关注无偿划转、分立合并、企业合并等情形的土增征免边界
- 🔢 **配套税种**：与资产重组增值税、契税、印花税优惠协同适用，整体改制与资产划转增值税处理须一并规划
- ⚠️ **风险**：土增口径误判导致重组方案税负骤增，或错享免征导致后续稽查调整

**典型问法：**
"重组资产划转要交土地增值税吗？"
"整体改制土地增值税怎么处理？"
