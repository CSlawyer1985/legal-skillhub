# 人身损害赔偿 CLI 场景指南

适用于 `personal-injury-compensation-calculation` skill。目标是将用户提供的人身损害案件事实整理为 deli-cli 可执行的赔偿计算任务，并将返回结果映射为最终计算书。

使用本指南前，必须先执行 [cli-common.md](./cli-common.md) 中的前置检查和命令发现步骤。

## 一、CLI 命令使用原则

1. 先用 `npx @delilegal/deli-cli@latest cmds personal-injury-compensation-calculation@1.0.0` 获取本次 `RUN id`、命令名和参数。
2. 后续调用必须采用当次返回的 `npx @delilegal/deli-cli@latest run_... <command> [options]` 形态。
3. 不在本指南中固化真实命令名；以下示例中的 `calculate`、`estimate`、`injury-calc` 仅表示可能的计算命令类型，实际以 `cmds` 输出为准。
4. 参数优先在 `cmds` 返回的 `usage` 和 `params` 中选择，不主动假设 `--query`、`--semantic`、`--long-text`、`--amount`、`--json` 或结构化字段一定存在。
5. 不调用法规检索或案例检索命令；如果 `cmds` 只返回检索类命令，应停止并说明当前 skill scope 未提供可用计算命令。

示例 `cmds` 返回后，实际调用可能形如：

```bash
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 calculate --long-text "交通事故人身损害，2024年10月发生，受诉法院江苏南京，受害人42岁，九级伤残，需计算残疾赔偿金、误工费、护理费、营养费和被扶养人生活费"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 injury-calc --long-text "死亡赔偿案件，受诉法院广东广州，死亡时间2025年3月，受害人68岁，有两名被扶养人，需要计算死亡赔偿金、丧葬费和被扶养人生活费"
```

以上仅为参数组织示例。正式执行时必须替换为当次 `cmds` 返回的 `run_...`、命令名和参数。

## 二、用户事实组织

每次 CLI 调用只聚焦一个计算分支。优先按以下字段整理事实摘要：

| 字段 | 写法 |
| --- | --- |
| 地区与时间 | 案发时间、受诉法院所在地、一审法庭辩论终结时间或预计时间 |
| 人员事实 | 受害人年龄、死亡/伤残情况、伤残等级、多处伤残 |
| 鉴定事实 | 误工期、护理期、营养期、护理依赖、鉴定意见是否已出具 |
| 收入事实 | 固定收入实际减少额、最近三年平均收入、同行业平均收入 |
| 票据损失 | 医疗费、交通费、住宿费、鉴定费、财产损失、辅助器具费 |
| 被扶养人 | 年龄、人数、扶养义务人数、是否无劳动能力 |
| 统计参数 | 用户提供的官方统计数据、数据年度、来源链接或文件名 |
| 计算目标 | 全项计算、单项估算、责任比例前金额、责任比例后金额、对比口径 |

不要把用户没有确认的票据、收入、伤残等级、责任比例或统计数据当作已知事实。

## 三、CLI 结果映射

- `items`、`lines` 或等价字段：映射为赔偿项目明细。
- `statistics` 或等价字段：映射为统计数据来源、年度和口径。
- `dependent_summary` 或等价字段：映射为被扶养人生活费年度限额说明。
- `total`、`total_compensation` 或等价字段：映射为合计金额。
- `rule_refs`、`basis`、`articles` 或等价字段：映射为依据来源；未返回时只能引用本地 references 中对应索引。
- `warnings`、`risks` 或等价字段：映射为风险提示。

CLI 未返回的地方统计数据、司法鉴定结论、责任比例、精神抚慰金裁量、法院口径或额外赔偿项目不得自行补写。

## 四、后端计算服务边界

发布给 CLI 客户端的 skill 包只包含 `SKILL.md` 和 `references/`。计算逻辑由 CLI 命令调用后端 MCP 计算服务完成，不存在可供 agent 调用的本地计算入口。

调用后端计算服务时：

1. 只使用当次 `cmds` 返回的 `run_...`、命令名和参数形态。
2. 只采纳 CLI 返回的结构化计算字段，例如赔偿项目、基数、天数、年限、系数、限额、合计和风险提示。
3. 稳定公式和法条索引以本地 references 或 CLI 返回字段为准。
4. CLI 未返回计算结果或必要字段时，不得自行补算；应说明缺失字段并要求补充事实或等待后端计算服务支持。

## 五、无结果或参数不足

单次调用无结果、计算命令不可用或参数不足时：

1. 明确缺少的事实、统计参数或命令能力。
2. 优先追问用户可提供的事实或官方统计数据。
3. 可基于本地稳定规则说明计算口径和所需参数，但不得输出自行补算的确定金额。
4. 不连续换词调用检索命令，也不将检索结果替代计算结果。
