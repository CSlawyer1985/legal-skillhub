# 人身损害赔偿计算

## 定位

本 skill 用于人身损害赔偿金额计算，属于**计算类 skill**。

命中本 skill 后，必须以 `npx @delilegal/deli-cli@latest` 为默认入口发现和调用当前可用的后端 MCP 计算命令；不得调用法规检索或案例检索命令。稳定公式、赔偿项目口径、统计数据口径和法条索引以本 skill 的 `references/` 为准；用户事实必须来自用户或其材料。

---

## 数据源与前置要求

1. **deli-cli 前置检查**：先执行 [deli-cli 通用前置](./references/cli-common.md)，获取当前 `RUN id`、命令名、参数形态和描述。
2. **CLI 场景指南**：按 [人身损害赔偿 CLI 场景指南](./references/cli-personal-injury-guide.md) 将用户事实组织为后端计算任务。
3. **稳定规则**：公式、赔偿年限、伤残系数、被扶养人规则和法条索引来自 [计算公式与口径](./references/formulas.md) 与 [核心法条索引](./references/law_articles.md)。
4. **统计数据**：平均工资、城镇居民人均可支配收入、消费支出等稳定表格来自 `references/`；缺动态数据时以 CLI 返回、用户提供的官方统计材料或待核提示处理。
5. **禁止事项**：不得读取、创建或提示用户配置 skill 目录内旧 `config.json`；不得编造 CLI 未返回或 references 未载明的统计数据、赔偿金额、地方口径或裁判规则。

---

## 工作流程

### 1. 先抽取用户事实

先判断案件分支，再抽取必要事实；缺关键事实时只追问缺失项。每轮追问不超过 3 个问题，优先追问影响计算的核心字段。

| 分支 | 必要事实 |
| --- | --- |
| 通用 | 案件类型、案件发生时间、受诉法院所在地、一审法庭辩论终结时间或预计时间、受害人年龄 |
| 2022-05-01 前案件 | 户籍性质；农村户籍还需确认是否可按城镇标准主张 |
| 伤残案件 | 伤残等级、多处伤残情况、误工期、护理期、营养期、是否有鉴定意见 |
| 死亡案件 | 死亡时间、被扶养人情况、是否主张丧葬费 |
| 被扶养人生活费 | 被扶养人人数、年龄、扶养义务人数、是否无劳动能力 |
| 实际损失 | 医疗费、住院天数、交通费、住宿费、鉴定费、财产损失、辅助器具费等票据金额 |
| 收入与护理 | 固定收入实际减少额、最近三年平均收入、同行业收入、护理人员收入或护理费标准 |

用户未提供完整事实时，不得自行假设金额、地区、伤残等级、鉴定期限、收入水平或统计年度。

### 2. 调用计算能力

完成事实抽取后，按 `cli-common.md` 发现当前 skill scope 的可用命令，再按 `cli-personal-injury-guide.md` 组织参数。

计算类流程固定为：

```text
用户事实
  -> Agent 抽取/追问
  -> npx @delilegal/deli-cli@latest 发现命令
  -> 本地 references 获取稳定规则和参数口径
  -> 后端计算命令返回赔偿项目、基数、年限、系数、限额、风险
  -> Agent 输出计算书
```

如 CLI 暂不可用或当前 skill scope 未返回可用计算命令，不得自行补算或寻找本地执行入口；应说明计算服务不可用或参数不足，并基于 `references/` 提示用户需要补充的事实或待后端计算确认的字段。

### 3. 生成最终输出

根据用户问题深度，输出可以简洁或完整，但必须包含以下核心项：

| 模块 | 要求 |
| --- | --- |
| 案件事实摘要 | 地区、时间、受害人年龄、伤残/死亡分支、统计年度 |
| 计算标准 | 适用城镇/农村标准、工资口径、数据来源和是否待核 |
| 计算明细 | 每个赔偿项目的基数、天数/年限/系数、金额 |
| 合计金额 | 各项目合计；被扶养人生活费是否并入残疾/死亡赔偿金需说明 |
| 依据来源 | 优先使用 CLI 返回字段；未返回时引用本地法条索引和公式口径 |
| 风险提示 | 数据缺失、统计口径、鉴定缺失、城乡标准、精神抚慰金裁量等 |

---

## 质量控制

- 计算类 skill 不调用法规检索或案例检索命令。
- 用户事实必须来自用户或其材料；统计数据必须来自 CLI、用户官方材料或本地 references。
- 经济特区、计划单列市、农村居民收入、最新年度数据缺失时，不得套用其他地区数据。
- CLI 返回结果与本地 references 口径不一致时，标注差异并建议人工复核。
- 精神损害抚慰金、护理依赖、伤残等级、责任比例等裁量或事实争议，应作为风险提示，不得硬算为确定结论。
