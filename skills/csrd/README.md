# 企业可持续发展报告指令（CSRD）技能

> **免责声明：** 本技能基于《指令 (EU) 2022/2464》及依据《委员会授权法规 (EU) 2023/2772》发布的《欧洲可持续发展报告标准》（ESRS），提供关于 CSRD 合规义务的信息性指引。不构成法律意见或保证。CSRD 披露须由合格审计师或独立保证服务提供者进行法定有限保证——本技能支持准备流程，但不能替代保证约定或合格可持续发展报告专家的建议。

---

## 1. 本技能做什么？

本技能使 Claude 成为具备 **《企业可持续发展报告指令》（CSRD）**——《指令 (EU) 2022/2464》——和依据《委员会授权法规 (EU) 2023/2772》通过的 **《欧洲可持续发展报告标准》（ESRS）** 全面知识的欧盟可持续发展报告顾问专家。CSRD 于 2023 年 1 月 5 日生效，取代《非财务报告指令》（NFRD），并将强制性可持续发展报告的范围从欧盟约 11,000 家公司扩大到约 50,000 家公司。

技能引导财务、法律、可持续发展和合规团队走完 CSRD 实施的每个阶段：确定公司是否在范围内及何时必须首次报告，开展支撑所有 ESRS 报告决策的**双重实质性评估（DMA）**，对照强制性及主题性 ESRS 标准评估当前报告差距，起草合规的可持续发展披露，并为自首个报告年度起即要求的有限保证约定做好准备。

技能的核心是全面覆盖 **ESRS 标准架构**——两项交叉性标准（ESRS 1 一般要求和 ESRS 2 一般披露，对所有范围内公司均为强制性）以及涵盖环境（E1–E5）、社会（S1–S4）和治理（G1）主题的十项主题性标准。对每项主题性标准，技能涵盖适用条件、要求的披露和具体数据点——包括最难收集的定量指标（范围三温室气体排放、性别薪酬差距、损失工时伤害频率、生活工资分析）。

技能还涉及 **CSRD 综合提案（Omnibus Proposal）**（欧盟委员会，2025 年 2 月），该提案建议收窄范围并减少数据点，并就这些变化的当前立法状态提供建议。对于已有 GRI、TCFD 或 SASB 报告项目的组织，技能将这些框架映射到 ESRS 对应项，实现基于差距而非从零开始的实施。

## 2. 目标受众

| 受众 | 如何使用本技能 |
| ---- | -------------- |
| **CFO 和财务总监** | 范围确定、首个报告年度、保证就绪、财务实质性评估 |
| **可持续发展总监和 ESG 经理** | DMA 流程、主题性标准选择、披露起草、KPI 和数据点差距分析 |
| **法律与合规团队** | 监管范围分析、第 19a 条要求、保证义务、XBRL 标记要求 |
| **董事会和审计委员会** | 治理披露要求（ESRS 2 GOV-1 至 GOV-5）、监督义务 |
| **供应链与采购团队** | 价值链实质性、ESRS S2（价值链中的工人）、供应商数据收集 |
| **GRI/TCFD/SASB 报告团队** | 框架到 ESRS 的映射、差距识别、过渡规划 |
| **审计师与保证提供者** | 有限保证范围、ESRS 披露结构、证据要求 |
| **非欧盟公司** | 欧盟收入 >1.5 亿欧元且有欧盟子公司/分支机构的公司的门槛分析 |
| **上市中小企业** | 选择退出条款、面向中小企业的自愿 ESRS、第三阶段就绪规划 |

## 3. 常见用例

### 范围与门槛分析

- _"我们的公司受 CSRD 约束吗？我们是未上市的欧盟公司，280 名员工，营业额 4500 万欧元，总资产 2200 万欧元。"_
- _"我们是美国公司，在欧盟收入 2 亿欧元，有两家大型欧盟子公司。我们何时需要开始报告？"_
- _"我们的母公司已在做 CSRD 报告。我们作为子公司可以豁免吗？"_
- _"我们是上市中小企业。可以使用选择退出条款吗？"_

### 双重实质性评估

- _"带我走一遍如何在 ESRS 1 下开展双重实质性评估。"_
- _"CSRD 下影响实质性（impact materiality）与财务实质性（financial materiality）有何区别？"_
- _"我们如何评估一项影响的显著性？ESRS 1 对规模、范围和不可补救性怎么说？"_
- _"对消费品制造商，哪些 ESRS 主题性标准最可能具有实质性？"_
- _"我们已完成 DMA。ESRS E1、S1 和 G1 被认定为具有实质性。需要哪些披露？"_

### 对照 ESRS 的差距评估

- _"我们目前按 GRI 标准报告。运行一次 CSRD 差距评估，将我们现有的 GRI 披露映射到 ESRS 要求。"_
- _"我们做 TCFD 报告。除 TCFD 外，ESRS E1 还要求哪些额外披露？"_
- _"无论我们的 DMA 结果如何，哪些 ESRS 2 披露是强制性的？"_
- _"我们完全没有可持续发展报告。首个 CSRD 报告（FY 2025）我们需要产出什么？"_

### 披露起草

- _"起草我们的 ESRS 2 SBM-1（战略、商业模式和价值链）披露。"_
- _"帮我按第 19a(2)(a) 条要求撰写我们的 ESRS E1 转型计划叙述。"_
- _"我们自己的劳动力在 ESRS S1 下必须披露哪些定量数据点？"_
- _"起草一份描述董事会可持续发展监督角色的治理披露（ESRS 2 GOV-1）。"_

### 实施路线图

- _"为首个报告年度为 FY 2025 的公司构建一份 12 个月的 CSRD 实施路线图。"_
- _"我们需要建立从供应商收集价值链数据的机制。CSRD 要求什么流程？"_
- _"对 CSRD 而言，'有限保证'意味着什么？我们如何为保证约定做准备？"_
- _"哪些 XBRL 标记要求适用于我们的 CSRD 披露？"_

## 4. 如何使用本技能

### 安装

1. 从本文件夹下载 `csrd.skill` 文件
2. 在 Claude 中，前往 **设置 → 技能**
3. 点击 **上传技能** 并选择 `csrd.skill`
4. 技能在您的 Claude 会话中立即可用

### 触发技能

当您的消息与 CSRD、ESRS 或欧盟可持续发展报告义务相关时，技能自动激活。可触发它的示例短语：

- _"CSRD compliance"_
- _"ESRS reporting obligations"_
- _"double materiality assessment"_
- _"EU sustainability disclosure"_
- _"non-financial reporting Europe"_
- _"ESG reporting CSRD"_
- _"CSRD gap assessment"_
- _"ESRS E1 climate disclosures"_
- _"CSRD scope thresholds"_

### 示例提示

## 5. 技能实现细节

### 架构

```
csrd/
├── SKILL.md                          # 核心技能——法律依据、范围门槛、DMA、
│                                     #   ESRS 架构、关键披露、保证、
│                                     #   XBRL、实施工作流、框架比较
└── references/
    ├── esrs-standards.md             # 逐标准 ESRS 深入：适用性、
    │                                 #   要求的披露，以及全部交叉性和
    │                                 #   主题性标准的具体数据点
    ├── double-materiality.md         # DMA 方法论、评分模板、利益相关方
    │                                 #   参与指南、行业特定实质性指引
    └── compliance-program.md         # CSRD 实施路线图、治理设置、
                                      #   数据收集模板、保证就绪清单
```

**总计：** 4 个文件（SKILL.md + 3 个参考文件）约 1,175 行

### SKILL.md 中的内容

- **法律依据**——《指令 (EU) 2022/2464》、CDR (EU) 2023/2772 下的 ESRS、与《会计指令》的关系
- **范围与门槛表**——四类实体（大型公共利益实体、其他大型公司、上市中小企业、非欧盟公司），附规模标准和首个报告年度
- **双重实质性评估**——双视角框架（影响实质性 + 财务实质性）、按 ESRS 1 第 45–56 段的 8 步 DMA 流程
- **ESRS 标准架构**——交叉性标准（ESRS 1、ESRS 2）和全部 10 项主题性标准（E1–E5、S1–S4、G1），附关键内容
- **关键披露要求**——ESRS 2 强制性披露（GOV-1 至 IRO-1）；ESRS E1 气候数据点；ESRS S1 劳动力数据点
- **报告格式与保证**——管理层报告位置要求、XBRL/iXBRL 数字标记、有限保证义务（第 26a 条）
- **CSRD 与其他框架**——6 个维度上的比较表（CSRD/ESRS 对比 GRI 对比 TCFD 对比 SASB）
- **综合提案（2025）**——欧盟委员会简化提案及状态说明
- **四个实施工作流**——范围确定、差距评估、转型计划起草、价值链报告设置

### 参考文件中的内容

| 文件 | 内容 |
| ---- | ---- |
| `esrs-standards.md` | 逐项单独处理每个 ESRS 标准：ESRS 1 和 ESRS 2 强制性披露细节；E1（气候）、E2（污染）、E3（水）、E4（生物多样性）、E5（循环经济）；S1（自有劳动力）、S2（价值链工人）、S3（受影响社区）、S4（消费者）；G1（商业行为）——适用条件、要求的披露引用、具体定量数据点 |
| `double-materiality.md` | 详细 DMA 流程：影响显著性评分方法论（规模 × 范围 × 不可补救性）；财务实质性评估标准；按 ESRS 1 第 22 条的利益相关方参与要求；行业特定实质性指引；SBM-3 的 DMA 文件化要求 |
| `compliance-program.md` | CSRD 实施项目结构：治理设置（董事会监督、数据归属）、关键指标的数据收集模板、内部报告流程、保证就绪清单（有限保证范围和证据要求）、XBRL 标记时间表 |

| 输入 | 描述 |
