## 1. 劳动合同期限与试用期

### 期限分类

| 类型 | 法条 | 特征 |
|------|------|------|
| 固定期限 | 第13条 | 约定具体起止时间 |
| 无固定期限 | 第14条 | 未约定终止时间 |
| 以完成一定工作任务为期限 | 第15条 | 任务完成即终止 |

### 无固定期限合同签订条件（第14条）

满足以下任一，劳动者提出→用人单位应当签订：
1. 在该单位连续工作满10年
2. 用人单位初次实行劳动合同制度或国企改制重新签合同，劳动者连续工作满10年且距退休不足10年
3. 连续订立2次固定期限劳动合同，续订时劳动者提出

### 试用期限制（第19条）

| 合同期限 | 试用期上限 | 注意 |
|---------|-----------|------|
| 不满3个月 | 不得约定 | — |
| 3个月以上不满1年 | ≤1个月 | — |
| 1年以上不满3年 | ≤2个月 | — |
| 3年以上固定期限/无固定期限 | ≤6个月 | — |

同一用人单位与同一劳动者只能约定一次试用期。试用期工资≥转正工资80%且≥最低工资。

## 2. 劳动合同解除

### 用人单位单方解除

**过失性解除（第39条）— 无需补偿，但需证据充分：**
- 在试用期间被证明不符合录用条件
- 严重违反用人单位规章制度
- 严重失职，营私舞弊，给用人单位造成重大损害
- 同时与其他单位建立劳动关系，经提出拒不改正
- 以欺诈、胁迫手段订立劳动合同
- 被依法追究刑事责任

**非过失性解除（第40条）— 需N+1补偿：**
- 提前30天书面通知或额外支付1个月工资
- 劳动者患病或非因工负伤，医疗期满后不能从事原工作也不能从事另行安排的工作
- 不能胜任工作，经培训或调岗仍不能胜任
- 客观情况发生重大变化，合同无法履行，协商不成

**经济性裁员（第41条）— 需N补偿：**
- 人数门槛：20人以上或占职工总数10%以上
- 程序：提前30天向工会说明→向劳动行政部门报告
- 优先留用：固定期限较长、无固定期限、家庭无其他就业人员

### 劳动者单方解除

| 类型 | 条件 | 经济补偿 |
|------|------|---------|
| 提前通知解除（第37条） | 提前30天书面通知（试用期内提前3天） | 0 |
| 随时解除（第38条） | 未提供劳动条件/未足额支付报酬/未缴社保/规章制度违法 | N |

### 不得解除的情形（第42条）

- 从事接触职业病危害作业未进行离岗前检查/疑似职业病
- 在本单位患职业病或因工负伤，确认丧失或部分丧失劳动能力
- 患病或非因工负伤，在规定医疗期内
- 女职工在孕期、产期、哺乳期
- 在本单位连续工作满15年且距法定退休不足5年

### 程序要求

- **通知工会**（第43条）：单方解除前应事先通知工会
- **书面送达**：解除通知须送达劳动者本人

## 3. 经济补偿金

### 计算公式

```
N = 工作年限 × 月平均工资

工作年限算法：
- 满1年 → 1个月工资
- 6个月以上不满1年 → 1个月工资
- 不满6个月 → 0.5个月工资

月平均工资 = 解除前12个月的应发工资总额 ÷ 12
（含计时/计件工资、奖金、津贴、补贴等）

封顶规则（第47条）：
- 月均工资 > 当地上年度职工月平均工资3倍 → 按3倍计算
- 封顶后年限最高12年
```

### 赔偿金（违法解除）

```
2N = 经济补偿金标准 × 2
适用：用人单位违法解除/终止劳动合同
选择权：劳动者可要求恢复劳动关系 OR 支付2N
```

### 代通知金（第40条）

```
+1 = 额外支付1个月工资（按上年度月平均工资标准）
适用：非过失性解除未提前30天通知
注意：代通知金与N可叠加，即N+1
```

## 4. 工作时间与加班

### 标准工时

| 项目 | 标准 | 法条 |
|------|------|------|
| 每日工作 | ≤8小时 | 第36条 |
| 每周工作 | ≤40小时 | 国务院规定 |
| 延长工时 | 一般≤1小时/天，特殊≤3小时/天，每月≤36小时 | 第41条 |

### 加班费标准（第44条）

| 类型 | 标准 | 适用条件 |
|------|------|---------|
| 延时加班 | 150% | 正常工作日延长时间 |
| 休息日加班 | 200% | 不能安排补休时 |
| 法定节假日加班 | 300% | 不可用补休替代 |

### 综合计算工时

- 适用：交通、铁路、邮电、水运、航空、渔业等
- 以周/月/季/年为周期综合计算
- 总工时不超过法定标准工时
- 超出部分按150%支付加班费

## 5. 社会保险与公积金

### 五险

| 险种 | 缴费主体 | 比例（一般参考） |
|------|---------|-----------------|
| 养老保险 | 单位+个人 | 单位16%+个人8% |
| 医疗保险 | 单位+个人 | 单位8%+个人2% |
| 失业保险 | 单位+个人 | 单位0.5%+个人0.5% |
| 工伤保险 | 单位 | 单位0.2-1.9%（按行业） |
| 生育保险 | 单位 | 与医疗保险合并 |

### 住房公积金

| 主体 | 比例 |
|------|------|
| 单位 | 5%-12% |
| 个人 | 5%-12% |

### 违规后果

- 未缴社保：员工可随时解除劳动合同+要求N补偿
- 跨过行政处罚时效（2年）仍可要求补缴
- 滞纳金按日万分之五计算

## 6. 竞业限制与保密

### 竞业限制（第23-24条）

| 要素 | 要求 |
|------|------|
| 适格人员 | 高级管理人员、高级技术人员、负有保密义务的人员 |
| 期限 | ≤2年 |
| 补偿金 | 解除后按月支付；标准无统一规定，一般≥30%离职前12个月平均工资（司法解释）；约定不明→按30%认定 |
| 违约金 | 有约定可主张；过高可请求法院调整 |
| 生效 | 竞业限制协议约定为准；未约定补偿→劳动者履行了→仍可主张补偿 |

### 保密义务（第23条）

- 不限于高管/技术人员，可覆盖所有接触保密信息的员工
- 保密义务是法定+约定义务，无需额外支付对价
- 无期限限制

## 7. 工伤

### 工伤认定（第14-16条）

| 情形 | 认定 |
|------|------|
| 工作时间和场所内，因工作原因受伤 | 工伤 |
| 工作时间前后在工作场所内，从事预备/收尾工作受伤 | 工伤 |
| 工作时间和场所内，因履行工作职责受暴力等意外伤害 | 工伤 |
| 患职业病 | 工伤 |
| 因工外出期间，由于工作原因受伤 | 工伤 |
| 上下班途中，非本人主要责任的交通事故 | 工伤 |
| 工作岗位突发疾病48小时内死亡 | 视同工伤 |

### 工伤待遇

| 项目 | 支付主体 | 标准 |
|------|---------|------|
| 医疗费 | 工伤保险基金 | 实报实销 |
| 停工留薪期工资 | 用人单位 | 原工资待遇 |
| 一次性伤残补助金 | 基金 | 1级27个月~10级7个月本人工资 |
| 伤残津贴 | 基金 | 1级90%~4级75%本人工资（按月） |
| 一次性工伤医疗补助金 | 基金 | 解除/终止时支付（各省标准不同） |
| 一次性伤残就业补助金 | 用人单位 | 解除/终止时支付（各省标准不同） |

## 8. 女职工特殊保护

| 保护事项 | 法条 | 要点 |
|---------|------|------|
| 孕期 | 第42条 | 不得解除；不得安排禁忌劳动 |
| 产假 | 女职工劳动保护特别规定 | 基础98天+各地延长（普遍128-190天） |
| 哺乳期 | 第42条 | 不得解除；每天1小时哺乳时间（至婴儿满1周岁） |
| 薪资 | 女职工劳动保护特别规定 | 产假期间工资照发/生育津贴 |

## 9. 劳动仲裁时效与管辖

| 项目 | 规定 |
|------|------|
| 仲裁时效 | 1年（劳动争议调解仲裁法第27条） |
| 起算点 | 知道或应当知道权利被侵害之日 |
| 管辖 | 劳动合同履行地或用人单位所在地 |
| 前置程序 | 劳动仲裁是诉讼的前置程序（先裁后审） |
| 一裁终局 | 追索劳动报酬不超过当地月最低工资12个月金额的争议 |
