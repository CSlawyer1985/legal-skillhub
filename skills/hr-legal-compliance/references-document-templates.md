## 1. 解除劳动合同通知书（协商解除）

```
解除劳动合同通知书

致：{{员工姓名}}

鉴于以下情况，公司提议与您协商解除劳动合同：
{{解除原因说明}}

一、经双方协商一致，劳动合同将于{{解除日期}}解除。
二、公司依法向您支付以下款项：
  1. 经济补偿金：人民币{{金额}}元（大写：{{金额大写}}）
  2. 代通知金：人民币{{金额}}元（如适用）
  3. 未休年休假折算工资：人民币{{金额}}元（如适用）
  4. 其他：{{说明}}
  合计：人民币{{总金额}}元

三、请您于{{最后工作日}}前完成工作交接，包括但不限于：
  1. 归还公司财产（电脑、门禁卡、文档等）
  2. 移交工作资料和客户资源
  3. 配合完成离职手续

四、公司将在您完成交接后的{{结算日}}个工作日内将上述款项
    支付至您的工资账户。

五、如您同意上述方案，请在本通知书回执上签字确认。

{{公司名称}}
{{日期}}
```

{{日期}}

## 5. 竞业限制协议

```
竞业限制协议

甲方（用人单位）：{{公司名称}}
乙方（劳动者）：{{员工姓名}}

鉴于乙方在甲方担任{{岗位名称}}，接触甲方商业秘密和保密信息，
双方就竞业限制事宜达成如下协议：

一、竞业限制范围
  乙方离职后{{竞业限制期限，≤2年}}内，不得：
  1. 自行从事与甲方业务有竞争关系的业务
  2. 到与甲方有竞争关系的单位任职
  3. 为竞争单位提供咨询或服务

二、竞争单位范围
  包括但不限于：{{列举主要竞争对手或行业范围}}

三、竞业限制补偿金
  甲方按月向乙方支付竞业限制补偿金，标准为：
  人民币{{金额}}元/月（建议≥离职前12个月平均工资的30%）
  支付方式：每月{{支付日}}日前支付至乙方指定账户
  首次支付时间：离职后{{首月支付时间}}

四、违约责任
  如乙方违反竞业限制义务，应向甲方支付违约金人民币{{金额}}元，
  并继续履行竞业限制义务。

五、豁免
  甲方有权在竞业限制期内书面通知乙方解除竞业限制义务，
  解除通知到达乙方后，甲方不再支付补偿金（已支付部分不退还）。

六、争议解决
  因本协议引起争议，双方协商解决；协商不成的，提交{{管辖地}}
  劳动仲裁委员会仲裁。

甲方（盖章）：              乙方（签字）：
日期：                      日期：
```

## 6. 保密协议

```
保密协议

甲方（用人单位）：{{公司名称}}
乙方（劳动者）：{{员工姓名}}

一、保密信息范围
  乙方对在甲方工作期间接触的以下信息负有保密义务：
  1. 技术信息：技术方案、源代码、产品文档、研发计划等
  2. 经营信息：客户名单、供应商信息、定价策略、营销计划等
  3. 财务信息：财务报表、成本数据、薪酬信息等
  4. 人事信息：员工个人信息、组织架构调整计划等
  5. 其他：甲方以书面或其他形式标明保密的信息

二、保密义务
  1. 不得向第三方泄露保密信息
  2. 不得将保密信息用于与工作无关的目的
  3. 不得复制、传播保密信息（工作需要除外）
  4. 离职后保密义务持续有效

三、例外
  以下情况不视为违反保密义务：
  1. 已公开的信息（非因乙方原因）
  2. 乙方在入职前已合法知悉的信息
  3. 法律法规要求披露的信息

四、违约责任
  如乙方违反保密义务，甲方有权：
  1. 要求停止违约行为
  2. 要求赔偿损失
  3. 依据规章制度给予纪律处分直至解除劳动合同

甲方（盖章）：              乙方（签字）：
日期：                      日期：
```

| 信息类别 | 处理目的 | 保存期限 | 法律依据 |
|---------|---------|---------|---------|
| 身份信息 | 劳动合同签订、社保缴纳 | 劳动关系存续期间+争议时效 | 劳动合同法 |

| 薪资信息 | 薪酬管理、税务申报 | 离职后{{N}}年 | 税法 |
| {{敏感信息}} | {{具体目的}} | {{期限}} | 个人信息保护法 |

二、您的权利
您有权查阅、更正、删除您的个人信息，详情请联系
{{HR部门联系方式}}。

三、信息保护措施
我们采取技术和管理措施保护您的个人信息安全，包括
访问权限控制、加密存储、定期审计等。

{{公司名称}}
{{日期}}
