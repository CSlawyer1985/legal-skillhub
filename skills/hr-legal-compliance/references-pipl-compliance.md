## 1. HR场景个人信息处理原则

### 合法基础（第13条）

| 合法基础 | HR场景适用 |
|---------|-----------|
| 同意 | 非必要信息的收集（如紧急联系人、婚育状况） |
| 订立/履行劳动合同所必需 | 入职登记、薪资支付、社保缴纳 |
| 法律/行政法规规定 | 社保申报、税务代扣、工伤认定、公积金缴纳 |
| 用人单位正当利益 | 考勤管理（但需比例原则） |

### 最小必要原则（第6条）

- 只收集与劳动合同履行直接相关的信息
- 收集范围应明确、具体，不得一揽子授权
- 敏感个人信息（第28条）需单独同意+必要性说明+处理目的

### 敏感个人信息判定

在HR场景中，以下信息属于敏感个人信息：
- 生物识别信息（指纹打卡、人脸识别门禁）
- 医疗健康信息（体检报告、病假证明、工伤鉴定）
- 金融账户信息（工资卡号）
- 行踪轨迹（GPS考勤、外勤定位）
- 住址（精确到门牌号）
- 婚姻状况、生育信息
- 身份证号、护照号

## 2. 入职环节合规

### 信息收集

| 可收集（合同必需） | 需单独同意（敏感） | 不得强制收集 |
|-------------------|-------------------|-------------|
| 姓名、身份证号 | 紧急联系人信息 | 婚姻状况（非特殊岗位） |
| 联系方式 | 体检/健康信息 | 生育计划 |
| 学历/工作履历 | 生物识别信息 | 家庭成员详细情况 |
| 银行账户（发薪） | 住址（精确地址） | 宗教信仰、政治面貌 |
| 照片（工牌用） | 前单位薪资（背景调查） | 社交账号密码 |

### 背景调查

- 需取得候选人**书面授权**
- 调查范围限于岗位相关的必要信息
- 不得调查与工作无关的个人信息

### 入职同意

**合规做法**：
- 入职登记表/劳动合同中**分项**勾选同意（不打包）
- 提供《个人信息处理告知书》（处理目的+范围+方式+保存期限）
- 员工签署《个人信息处理同意书》（敏感信息单独签署）

**违规做法**：
- "员工同意公司处理一切个人信息"（一揽子授权→无效）
- 不告知处理目的和范围
- 将同意作为入职的前提条件（胁迫同意→无效）

## 3. 在职管理合规

### 考勤与监控

| 监控方式 | 合规要求 |
|---------|---------|
| 指纹/人脸打卡 | 需告知处理目的+范围+保存期限；需单独同意；提供替代方案（如工卡） |
| 电脑监控 | 需告知+有合理必要性；不得监控私人通信 |
| 视频监控 | 不得安装在更衣室、卫生间等私密空间；需设置标识 |
| 邮件监控 | 需告知+明确政策；使用公司邮箱系统可监控 |
| 外勤GPS | 需与工作直接相关；下班后不得追踪 |

### 薪酬信息

- 员工薪酬信息属于个人敏感信息
- HR有保密义务，不得向无关人员泄露
- "薪酬保密"制度：法律不禁止员工互相讨论薪酬（第9条劳动法），但可要求不得打探/传播

### 员工调查/满意度

- 匿名调查：确保真正匿名
- 非匿名调查：需告知处理目的+保存期限

## 4. 离职环节合规

### 信息处理

| 离职后信息 | 处理方式 | 依据 |
|-----------|---------|------|
| 劳动合同/社保记录 | 保存至法定年限 | 劳动争议仲裁时效+社保审计要求 |
| 薪资记录 | 至少保存3年 | 税务要求 |
| 体检报告 | 返还本人或删除 | 最小必要原则 |
| 生物识别信息 | 及时删除 | 信息存储限制 |
| 工作邮件/文档 | 约定归属+备份后删除个人内容 | 合同约定+最小必要 |

### 员工数据转移

- 员工有权要求将其个人信息转移至新用人单位
- 用人单位不得以离职为由拒绝配合

## 5. 员工权利响应

### 数据主体权利（PIPL第44-49条）

| 权利 | HR响应要求 | 时限 |
|------|-----------|------|
| 查阅权 | 提供个人信息副本 | ≤30天（可延长30天） |
| 更正权 | 核实后及时更正 | 立即 |
| 删除权 | 保存期满/处理目的已实现 | 立即 |
| 可携带权 | 提供结构化/通用格式副本 | ≤30天 |
| 撤回同意权 | 同意被撤回后停止处理（合同必需除外） | 立即 |

### 响应流程

1. 收到请求→登记→验证身份
2. 判断是否属于法定豁免（合同必需、法定保存期限）
3. 属于豁免→书面告知原因+提供受限副本
4. 不属于豁免→在30天内完成

## 6. 跨境传输

### HR场景常见跨境需求

- 集团全球HR系统统一管理
- 向境外总部汇报人员数据
- 外籍员工数据传回母国

### 合规路径（第38-43条）

| 路径 | 适用条件 |
|------|---------|
| 安全评估 | 处理达到国家网信部门规定数量（100万人或累计10万人） |
| 标准合同 | 未达到安全评估门槛→签署国家网信部门制定的标准合同+备案 |
| 认证 | 通过个人信息保护认证 |

### 实操建议

- 跨境前做**个人信息保护影响评估（PIA）**
- 与境外接收方签署数据处理协议
- 告知员工跨境传输的目的+接收方+权利

## 7. 合规检查清单

### 入职阶段

- [ ] 提供《个人信息处理告知书》
- [ ] 敏感信息取得单独书面同意
- [ ] 不收集与劳动合同无关的信息
- [ ] 背景调查取得书面授权
- [ ] 同意不作为入职前提条件

### 在职管理

- [ ] 考勤监控告知+替代方案
- [ ] 薪酬信息保密措施
- [ ] 定期审查信息保存期限
- [ ] 访问权限最小化（仅HR可访问完整档案）

### 离职阶段

- [ ] 不必要的个人信息及时删除
- [ ] 法定保存信息标注保存期限
- [ ] 配合员工行使可携带权

### 通用

- [ ] 指定个人信息保护负责人
- [ ] 制定HR个人信息处理内部制度
- [ ] 每年开展一次个人信息合规审计
- [ ] 对HR人员进行PIPL培训
