# 合同审查与起草技能 V1.0
## 核心特性
1. 本地资源优先：强制调用本地合同模板、法规、审查规则，无资源时自动兜底
2. 全维度审查：错字/标点/专业用词/法律风险一站式检查
3. 一体化服务：起草→审查→修订→Word导出全流程
4. 溯源可查：所有操作自动记录日志
5. 纯Python实现：仅需python-docx，无Node/JS环境依赖

## 触发指令
- 审查合同/合同审查：启动全维度合同审查
- 起草合同/生成合同：按本地模板生成标准化合同
- 导出合同审查修订版/创建Word版合同：导出审查报告+修订版合同
- 查看本地合同模板/查看本地法规库：展示本地资源

## 导出文件
- 合同审查报告.docx：问题清单、修改建议、法规依据
- 合同修订版.docx：带修改痕迹的标准化合同文本
