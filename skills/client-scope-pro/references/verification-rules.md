# 重大事项核验规则与 Fact Card 规范（verification-rules）

## 1. 必须核验的事项清单

重大诉讼、仲裁、被执行、失信、行政处罚、刑事风险、股权冻结（含轮候冻结）、重大债务、债务逾期、担保风险、破产／预重整／重整、重大审计异常（更换审计机构、非标意见）、证券监管（立案、纪律处分、公开谴责、通报批评）、控制权变化（质押违约、司法拍卖、协议转让）、安全生产事故、严重环保问题。

核验标准：信源达一级或二级方可记【已核验事实】；仅三级/四级信源记【待核实】；证据不足不得写成确定事实。

## 2. Fact Card 字段（固定 15 项）

Fact ID｜事项名称｜企业主体｜事实内容｜发生时间｜披露时间｜来源文件｜发布主体｜原始链接｜信源等级｜核验状态｜交叉验证情况｜对应附件编号｜法律意义｜是否进入报告

另记录：检索/访问日期；如已保存原始附件，记录实际文件名。Fact Card 必须能通过 Fact ID 与正文标注、附件索引三向互查。

### 2.1 Fact ID 使用规则（V2 实战修订）

- Fact ID 沿编号 F01、F02…顺序分配；正文在关键数据后以【附件A01】【F05、F06】形式内联标注；
- **不设独立 Fact Card 汇总表**（正文已完整呈现事实，汇总表属冗余表格）；Fact Card 作为工作底稿留存于检索记录/中间产物中，正文与附件索引承担溯源职能；
- 新旧信息冲突处理：同一事实前后口径不一致（如2024年亏损额在当年年报与次年年报"上年同期"栏不一致）→ 按时间先后与差错更正逻辑判断，差异部分标【待核实】或"原披露口径"，不得悄悄取其一。

## 3. 常见核验陷阱（实战清单）

1. **主体错配**：集团内多家近似名称主体（母公司/项目公司/合资公司）；媒体报道简称与工商全名不一致。
2. **持股数矛盾**：协议转让/拍卖公告与后续定期报告披露的实控人持股数不一致——交易可能未完成过户，双向列明并标【待核实】。
3. **金额口径**：累计诉讼公告存在多期口径（12个月滚动 vs 半年度），引用时注明公告日期与口径。
4. **转述失真**：媒体转述公告常省略"未结/已结""占净资产比例"等限定语——重大数字尽量回原文。
5. **关系传闻**：实控人家庭关系等自媒体表述，无官方文件佐证一律【待核实】。
6. **时间≠因果**：CFO离任、审计辞任与业绩违规先后发生，只能写"时间接近，为治理风险信号【分析判断】"。

## 4. 分析模型（每一重要事项固定五层）

【已核验事实】（含 Fact ID 与附件编号）→【影响】→【法律问题】→【服务机会】→【建议核实】

禁止表述"客户一定需要某项法律服务"；服务机会须写触发事实＋判断依据＋潜在服务＋建议询问问题。

## 5. 时间轴与连续性分析

近 3—5 年重大事件按时间排列后，识别经营异常→债务压力→诉讼/执行增加→监管介入→控制权变化→破产重整的演进链条。区分三个层次：事实（有信源）、相关性（先后继起）、推断（明确标注）。不得因时间接近直接认定因果关系。
