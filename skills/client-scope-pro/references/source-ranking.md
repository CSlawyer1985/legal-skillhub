# 信源分级与证据保存规则（source-ranking）

## 1. 信源四级分级

| 等级 | 定义 | 典型信源 | 使用规则 |
|------|------|----------|----------|
| 一级 | 监管决定／法定披露原文 | 交易所纪律处分决定原文（PDF）、巨潮/深交所官网托管的公司公告原文、法院裁判文书、企业破产重整案件信息网、信用中国、中国执行信息公开网 | 可直接作为【已核验事实】 |
| 二级 | 法定披露的权威转述 | 新华财经/中国金融信息网/证券时报等对公告全文的逐段转述；定期报告数据经权威财经媒体转述 | 可作【已核验事实】，注明"公告转述"，建议拜访前调原文复核 |
| 三级 | 媒体报道与观点 | 大众证券报、每日经济新闻等报道；维权律师观点；自媒体 | 属【主体观点】或【待核实】，不得单独支撑"已核验事实" |
| 四级 | 商业聚合平台数据 | 爱企查、天眼查等聚合的司法案件数、被执行/失信条数、参保人数、专利数 | 仅作检索线索，一律标【待核实】，注明"以官方渠道查询为准" |

## 2. 检索顺序

对任何重大事项，按 一级 → 二级 → 三级 → 四级 的顺序**回溯**：先从聚合平台/媒体获得线索，再向官方原始信源回溯确认。只停在四级信源的事项不得写成确定事实。

禁止仅依据以下来源形成确定事实：搜索引擎摘要、AI 自动摘要、自媒体、股票论坛、商业聚合平台、未核验新闻报道。

## 3. 证据保存（Evidence Pack）

对每项重要事实至少保存：原始 URL、材料发布日期、材料名称、发布主体、检索/访问日期、对应附件编号。

### 3.1 下载实操（实战经验）

1. 巨潮资讯网 `static.cninfo.com.cn/finalpage/...` 直链 curl 常返回 403（返回体为 HTML 而非 PDF）。处理顺序：
   - 直链下载 → `file *.pdf` 校验；
   - 失败则加 `-A "Mozilla/5.0 ... Chrome/126"` 与 `-e "http://www.cninfo.com.cn/"` 重试；
   - 仍失败：找**深交所官网托管的同名/早版本公告**（`disc.static.szse.cn`、`reportdocs.static.szse.cn`）作**替代存证**——交易所常托管历史版本，内容关键信息通常一致，须在索引中注明版本差异；
   - 无任何官方托管：以二级信源全文转述核验，索引中记录"未保存（403）"。
2. 替代存证文件延续编号为 A11、A12…（不占用正文引用的 A01—A10 段位），并在附件索引的"存证状态"栏写明对应关系（如"A04 之替代存证"）。
3. **不得伪造附件**。检索环境无法稳定获取的文件，如实记录 URL 即可。
4. 证据包目录结构：交付目录下 `evidence/` 子目录，文件名 `{编号}_{材料名}_{发布日期}.pdf`。

### 3.2 附件索引表字段（固定）

附件编号｜材料名称｜发布主体｜发布日期｜原始URL｜访问日期｜存证状态｜对应Fact ID

存证状态取值：`已保存：evidence/文件名`／`未保存（403）`／`未保存（三级信源）`／`未保存（四级信源，仅作线索）`。
