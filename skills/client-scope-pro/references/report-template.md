# 主报告内容模板（report-template）

## 报告封面要素

居中式律师版式：`关于` / `{企业全称}` / `之` / `背景调查及法律服务机会分析报告`（大字）/（律师首次拜访前公开信息核查·内部参考）/ `二〇二六年九月`（汉字年月）。

## 五部分结构（固定）

### 第一部分：引言
- 一、目的和使用：内部参考、不构成法律意见、公开信息可能滞后。
- 二、释义：术语双栏表（15—22 个），覆盖报告中出现的专业缩写与程序术语（如 \*ST、预重整、临时管理人、无法表示意见、出资人权益调整、Fact ID、信源分级、D&O）。"本节释义仅服务于本报告的阅读理解，不构成法律定义。"
- 三、信源原则与核验规则：四类标注定义、信源分级、Fact ID 与附件编号溯源机制、references 缺失或公告未存证的说明。
- 四、相关基准日：信息检索截止日、报告出具日。
- 五、执行摘要：7 条左右核心风险（每条带 Fact ID），末尾一段【分析判断】给出最可能的服务需求组合。

### 第二部分：主体确认与企业分类
- 一、主体确认：企业基础信息表（项目｜内容｜信源与标注）——**必保留的表格**；主体消歧说明。
- 二、企业分类与调查重点：（一）—（五）层级文字；末尾一段动态调查重点。

### 第三部分：风险与服务机会（核心章）
开头一段说明合并逻辑（原重大事项核验＋检索矩阵概览＋服务机会识别三章合一，按具体事项分类对齐）。每个事项为二级标题，内部固定五层（见 verification-rules §4）。末两级：
- "十一、其他检索模块概览"：将检索矩阵 23 模块中未成事项的模块按 `1. 模块名：发现＋标注` 层级文字呈现（**不制表**）；
- "十二、法律服务机会优先级汇总"：高（一）/中（二）/储备（三）三级，层级文字，每项含触发事实、判断依据、可提供服务。

### 第四部分：重大事件时间轴与连续性分析
时间轴表（时间｜事件｜标注）——**必保留的表格**；其后"连续性分析"3 条左右（演进链条判断、口径差异推断、因果边界提示）。

### 第五部分：访谈与材料清单
- 一、首次会谈建议询问的十个问题（顺序即优先级）；
- 二、建议接触的企业内部岗位；
- 三、敏感问题与沟通边界（敏感问题／不宜直接作出的判断／推荐沟通措辞三类）；
- 四、待核实事项与建议取证清单（拜访前核实动作）＋质量审核记录说明；
- 五、附件索引及证据材料清单（**必保留的表格**，字段见 source-ranking §3.2）＋已存证原始文件列表。

### 附：免责声明
基于检索截止日公开信息、内部参考、不构成法律意见、以最新公告为准。

## 标注与溯源规则

- 每个关键数据后内联【附件A01】【F05、F06】；
- 全文区分【已核验事实】【主体观点】【分析判断】【待核实】；
- 分析性结论前必须带标注；不得将【分析判断】写成事实。

## 快速背调模式（精简输出）

仅输出：执行摘要、重大风险（五层模型精简版）、法律服务机会（三级）、首次会谈问题。不生成 Word/PDF，先文字交付待用户确认。
