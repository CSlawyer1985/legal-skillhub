# 建设工程纠纷答疑+司法解释、法院案例Plus

## 文件说明

- `SKILL.md`：主入口文件，包含完整的提示词设计（version 5.4.0）
- `references/司法解释一.md`：最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）（法释〔2020〕25号）
- `references/司法解释二.md`：最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（二）（法释〔2026〕12号）
- `references/典型案例.md`：最高法发布建设工程施工合同纠纷典型案例（共6个）
- `references/答记者问.md`：最高法民一庭庭长陈宜芳就解释（二）答记者问
- `references/法答网精选答问_建设工程.md`：从法答网第1-37批中精选的建设工程相关答问（第15、24、26批）
- `scripts/md_to_docx.py`：Markdown 转 docx 辅助脚本，用于将分析内容导出为 Word 文档

## 设计要点

1. 固定四主段回答结构：
   - 一、归纳性回答
   - 二、详细分析（（一）建工解释一、（二）建工解释二、（三）其他法律法规 + 法答网精选答问）
   - 三、参考案例（精选5个）
   - 四、其他（含风险提示、免责声明、AI 生成提示）
2. 法律依据优先级：先《建工解释（一）》《建工解释（二）》，再补充《民法典》《建筑法》《招标投标法》《民事诉讼法》，最后辅以法答网精选答问权威答疑
3. 引用条文时必须给出原文或完整核心内容，严禁仅列条号
4. 重要时点与同名司法解释说明：《建工解释（一）》以法释〔2020〕25号为准，历史上旧版法释〔2004〕14号已被替代；《建工解释（二）》特指 2026 年法释〔2026〕12号；历史上还有 2018 年法释〔2018〕20号同名解释，已被 2020 年《建工解释（一）》和 2026 年《建工解释（二）》替代。检索和引用时必须以完整发文字号区分，此前发生的纠纷需谨慎适用
5. 案例检索前必须确认或询问管辖地（工程所在地/不动产所在地），并支持多轮对话中记忆已确认管辖地
6. 默认优先检索 2021-01-01 以后裁判且明确引用两部司法解释（含全称、简称）的判例，精选5个案例
7. 华宇元典 MCP 不可用时自动切换到内置典型案例，并明确说明；若内置典型案例仍不足，应如实说明无法提供5个匹配案例
8. 案例输出必须与"二、详细分析"中的法律依据建立对应关系，**每个案例必须标注案号或清晰来源（如"最高法典型案例·案例X"），严禁使用来源不明的案例**
9. 四、其他中增加"类案不同判风险"提示
10. 集成华宇元典 MCP（yuandian_list_apis / yuandian_get_api_doc / yuandian_law_vector_search / yuandian_case_vector_search / yuandian_rh_ptal_search / yuandian_rh_qwal_search / yuandian_rh_case_details）
11. **新增**：集成法答网精选答问，在"二、详细分析（三）"中增加法答网精选答问维度，作为最高法专家权威答疑的补充印证
12. **术语更新**：自 2026-06-30 起，《建工解释（二）》不再使用"实际施工人"概括性表述，skill 中相应区分"借用资质的单位或个人""接受转包的单位或个人""接受违法分包的单位及个人""农民工"四类主体；解释一第 43-44 条仅在 2026-06-30 前受理或事实发生在该日期前的案件中保留适用
13. **同名司法解释区分**：案例检索优先以完整发文字号（法释〔2020〕25号、法释〔2026〕12号）作为援引法条条件；若命中 2018 年法释〔2018〕20号 判例，应明确标注为旧版解释、作为历史参考
14. **生成 docx 文件（可选）**：每次回答结束后主动询问用户是否将分析生成 docx 文件保存到桌面；用户确认后才执行文件写入操作，未确认前不得操作任何文件
