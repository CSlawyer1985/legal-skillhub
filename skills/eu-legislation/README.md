# 欧盟立法与判例法

直接从 Claude Code 访问欧盟法律。

## 功能

- **检索**欧盟立法和判例法（24 种语言）
- **获取**指令、条例、决定、条约、欧洲法院判决全文
- **核查状态**——现行有效、已修改、已废止
- **查看修改**——哪些法律文件修改了本法
- **转化状态**——哪些成员国转化了某指令
- **程序历史**——从提案到通过的立法程序

## 用法

```
"给我 GDPR"
"吹哨人指令是否已在法国转化？"
"CSRD 做了哪些修改？"
"显示 AI 法案的程序历史"
"查找关于 Cookie 同意的欧洲法院判决"
```

## 运作方式

| 事项                    | 方法          |
|-------------------------|-----------------|
| 按概念检索       | EUR-Lex 检索  |
| 状态与修改  | EUR-Lex /ALL/   |
| 转化           | EUR-Lex /NIM/   |
| 程序               | EUR-Lex /HIS/   |

## 语言

EN、FR、DE、IT、ES、NL、PL、PT 及全部 24 种欧盟语言。
