01 · Skill 的本质

先纠正一个最常见的误解：Skill 不是"一个保存起来的长提示词"。它是能力封装——把一套完成某类工作的方法、标准和工具，打包成 AI 可以自主发现和调用的组件。

一、六个容易混淆的概念

法律人第一次接触 AI 工作流时，最常在六个概念之间迷路。它们的关系可以用一张表说清：

概念本质什么时候生效法律工作中的类比
Prompt一次性对话指令这一次对话口头交代实习生办一件事
工作区规则（CLAUDE.md / rules）持久化的行为约束该工作区每一次会话律所的办案规程，进门就要遵守
Skill可调用的能力包（方法+标准+工具）AI 判断当前任务需要时自动加载一本《某类案件操作指引》，需要时才取下来用
Agent能自主规划、调用工具、循环执行的执行体被委派任务时一名可以独立办案的律师
MCP连接外部系统/数据的协议接口需要读写外部世界时律所开通的各类数据库账号（法宝、企查查）
Plugin打包分发的载体（可含多个 Skill/命令/Agent）安装后一整套引进的管理系统

关键区别在于：规则是"必须遵守"，Skill 是"需要才用"。你不需要 AI 每次都背一遍《建工司法解释》，你只需要在它处理建工案件时，能准确调用建工案件的处理方法——这就是 Skill 的位置。

二、一个 Skill 长什么样

一个 Skill 就是一个文件夹，里面唯一必须存在的是一张"名片"——SKILL.md：

contract-review/
├── SKILL.md          ← 必须：名片（叫什么、什么时候用、怎么做）
├── references/       ← 可选：知识库（法规、审查标准、内部口径）
├── scripts/          ← 可选：工具脚本（检索、计算、格式处理）
├── assets/           ← 可选：模板（合同范本、文书样式）
└── LICENSE           ← 可选：授权文件

AI 启动一个任务时，会先读所有 Skill 的"名片摘要"（frontmatter 里的 name 和 description），判断哪个 Skill 与当前任务相关；命中后才加载 SKILL.md 正文；正文里引用的附属文件，再按需读取。这个机制叫渐进式披露——用多少，加载多少，不浪费上下文。

本站收录的 2049 个法律 Skill 就是这个结构的 2049 个实例：约 65% 是"纯名片"（只有 SKILL.md），约 17% 带知识库，约 17% 带工具脚本。你可以在技能库里按"知识包型"筛选看看带知识库的长什么样。

三、Skill 是能力封装，不是知识堆积

新手写 Skill 最容易犯的错误，是把 Skill 当成"知识容器"——往里面堆法条、堆解释、堆资料。这是错的。法条 AI 训练时大多读过，你堆进去只是重复；真正让 Skill 有价值的是模型原本不知道的东西：

  • 你的方法：审查一份建工合同，你先看什么、再看什么、什么条款必须动、什么条款可以让；
  • 你的标准：什么样的违约金约定算"明显过高"，你的口径是超过 LPR 几倍；
  • 你的流程：先核验主体资格，再看效力性条款，最后看价格机制——顺序本身就是专业判断；
  • 你的模板：所里用了五年的法律意见书格式，每个部分怎么写、不能写什么；
  • 你的工具：一个能自动检索法规库的脚本，一套能生成批注版合同的工具链。
检验标准：如果一个内容删掉了，AI 的输出质量会明显下降——它才值得写进 Skill。法条原文属于"删了 AI 也知道"的，放检索路径和验证方法，别堆原文。

四、为什么法律人尤其需要 Skill

法律服务有个结构性矛盾：经验在资深律师脑子里，工作在 junior 手上。Skill 恰好打在这个点上：

  1. 方法论复用：把"怎么审一份抵押合同"写一次，全团队每次都能复用，不用逐个教；
  2. 质量稳定：AI 没有状态起伏——你写进 Skill 的审查清单，它每一次都逐项过，不会像人一样第 50 份合同开始走神；
  3. 团队传承：资深律师离开，方法论留下。Skill 是比"师带徒"便宜得多的传承介质；
  4. 能力组合：审查合同 → 生成批注版 → 起草沟通函，三个 Skill 串起来就是一条工作流。

这不是说 AI 能替代律师判断——而是说律师的判断可以被封装成工具，在每一次相似任务中被稳定调用。这是本学习中心后面六讲要手把手教你做的事。

五、Skill 可以跨平台迁移

Skill 的开放标准（agentskills.io）意味着它本质上是一个结构化的 Markdown 文件夹：不绑定某个 AI 产品。同一个 Skill 文件夹，放进 Claude Code 的 ~/.claude/skills/ 能用，放进其他遵循同一标准的 Agent 环境也能用。这也是本站把所有 Skill 以原始文件夹形式提供下载的原因——它不是某个平台的私有格式，而是你的工作资产。
