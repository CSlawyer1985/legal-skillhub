学习中心

《把专业经验封装成 Agent Skill》—— 不是教 YAML 语法，而是把律师脑中的判断方法、事实审查习惯、风险口径和交付标准，蒸馏成既不僵化又能稳定复现的 Skill。2049 个真实法律 Skill 就是最好的教材。

01
Skill 的本质
Prompt / 工作区规则 / Skill / Agent / MCP / Plugin 的区别；Skill 是能力封装，不是知识堆积
 02
什么适合做 Skill
反复做 + 有判断框架 + 有质量标准；七步蒸馏法：任务边界→输入→判断节点→步骤→质量标准→异常→输出
 03
编写 SKILL.md
描述就是路由器；触发与不触发；Intake 先行；任务自由度；渐进式披露
 04
工作环境与配套条件
运行宿主与目录机制；脚本/文档工具链/OOXML/检索/API key/MCP 各类依赖；安装验证与触发排查
 05
什么是好的法律 Skill
法域识别与法律时效；来源核验；事实与法律分离；禁止虚构；人工复核节点；正反案例对照
 06
评测和迭代
写完≠能用：3 正常+2 边界+2 不触发+1 对抗；有/无 Skill 基线对比；可测量增量
 07
