07 · 从 2049 个样本看法律 Skill

本站收录的 2049 个法律 Skill 是一个罕见的语料库——它让我们第一次能宏观地看清"法律人正在用 AI 做什么、怎么做"。这一讲用数据说话。

一、语言与风格：中文与英文几乎对半

本站收录的 2049 个法律 Skill 中，中文内容 1003 个、英文内容 1046 个，几乎对半。这意味着你能同时看到中英两种法律工作流的写法——这是任何单语 Skill 库都给不了的视角。

二、两种风格的对照

中文系 Skill 有强烈的"角色扮演 + 方法论灌注"倾向：

你是一名资深建设工程律师。请按照以下方法论审查施工合同……
（随后是上千字的领域知识与方法论叙述）

英文系 Skill 则更多是"程序化 SOP"：

## Intake
Collect: contract type, governing law, client position…
## Workflow
1. Identify parties → 2. Scope obligations → …
## Output Contract
Each risk: clause ref + risk level + basis + recommendation

两种没有绝对优劣：中文风格擅长把"律师怎么想"灌进去，适合需要专业判断的任务；美国风格擅长把"步骤怎么走"固化，适合需要稳定复现的任务。最好的法律 Skill 往往是两者的混合——用 SOP 锚定流程，用方法论灌注判断。

三、法域分布：中国与美国是绝对主力

主法域数量启示
中国大陆801中文法律 Skill 生态已相当成熟
美国608程序法（FRCP/FRBP）和行业监管（SEC/FDA/EEOC）的 Skill 最密集

欧盟113集中在 GDPR / AI Act 数据合规

一个值得注意的空白：日本、韩国、新加坡、香港、东南亚的法域 Skill 数量极少（个位数）。随着这些法域的合规需求上升，这正是写 Skill 的机会区。

四、技能形态：七成是"纯指令型"

形态数量占比

大多数法律 Skill 还停留在"一段好的指令"。真正把法律工作工程化（带检索脚本、知识库、验证闭环）的是少数——而这少数恰恰是质量最高的那批。从"指令"走向"工程"，是法律 Skill 进化的主方向。

五、法律 Skill 写作十条军规（从语料提炼）

  1. description 是路由器，不是简介——写清做什么、何时用、何时不用。
  2. Intake 先于分析——先收集事实，再下判断；不直接跳结论。
  3. 流程刚性 + 判断弹性——步骤锁死，判断给标准与空间。
  4. 渐进式披露——SKILL.md 做导航，知识拆附属文件一层。
  5. 输出契约具体到要素——每个风险点含哪几项，写死。
  6. 禁止虚构——法条/案例/案号必须可检索验证。
  7. 法域自觉——声明法域，跨域时退出。
  8. 事实/规范/评价三层分离——别混着写。
  9. 人工复核节点显式化——AI 给选项，人拍板。
  10. 用评测证明价值——相对基线的可测量增量。

这十条，前五条是"写得成"，后五条是"用得起"。本学习中心的前六讲，本质上都在展开这十条。
